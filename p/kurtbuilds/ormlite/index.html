Rust 语言 ORM，基于 sqlx，通过 Model 宏与原始 SQL 片段提供查询与迁移生成

综述（解读层）

ormlite 是一个面向 Rust 开发者的 ORM，底层构建在 sqlx 之上，支持 Postgres 与 SQLite 等数据库。它通过 `#[derive(Model)]` 派生宏生成模型的插入、更新、查询方法，迁移文件由 CLI 从 Rust 结构体自动生成，并提供 up/down 快照回滚。查询构建器拼接原始 SQL 字符串片段，支持以 `?` 占位符统一书写参数。适合已熟悉 SQL、希望保留手写查询能力的 Rust 后端开发者。需注意 join 功能处于 alpha 阶段，仅支持多对一关系。

  • 基于 `#[derive(Model)]` 宏自动生成模型的插入、更新、查询与 join 方法，支持插入结构体、builder 语法、upsert 等方式
  • 通过 ormlite-cli 从 Rust 结构体自动生成 SQL 迁移文件，`up` 默认创建快照并支持 `down` 回滚
  • 查询构建器拼接原始 SQL 字符串片段，统一使用 `?` 占位符并在 Postgres 中自动转换为 `$n` 占位符；支持回退到原始查询与底层 `sql` 引擎

适用场景（解读层）

  • Rust 后端项目中需要同时使用 ORM 方法与手写 SQL 查询的场景
  • 希望从 Rust 结构体自动生成数据库迁移文件并管理快照回滚的开发流程
  • 使用 Postgres 或 SQLite、包含 UUID/时间/JSON 字段的数据模型应用
