🧭 简介解读层（AI·证据行可回查）

TypeScript 持久化可恢复工作流框架，支持 Node.js 与 Bun。

综述（解读层）

OpenWorkflow 是一个 TypeScript 框架，用于构建可持久化、可恢复的工作流：任务可暂停数秒至数月，在崩溃或重新部署后从断点继续执行，无需额外管理服务器。通过 defineWorkflow 定义工作流，提供 CLI 初始化工具，支持 SQLite 和 PostgreSQL 作为后端存储，并提供仪表盘与 OpenTelemetry 文档。适合需要在 Node.js 或 Bun 中实现长时间后台任务的团队。

  • 工作流可暂停数秒到数月，崩溃或部署后从断点恢复
  • 提供 CLI 初始化工具，支持 SQLite 和 PostgreSQL 后端
  • 支持 Node.js 与 Bun 运行，文档含 OpenTelemetry 与生产检查清单

适用场景（解读层）

  • 需要长时间等待或跨部署存活的后台任务编排
  • 依赖崩溃恢复能力的事件驱动流程（如欢迎邮件、审批链）
  • 基于 TypeScript 技术栈的后台作业与工作流引擎搭建
