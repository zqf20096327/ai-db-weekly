🧭 简介解读层（AI·证据行可回查）

位于 Keycloak 与 PostgreSQL 之间的透明协议代理，在读写路径上加密 PII 列

综述（解读层）

该项目实现一个 PostgreSQL wire-protocol 代理，部署在 Keycloak 与 CloudNativePG 数据库之间，对写入的指定 PII 列加密、读取时解密，数据加密密钥由 KMS（Vault Transit 或静态 KEK）封装，不落库。提供离线 backfill 工具迁移存量明文，支持确定性加密保留按用户名/邮箱登录。不防护已被攻陷的代理或 Keycloak 进程。面向运维 Keycloak 的团队，Apache-2.0 许可。

  • 双向终止 SCRAM 并重建 TLS，按 Parse→Bind→Execute 状态跟踪参数，写入在 Bind 加密、读取在 DataRow 解密，未识别语句字节透传
  • 加密值带自描述 $KKP$ 标记，支持对部分加密数据库运行及幂等 backfill；用户名/邮箱列采用 AES-SIV 确定性加密以支持等值匹配
  • 支持静态 KEK 与 Vault Transit 两种 KMS，Vault 认证可用 Kubernetes、AppRole 或静态 token，并提供 Prometheus metrics 端点

适用场景（解读层）

  • 要求 Keycloak 用户 PII 列在数据库侧保持密文、密钥存于 PostgreSQL 之外的环境
  • 迁移已有 Keycloak 明文数据：停机后用 cmd/backfill 生成 DEK 集并批量加密存量行
  • 在 Cozystack 上通过 keycloak 系统包的开关式功能集成部署
