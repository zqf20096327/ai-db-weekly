SQLite 灾难恢复工具，以后台进程增量复制变更到文件或 S3

综述（解读层）

Litestream 是面向 SQLite 的独立灾难恢复工具，以后台进程运行，将数据库变更增量复制到另一文件或 S3。它仅通过 SQLite API 与数据库通信，复制时会在源库中创建 _litestream_lock 表以协调 WAL 检查点，因此源库 schema 与字节数会发生变化。适合需要对 SQLite 数据做异地备份的用户。

  • 以后台进程方式将 SQLite 变更增量复制到文件路径或 S3
  • 仅通过 SQLite API 与数据库通信

适用场景（解读层）

  • 需要将 SQLite 数据库备份到 S3 等对象存储的场景
  • 本地文件到本地/远程文件副本的增量备份
  • 需要进程级超时控制以保证最终同步完成的部署
