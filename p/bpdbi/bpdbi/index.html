JVM 上的 Postgres 阻塞式数据库接口库，以管道化为一等概念

综述（解读层）

Bpdbi 是运行在 JVM 上的 Postgres 阻塞式数据库访问库，从 Vert.x SQL Client 移植并移除异步/响应式机制，使用 java.net.Socket 做 I/O，不依赖 JDBC 与 Netty。核心提供 enqueue()/flush() 管道 API，可将多条语句合并为一次网络往返；连接非线程安全，标准用法为从池中借还连接。面向 Java 21+ 虚拟线程及 Kotlin 用户，经 Maven Central 发布，核心模块体积小于 200kB。

  • 提供 enqueue()/flush() 管道 API，将多条语句在一次网络写入中发送并一次读取全部响应，query() 调用同样参与同一管道机制
  • 所有查询使用扩展查询协议的二进制格式，Row 采用延迟解码与列式存储，未读取的列不解码
  • 核心与驱动模块不使用反射，支持 GraalVM native-image；提供 JSpecify 空安全注解与可插拔的 TypeRegistry 类型映射

适用场景（解读层）

  • 配合 Java 21+ 虚拟线程，在阻塞代码中对事务、批量插入、顺序查询等多语句场景减少数据库往返
  • 使用 Postgres 行级安全（RLS）的 SaaS 应用，将 SET、BEGIN 等设置语句与首个业务查询合并进同一次往返
  • 需要小型依赖、可 GraalVM 原生编译或不依赖 JVM 反射的 JVM/Kotlin 数据库访问项目
