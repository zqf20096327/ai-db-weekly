Room 扩展库，用于让 Room 读取 assets 中预置的 SQLite 数据库（已弃用）

综述（解读层）

RoomAsset 是 Android 上的辅助类，把 assets/databases 目录下的 SQLite 数据库文件复制到应用私有目录，使 Room 可直接使用已预填充数据的数据库，并支持指定自定义存储路径。用法与 Room 基本一致，仅改用 RoomAsset.databaseBuilder() 并将 @Database 版本号设为 2。README 标注该项目已弃用：Room 自 2.2.0 起原生支持预打包数据库。

  • 从 assets/databases 目录提取并复制 SQLite 数据库文件到应用私有数据目录，供 Room 使用
  • 提供备用构造函数可指定存储路径（如外部存储），需自行保证路径可用且可写
  • 用法接近 Room：替换 databaseBuilder() 调用并将 @Database version 设为 2；文件缺失时抛出 SQLiteAssetHelperException

适用场景（解读层）

  • 需要在 Android 应用中随安装包附带预填充数据的 SQLite 数据库并用 Room 访问
  • 需将数据库文件存放在自定义路径（如外部存储）的场景
  • 维护仍使用旧版 Room（<2.2.0）且需加载预置数据库的存量项目
