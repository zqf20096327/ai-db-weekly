面向 serverless 与边缘环境的嵌入式数据库，数据以 Parquet 存于 S3

综述（解读层）

Tonbo 是一个用 Rust 编写的嵌入式存储引擎，将数据以标准 Parquet 文件写入 S3 等对象存储或本地文件系统，通过 manifest 结合 CAS 实现协调，计算侧保持无状态。存储与查询引擎全异步，基于 LSM merge-tree 结构，支持 MVCC 快照隔离与 Arrow RecordBatch 零拷贝读取。适用于构建 serverless/边缘应用的状态层、在 WASM 或 Cloudflare Workers 中持久化结构化数据，或作为自建数据基础设施的存储引擎。项目目前处于 alpha 阶段，API 可能变动。

  • 数据以标准 Parquet 文件存储于 S3/R2/MinIO 或本地文件系统，通过 manifest CAS 提交协调，无需常驻服务
  • 全异步存储与查询引擎，支持 Tokio、WASM、Deno、Cloudflare Workers 等运行时，提供 MVCC 事务、快照读取与时间旅行查询
  • Arrow 原生 schema（派生宏或动态定义），支持投影下推、零拷贝 RecordBatch 读取、流式处理及嵌套类型

适用场景（解读层）

  • 为 serverless 或边缘应用提供无需运行数据库服务的持久化状态层
  • 在 S3 中直接存储追加型或事件类数据并进行查询
  • 嵌入自有数据基础设施中，作为轻量级 MVCC + Parquet 存储引擎
