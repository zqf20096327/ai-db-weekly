基于 Tonbo 存储引擎的 SQLite 扩展，以 LSM 组织 Parquet 文件支持分析处理

综述（解读层）

TonboLite 是一个兼容 WASM 的 SQLite 扩展，通过创建虚拟表在 SQLite 中实现分析处理，底层存储由嵌入式键值数据库 Tonbo 驱动。可在 SQLite CLI、Python、Rust（需 rusqlite 补丁）和 WASM 中使用，支持本地/S3/混合存储后端。项目当前为 Alpha 状态，WASM 使用需 secure context 与跨域隔离。

  • 使用日志结构合并树（LSM）组织 Parquet 文件
  • 支持 OPFS、S3 作为远程存储或二者混合作为存储后端
  • 提供 SQLite CLI 扩展加载、Python、Rust 与 WASM 四种使用方式

适用场景（解读层）

  • 在 SQLite 中直接进行面向分析的表处理
  • 在浏览器（WASM/OPFS）环境中运行嵌入式分析存储
  • 将部分数据存放本地、其余存放 S3 的分层存储场景
