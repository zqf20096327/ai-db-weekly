基于 Python curses 的终端 SQLite 数据库查看与编辑工具

综述（解读层）

Loula's SQLite Viewer 是一个运行在终端中的 SQLite 数据库查看与编辑工具，面向需要在命令行环境操作 SQLite 文件的用户。它提供 TUI 界面（依赖 curses，Windows 需安装 windows-curses，不可用时回退到 CLI 模式），支持保存多个数据库连接配置到 JSON 文件并自动重连上次使用的数据库。数据操作统一经由 DatabaseManager 类完成。

  • 提供基于 curses 的 TUI 界面，支持方向键导航、分屏表浏览器和分页显示
  • 支持执行自定义 SQL 语句及插入、更新、删除记录和管理表结构
  • 可将多个数据库连接以自定义颜色保存至 JSON 配置文件，启动时自动重连上次的数据库

适用场景（解读层）

  • 在没有图形界面的终端环境中查看和编辑 SQLite 数据库
  • 通过内置 CLI 模式进行脚本化和无头（headless）环境操作
  • 需要保存并快速切换多个 SQLite 数据库连接的管理场景
