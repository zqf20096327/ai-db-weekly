Go 轻量级 ORM，基于 database/sql 接口映射结构体与数据库表

综述（解读层）

Beedb 是一个 Go 语言 ORM，通过结构体标签将 Go struct 映射到数据库表，查询时将 where 子句直接委托给底层数据库执行。它基于 database/sql 接口，支持 MySQL/SQLite/PostgreSQL/DB2/ODBC/Oracle 等驱动，提供 struct 与 map 两种方式的增删改查、Join、Group By 等操作， BSD 协议开源。注意：该项目已停止维护，作者建议转向 Beego.orm，且未实现关系型关联支持，未标记 [*] 的驱动未经测试。

  • 基于 database/sql 接口，通过 beedb:"PK"、sql、tname 等结构体标签完成表名、列名与主键映射
  • 提供 Where/Limit/Join/GroupBy/Having 链式查询，支持 struct 与 map 两种方式的增删改查及批量操作
  • 兼容 MySQL、SQLite、PostgreSQL、DB2、MS ADODB、ODBC、Oracle 等数据库驱动，可通过 beedb.OnDebug 开启调试日志

适用场景（解读层）

  • 需要轻量 ORM 将 Go 结构体映射到关系数据库表的项目
  • 需要直接书写 SQL where 子句、保留底层查询灵活性的场景
  • 基于 map 的动态字段插入、更新与联表查询操作
