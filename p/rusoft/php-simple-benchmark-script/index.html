🧭 简介解读层（AI·证据行可回查）

单文件 PHP 脚本，用于测量各版本 PHP 操作执行速度

综述（解读层）

这是一个测试 PHP 操作执行速度的脚本，兼容 PHP 4.3 至 8.6。需将多个文件放入同一目录后，可通过命令行或 Web 服务器运行，支持以 JSON 或机器可读格式输出结果。部分测试依赖可选扩展（如 gd、redis、mysql 等）；脚本会提示 xdebug、opcache 等扩展可能影响测试结果。

  • 支持 PHP 4.3 至 8.6 版本，可通过 CLI 参数或环境变量配置内存限制、时间限制、运行/跳过指定测试
  • 输出格式包含普通文本、JSON 和机器可读格式，支持 -J、-M、-T 等命令行选项
  • 可在 Web 服务器上通过 URL 参数运行，并可在 Linux 下配合 nice、ionice、taskset 调整进程优先级与 CPU 绑定

适用场景（解读层）

  • 在命令行或 Apache+PHP 环境中对指定 PHP 版本运行一组操作速度测试
  • 需要 JSON 或机器可读格式结果以供程序处理的测试流程
  • 在 Raspberry Pi 等 ARM/MIPS 开发板或老旧处理器上运行完整测试套件（需配合较长的时间限制参数）
