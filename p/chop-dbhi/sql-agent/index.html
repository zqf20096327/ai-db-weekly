执行远程数据库即席查询的 HTTP 服务

综述（解读层）

SQL Agent 是一个用 Go 编写的 HTTP 服务，通过 POST 请求提交驱动名、连接信息和参数化 SQL 语句，连接远程数据库执行查询并以 JSON/ldjson/CSV 格式返回结果，设计动机是用于数据监控流程中将结果与历史快照对比。仅支持 SELECT 语句，支持七种数据库。推荐以 Docker 方式运行，也可作为 Go 库在其他程序中使用（库本身不含驱动）。

  • 支持 PostgreSQL、MySQL/MariaDB、Oracle、SQL Server、SQLite、Snowflake、Presto 七种数据库的查询
  • 通过 ?ping 参数可单独验证连接，查询结果支持 JSON、ldjson、CSV 三种返回格式
  • 提供 sqlagent Go 包供其他程序引入，连接参数标准化并可改用 dsn 直连

适用场景（解读层）

  • 在数据监控系统中执行查询并与历史快照结果进行比对评估
  • 需要通过 HTTP 接口对多种数据库执行参数化 SELECT 查询的服务
  • 作为 Go 库嵌入其他程序以复用其查询执行与结果序列化逻辑
