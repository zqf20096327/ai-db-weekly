🧭 简介解读层（AI·证据行可回查）

通过 MySQL 存储执行结果并生成 HTML 历史报告的 Robot Framework 工具

综述（解读层）

robotframework-historic 解析 Robot Framework 的 output.xml，将执行结果存入本地或远程 MySQL 数据库，并基于 Flask 生成包含图表和统计信息的 HTML 报告。面向需要查看测试历史记录的 Robot Framework 用户。安装需先配置 MySQL，再通过 pip 安装并提供 rfhistoricsetup、rfhistoricparser 等 CLI 命令；报告生成可在 CI/CD 流水线中自动化。

  • 解析 output.xml 提取执行详情，存储到本地或远程 MySQL 数据库
  • 提供最近 5/10/30 天执行趋势、按名称搜索测试历史、执行结果对比等报告功能
  • 提供 rfhistoric、rfhistoricparser、rfhistoricsetup、rfhistoricupdate 等命令行工具，支持 CI/CD 流水线集成

适用场景（解读层）

  • 持久化保存 Robot Framework 历史执行结果并在浏览器中查看图表报告
  • 在 CI/CD 流水线中测试执行后自动推送结果并生成报告
  • 按测试名称查询历史执行记录，或对多次执行结果进行并排比较
