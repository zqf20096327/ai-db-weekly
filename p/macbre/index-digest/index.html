分析 MySQL/MariaDB 查询与模式的数据库 linter，输出可操作的索引改进报告

综述（解读层）

index-digest 是一个 Python 编写的数据库 linter，连接 MySQL 5.7–9.x、Percona Server 8.x 或 MariaDB 10.x–12.x，检查库表 schema 并给出冗余索引、缺失主键等改进建议；可选提供 SQL 日志以检测未使用的索引与低效查询，共含 24 项检查。支持 pip、Docker 和 GitHub Action 运行，结果以纯文本、YAML 或 syslog 输出，可通过 --checks/--skip-checks 选择检查项。

  • 提供 24 项检查，包括 redundant_indices、missing_primary_index、not_used_indices、queries_using_filesort 等类别
  • 支持 --sql-log 读取查询日志文件、--analyze-data 分析表数据、--check-empty-databases 检查空库，检查项可通过命令行参数选择或跳过
  • 结果可输出为可读文本、YAML 或经 syslog 推送 JSON 消息供 ELK 聚合，可通过 pip 安装或以 Docker 镜像/GitHub Action 方式运行

适用场景（解读层）

  • 对 MySQL/MariaDB 数据库定期运行，生成表结构与索引的检查报告
  • 提供 SQL 查询日志（如预处理后的慢查询日志），定位未使用的索引与未走索引、使用 filesort 或临时表的查询
  • 接入 CI（GitHub Action）或 syslog/ELK 流程，对数据库检查结果做持续收集与处理
