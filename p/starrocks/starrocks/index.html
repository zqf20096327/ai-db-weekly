综述（解读层）

StarRocks 是 Linux 基金会下的分布式 MPP 分析型查询引擎，用 Java 和 C++ 编写，采用 Frontend 与 Backend 两模块架构，自 3.0 起支持存算分离架构。它支持 ANSI SQL 和 MySQL 协议，可直接查询 Hive、Iceberg、Delta Lake、Hudi 中的数据而无需导入，面向需要多维分析、实时分析与即席查询的团队。

  • 提供原生向量化 SQL 引擎，包含基于代价的查询优化器（CBO）与自动刷新的物化视图
  • 支持 ANSI SQL（覆盖 TPC-H 和 TPC-DS）并兼容 MySQL 协议，可直接查询 Hive/Iceberg/Delta Lake/Hudi 数据
  • 架构由 Frontend 与 Backend 组成，支持水平扩展、元数据与数据副本复制，并提供主键模型的实时 upsert/delete 与资源隔离能力

适用场景（解读层）

  • 对接多种 BI 工具与客户端的多维分析查询场景
  • 基于数据湖（Hive、Iceberg、Delta Lake、Hudi）的免导入即席查询
  • 需要主键级实时更新并并发查询的实时分析场景
