基于 Alpine 的 PgBouncer Docker 镜像，通过环境变量自动生成配置。

综述（解读层）

该镜像将 PgBouncer 连接池打包为约 15MB 的 Alpine 容器，启动时依据 DATABASE_URL 等环境变量自动生成 pgbouncer.ini 和 userlist.txt，并以标准 5432 端口对外提供服务。默认启用 MD5 认证，含 psql 等客户端工具，提供 Kubernetes 与 Docker Compose 示例。使用前提是后端 PostgreSQL 的 pg_hba.conf 允许其来源 IP 连接。

  • 镜像约 15MB，基于 Alpine Linux，通过环境变量配置，pgbouncer.ini 与 userlist.txt 在缺失时自动生成
  • 监听标准 Postgres 端口 5432，支持 DATABASE_URLS 以逗号分隔配置多个用户，pgbouncer.ini 中几乎所有设置可映射为环境变量
  • 包含 psql、pg_isready 等客户端工具，支持挂载自定义配置文件或通过 Dockerfile 扩展，定义 admin 用户后可连接 pgbouncer 管理库执行 SHOW STATS/POOLS 及 PAUSE/RESUME 等命令

适用场景（解读层）

  • 在应用与 PostgreSQL 之间部署连接池，由容器复用后端连接以减少每连接约 10MB 的内存及 TLS 建连开销
  • 在 Kubernetes 或 Docker Compose 中以环境变量方式快速启动 PgBouncer，无需手工编写配置文件
  • 需要临时断开后端数据库（重启维护）同时保持应用侧连接不中断的场景，通过管理台的 PAUSE/RESUME 实现
