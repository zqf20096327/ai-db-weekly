🧭 简介解读层（AI·证据行可回查）

将腾讯云 CloudBase 后端接入 AI 编程工具的集成层，通过 Plugin、Skills 与 MCP 实现后端操作

综述（解读层）

该项目为腾讯云 CloudBase 后端提供 AI 工具集成：npm 包 @cloudbase/cloudbase-mcp 提供 MCP Server，可在对话中登录环境、查询和修改数据库（PostgreSQL 与文档型数据库）、部署和调用云函数/Cloud Run、管理存储与静态托管并读取日志；Agent Skills 提供场景化编码约束。需自备 CloudBase 环境与 Node.js v18.15.0+，支持远程 HTTP、OAuth 或静态凭证三种连接方式，敏感操作需人工确认。

  • 通过 MCP 支持数据库 CRUD、云函数/Cloud Run 的编写、部署、调用与调试，以及日志查看和重新部署
  • 提供 Plugin、Skills、MCP 三种接入形态，覆盖 Cursor、Claude Code、Codex 等多款 AI IDE
  • 支持远程 HTTP 端点、OAuth 交互授权与静态凭证（适用于 CI/CD）三种连接模式

适用场景（解读层）

  • 在 AI IDE 中以对话方式创建和操作 CloudBase 环境（数据库、登录方式、对象存储）
  • 为 Web 应用或微信小程序生成代码后，直接在同一会话中部署与查看日志
  • 使用静态凭证模式在 CI/CD 流程中接入 CloudBase MCP
