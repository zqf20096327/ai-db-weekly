🧭 简介解读层（AI·证据行可回查）

自托管团队密码管理器，PHP/MySQL 实现，文件夹级权限与 AES-256-GCM 加密。

综述（解读层）

Teampass 是一个可自部署的开源凭据库（GPL-3.0），面向个人、中小企业及受监管行业的团队。密码以 AES-256-GCM 加密，私钥经 PBKDF2-SHA256（600,000 次迭代）派生，每个用户持有 RSA 封装的对象密钥副本以实现撤销。支持 LDAP/AD、OAuth2 SSO、TOTP/Duo/YubiKey 多因素、审计与合规报告，并提供 REST API 与浏览器扩展。需 PHP 8.2+ 与 MySQL 5.7+/MariaDB 10.7+，可 Docker 部署。

  • 文件夹级访问控制：角色与权限（读/写/禁改/禁删），支持按用户覆盖，个人文件夹对管理员不可读
  • 认证加密 AES-256-GCM，每用户 RSA 封装密钥分发，移除账号即撤销访问
  • LDAP/AD（嵌套组）、OAuth2/SSO、TOTP/Duo/YubiKey 多因素、IP 范围网络 ACL

适用场景（解读层）

  • 团队/中小企业替代聊天与表格共享密码，按文件夹和角色分配凭据访问
  • 受监管企业向审计方提供访问控制证据与合规报告
  • 个人或 Homelab 在 Raspberry Pi/VPS 上自托管，并可从 Bitwarden/LastPass/1Password/KeePassXC 导入
