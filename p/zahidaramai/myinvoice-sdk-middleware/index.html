面向马来西亚 MyInvois 电子发票系统的开源中间件 REST API 网关

综述（解读层）

该项目为 LHDN MyInvois 电子发票 API 提供中间层网关，处理令牌与会话管理、数字签名、文档提交、状态轮询、Retry-After 限流处理及 10 分钟幂等去重。面向 ERP、POS、Web 后台开发者，支持 9 种文档类型的 v1.0/v1.1 格式、多租户公司与 B2C 合并开票。为非官方社区项目，MIT 许可，默认端口 3000，基础路径 /api/v1。

  • 提供 4 种提交类型：合并 B2C、草稿（JustSave）、B2B（买家 TIN+BRN）、B2C（买家 NRIC），并通过 BullMQ 后台工作线程轮询提交状态
  • 基于 OpenAPI 规范生成 TypeScript、Python、Java、C# 四种 SDK，内置 10 分钟幂等去重窗口与 Retry-After 处理

适用场景（解读层）

  • ERP/POS/后台系统接入马来西亚 MyInvois 电子发票 API，无需自行处理签名、令牌与限流逻辑
  • 无买家 ID 的日常销售合并 B2C 开票场景（consolidated B2C invoicing）
  • 多公司/多供应商环境下的多租户发票管理，含 ERP 代开模式
