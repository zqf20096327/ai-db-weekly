Crystal 语言的数据库查询模块，提供连接管理、查询构建器与 ORM。

综述（解读层）

DBX 是一个基于 crystal-db 构建的 Crystal 语言模块，用于查询数据库，包含多连接管理器、查询构建器、查询执行器和 ORM（alpha 阶段）。采用解耦设计，可按需嵌入所需功能。开发环境依赖 Git、Docker 和 docker-compose，提供 prepare、check 等脚本辅助开发与测试。适用于需要在 Crystal 项目中操作数据库、管理多个数据库连接或构建 SQL 查询的场景。

  • 提供数据库连接管理器、查询构建器、查询执行器和 ORM（alpha）四类组件
  • 基于 crystal-db 通用驱动 API 构建
  • 采用解耦设计，可按需嵌入必要功能

适用场景（解读层）

  • 在 Crystal 项目中执行数据库查询
  • 需要管理多个数据库连接的应用
  • 通过查询构建器生成 SQL 而非手写查询语句
