🧭 简介解读层（AI·证据行可回查）

Kubernetes sidecar，提供带 Vault 凭据自动管理的 PgBouncer 代理

综述（解读层）

该项目以 sidecar 容器形式运行，内置 PgBouncer 提供 Postgres 连接代理，通过 Kubernetes service account 向 Vault 认证并自动获取、续期数据库凭据，主应用只需连接 localhost。凭据路径、Vault 地址等通过环境变量配置。限制包括仅支持单数据库、连接池固定为 transaction 模式、sidecar 不适用于 Job 等场景。

  • 应用无需改动即可接入 Vault 凭据管理，凭据自动续期
  • 内置 PgBouncer 连接池，主容器通过 localhost 连接
  • 使用 Kubernetes auth 方式向 Vault 认证，并支持通过 psql 定义 liveness probe

适用场景（解读层）

  • Kubernetes 中运行的应用需要使用 Vault 自动轮换的 Postgres 凭据
  • 需要数据库连接池但不想在应用内实现凭据刷新逻辑的场景
  • 配合通用 sidecar injector 注入该容器统一管理数据库连接
