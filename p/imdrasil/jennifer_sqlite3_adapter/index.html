Jennifer ORM 的 SQLite3 适配器，为 Crystal 语言提供数据库连接与迁移支持

综述（解读层）

该适配器为 Crystal 语言的 Jennifer ORM 提供 SQLite3 后端。使用时需在 shard.yml 中同时添加 crystal-sqlite3 驱动依赖，并要求 Jennifer 0.12.0 及以上版本。适配器启动时自动执行 PRAGMA foreign_keys = ON；由于 SQLite 不支持修改表结构，删列、改列、增删外键等迁移操作通过临时表复制数据实现，此类迁移需声明 with_transaction false。

  • 支持 bool、integer、float、text、date_time、json 等 SQLite3 数据类型的字段定义与映射
  • 提供 json_extract、json_array_length 等 JSON 查询函数（需 SQLite 3.38.0 及以上）
  • 实现基于临时表复制的表结构变更流程，保留数据与索引

适用场景（解读层）

  • 为基于 Jennifer ORM 的 Crystal 应用接入 SQLite3 数据库
  • 对含 JSON 字段的数据执行 json_extract 等查询
  • 对 SQLite 表执行删列、改列、增删外键等迁移操作
