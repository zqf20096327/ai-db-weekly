让 Metabase 连接 FirebirdSQL 数据库的驱动插件

综述（解读层）

该插件为 BI 平台 Metabase 提供 FirebirdSQL 数据库驱动，通过将 JAR 放入 plugins 目录加载，支持连接字符串与表单两种配置方式。标准版基于 Jaybird 6.x 支持 Firebird 2.5–5.0，另提供捆绑 Jaybird 2.2.15 的 legacy 版覆盖 Firebird 1.5–2.5，两者可共存。不同驱动版本对 Metabase 0.53+/0.57+ 有对应要求。

  • 提供标准与 legacy 两个驱动包，分别覆盖 Firebird 2.5–5.0 和 1.5–2.5，legacy 版注册为独立驱动名称且可与标准版共存
  • 支持原生 SQL 查询、MBQL 可视化查询、数据库模式同步、时间分组与字段过滤模板标签
  • 提供源码构建脚本（Java 21+、Clojure CLI）及包含 Metabase 与 Firebird 2.5/4.0 实例的 Docker 测试环境

适用场景（解读层）

  • 需要用 Metabase 的可视化图表和仪表盘查询 Firebird 数据库的场景
  • 仍运行 Firebird 1.5/2.x 旧版本数据库、需通过 legacy 驱动接入 BI 分析的场景
  • 需要从源码构建或本地开发调试 Metabase 驱动的场景
