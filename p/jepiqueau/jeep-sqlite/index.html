基于 sql.js 与 IndexedDB 的浏览器端 SQLite Web Component

综述（解读层）

jeep-sqlite 是一个 Stencil Web Component，通过 sql.js 在浏览器中执行 SQLite 查询，并将整个数据库以 localforage 形式持久化到 IndexedDB 的 jeepSQLiteStore 中，可存放多个数据库。其 API 与 @capacitor-community/sqlite 保持一致，用作该插件的 Web 实现，也可用于 Stencil、Ionic/Angular 等 PWA 应用，另提供 Vue、React、SolidJS 等框架的集成方式。需将 sql-wasm.wasm 复制到应用 assets 目录方可运行。

  • 数据库经 localforage 持久化于 IndexedDB 的 jeepSQLiteStore 存储，支持多数据库；在 close/closeConnection 时保存
  • 提供与 @capacitor-community/sqlite 相似的 API，含连接管理、execute/run/query、JSON 导入导出、增量升级、同步表（sql_deleted 列、deleteExportedRows）及事务方法
  • 支持从本地磁盘或远程 HTTP 读取数据库文件到存储、只读模式、WAL 并发访问（不支持 WAL2），并通过 File System Access API 将数据库保存回本地磁盘

适用场景（解读层）

  • PWA 应用中在浏览器端创建和查询 SQLite 数据库
  • 作为 @capacitor-community/sqlite 的 Web 实现进行集成测试
  • 开发 Stencil 或 Ionic/Angular、Vue、React、SolidJS 应用时的本地 SQLite 存储方案
