一个用于生成后端 API 项目脚手架的 CLI 工具与模板库

综述（解读层）

create-my-api 是一个 npm 发布的 CLI 工具，通过 npx 运行，交互式选择配置后生成 RESTful API 项目脚手架。它包含多种 Express/NestJS 模板（覆盖 JavaScript/TypeScript 与 MongoDB/PostgreSQL/Prisma 组合），并提供考勤、在线学习平台、2FA 认证、实时聊天等现成 API 可集成。面向需要快速初始化 Node.js 后端项目的开发者，需本机已安装 Node.js 和 Git。

  • 提供 npx create-my-api@latest 一条命令的交互式项目生成方式
  • 包含 5 种启动模板：Express 或 NestJS，搭配 JavaScript/TypeScript 与 MongoDB/PostgreSQL
  • 提供考勤门户、在线学习平台、2FA 认证、实时聊天 4 个现成 API 集成

适用场景（解读层）

  • 初始化指定框架、语言与数据库组合的后端 API 项目
  • 将现成的业务 API（如 2FA 认证、聊天）集成到已有项目
  • 参与开源贡献，向模板或 packages/APIs 目录添加新 API
