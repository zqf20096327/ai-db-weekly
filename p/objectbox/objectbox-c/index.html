面向 C/C++ 的嵌入式对象与向量数据库运行时库

综述（解读层）

ObjectBox 是一个嵌入到 C/C++ 应用中运行的设备端数据库，用于持久化对象（struct）与向量数据，支持跨设备与后端的数据同步（Sync 版）及时间序列扩展（TS 版）。API 以单头文件提供，通常配合 ObjectBox Generator 生成绑定代码；C API 同时作为 Go、Swift、Dart/Flutter、Python 等语言绑定的基础。支持 Linux、Windows、macOS 等平台，Apache 2.0 许可。

  • 提供 C 与 C++ 单头文件 API，通过 obx::Box 等类执行 put、insert、update、remove 等操作，支持异步 API
  • 包含向量数据管理与向量搜索、对象关系、属性二级索引、自动 schema 迁移等特性
  • 支持 Linux（含 ARMv6/7/8）、Windows、macOS，C API 可作为 Go、Swift、Dart/Flutter、Python 绑定的基础

适用场景（解读层）

  • 在 IoT 网关、微控制器、ECU 等设备端应用中进行对象与向量数据的本地持久化与查询
  • 构建离线优先、间歇联网场景下通过 ObjectBox Sync 与服务器同步数据的应用
  • 基于 C API 为其他编程语言实现 ObjectBox 绑定，或处理时间序列数据（TS 版）
