ObjectBox 官方 Gradle 插件，为 Java/Kotlin 项目自动配置 ObjectBox 数据库

综述（解读层）

该插件用于在 JVM 或 Android 的 Java/Kotlin 项目中接入 ObjectBox。它自动添加 ObjectBox Java API 及数据库依赖，通过注解处理器（Java 为注解处理，Kotlin 走 kapt 或 KSP）生成模型 JSON 文件与 MyObjectBox、下划线查询类等源码，并注册字节码转换器简化关系使用。要求 Gradle 8.3、JDK 11；Kotlin 项目默认使用 kapt，可改用 KSP。仓库包含插件、处理器、生成器和字节码转换器多个子项目，以 Maven 构件发布。

  • 自动添加 ObjectBox Java API、Kotlin 扩展函数及对应平台数据库库依赖
  • 通过注解处理器/kapt/KSP 生成模型 JSON 文件及 MyObjectBox、Example_ 等查询用源码
  • 为 Android 与 JVM 项目注册字节码转换器以简化关系（relations）使用

适用场景（解读层）

  • 在 Android 或 JVM 的 Java/Kotlin 项目中配置 ObjectBox 数据库构建流程
  • Kotlin 项目中配合 KSP 或 kapt 生成 ObjectBox 实体相关源码
  • 需要 @Entity 类字节码转换以简化关系操作的项目构建
