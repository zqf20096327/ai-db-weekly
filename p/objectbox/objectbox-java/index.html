综述（解读层）

ObjectBox Java 是面向 Java 与 Kotlin 应用的设备端 NoSQL 数据库，支持向量数据存储与向量搜索，用于 RAG AI 与相似度搜索场景。通过 @Entity 注解定义对象并放入 Box 管理，提供查询、对象关系与自动 schema 迁移。依赖要求：JVM 8+、Android API 21+、Gradle 7.0+ 或 Maven（仅 JVM 项目）。

  • 支持对象向量数据的设备端向量搜索，配合 RAG AI、生成式 AI 与相似度搜索场景
  • 通过 @Entity 注解将普通对象（POJO）持久化到 Box，内置对象关系，无需编写 SQL
  • 提供自动 schema 迁移、编译期类型检查，支持 ObjectBox Sync 与 TS 时间序列扩展

适用场景（解读层）

  • Android 或 JVM（Linux/macOS/Windows）应用的本地离线优先数据存储
  • 需要在设备端存储向量数据并进行相似度搜索的 AI 应用
  • 资源受限设备上的本地数据持久化与跨设备数据同步（Sync）
