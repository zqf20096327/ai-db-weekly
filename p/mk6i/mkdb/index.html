零第三方依赖的 Go 编写 SQL 关系型数据库，用于学习数据库开发

综述（解读层）

mkdb 是用 Golang（1.18+）编写的 SQL 关系型数据库管理系统，无任何第三方依赖。README 说明其目标是给想在低风险环境中实验数据库开发的开发者提供一个练习载体。它实现了递归下降 SQL 解析器、磁盘 B+ 树、WAL 与 NO FORCE/NO STEAL 页面缓存；限制包括单行最大 409 字节，且页面缓存脏页满时 INSERT 会导致进程终止。安装方式为克隆仓库后运行 go run ./cmd/console。

  • 实现遵循 SQL-92 语法的递归下降解析器，支持 SELECT/INSERT/UPDATE/DELETE、三种 JOIN、GROUP BY 聚合及 WHERE 条件
  • 使用磁盘 B+ 树存储，配合写前日志（WAL）和 NO FORCE/NO STEAL 语义的页面缓存
  • 无第三方依赖，运行只需 go run ./cmd/console，清理用 make clean

适用场景（解读层）

  • 开发者学习数据库内部机制（解析器、B+ 树、WAL）的实验环境
  • 教学或阅读 Database Internals 等资料后动手实践的配套项目
  • 轻量试用 SQL 操作的本地控制台场景
