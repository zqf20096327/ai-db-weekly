访问 AusTraits 澳大利亚植物性状数据库的 R 包

综述（解读层）

austraits 是 AusTraits 澳大利亚植物性状数据库的 R 接口，面向需要读取和使用该数据的 R 用户。它按版本号加载数据库发布版本，提供位置绘图等功能，并转发 traits.use 中的通用数据处理函数，适用于所有 traits.build 关系型数据库。该包尚未上架 CRAN，需从 GitHub 安装；5.0 之前的旧版 AusTraits 数据需安装旧版本包支持。

  • 通过 load_austraits()、get_versions()、get_version_latest() 按版本号加载 AusTraits 发布数据
  • 提供 plot_locations() 将性状数据映射到澳大利亚地图
  • re-export traits.use 的通用函数，支持表连接、记录筛选、数据库合并与可视化，适用于任何 traits.build 关系型数据库

适用场景（解读层）

  • 在 R 中按版本读取和分析 AusTraits 植物性状数据
  • 处理其他基于 traits.build 编译的性状数据库
  • 对性状记录的采集位置进行可视化绘图
