原生 macOS 数据库客户端，支持 AI 辅助查询与数据浏览

综述（解读层）

Pluk 是一个基于 AppKit 和 SwiftUI 的原生 macOS 数据库客户端，支持连接 PostgreSQL、MySQL、MariaDB、MongoDB、SQLite 和 Convex。提供可编辑数据表格、SQL 查询编辑器、笔记本仪表盘，以及基于当前表数据的上下文助手，生成的写入操作需经用户确认后执行。要求 macOS 15 及以上，采用 AGPL v3.0 许可证。

  • 支持 PostgreSQL、MySQL/MariaDB、MongoDB、SQLite、Convex 六种数据库连接，含 SSH 隧道、SSL 证书与 Docker 容器发现
  • 提供 SQL 自动补全、多结果集、查询历史与模式感知执行的查询工作区
  • 上下文感知助手可读取当前打开的表或笔记本内容，生成的写入操作在运行前需用户审核

适用场景（解读层）

  • 在单一 macOS 应用中浏览、筛选、编辑多种数据库中的数据
  • 通过笔记本将查询、文本与图表组合为数据仪表盘
  • 对 MongoDB 集合进行文档过滤与聚合查询
