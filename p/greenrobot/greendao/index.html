Android 平台的轻量 ORM 库，将对象映射到 SQLite 数据库

综述（解读层）

greenDAO 是面向 Android 的 ORM 库，用于将 Java 对象映射到 SQLite 数据库，适合需要在本地持久化对象数据的 Android 开发者。它通过 Gradle 插件在构建时生成 DaoMaster、DaoSession 及 DAO 类，提供基于属性常量的 QueryBuilder、跨实体 join，并支持 SQLCipher 加密。README 声明该项目已不再积极维护，并建议使用者关注同团队的 ObjectBox。

  • 通过 Gradle 插件在构建过程中生成 DaoMaster、DaoSession 和 DAO 类
  • QueryBuilder 使用属性常量构建查询，支持跨实体 join 及链式 join
  • 库体积小于 150K，为纯 Java jar（不含依赖 CPU 的本地部分），支持 SQLCipher 加密数据库

适用场景（解读层）

  • Android 应用中将对象持久化到 SQLite 数据库
  • 需要通过 SQLCipher 对本地数据库进行加密的场景
  • 在 R8/ProGuard 构建中使用 ORM 的 Android 项目（README 提供对应 keep 规则）
