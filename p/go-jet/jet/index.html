Go 语言的类型安全 SQL 构建器，结合代码生成与查询结果自动映射

综述（解读层）

Jet 是一个 Go 语言的类型安全 SQL 构建器，通过连接数据库读取 schema 元数据，自动生成 SQL Builder 和数据模型类型，并提供查询结果到任意 Go 结构的自动映射。支持 PostgreSQL、MySQL、SQLite（兼容 CockroachDB、MariaDB 协议），需要 Go 1.24+。README 明确说明它不是 ORM。

  • 支持 SELECT、INSERT、UPDATE、DELETE、WITH、LOCK 等语句的类型安全构建，列具有类型约束，字符串列只能与字符串表达式比较，整数列只能与整数表达式比较
  • 通过 jet 命令行工具连接数据库读取表、视图、枚举的元数据，生成 SQL Builder 与 Data Model 代码，生成行为可定制
  • 提供 stmt.Sql() 输出参数化查询与参数，stmt.Query(db, &dest) 将结果映射到可嵌套组合的目标结构，另提供 DebugSql() 供调试

适用场景（解读层）

  • 在 Go 项目中以代码补全和类型检查方式编写复杂 SQL 查询
  • 将多表关联查询结果自动映射到嵌套的对象组合结构
  • 基于 PostgreSQL、MySQL、SQLite 及其协议兼容数据库（如 CockroachDB、MariaDB）的应用开发
