TypeScript 编写的 AI 智能体记忆原语库，基于 Postgres + pgvector 实现提取-嵌入-存储-检索流程。

综述（解读层）

langmem-ts 是一个 MIT 许可的 TypeScript 记忆库，通过 Extractor、Embedder、Store、Retriever 四个接口实现事实提取、向量化、存储与相似度检索，默认提供 OpenAI 与 Postgres/pgvector 实现。面向需要在自有 TypeScript 智能体中添加记忆功能的开发者，要求 Node.js 18+、启用 pgvector 的 Postgres 及 OpenAI API key，所有配置在构造时注入。项目处于 0.1.0 早期阶段，命名空间、去重、冲突解决、情景记忆等功能尚未实现。

  • 提供 Embedder、Store、Retriever、Extractor 四个接口，每个均有默认实现，可在不改动库内部的情况下替换任一组件
  • 实现 extract → embed → store → retrieve 流水线，默认以 Postgres + pgvector 为参考后端，PgVectorStore.init() 在启动时校验向量维度
  • 不读取 process.env，全部配置通过构造函数注入，不与 LangGraph 等框架耦合

适用场景（解读层）

  • 为自研 TypeScript 智能体或普通脚本添加基于向量相似度的长期记忆检索
  • 已运行带 pgvector 扩展的 Postgres、希望复用现有数据库作为记忆存储的项目
  • 需要自定义嵌入模型或存储后端、通过实现接口替换默认组件的开发场景
