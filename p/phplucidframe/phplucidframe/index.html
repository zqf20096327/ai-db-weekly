面向 PHP/MySQL/Apache 的函数式架构 Web 应用开发框架

综述（解读层）

PHPLucidFrame 是一个 PHP 应用开发框架，为 PHP 开发者提供应用结构和辅助工具。它采用函数式架构，针对 PHP、MySQL 和 Apache 设计，几乎零配置，不使用模板引擎。路由在 /inc/route.config.php 中定义，可通过归档解压或 Composer 安装，测试支持命令行和浏览器两种运行方式。

  • 提供数据库访问 API、查询构建器、URL 路由、验证助手及用户认证授权 API
  • 包含 Schema Manager、数据库填充（Database Seeding）与 Shell 控制台工具（php lucidframe）
  • 无需 JSON/XML/YAML/vHost 复杂配置，仅需设置数据库参数，并提供 PDF/API 文档与代码示例

适用场景（解读层）

  • 搭建基于 PHP + MySQL + Apache（mod_rewrite）的 Web 应用
  • 需要数据库模式管理与测试数据填充的项目开发流程
  • 使用命令行或浏览器运行自动化测试的开发环境
