为 Rails/ActiveRecord 添加 Postgres 查询功能的 Ruby Gem

综述（解读层）

ActiveRecordExtended 是一个 Ruby Gem，通过在 ActiveRecord 查询接口上新增方法，提供 Array、JSONB、HSTORE、inet 等列类型的谓词查询，以及 any_of/none_of 条件方法、either_join/either_order 和 CTE（.with）支持。适用于使用 Postgres 后端的 Rails 应用；要求 Ruby 3.1+、Rails 6.1+、Postgres 12+（部分 CTE 修饰符仅限 PG12+）。安装方式为在 Gemfile 中添加 gem 'active_record_extended' 后执行 bundle。

  • 提供 Array、JSONB、HSTORE 列类型的 contains/overlap/any/all 等谓词查询方法，映射到 Postgres 的 @>、&&、ANY、ALL 表达式
  • 提供 inet_contains、inet_contained_within 等 IP/网络地址查询方法，对应 Postgres 网络运算符
  • 实现 .with 方法生成 CTE（WITH 语句），支持 recursive、materialized、not_materialized 修饰符，并提供 any_of/none_of、either_join、either_order 条件与查询方法

适用场景（解读层）

  • Rails 应用中需要按 Array、JSONB、HSTORE 列内容查询记录的场景
  • 基于 inet 列做 IP 地址与子网范围匹配的查询
  • 需要在 ActiveRecord 中编写 CTE、递归查询或多表条件 join/order 的场景
