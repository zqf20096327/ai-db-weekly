基于 Soybean Admin 与 Nest.js + Prisma 的全栈后台管理系统

综述（解读层）

Vue3 Admin 是一个前后端一体的后台管理系统，前端基于 Soybean Admin 二次开发（Vue 3.5、Ant Design Vue、Pinia、UnoCSS），后端采用 Nest.js 与 Prisma 连接 PostgreSQL。内置用户、角色、菜单、国际化、操作日志等模块，路由菜单由角色权限动态生成。README 注明项目主要用于学习交流，部分功能未经严格测试，仅限学习与非商业用途。

  • 前端基于 Soybean Admin 二次开发，后端采用 Nest.js + Prisma + PostgreSQL
  • 支持基于角色的动态路由菜单、CRUD 操作日志记录及基于 SSE 的消息公告推送
  • 提供在线预览地址、测试账号和 Swagger API 文档，使用 pnpm 管理依赖

适用场景（解读层）

  • 学习 Vue3 + Nest.js 全栈开发流程的参考项目
  • 需要用户、角色、菜单权限等基础后台功能模板的场景
  • 个人非商业用途的后台管理系统二次开发起点
