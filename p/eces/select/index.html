基于 YAML 声明式配置构建后台管理页面的工具

综述（解读层）

Select Admin 是一个用于搭建和运行后台管理页面的工具，用户通过编写 YAML 文件声明页面结构、数据块和查询，连接 MySQL、PostgreSQL、MSSQL、MongoDB、Redis、Google Spreadsheet 等数据源生成管理界面。可通过 npm 全局安装 CLI 本地运行，或使用官方 Docker 镜像部署；README 提示可本地安装的开源版本更新仍在准备中。适合需要快速搭建内部数据查询与内容管理页面的团队。

  • 提供对 MySQL、PostgreSQL、MSSQL、MongoDB、RESTful HTTP API、Redis、Google Spreadsheet 等后端数据源的支持
  • 支持基于角色的权限与访问控制、用户管理，以及可自定义的菜单、分组和标签页
  • 提供表格 UI、本地排序、本地与服务端分页，以及 Query、Modal、Markdown 等块类型和页面级参数

适用场景（解读层）

  • 为内部团队搭建客户查询、指标统计、内容管理等后台页面
  • 通过 YAML 声明式配置快速生成连接数据库或 HTTP API 的管理界面
  • 使用 Docker 镜像部署可分享 URL 的多页面管理后台
