纯 Java 从零实现的内存键值数据库，带 TTL、LRU 与 WAL 持久化

综述（解读层）

Prithvi 是一个不依赖外部框架、用纯 Java 编写的内存键值数据库，默认监听 1902 端口，通过自定义 TCP 协议提供服务。支持字符串、集合与列表操作、TTL 过期、10000 容量的 LRU 驱逐、JSON 快照与 WAL 追加日志恢复，并在 9100 端口暴露 Prometheus 格式指标。当前为 alpha 版本，README 明确声明面向教学与实验用途，不建议用于生产。

  • 支持 SET/GET/DEL 及集合（SADD/SMEMBERS）与列表（LPUSH/RPUSH）等命令，键可设置 TTL 过期时间
  • 提供 JSON 快照持久化（data/store.json）、周期性自动保存/加载，以及先写日志后应用内存的 WAL 崩溃恢复机制
  • 通过 LR LinkedHashMap 维护 10000 键上限的 LRU 缓存，每个客户端连接由独立线程处理

适用场景（解读层）

  • 学习网络编程、并发与数据结构实现的教学实验环境
  • 需要 TTL、LRU 驱逐和本地持久化的小型键值存储原型测试
  • 结合 Prometheus 抓取 9100 端口指标进行监控实验
