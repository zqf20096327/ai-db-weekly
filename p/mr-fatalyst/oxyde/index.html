基于 Pydantic v2、Rust 核心的异步 Python ORM

综述（解读层）

Oxyde 是一个面向 Python 的异步 ORM，模型基于 Pydantic v2，SQL 生成与执行由 Rust 实现，API 采用 Django 风格的 Model.objects 语法。支持 PostgreSQL、SQLite、MySQL 三种数据库，内置 transaction.atomic() 事务与 makemigrations/migrate 迁移 CLI，通过 pip 安装，附 FastAPI 集成示例和配套的 oxyde-admin 管理面板。README 提示项目处于早期开发阶段，API 可能随小版本变化。

  • 模型继承 Pydantic v2，提供校验、类型提示与序列化
  • 提供 transaction.atomic() 上下文管理器（含 savepoint）与 Django 风格迁移 CLI
  • 支持 PostgreSQL 12+、SQLite 3.35+、MySQL 8.0+，含 RETURNING、UPSERT 等特性

适用场景（解读层）

  • 在 asyncio/FastAPI 应用中访问 PostgreSQL、MySQL 或 SQLite
  • 需要迁移 CLI 与事务（含 savepoint）的异步数据层开发
  • 需要生成管理后台（CRUD、搜索、过滤、导出）的项目，可配合 oxyde-admin 使用
