🧭 简介解读层（AI·证据行可回查）

浏览、导出并恢复 Antigravity IDE 本地会话历史的桌面与命令行工具

综述（解读层）

该工具用 Python 编写，提供 CustomTkinter 桌面界面和 CLI 两种运行方式，用于读取 Google Antigravity IDE 存储在本地 SQLite、protobuf 和 JSONL 文件中的会话数据，支持导出为 db/pb/Markdown/JSON/HTML 格式，并可通过本地 Connect 协议接口将备份会话重新注入运行中的 IDE。适合需要查看、迁移或找回 Antigravity 会话记录的用户。要求 Python 3.10+，采用 MIT 许可证。

  • 读取 ~/.gemini/antigravity-ide/ 下的 SQLite、protobuf 与 JSONL 会话数据，跨工作区浏览含模型标签、时间戳、推理轨迹、终端输出和文件差异的完整消息线程
  • 支持将任意会话导出为 .db、.pb、Markdown、JSON 或 HTML，并可导入 .db/.pb 文件经 LanguageServer 重新激活到运行中的 IDE
  • 扫描本地存储以发现崩溃后遗留的未索引会话并重新激活；GUI 对 100+ 步长会话采用分块渲染

适用场景（解读层）

  • 浏览和检索 Antigravity IDE 中跨工作区的历史会话内容
  • 在更换机器或备份后导入 .db/.pb 会话文件并重新载入运行中的 IDE
  • 在 IDE 意外关闭后扫描本地存储，找回并重新激活未被索引的会话

Antigravity stores all session data locally in SQLite databases, protobuf files, and JSONL transcripts, but gives you no built-in way to browse or manage that history outside the active editor window.
