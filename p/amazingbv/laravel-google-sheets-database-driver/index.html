🧭 简介解读层（AI·证据行可回查）

将 Google Sheets 电子表格作为 Laravel 数据库后端的驱动包

综述（解读层）

该包为 Laravel 提供自定义 `google-sheets` 数据库连接，将一个电子表格映射为数据库、标签页映射为表、首行作为列名，支持 DB、Eloquent、Schema 与迁移。需 PHP 8.2+、Laravel 12/13 及配置服务账号 JSON 密钥。仅支持 SQL 子集，不提供事务、唯一约束与外键，适合轻量数据场景。

  • 支持 DB 查询构建器、Eloquent、Schema 及迁移，映射关系为：电子表格=数据库、标签页=表、首行=列名
  • 通过限流、指数退避重试和进程内缓存处理 Google Sheets API 配额
  • 迁移时忽略索引与关系约束而非报错，并在标签页被手动删除后自动修复元数据

适用场景（解读层）

  • 轻量后台数据、原型和运营工具等电子表格比传统数据库更贴合工作流的场景
  • 非技术用户需要直接查看和编辑数据的小型数据集场景
  • 不需要事务保证、数据库级约束和高写入吞吐的集成场景
