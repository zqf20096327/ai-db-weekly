Convex 平台的 TypeScript/JavaScript 客户端 SDK 与 CLI 包

综述（解读层）

该仓库为 Convex 后端应用平台提供 TypeScript SDK、客户端库和 CLI。包含多个入口：convex/server 用于定义后端函数与数据库 schema，convex/react 提供 React 集成 hooks，另有浏览器客户端、值处理工具及 Auth0/Clerk 认证组件。使用者需访问 docs.convex.dev 获取入门文档。

  • 提供 convex/server SDK 用于定义后端函数和数据库 schema
  • 提供 convex/react hooks 与 ConvexReactClient 用于 React 应用集成
  • 包含 convex CLI 命令行工具用于管理 Convex 项目

适用场景（解读层）

  • 在 React 应用中集成 Convex 后端
  • 为 Next.js 等框架实现 SSR 服务端辅助
  • 通过 Auth0 或 Clerk 进行用户认证
