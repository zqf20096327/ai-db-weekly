以 MySQL/MariaDB 为接口的 Pinba 统计服务器重实现

综述（解读层）

Pinba2 是对原 pinba_engine 的内部实现重写，作为统计服务器通过 MySQL/MariaDB 表接口提供数据。它通过 UDP 接收应用发来的请求指标，按时间窗口聚合并以只读 SQL 报表表呈现，支持 packet/request/timer 三种报表和直方图百分位。适用于需查看慢脚本或 SQL 查询统计的运维与开发团队，可通过 Docker 构建。

  • 通过 UDP 接收请求、标签与计时器数据，聚合并以只读 SQL 报表表形式提供统计
  • 支持 packet/request/timer 三种报表，聚合键可组合请求字段、请求标签与计时器标签（当前最多 15 键）
  • 报表可通过 SQL 表注释配置聚合窗口、直方图与百分位、过滤条件

适用场景（解读层）

  • 统计最慢的脚本或 SQL 查询等应用运行指标
  • 替代原版 Pinba 部署，附带 scripts 目录的迁移脚本
  • 为 PHP、Nginx 及其他语言的现有 Pinba 客户端提供后端接收服务
