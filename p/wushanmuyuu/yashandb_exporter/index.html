基于 Go 的 YashanDB Prometheus 监控指标导出器

综述（解读层）

该项目是一个面向 YashanDB 数据库的 Prometheus exporter，用 Go 编写，通过 YashanDB C 驱动（libyascli.so）查询系统视图并暴露 yashandb_* 前缀指标。内置覆盖实例状态、会话、SQL、存储、锁等 8 大类 15 个指标组的默认配置，指标可通过 TOML/YAML 自定义，支持单实例与多实例监控模式，并提供端口 9166 上的内置 Web UI。适用于需要在 Prometheus 体系中接入 YashanDB 监控的运维场景；使用前需安装 YashanDB C 驱动并配置具有系统视图查询权限的监控用户。

  • 内置默认指标配置文件 default-metrics.toml，包含 8 大类 15 个指标组，覆盖实例状态、会话进程、SQL 性能、系统资源、表空间、数据文件、锁与等待事件
  • 支持 SQL 语句归一化生成 SQL 指纹，提供慢 SQL（执行时间大于 1 秒）与高频 SQL（执行次数大于 100）监控指标
  • 支持多目标监控模式（ENABLE_MULTI_TARGET 与 targets.json）及通过 --custom.metrics 加载 TOML/YAML 自定义指标

适用场景（解读层）

  • 将 YashanDB 数据库指标接入 Prometheus/Grafana 监控体系
  • 集中监控多个 YashanDB 实例（多目标模式按 target 参数查询各实例指标）
  • 通过慢 SQL 与高频 SQL 指纹指标分析慢查询模式，或在 Web UI 中在线编辑指标配置
