Kotlin Multiplatform 平台的 ORM 库，按字段名约定映射实体并支持多数据库直连

综述（解读层）

Stormify 是 Apache 2.0 协议的开源 Kotlin Multiplatform ORM，覆盖 JVM、Android、iOS 及 Linux/Windows/macOS 原生平台。它基于字段名与数据库列名匹配的约定进行映射，无需大量注解或 XML 配置，支持 CRUD、事务、协程 API、懒加载和存储过程。原生平台可直接连接 PostgreSQL、MariaDB/MySQL、Oracle、MSSQL 和 SQLite（iOS 仅支持 SQLite），Android 要求 API 26 以上。

  • 跨 JVM、Android、iOS 与原生 Linux/Windows/macOS 平台提供统一 API，原生平台可不经 JDBC 直接连接 PostgreSQL、MariaDB/MySQL、Oracle、MSSQL、SQLite
  • 支持 CRUD 及批量操作、嵌套事务（savepoint 回滚/提交）、基于挂起函数的协程事务 API 与内置连接池、枚举映射、by db() 委托懒加载、复合主键、存储过程调用
  • 附带 schema-sync CLI 工具，可对比数据库与 Kotlin 实体并生成 SQL 迁移和 git apply 补丁，提供 TUI 交互模式与适用于 CI 的 headless 模式

适用场景（解读层）

  • 需要在 Kotlin Multiplatform 项目中共享同一套数据库访问代码、目标平台包含 Android/iOS 或原生桌面端的团队
  • 希望以普通 Kotlin 类配合字段名约定进行实体映射、减少注解和 XML 配置的项目
  • 需要对数据库 schema 与实体定义做差异检测并在 CI 流程中生成迁移 SQL 或补丁的工作流
