面向.NET的数据中间件，以XML建模驱动实体生成、多级缓存与自动分表分库

综述（解读层）

NewLife.XCode 是一个.NET 数据中间件，通过 XML 模型（db.xml）经 xcodetool 生成实体类，提供 CRUD、LINQ/流式查询、多级缓存、反向工程自动迁移及按时间/主键等策略的分表。支持 MySQL、SQLite、SqlServer、Oracle、PostgreSQL 及达梦等多类数据库，兼容 Dapper 用法。适合需要在.NET 项目中进行实体建模与数据访问的开发者。安装方式为 dotnet add package NewLife.XCode。

  • 通过 XML 模型生成实体类，包含每次覆盖的数据类与保留自定义逻辑的业务类
  • 提供全表缓存、单对象缓存、行数缓存等多级缓存，支持 Redis 跨进程缓存失效协调
  • 支持按时间、主键哈希等策略分表，业务代码无需感知实际表名

适用场景（解读层）

  • 需要在.NET 中以实体类为中心进行 CRUD 与强类型查询的业务系统
  • 读多写少、依赖缓存策略提升查询吞吐的场景
  • 单表数据量大、需要按时间或主键分表并透明路由的应用
