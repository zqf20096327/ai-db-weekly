.NET 数据中间件，以 XML 建模生成实体并自动迁移表结构

综述（解读层）

NewLife.XCode 是一个 .NET 数据访问中间件，通过 db.xml 定义模型，用 xcodetool 生成数据类与业务类（后者首次生成后不再覆盖），并在启动时反向同步表结构。支持 30 种内置数据库提供程序及 19 个协议兼容别名，面向需要在 .NET 应用中进行实体化 CRUD 与多数据库访问的开发者，兼容自 net45 起的旧版本。

  • 内置 30 个数据库提供程序，并通过 MySQL/PostgreSQL 协议别名复用支持 TiDB、openGauss、Redshift 等引擎
  • 提供 XML 建模、实体类生成与启动时的表结构反向同步，迁移策略可按实体配置
  • 包含实体缓存、单对象缓存与行数缓存等多级缓存，支持 Redis 注入实现跨进程缓存失效

适用场景（解读层）

  • 在 .NET / .NET Framework 项目中以实体方式操作关系型或多类型数据库
  • 需要从 XML 模型自动生成实体类并自动同步数据库表结构的开发流程
  • 读多写少的小表全表缓存查询，以及按主键的高频点查场景
