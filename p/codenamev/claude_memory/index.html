基于 hooks、MCP 工具与 SQLite 的 Claude Code 长期记忆系统

综述（解读层）

ClaudeMemory 为 Claude Code 提供跨会话的本地持久记忆。它通过 hooks 与 MCP 工具从对话中提取事实与观察记录，存入全局与项目两个 SQLite 数据库，并在下次会话开始时自动注入上下文。观察记录需经两次以上出现（corroboration）才提升为事实。以 Ruby Gem 分发，无需 API key。

  • 提供语义事实库与情景观察记录两层记忆，观察经佐证（≥2 次）后才提升为事实
  • 支持 FTS5 全文检索与本地向量搜索（sqlite-vec、fastembed-rb）并用 Reciprocal Rank Fusion 融合排序
  • 包含本地 Web 仪表盘、周报生成（digest）、OpenTelemetry 指标接收等可观测性命令

适用场景（解读层）

  • 在 Claude Code 多次会话间保留项目技术栈、约定与决策记录
  • 跨项目保存用户开发环境偏好，会话开始时自动注入
  • 需要记忆健康审计、成本与质量统计的 Claude Code 日常使用者
