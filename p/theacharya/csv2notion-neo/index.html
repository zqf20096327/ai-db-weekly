将 CSV/JSON 数据及图片上传合并到 Notion 数据库的命令行工具

综述（解读层）

CSV2Notion Neo 是一个命令行工具，用于将 CSV 或 JSON 文件（含图片）上传并合并到 Notion 数据库。它基于 Notion 官方 API（v2.0.0 起），需提供集成令牌（ntn_ 开头）和数据库/页面 URL，以第一列作为键合并现有行。支持 Linux x64、macOS ARM64、Windows x64，无额外依赖；安装方式包括预编译二进制、Homebrew、pip（需 Python 3.11+）及源码构建。注意 API 限制下逐行上传，可用 --max-threads 控制并发以避免被限流。

  • 支持 CSV/JSON 合并到现有数据库，以第一列作为键匹配现有行
  • 可上传文件至 Files & Media 列，并为每行设置图标、封面或内嵌图片
  • 基于 Notion 官方 API，通过 --token 和 --url 参数进行认证与定位，可手动指定列类型并校验输入数据

适用场景（解读层）

  • 需要将本地 CSV/JSON 数据定期同步或合并到已有 Notion 数据库
  • 需要批量上传图片文件到 Notion 数据库的 Files & Media 列并关联到对应行
  • 需要在空白页面 URL 上自动创建新 Notion 数据库并导入数据
