基于Python对象的内存数据库，提供类SQL查询API

综述（解读层）

littletable 是一个 Python 模块，为对象集合提供低开销、无模式的内存数据库访问。它接受 dict、dataclass、namedtuple、attrs、Pydantic 模型等对象类型，从对象的 __dict__/__slots__/_fields 推断列。支持插入/查询/删除、索引、CSV/TSV/JSON/Excel 导入导出、表连接与全文搜索。基础安装依赖 rich 包，Excel 与 DataFrame 功能需额外安装 openpyxl、pandas。

  • Table 无需预定义 schema，可存储 dict、namedtuple、dataclass、attrs、Pydantic 等对象类型
  • 提供索引（含唯一键约束）、使用 + 运算符的连接、多词文本属性的全文搜索
  • 支持 CSV/TSV/JSON/Excel .xlsx 导入导出，可直接读取 HTTP URL 与 .zip/.gz/.xz 压缩文件

适用场景（解读层）

  • 在 Python 程序内对对象集合进行检索、索引与连接操作
  • 导入 CSV/JSON 数据（含远程 URL 和压缩文件）进行查询分析
  • 在 Jupyter Notebook 或终端中以表格形式展示数据
