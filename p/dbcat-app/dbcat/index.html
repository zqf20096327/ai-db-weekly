🧭 简介解读层（AI·证据行可回查）

Rust 编写的 Mac/Windows 原生数据库客户端，支持多类数据库连接管理。

综述（解读层）

DbCat 是用 Rust 编写的 macOS 与 Windows 桌面数据库客户端，支持 MySQL、PostgreSQL、SQL Server、Redis、MongoDB、ClickHouse、DuckDB 等数据库，提供表浏览编辑、查询编辑器、ER 图、导入导出与备份功能，并内置 MCP 服务器供 AI 工具调用。该仓库仅托管发行包和 issue 跟踪，不包含源代码；支持 macOS 12+ 和 Windows 10/11 (x64)。

  • 支持 MySQL、PostgreSQL、SQL Server、SQLite、Redis、MongoDB、ClickHouse、DuckDB 等多种数据库的连接与操作
  • 表格分页加载（每页 300 行），变更先暂存、确认 SQL 后提交，支持只读连接
  • 密码存储于 macOS Keychain 或 Windows Credential Manager，支持 SSH 隧道与 SSL/TLS 验证

适用场景（解读层）

  • 在图形界面中浏览、筛选和编辑多种数据库的表数据
  • 通过 ER 图查看数据库表结构与外键关系
  • 将 MCP 服务器接入 Claude Code、Cursor 等 AI 工具以授权执行数据库操作
