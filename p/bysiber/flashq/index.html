零外部依赖的 Python 任务队列，默认以 SQLite 存储任务

综述（解读层）

FlashQ 是一个 Python 任务队列库，通过 pip install flashq 安装即可使用，默认采用 SQLite 后端，无需部署 Redis 或 RabbitMQ。它支持异步与同步任务、链式编排、中间件、速率限制和 Web 仪表盘；需要更大规模时可切换 PostgreSQL 或 Redis 后端。适用于需要在单机或小团队项目中运行后台任务的 Python 开发者。

  • 默认使用 SQLite 后端，任务持久化到本地数据库，无外部依赖；可切换 PostgreSQL 或 Redis 后端
  • 支持任务组合与调度：chain/group/chord 编排、间隔与 cron 定时任务、指数退避重试、死信队列
  • 内置 CLI 工具与 Web 仪表盘，可通过 flashq worker 启动多线程 worker，仪表盘支持按状态筛选、取消与清空队列

适用场景（解读层）

  • 不希望部署独立消息代理的 Python 项目中的后台任务（如发送邮件、调用外部 API）
  • 需要定时或周期任务调度，且希望复用现有 SQLite/PostgreSQL 数据库的场景
  • 需要可视化查看任务状态、重放失败任务的运维场景
