面向Java企业应用的多门面共享服务框架，聚合RPC与微服务实现

综述（解读层）

URSS 是一个 Java 开源框架，通过为数据、RPC、微服务、消息、缓存、日志、配置、分布式事务等提供统一门面接口，并在底层接入多种具体实现（如 Dubbo、gRPC、Spring Cloud、RocketMQ、Redis 等）。开发者只需编写业务代码，按需替换底层模块；可在存量 IT 资产基础上扩充分布式能力。

  • 为微服务、RPC、消息、缓存、配置、事务等提供统一门面 API，底层实现可替换，包含 Dubbo、gRPC、Spring Cloud、ServiceComb、Thrift、Netty 等多种实现模块
  • urss-data 模块支持 MySQL、Oracle、SQLServer、TiDB、MongoDB、Redis、HBase、Spark 等多种数据源访问及 MyCat、Sharding-JDBC 分库分表
  • urss-tool 提供 Windows/Linux 多集群一键更新工具、代码生成工具及可配置为系统服务的应用生成器

适用场景（解读层）

  • 在已有多种数据存储（RDBMS、NoSQL、大数据组件）并存的企业环境中统一数据访问接口
  • 需要在 Dubbo、Spring Cloud、gRPC 等不同 RPC/微服务实现之间切换或共存的 Java 系统
  • 需要统一消息队列（ActiveMQ、RocketMQ、RabbitMQ、Kafka、ESB）、分布式事务（TCC）与配置中心接入的企业服务架构
