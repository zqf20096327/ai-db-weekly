基于 MQTT 与 PostgreSQL 的 MeshCore 网络监控、数据采集与交互平台

综述（解读层）

MeshCore Hub 是一个 Python 3.13+ 平台，用于监控、采集并与 MeshCore 网格网络交互。数据由 meshcore-packet-capture 观察 RF 流量并发布到 MQTT，Collector 订阅后持久化到 PostgreSQL（v0.19 起仅支持），并提供 REST API 与 SPA 仪表盘。面向运行 MeshCore 社区网络的运维者，通过 Docker Compose profile 组合部署，支持 Redis 缓存、RSS/Atom 订阅与可选 bearer token 认证。

  • 包含 Collector、REST API、Web Dashboard 三个组件，数据经 MQTT 采集并持久化到 PostgreSQL
  • 支持原始包捕获与检索、多跳路由健康监测、节点打标，并提供 RSS 2.0/Atom Web Feeds
  • 通过 Docker Compose profiles 部署，提供 Swagger UI/ReDoc 文档与 Prometheus 格式指标端点

适用场景（解读层）

  • 部署单个节点即可构建 MeshCore 网格网络的监控与可视化仪表盘
  • 社区网络成员订阅公开消息、节点广播等网格活动 feeds
  • 运维人员监测多跳路由链路健康状态并查询历史报文数据
