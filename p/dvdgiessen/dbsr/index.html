PHP 编写的 MySQL 搜索替换工具，可解析 PHP 序列化字符串

综述（解读层）

DBSR 是一个用于对 MySQL 数据库执行搜索替换操作的 PHP 工具，提供 CLI 与网页 GUI 两个版本。它自行解析 PHP 序列化字符串（常见于 WordPress 数据库），因此能避免简单 REPLACE() 语句破坏序列化结构，并修复已被损坏的序列化数据。运行需 PHP 5.3+ 及 pdo、pdo_mysql 扩展，采用 GPLv3 许可。

  • 在 MySQL 数据库上执行搜索替换时解析 PHP 序列化字符串，并可修复损坏的序列化数据
  • 提供 CLI 和 GUI（4 步向导）两种使用方式，GUI 支持自动检测设置、防止常见错误及用后自删除
  • 支持通过 --file 读取 JSON 配置文件批量执行替换

适用场景（解读层）

  • WordPress 等使用 PHP 序列化数据的数据库中的文本替换（如更换站点域名）
  • 修复此前被其他搜索替换脚本损坏的序列化数据
  • 通过命令行或配置文件对数据库执行批量替换操作
