🧭 简介解读层（AI·证据行可回查）

数据库模式变更的版本跟踪与部署工具，基于变更日志文件驱动

综述（解读层）

Liquibase 用于跟踪、版本化和部署数据库模式变更，本仓库是其 Community 版主源码。它按版本控制数据库 schema 变更、自动排序部署脚本并支持回滚，可集成 Maven、Gradle、Spring Boot 及 CI/CD 工作流。Community 版内置支持多种数据库，其他数据库需下载扩展。采用 Functional Source License（FSL）许可，社区版每季度发布。

  • 跟踪、版本化并部署数据库 schema 变更，支持自动排序部署脚本与回滚
  • 可集成 Maven、Ant、Gradle、Spring Boot 及 GitHub Actions 等 CI/CD 工具
  • 内置多种数据库支持，非内置数据库可通过扩展接入

适用场景（解读层）

  • 多版本环境下数据库 schema 变更的版本控制与部署
  • 发布流程中数据库变更的自动排序与回滚
  • 配合 Maven/Gradle/Spring Boot 或 CI/CD 流水线执行数据库迁移
