基于 Notion API 管理 List 类型数据库的 Python 命令行工具

综述（解读层）

Notion CLI List Manager 是一个用 Python 编写的命令行工具，通过 Notion 内部 API 集成对 Notion List 类型数据库进行增删查操作。用户需先创建 API 集成并将数据库分享给它，用 list set 配置 token 与默认数据库 ID 后，即可用 list、list add、list rm 等命令管理条目。项目自述仍处于开发中。

  • 支持 list / list add / list rm / list db / list set 等命令，通过终端操作 Notion List 数据库
  • list rm 支持以范围与列表组合格式（如 3,4,6:10:2）批量删除条目
  • list db 可保存多个数据库、指定展示的属性及顺序，仅在管理器层面增删不作用于 Notion 本身

适用场景（解读层）

  • 在终端快速向 Notion List 数据库添加或删除待办条目
  • 将多个 Notion 数据库登记到管理器并自定义属性展示顺序
  • 配合作者提供的模板数据库记录想法或待办事项
