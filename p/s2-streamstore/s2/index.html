S2 持久流 API 的 CLI、Rust SDK 与可自托管服务端实现

综述（解读层）

该仓库提供 S2 持久流（Durable Streams）API 的三个组件：s2-cli 命令行工具、s2-sdk Rust SDK，以及 s2-lite 可自托管的服务端实现。s2-lite 基于 SlateDB 存储引擎，以对象存储作为持久化层，可指向 S3/Tigris 等桶或本地目录，也支持纯内存模式用于集成测试，面向需要实时流数据读写的开发者。其写前日志（WAL）可与主存储分桶部署；访问令牌经 /basins、/streams 等 REST 端点操作，但不支持 /access-tokens 与 /metrics API，为单节点二进制。

  • 提供 CLI、Rust SDK 与内嵌于 CLI 的 s2 lite 子命令，作为 S2 API 的自托管服务端实现
  • 存储引擎为 SlateDB，数据在对象存储确认前落盘，支持 S3 兼容桶、本地目录与内存三种存储模式
  • 提供 Prometheus 格式的 /metrics、/health 健康检查端点，支持 Helm 部署到 Kubernetes

适用场景（解读层）

  • 以 s2 lite 作为 S2 API 的本地或自托管运行环境，配合 CLI/多语言 SDK（TypeScript/Go/Rust/Python）进行流读写
  • 使用无 --bucket 的内存模式作为 S2 模拟器跑集成测试
  • 将流数据持久化到 S3 兼容对象存储，并可把 WAL 放入独立桶或本地盘以隔离延迟
