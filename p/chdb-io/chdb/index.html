嵌入式进程内 OLAP SQL 引擎，基于 ClickHouse 实现，无需安装独立服务器。

综述（解读层）

chDB 是由 ClickHouse 驱动的进程内 SQL OLAP 引擎，面向 Python 用户，通过 pip 安装后可在应用内直接执行 SQL，无需单独部署 ClickHouse。它支持 Parquet、CSV、JSON、Arrow、ORC 等 60+ 格式的文件查询、Pandas DataFrame 查询、有状态会话、流式查询与 Python UDF；目前仅支持 macOS 和 Linux（x86_64/ARM64）上的 Python 3.9+。

  • 进程内运行 ClickHouse SQL 引擎，无需安装 ClickHouse，支持 Python DB API 2.0
  • 输入输出支持 Parquet、CSV、JSON、Arrow、ORC 等 60+ 格式，可查询文件、Pandas DataFrame 和 Arrow 表
  • 提供有状态会话、分块流式查询、Python UDF 装饰器及通过 WebAssembly 在浏览器中运行 SQL 的版本

适用场景（解读层）

  • 在 Python 数据分析流程中对 Parquet/CSV 等本地文件执行 SQL 查询
  • 以进程内方式为数据处理脚本或 Notebook 提供 OLAP 查询能力
  • 通过 chDB-Wasm 在浏览器环境中运行 SQL 而无需安装服务端
