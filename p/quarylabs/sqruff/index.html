Rust 编写的 SQL 格式化与代码检查工具

综述（解读层）

sqruff 是用 Rust 实现的 SQL linter 和格式化工具，通过 CLI 对项目执行 lint 与自动格式化，支持 postgres、bigquery、snowflake 等多种方言。行为通过项目根目录的 .sqruff 文件配置。内置 LSP 服务器，可供各编辑器接入，仓库附带 VS Code 与 Zed 集成。可通过 Homebrew、pip、cargo 或二进制包安装。

  • 提供可配置的 SQL lint 与自动格式化能力，支持 postgres、bigquery、snowflake、clickhouse 等方言
  • 内置 LSP 服务器（sqruff lsp），可从任意编辑器接入，仓库维护 VS Code 与 Zed 两种集成
  • 支持 brew、pip、cargo 及二进制下载等多种安装方式，并提供浏览器 playground 试用

适用场景（解读层）

  • 在 CI 或本地工作流中批量检查 SQL 项目（sqruff lint .）
  • 为团队统一 SQL 格式规范，通过 .sqruff 文件配置方言与规则
  • 在 VS Code 或 Zed 编辑器中通过 LSP 集成实时检查 SQL 代码
