本地运行的 AI API 配额监控守护进程，用 Go 编写并存 SQLite

综述（解读层）

onWatch 是一个用 Go 编写的本地后台守护进程，用于轮询多家 AI API 提供商的配额与用量接口，将历史数据存入 SQLite，并在 localhost:9211 提供 Material Design 3 仪表盘。它面向同时使用多个 AI 编码工具的开发者，可配置任意提供商组合并行轮询，另提供 VS Code 扩展与 Docker 部署。项目处于 Beta 阶段，至少需要配置一个提供商密钥。

  • 以单个二进制作为后台守护进程运行，README 标注内存占用低于 50MB，数据存储于本地 SQLite，并声明零遥测
  • 支持配置 Synthetic、Z.ai、Anthropic、Codex、GitHub Copilot、MiniMax、Antigravity、Cursor 等多个提供商，可自动检测 Claude Code、Codex、Cursor 等工具的本地凭据
  • 安装方式包括一键脚本、Homebrew、Windows PowerShell、Release 二进制与 Docker 镜像，并提供 VS Code Marketplace 扩展与 macOS/Linux 托盘组件

适用场景（解读层）

  • 跨多个 AI 编码工具（如 Cline、Claude Code、Codex CLI、Cursor）集中查看各提供商配额的历史与当前周期用量
  • 在超过配额或预算前通过仪表盘与提醒查看用量趋势
  • 通过 API Integrations 接入自有 API 工作流的令牌与支出遥测数据
