基于 Rust 的 Windows 本地 PHP + MySQL/MariaDB 服务管理器，可移植、进程托管

综述（解读层）

Servisan 是一个用 Rust 编写的 Windows 本地服务器管理器，用于编排原生 PHP 与 MySQL/MariaDB 运行时。数据、日志、配置和项目均放在自含目录内，不写注册表；通过 Windows Job Objects（KILL_ON_JOB_CLOSE）在退出时清理子进程。支持一键下载切换 PHP 版本、目录联接挂载外部项目、从 Laragon/XAMPP/WAMP 迁移数据库，并提供系统托盘与 Web 面板。仅支持 Windows 10/11 64 位。

  • 使用 Windows Job Objects 管理子进程，stop 或 Ctrl+C 时关闭全部服务进程
  • 支持下载官方 PHP 版本（8.5 至 7.4）并切换活动运行时，可查看 CVE 安全公告
  • 通过目录联接链接外部项目目录，提供 *.test 域名与 localhost 子目录双访问方式

适用场景（解读层）

  • 在 Windows 上本地运行和调试 PHP / Laravel 项目
  • 在 USB 盘或任意目录携带完整的 PHP + MySQL 环境
  • 将 Laragon/XAMPP/WAMP 的数据库迁移到新的自含环境
