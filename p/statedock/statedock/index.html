🧭 简介解读层（AI·证据行可回查）

基于 MCP 的编码代理共享项目记忆服务，Cloudflare 自托管版。

综述（解读层）

StateDock 将项目目标、决策与交接记录集中存储，编码代理（Claude Code、Cursor、Codex）通过 MCP 读取上下文、认领任务并写回交接信息。本仓库为其 Cloudflare 自托管版，需自行运营 Workers、D1、KV、R2、域名、邮件投递与备份；服务端为 AGPL-3.0，插件代码为 MIT 许可。

  • 通过 MCP 向编码代理提供共享项目记忆，支持读取上下文与写回交接
  • 自托管版部署于用户自己的 Cloudflare 账户，涵盖 Workers、D1、KV、R2 等资源
  • 提供 Codex、DeepSeek Harness 等工具插件（独立 MIT 仓库），插件不执行任务代码、不调度代理

适用场景（解读层）

  • 团队中多个开发者与多个编码代理共享同一项目上下文
  • 在自有 Cloudflare 账户中部署并自行管理数据与备份
  • 通过 Skills 保存计划、恢复任务上下文、记录进度
