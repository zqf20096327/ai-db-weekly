以 Dockerfile 方式构建并运行 Oracle ORDS 独立模式的容器镜像项目

综述（解读层）

该项目提供 Oracle ORDS 的 Dockerfile，用于以 standalone 模式运行 ORDS。由于 Oracle 要求下载 ORDS 时接受其条款，镜像不发布在 Docker Hub，需用户自行下载 ORDS zip 后本地构建。支持首次运行生成配置（写入挂载的 /opt/ords 卷），之后可复用现有配置启动；内置健康检查，并提供 SQL Developer Web 访问路径。

  • 以 standalone 模式运行 Oracle ORDS，首次运行可在挂载卷 /opt/ords 中生成配置，之后复用现有配置启动
  • 内置健康检查，可通过 docker ps 查看 healthy 状态，日志可通过 docker logs 读取
  • 通过环境变量配置数据库连接（DB_HOSTNAME/DB_PORT/DB_SERVICENAME）、各用户密码、时区、REST SQL 与 SQL Developer Web 开关

适用场景（解读层）

  • 在 Docker 环境中为 Oracle 数据库部署 ORDS，供 APEX 或 SQL Developer Web 访问
  • 按 ORDS 版本号构建多个镜像标签，针对不同 ORDS 版本分别运行
  • 将 ORDS 配置持久化到本地目录卷，便于容器重建后复用配置
