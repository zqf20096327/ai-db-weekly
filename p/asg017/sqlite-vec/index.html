SQLite 向量搜索扩展，以 vec0 虚拟表存储与查询向量

综述（解读层）

sqlite-vec 是一个 SQLite 扩展，通过 vec0 虚拟表存储和查询 float、int8、二进制向量，并支持在元数据、辅助或分区键列中存放非向量数据。项目以纯 C 编写、无依赖，可作为扩展加载到 SQLite 运行的各平台，提供 Python、Node.js、Ruby、Go、Rust 等多种语言的安装包。README 注明其处于 v1 之前的预发布阶段，接口可能出现破坏性变更。

  • 通过 vec0 虚拟表存储和查询 float、int8 和二进制向量
  • 纯 C 编写、无依赖，可在 Linux/MacOS/Windows、WASM 浏览器等 SQLite 可运行的环境加载
  • 支持在元数据列、辅助列或分区键列中存储非向量数据

适用场景（解读层）

  • 在现有 SQLite 数据库中增加向量存储与查询能力
  • 需要跨平台（包括浏览器 WASM、树莓派等）运行向量检索的场景
  • 配合 sqlite-rembed、sqlite-lembed 等扩展生成文本嵌入并进行检索的 SQL 工作流
