用 Rust 编写 SQLite 可加载扩展的框架，封装 C API 入口

综述（解读层）

sqlite-loadable-rs 是一个 Rust 框架，用于编写 SQLite 运行时可加载扩展（.so/.dylib/.dll），支持在 SQLite CLI、Python、Node.js 等环境中加载。它通过 define_scalar_function、define_table_function、define_virtual_table 等 API 定义标量函数、表函数和虚拟表。项目处于 beta 阶段，README 注明大量使用 unsafe Rust，多线程环境未经测试，且无法与 rusqlite 代码复用，产物二进制体积大于 C 版本。

  • 提供 define_scalar_function、define_table_function、define_virtual_table 等 API，用于实现标量函数、表函数和虚拟表
  • 编译产物为动态链接库，可通过 .load 在 SQLite CLI 中加载，README 提到也可经 rusqlite 的 Connection.load_extension() 或 sqlite3_auto_extension() 使用
  • examples/ 目录包含可构建的扩展示例，基于该框架的项目包括 sqlite-xsv、sqlite-regex、sqlite-base64

适用场景（解读层）

  • 需要为 SQLite 添加自定义标量函数并在 CLI、Python、Node.js 等多种客户端中调用
  • 需要实现表函数或支持 CREATE VIRTUAL TABLE 语法的虚拟表（含读或写模式）
  • 已有 Go 或 C 编写扩展经验、希望改用 Rust 编写可加载扩展的开发者
