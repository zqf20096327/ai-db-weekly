基于 Kysely 类型注解生成 SQL 表结构与迁移的库

综述（解读层）

kysely-tables 让开发者用同一份 Kysely 表类型文件生成 CREATE TABLE 语句、快照与迁移（schema revision）。通过 Sized、Primary 等注解类型增强接口定义，运行 db.ts 文件时解析 CLI 标志完成建库、差分与迁移应用，迁移由 Postgrator 执行。项目自述为概念验证，自动差分生成功能尚无测试覆盖，作者欢迎 bug 报告。

  • 通过注解类型（Sized/Primary/Reference/Default/Unique 等）从 Kysely 兼容的接口定义生成 SQL schema 与迁移
  • 内嵌 runner：直接执行 schema 文件即成 CLI，支持 --create/--revision/--apply/--reset 等标志
  • 迁移执行基于 Postgrator，支持 PostgreSQL、SQLite、MySQL、MSSQL；解析基于 TypeScript 编译器 API

适用场景（解读层）

  • 希望 schema、迁移与查询共用同一份 Kysely 类型定义的 TypeScript 项目
  • 使用 Kysely 且需要轻量迁移工作流的 SQLite/PostgreSQL 等项目
  • 需要编写手写 SQL 迁移时，可用 --revision --empty 生成空迁移桩
