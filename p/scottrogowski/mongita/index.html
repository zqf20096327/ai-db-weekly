嵌入式文档数据库，以 Python 库形式实现 MongoDB/PyMongo 接口子集

综述（解读层）

Mongita 是一个自包含的 Python 嵌入式文档数据库，实现 PyMongo API 的常用子集，支持磁盘（默认 ~/.mongita）或内存两种存储方式，无需启动服务器进程。依赖仅 pymongo 和 sortedcontainers。它不是进程安全的，不支持多客户端场景，且大量命名关键字参数未实现。README 给出 10k 文档基准测试数据，并建议项目规模增长后迁移到 MongoDB。

  • 实现 PyMongo API 常用子集，含 find/insert/update/delete、Cursor 及 $eq/$gt/$in 等查询操作符与 $set/$inc/$push 更新操作符
  • 支持磁盘与内存两种存储模式，通过 MongitaClientDisk / MongitaClientMemory 初始化
  • 测试覆盖率为 100%，线程安全为实验性特性

适用场景（解读层）

  • 嵌入式应用中需要文档模型而非关系模型时的本地存储
  • 单元测试中通过 monkey-patch 替换 PyMongo，保持测试隔离
