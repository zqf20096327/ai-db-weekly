🧭 简介解读层（AI·证据行可回查）

基于 Tauri 的多数据库 AI 工作台，通过本地 AI Runtime 支持自然语言操作。

综述（解读层）

NexusPilot 是一个面向开发者和数据团队的多数据库桌面工作台，支持 PostgreSQL、MySQL、SQLite、Redis、ClickHouse 和 Oracle。AI 代理基于真实连接状态和引擎原生对象工作，数据库操作经由受限工具执行，SQL 与 Redis 写入需风险分析与审批。基于 Tauri v2、React 19 和 Rust 构建，AI Runtime 为 Bun + Elysia 本地边车。开发需 Bun ≥ 1.3 与 Rust 工具链。

  • 支持 PostgreSQL、MySQL、SQLite、Redis、ClickHouse、Oracle 六种数据源，各引擎呈现原生对象层级与操作而非统一表抽象
  • AI 代理通过受限工作台工具访问数据源，写入操作包含风险分析与审批流程，高风险操作需强确认
  • 本地 AI Runtime 托管模型供应商与凭证，支持自定义 OpenAI 兼容供应商，前端不存储 LLM 凭证；不启用 AI 与云同步时工作台仍可独立使用

适用场景（解读层）

  • 在单一连接树中管理关系型、键值与列式分析数据源并进行对象探索与查询编辑
  • 用自然语言描述多步骤数据任务，由代理经审批边界执行查询、解释与操作
  • 通过 NexusPilot Cloud 端到端加密在多设备间同步已保存的连接与文件夹（可选商业服务）
