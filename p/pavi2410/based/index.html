🧭 简介解读层（AI·证据行可回查）

基于 Rust 与 GPUI 的本地桌面数据库客户端，配置随 Git 仓库提交。

综述（解读层）

Based 是用 Rust 和 GPUI 编写的本地优先桌面数据库客户端，支持 PostgreSQL、SQLite 和 MongoDB。其特点是将连接配置与保存的查询存放在可提交到 Git 的 .based 目录中，无后端服务，数据保留在本机。提供 macOS、Linux、Windows 安装包，可通过 Homebrew 或 winget 安装，适合希望在版本库中管理数据库配置与查询的团队。

  • 连接配置与查询以 project.toml、connections/、queries/ 形式存放在 .based 目录，可随 Git 提交共享
  • 无后端服务，连接与查询均在本地运行，支持 PostgreSQL、SQLite、MongoDB
  • 提供 mise 任务脚本，覆盖开发运行、构建、测试、打包流程

适用场景（解读层）

  • 将数据库连接配置和常用查询纳入版本控制，供团队通过 Git 共享
  • 在本地桌面直接查询和管理 PostgreSQL、SQLite、MongoDB 数据库
  • macOS、Linux、Windows 平台用户通过包管理器或安装包部署
📖 README 首段存档原文 · 程序抽取

Based is a local-first desktop database client written in Rust. Connection configs and saved queries live in a committed .based/ folder — no backend service, data stays on your machine.
