🧭 简介解读层（AI·证据行可回查）

将 Notion 工作区镜像为本地 SQLite 归档与规范化 Markdown

综述（解读层）

notcrawl 通过桌面缓存快照、官方 API 或 Notion MCP 三种来源同步 Notion 工作区，以 SQLite 为规范归档、Markdown 为可读导出，提供 FTS5 全文检索、三栏 TUI 浏览、CSV/TSV 数据库导出及基于 git 的归档共享。适合需要不依赖 Notion UI 搜索、查询或分发工作区内容的个人与代理。API 源需配置 NOTION_TOKEN，桌面缓存覆盖范围有限。

  • 支持 desktop、api、notion-mcp 三种同步来源，API 只读请求对瞬时失败最多重试四次
  • 提供 FTS5 全文搜索、read-only SQL 查询、TUI 浏览及 Markdown/CSV/TSV 导出
  • git 共享模式发布压缩 JSONL 快照，订阅端无需 Notion 凭据即可搜索归档

适用场景（解读层）

  • 为个人或 AI 代理建立可离线搜索与 diff 的 Notion 工作区历史归档
  • 通过 git publish/subscribe 在多台机器间共享归档
  • 将已抓取的 Notion 数据库导出为 CSV/TSV 用于分析或备份
📖 README 首段存档原文 · 程序抽取

notcrawl mirrors a Notion workspace into local SQLite and normalized Markdown. It is for people and agents that need to search, query, diff, or share workspace history without depending on the Notion
