🧭 简介解读层（AI·证据行可回查）

将 Discord 服务器历史与桌面缓存消息归档到本地 SQLite 的 Go 命令行工具。

综述（解读层）

Discrawl 是一个 Go 编写的 CLI，用于将 Discord 服务器数据和 Discord Desktop 本地缓存消息归档到 SQLite，支持离线搜索、SQL 查询和终端浏览。它面向需要持久保存服务器历史或本地恢复缓存私信的用户。支持 bot 同步、缓存读取、Git 快照分享四种数据来源；wiretap 只读取已缓存消息，不获取完整账号历史。

  • 提供 FTS5 全文搜索、频道/作者过滤和 TUI 浏览，并可通过 sql 命令只读查询数据库
  • 支持四种归档来源：bot 同步（sync/tail）、Discord Desktop 缓存导入（wiretap）、Git 快照订阅（subscribe）和远程归档（subscribe-cloud）
  • 通过 publish 生成分片 Git 快照供他人订阅，读取者无需 Discord 凭据，快照排除 wiretap 私信

适用场景（解读层）

  • 用 Discord bot 持续同步并回填服务器消息，建立本地可搜索的历史归档
  • 无需 token 地扫描 Discord Desktop 本地缓存，离线检索已缓存消息和私信
  • 以 Git 快照向团队共享只读归档，或将 JSON 状态输出集成到自动化流程
