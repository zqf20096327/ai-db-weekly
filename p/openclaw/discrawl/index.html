将 Discord 服务器历史与本地缓存消息归档到 SQLite 的 CLI

综述（解读层）

discrawl 是一个 Go 编写的命令行工具，把 Discord 服务器数据及 Discord Desktop 本地缓存消息归档到本地 SQLite，用于离线搜索、SQL 查询和终端浏览。支持 bot 同步、缓存导入（wiretap）、Git 快照发布与订阅四种来源；FTS5 搜索为默认模式，语义搜索需另行配置嵌入提供方。发布快照会排除 wiretap 私信。

  • 支持 bot 同步、Desktop 缓存导入、Git 快照发布/订阅及远程归档等多种数据来源
  • 提供 FTS5 全文搜索、TUI 浏览、只读 SQL 查询，语义搜索为可选功能
  • 以 JSON 输出提供 status/diagnostics/coverage 等命令，供脚本与 CI 使用

适用场景（解读层）

  • 需要离线保留和检索 Discord 服务器历史的场景
  • 无凭据读取他人发布的归档快照（Git 订阅或远程 Worker）
  • 自动化流水线中通过 JSON 命令获取归档状态与指标
