Java 21 基准程序，比较文本文件、PostgreSQL 与 openGauss 的数据操作性能

综述（解读层）

该项目用 Java 21 实现了一套基准测试，比较 UTF-8 管道分隔文本文件、PostgreSQL 与 openGauss 在电影数据集上的查询、更新与并发读操作（E1–E4、U1–U4、C1），数据集含 9,204 行原始数据及确定生成的 1,012,440 行大表。仓库包含完整实现与不可变的原始测量 CSV。驱动 jar 与数据集未随仓库分发，需自行置于 lib/ 和 data/ 路径；密码仅从环境变量读取。

  • 支持纯文本文件、PostgreSQL、openGauss 三种存储方式的查询/更新基准，并发测试覆盖 1/2/4/8 三个以上并发级
  • 保留附加式（append-only）原始测量 CSV，附 SHA-256 校验与 experiment.md 中的方法学与操作 ID 映射
  • 提供三个源码版本：canonical 多文件实现、单文件完整版，以及省略测量框架、无法复现正式计时的 Blackboard 简化版

适用场景（解读层）

  • 需要对比文件扫描/重写与 JDBC 数据库操作在查找与更新负载下行为的课程实验或教学演示
  • 需要在相同顺序与并发负载下对 PostgreSQL 与 openGauss 做可复现测量并保留原始记录的场景
  • 以确定生成的 110 倍扩充数据集（含 SHA-256 校验）进行基准方法学或数据一致性验证
