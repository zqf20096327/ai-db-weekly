基于 Boost.Asio 的 C++11 MySQL/MariaDB 客户端库

综述（解读层）

Boost.MySQL 是 Boost 旗下的 MySQL/MariaDB 客户端库，基于 Boost.Asio 实现，采用 header-only 形式，要求 Boost 1.82+、C++11 编译器和 OpenSSL。它支持回调、future、协程等异步模型，可与其他 Asio 生态库配合。Boost 1.85 起需额外链接 Boost.Charconv（编译库）。

  • 支持文本查询、prepared statements、存储过程及客户端侧 SQL 生成
  • 支持 mysql_native_password 与 caching_sha2_password 认证插件、TLS 加密连接
  • 支持 TCP/UNIX socket 传输、连接池和（实验性）管道

适用场景（解读层）

  • 在基于 Boost.Asio 的 C++ 异步网络应用中访问 MySQL/MariaDB
  • 需使用回调、future 或协程（含 C++20）进行数据库异步操作的场景
  • 通过 TCP 或 UNIX socket 连接本地/远程数据库的 C++ 项目
