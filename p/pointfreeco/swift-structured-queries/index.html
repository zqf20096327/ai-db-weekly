用 Swift 宏为数据模型生成类型安全 SQL 查询构建器

综述（解读层）

StructuredQueries 是一个 Swift SQL 查询构建库：通过 @Table 等宏标注 schema 类型后，提供生成 SELECT/INSERT/UPDATE/DELETE、外连接和递归 CTE 的 API，并用 #sql 宏在表达式或整句级别嵌入 SQL 字符串。它不含数据库驱动，需配合 SQLiteData（GRDB 集成）等库执行语句，当前主要针对 SQLite 调优。支持 SwiftPM 安装，MIT 许可。

  • 支持构建 SELECT、INSERT、UPDATE、DELETE 语句、类型安全外连接与递归 CTE
  • 通过 #sql 宏可在表达式或整条语句粒度嵌入 SQL 字符串
  • 不自带数据库驱动，聚焦 SQL 构建，通过 SQLiteData/StructuredQueriesGRDB 集成 GRDB

适用场景（解读层）

  • Swift 应用中以类型安全方式构建 SQLite 查询
  • 需要将 SQL 字符串与查询构建 API 混合使用的项目
  • 作为 SwiftData/@Query 的替代方案（经由 SQLiteData 驱动）
