从关系型数据库向 Neo4j 导入数据的 ETL 工具

综述（解读层）

Neo4j ETL 用于将关系型数据库中的数据导入 Neo4j。它自动提取 RDBMS 元数据并派生图模型，支持在 UI 中可视化编辑标签、关系类型和属性映射，映射可保存为 JSON。提供命令行工具和 Neo4j Desktop 图形界面两种使用方式；MySQL 和 PostgreSQL 的 JDBC 驱动内置，其他数据库需自行提供 JDBC 驱动 jar。注意其采用 Neo4j 预发布许可协议。

  • 自动提取关系数据库元数据并派生图模型，映射结果可持久化为 JSON
  • 支持 neo4j-import、bolt-connector、cypher-shell、neo4j-shell 等多种导入方式
  • 内置 MySQL 与 PostgreSQL JDBC 驱动，支持配置自定义 JDBC 驱动（Oracle、SQL Server、DB2、SAP Hana 等提供 JDBC-URL）

适用场景（解读层）

  • 将 MySQL、PostgreSQL 等关系库数据迁移导入 Neo4j
  • 通过 Neo4j Desktop 界面交互式配置 RDBMS 连接并编辑图模型映射
  • 使用命令行批量执行从 RDBMS 到 Neo4j 的导出导入流程
🔌 适配哪些库db_scan 程序判定

MySQL、Oracle、PostgreSQL、SQL Server
