🧭 简介解读层（AI·证据行可回查）

面向 ML 特征存储的嵌入式键值数据库，基于 Rust 内存映射索引实现本地读取。

综述（解读层）

IKV 是一个面向 ML 特征在线检索的键值存储，由嵌入式数据库和数据平面两部分组成：数据平面（IKV Cloud 或自托管）通过 Kafka 流分发写入，嵌入式引擎以库形式运行在应用内，用内存映射文件与哈希表索引读取。提供 Python/Go/Java SDK，最终一致（毫秒级延迟），主键和分区键在创建时固定。自托管版本尚未上线。

  • 嵌入式架构：读取不经过网络调用，数据集可放入内存时官方基准报告 P99 为个位数微秒，配合本地 Flash/SSD 为亚毫秒级
  • 自动数据分层：内存映射索引保留热点数据，其余自动落盘，支持零拷贝磁盘读取，无需手动配置
  • 文档模型支持强类型字段（数值、UTF8 字符串、字节）以及单键与批量读、按字段粒度的 Upsert 和 Delete 操作

适用场景（解读层）

  • 推荐、搜索、电商等应用中 ML 推理/评分阶段的特征在线检索
  • 对延迟敏感且不要求读后写一致性的通用缓存或存储场景
  • 利用现有应用集群的内存/SSD 存储数据，避免单独部署数据库集群
