🧭 简介解读层（AI·证据行可回查）

本地优先的 AI 代理记忆层，以单个 SQLite 文件自动捕获并检索对话记忆

综述（解读层）

TrueMemory 是一个为 AI 编程代理提供长期记忆的本地工具，通过生命周期钩子从 Claude Code、Cursor、Gemini CLI 等工具的对话中自动捕获记忆并在下次会话注入，数据保存在本机单个 SQLite 文件中，无需云端调用（Pro 层查询扩展除外）。提供 Edge/Base/Pro 三个层级，也可作为 Python 库使用，采用 AGPL-3.0 许可，商业使用需单独授权。

  • 自动从对话中捕获并注入记忆，数据存储于本地 ~/.truememory/memories.db 单个 SQLite 文件
  • 提供 Edge、Base、Pro 三个层级，内置嵌入模型与重排序器，包含 6 层检索管线与 agentic 多轮搜索 API
  • 附 benchmarks/ 目录中可复现的 LoCoMo、LongMemEval、BEAM 评测脚本，兼容 Claude Code/CLI、Cursor、Codex CLI、Gemini CLI

适用场景（解读层）

  • 为 Claude Code、Cursor 等 AI 编程工具跨会话保留用户偏好、技术栈与决策记录
  • 作为 Python 库（pip install truememory）为应用添加 add/search/get/update/delete 记忆接口
  • 在不联网或对数据本地性有要求的环境运行，Edge 层仅用 CPU 即可运行
