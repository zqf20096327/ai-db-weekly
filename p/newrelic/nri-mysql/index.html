New Relic 的 MySQL 集成，通过查询数据库状态与配置变量采集指标和清单

综述（解读层）

该项目是 New Relic Infrastructure 的 MySQL 集成，用于捕获 MySQL 数据库的性能指标和清单数据。数据通过直接查询数据库的状态和配置变量获得。项目使用 Golang 编写（推荐 1.11+），通过 make 构建出可执行文件 nri-mysql，依赖由 govendor 管理。安装和使用说明、更多细节见官方文档网站，README 本身未包含具体配置步骤。适合需要将 MySQL 监控数据接入 New Relic 平台的用户。

  • 通过直接查询 MySQL 数据库的状态和配置变量生成指标与清单数据
  • 使用 Golang 构建，执行 make 生成可执行文件 nri-mysql，支持 -help 查看用法
  • 外部依赖通过 govendor 工具管理并锁定版本

适用场景（解读层）

  • 将 MySQL 数据库的性能指标采集到 New Relic Infrastructure 平台
  • 收集 MySQL 的状态与配置变量作为清单数据进行报告
  • 作为 New Relic 集成体系的一部分在基础设施环境中运行
