🧭 简介解读层（AI·证据行可回查）

开源协作 Web 应用，将数据笔记本与仪表盘结合在同一页面中。

综述（解读层）

Briefer 是一个协作式 Web 应用，每个页面可切换为笔记本或仪表盘模式，支持用 SQL、Python、Markdown 和原生可视化构建内容，并通过拖拽生成仪表盘。它面向技术与非技术用户组成的团队，需以 Docker 部署运行，采用 AGPLv3 许可证。

  • 支持在同一页面中以笔记本模式编写 SQL、Python 和 Markdown，并在仪表盘模式中拖拽复用这些元素
  • 支持连接 PostgreSQL、BigQuery、Redshift、Athena、MySQL 等数据源，SQL 查询结果自动转为 Python 可用的数据框
  • 支持多人实时协作编辑，以及定期调度运行并生成快照；AI 代码生成功能依赖可选的 ai 服务与 OpenAI API 密钥

适用场景（解读层）

  • 团队在共享工作区中共同编写数据分析笔记本并发布给非技术成员查看
  • 为已连接数据库的数据构建带输入框、下拉选择和日期筛选的交互式仪表盘或数据应用
  • 将需要定期更新的笔记本或仪表盘配置为周期性运行，并通过快照比较变化
