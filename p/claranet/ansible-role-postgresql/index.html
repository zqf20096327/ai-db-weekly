用于在 Debian 和 RedHat 系统上安装并配置 PostgreSQL 的 Ansible 角色

综述（解读层）

这是一个 Ansible 角色，通过变量驱动的方式在 Debian、Ubuntu、RockyLinux 等发行版上安装 PostgreSQL 12–17 并进行配置。除安装外，还实现数据目录初始化、物理复制、备份、定时 vacuum、用户与数据库对象管理等任务，各步骤通过 tag 分开执行。要求 Ansible >= 2.10，依赖 community.postgresql 等集合，安装方式为 ansible-galaxy。内置备份脚本仅建议用于开发或测试用途。

  • 支持 PostgreSQL 12–17，覆盖 Debian 11/12、Ubuntu 22.04/24.04、RockyLinux 8.9/9.3
  • 提供安装、初始化、配置、自动调优（基于 pgconfig.org）、物理复制、备份、vacuum 等带 tag 的分阶段任务
  • 支持管理数据库用户、成员关系、表空间、数据库、属主与权限、扩展，以及执行 SQL 语句；兼容 Patroni 场景的仅安装模式

适用场景（解读层）

  • 在受支持的 Debian 或 RedHat 系主机上以 IaC 方式批量部署 PostgreSQL 服务器
  • 配置主从物理复制（含 replication slot）的初始化
  • 通过变量集中管理数据库用户、表空间、权限与扩展等对象
