综述（解读层）

Libem 是一个开源复合 AI 工具链，用于实体匹配（EM），即判断两条描述是否指向同一实体。面向数据管理与集成场景的用户，可通过 pip 安装为库或 CLI 使用，经 calibrate 配置模型（GPT-4o、GPT-3.5-turbo、Llama3 等）与工具（如 browse）。调用依赖 OpenAI API 密钥。

  • 提供 Python 库与 CLI 两种使用方式，支持配置模型、工具与参数
  • 支持 GPT-4o、GPT-4o-mini、GPT-4、GPT-3.5-turbo、Llama3 等多种模型
  • 内置基准测试工具，覆盖 amazon-google、dblp-acm 等 10+ 常见 EM 数据集

适用场景（解读层）

  • 判断两条产品或文献描述是否指向同一实体的数据集成任务
  • 通过基准测试工具在不同数据集上比较 Libem 各配置的表现
  • 作为服务或库嵌入应用中执行实体匹配
