🧭 简介解读层（AI·证据行可回查）

纯 Rust 编写的 MCP 记忆服务器，融合混合检索与时间知识图谱，本地单二进制运行。

综述（解读层）

MemoryPilot 是一个为 AI 编程助手提供持久化记忆层的 MCP 服务器，用 Rust 实现，编译为单个二进制文件，无需运行时依赖。它通过 BM25、jina-embeddings-v5 嵌入的 RRF 融合与交叉编码器重排实现混合检索，写入时在本地完成去重、实体抽取、图谱链接与嵌入，调用 LLM 次数为零。检索默认开启自适应重排时约 900 毫秒/次，可通过环境变量关闭重排降至约 28 毫秒。适用于在 Cursor、Claude Desktop、VS Code 等客户端本地存储与检索会话记忆的用户。

  • 提供 BM25 与 jina-embeddings-v5 RRF 融合及交叉编码器重排的混合检索，支持 100+ 语言
  • 包含时间知识图谱、GraphRAG、AAK 压缩、自动分类与自动压缩机制，写入与检索各产生 0 次 LLM 调用
  • 以单个 Rust 二进制分发，默认暴露 25 个工具（完整配置 74 个），支持签名自动更新

适用场景（解读层）

  • 为 Cursor、Claude Desktop、VS Code、Windsurf 等 MCP 客户端添加本地持久化会话记忆
  • 以模糊描述检索过去的 Cursor 或 Claude 对话内容
  • 在不调用外部 API、数据完全保留在本地的环境中构建带知识图谱的代理记忆层
