🧭 简介解读层（AI·证据行可回查）

基于 XSD 自动生成关系模型并加载 XML 文件的 Python 包

综述（解读层）

xml2db 读取 XSD 模式生成由外键关联的数据库表模型，随后解析并加载 XML 文件内容，也可将数据导回 XML。它通过 SQLAlchemy 连接数据库，集成测试覆盖 PostgreSQL、MySQL、MS SQL Server 和 DuckDB。使用者需提供 XSD 模式，可经 pip 安装，并提供 CLI 与 Python API 两种入口。

  • 从 XSD 模式自动生成含外键关系的表结构，无需编写映射规则
  • 通过 SQLAlchemy 支持多种数据库后端，并提供 serve、import、render 三个 CLI 子命令
  • 加载后数据可导回 XML，经 DuckDB 可导出为 Parquet、Delta Lake 或 Iceberg

适用场景（解读层）

  • 需要保留深层嵌套、多层级重复元素的复杂 XML 文件
  • 同一模式的周期性文件批次，重复内容只存储一次
  • 需求未定的场景：全部加载一次后用 SQL 探索，或用 dbt、视图做后续转换
