🧭 简介解读层（AI·证据行可回查）

基于 Faker 的 Python 库，生成随机数据库表、Pandas 数据框和 Excel 文件

综述（解读层）

pydbgen 是一个 Python 包，用于按用户选择的数据类型（姓名、邮箱、电话等字段）和数量，生成随机数据库表、Pandas Series/DataFrame 或 Excel 文件，可指定 PRIMARY KEY 并写入新建或已有的 .db/.sqlite 文件。其数据生成核心依赖 Faker，另自行实现了真实感邮箱和车牌等类型。适用于需要练习 SQL 或测试数据的场景。

  • 提供 gen_data_series、gen_dataframe、gen_table、gen_excel 四个主要方法，分别生成 Pandas Series、DataFrame、SQLite 数据库表和 Excel 文件
  • 内置姓名、城市、日期、SSN、公司、职位、电话、车牌等多种数据类型，支持 real_email、real_city、phone_simple 等选项
  • gen_table 使用 Python 内置 SQLite 引擎建表，可指定数据库文件名、表名和 PRIMARY KEY 字段

适用场景（解读层）

  • SQL 初学者需要 .db/.sqlite 样本数据库文件进行练习
  • 数据科学学习者为 Pandas 操作生成含姓名、邮箱等常见字段的随机 DataFrame
  • 开发者生成合成测试数据表或 Excel 文件用于填充数据库
