🧭 简介解读层（AI·证据行可回查）

从 Mac 读取 Apple 各设备屏幕使用时间，存入 SQLite 并导出到多种数据平台

综述（解读层）

Screen Time Exporter 是一个 macOS 上的 Python 后台代理，每 15 分钟读取 Mac 本地的 Biome 与 knowledgeC.db 存储，获取通过 iCloud 共享的 iPhone、iPad 使用记录及本机记录，将每个应用会话存入本地 SQLite，并导出到 InfluxDB/Grafana、Home Assistant、终端或 MCP 服务器。使用前需在终端和 Python 解释器上授予完全磁盘访问权限；Apple 仅保留数周历史，更早数据只有在导出器运行期间才存在。

  • 每 15 分钟读取 Biome 与 knowledgeC.db，按设备、开始时间、bundle id 上插会话记录，并重建每日、每应用、每类别与每小时聚合
  • 提供 Grafana 仪表盘、Home Assistant 传感器、终端 summary/dump 报告以及只读 MCP 服务器（支持 Claude、Codex、Cursor 等客户端）
  • 内置 270+ bundle id 的名称与 14 个类别映射，`screentime setup` 与 `doctor` 完成配置、连接测试和 launchd 代理安装

适用场景（解读层）

  • 将 iPhone、iPad、Mac 的屏幕使用时间数据长期保存在自己的 SQLite/InfluxDB 数据库中供查询和绘图
  • 在 Home Assistant 中以传感器形式使用今日总时长、深夜使用、本周均值等指标驱动自动化
  • 通过 MCP 让本地 AI 助手回答如周对比、午夜后使用等屏幕时间问题
