在浏览器标签页内运行真实 Node、Bun 与 Python 的 MIT 开源运行时 SDK

综述（解读层）

Vivari 是基于 SharedArrayBuffer 与 Atomics.wait() 的浏览器内运行时，执行 Node 的真实 lib/、npm/yarn/pnpm CLI 与 Pyodide CPython，提供 @vivari/core SDK 和 React 绑定。运行依赖页面启用 COOP/COEP 跨域隔离；Bun 为 API 兼容 shim，部分原生 OS API 显式拒绝调用。适用于需要在前端嵌入代码执行环境的开发者。

  • 运行 Node 真实 lib/（fs、stream、http、crypto 等）及真实 npm、yarn、pnpm CLI，支持同步 require 与 node_modules 解析
  • 通过 Pyodide 运行 CPython 3.14，附带 pip、REPL 及 NumPy、pandas 等科学库；Postgres 经 PGlite 以 Wasm 形式运行于虚拟文件系统
  • 提供基于 Chrome DevTools Protocol 的步进调试器和经 isomorphic-git 的本地 Git 操作，无远程 clone/push/pull

适用场景（解读层）

  • 在网页中嵌入交互式代码演练场或在线 IDE（配合 Studio 模板运行 npm install 与 dev server）
  • 在前端运行 Next.js App Router、Vite 系框架及 Express/Hono 等服务器的开发预览
  • 在无服务端条件下执行 Python 科学计算或 SQLite/PGlite 数据库实验
