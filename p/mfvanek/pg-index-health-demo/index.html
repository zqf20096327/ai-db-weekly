🧭 简介解读层（AI·证据行可回查）

pg-index-health 库的演示项目集合，展示 PostgreSQL 结构健康检查用法

综述（解读层）

该项目是 pg-index-health 库的示例程序集合，包含三个模块：非 Spring 版本、Spring Boot 版本及 Kotlin 版 Spring Boot 版本，供希望使用该库的开发者参考。技术栈为 Java 21，使用 Testcontainers 连接数据库。旧版本需求可参考 0.6.x release（含 Embedded PostgreSQL 与 Java 8 兼容版本）。

  • 提供 without-spring、Spring Boot、Spring Boot Kotlin 三个演示模块
  • 基于 Java 21 与 Testcontainers 运行
  • 配套 super-linter（含 SQLFluff）的本地 lint 脚本

适用场景（解读层）

  • 学习 pg-index-health 库在 Spring 或非 Spring 项目中的集成方式
  • 作为功能测试中分析数据库结构的参考示例
  • 需要 Java 8 或 Embedded PostgreSQL 旧版示例时查阅历史 release
