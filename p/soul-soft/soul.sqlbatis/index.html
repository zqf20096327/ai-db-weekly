综述（解读层）

Soul.SqlBatis 是一个基于 .NET 的 ORM 框架，提供 DbContext 配置、实体模型约定（默认 Id 为主键自增列）、LINQ 风格查询、参数化 SQL、批量更新删除、自定义数据库函数映射与类型映射机制。源码约 4000 行，采用 MIT 许可，适合需要在 .NET 项目中操作关系数据库并希望自定义映射行为的开发者。

  • 支持 LINQ 与 SQL 混合查询，包含分页、聚合统计、IN 查询、子查询及查询复用
  • 提供实体变更跟踪，以及 ExecuteUpdate/ExecuteDelete 批量更新与删除
  • 支持通过 [DbFunction] 特性自定义数据库函数映射，并可通过 UseTypeMapper 或工厂方法自定义类型映射

适用场景（解读层）

  • 需要以 LINQ 语法进行数据库增删改查并分页查询的 .NET 项目
  • 需要自定义列到属性类型映射或映射数据库自定义函数的场景
  • 需要以参数化查询和 SqlBuilder 组装动态查询条件的场景
