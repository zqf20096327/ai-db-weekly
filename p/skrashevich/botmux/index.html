🧭 简介解读层（AI·证据行可回查）

自托管 Go 编写的 Telegram 群组/频道管理中枢，多机器人仪表盘与反向代理。

综述（解读层）

BotMux 是一个基于 Web 的 Telegram Bot 管理工具，用 Go 编写，可 Docker 部署。它接收 bot token 后自动发现所在聊天并生成仪表盘，通过接管长轮询实现消息监控、分析与管理操作；同时提供 API 反向代理，可将旧 webhook 机器人接入长轮询或推送模式。限制在于轮询权被 BotMux 独占，后端需改指向其 /tgapi/ 地址才能捕获出站消息。

  • 单实例管理多个 bot，每个可运行在管理模式、代理模式或两者同时
  • 提供 Telegram 兼容的 /tgapi/ 代理与 Long Poll 拉取模式，后端仅需修改 API 地址即可接入
  • 支持基于正则、用户 ID、聊天 ID 或 LLM 自然语言规则的 bot 间路由，含 Source-NAT 回路；可经通用 webhook 或原生 Slack 桥接外部协议

适用场景（解读层）

  • 为多个 Telegram 群组/频道提供集中式消息监控、统计与管理操作
  • 为使用 webhook 的既有 bot 后端接入长轮询或推送转发
  • 在 Slack 等外部协议与 Telegram bot 之间建立双向消息桥接
