综述（解读层）

Flossx83 是一套自托管的 ISO 8583 支付交易模拟工具，面向 BFSI 工程师、安全审计人员与金融科技开发者。核心交换引擎（Spring Boot/Java）解析并路由 ISO 8583 报文，支持 TCP 与 HTTP 接入；配套 PyQt5 图形化 POS/ATM 模拟器、FastAPI 风控微服务、AES256 令牌化模块与 JSON 审计日志。README 声明其仅限教育、演示与测试环境使用，Admin Dashboard 与下游网络路由仍在路线图中未完成。

  • 核心交换引擎解析并路由 ISO 8583 报文（MTI + Fxx），支持 TCP/HTTP 双接入与协议检测
  • PyQt5 图形化 POS/ATM 模拟器支持手工输入或随机化 ISO 字段，可复现回归与模糊测试场景
  • PAN/CVV 经 AES256+盐令牌化，日志脱敏，持久化仅存令牌化交易数据

适用场景（解读层）

  • 支付报文格式的学习与开发联调
  • 合规/审计演示环境的交易流程模拟与追踪
  • 回归与模糊测试场景的可视化构造与回放
