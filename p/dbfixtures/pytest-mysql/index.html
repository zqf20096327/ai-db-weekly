pytest 插件，为依赖 MySQL/MariaDB 的测试提供进程与客户端 fixtures

综述（解读层）

pytest-mysql 是一个 pytest 插件，用于测试依赖运行中 MySQL/MariaDB 数据库的代码。它提供 mysql、mysql_proc、mysql_noproc 三个 fixture：前者在每个测试后删除测试数据库，proc 在本地启动 mysqld，noproc 连接已有实例（如 Docker 容器）。支持经 fixture 工厂参数、命令行、pytest.ini 三层配置。需本机安装 mysqld、mysqladmin 等二进制，README 注明在 MySQL 8.0+ 与 MariaDB 10.11+ 下测试。

  • 提供 mysql（函数级客户端，测试后删除数据库）、mysql_proc（会话级启动本地进程）、mysql_noproc（会话级连接已有实例）三个内置 fixture
  • 可通过 fixture 工厂参数、命令行选项（如 --mysql-port）和 pytest.ini（如 mysql_port）三种方式配置主机、端口、用户、可执行文件路径等选项
  • 支持连接 Docker 中运行的 MySQL/MariaDB，并可用 factories 自定义额外的客户端与进程 fixture

适用场景（解读层）

  • 为依赖 MySQL/MariaDB 的 Python 代码编写集成测试，通过 mysql_proc 在测试会话中启动本地数据库实例
  • 通过 mysql_noproc 连接 Docker 容器或已运行的数据库服务执行测试
  • 结合 SQLAlchemy 等工具在测试中填充与清理数据库数据
