🧭 简介解读层（AI·证据行可回查）

Fat-Free 框架的数据库迁移插件，以 MigrationCase 管理结构变更

综述（解读层）

该插件为 Fat-Free 框架提供 SQL 数据库迁移功能，开发者可将每次数据库变更封装为 MigrationCase，插件通过自动注册的 /migrations 路由执行迁移。需先建立 SQL 连接，且仅在 DEBUG>=3 时启用；支持配置文件、日志记录、CLI 模式，采用 GPL v3+ 许可证。

  • 自动添加 4 条 /migrations 路由，提供 Web 界面并支持指定目标版本执行动作
  • 在数据库中创建 migrations 表记录迁移状态，动作日志写入 LOGS 目录的 migrations.log
  • 支持 CLI 模式运行（php index.php /migrations），并可经 ini 配置文件调整 ENABLE、PATH 等项

适用场景（解读层）

  • 在 Fat-Free 项目中以 MigrationCase 方式记录并执行数据库结构变更
  • 通过浏览器或 CLI 界面执行 migrate、fresh、makecase 等迁移动作
  • 升级插件版本时使用 upgrademc 动作更新旧的迁移用例
