🧭 简介解读层（AI·证据行可回查）

Rust 编写的独立向量数据库，用 HNSW 索引与磁盘存储实现相似度检索

综述（解读层）

Blaze-DB 是一个 Rust 实现的独立向量数据库，面向需要嵌入向量存储与相似度检索的开发者。核心机制包括 HNSW 图索引、多距离度量（余弦/欧氏/点积）、LRU 索引缓存与内存映射文件读取，支持 Docker 部署和 CLI 查询。README 明确标注项目尚在开发中，部分功能（如客户端文本分块、备份边缘场景）仍待完善。

  • 实现 HNSW 图结构进行近似最近邻搜索，支持 Cosine、Euclidean、Dot Product 三种距离度量
  • 索引以二进制/JSON 格式存储在磁盘，使用内存映射文件与 LRU 缓存进行读取，写入采用临时文件加原子重命名的崩溃安全方式
  • 提供 blaze-server 与 blaze-client 两个二进制，以及 blzdb bench 基准命令，可在隔离环境中模拟并发读写

适用场景（解读层）

  • 对产品描述、文本等内容的嵌入向量进行语义相似度搜索（如 README 中的 Amazon 商品数据集查询示例）
  • 需要通过 Docker 自托管向量检索服务的场景
  • 在本地磁盘上存储与检索向量索引，配合 CLI 客户端执行 top-k 查询

Blaze-DB is a *reasonably* high-performance vector database designed for efficient hard disk-storage and fast retrieval of embeddings thanks to HNSW Indexing & turboquant quantization.
