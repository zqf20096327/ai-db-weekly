基于 actix-web 的 Rust RESTful API 服务脚手架项目

综述（解读层）

该仓库提供一个使用 actix-web 构建的 REST API 服务器模板，集成 sqlx（postgres 连接池）、redis（mobc 连接池）、config 配置、slog 日志，内置用户鉴权表 SQL 脚本与 Docker Compose 开发环境。通过 cargo-make 提供 dev/clean/build/buildlinux 脚本，适合希望按此结构搭建 Rust 后端服务的开发者。注意需异步开发，当前暂未使用第三方输入验证库。

  • 集成 actix-web、sqlx、redis-rs（mobc 连接池）、config、slog 等组件，连接池与配置通过 app_data 注入
  • 提供 cargo-make 脚本（dev/clean/build/buildlinux）与 docker-compose 启动 postgres/redis 的开发环境
  • 错误以统一 JSON 格式（errcode/errmsg）输出，输入验证通过 validator 模块的正则方式处理

适用场景（解读层）

  • 快速搭建带有 postgres 与 redis 的 Rust REST API 服务端项目
  • 需要配置文件（app.toml）与文件/屏幕双输出日志的 Rust 后端工程参考
  • mac 上交叉编译 Linux 的 Rust 项目构建流程参考
