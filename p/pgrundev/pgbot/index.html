🧭 简介解读层（AI·证据行可回查）

连接 PostgreSQL 的只读诊断工具，读取统计视图生成健康报告

综述（解读层）

pgbot 是一个 Go 编写的单一静态二进制工具，以 pg_monitor 只读角色连接 PostgreSQL 14–18，读取数据库自身统计视图，生成健康检查报告，并对比本地基线指出变化。除可选的 ask/explain AI 层外，所有检查均为确定性计算且无需 API key。当前为 beta 状态，--json 契约有版本号，人类可读输出不是稳定接口。

  • 提供 inspect、indexes、queries、tables、vacuum、waits 等子命令，从只读会话读取 pg_stat_statements 等统计视图
  • 支持 --json（版本化契约，含 JSON Schema）、SARIF、JUnit、Prometheus 等输出格式，并通过 MCP 向 AI 代理提供检查结果
  • 每次运行写入本地基线，diff/why 命令可离线对比快照并解释回退；只读性由 pg_monitor 角色加会话级 READ ONLY 设置实现

适用场景（解读层）

  • 对不拥有的数据库做即时健康检查与性能排查，无需部署监控平台
  • 在 CI 中运行 lint/inspect 并以 SARIF/JUnit 格式输出检查结果
  • 让 AI 代理通过 --json 契约或 MCP 获取结构化的 PostgreSQL 检查发现
