Rust 编写的 Postgres 兼容运行时，单进程托管数千个隔离的一次性数据库。

综述（解读层）

PGX 是用 Rust 实现的数据库运行时，支持 Postgres 线协议与 SQL 方言，面向 AI agent 沙箱、CI、PR 与预览环境等短生命周期数据库场景。它从密封模板按写时复制分支数据库，空闲占用约 70 KB 内存；运行于 fsync=off 的配置，无崩溃恢复保障，不适用于生产数据。

  • 实现 Postgres 线协议与 SQL 方言，Rails、Django、Prisma、SQLAlchemy、node-postgres 可不经修改运行迁移、测试与模式变更流程
  • 支持从密封模板按写时复制（如 ZFS 块克隆）创建数据库，连接时以
