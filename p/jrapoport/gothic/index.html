Go 编写的用户注册与认证微服务，基于 OAuth2 与 JWT，提供 REST/gRPC 接口

综述（解读层）

Gothic 是用 Go 编写的用户注册与认证微服务，处理用户注册、认证和自定义用户数据，基于 OAuth2 与 JWT 实现。README 提到它是 Netlify GoTrue 的重写，适合需要自建认证服务的使用者。它通过 REST、gRPC 与 gRPC-Web 暴露接口，使用 Gorm 支持多种数据库，附带 gadmin 命令行工具，且 README 注明 API 仍在开发中、可能变更。

  • 同时提供 REST、gRPC 与 gRPC-Web 三种 API，gRPC-Web 可经 Envoy 代理对外访问
  • 通过 Gorm 支持 mysql、postgres、sqlserver、sqlite 数据库
  • 基于 goth 支持外部 OAuth 登录，并通过 gadmin 命令行工具生成注册码等管理操作

适用场景（解读层）

  • 为应用自建用户注册、登录与 JWT 令牌签发服务
  • 微服务间通过内部 gRPC 接口进行认证相关的管理通信
  • 通过环境变量或 .env/.json/.yaml 配置文件部署，并搭配 MySQL/PostgreSQL 等数据库使用
📖 README 首段存档原文 · 程序抽取

Gothic is a user registration and authentication microservice written in Go. It's based on OAuth2 and JWT and will handle user signup, authentication and custom user data.
