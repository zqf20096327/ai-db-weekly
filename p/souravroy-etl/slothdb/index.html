C++20 编写的嵌入式实验性 SQL 引擎，进程内直接用 SQL 查询多种文件格式

综述（解读层）

SlothDB 是一个用 C++20 从零编写的嵌入式 SQL 数据库，处于早期实验阶段，无服务进程、无导入步骤，直接对 Parquet、CSV、JSON、Arrow、Avro、SQLite、Excel 文件执行 SQL。面向需要在应用内做文件查询的开发者，提供 Python、Node/WASM、CLI 三种使用方式，并内置 .ask 自然语言转 SQL 子命令，模型本地运行。

  • 支持直接以 SQL 查询 Parquet、CSV、JSON、Arrow、Avro、SQLite、Excel 文件，进程内运行，无需建表或导入
  • 提供 Python（pip 安装）、Node/WASM（npm 包）、浏览器 Playground 和命令行 shell 多种运行方式
  • 内置 .ask 自然语言子命令：规则解析器处理常见问题，可选本地 Qwen2.5-Coder 模型（0.5B/1.5B）回退，支持 29 种语言，SQL 生成后先展示再执行

适用场景（解读层）

  • 在 Python 或 Node 应用中直接对本地 Parquet/CSV 文件执行分析查询并取回 DataFrame
  • 通过 WASM 在浏览器或边缘环境（Cloudflare Workers）中运行 SQL 查询
  • 用 CREATE LIVE VIEW 对持续增长的 CSV 日志文件做增量查询
