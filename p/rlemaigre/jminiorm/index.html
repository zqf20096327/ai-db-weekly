面向 Java 的轻量级微型 ORM 与数据库工具库，基于 JPA 注解实现映射。

综述（解读层）

JMiniORM 是一个 Java 语言的微型 ORM 与数据库工具库，约 100 KB 且无外部依赖。它通过标准 JPA 注解子集实现对象关系映射、CRUD 操作和 SQL 建表语句生成，支持事务、JDBC 批处理模式，并通过 ISQLDialect 等接口提供可插拔扩展点。适合希望在 Java 项目中以较少配置完成数据库访问的开发者；注意其仅部分支持 JPA 2.1 注解子集。

  • 使用标准 JPA 2.1 注解子集（Table、Column、Id、Convert 等）进行 ORM 映射与建表
  • 提供 CRUD、事务、JDBC 批处理模式与任意 SQL 语句执行，泛型查询结果支持 Map/原始类型等自定义返回类型
  • 核心组件（SQL 方言、映射提供者、类型映射器、语句执行器）均可插拔替换；内置基于 Jackson 的 JSON 属性转换器

适用场景（解读层）

  • Java 项目中对注解类进行 CRUD 操作与自动生成建表语句
  • 需要执行多表连接或无实体映射的 SELECT 查询，并以 Map 或指定类型获取结果
  • 通过 JSON 转换器将复杂对象结构存入单个文本列，或启用批处理模式进行批量插入/更新
📖 README 首段存档原文 · 程序抽取

JMiniORM is a lightweight ORM and database utility for the Java language. It has no dependencies, its footprint is small (~100 KB), it is extensible and it is very easy to learn.
