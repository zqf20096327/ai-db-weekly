基于 Spring Boot 的 32 个土耳其语示例项目合集

综述（解读层）

该仓库包含 32 个小型示例项目，每个项目演示一个特定概念或技术，覆盖 REST API、JPA/Hibernate、Spring Security、JSP/Thymeleaf 视图、H2/PostgreSQL/MongoDB 数据库以及 RabbitMQ 等。多数示例使用 PostgreSQL 并通过 application.properties 配置端口与建表策略，部分项目附 JUnit 测试和演示视频。适合希望按主题逐个查看可运行 Spring Boot 示例代码的读者。

  • 包含 32 个独立示例项目，每个项目演示一个特定功能或集成点
  • 覆盖 REST API、JPA/Hibernate 映射、Spring Security、RabbitMQ、MongoDB、JSP 与 Thymeleaf 等技术
  • 提供端口配置（server.port）与 JPA 建表策略（ddl-auto）的通用配置说明，部分项目含 JUnit 测试与访问链接

适用场景（解读层）

  • 按主题查阅特定 Spring Boot 功能（如 @OneToMany 映射、角色授权、自定义错误页）的可运行示例
  • 搭建 Spring Boot 学习或演示环境时参考各项目的配置与访问端点
  • 参考 H2 与 PostgreSQL 下的 schema.sql/data.sql 数据初始化写法
