基于 Quarkus 的 Java 项目脚手架，提供 RESTful API 与构建、测试、部署脚本。

综述（解读层）

该项目由 code.quarkus.io 生成，为 Quarkus Java 项目提供基础模板，包含按 entity、dto、repository、service 等包划分的目录结构与 Gradle 任务集。数据层使用 PostgreSQL 并通过 Flyway 管理迁移，认证采用 JWT，内置 Swagger UI。运行需 Java 11、GraalVM、Node.js、Docker 和 Ansible。适合需要统一团队项目结构的 Java 开发者参考使用。

  • 提供 gradle 任务自动化开发、测试、lint、迁移、镜像构建和部署流程，集成 Checkstyle、PMD、SpotBugs、SonarQube 静态分析
  • 支持 Flyway 数据库迁移、Lombok 生成 JPA 实体，可选用 jOOQ 生成类型安全查询
  • 测试分单元/功能/冒烟三层，JUnit 5 配合 Mockito 和 REST Assured，JaCoCo 最低覆盖率设为 80%

适用场景（解读层）

  • 团队协作 Java 项目需要统一目录规范和命名约定时，以此脚手架初始化 Quarkus 工程
  • 需要完整 CI/CD 流水线示例（Docker 镜像构建、Docker Swarm 部署）的项目
  • 需要数据库迁移、OpenAPI 文档、JWT 认证与国际化配置开箱即用的后端服务开发
