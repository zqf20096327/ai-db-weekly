🧭 简介解读层（AI·证据行可回查）

基于 Rust 与 Tokio 的流处理引擎，通过 YAML 配置输入-处理-输出管道并集成 AI 推理能力。

综述（解读层）

ArkFlow 是一个用 Rust 编写的流处理引擎，通过 YAML 文件声明式地组合输入源、处理器与输出目标。它内置 SQL 查询、Python UDF、VRL 等处理器，并集成 LLM、embedding 与向量检索组件。项目已收录进 CNCF Cloud Native Landscape，采用 Apache 2.0 协议，支持 Docker 镜像或源码编译运行。

  • 提供 Kafka、MQTT、HTTP、文件、SQL 数据库、NATS、Pulsar、Redis、WebSocket、Modbus 等多种输入源，以及 Kafka、InfluxDB、MongoDB、Qdrant、Milvus、pgvector 等多种输出目标
  • 内置 SQL、Python UDF、JSON/Protobuf 编解码、VRL 处理器，以及调用 OpenAI 兼容 API 的 LLM、embedding 处理器和 Qdrant/Milvus/pgvector 向量检索处理器
  • 支持基于 WAL 的 at-least-once 投递，提供滚动窗口、会话窗口等缓冲组件，并允许通过 error_output 接收处理失败的消息

适用场景（解读层）

  • 从 Kafka/MQTT 等消息源读取数据，经 SQL 或 Python UDF 处理后写入数据库或消息系统
  • 对流数据调用 LLM/embedding 并结合向量数据库进行相似检索或异常检测
  • 通过 generate 输入源生成测试数据，用于验证流处理管道配置
