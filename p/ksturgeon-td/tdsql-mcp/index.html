面向 Teradata Vantage 的 MCP 服务器，提供 SQL 执行与内置函数语法参考库。

综述（解读层）

tdsql-mcp 是一个 MCP 服务器，连接 Teradata Vantage 数据库，供 AI 代理执行 SQL 并查询其内置分析函数的语法参考。通过 get_syntax_help 工具和 teradata://syntax/{topic} 资源，提供覆盖数据准备、机器学习、文本分析、向量搜索、UAF 时间序列、地理空间等领域的参考文档，并以 guidelines/index 分层结构引导代理选择原生函数。适用于已在 Teradata 平台上构建代理式分析流程的团队。

  • 提供 get_syntax_help 工具与 teradata://syntax/{topic} 资源，覆盖数据探索、清洗、机器学习、文本分析、向量搜索、统计检验、BYOM、UAF 时间序列、地理空间等领域的 Teradata 原生函数参考
  • 包含 guidelines、index、专题文档三层参考库结构，将 50+ 常见分析操作映射到对应的原生函数
  • 提供 CTE 预测管道模式文档：预处理与打分在单条 SQL 内完成，FitTable 与模型表训练时构建并可复用

适用场景（解读层）

  • 让 AI 代理在 Teradata Vantage 上执行库内分析（训练/预测、向量检索、时间序列），不将原始数据拉取到客户端
  • 为代理生成机器学习打分 SQL 管道，随后提升为视图、存储过程或定时作业运行
  • 查询 TD_*、AI_*、UAF 及 BYOM 函数的语法与用法参考
