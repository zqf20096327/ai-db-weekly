面向图数据库的 ORM，使用 JSON 风格查询语言 BQL

综述（解读层）

Blitz-orm 是一个用于图数据库的 ORM，通过名为 BQL 的 JSON 查询语言构建查询。面向 JavaScript/TypeScript 开发者，通过 yarn 安装后定义 Borm schema 并初始化客户端即可执行查询与变更。当前兼容 TypeDB 与 SurrealDB，但 borm.define() 尚未实现，需手动将 BQL schema 翻译为 TypeQL schema，且项目处于 alpha 阶段，不适用于生产环境。

  • 支持 TypeDB 与 SurrealDB 两种数据库，查询功能已稳定
  • BQL 查询语言以 JSON 构建动态查询，类似 GraphQL
  • 提供基于 Borm schema 结构生成 TypeScript 类型的 typeGen 功能

适用场景（解读层）

  • 在 TypeDB 或 SurrealDB 上执行图数据的查询与变更
  • 与 next-auth (Auth.js) 集成的认证数据访问场景
  • 需要跨多个数据库执行基础查询并自动路由的场景
