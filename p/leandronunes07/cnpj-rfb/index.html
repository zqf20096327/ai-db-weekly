Go 编写的巴西联邦税务局 CNPJ 开放数据 ETL 引擎，含 REST API 与仪表盘

综述（解读层）

该工具用于从巴西联邦税务局（Receita Federal）下载并导入 CNPJ/Simples Nacional 公开数据。流程为：按月度（YYYY-MM）识别最新数据、并行下载未处理文件、以流式方式解压并转换编码（ISO-8859-1 转 UTF-8）、分批写入数据库。支持 PostgreSQL、MySQL、SQLite、ClickHouse 四种后端，通过环境变量切换；提供带 Token 认证的 REST API 与内嵌 Web 仪表盘，支持 --once 单次运行或 cron 定时模式。运行需配置 API_TOKEN 与 DB_PASSWORD，Redis 与 Meilisearch 为可选组件。

  • 并行下载与流式解压：每个 worker 下载后即解压导入，zip/CSV 逐行处理，支持 DOWNLOAD_WORKERS 配置
  • 多数据库支持：PostgreSQL、MySQL（含 LOAD DATA LOCAL INFILE）、SQLite、ClickHouse，经 DB_DRIVER 环境变量切换
  • 内置 REST API 与 Web 仪表盘（go:embed 编译进单一二进制），支持按 CNPJ 查询、按企业名/UF 搜索；可选 Redis 分布式锁与限流、Meilisearch 搜索

适用场景（解读层）

  • 需要将巴西 CNPJ 公开数据持续导入自有数据库（支持 PostgreSQL、MySQL、SQLite、ClickHouse），并定期同步月度更新
  • 需要通过 REST API 按 CNPJ 或企业名称查询巴西企业注册信息（注册状态、地址、CNAE、Simples Nacional/MEI 选项等）
  • 希望以 Docker 或单二进制方式自动定时运行 ETL 流程，且具备幂等增量导入与可选的 Redis 分布式锁/Meilisearch 搜索扩展能力
