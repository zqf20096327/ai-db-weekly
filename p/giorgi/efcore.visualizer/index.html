🧭 简介解读层（AI·证据行可回查）

在 Visual Studio、VS Code 与 Rider 调试时查看 EF Core 查询执行计划的调试器可视化工具

综述（解读层）

这是一个 EF Core 查询计划调试器可视化扩展，安装后在 Visual Studio、VS Code 或 JetBrains Rider 中调试时，可将鼠标悬停在查询变量上直接查看执行计划。支持 SQL Server、PostgreSQL、SQLite、MySQL、Oracle 五种数据库，要求 EF Core 7 及以上；Visual Studio 需 2022 17.14+，VS Code 需 1.90+，Rider 需 2026.2+。查看的是实际执行计划，会强制执行查询；VS Code 版本还提供复制含参数 SQL 的功能，并存在查询计划提取超时 5 秒等已知限制。

  • 在 Visual Studio、VS Code 和 Rider 中调试时悬停或点击查询变量即可查看查询计划，包含 Actual IO 统计、Outline 数据、投影与谓词等页面
  • 支持 SQL Server、PostgreSQL、SQLite、MySQL、Oracle 五种数据库，要求 EF Core 7 或更新版本
  • VS Code 版提供 Refresh 与 Copy SQL（复制含参数的 SQL）按钮；Rider 版为每个变量单独开标签页并可在查询变化后重新查看新计划

适用场景（解读层）

  • 调试 EF Core 应用时需查看某条 LINQ 查询对应数据库执行计划的场景
  • 需要在多数据库（SQL Server、PostgreSQL、SQLite、MySQL、Oracle）环境下分析查询计划的 EF Core 7+ 项目
  • 在 Visual Studio、VS Code 或 Rider 中进行 C# 调试并希望直接从 Variables/Watch 窗口查看查询计划的开发流程
