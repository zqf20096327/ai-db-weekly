🧭 简介解读层（AI·证据行可回查）

自托管 VPS 监控系统，Rust 单二进制服务端加轻量 Agent 经 WebSocket 上报指标。

综述（解读层）

ServerBee 是一个由 Rust 服务端、轻量 Agent 与 React 实时仪表盘组成的自托管服务器监控工具：Agent 通过 WebSocket 向中心服务端上报 CPU、内存、磁盘、网络等指标，存入内嵌 SQLite，无需外部数据库。适合管理多台 VPS 的运维人员。通过安装脚本部署服务端（Docker 或原生二进制），管理员生成一次性注册码后在各节点安装 Agent。配置支持 TOML 或 SERVERBEE_ 前缀环境变量。项目处于 v1.0.0-alpha.12 的活跃开发阶段。

  • Agent 冷启动约 4.3 MB、稳态约 27 MB；服务端为单二进制，内嵌 Web UI 与 SQLite 存储
  • 支持实时监控 CPU/内存/磁盘/网络/负载/温度/磁盘 I/O，可选自建 NVIDIA GPU 采集（需 --features gpu 编译）
  • 包含告警通知、Web 终端、文件管理器、Docker 统计、防火墙、状态页等功能，并提供 OAuth + 2FA、RBAC、审计日志与一次性 Agent 注册机制

适用场景（解读层）

  • 集中监控多台 VPS 的实时资源指标与历史图表（1 小时到 30 天）
  • 网络质量探测：Ping 监控（ICMP/TCP/HTTP）、运营商预设探测、SSL/DNS/WHOIS 等服务监控
  • 通过浏览器终端和沙箱文件管理器对远程主机进行日常运维管理
