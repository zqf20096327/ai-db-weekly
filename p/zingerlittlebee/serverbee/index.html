🧭 简介解读层（AI·证据行可回查）

自托管 VPS 监控：Rust agent 上报指标，中心服务器用 SQLite 存储并提供 React 实时仪表盘

综述（解读层）

ServerBee 是一套自托管服务器监控系统，由轻量 Rust agent、中心 server 和嵌入式 React 仪表盘组成，agent 通过 WebSocket 上报 CPU、内存、磁盘、网络等指标，数据存于内嵌 SQLite，无需外部数据库。适用于需要集中管理多台 VPS 的运维场景。注意项目处于 v1.0.0-alpha 阶段，GPU 指标需自行编译，预构建二进制不包含。

  • agent 冷启动约 4.3 MB、稳态约 27 MB；server 与 Web UI 打包为单一二进制，支持 Docker、脚本或 Railway 部署
  • 通过 WebSocket 实时展示 CPU/内存/磁盘/网络/负载/温度/磁盘 I/O，可编译启用 NVIDIA GPU 指标；历史图表覆盖 1 小时至 30 天
  • 包含 Web 终端、文件管理器、Docker 统计、告警通知（Webhook/Telegram/邮件等 14+ 指标类型）、OAuth+2FA、RBAC 与审计日志

适用场景（解读层）

  • 集中监控多台 VPS 或服务器节点的实时资源指标与网络质量
  • 需要自托管、不依赖外部数据库的轻量监控部署（Docker、原生二进制或 Railway）
  • 通过浏览器进行远程运维：Web 终端、文件管理、防火墙屏蔽与 Docker 容器查看
