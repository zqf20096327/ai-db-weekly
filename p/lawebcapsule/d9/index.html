Directus 9 的 GPLv3 开源分支，在 SQL 数据库上提供 API 与数据studio

综述（解读层）

d9 是 La Webcapsule 独立维护的 Directus 9 开源分支（GPLv3），与 Directus 10+ 的 premium 模式无关，也不隶属于 Directus 官方团队。它基于 Node.js 为 SQL 数据库提供 REST 和 GraphQL API，并配有 Vue.js 数据管理面板。与 Directus 9 使用相同数据库结构，迁移时仅需替换依赖包名并更新 import，无需数据库迁移；兼容原有 Directus 9 扩展。

  • 支持 PostgreSQL、MySQL、SQLite、OracleDB、CockroachDB、MariaDB、MS-SQL 多种数据库，可直接使用现有 SQL 数据库
  • 提供 REST 与 GraphQL API、Vue.js 数据面板（Data Studio），支持自托管与模块化扩展
  • 提供 @wbce/projen-d9 模板（Apache 2.0）及 d9-plumbing CLI，可将角色、权限（转写为 Cedar 策略）、flows、设置等配置保存到仓库并在环境间应用

适用场景（解读层）

  • 需要将现有 Directus 9 项目迁移到持续开源维护版本的场景
  • 在已有 SQL 数据库上搭建 API 与可视化管理界面的后端服务
  • 需要在多环境间以代码方式管理数据库配置与权限的团队工作流
