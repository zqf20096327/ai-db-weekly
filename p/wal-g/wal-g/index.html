云环境下多数据库的备份归档与恢复工具

综述（解读层）

WAL-G 是用 Go 编写的归档与恢复工具，面向 PostgreSQL、MySQL/MariaDB、MS SQL Server（MongoDB、Redis 为 beta），将备份存储到云端。它提供 lz4/lzma/zstd/brotli 压缩、libsodium 与 PGP 加密、statsd 监控指标和网络限速；通过环境变量或 viper 支持的 JSON/YAML 等配置文件进行配置，提供 backup-list、delete（含 retain/before/target 模式）等命令，二进制按数据库和操作系统分别发布。

  • 支持 PostgreSQL、MySQL/MariaDB、MS SQL Server，MongoDB 和 Redis 处于 beta 阶段，备份可存至 AWS S3、Azure 等云存储
  • 提供 lz4、lzma、zstd、brotli 或不压缩多种压缩方式，支持 libsodium、PGP 及基于 Yandex Cloud KMS 的信封加密
  • 配置支持环境变量与 JSON/YAML 等 config 文件，内置 statsd 指标上报、pprof 性能分析与网络速率限制

适用场景（解读层）

  • 需要对 PostgreSQL、MySQL 等数据库的备份与 WAL 进行云端归档存储的场景
  • 需要对备份数据进行压缩与客户端加密的运维环境
  • 需要通过 statsd 监控备份任务指标、控制备份网络带宽的生产环境
