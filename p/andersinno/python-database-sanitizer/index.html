对 PostgreSQL/MySQL 数据库转储执行脱敏的 Python 命令行工具

综述（解读层）

database-sanitizer 通过数据库 URL 从关系数据库获取转储文件，并按 YAML 配置文件中定义的规则对数据执行脱敏，支持 PostgreSQL 和 MySQL。使用者可在配置中为指定表、列映射脱敏函数，函数名对应 Python 模块中的 sanitize_ 前缀函数，也可通过 addon 包扩展自定义函数，或用 skip_rows 策略移除整表数据。需通过 pip 安装，MySQL 需附加额外依赖。

  • 支持 PostgreSQL 与 MySQL 两种数据库的转储脱敏
  • 通过 YAML 配置文件按表/列映射脱敏函数，函数可实现于内置 sanitizers 包或 addon Python 包
  • 支持 skip_rows 策略移除表的 INSERT INTO/COPY 数据语句但保留 CREATE TABLE 语句

适用场景（解读层）

  • 将含敏感数据的数据库转储脱敏后用于开发或测试环境
  • 需要按自定义规则处理特定表列脱敏的团队
  • 需要导出仅含表结构、不含数据的转储文件
