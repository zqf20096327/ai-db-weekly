🧭 简介解读层（AI·证据行可回查）

基础设施统一访问层：身份感知代理加短时效证书认证与审计

综述（解读层）

Teleport 是用 Go 编写的基础设施访问工具，提供连接、认证、访问控制与审计，覆盖 SSH、Kubernetes、数据库、RDP、Web 应用等协议。核心机制包括身份感知代理、签发自动过期短证书的 CA、隧道穿透 NAT/防火墙，以及 RBAC/ABAC 控制与 JIT 提权。可作为 Linux 守护进程或 Kubernetes 部署运行，采用 AGPL 许可。

  • 单二进制集成 SSH、Kubernetes、PostgreSQL/MongoDB/MySQL 等数据库、Windows 主机与内部 Web 应用
  • 基于证书的认证，支持 SSO（GitHub/OIDC/SAML）与全协议 MFA
  • 记录并审计 SSH、Kubernetes、数据库、RDP 与 Web 会话

适用场景（解读层）

  • 为云上与本地基础设施统一配置单点登录与访问控制
  • 在不使用 VPN 或堡垒机的情况下访问 NAT 与防火墙后的资源
  • 对多协议会话进行录制与审计，实施最小权限与 JIT 临时提权
