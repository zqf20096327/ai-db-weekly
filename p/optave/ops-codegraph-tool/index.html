🧭 简介解读层（AI·证据行可回查）

本地运行的代码智能 CLI，构建函数级依赖图并提供 34 个 MCP 工具

综述（解读层）

codegraph 是一个基于 tree-sitter 解析、SQLite 存储的代码智能 CLI，为代码库建立函数级依赖图，支持增量重建。它通过 44 个 CLI 命令、MCP 服务器和可嵌入的 npm 库三种方式暴露图数据，供开发者和 AI 代理查询调用关系、复杂度指标与架构边界规则。工具完全本地运行，无需 API key，不发起网络调用。

  • 使用 tree-sitter 解析 34 种语言，将函数级依赖图存储于 SQLite，支持增量重建
  • 提供 34 个工具的 MCP 服务器、44 个 CLI 命令和 npm 可嵌入 API
  • 包含复杂度指标（认知、圈复杂度、Halstead、MI）、架构边界检查、git diff 影响与 co-change 分析、BM25 + 语义混合搜索、角色分类（entry/core/utility/adapter/dead/leaf）

适用场景（解读层）

  • AI 代理通过 MCP 服务器查询函数调用者、依赖和上下文，获取代码库结构信息
  • 在 CI 流水线中通过 check 命令以退出码执行复杂度阈值与架构边界规则
  • 开发者用 fn-impact、diff-impact、context 等命令从终端查询函数影响范围与调用关系
