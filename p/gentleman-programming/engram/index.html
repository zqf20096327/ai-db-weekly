🧭 简介解读层（AI·证据行可回查）

面向 AI 编码代理的持久化记忆系统，单 Go 二进制加 SQLite 实现

综述（解读层）

Engram 用单个 Go 二进制为 AI 编码代理提供跨会话的持久化记忆，数据存于本地 SQLite（FTS5 全文检索），默认目录 ~/.engram。通过 MCP、HTTP API、CLI 和 TUI 四种方式访问，官方提供 14 种代理的一键 setup 命令，无需 Node.js、Python 或 Docker。记忆按项目隔离，支持 Git Sync 导出与可选的 Engram Cloud 复制。

  • 单个 Go 二进制，本地 SQLite + FTS5 全文检索，无 Node.js/Python/Docker 依赖
  • 提供 MCP、HTTP API、CLI、TUI 四种访问方式，支持 14 个代理的 setup 命令
  • 记忆默认本地存储、按项目隔离，支持 Git Sync 导出与可选 Cloud 复制

适用场景（解读层）

  • 为 Claude Code、Cursor 等 MCP 兼容代理添加跨会话记忆
  • 在终端浏览和检索代理保存的记忆（engram tui）
  • 通过 Git Sync 或 Cloud 在多台机器间共享项目记忆
