🧭 简介解读层（AI·证据行可回查）

基于 SQLite+FTS5 的 AI 编码代理持久化记忆系统，单 Go 二进制

综述（解读层）

Engram 为 AI 编码代理提供跨会话的持久化记忆存储，数据默认保存在 ~/.engram 下的 SQLite 数据库中。它通过 MCP stdio、HTTP API、CLI 和 TUI 四种方式访问，支持 14 个代理的 setup 命令及任意 MCP 兼容代理。核心机制包括 FTS5 全文检索、项目感知读取（按 ENGRAM_PROJECT 或 cwd 解析）以及冲突记忆标记。依赖方面无需 Node.js、Python 或 Docker；Git Sync 可导出压缩块跨机器共享，Cloud 复制为可选功能。

  • 单 Go 二进制内置 SQLite+FTS5 全文检索，通过 CLI、HTTP API、MCP 和 TUI 暴露
  • 提供 engram setup 子命令，为 Claude Code、Cursor、VS Code 等 14 个代理写入 MCP 配置
  • 默认本地存储于 ~/.engram，支持 Git Sync 导出与可选的按项目 Cloud 复制

适用场景（解读层）

  • 让编码代理在会话结束后保留项目记忆，避免重复解释项目背景
  • 用 engram tui 浏览、检索代理保存的观察记录
  • 多机器间通过 Git Sync 或 Cloud 共享同一份代理记忆
