🧭 简介解读层（AI·证据行可回查）

批量生成/导出 Gemini 公开分享链接，并导入本地 SQLite 进行检索的工具集

综述（解读层）

项目由三部分组成：Tampermonkey 脚本在 Gemini 页面批量生成分享链接并从 /sharing 导出 JSON/CSV；Python CLI 或 Tauri v2 + React 桌面端将导出文件增量导入 SQLite（按 url 去重）；支持 FTS5/BM25 全文检索、拼写容错、同义词扩展及可选语义检索，并提供标签/备注/收藏/批量打开。适合维护多个 Gemini 账号、需要统一管理与找回历史对话链接的用户。README 注明链接有效期依赖 Apps Activity 保留策略，且 UI 自动化在页面结构变化时可能失效。

  • Tampermonkey 脚本批量生成分享链接，从 /sharing 自动滚动加载并导出 JSON/CSV（含账号标签、标题、url、时间等字段）
  • 桌面端（Tauri v2 + React）与 Python CLI 两种导入方式，支持多库管理、增量更新与按 url 去重
  • 本地检索实现 FTS5/BM25 关键词搜索、拼写容错与同义词扩展，语义检索为可选功能

适用场景（解读层）

  • 多 Gemini 账号的对话链接统一导出与跨账号检索
  • 将历史对话链接沉淀为可打标签、收藏、批注的本地资料库
  • 跨设备通过导入同一份 JSON/CSV 恢复链接库
