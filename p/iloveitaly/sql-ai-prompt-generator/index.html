🧭 简介解读层（AI·证据行可回查）

连接 Postgres/sqlite 数据库，生成用于 LLM 编写 SQL 的提示词的 CLI 工具

综述（解读层）

该工具是一个 Python CLI（pip 安装 llm-sql-prompt），接收数据库 URL 和表名，生成可复制粘贴给 ChatGPT 等 LLM 的 SQL 编写提示词。提示词包含表结构快照、以 INSERT 语句形式呈现的示例行，以及表/字段注释。支持 Postgres 和 sqlite，可用 --all 处理多表。README 自述脚本较为基础，提示词尺寸限制等仍在待办中。

  • 读取 Postgres 和 sqlite 数据库，提取表结构、示例数据（INSERT 语句）及表/字段注释并生成提示词
  • 提供 CLI 入口 llm-sql-prompt [OPTIONS] DATABASE_URL [TABLE_NAME]，支持 --all 生成多表提示词
  • 安装方式为 pip install llm-sql-prompt；本地开发需 uv、just、zsh、jq

适用场景（解读层）

  • 为 LLM（如 ChatGPT）准备包含表结构与示例数据的 SQL 编写提示词
  • 快速将数据库表结构快照粘贴给他人或工具参考
  • 通过 SSH 隧道连接远程生产库并生成对应表结构的提示词
