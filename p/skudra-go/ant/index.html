🧭 简介解读层（AI·证据行可回查）

基于 Go 泛型的类型安全 ORM，用字段指针替代字符串编写查询

综述（解读层）

ant 是一个使用 Go 泛型实现的 ORM，供 Go 开发者在编译期检查查询中的列名、值类型和关联，无需代码生成步骤。README 注明其要求 Go 1.27 及以上，支持 PostgreSQL、MySQL、MariaDB、SQLite、SQL Server，其中迁移功能目前仅支持 PostgreSQL，且项目处于 1.0 之前的阶段，API 可能变更。安装通过 go get 完成，附带 vet 分析器、变更追踪（含 NoTracking 模式）及 anttest 测试工具。

  • 使用字段指针（如 ant.Gt(&Users.Age, 18)）编写查询条件，编译器检查列与值类型，无需代码生成
  • 支持类型化条件、连接、投影、聚合、子查询、CTE、窗口函数，以及 1:1/1:N/多对多关系的显式 Include 批量加载
  • 提供变更追踪与 SaveChanges（只写变更列）、事务（savepoint、隔离级别、重试、读副本）、软删除、乐观并发控制等特性，并附 go vet 分析器与 OpenTelemetry 支持

适用场景（解读层）

  • 希望在 Go 项目中以编译期检查替代字符串列名的数据库读写
  • 使用 PostgreSQL 且需要从结构体生成迁移 SQL 并做漂移检查的场景
  • 为 AI 编程助手配置 ORM 技能文档后进行 Go 数据库开发的团队
