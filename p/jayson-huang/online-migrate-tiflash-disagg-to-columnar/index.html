TiFlash 分离架构在线迁移到 tikv-worker columnar 的测试计划与 tiup 拓扑生成工具

综述（解读层）

该仓库包含一套测试计划文档与工具脚本，用于在持续 CH-benCHmark 负载下把 next-gen tiflash-write+tiflash-compute 集群在线迁移到 tikv-worker columnar（Write Node 下线、Compute Node 读 S3 上的 .col 文件）。提供 gen_tiflash_cluster_topo.py 生成 tiup topology YAML，以及 recon_snapshot.py 在固定 tidb_snapshot 下做 tikv 与 tiflash 聚合对账，一轮失败即非 0 退出。文档含分阶段测试计划、门禁条件和回滚用例。脚本默认参数对应特定实验室环境，需用命令行参数覆盖。

  • gen_tiflash_cluster_topo.py 生成起始态（CN+WN disagg）与最终态（纯 columnar、无 WN）的 tiup topology YAML，支持 --cn-count/--wn-count/--cn-mode/--dfs-prefix 等参数
  • scripts/recon_snapshot.py 连接 ks1、钉住 TSO 后运行固定聚合对账，支持 -k 轮数、--no-side、--no-smoke，依赖本机 mysqlclient
  • handoff.md 与 online-migrate-tiflash-write-to-columnar-test.md 记录进度、约束、阶段、门禁与环境参数，含 rollback_read_path 独立回滚用例

适用场景（解读层）

  • 在持续 TP+AP 负载下验证 TiFlash 分离式集群向 tikv-worker columnar 的在线迁移流程
  • 生成与部署 next-gen TiFlash classic CN 或 columnar CN 拓扑的 tiup 集群
  • 迁移各阶段（双重物化、切换 CN 读路径、删除 placement-rule 前）的数据一致性对账校验
