开源不可变 SQL 数据库，内置完整时间旅行与双时态版本管理

综述（解读层）

XTDB 是由 JUXT 开发的开源不可变 SQL 数据库，面向应用开发、时间旅行报表与数据合规场景。数据插入后不覆盖历史，可随时审计任意时点状态；同时记录系统时间与业务有效时间双轴版本。基于 Apache Arrow 列式引擎、面向对象存储设计，通过 Postgres 线协议提供 SQL 与 XTQL 查询，采用 MPL 2.0 许可证。

  • 不可变存储：无需快照或备份即可查询数据库任意历史时点的状态
  • 双时态模型：按 SQL:2011 标准同时记录系统时间与业务有效时间两个时间轴
  • 支持 SQL 与 XTQL 两种查询语言，通过 Postgres 线协议访问；文档数据可任意嵌套且无需预先定义模式

适用场景（解读层）

  • 需要审计与追溯数据完整历史的应用开发
  • 基于任意历史时点或业务有效时间的时间旅行报表
  • 满足数据合规与版本留痕要求的场景
