Watermill 消息发布/订阅组件的基准测试工具集

综述（解读层）

该项目为 Watermill 的 Pub/Sub 组件提供基准测试工具，在单个 16 核 GCloud 实例上通过 Docker Compose 部署基础设施，先向生成的 topic 大量发布消息再订阅消费，支持 Kafka、NATS、Redis、SQL、RabbitMQ、Google Cloud Pub/Sub、GoChannel 等后端，可测 16/64/256 字节三种消息尺寸。README 明确说明结果仅为粗略估算，不构成对各后端性能的定论。

  • 支持对 Kafka、NATS Jetstream、Redis、MySQL、PostgreSQL、RabbitMQ、Google Cloud Pub/Sub、GoChannel 等 Pub/Sub 运行发布与订阅吞吐测试
  • 附带 Terraform 定义，用于在 GCP 上创建 Ubuntu 实例、安装 Docker 并克隆仓库，测试后可用 terraform destroy 销毁
  • 通过 ./run.sh 运行测试，消息大小默认可选 16、64、256 字节

适用场景（解读层）

  • 估算 Watermill 各 Pub/Sub 实现的消息处理吞吐量量级
  • 在自建环境中复现测试流程并采集自己的数据
  • 为选定 Watermill 后端时提供参考数据点
