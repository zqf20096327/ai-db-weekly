Java 编写的对象关系映射框架，支持编译期检查查询与双时态数据管理。

综述（解读层）

Reladomo 是面向 Java 的 ORM 框架，用于以对象方式建模和操作数据库数据。类与关系通过 XML 文件定义，提供强类型查询语言、双时态链、多 schema 透明支持和可单元测试的测试资源机制。可通过 Maven Central 获取，仓库附带 Maven/Gradle 示例项目及教程、FAQ、架构等文档。

  • 提供编译期检查的强类型查询语言，支持按对象图遍历、查询与更新
  • 支持双时态（业务日期与处理日期）数据管理，可用于记录变更审计历史并回答 as-of 查询
  • 支持多数据库（Sybase、DB2、Oracle、Postgres、MS-SQL、H2、Derby 等）、透明多 schema、可调缓存与 MTLoader 批量合并

适用场景（解读层）

  • 需要在 Java 应用中以面向对象方式读写关系数据库数据的场景
  • 需要维护数据变更历史、按业务/处理日期查询历史版本的系统
  • 交互式 Web 应用或批处理程序；GUI 编辑场景可使用 detached 对象离线修改后再推送
