PostgreSQL 的 EF Core 提供程序，构建于 Npgsql 之上，支持 LINQ 查询

综述（解读层）

Npgsql.EntityFrameworkCore.PostgreSQL 是开源的 PostgreSQL EF Core 提供程序，供 .NET 开发者通过 Microsoft 的 EF Core O/RM 和 LINQ 语法访问 PostgreSQL。除常规 EF Core 支持外，它还提供查询 JSON、数组、范围列等 PostgreSQL 特有能力，底层依赖 Npgsql ADO.NET 提供程序，另有 NetTopologySuite（PostGIS）与 NodaTime 插件包。

  • 基于 Npgsql 构建，支持通过 LINQ 语法表达 PostgreSQL 查询
  • 提供 PostgreSQL 特有能力，支持查询 JSON、数组及范围列
  • 提供 NetTopologySuite（PostGIS 空间数据）与 NodaTime（日期/时间类型）相关插件包

适用场景（解读层）

  • 在 .NET 项目中使用 EF Core 访问 PostgreSQL 数据库
  • 需要在 LINQ 查询中操作 JSON、数组或范围类型的列
  • 需要配合 PostGIS 处理空间数据或使用 NodaTime 日期时间类型
