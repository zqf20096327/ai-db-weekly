PostgreSQL 的 .NET 数据提供程序，用于在 .NET 中连接 PostgreSQL。

综述（解读层）

Npgsql 是开源的 .NET 数据提供程序，让开发者通过 .NET 连接和操作 PostgreSQL 服务器。提供连接字符串方式建立连接，配套 EF Core 提供程序（Npgsql.EntityFrameworkCore.PostgreSQL），完整文档发布在其官网。适用于使用 .NET 技术栈访问 PostgreSQL 的应用开发。

  • 支持大多数 PostgreSQL 类型，包括数组、枚举、范围、多范围、复合类型、JSON、PostGIS 等
  • 提供批量导入/导出 API，支持故障转移、负载均衡等多主机场景
  • 通过 Npgsql.EntityFrameworkCore.PostgreSQL 与 Entity Framework Core 集成

适用场景（解读层）

  • .NET 应用程序连接并操作 PostgreSQL 数据库
  • 在 Entity Framework Core 项目中作为 PostgreSQL 底层数据提供程序
  • 需要批量数据导入导出或多主机部署的数据访问场景
