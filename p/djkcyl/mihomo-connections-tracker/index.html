🧭 简介解读层（AI·证据行可回查）

以主从架构采集 mihomo 连接数据并持久化到 SQLite 的监控工具。

综述（解读层）

该工具通过 WebSocket 连接 mihomo（Clash Meta 内核）API 采集连接信息，写入 SQLite。采用 Master/Agent 两级架构：Agent 部署在各 mihomo 节点旁，按同步间隔（默认 60 秒）向 Master 上传；Master 离线时 Agent 在本地缓存数据，恢复后批量补传。适用于需要集中留存多节点连接记录与统计查询的环境。

  • 支持一主多从架构，Agent 离线时本地缓存数据，Master 恢复后自动批量补传
  • Master 提供 HTTP 统计查询 API（/api/v1/stats），支持筛选、聚合与时间序列分析，可用 Bearer Token 认证
  • 基于 Rust 与 Tokio 异步模型实现，Agent 支持数据保留天数自动清理（默认 7 天）

适用场景（解读层）

  • 多台设备各自运行 mihomo，需将连接记录集中汇总到一个 Master 节点存储
  • 网络不稳定或无外网环境中采集连接数据，依赖 Agent 的离线缓存与自动恢复同步
  • 通过 Master 的统计 API 对连接数据做筛选、聚合和时间序列查询分析
📖 README 首段存档原文 · 程序抽取

此程序用于跟踪 Mihomo (Clash Meta 内核) 的连接信息，并将其存储在数据库中。支持主从架构，允许多个从节点（Agent）将数据同步到一个中央主节点（Master），同时支持离线操作。
