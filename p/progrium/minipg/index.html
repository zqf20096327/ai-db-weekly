🧭 简介解读层（AI·证据行可回查）

单可执行文件运行的 PostgreSQL，以 .pgdb 目录承载整个数据库

综述（解读层）

minipg 将 Docker Hub 的 postgres:18-alpine 镜像嵌入单个二进制，用 h9 虚拟化层直接在宿主机 hypervisor 上运行 Alpine 的 Postgres 二进制，无需安装 Linux 内核、VM 镜像或 Docker。数据库以 .pgdb 目录形式保存，适合本地开发与 CI 测试。README 注明项目处于早期，h9 是研究原型，不建议用于不可重建的数据。

  • 单二进制嵌入 postgres:18-alpine 镜像，支持 fetch 下载其他 Postgres 大版本并按 digest 缓存
  • .pgdb 目录包含数据、配置、凭据与版本信息，停止状态可整目录复制；运行中需用 pg_dump 备份
  • Linux 静态 musl 二进制无需特权即可在容器与 CI 中运行，无 /dev/kvm 时使用原生后端（需 Linux 5.11+）

适用场景（解读层）

  • 本地开发与测试：minipg run app.pgdb -- npm start 自动注入 DATABASE_URL
  • CI 测试：init + run 两步即可在 GitHub runner 上跑集成测试
  • 多版本 Postgres 需求：--pg 17 等按需下载对应 alpine 镜像根
📖 README 首段存档原文 · 程序抽取

PostgreSQL as a single executable. No install, no Docker, and a .pgdb folder that holds the whole database: minipg app.pgdb opens a shell on it.
