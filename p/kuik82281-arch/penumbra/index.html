🧭 简介解读层（AI·证据行可回查）

面向长期AI陪伴的本地记忆服务，整理并克制动召回对话记忆

综述（解读层）

Penumbra 是一个独立运行的本地 HTTP 记忆服务，供聊天程序（如 SillyTavern）接入长期陪伴场景。写入路径保存逐字原话，由 LLM 整理出可追溯的记忆（Episode/Pattern/Thread 三种结构），召回经入口闸、关键词+向量+实体融合与交叉编码器复判，每轮最多返回两条。支持 Docker 部署，SQLite 存储，AGPL-3.0 许可。

  • 原话只追加不修改，每条记忆可溯源并支持纠错与墓碑式删除
  • 三种记忆结构（Episode/Pattern/Thread），区分说话时间与事件发生时间
  • 召回链路包含入口闸、三路融合检索、冷却去重与交叉编码器复判，每轮最多两条

适用场景（解读层）

  • 长期 AI 陪伴类聊天应用的记忆后端
  • 自托管场景下配合 SillyTavern 等客户端使用
  • 需要逐字溯源与可纠错记忆的对话系统
📖 README 首段存档原文 · 程序抽取

Penumbra 是一个独立运行的本地 HTTP 服务。聊天程序把每一句原话交给它；它在后台把对话整理成可追溯的长期记忆， 并在下一轮对话时，只把真正相关的一两条交回去。
