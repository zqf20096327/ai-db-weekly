🧭 简介解读层（AI·证据行可回查）

本地加密的 AI 代理记忆库：SQLCipher/AES 加密 SQLite 存储，作用域签名与哈希链审计日志。

综述（解读层）

Kibisis 是 Perseus Computing 开源的 Python/Rust 库（MIT），把 AI 代理在运行中学到的决策、偏好和事实存入本地单个加密 SQLite 文件，而非托管服务。它提供按候选/已验证/争议/撤销四态组织的检索、墓碑式永久遗忘、每条变更的哈希链日志，以及基于 fencing token 的单写者租约协调。可通过 stdio 上的 MCP 服务器供代理调用，代理写入仅为候选条目，需人工按法定人数审核后才可验证。当前为 0.1.0-alpha.17 预发布版。

  • 条目内容以 AES-256-GCM 密封于单个 SQLite 文件，加载 SQLCipher 后整个数据库文件加密；每条记忆带 HMAC-SHA256 签名，校验失败的行不被返回
  • 检索支持按信任状态与日期查询，排除已撤销条目，MCP 的 recall() 会拦截冲突或覆盖不足的匹配并说明拦截原因；墓碑删除后同作用域内拒绝以任何变体形式重写
  • 全部写入、归档、墓碑和清除记录于与变更同一事务的哈希链日志；租约协调通过只增 fencing token 保证单机多进程/线程单写者

适用场景（解读层）

  • 为长时间运行的 AI 代理在本地保存经加密的记忆，避免数据离开本机
  • 需要人工审核流程的场景：代理写入候选条目，由操作系统账户按法定人数（默认 2 人）批准后变为已验证
  • 多进程协作写入同一记忆库、需要防止并发重复写入的代理系统
