通过解析 SQL dump 文件生成脱敏数据的命令行工具，用于 MySQL/MariaDB

综述（解读层）

MasKING 是一个 Ruby 编写的命令行工具（gem 安装），用于对 MySQL/MariaDB 的 SQL dump 文件做数据脱敏。它不连接数据库、不处理文件，仅通过 stdin/stdout 处理流数据，配合 mysqldump --complete-insert 管道使用。用户在 masking.yml 中指定需要脱敏的表和列及替换值，未列出的列保持原样。工具仅依赖 Ruby 标准库；它不读取实际 schema 类型，配置值与列类型不兼容时会在恢复数据库时报错。

  • 以 stdin/stdout 流方式处理 SQL dump，不连接数据库、不产生中间文件
  • 通过 masking.yml 配置脱敏目标表/列及替换值，支持 YAML 1.1 标签显式类型转换
  • 仅依赖 Ruby 标准库，无外部依赖；支持 MySQL 5.7–8.1 和 MariaDB 10.2–11.1 的 dump

适用场景（解读层）

  • 为 BI 分析、机器学习或问题排查生成经过脱敏的生产数据库副本
  • 基于生产规模数据进行压力测试、集成测试和慢查询调优
  • 在发布前用脱敏的生产数据模拟 schema 迁移以发现锁表等问题
