以 PostgreSQL 扩展实现的分布式数据库，通过分片实现水平扩展

综述（解读层）

Citus 是 PostgreSQL 扩展，将 Postgres 转为分布式数据库：通过 create_distributed_table 将表分片到多节点集群，提供引用表复制、分布式查询引擎与列式存储，支持单节点起步、添加 worker 并重平衡分片。适用于多租户应用、实时分析、时序与 IoT 数据场景，兼容现有 Postgres 版本与工具，可通过 Docker、deb/rpm 包或 Azure 托管服务部署。

  • 支持分布式表、引用表、co-location、模式分片（schema-based sharding）与列式存储
  • 提供 create_distributed_table_concurrently 在不中断读写的情况下分片已有表
  • 查询可从任意节点执行，分布式查询引擎路由并并行化 SELECT/DML 操作

适用场景（解读层）

  • 多租户 SaaS 应用的按租户分片（行级或 schema 级）
  • 时序/IoT 数据的实时分析与批量加载（COPY/INSERT..SELECT）
  • 单节点 Postgres 数据量增长后的 scale-out 扩展
