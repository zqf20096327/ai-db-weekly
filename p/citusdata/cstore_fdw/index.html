🧭 简介解读层（AI·证据行可回查）

PostgreSQL 列式存储扩展，基于外部数据包装器（FDW）实现

综述（解读层）

cstore_fdw 是 Citus Data 开源的 PostgreSQL 列式存储扩展，采用类 ORC 的数据布局格式，以外部表形式存储数据，适合批量加载的分析场景。它仅读取查询涉及的列并可压缩数据，支持 40 多种 Postgres 数据类型。限制：不支持 DELETE、UPDATE 和单行插入，仅支持 PostgreSQL 9.3 至 12。README 提示列式存储已并入 Citus 扩展。

  • 数据布局受 ORC 格式启发，包含压缩、列投影和基于行组 min/max 统计的跳过索引
  • 通过外部数据包装器 API 支持 40 多种 Postgres 数据类型和统计信息收集
  • 提供 filename、compression（none/pglz）、stripe_row_count、block_row_count 等表级参数

适用场景（解读层）

  • 批量加载数据的分析型查询场景
  • 需要压缩数据以减少存储空间的数据归档
  • 与 Citus 扩展配合，通过 create_distributed_table() 实现跨节点分布式分析
