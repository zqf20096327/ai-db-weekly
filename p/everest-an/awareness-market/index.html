🧭 简介解读层（AI·证据行可回查）

AI 编码代理的本地记忆插件，以 Markdown 存储并经 MCP 提供跨会话召回。

综述（解读层）

Awareness Local 为 Cursor、Claude Code 等 MCP 兼容 IDE 提供跨会话记忆能力：通过 npx 一条命令安装本地守护进程，将决策、偏好、风险等知识卡片存为 .awareness/ 目录下的 Markdown 文件，并用 SQLite FTS5 加 embeddings 做混合检索，召回路径不调用 LLM。可选接入云同步与 Python/TypeScript SDK。要求 Node.js 18+，MIT 协议。

  • 以 Markdown 文件在本地存储记忆，配 SQLite FTS5 + embeddings 混合检索，检索阶段零 LLM 调用，支持完全离线运行
  • 提供 5 个 MCP 工具（awareness_init/recall/record/lookup/get_agent_prompt），召回采用两阶段渐进式披露以控制 token 用量
  • README 列出对 13+ IDE 的支持（多数经 MCP 接入），另提供可选云同步、Web 控制台及 Python/TypeScript SDK

适用场景（解读层）

  • 跨多次会话的长期代码迁移，需要代理延续架构决策与待办事项
  • 团队交接场景，让 AI 保留先前的实现上下文与约束
  • 多代理协作环境中共享决策历史与任务记忆
