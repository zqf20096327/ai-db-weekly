LoopBack 框架的 MySQL 连接器，实现模型与 MySQL 数据库的映射

综述（解读层）

该模块为 LoopBack 框架提供 MySQL 连接器，通过 npm 安装或 lb4 datasource 命令生成数据源。它定义 LoopBack 与 MySQL 之间的类型映射（如 String→VARCHAR、Date→DATETIME），支持模型发现与自动迁移，可将模型定义建表。v7.x 起要求 MySQL 8.0+，自动生成 id 仅支持 integer 类型。

  • 支持 LoopBack 模型与 MySQL 表/列的双向类型映射，可通过 mysql. 配置表名、列名及数值/文本/日期等列类型
  • 提供模型发现（基于现有数据库 schema 生成模型）与自动迁移（由模型创建/修改数据库表）能力
  • 支持 MySQL 特有的 match 系列全文搜索操作符，需设置 allowExtendedOperators 为 true 且字段建有 FULLTEXT 索引

适用场景（解读层）

  • 在 LoopBack 4 或 LoopBack 3 应用中连接 MySQL 8.0+ 数据库
  • 基于已有 MySQL 数据库表结构生成 LoopBack 模型（lb4 discover）
  • 通过模型定义自动创建或修改数据库表结构，含外键约束与自增 id
