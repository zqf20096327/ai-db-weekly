🧭 简介解读层（AI·证据行可回查）

为 AI 编码代理提供本地共享记忆与会话间消息协作层的插件工具

综述（解读层）

MeMesh 是一个运行在本地的 AI 编码代理协作层，面向 Claude Code、Codex 与 Hermes Agent 用户。它将偏好、项目决策与经验存入本地 SQLite 知识图谱（~/.memesh/knowledge-graph.db），提供 12 个记忆与协调工具和 10 个 hooks，支持本地代理间消息收发与跨会话交接。原生消息投递仅限 macOS/Linux，单条载荷上限 64 KiB。

  • 提供 remember/recall/forget/learn/briefing/task_state 等 12 个记忆与协调工具，通过 MCP 或 CLI 调用
  • 支持同一台计算机上运行中的 Codex 与 Claude Code 会话通过共享本地收件箱互发消息，消息为持久存储并支持断点恢复
  • 记忆按相关性(30%)、时效(25%)、频率(18%)、置信度(17%)、召回影响(10%)加权排序；支持 JSON 导出/导入备份

适用场景（解读层）

  • 在多个开发会话之间保存并召回项目决策、用户偏好与经验教训，避免重复说明
  • 让一个会话实现代码、另一个会话进行评审或回答问题，通过本地消息交换任务与结果
  • 在会话结束前记录目标、下一步与阻塞项，供下一次会话接续工作
