🧭 简介解读层（AI·证据行可回查）

Kubernetes 上的 MySQL 集群运维器，基于 GTID 半同步复制管理集群

综述（解读层）

MOCO 是 Cybozu 开源的 Kubernetes Operator，通过 MySQLCluster 自定义资源管理最多 5 个实例的 MySQL 集群，采用 GTID 半同步复制，仅允许写入单一主实例。支持主从切换、故障转移、备份与时间点恢复，并提供 kubectl-moco 插件。仅支持 MySQL 8 特定版本的 LTS 版本，不管理组复制集群。

  • 使用 GTID 半同步复制管理 MySQL 集群，仅允许写入单个主实例，并检测含错误事务的实例
  • 支持主实例的手动/自动切换与故障转移、备份和时间点恢复
  • 提供 kubectl 插件，可为每个集群自定义 my.cnf、Pod/Service/PVC 模板及 MySQL 版本

适用场景（解读层）

  • 在 Kubernetes 上部署和维护具有奇数实例数的 MySQL 集群
  • 需要从外部 MySQL 实例复制数据或进行时间点恢复的备份场景
  • 需要切换主实例、升级集群 MySQL 版本或监控复制延迟的运维场景
📖 README 首段存档原文 · 程序抽取

MOCO is a [MySQL][] operator on Kubernetes. Its primary function is to manage MySQL clusters using GTID-based semi-synchronous replication. It does _not_ manage group replication clusters.
