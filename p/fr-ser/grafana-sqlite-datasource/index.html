Grafana 后端插件，将 SQLite 数据库文件接入为 Grafana 数据源。

综述（解读层）

该插件是一个 Grafana 后端数据源插件，用于读取运行 Grafana 设备文件系统上的 SQLite 数据库文件。它提供时间列推断、SQL 宏、Grafana 告警支持，并可通过 grafana.ini 配置 attach 限制与文件黑名单。README 提醒：拥有数据源编辑权限的用户可能通过 attach 访问系统上其他数据库文件，需注意权限管控。插件可通过 grafana-cli 安装。

  • 通过 grafana-cli 安装，或从 GitHub 安装未发布版本
  • 支持时间列推断：数字按 Unix 时间戳（秒）、字符串按 RFC3339 格式解析
  • 支持宏 __unixEpochGroupSeconds（含 NULL 填充）及告警中的 $__from/$__to 变量

适用场景（解读层）

  • 在 Grafana 中查询设备本地文件系统上的 SQLite 数据库并生成时序面板
  • 基于 SQLite 数据源配置 Grafana 告警规则
  • 需要按 Grafana UI 时间范围过滤查询或对时间序列做分组填充的场景

This is a Grafana backend plugin to allow using an SQLite database as a data source. The SQLite database needs to be accessible to the filesystem of the device where Grafana itself
