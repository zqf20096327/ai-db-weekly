受 Anchor modeler 启发的 PostgreSQL 双时态数据建模工具

综述（解读层）

modeler 是一个用 Python 编写的（双）时态数据建模工具，受 Anchor modeler 启发，面向 PostgreSQL。用户在 YAML 文件中定义 schema，运行 modeler.py 生成 SQL 或 Flask 模型代码。它追求 6NF 最大规范化，利用 domains、表继承、扩展等 PostgreSQL 特性，通过 GIST 索引保证时态一致性，并依赖 btree_gist 扩展。README 注明这是探索性项目，不适合生产环境使用，且尚无 YAML 示例。

  • 支持同时包含 validity time 与 transaction time 的时态 6NF 数据库，并提供本地化字段支持
  • 生成幂等的 SQL，可多次执行无副作用，同时可输出 Flask 模型代码
  • 使用 GIST 索引强制时态一致性，要求 UTF-8 编码的数据库并安装 btree_gist 扩展

适用场景（解读层）

  • 在 PostgreSQL 上实验双时态数据模型设计
  • 从 YAML schema 定义生成 SQL 建库脚本
  • 生成 Flask 应用可用的数据模型代码
