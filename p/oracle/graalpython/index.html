综述（解读层）

GraalPy 是 Oracle 维护的运行于 JVM 的 Python 3 实现，兼容 Python 3.13，面向需要在 Java 应用中嵌入 Python 或将 Python 程序打包为独立二进制的开发者。它通过 Maven Central 提供 polyglot 嵌入依赖，支持 pip 安装包；纯 Python 代码可用于生产，C 扩展模块支持为实验性，且含 C 代码的包需在安装时编译。采用 Universal Permissive License 1.0。

  • 支持在 GraalVM JDK、Oracle JDK 或 OpenJDK 的 Java 应用中嵌入运行 Python，可配合 Maven、JFR 等 JVM 工具
  • 可通过 GraalVM Native Image 将 Python 应用及其依赖打包为独立二进制文件
  • CPython 测试套件在每次提交时运行并通过约 85%，每日测试 PyPI 高依赖包并可安装其中 93% 的近期版本

适用场景（解读层）

  • 在 Java 应用中调用 Python 代码或 Python 库（如 NumPy、PyTorch、Hugging Face 模型）
  • 以 pip 工作流替换 CPython 运行 Python 程序，或借助 Native Image 分发独立二进制
  • 在 GitHub Actions 中通过 setup-python action 使用 GraalPy，或迁移使用 --python.EmulateJython 模式的 Jython 脚本
