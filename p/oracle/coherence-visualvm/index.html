VisualVM 插件，聚合 Coherence MBean 数据用于集群监控

综述（解读层）

该插件以 VisualVM 插件形式提供单个 Coherence 集群的管理与监控，聚合集群 MBean 数据并以操作视图展示，部分信息随时间呈现以便实时排查。面向开发与测试生命周期中的集群监控，通过 JMX 或 Management over REST（12.2.1.4 及以上）连接，支持社区版与商业版，要求 VisualVM 2.1 或更高。

  • 支持通过 JMX 直连进程、Management over REST 或 WebLogic Admin Server 三种方式连接集群
  • 提供 Cluster Overview、Machines、Members、Services 等标签页展示集群内存、成功率、负载等数据
  • Options 面板可配置刷新间隔、REST 超时、SSL 校验开关、日志分析等行为

适用场景（解读层）

  • 开发与测试阶段对单个 Coherence 集群进行运行状态监控与问题排查
  • 通过 VisualVM 图形界面查看集群成员、服务和机器的实时运行数据
  • 分析开启了 Partition Events Logging 的 Coherence 日志文件（21.06 及以上）
