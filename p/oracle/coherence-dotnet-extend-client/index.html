Oracle Coherence 的 .NET 客户端库，经 TCP/IP 代理访问集群缓存服务

综述（解读层）

该仓库提供 Coherence .NET 客户端库，使 .NET 应用从集群外部访问 Coherence 集群服务的数据、数据事件与数据处理，典型用途为需要访问 Coherence 缓存的桌面和 Web 应用。库以轻量 DLL 形式分发（含 Coherence 与 Coherence.SessionStore），需 .NET 6+ 构建，测试需 Java 17 及运行中的 Coherence 服务器，ASP.NET 会话测试需商业版。

  • 实现 INamedCache 接口（扩展自 IDictionary），支持查询、map/reduce 风格聚合及向存储节点发送计算函数
  • 基于 TCP/IP 通信层连接集群代理服务，由代理委托 Partitioned 或 Replicated 等缓存服务
  • 提供 Coherence.SessionStore 程序集，构建产物包含 NuGet 包，API 文档可用 docfx 生成

适用场景（解读层）

  • 需要从集群外部读写 Coherence 缓存的桌面与 Web 应用
  • 基于 IDictionary 风格 API 访问分布式分区/复制缓存的 .NET 应用
  • 运行 HelloCoherence 示例进行缓存插入与读取的集成开发场景
