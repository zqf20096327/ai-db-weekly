Oracle NoSQL 数据库示例代码合集仓库，涵盖部署、SDK、教程与工作坊。

综述（解读层）

该仓库汇集 Oracle NoSQL Database 相关示例代码，面向 NoSQL 开发者、架构师、管理员与 DevOps 工程师。内容包括多语言 SDK（Java、Node.js、Spring 等）示例、集群部署脚本、SQL 教程（含行李追踪与流媒体用户画像两个演示 schema）、Terraform 配置，以及 LiveLabs 工作坊代码。部署脚本支持 1-10 台机器的小型集群搭建，可用于本地或 OCI、AWS、Azure 环境。

  • 提供 Java direct driver、Java SDK、Node.js SDK、Spring SDK 等多种语言的示例代码
  • cluster_setup 脚本可在 OCI、AWS、Azure 等环境快速部署 1-10 台机器的 NoSQL 集群
  • 包含 SQL 教程所需的两个演示 schema（BaggageInfo、Streaming Media）及 Terraform 创建 NoSQL 服务的配置示例

适用场景（解读层）

  • 学习 Oracle NoSQL 数据库的部署与集群搭建，用于概念验证或小型本地安装
  • 通过 SQL 教程与示例 schema 练习对关系型、层级及 JSON 数据的查询
  • 使用各语言 SDK 示例开发连接 Oracle NoSQL 或其云服务的应用程序
