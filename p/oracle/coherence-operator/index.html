在 Kubernetes 上部署和管理 Coherence 集群的开源 Operator

综述（解读层）

Coherence Operator 是 Oracle 开源的 Kubernetes Operator，通过 Coherence 自定义资源定义实现 Coherence 集群在 Kubernetes 中的部署、配置覆盖与扩缩容。面向在 Kubernetes 环境中运行 Coherence 的用户，支持 Docker 容器化成员节点、按 Zone 分散数据，并支持接入 Prometheus、Grafana、ELK/EFK 等工具监控集群。

  • 提供 Coherence 自定义资源定义，用于覆盖和自定义集群配置
  • 支持通过 Kubernetes verbs 或更新安全扩缩集群角色，并利用 Zone 信息将数据分散到多个 Zone
  • 支持 Kubernetes 持久卷（Elastic Data、Persistence）及暴露端口供多种客户端访问

适用场景（解读层）

  • 在 Kubernetes 环境中以 Docker 容器方式运行 Coherence 集群成员
  • 为 Coherence 服务器端类部署自定义代码
  • 结合 Prometheus、Grafana、EFK 等工具监控集群性能、日志与健康状态
