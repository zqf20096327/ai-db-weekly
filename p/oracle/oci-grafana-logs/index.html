Grafana 数据源插件，用于接入 Oracle Cloud Infrastructure 日志服务

综述（解读层）

该插件由 Oracle 发布，将 OCI Logging 服务接入 Grafana 作为数据源，可读取计算、网络、存储、应用自定义日志及 OCI 审计日志，并与指标在同一面板中分析。使用需在 OCI 配置 IAM 策略，支持用户 Principal 与 Instance Principal 两种认证方式；4.x 版本对应 Grafana 10，从 2.x 迁移需重新配置。

  • 支持读取 OCI 上计算、网络、存储资源日志、应用自定义日志及 OCI 服务审计日志
  • 提供用户 Principal 与 Instance Principal（动态组）两种认证配置方式
  • 仓库包含 dev/ 本地开发环境，用于在多个 Grafana 版本上验证插件加载、数据源健康检查与真实日志查询

适用场景（解读层）

  • 在 Grafana 中统一查看存储于 OCI Logging 服务的云资源与应用日志
  • 将 OCI 日志与指标数据在同一 Grafana 环境中联合分析
  • 在 OCI 计算实例或 Kubernetes 上部署 Grafana 并接入租户日志
