🧭 简介解读层（AI·证据行可回查）

Oracle Coherence 的 Python 客户端，通过 gRPC 连接集群进行缓存读写操作

综述（解读层）

该客户端让 Python 应用以缓存客户端身份连接 Oracle Coherence 集群，使用 gRPC 作为网络传输。提供 NamedCache 的类 Map 接口及查询、聚合、事件监听等能力。需要运行 Coherence CE 22.06.11+ 或对应商业版并配置 gRPCProxy，Python 版本要求 3.9 及以上。

  • 提供 Map 风格接口（put、get、remove、size、contains_key 等）操作缓存条目
  • 支持集群侧查询、聚合、过滤，以及通过 EntryProcessor 在集群侧处理条目
  • 支持注册 Map 变更、Map 生命周期、会话生命周期事件的监听器

适用场景（解读层）

  • Python 应用（如微服务）需要读写 Coherence 集群中的分布式缓存数据
  • 需要监听缓存数据变更或集群会话状态事件的应用
  • 以 JSON 存储对象并与 Coherence 其他语言 API 共享访问的场景

The Coherence Python Client allows Python applications to act as cache clients to an Oracle Coherence cluster using gRPC as the network transport.
