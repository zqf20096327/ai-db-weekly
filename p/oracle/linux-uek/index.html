Oracle 构建的 Unbreakable Enterprise Kernel Linux 内核源码仓库

综述（解读层）

该仓库托管 Oracle 为 Oracle Linux 构建的 UEK 内核源码，包含少量尚未进入主线 Linux 的 Oracle 补丁（可在 ueknext/latest 分支预览）。README 列出 uek6 至 ueknext 多个生产分支及对应内核版本与目标架构（x86_64/aarch64），仓库每周刷新；构建需 libdtrace-ctf；不支持 GitHub PR，正式支持需通过 Oracle Linux Support。

  • 提供 UEK6 至 UEK-next 多个分支的源码，覆盖 v5.4、v5.15、v6.12 等内核版本，目标架构为 x86_64 与 aarch64
  • 跟踪主线内核源码，Oracle 新增改动持续合入上游 Linux 树，仓库每周刷新
  • 仓库完整保留 git 历史，源码此前已在 oss.oracle.com 公开

适用场景（解读层）

  • 需要获取 Oracle Linux 所用内核源码的开发者或合作伙伴
  • 希望预览尚未合入主线的 Oracle 内核补丁（ueknext/latest 分支）
  • 从源码自行构建 UEK 内核（需安装 libdtrace-ctf 及标准内核构建工具）
