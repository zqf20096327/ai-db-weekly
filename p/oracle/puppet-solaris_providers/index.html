Oracle 官方 Puppet 模块，为 Solaris 提供专有资源类型与 provider 实现

综述（解读层）

该模块为 Puppet 提供 Solaris 专有类型与 provider，覆盖 beadm 引导环境、SMF 服务属性、IPS 包管理、ILB、EVS、ipadm/dladm 网络配置及 ZFS ACL，并覆写核心 Zones provider。适用于 Oracle Solaris 11/11.4 环境的配置管理。在 Solaris 11.4 上 pkg install puppet 即随附安装，无需额外配置。

  • 通过 beadm、svccfg、pkg、ilbadm、evsadm、ipadm、dladm、chmod 等工具实现对 Solaris 特有资源（引导环境、SMF 属性、IPS、ILB、EVS、IP 接口、数据链路、ZFS ACL）的配置
  • 覆写 Puppet 核心的 Zones provider（基于 zoneadm/zonecfg）
  • 模块以 oracle-solaris_providers IPS 包形式随 Solaris 附带，随 puppet 自动安装

适用场景（解读层）

  • 在 Solaris 11/11.4 上用 Puppet 管理服务属性（如 dns/client 域名配置）
  • 通过 Puppet 声明式管理 IP 接口、数据链路与网络配置
  • 管理 Solaris Zones、引导环境与 IPS 包配置
