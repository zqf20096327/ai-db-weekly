Oracle Linux 云实例的 OCI 管理工具集，含守护进程与命令行工具

综述（解读层）

oci-utils 是 Oracle 官方为 OCI 上基于 Oracle Linux 镜像创建的实例预装的工具集合，包含 ocid 守护进程（通过 systemd 运行，扫描 iSCSI 与 VNIC 配置变更并缓存实例元数据和公网 IP）及多个命令行工具，用于管理块存储卷、配置辅助 VNIC、查询元数据与公网 IP、发送 OCI 通知消息。适用于在 OCI 上运行 Oracle Linux 实例的运维场景；详细用法需查阅 OCI 官方文档。

  • 提供 ocid 守护进程，扫描 iSCSI 与 VNIC 设备配置变更并缓存实例元数据和公网 IP
  • 包含 oci-growfs、oci-iscsi-config、oci-metadata、oci-network-config、oci-public-ip、oci-notify 等命令行工具
  • 支持块卷的挂载、移除与自动发现，以及向 OCI 通知服务发送消息

适用场景（解读层）

  • 在 Oracle Linux 实例上查看和管理 iSCSI 设备及 VNIC 网络配置
  • 查询实例元数据与公网 IP 地址（支持人类可读或 JSON 格式）
  • 扩展实例根文件系统到配置大小，或向 OCI 通知服务发送消息
