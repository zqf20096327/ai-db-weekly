Oracle Solaris 11.4 StatsStore 与 REST 接口的示例与文档集合

综述（解读层）

该仓库由 Oracle 维护，围绕 Solaris 11.4 的 StatsStore 提供访问方法、基于其数据构建自定义 sheet、捕获与检索数据供第三方应用使用，并包含 REST 接口交互示例、Analytics Dashboard WebUI 说明及博客配套演示。内容以示例、步骤和 markdown 文档形式组织，供 Solaris 11.4 用户参考。

  • 提供通过 REST 接口连接 Oracle Solaris 11.4 并访问 StatsStore 的示例
  • 包含从 StatsStore 数据构建自定义 sheet 及捕获、检索数据的步骤
  • 附有 Oracle SPARC 与 Solaris 功能的博客配套演示，如 Database In Memory 与 FOSS 包按需部署

适用场景（解读层）

  • 通过 StatsStore WebUI 或 REST 接口观察和交互 Oracle Solaris 11.4 操作系统
  • 将 StatsStore 数据导出供第三方应用程序使用
  • 参考博客配套演示深入了解 SPARC 与 Solaris 11.4 特性
