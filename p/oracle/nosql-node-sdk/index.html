🧭 简介解读层（AI·证据行可回查）

Oracle NoSQL Database 的 Node.js/TypeScript SDK，用于访问云服务与本地部署。

综述（解读层）

这是 Oracle NoSQL Database 的 Node.js SDK（版本 5.5），供 JavaScript 和 TypeScript 开发者访问 Oracle NoSQL 云服务或本地部署数据库（本地模式需通过 Proxy 服务器连接）。SDK 支持通过 npm 安装，内置 StatsControl API 收集客户端请求统计，示例代码支持云服务、Cloud Simulator 和本地三种环境。要求 Node.js 24.0.0 及以上，使用 TypeScript 时需 5.0.x 以上。

  • 提供 JavaScript 与 TypeScript 接口，通过 npm 包 oracle-nosqldb 安装
  • 支持连接云服务、Cloud Simulator 和本地部署（经 Proxy）三种环境
  • 提供 StatsControl API，按 NONE/REGULAR/MORE/ALL 四档采集请求统计，含延迟、重试、错误计数及 p95/p99 分位数

适用场景（解读层）

  • 开发访问 Oracle NoSQL Database Cloud Service 的 Node.js 应用
  • 使用 Cloud Simulator 在本地开发与测试
  • 通过 Proxy 服务器访问本地部署的 Oracle NoSQL Database
