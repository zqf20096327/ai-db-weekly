面向 Micronaut 的模块集合，经 GraalVM 原生镜像 AOT 编译生成原生可执行文件

综述（解读层）

GDK（Graal Development Kit for Micronaut）是一组开源 Micronaut 框架模块，从设计之初即支持以 GraalVM Native Image 进行提前编译（AOT），生成原生可执行文件，用于构建 Java 微服务。使用者可通过官网 Launcher 或 CLI 工具生成应用；CLI 是基于 Micronaut Picocli 的应用，其核心类独立于 gdk-cli 模块，便于构建替代 CLI。安装支持 Homebrew、SDKMAN 或从 Releases 下载二进制。

  • 提供一套精选的 Micronaut 开源模块，支持以 GraalVM Native Image 提前编译为原生可执行文件
  • 提供 CLI 工具（Micronaut Picocli 应用）生成 GDK 应用，CLI 核心类独立模块化以便构建替代 CLI
  • 支持 Homebrew、SDKMAN 及二进制发布包等多种安装方式

适用场景（解读层）

  • 构建以原生可执行文件形式部署的 Java 云原生微服务
  • 通过 Launcher 或 CLI 快速生成 Micronaut/GDK 应用骨架
  • 需要模块化 CLI 核心以定制应用生成工具的团队
