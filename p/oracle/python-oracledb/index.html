Oracle 官方维护的 Python 扩展模块，用于直连 Oracle Database，遵循 DB API 2.0

综述（解读层）

python-oracledb 是 Oracle 官方维护的 Python 连接 Oracle Database 的扩展模块，基于 Cython 构建，是 cx_Oracle 的后继版本。默认以 Thin 模式直连数据库、无需额外客户端库；部分高级功能需加载 Oracle Client 库（Thick 模式）。支持 Python 3.10–3.15。

  • 遵循 Python DB API 2.0 规范并有扩展，支持 SQL/PL-SQL 执行、数据帧、快速数据摄取、文档 API、消息队列、数据库通知及同步与并发编程风格
  • 提供 Thin/Thick 两种模式：Thin 模式无需 Oracle Client 库，要求 Oracle Database 12.1+；Thick 模式需 Oracle Instant Client 19+，支持 Oracle Database 11.2+
  • 支持通过 pip 安装，可选启用内置 OpenTelemetry 插件以导出操作时长指标

适用场景（解读层）

  • Python 程序直连 Oracle Database 执行 SQL 与 PL/SQL 语句
  • 被 Python 框架、SQL 生成器、ORM 及库集成使用
  • 需要快速数据摄取、消息队列或数据库通知等高级数据库功能的场景
