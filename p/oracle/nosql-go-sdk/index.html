🧭 简介解读层（AI·证据行可回查）

Oracle NoSQL 数据库的 Go 语言 SDK，提供连接云端、本地部署与模拟器的客户端 API

综述（解读层）

该 SDK 是 Oracle 官方开源的 Go 模块，提供 API 与示例，用于让 Go 应用连接 Oracle NoSQL Database Cloud Service、本地部署的 NoSQL Database（需 HTTP Proxy）以及 Cloud Simulator。要求 Go 1.24+，通过 go get 获取模块。三种环境的认证与 API 有差异：云端需 OCI 凭证文件，模拟器无需认证，README 注明模拟器不用于生产部署。另支持客户端统计日志，profile 模型与 Java SDK 兼容。

  • 支持连接三种环境：Cloud Service、Cloud Simulator 和本地部署（On-Premise，需运行 HTTP Proxy）
  • 以 Go module 形式发布，通过 import 与 go build/go test 自动管理依赖，支持 go get 指定版本
  • nosqldb.Client 实例可被多个 goroutine 并发使用，适合在多 goroutine 应用中共享

适用场景（解读层）

  • 开发访问 Oracle NoSQL Database Cloud Service 的 Go 应用程序
  • 使用 Cloud Simulator 进行本地开发与测试
  • 通过 HTTP Proxy 连接本地部署的 Oracle NoSQL Database 并对安全存储配置证书验证或用户身份
