基于 OCI 封装的 Oracle 数据库 C 语言访问接口库

综述（解读层）

ODPI-C 是 Oracle 开源的 C 代码库，对 Oracle Call Interface（OCI）进行封装，为 C/C++ 应用程序和各类语言驱动提供访问 Oracle Database 的接口。python-oracledb、node-oracledb 等 Oracle 官方驱动以及 Go、Rust、Ruby 等第三方语言驱动均基于它实现。安装、文档、示例与测试分别位于项目指定页面及 /samples、/test 目录。

  • 对 OCI 进行封装，供 C/C++ 应用调用
  • 支持 Oracle Database 与 Oracle Client 的基础和高级特性
  • 被 python-oracledb、node-oracledb 及多种第三方语言驱动使用

适用场景（解读层）

  • 为 C/C++ 应用程序提供 Oracle 数据库访问层
  • 作为开发新语言数据库驱动的基础接口库
  • 参考 /samples 与 /test 了解用法与接口行为
