将应用提前编译为原生可执行文件的 Java 开发工具链

综述（解读层）

GraalVM 是 Oracle 维护的开源项目，包含 Graal 编译器、Native Image AOT 编译框架及 Truffle 语言实现框架等组件，可将应用提前编译为独立二进制文件。可作为 JDK 在 IDE 中使用，文档位于 docs/ 目录，源码构建说明在 vm/README.md。

  • 提供 Native Image 框架，支持应用的提前（AOT）编译
  • 包含 Truffle 语言实现框架，仓库内提供 Java（Espresso）、LLVM bitcode（Sulong）、WebAssembly（GraalWasm）等运行引擎
  • 可作为常规 JDK 在 IDE 中使用，支持从源码构建

适用场景（解读层）

  • 将 Java 应用编译为独立原生可执行文件
  • 基于 Truffle 框架开发新的编程语言或工具
  • 在 GraalVM 上运行 JavaScript、Python、WebAssembly 等语言的程序
