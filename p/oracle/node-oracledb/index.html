Oracle 官方维护的 Node.js Oracle 数据库驱动模块

综述（解读层）

node-oracledb 是 Oracle 公司维护的开源 Node.js 驱动，通过 npm 安装后可让 Node.js 14.17 及以上版本的 JavaScript/TypeScript 应用连接 Oracle Database。它提供 SQL/PL/SQL 执行、数据写入、文档 API、消息队列等接口。6.0 起默认 Thin 模式直连数据库、无需 Oracle Client；部分高级功能需加载客户端库进入 Thick 模式。

  • 支持 Thin 模式直连 Oracle Database 12.1 及以上，Oracle Client 库为可选依赖
  • 提供 SQL 与 PL/SQL 语句执行、数据快速写入、NoSQL 风格文档 API、消息队列与数据库通知接口
  • 支持 TypeScript 与 JavaScript，附示例目录、文档与可运行的测试套件

适用场景（解读层）

  • Node.js 或 TypeScript 应用需要连接并操作 Oracle Database
  • 框架、SQL 生成器、ORM 或库需要集成 Oracle 数据库访问能力
  • 需要执行 PL/SQL、数据批量写入或数据库启停等管理操作的场景
