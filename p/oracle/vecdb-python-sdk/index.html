Oracle AI 数据库向量搜索的 Python SDK，支持嵌入、RAG 与 AI 代理

综述（解读层）

Oracle VecDB Python SDK 让 Python 开发者在 Oracle AI Database 上构建向量搜索、语义搜索、RAG 和 AI 代理应用，将向量与既有业务数据同库存放，无需单独部署向量数据库。支持集成嵌入或自带向量，默认自动创建向量索引，并可调整 HNSW 参数。要求 Python 3.10+、Oracle AI Database 23.26.3+ 和 ORDS 26.2.2+，通过 pip 或 uv 安装。

  • 支持语义搜索与元数据过滤的组合查询，可叠加空间与结构化约束
  • 提供集成嵌入与自带向量（BYOV）两种嵌入方式，默认自动创建向量索引
  • 提供 HNSW 调优、批量加载、索引管理等性能与维护相关 notebook

适用场景（解读层）

  • 在 Oracle AI Database 上对既有业务数据做语义与相似度搜索
  • 构建文档分块、嵌入生成、上下文检索的 RAG 应用
  • 需要向量检索与地理空间过滤结合的场景，如样例中的公园查询应用
