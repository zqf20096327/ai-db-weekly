Oracle 官方 MCP 服务器参考实现集合，用于管理 Oracle 产品与 OCI 资源

综述（解读层）

该仓库包含多个 Oracle MCP（Model Context Protocol）服务器的参考实现，用于让 MCP 兼容客户端管理和操作 Oracle 产品与 OCI 资源。每个 src/<server-name>/ 是独立服务器，可用 Python、Node.js、Java 等不同语言编写。服务器通过 stdio 或 HTTP 流式传输连接客户端，支持 uvx 或 podman 运行；README 明确说明这些为概念验证/参考实现，不用于生产环境。OCI 类服务器需配置 OCI CLI 凭证或 OCI IAM 机密应用。

  • 提供多个独立的 MCP 服务器参考实现，各服务器可采用不同编程语言，体现 MCP 的语言无关性
  • OCI 服务器支持 stdio 和 HTTP 流式两种传输模式，可用 uvx 直接运行或通过 podman 容器化部署
  • 包含通用型 OCI Cloud 服务器（直接调用 OCI Python SDK）、基于 OCI CLI 的 API 服务器，以及面向特定服务/产品工作流的专用服务器

适用场景（解读层）

  • 在 MCP 兼容客户端（如 Cline、Cursor）中配置服务器，以探索和原型化 OCI 云资源管理与 CLI 命令执行
  • 针对已知 Oracle 产品或 OCI 领域，选用 src/ 下特定领域的专用 MCP 服务器
  • 作为学习 MCP 服务器实现的参考代码，或作为构建自有 Oracle MCP 服务器的起点
