Oracle NetSuite 官方工具集，基于 SDF 定制账户并开发 SuiteApp

综述（解读层）

SuiteCloud SDK 是 Oracle 维护的工具集合，开发者通过 SuiteCloud Development Framework（SDF）定制 NetSuite 账户并创建 SuiteApp。仓库包含 CLI for Node.js、VS Code 扩展、单元测试、UIF Types、AI Agent 插件及 REST API 等组件，发布于 npm 与 VS Code 市场文档见 NetSuite Help Center。

  • 提供 SuiteCloud CLI for Node.js（npm 包 @oracle/suitecloud-cli）
  • 提供 Visual Studio Code 扩展与 SuiteCloud Unit Testing 测试工具
  • 包含 AI Agent Plug-ins、Agent Skills、UIF Types 与 SuiteApp Control Center REST API

适用场景（解读层）

  • 通过 SDF 定制 NetSuite 账户配置
  • 开发并单元测试 SuiteApp 应用
  • 在 VS Code 或 CLI 环境中进行 SuiteCloud 项目开发
