综述（解读层）

Bytebase 是开源数据库治理平台，充当用户（人与 AI 代理）与数据库间的控制平面，管理变更、访问控制与合规并记录全部操作。支持 PostgreSQL、MySQL、MongoDB 等多种数据库，提供 Docker 与 Helm 安装，可通过 MCP Server 接入 AI 代理。

  • 提供基于 Web 控制台的变更工作流，支持请求、审核、部署与回滚，并集成 GitHub/GitLab 实现 GitOps
  • 包含 200+ 条 SQL 审核规则、细粒度 RBAC、限时访问授权与查询时按角色执行的列级动态脱敏
  • 提供审计日志、Terraform Provider/API 策略即代码、数据分类标记，以及 MCP Server、Text-to-SQL 等 AI 功能

适用场景（解读层）

  • 开发团队：数据库 schema 版本管理与 CI/CD 自动化部署
  • DBA：集中管理多环境数据库并执行统一的 SQL 标准
  • 安全团队：列级权限控制、敏感数据脱敏与审计合规
