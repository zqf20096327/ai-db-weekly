🧭 简介解读层（AI·证据行可回查）

开源 GenBI 引擎：为 AI 代理提供语义层与上下文层的受治理 text-to-SQL

综述（解读层）

WrenAI 是 Apache-2.0 协议下的生成式 BI 引擎，通过 CLI（pip install wrenai）接入 Claude Code、Cursor、MCP 客户端等 50+ 代理。业务定义以 YAML/Markdown 文件存于 Git 仓库，SQL 在执行前基于 MDL 语义层做干跑校验；核心引擎与连接器开源，行级安全、GenBI UI 等为商业版功能。

  • 基于 MDL 的语义层与 AI 上下文层，业务定义以可版本控制的 YAML/Markdown 存于 Git
  • 基于 Apache DataFusion 的引擎，支持 BigQuery、Snowflake、PostgreSQL、ClickHouse 等 22+ 数据源
  • 提供治理执行机制：干跑校验、行数限制、结构化错误提示，以及 LangChain/Pydantic SDK 与 MCP server

适用场景（解读层）

  • 让 AI 代理在已有指标定义约束下生成 SQL 并部署可分享的仪表盘
  • 将业务语义（指标、枚举、join 关系）以 Git 管理并在 PR 中评审
  • 团队通过 git push 将本地模型同步到云端或自托管环境部署 GenBI 应用
