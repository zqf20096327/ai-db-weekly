使用 Go、sqlx 与 migu 操作 TiDB 的示例项目

综述（解读层）

该项目提供一个使用 Go 语言、sqlx 库与 migu 迁移工具连接 TiDB 的示例，演示 IN 与 LIKE 查询，并输出 10000 次操作的耗时结果。依赖通过 go mod 与 docker-compose 安装，数据库迁移可由 migu 在初始化时自动同步 schema.go。适合需要在本地搭建 TiDB + Go 环境的开发者参考。README 未说明 TiDB 版本与运行环境要求。

  • 演示在 TiDB 上使用 IN 与 LIKE 查询
  • 通过 migu 工具从 schema.go 同步数据库结构，初始化时自动执行
  • 使用 docker-compose 启动依赖环境，并提供 10000 次操作的耗时输出示例

适用场景（解读层）

  • 搭建 Go + sqlx + TiDB 的本地开发示例环境
  • 参考 migu 对 TiDB（MySQL 协议，端口 4000）的 schema 同步流程
  • 查看示例代码中 IN 与 LIKE 查询的写法
