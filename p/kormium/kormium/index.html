Kotlin 多平台类型安全 ORM 与 SQL DSL，一套模式多端运行。

综述（解读层）

Kormium 是面向 Kotlin Multiplatform 的类型安全 ORM 和 SQL DSL，提供表、实体、谓词、事务、迁移、连接与聚合的 API，供服务端与客户端开发者使用。核心运行于 JVM、Native、Android 和 iOS，Node 与浏览器 Wasm 为实验性支持；包含 PostgreSQL、MySQL/MariaDB、SQLite 后端、r2dbc 异步模块及 Ktor 集成。JVM 构建需 JDK 21+，schema 管理不由其负责，需用 SQL 或迁移工具完成。

  • 提供 Exposed 风格的类型化 SQL DSL，值以参数绑定，表与数据库作用域在编译期校验
  • 核心支持 JVM、Kotlin/Native、Android、iOS，实验性支持 Node 与浏览器 Wasm；内置 PostgreSQL、MySQL/MariaDB、SQLite 后端及 r2dbc 异步连接
  • 提供 kormium-observe 将查询转为 Flow，Ktor 集成模块分为 DI 无关、Ktor DI 与 Koin 三种 artifact

适用场景（解读层）

  • Kotlin Multiplatform 项目中服务端与客户端共享同一套数据模式与查询代码
  • 基于 Compose Multiplatform 或 Android 的界面需随数据表变化刷新的场景
  • Ktor 服务端使用 JDBC、r2dbc 或原生 libpq 访问 PostgreSQL/MySQL/SQLite 的应用
