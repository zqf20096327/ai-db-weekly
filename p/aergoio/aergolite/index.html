AergoLite：以轻量私有区块链实现SQLite数据库的节点间复制。

综述（解读层）

AergoLite 是一个在 SQLite 之上加入轻量区块链复制的数据库库：每个应用持有一个本地副本，事务经 VRF 共识确定执行顺序后各节点得到一致结果，并支持离线写入、回连后按共识处理或回滚。面向物联网与移动等资源受限设备，通过 URI 参数（blockchain、admin 等）开启区块链模式，支持存储过程限制节点可执行的操作。支持 Mac/Linux/Windows/Android/iOS/OpenWrt。

  • 通过 VRF 共识协议分发并排序事务，使各节点数据库内容一致，并提供绝对最终性
  • 支持离线写入，事务存入本地队列，重连后经共识处理，被拒绝时数据库回滚到前一状态
  • 通过 URI 参数开启区块链模式，节点私钥加密存储，可选 privkey、password 等参数配置

适用场景（解读层）

  • IoT、移动设备等资源受限环境中的多节点 SQLite 数据复制
  • 需要离线写入、联网后同步并按共识确认或回滚的应用
  • 需要记录全部 SQL 命令历史以支持审计与数据恢复的场景
