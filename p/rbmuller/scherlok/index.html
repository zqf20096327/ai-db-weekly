🧭 简介解读层（AI·证据行可回查）

零配置数据库表异常检测工具，通过学习历史基线发现数据漂移。

综述（解读层）

Scherlok 是一个 Python 编写的命令行数据质量监控工具，通过先采集表画像（行数、NULL 率、分布、基数、更新频率）建立基线，再检测漂移，无需编写 YAML 规则。支持 PostgreSQL、BigQuery、Snowflake、MySQL、DuckDB 与 dbt 模型。画像仅存 SQLite 聚合值，不保存行数据；提供 MCP 服务器和 GitHub Action 集成。检测到 CRITICAL 时基线不更新，需人工 accept 确认。

  • 支持 9 类异常检测：行数骤变、更新停滞、schema 漂移、NULL 率激增、分布偏移、基数爆炸等，自动分级 INFO/WARNING/CRITICAL
  • 提供 reconcile 命令对比管道输入输出（行数、键、金额合计），可捕获 join 扇出等自历史无法发现的问题
  • 包含 MCP 服务器、GitHub Action、Slack/Discord/Teams/邮件通知，以及 --against 跨库对比和 --fail-on CI 门禁选项

适用场景（解读层）

  • CI/CD 流水线中作为 pull request 的数据质量门禁，用 scherlok ci 或 verify 对比基线
  • dbt 项目运行后自动对全部物化模型做异常检测，无需编写 dbt test 规则
  • 通过 reconcile 校验 ETL 管道输出与源表的行数、键和数值总和一致性
