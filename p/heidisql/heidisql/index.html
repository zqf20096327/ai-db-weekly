用于管理多种数据库服务器的图形界面客户端工具

综述（解读层）

HeidiSQL 是一个数据库图形界面客户端，用于管理 MariaDB、MySQL、SQL Server、PostgreSQL、SQLite、Interbase 和 Firebird。用户可通过它浏览与编辑数据、创建和修改表、视图、存储过程、触发器及计划事件。项目以 Delphi 编写，Windows 版构建需 Delphi 12.1，非 Windows 平台需使用 lazarus 分支。拉取请求仅接受缺陷修复。

  • 支持浏览和编辑数据，创建和编辑表、视图、存储过程、触发器和计划事件
  • 支持将结构和数据导出到 SQL 文件、剪贴板或其他服务器
  • 通过 Transifex 平台提供多语言翻译贡献渠道

适用场景（解读层）

  • 管理和维护 MariaDB、MySQL、PostgreSQL 等多种数据库服务器
  • 需要在不同服务器之间导出数据库结构和数据的场景
  • 非 Windows 平台用户可使用 lazarus 分支编译运行
