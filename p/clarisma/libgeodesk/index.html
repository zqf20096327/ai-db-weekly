🧭 简介解读层（AI·证据行可回查）

面向 OpenStreetMap 数据的 C++ 地理空间数据库引擎，基于 GOL 文件格式运行。

综述（解读层）

GeoDesk 是一个 C++ 库，将 .osm.pbf 数据转换为 GOL（Geo-Object Library）文件后进行查询，返回轻量 C++ 对象，可直接访问标签、way 节点和 relation 成员，并可选用 GEOS 做缓冲、联合等几何运算。需要 CMake 3.14+、支持 C++20 的编译器和 Java 16+（运行 GOL Tool），支持 Windows/Linux/MacOS。另有 Python 和 Java 版本。声明有对比性数字（如 GOL 文件比 PBF 大 20%-50%）出自 README，未经独立验证。

  • 将 .osm.pbf 转换为 GOL 文件，并支持按日/小时/分钟的增量更新
  • 查询返回 C++ 对象，可读取标签、way 节点、relation 成员及长度/面积等几何信息
  • 可选集成 GEOS，实现 buffer、union、hull、Voronoi 等几何操作；查询引擎以内嵌方式运行，无需数据库服务器

适用场景（解读层）

  • 基于 OpenStreetMap 数据的本地地理空间查询与分析（如按标签、距离筛选要素）
  • 遍历 OSM 关系结构，如查询经过某条街道的公交线路、统计建筑物入口
  • 构建依赖 GOL 文件的 C++ 应用，或使用配套的 Java/Python 版本
