嵌入式 percolator，单 Python 进程内将文档与大量保存查询匹配。

综述（解读层）

Perq 是一个嵌入式前瞻搜索（percolator）库，用于在抓取流程中把新到的文档匹配到预先建好的保存查询集合，适用于商品、职位、文章提醒与文档路由。它通过稀疏子句候选筛选与位掩码缩小评估范围，提供 MemoryStore/SQLiteStore/可选 LMDBStore 三种后端，并附带 JSONL 的 build/match CLI。匹配为归一化后的精确匹配，不支持语义相似、词干化或否定等操作。

  • 使用 rare-clause 候选选择与位掩码，使每个文档只需完成候选查询的检查
  • 核心包无运行时依赖，支持 Python 3.11–3.14，可选 SQLite/LMDB 持久化后端
  • 提供 perq build/match/inspect CLI，按 JSONL 输入输出匹配结果；index() 原子替换整个查询集

适用场景（解读层）

  • 爬虫/抓取流程中对新条目运行大量保存搜索并生成提醒
  • 商品与价格监控、分类信息、职位提醒、文章过滤
  • 文档路由与代理/终端环境下的 JSONL 批量匹配
