基于 SQLite FTS5 的本地 AI 编程代理持久记忆 MCP 服务器与 CLI

综述（解读层）

DevMemory 是一个本地运行的 MCP 服务器和 CLI 工具，用 SQLite FTS5 为 AI 编程代理（如 Claude Code、Cursor）存储项目决策、架构、调试经验等记忆，数据保存在 ~/.devmemory 的单个 SQLite 文件中。存储前会对密钥做脱敏，项目间记忆相互隔离。需 Node.js ≥ 22.12；搜索为关键词匹配而非语义搜索，中日文分词较粗糙，Cursor 集成尚未端到端验证。

  • 通过 stdio 提供 9 个 MCP 工具，另含 15 个 CLI 命令，支持 JSON 输出与机器可读退出码
  • 使用 SQLite FTS5 全文搜索与 BM25 排序，结果按重要性、置信度和时间加权并说明评分依据
  • 存储前对 API 密钥、令牌、密码和私钥进行脱敏，检索到的记忆被包装为不可信数据

适用场景（解读层）

  • 在多个 AI 会话间持久保存项目的架构决策、团队约定和调试教训
  • 通过 memory_context 工具为当前任务生成带 token 预算的上下文包
  • 用 export/import 的 JSON 格式对项目记忆做备份与迁移
