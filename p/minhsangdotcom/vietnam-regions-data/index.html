提供越南省县乡行政区划数据并以 JSON/SQL 文件导出的 Web API

综述（解读层）

该项目是一个以 Web API 形式运行的越南行政区划数据生成工具，数据源取自越南官方统计网站 danhmuchanhchinh.gso.gov.vn，覆盖省、县、乡三级行政单位，输出 JSON 或 SQL 文件供导入数据库。其变更比对机制可在新旧 Excel 数据间生成 Changes.json 差异文件，便于增量更新。数据仅适用于关系型数据库，SQL 输出在 PostgreSQL、SQL Server、MySQL、Oracle 上测试运行。

  • 提供 /api/regions/json 与 /api/regions/sql 两个接口，分别输出 JSON 文件和 SQL 文件至 Output 目录
  • 数据源来自越南官方统计门户 danhmuchanhchinh.gso.gov.vn，包含省、县、乡三级数据及新旧数据差异比对，生成含 old/new/changes/type 字段的 Changes.json
  • 支持在 appsettings 中配置目标数据库类型（MySQL/PostgreSQL/SqlServer/Oracle）及自定义表名和列名

适用场景（解读层）

  • 需要将越南省县乡三级行政区划数据导入 MySQL、PostgreSQL、SQL Server 等关系型数据库的项目初始化
  • 行政区划数据因政策调整发生变更时，通过上传新旧 Excel 文件生成变更清单以更新数据库
  • C# / ASP.NET Core 项目中以 seed data 方式使用行政区划 JSON 数据
