基于 AutoFixture 定制化生成 EF Core 测试 DbContext 的库

综述（解读层）

该库为单元测试使用 Entity Framework Core 的代码提供 AutoFixture 定制化，通过 In-Memory 和 SQLite 两种实际数据库提供程序创建 DbContext，自动建库并允许配置存储名、连接字符串等参数。面向需要在 xUnit、NUnit、MSTest 等测试框架中减少上下文搭建样板代码的开发者，支持 EF Core v2.0.0 起版本，EF Core v7 需自行安装对应的数据库提供程序包。

  • 提供 InMemoryCustomization、SqliteCustomization、DbContextCustomization 三种定制化，不使用 mocking 框架或动态代理，而是使用实际数据库提供程序创建上下文
  • 默认配置下自动调用 Database.EnsureCreated() 创建数据库；In-Memory 定制生成带随机后缀的唯一存储名，SQLite 定制默认使用 Data Source=:memory: 连接字符串
  • 支持 Microsoft.EntityFrameworkCore v2.0.0+ 与 AutoFixture v4.4.0+，仅提供定制化，可与 xUnit、NUnit、MSTest 等测试框架配合使用

适用场景（解读层）

  • 为使用 EF Core 的代码编写单元测试时，减少 DbContext 的搭建样板代码
  • 需要基于 In-Memory 或 SQLite 内存数据库运行测试的场景
  • 需要自定义数据库提供程序定制化或扩展现有定制化的高级场景
