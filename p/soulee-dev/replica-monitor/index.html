🧭 简介解读层（AI·证据行可回查）

自动化搭建并对比 MySQL 主从复制与 python-mysql-replication 两种结构的指标工具

综述（解读层）

Replica-Monitor 用于自动搭建 Master-Slave 复制与 Master-python-mysql-replication 两种结构，创建多表多列并写入随机数据，随后对比两种结构的指标并生成 CSV 报告。使用者需安装 Docker、Docker Compose 和 Python，克隆仓库并安装依赖后执行 make 即可完成全部流程。项目采用 MIT 许可证发布。

  • 提供一键命令自动搭建 Master-Slave 复制与 Master-python-mysql-replication 两种结构
  • 自动创建多个表和列，并向数据库写入随机数据
  • 对比两种复制结构的指标并生成 CSV 报告

适用场景（解读层）

  • 需要对比 MySQL 主从复制与 python-mysql-replication 两种结构指标的场景
  • 需要批量生成测试表与随机数据以观察复制行为的场景
  • 需要以 CSV 形式留存复制指标结果的场景
