综述（解读层）

Databasify 是一个开源的自托管数据库管理平台，用于在自有服务器上运行 PostgreSQL、MySQL、MariaDB、MongoDB、Valkey 和 Redis，支持从单节点到带自动故障转移的高可用集群，并提供时间点备份与 TLS。通过一行脚本安装在至少 1GB 内存的 Linux 服务器上，技术栈为 Laravel 与 React。

  • 支持 PostgreSQL 15–18、MySQL 8.4/9.7、MariaDB 10.11–12.3、MongoDB 7.0–9.0、Valkey 7–9、Redis 7.2/8 等多版本引擎
  • 提供主备集群、自动故障转移、只读节点、时间点备份、TLS 和连接池等能力
  • 每个引擎独立仓库并以容器镜像分发，可通过 plugin SDK 注册自定义数据库引擎

适用场景（解读层）

  • 在自有或云服务器（DigitalOcean、Hetzner、Vultr、Linode）上自建数据库集群管理面板
  • 需要多数据库实例统一管理、用户、指标、日志与邮件告警的团队
  • 从现有数据库迁移并借助每周维护窗口自动更新的环境
