解密微信 4.1+ 本地 SQLCipher 数据库并导出聊天记录的命令行工具/智能体技能包

综述（解读层）

wxbak 是面向微信 4.1+ 的本地数据库解密与聊天记录导出工具，运行于 Windows（需 Python ≥ 3.9、管理员权限、微信已登录）。它从微信进程内存的 Config.Cipher 结构提取 32 字节密钥，解密 message_*.db 主库与 -wal 文件后按发言人、时间戳拆分为 txt/json。可作智能体技能安装或命令行使用；提供 selftest 离线自检与 doctor 环境诊断，未覆盖公众号消息库。

  • 支持微信 4.1+，从进程内存的 com.Tencent.WCDB.Config.Cipher 结构提取 32 字节密钥，并自动发现数据目录、message_*.db 分片与多账号
  • 一并解密 -wal 文件，发言人依据 Name2Id.real_sender_id 字段解析，输出 txt/json 并还原引用、转账、红包等富媒体为可读文本
  • 提供 selftest 离线自检、doctor 环境诊断、extract 失败分级诊断，以及 prepublish_check.py 隐私自检脚本

适用场景（解读层）

  • 导出并备份自己在 Windows 上登录的微信 4.1+ 聊天记录为可读文本
  • 本地取证或个人数据分析：按发言人、时间戳逐条解析聊天内容
  • 作为智能体技能接入支持 Agent Skills 的宿主，通过自然语言指令触发导出流程
📖 README 首段存档原文 · 程序抽取

微信 4.x 把聊天记录存成本地加密数据库，密钥不落盘、版本一变就取不到。市面上的工具大多只支持微信 4.0，在 4.1 上会静默失败。
