JavaScript 模拟框架，通过拦截请求、路由和数据库生成模拟数据

综述（解读层）

Kakapo.js 是一个 JavaScript 模拟（mocking）框架，通过 Router 定义路由、Database 管理模拟数据，并默认拦截 Fetch 和 XMLHttpRequest 请求。它面向前端开发者，用于在浏览器中模拟后端接口。安装方式为 npm 或 bower，Database 内置 id 自动生成，支持 Faker 生成假数据及 belongsTo/hasMany 关系定义。

  • 默认拦截 Fetch 与 XMLHttpRequest 请求，未匹配路由的请求按原样放行
  • 提供 Router、Database、Response、Serializers 组件，Database 支持 Faker 工厂、id 自动生成及 belongsTo/hasMany 关系
  • Router 支持 host、requestDelay 配置及 scenarios 多套预设切换

适用场景（解读层）

  • 前端开发阶段在后端接口未就绪时本地模拟 API 响应
  • 通过调整 requestDelay 或批量 create 数据来查看加载状态与大量元素下的页面表现
  • 通过未匹配请求放行机制，对部分路由进行模拟、其余请求照常发出
