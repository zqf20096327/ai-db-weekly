🧭 简介解读层（AI·证据行可回查）

本地优先的 MCP 记忆服务器，零依赖，SQLite 存储于本地磁盘。

综述（解读层）

Mnemosyne OS 是面向 AI Agent 的长期记忆服务器，提供 Python 库、CLI、HTTP API 和 MCP server 四种使用方式，pip 安装即可运行，无第三方依赖、无需 API key。默认使用内置 embedder 和规则抽取器，可按需接入外部 LLM/向量库；数据以 SQLite 存于本地磁盘，兼容 Mem0 的 52 个 MCP 工具名。

  • 支持 MCP、CLI、HTTP API 和 Python 库四种访问方式，提供 52 个与 Mem0 命名兼容的 MCP 工具
  • 核心零第三方依赖，数据以 SQLite 文件形式存储在本地磁盘，可离线运行
  • 支持 user_id/agent_id/run_id/app_id 四维隔离（每 scope 一个 SQLite 文件）、图记忆、热/温/冷分层记忆、SHA-256 哈希链审计账本，并内置 20 个 LLM、13 个 embedder、28 个向量存储的可选适配器

适用场景（解读层）

  • 为 MCP 客户端（如 Claude Code、Cursor 等）提供本地长期记忆服务，可从 Mem0 迁移而无需更改提示词
  • 在无网络、无 API key 的环境下离线运行 Agent 记忆读写
  • 作为 Python 库嵌入应用，按需组合 LLM provider、embedder 与向量存储适配器
