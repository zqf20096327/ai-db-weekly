基于事务机制的 ArangoDB 数据库迁移工具与 CLI

综述（解读层）

arango-migrate 是一个面向 ArangoDB 的数据库迁移工具和命令行程序，以 TypeScript 编写，通过包管理器作为开发依赖安装。它在事务中运行单个迁移，迁移失败时保持数据库处于有效状态；通过 step 函数向事务添加操作，并提供 up/down 生命周期函数、可选的前后钩子与 dry-run 支持。配置写在项目根目录的 config.migrate.js 中。

  • 以事务方式执行迁移，up/down 函数通过 step 函数将 ArangoDB 操作加入事务，迁移失败时保持数据库有效状态
  • 提供可选的 before/after 钩子和 dry-run 支持
  • CLI 支持 -i 初始化迁移文件、-u 运行未应用的迁移、-t 指定执行到某一版本号

适用场景（解读层）

  • 需要对 ArangoDB 集合（含 edge collection）和文档进行版本化迁移的项目
  • 需要在迁移失败时通过事务回滚保持数据库状态一致的场景
  • 需要执行迁移前先 dry-run 或添加前后钩子的流程
