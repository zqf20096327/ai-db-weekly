可调优的开源 text-to-SQL 引擎，含评测工具链

综述（解读层）

mnemiq 是 Apache-2.0 的开源 text-to-SQL 引擎，用于在自己的数据库上以自然语言查询数据。它将问题到 SQL 之间的各环节（模型选择、检索范围、语义增强、拒绝阈值等）暴露为可配置项，并在执行前用确定性层校验只读、权限、方言编译和 EXPLAIN。评测框架按返回数据而非 SQL 字符串评分，并将正确、拒绝、错误分开统计。适用于需要在自有数据上评估和调优 NL2SQL 系统的团队。

  • 管道各阶段（模型、检索、语义分层增强、验证阈值、行列策略）均以配置文件形式开放，支持命名配置档案与 mnemiq sweep 参数扫描
  • 查询须经确定性裁决层：只读检查、调用者权限、源方言编译与 EXPLAIN 验证，未通过则返回说明原因的拒绝
  • 内置评测工具，按返回数据评分并分别报告正确/拒绝/错误三类结果，支持 BIRD、Spider 等公开基准；访问基于角色且 fail-closed，支持 OIDC 身份与 MCP over HTTP

适用场景（解读层）

  • 在自己业务的数据库上评估和调优自然语言查询系统
  • 需要行/列级权限策略与审计追踪的数据问答部署
  • 基于 DuckDB/Postgres/Oracle/Databricks 等数据源构建 MCP 服务暴露 NL2SQL 能力
