纯 Go 实现的 SQLite 驱动，不依赖 cgo

综述（解读层）

该项目将 SQLite 的 C 代码转译为生成的 Go 代码，以纯 Go 方式实现 SQLite 数据库驱动，无需 cgo。主要面向需要在 Go 程序中嵌入 SQLite 且构建环境不便使用 C 工具链的开发者。源码托管于 GitLab，GitHub 为镜像仓库，接受 Issue 和 PR。注意大部分 Go 代码由 C 生成，直接修改会在下次重新引入时丢失；支持通过 vtab 包以 Go 实现虚拟表模块。

  • 以纯 Go 实现SQLite，不依赖 cgo，转译代码按 GOOS/GOARCH 生成
  • 提供 vtab 包的 Go API，可用任意数据源实现 SQLite 虚拟表模块
  • 附带 CycloneDX 与 SPDX 格式的机器可读 SBOM 及第三方许可清单

适用场景（解读层）

  • 在无法使用 C 工具链（如交叉编译或 CGO_ENABLED=0）的环境中构建包含 SQLite 的 Go 程序
  • 用 Go 编写虚拟表模块，将 CSV 文件、远程 API、向量索引等数据源接入 SQL 查询
  • 需要审查二进制中链接代码成分与许可合规的供应链审计场景
