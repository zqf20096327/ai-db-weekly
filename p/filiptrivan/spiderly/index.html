.NET 代码生成器，将 EF Core 实体转为 C#+Angular 全栈应用

综述（解读层）

Spiderly 是一个开源的 .NET (C#) 代码生成器，读取 EF Core 实体模型，生成包含 Angular UI、API 客户端、控制器、服务方法及前后端同步校验的 Web 应用，并在模型变更时更新样板代码。面向使用 .NET 和 Angular 的开发者，通过 dotnet tool 安装 CLI 后运行 spiderly init 初始化项目，需 .NET 9.0、PostgreSQL 或 SQL Server 及 Node.js。

  • 按 EF Core 实体生成 CRUD UI、Angular API 客户端、.NET 控制器和数据库服务方法
  • 生成 .NET FluentValidation 规则与匹配的 Angular 响应式表单校验器，两侧保持同步
  • 内置应用模板包含认证（含 Google 登录）、授权、邮件、日志和全局错误处理，并提供 Claude Code 插件

适用场景（解读层）

  • 基于 EF Core 实体快速生成含管理页面的 .NET + Angular 应用脚手架
  • 模型演进时自动更新前后端样板代码的迭代开发流程
  • 供 AI 编码代理使用的框架，含实体设计、迁移命令等技能包
