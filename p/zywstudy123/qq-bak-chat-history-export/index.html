解析已解密 NTQQ 数据库，将 QQ 聊天记录导出为 TXT/JSON/CSV 的 Python 工具

综述（解读层）

该项目用于将 QQ 旧版 .bak 备份经 QQ 官方导入后、或已解密的 NTQQ 本地数据库（nt_msg.db 等）中的群聊/私聊记录导出为 TXT、JSON、CSV，附摘要与每日统计文件，支持日期过滤、关键词命中和导入前后新增消息对比，脚本默认仅读写本地文件。适用于需要以文本或结构化数据方式处理本机聊天记录、供 AI agent 读取的用户；加密数据库需先本地解密。

  • 读取已解密 NTQQ 数据库，导出群聊与私聊为 TXT、JSON、CSV
  • 支持日期过滤、关键词命中导出、导入前后新增消息对比及合成测试数据
  • 提供 Codex Skill 安装方式，脚本默认只读写本地文件

适用场景（解读层）

  • bak 备份文件经 QQ 官方导入后，从本地 NTQQ 数据库导出聊天记录
  • 生成 agent 可读的 TXT/JSON 消息数据供 AI 脚本处理
  • 按日期或关键词筛选消息，或对比导入后新增消息
