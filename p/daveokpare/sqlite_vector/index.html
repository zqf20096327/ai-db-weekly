基于 SQLite 与 NumPy 存储和查询向量的 Python 库

综述（解读层）

sqlite_vector 是一个 Python 脚本库，用于在 SQLite 数据库中存储和查询向量，借助 NumPy 进行向量运算。它提供基于欧氏距离的最近邻查询，支持自定义数据表与查询，并可配合 SentenceTransformer 嵌入做语义相似度搜索。依赖 Python 3.6+ 与 NumPy 1.19+，采用 MIT 许可证，适合希望在 SQLite 中管理嵌入向量的 Python 开发者。

  • 将向量以 NumPy 数组形式存储在 SQLite 数据库中
  • 基于欧氏距离对查询向量做最近邻搜索
  • 支持自定义数据库表和查询，可配合 SentenceTransformer 嵌入使用

适用场景（解读层）

  • 在本地 SQLite 中存储与检索嵌入向量
  • 基于 SentenceTransformer 嵌入进行语义相似度搜索
  • 在 Python 项目中扩展自定义数据表与向量查询
