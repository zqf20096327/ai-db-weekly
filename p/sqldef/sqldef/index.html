🧭 简介解读层（AI·证据行可回查）

用纯 SQL DDL 声明目标 schema 的幂等式数据库迁移工具

综述（解读层）

sqldef 是面向 MySQL、PostgreSQL、SQLite3 和 SQL Server 的 schema 管理工具：用户维护一份完整 schema 的 SQL 文件，工具对比当前与目标 schema 后生成并执行 DDL，可重复运行。各数据库对应独立命令，连接选项仿照原生客户端，支持 --export/--dry-run/--apply 工作流、离线文件对比模式，以及 @renamed 注解处理重命名。提供单二进制、Docker 镜像与 Homebrew 安装，MIT 许可。

  • 以普通 SQL DDL 描述目标 schema，对比当前与期望状态自动生成迁移 DDL，操作幂等可重复执行
  • 支持离线模式，可对两个 SQL 文件做对比，无需连接数据库，适用于 CI/CD 与 schema 校验
  • 通过 -- @renamed 注解支持表、列、索引和 ENUM 值的重命名；提供 --export/--dry-run/--apply 工作流

适用场景（解读层）

  • 维护单文件 schema 定义，通过编辑该文件来增删列、改约束、建索引并应用到数据库
  • 在 CI/CD 流水线中离线对比 SQL 文件做 schema 校验或生成迁移脚本
  • 配合 sqldef-preview-action 在 GitHub Actions 中预览 schema 变更
