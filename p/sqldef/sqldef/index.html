🧭 简介解读层（AI·证据行可回查）

基于声明式 SQL DDL 的幂等 schema 管理工具

综述（解读层）

sqldef 是一个 schema 管理工具，用户在单个 SQL 文件中定义目标 schema，工具将其与数据库当前 schema 比较并生成、应用迁移 DDL。针对 MySQL/MariaDB/TiDB、PostgreSQL、SQLite3、SQL Server 分别提供 mysqldef、psqldef、sqlite3def、mssqldef 命令，连接参数模仿原生客户端。以单二进制分发，无依赖。重命名需使用 @renamed 注解，Debian 包暂未提供。

  • 通过导出、编辑、dry-run 预览、apply 四步完成 schema 变更，重复执行不产生额外变更
  • 支持离线模式，比较两个 SQL 文件，无需连接数据库，可用于 CI/CD
  • 支持通过 -- @renamed 注解重命名表、列、索引和 ENUM 值

适用场景（解读层）

  • 以声明式方式管理 MySQL/PostgreSQL/SQLite3/SQL Server 数据库 schema
  • CI/CD 流水线中校验 schema 或生成迁移脚本
  • 在 GitHub Actions 中预览数据库 schema 变更（官方提供 sqldef-preview-action）
