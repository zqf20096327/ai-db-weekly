面向 Rust 的 DynamoDB 单表设计抽象库

综述（解读层）

Deez 是一个 Rust 库，用于简化在 DynamoDB 上实现单表设计。它提供 Deez 过程宏为结构体生成 From 转换 trait，并转换为 aws_sdk_dynamodb 所需的 HashMap<String, AttributeValue> 类型，可直接传给 DynamoDB 客户端。设计灵感来自 ElectroDB，适合在 Rust 服务或 Lambda 中使用 DynamoDB 的开发者。

  • 提供 Deez 过程宏为实体结构体定义 schema 并派生 From 转换 trait
  • 将结构体转换为 aws_sdk_dynamodb 所需的 HashMap 类型
  • 包含用于单表设计的附加功能，README 提供与 DynamoDB 客户端交互的示例

适用场景（解读层）

  • 在 Rust 项目中以单表设计模式操作 DynamoDB
  • 在 AWS Lambda 等 Rust 环境中与 aws_sdk_dynamodb 配合进行实体序列化
  • 需要将领域结构体直接转换为 DynamoDB AttributeValue 的场景
