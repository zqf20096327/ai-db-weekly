requests 库的持久化 HTTP 缓存，支持多种存储后端

综述（解读层）

requests-cache 是一个面向 Python requests 库的持久化 HTTP 缓存库，通过 CachedSession 替代 Session 或全局 install_cache 实现透明缓存。响应默认存为 SQLite 文件，也支持 Redis、MongoDB、DynamoDB 等后端。过期策略可用 expire_after 固定时间或启用 Cache-Control 头自动判断，默认不过期。

  • 提供 CachedSession 作为 requests.Session 的替代，并支持 install_cache 全局启用缓存
  • 支持 SQLite、Redis、MongoDB、DynamoDB 等存储后端，以及 JSON、YAML 等文件格式
  • 过期策略支持 expire_after 参数、Cache-Control 等 HTTP 头，及支持原生 TTL 的后端

适用场景（解读层）

  • 需要重复抓取相同 URL 的网络爬虫脚本
  • 调用响应更新频率低的 API 并希望减少重复请求
  • 在测试或演示中临时为 requests 请求添加缓存
