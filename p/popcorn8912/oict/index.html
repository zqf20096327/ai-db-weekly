🧭 简介解读层（AI·证据行可回查）

面向游戏、3D/AR/VR 与 AI 代理购物场景的开源交易完整性层。

综述（解读层）

OICT 提供规范、零运行时依赖的参考实现与可对任意服务运行的符合性套件，用于在 checkout 之前校验授权链、所见即所订快照、代理权限与未成年人保护等规则。适合在已有结账流程之上接入的交易平台团队；需 Node 22.18+，持久化部署依赖 PostgreSQL。

  • 以规范（RFC 2119，规则带稳定 ID）、参考实现和 HTTP 符合性套件（57 个用例、八个类别）三部分交付，实现零运行时依赖
  • 授权链、快照哈希确认、幂等键与一次性确认、Ed25519 签名令牌等保证在 PostgreSQL 数据库层强制执行，支持多实例部署
  • 提供 append-only 审计日志、Prometheus 指标、JWKS 公钥端点，以及带演示与基准脚本（demo/conformance/bench/test:cluster）的命令集

适用场景（解读层）

  • 为游戏、3D 世界、AR/VR 场景中的真实商品购买流程加入授权与确认校验层
  • 限制 AI 代理只能起草购物车、不能下单，并为未成年人订单启用监护人同意流程
  • 用符合性套件对自建实现进行规则验证，或通过注入异常基准检验幂等与撤销处理
