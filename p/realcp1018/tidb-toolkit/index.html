面向 TiDB/MySQL 的 Python 工具集，将大表 SQL 自动拆分为批次执行

综述（解读层）

该工具集面向 TiDB 与 MySQL 数据库，提供对含数十亿记录的大表执行 delete/update/insert-select 语句的能力，SQL 会按 rowid、主键 id 或时间列自动拆分为批次并行执行。另含查看 TiDB 集群 store/region 分布与核心配置的打印功能。用户通过编辑 tk.toml 配置文件后以 python3 脚本运行；tk_dml_by_time 不写 savepoint，失败需手动调整 start_time。

  • 支持 delete/update/insert-select 三类 SQL，可按 rowid、_tidb_rowid 或时间数值列自动拆分为任务/批次执行
  • tk_chunk_update 基于 order by rowid limit 产生 chunk，兼容设置 SHARD_ROW_ID_BITS 或 auto_random 的 TiDB 表
  • tk_dml_by_id 与 tk_chunk_update 运行时写入 savepoint，进程中断后重跑可从断点继续；可打印 TiDB 集群 stores/regions/labels 与核心配置

适用场景（解读层）

  • 对 TiDB/MySQL 上的数十亿级记录大表执行分批 delete/update 或 insert-select 数据处理
  • 排查 TiDB 集群数据分布，查看各 store 的 region 与 label 情况
  • 查看 TiDB 核心集群配置及相关告警信息
