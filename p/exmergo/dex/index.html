🧭 简介解读层（AI·证据行可回查）

为编码 agent 提供数据分析构建能力的技能工具，核心是 explore-transform-maintain 引擎

综述（解读层）

Dex 是 Exmergo 开发的 Agent Skills 工具集，让 Claude Code、Codex 等 agent 连接数据库与数据仓库，完成探索、dbt 建模与语义层维护。数据源保持只读，构建在 dev 目标执行，查询前先报价成本，凭据不进入 agent 上下文。需在 PATH 安装 uv 0.13.4+，且要求本地 shell，不支持 claude.ai 聊天。

  • 提供 explore（表画像、连接验证、PIE 标记、ER 图）、transform（dbt 模型与语义层）、maintain（schema 漂移检测）三类技能
  • 内置查询防火墙与成本护栏：仅允许 SELECT、按 connector 计量估算并设上限、花销记录于本地账本
  • 支持 Snowflake、BigQuery、Databricks、Redshift、Postgres、DuckDB、ClickHouse、Trino 连接器及 dbt、Ossie、SLayer、Cube 语义层

适用场景（解读层）

  • 在 Claude Code 或 Codex 中让 agent 探索仓库结构、生成带测试与文档的 dbt 模型
  • 数据源 schema、体量或指标定义变更后，对比快照检测漂移并生成待审修改
  • 通过 dex init --mode demo 在无数据库无凭据的本地 DuckDB 环境演练完整流程
