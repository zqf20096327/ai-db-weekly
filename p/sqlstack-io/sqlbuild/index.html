🧭 简介解读层（AI·证据行可回查）

SQL 数据转换框架，提供编译期检查、端到端测试与保留表历史的重命名。

综述（解读层）

SQLBuild 是开源 SQL 转换框架，面向数据工程师与分析师。其编译器与规划器用 Rust 编写，仓库执行用 Python；状态以 append-only 表存放在用户仓库中，不依赖外部状态库或清单文件。安装方式为 pip install sqlbuild，命令行工具为 sqb，支持 Snowflake、DuckDB、PostgreSQL 等，BigQuery、Databricks、SQL Server 适配器为 Beta。许可证为 Apache 2.0。

  • 提供编译期离线检查：解析引用、校验 SQL、推断列类型、检查契约并计算列级血缘，支持用 Python 编写自定义规则生成编译错误
  • 支持跨模型 SQL 测试与端到端场景：mock 数据源、在 CI 中于本地 DuckDB 回放 fixture，并提供审计与数据 diff
  • sqb rename/mv 更新全部引用并迁移已有表而非重建，旧名称通过兼容视图继续可用；replay_on_change 可按范围回放变更，sqb recall 以 SQL 查询历史运行记录

适用场景（解读层）

  • 在数据仓库管道变更（改名、移动模型）前预览影响并迁移已有表，避免全量重建
  • 在本地 DuckDB playground 中无凭据运行示例项目，并将 fixture 场景回放接入 CI
  • 将 Python loader、任务、检查与 SQL 模型置于同一执行图中，组织数据仓库 ELT 流程
