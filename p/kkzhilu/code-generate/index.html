🧭 简介解读层（AI·证据行可回查）

基于MySQL元数据与FreeMarker模板的Java代码生成器，建表后一键生成CRUD项目

综述（解读层）

Code-Generate是一个Java代码生成工具，读取MySQL表结构信息，配合FreeMarker模板生成基于SpringBoot与Mybatis的Maven项目，包含增删改、分页查询等Mapper XML及LayUi前端页面。使用者配置数据库连接、项目名、输出路径等参数后运行App.java即可得到可直接用IDE打开的工程，并支持通过继承接口添加自定义模板。需要JDK、MySQL、Maven及Lombok环境。

  • 通过MySQL内置表字段查询配合FreeMarker模板生成代码，含mybatis原生XML（增、批量增、删、批量删、多条件分页查询、列表查询、单一查询、修改等）
  • 支持拔插式拦截器（基于org.reflections实现），可在不改动已有代码的情况下扩展新模板
  • 可配置项目名、包名、作者、输出路径、包含表等参数，生成结果为Maven项目

适用场景（解读层）

  • 规律性的定制化开发，快速生成固定模式的CRUD代码
  • 作为简单开源项目示例，供初学者阅读学习其实现
  • 快速构建用于测试或演示用途的Demo项目
