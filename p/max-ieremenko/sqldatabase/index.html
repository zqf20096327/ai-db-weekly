跨 MSSQL Server、PostgreSQL、MySQL 的命令行与 PowerShell 数据库脚本与迁移工具

综述（解读层）

SqlDatabase 提供命令行工具和 PowerShell 模块两种形态，用于对 MSSQL Server、PostgreSQL 和 MySQL 执行 SQL 脚本、数据库迁移和数据导出。目标数据库类型从连接字符串关键字自动识别；脚本支持 .sql、.ps1 和 .NET 程序集三种形式，变量通过 {{VariableName}} 占位符在执行前替换，可从命令行、环境变量或配置文件解析。安装支持 PowerShell Gallery、GitHub release 手动导入或 dotnet global tool。

  • 支持 execute、export、create、upgrade 命令，可对 MSSQL Server、PostgreSQL、MySQL 执行脚本、迁移和数据导出
  • 通过连接字符串关键字自动识别目标数据库类型
  • 脚本支持 .sql 文本、.ps1 PowerShell 脚本和 .NET 程序集三种形式，变量支持从命令行、环境变量和配置文件解析

适用场景（解读层）

  • 在 CI/CD 或运维脚本中通过命令行执行数据库迁移升级
  • 从数据库查询结果导出生成 SQL 脚本文件
  • 以 SQL/PowerShell/程序集脚本配合变量替换的方式初始化或操作数据库
