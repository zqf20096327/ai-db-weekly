🧭 简介解读层（AI·证据行可回查）

将策略文件编译为 Postgres 行级安全策略的授权工具

综述（解读层）

rowstile 把声明式的策略文件编译成 Postgres 的视图、触发器维护表、行级安全策略及 authz.* 函数，应用通过 act_as 或 API key 标识请求者后由 RLS 过滤读写。策略变更以迁移形式输出，兼容 Alembic、Prisma、Drizzle 等多种迁移工具，无需额外运行授权服务。适用于数据在单一 Postgres 中、访问权限依赖行间关系（所有者、团队、共享、租户）的应用；项目处于 beta 阶段，尚未经外部安全审计。

  • 策略文件编译为 SQL 行级安全策略、视图、触发器表和 authz.* 函数，无需独立授权服务
  • 策略变更以迁移形式发布，兼容 Alembic、Django、Prisma、Drizzle Kit、Flyway 等迁移工具
  • 提供 Python 与 TypeScript SDK、编辑器扩展（VS Code/Zed/Tree-sitter）、CI 策略评审及浏览器 playground

适用场景（解读层）

  • 应用数据集中在一个 Postgres 数据库中，行访问权限依赖所有者、嵌套团队、文件夹继承、租户或用户间共享
  • 原本计划引入需与数据库保持同步的独立授权服务，或手写 RLS 难以测试和维护
  • 需要实现共享、分组、嵌套目录和多租户的细粒度访问控制的应用
