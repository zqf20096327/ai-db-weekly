Rust 语言的异步 Redis 客户端库，基于 RESP3 协议实现

综述（解读层）

Rustis 是面向 Rust 开发者的异步 Redis 客户端 crate，基于 tokio 运行时，仅使用 RESP3 协议（要求 Redis ≥6.0 且启用 RESP3）。提供单客户端、多路复用、连接池三种模式，支持集群、哨兵、事务、Pub/sub、TLS 与 LUA 脚本。最低 Rust 版本为 1.88，整个 crate 禁用 unsafe 代码。

  • 支持截至 Redis 8.8 的全部文档化命令，提供单客户端、多路复用与基于 bb8 的连接池模式
  • 支持集群、Sentinel、事务、Pub/sub、TLS、LUA 脚本与客户端缓存，配置可用 Redis URL 或 builder
  • 全 crate `#![forbid(unsafe_code)]`，通过 `tracing` 发出日志事件（兼容 `log`），帧大小与嵌套深度可通过 `Config::limits` 限制

适用场景（解读层）

  • 在 tokio 异步 Rust 应用中读写 Redis 数据
  • 连接 Redis Cluster 或 Sentinel 部署的客户端开发
  • 需要离线可验证测试套件或模糊测试解析器的场景
