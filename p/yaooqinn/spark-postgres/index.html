面向 Apache Spark 的 PostgreSQL/Greenplum 数据源库

综述（解读层）

该库为 Apache Spark 提供 PostgreSQL 与 Greenplum 数据源，支持通过 Spark SQL 和 DataFrame 读取数据库数据并向 Greenplum 传输数据，写入过程具备事务性。README 给出 CTAS 建表和临时表插入两种用法，选项配置方式与 Spark JDBC 数据源一致，需按 Spark 数据源方式注册使用。README 中宣称的数据传输速度为该项目自述，属未经独立验证的信息。

  • 支持从 PostgreSQL 和 Greenplum 数据库读取数据到 Spark SQL 与 DataFrame
  • 提供向 Greenplum 传输数据的写入能力，写入为事务性操作
  • 用法通过 CREATE TABLE ... USING greenplum 的 SQL 语法完成，配置方式与 Spark JDBC 数据源类似

适用场景（解读层）

  • 在 Spark 作业中读取 PostgreSQL 或 Greenplum 中的表数据进行分析
  • 通过 CTAS 或 Insert 语句将 Spark 数据写入 Greenplum 表
  • 需要写入操作具备事务保证的数据传输场景

A library for reading data from and transferring data to Greenplum databases with Apache Spark, for Spark SQL and DataFrames.
