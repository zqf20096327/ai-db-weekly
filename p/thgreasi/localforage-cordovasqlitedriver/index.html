为 Cordova 应用中 localForage 提供的 SQLite 存储驱动

综述（解读层）

该包为 localForage 实现 CordovaSQLiteDriver 驱动，将数据存储到底层 Cordova SQLite 插件，面向使用 Cordova/Ionic 框架的前端应用。使用时需先安装 Cordova SQLite 存储类插件，再通过 defineDriver/setDriver 注册启用，要求 localForage v1.5.0 及以上；不同 localForage 版本需选用对应旧版发布包。

  • 通过 defineDriver 和 setDriver 接入 localForage，底层依赖 Cordova-sqlite-storage、SQLite Plugin 2 或 sqlcipher-adapter 插件
  • 支持通过 config() 或 createInstance() 传入 dbKey 以配合 cordova-sqlcipher-adapter 使用
  • 提供 TypeScript 类型定义，并支持 localforage.dropInstance() 方法

适用场景（解读层）

  • Cordova 或 Ionic 应用中需要将 localForage 数据写入 SQLite 的情况
  • 使用 cordova-sqlcipher-adapter 进行加密数据库存取的场景
  • Ionic2/Angular2/TypeScript 项目（README 附有对应示例工程）
