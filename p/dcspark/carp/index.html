将 Cardano 链上数据同步至 Postgres 的模块化索引器

综述（解读层）

Carp 是一个 Cardano Postgres 索引器，包含两个组件：将链数据写入 Postgres 的 Rust 索引器（基于 Oura 与 CML）和提供 REST API 查询接口的 TypeScript web 服务器。面向钱包等需要查询地址交易历史的应用。全量同步约需 4-5 天，地址历史本地查询可低于 10ms；支持模块化启用所需数据库功能，数据以原始 CBOR/字节格式存储。

  • 由 Rust 编写的索引器使用 Oura 与 CML 将 Cardano 链数据同步到 Postgres 数据库
  • 模块化设计，可按需启用部分数据库功能
  • 附带 TypeScript 编写的 web 服务器，提供 REST API 用于查询数据库，并提供客户端 NPM 包

适用场景（解读层）

  • 为轻钱包等应用提供链上数据查询后端
  • 自建 Cardano 数据索引服务并自行解析 CBOR 原始数据
  • 搭建私有网络的数据索引（genesis 块解析，功能开发中）
