综述（解读层）

Sequelize 是一个面向 Node.js 和 TypeScript 的 ORM 工具，用于 Postgres、MySQL、MariaDB、SQLite、DB2、SQL Server、Snowflake、Oracle DB 等数据库。它提供事务支持、关系定义、预加载与懒加载、读写分离等能力。README 注明 v6 为稳定版、v7 为 alpha 版，且项目正在公开招募新维护者以推进下一主版本发布。

  • 支持 PostgreSQL（含 JSON/JSONB）、MySQL、MariaDB、SQLite、SQL Server、Snowflake、Oracle DB、DB2 及 DB2 for IBM i
  • 提供事务支持、关联关系、eager/lazy 加载与读写复制
  • 提供 v6 稳定版与 v7 alpha 版两套入门文档，附带 CLI 工具及升级指南

适用场景（解读层）

  • Node.js/TypeScript 应用中需要以 ORM 方式操作关系型数据库
  • 同一代码需连接多种数据库（如 PostgreSQL 与 MySQL）的场景
  • 需要事务、关联加载或读写复制能力的后端服务
