🧭 简介解读层（AI·证据行可回查）

Go 编写的自托管 NVR，单静态二进制、内嵌 Web UI，支持多协议接入与自适应录像。

综述（解读层）

MiBee NVR 是一个用 Go 实现的网络视频录像机（NVR），以单个静态二进制分发，内嵌 Svelte Web UI，使用 SQLite 存储。它接入 RTSP/ONVIF/GB28181/Xiaomi/WHIP 等来源，提供 WebRTC/HLS/FLV 播放和浏览器端 AI 检测。安装提供一键脚本、Docker 与预编译二进制（AMD64/ARM64/ARMv7）三种方式。README 称其面向 512MB 内存预算的低功耗 ARM 设备，性能数据为项目自测结果。许可证为 AGPL-3.0。

  • 支持 RTSP、ONVIF、GB/T 28181、Xiaomi（CS2/TUTK）、WHIP、SRT/RTMP 推流等多种接入协议，输出 WebRTC (WHEP)、HLS/LL-HLS、HTTP-FLV，并可经 RTSP/RTMP 中继推送
  • 自适应录像：基于压缩域 P 帧尺寸分析（不解码），静默场景降至 timelapse 级基线，遇码率尖峰、响亮音频、像素域 CV、ONVIF 移动事件或语义触发 API 恢复全帧率
  • 提供约 100 项 Prometheus 指标、Grafana 仪表盘、结构化 slog 日志及可选 OpenTelemetry 追踪

适用场景（解读层）

  • 在树莓派等低功耗 ARM 设备或 NAS（unRAID/群晖/QNAP 等）上自托管多摄像头录像
  • 需要 GB/T 28181 国标设备接入与 SIP 门铃（Doorbird/Akuvox/Hikvision）对讲的监控场景
  • 与 Prometheus/Grafana、Home Assistant、MQTT 集成的可观测性与家庭自动化联动部署
