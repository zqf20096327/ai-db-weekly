开源自托管在线状态监控与状态页，运行于 Cloudflare Workers + Postgres 或单容器 Docker

综述（解读层）

OpenUptime 是开源的在线状态监控与状态页系统，基于 MIT 许可发布。它支持 HTTP/HTTPS、TCP、DNS、WebSocket、数据库等多种监控类型，提供事件管理、公共状态页和多渠道告警。部署方式有两种：Cloudflare Workers（API 与 Web 两个 Worker）加外部 Postgres，或单个 Docker 容器（compose 文件内置 Postgres）。注册可通过配置关闭，适合自托管。

  • 支持 HTTP/HTTPS（含关键词匹配与慢响应告警）、TCP、DNS、WebSocket、心跳推送、PostgreSQL/MySQL/Redis、域名到期及 EVM/Solana RPC 节点等监控类型，并支持多区域探测与监控依赖关系
  • 提供事件确认、分配与复盘、维护窗口、公共状态页、Email/RSS 订阅、状态徽章，以及 Slack/Discord/Telegram/PagerDuty 等多渠道告警
  • 提供 REST API 与 MCP 服务器（OAuth 或 API key 鉴权），供 AI 代理管理监控项、事件和状态页

适用场景（解读层）

  • 为 cron 任务和后台服务配置心跳推送监控，服务异常时通过 Slack、Telegram 等渠道接收告警
  • 自托管部署公共状态页，向访问者提供事件公告与 Email/RSS 订阅
  • 通过 REST API 或 MCP 服务器将监控、事件与状态页管理集成到自动化流程或 AI 代理工作流中
