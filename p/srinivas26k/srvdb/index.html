🧭 简介解读层（AI·证据行可回查）

SrvDB 是一个嵌入应用进程内的开源向量数据库库，用 Rust 实现，面向 Python 与 Rust。

综述（解读层）

SrvDB 是以库形式运行的向量数据库，将向量（embedding）存储在本地磁盘，进程内调用，无服务器、Docker 或网络连接。通过 pip 或 cargo 安装，提供 flat、hnsw、ivf、sq8、pq、auto 等索引模式。README 声明 persist() 返回后数据可在崩溃或断电后恢复，每个写入路径附有崩溃测试。适用于需要在本地存储向量数据、进程内完成最近邻检索的 Python 或 Rust 项目。

  • 以库形式嵌入应用进程运行，无需服务器、Docker 或网络连接，支持完全离线使用
  • 提供 exact、hnsw、ivf、sq8、pq、auto 等索引模式，支持 128–4096 维的嵌入向量，sq8 与 pq 可减少存储占用（README 标注 4×至最多 32×）
  • 声明持久化保证：persist() 返回后数据可承受进程崩溃或断电，每个写入路径配有崩溃测试；线程安全，Python 调用释放 GIL

适用场景（解读层）

  • 结合本地嵌入模型与本地 LLM 搭建本地 RAG 流程
  • 为 AI agent 实现跨重启的向量记忆存储
  • 在桌面、CLI 应用或离线/隔离环境中进行语义搜索，需求数据保留在本机
