🧭 简介解读层（AI·证据行可回查）

一组即用型 Shell 脚本合集，覆盖备份、恢复、服务管理与自动化

综述（解读层）

该仓库收录多个独立 Shell 脚本：通过 Rclone 将 Vaultwarden 备份至 Cloudflare R2、为 Android Termux/Udocker 生成 docker compose 并实现开机自启、管理 Pangolin 的 Newt VPN 客户端 systemd 服务、Stalwart 邮件服务器的 TLSA 记录更新与 PostgreSQL 及文件的完整备份恢复，以及断电后用 rtcwake 自动开机。适用于自托管服务维护者。README 提醒使用前须审查脚本内容。

  • 支持通过 Rclone 与自定义 cron 任务将 Vaultwarden Docker 容器备份/恢复到 Cloudflare R2
  • 提供 Termux 环境下的单容器 docker compose 脚本，可用 termux-boot 与 termux-services 在 Android 解锁后启动服务，已在无 Root 手机上测试
  • 包含基于提示交互的 Newt VPN 客户端管理脚本，支持安装、更新二进制、移除 systemd 服务，兼容 OLM 与 Native 模式

适用场景（解读层）

  • 自托管 Vaultwarden 或 Stalwart 邮件服务器时的定期备份与恢复
  • 在 Android 手机 Termux 环境中运行容器服务并随开机解锁自动启动
  • AC 断电恢复后自动唤醒局域网内设备，或管理 Pangolin Newt VPN 客户端服务
