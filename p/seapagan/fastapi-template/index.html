带认证、用户管理与 CLI 的 FastAPI 项目模板

综述（解读层）

该仓库是一个 FastAPI 应用模板，内置用户注册/登录、JWT 认证、API Key、密码恢复与刷新令牌机制，数据库使用 SQLAlchemy 2.0 异步访问 PostgreSQL 并由 Alembic 管理迁移。另含基于 Typer 的命令行工具、sqladmin 管理页面、缓存与限流（默认关闭）、Prometheus 指标及 Docker Compose 配置。要求 Python 3.10+，作者注明仍在活跃开发中，建议使用正式 Release。通过 GitHub 的 'Use this template' 按钮创建新仓库后克隆使用。

  • 提供注册、登录、密码恢复（30 分钟限时 token）与 30 天刷新令牌流程，JWT 有效期 120 分钟，另支持经 X-API-Key 头传递的 API Key 认证
  • 使用 SQLAlchemy 2.0 异步访问 PostgreSQL，Alembic 管理数据库迁移，附带用户增删改查/封禁路由与 fastapi-pagination 分页
  • 包含基于 Typer 的 CLI、loguru 分类日志、可选内存/Redis 缓存与限流（默认关闭）、Prometheus /metrics 端点、sqladmin 管理站点，并提供 Docker Compose 开发环境（容器内 API 端口为 8001）

适用场景（解读层）

  • 以 FastAPI 启动需要用户注册、登录与 JWT/API Key 认证的后端 API 项目
  • 需要 PostgreSQL 异步 ORM 访问并使用 Alembic 管理数据库迁移的项目
  • 需要 CLI 管理用户、批量生成测试数据或使用 Docker 容器进行本地开发与测试
