🧭 简介解读层（AI·证据行可回查）

纯 Erlang 编写的 Ecto 风格数据库层，含 schema、changeset、查询构建与迁移。

综述（解读层）

Kura 是面向 Erlang 开发者的数据访问层，借鉴 Elixir Ecto 的抽象，采用 behaviour 定义 schema 与 repo，支持 changeset 校验、可组合查询、迁移和多租户。后端可插拔：PostgreSQL 经 minato，SQLite 经 esqlite。依赖以 kura 及对应 backend 加入 deps，并在 sys.config 的 kura 应用下配置连接池。

  • 提供 schema、changeset、组合式查询构建器、迁移与 Multi 事务管道，SQL 经参数化编译生成
  • 支持 belongs_to/has_one/has_many/many_to_many 关联预加载、复合主外键、JSONB 嵌入 schema、游标与偏移分页及服务端游标流式读取
  • 提供 AES-256-GCM 字段加密（{encrypted, Type}）、多密钥轮换、向量类型 {vector, N} 映射 pgvector，以及 schema 前缀和属性两种多租户隔离方式

适用场景（解读层）

  • Erlang/OTP 项目中需要 Ecto 风格 schema 与 changeset 抽象的 PostgreSQL 或 SQLite 数据访问
  • 需要 DDL 迁移、审计追踪、乐观锁与 telemetry 查询日志的应用
  • 需要在字段级静态加密或基于 pgvector 做嵌入向量存取的场景
