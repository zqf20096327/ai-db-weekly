drt 是基于 YAML 配置、以 CLI 运行的开源反向 ETL 工具

综述（解读层）

drt 是一个开源反向 ETL 工具，将数据仓库中的数据同步到业务工具侧，采用 dbt 风格的 YAML 声明式配置并纳入 Git 管理。用户通过 drt init 初始化项目、drt plan 预览变更、drt apply 写入，支持 BigQuery、DuckDB、PostgreSQL、Snowflake 等源。内置 MCP 服务器和 Claude Code 技能，可用于 AI 环境中运行与调试同步。

  • 提供 drt plan / drt apply 工作流，apply 在数据或配置变更后拒绝写入，并支持 max_delete_pct 等删除防护
  • 支持 write_policy: fill_empty 写入策略，仅填充目标为空的字段
  • 内置 MCP 服务器（约 20 个工具）与 Claude Code 技能，提供连接器、CLI、同步引擎，Apache 2.0 协议

适用场景（解读层）

  • 将数据仓库中的模型结果同步回 Slack、HubSpot、Google Sheets 等业务工具
  • 在 GitHub Actions、Dagster、Airflow、Prefect 等编排环境中以 CLI 方式运行同步
  • 借助 MCP 服务器或 Claude Code 技能，在 AI 工具中生成、验证和运行同步配置
