Vapor 框架的 MongoDB Provider，通过 Fluent 驱动接入 MongoDB。

综述（解读层）

该包为 Vapor Web 框架提供 MongoDB 支持，以 Provider 形式注册到 Droplet，并将 Fluent 的驱动配置为 mongo。使用者通过 Package.swift 引入依赖，凭 url 连接数据库，配置文件可放在 secrets 目录避免提交，也支持代码内手动配置。适用于使用 Vapor 2 并以 MongoDB 作数据存储的 Swift 服务端项目，已在 macOS 与 Ubuntu 上测试。

  • 以 Provider 形式加入 Droplet，并在 fluent.json 中将 driver 设为 mongo 启用
  • 支持 JSON 配置文件与代码内手动配置两种方式
  • 主机与端口可选，配置文件可置于 secrets 目录且默认被 .gitignore 排除

适用场景（解读层）

  • 为 Vapor 项目接入 MongoDB 作为数据库驱动
  • 需要将数据库凭据与代码分离管理的部署场景
  • 在 macOS 或 Ubuntu 上开发 Swift 服务端应用
