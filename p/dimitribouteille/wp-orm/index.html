基于 Laravel Eloquent 的 WordPress ORM 库，复用 wpdb 连接

综述（解读层）

这是一个将 Eloquent ORM 引入 WordPress 的 PHP 库，为文章、用户、评论、术语等核心表提供模型，并复用 WordPress 自带的 wpdb 数据库连接，无需额外配置。要求 PHP >= 8.3、WordPress >= 6.3，通过 Composer 安装。支持 WP-CLI 迁移命令与自定义表模型；当前版本不支持 Multisite，且默认所有字段可批量赋值。

  • 内置核心 WordPress 模型：Post、User、Comment、Option、Term 及各类 Meta，支持文章、附件、页面类型
  • 复用 wpdb 连接，安装后无需配置数据库；提供 meta 过滤函数与 meta 属性转换
  • 通过 WP-CLI 提供数据库迁移（wp orm migrate），支持自定义文章类型和自定义表模型

适用场景（解读层）

  • 在 WordPress 插件或主题中以面向对象方式读写核心数据表
  • 为自定义数据表创建 Eloquent 模型并通过 WP-CLI 管理迁移
  • 使用 Eloquent 的查询构建器、关联关系与事务等特性操作 WordPress 数据
