基于 .erd.json 文件的 ERD 可视化编辑器，可在浏览器与 IDE 中运行

综述（解读层）

ERD Editor 是一个实体关系图编辑器，用于可视化设计数据库模式，数据以单个 .erd.json 文件保存。它以 Web 应用（erd-editor.io）、VS Code/JetBrains/Obsidian 插件、Google Drive 应用和 npm 包（custom element）多种形式提供。支持导入 SQL DDL、GraphQL SDL、DBML，导出八种数据库的 DDL 与 22 种语言/ORM 代码，并通过 MCP 服务器让编码代理实时编辑图表。

  • 导入 SQL DDL、GraphQL SDL、DBML 和 AML，导出八种数据库（PostgreSQL、MySQL、Oracle、SQLite 等）的 DDL、22 种语言与 ORM 代码及 PNG/SVG 图片
  • 通过 @dineug/erd-editor-mcp MCP 服务器供 Claude Code、Codex 等编码代理编辑图表，代理在协作会话中的撤销只回退其自身编辑
  • 提供 编辑器与只读 两个 custom element，可不依赖框架嵌入任意页面；Web 端支持基于 WebRTC 与 AES-GCM 加密的实时协作

适用场景（解读层）

  • 在浏览器或 IDE 中可视化设计数据库表结构与关系，并以 .erd.json 文件在多端之间共享同一份图表
  • 从现有 SQL DDL、DBML 或 GraphQL SDL 导入模式，再生成目标数据库的 DDL 或 TypeScript、Java、Go 等语言的 ORM 代码
  • 让编码代理通过 MCP 直接修改模式文件，同时开发者在画布上实时查看变更
🔌 适配哪些库db_scan 程序判定

MariaDB、MySQL、Oracle、PostgreSQL、SQL Server、SQLite
