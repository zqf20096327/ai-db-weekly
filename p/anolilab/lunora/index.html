🧭 简介解读层（AI·证据行可回查）

基于 Cloudflare Workers 与 Durable Objects 的 TypeScript 类型安全实时后端框架

综述（解读层）

Lunora 让开发者在自己的 Cloudflare 账户上获得 Convex 风格的开发体验：以 TypeScript 编写 schema、query、mutation，本地经 Vite/workerd 运行，生产部署到 Workers，实时状态由 Durable Objects 承载，D1 存 SQL、R2 存文件。支持单 DO 通过 .shardBy() 分片。项目处于 alpha 阶段，npm 包名为 lunorash。

  • 提供端到端类型安全的 schema、验证器、查询与客户端 hooks，开发服务器在保存时自动重新生成客户端类型
  • 客户端通过 WebSocket 订阅实时查询，mutation 变更推送至所有订阅者
  • 功能以 @lunora/* 包形式提供，包括 auth（基于 better-auth）、存储、定时任务、MCP server 等；React/Vue/Solid/Svelte/Angular/React Native 客户端适配器与 Python/Go/Rust 等语言的 SDK 生成

适用场景（解读层）

  • 希望将全栈应用部署到自己控制的 Cloudflare 账户上、使用 Workers/D1/R2/Queues 基础设施
  • 需要实时数据订阅的前端应用（React/Vue/Svelte 等多框架项目）
  • 需要通过 MCP 客户端让 AI agent 检查和调试部署的应用
