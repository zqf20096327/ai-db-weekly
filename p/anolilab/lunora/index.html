运行在自有 Cloudflare 账户上的 TypeScript 类型安全实时后端框架

综述（解读层）

Lunora 是一个面向全栈开发者的实时后端框架，提供类似 Convex 的开发体验：以 TypeScript 编写查询、变更和动作，本地通过 Vite/Rsbuild/Rspack 集成并在 workerd 上运行，生产环境部署到用户自己的 Cloudflare 账户（Durable Objects 管理实时状态、D1 存储 SQL 数据、R2 存储对象）。认证、存储、调度及 MCP 服务器以 @lunora/* 包形式提供。当前处于 Alpha 阶段，npm 包名为 lunorash，首个稳定版发布前可能出现破坏性变更。

  • 提供端到端类型安全：schema、校验器、查询结果与客户端 hooks 源于同一来源，开发服务器在保存时重新生成客户端类型
  • 查询为实时订阅模式：客户端通过 WebSocket 订阅，变更推送到所有订阅者；支持 .shardBy(key) 将应用从单个 Durable Object 扩展到多分片，.global() 提供地理复制读取
  • 核心不依赖 Cloudflare API：响应式引擎通过 @lunora/platform 中的主机契约通信，各目标有标注功能为原生、模拟或不支持的能力矩阵；@lunora/mcp 向 MCP 客户端暴露部署的表、函数、日志与问题

适用场景（解读层）

  • 在自有 Cloudflare 账户上构建需要实时数据同步的全栈应用，避免将生产基础设施托管在第三方 SaaS 上
  • 使用 React、Vue、Solid、Svelte、Angular 等前端框架开发，需要类型安全的客户端 hooks 与自动代码生成的项目
  • 需要 AI 代理通过 MCP 检查和调试应用（表、函数、日志、问题）的部署场景
