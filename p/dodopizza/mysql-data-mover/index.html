MySQL 数据迁移 CLI 工具，基于多线程队列并行搬运表数据

综述（解读层）

这是一个 .NET 编写的命令行工具，用于在两个 MySQL 数据库之间移动数据。它读取源库表元数据，按主键生成数据范围的 ReadCommand 放入队列，由多个读取任务并行读取、写入任务并行插入目标库，每个命令支持重试（默认最多 5 次，线性退避）。需提供源/目标连接字符串，通过 appsettings.json、环境变量或命令行参数配置；无主键表按整表作为数据范围。

  • 按表主键列生成数据范围命令，多线程并行读取和插入，支持每命令重试与线性退避
  • 可在迁移开始时复制数据库 schema（表、视图、存储过程、触发器）
  • 提供约 25 项配置参数，包括并发数、批大小、超时、表正则过滤、行数限制、INSERT IGNORE、字符集/排序规则覆盖等

适用场景（解读层）

  • 将一个 MySQL 数据库的数据和 schema 迁移到另一个数据库
  • 需要并行搬运大表并控制每表行数上限或按正则筛选表
  • 需要跳过特定列值或在目标库忽略主键重复行的迁移场景
📖 README 首段存档原文 · 程序抽取

This application moves data from one Mysql database to another. It is faster and more robust than mysqldump utility, has ability to move data in parallel threads with retries.
