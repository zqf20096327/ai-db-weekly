检查 SQLite ATTACH DATABASE 陷阱的静态/动态 lint 工具

综述（解读层）

sqlite-attach-lint 是一个 Python 编写的 SQLite ATTACH DATABASE 检查工具，可在 SQL 运行前发现跨库事务原子性风险、别名冲突、未限定表名歧义和超出附加上限等问题。通过 pip 安装，可用作 CLI 或库调用，支持传入 --db 实际重放 ATTACH/DETACH 语句以检查真实连接状态。适用于维护含 ATTACH 的迁移脚本的团队。需 Python 3.11+，无运行时依赖。

  • 支持 CLI 与 Python 库两种调用方式（check_sql/check_file/check_directory/check_connection），可检查 .sql 文件、目录或内联 SQL
  • 配合 --db 可重放目标 SQL 中的 ATTACH/DETACH 语句（不执行 INSERT/CREATE 等），读取真实的附加上限、journal mode 与表名解析结果
  • 退出码区分四种结果：0 无发现、1 有 WARN/ERROR、2 存在无法分类的语句、3 用法错误

适用场景（解读层）

  • 在 CI 或本地检查含 ATTACH DATABASE 的 SQL 迁移脚本，提前发现别名冲突与未限定表名引用
  • 用 --db 连接真实数据库，验证 SQLITE_LIMIT_ATTACHED 实际编译值与各 schema 的 journal mode
  • 排查跨库事务原子性条件（main 为 :memory: 或任一库为 WAL 模式）是否被触发
