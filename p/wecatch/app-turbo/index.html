基于 Tornado 的 Web 框架，用于快速构建网站与 RESTful API

综述（解读层）

Turbo 是基于 Tornado 的 Python Web 框架，面向希望以 Django/Flask 式项目结构开发 RESTful API 和网站的开发者。内置简易 MongoDB ORM、日志和 Session（支持 Redis、磁盘等存储），通过 turbo-motor 支持 MongoDB 异步驱动 Motor，兼容 Python3，可通过 pip 安装并使用 turbo-admin 创建项目。

  • 提供简易 MongoDB ORM，并通过 turbo-motor 支持 Motor 异步驱动
  • 支持 MongoDB、MySQL、PostgreSQL 等数据库
  • 提供 Session 存储（支持 Redis、磁盘等）与日志功能

适用场景（解读层）

  • 基于 Tornado 构建 RESTful API 服务
  • 以 Django/Flask 风格目录结构组织 Tornado Web 应用
  • 需要 MongoDB（含 Motor 异步）或 MySQL/PostgreSQL 数据访问的 Python3 Web 项目
