本地生物识别门控的凭据代理，为 AI 代理分发短时效、可审计的凭据

综述（解读层）

briefcred 是一个运行在本机的凭据代理：真实密钥保存在守护进程中，子进程只持有占位符令牌，由本地代理按 Cedar 策略替换为真实密钥，支持 Postgres 动态角色、AWS STS、SSH 证书的一次性签发与会话结束撤销，并有 Touch ID 门控与 JSONL 审计日志。面向在终端运行 AI 代理的开发者，当前为 alpha 版，尚未经外部安全评审。

  • 本地 TLS 代理支持 HTTP/1.1、HTTP/2、SSE、WebSocket 与 gRPC，按 Cedar 策略逐请求判定并施加会话配额
  • 可签发 Postgres 动态角色、AWS STS 会话与 SSH 证书，会话关闭即撤销
  • 记录铸造、请求、拒绝与撤销的 append-only JSONL 审计日志，并提供 Prometheus 指标端点

适用场景（解读层）

  • 让本地运行的 AI 代理调用 OpenAI/Anthropic/GitHub/Stripe 等 API 而不直接接触真实密钥
  • 为一次性数据库命令或 SSH 堡垒会话签发用后即撤销的短期凭据
  • 需要对凭据使用情况进行 Touch ID 确认与审计留痕的开发工作流
