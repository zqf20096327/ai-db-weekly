🧭 简介解读层（AI·证据行可回查）

VS Code 内直接查看与编辑 SQLite 数据库文件的扩展

综述（解读层）

该扩展面向需要在 VS Code 中处理 SQLite 数据库文件的开发者，支持直接打开 .db、.sqlite、.sqlite3 文件。它提供表与行的增删改查、全局与列级过滤、多格式导出，以及跨重启保留的撤销/重做历史。运行于 VS Code webview 沙箱，完全本地执行，不发送遥测数据；要求 VS Code 1.85.0 及以上。

  • 支持表与行的创建、读取、更新、删除，编辑历史可跨 VS Code 重启保留
  • 支持全局搜索与列级过滤，提供 >、<、=、前后缀匹配、非空、取反等操作符
  • 可导出为 CSV/TSV、Excel、JSON、HTML、Markdown、SQL INSERT 等格式

适用场景（解读层）

  • 在编辑器中直接查看和修改 .db/.sqlite/.sqlite3 文件
  • 将 SQLite 表数据导出为 CSV、Excel、JSON 等格式用于表格分析或程序处理
  • 通过过滤与排序浏览大表的特定数据子集
