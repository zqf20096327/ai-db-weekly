基于 Python 3 的数据库引擎，提供类 Django ORM 并自控磁盘存储格式

综述（解读层）

Alkali 是用 Python 3 编写的数据库引擎，目标是提供类似 Django 的 ORM 接口，同时由使用者控制数据在磁盘上的存储格式。README 将其定位为处理 json/yaml/csv 等文件数据的工具，并说明已有 Postgres 等数据库的场景适用 SQLAlchemy。可通过 pip 安装，文档站点提供快速入门指南。

  • 用 Python 3 实现数据库引擎，提供类 Django 风格的 ORM
  • 可控制数据在磁盘上的存储格式
  • 支持 pip install alkali 安装，测试使用 pytest 运行

适用场景（解读层）

  • 数据存放在 json/yaml/csv 等文件中、希望以 ORM 方式读写的场景
  • 需要类似 Django ORM 的模型接口但不使用传统数据库的场景
  • 需要修改源码并参与开发测试的场景（pip install -e .[dev]）
