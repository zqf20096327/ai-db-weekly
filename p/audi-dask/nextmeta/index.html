综述（解读层）

NextMeta 是一款数据库 SQL 审核平台，聚焦安全防护与性能优化，提供统一查询入口、工单审批和审计追踪能力，支持 MySQL 与 PostgreSQL 数据源。提供一键安装脚本，启动后通过 8080 端口访问，默认账号需登录后修改。路线图显示 PG 方言解析、静态审核规则、工单全流程等功能仍在开发中。

  • 提供统一的 SQL 查询入口、工单审批和审计追踪功能
  • 支持 MySQL 与 PostgreSQL 数据源接入，含元数据采集与 EXPLAIN（PG FORMAT JSON）
  • 提供一键安装脚本，启动后通过 localhost:8080 访问

适用场景（解读层）

  • 团队需要统一入口执行数据库查询并保留审计记录
  • DDL/DML 变更通过工单审批流程执行
  • 查询结果返回列的脱敏处理场景
