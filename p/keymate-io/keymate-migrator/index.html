基于 Quarkus 的规模化 Keycloak 用户迁移工具，支持断点续跑与持久化重试

综述（解读层）

Keymate Migrator 是一款用于将用户账户与身份批量迁入 Keycloak 的开源工具，面向企业、SaaS 服务商及身份系统现代化项目。其核心机制包括：以 PostgreSQL 工作队列领取任务、限制并发数、失败记录先写入磁盘分片 outbox 再按退避策略延迟重试，进度持久化支持停止后恢复。技术栈为 Java 21+、Quarkus、Mutiny 与响应式 PostgreSQL 客户端，配置经 application.properties 完成，附 Apache 2.0 许可。

  • 以 PostgreSQL 工作队列驱动任务领取，进度持久化，可停止后恢复且不重复处理已完成数据
  • 失败记录带错误上下文与下次重试时间戳，先持久化到磁盘分片 outbox，再按受控退避延迟重试
  • 内置模拟环境：mock REST 服务器可配置延迟、错误率与客户端/服务端错误比例，并提供 SQL 脚本生成百万级测试数据

适用场景（解读层）

  • 将数百万级用户账户与身份批量导入 Keycloak 的迁移项目
  • 需要迁移过程可中断恢复、失败可追溯的批量导入场景
  • 在无需真实 Keycloak 实例时通过模拟环境测试迁移与重试行为
