🧭 简介解读层（AI·证据行可回查）

语义知识图谱，为概念提供 grounding 评分、保留分歧并溯源。

综述（解读层）

该系统从 PDF、markdown、图片等文档中提取概念与关系，写入 PostgreSQL + Apache AGE 图数据库，每个概念带有依据支持与矛盾证据计算出的 grounding 分数（-1 到 +1），并保留来源分歧、支持追溯原始证据。面向需要证据溯源、AI 记忆或语义检索的团队；提供 FastAPI 后端、React/D3 可视化、CLI 与 MCP 服务器，可选 Ollama 本地推理，Docker 部署。

  • 每个概念携带依据支持与矛盾证据计算的 grounding 分数，并保留来源间的分歧
  • 支持 PDF、markdown、图片等文档摄入，概念可追溯至原始文本或图像证据
  • 可经 FUSE 挂载为文件系统使用 ls/grep/find 操作，并提供 MCP 服务器供 AI 助手查询

适用场景（解读层）

  • 研究综述：跨论文查找概念关联与作者分歧，查看各论断支持强度
  • AI 助手持久记忆：通过 MCP 服务器查询图谱并在作答前核对置信度
  • 合规审计：依据完整溯源链，将每个概念追踪至来源证据
