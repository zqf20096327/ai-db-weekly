基于miniob框架的OceanBase大赛预选赛代码实现

综述（解读层）

该仓库是团队参加OceanBase大赛预选赛的miniob数据库代码实现。miniob是面向在校学生的简化数据库教学系统，包含网络、SQL解析（flex/bison）、计划执行、元数据管理等模块，未实现并发、查询优化等部分。仓库还包含编译运行方法、输出约束和华东师大数据库实现课程资料。

  • 基于flex/bison实现SQL词法与语法解析，生成语法树
  • 采用seda异步事件框架和libevent进行网络IO处理，TCP纯文本协议以'\0'为消息终结符
  • 使用cmake管理构建，要求cmake≥3.14、C++14标准，基础版支持int、float、char三种字段类型

适用场景（解读层）

  • 参加OceanBase大赛预选赛，练习数据库内核模块开发
  • 学习数据库内核各模块功能与SQL执行流程
  • 配合华东师大数据库系统实现课程进行存储、查询、事务等实验
📖 README 首段存档原文 · 程序抽取

miniob设计的目标是让不熟悉数据库设计和实现的同学能够快速的了解与深入学习数据库内核，期望通过miniob相关训练之后，能够对各个数据库内核模块的功能与它们之间的关联有所了解，并能够在使用时，设计出高效的SQL。面向的对象主要是在校学生，并且诸多模块做了简化，比如不考虑并发操作。
