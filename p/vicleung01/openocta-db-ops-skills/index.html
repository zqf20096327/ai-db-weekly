面向 OpenOcta 的 8 个数据库运维技能包，附参考 MCP 服务器

综述（解读层）

该项目为 OpenOcta AI Agent 提供一组数据库运维技能工作流，覆盖 MySQL/MariaDB/TiDB 的慢查询、复制延迟、死锁、容量、Schema 审计与集群巡检，源自作者管理 600+ 实例的 DBA 实践。技能依赖暴露 9 个 db_* 工具的 MCP 服务器，仓库附带 Python 参考实现与端到端冒烟测试示例；破坏性操作（如 KILL）需二次确认。不包含 Redis 和 PostgreSQL 工作流。适用于使用 OpenOcta 并管理上述三类数据库的运维场景，采用 Apache 2.0 许可证。

  • 包含 8 个技能：慢查询诊断、复制延迟处理、批量健康检查、SQL 时长尖峰检测、容量预警、死锁分析、TiDB 集群巡检、Schema 审计
  • 提供参考 Python MCP 服务器，暴露 db_query、db_kill_query、db_get_slow_log 等 9 个 db_* 命名工具
  • 破坏性操作（KILL）需用户双重确认，支持映射兼容任意 MCP 服务器

适用场景（解读层）

  • 通过 OpenOcta 对话式诊断 MySQL/MariaDB/TiDB 的慢查询、复制延迟与死锁问题
  • 对多实例数据库集群执行批量健康巡检与容量增长预警
  • 进行 Schema 审计（主键、引擎、字符集、冗余索引、自增溢出等检查）
