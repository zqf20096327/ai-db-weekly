基于 Electron + React + tRPC + SQLite 的 TypeScript 桌面应用启动模板

综述（解读层）

该仓库是一个 pnpm monorepo，包含 template 目录下的 Electron 应用模板（通过 degit 复制使用）和 Next.js + Nextra 构建的文档站点。模板以 React 19、TanStack Router/Query、Tailwind CSS、Drizzle ORM 搭配 SQLite，通过 tRPC 实现端到端类型化 IPC，并集成 electron-builder、electron-updater、GitHub Actions 等发布流程。开发要求 Node.js 22.12+ 和 pnpm，模板本身用 npm 安装。项目采用 MIT 许可证。

  • 提供 tRPC + Zod 的端到端类型化 IPC，数据层为 SQLite 搭配 Drizzle ORM 的类型化查询与迁移
  • 包含 electron-builder 打包、electron-updater 自动更新、GitHub Actions 构建签名发布流程，以及主进程 V8 字节码编译
  • 内置 LicenseManager.dev 许可证密钥与激活、Stripe 支付集成，前端提供 i18next 类型化翻译与明暗主题

适用场景（解读层）

  • 使用 `npx degit nick-keller/electron-appstack/template` 复制模板后以 `npm install && npm run dev` 启动新桌面应用项目
  • 需要本地 SQLite 数据存储、类型安全 IPC 通信的 Electron 应用开发
  • 计划通过自动更新、代码签名和许可证密钥分发付费桌面软件的团队
