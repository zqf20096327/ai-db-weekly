基于 Docker Compose 的 Laravel + PostgreSQL 本地开发环境模板

综述（解读层）

该项目提供一套用 Docker Compose 编排的 Laravel 开发环境，容器包含 PHP 8.4-FPM Alpine（多阶段构建）、Nginx、PostgreSQL 15，并附带 Adminer 与 PgAdmin 两个数据库管理工具。使用者通过复制 .env、执行 make create-project 完成初始化，需自行保持根目录与 src/.env 的数据库凭据一致。适合需要在本地用容器运行 Laravel + PostgreSQL 的 PHP 开发者。

  • 提供 PHP 8.4-FPM Alpine、Nginx、PostgreSQL 15 的多容器编排，应用镜像采用多阶段构建
  • 包含 Adminer（8080 端口）与 PgAdmin（5050 端口）两个数据库管理界面
  • 通过 Makefile 命令（如 make create-project）执行环境初始化与常用操作

适用场景（解读层）

  • 在本地搭建 Laravel 与 PostgreSQL 的容器化开发环境
  • 需要 Vite HMR（5173 端口）配合前端热更新的 Laravel 开发
  • 通过 Adminer 或 PgAdmin 图形界面管理 PostgreSQL 数据库
