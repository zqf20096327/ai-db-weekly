🧭 简介解读层（AI·证据行可回查）

用 Golang 编写的将 MSSQL 变更数据捕获记录流转到 Kafka 主题的工具

综述（解读层）

Athena 读取 Microsoft SQL Server 的变更数据捕获（CDC）历史，将其以消息形式发布到单个 Apache Kafka 主题，使用 Golang 编写。它通过 setup 命令自动完成数据库端 CDC 配置，以轮询方式按间隔拉取变更，支持 SASL/TLS 连接 Kafka，并可将日志写入 ClickHouse。适用于需要在 MSSQL 与 Kafka 之间搭建变更流转管道的团队；使用前需手动创建 Kafka 主题，已有数据不会被推送。

  • 自动执行 MSSQL 端 CDC setup，轮询 create/update/delete 变更并发布到单一 Kafka 主题
  • 支持 SASL-PLAIN、SCRAM-SHA-256/512 及 TLS 的 Kafka 连接配置
  • 内置 uninstall、add-cdc、clear-cdc-history 等子命令，并可将记录写入 ClickHouse 表

适用场景（解读层）

  • 将 MSSQL 表的增删改事件以统一格式投递到 Kafka 供下游程序消费
  • 通过 skippedTables 和轮询间隔配置按需同步部分表的变更
  • 配合 ClickHouse 存储带 TTL 的变更日志记录
