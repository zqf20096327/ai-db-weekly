基于 Python/FastAPI 与 PostgreSQL 的自托管主数据管理（MDM）Web 应用

综述（解读层）

miniMDM 是一个开源主数据管理应用，提供 Web 界面、REST API 与 PostgreSQL 后端，面向需要集中管理主数据的团队。数据对象通过 YAML/JSON 配置文件定义；记录遵循 draft→active→retired 生命周期，配合草稿审批、版本回退、审计日志、查重标记与 JWT 四角色权限。要求 Python 3.11+、PostgreSQL 15+，支持 Docker 部署，采用 MIT 许可证。

  • 通过 YAML/JSON 配置定义数据对象，支持生命周期状态、校验规则与查重规则等治理策略配置
  • 提供记录版本管理、审计日志、基于 JWT 的四角色认证及按 schema 的访问控制
  • 支持 CSV/TSV/JSON 批量导入导出、入站 webhook 接收及自动生成的 OpenAPI 文档

适用场景（解读层）

  • 需要以草稿-审批流程集中维护客户、产品等主数据的团队
  • 需要通过 webhook 接收 ERP/CRM 等外部系统推送数据并统一入草稿审核的场景
  • 需要自托管、带审计与权限控制的主数据管理环境
