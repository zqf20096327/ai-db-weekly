🧭 简介解读层（AI·证据行可回查）

Go 编写的数据库迁移工具，可用作 CLI 或导入为 Go 库。

综述（解读层）

migrate 用于对数据库执行版本化迁移，从文件系统、io/fs、GitHub、S3 等来源读取迁移文件，按顺序应用到 PostgreSQL、MySQL、MongoDB、ClickHouse 等 20 余种数据库。每个迁移包含 up 与 down 两个文件。通过 CLI 或 Docker 运行，也可作为 Go 库以模块方式引入 v4 版本。

  • 支持 20 余种数据库驱动及文件系统、GitHub、GitLab、AWS S3、Google Cloud Storage 等迁移来源
  • 迁移文件采用带时间戳的 up/down 成对命名（如 1481574547_create_users_table.up.sql）
  • 库模式 API 在 v3/v4 已冻结，内部使用 io.Reader 流降低内存开销，支持 GracefulStop 并声称线程安全

适用场景（解读层）

  • 为使用 PostgreSQL、MySQL、MongoDB 等受支持数据库的项目管理 schema 版本变更
  • 在 CI/CD 流程中通过 Docker 镜像或 CLI 执行迁移命令（如 migrate -source file://... up 2）
  • 在 Go 项目中作为库嵌入，使用现有 database/sql 客户端执行迁移
