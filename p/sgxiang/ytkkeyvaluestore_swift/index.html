基于 SQLite 的 Swift 键值存储工具，封装表的创建与读写。

综述（解读层）

YTKKeyValueStore_Swift 是一个以 SQLite 为后端的键值存储工具库，为 iOS 应用提供本地持久化能力。它提供 YTKKeyValueStore、YTKTable、YTKItem 三个层次：打开数据库、按表名建表、以键值形式读写数据，值支持字符串、数字、字典、数组，以 JSON 字符串存储。要求 iOS 9.0+ 与 Swift 3.0。适合需要轻量键值持久化的 iOS 开发者。

  • 使用 SQLite 作为存储后端，支持创建或打开数据库文件及按名称建表
  • 键值写入支持字符串、数字、字典、数组类型，值以 JSON 字符串保存
  • YTKObject 提供按类型取值接口（string/number/dictionary/array），YTKItem 记录键、值与创建时间

适用场景（解读层）

  • iOS 应用中需要将配置、用户信息等结构化数据以键值形式本地持久化
  • 需要按表组织键值数据并记录条目创建时间的场景
  • 项目已使用 CocoaPods 或 Carthage 依赖管理并需要集成该存储库
