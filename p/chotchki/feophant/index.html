用 Rust 从零实现的 SQL 数据库服务器，兼容 Postgres v3 线协议

综述（解读层）

这是一个用 Rust 从零编写的 SQL 数据库服务器（约一万行代码），实现 Postgres v3 线协议，可直接用 psql 等真实客户端连接执行查询。包含堆存储、B-tree 索引、MVCC 和系统目录，支持单表的建表、插入与查询，数据可跨重启持久化。适合作为学习数据库内部机制的参考实现。项目于 2021 年暂停，无 WAL、不支持崩溃恢复，仅支持单表、无连接查询。

  • 手写 Postgres v3 线协议编解码器，支持启动与 SSL 协商，psql 与 tokio-postgres 等客户端可直接连接
  • 实现 8KB 页堆存储、B-tree 索引（含节点分裂）、基于 clog 模型的 MVCC 事务管理器，以及 pg_class 等系统目录
  • 采用 Tokio 异步并发模型与 64/128 位事务 ID，模式以代码形式内嵌于二进制

适用场景（解读层）

  • 阅读源码以了解存储引擎、B-tree 索引、MVCC 可见性等数据库内部子系统的实现
  • 用 psql 或 tokio-postgres 等真实 Postgres 客户端连接实验，执行单表的 CREATE TABLE / INSERT / SELECT
  • 运行其测试套件（含 MVCC 可见性专项测试与持久化基准）验证行为
