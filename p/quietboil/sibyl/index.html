🧭 简介解读层（AI·证据行可回查）

基于 OCI 的 Rust 与 Oracle 数据库接口，支持阻塞与非阻塞 API。

综述（解读层）

Sibyl 通过 Oracle 调用接口（OCI）为 Rust 应用提供访问 Oracle 数据库的能力，同时提供阻塞（线程）和非阻塞（async）两套 API，非阻塞模式依赖 Tokio 等异步运行时。README 提供阻塞与非阻塞两种示例代码，并附用户指南与 API 文档，许可证为 MIT。

  • 提供基于 OCI 的 Rust 到 Oracle 数据库的接口
  • 同时支持阻塞（线程）与非阻塞（async）两种 API 模式
  • 非阻塞模式支持 Tokio、Actix、async-std、async-global-executor 作为异步执行器

适用场景（解读层）

  • Rust 应用程序中需要读写 Oracle 数据库的场景
  • 基于 Tokio/Actix 等异步运行时访问 Oracle 的服务端程序
  • 需要在阻塞与非阻塞代码间保持相似写法的数据库访问层
📖 README 首段存档原文 · 程序抽取

Sibyl is an [OCI][1]-based interface between Rust applications and Oracle databases. Sibyl supports both blocking (threads) and nonblocking (async) API.
