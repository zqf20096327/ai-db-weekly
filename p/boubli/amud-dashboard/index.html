🧭 简介解读层（AI·证据行可回查）

Rust 编写的家庭实验室仪表盘，免 YAML，UI 内配置并聚合 Proxmox/Docker 遥测。

综述（解读层）

AMUD Dashboard 是面向家庭实验室（homelab）用户的自托管仪表盘，由 amud-server（Axum Web 服务器，状态存于 SQLite）和 amud-agent（部署在各主机的遥测守护进程）两个二进制组成。配置在 Web UI 中完成并持久化到 SQLite，无需 YAML 文件；代理通过 UDS 或 TCP/TLS 上报主机与容器数据。Docker 镜像仅支持 amd64，ARM64 需用原生二进制安装。

  • 通过 Proxmox VE REST API（API Token 认证）和 Docker UNIX socket 原生采集主机与容器遥测，经 WebSocket 推送到浏览器
  • 配置、布局与分类标签存储于嵌入式 SQLite（WAL 模式），全部通过 UI 设置，不使用 YAML 文件
  • 支持多节点部署：一个服务器接入多个主机上的代理，支持 LXC 容器控制、LDAP、Homepage YAML 导入及 AdGuard/Pi-hole/Plex/Home Assistant 等集成

适用场景（解读层）

  • 集中监控运行 Proxmox VE、Unraid、CasaOS 或 Docker 的多台家庭服务器
  • 在浏览器中直接管理容器并查看实时遥测数据
  • 从 Homepage 等现有仪表盘导入布局并配置自托管服务卡片
