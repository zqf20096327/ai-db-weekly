🧭 简介解读层（AI·证据行可回查）

为 Claude 提供只读访问 Quicken For Mac 财务数据的 MCP 服务器与技能

综述（解读层）

该项目通过 Claude Skill 和 MCP 服务器两种形式，让 Claude 读取 Quicken For Mac 的 Core Data SQLite 数据库，用于查询账户、交易、分类支出、投资持仓等。数据库始终以只读方式打开；需要 Quicken 应用处于打开状态。MCP 形式提供 8 个预置工具，技能形式由 Claude 直接编写 SQL；还附 qmac 命令行工具和 CSV 导出脚本。适用于在 macOS 上使用 Quicken 并希望通过 Claude 查询个人财务数据的用户。

  • 提供 Skill 与 MCP 服务器两种形式，共享同一份 schema 知识（docs/schema.md）
  • MCP 服务器包含 list_accounts、query_transactions、spending_by_category 等 8 个预置工具，raw_query 支持 500 行上限的任意 SELECT 查询
  • 包含 qmac 命令行工具与 export_sovereign_csv.py 脚本，可将数据库导出为 CSV 文件及 schema.json

适用场景（解读层）

  • 通过 Claude 查询账户余额、分类月度支出趋势、投资持仓等 Quicken 财务数据
  • 在 Cursor、Cline 等不支持加载技能的 MCP 客户端中调用类型化工具查询财务数据
  • 将 Quicken 中的完整财务历史导出为规范化 CSV 供 DuckDB、Pandas、PostgreSQL 等工具加载分析
