🧭 简介解读层（AI·证据行可回查）

面向编码代理的跨会话记忆服务器：以本地 Markdown 存笔记，经 MCP 协议供各代理检索。

综述（解读层）

Renor 是一个通过 MCP 为 Claude Code、Codex、Cursor 等编码代理提供跨会话记忆的工具。代理保存的决策与事实以纯 Markdown 存放在本地文件夹，SQLite 维护可随时重建的搜索索引，自托管模式无需账号或 API 密钥，仅支持 Node.js 22.16+ 运行环境。

  • 以 MCP stdio 服务器运行，提供 whats_new、get_context、search_text、retrieve_memory、remember 五个工具，兼容任意 MCP 客户端
  • 笔记以纯 Markdown 存储在本地文件夹（默认 ~/.renor，可由 VAULT_PATH 指定），SQLite 索引可从 Markdown 重建
  • 支持托管与自托管两种方式；托管默认混合搜索，自托管默认关键词与词干检索，可选接入 OpenAI 或本地嵌入模型

适用场景（解读层）

  • 让多个编码代理（Claude Code、Codex、Cursor、Grok 等）共享同一份项目决策与事实记忆
  • 在无账号、无 API 密钥的本地环境中为代理持久化会话知识
  • 在服务器或 Docker 环境中部署代理共享记忆服务
