F# SQL 数据库类型提供程序，将数据库架构编译为 .NET 类型

综述（解读层）

SQLProvider 是一个面向 F# 的 .NET SQL 数据库类型提供程序，在编译时将数据库架构映射为 .NET 类型，供 F# 开发者直接以类型化方式访问数据库。支持 LINQ 查询、懒加载架构探索、CRUD 操作、存储过程与异步操作，并可将数据库架构离线保存或读取 SQL-Server *.dacpac 文件。除 SQL Server 和 Access 外，其他数据库依赖动态程序集加载，在某些系统配置下可能需调整配置文件。

  • 为 SQL Server、SQLite、PostgreSQL、Oracle、MySQL/MariaDB、Firebird、DuckDB 等提供显式实现，另有支持任意 ODBC 数据源（功能受限）的 ODBC 提供程序
  • 支持 LINQ 查询、事务性 CRUD、存储过程、自定义操作符、异步操作及双向数据绑定
  • 支持 .NET Standard / .NET Core，可离线保存数据库架构并读取 SQL-Server *.dacpac 文件

适用场景（解读层）

  • F# 项目中以类型化方式查询和操作关系数据库
  • 需要通过 ODBC 连接已有数据源的场景
  • 需要在无数据库连接环境下基于离线架构（dacpac）开发的场景
