Android 响应式 ORM 库，基于注解实体和 DSL 查询实现对象映射。

综述（解读层）

Alchemy 是一个面向 Android 的对象关系映射库，通过 @Entry 注解将抽象类定义为实体，提供 DSL 风格的条件查询接口，并支持 Java 8 Stream 与 RxJava/RxJava2 响应式数据流。README 未给出安装依赖坐标，仅注明将发布到 bintray jcenter，使用时需自行引入源码或等待发布。适用对象为使用 RxJava 的 Android 开发者。

  • 通过 @Entry 注解从抽象类定义实体
  • 提供 DSL 风格的 where 条件查询接口
  • 支持 RxJava Observable 与 RxJava2 Flowable（可指定 BackpressureStrategy）

适用场景（解读层）

  • 在 Android 应用中实现实体对象与 SQLite 数据库之间的映射
  • 以链式 DSL 构建条件查询并获取结果列表
  • 将数据库查询结果转换为响应式数据流供 RxJava 订阅
