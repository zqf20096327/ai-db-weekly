用 Rust 编写的度量空间相似度搜索数据库管理系统

综述（解读层）

Emdrive 是一个用 Rust 实现的 DBMS，用于在度量空间内做相似度搜索，通过 SQL 接口操作，支持 UINT、TIMESTAMP、UUID、STRING 等定长数据类型。索引分为 btree（等值查询）与 emtree（基于度量的 @ 距离查询），目前提供 hamming 距离度量。服务通过环境变量配置，以 HTTP 接口对外提供，数据以分页文件存储于数据目录。适合需要对哈希等值做距离查询的场景，README 未包含序列自增类型，推荐用 ULID() 生成实体 ID。

  • 提供 EM-tree 度量索引与 @ 距离运算符，支持 METRIC KEY 列上的距离查询，目前实现 hamming 度量
  • 提供 btree 索引支持等值查询，支持 UINT8–UINT128、BOOL、TIMESTAMP、UUID、STRING(n) 等非空数据类型，可用 NULLABLE() 包装
  • 通过 EMDRIVE_* 环境变量配置数据目录与 HTTP 监听地址端口，数据按数据库/表组织为分页文件存储

适用场景（解读层）

  • 以感知哈希做图片查重或相似图片检索，用 Hamming 距离查询近邻记录
  • 需要对整型、时间戳、UUID 等定长数据建立等值或距离索引的应用
  • 通过 SQL 与 HTTP 接口嵌入现有服务进行相似度查询的数据管道
