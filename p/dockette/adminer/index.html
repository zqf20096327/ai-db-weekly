🧭 简介解读层（AI·证据行可回查）

基于单文件 PHP 工具 Adminer 的 Docker 镜像集合，用于多数据库管理。

综述（解读层）

该项目为 Adminer（单 PHP 文件的数据库管理工具）提供多个 Docker 镜像，覆盖 MySQL、PostgreSQL、SQLite、MongoDB、Oracle、MSSQL，按数据库家族提供 mysql、pgsql、mongo、mssql、full 等变体。通过环境变量配置内存、上传限制、端口、并发数与主题，并支持 autologin、服务器列表插件。适合需要以容器方式运行 Adminer 的用户。

  • 提供 full、mysql、pgsql、mongo、mssql、oracle-11/12/19、dg 等多种镜像变体，基于 Alpine Linux 或 Debian Bookworm 构建
  • 支持通过环境变量配置 MEMORY、UPLOAD、PORT、WORKERS、ADMINER_THEME 及 MSSQL 加密相关选项
  • 提供 autologin 与 server list 插件（通过环境变量启用），主题可通过 ADMINER_THEME 指定，镜像版本基于 Adminer 6.1.1

适用场景（解读层）

  • 以 Docker 容器方式运行 Adminer 管理多种数据库
  • 通过 autologin 或 server list 插件实现预配置服务器的连接流程
  • 通过 make build 等命令自行构建和测试各变体镜像
