🧭 简介解读层（AI·证据行可回查）

面向 AI 代理的单主题 SQLite 数据层，经 MCP 或 CLI 以带护栏的 SQL 操作

综述（解读层）

BaguetteDB（bdb）是一个单二进制工具，为每个主题（如看板、购物清单、助手记忆）维护一个独立的加密 SQLite 数据库。AI 代理通过 MCP（stdio 或 HTTP）或命令行在其中执行 SQL，架构与规则以文档形式提供给代理，所有变更记录日志并可撤销/重做。数据存储于本地 ~/.baguettedb 目录，用 SQLCipher 加密，支持邀请共享与 owner/editor/viewer 角色。仅支持 Linux 和 macOS，serve 模式只提供明文 HTTP，需自行加 TLS 代理。许可证为 FSL-1.1-ALv2。

  • 每个 bdb 为独立的 SQLCipher 加密 SQLite 文件，存于本地 ~/.baguettedb 目录
  • 代理通过 MCP（stdio/Streamable HTTP）或 bdb 命令行操作数据库，内置 SQL 与 formulas 文档可通过 get_docs 读取
  • 所有变更写入日志，支持按单条或整批撤销/重做；Formulas 为保存在库中的带参数命名 SQL

适用场景（解读层）

  • 让 Claude Desktop、Claude Code、Codex 等代理通过 MCP 工具维护看板、待办等结构化数据
  • 在本地保存可撤销、可导出的代理工作数据，并按主题与指定成员共享
  • 通过 bdb serve 与个人访问令牌，使多台机器上的代理和脚本访问同一数据目录
