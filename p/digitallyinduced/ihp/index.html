基于 Haskell 与 Nix 的电池全内置 Web 框架，提供类型安全的全栈开发体验

综述（解读层）

IHP 是构建在 Haskell 与 Nix 之上的全栈 Web 框架，2017 年起投入生产使用。它提供类型安全的路由、查询与 HSX 模板、代码生成器、Schema Designer 及内置认证表单验证；依赖（含 PostgreSQL 与 GHC）由 Nix 管理，经 devenv up 启动。项目为 monorepo，包含 GraphQL、实时数据同步、后台任务监控等子包。

  • 类型安全的路由、数据库查询与 HTML（HSX）模板，错误在编译期捕获
  • 内置 Schema Designer 可视化数据库工具、代码生成器、热重载、用户认证与表单验证
  • 通过 deploy-to-nixos 声明式部署到 NixOS，支持 systemd socket activation 实现零停机重启，也支持 Docker 与裸机部署

适用场景（解读层）

  • 使用 Haskell 构建以 PostgreSQL 为存储的 Web 应用
  • 团队需要 Nix 统一开发环境并声明式部署到 NixOS 服务器
  • 需要实时数据同步（WebSocket）或 GraphQL API 的全栈项目
