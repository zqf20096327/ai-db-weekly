源自 SQLite 的 Lemon 语法分析器生成器，用于解析 SQL 语句

综述（解读层）

该项目是来自 SQLite 的 Lemon 语法分析器生成器（单个 lemon.c 文件，约 4000 余行），配合 tokenize.c 分词器可处理 SQL 语句，被 Atlas sharding 分支使用。README 介绍编译步骤（gcc 编译、./lemon parse.y 生成 parse.h/parse.c）、ParseAlloc/Parse/ParseFree 接口流程，并逐段解析 parse.y 语法规则，还演示了增加 INSERT 多值插入语法的修改方法。适合需要阅读或改写 SQLite 语法文件、自建 SQL 解析流程的开发者。

  • 生成器源码为单个 lemon.c 文件，可用 gcc 直接编译，配合 lempar.c 模板与 parse.y 生成 parse.h 和 parse.c
  • 提供 ParseAlloc/Parse/ParseFree 接口，逐 token 送入解析，未以分号结尾的语句会补 TK_SEMI 终结符
  • README 演示了对 SQLite parse.y 的修改：增加 valueslist 规则以支持 INSERT 多值插入语法

适用场景（解读层）

  • 为 SQL 语句构建语法解析流程，如 Atlas sharding 分支中的用法
  • 阅读与修改 SQLite parse.y 语法规则，例如增加多值 INSERT 语法
  • 基于 Lemon 语法文件自定义语法分析器并生成解析引擎代码
