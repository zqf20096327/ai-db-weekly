50KB 零依赖的 Java 轻量 HTTP 后端框架，含伪数据库与 JSON 支持

综述（解读层）

NanoHTTPd2 是 NanoHTTPd 的延续版本，定位中小型 Web 后端开发。框架本体约 50KB，无第三方依赖，提供伪数据库（可直接使用可序列化的 ConcurrentHashMap 并支持跨版本序列化转换）、对象转 JSON 返回、CSV 导出、多线程处理、文件型 POST/GET 请求处理及 FileServer 工具类。README 的压力测试示例基于 DBServer 的 /create 接口。适用于小型后端项目；作者未提供系统化使用教程，示例代码在 example 文件夹中。

  • 框架本体约 50KB，不依赖任何第三方库，可自行理解、修改并重新编译
  • 提供伪数据库功能，可直接将可序列化的 ConcurrentHashMap 当作数据库使用，并支持不同版本序列化对象间的自动转换
  • 支持将简单对象直接作为 JSON 返回、导出 CSV（自动添加表头）、处理含文件的 POST/GET 请求，并提供 FileServer 工具类

适用场景（解读层）

  • 中小型 Web 后端项目开发
  • 运行于树莓派等边缘计算设备的轻量 HTTP 服务
  • 需要简单数据存储与 JSON/CSV 输出的小型接口服务
