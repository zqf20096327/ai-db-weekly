一套用于编写交互式 Web 服务的现代 C++20 库集合。

综述（解读层）

ThorsAnvil 是一组基于 C++20 的库，包含异步 IO（ThorsSocket）、HTTP 服务器（Nisse）、JSON/BSON/YAML 序列化（ThorsSerializer）、MongoDB wire protocol 客户端（ThorsMongo）、Slack API/Bot 库及加密工具。面向需要构建 Web 服务、对接 MongoDB 或 Slack 的 C++ 开发者，通过声明式序列化减少样板代码。可通过 brew、Conan、源码编译或 header-only 分支安装；Windows 构建需加 /Zc:preprocessor 标志。

  • 支持将 C++ 对象自动序列化为 JSON / BSON / YAML，无需手写序列化代码
  • 提供异步 IO 库，以 std::iostream 接口统一访问文件、管道、套接字与 TLS 套接字
  • ThorsMongo 直接收发 MongoDB wire protocol 消息，支持集合中对象的插入、更新与查找

适用场景（解读层）

  • 构建基于 C++ 的异步 HTTP/REST Web 服务
  • 在 C++ 项目中直接与 MongoDB 集合并传输 C++ 对象
  • 开发对接 Slack API 与 Webhook 的 Slack 机器人
