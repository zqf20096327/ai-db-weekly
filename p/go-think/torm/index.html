Laravel 风格的 Go ORM，提供查询构建器、模型与迁移

综述（解读层）

ThinkORM（仓库 go-think/torm）是一个面向 Go 的 ORM 库，设计上对齐 Laravel Eloquent 的语义，包含查询构建器、模型、关系、Schema 构建与迁移。支持 MySQL、MariaDB、Postgres、SQLite、SQL Server 五种方言。要求 Go 1.27+，通过 go get 安装，测试套件使用内置内存 fake 驱动、无需真实数据库即可离线运行。README 还列出相对 1.x 的行为变更及 Go 语境下有意不实现的能力（如动态属性 accessor/mutator）。

  • 查询构建器包含 where 族、CTE、游标分页、联接、upsert、returning 等；提供 ToSql/ToRawSql 检查生成 SQL
  • 模型支持时间戳、软删除、脏检查、mass-assignment 守卫、事件与观察者、UUID/ULID 主键；关系含 hasOne/hasMany/belongsTo/morph/belongsToMany 等及预加载、WhereHas、WithCount
  • 支持命名连接与读写分离（sticky 窗口）、嵌套事务（savepoint）与死锁重试、五方言的 Schema 构建与带批次/锁的迁移

适用场景（解读层）

  • 希望在 Go 项目中使用 Laravel Eloquent 风格模型与关系查询的开发者
  • 需要跨 MySQL、Postgres、SQLite、SQL Server 等多方言构建查询与执行迁移的项目
  • 需要读写分离、嵌套事务、软删除等数据库访问能力的 Web 服务（README 标签含 gin/thinkgo）
