Rust 的 std::time::Instant 替代库，基于 TSC 计时

综述（解读层）

minstant 是一个 Rust 计时库，作为 std::time::Instant 的替代接口，用于测量经过时间。它在 x86/x86_64 Linux 平台上使用 TSC 指令读取时间，其他平台或 TSC 不稳定时回退到 std::time；可选 fallback-coarse 特性以牺牲精度换取速度。该库被 tracing 库 minitrace-rust 使用。

  • 在 x86/x86_64 Linux 平台基于 TSC 测量时间，其余平台回退到 std::time
  • 提供与 std::time::Instant 相同的 API（now/elapsed），elapsed 返回 std::time::Duration
  • 提供 fallback-coarse 特性，回退时使用粗粒度时间

适用场景（解读层）

  • 为 Rust 程序中的代码段测量执行耗时
  • 作为 minitrace-rust 等追踪库的底层计时组件
  • 需要频繁调用 Instant::now 的采样场景
