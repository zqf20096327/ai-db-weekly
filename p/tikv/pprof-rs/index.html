🧭 简介解读层（AI·证据行可回查）

可嵌入 Rust 程序的 CPU 性能分析器，基于 backtrace-rs 采样实现

综述（解读层）

pprof 是一个以库形式集成到 Rust 程序中的 CPU profiler。使用方式为创建 ProfilerGuard 启动采样，guard 被释放时停止；期间可通过 guard 构建报告。实现上用 setitimer 定时发送 SIGPROF，在信号处理函数中采集回溯并计数。支持通过 blocklist 排除 libc、libgcc 等库以规避 libunwind 在信号处理中不安全的问题；也提供 frame pointer 展开（需 nightly）。适合需要在 Rust 程序内编程式采集 CPU 性能数据的开发者。

  • 通过 ProfilerGuardBuilder 设置采样频率与 blocklist，在 guard 生命周期内持续采样
  • 支持生成火焰图（flamegraph feature）、profile.proto 格式输出（protobuf-codec/prost-codec feature）
  • 提供 frame_post_processor 接口修改原始统计数据，并可与 criterion 基准测试集成

适用场景（解读层）

  • 对运行中的 Rust 程序进行进程内 CPU 采样并生成火焰图
  • 输出 profile.pb 后使用 Go pprof 工具查看分析结果
  • 在 criterion 基准测试中自动生成性能剖析文件
