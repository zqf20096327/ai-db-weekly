🧭 简介解读层（AI·证据行可回查）

TiKV 的 Rust 客户端库，提供事务性与原始键值两种 API。

综述（解读层）

该 crate 是连接 TiKV（需 >= v5.0.0）分布式键值数据库的 Rust 客户端库，支持事务 API 与无事务一致性保证的 raw API。提供 RawClient 和 TransactionClient 两种高层接口，也可通过 tikv-client-store、tikv-client-pd 直接发送 gRPC 消息。依赖 Tokio 异步运行时，README 注明当前版本 API 不稳定、不适合生产使用。使用方式为在 Cargo.toml 添加 tikv-client 依赖。

  • 提供 raw 模式与事务模式两种客户端 API，raw 模式支持 put/get/delete/scan/batch 操作及 compare_and_swap，事务模式支持 get_for_update、lock_keys、gc 等请求
  • 支持多级抽象：从 RawClient/TransactionClient 高层接口到通过 tikv-client-store 和 tikv-client-pd crate 直接发送 gRPC 消息
  • 异步 API 基于 Tokio 运行时；日志通过 log facade 输出，可用 RUST_LOG 控制事务生命周期与区域重试的 debug 追踪

适用场景（解读层）

  • Rust 应用程序连接 TiKV 集群进行键值数据的读写、扫描与批量操作
  • 需要对多条命令进行提交或回滚的事务性读写场景
  • 通过低层 request 模块直接收发消息，用于测试 TiKV 集群或高级使用场景
