🧭 简介解读层（AI·证据行可回查）

纯 Go 实现的 SQLite 向量检索扩展，基于虚拟表与 MATCH 查询。

综述（解读层）

sqlite-vec 是一个用 Go 编写的 SQLite 向量检索库，通过虚拟表模块提供对嵌入向量的 MATCH 相似性查询。它依赖 modernc.org/sqlite（无 CGO），支持从上游 MySQL 的 shadow 表按 SCN 日志同步到本地 SQLite。文档行按 (dataset_id, id) 不可变，且所有查询必须携带 dataset_id；需要约 4k 行、64 维以上向量时才自动切换为 cover-tree 索引。

  • 纯 Go 实现，基于 modernc.org/sqlite 驱动，无需 CGO 和自定义 SQLite 构建
  • 提供 vec 虚拟表，支持 dataset 隔离的 MATCH 查询与持久化向量索引（brute-force 与 cover-tree）
  • 包含 vecsync SCN 日志同步辅助包与 vecadmin 管理虚拟表，支持按需重建索引

适用场景（解读层）

  • 在边缘部署、serverless 函数或本地工具中于单个 SQLite 文件内保存嵌入与相似性检索
  • 从上游 MySQL 等数据源按 SCN 日志向下游 SQLite 副本回放向量文档同步
  • 通过 go test 基准比较 brute-force 与 cover-tree 在特定硬件上的构建与查询表现
