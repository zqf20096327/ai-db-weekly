基于kind的TiDB Operator稳定性测试方案文档项目

综述（解读层）

该项目提供tidb-operator稳定性测试的设计文档与流程说明，面向tidb-operator开发者。其机制是：用kind创建k8s集群并部署tidb operator，按组件异常、资源不足、环境异常三类方向注入变化因子，循环执行部署、扩缩容、升级等核心功能操作并检查结果，还可加入随机化混沌因子。README以方案描述为主，未见可执行测试代码的说明。

  • 提供三类异常注入方向：组件异常、资源不足、环境异常
  • 描述使用kind创建k8s集群并在其上部署tidb operator的测试环境搭建方式
  • 包含循环执行功能操作、注入随机混沌因子的测试流程设计

适用场景（解读层）

  • 为tidb-operator编写稳定性测试用例提供设计参考
  • 验证tidb集群在节点宕机、网络分区等异常下的功能表现
  • 搭建可重复执行异常注入的测试流程
📖 README 首段存档原文 · 程序抽取

- 能正常工作 - 能长期正常工作 - 能在预期的异常下按照预期工作，异常消失后恢复正常 - 能在一定的异常下，容忍/处理异常，继续正常保证服务，或者尽可能少的较少停顿时间 - 能一定程度容忍/处理未知异常
