为 ActiveRecord 提供主从数据库集群连接代理的适配器

综述（解读层）

该库通过 seamless_database_pool 适配器为 ActiveRecord 接入主从复制集群，将 select 语句分发到读池、写与事务语句走主库，并支持读连接失效自动切换。以 Rails 插件或 gem 形式发布，适合需要在现有 ActiveRecord 应用中接入主从集群的开发者。限制：主从须使用兼容的数据库适配器，启动时不可用的节点不会加入读池。

  • 提供 seamless_database_pool 适配器，在 database.yml 中配置主连接与读连接池，各连接可继承公共配置并支持 pool_weight 权重
  • select 语句由读池处理，insert/update/delete、事务内语句及 reload 走主连接
  • 读连接失效时自动尝试重连并切换到池内其他连接，三十秒后重试失效连接

适用场景（解读层）

  • Rails 应用按脚手架约定改造为读写分离：修改 database.yml 并在 ApplicationController 加入 ControllerFilter 声明
  • 开发与测试环境将读连接数据库用户限定为仅 select 权限，避免读连接被写入
  • 为读请求配置带权重的多节点读池，按 pool_weight 分配读流量
