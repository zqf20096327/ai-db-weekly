Rails gem，捕获并持久化 ActiveRecord 迁移生成的 SQL 语句

综述（解读层）

该 gem 用于捕获 ActiveRecord 迁移执行时产生的 SQL 并写入文件，供代码审查者或需要审批生产环境数据库变更的 DBA 查看原始 SQL。通过在 config/initializers 中调用 capture 启用，可自定义输出目录与起始版本；支持在迁移内按块开关记录、指定多数据库连接。已生成的 SQL 文件不会被覆盖，迁移回滚（down）时会删除以便重新生成。

  • 将每个迁移的 SQL 语句记录到 db/migration_sql 目录，可通过 directory 参数指定其他目录
  • 支持 starting_with 参数从指定版本号开始捕获，避免为历史迁移生成文件
  • 提供 disable_sql_logging 块开关捕获，以及 using_connection 块指定数据库连接并附加标签注释

适用场景（解读层）

  • 代码审查时查看迁移对应的原始 SQL，以了解数据库变更的具体内容
  • 数据库变更需 DBA 审批执行时，向其提供迁移生成的 SQL 清单
  • 应用使用多个数据库时，在迁移中指定 schema 语句使用的连接
