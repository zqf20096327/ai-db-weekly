🧭 简介解读层（AI·证据行可回查）

基于 Debezium CDC 的数据复制工具，将事务库数据写入 ClickHouse

综述（解读层）

该连接器将 MySQL、PostgreSQL 等事务数据库的数据同步到 ClickHouse 用于分析，主要维护方为 Altinity。它借助 Debezium 捕获变更数据，目标表使用 ReplacingMergeTree 引擎。提供轻量级单进程与 Kafka 两种部署模式，支持初始数据装载、失败恢复、上游 schema 变更处理与基于校验和的表对比，以 Docker 容器分发。

  • 使用 Debezium 捕获源库增量事务变更，并自动写入 ClickHouse 的 ReplacingMergeTree 表
  • 支持轻量级（单进程）与 Kafka（源/目标分离）两种部署模式，可从源端或目标端故障中恢复
  • 自动处理上游 schema 变更，提供基于校验和的表数据对比，可扩展到数千张表

适用场景（解读层）

  • 需要将 MySQL/PostgreSQL 业务库数据持续复制到 ClickHouse 做分析查询
  • 需要对源库执行初始全量装载后接续 CDC 增量同步的场景
  • 以 Docker 部署、需要支持失败重启恢复的 ClickHouse 数据管道
