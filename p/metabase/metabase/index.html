开源商业智能工具，支持无SQL提问、仪表盘与嵌入式分析

综述（解读层）

Metabase 是一个开源商业智能与嵌入式分析工具，供团队成员查询和探索数据。用户可通过图形界面提问而无需编写 SQL，也可使用 SQL 编辑器执行复杂查询，并构建带筛选、自动刷新等功能的交互式仪表盘。项目采用 Clojure 编写，提供云端托管与自托管两种部署方式，源码以 AGPL 及商业许可发布。

  • 提供无 SQL 的图形化提问界面与 SQL 编辑器两种查询方式
  • 支持构建带筛选、自动刷新、全屏模式的交互式仪表盘，并可嵌入到应用中
  • 支持官方数据库驱动与社区驱动，提供 API 供集成扩展

适用场景（解读层）

  • 团队内部数据查询与仪表盘搭建
  • 在自有应用中嵌入图表、仪表盘等分析组件
  • 通过邮件、Slack 或 webhook 订阅与数据告警分发分析结果
