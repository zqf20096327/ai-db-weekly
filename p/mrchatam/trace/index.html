本地优先的项目知识图谱工具，为 AI 编码代理提供渐进式规划与有界上下文

综述（解读层）

Trace 是一个 Go 编写的 CLI 工具，在项目 `.trace/` 目录下维护版本化 SQLite 图谱，记录决策、假设与证据，通过 CLI、stdio MCP（17 个工具）和可选回环 HTTP/GUI 三种界面为编码代理提供上下文检索（FTS/图遍历/时序）与渐进式规划。Git 仍是内容与历史的唯一事实源，`.trace/` 本地保留，可经 `trace/graph.json` 便携导出。检索不含嵌入向量语义搜索（DR-NOSSEM）。模块未发布到 Go proxy，需克隆后以 CGO_ENABLED=1 构建，依赖 Go 1.26+ 与 C 工具链。项目处于活跃迭代期，命令可能变动。

  • 提供 CLI、stdio MCP（17 个工具，含 trace_why/trace_context/trace_plan 等）及可选本地回环 GUI 三种访问界面，适配任何 MCP 客户端
  • 混合检索：精确查找、FTS 词汇检索、图标签遍历与历史时序检索；不含嵌入/向量语义搜索
  • 支持渐进式规划（粗规划→深化→基于发现重规划）、DONE 前的证据与独立评审门控，以及通过 trace/graph.json 的便携因果图导入导出

适用场景（解读层）

  • 为使用 MCP 的编码代理（如 Cursor、Claude Code）提供项目决策、假设与证据的有界上下文
  • 在代码之外记录变更动机、任务能力需求与影响分析（impact、agents recommend 等命令）
  • 克隆包含 trace/graph.json 的仓库后，通过 seed import 与 index 重建图谱并查看计划
