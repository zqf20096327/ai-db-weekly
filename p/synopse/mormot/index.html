综述（解读层）

Synopse mORMot 1 是面向 Delphi 6 至最新版本及 FPC 的开源客户端-服务器框架，提供 ORM/ODM 持久化、基于接口的 SOA REST 服务和 MVC Web 发布，支持 Oracle、MS SQL、SQLite3、PostgreSQL、MySQL 及 MongoDB 等数据源。该仓库已进入冻结维护模式，仅接收重要 bug 修复，新项目被建议迁移到 mORMot 2。部分单元（如 SynPdf、SynDB）可脱离主框架单独使用。

  • 提供 ORM/ODM 对象持久化，支持 SQL 数据库（SQLite3、Oracle、PostgreSQL、MySQL 等）和 MongoDB NoSQL 访问
  • 支持基于接口的 SOA 服务，以 JSON over HTTP 等 RESTful 模型通信，客户端无需第三方驱动依赖
  • 包含可单独使用的单元库：PDF 生成（SynPdf）、加密（SynCrypto）、Mustache 模板（SynMustache）、静态链接 SQLite3 引擎等

适用场景（解读层）

  • 为 Delphi/FPC 项目添加 ORM 数据持久化或客户端-服务器 REST 服务能力
  • 以 Mustache 模板或原生 JSON/REST 方式向 Web/AJAX 客户端发布业务逻辑
  • 仅引用部分单元实现 PDF 导出、数据库访问或 Mustache 模板渲染等独立功能
