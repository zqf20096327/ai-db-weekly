面向 AI 代理应用的模板优先本地开发生命周期工具包

综述（解读层）

AgentSeek 是由 OceanBase OSS 团队发布的命令行工具包，用于在本地管理 AI 代理应用的开发全流程。它从锁定的模板目录（agentseek-ai/agentseek-templates）按 commit 获取模板并生成完全可编辑的项目，提供 discover/create/inspect/configure/check/run/observe/iterate 八阶段生命周期，通过 info、doctor、dev 等命令检查就绪状态并启动本地栈，但本身不接管项目的源码、运行时或部署。适合需要在本地生成、运行并迭代观察代理应用的开发者与编码代理。

  • 从不可变目录按锁定 commit 解析 lifecycle-v2 模板，create 命令生成可编辑项目脚手架
  • 提供 agentseek info、doctor（含 --live）、dev、task 等命令，覆盖检查、运行与本地服务观测
  • info/doctor 支持版本化 JSON 输出契约，供桌面客户端与脚本等机器消费，并可选 LangSmith 追踪

适用场景（解读层）

  • 用 deepagents/research 模板快速生成含 LangGraph 后端与 React 前端的本地代理研究应用
  • 开发者或编码代理在本地检查项目拓扑、验证环境就绪并启动开发栈
  • 通过模板目录按目标检索模板，并在创建前用 --describe 查看模板说明
