🧭 简介解读层（AI·证据行可回查）

基于双时态知识图谱的企业知识库系统，Rust 单二进制加 Postgres 部署。

综述（解读层）

Utopia 是 DeepLethe 开发的企业知识工程系统，将文档摄取为带双时态（事实有效时间与系统知晓时间）的知识图谱，支持冲突检测、实体消歧审查、本体推导与决策账本，通过 MCP 向 Claude Desktop、Cursor 等代理提供只读工具。部署为单个 Rust 二进制加 Postgres（pgvector 存向量，Tantivy 做全文检索），提供 Docker 镜像可离线运行，需自行配置聊天与嵌入模型端点。

  • 双时态图谱：每条事实记录有效时间与来源，修正时关闭旧版本并建立链接而非覆盖
  • 知识摄取支持 PDF/DOCX/XLSX 等多格式及网页、RSS、GitHub、Jira、Notion、S3 等定时同步，扫描件经 MinerU 或视觉模型读取
  • 本体驱动查询可将 Postgres、MySQL、ClickHouse、Snowflake 等数据库挂载到知识库，代理经确认后通过 Ontology2SQL 查询

适用场景（解读层）

  • 合同链管理：查询某日期生效的付款条款及修订来源，修订关闭旧条款而非覆盖
  • 需要回答“某时期谁负责某项目、当时系统知晓什么”的人事、财务、科研记录场景
  • 让 Claude Desktop、Cursor 等代理经 MCP 以带类型和日期的方式读取图谱，写入以提案形式交人审核
