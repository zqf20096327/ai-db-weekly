面向 TypeScript/JavaScript 的无头（headless）ORM

综述（解读层）

Drizzle ORM 是运行于 NodeJS、TypeScript 与 JavaScript 环境的 headless ORM，支持 PostgreSQL、MySQL 和 SQLite 数据库，包括 Turso、Neon、PlanetScale、Cloudflare D1 等服务端型数据库。用户可声明 SQL schema 并构建关系型或 SQL 风格查询。配套 Drizzle Kit CLI 生成或执行迁移，Drizzle Studio 浏览数据。体积约 7.4kb（minified+gzipped），零依赖，支持 tree shaking。

  • 支持 PostgreSQL、MySQL、SQLite 及 Turso、Neon、PlanetScale、Cloudflare D1 等多种数据库
  • 可声明 SQL schema，构建 relational 与 SQL-like 查询，保持类型安全
  • 体积约 7.4kb（minified+gzipped），零依赖且可 tree shake，可在 NodeJS、Bun、Deno、Cloudflare Workers、Edge 运行时及浏览器中运行

适用场景（解读层）

  • 在 NodeJS/Bun/Deno/Edge 等多种 JavaScript 运行时中访问关系型数据库
  • 需要在 serverless 数据库（如 Turso、Neon、PlanetScale）上运行且不引入数据代理的场景
  • 需要生成 SQL 迁移文件或将 schema 变更直接应用于数据库的项目
