🧭 简介解读层（AI·证据行可回查）

面向 OpenClaw 的持久化 AI 智能体记忆系统，基于 PostgreSQL + pgvector 实现语义检索。

综述（解读层）

BrainX V6 为 OpenClaw 智能体提供跨会话的持久记忆层，由 CLI 记忆引擎和可选的 OpenClaw 运行时插件两部分组成。它将对话、决策、教训等记录存入 PostgreSQL，用 pgvector 和 OpenAI 嵌入实现语义搜索，并包含去重、矛盾处理、PII 清洗、生命周期管理等治理机制。适用于运行多个 OpenClaw 智能体并需要共享记忆库的本地部署场景；依赖 Node.js 20+、PostgreSQL 14+、pgvector 和 OpenAI API key。

  • 提供 CLI 与可选 OpenClaw 插件两种形态，支持记忆写入、语义搜索、上下文注入、诊断（doctor）等操作
  • 实现自动学习管线：捕获、分类、语义去重、矛盾取代、质量评分与分级（hot/warm/cold/archive）
  • 包含治理机制：PII 清洗、验证状态、跨智能体召回门控、评审门控的规则晋升，以及备份与迁移脚本

适用场景（解读层）

  • 为多个 OpenClaw 智能体搭建共享的持久记忆池，跨会话保留决策与经验
  • 通过 wiki 摘要、JIT 召回、工作记忆等插件面在运行时向智能体注入上下文
  • 导入已有 MEMORY.md 或 Markdown 知识库，构建可语义检索的知识存储
