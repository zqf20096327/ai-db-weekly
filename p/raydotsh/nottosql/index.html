用 C 从零实现的 SQLite 风格最小数据库学习项目

综述（解读层）

nottoSQL 是作者为理解数据库内部原理而编写的实验性 SQL 数据库引擎，纯 C 实现，包含核心 db.c 与设计说明文档 spec。面向学习数据库磁盘存储、查询解析、表/页结构的开发者。编译仅需 GCC/Clang 与类 Unix 环境，无正式测试套件，README 明确说明不适用于生产。

  • 纯 C 实现，单文件 db.c 包含核心引擎代码，附 spec 设计说明
  • 编译命令为 gcc db.c -o nottoSQL，依赖 GCC 或 Clang，建议 Linux/macOS/WSL 环境
  • 项目覆盖磁盘存储、查询解析、表/页结构与底层系统编程等探索主题

适用场景（解读层）

  • 学习数据库内部实现原理（页结构、磁盘存储、查询解析）
  • C 语言底层系统编程练习
  • 作为教学示例，供使用者修改 db.c、添加自己的测试用例
