🧭 简介解读层（AI·证据行可回查）

在 Windows 本机 PostgreSQL 13 上安装 MIMIC-IV 并构建物化视图的安装指南

综述（解读层）

该仓库提供在 Windows 环境下将 MIMIC-IV 数据集安装到 PostgreSQL 13 并通过 PGAdmin 管理的完整流程，包括虚拟机配置建议、Postgres 与 7-Zip 安装、数据下载与命令行建库步骤。作者改写了 MIT-LCP concepts 中不适配 Windows 的 SQL，改用物化视图复现 mimic_derived 功能，并给出视图的分组构建顺序；icu_stay_hourly、sofa、sepsis3 等查询尚未完成移植。

  • 提供从安装 Postgres、7-Zip、下载数据到命令行建库、建索引的完整 Windows 本地部署流程
  • 提供改写后可在 PGAdmin/Postgres 13 原生运行的 concepts SQL 及两组按序执行的物化视图代码
  • 说明虚拟机磁盘、SSD、CPU 核数等资源配置要求及建库耗时（约1.5-2小时）

适用场景（解读层）

  • 在 Windows 本地或独立 VM 上搭建 MIMIC-IV 数据库用于 SQL 查询分析
  • 在 datathon 等限时环境中通过物化视图加速常用派生数据查询
  • 需要替代不可用的 mimic_derived 云端库进行二次/三次派生查询
