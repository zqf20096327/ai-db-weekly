🧭 简介解读层（AI·证据行可回查）

运行在手机/平板/可穿戴设备上的移动端数据库的 JS/TS 实现

综述（解读层）

Realm 是直接运行在手机、平板和可穿戴设备内的移动数据库，此仓库为其 JavaScript/TypeScript 实现，支持 React Native（JSC 与 Hermes）、Node.js 和 Electron。数据以对象形式直接暴露并可用代码查询，支持关系、泛型与向量化。注意：Atlas Device Sync 及官方 SDK 已于 2024 年 9 月宣布弃用，无同步版本需从 community 分支或 npm 社区渠道安装；Node.js 仅支持 18 及以上版本。

  • 支持 React Native（iOS/Android 的 JSC 与 Hermes）、Node.js（18+）和 Electron（Windows/macOS/Linux）
  • 数据直接以对象形式暴露，可通过代码查询，支持关系、泛型与向量化
  • 提供 TypeScript 定义及 @realm/babel-plugin 将 TypeScript 类转换为 Realm schema，另有 @realm/react 提供 React hooks

适用场景（解读层）

  • 为 React Native、Node.js、Electron 应用提供本地数据持久化层
  • 通过 Expo 或 React Native 模板应用快速启动移动端数据存储项目
  • 构建运行在移动与边缘设备上的数据驱动型应用
