面向 Flutter 与 Dart 的面向对象移动端数据库 SDK

综述（解读层）

Realm 是运行在手机、平板与可穿戴设备上的数据库，本仓库为其 Flutter 和 Dart SDK 源码。开发者通过 @RealmModel 注解定义数据模型，运行 dart run realm generate 生成 RealmObject 类，无需 ORM 即可进行查询、写入并监听查询结果变更流。2024 年 9 月官方宣布弃用 Atlas Device Sync，无同步需求可安装 20 版或使用 community 分支。采用 Apache 2.0 许可证。

  • 支持通过 @RealmModel 注解定义数据模型并生成 RealmObject 类，采用面向对象数据模型
  • 支持查询结果变更流（changes.listen），可获取插入、修改等变更索引
  • Flutter 版支持 iOS、Android、Windows、macOS 和 Linux；Dart 独立版支持 Windows、macOS 和 Linux

适用场景（解读层）

  • Flutter 移动应用的本地数据持久化
  • Dart 桌面应用（Windows/macOS/Linux）的数据存储
  • 需要结合 Atlas App Services 进行设备间数据同步的应用（限同步功能未弃用的版本）
