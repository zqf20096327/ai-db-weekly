支持多种国产及主流数据库的 Nacos 发行版

综述（解读层）

NacosPlus 是一个 Nacos 服务端的衍生发行版，在原版基础上提供 OpenGauss、GaussDB、DM（达梦）、OceanBase、Oracle、PostgreSQL、SQL Server、MariaDB 等数据源支持。发布物为 tar/zip 包，附带各数据库的 schema SQL 脚本，连接配置写在 application.properties 中，支持集群或单机模式启动，也可从源码用 Maven 打包。面向需要在信创环境中部署 Nacos 的使用者。

  • 支持 OpenGauss、GaussDB、DM、OceanBase、Oracle、PostgreSQL、SQL Server、MariaDB/MySQL 等多种数据库作为 Nacos 数据源
  • 发布包内置各数据库类型对应的 {数据库类型}-schema.sql 初始化脚本
  • 提供 tar/zip 制成品，支持集群模式与 Windows 单机模式启动，并可通过 Maven 从源码构建

适用场景（解读层）

  • 在信创环境（OpenGauss、GaussDB、DM、OceanBase）中部署 Nacos 注册中心/配置中心
  • 使用 PostgreSQL、Oracle、SQL Server 等数据库替代 MySQL 存储 Nacos 数据
  • 需要特定数据库驱动或服务端版本组合时从源码自行构建 Nacos 包
🔌 适配哪些库db_scan 程序判定

Dameng、GaussDB、MariaDB、MySQL、OceanBase、Oracle、PostgreSQL、SQL Server、openGauss
