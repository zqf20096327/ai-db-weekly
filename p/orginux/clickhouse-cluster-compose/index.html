基于 Docker Compose 部署 ClickHouse 双分片双副本集群的示例项目

综述（解读层）

该项目用 Docker Compose 部署一个包含 ClickHouse Keeper 的 ClickHouse 集群，拓扑为两分片两副本，容器按 shard-id 与 replica-id 命名。通过 Makefile 命令启动、停止集群及进入客户端，可选启动 Grafana（端口 3000）与 RedPanda Connect 持续生成示例数据写入 events 表。适合需要本地搭建 ClickHouse 集群示例环境的用户；README 未涉及生产部署配置说明。

  • 通过 make up 启动两分片两副本的 ClickHouse 集群及 ClickHouse Keeper 容器
  • 可选以 make up-with-grafana 启动 Grafana，服务监听 http://localhost:3000
  • 可选以 make up-with-redpanda-connect 持续生成示例事件数据并插入 events 表

适用场景（解读层）

  • 本地搭建带 Keeper 的 ClickHouse 分片副本集群示例环境
  • 通过 Grafana 查看 ClickHouse 相关数据
  • 使用 RedPanda Connect 向集群写入持续生成的示例数据用于查询测试
📖 README 首段存档原文 · 程序抽取

This repository provides a simple example of how to deploy a ClickHouse cluster with ClickHouse Keeper using Docker Compose. The cluster consists of two shards and two replicas.
