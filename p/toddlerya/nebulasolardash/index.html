🧭 简介解读层（AI·证据行可回查）

Python 编写的分布式 Linux 服务器资源监控工具，含客户端采集与服务端 Web 展示。

综述（解读层）

该工具面向无法连接互联网、缺乏 yum 源的内网生产环境，用于监控多台 Linux 服务器资源。分客户端与服务端两部分：服务端用 bottle 作 Web 框架、echarts 渲染图表，数据存入 SQLite；客户端用 Python 原生库采集，采集代码参考 pyDash。部署前需配置服务端到客户端的 SSH 免密信任，并通过 manager.py 安装、启动各节点客户端。

  • 服务端使用 bottle 作为 Web 框架、echarts 渲染图表，客户端使用 Python 原生类库采集服务器资源
  • 支持配置 CPU/内存使用率的黄色与红色报警阈值，以及客户端采集间隔时间（建议不小于 60s）
  • manager.py 提供 -install/-uninstall/-startall/-stopall/-start/-stop 等参数，管理各节点客户端并设置 crond 守护

适用场景（解读层）

  • 无法连接互联网且无自建 yum 源的内网生产环境中监控多台 Linux 服务器
  • 希望通过 SSH 免密方式集中部署采集客户端、在 Web 页面查看各节点资源状态
  • 需要按服务器数量与存储空间自行调整采集间隔（单节点以 120s 间隔计，每日约写入 4MB 数据）的场景
📖 README 首段存档原文 · 程序抽取

写这个工具的目的是为了解决工作问题。 个人工作生产环境无法连接互联网，也没有自建的yum源等，手头又有很多服务器需要进行监控，使用现有的开源方案安装部署是个问题， 各种依赖组件包需要挨个安装，很麻烦，所以想找一款依赖较少部署简单的分布式服务器资源监控工具，找来找去没找到，索性自己动手写一个。 我的本职工作是测试，所以就用最熟悉的Python来写吧，第一次写web应用，先做出来再边学边优化吧。
