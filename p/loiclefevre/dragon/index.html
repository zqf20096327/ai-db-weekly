🧭 简介解读层（AI·证据行可回查）

基于 OCI 的自动化技术栈管理工具，用于配置 Autonomous Database 并生成应用代码

综述（解读层）

DRAGON Stack manager 是一个命令行工具，面向 Oracle Cloud Infrastructure 用户，可配置 Always Free Autonomous Database 及 REST Data Services，并生成 React、Oracle JET 或 Spring-Boot Petclinic 应用源码。它通过当前目录下的 dragon.config 文件和命令行参数驱动，支持加载 JSON 集合数据与 CSV 表数据（后者可自动推导表结构），提供 -destroy 命令销毁数据库。每个配置文件目录仅支持一个数据库；非租户管理员需预先配置 OCI Policy。

  • 提供 Linux x86/ARM、Windows、macOS 及 OCI Cloud Shell 的单文件可执行程序，发布版本 v2.2.0
  • 支持生成 React 前端、Oracle JET 前端、Spring-Boot Petclinic 应用及基于 SODA API 的微服务后端模板
  • 支持加载 JSON 转储格式（每行一个文档）和含表头的 CSV 文件，目标表不存在时按 CSV 数据自动创建表结构

适用场景（解读层）

  • 在 OCI Cloud Shell 或本地（Linux/ARM/Windows/macOS）快速配置 Always Free Autonomous Database 环境用于开发或演示
  • 为 JSON 或 CSV 数据生成配套的前端应用（React/JET）或 Spring-Boot 后端源码
  • 部署基于 SODA API 的 JSON 数据摄入微服务示例，并通过 NGROK 在 OCI Cloud Shell 中访问本地站点
