用于生成 Pyramid 起始项目的 Cookiecutter 模板

综述（解读层）

该项目是 Pylons 组织提供的 Cookiecutter 模板，用于在命令行生成 Pyramid 框架的起始项目。安装时可选模板语言（Jinja2/Chameleon/Mako）、持久化后端（无、SQLAlchemy+SQLite 或 ZODB）及路由映射方式；URL 映射方式与所选后端联动：zodb 对应 traversal，其余对应 URL dispatch。需要 Python 3.10+ 和 cookiecutter，支持通过分支名对齐不同 Pyramid 版本。适用于需要按预定义结构初始化 Pyramid 项目的开发者。

  • 支持通过 cookiecutter gh:Pylons/pyramid-cookiecutter-starter 命令生成项目，安装时可交互式选择模板语言、持久化后端与路由映射方式
  • 提供 latest、main、x.y-branch 等分支，分别对齐 Pyramid 的最新稳定版、开发主干与指定版本系列
  • 生成项目后附带创建虚拟环境、安装依赖、运行 pytest 测试及 pserve 启动的步骤说明

适用场景（解读层）

  • 需要按标准化目录结构初始化一个新的 Pyramid 项目的开发者
  • 需要自由组合模板语言与持久化后端（如 Jinja2+SQLAlchemy、Chameleon+ZODB）的项目脚手架场景
  • 需要生成与特定 Pyramid 版本分支对齐的项目结构的场景
