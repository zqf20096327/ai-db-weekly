用于管理 3DCityDB 4.x 数据的 QGIS 插件

综述（解读层）

该仓库是一个 QGIS 插件，用于管理和可视化存储在 PostgreSQL/PostGIS 上的 CityGML 3D City Database 4.x 数据，支持 CityGML 1.0/2.0。插件分服务端（PL/pgSQL）与客户端（Python）两部分，含 Layer Loader、Bulk Deleter 和数据库用户权限管理工具，适合不熟悉 CityGML 模型和 SQL 的从业者使用。安装需 QGIS 3.44/4.2 LTR 及 PostgreSQL>=10、PostGIS>=2。

  • Layer Loader 支持 CityGML 全部模块及 LoD0-LoD4，图层几何为 3D，可在 QGIS 中进行 2D/3D 可视化和属性编辑
  • 提供服务器端与客户端 AOI 范围选择以加载大型数据集，支持同一数据库实例中的多个 citydb 模式和多用户权限（只读/读写）
  • Bulk Deleter 可整体或按空间与要素过滤条件批量删除数据库中的要素

适用场景（解读层）

  • 在 QGIS 中直接连接本地或远程 3DCityDB 实例，加载 CityGML 数据进行分析与可视化
  • 面向缺乏 CityGML 数据模型或 SQL/空间数据库经验的人员，以表单方式编辑要素属性并直接写入数据库
  • 按空间范围或要素条件批量管理数据库中的城市模型数据
