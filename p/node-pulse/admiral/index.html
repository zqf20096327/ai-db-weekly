服务器集群监控平台：Agent 端解析指标、Ansible 自动化部署、Web SSH 终端

综述（解读层）

Node Pulse Admiral 是一个服务器监控平台，由 Go 后端（Submarines）、Laravel+React 管理面板（Flagship）和 Docker Compose 部署组成。它采集 node_exporter 指标（Agent 端解析为 39 个字段、推送上报）、提供浏览器 WebSocket SSH 终端、Ansible 剧本自动化部署和告警规则。适用于需要统一管理多台 Linux 服务器的运维场景；要求 Docker 24.0+ 与 2GB 以上内存。

  • Agent 在本地解析 Prometheus 指标后以约 1KB JSON 推送上报，每次抓取写入 PostgreSQL 一行数据
  • 内置 Ansible 剧本注册表，支持 node_exporter 部署、安全加固及 PostgreSQL、MySQL、Nginx、Docker 等应用剧本，也可上传自定义剧本
  • 提供 WebSocket 浏览器 SSH 终端、SSH 私钥加密存储与会话审计日志，支持 mTLS 和 TOTP 双因素认证

适用场景（解读层）

  • 集中监控多台 Linux 服务器的 CPU、内存、磁盘、网络指标（15 秒采集间隔）
  • 通过 Ansible 剧本批量部署和配置应用与安全策略
  • 通过浏览器 SSH 终端直接访问服务器，并留存审计记录
