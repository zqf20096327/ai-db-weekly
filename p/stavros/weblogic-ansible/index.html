用于在 RHEL 7 上安装配置 WebLogic 12.2.1.3 与 Fusion Middleware 的 Ansible 剧本

综述（解读层）

这是一个 Ansible 剧本（weblogic-fmw-domain.yml），用于在 RHEL/CentOS/Oracle Linux 7 最小化安装的系统上安装 WebLogic Server 12c 12.2.1.3 及 Fusion Middleware Infrastructure 软件，供部署 ADF 等应用。运行前需在 infra-vars.yml 配置环境变量、secrets.yml 设置密码，并准备 Oracle 数据库、Java 8 JDK 安装包和从 Oracle 支持渠道下载的 FMW 安装程序。包含五个角色，覆盖系统配置到托管服务器创建。执行完成后可通过 7001 端口的控制台访问。

  • 包含 linux-wls、linux-jdk、fmw-software、fmw-domain、fmw-managed-server 五个 Ansible 角色，覆盖系统配置、JDK 8 安装、FMW 软件安装、域创建与托管服务器创建
  • 针对 WebLogic 与 Fusion Middleware Infrastructure 12.2.1.3 版本
  • 创建的域包含 Enterprise Manager、JRF 等 Fusion Middleware 支持

适用场景（解读层）

  • 在 RHEL/CentOS/Oracle Linux 7 系统上自动化部署 WebLogic 12.2.1.3 与 FMW Infrastructure 环境
  • 搭建用于托管 Oracle Fusion Middleware（如 ADF）应用的服务器
  • 需要 Enterprise Manager、JRF 支持的 Fusion Middleware 域与托管服务器搭建
