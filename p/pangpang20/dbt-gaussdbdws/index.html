dbt-core 适配华为 GaussDB(DWS) 的适配器包，实现 dbt 对该数据库的支持

综述（解读层）

dbt-gaussdbdws 是一个 dbt 适配器包，包含让 dbt 与华为 GaussDB 或 GaussDB(DWS) 数据库协同工作所需的代码，供使用 dbt 做数据转换的分析师和工程师连接该数据库使用。安装上默认依赖 psycopg2-binary，也支持从源码安装 psycopg2，或加载 GaussDB 官方 Python 驱动包；README 注明 PostgreSQL 原生驱动无法直接连接 GaussDB，需将密码加密类型设为兼容模式（MD5 与 SHA256 同时支持）。

  • 提供 dbt-core 与华为 GaussDB / GaussDB(DWS) 数据库连接所需的适配代码
  • 默认安装 psycopg2-binary，可按脚本替换为版本一致的源码编译 psycopg2
  • 支持加载 GaussDB 官方 Python 驱动包（psycopg2 与 lib 文件）以匹配 SHA256 密码加密机制

适用场景（解读层）

  • 使用 dbt 编写数据转换（模型、清洗、预聚合）并运行在华为 GaussDB(DWS) 数仓上
  • 生产环境中需要源码编译 psycopg2 或 GaussDB 原生驱动的部署场景
  • 需要通过兼容模式配置使 PostgreSQL 原生驱动连接 GaussDB 的场景
