🧭 简介解读层（AI·证据行可回查）

Rust 联邦 SQL 查询引擎，经 PostgreSQL 协议接入多数据源并在查询计划中执行治理

综述（解读层）

Dataglot 是用 Rust 编写的联邦 SQL 查询引擎，基于 DataFusion 与 datafusion-federation/iceberg-datafusion 连接 PostgreSQL、MySQL、Oracle、Snowflake、S3 文件和 Apache Iceberg，并通过 pgwire 实现 PostgreSQL 线协议，兼容 psql、Metabase、dbt 等客户端。数据源、凭据和策略可用 SQL 管理，支持列掩码与行过滤。当前为 pre-1.0，仅读路径，非通用 PostgreSQL 替代品。

  • 实现 PostgreSQL 线协议，psql、DBeaver、Metabase、Tableau、dbt 等 Postgres 驱动无需专用客户端即可连接
  • 支持联邦查询 PostgreSQL、MySQL、Oracle、Snowflake、S3/Parquet/CSV、Apache Iceberg，将列掩码和行过滤编译进查询计划
  • 提供 Homebrew、Docker、tarball、cargo binstall 及源码编译等安装方式，支持进程内单条查询、交互式 REPL 及可选的 Apache Ballista 分布式执行

适用场景（解读层）

  • 通过一个 PostgreSQL 端点跨多个异构数据库与数据湖表执行联合 SQL 查询
  • 需要在查询计划层面实施列掩码、行过滤和基于标签的治理策略的读路径场景
  • 本地开发或测试中用 dataglot query/shell 进程内执行联邦查询
