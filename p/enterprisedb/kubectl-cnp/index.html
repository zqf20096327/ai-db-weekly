kubectl 插件，用于管理 Kubernetes 上的 Cloud Native PostgreSQL 集群

综述（解读层）

这是 EnterpriseDB 发布的 kubectl 插件，用于在 Kubernetes 集群中管理 Cloud Native PostgreSQL。通过安装脚本部署于 macOS/Linux，Windows 用户从 releases 页面下载对应架构的压缩包并可校验 SHA256 完整性。使用前提是集群内已安装 Cloud Native PostgreSQL operator。它也兼容 OpenShift 环境下的 oc 命令。

  • 以 kubectl 插件形式运行，用于管理 Cloud Native PostgreSQL 集群
  • 兼容 OpenShift 环境中的 oc 命令
  • 提供 macOS/Linux 安装脚本和 Windows 各架构发行包，附 checksums.txt 校验文件

适用场景（解读层）

  • 在 Kubernetes 中运维 Cloud Native PostgreSQL 集群的场景
  • 在 OpenShift 环境中使用 oc 管理 PostgreSQL 集群的场景
  • 需要通过命令行安装并校验插件二进制完整性的部署流程
