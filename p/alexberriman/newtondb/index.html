综述（解读层）

NewtonDB 是一个零运行时依赖的嵌入式 JSON 文档数据库，面向工作集可完整载入内存的 TypeScript/Node 应用。数据与索引驻留内存，读取返回递归冻结快照，事务为集合粒度可串行化；可选 newtondb/node 提供基于 Linux 本地文件系统的 JSON 文件持久化适配器。仅支持 ESM，要求 Node ^22.13.0 或 24+，不支持浏览器、CommonJS、SQL 连接与复制。

  • 提供原子事务，发布含修订号与持久化状态的不可变 receipt，冲突时回滚且不暴露部分写入
  • 查询使用版本化语法，不含正则与任意函数，解析与执行强制深度、字节、结果数等上限
  • 文件适配器通过加锁、校验和信封、临时文件原子重命名与目录同步实现持久化，进程崩溃后可恢复完整快照

适用场景（解读层）

  • 工作集可载入内存的 Node.js/TypeScript 应用本地数据存储
  • 需要可序列化事务与冻结快照读取、且数据规模在数万条量级的应用
  • 需要通过自定义适配器接入其他持久化介质的项目
