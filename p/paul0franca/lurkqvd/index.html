从 SQL Server 抽取数据生成 QVD 文件并发布到 Qlik Cloud 的调度队列工具

综述（解读层）

LurkQVD 是一个数据管道工具：将 SQL 查询结果转换为 QVD 文件（在 Qlik 之外生成）并发布到 Qlik Cloud，同时提供任务调度、基于 Postgres 的执行队列、应用级重载、执行审计及邮件通知功能。定位为使用 Qlik Cloud 进行数据加载的工程团队。架构基于 Docker Compose，通过浏览器操作，提供具有三种角色和 API token 的 Web 界面。源数据库目前仅支持 SQL Server 和 PostgreSQL，PostgreSQL 处于测试阶段（beta），无 QVD 等效类型的字段会被转换为文本。敏感信息通过 Fernet 密钥在 Postgres 中加密。

  • 支持从 SQL Server（PostgreSQL 处于测试阶段）进行数据提取，以流式方式按批次生成 QVD，并将它们发布到 Qlik Cloud
  • 在 Postgres 中实现具有多个 worker 的执行队列，支持 cron 调度、手动执行和 API 触发；上传失败时，支持可分块续传的上传，而无需重新读取数据库
  • 提供角色（reader/editor/admin）、审计、API token、邮件通知，并对 Qlik API key、数据库及 SMTP 密码进行加密

适用场景（解读层）

  • 团队需要在不消耗 Qlik Cloud capacity 配额的情况下从源数据库生成 QVD 并自动发布
  • 将一组加载任务组织为 Qlik 应用，仅在全部成功时才执行应用重载
  • 通过 API token 将加载任务的执行集成到 Airflow 等编排器中
