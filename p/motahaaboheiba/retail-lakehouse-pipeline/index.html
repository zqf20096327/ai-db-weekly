🧭 简介解读层（AI·证据行可回查）

基于 Databricks 的零售湖仓端到端数据管道，双路径摄取配 dbt 与 Airflow

综述（解读层）

该仓库实现一条零售数据工程管道：PostgreSQL OLTP 与 S3 CSV 两条独立摄取路径汇入 Databricks 湖仓，dbt 完成 silver/gold 星系模型转换（含 SCD2 快照与增量模型），Airflow 在 Docker 中编排并行 DAG，消费层同时提供 Power BI 三页报表和 Genie 自然语言查询。README 明确主摄取路径为游标列+主键 upsert 而非 CDC。复现需自备 Databricks 工作区与 Ghost.build PostgreSQL 实例。

  • dbt 实现增量模型、SCD2 快照、元数据驱动 OBT 与星系 schema，123 个测试通过并作为 CI 合并门禁
  • Airflow DAG 在构建 dim_date 后分叉为 Sales 与 Supplies 并行分支，实测平均耗时从 9:03 降至 7:35
  • 任务级 on_failure_callback 将失败告警推送到 Gmail 和 Telegram 两个独立通道

适用场景（解读层）

  • 学习零售场景下 lakehouse 分层建模（bronze/silver/gold 与星系 schema）的完整实现
  • 需要 PostgreSQL 与 S3 文件双来源摄取及 SCD2 历史追踪的转换参考
  • 基于 dbt 测试套件构建 CI 数据质量门禁的工程实践参考
