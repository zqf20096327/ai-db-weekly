基于 Promise 的 TypeScript SQLite 封装层，支持原生与纯 JS 双驱动

综述（解读层）

trilogy 是一个基于 Promise 的 SQLite 数据库封装库，使用 TypeScript 编写。它不是 ORM，不提供关系特性，API 风格更接近 Mongoose 而非 SQL。内部通过 knex 构建查询并对外暴露；支持 sqlite3 原生 C++ 驱动、纯 JavaScript 的 sql.js 后端以及内存存储，可在运行时切换后端而无需修改其余代码。适合在 Electron、NW.js 等环境下使用 sql.js 以免编译原生模块。通过 npm 或 yarn 安装，需另装任一后端；采用 MIT 许可证。

  • 支持 sqlite3 原生驱动与 sql.js 纯 JavaScript 后端，以及内存存储
  • 通过 schema 定义 String、Date、'increments' 等类型，自动在 JavaScript 与 SQLite 类型间转换
  • 提供 onQuery、beforeCreate、afterUpdate 等生命周期钩子，并暴露内部 knex 查询构建器

适用场景（解读层）

  • 跨平台桌面应用（Electron / NW.js）中使用无需编译的 SQLite 后端
  • 需要以 Mongoose 风格 API 操作 SQLite 而非完整 ORM 的项目
  • 测试或性能敏感场景下使用内存存储处理不持久化的数据
