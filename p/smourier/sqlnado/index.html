基于 SQLite 的 .NET 轻量级对象持久化框架

综述（解读层）

SQLNado 是一个面向 .NET 开发者的 SQLite 封装与对象持久化框架，支持 netstandard2.0 与 .NET Framework 4.6+，无第三方依赖，可运行于 Windows、Linux 和 Android。它将类自动映射为表并提供 Save、Load、LoadAll 等操作，支持通过 .NET 编写自定义函数、排序规则和 FTS3 分词器，也可直接执行 SQL 命令使用全部 SQLite 功能。提供 NuGet 包和单文件 amalgamation 两种引入方式。

  • 类到表的自动映射，含 Save、Delete、Load、LoadByPrimaryKey、LoadByForeignKey 等操作，并自动同步类与已有表之间的模式
  • 支持 Where/OrderBy 的 LINQ/IQueryable 表达式，可将增量 BLOB I/O 以 .NET Stream 形式读写以降低内存占用，支持 FTS3/4 全文搜索及 .NET 编写的自定义分词器
  • 无第三方依赖，Windows 上可自动使用系统的 winsqlite3.dll；另提供单个 .cs 文件的 amalgamation 形式便于嵌入部署

适用场景（解读层）

  • 需要将 C# 类对象直接持久化到 SQLite 数据库的 .NET 应用
  • 跨 Windows、Linux、Android（Xamarin/MAUI）运行的跨平台应用
  • 需要在 SQLite FTS 全文搜索中使用自定义分词器或用 .NET 编写自定义 SQL 函数的项目
