TiDB 与 PostgreSQL 回放 10 万事件的开创性对比实验仓库

综述（解读层）

仓库记录一项预备性实验：对 2025 年 1 月 1 日的 10 万条 NYC TLC FHVHV 事件进行回放，比较 TiDB v8.5.2（经 TiFlash 查询）与 PostgreSQL 16.15，共 18 种配置（2 个 DBMS × 3 种回放比率 × 3 种查询客户端数），每种配置各运行一次。作者注明结果为描述性、两系统资源限制不同，且独立于更大规模的正式实验。适合需要查看原始实验工件与校验脚本的研究者。

  • 包含 18 个有效 run 目录、TSV 输入、系统性抽样清单与 SHA-256 校验和等工件
  • 提供 scripts/verify_results.py 脚本，仅用 Python 标准库复核校验和、配置矩阵与结果完整性
  • 实验覆盖 TiDB+TiFlash 与 PostgreSQL 各 9 个配置，全部达成 10 万行/唯一 ID 目标且无失败查询

适用场景（解读层）

  • 复现或审计该实验的输入数据与结果工件
  • 以该实验设计为参考设计类似 DBMS 回放对比实验
  • 学习使用 Python 标准库编写结果校验脚本
