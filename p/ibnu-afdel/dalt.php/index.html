🧭 简介解读层（AI·证据行可回查）

透明可读的 PHP 学习框架，用真实 SQL 与调试挑战教后端原理

综述（解读层）

DALT.PHP 是一个面向学习者的 PHP 框架，核心代码约 3000 行、25 个文件，可直接通读。它不做 ORM 与会话封装，用户需手写预处理 SQL、操作 $_SESSION、自行加 CSRF token。通过 Composer 创建项目后用 php artisan serve 运行；/learn 提供可选课程与 22 个故意损坏状态的调试挑战，可用 platform:remove 移除。要求 PHP 8.2+ 与 Composer 2.x，默认 SQLite，不支持生产部署。

  • 核心框架约 3000 行 PHP、25 个文件，路由、会话、认证逻辑均可直接阅读
  • 提供 19 课 DALT Core、60 课全栈理论、71 课 Build 课程及 22 个按行为验证的调试挑战，均位于 /learn 且可通过 artisan 命令移除
  • 支持 SQLite（默认）与 PostgreSQL，要求 PHP 8.2–8.5 与 pdo/pdo_sqlite 扩展，运行项目无需 Node.js

适用场景（解读层）

  • 想通过阅读框架源码和手写 SQL、CSRF、会话操作来理解路由、认证、数据库等后端机制的学习者
  • 需要带有可验证损坏状态、用 challenge:start/verify 命令练习调试的教学场景
  • 按 issue-tracking 应用从零构建的引导式课程（DALT Build）进行项目式学习
