将 ORCA Cascades 代价优化器植入单机 PostgreSQL 的扩展

综述（解读层）

pg_orca 把源自 Greenplum/Apache Cloudberry 的 ORCA 优化器四核心库及 PostgreSQL 集成层抽出，适配 PG18/19 并打包为 CREATE EXTENSION 可安装插件。它以 memo 结构和转换规则统一做逻辑改写与物理计划选择，含子查询去关联、连接序枚举等机制，经 planner_hook 挂接，默认关闭、按会话启用；无法处理的查询自动回退标准规划器，代价是更长的规划时间。

  • 基于 memo 与转换规则的 Cascades 式代价优化，逻辑改写与物理实现统一定价，支持相关子查询去关联、多种连接序搜索策略、eager aggregation 等改写
  • 通过 planner_hook 接入，pg_orca.enable_orca 默认 off，按会话/数据库/角色启用，不可处理的查询自动回退标准规划器
  • 同一源码树经 PG_VERSION_NUM 条件编译支持 PG18 与 PG19，提供 CMake/Ninja 构建与 ORCA 回归测试

适用场景（解读层）

  • 需要 ORCA 优化器能力的 PostgreSQL 18/19 单机环境
  • 评估相关子查询去关联、超出 join_collapse_limit 的连接序搜索等改写行为
  • 在数据库或角色级别按会话启用 ORCA、保留标准规划器回退的部署
