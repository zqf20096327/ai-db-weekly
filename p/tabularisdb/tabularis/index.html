综述（解读层）

Tabularis 是一款开源桌面 SQL 工作台，面向需要通过图形界面管理多种数据库的开发者与数据从业者。内置 MySQL/MariaDB、PostgreSQL、SQLite 驱动，其余数据库（ClickHouse、DuckDB、Redis 等）通过 30 个驱动插件接入；插件以 JSON-RPC over stdio 通信，可用任意语言编写。提供 SQL 笔记本、可视化 EXPLAIN 和内置 MCP 服务器，供 Claude、Cursor 等 AI 客户端读取 schema 并执行查询。通过 WinGet、Homebrew、Snap、Flatpak、AppImage 等方式安装。

  • 内置 MCP 服务器，供 Claude、Cursor、Devin 等 AI 客户端读取 schema 并运行查询
  • SQL 笔记本支持 SQL 与 Markdown 单元混排、跨单元变量 {{cell_N}} 及柱/折线/饼图
  • 驱动插件通过 JSON-RPC over stdio 通信，可用任意语言编写，并可从插件注册表安装

适用场景（解读层）

  • 需要在一个桌面应用中连接 PostgreSQL、MySQL、SQLite 及 ClickHouse、DuckDB、Redis 等多种数据库
  • 通过 MCP 让 Claude、Cursor、Devin 等 AI 客户端读取数据库 schema 并执行查询
  • 编写包含 SQL 与 Markdown 单元、跨单元变量和图表的分析型 SQL 笔记本
