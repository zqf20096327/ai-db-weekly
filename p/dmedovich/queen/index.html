综述（解读层）

Queen 是一个 Go 编写的数据库迁移库，迁移以代码形式定义，可执行 SQL 或 Go 函数，并记录已应用的版本与校验和。它提供可嵌入的 CLI 用于迁移作业，README 指明 PostgreSQL 为参考生产驱动，MySQL、SQLite、ClickHouse、CockroachDB 和 SQL Server 有驱动级别的保证。安装通过 go get 完成，要求 Go 1.26.3 或更新版本，采用 Apache-2.0 许可证。

  • 支持运行 SQL 或 Go 函数形式的迁移，并跟踪已应用版本与校验和
  • 提供可嵌入的 CLI 用于运行迁移作业，支持将迁移注册表编译为独立二进制用于 CI/CD
  • 支持 PostgreSQL、MySQL、SQLite、ClickHouse、CockroachDB 和 SQL Server 驱动

适用场景（解读层）

  • 在 Go 项目中以代码方式管理数据库结构变更
  • 在 CI/CD 流程中于应用部署前运行迁移
  • 需要跨多种数据库（如 PostgreSQL、MySQL、SQLite）执行迁移的项目
