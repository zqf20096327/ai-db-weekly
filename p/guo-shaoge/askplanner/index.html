面向 TiDB 查询优化的本地 AI 助手，以 Codex CLI 为运行时并提供领域提示词与文档上下文

综述（解读层）

askplanner 是一个针对 TiDB 查询优化器问题的本地 AI 助手，面向 TiDB 用户与调优人员。它本身不含 LLM 调用循环，而是作为中继与领域上下文层：生成调优系统提示词、规范化后交给 Codex CLI，并管理会话复用。支持本地 REPL 和 Feishu/Lark 机器人两种入口，为每个用户提供隔离的 git worktree 工作区以读取 TiDB 源码与文档。运行依赖 Codex CLI 已登录及本地 contrib/ 下的 TiDB 源码、文档与 skills 子模块。

  • 提供本地 REPL（cmd/askplanner）与 Feishu/Lark websocket 机器人（cmd/larkbot）两种交互入口，支持 reset、/model 等会话与模型管理命令
  • 为 Lark 用户提供基于共享 bare mirror 的每用户隔离 git worktree 工作区，支持 /ws switch 切换 TiDB 仓库版本，并通过 workspace.json 跟踪状态
  • 内置本地 usage dashboard（默认 127.0.0.1:18080），基于 JSONL 事件存储提供用户数、问题数、延迟、模型等指标及分页查询 API；附带 askplanner_migrate_userdata 数据迁移工具

适用场景（解读层）

  • TiDB 用户在本地命令行提问查询调优问题，结合 EXPLAIN ANALYZE 输出获取索引、IndexMerge 或 UNION ALL 改写等方向的解答
  • 通过 Feishu/Lark 群聊或单聊机器人向团队成员提供 TiDB 优化器问答服务，支持多 bot 实例与附件上传
  • 需要将 .askplanner/ 下的会话、用量与工作区数据迁移到新目录或新机器时使用迁移工具
