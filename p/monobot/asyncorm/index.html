受 Django ORM 启发的 Python 全异步 ORM

综述（解读层）

AsyncORM 是一个受 Django ORM 启发的全异步 Python ORM，当前仅支持 PostgreSQL，设计上便于接入其他数据库接口，可配合任意异步库使用，开发时以 sanic 为目标场景。README 标明其处于 alpha 阶段，迁移支持、prefetch_related、OneToOneField 等仍在待办中。

  • 提供全异步 ORM，受 Django ORM 启发
  • 当前仅支持 PostgreSQL，依赖 asyncpg 与 netaddr
  • 设计为可配合任意异步库使用，以 sanic 为考虑对象

适用场景（解读层）

  • 基于 Python asyncio 的 PostgreSQL 应用数据访问
  • 使用 sanic 等异步 Web 框架的项目
  • 需要以异步方式操作数据库的 Python3 项目
🔌 适配哪些库db_scan 程序判定

MariaDB、MySQL、PostgreSQL
