🧭 简介解读层（AI·证据行可回查）

将 SQLite 数据库自动暴露为 RESTful 和 WebSocket 实时 API 的 Node.js 命令行服务器

综述（解读层）

Soul 是一个 Node.js 命令行工具，读取指定的 SQLite 数据库文件，自动生成对应的 REST API 和 WebSocket 服务，无需手写接口代码。通过 soul -d 数据库 -p 端口 即可启动，支持基于 JWT 的认证模式（含登录注册、角色权限表），并提供扩展机制用于添加自定义 API 和托管静态内容。依赖 better-sqlite3，要求 Node.js 22 及以上版本。

  • 运行 soul -d -p <端口> 后自动为数据库生成 REST API 和 WebSocket 服务
  • 支持认证模式：基于 JWT 的登录/注册，包含 _users、_roles 等权限表，可配置 access/refresh token 有效期
  • 提供扩展机制，可用于添加自定义 API 和托管静态内容；可通过 Docker 或 npm（soul-cli）安装

适用场景（解读层）

  • 为现有 SQLite 数据库快速生成可查询的 CRUD API 接口
  • 需要数据库变更实时推送的场景（通过其 WebSocket 服务）
  • 原型开发或小型应用中需要带 JWT 认证的数据库 REST 服务
