零依赖的 Node.js 后量子 P2P 网状网络协议，含 3 跳洋葱路由。

综述（解读层）

Metrice 是一个基于 Node.js 核心库（node:crypto、node:net、node:sqlite 等）构建的去中心化 P2P 网状网络协议，不依赖任何外部 npm 包。它实现 ML-KEM-768 后量子密钥封装、Ed25519 节点身份、AutoNAT 可达性检测、CGNAT 反向隧道与内置 SSH-2 服务器，面向需要在 P2P 网络中运行匿名多跳路由与加密身份寻址的 Node.js 使用者。用户载荷上限 768 字节，电路 10 分钟后回收。

  • 实现 NIST FIPS 203 ML-KEM-768 密钥封装与 Ed25519 签名帧验证，节点标识为 SHA-256 派生的 16 字符 RFC 4648 Base32 字符串
  • 支持 3 跳洋葱路由电路，每跳经 ML-KEM-768 协商临时密钥并以 AES-256-GCM 分层加密，帧统一填充至 2048 字节
  • 提供 Rendezvous 反向 TCP 隧道用于 CGNAT/防火墙穿越，并内置支持 2FA Vault 认证的纯 JavaScript SSH-2 服务器与 HAProxy PROXY Protocol v1/v2 解析

适用场景（解读层）

  • 在 CGNAT 或防火墙环境下通过反向隧道与中继路由建立 P2P 连接
  • 需要后量子密钥协商的多跳匿名消息传输电路
  • 在 HAProxy/Nginx Stream 等四层代理后部署并解析真实客户端 IP，或供 Docker/Kubernetes 健康探针接入（独立 8050 端口）
