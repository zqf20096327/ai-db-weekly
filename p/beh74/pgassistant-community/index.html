综述（解读层）

pgAssistant 是一个开源 PostgreSQL 优化平台，提供数据库内省、工作负载分析、多种确定性 advisor（索引、参数、autovacuum 等），并将发现整理为带优先级和负责人的 Executive Plan。它不是实时监控系统，而是基于周期性采集构建持续改进闭环；支持单库与数千实例的集群模式，通过 Collector 与 Grafana 组件实现历史对比。LLM 辅助为可选功能，MIT 协议，提供 Docker 镜像。

  • 提供 Global、Index、Parameter、Autovacuum、Fillfactor 等确定性 advisor，输出可复现的建议
  • 支持将建议整合为带优先级、依赖与负责人的有序工作包（Executive Plan），并可生成 PDF 报告
  • 支持单库深度分析与集群模式（配合 Collector 与 Grafana 进行历史采集与趋势展示），LLM 辅助为可选项

适用场景（解读层）

  • 开发者和 DBA 对单个 PostgreSQL 数据库做 SQL、模式、配置与维护分析
  • 在数百至数千实例的 PostgreSQL 集群中集中采集、排序和跟踪整改事项
  • 周期性对比采集结果，跟踪建议的生命周期与工作负载变化
