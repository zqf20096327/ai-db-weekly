面向 TiDB 集群的自动化测试用例工具

综述（解读层）

TiPoC 是用 Go 编写的针对 TiDB 集群的自动化测试用例工具，通过 TOML 配置文件运行，部署在 TiDB 集群所在 tiup 服务器上且需要 sudo 权限。其能力清单包含高可用故障注入（kill、crash、按 label 灾难等）、数据加载、在线 DDL 及自动安装 sysbench 等模块，部分项目仍处于未完成状态。

  • 支持 kill、crash、按 label 灾难、重启、磁盘等高可用故障场景，网络故障尚未实现
  • 支持 load data、import into、select info outfile 等数据加载方式
  • 包含在线加索引、修改列、加索引性能测试及 scale in 扩缩容用例，内置超过 100 条基础测试用例

适用场景（解读层）

  • 对部署在 tiup 上的 TiDB 集群执行自动化测试用例
  • 进行 TiDB 高可用故障注入与数据加载相关的验证
  • 自动安装 sysbench 并运行在线 DDL 相关测试
