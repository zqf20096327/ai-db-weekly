基于 Scrapy 的扩展工具库，提供通用中间件、管道与动态 Item

综述（解读层）

AyugeSpiderTools 是一个 Python 3.11+ 的 Scrapy 扩展库，通过 pip 安装后用 ayuge 命令创建项目、生成 Spider 模板。它内置通用 middleware 和 pipeline，提供可动态赋值字段的 AyuItem，支持 MySQL、MongoDB、PostgreSQL、Oracle、Elasticsearch 存储，配置可从本地 .conf、Consul 或 Nacos 读取，并包含基于 RabbitMQ 的分布式任务分发方式。README 说明测试覆盖率较低，作者建议复杂存储需求可自行编写 pipeline。

  • 提供 AyuItem 动态字段赋值，并支持自定义数据去重与更新规则
  • 内置多种数据库存储管道（MySQL/MongoDB/PostgreSQL/Oracle/Elasticsearch）及 Kafka、RabbitMQ 消息推送
  • 支持 aiohttp、curl_cffi 请求方式、随机 UA 与通用代理中间件，配置可从本地 .conf、Consul、Nacos 读取

适用场景（解读层）

  • 需要快速生成 Scrapy 项目模板并统一管理配置的采集项目开发
  • 采集数据需写入多种数据库或推送至 Kafka/RabbitMQ 的场景
  • 基于 RabbitMQ 进行分布式部署的任务采集场景
