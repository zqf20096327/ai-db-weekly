通过 Shell 脚本一条命令自动完成 Oracle 数据库全流程安装的工具

综述（解读层）

OracleShellInstall 是一个 Shell 脚本工具，通过命令行参数自动化执行 Oracle 数据库安装流程，涵盖操作系统参数配置、依赖安装、用户创建、软件安装、数据库创建与补丁应用。支持单机、单机 ASM、RAC 三种模式及 Oracle 11gR2 至 26ai 版本。需以 root 用户在安装介质目录执行，要求 Bash >= 4；社区版仅支持单机模式，其他模式与高级功能属付费专业版。

  • 支持 single、standalone（ASM）、rac 三种部署模式，RAC 模式自动完成 SSH 互信、Grid 安装与 ASM 配置
  • 支持 Oracle 11gR2/12cR2/19c/21c/26ai 版本及 CentOS、RHEL、openEuler、麒麟等 20+ Linux 发行版
  • 提供 50+ 命令行参数（字符集、归档、PDB、补丁编号等），并配有在线命令生成器

适用场景（解读层）

  • 需要在 Linux 服务器上批量或重复安装 Oracle 单机数据库的环境
  • 需要部署单机 ASM 存储（含 UDEV 绑盘、multipath、磁盘组配置）的场景
  • 需要在多节点上搭建 Oracle RAC 集群（Grid Infrastructure、Scan IP、OCR 磁盘等）的生产环境
