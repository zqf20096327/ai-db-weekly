🧭 简介解读层（AI·证据行可回查）

基于 Raft 的高可用协作式限流服务，按复制状态节流 MySQL 写入

综述（解读层）

freno 是一个协作式限流服务，客户端在写入前通过 HTTP check 请求咨询是否可写，freno 本身不代理流量。当前实现可对多个 MySQL 集群按复制延迟阈值节流，支持静态或经 haproxy 动态获取探测主机列表，并能强制节流指定应用。节点通过 Raft 选主，仅 leader 采集指标并服务客户端。适用于批量写入任务按小块执行前检查的场景，由 GitHub Engineering 开发，MIT 许可。

  • 通过 HTTP check 接口以 200/404/417/429/500 状态码回答客户端是否可写，支持 HEAD 请求
  • 采集每个 MySQL 集群的复制延迟，超过预设阈值时对协作客户端节流，主机列表支持静态配置或经 haproxy 动态解析
  • 基于 Raft 共识协议实现高可用，仅 leader 节点采集指标并服务客户端

适用场景（解读层）

  • 批量加载、归档、schema 迁移、大规模更新等任务分块执行前咨询是否可写，避免复制延迟过高
  • 通过查询实际复制延迟判断副本数据有效性，缓解主写从读场景的写后读问题
  • 在多个应用共用数据库时，按需强制节流某些应用以让高优先级任务完成
