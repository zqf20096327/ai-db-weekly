🧭 简介解读层（AI·证据行可回查）

自托管的 Web 文件目录管理器，用 SQLite 编目并去重离线存储介质上的文件。

综述（解读层）

File Hunter 是一个自托管的 Web 文件管理器，用于对 USB 硬盘、备份盘、DVD、网络挂载和本地文件夹中的文件建立目录（含元数据与哈希），介质离线时仍可浏览和搜索，并可跨归档查找重复文件后执行合并。目标用户是需要管理大量离线存储的自托管/家庭服务器用户。首次运行时会创建虚拟环境并安装依赖，数据库、配置均存放在安装目录内，支持 Docker 和源码安装。

  • 跨 USB 驱动器、备份盘、DVD、网络挂载和本地文件夹编目文件元数据与哈希，介质离线时仍可浏览和搜索
  • 查找跨归档的重复文件，并在完整审计记录下进行合并
  • 通过浏览器访问，可在无桌面的 headless 服务器上运行；扫描期间 UI 保持响应

适用场景（解读层）

  • 管理多块离线硬盘/备份介质的家庭实验室（homelab）归档存储
  • 在 headless 服务器上通过浏览器编目和检索归档文件
  • 跨 TB 级归档定位重复文件并合并整理
