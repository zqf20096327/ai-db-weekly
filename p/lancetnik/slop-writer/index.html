Telegram 频道分析 MCP 服务器与 Claude Code 技能，基于 Telethon 与 SQLite

综述（解读层）

slop-writer 将 Telegram 频道数据接入 Claude Code 或 Codex：抓取帖子文本、媒体、 reactions、转发与评论线程，写入每频道一个的 SQLite 文件，并以 MCP 工具形式供代理查询；两条写路径（发布/改期帖子、封禁审计标记的账号）均置于权限提示之后。作者自述为管理个人频道而写的技能。运行状态存于项目根的 gitignored .tg-analytic/ 目录，指标时序仅覆盖实际抓取的时刻，无法回填。

  • 提供十三个 MCP 工具，抓取帖子、评论线程、外部转发者、内向引用及订阅者增长/流失数据
  • 在每次运行时构建仅追加的每帖指标时间序列，并支持按小时统计浏览量
  • 支持安排、改期、重写未来帖子及封禁审计标记的账号，写操作需权限提示

适用场景（解读层）

  • 通过自然语言查询频道热门帖子、转发来源与引用关系
  • 审计近约 48 小时的新订阅并识别 bot-farm 账号
  • 定时发布帖子并定期刷新旧帖指标以累积时间序列
