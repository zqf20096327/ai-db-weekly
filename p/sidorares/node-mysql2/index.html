Node.js 的 MySQL 客户端驱动，API 兼容 mysqljs/mysql，纯 JS 实现

综述（解读层）

MySQL2 是面向 Node.js 的 MySQL 客户端，其协议解析器在 MySQL-Native 基础上重写，API 与 Node MySQL 大体兼容，由两团队在 mysqljs 组织下协作。可安装于 Linux、macOS、Windows，无原生绑定依赖。README 未给出具体性能数据，性能描述出自项目自述。

  • 支持预处理语句、二进制日志协议、压缩连接、SSL 与认证切换
  • 提供 Promise 包装、连接池、自定义流及扩展的字符集与排序规则支持
  • 无原生绑定，通过 npm 安装，支持 TypeScript（需另装 @types/node）

适用场景（解读层）

  • Node.js 应用连接 MySQL 数据库执行查询
  • 从 mysqljs/mysql 项目迁移并使用预处理语句、Promise 等扩展特性
  • 需要连接池或压缩/SSL 连接的服务端数据访问场景
