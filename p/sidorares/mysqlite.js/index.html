以 MySQL 协议访问 SQLite 数据库的纯 JS 服务端

综述（解读层）

mysqlite.js 是一个数据库服务端程序，对外监听 MySQL 协议端口，将请求转发到本地 SQLite 文件。其实现由两部分组成：使用 mysql2 作为 MySQL 线缆协议服务端，通过 emscripten 编译的 SQLite 作为数据库客户端。安装方式为 npm 全局安装，启动命令需指定监听端口与 SQLite 数据库文件路径。使用者可用标准 mysql 命令行客户端连接操作。

  • 通过 MySQL 线缆协议（基于 mysql2 实现）对外提供服务，客户端可用 mysql 命令行连接
  • 底层使用 emscripten 编译的 SQLite 读写数据库文件
  • 全部为原生 JavaScript 实现，通过 npm 安装，启动命令为 mysqlite 端口 数据库路径

适用场景（解读层）

  • 环境中只有 MySQL 客户端工具、需要读取或写入 SQLite 数据库文件的场景
  • 需要将本地 SQLite 文件以数据库服务形式暴露在指定端口供连接访问的场景
