Python 数据 ETL 框架，通过处理管道支持 SQL 与 OLAP 星型模式加载

综述（解读层）

CubETL 是一个 Python 编写的数据 ETL 工具，将数据项送入处理管道并管理组件初始化、数据流、日志与清理。它提供 CSV/XML/JSON 等格式组件、SQL 读写，以及 OLAP 支持：可从 SQL 数据库生成 OLAP 模式、单次存储操作写入跨表事实并自动执行查找缓存。项目处于开发阶段，文档不完整，维护不频繁，需用 setup.py 或 docker 安装。

  • 支持 CSV、XML、JSON 格式的读取与生成，包含 SQL 查询、插入/更新、模式创建与加载
  • 提供 OLAP 星型模式生成与数据加载，可检查 SQL 数据库生成 OLAP 模式，并可导出 Cubes OLAP Server 模型配置
  • 可命令行工具 cubetl 运行，也可通过 Python API 使用，支持缓存、GeoIP、HTTP 请求等组件并可扩展

适用场景（解读层）

  • 将 CSV、SDMX、PC-Axis 等格式数据经过转换加载到 SQL 表或 OLAP 星型模式
  • 检查现有关系数据库并生成 OLAP 模式，配合 Cubes Server 与 CubesViewer 进行分析查看
  • 解析 Apache 日志、HTML 抓取、Wikipedia 大型 XML 等数据源并导入 SQL 数据库
