SpringBoot数据源文档工具，自动可视化表结构与监控数据库信息

综述（解读层）

ShowDB 是面向 SpringBoot 项目的数据库文档工具，引入 pom 依赖后访问 /db 路径即可自动生成项目内所有数据源的表结构文档页面，无需单独配置数据源连接。它提供表结构 SQL 迁移、Java 实体类与 MyBatis 代码生成、连接数与事务明细监控等功能。当前仅支持 MySQL，要求 JDK 1.8+ 和 SpringBoot 2.3.9+。

  • 引入 starter 依赖即可自动检测并文档化 SpringBoot 项目中已存在的单/多数据源
  • 支持表结构文档可视化、模糊搜索、建表 SQL 查看、表结构 SQL 迁移与文档下载
  • 提供 Java 实体类生成与可定制化的 MyBatis 代码生成，并监控数据源 IP 连接数、事务明细等数据库信息

适用场景（解读层）

  • SpringBoot 项目中随服务实时展示当前数据源的表结构文档
  • 单独启动一个服务集中注入多个业务库，作为统一入口管理公司内部数据库文档
  • 查询表数据量、索引大小、存储引擎等详细信息以及主从状态、数据库配置等监控信息
