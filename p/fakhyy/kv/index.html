🧭 简介解读层（AI·证据行可回查）

基于 SQLite 的本地键值存储 CLI，支持 SQLCipher 全库加密。

综述（解读层）

kv 是一个 Rust 编写的命令行工具，用于在本地以键值形式存取数据，底层使用 SQLite 存储。用户可通过 kv init 创建明文库，也可启用 SQLCipher 对整个数据库加密；密码通过交互式输入而非命令行参数传递。项目自述为起始实现，作者建议在存储重要机密前先在目标平台测试 SQLCipher 行为。

  • 提供基于 SQLite 的本地键值读写命令
  • 通过 SQLCipher 支持可选的全库加密，加密页面无法被普通 SQLite 读取
  • 密码采用交互式输入，不作为命令行参数传递

适用场景（解读层）

  • 在本地终端中管理键值数据
  • 需要在本地存储加密数据库的场景
  • 通过 cargo 从源码安装使用的 Rust 工具链环境
