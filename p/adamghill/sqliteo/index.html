综述（解读层）

SQLiteo 是一款原生 macOS SQLite 浏览器，用 Swift 编写。面向需要查看和查询 SQLite 数据库的 macOS 用户。提供 SQL 编辑器（Cmd+Enter 执行）、表名/列名/关键字自动补全、模糊搜索定位表、外键数据弹窗查看、SQL 查询历史保存及数据分页加载。安装为下载 .dmg 拖入应用文件夹；应用未经 Apple 开发者证书签名，需在系统设置中放行或用 xattr 命令清除隔离属性。采用 MIT 许可证。

  • 内置 SQL 编辑器，支持 Cmd+Enter 执行查询，提供表名、列名与 SQL 关键字自动补全
  • 提供侧边栏模糊搜索定位表、外键引用数据弹窗查看，SQL 查询自动存储到磁盘
  • 数据分页加载，应用未经 Apple 证书签名需手动放行

适用场景（解读层）

  • 在 macOS 上浏览和查看 SQLite 数据库表结构与数据
  • 编写并保存临时 SQL 查询，查询本地数据库
  • 通过外键弹窗查看关联表数据而无需离开当前界面
