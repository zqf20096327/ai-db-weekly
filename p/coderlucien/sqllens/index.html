🧭 简介解读层（AI·证据行可回查）

本地单容器运行的 TiDB SQL 诊断工具，解析 Plan Replayer 证据输出中文诊断报告。

综述（解读层）

SQLLens 面向 TiDB 用户，读取 PLAN REPLAYER DUMP 导出的 zip，经确定性规则引擎生成含变更操作、风险、成本与收益预估的中文六段式诊断报告。可选配置 OpenAI/Anthropic 兼容端点生成 AI 增强报告，AI 结论不推翻规则结论且失败自动降级。当前为 M0 单机 MVP，仅支持离线上传模式，在线直连为后续版本；端点固定绑定回环地址且无鉴权。

  • 规则诊断覆盖索引访问、统计信息偏差、非 Sargable 谓词等，每条建议附 DDL/SQL、风险提示、成本与收益预估四要素
  • 支持任意 OpenAI/Anthropic 兼容端点作为可选 AI 增强，仅发送约 2KB 有界结构化摘要，不配置则零出网
  • 解析层实现有界解压（单条目/总量上限）及 zip-bomb 与路径穿越防护，诊断数据仅存会话内存不落盘

适用场景（解读层）

  • 使用 TiDB PLAN REPLAYER DUMP 导出 zip 进行离线 SQL 诊断分析
  • 需要在数据不出本机的约束下生成可复现的中文诊断报告
  • 以只读方式获得现成 DDL 建议与回滚验证方案，不执行生产变更
