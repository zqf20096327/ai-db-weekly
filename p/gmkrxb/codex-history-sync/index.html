修复 Codex Desktop 本地历史显示问题的桌面工具

综述（解读层）

Codex History Sync 是一个 Vue 3 + Electron 桌面应用，用于处理 Codex Desktop 切换账号、认证方式或 provider 后历史对话不可见的问题。它读取 ~/.codex 下的 state_5.sqlite 和 JSONL 文件，提供 provider 同步、数据库诊断修复、备份恢复等操作；后端为 Python CLI（sync_backend.py），可脱离 GUI 单独调用。写入前自动创建备份，修复策略默认只补不删。适用于本地历史索引异常的用户，不支持多机合并或云端同步。

  • 提供 status/detect/diagnose/preflight/sync/repair/backup/restore 等命令行命令，支持 --codex-home 指定 Codex 数据目录和 --json 输出
  • 同步前执行环境预检（进程、SQLite schema、PRAGMA quick_check、写入权限），写入后校验并在失败时回滚 SQLite 与 JSONL 备份
  • 数据库修复功能从 sessions/ 与 archived_sessions/ 的 JSONL 重建缺失的 threads 记录、补齐标题/预览、修正 provider 元数据，默认只补不删

适用场景（解读层）

  • 切换账号、API Key、认证方式或 model_provider 后，Codex Desktop 左侧历史列表不显示或只显示一部分
  • 本地 state_5.sqlite 存在但历史索引记录缺失、标题为空、预览为空，或 JSONL 与 SQLite provider 不一致
  • 需要在写入前预览改动、写入前自动备份，或从备份恢复历史数据
