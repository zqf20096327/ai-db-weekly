🧭 简介解读层（AI·证据行可回查）

将SQL（MOQL语法子集）转换为多种数据库DSL的Java语法转换工具包

综述（解读层）

MOQL-Transx是MOQL工程的姊妹工程，包含moql-translator和moql-querier两个模块，用于将MOQL语法（SQL92子集）转换为MySQL、Oracle、DB2、SQLServer、Postgresql等关系数据库语法，以及ElasticSearch DSL、MongoDB DSL和DynamoDB DSL。它还为ElasticSearch和MongoDB提供查询器，接受SQL语句并返回二维表结构对象，面向习惯使用SQL的数据开发与分析人员。

  • 实现MOQL语法到ElasticSearch DSL、MongoDB DSL及DynamoDB DSL的转换，并支持match、fuzzy、knn等ES特性的扩展函数（UDF）机制
  • 提供ElasticSearch查询器和MongoDB查询器（MongoDBQuerier），接受SQL语句并返回二维表结构的RecordSet对象
  • 升级后的SqlTranslator接口支持通过translationContext参数传入上下文，以实现依赖search_after的深度分页转换；SupplementReader可读取结果中的total、max_score、sort等字段

适用场景（解读层）

  • 用SQL语句查询ElasticSearch或MongoDB，替代学习各自DSL
  • 将SQL语句批量翻译为不同关系数据库（MySQL、Oracle、DB2等）方言
  • ElasticSearch深度分页场景下生成带search_after参数的查询DSL
📖 README 首段存档原文 · 程序抽取

​ MOQL-Transx是MOQL工程的姊妹工程，其早期与MOQL工程在一起，后独立出来。其核心思想是想让数据库使用者只掌握一种语言，即SQL语言，就可以去查询访问各类不同的数据库，以此减小开发者，使用者的学习成本。由于各类数据库语法差异比较大，MOQL-Transx并不追求从SQL语义到各类数据库DSL语义的完整映射，更多是将最常用到的语法功能进行了映射。目前MOQL-Transx已经完成了从
