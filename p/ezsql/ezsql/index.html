PHP 数据库操作类库，通过统一的 CRUD 快捷方法访问多种数据库。

综述（解读层）

ezSQL 是一个 PHP 数据库访问类库，通过 Database 类（工厂模式加依赖注入容器）支持 mysqli、pgsql、sqlsrv、sqlite3 及 PDO 多种连接方式。它提供 CRUD 快捷方法和对应的全局函数，支持预编译语句开关。安装方式为 composer require ezsql/ezsql，v5 版本引入命名空间并对旧版接口有破坏性变更，许可证为 LGPL-3.0 加 MIT。

  • 支持 mysqli、pgsql、sqlsrv、sqlite3 及 PDO 多种数据库连接接口
  • 提供 select/insert/update/delete/create/drop/alter 等快捷 SQL 方法及 join、where、groupBy、limit 等子句构造函数
  • 可通过 prepareOn 启用预编译语句，或直接调用 query_prepared 执行参数化查询

适用场景（解读层）

  • PHP 项目中需要对多种数据库执行增删改查操作
  • 希望以方法调用而非手写 SQL 字符串构造查询语句（含 where 条件分组、多表连接）
  • 需要使用预编译语句或参数化查询执行数据库操作
