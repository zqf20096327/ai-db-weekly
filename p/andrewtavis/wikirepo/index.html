🧭 简介解读层（AI·证据行可回查）

基于 Python 的 Wikidata 框架，将查询结果转为 pandas DataFrame

综述（解读层）

wikirepo 是一个 Python 包，用于获取并利用结构化的 Wikidata 数据。它把用户请求转换为 Wikidata 的 QID/PID，通过核心函数 data.query 返回按位置、时间组织的 DataFrame，支持指定地理层级、时间跨度和年/月/周/日间隔。数据上传与地图功能在 README 中标注为 WIP（进行中）。适合需要从 Wikidata 提取公共统计数据的分析者使用。

  • data.query 函数按 locations、depth、timespan、interval 参数返回 pandas.DataFrame，结果按列合并
  • 查询会访问位置子页面数据，并使用 EntitiesDict 缓存已加载实体以供后续属性读取
  • 可通过 pip 安装（pip install wikirepo），依赖 wikidata 包进行数据加载和索引

适用场景（解读层）

  • 按国家或下级行政区（如美国县级行政区）提取人口、收入等时序统计数据
  • 为政治学与议会分析类项目提供数据基础（README 提及 poli-sci-kit 示例）
  • 以地球、大洲、国家名称字符串或 QID 直接查询 Wikidata 属性数据
