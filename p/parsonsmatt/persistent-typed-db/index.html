🧭 简介解读层（AI·证据行可回查）

为 Haskell persistent 库提供带幻型参数的 SqlBackend，实现多数据库查询的类型安全区分

综述（解读层）

该库为 Haskell 的 persistent 数据库库定义了带幻型参数的替代 SqlBackend 类型（SqlFor db）。使用场景是同一应用连接多个数据库（如主库与辅助库）：persistent 默认的 SqlBackend 句柄模式无法在编译期阻止查询用错数据库或跨 schema 组合实体，本库通过为每个 schema 定义空类型标签并用 mkSqlSettingsFor 声明实体，使错误的查询组合产生类型错误。配套提供 SqlPersistTFor、runSqlPoolFor、specializeQuery、specializePool 等工具，用于将现有 SqlPersistT 代码特化到指定数据库。

  • 定义 SqlFor db 幻型参数类型，使 PersistEntityBackend 与具体数据库绑定
  • 提供 SqlPersistTFor 类型同义词与 runSqlPoolFor 函数，替代 persistent 的 SqlPersistT 与 runSqlPool
  • 提供 specializeQuery 与 specializePool，可将通用 SqlPersistT 查询与连接池特化到指定数据库类型

适用场景（解读层）

  • 同一 Haskell 应用需要访问多个 schema 不同的数据库，并希望用错后端时在编译期报错
  • 已有 persistent 项目需要改造 runner 函数（runMainDB/runAuxDB）以区分各自的数据库
  • 使用 rawSql 等不绑定实体后端的查询，需要将其特化到指定数据库类型时

This library defines an alternate SqlBackend type for the Haskell persistent database library. The type has a phantom type parameter which allows you to write queries against multiple databases safely
