LeetCode 风格的刷题平台，集成 Monaco 编辑器与 Judge0 代码执行

综述（解读层）

LeetLab 是一个受 LeetCode 启发的在线编程练习平台，面向准备编程面试的开发者。前端基于 React、Monaco Editor 与 Tailwind，后端为 Node.js/Express + PostgreSQL（Prisma ORM），代码运行与验证通过 Judge0 API 完成，用户登录采用 JWT。README 列出多项待办任务，包括编辑器初始化问题修复、新增代码运行提交逻辑等，部分功能仍在开发中。

  • 支持 JavaScript、Python、Java 三种语言的代码编写与提交
  • 通过 Judge0 API 运行并验证代码，返回运行时间、内存与状态
  • 内置动态代码编辑器（Monaco Editor）、题目描述、测试用例与提交历史记录

适用场景（解读层）

  • 准备编程面试时的算法题练习
  • 多语言编码技能训练与提交记录跟踪
  • 作为全栈项目参考，学习 React + Express + Prisma + Judge0 的集成方式
