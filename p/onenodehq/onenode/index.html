多模态语义搜索框架，统一编排 MongoDB、Pinecone、MinIO、Redis 与 LLM

综述（解读层）

OneNode 社区版是一个本地运行的语义搜索框架，通过统一 API 编排 MongoDB 文档存储、Pinecone 向量检索、MinIO 对象存储、Redis 缓存队列及 OpenAI/Anthropic 等大模型服务，支持文本与图片的语义索引和查询，面向搭建 RAG、商品搜索等 AI 应用的开发者。需注意其依赖 Pinecone 云服务与外部 LLM API 密钥，且托管版 SDK 与本地版 API 不兼容；项目处于公开测试阶段，采用 MIT 许可证。

  • 通过统一 API 编排 MongoDB、Pinecone、MinIO、Redis 和 LLM 服务，提供 MongoDB 兼容的查询接口
  • 支持文本和图像的语义索引与搜索，后台异步处理嵌入生成与图片分析
  • 使用 Docker Compose 一键启动本地服务，提供 Python 和 JavaScript 的直连 API 调用示例

适用场景（解读层）

  • 构建基于自有数据的 RAG 问答应用
  • 电商场景的图文混合商品搜索
  • 跨文档与图片的内容管理与检索
