SQLite.swift 是一个覆盖 SQLite3 的 Swift 类型安全封装层

综述（解读层）

SQLite.swift 在 SQLite3 之上提供纯 Swift 接口，通过类型安全、可感知可选值的表达式构建器在编译期检查 SQL 语句语法与意图，支持全文检索、SQLCipher、WAL 模式配置与模式迁移，也可直接作为 C API 的轻量封装使用，可在 Linux 上运行（有限制）。面向 Swift 开发者，可通过 Swift Package Manager（from 0.17.0）或 Xcode 子项目方式安装，采用 MIT 许可证。

  • 提供类型安全、可感知可选值的 SQL 表达式构建器和链式惰性执行查询层
  • 支持全文检索、SQLCipher（经 SPM）、WAL 模式与 journaling 配置 API
  • 提供 prepareRowIterator(_:) 以抛出方式处理读取中的错误；同时可作为 C API 的轻量封装

适用场景（解读层）

  • Swift 应用中的本地 SQLite 数据存储与查询
  • 需要加密数据库（SQLCipher）或 WAL 日志模式配置的场景
  • 需要 SQL 语句在编译期做类型与语法检查的项目
