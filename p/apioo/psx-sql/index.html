从数据库表结构生成类型安全 PHP 类的代码生成库

综述（解读层）

PSX SQL 采用 database-first 思路：先构建数据库表结构，再据此自动生成每张表的实体、仓库及列类，使 PHP 数据库操作全程类型化。可通过 Symfony 控制台命令或编程方式调用 Generator 生成。需注意变更表结构后须重新生成类。适合以数据库模式为源、希望获得类型化仓库与实体的 PHP 项目。

  • 依据数据库表结构自动生成实体、仓库和列类，支持通过 Symfony 控制台命令或 PSX\Sql\Generator 类编程调用
  • 提供基于类查询语言的过滤构建器，可解析类似 GitHub/Jira 查询语法的条件表达式
  • 生成的仓库为完全类型化实现，表结构变更后需重新生成类

适用场景（解读层）

  • PHP 项目中希望基于既有数据库表结构生成类型化数据访问代码
  • 需要为用户提供类 GitHub/Jira 语法的复杂集合过滤查询
  • 使用 doctrine migrations 等工具先定义表结构、再自动生成模型层的开发流程
📖 README 首段存档原文 · 程序抽取

This library generates type-safe PHP classes from your database tables and thus allows you to interact with your database in a complete type-safe way.
