综述（解读层）

qStudio 是一款 SQL 查询客户端和笔记本工具，用于浏览数据库表、运行 SQL 脚本、对查询结果绘图并导出。通过 JDBC 支持包括 kdb+、MySQL、PostgreSQL、ClickHouse、DuckDB 在内的多种数据源，可运行于 Windows、macOS 和 Linux。其 SQL Notebook 支持用 Markdown 编写并生成报告，另含 Text2SQL 等 AI 辅助功能。

  • 支持 Windows、macOS、Linux 三大平台运行
  • 内置图表功能，执行查询后可选择图表类型绘制
  • 提供服务器树形浏览、语法高亮、代码补全和 SQL 笔记本（Markdown 生成报告）

适用场景（解读层）

  • 在图形界面中浏览和查询多种数据库（如 kdb+、PostgreSQL、ClickHouse、DuckDB）
  • 对 SQL 查询结果进行可视化绘图与数据导出
  • 编写包含 SQL 与 Markdown 的笔记本并生成报告
