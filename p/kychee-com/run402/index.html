面向 AI 代理的开源后端基础设施，通过 CLI/SDK/MCP 供应并计费

综述（解读层）

run402 是面向 AI 代理的后端即服务：代理可通过 CLI、TypeScript SDK 或 MCP 服务器供应 Postgres 数据库、认证、文件存储、serverless 函数与静态托管，并用 x402（Base 上的 USDC）或 MPP（Tempo 上的 pathUSD、比特币闪电网络 sats）付费，测试网原型层免费。本仓库为 MIT 许可的代理接口层，可自托管运行时位于 Apache-2.0 的 run402-core 仓库，托管云控制面为专有。代理与人均以独立 principal 身份操作，动作可归因。

  • 提供 CLI（JSON 输入输出、失败返回退出码）、同构 TypeScript SDK（Node 22/Deno/Bun/V8 isolates）与 MCP 服务器三类接口，共享同一类型化内核
  • 支持 Postgres 数据库、REST API、用户认证、内容寻址文件存储、静态站点托管、serverless 函数与图像生成，通过分阶段部署工作流交付
  • 支付与恢复机制包含幂等键、收据验证、PaymentPolicyError 保留上游响应，以及 PAYMENT_INTENT_PENDING 的固定重试路径

适用场景（解读层）

  • 让自主代理端到端供应、部署后端资源并自行支付，无需人工注册或控制台操作
  • 在 Claude Desktop、Cursor、Cline、Claude Code 等 MCP 主机中通过 MCP 工具调用 run402 操作
  • 在脚本与 CI 中以 CLI 配置、部署、检查和恢复应用，配合 --check/--plan/--require-plan 进行本地校验与网关审查
