Run402 的开源可自托管后端运行时核心，基于 Postgres/PostgREST 与 RLS

综述（解读层）

Run402 Core 是 AI 代理后端基础设施 Run402 的开源运行时部分，采用 Apache-2.0 许可。它提供本地项目创建、ReleaseSpec 规划提交、PostgreSQL 迁移、PostgREST/RLS 服务、静态内容服务、本地存储与路由、可信函数执行及可移植项目归档导入，通过 Docker Compose 和 npm 运行。仓库不包含云版控制面、主体权限图、计费等托管能力，代理侧 SDK/CLI/MCP 位于另一仓库 kychee-com/run402。

  • 运行 runtime-kernel：ReleaseSpec 计划/提交、内联 PostgreSQL 迁移、PostgREST/RLS、静态内容与本地存储路由、可信函数与单节点定时触发、Astro SSR
  • 提供 @run402/functions、@run402/release、@run402/nwc（NIP-47 客户端）等公共包，部分已被 Cloud 消费
  • 支持对已验证的可移植项目归档进行检查、验证与导入，附带 docker-compose 本地栈与一致性 fixtures

适用场景（解读层）

  • 在本地机器自托管运行 Run402 支持的应用运行时切片
  • 使用可移植归档在 Cloud 导出与 Core 导入之间迁移项目
  • 基于 Postgres/RLS、存储与 serverless 函数构建供 AI 代理操作的本地后端
