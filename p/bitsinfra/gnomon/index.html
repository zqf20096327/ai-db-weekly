🧭 简介解读层（AI·证据行可回查）

以 PostgreSQL 扩展实现的数据库数据版本控制，支持分支、diff、合并与撤销。

综述（解读层）

Gnomon 是一个安装于 PostgreSQL 15-18（含 RDS、Aurora、Supabase 等托管环境）的扩展，为被跟踪的表提供历史记录、分支、diff、合并与回退能力。分支仅保存变更内容、以连接字符串形式使用，面向需要为 agent 运行、PR 或测试提供独立数据库分支的开发者。组件包括 SQL 核心、可选 C 模块、Go 编写的 CLI/MCP server/review 应用、TypeScript 与 Python SDK、GitHub Action 及多语言集成，采用 PostgreSQL License。

  • 提供 track、use、begin 等接口，分支以连接字符串或 SET gnomon.branch 方式使用，支持按时间点查询历史
  • 支持分支间合并、SQL 检查、冲突处理（计数累加、JSON 按键合并、文本按行合并）、事务级撤销与 gnomon bisect 定位事务
  • 包含 MCP server、TypeScript/Python SDK、GitHub Action、历史流式输出到 Kafka/NATS/webhook 及 dbt 快照，历史可归档至对象存储

适用场景（解读层）

  • 为 agent 运行、pull request 或测试各分配一个生产数据的只读主库分支，事后审查并合并或撤销其变更
  • 在迁移到分支上验证 schema 变更与数据，合并时一并带入主库
  • 查询数据库在任意历史时刻的状态，或将变更流接入 Kafka、NATS、webhook 与 dbt
