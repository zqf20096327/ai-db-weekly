基于 Java 的数据库迁移工具，将 JDBC 兼容数据库迁移至 PostgreSQL

综述（解读层）

Migrate2Postgres 是一个 Java 编写的迁移工具，用于将 JDBC 兼容 DBMS（内置 SQL Server 模板）迁移到 PostgreSQL。它通过 JSON 配置文件定义源/目标连接、SQL 类型映射、名称转换及前后置查询，分 DDL（生成建表脚本）与 DML（复制数据）两阶段执行，支持并发线程与运行时变量。需要 JRE 1.8 及相应 JDBC 驱动。

  • 支持任意 JDBC 兼容数据库作为源，内置 SQL Server 模板，可按文档模式添加其他源
  • JSON 配置文件支持模板继承、defaults.conf 默认值、%变量% 运行时求值及 Java 系统属性传参（如密码）
  • 提供 DDL、DML、ALL 三种命令：DDL 生成可人工审查修改的建表 SQL 脚本，DML 按配置复制数据并支持多线程

适用场景（解读层）

  • 将 SQL Server 等数据库的模式和数据迁移到 PostgreSQL
  • 需要自定义类型映射（如 NVARCHAR 转 TEXT）、名称转换或迁移前后执行触发器启停等查询的场景
  • 希望先审查/修改生成的 DDL 脚本再执行，或通过 JVM 参数注入连接凭据的迁移流程
