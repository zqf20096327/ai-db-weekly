🧭 简介解读层（AI·证据行可回查）

基于 Pydantic 模型的数据适配层，用统一接口读写多种数据库与文件格式

综述（解读层）

Pydapter 是一个 Python 数据适配库，为 Pydantic 模型（也支持 dataclass 等模型）提供 from_obj/to_obj 统一读写接口，覆盖 SQL（PostgreSQL、MySQL、SQLite）、NoSQL（MongoDB、DynamoDB）、向量库（Qdrant、Weaviate、Pinecone）、图数据库（Neo4j、ArangoDB）及 JSON、CSV、Excel、Parquet 文件，各适配器支持异步操作，并可通过继承 Adapter 类自定义扩展。适用于需要在多种存储间迁移数据的 AI 流水线与多环境部署场景。通过 pip 安装，可按需安装 extras 集成。

  • 提供 Adapter.from_obj/to_obj 统一读写接口，覆盖 SQL、NoSQL、向量库、图数据库与 JSON/CSV/Excel/Parquet 文件，均支持异步
  • 支持 Pydantic 模型及 dataclass 等其他模型框架，允许自定义序列化方法
  • 支持通过继承 Adapter 类创建自定义适配器，v1.0.0 起 API 稳定，Apache-2.0 许可

适用场景（解读层）

  • LLM 文档处理流水线将同一数据写入关系库、向量库、图库等多种存储
  • 同一应用按环境切换存储后端（本地 SQLite / 云端数据库），仅改配置不改代码
  • 在不停机前提下逐步迁移存储系统（如双写迁移 MongoDB 到 PostgreSQL）
