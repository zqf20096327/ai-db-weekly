SOCI：提供多后端数据库访问接口的 C++ 库

综述（解读层）

SOCI 是一个 C++ 数据库访问库，最初由 Maciej Sobczak 在 CERN 开发，作为 Oracle 的抽象层，后扩展为支持多数据库后端。它支持 DB2、Firebird、MySQL/MariaDB、ODBC、Oracle、PostgreSQL、SQLite 3。构建需 C++14 编译器、CMake 3.23+，可选依赖 Boost。采用 Boost 软件许可证发布。4.0 系列支持 C++98。

  • 提供 DB2、Firebird、MySQL/MariaDB、ODBC、Oracle、PostgreSQL、SQLite 3 等多个数据库后端
  • 构建要求支持 C++14 的编译器（或 MSVS 2017+）与 CMake 3.23+，可选使用 Boost
  • 以 Boost Software License 许可证分发，通过 GitHub Actions 与 AppVeyor 进行 CI 构建

适用场景（解读层）

  • C++ 项目中通过统一接口访问多种数据库
  • 需要在 C++14 环境接入 Oracle、PostgreSQL、MySQL 等后端的应用
  • 依赖 ODBC 驱动连接特定数据库的场景
