MiniVectorDB 参赛独立复核分支，修复超时风险并加固镜像构建

综述（解读层）

这是 OceanBase 2026 大赛 MiniVectorDB 题目的第二轮独立开发分支，实现支持磁盘表目录、行编解码、SQL 执行、精确向量查询、持久化向量索引和事务的数据库，默认使用官方 f4d4e266 的 JSONL 协议。README 记录了超时风险修复、镜像构建加固与 Agent prompt 材料重构，并保留历轮实验证据。需 C++20 编译器与 Python 3 运行测试，支持 CMake 构建与 Docker 镜像运行。

  • 支持 CREATE TABLE、INSERT/SELECT/UPDATE/DELETE、L2_DISTANCE 精确 TopK、向量索引与 BEGIN/COMMIT/ROLLBACK 事务
  • 4096 字节页存储，共享单文件表目录，提供进程崩溃恢复模型与 fsync 后确认的提交策略
  • 附带本地协议检查器、契约基准脚本与 CI 工作流，区分本地结果与正式评分

适用场景（解读层）

  • OceanBase 2026 大赛 MiniVectorDB 赛题的开发与提交前自查
  • 需要精确向量查询与事务、持久化能力的本地 JSONL 协议数据库实验
  • 复现历轮性能对照实验与崩溃恢复、强制外排等独立测试
