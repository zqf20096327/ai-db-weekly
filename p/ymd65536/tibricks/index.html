TiDB Cloud + Kubernetes 数据注入 + Databricks 可视化的 AI 记忆 PoC 指南

综述（解读层）

这是一份 PoC 执行指南文档，演示从 Kubernetes 多个 Pod 向 TiDB Cloud 写入数据，通过 Databricks JDBC 连接实现数据可视化，并集成 mem9 作为 AI 代理长期记忆存储。提供 uv 本地运行、Docker 容器、K8s Pod 三级部署步骤及 Secret 管理说明。面向希望验证 TiDB 扩展性与 AI 数据利用的工程师。

  • 支持本地 uv、Docker、Kubernetes 三种方式运行数据写入脚本，脚本使用 pytidb 创建库表并写入 sensor_events 表，pod_name 列记录数据来源
  • 提供 Databricks 通过 MySQL JDBC 连接器接入 TiDB Cloud 的分步操作，可在笔记本中以 SQL 和 Spark 读取数据
  • 集成 mem9 自托管服务，通过 API 与 mnemo CLI 创建和检索记忆，数据存入 TiDB 的 memories 表

适用场景（解读层）

  • 验证 TiDB Cloud 在多 Pod 并发写入下的扩容行为
  • 用 Databricks 笔记本对 TiDB 数据做 SQL 查询与 Python 处理
  • 为 AI 代理搭建基于 TiDB 的长期记忆存储与检索流程
📖 README 首段存档原文 · 程序抽取

Kubernetesの複数PodからTiDBに対してデータを投入してTiDBのスケーリングを検証しつつ、Databricksを使ってTiDBを可視化します。挿入されたデータが正しく可視化されることを確認することで、TiDBのスケーリングが正しく行われていることを検証したいです。 また、挿入したデータをAIが読めるようにすることで、AIがTiDBのデータを活用できることを検証します。
