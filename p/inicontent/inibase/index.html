基于文件的 Node.js 无服务器关系型数据库，提供 ACID 事务

综述（解读层）

iniBase 是一个纯 TypeScript 编写的基于文件的关系型数据库，数据以表和列为单位存入独立文件，通过 Node.js 的 npm/pnpm/yarn/bun 安装。单表 DML 具备崩溃原子性，多表原子性通过 begin/commit/rollback 事务 API 提供，并有事务内限制（如无读己之写、每表仅一次变更、禁 DDL）。Windows 环境需额外安装 zcat、sed、gzip 等 Unix 命令。

  • 写入前日志加崩溃恢复，单表 DML 崩溃原子，多表事务支持级联删除原子执行
  • 按列文件存储，支持 gzip 压缩、增量写入日志、内置缓存与列投影、表连接
  • 读取无锁，采用乐观版本重试；支持 begin/commit/rollback 事务接口与模式校验

适用场景（解读层）

  • Node.js 应用中需要文件级存储与 ACID 保证的嵌入式数据管理
  • 需要事务化级联删除与崩溃恢复的场景
  • 不适合安装独立数据库服务的无服务器环境（Windows 需装 Unix 工具或 WSL）
