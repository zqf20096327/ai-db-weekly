基于 Shell 脚本的 MySQL 5.7 二进制包自动化安装工具

综述（解读层）

该项目提供 MySQL_install.sh 脚本，用于在 CentOS 7.x 系统上以二进制方式自动安装 MySQL 5.7。脚本需与安装介质放在同一目录并用 root 运行，支持默认安装（软件装 /mysql/mysoft、数据 /mysql/mydata、端口 3306）和自定义安装（用户指定路径、端口、管理员账号密码），并包含取消安装选项；运行前会检查 /etc/hosts 中的本机 IP 与 hostname。示例介质为 mysql-5.7.29 linux-glibc2.12 x86_64 tar 包。

  • 提供默认、自定义、取消三种安装选项，默认安装路径为 /mysql/mysoft 与 /mysql/mydata，端口 3306
  • 安装前自动检查 /etc/hosts 中本机 IP 与 hostname 配置
  • 支持自定义软件目录、数据目录、端口及管理员用户与密码

适用场景（解读层）

  • 在 CentOS 7.x 服务器上通过二进制包部署 MySQL 5.7
  • 需要指定自定义安装路径、数据目录或端口的部署场景
  • 安装后验证服务端口监听与 mysqld 进程状态
