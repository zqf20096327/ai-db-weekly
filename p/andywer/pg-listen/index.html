基于 PostgreSQL LISTEN/NOTIFY 的 Node.js 发布/订阅消息订阅库

综述（解读层）

pg-listen 是一个 Node.js 库，封装 PostgreSQL 的 LISTEN 与 NOTIFY 语句，实现数据库客户端间的通知消息收发。适用于使用 PostgreSQL 并需要进程间消息传递的 Node.js 项目。它提供自动重连、连接健康检查、错误事件与 TypeScript 类型定义，需 Node.js 8+ 与 TypeScript 3；使用前须调用 listenTo 订阅频道。采用 MIT 许可证，通过 npm 或 yarn 安装。

  • 通过 NOTIFY 语句发送消息、通过 LISTEN 订阅通知，支持任意负载
  • 自动检测连接断开或无响应并重连，提供 connected/error/notification/reconnect 等事件
  • 提供 TypeScript 类型定义，支持设置 DEBUG=pg-listen:* 启用调试日志

适用场景（解读层）

  • 在多个 Node.js 客户端之间通过 PostgreSQL 传递通知消息
  • 需要订阅特定频道并处理数据库推送通知的应用
  • 使用 TypeScript 的 Node.js 项目中实现基于数据库的发布/订阅通信
