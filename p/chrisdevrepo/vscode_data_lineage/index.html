🧭 简介解读层（AI·证据行可回查）

VS Code 扩展，从 .dacpac 或 SQL Server 数据库元数据生成可交互 SQL 依赖血缘图。

综述（解读层）

这是一个在 VS Code 中可视化 SQL Server 系数据库对象依赖关系的扩展。它从 .dacpac 文件或连接 SQL Server、Azure SQL、Fabric Data Warehouse、Synapse Dedicated SQL Pool 读取 DDL/目录元数据，生成可搜索、可上下游追踪的依赖图，支持 DDL 预览、表数据剖析和 Draw.io 导出；接 GitHub Copilot 等语言模型提供 @lineage 自然语言查询。血缘仅基于静态元数据，动态 SQL、触发器、同义词及外部 ETL 流水线不在解析范围内，Synapse serverless 池不受支持。

  • 支持 .dacpac 文件与 SQL Server / Azure SQL / Fabric / Synapse 专用池的实时连接，可复用 MSSQL 扩展的已保存配置文件
  • 提供对象搜索、上下游依赖追踪、最短路径、Schema View 概览，以及存储过程/视图全文检索和 DDL 预览
  • 通过 @lineage 接入 VS Code 语言模型提供方进行自然语言血缘问答，仅此功能需要 Copilot 等提供方，其余功能可独立使用

适用场景（解读层）

  • 在修改表、视图或存储过程前查看其上下游依赖，定位孤儿节点、环依赖和枢纽对象
  • 由使用 SSDT/.dacpac 工作流的 SQL Server、Azure SQL 或 Fabric 数据仓库开发者浏览库内对象关系
  • 对已连接的数据库按需做列级统计剖析，或通过 @lineage 用自然语言查询依赖路径
