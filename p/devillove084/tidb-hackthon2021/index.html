🧭 简介解读层（AI·证据行可回查）

基于eBPF拦截存储I/O完成路径以削减内核存储栈开销的黑客松项目

综述（解读层）

该项目为TiDB黑客松参赛作品，已完成idea梳理、可行性分析与环境搭建。作者借鉴Xok Exokernel的downloaded code思路，计划通过在内核I/O completion路径挂载BPF函数、为文件描述符打标签并抽取文件偏移来发起后续I/O，以绕过文件系统与BIO层。README列出了文件-块映射、I/O粒度不匹配、并发锁与公平性等设计难点，后续尝试用Rust for Linux构建内核模块。

  • 为文件描述符打标签，在块I/O完成中断hook中将存储块传递给BPF函数，抽取文件偏移并重新发起I/O
  • 设计支持BPF的自定义数据结构（如B树、LSM），采用非原地更新结构避免读写冲突
  • 计划使用Rust for Linux构建内核模块及Rust版libbpf工具函数demo

适用场景（解读层）

  • 高速存储设备（NVMe）场景下减少内核存储栈软件开销
  • 希望在内核侧处理应用特定磁盘数据结构遍历（如B+树）的存储系统
  • 与标准Linux文件系统共存、尽量少修改应用的内核存储扩展实验
📖 README 首段存档原文 · 程序抽取

Kernel-bypass框架(如SPDK)以及用户态存储的处理方式可以降低内核开销，但通常需要定制，需要对应用程序进行更改，缺乏隔离性，在I/O使用率不高时会浪费大量等待时间，并且在计算存储中需要定制硬件。所以，本次设计希望使用一个支持标准OS的机制来降低高速存储设备的软件开销。当用于拦截I/O时，可以在应用中使用这些函数进行处理，以此来避免内核和用户空间的上下文切换和数据拷贝。
