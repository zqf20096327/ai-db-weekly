Postgres 实时同步引擎，基于 HTTP 协议读取并分发数据。

综述（解读层）

Electric 是一个 Postgres 读路径同步引擎，将 Postgres 数据同步到客户端或其他消费端。核心同步协议基于低层 HTTP API，可与 CDN 集成做数据分发；部分复制通过 Shapes 管理，提供客户端库与框架集成。要求 Postgres 开启逻辑复制，当前处于 Beta 阶段，使用 Apache 2.0 许可证，核心服务以 Elixir 实现。

  • 基于 HTTP API 的同步协议，API 定义在 OpenAPI 规范中，可与 CDN 集成进行数据分发
  • 通过 Shapes 机制管理部分复制，提供 React（useShape hook）、Elixir 等客户端库与框架集成
  • 包含可选的 Phoenix LiveDashboard 用于监控 VM 指标、进程信息、ETS 表等运行状态（无鉴权，需自行限制端口访问）

适用场景（解读层）

  • 需要将 Postgres 数据实时同步到前端应用或客户端的场景
  • 依赖 Postgres 逻辑复制进行数据读取分发的架构
  • 通过 React hook 等集成方式在组件中消费 Postgres 数据
