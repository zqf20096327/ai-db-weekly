演示在 Docker SQL Server 上对 EF Core 后端运行自动化数据库测试的示例项目

综述（解读层）

该项目展示针对 SQL Server 的自动化数据库测试：解决方案包含 Database（实体、EF 上下文与迁移）、Domain（CQRS 实现）、Domain.Tests（实体查询与更新测试）和 Api 四个部分。测试通过 xUnit + Respawn 实现，运行于 Docker 中的 SQL Server 容器；依赖 .NET SDK 9.x、dotnet-ef CLI 和 Docker。配套提供 bash 脚本启动容器并注入连接串环境变量。

  • CRUD 操作的自动化数据库测试示例，使用 xUnit 与 Respawn
  • 提供 dotnet-ef 生成建库脚本、Docker 启动 SQL Server 并建库的脚本流程
  • 包含可在 GitHub Actions 中执行的构建流水线示例（build_test.yml）

适用场景（解读层）

  • 为 .NET + EF Core 项目搭建针对真实 SQL Server 的自动化测试流程
  • 在 CI/DevOps 环境中运行数据库测试的参考配置
  • 演示 CQRS 分层结构下的实体查询与更新测试写法
