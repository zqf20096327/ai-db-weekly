MongoDB Compass 的 Web 版，浏览器中访问 MongoDB 图形界面

综述（解读层）

该项目将 MongoDB Compass 移植到 Web 环境，前端基于原 @mongodb-js/compass-web v1.46.2 重新构建打包。用户通过 npm、Docker 或 Docker Compose 部署后即可在浏览器中访问 MongoDB GUI，支持 Atlas、Amazon DocumentDB 和 Azure Cosmos DB。连接字符串在启动时固定，需开启 --enable-edit-connections 才能在界面中增改连接；内置 Basic auth 与 OIDC 两种认证方式，仅保护 Compass Web 本身而非数据库凭据。源码构建依赖 node-gyp 和 pnpm。

  • 移植 Compass Desktop 的多项功能：JSON/CSV 结果导出、JSON/CSV 数据导入、Gen AI、连接编辑和 Mongo Shell
  • 支持 npm、Docker、Docker Compose 三种部署方式，默认监听 8080 端口
  • 提供 Basic auth 和 OIDC（Authorization Code + PKCE）两种认证，并可通过 CLI 标志或 CW_ 前缀环境变量配置服务器选项

适用场景（解读层）

  • 在浏览器中为团队提供集中部署的 MongoDB 图形管理界面
  • 连接 MongoDB Atlas、Amazon DocumentDB 或 Azure Cosmos DB 进行数据查询与导入导出
  • 通过 OIDC（如 Keycloak）对接企业单点登录后访问数据库 GUI
