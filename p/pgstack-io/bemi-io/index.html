PostgreSQL 数据变更自动追踪工具，基于 WAL 逻辑解码实现 CDC

综述（解读层）

Bemi 通过连接 PostgreSQL 的 WAL 并实现 CDC 模式，自动记录数据变更并写入同库的 changes 表，支持 before/after 状态与时间旅行查询，无需修改现有表结构。面向需要审计追踪、历史数据回溯或变更回滚的应用团队。运行依赖 Node.js、Java 与 NATS 服务器，数据库 wal_level 须设为 logical；追踪 before 状态需将表设为 REPLICA IDENTITY FULL。许可证为 SSPL-1.0。

  • 连接 PostgreSQL WAL 进行逻辑解码，自动将数据变更写入同库 changes 表，无需改动现有表结构
  • 记录变更的 before/after 状态、操作类型、提交时间，支持按条件过滤查询历史数据
  • 可通过 ORM 包为底层变更附加应用上下文（如用户 ID、API 端点）

适用场景（解读层）

  • 为数据库变更生成审计日志，用于合规或向客服与外部客户展示变更记录
  • 在不实现事件溯源的情况下检索历史数据，或按时间点回滚/前滚变更
  • 将变更作为实时数据流发送给应用，或用于分布式系统间的变更追踪与问题排查
