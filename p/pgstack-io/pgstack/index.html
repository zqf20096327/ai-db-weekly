提供带记录的临时 PostgreSQL 访问会话的开源 CLI

综述（解读层）

PgStack CLI 用于从终端启动临时的、可记录的 PostgreSQL 访问会话，生成临时连接 URL，供 psql 或其他数据库客户端使用。使用者需拥有 PgStack 账户并配置 Access 的项目；该 CLI 连接托管的 PgStack API，仓库本身不含可自托管的后端。会话最长一小时，支持只读模式、延长与撤销。

  • 支持以 --read-only 启动只读会话，代理以只读事务模式运行并设置 60 秒语句与事务内空闲超时，按规则放行 SELECT 类语句、拦截写操作
  • 支持会话的创建、延长、撤销与列表管理，凭据存储于本地配置文件，支持 --json 输出用于脚本
  • 通过安装脚本分发独立可执行文件并校验 SHA-256，提供 macOS（Intel/Apple Silicon）与 Linux（glibc/musl、x64/arm64）及 Windows 版本

适用场景（解读层）

  • 工程师或团队管理员需要临时访问生产或 staging 环境数据库进行排查时，通过带 reason 的会话连接 PostgreSQL
  • 需要防止误写数据库时，使用只读会话以只读事务和语句超时方式连接
  • 脚本或自动化流程中通过 --json 输出管理会话生命周期
