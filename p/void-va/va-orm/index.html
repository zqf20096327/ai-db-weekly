基于 Schema-first、Prisma 风格语法的 TypeScript ORM，无查询引擎二进制

综述（解读层）

VA-ORM 是一个 TypeScript ORM，支持 PostgreSQL、MySQL、SQLite（SQLite 需 Bun 的 bun:sqlite，Node 环境仅支持 PostgreSQL/MySQL）。采用 Prisma 风格的 schema 定义，通过 CLI 完成 generate、migrate、db push/pull 等操作，无查询引擎二进制文件。数据库驱动以可选 peer 依赖安装。当前版本 0.1.x，API 尚在稳定过程中。

  • 提供 raw SQL、事务、聚合、关系查询、cursor/keyset 分页，@updatedAt 字段在写入时自动刷新
  • 提供 HTTP 驱动（HttpDriver），用于无 TCP socket 的 serverless 环境，SQL 方言与占位符风格由协议自动解析
  • CLI 支持 schema 校验、代码生成、文件迁移（up/down/status）、schema 与数据库间的 push/pull；提供 NestJS 适配器

适用场景（解读层）

  • 使用 TypeScript 且需要 schema-first 工作流（生成客户端、迁移、内省）的项目
  • 无法建立到数据库 TCP 连接的 serverless 运行环境（通过 SQL over HTTP）
  • 基于 Bun 运行时的 SQLite 应用（零额外依赖）
