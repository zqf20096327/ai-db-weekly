quellog 是一个用 Go 编写的 PostgreSQL 日志分析命令行工具

综述（解读层）

quellog 读取 PostgreSQL 日志文件，生成包含 SQL 性能、事件错误、锁等待、检查点和连接会话等内容的概览报告。面向 DBA 和运维人员。工具支持 stderr、CSV、JSON、syslog 及多家云厂商日志格式，可即时解压 gzip/zstd/tar/zip/7z 归档，并支持按时间、数据库、用户、应用过滤与 HTML/JSON/YAML/Markdown 导出，另有实时跟随模式。采用 PostgreSQL License 发布。

  • 支持 stderr、CSV、JSON、syslog 及 AWS RDS、Cloud SQL、Azure、CNPG 等云厂商日志格式，可即时解压 gzip、zstd、tar、zip、7z 归档
  • 提供逐查询性能分析、auto_explain 执行计划、锁等待与死锁检测、检查点与连接会话统计
  • 可导出 JSON、YAML、Markdown 及带交互详情的独立 HTML 报告，支持 --follow 实时监控与按时间/数据库/用户/应用过滤

适用场景（解读层）

  • 分析本地或云托管 PostgreSQL（RDS、Cloud SQL、Azure、CNPG）的日志文件，排查慢查询与错误
  • 检测锁等待、阻塞查询与死锁，以及检查点频率、WAL 写入等运维指标
  • 生成 HTML/Markdown 报告用于周期性巡检，或以跟随模式持续监控日志
