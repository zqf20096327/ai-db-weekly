DC3 出品的 SQLite 数据库解析与数据恢复（carve）命令行工具

综述（解读层）

SQLite Dissect 是 DC3 开发的 Python 命令行工具，用于解析 SQLite 数据库及其配套 journal 文件。它通过分析已分配内容和建表语句自动生成签名，对表 b-tree 的未分配内容进行 carving 恢复，支持 WAL 提交记录的时间线解析。面向数字取证分析人员，导出格式包括 text、csv、xlsx、sqlite 等；不支持 without rowid 表、虚拟表及索引 b-tree，rollback journal 目前仅支持输出 csv。

  • 基于已分配数据自动生成签名并对表 b-tree 的未分配内容和 freeblocks 进行 carving，无需用户提供签名
  • 自动检测并解析 WAL 文件，按提交记录顺序分配版本；可指定 rollback journal 文件（当前仅输出 csv）
  • 支持导出为 text、csv、xlsx、sqlite、case 多种格式，可递归搜索目录下 .db/.sqlite/.sqlite3 文件

适用场景（解读层）

  • 数字取证中恢复 SQLite 数据库中已删除或被部分覆盖的表记录
  • 解析含 WAL 文件的数据库并生成 schema 变更历史时间线
  • 批量解析目录下的多个 SQLite 文件并导出为 csv/xlsx/sqlite 供后续分析
