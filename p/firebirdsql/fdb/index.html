Firebird 2.5 的 Python DB-API 2.0 传统驱动

综述（解读层）

fdb 是面向 Firebird 2.5 关系数据库的 Python 驱动，符合 Python Database API 2.0 规范，对 Firebird 3.0 仅提供有限支持，不支持 Firebird 4 及更新版本。README 说明该项目已不再积极开发，维护有限，并建议使用 Firebird 3 及以上版本的用户改用官方 firebird-driver 包。文档托管于 fdb.readthedocs.io。

  • 提供符合 Python Database API 2.0 规范的接口
  • 支持 Firebird 2.5，对 Firebird 3.0 提供有限支持
  • 通过 pip install fdb 安装，采用 MIT 许可证

适用场景（解读层）

  • 运行 Firebird 2.5 数据库的 Python 应用程序
  • 维护仍依赖该旧版驱动的既有 Python 项目
  • 需要对老版本 Firebird 进行 DB-API 2.0 方式访问的环境
📖 README 首段存档原文 · 程序抽取

This package provides LEGACY Python Database API 2.0-compliant driver for the open source relational database Firebird version 2.5., with limited support for Firebird 3.0.
