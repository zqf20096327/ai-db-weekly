Python 美股撮合引擎模拟器，含 WebSocket/UDP 行情分发与交互式看板。

综述（解读层）

该项目用 Python 实现模拟美股交易所机制的订单撮合引擎，支持限价单与市价单的价格-时间优先撮合，并通过 Kafka、Redis、PostgreSQL 构建多服务架构。系统分为网关、撮合引擎、行情服务、数据库与 Streamlit 看板五部分，README 提供了 WebSocket 与 UDP 组播的基准测试数据。依赖 uv 管理与 Docker Compose 部署。

  • 价格-时间优先撮合限价单与市价单，通过 Kafka 传递订单流与行情
  • WebSocket 增量推送与 UDP 组播行情分发，含序列号断线恢复与快照回退机制
  • 提供 FastAPI REST 接口、Streamlit 看板与市场模拟器，支持 Docker Compose 一键部署

适用场景（解读层）

  • 学习或验证撮合引擎与订单簿数据结构的设计
  • 搭建行情分发架构（WebSocket 增量 vs UDP 组播）的测试环境
  • 通过 REST API 或模拟器生成订单流做撮合与回测相关的实验
