面向 AI Agent 的状态存储数据库，基于 OceanBase SQL 引擎支持向量、全文与标量混合检索。

综述（解读层）

seekdb 是由 OceanBase 团队开发的开源数据库（Apache 2.0），定位为 AI Agent 的状态存储。它基于 OceanBase SQL 引擎，兼容 MySQL 协议，可在嵌入式库、单机服务器或 OceanBase 分布式集群三种模式下运行。核心机制包括：通过 Change Stream 异步索引管道解耦写入与索引构建，两级 HNSW 索引支持增量向量即时可查，并提供内核级 COW 的 FORK/MERGE 数据库快照。安装支持 pip 安装 pyseekdb SDK、Docker 镜像、Homebrew 及 Linux 一行式脚本。

  • 支持向量、全文与标量过滤在单条 SQL 查询中执行，查询同时访问增量与快照 HNSW 索引
  • 提供 FORK DATABASE / MERGE TABLE / DROP DATABASE 的内核级写时复制快照机制
  • 兼容 MySQL 协议与完整 ACID，支持嵌入式、单机服务器和 OceanBase 分布式集群部署

适用场景（解读层）

  • Agent 记忆与状态存储：持续写入观测并在毫秒级检索，配合 FORK/MERGE 沙箱进行探索与回滚
  • RAG 与知识检索：在一条 SQL 中组合向量、全文与关系过滤
  • 通过 LangChain、LlamaIndex、Dify 等框架集成，用于语义搜索与企业 AI 应用
