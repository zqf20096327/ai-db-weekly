🧭 简介解读层（AI·证据行可回查）

本地运行的 Node MCP 服务器，为 Obsidian 库提供语义搜索、知识图谱与笔记编辑。

综述（解读层）

obsidian-brain 是一个独立的 Node MCP 服务器，直接读取 vault 目录中的 .md 文件，无需在 Obsidian 内安装插件。它以 stdio 单进程运行，通过 SQLite 索引实现块级语义检索（RRF 融合 FTS5 BM25）、知识图谱分析与笔记写入，写入后增量重建索引。适用于使用 Claude Desktop、Cursor 等 MCP 客户端并希望本地处理笔记内容的用户；首次启动会下载约 34 MB 嵌入模型并自动索引 vault。

  • 提供 18 个 MCP 工具，覆盖搜索读取、图谱分析（find_path_between、detect_themes、rank_notes）与笔记写入操作
  • 检索通过 SQLite 实现，语义嵌入为标题粒度分块，hybrid 模式用 RRF 融合向量排名与 FTS5 BM25
  • 支持通过环境变量切换 Ollama 本地嵌入模型（如 qwen3-embedding、nomic-embed-text、bge-m3），数据保留在本机

适用场景（解读层）

  • 在 Claude Desktop、Claude Code、Cursor 等 MCP 客户端中查询和编辑 Obsidian vault 笔记
  • 分析笔记间的连接关系、主题聚类与路径（find_connections、find_path_between、detect_themes）
  • Obsidian 未运行时对任意 .md 文件夹进行索引、搜索和写入
