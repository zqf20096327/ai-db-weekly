🧭 简介解读层（AI·证据行可回查）

面向开发团队的 MCP 语义记忆服务，用 Rust 与 Postgres/pgvector 存储检索隐性知识

综述（解读层）

Tribal 是一个自托管的 MCP 记忆服务器，用于从开发工作中捕获调试经验、启发式规则与决策依据，并通过 MCP 协议供编码代理检索。项目使用 Rust 编写，依赖 Postgres 加 pgvector 做向量存储。README 提供基于 just 的本地搭建流程，要求 Rust 1.89+、Docker、sqlx-cli 等工具。适合需要团队知识沉淀与代理接入的开发团队。

  • 通过 MCP 协议（stdio transport）向编码代理提供知识检索
  • 使用 Rust 实现，数据存储基于 Postgres 与 pgvector 向量扩展
  • 提供基于 just 的数据库启动、迁移、检查与测试命令

适用场景（解读层）

  • 为团队沉淀开发过程中的调试经验与决策依据
  • 让 Claude Code 等 MCP 客户端读取项目隐性知识
  • 自托管语义记忆服务的本地部署与研究
