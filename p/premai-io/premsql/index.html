综述（解读层）

PremSQL 是一个面向开发者的开源 Python 库，用于构建完全本地运行的 Text-to-SQL 流水线，定位在需要数据不出本地的自主数据分析场景。它提供数据集、生成器、执行器、评估器、错误自纠错数据构造和 LoRA/QLoRA 微调等组件，并附带基线 Agent、自托管 Playground UI 和基于 FastAPI 的 AgentServer。执行器原生支持 SQLite，也可接入 LangChain SQLDatabase。

  • 提供从数据集、SQL 生成、执行、评估到微调（全量/LoRA/QLoRA）的完整 Text-to-SQL 组件链
  • 支持执行引导式解码：生成 SQL 执行失败时依据错误信息自动重试纠正
  • 内置基线 Agent 支持自然语言查询、分析、绘图，可通过 AgentServer 与 Playground 自托管部署

适用场景（解读层）

  • 在不依赖第三方闭源服务的环境下搭建私有数据库的自然语言查询与分析
  • 为 Text-to-SQL 任务准备数据集并微调小型语言模型
  • 通过 Playground 和自托管 API 测试或部署自定义 Text-to-SQL Agent
