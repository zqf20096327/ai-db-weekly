🧭 简介解读层（AI·证据行可回查）

GUN 是一个用于去中心化图数据同步的开源网络安全协议。

综述（解读层）

GUN 由 Mark Nadal 于 2014 年创建，是一个图数据同步协议及配套工具集，采用 CRDT 冲突解决与加密机制，支持本地优先、离线与端到端加密的数据同步。图数据模型可承载键值、文档、表格等多种形式。安装方式包括 npm install gun、CDN 引入脚本或 Docker 运行中继节点，适用于构建多人实时协作应用的开发者。

  • 提供实时 P2P 状态同步，采用 CRDT 实现冲突解决
  • 图数据模型兼容键值、文档、表格等多种数据形式
  • 支持本地优先、离线使用与端到端加密，核心引擎约 9KB（gzip）

适用场景（解读层）

  • 构建多人实时协作与去中心化应用
  • 需要离线优先、设备间数据同步的场景
  • 部署中继节点为开发团队提供数据同步服务
