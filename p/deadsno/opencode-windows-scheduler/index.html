🧭 简介解读层（AI·证据行可回查）

OpenCode v2 插件，用于以 cron、DAG、矩阵方式调度 AI 代理任务并提供本地仪表盘

综述（解读层）

该插件为 OpenCode v2 提供 AI 代理任务的调度与编排能力，包含 cron 与一次性运行、dependsOn DAG 管道、矩阵扇出、质量门（命令通过才标记成功）、SQLite 历史、指标与本地 Web 仪表盘。任务注册到操作系统原生调度器（Task Scheduler、launchd、crontab），OpenCode 关闭时仍可运行。需 OpenCode v2 与 Node.js 20+，通过 opencode plugin add 安装。注意 Windows 默认仅在用户登录时运行。

  • 支持 cron、一次性、git 提交、文件变更、MCP 事件和带 HMAC 的 webhook 六类触发方式
  • 提供 24 个代理工具与内置 skill，涵盖调度、管道、观测与管理，任务经原生 OS 调度器注册可在 OpenCode 关闭后运行
  • 可观测性包含 SQLite 历史、Prometheus /metrics、OTLP 导出、JSONL 日志与含 14 天分析的本地仪表盘

适用场景（解读层）

  • 需要按依赖顺序串联多步代理任务（DAG）或对一个模板在多个仓库扇出并行运行
  • 需要质量门验证（如 npm test 通过才计为成功）并结合重试、超时与崩溃恢复保证任务可靠性
  • 需要本地化的运行历史、成本与时长指标分析，无需 SaaS 或遥测的私有部署调度
