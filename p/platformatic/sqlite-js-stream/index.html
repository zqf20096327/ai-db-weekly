Litestream 的 Node.js 移植，基于 node:sqlite 实现 SQLite 流复制与灾难恢复

综述（解读层）

这是 Litestream 的 Node.js 移植版本，用 TypeScript 编写，基于 Node 24 内置的 node:sqlite 模块，实现 SQLite 的流复制与灾难恢复。仓库为 pnpm workspace，包含核心库、S3 与 PostgreSQL 上传策略及按需读取数据库页面的原生 VFS，适合需要在 Node.js 环境中做 SQLite 复制备份的团队。

  • 基于 Node.js 内置 node:sqlite 模块，以 LTX 文件实现流复制与同步/恢复及分页恢复
  • 提供 S3 和 PostgreSQL 两种上传策略作为副本客户端
  • 附带原生 SQLite VFS，可按需读取数据库页面

适用场景（解读层）

  • 需要对 SQLite 数据库做流式复制与灾难恢复备份的 Node.js 项目
  • 使用 S3 或 PostgreSQL 作为复制目标存储的场景
  • 需要按需读取远程 SQLite 数据库页面以降低恢复开销的场景
