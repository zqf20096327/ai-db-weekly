用于创建 AWS RDS 数据库实例及相关资源的 Terraform 模块

综述（解读层）

该模块是 Cloud Posse 发布的 Terraform 模块，用于在 AWS 上开通 RDS 数据库实例，支持 MySQL、Postgres、SQL Server、Oracle 引擎。一次调用会创建 DB 实例、Option Group、Parameter Group、Subnet Group、Security Group，并可在 Route53 生成 DNS 记录。要求 Terraform >= 1.3、AWS provider >= 5.92.0，使用时须指定 db_parameter_group_family 与 database_port 等输入。

  • 一次调用创建 DB 实例、Option Group、Parameter Group、Subnet Group、Security Group 及 Route53 DNS 记录
  • 支持 MySQL、Postgres、SQL Server、Oracle 四种数据库引擎，可指定字符集（Oracle/SQL Server 通过 charset_name，MySQL/MariaDB 通过 db_parameter）
  • 支持安全组入站规则配置（CIDR、前缀列表、安全组）、备份保留期、RDS Blue/Green 低停机更新以及由 Secrets Manager 托管主用户密码

适用场景（解读层）

  • 在 AWS VPC 中以基础设施即代码方式开通 MySQL、Postgres 等关系数据库实例
  • 需要为数据库端点自动创建 Route53 DNS 记录并配置安全组访问控制的环境
  • 需要统一管理资源命名标签（集成 cloudposse/label 模块）的多环境基础设施部署
🔌 适配哪些库db_scan 程序判定

MariaDB、MySQL、Oracle、PostgreSQL、SQL Server
