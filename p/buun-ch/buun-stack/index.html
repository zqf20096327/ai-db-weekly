🧭 简介解读层（AI·证据行可回查）

基于 k3s 的远程可访问 Kubernetes 家庭实验室模板，集成 OIDC 认证与开源数据/AI 组件栈

综述（解读层）

buun-stack 提供一套以 k3s 为底座的家庭实验室部署方案，通过 Just 任务文件编排安装流程，使用 Cloudflare Tunnel 提供外部访问，核心组件为带 pgvector 的 PostgreSQL 集群和 Keycloak OIDC 认证，可选模块覆盖数据湖（Iceberg/Lakekeeper）、分析（Trino/ClickHouse/Superset）、编排（Dagster/Airflow）与 LLM 应用（Ollama/Langfuse）。安装依赖 mise 与 just 命令；默认存储为 k3s local-path，Longhorn 改为可选模块。适合希望在本地集群搭建自托管数据与开发环境的用户。

  • 核心必装组件：CloudNativePG 管理的 PostgreSQL 集群（含 pgvector 扩展）与提供 OIDC/OAuth2 单点登录的 Keycloak
  • 可选模块覆盖数据与分析栈（JupyterHub、Trino、ClickHouse、Lakekeeper、Superset、Dagster、Airflow）、ML/LLM 栈（MLflow、KServe、Ollama、vLLM、Langfuse）、可观测性（Prometheus、Grafana、Tempo、Loki）及密钥管理（Vault + External Secrets Operator）
  • 通过 Just 任务运行器部署，提供 quick start 命令序列；`custom-example/` 目录包含 Airbyte、Bytebase、Cube、Longhorn 等按需启用模块

适用场景（解读层）

  • 搭建可远程访问的自托管 Kubernetes 家庭实验室，统一 OIDC 单点登录
  • 构建包含数据摄取、转换、查询与编排的本地开源数据栈
  • 部署本地 LLM 推理与 AI 应用组件（Ollama、LibreChat、Langfuse）并支持 NVIDIA GPU 调度
