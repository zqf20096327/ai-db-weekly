Hermes Agent 的本地 SQLite 记忆提供器，单文件存储、工具化维护

综述（解读层）

hermes-local-memory 是一个面向 Hermes Agent 的开源 SQLite 记忆提供器，将档案、别名、原始历史、事实、卡片等存入单个本地数据库，无需运行独立记忆服务。提供 memory_* 工具集与 CLI，支持 FTS5 检索、上下文注入、dry-run 优先的整理维护，以及从 Hermes markdown 和 Honcho API 导入。项目处于 alpha 状态，README 建议先试导入并检查后再切换生产环境。

  • 提供 memory_search（FTS5 检索）、memory_context、memory_conclude、memory_consolidate 等 agent 可调用工具
  • CLI 支持 peers/aliases/cards/facts 检查、显式事实增删、dry-run 优先的整合维护与补丁校验
  • 支持 Hermes markdown 与 Honcho API 的幂等导入，保留原始消息且不修改 Honcho 源数据

适用场景（解读层）

  • 为 Hermes Agent 配置本地可审计的记忆后端，替代默认 markdown 记忆
  • 将 Hermes 内置 markdown 记忆或 Honcho 数据迁移至 SQLite 存储
  • 通过 CLI 检查、修复别名与事实，或运行定时记忆维护任务
