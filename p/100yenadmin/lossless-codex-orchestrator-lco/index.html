🧭 简介解读层（AI·证据行可回查）

本地 Codex 会话索引与编排层，经 MCP/CLI 向主 Agent 提供检索与 dry-run 指令

综述（解读层）

LCO 是一个 npm 全局安装的本地工具，将 ~/.codex/sessions 下的 Codex 会话导入 SQLite，用 FTS5 字段加权检索，为每条线程生成含目标、阻塞、生命周期的 prepared 卡片，并通过 CLI、MCP 服务器和 OpenClaw 插件暴露同一套工具。适合在多仓库大量使用 Codex 并以 Hermes/MCP 编排器的用户；仅偶尔运行单个短会话者用处有限。导入有单文件 256MB/20万事件上限。

  • 将本地 Codex 会话索引进 SQLite，支持字段加权 FTS5 搜索与相关性/时效混合排序
  • 为大会话生成确定性 summary leaves，Agent 可按 1k 简报或 4k 证据包有界展开而非加载全文
  • 提供 dry-run 指令包，Codex start/resume/send/steer/interrupt 动作在执行前可审查目标与动作；实时控制路径固定为 approvalPolicy=never 且只读无网络沙箱

适用场景（解读层）

  • 让主 Agent 通过 MCP/OpenClaw 检索、分诊跨仓库的 Codex 线程而无需重读完整记录
  • 维护 attention inbox 与项目摘要，回答哪些工作活跃、被阻塞、陈旧或已完成
  • 在 Hermes 等 stdio MCP 代理路径下对 Codex 会话做需审批的接力与续作操作
