🧭 简介解读层（AI·证据行可回查）

基于 WiscKey 思路的 Rust LSM 存储引擎，键值分离以降低 I/O 放大。

综述（解读层）

VelarixDB 是一个以 Rust 编写的嵌入式 LSM 键值存储引擎，采用 WiscKey 论文的键值分离设计：SST 中仅存键和 32 位值偏移，值存于独立 vlog，从而减少 compaction 期间读写的数据量。面向需要在 Rust 应用中嵌入键值存储的开发者。项目仍在开发中，未达生产可用；键上限 65536 字节，值上限 2^32 字节，不支持范围查询等尚未实现的功能。

  • 键值分离存储：SST 中保存键与 32 位值偏移，值存放于独立 value log，compaction 时不读写值数据
  • 提供原子 Put/Get/Delete/Update 操作、垃圾回收、基于 Value Log 的崩溃恢复、布隆过滤器与 SST 索引，memtable 使用 Crossbeam SkipMap（无 Mutex）
  • 以 100% safe stable Rust 编写，运行于 Tokio 异步运行时，采用 Sized Tier Compaction Strategy（STCS）

适用场景（解读层）

  • 需要嵌入 Rust 应用的键值存储场景（非独立服务器，非关系型数据库）
  • 写入密集、希望减少 compaction 数据搬移以降低 SSD 磨损的工作负载
  • 安装方式为 cargo add velarixdb，通过 DataStore API 进行 Put/Get/Delete/Update，支持经 serde 存取 JSON 数据
