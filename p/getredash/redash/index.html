🧭 简介解读层（AI·证据行可回查）

基于浏览器的数据查询、可视化与仪表盘共享平台

综述（解读层）

Redash 是一个运行在浏览器中的数据查询与可视化工具，供 SQL/NoSQL 用户探索、查询并分享来自各类数据源的数据，组织内其他成员可查看结果。其内置查询编辑器带 schema 浏览器与自动补全，仪表盘支持定时刷新与条件告警，UI 功能均通过 REST API 暴露。项目采用 BSD-2-Clause 许可证，部署可使用官方提供的 AWS/GCE 镜像。

  • 内置支持 35 种以上 SQL 与 NoSQL 数据源，并提供可扩展的数据源 API
  • 查询编辑器包含 schema 浏览器与自动补全，可视化支持拖拽创建并组合为仪表盘
  • 支持按自定义间隔定时刷新图表与仪表盘、基于数据条件触发告警，UI 可用操作均提供 REST API

适用场景（解读层）

  • SQL 用户连接数据库进行查询探索并将结果可视化为仪表盘
  • 在组织内通过分享链接共享可视化与查询，实现报告与查询的互相评审
  • 对业务数据配置定时更新与变更告警
