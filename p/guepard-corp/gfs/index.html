🧭 简介解读层（AI·证据行可回查）

GFS 是为数据库提供 Git 式版本控制的 CLI 工具，基于 Docker 隔离运行环境。

综述（解读层）

GFS（Git For database Systems）为 PostgreSQL、MySQL、SQLite 数据库提供提交、分支、checkout 回滚等 Git 式操作，面向 AI 编码代理和开发者。它用 Docker 管理隔离的数据库容器，通过 MCP 服务器（stdio/HTTP）供 Claude Code、Cursor、Cline 等代理调用，支持 schema diff、数据导入导出和懒克隆远程 PostgreSQL。项目处于活跃开发阶段，API 可能变动。

  • 提供 commit、branch、checkout、log 等 Git 式数据库版本控制命令，支持 HEAD~N 等修订引用语法
  • 内置 MCP 服务器（stdio 与 HTTP 模式），可被 MCP 兼容的 AI 代理直接调用
  • 支持 PostgreSQL 13-18、MySQL 8.0-8.1、SQLite 3；实验性的 copy-on-read 远程 PostgreSQL 懒克隆，含 source_changed/source_drift/pull 等同步检查机制

适用场景（解读层）

  • AI 编码代理操作数据库前自动提交检查点，出错后用一条命令回滚
  • 在独立分支上试验迁移或批量改动，再合入主数据库
  • 通过 gfs clone 懒克隆远程 PostgreSQL 用于本地测试或只读分析
