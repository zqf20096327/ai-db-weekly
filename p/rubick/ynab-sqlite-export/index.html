🧭 简介解读层（AI·证据行可回查）

将 YNAB 账户全量数据导出为本地 SQLite 文件的零依赖 Python 脚本

综述（解读层）

该工具通过 YNAB API 将账户下所有预算、账户、分类、收款方及交易导出到本地 SQLite 文件，采用纯 Python 3 标准库实现，无第三方依赖。支持基于 server_knowledge 游标的增量同步，首次全量抓取，后续仅拉取变更并以 upsert 方式写入；仅读取不写回 YNAB，本地编辑不会被同步。适合想用 SQL、pandas、Grafana 或 AI 代理查询个人预算数据的用户。

  • 导出 budgets、accounts、categories、payees、transactions、subtransactions 等表，金额由 milliunits 转为两位小数
  • 基于 sync_state 表存储游标实现增量同步，未变更预算每次仅需 4 次 API 调用，支持 --full 强制全量重建
  • 附带 Claude Code skill（.claude/skills/ynab-db/SKILL.md）与 AGENTS.md，为 AI 代理提供 schema 及软删除、转账、拆分交易等数据约定说明

适用场景（解读层）

  • 用 SQL、DB Browser、pandas 或 Grafana 对 YNAB 预算数据进行自定义查询与分析
  • 通过 cron/launchd/GitHub Actions 定时运行以维护本地最新数据副本
  • 让 Claude Code 等编程代理直接以自然语言查询本地财务数据库
