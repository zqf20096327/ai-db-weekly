基于 MyBatis 的增强框架，通过 QueryWrapper 构建 SQL 查询

综述（解读层）

MyBatis-Flex 是一个 MyBatis 增强框架，仅依赖 MyBatis 本身，无其他第三方依赖。开发者通过 @Table 注解实体类、继承 BaseMapper 即可获得 CRUD 与分页能力，QueryWrapper 用于以链式方式构建 select、where、join、group by 等查询；同时支持无实体类的 Row 映射与多数据库方言。实体类需经构建生成对应的表字段类。适用于 Java 项目中使用 MyBatis 的数据访问层。

  • 仅依赖 MyBatis，无其他第三方依赖，支持 JDK 8 至 25
  • 通过 QueryWrapper 构建查询条件，支持分页、联合主键及多种主键生成策略
  • 支持 Row 映射，可在无实体类的情况下进行数据库增删改查

适用场景（解读层）

  • Java 项目中使用 MyBatis 进行数据库 CRUD 与分页查询
  • 需在没有实体类的场景下操作数据库
  • 可脱离 Spring 原生运行，也可与 Spring 或 Spring Boot 集成
