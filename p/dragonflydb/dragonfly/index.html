内存键值数据存储，兼容 Redis 与 Memcached API，采用多线程架构。

综述（解读层）

Dragonfly 是用 C++ 编写的内存数据存储，提供与 Redis 和 Memcached 兼容的 API，现有客户端无需改代码即可连接。它支持多线程运行，通过 --cache_mode 启用自适应缓存淘汰，支持 cron 定时快照、Prometheus 指标导出和 HTTP 控制台。键过期上限约 8.5 年，超出会被截断。README 中的性能数据来自 memtier_benchmark 的自测结果，供参考。

  • 兼容 Redis 与 Memcached API，支持 port、requirepass、maxmemory 等常见 Redis 参数
  • 支持 cluster_mode、snapshot_cron 定时备份、cache_mode 自适应缓存淘汰
  • 主端口同时识别 RESP 与 HTTP 协议，并提供 Prometheus 兼容的 /metrics 端点

适用场景（解读层）

  • 以 Redis 或 Memcached 为缓存的现有应用，寻求不改代码接入的内存数据存储
  • 需要定时快照持久化与 Prometheus/Grafana 监控接入的部署环境
  • 需要开启集群模式（emulated/yes）的分片场景
