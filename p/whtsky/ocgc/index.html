综述（解读层）

ocgc 是一个 Python 编写的命令行工具，用于分析 OpenCode 的 SQLite 会话数据库（默认 ~/.local/share/opencode/opencode.db）及磁盘上的 diff、快照等文件，统计空间占用并按条件清除。面向使用 OpenCode 且数据库无限增长的用户。提供 status/analyze 只读查看，purge 支持 --dry-run 预览、多条件 AND 组合、删除 reasoning parts、清理孤立文件与快照，删除前有确认提示，并会在 OpenCode 运行时给出警告。

  • 提供 status、sessions、analyze 只读命令，展示数据库大小、会话明细及三类文件系统目录（session_diff、snapshot、tool-output）的占用
  • purge 支持多条件 AND 组合、--older-than 时间过滤、--strip-reasoning 移除 reasoning parts、--clean-orphans/--clean-snapshots，并可 --dry-run 预览
  • 删除前请求确认，检测 OpenCode 是否正在运行，支持通过 OCGC_DB_PATH 指定自定义数据库路径

适用场景（解读层）

  • OpenCode 会话 SQLite 数据库持续增长、需要查看各部分空间占用分布
  • 定期按时间等条件清除旧会话、孤立 diff 文件或项目 git 快照以回收磁盘空间
  • 通过 --dry-run 与确认机制在删除前审查将要执行的操作
