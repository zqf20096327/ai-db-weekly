基于 Go 的 Clean Architecture 示例模板，采用 CQRS 与分层目录结构

综述（解读层）

这是一个用 Go 编写的 Clean Architecture 项目模板，面向学习或启动后端方案的开发者。模板集成 wire、fiber、viper、zap、swagger 等组件，采用 CQRS 与 Repository 设计模式，按 api、domain、infrastructure 等目录分层组织代码，示例用例为 crag 的增删改查，数据存于内存。gRPC、GraphQL、MySQL、PostgreSQL 等项在清单中标记为未完成。

  • 采用 CQRS 与 Repository 设计模式，代码按 api、domain、infrastructure 等目录分层组织
  • 提供 Swagger UI、健康检查、分页、内存缓存与 Redis 缓存功能，包含单元测试
  • 通过 make local/setup/test/build/swag 等命令完成本地运行、依赖安装、测试与构建

适用场景（解读层）

  • 学习 Clean Architecture 在 Go 项目中的目录分层与依赖注入组织方式
  • 作为 Go 后端服务的起始模板，在其基础上扩展 REST API 与缓存功能
  • 参考其 Makefile 工作流（运行、测试、构建、生成 API 文档）搭建开发流程
