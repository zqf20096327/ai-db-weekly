pg_activity：类 top 命令行工具，用于监控 PostgreSQL 服务器活动。

综述（解读层）

pg_activity 是由 dalibo 维护的命令行工具，以类 top 界面展示 PostgreSQL 服务器的运行查询、等待查询、阻塞查询、锁与 TPS 等信息。支持本地或远程连接，可本地读取系统信息；数据库用户需为超级用户，否则进入降级模式。可通过 INI 配置文件与 profile 定制界面，运行时按键排序、筛选乃至终止或取消后端进程。

  • 以可调刷新率（0.5–5 秒）扫描 pg_stat_activity、pg_locks 等视图，展示运行/等待/阻塞查询及 TPS
  • 支持通过交互按键终止（K）或取消（C）后端进程，并将运行查询导出为 CSV
  • 支持 --rds 选项适配 AWS RDS，凭 libpq 认证（密码文件、环境变量或连接串）

适用场景（解读层）

  • 在终端中查看 PostgreSQL 实例的运行、等待与阻塞查询及系统资源占用
  • DBA 在具有足够权限时排查长时间运行的查询并按需终止或取消后端
  • 在 AWS RDS 实例上以 --rds 模式进行活动监控
