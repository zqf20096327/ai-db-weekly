Gleam 代码生成器，将 .sql 文件转为类型安全的 SQLite 函数

综述（解读层）

Marmot 是一个 Gleam 代码生成器，读取 src 下 sql 目录中的 .sql 文件，通过连接 SQLite 数据库读取 schema 元数据并执行 EXPLAIN 推断查询类型，生成包含函数、行类型和解码器的 Gleam 模块，底层使用 sqlight。还提供仅前向的迁移运行器和种子数据命令。适合使用 Gleam 且偏好手写 SQL 的开发者。README 明确指出当前 BEAM 的 SQLite 驱动 esqlite 存在线程切换、锁等待等性能与部署限制。

  • 读取 .sql 文件生成 Gleam 函数、行类型与解码器，生成函数使用带标签参数
  • 基于 SQLite schema 元数据和 EXPLAIN 推断查询类型，默认缓存语句
  • 提供仅前向迁移运行器（NNN_description.sql 命名、事务执行、可重复运行）与多数据库配置支持

适用场景（解读层）

  • 在 Gleam 项目中以独立 .sql 文件方式访问 SQLite 数据库
  • 需要为 SQLite 查询自动生成解码器并保持与查询输出同步
  • 使用约定式迁移与种子数据管理单个或多个 SQLite 数据库
