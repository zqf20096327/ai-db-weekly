Go 编写的可嵌入列式数据库，存储用 Parquet，查询用 Arrow

综述（解读层）

FrostDB 是一个用 Go 编写的可嵌入宽列列式数据库，存储采用 Apache Parquet，查询时使用 Apache Arrow，提供查询构建器和优化器。它面向写入为主、偶发分析查询的场景，为 Parca 的可观测性用例而构建。数据不可变，只支持写入和读取，不支持更新与删除，README 标明项目尚未达到生产可用状态，API 可能变化。

  • 支持半结构化模式，可定义动态列，遇到新标签名时即时创建列
  • 采用类 LSM 索引管理不可变数据，利用 Parquet 的 bloom filter 和 min/max 稀疏索引跳过无关 row group
  • 提供快照隔离，写事务按批次经 watermark 机制释放

适用场景（解读层）

  • Go 程序中嵌入列式存储，避免运行独立数据库服务器
  • 高基数维度数据的写入与聚合分析，如 Prometheus 风格的时间序列
  • 无需更新或删除的不可变数据集存储
