Stellar 网络实时分析与监控仪表盘，含 DEX 与 Soroban 指标

综述（解读层）

Lumina Analytics 是面向 Stellar 网络的实时分析与监控仪表盘，用于查看交易、账户、资产、DEX 活动和 Soroban 合约指标。前后端分离架构，提供 REST API 与 WebSocket 实时推送，支持 Docker Compose 或手动安装（需 Node.js 18+、PostgreSQL 14+、Redis 7+）。环境变量需配置数据库、Redis 及网络（testnet 等）。MIT 许可。

  • 提供实时仪表盘、交易浏览器、资产分析、DEX 监控与 Soroban 合约指标模块
  • 提供 REST API 端点与 WebSocket 事件流（如 ws://localhost:4001/stream/transactions）
  • 支持自定义仪表盘组件与事件阈值告警，数据可导出为 CSV/JSON

适用场景（解读层）

  • 监测 Stellar 网络交易量、活跃账户与网络健康指标
  • 追踪特定资产的发行、持有人分布与交易量
  • 监控 DEX 订单簿深度、流动性池及 Soroban 合约调用与 gas 消耗
