宠物店业务的学术数据建模项目，含概念到 SQL 实现的完整交付物。

综述（解读层）

这是数据建模课程小组（Grupo 05）围绕虚构宠物店 Pata Feliz 完成的学术项目，覆盖客户与宠物服务预约、商品订单、供应商采购与库存、应收应付与现金流等数据域。交付物分两部分：第一部分为初步 DER 与建模日志，第二部分为最终文档、逻辑模型、建表脚本、示例数据与管理/审计 SQL 查询。项目面向教学场景，README 未提供部署说明。

  • 交付物包含需求（RF/RNF）、业务规则、DER、数据字典、逻辑模型、规范化说明、流程图与 SQL 附录
  • 实现层提供建表脚本、演示用模拟数据以及管理类与审计类 SQL 查询
  • 模型通过 ITEM_PEDIDO、TUTELA 等关联表承载属性或化解多对多关系

适用场景（解读层）

  • 数据建模课程作业参考与教学演示
  • 学习宠物零售场景下库存、财务与服务的表结构设计
  • 阅读从概念模型到 SQL 实现的完整建模流程记录
