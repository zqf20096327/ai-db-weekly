综述（解读层）

Erdus 是一个运行在浏览器端的 ER 图/数据库模式转换工具，支持 ERDPlus、PostgreSQL DDL、Prisma、TypeORM 之间的互转，并可导出 DBML 和 Mermaid ER。所有转换经过统一的中间表示（IR），文件在本地处理不上传服务器。面向学生、教师及使用 TypeScript 生态的开发者，提供 Web 界面、CLI 和编程接口三种使用方式。

  • 通过统一中间表示（IR）实现 ERDPlus、PostgreSQL DDL、Prisma、TypeORM 双向转换，并可导出 DBML 和 Mermaid ER 格式
  • 完全在浏览器端处理文件，无需后端，支持离线使用（npm run build 后 npm run preview）
  • 以多种方式使用：Vercel 托管的 Web 界面、CLI 命令，或通过 npm 包以编程方式调用 erdplusToIR、irToSQL 等函数

适用场景（解读层）

  • 在 ERDPlus 新旧版本文件之间迁移（往返转换保留结构、键、顺序和位置）
  • 在 PostgreSQL DDL、Prisma schema、TypeORM 实体之间进行 Schema 格式转换
  • 从现有数据库模式生成 DBML（用于 dbdiagram.io）或 Mermaid ER 图用于文档编写
