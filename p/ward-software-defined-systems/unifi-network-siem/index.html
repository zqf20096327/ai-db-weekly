🧭 简介解读层（AI·证据行可回查）

自包含 Node.js SIEM 应用，收集解析 UniFi syslog 并提供实时安全仪表盘

综述（解读层）

该项目是一个单进程 Node.js 应用，通过 UDP 监听器接收 UniFi 控制台和网关的 syslog（5514 端口），用 11 种解析器处理防火墙、威胁、DHCP、DNS 等事件，存入 SQLite（默认）或 OpenSearch/WardSONDB，并经 Web 界面提供实时事件流、地图、威胁情报表。适用于运行 UniFi 网络并希望集中查看其安全日志的用户；使用前需在 UniFi 控制台配置多个日志源，其中防火墙规则需逐条开启 syslog 才会产生外部 IP 相关事件。

  • 内置 UDP syslog 收集器和 11 种事件类型解析器，自动识别 CEF、iptables、CoreDNS JSON、hostapd、dnsmasq 等格式
  • 支持三种可插拔存储后端：SQLite（WAL 模式、物化汇总表、保留清理）、WardSONDB 和 OpenSearch（均标注为 Beta）
  • 提供 WebSocket 实时事件流、Leaflet 地理地图、威胁情报表和基于大语言模型的 Threat Hunt 调查功能（Beta），支持接入 Anthropic/OpenAI/Google API 密钥

适用场景（解读层）

  • 将 UniFi 控制台/网关的流量日志与活动日志集中到本地单一应用中查看与检索
  • 通过仪表盘、实时事件流和地图监控防火墙拦截、IDS 告警、DHCP、Wi-Fi 等事件
  • 对可疑外部 IP 执行限定时间窗口的本地事件查询并结合外部情报（rDNS、WHOIS/ASN）生成调查报告
