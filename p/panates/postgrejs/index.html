基于 TypeScript 从零实现线协议的 PostgreSQL 客户端，支持 Node.js 和 Bun。

综述（解读层）

PostgreJS 是面向 Node.js 与 Bun 的 PostgreSQL 驱动，纯 TypeScript 实现，不依赖 libpq 或原生绑定，直接与服务器通信。提供连接池、预处理语句、服务端游标、LISTEN/NOTIFY、COPY 流、逻辑复制、两阶段提交、多主机故障转移等功能，通过 npm install postgrejs 安装，以 ESM 模块发布并附带类型定义。

  • 支持完整二进制线协议、逐列格式选择、自动预处理语句与服务端游标
  • 内置连接池、事务 API、两阶段提交、多主机故障转移与 SCRAM channel binding
  • 通过 diagnostics_channel 发布事件，配套 postgrejs-otel 提供 OpenTelemetry spans 与数据库客户端指标

适用场景（解读层）

  • 在 Node.js 或 Bun 应用中直接连接和查询 PostgreSQL 数据库
  • 作为 Kysely、Drizzle ORM、TypeORM、Prisma 等查询构建器/ORM 的底层驱动适配
  • 需要逻辑复制、大对象操作、二进制 COPY 或可观测性集成的数据管道与运维场景
