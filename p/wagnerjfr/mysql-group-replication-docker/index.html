🧭 简介解读层（AI·证据行可回查）

用 Docker MySQL 镜像搭建 MySQL 组复制环境的脚本与文档集合

综述（解读层）

该项目提供基于 Docker MySQL 官方镜像搭建 MySQL Group Replication 的步骤与脚本，包含拉取镜像、创建网络、启动 node1–node3 三个节点及清理资源的命令。面向需要本地部署组复制环境的开发或测试人员。默认为多主模式，可通过修改容器启动参数切换为单主模式，需预先设置 MYSQL_VERSION 环境变量。

  • 提供启动三个容器节点（node1、node2、node3）并组建 Docker 网络 groupnet 的完整命令
  • 支持通过修改 GR 启动参数在单主模式与多主模式间切换
  • 提供清理容器、数据目录与网络的对应命令

适用场景（解读层）

  • 在本地 Docker 环境中搭建 MySQL 组复制测试环境
  • 验证单主或多主模式下的复制配置参数
  • 按文章所述进行容错场景测试
