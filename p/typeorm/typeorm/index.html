🧭 简介解读层（AI·证据行可回查）

Node.js 与多平台的 TypeScript/JavaScript ORM，支持 Active Record 与 Data Mapper 两种模式

综述（解读层）

TypeORM 是运行于 Node.js、浏览器、React Native、Electron 等平台的 ORM，供使用 TypeScript 或 JavaScript 的开发者操作关系型数据库及 MongoDB。它通过装饰器定义实体，支持实体管理器、Repository、QueryBuilder、事务、迁移、连接池、复制与监听钩子等机制，并提供 CLI 与大量示例项目。

  • 支持 MySQL/MariaDB、Postgres、CockroachDB、SQLite、SQL Server、Oracle、SAP HANA、sql.js 及 MongoDB
  • 同时实现 Active Record 与 Data Mapper 两种模式，使用装饰器声明实体与列
  • 提供迁移生成、事务、连接池、多数据库实例、跨库跨 schema 查询、查询缓存、监听器与订阅者，附带 CLI

适用场景（解读层）

  • 在 Node.js 后端（如 Express、Koa）中以 TypeScript 或 JavaScript 访问关系型数据库
  • 在 React Native、Ionic、Cordova、Electron 等跨端应用中内置本地数据库操作
  • 需要迁移管理、多数据库实例或跨 schema 查询的多数据库应用开发
