单二进制 C++ 流式 SQL 引擎，基于 ClickHouse 实现实时流处理与分析

综述（解读层）

Timeplus Proton 是一个流式 SQL 引擎，以单个 C++ 二进制（<500MB）运行，无 JVM 依赖，基于 ClickHouse 引擎构建。它提供流式摄取、多流 JOIN、滚动/跳跃/会话窗口、增量物化视图、CDC 等能力，并内置可查询的存储。数据源方面支持 Kafka、Pulsar、ClickHouse 外部流等；需注意开源版为单节点部署，部分连接器（如 WebSocket、NATS、CSV 上传）仅在企业版提供。可通过 curl 脚本、Homebrew 或 Docker 安装，用 proton server/client 即可运行 SQL 查询。

  • 单二进制运行，无 JVM/ZooKeeper 依赖，可在 1 vCPU/0.5 GiB 环境运行
  • 支持流式 ETL、tumble/hop/session 窗口、watermark、增量物化视图、CDC 与 Python/JS UDF
  • 提供 Kafka/Pulsar 外部流与 ClickHouse 外部表，同一 SQL 可查询 live 与 historical 数据

适用场景（解读层）

  • 从 Kafka 摄取数据并在管道内做过滤、富化、脱敏后写入 ClickHouse 等下游
  • 日志、指标、链路遥测数据的实时处理、降噪与告警路由
  • 基于流式 SQL 与物化视图计算 AI/ML 实时特征，支持回填与窗口计算
