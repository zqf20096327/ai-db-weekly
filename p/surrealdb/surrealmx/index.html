Rust 编写的嵌入式内存键值引擎，基于 MVCC 与无锁并发自适应基数树

综述（解读层）

SurrealMX 是一个嵌入式、内存中的键值存储引擎，采用 MVCC、并发自适应基数树和环形提交缓冲实现无锁并发访问，支持事务、保存点与快照隔离。默认仅存于内存，可通过可选的追加日志（AOL）、快照、fsync 与 LZ4 压缩配置持久化级别。适用于 Rust 应用嵌入使用，包括高并发服务和 WebAssembly 环境。

  • 基于 MVCC 的无锁读写，支持事务、回滚与堆叠保存点
  • 可选持久化：追加日志、周期性快照、可配置 fsync 模式与 LZ4 压缩
  • 后台清理与垃圾回收线程可禁用并可手动触发

适用场景（解读层）

  • 微秒级延迟要求的高并发服务端应用
  • 缓存层与可由其他来源重建的临时数据存储
  • 浏览器 WebAssembly 环境中的嵌入式数据存储
