基于 Node.js 的 oneM2M 标准 IN-CSE 物联网服务器平台

综述（解读层）

Mobius 实现 oneM2M 标准 IN-CSE，面向需要注册、数据管理、订阅/通知与访问控制等公共服务功能的物联网应用，也可经互通机制接入非 oneM2M 设备。3.0 版重写核心：以 REST API 提供服务，经 knex 查询构建器支持 MySQL 与 SQLite 双数据库后端（SQLite 仅支持六种资源类型），仅接受 JSON 请求体，移除 MQTT/CoAP/WebSocket 请求绑定。

  • 提供 oneM2M IN-CSE 公共服务功能：注册、数据管理、订阅/通知、访问控制，通过 REST API 访问
  • 支持 MySQL 与 SQLite 两种数据库后端，经统一数据库门面适配；SQL 语句由 knex 构建并使用绑定值执行
  • 以 Node.js 集群运行：master 进程执行保留清理与计数器对账，worker 进程处理请求并支持自动重启

适用场景（解读层）

  • 需要符合 oneM2M 标准（TTA 认证）的物联网云服务器（IN-CSE）部署
  • 嵌入式网关或小规模部署场景，可用 SQLite 后端（支持 CSEBase、AE、container、contentInstance 等六种资源类型）
  • 通过 KETI TAS 与 &Cube 接入非 oneM2M 设备并与 oneM2M 应用互通
