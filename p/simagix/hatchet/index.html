基于嵌入式 SQLite3 的 MongoDB JSON 日志分析器与查看器

综述（解读层）

Hatchet 是用 Go 编写的 MongoDB JSON 日志分析和查看工具，读取本地文件、Web 服务器、MongoDB Atlas 或 AWS S3 上的日志，处理后存入嵌入式 SQLite3 数据库，并提供 Web 界面和 RESTful API。构建依赖 gcc（CGO），默认监听 3721 端口，支持 Docker、内存模式（不持久化）和日志脱敏输出，采用 Apache-2.0 许可证。

  • 读取本地、http/https、MongoDB Atlas API 和 AWS S3 来源的日志文件，支持 .gz 压缩格式
  • 提供 Web 界面和 REST API，包含审计报告、慢查询统计和性能图表，报告可下载为独立 HTML 文件
  • 支持日志脱敏，自动替换 attr 字段中匹配到的 IP 地址、邮箱、电话等敏感值，并保持替换一致性

适用场景（解读层）

  • 解析 mongod 日志，查看审计报告、慢查询统计和操作图表
  • 从 MongoDB Atlas 或 S3 直接下载并分析集群日志
  • 在分享或存储前对包含敏感信息的日志进行脱敏处理
