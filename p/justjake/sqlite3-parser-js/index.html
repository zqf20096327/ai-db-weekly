纯 JavaScript 实现的 SQLite LALR(1) SQL 解析器，提供改进的错误信息

综述（解读层）

该项目将 SQLite 的 parse.y 文法经补丁版 Lemon 生成器转为 TypeScript 解析器代码，用于在 Node、Bun 和浏览器中解析 SQLite 查询语法。提供 parse/parseStmt 等 API 与结构化诊断对象、AST 遍历接口及命令行 AST 查看工具，适合需要在 JS 环境中解析 SQLite SQL 并获取语法诊断的开发者。

  • 纯 JavaScript 实现，gzip 约 32 KB，可在 Node、Bun 和浏览器中运行
  • 解析失败时返回结构化诊断，包含源码位置、可接受的词法单元列表及语法提示
  • 提供 ESTree 风格的 traverse 遍历接口与命令行 AST 查看工具，支持 JSON 和 S 表达式输出

适用场景（解读层）

  • 在 JavaScript/TypeScript 项目中解析 SQLite 查询语句并生成 AST
  • 构建 SQL 编辑工具或语法检查功能，利用结构化诊断展示错误位置
  • 通过命令行工具查看查询的 AST，或与 sqllogictest-parser 组合批量解析测试文件
