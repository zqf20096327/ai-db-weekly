面向 Claude Code 与 Codex 的本地上下文管理器，基于 SQLite 存储。

综述（解读层）

ctx 是一个运行在本地的上下文管理工具，为 Claude Code 与 Codex 会话提供工作流（workstream）保存、恢复、分支与搜索功能。它将内部会话绑定到具体的 Claude/Codex 对话，避免后续拉取时漂移到最新聊天；数据存储在本地 SQLite 数据库和文件中，不需要 API 密钥，不使用托管服务。用户可通过斜杠命令（Claude）或 ctx 子命令（Codex）操作，并提供终端与浏览器两种管理界面。

  • 支持将内部会话精确绑定到来源 Claude/Codex 对话，后续拉取不会跳转到最新聊天
  • 提供工作流的创建（--pull 回填）、恢复、分支与压缩加载（--compress）等命令
  • 内置终端 curation UI 和本地浏览器界面，可对保存条目执行固定（pin）、排除、恢复或删除

适用场景（解读层）

  • 在同一仓库中长期维护多个独立工作流，分开保存和恢复不同任务的上下文
  • 从现有工作流状态分支出新工作流，用于并行尝试不同方向且不共享后续拉取
  • 通过 ctx search 检索已保存的上下文条目，并通过 curation 控制哪些内容进入未来的加载包
