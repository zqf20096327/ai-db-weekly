🧭 简介解读层（AI·证据行可回查）

基于 JSON 文件的 Python 轻量级数据库，提供路径式 CRUD 与备份加密。

综述（解读层）

LiteJsonDb 是一个以 JSON 文件为存储介质的 Python 数据库库，通过 pip 安装后以 JsonDB 类暴露 set_data、get_data 等路径式 CRUD API。它面向小型应用、原型、脚本和本地工具，支持嵌套子集合、批量写入、CSV 导出、Telegram 备份，可选 Base64 或 Fernet 加密；README 明确说明其不适用于高并发、大规模或分布式场景。

  • 提供路径式 CRUD API（set_data/get_data/edit_data/remove_data）及层级子集合结构
  • 支持原子写入、外部文件修改检测、自动备份，以及 Base64/Fernet 可选加密
  • 提供批量写入模式、跨值搜索、CSV 导出与 Telegram 备份功能

适用场景（解读层）

  • 小型应用与原型的本地持久化层
  • 本地工具、脚本与配置/元数据存储
  • 嵌入式或离线优先系统中的小规模文档式数据存储
