🧭 简介解读层（AI·证据行可回查）

以单一 Go 二进制运行的 LLM 辅助 PostgreSQL DBA 代理，无需安装扩展

综述（解读层）

pg_sage 是一个以单二进制形式部署在 PostgreSQL 旁的代理式 DBA 工具，通过标准线协议读取 catalog 视图与 pg_stat_statements，将问题投影为 Cases，并用 LLM 做深入分析。面向需要监控、诊断和优化 PostgreSQL 14-18 数据库的 DBA 与运维团队。其执行器按信任分级推进，高危操作需人工批准；支持 Lakebase、Cloud SQL、AlloyDB、Aurora、RDS、Neon、Supabase 及自建 Postgres。LLM 功能需配置端点与认证后才启用，此前仅运行确定性规则。

  • 提供 20+ 条确定性规则检查（索引、慢查询、vacuum/bloat、序列耗尽、复制延迟等），并支持 LLM 配置建议与经 8 项检查和 HypoPG 成本估算的索引建议
  • 内置 React SPA 仪表盘、REST API、Prometheus /metrics 端点，以及 Slack/PagerDuty/webhook 告警路由
  • 支持单二进制监控多数据库的 Fleet 模式，动作携带风险分级、护栏、回滚元数据，HIGH 风险操作必须审批

适用场景（解读层）

  • 托管或自建 PostgreSQL 实例的性能监控与事件调查（锁、连接耗尽、WAL、计划回退）
  • 自动/半自动的 vacuum、bloat、freeze 与索引优化流程，含验证计划与人工清理标记
  • 迁移风险预检与 DDL 安全审查，输出 PR/CI 可用的迁移 SQL、回滚与验证信息
