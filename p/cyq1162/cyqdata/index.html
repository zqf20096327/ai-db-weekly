CYQ.Data 是支持多数据源的 .NET ORM 与数据层组件库

综述（解读层）

CYQ.Data 是一个面向 .NET 与 .NET Core 的 ORM 及数据层组件库，提供 MAction 类以表名加 where 条件的方式执行增删改查，并包含日志、JSON 操作、分布式缓存等工具功能。其 where 条件可基于主键自动推导，内置防 SQL 注入处理。适合需要在同一数据层中访问多种关系型与非关系型数据源的 .NET 开发者。

  • 支持 Mssql、Mysql、Oracle、Postgres、Sqlite、达梦、人大金仓等多种数据库，以及 Txt、Xml、Excel、Redis、MemCache 等数据源
  • 除 ORM 外包含日志记录、JSON 操作、分布式缓存访问等工具功能
  • 提供 MAction 表名驱动的数据操作方式，where 条件支持主键自动推导并内置防注入处理

适用场景（解读层）

  • 需要统一数据层访问多种数据库或文本、缓存等数据源的 .NET 项目
  • 通过表名参数化构建通用 API 接口的场景
  • 希望以表名加 where 条件直接进行增删改查而不维护实体类的开发流程
