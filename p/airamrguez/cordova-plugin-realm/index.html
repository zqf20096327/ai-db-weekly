非官方 Cordova 插件，为 iOS、Android 和浏览器提供 Realm 移动数据库接口

综述（解读层）

该插件通过 JavaScript 接口在 Cordova 应用中访问 Realm 移动数据库，覆盖 iOS、Android 和浏览器平台。使用前需在项目根目录创建 realmrc.json 定义 schema，插件据此生成原生类，schema 变更后须重新构建。README 明确声明这是开发中的非官方项目，API 可能变化，不建议在生产环境使用。

  • 支持 iOS、Android 和浏览器三个平台，浏览器平台需配合 cdv-realm 服务端运行
  • 提供查询构建器 API，包含 between、equalTo、contains 等条件方法，支持 or/not 逻辑组合与 beginGroup/endGroup 分组
  • 通过 realmrc.json 文件定义 schema 并生成原生类，提供 create、delete、findAllSorted 等实例方法

适用场景（解读层）

  • Cordova 混合应用中需要在 iOS 和 Android 上本地存储结构化数据的场景
  • 需要使用构建器模式编写带排序、分组逻辑的复杂条件查询的场景
  • 希望用同一套 Realm 数据访问接口在浏览器端调试 Cordova 应用的场景
