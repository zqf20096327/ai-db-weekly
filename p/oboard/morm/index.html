MoonBit 语言的轻量级 ORM 工具包，通过代码生成替代运行时反射

综述（解读层）

morm 是面向 MoonBit 的 ORM 工具包，将实体、查询构建与数据库执行分层：实体注解描述表结构，mormgen 在 pre-build 阶段生成 .g.mbt 代码，查询构建器表达 SQL 意图，引擎负责渲染与执行。它不使用运行时反射，支持 select/insert/upsert/update/delete、分页、自动时间戳与多引擎，DuckDB 需另行安装 libduckdb 原生库。

  • 通过 #morm.entity 注解生成实体到表的元数据，并由 mormgen 在 pre-build 阶段生成 MoonBit 代码
  • 提供 select、insert、upsert、update、delete 的类型化查询构建器及 1 起始页码的分页辅助（paginate / paginate_raw）
  • 通过共享 Engine 契约支持多引擎，内嵌 DuckDB 绑定，并支持 PlainDate、PlainDateTime 等本地时间类型与 MoonBit 枚举直接作为实体字段

适用场景（解读层）

  • 在 MoonBit 项目中以注解和代码生成方式定义实体并访问关系型数据库
  • 需要分页查询（含原生 SQL 分页）与 created_at/updated_at 自动时间戳的应用
  • 使用 DuckDB 进行嵌入式分析场景，或需要 PostgreSQL schema 归属与授权管理的项目
