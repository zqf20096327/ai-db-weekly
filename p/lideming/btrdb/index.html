受 btrfs 启发的 B-tree 写时复制嵌入式 NoSQL 数据库引擎

综述（解读层）

btrdb 是用 TypeScript 编写的持久化嵌入式 NoSQL 数据库引擎，采用受 btrfs 启发的 B-tree 写时复制架构。它支持在 Deno 和 Node.js 上运行，可在同一数据库中混合使用键值集与文档集，提供命名快照、事务及 SQL 风格的标签模板查询。README 明确提示项目处于快速开发中，磁盘格式和 API 可能变动，尚不建议用于关键生产环境。

  • 采用固定 4KB 页的 B-tree 写时复制结构，页面修改时写入新位置而非覆盖，保留旧 Root 地址即可获得该时点的完整快照
  • 支持唯一、复合和计算索引，查询支持 ==、!=、比较运算、AND/OR/NOT 及 SKIP/LIMIT
  • 附带 btrdbfs FUSE 文件系统实现，可将数据库挂载为文件夹，并内置基本 HTTP 服务器用于远程访问

适用场景（解读层）

  • 需要在 Deno 或 Node.js 应用中嵌入持久化键值或文档存储的场景
  • 需要创建即时快照并读取历史时间点数据的场景
  • 在 Linux/macOS 上希望以 FUSE 挂载方式像文件夹一样读写数据库文件的场景
