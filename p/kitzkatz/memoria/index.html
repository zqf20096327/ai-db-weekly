🧭 简介解读层（AI·证据行可回查）

本地优先、与 LLM 无关的记忆基础设施，并行混合检索与多信号排序

综述（解读层）

Memoria 是一套本地运行的存储与检索系统，可独立于 LLM 使用。它并行运行 FAISS 向量、BM25 词汇、图、短语、属性和时间检索，经多信号融合与重排输出结果，通过 CLI、TUI、GUI、HTTP API 和 MCP 服务器访问。README 称在约 3.7 GiB 内存、无 GPU 的 Celeron N4020 上实测峰值 RSS 2.65 GiB，平均单查询约 580 MiB；文档另有基准页提供复现方法。

  • 并行混合检索：FAISS 向量、BM25 词汇、图、短语、属性检索，时间检索作为独立可评估路径在最终融合阶段合并
  • 提供 CLI、TUI、GUI、HTTP API 与 MCP 服务器（memory_search/store/fetch/update/delete 等操作）及面向 Obsidian vault 的摄取适配器
  • 配置驱动的插件系统，可注册检索 worker、排序信号、重排器、存储后端等，支持自动发现与运行时启停

适用场景（解读层）

  • 为 LLM 智能体提供本地外部记忆（通过 MCP 服务器）
  • 将 Obsidian vault 的 markdown 笔记、frontmatter 与 wikilinks 摄取并检索
  • 在无云端、无 API 密钥的低资源 CPU 环境中做记忆检索与基准评测
