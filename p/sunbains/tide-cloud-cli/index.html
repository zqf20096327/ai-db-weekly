🧭 简介解读层（AI·证据行可回查）

基于 SQLite 虚拟表将 SQL 操作实时转换为 TiDB Cloud API 调用的命令行工具

综述（解读层）

该工具通过 rusqlite 的虚拟表机制，将 SELECT、INSERT、UPDATE、DELETE 语句翻译为对应的 TiDB Cloud API 调用，提供交互式 SQL Shell，也支持通过 Unix 管道执行脚本化 SQL。面向需要以 SQL 方式管理 TiDB Cloud 集群、备份和端点的用户，需提供用户名、密码/API Key 及 base-url 进行认证。

  • 提供 tidb_clusters、tidb_backups 虚拟表和 tidb_endpoints 视图，支持完整 SQL 查询（WHERE、JOIN、GROUP BY、ORDER BY）
  • INSERT/UPDATE/DELETE 操作实时触发创建、修改、删除资源的 API 调用，虚拟表按需从 API 获取最新数据
  • 交互式 SQL Shell 支持命令历史与自动补全，通过分析 WHERE 子句约束在 API 层进行查询过滤

适用场景（解读层）

  • 通过交互式 SQL Shell 查询和管理 TiDB Cloud 集群、备份与端点信息
  • 以 INSERT/UPDATE/DELETE 语句方式创建、修改、删除集群和备份资源
  • 通过管道将 SQL 脚本以非交互方式执行，用于自动化运维流程
