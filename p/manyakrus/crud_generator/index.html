从 PostgreSQL 数据库表自动生成带 CRUD、模型与 GRPC/NRPC 接口的 Golang 微服务代码

综述（解读层）

该工具读取 PostgreSQL 数据库中已建好的表结构，为每张表自动生成 Golang 源码文件，包含 table/entities 结构体、CRUD 操作函数、GRPC 与 NRPC 的服务端和客户端文件及测试、Makefile 和 .env 配置文件，生成可直接运行的微服务。数据库表需事先手工创建，代码模板存放于 bin/templates 目录，可自行替换修改。

  • 为每张表生成 Create/Read/Update/Delete/Save/ReadFromCache 及按列更新、批量更新等函数
  • 生成 GRPC 与 NRPC（经 NATS）的服务端、客户端文件及对应测试
  • 代码模板为 .go 文件，可通过复制自有文件替换；名称含 DELETED 前缀的表和列会被忽略

适用场景（解读层）

  • 基于现有 PostgreSQL 表结构快速生成微服务骨架源码
  • 需要为多张表批量产出 CRUD 与 GRPC/NRPC 接口代码的场景
  • 希望以自定义 .go 模板控制生成代码风格的团队
