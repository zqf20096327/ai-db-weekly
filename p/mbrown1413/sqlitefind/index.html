从内存转储中发现并恢复 SQLite 数据库行的 Volatility 取证插件

综述（解读层）

SqliteFind 是一个 Volatility 插件，用于在内存转储中定位 SQLite 数据库行。它通过搜索 sqlite_master 表自动发现数据库 schema，再依据列类型签名匹配并解析行数据。面向计算机取证分析人员，安装需将插件文件放入 Volatility 插件路径并依赖 yara-python。手册明确列出限制：搜索速度受 needle 大小影响、跨页的大记录可能丢失或损坏、少列情形下可能出现误报。

  • 自动搜索内存中的 sqlite_master 表并列出其中的数据库 schema（可输出原始 SQL）
  • 支持通过表名或手动 schema 字符串（int/string/blob/timestamp 等类型及 int8–int64 位宽）指定行结构
  • 输出可包含行内存地址、各列值与序列类型，并支持 CSV 导出

适用场景（解读层）

  • 对内存镜像做计算机取证，恢复 SQLite 数据库的表结构与行内容
  • 使用 Volatility 框架的分析人员排查浏览器或其他应用在内存中残留的 SQLite 记录
  • 在无数据库文件头信息的情况下按 schema 模式扫描内存页中的记录
📖 README 首段存档原文 · 程序抽取

SqliteFind is a Volatility plugin for finding sqlite database rows. It can automatically find database schemas in sqlite_master tables, and recover database rows from memory.
