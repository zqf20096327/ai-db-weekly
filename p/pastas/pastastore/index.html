将 Pastas 时间序列与模型存入数据库的 Python 管理工具

综述（解读层）

pastastore 用于将 Pastas 时间序列和模型存储到数据库中，通过 Connector 对象提供存取方法，PasConnector 以 JSON 风格的 .pas 文件保存在本地文件夹。用户将 Connector 传入 PastaStore 对象后，可调用其方法添加、分析、可视化时间序列及构建模型，支持 pip 安装，地图绘制需 contextily、pyproj 等，Windows 用户需自行安装 rasterio。

  • 通过 Connector 对象提供时间序列和模型的存储与读取方法
  • PasConnector 以 JSON 风格 .pas 文件将模型保存在本地文件夹
  • PastaStore 对象包含分析、可视化时间序列以及构建、分析模型的方法

适用场景（解读层）

  • 在磁盘上管理 Pastas 时间序列和模型，避免重复加载数据
  • 水文/地下水位等时间序列数据的存储与分析
  • 通过 Notebook 中的示例进行时间序列模型的分析与可视化工作流程
