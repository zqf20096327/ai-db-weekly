大学电子书店案例的数据库设计文档库，含 ERD、业务规则、范式化与 SQL 实现

综述（解读层）

该仓库是一个面向大学电子书店场景的数据库设计案例，使用 Microsoft SQL Server 18 编写 SQL。内容覆盖从需求场景到 ERD、业务规则、UNF 至 3NF 的范式化过程、数据字典及数据库模式图。适合作为数据库设计课程的案例参考，完整展示从表单到规范化模式的设计流程。

  • 提供从 UNF 到 1NF、2NF、3NF 的逐步范式化过程文档
  • 包含 ERD 设计、业务规则列表与数据字典截图
  • 数据库使用 SQL 在 Microsoft SQL Server 18 上构建，并生成数据库模式

适用场景（解读层）

  • 数据库课程中的规范化（1NF/2NF/3NF）教学案例参考
  • 学习从业务场景推导 ERD 与业务规则的示例
  • 参考数据字典与数据库模式文档的编写结构
