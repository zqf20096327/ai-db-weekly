libcouchbase 的 Ruby FFI 绑定，支持多事件循环的非阻塞 Couchbase 客户端

综述（解读层）

libcouchbase 是 Ruby 的 Couchbase 客户端 FFI 封装，gem 内含 libcouchbase C 库，安装时需 cmake 编译。支持 Native Ruby、EventMachine、Libuv 三种运行时，通过 Fiber 实现非阻塞操作，客户端线程安全且可重入，可在集群节点增删时自动调整配置。提供 get/set/add/replace、原子 incr/decr、子文档操作、Views、N1QL 与全文检索查询。自 1.2 起所有写入保存为合法 JSON，不再支持原始字符串及 append/prepend。

  • 支持 Native Ruby、EventMachine、Libuv 三种运行时，通过 Fiber 在事件循环中实现非阻塞操作，各运行时语法一致
  • 提供同步与异步两种操作模式，异步模式下多个操作可并行执行后统一等待结果
  • 支持子文档读写（块式与链式）、View map/reduce、N1QL 查询及全文检索，全文检索结果通过枚举器懒加载

适用场景（解读层）

  • 在 Rails、Puma、Thin、SpiderGazelle 等 Ruby 框架/服务器中接入 Couchbase 数据库
  • 需要对 Couchbase 集群执行文档增删改查、原子计数器或子文档级精细操作的场景
  • 在 EventMachine 或 Libuv 事件循环环境中需要非阻塞数据库访问的应用
