Go 编写的嵌入式图数据库，基于 bbolt 存储并支持 Cypher 查询

综述（解读层）

goraphdb 是一个用 Go 编写的嵌入式图数据库，通过 go get 引入后作为库嵌入 Go 程序，底层使用 bbolt（B+树键值存储）。它实现有向带标签图模型，支持 Cypher 查询子集的读写、流式查询构建器、二级与复合索引、BFS/DFS/最短路径等图算法，并提供含查询编辑器与 cytoscape.js 图可视化的管理界面，默认参数针对约 50 GB 数据集。查询语言为 Cypher 子集，完整能力以 README 所列为准。

  • 基于 bbolt 的嵌入式存储，编译为无外部依赖的单二进制，支持 MVCC 并发读取与可选哈希分片
  • 支持 Cypher 子集的读写（CREATE/MERGE/MATCH...SET/DELETE、OPTIONAL MATCH、参数化查询、EXPLAIN/PROFILE）及 Go 链式查询构建器
  • 内置 BFS、DFS、最短路径（无权与 Dijkstra）、连通分量、拓扑排序等图算法，以及二级/复合索引与唯一约束

适用场景（解读层）

  • Go 应用内嵌有向带标签图数据的存储与查询，无需独立部署数据库进程
  • 需要 Cypher 查询子集、图遍历算法（最短路径、连通分量等）的关系网络分析
  • 需要主从复制、健康检查与管理界面的图数据服务部署场景
