以 Docker 容器运行的 MySQL/MariaDB 备份、恢复与迁移工具，支持流式处理与多种存储后端

综述（解读层）

mysql-bkup 是一个以 Docker 镜像形式运行的 MySQL 和 MariaDB 数据库备份、恢复与迁移工具，支持一次性运行、cron 定时任务及 Kubernetes CronJob 三种方式。备份以流式管道完成导出、压缩、GPG/age 加密与上传，不落盘临时文件。它面向使用容器环境的开发与运维人员，可通过本地目录、S3、GCS、Azure Blob、SFTP、FTP 等多种存储保存备份，并基于索引文件管理保留策略。注意恢复操作不具备原子性，DDL 无法回滚。

  • 支持 MySQL 8.0/8.4/9.x 与 MariaDB，自动通过 SELECT VERSION() 检测服务端类型并选用对应的 mysqldump 或 mariadb-dump 工具
  • 备份流程以单一流式管道完成导出、gzip/zstd 压缩、GPG 或 age 加密与上传，不产生临时转储文件
  • 提供 backup/restore/migrate/verify/list/delete/prune/reconcile 等子命令，支持基于索引的按天数或数量保留策略

适用场景（解读层）

  • 在 Docker 或 Kubernetes 环境中以 CronJob 方式定期备份数据库到 S3 或本地目录
  • 通过 migrate 命令在不落盘的情况下直接迁移数据库到目标实例
  • 需要对备份文件进行 GPG/age 加密、sha256 校验及定期清理的存储管理场景
