🧭 简介解读层（AI·证据行可回查）

Shell 编写的 LNMP/LAMP 一键部署脚本，源码编译安装 Web 服务环境

综述（解读层）

该项目提供一组 Shell 脚本，用于在 RHEL/CentOS/Debian/Ubuntu/Fedora 的 64 位系统上以源码编译方式快速部署 LEMP/LAMP/LNMP/LNMPA/LTMP 环境，覆盖 Nginx/Tengine/OpenResty/Apache、多种数据库与 PHP 版本，并提供虚拟主机、备份、升级、卸载等管理脚本。README 说明项目已停止新增功能，仅做日常维护，并建议改用其 docker-compose 版本 bypanel。适合需要在物理机或云主机上自行搭建 PHP/Java 运行环境的运维人员。

  • 支持交互式与自动安装两种方式，通过 screen 会在安装中断后恢复会话
  • 提供 MySQL、MariaDB、Percona、PostgreSQL、MongoDB 多版本数据库及 PHP 5.3–8.5 多版本可选安装
  • 内置虚拟主机管理、Let's Encrypt 证书申请、本地/远程/OSS/S3 等多种备份目标及 upgrade.sh/uninstall.sh 维护脚本

适用场景（解读层）

  • 在 CentOS、Debian、Ubuntu 等 64 位 Linux 服务器上部署 LEMP/LAMP/LNMP/LNMPA/LTMP 生产环境
  • 需要多版本 PHP 共存或按需安装 PHP 扩展、缓存加速器（ZendOPcache、apcu 等）的场景
  • 需要通过脚本管理虚拟主机、FTP 用户、定时备份及组件升级卸载的服务器运维工作
