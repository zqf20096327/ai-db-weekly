用于安装配置和管理 Oracle WebLogic 的 Puppet 模块

综述（解读层）

这是一个 Puppet 模块，用于在 Linux 与 Solaris 系统上安装、配置和管理 WebLogic 10.3 至 12.2.1 版本，包括域创建、BSU/OPatch 补丁应用及 OSB、SOA Suite、OHS 等 Fusion Middleware 组件。其 types/providers 通过 WLST 读取当前状态并执行变更，12.2.1 起部分支持 REST 管理 API。需要 Puppet 4.3 以上使用 2.x 版本，Puppet 3/4 需使用 1.x 版本，并依赖 hajee/easy_type、puppetlabs/stdlib 等多个模块。

  • 支持 WebLogic 10g、11g、12c（含 12.2.1 多租户功能）的安装与域创建、打包、跨节点复制
  • 提供 wls_setting、wls_adminserver、wls_managedserver、wls_ohsserver 等 types/providers，基于 WLST 读取状态与执行变更
  • 支持 FMW 组件安装与配置，包括 OSB、SOA Suite、OHS、OIM/OAM、OUD、Forms/Reports、WebCenter 等

适用场景（解读层）

  • 在 RedHat、CentOS、Ubuntu、OracleLinux、Solaris 等 Linux/Unix 系统上以 Puppet 自动化部署 WebLogic 环境
  • 为 WebLogic 11g/12c 集群（含 SOA/BAM/OSB、OIM/OAM、WebCenter 等参考实现）做安装与补丁管理
  • 需要通过 Puppet 声明式管理 WebLogic 管理服务器、受管服务器和 OHS 服务器的运维场景
