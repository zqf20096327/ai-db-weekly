非官方 Python 库，用于抓取 finviz.com 的股票与筛选数据

综述（解读层）

finviz-api 是一个非官方的 Python 库，通过抓取 finviz.com 页面提供股票数据访问。它包含 get_stock（返回 90+ 指标）、新闻、内部人交易、分析师目标价等函数，以及支持多表导出（CSV/SQLite/pandas）的 Screener 筛选器和图表下载。数据有 15-20 分钟延迟，README 明确声明不可用于实时交易，且可能违反 FinViz 服务条款。适合做金融分析与研究的开发者使用。

  • 提供 get_stock、get_news、get_insider、get_analyst_price_targets 等单股数据函数，get_stock 返回 90+ 数据点
  • Screener 支持编程式过滤或从 FinViz URL 初始化，提供 Overview/Valuation/Financial/Ownership/Performance/Technical 六类表，可导出 CSV、SQLite 和 pandas DataFrame
  • 支持异步请求方式，图表下载可配置周期、类型、尺寸与技术分析显示

适用场景（解读层）

  • 对股票基本面、估值、技术指标进行批量分析与研究
  • 将筛选结果导入 CSV、SQLite 或 pandas 做进一步数据处理
  • 获取个股新闻、内部人交易与分析师评级数据用于研究用途
