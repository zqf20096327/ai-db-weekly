基于 Docker Compose 编排的本地 LAMP 开发环境，含 PHP 多版本切换

综述（解读层）

该项目用 Docker Compose 编排 PHP、Apache、MySQL/MariaDB、phpMyAdmin 和 Redis，提供 5.4.x 到 8.4.x 共 11 个 PHP 版本，通过 .env 文件切换版本和配置文档根目录、虚拟主机、数据库等。默认启用 rewrite/headers 模块并预装 Xdebug 及常用 PHP 扩展。README 明确说明面向本地开发，不可直接用于生产，Apple Silicon 需选 MariaDB。

  • 提供 PHP 5.4.x 至 8.4.x 多版本，通过 .env 变量 PHPVERSION 切换
  • 内置 phpMyAdmin（端口 8080）、Redis（端口 6379），默认预装 Xdebug 和 mysqli、pdo_mysql、gd 等 PHP 扩展
  • 支持虚拟主机配置、initdb 初始化脚本（.sh/.sql 等）以及三种方式的本地 HTTPS/SSL 配置

适用场景（解读层）

  • 本地开发和调试 PHP Web 应用，需指定 PHP 版本或 Xdebug 断点调试
  • 搭建含 Apache 虚拟主机和自定义 SSL 域名的本地多站点测试环境
  • 快速初始化带数据库脚本的 PHP 项目开发环境
