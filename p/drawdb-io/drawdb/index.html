浏览器内的数据库 ER 图编辑器，支持导入导出 SQL 脚本

综述（解读层）

drawDB 是一个运行在浏览器中的数据库实体关系图（ERD）编辑器，用于绘制表结构图、导入导出 SQL 脚本、生成迁移脚本，使用无需注册账号。面向需要设计或记录数据库模式的开发者。本地开发通过 npm 安装运行，也可用 Docker 部署；共享功能需另行配置服务端，为可选组件。

  • 在浏览器中编辑数据库实体关系图（ERD），支持导入导出 SQL 脚本
  • 可生成迁移脚本并自定义编辑器，使用无需创建账号
  • 提供 npm 本地运行、npm build 与 Docker 三种部署方式

适用场景（解读层）

  • 设计或记录数据库表结构与关系（ER 图）
  • 从现有 SQL 脚本导入生成图表，或导出 SQL 脚本
  • 本地或 Docker 自部署的团队协作场景（需配置可选共享服务端）
