基于 docker-compose 的 LNMP（Nginx/PHP/MySQL/Redis）集成环境安装脚本

综述（解读层）

LDNMP 是一套通过 docker-compose 编排 Nginx、PHP-FPM、MySQL、Redis 和 Adminer 的 PHP 集成环境部署方案，面向需要在本地或服务器上搭建 PHP 运行环境的开发者。其 PHP 镜像基于官方镜像并预装全部可用扩展，各服务支持单独安装，配置、日志、数据目录按 apps 与 web 目录组织，端口和扩展列表可通过编辑 docker-compose.yaml 调整。要求宿主机为干净系统并预先手动安装 Docker 与 Docker Compose。

  • 默认安装 PHP 全部可用扩展（源自 docker-php-extension-installer），PHP_EXTENSIONS 字段支持按需增删后重新 build
  • 支持 Debian/RedHat 系主流发行版、macOS、openKylin 等，覆盖 x86_64 与 arm64 架构
  • 各服务（nginx/php/mysql/redis/adminer）可单独启动，端口与配置通过编辑 docker-compose.yaml 修改

适用场景（解读层）

  • 在 Linux 或 macOS 上快速搭建本地 PHP 开发环境
  • 需要多 PHP 扩展（如 swoole、xdebug、mongodb、redis 等）的调试与测试环境
  • 通过 Adminer（默认 8086 端口）进行 MySQL 数据库管理
