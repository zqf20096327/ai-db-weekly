🧭 简介解读层（AI·证据行可回查）

在 sqlite-utils 之上为 SQLite 交互式使用提供补充易用性的 Python 库

综述（解读层）

fastlite 基于 sqlite-utils 封装，为 SQLite 交互式操作提供便利接口，面向 Jupyter、IPython 等交互式环境用户。它提供表/列自动补全、动态生成 dataclass、f-string 内嵌 SQL 语句、xtra 字段过滤、多字段主键索引、CSV 等文件导入及基于 graphviz 的数据库图表生成。动态生成的 dataclass 仅在动态环境中有补全，编辑器支持需通过 create_mod 导出模块。

  • 提供数据库表与列的自动补全，表/列对象可字符串化为 SQL 片段并用于 f-string 拼接查询
  • 支持为表动态生成 dataclass，可导出为模块供编辑器导入使用
  • insert/update/upsert/delete 接受 dict、dataclass 或普通 Python 类，并支持多字段主键

适用场景（解读层）

  • 在 Jupyter/IPython 中以自动补全方式交互式浏览和查询 SQLite 数据库
  • 以 dataclass 或 dict 形式对 SQLite 表执行增删改查，含多字段主键和 upsert 操作
  • 导入 CSV/TSV 文件生成新表，或用 graphviz 生成数据库结构图
📖 README 首段存档原文 · 程序抽取

fastlite provides some little quality-of-life improvements for interactive use of the wonderful sqlite-utils library. It’s likely to be particularly of interest to folks using Jupyter.
