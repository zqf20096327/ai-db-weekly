将 PortfolioPerformance XML 与 SQLite 数据库互转的 Python 脚本工具

综述（解读层）

ppxml2db 提供 Python3 脚本，把 PortfolioPerformance 的 XML 文件导入 SQLite 数据库，并可导出回 XML，追求尽量一致的往返转换。数据库模式设计为贴近 PP 内部对象结构。项目为实验性质，不支持 Investment Plans、Exchange Rates 等对象；需 PP 0.70.3+ 的带 id 属性 XML 变体。

  • 提供 ppxml2db_init.py、ppxml2db.py、db2ppxml.py 三个脚本，实现建库、XML 导入、XML 导出的往返流程
  • 数据库模式按每表一个 .sql 文件组织，设计上对应 PP 内部对象结构
  • 支持 Python 3.8-3.12，输出时可用 diff 验证与原文件逐字符一致

适用场景（解读层）

  • 对 PP 数据做只读查询，用 SQL 生成统计与报表
  • 用熟悉的脚本语言编写自定义对账单导入器或价格更新源
  • 修改资产附加数据（如市值、财报日期）后导出回 XML 供 PP 读取
