将 Cycle ORM（PHP DataMapper ORM）集成到 Laravel 框架的扩展包

综述（解读层）

该包将 Cycle ORM 引入 Laravel 7.x（PHP 7.4+），提供 DatabaseManager、ORM、EntityManager 等门面与容器绑定，通过 env 变量和 config/cycle.php 配置数据库连接，并提供 cycle:migrate、cycle:refresh 两条 Artisan 命令。默认在 app 目录定位实体，目录可在配置中指定。适合希望在 Laravel 中使用 DataMapper 模式 ORM 的开发者。

  • 提供 EntityManager 门面与依赖注入方式，用于查找（findByPK）、持久化（persist）和删除（delete）实体
  • 包含 cycle:migrate 与 cycle:refresh 两个 Artisan 命令，分别用于运行迁移和刷新数据库 schema
  • 通过 env 变量与 config/cycle.php 配置连接与数据库，实体目录默认为 app 路径且可自定义

适用场景（解读层）

  • 在 Laravel 7.x 项目中以 Cycle ORM 的 DataMapper 模式管理实体持久化
  • 需要运行 Cycle ORM 迁移、维护数据库 schema 的 Laravel 应用
  • 常驻进程型 PHP 应用（如 RoadRunner 场景）中使用 Cycle 引擎的集成需求
