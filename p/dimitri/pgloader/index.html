pgloader：基于 COPY 命令的 PostgreSQL 数据加载与迁移工具

综述（解读层）

pgloader 是一个 PostgreSQL 数据加载工具，用于从 CSV 文件或 MySQL、SQLite、MSSQL 等数据库迁移数据。它基于 COPY 命令实现加载，遇到错误数据时将其写入单独的拒绝文件并继续加载其余数据，同时支持数据格式转换（如 MySQL 零日期转 NULL）。v4 为 Clojure 重写版本，以单个 JAR 分发，需要 Java 21 及以上，通过 .load 命令文件或命令行参数运行，可经 JAR 下载、Docker 或 Debian/Ubuntu apt（v3）安装。

  • 使用 PostgreSQL COPY 命令加载数据，错误数据写入单独文件并继续加载其余数据
  • 支持从 MySQL、SQLite、MSSQL、CSV、DBF、IXF 等来源迁移，可包含表、索引、外键等 schema 定义并并行加载
  • v4 为 Clojure 重写，以单个自包含 JAR 分发（需 Java 21+），兼容 v3 的 .load 文件语法和命令行参数，支持 JDBC 连接串与 SSL 参数

适用场景（解读层）

  • 从 MySQL、SQLite 等数据库整库迁移到 PostgreSQL，含表结构和索引
  • 加载含错误行的 CSV 或远程数据文件，同时保留被拒绝的数据供后续处理
  • 需要将源库中的特殊格式数据（如零日期）在导入时转换为目标库格式
