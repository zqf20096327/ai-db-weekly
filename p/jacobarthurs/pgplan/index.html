🧭 简介解读层（AI·证据行可回查）

在命令行分析并对比 PostgreSQL EXPLAIN 查询执行计划的 Go 工具

综述（解读层）

pgplan 是一个命令行工具，用于分析 PostgreSQL 查询执行计划并对比两份计划的差异。它提供 analyze 和 compare 命令，内置 15 条规则（如排序落盘、顺序扫描等），以严重级别分类并给出修复建议；支持 JSON EXPLAIN 输出、SQL 文件、stdin 和交互式输入，可通过连接配置文件直接执行 SQL 获取计划。输出为彩色文本或结构化 JSON，可接入 CI 流程。

  • analyze 命令对计划应用 15 条规则，按严重级别输出问题及修复建议
  • compare 命令逐节点对比两份计划的成本、耗时、行数估算和缓冲区差异，低于阈值（默认 5%）的变化被过滤
  • 接受 JSON EXPLAIN 输出、SQL 文件、stdin 或交互式粘贴，SQL 输入需通过 --db 或已保存的连接配置接入数据库

适用场景（解读层）

  • 在终端中分析慢查询的 EXPLAIN 计划，定位排序落盘、顺序扫描等问题
  • 对比优化前后两份执行计划，查看各节点指标变化并得到总结性判定
  • 将 JSON 格式的分析或对比结果接入脚本、CI 流程或仪表盘
