综述（解读层）

Azimutt 是一个用于探索、分析和记录数据库的全栈工具，支持通过 AML 设计模式、搜索定位表与列、按外键追踪关系查询数据，并为表/列添加备注与标签。支持 PostgreSQL、MySQL、MariaDB、MongoDB、Oracle、Couchbase 等数据源。可通过 URL 参数加载公开 SQL 文件，支持 Docker、Heroku、Kubernetes 部署。后端为 Elixir/Phoenix，编辑器为 Elm，采用 MIT 许可证。

  • 支持 PostgreSQL、MySQL、MariaDB、MongoDB、Oracle、Couchbase 等多种数据库的模式接入
  • 提供 AML 语法进行模式设计，支持搜索、按需展示表/列和沿关系导航
  • 支持表/列备注与标签、布局和备忘文档化，以及通过 URL 参数加载公开 SQL 文件生成徽章

适用场景（解读层）

  • 探索包含数百张表的真实数据库模式，梳理表间关系
  • 为团队整理数据库文档（表/列备注、标签、布局与备忘）
  • 通过 badge 在仓库 README 中嵌入公开 SQL 结构文件的在线浏览入口
