基于 MySQLdb1 分支的 Python MySQL/MariaDB C 扩展连接器

综述（解读层）

mysqlclient 是 MySQLdb1 的分支，为 Python 3 提供支持的 MySQL/MariaDB 连接库，通过 C 扩展实现数据库访问。安装依赖系统 C 连接器与开发头文件，Windows 提供 pip 二进制 wheel，Linux/macOS 需先安装开发库后经 pip 安装，可用 MYSQLCLIENT_CFLAGS/LDFLAGS 自定义编译选项。适用于需要在 Python 程序中连接 MySQL 或 MariaDB 数据库的场景。

  • 提供 Python 3 支持的 MySQL/MariaDB 连接扩展模块
  • 自 v2.2.8 起支持实验性自由线程 Python，导入 MySQLdb 不获取 GIL
  • 支持通过环境变量 MYSQLCLIENT_CFLAGS/LDFLAGS 自定义编译链接选项

适用场景（解读层）

  • Python 应用连接 MySQL 或 MariaDB 数据库
  • 自由线程 Python（experimental）环境中导入 MySQLdb
  • 在 Windows/macOS/Linux 上通过 pip 安装并按文档配置构建依赖
