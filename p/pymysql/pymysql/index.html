纯 Python 实现的 MySQL/MariaDB 客户端库，基于 PEP 249

综述（解读层）

PyMySQL 是一个纯 Python 编写的 MySQL 和 MariaDB 客户端库，遵循 PEP 249（DB-API 2.0）规范。它支持 CPython 3.9+ 和最新 PyPy，可连接 MySQL 与 MariaDB 的 LTS 版本。通过 pip 安装即可使用；使用 sha256_password、caching_sha2_password 或 ed25519 认证时需额外安装 [rsa] 或 [ed25519] 依赖。项目采用 MIT 许可证发布，文档托管在 readthedocs 上。

  • 纯 Python 实现，基于 PEP 249（DB-API 2.0）规范
  • 支持 CPython 3.9+ 与 PyPy，可连接 MySQL 和 MariaDB LTS 版本
  • 提供 sha256_password、caching_sha2_password、ed25519 等认证方式的扩展依赖

适用场景（解读层）

  • Python 应用中连接 MySQL 或 MariaDB 数据库执行查询与写入
  • 需要在 PyPy 环境下访问 MySQL/MariaDB 的场景
  • 需要通过 pip 快速安装、无编译依赖接入 MySQL 的项目
