支持 Tornado 的 PyMySQL 分支，提供协程式 MySQL 客户端

综述（解读层）

该项目是 PyMySQL 的分支，使其可在 Tornado 中以协程方式使用，提供 connect、cursor、execute 等接口及连接池模块 pools。README 明确声明其处于实验状态且不再维护，不新增功能，建议迁移至 aiomysql 或使用 asyncio 的 run_in_executor。支持 CPython 2.7/3.3+、PyPy 2.3.1+，连接 MySQL 4.1+ 或 MariaDB 5.1+，通过 pip 安装。

  • 基于 Tornado 的 gen.coroutine 提供 connect、cursor、execute 等异步 MySQL 操作接口
  • 包含 pools.Pool 连接池模块，支持 max_idle_connections、max_recycle_sec 等参数
  • 提供 runtests.py 测试脚本和 tox.ini 多版本 Python 测试配置

适用场景（解读层）

  • 在 Tornado 应用中以协程方式访问 MySQL/MariaDB 数据库
  • 需要连接池管理多协程并发查询的场景
  • 作为 PyMySQL 在 Tornado 环境下的适配层使用（README 提示为实验性、无人维护的项目）
