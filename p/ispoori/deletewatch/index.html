🧭 简介解读层（AI·证据行可回查）

监控并记录 Telegram 群聊中被删除消息的机器人，数据存入 SQLite。

综述（解读层）

DeleteWatch 是一个基于 Telethon 的 Telegram 机器人，用于跟踪聊天中的新消息（文本及可选媒体）并在消息被删除时记录到本地 SQLite 数据库。它向配置中指定的管理员发送删除通知，并提供按用户 ID 检索被删消息的搜索命令。运行需在 .env 中配置 Telegram API 凭据和管理员 ID，依赖 Python 3.7+。适合需要留存聊天删除记录的管理员自用部署。

  • 跟踪文本与可选媒体消息，检测删除事件并写入本地 SQLite 数据库
  • 提供仅限管理员使用的 /search、/stats、/debug 等命令，支持按用户 ID 搜索被删消息与查看统计
  • 通过 .env 文件配置 API 凭据、管理员 ID 及删除通知开关

适用场景（解读层）

  • 群组管理员留存并检索成员删除的消息记录
  • 按用户 ID 追溯特定账号的被删消息历史
  • 本地化保存聊天消息数据用于统计分析
