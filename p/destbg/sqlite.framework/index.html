🧭 简介解读层（AI·证据行可回查）

面向 SQLite 的轻量 ORM，提供 LINQ 式 IQueryable 查询并支持 AOT 发布

综述（解读层）

该项目为 SQLite 提供 LINQ-to-SQL 能力，将 LINQ 查询翻译为 SQL，面向 .NET MAUI、Avalonia 等 AOT 发布的 .NET 8–11 应用。模型通过特性标注（如 [Key]、[Table]），提供 JSON、FTS5、R-Tree、窗口函数支持及四种 provider 包（含 SQLCipher 加密）。无生成器时 AOT 下查询使用反射。

  • 将 LINQ 的 join、group-by、子查询、投影翻译为 SQL，支持 FTS5、JSON/JSONB、R-Tree 与窗口函数
  • 通过 SQLite.Framework.SourceGenerator 在构建期生成行到对象的代码，以适配 Native AOT 与裁剪
  • 提供四个 provider 包（系统 SQLite、自带 SQLite 二进制、SQLCipher 加密、自选 SQLitePCLRaw），API 与程序集名一致可互换

适用场景（解读层）

  • 以 AOT 方式发布的 .NET 8/9/10/11 应用（如 .NET MAUI、Avalonia）中需要 IQueryable 查询的场景
  • 需要对 SQLite 数据库进行加密的场景，可选用基于 SQLCipher 的 Cipher 包
  • 模型类使用特性标注定义表结构，并需要版本化迁移的 SQLite 应用
