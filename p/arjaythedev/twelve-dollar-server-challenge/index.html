🧭 简介解读层（AI·证据行可回查）

一个在 $12/月 VPS 上基准测试同规格 SQLite API 实现的挑战项目

综述（解读层）

该项目定义了一个基于 SQLite 的 5 端点 API 规范与固定的数据库 schema，参与者可用任意语言/框架实现并提交 PR，由 CI 在同一台 1 vCPU、2 GB 内存的 DigitalOcean 服务器上运行 42 项测试与 k6 负载测试打分。规则禁止跨请求缓存、要求写提交后才响应，适合想练习后端性能优化并进入公开排行榜的开发者。

  • 提供固定的 API 规范、SQLite schema、50k 用户/500k 帖子/200k 点赞的种子数据生成脚本及 42 项检查的测试套件
  • 支持任意语言、框架和 SQLite 驱动，允许 Nginx 前置或直接对外服务的两种部署方式
  • 使用 k6 负载测试评分，以通过 5 分钟压测（p95 < 500ms、p99 < 1s、错误率 < 1%）的最大并发用户数为成绩

适用场景（解读层）

  • 开发者在受限硬件上练习 API 性能优化与 SQLite 调优
  • 对比不同语言/框架在相同规范下的吞吐表现
  • 通过公开排行榜展示并分享实现方案
