为 GORM 数据库模式提供即插即用查询语言的 Go 库

综述（解读层）

Goven 是一个 Go 库，用于将任意 GORM 数据库结构对象转换为可搜索的查询语言接口。它通过反射从结构体生成 SQL 适配器，将用户查询解析为 AST 后输出 SQL，且值经过插值处理以防止注入。适合使用 GORM 且想让最终用户以受限语法查询数据库的 Go 项目；目前仅提供 SQL 适配器。

  • 基于 GORM 结构体反射生成查询适配器，几行代码即可使数据可搜索
  • 查询值经插值处理以防注入，不向用户暴露 SQL
  • 支持通过正则表达式和自定义匹配器扩展语法，并可从字段映射中删除字段以禁止查询

适用场景（解读层）

  • 为 GORM 应用添加面向最终用户的搜索/过滤查询功能
  • 通过自定义匹配器支持如 tags[key]=value 的模式化字段查询
  • 对包含不可搜索字段（如敏感字段）的模式提供受控查询入口
