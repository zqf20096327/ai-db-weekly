🧭 简介解读层（AI·证据行可回查）

基于特征扩展 Eloquent 的 Laravel 模型缓存包，支持依赖索引精准失效

综述（解读层）

一个面向 Laravel 的 Eloquent 模型缓存包，通过 HasModelCaching 特征启用，提供 remember()/auto_remember 等缓存读取方式，并记录模型主键到缓存键的依赖索引，使子模型更新时仅失效相关缓存键而非全量刷新。缓存键包含 SQL、绑定、预载、分页与 morph 映射等信息；支持 morph map 版本号与多租户上下文回调，生产环境建议使用 Redis（依赖索引可用原生 Redis sets）。

  • 通过依赖索引实现子模型更新时的精准缓存失效，新增/恢复记录时按模型类级键失效列表页缓存
  • 缓存键包含模型类、SQL 与绑定、嵌套预载、分页参数、morph map 版本及可选租户/认证上下文
  • 提供 Artisan 命令用于预热、检查和刷新依赖索引追踪的缓存条目

适用场景（解读层）

  • 父查询缓存需要随子模型变更而失效的应用
  • 多租户或多用户场景下查询结果随租户/用户上下文变化的读取缓存
  • 高流量的 Laravel 列表/详情接口读写（配合 Redis 驱动）
