用 Docker Compose 一键运行 Zabbix + PostgreSQL + Grafana 监控栈的部署配置

综述（解读层）

该项目提供一套 Docker Compose 配置，用于运行 Zabbix 7.4 监控系统并搭配 PostgreSQL 18 与 Grafana 13.2 仪表盘，使用官方 Zabbix Docker 镜像。适合已有 Zabbix 使用习惯、想用 Grafana 绘制仪表盘的用户。内置 zabbix-init 一次性服务，启动时调用 Zabbix API 将主机 agent 接口从 127.0.0.1 改指 DNS 名 zabbix-agent，解决容器内 loopback 指向问题；PostgreSQL 18 要求 Zabbix 7.4.4 或更新版本。

  • 基于官方 Zabbix Docker 镜像，通过 docker compose up -d 启动 Zabbix Server、Frontend、Agent、PostgreSQL 与 Grafana
  • 包含 zabbix-init 幂等初始化服务，启动时自动将 Zabbix server 主机的 agent 接口改指 zabbix-agent
  • 通过 .env 文件管理镜像标签、数据库与 Grafana 凭据、时区等配置，并在 compose 中预配置 Zabbix 数据源

适用场景（解读层）

  • 快速在单机环境搭建 Zabbix + Grafana 监控栈用于指标采集与仪表盘展示
  • 以 Docker Compose 方式部署并自行调整 .env、端口映射与缓存参数的环境
  • 需要绕过容器内 127.0.0.1 agent 接口指向问题的 Zabbix 部署场景
