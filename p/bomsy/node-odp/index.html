封装 ODP.NET DLL 的 Node.js Oracle 数据库绑定库

综述（解读层）

node-odp 是一个 Node.js 库，通过封装 ODP.NET（.NET 的 Oracle 数据提供程序）实现对 Windows 平台上 Oracle 数据库的访问。使用者需先安装 ODAC（策略 DLL 放入 GAC）、Visual C++ 2010 运行库，且仅支持 Node v0.10.x。API 提供 OracleConnection 与 OracleCommand 类，支持文本 SQL、函数调用、存储过程及 REFCURSOR 返回。

  • 提供 executeReader、executeNonQuery、executeScalar 三种执行方式，以回调返回结果
  • 参数对象支持 INPUT/OUTPUT/INPUTOUTPUT/RETURNVALUE 方向，涵盖 REFCURSOR 等 20 余种 dbType 常量
  • 通过 node-gyp 构建，支持 32 位与 x64 编译

适用场景（解读层）

  • Windows 环境下 Node.js 应用连接并查询 Oracle 数据库
  • 调用 Oracle 存储过程或函数并获取输出参数、REFCURSOR 结果集
  • 执行带输入/输出参数绑定的 SQL 语句
