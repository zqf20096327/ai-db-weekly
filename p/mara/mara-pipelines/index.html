🧭 简介解读层（AI·证据行可回查）

基于 Python 声明式代码与 GNU make 依赖语义的轻量 ETL 流水线框架

综述（解读层）

Mara Pipelines 提供一个轻量级数据转换框架，用声明式 Python 代码定义任务、节点与依赖，依赖 PostgreSQL 存储运行信息，基于 multiprocessing 在单机执行。适合需要介于纯脚本与 Airflow 之间的团队。限制：不支持 Windows 原生运行（需 Docker/WSL），文档仍在编写中，需参考示例项目入门。

  • 以声明式 Python 代码定义流水线、任务和命令，节点依赖遵循 GNU make 语义
  • 基于 Python multiprocessing 的单机执行，并按记录的运行时长实现成本优先级队列
  • 提供可集成到 Flask 应用的 Web UI，展示节点依赖图、30 天运行时长图表与输出日志，并可直接运行流水线和任务

适用场景（解读层）

  • 需要以代码方式管理数据集成与转换流水线的 Python 项目
  • 希望用浏览器查看、运行和调试流水线节点的团队
  • 单机 ETL 场景，无需引入分布式任务队列的数据处理工作流
