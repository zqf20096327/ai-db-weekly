无依赖的 OceanBase MySQL 模式 SQL 审计与索引评审 Skill

综述（解读层）

这是一个用于 OceanBase MySQL 模式 SQL 评审的 Skill，将正确性风险与性能信号分开处理，包含静态 SQL 审计脚本，并依据 schema、统计信息和 EXPLAIN 证据给出索引建议。其审计脚本为纯静态实现，不连接数据库也不执行被审查的 SQL，通过 python3 运行，入口为 SKILL.md。

  • 提供静态 SQL 审计脚本 ob_sql_audit.py，不连接数据库、不执行被审查的 SQL
  • 将正确性风险与性能信号分离
  • 基于 schema、统计信息与 EXPLAIN 证据生成索引建议

适用场景（解读层）

  • 对 OceanBase MySQL 模式的 SQL 语句进行风险与性能信号审查
  • 在有 schema、统计信息和 EXPLAIN 输出时进行索引评审
  • 在无法连接数据库的环境中做静态 SQL 检查
