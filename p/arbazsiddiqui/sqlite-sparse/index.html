🧭 简介解读层（AI·证据行可回查）

在单个 SQLite 文件内运行 SPLADE 稀疏语义检索的扩展

综述（解读层）

sqlite-sparse 是一个 SQLite 扩展，通过虚拟表在单个数据库文件中实现学习型稀疏检索：插入时用 llama.cpp 运行 SPLADE 编码器对文档加权分词，查询时仅需查表分词加倒排索引精确打分，无需模型或服务。面向读多写少的小型系统，提供 Python/npm 包和可加载二进制及 WASM 版；索引速度较慢且质量低于同规模稠密模型。

  • 插入时经 llama.cpp 运行 SPLADE 编码器生成加权词项并存入倒排索引，查询时只需分词与文件内静态权重表，无需模型、服务器或 ANN 索引
  • 提供 SQLite 虚拟表接口，结果为行，可用 SQL 进行过滤、连接与排序，支持 Python、Node（node:sqlite、better-sqlite3）及任意语言的加载扩展方式
  • 附带仅查询的 WebAssembly 构建，可在浏览器中搜索和写索引（无编码器），模型权重为 Apache-2.0 原版未修改

适用场景（解读层）

  • 需将语义搜索嵌入单文件 SQLite 应用、且查询端无模型下载条件的读多写少系统
  • 在 GPU 机器上一次性构建大语料索引后分发到读取端（如边缘设备、浏览器 WASM）的场景
  • 需要可解释匹配词项及权重的检索场景，或需用 SQL 对检索结果做过滤和连接的应用
