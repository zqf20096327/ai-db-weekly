SQLite 的 WebAssembly 构建，支持用 JavaScript 编写 VFS

综述（解读层）

wa-sqlite 是 SQLite 的 WebAssembly 构建，允许开发者完全用 JavaScript 实现 SQLite 虚拟文件系统（VFS），从而接入 IndexedDB、Origin Private File System 等浏览器存储。面向需要在浏览器中使用 SQLite 的 Web 应用开发者。项目提供同步与异步（Asyncify 或 JSPI）两种构建，附多款 VFS 示例和演示页面；自建需 Emscripten SDK 3.1.61+，Debian Linux 环境已知可用，采用 MIT 许可证。

  • 支持完全用 JavaScript 编写 SQLite 虚拟文件系统（VFS），可接入 IndexedDB 与 Origin Private File System 等浏览器存储
  • 提供同步构建及基于 Asyncify 和 JSPI 的异步构建，输出 ES6 模块 + WASM 至 dist/ 目录
  • 提供核心 SQLITE C API 函数的 JavaScript 封装及多个 VFS 示例实现（如 IDBBatchAtomicVFS、OPFSCoopSyncVFS 等）

适用场景（解读层）

  • 在浏览器 Web 应用中运行 SQLite 并将数据持久化到 IndexedDB 或 OPFS
  • 通过演示页面尝试不同 VFS 配置或运行基准测试
  • 需要以 JavaScript 扩展 SQLite 存储层的开发者自定义方案
