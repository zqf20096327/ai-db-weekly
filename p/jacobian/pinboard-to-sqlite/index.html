将 Pinboard 书签数据保存到 SQLite 数据库的命令行工具

综述（解读层）

pinboard-to-sqlite 是一个命令行工具，通过 Pinboard API 抓取用户书签并写入 SQLite 数据库。它基于 Dogsheep 项目的库构建，适合想把自己的 Pinboard 数据存入本地数据库、配合 Datasette 等工具查询的用户。安装后需先运行 auth 命令保存 API token（存于 auth.json），再用 posts 命令写入指定 db 文件。注意所用 API 有每分钟一次的速率限制。

  • 通过 pip 安装，提供 auth 命令以 API token 完成认证，凭证保存在 auth.json（可用 -a/--auth 指定其他文件）
  • 提供 posts 命令，将 Pinboard 书签数据写入指定的 SQLite 数据库文件
  • 基于 Simon Willison 的 Dogsheep 项目及其库构建

适用场景（解读层）

  • 将个人 Pinboard 书签导出为本地 SQLite 数据库文件
  • 在 Datasette 中浏览和查询保存后的书签数据
  • 定期备份 Pinboard 数据到本地
📖 README 首段存档原文 · 程序抽取

Inspired by (and using libraries from) [Simon Willison's Dogsheep project](https://github.com/dogsheep). You're probably going to want to run Datasette on the resulting db.
