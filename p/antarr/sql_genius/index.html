Rails 的 AI 辅助 SQL 仪表盘，用于检查和优化 MySQL/MariaDB/PostgreSQL。

综述（解读层）

SQLGenius 是一个挂载于 Rails 应用的 SQL 仪表盘 gem，用于检查 MySQL、MariaDB 与 PostgreSQL 数据库。它提供服务器健康概览、慢查询统计（读自 performance_schema 与 pg_stat_statements）、表大小与索引分析、EXPLAIN 执行计划，并包含可选的 AI 功能（依赖 OpenAI 兼容 API 或 Ollama）。SQL 执行强制只读，支持表封锁、列脱敏与行数限制。采用 source-available 非商业许可。

  • 提供仪表盘、查询统计、表大小、重复/未用索引检测与 EXPLAIN 分析等功能
  • SQL 执行内置只读强制、封锁表、列脱敏、行数限制与超时机制
  • AI 功能可选，兼容 OpenAI、Azure OpenAI、Ollama（本地/云）及 OpenAI 兼容 API

适用场景（解读层）

  • Rails 团队在开发或运维中检查数据库服务器健康与查询活动
  • 排查慢查询、昂贵查询并分析执行计划
  • 检测冗余或未使用索引并生成 DROP INDEX 语句
