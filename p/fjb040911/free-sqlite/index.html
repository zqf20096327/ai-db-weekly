VSCode 扩展，用于浏览和查询 SQLite 数据库文件

综述（解读层）

Free SQLite 是一个 VSCode 扩展，用于浏览和查询 SQLite 数据库。用户点击 .sqlite 或 .db 文件即可打开，在侧边栏查看库中全部表及表数据，界面随 VSCode 主题适配。内置 SQL 编辑器提供关键字、表名和字段自动补全，查询出错时可通过 Terminal>output>free sqlite 查看错误日志。查询结果可导出为 Excel 或 CSV，常用 SQL 语句可加入收藏以便快速执行或查看。适合需要在 VSCode 中直接查看和操作 SQLite 数据库的开发者。

  • 支持点击 .sqlite 或 .db 文件直接打开，并可在侧边栏浏览数据库中的所有表
  • SQL 编辑器支持自动补全 SQL 关键字、表名和字段，支持同时打开多个数据库文件
  • 查询结果可导出为 Excel 或 CSV，常用 SQL 语句支持收藏功能

适用场景（解读层）

  • 在 VSCode 中浏览 SQLite 数据库的表结构和数据
  • 编写并执行 SQL 查询语句并导出结果
  • 保存和复用常用的 SQL 语句
