🧭 简介解读层（AI·证据行可回查）

面向对话代理的分层记忆引擎，区分印象与精确细节并按召回策略注入。

综述（解读层）

Tidal Memory 是一个用于对话代理的 SQLite 记忆库，将低分辨率印象与高分辨率精确细节分离存储，并通过可配置的三阀召回策略（触发敏感度、关联半径、注入预算）控制注入。它面向构建长期人机对话应用的开发者，以库或 CLI 形式集成，无内置 UI；支持自定义检索器、印象生成器与事实抽取回调，采用 AGPL-3.0 许可。

  • 双分辨率存储：低分辨率印象与精确细节使用不同注入路径，背景类记忆不占用细节召回候选位
  • 渐进遗忘：窗口印象滚动为周/月摘要，源数据归档而非删除；时间感知事实支持新记录取代旧记录并保留历史
  • 可扩展接口：默认提供 SQLite FTS5 关键词检索，可接入自定义向量检索器、印象生成器和事实抽取回调

适用场景（解读层）

  • 为长期陪伴类对话应用添加可回溯的记忆层
  • 需要精确事实与模糊印象分开管理的对话代理
  • 希望以 CLI/库形式集成、通过代码代理完成接入的工程化记忆方案
