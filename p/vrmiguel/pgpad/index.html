基于 Tauri 的跨平台轻量数据库客户端

综述（解读层）

pgpad 是一个使用 Rust（Tauri + Svelte）构建的跨平台数据库查询工具，面向日常查询场景。当前支持 PostgreSQL（主要目标，经单元测试）、SQLite 和 CockroachDB（经 Postgres Wire Protocol），MySQL 等数据库在计划中。项目仍处于开发中（WIP），作者明确说明它不是一个类似 DBeaver 的完整数据库管理系统。

  • 支持 PostgreSQL、SQLite、CockroachDB 连接与查询，前两者经单元测试
  • 支持 Windows 7+、macOS 10.15+ 和 Linux（需 libwebkit2gtk 4.1+）
  • 通过 npm + Rust 工具链（1.85+）以 Tauri 构建，提供 build 与 dev 命令

适用场景（解读层）

  • 对 PostgreSQL 或 SQLite 进行日常查询
  • 连接使用 Postgres Wire Protocol 的 CockroachDB
  • 在 Windows/macOS/Linux 桌面环境运行数据库客户端
