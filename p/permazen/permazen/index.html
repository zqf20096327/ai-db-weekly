Java 语言驱动持久层，以有序键值存储为底层实现对象持久化

综述（解读层）

Permazen 是面向 Java 的持久化层，将数据库视为有序键值存储，在 Java 侧实现字段编解码、索引、模式管理、变更通知与校验。它支持 SQL、键值和内存数据库，包含 15+ 数据库适配器及基于 Raft 的分布式实现，自 2015 年起用于商业软件。适合代码与数据同机或近距离部署的场景；无查询计划器，需开发者自行设计查询方式。

  • 提供键值 API 及 15+ 数据库技术适配器，包含基于 Raft 共识算法的分布式键值数据库实现
  • 实现自动模式管理、增量模式演化、简单与复合索引、自定义类型索引及非本地字段变更通知
  • 提供内嵌 Java CLI，可用 Java 类型、值和表达式（含 Java 8 stream 与 lambda）执行数据库维护任务

适用场景（解读层）

  • 代码与数据库同机或近距离部署的 Java 应用持久化
  • 需要模式版本共存与滚动升级、增量数据迁移的场景
  • 需要以键值接口统一访问多种数据库技术并通过适配器切换存储后端的项目
