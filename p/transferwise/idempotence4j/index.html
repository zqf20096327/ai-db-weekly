Java 幂等操作处理库，将操作结果持久化到数据库

综述（解读层）

idempotence4j 是 TransferWise 开源的 Java 库，用于处理幂等操作：调用方提供 actionId、执行逻辑与结果映射函数，库将操作结果写入数据库，重试时返回已持久化的结果。要求 Java 17+，支持 PostgreSQL 和 MariaDB 两种数据库实现，内置 Flyway 迁移脚本，并提供 Spring Boot starter 自动装配。客户端需连接数据库主节点以避免复制延迟问题。

  • 提供 core、PostgreSQL、MariaDB、metrics、Spring Boot starter 五个模块，核心 API 定义动作执行策略
  • 每次动作执行采集指标并通过 io.micrometer 发布计数器和计时器指标，附 Grafana 仪表盘
  • 默认关闭动作保留（retention），可通过配置参数启用

适用场景（解读层）

  • 需要保证操作幂等性的 Java/Spring Boot 服务
  • 使用 PostgreSQL 或 MariaDB 并依赖数据库持久化幂等记录的场景
  • 需要监控幂等操作执行次数、重试次数和延迟的微服务
🔌 适配哪些库db_scan 程序判定

MariaDB、PostgreSQL
