SQLite.swift 的数据库 schema 迁移管理库，基于版本表记录迁移

综述（解读层）

SQLiteMigrationManager.swift 是面向 SQLite.swift 的 schema 管理系统，设计参考 FMDBMigrationManager。它在数据库中维护一张 schema_migrations 表，以整数版本号记录已应用的迁移，版本命名建议使用时间戳编码的整数。迁移可用 SQL 文件（文件名须为 <version>_<name>.sql 形式）或实现 Migration 协议的 Swift 代码编写。支持 Swift Package Manager、CocoaPods、Carthage 安装，MIT 协议，作者 Vincent Garrigues。

  • 通过 schema_migrations 表记录已应用的迁移版本，支持任意基于整数的版本方案
  • 支持 SQL 文件迁移（文件名格式 _.sql）与实现 Migration 协议的 Swift 迁移两种方式
  • 提供创建迁移表、执行迁移、检查 schema 状态等 API，兼容 SPM、CocoaPods、Carthage

适用场景（解读层）

  • 使用 SQLite.swift 的 iOS/macOS 应用需要对本地数据库结构做版本化升级
  • 团队希望通过时间戳命名的 SQL 文件或 Swift 代码统一管理迁移脚本
