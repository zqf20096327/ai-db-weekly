在内存虚拟盘上创建临时 SqlServer 数据库的 .NET 库

综述（解读层）

SqlInMemory 是一个 .NET NuGet 包，用于在内存虚拟盘（基于 ImDisk 的 RamDisk，默认挂载为 Z: 盘）上创建 SqlServer 数据库，而不是写入硬盘；使用方传入连接字符串并通过 using 作用域管理生命周期，作用域结束时自动删除数据库并卸载虚拟盘。使用前需先安装 ImDisk。适用于需要在真实 SqlServer 上运行测试的集成测试场景，文档给出的用法为单行 Create 调用。

  • 通过 RamDisk（后端使用 ImDisk）在内存中创建 SqlServer 数据库而非硬盘
  • 传入连接字符串即可创建虚拟盘并建库，Dispose 时自动删除数据库并卸载盘
  • 以 NuGet 包（Install-Package SqlInMemory）分发，MIT 许可

适用场景（解读层）

  • 针对真实 SqlServer 数据库的集成测试
  • 需要数据库生命周期随测试作用域自动创建与清理的测试流程
  • 希望测试期间数据库读写不落在物理硬盘上的场景
📖 README 首段存档原文 · 程序抽取

SqlInMemory is a library for creating SqlServer database on Memory instead of hard disk, at last Drops and Disposes database when you're done with it. This is useful for Integration Testing.
