基于 ES6 标签模板字符串的 PostgreSQL 客户端库

综述（解读层）

Postgres.js 是一个运行于 Node.js 18+、Bun、Cloudflare Workers 的 PostgreSQL 客户端，为 ES 模块、无依赖，Deno 可通过 Node 兼容层运行。它以标签模板字符串为核心：插值参数被替换为 $1、$2 等协议占位符并单独发送，由数据库端处理转义和类型转换，参数类型由服务器决定。可通过 npm install postgres 安装，连接配置支持 URL 字符串或选项对象，未提供的选项回退到 psql 环境变量。

  • 以标签模板字符串处理查询参数，值经序列化后替换为 $1、$2 等占位符并单独发送到数据库
  • 支持动态构建查询：动态列选择、插入、更新、where in、排序、表名与列名标识符，以及嵌套 sql 片段的查询组装
  • 提供游标（cursor）分批读取、forEach 逐行处理、describe 查询描述等高级方法

适用场景（解读层）

  • 在 Node.js、Bun、Deno 或 Cloudflare Workers 环境中连接 PostgreSQL（兼容 CockroachDB 等标签所示数据库）
  • 需要以模板字符串方式编写参数化查询、避免字符串拼接构建 SQL 的应用
  • 需要分批或逐行处理大量查询结果集的场景
