面向 Gigapipe 的 OpenTelemetry Collector 发行版，将多种观测数据写入 ClickHouse

综述（解读层）

这是 Gigapipe（原 qryn）的 OpenTelemetry Collector 发行版，把来自 Loki、Prometheus、Zipkin、Jaeger 等多类源的日志、指标与追踪数据，按 Gigapipe 指纹和表格式写入 ClickHouse，供 LogQL、PromQL、Tempo 等查询访问。镜像发布于 ghcr.io，提供 latest 与不可变版本标签，文档含 Kafka 标签配置示例及 v0.108→v0.154 迁移说明。源码构建需 Go 1.26。

  • 支持日志（Loki、Splunk、Fluentd、Cloudwatch、Syslog）、指标（Prometheus、InfluxDB、OTLP）与追踪（Zipkin、Jaeger、Skywalking、OTLP）等多种摄取格式
  • 使用 Gigapipe 指纹与表格式将数据存入 ClickHouse，可通过 LogQL、PromQL、Tempo 与 Pyroscope 查询
  • 镜像发布 latest 与不可变版本标签（如 0.0.52），版本标签不会被覆盖，可通过指向旧标签回滚；上游基于 open-telemetry/opentelemetry-collector v0.154.0 与 contrib v0.153.0

适用场景（解读层）

  • 需要将多种厂商/平台的日志、指标、追踪数据统一采集并存入 ClickHouse 的场景
  • 通过 Kafka 等通用接收器接收日志流，并需将 JSON 字段转换为标签的管道配置
  • 从 qryn/gigapipe 旧版本 collector 升级并需要迁移说明（如 qryn→gigapipe 导出器重命名、默认行为变更）的部署
