基于 ClickHouse 等存储的开源多标准可观测性栈

综述（解读层）

Gigapipe（前称 qryn）是面向日志、指标、追踪与性能剖析的开源可观测性后端，数据存储于 ClickHouse、DuckDB 或 GigAPI 加 S3。它实现 Loki、Prometheus、Tempo、Pyroscope 的 API 及 LogQL、PromQL、TraceQL 查询语言，支持 OpenTelemetry 及 Datadog、Elastic 等格式接入，可作 Grafana 数据源或使用内置 Explorer，采用 AGPL-3.0 许可。

  • 实现 Loki、Prometheus、Tempo、Pyroscope 兼容 API，支持 LogQL、PromQL、TraceQL 查询
  • 支持 OpenTelemetry OTLP（gRPC 与 HTTP，含 protobuf 与 JSON）及 Influx、Datadog、Elastic 等格式的数据接入
  • 内置零依赖数据浏览器 view，并提供 DOT 格式剖析图渲染（含 maxNodes 参数）

适用场景（解读层）

  • 以 ClickHouse/S3 为后端、自行掌控存储的可观测性数据采集与查询部署
  • 作为现有 Loki/Prometheus/Tempo/Pyroscope 客户端与 Grafana 数据源的后端接入点
  • 通过 OpenTelemetry Collector 直接推送日志、指标、追踪与剖析信号并集中查询
