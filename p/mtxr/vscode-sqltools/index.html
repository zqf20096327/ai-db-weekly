VS Code 上的 SQL 数据库管理与查询扩展，采用可插拔驱动架构

综述（解读层）

SQLTools 是一组 VS Code 扩展，用于连接、查询并展示 SQL 数据库的结果。项目采用可插拔驱动架构：核心扩展随驱动扩展一同安装，官方驱动覆盖 MySQL、PostgreSQL、SQLite、MSSQL、MariaDB 等，另有大量社区驱动（Oracle、Snowflake、ClickHouse 等）。使用前需为所用数据库安装对应驱动扩展并创建连接。

  • 提供 SQL 代码美化与格式化功能
  • 支持查询执行、历史记录与书签，包含连接资源管理器和 INSERT 语句生成器
  • 采用可插拔驱动架构，支持通过官方驱动（MySQL、PostgreSQL、SQLite、MSSQL 等）和社区驱动（Oracle、Snowflake、ClickHouse、DuckDB 等）连接多种数据库

适用场景（解读层）

  • 开发者在 VS Code 中直接连接并查询数据库，无需切换外部客户端
  • 需要 SQL 代码格式化和查询历史管理的日常数据库维护工作
  • 使用的数据库无官方驱动时，可依据项目的驱动开发指南自行编写驱动扩展
