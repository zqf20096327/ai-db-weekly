零运行时依赖的 PHP 全栈框架，内置路由、ORM、数据库适配与 OpenAPI 生成

综述（解读层）

Tina4 PHP 是一个通过 Composer 安装的 PHP Web 框架，要求 PHP 8.2+。它以单一包提供路由、ORM、多数据库适配、JWT 认证、队列、GraphQL、WebSocket、模板引擎等模块，核心无第三方运行时依赖，数据库驱动可选安装。支持 Rust CLI 热重载、开发者调试面板与脚手架生成。

  • 通过 Database::create() 统一适配 SQLite、PostgreSQL、MySQL、MSSQL、Firebird，包含连接池、事务与 SQL 方言翻译
  • ORM 实现 Active Record、has_one/has_many/belongs_to 关系、软删除、QueryBuilder、自动 CRUD 与支持回滚的迁移
  • 内置 JWT（HS256/HS384/HS512）、PBKDF2-SHA256 密码哈希、速率限制、CSRF 令牌，并提供 /swagger 自动 OpenAPI 文档

适用场景（解读层）

  • 需要单包安装、依赖精简的 PHP Web 应用或 API 服务开发
  • 需要基于注解自动生成 Swagger/OpenAPI 文档的接口项目
  • 使用 Firebird、SQLite 等多种数据库并通过统一适配器访问的项目
