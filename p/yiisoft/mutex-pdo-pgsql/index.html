基于 PDO 的 PostgreSQL 互斥锁驱动，实现 yiisoft/mutex 接口

综述（解读层）

该库为 yiisoft/mutex 提供 PostgreSQL 实现，通过 PDO 扩展连接数据库，要求 PHP 7.4 以上。提供 MutexInterface 与 MutexFactoryInterface 两个实现类，支持回调同步执行、手动开关锁、底层 acquire/release 及自定义重试间隔（默认 50 毫秒）四种使用层级，采用 BSD 许可证发布，适合已在用 PostgreSQL 的 Yii3 项目接入互斥锁机制。

  • 提供实现 MutexInterface 与 MutexFactoryInterface 的 PgsqlMutex 等类
  • 支持回调同步执行、手动 acquire/release 及 withRetryDelay 自定义重试间隔（默认 50 毫秒）
  • 通过 Composer 安装，依赖 PHP 7.4+ 与 PDO 扩展，BSD 许可证

适用场景（解读层）

  • 多进程/多实例环境下需对临界代码段做互斥执行的 PHP 应用
  • 已使用 PostgreSQL 且基于 yiisoft/mutex 抽象的 Yii3 项目
  • 需要可配置锁等待超时与重试频率的后台任务调度场景
