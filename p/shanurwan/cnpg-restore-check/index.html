🧭 简介解读层（AI·证据行可回查）

面向 CloudNativePG 备份的定时恢复验证 Kubernetes 控制器

综述（解读层）

该项目是一个 Kubernetes 控制器，按 cron 计划将 CloudNativePG（需 1.26+ 与 plugin-barman-cloud）的备份恢复到临时单实例集群，运行 amcheck、自定义 SQL 断言和新鲜度检查，测量恢复时间（RTO）与数据年龄（RPO），未达目标或恢复失败时记录结果、发送 Prometheus 告警并删除临时集群。适用于使用 barman-cloud 对象存储备份（S3/GCS/Azure Blob）且需例行验证备份可恢复性的运维团队。限制：只支持 barman-cloud 备份，freshness 检查需要数据库中频繁写入的时间戳数据；社区项目，非 CloudNativePG 官方组件。

  • 按 cron 计划创建临时 CloudNativePG Cluster，从备份走真实恢复路径，支持 backupID、targetTime、targetImmediate 等恢复目标
  • 对恢复后的主库运行 amcheck（含可选堆页与堆-索引一致性检查）、用户自定义 SQL 断言及新鲜度查询，输出恢复耗时与数据年龄
  • 导出 Prometheus 指标并内置五类告警规则（失败、数据年龄/恢复时间超标、无成功记录、运行卡住），每条附 runbook

适用场景（解读层）

  • 对生产 PostgreSQL 备份进行周期性可恢复性演练，发现 WAL 归档缺口、时间线切换失败等备份成功但恢复异常的情况
  • 用实测恢复时间与数据年龄对照 RTO/RPO 目标，通过 PrometheusRule 触发告警
  • 通过 run-now 注解在变更（配置、凭据、镜像、存储策略）后按需触发一次恢复验证
