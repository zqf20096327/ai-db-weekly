🧭 简介解读层（AI·证据行可回查）

单二进制 Go 工具，为 PostgreSQL 持续流式归档 WAL 并执行定时基础备份

综述（解读层）

pgrwl 是用 Go 编写的 PostgreSQL 备份工具，通过流复制协议接收 WAL 并做定时基础备份，输出到 S3、SFTP 或本地存储，内置压缩、加密、保留策略、恢复助手和 HTTP API。适合需要灾难恢复与 PITR 的数据库运维团队，以单个二进制运行，无需外部调度器或额外备份工具。

  • 通过流复制协议接收 WAL，支持复制槽、*.partial 文件与同步复制确认（RPO=0），写本地文件系统并 fsync 后再压缩、加密上传
  • 支持定时及通过 HTTP API 手动触发基础备份，按恢复窗口策略管理保留
  • 提供 receive 模式与 serve 模式，serve 模式作为 restore_command 助手从恢复守护进程取回 WAL 文件

适用场景（解读层）

  • 生产环境持续备份与 WAL 归档守护进程，配合 Kubernetes 或 docker-compose 运行
  • 崩溃后基于恢复窗口做时间点恢复（PITR）的灾难恢复流程
  • 高持久性同步复制场景下的零数据丢失归档部署
