🧭 简介解读层（AI·证据行可回查）

用词表对单个 MySQL 用户口令进行穷举的 C 语言命令行工具

综述（解读层）

MySQL Brute 是一个运行于 Linux 的 C 语言工具，读取词表文件并逐个尝试登录指定的 MySQL 用户，最初用于 localhost 账户口令丢失时的恢复场景（如 root 口令不可用且无法以安全模式重启 mysqld）。依赖 libmysqlclient-dev 或 libmariadb-dev 与 libssl-dev 编译，也提供 x86 64 位和 ARM 32 位可执行文件下载。词表超长条目需调大源码中的 MAX_WORD_LEN 并重新编译以避免缓冲区溢出。

  • 支持指定主机、用户名、词表文件和端口号（-p）运行，本地 socket 连接下在 Core i3 桌面 CPU 上约每秒尝试 20,000 个口令，局域网 TCP 连接约每秒 1,000 个
  • 可通过 make deps && make && make install 安装，支持 GCC 与 Clang 编译，并可改用 MariaDB 库构建
  • 附带远程 MySQL 连接故障排查说明，涵盖 bind-address、skip-networking、防火墙规则、mysql.user 主机授权及非默认端口等检查项

适用场景（解读层）

  • 恢复本机 MySQL 账户口令，例如 root 口令丢失且无法通过安全模式重置，或 PLESK 管理的 admin 用户
  • 在已授权场景下对指定 MySQL 用户进行口令词表测试
  • 按 README 清单诊断远程 MySQL 连接失败原因
