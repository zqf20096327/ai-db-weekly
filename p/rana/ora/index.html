基于 OCI C 库的 Go 语言 Oracle 数据库驱动

综述（解读层）

ora 是一个实现 database/sql/driver 接口的 Oracle 驱动，也可绕过 database/sql 直接使用 ora 包以获取指针、切片、可空类型等扩展特性。底层通过 cgo 调用 Oracle OCI C 库，因此部署需 CGO、GCC 及 Oracle 11g 或 Instant Client 11.2.0.4.0。提供存储过程 OUT 参数、批量绑定、会话池等能力。

  • 实现 Go database/sql/driver 接口，支持全部 Oracle 内置数据类型，包括 NUMBER、CLOB、BLOB、RAW、BFILE、SYS_REFCURSOR 等
  • 通过 cgo 调用 Oracle OCI 库，支持 Session Pool、Connection Pool 和 DRCP 三种连接池，以及 SYSDBA/SYSOPER 连接
  • 提供语句级预取行数和内存配置、数组绑定、可空类型及布尔值到 CHAR(1) 的 rune 映射

适用场景（解读层）

  • 需要在 Go 应用中通过 database/sql 访问 Oracle 数据库的场景
  • 需调用带 OUT 参数的存储过程或处理 LOB、REFCURSOR 等 Oracle 特有类型的应用
  • 可使用 OCI 库且需要连接池或批量 DML 的环境
