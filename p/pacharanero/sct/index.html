🧭 简介解读层（AI·证据行可回查）

本地优先的 SNOMED CT 工具链，单二进制将 RF2 转为 NDJSON 及多种查询格式

综述（解读层）

sct 是一个命令行工具，用于将 SNOMED CT 的 RF2 发布文件转换为规范 NDJSON 工件，并可派生 SQLite、Parquet、Markdown、Arrow 等格式，供 sqlite3、duckdb、jq 等标准工具本地查询，无需远程术语服务器。面向处理临床术语数据的开发者和健康信息学团队。核心 FHIR 服务器、TUI、搜索、MCP 等子命令默认编译在内，gui、dmwb、diagram-svg 为可选 feature；作者声明该项目仍处于进行中状态。

  • 提供单一二进制实现 RF2 到 NDJSON、SQLite（FTS5）、Parquet、Markdown、Arrow IPC、传递闭包表等多种工件的转换与导出
  • 内置 FHIR R4 术语服务器（$lookup/$validate-code/$subsumes/$expand，支持 ECL）、MCP 服务器、TUI/GUI，以及词法/模糊/语义多种搜索
  • 支持通过 NHS TRUD API 下载 RF2 发布、读取 CTV3 与 Read v2 映射、解析 refset，并提供 diff、info、cite 等辅助子命令

适用场景（解读层）

  • 在没有远程术语服务器的本地环境中，用 sqlite3、duckdb、jq、ripgrep 等标准工具查询 SNOMED CT 概念数据
  • 部署自托管的 FHIR R4 术语服务器（含 Docker Compose + Caddy HTTPS 流程），提供概念查找、校验、包含关系与 ECL 展开服务
  • 为 LLM/MCP 工具链提供本地术语访问，或生成 Ollama 向量嵌入做语义搜索（依赖 Ollama，标注为实验性）
