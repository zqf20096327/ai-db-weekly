基于Python和urwid的openGauss数据库实时监控命令行工具

综述（解读层）

ogtop是一款用于监控openGauss数据库实时容量、性能与运行状态的命令行工具，面向DBA。它通过psycopg2连接数据库，读取pg_stat*、dbe_perf等系统表和视图，经numpy与pandas处理后以urwid展示17个一级页面，涵盖session、锁、等待事件、流复制、慢SQL等。部分功能需开启enable_asp、enable_memory_limit等参数，且ASP页面仅能在postgres库下访问。

  • 提供database、session、asp、lock、wait_event、replication、slow_sql等17个页面，支持页面间跳转与按pid等字段进入对象详情页
  • 通过p键截取当前页面数据快照并持久化到本地，支持按pid、库名等条件在页面终止数据库会话
  • 集成dbmind索引推荐接口，提供SQL执行计划查看与SQL PATCH创建、删除等操作

适用场景（解读层）

  • DBA实时检查openGauss数据库的SQL负载、session、锁阻塞与等待事件等运行情况
  • 通过asp历史会话数据与slow_sql页面回溯分析过去某时间段的性能瓶颈
  • 在页面上查看流复制与复制槽状态、备机回放进度，并删除失效复制槽
📖 README 首段存档原文 · 程序抽取

ogtop是一款用于监控opengauss数据库实时容量、性能、运行状态等关键信息的命令行工具。ogtop的主要开发语言为python，通过opengauss原生接口psycopg2连接数据库，从数据库系统表中获取监控数据，经由numpy清洗数据后通过pandas进行实时数据的计算，最后通过urwid进行页面展示。本工具从各个角度提供了详细的opengauss实时运行数据，并且具备常用的数据筛选功
