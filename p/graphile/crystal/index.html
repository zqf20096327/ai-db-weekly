Graphile 旗下 GraphQL 相关包的 monorepo，核心为 Grafast 与 PostGraphile

综述（解读层）

该仓库汇集 Graphile 的多个 GraphQL 相关包，主打两个项目：Grafast 是 GraphQL.js 的计划与执行引擎，可替代其 execute 方法并使用 plan resolvers；PostGraphile 以 PostgreSQL 数据库为数据源自动生成 GraphQL API，可通过 graphile-export 导出后自行维护。仓库还包含 pg-sql2、pg-introspection、graphile-build 等可独立使用的包。适合自行构建 GraphQL schema 或基于 PostgreSQL 生成 API 的 Node.js 开发者。

  • Grafast 提供 GraphQL.js execute 方法的替代实现，使用 plan resolvers 执行业务逻辑
  • PostGraphile 基于 PostgreSQL 数据库自动生成 GraphQL API，并支持通过 graphile-export 导出 schema 源码
  • 包含 pg-sql2（基于标签模板构建 SQL 查询）、pg-introspection（PostgreSQL 强类型内省库）、graphile-build（插件式 schema 构建系统）等多个可独立使用的包

适用场景（解读层）

  • 自行构建 GraphQL schema 并希望使用计划式执行引擎的场景
  • 以 PostgreSQL 数据库为数据源自动生成 GraphQL API 的场景
  • 需要构建 SQL 查询或读取 PostgreSQL 数据库内省信息的场景
