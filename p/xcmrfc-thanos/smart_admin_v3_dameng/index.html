SmartAdmin v3.19.0 的达梦数据库适配版本快速开发平台

综述（解读层）

该项目是 SmartAdmin 快速开发平台的达梦数据库版本，基于拉取的 v3.19.0 代码。技术栈包含 SpringBoot2/3、Sa-Token、MyBatis-Plus、Vue3、Ant Design Vue 和 UniApp，提供 JavaScript/TypeScript 与 Java8/Java17 双版本，采用 MIT 协议。README 中达梦数据库安装部分仅指向官方文档链接，未包含具体安装步骤。

  • 提供 SpringBoot2/3 + Sa-Token + MyBatis-Plus 后端与 Vue3 + Ant Design Vue + UniApp 前端的技术栈组合
  • 提供 JavaScript/TypeScript 双版本与 Java8/Java17 双版本
  • 采用 MIT 协议，包含达梦数据库适配，安装说明引用达梦官方文档

适用场景（解读层）

  • 需要在使用达梦数据库的环境中运行 SmartAdmin 平台的团队
  • 基于 SpringBoot 与 Vue3 搭建管理类应用的开发项目
  • 需要 UniApp 多端前端配合 Java 后端的开发场景
