面向 AI agent 的嵌入式记忆数据库，核心 API 为 experience/activate/checkpoint。

综述（解读层）

FluctlightDB 是一个面向 AI agent 的嵌入式记忆数据库，Rust 内核、Python SDK，每个 agent 对应一个 brain 目录。核心操作为 experience() 写入记忆、activate(cue) 按线索混合召回（FTS5+向量+图）、checkpoint() 持久化重启状态，并支持来源标记使已验证证据优先于聊天内容。可通过 pip 安装，亦可经 Docker 提供 HTTP 服务。README 注明基准数据为维护者自报，尚无独立复现。

  • 提供 experience()/activate()/checkpoint() 等记忆原生操作，checkpoint 支持重启后状态保留
  • activate(cue) 在单次调用中结合 FTS5 全文、向量与图扩展进行混合召回；支持 provenance 标记使 verified 证据优先
  • 提供 connect_embedded/connect_chorus/connect_project 等多种连接模式、MCP 集成与 WebGL brain 可视化查看器

适用场景（解读层）

  • 为长期运行的 AI agent 持久化工具结果、用户事实等记忆并在重启后恢复
  • 按用户改述的问题或任务上下文召回历史记忆（如对话式助手、任务型 agent）
  • 多工具 monorepo 中多个 agent（如 Claude + Codex）共享项目级 brain 与交接信息
