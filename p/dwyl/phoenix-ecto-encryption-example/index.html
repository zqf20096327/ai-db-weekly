基于 Ecto 自定义类型实现数据库字段级加密的 Phoenix 示例教程

综述（解读层）

这是一个面向 Elixir/Phoenix 开发者的分步教程，演示如何在数据写入数据库前使用 Ecto 自定义类型进行字段级加密。项目基于 Erlang crypto 库的 AES-256-GCM 加密和 Argon2 密码哈希，示例包含 user 表的加密字段（name、email）与 email_hash 查找字段，并展示密钥获取与轮换函数的设计。读者需具备 Elixir、Phoenix 和 Ecto 基础知识。作者基于此教程抽出了 fields 库供直接使用。

  • 使用 Erlang crypto 库实现 AES-256 位密钥与 GCM 模式的对称加密
  • 使用 Argon2（argon2_elixir）进行密码哈希，email_hash 采用确定性快速哈希支持免解密查找
  • 示例包含加密、解密、取密钥、哈希邮箱、哈希密码、验证密码共 6 个函数的实现步骤

适用场景（解读层）

  • 学习如何在 Phoenix 应用中通过 Ecto Types 对用户敏感字段（姓名、邮箱）做入库前加密
  • 参考遵循 OWASP 加密与密码存储规则的实现方案
  • 构建需要加密存储与登录验证（密码哈希）的用户数据表设计
