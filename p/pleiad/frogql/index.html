🧭 简介解读层（AI·证据行可回查）

Rust 实现的嵌入式 GQL 图数据库，单文件存储并支持 ISO GQL 路径模式查询。

综述（解读层）

froGQL 是一个以 Rust 编写、实现 ISO/IEC 39075:2024 GQL 查询语言的嵌入式图数据库，数据存于单个 .gdb 文件。它提供 CLI REPL、Python、Node.js、WASM 绑定及 Rust 库，供需要在应用内嵌图存储的开发者使用。项目包含基于渐进类型系统的类型检查器，可在运行前检测因类型不匹配而无结果的查询；README 自述其为研究原型，部分代码由 AI 辅助生成。

  • 实现 ISO/IEC 39075:2024 GQL，含路径模式、逗号连接、{n,m} 重复等特性，并提供 INSERT/SET/REMOVE/DELETE 等数据修改语句
  • 连接执行采用 Leapfrog Triejoin 算法，不可分解模式回退到两两 hash-join；支持哈希与 btree 索引
  • 单 .gdb 文件存储（4KB 页），提供内存、Lazy 与磁盘三种存储后端，并支持基于 HNSW 侧车文件的 NEAREST k 向量近邻查询

适用场景（解读层）

  • 在 Python/Node.js/Rust 应用中嵌入图数据库，以 GQL 语句查询节点与关系
  • 导入 CSV/JSON/LDBC SNB 数据集进行图分析，如图查询实验与基准测试
  • 对含向量属性的节点执行模式匹配与近邻搜索的组合查询
