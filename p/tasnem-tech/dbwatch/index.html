综述（解读层）

DBWatch 是一个命令行数据库审计工具，通过对数据库生成快照并进行快照间比较，检测表结构变更、列更新、行数变化及数据的插入、修改和删除，并生成监控报告。面向数据库管理员、数据工程师、后端开发者和安全分析人员。提供 snapshot、compare、report、monitor 四个 CLI 子命令，通过 schedule 库支持定时监控，使用 Logging 记录活动与错误。README 所列技术栈包含 PostgreSQL、MySQL、SQLite 三种数据库。

  • 提供 snapshot（快照）、compare（比较）、report（报告）、monitor（持续监控）四个 CLI 子命令，通过 python cli.py 直接运行
  • 检测数据库中记录的插入、更新与删除，并维护历史快照
  • 支持 PostgreSQL、MySQL、SQLite，使用 SQLAlchemy 连接数据库、Pandas 处理数据、schedule 实现定时任务

适用场景（解读层）

  • 数据库审计与变更跟踪
  • ETL 验证与数据完整性监控
  • 备份验证与迁移测试
