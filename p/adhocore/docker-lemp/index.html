单容器 LEMP 全栈 Docker 镜像，面向本地开发

综述（解读层）

adhocore/lemp 是一个将 nginx、PHP（8.0–8.3 等多个标签）、MySQL/MariaDB、PostgreSQL、Redis、mailcatcher、adminerevo 等打包进单个容器的 LEMP 全栈镜像，基于 Alpine，支持 amd64/arm64，面向本地开发环境。README 明确标注不可用于生产环境。支持通过 DISABLE 环境变量按 CSV 关闭部分服务，nginx/PHP/adminerevo 为必启组件；MySQL/PostgreSQL 未传密码环境变量时使用默认密码。

  • 单容器包含 nginx、多版本 PHP、MariaDB、PostgreSQL、Redis、memcached、beanstalkd、elasticsearch、mailcatcher、adminerevo 等组件
  • 支持 DISABLE 环境变量以 CSV 形式停用 beanstalkd、mailcatcher、memcached、mysql、pgsql、redis 等服务，nginx/PHP/adminerevo 不可停用
  • 镜像约 350MB，基于 Alpine，提供 amd64/arm64 双架构，PHP 7.4–8.3 各版本对应独立镜像标签

适用场景（解读层）

  • 在本地快速搭建 PHP Web 应用的开发与联调环境
  • 开发多个应用时以不同容器名/端口并行运行多套 LEMP 环境
  • 本地调试邮件发送流程：通过 mailcatcher 在 localhost:8888 实时查看邮件
