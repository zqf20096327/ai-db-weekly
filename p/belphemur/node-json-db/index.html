基于 JSON 文件存储的 Node.js 数据库模块，通过 DataPath 路径读写数据

综述（解读层）

node-json-db 是一个 Node.js 模块，将 JavaScript 对象直接存入 JSON 文件，通过类似 XPath 的 DataPath（如 /test/data1）读取和写入任意层级数据。自 v2.0.0 起所有方法均为异步，需用 Config 对象初始化。内置 AES-256-GCM 加密（密钥须 32 字节）、Date/Map/Set/BigInt 等类型的自动序列化与自定义序列器接口；键名中不能包含分隔符字符。

  • 通过 DataPath 路径访问任意层级数据，支持数组追加、计数、按索引或自定义键查找操作
  • 支持 AES-256-GCM 加密存储（密钥须 32 字节），加密后文件扩展名变为 .enc.json
  • 自动序列化 JSON 原生不支持的类型（Date、Map、Set、RegExp、BigInt），并可通过 ISerializer 接口注册自定义序列化器

适用场景（解读层）

  • 需要以 JSON 文件持久化结构化数据的 Node.js 项目
  • 需要按路径读写嵌套对象或操作数组元素的轻量数据存储场景
  • 需要对本地 JSON 数据文件做加密存储的应用
