MySQL 到 openGauss 的多线程迁移工具，含数据校验

综述（解读层）

mysql-to-opengauss 是一个 Java 编写的 MySQL 到 openGauss 迁移工具，支持表、字段、索引、注释及表数据的迁移，迁移完成后可校验元数据与数据。运行方式为导入测试 SQL、修改 Druid 连接配置文件后执行 Main 类；构建依赖 Maven 3.3.9 与 JDK 1.8，多线程行为通过 dataMigrate.properties 配置。

  • 支持数据库表、字段、索引、注释的迁移
  • 支持表中数据的多线程迁移
  • 迁移完成后可校验元数据与表数据

适用场景（解读层）

  • 将 MySQL 数据库结构和数据迁移到 openGauss
  • 迁移后核对目标库元数据与数据一致性
📖 README 首段存档原文 · 程序抽取

多线程数据库迁移工具，支持数据库表，字段，索引，注释的迁移，支持数据库表中数据的迁移。在迁移完成后，支持对迁移内容的校验，包裹数据库元数据信息和数据库表中的数据。
