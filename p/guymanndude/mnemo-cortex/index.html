🧭 简介解读层（AI·证据行可回查）

面向 AI 代理的本地优先持久记忆层，以 MCP 服务器形式提供语义检索与跨代理共享。

综述（解读层）

Mnemo Cortex 是一个以 MCP 服务器运行的本地记忆系统，为 AI 代理提供跨会话持久存储、语义检索和代理间消息传递。保存时将内容分为两级：经分类的精炼笔记（Tier 1）与原始会话日志（Tier 2），默认召回仅返回前者。提供加密 USB 同步、防篡改账本、结构化事实存储等模块。支持 Claude、ChatGPT（经网关）及本地 MCP 客户端。

  • 以 MCP 服务器与 REST 接口暴露能力，支持 stdio 传输的本地客户端，ChatGPT 通过带鉴权与限流的网关接入
  • 保存时由推理模型将记忆分类为八类精炼笔记，原始日志单独归档且默认不参与召回，模型不可用时回退到正则标记
  • 包含夜间整合、SQLite FTS5 文件索引、代理间消息、AES-256 加密 USB 同步与防篡改记忆账本等模块

适用场景（解读层）

  • 为 Claude Code、Claude Desktop、LM Studio 等本地 MCP 客户端提供跨会话持久记忆
  • 多代理协作场景下通过代理间消息与夜间整合共享上下文
  • 需要本地运行、不依赖云端的记忆存储与语义检索部署
