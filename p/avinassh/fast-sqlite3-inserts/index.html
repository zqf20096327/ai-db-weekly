🧭 简介解读层（AI·证据行可回查）

SQLite 十亿行快速插入测试脚本集，含 Python 与 Rust 基准

综述（解读层）

该仓库包含一组用于测试向 SQLite 数据库快速插入十亿随机行方法的脚本，覆盖 Python（CPython/PyPy）与 Rust 实现，附带 100M 行插入的排行榜与基准数据，并支持 :memory: 内存库测试和 busy loop 基线测量。项目接受社区贡献的 PR，采用 MIT 许可证发布。

  • 提供 Python 与 Rust 多种插入实现脚本，基准规模为 1 亿至 10 亿行
  • 支持 :memory: 内存数据库模式与无 SQL 插入的 busy loop 基线测量
  • 接受社区 PR 优化基准结果，记录各次运行时间

适用场景（解读层）

  • 研究 SQLite 批量写入的优化手法（批量提交、线程等）
  • 对比不同运行时（CPython/PyPy/Rust）执行相同插入任务的耗时
  • 复现或扩展大规模行数据生成基准脚本
