🧭 简介解读层（AI·证据行可回查）

开源自改进上下文框架，通过查询意图账本将重复查询固化为工具

综述（解读层）

Skardi 是一个面向 AI agent 的数据查询框架：agent 通过统一 SQL 入口查询多种数据源，并在 ai_context 中声明查询目的；系统将每次查询写入 SQLite/Postgres 审计账本，重复出现的查询可被提升为命名 pipeline 或例程。项目处于 Beta 阶段，API 可能变动。

  • 提供联邦 SQL 查询能力，通过 ctx.yaml 声明数据源，支持 Postgres、S3 Parquet、MongoDB、Lance 等
  • 以 SQLite/Postgres 账本记录每次查询及其 ai_context（purpose、session_id、task），账本按 (session_id, created_at) 索引
  • 生成的 pipeline 以 YAML 形式落地，可同时以 shell、REST 和 MCP（stdio 与 HTTP 两种传输）方式调用

适用场景（解读层）

  • 为 AI agent 提供跨多数据源的统一查询入口
  • 从查询记录中识别重复模式，将其转化为可复用的 pipeline 或定时例程
  • 通过 auto-context 等技能将文档或数据存储转化为可检索的上下文服务
