🧭 简介解读层（AI·证据行可回查）

SQLite 扩展集合，按领域模块组织并打包为可加载的函数库

综述（解读层）

Sqlean 将多个 SQLite 扩展整理为按领域划分的模块，如 crypto、regexp、stats、uuid、fileio 等，提供统一的 API、文档和测试，并发布 Linux、Windows、macOS 的预编译二进制。用户可通过 .load 命令在 SQLite CLI 中加载，也可从源码构建；要求 64 位 SQLite。

  • 提供 12 个领域模块，包括 crypto、define、fileio、fuzzy、ipaddr、math、regexp、stats、text、time、uuid、vsv
  • 提供单文件 sqlean 集合包，包含全部列出的扩展
  • 提供 Windows、Linux、macOS（x64 与 ARM64）的预编译二进制，并支持从源码构建

适用场景（解读层）

  • 在 SQLite 中使用正则表达式、数学统计、哈希编码、UUID 等内置函数未覆盖的功能
  • 通过 vsv 模块将 CSV 文件作为虚拟表在 SQL 中查询
  • 需要跨 Windows/Linux/macOS 平台加载 SQLite 扩展的 CLI、IDE、Python 或 JavaScript 环境
