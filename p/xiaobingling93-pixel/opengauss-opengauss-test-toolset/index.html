🧭 简介解读层（AI·证据行可回查）

openGauss 外部测试工具集文档仓库，按目录组织各工具说明。

综述（解读层）

该仓库以目录形式汇总 openGauss 相关外部测试工具，每个目录对应一个工具，内容涵盖工具用途、使用说明、测试结果、调优方式、最佳实践与案例。收录 benchmark、sysbench、hybench 三类压测工具，以及 datakit 综合工具和 yat 自动化测试工具。适用于需要查阅这些工具使用方法的 openGauss 用户。新增或更新工具、案例需通过邮件联系 Tools/QA sig 组。

  • 包含五类工具：benchmark（tpcc）、sysbench、hybench 压测工具，datakit 综合工具，yat 自动化测试工具
  • 每个工具目录含用处、使用说明、测试结果、调优方式、最佳实践、案例等内容
  • 提供 Tools sig 与 QA sig 两组联系邮箱用于新增工具或案例

适用场景（解读层）

  • 查阅 openGauss 压测工具（tpcc/sysbench/hybench）的使用与调优方法
  • 了解 datakit 在安装、部署、迁移、运维等方面的工具说明
  • 查找 openGauss 自动化测试工具 yat 的使用说明与案例
