把数据库表转换为 Go struct 的命令行代码生成工具

综述（解读层）

yggdrasill 是一个 Go 命令行工具，读取 PostgreSQL 或 MySQL 数据库中的表结构，生成对应的 Go struct 代码。通过 DSN 连接数据库，默认生成全部表，也可用 -table_names 指定表，支持 -template_path 自定义生成模板、-dir 指定输出目录。适用于需要在 Go 项目中基于现有表结构生成模型代码的开发场景。

  • 支持 PostgreSQL 和 MySQL，通过 DSN 连接并读取表结构
  • 默认生成数据库内所有表，可用 -table_names 指定单个或多个表
  • 支持通过 -template_path 使用自定义模板，可用 -dir 指定生成文件目录

适用场景（解读层）

  • 为现有 MySQL/PostgreSQL 数据库表批量生成 Go struct 模型代码
  • 只针对指定的若干张表生成模型文件
  • 基于自定义模板生成符合项目代码规范的模型代码
🔌 适配哪些库db_scan 程序判定

MySQL、PostgreSQL
