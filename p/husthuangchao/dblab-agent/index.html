通过真实执行 SQL 验证答案的数据库兼容性问答 LLM agent

综述（解读层）

dblab-agent 是一个连接 PostgreSQL、MySQL、openGauss 的数据库问答 agent，要求模型在回答兼容性问题前先对真实连接执行最小验证 SQL，并在界面展示每条查询及返回结果。技术栈为 Python/FastAPI，LLM 走 OpenAI 兼容接口（默认 DeepSeek），支持 Docker 一键启动演示环境，密钥使用 Fernet 加密存储。

  • 内置 agent 循环与 6 个纯函数工具（list_connections、exec_sql、exec_sql_batch 等），工具内不含 LLM 调用
  • Docker 启动时附带 MySQL 8、PostgreSQL 17、openGauss 3.0 三个演示库并自动灌入数据
  • 支持通过 UI 或环境变量接入自定义数据库连接，并可在聊天中上传截图交给视觉模型识别

适用场景（解读层）

  • 验证某函数、语法、数据类型在特定数据库版本上的实际行为
  • 对比同一表达式或语句在 PostgreSQL、MySQL、openGauss 之间的差异
  • 在聊天中粘贴 SQL 报错截图或 schema 图，让视觉模型读取后继续排查
