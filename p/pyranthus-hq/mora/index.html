🧭 简介解读层（AI·证据行可回查）

本地优先的记忆 CLI，将消息、邮件、日历与文件汇编为带引用的本地知识库供 MCP 智能体读取。

综述（解读层）

Mora 是一款运行于 macOS 的 Go 语言 CLI 工具（现处 beta 阶段），以只读方式接入 iMessage、Gmail、日历和本地文件，将内容存入 Markdown 仓库与 SQLite 索引，通过 MCP 协议向 Claude Code、Codex 等客户端提供检索、摘要与会话交接功能。写入需经 `mora review` 由所有者确认，全部数据存储于本地。

  • 提供只读 iMessage、Gmail、日历与文件连接器，数据存入本地 Markdown 仓库与 SQLite 索引
  • 实现 MCP 服务器，暴露 brief、search_memory、meeting_prep 等 13 个工具，并通过会话钩子注入项目简报与范围检索
  • 所有者写入需在真实终端确认（--mine），智能体写入的笔记进入待审队列，支持 mora given 查看每次交付记录

适用场景（解读层）

  • 为编码智能体跨会话保存项目决策、修正与会话交接（handoff）
  • 无云端邮箱环境下本地检索 iMessage 与 Gmail，结合日历生成会前简报
  • 通过人员图谱检索与某人相关的消息和会议证据
