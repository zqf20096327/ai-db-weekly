基于 SQLite/PostgreSQL 的 TypeScript 内嵌知识图谱库，用 Zod 定义节点与边

综述（解读层）

TypeGraph 是一个 TypeScript 优先的内嵌式属性图库，直接在既有 SQLite 或 PostgreSQL 数据库上实现知识图谱，无需独立图服务。开发者用 Zod 定义节点和边，通过流式 TypeScript API 进行类型安全遍历查询，支持本体建模（subClassOf、inverseOf 等）、混合向量与全文检索、双时态历史查询，并可在运行时由 JSON 演进 schema。适用于构建 RAG 上下文、可审计的 Agent 记忆等关系密集型应用；不面向分布式图处理或超大规模图计算。

  • 用 Zod 定义节点与边，支持 subClassOf、implies、inverseOf、disjointWith 等本体语义，遍历查询具备编译期类型安全
  • 在 SQLite 与 PostgreSQL 上运行向量与混合搜索（pgvector、sqlite-vec、libSQL/Turso 原生向量），图定义可跨后端迁移
  • 提供双时态读取重建有效时间与记录时间历史，支持固定与递归遍历阶段的组合及运行时 schema 演进

适用场景（解读层）

  • 知识图谱构建与 RAG 上下文建模
  • 可审计的 Agent 记忆、决策回放与双时态取证分析
  • 身份/权限等关系密集型领域模型，且不希望引入额外图基础设施
