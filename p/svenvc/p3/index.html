面向 Pharo 的轻量 PostgreSQL 客户端，实现协议 3.0 查询循环

综述（解读层）

P3 是运行在 Pharo Smalltalk 中的 PostgreSQL 客户端，通过 TCP 使用前端/后端协议 3.0 与服务器通信，实现简单与扩展查询周期。其公共接口以 #query:/#execute: 为主，支持 URL 配置、SSL 连接及三种口令认证；提供 prepared 与 formatted 两类语句，查询结果转换为 Pharo 对象。当前实现 41 种通用类型中的 32 种，未覆盖 inet、xml 等类型，GSS/SSPI 认证暂不支持。

  • 实现 PostgreSQL 协议 3.0 的简单与扩展查询周期，支持 plaintext、md5 和 scram-sha-256 认证，可通过 #connectSSL 或 URL 参数 sslmode=require 使用 SSL/TLS 连接
  • 提供 #prepare:（服务端预编译）与 #format:（客户端文本替换）两种带 $n 占位符的语句机制，执行时自动进行参数转换
  • 实现 PostgreSQL 41 种通用数据类型中的 32 种及 oid、数组等 10 种常见类型，并可通过 #loadEnums 加载枚举类型映射

适用场景（解读层）

  • 在 Pharo Smalltalk 环境中直接通过 SQL 查询和操作 PostgreSQL 数据库
  • 需要带参数的语句执行，避免手工拼接 SQL 参数的场景
  • 读取包含数值、时间、几何、JSON 等类型的数据并映射为 Pharo 对象
