Raku 语言的 SQLite 数据库绑定库，提供连接、语句与结果三层 API

综述（解读层）

DB::SQLite 是 Raku 语言访问 SQLite 数据库的绑定实现。主对象作为连接工厂并维护连接缓存，支持通过 .db 获取连接、.prepare 预编译语句并缓存复用。支持多种占位符形式、事务的 begin/commit/rollback 控制、多个扩展打开标志（如 readonly、wal），查询结果以 value/array/hash/arrays/hashes 形式返回，数据库错误以异常抛出。适合需要在 Raku 程序中读写 SQLite 数据库的开发者。

  • 支持位置与命名占位符绑定，未绑定的占位符取 NULL，语句默认缓存并可通过 :nocache 关闭
  • 提供 .begin/.commit/.rollback 事务方法，commit 前调用 .finish 会自动回滚未提交事务
  • 支持多种连接选项：filename、busy-timeout、:memory: 内存数据库及 readonly、wal 等扩展打开标志

适用场景（解读层）

  • 在 Raku 程序中创建、查询和写入 SQLite 数据库
  • 使用事务批量执行大量插入、更新或删除操作
  • 以只读方式打开数据库文件，或使用内存数据库进行临时数据处理
