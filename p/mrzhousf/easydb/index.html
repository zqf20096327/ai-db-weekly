基于ORMLite封装的Android SQLite数据库操作工具类库

综述（解读层）

EasyDB是一个基于ORMLite封装的Android数据库操作类库，底层运行于SQLite。它通过@TableModel注解实现多个Module中表模型分散存放、由框架自动注册统一管理，并提供增删改查、事务、批处理、异步操作等API。集成需在Application中初始化DBHelper并编写表模型，通过Maven或Gradle引用。

  • 支持多Module表模型分散、表管理统一，通过@TableModel注解自动注册各module的表
  • 支持自定义数据库路径（SD卡或系统）、事务、批处理、异步任务与数据库升级
  • 支持分页查询及like、between、equal等条件查询，并提供生成字段别名的Android Studio插件

适用场景（解读层）

  • Android应用中基于SQLite的表模型增删改查与事务、批处理操作
  • Android Studio多模块项目中需要将表模型分散在各module并统一管理表的场景
  • 需要自定义数据库存储路径（如SD卡）或执行数据库升级的Android项目
📖 README 首段存档原文 · 程序抽取

基于ORMLite封装的数据库操作工具类——致力于最简洁的数据库操作API。 由于目前流行的数据框架（如Realm、GreenDAO、ObjectBox）在做项目模块架构时都无法使得表模型分散，表管理统一的架构设计， 所以本框架还是从SQLite出发，综合考量Android Studio应用架构设计思想通过技术封装以实现该目标。
