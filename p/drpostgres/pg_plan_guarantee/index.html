Postgres 扩展，固化查询执行计划，计划不符时报错

综述（解读层）

pg_plan_guarantee 是一个 Postgres 扩展，通过 SQL 命令生成并固化查询执行计划：先对指定查询生成 guaranteed-plan，再提交该计划供执行；当计划器无法按给定计划执行时抛出错误而非自行选择计划。需放入 Postgres extensions 目录并配置 shared_preload_libraries，可通过 pg_plan_guarantee.enabled=false 禁用。适用于已调优查询、希望计划不随数据或统计信息变化而改变的用户。

  • 通过两步 SQL 命令生成和使用 guaranteed-plan
  • 指定计划无法执行时抛出错误而非回退到计划器选择
  • 支持通过 pg_plan_guarantee.enabled 参数在不移除文件的情况下禁用

适用场景（解读层）

  • 查询已调优、希望执行计划不受数据或统计信息变化影响的场景
  • 生产环境中需要固定关键查询执行路径的场景
