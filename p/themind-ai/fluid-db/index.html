TypeScript 对话记忆库：将消息转为可检索证据并生成提示片段

综述（解读层）

FluidDB 是一个 TypeScript 会话记忆库，把原始消息处理为可搜索窗口、陈述与档案，每轮对话可检索相关证据。面向为 AI 助手构建持久记忆的产品开发者。通过单一 npm 包提供 SDK、SQLite/PostgreSQL/Firestore 适配器、MCP 接口与 CLI；模型、嵌入器与存储均为可替换接口。项目自述 retelling 检测在实验中误报较多，且合成评估不衡量模型质量。

  • 每轮对话检索相关证据并可检测重复事实，输出类型化数据与提示片段
  • 支持 SQLite（Node/Bun）、PostgreSQL、Firestore（Node/REST）存储适配器，及 MCP、CLI、评估器等组件
  • 提供带修订检查的源删除（forget/erase）机制，含 tombstone 防止延迟投递恢复已删内容

适用场景（解读层）

  • 为 AI 助手/Agent 产品添加按人绑定的会话记忆
  • 在 Cloudflare Workers 等环境部署记忆服务（Durable Object 存储）
  • 使用 MCP 协议为代理工具提供记忆与反馈接口
