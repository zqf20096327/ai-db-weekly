专为 PostgreSQL 设计的 Node.js 数据库迁移管理工具

综述（解读层）

node-pg-migrate 是一个仅面向 PostgreSQL（另经 CockroachDB 测试）的 Node.js 迁移工具。开发者通过 CLI 创建迁移文件，以 pgm API 编写 up 操作，工具据此生成 SQL；基于操作栈可自动推断部分 down 迁移。需 Node.js 22.12+、PostgreSQL 14+，并通过 DATABASE_URL 连接数据库运行迁移。

  • 提供 CLI（node-pg-migrate）用于创建和执行迁移文件，通过 DATABASE_URL 环境变量配置数据库连接
  • 以 pgm API 编写操作（如 createTable、addColumns、alterColumn），由工具生成 SQL，并可自动推断部分 down 迁移
  • 允许直接传入原始 SQL（pgm.sql），值直接传递到 SQL 语句中

适用场景（解读层）

  • 使用 PostgreSQL 的 Node.js 项目需要以代码文件形式管理数据库表结构的创建与变更
  • 迁移脚本需在 CI 或生产环境中通过命令行执行（依赖注入 devDependencies 或 dependencies 的场景均有说明）
  • 需要对已有数据的表做加列等结构变更，并按文档分步填充与设置约束
