基于逻辑复制/binlog/oplog的PostgreSQL、MySQL、MongoDB变更流式工具

综述（解读层）

Lapidus 是一个数据库变更数据捕获（CDC）流式工具，读取 PostgreSQL 逻辑复制槽（需 JSONCDC 插件）、MySQL binlog 和 MongoDB 副本集 oplog，将增删改事件以 schema.table.pk 主题发布，可经内置 NATS 插件向外推送。它可作为守护进程或 Node.js 模块运行，通过 lapidus.json 配置多后端。限制：MongoDB 更新事件返回操作副本而非最终对象，Redis 支持尚未完成。

  • 支持 PostgreSQL 9.4+（JSONCDC 逻辑解码插件）、MySQL 5.1.15+（binlog row 格式）和 MongoDB 副本集三类数据源
  • 可作为守护进程或 Node.js 模块运行，配置文件为 lapidus.json
  • 内置 NATS 插件，按 schema.table.pk 主题发布 Insert/Update/Delete 事件

适用场景（解读层）

  • 将数据库变更事件流式发布到 NATS 等消息系统供下游订阅
  • 以 Node.js 模块形式在应用内嵌入 CDC 能力
  • 连接多个异构数据库后端并统一输出变更事件
