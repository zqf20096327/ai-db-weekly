DeepSeek Harness 的跨会话记忆插件：审批门控写入本地 SQLite，注入冻结快照

综述（解读层）

dsh-memento 为 DeepSeek Harness 提供 ctx.memory 能力接缝，包含类型安全服务、零依赖 SQLite 提供方、memory 工具与注入 systemPrompt 的冻结快照。写入经服务内部审批门（writePolicy ask/auto/off），审计由 approval 事件对与插件审计表构成。面向 DSH 社区用户；另提供只读 stdio MCP 服务器供外部客户端检索。检索默认为大小写不敏感子串匹配，向量召回为可选项。

  • 两条轨道（user/agent）×两个层级（user-global/workspace）×按 agentPreset 隔离，每轨每层硬字符预算（默认 user 2000 / agent 4000），写满返回结构化错误而非截断
  • 所有写路径（add/replace/remove/seed）经服务内部审批 waterfall，replace/remove/consolidate 审批载荷携带将被改动的条目全文，被拒写入落 *-denied 审计行
  • 附带只读 stdio MCP 服务器（dsh-memento-mcp），以 node:sqlite readOnly 模式打开数据库，支持 memory_search 与 memory_stats 工具

适用场景（解读层）

  • 需要模型跨会话记住用户事实与环境约定，且每次写入需人工审批与可重建审计的 DSH 会话
  • 外部 MCP 客户端（如 Claude、Codex）需免 harness 只读检索同一记忆库的场景
  • 通过内置适配器从 mem0 fact collections、Hermes memory.md 或 CLAUDE.md 风格 markdown 导入既有记忆
