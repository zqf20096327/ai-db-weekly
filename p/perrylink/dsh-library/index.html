DeepSeek Harness 本地文档知识库插件，混合检索带 [n] 引用标记

综述（解读层）

dsh-library 是面向 DeepSeek Harness 的社区插件，把本地 md/txt 文档按路径导入、滑窗切片并写入宿主的 dsh_library 存储域（JSON 或 SQLite 后端）。它提供 library_add/remove/list/search、library_cite_check、library_diagnose 与 /library 命令，检索采用 BM25+语义融合、MMR 多样性重排、相关性过滤与中段规避。默认嵌入为确定性哈希，零模型下载、零网络请求；仅支持 md/txt，PDF/docx 不在范围内。

  • library_search 支持 BM25 与语义倒数排名融合（rrf）、MMR 多样性重排、相关性阈值过滤，命中结果带 [n] 来源标记，inject: true 时注入调用 agent
  • 内置确定性哈希嵌入（零下载、零网络请求），可选 ollama、openai 兼容端点或外部子进程作为嵌入后端
  • library_remove 用被删内容签名探测剩余索引报告残留；library_cite_check 用模糊词面匹配加语义相似度双重校验 [n] 引用

适用场景（解读层）

  • 为 agent 提供本地 md/txt 文档的检索问答，回答需带 [n] 引用并可逐条核验
  • 无网络、无模型下载环境下运行本地知识库检索
  • 审计文档删除后索引残留，以及诊断切片分布、重复切片与检索信号
