🧭 简介解读层（AI·证据行可回查）

面向 DeepSeek Harness 的本地文档知识库插件，提供混合检索与引用核验

综述（解读层）

dsh-library 是一个 DeepSeek Harness 社区插件，将本地 md/txt 文档按路径导入、滑窗切片并写入宿主 dsh_library 存储域（JSON 或 SQLite），供 agent 查询。检索管线包含 BM25 与语义融合打分、MMR 多样性重排、相关性过滤及首尾钉位；引用可经 library_cite_check 逐条核验。默认使用内置确定性哈希嵌入，零模型下载、零网络请求；已知限制为词法级语义与仅支持 md/txt 导入。适合需要在本地离线环境为 agent 构建可核验文档库的开发者。

  • 提供 library_add/remove/list、library_search、library_cite_check、library_diagnose 及 /library 命令
  • library_search 实现 BM25 + 语义倒数排名融合、MMR 重排、相关性过滤与中段规避，命中带 [n] 来源标记，支持 inject 注入
  • 默认内置确定性哈希嵌入（零下载、零网络请求），可配置为 ollama、OpenAI 兼容端点或外部子进程嵌入；索引存于宿主存储域（JSON 或 SQLite）

适用场景（解读层）

  • 为 DeepSeek Harness agent 导入本地 md/txt 文档并进行带 [n] 引用标记的检索问答
  • 对 agent 答案中的 [n] 引用做模糊词面 + 语义相似度的逐条核验
  • 在无网络、无模型下载的环境下运行本地文档知识库，或按需接入本地 Ollama 嵌入
