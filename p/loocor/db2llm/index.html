基于 SQLite 元数据与 RESTful API 连接大语言模型的自然语言查库原型

综述（解读层）

DB2LLM 是一个概念验证原型：读取用户上传的 SQLite 数据库文件，提取表结构、主外键、索引及字段枚举值映射等元数据，动态生成 RESTful API，并将自然语言查询转换为 API 请求执行。基于 Bun、Hono 与 TypeORM 实现，支持 DeepSeek、OpenAI、Claude 等 OpenAI 兼容接口，适合想体验自然语言操作数据库的开发者本地试用。项目未实现用户认证，API 密钥在前端直接输入，会话数据存于内存，README 明确不建议用于生产环境。

  • 自动分析 SQLite 数据库结构，提取表/字段、主外键、索引信息与字段枚举值映射
  • 动态生成数据库操作的 RESTful API，并将自然语言查询转换为 API 请求执行，支持多步复杂查询与会话上下文追问（会话 30 分钟超时自动清理）
  • 通过 config.yaml 或前端界面配置 LLM API 地址与密钥，支持 DeepSeek、OpenAI、Azure OpenAI、Claude 等 OpenAI 兼容接口

适用场景（解读层）

  • 本地试用自然语言方式查询和操作 SQLite 数据库
  • 对已有 SQLite 数据进行增删改查而无需手写 SQL 的演示场景
  • 作为元数据提取 + LLM + API 生成的概念验证参考实现
