扩展官方 oracledb 驱动的 Node.js 库，为连接、连接池提供简化 API

综述（解读层）

simple-oracledb 是一个 Node.js 库，用于扩展 Oracle 官方 node.js 驱动 oracledb 的主对象、连接池和连接实例。它提供 query、insert、update、queryJSON 等简化方法，支持 getConnection 失败重试、连接自动释放、并行查询及 LOB 流式读写。适用于使用 oracledb 驱动进行 Oracle 数据库开发的场景。限制包括：query 会读取全部行和 LOB，不适合超大结果集或超大 LOB 值。

  • 可在 oracledb 主对象、连接池或连接实例三个层面进行扩展，支持池在代码外部创建的场景
  • pool.getConnection 支持可配置次数与间隔的重试，并通过测试 SQL 验证连接有效性，失效时重新获取
  • 提供 run/pool.run 方法，自动获取并释放连接；connection.query 返回对象数组并读取所有 LOB，insert/update 通过流写入 LOB

适用场景（解读层）

  • Node.js 应用中简化 Oracle 数据库的查询、插入、更新操作开发
  • 连接池获取连接易失败的环境，需要自动重试与连接验证
  • 需要在 SQL 中不写 RETURNING 子句即可写入 CLOB/BLOB 数据的场景
