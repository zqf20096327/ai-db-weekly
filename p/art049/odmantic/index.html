基于 Python 类型提示与 Pydantic 的 MongoDB 同步/异步 ODM。

综述（解读层）

ODMantic 是一个面向 MongoDB 的对象文档映射器，基于 Python 类型提示定义模型，模型定义与校验构建在 Pydantic 之上。数据库操作通过 engine 对象执行，支持 AIOEngine 异步引擎，可配合 FastAPI 等 ASGI 框架使用，也可在同步环境运行。要求 Python 3.8+、Pydantic 2.5+、MongoDB 4.0+，通过 pip install odmantic 安装。

  • 使用 Python 类型注解定义模型，查询通过 Python 比较运算符构建
  • 提供内置 JSON 序列化与 JSON Schema 生成，字段校验基于 Pydantic
  • AIOEngine 支持 AsyncIO，同时兼容同步运行环境

适用场景（解读层）

  • 需要类型化模型与数据校验的 MongoDB 应用开发
  • FastAPI/Quart/Sanic/Starlette 等 ASGI 框架下的异步数据访问
  • 已有 Pydantic、FastAPI 经验的团队接入 MongoDB
