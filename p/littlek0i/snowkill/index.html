面向 Snowflake 的近实时查询监控工具，检测并可选终止异常查询

综述（解读层）

SnowKill 监控 Snowflake 中正在运行、排队和被阻塞的查询，分析查询统计与执行计划、检测不良模式，并可自动终止匹配的查询。其核心逻辑基于内部 REST API 调用而非 SQL 查询，无需活跃仓库即可运行；通过程序化访问 Query Profile 页面的查询计划及锁信息，报告事务冲突原因。适用于需要近实时查询监控的 Snowflake 使用者。

  • 通过内部 REST API 获取当前 RUNNING/QUEUED/BLOCKED 状态的查询，无需活跃仓库即可运行
  • 提供可自定义的检测条件与内置条件（Join Explosion、Storage Spilling、Queued Duration 等），可按阈值自动终止匹配查询
  • 支持通过 Slack、Email 等发送通知，内置 Markdown/Slack 格式化器及 Postgres、Snowflake 表等存储后端

适用场景（解读层）

  • 对当前运行、排队或被阻塞的查询进行近实时监控并接收通知
  • 自动终止超过指定阈值的异常查询
  • 报告查询事务锁冲突的具体原因
