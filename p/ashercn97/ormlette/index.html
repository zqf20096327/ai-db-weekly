Gleam 语言的 ORM，提供 schema 与查询 DSL 及代码生成 CLI。

综述（解读层）

Ormlette 是面向 Gleam 的对象关系映射库，用于定义数据库 schema、构建查询并生成配套代码。其查询 DSL 基于 gleam-cake 实现，可通过 q.export 导出为 cake 查询直接使用；CLI 借助 Glerd 生成反射值、通用解码器、decoder 类型和 usage 类型。Changesets 功能尚在开发中，作者自述其 API 尚不理想，文档也未完善，项目处于早期阶段。

  • 提供 schema DSL 定义表、列及表间关系，支持 select、insert、update、delete 查询构建
  • 提供通用解码器（universal decoders），同一解码器可用于列顺序不同的多条 select 查询，并自动生成 join 类型及对应解码器
  • CLI 可自动生成类型、解码器和 record-to-dict 函数；changesets 支持自定义错误类型和内置校验库

适用场景（解读层）

  • 在 Gleam/BEAM 项目中对数据库进行 schema 定义与 CRUD 查询
  • 需要将查询结果动态解码为类型化记录，或解码多表 join 结果的场景
  • 参照 Ecto 模式在写入前对数据做校验与转换（功能仍在开发中）
