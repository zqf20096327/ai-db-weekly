将公开 Telegram 频道同步为自包含 Zola 静态网站的工具

综述（解读层）

tg2zola 是用 Rust 编写的单二进制工具，抓取公开 Telegram 频道网页预览（无需 bot、token 或 API），下载媒体到本地并生成完整 Zola 博客，支持每日定时或按需通过 GitHub Actions 重建并部署到 GitHub Pages。可选 MTProto 后端补充音频与讨论区内容；输出不含 Telegram 依赖，频道删除后站点仍可运行。

  • 读取 t.me/s 公开页面抓取全历史消息，下载照片、视频、音频、文档等媒体并以 Telegram 文件 id 做内容寻址缓存
  • 将格式化文本、话题标签、投票、浏览量、评论线程等转换为 Markdown 与 Zola 页面，生成 RSS、播客 feed、Open Graph 标签，支持 13 种界面语言
  • 提供离线 file:// 导出、键盘 j/k 导航，附带 daily.yml 与 release.yml 两个 GitHub Actions 工作流

适用场景（解读层）

  • 备份公开 Telegram 频道内容为可独立访问的静态站点
  • 将频道作为博客或播客发布，生成可订阅的 RSS/播客 feed
  • 本地离线保存单页 HTML 或在 CI 中定时同步
