基于 node:sqlite 的 Node.js SQLite 客户端库，提供单连接与连接池两种实现

综述（解读层）

该库基于 Node.js 内置 node:sqlite 模块封装，无需原生插件，用于在 Node.js 中查询 SQLite 数据库。它导出 createSyncConnection（同步单连接）和 createConnectionPool（异步连接池）两个实现，查询通过 @databases/sql 构建，支持事务回调和流式结果。要求 Node.js 22.13.0 及以上；由于 SQLite 同时仅支持一个写事务，事务使用受限。

  • 提供同步单连接与基于 @databases/connection-pool 的异步连接池两种客户端实现
  • 查询接口包含 query（返回结果数组）与 queryStream（返回可迭代流式结果），并支持 tx 回调事务，出错自动执行 ROLLBACK
  • 复用 Node 内置 node:sqlite 模块，不需要原生 addons；查询可用 @databases/sql 构建，可配置 readBigInts、maxSize、releaseTimeoutMilliseconds 等选项

适用场景（解读层）

  • 在 Node.js 22.13+ 应用中读写 SQLite 数据库文件或内存数据库
  • 需要对大量查询结果进行流式逐行处理的场景
  • 需要将多步读写封装在 BEGIN/COMMIT/ROLLBACK 事务回调中的场景
