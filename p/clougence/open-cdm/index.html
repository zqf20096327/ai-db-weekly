CloudDM：Web 控制台的团队数据库管理工具，含权限、工单与 SQL 变更流程

综述（解读层）

CloudDM 是开源的团队数据库管理工具，通过单一 Web 控制台提供数据查询、访问管理与经审核的数据库变更。支持 RBAC 权限（可细到表级）、LDAP/OIDC 认证集成、SQL 工单审批、数据库 CI/CD（可对接 Git 仓库触发发布），支持 44 种数据源，提供单机与集群部署，Docker 启动后经 8222 端口初始化。适用于需要 SQL 审核流程与权限管控的团队。

  • 支持 44 种数据源类型，提供 RBAC、SQL 执行前规则检查与数据脱敏
  • 提供工单审批流程（内置审批引擎，可对接钉钉/飞书/企业微信）与数据库 CI/CD（Git push、webhook、HTTP API 触发发布）
  • 支持 Standalone 与 Cluster（Console + Sidecar）两种部署模式，可运行于安装包、Docker、Kubernetes

适用场景（解读层）

  • 需要按实例/库/schema/表级分配权限并管理临时授权的团队数据访问管理
  • 通过工单审批执行 SQL 变更并支持定时或手动执行
  • 以 Git 仓库为变更源、通过 webhook/API 触发的数据库 CI/CD 流水线
