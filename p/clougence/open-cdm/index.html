综述（解读层）

CloudDM 是一个面向团队的开源数据库管理工具，通过统一 Web 控制台查询和管理多种数据源（MySQL、Oracle、PostgreSQL、MongoDB、Redis 等）。权限模型将资源与功能分离，支持实例/库/表级授权与临时权限；内置 54 条 SQL 审计规则并可自定义扩展。支持单机与集群部署，可通过 Docker 或 Kubernetes 运行。

  • 支持 MySQL、Oracle、PostgreSQL、DB2、MongoDB、Redis 等多种数据源，提供查询编辑器、语法高亮与执行计划查看
  • 权限模型区分资源与功能授权，支持实例/库/schema/表级权限、权限申请与临时权限
  • SQL 审计内置 54 条规则，支持规则脚本扩展与执行前预检，可拦截或告警风险语句

适用场景（解读层）

  • 团队统一的数据库查询与管理入口
  • 需要 SQL 审核与数据脱敏的变更流程
  • 通过 Git 推送或 Web Hook 触发的数据库变更流水线
