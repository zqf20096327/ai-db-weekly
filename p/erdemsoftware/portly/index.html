面向 Windows 的便携式本地 Web 开发环境，单文件夹运行多种服务栈

综述（解读层）

Portly 是一个开源（MIT）的 Windows 本地 Web 开发环境，从单个文件夹运行 Apache/Nginx、PHP、MySQL/MariaDB、PostgreSQL、MongoDB、Redis、Node.js 等组件，无需安装器，默认不写入 Windows 服务或注册表，可从 U 盘运行。`www` 下的每个文件夹自动映射为 `https://name.portly` 站点，支持每站点独立 PHP 版本、局域网/Cloudflare 分享，以及从 Laragon、XAMPP 等环境迁移项目和数据库。另有支持 Windows 7/8 的 Legacy 版本和处于 beta 阶段的 macOS/Linux 版本（Portly 2）。

  • 便携运行：单文件夹包含全部组件，无安装器，默认不注册 Windows 服务、不写注册表，可从 U 盘运行
  • 每站点独立 PHP 版本（各自 FastCGI 端口），一键安装 PHP 扩展与 Xdebug，终端跟随项目的 PHP/Node 版本配置
  • 项目分享支持局域网 QR 码（https、密码、时限）与 Cloudflare 隧道（免账户随机地址或自有域名固定地址）

适用场景（解读层）

  • 在 Windows 上本地运行 PHP/Node Web 项目（如 Laravel、WordPress），每个项目可配置不同 PHP 版本
  • 将本地项目通过二维码在手机或局域网设备上以 https 预览，或经 Cloudflare 隧道临时对外分享
  • 从 Laragon、XAMPP、WampServer 等环境迁移现有项目与数据库到新的本地开发环境
