受 Laravel Eloquent 启发的 Go 语言迷你数据库 ORM，提供链式查询构建。

综述（解读层）

GoRose 是一个 Go 语言的 ORM 库，自称参照 Laravel query builder 文档实现查询接口，提供 go 风格（struct 绑定）与 php 风格（map）两种用法。支持 mysql、sqlite3、postgres、oracle、mssql、clickhouse 驱动，包含读写分离集群配置、自动事务、子查询、结果绑定等功能。当前处于 beta 阶段，仅可通过 go mod 引入 master 分支。

  • 支持 mysql、sqlite3、postgres、oracle、mssql、clickhouse 六种数据库驱动，可通过实现 IDialect/IDriver 接口扩展其他数据库
  • 提供链式查询 API，README 列出已支持的 Laravel query builder 方法（Where、Join、Union、Paginate 等）及 To、Bind、LastSql 等额外 API
  • 支持读写分离集群配置、事务内强制读写库、全自动事务（出错回滚）、struct/map 两种用法及 null 值绑定

适用场景（解读层）

  • Go 项目中需要以链式调用方式构建 SQL 查询的场景
  • 熟悉 Laravel Eloquent 或 php/python/ruby 开发者迁移到 Go 后使用相近的 ORM 写法
  • 需要配置读写分离集群或使用自动事务管理写入操作的场景
📖 README 首段存档原文 · 程序抽取

PHP Laravel ORM 的 go 实现, 与 laravel 官方文档保持一致 https://laravel.com/docs/10.x/queries . 分为 go 风格 (struct 结构绑定用法) 和 php 风格 (map 结构用法). php 风格用法, 完全可以使用 laravel query builder 的文档做参考, 尽量做到 1:1 还原.
