🧭 简介解读层（AI·证据行可回查）

基于 Rust + Postgres/pgvector 的 MCP 服务，为 AI 编码代理提供字段级代码图与会话持久记忆

综述（解读层）

RemembrallMCP 是一个通过 MCP 协议向 Claude Code、Cursor、Codex 等 AI 编码客户端提供代码知识与持久记忆的服务。它用 tree-sitter 构建覆盖 9 种语言的代码图，包含函数、类、方法、字段及其调用/导入/继承/字段引用关系，存入 Postgres + pgvector；另提供记忆的存取与混合检索（语义+全文、RRF 融合）。共 9 个工具，安装支持 Docker Compose、预编译二进制或源码构建（Rust 1.94+），GitHub 摄取依赖已认证的 gh CLI。

  • remembrall_index 将项目解析为字段感知代码图，remembrall_impact 可分析函数、类、方法、字段级变更的影响范围
  • remembrall_store/recall 支持带向量嵌入的记忆存储与语义+全文混合检索，并可从 GitHub PR 历史或 markdown 文档批量摄取
  • 支持 Python、Java、JavaScript、Rust、Go、Ruby、TypeScript、Kotlin、C# 九种语言，README 附有各语言基于真实开源项目的质量评分

适用场景（解读层）

  • 在 AI 代理修改函数或字段前查询引用与影响范围
  • 跨会话保存并检索架构决策、代码模式等项目知识
  • 从已有仓库的 PR 描述或 markdown 文档（ADR、架构说明）冷启动构建项目记忆
