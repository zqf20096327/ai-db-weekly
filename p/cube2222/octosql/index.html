基于 Go 的 CLI 工具，用 SQL 统一查询和联接多种数据库与文件格式

综述（解读层）

OctoSQL 是一个 CLI 工具，用 SQL 查询多种数据库和文件格式，并支持跨数据源 JOIN，例如将 JSON 文件与 PostgreSQL 表联接。它内置 JSON、CSV、TSV、Parquet 等文件支持，数据库（如 MySQL、PostgreSQL、Redis）通过插件安装，插件管理也通过 SQL 接口完成。内核是数据流引擎，支持基于 retractions 的流式更新查询，需 Go 1.18 以上可从源码构建。

  • 通过统一 SQL 接口查询文件（JSONLines、CSV、TSV、Parquet、Lines）和数据库，支持跨数据源 JOIN
  • 数据库支持以插件形式安装（如 postgres、mysql），插件浏览与安装通过内置 SQL 表完成
  • 静态类型系统支持联合类型、类型断言（value::type）与 COALESCE 等转换函数

适用场景（解读层）

  • 在命令行中对 JSON/CSV/Parquet 等本地文件运行 SQL 查询
  • 跨不同数据源（如 JSON 文件与 PostgreSQL 表）进行 JOIN 和数据分析
  • 为自有应用嵌入 SQL 查询接口（作为可扩展的数据流引擎）
