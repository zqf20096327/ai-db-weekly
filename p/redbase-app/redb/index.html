面向 .NET 的类型化对象存储，模式即 C# 类，基于 LINQ 查询

综述（解读层）

RedBase 是一个 .NET 数据平台，将强类型对象存入 PostgreSQL、SQL Server 或 SQLite 后端。开发者以普通 C# 类定义模式，通过单一 LINQ 风格 API 完成存储、索引、查询、树结构、聚合与窗口函数，无需迁移文件；属性以带类型的真实列存储而非 JSON。提供免费版与 Pro 版包及 CLI、项目模板，采用 Apache 2.0 许可证。

  • 支持 PostgreSQL、SQL Server 与 SQLite 三种后端，SQLite 可用于嵌入式、离线、Blazor WebAssembly 与移动场景
  • 属性存储为按类型映射的真实数据库列并建立索引，树查询、聚合和窗口函数通过 LINQ API 提供
  • 提供 CLI 工具（init/schema/export/import/flat）、.redb 导出导入格式用于备份与跨后端迁移，以及多节点启动的 schema 锁机制

适用场景（解读层）

  • .NET 应用中需要以 C# 类为中心管理数据模式并避免迁移流程的项目
  • 需要存储和查询树形结构、列表、聚合与窗口计算的领域数据
  • 使用 SQLite 后端的离线/嵌入式应用、Blazor WebAssembly 或移动端场景
