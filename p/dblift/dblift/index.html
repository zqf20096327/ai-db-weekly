Python 版 SQL 数据库迁移工具，读取 Flyway 风格的版本化 .sql 文件并记录执行历史

综述（解读层）

DBLift 是面向 Python 团队的数据库 schema 迁移工具，直接执行手写的版本化 .sql 文件并记录历史。以 CLI 或 Python 库方式安装运行，无需 JVM，提供 dry-run 预览、undo、校验和、锁与基线机制，并可通过 import-flyway 导入已有 flyway_schema_history。许可为 Apache 2.0，另有商业 Pro 层提供 diff 与 schema 导出。

  • 读取 Flyway 命名约定（V/R/U 前缀）的 .sql 迁移文件，支持 migrate --dry-run --show-sql 预览每条待执行语句
  • 提供 validate 校验和检查、undo 回滚（U 文件配对）、baseline 基线接管已有数据库、锁表串行化并发执行
  • 包含同步与异步 Python API、pytest-dblift 测试夹具，以及 Django/FastAPI/Flask/SQLAlchemy 等集成，支持 20 种数据库引擎

适用场景（解读层）

  • Python 项目中替代 JVM 方式执行 Flyway 风格的 SQL 迁移，并导入现有 flyway_schema_history
  • 取代自维护的 migrate.sh/migrate.py 脚本，获得版本冲突、文件篡改和并发执行的检测与保护
  • 在 pytest 或应用启动流程中以库方式运行迁移，使测试数据库与生产 schema 保持一致
