🧭 简介解读层（AI·证据行可回查）

用于在应用内查看 SQLite 数据、应用偏好设置与实时 HTTP 流量的 Capacitor 原生插件

综述（解读层）

该插件为 Capacitor 5+ 应用提供原生调试界面，用于浏览 SQLite 数据库表与记录、以键/值/类型形式查看并增删改 Shared Preferences（Android）与 plist（iOS）条目，以及通过注入 WebView 补丁捕获 JavaScript 发起的 fetch/XHR 请求。面向开发者与 QA/QC 团队，通过 npm 从 GitHub 安装并 npx cap sync 同步。README 建议仅在 debug/内部构建中暴露入口。

  • 提供 SQLite 浏览器：列出数据库与表，支持分页、数据网格、列显隐与筛选条件（=、LIKE、IN 等）
  • 支持偏好设置条目的增删改，保存前进行类型化校验（String、Int、Bool、Data、Dictionary、Array 等）
  • 网络检查器通过拦截 fetch 与 XMLHttpRequest 捕获请求，展示方法、URL、状态码、耗时及请求/响应头与 JSON 正文，内存中保留最近 200 条

适用场景（解读层）

  • 在内部 QA 构建中检查应用本地数据，替代自建调试界面
  • 调试时直接查看、编辑 Shared Preferences/plist 键值并验证类型化输入
  • 排查 JavaScript 发起的 HTTP 调用，无需修改应用 HTTP 代码即可与 CapacitorHttp 共存使用
