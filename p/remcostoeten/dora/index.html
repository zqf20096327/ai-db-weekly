🧭 简介解读层（AI·证据行可回查）

基于 Rust 和 Tauri 的本地数据库客户端，连接多种数据库并可浏览、编辑数据和运行 SQL。

综述（解读层）

Dora 是一个 GPLv3 开源桌面数据库客户端，用于连接 PostgreSQL、MySQL、MariaDB、CockroachDB、SQLite、libSQL/Turso、Cloudflare D1 和 DuckDB，也可将 CSV、JSON、Parquet 等文件作为表查询。面向需要浏览、编辑数据、运行 SQL 和编写 Drizzle/Prisma 查询的开发者。核心机制包括：通过 OAuth 或 API key 登录 Supabase、Neon、Turso 等托管服务自动填充连接配置，编辑采用先暂存后落库的 dry-run 模式；AI 功能需自行配置密钥，Ollama 可完全离线运行。数据不经项目方服务器，凭据以 AES-256-GCM 加密存储在系统钥匙串中。

  • 支持 8 种数据库引擎及 CSV、JSON、Parquet、TSV、NDJSON 文件的表格化查询与跨文件连接
  • 提供表格浏览、内联编辑（带 dry-run 暂存模式）、基于 Monaco 的多标签 SQL 控制台与键盘优先操作
  • 支持原生编写 Drizzle 和 Prisma 查询，可对比 schema 与在线数据库并生成迁移

适用场景（解读层）

  • 在统一客户端中跨多种数据库引擎浏览、编辑和导出数据
  • 为 Drizzle 或 Prisma 项目编写查询并生成 schema 对应的迁移
  • 通过 SSH 隧道连接远程数据库，或使用本地文件格式（SQLite、CSV、Parquet）进行临时查询分析
