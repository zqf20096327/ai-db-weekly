将 Grafana 数据库从 SQLite 迁移到 PostgreSQL 的脚本集

综述（解读层）

该项目提供一组脚本与操作说明，用于把 Grafana 的 SQLite 数据库文件转换为 PostgreSQL 数据库并导入。流程包括在 PostgreSQL 端创建库与用户、让 Grafana 生成目标表结构、运行 migrator.sh 执行转换导入。README 说明代码基于 5.1.3 版本的 gist 改编，明确在 Grafana 9.1.5 数据库上测试过，其他版本可能需修改。面向需要在 Ubuntu 16.04 或 RHEL 8 环境执行此迁移的 Grafana 运维人员。

  • 包含 migrator.sh 与 sqlite_to_postgres.py 脚本，用于读取 SQLite 数据库并写入 PostgreSQL
  • 支持通过 PYTHON_CMD 与 PSQL_CMD 环境变量自定义 Python 和 psql 命令，可连接远程 PostgreSQL
  • README 列出可安全忽略的重复键错误类型，并记录经过测试的 Grafana 9.1.5 版本

适用场景（解读层）

  • Grafana 目前使用 SQLite 存储，需要改用 PostgreSQL 作为后端数据库
  • 数据保留在同一实例：导出 grafana.db 后在同一服务器完成转换导入
  • 需要在 Ubuntu 16.04 / RHEL 8 服务器上按文档化流程执行数据库迁移
