开源浏览器端 ERD 可视化设计工具，支持 AI 代理编辑与七种数据库 DDL 导出

综述（解读层）

ERD Designer 是一个开源的数据库模式可视化设计工具，可在浏览器、VSCode 或 Google Drive 中拖拽设计表与关系。.erd 文件为纯 JSON 格式，可纳入 Git 差异审查。AI 代理可通过 MCP 服务器或插件（CLI + skill）直接编辑图表。代理插件与 MCP 功能标记为实验性。采用 Apache License 2.0。

  • 提供浏览器、VSCode 扩展和 Google Drive 应用三种使用方式，.erd 文件为纯 JSON 格式
  • 内置 MCP 服务器与代理插件（CLI + skill），AI 代理可通过工具目录添加表、列、关系并导出 DDL
  • 支持导出 PostgreSQL、MySQL、MariaDB、MS SQL Server、SQLite、BigQuery、Snowflake 七种数据库的 DDL，并可导入 DDL 生成图表

适用场景（解读层）

  • 在画布上以拖拽方式设计表结构与 1:1 / 1:N 关系，自动同步外键
  • 通过 Claude Code 或 GitHub Copilot CLI 让编码代理直接编辑 .erd 文件并生成 DDL
  • 使用 @kajitiluna/erd-cli 对比 .erd 版本差异或检测线上数据库与设计的偏差（只读 SELECT）
