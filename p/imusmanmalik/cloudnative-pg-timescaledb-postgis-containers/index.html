为 CloudNativePG 构建的含 TimescaleDB 与 PostGIS 扩展的 PostgreSQL 容器镜像

综述（解读层）

该项目在官方 CloudNativePG PostgreSQL 操作镜像上叠加扩展层，提供包含 TimescaleDB、TimescaleDB Toolkit、PostGIS 及 pgRouting 的容器镜像，发布于 ghcr.io。面向使用 CloudNativePG 运维 PostgreSQL 集群并需要时序或地理空间扩展的用户。扩展版本按 PostgreSQL 大版本与发行版固定，镜像附带 SBOM、来源证明与 cosign 签名。TimescaleDB 未为 PostgreSQL 14 的 trixie 发布软件包，该组合不提供镜像。

  • 基于官方 CloudNativePG 操作镜像，以 USER 26 运行并保留上游 entrypoint，可直接用于 Cluster 资源
  • 覆盖 PostgreSQL 14–18，Debian bookworm 与 trixie 两种发行版、standard 与 system 两种类型，构建于 linux/amd64 与 linux/arm64
  • 每个发布镜像附 SBOM、provenance 与 cosign 签名，并经冒烟测试验证扩展可用；提供 ClusterImageCatalog 按主版本以 digest 引用镜像

适用场景（解读层）

  • 在 Kubernetes 上通过 CloudNativePG 运行带 TimescaleDB 时序扩展的 PostgreSQL 集群
  • 在同一集群镜像中使用 PostGIS、postgis_topology 与 pgRouting 处理地理空间数据
  • 需要扩展版本固定、按 digest 引用不可变镜像标签的生产环境部署
