基于 Docker Compose 的 MySQL 高可用示例环境，集成 ProxySQL、Percona Heartbeat 与 Orchestrator

综述（解读层）

该仓库用 Docker Compose 构建一套基础的 MySQL 高可用环境：MySQL 主从复制基于 GTID 配置，由 ProxySQL 做代理、Percona Heartbeat 监测复制延迟、Orchestrator 提供复制管理与 Web 界面（localhost:3000）。适合需要在本地快速运行 MySQL HA 拓扑进行学习或测试的用户。README 说明项目仅覆盖基础环境，高级与自定义配置需参考各组件自身文档；所有集群密码定义在 grants/users.sql 中。

  • 通过 docker-compose pull 和 docker-compose up -d 启动环境，支持本地重新构建镜像
  • MySQL 复制基于 GTID 配置
  • 提供 ProxySQL 连接池统计、Orchestrator Web 页面（http://localhost:3000）和 percona.heartbeat 表三种集群状态查看方式

适用场景（解读层）

  • 本地搭建带 GTID 复制的 MySQL 高可用演示/学习环境
  • 需要查看 ProxySQL 连接池状态、Orchestrator 复制拓扑和复制延迟数据时
  • 用 docker-compose down -v 清理数据后重复测试的场景
