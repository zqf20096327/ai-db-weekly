JDBDT 是基于 JDBC 的 Java 数据库测试自动化库，实现差分测试机制。

综述（解读层）

JDBDT（Java Database Delta Testing）是一个用于数据库测试自动化的 Java 库，基于 Java 8 SE API 实现，无外部依赖，发布于 Maven Central，采用 MIT 许可证。它提供数据集（DataSet）的导入导出（含 CSV）、表填充/删除/存在性断言、查询构建（支持 LIMIT）等能力，供使用 JUnit 做数据层测试的 Java 开发者使用。编译需 Maven 3.0+ 和 Java 8+。

  • 仅依赖 Java 8 SE API，无外部依赖，可从 Maven Central 获取
  • 支持 CSV 数据集导入/导出，并可按 JDBC 类型自定义转换
  • 提供表填充、删除、存在性断言、SQL 语句执行及查询构建（含 LIMIT）

适用场景（解读层）

  • 在 JUnit 测试中自动化验证数据库表内容的变化
  • 为测试准备数据集（填充、插入）及导出数据库数据为 CSV
  • 对数据库对象的存在性进行断言验证
