🧭 简介解读层（AI·证据行可回查）

终端里的 PostgreSQL/MySQL 数据库客户端，基于 Rust/Ratatui 构建的 TUI 界面。

综述（解读层）

datarig 是一个运行在终端的数据库客户端，用 Rust 编写，基于 Ratatui 构建界面，支持 PostgreSQL 与 MySQL。它提供表格编辑（变更以 SQL 形式列出并在单一事务中执行）、带补全的 SQL 编辑器、多视图查询计划、结果图表和服务器监控。项目处于 pre-1.0 阶段，MySQL 支持为部分实现，配置格式与按键绑定可能在版本间变动。

  • 支持 PostgreSQL 与 MySQL（8.0+），可同时打开多个连接并各占独立标签页
  • 表格编辑生成待应用的变更列表与确切 SQL，Apply 在一个事务中执行；读-only 配置在发送前拒绝写入，PostgreSQL 上由服务端强制
  • EXPLAIN/EXPLAIN ANALYZE 结果以树、icicle、flame graph、treemap、时间轴等多种视图呈现

适用场景（解读层）

  • 需要在终端中通过 SSH 隧道连接并浏览/编辑 PostgreSQL 或 MySQL 数据
  • 阅读与分析慢查询的执行计划（树形/火焰图等多种视图）
  • 观察数据库服务器的会话、锁等待与复制状态并处理阻塞语句
