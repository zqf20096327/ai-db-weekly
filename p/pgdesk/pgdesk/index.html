Go 服务器内挂载的 PostgreSQL 管理面板，从 pg_catalog 读取 schema 自动生成界面

综述（解读层）

pgdesk 是一个 Go 库，用于在已有 Go 服务器中挂载 PostgreSQL 数据库管理面板。开发者传入现有 pgxpool，它通过 pg_catalog 读取 schema，自动生成列表、搜索、筛选、表单和 CSV 导出。认证依赖宿主应用的中间件，自身不含登录页。要求 Go 1.25+ 和 PostgreSQL 12+，v1 前 API 可能变更。

  • 接受现有 *pgxpool.Pool，唯一依赖为 pgx，无 JS 构建步骤
  • 从 schema 推导界面：外键显示关联记录并提供搜索选择器，CHECK 约束生成下拉框，timestamptz 生成日期范围筛选，只读视图不提供编辑
  • 提供 Authorizer 与可选 Scoper 机制，行级范围注入 SQL WHERE 子句；支持并发编辑保护与 WithTxAuditLogger 事务审计日志

适用场景（解读层）

  • 为 Go 服务背后的 PostgreSQL 数据库搭建内部后台管理界面
  • 面向可信运维人员的 backoffice/内部工具，置于自有认证与内网之后使用
  • 按表注册（或 WithAutoRegister 全量）管理指定数据表及相关子记录
