MySQL 表结构差异对比与同步工具，只同步 Schema 不同步数据

综述（解读层）

该工具读取同步源与目标数据库的表结构并执行差异同步，覆盖新表、字段、索引的新增与修改，可预览生成变更 SQL、发送邮件通知。适用于需在测试环境复现线上 Schema 变化的开发者。限制包括：不支持分区同步、数据不同步、默认不删除目标端多余对象。

  • 同步新表及字段、索引的新增与修改，支持通过 -drop、-field-order 参数控制删除和字段顺序同步
  • 提供预览模式只对比不同步，可生成变更 SQL 文件；支持邮件通知同步结果
  • 支持通配符配置表范围、屏蔽指定表/字段/索引/外键，并兼容分区表与 TiDB 单条 DDL 模式

适用场景（解读层）

  • 将线上数据库的表结构变化同步到本地或测试环境
  • 定时运行（crontab）批量对比多个数据库的 Schema 差异并邮件告警
  • 在执行变更前预览并导出 ALTER 语句供人工审核
