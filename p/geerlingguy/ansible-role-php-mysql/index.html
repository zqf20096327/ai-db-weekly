在 Linux 上安装 PHP MySQL 支持扩展的 Ansible 角色

综述（解读层）

该 Ansible 角色用于在 Linux 系统上安装 PHP 的 MySQL 支持（如 php-mysqlnd 或 php8.2-mysql），适用于需要通过 Ansible 自动化配置 PHP 与 MySQL 连接环境的服务器管理员。角色提供 php_enablerepo 和 php_mysql_package 等变量以适配不同发行版或软件集合场景，依赖 geerlingguy.php 角色。创建于 2014 年，采用 MIT/BSD 许可证。

  • 通过 apt/yum 安装 PHP MySQL 扩展包，默认按发行版选择 php-mysqlnd（RedHat）或 php8.2-mysql（Debian）
  • 提供 php_enablerepo 变量，支持在 RedHat/CentOS 上启用额外仓库以安装不同版本的 PHP 包
  • 依赖 geerlingguy.php 角色，可与其他 geerlingguy 系列角色组合使用

适用场景（解读层）

  • 为运行 PHP 应用的 Web 服务器批量配置 MySQL 数据库连接扩展
  • 在 Enterprise Linux 上通过软件集合或 Remi 仓库安装特定版本 PHP 的 MySQL 支持
  • 需沿用旧包名（如 RHEL 7 上的 php-mysql）的遗留环境配置
