分布式键值 NoSQL 数据库，自实现 SWIM 与 Raft 协议

综述（解读层）

NodeDial 是用 Scala 编写的分布式键值 NoSQL 数据库，参考 Redis 类主从架构模型。自实现 SWIM（成员管理与故障检测）和 Raft（复制）协议，内部通信使用 gRPC。需 Java 8、Scala、protobuf 编译环境，支持 Docker 容器与 Kubernetes StatefulSet 部署。README 明确说明该程序主要用于学习目的，作者声明不建议用于生产系统。

  • 自实现 SWIM 协议用于集群成员管理和故障检测，Raft 协议用于复制层，内部通信全部使用 gRPC
  • 支持 GET、POST、DELETE 三种基本操作，并提供 nodedial 命令行客户端进行读写请求
  • 支持 Docker 容器运行，并可通过 Kubernetes StatefulSet 部署集群，用 kubectl scale 扩容节点（默认每节点加入间隔至少 25 秒）

适用场景（解读层）

  • 学习分布式系统概念（Raft 共识、gossip 成员管理、故障检测）的可运行实现参考
  • 在本地 Kubernetes 环境中搭建多节点集群，观察节点加入与同步日志流程
  • 通过 CLI 或 Docker 容器运行单节点键值存储进行读写实验
