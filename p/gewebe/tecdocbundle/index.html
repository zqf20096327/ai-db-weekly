将 TecDoc 车辆与配件数据库集成到 Symfony 应用的 Bundle

综述（解读层）

该 Symfony Bundle 用于把 TecDoc 车辆与配件数据库导入并接入 Symfony 项目。它提供定宽文件的数据库导入命令、对应实体模型、描述与图片的自动翻译，以及用于演示的 REST API。因版权原因未发布完整 TecDoc schema，需更多实体须联系作者。

  • 提供 tecdoc:extract、tecdoc:import 等命令，将 7z 解压后的定宽文件（支持多线程）导入数据库
  • 包含定宽文件对应的 Doctrine 实体模型，可通过独立 entity manager 建表
  • 提供描述、文本模块与图片的自动翻译，并附带基于 FOSRest 的演示 REST API（Swagger 文档）

适用场景（解读层）

  • 在 Symfony 项目中存储和查询 TecDoc 车辆与配件数据
  • 处理 TecDoc 参考数据定宽文件的批量导入
  • 通过演示 REST API 展示或验证导入后的数据
