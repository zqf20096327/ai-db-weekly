🧭 简介解读层（AI·证据行可回查）

Cloud Foundry CLI 插件，连接 mysql 客户端到 CF 应用的 MySQL 兼容数据库

综述（解读层）

该插件为 Cloud Foundry CLI 提供 cf mysql 与 cf mysqldump 命令，通过创建名为 cf-mysql 的服务密钥获取凭据，并借助 SSH 隧道连接服务实例。支持管道传输入查询、向 mysql 透传参数、导出整库或指定表。适用于使用 CF 部署应用的运维与开发人员；需当前空间内有运行中的应用实例，且服务密钥需手动删除。

  • 提供 cf mysql 命令，传入服务实例名即可打开 mysql 客户端
  • 提供 cf mysqldump 命令，支持导出整个数据库或指定表
  • 子进程继承标准输入/输出/错误，支持管道导入 SQL 转储与透传 mysql 参数

适用场景（解读层）

  • 调试时检查 CF 应用所使用数据库的内容
  • 在开发环境中手动调整数据库模式或数据
  • 导出并恢复数据库转储文件
