🧭 简介解读层（AI·证据行可回查）

Go 语言领域驱动设计项目模板，内置 CQRS、幂等键与事务性 Outbox。

综述（解读层）

这是一个 Go 后端项目模板，以洋葱架构组织 domain、application、infrastructure、interface 四层，内置市场示例（Seller/Product 聚合）、CQRS 命令查询分离、原子幂等键与 Outbox 事件中继。技术栈为 Go 1.26、Echo v4、pgx/v5、sqlc 与 golang-migrate，提供 Docker Compose 一键启动本地环境，适合学习或搭建遵循 DDD 实践的 Go 服务。

  • 提供洋葱分层结构（domain/application/infrastructure/interface）与市场示例聚合、值对象及校验规则
  • 实现幂等键写入路径：原子预留（INSERT ON CONFLICT）、缓存响应、冲突负载拒绝与 TTL 过期
  • 包含事务性 Outbox：事件与状态同库持久化，由 relay 轮询实现至少一次投递；配套 golang-migrate 与 sqlc 数据库工具链

适用场景（解读层）

  • 以该模板为起点搭建分层清晰的 Go 后端服务
  • 参照九章节教程学习 DDD、CQRS、幂等与 Outbox 模式
  • 复用其健康探针、OpenAPI、Docker Compose 与迁移规范组织工程实践
