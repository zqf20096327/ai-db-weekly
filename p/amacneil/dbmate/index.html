独立命令行数据库迁移工具，用纯 SQL 管理多数据库架构变更

综述（解读层）

Dbmate 是一个独立的数据库迁移命令行工具，面向使用 Go、Node.js、Python、Ruby、PHP 等多种语言编写数据库应用的开发团队。它支持 MySQL、MariaDB、PostgreSQL、SQLite 和 ClickHouse，使用时间戳版本号避免多人协作冲突，迁移在事务内原子执行，并可生成 schema.sql 文件供 git 差异比对。连接信息通过 DATABASE_URL 等环境变量配置。

  • 支持 MySQL、MariaDB、PostgreSQL、SQLite、ClickHouse 五种数据库，使用纯 SQL 编写迁移
  • 迁移文件采用时间戳版本命名，并在事务内原子执行；支持创建和删除数据库
  • 以单个自包含二进制分发，提供 NPM、Homebrew、Scoop、直接下载和 Docker 多种安装方式

适用场景（解读层）

  • 多语言服务团队需要统一的数据库迁移工具链
  • 开发/测试环境中需要频繁创建、重建数据库并通过 schema.sql 在 git 中追踪架构变更
  • 十二因子风格的部署流程，通过环境变量或 .env 文件管理数据库连接配置
