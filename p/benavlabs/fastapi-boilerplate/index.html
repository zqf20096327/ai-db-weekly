🧭 简介解读层（AI·证据行可回查）

基于 FastAPI 的异步后端启动模板，含认证、CRUD、任务队列与缓存等九个可移除模块。

综述（解读层）

Fastro 是一个开源 FastAPI 项目模板，提供账户、RBAC、速率限制、API 密钥、管理后台、缓存与 Taskiq 任务队列等九个模块，各模块可独立移除并带走相关路由、模型与测试。技术栈为全异步 FastAPI + SQLAlchemy 2.0 + Pydantic v2，数据库用 PostgreSQL，可经 Alembic 做迁移。面向需要后端起点的开发者，通过 uv 工作区与 bp CLI 生成 Docker Compose 配置运行；README 注明不适用于单体仓库微服务脚手架场景。

  • 包含九个可移除功能模块（accounts、rbac、tiers、ratelimit、api_keys、admin、cache、taskiq 等），移除时带走对应路由、模型、设置、测试
  • 提供 bp CLI 用于生成 local/prod/nginx 三种 Docker Compose 文件、生成密钥与校验 .env 配置
  • 认证包含服务端会话 + CSRF、Google/GitHub OAuth 与 API 密钥；缓存支持 Redis 或 Memcached；队列支持 Redis 或 RabbitMQ broker

适用场景（解读层）

  • 需要带认证、CRUD、任务队列、缓存与速率限制的 FastAPI 后端起点
  • 使用 Docker Compose 部署到本地、单机生产或 nginx 反代环境
  • 搭配 PostgreSQL（本地容器或 Neon serverless）运行异步 API 服务
