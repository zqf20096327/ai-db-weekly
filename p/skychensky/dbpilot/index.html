自托管数据库性能诊断平台，采样 DMV 等元数据视图生成 Web 控制台

综述（解读层）

DBPilot 是一个自托管的数据库性能诊断平台，通过 .NET 单进程部署，持续采样 SQL Server、MySQL、PostgreSQL 实例的内存元数据视图（DMV/pg_stat_*/performance_schema），提供性能趋势、AAS 负载分解、Top SQL、执行计划变更跟踪、阻塞与死锁分析等功能，面向日常 DBA 运维工作。监控能力因引擎而异，如执行计划快照仅支持 SQL Server；需配置元数据库连接串和主密钥才能启动。

  • 单进程部署：一个 .NET 8+ 进程加一个元数据库（支持 SQL Server/MySQL/PostgreSQL/SQLite），启动时自动建表
  • 内置只读 MCP Server，向 AI 代理（如 Claude Code、Codex CLI）暴露 11 个诊断工具
  • 采集器只读取内存元数据视图，不扫描业务表；性能趋势粒度 10 秒，保留 30 天并自动降采样

适用场景（解读层）

  • 为 SQL Server/MySQL/PostgreSQL 实例集中查看性能趋势、AAS 负载构成与 Top SQL
  • 排查阻塞链、死锁循环及慢查询，留存历史统计与事件详情
  • 通过内置 MCP Server 让 AI 代理以自然语言查询近期诊断数据
