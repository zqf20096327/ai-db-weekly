🧭 简介解读层（AI·证据行可回查）

基于 shell 脚本的服务器备份教程项目，用 tar 与 mysqldump 打包文件和数据库并通过 crontab 定时执行、邮件通知

综述（解读层）

该项目提供一个 shell 备份脚本及配套教程，用于在 Ubuntu 服务器上备份指定文件夹和 MariaDB/MySQL 数据库。脚本用 tar 打包文件、mysqldump 导出数据库，通过 crontab 定时运行，并可用 mail 发送完成通知。README 覆盖从 SSH 登录、脚本创建到 crontab 配置、备份下载的完整流程，面向具备基本 CLI 使用能力的服务器管理员。已知限制：备份文件名按日期生成，一天内多次运行会覆盖同名文件。

  • 使用 tar czvfP 打包指定目录，保留文件权限信息
  • 使用 mysqldump 带 --routines --triggers --single-transaction 参数导出数据库
  • 通过 crontab 定时执行脚本，可用 mail 发送备份完成邮件通知

适用场景（解读层）

  • Ubuntu 服务器上定时备份网站文件夹、配置文件与数据库
  • 需要备份完成后通过邮件获知结果的服务器维护流程
  • 将 /mnt/backup 下的备份文件通过 scp、rsync 或 SFTP 传输到本地机器保存
