面向 Delphi、FreePascal/Lazarus 与 C++ Builder 的多数据库组件库

综述（解读层）

Zeos Library 为 Delphi、FreePascal/Lazarus 和 C++ Builder 提供数据库组件，支持 MySQL、PostgreSQL、Oracle、Firebird、SQLite、ODBC 等多种数据库。除常规的连接、查询和存储过程对象外，还提供序列、数据库事件监听、元数据读取、脚本执行等支持对象。本仓库为 SourceForge 官方 SVN 库的 Git 镜像，标注仅用于测试，可能被删除。

  • 提供覆盖 MySQL、MariaDB、PostgreSQL、Oracle、SQL Server、SQLite 等多种数据库及 ODBC/OleDB/ADO 的连接组件
  • 在连接、查询、存储过程对象之外，提供序列、数据库事件（Firebird/Interbase/PostgreSQL）、元数据读取、脚本执行支持对象
  • 包含通过 SOAP/HTTP 访问受支持数据库的服务器与数据库驱动，并提供 DuckDB、QuestDB 的初步支持

适用场景（解读层）

  • 在 Delphi、FreePascal/Lazarus 或 C++ Builder 项目中连接多种数据库
  • 需要读取数据库对象元数据或执行数据库脚本的应用开发
  • 需要监听 Firebird、Interbase、PostgreSQL 数据库事件，或通过 SOAP/HTTP 访问数据库的场景
