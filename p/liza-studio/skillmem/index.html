🧭 简介解读层（AI·证据行可回查）

为编码代理提供本地 SQLite 技能记忆层，记录、召回、强化并衰减过程性技能。

综述（解读层）

skillmem 为 Claude Code、Codex CLI 等六个代理工具提供本地持久化的技能与记忆层，存储过程（触发、步骤、结果、教训）而非事实。强度依据外部证据（如 test_passed 需 test-witness 钩子见证）而非代理自报提升，未用技能按 Ebbinghaus 日程衰减并归档。每条记忆带来源标记，仅所有者可批准为规则；无 API key、无云服务。注意 test_passed 只能证明测试通过而非技能有效，CLI/HTTP 调用者的证据不校验。

  • 本地运行：SQLite + FTS5 BM25 + Snowball 词干化（英/俄）+ 本地 ONNX 嵌入模型，CPU 离线检索，读写无 LLM 调用
  • 通过六个事件钩子（SessionStart 至 SessionEnd）自动召回，另提供 9 个 MCP 工具；多代理共享同一数据库并按来源记录作者
  • 编辑历史追加至 SHA256 哈希链，skillmem verify 可检测事后篡改；export-all 导出为带 YAML frontmatter 的 markdown 并可重导入

适用场景（解读层）

  • 使用 Claude Code 或 Codex CLI 等代理进行开发，希望跨会话保留任务执行过程与经验
  • 需要区分所有者规则与代理自写记忆，并对导入或代理生成的内容做来源隔离的团队
  • 在离线或本机环境中存储记忆，不接受云端或 API key 依赖的个人开发者
