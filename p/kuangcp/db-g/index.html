Go 编写的本地桌面 SQL 客户端，单可执行文件支持四类数据库

综述（解读层）

DB-G 是本地优先的桌面数据库客户端，用 Go 与 mygo 构建，编译为单一可执行文件，无需 Java、Electron 或 WebView 运行时。它为 SQLite、MySQL、PostgreSQL、ClickHouse 提供连接、SQL 编辑执行、对象树、补全与导出等功能，配置与数据保存在本机目录。Windows 提供 exe 安装包，Linux 需要 GTK 3 环境。

  • 支持 SQLite、MySQL、PostgreSQL、ClickHouse 四种数据源，共用对象树、补全、结果表格与导出流程
  • 提供 SQL 编辑器（高亮、多光标、补全）、多语句执行、结果单元格编辑、CSV/JSON/SQL INSERT 导出与执行计划查看
  • 元数据按页加载并带 24 小时磁盘缓存；连接密码 AES-256-GCM 本机加密，日志自动脱敏

适用场景（解读层）

  • 在本地桌面统一管理多种数据库连接并进行日常查询与数据修改
  • 需要免安装、无运行时依赖的 SQL 工作台的 Windows/Linux 用户
  • 通过 Ollama 或 OpenAI-compatible 接口在客户端内使用 AI 生成与改写 SQL
