🧭 简介解读层（AI·证据行可回查）

基于图RAG的SQL生成工具，自动探索无文档数据库并生成查询

综述（解读层）

该工具面向缺乏文档的大型数据库（如EHR），通过缓存各表前X行数据、用FAISS构建向量库并用NetworkX建立表间关系的知识图，将自然语言提示转化为SQL查询。包含Flask服务器和网页界面，默认使用SQLite示例和Google AI API。项目定位为演示用途，生产环境需自行替换数据库连接器并处理PHI合规。

  • 缓存表数据并用FAISS向量库做相似检索，结合NetworkX知识图补充关联表上下文
  • 支持多表JOIN的SQL生成，组件化设计可替换数据库连接器与LLM API
  • 提供基于Flask的网页界面用于输入提示与查看生成的SQL

适用场景（解读层）

  • 缺乏schema文档或数据字典的大型数据库的自然语言查询
  • EHR等医疗数据的SQL生成（需使用机构批准的PHI API）
  • 作为graph-RAG与LLM结合的演示或二次开发基础
