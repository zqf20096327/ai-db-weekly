SQL 数据库敏感数据扫描、脱敏与验证的审计式 Python 工具

综述（解读层）

dbmask 通过 pip 安装，提供 scan→mask→validate 工作流：识别 SQL 库中的敏感列，用确定性假数据（种子映射保证跨表一致）改写，再按主键逐行校验脱敏完整性。决策链为人工覆盖>复核历史>模式规则>可选 LLM（默认关闭）。默认需 --apply 才写入，validate 非零退出可作 CI 门禁。支持 SQLAlchemy 方言的数据库，自动测试覆盖 SQLite 与 PostgreSQL 16 基础场景，未覆盖大表与复杂关系。

  • 支持扫描、预览、脱敏、验证四阶段流程，mask 需 --apply 显式确认才写入，validate 失败时非零退出
  • 提供十余种脱敏策略（fake_email、fake_credit_card、format_random 等），由种子与种子映射保证同输入输出一致且跨库连接可保留
  • 决策来源包含人工覆盖、可导入导出的复核历史、格式规则及可选 LLM（默认关闭，可限制仅发送列名）

适用场景（解读层）

  • 为开发、测试或演示环境生成脱敏后的生产数据库副本
  • 将脱敏验证接入 CI 门禁，逐行检查敏感值未被遗漏
  • 对含 PII 的数据交接、分析仓库或 AI 管道执行可审计的脱敏流程
📖 README 首段存档原文 · 程序抽取

Discover which columns hold sensitive data, mask them with realistic deterministic fakes, then verify the masking actually happened — one auditable workflow for making safe copies of SQL databases.

🔌 适配哪些库db_scan 程序判定

MariaDB、MySQL、Oracle、PostgreSQL、SQL Server、SQLite
