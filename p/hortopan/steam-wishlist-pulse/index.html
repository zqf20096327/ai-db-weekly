基于 Valve Wishlist API 的 Steam 愿望单监控工具，推送 Telegram/Discord 通知

综述（解读层）

Steam Wishlist Pulse 是面向在 Steam 发行的游戏开发者的愿望单监控工具，通过 Valve 的 Wishlist Data API 同步愿望单历史数据，检测异常活动并推送通知。项目以单个 Rust 二进制文件发布，内置 Web 仪表盘（localhost:3000），使用 SQLite 存储数据，支持 Windows、macOS 和 Linux（含 ARM）。需创建具备 General 和 Financial 权限的 Financial API Group 以获取 API Key，Telegram/Discord 机器人可选配置。

  • 实时推送愿望单新增、删除、购买、赠送等变动到 Telegram 和 Discord，支持两种提醒模式
  • 使用基于中位数和 MAD 的修正 z-score 算法检测异常，提供四种灵敏度预设及自定义参数，并检测国家级区域异动
  • 单个二进制文件（约 4 MB）内置 Web 管理面板，含 Argon2 密码哈希、JWT 会话、登录限速及可选 AES-256-GCM 静态加密

适用场景（解读层）

  • 游戏开发者追踪自己游戏的愿望单变动，在预告片发布、媒体提及后观察变化
  • 需要监控特定地区愿望单激增的发行团队
  • 希望在树莓派等低配设备上持续轮询并保存完整历史数据的环境
