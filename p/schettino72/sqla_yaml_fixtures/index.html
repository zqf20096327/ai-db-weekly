把 YAML 数据加载为 SQLAlchemy 模型记录的 fixtures 工具

综述（解读层）

sqla_yaml_fixtures 提供按 SQLAlchemy declarative mapper 结构编写的 YAML fixtures 加载，支持 __key__ 标识、点号引用、一对一嵌套和 to-many 列表。提供 ORM 的 load()、Core 的异步 load_core() 以及命令行入口（含 --reset-db、--alembic-stamp、--jinja2 等选项）。load() 会执行 commit；默认 YAML 加载器为 FullLoader，README 提示对不可信输入可通过 loader 参数覆盖。

  • 提供 load(ModelBase, session, fixture_text) 的 ORM API 和 load_core(metadata, connection, ...) 的 Core 异步 API
  • 通过 __key__ 与点号引用表达关系依赖，to-one 可嵌套、to-many 可用引用列表
  • 命令行支持 --reset-db、--alembic-stamp、--jinja2 模板加载等选项，可经 Store.get(key) 取回数据库生成属性

适用场景（解读层）

  • 为测试或开发环境准备 SQLAlchemy 数据库的初始数据
  • 以 YAML 文件描述含关系依赖的模型实例并批量写入数据库
  • 配合命令行在开发流程中重建 schema 并载入 fixtures
