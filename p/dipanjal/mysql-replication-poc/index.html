基于 Docker 搭建 MySQL 主从复制与 ProxySQL 读写分离的演示项目

综述（解读层）

该项目是一份概念验证文档型仓库，内容包含讲解性文档、docker-compose 配置与 ProxySQL 配置文件，用于演示如何搭建 1 主 2 从的 MySQL 异步复制（基于 Bin Log），并通过 SQLAware 反向代理 ProxySQL 按读写操作分发请求，再以 Spring Boot 应用发起请求并在主从的 General Log 中观察查询执行。运行方式为 docker-compose up -d 启动容器，附有主从状态检查命令与 clean-up.sh 清理脚本；README 注明使用 MySQL 5.7 与 ProxySQL 2.0.12 镜像。

  • 提供 docker-compose 配置，运行 1 个 MySQL Master 与 2 个 Slave 及 ProxySQL 容器
  • 通过 MySQL Bin Log 实现异步主从复制，并用 show master/slave status 命令验证复制状态
  • 使用 ProxySQL（6032 管理端口、6033 MySQL 端口）按查询类型将请求分发到 Master 或 Slave

适用场景（解读层）

  • 学习 MySQL 主从复制与 Bin Log 机制的本地实验环境
  • 演示 ProxySQL 读写分离与负载分发配置
  • 配合 Spring Boot 应用观察读写在主从节点上的执行分布
