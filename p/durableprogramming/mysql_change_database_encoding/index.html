🧭 简介解读层（AI·证据行可回查）

批量修改 MySQL 库表编码与排序规则的 Ruby CLI 工具，可经 pt-online-schema-change 在线变更。

综述（解读层）

这是一个 Ruby 命令行工具，用于将数据库中所有表的字符编码、排序规则或两者改为目标值。连接参数可通过命令行开关或 MYSQL_* 环境变量传入（环境变量因 ps 可见性更安全，命令行优先）。默认支持通过 pt-online-schema-change 做在线 schema 变更，也可用 --direct-alter-table --no-osc 直接修改表。提供 deb/rpm/Docker/源码四种安装方式，需 Ruby 3.0+。GPL v3 许可，由 Durable Programming 提供商业支持。

  • 支持修改数据库的编码、排序规则或两者，可指定目标 encoding 与 collation
  • 支持通过 pt-online-schema-change 进行在线 schema 变更，并可配置回退为直接 alter table
  • 提供命令行参数与 MYSQL_* 环境变量两种配置方式，命令行参数优先

适用场景（解读层）

  • 将包含旧编码表的数据库批量迁移到 utf8mb4/utf8mb4_unicode_ci
  • 需要在生产系统上执行在线表结构变更且已安装 pt-online-schema-change 的环境
  • 无法使用在线变更、可直接修改表的场景（--direct-alter-table --no-osc）
