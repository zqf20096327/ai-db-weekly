🧭 简介解读层（AI·证据行可回查）

Go 编写的向量数据库与亚微秒级键值存储合一引擎，可嵌入、独立运行或 Raft 集群部署

综述（解读层）

Rostam 是用 Go 实现的开源引擎，包含向量检索与键值存储两部分，支持独立服务器（REST/gRPC/TCP）、Raft 副本集群和纯 Go 嵌入式三种运行方式。向量侧提供 HNSW/IVF/Vamana 索引、SQ8/二进制/PQ 量化、混合稠密+稀疏与 BM25 搜索；另附 MCP 服务器、LLM 缓存代理和 RAG CLI。当前为 Beta，API 在 1.0 前可能变动；纯 Go 构建下 WASM 存储过程不可用。

  • 提供 HNSW、IVF、Vamana 三种索引及 SQ8/二进制/PQ 量化，支持稠密+稀疏混合融合与 BM25 全文检索及元数据过滤
  • 键值存储以单一 Store 接口覆盖进程内缓存、副本存储与 TCP 服务器，支持服务端自定义操作与沙箱 WASM 存储过程（需 cgo 构建）
  • 内置 MCP stdio 服务器、OpenAI 兼容的 LLM 语义缓存代理和 RAG CLI，本地嵌入为纯 Go 实现，无需 cgo/ONNX Runtime

适用场景（解读层）

  • 为 Claude Code、Cursor 等 MCP 客户端提供持久化 agent 记忆与向量库工具
  • 需要向量检索、BM25 或带引用来源问答（RAG）的文档检索应用
  • 对延迟敏感的键值读写场景，可嵌入 Go 二进制或以 Raft 集群方式部署，并支持 S3 备份与 RBAC/JWT/mTLS
