基于 LevelDB 的 C 语言嵌入式临时缓存库，支持 TTL 过期机制

综述（解读层）

LevelCache 是用 C 编写的嵌入式键值缓存库，构建在 Google LevelDB 之上，提供带 TTL 的缓存能力：每个键可设置过期时间，访问时判定失效并删除。提供 open/close/put/get/delete 五个基础 API，可控制 LevelDB 缓存的内存上限。通过 Makefile 构建静态库 liblevelcache.a，并附 Google Test 测试与基准测试套件，适用于需要在应用内嵌入本地缓存的 C 项目。

  • 支持为每个键设置 TTL，过期键在访问时被判定无效并删除
  • 提供 open、close、put、get、delete 的 C API
  • 可配置 LevelDB 缓存的最大内存占用

适用场景（解读层）

  • 在 C 应用中嵌入本地键值缓存
  • 需要按键设置过期时间的数据缓存
  • 对内存占用需可控的嵌入式存储场景
