基于 Vert.x 与 Kotlin 的事件溯源/CQRS 实验框架

综述（解读层）

Crabzilla 是一个基于 Vert.x 和 Kotlin 的事件溯源（Event Sourcing）/ CQRS 实验项目。它提供 crabzilla-core 模块用于以纯函数方式表达领域模型，命令处理结果与事件写入 Postgres，并可将事件投影到视图模型或发布到 Vertx eventbus。据 README，该项目已于 2025 年标记为 deprecated，作者转向新项目 crablet。

  • 使用 Vert.x 非阻塞 IO Postgres 驱动，并利用 Postgres 的 json、notification 和 advisory locks 特性
  • 状态转移通过纯函数 (State, Event) -> State 计算，BDD 风格测试仅依赖 crabzilla-core，不依赖 Vertx
  • 支持将事件有序投影到 Postgres 视图模型，并发布到 Vertx eventbus 以对接消息代理、数据库或缓存

适用场景（解读层）

  • 使用 Kotlin 和 Vert.x 开发事件溯源/CQRS 应用
  • 需要将命令产生的事件一致地持久化到 Postgres 并投影到读模型
  • 通过 Vertx eventbus 与其他消息系统集成
