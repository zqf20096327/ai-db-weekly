基于 SQLAlchemy 直连 Magento 2 数据库的 Python 模块，附 FastAPI 查询接口与批量导入

综述（解读层）

PyGento 是一个绕过 Magento 2 核心、直接读写其 MySQL 数据库的 Python 模块，基于 SQLAlchemy 构建，面向需要用 Python 访问 Magento 数据的开发者。包含 77 个模型文件（catalog/sales/customer/checkout 等），通过 MAGENTO_EDITION 开关兼容社区版与企业版的 entity_id/row_id 列差异；提供 CSV 批量导入脚本、FastAPI 商品查询接口和 Jinja2 店面应用。运行需自行配置指向真实 Magento 2 数据库的 .env。

  • 基于 SQLAlchemy 提供 Pythonic 接口，通过 MAGENTO_EDITION 开关透明处理社区版与企业版的列名差异
  • 提供 Magmi 风格 CSV 批量导入，按 EAV backend_type 分桶并经 on_duplicate_key_update 批量 upsert 五张属性值表
  • 包含 FastAPI 商品/属性查询接口、三路由 Jinja2 店面应用，以及 17 个针对真实数据库的 pytest 测试（数据库不可达时自动跳过）

适用场景（解读层）

  • 用 Python 直接读取或写入 Magento 2 数据库的商品、订单、客户等数据
  • 批量导入/更新商品属性（CSV + EAV 批量 upsert）
  • 为 Magento 数据搭建独立 HTTP API 或店面页面而不依赖 Magento 核心
