VS Code 扩展，调用 Oracle SQLcl 对 PL/SQL 代码进行格式化

综述（解读层）

该扩展为 VS Code 提供 PL/SQL 格式化功能，底层调用 Oracle SQLcl 完成格式化。它接入 Format Document、Format Selection 命令及保存时格式化，适用于 plsql 和 oraclesql 语言文件。用户需预先安装 SQLcl，可配置 sql.exe 路径、样式规则文件（style.xml）及关联语言，规则文件支持工作区相对路径。格式化输出打印到名为 oracle-format 的输出通道。

  • 支持 Format Document、Format Selection 命令和 editor.formatOnSave 保存时格式化，作用于 plsql 与 oraclesql 语言文件
  • 可配置 SQLcl 可执行文件路径和格式化规则文件（style.xml），规则文件支持 ${workspaceFolder} 相对路径
  • SQLcl 命令输出打印到 Output 通道（oracle-format）

适用场景（解读层）

  • 在 VS Code 中编辑 PL/SQL 或 Oracle SQL 文件时按统一规则格式化代码
  • 通过 editor.formatOnSave 在保存时自动执行格式化（大文件需调大 formatOnSaveTimeout 超时）
  • 团队通过共享 style.xml 规则文件在工作区内统一格式化配置
