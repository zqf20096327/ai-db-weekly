Rust 嵌入式 SQL 数据库，数据存于可插拔 KV 存储引擎

综述（解读层）

KiteSQL 是一个用 Rust 编写的嵌入式关系数据库，运行在应用进程内，无需外部服务。它支持大部分 SQL 2016 语法，可直接执行 SQL 或使用类型化 ORM。存储后端可插拔：RocksDB、LMDB、内存或 SlateDB over S3，其中 LMDB 后端提供零拷贝读取。提供 Shell、WebAssembly 和 Python 绑定，采用 Apache 2.0 许可证。适合需要在应用内嵌 SQL 能力的 Rust 开发者。

  • 支持大部分 SQL 2016 语法，提供类型化 ORM 与 schema 迁移（orm feature）
  • 存储后端可插拔：RocksDB、LMDB、内存、SlateDB over S3（异步 API）
  • LMDB 上实现零拷贝读取，字符串以 Cow::Borrowed 形式从 mmap 文件进入结构体

适用场景（解读层）

  • 在 Rust 应用中嵌入 SQL 数据库，无需部署独立数据库服务
  • 基于 Amazon S3 或兼容存储（MinIO、R2）构建异步 API 的数据存取层
  • 通过内存后端（build_in_memory）运行测试或处理临时数据
