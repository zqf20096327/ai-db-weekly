综述（解读层）

CipherStash Stack 是一个用于 PostgreSQL 的字段级可搜索加密 SDK。它在应用内完成加解密，数据库仅存密文（EQL payload），密钥由 ZeroKMS 按值签发并在应用内派生。支持等值、范围、模糊文本和 JSON 查询，提供 Supabase、Prisma Next、Drizzle 及原生 pg 的集成；需注册其服务并依赖 ZeroKMS 密钥管理。

  • 支持对加密字段执行等值、范围/排序、模糊文本搜索及 JSON 包裹/JSONPath 查询
  • 通过 OIDC 联邦将密钥绑定到用户身份（identity-locking），并提供 keysets 实现多租户密钥隔离
  • 内置密钥管理：每值唯一密钥、自动轮换、单次最多 10,000 个批量密钥操作，并记录每次解密审计日志

适用场景（解读层）

  • 对 Postgres 中的敏感字段（邮箱、薪资等）加密且需保留按字段查询能力的应用
  • 需要按最终用户身份进行加密数据访问控制的多租户或隐私优先应用
  • 需要解密审计日志以满足 SOC 2 / ISO 27001 等合规加密要求的团队
