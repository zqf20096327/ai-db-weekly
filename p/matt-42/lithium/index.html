基于 C++17 的 HTTP 服务器与客户端库，含 ORM 与 MySQL 支持

综述（解读层）

Lithium 是一个 C++17 编写的 HTTP 服务器库，同时提供 HTTP 客户端、JSON 处理及 MySQL ORM 组件。README 称其 HTTP 服务器与 SQL 驱动在 TechEmpower 基准测试综合得分排名第一。目前仅支持 Linux 与 macOS 平台的指定编译器，Windows 因 MSVC 编译器缺陷尚未支持。

  • 提供 C++17 实现的 HTTP 服务器与 HTTP 客户端
  • 包含 JSON 处理与 MySQL 对象关系映射（ORM）组件
  • 支持 Linux（G++ 9.2、Clang++ 9.0）与 macOS（Apple clang 12.0.0）

适用场景（解读层）

  • 在 Linux 或 macOS 上使用 C++17 构建 HTTP API 服务
  • 需要通过 ORM 访问 MySQL 数据库的 C++ 项目
  • 需要同时使用 HTTP 服务器与客户端功能的 C++ 应用
