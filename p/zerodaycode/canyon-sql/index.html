基于 async 的 Rust 多数据库 ORM 与查询构建器

综述（解读层）

Canyon-SQL 是一个用 Rust 编写的 ORM 与查询构建器，用于以并发方式操作多个数据库，支持 PostgreSQL、SqlServer 和 MySql（分别基于 tokio-postgres、tiberius、mysql-async 等异步 crate）。它通过宏注解和配置文件生成数据访问代码，并提供迁移管理能力。README 标明项目处于早期阶段，构建时可能需自行安装 OpenSSL 和 pkg-config 依赖。

  • 默认异步，可在同一项目中并发查询 PostgreSQL、SqlServer、MySql 等不同数据库
  • 基于宏注解与配置文件生成数据访问代码，并提供表结构迁移管理
  • 提供 SelectQueryBuilder 等查询构建器，支持 where 过滤与 inner join 等表连接

适用场景（解读层）

  • 需要在 Rust 项目中同时访问多种数据库（如 PostgreSQL 与 SqlServer）的场景
  • 希望通过宏注解减少手写数据访问代码的 Rust 服务开发
  • 需要以编程方式管理数据库表结构（迁移）的项目
