🧭 简介解读层（AI·证据行可回查）

基于 Dolt 存储引擎的带版本控制 MongoDB 兼容文档数据库

综述（解读层）

DumboDB 使用 Dolt 存储引擎与 prolly tree，为文档数据提供提交、分支、合并等版本控制能力，通过自定义命令（如 dumboCommit、dumboMerge）从 MongoDB 客户端调用。它实现 MongoDB 8.0 wire protocol，可作为单节点环境下标准驱动与 mongosh 的替代接入。项目为 pre-1.0 软件，不支持副本集多数功能、分片、TTL、capped collections 及 Atlas 专有功能。

  • 实现 MongoDB 8.0 wire protocol，兼容 mongosh 与标准 MongoDB 驱动，支持多文档事务、聚合管道、二级索引、SCRAM 认证、RBAC 与 X.509、TLS
  • 基于 Dolt 的 prolly tree 结构共享，支持对数据的提交、分支、合并与历史查看
  • 文档验证器贯穿写入与分支合并；密钥编码上限 1024 字节，超出报 KeyTooLong (17280) 错误

适用场景（解读层）

  • 需要用 MongoDB 驱动或 mongosh 接入的单节点文档数据存取场景
  • 需要按提交/分支/合并方式追踪数据变更历史的场景
  • 通过 Docker 或预编译二进制（Linux/macOS/Windows）在本地快速运行 --data-dir 数据目录的场景
