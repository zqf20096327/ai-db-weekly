🧭 简介解读层（AI·证据行可回查）

SQLite 分支版，用内容寻址 prolly tree 替换 B-tree 实现 Git 式版本控制

综述（解读层）

DoltLite 是 DoltLite 项目的 SQLite fork，将存储引擎替换为内容寻址的 prolly tree，在 SQL 层以函数和虚拟表提供 commit、branch、diff、merge 等版本控制操作。解析器、规划器和 VDBE 保留自上游 SQLite。可嵌入多种语言，配套提供 Python、Go、Rust 等绑定及 HTTP 远程同步服务器 doltlite-remotesrv。当前处于 Beta 阶段，版本 12 存储格式已冻结。

  • 提供 SQL 函数形式的版本控制操作：dolt_commit、dolt_branch、dolt_diff、dolt_merge、dolt_rebase 等
  • 内置 vec1 向量 ANN 扩展，向量表支持分支、diff、历史查询和推送
  • 保留 sqlite3_* API，可按文件头自动打开原生 SQLite B-tree 格式数据库

适用场景（解读层）

  • 需要数据库级版本控制（分支、diff、合并、回滚）的本地应用开发
  • 通过 C 库或语言绑定嵌入应用，实现 local-first 场景
  • 通过 doltlite-remotesrv 或 push/pull 进行数据库的远程同步与克隆
