支持分支、合并等 Git 式版本控制的 SQL 数据库

综述（解读层）

Dolt 是一个可进行 fork、clone、branch、merge、push、pull 操作的 SQL 数据库，通过系统表、函数和存储过程在 SQL 中暴露版本控制功能，同时提供与 Git 命令对应的 CLI。它内置 MySQL 兼容服务器，支持外键、二级索引、触发器、检查约束和存储过程。适合需要数据版本管理与协作的数据团队；可通过 MySQL 客户端（8.4 及以下版本）连接。

  • 提供 Git 式 CLI 与 SQL 系统表/存储过程两套版本控制操作方式（如 dolt_add、dolt_log）
  • 内置 MySQL 兼容服务器，支持外键、二级索引、触发器、检查约束、存储过程
  • 单二进制约 103MB，支持 Linux/macOS/Windows/Docker 及源码编译安装

适用场景（解读层）

  • 需要分支、合并、提交历史来管理表数据版本变更的场景
  • 通过 DoltHub/DoltLab 共享和托管数据库的场景
  • AI agent 记忆存储（README 提及用于多 agent、多机工作流）
