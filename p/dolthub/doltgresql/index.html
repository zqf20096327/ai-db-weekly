带版本控制功能的 Postgres 兼容 SQL 数据库，可分支合并提交

综述（解读层）

Doltgres 是 Dolt 的 Postgres 方言版本，提供可像 Git 一样进行分支、合并、克隆、推送的 SQL 数据库。用户通过标准 Postgres 协议连接，版本控制操作以系统表、函数和存储过程形式暴露在 SQL 中。数据按目录存储，支持 pg_dump 导入现有 Postgres 数据库。限制包括：无 Git 式 CLI、不支持 GSSAPI、扩展支持有限，部分 Postgres 语法和特性未实现。

  • 支持分支、合并、fork、clone、push/pull 等版本控制操作，通过 SQL 系统表（如 dolt.status、dolt.log）、函数和存储过程暴露
  • 模拟 Postgres 服务器，将 Postgres SQL 解析为 AST 后交由 Dolt 引擎解释，使用与 Dolt 相同的 SQL 引擎和存储格式
  • 提供 Linux/macOS 安装脚本、Windows MSI 安装包、官方 Docker 镜像，并支持源码编译；可用 pg_dump 和 psql 导入现有 Postgres 数据库

适用场景（解读层）

  • 需要表数据/schema 版本历史的 Postgres 应用
  • 需要将数据库变更以分支合并流程管理的团队协作场景
  • 从现有 Postgres 通过 pg_dump 导入数据进行版本化管理的迁移场景
