纯 Go 实现的 SQL 解析器，提供格式化、lint 与安全扫描

综述（解读层）

GoSQLX 是一个纯 Go 编写的 SQL 解析 SDK，通过分词器与递归下降解析器生成 AST，并在此之上实现格式化器、30 条 lint 规则、SQL 注入扫描器与指纹提取。它不负责执行 SQL，而是把 AST 交给使用者处理。支持 PostgreSQL、MySQL 等 8 种方言，提供 CLI、VS Code 扩展、GitHub Action、LSP 与 MCP 服务器等形态，适合需要在 Go 程序或 CI 中解析、检查 SQL 的开发者。

  • 支持 PostgreSQL、MySQL、MariaDB、SQL Server、Oracle、SQLite、Snowflake、ClickHouse 8 种方言，并提供 generic、bigquery、redshift 等名称的方言参数
  • 包含分词器、AST 生成、格式化器、30 条 lint 规则、20 条优化器规则、SQL 注入扫描器与元数据提取
  • 提供 CLI、Go 库、VS Code 扩展、GitHub Action、LSP、MCP 服务器（7 个工具）、WASM playground 与 Python bindings

适用场景（解读层）

  • 在 Go 程序中解析 SQL 并基于 AST 做自定义分析或转换
  • 通过 CLI 或 GitHub Action 在 CI 中校验、格式化和 lint SQL 文件
  • 通过 MCP 服务器将 SQL 分析工具接入 Claude、Cursor 等 AI 客户端
