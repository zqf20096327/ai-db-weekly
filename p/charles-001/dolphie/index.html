🧭 简介解读层（AI·证据行可回查）

基于 TUI 的 MySQL/MariaDB 与 ProxySQL 实时分析监控工具

综述（解读层）

Dolphie 是一个终端界面工具，用于对 MySQL/MariaDB 和 ProxySQL 进行实时数据采集与图表展示。面向数据库运维人员，通过 URI 连接数据库，支持记录会话数据到 SQLite（ZSTD 压缩）并可回放；守护进程模式可后台持续录制。需要 Python 3.10+，最低权限需 performance_schema 的 SELECT 及复制权限。

  • 支持 MySQL/Percona 5.6-9.x、MariaDB 5.5-11.0+、AWS RDS/Aurora、Azure 及 ProxySQL 2.6+
  • 提供 --record/--replay-file 会话录制与回放，支持前进、后退、暂停和按时间戳跳转
  • 提供 --daemon 后台模式持续录制，回放文件为可用任意 SQLite 客户端只读打开的数据库

适用场景（解读层）

  • 运维人员实时查看数据库状态、进程列表与复制延迟等指标
  • 故障或性能问题发生后按时间点回放录制数据进行排查
  • 外部工具读取守护进程生成的回放文件，绘制时间线或采样指标
