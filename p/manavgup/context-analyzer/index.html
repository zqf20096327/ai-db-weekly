面向 AI 编码代理的上下文窗口取证工具，用 Hooks、SQLite 与仪表盘追踪令牌与成本流向

综述（解读层）

Context Analyzer 是用于分析 AI 编码代理（Claude Code、Codex CLI）上下文窗口使用的可观测性工具。它通过 Claude Code Hooks 捕获工具调用、压缩事件与会话生命周期，解析转录中的 API 报告令牌数，存入 SQLite，并在本地仪表盘（端口 8080）提供单会话与跨会话视图。安装依赖 Python 3.11+，通过 uv 或 pip 安装 context-tracker 后运行 context-tracker up，该命令会备份并写入 Hooks 设置，可用 context-tracker down 撤销。压缩上限审计需另装 headroom-ai，报告仅含数字，不包含提示内容。

  • 通过 ~/.claude/settings.json 中的 Hooks 捕获工具调用、压缩事件、会话生命周期与子代理活动，安装器幂等、先备份且可逆
  • 解析转录中的 API 报告令牌数（input、output、cache_read、cache_creation），并支持从 ~/.codex/sessions/ 摄取 Codex CLI 会话
  • 提供单会话仪表盘（上下文增长、缓存读取、构成分解、消息检查器）与跨会话分析页（成本/调用对峰值上下文散点图、汇总卡片、可排序表格），以及离线的 headroom 压缩上限审计命令

适用场景（解读层）

  • 按调用、回合、会话查看令牌与成本分布，定位使会话进入高成本区间的具体回合
  • 通过消息检查器与构成面板查看 Tool I/O、对话与系统前缀的占比，排查残留于每次调用中的陈旧上下文
  • 在 200K/500K/700K/1M 预算阈值下监控使用量，并对本地转录运行离线压缩上限审计
