🧭 简介解读层（AI·证据行可回查）

基于 Redis 修改的数据读取服务，可经连接器直接读取任意数据库

综述（解读层）

Hedis（Hyper Redis）是 Redis 的修改版本，应用服务器从 Hedis 读取热数据；未命中时，Hedis 通过连接器从原始数据库直接取数并存储到自身。连接器在 YAML 配置文件中声明，现有 hbase、mysql 及模板连接器，用 make 构建，以 redis-server --hedis 命令运行。SCAN 等命令标注为 TODO。

  • 通过连接器（HBase、MySQL、模板）直接从原始数据库检索数据并存储到自身
  • 以 YAML 配置文件声明连接器名称、类型及其参数
  • 以 GET [CONNECTOR-NAME]://... 命令语法访问数据

适用场景（解读层）

  • 应用服务器需要绕过回源路径、经中间层直接读取 HBase 或 MySQL 数据的场景
  • 已有 Redis 使用习惯、希望以 GET 命令语法访问后端数据库的场景
  • 需要按连接器模板自行实现新数据库连接器的场景
📖 README 首段存档原文 · 程序抽取

Hedis stands for "Hyper Redis". It can retrieve data from ANY database directly and stores to itself.
