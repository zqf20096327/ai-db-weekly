在 n8n 工作流中本地操作 SQLite 数据库的社区节点

综述（解读层）

这是一个 n8n 社区节点，通过 better-sqlite3 原生绑定在工作流中读写本地 SQLite 文件数据库。提供 Select/Insert/Update/Delete/Upsert 等结构化操作及任意 SQL 执行，凭据中只存数据库文件路径，目录和文件可自动创建。默认禁止在 SQL 查询字段中求值表达式以防注入，可按需开启不安全开关；节点标记为 usableAsTool，可接入 AI Agent 作为工具使用。

  • 提供 Select、Insert、Update、Delete、Create or Update（基于冲突键的 upsert）及 Execute SQL 六种操作，Execute SQL 支持分号分隔的多语句脚本与 DDL
  • 支持 $1、$2 位置参数化查询，Query Parameters 字段可用 n8n 表达式注入上游动态值；默认不在 SQL 查询字段求值表达式以防注入
  • 节点标记 usableAsTool，可作为工具接入 AI Agent；预编译绑定面向 n8n Docker 镜像（node-v127-linux-musl-x64），Docker 外自动回退系统绑定

适用场景（解读层）

  • 在 n8n 自动化工作流中对本地 SQLite 文件执行查询、写入、更新或建表等数据库操作
  • 将数据库操作以工具形式接入 AI Agent，可通过只暴露 Select 等结构化操作限制代理可执行的操作范围
  • 本地开发或小中型项目中无需部署数据库服务器即可在工作流中持久化数据
