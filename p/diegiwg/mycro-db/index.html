基于 JSON 文件或内存存储的 JavaScript 文档数据库管理库

综述（解读层）

MycroDB 是一个 JavaScript 库，用于管理存储在单个 JSON 文件或内存中的文档数据库，通过 npm 安装。它采用集合结构组织数据，提供 insert、update、get、query、remove 等操作，支持批量处理；update 为原子性，仅更新指定字段。提供内存、JSON、TypedJSON 三种存储策略，后者在写入时按 Schema 校验字段结构与类型。查询默认 limit 25、offset 0。适用于 JavaScript 项目的本地文档数据管理场景。

  • 提供 insert/update/get/query/remove 集合操作，支持单条或数组批量传入
  • 内置 MemoryStorage、JsonStorage、TypedJsonStorage 三种存储策略，Typed 策略按 Schema 校验插入与更新
  • query 支持过滤函数、limit 与 offset 分页参数，默认 limit 为 25

适用场景（解读层）

  • 需要将文档数据持久化到单个 JSON 文件的 JavaScript 项目
  • 应用运行期临时存储数据且无需持久化的内存场景
  • 需要字段结构与类型校验的小型文档数据管理场景
