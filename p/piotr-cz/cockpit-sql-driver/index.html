Cockpit CMS 的 SQL 数据库驱动插件，支持 MySQL/MariaDB/PostgreSQL 替代默认 MongoDB/SQLite

综述（解读层）

该插件为 Cockpit CMS 提供 SQL 数据库驱动，使系统能以 MySQL、MariaDB 或 PostgreSQL 作为存储，替代默认的 MongoDB/SQLite。需 PHP 7.1 及 pdo_mysql/pdo_pgsql 扩展，支持手动、CLI 或 Composer 安装，并提供 CLI 数据导出/导入迁移流程。由于 Cockpit 无自定义驱动公开 API，插件通过 monkey-patch MongoHybrid Client 实现，未来版本兼容性无保证；部分集合过滤器未实现或行为有差异。

  • 支持 MySQL 5.7.9+/ MariaDB 10.2.6+/ PostgreSQL 9.4 作为 Cockpit CMS 的存储后端
  • 提供 CLI export/import 命令实现数据库内容迁移
  • 默认为每个集合创建带唯一索引的 _id 虚拟列，并提供手动添加虚拟列与索引的 SQL 示例

适用场景（解读层）

  • 需要使用 MySQL/MariaDB/PostgreSQL 作为 Cockpit CMS 存储的场景
  • 从 MongoDB/SQLite 存储迁移到 SQL 数据库的场景
  • 需要在关系型数据库环境中部署 Cockpit CMS 的项目
