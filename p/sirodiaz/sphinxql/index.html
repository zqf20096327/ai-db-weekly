Node.js 的 SphinxQL 查询构建器，支持 Manticore/Sphinx

综述（解读层）

该包用 TypeScript 编写，为 Node.js 提供 Manticore Search 和 Sphinx Search 的 SphinxQL 查询构建 API，通过链式方法生成 SELECT、INSERT、REPLACE、UPDATE 及事务等语句，默认对查询参数做转义。底层连接基于 mysql2，提供单连接与连接池两种方式；Node.js 版本需不低于 6.x。适合需要在 Node 应用中操作 Manticore/Sphinx 索引的开发者。

  • 提供链式查询构建方法，支持 SELECT/INSERT/REPLACE/UPDATE 及 MATCH、WHERE、OPTION 子句
  • 默认使用转义的查询参数，并支持 ? 占位符的预处理语句与原始查询
  • 支持事务（限 RT 索引）、多语句批处理队列，以及 ATTACH/TRUNCATE/RELOAD/FLUSH/OPTIMIZE 等索引管理语句

适用场景（解读层）

  • 在 Node.js 应用中以构建器方式读写 Manticore/Sphinx 的 RT 索引文档
  • 通过连接池承载多连接的搜索查询服务
  • 需要执行索引维护操作（ATTACH、TRUNCATE、RELOAD、OPTIMIZE）的运维脚本
