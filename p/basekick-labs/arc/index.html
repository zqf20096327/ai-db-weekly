SQL 原生开源时序数据库，以标准 Parquet 文件存储遥测数据

综述（解读层）

Arc 是一个 SQL 原生的开源时序数据库，用 Go 编写并采用 AGPL-3.0 许可。它通过 InfluxDB Line Protocol 或 MessagePack 接收遥测写入，将数据存储为 Apache Parquet 文件（本地磁盘、S3、Azure 或 S3 兼容存储），内部使用 DuckDB 作为查询引擎，并把摄入、压缩、保留策略、连续查询等功能打包为单个二进制文件。README 提供的性能数字基于 MacBook Pro M3 Max 基准测试，官方给出的适用方向包括物联网、日志、可观测性和边缘部署。

  • 兼容 InfluxDB Line Protocol 与 Telegraf，支持 Arrow IPC、MessagePack、JSON 三种查询线路格式，另有可选 Arrow Flight SQL 监听器
  • 数据以标准 Apache Parquet 存储于用户自有基础设施（本地磁盘、S3、Azure、MinIO/R2 等兼容存储），后台自动执行小文件压缩合并
  • 单二进制零依赖运行，包含保留策略、连续查询、认证、备份恢复与企业集群；配套提供自托管控制台 Launchpad 和命令行工具 arcli

适用场景（解读层）

  • 机器、设备、车辆遥测数据的长期全分辨率存储与分析查询
  • 通过 Line Protocol 双写方式从 InfluxDB 体系逐步迁移的既有监控链路
  • 无法连接外部服务（air-gap）或以本地/对象存储自建数据仓的边缘与内网环境
