受 EQL 启发的简化 EDN 查询语言，用于访问 SQL 数据库中的实体

综述（解读层）

seql 是一个 Clojure 库，基于数据式 schema 描述存储在 SQL 数据库中的实体及其关系，通过 next.jdbc、honeysql 和 coax 实现 EDN 风格查询、clojure.spec 记录映射与隐式类型转换。查询支持任意字段返回与嵌套关系展开，变更则需在 schema 中显式声明并附 spec 输入校验，适合需要在 SQL 上使用声明式查询描述的 Clojure 项目。

  • 支持一对多、一对一、多对多关系的嵌套查询，可指定外键以适配任意数据库布局
  • 变更操作需提供输入 spec 并在执行前校验，支持前置条件、多变更事务及通过 mutation-fn 表达任意 honeysql 查询
  • 提供 listener 设施以支持 CQRS 方式，并可从 s/keys spec 推断实体 schema

适用场景（解读层）

  • 在传统 SQL 数据库上使用 EQL 风格的声明式数据查询与嵌套关系展开
  • 需要在入口处对写入操作进行 spec 验证的 Clojure 应用
  • 通过 listener 设施实现 CQRS 架构的系统
