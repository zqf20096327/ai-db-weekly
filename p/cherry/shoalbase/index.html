将 phpMyAdmin 5.2.3 移植到 TypeScript 并运行于 Cloudflare Workers 的数据库管理界面

综述（解读层）

该项目把 phpMyAdmin 5.2.3 的全部路由移植为 TypeScript，运行在 Cloudflare Workers 上，复用 phpMyAdmin 原有的模板、主题与 JavaScript，无需 PHP 或 Web 服务器。每个会话由独立 Durable Object 承载，用户用自己的 MySQL/MariaDB 凭据登录，Worker 通过 TCP 连接数据库。README 声明代码主要由 AI 编写，并建议在生产使用前审查代码。

  • 逐页对照真实 phpMyAdmin 5.2.3 实例进行移植，docs/PARITY.md 记录已知差异
  • TLS 在进程内实现，支持证书固定（MySQL）和 MariaDB 认证后校验两种信任方式
  • 提供单元测试、workerd 会话测试、pma-diff 路由比对、可视化像素对比与约 270 例爬取比对等多层测试

适用场景（解读层）

  • 在无 PHP 环境下通过 Cloudflare Workers 管理 MySQL/MariaDB 数据库
  • 希望界面与 phpMyAdmin 5.2.3 行为一致的数据库管理场景
  • 需要从 Cloudflare 网络以 TCP/TLS 直连互联网可达数据库服务器的场景
