基于种群训练（PBT）的 PostgreSQL 配置自动调优研究工具

综述（解读层）

PBTune 是一个研究性质的开源项目，将 DeepMind 提出的 Population-Based Training 进化算法应用于 PostgreSQL 配置参数调优。它维护多个 worker 各自持有配置并在隔离的数据库实例上并行评估，按代执行截断选择（底部 20% 复制顶部 20%）与扰动（连续参数 ±20%），无需预先训练数据。面向数据库管理员与研究人员，要求 Python 3.11+ 和 PostgreSQL 14+，支持 minimal 到 extensive 四档参数空间（5 至 80+ 个 knob），可通过 --tier、--population、--generations 等 CLI 参数控制调优过程，结果以 JSON 和 HTML 输出。

  • 提供基于 PBT 进化算法的配置搜索：种群 worker 并行评估，周期性执行 exploit（截断选择）与 explore（比例扰动）步骤
  • 提供四档 knob 空间（minimal 5 个至 extensive 80+ 个）与 oltp/olap/mixed 工作负载类型，支持自定义工作负载文件和 sysbench OLTP 基准模式
  • 实现 feature_driven_v2 与 fixed_v1 两种评分策略、百分位指标归一化，以及每 10 代批量重启的重启管理；支持手动分配每个 worker 的 RAM 与 CPU 核数

适用场景（解读层）

  • 为 PostgreSQL 实例自动搜索配置参数值，替代人工或规则方式的 knob 调整
  • 作为研究项目复现或扩展 PBT 在数据库调优领域的实验（配套 research-paper、架构文档与 CI 测试）
  • 在受控环境中对 OLTP 读/写/读写工作负载进行基准化配置评估并生成调优会话报告
