🧭 简介解读层（AI·证据行可回查）

面向 agentic AI 的流式事件平台，融合摄取、增量处理与低延迟查询服务。

综述（解读层）

RisingWave 用 Rust 实现的事件流平台，持续从数据库 CDC、Kafka 等消息队列、webhook 及 S3 批量数据摄取，通过增量物化视图处理并以内置行存提供 SQL 查询，同时写入 Apache Iceberg 表。支持 PostgreSQL wire protocol，兼容 psql/JDBC。状态存于对象存储，可弹性扩展；Iceberg 数据可被 Spark、Trino、DuckDB 等引擎读取。

  • 从 webhooks、数据库事务日志（PostgreSQL/MySQL CDC）、Kafka/Pulsar/Kinesis 及 S3 等存储统一摄取，支持流表自由连接
  • 基于增量计算的物化视图，上游变化时仅重算受影响结果；查询结果由内部行存提供，支持标准 SQL
  • 内置 Iceberg REST catalog，自动执行 compaction、小文件优化与快照清理，数据可被 Spark、Trino、DuckDB 等引擎读取

适用场景（解读层）

  • 实时监控与告警：对流式指标按阈值持续求值
  • 特征工程与特征服务：同一管道上批量与流式特征计算
  • 流式湖仓：以 exactly-once 方式持续写入开放格式表并自动维护
