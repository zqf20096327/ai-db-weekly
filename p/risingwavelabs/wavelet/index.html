🧭 简介解读层（AI·证据行可回查）

基于 RisingWave 的响应式后端，用 SQL 定义计算并自动推送变更结果

综述（解读层）

Wavelet 由 RisingWave 团队开发，让开发者用 SQL 定义查询并订阅结果：底层数据变化时通过 WebSocket 自动推送更新，无需自建 API 或缓存。写入经 HTTP 直接进 RisingWave，物化视图增量重算（约 1 秒）后推送，端到端延迟通常 1-2 秒。服务端无状态，支持 JWT 服务端过滤、MCP 工具调用与类型化客户端生成；租户查询须手动配置 filterBy，否则会广播全部行。

  • 提供 wavelet.config.ts 配置驱动的 DDL 同步与 idempotent CLI（init/dev/push/generate/status）
  • 通过 MCP 暴露 list_queries/query/emit_event/emit_batch/run_sql 等工具供 AI Agent 调用读写
  • 支持 JWT 服务端租户过滤、每查询独立游标与 WebSocket 断线指数退避重连

适用场景（解读层）

  • 实时 SaaS 多租户仪表盘（按租户 JWT 隔离推送指标）
  • 用量计量与计费（流式聚合 API 调用、token 与成本并推送至仪表盘和限流器）
  • 主动式 AI Agent（订阅计算结果，如 SLA 违规行出现时自动升级或触发处理）
