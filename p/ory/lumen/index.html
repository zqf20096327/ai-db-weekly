🧭 简介解读层（AI·证据行可回查）

本地语义代码搜索 MCP 服务器，为 AI 编码代理提供向量化代码检索

综述（解读层）

Lumen 是一个完全本地运行的语义代码搜索引擎，以 MCP 服务器形式接入 Claude Code、Cursor、Codex、OpenCode 等代理。它用 Ollama 或 LM Studio 生成嵌入，按函数/类型等语义分块（Go 原生 AST、其他语言用 tree-sitter），存入 SQLite+sqlite-vec 并以余弦距离 KNN 检索；通过 Merkle 树做增量索引，索引存于仓库外。支持 12 种语言家族和 Git worktree 共享索引，配置经环境变量完成。

  • 支持 12 种语言家族的语义分块索引，Go 使用原生 AST 解析，其余语言使用 tree-sitter 语法
  • 通过 Merkle 树变更检测实现增量索引，Git worktree 之间自动共享索引数据
  • 嵌入与检索完全本地运行（Ollama 或 LM Studio 后端 + SQLite/sqlite-vec），支持 Linux、macOS 和 Windows

适用场景（解读层）

  • 在 AI 编码代理中用 semantic_search 按含义查找函数、类型和模块，替代整文件读取
  • 需要代码与嵌入数据不出本机的本地化开发环境
  • 大型代码库或 monorepo 的增量索引与多 worktree 并行开发场景
