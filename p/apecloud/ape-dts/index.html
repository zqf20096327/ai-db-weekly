🧭 简介解读层（AI·证据行可回查）

基于 Rust 的多引擎数据迁移与 CDC 同步工具，单进程运行。

综述（解读层）

ApeDTS 是 ApeCloud 用 Rust 编写的数据迁移与 CDC 引擎，以单二进制（约 17 MB）形式运行，无外部运行时依赖。它支持 MySQL、PostgreSQL、MongoDB、Redis 等数据源之间的快照迁移、增量同步、数据校验与修订，目标端包括 Kafka、ClickHouse、StarRocks、Doris、TiDB。提供断点续传、Prometheus 指标接口和基于 Lua 的在途数据转换，支持通过 dtscli 命令行管理本地任务。

  • 支持快照迁移、CDC 增量同步、数据校验/修订及结构迁移等多种任务类型
  • 提供基于 checkpoint 的断点恢复、Prometheus 格式指标接口及任务级可观测性
  • 支持库/表/列级过滤路由，并可在传输中执行 Lua 数据转换

适用场景（解读层）

  • MySQL、PostgreSQL 等数据库间的同构或异构数据迁移
  • 通过 CDC 持续同步数据至 Kafka、ClickHouse、StarRocks 等分析引擎
  • 迁移后对源端与目标端数据进行校验与修订
