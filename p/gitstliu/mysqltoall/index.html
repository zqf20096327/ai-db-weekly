🧭 简介解读层（AI·证据行可回查）

基于 MySQL binlog 的数据同步工具，写入多种目标存储

综述（解读层）

MysqlToAll 是一个读取 MySQL binlog 并将数据写入 file、elasticsearch、kafka、redis、redis-cluster、mongodb、TiDB、postgresql 等目标的工具。配置由 canal 配置文件、binlog pos 文件和输出源 config.toml 组成。README 附有 4C 8G 机器上各写入通道的测试数据，具体用法需参见项目文档。

  • 支持将 MySQL binlog 数据写入 file、elasticsearch、kafka、redis、redis-cluster、mongodb、TiDB、postgresql 等目标
  • 通过 canal 配置文件与 binlog pos 文件管理同步位点
  • README 提供 6 个场景在 4C 8G 机器上的测试数据（含 CPU、内存占用与耗时）

适用场景（解读层）

  • 将 MySQL 数据变更同步到 elasticsearch、kafka、redis 等下游存储
  • 多个 MySQL 主库的 binlog 同时写入多个目标通道
  • 使用 pos 文件记录 binlog 位点的增量同步场景
