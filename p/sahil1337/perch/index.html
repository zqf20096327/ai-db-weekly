面向开发者的本地优先轻量 SQL 工作台，支持 PostgreSQL 与 MySQL。

综述（解读层）

Perch 是一个运行在本地的 SQL 工作台，将模式浏览、SQL 编辑、查询执行、结果查看与外键关系图整合在一起，面向需要编写和调试 SQL 的开发者。它以约 14 MB 的单二进制分发，无账号与云服务，SQL 以普通 .sql 文件保存在磁盘。需注意它不内置数据库服务器，需自行连接 PostgreSQL 或 MySQL。MIT 协议。

  • 支持 PostgreSQL 与 MySQL，通过自动发现本机/容器数据库或连接字符串接入，远程连接使用 TLS
  • 提供基于模式元数据的语法高亮与补全、外键关系图（Relationship View），以及按 FROM→JOIN→WHERE 等阶段逐步展示 SELECT 结果的 Query Walk 可视化，使用只读执行
  • 以单个自包含二进制分发（约 14 MB），提供 perch status/stop/update/update --check 等命令，可通过 curl 脚本安装到 macOS、Linux 与 Windows

适用场景（解读层）

  • 需要将 .sql 文件以 notebook 方式组织、逐条运行并保留各自结果与执行时间的开发流程
  • 希望直观理解复杂 SELECT（多表连接、聚合、窗口函数、子查询）各阶段产出行集的学习与调试场景
  • 在本地或远程（Neon、Supabase、RDS 等）数据库上进行无账号、无遥测的本地查询工作
