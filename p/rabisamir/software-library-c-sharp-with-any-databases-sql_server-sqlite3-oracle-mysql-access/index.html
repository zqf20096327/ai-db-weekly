🧭 简介解读层（AI·证据行可回查）

为 C# 桌面项目生成可操作多种数据库的开源库代码的代码生成工具

综述（解读层）

该项目包含两个 C# 代码生成程序：第一个根据用户填写的表名、字段、主外键等数据库细节，生成包含连接信息、SQL 命令生成与执行等类的数据访问库；第二个为每张表生成数据录入与查询界面的 WinForm 代码，界面颜色可由用户指定。支持 Sql Server、SQLite3、MySql、Access 和 Oracle，并可在这些数据库之间迁移数据，生成的代码全部开源可修改。

  • 支持从 Sql Server、SqLite3、MySql、Access、Oracle 五种数据库导入定义并生成代码
  • 生成的库包含数据库信息类、字段信息类、SQL 命令生成与执行类，以及每张表对应的独立类
  • 可生成数据展示与查询两种 Form 界面代码，支持自定义背景色、字体色及查询字段

适用场景（解读层）

  • 为使用 C# 的软件项目或桌面系统生成数据库增删改查代码
  • 在 Sql Server、SqLite3、MySql、Access、Oracle 之间迁移或导入数据库结构
  • 阅读生成的开源类代码以学习 OOP 类组织与数据库编程结构
