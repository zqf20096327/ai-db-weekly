Go 嵌入式持久化键值存储，索引采用内存中的无锁基数树

综述（解读层）

Lunar 是一个面向 Go 语言的嵌入式持久化键值存储，通过 go get 安装，提供 Get/Set 两个基础操作。索引使用仅驻内存的无锁基数树，数据经内存映射文件持久化，打开时自动创建数据与索引文件。作者声明该项目为学习用途构建，可能存在缺陷，尚不建议用于真实工作负载；数据压缩、写同步配置、MVCC 事务仍在计划清单中。

  • 无锁基数树索引，仅保存在内存中
  • 通过内存映射文件（MMAP）实现数据持久化
  • 提供 Get/Set 基本键值读写 API

适用场景（解读层）

  • Go 应用内嵌的键值数据存取
  • 学习嵌入式数据库与无锁索引实现方式
  • 原型验证或实验性场景（README 注明暂不建议用于真实负载）
