SQL Server Profiler 替代工具，基于服务端 trace 的图形化 SQL 跟踪器

综述（解读层）

SqlProfiler 是一款带基础图形界面的 Windows 桌面工具，用于跟踪 SQL Server（2005 及以上，含 LocalDB/Express）的事件。它通过 sp_trace_create 等存储过程在服务端创建 trace，事件流式传输到客户端展示，支持过滤、Top queries 汇总、多种格式导出与 .sptrace 存档。运行需 .NET Framework 4.8 及具备 ALTER TRACE 权限的登录账户，提供免安装的便携版。许可仅限个人及非商业用途。

  • 通过 sp_trace_create/sp_trace_setevent/sp_trace_getdata 实现服务端跟踪，支持 SQL:Batch、RPC、SP:Stmt、Audit Login 等事件及服务端过滤
  • 提供 Top queries 分组统计、T-SQL 语法高亮、快速搜索、事件列表及 XML/Excel/CSV/JSON/.sptrace 导出
  • 支持 Windows 与 SQL Server 身份验证、预设保存、命令行参数、自定义主题及便携模式设置

适用场景（解读层）

  • 在 SQL Server 2005 及以后各版本（含 LocalDB/Express）上捕获并分析 SQL 批处理、RPC、存储过程语句等事件
  • 按 CPU/Reads/Duration/登录名等条件过滤跟踪事件，查看查询的次数与耗时统计
  • 导出捕获的事件为 Excel/CSV/JSON 或 .sptrace 文件供后续查阅
