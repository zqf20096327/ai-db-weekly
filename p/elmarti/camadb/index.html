TypeScript 编写的嵌入式 NoSQL 数据库，支持 Node、Electron 与浏览器环境

综述（解读层）

CamaDB 是一个用纯 TypeScript 编写的嵌入式 NoSQL 数据库，面向 Node、Electron 和浏览器环境。它通过可切换的持久化适配器（fs、indexeddb、localstorage、inmemory）存储数据，查询、更新和聚合采用 MongoDB 风格语法（基于 SiftJS、obop、Mingo）。安装时需同时引入 reflect-metadata。README 明确指出索引和富文本搜索尚未实现，项目仍在开发中。

  • 提供 fs、indexeddb、localstorage、inmemory 四种持久化适配器
  • 查询、更新、聚合均采用 MongoDB 风格语法，基于 SiftJS、obop 和 Mingo 实现
  • 提供完整的 TypeScript 类型支持，可在集合初始化时为列声明数据类型

适用场景（解读层）

  • Electron 主线程中的数据存储场景
  • 需要在浏览器环境中持久化数据的 JS 项目
  • 需要原生 JavaScript 数据类型（如 Date）存取的嵌入式数据库场景
