🧭 简介解读层（AI·证据行可回查）

本地运行的 MCP 服务器，将代码、文档与基础设施索引为持久知识图。

综述（解读层）

codebase-memory-mcp 是一个 MCP 服务器，用 C 后端将代码符号、文档、架构决策和基础设施配置（Docker、Kubernetes、Terraform 等）解析为本地持久知识图，支持 Cypher 查询。面向开发者及其编码代理（如 Claude Code、Cursor 等），安装器支持 46 种客户端集成，暴露 17 个 MCP 工具。索引与图查询在本地完成，无需托管服务或 API key；附带的可视化组件 CBM Lens 处于开放测试阶段（v0.0.1）。

  • 原生 C 后端暴露 17 个 MCP 工具，使用内置语法解析多种语言与文件格式，并为受支持语言提供 Hybrid LSP 类型解析
  • 安装器支持 46 种自动或条件的客户端集成，包括配置、skills、agent profiles 和 hooks
  • 索引范围覆盖代码之外的文档段落、PDF 页面及 Docker、Kubernetes、Helm、Terraform/OpenTofu、Ansible、Make、CI 等基础设施配置

适用场景（解读层）

  • 通过 MCP 为编码代理提供符号、依赖与调用路径等结构化上下文，用于查找不熟悉的功能或跨服务追踪调用
  • 评估某次代码变更可能影响的符号范围，并查找相关测试（实验性 Smart CI 结合静态关系与逐测试覆盖率）
  • 使用 CBM Lens 可视化浏览架构图、3D Galaxy 图与源码阅读器，本地处理、源码分析不出机器的场景
