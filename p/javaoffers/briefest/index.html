综述（解读层）

Brief 是一个 Java ORM 框架，提供 JQL 流式 API，用类型化 Java 代码组合 SELECT/INSERT/UPDATE/DELETE，免写 SQL 字符串与 XML 映射。支持两种模式：无框架依赖的 standalone（brief-speedier）和对既有 MyBatis 项目的增强（brief-mybatis）。要求显式 where() 以防全表扫描；README 自称内部基准约为 MyBatis 的 2 倍（属未经验证的官方数据）。面向需要持久层方案及 MyBatis 增强的 Java 应用。

  • 提供 JQL 流式 API，以类型化 Java 代码组合查询，每步返回类型约束后续可调用方法
  • 提供注解形式的 MySQL 与 JSON 函数集（LEFT、CONCAT、JSON_EXTRACT 等），支持多层叠加组合
  • 支持多表关联的自动一/多对多映射、字段级 AES 加密与脱敏注解、可插拔分表策略、流式查询及 JQL/JDBC 两级拦截器 SPI

适用场景（解读层）

  • Java 应用或框架中需要以类型安全方式编写持久层逻辑的场景
  • 已有 MyBatis 项目希望在保留现有 Mapper 的基础上增加流式查询能力
  • 需要对敏感字段加密、读取脱敏或按策略分表的业务系统
