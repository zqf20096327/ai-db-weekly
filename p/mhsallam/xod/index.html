面向 .NET 的内嵌对象数据库，数据以可读文件（XML/JSON）存储

综述（解读层）

XOD 是一个运行在 .NET 8/9 进程内的嵌入式数据库，无需安装服务器，以 C# 类为模式，将对象持久化为可编辑、可 git diff 的 XML/JSON 文件。它提供事务、主键/唯一/二级索引、多种 join、属性加密和 SQL SELECT 查询，适合桌面应用、独立服务等自持数据的场景。限制包括：单进程独占文件夹、不支持多进程写入与复制/集群。

  • 支持 XML、JSON 和 Brotli 压缩二进制三种存储格式，XodMigrator 可在格式间迁移且无需模型程序集
  • 提供事务（崩溃后未完成提交在下次打开时回滚）、主键/唯一/二级索引、一对多/多对多/自连接、级联删除和 AES-256-GCM 属性加密
  • 内置并发模型为进程内多读取者加排队写入者，README 引用在相关场景下每秒 140,000 次读取；测试覆盖崩溃安全、百万行等并在 Windows 和 Linux 上运行

适用场景（解读层）

  • 桌面应用或自带数据文件夹的服务，需要数据库以目录形式复制、备份或纳入版本控制
  • 无法容纳数据库服务器的设备场景
  • 以批量加载、按键查找、索引查询和分页为主的读多写少型工作负载
