面向 AI 代理开发的数据库隔离技能，为分支提供独立预览库

综述（解读层）

SafeAgentDB 是一个可安装的 agent skill 与基础设施模板集，用于让 AI 代理为每个 Git 分支和 PR 创建带实时预览 URL 的隔离数据库。默认模板面向 Supabase + Vercel + GitHub Actions 栈，其他栈需由代理按其概念模式自行适配。它不是一键式 SaaS 产品，安装后由代理检查项目并规划配置。

  • 为每个分支和 PR 提供独立数据库及实时预览 URL
  • 支持迁移前置检查、仅预览库的功能迁移、从 main 部署生产的流程
  • 提供 PR 关闭时的清理、定时孤儿库清理，以及干跑式配置预演

适用场景（解读层）

  • 多个 AI 代理并行开发并各自运行数据库迁移的场景
  • 需要给用户可测试的 PR 预览链接且不触碰生产数据的团队
  • 使用 Supabase + Vercel + GitHub Actions 的 Next.js 项目搭建分支数据库工作流
