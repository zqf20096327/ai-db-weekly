单 Go 二进制的本地 PostgreSQL 托管控制平面，基于 Docker 管理实例生命周期

综述（解读层）

ODDK 是一个运行于 Linux 宿主机的单 Go 二进制工具，通过 daemon + CLI 将 Docker 容器形式的 PostgreSQL 实例按托管数据库方式管理：创建实例、生成连接串、定时快照并异地备份到 S3、健康监控告警、按需恢复及 dump/restore 大版本升级。面向在自有硬件上需要托管式运维体验的单机运维者。其限制包括：无高可用/复制，仅绑定 127.0.0.1 本地 API，需宿主机直接运行（不可容器化），目标平台为 Linux。

  • 以 Docker 容器运行 PostgreSQL 实例，提供创建、参数组调优、密码与用户管理、小版本切换和 dump/restore 大版本升级
  • 快照包含实例数据与 ODDK 自身配置，可定时执行并加密上传 S3，支持单实例或整机恢复
  • 健康监控支持 Email/Slack/Telegram/Webhook 告警；API 仅绑定 127.0.0.1 并使用 bearer token 认证

适用场景（解读层）

  • 在自有 Linux 服务器上以托管服务方式管理 PostgreSQL 实例的运维场景
  • 需要定时快照加密备份至 S3 并支持整机灾难恢复的单主机部署
  • 为容器化应用提供本机 bridge 网络可达的 PostgreSQL 数据库服务
