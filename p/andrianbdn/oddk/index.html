单二进制 Go 工具，在本地以 Docker 容器提供托管式 PostgreSQL 部署与运维

综述（解读层）

ODDK 是一个 Go 编写的单二进制控制面，由守护进程加 CLI 管理 Linux 主机上以 Docker 容器运行的 PostgreSQL 实例，提供创建、参数组、定时快照并上传 S3、健康告警、还原及 dump/restore 大版本升级。面向在自有主机上自托管数据库的单操作者。限制：不含高可用/复制，API 仅绑定回环地址，需 Linux、Docker 与 systemd。

  • 以单一 Go 二进制实现实例创建、密码/用户管理、参数组和健康监控（Email/Slack/Telegram/Webhook 告警）
  • 快照包含实例数据与自身配置，可定时执行并经加密后离站存储到 S3，支持单实例或整主机还原
  • 通过 dump/restore 执行大版本升级，经测试支持 PostgreSQL 15–19 及 pgvector/postgis 等兼容镜像

适用场景（解读层）

  • 在自有 Linux 服务器上运行 PostgreSQL，获得连接字符串、定时备份与故障通知的托管式工作流
  • 需要将加密快照离站保存到 S3，并能在主机损坏后从单个归档加主密钥重建部署的场景
  • 开发/自托管环境中需以命令快速创建数据库及其属主用户，或在单机上进行大版本迁移
