🧭 简介解读层（AI·证据行可回查）

本地优先的 SQL 分析工作台，将 ClickHouse/Trino 查询结果转为图表与看板

综述（解读层）

Miracle 是运行在个人电脑上的浏览器 SQL 工作台，连接 ClickHouse 或 Trino 执行查询，并把结果快照组织成表格、图表、看板和演示幻灯片。项目数据（SQLite、文档、看板、聊天）保存在项目文件夹的 `.miracle/` 目录中，无需账户或 Docker。界面为俄语，面向桌面浏览器，设计为单机单人使用。

  • 支持多标签 SQL 编辑，含补全、格式化、运行选中片段及按日期分批执行的剩余量估算
  • 查询结果快照保留原始 SQL 与连接上下文，可独立刷新，出错时保留上次结果
  • 提供画布看板、16:9 演示幻灯片、基于 DuckDB 的表格公式模式，以及与本地 Codex CLI / Claude CLI 集成的代理聊天

适用场景（解读层）

  • 在本地对 ClickHouse 或 Trino 数据库编写 SQL 并将结果整理为表格与图表
  • 在同一工作区内组合查询快照、笔记、图形和幻灯片进行展示
  • 按项目文件夹组织分析工作，并通过备份命令迁移或保存完整工作区
