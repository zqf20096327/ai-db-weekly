🧭 简介解读层（AI·证据行可回查）

基于 Docker Compose 的本地开发服务集，按需启停多数据库与工具栈

综述（解读层）

该仓库用单个 docker-compose.yml 打包 PostgreSQL、MySQL、TiDB、MongoDB、Redis 等数据服务及配套 UI。默认仅启动 Portainer，其余服务归入 manual profile，需显式启动且不随守护进程自启；共享网络与 .env 统一凭据。适合需要在本地同时运行多种数据/消息/搜索服务的开发者。

  • 包含 PostgreSQL 18、Redis 6.2、MongoDB、MySQL 8.0、TiDB、MinIO、RabbitMQ、Redpanda、Meilisearch、Mailpit 等 20 余项服务，统一映射在 4601-4634 端口段
  • 默认仅启动 Portainer，其余服务带 manual profile，可按名单独启动或一次性全启，且均不随 Docker 守护进程开机自启
  • 提供 CoreDNS + Nginx 组合实现 *.myapp.local 通配子域名解析，并转发 X-Tenant-ID 请求头用于本地多租户路由

适用场景（解读层）

  • 为本地开发提供按需启停的多种数据库与消息队列实例
  • 通过 Mailpit、MinIO、Redpanda 等替代服务在本地测试邮件、对象存储与 Kafka API 集成
  • 借助 CoreDNS/Nginx 子域名路由在本地调试多租户应用
