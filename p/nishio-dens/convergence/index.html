纯 Ruby 编写的数据库 Schema 迁移工具，用 DSL 定义并同步表结构

综述（解读层）

Convergence 是一个用 Ruby 编写的数据库 Schema 迁移工具，支持 MySQL、PostgreSQL 和 SQLite。使用者以类 Rails DSL 的语法编写 schema 文件，工具通过 export 导出现有库结构、apply 生成并执行差异 SQL，提供 dry-run、safe-migration、--ignore-auto-increment 等选项，还可导出为 Rails migration 文件；DSL 未覆盖的语句可用 execute 执行原生 SQL。安装方式为 gem。

  • 以类 Rails 的 Convergence DSL 定义表结构，支持 25 种列类型、索引、外键和表选项，并可 include 拆分多个 schema 文件
  • 提供 export 导出现有数据库为 DSL 或 ActiveRecord migration 文件，apply 时支持 --dry-run、--rollback-dry-run、--safe-migration、--ignore-auto-increment 等选项
  • 支持 MySQL SSL 连接选项，通过 renamed_from: 声明表/列重命名，execute 语句可运行任意 SQL

适用场景（解读层）

  • 以文件形式管理 MySQL/PostgreSQL/SQLite 数据库的表结构变更
  • 将现有数据库结构导出为 Convergence DSL 或 Rails migration 文件
  • 需要防止误删表（--safe-migration）或避免 AUTO_INCREMENT 值跳变（--ignore-auto-increment）的 schema 同步场景
