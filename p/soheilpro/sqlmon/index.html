从 SQL Server 采集事件并写入 Elasticsearch 的命令行跟踪工具

综述（解读层）

sqlmon 通过 npm 安装，从 SQL Server 采集事件并保存到 Elasticsearch，可配合 sqltop 或 Kibana 分析。它先在服务器临时目录写跟踪文件（需授予服务账户写权限，结束后文件需手动删除），支持设置采集时长、文件大小上限、事件与字段过滤、索引前缀、延迟启动及 hooks。还提供 --collect-only 模式，并可导入 sqlmon 或 SQL Server Profiler 生成的 .trc 文件。

  • 支持采集大量 SQL Server 事件（如 RPCCompleted、SQLBatchCompleted、DeadlockGraph、AuditLogin 等）并可指定字段
  • 提供 QueryHash 等计算字段，去除参数后哈希以便对查询分组
  • 支持通过 --import 导入 sqlmon 或 SQL Server Profiler 生成的跟踪文件

适用场景（解读层）

  • 将 SQL Server 跟踪数据写入 Elasticsearch 后用 Kibana 查询分析
  • 仅采集事件而不落库（--collect-only），或导入现有 .trc 跟踪文件进行分析
  • 通过 hooks 与延迟启动把采集流程集成到定时或自动化脚本中
