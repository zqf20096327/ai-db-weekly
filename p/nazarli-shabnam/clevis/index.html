🧭 简介解读层（AI·证据行可回查）

自托管的 GitHub 组织安全仪表盘，基于 GitHub API 数据生成安全评分与维护自动化。

综述（解读层）

Clevis 是一个自托管面板，通过 GitHub App 或 PAT 连接组织，展示仓库活动、协作者及由六项核心检查（MFA、分支保护、密钥扫描等）计算的安全评分与趋势，并提供带 dry-run 和审计日志的 Actions 缓存清理等维护任务。采用 FastAPI、Next.js 与 PostgreSQL 三服务架构，长任务经 Postgres 队列由后台 worker 执行。适合需要集中查看组织安全状况与执行特权维护操作的自托管场景。

  • 提供基于六项核心检查（MFA 强制、分支保护、密钥扫描、Dependabot 告警、代码扫描告警、默认分支强推保护）与可选卫生检查计算的安全评分，含修复指引
  • 提供带 dry-run 支持与 append-only 审计日志的特权维护任务，任务经 Postgres 队列（SELECT … FOR UPDATE SKIP LOCKED）分发给可多副本运行的 worker
  • 支持 GitHub App 安装令牌（短期 token）或 Fernet 加密的 PAT 两种凭据路径，路由级 JWT 鉴权与组织级 RBAC

适用场景（解读层）

  • 集中查看 GitHub 组织的安全检查状态、评分趋势与仓库活动流
  • 以 dry-run 和审计记录方式执行 Actions 缓存清理等特权维护作业
  • 团队自托管部署，通过 Docker Compose 与反向代理接入现有环境
