面向 PostgreSQL v15+ 实例的监控管理环境，内置可选 AI 智能体

综述（解读层）

pgEdge AI DBA Workbench 是一个用于监控和管理 PostgreSQL v15+ 实例（含 Supabase、Amazon RDS）的统一环境，由 Collector、Server、Alerter、Client 四个组件构成，通过 MCP Server 向语言模型暴露工具与数据源。LLM 可在云端（如 Claude）与本地 Ollama 模型间切换，支持气隙环境。安装方式包括二进制文件、源码构建、Docker 容器及 pgEdge 软件包仓库。

  • 由 Collector（采集指标）、Server（提供 MCP 工具与资源）、Alerter（阈值与 AI 异常检测生成告警）、Client（Web 界面）四个组件构成
  • 架构支持在云端 LLM（如 Claude）与本地 Ollama 模型之间切换
  • 可通过二进制文件、源码构建、Docker 容器或 pgEdge 软件包安装

适用场景（解读层）

  • 监控 PostgreSQL v15+ 实例，包括 Supabase 和 Amazon RDS 等托管环境
  • 在气隙或安全环境中使用本地模型进行数据库诊断
  • 以自然语言查询、分析和管理分布式集群（如 Spock 复制状态与集群配置）
