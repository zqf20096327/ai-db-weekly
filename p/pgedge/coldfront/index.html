🧭 简介解读层（AI·证据行可回查）

PostgreSQL 数据分层扩展：单表冷热分区，热数据在本地分区，冷数据写入 Iceberg 对象存储

综述（解读层）

ColdFront 运行在 PostgreSQL 内部，改写每条 SQL 语句路由到正确的层，应用看到的是同一张表：近期数据存于 PostgreSQL 分区，较老数据存于 S3、Azure 或 GCS 上的 Apache Iceberg，冷层可通过同一 SQL 读写。依赖 pg_duckdb 和 DuckDB 补丁版扩展，配合 Lakekeeper 作为 Iceberg 目录，并提供 archiver、partitioner、compactor 命令行工具。README 标注为 BETA 版，不用于生产环境；支持 PostgreSQL 16/17/18，分布式模式需 pgEdge 带 Spock 的构建。

  • 在 PostgreSQL 内部改写语句并路由到对应层级，应用通过同一关系读写冷热数据
  • 冷层数据以 Apache Iceberg 格式存储于 S3 兼容、Azure 或 GCS 对象存储
  • 提供 archiver、partitioner、compactor 三个命令行工具，配置存于服务器内而非配置文件

适用场景（解读层）

  • 需要将 PostgreSQL 大表的老旧数据归档到对象存储并保持 SQL 可读写的场景
  • 已有 pgEdge Enterprise Postgres（含 Spock）环境，想部署分布式数据生命周期管理
  • 使用 Docker Compose 加 SeaweedFS 本地对象存储搭建开发测试栈
