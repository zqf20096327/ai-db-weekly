命令行工具，将 HTML/RST 等文档转为 Markdown 并载入 PostgreSQL

综述（解读层）

pgEdge Document Loader 是一个 Go 编写的命令行工具，用于将 HTML、Markdown、reStructuredText、DocBook SGML/XML 文档自动转换为 Markdown 并连同提取的元数据写入 PostgreSQL 表。支持从单文件、目录、glob 模式或 Git 仓库读取，可用 YAML 配置文件管理参数，采用事务方式处理（失败自动回滚）。依赖 Go 1.23+ 与 PostgreSQL 14+，需用户预先建好存储表。项目仍在活跃开发中，采用 PostgreSQL License。

  • 支持 HTML、Markdown、reStructuredText、DocBook SGML/XML 格式，统一转换为 Markdown
  • 支持单文件、目录、glob 模式和 Git 仓库 URL 作为输入源
  • 提供元数据提取、自定义元数据列、更新模式与事务性处理（失败自动回滚）；密码可经环境变量、.pgpass 或交互提示提供

适用场景（解读层）

  • 批量将 HTML/RST/DocBook 文档导入 PostgreSQL，为 RAG 检索准备语料表
  • 直接从 Git 仓库克隆并加载项目文档
  • 在文档更新流程中按更新模式维护已有行（插入新行或更新旧行）
