🧭 简介解读层（AI·证据行可回查）

PostgreSQL 扩展，异步分块文本并用 LLM 生成向量嵌入。

综述（解读层）

该扩展为已有文本表自动生成分块表，通过触发器检测变更、后台工作进程异步调用嵌入 API（OpenAI、Voyage、Ollama、Gemini）生成向量。依赖 PostgreSQL 14+、pgvector 和 libcurl，通过 SQL 函数启用/禁用向量化，并提供队列监控视图。支持可配置的分块策略、批量处理与失败重试。

  • 支持 OpenAI、Voyage AI、Ollama、Gemini 四种嵌入提供方，api_url 可覆盖默认端点
  • 源行删除或表清空时自动清理对应分块、嵌入、队列项和 BM25 统计
  • 提供 BM25 稀疏向量与 RRF 融合的混合搜索，参数经 GUC 配置

适用场景（解读层）

  • 为现有 PostgreSQL 文本表构建嵌入分块表以支持向量检索
  • 使用 Ollama 在本地生成嵌入（无需 API key）
  • 结合 BM25 关键词与稠密向量做混合搜索，处理含专有名词的查询
