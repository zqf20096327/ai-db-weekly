开源多模态数据库，用声明式表和计算列统一存储、编排与服务

综述（解读层）

Pixeltable 是一个通过 Python 使用的开源多模态数据库，面向构建处理视频、图像、音频和文档的 AI 应用开发者。用户在 app.py 中声明表、计算列和 HTTP 路由，插入数据后系统自动运行计算、存储结果并更新索引；需 Python 3.11 以上，可通过 pip 安装，支持本地或自托管运行。

  • 支持声明式表、计算列与 FastAPIRouter 路由，插入行后自动执行计算、存储结果并维护嵌入索引
  • 支持增量处理新行、按提供方限制限流重试，以及通过 pxt recompute 选择性重算指定列而保留其余结果
  • 支持本地、自托管基础设施及 Pixeltable Cloud 部署，媒体文件可存本地磁盘或 S3、GCS、Azure 存储桶

适用场景（解读层）

  • 对文档集合进行 RAG 检索，文档增删时自动更新分块与嵌入索引
  • 构建视频和图像处理管线，包含抽帧、转写与检测结果
  • 记录 agent 的工具调用及结果为可查询的表列，并配合记忆表实现跨会话召回
