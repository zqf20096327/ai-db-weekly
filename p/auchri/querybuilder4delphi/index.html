面向 Delphi 12+ 的流式接口 SQL 查询构建器，支持多方言编译与参数化执行。

综述（解读层）

QueryBuilder4Delphi 是一个用 Delphi 12+ 构建参数化 SQL 查询的构建器库，通过流式链式调用生成 SELECT/INSERT/UPDATE 等语句，经方言编译器输出 MSSQL、MySQL、PostgreSQL、SQLite、Oracle、Firebird 六种 SQL。核心仅需 Delphi RTL，可离线构建 SQL，或经可选 FireDAC provider 执行；连接与事务由调用方管理。执行 API 最多暴露一个结果集，不管理连接或自动事务。适用于需要在 Delphi 项目中以类型化、可组合方式生成 SQL 而非拼接字符串的场景。

  • 提供流式链式 API 构建查询，Compile 返回参数化 SQL 与有序绑定，ToDebugSql 输出替换值后的诊断预览
  • 内置 MSSQL、MySQL、PostgreSQL、SQLite、Oracle、Firebird 六种方言编译器，分页等方言差异由编译器处理
  • 提供基于 RTTI 的对象映射（[Column]/[Key]/[Ignore]），支持 ToList/First/Single 及三种 SQL NULL 处理策略

适用场景（解读层）

  • 为 Delphi 应用按方言生成含可选过滤、JOIN、分页的参数化 SQL
  • 通过 FireDAC provider 或自定义 provider 执行查询并映射为普通 Delphi 对象
  • 仅生成 SQL 文本（无需连接数据库）用于诊断或交付给其他执行层
