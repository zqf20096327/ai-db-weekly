用 Go 实现 CodeCrafters「Build Your Own SQLite」挑战的解答仓库

综述（解读层）

该仓库是作者对 CodeCrafters「Build Your Own SQLite」挑战的 Go 语言解答，通过读取 SQLite 原始文件格式，实现基础 SQL 查询、WHERE 过滤、索引检索和 B-tree 遍历。最终实现通过 sqlite-tester v47 全部阶段。仓库自带 sample.db，另两个较大示例库需运行脚本下载。适合想对照学习该挑战的 Go 开发者。

  • 实现读取 SQLite 原始文件格式并执行基础 SQL 查询
  • 支持 WHERE 子句过滤、全表扫描与基于索引的数据检索
  • 通过 sqlite-tester v47 的全部测试阶段

适用场景（解读层）

  • 对照学习 SQLite 文件格式与 B-tree 存储结构
  • 作为 Build Your Own SQLite 挑战的 Go 参考解答
  • 使用附带示例数据库本地测试 SQL 查询实现
