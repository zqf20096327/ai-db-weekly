基于 PostgreSQL 行级安全的 Django 多租户隔离库

综述（解读层）

这是一个通过 PostgreSQL RLS 策略实现租户隔离的 Django 库，隔离发生在数据库层而非应用层，缺失租户上下文时返回零行。模型继承 RLSProtectedModel 即自动获得租户外键、RLS 策略和租户范围管理器。注意：RLS 仅对非超用户、非 BYPASSRLS 的数据库角色生效，且防护的是遗漏租户过滤而非任意 SQL，需 Python 3.12+、Django 5.2+、PostgreSQL 15+。

  • 隔离由数据库 RLS 策略执行，覆盖 ORM、原生 SQL、dbshell 与数据迁移
  • 提供 Celery（@rls_task 跨链/组/和弦传递租户上下文）、DRF、Django Ninja、异步视图集成
  • run_as_tenant / run_for_all_tenants 管理命令按租户运行任务，audit logger 记录上下文进入/退出/拒绝事件

适用场景（解读层）

  • 需要数据库层强制租户隔离的 Django 单库单 schema 多租户应用
  • 含 Celery 异步任务、DRF/Ninja API 或 async 视图的租户系统
  • 需要按租户批量执行管理命令（报表、回填、重建索引）的运维场景
