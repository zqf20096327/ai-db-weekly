🧭 简介解读层（AI·证据行可回查）

基于 Java 8 零依赖内核的数据库迁移工具，提供 CLI、本机 GUI 与 Agent 接入三入口

综述（解读层）

Flydb 是面向开发、运维和实施人员的数据库版本迁移工具，以 GUI、CLI 和 Java API（含 Spring Boot 2/3 starter）三种入口共用同一配置与迁移引擎。机制包括 checksum 校验、并发锁、SQL 预览与执行记录；支持 MySQL、PostgreSQL、Oracle 及达梦、金仓等国产数据库，可通过 DatabaseType SPI 扩展其他 JDBC 数据库，但不自动翻译不同方言间的 SQL。

  • 提供 SQL 预览、checksum 校验、并发锁与失败阻断，GUI 与同机 CLI 共用执行记录
  • Java 8 内核无第三方运行时依赖，各模块已发布至 Maven Central，支持 Spring Boot 2/3 starter
  • 内置多种数据库方言并支持 DatabaseType SPI 扩展；提供 Skill、JSON 与 MCP 方式供 Agent 接入

适用场景（解读层）

  • 在开发、测试、生产多套环境间以版本化脚本（V/R/U 命名）管理数据库结构变更
  • 通过 CLI 命令与环境变量配置在 CI/CD 流水线中自动执行迁移与校验
  • 在应用启动期间由 Spring Boot starter 自动执行 migrate，或让 AI Agent 按 AGENTS.md 指引处理迁移任务
