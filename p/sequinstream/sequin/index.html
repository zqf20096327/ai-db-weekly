Postgres 变更数据捕获平台，以 Docker 容器部署，将变更流式传输到多种下游。

综述（解读层）

Sequin 是一个面向 Postgres 的变更数据捕获（CDC）平台，以独立 Docker 容器部署在 Postgres 旁，支持 Postgres 14 及以上版本。它将指定 schema 和表的变更实时流式传输到 Kafka、SQS、Elasticsearch 等 17 种 sink，支持回填存量数据、过滤、转换、按幂等键实现恰好一次处理，并重试失败投递。可通过 Web 控制台、YAML 配置加 CLI 或 Management API 管理，提供 Prometheus 指标端点。

  • 支持 Kafka、SQS、GCP Pub/Sub、Elasticsearch、Typesense、Redis、NATS、RabbitMQ、Webhook 等 17 种 sink
  • 支持回填存量行与实时流式传输新变更，提供过滤、转换、路由和基于幂等键的恰好一次处理
  • 以独立 Docker 容器运行，兼容任意 Postgres 14+，提供 Web 控制台、YAML 配置、Management API 和 Prometheus 指标端点

适用场景（解读层）

  • 将数据库变更作为事件发布到 Kafka、SQS、Pub/Sub 供其他服务消费
  • 通过流式变更同步 Redis 缓存或维护 Typesense、Elasticsearch 搜索索引
  • 记录数据库的全部变更用于审计日志或合规需求
