基于 PDO 的 PHP 数据库库，统一 API 支持六种数据库及查询构建器

综述（解读层）

PDOdb 是无框架依赖的 PHP 数据库库，基于 PDO 以流式查询构建器统一操作 MySQL、MariaDB、PostgreSQL、SQLite、SQL Server 和 Oracle。它提供窗口函数、CTE、JSON 辅助、迁移、可选 ActiveRecord 层，并可将执行计划、列和索引发送到用户配置的 AI 提供方生成查询建议。需 PHP 8.4+，MIT 许可。

  • 统一 API 覆盖六种数据库，提供流式查询构建器、窗口函数、递归 CTE、LATERAL 连接及各方言原生全文搜索
  • 包含 PSR-16 缓存、读写分离、分片、流式读取、迁移与回滚、事务保存点及事务性 outbox
  • 可收集执行计划、列与索引信息发送至配置的 AI 提供方生成查询建议，并提供 CLI 迁移、outbox worker 与终端面板工具

适用场景（解读层）

  • 同一项目中需连接多种数据库并保持一致的构建器调用方式
  • 需要通过读取执行计划与索引信息来排查慢查询的场景
  • 不依赖框架的 PHP 应用中需要查询构建器、迁移或可选 ActiveRecord 层
