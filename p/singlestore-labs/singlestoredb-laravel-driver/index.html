SingleStoreDB 官方 Laravel 数据库驱动，基于 MySQL 驱动扩展

综述（解读层）

该仓库是 SingleStoreDB 的官方 Laravel 驱动，通过包装 Laravel 原生 MySQL 支持使其适配 SingleStoreDB，供在 Laravel 应用中使用 SingleStoreDB 的 PHP 开发者使用。它扩展了 Eloquent 迁移 API 以支持 SingleStoreDB 特有功能（rowstore、reference、全局临时表、shard key、sort key 等），并提供 JSON 列支持与查询生成兼容性修复。安装依赖 pdo_mysql 扩展；文档提及若干限制，如不支持 DELETE/UPDATE 中的 ORDER BY 子句，以及唯一键需包含 shard key 的约束。

  • 扩展 Eloquent 迁移 API，支持 rowstore、reference、全局临时表、sparse 列、shard key、sort key、unique key 等 SingleStoreDB 特性
  • 支持 JSON 列，并对查询生成提供兼容性修复
  • 支持启用 PDO::ATTR_PERSISTENT 持久连接，并可通过配置忽略 DELETE/UPDATE 中的 orderBy

适用场景（解读层）

  • 在 Laravel 应用中将 SingleStoreDB 作为默认数据库连接，包括队列失败任务存储
  • 需要通过迁移创建 SingleStoreDB 各类表结构（通用存储/行存/参考表等）
  • 连接 SingleStore Managed Service 时需配置 SSL 证书的场景
