SingleStore 开发用 Docker 镜像，一键启动单聚合器+叶子节点集群

综述（解读层）

该项目提供 SingleStore 数据库的 Docker 开发镜像，面向本地开发和 CI/CD 环境。运行后创建一个 Master Agenerator 加一个叶子节点的集群，主机 8 核 64GB 内存内无需许可证。暴露 3306（MySQL 协议）、8080（Studio UI）、9000（Data API）端口；官方明确说明不适用于生产负载或基准测试。

  • 通过 docker run 启动包含一个 Master Aggregator 和一个叶子节点的 SingleStore 集群，8 核/64GB 资源内无需许可证
  • 支持 MySQL 兼容客户端连接（端口 3306）、浏览器 Studio UI（8080）与 JSON over HTTP 的 Data API（9000）
  • 默认启用 Wasm 函数（Code Engine），支持挂载 /data、/logs 等卷持久化，并可通过 /init.sql 初始化数据库

适用场景（解读层）

  • 本地笔记本上的 SingleStore 应用开发与 SQL 测试
  • GitHub Actions 等 CI/CD 流水线中运行数据库集成测试
  • 通过挂载 init.sql 和 Docker 卷搭建可重复初始化的开发/测试环境
