一个用于在 Windows 上编译 SQLCipher 加密 SQLite 的 CMake 脚本

综述（解读层）

该项目提供一组 CMake 脚本，用于构建 SQLCipher 加密库、SQLite shell 程序和 Qt4 SQL 插件，支持 Microsoft 编译器和 MinGW。使用者需自行准备 SQLCipher、SQLite amalgamation、OpenSSL 源码，并在 CMakeLists.txt 中配置源码路径变量。README 注明测试过的版本为 SQLCipher-2.0.6、SQLite-3.7.14.1、Qt-4.8.3、OpenSSL-1.0.1b。

  • 提供 OPENSSL_MT、OPENSSL_STATIC、BUILD_QT_PLUGIN、BUILD_SHELL 等 CMake 选项控制构建内容
  • 支持 MSVC（NMake）和 MinGW（MSYS Makefiles）两种编译环境
  • 可同时生成 SQLCipher 库、SQLite shell 和 qsqlcipher4 Qt 插件

适用场景（解读层）

  • 在 Windows 上使用 MSVC 或 MinGW 编译带加密功能的 SQLite
  • 需要构建 Qt4 的 SQLCipher 数据库驱动插件
  • 将加密 SQLite 以静态 OpenSSL 库或 MT 运行时方式集成
