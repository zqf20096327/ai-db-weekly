🧭 简介解读层（AI·证据行可回查）

Go 编写的 WebSocket 服务，基于 Postgres 逻辑复制至少一次地流式传输变更

综述（解读层）

PGDeltaStream 是一个 Golang webserver，通过 Postgres 逻辑解码功能把表变更以 WebSocket 流式推送，保证至少一次送达。工作流分三阶段：init 创建复制槽、snapshot 经 HTTP 获取快照数据、stream 经 WebSocket 推送 WAL 变更；客户端可通过 ACK LSN 偏移量实现断线续传。README 提示其定位为参考样板服务，不应直接向任意客户端暴露 WebSocket，且目前仅支持单复制槽会话，调用 /v1/init 会删除并重建已有槽。

  • 分三阶段工作流：/v1/init 创建复制槽、/v1/snapshot/data 经 HTTP 读取快照数据（支持分页与排序）、/v1/lr/stream 经 WebSocket 流式推送 WAL 变更
  • 变更记录包含操作类型（create/update/delete）、表信息、旧值、新值及 nextlsn；客户端可通过 WebSocket 发送 lsn 进行 ACK，重连后从最后 ACK 的偏移继续流式传输
  • 通过环境变量（DBNAME、PGUSER 等）配置连接，以 Docker 镜像方式运行，需 Postgres 开启逻辑复制并安装 wal2json 插件

适用场景（解读层）

  • 需要监听 Postgres 表插入、更新、删除事件并经 WebSocket 推送给后端服务的场景
  • 需要快照初始数据与后续增量变更衔接、且事件不丢失的 CDC 数据管道原型
  • 作为参考样板，学习如何用 Go 连接 Postgres 逻辑复制槽并流式读取 WAL 变更
