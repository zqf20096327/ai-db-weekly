基于数据库自动生成 GraphQL API 的开源引擎

综述（解读层）

Hasura GraphQL Engine 是一个开源服务，通过单一 API 端点提供对数据的访问，并在数据库事件发生时触发 webhook。项目采用 monorepo 结构，包含 V2（当前稳定版本）与 V3（驱动 Hasura DDN）两个引擎；V3 通过 Data Connectors 连接数据源，支持 PostgreSQL、MongoDB、ClickHouse、MS SQL Server 等。适用于需要为既有数据库生成 API 的后端与全栈开发者。仓库较大，首次克隆建议使用 shallow clone 或 sparse-checkout。

  • 通过单一、可组合的 API 端点提供数据访问，并支持在数据库事件发生时触发 webhook
  • V3 引擎通过 Data Connectors 连接数据源，支持 PostgreSQL、MongoDB、ClickHouse、MS SQL Server，并提供 TypeScript、Python、Go 的 Connector SDK 用于编写自定义业务逻辑
  • 核心引擎与所有 Data Connectors 以 Apache License 2.0 开源发布

适用场景（解读层）

  • 为 PostgreSQL、MongoDB、ClickHouse、MS SQL Server 等数据源生成 GraphQL API
  • 基于数据库事件触发 webhook 实现数据变更联动
  • 使用 TypeScript、Python、Go Connector SDK 接入自定义数据源或业务逻辑
