🧭 简介解读层（AI·证据行可回查）

Hasura 数据连接器代理的 SQLite 实现，将本地 SQLite 数据库以 GraphQL 接口暴露。

综述（解读层）

该项目是面向 Hasura GQL Engine 的 SQLite 数据连接器代理，基于 NodeJS 实现，可将本地 SQLite 数据库文件通过 GraphQL schema 和查询接口暴露。支持关系、聚合、变更、原生查询与 Prometheus 指标，但不支持订阅类能力。运行依赖 SQLite >= 3.38.0 的 JSON 聚合函数，可通过环境变量控制只读、数据库白名单等行为。仓库为上游镜像。

  • 支持 GraphQL schema、查询、关系、聚合、变更与原生（插值）查询，不支持订阅
  • 提供数据库只读、创建、白名单、CORS、日志级别等环境变量配置
  • 支持数据集模板克隆操作与 /capabilities、/metrics 端点

适用场景（解读层）

  • 为 Hasura GQL Engine 接入本地 SQLite 数据库文件
  • 以 GraphQL 方式查询和变更 SQLite 数据
  • 通过数据集模板机制创建测试用数据库副本
