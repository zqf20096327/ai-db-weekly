基于 PostgreSQL 逻辑复制的 Java 工具，将数据库变更发布到 Kinesis

综述（解读层）

pg2k4j 用于将 PostgreSQL 的插入、更新、删除操作发布到 Amazon Kinesis 流。它通过逻辑复制槽读取 WAL 变更，经 wal2json 插件反序列化为消息后经 Kinesis Producer Library 写入，确认写入成功才推进序列号，以保证变更到达 Kinesis。可用 Docker 独立运行，也可作为 Java 库嵌入并扩展。README 标明该项目已不再由 Disney Streaming 积极维护，支持有限。

  • 支持将 PostgreSQL 的插入、更新、删除变更通过逻辑复制槽发布到 Kinesis 流
  • 提供 Docker 独立运行方式，并发布 Maven/Gradle/SBT 构件供作为 Java 库使用
  • 写入成功确认后才推进复制槽序列号，并在闲置 5 分钟（默认）后推进以避免 WAL 堆积

适用场景（解读层）

  • 需要将 PostgreSQL 数据变更流式发布到 Kinesis 供下游消费的场景
  • 需要以 JVM 应用集成了 Amazon Kinesis Producer Library 的事件发布管道
  • 已有逻辑复制配置的 PostgreSQL（含 RDS）环境
