面向 Rails 的异步优先搜索抽象层，以可链式 DSL 统一多搜索后端

综述（解读层）

Noiseless 是一个 Ruby gem，为 Rails 应用提供搜索抽象层，通过统一的链式 DSL 支持 OpenSearch、Elasticsearch、Typesense 和 PostgreSQL（含 pgvector）四种后端。它构建于 Ruby 4.0+ 的 fiber scheduler 之上，.execute 返回 Async::Task 对象，并经 Async::Pool 提供 HTTP/2 连接池。要求 Ruby >= 4.0 且 Rails >= 8.1，采用 BSD 3-Clause 许可。

  • 提供带运行时校验的链式查询 DSL，通过适配器连接 OpenSearch、Elasticsearch、Typesense 与 PostgreSQL 四种后端
  • 基于 Ruby fiber scheduler 实现非阻塞 I/O，execute 调用返回 Async::Task，支持在单个 Async 块中并发执行多个搜索
  • 提供分页器、多搜索（MultiSearchResponse）、record_class 记录加载，以及带 VCR 磁带自动命名的测试辅助模块

适用场景（解读层）

  • Rails 应用需要在多个搜索后端（OpenSearch、Elasticsearch、Typesense、PostgreSQL）间切换或并存
  • 需要在同一异步上下文中并发执行多个搜索请求以获取结果的场景
  • 搜索后将结果映射回 ActiveRecord 记录，或需要懒执行分页与多模型搜索的查询流程
