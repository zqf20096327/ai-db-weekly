为 ActiveRecord PostgreSQL 适配器提供 PostGIS 空间类型与查询的扩展 gem

综述（解读层）

这是一个 Ruby gem，通过扩展现有 PostgreSQL 适配器为 Rails 8.1+/Ruby 3.3+ 应用添加 PostGIS 支持。使用标准 postgres:// URL，无需自定义适配器名。迁移中支持 st_point 等空间列类型，模型自动解析/序列化空间属性，查询可经 RGeo 对象、Arel 方法或 WKT 字符串进行。依赖 PostGIS 扩展的数据库。

  • 提供 st_point、st_polygon、st_geography 等空间列类型，支持 SRID 与 Z/M 维度
  • 提供 st_distance、st_dwithin、distance_operator（KNN）等空间查询方法及自定义 Arel visitor
  • 内置测试辅助工具：空间断言、可链式列断言与几何工厂方法

适用场景（解读层）

  • 在 Rails 应用中存储和查询地理/几何数据（如距离检索、缓冲区分析）
  • 需要对空间列编写带断言和几何工厂的测试
  • 使用标准 postgresql 适配器配置的多数据库项目接入空间类型
