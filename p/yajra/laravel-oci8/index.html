基于 OCI8 扩展的 Laravel Oracle 数据库驱动包

综述（解读层）

Laravel-OCI8 是 Illuminate/Database 的扩展包，通过 PHP OCI8 扩展使 Laravel 框架连接 Oracle 数据库，供使用 Laravel 且后端为 Oracle 的应用使用。安装方式为 composer require yajra/laravel-oci8，兼容 Laravel 5.1 至 13.x。其 Schema Builder 对不同 Oracle 版本（11g 为基线至 21c）生成不同 SQL，部分 Laravel 构建器操作不被支持或为空操作；不支持通过 schema builder 创建或删除数据库。

  • 扩展 Illuminate/Database，经由 OCI8 扩展与 Oracle 通信，兼容 Laravel 5.1–13.x
  • 支持 JSON 查询与 JSON 路径更新（后者需 Oracle 19c+，JSON 功能整体需 12cR2+）
  • 提供 Schema Builder 兼容表，明确列出支持、不支持（如 createDatabase、geometry）及空操作项

适用场景（解读层）

  • Laravel 应用需连接 Oracle 数据库的项目
  • 需要通过 Laravel Schema Builder 在 Oracle 上建表、索引与外键的迁移场景
  • 使用 Oracle 用户认证并需处理大小写敏感查询的 Laravel 认证场景

Laravel-OCI8 is an Oracle Database Driver package for Laravel. Laravel-OCI8 is an extension of Illuminate/Database that uses OCI8 extension to communicate with Oracle. Thanks to @taylorotwell.
