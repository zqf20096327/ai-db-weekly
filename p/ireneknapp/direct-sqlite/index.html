面向 Haskell 的低层 SQLite3 绑定库

综述（解读层）

direct-sqlite 是为 Haskell 提供的 SQLite3 低层绑定。相比 bindings-sqlite3，它在层次上略高，支持数据库值的封送处理，包括 UTF-8 编码的字符串和以 ByteString 表示的 BLOB。项目发布于 Hackage，贡献者提交 PR 前需先阅读其贡献指南。

  • 提供 SQLite3 的低层 Haskell 绑定
  • 支持数据值与数据库之间的封送（marshalling）
  • 支持 UTF-8 字符串和以 ByteString 表示的 BLOB

适用场景（解读层）

  • 在 Haskell 程序中读写 SQLite 数据库
  • 需要处理 UTF-8 字符串或 ByteString 类型 BLOB 数据的场景
  • 希望直接使用 SQLite3 底层接口的 Haskell 项目
