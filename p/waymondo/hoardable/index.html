基于 PostgreSQL 单时态继承表实现 ActiveRecord 记录版本化与软删除的 Ruby gem

综述（解读层）

Hoardable 是面向 Ruby 3+/Rails 7+/PostgreSQL 9+ 的 ActiveRecord 扩展，利用 Postgres 表继承特性为模型动态生成 Version 子类，将记录的每次更新和删除以带时间范围的只读版本存入继承表。支持 revert!/untrash! 回滚恢复、at 时点查询及 whodunit/meta 上下文记录。适用于 Rails 应用。

  • 通过 PostgreSQL 表继承自动为模型生成只读的 _versions 版本表，版本记录带 _during 时间范围与 jsonb 上下文数据
  • 支持 version.revert! 回滚、version.untrash! 以原主键恢复已删除记录、.at 方法按时间点查询历史状态
  • 提供全局与模型级配置项（enabled/version_updates/save_trash），支持 STI 及 belongs_to/has_many 的 trashable/hoardable 选项

适用场景（解读层）

  • Rails 应用中需要对记录修改历史进行审计追溯与查询的场景
  • 需要软删除并能在事后恢复数据及其指定历史版本的业务
  • 需要查询某模型（含关联）在过去某一时间点状态的数据回溯需求

Hoardable is an ActiveRecord extension for Ruby 3+, Rails 7+, and PostgreSQL 9+ that allows for versioning and soft-deletion of records through the use of _uni-temporal inherited tables_.
