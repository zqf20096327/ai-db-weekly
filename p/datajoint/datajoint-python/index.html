基于关系工作流模型的 Python 科学数据管道框架，数据库模式即可执行规范

综述（解读层）

DataJoint for Python 是一个面向科学数据管道的开源框架（Apache-2.0），实现了关系工作流模型：用数据库表表示工作流步骤，外键编码依赖关系，父表需先于子表填充。使用者通过声明式定义计算内容，由框架调度执行时机，结果不可变以支持数据溯源。可通过 pip 或 conda 安装，支持 MySQL 与 PostgreSQL。

  • 以数据库表表示管道步骤，外键编码表间依赖，父表须在子表之前填充
  • 计算采用声明式定义，框架负责调度执行时机，结果不可变以保留完整数据血缘
  • 支持通过 pip 或 conda-forge 安装，后端支持 MySQL 与 PostgreSQL

适用场景（解读层）

  • 构建需要数据溯源与血缘记录的科学计算数据管道
  • 神经科学领域可参考 DataJoint Elements 提供的示例管道
  • 从 pre-2.0 旧版升级的项目可参考官方迁移指南
