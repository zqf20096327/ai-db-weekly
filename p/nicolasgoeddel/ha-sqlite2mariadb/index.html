将 Home Assistant 的 SQLite 数据库迁移至 MariaDB 的 Bash 脚本

综述（解读层）

这是一个用于 Home Assistant 的数据库迁移脚本，通过停止 HA、导出 SQLite 表数据、转换 schema 并导入 MariaDB 的方式完成迁移。面向需要更换 recorder 数据库后端的 Home Assistant 自托管用户。脚本按七个可选步骤交互执行，导入时关闭外键检查并在单事务中执行；已在 Home Assistant 2024.6.3 的 Docker compose 部署上测试。迁移期间 HA 重启后写入的数据不会包含在本次迁移中。

  • 交互式分步执行：停止 HA、导出各表数据与 schema、转换列类型、重建表并导入数据
  • 导入阶段禁用外键检查、关闭 autocommit，在单一事务中完成数据写入
  • 包含独立的 sqlite2mariadb.sh 脚本，可将 SQLite schema 文件转换为 MariaDB/MySQL 兼容 schema 并输出到标准输出

适用场景（解读层）

  • Home Assistant 长期未清理 recorder 数据、SQLite 数据库文件体积较大时的数据库后端更换
  • 使用 Docker compose 同时运行 Home Assistant 与 MariaDB 的部署环境
  • 仅需将 SQLite schema 转换为 MySQL/MariaDB 兼容格式的场景（使用独立转换脚本）
