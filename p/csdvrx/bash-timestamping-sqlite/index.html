🧭 简介解读层（AI·证据行可回查）

用 bash 函数将命令历史写入 SQLite 的命令行时间戳记录工具

综述（解读层）

该项目通过纯 bash 函数把 bash 命令历史替换为基于 SQLite 的后端，在提示符中显示命令时间戳与返回错误码，并用 fzy 提供交互界面、附带 SQL/gnuplot 分析脚本。安装方式为将 bashrc.txt、bash_profile.txt、bash_logout 内容分别加入对应文件。README 明确指出数据库记录不可防篡改，适合需要操作日志或个人分析的用户。

  • 用纯 bash 函数将命令历史写入 SQLite 数据库（~/.bash_history-$HOST.db），可用 SQL 查询分析命令使用情况
  • 提示符显示所输入命令的时间戳及其返回的错误码，交互界面基于 fzy
  • 附带 gnuplot 绘图与分析 SQL 脚本，支持可选的 GNU screen 会话自动记录

适用场景（解读层）

  • 需要留存操作时间与执行者记录的审计/运维场景（README 提示该记录不可防篡改）
  • 对个人命令行使用习惯做统计分析，如各时段命令成功率、最常用命令
  • 查询长任务启动时间与耗时，辅助部署和编写文档时的回顾
