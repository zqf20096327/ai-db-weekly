基于 MySQL LOAD DATA/SELECT INTO 语句的 pandas DataFrame 读写工具包

综述（解读层）

pd2ml 是一个 Python3 包，用于在 pandas DataFrame 与 MySQL 表之间上传和下载数据，底层使用 LOAD DATA LOCAL INFILE 与 SELECT INTO OUTFILE 语句实现。依赖 pandas、NumPy 和 SQLAlchemy，通过 pip 安装。使用时需在连接串加 local_infile=1，并在 MySQL 配置中设置 secure-file-priv 为空。README 附有作者笔记本上的对比测试数据。

  • 提供 load_to 与 load_from 接口，支持 DataFrame 与 MySQL 表互传
  • 支持 pandas 扩展方式调用及多进程/多线程配合使用
  • README 包含与多值 INSERT/REPLACE SQL 及 pandas read_sql_table 的耗时对比测试

适用场景（解读层）

  • 将 csv 等来源的 DataFrame 批量写入 MySQL 表
  • 从 MySQL 表读取数据到 DataFrame 进行后续处理
  • 配合多进程/多线程拆分数据进行批量导入导出
