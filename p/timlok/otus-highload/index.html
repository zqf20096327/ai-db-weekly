基于 Ansible 自动化部署的 Zabbix 高可用高负载测试环境项目

综述（解读层）

这是一个面向高负载场景的组织故障可容错 Web 应用（Zabbix）的教学研究项目。通过 Ansible 自动化部署包含 HAProxy/Keepalived 负载均衡、Pacemaker/Corosync 集群、Patroni/PostgreSQL 数据库、Consul 服务发现、Odyssey 连接池等多组件的完整环境，支持 Vagrant 和 Proxmox 两种部署方式。适用于需要学习或搭建基础设施即代码的高可用监控环境测试的用户。

  • 通过 Ansible roles 自动化部署，包含负载均衡、Web集群、数据库集群等完整层次
  • 采用 Patroni/PostgreSQL 实现数据库故障转移，Keepalived 管理 VIP 地址漂移
  • 使用 Pacemaker/Corosync 管理 zabbix-server 与 mamonsu 资源，支持节点宕机自动恢复

适用场景（解读层）

  • 需要搭建故障可容错 Zabbix 监控环境并验证任意主节点宕机后仍可正常工作的场景
  • 用于负载测试实验中观测集群各节点及数据库的运行指标
  • 需要学习 Patroni/Consul/vip-manager/Odyssey 等组件在真实环境中的组合部署
