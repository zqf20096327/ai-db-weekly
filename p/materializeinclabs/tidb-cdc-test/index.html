🧭 简介解读层（AI·证据行可回查）

TiDB 经 Kafka 同步至 Materialize 的 CDC 概念验证，含并行可续传快照加载器。

综述（解读层）

该项目是一个概念验证：通过 TiCDC 的 Avro 协议与 Materialize 的 ENVELOPE UPSERT，将 TiDB 数据经 Kafka 以 exactly-once 语义接入 Materialize，并验证了初始快照到增量 CDC 的衔接。快照加载器 snapshot.py 采用多进程、PK 范围分块与 JSON 检查点实现断点续传。仓库提供 docker-compose 栈（TiDB v8.5、Kafka、Schema Registry、Materialize）及 parity 测试脚本。限制：仅支持单列整数主键，不支持 CDC 期间的 DDL。

  • 单跳管道：TiCDC Avro 协议原生输出 UPSERT 形状消息，Materialize 直接以 ENVELOPE UPSERT 消费，无需变换 sidecar 或 rekey 作业
  • snapshot.py 支持多进程、PK 范围分块、逐语句 AS OF TIMESTAMP 读取及 JSON 检查点续传
  • 提供 make up / make reset 的 docker-compose 栈（TiDB v8.5.0、Kafka KRaft、Schema Registry、Materialize v0.130.0）及 tests/parity.py 逐行比对脚本

适用场景（解读层）

  • 评估 Materialize 消费 TiDB CDC 数据的可行性验证
  • 对大规模 TiDB 表做可断点续传的初始快照加载
  • 研究 TiCDC Avro 输出格式与 Materialize 数据源配置方案
