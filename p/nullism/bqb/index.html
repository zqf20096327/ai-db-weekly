Go 语言 SQL 查询构建器，支持 ? 与 $ 两种占位符语法

综述（解读层）

BQB 是一个 Go 语言的查询构建库，用于以追加方式组合 SQL 片段并管理参数。它通过 ToSql/ToPgsql 输出对应占位符格式的语句，支持切片自动展开、JSON 辅助类型、driver.Valuer 与 Embedder 接口。README 说明已在 sqlite、Postgres、MySQL 上测试，要求 Go 1.20 以上（v1.4.0+）。

  • 同一查询可通过 ToSql() 与 ToPgsql() 分别生成 ? 和 $N 占位符格式
  • 支持 []string、[]int、[]any 等切片参数自动展开为多个占位符
  • 提供 JsonMap/JsonList 辅助类型、Folded 类型及 driver.Valuer、Embedder 接口

适用场景（解读层）

  • 需要在 MySQL 与 Postgres 等不同占位符语法之间切换的应用
  • 根据条件动态拼接 WHERE 子句等 SQL 片段的场景
  • 需要将 Go 结构化数据（切片、JSON、driver.Valuer）作为查询参数的场景
