🧭 简介解读层（AI·证据行可回查）

VS Code 数据库客户端扩展，支持多类型数据库管理与 SSH 连接

综述（解读层）

该扩展在 VS Code 内提供数据库连接、表数据查看与修改、SQL 查询执行、备份导入导出、Mock 数据生成及查询历史等功能。支持 MySQL/MariaDB、PostgreSQL、SQLite、Redis、ClickHouse、达梦、ElasticSearch 等多种数据库，亦可作为 SSH 客户端使用。仓库中仅包含早期源码，新版本为闭源。适合需要在编辑器内直接操作数据库的开发者。

  • 支持 MySQL/MariaDB、PostgreSQL、SQLite、Redis、ClickHouse、达梦、ElasticSearch 连接，并可作 SSH 客户端
  • SQL 编辑器提供 IntelliSense、代码片段及快捷键执行选中或全部 SQL
  • 提供备份导入导出、Mock 数据生成、查询历史记录，依赖 mysql_dump/pg_dump 等工具可实现备份

适用场景（解读层）

  • 在 VS Code 中通过 Database Explorer 面板连接并管理多种数据库
  • 在表视图中直接进行数据修改，或在绑定数据库的编辑器中编写并执行 SQL
  • 导出/导入数据及生成测试数据
