基于 PostgreSQL 扩展栈的 4D 时空 AI 平台基础版，提供参考实现与演示 UI

综述（解读层）

Atlas4D Base 是 Atlas4D 平台的开源基础与参考实现，围绕 PostgreSQL 16 集成 PostGIS、TimescaleDB、H3 与 pgvector，构建空间+时间+向量的统一数据层，并附带异常检测、威胁评估、轨迹向量化、自然语言转 SQL（保加利亚语+英语）等参考服务和 Prometheus/Grafana 可观测性组件。项目处于 Public Preview 阶段，README 明确说明开箱不具备生产就绪性，企业模块与生产加固包含在完整版中。适合数据工程师、GIS 开发者等用于学习、实验与扩展。

  • 在单一 PostgreSQL 数据库内集成 PostGIS 空间操作、TimescaleDB 时间序列（含压缩）、H3 六边形索引与 pgvector 向量相似度搜索
  • 提供 REST 数据接入/查询 API、异常检测、威胁评估、带 Redis 缓存的轨迹向量化及保加利亚语+英语 NLQ 服务等参考实现
  • 内置 Prometheus 指标采集、Grafana 仪表盘和针对 ML 管线与 Redis 的预配置告警规则，通过 make demo 或 docker compose 启动

适用场景（解读层）

  • 数据工程师构建实时时空管线，或 GIS/Geo 开发者在同一数据库中使用时间序列与向量搜索
  • 电信网络监测、智慧城市交通/车队轨迹分析、空域无人机轨迹监控等行业场景的模块化扩展基础
  • 研究实验室处理 4D 轨迹数据，并通过 NLQ 以自然语言（保加利亚语/英语）查询异常与威胁
