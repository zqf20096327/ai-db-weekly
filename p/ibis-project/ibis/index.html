综述（解读层）

Ibis 是一个 Python dataframe 库，通过将惰性表达式编译为各后端的原生语言（多数为 SQL）来连接执行引擎与数据库。开发者可用同一套 API 操作 DuckDB、Polars、PostgreSQL、BigQuery 等 20 多种后端，也可混用 Python 与 SQL。默认本地执行走 DuckDB，通过 set_backend 或连接对象切换后端，并支持读取 CSV、Parquet 等文件格式。项目采用 Apache 许可证，为独立治理的开源社区项目。

  • 提供惰性 dataframe 表达式，多数后端下编译为 SQL 执行
  • 支持超过 20 种后端，包括 DuckDB、Polars、DataFusion、PostgreSQL、BigQuery、ClickHouse、Snowflake 等
  • 支持在 Python 中混用 dataframe API 与 SQL 代码，并可读取 CSV、Parquet 等文件格式

适用场景（解读层）

  • 在本地用 DuckDB 迭代探索数据，再通过更改一行代码将同一份分析代码部署到远程后端（如 BigQuery）
  • 为只提供 SQL 接口、无 Python API 的数据库编写 Python 数据操作代码
  • 需要在不同执行引擎（SQL 生成型与 dataframe 生成型）之间复用同一套数据处理代码
