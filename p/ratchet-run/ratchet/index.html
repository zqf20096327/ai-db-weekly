🧭 简介解读层（AI·证据行可回查）

Java 分布式任务调度器，以已有数据库为队列运行持久化后台作业。

综述（解读层）

Ratchet 是 Apache-2.0 协议的 Java 分布式任务调度器，在 Jakarta EE、Quarkus、Spring Boot、Micronaut 应用内运行持久化后台作业、周期调度、批次与多步工作流，使用 PostgreSQL、MySQL、Oracle、SQL Server 或 MongoDB 作为存储与队列。通过 CDI 注入即可使用，提供重试、熔断、死信队列等机制；要求 Java 17+，SQL 存储需手工应用 DDL，且必须配置反序列化白名单 ClassPolicy 才能启动。当前版本 0.5.1-SNAPSHOT，API 尚在稳定化过程中。

  • 支持 Jakarta EE 10/11、Quarkus、Spring Boot 3.5/4.1 与 Micronaut 4.10/5，含 JVM 与原生镜像运行方式
  • 内置重试退避、熔断器、死信队列，支持链式工作流、条件分支、批次与外部信号挂起恢复
  • 提供两打以上 SPI 扩展点，可用单个 CDI @Alternative bean 替换重试、轮询、加密等组件；存储实现可通过 TCK 套件验证一致性

适用场景（解读层）

  • 在 Jakarta EE 或 Spring Boot 集群应用中运行持久化后台作业与周期任务
  • 构建需要条件分支和审批/回调信号恢复的多步工作流
  • 复用现有 PostgreSQL、MySQL 或 MongoDB 作为任务队列，不引入独立调度守护进程
