在 Electron 中通过主进程使用 TypeORM 与 SQLite3 的项目模板

综述（解读层）

这是一个面向想在 Electron 应用中使用 TypeORM 加 SQLite3 的开发者的项目脚手架，技术栈含 TypeScript、React、Webpack 与 Babel。因 webpack 问题导致渲染进程几乎无法运行 TypeORM，该模板将 TypeORM 放在主进程运行，渲染进程通过 remote/ipc 调用与之通信，并提供开发、构建与打包脚本。

  • 在主进程中运行 TypeORM 与 SQLite3，渲染进程通过 remote/ipc 调用通信
  • 提供 npm start、build、build:dev、package 等脚本，打包使用 electron-builder（配置位于 ./electron-builder.json）
  • 支持 Windows、Linux 和 Mac 三个平台

适用场景（解读层）

  • 需要本地 SQLite 数据库持久化的 Electron 桌面应用开发
  • 希望以 React + TypeScript + Webpack 构建带数据库功能的桌面项目
  • 快速创建带有开发热更新与打包流程的 Electron 项目起点
