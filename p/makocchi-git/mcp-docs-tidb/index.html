MCP 服务器，将 TiDB 作为语义记忆层存储与检索文档

综述（解读层）

该项目是一个 MCP 服务器，借助 TiDB 原生 VECTOR 类型和 VEC_COSINE_DISTANCE 函数实现文档的向量化存储与相似度检索，提供 store/ingest/find/list 四个工具。面向使用 Claude Desktop、Cursor、Claude Code 等 MCP 客户端并已有可达 TiDB 实例（v8.4+，支持向量）的用户。服务器不自建 TiDB，依赖 Python 3.10+ 和 uv，可通过 uvx 从 GitHub 直接运行；支持 TIDB_READ_ONLY 只读模式与 HNSW 向量索引。

  • 提供 docs-tidb-store、docs-tidb-ingest、docs-tidb-find、docs-tidb-list 四个 MCP 工具，分别用于写入文本、批量导入本地文件、相似度检索和按来源列出已注册文档
  • 表结构在首次写入时自动创建，含 VECTOR 类型 embedding 列，可按配置在建表时附带 HNSW 向量索引（需 TiDB v8.4+ 及 TiFlash 副本）
  • 通过环境变量配置连接与行为：TIDB_READ_ONLY 只读模式、COLLECTION_NAME 默认表、TIDB_INGEST_ROOT 路径白名单限制 ingest 目录、支持 stdio/streamable-http/SSE 传输

适用场景（解读层）

  • 在 Claude Desktop、Cursor、Windsurf、Claude Code 等 MCP 客户端中接入，将文档存入 TiDB 并按语义检索
  • 批量导入本地 Markdown 等文件目录，按 source 分块入库，配合 only_modified 做增量刷新
  • 以只读模式（TIDB_READ_ONLY=1）部署，供客户端查询已有集合内容
