🧭 简介解读层（AI·证据行可回查）

单 Go 二进制的原生跨平台数据库 GUI，支持多种 SQL 引擎与 Redis 客户端。

综述（解读层）

DGopher 是一个开源数据库客户端，运行于 Linux、macOS 和 Windows，支持 PostgreSQL、MySQL、SQL Server、Oracle、ClickHouse、SQLite、DuckDB 及 Redis 等，无需 Electron。面向数据库开发与运维人员，提供查询编辑、结果网格、查询计划、仪表盘与审计日志；生产连接需输入连接名确认破坏性语句。项目尚未达到 1.0，README 列有已知限制清单。

  • 单 Go 二进制实现，不依赖 Electron、webview 或 JVM，提供 Linux amd64/arm64、macOS（Apple silicon/Intel）与 Windows amd64 构建
  • 支持 PostgreSQL、MySQL、SQL Server、Oracle、ClickHouse、SQLite、DuckDB、Redis，以及 CockroachDB、YugabyteDB、TimescaleDB、MariaDB、TiDB 等引擎
  • 包含查询计划树/火焰图、ER 图、笔记本单元格、CSV/JSON/Parquet/Excel/XML 导入导出、Redis 键浏览器，且审计日志与连接配置可存入 Git 仓库

适用场景（解读层）

  • 在单一客户端中连接并查询多种 SQL 数据库与 Redis（含集群和 Sentinel）
  • 在标记为生产的连接上执行写操作前需确认，适合需要防误操作机制的日常 SQL 工作
  • 将连接配置、查询文件、仪表盘与数据模型纳入 Git 仓库供团队共享，并保留操作审计日志
