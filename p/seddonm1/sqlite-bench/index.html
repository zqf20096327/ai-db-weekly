SQLite 事务行为的基准测试工具，用 Rust 编写

综述（解读层）

该项目是配套博客文章的 SQLite 事务行为测试工具，用 Rust 实现，通过 cargo 构建运行。使用者需提供数据库路径和输出文件两个必填参数。README 提示建议先在内存文件系统上运行以减少对 SSD 的写入损耗，并给出了 macOS 和 Linux 创建 RAM 盘的命令，另提供多平台 Docker 镜像。适合需要观察 SQLite 事务读写性能数据的开发者。

  • 基于 Rust 实现，通过 cargo build --release 编译
  • 命令行工具，必填 --path 与 --output 参数
  • 提供多平台 Docker 镜像

适用场景（解读层）

  • 复现博客文章中的 SQLite 事务性能测试
  • 验证不同文件系统（RAM 盘等）下的 SQLite 事务读写表现
  • 在容器环境中运行 SQLite 基准测试
