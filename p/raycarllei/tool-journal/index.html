🧭 简介解读层（AI·证据行可回查）

面向可重试工具的 TypeScript 执行日志库，基于 SQLite 记录意图与租约

综述（解读层）

tool-journal 是一个 TypeScript 库，为崩溃后可能被重试的工具提供执行日志：在执行前记录意图、用 SQLite 事务序列化多进程认领、以租约代次隔离过期执行者，并将无法确定的结果显式标记为 indeterminate。要求下游具备幂等契约和有限的_retry 准入窗口。无运行时依赖，需 Node.js 24.15+，发布为 .tgz 源码包而非 npm registry。适合需要在崩溃恢复中避免重复外部副作用的开发者集成。

  • SQLite 事务序列化共享同一本地数据库的多进程认领，已完成结果可由协作调用方重放而无需再次调用工具
  • begin/complete/renew/settle 实现 lease fencing、变更冲突检测与不确定结果的收据登记
  • 提供崩溃演示、针对性变异检查（逐个移除九项防护并要求断言失败）及含 500 内存与 40 SQLite 历史的独立模型验证

适用场景（解读层）

  • 工具执行外部动作后崩溃、需区分'已生效但未记录'与'未执行'的重试场景
  • 与下游幂等接口配合，在有界重试窗口内恢复原始收据
  • 需要人工介入决策的不可自动恢复操作，以 indeterminate 状态停止
