在单机上创建、运行和管理多个独立 Neo4j 实例的 shell 管理脚本

综述（解读层）

neo4j_manager 是一个单机多 Neo4j 实例管理工具，通过 manage.sh 脚本实现实例的创建、启动、配置与管理，支持为每个实例挂载 apoc 与 GDS 插件。使用前需手动下载 neo4j community unix 版 tar 包及 apoc、GDS 的 standalone jar 放入指定目录，初始化后可创建默认实例，并提供查询实例 bolt 端口等监控命令。适用于社区版且面向 unix 环境。

  • 通过 manage.sh 命令创建、运行、配置和管理多个 standalone Neo4j 实例
  • 支持为实例安装 apoc 与 graph-data-science（GDS）插件
  • 提供 find_bolt_port 等实例监控相关命令

适用场景（解读层）

  • 在一台机器上运行多个相互独立的 Neo4j 社区版实例
  • 需要为各实例配置 apoc 或 GDS 插件的环境
  • 需要查询各实例 bolt 端口以便连接与监控
📖 README 首段存档原文 · 程序抽取

neo4j_manager provides the functionalities to create, run, config and manage multiple standalone instances of neo4j with "apoc" and "gds" plugin on a single machine.
