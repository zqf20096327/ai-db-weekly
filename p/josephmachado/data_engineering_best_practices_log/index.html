演示数据工程元数据记录与日志实践的示例项目，含 Spark、PostgreSQL、Prometheus 与 Grafana。

综述（解读层）

该仓库是作者数据工程最佳实践系列博客第 2 篇（元数据与日志）的配套代码。它提供基于 Docker Compose 的环境：Spark standalone 集群运行 ETL 任务，PostgreSQL 存储 Great Expectations 数据质量检查结果和 run_metadata 运行信息，Prometheus 每 5 秒经 SparkServlet 抓取指标并由 Grafana 展示。适合想跟随博客动手实践的数据工程师。未来计划包括配置 Grafana 面板、将日志迁移至 Loki 等。

  • 提供 Docker Compose 一键启动的环境，包含 Spark、PostgreSQL、Prometheus 和 Grafana 服务
  • 使用 PostgreSQL 存储数据质量检查结果和 run_metadata 运行信息，可通过 make meta 命令访问
  • Prometheus 每 5 秒通过 Spark PrometheusServlet 抓取 Spark 指标，并在 Grafana（localhost:3000）展示

适用场景（解读层）

  • 跟随作者博客学习数据工程元数据与日志记录实践时进行代码演示
  • 查看 Great Expectations 数据质量检查结果与 ETL 运行元数据的存储方式
  • 搭建包含 Spark 指标抓取的本地监控环境（Prometheus + Grafana）
