基于 Debezium 的 PostgreSQL 变更数据捕获示例管道，配套博客教程

综述（解读层）

该仓库是 startdataengineering.com 上 Debezium CDC 博文配套的示例项目，用 Docker Compose 运行 Postgres、Kafka、Kafka Connect、Minio 及一个 Python 数据生成器，通过 Debezium 连接器捕获表变更并写入 Minio，支持 GitHub Codespaces 或本地运行。数据以 JSON 文件形式存储，可用 DuckDB 通过文件系统或 S3 API 读取并构建 SCD2。默认凭据 minio/minio123，仅用于实验环境。

  • 通过 make 命令一键启动 Postgres、Kafka、Kafka Connect、数据生成器与 Minio 容器，并部署 Debezium 与 S3 sink 两个连接器
  • 捕获的表变更以 JSON 文件写入 Minio，可通过挂载的本地文件系统或 S3 API 用 DuckDB 访问
  • 支持 GitHub Codespaces 运行，无需本地安装 Docker

适用场景（解读层）

  • 学习 Debezium + Kafka 的 CDC 数据管道搭建流程
  • 用 DuckDB 查询 Minio 中的变更数据并构建 SCD2 缓慢变化维度
  • 本地快速验证 CDC 数据流到对象存储的端到端演示
