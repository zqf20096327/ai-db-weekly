🧭 简介解读层（AI·证据行可回查）

面向 Cloudflare D1 的 SQLite 查询构建库，提供 CRUD 操作接口。

综述（解读层）

该库为 Cloudflare D1 数据库提供查询构建接口，通过 insert、query、update、remove 四类函数实现增删改查操作，各函数返回受影响的行。where 子句以对象表示 AND、数组表示 OR，支持 join、select、group by 及参数占位符写法，面向在 D1 上操作数据的开发者。

  • 提供 insert、query、update、remove 四类 CRUD 函数，均返回受影响或匹配的行
  • where 子句支持对象（AND）与数组（OR）组合，支持 join、select、group by
  • 支持 "height = ?" 表达式写法，并可用 height: 31 作为等值简写

适用场景（解读层）

  • 在 Cloudflare Workers 中以 JS 对象方式构建 D1 查询
  • 需要返回插入/更新/删除行的增删改查操作
  • 需要简化条件组装（AND/OR、占位符）的查询场景
