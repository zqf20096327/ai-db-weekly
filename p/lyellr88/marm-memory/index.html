🧭 简介解读层（AI·证据行可回查）

本地优先的 AI 代理记忆层与 MCP 服务器，用 SQLite 融合会话、代码图谱与概念图谱

综述（解读层）

MARM 是一个本地运行的 MCP 记忆服务器（Python/FastAPI，PyPI 包 marm-mcp-server），为 Claude Code、Codex、Gemini、Cursor 等 AI 代理提供跨会话持久记忆。共 16 个工具分三部分：核心记忆（8）、代码图谱（6）、概念图谱（2），数据存于本地 SQLite（WAL 模式），支持 HTTP 与 STDIO 两种传输及多代理共享的 swarm 启动配置。README 注明作者目前处于短暂停更状态，项目自称仍活跃。

  • 提供 16 个 MCP 工具：核心记忆存储/检索 8 个、代码仓库索引与符号追踪 6 个、概念图谱抽取 2 个，均支持 HTTP 与 STDIO
  • 数据存储于本地 SQLite（WAL 模式、连接池、串行化写入队列），附 Web 控制台与守护进程生命周期管理（status/logs/restart/stop）
  • 通过 pip 安装后以 marm-memory init 配合 --g-* 参数为多种代理客户端生成配置，并提供 solo/stdio/swarm/swarm-max/trusted 等启动配置

适用场景（解读层）

  • 为多个 AI 编码代理（Claude Code、Codex、Gemini、Cursor 等）建立共享的本地长期记忆
  • 对代码仓库建立符号索引与调用追踪，供代理查询项目结构与变更影响
  • 在无云端依赖的环境中保存决策、研究与项目历史并跨会话检索
