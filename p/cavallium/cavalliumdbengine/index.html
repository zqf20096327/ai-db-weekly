基于 Reactor 的 Java 响应式数据库引擎，封装 RocksDB 键值存储与 Lucene 搜索

综述（解读层）

CavalliumDB Engine 是用 Java 17+ 和 Project Reactor 编写的响应式数据库引擎，提供键值存储与搜索引擎两类抽象，内置 RocksDB 持久化、内存 ConcurrentSkipListMap、Lucene 持久/内存索引四种实现。作者声明这是个人项目、API 不稳定、缺乏测试，定位为构建 DBMS 的底层引擎而非 DBMS 本身。

  • 基于 Project Reactor 提供 key-value 存储与搜索引擎的响应式抽象，可扩展更多实现
  • RocksDB 实现支持快照、多列数据库、写前日志与损坏恢复；Lucene 实现支持排序、模糊搜索、N-gram 分词与结果过滤
  • 提供可序列化查询格式、基于 Netty 5 缓冲区的直接字节缓冲，以及由 YAML 定义生成 Java record 与版本化编解码器的数据生成器

适用场景（解读层）

  • 需要在其上构建自定义 DBMS 或数据抽象层的 Java 响应式应用
  • 使用 RocksDB 做持久化键值存储并同时需要 Lucene 全文检索的场景
  • 构建和分析临时索引的内存搜索场景
