基于 SQLite 的类 Datalog 查询修改库

综述（解读层）

owoof 是一个 Rust 库，提供类 Datalog 格式对 SQLite 数据库中信息的查询与修改，受 Datomic 启发。除库之外还提供两个可执行目标：CLI（用于初始化数据库、断言/撤回、查询）和 CSV 导入工具（owoof-csv）。README 明确标注其为个人练手项目，测试覆盖有限、无值索引导致性能不稳定，且暂不支持范围约束和逻辑运算。适用于想尝试类 Datomic 数据模型与模式匹配查询的开发者。

  • 以类 Datalog 模式对 SQLite 数据进行断言、撤回与查询
  • 提供 CLI 与 owoof-csv 两个可执行目标，支持初始化数据库和从 CSV 导入数据
  • 0.2 版本为特定属性添加部分索引以提升搜索性能

适用场景（解读层）

  • 以 Datomic/Datalog 风格的模式匹配方式查询 SQLite 中的三元组数据
  • 从 CSV 文件批量导入数据并按属性查询
  • 作为学习或实验 Datomic 式数据模型的 Rust 库使用
