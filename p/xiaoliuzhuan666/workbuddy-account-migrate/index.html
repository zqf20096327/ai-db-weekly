🧭 简介解读层（AI·证据行可回查）

WorkBuddy 本地数据迁移 CLI，基于 SQLite 修改 user_id 实现跨设备与跨账号数据搬运。

综述（解读层）

这是一组面向 WorkBuddy 用户的 Python 脚本，用于跨设备打包迁移项目会话，以及在切换账号后将旧账号留存在磁盘上的对话记录、长期记忆、MCP 连接器合并到当前账号。工作原理是修改 SQLite 数据库中的 user_id 字段并处理 WAL checkpoint，支持国内版/国际版目录、自动备份与回滚。限制：仅适用于 WorkBuddy 本地数据，无第三方依赖但需 Python 3.8+。

  • 提供 migrate_project.py、migrate.py、migrate_session.py 三个脚本，支持无参数运行进入交互向导，无需知道 user_id
  • 迁移前自动备份数据库、记忆与连接器，支持 --rollback 回滚，并执行 SQLite WAL checkpoint
  • 跨平台路径自动重映射（macOS/Windows/Linux），同一导出包重复导入不产生重复会话

适用场景（解读层）

  • 家用与办公两台电脑使用不同账号交替进行同一项目，需携带项目会话与工作区记忆
  • WorkBuddy 切换账号或重新登录后，恢复旧账号的对话记录、长期记忆和 MCP 连接器
  • 将单个对话在国内版与国际版之间迁移，或在迁移前用 --diagnose 查看账号数据分布
