基于 Node.js 内置 node:sqlite 模块的 Fastify SQLite 连接插件

综述（解读层）

该插件为 Fastify 应用提供 SQLite 数据库连接，内部使用 Node.js 22.5.0 起提供的实验性 node:sqlite 模块，将数据库实例装饰到 fastify.sqlite 上，并附带 migrateSqlite 迁移方法与 TypeScript 类型定义。适用于使用 Node.js >=22.5.0 的 Fastify 项目；DB 文件默认为内存模式，可配置只读、多库命名等选项。

  • 基于 Node.js 内置 node:sqlite 模块，无需额外原生 SQLite 驱动
  • 支持 dbFile、name（多实例装饰）、readOnly、verbose（SQL 语句经 fastify.log.trace 输出）等选项
  • 内置 migrateSqlite 迁移：按字母序执行 .sql 文件、每个迁移独立事务、用 _migrations 表记录已执行文件

适用场景（解读层）

  • 在 Node.js 22.5+ 的 Fastify 服务中接入 SQLite 数据库
  • 同一应用中通过 name 选项连接并管理多个 SQLite 数据库
  • 使用目录中的 .sql 文件执行可追踪、可独立回滚的数据库迁移
