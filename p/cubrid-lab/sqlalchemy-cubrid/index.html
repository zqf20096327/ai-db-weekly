CUBRID 数据库的 SQLAlchemy 2.0–2.1 方言，提供 ORM、Alembic 迁移与异步连接支持

综述（解读层）

sqlalchemy-cubrid 是一个让 SQLAlchemy 连接 CUBRID 数据库的方言库，适用于使用 Python ORM 操作 CUBRID 的开发者。它要求 CUBRID 服务器（10.2–11.4）已单独运行，支持 SQLAlchemy 2.0–2.1 与 Python 3.11+。提供三种驱动方案：纯 Python 的 pycubrid（含异步 aiopycubrid）为推荐方式，另有 CUBRIDdb C 扩展驱动。注意不支持 RETURNING 子句与序列，仅支持单一有效 schema。

  • 支持 SQLAlchemy 2.0–2.1，兼容 ORM、Schema 反射与 Alembic 迁移（通过 CubridImpl 自动注册）
  • 提供三种驱动：cubrid+pycubrid://（同步纯 Python）、cubrid+aiopycubrid://（异步）、cubrid://（CUBRIDdb C 扩展）
  • 实现 CUBRID 特有 DML 构造 ON DUPLICATE KEY UPDATE、MERGE、REPLACE INTO，以及三种 MVCC 隔离级别

适用场景（解读层）

  • 在 Python 项目中通过 SQLAlchemy ORM 或 Core 访问已运行的 CUBRID 数据库
  • 使用 Alembic 管理 CUBRID 数据库的模式迁移与版本控制
  • 需要异步访问 CUBRID 的 asyncio 应用（通过 aiopycubrid 驱动）
