面向 CUBRID 数据库的 Python 示例集，覆盖入门到生产模板

综述（解读层）

该仓库提供 CUBRID 数据库的 Python 可运行示例集合，包含快速入门、迁移指南、生产模板、性能模式与常见陷阱七类内容。面向从 Java/JDBC 或 CUBRIDdb 驱动迁移到 Python 的开发者，以及需要 FastAPI、Flask、Django、Celery、Pandas 等集成模板的使用者。要求 Python 3.11+ 和 CUBRID 11.2/11.4，通过 Docker Compose 启动本地数据库；性能基准数据基于 pycubrid 1.10.0。项目属 CUBRID Lab，与 CUBRID 公司无隶属关系，采用 MIT 许可。

  • 包含快速入门、Java 到 Python 迁移指南、CUBRIDdb 到 pycubrid 驱动迁移指南
  • 提供 FastAPI、Flask、Django、Celery、Pandas、Streamlit、RAG 等 8 类生产模板
  • 含 22 条 pycubrid DB-API 配方、7 条 SQLAlchemy 配方及参数化查询、LOB、MVCC 隔离级别等基础参考

适用场景（解读层）

  • 从 Java/JDBC 或 CUBRIDdb 驱动迁移到 Python/pycubrid 的团队参考
  • 搭建基于 FastAPI、Flask 或 Django 并连接 CUBRID 的应用起点
  • 学习 CUBRID 事务、批量插入、连接池等操作与性能模式
