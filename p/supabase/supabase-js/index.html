Supabase 的同构 JavaScript 客户端 SDK，Monorepo 管理多套子包

综述（解读层）

supabase/supabase-js 是 Supabase JavaScript SDK 的 monorepo，主包 @supabase/supabase-js 整合数据库查询、实时订阅、文件存储、Edge Functions 调用与 rpc 调用 Postgres 函数等子 SDK。适用于 Node.js、Deno、浏览器、Bun、React Native、Cloudflare Workers 环境；仅支持各运行时的 Active LTS 或稳定版本，过期版本会在 minor 版本中被移除且不视为破坏性变更，自托管用户需配合升级服务端。

  • 提供 @supabase/supabase-js 及 auth、postgrest、realtime、storage、functions 五个核心子包，覆盖认证、数据库、实时、存储、Edge Functions
  • 支持 Node.js、Deno、现代浏览器（原生 fetch/WebSocket）、Bun、React Native、Cloudflare Workers 多运行时
  • 提供 npm registry 签名与 provenance attestation 验证方式（npm audit signatures）

适用场景（解读层）

  • 在 Web/Node 应用中通过 JavaScript 访问 Supabase 数据库、存储与认证服务
  • 在 Edge 运行时（Deno、Cloudflare Workers）或 React Native 中调用 Supabase 服务
  • 自托管 Supabase 时通过 SDK 对接 PostgREST（最低支持 v12）等服务端组件
