Supabase 官方 Python 客户端 monorepo，用于在 Python 应用中访问 Postgres 及配套服务

综述（解读层）

supabase-py 是 Supabase 的 Python 客户端代码库，以 monorepo 形式包含 supabase、realtime、storage3、postgrest、supabase_auth 等子包，供 Flask、Django、FastAPI 等 Python 项目调用 Supabase 的数据库、认证、存储、边缘函数与实时数据流服务。该仓库 main 分支为 v3 早期开发版，暂不接受外部贡献；v2 分支仅接受关键缺陷和安全修复。仅官方支持 CPython，兼容各服务最新版本。

  • 以 monorepo 组织，包含 supabase、realtime、storage3、postgrest、supabase_auth、supabase_functions、supabase_utils 七个子包
  • 纯 Python 实现，在 Linux 上测试，预期可在 macOS、Windows 等 CPython 支持的平台运行
  • 通过 make 管理测试命令，支持按子包单独执行（如 make realtime.tests）及并行运行

适用场景（解读层）

  • 在 Flask、Django、FastAPI 应用中通过 Python 查询和写入 Postgres 数据
  • 需要 Python 用户认证、文件存储或实时数据流的 Supabase 项目
  • 自托管 Supabase 并需配套 Python SDK 的场景
