Supabase 官方 Python 客户端库的 monorepo，用于从 Python 访问 Supabase 服务

综述（解读层）

该仓库是 Supabase 各 Python 库（supabase、realtime、postgrest、storage3、supabase_auth、supabase_functions 等）的 monorepo，供 Python 开发者在 Flask、Django、FastAPI 等框架中查询 Postgres、使用身份认证、文件存储、Edge Functions 与实时数据流。README 主要面向贡献者，说明 main 分支的 v3 处于早期开发阶段且暂不接受外部贡献，v2 分支仅接受关键缺陷与安全修复；仅官方支持 CPython。本地开发依赖 uv、make、supabase-cli 与 docker，通过 make ci 运行测试。

  • 包含 supabase、realtime、postgrest、storage3、supabase_auth、supabase_functions、supabase_utils 七个子包
  • 支持 Python 3.12 及所有未到生命周期终点的后续版本，纯 Python 实现，在 Linux 上测试，预期可在 CPython 支持的 macOS、Windows 等平台运行
  • 提供 make ci 命令统一调度各子包测试，支持 -jN 并行执行及 {package_name}. 前缀的子包级命令

适用场景（解读层）

  • 在 Flask、Django、FastAPI 等 Python 应用中查询 Postgres 数据
  • 在 Python 项目中使用 Supabase 的用户认证、文件存储与实时数据流功能
  • 为 Supabase Python 各子库做本地开发与测试（需 uv、make、supabase-cli、docker）
