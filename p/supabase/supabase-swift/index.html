Supabase 官方 Swift SDK，集成认证、数据库查询、实时订阅与存储

综述（解读层）

该 SDK 为 Swift 应用提供访问 Supabase 服务的客户端，包含 Auth、PostgREST、Realtime、Storage、Functions 等子库，可按需单独引入。支持 SwiftUI 会话管理、Keychain 存储及通过 supabase-typegen 生成 @Table 类型。要求 iOS 16+/Swift 6.2+，仅保证兼容各服务最新版本。

  • 提供 Auth、PostgREST、Realtime、Storage、Functions 五个子库，支持整包引入或单独引入
  • SwiftUI 中提供 @Observable 的 AuthModel 管理会话，Apple 平台上会话默认存于 Keychain
  • 内置 supabase-typegen 可执行文件，可通过 supabase gen types --lang swift 从数据库 schema 生成 @Table 结构体

适用场景（解读层）

  • iOS/macOS 等苹果平台应用接入 Supabase 进行用户认证与会话管理
  • Swift 客户端通过 REST 查询 Postgres 数据、上传下载文件、订阅数据库变更
  • 调用 Edge Functions 并流式读取响应，或经 rpc 调用 Postgres 函数
