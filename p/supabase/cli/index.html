Supabase 官方命令行工具，支持本地运行全套服务栈并管理迁移部署

综述（解读层）

这是 Supabase 平台的命令行工具，提供本地开发栈（含 Postgres、Auth、Realtime、Storage、Edge Functions 及 Supabase API）的启动，数据库迁移的创建、diff 与 push（可通过 --remote 作用于已链接的托管项目），Edge Functions 的构建、serve 与部署，以及从数据库 schema 生成 TypeScript 类型。适用于使用 Supabase 平台进行本地开发与项目工作流自动化的开发者。仓库为 pnpm monorepo，CLI 包位于 apps/cli，采用 MIT 许可证发布。

  • 在本地运行包含 Postgres、Auth、Realtime、Storage、Edge Functions 与 Supabase API 的完整开发栈
  • 管理数据库迁移：创建迁移、比较 schema 差异、应用变更，支持 --remote 操作已链接的托管项目
  • 从本地数据库或已链接项目生成 TypeScript 类型，并构建、serve、部署 Edge Functions

适用场景（解读层）

  • 在终端中搭建并运行 Supabase 本地开发环境
  • 维护本地与托管项目间的 Postgres 数据库迁移流程
  • 自动化 Edge Functions 部署与项目工作流，或为数据库 schema 生成类型定义
