面向 Supabase 的 Kotlin 多平台客户端 SDK

综述（解读层）

supabase-kt 是一个用于访问 Supabase 服务的 Kotlin 多平台客户端库，按模块提供认证、PostgREST 数据库、Storage 存储、Realtime 和 Edge Functions 访问能力，基于 Ktor Client 构建，需为各 Kotlin 目标平台配置对应的 Ktor 引擎。适用于 Android、桌面、JS、iOS 等目标的应用开发；最低 Android SDK 为 26，服务端兼容性仅保证各服务的最新版本。

  • 提供 auth-kt、postgrest-kt、storage-kt、realtime-kt、functions-kt 等模块，分别对应 Supabase 的认证、PostgREST、存储、Realtime 和 Edge Functions 服务
  • 支持 Apollo GraphQL、Compose Auth、Compose Auth UI、Coil3 等插件，可在 createSupabaseClient 函数中安装
  • 支持 Kotlin 多平台目标（含 jvm、android、js、ios 等），3.0.0 及以上版本提供 WASM-JS 目标

适用场景（解读层）

  • 在 Android、桌面、iOS、浏览器等多平台 Kotlin 项目中接入 Supabase 认证与数据库
  • 构建使用 Jetpack Compose / Compose Multiplatform 的应用并使用其认证 UI 组件
  • 在 Kotlin 服务端应用（如 Spring Boot）中通过 RESTful 接口访问 Supabase 服务
