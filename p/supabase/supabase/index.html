基于 Postgres 的开发平台，整合认证、API、实时订阅、存储与向量工具。

综述（解读层）

Supabase 是一个 Postgres 开发平台，为 Web、移动和 AI 应用提供专用 Postgres 数据库。它由 PostgREST、GoTrue、Realtime 等开源工具组合而成，支持托管使用、自托管和本地开发。提供官方 JavaScript/Flutter/Swift/Python 客户端库，社区支持 C#、Go 等语言客户端。

  • 提供托管 Postgres 数据库，支持 REST、GraphQL 自动生成 API 与 WebSocket 实时订阅
  • 包含 JWT 认证、S3 文件存储、数据库函数与 Edge Functions、向量/嵌入工具包
  • 架构由 PostgREST、GoTrue、pg_graphql、Storage 等开源组件组合，支持自托管

适用场景（解读层）

  • 需要 Postgres 数据库配合认证、文件存储与自动生成 API 的 Web 或移动应用开发
  • 使用 pgvector 处理向量与嵌入数据的 AI 应用
  • 需要通过 WebSocket 监听数据库增删改事件并广播给客户端的场景
