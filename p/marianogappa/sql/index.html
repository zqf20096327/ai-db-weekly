命令行工具，将 STDIN 中的 SQL 管道传给多个 MySQL/PostgreSQL 数据库执行

综述（解读层）

sql 是一个 CLI 工具，把 STDIN 中的 SQL 发送到一个或多个预先配置的 MySQL 或 PostgreSQL 数据库，输出以制表符分隔以便继续管道处理。多库查询并行执行且行前缀标注库标识，支持本地执行、连接远程主机或经 SSH 到远程主机执行。依赖本地 mysql-client/postgresql-client；凭据以明文存放于 ~/.databases.json，定位为轻量临时 SELECT 自动化。

  • 支持并行查询多个数据库，结果行以制表符分隔输出
  • 可本地执行、连接远程主机，或通过 SSH 在远程主机上运行 mysql/psql
  • 通过 ~/.databases.json 配置数据库，凭 sqlType 区分 MySQL 与 PostgreSQL，未设置时默认 MySQL

适用场景（解读层）

  • 对多个数据库批量执行同一份 ad-hoc SELECT 查询
  • 将查询结果通过管道接续处理，例如配合图表工具使用
  • 跨本地与远程（SSH）环境执行数据库查询的自动化脚本
🔌 适配哪些库db_scan 程序判定

MySQL、PostgreSQL
