🧭 简介解读层（AI·证据行可回查）

用于 TiKV fail-slow 测试的基准实验脚本集

综述（解读层）

该项目包含在本地通过 TiUP 启动 1 个 PD 节点和 3 个 TiKV 节点的集群、配合 go-ycsb 运行基准测试的脚本，以及用 Python 解析日志并绘图的工具，面向需要对 TiKV 做故障变慢（fail-slow）测试的人员。测试通过 benchmark.xsh 运行，需注释 main 中部分内容来分别执行测试；结果需另行查看 Report。

  • 通过 TiUP playground 部署 1 节点 PD 与 3 节点 TiKV 的本地集群（--without-monitor）
  • 使用 go-ycsb 运行基准测试，benchmark.xsh 支持通过注释部分代码分别运行测试
  • 提供 log_to_json.py 解析日志、graph.py 绘制图表

适用场景（解读层）

  • 对 TiKV 集群执行 fail-slow 场景的基准测试
  • 本地搭建多节点 TiKV 测试环境并采集负载数据
  • 将测试日志转换为 JSON 并生成图表用于分析
