Spring Boot 2.7 学习示例集，按模块演示邮件、Excel、文件上传等功能集成

综述（解读层）

该仓库是作者以 Spring Boot 2.7.0 为基础的示例与笔记合集，目录中包含 springboot-excel 等模块，配套博客笔记涵盖支付宝沙箱支付、Redis 集成、爬取 IP 代理池、文件上传、JPA、MongoDB 等主题。技术栈使用 MySQL、MyBatis PLUS 3.5.2、Redis。适合跟随笔记学习 Spring Boot 集成开发的读者。

  • 提供 springboot-excel 模块实现 Excel 导入导出
  • 基于 Spring Boot 2.7.0、MySQL 5.7.2、MyBatis PLUS 3.5.2 构建
  • 配套博客笔记覆盖 Redis 集成、MongoDB、JPA、支付宝沙箱支付、IP 代理池爬取等主题

适用场景（解读层）

  • 参考仓库中的 Docker、MySQL、Redis 安装笔记搭建本地开发环境
