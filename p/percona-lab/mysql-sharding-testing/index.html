🧭 简介解读层（AI·证据行可回查）

对五种 MySQL 分片方案在 4 分片环境下的实测基准脚本与结果集合

综述（解读层）

该项目包含一套基准测试脚本与结果数据，用于在 4 个分片的统一环境中比较 Vitess、ShardingSphere、DBLE、Spider 和 TiDB：通过 TPC-C、sysbench 测吞吐，记录路由层每事务 CPU 开销，并对照未分片副本核验跨分片查询正确性。脚本涵盖数据加载、快照恢复、一致性校验与结果汇总，README 同时列出测试限制。适合需要自行搭建分片评测环境的工程团队复现或参考。

  • 提供可复现的测试流程脚本：分片数据加载、datadir 快照恢复、一致性校验（33 项 TPC-C 不变量、49 项 sysbench 检查）与结果汇总
  • 覆盖吞吐（TPC-C 200 warehouses、sysbench 倾斜/均匀键）、路由 CPU 每事务开销、跨分片查询正确性（31 条查询对照未分片副本）三类指标
  • 保留两轮结果（2 vCPU 与 8 vCPU 路由机）及失败尝试记录（failed-* 目录），并附 go-tpc 补丁与各路由的配置文件

适用场景（解读层）

  • 需要在统一数据布局和硬件条件下对比多种 MySQL 分片方案的测试基准设计
  • 构建包含数据加载、快照恢复、一致性校验与汇总环节的分片基准流水线
  • 排查分片中间件的兼容性问题，参考 notes/FINDINGS.md 中的各工具问题与变通方法
