面向 n8n 的自托管可观测性仪表板，单容器部署，推送式采集数据。

综述（解读层）

n8n-trace 是一个自托管的 n8n 可观测性与分析平台，为自建 n8n 的团队和平台工程师提供执行分析、实例监控、指标查询、RBAC 与审计日志。数据采集通过两个随附的 n8n 工作流直接写入 PostgreSQL，服务端不向 n8n 发起外呼；系统不采集工作流负载数据。指标功能可选，可通过环境变量关闭。MIT 许可，需 Node 22+/PostgreSQL 17+。

  • 提供执行分析（成功率/失败率、耗时趋势、节点级指标）与基于 Prometheus 端点的实例监控，指标采集功能可通过配置关闭
  • 实现 Admin/Analyst/Viewer 三级角色访问控制，支持按实例、工作流或标签限定范围，并记录可配置 IP 处理模式（raw/hashed/none）的审计日志
  • 以单个 Google Distroless Docker 容器运行，采用推送式数据采集，n8n 工作流直接写入 PostgreSQL，服务端不调用 n8n；提供无需鉴权的 /health 与 /ready 端点

适用场景（解读层）

  • 集中查看多套 n8n 实例（生产、预发、开发）的工作流执行情况与实例健康指标
  • 为需要访问统计但不应接触敏感负载数据的团队（如管理、QA）提供只读仪表板
  • 需要审计日志与按工作流/实例限权访问控制的 n8n 自托管部署场景
