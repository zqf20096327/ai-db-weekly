面向 PostgreSQL 的静态 SQL/ORM 查询检查工具，在合并前扫描源码发现风险查询

综述（解读层）

Valk Guard 是一个 Go 编写的 SQL 检查工具，扫描 .sql 文件以及 Go、Python、C# 源码，通过各语言 AST 从 Goqu、SQLAlchemy、EF Core 等 ORM 链中合成 SQL，用 PostgreSQL 语法解析后执行 19 条规则，包含 schema 漂移检查，并可将结果写入 Pull Request。它无需连接数据库，仅支持 PostgreSQL 方言；扫描 Python 需 Python ≥3.6，扫描 C# 需 .NET SDK ≥8.0。

  • 内置 19 条规则，覆盖无 WHERE 的 UPDATE/DELETE、无 LIMIT 查询、前导通配符 LIKE、非 CONCURRENTLY 建索引及 DDL 等，默认全部启用
  • 通过 go/ast、Python ast 与 Roslyn 提取器解析源码，从 ORM/查询构造器调用合成 SQL；C# 查询构造器合成采用保守策略，跳过不确定的动态表达式
  • 支持将发现以 PR 评论形式提交，输出终端、JSON、rdjsonl、SARIF 格式，提供行内抑制与 .valk-guard.yaml 配置

适用场景（解读层）

  • 在 CI 中对包含 .sql、Go、Python 或 C# 代码的仓库做合并前扫描，检出无 WHERE 的批量更新/删除等查询
  • 将 ORM 模型定义与迁移 DDL 交叉比对，检查列被迁移删除但模型仍引用等 schema 漂移
  • 配合 GitHub Actions 与 reviewdog 流程，仅扫描 PR 变更文件或在全仓库运行检查
