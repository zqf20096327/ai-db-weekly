🧭 简介解读层（AI·证据行可回查）

将 NHTSA vPIC VIN 解码数据库迁移为 SQLite/Postgres 的流水线脚本集

综述（解读层）

该项目是一组脚本，用于下载 NHTSA vPIC 数据库备份，借助 Docker 运行 SQL Server 容器恢复备份，再迁移为 SQLite（也涉及 Postgres 容器配置），并按 VIN 解码所需保留核心表、删除其余表后提供 gzip/bzip2/xz/zstd 等压缩输出。使用方需准备 Docker、Python 3.8+、Make 及常用 Unix 工具，通过 make 目标运行完整或分步流程。README 未说明数据更新频率与许可细节，使用前需自行确认。

  • 下载约 180MB ZIP（解压约 1.1GB）的 vPIC SQL Server 备份并恢复后迁移为 SQLite
  • 提供 Full（336MB）与 Lite（63MB）两种数据库输出，Lite 仅保留 VIN 解码所需核心表
  • 支持 gzip、bzip2、xz、zstd 多种压缩格式，Lite 版 xz 压缩后约 12MB

适用场景（解读层）

  • 需要本地 SQLite 版 vPIC 数据进行 VIN 解码的应用
  • 需将 vPIC 数据从 SQL Server 迁移到 Postgres/SQLite 的数据工程流程
  • 需要较小体积、按核心表裁剪后的车型数据库分发场景
