🧭 简介解读层（AI·证据行可回查）

基于 Wails(Go)+React 构建的多数据源桌面数据库客户端，支持 AI 与 MCP 接入。

综述（解读层）

GoNavi 是一个基于 Go + Wails + React 的跨平台数据库客户端，供开发者连接查询多种数据源。内置支持 MySQL、PostgreSQL、Redis、Kafka、Milvus 等数据源，另可通过可选驱动代理连接 SQLite、ClickHouse 等。提供 AI 生成 SQL、MCP 连接、数据编辑、导出与审计日志；安装包约 20–26MB，也提供 Web Server 模式与 Docker 打包。

  • 内置支持 MySQL、PostgreSQL、Oracle、Redis、向量库、消息队列等多类数据源，并可经可选驱动代理扩展
  • 支持接入 OpenAI、Gemini、Claude 及 OpenAI 兼容 API，可附加表结构生成 SQL，并提供 MCP 连接本地或远程 Agent
  • 提供虚拟化数据表格、就地编辑、事务提交/回滚、CSV/XLSX/JSON/Markdown 导出、SSH 隧道、SQL 审计与执行日志

适用场景（解读层）

  • 开发者在同一桌面工具中查询与编辑关系型数据库、缓存、消息队列和向量库
  • 借助 AI 助手与 MCP 将结构化数据库上下文提供给编码 Agent，同时密钥保留在本机
  • 需要 SQL 审计、执行日志及 Docker/K8s/Web Server 部署形态的团队环境
