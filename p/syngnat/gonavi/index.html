基于 Wails（Go）+React 的跨平台多数据源数据库桌面客户端

综述（解读层）

GoNavi 是一个基于 Wails v3（Go + 系统 WebView）和 React 构建的数据库客户端，支持 SQL 数据库、缓存、向量库、消息队列等多类数据源，内置 MySQL、PostgreSQL、Redis、Kafka、Milvus 等驱动，另有大量可选驱动代理。它面向需要在本地统一管理多种数据源的开发者，提供 SQL 编辑、数据编辑导出、AI 辅助和 MCP 连接，并支持桌面与 Web Server 两种运行模式。

  • 内置支持 MySQL、PostgreSQL、Oracle、Redis、Kafka、Milvus 等 12 类数据源，并通过可选驱动代理扩展 SQL Server、ClickHouse、Elasticsearch 等
  • 支持接入 OpenAI、Gemini、Claude 及自定义 OpenAI 兼容 API，可将表结构作为上下文生成 SQL，并支持 MCP 连接 Claude Code 等代理，密钥保留在本地主机
  • 提供虚拟化数据网格、单元格就地编辑、事务提交回滚、CSV/XLSX/JSON/Markdown 导出、SSH 隧道连接及 SQL 审计中心，支持 Docker/K8s/Helm 打包

适用场景（解读层）

  • 在单一桌面工具中浏览和查询多种数据源（关系库、缓存、向量库、消息队列）
  • 借助表结构上下文生成、解释和审查 SQL，或将数据源工具通过 MCP 提供给编码代理使用
  • 通过执行日志、审计中心（默认脱敏、可保留导出）记录和检查 SQL 操作
