MySQL 相关工具与功能的 HOWTO 指南合集

综述（解读层）

该仓库收录围绕 MySQL 的操作指南，按安全、性能、高可用、云、备份恢复、监控等主题分类，涵盖企业审计、防火墙、透明加密、查询重写插件、复制与 InnoDB Cluster 等内容，适用于 5.7 与 8.0。作者提供安装脚本以便复现演示命令；部分功能需 MySQL 企业版，部分指南仍在编写中。

  • 包含 MySQL 企业审计、企业防火墙、透明数据加密（TDE）、查询重写插件等主题的指南
  • 指南声称兼容 MySQL 5.7 与 MySQL 8
  • 提供安装脚本用于搭建可复制粘贴命令的演示环境

适用场景（解读层）

  • 需要按步骤上手 MySQL 安全功能（审计、防火墙、TDE）的运维人员
  • 需要参考复制、InnoDB Cluster、NDB Cluster 搭建步骤的数据库管理员
  • 需要查询重写、分区自动化、备份恢复与监控入门资料的使用者
