libdrizzle 的延续分支，提供简化 API 的 C/C++ MySQL 连接库

综述（解读层）

libdrizzle-redux 是 libdrizzle C 连接器（上游 v5.1.4 于 2013 年停止开发）的 fork，支持以同步或异步方式连接并查询 MySQL 服务器。适合需要在 C/C++ 中直连 MySQL 的开发者。基于 autoconf 构建，可经 deb 包或源码安装，v6.0.3 起库文件名带主版本号以区分 API 级别。

  • 支持同步与异步两种方式连接并查询 MySQL 服务器
  • 提供 deb 包（Ubuntu Xenial/Bionic）、本地 deb/rpm 及源码多种安装方式
  • 遵循 SemVer 版本管理，v6.0.3 起库文件名与头文件安装路径附带 API 级别

适用场景（解读层）

  • 在 C/C++ 应用中通过简化 API 连接 MySQL 数据库
  • 需要异步查询 MySQL 服务器数据的场景
  • 上游 libdrizzle 已停止维护、需要包含后续修复版本的构建环境
