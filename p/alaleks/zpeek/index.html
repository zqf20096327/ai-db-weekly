🧭 简介解读层（AI·证据行可回查）

Zig 编写的终端数据库 TUI，支持 PostgreSQL、MySQL、SQLite 和 ClickHouse。

综述（解读层）

zpeek 是一个运行在终端里的数据库浏览与查询工具，基于 Zig 构建，发布为单个二进制文件并内置驱动。它面向希望在编辑器终端或 SSH 远程环境中直接查看数据的开发者：可浏览表行、按外键跳转关联记录、在带语法高亮和自动补全的编辑器中执行 SQL。连接配置和已保存查询存放在可编辑的普通文件中；文档说明客户端侧 SQL 检查不构成安全边界。

  • 支持 PostgreSQL、MySQL/MariaDB、SQLite、ClickHouse 四类数据库，通过连接字符串或 SQLite 文件路径打开
  • 提供表浏览、行过滤与排序、隐藏列、按 f 键跟随外键查看关联记录，以及带语法高亮和自动补全的 SQL 编辑器、查询历史与保存查询
  • 查询结果可导出为 CSV 或 JSON，支持保存连接、访问模式、dev/prod 颜色标识，并可在 SSH 环境下运行

适用场景（解读层）

  • 在不离开编辑器终端或 SSH 远程服务器的情况下浏览表数据与外键关联记录
  • 需要编写、保存并复用 SQL 查询，或将结果导出为 CSV/JSON 时
  • 本地开发与生产库之间切换连接，并借助颜色标识区分环境
