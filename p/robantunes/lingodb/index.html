🧭 简介解读层（AI·证据行可回查）

以3D空间坐标组织语言数据的Rust语言形态学数据库

综述（解读层）

Lingo 是一个用 Rust 实现的语言学数据库，将字母、音素、词素等元素按语义相似度、词源、语言层级三个维度编码为 3D 坐标，并通过八叉树索引和内存映射文件提供查询。内置 168 个英文节点（26 字母、42 音素、100 词素），支持词素分解、词源检索与跨域类比查询，提供流式查询 API 和 C 兼容 FFI。项目处于活跃开发阶段，尚未发布为 crate，需从源码构建；采用 FSL-1.1-ALv2 许可证，两年后自动转为 Apache 2.0，商业竞争性用途在转换前受限制。

  • 内置 168 个英文节点（26 字母、42 IPA 音素、100 词素），数据库文件约 13KB，通过 memmap2 内存映射读取
  • 提供流式查询 API（QueryBuilder），支持层级导航、相似度阈值、词源过滤等方法链查询
  • 使用八叉树索引实现空间查找，节点采用 60 字节打包结构；提供 C 兼容 FFI，JS/Python 绑定标注为开发中

适用场景（解读层）

  • 词汇学习类应用中按词根（如 photo、bio）检索关联词汇
  • NLP 流水线中的形态学预处理，如词素分解、词干提取与特征抽取
  • 语言学研究中的词源模式追踪，如希腊/拉丁/日耳曼语源词素的能产性分析
