SQLite 扩展，以 SQL 函数生成 RFC 4122 UUID

综述（解读层）

sqlite3-uuid 是一个 SQLite 加载式扩展，通过 make 编译为共享库后可由 Python sqlite3 或 sqlite3 CLI 等加载。它提供 uuid1/3/4/5、nil UUID、DNS/OID/URL/X500 命名空间函数，以及 TEXT 与 16 字节 BLOB 互转函数。构建需 libsqlite3、OpenSSL、uuid 开发头文件，目前仅支持 Linux 和 Mac OS X。

  • 提供 uuid1、uuid3、uuid4、uuid5 及 nil UUID 生成函数
  • 提供 uuid_ns_dns、uuid_ns_oid、uuid_ns_url、uuid_ns_x500 命名空间函数
  • 提供 uuid_to_blob 与 uuid_to_text 实现 TEXT 与 16 字节 BLOB 互转

适用场景（解读层）

  • 在 SQL 查询或表默认值中直接生成符合 RFC 4122 的 UUID
  • 将 TEXT 形式 UUID 转为 16 字节 BLOB 以减小存储
  • 在 Linux 或 Mac OS X 的 SQLite 应用中通过加载扩展获得 UUID 函数
