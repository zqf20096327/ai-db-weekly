Swift/AppKit 编写的原生 macOS 数据库客户端，支持 PostgreSQL 与 MySQL

综述（解读层）

Foxlume Query 是一个用 Swift 和 AppKit 编写的开源 macOS 数据库客户端，采用 AGPL-3.0 许可，当前版本为 0.1.0 早期 alpha。它提供上下文感知的 SQL 补全、表格数据编辑、查询计划图和 ER 图，PostgreSQL/MySQL/MongoDB/Redis 协议内置于应用中，无需单独安装驱动。数据编辑默认暂存、保存时运行事务，连接可设多种安全模式。

  • 内置 PostgreSQL、MySQL、MongoDB、Redis 协议，无需安装驱动；SQL 编辑器提供上下文感知补全、保存查询、语句级运行与格式化
  • 支持 Explain/Explain Analyze 查询计划图、整 schema ER 图导出 PNG/PDF，以及带 ALTER 预览的表结构编辑器
  • 数据编辑暂存至保存、保存运行事务；导出 CSV/JSON/NDJSON/XLSX/SQL dump，导入 CSV/JSON/NDJSON/XLSX，可运行任意大小 SQL 文件并经 SSH 隧道执行备份与恢复

适用场景（解读层）

  • 在 macOS 上浏览、编辑 PostgreSQL 和 MySQL 的表数据并编写 SQL
  • 查看查询执行计划、绘制 schema ER 图及修改表结构
  • 导入导出 CSV/JSON/Excel 数据，或对数据库执行备份与恢复
