sqlite-simple：SQLite 的 Haskell 中层绑定库，提供自动类型转换 API

综述（解读层）

sqlite-simple 是面向 Haskell 开发者的 SQLite 数据库中层绑定库，构建于 direct-sqlite 之上，其 API 建模自 postgresql-simple 并部分代码借用自 mysql-simple。它在数据库与 Haskell 类型之间实现一定程度的自动数据转换，通过 cabal 从 Hackage 安装。README 提示 Windows 安装需参考 direct-sqlite 的说明。

  • 提供在数据库与 Haskell 类型之间进行部分自动数据转换的便捷 API
  • API 建模自 postgresql-simple，构建于 direct-sqlite 包之上
  • README 附带基准测试套件 db-bench 及单元测试示例

适用场景（解读层）

  • 需要在 Haskell 程序中读写 SQLite 数据库文件
  • 从 postgresql-simple/mysql-simple 迁移或统一风格的 SQLite 访问
  • 希望减少手写 SQL 结果到 Haskell 类型转换代码的场景
