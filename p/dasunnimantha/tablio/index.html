🧭 简介解读层（AI·证据行可回查）

开源跨平台桌面数据库客户端，以 Rust+React 统一连接多种数据库

综述（解读层）

Tablio 是一个开源桌面数据库客户端，基于 Rust/Tauri 2 后端与 React/TypeScript 前端构建，通过统一界面连接 PostgreSQL、MySQL、MariaDB、SQL Server、CockroachDB、TiDB、SQLite 及 Cassandra/ScyllaDB。提供数据浏览编辑、SQL 控制台、ER 图、导入导出和服务器管理功能，支持 SSL/TLS 与 SSH 隧道，采用 MIT 许可证，可通过 deb/rpm/dmg/msi 包安装或从源码构建。

  • 支持通过单一应用连接 PostgreSQL、MySQL、MariaDB、SQL Server、CockroachDB、TiDB、SQLite 和 Cassandra/ScyllaDB，使用 sqlx 连接池（MSSQL 使用 tiberius 单连接）
  • 提供基于 AG Grid 的数据网格、Monaco 编辑器的 SQL 控制台、查询执行计划查看、结果图表化以及 CSV/JSON/SQL/Excel 导入导出
  • 支持 SSL/TLS、SSH 隧道（密码/身份文件/agent 认证）、连接保存与颜色标记，使用 pg_dump/mysqldump 等原生工具执行备份恢复

适用场景（解读层）

  • 需要在桌面端集中浏览、查询和编辑多种数据库的表数据
  • 通过可视化界面管理表结构、角色、会话与查询性能统计
  • 需要将 CSV/Excel 数据导入数据库或导出为 CSV/JSON/SQL/Excel 格式
