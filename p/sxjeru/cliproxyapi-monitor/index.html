CLIProxyAPI 用量数据看板，拉取并持久化到 Postgres 进行可视化。

综述（解读层）

这是一个基于 Next.js App Router、Drizzle 和 Postgres 构建的数据看板，供自部署 CLIProxyAPI 的用户追踪模型用量。它通过 /api/sync 接口拉取上游用量数据并去重入库，前端提供折线图、柱状图和费用列表。因 CPA v6.10.0 移除了 /usage 接口，需配置随附的 adapter.js 从 Redis 队列聚合数据还原接口，或回退旧版 CPA。

  • 通过 /api/sync 接口（支持 GET/POST、带鉴权）拉取上游用量数据并去重写入 Postgres
  • 前端提供日粒度折线图、小时粒度柱状图和模型费用列表，支持按时间范围、模型、Key、凭证筛选
  • 支持模型单价配置与从 models.dev 自动拉取价格，并提供 Vercel Cron、Cloudflare Worker 等定时同步方式

适用场景（解读层）

  • 将 CLIProxyAPI 的临时性用量数据持久化到数据库并长期追踪
  • 在 Vercel 上部署看板，通过定时任务自动同步用量与费用数据
  • CPA 升级到 v6.10.0 及以上后，通过 adapter.js 从 Redis 队列还原 /usage 接口继续采集数据
