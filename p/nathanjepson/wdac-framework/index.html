基于 PowerShell 与 SQLite 管理 WDAC 策略创建、部署与编辑的模块

综述（解读层）

WDAC-Framework 是一个 PowerShell 模块，用于创建、部署和编辑 Windows Defender Application Control（App Control for Business）策略，并用 SQLite 数据库跟踪所信任的发布者、证书、文件哈希等规则。规则可通过文件扫描或代码完整性事件日志解析生成；支持经 WinRM 与 SMB 管理远程设备，按设备组分配策略。要求 PowerShell 7、Windows 10/11 Pro 或企业版（ConfigCI cmdlets），仅支持多策略格式，不支持 WHQL 等部分规则级别，作者注明服务器环境未经验证。

  • 通过文件扫描（封装 Get-SystemDriver）或解析 Windows 代码完整性事件日志（封装 WDACAuditing 模块）生成规则，经 Register-WDACEvents 注册后用 Approve-WDACRules 系列逐级设定信任
  • 使用 WinRM（端口 5985/5986）与 SMB（端口 445）远程部署策略，支持创建设备组并分配策略；可选用合并 Microsoft 推荐的用户态与内核态阻止规则
  • 支持策略签名（需政策签名证书与 Windows SDK 的 SignTool）、在规则上方添加注释说明信任原因、用 -purge 清理数据库中的扫描/日志记录

适用场景（解读层）

  • 未部署 UEM（如 Intune）的环境中，通过 WinRM/SMB 集中创建并推送 WDAC 策略到分组的 Windows 工作站
  • 在启用策略前，以审计模式解析代码完整性日志，审查并逐级批准发布者、文件名、哈希等信任规则
  • 用 SQLite 数据库集中记录与维护企业所信任的发布者、证书与二进制规则，并附带信任原因注释
