桌面 SQL 编辑器，支持 PostgreSQL、MySQL/MariaDB、SQLite 及 SSH 隧道连接

综述（解读层）

OpenTable 是一个 MIT 协议的开源桌面数据库客户端，基于 Electron/React/TypeScript 构建，用于连接 PostgreSQL、MySQL/MariaDB 和 SQLite。提供基于数据库实际 schema 的自动补全、虚拟化结果表格、带主键映射的单事务编辑，以及可视化建表/改表。AI 聊天为可选功能，需自备密钥或本地模型，自动执行的 SQL 受白名单控制。

  • 支持 PostgreSQL、MySQL/MariaDB、SQLite 连接，可通过 ssh-agent、私钥或密码建立 SSH 隧道，密码经操作系统钥匙串加密存储
  • 查询支持取消运行、多语句脚本分结果渲染、查询历史与保存查询；结果表格采用虚拟化 DOM 渲染，可导出 CSV、JSON、SQL inserts 和 Markdown
  • 单元格编辑在单个事务中以绑定参数提交；可视化 schema 构建器将每次变更预览为确切 SQL，SQLite 的列变更通过事务内整表重建实现

适用场景（解读层）

  • 开发者或 DBA 在本地或经 SSH 隧道连接远程数据库进行查询与数据浏览
  • 对含主键的单表查询结果进行行内编辑，或将大结果集导出为 CSV/JSON/SQL/Markdown
  • 通过可视化界面创建或修改表结构（列、主键、索引、外键），运行前预览 SQL
