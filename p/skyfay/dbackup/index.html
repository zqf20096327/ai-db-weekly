🧭 简介解读层（AI·证据行可回查）

自托管备份自动化平台，单容器按计划备份加密数据库与文件

综述（解读层）

DBackup 以单个 Docker 容器运行，按计划备份 10 种数据库（如 PostgreSQL、MySQL、MongoDB、Redis）及目录文件，支持直连或经 SSH 执行备份工具。备份产物为标准 dump 或 TAR 归档，用 AES-256-GCM 加密后推送至 13 类存储目标，并提供 Web 界面执行恢复。适用于自托管服务器与团队运维场景；许可证为 GPL-3.0，尚无外部正式安全审计。

  • 支持 PostgreSQL、MySQL、MariaDB、MongoDB、Redis、Valkey、SQLite、MSSQL、Firebird 等 10 种数据库，可直连或经 SSH 备份
  • 备份经 AES-256-GCM 加密压缩，输出到 S3、Google Drive、Dropbox、SFTP、SMB、WebDAV 等 13 类存储目标
  • 支持增量备份、日/周/月/年保留策略、REST API、OIDC SSO、2FA 与审计日志

适用场景（解读层）

  • 为自托管服务器的多数据库和关联目录配置统一计划备份与加密存储
  • 需要增量备份与多级保留策略、并支持多种云存储目标的环境
  • 团队场景下需要权限分组、审计日志和 REST API 管理备份的部署
