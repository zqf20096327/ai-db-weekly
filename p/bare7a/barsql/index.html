基于 Rust 与 GPUI 的本地优先桌面 SQL 客户端，支持多种数据库。

综述（解读层）

BarSQL 是一款用 Rust 和 GPUI 构建的桌面 SQL 工作台，连接 PostgreSQL、MySQL/MariaDB、SQL Server、ClickHouse、Turso/libSQL 和 SQLite。所有数据处理在本地完成，无账户和遥测，数据存于可随程序移动的 BarSQL-data 文件夹。提供 Windows、macOS、Linux 安装包，支持自更新和 SHA-256 校验，采用 GPL-3.0 许可证，也可通过 cargo 从源码构建。

  • 支持 PostgreSQL、MySQL/MariaDB、SQL Server、ClickHouse、SQLite 和 Turso/libSQL 的连接与读写，并提供只读模式、SSL/TLS 传输和 SSH 隧道
  • 内置模式感知自动补全、多光标编辑、查询计划查看、ER 图、结构对比同步脚本、CSV/SQL 导入导出与结果图表
  • 通过 MCP 协议向 AI 助手开放数据库读取，并可按位置限制写入权限；数据集中于便携的 BarSQL-data 文件夹

适用场景（解读层）

  • 开发者在本地桌面环境中查询、编辑和管理多种数据库，无需账户或云服务
  • 通过 SSH 隧道访问堡垒机后的数据库，或以只读模式安全查看生产库
  • 需要便携化部署（U 盘/网络盘）的场景，以及在受控环境下让 AI 助手通过 MCP 有限访问数据库
