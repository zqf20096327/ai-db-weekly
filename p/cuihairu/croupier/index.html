面向游戏运营的 Server/Agent/SDK 控制平面平台

综述（解读层）

Croupier 是面向单个游戏公司多游戏、多环境运营场景的控制平面平台，由 Web 控制台、Server 控制面、游戏 VPC 内 Agent 代理和六语言 SDK 组成。传输采用统一 TCP 会话模型（双向请求、多路复用、重连），业务边界为 gameId+env，底层基于 Gin、GORM、Casbin 等开源组件。README 明确说明高风险生产写入尚未获得审批，属于需注意的当前限制。

  • 提供 sidecar、devops、capture、synthetics 四类 Agent 角色，分别承担函数网关、带审计的内网远程访问、数据库 CDC 与外部探测
  • 统一会话传输：单长连接、双向请求、心跳/重连/背压/流分离，Agent-Server 与 SDK-Agent 共享同一会话运行时
  • 提供 Go/C#/Java/C++/Python/JS 六种官方 SDK，并通过 MCP 协议以只读方式和身份审计方式向 AI 代理暴露控制面

适用场景（解读层）

  • 游戏公司内部 GM 运营：通过 Web 控制台统一管理多游戏多环境的函数注册、调度与作业
  • 游戏服务可观测性运维：数据库 CDC 捕获、HTTP/TCP/ICMP 外部探测与带回放存档的远程访问
  • 开发调试：SQLite 驱动支持本地开发测试，JSON Schema 能力契约自动生成控制台 UI
