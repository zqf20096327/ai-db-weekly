🧭 简介解读层（AI·证据行可回查）

基于 Data Mapper、Unit of Work 与 Identity Map 模式的 Node.js TypeScript ORM。

综述（解读层）

MikroORM 是面向 Node.js 的 TypeScript ORM，采用 Data Mapper、Unit of Work 和 Identity Map 模式实现自动变更追踪，通过 em.flush() 在单个事务中写出变更。支持 MongoDB、MySQL、PostgreSQL、SQLite/libSQL 等多种数据库，实体可用 defineEntity、装饰器或 EntitySchema 定义。适合需要在 Node.js 项目中管理数据库实体与事务边界的 TypeScript/JavaScript 开发者。

  • 支持 MongoDB、MySQL、MariaDB、PostgreSQL（含 CockroachDB 和 PGlite）、SQLite/libSQL、MSSQL 和 Oracle 数据库驱动
  • 通过 Identity Map 与 Unit of Work 实现实体变更自动追踪，flush 时在事务内执行计算出的变更
  • 提供 QueryBuilder、Kysely 集成、模式生成与迁移、实体生成与数据填充、生命周期钩子等核心功能

适用场景（解读层）

  • Web 应用中通过 RequestContext 按请求隔离 identity map，管理请求级实体状态
  • 需要以实体操作方式控制数据库事务边界，由 flush 统一生成 SQL 的应用
  • 使用 Express、Nest、Koa、NextJS 等框架的 Node.js/TypeScript 项目接入数据库
