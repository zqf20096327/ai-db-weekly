🧭 简介解读层（AI·证据行可回查）

Go 语言的 SQL 数据映射库，将查询结果映射到含关联关系的复杂结构体

综述（解读层）

Carta 是一个面向 Go 的 SQL 数据映射库，用于把 database/sql 查询的行结果映射到 Go 结构体，并在映射过程中追踪 has-one 与 has-many 关系。字段可通过 db 标签或蛇形命名匹配列名，支持基本类型、time.Time、protobuf Timestamp 和 sql.NullX。它不是 ORM，不生成 SQL；使用 MySQL 时需在连接串加 parseTime=true，且会去重查询结果。适合需自行编写 SQL 但希望自动组装嵌套关联数据的开发者。

  • 在映射 SQL 行时自动追踪并组装 has-one 与 has-many 关系
  • 支持 db 标签自定义列名，未加标签时按字段名蛇形命名匹配
  • 缓存结构体元信息以减少反射操作

适用场景（解读层）

  • 需要执行手写复杂 SQL（含 join）并将结果映射为嵌套 Go 结构体
  • 查询结果包含一对多关系、希望避免多次查询或手工后处理
  • 代码评审流程严格、倾向数据库映射模式而非 ORM 的团队
