🧭 简介解读层（AI·证据行可回查）

SQL数据库性能测试桌面工具，生成测试数据并运行随机化查询分析响应时间

综述（解读层）

SQLitmus 是一款面向中小型项目开发者的 SQL 数据库性能测试工具，基于 Electron 构建，支持 Windows、macOS 和 Linux。它通过 GUI 配置字段约束与数据生成器，向测试数据库写入大量符合模式的测试数据，再依据查询模板生成随机化查询并记录响应时间，同时提供结果绘图与过滤功能。支持 MySQL、PostgreSQL、MariaDB 三种数据库。

  • 提供 GUI 管理数据库连接配置，并按数据库级别持久化配置
  • 内置 23 种数据生成器及自定义生成器，支持六种字段约束类型
  • 通过查询模板语法 ${expression} 自动生成数百条随机化有效查询

适用场景（解读层）

  • 为中小型项目数据库填充符合模式的大规模测试数据
  • 对 MySQL、PostgreSQL、MariaDB 数据库执行随机化查询负载并测量响应时间
  • 通过 schema 图表检查外键关系配置
