🧭 简介解读层（AI·证据行可回查）

单时钟并发压测 HTTP、数据库与 Redis 的 Go 负载测试工具，按时间桶关联各层延迟。

综述（解读层）

Barrage 是一个 Go 编写的 CLI 负载测试工具，在同一时钟下驱动 HTTP、数据库与 Redis 并发负载，把各层延迟记录到相同时间桶并逐桶对比，生成自包含 HTML 报告定位延迟尖峰归属。数据库端通过 database/sql 内置支持 Postgres、MySQL、SQLite，其他驱动可经空导入注册接入。适用于需要区分应用层与存储层延迟来源的测试者。

  • 在同一时钟下并发运行 HTTP、数据库、Redis 压测，并将各层 P99 延迟对齐到共享时间轴
  • 提供 compare 命令对比两次运行的 JSON 结果，按 --fail-on 延迟预算返回非零退出码，可作 CI 门禁
  • 支持容量扫描模式，逐级提升并发（先倍增后线性细化），输出 concurrency vs P99 曲线与断点归因

适用场景（解读层）

  • 应用变慢时判断瓶颈来自应用本身还是数据库/缓存层
  • 在 CI 流水线中用基线对比与退出码做发布前的延迟回归检查
  • 通过容量扫描实验确定系统在延迟阈值下的并发断点
