🧭 简介解读层（AI·证据行可回查）

用 quick-xml 状态机解析 Discogs 月度 XML 数据转储并写入 Postgres 的 Rust 工具。

综述（解读层）

该项目是一个 Rust 编写的 ETL 工具，将 discogs.com 每月发布的 XML 数据转储文件解析后导入 Postgres 数据库。使用者通过命令行传入 gz 压缩的 XML 文件路径即可运行加载，支持导入后创建项目预定义的索引，并提供小型测试数据供本地验证。适用于需要将 Discogs 音乐发行数据落入关系型数据库的场景。

  • 基于 quick-xml 库的状态机解析机制读取 gz 压缩的 Discogs XML 转储文件
  • 支持通过命令行参数一次传入多个 XML 文件进行加载
  • 提供 --create-indexes 参数用于导入后初始化预定义索引

适用场景（解读层）

  • 将 Discogs 月度数据转储（releases、artists、labels 等）导入 Postgres 用于本地数据分析
  • 使用附带的 test_data 小型示例文件快速验证加载流程
  • 通过 docker-compose 启动 Postgres 后批量导入音乐发行数据
