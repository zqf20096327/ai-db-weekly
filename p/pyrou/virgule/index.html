原生 macOS CSV 探索器，将 CSV 导入本地 SQLite 并以 SQL 查询浏览。

综述（解读层）

Virgule 是运行在 Apple Silicon Mac 上的原生 CSV/TSV 查看与查询工具，用 Swift/AppKit 构建界面，Rust 引擎通过 C API 将文件流式写入应用管理的 SQLite 缓存，查询仅接受只读的 SELECT/WITH/EXPLAIN。项目处于早期开发阶段，暂无预编译版本，需 Xcode 26 与 Rust 1.85 以上环境从源码构建。

  • 每个导入的文件成为本地 SQLite 表，可用 $file 与 $row_id 编写含聚合、CTE 与计算列的只读 SQL 查询
  • 支持逗号、分号、制表符、管道分隔符，UTF-8/UTF-16/Windows-1252 编码，带引号字段与无表头文件，类型推断保守处理歧义值
  • 网格按需加载分页，界面基于 AppKit 实现，无内嵌 WebView，查询编辑器提供语法高亮、补全与历史记录

适用场景（解读层）

  • 在 Mac 上浏览大型 CSV/TSV 数据集并按列排序、搜索（支持正则）
  • 用 SQL 对 CSV 数据进行筛选、聚合与计算而不修改源文件
  • 将当前查询视图导出为新的 CSV 文件
