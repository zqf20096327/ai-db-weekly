Rust 编写的原生 PostgreSQL 图形客户端，单二进制约 10 MB

综述（解读层）

Ferox 是一个用 Rust 构建的 PostgreSQL 桌面客户端，支持多标签查询编辑、EXPLAIN 可视化、表结构编辑、ER 图、Schema diff、CSV 导入导出和 SSH 隧道连接，并集成 AI 辅助功能（自然语言生成 SQL、解释与优化查询）。凭据存于系统密钥链，支持从 DBeaver 导入连接。AI 生成的 SQL 不会自动执行，仅打开复核窗口。提供 Windows/macOS/Linux 预编译包，也可用 Rust 1.88+ 从源码构建。

  • 基于 egui 与 tokio，单二进制约 10.1 MB，README 记载空闲内存约 40–55 MB、冷启动低于 200 ms（v0.3.1 Windows 11 实测）
  • 包含 AI 辅助查询功能，支持 Anthropic、Groq、Ollama、OpenAI 及任意 OpenAI 兼容端点，可从数据库读取实时 schema 生成 SQL；生成结果不自动执行
  • 提供 schema dump（无需 pg_dump、经 SSH 隧道可用，要求 PostgreSQL 12+）、CSV 流式导入（COPY FROM STDIN）、CSV/JSON/INSERT 导出，凭据通过 OS 密钥链存储

适用场景（解读层）

  • 需要图形界面浏览、编辑和查询 PostgreSQL 数据库的开发者与 DBA
  • 希望用自然语言或可视化 Join Builder 组装 SQL、并通过 EXPLAIN 可视化查看执行计划的用户
  • 需要通过 SSH 隧道管理多连接、批量导入导出数据或比较两个 schema 结构差异的场景
