🧭 简介解读层（AI·证据行可回查）

一个以 PSR-4 命名空间和默认/自定义路由为核心的轻量 MVC PHP 框架

综述（解读层）

Ciro 是一个面向个人项目快速搭建的 MVC PHP 框架，采用单一入口与 PSR-4 命名空间结构，支持默认路由和自定义路由两种 URL 解析方式。框架附带含注册登录的模板项目，提供 Mysqli、PDO、MongoDB 三种 UserRepository 变体，需 PHP 5.6+（MongoDB 需 7.0+）和 mod rewrite 支持，可按 XAMPP 步骤部署。

  • 提供默认路由（{route}/{controller}/{action}/{param}）与支持 GET/POST/PUT/DELETE 等 HTTP 动词的自定义路由，参数可通过 $this->params 或方法实参传入
  • 数据库辅助类覆盖 Mysqli、PDO 和 MongoDB，控制器分 WebController（返回 HTML）与 ApiController（返回 JsonResult）
  • 内置视图布局（Bootstrap 4、jQuery 3.2.1、Font Awesome 5）、Flash 消息、自定义错误页及带日志的异常处理

适用场景（解读层）

  • 在 XAMPP 环境中快速启动 PHP 个人项目或原型开发
  • 借助模板项目中的注册/登录系统及三种数据库 UserRepository 变体启动含用户认证的应用
  • 需要 REST 风格自定义路由模式匹配与通用模式路由的 PHP Web/API 项目
