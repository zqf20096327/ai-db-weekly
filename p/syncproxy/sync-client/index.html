SyncProxy 的 JavaScript 客户端，通过 script 标签配置实现嵌入式数据库双向实时同步

综述（解读层）

该客户端用于让使用 IndexedDB、SQLite、WebSQL、LokiJS 等嵌入式数据库的 JavaScript 离线应用与 SyncProxy 服务端后端数据库（MySQL、SQL Server、MongoDB 等）双向同步。安装方式为 git clone 后在 index.html 中以 script 标签引入，通过标签属性配置连接器类型、代理 ID、协议等参数，需配合 SyncProxy 服务端使用。

  • 支持 IndexedDB、WebSQL、SQLite、SQLJS、LocalStorage、IonicStorage、LokiJS 等连接器类型，默认 IndexedDB
  • 通过 ws/wss 协议通信，支持 reactiveSync 双向实时同步，可配置按表和方向在服务端启用
  • 提供 autoUpgradeDB 自动升级库结构、zipData 压缩传输、customCredentials 自定义凭据及 onServerChanges/onSyncEnd 回调等参数

适用场景（解读层）

  • 需要离线能力并与后端数据库同步的移动应用或渐进式 Web 应用
  • 使用 Ionic 混合移动应用并接入 IonicStorage 的场景
  • 无服务端 schema 的 NoSQL 或 Auto Backendless 数据库，需从客户端数据发现待同步表结构的场景
