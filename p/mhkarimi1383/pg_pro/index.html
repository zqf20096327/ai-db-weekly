综述（解读层）

pg_pro 是一个位于 PostgreSQL 之上的代理层，用 Go 编写。它在启动时按 config.yaml 为每台服务器建立连接池，对到来的查询先进行解析并检查关系信息，返回语法错误后按查询类型（读/写）在主库与副本间做负载均衡，并支持基于查询类型判断的缓存和通过中央 yaml 文件管理用户。README 明确说明当前不建议用于生产，自动主从检测尚未实现。

  • 解析传入查询并检查关系信息，可识别并返回查询错误
  • 按查询类型（读/写）在多台服务器间做负载均衡，配置文件可位于 /etc/pg_pro/、$HOME/.pg_pro 或当前目录
  • 用户管理支持中央 yaml 提供者；缓存按查询类型判断实现

适用场景（解读层）

  • 希望在主库与副本之间按查询读写类型分发连接的场景
  • 希望通过中央 yaml 文件集中管理 PostgreSQL 用户的场景
  • 需要构建本地开发环境（Go + CGO_ENABLED=1，依赖 pganalyze/pg_query_go 解析查询）或用 Docker 构建部署的场景
