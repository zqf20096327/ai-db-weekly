基于文件管理 FaunaDB 资源的 Node.js CLI 工具

综述（解读层）

Fauna GQL Upload 是一个 Node.js 命令行工具，用于通过项目内文件更新 FaunaDB 数据库的 GraphQL schema、函数、索引与角色，无需访问 FaunaDB 控制台。它通过 graphql.fauna.com/import 端点导入 schema，并用 faunadb JS 驱动创建其他资源；需本地安装 faunadb（不低于 4.0.0 才支持 AccessProvider），v2 起不再支持全局安装，密钥环境变量为 FGU_SECRET。

  • 支持以文件方式管理用户自定义函数、角色、索引和 GraphQL schema，并可通过 graphql.fauna.com/import 端点更新 schema
  • 支持 TypeScript，自 1.9.0 起自动处理类型检查与编译，无需额外配置
  • 支持通过 GraphQL codegen 生成代码，资源可纳入版本控制

适用场景（解读层）

  • 在编辑器内直接更新 FaunaDB 数据库 schema 与 FQL 函数，不经 FaunaDB 控制台
  • 将 FaunaDB 资源以代码形式纳入 Git 版本控制与 CI 流程
  • 在多个数据库或账户之间复制 FaunaDB 资源配置
