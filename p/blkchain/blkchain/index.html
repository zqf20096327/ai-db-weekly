将比特币区块链快速导入 PostgreSQL 的 Go 工具

综述（解读层）

该项目用 Go 实现从 Bitcoin Core 节点直接读取 LevelDb 区块索引、区块文件与 UTXO 集（非 RPC 方式），将整个区块链导入 PostgreSQL，README 称在普通硬件上约 21 小时完成。导入后可经 Bitcoin 协议连接节点增量追块（支持 -wait 持续写入），并可为自托管 Block Explorer 提供数据源。导入分流式 COPY 与建索引两阶段；需 Core 停止运行，磁盘占用超 600GB。

  • 直接读取 Bitcoin Core 的 LevelDb 区块索引与 UTXO 集完成初始批量导入
  • 通过 COPY 流式写入，每张表由独立 goroutine 负责导入
  • 支持通过 Bitcoin 协议连接节点增量追加新区块，可用 -wait 持续等待新区块

适用场景（解读层）

  • 为比特币数据构建私有 PostgreSQL 数据库，配合私有 Block Explorer 使用
  • 对区块链交易、输入、输出数据进行 SQL 查询与分析
  • 需要离线批量导入后持续追块的链上数据归档场景
