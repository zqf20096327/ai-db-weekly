零配置的 Node.js SQLite 封装库，以 JavaScript 对象直接操作 SQLite 表。

综述（解读层）

NoSQLite 是一个用 CoffeeScript 编写的 Node.js SQLite 封装库，面向希望在 Node 应用中直接存储和查询 JS 对象的开发者。它省去建表和 ALTER 操作：首次 save 时自动创建表，新增属性时自动加列；API 提供 save、find、find_or_save 等方法。运行前需自行编译其 fork 版 node-sqlite 驱动并复制绑定文件。

  • 零配置：save 时自动创建缺失的表和列，无需写 CREATE TABLE 或 ALTER TABLE
  • 提供 save、find（支持谓词表达式）、find_or_save 及 migrate_table 等数据迁移方法
  • 支持 web 模式，通过 HTTP 接口暴露 find/save/find_or_save 操作

适用场景（解读层）

  • Node.js 应用中以对象方式读写 SQLite 数据，无需手写 SQL
  • 需要把既有表结构或数据格式迁移到新 schema 的场景
  • 通过 HTTP 接口远程访问本机 SQLite 数据库
