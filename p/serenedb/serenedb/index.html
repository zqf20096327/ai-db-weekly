Postgres兼容的搜索引擎与分析一体的实时OLAP数据库

综述（解读层）

SereneDB 是一个开源数据库，在单个 Postgres 兼容引擎中同时提供 BM25 全文检索和列式分析能力，检索部分基于 IResearch C++ 库实现。可直接查询 S3/HDFS 上的 Parquet、Iceberg、CSV、JSON 数据，并支持向量检索与混合排序。适用于需要同时使用 SQL 和搜索功能的团队。README 未包含安装与运行的具体步骤，仅提示构建说明位于 Contributing 文档。

  • 基于 IResearch 检索库实现 BM25 全文搜索，查询语法兼容 Postgres
  • 支持零 ETL 直接查询 S3/HDFS 上的 Parquet、Iceberg、CSV、JSON 数据
  • 内置向量搜索与混合排序，采用列式实时更新

适用场景（解读层）

  • 日志数据的搜索与分析混合负载场景
  • 基于向量与混合排序的 AI 应用检索
  • 希望复用 Postgres 生态工具与 SQL 经验的团队
