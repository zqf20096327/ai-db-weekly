🧭 简介解读层（AI·证据行可回查）

基于 Docker 的实时数据流处理管道，串联 Airflow、Kafka、Spark 与 Cassandra。

综述（解读层）

该项目搭建一条端到端数据管道：从 randomuser.me API 获取合成用户数据，经 Airflow 编排写入 PostgreSQL，再由 Kafka 与 Zookeeper 流式传输，交由 Spark 处理后存入 Cassandra，全流程以 Docker 容器封装。README 提供架构说明与配套 YouTube 教程，适合作为学习各组件协作方式的教学项目，未见独立安装脚本说明。

  • 整合 Airflow、Kafka、Zookeeper、Spark、Cassandra、PostgreSQL 六类组件，通过 Docker 容器化部署
  • 包含 Control Center 与 Schema Registry 用于 Kafka 流的监控与 schema 管理
  • Spark 采用 master/worker 节点结构进行数据处理

适用场景（解读层）

  • 学习数据工程管道中各组件的协作流程
  • 搭建从 API 数据摄取到流式处理的演示环境
  • 按配套教程复现实时数据流处理实践
