Go 编写的 Postgres→Kafka 事务性 Outbox 收割器

综述（解读层）

goharvest 是 Postgres 与 Kafka 之间的事务性 Outbox 模式实现。应用在事务中向 outbox 表写入记录，goharvest 在后台轮询该表并按记录中的 topic、key、headers 发布到 Kafka，维护消息因果顺序，无需数据库开启 CDC。支持独立进程（reaper）与嵌入式两种运行方式，通过 NELI 基于 Kafka 实现主节点选举，面向需要将数据库变更与消息发布绑定的微服务开发者。

  • 支持 standalone（reaper 进程）与 embedded（库引入）两种运行模式，standalone 模式可服务非 Go 应用
  • 通过 NELI 基于 Kafka 的分区独占分配实现主节点选举，维护消息的因果顺序，不需要数据库开启 CDC
  • outbox 记录支持自定义 topic、必填 key、可选 value（可为 compaction tombstone）与 header 键值对

适用场景（解读层）

  • 微服务中需要将 Postgres 数据变更与 Kafka 消息发布在同一事务内保证一致的场景
  • 以 sidecar 守护进程（reaper）形式部署，配合任意语言编写、写入标准 outbox 表的应用
  • 嵌入式运行并注册 EventHandler，在同一时间仅单进程执行附加工作负载的调度场景
