原生 Mac 数据库客户端与 GUI，Swift 加 Rust 核心实现

综述（解读层）

TablePort 是一款运行于 Apple silicon Mac 的原生数据库 GUI，使用 Swift/AppKit 与 Rust 核心构建，采用 Apache-2.0 许可。它提供连接管理、数据网格编辑、SQL 查询、CSV/JSON/SQL 导出等功能，密码存于 macOS 钥匙串。目前处于公开测试阶段，仅支持 macOS 14 以上，因依赖未公开的 mac-kit，暂无法在作者环境外从源码构建。

  • 支持 PostgreSQL、MySQL/MariaDB、SQLite、libSQL/Turso、Redis、MongoDB、Cassandra 和 Firestore；SQL Server、Oracle 与 Cloudflare D1 处于预览阶段
  • 提供数据网格排序、筛选、分页、就地编辑、外键跳转，编辑以事务方式在审查 SQL 后提交，并支持只读模式与 SSH 隧道、TLS 连接
  • 连接、查询历史和保存的查询保存在本机，密码存于 macOS Keychain；README 称大表切换耗时约 60–100 毫秒

适用场景（解读层）

  • 在 Apple silicon Mac 上浏览、筛选、编辑和查询多种数据库
  • 需要以 CSV、JSON 或 SQL 格式导出表数据的场景
  • 希望连接信息与查询历史保留在本机、密码由 macOS Keychain 管理的工作流
