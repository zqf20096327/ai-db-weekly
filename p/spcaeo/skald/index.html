🧭 简介解读层（AI·证据行可回查）

自托管的访问日志网页分析工具，统计含AI爬虫在内的全量流量

综述（解读层）

Skald 读取 Web 服务器自身的访问日志做统计分析，将请求归入真人、AI 助手、搜索引擎、爬虫扫描器和自有流量五组，并覆盖来自 Vercel、Cloudflare、CloudFront 等来源的日志。无 Cookie、无需浏览器脚本，数据留存于自托管服务器，提供实时面板、线索/收入归因和安全扫描分析，面向网站所有者与运维。需 Python 3.11+，采用 Elastic License 2.0，不拦截流量、只读日志。

  • 读取服务器访问日志并将每个请求归入五组互斥分类（真人/AI助手/搜索引擎/爬虫扫描/自有流量），五组之和等于日志总量
  • 内置独立审计机制，用第二套解析规则重算全部数字，不一致时整天数据不予展示
  • 通过 IP 所有方地址或 DNS 校验爬虫身份，识别伪造 UA 并单独归类；支持按 IP/邮箱/访客 ID 跨日追踪单个访客

适用场景（解读层）

  • 统计 JavaScript 分析工具覆盖不到的 AI 助手与爬虫流量，识别藏在 Direct 来源中的 AI 引荐点击
  • 基于访问日志做线索与收入归因，对接 CRM 与预约工具的 webhook
  • 监控站点安全扫描与攻击尝试，配合防火墙生成屏蔽规则
