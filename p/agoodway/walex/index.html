Elixir 编写的 Postgres CDC 库，基于 WAL 逻辑复制监听表变更事件

综述（解读层）

WalEx 是一个 Elixir 库，通过 Postgres 逻辑复制读取 WAL 变更事件，并以 Event DSL 提供回调处理。使用者需在 Postgres 端配置 wal_level=logical、创建 publication 并设置 replica identity。支持临时与持久复制槽（持久槽同一时刻仅允许单进程连接）、运行时动态配置，以及通过 message_middleware 实现背压控制。仅支持 PostgreSQL。

  • 通过 Postgres 逻辑复制监听表的 INSERT/UPDATE/DELETE 等变更事件，以 Event 结构体列表返回变更数据
  • 提供 Event DSL、记录/字段过滤（unwatched_records、unwatched_fields）和异步函数列表执行
  • 支持临时与持久复制槽两种模式，并提供 message_middleware 配置用于自定义事件中间件与背压处理

适用场景（解读层）

  • 在 Elixir 应用内直接订阅 Postgres 表变更并执行回调逻辑，如新用户注册后发送欢迎邮件
  • 将数据库变更事件流式转发到外部服务（分析、CRM、webhook 等）
  • 记录变更时更新索引或使缓存失效
