面向查询密集型应用的列存储开源 SQL 数据库内核

综述（解读层）

MonetDB 是由 CWI 数据库研究组发起、现由 MonetDB Solutions 维护的开源数据库内核，采用 Mozilla Public License 2.0，源码托管于 Mercurial 服务器，GitHub 仓库为每小时更新的镜像且不接受 Pull Request。构建使用 cmake（需 3.12 以上），可选启用 GEOM、FITS、ODBC、128 位整数等功能模块。

  • 使用 cmake 构建，提供多种编译选项，包括 GEOM、FITS、netcdf、SHP、ODBC 驱动及 128 位整数支持
  • 支持通过 WITH_OPENSSL 等选项启用 TLS 安全连接，并集成 bz2、lz4、lzma、zlib 等压缩库
  • 提供 ODBC 驱动编译选项与回归测试体系（Testweb 发布测试结果）

适用场景（解读层）

  • 需要自行从源码编译定制数据库内核功能的场景
  • 查询密集型应用的后端数据存储
  • 需要 FITS、netcdf、Shapefile 等科学/地理数据格式支持的 SQL 环境
