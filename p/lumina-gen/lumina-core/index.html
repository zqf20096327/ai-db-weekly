自托管的 LLM 可观测性平台，提供追踪、成本、延迟与 Agent 分析

综述（解读层）

Lumina 是一个自托管的 LLM 可观测性平台，采集追踪、成本、延迟、Agent 运行、工具调用与 RAG 指标。面向部署 LLM 应用的团队，数据可经 Python SDK、REST API 或 OpenTelemetry OTLP 写入，后端由 Postgres、ClickHouse、Kafka 组成，`make start` 一条命令启动全部组件及 Next.js 控制台。Python SDK 支持自动插桩 OpenAI、Anthropic、LiteLLM 等调用，PyPI 发布尚为独立事项，目前需从仓库安装。

  • 提供三条数据接入路径：Python SDK（含自动插桩）、OTLP/HTTP、REST `/v1/spans` 接口
  • 仪表盘覆盖用量、成本（含缓存节省与预算）、p50/p95/p99 延迟与 TTFT、Agent 轨迹、工具目录及 RAG 检索指标
  • 提供 LLM 分析 REST API（用量/成本/性能/对比/Agent/工具），并支持基于成本、延迟、错误率等指标的规则告警

适用场景（解读层）

  • 自托管环境中追踪 LLM 应用的 token 用量、费用与延迟表现
  • 监控 Agent 运行轨迹与工具调用情况（含超过 20 步的失控检测标记）
  • 无法修改应用代码时，通过 LiteLLM 代理的 OTLP 遥测零代码接入
