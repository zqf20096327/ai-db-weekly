🧭 简介解读层（AI·证据行可回查）

Bottle 框架的 SQLite 数据库插件，通过路由关键字参数注入连接。

综述（解读层）

bottle-sqlite 是 Bottle Web 框架的插件，用于在路由回调中简化 SQLite 数据库的使用。安装后，凡声明 db 关键字参数的路由会自动获得一个打开的 sqlite3.Connection 实例，无该参数的路由不受影响。请求结束时自动提交事务并关闭连接，出错时回滚。配置项包括 dbfile、keyword、autocommit、dictrows、text_factory，以及用户自定义函数、聚合函数、排序规则和扩展加载，且支持按路由覆盖配置，也可用不同 keyword 安装多个插件实例。适用于使用 Bottle 框架并需在路由中访问 SQLite 数据库的应用开发场景。

  • 通过 db 关键字参数自动向路由回调传入 sqlite3.Connection，不影响未声明该参数的路由
  • 请求周期结束自动提交事务并关闭连接，出错时回滚至上次提交以保持数据库状态一致
  • 提供 dbfile、keyword、autocommit、dictrows、text_factory、functions、aggregates、collations、extensions 配置项，支持按路由覆盖及多实例不同关键字并存

适用场景（解读层）

  • 使用 Bottle 框架开发需要在路由中读写 SQLite 数据库的 Web 应用
  • 数据库驱动的应用原型开发，之后迁移至 PostgreSQL 或 MySQL 等更大规模数据库
  • 同一应用需同时连接多个 SQLite 数据库（如业务库与内存缓存库）的场景
