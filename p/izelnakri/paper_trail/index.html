🧭 简介解读层（AI·证据行可回查）

Elixir/Ecto 的数据库变更版本记录库，将变更写入 versions 表

综述（解读层）

PaperTrail 是一个基于 Ecto 的 Elixir 库，通过 PaperTrail.insert/2、update/2、delete/2 函数在数据库事务中记录每次变更到 versions 表，适用于需要保留数据历史的 Phoenix/Ecto 应用。支持 origin 来源标注、originator 操作人关联和 meta 元数据存储，并提供 strict_mode：要求模型持有 first_version_id/current_version_id 外键以防止删除首末版本。安装需配置 repo 并运行 mix papertrail.install 生成迁移。

  • 通过包装 Repo 操作的事务生成 versions 记录，事务失败不产生版本
  • 支持 origin、originator 关联与 meta 元数据字段
  • 提供 strict_mode，通过外键约束关联模型的首个与当前版本

适用场景（解读层）

  • 需要保留记录变更历史的 Ecto 应用
  • 需要标注变更来源与操作人的多入口应用（迁移、worker、用户）
  • 需要防止版本记录被误删的大型应用（strict_mode）
