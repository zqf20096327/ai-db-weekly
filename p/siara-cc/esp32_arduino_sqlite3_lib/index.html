在 ESP32 上通过 Arduino 直接读写 SPIFFS/SD 卡中 SQLite 数据库的库

综述（解读层）

该库将 SQLite 代码打包为 Arduino 库，使 ESP32 可通过 SPIFFS、SD（SPI）或 SD_MMC（4 位模式）访问 SQLite 数据库文件，可直接调用 sqlite3_open 等 C API，使用前需先 begin 对应文件系统。示例数据库需复制到 SD 卡根目录。未实现锁，多线程下除只读外不可靠；大数据库检索较慢，一千万行约需 700ms。依赖仅有 Arduino 和 ESP32 核心 SDK，SQLite 代码已随库包含。

  • 支持从 SPIFFS、SPI 模式 SD 卡和 SDMMC 4 位模式 SD 卡访问 SQLite 数据库文件
  • 可直接调用 sqlite3_open 等 SQLite3 C API，通过挂载点前缀（/sdcard、/sd、/spiffs）打开数据库
  • 内置 shox96 与 unishox 压缩函数，可在 SQL 中对短字符串进行压缩与解压（README 称可减少约 40% 大小）

适用场景（解读层）

  • 在 ESP32 项目中用 SQL 索引查询 SD 卡上百万级记录的数据库
  • 通过 WebServer 示例对 ESP32 上的 SQLite 数据库进行查询展示
  • 需要存储 UTF-8 短文本并减少占用时使用 unishox 压缩函数
