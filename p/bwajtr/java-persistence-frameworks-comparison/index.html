🧭 简介解读层（AI·证据行可回查）

Java 非 JPA SQL 映射框架对比示例集，覆盖 CRUD 与关联查询场景

综述（解读层）

该项目用统一的公司数据库模型和 12 个常见数据访问场景，在 Spring JDBCTemplate、jOOQ、MyBatis、EBean、JDBI 五个框架下各实现一份代码，供开发者在选型时参考用法与最佳实践。不比较性能，聚焦日常任务的可读实现。需 PostgreSQL，运行 create-script.sql 与存储过程脚本后通过 Gradle 执行 JUnit 测试，代码采用 MIT 许可。

  • 针对 12 个常见数据访问场景（按主键查询、批量插入、一对一/一对多关联更新、复杂 JOIN 条件构造、调用存储过程、原生 Statement 执行等）提供每个框架的对照实现
  • 比较对象涵盖 Spring JDBCTemplate、jOOQ、MyBatis、EBean、JDBI 五个非 JPA SQL 映射框架，README 记录了 Speedment 和 sql2o 因不满足入选条件而未纳入的原因
  • 以简单公司数据库模型为基础，代码含说明注释与 FIXME，通过 Gradle 运行 JUnit 测试验证各场景实现

适用场景（解读层）

  • 为 Java 项目选择非 JPA 的 SQL 映射框架时，查看同一场景在不同框架下的写法作为参考
  • 作为各框架常见用法（批量操作、关联更新、存储过程调用等）的代码模板
  • 结合 README 中各框架的注记，了解各框架的配置要点（如 MyBatis 的 Java8 时间类型处理器、EBean 的实体增强环境设置）
