基于 go-zero 与 PostgreSQL 的多 Agent 共享基础设施托管平台

综述（解读层）

PomClaw 是一个用 Go 编写的 AI Agent 平台，采用 M 个计算节点通过 Gateway 服务多个 Agent 的共享架构，替代一 Agent 一虚拟机的部署方式。它面向需要批量运行 Agent 的团队，提供对话、记忆、Agent 市场等功能。核心机制包括：基于 pgvector 与全文索引的双路记忆检索、SSH 沙盒池执行工具调用，以及通过 eino callbacks 自动采集 trace 与 token 成本。开发流程要求先修改 docs/api 与 docs/sql 再用 make generate 生成代码。

  • 通过 Gateway 与共享 PostgreSQL 让多个 Agent 共用数据库和计算资源，Agent 执行在 SSH 沙盒池中运行
  • 记忆模块将文档分块后用 pgvector HNSW 语义检索与全文关键词检索并行混合打分，提供 remember/recall 工具
  • 通过 eino OpenTelemetry 回调记录 trace/span 调用链、token 用量、成本与错误信息

适用场景（解读层）

  • 需要在一组机器上集中托管和监控大量 AI Agent 的企业部署场景
  • 需要持久化 Agent 长期记忆并可查阅检索内容的对话应用
  • 训练好的 Agent 及其技能包需要共享给他人复用的团队协作场景
