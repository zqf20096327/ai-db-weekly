AWS Lambda 函数，响应 S3 事件将 JSON 数据导入 RDS PostgreSQL

综述（解读层）

这是一个 AWS Lambda 函数，在 S3 桶发生 JSON 文件创建事件时被触发，将文件数据写入 RDS 上 PostgreSQL（11+）的 jsonb 表 json_table，并可发布 SNS 通知。部署依赖 AWS CLI、Python 3.6+、CloudFormation 模板和 command.sh 打包脚本，需在 database.cfg 中配置数据库连接信息，且 RDS 实例需关联具有 s3Import 特性的 IAM 角色。适合已使用 AWS 服务、需要事件驱动导入流程的用户。

  • 响应 S3 事件通知（如 Put 事件）自动将 JSON 文件数据插入 PostgreSQL jsonb 表 json_table
  • 每次调用时可向 SNS 主题 message-from-lambda 发布消息，SNS 部分代码可注释移除
  • 通过 CloudFormation 模板部署，打包与部署命令包含在 command.sh 脚本中

适用场景（解读层）

  • S3 桶中 JSON 文件上传、复制或写入后自动入库到 RDS PostgreSQL
  • 构建基于 S3 事件驱动的数据导入流程
  • 需要在导入完成后通过 SNS 接收消息通知的场景
