🧭 简介解读层（AI·证据行可回查）

node-mysql 驱动的工具集，提供数据访问方法、元数据内省与 SQL 自动生成。

综述（解读层）

该项目为 node.js 的 node-mysql 驱动提供附加工具，通过 mix-in 方式挂载到连接对象上使用。功能包括四类：queryRow/queryValue/queryCol/queryHash 等专用查询方法、读取主键/外键/字段/索引等表元数据的内省方法、select/insert/update/upsert/count/delete 等 SQL 语句自动生成方法，以及 query/error/slow 事件。最初为 Impress Application Server 的一部分，后独立发布，通过 npm install mysql-utilities 安装。

  • 提供 queryRow、queryValue、queryCol、queryHash、queryKeyValue 等返回不同结果结构的查询方法
  • 提供主键、外键、约束、字段、索引、表信息、数据库列表等元数据内省方法
  • 提供 select、insert、update、upsert、count、delete 及 where 条件生成的 SQL 自动构建方法

适用场景（解读层）

  • 在 node.js 中配合 node-mysql 驱动进行 MySQL 数据访问层开发
  • 程序化读取数据库表结构、主键、外键、索引等元数据
  • 以 JSON 条件方式生成 CRUD SQL 语句并执行
