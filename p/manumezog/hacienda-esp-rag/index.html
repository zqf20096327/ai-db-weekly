基于 Matryoshka 嵌入切片的西班牙税务裁决法律 RAG 基准系统

综述（解读层）

该项目对 36,053 份西班牙税务总局约束性税务裁决（2016–2026，约 1.05 GB）构建法律 RAG 检索基准。它使用 EmbeddingGemma 生成嵌入，云端 Supabase pgvector 仅存 halfvec 向量与裁决编号，完整正文存于 Jetson Orin Nano 本地 SQLite（只读模式）并在检索后水合，由 Gemini 生成双语法律摘要并附引文。适合研究嵌入降维权衡与边缘+云混合部署的开发者。

  • 支持 768D/512D/256D/128D 多档 Matryoshka 前缀切片（vector[:d] + L2 归一化）实时对比检索，云端库中通过 SQL subvector 动态执行，无需重建索引
  • 采用云边分离架构：Supabase 免费层仅存向量与标识（约 276 MB），完整文本由本地 NVMe SQLite 以只读模式提供，官方称水合耗时低于 2ms
  • 包含三级检索-水合-生成流水线，Top-K=10 检索去重，LLM 合成限基于检索裁决，支持 ES/EN 双语输出与可点击引文徽章

适用场景（解读层）

  • 在不同嵌入维度下对法律文本语义检索质量与向量内存占用进行对比测试
  • 基于西班牙 DGT 官方裁决构建带引文溯源的税务咨询问答应用
  • 参考云向量索引与本地全文存储解耦的边缘+云混合部署方案
