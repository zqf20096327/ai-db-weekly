基于数据库的 Streamlit 用户名/密码登录认证库

综述（解读层）

这是一个面向 Streamlit 应用的用户名/密码认证库（st_auth_simple），作者明确说明它不是身份管理方案。核心机制为服务端会话令牌（浏览器仅存 32 字符令牌），后端通过 Provider 抽象在 SQLite 与 Airtable 间切换，仅改 .env 变量。支持 AES256-CBC 加密密码、requires_auth 装饰器、MIT 许可，可 pip install -e 以库形式集成。

  • 服务端会话令牌与登出立即生效，登录态通过 st.session_state['auth_state'] 隔离
  • 后端支持 SQLite（本地）与 Airtable（云端），通过 .env 的 STORAGE 变量切换，抽象接口可扩展其他数据库
  • 提供 requires_auth 装饰器、authenticated 检查、内置登录/注册表单，可选 SendGrid 邮箱注册加 6 位 PIN 验证

适用场景（解读层）

  • 为多页 Streamlit 应用中的特定页面或函数添加登录保护
  • 需要本地 SQLite 用户表或 Airtable 云端用户表的轻量登录场景
  • 需要邮箱自助注册（PIN 验证）与 30 天 Remember me 会话的应用
