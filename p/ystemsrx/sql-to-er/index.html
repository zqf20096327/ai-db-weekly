纯前端工具，将 SQL CREATE TABLE 或 DBML 代码生成 Chen 模型 ER 图

综述（解读层）

该项目是基于 React、Vite 与 G6 的纯前端网页工具，用于从 SQL CREATE TABLE 语句或 DBML 代码生成 Chen 模型 ER 图，无需登录。支持节点拖拽、双击编辑、缩放旋转、智能布局整理，生成历史快照持久化于浏览器 IndexedDB。也可通过 npx skills add 作为 Agent Skill 安装。生成的图默认使用表名/列名/外键字段名，与标准 Chen 模型存在命名差异；复杂逻辑模型绘制不在其目标范围内。

  • 支持输入 SQL CREATE TABLE 语句与 DBML 代码，生成 Chen 模型 ER 图（矩形实体、菱形关系、椭圆属性、下划线主键）
  • 提供节点拖拽、双击编辑、滚轮缩放、Ctrl+滚轮旋转、智能布局整理等画布交互
  • 生成历史以快照形式存储于浏览器本地 IndexedDB，可恢复、删除，刷新后自动恢复 6 小时内的编辑

适用场景（解读层）

  • 从已有 SQL 建表语句或 DBML 代码快速生成 Chen 模型 ER 图用于教学或文档
  • 需要免费、无需登录的纯前端转换工具且数据不出本地的场景
  • 在 AI Agent 工作流中通过 Skill 调用 SQL/DBML 到 ER 图的转换
