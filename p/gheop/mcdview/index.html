把 SQL DDL 转成单个自包含 HTML 页面的交互式数据模型浏览器

综述（解读层）

mcdview 是一个 Python CLI 工具，读取 PostgreSQL 及约 15 种 SQL 方言的 DDL 文件（也可直接读运行中数据库），生成一个无需服务器、可从 file:// 直接打开的单文件 HTML 交互式 ER 图页面。支持表隔离、字段详情、搜索、diff 对比、Mermaid 导出和 CI lint 门禁；默认零依赖，非 PostgreSQL 方言需安装 sqlglot。

  • 读取 PostgreSQL 内置解析及经 sqlglot 的 MySQL、SQLite、Oracle 等 15 种方言，另支持 pgModeler .dbm、dbdiagram.io .dbml、Prisma、MySQL Workbench .mwb、Rails schema.rb、Mermaid erDiagram、Drizzle schema.ts 等模型文件
  • 提供 --diff 版本对比（增删改着色、重命名检测、JSON 摘要）、--to-mermaid/--to-dico/--to-preview 导出、--lint 规则检查及 --fail-on 非零退出码
  • 生成单文件 HTML，含缩放拖拽、表隔离、字段级详情、搜索、小地图、#schema.table 永久链接、SVG 导出，可离线打开

适用场景（解读层）

  • 浏览和分享数据库表结构文档，无需部署服务器或构建流程
  • 迁移评审前对比两个版本的模型差异（--diff/--summary）
  • CI 流水线中做 schema 门禁检查或生成 Mermaid 图、数据字典、SVG 卡片等制品
