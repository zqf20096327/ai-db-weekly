Redis Module，为 Redis 服务器增加直接读写 TiKV 集群的 tikv.* 命令

综述（解读层）

RedisTiKV 是一个以 Rust 编写、通过 cargo 构建的 Redis Module（README 标注支持 Redis 4.0 引入的模块机制），加载后为 Redis 提供 tikv.* 系列命令，直接操作 TiKV 集群的 RawKV 数据，并支持通过 PD HTTP API 连接 PD、连接 TiDB 执行 SQL。它提供 String、Hash、List 类型命令及缓存式 cget/cset/cdel 命令，键经 x$R_ 前缀编码以区分实例与数据类型。适合需要在 Redis 进程内访问 TiKV 数据的场景；README 说明 Lua 脚本中执行时切换为同步模式，且键编码格式尚为草案，可能变更。

  • 提供 tikv.set/get/del/scan/mget/mset/exists/setnx 等 RawKV 操作命令，以及 Hash、List 系列命令和 tikv.ttl/expire TTL 命令
  • 提供 cget/cset/cdel 命令，先读写 Redis 内存缓存再读写 TiKV，并可经 replacesys 参数替换 GET/SET 等 8 个系统命令
  • 支持 execmode（async/sync）、pdaddrs、instanceid、enablepromhttp（在 127.0.0.1:9898 暴露 Prometheus 指标）等模块参数，键编码含 8 字节 INSTANCE_ID 支持多实例

适用场景（解读层）

  • 在 Redis 服务器中通过模块命令直接读写 TiKV 集群的键值数据
  • 通过 PD 地址连接集群，并按需连接 PD HTTP API 或 TiDB 执行 SQL 操作
  • 以缓存模式或替换系统命令的方式，将 Redis GET/SET 类操作导向 TiKV 存储
