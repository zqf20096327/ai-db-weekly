面向 Delphi 的轻量级、基于特性的 ORM 框架

综述（解读层）

Trysil 是一个面向 Delphi 10.3 至 13 的对象关系映射框架，通过 [TTable]、[TColumn] 等特性将数据库表映射为 Object Pascal 类。查询、插入、更新、删除操作经由 TTContext API 完成，底层统一使用 FireDAC 驱动，支持 Firebird、InterBase、MariaDB、Oracle、PostgreSQL、SQL Server、SQLite 七种数据库。部分驱动的远程连接依赖 RAD Studio Enterprise/Architect 版本。项目采用 BSD-3-Clause 许可证。

  • 基于特性（attribute）声明实体映射，配合 TTFilterBuilder 提供类型安全的流式查询构建
  • 提供延迟加载（TTLazy）、乐观锁（[TVersionColumn]）、变更跟踪、软删除、Unit of Work 事务提交与 JSON 序列化
  • 附带 REST HTTP 模块（属性路由、CORS、JWT 与多租户）、OpenAPI 3.1 文档生成、IDE Expert 实体设计器与 DDL 生成器

适用场景（解读层）

  • 需要以纯 Object Pascal 代码操作关系数据库的 Delphi 应用开发
  • 基于 FireDAC 构建 REST 服务并需要 OpenAPI 文档的场景
  • 使用 SQLite、Firebird、InterBase 等 Community 版本可驱动数据库的本地开发与测试
