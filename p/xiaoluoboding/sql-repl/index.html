网页版 SQL REPL，带语法高亮编辑器与表格结果视图

综述（解读层）

SQL REPL 是一个运行于浏览器的 SQL 交互工具，包含前端客户端与 Koa 后端。编辑器基于 CodeMirror 提供语法高亮，结果以可排序表格展示，并支持暗色模式与多语言。目前支持连接 SQLite 数据库，MySQL 支持处于开发中。安装使用 pnpm，pnpm start 后运行在 3000 端口，采用 MIT 许可证。

  • SQL 编辑器提供语法高亮，采用分栏布局且面板大小可调
  • 查询结果以表格视图展示并支持排序
  • 支持暗色模式、多语言（i18n），当前支持 SQLite 连接，MySQL 处于开发中

适用场景（解读层）

  • 在浏览器中编写并执行 SQL 查询语句
  • 查看本地 SQLite 数据库中的数据
  • 调整分栏布局查看查询结果与编辑器
