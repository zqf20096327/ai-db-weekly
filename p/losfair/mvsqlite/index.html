🧭 简介解读层（AI·证据行可回查）

基于 FoundationDB 的分布式 MVCC SQLite 实现，通过自定义 VFS 层接入。

综述（解读层）

mvSQLite 是运行在 FoundationDB 之上的 SQLite 存储层，以自定义 VFS 方式实现，保留 SQLite 全部功能。支持时间旅行（读取历史快照）、乐观细粒度无锁并发读写、同步/异步复制与备份恢复，且取消了 FDB 原生五秒事务限制。适合需要分布式 SQLite 且已具备 FoundationDB 部署的用户，需运行服务端 mvstore 并通过 LD_PRELOAD 或替换 libsqlite3.so 接入现有应用。

  • 以自定义 VFS 层集成 SQLite，SQLite 全部功能可用，可查看数据库任意历史时点的快照
  • 数据面操作不获取分布式锁，采用 BEGIN CONCURRENT 类语义的乐观细粒度并发，事务可远大于 FDB 原生事务限制
  • 提供实验性 commit groups 功能，可将多个数据库的写入批量打包为单个 FoundationDB 原子提交

适用场景（解读层）

  • 需要将现有基于 SQLite 的应用以较小改动接入 FoundationDB 分布式事务的场景
  • 需要查询数据库历史时点快照的工作流
  • 需要跨多个 SQLite 数据库原子提交（如一库扣款、一库入账）的场景，但注意其不提供跨库一致性快照读
