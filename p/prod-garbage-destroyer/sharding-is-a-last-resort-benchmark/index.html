🧭 简介解读层（AI·证据行可回查）

手动 PostgreSQL 分片与 CockroachDB、TiDB 的本地基准测试套件与结果包

综述（解读层）

该仓库包含一个基准测试套件，用于对比手动 PostgreSQL 分片路由、CockroachDB 与 TiDB 在同一逻辑 schema、相同种子和相同请求配比下的混合账本负载表现。包含 Go 编写的 runner（负责数据播种、负载执行与产物输出）、基准契约 spec.yaml、公平性政策与有效性分析文档，以及结果产物与图表数据集。适合需要查看或复跑该基准的数据库开发者与研究者使用。

  • 提供 Go 实现的基准 harness，负责数据播种、负载执行与产物输出
  • 包含 spec.yaml 基准契约、公平性政策与基准有效性分析文档
  • 提供结果产物（verdict.json、summary.md）及可用于绘图的数据集

适用场景（解读层）

  • 在本地复跑手动 PostgreSQL 分片与分布式 SQL（CockroachDB、TiDB）的对比基准
  • 查阅基准设计的公平性边界与有效性评估
  • 获取结果产物与数据集用于图表分析
