面向 Cloud Firestore 的客户端 SQLite 数据库，含 schema 生成器与 Admin UI

综述（解读层）

该项目为 Cloud Firestore 提供 schema 定义、Admin UI 管理界面与客户端 SQLite 支持。schema 以 JSON 描述集合字段，用于生成 UI、验证数据、生成类与接口；客户端通过 SQLite FTS5/jsonb 扩展实现全文检索与图查询。适用于使用 Firebase 且需要客户端结构化数据层的开发者；项目部分功能标注为开发中。

  • 基于 JSON schema 生成 Admin UI、辅助类、GraphQL/REST 接口，并在客户端保存前做数据验证
  • 客户端通过 SQLite FTS5 扩展实现全文检索，通过 jsonb 扩展与虚拟表实现图数据库能力
  • 支持 schema 变更迁移（previous 字段映射）、软删除（tombstone）、TTL 清理与多设备同步（Firebase Storage/iCloud）

适用场景（解读层）

  • 使用 Firestore 且需要客户端本地 SQLite 缓存与查询的应用
  • 需要为 Firestore 集合定义字段类型、验证规则并生成管理界面的团队
  • 需要离线全文搜索、按 previous 字段平滑重命名字段的数据迁移流程
