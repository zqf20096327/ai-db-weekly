基于 CentOS+Supervisor 的带 BDR 双向复制支持的 PostgreSQL Docker 镜像

综述（解读层）

该 Docker 镜像封装了支持 BDR 双向复制的 PostgreSQL 服务器，运行于 CentOS 并由 Supervisor 管理进程。通过环境变量 MODE 可指定 single/master/slave 三种运行模式，即使 BDR 是多主方案，部署时仍需先指定一个节点作为 master 来建立 BDR 设置。适合需要在容器中部署 PostgreSQL 双向复制的用户。

  • 提供 single、master、slave 三种运行模式（默认 single）
  • 通过 POSTGRES_PASSWORD、POSTGRES_USER、POSTGRES_DB、POSTGRES_PORT、MASTER_ADDRESS 等环境变量配置
  • 提供 docker-compose.yml 示例，可一次性部署一个 master 加两个 slave

适用场景（解读层）

  • 以 standalone 方式运行带 BDR 支持的 PostgreSQL 容器
  • 通过 docker compose 部署 master 与多个 slave 节点组成双向复制集群
  • 单独启动 master 或某个 slave 节点
