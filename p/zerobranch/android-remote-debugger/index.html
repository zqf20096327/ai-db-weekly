🧭 简介解读层（AI·证据行可回查）

Android 远程调试库，可在浏览器中查看日志、数据库、SharedPreferences 和网络请求

综述（解读层）

该库在 Android 应用内启动本地服务，开发者通过浏览器访问设备 IP:8080 查看日志、数据库、SharedPreferences 和网络请求。日志需通过其静态方法输出，网络查看依赖 OkHttp3 拦截器。发布版本使用 no-op 依赖，生产构建不启动服务。设备和电脑需在同一局域网，或用 adb 端口转发。

  • 提供日志过滤（按优先级和标签）、搜索、下载及崩溃日志记录
  • 支持查看、编辑、删除数据库条目并执行自定义 SQL 查询
  • 通过 OkHttp3 拦截器 NetLoggingInterceptor 记录网络请求与响应

适用场景（解读层）

  • Android 应用开发期在浏览器中调试应用日志与数据
  • 排查 OkHttp3 网络请求的请求/响应内容
  • 在真机或模拟器上查看和修改数据库与 SharedPreferences 数据
📖 README 首段存档原文 · 程序抽取

Android Remote Debugger is a library for remote debugging Android applications. It allows you to view logs, databases, shared preferences and network requests directly in the browser.
