pgBouncer 与 HAProxy 结合的 PostgreSQL 连接池与负载均衡配置教程

综述（解读层）

该仓库提供在分布式 PostgreSQL 环境中部署 pgBouncer 连接池与 HAProxy 负载均衡的步骤指南，内容包含 pgbouncer.ini 配置、md5 认证设置、haproxy.cfg 的 TCP 监听与 roundrobin 均衡规则、故障切换测试方法以及 HAProxy 统计页面的配置方式。面向需要在主从架构中分发请求的开发或运维人员，示例使用单一配置文件且未包含自动化部署脚本。

  • 包含 pgBouncer 安装、pgbouncer.ini 数据库映射与 md5 密码认证配置步骤
  • 包含 HAProxy 的 TCP 监听、pgsql-check 健康检查与 roundrobin 负载均衡配置示例
  • 提供浏览器访问的 HAProxy 统计页面配置及服务器故障切换验证步骤

适用场景（解读层）

  • 为 PostgreSQL 主从/多副本架构配置请求分发与故障切换
  • 为数据库连接配置连接池以复用连接
  • 通过 HAProxy 统计页面查看后端服务器状态
