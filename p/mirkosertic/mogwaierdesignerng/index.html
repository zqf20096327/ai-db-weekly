基于 Java 的开源 ER 实体关系建模工具，支持 2D/3D 设计与 SQL DDL 生成

综述（解读层）

Mogwai ERDesigner NG 是一个用 Java 编写的实体关系建模与设计工具，可在 Windows、Unix、Mac 上运行。它提供所见即所得编辑器、2D/3D 建模，面向 MySQL、Oracle、SQL Server、PostgreSQL、H2 等数据库，支持正向与逆向工程、Schema 版本控制和迁移脚本生成。采用 GPL 许可发布，可经 GitHub 或 Microsoft Store 获取。

  • 支持 2D 和 3D 数据库建模、浏览与设计，可生成 3D 红蓝立体视图
  • 支持 MySQL、Oracle、SQL Server、PostgreSQL、H2、HypersonicSQL 六种数据库，并可跨方言转换 Schema
  • 内置 Schema 版本控制、Schema 比较、迁移脚本生成，以及 PDF/HTML/RTF 等格式的文档生成

适用场景（解读层）

  • 对新数据库进行物理建模设计并生成 SQL DDL 语句
  • 对已有数据库执行逆向工程，导出 Schema 图（GIF/BMP/JPEG/SVG）
  • 跟踪 Schema 变更并生成迁移脚本，或生成 OpenXava 应用
