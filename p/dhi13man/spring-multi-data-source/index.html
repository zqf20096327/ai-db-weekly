基于注解处理器的 Spring 多数据源配置代码生成库

综述（解读层）

该库提供两个编译期注解，用于在构建过程中生成 Spring 单服务多数据源所需的 Bean 配置类与按包隔离的仓库副本，替代手工编写 @EnableJpaRepositories、@EntityScan 及各数据源的 Bean 声明。适用于使用 Spring Boot 并需接入多个数据源的 Java 服务。注解仅保留在源码级，不保留到运行时。生成的代码位于 target/generated-sources/annotations，可直接复制到主代码中脱离本库运行。

  • 提供 @EnableMultiDataSourceConfig 与 @TargetSecondaryDataSource 两个注解，在构建期生成数据源 Bean、事务管理器、实体管理器工厂等配置类及仓库副本
  • 生成代码输出到 target/generated-sources/annotations 目录，命名遵循 DataSourceConfig 与 格式
  • 生成代码为可读 Java 源文件，可按 README 步骤复制到主代码并移除本库依赖

适用场景（解读层）

  • Spring Boot 单服务需要配置多个数据源（如主库与读副本）的场景
  • 希望减少多数据源所需的样板配置类与仓库分包维护工作的项目
  • 需要为次数据源生成按名称隔离的仓库副本并按前缀组织属性配置（如 spring.datasource.read-replica）的服务
