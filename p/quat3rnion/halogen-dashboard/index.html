Rust + SQLite 实现的 Halogen LLM 推理服务器实时监控仪表盘

综述（解读层）

该项目为 Halogen LLM 推理服务器提供实时仪表盘。单进程 Rust Collector 每秒读取 Halogen 的 /metrics，历史数据存入 SQLite，并将实时数据推送到 Svelte 网页；展示状态、吞吐、KV 池、缓存命中等指标，支持 Live 到 30 天的时间范围。限制：因 Halogen 每次被读取会重置吞吐计数器，Collector 必须是唯一读取者，不可再为 Halogen 添加 Prometheus 抓取任务。提供 Docker Compose 部署和内置模拟器。

  • 单进程 Rust Collector 每秒读取 Halogen /metrics，历史存入 SQLite，实时推送至网页
  • 展示状态/吞吐/KV 池/缓存命中率等指标，时间范围覆盖 Live 至 30 天，Outages 显示为间隙、Restarts 显示为标记
  • 提供 fake-halogen 模拟器与 Docker Compose 部署，支持深浅主题

适用场景（解读层）

  • 监控 Halogen LLM 推理服务器的运行状态与性能指标
  • 查看历史时间段（最长 30 天）的推理吞吐、KV 池与缓存表现
  • 无需真实服务器时用内置模拟器演示或开发仪表盘
📖 README 首段存档原文 · 程序抽取

A live dashboard for the Halogen LLM inference server. One Rust process (the Collector) reads Halogen each second, keeps the history in SQLite and sends live data to the web page.
