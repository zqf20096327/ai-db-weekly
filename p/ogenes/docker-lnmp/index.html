🧭 简介解读层（AI·证据行可回查）

基于 Docker Compose 编排的 LNMP 本地开发环境，可切换多版本服务。

综述（解读层）

该项目通过 Docker Compose 编排 Nginx、PHP、MySQL、Redis 等服务镜像，用于快速构建本地 LNMP 开发环境。PHP 支持 5.6 至 8.4 十个版本，MySQL 支持 5.7/8.0，Redis 支持 4.0/5.0/6.0，可通过修改 .env 文件切换版本，支持配置与日志文件映射。适合个人开发者本机部署或团队统一开发环境。安装需自建 Docker 网络，默认项目目录为上级 www 目录。

  • PHP 支持 5.6 至 8.4 共十个版本，可切换并多版本同时运行
  • 支持配置文件与日志文件映射，通过 .env 文件选择 MySQL、Redis 版本
  • 内置 Certbot 流程用于申请 Let's Encrypt SSL 证书并配置自动续期

适用场景（解读层）

  • 个人开发者本机快速部署 LNMP 开发环境
  • 团队设定统一配置后一键部署开发环境
  • 需要切换或学习不同 PHP、MySQL、Redis 版本时使用
