基于 Postgres 逻辑复制的 .NET 变更数据捕获引擎，由 EF Core 模型等驱动

综述（解读层）

Wallaby 是一个面向 .NET 的 Postgres CDC 引擎，读取逻辑复制的行变更，物化为 EF Core 实体、Marten 文档或注解 POCO，经转换后路由到搜索引擎、Kafka、pgvector 等 sink，至少一次投递。它自配置发布与复制槽，支持版本化回填与集群 leader 选举，要求 Postgres 15+ 和 .NET 10+。

  • 从 Postgres 逻辑复制流读取行变更，物化为 EF Core 实体、Marten 文档或注解 POCO，支持转换与富化
  • 自模型自动配置发布与复制槽，支持版本化回填（初始快照与结构变更重建索引），通过 leader 选举实现集群安全
  • 提供多种 sink 包（HTTP、Elasticsearch、Kafka、Meilisearch、OpenSearch、pgvector），Kafka 消息按键分区并支持墓碑删除，pgvector 可选 sink 侧嵌入

适用场景（解读层）

  • 在不使用双写、outbox 表、Debezium 或 Kafka Connect 的前提下，将 Postgres 数据变更同步到搜索索引或消息队列
  • 将表变更路由到 pgvector 以维护向量数据，可配合 sink 侧生成嵌入
  • 使用 Wallaby.Testing 与 Wallaby.TraceDemo 以真实逻辑复制运行端到端管道测试并导出链路与指标
