基于 pebble LSM 存储引擎实现 CRDT 的可同步数据存储

综述（解读层）

Chotki 是一个支持多主同步的数据存储，内部用 pebble db 通过 RDX 合并算子原生运行 CRDT。数据模型包含类、对象和字段，字段为可复制数据类型，含计数器、集合等。提供 REPL、HTTP REST 接口，支持副本实时或离线差分同步。目前不支持 SQL 和过滤查询，仅支持按 ID 或引用获取对象。

  • 提供增量计数器（N/Z 类型）等可复制数据类型，CRDT 逻辑以合并算子实现于 pebble db 之上
  • 副本可主主同步，支持实时增量同步与离线后差分同步，网络拓扑为生成树结构
  • 提供 REPL 与 HTTP REST 接口，接受和返回 RDX 或 JSON 格式数据

适用场景（解读层）

  • 需要多副本离线工作后重新同步的场景
  • 分布式计数器、配额、计费等实时统计数据的存储与更新
  • 通过对象引用构成对象图并按 ID 点查或按引用递归读取的应用
