🧭 简介解读层（AI·证据行可回查）

为 Polars 惰性执行提供自定义 I/O 数据源与谓词下推扩展的 Python 库。

综述（解读层）

polars-io-tools 通过 scan_* / sink_* 函数和 piot 命名空间扩展 Polars LazyFrame，将过滤与列投影下推到 SQL 数据库、ClickHouse、Datadog、Delta Lake 等外部存储，只取所需行列；另提供保留下推的连接、时间序列窗口、缓存及基于 Ray 的分区执行。适合数据存于远端、大且分区化的场景；数据已在内存或本地 Parquet/CSV 时 README 建议直接用原生 Polars。

  • 提供 scan_db、scan_clickhouse、scan_datadog、scan_delta 等惰性读取源，将过滤翻译为源端查询语言以减少取回数据
  • 提供 sink_delta、sink_clickhouse 惰性写入，支持流式/分块写入与类型转换处理
  • 包含 filtered_join、ts_with_columns 等保留谓词下推的查询构建操作，以及内存/Parquet 缓存和 execute_on_ray 分布式执行

适用场景（解读层）

  • 对远端大型分区数据集用 Polars 惰性 API 查询，避免取回将被丢弃的行列
  • 将 LazyFrame 直接写入 Delta Lake 或 ClickHouse
  • 在已有 Ray 集群上按时间窗口、键值或数值区间分区并行执行查询
