SQL Server Compact Edition 数据库查询分析工具，支持多版本 SDF 文件操作

综述（解读层）

SQL Compact Query Analyzer 是一个用于查询和操作 SQL Server Compact Edition（SQLCE）数据库的工具。使用者可对 SQLCE 3.0、3.1、3.5 和 4.0 版本的 SDF 数据库文件执行 SQL 查询、编辑数据、查看模式信息，以及收缩和压缩数据库。运行需 .NET Framework 4.0，支持密码保护的数据库，并可将 SDF 文件关联到工具以便在 Windows 资源管理器中直接打开。

  • 支持 SQLCE 3.0、3.1、3.5 和 4.0 版本
  • 可执行单条或多条 SQL 查询（分号分隔），结果可显示为 XML
  • 提供数据库信息、模式摘要、列与索引信息展示，并支持生成模式和数据脚本

适用场景（解读层）

  • 查询和编辑 SDF 格式的 SQLCE 数据库内容
  • 查看数据库结构与模式信息（表、列、主键、索引等）
  • 收缩、压缩数据库或生成模式与数据脚本
