🧭 简介解读层（AI·证据行可回查）

基于 Docker Compose 快速搭建 ClickHouse 集群环境的编排脚本。

综述（解读层）

该项目提供 Docker Compose 脚本，基于官方 clickhouse/clickhouse-server 镜像一键启动 ClickHouse 集群，默认含 1 个 ZooKeeper 节点与 3 个 server 节点（3 分片、每节点 1 副本），支持多套集群拓扑配置文件，可通过修改 metrika XML 配置调整节点，并借助 CLICKHOUSE_VERSION 环境变量指定镜像版本。适合需要在本地或测试环境部署 ClickHouse 集群的开发者使用。

  • 基于官方 clickhouse/clickhouse-server 镜像，支持通过 CLICKHOUSE_VERSION 环境变量自定义版本
  • 默认部署 1 个 ZooKeeper 节点（3.6）加 3 个 ClickHouse server 节点（20.11），构成 3 分片、每节点 1 副本的集群
  • 提供多种集群拓扑的 compose 配置，并可通过 ch-conf/metrika_ch01~03.xml 修改分片配置

适用场景（解读层）

  • 本地快速搭建用于开发或测试的 ClickHouse 分片集群环境
  • 通过宿主机映射端口（8124-8126）或 Docker 子网 IP，用 DBeaver 或 clickhouse-client 连接集群进行调试
  • 按需切换不同集群拓扑（如单 ZooKeeper 3 分片 1 副本）或指定 ClickHouse 镜像版本做兼容验证
