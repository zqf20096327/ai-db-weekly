Supabase RLS 安全测试 CLI，自动检测策略漏洞

综述（解读层）

SupaShield 是一个 npm 安装的命令行工具，面向使用 Supabase 的开发者，用于在部署前测试 RLS 策略。它通过读取数据库连接串自动发现 schema，运行 lint、coverage、audit、test 等子命令，覆盖表和存储桶的 CRUD 场景；测试在事务中执行并回滚。README 建议在 staging 或本地环境先测试。

  • 支持 audit、lint、coverage、test 等子命令，进行 RLS 策略静态分析与真实用户上下文的功能测试
  • 自动发现 schema，测试各角色对表和存储桶的 CRUD 操作，策略变更可通过快照与 diff 检测
  • 通过 --json 输出结构化结果，操作在事务中运行并回滚，不持久化数据

适用场景（解读层）

  • 在 CI/CD 流水线中运行 RLS 策略测试
  • 使用 AI 编码工具时以 JSON 输出生成结果供其读取分析
  • 生成 RLS 覆盖率报告查看各角色可访问的内容
