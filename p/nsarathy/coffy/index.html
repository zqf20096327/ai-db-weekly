纯 Python 嵌入式数据库引擎，支持 NoSQL、SQL 与 Graph 三种模型

综述（解读层）

Coffy 是一个纯 Python 编写的本地嵌入式数据库引擎，包含 coffy.nosql（文档存储）、coffy.sql（SQLite 薄封装）与 coffy.graph（基于 NetworkX 的图库）三个引擎。面向原型开发、脚本编写与本地应用，无需服务器，通过 pip install coffy 安装，数据以 JSON 或 SQLite 持久化，也可用内存模式运行。

  • 支持 NoSQL、SQL、Graph 三种数据模型，全部以纯 Python 实现
  • 提供本地持久化（JSON、SQLite）与内存模式（:memory: 或 None），无需服务器
  • 包含统一查询接口、链式逻辑查询、match_node_path 声明式图遍历语法及命令行界面

适用场景（解读层）

  • 原型开发与快速验证场景中的本地数据存储
  • 脚本与本地应用中无需部署数据库服务的场景
  • 需要节点与关系遍历的图数据本地处理

Coffy is a lightweight, local-first embedded database engine supporting NoSQL, SQL, and Graph models — all in pure Python. Designed for fast prototyping, scripting, and local apps.
