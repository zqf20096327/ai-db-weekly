🧭 简介解读层（AI·证据行可回查）

基于 SQLite 文件的 AI 代理长期记忆，五层级结构与 FTS5 检索，不用向量库。

综述（解读层）

Sibyl-Memory 是 Sibyl Labs 发布的一组 Python 包（SDK、CLI、MCP server、Hermes 适配器、LangGraph BaseStore），为 AI 代理提供基于本地 SQLite 文件的长期记忆，采用 HOT 到 ARCHIVE 五层级结构，用 FTS5 做全文检索，不依赖向量数据库或嵌入模型。使用需经 sibyl init 激活账户并定期在线续签权限，支持 Linux、macOS 和 WSL2 下的 Windows。

  • 五个 PyPI 包共享同一 SQLite + FTS5 引擎，实体唯一性由 UNIQUE 约束在 schema 层强制
  • 提供 MCP server 接入 Claude Code、Codex、Cursor 等 MCP 客户端，并附带 LangGraph BaseStore 适配器
  • 记忆数据保存在本机单个文件中，sibyl memory 命令无需账户即可读取

适用场景（解读层）

  • 为 MCP 兼容代理（Claude Code、Cursor 等）添加跨会话长期记忆
  • 作为 LangGraph 应用的 BaseStore 实现跨线程持久存储
  • 在无向量数据库、无嵌入成本的单机环境下运行代理记忆基础设施
