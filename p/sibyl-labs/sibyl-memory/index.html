🧭 简介解读层（AI·证据行可回查）

基于 SQLite 文件的 AI 代理长期记忆插件家族，不用向量库与嵌入模型

综述（解读层）

Sibyl-Memory 提供五个 PyPI 包（SDK、CLI、MCP 服务器、Hermes 适配器、LangGraph BaseStore），基于本地 SQLite 单文件实现五层分层记忆结构与 FTS5 全文检索，支持多租户。适用于使用 Claude Code、Cursor、Hermes 等代理的开发者。使用需激活账户，授权文件每日在线续期、离线最长可用 14 天；原生 Windows 不支持，仅限 WSL2。

  • 本地优先架构：记忆存储为磁盘上的单个 SQLite 文件，使用 FTS5 全文检索，不依赖向量数据库、嵌入模型或外部检索服务
  • 五层分层 schema（HOT/WARM/COLD/REFERENCE/ARCHIVE），实体唯一性由 UNIQUE(tenant_id, category, name) 约束在 schema 层强制执行
  • 通过 MCP 服务器接入 Claude Code、Codex、Cursor、Continue 等 MCP 客户端，并提供 LangGraph BaseStore 适配器；代码按 MIT 许可发布，运行于 Linux、macOS 及 WSL2

适用场景（解读层）

  • 为 MCP 兼容代理（Claude Code、Cursor 等）添加跨会话持久记忆，保存决策日志、实体与待办状态
  • 作为 LangGraph 的 BaseStore 实现跨线程长期存储
  • 测量并精简代理每次会话加载的上下文文件（CLAUDE.md、AGENTS.md 等），将历史迁移至独立文件或记忆库
