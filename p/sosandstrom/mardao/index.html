基于注解领域类生成 DAO 代码的 Java Maven 插件

综述（解读层）

Mardao 是一个以 Maven 插件形式打包的 ORM 和 DAO 生成器，读取带注解的领域类，生成对应的 DAO 类。支持 Spring JDBC、AppEngine Datastore（低层 API）和 Android SQLite 三种持久化类型，通过 persistenceType 配置切换。最新稳定版为 3.0.13（2015 年），采用 GPL 许可证，项目已多年未更新，适合维护旧 Java 技术栈的开发者。

  • 以带注解的领域类为输入，通过 Maven 插件生成 DAO 类
  • 支持 Spring JDBC、AppEngine Datastore 低层 API 和 Android SQLite 三种持久化后端
  • 提供 Dao 层事务支持、parent key 查询以及 findBy/Expression 查询方法

适用场景（解读层）

  • 需要为基于注解的领域模型批量生成 Spring JDBC 数据访问层的 Java 项目
  • 使用 AppEngine 低层 API 并需要 parent key 支持的应用
  • Android 应用中基于 SQLiteDatabase 生成数据访问代码
