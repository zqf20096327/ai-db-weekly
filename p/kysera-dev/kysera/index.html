🧭 简介解读层（AI·证据行可回查）

基于 Kysely 的 TypeScript 类型安全数据访问层，非 ORM 设计

综述（解读层）

Kysera 是构建在 Kysely 查询构建器之上的数据层，由 13 个 npm 包和一个 CLI 组成，提供仓库模式与函数式 DAL 两种访问方式，通过统一 executor 拦截层挂载软删除、RLS、审计等插件。支持 PostgreSQL、MySQL、SQLite、MSSQL 四种数据库，运行于 Node.js ≥22，Bun 与 Deno 经冒烟测试验证。ESM-only，kysely 为 peer dependency。

  • 提供统一 executor 拦截层，软删除、RLS、审计等插件按固定优先级顺序作用于仓库、DAL 及事务内的所有查询路径
  • RLS 策略（allow/deny/filter/validate）编译进 SELECT/UPDATE/DELETE 语句，并可生成 PostgreSQL 原生 CREATE POLICY DDL
  • 内置咨询锁加 sha256 校验的迁移运行器、健康检查、重试、熔断器与事务重试等运维原语，零第三方运行时依赖

适用场景（解读层）

  • 多租户场景下需要在 SQL 层强制行级隔离的服务端应用
  • 需要审计日志与数据写入原子一致的金融类写入场景
  • 多个服务共享同一迁移历史的基础设施团队
