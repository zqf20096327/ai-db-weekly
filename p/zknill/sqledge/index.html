🧭 简介解读层（AI·证据行可回查）

用 Postgres 逻辑复制将数据流式同步到边缘 SQLite 的工具

综述（解读层）

SQLedge 通过 Postgres 逻辑复制流将源库变更写入本地 SQLite，读请求由 SQLite 提供，写请求转发到上游 Postgres。它内置 SQL 生成器、自动建表和一个默认监听 localhost:5433 的 Postgres wire 代理；启动时按记录的 LSN 续传，无 LSN 则基于复制槽快照执行全量 COPY。读查询需直接兼容 SQLite 语法，Postgres 特有函数不做转换，上游用户需具备 superuser 权限。

  • 使用 Postgres 逻辑复制流式同步变更到本地 SQLite，读操作由本地库提供，写操作转发至上游
  • 内置 Postgres wire 代理（默认 localhost:5433），并包含根据复制消息生成 SQLite insert/update/delete 语句的 SQL 生成器
  • 通过 postgres_pos 表记录 LSN 以实现断点续传，首次启动时基于复制槽导出的事务快照执行全表 COPY，并自动创建新表

适用场景（解读层）

  • 应用部署在边缘节点，需要本地读取数据并向 Postgres 写入的场景
  • 读查询以简单 SELECT 为主且与 SQLite 语法兼容的场景
  • 需要本地存在一份与上游最终一致的 SQLite 数据副本用于读取或查看的场景
