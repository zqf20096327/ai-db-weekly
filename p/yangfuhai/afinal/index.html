Android 平台的 SQLite ORM 与 IOC 框架，含四大功能模块

综述（解读层）

Afinal 是一个 Android 的 SQLite ORM 和 IOC 框架，同时封装了 HTTP 请求功能，包含 FinalDB、FinalActivity、FinalHttp、FinalBitmap 四个模块，分别用于数据库增删改查、注解方式绑定 UI 和事件、HTTP 数据请求与文件下载、Bitmap 图片加载与缓存。面向 Android 应用开发者，使用需声明 INTERNET 和 WRITE_EXTERNAL_STORAGE 权限。

  • FinalDB 支持一行代码进行 SQLite 增删改查，支持一对多、多对一查询及懒加载
  • FinalActivity 通过注解方式实现 UI 绑定和事件绑定，无需 findViewById 和 setClickListener
  • FinalBitmap 使用 LRU 算法管理内存，可配置线程数量、缓存大小、缓存路径，支持自定义下载器和显示器；FinalHttp 支持文件上传下载与断点续传

适用场景（解读层）

  • Android 应用中对 SQLite 数据库进行对象化读写操作
  • 通过注解方式绑定 Activity、Fragment 中的 UI 控件与事件
  • 异步加载网络图片及 HTTP 数据请求、文件上传下载
