🧭 简介解读层（AI·证据行可回查）

自托管开源 SIEM，基于 ClickHouse 存储检索日志并提供溯源图与告警分析。

综述（解读层）

Bifract 是部署在自有基础设施上的开源 SIEM，日志存于 ClickHouse 并以 Parquet 归档到对象存储。提供管道式查询语言 BQL、进程溯源图、行为基线模型、基于游标的 Sigma 规则告警及协作调查功能。单机需 Linux 与 Docker Compose，4 核 8GB 约可处理每日 10GB 日志；由单一开发者维护，Iceberg 归档为最新且可能变动的部分。

  • 提供管道式查询语言 BQL，支持过滤、分组、排序及 pgr() 溯源图等源命令
  • 在摄取时维护 rarity、first/last seen、volume 基线及 beacon 评分模型，可通过 model_lookup() 关联回搜索
  • 基于游标的告警评估，支持从 Git 同步并转换 Sigma 规则；日志以 Parquet + Iceberg 元数据归档并可原地检索

适用场景（解读层）

  • 在自有基础设施上集中存储与检索主机日志（支持 Sysmon 或规范化到相同字段的 EDR 遥测）
  • 基于进程溯源图与行为基线进行检测工程与威胁狩猎
  • 团队协作开展事件调查：日志评论、调查笔记本与共享仪表板
