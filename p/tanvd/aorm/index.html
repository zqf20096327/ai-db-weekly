面向 ClickHouse 的 Kotlin 分析型 SQL 框架，Exposed 的方言分支

综述（解读层）

AORM 是基于 Exposed SQL 框架分支而来的分析型 SQL 框架，面向使用 ClickHouse 数据库的 Kotlin 开发者。它提供 Exposed 风格的 DSL 用于标准 SQL 操作，并支持 ClickHouse 特有功能，如状态聚合函数、多种引擎及副本执行上下文。使用时需先构建 Database 对象，在 withDatabase 上下文中执行建表、插入与查询。目前不支持空值（nullability），null 会回退为 ClickHouse 默认值；同步表结构时默认不执行删除操作，不会丢弃已存在的表或列。发布于 JCenter。

  • 提供 Exposed 风格的 Kotlin DSL，支持标准 SQL 操作（建表、插入、查询等）
  • 支持 ClickHouse 方言特性，包括状态聚合函数、多种引擎和 ReplicatedConnectionContext 副本执行上下文
  • 支持 syncScheme 表结构对齐：表不存在则创建，缺少的列则添加，默认不删除已有表或列

适用场景（解读层）

  • 在 Kotlin 项目中以编程方式读写 ClickHouse 数据仓库中的分析型数据
  • 需要管理 ClickHouse 表结构定义与同步的场景
  • 副本集群环境下通过多个 Database 对象进行负载均衡访问
