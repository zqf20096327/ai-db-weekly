将 GPU 加速的机器学习推理集成到 PostgreSQL 中的扩展。

综述（解读层）

PostgresML 是一个 PostgreSQL 扩展，将机器学习与 AI 推理运行在数据库内部，无需单独的模型服务系统。它支持 Hugging Face 模型、RAG 流水线（chunk/embed/rank/transform 四个 SQL 函数）及 47 种以上分类回归算法。适用于希望在数据所在位置直接运行模型推理的团队；目前不直接支持调用 OpenAI 等远程 LLM 提供商，可通过 Docker 自托管或使用其云服务运行。

  • 提供 pgml.chunk、pgml.embed、pgml.rank、pgml.transform 四个 SQL 函数构建 RAG 流水线，并通过 pgvector 实现向量存储与相似性检索
  • 支持 Hugging Face 模型库中的预训练模型，提供文本分类、翻译、摘要、问答等 NLP 任务
  • 提供 47 种以上分类与回归算法，可通过 pgml.train 训练并用 pgml.predict 推理

适用场景（解读层）

  • 在数据库内为检索增强生成（RAG）应用做文本分块、向量嵌入与重排序
  • 使用 SQL 对已有数据训练分类/回归模型并执行推理
  • 在 PostgreSQL 环境中执行文本生成、翻译、摘要等 NLP 任务
