Eden 框架的 SQLite ORM 组件，提供查询、搜索、集合与模型操作

综述（解读层）

Eden SQLite 是 Eden 框架中面向 SQLite 的 ORM 组件，供 PHP 开发者通过 Composer 安装使用。它基于 PDO 连接数据库文件并采用惰性连接，支持绑定参数的原生查询、insertRow/updateRows/setRow/deleteRows 等数据操作，并提供 search 查询构建器、集合与模型三层抽象；模型属性可通过方法、对象或数组访问，save() 时按表列名匹配自动决定插入或更新。README 提到其 SQL 数据库组件接口与 MySQL、PostgreSQL 版本保持一致。

  • 基于 PDO 连接 SQLite 文件，首次查询时才建立连接（惰性加载），支持绑定参数查询
  • 提供 search() 链式查询构建器，含八种 join 方法、filterBy/sortBy 魔术方法及分页、分组方法
  • 提供集合与模型抽象，模型属性可用方法、对象或数组三种方式访问，save() 按表列名匹配并自动判断插入或更新

适用场景（解读层）

  • 需要在 PHP 项目中对 SQLite 数据文件执行增删改查的场景
  • 需要用链式构建器组装含 join、过滤、排序、分页的复杂查询的场景
  • 需要以集合/模型方式批量读取、修改并回写数据的场景
