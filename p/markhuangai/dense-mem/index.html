综述（解读层）

Dense-Mem 是一个独立运行的 HTTP MCP 记忆服务器（Streamable HTTP），供 AI 客户端跨会话存取记忆。它保存确切 Evidence 及其来源与生命周期，支持私有/团队共享记忆、溯源追踪（Trace）与基于 pgvector 的检索。以 PostgreSQL 为持久层，多实例部署需 Redis 协调。通过 Docker Compose 部署，Apache-2.0 许可。

  • 以 MCP（Streamable HTTP）接口提供 Remember/Recall/Trace 工作流，保留 Evidence 的来源、版本与 append-only 生命周期
  • 支持私有与团队共享两类记忆目标，共享可见性不授予修改他人 Evidence 的权限
  • 持久层为 PostgreSQL+pgvector，单实例可用进程内存协调，多实例需 Redis 等分布式协调

适用场景（解读层）

  • 为自托管 AI 客户端提供跨会话记忆存取
  • 需要记录记忆来源与更正/撤回谱系的团队场景
  • 需将模型与数据流量限定在自有基础设施内的部署（可自托管嵌入与模型服务）
