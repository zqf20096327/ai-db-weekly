pg_expecto 是一套面向 PostgreSQL 的性能统计分析与负载测试工具集

综述（解读层）

pg_expecto 用于对 PostgreSQL 进行统计与相关性分析、等待事件分析，并内置负载测试功能。它采集 pg_stat_statements、pg_wait_sampling 及 vmstat/iostat 的操作系统指标，可导出 Excel 兼容报告，并包含生成 AI 提示词与基于马尔可夫链的性能事件预测模块。部署需在目标数据库服务器上运行 shell 安装脚本，依赖特定日志与预加载配置。

  • 分析 PostgreSQL 等待事件（wait_event_type/wait_event）并通过 vmstat/iostat 采集操作系统磁盘、内存、CPU 指标，建立其与数据库行为的关联
  • 内置负载测试功能与 Excel 兼容的报告导出；v10 引入基于马尔可夫链的性能事件预测实现
  • 要求预加载 pg_stat_statements 与 pg_wait_sampling（顺序重要）并配置一组日志参数（log_checkpoints、track_io_timing 等）

适用场景（解读层）

  • 排查 PostgreSQL 性能瓶颈时，将数据库内部等待事件与操作系统资源指标进行关联分析
  • 通过内置负载测试评估数据库在压力下的行为并确定性能极限
  • 建立标准化性能指标文件用于主动监控，并在性能下降事件发生时触发响应流程
