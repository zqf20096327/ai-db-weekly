Python 编写的 PostgreSQL 到 OceanBase MySQL 租户全量迁移工具

综述（解读层）

该工具用于将 PostgreSQL 数据库迁移到 OceanBase MySQL 租户，覆盖表结构与全量数据迁移，自动做类型转换并忽略 JSON/JSONB 和数组字段。支持断点续传、并发迁移、数据一致性验证，大数量场景可用 obloader 文本导入方案。要求 Python 3.8+、PostgreSQL 11.x+，支持 Docker 部署，MIT 许可证发布。

  • 支持全量表结构与数据迁移，自动执行 PostgreSQL 到 OceanBase MySQL 的类型转换
  • 提供断点续传、并发迁移、批量迁移进度显示与数据一致性验证
  • 提供 schema-only、data-only 拆分模式及文本导出配合 obloader 的导入方案

适用场景（解读层）

  • 需要将 PostgreSQL 数据库整体迁移到 OceanBase MySQL 租户的场景
  • 数据量较大、需借助 obloader 加速导入的迁移任务
  • 迁移前需在测试环境验证结构转换与数据一致性的场景
