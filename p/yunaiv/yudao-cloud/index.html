基于 Spring Cloud Alibaba 的微服务后台管理与业务系统脚手架

综述（解读层）

yudao-cloud 是 ruoyi-vue-pro 的 Spring Cloud 微服务版本，后端采用 Spring Cloud Alibaba（Nacos、Gateway、Sentinel、Seata、XXL-Job），前端提供 Vue2/Vue3 多套管理后台及 uni-app 移动端。内置系统管理、工作流、支付、商城、CRM、ERP、AI 等模块，分完整版与精简版，采用 MIT 协议，适合需要微服务架构的企业级管理系统开发团队。

  • 后端基于 Spring Cloud Alibaba：Nacos 注册与配置中心、Gateway 网关、Sentinel 服务保障、Seata 分布式事务、XXL-Job 定时任务
  • 支持多租户（SaaS）、RBAC 动态权限、数据权限、SSO 单点登录，数据库兼容 MySQL、Oracle、PostgreSQL 及达梦、人大金仓等国产数据库
  • 工作流基于 Flowable，提供仿钉钉/飞书与 BPMN 双设计器，支持会签/或签、加签、父子流程、条件/并行分支等操作

适用场景（解读层）

  • 需要微服务架构的企业级后台管理系统开发
  • SaaS 多租户业务系统的快速搭建
  • 需要审批工作流、支付、商城、CRM/ERP 等模块的业务系统
🔌 适配哪些库db_scan 程序判定

Dameng、MariaDB、MySQL、Oracle、PostgreSQL、SQL Server、TiDB
