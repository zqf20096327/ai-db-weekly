🧭 简介解读层（AI·证据行可回查）

以 Docker 容器形式运行的服务，为 MySQL/MariaDB/Aurora 数据库提供 REST 接口。

综述（解读层）

Boreal 将运行在容器中的 MySQL、MariaDB 和 Amazon Aurora 数据库封装为 REST API。用户通过 docker run 传入数据库地址、账号、密码等环境变量即可启动；支持读写分离配置（主库与读库），并可连接 Memcached 或 Redis 作为缓存。接口覆盖 SELECT、INSERT、批量插入、UPDATE、DELETE 及原始 SQL 查询，同时提供 FLUSH TABLES、SHOW PROCESSLIST、DESCRIBE 等管理端点。

  • 通过 HTTP 参数映射 SQL：_fields 指定查询列、_where 指定过滤条件，生成对应 SELECT 语句
  • 支持单条与批量 JSON 数据插入、按 where 条件更新与删除，以及 POST 原始 SQL 到 /v1/_QUERY 端点
  • 提供管理端点：_FLUSHTABLES、_RESETQUERYCACHE、_PROCESSLIST、_SHOWTABLES、_DESCRIBE、_SHOWCREATE 等

适用场景（解读层）

  • 需要以 HTTP 接口访问容器环境中 MySQL/MariaDB/Aurora 数据库的场景
  • 希望通过 REST 端点执行查询缓存管理、查看进程列表等数据库管理操作的运维流程
  • 在主从架构中按读写分别转发请求的场景
