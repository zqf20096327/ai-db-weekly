综述（解读层）

Synnax 是一个 monorepo 项目，用于硬件操作的实时数据采集、控制与数据审查，按全速率记录每个采样，提供实时绘图、操作员原理图与自动化序列。工程师可通过 C++/Python/TypeScript 客户端库或 Console 桌面应用访问。核心服务器集成嵌入式时序引擎 Cesium；免费版限 50 通道，运行于 macOS（Apple silicon）与 Windows。项目仍在积极开发中，遵循语义化版本。

  • 以全速率记录采样数据，支持实时绘图、控制序列与数据审查
  • 通过 Driver 连接 NI、LabJack、EtherCAT、HTTP 设备及 OPC UA、Modbus TCP 服务器
  • 内含嵌入式时序数据库引擎 Cesium 与自动化领域语言 Arc（支持 WebAssembly 编译目标）

适用场景（解读层）

  • 硬件测试台架的实时遥测采集与操作员监控界面搭建
  • 基于 Arc 语言的硬件自动化与控制序列执行
  • 通过 Python 等客户端库以编程方式访问与处理时序传感器数据
