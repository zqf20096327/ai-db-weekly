PostgreSQL 数据库集群的备份与恢复管理工具

综述（解读层）

pg_probackup 是用于管理 PostgreSQL 数据库集群备份与恢复的命令行工具，适用于需要对 PostgreSQL 实例进行周期性备份并在故障后恢复服务器的运维场景。它通过备份目录统一存放备份文件、元信息和 WAL 归档，支持全量备份及 PAGE、DELTA、PTRACK 三种增量模式，并可按保留策略管理备份与 WAL。限制包括：源服务器与恢复服务器需相同大版本且 block_size、wal_block_size 兼容；Windows 不支持经 ssh 的远程备份。

  • 支持全量备份和 PAGE、DELTA、PTRACK 三种页面级增量备份模式，兼容 PostgreSQL 13–18
  • 支持增量恢复、备份合并、数据一致性校验（validation/checkdb）、压缩、去重与多线程并行操作
  • 支持从备库备份、远程备份与恢复、PGDATA 外部目录备份，备份目录信息可输出为纯文本或 JSON

适用场景（解读层）

  • 需要按保留策略（TTL、恢复时间或备份数量）管理周期性备份与 WAL 归档的 PostgreSQL 生产实例
  • 依赖持续归档进行时间点恢复（PITR），或希望采用增量合并备份策略以减少周期性全量备份的环境
  • 需要从 standby 备份、跨机器远程备份/恢复，或将 PGDATA 之外的配置文件、脚本等一并纳入备份的场景
