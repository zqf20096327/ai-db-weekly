PostgreSQL 自适应查询优化扩展，用执行统计改进基数估计

综述（解读层）

AQO 是 PostgresPro 开发的 PostgreSQL 扩展，由补丁和扩展两部分组成，需对源码打补丁并完整重建 PostgreSQL 后安装。它基于查询执行统计为每类规范化查询维护机器学习模型，用于改进基数估计，适用于 9.6 及以上版本。限制包括不支持临时对象，且库须在服务器启动时预加载。

  • 提供 controlled、learn、intelligent、forced、disabled 五种模式，通过 aqo.mode GUC 变量切换
  • 按规范化查询（去除常量）的哈希存储每类查询的 learn_aqo、use_aqo、fs、auto_tuning 设置及查询文本
  • 支持 aqo.show_details 和 aqo.show_hash 显示各计划节点的基数预测结果与哈希签名

适用场景（解读层）

  • 复杂查询因基数估计偏差导致执行时间过长时的优化尝试
  • 动态生成查询结构的工作负载（forced 模式使用 COMMON 特征空间）
  • 对已知查询类型按预定义设置运行、未知查询回退标准优化器的生产环境（controlled 模式）
