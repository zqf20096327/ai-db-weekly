🧭 简介解读层（AI·证据行可回查）

PostgreSQL 扩展，通过补丁内核后实时查看运行中后端的查询执行计划与统计。

综述（解读层）

pg_query_state 是一个 PostgreSQL 扩展，用于从外部后端提取指定进程当前查询的实时执行统计，输出格式与 EXPLAIN ANALYZE 类似，支持并行 worker、嵌套函数调用的调用栈展示及进度条功能。安装需按版本给 PostgreSQL 打补丁并重新编译部署二进制，需将模块加入 shared_preload_libraries 后重启实例并 CREATE EXTENSION。调用角色须为超级用户或目标后端所属角色的成员。

  • 提供 pg_query_state(pid) 函数，返回指定后端当前查询的计划树及实时统计，支持 leader/worker 树结构与函数调用栈分帧展示
  • 支持 verbose、costs、timing、buffers、triggers 选项及 text/xml/json/yaml 输出格式
  • 提供 pg_progress_bar 与 pg_progress_bar_visual 函数，返回 0 到 1 的查询完成度数值并支持周期性打印

适用场景（解读层）

  • 排查长时间运行或疑似卡住的重查询，查看其当前执行的算子统计
  • 持续观察并行查询中 leader 与各 worker 的执行状态
  • 跟踪函数体内嵌套子查询的执行进度
