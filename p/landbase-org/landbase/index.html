MiniOB：面向零基础学习者的教学用简化数据库内核项目

综述（解读层）

MiniOB 是 OceanBase 团队基于华中科技大学数据库课程原型开发的教学项目，面向在校学生、数据库从业者和爱好者。其简化了并发、安全、事务管理等模块，包含网络、SQL 解析、查询优化、计划执行、元数据管理等关键模块，部分模块（如执行计划缓存、查询缓存）尚未实现。通过 git clone 后运行 build.sh 即可编译，也可使用 Gitpod 在线开发。

  • 包含网络、SQL 解析、语义解析、查询优化、计划执行、会话管理、元数据管理等数据库关键模块
  • 支持通过 build.sh 脚本编译，并提供 Gitpod 在线开发平台
  • 提供 doxygen 生成的代码文档及配套视频教程、讲义等学习资料

适用场景（解读层）

  • 零基础学习数据库内核实现原理
  • 作为 2023 OceanBase 数据库大赛的训练平台，在 MiniOB 训练营提交测试
  • 学习内存管理、网络通信、磁盘 I/O 等工程编码实践
