基于 firebird-driver 的 Django Firebird SQL 数据库后端

综述（解读层）

django-firebird 让 Django 应用以 Firebird 作为数据库，底层使用官方 firebird-driver 2.x，要求 Firebird 3.0 及以上服务器，支持 Python 3.11–3.14。安装后需额外部署 libfbclient 客户端库，客户端版本需不低于服务器版本以支持 INT128 NUMERIC 类型。配置通过 settings.py 的 ENGINE 指定 django_firebird。适用于已有 Firebird 数据库的 Django 项目。

  • 基于官方 firebird-driver 2.x 实现，通过 ENGINE 'django_firebird' 接入 Django ORM
  • CI 对 Firebird 3.0/4.0/5.0 官方 Docker 镜像持续测试，6.0 快照作为非阻塞目标
  • 5.0 起 BooleanField 使用原生 BOOLEAN 类型，不再创建 check 约束

适用场景（解读层）

  • Django 项目需要连接 Firebird 3.0+ 数据库
  • 从旧版 firebird/fdb 后端迁移到 firebird-driver 2.x 的项目
  • 在 migrate 流程中让 Django 直接管理 Firebird 数据库 schema
