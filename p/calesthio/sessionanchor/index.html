🧭 简介解读层（AI·证据行可回查）

为 Claude Code 会话提供基于本地 SQLite 分层记忆的上下文管理命令行工具

综述（解读层）

SessionAnchor 是一个 Python 编写的命令行工具，用仓库内 .claude/memory/ 下的单个 SQLite 数据库替代扁平上下文文件，为 Claude Code 项目提供跨会话的上下文延续。启动时仅加载 L0+L1 两层约 2000 token 的简报，完整历史存入 L2、按需通过 FTS5 关键词检索。启动时自动执行降级压缩（时间、数量、完成、替代规则），并通过 .contextignore 与密钥模式扫描过滤敏感内容。需 Python 3.9+，无第三方依赖。

  • 三级分层记忆：L0/L1 每次启动加载（约 2000 token），L2 通过 FTS5+BM25 关键词查询按需检索
  • 启动时自动压缩：按 14 天过期、20 条上限、完成宽限、supersedes 归档四条规则将旧条目降级至 L2
  • 存储层使用 SQLite WAL 模式、FTS5 全文检索、sha256 确定性 ID 去重，内容存储前自动替换 AWS/API/JWT 等密钥模式

适用场景（解读层）

  • 在真实项目上使用 Claude Code，希望新会话延续上次决策、待办与阻塞项而不重读全部 markdown 上下文文件
  • 关注启动 token 消耗并希望量化对比的开发者（boot 命令附带 token 估算页脚，session-end 可记录）
  • 需要本地化、无服务器、无 API key 的个人记忆方案，不适合多用户协调或云端同步场景
