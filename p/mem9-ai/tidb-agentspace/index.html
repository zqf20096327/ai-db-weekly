为 AI agent 提供跨会话持久化的文件与数据库工作空间

综述（解读层）

TiDB AgentSpace 是一个面向 AI agent 的持久化工作空间：提供 PostgreSQL 兼容数据库、持久化文件系统，并通过 Workspace Key 管理资源与操作权限。用户可在 Studio 中查看 agent 保存的文件与查询结果，Studio 与外部 agent 使用同一 Rust API。README 说明 agent 托管执行、Runs、Memory 等尚未实现。

  • 提供 PostgreSQL 兼容数据库与持久化文件系统两类资源
  • 通过 Workspace Key 实现按资源与操作范围限定权限，密钥可换取短期 Region 访问 Token
  • 提供 JavaScript/Python API 客户端、OpenAPI 导出工具，并以 Rust 实现后端，Apache 2.0 许可

适用场景（解读层）

  • 让外部 agent（如 Codex CLI、Claude Code）跨会话保存和读取分析报告、CSV 等文件
  • 在 Studio 中创建数据库、运行 SQL 教程查询并浏览表数据
  • 本地以 Rust 后端搭建工作空间服务并开发基于其 API 的应用
