基于 SPI 机制的 Nacos 达梦数据库数据源插件

综述（解读层）

该插件通过 Java SPI 机制为 Nacos 2.2.0 及以上版本提供达梦数据库（DM8）的数据源支持，插件按 Nacos 版本划分兼容版本（如 2.2.0–2.3.0 对应 0.0.2，3.0.0 以上对应 0.0.6），依赖发布在 Maven 中央仓库。使用者需修改 spring.datasource.platform 属性并配置达梦 JDBC 连接；README 同时给出用 SQLark 或达梦 DTS 工具从 MySQL 迁移数据的两种方案。项目采用 Apache License 2.0 协议。

  • 通过 SPI 机制扩展 Nacos 数据源，修改 spring.datasource.platform 属性即可启用达梦数据库
  • 按 Nacos 版本提供对应插件版本，覆盖 2.2.0 至 3.0.0 以上，依赖已发布至 Maven 中央仓库
  • README 提供两种 MySQL 到达梦的数据库迁移方案（SQLark 与达梦 DTS）

适用场景（解读层）

  • 需要将 Nacos 配置/服务数据存储于达梦数据库 DM8 的部署环境
  • 已使用 MySQL 存储 Nacos 数据、需迁移到达梦数据库的场景
  • 信创环境下的 Nacos 集群部署，需替换默认的 MySQL 或 Derby 存储
📖 README 首段存档原文 · 程序抽取

本插件为 Nacos（2.2.0 版本及以上）提供达梦数据库（DM8）的数据源支持。通过 SPI 机制实现，您只需在 application.properties 配置文件中修改 spring.datasource.platform 属性即可启用达梦数据库。
