基于 Postgres/SQLite 的事务性后台任务队列，支持多语言

综述（解读层）

River 是一个基于 Postgres 或 SQLite 的后台任务队列库，提供 Go、Java、JavaScript/TypeScript、Ruby 和 Rust 实现，各实现之间相互兼容，可在一种语言中入队、在另一种语言中处理。其核心机制是事务性入队：任务与应用数据共用同一数据库，任务随事务提交而生效、随回滚而移除。支持自动重试、定时与 cron 任务、唯一任务、多队列，并附带 Web UI。适用于需要将任务队列与应用事务绑定的 Go 及多语言服务场景。

  • 任务与应用数据同库，通过事务入队保证任务与数据库变更的一致性
  • 支持自动重试、定时/周期任务、唯一任务、多队列及批量插入（Postgres COPY FROM）
  • 多语言实现相互兼容，可跨语言共享队列，并提供 Web UI 与测试辅助工具

适用场景（解读层）

  • 需要在同一事务中将任务入队与业务数据写入绑定的应用
  • 由多种语言（Go/Java/JS/Ruby/Rust）服务共享同一任务队列的系统
  • 需要定时、周期执行或按参数去重的后台任务处理
