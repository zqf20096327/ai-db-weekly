直接读取 PostgreSQL 数据文件与 WAL 的数据恢复提取工具

综述（解读层）

PDU（PostgreSQL Data Unloader）是一个开源的 PostgreSQL 数据恢复与提取工具，面向需要处理损坏实例、误删数据、文件丢失等场景的 DBA。它不经运行中的数据库实例，直接解析 heap/TOAST 数据文件，也可扫描 WAL 归档提取被删除行或 UPDATE 前值，支持按事务 ID 或时间范围过滤，输出 CSV/SQL。构建时需在 basic.h 中指定目标 PostgreSQL 版本（14-18），运行依赖 LZ4/Zlib 库，交互命令需以分号结尾。部分命令（如 restore db、dropscan 系列）标注为 Pro/Enterprise 功能。

  • 直接解析 PostgreSQL 14-18 的 heap/TOAST 数据文件，无需运行数据库实例，导出 CSV 并可生成 DDL/COPY 语句
  • 扫描 WAL 归档以提取被 DELETE 的行和 UPDATE 前的值，支持按事务 ID 或时间范围恢复
  • 支持 numeric、时间、文本、json、uuid、网络地址等类型，自动处理 TOAST 大对象（含 LZ4 解压）；不支持枚举、复合、范围类型及 tsvector/tsquery

适用场景（解读层）

  • PostgreSQL 因系统目录或文件损坏无法启动时，直接从数据文件提取数据
  • 误执行 DELETE/UPDATE 后，从 WAL 归档恢复被删行或更新前值
  • 特定数据文件丢失或被删除/截断（含 DROP TABLE 场景）时，从剩余文件和 WAL 元数据重建数据
