基于 PDO 的轻量 PHP Active-Record 模型类，提供表列映射、CRUD 与动态查找器

综述（解读层）

Freshsauce\Model 是一个 PHP 单模型类库，通过继承基类将 PHP 类映射到数据库表，提供 save/insert/update/delete 等 CRUD 方法、按方法名生成查询的动态查找器与计数器，并支持事务助手、时间戳自动填充、属性类型转换和校验钩子。要求 PHP 8.3+ 与 ext-pdo，支持 MySQL/MariaDB、PostgreSQL 和 SQLite。README 明确说明其不包含关系图、迁移或链式查询构建器。

  • 提供 CRUD 助手、动态查找器（如 findByName）、exists/fetchWhere 等查询助手，以及 transaction 等事务包装方法
  • 支持 created_at/updated_at 自动填充（UTC）、每模型可配置时间戳列，以及 integer/float/boolean/datetime/array/object 属性类型转换
  • 支持 MySQL/MariaDB、PostgreSQL、SQLite，可在需要时直接执行原生 SQL，并提供模型专用异常类与严格字段模式

适用场景（解读层）

  • 需要在自定义、遗留或小型 PHP 应用中使用 Active-Record 风格模型而不引入完整框架 ORM
  • 需要保留 PDO 与原生 SQL 直接访问能力的数据库读写场景
  • 简单服务或新项目中需要 CRUD、计数、校验与时间戳等常见模型功能
