PHP 数据库封装库，统一操作 MySQL/Postgres/SQLite

综述（解读层）

dbhelper 是一个 PHP 数据库封装库，通过 PDO 或 wpdb 连接 MySQL、Postgres、SQLite 数据库，提供统一的查询、插入、更新、删除接口，并内置基于触发器的数据变更日志功能，可自动记录 updated_by 字段和日志表。通过 Composer 安装，也支持 WordPress 环境，SQLite 连接默认提供 60 秒锁超时。

  • 通过 PDO 支持 MySQL、Postgres、SQLite，并通过 wpdb 支持 WordPress
  • 提供 setup_logging() 方法，自动创建日志表、为所有表添加 updated_by 列并创建 insert/update/delete 触发器
  • 支持自动注入 updated_by（enable_auto_inject）、日志清理（purge_logging，分批删除）、日志状态检查（check_logging）

适用场景（解读层）

  • PHP 项目中需要以统一接口访问多种关系数据库
  • 需要在 MySQL/Postgres 数据库上建立数据变更审计日志（记录修改人、修改时间、变更值）
  • WordPress 插件开发中需要使用预处理语句查询数据库
