为 SQL 智能体提供模式地图的 MCP 服务器，确定性输出、无 LLM 调用

综述（解读层）

keygraph 是面向构建数据分析或 text-to-SQL 智能体的开源模式地图工具。它扫描数据库元数据，映射键、索引、外键、join 路径、表粒度、状态码与值画像，并通过 MCP 服务器、CLI --json、markdown 文件或离线 HTML 探索器输出。运行于 Python 3.11+，MIT 协议，只读取元数据且不做 LLM 调用，不执行查询；查询需配合 DBHub 等只读数据库服务器。

  • 提供 20 个 MCP 工具（14 个只读、1 个查询日志、5 个 LLM 索引工具），path 命令返回带证据、置信度和 JOIN 片段的路径，并标记一对多 fan-out
  • describe 命令输出行粒度、状态码含义及数据中存在但未文档化的码值；推断关系带置信度，低于 0.6 默认隐藏
  • 支持 MySQL、MariaDB、PostgreSQL、SQLite、SQL Server、ClickHouse、Metabase、MongoDB 及 information_schema 转储；scan 接受任意 SQLAlchemy URL

适用场景（解读层）

  • 为 text-to-SQL / 数据分析智能体提供表连接路径、键与状态码上下文，避免在 join 时重复计数
  • 将离线 HTML 探索器和 markdown 页面用于人工查看或只读文件的智能体
  • 无法直连数据库时，从 information_schema 转储构建模式地图
