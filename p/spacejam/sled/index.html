Rust 编写的嵌入式 KV 数据库，基于无锁 B+ 树与日志结构存储。

综述（解读层）

sled 是一个嵌入 Rust 程序的键值数据库，提供类似线程安全 BTreeMap 的 API。它支持 ACID 乐观事务、零拷贝读取、前缀订阅与 merge operators，底层由无锁树、页缓存和日志三层构成。README 注明主分支正在大规模重写，磁盘格式在 1.0 前可能要求手动迁移，且进程内暂不支持多实例。

  • 提供可序列化的 ACID 事务，支持跨多个 keyspace 原子读写多个键，以及单键原子操作（含 compare-and-swap）
  • 采用无锁实现与日志结构存储，通过前缀编码和后缀截断减少共享前缀长键的存储开销
  • 支持前缀变更订阅、写批次、merge operators、双向范围迭代器，以及默认每 500ms 自动 fsync（可配置）的崩溃安全单调 ID 生成器

适用场景（解读层）

  • 需要嵌入到单个 Rust 进程中的键值存储场景，如长期运行、高并发的有状态服务
  • 需要原子事务、键前缀变更订阅或崩溃安全 ID 生成的应用
  • 数据集可完全驻留内存缓存时的异步友好读写场景
