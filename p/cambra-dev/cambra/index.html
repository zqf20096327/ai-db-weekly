综述（解读层）

Cambra 是一门用 Rust 编写的研究性编程语言，面向数据密集型应用，将事务、流处理与分析统一为单一程序：Pythonic 语法 CHL 编译到核心语言 CCL，再转为数据流算子图运行。类型系统基于精化类型并依赖 z3 求解器。目前为研究预览：无发布版本，需从源码构建，不适用于生产环境，暂不接受 PR。

  • 提供精化类型系统，类型携带语义谓词，类型检查通过子进程调用 z3 求解约束
  • 程序编译为数据流算子，以流式数据流语义运行，内建流水线、增量计算与并行化
  • 提供 --inspect（查看算子流经数据）、--inspect-only（查看 IR 树）与 --control（/diff 与 /reload 对比并热替换运行中程序）

适用场景（解读层）

  • 阅读与研究统一事务/流/分析的语言设计与形式语义文档
  • 从源码构建后运行 tests/programs 下的示例程序并借助 inspector 观察数据流
  • 使用 control 端口对运行中程序做版本 diff 与原地 reload 实验验证
