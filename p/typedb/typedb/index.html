基于类型系统和声明式查询语言 TypeQL 的开源数据库

综述（解读层）

TypeDB 是一个开源数据库，模式基于支持继承与接口的类型系统，数据被建模为实体、关系和属性三类根类型；查询通过其声明式强类型语言 TypeQL 完成。README 提供云版、企业版与开源社区版三个版本，社区版可从 GitHub Releases 下载，或用 Bazel、Cargo 从源码编译，采用 MPL 2.0 许可证。

  • 模式类型系统原生支持继承与接口，用户定义类型归属于实体、关系、属性三类根类型
  • TypeQL 查询语言支持全变量化语法、多态查询与可复用的函数（3.0 引入）
  • 提供语言驱动、TypeDB Studio 图形界面，社区版可经 Bazel 或 Cargo 编译，支持 macOS/Linux/Windows 多架构构建

适用场景（解读层）

  • 需要以实体-关系-属性类型模型组织数据并编写声明式查询的数据应用
  • 需在 macOS、Linux、Windows 上自托管部署或从源码构建数据库服务的场景
  • 配合 TypeDB Studio 与语言驱动进行数据建模与查询的开发流程
