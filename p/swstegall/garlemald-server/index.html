用 Rust 重写的 FFXIV 1.23b 私服模拟器，移植自 Project Meteor Server

综述（解读层）

Garlemald Server 是 Project Meteor Server（C#）的 Rust 移植版，用于模拟《最终幻想14》1.0 版最终补丁 v1.23b 的服务器，面向怀旧服务器搭建者。项目以单 Cargo 工作区提供 lobby/world/map/web 四个二进制，用 SQLite 替代 MySQL、内嵌 axum 替代 PHP 前端，启动时通过 mlua 5.4 加载 1142 个 Lua 内容脚本。README 明确说明这是进行中的移植，战斗公式、库存事件、任务奖励等子系统仅部分实现；仅版本 2012.09.19.0001 的客户端能正确协商协议。以 AGPL v3 许可发布。

  • 四个二进制（lobby/world/map/web-server）组成 Cargo 工作区，共享 protocol、数据库与 Lua 绑定的 common crate
  • 实现 1.23b 客户端线协议：TCP + Blowfish 帧、1.x opcodes、FACEINFO 位域、Director/Zone/Weather 等状态机
  • 启动时经 mlua 5.4 加载 1142 个 Lua 脚本（任务、商店、传送点等），带支持 _WAIT_TIME/_WAIT_SIGNAL 的协程调度器

适用场景（解读层）

  • 本地搭建可连接零售 1.23b 客户端的单人/开发用 FFXIV 1.0 模拟服务器
  • 基于 Lua 脚本系统开发或移植 1.x 游戏内容（任务、导演、商店等）
  • 借助包日志开关与各服务独立启动脚本进行 1.x 线协议的调试与研究
