🧭 简介解读层（AI·证据行可回查）

把数据模型转译为 C、SQLite3 SQL 与 TypeScript 代码的源码生成器

综述（解读层）

openradtool（ort）读取数据模型定义，生成 C、SQLite3 SQL 与 TypeScript 源码，并包含基于角色的访问控制、审计与生成源码文档等功能。通过 configure/make（BSD make）编译安装，支持 PREFIX 指定安装目录。README 主要覆盖安装与回归测试流程，测试可选依赖 Node.js、kcgi、cargo 等工具。

  • 将数据模型转译为 C、SQLite3 SQL 和 TypeScript 代码
  • 内置基于角色的访问控制、审计与生成源码文档
  • 提供 make regress 回归测试套件，测试无需外部网络

适用场景（解读层）

  • 以 SQLite 为存储、需要由数据模型生成 C/TypeScript 访问代码的项目
  • 需要数据层附带角色访问控制与审计功能的 C 应用开发
  • 需要对生成代码运行离线回归测试的构建流程
