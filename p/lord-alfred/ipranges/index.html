🧭 简介解读层（AI·证据行可回查）

汇总多家云厂商与爬虫 IP 段的 CIDR 列表仓库，每日更新

综述（解读层）

该仓库从公开来源收集 Google、AWS、Microsoft、GitHub、Meta、OpenAI 等服务商及爬虫的 IPv4/IPv6 地址段，以 .txt 文件按 CIDR 逐行存储，并提供合并去重后的 merged 版本与 All-In-One 汇总文件，每日更新。README 给出各文件的 raw 下载链接，用户直接下载即可使用；README 还说明 GoogleBot 可通过先屏蔽全部 Google IP 再放行 GoogleBot 段的方式使用。

  • 覆盖 Google (Cloud & GoogleBot)、AWS、Microsoft、Oracle、DigitalOcean、GitHub、Meta、OpenAI (GPTBot)、CloudFlare、Apple (Private Relay)、ProtonVPN 等二十余个来源
  • 每个来源提供原始 CIDR 列表与合并后的最小 CIDR 列表，含 IPv4 和 IPv6
  • 提供合并全部来源的 All-In-One 文件，并以 raw 链接形式发布、每日更新

适用场景（解读层）

  • 基于 IP 段配置防火墙或访问控制规则（如先屏蔽 Google 全部 IP 再放行 GoogleBot 段）
  • 安全测试、漏洞赏金（bug bounty）中识别目标资产所属云服务商
  • 识别爬虫（GoogleBot、Bingbot、GPTBot、DuckDuckBot 等）来源 IP 用于流量分类
