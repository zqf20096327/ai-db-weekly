接口编排低代码工具，将多个 API 组合为复杂接口

综述（解读层）

Juggle 是一个接口编排低代码工具，用于将现有 API 组合成新接口，供前端或第三方系统调用。支持同步、异步、定时、监听四类流程，内置方法、并行、判断、循环、代码等多种节点，可通过 Groovy、JavaScript、Python、Java 脚本扩展逻辑。运行依赖 64 位 JDK 21，解压后执行启动脚本即可访问，默认端口 9127。

  • 支持 Http、Dubbo、WebService 等协议的接口调用，以及 Groovy、JavaScript、Python、Java 等脚本语言的代码节点
  • 提供方法、并行、判断、循环、赋值、调用、队列、数据库、缓存等多种节点，支持同步、异步、定时、监听四类流程及流程多版本管理
  • 内置套件市场（含通义千问、钉钉机器人等官方套件），支持 MySQL、达梦、TiDB、OceanBase、Doris 等数据源

适用场景（解读层）

  • 已有基础微服务能力时，通过编排接口快速搭建新产品或构建 BFF 前端适配层
  • 与第三方系统对接，通过编排方式完成集成而无需编写对接代码
  • 面向私有化或定制化场景，编排定制接口以复用标准代码
