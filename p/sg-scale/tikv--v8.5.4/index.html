🧭 简介解读层（AI·证据行可回查）

Rust 编写的分布式事务型键值数据库，基于 Raft 共识与 RocksDB 存储

综述（解读层）

TiKV 是开源分布式键值数据库，使用 Rust 实现，通过 Raft 共识算法保证数据一致性，共识状态存储于 RocksDB。提供经典 KV API 与符合 ACID 的事务 API，支持快照隔离与外部一致性读写。可独立与 PD 部署，也可作为 TiDB 的存储层。仓库记录了 TiUP、二进制及源码构建等部署方式，客户端驱动包含 Go、Java、Rust、C。

  • 使用 Raft 共识算法与 Placement Driver 实现自动分片、数据迁移与跨地域复制
  • 提供 ACID 事务 API，支持快照隔离、带锁快照隔离及外部一致性读写
  • 实现协处理器框架以支持分布式计算，每个 Store 内置 RocksDB 本地存储

适用场景（解读层）

  • 需要事务性键值存储的分布式数据场景
  • 作为 TiDB 的底层存储引擎配合使用
  • 通过 Python/Go/Java/Rust/C 客户端访问的 KV 数据读写
