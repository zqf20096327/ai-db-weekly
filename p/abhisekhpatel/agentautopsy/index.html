🧭 简介解读层（AI·证据行可回查）

基于本地 SQLite 记录的 AI Agent 事后调试与回放工具

综述（解读层）

AgentAutopsy 是一个 Python 库（PyPI 可安装，MIT 许可，支持 Python 3.8+），用于记录和调试 AI Agent 的运行失败。调用 watch() 后它会拦截 LLM、HTTP、MCP 和工具调用，将事件时间线写入本地 SQLite 文件，无需云服务或配置文件。提供回放、从任意步骤分叉、提示词对比、循环检测等功能。适用于使用 LangChain、AutoGen 等框架开发或运维 Agent 的开发者。

  • 通过 agentautopsy.watch() 拦截 LLM、HTTP、MCP 和工具调用并记录到本地 SQLite 文件
  • 支持从任意步骤回放（replay）和分叉（fork），并可对比原始运行与回放结果
  • 包含 SchemaDriftDetector、LoopDetector、ContextMonitor、EvalGenerator 等模块，分别用于检测 API 字段变更、重复调用、上下文占用及生成 pytest 测试

适用场景（解读层）

  • Agent 静默失败后查看完整事件时间线（提示词、工具、token、时间戳）定位原因
  • 多 Agent 工作流的跨代理因果追踪
  • 在 API 或工具升级后检测字段重命名/删除/新增等 schema 变更
