🧭 简介解读层（AI·证据行可回查）

基于 openEuler 与达梦 DM8 的数据库自动化备份、灾备演练与运维排错项目

综述（解读层）

该项目在 openEuler 24.03 LTS 与达梦 DM8 V8.1.5 单机环境中，提供逻辑全备（dexp/dimp）、flock 防重入调度、MD5 校验、健康巡检晨报及 Nginx 443 多域名网关等脚本与文档，适用于学习信创数据库运维与灾备流程的工程师。含性能实测数据、排障 Runbook 及 Grafana/Prometheus 监控配置，需自行配置凭据与私有 PKI 证书。

  • 提供 crontab 调度的达梦全量冷备脚本，使用 dexp 导出、Gzip 压缩并生成 .md5 校验文件，恢复时通过 dimp 导入
  • 包含 server_health_check.sh 巡检脚本，采集 CPU、内存、磁盘、Inode、服务与端口状态并输出 HTML 晨报
  • 提供 OpenSSL 自建私有 PKI 签发 SAN 泛域名证书及 Nginx SNI 443 端口多域名路由配置

适用场景（解读层）

  • 学习达梦 DM8 在 openEuler 上的备份恢复、锁排查与表空间扩容演练
  • 需要在内网无备案域名环境下搭建 HTTPS 多域名统一网关
  • 参考生产排障 Runbook 进行慢 SQL 调优、长事务查杀与 OOM 取证
