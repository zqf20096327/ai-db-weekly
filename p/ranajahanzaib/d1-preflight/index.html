🧭 简介解读层（AI·证据行可回查）

离线 Rust CLI，在一次性 SQLite 快照上分析 Cloudflare D1 迁移风险。

综述（解读层）

该工具将待执行的 D1 迁移 SQL 应用到本地一次性 SQLite 快照上，比较 schema 与行标识、验证约束并对比工作负载查询计划，输出带证据、严重级别和迁移归属的检查报告。使用需 Rust 工具链与 C 编译器，编译后的二进制完全离线运行。README 明确说明其不连接 Cloudflare、不部署迁移，SQLite 评估只是近似 D1，查询计划不等于延迟基准。

  • 支持 schema/数据/迁移文件、SQLite 快照、Wrangler TOML 等多种基线输入，输出纯文本、JSON 与 Markdown 报告
  • 内置规则覆盖删表删列、行数丢失、唯一性缺失、外键检查、索引移除、无界变更、视图/触发器变化及执行与完整性失败等
  • 提供 GitHub Actions 注解输出与按严重级别的退出码策略（fail_on），迁移原子按文件执行，显式事务语句被拒绝

适用场景（解读层）

  • 在部署前对 D1 迁移做本地离线的破坏性变更与约束检查
  • 接入 CI 流程，在 GitHub Actions 中生成迁移风险注解与报告
  • 对提供的 SELECT 工作负载做查询计划变化对比（不做延迟基准）
