用一次性 Docker 容器验证 PostgreSQL 逻辑备份可恢复性的 CLI 工具

综述（解读层）

pbrc 是一个用 Rust 编写的命令行工具，将 pg_dump 逻辑备份恢复到隔离的 Docker 容器中，验证数据完整性并输出 JSON/Markdown 报告。适用于需要验证备份产物的运维与 CI 流程。仅支持逻辑转储（custom/tar/directory/plain SQL/gzip），不支持物理备份、WAL 回放与 PITR；恢复不可信备份时建议使用一次性 VM。

  • 支持 PostgreSQL 16/17/18 与五种逻辑格式，恢复前用 pg_restore --list 检查归档
  • 容器运行于 none 网络，无端口发布、主机挂载与 socket 挂载，可配置内存/CPU 限制
  • 支持 TOML 期望清单（表、行数、索引、约束、只读 SELECT 断言）与三级保证等级报告

适用场景（解读层）

  • CI 中验证定时备份产物（如 GitHub Actions 下载 artifact 后运行 check）
  • 灾备演练前检验备份文件的可恢复性与内容完整性
  • 按目录/通配符选取最新备份文件进行批量或并行恢复检查
