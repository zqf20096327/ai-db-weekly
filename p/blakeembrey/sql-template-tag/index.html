🧭 简介解读层（AI·证据行可回查）

基于 ES2015 标签模板生成参数化 SQL 语句的工具库

综述（解读层）

这是一个 Node.js 库，通过 ES2015 标签模板将字符串与值分离，生成包含 sql 与 values 属性的查询对象，用于配合 pg、mysql、sqlite、oracledb 等驱动执行参数化查询。提供 join、raw、bulk、empty 等辅助函数；README 提醒 raw 接受用户输入会造成 SQL 注入风险，使用时需注意。

  • 通过标签模板生成含 sql 与 values 属性的参数化查询对象
  • 提供 join、bulk、raw、empty 辅助函数，用于拼接条件、批量插入等场景
  • 生成的查询可直接配合 pg、mysql、sqlite、oracledb 驱动使用，MSSQL 可按文档示例传参调用

适用场景（解读层）

  • Node.js 中需要拼接动态条件同时又使用参数占位符的 SQL 查询
  • 批量插入数据时生成多行 VALUES 语句
  • 配合 TypeScript 自定义值类型以收窄支持的参数类型
