综述（解读层）

Kuayle 是一个运行在自己服务器上的开源 issue 跟踪器，用 Go API 与 SvelteKit 前端实现，涵盖 issues、周期（burndown/velocity 图）、跨团队项目（Gantt 视图）、wiki 与每日日志。它内置 AI 助手并可将 issue 委派给自托管 Dev Machines 上的编码代理（Claude Code、Codex 等）。README 明确说明当前版本为可运行的 MVP，不包含 SSO，生产使用前需自行评估测试。

  • 提供键盘优先的 issue 工作流：命令面板、快捷键、多指派人、子任务、关系、版本历史 diff
  • 内置 AI 助手与编码代理委派：OpenAI 兼容 provider 接入，Dev Machines 上的 Claude Code、Codex、OpenCode 等运行委派任务，可视化 agent 工作流编辑器（高风险操作需人工批准）
  • 提供 Docker Compose 参考部署栈（Caddy、PostgreSQL、Redis），HTTP API、webhooks、MCP server、GitHub 集成及官方 CLI 与 Rust SDK

适用场景（解读层）

  • 团队在自有服务器上自托管管理 issues、周期冲刺与跨团队项目
  • 将 issue 委派给编码代理执行实现、测试、PR、CI、合并等流程，并由人工审批关键步骤
  • 通过 API、webhooks、MCP server 或 CLI 将 issue 跟踪器接入现有开发与自动化流程
