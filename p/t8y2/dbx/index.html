🧭 简介解读层（AI·证据行可回查）

基于 Rust 的轻量跨平台数据库客户端，支持 100+ 数据库及 AI、MCP 集成

综述（解读层）

DBX 是一个约 25 MB 的开源数据库管理工具，支持 MySQL、PostgreSQL、Redis、MongoDB、达梦等 100+ 数据库，提供桌面端（macOS/Windows/Linux）、Docker 与 CLI 运行方式。内置 AI SQL 助手、MCP 服务器（经 npx 独立分发）、消息队列与中间件控制台、插件系统（Go/TypeScript SDK），并支持从 DBeaver/Navicat 导入连接配置。

  • 支持 MySQL、PostgreSQL、SQLite、Redis、MongoDB、ClickHouse、达梦等 100+ 数据库，单个应用约 25 MB，不捆绑 Chromium/JRE/Python
  • 内置 AI SQL 助手，可对接 Claude、OpenAI、Ollama 本地模型或任意 OpenAI 兼容端点；独立的 MCP 服务器允许 AI 编码代理使用已配置的数据库连接
  • 提供查询编辑器、数据表格、模式对比、ER 图、CSV/Excel 导入、数据库间数据迁移，以及 Kafka、RocketMQ、MQTT、Nacos、etcd 等消息队列与中间件控制台

适用场景（解读层）

  • 开发或运维人员需要在单一客户端中连接多种类型数据库（含国产数据库）进行查询、编辑和数据迁移
  • 团队需要通过 Docker 自托管 Web 版本，集中管理数据库连接访问
  • 使用 Claude Code、Cursor 等 AI 代理时，希望通过 MCP 协议让代理按只读/读写/完全访问三种模式查询数据库
