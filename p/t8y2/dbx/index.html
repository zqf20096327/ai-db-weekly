🧭 简介解读层（AI·证据行可回查）

Rust 编写的约 25 MB 跨平台数据库客户端，支持 100+ 数据库与消息队列管理。

综述（解读层）

DBX 是一个以 Rust 构建的桌面数据库管理工具，支持 MySQL、PostgreSQL、Redis、MongoDB、达梦等 100+ 数据库，提供桌面端、Docker、Web 和 CLI 四种运行方式。除数据库外还包含 Kafka、RocketMQ 等消息队列与 Nacos、etcd 等中间件的控制台，并提供 AI SQL 助手、MCP Server 接口和基于签名沙箱机制的可扩展插件系统。

  • 支持 100+ 数据库连接，含达梦、人大金仓等国产数据库，可通过 JDBC 插件扩展 H2、Snowflake、Hive 等更多连接类型
  • 内置 AI SQL 助手，支持 Claude、OpenAI、Ollama 本地模型及 OpenAI 兼容端点，并实现 MCP 协议供 Claude Code、Cursor 等 Agent 调用
  • 提供查询编辑器、数据表格编辑、ER 图、Schema diff、数据迁移比对、CSV/Excel 导入，及 Kafka、MongoDB、Redis 等专用控制台；插件经签名校验并在沙箱 sidecar 进程中运行

适用场景（解读层）

  • 开发与运维人员需要用单一工具连接多种异构数据库（含国产库）进行查询、表结构编辑和数据迁移
  • 需要在 Docker 或浏览器环境中自部署，供团队共享访问数据库连接
  • 希望通过 MCP 让 AI 编码工具查询已有数据库连接，或在管理数据库的同时查看 Kafka、Redis 等中间件数据
