Rust 编写的 MySQL 兼容 HTAP 数据库，内置向量检索与 AI 接口

综述（解读层）

MyDB 是用 Rust 编写的通用数据库，面向 HTAP 混合负载、AI 代理与 MySQL 兼容场景。它复用 MySQL 客户端与 JDBC 驱动，提供原生全文与向量检索（HNSW/IVF）、SQL 外部模型调用、REST/MCP 接口、自动 Zone Maps、在线 DDL 与可查询备份。当前 1.2.1 为公开预览版，面向功能验证与受控环境评估，磁盘格式不保证向后兼容。

  • 支持 MySQL 客户端/驱动复用、ROW/FULL binlog 集成及原生 REST SQL 与 MCP 接口
  • 在同一数据集上并行处理事务读写与分析查询，包含向量检索、全文混合检索与外部模型调用
  • 提供 MVCC 事务、时间旅行查询、在线 schema 变更与可直接查询的备份

适用场景（解读层）

  • 同一业务数据上混合事务与分析查询的 HTAP 应用
  • 需要通过 SQL、REST 或 MCP 访问向量与全文检索的 AI 代理/服务
  • 希望复用现有 MySQL 客户端与 JDBC 驱动接入新引擎的应用评估场景
