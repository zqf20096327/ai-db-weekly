🧭 简介解读层（AI·证据行可回查）

PostgreSQL 迁移脚本的静态分析工具，检测锁表、重写、破坏性操作

综述（解读层）

migsafe 对 PostgreSQL 迁移 SQL 做静态分析，在合并前检查表锁、重写、破坏性操作和缺失超时设置。支持单文件或目录检查，可按严重级别以退出码 2 使构建失败。PyPI 包名为 migsafe-pg，零运行时依赖，需 Python 3.9+，MIT 许可。

  • 静态分析迁移 SQL，检测表锁、全表重写、破坏性操作和缺失的锁超时设置
  • 支持单文件/目录检查、--fail-on 阈值触发退出码 2、--json 机器可读输出
  • 零运行时依赖，Python 3.9+，通过 pipx 或 PyPI（migsafe-pg）安装

适用场景（解读层）

  • CI 流水线中自动检查迁移文件，按严重级别阻止合并
  • 为机器人或 agent 技能提供 JSON 格式的迁移检查结果
  • 运行迁移前用 `migsafe check migrations/ && psql ...` 预检 SQL
