基于 openGauss 向量检索的 RetrievalQA 工程实验与最佳实践记录项目。

综述（解读层）

该项目记录了一条覆盖文档切分、DPR embedding、openGauss 向量入库与检索、上下文拼接、生成回答的完整 RAG 管线实验过程，并沉淀 chunk、检索算子、top-k、生成器等参数的阶段性收敛结论。适合需要在 openGauss 上验证 RAG 方案、做检索与生成解耦实验的工程人员参考。其结论绑定特定知识库与环境，README 明确标注部分结论不可无条件推广，Docker/BentoML 文件属于阶段性材料，License 尚未最终确定。

  • 实现从文本切分、DPR embedding 生成、向量写库、相似度检索到生成回答的完整链路，支持 chunk / 算子 / top-k / 生成器参数化解耦配置
  • 评测按检索（Top-1/Top-3 命中率）与生成（正确性、groundedness、完整性、幻觉）分层进行
  • 实验基于 CPU 推理环境（Ubuntu 24.04、openGauss 6.0.2、Python 3.10），并记录面向 AArch64 / RK3568 的开发机—边缘端职责拆分部署思路

适用场景（解读层）

  • 在 openGauss 上验证 RAG / RetrievalQA 方案并复用其参数配置经验
  • 进行向量检索与生成模型解耦的对比实验，检索层与生成层分开评估
  • 参考边缘部署场景下的系统拆分方式（开发机重处理 + 边缘端最小闭环）
📖 README 首段存档原文 · 程序抽取

本项目是一个基于 openGauss 的 RetrievalQA / RAG 工程实践项目，围绕“文档切分 → embedding 生成 → 向量写库 → 相似度检索 → 上下文拼接 → 生成回答”的完整链路展开，重点不只是验证系统能否跑通，而是沉淀一套更适合工程复用的配置收敛过程与最佳实践。
