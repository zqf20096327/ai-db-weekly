Rust 实现的分布式事务型键值数据库，基于 Raft 与 RocksDB

综述（解读层）

TiKV 是开源分布式事务键值数据库，使用 Rust 编写，以 Raft 共识算法和 RocksDB 存储实现数据一致性，由 Placement Driver 管理自动分片与数据迁移。它可作为 TiDB 的存储组件运行，也可单独部署；提供 Go、Java、Rust、C 客户端接口，采用 Apache 2.0 许可证，为 CNCF 沙箱项目。

  • 提供经典键值 API 与满足 ACID 的事务 API，支持快照隔离、带锁快照隔离（SELECT ... FOR UPDATE）及外部一致性读写
  • 通过 Raft 与 Placement Driver 支持异地复制和水平扩展，可将数据扩展至 100+ TB
  • 实现协处理器框架以支持分布式计算，共识状态存储于 RocksDB

适用场景（解读层）

  • 作为 TiDB 的存储引擎组件，搭配 TiDB 提供 MySQL 协议兼容的分布式数据库
  • 独立部署为分布式键值存储，通过 Go/Java/Rust/C 客户端访问
  • 需要多副本异地复制与自动数据迁移的场景
