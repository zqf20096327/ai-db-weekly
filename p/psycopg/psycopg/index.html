面向 Python 的 PostgreSQL 数据库适配器（Psycopg 3）

综述（解读层）

Psycopg 3 是 Python 语言的 PostgreSQL 数据库适配器，供需要在 Python 程序中连接和操作 PostgreSQL 的开发者使用。仓库包含多个包：纯 Python 实现的 psycopg、C/Cython 编写的 psycopg_c 优化模块，以及独立发布、提供连接池的 psycopg_pool。安装依赖 libpq 客户端库，可通过 pip 安装预编译二进制包。

  • 提供纯 Python 实现和 C/Cython 优化模块（psycopg_c）两种运行方式
  • psycopg_pool 包提供连接池实现，独立发布周期
  • 提供同步与异步工作负载的微基准比较脚本，可测量 COPY、内存等指标

适用场景（解读层）

  • Python 应用连接 PostgreSQL 数据库
  • 需要连接池管理的数据库服务场景
  • 基于 shiv 的跨平台 zipapp 打包中作为 PostgreSQL 依赖
