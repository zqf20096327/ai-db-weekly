在 Django Admin 中预览 Selenium 窗口的 Docker 化演示应用

综述（解读层）

该仓库提供一个演示 Web 应用，用于在 Django Admin 界面中显示 Selenium 浏览器窗口预览，并演示如何用 Python 生态（Django、Celery、RabbitMQ、Django Channels、Redis、PostgreSQL、Docker）配置 Selenium。应用会访问 Facebook、LinkedIn、Instagram、Twitter 等页面作为示例。适合需要搭建 Selenium 与 Django 组合环境的开发者参考。可通过 docker-compose 或本地启动两种方式运行。

  • 提供 docker-compose 一键启动与本地两种运行方式，默认账号 django:selenium
  • 集成 Celery 处理任务，RabbitMQ 作为消息代理，Redis 作为 Channel layers
  • 通过 Django Channels（WebSocket）向 Django Admin 展示 Selenium 窗口预览

适用场景（解读层）

  • 需要参考 Selenium 与 Django/Docker 生态集成配置的开发者
  • 学习 Celery + RabbitMQ + Django Channels 组合的示例项目
  • 搭建浏览器自动化任务可视化界面的起点模板
