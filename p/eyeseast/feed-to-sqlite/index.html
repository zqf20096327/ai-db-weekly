把 RSS/Atom 订阅源保存到 SQLite 数据库的命令行与 Python 工具

综述（解读层）

feed-to-sqlite 用于抓取 RSS 或 Atom 订阅源并写入 SQLite 数据库，可配合 Datasette 使用。提供 CLI 和 Python API 两种方式：CLI 默认按订阅源标题生成独立表，也可用 --table 参数合并到同一表；Python 的 ingest_feed 支持 normalize 函数在入库前转换条目，返回假值可跳过该条。适合需要将订阅内容存入本地数据库查询的用户。

  • 支持通过 pip 安装，提供 CLI 与 Python API（ingest_feed）两种使用方式
  • 默认为每个订阅源建独立表，并维护 feeds 元数据表，条目含指向源的外键
  • Python 调用时可传入 normalize 函数在保存前转换或过滤条目

适用场景（解读层）

  • 将多个 RSS/Atom 订阅源条目存入 SQLite，供 Datasette 查询浏览
  • 把多个订阅源合并写入同一张表进行统一存储
  • 在 Python 中自定义入库前的数据清洗与转换流程
📖 README 首段存档原文 · 程序抽取

Download an RSS or Atom feed and save it to a SQLite database. This is meant to work well with datasette.
