面向 PostgreSQL 的 Crystal 语言 ORM 与 SQL 构建器

综述（解读层）

Lustra 是一个仅支持 PostgreSQL 的 Crystal ORM，由 Clear v0.8 分支演化而来。它提供 Active Record 风格模型、可链式调用的查询集合、迁移、关联、校验与生命周期回调，并直接暴露 JSONB、数组、全文搜索、CTE、几何类型等 PostgreSQL 特性。要求 Crystal 1.21.0 以上，不适用于 MySQL、MariaDB 或 SQLite。

  • 提供 Active Record 模型层、迁移、关联、预加载、作用域、回调与校验
  • 支持 JSONB、数组、CTE、游标、全文搜索、枚举、UUID 和几何类型等 PostgreSQL 特性
  • 查询集合可链式组合，在 each/to_a/first/count 等终端方法调用时执行

适用场景（解读层）

  • 使用 Crystal 构建、且数据库固定为 PostgreSQL 的应用
  • 需要使用 JSONB、全文搜索、CTE 等 PostgreSQL 专属查询能力的项目
  • 需要 Active Record 风格模型与迁移管理的 Crystal 应用开发
