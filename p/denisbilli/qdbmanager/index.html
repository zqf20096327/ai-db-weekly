基于 Qt 元对象系统将 QObject 实体映射到 SQLite 的轻量 ORM

综述（解读层）

qDBManager 是面向 Qt 应用的实体管理器，用宏将 BaseEntity 子类的 Q_PROPERTY 声明映射为 SQLite 表，支持 C++ 与 QML 访问同一实体。它不提供查询 DSL、懒加载或代码生成，仅含 CRUD、CriteriaBuilder 条件查询、事务与保存点、加列式表同步。要求 Qt 5.12+（含 Qt 6）、C++11 与 QSQLITE 驱动，支持 CMake/qmake 集成，MIT 许可。

  • 通过宏声明实体属性，经 Qt 元对象系统在运行时完成实体与表列的映射，无需代码生成步骤
  • 所有值经绑定参数写入数据库，标识符经 isValidIdentifier 校验并加引号；支持事务、命名保存点嵌套及外键级联
  • 支持多命名上下文同时打开多个数据库，错误通过 error 信号上报；QDBManager 为抽象类，可按方言子类化添加后端

适用场景（解读层）

  • 需要 CRUD 与 SQLite 持久化、但不想引入完整 ORM 的 Qt5/Qt6 桌面或 QML 应用
  • 实体需同时从 C++ 与 QML 访问并作为数据库行使用的场景
  • 以子项目、FetchContent 或安装包形式集成轻量数据层的 CMake/qmake 工程
📖 README 首段存档原文 · 程序抽取

A small ORM / entity manager for the Qt Framework. It maps QObject subclasses to SQLite tables using Qt's meta-object system, so an entity is declared once — as properties — and is then usable from C+
