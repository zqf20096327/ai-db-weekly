面向AI代理的代码索引MCP服务器，SQLite存储，tree-sitter解析，支持1C导出

综述（解读层）

code-index-mcp 是一个用 Rust 编写的 MCP 服务器，将源码解析为语法树并存入 SQLite，向 AI 代理提供搜索、调用图、文件读取等工具，以减少逐文件遍历的 token 消耗。支持 HTTP（默认仅监听 127.0.0.1）和 stdio 两种连接方式，后台索引器需单独运行。通过 bsl-indexer 构建版本可解析 1C:Предприятие 8.3（Конфигуратор与EDT）导出，含元数据、表单与权限等专用工具；非 1C 构建支持 14 种语言。提供 npm 包、单二进制发布与源码编译三种安装途径。

  • 提供约 32 个 MCP 工具：函数/类全文搜索、调用者/被调用者/调用路径等调用图查询、grep 与正则搜索、带行范围的文件读取（内容以 zstd 压缩存于索引）
  • 可选 git 工具集（git_log、git_diff、git_changed_files 等），仅本地读取仓库，不访问网络
  • 1C 构建在检测到导出仓库时自动启用 get_object_structure、find_references、get_register_writers 等对象级工具

适用场景（解读层）

  • 为 Claude Code、Cursor、VS Code 等 MCP 客户端提供 1C:BSL 或通用代码库的符号检索与调用图查询
  • 在配置导出仓库上查询 1C 对象结构、表单事件处理器、角色权限引用等元数据级信息
  • 需要离线、本地运行、依赖单一的代码搜索后端（SQLite + 单二进制）的环境
