综述（解读层）

MantisBase 是用 C++20 编写的自托管后端即服务，单个二进制文件包含自动生成的 REST CRUD 接口、JWT 认证、SSE 实时推送、文件上传和 Web 管理面板，默认使用 SQLite，也支持 PostgreSQL。可通过预编译二进制、Docker 或源码构建运行，还能作为 C++ 库嵌入应用，并通过 JavaScript 扩展自定义路由。项目采用 MIT 许可证，无外部运行时依赖。

  • 创建实体（表）后即时生成 REST CRUD 端点，API 位于 /api/v1/
  • 内置 MbAuth 认证：JWT 登录（密码或邮箱一次性码）、刷新、登出与令牌验证，支持表达式权限规则
  • 支持 SQLite 与 PostgreSQL 存储、SSE 实时数据变更推送，可作为 CMake 子模块嵌入 C++ 应用或用 JavaScript 编写扩展

适用场景（解读层）

  • 为应用快速搭建带认证和实时能力的自托管后端服务
  • 部署在嵌入式设备或桌面应用中，作为 C++ 库内嵌运行
  • 通过管理面板或 REST API 管理数据表、记录、用户与文件
