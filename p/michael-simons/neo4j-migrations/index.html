Neo4j 数据库迁移与重构工具，以可控、可重复方式运行 Cypher 脚本

综述（解读层）

Neo4j-Migrations 是面向 Neo4j 的数据库迁移与重构工具集，受 Flyway 启发。它以 Cypher 脚本为主，也支持 Java 类形式的编程式迁移，迁移历史以子图形式存于数据库内。基于官方 Neo4j Java 驱动构建，支持 Neo4j 3.5 至 2026 各版本及多数据库、身份模拟等企业特性，仅依赖该驱动与 ClassGraph。适用于需要版本化变更 Neo4j 图结构的应用、CLI 与构建工具使用场景。

  • 支持以 Cypher 脚本和 Java 类（Core API）两种方式定义迁移，迁移历史以子图形式存储在数据库中
  • 提供 Core API、Spring Boot Starter、Quarkus 扩展、Maven 插件及 CLI（含 macOS/Linux/Windows 64 位原生二进制，无需 JVM）多种使用形态
  • 基于官方 Neo4j Java 驱动，支持 Neo4j 3.5、4.1–4.4、5 及 2025/2026 版本，包含多数据库与 impersonation 等企业特性

适用场景（解读层）

  • 对单个或多个 Neo4j 数据库进行版本化 schema 迁移与重构
  • 在应用、命令行、Maven 构建流程中以统一方式跟踪并应用数据库变更
  • Spring Boot 或 Quarkus 项目中通过 Starter/扩展集成迁移能力
