综述（解读层）

Mysqly 是一个面向 MySQL 的 PHP 数据访问框架，以单个 PHP 文件分发，通过下载 mysqly.php 并调用静态方法完成连接与查询。其实现基于 PDO，采用过程式风格和懒连接机制，除查询封装外还包含键值存储、任务队列、带 TTL 的缓存组件。依赖单一（PDO），适合希望在 PHP 项目中直接使用 SQL 的开发者。

  • 单文件、单静态类实现，仅依赖 PDO
  • 支持参数绑定、IN 数组绑定、事务及断线自动重连
  • 内置键值存储、任务队列与带 TTL 的缓存组件

适用场景（解读层）

  • 在 PHP 项目中简化 MySQL 查询的编写与执行
  • 为应用添加键值存储、任务队列或缓存能力
  • 将查询结果导出为 CSV/TSV 或以 JSON 形式读取
