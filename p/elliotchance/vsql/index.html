纯 V 编写的嵌入式 SQL 数据库，单文件存储，兼作 PostgreSQL 兼容服务器

综述（解读层）

vsql 是一个嵌入式事务型 SQL 数据库，用纯 V 实现，整个数据库存于单个文件或内存中。它面向需要标准 SQL（遵循 SQL:2023）、严格类型和多连接访问的应用开发者，提供 V、C、Go、Python、Java、Rust、Node.js 七种语言的库，也可作为 PostgreSQL 兼容服务器或 CLI/浏览器工具运行。事务默认 SERIALIZABLE，基于 MVCC 并带写前日志。安装只需下载单个二进制文件，无需其他依赖。

  • 支持 Join、子查询、聚合、索引、PRIMARY KEY/UNIQUE/FOREIGN KEY/CHECK 约束、序列、游标、ALTER TABLE 及标准 INFORMATION_SCHEMA 视图
  • 提供四种标准隔离级别（默认 SERIALIZABLE），基于 MVCC，多个进程可共享同一文件，配备写前日志用于崩溃恢复
  • 提供库（7 种语言）、CLI、PostgreSQL 兼容服务器和浏览器应用四种使用方式，导出/导入支持 SQL、CSV、TSV、JSON

适用场景（解读层）

  • 在测试中替代生产环境 PostgreSQL 等数据库进行应用测试
  • 多连接场景：Web 服务器连接池、多进程或后台工作线程共享同一数据库文件
  • 涉及金额、库存、预订等需要严格类型与精确数值的应用
