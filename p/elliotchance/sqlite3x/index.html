与 sqlite3 数据兼容的分支，在引擎之上追加数学函数

综述（解读层）

sqlite3x 是 sqlite3 代码库的分支，其读取和写入的数据文件与 sqlite3 相互兼容，并跟随上游代码更新。它在 SQL 引擎之上新增 acos、atan2、sqrt、pow 等数学函数；使用这些函数的查询无法在原版 sqlite3 中执行。构建沿用 sqlite3 的构建体系，新增以 x 结尾的目标以免与原版混淆。适合需要在 SQL 内直接使用数学函数的 sqlite3 用户。

  • 数据文件与 sqlite3 相互兼容，可互换读写
  • 在 sqlite3 内置函数之上追加 acos、atan2、ceil、floor、pow、sqrt 等数学函数
  • 沿用 sqlite3 的构建与测试体系，通过 make test 运行含核心与 sqlite3x 的 TCL 测试

适用场景（解读层）

  • 希望在 SQL 查询中直接调用三角、对数、幂等数学函数的场景
  • 需与现有 sqlite3 数据文件和应用保持兼容的项目集成
  • 通过 amalgamation 源文件（sqlite3x.c/sqlite3x.h）嵌入应用程序
