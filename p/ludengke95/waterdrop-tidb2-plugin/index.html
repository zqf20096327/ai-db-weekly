一个将 waterdrop 的 TiDB input 插件适配 tispark2.0+ 的补丁包

综述（解读层）

该项目提供替换用 jar 包，使 waterdrop-1.4.2 的 TiDB input 插件支持 tispark2.0+，解决原版依赖 tispark1.1 导致 TiContext 构造报错、无法读取 TiDB 3.0 数据的问题。使用者需同时满足 waterdrop-1.4.2、spark2.3+、tispark2.0+、TiDB3.0+ 的版本组合，替换 lib 下的 jar 并将插件放入 plugins 目录。

  • 提供 Waterdrop-1.4.2-tispark2.2.jar，用于替换 waterdrop 1.4.2 lib 下的原版 jar 包
  • 插件以 waterdrop 插件形式放入 plugins 目录，input 中通过 warterdrop.input.batch.Tidb 配置使用
  • 适配 tispark2.0+ 中 new TiContext(spark) 增加第二参数后的接口变化

适用场景（解读层）

  • 使用 waterdrop-1.4.2 读取 TiDB 3.0 数据且需搭配 tispark2.0+ 的批处理任务
  • 原版 waterdrop TiDB input 因 tispark1.1 依赖在 spark2.3 上读取失败时的替代方案
