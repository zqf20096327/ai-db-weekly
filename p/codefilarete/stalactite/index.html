基于 Java 方法引用的 fluent ORM，映射外置于 Bean，无字节码增强

综述（解读层）

Stalactite 是一个 Java ORM，通过 Fluent API 和方法引用定义 Bean 到数据库的映射，不依赖注解、XML 或 CGLib/AspectJ 字节码操作。项目分 SQL、Core、ORM 三层模块，提供 MariaDB/MySQL/PostgreSQL/HSQLDB/H2 适配器及 Spring 事务集成。适合希望持久化逻辑外置于领域模型、采用 Clean/Hexagonal 架构的 Java 项目。注意它不做懒加载，实体采用即时抓取。

  • 通过 Fluent API 与方法引用定义映射，不使用注解/XML，不对 Bean 做字节码增强
  • 分 SQL、Core、ORM 三层模块，含 JDBC 语句构建器与实体关系管理
  • 提供 MariaDB、MySQL、PostgreSQL、HSQLDB、H2 适配器及 Spring 事务管理集成

适用场景（解读层）

  • 需要在 Clean/Hexagonal 架构中保持领域模型无持久化代码的 Java 项目
  • 希望避免 JPA merge/attach 状态与懒加载、采用即时抓取聚合的应用
  • 仅需 JDBC 语句构建辅助工具、不需要完整 ORM 的场景（使用 SQL 模块）
