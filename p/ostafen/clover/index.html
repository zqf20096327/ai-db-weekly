纯 Go 编写的轻量级嵌入式文档型 NoSQL 数据库

综述（解读层）

CloverDB 是一个以纯 Go 实现的嵌入式文档型 NoSQL 数据库，将数据以 JSON 文档形式存于无模式集合中，底层通过接口抽象支持 Badger 与 Bolt 两种键值存储（默认 Bolt）。项目明确以可维护性换取性能，不面向 MongoDB 类场景，适合不适合运行独立数据库进程、查询较简单的 Go 程序。要求 Go 1.18 及以上，以 MIT 协议开源。

  • 提供无模式集合存储 JSON 文档，每条文档由插入时生成的 Version 4 UUID（_id 字段）唯一标识
  • 提供流式查询 API，支持 Criteria 过滤、字段比较、And/Or 组合、排序、Skip/Limit 及按查询条件更新与删除
  • 存储层通过接口抽象，可运行于 Badger 或 Bolt 键值存储之上，并支持任意引擎下集合的 JSON 导入导出

适用场景（解读层）

  • 不适合部署独立数据库服务器的 Go 应用内的本地数据存储
  • 以简单条件查询为主、希望降低网络延迟开销的场景
  • 对数据库体积有约束或需要可替换键值存储引擎的嵌入式场景

CloverDB is a lightweight NoSQL database designed for being simple and easily maintainable, thanks to its small code base. It has been inspired by tinyDB.
