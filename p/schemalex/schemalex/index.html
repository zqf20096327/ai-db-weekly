比较两个 MySQL schema 生成迁移 SQL 差异的 Go 工具

综述（解读层）

schemalex 是一个 Go 编写的命令行工具与库，用于比较两个 MySQL schema，生成从旧结构迁移到新结构所需的 SQL 语句。输入可以是本地 SQL 文件，也支持 URI 格式来源，例如对比本地文件与在线 schema、git 仓库中的不同版本。采用 MIT 许可证，也可作为 Go 库嵌入使用。

  • 读取两个 MySQL schema 并生成迁移所需的 SQL 语句
  • 支持以 URI 形式指定比较来源，包括本地文件、在线 schema 及 git 仓库中的版本
  • 提供命令行工具和 Go 库两种使用方式

适用场景（解读层）

  • 在 schema 变更前后生成迁移 SQL 语句
  • 对比 git 仓库中不同提交版本的数据库 schema
  • 在 Go 程序中通过库调用实现 schema 差异生成
