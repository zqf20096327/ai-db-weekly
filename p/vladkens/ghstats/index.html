自托管 GitHub 流量分析工具，定时抓取 API 数据存入 SQLite

综述（解读层）

ghstats 是一个自托管的 GitHub 仓库流量分析服务。GitHub 仅保留 14 天流量数据，它每小时通过 GitHub API 拉取 views、clones、stars、forks、issues、PR 等指标并存入本地 SQLite，提供 Web 仪表盘、SVG 徽章与卡片、JSON API。适用于个人项目、开源作品集或组织统计页面。部署为单个 Rust 二进制或 Docker 镜像，需配置 GitHub Token；采集范围默认限可访问的公开仓库。

  • 定时（默认每小时，可经 GHS_CRON_SCHEDULE 调整）从 GitHub API 拉取仓库指标，按天存入本地 SQLite，保留长期历史
  • 提供仓库仪表盘、SVG 徽章与卡片、受 x-api-token 保护的 JSON API（/api/repos、/health 等）
  • 单 Docker 镜像部署，前端依赖内嵌于二进制，运行时不请求 CDN；支持按 owner、fork、archived 等条件过滤仓库及私有仓库采集

适用场景（解读层）

  • 为个人项目或开源作品集保留超过 GitHub 14 天限制的流量历史
  • 搭建组织或公开的仓库统计页面，通过徽章和卡片嵌入个人站点
  • 在私有部署中通过 API 或仪表盘查看仓库 views/clones/stars 等趋势数据
