🧭 简介解读层（AI·证据行可回查）

本地优先的推理前上下文编译器，将仓库历史编译为缓存稳定的上下文包

综述（解读层）

memory.cpp 是一个面向开发者与编码代理的本地上下文编译工具，用 Rust 编写。它在推理前处理仓库历史（决策、修复、测试、规则、代理工作记录），生成带来源锚点与新鲜度证明的上下文包：稳定前缀做 blake3 哈希以复用提示缓存，负面记忆用于排除过时内容与机密，账本与 lockfile 使发送内容可复现审计。数据存于本地 SQLite，默认无网络调用。README 的基准数字来自合成语料，真实运行数据需另行测量。

  • 提供 MemoryIR 中间表示，为每条记忆标注来源锚点、信任度、新鲜度、敏感性与缓存角色
  • 支持稳定前缀与新鲜后缀分离、负面记忆排除、新鲜度证明、可复现账本与 lockfile
  • 提供 CAMC-Bench 基准、kv-sim 估算、MCP 只读资源暴露及面向 claude/codex/cursor 等的 provider 包

适用场景（解读层）

  • 为长周期编码代理构建可审计、可复现的上下文包，避免过期文档与失败尝试进入提示
  • 需要提高提示缓存前缀复用的 CLI 工作流
  • 本地化、无云依赖的代理记忆管理，含机密脱敏与写入防火墙
