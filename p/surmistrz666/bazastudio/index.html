🧭 简介解读层（AI·证据行可回查）

Rust 编写的 Windows/macOS 原生桌面数据库客户端，支持 SQL 与 NoSQL 多引擎连接。

综述（解读层）

Baza Studio 是一款面向 Windows 和 macOS 的原生桌面数据库客户端，用于连接关系型、分析型、键值/文档型数据库及搜索引擎等十余类产品。它以 Rust 编写，用 egui 和 wgpu 自绘窗口，不含 Electron 或浏览器引擎，提供 SQL 编辑器、表格数据编辑、表设计器、查询构建器、SSH 隧道和本地加密凭据库。当前为 0.4.0 预览版，采用 GPL-3.0-or-later 许可，可下载预览包或从源码构建（需 Rust 1.99.0）。

  • 支持 PostgreSQL、MySQL、SQLite、SQL Server、Oracle、ClickHouse、DuckDB、Redis、MongoDB、Cassandra、DynamoDB、Elasticsearch/OpenSearch 等数据库家族，部分引擎已对照真实服务器验证
  • 提供 SQL 编辑器、结果网格、表格数据就地编辑、表设计器、查询构建器、查询历史、CSV/JSON 导入导出，以及每连接内置的 SSH 隧道与 TLS
  • 连接配置与密码存储于 AES-256-GCM 加密的本地库（密钥由 Windows DPAPI 或 macOS 钥匙串保护），可选本地密码与 TOTP 应用锁

适用场景（解读层）

  • 在 Windows 或 macOS 桌面上连接并管理多种数据库引擎，浏览表结构、过滤分页浏览数据并就地修改单元格
  • 通过内置 SSH 隧道和 TLS 访问远程数据库，凭据保存在本地加密库中
  • 从源码构建或下载预览包使用，配合 --self-test、BazaQa 等测试模式检查引擎与界面构建
