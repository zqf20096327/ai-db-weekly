🧭 简介解读层（AI·证据行可回查）

自托管的 Webhook 请求检查工具，以单二进制加 SQLite 存储

综述（解读层）

Webhix 是一个自托管 Webhook 检查工具，用 Go 编写，编译为单个二进制文件并以 SQLite 存储数据。它捕获发往 `/r/<token>` 端点的任意 HTTP 请求（头、体、查询参数等），支持 SSE 实时界面、一键重放、自定义响应、CLI 转发到 localhost 及 curl 导出。适合需要在本地环境检查 Webhook 请求的开发者；界面默认公开，需通过可选的 Basic Auth 保护。

  • 捕获任意 HTTP 方法的请求，包含 headers、body、query 参数、IP、时间戳、content type 与大小，存储于 SQLite
  • 通过 SSE 实时更新界面，支持一键重放请求、配置自定义响应（状态码、headers、body）以及 CLI 转发到本地端口（webhix forward --to localhost:3000）
  • 单二进制部署，UI 经 go:embed 内嵌，支持 Docker/Compose 运行，跨 Linux/macOS/Windows 的 amd64+arm64，支持 Basic Auth 与反向代理（自动读取 X-Forwarded-* 头）

适用场景（解读层）

  • 在自有基础设施上捕获并查看 Stripe、GitHub 等第三方服务发来的 Webhook 请求内容，用于调试集成
  • 在本地开发中将公网 Webhook 请求转发到 localhost 服务（webhix forward），无需外部隧道服务
  • 用自定义响应功能充当轻量 mock 服务器，向调用方返回预设的状态码、headers 与 body
