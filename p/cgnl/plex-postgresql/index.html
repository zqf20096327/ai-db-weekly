🧭 简介解读层（AI·证据行可回查）

通过 Rust shim 层拦截 Plex 的 SQLite 调用并转交 PostgreSQL，无需修改 Plex 源码

综述（解读层）

这是一个小型 shim 库，用于将 Plex Media Server 的数据库后端从 SQLite 替换为 PostgreSQL：它拦截 SQLite 调用并转发至 PostgreSQL。面向使用 Docker、Linux 或 macOS 部署 Plex 的用户。shim 以纯 Rust 实现，提供 SQLite 到 PostgreSQL 及反向的迁移脚本和 schema 检查工具。要求 PostgreSQL 的 max_connections 不低于 200；Plex 版本更新后需重新安装 shim。

  • 提供迁移脚本，支持 SQLite 到 PostgreSQL 及反向（beta）迁移，doctor.sh 可检查并修复缺失的表、函数、触发器及常见数据问题
  • 支持 Linux x86_64/ARM64、macOS ARM64 原生安装及 x86_64 + ARM64 多架构 Docker 镜像（LinuxServer 与 PlexInc 两种镜像）
  • 通过环境变量配置 PostgreSQL 连接，支持 TCP 或 Unix socket 方式

适用场景（解读层）

  • 已有多库 Plex 用户希望将 SQLite 数据迁移到 PostgreSQL
  • 通过 Docker Compose 全新部署并将 Plex 库数据存于 PostgreSQL 的环境
  • 远程媒体场景（如 rclone 云存储挂载）下的 Plex 部署
