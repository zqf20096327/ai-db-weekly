🧭 简介解读层（AI·证据行可回查）

嵌入式的本地优先向量数据库引擎，结合 SQLite 持久化与 FAISS 检索。

综述（解读层）

ToucanDB 是一个以 Python 包形式运行的内嵌向量数据库，用于存储、索引和检索高维向量嵌入，面向语义搜索、RAG 和应用记忆场景。它以 SQLite 记录为权威数据源，FAISS 索引可在崩溃后按代数校验重建，无需独立数据库服务进程。要求 Python 3.10+，pip 安装，MIT 协议。注意它不是分布式服务，单进程独占数据库目录，且仍为 beta 状态。

  • 支持 cosine、内积、欧氏距离三种相似度，提供 flat 精确检索及 HNSW、IVF 近似索引
  • SQLite WAL 存储支持原子批量写入；带生成校验的 FAISS 快照，崩溃或跨架构恢复后可确定性重建
  • 内置无依赖的 RAG 管线（分块、命名空间隔离、来源归因），并提供 Sentence Transformers、OpenAI 及自定义 callable 嵌入适配器；可选基于每库盐值与内存困难密钥派生的加密

适用场景（解读层）

  • 单个 Python 应用持有本地数据的场景，如桌面工具、本地 agent、私有 RAG、评估管线
  • 作为应用进程内的嵌入组件使用，避免部署独立数据库服务
  • 需要可选载荷加密与离线语义检索的本地数据存储场景
