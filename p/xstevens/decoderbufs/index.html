将 PostgreSQL 逻辑解码 WAL 变更以 Protocol Buffers 格式输出的插件

综述（解读层）

decoderbufs 是一个 PostgreSQL 逻辑解码输出插件，用 C 编写，将 WAL 变更数据编码为 Protocol Buffers 格式，供外部逻辑复制客户端消费。需 PostgreSQL 9.4+、PostGIS、Protocol Buffers 3.x 与 protobuf-c 1.2.x，通过 make 安装并在 postgresql.conf 启用逻辑复制后以复制槽方式使用。README 标明该项目已停止维护，作者建议关注 Debezium 的 fork。

  • 以 Protocol Buffers 格式输出 PostgreSQL 逻辑解码的 WAL 变更
  • 支持内置类型及 PostGIS geometry/geography 到 protobuf 字段的映射，并含 debug-mode 供 SQL 控制台查看变更
  • 通过 pg_create_logical_replication_slot 创建复制槽，配合 pg_logical_slot_get_changes/peek_changes 使用

适用场景（解读层）

  • 需要以 Protocol Buffers 二进制格式消费 PostgreSQL WAL 变更的 CDC 数据管道
  • 配合 PostGIS 空间数据表的逻辑复制场景
  • 需要通过 SQL 控制台以 debug 模式查看 WAL 变更内容的调试场景
