Aqua 开源的云安全态势扫描工具，检测多云账号配置风险

综述（解读层）

CloudSploit 是 Aqua 开源的云安全态势扫描工具，用于检测云基础设施账号中的配置错误与安全风险，支持 AWS、Azure、GCP、OCI 及 GitHub，可由运维或安全团队以只读凭据自托管运行。工作分采集与扫描两阶段；凭据可经配置文件或环境变量传入，提供 Docker 部署方式，并支持 HIPAA、PCI、CIS 等合规映射输出。

  • 支持 AWS、Azure、GCP、OCI 等多云账号扫描，仅需只读权限，凭据可通过 JSON 文件或环境变量传入
  • 支持 HIPAA、PCI、CIS（Level 1/2）合规策略映射，结果可输出为 CSV、JSON、JUnit XML 及 --collection 原始数据
  • 支持 --exit-code 用于 CI/CD、按 pluginId:region:resourceId 抑制结果、--plugin 运行单个插件，架构分 collection 与 scanning 两阶段

适用场景（解读层）

  • 对多云账号做周期性安全配置审计，识别潜在配置错误与风险
  • 在 CI/CD 流水线中以非零退出码拦截未通过扫描的部署
  • 按 HIPAA/PCI/CIS 基准生成合规映射报告供审计使用
