基于内嵌 SQLite 的命令行 ETL 工具，用 SQL 查询多种数据源

综述（解读层）

xyr 是一个命令行数据查询工具，用户在 XYRCONFIG 中以 HCL 定义表结构后，通过 table:import 将本地 JSON 目录、S3 或 MySQL、PostgreSQL 等数据源导入内嵌 SQLite 存储，再用 xyr exec 执行 SQL 查询并默认输出 JSON 结果。适合需要将异构数据文件转成可 SQL 查询形式的开发者。

  • 支持 jsondir、s3jsondir、mysql、postgres、sqlite3、sqlserver、hana、clickhouse、oracle 九种驱动
  • 可递归加载目录中多种 JSON 格式（对象、数组、换行分隔、无分隔），并将多张表在同一查询中 JOIN
  • 内部使用 SQLite 作为嵌入式数据存储，查询结果默认以 JSON 输出

适用场景（解读层）

  • 将本地或 S3 上的 JSON 文件目录导入为 SQL 表进行查询
  • 通过统一 SQL 接口读取 MySQL、PostgreSQL、SQL Server 等多种数据库的数据
  • 把 JSON 文档集合转换为 SQLite 形式的 SQL 数据库
🔌 适配哪些库db_scan 程序判定

ClickHouse、MySQL、Oracle、PostgreSQL、SQL Server、SQLite
