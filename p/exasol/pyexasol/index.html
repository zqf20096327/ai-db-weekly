Exasol 官方支持的 Python 连接器，基于 WebSocket 协议

综述（解读层）

PyExasol 是 Exasol 官方支持的 Python 连接器，用于处理该数据库常见的大规模数据量场景。它基于 WebSocket 协议，通过 HTTP 传输与 pandas、parquet、polars 集成，并提供基于多进程的并行多数据流读写 API。要求 Exasol >= 8、Python >= 3.11，可通过 PyPI 或 Anaconda 安装。

  • 基于 WebSocket 协议，提供压缩选项以减少网络瓶颈
  • 通过 HTTP 传输与 pandas、parquet、polars 集成
  • 提供使用独立进程并行读写多个数据流的 API

适用场景（解读层）

  • 在 Python 进程中读写 Exasol 数据库
  • 使用 pandas、parquet 或 polars 处理 Exasol 中的数据
  • 通过多进程并行数据流传输处理大批量数据
📖 README 首段存档原文 · 程序抽取

PyExasol is the officially supported Python connector for Exasol. It helps to handle massive volumes of data commonly associated with this DBMS.
