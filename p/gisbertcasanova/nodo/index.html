面向单台自托管服务器的私有运维面板，仅经 WireGuard VPN 访问

综述（解读层）

NODO 是一个用 Go 与 Svelte 编写、以 SQLite 存储的开源（MIT）运维面板，整合监控、告警、容器管理、备份状态与安全信息。面向管理单台 VPS 的单人运维者，要求以 wg-easy 方式访问，不对外暴露端口；含 18 条告警规则、每分钟指标采集与审计日志，不支持多服务器或多用户。

  • 提供主机与容器监控（CPU/内存/磁盘/uptime，逐分钟保存 7 天、逐小时一年）、18 条告警规则及邮件/Telegram 通知
  • 提供容器启停操作、crontab 任务管理、备份状态检查、fail2ban 管理与 Docker 磁盘清理功能
  • 面板以单 Go 二进制嵌入 Svelte 应用、无发布端口运行，仅绑定 WireGuard 网关；TLS 经 Cloudflare DNS-01 获取，支持 TOTP、passkey 与仅追加审计日志

适用场景（解读层）

  • 单人管理一台运行数十个 Docker 容器的 VPS，希望从手机查看健康状态并执行常见修复操作
  • 要求管理面板不暴露公网、仅通过 WireGuard VPN 访问的自托管环境
  • 需要整合 uptime 检查、备份文件状态、SSH 登录记录与 crontab 任务到单一界面的 homelab 场景
