基于 AST 解析的 PostgreSQL 查询逻辑可视化工具

综述（解读层）

actuallyEXPLAIN 将粘贴的 PostgreSQL SQL 解析为 AST，再转换为节点/边图与词典化说明，用于理解查询的逻辑意图，无需连接数据库。面向全栈开发者、独立开发者及使用 AI 生成 SQL 的用户，适合在生产运行前核对代码行为。基于 React 19 + TypeScript + Vite 构建，使用 Monaco Editor、React Flow 与 pgsql-ast-parser。当前仅映射逻辑意图，尚未包含执行计划分析或反模式警告功能。

  • 将 SQL 解析为 AST 并生成 React Flow 节点/边图，布局由 dagre 计算，支持递归/CTE 引用的自定义边
  • 纯前端解析，不要求连接数据库，SQL 输入使用 Monaco Editor
  • 以 MIT 许可开源，技术栈为 React 19 + TypeScript + Vite，样式使用 CSS Modules

适用场景（解读层）

  • 在生产环境执行前核对复杂 SQL 查询的实际逻辑
  • 检查 AI 生成的 SQL 代码做了什么
  • 无需数据库连接即可阅读和理解查询结构
