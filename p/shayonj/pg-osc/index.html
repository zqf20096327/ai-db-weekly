PostgreSQL 零停机在线表结构变更 CLI 工具，基于影子表机制

综述（解读层）

pg-osc 是一个 Ruby 编写的命令行工具，用于在 PostgreSQL 表上执行 ALTER 语句及数据回填。它通过创建结构相同的影子表、在其上执行变更并复制数据，同时用触发器经审计表记录主表增量变更，最后交换表名完成切换。适用于需要对生产表做结构变更的 PostgreSQL 使用者。要求表有主键，不支持分区表，操作期间需两次短暂获取 ACCESS EXCLUSIVE 锁，且需要足够磁盘空间存放副本表。

  • 通过影子表加触发器审计表机制执行 ALTER 变更，变更期间仅短暂持有 ACCESS EXCLUSIVE 锁
  • 支持在数据复制时通过自定义 SQL 的 copy-statement 执行列回填，并可调优审计表重放批次参数
  • 复制索引与外键，外键以 NOT VALID 方式重建后运行 VALIDATE CONSTRAINT，最后可选删除旧表并执行 ANALYZE

适用场景（解读层）

  • 对生产环境的 PostgreSQL 大表执行加列、删列、重命名列等 ALTER 操作
  • 在复制数据的同时回填新列数据（通过自定义 copy SQL）
  • 重建表以减少表膨胀
