🧭 简介解读层（AI·证据行可回查）

针对 Debezium CDC 管道三份 Schema 一致性的静态 Lint 工具

综述（解读层）

cdclint 是一个命令行 Linter，读取 Postgres/MySQL 迁移脚本、Debezium 连接器 JSON 与下游 Sink（ClickHouse、BigQuery、Snowflake、Iceberg）的 Schema 文件，构建统一模型并运行规则检查两者之间的不一致，发现问题时以非零退出码使 PR 失败并给出修复建议。当前为 v0.5，包含 11 条规则，仅读取文件、不连接运行中的系统，支持 --disable 与 cdclint:ignore。

  • 静态读取迁移 SQL、连接器 JSON 和 Sink Schema 三类文件进行规则检查，不连接任何运行中的系统
  • 提供 11 条规则，覆盖 column.include.list 遗漏、topic 映射、Flatten 变换、物化视图列匹配、replica identity 等，发现时输出文件、列、规则与修复建议
  • 可通过 --disable 关闭规则、用 cdclint:ignore 在行内记录决策，并可集成到 GitHub Marketplace

适用场景（解读层）

  • 在修改迁移脚本、Debezium 连接器配置或 Sink Schema 的拉取请求中运行检查，使配置不一致在合并前暴露
  • 排查下游列全为默认值（0、空串、NULL）或新列未出现在 Sink 的 CDC 管道问题
  • CI 中配合 --base 检查新增列是否被有意或无意地排除在捕获范围之外
