基于 Go/Wails 的本地桌面主机存活监控工具，数据存于本机 SQLite

综述（解读层）

PingPulse 是一个桌面端主机监控应用，对配置的 IP 或主机名按计划执行 ICMP、HTTP 或 TCP 探测，结果存储在本地 SQLite（WAL 模式）中，支持事件报告、SLA 统计和通过桌面通知、Telegram、Webhook 等渠道告警。适用于需要监视自管服务器的个人用户。安装方面提供 Windows、macOS、Linux 安装包；当前构建未签名，macOS 首次启动需在系统设置中手动放行。

  • 支持 ICMP、HTTP、TCP 三种探测类型，可配置间隔、超时、重试及失败/恢复阈值
  • 包含事件（Incident）记录、停机/MTTR 报告与 99–99.99% SLA 报表，可导出 CSV/JSON
  • 支持维护窗口、全局与按目标静音、SQLite 备份恢复及 GitHub Releases 应用内更新

适用场景（解读层）

  • 自管服务器或家庭主机 owner 希望在本机本地监测主机离线与恢复
  • 需要按目标与组安排维护窗口并在窗口期抑制告警
  • 需要将探测历史、事件与 SLA 数据导出为 CSV/JSON 做进一步分析
