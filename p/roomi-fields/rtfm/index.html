🧭 简介解读层（AI·证据行可回查）

本地开源检索层，为 AI 编码代理索引多格式内容并通过 MCP 提供检索。

综述（解读层）

RTFM 是一个面向 AI 编码代理的本地检索层，将项目中的代码、文档、PDF、法律文本、研究资料等索引进单个 SQLite 文件，支持全文（FTS5）、语义与混合检索，并生成知识图谱，通过 MCP 工具（如 rtfm_search、rtfm_expand）供代理渐进式获取上下文。安装方式包括 Claude Code 插件或 pip install rtfm-ai 后运行 rtfm init；语义检索和 PDF 解析为可选组件，按需安装到隔离 venv。支持 Obsidian 仓库模式和跨项目 memory 文件索引，采用 MIT 许可。

  • 提供 24 种格式解析器（含 EPUB、DOCX、ODT、MIDI、音频），支持代码 AST 级索引与文档标题解析
  • 实现 FTS5 全文检索、可选的 FastEmbed ONNX 语义检索及混合检索，并将 wikilink 等文件级关系存为知识图谱边
  • 支持 MCP 协议接入，通过 rtfm_search 返回带分数排名的元数据，配合 rtfm_expand 按需展开段落；memory 文件提供无上限版本历史快照

适用场景（解读层）

  • 在包含代码、规范、PDF、法规等混合内容的项目中，为 Claude Code 等 MCP 客户端代理提供检索工具
  • 对 Obsidian 研究笔记仓库运行 rtfm vault，生成索引、Mermaid 图谱与孤岛/断链导航文件
  • 对 ~/.claude/projects 下的 memory 文件建立跨项目索引，配合 SessionEnd 钩子自动快照并查询历史版本
