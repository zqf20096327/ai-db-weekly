基于 .NET 与 Avalonia 的开源 PostgreSQL 图形客户端

综述（解读层）

pgNimbus 是一个用 .NET 与 Avalonia 构建、以 NativeAOT 编译发布的 PostgreSQL GUI 客户端，MIT 协议开源，面向需要频繁查询、排查锁与检查迁移结果的开发者与 DBA。支持 SSH 隧道、TLS 校验、生产环境默认关闭写入的安全模式、EXPLAIN 计划树与对比、通过 pg_dump/pg_restore 备份恢复。Windows 为正式支持平台，macOS 与 Linux 版本标注为 beta，macOS 版未公证。

  • 基于 NativeAOT 编译，提供 Windows（含 Arm64）、macOS（Apple Silicon）与 Linux（x64/arm64）构建
  • 提供 SQL 编辑、流式结果网格、安全模式事务性编辑、EXPLAIN 计划树与 Query Lab 计划对比
  • 支持 SSH 隧道、TLS 证书校验、只读配置与 pg_dump/pg_restore 备份恢复

适用场景（解读层）

  • 需要快速连接查看行数据、排查锁与服务器活动
  • 通过 Query Lab 对比 EXPLAIN 计划以分析索引或查询调整
  • 通过图形界面安全地编辑生产数据或执行备份恢复

On screen in about 0.2 s. Results stream while the query runs. No telemetry, no account, no cloud. Free and open source, from the same family as kubeNimbus.
