pgNimbus 是基于 .NET 与 Avalonia 的开源 PostgreSQL 图形客户端，NativeAOT 编译

综述（解读层）

pgNimbus 是一个用 .NET 与 Avalonia 编写、以 NativeAOT 编译发布的 PostgreSQL 图形客户端，面向需要频繁连接数据库查看数据、执行迁移检查、排查锁与慢查询的开发者和 DBA。它提供 SQL 编辑器、流式结果网格、安全模式编辑、EXPLAIN 树视图、pg_dump/pg_restore 备份恢复、SSH 隧道与 TLS 连接等能力。无遥测、无账号、无云服务，Windows 支持最完整，macOS 与 Linux 为 beta 版本

  • 采用 NativeAOT 编译发布，README 记载启动至窗口显示约 0.2 秒，查询结果可在执行过程中流式显示，Esc 可中途停止查询
  • 提供安全模式数据编辑：变更暂存为 SQL 审阅后以单事务提交，提交时在锁下重读各行，冲突则整批回滚
  • 内置 PostgreSQL 运维工具：EXPLAIN 计划树与 Query Lab 计划对比、锁阻塞树、pg_stat_statements 慢查询、pg_dump/pg_restore 备份恢复、基于 has_*_privilege() 的角色权限查询

适用场景（解读层）

  • 开发者日常快速查看行数据、核实迁移结果、定位持锁会话等短时数据库操作
  • DBA 通过活动监控、阻塞树、慢查询排行与数据库概览进行服务器巡检与排查
  • 使用 Query Lab 保存并对比 EXPLAIN 计划，如建索引前后的性能变化分析
