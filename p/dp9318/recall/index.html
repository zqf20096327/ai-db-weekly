面向 AI 编码代理的本地持久化记忆引擎，基于 MCP 提供上下文检索

综述（解读层）

RECALL 是一个为 AI 编码代理提供持久化项目记忆的本地服务，以 SQLite 为权威存储、ChromaDB 为语义索引，通过 FastMCP stdio 服务器和 REST API 对接 Cursor、Claude Desktop 等代理工具。它按层级权威规则仲裁记忆冲突，记录记忆谱系并支持压缩。仅支持 Windows 10/11 与 Python 3.11/3.12，通过发行包 setup.bat 安装。

  • 提供 9 个 MCP 工具，覆盖搜索、保存、上下文组装、压缩及自定义指令增删改查
  • 混合结构化 SQL 检索与 ChromaDB 语义向量检索，记忆存储于 ~/.recall/recall.sqlite3
  • 包含 React 构建的 Web Dashboard，用于查看记忆、管理指令和审计冲突仲裁

适用场景（解读层）

  • 为跨会话的 AI 编码代理保留架构决策、项目约定与自定义指令
  • 在多个代理工具（Cursor、Claude Desktop、OpenCode 等）间共享项目上下文
  • 需要可审计的记忆谱系与冲突仲裁记录的团队开发流程
