🧭 简介解读层（AI·证据行可回查）

把十个编程渠道封装为 OpenAI/Anthropic 兼容 API 的凭证池网关

综述（解读层）

Coding2API 将 CodeBuddy（国内/国际）、TRAE SOLO、OpenCode Zen、Kilo、Qoder、CodeArts、OfficeAce、小浣熊、灵犀等渠道封装为 OpenAI / Responses / Anthropic 兼容接口，供团队通过公共凭证池统一调用。调度按健康度与到期额度选号，支持会话粘性、按人用量统计与月度账单；数据存 SQLite，Python 3.12+/uv 或 Docker 部署。README 注明为逆向接口，未做安全审计，仅供学习研究，公网部署需反向代理与鉴权。

  • 提供 /v1/chat/completions（流式/非流式）、/v1/responses、/v1/messages、/v1/models 与 /v1/user/balance 接口，模型@渠道写法可强制指定上游
  • 凭证池支持设备码登录、多账号切换、额度探测、每日签到与 token 预刷新，凭证加密入库；模型列表只列出有可用凭证的渠道
  • 包含 admin/operator/viewer 三角色体系、审计日志、月度账单 CSV/JSONL 导出、按人/渠道/模型/凭证的用量统计（不存对话内容）

适用场景（解读层）

  • 团队内部搭建统一的模型 API 网关，用 sk-... Key 接入任意 OpenAI 兼容客户端（含 Codex CLI、Claude Code）
  • 需要多人共用凭证池并按人统计用量、生成月度账单的小型团队
  • 本地或 VPS 上以 Docker/Caddy 部署，用于学习研究各渠道的接口封装与调度机制
