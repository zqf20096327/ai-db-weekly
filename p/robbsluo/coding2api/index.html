🧭 简介解读层（AI·证据行可回查）

把十个编码渠道凭证池化并封装为 OpenAI/Anthropic 兼容 API 的网关

综述（解读层）

该项目将 CodeBuddy（国内/国际）、TRAE SOLO、OpenCode Zen、Kilo、Qoder、CodeArts、OfficeAce、小浣熊、灵犀等渠道封装为 OpenAI / Responses / Anthropic / Gemini 兼容接口。核心机制包括公共凭证池、健康度调度、会话粘性与到期额度优先策略。基于 FastAPI 与 SQLite 构建，支持 uv 或 Docker 部署，提供 admin/operator/viewer 三角色管理与审计日志。README 声明其为逆向接口，仅供学习研究，未做安全审计，公网部署需自行配置鉴权。

  • 提供 /v1/chat/completions、/v1/responses、/v1/messages、Gemini generateContent 等多协议出口，支持流式与非流式
  • 实现公共凭证池与健康度调度，支持 模型@渠道 强制指定、多轮对话凭证粘性与到期额度优先
  • 包含三角色权限体系、审计日志、按人用量统计、月度账单导出与 Prometheus /metrics

适用场景（解读层）

  • 用统一的 OpenAI 兼容客户端访问多个编码渠道的模型
  • 团队内共享凭证池并按人统计用量与成本
  • 本地或内网部署用于学习研究上游接口协议
