基于 Effect 的关系型数据库操作工具集，含驱动封装、Schema 声明与查询构建器

综述（解读层）

effect-sql 是一套面向 Effect 生态的关系型数据库工具集合，由多个可独立选用的模块组成：query 提供对 Node 数据库驱动的 Effect 化封装，schema 提供基于 Drizzle 的 TypeScript Schema 声明并可推导 Kysely 数据库类型，builders 提供基于 Kysely/Drizzle 的类型安全查询构建器。README 首行声明该项目已停止维护，建议改用官方 @effect/sql 包。适用对象为使用 Effect 与 TypeScript 的开发者。

  • query 模块提供基于 Effect Pool 的连接池 Layer、带 tagged error 的查询操作符，以及基于 savepoint 的嵌套事务 DSL
  • schema 模块支持 TypeScript-first 的 Schema 声明，并可通过 effect-sql/schema/kysely 推导 Kysely 数据库类型
  • builders 模块提供 Kysely 与 Drizzle 两种查询构建器，构建于 effect-sql/query 之上

适用场景（解读层）

  • 在 Effect 应用中以 Effectful 接口执行原生 SQL 并管理连接池
  • 需要声明式 Schema 并生成类型安全查询的项目
  • 需要嵌套事务（savepoint）的场景
