🧭 简介解读层（AI·证据行可回查）

生成合成产品分析事件数据与隐藏基准真值，用于测试 Agent 的信号发现能力

综述（解读层）

dryfit 是一个 Python 数据生成工具：按 YAML 配置生成 PostHog 风格的合成事件数据写入 PostgreSQL 的 events 表，同时输出 ground_truth.json 与 manifest.json 作为隐藏基准真值，供测试 AI Agent 在信号发现任务上的表现。包含 15 个场景（posthog_web、telegram_chat 基线及 13 个商业模式变体），信号以事件序列代理实现。注意：项目已不在活跃开发中。

  • 提供 15 个场景配置，含两个基线（posthog_web、telegram_chat）与 13 个 PostHog 商业模式变体
  • 每次运行写入 PostgreSQL events 表并生成 ground_truth.json、manifest.json，真值文档引用实际生成的 event_id
  • 支持 --dry-run、--skip-db-write、--output-dir 等参数，并附带 Docker Compose 检查栈（PostgreSQL + Grafana 预置仪表盘）

适用场景（解读层）

  • 为评测 AI Agent 的产品信号发现任务生成可复现的合成数据集
  • 通过配置文件按商业模式（席位制、计量计费、交易量、存储、功能门控等）定制事件数据
  • 借助 Grafana 仪表盘可视化检查生成的事件数据
