SSMS 22 的开源扩展套件，集成架构浏览、格式化与监控面板

综述（解读层）

SQLExtended 是面向 SQL Server Management Studio 22 的免费开源 VSIX 扩展，提供架构浏览与搜索、基于 ScriptDom 的 T-SQL 格式化、IntelliSense 补全、四个实时监控面板、按文件夹导出架构以便 diff，以及结果网格工具。需要 Windows 与 .NET Framework 4.8；仅支持 SSMS 22，部分功能通过反射访问 SSMS 内部接口，官方无公开 API，SSMS 升级可能使相关路径失效。

  • 提供架构缓存驱动的对象浏览、SQL Search 全文搜索（基于 SQLite 索引）与 F12 打开定义
  • 包含基于 ScriptDom 的 T-SQL 格式化器，支持预设与单规则应用（大小写、分号、去括号等）
  • 提供 Performance、Agent Jobs、Always On、Replication 四个实时监控面板，仅实时显示不持久化

适用场景（解读层）

  • 需要在 SSMS 22 中搜索对象名、列与模块定义的数据库开发者
  • 需要将数据库架构导出为无时间戳的文件夹树以便工具对比的服务器管理员
  • 需要在多服务器多数据库上并行执行同一脚本并合并结果的运维团队（ScriptCast）
