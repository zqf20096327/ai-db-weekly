解析并比较两份 DDL（SQL 文件或语句）的 Python 工具

综述（解读层）

Sondesh 是一个 Python 编写的 DDL 解析与比较工具，当前版本 V-1.0.0 仅支持比较两个 .sql DDL 文件或两条 DDL 语句，可解析 SQL 文件，并提供 CLI 应用在终端显示差异。支持 Oracle、PostgreSQL、SparkSQL、Hive 等多种 SQL 方言，依赖 Python 3.8 及以上，支持 Windows 10、Debian、BSD 平台。

  • 支持解析多种 SQL 方言的 DDL 语句，包括 Oracle、PostgreSQL、SparkSQL、Hive 等
  • 提供 CLI 应用，在终端中比较两条 DDL 语句并显示差异
  • 可通过 pip 安装（pip install sondesh），支持从文件读取 DDL 并解析

适用场景（解读层）

  • 比较两个 .sql DDL 文件或两条 DDL 语句的差异
  • 解析 SQL 文件中的 DDL 语句并输出结构化结果
  • 在终端中快速查看两条 DDL 语句的不同之处
