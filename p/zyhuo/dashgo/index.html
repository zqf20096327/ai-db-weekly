基于 Go + Vue 3、底层 sing-box 的自托管代理面板管理系统

综述（解读层）

dashGO 是一个自托管代理面板，用于在 Linux VPS 上管理代理节点、用户和流量统计。后端为 Go（Gin + GORM + Redis），前端为 Vue 3，底层使用 sing-box。部署依赖 Docker Compose，提供 install.sh 一键脚本，支持 SQLite（默认，不支持 linux arm64）或 MySQL 数据库，采用 MIT 许可证。

  • 支持 SQLite（默认）和 MySQL 两种数据库，可切换
  • 提供 JWT 认证、HTTPS 配置和实时流量统计
  • 通过 install.sh 脚本或 Docker Compose 部署，支持 Cloudflare Origin Certificate、自签名或自有证书

适用场景（解读层）

  • 在自有 Linux VPS 上自托管代理面板，自行管理用户与节点数据
  • 通过 Docker Compose 快速部署代理面板并进行流量监控
  • 中小规模部署（README 提及 SQLite 适用 < 10,000 用户场景）
