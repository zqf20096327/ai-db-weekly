n8n 社区节点插件，用于在工作流中操作 OceanBase 数据库

综述（解读层）

n8n-nodes-oceanbase 是一个 n8n 社区节点插件，让用户在 n8n 工作流中连接并操作 OceanBase 数据库。它提供执行自定义 SQL、插入、更新、删除四类操作，通过配置主机、端口（默认 2883）、库名、用户名密码等凭据建立连接。要求 n8n 1.0+、Node.js 14+，支持 OceanBase 3.x/4.x；向量操作需 OceanBase 4.4+ 或支持向量的 SeekDB。适合需要在 n8n 自动化流程中读写 OceanBase 数据的用户。

  • 支持 Execute Query、Insert、Update、Delete 四种数据库操作
  • Execute Query 支持 ? 占位符与逗号分隔的查询参数
  • 凭据配置包含主机、端口、数据库、用户、密码及连接超时（默认 10000 毫秒）

适用场景（解读层）

  • 在 n8n 工作流中执行自定义 SQL 查询 OceanBase 数据
  • 在自动化流程中对 OceanBase 表执行插入、更新、删除
  • 对接兼容 MySQL 协议的 OceanBase 3.x/4.x 版本数据库
