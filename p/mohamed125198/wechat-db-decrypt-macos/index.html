macOS Apple 芯片上解密微信 SQLite 数据库的命令行工具

综述（解读层）

wechat-db-decrypt-macos 是一款在 macOS Apple 芯片（arm64）上运行的命令行工具，通过读取本机已安装微信 4.1.2.241 的内部密钥，将加密的 SQLite 数据库文件（如 MM.sqlite）解密为可读的 _decrypted.sqlite 文件。用户从 Releases 下载二进制文件后，在终端以「工具路径 + 数据库路径」的方式运行。仅支持该微信版本，不适用于 Intel Mac、Windows 或旧版微信数据库，解密后的数据需自行妥善保管。

  • 支持 Apple 芯片（M1/M2 及更新）的 macOS，无需模拟或额外软件
  • 利用本机安装的微信 4.1.2.241 内部密钥解密 SQLite 数据库文件
  • 输出标准 SQLite 文件，可用任意 SQLite 浏览工具打开

适用场景（解读层）

  • 读取本机微信数据库中受限访问的信息
  • 将解密后的 SQLite 文件导入数据库查看工具进行检索浏览
  • 在满足版本与架构条件的环境中对聊天记录数据库做本地存档
