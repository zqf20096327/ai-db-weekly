🧭 简介解读层（AI·证据行可回查）

面向 AI agent 的受治理双时态知识图谱存储，基于 RDF/SPARQL 与 SQLite

综述（解读层）

Quipu 是一个本地运行的知识图谱存储，使用 Rust 编写（crates.io 发布 quipu-ai）。它以 Turtle 格式写入事实，写入时校验词表与形状（SHACL/OWL），并通过事务保留可查询的历史版本。提供 CLI、REST、MCP 服务器和 Rust 库四种访问方式，支持 SPARQL 查询当前或指定事务的数据。适合需要在多个 agent 之间共享带出处和时间的结构化知识的开发者。

  • 支持 CLI、REST、MCP 与 Rust 库四种接口，CLI 本地运行，quipu-server 提供网络 API 与浏览器界面
  • 写入时依据自有词表和 shapes 校验事实，记录来源（provenance），保留双时态历史，可按事务号查询早期版本
  • 知识包附带 repository pendant、校验和与出处，导入时进入暂存区，ROOT 不变，冲突不静默合并

适用场景（解读层）

  • 为 Claude Code 等 MCP 客户端配置本地知识库，通过 quipu mcp --db 连接数据库
  • 集中存放项目事实、决策与关系，避免在多个 agent 会话中重复粘贴相同上下文
  • 通过 export/import 工作流在隔离环境中验证后再显式提升，共享受治理的知识包
