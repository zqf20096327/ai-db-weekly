Apache SedonaDB 空间 SQL 引擎的浏览器端 Wasm 构建

综述（解读层）

CereusDB 将基于 Apache DataFusion 与 Arrow 的 SedonaDB 空间 SQL 引擎编译为 WebAssembly，供浏览器内执行空间 SQL 查询。提供 minimal/standard/global/full 四档 npm 包，按需启用 GEOS、PROJ、S2、GDAL；空间连接目前限于单分区、内存内、顺序精化的受限运行模式。

  • 提供 minimal/standard/global/full 四档构建（压缩后 4.2–9.2 MB），分别启用 GEOS、PROJ、S2、GDAL 及栅格 SQL 能力
  • 支持空间关系连接、距离连接与 ST_KNN，并可用 registerFile/registerRemoteParquet 等注册 Parquet、GeoJSON、GeoTIFF 数据
  • 核心层提供 66 个标量加 3 个聚合函数，SQL 结果以 Arrow IPC 字节或 JSON 返回

适用场景（解读层）

  • 在浏览器端交互式执行空间 SQL 与 Playground 演示
  • 对上传或远程 Parquet/GeoJSON/GeoTIFF 数据进行客户端空间查询
  • 需要坐标参考转换或 S2 geography 计算的前端地理数据应用
