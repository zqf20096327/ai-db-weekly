SwellDB 是一个基于 LLM 动态生成表并用 SQL/DataFrame 查询的数据系统

综述（解读层）

SwellDB 是一个支持 SQL 分析查询的数据系统，其表在查询时由 LLM、现有数据库、CSV/Parquet 文件、网页搜索结果等来源按提示与模式实时合成，不依赖预加载的数据。面向需要混合结构化与非结构化数据做即席查询的开发者。安装方式为 pip install swelldb，运行示例需配置 OpenAI API Key，SQL 执行通过 DataFusion 实现，并可通过数据源 API 扩展新来源。

  • 支持从 LLM、数据库、CSV/Parquet、网页搜索结果等多种来源动态合成表
  • 支持用自然语言提示加模式注解声明式定义表，并用 SQL 或 DataFrame 查询
  • 提供结构化与非结构化数据源 API，可接入新的数据来源

适用场景（解读层）

  • 从非结构化来源生成表以填充关系型数据库（如 SQLite）
  • 跨本地 CSV、远程数据库、LLM 生成内容与网页结果进行混合查询
  • 无需预定义 ETL 流水线、按需生成特定主题的数据表
