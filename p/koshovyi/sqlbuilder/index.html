面向 .NET 的轻量 SQL 查询构建库，以链式 API 与特性注解生成 DML 语句。

综述（解读层）

SqlBuilder 是一个用于 .NET Core 的 SQL 语句生成库，通过链式 API 生成 SELECT、INSERT、UPDATE、DELETE 四类 DML 语句，支持 SQL Server、MySQL、PostgreSQL 等格式（如示例中的 Format.MsSQL）。它通过特性标注表名/列名/主外键并借助反射读取，仅生成参数化查询，也可嵌入原始 SQL 片段。适合需要在代码中拼接 SQL 并自行控制语句结构的 .NET 开发者。当前标注为 Beta 版本。

  • 支持 SELECT、INSERT、UPDATE、DELETE 四类标准 DML 语句的链式构建
  • 提供 TableName、Column、PrimaryKey、ForeignKey 等数据库特性，并通过反射方法读取表名、别名、主键与外键
  • 仅生成参数化查询以转义参数值，并支持查询模板与 LINQ 扩展（SqlBuilder.Linq）

适用场景（解读层）

  • 在 .NET 应用中以代码方式生成参数化的增删改查 SQL 语句
  • 基于实体类的特性标注自动生成对应表/列的 INSERT 或 UPDATE 语句
  • 与 Dapper 等数据访问组件配合，由开发者自行执行生成的 SQL 字符串
