🧭 简介解读层（AI·证据行可回查）

运行于 Docker 的容器化脚本，自动备份宿主机上所有 Docker 数据库容器

综述（解读层）

该项目以 Docker 容器形式运行，自动检测并备份同一宿主机上的 MySQL、MariaDB、PostgreSQL、Redis 等数据库容器，未识别的容器可通过标签指定。依赖挂载 Docker socket 或经 DOCKER_HOST 代理访问；备份按容器名存入挂载目录，默认不压缩、不加日期，每日零点执行，调度与压缩方式均由环境变量配置。

  • 支持 MySQL、MariaDB、PostgreSQL（含 TimescaleDB、pgvector 等）、Redis 等数据库容器，未识别容器可用 db-auto-backup 标签指定
  • 通过 SCHEDULE 环境变量配置 cron 调度，默认每日零点执行，置空可单次运行；支持 gzip/lzma/bz2/zstd 压缩选项
  • 备份成功后可向 SUCCESS_HOOK_URL 发送 GET/POST 通知，并兼容 healthchecks.io 与 Uptime Kuma 变量

适用场景（解读层）

  • 宿主机上运行多个 Docker 数据库容器、需要集中定时备份的环境
  • 搭配 ZFS 等快照/压缩文件系统的存储方案，或需自行选择压缩算法的场景
  • 配合 healthchecks.io、Uptime Kuma 等外部监控或调度器进行备份状态跟踪与触发
