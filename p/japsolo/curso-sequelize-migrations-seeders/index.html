Node + Express 下使用 Sequelize 编写模型、迁移与种子数据的教程指南

综述（解读层）

该项目是一份西班牙语教程，演示在 Node + Express 项目中通过 sequelize-cli 创建模型、迁移（migrations）和种子文件（seeders），并用 `db:migrate`、`db:seed:all` 等命令执行与回滚。内容涵盖 .sequelizerc 配置、up/down 方法结构及 SequelizeMeta 记录表；README 注明读者需具备 Node、Express 和 Sequelize 的中级知识，数据库为 MySQL。

  • 提供从 `sequelize init`、`model:generate` 到 `db:migrate` / `db:seed:all` 的完整命令流程示例
  • 说明 migration 与 seeder 文件的 up/down 结构，支持执行与撤销（含 undo:all 和指定文件回滚）
  • 介绍 .sequelizerc 配置、目录结构、config.js 环境配置及 SequelizeMeta 迁移记录机制

适用场景（解读层）

  • 在 Node + Express 项目中学习用 sequelize-cli 管理数据库表结构的创建与回滚
  • 为开发或演示数据库批量生成并填充测试数据（seeders）
  • 团队协作中统一各成员的数据库结构初始化流程
