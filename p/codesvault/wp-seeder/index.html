🧭 简介解读层（AI·证据行可回查）

WordPress 数据库填充工具，通过命令行生成并执行 Seeder 写入演示数据

综述（解读层）

WP Seeder 是一个面向 WordPress 插件开发的数据库填充工具。开发者通过 Composer 安装后，使用 wpseed new 命令在插件的 database/seeders 目录下生成 Seeder 类文件，配置表名、行数等属性后，执行 wpseed store 命令即可将数据写入数据库。工具内置 FakerPHP 支持，要求 PHP 7.4 及以上，且 seeders 目录需保持在指定位置不可移动。

  • 提供 wpseed new 与 wpseed store 两个命令行命令，用于生成 Seeder 类并执行数据写入
  • 内置 FakerPHP 支持，用于生成演示数据
  • 生成继承 WPSeeder 的类文件，通过 $table 和 $row 属性指定目标表与生成行数

适用场景（解读层）

  • 为 WordPress 插件开发过程中的数据表填充演示数据
  • 为多张不同的表批量生成对应 Seeder 并写入数据
