基于Python的Sqlite3助手类库，通过连贯操作实现数据库增删改查

综述（解读层）

SqliteHelper是一个封装Sqlite3的Python类库，以链式调用（table/where/order/field/data）执行建表、插入、查询、更新、删除。将单个SqliteHelper.py文件复制到项目目录即可import使用，支持文件数据库与内存数据库。字典条件会对key与表字段匹配过滤，create仅在表不存在时创建。适合在Python项目中需要简化Sqlite3操作代码的开发者。

  • 支持连贯（链式）操作方法where、data、field、order，执行方法create/add/find/findAll/save/delete须置于链尾
  • where支持字符串条件（直接拼接SQL）与字典条件（含=、<>、>、>=、<、<=、LIKE表达式及and/or/xonic关系参数，不存在的字段名会被过滤）
  • find支持返回单条、指定数量及按页查询（page参数），并内置count/max/min/avg/sum统计方法；Connect不传路径时在内存中创建数据库

适用场景（解读层）

  • Python项目中需要对Sqlite3数据库进行增删改查操作的场景
  • 使用字典条件处理来自网络的数据写入，过滤不存在的字段
  • 使用内存数据库存放无需持久保存的临时数据（注意内存释放后数据丢失）
📖 README 首段存档原文 · 程序抽取

SqliteHelper是一个基于Python和Sqlite3的助手类库，根据实际使用大大简化数据库增删改查的操作，助手类库采用连贯操作，使开发更加灵活速度进一步得到提高。
