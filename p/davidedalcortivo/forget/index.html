🧭 简介解读层（AI·证据行可回查）

基于 Dapper 的多数据库扩展层，按映射表生成类型安全的 CRUD SQL。

综述（解读层）

Forget 是构建在 Dapper 之上的 .NET 扩展层，面向需要在 MySQL、Oracle、PostgreSQL 和 SQL Server 上操作单表的开发者。它通过数据注解属性映射实体，提供 CRUD、筛选、排序、分页与批量 upsert，并按所用数据库引擎生成对应方言的 SQL。它不处理多表 join、变更跟踪或迁移，这类查询仍需直接使用 Dapper 或完整 ORM。

  • 提供类型安全的单行与多行 CRUD、筛选、排序、分页方法，覆盖 MySQL、Oracle、PostgreSQL、SQL Server 四种方言，各提供同步与异步重载
  • 支持编译期 LINQ 表达式筛选与运行时基于属性名的 FilterDescriptor/FilterGroup 动态筛选，二者生成相同 SQL
  • 多行写入在未传入事务时自动开启事务以保持原子性，批量大小可通过 batchSize 参数控制，默认 500

适用场景（解读层）

  • 在 .NET 项目中需要对单张映射表执行重复的 SELECT/INSERT/UPDATE/DELETE/MERGE 操作并希望由库生成 SQL 的场景
  • 筛选条件来自查询字符串或请求体、需在运行时按属性名动态组合过滤条件的搜索类接口
  • 需要对自然键（非自增列）做跨四种数据库统一 upsert 的场景
