🧭 简介解读层（AI·证据行可回查）

基于 TiKV 存储的 DynamoDB 兼容 HTTP 服务，实验性实现 DynamoDB API 子集

综述（解读层）

TiKronos 是一个独立运行的 Kotlin 应用（Ktor、Netty、Java 21），对外提供 DynamoDB 兼容的 HTTP API，底层由单独部署的 PD 和 TiKV 提供事务性持久化存储。项目处于实验阶段，仅实现 DynamoDB 的一个子集，未达到完整 API 对等。适合希望将现有 DynamoDB 客户端接入 TiKV 集群的开发者；使用持久数据前需阅读兼容性指南和运维升级要求。

  • 支持表管理、条目 CRUD、条件写入、Query、Scan、批量操作和二级索引
  • 支持 TTL 和 DynamoDB Streams（有文档化的兼容性限制）
  • 通过 Docker Compose 快速启动，API 仅暴露在回环地址，命名卷可保留数据

适用场景（解读层）

  • 将现有 DynamoDB 客户端接入已有 TiKV 集群进行表和条目读写
  • 在本地开发环境中用 Docker Compose 搭建 DynamoDB 兼容 API 做功能测试
  • 结合 quickstart 中的 Terraform locking 指引做基于 TiKV 的锁存储场景

A DynamoDB-compatible HTTP service backed by TiKV. Point your DynamoDB client at TiKronos; TiKV stores the tables and items and provides transactional persistence.
