基于达梦官方 JDBC JAR 的数据库 MCP Server，供 AI 编程工具调用

综述（解读层）

该项目实现达梦数据库的 MCP Server，通过 java-bridge 动态加载达梦官方 JDBC JAR，无需预装 Java 环境，面向使用 Claude Code、Cursor、VS Code Copilot、Windsurf 等 AI 编程工具的开发者。提供 13 个覆盖查询、DML、DDL、事务与诊断的工具，内置 readonly 到 admin 四级权限及 Schema 白名单、表黑名单等控制。使用前需自备达梦 JDBC 驱动 JAR，支持 npm 安装、配置文件或纯命令行参数接入。

  • 通过 java-bridge 动态加载达梦 JDBC JAR，stdio 传输兼容 MCP 协议客户端
  • 提供 13 个 MCP 工具，覆盖 SELECT、DML、DDL、元数据、事务与连接诊断
  • 内置四级权限模型及 allowedSchemas 白名单、blockedTables 黑名单、maxResultRows 行数限制

适用场景（解读层）

  • 在 AI 编程工具中通过自然语言查询和操作达梦数据库
  • 以 readonly 模式让 AI 助手仅执行查询与表结构分析
  • 通过 jdbcParams 设置 compatibleMode=mysql/oracle 等连接参数适配既有达梦实例
