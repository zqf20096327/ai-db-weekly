🧭 简介解读层（AI·证据行可回查）

基于线程池实现的 cx_Oracle 异步封装，供 asyncio 程序访问 Oracle 数据库。

综述（解读层）

cx_Oracle_async 是一个异步封装库，让 asyncio 程序能通过线程池方式调用 cx_Oracle 访问 Oracle 数据库。异步操作方式与 aiomysql 相近，但仅支持 cx_Oracle 的部分功能，且无内置日期格式转换。连接远程数据库需另行安装 Oracle Client。适用于需要在异步代码中使用 Oracle 的 Python 项目。

  • 提供基本 insert/select/delete 等 SQL 操作，异步用法与 aiomysql 相近
  • 包含 AQ（Advanced Queueing）功能，支持修改部分 cx_Oracle 连接属性
  • 基于 ThreadPoolExecutorPlus 线程池实现异步，依赖 cx_Oracle >= 8.1.0

适用场景（解读层）

  • 在 asyncio 程序中读写 Oracle 数据库
  • 通过 Oracle AQ 进行异步消息队列操作
  • 为原有同步 cx_Oracle 代码提供异步调用入口（需接受线程池开销）
