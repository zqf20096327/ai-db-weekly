🧭 简介解读层（AI·证据行可回查）

为 AI 编码助手提供持久化 SQLite 状态图记忆的 MCP 服务器

综述（解读层）

该项目是一个基于 Model Context Protocol 的服务器，在本地工作区的 SQLite 中维护任务、决策、阻塞项等节点及其语义关系的有向图，供 Cursor、Claude Code 等编码助手读写工作流状态。内存操作不调用 LLM，通过 13 个 MCP 工具完成查询与更新，数据全部存于工作区 .state-memory-mcp/ 目录。需要 Node.js >= 18.18.0，通过 npm 全局安装后以 CLI 启动。

  • 提供 13 个 MCP 工具，覆盖节点/边 CRUD、任务队列、FTS5 搜索、快照回滚、事件账本与诊断校验等功能
  • 记忆操作不经 LLM，直接执行 SQLite 图遍历，可提取压缩的 TaskSlice 上下文切片
  • 支持多智能体共享黑板、Git 分支合并、3D WebGL 图可视化（state-memory-mcp view）

适用场景（解读层）

  • 为 AI 编码助手跨会话持久保存任务、决策与阻塞项，避免重复传递上下文
  • 多子智能体并行协作时通过共享黑板发布任务与决策更新
  • 按 README 给出的 5 步工作流执行规格驱动开发（SDD）与依赖追踪
