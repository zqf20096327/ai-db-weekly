🧭 简介解读层（AI·证据行可回查）

为 Claude Code 提供跨会话记忆的插件，将记忆存于单个 .mv2 文件

综述（解读层）

该项目是一个 Claude Code 插件，用于在会话之间保存与检索上下文：会话中的决策、bug、解决方案等会被记录到项目内 .claude/mind.mv2 文件，并在新会话启动时自动注入。适合希望保留项目历史上下文的 Claude Code 用户。基于 memvid 单文件引擎，本地运行无需数据库、云服务或 API 密钥；重置只需删除该文件。

  • 将记忆保存为单个 .mv2 文件，可被 git commit、scp 传输或分享给他人
  • 会话启动时自动注入记忆，支持 search/ask/stats/recent 等命令
  • 提供可选的 npm CLI（memvid-cli），可对 .mv2 文件执行 stats/find/ask/timeline 操作

适用场景（解读层）

  • 在多次开发会话间保留项目决策、bug 与解决方案的上下文
  • 将 .mv2 文件交给队友，用于了解项目历史
  • 通过 CLI 直接检索或查询记忆文件内容
