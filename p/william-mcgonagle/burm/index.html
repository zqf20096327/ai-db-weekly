综述（解读层）

Burm 是一个运行于 Bun JavaScript 运行时的对象关系管理器，名称由 Bun 与 ORM 合并而来，采用 MIT 许可证，由 Fairfield Programming Association 维护。它支持在运行时创建模型、执行 CRUD 操作，以及用于测试的程序化数据生成。安装方式为通过 Bun 或 NPM 添加 burm 依赖。README 中列出的部分功能（如表间关系、中间件）仍处于计划阶段，尚未实现。

  • 提供模型定义与 CRUD 操作，模型可在运行时创建
  • 支持程序化数据生成，可用于测试
  • 无外部依赖，通过 bun add burm 或 npm i burm 安装

适用场景（解读层）

  • 在 Bun 运行时环境中进行数据建模与增删改查操作
  • 生成测试用程序化数据
  • 按 MIT 许可证集成到 JavaScript/TypeScript 项目中
