🧭 简介解读层（AI·证据行可回查）

基于华为云 DAS 管控面的 GaussDB 数据面 MCP 服务器，三层安全防护下执行 SQL。

综述（解读层）

该项目是一个 MCP 服务器，供 Dify、Claude Code 等 AI 客户端查询与操作华为云 GaussDB 业务数据。SQL 经 DAS 管控面 HTTPS 接口执行，无需数据库端口公网可达；提供 11 个工具，按 READ/WRITE/DANGEROUS 三通道分类，每次调用执行一条语句。对 Oracle 兼容（A）库的语法做了实测验证。许可证为 MIT。

  • SQL 经 DAS 管控面 HTTPS 接口执行，数据库端口零公网可达，部署位置只需能访问华为云管控面
  • 三层安全机制：SQL 白名单通道锁、只读/受限账号、凭证域分离（密码不进入执行链路），每次调用写 JSONL 审计
  • 提供 11 个工具覆盖只读查询、DML、DDL、执行计划、元数据浏览与 DAS 连接注册，含建库 verified 确认与会话失效自愈机制

适用场景（解读层）

  • AI 客户端（Dify、Claude Code 等）在本地或云上通过 MCP 查询与操作 GaussDB 业务数据
  • 对 Oracle 兼容（A/ORA）库执行 MERGE INTO、DUAL、MINUS、DECODE、NVL 等语句
  • 通过 streamable-http + Bearer token 部署为远程 MCP 服务并记录审计日志

GaussDB 数据面 MCP 服务：AI 客户端（Dify、Claude Code 等）通过它在三层安全防护下查询与操作 GaussDB 业务数据。连接走 DAS 传输轨——SQL 经数据管理服务（DAS）的管控面 HTTPS 接口执行，数据库端口零公网可达，MCP 可部署在任意能访问华为云管控面的位置（本地 / 云上均可，无需 VPC、专线或 EIP）。
