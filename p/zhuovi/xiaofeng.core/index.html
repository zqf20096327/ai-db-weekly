C# 公用核心类库，集成 JSON/XML 序列化、多数据库操作与加密等基础功能

综述（解读层）

XiaoFeng.Core 是一个以 NuGet 包分发的 C# 基础类库，通过 ADO.NET 封装支持 SQLSERVER、MYSQL、ORACLE、达梦、SQLITE 等数十种数据库，并包含 Json/Xml 序列化、HttpHelper 网络请求（提供 HttpClient/HttpWebRequest/HttpSocket 三种内核）、ConfigSet 配置管理、加密算法、线程调度等模块。安装方式为 dotnet add package XiaoFeng.Core，适用于需要在 .NET 项目中复用这些基础功能的开发者。

  • 数据库操作库 DataHelper 支持 SQLSERVER、MYSQL、ORACLE、达梦、SQLITE、ACCESS、OLEDB、ODBC 等数据库，提供执行 SQL、返回 DataTable/DataReader/DataSet 及执行存储过程等接口
  • HttpHelper 提供三种请求内核（HttpClient、HttpWebRequest、HttpSocket），支持 GET、POST 表单/BODY/FORMDATA 请求及文件下载
  • 包含 AES、DES、DES3、MD5、RSA、RC4、SHA 等加密算法实现，以及 ConfigSet 配置管理器（支持 JSON/XML/INI 格式，文件变更后自动更新缓存）

适用场景（解读层）

  • 需要在 C# 项目中统一操作多种数据库（含达梦等国产数据库）的场景
  • 需要模拟 HTTP 请求、调用接口或下载文件的 .NET 应用
  • 需要通过配置模型自动生成并读写 XML/JSON/INI 配置文件的应用
