综述（解读层）

Parse Server 是运行于 Node.js/Express 的开源后端服务，提供对象存储、REST API、GraphQL、推送通知与 Cloud Code 等能力，支持 MongoDB 或 PostgreSQL（需 PostGIS）作为数据库。可通过 npm、Docker 安装，或作为模块挂载到已有 Express 应用；需自行配置 appId、masterKey 与 databaseURI，官方对 Node.js、数据库版本有明确兼容矩阵。

  • 支持 MongoDB 与 PostgreSQL（PostGIS 2.2.0+）作为数据库，并提供 Node.js 版本兼容矩阵
  • 支持 REST API 与 Parse SDK 连接，提供 Cloud Code、推送通知（APNS/FCM）与 /parse/health 健康检查端点
  • 提供 release/alpha 分支及 LTS 分支（release-.x.x），可独立运行、Docker 运行或挂载到现有 Express 应用

适用场景（解读层）

  • 为移动或 Web 应用搭建自托管后端，通过 Parse SDK 或 REST API 保存和查询对象
  • 将 Parse Server 实例挂载到现有 Express 网站中，为已有应用附加后端能力
  • 需要 LTS 版本保障安全更新的团队，或在 Heroku、AWS、Azure、GCP 等基础设施上部署后端
