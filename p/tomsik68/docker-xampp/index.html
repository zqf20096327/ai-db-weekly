🧭 简介解读层（AI·证据行可回查）

基于 Debian 打包 XAMPP（Apache+MySQL+PHP+phpMyAdmin）并附带 SSH 服务的 Docker 镜像

综述（解读层）

该镜像将 XAMPP 打包进 Docker，包含 Apache、MySQL、PHP 和 phpMyAdmin，并运行 SSH 服务器，面向 PHP+MySQL 开发场景。网页文件挂载到 /www 目录（或直接挂载 /opt/lampp/htdocs），支持自定义 Apache 配置目录。README 标注该镜像已停止安全更新，组件版本存在已知漏洞，维护者建议改用 tomsik68/lamp，2027 年起标签默认拒绝启动。

  • 提供 PHP 5.6.40、7.4.33、8.2.12 三个版本标签，一条 docker run 命令即可启动
  • 内置 SSH 服务器（默认 root/root），支持 docker exec 进入容器及使用 /opt/lampp/bin 下的 XAMPP 二进制
  • 支持挂载自定义 Apache .conf 配置文件目录，并可通过 /opt/lampp/lampp restart 重启服务

适用场景（解读层）

  • 本地 PHP+MySQL 开发环境搭建
  • 需要通过 SSH 或容器内 shell 操作服务器的开发调试
  • 需运行特定旧版 PHP（如 5.6/7.4）的项目测试（需自担风险）
