🧭 简介解读层（AI·证据行可回查）

基于 SQL Server、按铜银金三层构建的数据仓库教学项目

综述（解读层）

该项目是 Data With Baraa 课程配套材料库，演示从 CRM 与 ERP 两套 CSV 源系统在 SQL Server 中构建数据仓库：铜层原样入仓、银层做清洗标准化、金层建星模型，配套 45 章视频、加载脚本、数据目录与质量检查脚本。面向数据工程学习者，MIT 许可；范围仅限最新数据集，不含历史化处理。

  • 提供铜-银-金（Medallion）三层架构的完整 ETL SQL 脚本，含 Bronze/Silver 加载存储过程与 DDL
  • 金层数据建模为星型模式，包含维度表、事实表、数据目录与数据流文档
  • 附质量检查脚本、命名规范、Notion 项目模板及 Mac 下的 Docker 一键启动配置

适用场景（解读层）

  • 学习在 SQL Server 上以分层架构搭建数据仓库的完整流程
  • 练习 ETL 管道开发、数据清洗与标准化操作
  • 参考星型模式建模与数据仓库文档编写的模板样例
