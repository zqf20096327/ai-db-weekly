🧭 简介解读层（AI·证据行可回查）

在 Node.js 中读取 MyBatis3 Mapper XML 并生成 SQL 字符串的库

综述（解读层）

mybatis-mapper 用于在 Node.js 中读取 MyBatis3 的 mapper XML 文件，解析 select/insert 等语句标签与 if、foreach、bind 等动态 SQL 标签，替换 #{...}/${...} 参数后输出 SQL 字符串，可直接交给 mysql2、pg 等数据库客户端执行，适合需要在 Node 环境复用既有 MyBatis mapper 文件的项目。注意其输出为插值字符串而非预编译语句，需按文档建议使用参数写法。

  • 支持 if、choose/when/otherwise、trim/where/set、foreach、bind、include 等动态 SQL 标签，以及 CDATA 与嵌套参数路径
  • 提供 createMapper、getStatement、getMapper 三个 API，getStatement 第四参数可传入 sql-formatter 选项对生成的 SQL 进行格式化
  • 包含 TypeScript 类型定义，支持 Node.js >=12，测试使用 Node.js 内置 test runner 并在 CircleCI 上以 Node 20 运行

适用场景（解读层）

  • 在 Node.js 服务中复用已有的 MyBatis3 mapper XML 文件生成 SQL
  • 将生成的 SQL 字符串传入 mysql2、pg 等驱动执行查询
  • 需要对动态拼接后的 SQL 按指定方言（如 mysql、postgresql）进行格式化输出的场景
