🧭 简介解读层（AI·证据行可回查）

基于 pg_dump 备份 PostgreSQL 并上传至 Google Cloud Storage 的脚本工具

综述（解读层）

该项目通过 pg_dump 生成 PostgreSQL 数据库备份并存档到 Google Cloud Storage，失败时可向 Slack 发送告警。支持环境变量配置、备份保留期清理、pg_dump 自定义参数，可本地运行或通过内置 Helm chart 部署到 Kubernetes，服务账号密钥以 K8s Secret 挂载。

  • 使用 pg_dump 备份单个或全部数据库并上传到 GCS bucket
  • 支持 BACKUP_RETENTION_DAYS 按天数清理旧备份、PGDUMP_EXTRA_OPTS 传递 pg_dump 额外参数
  • 提供 Helm chart 以部署到 Kubernetes，并支持 Slack 失败告警

适用场景（解读层）

  • 定时备份 PostgreSQL 数据库到 GCS
  • 在 Kubernetes 集群中以 CronJob 形式运行数据库备份任务
  • 备份失败时通过 Slack webhook 接收通知
