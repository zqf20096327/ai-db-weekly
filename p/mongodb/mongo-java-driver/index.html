MongoDB 官方 Java/Kotlin/Scala 驱动，JVM 语言客户端库

综述（解读层）

该仓库包含 MongoDB 面向 Java、Kotlin 和 Scala 的官方驱动，供 JVM 应用连接与操作 MongoDB。二进制发布于 Maven Central（org.mongodb 组，如 mongodb-driver-sync），也提供 Sonatype 快照版。版本遵循语义化版本，API 按 @Alpha/@Beta/@Deprecated 分级管理稳定性；从源码构建需 Java 17+、Git，测试需启用 enableTestCommands 的 mongod 实例。

  • 提供 Java、Kotlin（含 Kotlin 协程）与 Scala 三种 JVM 语言的 MongoDB 驱动
  • 通过 Maven、Gradle、Ivy 等构建工具获取依赖，并定期发布 Sonatype 快照版
  • 遵循语义化版本，以 @Alpha/@Beta/@Deprecated 注解区分 API 稳定性层级

适用场景（解读层）

  • JVM 应用中连接与操作 MongoDB 数据库
  • 需要 Kotlin 协程或 Scala API 的 MongoDB 访问场景
  • 参与驱动开发或贡献，本地构建与运行测试套件
