🧭 简介解读层（AI·证据行可回查）

Claude Code 插件，读取 Reddit 公共 RSS 识别买家意向帖子并按信号模式排序返回。

综述（解读层）

subscope 是 MIT 许可的 Claude Code 插件，无需 API key、OAuth 或 Reddit 账号，通过读取 Reddit 公共 RSS 获取帖子，用 8 种购买信号模式（如 pricing-rage、churn）打分排序，在聊天中返回买家信号与权威回答两条列表。提供 /subscope-onboard、/subscope-run、/subscope-judge、/subscope-tune 等命令；插件不代发回复，用户需自行到 Reddit 评论。首次运行必须完成约 5 分钟的目标定位配置，数据写入本地 SQLite。

  • 免密钥运行：读取 Reddit 公共 RSS，主源失败时自动切换备用源，遇到 HTTP 429 限速会报告而不绕过
  • 按 8 种信号模式（pricing-rage、churn、build-vs-buy、rfp-bait、stack-audit、alternative-seeking、resurrect、rivals）分别打分排序
  • 本地运行，仅写入本地 SQLite；支持 /subscope-tune 将用户对帖子的好坏标记反哺为各子版块权重和关键词分数

适用场景（解读层）

  • B2B 销售/营销人员按需扫描 Reddit，寻找处于比价、换工具阶段的潜在买家帖子
  • 代理或自由职业者寻找可接单的项目需求帖（如按周期、技能描述的招聘类帖子）
  • 开发者工具团队监控竞品品牌提及和 "是否迁移离开 X" 类讨论帖
