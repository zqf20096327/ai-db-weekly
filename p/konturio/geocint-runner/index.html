基于 GNU Make 与 PostgreSQL 的单节点地理数据 ETL/CI/CD 流水线

综述（解读层）

geocint-runner 是 Kontur 开源的地理数据 ETL/CI/CD 流水线核心组件，包含工具集与初始 Makefile，配合 geocint-openstreetmap 仓库下载、更新 OpenStreetMap planet dump 并写入数据库。以 GNU Make 为作业服务器调度并发任务，需自备 Ubuntu 单机环境。README 在 L44 之后才提供安装与首次运行指南，本页未含具体安装步骤。

  • 以 GNU Make 简单的 file-depends-on-file 模式作为作业服务器，自动并发运行可用任务，并配合 make-profiler 输出构建网络图以便定位问题与查看日志
  • PostgreSQL 配置为最小 WAL 日志、关闭 synchronous_commit（保留 fsync）、调优并行参数，并启用 auto_explain 在日志中记录慢查询计划
  • 集成 GNU Parallel、PostGIS master 版本、h3_pg、aws-cli、Python 及 GDAL、OGR、osmium、osm-c-tools 等工具，用于地理数据处理与 S3 数据传输

适用场景（解读层）

  • 以 Make 目标形式记录团队数据处理代码，使流程可自主运行、可审查测试，并在新输入数据到达时自动生成新产物
  • 下载、更新 OpenStreetMap planet dump 并导入 PostgreSQL/PostGIS 数据库
