PostgreSQL 列级透明加密扩展，基于 AES 与 KEK/DEK 两级密钥模型

综述（解读层）

column_encrypt 是一个 PostgreSQL 扩展，通过自定义数据类型 encrypted_text 和 encrypted_bytea 在类型输入/输出层透明完成加解密，用户无需修改 SQL。密钥采用 KEK 包裹 DEK 的两级模型，密文内置 2 字节密钥版本头以支持轮换。适用于 PostgreSQL 14–18，需 pgcrypto 依赖、C 编译安装并以超级用户创建扩展，且要求加载到 shared_preload_libraries。

  • 提供 encrypted_text 与 encrypted_bytea 两个自定义类型，在类型 I/O 层透明加解密，密文含 2 字节密钥版本头并按版本解密
  • 实现 KEK/DEK 两级密钥管理，支持密钥注册、会话加载、pending/active/retired/revoked 状态及全表或分批重加密的轮换辅助函数
  • 包含日志脱敏（密钥操作与 SQL 字面量掩码）、盲索引等值查询辅助，等值与哈希语义基于解密后明文定义

适用场景（解读层）

  • 需要在指定列（如身份证号等敏感字段）落盘加密、且持有密钥的会话无需改写 SQL 即可读写的 PostgreSQL 应用
  • 需要密钥轮换与版本化密文的存量数据重加密场景
  • 需要对加密列做等值查询、可接受配套盲索引列的查询模式
