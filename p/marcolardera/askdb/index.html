🧭 简介解读层（AI·证据行可回查）

用 OpenAI LLM 将自然语言问题转换为 SQL 查询并返回答案的数据库问答工具。

综述（解读层）

AskDB 是一个基于 Python 的数据库问答工具，连接 PostgreSQL、MySQL 或 SQLite 数据库后，提取表结构和示例行作为提示发送给 OpenAI LLM，由模型生成 SQL 并执行，再将结果集转为自然语言回答。提供 NiceGUI 网页界面和 Click 命令行两种入口，连接信息通过 XDG 配置目录下的 connections.json 定义。README 说明项目处于早期阶段，并提醒应使用仅具 SELECT 权限的数据库用户。

  • 支持 PostgreSQL、MySQL、SQLite，基于 SqlAlchemy 的连接字符串，理论上兼容其他 SqlAlchemy 支持的 DBMS
  • 采用两阶段 LLM 调用：先生成 SQL 查询并执行，再将结果集转换为自然语言答案
  • 提供网页图形界面（NiceGUI）和命令行接口（askdb-cli）两种使用方式

适用场景（解读层）

  • 用自然语言查询关系型数据库中的数据
  • 需要查看 LLM 生成的 SQL 及结果表格的数据问答
  • 通过命令行对已配置数据库进行快速问答测试
🔌 适配哪些库db_scan 程序判定

MySQL、PostgreSQL、SQLite
