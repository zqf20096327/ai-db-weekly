TiDB 相关工具集合，含数据导入、对比与 binlog 运维工具

综述（解读层）

tidb-tools 是面向 TiDB 的工具集合，通过 make build 构建后在 bin 目录生成二进制。包含 importer（向兼容 MySQL 协议的数据库生成并插入数据）、sync_diff_inspector（对比两库数据差异并输出报告）、binlogctl（查询 Pump/Drainer 状态及暂停/下线操作）、ddl_checker（检查 DDL SQL 能否被 TiDB 执行）。适用于需要这些运维与数据操作功能的用户。采用 Apache 2.0 许可证。

  • importer 支持向兼容 MySQL 协议的数据库（如 MySQL、TiDB）生成并插入数据
  • sync_diff_inspector 对比两个数据库的数据并输出差异报告
  • binlogctl 支持查询 Pump/Drainer 状态及暂停、下线操作；ddl_checker 检查 DDL SQL 能否被 TiDB 执行

适用场景（解读层）

  • 需要向 MySQL 协议兼容数据库批量生成和插入测试数据的场景
  • 需要比对两个数据库数据差异并获取报告的场景
  • 需要执行 tidb-binlog 相关运维操作或验证 DDL 兼容性的场景
