🧭 简介解读层（AI·证据行可回查）

自托管的 AI 代理沙箱平台，以幂等获取与自动冻结实现沙箱长存

综述（解读层）

Dormice 是一个自托管的 AI 代理沙箱平台，部署为单个守护进程加 SQLite 账本，供运行 AI 代理的开发者使用。核心是幂等的 acquireSandbox：同一 key 永远返回同一沙箱，沙箱按 active→frozen→stopped→archived 逐级冷却，任何获取将其唤醒。使用 Docker+gVisor 执行器运行真实沙箱，官方 e2b SDK 改两个 URL 即可对接。项目处于早期开发阶段，README 明确声明尚不可用于生产。

  • 提供 E2B 兼容 API（/e2b/api、/e2b/envd），未修改的官方 e2b SDK 经配置即可对接，覆盖命令执行、文件 I/O、PTY、签名 URL 等接口
  • 实现 create→freeze→stop→archive→restore 生命周期：冻结使 1 GiB 沙箱降至约 5 MiB 常驻内存，唤醒约 50 ms；可选 S3 冷归档（tar+zstd）
  • 支持 HTTP RPC、@dormice/sdk（TypeScript）、dor CLI 与 Web 控制台，含 Agent Skills 格式的使用手册，节点可用 --role node 加入集群并由网关逐台升级

适用场景（解读层）

  • 在自有机器上为 AI 代理提供持久化代码执行沙箱
  • 将现有基于 e2b SDK 的应用迁移到自托管基础设施
  • 需要沙箱长期保留状态（文件、挂起进程）并按需唤醒的代理工作流
