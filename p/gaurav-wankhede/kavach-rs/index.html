🧭 简介解读层（AI·证据行可回查）

面向自主 AI 编码代理的 Rust CLI，提供上下文切片、运行时治理与嵌入式状态存储

综述（解读层）

Kavach 是一个 Rust 静态二进制 CLI，定位为 AI 编码代理（如 Claude Code、Cursor 等）与操作系统之间的工具层，提供 AST 级代码切片、符号调用图追踪、JSON 字段投影、嵌入式 Turso/libSQL 状态存储及 mistakes ledger、生命周期门禁与 Webfind 实时联网检索。通过 cargo install 安装，先执行 kavach db register 注册项目。README 中大量性能与 token 节省数据均为作者自测，具体数值未经独立验证。

  • 提供 kavach grep/trace/origin/json 等子命令，支持 AST 模式提取、调用图追踪、JSON 字段投影与原子化文本替换
  • 内嵌 Turso/libSQL SQLite，包含依赖图、路线图 DAG、mistakes ledger 与 working-state 等持久化状态组件
  • 实现 lifecycle gates、verify 阶段门禁与 3-witness 验证机制，并配套 webfind 实时搜索工具

适用场景（解读层）

  • 为自主编码代理提供受限的代码读取与修改工具集，替代 cat/grep/sed 等传统 CLI
  • 需要跨会话保留任务路线图、架构决策与错误记录的代理工作流
  • 在工具调用中引入实时联网检索以获取外部 API 与文档信息
