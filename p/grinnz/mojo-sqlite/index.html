基于 DBD::SQLite 的轻量封装，为 Mojolicious 提供 SQLite 数据库访问

综述（解读层）

Mojo::SQLite 是对 DBD::SQLite 的小型封装，用于在 Mojolicious 框架中使用 SQLite。它提供连接池缓存、迁移管理，并通过 SQL::Abstract 从数据结构生成 CRUD 查询。所有查询为同步执行，默认 journal 模式下仅支持并发读，可启用 WAL 模式实现多进程读写。适用于单文件数据库的中小型 Web 应用。

  • 通过 SQL::Abstract 从数据结构生成 CRUD 查询，支持 on_conflict、limit/offset、JSON 展开等特性
  • 内置 migrations 机制管理数据库 schema，可从字符串或文件加载迁移脚本
  • 自动缓存数据库与语句句柄，fork 后自动重置连接，事务通过 begin/commit 实现

适用场景（解读层）

  • Mojolicious Web 应用中的数据存储层
  • 需要 schema 版本迁移管理的 SQLite 项目
  • 多进程共享同一数据库文件的应用（配合 WAL 模式）
