将自然语言问题翻译为 SQL 查询的跨领域语义解析库

综述（解读层）

该仓库是 EMNLP 2020 论文 BRIDGE 的官方代码实现，用于跨领域 text-to-SQL 语义解析：输入自然语言问题与数据库 schema 及字段取值列表，经预处理拼接、序列到序列翻译、SQL 校验后处理，生成可执行的 SQL。面向研究者和开发者，基于 PyTorch，附 Spider/WikiSQL 预训练检查点。README 声明仓库已停止维护，代码按现状提供。

  • 实现 BRIDGE 序列到序列架构，通过 schema 引导解码与后处理生成可执行 SQL
  • 包含一套 SQL 处理工具，用于 SQL 查询的解析、分词与校验（改编自 Moz SQL Parser）
  • 提供 Spider/WikiSQL 预训练检查点、模型集成推理与命令行交互演示

适用场景（解读层）

  • 针对 Spider 或 WikiSQL 数据集训练、推理与复现论文实验
  • 通过修改形式语言前后处理模块，将解析器适配到 SOQL 等其他结构化查询语言
  • 通过命令行演示对自定义数据库进行自然语言查询解码
