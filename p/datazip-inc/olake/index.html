将数据库、Kafka 与 S3 数据复制到 Apache Iceberg 的开源数据摄取引擎

综述（解读层）

OLake Go 是一个用 Go 编写的开源数据摄取引擎，用于将 PostgreSQL、MySQL、MongoDB、Oracle、MSSQL、DB2、Kafka 和 S3 中的数据复制到 Apache Iceberg 或 Parquet。它提供 Web UI 和 CLI 两种操作方式，支持全量、CDC 和增量三种同步模式，并包含自动 schema 发现与演进、Exactly-once 写入等机制。可通过 Docker Compose、Helm、Standalone Docker 及 Airflow 等方式部署。注意 Oracle 的 CDC 功能目前处于开发中（WIP）状态。

  • 支持全量、CDC（基于 pgoutput、Binlog、Oplog 等）与增量同步，含自动 schema 发现与 schema 演进
  • 目标端支持 Apache Iceberg（Glue、Hive、JDBC、REST 目录）与 Parquet，存储可写入 S3、GCS、ADLS Gen2、MinIO 及本地文件系统
  • 提供 Web UI 与 CLI 两种使用方式，CLI 暴露 spec/check/discover/sync/clear-destination 五个命令，无需依赖 Spark、Flink 或 Debezium

适用场景（解读层）

  • 将 OLTP 数据库数据迁移至 Iceberg 表，用于后续分析查询
  • 基于 CDC 数据构建准实时数据湖仓，供 Athena、Trino、Spark 等查询引擎读取
  • 从 S3 或 S3 兼容存储（如 MinIO）摄取文件数据并转换为开放表格式
