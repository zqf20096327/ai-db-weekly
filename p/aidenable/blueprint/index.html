macOS 上的无限画布 ER 图应用，可将绘制的表结构导出为 PostgreSQL DDL

综述（解读层）

Blueprint 是一款 macOS 应用，用于在类白板的无限画布上绘制 ER 图：卡片表示表与枚举，字段间连线的基数决定外键归属。它可将画布导出为 PostgreSQL DDL、SVG、Mermaid、DBML，也能读取 pg_dump 生成的 SQL 并生成图。应用同时充当 MCP 服务器，允许 Claude 等 MCP 客户端编辑打开的模式。要求 macOS 14+ 与 Swift 6 工具链，采用 MIT 许可证。

  • 支持导出 PostgreSQL DDL、SVG、JPEG/PNG、Mermaid ERD、DBML，并可基于同模式早期版本生成 ALTER TABLE 迁移脚本
  • 可作为 MCP 服务器运行，供 Claude 等客户端编辑模式、列出并切换库中的 schema
  • 模式以 .blueprint（纯 JSON）保存，支持 Quick Look 预览、blueprint:// 链接跳转，以及 CLI 渲染 SVG/PNG/SQL/DBML/MMD

适用场景（解读层）

  • 为项目初期草图式设计数据库表结构，并生成可执行的建表 SQL
  • 导入 pg_dump --schema-only 输出，为已有数据库生成可浏览的 ER 图
  • 通过 MCP 让 AI 代理代为修改模式，或在 CI 中渲染 README 用的架构图
