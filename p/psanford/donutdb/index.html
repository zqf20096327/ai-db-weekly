基于 DynamoDB 实现 SQLite VFS 的 SQL 数据库

综述（解读层）

DonutDB 通过在 DynamoDB 上实现 SQLite VFS（虚拟文件系统），使 SQLite 数据库文件直接以 DynamoDB 表为存储后端。适合需要 SQL 存储、但不希望运维独立数据库实例的 AWS 用户，例如 Lambda 函数。项目处于 Alpha 阶段，并发访问依赖 DynamoDB 实现的全局锁，多个客户端同时访问时串行化，持锁过久可能出现 Database locked 错误。查询性能受 DynamoDB 往返延迟影响，建议应用与表同区域部署。

  • 实现 SQLite VFS，将数据库文件以 4k 扇区形式存储在单个 DynamoDB 表中
  • 提供 SQLite3 CLI 可加载模块和用于推送/拉取数据库文件的 donutdb-cli 工具
  • 使用 DynamoDB 全局锁实现并发安全，并支持 v1/v2 两种表结构（v2 将扇区分入独立分区以便缓存）

适用场景（解读层）

  • 为 AWS Lambda 函数提供可读写的 SQL 数据库
  • 供运行在 EC2 实例上的软件访问以 DynamoDB 为后端的 SQLite 数据库
  • 通过 SQLite3 CLI 交互式操作存储在 DynamoDB 中的数据库
