🧭 简介解读层（AI·证据行可回查）

Rust 多线程后台任务与消息处理库，支持多种存储后端

综述（解读层）

apalis 是面向 Rust 的后台任务和消息处理库。任务处理器为异步函数，无需宏；内置重试、限流、超时、幂等等执行机制。存储后端涵盖 Redis、PostgreSQL、SQLite、MySQL 及内存实现。通过 Cargo.toml 添加依赖即可使用，采用 MIT 许可证。

  • 任务处理器为异步函数，无宏 API，支持 tokio、async-std 等异步运行时
  • 内置重试、限流、超时、幂等、任务去重与结果追踪机制
  • 提供 Redis、PostgreSQL、SQLite、MySQL 及内存存储后端，支持顺序、DAG 和条件工作流

适用场景（解读层）

  • 在 Rust 应用中执行延迟或定时（cron）任务
  • 基于 Redis 或 SQL 数据库的分布式后台作业队列
  • 需要 Web 界面管理监控任务的作业处理场景
