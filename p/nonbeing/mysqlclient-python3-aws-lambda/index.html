为 AWS Lambda Python 函数提供 mysqlclient（MySQLdb）Layer 的构建方案

综述（解读层）

该项目提供预构建的 AWS Lambda layer zip（覆盖 Python 3.8/3.11 与 MySQL 5.6/8.0 组合），并附带基于 Docker 的本地构建脚本，用于在 Amazon Linux 2 环境中编译含 libmysqlclient.so 的 layer；general-purpose 分支可推广至任意含平台特定依赖的 Python 包。适合需要在 Lambda 中直接 import MySQLdb 的开发者。构建需可运行 Docker 的 *nix 环境，自定义版本需自行修改 Dockerfile 与 requirements.txt。

  • 提供 Python 3.11/MySQL 8.0、Python 3.8/MySQL 8.0、Python 3.8/MySQL 5.6 组合的预构建 layer.zip
  • 基于 Docker（public.ecr.aws/sam/build-python3.9 镜像）本地构建 layer，运行 build.sh 生成 build_output/layer.zip
  • general-purpose 分支支持为任意 Python 包（含含 .so 文件的平台特定依赖包）构建 Lambda layer

适用场景（解读层）

  • 在 AWS Lambda Python 函数中直接 import MySQLdb 访问 MySQL 5.6 或 8.0 数据库
  • 目标 MySQL 或 Python 版本不在预构建列表中时，本地自行构建对应 layer
  • 为 pandas、numpy 等含平台特定二进制依赖的 Python 包制作 Lambda layer
