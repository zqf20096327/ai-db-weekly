Odin 语言的 SQLite3 C API 绑定库，附高层封装包

综述（解读层）

该项目为 Odin 语言提供 SQLite3 C API 的绑定，包含基础包（覆盖约 80% 的 SQLite3 函数，调用方式与 C API 一致）和基于 Odin 反射机制的 addon 包（提供 query、execute、prepare、read_all_rows 四个便捷函数）。作者声明仅验证了基本使用场景。默认静态链接，可通过 define 切换动态库、系统库路径或链接 SQLCipher，MIT 许可。

  • 基础包覆盖约 80% 的 SQLite3 C API 函数，用法与原始 C API 一致
  • addon 包利用 Odin 反射实现 query/execute/prepare/read_all_rows 四个高层函数，支持泛型结果切片
  • 通过编译 define 可切换动态/静态库、系统库路径，或链接 SQLCipher 并使用 sqlite3_key/rekey 等加密函数

适用场景（解读层）

  • 在 Odin 项目中直接调用 SQLite3 C API
  • 希望以 Odin 惯用方式执行 SQL 并将结果解析为类型化切片
  • 需要通过 SQLCipher 对 SQLite 数据库进行加密访问的项目
📖 README 首段存档原文 · 程序抽取

This is a set of Odin bindings to the SQLite3 C API, providing direct access to SQLite's functionality while also including a more Odin-like "addon" package for convenience.
