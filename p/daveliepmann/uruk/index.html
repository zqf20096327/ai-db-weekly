Uruk 是 MarkLogic XCC/J 的 Clojure 封装库，用于在 Clojure 中访问 MarkLogic。

综述（解读层）

Uruk 封装 MarkLogic 的 Java 版 XML Content Connector（XCC/J），使 Clojure 程序能通过 XDBC 连接执行 XQuery：可运行已存储的 XQuery 程序、动态构造并执行查询、管理文档与流式插入。它提供类型自动转换、:shape 结果整形、请求选项与 XDM 变量传递（支持 hiccup 风格向量构造 XML 节点）。依赖本地或远程 MarkLogic 服务器，经 Clojars 安装，由 LambdaWerk 赞助并处于维护状态。

  • 支持评估存储的 XQuery 程序以及动态构造并执行 XQuery，并可管理文档与流式插入
  • 提供 XCC 类型自动转换为 Clojure 类型，可通过 :types/:raw 与自定义映射覆盖转换
  • 支持 :shape 结果整形、:options 请求选项及 :variables 传递 XDM 变量（含 hiccup 向量与 clojure.data.xml 节点构造 XML）

适用场景（解读层）

  • 在 Clojure 应用中通过 XDBC 会话查询和写入 MarkLogic 文档数据库
  • 在 REPL 中针对本地 MarkLogic 数据库运行测试与 XQuery 示例
  • 需要以 Clojure 类型接收结果或将 hiccup 风格数据作为 XML 变量传入查询的场景
