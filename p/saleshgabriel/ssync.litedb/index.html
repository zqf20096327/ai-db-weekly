面向 .NET 前后端、基于 LiteDB/SQLite 的数据同步框架

综述（解读层）

SSync.LiteDB 是一套用于在前端（LiteDB 或 SQLite 本地库）与后端数据库之间实现数据同步的框架，提供客户端与服务器 NuGet 包。服务器端要求 ASP.NET 10，客户端要求 .NET 10，支持 Avalonia UI、.NET MAUI、Uno Platform。它要求标识符使用 GUID，同步表包含 CreatedAt、UpdatedAt、DeletedAt 三个时间戳列并采用软删除，通过实现 Pull/Push Handler 接口完成拉取与推送，也可调用 MapApiEndpointsSync 自动注入同步端点。

  • 客户端支持 LiteDB 与 SQLite，服务器端基于 ASP.NET 10，客户端基于 .NET 10，支持 Avalonia UI、.NET MAUI、Uno Platform
  • 通过实现 ISSyncPullRequest / ISSyncPushRequest 接口构建拉取与推送处理器，可继承 SSyncParameter 传递自定义参数，或调用 MapApiEndpointsSync 自动生成同步端点
  • 要求同步表使用 GUID 标识符并包含 CreatedAt、UpdatedAt、DeletedAt 列，采用软删除机制，删除记录仅以 ID 表示

适用场景（解读层）

  • 需要在 .NET 跨平台客户端（MAUI、Avalonia、Uno）本地数据库与后端之间进行数据同步的应用
  • 采用离线优先（offline-first）模式、本地执行 CRUD 后定期与服务器拉取/推送变更的项目
  • 需要以软删除方式和时间戳（CreatedAt/UpdatedAt/DeletedAt）管理增量同步数据的系统
