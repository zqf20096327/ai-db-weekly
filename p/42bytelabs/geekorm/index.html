综述（解读层）

GeekORM 是一个用于 Rust 项目的对象关系映射库。开发者通过 `Table`、`Data` 等 derive 宏为结构体生成 `.save`、`.update`、`.delete` 等函数及对应 SQL 查询；后端驱动支持 rusqlite 与 libsql（Turso）。配套 geekorm-cli 可生成与校验迁移，MIT 协议发布，主版本升级含破坏性变更。

  • 通过 Derive 宏（Table/Data）为结构体动态生成函数与 SQL 查询
  • 支持 rusqlite 与 libsql（Turso）两种后端驱动，按 feature 开启
  • 提供 geekorm-cli（init/migrate/test）生成与验证自动迁移

适用场景（解读层）

  • Rust 项目中以结构体模型读写 SQLite/LibSQL 数据库
  • 使用 CLI 管理 migrations 并从初始迁移验证到最新迁移
  • 需要随机字符串或密码哈希生成时启用 rand/hash 等 opt-in feature
