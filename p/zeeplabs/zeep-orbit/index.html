自托管的多应用后端平台，基于表定义生成 REST API 并提供仪表盘管理

综述（解读层）

Zeep Orbit 是一个用 Go 编写的开源自托管平台，面向需要在自有基础设施上运行服务的技术团队。用户在 Web 仪表盘中定义 PostgreSQL 表后，平台自动生成对应的 CRUD REST API，并内置邮箱/Google 登录、行级安全（由 Postgres 原生 RLS 策略强制执行）、文件存储和前端部署（GitHub 模板 + Render）。它支持 Docker Compose、二进制和 Helm 三种部署方式，一个服务可承载多个相互隔离 schema 的应用。前端部署依赖外部 Render 服务，AI 功能需要 superadmin 配置 OpenAI 密钥。

  • 在仪表盘中定义表结构后自动生成带分页、过滤、排序的 CRUD REST API，并按依赖顺序验证和执行 DDL
  • 行策略通过 Postgres 原生 CREATE POLICY 强制执行，支持按最终用户业务角色与行数据条件组合过滤
  • 提供每应用 JWT 鉴权（含可撤销、可刷新的 App Token）、S3 兼容文件存储、限流、软删除与 Prometheus 指标

适用场景（解读层）

  • 团队在自托管环境中为多个内部或外部应用快速生成后端 REST API 与用户管理
  • 需要由 Postgres 原生 RLS 控制最终用户数据可见性的多租户类应用
  • 通过 GitHub 模板创建前端项目并部署到 Render，配合自定义域名管理
