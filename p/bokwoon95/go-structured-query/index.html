Go 的类型安全 SQL 查询构建器与结构体映射库

综述（解读层）

go-structured-query 在 database/sql 之上提供类型安全查询构建与结构体映射，面向 Postgres 和 MySQL 用户。它通过 sqgen 代码生成器从数据库生成表结构体，将 mapper 函数与 SELECT 子句合一，NULL 扫描为零值。项目已停止新功能开发，作者推荐后续库 sq。类型检查限于方法签名，语义错误交由数据库报出。

  • 提供 sqgen-postgres/sqgen-mysql 代码生成器，从数据库生成表结构体，SELECT 结果自动映射到 Go 结构体
  • 支持 WITH/窗口函数/子查询/UNION/CASE/Upsert/INSERT...SELECT/UPDATE 与 DELETE with JOIN 等 SQL 特性，NULL 扫描为零值并可检测
  • 按方言分包（postgres/mysql），非方言无关，类型安全仅由方法签名约束，语义错误延迟到数据库执行时报出

适用场景（解读层）

  • 需要将查询结果扫描进嵌套结构体（含自连接表的重复结构体）的 Go 数据库应用
  • 希望以代码生成的表结构体替代手写表名/列名字符串的 Postgres 或 MySQL 项目
  • 已在使用该库、需评估迁移到后续项目 sq 的存量代码库
