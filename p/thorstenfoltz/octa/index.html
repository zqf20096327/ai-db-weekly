综述（解读层）

Octa 是一款面向 Linux、macOS 与 Windows 的本地桌面应用，用于打开、编辑、查询与转换数据文件，无需注册账号。它以表格形式展示 Parquet、CSV、Excel、SQLite 等多种格式内容，支持 DuckDB SQL 查询、表格比较与格式转换；同一引擎也可作为命令行工具和 MCP 服务器运行，供 AI 代理调用。源码以 Rust 编写，采用 MIT 许可证，可从源码构建，也提供 AUR、Microsoft Store、AppImage 及 Docker 等分发方式。

  • 读取 Parquet、CSV、Excel、SQLite、GeoJSON、Jupyter notebook 等多种文件格式，并可连接 S3、GCS、Postgres、Snowflake、BigQuery 等数据源
  • 内置 DuckDB SQL 查询，并可作为 CLI 工具与 MCP 服务器运行
  • 支持表格编辑、去重、文件与 schema diff、图表及 HTML 报告等分析与清理功能

适用场景（解读层）

  • 在本地打开并查询超出内存大小的 Parquet、CSV 等数据文件
  • 在表格界面中连接数据库或对象存储，浏览、编辑并转换数据格式
  • 通过 MCP 服务器让 AI 代理对同一份数据执行查询
