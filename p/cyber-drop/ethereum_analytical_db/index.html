基于 ClickHouse 的以太坊数据分析数据库，通过 ETL 从 Parity 节点同步链上数据

综述（解读层）

该项目将 Parity 以太坊节点的链数据经 ETL 管道写入 ClickHouse，用于分析与应用开发。通过 docker-compose 一键启动并自动开始同步，捆绑 Grafana 面板查看数据库状态，examples 目录提供 SQL 查询、API 和 gas 价格估算 Jupyter Notebook 示例。硬件需求较高，ClickHouse 节点需约 20 GB 内存与超过 220 GB SSD 存储。

  • 通过 docker-compose 一键部署 ClickHouse、Parity、Grafana 和 core 容器，启动后自动开始数据同步
  • 支持 SQL 查询、API 访问及 Jupyter Notebook（gas 价格估算）等使用示例
  • 提供 config.py 配置文件与 CLI 工具（extractor.py），可运行测试及其他数据操作

适用场景（解读层）

  • 搭建本地以太坊链上数据分析环境，用 SQL 查询区块、交易等数据
  • 为应用开发提供链上数据的数据库存储与 API 访问层
  • 基于链上数据进行 gas 价格估算等研究分析任务
