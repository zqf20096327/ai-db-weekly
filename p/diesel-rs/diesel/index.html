Rust 语言的 ORM 与查询构建器，利用类型系统在编译期校验数据库查询。

综述（解读层）

Diesel 是面向 Rust 开发者的 ORM 和查询构建器，支持 PostgreSQL、MySQL、SQLite 和 MariaDB 四种数据库后端。它通过宏代码生成（如 Queryable、Insertable 等 derive）减少手写映射代码，在编译期利用 Rust 类型系统检查查询，并提供查询构建器和原生 SQL 两类接口。数据库后端通过 Cargo.toml 的 feature 配置。

  • 支持 PostgreSQL、MySQL、SQLite、MariaDB 四种数据库后端，通过 Cargo.toml feature 选择
  • 提供 derive 宏（Queryable、Selectable、Insertable、QueryableByName）自动生成与 SQL 行的映射代码
  • 提供查询构建器 API 与原生 SQL API，支持查询、插入（含 RETURNING）、单条与批量更新

适用场景（解读层）

  • Rust 应用中需要以类型化方式读写关系型数据库的场景
  • 需要用代码构建简单或复杂 SQL 查询并避免手写样板映射代码的项目
  • 部分查询需直接编写原生 SQL 并映射到结构体的场景
