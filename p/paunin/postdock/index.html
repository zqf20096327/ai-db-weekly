🧭 简介解读层（AI·证据行可回查）

基于 Docker 的 PostgreSQL 流复制集群方案，集成 repmgr 与 pgpool

综述（解读层）

PostDock 提供 PostgreSQL 高可用流复制集群的 Docker 镜像与编排示例，包含 postgres、pgpool、barman 三类组件，节点由 repmgr/repmgrd 管理以实现自动 failover。支持 Docker Compose、Kubernetes（含 Helm）部署，通过 ENV 变量配置节点、后端与备份凭据。恢复流程需 SSH 访问，别名镜像标签被标注不建议用于生产。

  • 节点由 repmgr/repmgrd 管理，支持自动 failover、集群状态检查与健康检测脚本
  • pgpool 提供读写负载均衡与连接池，barman 提供 WAL 流式备份与 PITR 恢复
  • 支持复制槽、adaptive mode（通过 PARTNER_NODES）与 SSH 节点间互连（SSH_ENABLE=1）

适用场景（解读层）

  • 在 Docker Compose、Docker Swarm、Kubernetes 等环境中搭建 PostgreSQL 流复制集群
  • 需要自动 failover、读负载均衡与增量备份/PITR 的 PostgreSQL 部署
  • 使用健康检查脚本配合 Kubernetes livenessProbe 防止 split-brain
