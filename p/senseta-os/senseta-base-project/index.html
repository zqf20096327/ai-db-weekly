基于 Cookiecutter 的 Flask+Angular 全栈 Web 应用项目生成器

综述（解读层）

该项目是一个项目模板生成器，通过 cookiecutter 命令生成包含 Flask 后端（JWT 认证、Alembic 迁移、Celery worker）、Angular 前端、PostgreSQL 与 PGAdmin 的完整 Docker 化项目，面向需要在 Docker Swarm 集群上部署全栈应用的开发者。注意：README 声明维护已转移到 tiangolo/full-stack 分叉仓库继续开发。使用 MIT 许可证。

  • 通过 Cookiecutter 生成的项目包含 Flask 后端（Flask-apispec 自动生成 Swagger 文档、Marshmallow 序列化、JWT 认证、SQLAlchemy 模型、Alembic 迁移）与 Angular 前端
  • 集成 Docker Compose 与 Docker Swarm Mode 部署，含 Traefik 负载均衡与 Let's Encrypt HTTPS 证书自动生成
  • 提供 GitLab CI 配置、基于 Pytest 的后端 API 测试、Flower Celery 监控及 Sentry 错误上报接入变量

适用场景（解读层）

  • 快速生成带交互式 API 文档的 Python Flask + Angular 全栈项目脚手架
  • 需要 Docker Swarm 集群部署、多环境（生产/预发布/分支）域名配置的项目
  • 需要 Celery 异步任务、PostgreSQL 及 GitLab CI 持续集成的团队开发环境
