基于 Tauri 与 Rust 的桌面 SQL 客户端，支持多种数据库。

综述（解读层）

SQL Pro 是一个桌面 SQL 客户端，用于连接 MySQL、PostgreSQL、SQL Server、SQLite 和 MariaDB。项目采用 Tauri v2（Rust 后端）与 Vue 3 + TypeScript 前端构建，提供脚本化安装（shell/PowerShell）及 Homebrew、deb/rpm、AppImage 等安装方式。应用未签名，从浏览器下载的安装包在 macOS 和 Windows 上会显示警告。开发者可通过 bun 运行 tauri dev 进行开发。

  • 支持 MySQL、PostgreSQL、SQL Server、SQLite 和 MariaDB 连接
  • 可在 macOS（Apple silicon 和 Intel）、Windows（64 位 Intel/AMD/ARM）和 Linux（64 位 Intel/AMD/ARM）上运行
  • 提供 curl 脚本、Homebrew cask、deb/rpm/AppImage 和 PowerShell 等多种安装方式

适用场景（解读层）

  • 需要在桌面端查看和操作多种数据库表数据的场景
  • 希望在 macOS、Windows 或 Linux 上使用本地 SQL 客户端的用户
  • 开发者基于 Tauri/Vue/Rust 技术栈参与或学习桌面应用开发

A small desktop SQL client, like Sequel Pro. It works with MySQL, PostgreSQL, SQL Server and SQLite.
