🧭 简介解读层（AI·证据行可回查）

将 Signal Desktop 聊天记录导出为 Markdown/HTML 文件及附件的命令行工具

综述（解读层）

signal-export 读取 Signal Desktop 应用的 SQLite 消息数据库，将聊天导出为单个 .md/.html 文件，附件存于独立文件夹并在文件中链接。HTML 导出支持分组消息、日分隔、表情回应和图片灯箱。使用前须完全退出 Signal 应用，否则数据库只读会导致 I/O 错误。支持按聊天名单选择性导出，并可通过 --old 合并此前导出而不覆盖旧文件。

  • 读取 Signal Desktop 配置目录下的 sql/db.sqlite 数据库，将每个聊天导出为独立的 .md 或 .html 文件，附件存于单独文件夹
  • HTML 导出包含分组消息、日期分隔、reactions 和图片 lightbox，支持跟随浏览器浅色/深色偏好并可手动固定
  • 提供 --list-chats 列出聊天、--chats 选择性导出、--old 合并历史导出等选项，导出结果不覆盖既有文件

适用场景（解读层）

  • 需要将 Signal Desktop 聊天记录及图片、语音、视频附件导出为可离线浏览文件的备份场景
  • 需要将导出结果与此前导出合并、保留完整历史且不覆盖旧文件的增量归档场景
  • 需要从 Linux、macOS、Windows（含 WSL2）或 nix/NixOS 环境运行导出脚本的用户
