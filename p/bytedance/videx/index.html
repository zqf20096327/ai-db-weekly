🧭 简介解读层（AI·证据行可回查）

面向 MySQL/MariaDB 的虚拟索引引擎，仅凭统计信息模拟查询计划

综述（解读层）

VIDEX 是字节跳动开源的虚拟索引（What-If 分析）引擎，由 Optimizer 插件和统计服务两部分组成：在独立实例中按原库 DDL 创建引擎替换为 VIDEX 的虚拟表，依据 NDV 与基数估算模拟 EXPLAIN 的执行计划，无需真实建索引或读全量数据。它提供插件与独立实例两种模式，以 Docker 镜像发行，供数据库开发者和研究人员用于索引推荐等 SQL 优化实验。

  • 支持创建和删除单列、复合、EXTENDED_KEYS、降序索引，不支持函数索引、全文与空间索引
  • 架构分为 VIDEX-Optimizer 插件与 VIDEX-Statistic-Server 两部分，统计服务可独立部署并支持热更新
  • 以 MySQL handler 的索引相关接口为切入点实现，并提供 ndv、cardinality、pct_cached 三类算法接口供自定义替换

适用场景（解读层）

  • 在不改动生产实例的前提下验证新增索引对查询计划的影响
  • 为索引推荐、连接顺序优化等 SQL 优化任务提供成本估算接口
  • 在 TPC-H、JOB 等基准上测试自定义基数与 NDV 估算算法
