🧭 简介解读层（AI·证据行可回查）

OstrichDB 的终端数据库管理工具，用 Odin 编写，通过 CLP 令牌查询数据。

综述（解读层）

OstrichDB CLI 是用 Odin 编写的终端数据库管理工具，面向需要在命令行管理数据的用户。数据按记录-簇-集合三层组织，查询采用命令、位置、参数三类令牌（CLP）构成的点号语法，支持点号路径定位和 && 链式查询。需要 macOS/Linux 系统并安装 Go 与 Odin 才能构建，也可通过 Docker 运行；自然语言查询为实验性功能，且仅支持 Unix 系统。

  • 提供 CLI 手动查询、内置 HTTP 服务器和实验性自然语言查询三种交互方式
  • 实现用户认证、角色访问控制、集合加密解密及锁定/只读等权限管理
  • 支持 .csv 与 .json 文件导入、备份、查询历史和内置基准测试

适用场景（解读层）

  • 在终端通过点号语法直接管理 OstrichDB 中的记录、簇与集合
  • 启用内置 HTTP 服务器后，用其他语言编写的客户端访问数据库
  • 导入现有 .csv/.json 文件并按层级结构组织数据
