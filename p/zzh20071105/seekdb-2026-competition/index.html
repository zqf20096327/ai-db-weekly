面向 Agent 负载的 MySQL 兼容数据库，本仓库为其 2026 OceanBase 大赛赛题工作分支

综述（解读层）

seekdb 是面向 agent 负载的 MySQL 兼容数据库，写入先落 redo 日志并异步维护 HNSW 索引，支持单条 SQL 混合向量、全文与关系检索，并提供写时复制沙箱分支。本仓库为 2026 OceanBase 数据大赛 seekdb 赛题的参赛工作分支，面向参赛选手；可用 Docker 运行镜像，或以 C++20/CMake 3.20+ 从源码构建。许可证为 Apache-2.0。

  • 写入写入 redo 日志后立即返回，索引通过 delta-then-snapshot HNSW 异步维护
  • 在单条 SQL 中组合向量距离、全文相关性与关系谓词
  • 支持写时复制沙箱分支、ACID 事务与 MySQL 协议/语法

适用场景（解读层）

  • 作为 2026 OceanBase 数据库大赛 seekdb 赛题的参赛与开发仓库
  • 运行与测试包含流式写入与并发检索的 agent 负载场景
  • 在应用旁以嵌入式二进制方式运行数据库实例
