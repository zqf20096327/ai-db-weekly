Feathers 的 Sequelize ORM 服务适配器，连接多种 SQL 数据库

综述（解读层）

feathers-sequelize 是 Feathers 框架的数据库服务适配器，将 Sequelize ORM 模型封装为 Feathers 服务，支持 PostgreSQL、MySQL、MariaDB、SQLite 和 MSSQL。使用者需熟悉 Feathers 基础与 Sequelize 用法；默认返回 raw 查询结果，会绕过模型级校验与自定义 getter/setter，可通过 raw:false 或 hydrate 钩子获取模型实例；服务所用表必须包含主键。

  • 实现 Feathers Common 数据库适配器 API 与查询语法，支持 Sequelize 查询操作符及通过 operatorMap/operators 扩展
  • 通过 params.sequelize 传递 include 等 Sequelize 选项以检索关联数据，multi 选项支持批量创建、更新、删除
  • 提供 raw 查询（默认）与模型实例两种返回方式，含 hydrate/dehydrate 钩子

适用场景（解读层）

  • 为 Feathers 应用接入 PostgreSQL、MySQL/MariaDB、SQLite 或 MSSQL 数据库
  • 需要在 Feathers 服务中使用 Sequelize 关联（include）、作用域、schema 等 ORM 特性
  • 批量创建/修改/删除大量记录并结合 sequelize.returning 控制返回结果
📖 README 首段存档原文 · 程序抽取

A Feathers database adapter for Sequelize, an ORM for Node.js. It supports PostgreSQL, MySQL, MariaDB, SQLite and MSSQL and features transaction support, relations, read replication and more.

MariaDB、MySQL、PostgreSQL、SQL Server、SQLite
