Cobalt Strike BOF，用于提取并解密 Firefox 已保存的密码与 Cookie。

综述（解读层）

该仓库是一个运行于 Cobalt Strike Beacon 的 BOF 工具，用于从本地 Firefox 配置中提取已保存的密码与 Cookie。它枚举 %APPDATA% 下的所有 Firefox profile，加载 Firefox 自带的 NSS 库并调用 PK11SDR_Decrypt 解密凭据，兼容新旧两种存储格式（key4.db/logins.json 与 key3.db/signons.sqlite）。使用者需具备 Cobalt Strike 环境，编译依赖 MinGW-w64 交叉编译器，README 声明仅用于授权测试。

  • 支持从 logins.json/signons.sqlite 提取密码，从 cookies.sqlite 提取 Cookie，均通过 NSS 解密
  • 提供 firefoxdump、/all、/cookies 三种命令，支持多 profile 枚举与 x86/x64 两种架构
  • 兼容 Firefox 75+（key4.db）及旧版（key3.db）格式

适用场景（解读层）

  • 授权红队评估中收集浏览器凭据（MITRE ATT&CK T1555.003）
  • 安全研究中分析 Firefox 凭据存储机制（logins.json/key4.db 等）
  • 取证场景下读取本地 Firefox 配置中的已存密码与 Cookie
