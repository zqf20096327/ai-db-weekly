🧭 简介解读层（AI·证据行可回查）

本地优先的多智能体上下文与记忆运行时，自动索引多工具会话并提供混合检索

综述（解读层）

ContextGO 是一个面向 AI 编码工作流的本地记忆运行时：自动发现并索引 15+ 种 AI 工具（Claude Code、Cursor、Windsurf 等）的会话数据，存入本地 SQLite，通过 FTS5 BM25 粗召回加 256 维向量余弦重排的两阶段混合检索返回历史上下文，并提供基于 stdio JSON-RPC 2.0 的 MCP 服务器与 contextgo save 持久化命令。经 pipx 安装，支持 macOS、Linux、WSL2，可选 AES-256-GCM 加密多机同步；数据读取依赖各工具本地会话格式，格式变更可能影响适配。

  • 自动发现并索引 15+ 种 AI 编码工具的本地会话数据，无需手动配置
  • 两阶段混合检索：SQLite FTS5 BM25 粗召回 + 256 维向量余弦重排与 RRF 融合
  • 原生 MCP 服务器（contextgo mcp），提供 search/semantic/save/status 四个工具

适用场景（解读层）

  • 在多个 AI 编码工具间切换时召回历史决策、错误排查记录与会话上下文
  • 为 MCP 兼容客户端（Claude Desktop、Cursor 等）提供共享记忆的查询与写入
  • 通过 systemd/launchd 守护进程在本地或远程 Linux 节点部署离线记忆服务
