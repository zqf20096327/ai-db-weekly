🧭 简介解读层（AI·证据行可回查）

本地运行的 AI 编码工具记忆与规则共享中心，单一 SQLite 存储

综述（解读层）

Aletheia 是一个本地、免费的记忆与规则中心，为 Claude Code、Codex CLI、Cursor、Gemini CLI、Windsurf、OpenCode 等工具提供共享的持久记忆：数据存于单一 SQLite 库，工具通过 MCP（stdio/HTTP）、REST 或 CLI 读取，规则可同步写入 CLAUDE.md、AGENTS.md 等各工具的指令文件。通过 aletheia install 命令安装钩子实现自动捕获，含密钥脱敏与备份机制。项目处于 alpha 阶段，仅部分工具在真实环境中验证过；运行需 Bun 1.1+，仅监听 loopback，无账号与遥测。

  • 单一 SQLite 存储通过 MCP（stdio 与 HTTP）、REST API 和 CLI 三种接口读取，支持多 AI 编码工具共享记忆
  • 规则可同步写入 CLAUDE.md、AGENTS.md、GEMINI.md、.cursor/rules、.windsurf/rules 等各工具指令文件
  • 钩子捕获前进行密钥脱敏与 块处理，数据库不可用时写磁盘暂存，始终以 0 退出避免阻塞宿主工具

适用场景（解读层）

  • 多个 AI 编码工具（如 Claude Code 与 Codex CLI）之间共享同一份项目记忆与规则，避免各工具重复维护
  • 对本地数据隐私有要求的场景：无账号、无遥测、仅监听 loopback，除配置模型提供商外无网络调用
  • 需要规则一次编写、同步分发到多种工具指令文件的团队或个人工作流
