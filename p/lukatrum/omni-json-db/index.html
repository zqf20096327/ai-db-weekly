纯Python嵌入式KV JSON数据库，含图引擎与时间回溯

综述（解读层）

omni-json-db 是面向 Python 开发者的嵌入式数据库引擎，以键值存储为底，叠加文档查询与属性图引擎（支持 BFS、Dijkstra 等）。无需数据库服务器，支持 JSON/MsgPack/Pickle/YAML 序列化与 LZ4/Zstd/Brotli 压缩，核心零第三方依赖，需 Python 3.7+。事务为异常安全而非崩溃安全，kill -9 不回滚。

  • 内置属性图引擎，支持 BFS、DFS、Dijkstra、环检测及 O(1) 邻接索引
  • 提供 Time-Travel 状态管理（unmodify/unremove/history）与异常回滚事务
  • 序列化格式与压缩算法可插拔，支持自定义 dumps/loads 编解码与加密

适用场景（解读层）

  • 本地缓存、日志聚合等嵌入式存储场景
  • 需要在 Python 中以原生语法操作 JSON 数据的轻量应用
  • 构建属性图/知识图谱并需撤销恢复能力
