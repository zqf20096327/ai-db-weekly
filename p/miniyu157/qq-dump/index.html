QQNT 数据库解密、消息解析导出与查询的一站式 Python 流水线

综述（解读层）

该项目提供 QQNT 聊天数据库从密钥获取、sqlcipher 解密到消息解析导出的完整流程，支持 Android、Windows、Linux 三平台，附好友查询与本地 WebUI。核心消息导出走 Legacy（QQRootFastDecrypt）路径，支持 TXT、MD、HTML 输出与多种消息类型解析。项目以 Python 实现，运行时依赖均为可选，采用 MIT 许可证。

  • 支持 Android（数据库文件头推算密钥）、Windows/Linux（进程内存扫描 raw_key）三种密钥获取方式，可缓存复用
  • 处理超过 1 GiB sqlcipher 数据库的锁页迁移，并读取 -wal 文件以包含未写回主文件的最近数据
  • Legacy 导出支持 TXT/MD/HTML 三种格式、时间范围过滤、非好友扫描，可解析红包、图片、Ark 卡片、引用消息等类型

适用场景（解读层）

  • 对 QQNT 数据库进行本地解密与消息内容导出存档
  • 查询数据库持有者的好友列表信息，包括分组、非好友、删除时间与亲密度
  • 在终端或本地 WebUI 中查看消息统计与好友信息
