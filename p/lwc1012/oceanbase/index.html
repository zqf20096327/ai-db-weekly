面向零基础学习者的数据库内核入门实训项目

综述（解读层）

MiniOB 由 OceanBase 团队基于华中科技大学数据库课程原型联合多所高校开发，面向在校学生、数据库从业者和爱好者，用于学习数据库实现原理。项目包含网络、SQL 解析、查询优化、执行器、存储引擎、MVCC 事务等模块，并配套设计文档、教程和在线训练平台。为便于学习，它简化了并发操作、安全特性和复杂事务管理等功能；源码采用木兰宽松许可证第 2 版发布。

  • 包含网络服务、SQL 解析、语义解析、查询优化、计划执行、存储引擎、MVCC 事务、日志、B+ Tree 索引等数据库关键模块
  • 配套 GitHub Pages 文档、《从0到1数据库内核实战教程》视频与讲义，并提供在线编程环境和代码提交测试的训练营平台
  • 采用木兰宽松许可证第 2 版，允许自由拷贝和使用源码

适用场景（解读层）

  • 数据库内核原理的入门学习与工程编码训练（内存管理、网络通信、磁盘 I/O）
  • 参加全国大学生计算机系统能力大赛数据库赛的赛前练习
  • 高校数据库课程的教学实践配套项目
📖 README 首段存档原文 · 程序抽取

MiniOB 是 OceanBase 团队基于华中科技大学数据库课程原型，联合多所高校重新开发的、专为零基础的同学设计的数据库入门学习项目。MiniOB 的目标是为在校学生、数据库从业者、爱好者或对基础技术感兴趣的人提供一个友好的数据库学习项目，更好地将理论、实践进行结合，提升同学们的工程实战能力。
