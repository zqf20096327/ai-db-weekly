SlicingDice 数据仓库与分档数据库服务的官方 JavaScript 客户端

综述（解读层）

该客户端封装了 SlicingDice（一种以 SQL 和 API 方式提供的数据仓库/分析数据库服务）的 API 调用逻辑，面向需要在 JavaScript/Node.js 环境中接入该服务的开发者。通过 `npm install slicerjs` 安装后，可执行建列、插入数据、实体/事件计数、聚合、top values、存储查询管理及 SQL 查询等操作；方法为 API 端点的薄封装，参数与返回值为与 API 端点语法一致的 JSON-like 对象。版本 v2.1.0，MIT 许可。

  • 提供覆盖 API 端点的完整方法集：数据库/列管理、insert 插入、countEntity/countEvent 计数、aggregation 聚合、topValues、数据提取（result/score）与 sql() 查询
  • 方法为 API 端点的薄层封装，参数与返回值是与端点语法一致的 JSON-like Object
  • 通过 npm 安装（npm install slicerjs），仓库附 tests 与 examples 目录，MIT 许可

适用场景（解读层）

  • 在 Node.js 或浏览器 JavaScript 项目中写入与查询 SlicingDice 数据仓库
  • 构建需要实体计数、时间序列事件计数、聚合与 top values 等分析查询的应用
  • 以 SQL 语句方式对 SlicingDice 执行查询与插入操作
