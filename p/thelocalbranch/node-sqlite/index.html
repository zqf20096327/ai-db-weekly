TypeScript 编写的 sqlite3 包装库，提供 Promise API 与 SQL 迁移

综述（解读层）

该库是 Node.js 下 sqlite3 的零依赖包装，用 TypeScript 编写，将 sqlite3 的回调式 API 转为返回 ES6 Promise 的方法，并提供基于 SQL 文件的迁移 API（通过 migrations/ 目录配合 db.migrate() 运行）。v4 要求 Node.js 10 及以上，旧环境需安装 v3。使用前需自行安装 sqlite3 或符合其 API 的驱动。

  • API 与 sqlite3 保持一致，除 each() 外所有方法均返回 ES6 Promise、不接受回调参数
  • 包含基于 SQL 迁移文件的轻量迁移 API，支持 force 回滚重放等配置项
  • 支持自定义驱动、多数据库打开、缓存模式，可导出底层驱动实例

适用场景（解读层）

  • Node.js 应用中以 Promise/async-await 方式操作 SQLite 数据库
  • 需要以 SQL 文件形式管理数据库结构变更的项目
  • 无法编译 sqlite3 原生模块时可搭配 sqlite3-offline-next 等兼容驱动使用
