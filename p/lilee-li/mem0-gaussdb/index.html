适配 GaussDB（集中式、A 模式、Ustore）的 Mem0 记忆层移植版本

综述（解读层）

该项目是 Mem0 针对 GaussDB 的适配版本，目标部署形态为集中式部署、A 模式及 Ustore 存储引擎。Mem0 本身为 AI 助手与智能体提供记忆层，支持多级记忆（用户/会话/智能体）、混合检索与 LLM 集成。README 内容沿用上游 Mem0 文档，未包含 GaussDB 适配的配置说明，具体改动需查阅代码。

  • 提供用户、会话、智能体三级记忆的存储与检索，支持语义、BM25 关键词与实体匹配的多信号融合检索
  • 支持通过 pip（mem0ai、mem0ai[nlp]）与 npm 安装，提供自托管 Server（docker compose）与 CLI（mem0 add/search）方式运行
  • 依赖外部 LLM 与嵌入模型运行，默认使用 OpenAI 的 gpt-5-mini 与 text-embedding-3-small，并支持配置其他模型

适用场景（解读层）

  • 在华为 GaussDB 环境中使用 Mem0 记忆能力的团队（需集中式、A 模式、Ustore 部署）
  • 为客服机器人、AI 助手等应用添加用户偏好与历史记录的持久化记忆
  • 基于 pip/npm 库或 CLI 进行记忆功能的功能验证与原型测试
