🧭 简介解读层（AI·证据行可回查）

以单个 SQLite 文件为载体的智能体记忆数据库

综述（解读层）

remindb 是一个用 Go 编写的智能体长期记忆数据库，将 Markdown、HTML、JSON、YAML、TOON 等格式的笔记解析为带哈希、温度标记与 token 计数的节点树，存入单个 SQLite 文件，并通过 MCP 工具套件（MemoryTree、MemorySearch、MemoryDelta 等）供 Claude Code、Codex、Gemini CLI 等智能体调用。支持 FTS5 搜索、快照版本回滚、wiki-link 知识图谱。安装提供脚本一键安装或 Go 1.26+ 源码编译。

  • 解析 Markdown/HTML/JSON/YAML/TOON 为结构化节点树，每个节点含哈希、温度与 token 计数，存储于单个可移植的 SQLite 文件
  • 提供 16 个 MCP 工具，包括节点树浏览、FTS5 全文搜索、快照差量同步（MemoryDelta）、版本回滚与最多 5 跳的关系图谱遍历
  • 节点温度随读取升高、随时间衰减，冷节点触发就地摘要压缩，MemoryPin 可保护节点免于衰减

适用场景（解读层）

  • 为 Claude Code、Codex、Gemini CLI 等 MCP 智能体提供跨会话持久记忆，避免每会话重复读取全部笔记
  • 将记忆文件拷贝到其他机器、提交进仓库或交给其他智能体共享同一知识库
  • 对频繁变动的笔记库进行节点级版本管理，返回会话通过快照游标差量同步而非整文件重读
