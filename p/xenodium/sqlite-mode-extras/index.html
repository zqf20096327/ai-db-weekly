扩展 Emacs 29 内置 sqlite-mode 的实验性增强包

综述（解读层）

sqlite-mode-extras 是一个基于 Emacs 29 自带 sqlite-mode 的扩展包，通过 minor mode（sqlite-extras-minor-mode）提供 Tab/RET 的 DWIM 导航、字段编辑、查询编写与执行、行增删、缓冲区刷新等交互命令，可从 MELPA 安装。作者声明代码未经充分测试，属实验性质，建议使用前备份数据库。适合需要在 Emacs 中交互操作 SQLite 数据库的用户。

  • 提供 tab-dwim/ret-dwim 等 DWIM 导航与编辑命令，支持在表格上切换展开、在行上编辑字段
  • 支持编写并执行 SQL 查询、执行并显示 SELECT 查询结果，以及向当前表添加行、按区域删除多行
  • 通过 sqlite-extras-minor-mode 提供默认键绑定，含 sqlite-mode-extras-auto-complete-enabled 等自定义变量

适用场景（解读层）

  • 在 Emacs 29 的 sqlite-mode 缓冲中浏览和导航 SQLite 表格数据
  • 直接在编辑器内编写并执行 SQL 查询、编辑字段或增删行
  • 需要刷新缓冲以重新查询数据库最新内容的场景
