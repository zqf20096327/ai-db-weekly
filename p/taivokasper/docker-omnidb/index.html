基于 Alpine Linux 的 OmniDB Docker 容器，通过 Web 界面管理数据库

综述（解读层）

该项目将 OmniDB 打包为基于 Alpine Linux 的 Docker 容器镜像，可通过 docker run 命令启动并经由 Web 界面管理数据库。容器暴露 8080（HTTP）和 25482（Websocket）端口，默认登录凭据为 admin/admin，配置持久化目录为 /etc/omnidb，支持通过卷映射保存配置。适用于需要以容器方式运行 OmniDB 的使用者。

  • 提供基于 Alpine Linux 的 OmniDB Docker 镜像，可从 Docker Hub 拉取
  • 暴露 8080（HTTP）与 25482（Websocket）两个端口，通过 Web 界面访问
  • 配置存储于 /etc/omnidb，支持通过卷映射实现配置持久化

适用场景（解读层）

  • 需要通过 docker run 快速启动 OmniDB Web 客户端的环境
  • 需要对 OmniDB 配置做持久化保存的容器化部署
  • 通过映射到 127.0.0.1 的端口在本地访问数据库管理界面
