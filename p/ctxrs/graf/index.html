🧭 简介解读层（AI·证据行可回查）

用 Rust 实现的代码图谱索引工具，将代码库关系存入 SQLite 供查询

综述（解读层）

Graf 是一个独立的 Rust 实现（受 Graphify 启发，非其分支），用于为代码库和文档构建符号关系图谱，支持查询调用者、被调用者和变更影响范围，并通过 MCP 只读连接供 Codex、Claude Code、Cursor 等编码代理使用。图索引保存在 SQLite 中，更新仅处理变更文件，更新以完整代（generation）形式生效。README 称在 VS Code 仓库上其搜索耗时 13 毫秒、未变更图更新耗时 880 毫秒。依赖 Rust 1.90+，采用 Apache-2.0 许可证。

  • 将代码库符号关系图保存在 SQLite（.graf/index.db），搜索直接查询数据库，更新仅处理变更文件，更新以完整代形式发布
  • 提供 impact 查询展示符号及其依赖代码与关系，支持 --json 结构化输出、歧义符号返回来源证据而非猜测
  • 以单个原生二进制运行索引与搜索，无需 Python 环境、API 密钥、模型或后台服务；支持从 graphify-out/graph.json 迁移并可撤销（graf switch --undo）

适用场景（解读层）

  • 为大型代码库建立符号调用与依赖图谱，供编码代理通过 MCP 查询调用者、被调用者、路径与变更影响
  • 已使用 Graphify 的项目需导入既有图数据并切换到 Rust 实现时，可用 graf switch 迁移并保留原配置
  • 编码模型训练者在 rollout 环境中为代理提供代码图谱查询能力（README 建议的用法）
