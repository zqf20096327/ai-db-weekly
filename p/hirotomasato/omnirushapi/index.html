自托管 LLM 网关，聚合多上游账号为单一 OpenAI/Anthropic 兼容端点，支持轮询故障转移

综述（解读层）

omnirushapi 是一个自托管网关，在多个上游账号前提供 OpenAI 和 Anthropic 兼容的统一端点。它以三种方言（OpenAI chat、OpenAI responses、Anthropic messages）与客户端和上游通信并双向翻译，含流式与工具调用；按优先级/轮询或最少使用路由账号，失败时冷却并切换重试，支持 device-flow 凭证自动续期。数据存于单个 SQLite 文件，提供控制台、CLI 和管理 API。需 Node 22+ 与 curl，无构建步骤。

  • 支持 OpenAI chat completions、OpenAI responses、Anthropic messages 三种方言的客户端与上游双向翻译，含流式事件和工具调用
  • 按优先级加权轮询或最少使用策略路由账号，拒绝账号进入冷却并在其他账号重试，每次尝试均记录日志
  • 提供六个服务端渲染的控制台页面、CLI 和带 admin token 的管理 API，数据存储为单个 SQLite 文件（增量迁移）

适用场景（解读层）

  • 持有多个上游账号（免费额度、按 key 限速）且希望客户端使用统一 base URL 和 key 的自托管场景
  • 客户端与上游使用不同 API 方言（如 OpenAI 客户端调用 Anthropic 上游）需要协议翻译的环境
  • 使用 device-flow/OAuth 账号需要自动轮换刷新凭证、避免并发续期冲突的部署
