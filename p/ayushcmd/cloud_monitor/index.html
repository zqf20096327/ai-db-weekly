自托管 Docker 主机与容器监控平台，React+FastAPI+Prometheus 组成

综述（解读层）

CloudMonitor 是一个自托管可观测性平台，用于在单一仪表板中监控 Docker 主机及容器状态。它由 React 前端、FastAPI 后端、PostgreSQL 存储、Python 监控 agent 和 Prometheus 栈组成，面向运行小型 Docker 环境的开发团队、学生实验室和测试环境。Agent 读取 Docker 守护进程并上报心跳与容器指标；README 明确标注为学生课程项目，本地与 AWS 部署的服务覆盖不同，演示站点仅提供 HTTP。

  • Python agent 通过 Docker SDK 读取容器元数据与资源统计，以 JWT 认证方式向 API 发送心跳和遥测数据
  • 后端为 FastAPI（JWT HS256 认证），使用 PostgreSQL 16、SQLAlchemy 与 Alembic 迁移持久化用户、agent 和指标记录
  • 内置 Prometheus、Node Exporter、Alertmanager 及告警规则，本地 Compose 还包含 Grafana 与 cAdvisor；提供 Docker Compose 部署文件、可选 Caddy TLS profile 和 GitHub Actions CI/CD 工作流

适用场景（解读层）

  • 集中查看已注册主机及其 Docker 容器的运行状态与 CPU、内存等资源指标
  • 通过 Prometheus 与 Node Exporter 采集应用和主机级指标，并用告警规则演练运维监控流程
  • 结合云端 VM、容器部署、服务网络与持久存储，用于云计算课程或 DevOps/SRE 实践学习
