Hermes 本地记忆插件，基于嵌入式图数据库 .lbdb 文件存储

综述（解读层）

该插件为 Hermes Agent 提供基于 LadybugMemory 列式嵌入式图数据库的本地记忆后端，数据保存在单一 .lbdb 文件中，无需 API 密钥或云服务。提供 store/search/recall/update/delete/link 等 8 个工具，支持 BM25 检索、重要度加权和带类型的图关系边。面向需要本地、可检查且无 SaaS 依赖记忆的 Hermes 用户。注意安装时需手动创建 symlink，因 Hermes 目前的记忆发现系统仅扫描源码树内的 provider 目录。

  • 提供 8 个记忆工具：存储（含类型与重要度）、BM25 搜索、按重要度召回、按 ID 更新/删除、创建命名关系边及图遍历，另可选启用 GLiNER2 实体抽取查询
  • 支持 7 种记忆类型（general/preference/fact/project/person/event/task）和 1–10 重要度评分，每轮对话前按重要度加权后台预取记忆，并将内置 MEMORY.md/USER.md 写入自动镜像到 Ladybug
  • 所有数据存储在 HERMES_HOME 下的单个 .lbdb 文件中，通过 config.yaml 的 memory.ladybug 配置 db_path、prefetch_limit、min_importance、auto_link 等项

适用场景（解读层）

  • 为 Hermes Agent 配置无需外部服务的本地记忆后端
  • 需要以类型化条目加图关系（named edges）组织记忆并进行关键词搜索与重要度召回的场景
  • 通过 GLiNER2 扩展进行实体级知识图谱查询的应用
