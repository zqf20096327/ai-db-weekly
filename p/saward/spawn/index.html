基于 Rust 的 PostgreSQL 迁移工具，以可编辑组件配合固定（pin）机制编译不可变历史迁移

综述（解读层）

Spawn 是一个面向 PostgreSQL 的数据库迁移与测试工具，用 Rust 编写。它将函数、视图、触发器等数据库逻辑维护为可就地编辑的源文件组件，通过 Minijinja 模板在迁移中引用，并支持对已构建迁移执行 pin 固定以保证旧迁移输出不变。测试为单个 SQL 文件加 expect 文件的 golden file 形式，可在临时数据库上运行。适合重度依赖数据库逻辑并需要可审查迁移历史的开发团队。

  • 迁移由时间戳目录与 up.sql 组成，提供 new、build、apply、status、pin 子命令
  • 使用 Minijinja 模板实现组件复用，pin 后旧迁移不受组件后续修改影响
  • 提供 golden file 测试：SQL 测试文件可在临时数据库运行，配合 expect/compare 命令对比输出，测试本身也可使用模板宏生成数据

适用场景（解读层）

  • 维护 PostgreSQL 函数、视图、触发器等数据库逻辑并需要可审查的变更历史
  • 为数据库函数、触发器编写基于期望输出的回归测试
  • 通过模板宏减少测试数据创建的重复 SQL
