基于 MyBatis-Flex 的 PostgreSQL 与 DM 达梦双数据源跨库查询示范项目

综述（解读层）

该项目是一个多数据源查询示范工程，演示如何用 MyBatis-Flex（1.10.8）+ Spring Boot 3.3.6 + Java 21 同时访问 PostgreSQL（存用户数据）和 DM8（存订单数据）。核心机制是通过实体类 @Table 注解的 dataSource 属性自动切换数据源，跨库关联通过 user_id 字段在应用层用 Relations API 组装实现。项目提供 6 个 REST API 场景端点，采用 Maven 多模块分层结构（api/service/dm/pg/common），面向需要同时访问两类数据库或做国产化迁移参考的开发者。

  • 通过实体类 @Table(dataSource = "xxx") 注解自动切换 PostgreSQL 与 DM8 数据源，业务代码无需手动干预
  • 使用 MyBatis-Flex Relations API 实现自动级联查询，包括同库跨表与跨库跨表（订单→用户）的关联数据填充
  • 提供 6 个核心查询场景的 REST API 端点，覆盖单表、同库关联、跨库单查与批量跨库查询

适用场景（解读层）

  • 政务或企业系统需要同时访问 PostgreSQL（业务数据）与 DM 达梦（历史数据）的场景
  • 从 Oracle/DM 迁移到 PostgreSQL 的过渡期双库共存方案参考
  • 微服务架构下不同服务使用不同数据库、需在应用层做跨服务数据关联的开发参考
