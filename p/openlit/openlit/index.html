基于 OpenTelemetry 的 AI 智能体观测与评测平台

综述（解读层）

OpenLIT 是一个 Apache 2.0 开源项目，为 AI 智能体与编码智能体的运行环境提供追踪、评测、护栏、提示词管理和成本/GPU 监控。通过 pip/npm 安装 SDK 并调用 openlit.init() 即可自动采集 LLM 调用、工具调用等遥测数据，导出符合 GenAI 语义约定的 OTLP 格式，可自托管运行，也可接入已有的 OpenTelemetry 体系。

  • 自动采集 LLM 调用、工具调用、检索、智能体步骤等遥测数据，遵循 OpenTelemetry GenAI 语义约定，监听 OTLP :4317/:4318 端口
  • 提供 LLM-as-a-Judge、程序化评测与 CI 门禁，内置幻觉、偏见、毒性等评测类型
  • 包含 Prompt Hub、Rule Engine、Guardrails、Vault、OpenGround 及 NVIDIA/AMD/Intel GPU 监控等组件，宣称支持 70+ 集成（Claude Code、Cursor、Codex、LangGraph 等）

适用场景（解读层）

  • 对生产环境中的 LLM/智能体应用进行调用链追踪、成本核算与故障排查
  • 对编码智能体（Claude Code、Cursor、Codex 等）的会话进行观测与记录
  • 自托管场景下集中管理提示词版本、API 密钥并配置运行时护栏规则
