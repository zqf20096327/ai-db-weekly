🧭 简介解读层（AI·证据行可回查）

基于 Wails v2 的桌面多数据库客户端，覆盖六种引擎并内置数据生成、库对比与变更日志

综述（解读层）

db-manager 是用 Wails v2 + React 构建的桌面数据库客户端，支持 MySQL、PostgreSQL、SQLite、MongoDB、TiDB 和 Apache Doris，以单个可执行文件发布于 Windows/macOS/Linux。除浏览查询外，提供 SQL 文件逐句执行、mock.js 数据填充、双库结构对比并生成同步脚本、18 种语言代码生成，并记录每条写语句及影响行数。连接配置和日志仅存本机，密码用 AES-256-GCM 加密；Oracle 和 SQL Server 尚在计划中。

  • 支持 MySQL、PostgreSQL、SQLite、MongoDB、TiDB、Apache Doris 六种引擎，通过 Driver/Conn/Dialect 接口接入，UI 按能力而非引擎名显示功能入口
  • 提供数据库导出、.sql 文件逐句执行、mock.js 模板数据生成（40+ 占位符）、双库对比并生成同步脚本、18 种语言代码生成，以及记录每条写语句影响行数的变更日志
  • 单文件便携发布（Windows/macOS/Linux），连接与日志仅存本机，密码以 AES-256-GCM 加密，无遥测

适用场景（解读层）

  • 需要在同一桌面工具中连接多种引擎（含 MongoDB 和 Doris）进行浏览、编辑与导出
  • 开发或测试环境需要按 mock.js 模板批量填充数据、对比两个库的结构差异并生成同步脚本
  • 需要保留每条写语句的执行记录（时间、连接、表、影响行数）用于审计回溯
