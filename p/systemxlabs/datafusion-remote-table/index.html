🧭 简介解读层（AI·证据行可回查）

一个 DataFusion 表提供器，用于在远程数据库上执行 SQL 并流式返回结果

综述（解读层）

这是一个用 Rust 编写的 DataFusion 表提供器（table provider），通过远程数据库连接执行 SQL 查询并将结果以流方式接入 DataFusion，同时支持向远程数据库写入数据。README 给出了基于连接选项构造实例的 Rust 使用示例，支持 Postgres、MySQL、Oracle、SQLite、达梦、GaussDB/OpenGauss 及 Microsoft Access 等数据库，并逐一列出各库已支持的数据类型；README 未说明版本号与许可证具体内容。

  • 支持将远程数据库上的 SQL 查询结果作为 DataFusion 表提供器流式输出，并可向远程数据库插入数据
  • 支持模式推断或用户指定模式，支持下推过滤条件与 limit 到远程数据库，执行计划可序列化用于分布式执行
  • 覆盖 Postgres、MySQL、Oracle、SQLite、达梦、GaussDB/OpenGauss、MDB/Access（经 MDBTools ODBC 驱动）等数据库及其各自的数据类型列表

适用场景（解读层）

  • 在 DataFusion 查询流程中读取远程关系数据库（如 Postgres、MySQL、Oracle）中的表数据
  • 需要在分布式执行计划中接入远程数据库数据源的场景
  • 需要向远程数据库写入数据或将 Access/MDB 文件作为数据源接入的场景
