🧭 简介解读层（AI·证据行可回查）

以 Ansible 部署自托管 Supabase 生产栈，并经 SSH 暴露只读 MCP 供 AI 编码代理使用。

综述（解读层）

该项目通过 setup.sh 一条命令在 Debian/Ubuntu/Arch 服务器上部署 Supabase 全套容器，并集成 Caddy SSO、pgBackRest 备份、Grafana 监控、LUKS 加密等组件。面向希望在自控服务器上运行 Supabase 并让 AI 编码代理接入的开发者。每次部署生成不含密钥值的实例清单（/etc/supabase/instance.json）和一个只读 MCP 服务器；代理通过受限 SSH 密钥以专用 agent_reader 角色连接，数据库层面强制只读。README 提醒：仪表盘在组件全部禁用时无认证，生产部署需至少启用 caddy、ufw、fail2ban 和 backup。

  • 部署只读 MCP 服务器（经 SSH stdio，无公网端口），提供 list_tables、describe_table、SELECT-only query 等工具，工具输出不含密钥值
  • 内置 pgBackRest 实现 WAL 持续归档与按时间点恢复，备份写入 S3、RustFS 或 POSIX 路径，并附 restore-verify.yml 离线验证
  • 部署 Caddy（Let's Encrypt TLS + OAuth2 SSO + IP 白名单）、UFW、Fail2ban、Grafana/Prometheus/Loki 监控及 LUKS 磁盘加密；提供 migrate.sh 从 Supabase Cloud 迁移

适用场景（解读层）

  • 在自有服务器上自托管 Supabase 生产环境，要求 SSO 保护的仪表盘、监控告警和 PITR 备份
  • 让 Claude Code、Codex 等 AI 编码代理安全发现并查询已部署的 Supabase 实例
  • 通过 migrate.sh 将现有 Supabase Cloud 项目（schema、数据、auth 用户、存储对象）迁移到自托管栈
