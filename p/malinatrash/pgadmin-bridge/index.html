PostgreSQL 线协议代理，通过 pgAdmin 4 Query Tool API 执行 SQL

综述（解读层）

pgadmin-bridge 是一个用 Python 编写的 PostgreSQL 线协议代理，在本地 127.0.0.1 监听 5432 端口，把客户端的 SQL 转发到 pgAdmin 4 的 Query Tool REST API 执行，用现有的 pgAdmin 账号登录。适用于数据库端口被防火墙限制、只能通过 pgAdmin 网页访问的用户。限制：仅限回环监听，web UI 自身无登录，使用前需确认符合公司访问策略。

  • 支持简单与扩展查询协议，兼容 psql、DataGrip、DBeaver、JDBC、psycopg、node-postgres 等使用 PostgreSQL 线协议的客户端
  • 可同时配置多个 pgAdmin 实例，提供只读会话、语句超时、空闲后端释放与目录缓存等可配置项
  • 纯 Python 标准库实现，无第三方依赖，提供 Docker 镜像、pip 安装和源码运行三种方式

适用场景（解读层）

  • 公司仅开放 pgAdmin 网页访问数据库，需要用 IDE、psql 或脚本工具执行查询
  • 通过 pgAdmin 访问 staging 数据库来运行本地应用或迁移工具
  • 多套 pgAdmin 环境（生产、staging、分析库）需要统一的本地连接入口
