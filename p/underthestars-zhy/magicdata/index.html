基于 SQLite 的 Swift 数据库库，用 Swift Macro 实现对象存储

综述（解读层）

MagicData 是一个基于 SQLite 的 Swift 数据库库，面向 iOS/macOS 等Swift 开发者，提供增删改查、关系（一对一/多对多/反向）与异步查询能力。模型需遵循 MagicObject 协议，属性用 @PrimaryMagicValue、@OptionMagicValue 等包装器标注；所有操作在单一 actor 线程执行以保持线程安全。数据库自身维护 ZIndex 作为内部主键，Codable 对象编码为其 zIndex 整数值。

  • 基于 SQLite，通过 MagicObject 协议与属性包装器定义模型，支持 String/UUID/Int/Double/Data/Array/Dictionary/Set 等存储类型
  • 所有数据库操作运行在同一 actor 线程，支持 async/await API 与 AsyncStream 流式查询
  • 支持对象关系（一对多、多对多 Set/Array/Dictionary、反向关系）、MagicAsset 大文件存储（文件保存在本地文件系统，数据库仅存路径）与 AsyncMagical 延迟取值

适用场景（解读层）

  • iOS/Swift 应用中需要本地持久化结构体模型数据的场景
  • 需要存储大文件（图片、数据等）但数据库仅保存路径的场景
  • 需要对象间一对多/多对多关系并配合 async/await 查询的场景
