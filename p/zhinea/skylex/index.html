自托管 PostgreSQL 数据库控制平面，双二进制实现集群自动化管理

综述（解读层）

Skylex 是一个自托管控制平面，用于自动化 PostgreSQL 集群的供应、复制、备份与高可用，由 skylex-server（REST/gRPC API、调度器、元数据存储）与 skylex-agent（节点执行与状态上报）两个二进制组成。元数据默认使用嵌入式 SQLite，生产模式可切换 PostgreSQL，支持 Docker Compose、systemd 和 Helm 部署。README 标注内存占用约 20MB，MVP 阶段仅支持 PostgreSQL 引擎。

  • 提供 REST（8080）、gRPC（9090）与指标/健康检查（9091）三类服务端口，元数据存储默认 SQLite、可切换 PostgreSQL
  • 通过 skylex-agent 在各数据库节点执行命令并经 gRPC 上报健康状态，参考栈含 server、3 agents、etcd 与 MinIO
  • 支持 Docker Compose、systemd 裸机与 Kubernetes Helm 三种部署方式，配置经 YAML 文件或 SKYLEX_ 前缀环境变量覆盖

适用场景（解读层）

  • 希望在不依赖云厂商托管服务的前提下管理自有 PostgreSQL 集群的团队
  • 需要在 Docker Compose、裸机 systemd 或 Kubernetes 环境中部署数据库控制平面的运维场景
  • 需要通过 gRPC 接口对集群管理能力做性能基准测试（内置 cmd/bench 工具）的开发者
📖 README 首段存档原文 · 程序抽取

Skylex is a self-hosted database control plane. It automates provisioning, replication, backups, and high availability for PostgreSQL clusters — without handing your data to a cloud vendor.
