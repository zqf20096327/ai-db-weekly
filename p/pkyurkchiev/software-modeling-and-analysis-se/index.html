普罗夫迪夫大学软件建模与分析课程仓库，含数据建模课件

综述（解读层）

该仓库是普罗夫迪夫大学软件工程专业软件建模与分析课程的配套资源，提供数据建模原理、课件与练习安排。课程按周推进，覆盖概念/逻辑/物理模型、规范化与反规范化、数据仓库、多维模型、NoSQL 及商业智能等主题。练习需要自备工具，具体工具未在 README 中列出。仓库采用 MIT 许可证，问题可通过 issue 反馈。

  • 提供按周组织的课程结构与演示课件，涵盖概念、逻辑、物理数据模型及规范化流程
  • 主题包括数据仓库、多维数据库模型、表格式数据库、数据流图、NoSQL 与商业智能
  • 列出课程的知识与技能目标，如识别模型元素、定义关系与业务规则、通过规范化实现数据完整性

适用场景（解读层）

  • 学习数据建模的理论与形式化流程
  • 了解数据库课程内容组织方式
  • 准备课程作业与考核要求相关的练习
