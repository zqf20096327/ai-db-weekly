通过 SQLite 触发器将表变更记录到独立历史表的 Python 库

综述（解读层）

sqlite-history 是一个 Python 库，用于在 SQLite 数据库上配置触发器，将表的插入、更新、删除操作记录到独立的历史表中。可通过 configure_history() 函数或 python -m sqlite_history 命令行启用，支持 --all 为全部表配置。历史表包含 _version、_updated（毫秒时间戳）和 _mask 位掩码等字段，-1 表示删除。适用于需要在 SQLite 层面留存行级变更记录的开发者。

  • 通过触发器捕获表的插入、更新、删除操作并写入独立历史表
  • 提供 Python API（configure_history）和 CLI（python -m sqlite_history）两种启用方式，支持 --all 配置全部表
  • 历史表包含 _version 递增版本号、_updated 毫秒时间戳、_mask 列变更位掩码，_mask 为 -1 表示删除

适用场景（解读层）

  • 需要记录 SQLite 表行级变更历史的场景
  • 通过 SQL 查询历史表追溯某行多次更新及变更列
  • 无原生审计机制的 SQLite 应用中补充变更记录
