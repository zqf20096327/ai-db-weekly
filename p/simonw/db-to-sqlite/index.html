🧭 简介解读层（AI·证据行可回查）

命令行工具，通过 SQLAlchemy 将任意 SQL 数据库的表或查询导出为 SQLite 文件

综述（解读层）

db-to-sqlite 是一个 Python 命令行工具，用于将数据库中的表数据或自定义 SQL 查询结果导出到 SQLite 文件。它基于 SQLAlchemy 连接源数据库，支持 PostgreSQL、MySQL、MS SQL 等数据库，--all 模式可复制整库并检测外键关系。需通过 pip 安装，使用 MySQL/PostgreSQL 时需额外安装对应依赖。

  • 支持 --table 导出指定表、--all 导出全部表并可 --skip 跳过指定表
  • --sql 选项可将自定义查询结果写入目标表，并用 --pk 指定主键
  • 导出全部表时自动检测并添加外键关系，支持 --postgres-schema 指定非默认 schema

适用场景（解读层）

  • 将 PostgreSQL/MySQL 等数据库的表数据复制为本地 SQLite 文件
  • 把自定义 SQL 查询结果保存为 SQLite 表以便离线查看
  • 结合 heroku config 获取连接串，导出 Heroku Postgres 应用的数据
