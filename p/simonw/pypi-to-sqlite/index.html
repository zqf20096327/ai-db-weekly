从 PyPI 抓取 Python 包数据并写入 SQLite 的命令行工具

综述（解读层）

pypi-to-sqlite 是一个 Python 命令行工具，用于从 PyPI 读取指定包的元数据并写入 SQLite 数据库。使用 pip 安装，命令中可直接传入包名，也支持用 -f 参数读取此前保存到本地的 PyPI JSON 文件。工具创建 packages、versions、releases 三张表，可通过 --prefix 添加表名前缀。适合需要将 PyPI 包信息存入 SQLite 做查询或配合 Datasette 浏览的用户。

  • 支持按包名从 PyPI 获取数据，也支持读取已保存的 JSON 文件
  • 创建 packages、versions、releases 三张表存储包信息
  • 提供 --prefix 选项为表名添加前缀

适用场景（解读层）

  • 将 PyPI 包元数据导入 SQLite 数据库
  • 对离线保存的 PyPI JSON 数据建库查询
  • 在 Datasette 中浏览 PyPI 包数据表
