操作 SQLite 数据库的 Python CLI 工具与库

综述（解读层）

sqlite-utils 是一个 Python 命令行工具和库，用于操作 SQLite 数据库。它支持将 JSON/CSV/TSV 数据导入数据库并自动创建表结构，对文件数据运行内存 SQL 查询，配置全文检索，执行 ALTER TABLE 不直接支持的表结构变更，以及通过 Python 迁移文件管理数据库迁移。可通过 pip 或 Homebrew 安装，也可作为 Python 库导入使用。

  • 支持将 JSON、CSV、TSV 数据直接导入 SQLite 数据库文件并自动创建相应表结构
  • 支持对 CSV、TSV 或 JSON 文件数据运行内存 SQL 查询（含 join），并支持按相关度排序的全文检索查询
  • 支持 SQLite ALTER TABLE 不直接支持的表结构变更（如修改列类型）、列提取规范化以及基于 Python 迁移文件的数据库迁移，并可通过插件扩展自定义 SQL 函数

适用场景（解读层）

  • 将 curl 获取的 API JSON 数据或本地 CSV 文件导入 SQLite 数据库
  • 用单条命令对 CSV/JSON 文件数据运行 SQL 查询并以 JSON、CSV 或表格形式输出结果
  • 在 Python 代码中以库的方式创建表、插入数据和管理 SQLite 数据库
