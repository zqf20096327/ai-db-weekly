将 FEC 竞选财务申报数据导入 SQLite 数据库的命令行工具

综述（解读层）

fec-to-sqlite 用于将美国 FEC 竞选捐款申报数据写入 SQLite 数据库，基于 Evan Sonderegger 的 fecfile 构建。用户通过 pip 安装后，运行命令并传入申报文件 ID 即可获取数据，工具会自动创建所需的表结构，也可在一条命令中传入多个 ID 批量导入。适用于需要本地保存和查询 FEC 申报数据的用户。

  • 通过命令行按申报文件 ID 抓取 FEC 竞选财务数据并存入 SQLite 数据库
  • 自动创建所需的数据库表结构
  • 支持在单条命令中传入多个申报文件 ID 批量导入

适用场景（解读层）

  • 将指定 FEC 申报文件的数据保存为本地 SQLite 数据库
  • 批量导入多个 FEC 申报文件用于后续查询
  • 配合 Datasette 等工具浏览已生成的 SQLite 数据库
