🧭 简介解读层（AI·证据行可回查）

连接 MarkLogic 数据库 REST API 的 Java 客户端，用于文档读写、删除与查询

综述（解读层）

MarkLogic 官方 Java 客户端库，用于对 MarkLogic 数据库中的文档执行写入、读取、删除和查找操作。需连接 MarkLogic REST API 应用服务器，适合基于该 REST API 构建应用的 Java 开发者。8.0.0 版本要求 Java 17 或 21，经 Maven 或 Gradle 引入依赖即可使用。

  • 支持写入和读取 binary、JSON、text、XML 四类文档
  • 支持部分更新（Patch）、乐观锁检测以及单语句 ACID 修改和多语句事务
  • 支持通过 Java 接口调用服务器端点实现的数据服务（Data Services）

适用场景（解读层）

  • Java 应用中对 MarkLogic 数据库文档进行增删改查
  • 从层次化文档中投影值、元组、三元组并进行聚合
  • 基于 MarkLogic REST API 构建 Java 应用
