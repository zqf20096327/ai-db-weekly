面向 Node.js 的 MySQL 数据库对象映射连接框架

综述（解读层）

Database Jones 是 Oracle MySQL 团队提供的 Node.js 数据库应用框架，通过对象映射层将 JavaScript 对象映射到关系表，提供 mysql 与 ndb 两个适配器，后者基于 NDBAPI 操作 MySQL Cluster。包含测试工具、性能基准、数据加载器等子项目。mysql 适配器依赖 node-mysql；ndb 适配器需 MySQL Cluster 并用 node-gyp 编译 C++ 代码。

  • 提供基于 JavaScript 对象到关系表映射的 CRUD API 与流式查询语言
  • 支持显式与隐式 ACID 事务、连接池及 Promises/A+ 异步模式
  • 包含 mysql 与 ndb 两种适配器，后者通过 NDBAPI 访问 MySQL Cluster

适用场景（解读层）

  • 在 Node.js 应用中读写已有 MySQL 表
  • 基于 MySQL Cluster 构建数据库应用
  • 使用 Jones 开发数据加载、基准测试或命令行数据库工具
