MySQL 官方 .NET ADO.NET 驱动，纯 C# 实现的 MySQL 协议客户端库

综述（解读层）

MySQL Connector/NET 是 Oracle 提供的 .NET Framework 与 .NET Core 兼容类库，用于客户端应用程序连接 MySQL 数据库。驱动以纯 C# 实现 MySQL 协议，不依赖 MySQL 客户端库。8.0 起包含 MySQL X DevAPI，支持以 Document Store 方式进行 CRUD 式 NoSQL 操作。许可证为 GPLv2 及 FOSS 例外，可通过 NuGet、MySQL Installer 安装或从源码编译。

  • 纯 C# 实现 MySQL 协议，不依赖 MySQL 客户端库
  • 包含 ADO.NET 接口与 MySQL X DevAPI（CRUD 式 NoSQL 文档操作）
  • 支持 WebAuthn 认证、TLS 1.3，并提供 OpenTelemetry 集成（需 MySql.Data.OpenTelemetry 包）

适用场景（解读层）

  • 在 .NET / .NET Core 应用程序中通过 ADO.NET 连接 MySQL 数据库
  • 通过 X DevAPI 以文档存储方式对 MySQL 执行 CRUD 操作
  • 需要 EF Core 访问 MySQL 的实体框架项目
