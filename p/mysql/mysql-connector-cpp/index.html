MySQL 官方 C++ 连接器，用于 C/C++ 应用连接 MySQL 服务器

综述（解读层）

MySQL Connector/C++ 是 MySQL 服务器与 C++/C 应用之间的通信接口。应用开发者可通过包含 mysqlx/xdevapi.h 头文件编写连接 MySQL 的代码。它可从预编译包安装，也可从源码构建；当前 RPM 发行版不再包含 ABI 9 兼容包，依赖旧 ABI 的应用需保留旧包或重新构建。

  • 提供 C++ 接口，支持 C++ 和 C 应用连接 MySQL 服务器
  • 支持从预编译包安装或从源码构建
  • 提供 X DevAPI 示例代码、API 参考文档及讨论区/Slack/Bugs 渠道

适用场景（解读层）

  • C++ 或 C 应用程序需要连接和操作 MySQL 服务器
  • 需要将连接器集成到构建流程中的项目（源码构建）
  • 部署环境中使用预编译二进制包快速安装连接器
