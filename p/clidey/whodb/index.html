综述（解读层）

WhoDB 是一个用 Go 与 React/TypeScript 编写的自托管数据库工作区，可在浏览器、桌面应用或终端 CLI 中运行。它支持 PostgreSQL、MySQL、MongoDB、Redis、ClickHouse 等多种数据源，提供电子表格式数据编辑、交互式模式图、多单元格查询草稿板、导入导出与模拟数据生成，并可选接入 Ollama、OpenAI 等提供英文问答。通过 Docker 一行命令即可启动，默认监听 8080 端口。

  • 支持 20 种左右的数据源，涵盖关系型、文档型、键值型、搜索与列存数据库，不同数据源能力有所差异
  • 提供电子表格式数据网格（排序、筛选、分页、内联编辑）、交互式模式关系图和多单元格查询草稿板
  • 可选接入 Ollama、LM Studio、OpenAI、Anthropic 等 AI 提供商，CLI 内置交互式终端界面与 MCP 服务器

适用场景（解读层）

  • 在本地或自托管环境中浏览、检查并内联编辑数据库数据
  • 通过模式关系图理解陌生数据库的表结构与表间关系
  • 借助 MCP 服务器将数据库访问接入 AI 工具，或在终端使用 CLI 进行查询操作
