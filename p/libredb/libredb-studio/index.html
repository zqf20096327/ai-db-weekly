开源多数据库 Web 版 SQL IDE，部署在数据旁，统一界面管理多种数据库

综述（解读层）

LibreDB Studio 是一个 MIT 许可的开源 Web 端数据库编辑器，用于在浏览器中访问 PostgreSQL、MySQL、Oracle、SQL Server、MongoDB、Redis、SQLite、ClickHouse 等多种数据库。它以容器方式部署在数据所在环境中而非本地笔记本，支持 SSO、审计日志和 AI 辅助查询。可通过 Docker 一条命令或 npx 运行，首次启动的 admin 密码打印在日志中；非 localhost 或 HTTPS 访问需设置 AUTH_COOKIE_SECURE=false，否则登录会静默失败。

  • 支持 PostgreSQL、MySQL、Oracle、SQL Server、MongoDB、Redis、SQLite、ClickHouse、DuckDB 等多种数据库，共用一个浏览器界面
  • 提供 SSO（OIDC）、审计日志和 AI 辅助查询功能，采用 MIT 许可证
  • 可通过 Docker、npx、Helm、Homebrew、Snap、winget、deb/rpm 等多种方式安装部署，支持 Kubernetes

适用场景（解读层）

  • 团队需要一个部署在数据侧的 Web 数据库管理工具，避免为每台机器安装桌面客户端
  • 需要带 SSO 和审计日志的自托管数据库访问入口
  • 快速查看托管平台上创建的数据库内容，不想暴露端口或搭建 SSH 隧道
