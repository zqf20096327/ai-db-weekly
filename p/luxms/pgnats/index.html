🧭 简介解读层（AI·证据行可回查）

pgnats 是基于 pgrx/Rust 的 PostgreSQL 扩展，用于在 SQL 中操作 NATS 消息系统。

综述（解读层）

pgnats 是一个用 Rust 编写的 PostgreSQL 扩展，通过 pgrx 构建打包。它提供向 NATS 主题发布消息（二进制/文本/JSON/JSONB）、订阅主题并触发 PostgreSQL 函数、Request 请求、JetStream KV 存储和对象存储读写等 SQL 接口，并通过 FDW 形式的 Foreign Server 配置连接。订阅回调函数须接受单个 bytea 参数。支持按 feature（kv、sub、object_store）裁剪构建，最低要求 Rust 1.88.0。

  • 提供 nats_publish_binary/text/json/jsonb 与 nats_request 等 SQL 函数用于 NATS 消息收发
  • 支持 nats_subscribe 将 NATS 主题订阅绑定到接受 bytea 参数的 PostgreSQL 函数，并包含与 Patroni 的 HTTP 集成（sub 特性）
  • 通过 JetStream 实现 KV 存储与对象存储操作，支持按 kv/object_store/sub 特性选择性构建，可在 Postgres 集群上运行

适用场景（解读层）

  • 在 SQL 中直接向 NATS 发布事件或通过 KV/Object Store 读写 JetStream 数据
  • 订阅 NATS 主题并在消息到达时调用 PostgreSQL 函数处理载荷
  • 需要裁剪构建体积时按功能特性（KV、订阅、对象存储）单独编译
