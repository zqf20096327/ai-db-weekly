通过 RPC 暴露 database/sql 数据库并提供对应 SQL 驱动的 Go 包

综述（解读层）

sqlrpc 是一个 Go 包，提供 RPC 服务端以暴露任意 database/sql 的 *DB，并附带可连接该服务的 SQL 驱动，主要动机是暴露 SQLite3。项目附带 cmd/sqlite3server，默认监听 6033 端口，通过 --dsn 参数传入数据源名称；服务端可改用于其他数据库。使用方需在 Go 客户端中导入该驱动包后通过 database/sql 连接。

  • 可将任意 database/sql 的 *DB 通过 RPC 服务暴露，并附带配套的 SQL 驱动用于连接
  • 提供 cmd/sqlite3server 程序，默认在 6033 端口提供 RPC 服务，通过 --dsn 指定 SQLite 数据源
  • 服务端实现可适配到 SQLite 以外的其他数据库

适用场景（解读层）

  • 需要通过 RPC 远程访问 SQLite3 数据库
  • 在 Go 程序中通过 database/sql 接口连接远程 SQL 服务
  • 为其他 database/sql 兼容数据库搭建类似的 RPC 暴露服务
