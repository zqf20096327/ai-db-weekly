🧭 简介解读层（AI·证据行可回查）

基于单个 SQLite 文件的 AI 代理本地持久化记忆库

综述（解读层）

remembrane 是面向 AI 代理的本地优先持久化记忆组件，将全部记忆存于一个 SQLite 文件，默认嵌入器为纯标准库实现、无必装依赖。提供向量加 BM25 的精确混合检索、基于时间衰减和重要性的排序、冲突检测、时间旅行日志、token 预算装填，并通过 LangChain/CrewAI 适配器和 MCP 服务器集成。默认嵌入器相似度为词法层面，语义检索需另接模型。

  • 精确混合检索：对每条记忆同时计算向量相似度与 BM25 关键词得分，支持确定性、可复现的召回行为
  • 提供基于 journal 的记忆历史：snapshot、diff、as_of 等接口可查询任意时点的记忆状态
  • 内置 MCP 服务器暴露 9 个工具（store/recall/forget/reinforce/conflicts/resolve/feedback/pack/stats），并提供 CLI 与 pytest 测试断言模块

适用场景（解读层）

  • 为 MCP 兼容代理（如 Claude Desktop/Code）提供本地持久化记忆服务
  • 通过 LangChain 或 CrewAI 适配器为框架内代理接入记忆层
  • 在 CI 中以确定性断言单元测试代理的记忆行为
