基于 Promise 的 Node.js ORM 库，面向 MySQL、Postgres 与 SQL Server

综述（解读层）

OpenSql 是一个 JavaScript 编写的 Node.js ORM 库，用于简化 SQL 代码的编写，支持 MySQL、Postgres 和 Microsoft SQL Server 三种数据库。项目提供 Getting Started 快速上手文档与 API 文档，采用 MIT 许可证发布，并公开征集社区贡献。

  • 提供基于 Promise 的 API，用于 Node.js 环境
  • 支持 MySQL、Postgres 和 Microsoft SQL Server 三种数据库
  • 包含 Getting Started 文档与 API 文档

适用场景（解读层）

  • Node.js 项目中对 MySQL、Postgres 或 SQL Server 的数据访问层开发
  • 希望以库方式编写 SQL 代码而非手写 SQL 语句的场景
