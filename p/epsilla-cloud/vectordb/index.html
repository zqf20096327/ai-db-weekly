开源向量数据库，核心以 C++ 实现并行图遍历向量索引

综述（解读层）

Epsilla 是一个开源向量数据库，核心用 C++ 编写，采用并行图遍历技术做向量索引，README 称其在保持 99.9% 以上精度的同时检索速度较快。它提供数据库、表、字段等概念，向量仅作为一种字段类型。可通过 Docker 部署并用 Python 客户端或 REST API 访问；Python 直接嵌入库方式为实验性功能。

  • 支持嵌入向量的相似度搜索、元数据过滤以及稠密与稀疏向量融合的混合搜索
  • 内置嵌入生成能力，提供自然语言输入输出的检索方式
  • 提供 Python/JavaScript/Ruby 客户端与 REST API，并与 LangChain、LlamaIndex 集成

适用场景（解读层）

  • 为大语言模型应用提供向量存储与检索能力
  • 需要对嵌入向量做元数据过滤或混合搜索的生产场景
  • 作为 DBaaS 之外的自托管向量数据库部署
