基于 MCP 协议的 Java 数据库反向工程代码生成服务器

综述（解读层）

DBJavaGenix 是一个 MCP 服务器，读取 MySQL、PostgreSQL、SQLite 的表结构与外键关系，经 Skill 定义的 5 阶段工作流生成 Spring Boot 的 Entity/DAO/Service/Controller/DTO/Mapper 分层代码。提供 34 个工具与 4 个 MCP Apps UI 组件。Oracle 与 SQL Server 尚未实现运行时支持。需 Python ≥ 3.11，可用 Docker 运行，MIT 许可。

  • 提供 34 个 MCP 工具，包含连接查询、表结构读取、schema 图算法与 7 个原子代码生成工具，context 显式传递
  • 支持 progressive discovery 模式，README 称启动 token 开销可从约 3300 降至约 985；AI 语义工具在无 ANTHROPIC_API_KEY 时以规则模式运行
  • 包含 4 个 MCP Apps UI 组件（Mermaid ER 图、依赖仪表盘、code-diff、包结构树）及 server_metrics/server_health 可观测工具，含 620+ 单元测试与 Dockerfile

适用场景（解读层）

  • 在 Claude Desktop、Cursor 等 LLM 客户端中连接 MySQL/PostgreSQL/SQLite，由 LLM 按工作流生成 Spring Boot 分层代码
  • 通过 db_render_er_diagram 与 schema_topo_order/cluster/cycles 工具查看和分析数据库表结构关系
  • 批处理或 CI 场景使用 agentic runner（需 claude-agent-sdk 与 ANTHROPIC_API_KEY）执行一次性代码生成任务
