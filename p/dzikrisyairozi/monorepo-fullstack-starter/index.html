基于 Turborepo 的全栈项目模板，含 Next.js 前端与 Rust/Axum 后端

综述（解读层）

这是一个使用 Turborepo 管理的全栈项目启动模板，包含四个应用：Next.js 15 的 Web 与文档站点、Rust (Axum + SQLx) 后端 API、React (TanStack Router) 管理面板，以及共享 UI/i18n/ESLint 等包。面向需要快速搭建全栈项目的开发者，通过模板复制后用 pnpm install 与 cargo sqlx database setup 即可运行；需要 Node.js 22+ 与 PostgreSQL。

  • 包含 web、docs、dashboard 三个前端应用与 api（Axum + SQLx）一个 Rust 后端，共享 @repo/ui、@repo/i18n 等 6 个内部包
  • 内置 ESLint、Prettier、Husky、Commitlint、GitHub Actions CI/CD，支持 Docker 构建部署
  • @repo/ui 提供 40+ shadcn/ui 组件；支持英/印尼双语 i18n 与深浅色模式；@repo/api-types 从 Rust API 自动生成 TS 类型

适用场景（解读层）

  • 需要同时开发前端、文档站、管理面板与 Rust 后端的全栈项目
  • 希望以 monorepo 方式统一管理多应用的团队项目
  • 需要 Docker 或 Vercel/Railway 部署的应用启动底座
