🧭 简介解读层（AI·证据行可回查）

包裹 SQL 数据库的协作后端，自动生成 REST/GraphQL API 与可视化管理界面。

综述（解读层）

Directus 连接现有 SQL 数据库（Postgres、MySQL、SQLite 等），依据数据库模式自动生成 REST 和 GraphQL API，并提供可视化 Studio 与内嵌 AI 助手、原生 MCP 服务器。可自托管或使用云服务。适用于需要让非技术人员和 AI 代理直接操作数据库数据的团队。采用 MSCL 1.0 源码可用许可证，营收低于 500 万美元且员工少于 50 人的组织可在 Open Innovation Grant 下免费使用。

  • 根据数据库模式自动生成 REST 和 GraphQL API，无需额外配置
  • 内置 MCP 服务器，AI 代理与人共用同一套基于角色的字段级权限策略
  • 支持自定义端点、钩子、接口和模块进行扩展

适用场景（解读层）

  • 将现有 SQL 数据库转换为无头 CMS
  • 为非技术团队成员提供数据管理与可视化后台
  • 通过 MCP 让 AI 代理在权限策略约束下访问实时数据
