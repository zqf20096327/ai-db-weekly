🧭 简介解读层（AI·证据行可回查）

仿 psql 的通用 SQL 数据库命令行客户端，用 Go 实现

综述（解读层）

usql 是一个用 Go 编写的通用命令行数据库客户端，交互模型仿照 PostgreSQL 的 psql，支持 psql 的变量、反引号、反斜杠命令等核心特性，并额外提供跨数据库复制、上下文补全和终端图表功能。它面向需要在非 PostgreSQL 数据库上使用 psql 式操作界面的管理员和开发者，可通过 Release、Homebrew、AUR、Go、Docker 安装，且能用构建标签裁剪内置驱动。

  • 支持 PostgreSQL、MySQL、Oracle、SQL Server、SQLite3 等 50 余种数据库的连接协议（scheme），包含关系型、NoSQL 与非关系型数据库
  • 提供变量、反引号、反斜杠命令、上下文补全、终端图表渲染及数据库间数据复制功能
  • 通过 go build 标签（no_、no_drivers、no_charts 等）可自定义构建时包含的驱动集合

适用场景（解读层）

  • 需要在同一命令行工具中连接多种不同数据库的日常运维与开发
  • 希望在非 PostgreSQL 数据库上使用 psql 风格交互界面（变量、反斜杠命令）的场景
  • 通过 Docker 镜像或自定义构建标签在容器或受限环境中运行特定数据库客户端
