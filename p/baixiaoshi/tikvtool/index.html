🧭 简介解读层（AI·证据行可回查）

TiKV 键值数据的交互式命令行工具，提供 vim 风格的前缀浏览与 CRUD 操作

综述（解读层）

TiKV Tool 是一个用于浏览和管理 TiKV 键值数据的交互式命令行应用，通过 PD 端点连接集群，支持按键前缀搜索键、查看与编辑值，并提供增删改查操作。界面采用 vim 风格按键绑定，基于 Bubble Tea 构建终端 UI，使用 tikv client-go 连接集群，需 Go 1.21 以上构建。适合需要在终端内直接检查和操作 TiKV 数据的运维与开发人员。

  • 支持按前缀实时搜索浏览 TiKV 键，提供创建、读取、更新、删除（CRUD）操作
  • 界面采用 vim 风格按键绑定，分主模式、搜索、详情、编辑、添加五种模式
  • 自动识别并以 JSON、YAML、TOML 或纯文本格式展示值，支持一键复制键值到剪贴板

适用场景（解读层）

  • 通过 PD 端点连接 TiKV 集群，在终端内交互式查看和检索键值数据
  • 对 TiKV 中的指定键进行删除、修改或新增操作
  • 以 JSON/YAML/TOML 等格式查看存储值并将键或值复制到剪贴板
