🧭 简介解读层（AI·证据行可回查）

基于单一 SQLite 事件表的本地自托管事件日志记忆库，经 MCP 供代理读写。

综述（解读层）

Open Brane 是一个自托管的事件日志存储，将笔记、项目检查点、会话决策等归一化写入一张仅追加的 SQLite `events` 表，提供 Web 界面、文本搜索与 MCP 接口（stdio 与 Bearer 认证 HTTP）供本地代理读取与写入。核心记录与搜索无需 LLM 或向量库；语义搜索依赖可选的 Ollama 与 Qdrant。仅追加为应用层约定，需自行备份数据库。

  • 全部数据写入单一 append-only 的 SQLite events 表，仅经 record_event.py 一条写入路径，修正通过追加引用先前事件 ID 实现
  • 提供本地 stdio 与带 Bearer token 的 HTTP 两种 MCP 接口，工具包括 workspace_overview、read_saved_project、save_work_session、resume_work_session 等
  • 核心记录与文本搜索仅依赖 Python 3.11+ 标准库及少量外部依赖；Ollama/Qdrant 语义检索为可选组件；提供 governance、recall_traces、edges 三个可选附加 SQL 模式

适用场景（解读层）

  • 跨会话保存与恢复代理工作上下文：记录会话决策、阻塞项、来源与下一步动作，供后续会话或代理读取
  • 为个人代理网格提供持久记忆层：代理通过 MCP 写入与检索事件，检索可记录 trace 以观察使用情况
  • 将多来源数据（GDrive 等，可按 ADAPTERS.md 扩展）归一化为事件流，再按需重建 Obsidian 页面、仪表盘等派生视图
