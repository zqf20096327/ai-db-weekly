开源 Web 与产品分析平台，基于 ClickHouse 与 PostgreSQL

综述（解读层）

Vemetric 是一个开源的 Web 与产品分析平台，用于了解用户在网站或产品上的行为。功能包括实时分析、用户旅程行为追踪、自定义事件与跨子域名追踪。部署方式以官方托管为主，自托管的 Community Edition 尚在规划中，采用 AGPLv3 许可证，代码可商用使用。

  • 提供实时分析与自定义事件追踪
  • 通过用户旅程记录用户行为，并支持过滤机制查看交互情况
  • 支持跨多个子域名的追踪

适用场景（解读层）

  • 网站访问数据分析
  • 产品内用户行为与交互路径分析
  • 跨多个子域名站点的用户追踪
