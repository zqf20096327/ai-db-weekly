Kafka Connect SMT 转换器，用于 TiDB 到 Postgres 的 BIT/ENUM 类型转换

综述（解读层）

该项目实现了一个 Kafka Connect 单消息转换（SMT），处理 TiDB 数据同步到 Postgres 时 BIT 与 ENUM 类型的转换：BIT 经 bytea 转为二进制串再写入 Postgres BIT 列。以 Maven 编译打包为 jar，复制到 Kafka Connect 插件目录后重启加载，通过在 JDBC Sink 连接器配置 transforms 中指定字段名、类型和长度来启用。适用于使用 Confluent JDBC Sink 将 TiDB 数据写入 Postgres 的数据管道场景。

  • 以 Kafka Connect SMT 形式实现 TiDB BIT/ENUM 到 Postgres 的类型转换
  • BIT 转换链路：bytea(java) → binary string → Postgres BIT
  • 通过 Maven 编译，产出的 jar 复制到 Kafka 插件目录重启加载

适用场景（解读层）

  • 通过 Kafka Connect JDBC Sink 将 TiDB 数据同步到 Postgres 时处理 BIT 列
  • 同步链路中需要对 ENUM/SET 类型做映射转换的场景
