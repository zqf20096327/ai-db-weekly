演示 Hibernate 使用 TiDB SEQUENCE 生成主键的 Java 示例项目

综述（解读层）

该项目是一个示例程序，展示在 Hibernate ORM（5.2.11、Java 8）中如何让 TiDB 的 CREATE SEQUENCE 为实体生成主键。README 给出建库建序列、修改 hibernate.properties 连接配置、以 ./gradlew run 运行的完整步骤，并附建表与插入数据的验证 SQL。代码由 tidb-hibernate-example 改编。适用于需要在 TiDB 上验证 Hibernate 序列映射的开发者。

  • 提供基于 Java 8 与 hibernate-core 5.2.11 的可运行示例代码，含 Example.java 源码链接
  • 通过 hibernate.properties 配置 TiDB4Dialect 与 MySQL JDBC 连接
  • README 包含创建 SEQUENCE、运行应用及查询生成数据的完整 SQL 步骤

适用场景（解读层）

  • 学习在 Hibernate 实体中映射 TiDB SEQUENCE 生成主键
  • 验证 TiDB 集群与 Hibernate ORM 的序列功能集成
  • 作为 TiDB 相关 Hibernate 示例项目的改造起点
