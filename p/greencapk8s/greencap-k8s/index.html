轻量级 Kubernetes Web 管理平台，通过 UI 运维集群资源

综述（解读层）

GreenCap K8s 是一个基于 Java 21 与 Spring Boot 3.3 的 Web 平台，用于以界面方式管理 Kubernetes 集群，面向学习、开发与测试 Kubernetes 的个人和中小团队。它通过 Fabric8 客户端连接 minikube、kind、托管或自建集群，提供工作负载、网络、存储等资源的浏览与操作；每个非管理员用户绑定独立 ServiceAccount，权限由集群 RBAC 控制。注意它不是集群生命周期工具，仅管理集群内部资源。

  • 提供四种引导式部署向导：容器镜像、Docker Compose 导入、Dockerfile（Kaniko 在集群内构建）、Helm Chart
  • 支持多用户访问，每个非管理员用户通过专属 ServiceAccount 由 Kubernetes RBAC 授权
  • 包含交互式拓扑图，展示所有权、路由、存储关系及推断的服务间依赖

适用场景（解读层）

  • 个人或中小团队通过一条脚本在本地（minikube）快速搭建带管理平台的集群环境
  • 通过 kubeconfig 或 API Server URL + bearer token 接入已有的 minikube、kind、托管或自建集群，在 UI 中执行扩缩容、重启、回滚、查看日志等操作
  • 无需手写 YAML，通过向导从镜像、Compose 文件、Dockerfile 或 Helm Chart 部署应用
📖 README 首段存档原文 · 程序抽取

GreenCap is a web platform for operating Kubernetes through a UI instead of a terminal. One command (./setup/setup.sh) brings up a local cluster with GreenCap running on it — the fastest way to start.
