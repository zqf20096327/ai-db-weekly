基于 C++20 的业务应用开发平台，用元数据描述生成 ERP 应用

综述（解读层）

OES 是一个面向库存、会计、工资等业务应用开发平台，用 C++20 编写。开发者以元数据描述业务对象（目录、单据、登记簿、科目表），用内置脚本语言编写规则，平台据此生成数据库表、表单和报表。提供设计器、编译器、调试器、应用服务器、集群和 MCP 工具。当前为 2.0.0-preview.1，数据库格式可能变化，不支持从 1.x 迁移。

  • 提供查询语言（含寄存器虚拟表）、报表设计器（支持导出 Excel/Word）与带 LINQ 的脚本语言（双方言共用一个编译器，106 个内置函数）
  • 包含设计器、WebSocket 远程调试器、对象级与行级访问控制、基于 diff 的模式变更（含 Firebird 两阶段提交补偿）
  • 内置 MCP 服务器，提供 135 个工具供 AI 助手读写元数据、运行代码、查询数据和驱动调试器

适用场景（解读层）

  • 开发库存、会计、工资、销售等记账类业务应用程序
  • 需要 AI 助手通过 MCP 参与读取、构建和检查应用的开发流程
  • 通过应用服务器、集群和 Web 客户端部署多用户业务系统
