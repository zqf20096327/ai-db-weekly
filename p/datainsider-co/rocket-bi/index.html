面向分析型数据库的开源 Web 自助式 BI 平台

综述（解读层）

Rocket BI 是 DataInsider 体系的核心产品，是一个基于 Web 的自助式商业智能工具，用于数据分析、可视化和协作。它针对 Clickhouse、BigQuery、MySQL、PostgreSQL、Vertica 等分析型数据库设计，可通过 Docker 快速本地部署（默认端口 5050），也可用 Java 8/Maven 和 Node.js 从源码构建服务端与 Web 客户端。

  • 提供 SQL 即席查询（含函数与自动补全）、拖拽式图表构建器和交互式仪表盘，支持仪表盘过滤、图表控件与数据下钻
  • 提供无代码 ETL 数据建模、行级安全控制、计算字段、跨表关系构建等能力
  • 支持 Clickhouse、BigQuery、Vertica、MySQL、PostgreSQL 等多种数据连接器，可分享链接或授权实现协作

适用场景（解读层）

  • 团队需要连接 Clickhouse/BigQuery 等分析型数据库进行数据探索与可视化报表时
  • 业务人员希望通过无代码方式完成数据加载、转换与仪表盘搭建时
  • 需要对不同行级数据设置访问权限并在组织内分享仪表盘时
