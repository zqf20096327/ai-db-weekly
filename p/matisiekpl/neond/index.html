基于 Neon 的开源 PostgreSQL 控制平面守护进程

综述（解读层）

NeonD 是基于 neondatabase/neon 构建的 PostgreSQL 控制平面，以单个 Docker 容器运行，提供分支、S3 检查点、秒级 PITR、TLS SNI 路由、内置 PgBouncer 和 Web 控制台。面向早期创业项目等非关键业务负载，官方建议部署在裸金属 VPS 上，每台服务器仅运行一个实例。

  • 支持 PostgreSQL v14-v17，可从生产时间线创建开发/预览分支，支持秒级时间点恢复
  • 数据以检查点方式写入 Amazon S3，检查点间隔可配置；支持导入外部 PostgreSQL 到新分支
  • 单容器部署，内置 PgBouncer 连接池，提供基于 {instance-slug}.domain 的 TLS SNI 路由，内置 pgvector、PostGIS 及 contrib 扩展

适用场景（解读层）

  • 在小 VPS 上快速搭建自托管的多租户 PostgreSQL 实例管理平台
  • 为开发/预览环境从生产时间线创建分支数据库
  • 将外部 PostgreSQL 数据库导入并纳入分支与 PITR 管理
