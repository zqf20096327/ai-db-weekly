pgAdmin3 v1.22 的续维护分支，为 PostgreSQL 新版本扩展功能

综述（解读层）

该项目是已停止维护的 pgAdmin3 v1.22 的 fork，在其基础上添加对 PostgreSQL 新版本（12–18）的功能支持，修改查询执行、执行计划、服务器监控和日志查看等界面，并将部分图标转为 SVG。面向继续使用 pgAdmin3 的 PostgreSQL/PostgresPro 用户。部分新功能依赖 amcheck、pg_query_state 等扩展；仅支持 64 位版本，声明支持的操作系统为 Alt Linux 和 Windows。

  • 基于 pgAdmin3 v1.22 分支，支持 PostgreSQL 12 至 18 及 PostgresPro Enterprise，使用 wxWidgets 3.0 编译
  • 提供查询结果 Excel 导出、结果过滤与多列排序（最多 5 列）、跨服务器对象比较并生成 HTML 报告、CSV 日志查看窗口等功能
  • 支持过程、分区（树中显示）、publications 等新版本对象的显示；btree 索引检查需在目标库安装 amcheck 扩展

适用场景（解读层）

  • 继续在 Windows 或 Alt Linux 上使用 pgAdmin3 界面管理较新版本 PostgreSQL 数据库
  • 通过 Server Status 窗口监控进程阻塞情况并通过 CSV 日志窗口查看数据库日志
  • 比较不同服务器上对象的定义差异并生成 HTML 差异报告
