🧭 简介解读层（AI·证据行可回查）

Rust 编写的图数据库，内置向量检索与 BM25 全文搜索，基于对象存储。

综述（解读层）

HelixDB 是 Apache 2.0 开源的图数据库，以带标签属性图存储实体、关系、嵌入与文本，在同一事务引擎中支持图遍历、向量近邻检索和 BM25 搜索的组合查询。提供 Rust、TypeScript、Go、Python 四种 SDK，可嵌入进程内运行、本地/自托管服务器（内存、磁盘或 S3 兼容对象存储）或使用托管云服务；源码构建还支持通过 openCypher 配置文件执行读和 CRUD 操作。本地开发需 Docker 或 Podman。

  • 在单一事务引擎中原生存储实体、关系、嵌入向量与文本，图与向量写入一起提交或回滚
  • 向量搜索可由图遍历预过滤，将相似度检索限定在指定节点范围内
  • 提供 Rust、TypeScript、Go、Python SDK，通过 POST /v2/query 统一发送 JSON 请求；源码构建支持 openCypher 读与 CRUD

适用场景（解读层）

  • AI 应用的记忆与检索：长期 agent 记忆、GraphRAG 与混合 RAG
  • 连接文档、人员、工具和决策的内部知识图谱
  • 自托管或嵌入式的图+向量+全文一体化数据存储
