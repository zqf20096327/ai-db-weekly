基于 PostgreSQL 实现 MySQL 方言与协议兼容的数据库系统

综述（解读层）

openHalo 是 Halo Tech 开源的数据库系统，在 PostgreSQL 基础上实现 MySQL 的 SQL 方言与通信协议，使面向 MySQL 编写的应用程序（5.7 及以上迁移）在少量修改代码的情况下连接使用。需通过源码编译安装，配置 database_compat_mode='mysql' 并创建 aux_mysql 扩展后，可用 mysql CLI 以 3306 端口访问。README 中关于性能的表述为其自称，未附基准数据。

  • 支持常用 MySQL SQL 方言与通信协议，可用 mysql CLI、驱动和查询工具连接
  • 通过 database_compat_mode 配置项提供 mysql 兼容模式
  • 提供源码编译安装流程，并配有开源迁移工具 HMT 用于迁移 schema 与数据

适用场景（解读层）

  • 将运行于 MySQL 5.7 或更新版本的应用迁移至 PostgreSQL 体系
  • 减少应用中涉及数据库调用的代码改写
  • 沿用现有 MySQL 命令行工具与驱动进行开发运维
