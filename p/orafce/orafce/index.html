在 PostgreSQL 中实现 Oracle 兼容函数与包的 C 扩展

综述（解读层）

orafce 是一个 PostgreSQL 扩展，用 C 语言实现 Oracle 数据库中缺失或行为不同的部分函数和包，包括日期函数、oracle.date 数据类型、dual 表等，内置日期函数曾对照 Oracle 10 验证，日期范围为 1960 至 2070 年。它面向需要将 Oracle 应用迁移或移植到 PostgreSQL 的开发者。使用 oracle 模式下的函数需设置 search_path 包含 oracle 模式；1582-10-05 之前的 'J' 格式日期及 1100-03-01 之前的其他格式日期因 Oracle 本身的缺陷无法验证，默认会报错，可通过 GUC 关闭。

  • 提供 add_months、last_day、next_day、months_between、trunc、round、to_date、to_char 等兼容 Oracle 的日期函数
  • 实现 oracle.date 数据类型及配套函数与加减日期运算符，支持 to_date 中 Oracle 特有的 RR/RRRR 格式元素
  • 包含 oracle 模式下的 dual 表，可通过 orafce.nls_date_format 等 GUC 配置行为

适用场景（解读层）

  • 将基于 Oracle 的应用程序迁移或移植到 PostgreSQL
  • 在 AWS Aurora（PostgreSQL 兼容版）或 Azure Database for PostgreSQL 上运行依赖 Oracle 函数的应用
  • 需要 Oracle 风格日期处理（如 sysdate、months_between、dual 表查询）的 PostgreSQL 环境
