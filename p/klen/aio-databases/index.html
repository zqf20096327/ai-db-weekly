综述（解读层）

aio-databases 是一个 Python 异步数据库访问库，支持 SQLite、PostgreSQL、MySQL，兼容 asyncio 与 trio。它通过统一的 Database 接口封装 aiosqlite、aiopg、asyncpg、aiomysql 等驱动，提供连接获取、查询执行、事务管理和连接池功能，并支持只读副本路由。要求 Python >= 3.10，除驱动外无其他依赖，通过 pip 安装并按所选驱动附加 extras。

  • 支持 asyncio 与 trio，适配 aiosqlite、aiopg、asyncpg、aiomysql、trio-mysql 等驱动
  • 提供连接池、事务管理及断线后自动重连（失败查询不重试，错误继续抛出）
  • 支持副本路由：replica 块内 execute 触发 ReadOnlyError，fetch 查询正常，事务被阻止，副本块内可嵌套主连接

适用场景（解读层）

  • 在 asyncio 或 trio 应用中以统一接口访问多种数据库
  • 需要连接池和事务管理的异步服务
  • 配置读写分离，将只读查询路由到副本连接
