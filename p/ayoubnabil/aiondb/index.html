Rust 编写的数据库，实现 PostgreSQL 线协议并集成向量与图访问路径

综述（解读层）

AionDB 是用 Rust 从零实现的数据库，通过 PostgreSQL 线协议接受 psql 及常见驱动连接，使用自有存储引擎将行写入磁盘，并在同一 catalog 上提供向量与图访问路径。当前为 v0.5 Alpha，README 明确声明不可用于生产数据。许可证为 Business Source License 1.1，每个发布会在变更日期或发布后四年转换为 Apache 2.0。

  • 支持表、谓词、连接、事务、索引及 PostgreSQL catalogs，兼容 pgvector 的 VECTOR(n)/HALFVEC(n) 列类型
  • 提供 HNSW 与 IVF-flat 向量索引，支持 L2、余弦、内积、L1 距离；节点标签与边标签建立在普通表之上
  • 提供 aiondb init 引导设置、serve --config 文件配置、健康检查、指标、dump/restore 及 Docker Compose 部署

适用场景（解读层）

  • 通过 psql 或 PostgreSQL 驱动访问同时包含行、向量与图数据的存储
  • 在 pgvector 兼容的向量列上运行 HNSW/IVF-flat 相似度查询
  • 本地开发环境测试 Alpha 阶段的 SQL、向量与图混合查询能力
