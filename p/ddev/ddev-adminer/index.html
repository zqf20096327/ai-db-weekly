🧭 简介解读层（AI·证据行可回查）

将 Adminer 数据库管理工具集成到 DDEV 项目的 add-on

综述（解读层）

该 DDEV add-on 通过 `ddev add-on get` 安装 Adminer，作为 Web 界面管理项目数据库。安装后通过 `ddev adminer` 在浏览器访问（端口 9101），支持 MySQL、MariaDB、PostgreSQL 和 SQLite。SQLite 连接需通过 .env.adminer 配置默认驱动和文件路径（挂载于 /mnt/ddev_app），且要求数据库文件属主与 Adminer 运行用户一致。可通过环境变量自定义设计主题、插件和 Docker 镜像等选项。

  • 支持 MySQL、MariaDB、PostgreSQL 和 SQLite 四种数据库
  • 提供 `ddev adminer` 命令直接在浏览器打开管理界面（端口 9101）
  • 通过 .ddev/.env.adminer 支持自定义默认数据库、驱动、设计主题、插件及 Docker 镜像

适用场景（解读层）

  • 在 DDEV 本地开发环境中浏览和管理项目数据库
  • 通过 Web 界面查看或编辑 SQLite 文件数据库
  • 按项目需求配置 Adminer 的默认连接参数与插件
