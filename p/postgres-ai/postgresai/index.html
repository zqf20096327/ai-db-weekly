面向人类和 AI Agent 的 PostgreSQL 可观测性工具，提供健康检查与监控栈。

综述（解读层）

postgresai 是一个 CLI 工具与监控栈，提供 PostgreSQL 健康检查、45+ 指标采集和 Grafana 仪表盘，输出结构化 JSON 供 LLM 消费，并附带 Claude Code 插件和 MCP server。Express 模式需 Node.js 18+、PostgreSQL 14-18；完整监控栈需 Linux 加 Docker。可通过 --no-upload 离线运行，不必连接 console.postgres.ai。

  • 提供 45+ 健康检查项，覆盖 bloat、索引、查询、配置与安全；支持 --check-id 运行单项检查
  • 监控栈基于 pgwatch v3 + VictoriaMetrics 采集指标，并包含 13+ 个 Grafana 视图；诊断查询设计有超时、行数上限等防护措施
  • 输出结构化 JSON 报告，提供 Claude Code 插件和 MCP server，支持将检查结果管道传给 LLM 分析

适用场景（解读层）

  • 对 PostgreSQL 实例运行即时健康检查，生成包含建议修复项的 JSON 报告
  • 在 Linux 服务器上以 Docker 部署持续监控栈，通过 Grafana 仪表盘查看多实例指标
  • 在 Claude Code、Cursor 等工具中通过插件或 MCP server 处理检查结果与 Issues
