Java 版 Eloquent ORM，提供 ActiveRecord、查询构造器与原生 SQL 支持

综述（解读层）

这是一个面向 Java 应用的 Eloquent ORM 实现，发布于 Maven Central。每张数据表对应实体（Entity）与模型（Model），通过模型类进行增删改查并映射到 Java 对象。支持 Java 8/11/17/21/23 与 Spring Boot 2.x/3.x，兼容常见数据源及 JDBC 支持的数据库。引入 database-spring-boot-starter 依赖并配置 datasource 后，可使用预置的 GeneralModel 直接查询。

  • 提供 ActiveRecord 实现、查询构造器与原生 SQL 三种数据库操作方式
  • 通过声明式注解实现数据映射与关联关系（Relationship）声明
  • 提供 Generate 代码生成，自动为数据表创建实体与模型

适用场景（解读层）

  • Spring Boot 2.x/3.x 项目中的数据库访问层开发
  • 需要为现有数据表自动生成实体与模型代码的场景
  • 同一代码库需运行于多个 Java 版本（8-23）的项目
