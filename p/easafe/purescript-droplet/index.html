🧭 简介解读层（AI·证据行可回查）

PureScript 的类型安全 eDSL 与查询映射库，面向 PostgreSQL。

综述（解读层）

purescript-droplet 为 PureScript 提供针对 PostgreSQL 的组合式类型安全 eDSL 与查询映射器。其组合子与 SQL 语法对应，生成的 SQL 与 eDSL 一一对应；查询结果自动映射到记录类型。表定义、类型声明与迁移可借助 pebble 自动化，pg 包装代码源自 purescript-postgresql-client。适合在 PureScript 项目中编写类型检查的 SQL 查询的开发者。

  • 提供由组合子构成的 eDSL，支持 SELECT/INSERT/UPDATE/DELETE 及连接、聚合、子查询等常见 SQL 操作
  • 查询结果自动映射到记录，合法查询无需类型标注
  • 通过 pebble 支持表迁移

适用场景（解读层）

  • 在 PureScript 应用中执行 PostgreSQL 查询
  • 以类型安全方式编写包含连接与子查询的 SQL
  • 配合 pebble 管理数据库表结构与迁移
