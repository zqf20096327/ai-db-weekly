Titanium 应用中 SQLite 数据库的 CommonJS 封装库，以 JavaScript 对象风格操作数据

综述（解读层）

jssql 是面向 Titanium 应用开发的 CommonJS 模块，封装 Ti.Database，提供 get/set/update/delete 等方法以 JavaScript 对象风格访问 SQLite。支持回调或同步返回、JOIN 查询、Blob 取图、由 JSON 字符串建表及表结构检查。README 明确说明它不是 Alloy Models 的替代品，MIT 协议发布。

  • 提供 get/set/update/delete/countRows 等方法，支持同步返回或传入回调两种调用方式
  • 支持 JOIN 查询、getLastId/getLastEntry、从 Blob 列读取图片、由扁平 JSON 字符串创建表
  • 包含 addColumn、drop、tableExists、exec（执行 SQL 字符串）及关闭连接等辅助方法

适用场景（解读层）

  • Titanium 应用中需要以 JS 对象风格读写本地 SQLite 数据库
  • 从 Web Service 获取 JSON 数据后存入本地表并进行检索或处理
  • 需要从数据库 Blob 列读取图片并直接用于界面显示
