将大数据集分片到多个小型 SQLite 库协同查询的 Python 系统

综述（解读层）

Trough 是 Internet Archive 开发的数据分片系统，把大 dataset 按选定分片键拆分为多个 SQLite 文件，在集群上协同查询。设计上依赖磁盘存储而非大量 CPU/内存，最坏性能可通过最大分片本地加载来预估。配置量少，代码规模可供单人审计；曾附带的 ansible 部署示例现移到历史分支，针对 Ubuntu 16.04 节点。

  • 支持按选定键将大数据集分片为多个 SQLite 数据库并协同查询
  • 依赖扁平 SQLite 文件进行存储与分发，而非依赖大量 CPU/内存
  • 最坏情况性能可通过将最大分片本地加载来预先确定

适用场景（解读层）

  • 需要在普通集群上查询大规模数据集的场景
  • 希望以较少配置部署数据分片查询系统的团队
  • 对最坏情况查询性能有预估需求的存储型数据服务
