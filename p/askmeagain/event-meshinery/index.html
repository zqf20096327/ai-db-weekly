状态存储无关的异步事件/多步任务编排框架

综述（解读层）

Event Meshinery 是一个用于构建长时间运行、多步骤异步处理任务的框架，通过任务定义将事件路由到各处理步骤。核心机制是弃用分区内顺序处理保证、以 RoundRobin 调度器并发执行，从而缓解长阻塞调用（如 REST 调用）对分区的占用。模块按 core、Spring 集成、监控（Prometheus/OpenTelemetry）及 MySQL/Postgres/Kafka/PubSub 连接器拆分，也可不用 Spring 单独使用。

  • 支持 Kafka、MySQL、Postgres、PubSub 等状态存储连接器，并可自定义实现
  • 基于 Java Futures 的异步处理，由 RoundRobinScheduler 分发任务，支持连续与批处理模式
  • 提供 Spring 自动配置、Prometheus/OpenTelemetry 监控集成及自动生成事件关系图

适用场景（解读层）

  • 需要在 Kafka 等消息流中执行长时间阻塞调用（如 REST 请求）而不阻塞分区其他消息的场景
  • 需要跨多种状态存储（如 Kafka 与 MySQL）桥接事件信号的应用
  • 多步骤长运行业务流水线的结构化编排与监控
