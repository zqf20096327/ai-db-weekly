Go 编写的通用指标数据采集与转发框架

综述（解读层）

Skogul 是 Telenor NMS 开源的 Go 语言指标/数据搬运工具，既可作为采集器，也主要用作采集端与存储端之间的桥接框架。其核心机制是链式配置：接收器收数据，经解析器、转换器处理后由发送器写出，支持 HTTP、UDP、Kafka 等接收方式及 InfluxDB、SQL 等存储目标，通过 JSON 配置文件组装，并提供 RPM、Docker 镜像和源码构建三种安装方式。

  • 提供五种模块类型：接收器、发送器、解析器、编码器和转换器，通过 JSON 配置组装成数据处理链
  • 支持 HTTP、UDP、Kafka、文件、SQL 等接收方式，以及 InfluxDB、SQL、MQTT 等外部发送目标
  • 提供批量、路由、复制等内部逻辑发送器，可将同一数据写入新旧多个存储系统

适用场景（解读层）

  • 在更换存储引擎时保持采集端不变，将指标数据从采集器桥接到新旧存储系统
  • 构建多数据中心环境下的指标数据接收、转换与路由管道
  • 对采集到的指标数据进行批量、按元数据分流或复制到多个目标
