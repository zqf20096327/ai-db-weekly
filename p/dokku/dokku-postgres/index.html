Dokku 官方 Postgres 插件，以 Docker 容器运行 Postgres 服务

综述（解读层）

该插件为 Dokku 平台提供 Postgres 服务管理能力，默认安装 postgres 18.6，要求 dokku 0.35.x+ 与 docker 1.8.x。通过 postgres:create 等命令创建服务，支持指定后端（docker/compose）、镜像版本、环境变量、网络与内存限制等参数，并提供 backup 等 service 子命令，面向使用 Dokku 部署应用的开发者。

  • 通过 dokku plugin:install 一条命令安装，默认安装 postgres 18.6
  • postgres:create 支持指定执行后端（docker 或 compose）、自定义镜像及版本、环境变量、docker 网络与标签等启动参数
  • 提供 postgres:backup 命令，可将服务备份到已有 s3 bucket，并支持 IAM 认证与多数据库备份

适用场景（解读层）

  • 在 Dokku 托管的应用旁创建和管理 Postgres 数据库服务实例
  • 为 Postgres 服务配置基于 s3 的数据库备份及 AWS 认证
  • 按需定制服务容器（镜像版本、内存限制、日志驱动、挂载等）的部署参数
