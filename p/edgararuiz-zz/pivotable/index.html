R 包，用管道函数以代码方式生成透视表并复用维度/度量定义

综述（解读层）

pivotable 是一个 R 包，通过 pivot_rows()、pivot_columns()、pivot_values() 等函数以代码而非拖拽方式构建透视表，支持 pivot_flip() 行列互换、pivot_drill() 层级下钻、焦点筛选与总计控制。基于 dplyr 实现，可运行于数据库、Spark 和 data.table 后端。项目标注为 experimental 生命周期，安装需通过 remotes 从 GitHub 获取。适合需要在 R 中以可复现代码生成报表分析的用户。

  • 通过管道串联 pivot_rows()/pivot_columns()/pivot_values() 以代码构建透视表，支持 flip、focus、drill 操作
  • 可用 prep_dimensions()/prep_measures() 预定义维度与度量，实现集中化数据定义与复用
  • 基于 dplyr 聚合命令，支持数据库、Spark 与 data.table 后端；可经 to_pivottabler() 转出 pivottabler 对象

适用场景（解读层）

  • 在 R 中以代码方式创建行列分组、聚合的透视表并下钻日期层级
  • 将维度/度量定义集中管理，供多个报表复用保持口径一致
  • 直接对数据库、Spark 或 data.table 连接的数据执行聚合分析
