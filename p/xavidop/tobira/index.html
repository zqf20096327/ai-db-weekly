单二进制终端工具，统一浏览、查询和解释多种数据库并内置只读防护

综述（解读层）

tobira 是一个用 Go 编写的 CLI 与终端 UI 工具，用于连接 SQL、文档、键值、时序、向量等多种数据库。二进制内含 32 个驱动，支持跨连接联邦查询、TUI 浏览编辑、查询输出 JSON/CSV、SSH 隧道、MCP 服务器与 AI 助手；每个驱动前有只读防护，密码经 env/file/keyring 引用而不落盘。适合需要统一管理多种数据库连接的开发者与运维人员。

  • 二进制内置 32 个驱动，覆盖 PostgreSQL、MySQL、MongoDB、Redis、ClickHouse、Qdrant 等，另支持外部驱动插件
  • 内置只读防护，写操作被拒绝并返回退出码 4；支持跨连接的联邦查询，各源以原生只读查询运行并由 SQLite 本地合并
  • 提供 tobira query（JSON/NDJSON/CSV 输出与明确退出码）、tobira mcp 服务器、tobira ask AI 助手和 tobira doctor 环境检查

适用场景（解读层）

  • 在终端中统一浏览、查询和编辑多种类型数据库的生产数据（开启只读防护）
  • 在脚本和 CI 流水线中以结构化输出（JSON/CSV）运行查询并检查环境配置
  • 将选定的数据库连接通过 MCP 接入 Claude Code、Cursor 等 AI 编码代理
