本地 Git 备份的 Markdown 记忆库，供 Claude Code 与 Codex 共享

综述（解读层）

这是一个本地优先的长期记忆库系统，用 Markdown 作为唯一事实源，SQLite 提供结构与全文检索，可选 EmbeddingGemma 加 Zvec 实现本地语义搜索。仓库只含模板、脚本和虚构示例，真实记忆留在用户私有本地库中。写入流程分 read-target、prepare、apply 三步，带提案哈希、fencing token 与会话租约机制，检索端提供 outline/section 分段读取，安装支持 macOS/Linux 与 Windows 10/11 脚本，要求 Python 3.10+ 与 Git。

  • Markdown 为源，SQLite 结构化/全文检索，可选 Zvec 本地语义搜索（混合 RRF 融合 Unicode FTS、trigram FTS）
  • Claude Code 与 Codex 共享同一 vault、Git 历史与索引，通过 memoryctl CLI 以各自 actor/会话身份调用
  • 写入使用内容绑定意图、提案哈希、单调 fencing token 与 closeout，提供 outline/section 分段读取

适用场景（解读层）

  • 多个 AI 编码代理共享同一份长期项目记忆、决策与工作流记录
  • 需要 Git 历史回滚与可审计写入流程的本地记忆管理
  • 用 Obsidian 或任意编辑器浏览与维护结构化 Markdown 记忆目录
