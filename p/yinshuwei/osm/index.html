仅依赖 Go 标准库的轻量级 ORM，用 SQL 模板与参数绑定操作数据库

综述（解读层）

osm（Object SQL Mapping）是一个用 Go 编写的 SQL 工具库，供需要在 Go 程序中直接书写 SQL 的开发者使用。它通过 #{ParamName} 语法实现命名参数绑定，自动转换为各数据库占位符格式，也支持原生占位符直传驱动；结果可映射到结构体、基本类型切片或键值对，并提供传统与闭包两种事务模式。安装方式为 go get github.com/yinshuwei/osm/v2。

  • 仅依赖 Go 标准库，支持 MySQL、PostgreSQL、SQL Server、SQLite、Oracle、TiDB、CockroachDB、ClickHouse 八种数据库
  • 支持 #{ParamName} 命名参数绑定（顺序参数、Map、Struct、IN 查询）与原生占位符模式，按 SQL 内容自动检测
  • 提供 Struct/Value/Kvs/ColumnsAndData 等多种结果接收方法，支持 db 标签、嵌套结构体与指针类型的 NULL 映射

适用场景（解读层）

  • 在 Go 项目中直接书写 SQL 并进行结构体映射，而不引入第三方 ORM 依赖
  • 同一套 #{ParamName} 风格 SQL 需要运行在多种数据库（如 MySQL 与 PostgreSQL）上的场景
  • 需要表前缀替换、环境 Schema 切换或用闭包事务自动提交/回滚的数据库操作
