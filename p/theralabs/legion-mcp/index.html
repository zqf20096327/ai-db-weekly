🧭 简介解读层（AI·证据行可回查）

基于 MCP 协议的 Python 数据库查询服务器，统一接入多种数据库

综述（解读层）

这是 Legion AI 发布的数据库 MCP 服务器，通过 Legion Query Runner 连接 PostgreSQL、MySQL、SQL Server、Oracle 等 9 类数据库。它将数据库操作暴露为 MCP 资源、工具和提示，供 AI 助手调用查询。支持单库或多库同时连接，配置可通过环境变量、命令行参数或 JSON 完成，多库时需用 db_id 指定目标。许可证为 GPL。

  • 通过 Legion Query Runner 支持 PostgreSQL、MySQL、SQL Server、BigQuery、Oracle、SQLite 等 9 种数据库类型，可同时连接多个数据库
  • 暴露 execute_query、find_table、describe_table 等 10 个 MCP 工具及 sql_query、select_database 等 4 个提示，查询结果可输出为 markdown 表格或 JSON
  • 支持环境变量、命令行参数和 MCP settings JSON 三种配置方式，可通过 uvx 或 pip 安装运行

适用场景（解读层）

  • 为需要数据库访问能力的 AI 助手或代理提供 MCP 工具接口
  • 同时连接多个异构数据库，通过 list_databases、find_table 定位并查询特定表
  • 使用 MCP Inspector 进行本地开发调试，或与 FastAPI 等环境集成部署
