基于 SQL Server Change Tracking 同步数据库变更的服务与库

综述（解读层）

SyncChanges 提供 Windows 服务、控制台工具和 .NET 库三种形态，读取源库 Change Tracking 记录并将增删改复制到多个目标库。面向只有 Web/Express 等不支持内置复制功能的版本、需要单写多读同步的场景。要求源库为 SQL Server 2008 以上并启用 Change Tracking，建议开启快照隔离；目标库自动创建 SyncInfo 表记录版本，外键约束通过延迟插入或临时禁用处理。

  • 支持控制台应用、Windows 服务和 NuGet 库三种使用方式，配置文件可指定复制的表、超时、间隔和批大小
  • 仅依赖 Change Tracking，源库可用所有版本（含 Web/Express），目标库无需启用 Change Tracking
  • 通过延迟插入、延迟删除和同事务内禁用/恢复外键约束处理外键依赖，无需手动关闭约束

适用场景（解读层）

  • 源库为单一写入库、多个只读目标库需周期性保持一致的单向同步部署
  • 仅使用 SQL Server Web/Express 等版本、无法使用 Mirroring/Replication/AlwaysOn 的环境
  • 通过任务计划程序定时调用或以服务按轮询间隔自动执行变更复制的运维场景
