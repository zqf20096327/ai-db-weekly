🧭 简介解读层（AI·证据行可回查）

自托管 Web 端 Active Directory 管理工具，通过 LDAPS 读写域控制器

综述（解读层）

OpenADUC 是替代 MMC「AD 用户和计算机」管理单元的自托管 Web 应用，面向中小 IT 团队，通过 LDAPS 对域控制器读写用户、计算机、组、OU。缓存、会话与审计日志存于 PostgreSQL（内嵌或外部），支持一键脚本或 docker compose 部署。当前为 beta，采用 BSL 1.1 许可，需 Node 22；自身不含 TLS 与应用层 MFA。

  • 支持通过 LDAPS（或 StartTLS）执行密码重置、账户解锁、组成员与属性管理
  • 审计日志为仅追加模式，数据库触发器拒绝 UPDATE/DELETE/TRUNCATE
  • 写操作需重新输入 AD 密码进行二次认证，静态机密用 AES-256-GCM 加密

适用场景（解读层）

  • 中小规模（约 10,000 对象以内）AD 域的浏览器端日常管理
  • 需要记录每次变更操作者与内容的审计场景
  • 通过管理 VLAN、跳板机或 VPN 访问的内网运维部署
