综述（解读层）

DBConvert Streams 是一个包含数据库 IDE、数据迁移与实时 CDC 的桌面/自托管工作台。用户可浏览数据库、本地文件与 S3，运行跨数据源的联邦 SQL，执行 INSERT/UPDATE/DELETE 的实时流同步，并通过内置 MCP 服务器向 Claude、Cursor 等 AI 客户端提供 27 个只读工具。IDE 部分免费，迁移与 CDC 功能需付费；本仓库为文档与示例，核心产品为专有软件。

  • 提供联邦 SQL 查询，可在 PostgreSQL、MySQL 与 CSV/JSON/Parquet 文件及 S3 之间直接 JOIN
  • 支持基于日志的实时 CDC，将 INSERT/UPDATE/DELETE 操作从源端流式同步到数据库、文件或 S3 目标
  • 内置 MCP 服务器，包含 27 个只读工具（连接、Schema、SELECT、流诊断、文件与 S3），服务端仅放行 SELECT

适用场景（解读层）

  • 跨多个数据库引擎与文件/S3 数据源执行联合查询与数据浏览
  • 数据库间大批量迁移（Load Mode），含自动 Schema 转换与校验
  • 为 Claude、Cursor、VS Code Copilot 等 MCP 客户端接入实时 Schema、数据与流状态的只读访问
