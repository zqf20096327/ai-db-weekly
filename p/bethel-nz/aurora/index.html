Rust 嵌入式数据库，内建类 GraphQL 查询语言、实时订阅与任务队列

综述（解读层）

Aurora 是一个以 crate 形式嵌入 Rust 应用的持久化数据库，无需独立服务进程。它提供 Fluent Rust API 和类 GraphQL 语法的 AQL 两种查询方式，并集成了响应式查询、PubSub、带优先级的后台任务队列与版本化迁移机制。底层采用内存 LRU 热缓存加 Sled 冷存储、WAL 日志的分层架构。适合希望在单个二进制内获得存储、查询与作业队列能力的 Rust 开发者。当前版本 0.5/0.6 阶段，API 可能变动。

  • 提供 AQL（类 GraphQL 语法）与 Fluent Rust API 两种查询接口，支持过滤、游标分页、聚合与分组
  • 支持响应式查询、PubSub 集合监听与 AQL subscription 订阅
  • 内置持久化优先级任务队列，含 Low 至 Critical 四级优先与 DeadLetter 状态

适用场景（解读层）

  • 嵌入 Rust 单体应用或 CLI 工具的本地数据存储
  • 需要文档变更实时通知的场景，如订单状态监听、界面数据联动
  • 应用内后台作业处理，如邮件发送等异步任务
