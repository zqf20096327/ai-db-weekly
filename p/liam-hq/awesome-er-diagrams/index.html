收录开源项目ER图的清单，展示各项目的关系型数据库结构

综述（解读层）

该项目库汇集开源项目的实体关系图（ERD），按沟通社交、财务管理、文档管理、位置追踪等类别组织，每条记录附带表数量、数据库、外键数等元信息，并提供源码链接。面向想通过图表了解开源项目数据库设计的学习者与贡献者。收录项目均为活跃维护的代码库。

  • 收录 Mastodon、Maybe、DocuSeal、Dawarich 等项目的 ER 图，标注表数量、PostgreSQL、外键数、主键类型等元信息
  • 按应用领域分类组织条目，每条附源码链接
  • README 列出社交网络、财务管理、文档签署、位置追踪四个类别共 4 个项目

适用场景（解读层）

  • 阅读开源项目数据库结构，辅助了解代码库以参与贡献
  • 参考不同项目的表结构、外键与数据类型设计
  • 对比多个项目的 schema 设计以学习数据库建模
