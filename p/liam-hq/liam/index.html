🧭 简介解读层（AI·证据行可回查）

从数据库 schema 文件自动生成可交互 ER 图的工具

综述（解读层）

Liam ERD 读取现有数据库 schema 文件（README 提及 Rails 的 schema.rb，主题标签包含 Prisma 与 PostgreSQL），自动生成可交互的实体关系图，支持平移、缩放和筛选操作。公开仓库可通过在 GitHub 文件 URL 前插入 liambx.com/erd/p/ 前缀生成图表；私有仓库需运行 npx @liam-hq/cli init 完成交互式设置。项目采用 Apache 2.0 许可证，基于 Node.js 生态。

  • 从数据库 schema 文件反向工程生成实体关系图，支持平移、缩放、筛选等交互操作
  • 公开仓库无需配置，通过修改 schema 文件的 GitHub URL 前缀即可生成 ER 图；私有仓库提供 npx @liam-hq/cli init 交互式设置
  • README 说明支持包含 100+ 表的项目，采用 Apache License 2.0 开源

适用场景（解读层）

  • 为公开 GitHub 仓库中的 Rails schema.rb 或 Prisma schema 文件生成在线 ER 图用于文档展示
  • 在私有仓库中通过 CLI 对现有数据库 schema 进行可视化查看
  • 浏览含大量表（README 称可达 100+ 表）的数据库 schema 结构，借助缩放与筛选定位表及其关系
