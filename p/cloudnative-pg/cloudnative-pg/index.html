🧭 简介解读层（AI·证据行可回查）

Kubernetes 上的 PostgreSQL 管理平台，以 Operator 直连 K8s API 实现全生命周期运维

综述（解读层）

CloudNativePG（CNPG）是用于在 Kubernetes 环境中管理 PostgreSQL 数据库的开源平台，由 CloudNativePG operator 实现从部署到持续维护的完整生命周期管理。它面向 Kubernetes 管理员，不依赖 Patroni、repmgr、Stolon 等外部高可用工具，而是直接集成 Kubernetes API，以 Operator 模式自动调和 Cluster 资源声明的目标状态。项目仅支持 CNCF 维护的原生 Kubernetes 与 PGDG 维护的原生 PostgreSQL，不支持 PostgreSQL 分支版本和其他数据库，可通过 CNPG-I 插件接口扩展。现为 CNCF 孵化项目，最初由 EDB 构建并赞助。

  • 提供故障转移管理：主实例失败时选举新主实例并编排切换过程
  • 支持通过声明式副本数伸缩只读副本，自动管理持久卷、Secret、ConfigMap 及流复制
  • 定义 Backup、Database、Pooler、ScheduledBackup、Publication、Subscription 等多个 Kubernetes 自定义资源

适用场景（解读层）

  • 在 Kubernetes 上以 GitOps 驱动的 CI/CD 流程部署和维护 PostgreSQL 主/备集群
  • 需要通过 Kubernetes API 直接检查数据库集群状态并自动化日常 DBA 操作的运维场景
  • 仅使用原生 PostgreSQL、希望以 Operator 模式管理故障转移和副本伸缩的团队
