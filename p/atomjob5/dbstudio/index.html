🧭 简介解读层（AI·证据行可回查）

基于浏览器工作台与本地 Java 服务的桌面数据库管理工具，支持 MySQL、Oracle、OceanBase。

综述（解读层）

DBStudio 将 Vue 3 + Monaco 前端与 Spring Boot 后端打包为单个可执行 JAR，通过系统浏览器打开，运行在本机的 127.0.0.1 上。它提供 SQL 编辑、流式查询执行、对象浏览与连接管理，当前支持 MySQL 8、Oracle 19c/21c 及 OceanBase Oracle 兼容模式；数据库差异通过 SPI 模块隔离，新增数据库类型无需修改编辑器工作台。适合需要在本地管理多种 JDBC 数据库的开发与运维人员。

  • Monaco SQL 编辑器支持方言感知补全、诊断、格式化，查询通过 JDBC 流式执行并支持取消、历史记录与事务控制
  • 数据库提供方通过 SPI 架构隔离连接、元数据、SQL 方言与能力差异，可扩展新数据库
  • 服务绑定 127.0.0.1 随机端口，使用一次性认证 URL 交换 HttpOnly cookie，保存的密码存入 macOS Keychain 或 Windows 凭据管理器而非本地数据库

适用场景（解读层）

  • 在同一本地工具中管理 MySQL、Oracle 与 OceanBase（Oracle 兼容模式）连接并执行 SQL 脚本
  • 浏览表、视图、索引、触发器、存储过程等数据库对象，进行 CSV 导入与结果导出
  • 运行需要处理大结果集的查询，利用虚拟化表格、分页与批式 WebSocket 流式返回查看数据
