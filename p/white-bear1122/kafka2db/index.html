轻量级 Java 服务，将 Kafka 消息按配置批量写入 OceanBase 与 TDengine

综述（解读层）

kafka2db 是基于 Java 8 的数据同步服务，最多连接 10 个 Kafka 集群，按外置 YAML 配置的字段映射，把自定义分隔符格式（~ / ||）的消息解析后批量写入 OceanBase 或 TDengine，也可双库同时写入。写入失败按 1/2/4 秒重试，耗尽后消息落盘为 JSONL 失败文件；offset 手动提交保证幂等语义。适合已有固定报文格式、需落地上述两类数据库的团队。

  • 单实例最多连接 10 个 Kafka 集群，每个 Topic 可独立配置写入 OceanBase、TDengine 或两者
  • OceanBase 生成多值 upsert SQL，TDengine 生成多子表 INSERT 并自动创建子表
  • 数据库写入失败重试 3 次，耗尽后将原始消息落盘为 JSONL 失败文件；offset 手动提交

适用场景（解读层）

  • 将 Kafka 中的自定义分隔符格式明细消息批量同步到 OceanBase 表
  • 将 Kafka 消息按超级表结构写入 TDengine 子表（时序场景）
  • 单条消息需同时写入两个数据库且可接受无分布式事务的双库写入
📖 README 首段存档原文 · 程序抽取

本服务同时连接最多 10 个 Kafka 集群。每个集群可以订阅多个 Topic，并按 Topic 的外置映射配置，将一条 Kafka 消息中的全部明细批量写入 OceanBase、TDengine 或两个数据库。
