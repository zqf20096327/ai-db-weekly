定时轮询 FTP 目录并按 YAML 映射将解析数据写入 TDengine 与 OceanBase 的 Java 同步服务

综述（解读层）

ftpflow 是一个 Java 8 编写的同步服务，定时轮询 FTP 服务器上的多个目录，读取符合 xxx_yyy_yyyyMMddHHmmss.txt 命名规则的文件，解析后按 mapping.yaml 配置写入 TDengine（历史数据）和 OceanBase（最新数据）。适用于工业/物联网场景下 FTP 文本数据增量入库。依赖人工核对映射配置与库表结构，失败文件不自动重试。

  • 基于 checkpoint.json 记录各目录已处理的最大文件时间戳，只处理时间戳大于 checkpoint 的文件，checkpoint 以临时文件加原子重命名方式写盘
  • TDengine 写入按文件生成多子表批量 INSERT 并通过 USING 超级表 TAGS 自动建子表；OceanBase 写入按 uniqueKeyField 执行 ON DUPLICATE KEY UPDATE upsert，两库写入相互独立

适用场景（解读层）

  • 工业/物联网场景中 FTP 服务器上批量落地文本文件的增量入库
  • 同一份数据需要同时保留时序历史（TDengine）和最新状态（OceanBase）的存储分工
  • 文件类型与目标库表映射需要通过配置文件管理、不修改代码即可调整写库规则
