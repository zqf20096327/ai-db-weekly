基于 Boost.Asio 的 C++17 header-only PostgreSQL 异步通信库

综述（解读层）

OZO 是一个用于与 PostgreSQL 异步通信的 C++17 header-only 库，底层通过 libpq 与服务器通信，基于 Boost.Asio 构建。它借助模板元编程提供 C++ 类型到 SQL 的映射和查询构建能力，支持回调、future、协程等并发模式。适用于需要异步数据库访问的 C++17 项目。文档尚在建设中，需 Boost≥1.66 与 libpq≥9.3。

  • 支持回调、future、协程等多种并发模式，基于 Boost.Asio 实现
  • 提供 C++ 类型到 SQL 的映射与查询构建能力
  • header-only 库，底层通信依赖 libpq

适用场景（解读层）

  • 需要在 C++ 项目中异步访问 PostgreSQL 的场景
  • 需要通过模板元编程实现 C++ 类型与 SQL 查询映射的项目
  • 希望扩展或替换库内概念以适配特定项目需求的开发场景
