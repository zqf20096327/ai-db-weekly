🧭 简介解读层（AI·证据行可回查）

基于 Kopf 框架的 Kubernetes Operator，用于在 K8s 中运行 CrateDB 集群。

综述（解读层）

CrateDB Kubernetes Operator 通过自定义资源 CrateDB 在 Kubernetes 集群中部署和管理 CrateDB。它基于 Kopf 框架实现，要求 CrateDB 版本不低于 4.5。用户通过 YAML 声明节点数、CPU/内存、磁盘与 storageClass 等配置后用 kubectl 创建即可。支持 Helm 或 kubectl 两种安装方式，OpenShift 需额外配置环境变量并提供自建的 crate-control 镜像。

  • 支持 all equal nodes 与 master + data nodes 两种集群拓扑
  • 提供集群安全扩缩容与滚动版本升级
  • 通过 Let's Encrypt 证书为 HTTP 和 PG 连接启用 SSL

适用场景（解读层）

  • 在 Kubernetes 集群中声明式部署指定版本和资源规格的 CrateDB 集群
  • 需要对集群执行滚动升级或安全扩缩容的运维场景
  • 在 OpenShift 或多家云厂商多可用区环境中运行 CrateDB
