综述（解读层）

CrateDB 是一个分布式 SQL 数据库，用于存储并分析海量数据，基于 Lucene 实现，兼容 PostgreSQL 线协议。它通过标准 SQL 或 HTTP API 访问，支持动态表结构、对象类型、全文与地理空间查询，集群具备自动分片、分区、副本及自愈重平衡能力，主要面向时序与 IoT 数据分析等场景，可经 Docker 官方镜像运行。

  • 通过 PostgreSQL 线协议或 HTTP API 使用标准 SQL 进行查询
  • 支持时序数据、实时全文搜索、地理空间类型及文档式动态表结构与可查询对象
  • 具备自动分区、自动分片、自动复制以及自愈与自动重平衡机制，提供 Admin UI 管理界面

适用场景（解读层）

  • 海量数据的近实时分析与即时查询场景
  • IoT 与时序数据的存储和分析
  • 基于 Kubernetes 或虚拟机的水平扩展、无共享状态集群部署
