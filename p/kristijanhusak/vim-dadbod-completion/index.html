基于 vim-dadbod 的数据库自动补全 Vim 插件

综述（解读层）

该插件为 SQL 缓冲区提供表名与列名补全，依赖 vim-dadbod，支持 coc.nvim、deoplete、nvim-cmp、ddc、blink.cmp 等补全框架及内置 omnifunc。列补全具备上下文感知并读取别名，支持 PostgreSQL、MySQL、Oracle、SQLite（≥3.37.0）、SQL Server，通过 w/t/b/g 变量或 $DATABASE_URL 配置连接，并用缓存提升补全速度。

  • 自动补全表名并在需要时添加引号，覆盖 vim-dadbod 支持的所有 scheme
  • 上下文感知的列名补全，支持读取表别名，支持 PostgreSQL、MySQL、Oracle、SQLite（≥3.37.0）、SQL Server/MSSQL
  • 通过 :DBCompletionClearCache 命令清除表和列缓存，补全标记可用 g:vim_dadbod_completion_mark 自定义

适用场景（解读层）

  • 在 Vim/Neovim 中编写 SQL 时按连接的数据库结构补全表名与列名
  • 配合 vim-dadbod-ui 使用时从其缓冲区配置自动读取连接信息，无需额外设置
  • 通过 window/tab/buffer/global 变量或 $DATABASE_URL 为不同缓冲区指定不同数据库连接
