基于 DAG 的 SQL 数据库迁移 CLI 与 Go 库

综述（解读层）

Kat 将数据库 schema 迁移组织为有向无环图而非线性日志，每个迁移通过 up.sql/down.sql 声明依赖，由工具自动解析父节点并确定执行顺序。提供 kat add/up/down/export 等 CLI 命令及可嵌入的 Go 库，基于 Sourcegraph 的 sg CLI 与 golang-migrate 构建，支持 PostgreSQL 和 SQLite，配置经 kat.conf.yaml 定义，采用 Apache 2.0 许可。

  • 将 schema 视为 DAG，迁移间支持显式依赖与确定性排序
  • 提供 CLI 命令集（init/add/up/down/ping/export/version）与 Go 库两种使用方式
  • kat export 可将迁移图导出为 DOT 格式；支持 PostgreSQL 与 SQLite

适用场景（解读层）

  • 多名开发者并行编写迁移、需要显式声明依赖的团队
  • 需要将迁移管理嵌入 Go 应用（通过 go:embed）的项目
  • 需要以 DOT 格式可视化迁移依赖图的数据库工程流程
📖 README 首段存档原文 · 程序抽取

Graph-based SQL migrations. Kat treats your schema as a DAG, not a linear log — enabling parallel development, explicit dependencies, and deterministic ordering. Supports PostgreSQL and SQLite.
