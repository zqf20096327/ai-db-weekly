Raku 语言的 ORM 库，通过 traits 声明模型并生成 SQL

综述（解读层）

Red 是 Raku 语言的 ORM 库，处于开发中（WiP）状态。它通过 `is column`、`is id`、`is referencing` 等 traits 将 model 类映射为数据库表，将 Raku 方法调用转换为 SQL 查询，支持关系推断、命名索引、约束、事务与保存点。通过 zef 安装，需 rakudo 2018.12 之后版本，PostgreSQL 需单独安装驱动发行版。实验性迁移功能 API 可能变动，SQLite 表重建需手写 SQL。

  • 通过 traits（is column、is id、is serial、is relationship 等）声明模型与表结构，自动生成对应 SQL
  • 提供实验性 `red migration` 命令，用于生成、验证与应用版本化的 schema 与数据迁移，回滚依赖可用的逆操作
  • 支持嵌套保存点事务、命名/复合/部分索引、CHECK 与 PostgreSQL EXCLUDE 约束，索引可按 Pg/SQLite/MySQL 后端分别声明

适用场景（解读层）

  • 在 Raku（rakudo）项目中以 model 对象方式读写关系数据库记录
  • 需要对 schema 变更做版本化迁移管理并纳入版本控制的项目
  • 需要在 PostgreSQL 等多后端间声明差异索引与约束的 Raku 应用
