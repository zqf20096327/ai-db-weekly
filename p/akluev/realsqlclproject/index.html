Oracle SQLcl Project 部署模式的文档集与工作流仓库

综述（解读层）

该仓库收录围绕 Oracle SQLcl Project 的部署指南、模式与可复用工作流，覆盖开发到生产的端到端流程、漂移检测、APEX 复杂部署、热修复流程与安全建议，文档位于 /docs 目录。面向 Oracle APEX/PL/SQL 开发者、DBA 与 DevOps 团队，采用 MIT 许可并接受 issue 与 PR 贡献。

  • 提供开发→测试→生产的端到端部署工作流，含 CI/CD 与非 CI/CD 两种方式
  • 包含漂移检测与基线同步、热修复补丁流程及安全（权限、密钥、网络 ACL）建议
  • 提供 GitHub Copilot（Agent 模式）+ MCP 服务器配置及常用 SQLcl、Liquibase、Git、APEX 命令脚本

适用场景（解读层）

  • 为中大型 Oracle APEX 或 PL/SQL 系统实施基于 Git 的自动化部署
  • 排查多 schema、多环境下 SQLcl Project 的行为与边缘案例
  • 搭建开发者→测试→生产的多环境部署流水线
