纯 Rust 实现的 openGauss 数据库客户端驱动

综述（解读层）

rustGauss 是纯 Rust 编写的 openGauss 客户端驱动，通过实现 openGauss 扩展的协议（SHA256/RFC 5802 认证、SM3 等）连接华为开源数据库，面向需要在 Rust 中访问 openGauss 的开发者。当前为 Phase 1 原型，验证协议兼容性；提供 tokio 异步 I/O、TLS、可选连接池及类型映射，并通过 cargo 安装、示例程序（CLI、benchmark 等）运行。

  • 纯 Rust 实现，基于 tokio 的异步 I/O，支持 MD5、SHA256、SCRAM-SHA-256 等认证与可选 TLS/连接池
  • 实现 openGauss 基于 TCP/IP 的消息协议，包含 SHA256 认证流程与常用数据类型到 Rust 类型的映射
  • 附带 simple、benchmark、cli、sample_db、query 等示例程序，测试含 89 个单元测试与 8 个集成测试

适用场景（解读层）

  • 在 Rust 应用中连接和操作 openGauss 数据库
  • 需要 SHA256/RFC 5802 或 SM3 认证方式的 openGauss 访问场景
  • openGauss 与 Apache Spark 的数据集成（Phase 2 的 Spark Connector 规划）
