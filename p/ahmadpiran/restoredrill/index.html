综述（解读层）

restoredrill 是一个命令行工具，用于验证 PostgreSQL 与 MySQL 备份能否实际恢复：拉取最新备份、在临时容器中恢复、按分层检查（预检、结构、读路径、RTO、环境）执行校验，并输出字段固定的 JSON 报告，带真实时间戳与 RPO/RTO 证据。适用于需要为 SOC 2、ISO 27001、AWS FTR 等审计提供恢复演练记录的团队。当前 v0.4.4，支持 pg_dump 归档/SQL、mysqldump、pgbackrest 及已恢复数据库连接；检查默认失败即报错（fail closed），依赖 Docker（existing_connection 模式除外）。

  • 按分层执行检查：备份预检（含 RPO 新鲜度）、结构完整性、行数与自定义 SQL 断言、RTO 时长、容器环境可用性，检查无法运行时计为失败
  • 生成固定 schema 的 JSON 报告，包含触发者、备份来源选择过程、恢复起止时间、失败原因与通知错误等字段，时间戳统一为 UTC 字符串格式
  • 支持本地磁盘或 S3 的备份来源、pgbackrest 仓库、已恢复数据库连接模式，并通过 Prometheus textfile、Slack 与通用 webhook 输出结果

适用场景（解读层）

  • 在本地或 CI 中按恢复策略定期执行备份恢复演练，获取带时间戳的验证证据
  • 为 SOC 2、ISO 27001、AWS Foundational Technical Review 等合规审计整理恢复演练报告
  • 通过 Prometheus 或 Slack 监控演练是否按时运行，捕获停止运行或通知失败的情况
