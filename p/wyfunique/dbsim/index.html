纯 Python 的可扩展数据库模拟器，用于快速原型化库内算法

综述（解读层）

DBSim 是用纯 Python 实现的数据库模拟器，模拟 RDBMS 查询引擎环境，面向需要开发和验证库内分析算法原型的数据科学家。它包含 SQL 解析器、关系算子、逻辑/物理计划生成器与查询优化器等组件，并提供 GUI 和计划可视化工具；目前仅支持启发式（基于规则的）优化器，GUI 仅在 Microsoft Edge 上测试过。

  • 包含通用 RDBMS 查询引擎的主要组件：SQL 解析器、关系算子、逻辑与物理计划生成器、查询优化器等
  • 提供 API 扩展几乎任何数据库组件，如新增查询语法关键字、实现自定义算子、编写自定义优化规则、扩展物理计划执行器等
  • 提供查询计划可视化器和 GUI 等调试分析工具，基于 Python 实现，依赖 Python 3.6+

适用场景（解读层）

  • 在实现到真实数据库内核之前，对库内分析算法进行原型开发、验证与分析
  • 扩展 SQL 语法关键字、实现自定义算子或编写自定义优化规则的实验
  • 解析 SQL 生成抽象语法树并可视化，或手动优化逻辑计划并查看结果计划
