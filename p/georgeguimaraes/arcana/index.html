🧭 简介解读层（AI·证据行可回查）

嵌入 Elixir/Phoenix 应用的 RAG 库，复用现有 Ecto Repo 与 Postgres/pgvector。

综述（解读层）

Arcana 是面向 Elixir/Phoenix 应用的可嵌入 RAG 库，将文档、分块、向量与知识图谱存入应用现有的 Postgres（pgvector），无需独立向量数据库或检索服务。嵌入与重排默认经 Bumblebee/EXLA 本地运行，也可切换 OpenAI、Anthropic、Z.ai 等云端模型。提供三种使用形态：Arcana.search/ask（含查询改写、混合检索、RRF 融合、交叉编码器重排）、Pipeline 组合式步骤、以及 LLM 在运行时自选工具的 Loop 模式；另含 LiveView 仪表盘与 :telemetry 事件。安装用 mix igniter.install arcana 完成。

  • 提供 Advanced（search/ask）、Modular（Pipeline）、Agentic（Loop）三种 RAG 使用形态
  • 文档、分块、向量与知识图谱均存于现有 Postgres/pgvector 表，无需额外基础设施
  • 嵌入与交叉编码器重排默认经 Bumblebee（EXLA/EMLX/Torchx）本地运行，可换 OpenAI/Cohere 等

适用场景（解读层）

  • 已有 Ecto Repo 的 Phoenix 应用需在库内添加向量检索与问答
  • 需要 Pipeline 自定义检索步骤顺序或替换重排/搜索行为
  • 多跳、开放式问题需 LLM 在运行时逐步选择搜索与回答工具
