🧭 简介解读层（AI·证据行可回查）

本地 MCP 记忆服务器，为多个 AI 代理提供共享且带版本的记忆

综述（解读层）

Make0 Brain 是一个本地优先的开源 MCP 记忆服务器，供 Claude Code、Cursor、Codex、Windsurf 等代理共享同一份记忆数据。数据存于本机单个 SQLite 文件，首次下载模型后可离线运行且无需 API key。安装通过 `npx @make0-ai/brain init` 完成，该命令会检测已装代理、写入配置并保留配置备份；自定义指令需部分应用手动粘贴。每条记忆保留编辑版本与写入者信息。

  • 通过 MCP 提供 7 个工具（list_brains、search_brain、get_memory、get_memory_versions、add_memory、update_memory、delete_memory），各连接应用使用同一套名称与 schema
  • 所有记忆存储于本地单个 SQLite 文件（~/.make0/brain.db），每次编辑保留版本、写入者与时间，删除的记忆可从存档恢复
  • 支持从 41 个编码代理读取历史会话，以及从 CLAUDE.md、AGENTS.md、Cursor 规则、Obsidian vault 等 Markdown 目录导入；会话导入前对凭据做脱敏处理

适用场景（解读层）

  • 多代理工作流：在一个代理中保存的偏好与决策，供其他代理在后续会话中通过 search_brain 检索
  • 导入已有编码代理的磁盘会话历史，生成每个会话的记忆摘要并按项目归档
  • 需要离线运行或本地数据存储的记忆场景；也支持创建多个 brain 以隔离不同项目的记忆
