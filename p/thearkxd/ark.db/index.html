ark.db 是面向 Node 与浏览器的 JSON 数据库模块，支持 MongoDB 适配

综述（解读层）

ark.db 是一个以 JSON 文件为存储的数据库模块，提供 Node 端 Database 类、浏览器端 LocalStorage 类以及 MongoDB 适配器。安装方式为 npm 或 yarn 安装，浏览器端通过 unpkg 引入脚本使用。要求 Node.js 版本高于 12，数据文件路径可由用户指定，支持相对路径。

  • 提供 Database、LocalStorage、MongoDB 三种适配器，分别用于 Node、浏览器和 MongoDB 连接
  • 支持点号表示法和相对路径，可指定 JSON 数据文件的保存位置
  • 2.0.0 起所有方法为同步，2.6.0 版本使用 TypeScript 重写

适用场景（解读层）

  • Node.js 项目中以 JSON 文件方式读写结构化数据
  • 浏览器端通过 LocalStorage 适配器在页面中存取数据
  • 已有 MongoDB 实例时通过适配器连接指定 schema 进行操作
