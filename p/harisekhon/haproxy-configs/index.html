面向 Hadoop、NoSQL 等系统的 80+ HAProxy 配置模板合集

综述（解读层）

该仓库提供 80 余个针对 Hadoop、HBase、Elasticsearch、SolrCloud、MySQL、Redis 等系统的 HAProxy 配置文件，按 <service>.cfg 拆分、可与 10-global.cfg 组合加载，用于多主、主备和对等架构的负载均衡。每个配置包含按技术定制的健康检查、负载算法、缓冲参数与 ACL 私网访问限制；用户需自行填入后端服务器地址，可选加入 20-stats.cfg 启用带密码保护的统计界面。配置经 CI 针对 Docker 容器测试，untested/ 目录含未测的 SSL 版本。

  • 每个配置包含针对对应技术 API 的专用健康检查与按主备/对等模式选择的负载均衡算法
  • 配置按服务拆分为 .cfg，可与 10-global.cfg 及 20-stats.cfg 组合通过 haproxy -f 加载
  • 内置 ACL 限制仅允许私有 IP 访问，缓冲区、连接数、重试等参数已预先调优

适用场景（解读层）

  • 为 Hadoop、HBase、Presto 等主备或多主架构搭建 HAProxy 负载均衡
  • 为 Elasticsearch、SolrCloud 等对等系统配置前端代理以便脚本调用和监控
  • 需要统一的 HAProxy 配置模板库，通过填入后端地址快速启动代理服务
