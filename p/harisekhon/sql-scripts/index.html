面向多种数据库的 100+ 个 DBA与分析 SQL 脚本集合

综述（解读层）

该仓库收录 100 余个 SQL 脚本，从作者的 DevOps Bash tools 仓库拆分而来，覆盖 PostgreSQL、MySQL/MariaDB、Oracle、AWS Athena、Google BigQuery 等数据库，内容包括 DBA 排查与性能调优查询、GCP 计费查询、信息模式查询，以及 BigQuery ML 逻辑回归分类与购买预测脚本。适合 DBA、DevOps 和数据分析人员直接在客户端中 source 运行。各脚本注明了已测试的数据库版本范围。

  • 提供 PostgreSQL、MySQL/MariaDB、Oracle、AWS Athena、Google BigQuery 多平台的 DBA 排查与性能调优查询脚本
  • 包含 GCP 计费分析查询和 BigQuery ML 逻辑回归分类与购买预测脚本
  • 提供 postgres.sh/mysqld.sh 等配套脚本，可启动 Docker 容器并挂载脚本目录直接进入 psql/mysql shell 测试

适用场景（解读层）

  • 数据库性能排查与调优，如查询耗时、会话、用户权限概览
  • GCP 用量与成本分析，如最高成本服务、最近消费记录查询
  • 通过 Athena 查询 CloudTrail 日志、通过 BigQuery ML 做电商购买预测分类
