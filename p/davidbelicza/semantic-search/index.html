🧭 简介解读层（AI·证据行可回查）

Go 语义搜索库：将 PDF、Markdown、代码等文件切块并嵌入向量数据库实现语义检索

综述（解读层）

这是一个用 Go 编写的语义搜索库，递归索引目录中的 PDF、Markdown、代码、DOCX、字幕等文件类型，将其切块并通过 OpenAI 兼容的嵌入服务器转为向量，存入 SQLite（客户端）或 PostgreSQL/pgvector（服务端），支持基于含义而非关键词的检索。使用方需自行准备嵌入服务；客户端构建依赖 cgo 和 C 编译器；检索默认为精确 kNN，PostgreSQL 下可切换 HNSW 近似索引。

  • 支持 Markdown、PDF、纯文本、多种编程语言源码、DOCX、HTML、配置文件、字幕、ePub 等格式，按标题、章节、函数等结构切分为带标题路径的 token 预算块
  • 提供 SQLite（磁盘/内存）和 PostgreSQL+pgvector 两种存储后端，检索支持精确 kNN 和 HNSW 近似最近邻两种方式
  • 内置多个预定义嵌入模型定义（EmbeddingGemma、Nomic、E5、BGE、Qwen 等，768 或 1024 维），通过模型接口可更换模型与维度

适用场景（解读层）

  • 桌面、移动应用或 CLI 工具中嵌入 SQLite，对本地文件和个人知识库做端侧语义搜索/RAG
  • Web 系统中配合 PostgreSQL 与 pgvector 搭建服务端语义知识库，如电商或产品目录检索
  • 对本地文档、笔记、字幕、代码仓库建立可按含义检索的索引
