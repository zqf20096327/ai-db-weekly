ESQL：为 Erlang 程序与多种 SQL 数据库提供抽象层的连接库

综述（解读层）

ESQL 是一个 Erlang 库，在 Erlang 程序与 SQL 关系型数据库之间提供抽象层，使数据库代码只需用 Erlang 编写一次，即可运行于多个后端数据库（如 Sqlite、MySQL、Oracle、PostgreSQL 及 ODBC 兼容数据库）。README 当前列出两个驱动：基于 esqlite 的 esql_sqlite3 和基于 pgsql 的 esql_pgsql，其他后端需有对应驱动支持。

  • 提供 Erlang 程序与 SQL 数据库之间的抽象层，统一数据库访问代码
  • 声明支持 Sqlite、MySQL、Oracle、PostgreSQL 及 ODBC 兼容数据库等后端
  • 当前包含 esql_sqlite3（基于 esqlite）和 esql_pgsql（基于 pgsql）两个驱动

适用场景（解读层）

  • 需要用 Erlang 访问 SQLite 或 PostgreSQL 数据库的应用
  • 希望数据库访问代码在不同 SQL 后端之间迁移的项目
  • 需通过统一接口访问 ODBC 兼容数据库的 Erlang 系统
🔌 适配哪些库db_scan 程序判定

MySQL、Oracle、PostgreSQL、SQLite
