纯 R7RS Scheme 编写的 PostgreSQL 套接字前端接口库

综述（解读层）

该库以纯 R7RS Scheme 实现 PostgreSQL 的套接字协议前端接口，提供连接管理、预处理语句、事务控制及 COPY 数据处理等高级 API。支持 Sagittarius、Gauche、Chibi Scheme 等实现，依赖 SRFI-60/33、SRFI-106（可选 SRFI-19）。数据类型由高级 API 自动转换。README 注明项目仍处于工作状态，低层 API 尚未完成，COPY 处理器需要使用者了解 PostgreSQL 协议细节。

  • 提供连接、预处理语句、事务（含隔离级别/访问模式设置）与 COPY 命令的高级 API
  • 在多个 R7RS Scheme 实现上运行，依赖 SRFI-60/33、SRFI-106，可选 SRFI-19
  • 高级 API 自动进行 PostgreSQL 与 Scheme 之间的数据类型转换

适用场景（解读层）

  • 需要在 R7RS Scheme 程序中直接以套接字方式连接 PostgreSQL 数据库
  • 需要使用预处理语句、事务隔离级别控制或 COPY 数据流处理的 Scheme 项目
  • 跨多种 R7RS Scheme 实现（Sagittarius/Gauche/Chibi 等）复用数据库访问代码
