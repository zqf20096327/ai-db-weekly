Outcrop：直读对象存储中 SlateDB 状态的只读 Web 仪表盘

综述（解读层）

Outcrop 是面向 SlateDB（0.15.x）的只读 Web 仪表盘，通过读取对象存储中的 manifest、SST 元数据和对象列表来展示数据库状态，不执行任何写入，也不需要运行中的写入端配合。它自动发现存储桶中的 SlateDB 实例，提供 LSM 树层级可视化、manifest 语义 diff、垃圾回收统计、REST API（含 OpenAPI 文档）和 Prometheus 指标。无内置认证，默认绑定 localhost，共享部署需自配反向代理鉴权；manifest 格式不兼容版本可能无法解码。

  • 零写入：仅读取 manifest、SST 元数据与对象列表，无需写入端配合或部署代理
  • 自动发现对象存储中的 SlateDB 实例（按 manifest/ 目录识别），支持多 store 的 TOML 配置与环境变量凭证引用
  • 提供 OpenAPI 3.1 REST API、/metrics Prometheus 指标、LSM 层级与 key-range 覆盖可视化，可变状态读取默认缓存 5 秒

适用场景（解读层）

  • 运维团队巡检对象存储上 SlateDB 实例的层级大小、WAL 窗口、检查点与垃圾占比
  • 为多实例 SlateDB 集群配置统一的只读观测面板与 Prometheus 监控接入
  • 基于 /api/dbs 的 JSON 接口编写自定义查询脚本或生成类型化客户端
