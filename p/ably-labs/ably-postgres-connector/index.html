基于 pg_notify/LISTEN 的 PostgreSQL 变更到 Ably 实时频道的连接器库

综述（解读层）

该库在 PostgreSQL 表发生 insert/update/delete 时，向指定 Ably 频道发布消息。其机制是：创建 ablycontroltable 维护表与频道映射，生成调用 pg_notify 的存储过程，并为表-操作组合建立触发器，再通过 LISTEN 接收通知并转发到 Ably 频道。支持 JSON/env 文件及 docker-compose 三种配置方式，适合需要在数据库变更时向 Ably 客户端推送通知的 Node.js 项目。

  • 为配置中指定的表-操作组合自动创建触发器和调用 pg_notify 的存储过程
  • 创建 ablycontroltable 维护数据表到 Ably 频道的映射
  • 支持 JSON 配置文件、env 文件和 docker-compose 三种配置方式

适用场景（解读层）

  • 在数据表发生 insert/update/delete 时向 Ably 频道发布消息
  • 通过 docker-compose 部署带 PostgreSQL 镜像和连接器容器的环境
📖 README 首段存档原文 · 程序抽取

The Ably-Postgres connector publishes a message on a given Ably channel whenever any operations (insert/update/delete) are executed on the tables of your PostgreSQL database.
