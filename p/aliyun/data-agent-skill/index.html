🧭 简介解读层（AI·证据行可回查）

让 AI 助手调用阿里云 Data Agent 进行自然语言数据分析的技能包

综述（解读层）

该仓库提供一组 AI Agent 技能，使 Claude Code、Qoder、Codex 等运行时能够调用阿里云 Data Agent for Analytics，将自然语言问题转为 SQL、洞察与分析报告。包含 CLI（Python 3.10+）与 MCP Server（Go 构建，19-30 个工具）两种接入方式，二者独立不可混用；另含一个教 AI 编写技能包的元技能。需阿里云账号、DMS 数据源或内置演示库，并配置 RAM 权限。

  • 提供 CLI 与 MCP Server 两种独立接入方式，MCP 含 19 个基础工具，启用网关后可扩展至 28-30 个
  • 支持自然语言问答、多步深度分析生成报告、本地 CSV/XLSX/JSON/TXT 文件分析与会话多轮复用
  • data-agent-arcvis-skill 元技能用于生成 Quest 技能包与自包含 HTML 报告模板包

适用场景（解读层）

  • 在支持的 Agent 运行时中对企业数据库或文件做自然语言查询、趋势分析与报告生成
  • 通过 MCP 客户端调用 data_agent_* 工具进行数据发现、会话管理与图表获取
  • 将周期性多步分析流程或已有 HTML 报告固化为可复用的技能包/模板包
