PolarDB for PostgreSQL 的纯 Java（Type 4）JDBC 驱动，基于 PgJDBC 扩展 Oracle 兼容特性。

综述（解读层）

该驱动是阿里云 PolarDB for PostgreSQL（含 Oracle 兼容版）的 JDBC 驱动，用纯 Java 实现（Type 4），派生自 PgJDBC，通过 PostgreSQL 原生网络协议通信，也可连接 PostgreSQL 8.4 及以上版本。面向需要以标准 Java 代码访问 PolarDB 的开发者，在 PgJDBC 基础上增加 Oracle 风格 DATE/NUMBER 处理、BLOB/CLOB 映射、REF CURSOR、命名参数等兼容特性，通过 jdbc:polardb: URL 和连接属性配置，支持 SSL、预编译语句缓存、多主机负载均衡等参数。

  • 纯 Java（Type 4）实现，基于 PgJDBC，使用 PostgreSQL 3.0 版线路协议通信
  • 提供 Oracle 兼容特性，包括 DATE/NUMBER 处理、BLOB/CLOB 映射、关联数组、REF CURSOR、命名参数，及 blobAsBytea、oracleCase、namedParam 等 PolarDB 专属连接属性
  • 实现 java.sql.Driver、DataSource、ConnectionPoolDataSource、XADataSource 接口，支持 SSL 配置、二进制传输、预编译语句缓存及 targetServerType/loadBalanceHosts 多主机连接策略

适用场景（解读层）

  • Java 程序通过标准 JDBC 接口连接 PolarDB for PostgreSQL（含 Oracle 兼容 1.0/2.0 版）或 PostgreSQL 8.4+ 数据库
  • 从 Oracle 迁移到 PolarDB 的应用需要 Oracle 风格数据类型行为（DATE/NUMBER、BLOB/CLOB、REF CURSOR 等）的 Java 访问层
  • 需要 XA 数据源、连接池数据源或 SSL 加密连接的 Java 应用集成场景
