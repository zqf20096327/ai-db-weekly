面向 Rust 的脚手架式后端框架，生成 Axum+SQLx 的 CRUD 代码

综述（解读层）

Gize 提供 gize new/make crud 等命令，从空目录生成完整 CRUD 资源：Axum handler、SQLx 查询、SQL 迁移，内置 users 资源与 Argon2id+JWT 认证，支持 PostgreSQL、MySQL、SQLite。生成的是可直接阅读修改的常规 Rust 文件，框架本身不保留运行时。当前为 1.0.0-rc.2，需 Rust 1.85+。

  • gize make crud 生成含 model/dto/repository/service/handler/routes/tests 九文件的垂直切片并自动注册
  • 支持 PostgreSQL、MySQL、SQLite 三种数据库，可选 OpenAPI 文档与 WebSocket 端点
  • 迁移通过 SQLx migrator 管理，提供 --dry-run/--force 全局标志与 gize doctor 环境诊断

适用场景（解读层）

  • 用 Rust 搭建带分页、认证的 CRUD API 服务
  • 通过 gize make admin 生成 React 管理后台
  • 在 CI 中用 gize createadmin --password-env 非交互创建管理员
