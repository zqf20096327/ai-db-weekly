综述（解读层）

SQLight 是一个用 Go 编写的 SQLite 克隆项目，面向学习数据库核心概念的开发者。它实现了 SQL 解析、查询执行、事务管理和基于 JSON 的持久化存储，内含 B-tree 存储结构，并通过分层架构划分为 Web UI/CLI、解析器、执行器与存储引擎。目前支持的 SQL 命令包括 CREATE TABLE、INSERT、SELECT 和 DELETE，数据类型仅支持 INTEGER 和 TEXT，UPDATE 和 JOIN 等命令尚未实现。

  • 同时提供 Web 界面和命令行两种交互方式，Web 界面支持实时查询执行与表浏览
  • 实现 SQL 解析、查询执行、事务管理和 B-tree 数据存储，数据以 JSON 格式持久化
  • SELECT 支持 WHERE 子句多条件（AND）过滤，SQL 命令与表/列名不区分大小写

适用场景（解读层）

  • 学习 SQL 解析、查询执行和 B-tree 等数据库核心机制的实现原理
  • 需要通过 Web 界面或终端执行基础 SQL 建表、插入、查询和删除操作
  • 作为 Go 标准库实现的分层架构项目用于阅读和贡献代码
