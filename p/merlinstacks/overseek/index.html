面向 WooCommerce 店铺的自托管运营面板，集中管理订单、库存、营销与分析

综述（解读层）

OverSeek 是一个自托管的 WooCommerce 运营平台，将店铺数据同步到自建的 PostgreSQL 应用中，提供订单、库存、邮件营销、客服收件箱和分析模块，配合 WordPress 插件完成数据同步与实时追踪。部署依赖 Docker Compose，本地开发需 Node.js 22、PostgreSQL 17（pgvector）、Elasticsearch 9 与 Redis 7；首个注册用户自动成为超管，部分模块为账户级功能门控。

  • 提供拖拽式自定义仪表盘、订单同步、库存预测、BOM 同步与采购单管理
  • 包含客服收件箱（实时聊天、AI 草稿辅助）、邮件营销（流程、广播、细分、送达日志）与分析模块（归因、 cohorts、CLV）
  • 内置安全机制：Argon2id 密码、JWT 刷新令牌轮换、TOTP 2FA、静态加密凭据及默认端口隔离

适用场景（解读层）

  • 需要将 WooCommerce 订单、库存与客户数据集中在自托管环境中管理的店铺运营团队
  • 希望在单一面板内处理客服对话、邮件营销与增长分析（SEO、广告、评论）的电商团队
  • 需要开发扩展能力（MCP server、CLI、共享核心包）接入自有系统的技术团队
