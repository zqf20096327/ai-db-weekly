可视化查看 SQL Server 存储引擎内部结构的 Windows 工具

综述（解读层）

Internals Viewer 是一款用于查看 SQL Server 存储引擎内部结构的可视化工具，可连接在线数据库、读取已分离或离线数据库的数据文件，或直接打开 .bak 备份而无需恢复。需 sysadmin 角色，运行于 Windows 10 2004+/Windows 11，经测试支持 SQL Server 2019–2025。README 提示其虽不修改数据库，但存在 I/O 开销，不建议在生产服务器上使用；部分功能（如清空缓冲池、Full Trace 重启 SQL Server 服务）需谨慎。

  • 支持连接在线数据库、打开分离/离线数据库的数据文件，以及无需恢复直接读取 .bak 备份（含 zstd 压缩备份）
  • 5.0 版本包含 Full Trace 功能与用于 AI 集成的本地 MCP
  • 通过 Microsoft Store 或 GitHub Release 的 .msix 包安装，基于 C#/.NET 11 与 WinUI 3 构建

适用场景（解读层）

  • 在本地或非生产环境检查 SQL Server 数据页等存储引擎内部结构
  • 直接分析分离/离线数据库文件或 .bak 备份数据
  • 通过 Query tracing 和 Full Trace 观察查询的存储层行为
