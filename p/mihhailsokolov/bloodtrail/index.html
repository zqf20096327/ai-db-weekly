BloodHound CE 的内存图引擎，以 DAWGS 驱动加速攻击路径查询

综述（解读层）

BloodTrail 是部署在 BloodHound CE 之下的内存图引擎，以 DAWGS 驱动形式接入，维护与 PostgreSQL 逐写同步的内存副本，用于服务最短路径、结构化查询和大部分 Cypher；无法保证与 PostgreSQL 一致结果的读取回退给 PostgreSQL。安装脚本会备份并迁移图数据、切换镜像并验证结果。面向运行大型 Active Directory 环境的 BloodHound 使用者，要求 v9.6.0 以上版本。

  • 以 DAWGS 驱动实现，不改 BloodHound 的采集、分析、API 与 UI，写入先落 PostgreSQL 并同步到内存副本
  • 提供最短路径引擎、结构化查询识别器和 Cypher 解释器三条读取路径，不可精确回答的查询委托给 PostgreSQL
  • 支持快照加速重启、安装/回滚/状态/验证 CLI 命令及发布版本固定

适用场景（解读层）

  • 大型 Active Directory 环境下运行 BloodHound CE 的攻击路径分析
  • 预置查询在大规模图上超时、需要降低查询延迟的部署
  • 从 Neo4j 迁移到 PostgreSQL 存储的 BloodHound 部署升级场景
