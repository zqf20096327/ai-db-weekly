基于 Dask 的 Python 分布式 SQL 查询引擎

综述（解读层）

dask-sql 是运行在 Python 中的分布式 SQL 查询引擎，允许在 pandas/Dask DataFrame 上混合执行 SQL 与 Python 代码。其内部用 Arrow DataFusion 将 SQL 翻译为逻辑查询计划，再转成 Dask 执行计划。可通过 pip/conda 安装，附带基于 presto 协议的 SQL 服务器。注意 README 声明该项目目前不再处于活跃维护状态，且尚不支持全部 SQL 命令。

  • 支持在 SQL 查询中混用 pandas/Dask DataFrame API 与 Python 自定义函数（UDF）
  • 支持 CSV、Parquet、JSON 等格式及 s3、hdfs、gcs 等数据源，并可通过 cuDF 在 CUDA GPU 上运行查询
  • 提供基于 presto wire protocol 的 SQL 服务器、CLI 及 docker 镜像运行方式

适用场景（解读层）

  • 在 Jupyter 或 Python 模块中用 SQL 查询和转换 dask/pandas 数据
  • 需要随数据规模扩展的 SQL 计算，借助 Dask 从单机运行到集群部署
  • 从 presto 客户端或 BI 工具通过 SQL 服务器连接执行查询
