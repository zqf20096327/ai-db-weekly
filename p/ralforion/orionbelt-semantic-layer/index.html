🧭 简介解读层（AI·证据行可回查）

YAML 声明式语义层，将模型编译为 8 种 SQL 方言

综述（解读层）

OrionBelt 是一个语义与上下文层，用户或 AI 代理在 YAML 中声明维度、度量与连接，系统经 AST 编译为 8 种方言（BigQuery、ClickHouse、Snowflake、DuckDB 等）的 SQL，并提供 PostgreSQL wire、Arrow Flight SQL、REST 和 MCP 四种接入接口。它以 sidecar 形式运行，不管理集群或缓存，要求 Python 3.12+，许可为 BUSL-1.1，可通过 pip 安装或 Docker 运行。

  • 将 YAML 声明的语义模型通过 AST 编译为 BigQuery、ClickHouse、Databricks、Dremio、DuckDB/MotherDuck、MySQL、PostgreSQL、Snowflake 八种方言的 SQL
  • 提供 PostgreSQL wire（5432）、Arrow Flight SQL（8815）、REST（8000）与 MCP 四种接入接口；v3.0.0 起支持跨数据库联邦查询，将拆分后的子查询经内存 DuckDB 合并
  • 模型可导出为 Apache Ossie（OSI）格式与 RDF 图（OWL/SHACL/SKOS/PROV），支持只读 SPARQL 查询，并以 JSON、Mermaid 或 Turtle 输出查询与物件的血缘

适用场景（解读层）

  • AI 代理通过 MCP 或 oneshot 批量接口提交任务级 OBML 模型并执行查询
  • BI 工具（Tableau、Power BI、Superset、Metabase 等）经既有 Postgres 驱动或 Flight SQL 驱动连接语义模型
  • 同一模型需跨多个数据仓库编译，并对 NULL 处理、取整等表达式行为做统一化处理
