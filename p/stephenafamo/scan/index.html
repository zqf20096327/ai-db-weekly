Go 的 SQL 行扫描库，将查询行直接映射到任意结构

综述（解读层）

Scan 是一个 Go 语言库，通过 database/sql.Rows 或 pgx 将查询结果行直接扫描到用户定义的结构中。提供 stdscan、pgxscan 及基于 Queryer 接口的基础包三种接入方式，配套 One/All/Each/Cursor 四种读取函数和可扩展的 Mapper 机制。适合需要在 Go 项目中手动控制 SQL 结果映射的开发者。

  • 提供 One、All、Each（range-over-func）与 Cursor 四种行读取函数
  • 内置 ColumnMapper、StructMapper 等多种 Mapper，StructMapper 支持 tag 前缀、行校验与类型转换选项
  • 同时适配 database/sql 与 pgx/v5，基础包可用于任何实现 Queryer 接口的执行器

适用场景（解读层）

  • 将 SQL 查询结果按 db tag 映射到 Go 结构体
  • 流式处理或按需读取大批量查询结果（Cursor）
  • 将单列查询扫描为切片、或将整行扫描为 map 等非结构化形式
