Forkget：基于固定快照为应用与 Agent 创建可隔离、可过期的数据库分支工具

综述（解读层）

Forkget 从 MySQL、PostgreSQL、TiDB 或 MongoDB 的固定快照创建隔离分支，供应用与 AI Agent 使用。通过原生客户端或 SQLAlchemy 连接，可导出 JSON 差异并对基线重放。项目尚在准备 v0.1.0-rc.1，未发布二进制或容器镜像；TiDB 存在外键并发完整性缺陷，被列为发布阻塞项。采用 MIT 许可证。

  • 支持从 MySQL、PostgreSQL、TiDB、MongoDB 快照创建只读或可写分支，分支带显式权限、行预算与过期机制
  • 通过 forkget diff 生成 JSON 变更文件，并支持将保存的结果对保留基线重放
  • 部署包含代理、控制服务、元数据 PostgreSQL 与独立配置的原生服务引擎，数据链路双向验证 TLS

适用场景（解读层）

  • 为 AI Agent 或应用提供带行预算与自动过期的临时沙箱数据库分支
  • 在只读分支上验证应用变更后导出差异，人工审阅后再决定是否处理
  • 需要隔离测试数据库变更但不自动合并回生产源的场景
