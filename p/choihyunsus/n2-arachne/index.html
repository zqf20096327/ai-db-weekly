搜索项目代码与文档，为 AI 任务组装相关上下文的 Node.js 工具

综述（解读层）

n2-arachne 是一个基于 Node.js 22+ 的工具，用于搜索项目代码和文档，找出 AI 在当前任务中应读取的部分。工作流程为读取项目文件、构建搜索索引、检索相关内容，使用 SQLite 存储，通过 MCP 连接 AI 应用。安装需从 GitHub release 下载 tgz 包，读取 PDF/Office 文档可能需平台特定解析器，SQLite 构建失败需平台 C/C++ 构建工具。

  • 读取项目文件并构建可搜索索引，用于定位函数或配置等内容
  • 支持搜索代码及 PDF/Office 等文档（部分格式需平台特定解析器）
  • 通过 MCP 连接 AI 应用，多个 N2 模块可共享同一 mimir.db 数据库

适用场景（解读层）

  • 在大型项目中查找函数或配置项
  • 为模型请求收集相关文本段落
  • 将源码文件夹建索引后供 AI 应用检索上下文
