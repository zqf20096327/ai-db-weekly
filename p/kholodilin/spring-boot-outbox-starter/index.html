🧭 简介解读层（AI·证据行可回查）

基于 PostgreSQL 的事务性 Outbox Spring Boot Starter，支持多通道管道与可插拔 Sink。

综述（解读层）

该项目是一个面向 Java 21 与 Spring Boot 3.2+/4.x 应用的事务性 Outbox Starter，用于将事件写入与业务同一事务内落库（PostgreSQL 为事实来源），再经内存或 Redis 唤醒队列由 publisher worker 分发到应用提供的 OutboxSink。核心机制包括按通道隔离的管道、fluent API、分区表 schema、Micrometer 指标与健康指示器；不含 HTTP 幂等，需单独组合幂等 starter。

  • 支持多通道隔离管道：每通道独立 table → queue → publisher worker → OutboxSink
  • 队列实现可在 memory 与 Redis 间选择，type=auto 时按上下文中是否存在 StringRedisTemplate 解析
  • 提供事件级 Micrometer 指标（入队/出队/发布/恢复）与名为 outbox 的健康指示器

适用场景（解读层）

  • 微服务中需在同一事务内持久化业务数据与待发布事件的场景
  • 同一应用部分实例有 Redis、部分没有，需要自动选择队列实现的部署
  • 需要按通道隔离事件流（如 payments 与 webhooks 分开投递到 Kafka 或 REST）的应用
