docsql：将 Google Docs 电子表格导入 MySQL 表的 Go 命令行工具

综述（解读层）

docsql 是一个用 Go 编写的命令行工具，用于将托管在 Google Docs 上的电子表格导入 MySQL 表。它要求电子表格以“任何拥有链接的人可访问”方式公开分享，并以 TSV 格式的导出 URL 作为输入；导入时先删除旧输出表再写入新内容，可通过 --keep 保留若干张旧版本表，适合配置为定时任务运行。表结构由工具自动生成：所有字段为 VARCHAR(255)，附自动主键与时间戳字段。

  • 通过 TSV 导出 URL 读取 Google Docs 电子表格，支持通过 gid 参数选择文档中的具体工作表
  • 每次运行时重建输出表，并支持 --keep 参数保留指定数量的历史版本表
  • 支持通过环境变量传递 MySQL 连接串，避免凭据留在命令行历史中

适用场景（解读层）

  • 定期将公开分享的 Google 电子表格同步到 MySQL 表中供查询使用
  • 电子表格每次更新后手动触发一次数据导入
  • 需要简单批量载入表格数据且服务器支持 LOAD DATA LOCAL INFILE 的场景
