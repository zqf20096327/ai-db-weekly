编译为 SQL 的开源声明式逻辑编程语言，可运行于多种数据库引擎

综述（解读层）

Logica 是 Datalog 家族的开源逻辑编程语言，将逻辑程序编译为 SQL 表达式，在 BigQuery、PostgreSQL、SQLite、DuckDB 等引擎上执行。面向希望在数据库查询与管道中使用逻辑编程语法的工程师和数据科学家。本地运行需 Python3，可通过 pip 安装或克隆仓库；在 BigQuery 上运行需 Google Cloud 项目，命令行执行需 bq 工具。

  • 将逻辑程序编译为 SQL 表达式，通过 @Engine 指令选择目标引擎
  • 支持 BigQuery、PostgreSQL、SQLite、DuckDB 等运行环境
  • 提供 CoLab 教程（tutorial 目录）和示例（examples 目录），可通过 pip 安装命令行工具

适用场景（解读层）

  • 对 BigQuery、PostgreSQL 或 SQLite 中的现有数据编写逻辑编程风格的查询与管道
  • 在 BigQuery 等分布式数仓上运行可并行执行的逻辑程序
  • 学习逻辑编程并将其应用于大数据处理
