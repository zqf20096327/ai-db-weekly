🧭 简介解读层（AI·证据行可回查）

基于 PostgreSQL pgvector 与行级安全的 Google ADK 多租户语义记忆服务。

综述（解读层）

adk-memshield 是实现 Google ADK BaseMemoryService 接口的 Python 库，将多租户语义记忆的归属过滤从应用层移入 PostgreSQL，通过 FORCE ROW LEVEL SECURITY 与事务级 set_config 绑定 app_name、tenant_id、user_id 和 agent_clearance。适用于多租户、多代理 ADK 部署。限制：不防护已持库凭据的失控应用进程，租户与密级需按服务实例配置。

  • 以 BaseMemoryService 形式接入 Google ADK，使用 PostgreSQL pgvector 存储语义向量并借助 RLS 在数据库层执行行级隔离
  • 每次操作在显式事务中通过 set_config 绑定身份，连接池化后身份不残留；缺失身份上下文时查询返回 0 行
  • SELECT/INSERT/UPDATE/DELETE 四类操作均受策略约束，支持 tenant_shared 行的最低密级过滤，并禁止向高于自身密级的内容写入；事件按 (owner, session_id, event_id) 唯一索引幂等写入

适用场景（解读层）

  • 多租户 google-adk 部署中需要长期语义记忆且要求跨用户语义隔离的场景
  • 多代理（sub-agent）体系中按密级控制共享租户记忆读取的部署
  • 希望将记忆归属过滤从应用 SQL 迁移至数据库强制执行、防范检索过滤遗漏的项目
