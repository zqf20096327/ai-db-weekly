SimpleDB 教学型数据库作业实现，覆盖存储、算子、优化器与事务四大模块

综述（解读层）

该仓库是 UC Berkeley CS186（与 MIT 6.830 相同实验）的 SimpleDB 数据库作业 Java 实现，包含四个项目：数据管理、算子实现、基于代价的查询优化器和基于 2PL 的事务管理。作者将课程推荐的 Ant 构建改为 Maven，并修改了部分课程代码方法参数与 JoinOptimizer 逻辑；另附两个课程外的 Recovery 与 B+Tree 实验。适合学习数据库课程并具备 Java 基础的开发者，作者称全部完成约需一个月。

  • 实现四个项目模块：物理数据存储与 SeqScan、insert/delete/select/join/group by/order by 等算子、基于 left-deep-tree 与动态规划的成本优化器、使用 2PL 与 NO STEAL/FORCE 策略及页级锁的事务管理
  • 使用 Maven 构建替代课程推荐的 Ant，可在 Windows 上完成
  • 包含课程原文档之外的两个新增实验：Recovery 与 B+Tree

适用场景（解读层）

  • 学习数据库课程实验（CS186/MIT 6.830）时参考已有实现
  • 研究基于代价的连接优化器与 left-deep-tree 动态规划实现
  • 学习基于 2PL 与页级锁的事务管理及死锁检测（超时或依赖图环检测）
