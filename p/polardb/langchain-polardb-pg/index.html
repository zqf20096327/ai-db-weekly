PolarDB PostgreSQL 的 LangChain 集成库，基于 polar_ai 扩展实现库内向量检索

综述（解读层）

langchain-polardb-pg 是 Alibaba Cloud PolarDB for PostgreSQL 的 LangChain 集成包，提供库内文本向量化、向量存储与 AI 模型管理，依赖 polar_ai 扩展。面向使用 LangChain 构建检索应用且数据存于 PolarDB 的开发者。支持两种嵌入模式：标准版 ai_text_embedding（单条 SQL 内联计算，1536 维）与企业版 AI 节点 call_model（两步调用，1024 维），模式可从集群属性自动解析。需 Python 3.9+，auto-discovery 需阿里云 OpenAPI 凭据。

  • 在 PolarDB 数据库内直接计算文本嵌入，无需外部 API 调用
  • PolarDBPGVector 继承社区 PGVectorStore，支持相似度搜索、MMR 检索、按 ID 或元数据过滤删除
  • PolarDBPGModelManager 提供 create/alter/drop/list 等 Python API 管理模型，from_instance() 可通过阿里云 OpenAPI 自动发现集群端点

适用场景（解读层）

  • 在 PolarDB 中存储文档并使用 LangChain 构建向量相似度检索应用
  • 通过 in-database 嵌入减少外部 embedding API 调用的数据处理流程
  • 以 Python API 管理数据库中注册的 AI 模型及其调用
