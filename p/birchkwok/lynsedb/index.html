🧭 简介解读层（AI·证据行可回查）

Python 优先向量数据库，Rust 存储/检索引擎，支持嵌入式、HTTP 服务与分片集群三种部署形态。

综述（解读层）

LynseDB 是面向 AI 应用的向量数据库：Python 客户端 API，底层为 Rust 实现的存储与检索核心。同一客户端 API 可连接嵌入式模式、HTTP 服务模式（含 API 密钥、健康检查等运维端点）或由协调者管理的分片集群。需 Python 3.9+，通过 pip 安装 lynsedb；嵌入式模式限定单进程持有数据目录。

  • 同一 VectorDBClient API 覆盖嵌入式、HTTP 服务与协调者分片集群三种部署形态，集群含哈希分桶路由、副本写入镜像与主节点故障提升
  • 检索功能包含稠密/稀疏向量、SQL 风格元数据过滤、BM25、混合检索、命名字段与外部重排钩子，索引支持 FLAT、HNSW、IVF、SPANN、DiskANN 及量化索引
  • 除嵌入向量外，原生提供坐标（Haversine）、二进制指纹（Hamming/Tanimoto 等）、数值特征与概率分布等领域的距离度量

适用场景（解读层）

  • RAG、语义搜索、Agent 记忆、文档问答等需要在本地原型与服务/集群间平滑迁移的检索场景
  • 需要按坐标、分子指纹、传感器曲线或分布数据做相似度检索的应用
  • 多进程或多服务共享向量数据的部署，可通过 HTTP 服务模式或集群模式运行
