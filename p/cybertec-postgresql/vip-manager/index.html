🧭 简介解读层（AI·证据行可回查）

基于 etcd/Consul/Patroni 状态管理虚拟 IP 的工具

综述（解读层）

vip-manager 监控 etcd、Consul 或 Patroni REST API 中的 leader 状态键，当返回值匹配 trigger-value 时在本机网络接口上注册虚拟 IP，否则注销，通常用于 Patroni PostgreSQL 集群的主节点切换。本地注册/注销需要超级用户权限；也可通过 Hetzner API 管理 Floating-IP，无需该权限。配置支持 YAML、环境变量和命令行 flag，优先级为 flag > env > config。

  • 支持 etcd、Consul 和 Patroni REST API 三种状态源，可按指定间隔轮询 trigger-key 并在值匹配时注册、不匹配时注销虚拟 IP
  • manager-type 支持 basic（本地接口加/删 IP）和 hetzner（通过 Hetzner Robot/Cloud API 路由 Floating-IP）两种机制
  • 支持 etcd TLS 证书认证、consul-token 鉴权，重复错误日志每分钟汇总一次并显示抑制条数

适用场景（解读层）

  • Patroni 管理的 PostgreSQL 高可用集群中，为主节点提供虚拟 IP 接入点
  • 使用 Hetzner 托管服务器、需通过 API 切换 Floating-IP 路由的场景
  • PostgreSQL 需绑定非本地虚拟 IP 时配合 ip_nonlocal_bind 内核参数部署
