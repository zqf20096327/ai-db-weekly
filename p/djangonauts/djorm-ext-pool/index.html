基于 SQLAlchemy 连接池实现的 Django DB-API2 连接池应用

综述（解读层）

djorm-ext-pool 是一个 Django 应用，借助 SQLAlchemy 的连接池机制为 Django 提供数据库连接池功能，工作基于 django-postgrespool 项目。安装后只需将 djorm_pool 加入 INSTALLED_APPS 即可启用。README 说明目前仅在 postgresql 上经过测试，mysql 与 sqlite3 尚未实测。可通过 DJORM_POOL_OPTIONS 配置池大小等参数。

  • 通过在 INSTALLED_APPS 中添加 djorm_pool 即可启用连接池
  • 支持通过 DJORM_POOL_OPTIONS 配置 pool_size、max_overflow、recycle 等参数
  • 提供 DJORM_POOL_PESSIMISTIC 选项，在每次取出连接时执行额外查询检查连接状态

适用场景（解读层）

  • 使用 PostgreSQL 的 Django 项目需要数据库连接池
  • 需要自定义连接池大小与连接回收周期
  • 需要悲观连接检测以确保取出的连接可用
🔌 适配哪些库db_scan 程序判定

MySQL、PostgreSQL、SQLite
