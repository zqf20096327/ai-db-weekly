🧭 简介解读层（AI·证据行可回查）

Java 事务性发件箱库：同事务写 PostgreSQL，中继保序投递到 Kafka

综述（解读层）

Tandem 是实现 Transactional Outbox Pattern 的 Java 库：业务变更与 outbox 行在同一个数据库事务中写入，由独立 relay 轮询 tandem_outbox 表并以 at-least-once、按 aggregate 保序的方式发布到 Kafka，不依赖 CDC 或 Kafka Connect。面向使用 PostgreSQL 与 Kafka 的 Java/Spring Boot 开发者，提供 Spring Boot 自动配置、Admin API、tandem-cli 与 Micrometer/OpenTelemetry 可观测性。要求 Java 17+，事件按 aggregate_id 作为 Kafka key 发布，崩溃重发可能产生重复，需消费方幂等。

  • 在同一数据库事务中写入领域变更与 outbox 事件，relay 轮询 PostgreSQL 并以 at-least-once、按 aggregate 保序发布到 Kafka，无需 CDC 或 Kafka Connect
  • 提供 Spring Boot 自动配置、Admin API（含 replay/discard、bucket/worker 查询，LEASE/SINGLE 协调模式）、tandem-cli 命令行工具及 Micrometer/OpenTelemetry 指标与链路导出
  • 附带 tandem-sample、Spring、JPA 三类示例与 benchmark 演示，通过 Testcontainers 启动真实 PostgreSQL/Kafka；基准文档报告 600 events/s 下 p50 13ms、p99 87ms，清空 71.3 万行积压约 405 秒

适用场景（解读层）

  • 微服务中需要避免双写、将数据库变更以事件形式发布到 Kafka 的 Java/Spring Boot 应用
  • 需要按聚合保证事件顺序、且不希望部署 Debezium 等 CDC 基础设施的 PostgreSQL + Kafka 环境
  • 需要 outbox 积压监控、失败消息重放/丢弃及 Grafana 指标面板的事件驱动系统运维场景
