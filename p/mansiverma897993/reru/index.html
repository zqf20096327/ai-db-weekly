Rust 编写的 Redis 兼容缓存服务器，通过 RESP2 协议复用现有客户端

综述（解读层）

ReRu 是用安全 Rust 实现的 Redis 兼容内存数据服务器，支持 RESP2 协议，现有 Redis 客户端（redis-cli、redis-py 等）无需修改即可连接。实现约 203 条命令、TTL、多种淘汰策略、快照/AOF/RDB 持久化、只读副本、流与发布订阅。每个连接使用一个操作系统线程，写命令串行执行。项目处于实验阶段，官方明确不建议用于生产环境，TLS、多用户 ACL、RESP3、Lua 等尚未实现。

  • 支持 RESP2 协议，兼容 redis-cli、redis-py、ioredis、Lettuce 等客户端
  • 实现 459 条命令元数据中的 228 条（49.7% 命令名覆盖），含字符串、列表、哈希、集合、有序集合、流、地理空间等结构
  • 提供快照、单文件 AOF（支持在线重写）、Redis RDB 子集读取三种持久化模式及只读副本复制

适用场景（解读层）

  • 本地开发与兼容性实验环境
  • 复用现有 Redis 客户端进行协议与命令行为验证
  • 研究 Redis 命令语义与持久化格式的参考实现
📖 README 首段存档原文 · 程序抽取

ReRu speaks RESP2, so existing Redis clients connect without changes. It reimplements a growing slice of Redis and its persistence formats in safe, dependency-light Rust.
