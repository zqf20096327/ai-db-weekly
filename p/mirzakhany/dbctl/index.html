🧭 简介解读层（AI·证据行可回查）

DBCTL 是在 Docker 中运行临时数据库的命令行工具，用于测试环境。

综述（解读层）

DBCTL 用于在 Docker 容器中启动临时数据库（Postgres、Redis、MongoDB），自动应用迁移文件与示例数据，输出连接 URL，并在结束时清理。面向需要独立测试数据库的开发者，提供 Go 与 Python SDK，可在单元测试中为每个测试创建独立数据库实例。README 明确说明其不用于生产环境。

  • 支持通过 `go install`、预编译二进制或 Docker 镜像安装，可启动 Postgres（含 PostGIS）、Redis、MongoDB 并按路径顺序应用迁移文件，跳过 `*.down.sql` 文件
  • 提供 testing 模式与 API 服务器，配套 Go 和 Python SDK 可在测试中创建数据库；首个实例会被快照为模板，后续实例从快照创建而不重新执行迁移
  • 支持 `-d` 后台运行、`ls` 列出实例、按实例 ID/标签停止，`--label` 可隔离多项目实例，`-p 0` 自动分配可用端口，Postgres 与 MongoDB 可通过 `--ui` 启动 pgweb 或 mongo-express

适用场景（解读层）

  • 为单元测试提供独立数据库：通过 Go 或 Python SDK 在每个测试中创建带迁移和样例数据的临时数据库，测试结束后自动删除
  • 本地开发与实践：快速启动带迁移文件和示例数据的 Postgres、Redis 或 MongoDB，并可选择启动 pgweb / mongo-express Web UI 进行查看
  • 并行运行多个项目：使用 `--label`、`-p 0` 和 `--api-port` 让多个项目同时运行各自的测试数据库实例且互不影响
