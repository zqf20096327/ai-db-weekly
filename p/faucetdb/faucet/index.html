🧭 简介解读层（AI·证据行可回查）

单二进制 Go 服务器，将 SQL 数据库生成 REST API 与 MCP 服务

综述（解读层）

Faucet 是 MIT 许可的开源单二进制服务器，通过运行时内省 PostgreSQL、MySQL、MariaDB、SQL Server、Oracle、Snowflake 或 SQLite 的模式，生成 CRUD REST 端点、OpenAPI 3.1 文档、MCP 工具和内置管理界面。支持 API key、JWT 认证与按表 RBAC。安装方式含 npm、Homebrew、Docker、go install 及预编译二进制。行级安全过滤器目前仅存储返回，未强制执行。

  • 运行时内省数据库模式，生成 CRUD REST API、OpenAPI 3.1 规范与 MCP 工具，无需代码生成或 ORM
  • 内置 MCP 服务器（8 个工具 + 2 个资源），位于 /mcp 端点，AI 代理遵循与 REST 客户端相同的 RBAC 规则和 API key
  • 支持 API key（SHA-256 哈希）、JWT 认证、按表动词级 RBAC，以及三种模式的 schema 契约锁定与漂移检测

适用场景（解读层）

  • 为应用快速生成 CRUD 后端，跳过手写 API
  • 向 Claude、Cursor、ChatGPT 等 MCP 兼容 AI 工具提供受角色权限管控的数据库读写访问
  • 为旧版数据库（如 SQL Server 2012、MySQL 5.7）或多库环境提供统一 REST API 入口
📖 README 首段存档原文 · 程序抽取

Endpoints, OpenAPI specs and MCP tools are generated from your database schema at runtime. No code generation, no ORM, no boilerplate.
