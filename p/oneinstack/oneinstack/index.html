基于 Shell 交互的 LEMP/LAMP 等环境一键部署脚本

综述（解读层）

OneinStack 是用 Shell 编写的 Web 环境部署脚本，在 64 位 RHEL、Debian、Ubuntu 等主流发行版上以源码编译方式安装 Nginx/Tengine/OpenResty/Caddy/Apache、多种 MySQL/MariaDB/Percona/PostgreSQL/ClickHouse/MongoDB、多版本 PHP 及 JDK/Tomcat。提供交互与自动安装、虚拟主机管理、升级卸载脚本及多种远端备份方式。安装时发送匿名遥测（不采集个人数据）。适用于需要在 Linux 服务器上自行搭建 PHP/JAVA 运行环境的管理员。

  • 支持交互式与自动安装，通过 install.sh 以源码编译方式部署 Web 服务器、数据库、PHP、JDK/Tomcat 等组件
  • 提供多版本组件选择（如 PHP 5.3–8.6、MySQL 5.5–9.7、Tomcat 7–11、OpenJDK 8/11/17/18），并附虚拟主机管理、组件升级、卸载与备份脚本
  • 备份脚本支持本地、rsync 远程、阿里云 OSS、腾讯 COS、七牛、Amazon S3、Google Drive、Dropbox；虚拟主机支持 Let's Encrypt 及 DNS-01 通配符证书自动续期

适用场景（解读层）

  • 在 RHEL/Debian/Ubuntu 等 64 位发行版服务器上快速部署 LNMP/LAMP 等 PHP 或 JAVA 运行环境
  • 需要多版本 PHP、多数据库版本共存或按需添加 PHP 扩展的运维部署
  • 需要配置虚拟主机 SSL 证书并定时备份到本地或多种对象存储的服务器管理
