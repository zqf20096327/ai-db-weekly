🧭 简介解读层（AI·证据行可回查）

基于 Claude Code hooks 与 statusline 的本地 SQLite 会话分析 CLI 工具。

综述（解读层）

该项目通过 Claude Code hooks（PostToolUse、UserPromptSubmit）在会话暂停期间采集会话、工具调用、成本与性能数据，写入本地 SQLite 数据库，并提供 statusline 显示与 analytics/quick-stats 等子命令生成报表。数据仅存于本地，无网络请求，可通过配置文件按项目关闭采集。适用于使用 Claude Code 且希望留存本地使用数据的开发者。

  • 通过 hooks 在 Claude Code 暂停时段执行数据采集，statusline 以亚毫秒查询预计算数据
  • 提供 config、analytics、quick-stats、install/uninstall 等子命令，含表格与 ASCII 图表报表
  • 数据存储于本地 SQLite（~/.claude/claude-code-analytics.db），README 声明无遥测与网络调用

适用场景（解读层）

  • 本地留存并查看 Claude Code 会话成本、缓存效率与工具性能统计
  • 为 Claude Code statusline 配置可定制的生产力量表与迷你图显示
  • 在特定仓库中通过项目级配置启用或禁用数据采集
