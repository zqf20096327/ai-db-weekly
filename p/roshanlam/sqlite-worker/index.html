sqlite-worker：基于队列机制的 Python 线程安全 SQLite 操作封装库

综述（解读层）

sqlite-worker 是一个 Python 包，为 SQLite 提供线程安全操作接口，通过队列执行多线程发出的查询。它提供初始化动作、定期提交、事务（手动与上下文管理器）、ORM 风格 CRUD、查询钩子、带版本控制与回滚的迁移以及自动重连。通过 pip3 install sqlite-worker 安装，适用于多线程应用、Web API、后台任务等需要并发访问 SQLite 的场景，操作完成后需调用 close() 清理。

  • 通过队列机制提供线程安全的 SQLite 查询执行，支持跨线程访问同一数据库
  • 提供 ORM 风格 CRUD 方法、事务（手动与上下文管理器）、查询钩子（on_insert/on_update 等）、带版本控制与回滚的数据库迁移及自动重连（可配置重试次数与延迟）
  • 支持连接时执行一次的初始化动作与按查询数量触发的定期提交

适用场景（解读层）

  • 多线程 Python 应用中并发读写 SQLite 数据库
  • Web API 与后台任务队列中的数据存储
  • 需要版本化数据库迁移与查询事件通知的应用
