综述（解读层）

Otto 是一个开源的基于 Web 的 ETL 工作流管理器，用于编排数据的收集、转换和加载。用户通过浏览器以可视化方式创建工作流，添加 schedule、extract、transform、load 四类节点并连线定义执行顺序，配置定时执行或手动执行。技术栈包含 Node.js、Express、React、ReactFlow、PostgreSQL 等，通过 Docker Compose 部署，运行后经 localhost:3001 访问。

  • 提供可视化节点编辑界面，支持 schedule、extract、transform、load 四类节点及连线排序
  • 工作流分为 Test 与 Active 两种状态，Active 状态按 schedule 节点设定的时间与间隔自动执行
  • 保存全部工作流执行日志，可查看各节点的输入输出、成功状态与错误信息，并跟踪 Active 工作流指标

适用场景（解读层）

  • 需要定时调度数据抽取、转换与加载流程的数据处理场景
  • 希望在浏览器中以节点连线方式搭建和调试 ETL 流程的团队
  • 需要保存执行日志并查看节点级输入输出与错误信息以排查数据任务问题的场景
