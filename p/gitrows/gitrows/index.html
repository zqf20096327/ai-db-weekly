以 Git 仓库作为数据库的轻量 JS 模块，支持 GitHub/GitLab

综述（解读层）

GitRows 是一个 JS 模块，可在 node 与浏览器中运行，用于读写 GitHub/GitLab 仓库中的 .csv、.json 及基础 .yaml 文件。它提供 get/put/update/delete 等 CRUD 方法，写入需提供用户名与访问令牌；读取公开仓库无需令牌，私有仓库需令牌。路径支持浏览器文件 URL 或 API 风格表示法。

  • 实现对仓库数据文件的完整 CRUD 操作，支持 GitHub 与 GitLab（含自托管 GitLab，通过 server 选项指定地址）
  • 支持对象数组形式的行级数据操作，提供 filter 表达式、strict 列模式、types() 列类型检测及文件级的 create()/drop()
  • 读取公开仓库无需令牌，可选 fetch 或 pull 两种取数方式；也可通过免费 API（api.gitrows.com）查询公开仓库

适用场景（解读层）

  • 在网站或应用中读取 GitHub/GitLab 公开仓库里的 .csv/.json 数据
  • 通过版本控制方式以提交记录维护仓库中的结构化数据文件
  • 在前端或 node 脚本中程序化创建、更新、删除仓库中的数据文件
