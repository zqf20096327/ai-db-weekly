综述（解读层）

Stiller Brain 是一个基于 Python 与 SQLite 的 LLM 长期记忆后端，面向支持 OpenAI 兼容 Chat Completions 网关与 MCP 工具调用的模型及客户端。AI 通过工具保存经历、知识与计划，网关按对话语境在回复前注入相关记忆，支持自写提醒、主动整理与版本回看。提供 Windows、Linux 及 Android Termux 实验性部署路线，许可证为非商业源码预览。

  • 提供两种接入方式：ST 网关在回复前自动注入相关记忆，MCP 工具支持主动查询、保存与修改记录
  • 包含自我定义、情感、学习、工具、规划等模块及独立的幻觉黑匣子区域，记忆保留原文与版本历史
  • 支持自写提醒、短期换窗交接、图片附件、情绪词表，可按模块开关自动浮现

适用场景（解读层）

  • 为具备 MCP 调用能力的 LLM 客户端构建可跨会话延续的记忆库
  • 部署者通过网关让模型在多轮对话中按话题关联自动带回既往记录
  • 在 Windows/Linux/VPS 或 Android Termux 上本地部署记忆后端
