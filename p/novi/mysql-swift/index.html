基于 libmysqlclient 的 Swift 类型安全 MySQL 客户端库

综述（解读层）

mysql-swift 是面向 Swift 服务端开发的 MySQL 客户端库，设计参考 Node.js 的 mysql。它基于 libmysqlclient，支持原始 SQL 查询、参数格式化与转义，并可将查询结果映射为 Codable 结构体。README 声明该库已停止维护，且依赖 libmysqlclient，暂不支持异步 I/O。许可证为 MIT。

  • 基于 libmysqlclient，支持 Linux 和 macOS
  • 提供原始 SQL 查询及参数格式化与转义
  • 支持将查询结果映射为 Codable 结构体或类，内置连接池和事务接口

适用场景（解读层）

  • 在 Swift 服务端项目中执行 MySQL/MariaDB 查询
  • 需要将查询结果直接映射为 Swift Codable 类型的场景
  • 使用连接池管理多个连接或以事务方式执行多条 SQL 的场景
