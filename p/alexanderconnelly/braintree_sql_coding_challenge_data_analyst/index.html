Braintree 数据分析师面试 SQL 编码测试的题库与要求存档

综述（解读层）

该仓库收录一份 Braintree 数据分析师招聘流程中的 SQL 编码挑战题目及说明。要求候选人在 7 天内用任意 SQL 方言（如 MySQL、Postgres）从 CSV 文件建库，完成数据清洗、排名、占比、窗口累计等 7 道题并提交查询与答案。数据含空值与重复记录，需说明处理方式。适合作为 SQL 面试题练习材料。

  • 包含 7 道覆盖数据清洗、同比增长计算、占比报表、排序与累计求和的 SQL 题目
  • 提供含空值与重复记录的 GDP 数据集，要求提交建库与导入数据的完整代码
  • 规定答案格式：金额保留两位小数带 $ 前缀，百分比保留两位小数带 % 后缀

适用场景（解读层）

  • 准备数据分析师岗位 SQL 面试的自测练习
  • 学习用 SQL 处理含空值与重复数据的真实场景
  • 练习窗口函数、排序规则与数据完整性检查等查询技巧
