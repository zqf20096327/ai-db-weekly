基于 go-kratos 的多租户用户行为分析（UBA）平台，事件经 Kafka 入 OLAP 数仓

综述（解读层）

GoWind UBA 是用 Go/go-kratos 编写的用户行为分析平台，提供事件、漏斗、留存、归因、路径、分群及游戏专项共 25 个分析模型。数据由 Web/C# SDK 经 Collector 写入 Kafka，由 Doris Routine Load（ClickHouse 路径当前为编译期关闭）入仓，前端为 Vue 3 + Ant Design Vue，报表可对接 Superset。适用对象是自建行为分析的企业与游戏团队；部署依赖 PostgreSQL、Kafka、Doris 等较多组件。

  • 提供 25 个分析模型，覆盖通用行为分析、用户深度洞察和游戏专项（关卡/LTV/滚服留存/PCU/经济系统）三类
  • 事件采集链路为 SDK → Collector → Kafka → Doris Routine Load 入仓，ClickHouse 分支存在但当前编译期常量设为 false
  • 多租户数据隔离，JWT 鉴权与 Casbin/OPA 权限引擎，Docker 提供完整模式与仅中间件两种部署方式，MIT 协议开源

适用场景（解读层）

  • 网站/网页产品的事件、漏斗、留存、路径等用户行为分析，通过 Web SDK 埋点接入
  • Unity/Godot 游戏的关卡卡关率、付费分层、LTV、区服留存与经济系统监控
  • 需要分群、指标阈值告警、定时报告与 Webhook 告警的自建数据增长/风控场景
