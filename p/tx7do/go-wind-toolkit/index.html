面向 Go-Kratos 微服务的 CLI 与桌面端代码生成工具集

综述（解读层）

该项目为 Go-Kratos 微服务生态提供 gow CLI 与 Wails (Vue 3) 桌面客户端两种使用方式，功能涵盖项目脚手架、从数据库 Schema 生成 Ent/GORM 模型与 Protobuf gRPC/REST 定义、Wire 依赖注入、基于 OpenAPI 的前端页面生成、watch 模式运行、ent schema 逆向导出 DDL 及配置导出到 Consul/Etcd/Nacos。面向使用 Kratos 框架进行微服务与配套管理页面的开发者；Oracle 连接不能作为生成数据源，模块提取默认会删除源端文件。

  • 支持从 MySQL/PostgreSQL/SQLite 数据源、DDL 文件或 ent/gorm 源码目录生成 CRUD 代码、Ent/GORM 模型、proto 定义与 Wire 注入代码
  • 基于 OpenAPI 3.0 规范生成 Vue3 + Element Plus、Vue3 + Vben Admin、React + Ant Design Pro 三种框架的管理页面代码
  • 提供 watch 模式增量重建、微服务模块提取、ent schema 离线导出 DDL 及版本化迁移文件生成

适用场景（解读层）

  • 为 Kratos 微服务项目创建脚手架并从数据库表生成后端 gRPC/REST 服务代码
  • 从 proto 或 OpenAPI 定义批量生成配套的前端管理页面及 TS/Dart 客户端 SDK
  • 在开发过程中实现服务热重载运行、配置导出到远程配置中心以及 schema 迁移脚本管理
