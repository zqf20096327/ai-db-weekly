面向 Crystal 的 SQL 查询生成库，用 DSL 生成多方言 SQL 语句

综述（解读层）

该项目是一组围绕 SQL 查询处理的 Crystal shard，包含 SQL::Query 查询生成 DSL、InformationSchema 数据库内省与 Migrate 迁移三个模块，目前处于早期 alpha 阶段。它支持 MySQL/MariaDB、PostgreSQL、SQLite3 三种数据库方言，可自动处理占位符与标识符引用等方言差异，并明确声明不执行查询、不做 ORM。适合需要以 Crystal 代码构建 SQL 语句、作为 ORM 基础层的开发者。InformationSchema 与 Migrate 模块文档尚缺。

  • 提供 SQL::Query DSL 生成 SQL 语句，支持子查询、函数、别名、WITH 等结构，不执行查询
  • 针对 MySQL、PostgreSQL、SQLite3 方言生成对应格式的占位符与标识符引用
  • 包含 SQL::InformationSchema 数据库内省模块与 SQL::Migrate 数据库迁移模块

适用场景（解读层）

  • 在 Crystal 项目中以类型安全的方式拼接生成 SQL 查询语句
  • 为自研 ORM 或 Repo 层提供查询构建基础
  • 需要适配多种数据库方言占位符与引用规则的查询生成
