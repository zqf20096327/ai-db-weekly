自托管零代码 AI Agent 平台，拖拽工作流 + 知识库 RAG + 可扩展技能目录

综述（解读层）

AgentFlow 是一个自托管的零代码 AI Agent 平台，提供 ReactFlow 拖拽式工作流编辑、知识库 RAG（向量模型独立配置）、多模型热切换和以 SKILL.md 目录形式扩展的技能体系，内置 26 个技能。默认使用 SQLite 单机运行，支持 docker compose 部署，面向无开发团队的企业、产品经理与低代码开发者。注意 Docker 镜像未装 sentence-transformers，需配置 EMBEDDING_BASE_URL 才能使用知识库检索。

  • 六类节点（触发器/LLM/知识库/工具/条件分支/回复）的 ReactFlow 拖拽式工作流编辑，保存即生效
  • 知识库 RAG：文档上传自动分块入库，向量嵌入与对话模型分开配置
  • 内置 26 个技能目录，按 SKILL.md 格式添加文件夹即可扩展，管理员可后台增删

适用场景（解读层）

  • 无开发团队的企业搭建 AI 客服、销售助手等场景 Agent
  • 产品经理快速验证 Agent 场景（可用模板市场一键套用）
  • 需要数据自托管的私有化部署，通过 docker compose 单机运行
