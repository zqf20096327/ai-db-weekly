随机 SQL 查询生成器，用于对数据库进行模糊测试

综述（解读层）

SQLsmith 是一个随机 SQL 查询生成器，用于对 RDBMS 进行模糊测试。它连接目标数据库读取模式信息并生成查询发送执行，当前支持 PostgreSQL、SQLite 3 和 MonetDB；所有生成的语句会回滚。面向数据库产品及扩展的开发者。需注意其可能调用有副作用的函数，README 建议使用低权限用户连接，且工具可能损坏数据库。

  • 支持为 PostgreSQL、SQLite 3 和 MonetDB 生成随机查询；扩展新 RDBMS 需实现两个类（模式信息与连接）
  • 提供 --seed、--dry-run、--max-queries、--log-to、--dump-all-queries 等命令行选项，并支持多实例日志汇入中央 PostgreSQL 库
  • 自 2015 年起在上述产品的 alpha、beta 和发布版本中发现 118 个 bug，包括已发布版本中的安全漏洞

适用场景（解读层）

  • 数据库产品开发者在发布前对 RDBMS 进行随机查询测试
  • 扩展开发者让其代码接受随机工作负载检验
  • 通过 --log-to 集中收集多个测试实例的错误报告
