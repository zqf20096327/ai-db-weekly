基于多LLM的AI代码审查平台，支持Git集成与实时协作

综述（解读层）

AIReview 是一个代码审查平台，后端采用 .NET 8（ASP.NET Core、EF Core、Hangfire、SignalR），前端为 React 19 + TypeScript + Vite，README 声明代码全部由 Copilot 生成。它通过可配置的 LLM 提供商（OpenAI、Azure OpenAI 等）分析代码变更，生成风险评分与改进建议，内置三级 Prompt 模板体系、RBAC 权限和 Docker 部署方案。需要自行配置 LLM API 密钥；Kubernetes 编排在 README 中标注为计划中。

  • 支持多维度 AI 分析（质量、安全、性能、可维护性）与自动风险评分，LLM 提供商可配置
  • 提供三级 Prompt 模板系统（内置→用户级→项目级），支持代码审查、风险分析、PR 摘要等模板类型
  • 内置基于 JWT 的身份认证、基于角色的访问控制（Owner/Reviewer/Developer），并提供 Docker Compose 部署与 SQLite/PostgreSQL 双数据库选项

适用场景（解读层）

  • 团队需要对 Pull Request 进行 AI 辅助的变更摘要、影响评估与风险检测
  • 需要结合 Git 仓库导入、Diff 解析和逐行评论的审查工作流
  • 希望以自定义 Prompt 模板管理不同项目的代码审查规则
