面向 Ubuntu 的 Ansible playbook 与角色集合，覆盖服务器部署运维

综述（解读层）

该仓库是作者编写的 Ansible playbook 集合，目标平台为 Ubuntu。内容分为 AWS 资源管理（VPC、EC2、IAM、安全组）、MySQL 操作（建库建用户、导出导入、迁移）及数十个 role，涵盖 Elasticsearch、Mesos、Jenkins、Kafka、Kubernetes 等服务的安装配置。部分 role 标注为 WIP 或不可用，使用者需自行验证。

  • 包含 AWS 相关 playbook，可创建 VPC、安全组、IAM 用户/组/角色及启动、启停 EC2 实例
  • 提供约 90 个 Ansible role，覆盖 Elasticsearch、Mesos、Kafka、Kubernetes、Jenkins、GitLab 等中间件部署
  • 提供 MySQL playbook，支持创建数据库和用户、导出导入数据及跨主机传输数据库

适用场景（解读层）

  • 在 Ubuntu 服务器上以 Ansible 自动化安装与配置常见中间件和开发工具
  • 通过 playbook 编排 AWS 资源的创建与 EC2 实例的启停管理
  • 自动化执行 MySQL 数据库的创建、备份导出、导入与迁移
