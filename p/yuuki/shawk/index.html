🧭 简介解读层（AI·证据行可回查）

基于 eBPF 内核追踪的服务器网络依赖记录工具，存储于 PostgreSQL 并以 Grafana 展示。

综述（解读层）

shawk 在每台主机上用 eBPF 追踪所有进程的 TCP/UDP 及 Unix stream socket 连接，无需插桩即可覆盖 cron 任务和第三方软件；agent 每 15 秒以 OTLP 上报，由 OpenTelemetry Collector connector 写入 PostgreSQL 并将指标送 Prometheus，Grafana 提供仪表盘。它记录每台主机的观测时段，可区分「未被使用」与「未被观测」。要求 Linux BTF 内核（5.14+，Unix socket 追踪需 BPF trampoline）、PostgreSQL 14+、Prometheus 3 与 Grafana；不追踪 datagram Unix socket 与 RDMA 传输。

  • 内核 eBPF 追踪全部进程的 TCP/UDP 与 Unix stream socket 连接，无需按语言或协议插桩
  • 同目标服务的流量在内核聚合，TCP 仅在连接状态变化时追踪，agent 不采样，低频任务（如每月一次的作业）也被记录
  • 记录主机观测时段与丢包时段，支持用 SQL（shawk_v1 视图）查询如「过去 90 天谁连接过某数据库」并判断是否在观测中

适用场景（解读层）

  • 系统变更前排查依赖：确认哪些进程仍在使用某个数据库、主机或服务
  • 部署后比对：通过 Grafana Changes 仪表盘查看新出现或消失的依赖
  • 集群可观测性建设：agent 经 OTLP 汇聚到 Collector，指标与 OBI 应用层指标共享同一 job 命名
