基于 PostgreSQL 收集多来源日志的 Go 日志服务

综述（解读层）

Bark 是一个用 Go 编写的日志收集服务，通过 REST 接口接收多个来源的日志并存储到 PostgreSQL，查询和清理直接用 SQL 完成。定位在纯文本日志与大规模日志聚合方案之间，README 明确它不适用于 TB 级日志场景。客户端库尚在开发中；发送日志时必须携带 code（LMID）或 message，批量插入时任一条目字段无效将导致整批被拒。

  • 提供 Web 服务，通过 REST 接口接收多来源日志并写入 PostgreSQL
  • 支持通过 SQL 按级别、日期、服务等条件过滤和删除日志
  • 数据库无法写入时将日志输出到服务器 STDOUT

适用场景（解读层）

  • 中小规模项目（约十几个服务）集中收集多服务日志
  • 希望用已有 SQL 技能直接查询、筛选和清理日志的场景
  • 作为纯文本日志向企业级日志方案过渡的中间方案
