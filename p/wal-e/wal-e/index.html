用于 PostgreSQL WAL 归档与基础备份的对象存储归档工具

综述（解读层）

WAL-E 是一个用 Python 编写的 PostgreSQL 持续归档工具，通过 wal-push/wal-fetch 处理 WAL 段、backup-push/backup-fetch 处理基础备份，支持 S3、Azure Blob、Google Cloud Storage、Swift 及本地文件系统。配置依赖环境变量，推荐配合 envdir 使用。README 声明该项目已废弃，不再例行审查补丁，维护者列出 WAL-G 与 pgBackRest 作为备选。

  • 提供 backup-push/backup-fetch 与 wal-push/wal-fetch 命令，配合 PostgreSQL 的 archive_command 与 restore_command 实现持续归档与恢复
  • 支持 AWS S3、Azure Blob、Google Cloud Storage、OpenStack Swift 及本地文件系统等多种存储后端
  • backup-fetch 支持 LATEST 伪备份名及按名称指定旧备份，用于时间点恢复（PITR）

适用场景（解读层）

  • 需要将 PostgreSQL WAL 段与基础备份存放到云对象存储的归档场景
  • 基于基础备份加 WAL 回放执行时间点恢复（PITR）的场景
  • 已有历史 WAL-E 归档、需要读取其存档的环境（可配合能读取 WAL-E 格式的工具）
