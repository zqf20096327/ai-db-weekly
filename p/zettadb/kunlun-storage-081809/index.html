基于 Percona MySQL 8.0 的存储组件，为 Kunlun 分布式数据库提供存储与 XA 增强

综述（解读层）

Kunlun-storage 是 Kunlun 分布式数据库（DDC）的存储组件，基于 percona-mysql-8.0.18-9 修改开发，包含 MySQL 已知 XA bug 的修复、XA 事务崩溃安全增强及部分性能增强，用作 DDC 的元数据集群和存储分片。其数据文件与部分 binlog 事件格式与社区版 MySQL/Percona Server 不同，数据目录不可互换；可使用 Percona xtrabackup 备份恢复。安装方法见 INSTALL.kunlun.md。

  • 基于 percona-mysql-8.0.18-9，修复 mysql-8.0.18-9 中的已知 XA bug
  • 修改了 innodb、binlog 恢复与 binlog 格式，支持 XA 事务崩溃安全
  • 数据目录可用 Percona xtrabackup 进行备份与恢复

适用场景（解读层）

  • 作为 Kunlun 分布式数据库集群（DDC）的元数据集群与存储分片
  • 需要在故障场景下保证 XA 事务提交不丢失的存储环境
  • 配合 Kunlun 计算节点使用（含功能一致的开源版/企业版数据目录互换）
