🧭 简介解读层（AI·证据行可回查）

面向 OceanBase 与 SeekDB 的 AI Agent Skills 技能包集合

综述（解读层）

该项目为 OceanBase 与 SeekDB 提供遵循 Agent Skills 规范的技能目录，每个技能是一个含 SKILL.md 与可选 references/ 的自包含目录，供 Claude Code、Cursor、Windsurf 等 Agent 加载使用。内容覆盖集群部署运维、obd 管理、obdiag 诊断、租户管理、基准测试及 SeekDB 全生命周期操作，可通过 skills.sh 或克隆复制安装。注意 oceanbase-deploy 为路由式捆绑包，需保留完整目录结构。

  • 包含 oceanbase-deploy 与 seekdb 两大技能包，覆盖集群生命周期、诊断、租户、测试基准及安装、构建、文档检索、CLI、导入、查询等子技能
  • 每个技能为含 SKILL.md 与按需加载 references/ 的自包含目录，遵循 Agent Skills 规范
  • 支持通过 npx skills add 自动检测 IDE 安装，或克隆仓库后复制目录进行版本固定的手动安装

适用场景（解读层）

  • 借助 AI Agent 执行 OceanBase 集群部署、启停、升级、租户管理与备份恢复等运维任务
  • 运行 Sysbench、TPC-H、TPC-C 等基准测试流程
  • 对 SeekDB 进行安装、源码构建、数据导入（含按列向量化）与混合检索查询
