面向数据库内核学习的教学用小型数据库，用 C++ 实现完整模块

综述（解读层）

MiniOB 是 OceanBase 团队基于华中科技大学数据库课程原型联合多所高校重写的教学项目，面向学生、数据库从业者和爱好者。代码简化了并发、安全等特性，保留网络、SQL 解析、优化、执行、存储引擎、MVCC、日志等关键模块，并提供由浅入深的题目与训练营平台。官方声明仅供学习，不可用于生产环境。

  • 包含网络、SQL 解析、语义解析、查询优化（部分实现）、执行器、存储引擎、MVCC 事务、Redo 日志、B+ Tree 索引等数据库关键模块
  • 提供 GitHub Pages 文档、doxygen 代码文档、《从0到1数据库内核实战教程》视频与讲义等配套学习资料
  • 支持通过 GitPod 和开源学堂在线编程环境进行开发，并可在 MiniOB 训练营提交代码测试

适用场景（解读层）

  • 在校学生或零基础学习者系统学习数据库内核原理与实现
  • 参加全国大学生计算机系统能力大赛数据库赛道的赛前训练
  • 练习内存管理、网络通信、磁盘 I/O 等工程编码能力
