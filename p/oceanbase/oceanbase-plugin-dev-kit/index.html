OceanBase 插件开发包仓库，维护开发头文件打包、示例代码与插件开发文档。

综述（解读层）

该仓库维护 OceanBase 数据库的插件开发包，包含打包于 OceanBase 源码 src/plugin/include/oceanbase 下的开发头文件、src/examples 目录下的示例代码，以及插件开发文档。README 注明插件机制目前属于实验室特性阶段，且仅支持分词器插件。面向需要开发或安装 OceanBase 插件的用户与开发者。

  • 提供插件开发包打包，开发头文件位于 OceanBase 源码 src/plugin/include/oceanbase 目录
  • 包含插件示例代码（src/examples 目录）和使用手册、开发手册、API 手册等文档
  • 文档涵盖插件安装卸载、插件开发及新增插件类型的流程

适用场景（解读层）

  • 开发 OceanBase 分词器插件
  • 查询插件安装、卸载及开发流程文档
  • 为 OceanBase 新增一种插件类型时参考示例与手册
