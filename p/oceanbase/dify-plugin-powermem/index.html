封装 PowerMem SDK 的 Dify 工具插件，用于在工作流中管理记忆

综述（解读层）

该插件由 oceanbase 发布（v0.0.3），将 PowerMem SDK 的同步工具接入 Dify 工作流与 Agent 策略，提供记忆增删改查及用户画像工具。输出 SDK 原始 JSON 与文本。凭据需配置 LLM 与嵌入 provider（默认 qwen）及数据库；默认 db 为 sqlite，用户画像与图存储功能仅在 db_provider=oceanbase 时可用。适合在 Dify 平台构建带记忆能力的 Agent 的开发者。

  • 提供 8 个记忆管理工具：add_memory / search_memories / update_memory / delete_all_memories / list_memories / get_profile / list_profiles / delete_profile
  • search_memories 支持向量与混合检索，可按 user_id/agent_id/run_id 划定作用域并附加过滤条件
  • add_memory 支持 infer 参数在智能合并与简单模式间切换；凭据支持 qwen/openai/siliconflow/deepseek 等 LLM 与嵌入 provider

适用场景（解读层）

  • 在 Dify 工作流或 Agent 策略中为助手添加记忆写入、检索、更新与删除能力
  • 在 OceanBase 数据库上启用用户画像工具，按 user_id 获取、列举或删除画像
  • 以 sqlite 为默认存储快速接入，或通过 seekdb 填写 OceanBase 连接方式作为向量存储
