OceanBase 数据库内核开发者入门教程文档仓库，基于 MiniOB 讲解数据库原理

综述（解读层）

该仓库托管 OceanBase 数据库开发者入门教程文档，共五章，从数据库系统概述、存储结构、索引、SQL 引擎到事务引擎，结合教学系统 MiniOB 讲解数据库内核原理，各章附 MiniOB 实践题目。文档以中文编写，面向学习数据库内核开发的开发者。仓库同时提供文档贡献流程，要求贡献者签署 CLA，并按 Fork、建分支、提交 PR 的 GitHub 工作流协作。

  • 提供五章教程，覆盖数据库概述、存储结构、B+ 树与 LSM 索引、SQL 引擎（Parser/Optimizer/Executor 等）及事务（undo/redo 日志、隔离级别、MVCC）
  • 结合 MiniOB 系统讲解实现原理，每章包含课后实践题目，并支持通过 Dockerfile 或手动构建搭建开发调试环境
  • 接受社区文档贡献，贡献流程包含签署 CLA 与标准 Git Fork-PR 工作流

适用场景（解读层）

  • 系统学习数据库内核原理（存储、索引、SQL 引擎、事务）
  • 为参与 OceanBase 相关训练营或 MiniOB 开发做入门准备
  • 查阅或参与共建 OceanBase 开发者教程文档
