基于ob-operator与chaosblade的OceanBase高可用测试平台

综述（解读层）

ob-open-test是在Kubernetes环境上面向OceanBase的测试工具，依赖ob-operator实现集群的创建与销毁，依赖chaosblade注入混沌实验，通过HTTP接口提供集群增删查等服务。它提供服务和单例两种使用方式：服务允许用户自行编排task>steps>model结构的任务，单例则直接运行预设场景。运行需在可访问K8s集群的环境。

  • 基于ob-operator实现OceanBase集群的创建、信息获取与销毁，集群创建为异步操作
  • 封装chaosblade调用，可对拉起的namespace执行混沌实验注入
  • 采用task>steps>model三层调度结构，task支持步骤顺序编排，model以SDK形式包装各工具

适用场景（解读层）

  • 在Kubernetes环境上对OceanBase进行高可用与稳定性测试
  • 通过task编排设计稳定性测试、压测、基础SQL验证、模糊测试等自动化测试任务
  • 通过HTTP接口独立调用obcluster等模块，实现集群的自动化创建与销毁
📖 README 首段存档原文 · 程序抽取

ob-open-test是一个基于ob-operator、chaosblade的开源测试工具，其核心为基于K8S环境建设的高可用测试平台。 开源最重要的是可信，一个产品是否能被选用，可靠性测试是极为重要的。OceanBase是一个属于数据库基建的底层应用，其是否稳定、是否高可用于上层业务逻辑强关联。 因此我们设计了ob-open-test来面向OceanBase实现低成本的测试，多场景平台设计。
