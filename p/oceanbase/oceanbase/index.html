基于 Paxos 协议的分布式关系数据库，提供 HTAP 能力与 MySQL 兼容

综述（解读层）

OceanBase 是由蚂蚁集团开发的分布式关系数据库，基于普通服务器集群运行，依赖 Paxos 协议与分布式结构提供高可用和水平扩展能力，不依赖特定硬件架构。兼容 MySQL 协议便于迁移，支持 HTAP 场景，并提供 all-in-one 安装包、Docker 镜像和 Kubernetes 的 ob-operator 三种部署方式，仅支持 Linux 运行。

  • 基于 Paxos 协议实现高可用，README 标注 RPO=0、RTO<8s
  • 支持 MySQL 兼容，用于从 MySQL 迁移
  • 支持单机、Docker、Kubernetes（ob-operator）部署方式

适用场景（解读层）

  • 需要从 MySQL 迁移的分布式数据库场景
  • 事务与分析混合处理（HTAP）场景
  • 在 Kubernetes 集群中部署管理数据库实例
