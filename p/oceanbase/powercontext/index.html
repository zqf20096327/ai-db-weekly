🧭 简介解读层（AI·证据行可回查）

面向 AI Agent 的开源上下文服务，以修订版 Artifact 在会话与 Agent 间延续工作状态。

综述（解读层）

PowerContext 是 OceanBase 开源的上下文服务，面向使用 Claude Code、Codex 等 Agent 的开发者与团队。它将决策、约束、交接记录等存为服务器端修订版 Artifact，划分 Scope 隔离数据，提供 Memory、Handoff、Experience、Skill 服务，经 HTTP/MCP、Python Client、CLI、Dashboard 暴露。安装需 Python 3.11+、Git、uv，支持 macOS/Linux，Windows 为实验性。

  • 提供 Memory、Handoff、Experience、Skill 四类服务，Artifact 以 FAMILY/ARTIFACT_ID@REVISION 形式编址，读取精确引用返回历史快照
  • 提供 HTTP/MCP 接口、Python Client、CLI、Dashboard 与 Desktop 预览，支持 Kubernetes 部署与外部 OceanBase 的 Helm chart
  • PreparedContext 按共享字节预算选择活跃 Memory 与已批准 Experience 内容，显式 Memory 写入无需模型 API

适用场景（解读层）

  • 跨会话或跨 Agent（如 Codex 与 Claude Code 之间）延续任务上下文与工作交接
  • 团队中人与人之间通过 Handoff 与审查后的 Memory 接手进行中的工作
  • 无模型 API 的本地部署场景下进行显式记忆保存与检索
