通过 libseekdb C API 在 Go 程序中管理嵌入式 seekdb 服务器的绑定库

综述（解读层）

seekdb-go 是一个 Go SDK，通过 cgo 调用 libseekdb C API 来启动、打开和关闭嵌入式 seekdb 服务器，SQL 查询需配合 MySQL 协议驱动完成。构建要求 Go 1.22+、CGO_ENABLED=1 和目标平台的 C 编译器；原生运行时以四个按平台独立版本化的 Go 模块形式分发，构建时嵌入所选平台的 bundle，首次 Open 时解压到用户缓存目录，Open 不会联网下载。适用对象为需要在 Go 应用中内嵌 seekdb 的开发者。

  • 提供 Open、ConnectionOptions、Close 三个核心 API，Open 可自动创建数据库目录并重新打开既有数据
  • 四个平台原生模块（macOS arm64、Linux amd64/arm64、Windows amd64）经 build constraints 选择并嵌入程序，附 SHA-256 校验
  • Linux 捆绑包包含 OpenSSL 1.1、libaio、zlib，当前版本为 seekdb 1.4.0.0-r1；CI 覆盖 SQL 集成测试

适用场景（解读层）

  • 在 Go 应用中以嵌入式方式运行 seekdb，无需单独部署数据库进程
  • 需要离线分发（bundle 嵌入二进制，Open 不下载文件）的桌面或边缘场景
  • 配合 go-sql-driver/mysql 等 MySQL 协议驱动执行 SQL，包括事务、向量查询等集成用法
📖 README 首段存档原文 · 程序抽取

This package manages an embedded seekdb server through the libseekdb C API. It provides Open, ConnectionOptions, and Close. Use a MySQL protocol driver of your choice for SQL queries.
