OceanBase 与 LangChain/LangGraph 的官方集成包，提供向量存储与检查点持久化

综述（解读层）

该包为 LangChain 生态提供 OceanBase 集成，包含 OceanbaseVectorStore、OceanBaseCheckpointSaver、OceanBaseStore 三个持久化组件，覆盖向量检索、LangGraph 图状态与长期记忆存储。支持 OceanBase、seekdb（含嵌入式模式）和 MySQL（仅 checkpoint/store）三种后端，通过 connection_args 配置连接。要求 Python 3.11–3.13，0.6.x 需搭配 LangChain 1.x 与 langgraph-checkpoint 4.x。

  • 提供向量存储、LangGraph 检查点与 Store 三类持久化组件，支持 HNSW/IVF/FLAT 索引与混合检索（稠密+稀疏+全文）
  • 支持嵌入式 seekdb 模式，通过本地路径运行无需部署服务器；内置 all-MiniLM-L6-v2 ONNX 嵌入模型，无需 API 密钥
  • 提供异步操作、元数据过滤、TTL 过期、MMR 多样性过滤等能力，兼容 Linux/macOS/Windows 平台

适用场景（解读层）

  • 为 LangGraph 应用持久化图状态，实现会话恢复、重放与 time-travel 工作流
  • 在 OceanBase 或 seekdb 上构建向量检索与混合检索工作流
  • 使用本地嵌入式 seekdb 进行无需服务器部署的原型开发与测试
