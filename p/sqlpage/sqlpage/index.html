仅用 SQL 文件构建数据应用界面的 Web 框架

综述（解读层）

SQLPage 是一个以 SQL 为唯一开发语言的 Web 应用构建器：开发者编写含查询的 .sql 文件，通过 component、title 等约定字段将查询结果渲染为文本、列表、网格、图表和表单页面。支持 SQLite、PostgreSQL、MySQL、SQL Server 及 ODBC 兼容数据库，可通过二进制、Docker 部署，也支持打包到 AWS Lambda 运行，甚至可从数据库表中读取 .sql 文件。适合熟悉 SQL 的数据从业者快速搭建数据查看与录入界面。

  • 通过 .sql 文件中的约定字段（如 component、title）生成列表、图表、表单、卡片等页面组件
  • 支持 SQLite、PostgreSQL、MySQL、SQL Server 及任意 ODBC 兼容数据库
  • 提供可执行文件、Docker 镜像及 AWS Lambda 打包等多种运行方式

适用场景（解读层）

  • 为现有数据库快速搭建数据展示、查询与表单录入页面
  • 熟悉 SQL 但不使用其他编程语言的团队构建内部数据应用
  • 在服务器、Docker 或 AWS Lambda 环境中部署数据驱动的小型站点
