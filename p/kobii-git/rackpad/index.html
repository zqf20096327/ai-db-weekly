自托管的实验室基础设施台账与运维平台，单容器部署。

综述（解读层）

Rackpad 是一个面向家庭实验室、小型机架与网络机房的自托管基础设施台账与运维应用，将机架、设备、端口、线缆、IPAM、VLAN、Wi-Fi、计算、存储、发现、监控、报告与拓扑图整合在同一应用中。技术栈为 React+Vite 前端、Fastify API、SQLite 持久化；官方支持的部署方式是单个 Docker 容器，原生 Proxmox LXC 处于实验阶段。内置管理员/编辑者/查看者三种角色，支持 OIDC 可选登录。源码对应稳定版本 v1.8.7。

  • 支持机架立面、端口映射、线缆跳接记录，以及基于 React Flow 的可移动网络拓扑图（含线缆路径与健康状态叠加）
  • 提供 IPAM、VLAN、子网、DHCP 区域与预留管理，支持 IPAM 子网/全子网/手动 CIDR 扫描发现并经人工核对后导入
  • 内置 ICMP、TCP、HTTP/HTTPS、SNMP（v1/v2c/v3）健康检查，可通过邮件、Discord、Telegram 告警

适用场景（解读层）

  • 为家庭实验室或小型机房建立机架、设备、端口、线缆的物理与逻辑台账
  • 管理 VLAN、子网、DHCP 预留等网络规划信息并执行子网扫描发现
  • 对设备进行多协议健康监控，并导出 PDF/Excel/CSV 格式的库存报告
