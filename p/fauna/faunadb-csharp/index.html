Fauna v4 的官方 C# 驱动，提供 FQL 查询与文档流订阅

综述（解读层）

该仓库是 Fauna v4 的官方 C# 客户端库，通过 NuGet 包 FaunaDB.Client 提供，用于在 .NET 应用中执行 FQL 查询、用 Encoder/Decoder 在用户类型与 Value 间转换、订阅文档变更流。README 标注其已弃用：FQL v4 于 2025 年 6 月 30 日退役，该驱动不兼容 FQL v10，现有项目需迁移至官方 v10 驱动 fauna-dotnet。支持多 .NET 框架，4.0.0 起在 .NET Standard 2.1+ 默认启用 HTTP/2。

  • 提供 FaunaClient 客户端，通过 Expr 组合表达式执行 FQL 查询，支持自定义 HttpClient、超时和 HTTP 协议版本参数
  • 提供 Encoder/Decoder 在用户定义类与 Value 类型间转换，支持 FaunaField、FaunaConstructor、FaunaIgnore 三个特性控制映射行为
  • 基于 Observer 模式实现文档流订阅，通过 StreamingEventHandler 与 StreamingEventMonitor 接收文档变更通知

适用场景（解读层）

  • 维护仍运行在 FQL v4 上的存量 .NET 项目，直至 2025 年 6 月 30 日 v4 退役前迁移
  • 在 .NET 应用中以强类型方式读写 Fauna 文档（自定义类与 Value 互转）
  • 订阅指定文档的变更并实时接收推送通知
