FaunaDB 的 Ruby 驱动，以 gem 分发，通过 Fauna::Client 发送查询

综述（解读层）

该仓库是 FaunaDB 的 Ruby 驱动，以 gem 名 'fauna' 分发，供 Ruby 应用连接 FaunaDB 使用。所有 API 请求经由 Fauna::Client 发出，创建客户端需提供 admin key、server key、client key 或 token，可配置 observer 进行日志调试。README 注明该驱动现为社区支持状态：已有功能继续可用，新特性依赖社区贡献。

  • 通过 Fauna::Client 执行 FaunaDB 查询，支持 query 块内创建类等操作
  • 提供 Fauna::ClientLogger.logger 日志观察者用于调试
  • 测试可对 FaunaDB Cloud 运行，支持 rake spec、单测执行及 Docker 容器方式，并自动生成覆盖率报告

适用场景（解读层）

  • 在 Ruby 应用中通过 server key 等凭证访问 FaunaDB 并执行查询
  • 需要对驱动请求做日志调试的 Ruby 项目
  • 希望以 rake 或 Docker 方式运行驱动测试套件的贡献者
