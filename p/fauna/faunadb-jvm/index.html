FaunaDB v4 的官方 Java 与 Scala 客户端驱动

综述（解读层）

该仓库包含 Fauna v4 的官方 Java 和 Scala 驱动，两种客户端共享底层库 faunadb-common。支持通过 Maven 或 sbt 安装，提供每请求指标读取、自定义 HTTP 头与基于 Flow/Monix 的文档流订阅。注意：FQL v4 将于 2025 年 6 月 30 日停用，该驱动不兼容 FQL v10，官方要求迁移至 v10 驱动。

  • 提供 Java 与 Scala 双语言客户端，共享底层库 faunadb-common
  • 支持读取响应头中的每请求指标，并集成 Dropwizard Metrics 统计上报
  • 支持文档流式订阅，可基于 java.util.concurrent.Flow 或 Monix 实现

适用场景（解读层）

  • Java 11 或 Scala 2.11/2.12 应用通过 FQL v4 访问 Fauna v4 数据库
  • 需要订阅文档变更推送的实时读取场景
  • 需要对请求指标做统计上报的 JVM 服务

This repository contains the official Java and Scala drivers for [Fauna v4](https://docs.fauna.com/fauna/v4/).
