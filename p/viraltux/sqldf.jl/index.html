在 Julia 表格对象上执行 SQL 查询的宏接口，默认底层 SQLite 引擎

综述（解读层）

SQLdf 提供 @sqldf 宏和 sqldf 函数，用于对实现 Tables.jl 接口的 Julia 类型（含 DataFrame）执行 SQL 查询，结果以 DataFrame 返回。默认引擎为 SQLite.jl；0.2.0 之前版本默认经 RCall 调用 R/sqldf，现可通过 setRDB("R") 切换，但需安装 R 并含 sqldf 包。示例覆盖单表查询、多表连接及 TimeSeries 类型。

  • 支持对任何实现 Tables.jl 接口的类型（含 DataFrame）执行 SQL 查询
  • 查询结果统一以 DataFrame 类型返回
  • 通过 setRDB 可在 SQLite（默认）与 R/sqldf 两种后端间切换

适用场景（解读层）

  • 对内存中的 DataFrame 运行 SQL select、join 等查询
  • 对 TimeSeries 等实现 Tables.jl 接口的自定义类型执行 SQL 操作
  • 在已装有 R/sqldf 的环境中复用 R 端查询后端
📖 README 首段存档原文 · 程序抽取

This package allows SQL queries on any Julia type implementing the Table.jl interface an in particular the DataFrame type from DataFrames.jl. All results from a query are returned in a DataFrame type.
