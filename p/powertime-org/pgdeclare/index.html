🧭 简介解读层（AI·证据行可回查）

声明式 Postgres schema 差异工具：以 SQL 文件描述现状，经 scratch 库内省生成迁移。

综述（解读层）

pgdeclare 是一个 Postgres schema 差异工具。使用者在纯 SQL 文件中为每张表写一条 CREATE TABLE 声明；工具将文件构建到临时 plan 库并内省，与线上库经 pg_catalog 比对后应用差异。重命名、回填等需 @migrate-before/after 块，每次运行记录于哈希账本，破坏性变更需 @drop。需 Python 3.12+、PostgreSQL 14–18，pip 安装，Apache-2.0 许可。

  • 在 scratch plan 数据库中执行 schema 文件并内省，由 Postgres 自身解析默认值、隐式约束与类型规范化，而非从解析器模型重建
  • 语句按 retry-until-stable 方式重排执行，依赖失败的变更在其余完成后重试，无需手工维护依赖顺序
  • @migrate-before/after 块由哈希账本记录、每库只运行一次，运行后编辑会被拒绝；已运行的迁移可修剪

适用场景（解读层）

  • 希望以可读的 SQL 声明文件维护数据库当前状态、而非逐条编写迁移文件的团队仓库
  • 包含 LLM 或自动化工具读取代码库、需要从文件直接得到完整 schema 状态的工作流
  • 需要预览 diff（pgdeclare diff）、执行前后迁移块与 --prove 安全校验的 Postgres 14–18 环境
