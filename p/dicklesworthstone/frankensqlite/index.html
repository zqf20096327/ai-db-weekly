Rust 从零重写的 SQLite 引擎，核心机制为页级 MVCC 并发写入

综述（解读层）

FrankenSQLite 是用 Rust 从零实现的 SQLite 兼容引擎，面向需要并发写入与内存安全嵌入式数据库的开发者。当前可运行路径是兼容模式：直接读写标准 SQLite 3.x 文件（含 UTF-8/UTF-16 编码），通过页级 MVCC 与 SSI 支持多写者并发；RaptorQ 自愈存储为设计加部分实现，尚未接入现行运行时。unsafe 仅限 VFS 和可选 C ABI 两个 crate。

  • 支持页级 MVCC 多写者并发，默认启用可串行化快照隔离（SSI）
  • 兼容模式可直接读写标准 SQLite 3.x 文件及 WAL/回滚日志，支持 UTF-8 与 UTF-16le/be 文本编码
  • 引擎核心为安全 Rust（工作区禁止 unsafe），unsafe 仅存在于 fsqlite-vfs 与可选 C ABI shim

适用场景（解读层）

  • 写密集型嵌入式场景下需要多写者并发的应用
  • 在现有 SQLite 数据库文件上无需迁移即可运行的 Rust 项目
  • 需要嵌入使用且通过 CLI 或 Rust crate 集成的本地数据库工具链
