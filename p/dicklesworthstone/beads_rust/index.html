🧭 简介解读层（AI·证据行可回查）

本地优先的 Rust 版 issue 跟踪器，SQLite 存储 + JSONL 导出配合 git 协作

综述（解读层）

br 是 Steve Yegge 的 beads 的 Rust 移植，冻结在其经典 SQLite+JSONL 架构上，命令为 br 以区别原版 bd。它将 issue 存于仓库内 .beads/ 目录的 SQLite 数据库并导出 JSONL，支持依赖跟踪、--json 机器可读输出、同步与恢复工具；不自动 commit/push、不装 hooks、无后台进程，同步由用户显式执行。面向本地及 AI 代理工作流的开发者，可通过脚本、Homebrew、Scoop 或源码（需 Rust nightly）安装。

  • 提供依赖感知的 issue 跟踪，状态存于仓库内 .beads/（SQLite 数据库 + JSONL 导出）
  • 所有命令支持 --json，另有 TOON、plain、quiet 等输出模式；默认不执行 git commit/push/pull、不安装 hooks、不运行后台服务
  • 支持 auto-import 检查本地 JSONL 变更、sync --flush-only 导出检查，以及 MCP 支持、conformance 检查与恢复工具

适用场景（解读层）

  • 离线或仓库内跟踪任务与依赖关系，经 JSONL 在 git 中与协作者共享 issue 状态
  • AI 编码代理工作流：通过 --json/TOON 结构化输出读取 ready 列表并更新 issue
  • 需要原 beads 经典 SQLite+JSONL 架构稳定快照、从 bd 迁移的用户（提供可选迁移 skill）
