🧭 简介解读层（AI·证据行可回查）

本地优先的 AI 编程代理技能管理平台，Rust 编写，双持久化加 MCP 集成。

综述（解读层）

ms 是一款本地优先的技能管理平台，用于把操作知识整理为可搜索的结构化技能（SKILL.md、会话挖掘、bundle 导入等）。数据以 SQLite 存查询、Git 存审计历史；检索融合 BM25 与本地哈希嵌入（RRF），推荐引擎用 Thompson sampling bandit 从反馈学习，并通过 MCP 服务器向 Claude、Codex 等代理暴露六个工具。适合需要跨机器同步与技能治理的个人或团队。安装用 cargo install --path .，需固定 nightly-2026-08-31 工具链，支持 Linux/macOS/Windows。

  • SQLite 与 Git 双持久化，支持审计追踪与损坏后从 Git 重建
  • 混合检索：BM25 加本地确定性哈希嵌入（FNV-1a，384 维），经 RRF 融合，无外部模型依赖
  • 内置多层安全机制：ACIP 提示注入防御、DCG 危险命令分级门控、路径策略与密钥扫描

适用场景（解读层）

  • 为 AI 编程代理提供本地技能库检索与调用（通过 MCP 或 CLI）
  • 从 CASS 会话历史挖掘、结构化并沉淀可复用操作知识
  • 团队通过 Git 远端或 bundle 包分发技能并保持多机同步
