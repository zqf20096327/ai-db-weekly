基于 PostgreSQL 的实验数据管理数据库系统

综述（解读层）

Molar 是一个基于 PostgreSQL 的数据库管理系统，由 FastAPI 实现的 REST API 和 Python 客户端组成，用于化学家和材料科学家存储实验（含计算实验）结果。通过 JWT/OAuth2 管理用户权限，采用事件溯源记录数据，并支持 Alembic 管理不同数据库结构。可通过 PyPI 安装，后端需额外依赖并以 docker-compose 部署。

  • 提供基于 FastAPI 的 REST API 和 Python 客户端，客户端可与 pandas 集成
  • 支持按用户请求创建/删除数据库，通过 JWT 令牌和 OAuth2 实现按数据库的用户管理
  • 采用事件溯源（event sourcing）机制，支持借助 Alembic 使用不同的数据库结构

适用场景（解读层）

  • 化学和材料科学实验室存储实验结果数据
  • 需要多数据库结构与按数据库用户权限管理的团队
  • 需要记录数据变更历史（事件溯源）的实验数据管理
📖 README 首段存档原文 · 程序抽取

Molar is a database management system for PostgreSQL. Its main focus is to enable chemists and material scientist to store the results of their experiment, whether exprimental or not!
