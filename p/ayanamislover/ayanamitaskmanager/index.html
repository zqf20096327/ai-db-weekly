🧭 简介解读层（AI·证据行可回查）

面向多 Agent 开发的本地优先任务与上下文管理器，桌面、MCP、CLI 共用同一 SQLite 事实源。

综述（解读层）

AyanamiTaskManager（ATM）是一个运行在 Windows 上的 Electron/Rust 桌面应用，把项目的计划、任务、进度、阻塞、长期记录和 Session 交接存入本地 SQLite 数据库，供 Codex、Claude Desktop、Claude Code、Kimi Code 等 Agent 通过 MCP 工具读取和写入。Agent 开工时调用 atm_begin 获取 brief 接续工作；桌面界面与 Agent 读写同一数据库。采用 AGPL-3.0-only 许可，服务仅监听 loopback，不依赖云端账号；手机同步为可选功能，需自建中继且内容端到端加密。

  • 提供 13 个 MCP 工具，按 core/memory/actions 三个 Profile 划分，支持开工 brief、任务领取、进度记录、交接与跨项目知识库检索
  • 桌面端支持任务列表、看板、时间线、层级四种视图，按项目聚合 Agent Session 并显示 Git 分支与工作区状态，含备份恢复与导入导出
  • 3.0 版以 Rust 重写核心并合并为单一进程，发布链包含四层验证（SOURCE_DONE 到 INSTALLED_VERIFIED），每个 Release 附带 test-report 与 SHA256SUMS

适用场景（解读层）

  • 多个 AI Agent 跨 Session 协作开发同一项目时，通过 brief 与结构化记录接续上下文，避免依赖聊天记录回顾项目历史
  • 在桌面端集中查看多个受管项目的进行中、受阻、等待任务和在线 Agent 状态
  • 以共享知识库存放跨项目的规范、接口约定和排障经验，通过不可变的 id@revisionId 引用
