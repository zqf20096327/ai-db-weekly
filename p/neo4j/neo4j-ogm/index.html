面向 Neo4j 的 Java 对象-图映射（OGM）库，基于注解 POJO 与 Cypher。

综述（解读层）

Neo4j-OGM 是 Neo4j 官方的 Java 对象-图映射库，用于将带注解的 POJO 领域对象（@NodeEntity、@Relationship）映射到图数据库，通过 SessionFactory/Session 执行 save/load 操作，针对基于服务器并使用 Cypher 的部署方式设计。适合在 Java 应用中持久化图数据的开发者。当前版本 5.0.11，测试默认用 TestContainers 和 neo4j:5 镜像；嵌入式驱动模块为 GPL v3，其余模块为 Apache 2.0。

  • 通过 @NodeEntity、@Relationship 等注解将 POJO 映射为图节点与关系，持久化时级联保存关联对象
  • 提供 SessionFactory/Session API 进行实体的 save 与 load 操作，面向使用 Cypher 的服务器版 Neo4j
  • 提供 Quarkus 扩展与 Spring Data Neo4j 5 的 fork 两种官方框架集成，支持 Maven/Gradle 引入

适用场景（解读层）

  • Java 应用中以面向对象方式读写 Neo4j 图数据，避免手写 Cypher 映射逻辑
  • 在 Quarkus 或 Spring（兼容 Spring Data Neo4j 5 API）项目中集成 Neo4j 持久层
  • 需要通过属性文件或编程方式配置连接，并对领域实体进行级联持久化与加载的场景
