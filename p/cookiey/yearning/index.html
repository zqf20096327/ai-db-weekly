基于 AI 预审的多数据库 SQL 变更治理与审核平台

综述（解读层）

Yearning 是面向 MySQL、PostgreSQL、TiDB、OceanBase、PolarDB 的 SQL 审核与数据库变更治理平台，v4 采用 Go 单体二进制加 React 19 前端和 PostgreSQL 元数据库构建。核心机制包括 AI 两阶段预检（SQL 指纹归并脱敏）、提交时加密冻结的多级审批流、内置 gh-ost 在线 DDL、基于前置镜像的免 binlog 回滚，以及带列掩码的只读查询工作台。适用于 DBA、平台团队等需要结构化变更流程的组织。

  • 提供确定性加 AI 的两阶段 SQL 预检，支持指纹归并、内存内脱敏及本地自托管模型（vLLM/Ollama）接入
  • 内置进程内 gh-ost 在线 DDL，并实现基于 AST 与前置镜像的 MySQL/PostgreSQL 跨引擎回滚
  • 提供审批制的只读查询工作台，包含服务端敏感列掩码、流式导出与 Top SQL 诊断图表

适用场景（解读层）

  • DBA 与平台团队对生产数据库的 DDL/DML 变更实施多级审批与审计
  • 开发与分析人员按授权申请限时只读查询权限，避免直接分发数据库凭据
  • 工程组织通过 /api/v4/* 接口将 AI coding agent 与数据库变更流程集成
