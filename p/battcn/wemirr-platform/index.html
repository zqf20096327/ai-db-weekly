基于Spring Cloud的多租户SAAS微服务开发平台

综述（解读层）

Wemirr Platform 是一个基于 Spring Cloud 2024、Spring Cloud Alibaba 2023、MyBatis-Plus、Nacos、Sentinel 等构建的多租户 SAAS 平台脚手架，前端配套 Vue3，面向需要搭建多租户/SAAS 系统的 Java 开发者。项目按 v2/v3/v4 多版本分支维护，README 说明 v2 到 v3 为破坏性升级；提供 Docker Compose 一键启动、演示账号，并附带付费的模块定制与远程技术支持服务。

  • 提供 SAAS/多租户/RBAC 权限控制，集成 Sa-Token
  • 支持 SkyWalking / Zipkin / Pinpoint 链路追踪，动态网关路由
  • 集成 WebSocket+Redis 分布式消息推送、snail-job 分布式调度与 SpringDoc 接口文档

适用场景（解读层）

  • 搭建多租户 SAAS 后台管理系统
  • 作为 Spring Cloud 微服务项目的基础脚手架
  • 需要 Docker Compose 快速部署演示或开发环境时使用
