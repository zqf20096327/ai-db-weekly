🧭 简介解读层（AI·证据行可回查）

基于 Spring Boot 与 React 的 Web 数据库管理工具，支持多数据库连接与在线 SQL 查询。

综述（解读层）

这是一款部署在服务端的数据库管理工具，通过浏览器操作多种数据库。它使用 Spring Boot 2.7 与 React 18 构建，连接配置和查询历史存于内嵌 H2 数据库；前后端 API 通信采用 AES-CBC 加密，配合 JWT 做认证。适合需要统一入口管理多个数据库连接、执行在线 SQL 查询与数据导入导出的团队或个人。支持上传 JDBC 驱动 JAR 包动态扩展数据库类型。

  • 支持 MySQL、PostgreSQL、Oracle、SQL Server、达梦及自定义 JDBC 连接，可上传驱动 JAR 包自动扫描驱动类
  • 内置 SQL 编辑器，提供语法高亮、查询历史与结果分页
  • Excel 导入导出基于 Apache POI 流式处理，并支持表结构、列、主外键、视图等元数据浏览

适用场景（解读层）

  • 通过 Web 界面集中管理多种数据库的连接配置
  • 在浏览器中执行 SQL 查询并将结果导出为 Excel，或从 Excel 导入数据
  • 浏览数据库表结构、主外键关系及视图等元数据信息
