开源 BaaS 平台，以 Postgres 为底层，集成认证、存储、函数与 MCP 服务器

综述（解读层）

Butterbase 是一个 Apache 2.0 协议的后端即服务平台，为应用提供独立的 Postgres 数据库、行级安全、自动生成 REST、TypeScript 无服务器函数（Deno 运行时）、文件存储、实时订阅、LLM 网关、RAG，并通过 MCP 服务器向 AI 代理暴露全部能力。支持 Docker Compose 一条命令自托管，也可使用 butterbase.ai 的托管云；自托管时计费与配额为无操作实现。面向构建 AI 应用的开发者。

  • 每个应用一个独立 Postgres 数据库，包含声明式 schema、迁移、RLS 策略管理和自动生成的 REST 端点
  • 内置 MCP 服务器，将数据、函数、认证、RAG 等能力以 MCP 工具形式暴露（HTTP /mcp 或 stdio）
  • 提供 Deno 运行时的无服务器函数、每键持久化的 Durable Objects、WebSocket 实时订阅和边缘 SSR 部署

适用场景（解读层）

  • 自托管搭建具备认证、数据库、存储与实时能力的应用后端
  • 构建需要 LLM 网关、RAG 与代理工作流（含人工审批暂停）的 AI 驱动应用
  • 通过 MCP 让 AI 代理（如 Claude Code 插件）以工具方式操作后端数据与功能
