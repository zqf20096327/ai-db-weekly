Apache HBase 项目站点仓库，运行于 Hadoop 之上的分布式列式存储

综述（解读层）

该仓库为 Apache HBase 的站点项目。HBase 是开源、分布式、带版本、面向列的存储系统，参照 Google Bigtable 论文实现，在 Apache Hadoop 之上提供类似 Bigtable 的能力。文档位于 doc/ 目录，可通过浏览器打开 docs/index.html；下载、源码、问题跟踪、邮件列表等入口见 README 中的链接列表。发行版遵循 Apache License 2.0，并包含密码学软件。

  • 提供开源、分布式、带版本、面向列的数据存储，构建在 Apache Hadoop 之上
  • 随发布附带完整文档（doc/ 目录下的 docs/index.html），官网提供含 quickstart 章节的 HBase Book
  • 以 Apache License 2.0 发布，提供源码仓库、issue 跟踪与邮件列表等社区入口

适用场景（解读层）

  • 需要基于 Hadoop 生态的分布式列式存储时使用
  • 需要查阅 HBase 某一版本的官方文档时访问 doc/ 目录
  • 参与或跟踪 HBase 项目时使用 issue tracker 与邮件列表

Apache HBase [1] is an open-source, distributed, versioned, column-oriented store modeled after Google' Bigtable: A Distributed Storage System for Structured Data by Chang et al.[2] Just as Bigtable
