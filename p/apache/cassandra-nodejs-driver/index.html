Apache Cassandra 的 Node.js 客户端驱动，基于二进制协议与 CQL

综述（解读层）

该驱动是 Apache Cassandra 项目下维护的 Node.js 客户端库，使用 Cassandra 二进制协议和 CQL 连接 Cassandra、DSE、HCD 与 Astra DB，供 JavaScript/TypeScript 开发者访问 Cassandra 集群。提供简单、预编译和批量语句、连接池、自动节点发现与重连、可配置负载均衡与重试策略、内置对象映射器，并支持 promise 与回调两种 API。支持 Cassandra 3.0+、Node.js 20/22/24.x，通过 npm install cassandra-driver 安装。

  • 支持简单、预编译和批量语句，预编译语句在节点端解析并实现 JavaScript 与 Cassandra 类型的准确映射
  • 提供行流式读取（eachRow/stream）、默认 5000 行分页、连接池、自动节点发现与自动重连
  • 内置对象映射器、TypeScript 支持，并支持全部 CQL 数据类型（含 decimal、varint、bigint 等无原生 JS 表示的类型）

适用场景（解读层）

  • Node.js 应用程序读写 Apache Cassandra / DSE / HCD / Astra DB 集群数据
  • 需要流式处理或分页读取大结果集的场景
  • 以文档式对象操作方式访问表数据的 JavaScript/TypeScript 项目
