综述（解读层）

Apache Cloudberry（孵化中）是由 Greenplum 原始开发者创建的 MPP 数据库，基于开源 Greenplum 演化而来，使用较新的 PostgreSQL 内核。可用于数据仓库、大规模分析及 AI/ML 负载。支持在 Linux（RHEL/Rocky、Ubuntu）和 macOS 上源码构建，并提供 Docker Sandbox 快速试用。项目采用 Apache 2.0 许可证，目前处于 ASF 孵化阶段。

  • 实现大规模并行处理（MPP）架构，可部署为数据仓库
  • 使用较新的 PostgreSQL 内核，并包含 TLS/SCRAM-SHA-256、GSSAPI（Kerberos）、LDAP 等认证与加密能力
  • 配套生态仓库包括 PXF 扩展框架、备份工具、Go 库及网站文档等

适用场景（解读层）

  • 数据仓库与大规模数据分析（OLAP）场景
  • AI/ML 相关的数据处理工作负载
  • 需要通过 Docker Sandbox 快速体验或自行源码构建的数据库部署环境
