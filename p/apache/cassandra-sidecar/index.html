Apache Cassandra 的 Sidecar 伴随服务，提供含 CDC 变更流至 Kafka 的能力

综述（解读层）

该项目是 Apache Cassandra 数据库的伴随进程（Sidecar），以 Java 实现，通过读取 sidecar.yaml 配置与本地 Cassandra 实例（4.0+，依赖虚拟表特性）交互运行，当前处于 WIP 状态。它支持将开启 CDC 的表变更以 Avro 序列化发布到 Kafka，并提供 CDC/Kafka 配置的 HTTP API。面向需要管理 Cassandra 节点或接出变更数据的运维与开发人员。

  • 支持 Cassandra 4.0+，通过虚拟表读取实例信息，二进制发行版经 bin/cassandra-sidecar 启动
  • 内置 CDC 功能：跟踪启用 CDC 的表，将变更以 Avro 格式发布到 Kafka，支持 STATIC/KEYSPACE/KEYSPACETABLE/TABLE/MAP 等主题命名方式与 log_only 模式
  • 提供 CDC 与 Kafka 生产者的 REST 配置接口，内置 CachingSchemaStore 自动将 CQL 表结构转换为 Avro schema 并定期刷新

适用场景（解读层）

  • 为 Cassandra 集群节点部署伴随服务，进行配置管理
  • 将 Cassandra 表的增量变更（INSERT/UPDATE/DELETE）流式写入 Kafka 供下游消费
  • 在开发环境中通过 Gradle 运行并连接本地或 CCM 多节点集群进行测试
