Apache Doris 的 Stream Load 数据加载命令行工具，支持并行导入

综述（解读层）

doris-streamloader 是 Apache Doris 官方仓库下的数据加载工具，用于通过 Stream Load 接口向 Doris 导入本地文件。它会自动切分数据文件并行加载，支持一次导入多个文件或目录（含 * 通配符），失败后可从断点恢复并自动重试。使用时通过命令行参数指定源文件、FE 或 BE 地址、Stream Load 头（与 curl 用法一致）、目标库和表。构建需 Go 1.19.9 以上，采用 Apache-2.0 协议。

  • 自动切分数据文件并执行并行加载，支持多文件、目录及路径遍历，源文件可用 * 通配符
  • 失败或取消后可从上一次位置恢复加载，并具备自动重试机制
  • header 参数兼容 curl Stream Load 的全部头配置，多个头用 ? 分隔

适用场景（解读层）

  • 需要将本地 CSV 等文件批量导入 Doris 指定库表的场景
  • 源数据分散在多个目录和文件、希望一条命令完成导入的场景
  • 大文件导入时希望切分并行加载、且需要断点续传与自动重试的场景
