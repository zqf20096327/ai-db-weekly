基于 Apache Flink 的分布式实时与批量数据集成工具

综述（解读层）

Flink CDC 是构建在 Apache Flink 之上的分布式数据集成工具，用于实时与批量数据的端到端集成，提供整库同步、分库分表同步、Schema 演变和数据转换能力。它提供 YAML、SQL、DataStream 三层 API，供数据管道搭建者、Flink SQL 用户和流应用开发者使用，源端连接器覆盖 MySQL、PostgreSQL、Oracle 等。使用时需按版本表匹配对应的 Flink 版本。

  • 提供 YAML（Pipeline）、SQL、DataStream 三层 API，分别用于声明式管道定义、Flink SQL 集成和编程式流应用构建
  • Pipeline 连接器支持 Doris、Elasticsearch、Iceberg、Kafka、Paimon、StarRocks 等写入端；源端连接器覆盖 MySQL、PostgreSQL、Oracle、MongoDB、TiDB 等
  • 支持整库同步、分库分表同步、Schema 演变与数据转换，README 提供各版本与 Flink 的兼容对照表

适用场景（解读层）

  • 以 YAML 声明式定义从 MySQL 等源到 Doris、Paimon、StarRocks 等端的数据管道
  • 在 Flink SQL Client 中通过 SQL DDL 定义 CDC 源表读取数据库变更
  • 以 Maven 依赖方式在自定义 Flink 流式应用中以 DataStream API 接入数据库变更数据
