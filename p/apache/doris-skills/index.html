Apache Doris 的 Agent Skills 集，以 SKILL.md 格式供多种 agent 工具使用

综述（解读层）

该仓库提供 Apache Doris 相关的 agent skills，采用开放的 SKILL.md 格式，覆盖两类工作：操作集群（表设计、容量规划、生产诊断、Query Profile 解读）和参与 Doris 开发（开发流程、PR 描述撰写、PR 审查）。面向使用 Claude Code、Cursor 等 agent 工具的 Doris 用户与贡献者。安装支持 npx skills add 或手动拷贝至技能目录；集群管理、计费、网络等托管服务操作被明确排除在范围之外。

  • 通过 npx skills add 或手动拷贝安装，适用于 Claude Code、Cursor、Codex、Cline、Amp 等 agent 工具
  • 提供 verify/ 验证体系，对技能中的事实性描述在真实集群、doriscli 和运行时行为三个层面做回归测试

适用场景（解读层）

  • 设计或审查 Doris 建表 DDL、选择数据模型与分区/分桶策略
  • 诊断生产问题，如慢查询、导入失败、compaction 错误、节点 OOM
  • 在 apache/doris 源码检出中开发、撰写 PR 描述或进行本地 PR 审查
