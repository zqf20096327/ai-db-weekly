Apache AGE 是以 PostgreSQL 扩展形式提供图数据模型的图数据库扩展

综述（解读层）

Apache AGE 是 Apache 基金会下的 PostgreSQL 扩展，在现有关系数据库之上提供图存储与查询。它支持 openCypher 图查询语言，可混合使用 SQL 与 Cypher，在同一存储中处理关系与图数据模型，项目受 Bitnine 的 AgensGraph 启发。目前支持 PostgreSQL 11 至 18，可通过源码编译（make install）或 Docker 镜像安装，每个连接需执行 CREATE EXTENSION age 并设置 ag_catalog 搜索路径。

  • 在 PostgreSQL 上实现图数据模型，支持 openCypher 查询语言，可与 SQL 混合查询
  • 支持同时查询多个图，顶点和边均可建立属性索引，图标签采用层级组织
  • 继承 PostgreSQL 的功能特性，提供 Docker 镜像和源码编译两种安装方式

适用场景（解读层）

  • 已使用 PostgreSQL、需在同一数据库中存储和查询图数据的系统
  • 涉及关系分析的业务场景，如 README 中提及的欺诈检测、产品推荐、身份与关系管理
  • 需要同时编写 SQL 与 Cypher 查询的多模型数据应用
