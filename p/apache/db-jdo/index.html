Apache JDO：Java对象持久化标准API及其TCK兼容性认证套件

综述（解读层）

Apache JDO 项目包含定义 Java 1.8+ 对象持久化 API 的 jdo-api jar、用于运行兼容性测试的 TCK、execTck Maven 插件及 OpenDocument 格式的规范文档。面向 JDO 实现开发者和需要认证实现的人员，通过 Maven 构建，TCK 可配置在参考实现或待测实现上运行，认证规则见 tck 目录 RunRules.html。

  • api 子项目构建定义 JDO API 的 jdo-api jar，支持 Java 1.8 及以上
  • tck 子项目包含 Java 1.8+ 的 JDO TCK，可通过 jdo-exectck Maven 插件在参考实现或待测实现上运行
  • execTck 插件提供 installSchema、enhance、runtck 等自定义目标及配置文件、数据库、身份类型、并行执行等命令行选项

适用场景（解读层）

  • 构建并安装 jdo-api 到本地 Maven 仓库供项目依赖
  • JDO 实现开发者运行 TCK 验证其实现与 API 的兼容性
  • 查阅 OpenDocument 格式的 JDO API 规范
