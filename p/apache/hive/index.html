🧭 简介解读层（AI·证据行可回查）

基于 Hadoop 的数据仓库软件，用 SQL 读写分布式存储中的大数据集

综述（解读层）

Apache Hive 是构建在 Apache Hadoop 之上的数据仓库软件，通过 SQL 读取、写入和管理分布式存储中的大规模数据集，适用于 ETL、报表和数据分析等任务。查询执行使用 Apache Tez 框架；SQL 可通过 UDF、UDAF、UDTF 扩展。它不面向在线事务处理，需依赖 Hadoop 3.x 集群，升级时须执行 MetaStore schema 升级脚本。

  • 提供标准 SQL 功能，含 OLAP 函数、子查询、公共表表达式等 2003/2011 特性
  • 支持通过 UDF、UDAF、UDTF 以用户代码扩展 SQL
  • 可访问存储在 HDFS 或 HBase 等其他数据系统中的文件

适用场景（解读层）

  • 基于 Hadoop 集群的 ETL、报表与数据分析等数据仓库任务
  • 数据量大到需要分布式系统处理的场景
  • 为多种数据格式施加结构并统一查询
