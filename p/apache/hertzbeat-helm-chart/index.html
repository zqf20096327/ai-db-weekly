Apache HertzBeat 的 Helm Chart，用于在 Kubernetes 集群中安装部署该实时观测系统

综述（解读层）

该仓库提供 Apache HertzBeat 实时观测系统的 Helm Chart，可在 Kubernetes 集群中一键部署。HertzBeat 整合指标与日志采集、告警处理与消息分发，无需 Agent，通过在线配置 YML 模板支持 Http、Jmx、Ssh、Jdbc、Prometheus 等协议采集。Chart 要求 K8s 1.20+ 和 Helm v3.2.0+，支持 Ingress、NodePort、LoadBalancer 等多种服务暴露方式，并可配置数据库与 TSDB 的持久化存储。适合需要在集群中部署监控平台并通过 Helm 管理的运维人员。

  • 支持 Ingress、ClusterIP、NodePort、LoadBalancer 四种服务暴露方式，并可配置外部 URL
  • 提供数据库与 TSDB 组件的持久化配置，支持 StorageClass 动态供给或使用已有 PVC
  • 可配置 collector 副本数与自动伸缩，以及 manager、collector、database、tsdb 组件的资源、nodeSelector、亲和性等参数

适用场景（解读层）

  • 在 Kubernetes 集群中通过 Helm 部署 HertzBeat 监控平台
  • 需要自定义服务暴露方式（如 NodePort 或云负载均衡）的部署场景
  • 为 HertzBeat 及其内置数据库、时序数据库配置持久化存储的部署场景
