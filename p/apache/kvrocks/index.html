基于 RocksDB 存储引擎的分布式 KV NoSQL 数据库，兼容 Redis 协议

综述（解读层）

Apache Kvrocks 是 Apache 基金会旗下的分布式键值 NoSQL 数据库，采用 RocksDB 作为存储引擎，将数据落盘以降低内存成本。用户可通过任意 Redis 客户端访问，支持命名空间隔离（每个命名空间独立 token）、类 MySQL binlog 的异步复制、Redis sentinel 故障转移，以及无代理的集中式集群方案。提供 Docker 镜像与源码构建（Linux/macOS），适用于希望用磁盘存储承载 Redis 协议服务的场景。

  • 兼容 Redis 协议，可用任意 Redis 客户端或 Redis Cluster SDK 访问
  • 以 RocksDB 为存储引擎，数据存储于磁盘
  • 支持异步复制（类 MySQL binlog）、Redis sentinel 故障转移与集中式管理集群

适用场景（解读层）

  • 需要以磁盘存储承载 Redis 协议键值服务的场景
  • 需要命名空间隔离多用户/多租户数据的部署
  • 需要副本复制与 sentinel 故障转移的分布式 KV 集群
