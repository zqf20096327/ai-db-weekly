Cayenne Modeler 的 JavaFX 原型重写版，用于 Cayenne 数据模型建模

综述（解读层）

这是 Apache Cayenne Modeler 的新版原型，采用 JavaFX 与 Scene Builder 重写界面，保留原功能同时支持生成类 JavaDoc、自定义注解与导入、接口、Velocity 模板编辑及多窗口打开项目。README 注明项目完成度约 15-20%，属早期原型，可通过 Eclipse 或 Maven 运行，图标使用 FontAwesomeFX 库。

  • 使用 JavaFX 与 Scene Builder 构建 UI，沿用原 Cayenne Modeler 的基础布局
  • 为生成的 Java 类、getter/setter 和关系提供 JavaDoc、自定义注解与自定义导入支持
  • 支持多窗口同时打开多个项目（含同一项目）并进行数据同步，以及 Velocity 模板的编辑与管理

适用场景（解读层）

  • 编辑 Apache Cayenne 的 DataDomain、DataMap 与 ObjEntity 数据模型
  • 需要为 Cayenne 生成代码添加自定义注解、导入和 JavaDoc 的建模工作流
  • 需要同时在多个窗口打开 Cayenne 模型项目并保持数据同步的开发场景
