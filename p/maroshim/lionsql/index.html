单二进制 OLTP 数据库服务器，以字节码虚拟机执行 T-SQL 与存储过程

综述（解读层）

LionSQL 是用 Go 编写的单二进制 OLTP 数据库服务器，支持 T-SQL 语法与存储过程，并提供 PGWire（5433）与 TDS（1433）双协议接入。查询与存储过程均编译为字节码后在 VDBE 虚拟机执行，提供内存 OCC 与 WiredTiger MVCC 两种存储引擎。适合需要运行 MSSQL 风格存储过程、且希望以单文件部署的开发者。构建需 Go 1.26+，磁盘引擎需 wiredtiger 头文件，Windows 版仅提供内存引擎二进制。

  • 同时提供 PostgreSQL v3 协议（5433 端口）与 MSSQL TDS 协议（1433 端口），可由 psql、SSMS、sqlcmd 及 pgx、GORM 等驱动连接
  • 存储过程、函数与触发器（含 IF...ELSE、WHILE、TRY...CATCH、游标等）编译为字节码，在寄存器式 VDBE 虚拟机上执行，支持 EXPLAIN BYTECODE 反汇编
  • 包含 8090 端口的内置 Web 管理界面、--app 静态网页托管、自动生成的 REST CRUD API、在线热备份及 WAL 流复制

适用场景（解读层）

  • 在单二进制部署环境中运行基于 T-SQL 存储过程的应用后端
  • 使用 psql、SSMS 等现有客户端或 pgx/GORM/Prisma 等 ORM 直接接入
  • 托管静态前端并通过同源 REST API 访问数据库，或通过 Web Studio 进行日常管理与备份
