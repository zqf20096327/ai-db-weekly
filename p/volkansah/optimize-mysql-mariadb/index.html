🧭 简介解读层（AI·证据行可回查）

MySQL/MariaDB 性能调优指南文档，覆盖配置、查询、日志与监控

综述（解读层）

该仓库是一份 MySQL/MariaDB 服务器性能优化指南，而非可安装的软件。内容包括配置参数（InnoDB 缓冲池、日志文件、线程缓存）、查询优化方法（EXPLAIN 分析、索引）、慢查询日志设置、连接池方案及监控工具（Performance Schema、MySQLTuner、pt-query-digest）的使用，并说明已废弃特性（如 Query Cache）的替代做法。适合需要自行调优数据库参数的运维和开发人员查阅，文中提供各 Linux 发行版的配置文件路径与示例值。

  • 提供 innodb_buffer_pool_size、innodb_log_file_size、thread_cache_size 等配置参数的说明与示例值
  • 包含慢查询日志开启方法及 pt-query-digest、MySQLTuner、Prometheus + Grafana 等工具的使用命令
  • 列出 MySQL/MariaDB 已废弃特性（Query Cache、expire_logs_days、binlog_format）及对应替代参数

适用场景（解读层）

  • 为专用数据库服务器调整 InnoDB 缓冲池等配置参数
  • 通过慢查询日志和 EXPLAIN 分析定位资源消耗大的查询
  • 为高并发应用配置连接池（PDO 持久连接、ProxySQL）
