SQLite3 数据库定期备份与旧备份轮转的 shell 脚本

综述（解读层）

该项目提供 backup.sh 脚本，将参数指定的 SQLite 数据库全部表导出为备份，并轮转删除旧备份以控制磁盘占用。备份支持 SQL 文本格式（.dump）和二进制副本（.backup）两种，默认以 Docker 镜像运行，entrypoint 经 tini 封装以正确终止子进程。删除旧备份要求脚本独占目标目录。适合在容器化环境中配合定时器周期执行备份的用户。

  • 支持两种备份格式：SQL 文本转储（.dump 命令）与二进制完整副本（.backup 命令），由输出文件扩展名决定
  • 内置备份轮转机制，可删除旧备份（默认保留最近 10 份）以控制磁盘占用
  • 以 shell 脚本实现（非 bash），并作为 Docker 镜像默认 entrypoint，经 tini 封装处理子进程终止

适用场景（解读层）

  • 在 Docker 化环境中通过宿主机 cron 类定时器（如 dockron）周期性重启容器执行 SQLite 备份
  • 需要同时输出 SQL 文本转储或二进制数据库副本的备份流程
  • 需要自动清理旧备份、限制磁盘占用的单机数据库备份场景
