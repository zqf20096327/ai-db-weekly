记录并分析 Laravel Eloquent 生成的 SQL 查询的开发调试包

综述（解读层）

Laravel Query Adviser 是一个通过 Composer 以开发依赖安装的 Laravel 包，用于记录应用运行期间 Eloquent 产生的 SQL 查询并生成可浏览的日志会话总览。查询卡片支持重新执行查询、查看 explain 信息和复制 SQL，可通过 Web 界面或 Chrome 扩展启停会话；支持 MySQL、PostgreSQL 及 MSSQL 标签所列数据库。提供 qadd/qadump 辅助方法在代码中直接输出查询，配合 Tinker 与 Job 使用。

  • 记录应用运行的 SQL 查询，支持按时间、路由、原始查询等方式分组与排序
  • 查询卡片支持重新执行、explain 信息查看和复制 SQL，并标注来源类/文件/函数
  • 提供 qadd/qadump 方法直接输出查询构建器或 Eloquent 模型的 SQL 与绑定参数

适用场景（解读层）

  • 开发环境下查看特定页面或路由执行了哪些 SQL 查询
  • 分析慢查询或高频重复查询并重新执行以观察数据库影响
  • 在 Tinker 或 Job 中调试查询构建器生成的 SQL 语句
