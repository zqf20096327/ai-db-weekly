dft 是基于 DataFusion 的多接口 SQL 工具套件，含 TUI、CLI、REPL 与服务器。

综述（解读层）

dft 是一套基于 Apache DataFusion 的应用集合，提供 TUI、REPL、CLI、FlightSQL 服务器和 HTTP 服务器五种接口，共享同一执行引擎。它支持查询 S3、本地文件和 HuggingFace 数据集，内置 Delta Lake、Vortex 表格式与 WASM UDF 扩展，可通过 DDL 文件在启动时加载表定义。面向需要用 SQL 查询文件数据的开发者，CLI 与 REPL 默认可用，TUI 和服务器需启用对应 feature 编译。

  • 支持从 S3、本地文件系统和 HuggingFace 数据集查询文件，内置 Delta Lake 与 Vortex 表格式支持
  • 提供 TUI、REPL、CLI、FlightSQL、HTTP 五种接口，全部共享同一执行引擎
  • 内置基准测试，输出逻辑规划、物理规划、执行三阶段计时及统计，支持 CSV 导出

适用场景（解读层）

  • 在终端中以 TUI 或 REPL 交互方式探索和查询本地或 S3 上的文件数据
  • 通过 CLI 从文件或命令行执行脚本化 SQL 查询
  • 部署 FlightSQL 或 HTTP 服务器，为程序化访问提供 SQL 接口
