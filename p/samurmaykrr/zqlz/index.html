基于 Rust 与 GPUI 构建的数据库 IDE

综述（解读层）

ZQLZ 是用 Rust 与 GPUI 编写的数据库 IDE，包含 GUI 应用与 CLI 两个组件。目前 SQLite 支持完整可用，PostgreSQL、MySQL 与 Redis 处于开发中，属早期项目。本地工作免费且无需账号，托管同步（加密备份、跨设备同步连接与配置）按计划为每位用户每月 10 美元的付费服务。许可证为 GPL-3.0-or-later。

  • 支持 SQLite（完整可用），PostgreSQL、MySQL、Redis 支持开发中
  • 提供 GUI 应用与 CLI，CLI 无子命令时可作为启动器
  • 本地连接无数量限制且不需账号，托管同步计划支持加密备份与跨设备同步

适用场景（解读层）

  • 本地 SQLite 数据库的编辑与管理工作
  • 需要在同一工具中逐步接入 PostgreSQL/MySQL 的开发者
  • 希望跨设备同步连接、设置与代码片段的用户（依赖计划中的托管同步服务）
