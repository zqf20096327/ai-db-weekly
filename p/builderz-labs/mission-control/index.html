🧭 简介解读层（AI·证据行可回查）

自托管的 AI 代理控制平面，用 SQLite 与本地仪表盘统一调度与审查代理任务。

综述（解读层）

Mission Control 是一个自托管控制平面，用于调度任务、审查执行结果、追踪花费并协调 OpenClaw、Claude Code、Codex 等多种代理运行时。面向需要管理多个代理的运维者，通过本地仪表盘、REST API、CLI 和 MCP 接口操作，状态存储于 SQLite。项目处于 alpha 阶段，API 与 schema 可能随版本变化。

  • 提供任务看板，覆盖收件、分配、执行、审查、Aegis 质量门与完成回执流程
  • 通过适配器支持 OpenClaw、Claude Code、Codex、CrewAI、LangGraph、AutoGen 等运行时（深度各异）
  • 提供 Web UI、CLI、MCP server、OpenAPI REST API、WebSocket 与 SSE 多种接口

适用场景（解读层）

  • 多个代理/运行时并存，需要统一查看任务归属、执行记录、审查结果与花费
  • 需要自托管的代理任务调度、定时任务与活动审计面板
  • 需通过 REST API、CLI 或 MCP 为代理或脚本提供无头接入控制平面
