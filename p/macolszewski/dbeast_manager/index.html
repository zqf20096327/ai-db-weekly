🧭 简介解读层（AI·证据行可回查）

用 Rust 编写的 PostgreSQL、MySQL、SQLite 原生桌面数据库客户端，内置 MCP 服务器。

综述（解读层）

DBeast 是一个基于 egui、以 Rust 实现的桌面数据库客户端，支持 PostgreSQL、MySQL 和 SQLite，提供 SQL 控制台、可编辑结果表格、执行计划、模式图、数据导入导出与活动监控等功能。它内置仅监听 127.0.0.1 的本地 MCP 服务器，供 AI 代理连接数据库。提供 macOS、Linux 与 Windows 预编译包，也可用 cargo 从源码构建；使用 Apache 2.0 许可证。

  • SQL 控制台支持子句感知补全、语法高亮、代码折叠、事务控制与查询历史；结果表格支持分页、排序、批量提交/回滚编辑和跨外键关联行查看。
  • 提供 Explain Plan / Explain Analyse（PostgreSQL 与 MySQL）、二维或三维数据库关系图、DDL Diff，以及 CSV、TSV、JSON、SQL INSERT 等格式导出和 CSV/TSV 导入。
  • 内置本地 MCP 服务器，每个代理连接使用独立令牌；只读访问由 SQL 策略、只读事务与锁强制执行，其余请求需按精确 SQL 逐条批准。

适用场景（解读层）

  • 需要在一个桌面工具中编写、执行 SQL 并直接编辑查询与表数据的 PostgreSQL、MySQL、SQLite 日常开发工作。
  • 通过执行计划、模式图、活动监控（PostgreSQL 会话与阻塞链）排查数据库结构与运行中的查询。
  • 让 Claude Code、Codex 等 AI 代理在受限授权（仅目录、只读或读写）下访问数据库，连接不接触密码或连接字符串。
