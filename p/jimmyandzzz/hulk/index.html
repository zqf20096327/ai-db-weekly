基于MySQL协议的数据库中间件，用SQL统一查询多类数据源

综述（解读层）

Hulk是一个基于MySQL协议的数据库中间件，通过navicat、jdbc等客户端即可连接。它基于Calcite解析SQL并支持自定义扩展，可查询Mysql、Oracle、Clickhouse、Excel、elasticsearch等数据源，提供分库分表、字段级权限和读写分离能力。数据源通过XML配置，使用mvn构建，bin脚本启停。README注明尚不支持alter语句及exists复杂SQL。

  • 支持SQL查询Mysql、Oracle、Clickhouse、Excel、elasticsearch等数据源，跨数据源支持inner join和left join
  • 基于Calcite解析SQL并支持自定义扩展，基于Aviator表达式扩展自定义函数，提供CACHE、FLUSH、NATIVE等扩展SQL语法
  • 提供分库分表、字段级权限配置及读写分离（单写多读）功能

适用场景（解读层）

  • 通过MySQL协议客户端统一访问多种异构数据源的场景
  • 需要对分库分表、字段级权限或读写分离进行管理的MySQL应用
  • 使用SQL关联查询或写入不同数据源（如数据库与Excel、Elasticsearch）的场景
📖 README 首段存档原文 · 程序抽取

- 基于Mysql协议，可以通过navicat、jdbc等连接方式 - 支持用SQL查询非结构化和结构化数据库，例如Mysql、Oracle、Clickhouse、Excel、elasticsearch - 支持不同数据源之间表关联查，目前支持inner join和left join - 基于calcite进行SQL解析，并对SQL进行扩展，支持自定义扩展操作
