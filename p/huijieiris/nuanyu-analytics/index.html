基于 Next.js + PostgreSQL 的 AI Agent 埋点采集与行为分析后台

综述（解读层）

暖屿是一个可独立运行的 AI 产品数据分析后台，覆盖埋点上报、Bad Case 复盘与用户行为分析。产品侧通过 HTTP 接口上报事件即可接入，无需改后台代码；人工评审记录存入 reviews 表作为坏例子率分母。默认不存聊天原文，user_id_hash 仅接受十六进制摘要，明文 PII 会被拒绝。适合需要区分用户/会话口径的 AI 产品团队自部署。

  • 提供埋点上报、人工评审、Case 建立与 JSON 导出、行为钻取等 API，鉴权用 x-api-key Header
  • 支持 D0–D7 留存队列矩阵、行为漏斗与 DAU/WAU 指标，并能自动标注用户口径或会话口径
  • 数据库连接串可指向任意 Postgres（含 Supabase），明文 PII 默认丢弃，聊天原文需显式开启存储

适用场景（解读层）

  • AI Agent 产品上线路径复盘：查看事件时间线、按状态/模型/错误码筛选并一键建 Case
  • 分析用户行为漏斗与留存：通过钻取接口查看卡在某一步或某队列日的具体账号
  • 埋点数据质量自检：通过 /health 的 A01–A11 检查项（含用户标识覆盖度）验证接入情况
