跨数据库SQL语句语法转换的Java工具库

综述（解读层）

SQL Converter 是一个 Java 工具，用于将源数据库（MySQL、Oracle、Dameng 等）的 SQL 语句转换为目标数据库兼容的语法。核心接口 convertSql 接收 SQL、源/目标库类型、目标 Schema 与表名，返回转换后的语句列表；另提供表结构模板生成 DDL 和 SQL 类型识别接口。适用于需要在 Java 项目中集成数据迁移或跨库开发功能的团队。注意存储过程等特有 DDL 语法可能无法完全转换，无法解析的语法会抛出异常。

  • 支持 MySQL、Oracle、Dameng 等数据库类型之间的 SQL 语句互转
  • 自动区分 DML（INSERT/UPDATE/DELETE）与 DDL（CREATE/ALTER/DROP/TRUNCATE/COMMENT）语句类型
  • 提取表结构元数据生成目标数据库兼容的 DDL，支持大小写敏感与目标库命名规则配置

适用场景（解读层）

  • 数据迁移时将建表、增删改等 SQL 语句转换为目标数据库语法
  • 在 Java 项目中集成 SQL 类型识别与异构 DDL 转换能力
  • 根据预定义表结构模板生成指定数据库的 CREATE 语句
