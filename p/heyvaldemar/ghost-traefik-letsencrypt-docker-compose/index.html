基于 Docker Compose 编排 Ghost、Traefik 与 Let's Encrypt 的自托管博客部署模板

综述（解读层）

该项目是一个部署模板而非自建镜像，通过 Docker Compose 编排 Traefik、Ghost 6 与 MySQL 8.4 三个上游官方镜像，面向想在自己服务器上运行 Ghost 博客的用户。Traefik 通过 ACME 自动签发并续期 Let's Encrypt 证书；backups 容器按周期执行数据库转储与内容目录归档并附带恢复脚本。镜像以 sha256 摘要固定版本，CI 在每次推送时验证部署。需要具备公网 IP 的 Linux 服务器、域名 A 记录、开放的 80/443 端口及约 1 GB 内存。

  • Traefik v3 实现 HTTP→HTTPS 重定向与 Let's Encrypt TLS-ALPN 证书自动签发
  • backups 容器按 BACKUP_INTERVAL 循环执行 mysqldump|gzip 数据库转储、内容目录 tar.gz 归档与保留期清理，并提供交互式恢复脚本
  • 三个上游镜像以 tag@sha256 摘要固定，.env 中的 *_IMAGE_VERSION/*_IMAGE_TAG 变量可覆盖版本

适用场景（解读层）

  • 在自有 Linux 服务器上以 Docker Compose 部署带自动 TLS 证书的 Ghost 博客
  • 需要定时数据库与内容目录备份及恢复脚本的自托管博客站点
  • 希望以摘要固定镜像并依赖 CI 部署验证的供应链可控部署场景
