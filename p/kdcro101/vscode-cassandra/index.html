VS Code 中的 Apache Cassandra 工作台扩展，支持 CQL 模板、自动补全与查询执行

综述（解读层）

该扩展是一个 Visual Studio Code 插件，用于设计和查询 Apache Cassandra 数据库，提供 CQL 生成模板、自动补全和内联代码装饰。它支持 Cassandra 2.* 和 3.* 版本，通过 `.cassandraWorkbench.jsonc` 配置文件管理集群连接。使用前需在命令面板运行生成配置命令，且脚本执行有限制：不允许单脚本包含多条 SELECT 语句，也不允许 SELECT 与数据/结构变更语句混合执行。PasswordAuthenticator 模式下连接用户需对 system_schema 等系统键空间具有 SELECT 权限。

  • 提供生成模板、自动补全和内联代码装饰，用于编写 CQL
  • 支持 Apache Cassandra 2.* 和 3.* 版本，含 AllowAllAuthenticator 与 PasswordAuthenticator 两种认证模式
  • 提供键绑定（如 CTRL+ENTER 执行脚本）和面板中按正则排除键空间的配置项

适用场景（解读层）

  • 在 VS Code 中连接并查询 Cassandra 集群
  • 借助模板和自动补全编写 CQL 脚本
  • 通过侧边栏面板浏览和管理多个集群连接与键空间
