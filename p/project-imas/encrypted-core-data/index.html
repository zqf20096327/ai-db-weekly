基于 SQLCipher 的 iOS Core Data 加密 SQLite 存储库

综述（解读层）

encrypted-core-data 为 iOS Core Data 提供一个加密 SQLite 持久化存储，底层使用 SQLCipher 对落盘数据加密，除初始配置外用法与标准 Core Data 相同，可接入既有 Core Data 项目。安装支持手动集成（含 git 子模块）和 CocoaPods。支持一对一、一对多、多对多关系、谓词和实体继承；README 明确不支持 v2.0.6 到 v3.1.0 的旧数据库迁移。适用 iOS 6.0–9.2。

  • 通过 SQLCipher 对持久化到 SQLite 的数据加密，针对 CWE-311 与 CWE-326 所述明文存储及弱加密问题
  • 除初始设置外用法与 Core Data 一致，提供 makeStore/makeStoreWithOptions 接口替换 NSPersistentStoreCoordinator，支持自定义口令、缓存大小与数据库位置
  • 提供 EncryptedStoreFileManager 配置，可自定义数据库文件名、扩展名、所在 bundle 及文件属性

适用场景（解读层）

  • 需对本地 Core Data 数据落盘加密的 iOS 应用
  • 存在安全合规要求（如移动应用访问控制 CAT II 条目）的项目
  • 需要将数据库文件放置于非默认位置或指定 bundle 的 Core Data 集成场景
📖 README 首段存档原文 · 程序抽取

Provides a Core Data store that encrypts all data that is persisted. Besides the initial setup, the usage is exactly the same as Core Data and can be used in existing projects that use Core Data.
