🧭 简介解读层（AI·证据行可回查）

Rust 编写的 MySQL/MariaDB 复制、集群与负载均衡工具

综述（解读层）

WolfScale 是一套 Rust 编写的服务器集群工具套件，包含 WolfStack、WolfScale、WolfDisk 和 WolfNet 四个工具，每个以单一二进制文件运行，通过 UDP 广播自动发现节点。WolfScale 提供 MariaDB/MySQL 的自动主节点选举、WAL 复制与 MySQL 协议代理；WolfDisk 提供 FUSE 分布式文件系统；WolfNet 提供加密私有组网。所有工具均通过 setup.sh 脚本安装，面向需要搭建 Linux 集群基础设施的运维人员。

  • WolfScale 采用单主模型与基于节点 ID 的确定性选举，返回节点需先经 WAL 同步后才能参与主节点竞选
  • 内置 MySQL 协议代理与负载均衡器，应用程序无需修改连接方式即可接入集群
  • WolfNet 基于 TUN 接口实现节点间通信，使用 X25519 密钥交换与 ChaCha20-Poly1305 加密，支持邀请令牌、中继转发与每 60 秒重解析主机名

适用场景（解读层）

  • 为 MariaDB/MySQL 数据库搭建多节点复制与自动故障转移集群，前提是各节点启动前已有相同数据
  • 在多台 Linux 服务器间共享与同步文件，支持 leader、follower、client 与自动选举四种节点角色
  • 将分布在不同位置或 NAT 后的机器通过邀请令牌或静态配置组成加密私有网络
