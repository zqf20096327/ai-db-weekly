🧭 简介解读层（AI·证据行可回查）

基于知识图谱与递归检索的本地优先 AI 代理持久化记忆基础设施

综述（解读层）

Ori Mnemos 是面向 AI 代理的开源持久化记忆系统，将记忆存储为磁盘上的 Markdown 文件，以 wiki 链接作为图谱边，配合本地 SQLite 索引实现检索。核心机制包括 ACT-R 激活衰减、沿链接的扩展激活、基于检索模式的共现强化，以及带子问题分解的递归图遍历。通过 CLI、MCP 服务器和 TypeScript 库三种入口使用，数据保留在本地，无需数据库或云服务。版本为 v0.7.0，采用 Apache-2.0 许可。

  • 以 Markdown 文件为事实源、wiki 链接为图边、Git 为版本控制，索引可由 npx ori index build 重新派生
  • 提供 CLI（init/index build/explore/sql）、MCP 服务器（ori serve）与库接口（recall/searchComposite）三种访问方式
  • 内置确定性离线遗忘操作（supersede/release/purge），并提供可复现的 ForgetEval 评测适配器

适用场景（解读层）

  • 为需要跨会话、跨客户端持久记忆的 LLM 代理提供本地记忆存储与召回
  • 通过 MCP 协议接入支持该协议的客户端，作为代理的记忆后端
  • 在无网络、无 API 密钥的离线环境中进行多跳知识检索与长期对话记忆管理
