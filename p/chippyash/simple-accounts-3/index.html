基于 MariaDB/MySQL 纯 SQL 存储过程实现复式记账的 PHP 总账库

综述（解读层）

这是一个数据库驱动的总账会计库，通过存储过程与 PHP API 在应用中快速实现复式记账，支持 MariaDB（需 OQGraph 插件）与 MySql（嵌套集实现）两种 SQL 后端。它不提供销售/采购等业务台账，仅包含中央会计功能，且只处理整数金额，浮点需配合 Chippyash\Currency 使用。适合需要在应用内建立内部账户体系的开发者。

  • SQL API 通过存储过程提供，MariaDB 实现使用 OQGraph 插件处理层级科目结构，MySql 实现使用嵌套集
  • 日志记录强制借贷金额相等，由触发器维护科目余额，子科目更新会逐级同步至根科目
  • 默认支持最多 10 位数字 Nominal Code，并附带 Doctrine Migrations 迁移文件

适用场景（解读层）

  • 在 PHP 应用中嵌入复式记账总账功能
  • 需要追踪积分等内部账户变动的站点（如游戏积分与实际价值换算）
  • 使用 Doctrine Migrations 的 MariaDB 项目复用其数据库结构迁移
