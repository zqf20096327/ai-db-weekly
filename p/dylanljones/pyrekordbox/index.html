读写 Pioneer Rekordbox 数据库与配套文件（master.db、XML、ANLZ、My-Settings）的 Python 包

综述（解读层）

pyrekordbox 是一个非官方的 Python 包，用于访问 Pioneer Rekordbox DJ 软件的曲库数据，支持 master.db（经 SQLCipher 加密解锁）、Rekordbox XML、ANLZ 分析文件、My-Settings 文件及 OneLibrary 数据库的读取与部分写入。安装后可自动检测本机 Rekordbox 配置，经 pip install pyrekordbox 安装。项目声明与 Pioneer 无关联，已在 Windows 和 macOS 上测试，README 提示修改数据前应备份曲库。

  • 支持 Rekordbox master.db（SQLCipher 加密解锁）、XML、ANLZ、My-Settings 文件与 OneLibrary 数据库的读取，并可修改 master.db 部分表中的曲目、播放列表、专辑等条目
  • 可解析 ANLZ 分析文件中的波形、beat grid、时间索引及记忆提示/循环点标签
  • 自动检测本机安装的 Rekordbox 并完成配置，可通过 show_config 查看或手动更新路径

适用场景（解读层）

  • 编程方式读取或修改 Rekordbox 曲库元数据与播放列表
  • 解析导出到 USB 设备的 ANLZ 与 My-Settings 文件，供分析或同步使用
  • 在两个 Rekordbox 数据库之间通过 XML 分享播放列表
