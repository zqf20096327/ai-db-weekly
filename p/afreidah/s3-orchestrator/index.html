🧭 简介解读层（AI·证据行可回查）

在多个 S3 兼容后端前提供单一 S3 端点的存储编排层

综述（解读层）

s3-orchestrator 是用 Go 编写的存储编排层，将 OCI、B2、AWS S3、MinIO、R2 等多个 S3 兼容后端聚合为一个虚拟端点，客户端仅需对接一个命名空间。它通过自建元数据数据库跟踪对象位置，实现后端字节/请求/流量配额、N 副本复制与读失败转移，并支持 zstd 压缩与信封加密。面向 homelab、自托管 MinIO 用户及小型团队。元数据存储可用内嵌 SQLite 或 PostgreSQL 14+，多实例部署需 PostgreSQL。

  • 支持按后端配置字节、月度请求、入站与出站流量上限，写满后自动溢写至下一后端
  • 可配置副本因子将每个对象写入多个不同后端，提供后台复制器与写入路径并行复制两种方式，读请求在副本间失败转移
  • 提供 AES-256-GCM 信封加密（密钥可内联、文件或 Vault Transit）、分块 zstd 压缩、对象标签、SigV4 与预签名 URL

适用场景（解读层）

  • 将多个云服务商的免费额度叠加为一个可用存储桶
  • 为本地 MinIO 实例通过修改配置自动进行云端备份
  • 在不改动应用代码的前提下更换、增加或移除 S3 后端以实现多云冗余
