基于 Tauri 2 与 Vue 3 的跨平台桌面应用脚手架，AI 能力可插拔

综述（解读层）

meow-starter 是一个 AI Native 的跨平台应用脚手架，提供本地数据（桌面 SQLite、Web IndexedDB）、系统托盘、自动更新与设计系统等核心能力，Agent、MCP、本地推理、同步等以可选模块形式按需启用。面向希望构建桌面及多端产品的开发者。使用需 Node.js 22+ 与 Rust 1.77.2+，Web 与移动端尚处 Beta，更新发布需下游自行配置端点与签名密钥。

  • 提供模块化架构：core 模块常载，sync、agent、mcp 等可选模块由配置控制，禁用模块不被默认运行时加载
  • 数据层为统一领域接口，桌面运行时使用 SQLite，Web 运行时使用 IndexedDB，并含内存回退实现
  • 包含设计令牌、六个基础组件与四套主题，支持系统感知的深色模式

适用场景（解读层）

  • 以 Tauri 2 + Vue 3 为基础启动新的跨平台桌面应用开发
  • 需要在桌面、Web 及移动端复用同一前端代码库的项目
  • 需要按需接入 Agent、MCP 或 Ollama 本地推理能力的应用
