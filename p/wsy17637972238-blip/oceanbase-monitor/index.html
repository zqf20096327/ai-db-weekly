🧭 简介解读层（AI·证据行可回查）

面向 OceanBase 数据库的 AIOps 智能巡检平台，集采集、告警、AI 诊断与守卫式自治处置于一体。

综述（解读层）

该项目为银行内部两地三中心场景下的 OceanBase 数据库提供智能巡检能力：通过 JDBC 直连 OB 4.4 系统视图定时采集指标，经规则引擎阈值判定生成告警并处理全生命周期状态，再由多个专用 AI Agent 做根因诊断，自治处置动作需经守卫链裁决与审批门。适用于需要国产数据库巡检与告警管理的运维团队；主项目基于 Spring Boot 3 与 Vue3，依赖 Docker 运行的 OceanBase 实例，仓库另含已被取代的早期 Demo 代码。

  • 支持 8+3 类指标 JDBC 直连 OceanBase 4.4 系统视图采集，内置 14 条规则引擎并支持阈值热调整
  • 提供 4 个专用 AI Agent（慢 SQL/容量/事务/兜底）诊断，采用确定性路由、只读取证 SQL 防火墙、grounding 校验与 per-agent 熔断降级
  • 自治处置仅允许模型提议预定义动作（kill_session/major_freeze/restore_param_baseline），经白名单、前置检查、限频熔断、审批门、dry-run、复测的守卫链裁决

适用场景（解读层）

  • OceanBase 数据库的定时/手动指标巡检与阈值告警管理
  • 慢 SQL、容量、事务等问题的多 Agent AI 根因诊断
  • 需要审批与 dry-run 保障的数据库会话终止、合并冻结等受限自治处置场景
