🧭 简介解读层（AI·证据行可回查）

面向 .NET 微服务开发的脚手架组件集，以 Nuget 包形式提供分布式与微服务常用能力。

综述（解读层）

Hummingbird 是一组 .NET Nuget 包集合，用于在 ASP.NET Core 项目中接入分布式锁、分布式缓存、Snowfake 分布式 ID、Jaeger 分布式追踪、基于 RabbitMQ/Kafka 的消息总线、健康检查、Consul/Nacos 服务注册发现与负载均衡、Apollo/Nacos 配置中心、Canal 数据集成及 OSS/本地文件系统。每个功能通过安装对应包并在 Startup 中配置使用，README 提供了各组件的代码示例。 Canal 输出到 RabbitMQ/Kafka 的功能标注为待实现。

  • 提供分布式锁、分布式缓存、Snowfake 分布式 ID、基于 Jaeger 的 OpenTracing 分布式追踪等多种扩展包
  • 消息总线支持 RabbitMQ 与 Kafka，并提供基于 MySql/SqlServer 的消息可靠性持久化
  • 弹性 HTTP 客户端支持服务发现、负载均衡、超时、重试、熔断；Canal 输出到 RabbitMQ/Kafka 标注为待实现

适用场景（解读层）

  • 在 .NET 微服务项目中集成服务注册发现、配置中心、健康检查等基础设施能力
  • 需要在应用内使用分布式锁、分布式缓存或分布式唯一 ID 生成
  • 通过 Canal 订阅 MySQL binlog 并将变更事件输出到控制台等目标
