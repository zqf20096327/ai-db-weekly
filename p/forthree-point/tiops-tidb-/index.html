轻量级可私有化部署的 TiDB 多集群 Web 运维平台

综述（解读层）

TiOps 是一个用纯 Python 实现的 TiDB 多集群运维平台，面向 DBA 与运维团队，提供集群总览、会话管理、SQL Binding、巡检、告警与每日报告等功能。它基于 ThreadingHTTPServer，仅依赖 PyMySQL，集群配置存于本地 JSON，不需要额外管理数据库；部署时需 Python 3.8+、OpenSSL 及可访问 TiDB SQL 端口、Status API 和 Prometheus 的网络。

  • 基于 Python 内置 ThreadingHTTPServer 与 Mixin 路由，仅依赖 PyMySQL，无 Web 框架与管理数据库
  • 使用线程池并发查询 TiDB SQL、Status API 与 Prometheus，每日报告跨集群采集 12 项健康指标并自动评级
  • 集群地址与密码使用 OpenSSL AES-256-CBC 加密落盘，密钥与代码分离存放于 /etc/tidb-portal/portal.key

适用场景（解读层）

  • 统一管理开发、测试、预生产和生产环境中的多套 TiDB 集群
  • 在内网或隔离网络中部署数据不出域的轻量运维工具
  • 定位慢 SQL、异常会话、CDC/Drainer 延迟等问题并生成每日健康巡检报告
