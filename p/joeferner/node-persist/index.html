Node.js ORM 框架，支持 SQLite、MySQL、PostgreSQL、Oracle

综述（解读层）

persist 是一个 Node.js ORM 框架，通过各数据库驱动连接 sqlite3、MySQL、PostgreSQL 和 Oracle。开发者可用 persist.define 定义模型，模型支持主键默认值、hasMany/hasOne 关联及 through 多对多关系；同时提供事务、连接池、SQL 链式执行与从文件读取 SQL 等能力。连接配置可通过 database.json 按环境加载。README 首行声明该项目已不再维护。

  • 通过 node-sqlite3、node-mysql、node-postgres、node-oracle 驱动支持 sqlite3、MySQL、PostgreSQL、Oracle 四种数据库
  • 提供模型定义（persist.define/defineAuto）、hasMany/hasOne 关联及 through 多对多关系
  • 支持事务（commit/rollback）、连接池、语句链式执行及从文件加载 SQL

适用场景（解读层）

  • 在 Node.js 应用中以模型方式读写关系型数据库表
  • 需要事务控制或连接池的数据库访问场景
  • 按环境（dev/test/prod）通过 database.json 管理多套数据库连接配置
