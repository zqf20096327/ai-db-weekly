开源 agentic BI 平台，通过数据团队控制的上下文层让全员对话式分析数据

综述（解读层）

nao 是一个开源 agentic BI 平台（Apache 2.0，企业版功能另收费），面向数据团队与业务用户：前者用 nao-core CLI 将数据仓库、dbt、文档同步为文件形式的上下文层，后者通过 Web 应用、Slack、Teams 等渠道以自然语言提问并生成 story 仪表板。提供 nao test 离线评估、对话回放、Docker 部署及 nao Cloud 托管。

  • nao-core CLI 将数据仓库、dbt、文档与规则同步为 agent 读取的文件化上下文
  • nao test 基于 YAML 中的问题与期望 SQL 对上下文变更进行离线打分评估
  • 通过 Web 应用、Slack、Teams 或 MCP 客户端提问，生成可分享的交互式 story

适用场景（解读层）

  • 数据团队为全公司搭建可测试、可观测的对话式数据分析代理
  • 业务人员在 Slack/Teams/Web 中以自然语言查询数据并自制仪表板
  • 需要行级安全、SSO、LLM 预算管控的企业级自助分析部署
