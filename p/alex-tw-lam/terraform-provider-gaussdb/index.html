面向 openGauss/GaussDB 的 Terraform 供应商，管理逻辑数据库层资源

综述（解读层）

这是一个 Terraform provider，用于管理 openGauss/GaussDB（含华为云 HCS 企业版）的逻辑数据库层，涵盖租户、角色、授权、表空间、发布、复制槽等资源。它 fork 自 cyrilgdn/terraform-provider-postgresql，将 lib/pq 驱动替换为 gaussdb-go，并适配 openGauss 方言；不支持原生 PostgreSQL。各资源已在 openGauss 5.0 上实测验证。安装需从源码构建并使用 dev override 方式加载。

  • 提供 14 种资源，覆盖数据库、角色、schema、授权、表空间、扩展、函数、发布与复制槽等逻辑层对象
  • 以 Huawei gaussdb-go 驱动替换 lib/pq，资源实现适配 openGauss 方言（SYSADMIN、DBCOMPITIBILITY、MAXSIZE 表空间等）
  • 使用 openGauss 原生 sha256 认证，资源与内置 tenant 模块均已在 openGauss 5.0 上实测验证

适用场景（解读层）

  • 用 Terraform/OpenTofu 以基础设施即代码方式管理 openGauss/GaussDB 的租户与逻辑数据库对象
  • 基于 modules/tenant 模块批量创建带表空间配额、组角色与应用登录的租户
  • 华为云 HCS 企业版 GaussDB 环境的逻辑层数据库资源自动化编排
