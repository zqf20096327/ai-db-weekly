为 AI 编码代理提供 Siemens NXOpen .NET API 检索的 MCP 服务器，基于本地混合检索

综述（解读层）

这是一个 MCP 服务器，通过 BGE-M3 嵌入与精确名称匹配的混合检索，为 Claude Code、Codex、Cursor 等 AI 编码代理提供来自用户自有 NX 安装文档的 NXOpen .NET API 知识。索引在本地离线构建为 SQLite 文件；需 Python 3.11+，全量 NX 12 文档集（约 10 万成员）嵌入需数小时，首次语义查询需加载约 2GB 模型。README 附带 73 查询集的检索评估数据。

  • 提供 search_api、get_class、get_member、find_builder 四个工具，支持中英文语义查询、类成员列表（含继承链）、成员签名与 NX 版本信息、CAM 操作到 Builder 类的代码骨架映射
  • 索引基于自有许可 NX 安装的 XML/DLL 构建并本地运行，仓库不含 Siemens 文件；采用一成员一分块索引与 RRF 融合，默认检索通道为 dense+exact
  • 支持通过 .mcp.json、Codex config.toml、Cursor MCP 设置接入；索引为单个 SQLite 文件（全量 NX 12 约 500MB），可在持有许可的组织内共享

适用场景（解读层）

  • 为 AI 编码代理编写 Siemens NX CAM/CAD 自动化代码时提供真实 API 签名与 NX 版本信息查询
  • 根据 CAM 操作名称查找对应 Builder 类及 Builder → Commit → Destroy 代码骨架
  • 在持有多席位 NX 许可的团队内共享预构建索引，免去各成员数小时的索引构建
