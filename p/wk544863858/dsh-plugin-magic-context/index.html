DSH 插件：SQLite 项目记忆加可回滚上下文回收与摘要压实

综述（解读层）

这是 DeepSeek Harness（DSH 0.2.x 桌面版）的一个插件，为会话提供持久化项目记忆和上下文窗口管理。记忆侧用自带 SQLite 库（memories.db）存语料，经 MiniLM WASM 本地向量加全文 0.7/0.3 混合检索并注入 m[0] 基线；上下文侧提供 ctx_reduce/ctx_expand 工具，删除以占位符落地且可恢复。依赖 Node ≥ 22.19，经 dsh plugin add 安装后热加载。压实接管 registerCompactionEngine 默认关闭。

  • 项目记忆存于插件自有 SQLite 库，支持全文 0.7 + 向量 0.3 混合检索，向量嵌入由 onnxruntime-web WASM 本地运行，无需 API 密钥
  • ctx_reduce 仅排队删除、以 [dropped §N§] 占位符落地，ctx_expand 可原地恢复原文；historian 以 p1–p4 四级摘要作区间替换发布
  • 全局域共享中 staging 可自动化，发布需人工审批（审批卡 / ctx-global approve）；维护 tick 每 30 分钟执行归档、验证与向量回填

适用场景（解读层）

  • 长会话中需跨重启保留项目知识、并以混合检索回注给模型的 DSH 桌面用户
  • 工具输出占用上下文窗口、需要按 §N§ 标签排队回收且可恢复原文的场景
  • 机器/组织级记忆共享流程需保留人工发布审批环节的团队
