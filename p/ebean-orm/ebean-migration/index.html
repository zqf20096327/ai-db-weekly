Java 数据库迁移执行器，可独立运行或随 EbeanServer 启动执行

综述（解读层）

ebean-migration 是一个读取 .sql 脚本并执行数据库迁移的 Java 运行器，遵循 FlywayDB 约定，支持版本化与可重复迁移（基于 MD5 校验）。可传入 Connection、DataSource 或由配置创建连接运行，也可在 EbeanServer 启动时执行。提供 rebaseMigrationHistory 选项用于压缩历史后一次性重置迁移记录，README 提示该操作具破坏性。

  • 支持 Versioned 与 Repeatable（R__ 前缀）两类迁移脚本，Repeatable 通过 MD5 校验检测内容变化
  • 迁移脚本可从 classpath 或文件系统路径加载，连接方式支持显式 Connection、DataSource 或配置中的 JDBC Driver/URL
  • 提供 rebaseMigrationHistory 设置，在不执行 SQL 的情况下按现存脚本重建迁移历史记录

适用场景（解读层）

  • 在应用启动或 EbeanServer 初始化时自动执行 SQL 迁移脚本
  • 独立运行工具中按版本顺序应用 .sql 迁移文件
  • 在压缩合并历史迁移脚本后，对已知匹配的数据库重建迁移记录
