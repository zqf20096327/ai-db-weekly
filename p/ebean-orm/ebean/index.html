面向 Java 与 Kotlin 的 ORM 库，提供多层级查询抽象与数据库迁移生成

综述（解读层）

Ebean 是面向 Java 和 Kotlin 的 ORM 库，发布于 Maven Central（groupId: io.ebean）。它提供多层级查询抽象，包含 ORM 查询、DTO 查询、SqlQuery 以及直接使用 JDBC；内置数据库迁移的生成与执行，支持 rebase、repeatable、init 及普通迁移；可对 ORM 查询进行基于对象图使用情况的自动调优。支持 Postgres、MySQL、Oracle、SqlServer 等多种数据库平台。从源码构建需 JDK 11+ 与 Maven，因使用 module-info，暂不能在 Eclipse IDE 中构建和运行测试。

  • 提供 ORM 查询、DTO 查询、SqlQuery 与 JDBC 等多层查询抽象
  • 内置数据库迁移生成与运行，支持 rebase、repeatable、init 和普通迁移
  • 支持基于类型安全 query bean 的查询构建，可在 IDE 中自动补齐并在编译期检查

适用场景（解读层）

  • Java 或 Kotlin 项目中需要 ORM 与 SQL 混合使用的数据库访问层
  • 需要生成并运行数据库迁移脚本的项目
  • 需要通过 profile 自动调优 ORM 查询、避免 N+1 查询的应用
