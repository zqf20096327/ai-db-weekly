将 ODK 问卷数据转换为 MySQL 关系模式的命令行工具集

综述（解读层）

ODK Tools 包含四个命令行工具和八个实用程序，用于把 ODK 问卷数据处理进 MySQL 数据库：JXFormToMySQL 从 PyXForm JSON 生成关系模式，FormShareToJSON 和 XMLtoJSON 把提交数据导出为 JSON，JSONToMySQL 再将 JSON 导入 MySQL 并生成 Map 文件供反规范化。支持多语言、查找表、repeat 子表，可通过 JavaScript 的 beforeInsert 函数定制插入逻辑。适用于已使用 ODK 收集数据并需要存入 MySQL 的团队。

  • JXFormToMySQL 将 PyXForm JSON 转换为含主键、查找表和多语言支持的关系型 MySQL 模式，输出 create.sql、insert.sql、metadata.sql、manifest.xml 等文件
  • JSONToMySQL 支持通过外部 JavaScript 的 beforeInsert 函数在插入前定制数据，并生成记录 UUID 树结构的 Map 文件用于反规范化
  • 工具箱跨平台，可在 Windows、Linux 和 Mac 上构建，可处理 FormShare 的 JSON 提交和 ODK 原始 XML 提交

适用场景（解读层）

  • 将 ODK 问卷的 PyXForm 定义转换为规范化的 MySQL 数据库结构，含查找表、repeat 独立表和多语言字典
  • 从 FormShare 的 MongoDB 或 ODK 原始 XML 提交中导出 JSON 并批量导入 MySQL，附错误日志与 UUID Map 文件
  • 通过 beforeInsert JavaScript 钩子在数据入库前执行自定义转换或校验
