Go 日志库，以 slog Handler 接入并通过分块非阻塞写入实现日志持久化

综述（解读层）

SQLog 是一个 Golang 库，实现 slog.Handler 接口，用于捕获并管理应用日志。内部由 Handler、Ingester、Chunk、Storage 四层组成：日志转为 JSON 后经内存 Chunk 链表缓冲，由 Ingester 定期 Flush 持久化；当前内置 SQLite 存储实现（需自行注册 SQLite 驱动），内存存储尚在开发中。适合需要在 Go 应用中落地并检索 slog 日志的开发者。

  • 实现 slog.Handler，支持默认 slog.NewJSONHandler 编码器或自定义编码器
  • Ingester 基于 sync/atomic 原子操作实现非阻塞写入，不使用互斥锁
  • Chunk 采用链表结构，存储层为模块化设计，内置 SQLite 实现

适用场景（解读层）

  • 为 Go 应用提供基于 slog 的日志采集与持久化
  • 将日志存储到 SQLite 并通过内置 API（如 /logs/ 页面）查看
  • 需要多 goroutine 并发写日志、低延迟场景下的日志管理
