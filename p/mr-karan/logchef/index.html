🧭 简介解读层（AI·证据行可回查）

自托管单二进制日志分析平台，为 ClickHouse/VictoriaLogs 提供查询与可视化界面

综述（解读层）

Logchef 是一个自托管的日志分析与可观测性平台，以单一可执行文件运行于已有 ClickHouse 或 VictoriaLogs 之上，不迁移或重构数据。它提供 LogchefQL 及原生 SQL/LogsQL 查询、实时 tail、多面板仪表盘、定时告警、RBAC 访问控制，默认使用 SQLite 存元数据，可选 Postgres。适合已在运行上述日志后端并需要统一查询控制面的团队，采用 AGPLv3 许可。

  • 连接 ClickHouse、VictoriaLogs 或两者，使用 LogchefQL 或原生 SQL/LogsQL 查询，支持实时 tail 与保存查询
  • 提供多面板仪表盘（时间序列、stat、breakdown、表格），支持拖拽布局与共享时间范围，内置定时告警和 email/webhook 通知
  • 单二进制部署无运行时依赖，元数据默认 SQLite，可切换 Postgres；支持 OIDC 或本地邮箱密码认证加 RBAC，并暴露 Prometheus 指标和 MCP 端点

适用场景（解读层）

  • 团队在已有 ClickHouse 或 VictoriaLogs 数据存储上需要统一的日志查询、仪表盘与告警界面
  • 无外部身份提供方的环境中用内置邮箱密码认证运行，或通过 OIDC 单点登录并配合 RBAC 管理访问
  • 通过 CLI 或内置 MCP 端点从终端或 AI 助手查询与排查日志
