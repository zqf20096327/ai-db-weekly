🧭 简介解读层（AI·证据行可回查）

通过 SQL 查询外部数据库并将结果转换为 Prometheus 格式指标的导出工具

综述（解读层）

store-exporter 读取 SQL 查询文件，从 PostgreSQL 或 MySQL 等外部数据存储中获取数据，将查询结果转换为 Prometheus 文本格式并通过 HTTP 服务暴露。适用于不想在应用内嵌指标采集逻辑的场景，采用 Sidecar 方式运行。支持配置多个 job，每个 job 可连接不同的数据库；Redis 支持标注为即将提供。MIT 许可证。

  • 从 SQL 查询结果中提取列名，并将其暴露为自定义指标标签
  • 支持注册多个 job，分别连接不同的数据库存储
  • 支持 postgres 和 mysql 两种数据库类型，通过 TOML 配置文件定义查询与连接参数

适用场景（解读层）

  • 应用本身无 HTTP 服务器，无法直接暴露 /metrics 端点的场景
  • 不希望在应用代码中引入指标采集库或混合采集逻辑的项目
  • 以 Sidecar 方式从应用写入的外部持久化存储中提取自定义业务指标
