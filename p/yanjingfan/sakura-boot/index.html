🧭 简介解读层（AI·证据行可回查）

基于 Spring Boot 2.x 的微服务脚手架，按模块封装常用中间件组件。

综述（解读层）

该项目将 Redis、ElasticSearch、RabbitMQ、MinIO、Nacos、Seata 等常见中间件能力拆分为多个 Maven 模块，提供限流注解、认证、分布式 ID、数据库版本管理等通用组件，供 Java 微服务开发者按需引入。技术栈为 Spring Boot 2.3.12 与 Spring Cloud Hoxton，README 提到升级 Spring Boot 3 尚在待开发状态。

  • 包含 cache、db、es、mq、gateway、oauth2、sa-token、seata、uid-generator 等 20 余个可按需引入的功能模块
  • 集成 Spring Cloud Hoxton 与 Spring Cloud Alibaba，含 Nacos、Seata、OpenFeign 等组件
  • 提供分布式限流注解、单机限流注解、SQL 盲注处理、Swagger/knife4j 文档配置等通用工具

适用场景（解读层）

  • 搭建基于 Spring Boot 2.x 与 Spring Cloud Alibaba 的 Java 微服务项目
  • 需要统一封装 Redis、ES、RabbitMQ、MinIO 等中间件访问层的服务端开发
  • 需要认证、分布式 ID、数据库版本管理等基础能力的后端工程复用组件
