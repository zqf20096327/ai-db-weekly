自托管数据库备份管理器，通过 Web UI 调度、备份与恢复多类数据库

综述（解读层）

Databasement 是一个自托管数据库备份管理应用，基于 Web UI 管理多台数据库服务器的定时备份与恢复。它通过调用各数据库原生命令行工具（mysqldump、pg_dump、mongodump 等）导出数据，支持 SSH 隧道连接私有网络数据库，并提供远程 agent 以 outbound HTTPS 方式覆盖无入站端口的隔离网络。支持 gzip/zstd/加密压缩、GFS 保留策略，存储目标涵盖本地、S3 兼容、Azure Blob、SMB 及 SFTP/FTP。支持多租户、RBAC 与 OAuth/SSO 登录，提供 REST API 与 MCP server。MIT 许可，Redis/Valkey 仅支持备份不支持恢复。

  • 通过单一 Web 界面管理 MySQL、PostgreSQL、MariaDB、SQL Server、MongoDB、SQLite、Firebird、Redis/Valkey 八类数据库的备份与恢复（Redis/Valkey 不支持恢复）
  • 支持 SSH 隧道（密码或密钥认证）及远程 agent 模式，agent 经 HTTPS 出站连接并上传备份
  • 提供 gzip/zstd/AES-256 加密压缩、GFS 或按天数保留策略、定时恢复，以及 Email/Slack/Discord/Telegram 等失败通知

适用场景（解读层）

  • 在单一自托管界面中集中调度多台数据库服务器的定时备份
  • 备份内网或防火墙后无入站端口的数据库
  • 通过 REST API 或 MCP 将备份管理集成到脚本、CI/CD 流程或 AI 助手
