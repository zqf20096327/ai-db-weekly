🧭 简介解读层（AI·证据行可回查）

基于 Go 的 TiDB 优化器决策校准工具，聚焦索引查找与全表扫描选择验证

综述（解读层）

该工具用 Go 编写，连接本地 TiDB 集群（默认 localhost:4000）执行 144 个测试场景，覆盖 8 种数据规模与 9 种选择率组合，比较带与不带 hint 的查询计划，采集执行时间、RU、代价等指标并输出 JSON 报告。适用于需要验证优化器选择是否与预期一致、检测回归的 TiDB 使用者或开发者；运行需先编译并准备可访问的 TiDB 实例。

  • 内置 144 个场景：8 种数据行数（1 至 10M 行）与 9 种选择率（1/2 至 1/512）的组合，通过 IGNORE_INDEX hint 对比强制表扫描与优化器自主选择的计划
  • 采集执行时间、RU、计划类型、估算行数、总代价等指标，自动识别 index_lookup 与 table_scan 计划类型
  • 提供校验框架：按可配置容差比较代价、校验算子与决策类型，支持 hash/nested loop/sort-merge 连接算法选择验证，并输出 JSON 差异报告

适用场景（解读层）

  • 在不同数据规模与选择率下验证 TiDB 优化器对索引查找与表扫描的选择是否符合预期
  • 通过与历史结果的比较检测优化器行为变化或性能回归
  • 在变更 TiDB 配置或代价模型参数后执行校准测试并生成详细报告
