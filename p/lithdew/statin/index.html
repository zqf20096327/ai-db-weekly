基于 bun:sqlite 的时序统计与分位数草图聚合库

综述（解读层）

statin 是一个运行在 bun:sqlite 之上的时序统计库，在业务已有的 OLTP 事务内增量聚合 min/max/mean 等统计量，并用 DDSketch 以有限内存维护 p50/p90/p95/p99 等分位数。数据存储在 events、stats、stat_sketches 三张表中，默认相对误差界为 0.01%。要求事件时间戳单调递增，乱序事件需删除并重建相关草图。项目仍处于 WIP 阶段。

  • 在 OLTP 数据库同一事务内增量聚合统计量（min、max、mean、median 等）
  • 使用 DDSketch 以有限内存增量维护 p50/p90/p95/p99 等分位数，默认相对误差界 0.01%
  • 数据落在 events、stats、stat_sketches 三张 SQLite 表中，通过 bun add statin-bun 安装

适用场景（解读层）

  • 需要在使用 bun:sqlite 的后端中记录 API 响应时间等时序指标并查询分位数
  • 希望避免单独部署 OLAP 数据库及 OLTP 到 OLAP 的数据同步代码
  • 需要跟踪某个统计量随时间的变化率
