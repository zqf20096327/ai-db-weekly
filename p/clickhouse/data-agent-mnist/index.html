🧭 简介解读层（AI·证据行可回查）

将自有数仓转化为分析 Agent 基准测试的评测框架

综述（解读层）

该项目是一个 Python 评测框架，用户接入自己的数仓和问题集，生成针对分析型 Agent 的评分板。它通过确定性播种生成可复放的数仓状态，由多个供应商模型独立解题、以至少两家一致的结果作 ground truth，再用跨供应商评委团打分，输出通过率及差异检验等统计。仓库只含机制，不含题目和数仓数据。

  • 提供确定性数据播种，使每次评测在相同的数仓状态下运行
  • 以多供应商模型交叉一致作为 ground truth 生成机制，无需人工编写答案
  • 评委团按供应商分配席位，候选模型不参与评自己的答案，并内置评委偏差与失败模式分析脚本

适用场景（解读层）

  • 针对自有数仓的模式、连接深度和真实问题评估候选分析型 Agent 或模型
  • 在可复放、环境固定的条件下对模型结果进行可核验的对比统计
  • 以 examples/ 下两个示例数仓为基础学习评测流程并接入自有数据
