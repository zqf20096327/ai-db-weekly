用 ClickHouse 作为 Graphite 存储后端的指标存储服务

综述（解读层）

Graphouse 由 ClickHouse 团队维护，用于将 ClickHouse 作为 Graphite 的存储层。它提供接收 Graphite 明文协议指标的 TCP 服务、供 graphite-web 使用的指标查询与数据读取 HTTP API，以及指标树管理的 HTTP API。README 含安装、配置与构建指引，社区支持通过 Telegram 群组。

  • 提供 TCP 服务器，通过 Graphite 明文协议接收指标
  • 提供 HTTP API 用于指标搜索与数据读取，可配合 graphite-web python 模块使用
  • 提供 HTTP API 管理指标树

适用场景（解读层）

  • 需要以 ClickHouse 存储 Graphite 监控指标的场景
  • 已运行 graphite-web 并需要替代存储后端的部署
  • 需要通过 HTTP API 管理指标树结构的监控系统
