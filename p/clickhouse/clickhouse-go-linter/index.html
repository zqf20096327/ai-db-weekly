🧭 简介解读层（AI·证据行可回查）

针对 clickhouse-go 原生 API 的 Go 静态检查工具，检测遗漏 rows.Err 与 batch.Close

综述（解读层）

ClickHouse 官方提供的 Go linter，面向使用 clickhouse-go 驱动原生 API（clickhouse.Open() 返回 Conn）的代码库，不适用于 database/sql 接口。包含两条规则：chrowserr 检查 rows.Next() 后缺失 rows.Err()，chbatchclose 检查 Batch 缺失 defer batch.Close()。可通过 go vet -vettool 或独立命令运行，支持变量重赋值追踪，但存在不跨函数块边界等限制。

  • 提供 chrowserr 规则：检测 rows.Next() 后未调用 rows.Err() 的情况，支持变量重赋值与交织变量分析
  • 提供 chbatchclose 规则：检测 Batch 变量缺失 defer batch.Close()，识别直接调用与立即执行闭包两种 defer 形式
  • 支持 go vet -vettool 方式与独立命令两种运行方式，规则与 HTTP/TCP 协议无关

适用场景（解读层）

  • 使用 clickhouse-go 原生 API 进行查询的项目，在 CI 中检查遗漏 rows.Err() 导致的部分结果问题
  • 使用 Batch 写入数据的项目，检查未 defer Close 造成的连接泄漏
  • 集成到 go vet 流程中对代码库做静态检查；golangci-lint 集成在 README 中标注为即将支持
