用递归 CTE 在 SQL 中计算 Mandelbrot 集的 SQL 引擎基准测试套件

综述（解读层）

该项目通过 SQL 递归 CTE 迭代 z=z²+c 公式计算 Mandelbrot 集并生成图像，用于测试各 SQL 引擎的递归查询性能、浮点精度与计算能力，测点覆盖 ClickHouse、chDB、SereneDB、CedarDB、DuckDB、ArrowDatafusion、SQLite 以及 NumPy、Python 参考实现。新增引擎只需实现一个 run 函数并在 main.py 注册；部分引擎需经 Docker 启动，CedarDB 需约 16 GB 以上内存。

  • 使用纯 SQL 递归 CTE 计算 Mandelbrot 集，无过程式代码，参数（宽度、高度、最大迭代数）可在 main.py 中配置
  • 支持 ClickHouse、chDB、SereneDB、CedarDB、DuckDB、ArrowDatafusion、SQLite 等引擎，并含 NumPy 与纯 Python 参考实现；不可用的引擎会被自动跳过
  • README 给出 1400x800 像素、256 次迭代、MacBook Pro M3 Max 上的测试结果表，并说明扩展新引擎需实现 run 函数并注册到 main.py

适用场景（解读层）

  • 评估 SQL 引擎处理深层递归 CTE 查询的性能与查询优化能力
  • 检验引擎对 DOUBLE/Float64 浮点精度的支持（部分引擎使用 DECIMAL 会导致像素化结果）
  • 在不同迭代深度与分辨率下观察引擎的计算可扩展性，并以 NumPy/Python 实现作为参照
