🧭 简介解读层（AI·证据行可回查）

基于 Docker 的 PostgreSQL + ClickHouse 数据栈，用 PeerDB CDC 同步并经 pg_clickhouse 卸载分析查询

综述（解读层）

该项目提供一个由 PostgreSQL、ClickHouse、PeerDB 和 pg_clickhouse 组成的容器化数据栈：PostgreSQL 作为事务主库与数据源，PeerDB 通过 CDC 近实时同步数据到 ClickHouse，pg_clickhouse 扩展将分析查询透明卸载到 ClickHouse。附带 Next.js 示例费用应用演示看板查询加速。运行需 Docker 与 Bash，通过 run.sh 启停各服务。

  • 通过 ./run.sh start 一键启动 PostgreSQL、ClickHouse、PeerDB UI 及示例应用等容器服务
  • PeerDB 以 CDC 策略将 PostgreSQL 表数据近实时复制到 ClickHouse
  • pg_clickhouse 提供 ClickHouse 外部数据包装器，可导入外部 schema 并从 PostgreSQL 侧卸载分析查询

适用场景（解读层）

  • 已基于 PostgreSQL 的应用在数据量增长后需要承接仪表盘、报表等分析查询
  • 希望应用不改写代码、仍以 PostgreSQL 为唯一入口的情况下使用独立 OLAP 数据库
  • 需要完整示例环境来学习或演示 Postgres 到 ClickHouse 的 CDC 数据管道搭建
