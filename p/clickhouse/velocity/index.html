🧭 简介解读层（AI·证据行可回查）

基于 ClickHouse 公共 GitHub 事件数据集的团队活动可视化仪表板

综述（解读层）

该仪表板为单页应用，查询 ClickHouse 公共 GitHub 事件数据集，展示组织或仓库的评论、Issue、PR 等活动指标，支持多组织同时查询、双方对比模式及按日/周/月/季度聚合。面向需要查看 GitHub 团队活动数据的用户，使用 D3.js 渲染水平图，通过 URL hash 持久化状态。查询预过滤至前 1000 名贡献者并内置机器人账号过滤。

  • 支持评论、新建/关闭 Issue、提交/评审 PR 等多种 GitHub 活动指标，可同时查询多个组织或仓库并提供双方对比模式
  • 提供日/周/月/季度及自动聚合的时间分组，仪表板状态（指标、时间范围、过滤条件等）通过 URL hash 持久化以便分享
  • 前端为纯 HTML/CSS/JavaScript（ES6+），使用 D3.js v7 渲染 OKLCH 色彩空间的水平图，数据来自 ClickHouse Playground REST API

适用场景（解读层）

  • 查看特定组织或仓库在指定时间范围内的 GitHub 活动趋势
  • 将两个组织或仓库的活动数据在同一时间范围下并排对比
  • 点击登录名跳转 ClickHouse Playground 查看贡献者的具体活动明细
