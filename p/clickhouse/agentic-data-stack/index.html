🧭 简介解读层（AI·证据行可回查）

基于 Docker Compose 一键自托管的 ClickHouse 智能体数据分析栈

综述（解读层）

该项目通过 Docker Compose 将 LibreChat 聊天界面、ClickHouse MCP 服务器、Langfuse 观测平台及 ClickHouse 数据库整合为自托管环境，AI 智能体经 MCP 协议查询 ClickHouse 数据，全部 LLM 交互在 Langfuse 中留痕。适用于希望在本地部署对话式数据分析能力的团队。注意：文件搜索/RAG 功能需配置真实 embeddings API 密钥，user_provided 方式不适用。

  • 通过 MCP 服务器连接 LibreChat 与 ClickHouse，支持智能体查询分析数据
  • 提供 Langfuse 轨迹追踪、评估与提示词管理，支持本地或远程部署
  • 提供 Railway 一键部署模板与 prepare-demo.sh 交互式初始化脚本，支持 OpenAI/Anthropic/Google 多模型提供商

适用场景（解读层）

  • 自托管对话式数据分析环境
  • 为 LLM 应用建立本地可观测性与提示词管理
  • 基于公开 ClickHouse 演示集群快速体验智能体查询
