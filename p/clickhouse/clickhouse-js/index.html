ClickHouse 官方 JavaScript 客户端，基于 HTTP/Stream API 访问数据库。

综述（解读层）

该仓库是 ClickHouse 官方的 JS 客户端，纯 TypeScript 编写，无外部依赖，包含四个包：Node.js 版（支持查询与插入的双向流式传输）、Web 版（基于 Fetch，兼容浏览器与 Cloudflare workers）、共享公共库及 RowBinary 读取库。通过 npm 安装，可连接 ClickHouse Cloud 或自托管实例。客户端 1.12.0+ 要求 ClickHouse 24.8+。

  • 提供 Node.js 版与 Web 版两个客户端包，分别基于 HTTP/Stream 与 Fetch/Web Streams API 实现
  • Node.js 版支持查询与插入的双向流式传输，Web 版支持查询流式传输
  • 仓库另含 @clickhouse/client-common 公共库与 @clickhouse/rowbinary 二进制格式读取库，并提供 AI agent 排障技能安装方式

适用场景（解读层）

  • 在 Node.js 服务端应用中通过 HTTP 接口查询与写入 ClickHouse 数据
  • 在浏览器或 Cloudflare workers 中以 Fetch 方式查询 ClickHouse
  • 在 ClickHouse Cloud 或自托管部署中使用统一 JS 客户端接入
