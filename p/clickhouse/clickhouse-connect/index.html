连接 ClickHouse 与 Python 生态的数据库驱动库

综述（解读层）

clickhouse-connect 是 ClickHouse 官方的 Python 驱动，通过 HTTP 接口连接 ClickHouse Cloud 或自建实例，返回 Pandas、NumPy、PyArrow、Polars 数据结构。同时提供面向 Superset 的 SQLAlchemy 方言（clickhousedb://）及 Alembic 迁移支持。要求 Python 3.10+；SQLAlchemy 方言功能限于 Core 操作，不提供完整 ORM。1.0 版本相对 0.x 有破坏性变更。

  • 支持返回 Pandas、NumPy、PyArrow、Polars 数据格式，通过 HTTP 接口与 ClickHouse 通信
  • 提供 SQLAlchemy 方言，支持 SELECT/JOIN、轻量级 DELETE、物化 CTE 及 Alembic schema 迁移
  • 提供基于 aiohttp 的原生 async 客户端及实验性 chDB 内嵌引擎后端

适用场景（解读层）

  • 在 Python 数据分析流程中读取 ClickHouse 数据为 DataFrame/Arrow 表
  • 为 Apache Superset 接入 ClickHouse 数据源
  • 使用 Alembic 管理 ClickHouse 表结构迁移
