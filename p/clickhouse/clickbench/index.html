ClickBench：面向分析型数据库的可复现基准测试套件

综述（解读层）

ClickBench 是 ClickHouse 维护的分析型数据库基准项目，用于测试各类 OLAP/OLTP/NoSQL/云数据库在点击流与日志分析场景下的表现。数据集来自真实流量记录并匿名化，含约 1 亿条记录的单表和 43 条查询。测试以 shell 脚本半自动化运行，单次约 20 分钟起；README 亦列明单表模型、无并发负载等限制。

  • 数据集提供 CSV、TSV、JSONlines、Parquet 多种格式，约 9999.7 万条记录，查询负载为 43 条 SQL
  • 测试流程由 shell 脚本实现，覆盖安装、加载、查询与结果收集，结果以 JSON 提交并可自动生成网页
  • 覆盖自管理 OLAP、传统 OLTP、托管云数据库、serverless、NoSQL、文档库与时序库等系统类型

适用场景（解读层）

  • 评估数据库在临时分析与实时仪表盘查询负载下的加载时间、数据大小与查询耗时
  • 以标准化脚本在新机器（如 AWS EC2 多种型号）上复现测试或提交新系统的对比结果
  • 研究不同硬件配置（CPU 核数、存储吞吐、内存带宽）对分析查询的影响
