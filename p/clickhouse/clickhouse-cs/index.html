ClickHouse 官方 C# 客户端，含 HTTP/ADO.NET 与原生 TCP 两种实现

综述（解读层）

ClickHouse.Driver 是 ClickHouse 官方 NuGet 包，内含两个客户端：基于 RowBinary over HTTP 的 ClickHouseClient 及 ADO.NET 提供程序，以及实验性的原生 TCP 客户端 ClickHouseTcpClient。HTTP 客户端支持 Dapper、EF Core 等 ORM 和 CSV/JSONEachRow/Parquet 格式；TCP 客户端要求 .NET 8+，提供列式块读取与进度回调。两者支持最近 3 个版本加最近 2 个 LTS 的服务端。

  • 提供 HTTP 客户端（ClickHouseClient）及 ADO.NET 提供程序，兼容 Dapper、EF Core、linq2db 等 ORM
  • 提供实验性原生 TCP 客户端 ClickHouseTcpClient，支持列式块读取、进度/日志回调及 W3C trace 上下文传播
  • HTTP 客户端支持 CSV、JSONEachRow、Parquet 及原始流格式，以及 Bearer 认证和自定义 HTTP 头

适用场景（解读层）

  • 在 .NET 6+ 应用中通过 ADO.NET/ORM 读写 ClickHouse 数据库
  • 需要日志集成或框架集成的场景（提供 Serilog、EF Core、Aspire、Semantic Kernel 官方集成包）
  • 对读取吞吐有要求且可接受实验性 API 的 .NET 8+ 应用，可使用原生 TCP 客户端
