用于自学目的的文档数据库，Rust 编写，含 JS+SQL 混合脚本语言

综述（解读层）

LykiaDB 是一个以教学为目的构建的文档数据库管理系统，灵感来自《Crafting Interpreters》一书。它使用 100% 安全 Rust 编写，支持 ACID、磁盘与内存存储。查询语言是 JavaScript 与 SQL 的组合，作为独立模块可脱离数据库使用。项目尚未完成查询执行、事务与 MVCC 等部分，README 明确声明其非生产级。

  • 提供结合 JavaScript 与 SQL 的脚本/查询语言，该语言为独立模块，可脱离数据库单独使用
  • 支持磁盘与内存两种存储方式，存储采用 JSON 数据类型子集
  • 提供客户端/服务端应用、最小标准库，并按阶段列出字节码执行、Raft 复制等目标

适用场景（解读层）

  • 学习数据库与解释器实现原理的教育用途
  • 独立使用其脚本语言模块进行语言实验
  • 在本地通过 cargo 运行服务端与 shell 进行体验
