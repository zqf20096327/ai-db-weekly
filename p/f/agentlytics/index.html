🧭 简介解读层（AI·证据行可回查）

本地运行的 AI 编程助手会话分析面板，聚合多编辑器会话数据至 SQLite

综述（解读层）

Agentlytics 读取 Cursor、Claude Code、GitHub Copilot 等 17 种编辑器的本地会话记录，归一化存入 ~/.agentlytics/cache.db 的 SQLite 缓存，经 Express 只读 REST 接口供给 React 前端展示。提供 npx 一条命令启动，运行于 4637 端口，数据不出本机；Relay 功能可在团队内经 MCP 端点共享会话。要求 Node.js ≥20.19 或 ≥22.12，仅支持 macOS；Devin、Devin Next、Antigravity 需应用运行中才能扫描。

  • 支持 17 种 AI 编辑器的会话、消息、工具、模型数据读取，部分编辑器（如 Zed、Goose）不支持 token 统计
  • 提供仪表盘、成本估算、会话搜索、编辑器对比、订阅额度查看等页面，并暴露只读 REST API（支持 editor 过滤与 SSE 重新扫描）
  • Relay 模式（端口 4638）通过 --relay/--join 命令共享选定项目会话，每 30 秒同步，暴露 list_users、search_sessions 等 MCP 工具与 REST 端点

适用场景（解读层）

  • 集中查看和搜索散落在多个 AI 编辑器中的会话记录
  • 按模型、编辑器、项目、月份估算 AI token 花费
  • 团队在可信局域网内通过 MCP 查询彼此的编程会话历史
