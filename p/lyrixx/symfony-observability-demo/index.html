演示 Symfony 应用 Monolog 日志可观测性配置的示例项目

综述（解读层）

这是一个基于 Symfony 8.1 的演示应用，用于展示如何配置 Monolog 及配套的可观测性栈。所有日志记录发送到 Vector，再分发至 ClickHouse、Elasticsearch 和 Loki，分别通过 Redash、Kibana 和 Grafana 查看。项目提供 Docker 环境，需安装 Docker 与 Castor，首次运行前需配置 /etc/hosts 域名指向，通过 castor start 启动。运行时 Traefik 绑定 80/443 端口，使用自签名证书；Redash 需以预设账号登录。内置日志生成器可回填历史数据用于填充仪表盘。

  • 日志记录经 Vector 分发到 ClickHouse、Elasticsearch 和 Loki，分别以 Redash、Kibana、Grafana 查看
  • Docker 环境包含 nginx + PHP 8.5、PostgreSQL、Traefik 及带 Composer 与 QA 工具的 builder 容器
  • castor start 自动预置 Kibana、Grafana、Redash 仪表盘，并提供日志生成按钮可回填指定时间窗口的日志数据

适用场景（解读层）

  • 学习 Symfony 应用中 Monolog 与可观测性栈的配置方式
  • 本地运行包含 ClickHouse、Elasticsearch、Loki 三套日志后端的完整演示环境
  • 为演讲或培训演示日志采集与仪表盘（附带法语文档幻灯片）
