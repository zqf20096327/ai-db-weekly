内嵌 sing-box 的自托管代理控制面,单 Go 二进制加 SQLite,以线路统一管理入口与出口

综述（解读层）

m-ui 是一个面向自托管部署的代理面板,用单个 Go 二进制和 SQLite 数据库实现,内嵌 sing-box 数据面。项目以「线路」概念合并入口协议、端口与出口上游的配置,保存前对整份配置做干跑校验,失败自动回滚,支持一台主机管理多台副机并统一判定配额。目标用户为自行搭建和维护代理服务器的个人或运营者,依赖 Linux amd64/arm64 与 systemd,需 root 权限安装。

  • 单二进制 + SQLite 架构,内嵌面板、订阅服务、sing-box 数据面与后台任务四个组件,共用同一数据库文件
  • 配置保存前先经 sing-box 干跑校验,失败不落库;用户与上游改动热更新,线路改动重启数据面且新配置启动失败时自动回滚
  • 支持一主多副部署:主机推送配置并统一判定配额,副机仅转发;订阅按客户端自动输出通用链接、Clash、sing-box 三种格式

适用场景（解读层）

  • 自托管代理服务器管理:从单台服务器自用,到多台服务器的集中配置推送与用户配额统一判定
  • 面向多用户的订阅分发:通过订阅链接向客户端提供多格式节点配置、落地页与二维码
  • 对外运营场景:多服务器、套餐模板、代理分销面板与外部 API 对接商城或 Telegram 机器人
