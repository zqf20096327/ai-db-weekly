MySQL 到达梦 DM8 的表结构与数据迁移工具，单 jar 运行

综述（解读层）

MySql2Dm 是一个将 MySQL 5.7/8.0/MariaDB 表结构、数据和视图迁移到达梦 DM8 的 Java 命令行工具，MIT 协议。它以双引号包裹标识符保留原始大小写，强制要求目标库 CASE_SENSITIVE=Y；迁移按建表→装载数据→索引/外键三阶段执行，完成后逐表校验行数。函数、存储过程、触发器不迁移。需 Java 8 及以上，内置 JDBC 驱动，无需安装数据库客户端。

  • 所有 DDL/DML 用双引号包裹标识符，迁移后保留 MySQL 原始表名/字段名大小写，并自动检测目标库 CASE_SENSITIVE()，不敏感时终止
  • 内置 40+ 类型映射断言，处理 unsigned 扩宽、enum/set/json 转换、AUTO_INCREMENT 转 IDENTITY；支持 --dry-run 模拟运行和迁移后行数校验
  • MySQL 侧流式游标读取、达梦侧批量写入，坏行时打印字段级诊断（列名/类型/值预览/字节长度），支持 --onInsertError=continue 跳过计数

适用场景（解读层）

  • 需要将 MySQL 数据库整体或按表迁移到达梦 DM8（大小写敏感库）的场景
  • 迁移前用 --dry-run 预览将生成的 DDL 和行数、仅迁移表结构（--mode=structure）等分步操作
  • 源表含 enum/set/json/unsigned/自增主键等类型，或含视图需要基础方言改写（改写失败的语句输出到日志人工修正）的场景
