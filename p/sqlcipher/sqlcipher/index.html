SQLite 独立分支，为数据库文件提供 256 位 AES 加密

综述（解读层）

SQLCipher 是 SQLite 的独立分支，由 Zetetic 维护，为数据库文件提供 256 位 AES 加密，包含实时加密、防篡改检测、内存清理和 PBKDF2 密钥派生。通过 PRAGMA key 提供口令或 256 位密钥，支持 rekey 更换。适用于需要在应用层加密本地数据库文件的开发者。主要版本间默认格式不兼容，需迁移或启用兼容模式。

  • 对数据库文件全部数据实现 256 位 AES 实时加密，支持 CBC 模式、HMAC 与 PBKDF2 密钥派生
  • 支持多种加密提供者（OpenSSL、LibTomCrypt、CommonCrypto/Security.framework、NSS），未提供密钥时行为与标准 SQLite 相同
  • 提供 PRAGMA key / rekey 及 sqlite3_key / sqlite3_rekey 接口，可用 sqlcipher_export() 将明文库转换为加密库

适用场景（解读层）

  • 需要加密本地 SQLite 数据库文件的应用（移动端或桌面端）
  • 需要将现有明文 SQLite 数据库转换为加密数据库的场景
  • 需要更换数据库加密密钥或使用二进制密钥的应用
