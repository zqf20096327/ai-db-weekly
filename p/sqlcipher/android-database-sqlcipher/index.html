基于 SQLCipher 的 Android SQLite 加密数据库接口库

综述（解读层）

该库为 Android 平台提供基于 SQLCipher 的加密 SQLite 数据库访问接口，面向需要在本地存储中启用加密的 Android 应用开发者。它兼容 Android 5.0（API 21）及以上，支持四种 CPU 架构；可通过 SupportFactory 接入 Room 或 androidx.sqlite API，也可通过替换包名方式迁移原生 SQLiteDatabase 代码。注意：该项目已官方弃用，建议迁移至继任项目 sqlcipher-android。

  • 提供 SupportFactory 类，可用于配置 Room 及其他 androidx.sqlite API 消费方使用 SQLCipher
  • 提供与 android.database.sqlite 类名对应的 net.sqlcipher.database 原生 API，迁移只需替换 import 并传入口令
  • 支持 Android 5.0（API 21）及以上，覆盖 armeabi-v7a、x86、x86_64、arm64_v8a 四种架构

适用场景（解读层）

  • 已有 Room 应用的 Android 项目需要接入加密 SQLite
  • 使用 SQLiteDatabase/SQLiteOpenHelper 的现有代码需转为加密数据库访问
  • 需要从源码构建包含加密支持的 Android SQLite 库的项目
