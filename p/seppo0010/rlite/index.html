嵌入式零配置、兼容 Redis 命令的单文件数据库引擎

综述（解读层）

rlite 是一个自包含、免配置、支持事务的嵌入式数据库引擎，提供与 Redis 兼容的命令接口，数据存储在单个文件中，也支持 ':memory:' 内存模式。通过 C API（hirlite.h）或九种语言的绑定接入，可嵌入移动应用、开发与测试环境，或以 rlite-server 作为 Redis 主实例的 slave 运行。无依赖，直接 make all 编译。

  • 实现 string、list、set、zset、hash、key 管理、事务（multi/exec）、Lua 脚本（eval）及 pubsub 等命令
  • 数据以自有格式存储于单个文件，支持 write ahead log 和多进程安全访问
  • 提供 C API 和 Ruby、Go、Java、Node.js、PHP、Python、R、Rust 等语言绑定，附带 rlite-cli 命令行工具与 rlite-server

适用场景（解读层）

  • 移动应用或命令行程序的本地数据存储
  • 开发与测试环境中替代 Redis，简化 CI 栈与 fixture 分发
  • 作为 Redis 主实例的 slave 进行数据持久化备选方案
