基于 Janet 语言的全栈 Web 框架，以函数和 CLI 驱动开发

综述（解读层）

Joy 是用 Janet 语言编写的全栈 Web 框架，通过 joy 命令行工具生成项目、数据库迁移和路由控制器，使用 SQLite 存储数据。README 明确其不含 ORM、类和对象，仅由接收请求并返回响应的函数构成路由，适合习惯函数式风格的 Janet 开发者。框架提供 Dockerfile 便于容器中运行。

  • 提供 joy CLI，支持生成项目、创建 SQLite 数据库与表迁移、生成控制器路由
  • 路由由接收请求并返回响应的函数实现，不包含 ORM、类或对象
  • 提供 Dockerfile，可在容器中挂载代码运行，无需本地安装

适用场景（解读层）

  • 使用 Janet 语言开发 Web 应用
  • 基于 SQLite 的中小型网站后端开发
  • 在 Docker 容器或资源受限的 VPS 上运行 Web 服务
