🧭 简介解读层（AI·证据行可回查）

Janet 语言的数据库库，提供 CLI 迁移工具与 CRUD/查询 API，支持 SQLite 与 Postgres。

综述（解读层）

db 是面向 Janet 语言的数据库库，通过 jpm 安装，依赖 janet-pq 或 sqlite3 作为驱动。它提供名为 db 的命令行工具用于创建数据库、生成迁移文件、执行 migrate/rollback，连接串从环境变量 DATABASE_URL 读取；库内提供 insert/update/delete/find/fetch/from 等操作，from 与 find-by 支持 :join/one、:join/many 等选项。仅支持 SQLite 与 Postgres 两种数据库，部分功能未写入文档，需查看测试代码了解。

  • 提供 CLI 工具 db，用于创建数据库、生成迁移 SQL 文件及执行 migrate/rollback
  • 支持按主键查询（find/fetch）、外键作用域（fetch-all）以及带 :where/:limit/:order/:offset/:join 选项的 from 查询
  • 通过 DATABASE_URL 环境变量自动选择 postgres 或默认 sqlite3 驱动

适用场景（解读层）

  • Janet 项目中的数据库迁移管理与建表流程自动化
  • 以 Janet 结构体方式对 SQLite 或 Postgres 表执行增删改查
  • 需要通过外键作用域或 join 选项查询关联数据的场景
