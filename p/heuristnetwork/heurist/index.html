面向人文研究者的 Web 数据库自建与发布系统，基于 PHP/MySQL。

综述（解读层）

Heurist 是一个基于 PHP、JavaScript 和 MySQL 的 Web 数据管理系统，面向人文研究者，可通过 Web 界面设计、创建、管理、分析和发布结构化数据库，无需编程人员。项目 2005 年起源于悉尼大学，2024 年起由巴黎的非营利组织 Heurist Network 维护。数据库结构可在运行中增量修改；安装推荐使用 /var/www/html/HEURIST 目录，并需配置 heuristConfigIni.php；支持 Docker Compose 本地部署，最新代码位于 h7dev 分支。

  • 支持在运行中的数据库上增量修改结构，并保持子版本间数据库格式的向后与向前兼容
  • 提供导入（Zotero 同步、CSV/TSV）与导出（JSON、XML/HML、KML、备份）工具，以及基于 Leaflet 的地图、时间线、交叉表和网络图等查看器
  • 版本 6 提供外键与关系指针字段、多级分面检索、向导式网络扩展规则、交互式地图与时间线，以及内嵌数据库内容的 CMS 网站

适用场景（解读层）

  • 人文领域研究者自建并发布结构化数据库（如考古、历史资料管理）
  • 需要将地图、时间线、图表与保存的检索嵌入网站发布的项目
  • 机构或个人自托管运行 Heurist 实例，或使用澳大利亚与法国提供的免费托管服务
