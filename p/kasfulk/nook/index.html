基于 Rust 的 SQLite/PostgreSQL/MySQL 数据库工作台，含桌面应用、CLI 与 MCP server

综述（解读层）

Nook 是一个用 Rust 编写的数据库管理工作台，支持 SQLite、PostgreSQL 和 MySQL/MariaDB，提供 egui 桌面应用、命令行工具和 MCP server 三种入口，所有操作共享同一套命令注册表。功能包含数据表格编辑、SQL 编辑器、跨引擎数据传输、同步、备份、调度任务、ER 图和测试数据生成。本地运行，无需浏览器或账户。安装需 Rust 1.95+，可选依赖 ssh 与 pg_dump/mysqldump。

  • 支持 SQLite、PostgreSQL、MySQL/MariaDB 连接，可通过系统 ssh 建立隧道，密码存于操作系统钥匙串
  • 桌面应用、CLI 与 MCP server（stdio）共享同一命令注册表，每个命令在三个入口均可调用
  • 包含数据网格编辑、查询编辑器、跨引擎表复制、按主键的行级同步、备份恢复、定时任务、ER 图与 CSV/JSON 导入导出

适用场景（解读层）

  • 在本地桌面环境中浏览和编辑多引擎数据库的表结构与数据
  • 通过脚本化 CLI 命令执行查询、导出备份等批量操作
  • 将 MCP server 接入 AI 代理，让代理调用与人工相同的数据库命令
