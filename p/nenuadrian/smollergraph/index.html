从零用 C++ 实现的小型图数据库，含存储引擎与 Cypher 查询

综述（解读层）

smollerGraph 是一个用 C++20 从零实现的图数据库，配套 YouTube 系列逐集构建，每个步骤对应仓库中的一个 tag。它以 4 KiB 页和缓冲池管理固定大小记录，用 B+ 树按名称定位节点，支持 Cypher 子集查询、双向最短/最廉价路径、FastRP 嵌入与 HTTP 可视化界面。附 Wikidata 哺乳动物与鸟类数据集，采用 MIT 许可证。

  • 以 4 KiB 页、缓冲池、B+ 树索引和属性记录链组织磁盘存储；关系以出边和入边两条链存放，可双向遍历
  • 支持 Cypher 子集查询（含 WHERE/RETURN/EXPLAIN），实现双向 BFS 最短路径与基于权重的 Dijkstra 最廉价路径
  • 通过 FastRP 为节点生成 256 维嵌入，sg similar 按余弦相似度输出相近节点，sg serve 提供 HTTP 页面绘制查询结果

适用场景（解读层）

  • 学习图数据库存储引擎与查询计划的实现细节，按视频 tag 逐步阅读代码
  • 加载 Wikidata 分类等事实数据，执行标签/属性匹配、多跳关系遍历与路径查询
  • 在浏览器中可视化图结构与节点磁盘记录，运行嵌入相似度查询
