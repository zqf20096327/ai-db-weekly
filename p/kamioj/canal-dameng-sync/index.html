基于 Canal 1.1.8 的 MySQL 到达梦数据库全量与增量实时同步工具

综述（解读层）

该项目基于 Canal 1.1.8 订阅 MySQL binlog，将表结构（DDL）和数据变更（INSERT/UPDATE/DELETE）同步到国产达梦数据库 8.x，支持全量迁移、增量同步、断点续传及多表并行处理。适用对象为需将 MySQL 数据迁往达梦数据库的用户。限制：UPDATE/DELETE 依赖主键，复杂 DDL 转换可能需手动调整，仅支持单库对单库模式。

  • 基于 Canal 订阅 binlog，解析 INSERT/UPDATE/DELETE 事件并执行达梦侧 DML，定期保存检查点实现断点续传
  • 读取 MySQL CREATE TABLE 语句并转换为达梦 DDL，分批迁移表数据，支持可配置的多表并行同步
  • 支持环境变量/配置文件/默认值三级配置，提供 Docker Compose 部署方式和按天滚动的错误日志文件

适用场景（解读层）

  • 将 MySQL 库的表结构与存量数据全量迁移到国产达梦数据库
  • 通过 binlog 实时捕获源库增删改变更，保持达梦侧数据同步
  • 借助检查点机制在服务重启后从上次 binlog 位置继续同步
