将 PostgreSQL 全文检索暴露给 ActiveRecord 的 Ruby gem

综述（解读层）

Textacular 是一个 Ruby gem，为 ActiveRecord 模型提供基于 PostgreSQL 的全文检索方法，面向 Rails 或独立使用 ActiveRecord 的开发者。它提供 basic_search、advanced_search、web_search 和 fuzzy_search（依赖 pg_trgm 扩展）四类搜索，方法可链式调用，并支持通过迁移声明 GIN/GiST 索引。限制：仅支持 PostgreSQL，且与修改 SELECT 语句的操作（如 pluck）可能冲突。

  • 提供 basic_search、advanced_search、web_search、fuzzy_search 四种搜索方法，支持链式调用
  • 可通过迁移为文本列声明 GIN/GiST 全文索引；模糊搜索需安装 pg_trgm 扩展
  • 支持自定义搜索语言字典和可搜索列范围

适用场景（解读层）

  • 在 Rails 或 ActiveRecord 项目中实现 PostgreSQL 全文/模糊文本搜索
  • 为用户提供带 OR/AND/NOT 语法的搜索接口
  • 需要按相似度阈值进行近似字符串匹配的查询场景
