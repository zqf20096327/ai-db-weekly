跨平台 SQL 编辑器与数据库管理客户端，基于 Electron 与 Vue.js 构建

综述（解读层）

Beekeeper Studio 是一个可运行于 Linux、Mac 和 Windows 的 SQL 编辑器和数据库管理器，支持 PostgreSQL、MySQL、SQLite、SQL Server、ClickHouse 等多种数据库。项目采用开源（GPLv3）加商业源码许可的双轨模式，部分数据库（如 Oracle、MongoDB）的支持仅包含在付费版中。代码为 monorepo 结构，核心应用位于 apps/studio，由 Electron 后台进程与 Vue.js 前端两部分组成。

  • 提供带自动补全和语法高亮的 SQL 查询编辑器，支持多标签界面与查询保存、运行历史记录
  • 支持数据的排序、筛选、JSON 格式查看，以及导入/导出和备份/恢复功能
  • 发布 MacOS、Windows 和 Linux 三个平台的安装包，支持 PostgreSQL、MySQL、Redis、BigQuery 等多种数据库连接

适用场景（解读层）

  • 开发或运维人员需要图形界面连接并管理多种数据库（如 MySQL、PostgreSQL、ClickHouse）
  • 需要编写、保存和回溯 SQL 查询的日常工作场景，利用自动补全与查询历史
  • 需要在 Windows、Mac、Linux 多平台上使用同一款数据库客户端的团队环境
