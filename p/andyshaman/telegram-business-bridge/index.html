🧭 简介解读层（AI·证据行可回查）

通过 Telegram 官方 Business API 将 AI 代理接入个人私聊的 MCP 服务器

综述（解读层）

该项目是一个常驻守护进程，通过官方 Telegram Business API（普通免费账号即可，无需 Premium）将个人私聊消息实时存入本地 SQLite/FTS5 归档，并向任意 MCP 客户端提供 9 个工具用于读取历史、全文搜索和起草回复。每条回复默认需用户在 Telegram 中点击 ✅ 确认后才发送。限制：仅覆盖私聊，群组和频道不可见；归档从接入时开始累积；MCP 服务器无认证，仅限本地使用。

  • 提供 9 个 MCP 工具：list_chats、get_history、search_messages、get_context、read_media、draft_reply、send_reply、list_drafts、list_recent_edits
  • 回复默认采用草稿审批卡（✅ 发送 / ✏️ 编辑 / 🔕 暂停），消息内容以 UNTRUSTED 标记包装以隔离提示注入
  • read_media 可将归档图片、文本/PDF、语音/视频返回为图像、文本或转录内容；语音转录依赖可选的 Deepgram API key

适用场景（解读层）

  • 为接入 MCP 的 AI 代理（如 Claude Code）提供个人 Telegram 私聊的长期记忆与上下文检索
  • 让代理起草回复并由用户逐条审批后发送，避免代理直接以本人身份发消息
  • 部署 Docker/systemd 守护进程，从接入时刻起永久保存私聊消息并支持全文搜索
