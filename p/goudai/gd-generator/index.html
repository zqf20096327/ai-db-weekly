🧭 简介解读层（AI·证据行可回查）

以实体类为主导、生成 MyBatis Mapper 与 XML 的代码生成器

综述（解读层）

gd-generator 是一个基于 Java 实体类的代码生成器，通过解析 JPA 注解生成 MyBatis 的 Mapper 接口与 XML 配置、QueryModel 及 VO 对象，并可依据实体类自动建表、加索引、更新列，在实体变更时打印修复 SQL 并保留用户自定义的 XML 语句。适合使用 MyBatis 或从 Hibernate/JPA 迁移到 MyBatis 的 Java 开发者。部分 MySQL 字段特性（如 NOT NULL、默认值）需启用 AllMappingMysqlHandler 并设置 mappingAll 为 true。

  • 解析 JPA 注解，生成 MyBatis Mapper 接口、XML 配置文件与 QueryModel
  • 根据实体类自动创建表、添加索引、更新数据列，并输出实体与数据库差异的修复 SQL
  • 通过 @ViewObject、@View、@AssociationView、@CollectionView、@MapView 注解生成 VO 对象

适用场景（解读层）

  • 以实体类为源头维护 MyBatis Mapper 与 XML 配置
  • 从 Hibernate/JPA 项目迁移到 MyBatis
  • 开发过程中随实体类变更同步 MySQL 表结构并获取修复 SQL
📖 README 首段存档原文 · 程序抽取

* 基于实体类为主导的代码生成器，可基于实体类快速的生成mybatis的相关配置。 如生成接口mapper,生成xml配置文件。 * 可通过实体类在生成自动建表，自动加索引,自动更新数据列。 * 可检测出数据库与实体类之间的差异并在日志中打印出对应警告或者修复用的sql语句。 如 warn : 数据库中的列 [mysql_name --> mysqlName] 在实体类 Admin 不存在;
