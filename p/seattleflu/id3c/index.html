基于 PostgreSQL 的传染病病原体基因组监测数据物流系统

综述（解读层）

ID3C 是西雅图流感研究项目使用的传染病数据分发中心，数据库按 receiving（接收日志）、warehouse（仓库）、shipping（分发视图）三个 PostgreSQL schema 组织，ETL 流程以 Python 实现、经 bin/id3c etl 子命令运行，并配有 Flask Web API 与 click CLI。部署使用 Sqitch 管理数据库变更，依赖 Pipenv 管理依赖，需自行准备 PostgreSQL 15 服务器。

  • 数据库按 receiving/warehouse/shipping 三个 schema 组织，仓库采用关系表加 JSON 列的混合模型，支持地理空间等数据类型，并提供基于行/列级访问控制的角色认证与静态加密、仅 TLS 连接
  • 提供 Python CLI（id3c 命令）用于生成标识符与条形码、运行 ETL 例程、解析与上传样本清单、发送 Slack 通知；Web API 基于 Python 3 + Flask，接收并存储来自 Audere 系统的注册文档
  • 数据库模式用 Sqitch 部署，术语参照 FHIR R4 资源命名，词汇可引用 SNOMED CT、LOINC、GenEpiO 本体；测试与生产环境通过 sqitch target 与 libpq 环境变量配置连接

适用场景（解读层）

  • 流感、RSV 等呼吸道病原体的实时基因组流行病学监测数据汇集与分发
  • 向发病率建模团队等数据消费方提供面向特定用途的数据库视图
  • 参与者的去标识化元数据与样本诊断结果、测序读组及基因组组装（以 URL 引用云端存储）的集中管理
