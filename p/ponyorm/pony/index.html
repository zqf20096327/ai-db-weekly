Pony ORM：用 Python 生成器表达式写数据库查询的对象关系映射库

综述（解读层）

Pony 是一个 Python 对象关系映射库，核心机制是解析生成器表达式与 lambda 的抽象语法树并翻译成对应数据库方言的 SQL。它支持 SQLite、MySQL、PostgreSQL、Oracle 数据库，面向希望用 Pythonic API 进行应用开发的开发者。项目采用 Apache 2.0 许可证发布。

  • 通过生成器表达式和 lambda 编写查询，将表达式 AST 翻译为 SQL
  • 支持 SQLite、MySQL、PostgreSQL 和 Oracle 四种数据库
  • 提供可在线创建数据库图并生成 schema 的 ER 图编辑器

适用场景（解读层）

  • 在 Python 应用中以生成器表达式方式编写数据库查询
  • 需要同时适配多种关系型数据库的应用开发
  • 通过在线 ER 图编辑器进行数据库原型设计与 schema 生成
