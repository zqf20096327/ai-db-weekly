🧭 简介解读层（AI·证据行可回查）

基于 C++ 与 Qt 的全栈 MVC Web 应用框架

  • 支持 MySQL、PostgreSQL、ODBC、SQLite、MongoDB、Redis 等多种数据库
  • 内置 O/R 映射系统与 ERB 风格模板引擎，可自动生成脚手架和 Makefile
  • 支持 HTTP 与 WebSocket 协议，提供 JSON、XML、CBOR 响应类型

适用场景（解读层）

  • 需要用 C++ 开发多平台 Web 应用程序的项目
  • 需要 WebSocket 全双工通信的应用
  • 需访问 MySQL、PostgreSQL、MongoDB 等多种数据库的 MVC Web 应用
