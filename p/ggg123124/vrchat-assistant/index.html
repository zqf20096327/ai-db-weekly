🧭 简介解读层（AI·证据行可回查）

自托管 VRChat 好友动态监控服务，通过 WebSocket 采集数据并以 MCP 接口供 AI Agent 调用。

综述（解读层）

该项目是一个基于 Node.js 与 SQLite 的常驻后台服务，通过 WebSocket 实时采集 VRChat 好友的上下线、进房、换 Avatar 等事件并存入本地数据库，再以 MCP 接口暴露给 AI Agent（如 Hermes）调用。适用于希望由 AI Agent 代为执行好友查询、社交互动、媒体管理等操作的 VRChat 用户。需自行提供 VRChat 账号并配置邮箱 OTP（IMAP）或 TOTP 登录，要求 Node.js ≥ 22。

  • 通过 WebSocket 实时采集好友上下线、进房、换 Avatar、状态变化事件，存入本地 SQLite（WAL 模式）数据库，支持断线自动重连与 cookie 过期自动 OTP/TOTP 登录
  • 通过 MCP 接口暴露核心域工具与官方插件域工具（auth-guard、booth、events、media、groups、recommend 等），并提供 skills/ 目录下的 Agent Skill 合集
  • 支持 VRCX 历史数据迁移、一周游戏周报生成、数据库 24h WAL 在线备份，提供 Windows 开机自启与 Linux systemd 服务脚本

适用场景（解读层）

  • 让 AI Agent（如 Hermes）代为查询好友在线状态、发送邀请/好友请求、管理相册与群组等社交操作
  • 长期记录好友上下线与进房历史，生成一周游戏报告与上线规律分析
  • 通过 VRCX 迁移脚本将既有历史数据导入本服务的本地数据库
