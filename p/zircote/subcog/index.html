🧭 简介解读层（AI·证据行可回查）

面向 AI 编程助手的持久化记忆系统，用 SQLite+FTS5+HNSW 三层存储与混合检索实现会话记忆沉淀。

综述（解读层）

Subcog 是一个用 Rust 编写的持久化记忆系统，用于为 AI 编程助手捕获编码会话中的决策、经验与上下文，并在相关时提供检索。它提供 CLI 与 MCP 服务器两种接入方式，包含 Claude Code 插件与 5 类 hooks 集成，暴露约 22 个 MCP 工具，支持 project/branch/file_path 多维过滤、10 种记忆命名空间、密钥与 PII 过滤、静态加密及 GDPR 导出。存储为 SQLite/FTS5/usearch 三层架构，持久层可切换 PostgreSQL 或文件系统。安装支持 cargo、Homebrew、Docker、npm 等方式。

  • 混合检索：BM25 全文搜索（FTS5）与向量相似度（all-MiniLM-L6-v2, 384 维，usearch HNSW）经 RRF 融合，输出 0.0-1.0 归一化分数
  • 以 MCP 服务器（stdio/HTTP+JWT 两种传输模式）运行，提供约 22 个工具；作为 Claude Code 插件集成全部 5 个 hooks
  • 知识图谱功能含实体抽取与关系推断；支持分支垃圾回收、嵌入迁移、OpenTelemetry 可观测性与审计日志

适用场景（解读层）

  • 在 Claude Desktop 或其他 MCP 客户端中为 AI 编程会话提供本地持久化记忆与上下文注入（SessionStart hook 等）
  • 按项目、分支、文件路径维度检索团队或个人的历史决策、模式与阻塞记录
  • 在团队/远程部署场景下通过 HTTP 传输（JWT 认证）提供网络可访问的记忆服务
