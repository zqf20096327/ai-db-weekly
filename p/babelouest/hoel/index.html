C 语言数据库抽象库，用基于 JSON 的查询语言操作 SQLite3/MariaDB/PostgreSQL

综述（解读层）

Hoel 是用 C 编写的数据库抽象库，支持 SQLite3、MariaDB 和 PostgreSQL 三种后端，依赖 jansson 库以 JSON 对象描述针对单表的简单查询，也提供 h_execute_query 执行原生 SQL。安装支持 CMake（3.5+）和 Makefile 两种方式，可按需编译开关禁用不需要的数据库后端。适用于需要在 C 程序中以统一 API 访问多种关系数据库的后端开发场景；结果以 struct _h_data 二维数组返回，需手动调用 h_free 等函数清理内存。

  • 支持 SQLite3、MariaDB、PostgreSQL 三种数据库后端，可通过编译选项按需启用或禁用
  • 提供基于 JSON（jansson）的简单查询语言，以及 h_execute_query 执行原生 SQL、h_build_where_clause 构建复杂 where 子句（Beta）
  • 查询结果以 struct _h_result/struct _h_data 结构返回，支持 INT、DOUBLE、TEXT、DATE、BLOB、NULL 六种列类型

适用场景（解读层）

  • C/C++ 后端程序需要以统一 API 访问 SQLite3、MariaDB 或 PostgreSQL 数据库
  • 需要用 JSON 对象描述单表的增删改查等简单查询
  • 需要执行原生 SQL 并处理结构化查询结果的 C 项目
