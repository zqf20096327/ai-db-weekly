Nim 编写的多模态数据库引擎，单引擎支持文档、图、向量等存储与统一查询语言。

综述（解读层）

BaraDB 是用 Nim 编写的多模态数据库引擎，将文档、图、向量、列式与全文检索存储整合在单一引擎中，通过 BaraQL 查询语言访问，编译为无运行时依赖的单个 3.3MB 二进制文件。它面向需要在同一引擎内混合使用多种数据模型与检索方式的开发者，提供二进制协议、HTTP/REST、WebSocket 和嵌入式接入方式；README 注明部分边缘场景仍有待改进项。

  • 提供 LSM-Tree、B-Tree、HNSW/IVF-PQ 向量索引、邻接表图引擎等多种存储引擎，包含 WAL、布隆过滤器与 LR 页缓存等组件
  • 实现部分 SQL:2023 覆盖的 BaraQL，支持 JOIN、CTE、子查询、JSON/JSONB、全文检索、VECTOR 类型与 hybrid_search 等 SQL 函数
  • 内置 BFS、DFS、Dijkstra、PageRank、Louvain 等图算法，支持 CREATE GRAPH、GRAPH_TABLE() 与 Cypher 函数转换；核心分布式算法附有 TLA+ 规范与 TLC 模型检查脚本

适用场景（解读层）

  • 需要在单一引擎中同时存储和查询文档、关系、图与向量数据的应用
  • 构建 RAG 流程：文本分块、外部 API 嵌入生成、向量+BM25 混合检索与 RRF 重排
  • 以嵌入式模式（类似 SQLite）运行，或通过 REST/WebSocket/二进制协议作为服务端数据库接入
