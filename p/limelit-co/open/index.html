🧭 简介解读层（AI·证据行可回查）

自托管 AI 可见性追踪工具，用单二进制加 SQLite 测量 AI 引擎对品牌的提及与引用。

综述（解读层）

Limelit Open 是 Limelit 的开源核心，运行在自有基础设施上，追踪 ChatGPT、Claude、Perplexity、Gemini、Google AI Overview 等七个引擎对品牌及竞品的提及与引用，并将引用来源分类。指标通过文本搜索匹配与存储行计算，可复算；经 API 获取的引擎答案与爬取的消费端界面在指标上分别标注。数据存于单个 SQLite 文件，通过 limelit export 导出 JSON 或 CSV。项目处于 pre-release 状态，11 个提供商中 6 个已实现。

  • 单二进制运行，启动时自建并迁移 SQLite 数据库，仪表盘内嵌于二进制，服务地址 localhost:1515，支持 curl 下载、go install 和 Docker 三种安装方式
  • 覆盖七个引擎：ChatGPT、Claude、Perplexity、Gemini 走厂商 API（开启 web search），Google AI Overview、Google AI Mode、Bing Copilot 通过爬虫获取，11 个提供商已实现 6 个
  • 内置 MCP 服务器（stdio 或带 bearer token 的 streamable HTTP），提供 14 个只读工具，与 Limelit Cloud 使用相同的工具名称、引擎 ID 和指标定义，另有按日或按小时的调度执行及 runs_per_day 硬性上限

适用场景（解读层）

  • 在自有基础设施上持续测量品牌与竞品在多个 AI 引擎答案中的提及频率、平均位置与引用来源
  • 通过 MCP 服务器让 Claude Code、Claude Desktop 等 MCP 客户端以对话方式读取可见性数据
  • 使用 limelit export 将全部实例数据导出为 JSON 或 CSV，或通过 --key 将数据上传至 Limelit Cloud 工作区
