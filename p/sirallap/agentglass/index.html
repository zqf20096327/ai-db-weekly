🧭 简介解读层（AI·证据行可回查）

本地桌面工作台，将多个 AI 编码代理的终端、审批与 PR 汇聚于一窗

综述（解读层）

agentglass 是一款 Electron 桌面应用，附加到本机 tmux 会话，统一管理 Claude Code、Codex、Gemini CLI、OpenCode 等代理的终端、diff、PR 与权限审批，并配 Android 配套应用远程查看和批准。数据存于本地 SQLite，无账户无遥测；orchestrator 策略是限制而非沙箱，README 建议先读 SECURITY.md。

  • 附加 tmux 中已运行的代理会话，或从任务/GitHub issue 创建 worktree、分支并启动代理
  • Lantern 视图以颜色标记等待权限或等待输入的代理，审批队列落盘，可从桌面或手机批准
  • 内置 diff 查看器、PR 审阅面板、可由代理经 CLI 和 MCP 驱动的浏览器，以及 Docker/端口/CPU/成本监控视图

适用场景（解读层）

  • 同时运行多个编码代理，需集中查看成本、token 与工具调用
  • 代理触发敏感工具调用时需人工批准，包括离开工位后经手机批准
  • 本地开发环境中以 orchestrator-worker 策略分派任务并限制 worker 权限
