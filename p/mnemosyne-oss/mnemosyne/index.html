🧭 简介解读层（AI·证据行可回查）

基于 SQLite 的本地优先 AI 代理记忆层，提供 remember/recall 接口与 MCP 服务

综述（解读层）

Mnemosyne 是一个面向 AI 代理的记忆层，数据存储于单个 SQLite 文件，通过 pip 安装即可使用，无外部服务依赖。它以 MCP 服务器和 Python SDK 两种方式接入，支持 Cursor、Claude Code 等客户端。架构上包含工作记忆、情景记忆（sqlite-vec + FTS5 混合检索）和 TripleStore 时序知识图；向量采用二值化压缩存于 SQLite。注意：若启用远程 embedding，记忆文本会发送到 API 端点。

  • 提供 remember/recall Python API 与内置 MCP 服务器（stdio/SSE 传输），支持 Cursor、Claude Code、Codex、OpenWebUI 等多平台接入
  • 记忆分三层：TTL 驱动的工作记忆、sqlite-vec + FTS5 混合检索的情景记忆、带版本链的 TripleStore 时序知识图
  • 384 维向量经二值化压缩为 48 字节，Hamming 距离检索全部在 SQLite 内完成，不依赖外部向量数据库

适用场景（解读层）

  • 为运行在本地环境中的 AI 代理（Claude Code、Cursor、自定义 Python 代理等）持久化与检索会话记忆
  • 需要自托管、无遥测且可选客户端加密同步的个人或桌面场景
  • 通过 MCP 协议为任意 MCP 客户端一键接入记忆服务的集成开发
