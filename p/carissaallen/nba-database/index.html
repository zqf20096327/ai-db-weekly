基于 PostgreSQL 的 NBA 2017-18 赛季统计数据库实现项目

综述（解读层）

该项目将 2017-2018 NBA 赛季的球队、教练、球员统计等数据导入 PostgreSQL 关系数据库，包含 CSV 数据文件、建表语句、ER 图与示例 SQL 查询，属于数据库课程作业性质的实现。适合学习数据库设计流程的人参考，数据源为 Basketball Reference 与 NBA 官方等，仅覆盖该赛季数据。

  • 提供 ER 图与含主键、外键的关系模式
  • 仓库包含 Coach_Stats、Coaches 等 CSV 数据文件
  • 包含 20 个英文问题的 SQL 查询翻译及执行结果

适用场景（解读层）

  • 学习数据库课程设计（ER 图、关系模式、建表）的完整流程示例
  • 参考如何从公开数据源获取 CSV 并导入 PostgreSQL
  • 查阅 2017-2018 NBA 赛季的球队、教练统计数据的 SQL 查询示例
