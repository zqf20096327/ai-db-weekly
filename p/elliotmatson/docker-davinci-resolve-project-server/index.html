🧭 简介解读层（AI·证据行可回查）

基于 Docker 的 DaVinci Resolve 项目服务器，内置定时备份与 PGAdmin。

综述（解读层）

该项目用 docker-compose 部署 DaVinci Resolve 的 PostgreSQL 项目服务器，包含定时备份与 PGAdmin 管理组件，面向无 IT 团队的小型团队。默认镜像为 PostgreSQL 13（对应 Resolve 18-20），可通过修改 compose 文件切换至 9.5 或 11 以兼容旧版 Resolve；备份文件采用 Resolve 标准 *.backup 格式。

  • 自动备份按 cron 计划执行，支持按日/周/月保留策略清理旧备份
  • 备份文件使用 Resolve 标准 *.backup 语法，可从 Resolve UI 直接恢复
  • 支持配置 PostgreSQL 13、11 或 9.5 镜像以匹配不同 Resolve 版本

适用场景（解读层）

  • 为小型团队部署 Resolve 多人协作项目服务器
  • 在 QNAP/Synology NAS 或 Linux 主机上运行项目数据库
  • 需要为旧版 Resolve（17 及以下）搭建 PostgreSQL 11/9.5 服务器
