🧭 简介解读层（AI·证据行可回查）

读取 MySQL/MariaDB 数据库结构生成 Go 数据库交互代码的命令行工具

综述（解读层）

Modelgen 是一个用 Go 编写的命令行工具，通过读取 MySQL/MariaDB 数据库的表结构生成可用的数据库交互代码。使用者需遵循约定：表必须含主键 id 字段，列名不得与 Go 类型名冲突。支持通过 id 字段注释（modelgen:N）控制迁移顺序，以处理外键依赖。可通过 Homebrew 安装。

  • 读取 MySQL/MariaDB 数据库结构并生成 Go 数据库交互代码
  • 支持通过 id 字段注释（modelgen:1、modelgen:2 等）控制迁移生成顺序
  • 基于 cobra 和 go-sql-driver/mysql 构建，可通过 Homebrew 安装

适用场景（解读层）

  • 从现有 MySQL/MariaDB 数据库生成 Go 数据库交互代码
  • 存在外键约束、需要按指定顺序生成迁移的数据库
  • 使用 Homebrew 的 macOS/Go 开发环境
