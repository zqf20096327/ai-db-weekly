命令行工具，将 Oracle SQL 查询结果快速导出为 CSV/文本文件

综述（解读层）

q_unload 是一个 C 命令行程序，通过 OCI 数组化读取的方式将 Oracle 查询结果写入文本/CSV 文件，编译后得到 q2csv 可执行文件，用 Makefile 构建，README 注明在 Oracle 11.2 上测试。适用于需要从 Oracle 服务器批量导出查询结果的运维或数据工程人员。支持自定义分隔符、字段包裹与转义、NULL/换行替换、CLOB 读取（默认上限 65K）、从文件读取 SQL、设置 dbms_application_info 等。作者称其导出速度通常比 sql*plus 手工拼接快 10 倍，极端场景可达 100 倍，此数据来自 README 自述。

  • 通过命令行参数指定 userid、sqlstmt 或 sqlfile，将查询结果输出到标准输出，可重定向为文件
  • 支持自定义字段分隔符（默认 |）、包裹引号与转义字符、NULL 与换行替换、可选 CSV 表头（headers）
  • 支持 CLOB 字段导出，最大大小可配置（默认 65K），并可设置 arraysize 控制 fetch 数组大小

适用场景（解读层）

  • 需要将 Oracle 查询结果批量导出为分隔符文本或 CSV 供下游加载的场景
  • 包含大 CLOB（如 XML）字段的表数据卸载
  • 长查询需在数据库端标记 client/module/action 以便追踪的批处理任务
