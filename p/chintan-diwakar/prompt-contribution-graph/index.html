本地运行的 CLI 编码代理提示词贡献追踪工具

综述（解读层）

Prompt Contribution Graph 通过 Claude Code 和 Codex 的官方 hooks 捕获提示词、最终响应与工具元数据，写入本地 SQLite 数据库，并在本地仪表盘中展示 53 周贡献图、连续记录与每日洞察。面向使用 CLI 编码代理并希望留存本地活动记录的开发者。注意：macOS 包目前未经签名，安装时会触发安全警告。

  • 通过官方 hooks 捕获 Claude Code 与 Codex 的提示词、响应及工具名称、状态、耗时、文件路径等元数据，数据存储于本地 SQLite
  • 仪表盘提供 53 周贡献图、当前/最长连续记录、提示词统计、每日洞察，以及按项目过滤的全文搜索
  • 分享功能仅输出包含计数、连续记录与贡献图的图片，不包含提示词或响应内容；卸载命令保留数据库且不影响已有 hooks

适用场景（解读层）

  • 在本地追踪自己在 Claude Code 或 Codex 中的每日提示词提交情况与使用连续记录
  • 按项目搜索和回顾历史提示词与最终响应文本
  • 生成不含提示词内容的聚合活动图片用于分享
