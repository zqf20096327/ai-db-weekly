嵌入式的 Rust 框架，用 SQLite 运行带围栏所有权和精确恢复的 Cell。

综述（解读层）

Cellule 是一个嵌入式 Rust 框架，用于运行由 SQLite 支撑、按租户/命名空间/分区寻址的 Cell。应用定义模块与 Cell 拓扑，框架经围栏所有者执行命令、发布持久结果并支持恢复；HTTP 入口、鉴权与凭证由应用自己负责。提供 SQL、KV、Blob、Queue、Cron、Workflow、Activities、Effects 八类原语，需 Rust 1.97 及以上。

  • 提供八类原语：SQL 批处理与回执绑定读取、KV 条件更新、Blob 分段发布、Queue 租约认领、Cron 调度、Workflow、Activities 监督和跨 Cell Effects 投递
  • 命令在单个 SQLite 事务中存储状态变更与结果，恢复时按 authority 固定的 LTX 根校验对象块
  • 附带 basic/sql/blob/workflow/schedules 五个本地示例，使用临时 SQLite 文件和内存对象存储，无需云凭证

适用场景（解读层）

  • 需要命令结果在所有者切换或恢复后仍可查询的应用
  • 按租户或实体划分独立状态分区的多租户服务
  • Axum 服务（可选 cellule-axum 适配器提供类型化句柄提取和带 Cell 回执的响应）
