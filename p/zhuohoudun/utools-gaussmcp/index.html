uTools 插件，连接华为 GaussDB 提供 SQL 控制台与 MCP 工具。

综述（解读层）

这是一个 uTools 插件，用于连接华为 GaussDB。它提供类 DBeaver 的 SQL 控制台（多 Tab 编辑、Ctrl+Enter 执行光标所在语句、元数据浏览、结果表格展示），并通过 utools.registerTool 注册 MCP 工具供 Cursor 等智能体调用。驱动使用官方 gaussdb-node，写操作经二次确认并记录审计日志，密码保存在 uTools 本机加密存储。适合需要在本机快速查 GaussDB 或让 AI 助手访问该库的开发者。

  • SQL 控制台支持多 Tab 编辑、Ctrl+Enter 执行光标所在语句或选中片段、关键词 Tab 补全、拖入/保存 .sql 脚本
  • 元数据浏览覆盖模式→表/视图→字段，表详情含列/索引/约束，可一键生成 LIMIT 100 预览
  • MCP 工具包含只读元数据工具及 insert_rows/update_rows/delete_rows/execute（须 confirm:true）与审计日志工具

适用场景（解读层）

  • 在本机通过 uTools 呼出快速执行剪贴板或编辑器中的 GaussDB 查询
  • 浏览 GaussDB 的模式、表结构、索引与约束后再编写 SQL
  • 让 Cursor 等支持 MCP 的智能体连接同一 GaussDB 执行查询与写操作
