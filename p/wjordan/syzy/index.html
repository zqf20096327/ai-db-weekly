🧭 简介解读层（AI·证据行可回查）

为 SQLite 和 Postgres 提供本地优先、多写入者复制的系统

综述（解读层）

Syzy 实现应用对本地 SQLite 文件或普通 Postgres 数据库的直接读写，无需网络往返，通过复制已提交事务并按 CRDT 规则解决并发写冲突使各副本收敛。SQLite 侧提供 Go API 与加载扩展，Postgres 17+ 依赖 syzy-pg sidecar 做逻辑解码复制，并持续备份到对象存储。适合边缘与多区域部署；要求全局有序提交的场景不适用，且项目处于 1.0 前的活跃开发阶段。

  • 所有副本均可写入，通过冲突规则使接收到相同变更的副本收敛到同一结果，重复投递安全
  • 支持复制的 DDL：CREATE/ALTER/DROP 语句与行变更一起按序复制，旧 schema 下的写入保持有效
  • 持续将数据库及复制历史备份到对象存储，新副本或回归副本可恢复并追赶，计算层可缩容到零

适用场景（解读层）

  • 延迟敏感、需要数据库紧邻应用的服务
  • 多区域或边缘部署中每个位置都有可写副本的场景
  • 需要缩容到零但仍保持数据库持久性的弹性负载
