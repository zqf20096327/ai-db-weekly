Takeout：用 Docker 为开发环境按需启停依赖服务容器的 CLI 工具

综述（解读层）

Takeout 是一个 CLI 工具，通过启动小型 Docker 容器来提供开发环境依赖（如 MySQL、Redis、PostgreSQL、Mongo、ElasticSearch 等），面向需要本地依赖服务、且常与 Laravel Valet 配合使用的开发者。容器删除后数据经 volume 保留，支持同一依赖多版本并行运行在不同端口。仅支持 macOS、Linux、Windows 10/WSL2；推荐以 dockerized alias 安装，Composer 方式仅支持当前 PHP 主版本。

  • 通过 `takeout enable/disable/start/stop` 等命令管理各依赖服务的 Docker 容器，支持 `--default` 跳过参数询问、`--run=` 传入额外 docker run 选项及容器参数透传
  • 支持同一依赖的多版本同时运行（不同端口与卷名），容器自动加入名为 takeout 的 Docker 网络并获得 base_alias 与 full_alias 两个别名
  • 禁用服务时数据保留在 Docker volume 中，重新启用并挂载同名卷即可恢复；`takeout shell` 可进入运行中容器的 bash/sh

适用场景（解读层）

  • 开发机需要临时启用/停用 MySQL、Redis、Meilisearch 等依赖服务，而不想用 Homebrew 等方式常驻安装
  • 同一台机器上需要并行运行某依赖的多个版本（如 MySQL 5.7 与 8.0，映射不同端口）
  • 与 Laravel Valet 或 Sail 等工具配合，为本地项目提供全局共享的数据库等服务容器
