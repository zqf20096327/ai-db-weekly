综述（解读层）

psql2csv 是一个命令行工具，用于在 PostgreSQL 中运行查询并把结果导出为 CSV。查询可来自 STDIN 或最后一个参数，其余参数转发给 psql；底层基于 COPY 语句实现，支持自定义分隔符、引号、转义符、NULL 表示、编码、表头开关及时区与 search_path 配置，并提供 --dry-run 预览。适合需要从 PostgreSQL 导出 CSV 的开发者或运维人员。

  • 查询可从 STDIN 读取或作为最后一个参数传入，其余参数转发给 psql
  • 支持自定义字段分隔符、引号、转义字符、NULL 字符串、强制引号列及输出编码（默认 UTF8）
  • 提供 --dry-run 打印将执行的 COPY 语句，并支持通过 -v/--set 传递 psql 变量插值到查询

适用场景（解读层）

  • 将 SQL 查询结果导出为 CSV 文件供表格软件使用
  • 运行 SQL 脚本文件并参数化变量（如按月份生成报表）
  • 生成符合特定格式要求的 CSV（如 latin1 编码、制表符分隔、无表头）
