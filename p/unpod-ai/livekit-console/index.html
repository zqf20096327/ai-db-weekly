🧭 简介解读层（AI·证据行可回查）

面向自托管 LiveKit 的管理控制台，React 前端加 Express 后端，密钥留在服务端

综述（解读层）

这是一个为自托管 LiveKit 服务器提供的管理控制台，参照 LiveKit Cloud 仪表盘实现，覆盖房间、会话、通话记录、SIP、egress/ingress、用量和令牌生成。前端为 React + Vite + TypeScript，Express 后端保存 API 密钥并接收 webhook 写入 SQLite。会话与用量数据来自 webhook 历史，从采集器启动后才开始记录；Cloud 完整对等、PCAP 捕获、号码购买与计费未包含。通过 npm 或 Docker 部署，需配置 .env 中的 LIVEKIT_URL 与密钥。

  • 通过 LiveKit server API 提供实时房间、参与者、agent dispatch 和令牌生成；通过 SIP admin API 提供中继与 dispatch 规则的创建编辑表单
  • 接收带签名验证的 LiveKit webhook 并存入 SQLite，形成会话、通话、用量历史
  • 支持轮询 Agents worker 的状态端点（默认每 10 秒）、可选 agent 遥测采集、延迟指标（TTFT/TTFB）、Admin/Viewer 角色访问控制

适用场景（解读层）

  • 为自托管 LiveKit 服务器提供网页端管理与通话/会话历史查看
  • 运维 LiveKit SIP 中继、dispatch 规则及 egress/ingress 任务
  • 自托管 LiveKit Agents 场景下的 worker 状态监控与延迟分析（可选开启遥测与结构化日志）
