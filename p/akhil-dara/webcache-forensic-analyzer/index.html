🧭 简介解读层（AI·证据行可回查）

用于 WebCacheV01.dat 的只读取证分析工具，可恢复已删记录并导出带哈希溯源的报告。

综述（解读层）

这是一款 Windows 桌面应用，用于检查 Windows 记录 IE、旧版 Edge 及相关组件缓存活动的 WebCacheV01.dat 数据库。它基于 dissect.esedb 以严格只读方式打开脏状态数据库，不做修复或软恢复；从未分配页和事务日志恢复已删除记录，每条记录标注来源文件、字节偏移与置信度，并以 SHA-256 校验所读文件。面向需说明证据来源与完整性的取证分析人员，支持 UTC 与本地时间双时钟显示及二进制属性解码。

  • 以只读方式解析脏停机状态的 ESE 数据库，并对每个读取的文件计算 SHA-256，不修改证据文件
  • 从未分配页与事务日志恢复已删除和未刷新记录，每条记录附来源文件、字节偏移、恢复方法与置信度
  • 提供 16 个分析视图，支持逐列过滤与通配符，可导出 CSV、Excel、JSON、SQLite、PDF、离线 HTML 及含 SHA-256 清单的完整案卷

适用场景（解读层）

  • 检查dirty状态获取的 WebCacheV01.dat，从中恢复已删除的浏览历史与缓存记录
  • 需要为每项发现提供文件、字节偏移与证据完整性（哈希）溯源说明的取证审查场景
  • 构建带过滤条件的时间线、域名、位置等分析视图并导出留痕报告
