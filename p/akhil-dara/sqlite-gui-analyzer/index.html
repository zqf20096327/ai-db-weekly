🧭 简介解读层（AI·证据行可回查）

只读的 SQLite 桌面浏览器与取证分析工具，无需 SQL 即可检索、解码并恢复已删除记录

综述（解读层）

SQLite GUI Analyzer 是面向 Windows/macOS/Linux 的桌面 SQLite 浏览器与取证工具，服务于 DFIR、移动取证、CTF 和日常数据库查看。它以 immutable 模式打开文件，在内存中合并 WAL，打开与关闭时计算 SHA-256，不向证据文件写入任何内容；可从 WAL、空闲页和回滚日志中恢复已删除记录。单个 Python 文件、仅标准库，Python 3.8+ 可运行，Windows 提供安装包或便携版。

  • 以只读方式打开数据库（immutable 模式、WAL 内存合并、SHA-256 校验），不生成 -shm 等伴随文件
  • 跨多表多库并行搜索（9 种搜索模式，含正则、十六进制字节模式、列名搜索），支持数百万行浏览
  • 解码 bplist/NSKeyedArchiver、protobuf、gzip、zlib、LZ4、LZFSE、zstd 等 BLOB 及 Unix、WebKit、Cocoa、FILETIME 等时间戳

适用场景（解读层）

  • 移动取证与 DFIR：浏览手机提取目录中的 msgstore.db、sms.db、History 等数据库并恢复删除记录
  • CTF 题目分析：查看 Chrome/Firefox 历史等 SQLite 文件中的隐藏或已删除数据
  • 日常数据库查看：无 SQL 基础下通过 Query 标签联表、筛选、汇总并导出数据
