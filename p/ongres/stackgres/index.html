Kubernetes 上的 PostgreSQL 全栈发行版，以 Operator 方式部署管理

综述（解读层）

StackGres 是面向 Kubernetes 的 PostgreSQL 全栈发行版，以 Operator 形式打包部署，内置 Patroni 高可用、连接池、备份、Prometheus/Grafana 监控与集中日志等组件，均为 PostgreSQL 生态的原版软件，未修改 PostgreSQL 本身。支持 PostgreSQL 12–18 版本，适用于需要在 Kubernetes 认证平台上运行生产级 Postgres 集群的团队。源码采用 AGPLv3 许可，另提供不含 GPL 条款的商业授权。

  • 基于 Patroni 实现自动故障转移与高可用，依赖 Kubernetes API（进而使用 etcd）而非外部 DCS
  • 提供高级 CRD（GitOps 就绪）、Web 管理控制台、自动备份与生命周期管理、集成连接池和基于 Envoy Proxy Postgres filter 的可观测性
  • Operator 用纯 Java 与 Quarkus 编写，经 GraalVM 编译为原生二进制；容器镜像基于 Red Hat UBI 构建

适用场景（解读层）

  • 在云端托管的 Kubernetes 或本地部署发行版上运行 PostgreSQL 集群
  • 需要自动故障转移、自动备份与生命周期管理的 Postgres 部署
  • 通过 GitOps/CRD 声明式管理数据库并集成 Prometheus/Grafana 监控的团队
