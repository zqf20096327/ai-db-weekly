基于 LSM-Tree 的 C++20 KV 存储引擎，支持 Redis RESP 协议子集

综述（解读层）

Tiny-LSM 是一个教学性质的 KV 数据库实现，以 LSM-Tree 为存储引擎，使用 xmake 构建。它提供 C++ 库接口，并部分兼容 Redis RESP 协议，可通过 xmake run server 启动后用 redis-cli 连接。核心组件包含 SkipList、MemTable、SST、WAL 与 MVCC 事务。README 标明项目仍在开发中，当前版本不稳定，Redis 命令仅支持常用子集。

  • 实现 WiscKey 风格键值分离：超过阈值的 value 写入 VLog，SST 中仅存 12 字节引用，VLog 记录带 CRC32 校验，阈值可在 config.toml 中配置（0 为关闭）
  • 事务支持 MVCC 与三种隔离级别（Read Uncommitted、Read Committed、Repeatable Read 为默认），含同步 WAL 与崩溃恢复
  • 提供 Python SDK（sdk 目录下构建），并附 sst_visualize.py 等调试工具

适用场景（解读层）

  • 学习 LSM-Tree 存储引擎实现（项目提供分步 Lab 课程、博客/知乎文章与视频课程）
  • 作为教学或实验环境中的 Redis 后端（仅支持部分 Redis 命令，需查看 TODO 确认支持范围）
  • 作为 C++ 库嵌入应用，进行 KV 读写、范围查询等操作
