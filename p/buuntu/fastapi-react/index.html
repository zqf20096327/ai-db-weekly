用 Cookiecutter 生成 FastAPI + React 全栈项目的模板

综述（解读层）

该仓库是一个 Cookiecutter 模板，用于生成包含 FastAPI 后端、React/TypeScript 前端、PostgreSQL 数据库和 SQLAlchemy ORM 的项目，面向需要快速搭建全栈应用的开发者。内置 JWT/OAuth2 认证、Celery 后台任务、Alembic 迁移、Pytest 测试夹具及 react-admin 管理面板，通过 Docker Compose 运行，前端 JWT 存于 localStorage，管理面板仅限超级用户访问。

  • 通过 cookiecutter gh:Buuntu/fastapi-react 生成项目，可配置项目名、端口、PostgreSQL 凭据与超级用户等变量
  • 后端包含 OAuth2 password flow 的 JWT 认证、Celery/Redis 后台任务（含 Flower 监控）、Alembic 迁移及带事务回滚的 Pytest 测试夹具
  • 前端提供 react-router 路由、登录/登出等认证工具函数、PrivateRoute 高阶组件及 react-admin 管理面板，Nginx 将前后端代理到同一端口

适用场景（解读层）

  • 需要带 JWT 认证和用户管理的 FastAPI + React 全栈项目起步模板
  • 需要 Celery 处理邮件发送、大文件上传等后台任务的场景
  • 需要 react-admin 管理面板对接 FastAPI REST 接口的后台管理系统
