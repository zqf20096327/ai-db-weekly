基于 Docker 的 MySQL 备份还原工具，用 mydumper/myloader 实现 Web 化全量与增量备份

综述（解读层）

这是一个以 Docker 镜像发布的 MySQL 备份与还原管理工具：Python3 提供 HTTP API，VbenAdmin 构建前端界面，备份由 mydumper 完成、还原由 myloader 完成。支持全量与基于 binlog 位点的增量备份、按表黑白名单过滤、Cron 定时任务和 RSA 登录认证，实例配置与任务脚本持久化在挂载的 backup_data 目录。面向需要通过界面或 API 管理 MySQL 备份的运维人员。限制：增量还原仅支持还原到与备份时相同的数据库名，默认账号 admin/123456 需自行修改。

  • 支持全量备份（mydumper 按表导出 *.sql.zst）与基于 binlog 位点的增量备份链，可按表白/黑名单过滤并按 clean_days 自动清理旧备份
  • 提供 VbenAdmin Web 界面与完整 HTTP API（认证、实例管理、任务调度、备份文件管理），任务由 crontab 生成脚本并经 X-Backup-Cron-Secret 密钥校验触发
  • 支持多数据库实例集中管理（配置按登录账号隔离）与「全量+增量」组合还原，大表按分片号拆分存储

适用场景（解读层）

  • 需要通过 Web 界面或 REST API 对多个 MySQL 实例执行定时全量/增量备份的运维场景
  • 需要按表筛选备份内容、保留增量链并执行「全量+增量」组合还原的日常备份管理
  • 需要下载、查看、删除备份文件并留存执行日志的备份文件管理场景
