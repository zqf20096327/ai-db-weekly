🧭 简介解读层（AI·证据行可回查）

基于 JSON 配置的开源 ETL 工具，用于 30 多种数据源间的数据抽取与加载

综述（解读层）

Addax 是阿里 DataX 的持续维护分支，通过 JSON 作业描述实现数据库与文件之间的数据抽取、转换和加载，支持 MySQL、Hive、ClickHouse、MongoDB、Excel 等 30 多种数据源。面向需要异构数据源间离线同步的场景，运行依赖 JDK 17，提供 Docker 镜像、安装脚本与源码编译三种部署方式。

  • 通过插件架构支持 30 多种 RDBMS 和 NoSQL 数据源，包括 HDFS、Kafka、S3、Elasticsearch 等
  • 作业以 JSON 文件描述配置，通过 addax.sh 命令行执行任务
  • 遵循 SemVer 版本规范，按月发布包含依赖更新和修复的维护版本

适用场景（解读层）

  • 数据库之间或数据库到 HDFS 等文件存储的批量数据同步
  • 从 Excel、CSV 等文件向数据库导入数据
  • 在 DataX 停止更新后继续运行原有 DataX 类型的同步作业
