基于 JSON 任务描述的 ETL 工具，支持 30+ SQL 与 NoSQL 数据源

综述（解读层）

Addax 是阿里巴巴 DataX 的持续维护分支，提供数据的抽取、转换与加载能力。用户通过 JSON 编写任务描述即可在 30 多种数据库和文件源之间同步数据。运行需 JDK 17，可通过 Docker、安装脚本或源码编译部署，另可选配 Addax Admin 提供 Web 控制台，支持调度、回补与告警。

  • 支持 30+ 种 SQL 与 NoSQL 数据源及 Excel、HDFS 等文件源，插件可扩展
  • 通过基于 JSON 的任务描述配置数据同步作业
  • 提供 Docker 镜像、一键安装脚本与源码编译（Maven + JDK 17）三种部署方式

适用场景（解读层）

  • 关系型数据库与 HDFS、Hive、ClickHouse 等大数据组件之间的数据同步
  • Excel、CSV 等文件与数据库之间的批量导入导出
  • 需要 Web 控制台进行采集配置、调度与告警的数据集成场景
