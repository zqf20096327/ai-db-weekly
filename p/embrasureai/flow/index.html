Rust 编写的 PostgreSQL 变更流式复制到标准 Apache Iceberg 表的服务

综述（解读层）

Embrasure Flow 是一个用 Rust 编写的单进程服务，通过初始 COPY 加逻辑复制，把 PostgreSQL 的插入、更新、删除持续写入标准 Iceberg 表（Parquet 数据，经 REST 目录发布到 S3 兼容存储），适合需要以开放表格式消费 Postgres 变更的团队。使用需为可变复制表准备主键与 REPLICA IDENTITY，服务状态依赖本地持久磁盘。当前为 beta，不支持分区表、高可用等特性。

  • 在同一 Rust 进程内完成初始 COPY、逻辑复制与后台压缩
  • 支持插入、更新、删除及主键变更；无主键表以追加方式复制
  • 通过事务日志、持久行索引和发布账本支持重放、重连与中断恢复

适用场景（解读层）

  • 将 PostgreSQL 变更以 Iceberg 表形式发布到 S3 兼容对象存储供查询引擎读取
  • 需要增量同步且含更新删除语义的 Postgres 到数据湖管道
  • 构建含 Postgres、MinIO、REST 目录与 Trino 的本地演示或集成环境
