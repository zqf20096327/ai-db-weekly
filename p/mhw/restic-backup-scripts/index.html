基于 restic 的服务器备份 shell 脚本集，含数据库导出与保留策略

综述（解读层）

该项目是一组 shell 脚本，用于在服务器上通过 restic 维护备份，包含文件系统备份、mysqldump/pgdump 数据库导出、按保留策略清除旧备份，并对轮转日志等瞬态文件使用独立保留策略。设计为每日经 cron 运行，可选集成 healthchecks.io 监控。适用于自行维护 Linux 服务器备份的运维人员；示例配置假定存储后端为 Backblaze B2，需自行配置存储凭据并初始化 restic 仓库。

  • 支持文件系统备份及通过 mysqldump、pgdump 导出 MySQL/PostgreSQL 数据库
  • 按保留策略清除旧备份，瞬态文件可用单独的保留策略与 restic 标签处理
  • 可通过 runitor 与 healthchecks.io 集成监控备份任务的 cron 执行

适用场景（解读层）

  • 每日定时备份 Ubuntu 等 Linux 服务器上的重要文件到 Backblaze B2 等对象存储
  • 备份服务器上的 MySQL/PostgreSQL 应用数据库
  • 对每夜轮转的日志等瞬态文件执行独立的备份与清理策略
