自托管 Kubernetes 观测与 AI 运维平台，基于 eBPF 零插桩采集与事务化 MCP 操作接口

综述（解读层）

rocketplaneIO 是自托管的 Kubernetes 可观测平台：通过 Beyla eBPF DaemonSet 在不修改代码的情况下采集 HTTP/gRPC 跨服务链路、SQL/Redis/Kafka 客户端 span 及日志、指标，在 ClickHouse 上提供 PromQL 查询与服务拓扑图。它同时实现 MCP 接口，供外部 AI 代理经 kubectl 形状的原语操作集群，所有变更纳入事务：变更前快照、按风险分级、破坏性操作需人工 UI 审批，支持 LIFO 回滚与审计。需 Docker 与 Kubernetes 集群，compose 一键安装，README 标注处于 Alpha 阶段，API 与 schema 仍会变动，不建议用于生产。

  • eBPF 零插桩采集：无需 SDK、sidecar 或代码变更即可获得含跨服务上下文传播的 HTTP/gRPC 链路（含编译型 Go 二进制）及 SQL/Redis/Kafka 客户端 span
  • 以事务机制保障变更安全：每次变更前持久化快照，按参数感知的风险四级分类，破坏性操作需人工审批，API token 不能审批自己提交的提案，支持 LIFO 回滚与完整审计
  • 提供 MCP 接口供既有 AI 代理（Claude Code、Cursor 等）接入，操作原语为 k8s_get/patch/apply/delete/exec 及 Starlark 工作流，可作用于任意资源含 CRD

适用场景（解读层）

  • 对未插桩的服务进行链路追踪、日志关联与基于真实流量的服务拓扑观测
  • 将外部 AI 代理接入集群执行诊断与修复，同时保留人工审批与回滚通道
  • 自托管或气隙环境下集中存储与查询日志、指标、链路与 Kubernetes 资源清单
