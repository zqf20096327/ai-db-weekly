🧭 简介解读层（AI·证据行可回查）

以 SQLite 扩展形式将表存储到 S3 兼容对象存储的虚拟表引擎

综述（解读层）

s3db 是一个 SQLite 可加载扩展，通过 CREATE VIRTUAL TABLE 语法将表数据存入 S3 兼容对象存储，可与普通表混用。每次事务生成新版本，支持多写入者按列合并、last-write-wins 冲突处理，并提供 s3db_changes 版本比较与 s3db_vacuum 释放旧版本空间。目前仅使用列名和 PRIMARY KEY，暂不支持类型亲和性。

  • 通过 SQLite 虚拟表机制把表数据写入 S3 兼容对象存储，可与常规表在同一数据库中混用
  • 提供 s3db_changes() 比较两个版本间新增/删除的行，s3db_vacuum() 释放旧版本空间
  • 支持多写入者并发提交，冲突按列以 last-write-wins 解决，write_time 可用于重试幂等

适用场景（解读层）

  • 需要把 SQLite 表数据存放在 S3 或自建 S3 兼容存储中的场景
  • 多个写入者各自提交修改、由读取方自动合并版本的场景
  • 在 Go 程序中通过 github.com/jrhy/s3db/sqlite/mod 集成使用（见仓库示例应用）
