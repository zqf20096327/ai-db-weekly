🧭 简介解读层（AI·证据行可回查）

面向 Bun 的任务队列，内嵌内存/SQLite 存储，可选 PostgreSQL 多代理模式，无需 Redis。

综述（解读层）

bunqueue 是运行在 Bun 上的任务队列库，提供嵌入式（进程内）与独立服务器（TCP）两种模式，内置 DLQ、cron 调度、SQLite S3 备份和 MCP 服务器。服务器与嵌入式模式要求 Bun（≥1.4.0），不支持 MySQL；客户端覆盖 Node.js、Deno、Python 等多语言。

  • 支持嵌入式内存/SQLite 持久化与 PostgreSQL 16–18 多代理服务器模式，含数据库权威认领、围栏租约与故障转移状态
  • 提供与 BullMQ 兼容的 Queue、Worker、QueueEvents、FlowProducer API，内含 79 个工具的 MCP 服务器
  • 服务端实现重试退避、优先级、速率限制、死信队列与 cron 调度，Docker 镜像支持 amd64/arm64 四种发行版变体

适用场景（解读层）

  • 单机或嵌入式部署中不需要运维 Redis 的后台任务处理
  • 需要调度器的 AI 代理与自动化流程（通过 MCP 控制队列）
  • 以 PostgreSQL 为存储的多代理队列集群与边缘/serverless 任务缓冲

High-performance job queue for Bun. Memory or one-file SQLite; PostgreSQL 16–18 multi-broker when you scale. DLQ, cron, SQLite S3 backups, and native MCP. Built for AI agents and automation. No Redis.
