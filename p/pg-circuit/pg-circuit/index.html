🧭 简介解读层（AI·证据行可回查）

PostgreSQL 原生熔断扩展，基于实时状态对危险 SQL 给出 ALLOW/WARN/BLOCK 判定

综述（解读层）

PG Circuit Community 是 Apache 2.0 的 PostgreSQL 原生扩展，通过 planner/ProcessUtility 钩子对语句做 AST 分类与 0-100 确定性风险评分，按 observe/warn/enforce 三种模式处理无 WHERE 的 UPDATE/DELETE、TRUNCATE、DROP 及部分 DDL。需配置 shared_preload_libraries 并重启；托管型 Postgres 常无法加载，须自建或 Docker。Community 版运行模式固定为 NORMAL，压力信号仅作展示。

  • 基于解析树/计划树分类语句，提供 PGC001-PGC016 等固定规则 ID 与可解释的 0-100 风险评分，无 AI、无网络调用
  • 提供 observe/warn/enforce 三种模式，enforce 模式下风险达到阈值（默认 80）时阻断语句，事件写入共享内存环形缓冲
  • 附 Go 编写的 pgcircuit CLI（status/runtime/blockers/events/doctor/metrics 等）及 SQL API（pg_circuit_status()、pg_circuit_events()、pg_circuit_explain_risk()）

适用场景（解读层）

  • 在 enforce 模式下拦截缺少 WHERE 的 UPDATE/DELETE、TRUNCATE、DROP TABLE/DATABASE 等高危操作
  • 对 ALTER/CREATE INDEX/REINDEX/VACUUM FULL/CLUSTER 等 DDL 在 enforce 前先以 warn/observe 模式观察
  • 通过 pg_circuit_events() 与 CLI events/doctor 查看本机 WARN/BLOCK 事件历史进行运维排查
