🧭 简介解读层（AI·证据行可回查）

基于 Go 的微信公众号事件分发网关，多下游 Webhook 订阅投递

综述（解读层）

该项目以 Go 单二进制实现微信公众号事件的接收与转发，用于多业务系统同时消费微信推送的场景。收到消息后先落库并向微信回复 success，再由后台 Worker 异步按 JSON Filter 规则过滤并投递到各订阅方 Webhook，支持指数退避重试与手动重放。存储依赖嵌入式 SQLite，提供内嵌 Web 管理控制台，需自行配置微信开发者凭据。

  • 支持明文、兼容与安全模式（AES-256-CBC）解析，落库后快速回复 success，分发由后台 Worker 异步执行
  • 订阅方可用 JSON Filter 按 msgTypes、events、eventKeyPrefixes 过滤，失败投递按阶梯间隔退避重试最多 6 轮，支持手动重放
  • 内置 Go 单二进制嵌入的 Web 管理控制台，数据存储使用纯 Go 实现的嵌入式 SQLite（WAL 模式），出站消息支持 HMAC-SHA256 签名

适用场景（解读层）

  • 多个系统需同时消费微信公众号事件（菜单点击、关注归因、消息内容等）的接入层
  • 需要事件先落库应答微信再异步分发，以规避微信回调响应时限的消息处理流程
  • 希望将微信 Token/AES 凭据集中在网关托管、下游通过 HMAC 验签接收数据的企业部署
