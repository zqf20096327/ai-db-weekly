.NET 10 的 Database-per-Tenant 多租户引擎，含连接解析、JWT 校验与租户级迁移工具

综述（解读层）

该仓库为 .NET 10 提供 Database-per-Tenant 多租户构建块：动态解析每个租户的数据库连接，JWT 校验租户声明，支持基于套餐的功能开关与配额、租户级熔断隔离，并提供带 dry-run 模式的 DbMigrator 迁移工具。面向在 .NET 中搭建多租户 SaaS 后端的开发者。租户开通无自助界面，需手动建库并写入 catalog；容器化 api 服务对演示租户的 DbHost 配置尚不兼容。

  • 提供三租户元数据缓存层（默认直连 catalog，可配置 Redis 连接启用缓存）
  • Tools.DbMigrator 支持 --dry-run 预览迁移与 --tenant 指定租户执行
  • 包含单元测试与基于 Testcontainers 的集成测试（11/11 单元测试、39/39 集成测试）

适用场景（解读层）

  • 在 .NET 10 / EF Core / PostgreSQL 技术栈上搭建数据库级隔离的多租户 SaaS 服务
  • 需要按租户执行迁移并隔离单个租户失败影响的运维流程
  • 需要按套餐控制功能开关与配额的计费/订阅类后端
