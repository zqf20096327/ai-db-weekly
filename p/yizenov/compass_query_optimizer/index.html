基于在线 sketch 的内存数据库查询优化器，MapD 扩展实现

综述（解读层）

COMPASS 是一个基于在线 sketch 的查询优化器，以 MapD（现 OmniSciDB）3.6.1 版本克隆的扩展形式实现，当前仅实现于 MapD 的 GPU 执行路径。它附带 IMDB 数据集加载流程（21 个关系）与 Join Order Benchmark（113 条查询、33 个查询族）用于复现实验，sketch 大小等超参数通过配置文件设置。适用于希望在其指定环境（Ubuntu 16.04、CUDA v10、特定硬件）中复现论文结果或研究 sketch 优化机制的研究者。

  • 作为 MapD System 3.6.1 的扩展实现，运行于 GPU 执行模式
  • 支持预构建 sketch 模板，对无选择谓词的关系可跳过 sketch 构建以降低开销
  • sketch 大小等超参数通过 COMPASS_init_variables.txt 配置文件设置

适用场景（解读层）

  • 按 instructions.pdf 复现论文实验结果与图表
  • 在 IMDB 数据集上运行 Join Order Benchmark 的 113 条查询
  • 更换 sketch 尺寸等超参数以研究其行为影响
