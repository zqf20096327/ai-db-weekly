🧭 简介解读层（AI·证据行可回查）

基于 Docker Compose 的 AMP（Nginx/MySQL/PHP）开发环境配置集。

综述（解读层）

该仓库提供一套基础配置，通过 docker-compose 启动 Nginx、MySQL 和 PHP 容器，用于运行 public 文件夹中的项目文件，面向需要本地 PHP 开发环境的开发者。默认 PHP 5.6，可在 Dockerfile 中修改版本；phpMyAdmin 运行于 8090 端口，数据库文件通过 volume 持久化存储。

  • 通过 docker-compose up 一条命令启动 Nginx、MySQL、PHP 三类容器，服务地址为 localhost:8080
  • 内置 phpMyAdmin 容器，默认在 8090 端口访问；数据库文件存于独立 Docker volume
  • PHP 版本可通过编辑 ./docker/php/Dockerfile 中的版本号切换

适用场景（解读层）

  • 本地运行典型 AMP 架构的 PHP 项目
  • 通过容器命令行（docker exec）执行导入数据库等操作
  • 需要通过修改 Dockerfile 切换 PHP 版本的本地开发场景
📖 README 首段存档原文 · 程序抽取

This repository contains a basic configuration for a development environment for a typical AMP stack (Nginx, MySQL and PHP). Project files stored in the public folder are served by Nginx.
