连接美国人口普查局数据 API 与 AI 助手的 MCP 服务器

综述（解读层）

这是一个基于 MCP TypeScript SDK 构建的服务器项目，连接美国人口普查局数据 API，供 AI 助手获取官方统计数据。部分 API 数据会被拉取到本地 Postgres 容器以支持搜索。运行需 Census API key、Docker 和 Node 18+，首次使用需执行数据库初始化命令。提供 list-datasets、fetch-aggregate-data、resolve-geography-fips 等工具及人口查询提示模板。

  • 提供 list-datasets、fetch-dataset-geography、fetch-aggregate-data、resolve-geography-fips 四个工具，并暴露 tools/list、tools/call、prompts/list、prompts/get 方法
  • 将部分 Census Data API 数据拉取到本地 postgres 容器以支持搜索功能
  • 使用 Vitest 测试 MCP Server 与 MCP Database，并提供 scripts/dev 下的 bash 辅助脚本封装 Docker 命令

适用场景（解读层）

  • 让 AI 助手查询美国人口普查局的统计数据（如各州、县、市人口数据）
  • 按数据集与年份获取聚合数据，或将地理名称解析为对应 FIPS 代码
  • 列出 Census Bureau API 中可用数据集的元数据
