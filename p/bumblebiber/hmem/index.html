🧭 简介解读层（AI·证据行可回查）

面向 AI 代理的持久化记忆框架，以 SQLite 树结构与 5 级惰性加载实现跨会话记忆

综述（解读层）

hmem 是为 AI 代理（如 Claude Code）设计的持久化记忆框架，通过 MCP 服务器提供记忆读写、检索与项目生命周期管理。其核心机制是将记忆组织为层次树并分 5 级按需加载：会话启动加载一行摘要（约 5k tokens 覆盖 300+ 条目），详情逐级深入。自动记录每次会话并由 Haiku 子代理周期性提取要点，支持跨设备同步与公司共享记忆库。适用于需要多项目、多设备、多模型客户端持续记忆的开发者，可通过 npm 安装并以 SDK 形式嵌入自有工具。

  • 5 级惰性加载：L1 摘要常驻加载，L2-L5 完整原文按需读取，单项目简报约 3000 tokens
  • 提供两个 MCP 服务器：日常用 hmem（13 个工具）与维护用 hmem-curate（11 个工具，opt-in 激活）
  • 自动会话记录：Stop hook 保存每次交互到 O-entry，每 N 次交互由 Haiku 子代理写入长期记忆与交接笔记

适用场景（解读层）

  • 多设备、多 AI 提供商间切换开发，需要项目上下文跨会话延续
  • 团队场景下多个代理/成员共享公司级记忆库（company.hmem）
  • 将记忆能力通过 SDK 嵌入自研代理、工具或自动化流水线
