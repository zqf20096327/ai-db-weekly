Python Discord 服务器的使用指标采集应用

综述（解读层）

Metricity 是 Python Discord 社区的指标采集应用，通过 Discord bot 机制收集服务器成员与使用数据，仅负责采集，可视化需另接 Grafana 等工具。数据存储于 PostgreSQL，使用 Poetry 管理依赖、Alembic 管理数据库迁移，配置可通过环境变量或 config.toml 设置。适合自托管 Discord 服务器数据统计的运维者。

  • 通过 BOT_TOKEN 连接 Discord，采集服务器使用指标并存入 PostgreSQL
  • 支持环境变量（BOT_TOKEN、DATABASE_URI）与 config.toml 两种配置方式
  • 使用 Poetry 管理依赖、Alembic 执行和生成数据库迁移，提供 Docker 镜像

适用场景（解读层）

  • 为 Discord 服务器搭建指标采集管线
  • 将采集数据接入 Grafana 生成可视化
  • 自托管并定制 Discord 服务器统计模型与迁移
