本地多代理协调层，用 SQLite 存储会话、任务租约与交接上下文

综述（解读层）

AgentRelay 是一个本地运行的编码代理协调与记忆层，供 Codex、Claude Code 等多个 AI 代理在同一工作区内接力工作。它通过 MCP 服务器提供十项协调工具与五项终端工具，数据以 SQLite 存于仓库本地 .agentrelay 目录；安装需 Node.js 22.13+，尚未发布到 npm，需从 GitHub 安装；终端工具额外依赖 tmux 3.2+。

  • 提供任务租约、文件/glob 范围声明、决策冲突提示与 FTS5 全文搜索等十项 MCP 协调工具
  • 内置 tmux 传输，支持带红action与大小限制的终端读取及先读后发的单行消息发送
  • 生成确定性 Git 感知的 Markdown 交接文档，并按 token 预算编译上下文包

适用场景（解读层）

  • 多个 AI 代理在同一项目或工作区内接力完成任务的交接场景
  • 需要记录开发事件、架构决策与失败尝试供后续代理检索的团队流程
  • 在 tmux 会话内让代理读取并向可信面板发送消息的协调场景
