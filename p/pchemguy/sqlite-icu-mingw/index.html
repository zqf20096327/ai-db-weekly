在 Windows 上用 MSVC 或 MinGW 构建 ICU 版 SQLite 与 SQLiteODBC 驱动的脚本集

综述（解读层）

该项目提供一系列构建脚本，用于在 Windows 上以 MSVC 或 MSYS2/MinGW 工具链编译 SQLite 库和 SQLiteODBC 驱动，构建产物默认启用 ICU 与多个集成扩展（如 csv、regexp、uuid、zipfile 等），并可将当前版 SQLite 嵌入 ODBC 驱动，构建时动态链接 ICU 与 Zlib 并复制依赖。适用于需要在 Windows 上自定义 SQLite 构建的 C/C++ 与 VBA 开发者；注意应使用 Current 目录下的脚本。

  • 提供 MSVC 与 MSYS2/MinGW 两套构建脚本，可生成 x32 STDCALL 与 x64 的 SQLite DLL 及 shell
  • 默认启用 ICU 与集成扩展（csv、fileio、normalize、regexp、series、sha、shathree、sqlar、uint、uuid、zipfile）
  • 支持构建嵌入当前版 SQLite 并启用全部集成扩展的 SQLiteODBC 驱动，依赖 ICU/Zlib 动态链接并随产物复制

适用场景（解读层）

  • 需要 ICU 支持非拉丁字符不区分大小写操作的 Windows 应用构建
  • x32 VBA 通过 STDCALL 直接调用 SQLite 库
  • 需要启用全部扩展或集成当前 SQLite 版本的 SQLiteODBC 驱动场景
