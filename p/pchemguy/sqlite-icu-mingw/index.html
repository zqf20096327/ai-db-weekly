用 MSVC 或 MinGW 工具链在 Windows 上构建带 ICU 的 SQLite 与 SQLiteODBC 的脚本集

综述（解读层）

该项目提供一组脚本，用于在 Windows 上以 MSVC 或 MSYS2/MinGW 工具链构建 SQLite 库与 SQLiteODBC 驱动，默认启用 ICU 及 csv、uuid、zipfile 等扩展，也可在 Linux 上用 Bash/GCC 构建静态与动态库。适合需要自定义 SQLite 构建的 Windows 开发者；脚本以动态链接 ICU/Zlib，ODBC 驱动构建不可配置。

  • 提供 MSVC 与 MSYS2/MinGW 两套构建脚本，可生成 DLL、导入库、静态库及 SQLite CLI
  • 支持 ICU 启用构建、x32 STDCALL 构建，并默认启用集成扩展及 csv、fileio、uuid、zipfile 等 11 个附加扩展
  • 可构建嵌入当前 SQLite 版本并启用全部集成扩展的 SQLiteODBC 驱动，并将 ICU/Zlib 依赖复制到输出目录

适用场景（解读层）

  • 需要在 Windows 上构建启用 ICU 的 SQLite 二进制，用于非拉丁字符大小写不敏感操作
  • 需要从 32 位 VBA 直接调用 SQLite 库（STDCALL 约定）的场景
  • 需要嵌入新版 SQLite 并启用扩展的 SQLiteODBC 驱动，或将脚本作为模板定制构建流程
