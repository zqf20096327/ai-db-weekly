🧭 简介解读层（AI·证据行可回查）

自托管上下文编译器：以 git 中的 Markdown 知识库经 MCP 输出受 token 预算约束的上下文包

综述（解读层）

briefd 是面向 AI 编码团队的自托管知识服务：团队知识以 Markdown 存于 git 仓库，briefd 索引后通过 MCP 或 REST 提供检索与打包。检索采用 SQLite FTS5（BM25）与纯 Go 计算的多语言 embedding 的混合方案，配以 reciprocal rank fusion；所有返回上下文的接口均接受 max_tokens 且不超预算。索引仅是可丢弃缓存，知识以 git 为唯一来源，代理只能经 propose_update 开分支提交修改。

  • 提供 compile_bundle、search_context 等 7 个 MCP 工具，接口支持 max_tokens 硬预算；同类操作也可经 REST 访问
  • 混合检索：SQLite FTS5（BM25）+ multilingual-e5-small 多语言 embedding，由纯 Go 实现计算，无外部数据库或 ONNX 运行时依赖
  • 支持 Obsidian vault 读取 [[wikilinks]] 等链接并构建链接图；可选接入 Jira Cloud 与 Confluence Cloud，propose_update 通过分支/PR 修改知识

适用场景（解读层）

  • 多个项目共享同一领域术语、业务规则与编码规范时，向编码代理按需提供该领域上下文
  • 团队希望通过 git review 流程管理代理可见的知识，代理仅能经 PR 提案修改
  • 以 Obsidian vault 作为知识库，并让代理通过 MCP/stdio 或 HTTP 访问其链接图与文档
