面向关系型数据库复杂查询的ES+缓存混合加速中间件

综述（解读层）

DBSearchAccel 是一款数据库复杂只读查询加速中间件，用 Elasticsearch 做条件过滤取主键、数据库查详情，并以 Redis 缓存增删改主键补全 ES 同步延时，数据经 Canal/DataX 同步。支持 MySQL、OceanBase、PostgreSQL，提供配置化路由/过滤/降级规则，故障时兜底回原生数据库查询。适用于已出现复杂多条件、多表联查慢 SQL 的只读查询场景。

  • 采用 Elasticsearch 查主键 + 关系型数据库查详情的混合查询架构，支持 MySQL 5.7+/8.0+、OceanBase 2.x/3.x、PostgreSQL 12+/14+
  • 基于 Canal 监听 Binlog 做增量同步、DataX 做全量同步，配合 Spring AOP 拦截增删改并写入 Redis 缓存实时主键
  • 内置接口级/场景级/全局级三级降级熔断（基于 Sentinel），故障时自动切回原生数据库查询，并提供 ES 与数据库数据一致性校验

适用场景（解读层）

  • 存在复杂多参数 Where 子句、多表联查、大数据量表列表查询慢 SQL 的只读查询场景
  • 需要将搜索引擎引入查询加速但缺少专业搜索引擎运维团队的中小企业
  • 需要在查询链路故障时兜底回数据库、并要求可校验索引与数据库数据一致性的业务系统
