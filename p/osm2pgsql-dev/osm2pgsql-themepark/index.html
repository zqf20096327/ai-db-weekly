基于构建块组装 osm2pgsql flex 输出配置的 Lua 框架

综述（解读层）

该项目为 osm2pgsql 的 flex 输出提供配置框架，将地图数据转换拆分为可复用的主题与主题块，使用者按需组合或自行编写。需 osm2pgsql 1.9.2 以上版本，运行时以 `-O flex -S CONFIG.lua` 方式调用。仓库含 basic、core、shortbread_v1 等主题及 taginfo、tilekiln、t-rex、bbox 插件；项目为 Beta 状态，接口可能变更。

  • 以插件机制生成 Taginfo 项目文件及 Tilekiln、T-Rex、BBOX 瓦片服务器的配置文件
  • 内置 basic、core、explore、external、shortbread_v1 等多个主题，其中 shortbread_v1 实现 Shortbread v1.1 schema
  • 提供基于 busted 框架的单元测试，可通过 bin/run-tests.sh 运行

适用场景（解读层）

  • 为 PostGIS 数据库构建 OpenStreetMap 地图图层表，避免每次从零编写 flex 配置
  • 为 Tilekiln、T-Rex、BBOX 等矢量瓦片服务器生成对应配置文件
  • 配合 QGIS 探索和筛选 OSM 数据，或作为自定义主题开发的起点
