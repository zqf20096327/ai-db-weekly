🧭 简介解读层（AI·证据行可回查）

单容器一体化 Docker 镜像，用于搭建和运行自动化媒体栈。

综述（解读层）

DUMB 是一个 All-In-One Docker 镜像，把 Debrid/Usenet 工作流、*arr 自动化、媒体服务器（Plex/Emby/Jellyfin）、请求与监控工具整合在一个容器内，通过控制面板统一管理服务安装、配置、日志、健康检查和更新。需设置 PUID/PGID/TZ 环境变量，支持 docker-compose、Docker Hub/GHCR 镜像或 Proxmox LXC 部署，许可证为 GPLv3。

  • 以单个容器提供 30 余个媒体栈组件，包括 Radarr、Sonarr、Prowlarr、Plex、Jellyfin、PostgreSQL、Traefik 等
  • 提供 DUMB 前端仪表盘与 API（默认端口 3005/8000），用于服务的生命周期管理、日志、健康检查与更新
  • 支持可选的 Authelia 身份认证、Traefik 反向代理和 Cloudflare 访问工具，并可通过 Proxmox Community Scripts 以 LXC 方式部署

适用场景（解读层）

  • 在单台 NAS/服务器上通过一个容器运行完整的自动化媒体下载与管理栈
  • 需要统一界面管理多个媒体服务（*arr、媒体服务器、索引工具）的部署与运维
  • 在 Proxmox 环境中使用 LXC 脚本原生部署媒体栈组件
