基于 JSON 文件的轻量级嵌入式 JavaScript 本地数据库

综述（解读层）

lowdb 是一个面向 JavaScript/TypeScript 的本地 JSON 数据库，通过 JSONFilePreset 等预设读写 db.json 文件，数据即普通 JavaScript 对象，可用原生数组方法查询，支持浏览器 LocalStorage 和内存适配器。适用于 Node.js、Electron 与浏览器场景。限制：不支持 Node cluster 模块，写入时整体序列化，大规模数据场景 README 建议改用 PostgreSQL 或 MongoDB。

  • 提供 JSONFile、Memory、LocalStorage 等适配器，可自定义适配器支持 YAML、加密等其他格式或存储
  • 支持 TypeScript 类型检查，提供异步 Low 与同步 LowSync 两个类及 read/write/update 方法
  • 写入采用安全的原子写，测试时可自动切换到内存模式

适用场景（解读层）

  • Node.js 或 Electron 应用的小型本地数据存储
  • 浏览器中基于 localStorage/sessionStorage 的数据持久化
  • 单元测试中使用内存适配器加速读写
