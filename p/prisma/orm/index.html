🧭 简介解读层（AI·证据行可回查）

Prisma ORM 的 TypeScript 重写版，用可读查询替代 SQL 并面向 AI 代理设计。

综述（解读层）

Prisma 8 是 Prisma ORM 的 TypeScript 重写版本，目前处于发布候选阶段，供使用 TypeScript 与 Node.js（24+）的开发者构建数据库应用。它通过 `npm create prisma` 或 `npx prisma orm init` 接入项目，并在项目根目录安装 `prisma-8.md` 与各工作流的 SKILL.md，供 Claude Code、Cursor、Copilot Agent、Devin 等代理运行时读取。其核心采用最小内核加公共 SPI 扩展机制，pgvector、PostGIS 等扩展均基于同一 SPI 构建。当前正式支持 PostgreSQL 与 MongoDB，SQLite 为概念验证，MySQL 排在其后。

  • 提供交互式脚手架与 `orm init` 命令，支持 Next.js、Hono、Nuxt、Astro、NestJS、SvelteKit 等应用模板
  • 在每个工作流中安装 SKILL.md 文件到 .claude、.cursor、.agents、.devin 等代理运行时目录
  • 公开 SPI 扩展机制，已提供 pgvector、PostGIS、ParadeDB、Supabase 等扩展包

适用场景（解读层）

  • 在 Node.js/TypeScript 项目中以可读查询方式访问 PostgreSQL 或 MongoDB
  • 让 AI 编码代理按项目内安装的技能文件驱动数据库模型与查询变更
  • 通过 SPI 编写扩展，为 Prisma 接入自定义数据库或第三方库功能
