受 Django ORM 启发的 Python Redis ORM，提供带字段模型的 CRUD 操作

综述（解读层）

这是一个 Python 编写的 Redis ORM 库，作者因 redis-py 提供的抽象层级较低而编写，供需要在 Redis 中操作带字段模型的 Python 开发者使用。它通过 RedisRoot 管理模型注册与连接配置（prefix、connection_pool 等），RedisModel 提供 CRUD 和 TTL，字段支持自动序列化/反序列化与过滤。需自备 Redis 服务器（v3+），通过 pip 安装。

  • 提供 13 种内置字段类型（RedisString、RedisJson、RedisForeignKey、RedisManyToMany 等），支持自动序列化/反序列化、TTL、默认值与 choices
  • 支持 16 种过滤操作符（exact、contains、gte、range、isnull 等）及深度过滤
  • RedisRoot 提供 economy、save_consistency、use_keys 等配置项，操作可以非阻塞方式在后台创建 asyncio 任务

适用场景（解读层）

  • 需要在 Redis 中以模型化字段方式存储和查询数据的 Python 项目
  • 使用 Redis 作为缓存或存储并需要字段级 TTL 与过滤查询的场景
  • 希望用 asyncio 非阻塞方式执行 Redis 读写操作的应用
