sqlc 的 .NET 插件，为 SQL 查询生成类型安全的 C# 数据访问代码

综述（解读层）

sqlc-gen-csharp 是 sqlc 的 .NET 插件，读取 sqlc 配置后为 PostgreSQL、MySQL 和 SQLite 生成类型安全的 C# 代码，对应 Npgsql、MySqlConnector、Microsoft.Data.Sqlite 驱动，可选启用 Dapper。支持 sqlc 的查询注解、事务与类型覆盖，可通过 yaml 选项指定目标框架（netstandard2.0/2.1/net8.0）、命名空间、是否生成 .csproj 等。适用于已在 sqlc 工作流中的 .NET/C# 项目。

  • 支持 PostgreSQL、MySQL、SQLite 三种数据库的全部查询注解（:one/:many/:exec/:execrows/:execlastid/:copyfrom）与事务
  • 提供 override 选项，可按 query_name:column_name 或全局通配方式覆盖生成代码的列类型与可空性
  • 可配置目标框架、命名空间、.csproj 生成、中央包管理、异步方法后缀、CancellationToken 注入及模型名单数化

适用场景（解读层）

  • 在 .NET（含 netstandard2.0 兼容场景）项目中由 SQL 查询生成 C# 数据访问代码
  • 需要覆盖 sqlc 推断类型或自定义生成行为（命名、异步后缀、取消令牌）的团队
  • 使用批量插入（PostgreSQL COPY FROM、MySQL LOAD DATA）或需在 MySQL/SQLite 中动态生成 IN 参数列表的场景
