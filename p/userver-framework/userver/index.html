C++ 异步框架，以透明 I/O 调度支撑微服务开发

综述（解读层）

userver 是开源 C++ 异步框架，用于构建微服务、服务与工具程序。其机制是当 I/O 操作会阻塞线程时挂起任务而非线程，让少量执行线程转去处理其他请求，待可立即执行时再返回。提供数据库驱动、多协议支持、缓存/分布式锁/指标等组件，并支持运行中修改服务配置。

  • 为 MongoDB、PostgreSQL、Redis、ClickHouse、MySQL 等数据库及 HTTP/1.1、HTTP/2.0、gRPC、Kafka、WebSocket 等协议提供异步驱动
  • 包含缓存、任务、分布式锁、日志、追踪、统计、指标、JSON/YAML/BSON 等高层组件
  • 支持运行中修改服务配置，提供超时、截止时间传播与拥塞控制选项

适用场景（解读层）

  • 使用 C++ 构建微服务
  • 需要以少量线程处理大量 I/O 请求的服务
  • 需要数据库与多种数据传输协议异步交互的应用
