Rust 编写的 PostgreSQL schema 对比、迁移执行与类型安全查询工具

综述（解读层）

Tusker 是一个 Rust 项目，提供 PostgreSQL schema diff 引擎、可嵌入的 SQL 迁移运行器，以及基于 tokio-postgres、通过过程宏派生实现 SQL 绑定的查询层。由多个 crate 组成，核心面向 tusker CLI。需 Rust 1.88+，可通过 crates.io、预编译二进制或 ghcr.io 容器镜像安装。

  • 包含 PostgreSQL schema 检查与 diff 引擎（tusker-schema）
  • 提供可嵌入的 SQL 迁移文件运行器（tusker-migration）
  • 基于 tokio-postgres 并通过 derive 宏实现类型安全查询绑定（tusker-query / tusker-query-derive）

适用场景（解读层）

  • 对比 PostgreSQL 数据库 schema 差异并执行迁移流程
  • 在 Rust 应用中嵌入数据库迁移运行器
  • 构建需要 SQL 与类型元数据绑定的查询工具链
