基于离线 schema 快照的 PostgreSQL MCP 服务器与 CLI 工具

综述（解读层）

dryrun 是一个 CLI 工具加 MCP 服务器的组合，用于 PostgreSQL schema 情报：CLI 连接数据库提取目录信息（表、视图、索引、约束、分区、触发器、RLS 等）写入本地快照文件，MCP 服务器读取该快照并向 AI 助手提供 schema 探索、查询验证、迁移检查、lint 等工具。分析离线进行，AI 助手无需数据库凭据；需 PostgreSQL 15 或更新版本，经 Homebrew、npm 或源码（Go 1.26+）安装。

  • 提供 20+ 约定 lint 规则和 13 条结构审计规则（重复索引、FK 覆盖、循环外键、vacuum 调参等）
  • 支持迁移安全分析：锁类型、时长估计、表重写检测及每条 DDL 的替代方案；查询验证基于 libpg_query 解析并对照实际 schema
  • MCP 服务器通过 stdio 或 SSE 暴露 9 个工具，快照可 push/pull 共享，团队其他成员无需数据库凭据

适用场景（解读层）

  • 为 Claude Code、Cursor、Codex、Zed 等 AI 编码助手提供 schema 上下文，供其编写 SQL 前查询结构、约束与索引
  • 在 CI 或无凭据环境中离线执行 schema lint、迁移安全检查与查询验证
  • DBA 捕获快照并共享给团队，多人/多代理在不接触生产凭据的情况下获得 schema 信息
