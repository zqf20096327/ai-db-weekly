基于离线 schema 快照的 PostgreSQL MCP 服务器与 CLI 工具

综述（解读层）

DryRun 通过 CLI 连接 PostgreSQL 抽取完整目录（表、视图、索引、约束、RLS 策略、触发器等）生成快照文件 `.dryrun/history.db`，再以 MCP 服务器（stdio 或 SSE）向 AI 编码助手提供 9 个离线工具，包括 lint、查询验证、迁移锁分析和外键图探索。安装需 Homebrew、npm 或 Go 1.26+，要求 PostgreSQL 14 及以上；离线快照分发需提交 `dryrun.toml` 与 snapshots 目录，多数据库需每库各启一个 MCP 进程。

  • CLI 抽取完整数据库目录并生成快照，lint、迁移安全分析、查询验证等均在离线快照上运行
  • MCP 服务器通过 stdio 或 SSE 暴露 9 个工具，连接真实数据库后额外启用 explain_query、check_drift、columnar_report
  • 支持快照推送/拉取共享（snapshot push/pull）、快照间 diff、pg_stat_statements 查询形状统计与多副本统计

适用场景（解读层）

  • 让 AI 编码助手在编写 SQL 前获得 schema、索引、约束感知，而无需暴露数据库凭据
  • 在 CI 或开发者本机离线检查 schema 规范与 DDL 迁移的锁类型和表重写风险
  • 团队成员中仅一人持有数据库凭据，通过共享快照让其他人获得完整 schema 信息
