面向 Laravel 应用的 Web 图形化数据库管理工具包

综述（解读层）

Laravel Dibi 是一个以 Composer 包形式安装的数据库管理 GUI，集成进 Laravel 应用后在 /dibi URI 提供数据库浏览界面，面向需要在本地或开发服务器上查看数据库的开发者。当前仅支持 MySQL（默认使用名为 mysql 的连接，可通过 Dibi::useDatabaseConnectionName 更换），支持通过授权 gate 控制非本地环境访问、自定义路由中间件，也可用 --dev 仅本地安装。

  • 通过 Composer 安装并运行 dibi:install 后，在 /dibi URI 提供 Web 管理界面，无需安装其他应用
  • 提供授权 gate 机制控制非本地环境的访问，并支持通过 config/dibi.php 自定义路由中间件
  • 支持 --dev 仅本地安装，并可配置环境判断注册服务提供者与禁止自动发现

适用场景（解读层）

  • 在本地或开发服务器上浏览 Laravel 应用的 MySQL 数据库
  • 需要通过授权 gate 与中间件限制数据库面板访问的团队项目
  • 仅用于本地开发、按环境条件加载的数据库查看场景
