🧭 简介解读层（AI·证据行可回查）

基于 SQLite 的本地优先 AI 代理共享记忆系统，经 MCP/CLI 存取。

综述（解读层）

Max Chronicle 用 SQLite 为 AI 代理存储带署名的事件与当前断言，代理通过 MCP 或 CLI 记录决策、检索记忆、交换检查点，使新代理可在无先前对话的情况下接续任务。它面向需要多代理协作与任务交接的开发者，核心不依赖 Ollama 或付费 API，本地向量检索为可选功能；所有记录保留作者、证据与类型标记，并在写入前对疑似机密做脱敏处理。

  • 提供六个 MCP 工具（startup_bundle、query_memory、get_memory、record_event、recent_events、state_at），支持按词语与语义检索事件和笔记
  • 存储的断言保留作者、证据与类型（observed/decision/assumption），记录的一切内容作为数据处理而非指令
  • 提供 Web 视图、Atlas 三维可视化、CLI（query-memory/timeline/record/doctor）以及健康检查、定时任务与备份；MIT 许可

适用场景（解读层）

  • 代理会话交接：通过检查点与任务简报让另一代理在没有先前聊天记录的情况下继续任务
  • 团队或个人查看项目开放任务、当前事实与近期决策，并浏览记忆历史与 Atlas 可视化
  • 在本地（无付费 API 依赖）为多代理工作流记录决策、发现与证据以供检索
