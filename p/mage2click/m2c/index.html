用于创建和管理 Magento Docker 开发环境的系统级命令行工具集

综述（解读层）

m2c 是一个系统级命令行工具，用于同时创建和运行多个 Magento Docker 项目。它内置 Traefik、Portainer、MailHog、Dnsmasq 等全局服务，每个项目默认包含 Nginx、PHP-FPM、MariaDB、Redis、Xdebug，并可选装 Varnish、Elasticsearch 等；在 macOS 上捆绑 mutagen.io 实现宿主机与容器间文件同步。适用于 Magento 2 本地开发，要求 Docker 环境至少 6GB 内存、双核 CPU 和 SSD。README 注明该配置已在 macOS 上测试，Linux 平台仍待验证。

  • 提供交互式（m2c init）与命令行参数两种项目初始化模式，支持添加或移除 elasticsearch、phpmyadmin、rabbitmq、varnish 等可选服务
  • 内置 m2c composer、m2c m、m2c mr、m2c node、m2c npm、m2c redis、m2c varnish 等命令，可在容器内运行对应工具，并支持 Xdebug 调试与 ngrok 会话共享（m2c share）
  • 在 macOS 上捆绑 mutagen.io 工具实现宿主机与 Docker 容器间文件同步，Linux 上使用原生文件系统挂载

适用场景（解读层）

  • 在 macOS 或 Linux 上搭建 Magento 2 本地 Docker 开发环境
  • 同时管理多个 Magento Docker 项目的服务启停、数据库导入导出与 Xdebug 调试
  • 通过 ngrok 隧道（m2c share）将本地项目共享给外部访问
