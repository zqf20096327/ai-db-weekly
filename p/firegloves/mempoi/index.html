基于 Apache POI 的 Java 库，通过 JDBC 查询将数据库数据导出为 xlsx 文件

综述（解读层）

MemPOI 是一个 Java 库，用于把 SQL 查询结果导出为 Excel（.xlsx）文件，面向需要导出数据库数据的 Java 开发者。它不依赖 ORM，直接基于 JDBC PreparedStatement 读取数据，经 MempoiBuilder 构建，默认使用 SXSSFWorkbook，支持异步生成。使用者需自行管理数据库连接，PreparedStatement 与 ResultSet 由库内部管理并关闭。通过 Gradle 或 Maven 引入，支持 Java 8/11/17/21。

  • 直接基于 JDBC 类访问数据库数据，无需 ORM，支持 SXSSF/XSSF/HSSF 三种 Workbook 及多 Sheet 生成
  • 支持列宽自适应、多套内置样式模板、自定义 CellStyle、文本页眉页脚及数值求和/最大/最小子页脚
  • 支持写入文件或返回字节数组两种输出方式，并以 CompletableFuture 返回报告结果

适用场景（解读层）

  • Java 应用中批量导出数据库查询结果为 Excel 报表文件
  • 需要多个查询写入同一 xlsx 文件多个 Sheet 的报表生成
  • Web 服务中将报表以字节数组形式返回给客户端下载
