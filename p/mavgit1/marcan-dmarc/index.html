单容器自托管 DMARC 报告分析器，Rust 单二进制配 SQLite 存储

综述（解读层）

Marcan 从多个邮箱（IMAP 或 Microsoft Graph）读取 DMARC 聚合报告，基于原始 SPF/DKIM 结果重新计算对齐判定，并支持 DMARC、SPF、DKIM、MTA-STS 等记录的实时 DNS 检查，结果在 Web 仪表盘展示。适用于管理自有邮件域名者及 MSP。限制：仅聚合报告、每账户单文件夹、无内置用户体系需反向代理登录，当前为 0.x 公测版。

  • 从报告原始 SPF/DKIM 结果按 RFC 9989 重新计算 DMARC 对齐判定，区分转发与真实失败
  • 支持任意 IMAP/SMTP 或 Microsoft 365（Graph）多邮箱收取报告，凭据可选 AES-256-GCM 加密，对邮箱只读
  • 提供实时 DNS 检查（含 SPF include 树与查找限制、DKIM、MTA-STS、TLS-RPT、BIMI）、变更告警、月度客户报告与 CSV 导出

适用场景（解读层）

  • 为自有域名集中处理 DMARC 聚合报告并排查投递认证失败
  • MSP 为多组织/多域名客户汇总报告并生成月度客户报告
  • 监控域名 DNS 邮件安全记录（SPF/DKIM/DMARC/MTA-STS 等）变更并接收告警
