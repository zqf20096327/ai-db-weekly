SquashQL 是位于 SQL 数据库与应用之间的多维分析查询引擎中间件

综述（解读层）

SquashQL 是一个开源 SQL 查询引擎，以中间件形式部署在 SQL 数据库与前端应用之间，为后端开发者提供查询优化入口，为前端提供配置指标的 TypeScript API。支持 Spark、ClickHouse、BigQuery、Snowflake、PostgreSQL、DuckDB 等数据库，透视表总计由数据库端计算，内置可自定义的内存查询缓存。

  • 支持 Apache Spark、ClickHouse、BigQuery、Snowflake、PostgreSQL、DuckDB 等多种数据库连接
  • 提供 TypeScript 查询构建器，支持透视表、分桶、层级/时间序列比较度量与跨事实表钻取合并
  • 提供内存查询缓存及 text/plain、CSV、JSON 多种输出格式

适用场景（解读层）

  • 需要在多个不同 SQL 数据库上执行同一套多维查询的应用
  • 在 Web 前端构建透视表、层级比较等分析视图
  • 需要将多个事实表查询结果按共享列拼接分析的场景
