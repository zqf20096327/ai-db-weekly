综述（解读层）

Elephant Shed 是 credativ 开发的基于 Web 的 PostgreSQL 管理前端，将 PostgreSQL、OmniDB、pgBackRest、pgBadger、Prometheus、Grafana、Cockpit、Shell In A Box、tmate 等组件打包为一体，通过门户页提供集群启停、备份和日志报告入口。面向管理单节点 Linux PostgreSQL 服务器的管理员，支持 Debian 与 Ubuntu 发行版，采用 GPLv3 许可证。

  • 通过门户页展示 PostgreSQL 状态，并支持集群启停、备份和日志报告
  • 内置 pgBackRest 备份方案、Prometheus+Grafana 监控与 pgBadger 日志报告
  • OmniDB 提供用户管理、DDL 操作和交互式 SQL shell；tmate 支持基于令牌的终端共享

适用场景（解读层）

  • 在单节点 Linux 服务器上集中部署和运维 PostgreSQL 实例
  • 为 DBA 提供网页端的 SQL 执行、集群管理与监控仪表盘
  • 需要预配置备份（pgBackRest）和日志报告（pgBadger）的 PostgreSQL 部署场景
