Rust 编写的分布式内存数据库，兼容 PostgreSQL 并支持插件

综述（解读层）

Picodata 是一个用 Rust 编写的 PostgreSQL 兼容分布式 DBMS，以插件机制扩展功能。它基于 shared-nothing 架构，将数据划分到各自独占 CPU 核心的独立进程中，并在 SQL 层和通信协议层面与 PostgreSQL 兼容。官方为 Debian、Ubuntu 及 RHEL 系发行版提供预编译包，单实例只需一条 picodata run 命令即可运行，跨主机组建集群通过 --peer 参数指向已有节点完成。

  • 与 PostgreSQL 兼容：支持 SQL 语法和通信协议（wire-compatible）
  • 基于 shared-nothing 架构，数据划分到运行于独立 CPU 核心的进程
  • 以 Rust 实现，内置插件机制扩展功能

适用场景（解读层）

  • 需要分布式部署且沿用 PostgreSQL 客户端与生态的场景
  • 通过官方预编译包在 Debian、Ubuntu 或 RHEL 系 Linux 上搭建数据库环境
  • 通过两条命令在不同主机上组建基础分布式集群
