🧭 简介解读层（AI·证据行可回查）

PHP 编写的数据库脱敏 CLI 工具与库，按 YAML 配置替换敏感字段

综述（解读层）

该工具面向需要在开发环境中使用生产数据库副本的开发者，通过命令行读取 YAML 配置，将数据库中的个人数据替换为随机但格式合理的数据。它可作为 Composer 依赖安装，也可通过 Docker 运行；支持 MySQL、PostgreSQL、SQL Server 等驱动，提供 guess-config 命令自动探测疑似敏感列并生成配置。截断表时会停用外键约束，可能导致外键不一致。

  • 提供 anonymize 命令，依据 YAML 配置对指定表和字段进行数据替换
  • 内置 Constant 与 Faker 两类生成器，支持 locale、unique、optional、date_format 等选项
  • 提供 guess-config 命令，扫描各表各列并自动生成疑似敏感字段的配置文件

适用场景（解读层）

  • 将生产数据库导出用于开发或测试前的个人数据脱敏处理
  • 在 PHP 项目中作为 Composer 依赖集成 anonymization 流程，或通过 Docker 镜像在非 PHP 环境运行
  • 对包含姓名、出生日期、社保号等疑似敏感列的数据库自动生成初始脱敏配置
