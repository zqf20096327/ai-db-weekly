命令行 SQL 客户端，通过统一 URL 连接多种数据库与数据文件格式

综述（解读层）

rsql 是一个用 Rust 编写的命令行 SQL 客户端，通过统一的连接 URL（如 postgresql://、parquet://、csv://）访问 20 多种数据源，用标准 SQL 查询数据库、本地文件和远程存储。支持交互式模式（语法高亮、自动补全、历史记录）与单次执行模式，结果可输出为 ascii、json、csv 等多种格式。适合需要在命令行中查询多类数据源的用户。

  • 通过统一 URL 方案连接数据库、文件格式与云端存储，支持 PostgreSQL、MySQL、SQLite、DuckDB、JDBC、Parquet、CSV、Excel 等数据源
  • 支持 gzip、brotli、bzip2 等压缩文件的自动识别与读取，并提供 15 种输出格式（ascii、json、csv、html、markdown 等）
  • 交互模式包含 SQL 语法高亮、关键字与表名自动补全、命令历史搜索，并支持直接执行 .sql 文件与内嵌 PostgreSQL/H2 运行

适用场景（解读层）

  • 连接多种关系数据库执行交互式查询或单次 SQL 语句
  • 直接用 SQL 查询 CSV、Parquet、JSON、Excel 等本地文件数据
  • 通过 --format 参数将查询结果转换为 JSON、CSV、Markdown 等格式，用于数据转换管道
