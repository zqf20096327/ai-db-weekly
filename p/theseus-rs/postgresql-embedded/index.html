在 Rust 应用中安装并运行嵌入式 PostgreSQL 的库

综述（解读层）

postgresql-embedded 是一个 Rust 库，用于在 Linux、macOS 和 Windows 上本地安装并运行 PostgreSQL，提供类似 SQLite 的嵌入式体验。它在运行时下载安装 PostgreSQL，也可启用 bundled 特性在编译期打包安装档案进二进制文件；PostgreSQL 以独立进程运行。适用于需要在应用内自含数据库的 Rust 开发者。

  • 支持运行时下载安装 PostgreSQL，或通过 bundled 特性在编译期将安装档案打包进二进制
  • 提供 async 与阻塞两种 API，支持临时端口、Unix socket、启动选项配置与语义化版本解析
  • 使用 #![forbid(unsafe_code)]，全部以安全 Rust 实现

适用场景（解读层）

  • 为 Rust 应用程序打包或按需安装本地 PostgreSQL 数据库
  • 测试环境中启动临时 PostgreSQL 实例（临时端口、按需安装）
  • 需要将数据库安装档案嵌入可执行文件进行分发的场景

Install and run a PostgreSQL database locally on Linux, MacOS or Windows. PostgreSQL can be bundled with your application, or downloaded on demand.
