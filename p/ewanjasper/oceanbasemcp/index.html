🧭 简介解读层（AI·证据行可回查）

通过 MCP 协议让 AI 助手直连 OceanBase（Oracle 模式）数据库的 Python+Java 混合服务器。

综述（解读层）

该项目是一个 MCP 服务器，为 Reasonix、Claude Code 等 AI 客户端提供 9 类数据库工具：SELECT 查询、列出/搜索表、查看表结构、索引、统计信息、执行计划、导出 PL/SQL 源码，以及带确认令牌的两阶段写操作。架构上由 Python 处理 MCP 协议，Java 常驻进程经 JDBC 保持数据库长连接，二者以 stdin/stdout 行协议通信。运行要求 Python 3.13+ 和 Java 8+，通过环境变量配置数据库地址与用户（格式为 用户名@租户名#集群名）。

  • 提供 9 个 MCP 工具：query_db、list_tables、get_table_schema、search_tables、get_table_indexes、export_source、explain_plan、get_table_stats，以及 preview_write/confirm_write 两阶段写操作
  • 采用 Python+Java 混合架构：Java 进程常驻内存（约 42MB）维持 JDBC 长连接，通过 stdin/stdout 行协议与 Python 通信，查询统一设置 15 秒超时
  • 内置安全机制：query_db 仅允许 SELECT，写操作需一次性确认令牌，查询结果默认限 1000 行、最大 10000 行

适用场景（解读层）

  • 在聊天界面内查询 OceanBase Oracle 模式数据库数据、排查问题
  • 浏览表结构、索引、统计信息与分析执行计划，用于 SQL 调优参考
  • 导出 PL/SQL 包、函数、存储过程源码到备份目录，用于源码备份与版本对比
