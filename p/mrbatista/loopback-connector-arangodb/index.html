LoopBack 框架的 ArangoDB 数据源连接器，基于 Node.js 实现。

综述（解读层）

该模块为 LoopBack 框架提供 ArangoDB 连接器，供 LoopBack 应用通过数据源配置访问 ArangoDB。2.x 版本仅支持 Node v4.x 与 v6.x；若使用 ArangoDB 2.8.x 需在配置中指定旧版本。项目自身测试默认连接 localhost:8529 的服务器，可通过项目根目录或用户主目录下的 .loopbackrc（JSON 格式）自定义连接设置，但该配置方式已被标记为弃用，应用内配置应参考 LoopBack 官方文档。仅当服务器启用认证时才需提供用户名和密码。许可证为 MIT。

  • 为 LoopBack 框架提供 ArangoDB 数据源连接器
  • 支持通过 JSON 格式的 .loopbackrc 文件自定义连接配置（host、端口、用户名/密码）
  • 针对 ArangoDB 2.8.x 提供旧版本兼容的配置选项

适用场景（解读层）

  • LoopBack 应用需要连接 ArangoDB 作为数据源
  • 使用 ArangoDB 2.8.x 的项目迁移至连接器 2.x 版本
  • 本地开发与测试时自定义 ArangoDB 服务器连接参数
