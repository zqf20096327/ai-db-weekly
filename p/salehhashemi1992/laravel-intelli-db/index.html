🧭 简介解读层（AI·证据行可回查）

基于 OpenAI 生成 Laravel 数据库相关 artisan make 组件的扩展包

综述（解读层）

该包为 Laravel 提供四条 AI 生成命令（ai:rule、ai:migration、ai:factory、ai:model），根据用户提供的描述调用 OpenAI API 生成验证规则、迁移、工厂与模型文件。需通过 Composer 安装、发布配置并在 .env 中配置 OPEN_AI_KEY，可选指定 gpt-4 等模型及 temperature 参数；描述缺省时会交互式询问，MIT 协议开源。

  • 实现 ai:rule、ai:migration、ai:factory、ai:model 四条命令，基于描述生成对应文件并放置于 Laravel 默认目录
  • 迁移命令支持 --table 选项读取目标表的 schema 以生成结果，并可用 --path 指定输出路径
  • 支持在 .env 中配置 OpenAI API Key、模型（如 gpt-4）及 temperature、frequency_penalty 参数

适用场景（解读层）

  • 在 Laravel 项目中根据文字描述生成自定义验证规则类（如唯一邮箱校验）
  • 按描述生成迁移文件，如向已有表添加列
  • 为指定模型生成包含 PHP DocBlock 注释的模型与工厂文件
