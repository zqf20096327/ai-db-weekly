面向具身智能与机器人的 Rust 嵌入式多模态数据库，单库支持向量、文本、空间与时序检索

综述（解读层）

MoteDB 是用 Rust 编写的嵌入式列式数据库，以单一库文件形式运行，无守护进程，面向具身智能与机器人场景。它通过 SQL 提供向量（DiskANN）、全文（BM25 倒排）、三维空间（i-Octree）和表格检索，并包含 MVCC 快照隔离、WAL 恢复、MCAP 导入与数据集快照等机制。项目处于 pre-1.0 阶段：Rust API 与存储引擎已稳定，SQL 覆盖面和多语言 FFI 仍在演进，Node.js 与 Go 绑定为 preview 状态。

  • 单引擎支持四种索引：表格 B-tree、向量 DiskANN（`ORDER BY col <-> ? LIMIT k`）、全文倒排（MATCH/BM25，含 RRF 混合检索与 snippet 摘要）、空间 i-Octree（ST_DISTANCE、KNN、半径搜索）
  • 提供 ASOF JOIN（帧与关节状态按时间戳对齐）、CREATE EPISODE TABLE 轨迹分段、COMMIT/EXPORT DATASET 快照固定与导出，以及 `motedb import mcap` 一键导入机器人记录（按 topic 建表、`_uid` 去重支持断点续导）
  • 内嵌 ACID：WAL 崩溃恢复、MVCC 快照隔离、mmap 零拷贝读取、zstd 压缩（约 40-50% 缩减）、Rust/Python SDK 标记为 stable，Node.js（napi-rs）与 Go（cgo）为 preview，支持禁用默认特性的精简边缘构建

适用场景（解读层）

  • 机器人在本机端（如 arm64 边缘设备）以嵌入式方式存储和查询多模态运行数据：图像/关节向量、传感器时序、日志文本与三维位姿
  • 将 MCAP 录制文件导入为可 SQL 查询的数据集，配合 ASOF JOIN 和 episode 分段做帧-状态对齐与轨迹检索分析
  • 在应用内构建混合检索（BM25 全文 + 向量 RRF 融合），或对不断演进的表打快照并导出为独立数据库文件用于数据集分发
