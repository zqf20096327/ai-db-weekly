面向 .NET Standard 的微型 ORM 框架，提供查询构建与 POCO 映射

综述（解读层）

Kros.KORM 是由斯洛伐克 Kros a.s. 开发的 .NET Standard 微型 ORM 框架，用于将查询结果物化为 POCO 对象并执行增删改。支持查询构建器、部分 Linq 方法到 SQL 的翻译、异步执行、通过特性或 Fluent API 配置映射、全局查询过滤器和值转换器。Linq 翻译目前不支持 Select、GroupBy、Join 等方法。可通过 NuGet 的 Kros.KORM、Kros.KORM.MsAccess、Kros.KORM.Extensions.Asp 三个包安装。

  • 提供查询构建器与 Linq 查询翻译（支持 Where、FirstOrDefault、OrderBy、Count 等），全部查询可异步执行并接受 CancellationToken
  • 支持 BulkInsert、BulkDelete 批量操作，用于大量数据的快速插入与更新删除
  • 支持 DataAnnotation 别名映射、约定式 ModelMapper 重定义、Fluent API 配置、全局查询过滤器、IValueConverter 类型转换与自定义值生成器

适用场景（解读层）

  • 需要将 SQL 查询结果映射为 POCO 对象并执行增删改的 .NET 应用
  • 需要批量插入/删除大量数据的场景
  • 希望实体定义与数据库映射分离（如领域层与基础设施层分层）的项目
