基于 KSP 生成实体元数据的 Hibernate Criteria 类型安全 Kotlin 查询封装库

综述（解读层）

Yawn 是 Hibernate Criteria Query API 的 Kotlin 封装，通过 KSP 为标注 @YawnEntity 的实体生成 TableDef/ColumnDef 元数据，以泛型携带类型信息，编译期约束查询列与比较值类型。适用于使用 Hibernate 的 Kotlin 项目；需提供 QueryFactory 实现接入现有 Hibernate 配置，采用 compileOnly 加 ksp 依赖方式引入。

  • 通过 KSP 为 @YawnEntity 实体生成表和列定义，类型信息以泛型形式包含在生成代码中
  • 编译期强制查询列属于被查询表或其 join 路径，并约束比较值的类型
  • 保留与 Hibernate Criteria API 基本一致的查询语法，支持投影到 data class

适用场景（解读层）

  • 在 Kotlin + Hibernate 项目中以编译期类型检查方式构建 Criteria 风格查询
  • 利用 IDE 补全和 Kotlin 重构工具查找、追踪列的所有使用点以辅助字段重构
  • 多模块 Gradle 项目中通过官方 Gradle 插件自动接入处理器
