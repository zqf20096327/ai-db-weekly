直接读取 MySQL InnoDB 数据文件的 Java 库与命令行工具

综述（解读层）

innodb-java-reader 提供 Java 库和命令行工具，用于直接读取 InnoDB 表空间文件（*.ibd），实现按主键/二级索引查找、范围查询、检查页面结构和生成页面热力图等只读功能，适用于需要绕过 MySQL 服务器进行数据导出的场景。要求行格式为 COMPACT/DYNAMIC、启用 innodb_file_per_table、页大小 16K；脏页未刷盘时结果可能不一致。

  • 支持按主键和二级键进行记录查找与范围查询，支持导出全表数据
  • 可检查页面信息并基于 LSN 或填充率生成页面热力图
  • 支持 COMPACT 和 DYNAMIC 两种行格式的页面解码，覆盖数值、字符串/二进制、日期时间和 BIT/ENUM/SET 等列类型

适用场景（解读层）

  • 从 MySQL 服务器卸载（offload）数据导出与查询负载
  • 分析 InnoDB 文件结构与页面分布，用于学习 InnoDB 内部机制
  • 生成页面热力图以查看数据文件中 LSN 分布与填充情况
