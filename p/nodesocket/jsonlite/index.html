基于 Bash 实现的免服务器、零配置 JSON 文档存储工具

综述（解读层）

JSONlite 是一个用 Bash 编写的 JSON 文档存储命令行工具，数据目录默认位于当前工作目录下的 jsonlite.data，文档经校验后以 UUID 命名保存并提供 get/set/count/delete/drop 等子命令。依赖 bash、uuidgen 及 JSON 格式化工具（python -m json.tool 或 yajl/json_reformat、jq），适合需要在命令行环境直接持久化 JSON 文档、不运行数据库服务的场景。

  • 提供 set、get、count、delete、drop 等子命令，set 支持参数传入、管道输入和从文件读取 JSON
  • 免服务器、零配置，数据目录可通过 JSONLITE_DATA_DIR 环境变量指定，文档以 UUID 命名并 pretty print 保存
  • 支持三种 JSON 格式化后端（json_reformat、jq、python -m json.tool），README 附带 1k 次写入基准数据

适用场景（解读层）

  • 在 shell 脚本或命令行中按文档 ID 读写和删除 JSON 文档
  • 以当前工作目录为沙盒存放结构化 JSON 数据的本地工具集成
  • 需要免安装数据库服务的轻量 JSON 文档持久化场景
📖 README 首段存档原文 · 程序抽取

JSONlite sandboxes the current working directory similar to SQLite. The JSONlite data directory by default is named jsonlite.data and each json document is validated and saved pretty printed as a uuid
