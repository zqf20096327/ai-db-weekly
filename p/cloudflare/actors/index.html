简化 Cloudflare Durable Objects 开发的框架

综述（解读层）

Cloudflare Actors 是一个用于开发 Cloudflare Durable Objects 的框架，处于活跃开发中。通过继承 Actor 类和装饰器（handler）来组织代码，提供生命周期方法、持久化属性、RPC 接口、SQL 迁移、多闹钟与重试工具等能力。使用者需在 Wrangler 配置中注册 SQLite 类并保持类名与绑定一致；单次请求约保持实例存活 10 秒。

  • 提供生命周期钩子、持久化属性和基于 MyActor.get('id') 的 RPC 调用接口
  • 支持对 SQLite 存储执行 SQL 迁移，以及按时间戳、延迟或 cron 设置多个闹钟
  • 包含指数退避加抖动的重试工具，可判断 Durable Object 错误是否可重试

适用场景（解读层）

  • 在 Cloudflare Workers 平台上构建有状态的 Durable Objects 应用
  • 需要定时任务/闹钟触发和 SQLite 持久化存储的服务端逻辑
  • 需要跨 Actor 实例 RPC 调用与实例管理的多实例场景
