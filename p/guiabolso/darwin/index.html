Go 语言的数据库模式演进库，以纯库形式管理 schema 迁移脚本

综述（解读层）

Darwin 是一个用于 Go 程序的数据库模式演进库，通过在代码中组织 Script 迁移列表来驱动数据库 schema 变更。它不提供命令行工具，迁移文件需自行用标准库读取构建。作者建议每个迁移只放一条语句，不提供降级迁移，回滚行为依赖数据库实现。适合希望在 Go 应用内嵌迁移逻辑的团队。

  • 以纯库形式提供，可在 Go 程序中直接调用运行迁移
  • 支持在同一 Script 中组织多条迁移语句，迁移可按 1.0、1.1 等版本号编排
  • 迁移列表可由标准库读取文件系统后自行构建

适用场景（解读层）

  • 在 Go 应用启动或部署流程中执行数据库 schema 变更
  • 从文件系统读取 SQL 迁移文件并在程序内组装后执行
  • 遵循每迁移一条语句、不做降级迁移的迁移管理流程
