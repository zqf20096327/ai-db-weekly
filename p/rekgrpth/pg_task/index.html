运行于 PostgreSQL 等数据库内部的后台作业调度器扩展

综述（解读层）

pg_task 是一个 PostgreSQL、Greenplum 和 Greengage 的作业调度扩展，以一组后台 worker 进程在数据库内部运行，无需外部守护进程或客户端库。用户通过向 task 表插入行来调度 SQL 命令，结果、错误和状态写回同一行。需将扩展加入 shared_preload_libraries 并重启；构建依赖 pg_config、C 编译器、make、curl 和 pcregrep。

  • 通过向 task 表插入行调度任务，执行 input 中的 SQL，结果写入 output、错误写入 error，状态按 PLAN→TAKE→WORK→DONE/FAIL 流转
  • 以 GUC 提供配置，支持 config、database、user、session 多级别设置，并可按数据库/角色配置任务组并发数与取行数等参数
  • 支持定时执行：可立即执行一次、延迟指定间隔执行，或在指定时间戳执行

适用场景（解读层）

  • 在 PostgreSQL、Greenplum 或 Greengage 数据库中按用户定义时间后台异步执行 SQL 命令
  • 需要以普通表 INSERT 方式管理任务并通过查询该表获取任务结果与状态的环境
  • 需在数据库实例内部完成调度、不希望维护外部调度进程的场景

PostgreSQL, Greenplum and Greengage job scheduler pg_task allows to execute any sql command at any specific time at background asynchronously.
