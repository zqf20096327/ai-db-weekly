🧭 简介解读层（AI·证据行可回查）

存储 Allure 2 结果并生成报告的服务器，提供 REST API 与 Web UI

综述（解读层）

该项目是一个自托管服务器，用于接收、存储与管理 Allure 2 测试结果，并生成 Allure 报告，通过 REST API 和服务端渲染的 Web UI 访问。仅支持 Allure 2 格式，不支持 Allure 1（XML）与 Allure 3。可经 Docker 镜像、Helm chart 或 Java 25 环境下的 Spring Boot Jar 部署，认证始终开启，首启需轮换 admin 临时密码后才能访问 API。

  • 仅接收 Allure 2 格式的 zip 压缩结果，按逻辑 path 键对报告及历史进行分组
  • 认证始终开启，含 GUEST/USER/ADMIN 三种角色、API Token（X-API-Token 请求头）及可选 OAuth2 登录
  • 提供 Docker 镜像（Docker Hub 与 GHCR）与 Helm chart，容器以 uid/gid 1000 非 root 运行，数据目录为 /allure

适用场景（解读层）

  • 集中存储 CI 产出的 allure-results 并生成与管理 Allure 报告
  • 在 Kubernetes 中通过 Helm chart 部署报告服务，配合 PostgreSQL 存储数据
  • 通过 REST API 或 GitHub Actions 上传结果并触发生成报告
