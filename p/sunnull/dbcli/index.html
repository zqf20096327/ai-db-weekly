🧭 简介解读层（AI·证据行可回查）

基于 .NET 的多数据库 SQL 命令行工具，面向 AI Agent 调用。

综述（解读层）

dbcli 是一个用 .NET 11 编写的命令行 SQL 执行器，支持 Dameng、MySQL、PostgreSQL、SQL Server、SQLite 五种数据库，通过 config.json 管理命名连接，并支持命令行参数覆盖。输入可来自 -e 内联语句、-f SQL 文件或 stdin，输出支持 text 与 json 两种格式。所有 SQL 在单个事务中执行，任一语句失败即整体回滚，并以退出码区分成功、SQL 失败、参数错误、连接失败。项目面向 AI Agent 调用场景，构建需 .NET 11 SDK，使用 SqlSugarCore 实现数据库访问，附带 73 个 MSTest 单元测试用例。

  • 支持 Dameng、MySQL、PostgreSQL、SQL Server、SQLite 五种数据库，连接字段统一
  • 输出提供 text 与 json 两种格式，json 模式下每条语句输出一个对象
  • 所有 SQL 在单事务中执行，全部成功提交、任一失败回滚，并以 0-3 退出码返回结果

适用场景（解读层）

  • AI Agent 通过命令行执行 SQL 并解析结构化 JSON 输出
  • 在脚本或流水线中批量执行 SQL 文件，依据退出码判断执行状态
  • 统一访问多种数据库（含达梦）的运维查询入口
