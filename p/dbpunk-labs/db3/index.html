🧭 简介解读层（AI·证据行可回查）

面向 Web3 的轻量 JSON 文档数据库，定期将文档归档至 Arweave

综述（解读层）

DB3 Network 是一个面向去中心化应用的 JSON 文档数据库，提供文档存储与查询，并周期性把数据 rollup 到 Arweave 实现长期保存。每份 JSON 文档需所有者签名，仅所有者可更新或删除。节点可通过 Docker 自托管，或经 db3.js 连接测试网节点，采用 Apache-2.0 许可。

  • 提供 Data Rollup Node 与 Data Index Node 两类角色，分别负责写入压缩归档与索引查询服务
  • 每个 JSON 文档由所有者签名，仅所有者可更新或删除
  • 提供 Docker 自托管部署、Web 管理界面与 db3.js SDK，测试网覆盖 Arweave、Polygon、zkSync、Scroll、Linea 等链

适用场景（解读层）

  • 为链上游戏、链上社交等去中心化应用存储和检索 JSON 数据
  • 自托管节点进行本地开发与测试
  • 通过 Arweave 归档实现数据的长期留存与节点故障后恢复
