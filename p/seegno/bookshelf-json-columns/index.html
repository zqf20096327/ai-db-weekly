Bookshelf.js 插件，声明式解析模型中的 JSON 格式列

综述（解读层）

bookshelf-json-columns 是一个 Bookshelf.js 插件，通过在模型上声明 jsonColumns 属性来指定哪些列以 JSON 格式解析，免去为每个模型手写 hook。通过 bookshelf.plugin() 注册后即可使用；它扩展了 Model 的 initialize 和 save 方法，若模型自定义这两个方法需手动调用原型。通过 npm 安装，MIT 许可。

  • 通过 jsonColumns 类属性（或 ES6 静态属性）声明 JSON 列
  • 以 Bookshelf 插件形式注册，扩展 Model 的 initialize 与 save 方法
  • 基于 knex，主题标签覆盖 postgresql、mysql、sqlite 等

适用场景（解读层）

  • 使用 Bookshelf.js 且表中含 JSON/JSONB 列的项目
  • 希望以声明式配置替代逐模型手写 hook 的团队
  • 需要覆盖 postgresql、mysql、sqlite 等多种数据库的 knex 场景
📖 README 首段存档原文 · 程序抽取

This Bookshelf.js plugin enables you to define which model columns have JSON format, preventing manual hook definition for each model with JSON columns.
