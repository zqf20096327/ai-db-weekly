面向 Apache Cassandra 的跨平台桌面数据库管理工具

综述（解读层）

AxonOps Workbench 是一款运行于 macOS、Windows 和 Linux 的桌面应用，用于管理 Apache Cassandra、DataStax Enterprise 和 Astra DB 连接，面向 Cassandra 开发者与 DBA。它提供 CQL 控制台、查询追踪、SSH 隧道连接，并可通过 Docker 或 Podman（需 Compose 插件）一键启动本地 Cassandra 集群——该依赖仅在运行本地集群时需要。支持 Homebrew 安装，每个版本发布附 CycloneDX 与 SPDX 格式的 SBOM 文件。

  • 提供带语法高亮、自动补全、查询历史和多标签的 CQL 控制台，并支持查询追踪与执行计划分析
  • 内置 SSH 隧道与系统钥匙串凭据管理，支持多集群连接和工作区配置的版本控制共享
  • 集成 Docker/Podman 以一键启动本地 Cassandra 集群，并提供 CLI 用于自动化及在命令行启动 CQLSH

适用场景（解读层）

  • 在本地通过容器编排快速启动 Cassandra 集群进行开发与测试
  • 连接远程或 Astra DB 集群执行 CQL 查询并分析查询性能
  • 通过 CLI 管理工作区与连接，将 CQLSH 操作集成到 CI/CD 流程中
