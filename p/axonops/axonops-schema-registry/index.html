综述（解读层）

AxonOps Schema Registry 是用 Go 编写的 Schema Registry，兼容 Confluent Schema Registry 的 REST API 与序列化客户端库，支持 Avro、Protobuf、JSON Schema 及 7 种兼容模式。它不依赖 Kafka 存储，而是使用 PostgreSQL、MySQL 或 Cassandra，并提供内置 RBAC、审计日志、数据契约、CSFLE 加密和 MCP 服务器。适用于希望以标准数据库存储模式、更换接入 URL 即可迁移的 Kafka 用户团队。

  • 兼容 Confluent Schema Registry REST API，支持 Avro、Protobuf（proto2/proto3）、JSON Schema 与 7 种兼容模式
  • 以 PostgreSQL、MySQL 或 Cassandra 作为存储后端，无需 Kafka；以单个约 50 MB 静态链接二进制发布
  • 内置 6 种认证方式、RBAC 角色、多目标审计日志、数据契约、DEK/KEK 注册表及 MCP 服务器（Beta）

适用场景（解读层）

  • 将现有基于 Confluent Schema Registry 的 Java/Go/Python 生产者与消费者迁移到以标准数据库为存储的注册表
  • 需要对模式注册表实施认证、RBAC、限流与写操作审计日志的团队环境
  • 需要在生产者端对敏感字段加密（CSFLE），或通过 MCP 让 AI 助手以自然语言操作模式的场景
