🧭 简介解读层（AI·证据行可回查）

Oracle 与 PostgreSQL 活动会话历史数据的图形化查看工具

综述（解读层）

ASH Viewer 是一个 Java 桌面应用，用于以图形方式查看 Oracle 和 PostgreSQL 数据库的活动会话历史数据。运行需下载二进制包并配置对应 JDBC 驱动，连接后可查看 Top Activity 图表及原始数据；通过双击可查看按 SQL 或会话 ID 的 ASH 细节。对 Oracle 标准版和 PostgreSQL，它以本地存储方式模拟 ASH；注意 v$active_session_history 属于 Oracle 诊断包，需要购买 ODP 许可证。

  • 提供类似 Oracle Enterprise Manager 性能页 Top Activity 的图形视图与下钻功能
  • 使用内嵌 Oracle Berkeley DB Java Edition 在本地存储 ASH 数据
  • 提供数据库口令的加密与容器存储设置，支持 AES 256 位加密和 Windows DPAPI

适用场景（解读层）

  • 监控 Oracle 或 PostgreSQL 数据库的活动会话与等待事件
  • 对特定 SQL 或会话 ID 下钻查看 ASH 明细
  • 在无 ODP 许可的环境（Oracle 标准版、PostgreSQL）中以本地模拟方式记录活动会话数据
