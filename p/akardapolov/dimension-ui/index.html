基于内置块列式数据库的时序数据采集、存储、可视化与分析桌面应用

综述（解读层）

Dimension UI 是一款用于采集、存储、可视化和分析时序数据的桌面应用，面向系统管理员、DBA、开发者和分析人员。数据实时采集后存入内置块列式数据库 Dimension-DB（含压缩与去重），可通过 JDBC 或 HTTP（Prometheus、JSON）接入外部数据源，并内置 Matrix Profile 与 ARIMA 算法。应用依赖 Dimension-DI、Dimension-DB 等组件，需 Java 25+ 并用 Maven 构建，运行于 Windows/Linux/macOS。

  • 支持实时采集时序数据，数据存入内置块列式数据库 Dimension-DB，具备压缩与去重
  • 通过 JDBC（PostgreSQL、Oracle、ClickHouse、DuckDB 等 8 种数据库）和 HTTP API（Prometheus、JSON）读取外部数据，无代码模式下自动生成 SQL
  • 内置 Matrix Profile 与 ARIMA 算法，用于异常检测、motif 发现和预测分析；支持 JMX 采集本地及远程 JVM 指标，并可生成 PDF 报告

适用场景（解读层）

  • 信息系统、硬件软件及数据库的实时监控与问题诊断
  • 负载与压力测试中的指标采集与结果报告生成
  • 通过 JDBC 直连外部数据库对时序和常规表数据进行无代码探索与多维分析
