Scala 3 类型安全 JDBC 库，用纯 SQL 字符串映射结果集

综述（解读层）

Squery 是面向 Scala 3 开发者的 JDBC 访问库：不提供查询 DSL 或隐藏连接层，SQL 以字面字符串书写，插值自动转为 prepared-statement 参数，结果行可解码为 case class、named tuple 等值。需自行提供 JDBC DataSource；查询在 run/runTransaction 中执行，支持事务隔离级别配置。附带 CLI 与构建插件，可从现有数据库生成行模型与 DAO。

  • 支持任意 JDBC 驱动，并为 PostgreSQL、MySQL、MariaDB、Oracle、H2、SQLite 内置数据库专用编解码器
  • 支持嵌套行、外连接可选行、三维以内 SQL 数组、UUID、Java time 类型及动态 SQL 组合
  • 提供代码生成（CLI 或 Mill/sbt 2/Deder 插件），用 Regenesca 原地更新生成定义并保留自定义成员

适用场景（解读层）

  • 需要书写原生 SQL 并获得类型安全结果解码的 Scala 3 应用
  • 在 JVM 或 Scala Native 上运行、需对接多种数据库的项目
  • 希望从既有数据库 schema 自动生成行模型与 DAO 代码的团队

Squery is a small Scala 3 library for type-safe JDBC access with plain SQL: no query DSL, no generated runtime layer, and no hidden connection management.
