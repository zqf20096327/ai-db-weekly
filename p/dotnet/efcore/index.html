.NET 的对象-数据库映射器，支持 LINQ 查询、变更跟踪与架构迁移

综述（解读层）

该仓库托管 .NET Foundation 下的 Entity Framework Core 与 Microsoft.Data.Sqlite 两个项目，由 Microsoft 维护，采用 MIT 许可证。EF Core 用于在 .NET 应用中将对象映射到数据库，通过 provider 插件 API 对接多种数据库，经 NuGet 安装对应数据库的 provider 包即可使用。

  • 支持 LINQ 查询、变更跟踪、更新和架构迁移
  • 通过 provider 插件 API 支持 SQL Server、SQLite、Azure Cosmos DB、MySQL、PostgreSQL 等数据库
  • 基于 NuGet 分发，可安装预构建包或从源码构建

适用场景（解读层）

  • 在 .NET 应用中以对象方式读写关系型或 Cosmos DB 数据
  • 需要架构迁移的数据库模型演进场景
  • 通过 Microsoft.Data.Sqlite 独立或配合其他数据访问库访问 SQLite
