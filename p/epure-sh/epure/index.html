自托管错误追踪服务，兼容 Sentry SDK，Rust 双容器部署

综述（解读层）

Epure 是一个面向 1-2 人开发的 SaaS 团队的错误追踪服务，用 Rust 编写，由 ingest 和 Postgres 16 组成的两个容器运行。保留官方 Sentry SDK，仅更换 DSN 即可接入；需将 tracing、replay、profiling 采样率设为 0，因其不存储这些数据。支持 docker compose 快速启动，亦提供 $29/月起的云服务。当前版本 v0.2.2，引擎采用 AGPL-3.0，CLI 与 MCP 客户端为 Apache-2.0。

  • 兼容官方 Sentry SDK，更换 DSN 即可接入，同一 DSN 支持各语言 SDK
  • 两个容器部署（ingest + PostgreSQL 16），无 Kafka、Redis 或 ClickHouse 依赖
  • 提供 MCP 服务器与 agent skills，使编码 agent 可读取 issue；包含分组 issue、sourcemaps、回归检测、Spike 防洪、RBAC 与 PostgreSQL RLS

适用场景（解读层）

  • 1-2 人团队的 SaaS 项目需要自托管错误追踪
  • 已有 Sentry SDK 接入、希望保留现有埋点并更换后端
  • 通过 Claude Code 等 agent 的 MCP/skills 集成读取错误 issue 辅助修复
