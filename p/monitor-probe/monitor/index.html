基于 Rust/axum/SQLite 的自托管服务器监控探针系统

综述（解读层）

monitor 是一个自托管的服务器监控项目，由 hub（后台、API、公开页宿主）与 Linux agent 组成，agent 通过 WebSocket 上的 JSON-RPC 2.0 连接 hub，数据存储于 SQLite。适用于需要自托管节点状态展示与通知推送的运维场景；文档站与主题站提供安装、配置与主题安装说明。

  • agent 通过 WebSocket 上的 JSON-RPC 2.0 与 hub 通信，hub 使用 axum 与 SQLite 构建
  • 提供秒级实时数据展示，后台、API 与公开页由 hub 承载
  • 支持节点掉线、流量、到期与登录事件通知，推送到 Telegram 或自定义 Webhook

适用场景（解读层）

  • 自托管多台 Linux 服务器的运行状态监控
  • 搭建面向访客的公开状态页（公开页主题可在线预览并安装）
  • 通过 Telegram 或 Webhook 接收节点掉线、流量、到期与登录通知
