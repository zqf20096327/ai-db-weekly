DuckDB 的 JDBC 驱动，供 Java 程序通过 JDBC 接口访问 DuckDB

综述（解读层）

该仓库是 DuckDB 数据库的 JDBC 驱动实现，README 主要面向驱动开发者：构建需安装 JDK 并设置 JAVA_HOME，通过 make release 生成主 jar 与测试 jar，用 make test 运行测试，另有可选的字符串写入性能基准（make stress）及 UDF、JFR 内存监控示例文档。未包含最终用户的安装使用说明。

  • 支持通过 make release 构建驱动 jar，make test 运行 JDBC 测试套件
  • 提供可选的字符串写入性能基准，可通过 PERF_ROWS 和 PERF_SAMPLES 调整负载
  • 包含标量函数（UDF）用法示例与 JFR 内存监控使用文档

适用场景（解读层）

  • 在 Java 应用中通过 JDBC 连接 DuckDB 数据库
  • 开发者构建和测试该 JDBC 驱动本身
📖 README 首段存档原文 · 程序抽取

It's required to have a JDK installed to build. Make sure the JAVA_HOME environment variable is set.
