DuckDB 的 Rust 语言绑定，提供类 rusqlite 的类型安全 API

综述（解读层）

duckdb-rs 是 DuckDB 的 Rust 封装，面向在 Rust 应用中使用 DuckDB 的开发者。它通过 libduckdb-sys 提供 C API 的 Rust 声明，支持类型安全查询、Arrow/Parquet/JSON/CSV 读写，以及用 Rust 编写带自定义标量与表函数的 DuckDB 扩展。构建时可选用 bundled 特性从源码编译 DuckDB，避免依赖系统库；另有针对 v2 C API 的 beta 版 crate duckdb-neo。

  • 提供类型安全查询 API，风格参考 rusqlite
  • 原生读取和写入 Arrow、Parquet、JSON、CSV 格式
  • 支持以 Rust 编写 DuckDB 扩展，含自定义标量函数与表函数

适用场景（解读层）

  • 在 Rust 应用中通过 SQL 创建表、插入与查询数据
  • 将 Arrow RecordBatch、Parquet 等数据直接接入 DuckDB SQL 查询
  • 用 Rust 开发可加载或静态链接的 DuckDB 扩展
