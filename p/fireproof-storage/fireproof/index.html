运行于浏览器的嵌入式文档数据库，以哈希历史实现加密同步

综述（解读层）

Fireproof 是一个轻量级嵌入式文档数据库，在浏览器中运行，通过 use-fireproof 或 @fireproof/core npm 包安装，提供 React hooks 与独立核心 API 两种统一接口。数据以内容寻址的加密 blob 存储和复制，基于 Merkle 哈希树时钟提供版本历史与多写入者同步。适用于 JavaScript 运行环境（浏览器、Node、Deno、Bun）。

  • 提供 useLiveQuery 与 useDocument React hooks，支持实时查询与自动持久化
  • 以内容寻址加密 blob 存储数据，使用哈希历史实现因果一致性与账本完整性校验
  • 支持 TypeScript，可在 Deno、Bun、Node.js 和浏览器中运行，包内不含 wasm

适用场景（解读层）

  • AI 生成的应用与快速原型（README 提供面向 LLM 代码生成的文档入口）
  • 基于 CRDT 的协作编辑与离线/本地优先应用
  • 通过对象存储进行端到端同步的个性化与配置存储
