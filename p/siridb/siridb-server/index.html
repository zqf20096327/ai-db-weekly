🧭 简介解读层（AI·证据行可回查）

SiriDB 服务器，一个采用非全局索引机制、可动态添加节点的时序数据库。

综述（解读层）

SiriDB server 是开源时序数据库 SiriDB 的服务端实现，以 C 语言编写。它不依赖全局索引来管理时间序列，并支持在运行中向数据库添加服务器资源。提供 Ubuntu deb 包、源码编译与 Docker 镜像三种安装方式，创建或扩容数据库可通过 siridb-admin 工具或 HTTP API 完成。配置支持文件（默认 /etc/siridb/siridb.conf）与环境变量两种途径。

  • 采用无全局索引的机制运行，并支持在运行过程中添加服务器资源以扩展数据库
  • 提供 C/C++、Python、Go、Node.js 原生连接器，另有支持 JSON、MsgPack、Qpack、CSV、Socket.io 的 SiriDB HTTP 接口
  • 支持配置文件与环境变量两种配置方式，可通过 Docker 镜像直接运行（默认端口 9000）

适用场景（解读层）

  • 存储和查询时间序列数据，使用其自带查询语言对时间序列进行动态分组分析
  • 通过 Grafana 数据源插件在 Grafana 中展示 SiriDB 数据
  • 使用 SiriDB Prompt 命令行客户端（含自动补全）向数据库加载 JSON 或 CSV 数据
