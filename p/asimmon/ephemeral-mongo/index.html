🧭 简介解读层（AI·证据行可回查）

在 .NET 中按需启动临时 MongoDB 服务器的测试库，无需 Docker。

综述（解读层）

EphemeralMongo 是一个 .NET 库，在运行时下载 MongoDB 二进制文件并启动临时 mongod 进程，用于集成测试和本地调试。可通过选项配置数据目录、端口、副本集等；释放 runner 时自动停止进程并删除数据。支持 MongoDB 6-9、Community/Enterprise 版及三大操作系统，需网络下载或自行提供二进制文件。

  • 运行时自动下载 MongoDB 二进制文件并经 SHA256 校验，无需 Docker 或预装 MongoDB
  • 支持 MongoDB 6/7/8/9、Community 与 Enterprise 版本、单节点副本集（事务和变更流）、mongoimport/mongoexport
  • 提供实验性 MongoRunnerPool 复用 mongod 进程，runner 释放时自动清理进程与数据目录

适用场景（解读层）

  • 在 .NET 集成测试中为每个测试启动隔离的临时 MongoDB 数据库
  • 为本地开发环境快速搭建一个可用的 MongoDB 服务器
  • 在 CI 中运行依赖 MongoDB 的测试，可缓存二进制目录避免重复下载
