基于 Cube 的开源语义层与指标管理数据工程平台

综述（解读层）

Synmetrix（原 MLCraft）是基于 Cube 构建的开源数据工程平台与语义层，用于集中管理指标：通过 SQL 和 Cube 数据模型定义指标与维度，支持定时报告、告警、版本控制、RBAC 及 SQL API 供 BI 工具接入。部署采用 Docker Compose（含 PostgreSQL 存储），硬件要求 8GB 内存、30GB 磁盘，Apache-2.0 许可。

  • 基于 Cube 实现多阶段 SQL 数据建模，支持指标、维度、粒度与关系定义
  • 提供 SQL API 接口与 GraphQL 端点，可对接 BI 工具与应用
  • 内置预聚合与缓存机制，生产环境使用 Cube Store 作为缓存与查询执行层

适用场景（解读层）

  • 组织内指标统一管理与自助式数据探索
  • 对接 BI 工具进行报表与数据分析
  • 通过 API 在应用中嵌入分析功能，或为 LLM 提供语义层
