🧭 简介解读层（AI·证据行可回查）

自托管的 Proxmox 管理面板，通过 SSH 无代理采集监控、备份配置并内置 AI 代理。

综述（解读层）

Reanimator 是面向 Proxmox 环境的自托管 Web 面板，适合自行运维 Proxmox 节点的管理员。它通过 SSH 无代理方式连接节点（无需在目标服务器装插件），实时展示 CPU、内存、磁盘用量，自动备份 /etc/network、corosync、存储配置等并生成 Markdown 恢复指南；数据存于本地 SQLite。内置 AI 代理需自备 Ollama 实例，支持经网页或 Telegram 执行查询、建 VM、跑命令等操作。默认登录 admin/admin，需首登修改。

  • 通过 SSH 以无代理方式连接 Proxmox 节点，自动检测集群，数据存储在本地 SQLite
  • 自动备份 /etc/network、/etc/corosync、存储配置、crontabs、SSH 密钥，并为每次备份生成 Markdown 恢复指南，支持浏览器内对比与下载
  • 内置 AI 聊天代理运行于用户自己的 Ollama 实例，可执行查询状态、创建 VM、运行 SSH 命令、管理服务等操作，并支持 Telegram 控制与基于事件的自动响应（Reflex 系统）

适用场景（解读层）

  • 集中监控多个 Proxmox 节点的 CPU、内存、磁盘用量与集群状态
  • 自动化备份节点关键配置文件并在需要时按生成的指南恢复
  • 通过网页聊天或 Telegram 以自然语言指令管理 VM、容器与节点服务
