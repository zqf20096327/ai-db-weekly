使用 Docker 编排 SEI 环境的基础设施即代码项目

综述（解读层）

SEI-Docker 用于以 Docker 与 docker-compose、cattle、kubernetes 编排器部署 SEI 环境，包含 44+ 容器与 230+ 环境变量的配置。项目分 dev、infra、containers 三个部分，分别面向开发者调试源码、基础设施人员搭建完整环境以及自定义镜像构建。运行前提为 SEI 源码、docker 与 docker-compose。

  • 提供 dev、infra、containers 三个目录，分别支持本地开发调试、完整环境部署和自建镜像推送自有 Registry
  • 支持 mariadb、sqlserver、oracle 数据库及 openldap、solr、memcached、邮件模拟等组件的配置
  • 各目录包含自动化测试，可通过 make 命令分别执行容器、开发环境与基础设施的测试

适用场景（解读层）

  • 开发者本地搭建挂载 SEI 源码并启用 xdebug 的调试环境
  • 搭建测试、培训或评估用途的 SEI 环境，可生成 Kubernetes 或 Cattle 配置部署到本地集群
  • 安全人员对 SEI 实例进行评估与漏洞排查
