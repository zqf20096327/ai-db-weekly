Android 上的 SQLite 访问库，基于 DAO 与 Transformer 模式封装 CRUD 操作。

综述（解读层）

EasySQLite 是一个 Android 平台的 SQLite 数据访问库，通过 SQLiteTransformer<T> 实现实体与数据库行的转换，通过 SQLiteDelegate<T> 提供已实现的增删改查基础方法，开发者可继承该类扩展自定义查询。它还提供 SQLiteHelper 构建器替代 SQLiteOpenHelper 管理建表与版本，支持回调自定义 onCreate/onUpgrade。适用于需要在 Android 项目中以 DAO 模式组织 SQLite 数据层的开发者。

  • SQLiteDelegate 内置 create、update、read、readAll、delete、deleteAll 六个 CRUD 方法，可通过继承扩展更多查询
  • SQLiteTransformer 接口负责实体对象与数据库记录的转换，支持外键关联对象的映射
  • SQLiteHelper 采用 builder 模式创建，可配置表、数据库名称、版本，并允许通过回调自定义建表与升级逻辑

适用场景（解读层）

  • Android 应用中以 DAO 模式管理 SQLite 数据表的基础增删改查
  • 包含外键关联的多表数据库，按声明顺序建表并映射关联实体
  • 需要自定义数据库创建或升级逻辑，同时复用默认 CRUD 封装的项目
