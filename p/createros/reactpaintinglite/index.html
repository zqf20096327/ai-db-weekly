面向 iOS/Objective-C 的 SQLite3 轻量 ORM 框架，支持对象映射与 PQL 条件查询。

综述（解读层）

Paintinglite 是一个 Objective-C 编写的 SQLite3 数据库框架，通过 POJO 与数据表建立映射，支持自动生成 SQL、手写 SQL 和 XML 配置三种操作方式。提供查询结果封装为字典数组或对象、条件占位符查询、模糊查询、事务及数据库压缩备份等能力，通过 CocoaPods 安装，供 iOS 开发者在应用内做本地数据持久化。

  • 支持 ORM 对象映射，可依据对象自动建表、更新表结构并生成 UUID/ID 主键
  • 支持原生 SQL、XML 配置及自定义 PQL 占位符条件查询、模糊查询
  • 支持事务操作、线程保护机制，以及数据库压缩、备份和向 MySQL、SQL Server 移植

适用场景（解读层）

  • iOS 应用中需要将查询结果直接映射为 Objective-C 对象的本地存储场景
  • 需要用条件占位符或模糊查询检索 SQLite 数据的场景
  • 需要备份、压缩 SQLite 数据库或移植到 MySQL/SQL Server 的场景
