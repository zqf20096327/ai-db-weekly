🧭 简介解读层（AI·证据行可回查）

基于 sql.js 的 FiveM 独立资源，通过 Lua 导出函数读写 SQLite 数据库。

综述（解读层）

u5_sqlite 是一个面向 FiveM 服务器开发者的独立资源，封装 sql.js 并以 Lua 导出形式暴露数据库操作接口。它将整个数据库存于单个文件中，无需单独安装数据库服务或建立连接。查询默认使用参数化占位符（前缀冒号），也支持 rawWhere 参数传入原始 SQL 字符串。导出函数供服务器端脚本调用。

  • 提供 createTable、insert、update、delete、select 等 Lua 导出函数，select 返回以列名为键的对象数组
  • 提供 executeRaw 和 executeRawWithParams，可执行任意 sql.js 支持的 SQL 查询并传递参数化占位符
  • 数据库存储在单个文件中，可备份和转移；where 条件默认参数化，可通过 rawWhere=true 传入原始字符串

适用场景（解读层）

  • FiveM 服务器脚本中需要通过 Lua 进行 SQLite 数据读写
  • 需要无独立数据库服务、单文件存储的持久化方案
  • 需要执行参数化 SQL 或复杂原始查询的服务端脚本
