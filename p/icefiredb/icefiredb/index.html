🧭 简介解读层（AI·证据行可回查）

面向 Web2 与 Web3 的去中心化数据库，支持 Redis RESP 与 MySQL 协议接口

综述（解读层）

IceFireDB 是用 Go 编写的去中心化 KV 数据库，提供 Redis RESP 兼容命令与 MySQL 协议接口，覆盖字符串、哈希、列表、集合、有序集合等数据类型。存储层支持 goleveldb、hybriddb、badger、IPFS、OSS、CRDT 等后端并按 GA/Beta/Experimental 分级，写入经 Raft 日志落盘。适合需要在既有 Redis/MySQL 应用上叠加分布式同步与去中心化存储的团队；SCAN 类游标语义与 Redis 有差异需注意。

  • 支持 Redis RESP 协议的多数据类型命令（Strings/Hashes/Lists/Sets/Sorted Sets）及 SCAN/HSCAN 等扫描命令
  • 存储后端矩阵分级：goleveldb 与 hybriddb 为 GA，badger、ipfs-synckv 为 Beta，IPFS、OSS、CRDT 为 Experimental，均接入 CI
  • 写入经 Raft 日志并默认 fsync 后确认，可经 --nosync 关闭同步换取速度；混合共识结合 Raft（站点内）与 P2P CRDT（跨站点）

适用场景（解读层）

  • 以 Redis 客户端直接接入、需 Raft 分布式一致性或 CRDT 跨站点同步的 KV 存储场景
  • 通过 IceFireDB-Redis-Proxy / SQLProxy 为既有 Redis、MySQL 应用引入 P2P 数据同步
  • 需要 IPFS 等去中心化存储后端的 Web3 数据持久化场景
