基于 PostgreSQL 17 扩展的记忆型 DBMS，用于机构长期记忆与人机知识共享检索。

综述（解读层）

MaluDB 是以 C 语言实现的 PostgreSQL 17 扩展（maludb_core），面向需要长期机构记忆、人机知识共享与上下文召回的数据库场景。它提供源→声明→事实→记忆管线、双时态时间（有效时间+事务时间）、超取代（修正不覆盖历史）、图遍历、FTS+pg_trgm 模糊匹配与三阶段授权检索。本仓库为 Ubuntu 24.04/PG17 线，仅做修复，新开发位于 maludb/maludb-core-26。安装通过克隆仓库运行 bootstrap 脚本从源码构建并自动建库装扩展。

  • 以 C 语言实现为 PostgreSQL 17 扩展，依赖 pgvector、pgaudit、pg_partman，提供 Python/Node.js/PHP/C 四种驱动
  • 提供双时态时间、超取代机制（修正生成新版本并带 supersession 边，不覆盖历史）、强制溯源账本（malu$derivation_ledger）与三阶段授权检索
  • 包含图导入/路径查询/社区分析、租户级 principal 作用域控制、遗忘接口（maludb_forget_document/chunk）及 REST/SSE/MCP 等配套服务进程

适用场景（解读层）

  • 为机构构建带溯源与版本历史的长期记忆库，支持修正留存与法律保留（legal hold）
  • 人与 AI 共享知识并通过统一关系/图优先检索面进行上下文召回
  • 需租户隔离与读写授权管控的多主体记忆/文档检索服务
