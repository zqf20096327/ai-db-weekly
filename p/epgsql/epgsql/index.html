🧭 简介解读层（AI·证据行可回查）

Erlang 的 PostgreSQL 客户端库，基于前端/后端协议实现请求流水线。

综述（解读层）

epgsql 是一个用 Erlang 编写的 PostgreSQL 客户端库，源自 wg/epgsql 的异步分支，现为社区共同维护版本。它提供 epgsql/epgsqla/epgsqli 三套 API：同步调用、Erlang 消息返回结果、以及逐行增量消息。内部维护客户端请求队列以利用协议的流水线特性，同一连接可混用三套接口。配套的 pgapp 项目可提供基于 poolboy 的连接池和自动重连。默认使用未命名语句，同一连接并发使用会失败。

  • 提供 epgsql、epgsqla、epgsqli 三套 API，分别以同步返回、Erlang 消息、逐行增量消息方式交付结果，三套接口可在同一连接上任意组合使用
  • 利用 PostgreSQL 前端/后端协议的请求流水线特性，维护内部请求队列，无需等待上一命令响应即可发送下一请求；支持多条已解析语句批量执行
  • 支持简单查询、扩展查询（$1/$2 参数绑定、二进制格式返回整数/浮点/布尔等类型）、命名预编译语句的 parse/bind/execute 流程、SSL 连接（true/required 选项）、流复制协议及可插拔数据类型编解码器

适用场景（解读层）

  • Erlang/OTP 应用需要连接 PostgreSQL 执行查询、参数绑定或预编译语句的场景
  • 需要异步或逐行处理大量查询结果、避免进程信箱溢出的场景（epgsqla/epgsqli 与 socket_active）
  • 需要连接池、数据库断线自动重连且不向 supervisor 树传播崩溃的应用，可配合 epgsql/pgapp 使用
