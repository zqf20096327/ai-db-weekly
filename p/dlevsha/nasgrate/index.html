🧭 简介解读层（AI·证据行可回查）

基于 PHP PDO 的控制台数据库 schema 迁移工具，支持自动生成 diff 迁移。

综述（解读层）

Nasgrate 是一款 PHP 控制台工具，用于组织数据库 schema 迁移流程，通过 PDO 驱动支持 MySQL、MS SQL、PostgreSQL、Oracle 等数据库。迁移文件采用带 -- UP --/-- DOWN -- 分区的 SQL 文件，可基于已保存的数据库状态快照自动生成 schema diff（目前仅限 MySQL），并提供命令行与 Web 界面查看迁移。需 PHP 5.3.0 及以上并启用 PDO 扩展，官方推荐以 Docker 方式运行。

  • 迁移文件使用原生 SQL 语法，每个迁移包含 UP（升级）和 DOWN（回滚）两个分区，支持 Skip 标记跳过指定迁移
  • 每次创建迁移时保存数据库 schema 快照，可自动生成包含 schema 变更差异的迁移文件（当前仅支持 MySQL）
  • 提供 status、generate、diff、up、down 等命令，并可通过内置 PHP 服务器以 Web 界面查看已执行与未执行的迁移

适用场景（解读层）

  • 在 prod 与 test 等多个数据库之间生成 schema 差异迁移文件（database 策略需配置Secondary connection）
  • 团队通过 git 等版本控制系统共享迁移文件，可将 migrations 目录配置到项目路径下统一管理
  • PHP 项目中需要以命令行或 Docker 方式执行数据库结构升级与回滚的场景
