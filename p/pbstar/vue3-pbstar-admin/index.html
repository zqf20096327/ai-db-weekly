基于 Vue3 与 Node.js 的前后端一体后台管理系统脚手架

综述（解读层）

这是一个包含前端与后端的后台管理项目：前端使用 Vue3、Vite、Element-Plus、Pinia，后端使用 Express 与 MySQL，内置用户体系以及页面和接口的权限配置，权限数据以 JSON 文件存储，并在 logs 目录记录操作日志。部署时前端打包产物放入 public 文件夹，由后端服务器统一提供。适用于需要自定义开发后台功能的场景。

  • 前端采用 vue3 + vite + element-plus + pinia，后端采用 Express + MySQL
  • 提供前置/后置路由守卫、axios 拦截器封装及接口鉴权 token 机制
  • 角色权限配置以 JSON 文件存储，并在 logs 文件夹记录操作日志

适用场景（解读层）

  • 需要用户登录与页面/接口权限配置的后台管理开发
  • 前后端同仓库、由 Node.js 服务统一托管前端静态资源的部署方式
  • 在基础用户体系和权限模块之上进行自定义业务扩展
📖 README 首段存档原文 · 程序抽取

Vue3-pbstar-admin 是一个简洁的后台解决方案，提供了基础的用户体系和页面接口权限配置，方便进行自定义开发，避免不必要的代码冗余。该方案结合了 Vue3、Element-Plus、Pinia 和 Vite 等先进技术，实现高效的页面布局、状态管理和构建体验。同时，后端采用基于 Node.js 的 Express 框架和 MySQL 数据库，提供稳定的数据存储和高效的后台服务。
