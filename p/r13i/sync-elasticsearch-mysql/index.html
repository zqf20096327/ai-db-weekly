基于 Logstash 的 MySQL 到 Elasticsearch 数据同步示例项目

综述（解读层）

该项目演示如何用 Logstash 将 Elasticsearch 与 MySQL 连接：从零构建索引，并持续监控数据库记录的增、改、删并同步到 Elasticsearch。组件包括 MySQL 8.0、Elasticsearch 7.9.3、Logstash 7.9.3、Kibana 7.9.3，通过 Docker Compose 部署。README 注明这是原型，不适用于生产环境。

  • 支持从零构建 Elasticsearch 索引
  • 通过 Logstash JDBC 输入插件持续监控并同步记录的 create、update、delete 变更
  • 使用 Docker Compose 部署，可整体启动或按服务分别启动

适用场景（解读层）

  • 学习 MySQL 与 Elasticsearch 之间的数据同步机制
  • 搭建包含 MySQL、Elasticsearch、Logstash、Kibana 的本地开发/原型环境
  • 参考删除记录与全量索引的场景实现
