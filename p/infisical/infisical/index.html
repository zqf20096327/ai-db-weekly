综述（解读层）

Infisical 是一个采用 MIT 许可（ee 目录除外）的开源安全基础设施平台，提供密钥管理、证书管理、KMS、特权访问管理和 AI Agent 凭据代理等功能。支持 Docker 自托管或使用 Infisical Cloud，可通过 CLI、SDK（多语言）和 API 交互，适用于开发团队与安全运维场景。

  • 提供密钥集中管理，含版本控制、定时轮换、动态密钥生成与泄漏防护（Honey Tokens）
  • 支持内部与外部 CA 的 X.509 证书生命周期管理，含 ACME/EST/SCEP 注册与代码签名
  • 提供 AI Agent 凭据代理（Agent Vault），在代理边界附加真实凭据，并记录加密会话日志

适用场景（解读层）

  • 为多环境（开发/生产）应用集中管理配置与密钥，并同步至 GitHub、Vercel、AWS、Terraform 等平台
  • 在 Kubernetes 中通过 Operator 或 Agent 向工作负载注入密钥并自动重载部署
  • 管理数据库、SSH、RDP 等基础设施的特权访问，含审批、会话录制与定时凭据轮换
