面向 MonetDB 的 TPC-H 基准测试辅助工具集

综述（解读层）

该仓库为 TPC-H 基准在 MonetDB 上的使用提供辅助：包含自动化脚本，完成数据生成、建库（含 schema 与约束）和数据加载；附 22 条查询文件、对应预期结果文件及 dbgen 子模块。用户需递归克隆仓库，并用 bash、unzip 等工具及已运行的 MonetDB。当前仅支持 MonetDB；仓库不含基准规格说明，也不含实际执行基准查询的代码。

  • 提供 setup-tpch-db 脚本，自动化 TPC-H 数据生成、建库与数据加载流程
  • 包含基准全部 22 条查询的 SQL 文件及各自的预期结果文件，可用于结果比对
  • 以子模块形式集成 dbgen 数据生成工具（维护于 eyalroz/tpch-dbgen）

适用场景（解读层）

  • 为 MonetDB 准备含 TPC-H 模式与数据的测试数据库
  • 生成指定 scale factor 的 TPC-H 数据集并加载入库
  • 将查询执行结果与预期结果文件进行 diff 比对以做一致性检查
📖 README 首段存档原文 · 程序抽取

This repository facilitates the use of the TPC-H benchmark (or, more precisely, the TPC-H benchmark data and individual queries) for DBMS-related work in and around the MonetDB in-memory DBMS
