综述（解读层）

该项目同步 sequelize/sequelize 的教程与指南并翻译为中文，覆盖入门、模型、查询、关联、事务、迁移等章节，同时提供 v4 至 v7 多版本文档链接与主版本升级日志。面向需要在中文环境下查阅 Sequelize 用法的 Node.js 开发者。项目注明 v7 处于 alpha 阶段、API 尚未稳定，生产环境建议参考 v6 文档；API 参考部分仍为英文。

📖 README 首段存档原文 · 程序抽取

Sequelize 是一个易用且基于 promise 的 Node.js ORM 工具 适用于 Postgres, MySQL, MariaDB, SQLite, Microsoft SQL Server, Amazon Redshift 和 Snowflake’s Data Cloud. 它具有强大的事务支持, 关联关系, 预读和延迟加载,读取复制等功能.

🔌 适配哪些库db_scan 程序判定

MariaDB、MySQL、PostgreSQL、SQL Server、SQLite
