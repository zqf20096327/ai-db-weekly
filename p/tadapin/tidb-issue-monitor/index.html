🧭 简介解读层（AI·证据行可回查）

用 GitHub Actions 监控 pingcap/tidb 版本相关 Bug Issue 并推送 Slack 通知的系统

综述（解读层）

该系统定时检查 pingcap/tidb 仓库，将指定版本相关的 Bug Issue 新建与状态变化推送到 Slack。通过 Fork 仓库并在 GitHub Secrets 中配置 TiDB 连接串与 Slack Webhook 即可运行，无需自备服务器；Issue 快照存入 TiDB，以差分检测变化并防止重复通知。需要准备 TiDB 与 Slack Incoming Webhook，默认仅通知 critical 级别。

  • 检测 6 类事件（OPEN/CLOSE/REOPEN/LABEL_ADDED/LABEL_REMOVED/TITLE_CHANGED），可通过 NOTIFY_EVENTS Secret 自定义
  • Issue 状态存入 TiDB（issue_snapshots/notification_log 表，首次运行自动建表），以差分检测变化防止重复通知
  • 配置全部经 GitHub Secrets 管理，无需改动源码；支持修改 cron 调度与手动运行（lookback_hours 可回溯检测历史 Issue）

适用场景（解读层）

  • 跟踪特定 TiDB 版本（如 v8.5.5）关联 Bug Issue 的新增与修复进展并汇总到 Slack
  • 监控 Issue 标签变化（如 severity/critical）或重新打开等状态变动的团队通知流程
  • 通过修改 REPO 环境变量以相同机制监控其他 GitHub 仓库的 Issue 动态
📖 README 首段存档原文 · 程序抽取

GitHub の pingcap/tidb リポジトリを定期的に監視し、指定バージョンに関連するバグ Issue の新規登録・ステータス変化 を Slack に通知するシステムです。
