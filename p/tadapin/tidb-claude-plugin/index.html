面向 Claude Code 的 TiDB Cloud 插件，打包 11 个技能与 MCP 服务器

综述（解读层）

该插件为 Claude Code 提供 TiDB Cloud 相关的 11 个技能（覆盖集群开通、SQL 编写、pytidb/Prisma/Kysely/Next.js 集成等）及基于 pytidb[mcp] 的 MCP 服务器集成，通过 marketplace 或本地目录方式安装后按上下文自动激活技能。运行前提包括 Claude Code CLI、uv 和一个 TiDB Cloud Serverless 集群；技能内容来源于 pingcap/agent-rules 仓库，许可证为 Apache-2.0。

  • 包含 11 个技能，覆盖 TiDB Cloud 集群开通、SQL 编写、Python/Node.js 驱动、Prisma、Kysely、Next.js 等方向
  • 集成基于 pytidb[mcp] 的 TiDB MCP 服务器，提供数据库操作工具
  • 提供多环境管理，凭据存于 .tidb/envs/ 并自动加入 .gitignore，切换时更新 .env 中的 TIDB_* 变量

适用场景（解读层）

  • 在 Claude Code 中开通和管理 TiDB Cloud Serverless 集群
  • 开发使用 TiDB 的 Python 或 Node.js/Next.js 应用
  • 开发/预发布/生产等多 TiDB 环境间切换连接配置
