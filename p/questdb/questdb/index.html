基于开放格式的开源低延迟时序数据库，SQL 引擎覆盖摄入、流处理与分层存储

综述（解读层）

QuestDB 是 Apache 2.0 许可的开源时序数据库，采用零 GC Java 引擎并在热路径使用 C++/Rust，数据存于内存映射、按时间分区的列式存储，支持转换为或直接以 Parquet 建表。面向资本市场、机器人、能源遥测等时序场景，可通过 Docker 或 Homebrew 运行，兼容 PostgreSQL 协议、InfluxDB Line Protocol 与 REST API。README 中与其他数据库的对比数据为官方基准，仅供参考。

  • 通过 QWP 二进制 WebSocket 协议在单连接上完成写入与查询，Python 客户端默认返回 Apache Arrow 数据
  • SQL 扩展时序语法：SAMPLE BY、LATEST ON、ASOF JOIN、WINDOW JOIN、物化视图、live views 与 n 维数组
  • 支持有序与乱序事件摄入、去重、乱序修正；提供 PostgreSQL Wire、ILP、REST 等兼容协议接入

适用场景（解读层）

  • 资本市场 tick 数据、订单簿与盘前盘后分析
  • 飞行测试遥测、车队数据与任务回放等航天/机器人场景
  • 已产出 ILP 数据的采集器与管道，或经 Postgres 驱动/BI 工具接入的现有工具链
