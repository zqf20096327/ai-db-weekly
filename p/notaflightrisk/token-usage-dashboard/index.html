🧭 简介解读层（AI·证据行可回查）

读取本地 AI 编码工具记录并生成令牌用量仪表盘的自托管应用

综述（解读层）

该项目读取本机 Claude Code、Codex 和 OpenCode 的会话记录，构建历史令牌用量仪表盘，展示日历热力图、按工具/模型分类的每日总量、缓存读写占比及 5 小时/7 天窗口等数据。统计数据缓存在本地 SQLite 中，即使原始记录被修剪仍可保留历史；费用按当前公开 API 费率估算。处理全部在本地完成，仅查询订阅计划窗口时会调用一次 Anthropic 接口（可在设置中关闭）。

  • 支持读取 Claude Code、Codex、OpenCode 三种工具的本地会话记录
  • 统计数据缓存于本地 SQLite，可保留被修剪记录之外的历史
  • 提供 Docker、systemd 服务、release 包和源码四种部署方式

适用场景（解读层）

  • 需要统计 Claude Code、Codex、OpenCode 的历史令牌用量与费用估算
  • 查看 Anthropic/OpenAI 5 小时与 7 天窗口的使用情况
  • 以自托管方式在本地分析 AI 工具使用记录且数据不出本机
