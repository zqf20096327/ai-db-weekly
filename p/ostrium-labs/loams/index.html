🧭 简介解读层（AI·证据行可回查）

Rust 编写的开源 AI 原生数据平台，单引擎在对象存储上提供混合检索。

综述（解读层）

Loams 是用 Rust 编写的开源数据平台与配套工具链，面向以 AI 代理为核心业务的服务型软件公司及使用编码代理的开发团队。引擎将数据存于用户自己的对象存储桶（S3、GCS、Azure Blob 等）中的开放格式，通过日志实现写入一致性，融合向量、BM25 与过滤器的混合检索，并提供 Qdrant、Elasticsearch 兼容 API、Postgres/MySQL wire 协议及多语言 SDK。运行方式为 Docker Compose 自托管或单机 cargo 启动。需注意 0.x 版本 API 与磁盘格式可能在次版本间变更。

  • 单引擎提供向量、BM25 与过滤器的混合检索，通过 DataFusion 查询以 RRF 融合，热数据层级在 RAM 与 NVMe
  • 兼容 Qdrant 与 Elasticsearch 客户端（含 LangChain、LlamaIndex），提供 Arrow Flight SQL 及 Postgres、MySQL wire 协议
  • 同一存储上包含响应式文档（Live）、图数据库（Graph）、ClickHouse 兼容分析（House）、Postgres/MySQL 与持久化代理运行（Durable）

适用场景（解读层）

  • 在自有的对象存储上构建混合检索服务，复用现有 Qdrant/Elasticsearch 客户端代码
  • 以 Docker Compose 或单机模式自托管 AI 代理运行栈，数据保留在自有桶中
  • 通过 SDK（TypeScript、Python、Go、Rust 等）在应用中集成集合、搜索、图、SQL 与流能力
