用 PostgreSQL JSONB 查询替代 ZCatalog BTree 索引的 Plone 目录插件

综述（解读层）

plone-pgcatalog 是 Plone 6 的目录插件，将 ZCatalog 的 BTree 索引替换为 PostgreSQL JSONB 上的 SQL 查询，依赖 zodb-pgjsonb 作为 ZODB 存储后端。安装后 portal_catalog 被 PlonePGCatalogTool 替换，查询沿用 ZCatalog API；目录数据在 ZODB 提交时与对象状态一同原子写入。需 Python 3.12+、PostgreSQL 15+。

  • 支持全部标准索引类型及 DateRecurringIndex，可经 IPGIndexTranslator 命名工具扩展自定义索引类型
  • 基于 tsvector/tsquery 提供面向 30 种语言的词干化全文检索，检测到 vchord_bm25 扩展时自动改用 BM25 排序
  • 目录写入在 ZODB 提交时原子完成，不在 ZODB 中存储 BTree/Bucket 对象

适用场景（解读层）

  • 已运行于 zodb-pgjsonb 的 Plone 6 站点将目录迁移到 PostgreSQL
  • 含循环事件的 Plone 站点（查询时经 rrule_plpgsql 展开重复日期）
  • 通过 plone.distribution 创建使用 PG 目录的新站点，或经 catalog.xml 动态注册索引的插件场景
