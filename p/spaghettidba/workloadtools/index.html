采集、分析与回放 SQL Server 工作负载的工具集

综述（解读层）

WorkloadTools 是一组用于采集、分析和回放 SQL Server 工作负载的工具，含命令行工具 SqlWorkload、GUI 工具 WorkloadViewer 和格式转换工具 ConvertWorkload。SqlWorkload 通过 SqlTrace 或 Extended Events 捕获事件，将批处理归一化后计算 CPU、duration、reads、writes 等指标并实时回放到目标实例；配置通过 JSON 文件完成，支持 x86/x64 安装包。适用于需要在本地与云环境间采集和对比工作负载数据的数据库管理员。

  • SqlWorkload 支持通过 SqlTrace 或 Extended Events 捕获事件，实时回放到目标实例并分析语句
  • 批处理会被归一化（剥离参数和常量），按归一化批处理计算 cpu、duration、reads、writes 指标
  • WorkloadViewer 提供 GUI 展示 CPU、Duration、Batches/sec 等图表，可对比两个工作负载（Baseline 与 Benchmark）并识别查询回归

适用场景（解读层）

  • 在生产服务器采集工作负载并回放到测试服务器，对比两台机器上的指标数据
  • 用 ConvertWorkload 将现有 trace 文件转换为内部 SQLite 格式
  • 通过 WorkloadViewer 或 PowerBI 仪表板查看采集的分析数据
