综述（解读层）

DBBridge 是用 Go 和 Wails 编写的数据库迁移工具，在数据库之间迁移表结构和数据，并转换 SQL 脚本方言。它面向需要在 MySQL、PostgreSQL、达梦、金仓、OceanBase 等数据库之间迁移数据的用户。迁移通过图形界面分步完成：填写连接信息、选择表、执行；它还提供迁移前的自动备份和回滚。Windows 版需要 WebView2 运行时；Linux 版以 Web 服务形式运行在 8989 端口。

  • 支持 23 种数据库，包括 MySQL、PostgreSQL、SQLite、OceanBase、TiDB、达梦、金仓、openGauss，可进行任意组合的源到目标迁移
  • 包含触发器和存储过程的语法级转换（在 MSSQL、MySQL、PostgreSQL 方言之间）、CHECK 约束迁移以及迁移报告
  • 提供额外的工具：SQL 脚本转换、SQL 方言检查器、数据验证（行数对比和主键抽样）、结构兼容性检查以及连接字符串生成器

适用场景（解读层）

  • 异构数据库迁移，包括信创场景下的国产数据库迁移
  • 从现有 .sql 备份文件导入，并进行自动方言转换
  • 迁移后验证和 SQL 兼容性检查，然后再进行应用程序切换
