开源 PostgreSQL 监控与故障排查平台，基于只读采集与证据化事件分析

综述（解读层）

LockLens 是一个用 Go 与 nginx 实现的开源 PostgreSQL 监控和事件排查工具，面向 DBA 和运维人员。它以只读角色连接被监控库，采集会话、查询、阻塞链、复制等数据，将证据关联为带时间线的事件记录。支持 PostgreSQL 14–18，历史数据存于独立的 PostgreSQL/TimescaleDB 存储，MIT 协议发布。

  • 通过只读角色采集，不取消查询、终止会话或执行 DDL/DML
  • 基于 pg_blocking_pids() 生成阻塞树，并提供 incident recorder 保留事件证据与时间线
  • 支持 Slack、webhook、邮件、Alertmanager 通知，以及 Prometheus 指标与 Grafana 面板；另提供独立于服务器的 CLI（doctor/inspect/watch/snapshot）

适用场景（解读层）

  • 排查阻塞链与空闲事务等锁等待问题
  • 汇总多实例环境的连接、慢查询、复制延迟等运行状态
  • 通过 CLI 直接对数据库做现场检查并导出离线快照
