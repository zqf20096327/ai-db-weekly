基于内容定义分块与事务性索引的 RAG 增量索引工具

综述（解读层）

Steadlith 是一个 Python 3.10+ 的库和 CLI，为单主机 RAG 索引提供增量更新能力。它使用 Rabin 滚动指纹做内容定义分块，使文档局部编辑后未变更块的边界保持稳定；通过清单 diff 将块分类为 add/keep/move/delete，仅对未缓存的 add 内容生成新嵌入。索引与嵌入缓存均存于 SQLite，支持预览、回滚和墓碑删除。适用于维护单机 RAG 索引的工程师。

  • 提供 Rabin CDC 分块策略，生成内容寻址的块标识与嵌入缓存键，并输出 add/keep/move/delete 变更计划
  • 包含事务性 SQLite 索引与内容寻址嵌入缓存，支持干跑预览、迁移恢复、回滚与墓碑压缩
  • 内置五语料基准与 measure churn/retrieval 命令，支持 hash、OpenAI、sentence-transformers 三种嵌入提供者

适用场景（解读层）

  • 维护频繁编辑的文档或源码文本的单主机 RAG 索引，增量复用未变更块的缓存嵌入
  • 通过 plan 干跑预览索引变更，再按需 apply、迁移或回滚，无需改动持久状态
  • 在离线环境下使用 feature hashing 进行精确词与关键词检索，或切换学习型提供者实现语义检索
