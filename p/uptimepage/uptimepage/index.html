🧭 简介解读层（AI·证据行可回查）

开源在线监控工具，整合状态页、事件管理与值班通知，支持自托管。

综述（解读层）

uptimepage 提供 HTTP、TCP、ICMP、DNS、TLS 证书、域名到期、心跳及浏览器登录流程等九种检查类型，可从多区域发起探测，生成公开状态页并通过十四种以上渠道告警。支持 REST API、Terraform 与 MCP 接口，提供托管服务，也可基于 AGPL-3.0 自托管，运行需 Postgres 与 ClickHouse。

  • 支持 9 种检查类型，频率可低至 30 秒，覆盖 HTTP、TCP、ICMP、心跳、DNS、TLS 证书到期、域名到期、浏览器登录流程和手动状态
  • 内置公开状态页（HTML + JSON + RSS），支持事件叙述、维护窗口和邮件/webhook 订阅者
  • 提供 REST API、Terraform provider 与 MCP server，探测代理可在自建服务器上多区域运行

适用场景（解读层）

  • SaaS 团队面向客户发布包含组件状态与 90 天历史的公开状态页
  • 平台/SRE 团队以 Terraform 管理监控目标，并通过值班轮换与升级策略进行事件分页
  • 自托管用户以单二进制加 Postgres、ClickHouse 运行，无需托管服务
