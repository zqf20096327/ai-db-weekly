Acronis 开源的 Go 性能测试库与基准测试工具套件

综述（解读层）

perfkit 由 Acronis 开源，包含 benchmark 与 db 两个 Go 库，以及 acronis-db-bench（SQL/NoSQL 数据库基准测试工具）和 acronis-restrelay-bench（REST API 与云部署基准测试工具）两个可执行工具。面向性能研究人员、开发者和数据库管理员，采用 MIT 许可证发布。

  • acronis-db-bench 支持 MySQL、PostgreSQL、Cassandra、ClickHouse、ElasticSearch、OpenSearch 等 SQL 和 NoSQL 数据库，覆盖插入、更新、分面搜索、索引搜索、向量搜索等数据访问模式，并内置多租户环境模拟
  • acronis-restrelay-bench 由 REST HTTP 客户端和 API 服务端两部分组成，可多实例部署，支持自定义客户端参数和服务端动作（内存分配、CPU 密集任务、请求转发），用于在裸金属、VM 和 Kubernetes 环境间对比
  • 提供 benchmark 和 db 两个 Go 库，可通过 go get 引入用于编写自定义基准测试

适用场景（解读层）

  • 对多种 SQL/NoSQL 数据库进行跨库性能对比测试，评估不同索引策略、高基数数据和并发负载下的表现
  • 在裸金属、虚拟机、Kubernetes 等不同环境中测试 REST API 服务端基础设施的负载表现，调整 CPU/内存限制并分析影响
  • 基于 benchmark Go 库开发自定义基准测试程序
