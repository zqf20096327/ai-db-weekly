🧭 简介解读层（AI·证据行可回查）

Node.js 的非阻塞 PostgreSQL 客户端，纯 JS 实现并可选 libpq 原生绑定

综述（解读层）

node-postgres（pg）是一个运行于 Node.js 及 bun、deno、cloudflare 等环境的非阻塞 PostgreSQL 客户端，通过 npm install pg 安装。该仓库为 monorepo，包含 pg、pg-pool、pg-query-stream 等多个相关模块。客户端提供参数化查询、连接池、LISTEN/NOTIFY 与 COPY 导入导出等功能，本地开发需安装 libpq-dev 并通过 yarn 运行测试。

  • 纯 JavaScript 客户端与原生 libpq 绑定共享同一套 API
  • 支持连接池、参数化查询、具名语句查询计划缓存、LISTEN/NOTIFY 异步通知及 COPY TO/COPY FROM 批量导入导出
  • 提供可扩展的 JS 与 PostgreSQL 数据类型转换机制

适用场景（解读层）

  • Node.js 服务端应用连接和查询 PostgreSQL 数据库
  • 需要连接池管理或流式读取大查询结果的场景
  • 使用 COPY 进行批量数据导入导出的数据处理流程
