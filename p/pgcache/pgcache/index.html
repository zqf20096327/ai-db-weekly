🧭 简介解读层（AI·证据行可回查）

基于逻辑复制保持一致性的 PostgreSQL 读缓存代理

综述（解读层）

pgcache 是一个兼容 PostgreSQL 线协议的代理，位于应用与源库之间，缓存查询结果并通过订阅源库的逻辑复制流（CDC）维护一致性：变更可直接应用到缓存结果或使相关查询失效。写入仍发往主库。适合希望不改应用代码来分担主库读负载的团队。限制：缓存要求表有主键，需开启 logical replication，项目处于 pre-1.0 阶段。

  • 兼容 PostgreSQL 线协议，应用只需更换连接字符串即可接入，写入仍转发至主库
  • 通过逻辑复制流维护缓存一致性：单表查询的变更可直接应用于缓存结果，联接与复杂查询在需要时失效并回源
  • 提供 Fit Analyzer 工具，基于 pg_stat_statements 导出在浏览器本地分析可缓存比例

适用场景（解读层）

  • 为读密集的 PostgreSQL 工作负载分担主库读流量，且不修改应用代码
  • 以源库 CDC 驱动的缓存替代基于定时过期的缓存方案，避免读到已提交写所覆盖的旧数据
  • 只缓存热点读工作集，而非维护一份完整只读副本
