C++ 编写的轻量级内存键值数据库，支持 WAL 持久化与 TTL

综述（解读层）

BranchDB 是一个用 C++ 实现的键值数据库，以 std::unordered_map 为内存存储核心，通过 WAL 实现磁盘持久化，并提供读写锁、键过期、LRU 缓存驱逐、多数据库实例与用户认证等功能。服务器默认监听 1981 端口，可通过本地编译、Docker 运行，客户端可经 telnet/nc 连接 CLI 或使用 Node.js SDK。适合用于学习存储引擎、并发与持久化等数据库底层概念，Apache-2.0 协议开源。

  • 支持 SET/GET/DEL/EXISTS/TTL/EXPIRE/PERSIST/GETALL/FLUSH 等命令，SET 可带过期时间
  • 采用 WAL 写前日志持久化，FLUSH 时自动压缩日志文件，LRU 缓存达到容量后驱逐最久未用键
  • 读写锁保证线程安全，后台线程周期性清理过期键，支持单实例多数据库与内置认证

适用场景（解读层）

  • 学习存储引擎、WAL 持久化、并发控制等数据库底层机制的实验环境
  • 需要内存键值存储并可选择性持久化的开发/测试场景
  • 通过 telnet/nc 或 Node.js SDK 以文本协议交互的简单数据存取
