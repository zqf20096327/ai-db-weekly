Node.js 的 MySQL 链式操作工具库，无需 ORM 模型即可生成 SQL 并支持 Redis 缓存

综述（解读层）

superdb 是一个 Node.js 数据库工具库，通过链式方法和 Op 操作符集合生成 SQL 语句，无需定义 ORM 模型即可执行查询。它通过 yarn 或 npm 安装，使用 MySQL 连接字符串初始化，支持连接池配置。内置 ttl 方法可将查询结果存入 Redis 缓存，并提供 beforeHooks/afterHooks 钩子处理参数与结果；find 未指定 limit 时默认最多返回 1 万条。

  • 提供链式方法（table/select/where/join/limit/order/group/having 等）生成 SQL，支持 find/findOne/count/exists/createOne/bulkCreate/update/delete 等连接方法
  • 提供 Op 操作符集合（or/and/eq/ne/gt/in/like/between 等），并通过 ttl 方法设置 Redis 缓存过期时间
  • 支持连接池配置、SQL 日志输出（logging）及 beforeHooks/afterHooks 前后钩子

适用场景（解读层）

  • Node.js 项目中以链式调用方式生成并执行 MySQL 查询，替代手写 SQL 语句
  • 对读频繁的查询结果设置 Redis 缓存（通过 ttl 指定过期时间）
  • 不希望维护 ORM 模型定义、表结构更新频繁的场景下执行增删改查
