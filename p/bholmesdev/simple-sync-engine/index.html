基于 SQLite 的简易同步引擎教学实现，采用 push/pull 模型

综述（解读层）

Simple Sync Engine 是一个教学用途的同步引擎示例，在客户端和服务器端均使用 SQLite，采用 Replicache push/pull 模型的简化版本同步变更。服务器维护 mutation_log 表并配合 lastLogId cookie 跟踪变更，客户端通过 base db 与 optimisticDb 两个数据库执行 rebase。项目定位为学习跳板而非生产基础，README 明确指出未处理认证、离线重试和数据库迁移。

  • 客户端与服务器均使用 SQLite，实现简化版 Replicache 的 push/pull 同步模型
  • 服务器维护 mutation_log 表记录变更历史，通过 lastLogId cookie 增量返回未同步的变更
  • 客户端使用 base db 与 optimisticDb 双数据库执行 rebase，并回放未被服务器确认的变更

适用场景（解读层）

  • 学习同步引擎的 push/pull 与乐观更新机制
  • 作为自行实现完整同步引擎的起点
  • 需要理解 rebase、mutation log 等概念的教学演示
