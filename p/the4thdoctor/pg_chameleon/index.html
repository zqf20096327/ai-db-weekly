Python 编写的 MySQL 到 PostgreSQL 复制系统，经 JSONB 中转回放变更

综述（解读层）

pg_chameleon 用 Python 3 实现 MySQL 到 PostgreSQL 的复制：通过 mysql-replication 拉取行镜像存为 JSONB，再由 pl/pgsql 函数解码回放。支持多源 schema、基础 DDL、类型覆盖与几何数据（需 PostGIS）。无主键/唯一键的表仅初始化而不参与复制。适用于分析、迁移和多库数据聚合。

  • 从多个 MySQL schema 读取并还原到目标 PostgreSQL，源与目标 schema 名可不同
  • 提供基础 DDL 支持（CREATE/DROP/ALTER TABLE、DROP PRIMARY KEY、TRUNCATE、RENAME）与数据类型覆盖（如 tinyint(1) 转 boolean）
  • 复制进程以守护方式运行，读取与回放分为两个子进程；出错表自动排除出复制，支持单表/单 schema 刷新与脱离 MySQL 的迁移 detach 流程

适用场景（解读层）

  • MySQL 到 PostgreSQL 的数据库迁移，detach 后重置序列并创建外键使 PostgreSQL 独立运行
  • 将 MySQL 作为 PostgreSQL 的复制源，用于分析场景
  • 从多个 MySQL 数据库聚合数据到同一 PostgreSQL 目标
