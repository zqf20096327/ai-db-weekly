内嵌 Redis 服务器的 Python 模块，封装 redis-py 接口

综述（解读层）

redislite 是对 Redis 键值存储的 Python 封装模块，提供增强版 redis-py 绑定，可在创建 Redis 对象时自动启动、配置并管理内置 Redis 服务器，解释器退出时自动关闭。需 Python 3.6+，Linux 安装需 python-dev 头文件，Windows 需在 Bash on Ubuntu 环境运行。适合需要进程内 Redis 的 Python 开发者，支持通过 rdb 文件路径实现数据持久化。

  • 创建 Redis 对象时自动启动内置 Redis 服务器，退出时自动关闭
  • 提供 patch_redis() 等 MonkeyPatch 函数，使现有 redis-py 代码少量修改即可运行
  • 支持单脚本运行多个服务器实例，并可配置端口与主从复制（slaveof）

适用场景（解读层）

  • Python 应用中需要嵌入式键值存储并按 rdb 文件持久化数据
  • 在不改动代码的前提下将依赖 redis-py 的现有模块切换到内嵌服务器
  • 在同一脚本内运行多个不同配置的 Redis 实例（如主从复制测试）
