🧭 简介解读层（AI·证据行可回查）

将 SQLite 编译为 WebAssembly、在浏览器或 Node.js 中运行内存数据库的 JavaScript 库

综述（解读层）

sql.js 使用 emscripten 将 SQLite 编译为 WebAssembly，使开发者可在浏览器中创建关系型数据库并执行 SQL 查询。数据库存储在内存中的虚拟文件里，不持久化修改，但支持导入现有 sqlite 文件并将数据库导出为 JavaScript 类型化数组。1.x 版本采用异步初始化 API，提供浏览器、Node.js（需 18.3+）及 Web Worker 多种构建。

  • 通过 emscripten 将 SQLite 编译为 WebAssembly，提供默认分离 .wasm 文件与单文件内嵌两种构建
  • 支持导入现有 sqlite 文件、导出为类型化数组，提供 Web Worker API 和 BigInt 64 位整数选项
  • 提供含 debug、browser、inline、worker 等 10 种构建产物，默认启用 SQLite 的数学函数与 legacy 扩展

适用场景（解读层）

  • 在浏览器中创建并查询内存中的关系型数据库，如在线 SQL 演示工具
  • 让用户选择本地 sqlite 文件加载查询，或从服务器 fetch 数据库文件
  • 在 Web Worker 中运行 SQL 查询以避免占用主线程
