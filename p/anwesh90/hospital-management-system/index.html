基于 SQL Server/T-SQL 的医院管理工作流数据库设计项目

综述（解读层）

该项目实现了医院管理工作流的 SQL 数据库，包含患者与员工信息、预约、账单、化验、病史及反馈等表，并附有设计规范文档。README 提供了数据库用途、业务规则、设计要求（采用 Crow's Foot 记法的 ER 图）等内容，适合需要学习或参考医院数据库表结构设计的开发者。

  • 维护患者与员工（管理员、医生、护士、化验员）详细信息，按角色区分
  • 涵盖预约、账单（含保险/陪护/化验等多类型账目）、化验、病史及患者反馈表
  • 提供使用 Crow's Foot 记法标注主键与关系的 ER 图及设计规范文档

适用场景（解读层）

  • 需要管理患者就诊、预约与账单信息的医院数据库系统
  • 数据库课程作业或学习中 ER 图设计（Crow's Foot 记法）的参考示例
  • 使用 SQL Server/T-SQL 搭建医院相关表结构与查询
