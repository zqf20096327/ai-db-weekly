一条命令将 SQLite 数据库转换为 DuckDB 数据库的工具

综述（解读层）

sqlite2duckdb 是一个 Python 编写的命令行工具，用于把 SQLite 数据库文件转换为 DuckDB 数据库，转换表及数据、主键/NOT NULL/UNIQUE 约束、索引和视图。既可通过 uvx 直接运行或 pip 安装后以 CLI 使用，也可作为 Python 库导入调用，返回表、视图数量和耗时。限制：FOREIGN KEY 和 CHECK 约束不会被复制；含 DuckDB 无等价物（如 MATCH、julianday()）的视图会被跳过并警告。

  • 支持转换表及数据、主键/NOT NULL/UNIQUE 约束、索引和视图
  • 提供 CLI 命令行和 Python API（sqlite_to_duckdb）两种使用方式，--force 参数可覆盖目标文件
  • 含 DuckDB 无等价语法（如 MATCH、julianday()）的视图会被跳过并给出警告，不中断转换

适用场景（解读层）

  • 将 SQLite 中的 OLTP 数据迁移到列式存储的 DuckDB 用于分析处理
  • 数据工程流程中以编程方式批量执行 SQLite 到 DuckDB 的数据库转换
  • 需要一次性迁移含索引、视图等结构的既有 SQLite 库文件的场景
