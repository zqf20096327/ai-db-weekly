基于 Web 的 Postfix 邮件服务器虚拟域/邮箱管理界面

综述（解读层）

PostfixAdmin 是一个开源 Web 界面，用于管理基于 Postfix 的邮件服务器上的域名、邮箱和别名，可与 Dovecot/Courier 等 IMAP/POP3 服务器及数据库后端集成。管理员通过它维护虚拟域与用户，普通用户可登录修改密码或设置自动回复。运行需 PHP 8.2+（master 分支）、MySQL/PostgreSQL/SQLite 之一及支持 PHP 的 Apache 或 Nginx；需要旧版 PHP 可用 3.3 分支，生产部署建议使用发布的稳定版本而非 master 分支。

  • 支持管理不限数量的域名、别名和邮箱，提供可选的存储配额与密码过期（beta）功能
  • 支持 PostgreSQL、MySQL、MariaDB、SQLite 四种数据库后端（任选其一），以及多种密码哈希格式
  • 提供 TOTP 登录验证、应用专用密码、DKIM 密钥存储、XMLRPC API，并通过插件集成 Squirrelmail/Roundcube

适用场景（解读层）

  • 为基于 Postfix 与 Dovecot/Courier 的自建邮件服务器提供虚拟域、邮箱、别名的 Web 管理
  • 向邮箱用户提供自助入口：登录修改密码、设置休假/自动回复
  • 通过 Fetchmail 从远程 POP3 服务器拉取邮件，或经 XMLRPC API 与其他系统集成
