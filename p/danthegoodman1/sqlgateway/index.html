Go 编写的 SQL 数据库 HTTP 网关，提供连接池与事务代理

综述（解读层）

SQLGateway 是一个将 SQL 数据库暴露为 HTTP API 的网关，用 Go 编写，基于 PSQL wire 协议连接数据库。它为无法建立 TCP 连接的 WASM 运行时（如 Cloudflare Workers、Vercel Edge Functions）提供访问 Postgres 系数据库的途径，支持单查询、事务端点和连接池。集群模式通过 Redis 协调事务路由，缓存功能在 README 中标注为尚未实现。

  • 通过 HTTP 暴露 PSQL 协议数据库，支持 WASM 运行时访问 SQL 数据库
  • 提供 /psql/query、begin、commit、rollback 端点，多查询在事务内原子执行，事务默认 30 秒超时并自动回滚
  • 支持单节点或集群部署，集群模式下通过 Redis 查找并将事务请求代理到远端节点，可选 Basic Auth

适用场景（解读层）

  • 在 Cloudflare Workers、Vercel Edge Functions 等 WASM 边缘运行时中访问 Postgres、CockroachDB 等数据库
  • Lambda 类突发执行环境下复用连接池连接，减少数据库连接创建与空闲会话
  • 通过有限的池连接数量限制直接打到数据库的负载
