基于 S3 的进程内 Parquet 合并引擎，带 MVCC

综述（解读层）

IceDB 是运行在 S3 上的进程内 Parquet 合并引擎，用 Python 和 DuckDB 实现插入、合并与墓碑清理。状态与数据全部存于 S3（日志为 JSONL，数据为 Parquet），支持 MVCC、时间旅行查询与原子操作，适合需要自建无状态数仓、多租户分析或多语言读取 Parquet 的团队。合并与清理逻辑需使用者自行调度。

  • 使用 JSONL 日志和 Parquet 数据两种开放格式，任何语言均可解析和读取
  • 支持 MVCC、时间旅行查询、原子操作、动态 schema 演进和表/分区划分
  • 通过 S3 Proxy 支持透明查询，兼容 DuckDB、ClickHouse、Pandas 等多种查询引擎

适用场景（解读层）

  • 在 S3 上构建无需 JVM/Spark 的无服务器分析数仓
  • 需要让终端用户直接运行 SQL 的多租户数据分析场景
  • 以 DuckDB、ClickHouse、Pandas 等引擎直接查询 S3 上的 Parquet 数据
📖 README 首段存档原文 · 程序抽取

IceDB is an in-process Parquet merge engine for better data warehousing in S3, using only S3, with MVCC, time travel queries, and atomic operations.
