🧭 简介解读层（AI·证据行可回查）

基于 Next.js 的开源 SaaS 应用模板/脚手架，集成认证、支付与 i18n。

综述（解读层）

Saasfly 是一个 MIT 许可的开源 Next.js SaaS 模板，面向需要快速搭建 SaaS 应用的开发者。项目采用 monorepo 结构（web/ui/db/auth/email 等包），默认使用 Clerk 作为认证提供方（NextAuth 版本在独立分支），数据库为 PostgreSQL，配合 Prisma/Kysely、trpc、Stripe、Resend 等。创建方式为 `bun create saasfly`，可通过 Vercel 一键部署。

  • 使用 Bun 创建项目并运行开发服务器，支持 Vercel 部署
  • 集成 Clerk 认证、Stripe 支付、Resend 邮件，NextAuth 实现位于 feature-nextauth 分支
  • 包含 i18n、SEO、T3 Env、trpc + react-query、Zustand、Tailwind CSS 与 Shadcn/ui

适用场景（解读层）

  • 从模板快速初始化 SaaS 应用开发项目
  • 需要多语言（i18n）与 Stripe 支付的 Web 应用搭建
  • 作为 Next.js + TypeScript monorepo 工程结构的参考模板
