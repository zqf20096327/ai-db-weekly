嵌入式 PostgreSQL Go 库：在 Wasm 运行时中运行 PGlite，通过 database/sql 访问

综述（解读层）

pglite-go 将编译为 WebAssembly 的 PostgreSQL 18（PGlite）运行在 wasmtime 或 wazero 上，向 Go 程序提供进程内数据库，支持 database/sql 接口、v3 线协议、事务与服务端预编译语句。适用于 Go 1.25+ 且启用 CGo 的环境，需另行获取 wasm 资源文件；限制为单连接，暂不支持 COPY 与 LISTEN/NOTIFY。

  • 通过标准 database/sql API 提供类型化结果、RowsAffected、服务端预编译语句与事务，兼容 jmoiron/sqlx
  • 支持 wasmtime（CGo，默认）与 wazero（纯 Go，-tags wazero）两种 Wasm 运行时
  • 提供多种 wasm 资源加载方式：目录、go build 嵌入、按需下载或自定义 fs.FS；集群可持久化到宿主目录并支持内存模式

适用场景（解读层）

  • 在 Go 程序中以内嵌方式运行 PostgreSQL，无需独立服务器进程或 libpq
  • 需要真实 PostgreSQL 行为（事务、预编译语句、类型系统）的本地开发、测试或单机应用
  • 希望以自包含二进制或按需下载方式分发应用的构建场景
