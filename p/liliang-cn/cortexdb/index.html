🧭 简介解读层（AI·证据行可回查）

纯 Go 实现的单文件本地优先 AI 记忆库，含知识图谱与可追溯召回。

综述（解读层）

CortexDB 用 Go 编写，将向量索引、FTS5 全文检索、RDF 1.2 知识图谱和本体约束存于一个 SQLite 文件（也可切 PostgreSQL），供 AI 编码代理如 Claude Code、Codex 及 Go/Rust/Python/JS 客户端使用。提供 /remember 与 /recall 命令、自动召回钩子、gRPC 共享服务与 3D Web 可视化；未配置嵌入模型时回退词法检索。

  • 向量检索（HNSW/IVF/flat/二值编码）与 FTS5 混合检索，可在无嵌入模型时以词法模式运行
  • 内置 RDF 1.2 知识图谱，支持 SPARQL 1.1/1.2、RDFS+OWL 2 RL 推理、SHACL 约束及只读 Cypher
  • 提供记录变更历史、召回解释日志、W3C trace 链路，以及 3D 图谱 Web 视图

适用场景（解读层）

  • 为 Claude Code/Codex 等编码代理提供跨会话持久记忆与自动召回
  • 多代理或多机共享同一记忆图谱（通过 gRPC 服务）
  • 构建带本体约束与版本历史的本地知识图谱/GraphRAG 应用

AI memory and a knowledge graph in one SQLite file. Pure Go, no service to run, works without an embedding model.
