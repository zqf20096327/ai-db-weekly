本地运行的 AI 代理记忆层，含混合检索、钩子与 MCP 服务器。

综述（解读层）

ClawMem 是面向 Claude Code、OpenClaw 和 Hermes 代理的本地记忆层，将 markdown 笔记与会话内容转为可检索记忆。它通过钩子、MCP 服务器或原生插件集成，所有模式写入同一本地 SQLite 库；检索采用 BM25 与向量混合加多路图遍历。需 Bun 1.0+，完全本地运行、无 API 密钥；Windows 原生不受推荐，建议 WSL2。

  • 混合检索：BM25、向量搜索、倒数排名融合、交叉编码器重排与查询扩展
  • 多种集成路径：Claude Code 钩子、MCP 服务器、OpenClaw 插件、Hermes MemoryProvider 插件，共享同一 SQLite vault
  • 完全本地运行，无 API 密钥与云依赖；支持 llama.cpp GPU 推理

适用场景（解读层）

  • 为本地 AI 编码代理提供跨会话持久记忆与上下文注入
  • 导入 Claude Code、ChatGPT、Slack 等对话导出并提取结构化决策/偏好
  • 会话结束时生成交接内容，供下一会话续接工作
