面向 Rust 的 JSON 日志结构数据库，支持内存与磁盘存储

综述（解读层）

JasonDB 是一个用 Rust 编写的 JSON 数据库，采用日志结构存储，供 Rust 开发者在其程序中嵌入使用。它允许开发者在内存存储与磁盘存储之间选择，并提供创建和管理数据库的 API 以及查询能力。README 提供了独立的 API 文档链接，当前 README 内容较简短，未包含安装与使用示例。

  • 支持内存与磁盘两种存储方式，由开发者选择
  • 提供用于创建和管理数据库的 API
  • 提供复杂且经过优化的查询功能

适用场景（解读层）

  • Rust 应用中嵌入 JSON 数据存储
  • 需要在内存或磁盘存储间切换的数据管理场景
  • 需要执行结构化查询的 Rust 项目
