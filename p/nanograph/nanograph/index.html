综述（解读层）

nanograph 是运行在本地的类型化属性图数据库，无需服务器、云服务或 Docker，数据存于本地文件夹。基于 Rust、Lance、Arrow 与 DataFusion 实现，通过 CLI 创建、加载和查询图数据，schema 以 .pg 文件形式纳入版本控制并在查询时校验。提供 TypeScript 与 Swift SDK。适用于需要在本地运行图查询的开发者和 AI agent 场景。

  • 提供 schema-as-code 机制，.pg 文件可纳入 git 版本控制并在查询时强制校验
  • 内置 CDC 账本记录每次变更，支持重放、审计与从任意版本同步
  • 提供全文、语义、模糊、BM25、混合检索及图约束重排序搜索能力

适用场景（解读层）

  • 为 AI agent 构建上下文图与决策轨迹
  • 带 schema 校验的个人知识图谱
  • 依赖关系与数据血缘建模
