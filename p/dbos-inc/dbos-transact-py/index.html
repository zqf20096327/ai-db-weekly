基于 Postgres 的轻量级 Python 持久化工作流库

综述（解读层）

DBOS Transact 是一个开源 Python 库（MIT 许可），通过在 Postgres 中对函数执行状态做检查点，实现可自动恢复的持久化工作流。开发者用装饰器标注普通函数为 workflow 和 step，无需额外部署编排服务器或消息中间件。还提供持久化队列、通知、cron 调度、事件处理等原语，需连接 Postgres 或 SQLite 使用。

  • 通过装饰器将 Python 函数标注为工作流和步骤，检查点状态存于 Postgres，失败重启后从最后完成的步骤自动恢复
  • 提供持久化队列，支持并发限制、速率限制、超时、去重与优先级控制，无需独立消息队列服务
  • 工作流以表行形式存储，可通过 DBOSClient 编程查询、批量暂停/恢复或从指定步骤重启失败工作流

适用场景（解读层）

  • 需在服务器崩溃或中断后可靠恢复的支付、计费等业务流程
  • 长时间运行的数据管道，需从检查点续跑而非重新开始
  • Webhook/事件监听的恰好一次处理，或依赖不稳定 API 的 AI Agent 运行
