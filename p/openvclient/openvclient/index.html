Rust/egui 编写的 GPU 渲染桌面客户端，用于连接数据库、对象存储与服务器。

综述（解读层）

OpenVClient 是一个用 Rust 与 egui 编写的开源桌面客户端，运行于 macOS、Windows 和 Linux。它将 SQL 数据库、MongoDB、Redis、Elasticsearch、S3/Azure 存储、SSH 和 Docker 等连接集中在一个窗口内管理，提供 SQL 编辑、表浏览、文件管理和 SSH 终端等功能。当前处于 1.0.0 公测阶段，无遥测，密码存于操作系统钥匙串。备份还原功能依赖外部工具在 PATH 中。

  • 支持 PostgreSQL、MySQL/MariaDB、SQL Server、SQLite、ClickHouse、GaussDB 等 SQL 引擎，含自动补全、EXPLAIN 图形化执行计划、表数据编辑与 CSV/JSON/SQL 等格式导入导出
  • 提供 S3 兼容存储、Azure Blob、FTP/FTPS、SFTP 的文件管理，支持上传、下载、预览与共享链接（SAS、presigned URL）
  • 内置 Redis 键浏览、MongoDB 文档操作、Elasticsearch/OpenSearch 索引与搜索、RabbitMQ 队列管理、SSH 终端与 Docker 容器管理

适用场景（解读层）

  • 日常编写与执行 SQL，通过对象树浏览库表结构、查看执行计划、编辑表数据
  • 通过环境标签、只读连接和删除操作前的名称确认，在生产环境中执行监控、会话管理与备份恢复等运维任务
  • 在客户端内管理服务器：SSH 终端与 SFTP 浏览、Docker 容器/镜像/卷操作，以及云存储文件的浏览与传输
