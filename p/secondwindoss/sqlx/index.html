jmoiron/sqlx 的社区维护分支，扩展 Go database/sql 提供 struct 扫描与命名查询

综述（解读层）

sqlx 是 jmoiron/sqlx 的社区维护分支，通过内嵌标准库 DB/Tx/Stmt/Rows 类型扩展 database/sql，提供 struct 扫描、命名查询、In 展开与 Get/Select 便捷方法。导出 API 与上游 v1.4.0 保持一致（CI 用 apidiff 校验），迁移仅需改 import 路径。要求 Go 1.24 及以上；v1.4.1 起修复了 SQL 扫描、In 空切片等行为，使用前需检查查询写法。

  • 内嵌 database/sql 标准类型，原方法可直接使用，并提供 struct/map/slice 扫描、:name 命名查询、In 与 Rebind、批量插入及 Get/Select 方法
  • SQL 解析器可跳过字符串字面量、引号标识符和注释，:: 转型与 PostgreSQL JSONB 操作符 ?? 按原样传递
  • 每个方法含 Context 变体；CI 在 Go 1.24、1.25 等四个版本上对 PostgreSQL 16、MySQL 8、SQLite 运行测试，go.mod 无其他模块依赖

适用场景（解读层）

  • 使用 database/sql 且需要将查询结果扫描到 struct 或 map 的 Go 项目
  • 需要用命名参数写 SQL、将切片展开为 IN 占位符或按驱动转换占位符风格（$1、?、:name、@p1）的场景
  • 已使用 jmoiron/sqlx、希望沿用相同 API 并获得后续修复的项目
