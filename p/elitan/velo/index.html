自托管的 Postgres 分支控制平面，基于 ZFS 与 pgBackRest

综述（解读层）

Velo 是一个自托管控制平面，用于管理生产环境的 Postgres 备份、PITR 及可丢弃的开发分支。生产库运行在独立服务器上并用 pgBackRest 做备份；开发分支以 Docker 容器形式运行在 ZFS 写时复制数据集上，通过 Web UI（dev 服务器上的 3000 端口）管理。要求 Ubuntu/Debian 双服务器、SSH、Docker、ZFS、Bun 与 pgBackRest；v2 仅提供 Web 界面，无 CLI，本地状态存于含密钥的 SQLite 文件，需保持 .velo 私密。

  • 支持生产 Postgres 的 pgBackRest 备份与 PITR 恢复
  • 开发分支以 Docker Postgres 容器运行在 ZFS 写时复制数据集上，分支连接串经 Go TCP 代理，可唤醒已停止的分支并停止空闲分支
  • 安装可交给 AI 编码代理执行 install.md 端到端完成，并以 /healthz?ready=1 验证就绪

适用场景（解读层）

  • 需要为生产 Postgres 创建一次性开发分支副本的团队
  • 需要在自托管服务器上管理 Postgres 备份与 PITR 的运维场景
  • 本地开发时用 local:dev 起一套含 MinIO、pgBackRest 的类生产环境做备份/PITR 相关开发
