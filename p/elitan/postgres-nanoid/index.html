🧭 简介解读层（AI·证据行可回查）

用纯 SQL 在 PostgreSQL 中生成带前缀的 nanoid 标识符的函数实现

综述（解读层）

该项目以 SQL 函数形式在 PostgreSQL 内实现 nanoid 生成，支持自定义前缀、长度和字符集，并提供可选的时间可排序版本 nanoid_sortable()。通过 CREATE EXTENSION pgcrypto 后执行 SQL 安装即可使用，无需编译扩展，可在托管与自托管（v12+）环境运行。README 给出约 110,000 IDs/秒的生成性能数据，并提示可排序版本会暴露创建时间信息。适合需要在数据库层生成短 URL 安全 ID 的开发者。

  • 提供 nanoid(prefix, size, alphabet, additionalBytesFactor) 四参数函数，默认生成 21 字符、62 字符 URL 安全字母表的 ID
  • 安装仅需 pgcrypto 扩展加 SQL 脚本，README 声称适用于 AWS RDS、Google Cloud SQL、Azure 等托管及自托管 PostgreSQL 12+
  • 提供 nanoid_sortable() 生成内嵌时间戳、可按字典序时间排序的 ID

适用场景（解读层）

  • 为 customers、orders 等表生成带 cus_/ord_ 前缀的对外公开 ID，内部保留 SERIAL 主键
  • 分布式系统中无需协调地生成唯一标识符
  • 审计日志、事件流等需要按 ID 字典序反映时间顺序的场景（接受暴露创建时间的权衡）
