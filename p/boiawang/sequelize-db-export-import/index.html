基于 Sequelize 在 MySQL 数据库与模型文件之间双向生成代码的命令行工具

综述（解读层）

该工具是一个 Node.js 命令行程序（seq-ei），用于在 MySQL 数据库与 Sequelize 模型文件之间做双向转换：从数据库导出生成模型文件，或从模型文件反向建表。通过命令行参数或 config.json 指定主机、账号、端口、输出目录等，支持 coffee 等文件格式。仅支持 MySQL；Postgres 列于 Todo。适用于使用 Sequelize 的 Node.js 项目

  • 提供 seq-ei 命令，支持从 MySQL 数据库生成 Sequelize 模型文件（-H/-u/-p/-d/-o 等参数）
  • 支持加 -r 参数从模型文件反向生成数据库表
  • 支持通过 config.json 配置文件运行（seq-ei -c config.json），可指定输出格式如 coffee 及缩进

适用场景（解读层）

  • 使用 Sequelize 的 Node.js 项目需要根据已有 MySQL 数据库表生成模型文件
  • 需要根据现有模型文件在 MySQL 中创建对应数据表
  • 希望通过配置文件在多个环境间重复执行导出/导入操作
