纯 Zig 实现的 SQLite 兼容数据库引擎，含存储引擎、SQL 编译器与虚拟机

综述（解读层）

SQLite.zig 是用 Zig 从零编写的 SQLite 兼容引擎，无 C 依赖，包含实现 .db 磁盘格式的存储引擎、手写 SQL 词法/语法解析器、字节码虚拟机，以及 Raw SQL、动态 DSL、类型安全 DSL 三种查询接口。需 Zig 0.16.0+，支持 Linux/Windows/macOS。项目处于早期开发阶段，文件格式与 API 均无稳定性保证，README 明确提示勿用于生产环境。

  • 使用真实 SQLite .db 磁盘文件格式（100 字节头、B-tree 页），可无损重新打开数据库
  • 支持 WAL 与回滚日志两种持久化模式，以及事务、外键级联、视图、触发器、CTE、窗口函数等 SQL 特性
  • 提供 comptime 类型安全的 DSL 查询构建器，与 Raw SQL 使用同一内部查询表示，可在编译期校验表名、列名和类型

适用场景（解读层）

  • 在 Zig 项目中通过 zig fetch 引入依赖，以内嵌方式读写 SQLite 格式数据库文件
  • 利用类型安全 DSL 在编译期校验查询中的表、列与类型
  • SQL 引擎架构与存储格式实现的学习与实验（README 标注项目处于早期开发阶段）
