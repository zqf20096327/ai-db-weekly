面向 SSMS 2018 的插件，提供 TSQL 格式化、模板与结果导出功能

综述（解读层）

一款以工具箱窗口形式运行的 SSMS 插件，作者说明因未能实现工具栏动态菜单而采用窗口布局。面向 SQL Server 开发与运维人员，提供 TSQL 代码格式化（内部解析器或 Poor Man's SQL Formatter）、代码模板快速访问等能力。安装需 .NET 4.7.2，需将发布包解压至 SSMS 18 的 Extensions 目录；不支持 SSMS 2016+。仓库已归档，后续版本迁移至 Axial SQL Tools。

  • 使用 SQL Server 内部解析器或 Poor Man's SQL Formatter 格式化选中的 TSQL 代码
  • 提供代码模板的快速访问
  • 旧版（2008-2014）支持将当前 GRID 导出到 Excel 文件且无需重新执行查询

适用场景（解读层）

  • 在 SSMS 18 中对选中的 TSQL 代码进行格式化
  • 通过模板快速插入常用 SQL 代码片段
  • 将查询结果网格导出为 Excel 文件（旧版功能）
