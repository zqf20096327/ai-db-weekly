嵌入四种数据库引擎的倾斜稀疏关系连接聚合加速算子

综述（解读层）

Tessera 是一个嵌入 DuckDB、PostgreSQL、SQLite 和 Spark 的连接聚合算子，将 join-aggregate 计算为稀疏乘积加 AMX 上的稠密核心，避免逐行构建连接结果。它挂接引擎规划器，SQL 无需修改，遵循引擎的取消、线程数与内存限制，超限部分落盘。发布于 PyPI、Maven Central 和 PGXN，二进制包覆盖 Linux x86-64 与 macOS Apple silicon，密集核心路径需第四代及以后 Intel Xeon 与 Linux 5.16+。

  • 以一次输入遍历计算矩阵乘积 XᵀX，不构建中间连接行，稀疏部分走稀疏路径、稠密核心在 CPU 矩阵加速器上以 8-bit tile 运行
  • 通过 `HAVING` 或 `ORDER BY ... LIMIT` 剪枝无法达到阈值的值，结果保持精确；支持 `COUNT(DISTINCT)`、`AVG`、多列键/组、NULL 处理及 64/128 位精确整数求和
  • 以成本模型为每个查询选择稠密边界位置；作为 DuckDB 社区扩展安装（INSTALL tessera FROM community），其余引擎经 PyPI、PGXN、Maven Central 分发

适用场景（解读层）

  • 词共现、物品对物品推荐、共同邻居计数等成对计数与求和的连接聚合查询
  • 含偏斜分布的稀疏关系数据集上的分析查询，如新闻文章词对、MovieLens 评分电影对、基因网络基因对
  • 希望在不修改 SQL 的前提下让 DuckDB、PostgreSQL、SQLite 或 Spark 中的特定连接聚合查询走专用算子路径
