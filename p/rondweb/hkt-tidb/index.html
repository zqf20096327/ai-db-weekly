将蒙特利尔空气质量数据同步到 TiDB/MySQL 兼容数据库的 Python 管道

综述（解读层）

该项目是一个小型数据同步管道，用于将蒙特利尔空气质量数据写入 TiDB/MySQL 兼容数据库。基于 Python 3.9+ 与 SQLAlchemy，通过 TIDB 环境变量配置连接串，支持单次运行（--once）和每日定时调度（--schedule）。表不存在时自动创建，采用方言特定的 upsert 语义去重；提供 Docker/docker-compose 部署方式，写运行产物到 artifacts 目录并以此实现健康检查。

  • 支持单次运行与每日定时调度两种模式
  • 目标表不存在时自动创建，缺失主键时生成 ingest_id 自增主键
  • 提供 Docker、docker-compose 部署及基于 last_run JSON 文件时间戳的健康检查

适用场景（解读层）

  • 需要定时将空气质量数据同步到 TiDB 或 MySQL 数据库的场景
  • 需要容器化部署并通过健康检查监控运行状态的 ETL 任务
  • 本地开发时希望用 SQLite 快速验证管道流程
