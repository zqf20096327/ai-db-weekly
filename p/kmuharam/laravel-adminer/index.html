将 Adminer 数据库管理工具封装为 Laravel 应用的 Composer 包

综述（解读层）

该包是 Adminer（原 phpMinAdmin）在 Laravel 应用中的封装，用于简化 Adminer 的安装、配置和路由注册。当前内置 Adminer 4.7.7，同时支持 Adminer Editor 模式。通过发布配置文件可自定义应用名、路由名称/路径、外观样式及插件列表。注意 frames 插件会关闭 ClickJacking 防护，database-hide 明确不是安全插件。

  • 支持 Adminer 与 Adminer Editor 两种模式，可在配置中启用或切换
  • 集成插件机制，提供 dump-json、dump-xml、sql-log、tables-filter 等多个插件
  • 支持包内置外观与自定义外观，可通过路由配置指定

适用场景（解读层）

  • 在 Laravel 项目中通过路由访问 Adminer 管理多种数据库（MySQL、MariaDB、PostgreSQL、SQLite、MS SQL、Oracle、Elasticsearch、MongoDB 等）
  • 面向普通用户启用 Adminer Editor 进行数据编辑
  • 需要按项目定制导出格式（Bzip2/ZIP/JSON/XML）或记录 SQL 日志的场景
🔌 适配哪些库db_scan 程序判定

MariaDB、MySQL、Oracle、PostgreSQL、SQLite
