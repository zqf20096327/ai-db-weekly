🧭 简介解读层（AI·证据行可回查）

面向个人和小型打印农场的订单与打印任务管理平台，含打印机控制与成本分析

综述（解读层）

Daedalus 是面向个人制作者和小型 3D 打印工作坊的管理平台，提供产品目录、多渠道订单（Etsy/Squarespace/手动录入）、任务流转、多打印机控制及成本利润分析。后端 Go + SQLite（WAL 模式），前端 React 19，可经 Wails 打包为 macOS/Windows 桌面应用，或用 Docker 自托管；认证默认关闭，需通过环境变量开启。

  • 通过 REST API 接入 OctoPrint，MQTT 接入 Bambu Lab（含局域网/云端与 AMS），REST 接入 Moonraker/Klipper，并支持网络自动发现打印机和手动记录模式
  • 提供产品目录、任务（Task）与打印作业（Print Job）三层模型，设计文件不可变版本化并解析 3MF 获取打印时长、重量与耗材用量
  • 内置费用追踪（含收据 OCR）、材料与料卷库存、按产品汇总的成本与利润率计算，以及按渠道/产品的销售分析；实时状态经 WebSocket 推送，时间线以甘特图展示订单、任务与作业

适用场景（解读层）

  • 同时运营 Etsy 或 Squarespace 店铺与多台打印机的小型打印农场，集中管理订单到打印的履约流程
  • 个人制作者记录产品成本（耗材、配件、平台手续费等）并计算单产品利润率
  • 需要单一界面对 OctoPrint、Bambu Lab、Klipper 等不同固件打印机进行状态监控与作业控制
