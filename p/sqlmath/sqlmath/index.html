在 SQL 查询中直接运行统计与 LightGBM 机器学习的 SQLite 扩展

综述（解读层）

sqlmath 是一个 SQLite 扩展，在 SQL 查询中内置 20 多个数学、统计、数组、日期、压缩与哈希函数，并嵌入 LightGBM 实现 SQL 内模型训练与预测。可通过 Python（pip）、Node.js（npm）安装，或以 WebAssembly 形式在浏览器运行，以单文件二进制分发、无外部依赖。README 注明 Python 绑定为同步 API 且尚在开发中，使用 lgbm_* 函数前需先调用 lgbm_dlopen()。

  • 提供 20+ 内置 SQL 函数，涵盖数学、聚合统计（MEDIAN2、PERCENTILE、STDEV）、数组、日期、gzip 压缩与 SHA-256 哈希
  • 通过 LGBM_TRAINFROMTABLE 等聚合/窗口函数在 SQL 内完成 LightGBM 模型训练与预测
  • 支持 Python、Node.js 与浏览器（WebAssembly）三种运行环境，单二进制无外部依赖

适用场景（解读层）

  • 数据已存于 SQLite 中、需直接在 SQL 内执行统计或 ML 训练/推理的场景
  • 嵌入式 ML 管道：导入 CSV 后训练与部署模型，数据无需在数据库与 Python 间搬运
  • 金融数据分析与信号处理（如正弦拟合窗口函数、信用卡欺诈检测示例）
