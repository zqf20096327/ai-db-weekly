🧭 简介解读层（AI·证据行可回查）

基于 Laravel 与 Prism PHP 的驱动式 RAG 流水线，支持 pgvector/sqlite-vec 向量存储。

综述（解读层）

这是一个面向 Laravel 11+（PHP 8.2+）应用的 RAG 流水线扩展包，通过 Composer 安装后提供文档摄取、分块、嵌入缓存与检索问答能力。内置 pgvector 与 sqlite-vec 两种向量存储驱动（后者仅限 Docker/Linux），支持流式 SSE、混合检索、Agentic 迭代检索、会话记忆，并提供 RAG 评估、MCP Server、Livewire 聊天组件与 Filament 管理面板。

  • 提供 pgvector 与 sqlite-vec 两种可切换的向量存储驱动，并实现 $table->vector() 等 Blueprint 宏与 HasVectorSearch/AutoEmbeds 模型 Trait
  • 支持 SSE 流式响应、RRF 混合检索、LLM 重排序、带充分性评估的迭代式 Agentic 检索与线程化会话记忆
  • 内置 RAG 评估套件（Faithfulness/Relevancy/Context Recall）、MCP Server、rag:index 等 Artisan 命令及 Debugbar/Telescope 集成

适用场景（解读层）

  • 在 Laravel 应用中为 Eloquent 模型（如文档表）添加向量检索与 RAG 问答
  • 为 Claude Desktop、Cursor 等 MCP 客户端暴露自有知识库检索工具
  • 配合 Filament 管理面板管理文档、嵌入数据并进行交互式测试
