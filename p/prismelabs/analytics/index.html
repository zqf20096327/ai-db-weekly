🧭 简介解读层（AI·证据行可回查）

开源自托管网页分析服务，基于 ClickHouse 存储并用 Grafana 展示数据

综述（解读层）

Prisme Analytics 是一个用 Go 编写的自托管网页分析服务，面向需要网站流量统计的用户。它不使用 Cookie、仅收集匿名化数据，并集成 Grafana 提供仪表盘、用户与团队管理。接入方式为在网页中嵌入约 2kB 的追踪脚本，或以单像素图片支持无 JavaScript 页面。采用 AGPL-3.0-only 许可证。

  • 集成 Grafana，提供用户、团队、权限、多组织及自定义仪表盘管理
  • 无 Cookie 且仅收集匿名化数据，支持自定义事件与 UTM 活动追踪
  • 提供约 2kB 的 JavaScript 追踪脚本及 35 字节单像素图片的无脚本采集方式

适用场景（解读层）

  • 自托管部署网站或 Web 应用的流量统计
  • 营销活动流量来源的 UTM 追踪
  • SPA（基于 pushState 路由）应用的页面浏览统计
