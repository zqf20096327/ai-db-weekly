🧭 简介解读层（AI·证据行可回查）

面向 AI Agent 的轨迹级 CI/CD 平台，将生产失败固化为可回归的 CI 用例

综述（解读层）

Tracely 通过 OTLP 接收 Agent 运行轨迹，用 LLM-as-judge 与结构化检查自动评分，将失败按签名与语义聚类成 issue，并把失败轨迹固化为附带 fail-to-pass 契约的密封回归用例。CI 中用录制的工具与 LLM fixtures 离线重放，不需 API key。技术栈含 ClickHouse、Postgres、Redis、MinIO，需 Docker 部署。

  • 通过 OTLP/HTTP 接收轨迹，将 agent.id、conversation.id 等 Agent 语义提升为索引列，支持会话线程分组与瀑布图查看
  • 提供 LLM-as-judge（会话/运行/span 级）与无模型结构化检查两类评估器，失败按结构签名与嵌入聚类成 issue
  • 回归用例以录制 fixtures 离线重放，`tracely gate` 输出非零退出码、commit status 与 PR 评论；支持多轮 scenario 与红队对抗目标

适用场景（解读层）

  • 为生产环境中的 AI Agent 建立失败检测、聚类与回归测试流程的团队
  • 在 CI 中以离线 fixture 重放方式阻止引入已知失败的 PR 合并
  • 需要 LLM 评估器校准、失败率/延迟/成本趋势分析以及 Slack/邮件/webhook 告警流的多 Agent 系统运维
