🧭 简介解读层（AI·证据行可回查）

读取 dump1090 的 ADS-B 消息流并带时间戳写入 SQLite 数据库

综述（解读层）

该工具连接网络中的 dump1090 实例，将 ADS-B 消息流逐条加时间戳存入 SQLite 的 squitters 表。支持指定主机、端口、数据库路径、缓冲区与批量写入大小，Ctrl+C 退出时提交剩余记录。内置 callsigns、locations、flights 三个视图，用于合并同一飞机的多条广播并按航班号查询航迹。适合已运行 dump1090 并需持久化原始报文的用户。

  • 支持通过 -l/-p 参数连接网络中任意 dump1090 实例，可配置 buffer-size 与 batch-size 控制读取和批量写入
  • 数据存入 squitters 表，附带时间戳；退出时将未提交记录写入数据库
  • 提供 callsigns、locations、flights 视图，按天映射呼号与 hex_ident 并支持按航班号查询航迹，flights 视图限制在 first_seen 前后 10 分钟内以避免 hex_ident 复用干扰

适用场景（解读层）

  • 将树莓派等设备上 dump1090 接收的 ADS-B 报文持久化到 SQLite 供后续 SQL 查询
  • 通过 callsigns 与 flights 视图按航班号追踪特定航班（如 FDX 货运航班）的航迹与时间
  • 按 hex_ident 或呼号分析本地空域中出现的飞机历史记录
