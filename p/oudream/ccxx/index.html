基于 C/C++/Unix/POSIX 的跨平台基础库，模块多以单文件实现

综述（解读层）

CCXX 是一个面向 C/C++/Unix/POSIX 的跨平台库，涵盖文件、网络、线程、进程锁、共享内存、数据库、配置、日志等模块，大多以单个头文件实现并默认静态类方式调用。核心代码约 14MB，可按需拷贝部分文件使用；编译依赖 ODBC 与 libuuid，通过 CMake 可开关 libuv、OpenSSL 等组件，并在 Linux、Windows、macOS 上提供编译说明。

  • 提供网络通道（UDP/TCP 服务端/客户端/串口）、Event Loop、定时器、进程锁、共享内存 IPC、数据库（ODBC/SQLite）、JSON/XML 配置读写等模块
  • 模块大多以单个 .cpp/.h 文件完成，模块间尽量不依赖，可单独提取若干文件使用
  • 使用 CMake 构建，可通过配置开关 libuv、OpenSSL 等组件，支持 Docker 镜像运行环境

适用场景（解读层）

  • 需要跨平台的 C/C++ 网络通信、多线程与进程间通信开发
  • 需要统一接口访问数据库（ODBC、SQLite）、Redis 及读写 JSON/XML 配文件的程序
  • 需要在 C++ 与 Lua、Python 之间互相调用的项目
