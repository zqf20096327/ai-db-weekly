Home Assistant 侧边栏面板组件，图形化管理 recorder 配置与 SQLite 维护

综述（解读层）

GUI Recorder 是一个 Home Assistant 自定义集成，在侧边栏添加面板，用于以开关方式控制设备/实体的记录与否，并执行数据库统计、清理和重打包，无需手改 YAML。配置写入 gui_recorder.yaml 并通过 !include 引入；仅支持 SQLite，MariaDB 与 PostgreSQL 在安装时被拒绝。清理操作会永久删除历史，需提前备份。

  • 侧边栏面板支持按设备或实体开关记录，无需编辑 YAML
  • 提供数据库统计（总/当前/过时记录数、磁盘占用等）及 purge、repack 维护操作
  • 包含孤立排除项检测、configuration.yaml 三步导入迁移流程；卸载集成不删除数据库与已生成配置

适用场景（解读层）

  • 通过 GUI 管理大量实体的 recorder 记录开关，避免手工编辑 YAML
  • 对 SQLite recorder 数据库执行清理、重打包与磁盘占用分析
  • 将现有 configuration.yaml 中的 recorder 配置迁移到由组件管理的 gui_recorder.yaml

A Home Assistant custom component that adds a sidebar panel to manage your recorder configuration (which entities get recorded) and database maintenance (purge, repack, stats) — without editing config
