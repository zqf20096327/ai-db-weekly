🧭 简介解读层（AI·证据行可回查）

JavaFX 跨数据库桌面客户端，以字符串路径保证数值精度无损。

综述（解读层）

Plainly 是面向数据库开发与运维人员的 JavaFX 桌面管理工具，支持 MySQL、PostgreSQL、Oracle、SQL Server、达梦、SQLite、H2、Redis、MongoDB 等。其核心机制是 Row 值以 String 存储、CellReader 用 BigDecimal 转换，全程不经 double；提供网格编辑、结构设计器、结构/数据同步、导入导出等。注意：部分数据库未在真机验证，非 Windows 平台口令尚未加密。

  • 数值以 BigDecimal/String 全链路传输，DECIMAL(38,10)、Int64、Decimal128 不经 double；PrecisionConformanceTest 作为驱动接入的准入测试
  • 支持数据网格编辑（参数化写回、手动事务）、表结构设计器、结构同步、数据传输、CSV/JSON/SQL 导入与 CSV/xlsx/JSON/SQL 导出
  • DDL 按方言声明是否支持事务性回滚（默认 false），失败时明确告知已执行到第几条

适用场景（解读层）

  • 在单一客户端中管理 MySQL、PostgreSQL、Oracle、达梦等多种数据库的连接、浏览与编辑
  • 对精确数值敏感的查询、导出与写回场景（如 DECIMAL 满位、大整数边界、MongoDB Decimal128）
  • 跨库结构比对与同步、生成数据字典（HTML/Markdown/xlsx）、定时备份与脚本任务
