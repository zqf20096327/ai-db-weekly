🧭 简介解读层（AI·证据行可回查）

Rust 编写的 PostgreSQL 数据库脱敏导出工具，导出时按规则替换敏感字段。

综述（解读层）

pg_datanymizer 是一个 PostgreSQL 数据库导出工具，在生成 SQL dump 时按 YAML 配置对指定字段应用替换规则（共 70 余条规则，如 email、phone、datetime 等），生成可直接用 psql 导入的 PostgreSQL 原生 dump。适合需要在非生产环境使用生产数据的开发与测试团队。当前仅支持 PostgreSQL，MySQL/MariaDB 在 TODO 列表中；支持按表过滤、WHERE 条件、SQL 断言与流式输出到 STDOUT。

  • 提供 70 余条替换规则（email、ip、phone、password、datetime 等），支持 pipeline/template 组合、唯一性约束与多语言 locale（EN、RU、ZH_TW 等）
  • 支持表级 filter（only/except、通配符）、dump_condition/transform_condition/limit、SQL 断言校验，以及输出到文件或 STDOUT 管道
  • 提供预编译二进制、Homebrew 与 Docker（对应 PostgreSQL 14–17）三种安装方式，dump 为原生 SQL 无需第三方导入工具

适用场景（解读层）

  • 生成包含脱敏数据的数据库名 dump，用于开发或测试环境导入
  • 通过 STDOUT 管道将脱敏导出集成到既有数据流转流程中
  • 导出前用 SQL 断言校验源数据（如唯一邮箱、计数范围）
