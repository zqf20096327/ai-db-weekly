mysql2yasdb 是一个将 MySQL 数据同步到 YashanDB 的命令行迁移工具

综述（解读层）

该工具面向需要将数据从 MySQL 迁移到 YashanDB 的用户，提供 export、sync、check 三条子命令：export 读取 MySQL 元数据生成 YashanDB 建表 DDL，sync 按配置文件迁移表数据，check 校验迁移结果。工具依赖 libyascli 等 lib 包运行，导出的 DDL 直接执行可能报错，需手动修改。

  • 读取 MySQL 中的表、约束、默认值、自增序列、主键、外键、索引、视图并生成 YashanDB 的元数据创建 SQL，暂不包含存储过程、自定义函数和触发器
  • 数据迁移支持表模式、库模式、模式对应、并行迁移、批量处理、指定排除表和表的过滤条件等配置参数
  • 提供 check 子命令校验 MySQL 与 YashanDB 中指定表的数据是否一致

适用场景（解读层）

  • 将 MySQL 数据库指定 schema 或表的 DDL 导出为 YashanDB 建表脚本
  • 以并行、批量等方式将 MySQL 表数据迁移到 YashanDB
  • 迁移完成后校验源库与目标库的数据一致性
