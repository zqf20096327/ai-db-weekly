iOS 端 SQLite3 API 的 Swift 封装与使用教程库

综述（解读层）

该仓库以教程加代码的形式介绍 iOS 中 SQLite3 的封装与使用，内容涵盖打开/关闭数据库、执行 SQL、查询、事务、二进制数据绑定、表结构版本控制、索引与加密等。面向需要在 iOS 本地持久化中直接使用 SQLite3 C API 的 Swift 开发者。代码在执行数据库操作时加入同步锁，加密部分依赖第三方库 SQLCipher。

  • 提供 openDB、execSql、querySql、doTransaction 等 Swift 封装方法，并在每次数据库操作中使用 objc_sync_enter 同步锁
  • 支持通过 BEGIN/COMMIT/ROLLBACK 使用事务，以及通过 sqlite3_bind 系列函数处理二进制等特殊类型数据
  • 包含基于 UserDefaults 的表结构版本控制示例和 SQLite 加密说明（使用 SQLCipher 与 sqlite3_key/sqlite3_rekey）

适用场景（解读层）

  • iOS 应用中的本地结构化数据持久化
  • 需要事务批量写入或二进制数据存取的场景
  • 需要对本地数据库加密或多版本表结构升级管理的场景
