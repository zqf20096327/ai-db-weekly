SQLite C API 的 Swift 类型化薄封装，无新增抽象、非抛错设计

综述（解读层）

LSQLite 是一个 Swift 编写的 SQLite C API 薄封装库，将 OpaquePointer 句柄和 Int32 常量包装为 Connection、Statement、ResultCode 等类型，保持与 C API 一比一的名称和语义，仍以结果码而非 throw 处理错误。包装函数为 @inlinable 单行转发，并支持通过 rawValue 与 C API 互操作。适合已熟悉 SQLite C API、希望在 Swift 中获得类型安全的开发者；不提供 ORM、查询构建器或自动迁移。

  • 将 SQLite C API 一比一映射为 Swift 类型化接口，保留 prepare → bind → step 流程与结果码错误处理
  • 公开 API 为 @inlinable 转发，且 SQLite #define 常量以真正的 Swift 常量暴露
  • 通过 rawValue 可与原生 C API 双向互操作，全部公共符号附 Swift 文档注释

适用场景（解读层）

  • 在 Swift 项目中以类型安全方式直接使用 SQLite C API
  • 对现有 C API 代码库逐步引入 Swift 封装，可随时回退到原始句柄
  • 需要完整 SQLite 文档注释与 IDE 内联提示的开发场景
