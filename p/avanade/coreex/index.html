🧭 简介解读层（AI·证据行可回查）

面向.NET后端服务的框架，提供运行时原语、数据访问与事件通信的模块化组件集合。

综述（解读层）

CoreEx是一个由多个NuGet包组成的.NET框架，用于构建企业后端服务。核心包提供运行时原语，其余包按需添加AspNetCore集成、事件发布订阅、数据库访问、校验等能力。它将异常到HTTP响应映射、领域事件发布、单元OfWork等.NET未内置标准化的场景给出统一实现，采用可选模块化设计，抽象接口可替换扩展。适用于使用.NET构建微服务与事件驱动服务的团队。

  • 提供类型化异常体系并自动映射HTTP状态码与ProblemDetails序列化，包含Result类型的Railway-Oriented Programming支持
  • 数据层支持ADO.NET抽象、Entity Framework Core与Azure Cosmos DB，共享IUnitOfWork事务编排，含SQL Server与PostgreSQL实现及OpenTelemetry指标
  • 事件消息支持EventData与CloudEvents格式转换、事务性outbox中继，以及Azure Service Bus的命令队列/事件主题路由与死信处理

适用场景（解读层）

  • 构建需要统一错误响应格式、校验与幂等键处理的ASP.NET Core Web API服务
  • 实现事件驱动或最终一致性的微服务架构，需事务性发布领域事件
  • 管理带缓存与有效期校验的引用数据，以及跨SQL Server、PostgreSQL、Cosmos DB的数据访问
