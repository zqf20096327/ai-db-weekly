PostgREST 的 Go 客户端库，以 ORM 风格链式调用接口操作 REST API

综述（解读层）

该库为 PostgREST 提供 Go 语言客户端，目标是构建类似 ORM 的 RESTful 接口，适用于需要在 Go 程序中通过 PostgREST 访问 PostgreSQL 的开发者。README 标注该项目已不再由 Supabase 或社区积极维护，官方正在开发 Supabase Go SDK。支持链式查询构建、结构化响应与上下文感知的 Execute 方法。

  • 提供 Select/Insert/Update/Upsert/Delete/RPC 的链式查询构建接口，含 Eq、In、TextSearch、Or 等 17 种过滤器方法
  • main 分支支持泛型、结构化响应（PostgrestResponse[T]）、ExecuteTo 直接反序列化、Schema 切换与 CSV/GeoJSON/Explain 输出格式
  • 集成测试使用 testcontainers-go 启动真实 PostgreSQL 与 PostgREST 容器，也可通过环境变量连接已有实例

适用场景（解读层）

  • 在 Go 服务中通过 PostgREST 对 PostgreSQL 表执行增删改查与调用数据库函数
  • 需要复杂过滤（全文检索、数组/jsonb 包含、OR 条件）及排序、分页、单行结果的查询场景
  • 对接 Supabase 等 PostgREST 风格 API 服务的 Go 应用（需注意项目维护状态）
