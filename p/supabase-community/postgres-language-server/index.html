基于 libpg_query 解析器的 Postgres 语言服务器（LSP）实现

综述（解读层）

该项目为 Postgres 开发提供语言工具集与 LSP 实现，底层使用 Postgres 自身的解析器 libpg_query。所有功能可通过 LSP、CLI、HTTP API 和 WebAssembly 模块访问，采用传输无关的 Server-Client 架构，适配 VSCode、Neovim、Zed 等编辑器。功能包含自动补全、语法诊断、类型检查、格式化、迁移与数据库 lint 及 PL/pgSQL 支持。本地开发依赖 Nix 与 just 工作流。

  • 提供自动补全、悬停提示、Inlay Hints 与语义高亮，支持语法诊断、类型检查与格式化
  • 包含迁移 lint、数据库 lint 与 PL/pgSQL 支持，解析基于 libpg_query
  • 功能可通过 LSP、CLI、HTTP API 和 WebAssembly 模块四种途径访问

适用场景（解读层）

  • 在 VSCode、Cursor、Neovim、Zed、Sublime Text 等编辑器中接入 Postgres SQL 语言服务
  • 通过 CLI 或 HTTP API 在编辑器之外运行 SQL 诊断、格式化与 lint 检查
  • 在浏览器等 WebAssembly 运行环境中调用其语言工具能力
