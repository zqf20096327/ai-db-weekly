🧭 简介解读层（AI·证据行可回查）

Java编写的数据库仿真数据填充库，按字段类型批量生成插入数据

综述（解读层）

SqlFaker 是一个用于向数据库批量插入仿真数据的 Java 库。开发者通过链式 API 为表字段指定数据生成器，即可生成并执行 INSERT 语句，README 提及可用于数据库调优场景。它支持 MySQL、Oracle、SQL Server、Sqlite、H2 五种数据库，内置 8 种数据类型，并支持实现 RandomData 接口自定义生成器；项目以 Maven 依赖形式发布，要求 JDK 1.6 及以上版本。

  • 内置 ID、用户名、时间、手机号、地址、年龄、性别、邮箱 8 种 DataType 数据生成器，并支持实现 RandomData 接口自定义扩展
  • 提供 Values.of 随机取值、Generator.of 有序循环取值、数值/时间范围取值等多种字段填充方式
  • 通过链式 API 设置表名、字段与插入条数后执行，支持 onlyShowSql 仅显示 SQL、支持事务，支持一次性插入大量数据

适用场景（解读层）

  • 为数据库表批量插入仿真测试数据，用于数据库调优等操作
  • 在开发或测试环境中按范围（数值、时间、枚举列表）生成有规律的填充数据
  • 为已有数据库表反向生成 Java 代码文件，在其基础上继续开发
📖 README 首段存档原文 · 程序抽取

SqlFaker是一个Java开发的可快速为数据库生成大量仿真的工具，仅需简单的配置，即可为数据库表批量插入有规律的类似真实数据的内容，可用于数据库调优等操作。
