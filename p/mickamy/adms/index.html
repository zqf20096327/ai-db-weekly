基于数据库模式自省生成 PostgREST 风格 HTTP API 与可选管理 UI 的单二进制工具

综述（解读层）

adms 是一个 Go 编写的单二进制工具，连接 PostgreSQL 或 MySQL 后在启动时自省数据库模式，自动将每张表暴露为 /<table> 资源，提供过滤、投影、排序、分页、FK 嵌套等查询参数和 POST/PATCH/DELETE 写操作。配置 ui.enabled: true 后同进程在另一端口附带浏览器管理界面。PATCH/DELETE 强制带过滤条件以防全表更新；MIT 协议。适合需要基于现有数据库快速生成读写 API 或内部数据管理界面的开发者。

  • 启动时自省数据库模式，为每张表生成 PostgREST 风格的 REST 端点，支持 eq/gt/ilike/in 等过滤操作符、列投影、排序、分页和基于外键的可嵌套关联行读取
  • 支持 POST 插入（含批量）、PATCH 更新、DELETE 删除，PATCH/DELETE 拒绝无过滤条件的请求，并提供 Prefer 头控制返回内容与行数统计
  • 可选的嵌入式管理 UI（默认关闭）独立监听端口运行，包含行浏览/过滤/分页、内联编辑、CSV/JSON 导出、模式 ER 图，前端资源通过 embed.FS 打包进二进制，无需外部 CDN

适用场景（解读层）

  • 为现有 PostgreSQL/MySQL 数据库快速生成前后端可直接调用的 CRUD HTTP API，无需编写服务层代码
  • 在受限网络（无外网访问）环境中部署带管理界面的数据查看/编辑工具
  • 内部运营后台：通过浏览器对数据表进行过滤、排序、分页浏览和内联编辑，并导出 CSV/JSON
