🧭 简介解读层（AI·证据行可回查）

通过 Docker 或 Helm 部署的数据库管理后台面板服务

综述（解读层）

RocketAdmin 是一个用于为服务创建数据库管理面板的应用，支持 PostgreSQL、MySQL、MSSQL、Oracle 等数据库。通过 Docker 拉取 rocketadmin/rocketadmin 镜像或使用 Helm chart 部署，容器在 8080 端口提供服务，首次访问通过浏览器页面创建管理员账户。运行需配置 DATABASE_URL（或内置 PGLite）、JWT_SECRET、PRIVATE_KEY 等环境变量，数据库凭据以 PRIVATE_KEY 加密存储；可选配置 SMTP 用于发送邀请邮件，未配置时邀请链接打印到后端日志。

  • 提供 Docker 镜像（rocketadmin/rocketadmin）与 Helm chart 两种部署方式，容器默认监听 8080 端口
  • 通过环境变量配置内部数据库连接（DATABASE_URL 或 PGLITE_FOLDER_PATH）、JWT 密钥与凭据加密私钥
  • 支持可选 SMTP 邮件配置与 OPENAI_API_KEY，未配置相应变量时对应功能停用或以日志方式输出

适用场景（解读层）

  • 为使用 PostgreSQL、MySQL、MSSQL、Oracle 等数据库的服务自托管管理面板
  • 在 Kubernetes 环境中通过 Helm 安装并使用 values.yaml 定制配置
  • 无法配置 SMTP 的环境中部署，通过后端日志获取邀请与确认链接完成账户设置
