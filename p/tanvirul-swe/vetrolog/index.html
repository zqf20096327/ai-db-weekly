🧭 简介解读层（AI·证据行可回查）

基于 Wails 的桌面端移动应用本地数据库查看器，支持 ADB 实时读取 SQLite。

综述（解读层）

VetroLog 是一个用 Go 与 React（Wails 框架）构建的桌面数据库检查工具，面向 Flutter、Android、iOS、React Native 开发者。通过 USB 连接 Android 设备并启用调试模式，无需修改应用代码即可浏览、查询和编辑其 SQLite 数据库，并支持 WAL/-shm 实时同步。它同时提供 VS Code 扩展、--web 浏览器模式和远程数据库连接（PostgreSQL、MySQL、Redis 等），可从源码构建，采用 MIT 协议开源。

  • 通过 ADB 连接 Android 设备，无需修改应用代码即可查看 SQLite 数据库，支持基于 WAL/-shm 的实时插入、更新、删除同步与双向单元格编辑
  • 提供桌面应用（macOS/Windows/Linux）、--web 浏览器模式和 VS Code 扩展三种运行形态
  • 包含 SQL 查询计划可视化（EXPLAIN QUERY PLAN）、ER 图生成（导出 DBML/Mermaid/SVG/SQL DDL）与自然语言转 SQL（离线及 Gemini/OpenAI/Ollama）功能

适用场景（解读层）

  • 移动应用开发调试中实时查看和修改设备沙盒内的 SQLite 数据
  • 在 VS Code 或浏览器中检查本地工作区数据库及远程 PostgreSQL/MySQL/MariaDB/MSSQL/Redis
  • 浏览连接数据库的自动生成 ER 图并导出多种格式
