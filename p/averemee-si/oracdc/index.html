面向 Kafka Connect 的 Oracle 数据库变更数据捕获（CDC）连接器套件

综述（解读层）

oracdc 是一组 Apache Kafka Connect 连接器，用于捕获 Oracle 数据库（9i 至 26ai）的变更并写入 Kafka，供事件驱动架构或异构数据集成使用。包含直接读取 redo 日志、基于 LogMiner、基于物化视图日志三种源连接器，以及面向 PostgreSQL/Oracle 的 JDBC sink 连接器和 NUMBER、INTERVAL 等类型转换器，发布于 GitHub、Confluent Hub、DockerHub 和 Maven Central，采用 AGPL 与商业双许可。

  • 提供三个 CDC 源连接器：OraCdcRedoMinerConnector 直接读取 redo 日志文件，OraCdcLogMinerConnector 使用 Oracle LogMiner，KafkaSourceSnapshotLogConnector 读取物化视图日志
  • RedoMiner 连接器不向数据库写入对象、不需在数据库服务器安装额外软件，支持 Oracle RAC、ASM 流式读取及 SSH/SMB/BFILENAME 传输方式，可使用物理备库作为变更来源
  • 包含两个针对 PostgreSQL/Oracle 优化的 sink 连接器，以及 Oracle NUMBER/INTERVAL 原生类型到 Kafka 类型的转换器和多个字段/键转换器

适用场景（解读层）

  • 将 Oracle 源系统变更以事件形式发布到 Kafka，用于事件驱动架构
  • Oracle 到 PostgreSQL 或其他异构系统的数据集成与复制
  • 组织安全策略允许 SYSASM/SYSDBA 远程连接 ASM 时，用 RedoMiner 方式降低数据库实例上的 CPU/IO 负载；不允许时改用 LogMiner 方式
