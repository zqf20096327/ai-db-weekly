🧭 简介解读层（AI·证据行可回查）

Go 编写的非侵入式 SQL 缓存库，将 SQL 转为 id 缓存并复用实体。

综述（解读层）

gdcache 是一个用 Go 实现的非侵入式缓存库，用于缓存 SQL 查询结果。其核心机制是把 SQL 转换为 id 并缓存 id 对应的实体，使相同 id 的查询复用实体内容，仅缓存一次实体值以节省内存。使用者需让缓存类实现 TableName() 方法并通过 cache 标签指定缓存键，同时实现 ICache 与 IDB 接口以接入底层缓存（如 redis、gocache）和数据库（Gorm、Xorm 或原生 SQL）。

  • 自动缓存 SQL，并将 SQL 转换为 id 以复用对应实体内容
  • 适配 Xorm 和 Gorm 框架，也可通过实现 IDB 接口使用原生 SQL
  • 支持联合键缓存，可通过实现 ICache 接口使用 redis 或 gocache 作为底层缓存

适用场景（解读层）

  • 对 Gorm 或 Xorm ORM 查询结果进行缓存
  • 多个 SQL 查询需复用相同实体内容以减少重复缓存的场景
  • 自定义底层缓存实现（如 redis、内存缓存）的应用
