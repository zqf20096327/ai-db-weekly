Rust 编写的无头仪表盘后端，按声明式请求自动生成 SQL 查询

综述（解读层）

Frolic 是一个用 Rust 编写的开源后端服务，用于支撑面向客户的仪表盘。用户连接数据库后，通过单个 API 端点以 JSON 声明 metrics（含表.列格式与聚合操作符）和 dimensions，服务自动生成并执行 SQL、处理表关系，并可用 memcached 缓存调用。支持 MySQL、Postgres 与 Clickhouse，可搭配 frolic-react 构建 UI。部署采用 docker-compose 并在 config.toml 配置数据库。

  • 提供单一 API 端点，通过 metrics 与 dimensions 字段以 JSON 请求查询仪表盘数据
  • 自动生成并执行 SQL 查询，并自动处理表关系
  • 使用 memcached 缓存 API 调用；当前支持 MySQL、Postgres 与 Clickhouse

适用场景（解读层）

  • 为面向客户的仪表盘提供数据查询后端，免去为各组件编写自定义 API
  • 已有 MySQL/Postgres/Clickhouse 数据库，需直接连接并生成查询的项目
  • 配合 frolic-react 前端构建全栈仪表盘
