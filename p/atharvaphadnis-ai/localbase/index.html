单文件 Python 自托管后端，基于 FastAPI 与 SQLite 生成 REST API

综述（解读层）

LocalBase 是一个以单个 Python 文件运行的自托管后端平台，基于 FastAPI、Uvicorn 和 SQLite 构建，面向需要在本地或局域网中搭建数据后端的开发者。每个项目对应独立的 SQLite 数据库文件，自动生成带过滤、排序、分页的 REST API，并通过内嵌的 Web 控制台提供 SQL 编辑器、数据表格编辑、API 密钥管理、备份与请求日志等功能。运行仅要求 Python 3.11+ 与 pip，不需要 Node.js 或外部数据库服务。

  • 单文件 Python 应用，执行 python localbase.py 即可启动，默认监听 127.0.0.1:8000
  • 为每个项目自动生成 REST API，支持查询过滤（eq/gt 等运算符）、排序、分页，单次查询上限 1000 条记录
  • 提供 API 密钥管理（public/server 两种角色）、WebSocket 事件、数据库备份、CSV 导入与 CSV/JSON 导出

适用场景（解读层）

  • 本地开发环境或局域网（IoT 设备通过 HTTP 上报数据）的轻量数据后端
  • 需要快速为 SQLite 数据暴露 REST API 并附带管理控制台的项目
  • 配合反向代理或 Cloudflare Tunnel 部署到服务器的自托管场景
