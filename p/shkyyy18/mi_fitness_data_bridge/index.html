🧭 简介解读层（AI·证据行可回查）

将小米运动健康数据导出为本地 SQLite、CSV、JSON 的非官方连接器，含 stdio MCP 服务。

综述（解读层）

该工具通过小米的非公开云接口同步 Mi Fitness 数据（活动、睡眠、运动、心率等），缓存到本地 SQLite 并导出 CSV/JSON，同时提供本机 stdio MCP 查询服务和 Python 接口。面向希望自行备份和分析个人健康数据的用户。它是非官方实验性项目，依赖上游接口，兼容性受设备、固件与账户地区影响，需 Python 3.11+，采用 AGPL-3.0-only 许可。

  • 支持同步日常活动、睡眠、运动记录、身体测量、心率、血氧、压力和异常心跳八类数据，指定日期范围的重复同步为幂等
  • 提供 sync/export/serve/doctor 等 CLI 命令，导出 JSON（UTF-8）与 CSV（utf-8-sig），凭证保存到本机操作系统密钥环
  • 本地 stdio MCP 服务包含查询、同步控制等 18 个工具，记录列表支持 limit/offset 分页，任务状态保存在本地 SQLite

适用场景（解读层）

  • 将个人小米运动健康数据备份为本机 SQLite、CSV 或 JSON 文件
  • 在本地 AI 工作流中通过 MCP 客户端查询已同步的健康与运动记录
  • 作为 Python 依赖（包名 mi_fitness_mcp）接入自定义分析程序
