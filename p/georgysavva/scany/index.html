综述（解读层）

scany 是一个 Go 数据扫描库，用于把数据库查询结果映射到结构体、map 或基本类型，免去手动迭代行和逐列 Scan 的样板代码。它不是 ORM，只支持数据库到对象单向扫描，不处理对象关系，也不生成查询。通过 sqlscan 支持 database/sql，通过 pgxscan 支持 pgx 原生接口，核心逻辑在 dbscan 包，可扩展到其他数据库库。安装：go get github.com/georgysavva/scany/v2，MIT 许可。

  • 支持 database/sql 驱动的任意数据库及 pgx 原生接口，提供 sqlscan、pgxscan、dbscan 三个包
  • 通过结构体标签自定义列名，支持嵌套/嵌入结构体复用、NULL 与自定义类型、省略字段
  • 除结构体外，支持 map 和 Go 基本类型作为扫描目标，并允许覆盖默认设置

适用场景（解读层）

  • 直接使用数据库驱动而不想引入 ORM 的 Go 项目中简化行扫描代码
  • 使用 pgx 原生接口访问 PostgreSQL 并需要结果映射到结构体的场景
  • 需要将查询结果扫描进 map 或基本类型等非结构体目标的场合
