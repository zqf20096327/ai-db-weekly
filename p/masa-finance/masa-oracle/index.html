去中心化数据协议，通过 Oracle 节点和 Worker 节点的 P2P 网络提供 AI 训练数据与计算资源交易。

综述（解读层）

Masa Oracle 是一个用 Go 编写的去中心化数据协议实现，网络由 Oracle Node 和 Worker Node 组成。Worker 节点通过质押代币接收并处理来自 Oracle 节点的数据与 LLM 请求，可获得网络排放和费用；Oracle 节点面向开发者，用于向 Worker 节点提交数据或 LLM 请求。项目另含 Masa Bittensor 子网，聚焦 Twitter 数据。README 未提供具体安装运行步骤，需查阅文档。

  • 支持两类节点角色：Worker 节点处理数据和 LLM 请求，Oracle 节点提交请求
  • 包含 Twitter Scraper、Web Scraper、Discord Profile Scraper 等数据源组件
  • 参与节点需质押代币，按可用性与在线时长获得网络排放和费用

适用场景（解读层）

  • 需要获取 Twitter、网页、Discord 等数据源用于 AI 训练的场景
  • 开发者通过 Oracle 节点访问开源 LLM 服务
  • 数据或计算资源贡献者运行 Worker 节点以获取收益
