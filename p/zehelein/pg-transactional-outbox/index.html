基于 PostgreSQL 与 TypeScript 实现事务性发件箱/收件箱模式的库

综述（解读层）

该库为 PostgreSQL、TypeScript 及消息代理/事件流场景实现事务性发件箱与收件箱模式：将外发消息作为业务数据库事务的一部分存储，并对入站消息去重存储、使处理程序恰好处理一次。适用于对消息可靠性有要求的事件驱动架构，README 提供模式介绍，并含单元与集成测试及 RabbitMQ 示例。

  • 将外发消息作为业务逻辑数据库事务的一部分可靠存储，至少发送一次
  • 存储入站消息恰好一次，使处理程序恰好处理一次
  • 包含单元测试、基于 PostgreSQL 实例的 outbox/inbox 集成测试，以及 RabbitMQ 示例实现

适用场景（解读层）

  • 事件驱动架构中需要原子性写入业务数据与消息的场景
  • 使用 PostgreSQL 与 TypeScript 的微服务间消息传递
  • 以 RabbitMQ 为消息代理时实现事务性 outbox/inbox 流程
