基于 Laravel 模型或数据库表生成 CRUD 后台的扩展包

综述（解读层）

easy-crud 是一个 Laravel 扩展包，通过 composer 安装并注册服务提供者后，可从已定义的 Laravel 模型生成 CRUD 管理界面，界面基于 Gentelella Bootstrap 后台模板。使用时需在生成的 easy-crud.php 配置文件的 models 数组中登记要管理的模型，键名为后台显示的标签。注意其兼容范围仅覆盖 Laravel 5.1 和 5.2，从数据库表生成 CRUD 的功能 README 标注为尚未就绪。

  • 支持从 Laravel 模型生成 CRUD 管理界面
  • 界面基于 Gentelella Bootstrap 后台模板
  • 支持防止与已定义路由发生冲突

适用场景（解读层）

  • 为已有 Laravel 5.1/5.2 项目的模型快速生成数据管理后台
  • 需要带管理模板的简单数据维护界面
