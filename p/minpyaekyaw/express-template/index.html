基于 Express.js + TypeScript 的 RBAC 后端启动模板

综述（解读层）

该项目是一个 Express.js 与 TypeScript 编写的后端启动模板，内置 RBAC 权限控制、JWT 认证、带分页/筛选/排序的 CRUD 接口、软删除、文件上传、访问与审计日志，以及基于 node-cron 和 Redis/BullMQ 的定时与队列任务。技术栈为 MySQL+Knex，通过 Docker Compose 一键启动并自动执行迁移和种子数据，适合需要角色权限体系的 Node.js 后端开发者。

  • 提供 RBAC 角色权限控制与基于 JWT 的认证登录，种子数据预置多个测试用户
  • 实现带分页、筛选、排序、搜索的 CRUD 接口，支持软删除与批量创建/删除
  • 集成访问日志、审计日志（含前后快照）、node-cron 定时任务和 Redis/BullMQ 任务队列

适用场景（解读层）

  • 需要角色权限体系的管理后台或内部工具后端
  • Web/移动应用的 API 服务起点
  • SaaS 产品的后端原型与脚手架
