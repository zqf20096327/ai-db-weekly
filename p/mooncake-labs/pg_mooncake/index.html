Postgres 扩展，为表创建 Iceberg 列存镜像以支持实时分析查询

综述（解读层）

pg_mooncake 是一个 Postgres 扩展，通过 moonlink 组件实时摄取 INSERT/UPDATE/DELETE，在 Iceberg 中维护表的列存镜像，并借助 DuckDB 加速分析查询。用户用普通 SQL 创建镜像表即可同步查询。构建需 Rust、pgrx 和 DuckDB 构建工具，运行需配置 shared_preload_libraries 并开启逻辑复制，支持 Postgres 14-18。

  • 通过 moonlink 支持流式和批量 INSERT/UPDATE/DELETE 实时摄取
  • 基于 DuckDB 加速分析查询
  • 数据以 Iceberg 格式存储，可被其他查询引擎读取

适用场景（解读层）

  • 对 Postgres 表执行低延迟分析查询
  • 构建数据可供其他引擎访问的 Iceberg 湖仓
  • 流式与批量数据同步写入的分析场景
