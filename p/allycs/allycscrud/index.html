🧭 简介解读层（AI·证据行可回查）

基于 Dapper 的增删改查扩展库，封装常用 CRUD、分页与实体-SQL 命名映射。

综述（解读层）

ALLYCSCRUD 是对 Dapper 的扩展封装，提供按主键/条件查询、插入、更新、删除、计数和分页的同步与异步方法，支持 MSSQL、MySQL、PostgreSQL、SQLite。通过启动时 SetDBType 配置数据库类型、schema 与大小写转换（AaBb 转 aa_bb），并支持自定义表名、标签指定表名与属性名映射。异步方法要求 .NET 4.5 以上或 .NET Core。

  • 提供 Get/GetList/GetListPaged/Insert/Update/Delete/RecordCount 等同步与异步扩展方法，条件可用匿名对象或字符串 WHERE 传入
  • 启动时通过 SetDBType 配置数据库类型、schema 名及实体属性到列名的大小写转换（AaBb 转 aa_bb）
  • 支持 [Table]/[Column] 标签自定义表名与属性名映射，查询时可传入非必传表名

适用场景（解读层）

  • 在 .NET 4.5+ 或 .NET Core 项目中通过 Dapper 执行常规增删改查与分页查询
  • 实体类名/属性名与数据库表名、列名不一致（如 AaBb 对应 aa_bb）时的映射处理
  • 需在同一项目中连接多种数据库（MSSQL、MySQL、PostgreSQL、SQLite）并指定 schema 的场景
