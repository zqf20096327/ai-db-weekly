综述（解读层）

OpenTrace 是一个 Rust 单二进制工具，作为本地反向代理拦截 LLM API 调用并把请求/响应写入本机 SQLite（默认 ~/.trace/trace.db）。使用者只需将 OPENAI_BASE_URL 指向代理端口即可接入，无需改代码；提供 stats、query、watch、report、serve 等子命令及本地 Web 面板查看用量与成本。数据保留默认 90 天，支持字段脱敏、预算告警和 CI 成本检查。

  • 单二进制反向代理，记录请求/响应到本地 SQLite，支持设置保留天数、字段脱敏与不存请求体
  • 提供 query/stats/watch/report/serve 等命令和本地 Web 面板，展示延迟、token、成本与错误分类
  • 支持 X-Trace-Tag 标记调用、Prometheus 指标、OTLP 导出、价格自定义及 CI 中的成本超限退出码

适用场景（解读层）

  • 在不修改代码的情况下本地记录和检查应用的 LLM API 调用
  • 在 CI 流水线中生成成本报告并在支出超过阈值时使任务失败
  • 按标签/模型/状态筛选排查失败调用（限流、超时、上游 5xx 等）
