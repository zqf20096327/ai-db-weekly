将 Markdown 解析为区间索引块并以 SQL/mq 查询的嵌入式数据库

综述（解读层）

mq-db 是 Rust 编写的嵌入式数据库，把 Markdown 文档解析为带前序/后序区间索引的块列表，使章节层级查询化为单次整数比较，支持 SQL 与 mq 查询、写回源文件，并提供 CLI、REPL、TUI、HTTP 服务与 Rust 库多种使用形式。安装走脚本或 cargo install。项目处于活跃开发期，README 明确警告 API 可能变动。

  • 块列表采用前序/后序区间索引，配合 under() 支持章节层级查询
  • 支持 SQL 与 mq 查询、CTE、EXPLAIN、视图、ATTACH，以及 INSERT/UPDATE/DELETE 写回源 Markdown
  • 提供全文检索（match/bm25）、基于 HNSW 的向量搜索，以及增量重建索引、zone map 和二级索引

适用场景（解读层）

  • 对文档目录建立索引后按章节层级检索 Markdown 内容
  • 通过 SQL 或 mq 对 Markdown 块执行查询、更新并写回源文件
  • 结合 bm25 全文检索与 HNSW 向量搜索做语义查找
