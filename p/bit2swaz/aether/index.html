🧭 简介解读层（AI·证据行可回查）

基于 Raft 复制 SQLite 并以 Postgres 协议暴露的分布式数据库

综述（解读层）

Aether 是用 Go 编写的分布式关系数据库，通过 Raft 共识算法在集群内复制 SQLite，并向外提供 PostgreSQL v3.0 线协议接口，可用 psql 等标准客户端连接。写入需定向到 leader，follower 上的写请求会被拒绝；读取由本地节点响应，可能读到过期数据。v1.0 定位为教学性质的引擎，不支持 PL/pgSQL、存储过程等 Postgres 特有功能，SSL/TLS 未启用。

  • 实现 PostgreSQL v3.0 线协议，可使用 psql、pgAdmin 等 Postgres 客户端连接
  • 基于 hashicorp raft 实现强一致复制，leader 失效后自动选举新 leader
  • 使用 SQLite 的 VACUUM INTO 生成快照，内置 Prometheus 指标与 system_nodes 等系统表用于集群检查

适用场景（解读层）

  • 需要通过 Postgres 协议访问 SQLite 数据的场景
  • 学习 Raft 共识、leader-follower 复制与数据库引擎实现的场景
  • 使用 docker compose 或单节点 docker 部署的本地/内网环境（v1.0 未启用 TLS，不应直接暴露公网）
