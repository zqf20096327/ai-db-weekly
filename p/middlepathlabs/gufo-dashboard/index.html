🧭 简介解读层（AI·证据行可回查）

为 Gufo 推理服务器提供本地统计面板与 HTTP/SSE/WebSocket 代理的应用

综述（解读层）

Gufo Dashboard 是一个部署在本地的统计仪表盘与代理服务，客户端将请求经其转发至 Gufo 推理服务器时，会按模型记录令牌用量、吞吐、首字延迟、缓存命中等指标并存入 SQLite。它支持 Chat Completions、Completions、Responses、Messages 等 OpenAI 兼容端点及 WebSocket 代理；无内置认证与 TLS，仅适用于可信本地网络，需自行限制访问地址。

  • 代理 HTTP、SSE 与双向 WebSocket（含文本和二进制音频）响应，覆盖 Chat Completions、Completions、Responses、Messages 及 Gufo 原生 /completion 端点
  • 统计存入 SQLite，支持可配置保留期、每日汇总，按模型分别记录吞吐、首字延迟、缓存命中与草稿接受率
  • 可选内容捕获（默认关闭）与投影端口模式，支持 Python（3.12+，uv）或 Docker Compose 部署，前端无构建步骤

适用场景（解读层）

  • 在本地或私有网络中运行 Gufo 推理服务器，需要通过代理查看各模型的请求指标与延迟分位的场景
  • 需要审计通过代理的问答文本（可选功能，含保留期与删除控制）的自托管部署
  • 需要通过投影端口为无法修改请求体的客户端注入 projection 字段并对比普通与投影请求
