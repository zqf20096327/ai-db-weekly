分布式时序数据库，内存列式存储，兼容 Prometheus PromQL 查询

综述（解读层）

FiloDB 是用 Scala 编写的开源分布式时序/事件数据库，支持 PromQL 查询。典型部署为集群独立进程，经 Akka Cluster 组成对等集群，从 Kafka 实时摄取数据并用 Cassandra 持久化，数据摄取后即可查询。构建需 Java 11、SBT、Rust 与 C 编译器。README 声明其不适用于重事务更新型和 OLAP 分析场景。

  • 支持 PromQL 查询与基于标签（tag）的时序索引
  • 从 Kafka 实时摄取数据，数据摄取后立即可查询，采用列式压缩的内存存储与堆外内存管理
  • 内置分布式查询与分片，支持双数据中心运行，附 Gateway 服务接收 TCP 指标数据（当前支持 Influx Line Protocol）

适用场景（解读层）

  • 实时运维指标的存储、查询与仪表盘展示
  • 分布式追踪（类 Zipkin）数据存储
  • 实时事件存储与查询、低延迟应用指标调试
