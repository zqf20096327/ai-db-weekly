🧭 简介解读层（AI·证据行可回查）

自托管的家庭实验室状态面板，单一 Go 二进制配 SQLite，自动发现 Docker 容器

综述（解读层）

Lantern 是面向家庭/私有网络的自托管状态监控面板，用 Go 编写、依赖 SQLite 且无 CGO。它通过挂载 Docker socket 自动发现并轮询容器，也接受心跳推送或主动执行 HTTP/TCP/ICMP 检查，三种来源写入同一历史。默认安装完全开放，需在首次启动后手动开启登录；若暴露公网，README 建议前置带 TLS 的反向代理。

  • 支持 Docker socket 自动发现容器、POST /api/status 心跳推送、HTTP(S)/TCP/ICMP 主动检查三种监控来源，统一写入同一历史
  • 提供 WebSocket 实时仪表盘、公开 /status 状态页、Discord/Telegram/Gotify/通用 JSON 告警渠道及静默时段、维护模式、服务依赖抑制
  • 包含 owner/admin/viewer 三种角色、bcrypt 密码、可选 TOTP、作用域 API token 和审计日志，并通过 /metrics 暴露 Prometheus 指标

适用场景（解读层）

  • 监控家庭实验室中的 Docker 容器并查看其端口、镜像、网络拓扑与在线时间
  • 为 NAT 后主机、systemd 单元、cron 任务等无法主动探测的对象提供心跳上报
  • 对外发布可自定义品牌的状态页和状态徽章，用于 README 或独立域名展示
