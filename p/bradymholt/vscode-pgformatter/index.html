调用 Perl 版 pgFormatter 的 VS Code PostgreSQL SQL 格式化扩展

综述（解读层）

该扩展在 VS Code 中对 SQL 文件执行格式化，底层调用 Gilles Darold 开发的 Perl 工具 pgFormatter，因此运行环境需安装 Perl（可通过 PATH 或 pgFormatter.perlBinPath 指定）。面向需要统一 PostgreSQL SQL 代码风格的开发者，通过 editor.action.formatDocument 触发，支持保存时自动格式化，并提供缩进、逗号位置、关键字大小写等约二十项配置项。

  • 支持 SQL-92/99/2003/2008/2011 及 PostgreSQL 特有关键字的格式化
  • 提供缩进、逗号、大小写、换行等约二十项格式化配置，支持自定义 pg_format 配置文件
  • 支持 formatOnSave 自动格式化，以及通过首行注释 pgFormatter-ignore 跳过指定文件

适用场景（解读层）

  • VS Code 中编写或维护 PostgreSQL SQL 文件时统一代码风格
  • 需要按团队规范控制缩进、逗号与关键字大小写的 SQL 项目
  • 通过 files.associations 与 formatOnSave 将格式化纳入保存流程的工作流
