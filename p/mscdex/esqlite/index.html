基于 SQLite3MultipleCiphers 的 node.js SQLite 绑定，查询经队列异步执行并支持加密

综述（解读层）

esqlite 是 node.js 的 SQLite 绑定，底层使用 SQLite3MultipleCiphers，当前对应 SQLite 3.51.1。它提供统一的接口：打开/关闭为同步，查询仅异步并通过每连接队列在线程池执行；列值仅支持字符串、null 和 Buffer。加密仅支持 ChaCha20-Poly1305，通过 PRAGMA key/rekey/kdf_iter 控制。通过 npm install esqlite 安装，需 node-gyp 构建环境。

  • 基于 SQLite3MultipleCiphers，支持数据库加密，加密仅使用 ChaCha20-Poly1305，提供 PRAGMA key/rekey/kdf_iter 配置
  • 查询仅提供异步 API，经每连接队列在线程池执行，避免阻塞主线程
  • 支持流式读取行、authorizer 权限回调、interrupt 中断查询及多种打开标志（READONLY/MEMORY/SHAREDCACHE 等）

适用场景（解读层）

  • 需要在 node.js 中读写加密 SQLite 数据库的应用
  • 需要异步查询接口且希望避免事件循环阻塞的服务
  • 需要 authorizer 或流式逐行处理查询结果的场景
