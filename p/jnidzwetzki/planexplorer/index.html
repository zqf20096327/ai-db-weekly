在浏览器中可视化 PostgreSQL 查询计划随参数变化的 Web 应用

综述（解读层）

Plan Explorer 用于探索 PostgreSQL 查询计划器在不同参数下的执行计划选择，支持定义一至二维参数空间（如谓词选择度、成本参数），通过计划指纹分组着色相似计划并绘图展示。默认使用 PGlite（WebAssembly 版 PostgreSQL）在浏览器内运行，也可通过 Node.js 代理连接真实数据库。适用于研究查询优化器行为的开发者，README 注明其为研究原型。

  • 支持一至二维参数空间迭代，SQL 查询中用占位符（%%DIMENSION0%% 等）注入参数
  • 通过计划指纹自动分组并着色相似查询计划
  • 默认纯浏览器模式（PGlite），亦可经 Node.js 代理连接真实 PostgreSQL（dev:full 模式）

适用场景（解读层）

  • 观察选择度或成本参数变化时 PostgreSQL 在表扫描与索引扫描间的切换
  • 分析 random_page_cost 等规划器设置对计划选择的影响
  • 分析自连接等复杂查询的多种执行策略
