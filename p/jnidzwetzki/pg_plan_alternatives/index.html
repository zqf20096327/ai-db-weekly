🧭 简介解读层（AI·证据行可回查）

基于 eBPF 的 PostgreSQL 查询计划备选方案追踪器，展示优化器考虑过的全部计划。

综述（解读层）

该工具通过 eBPF 追踪 PostgreSQL 查询规划过程，输出优化器考虑的所有备选计划及其启动/总成本估算，并用 [CHOSEN] 标记最终选中计划，弥补 EXPLAIN 仅显示最终计划的不足。附带 visualize_plan_graph 工具可从 JSON 输出生成交互式图。支持 PostgreSQL 17/18，需 root 权限、含 DWARF 调试符号的 postgres 二进制及 nodetags.h 头文件。README 声明其为早期原型，不适用于生产环境。

  • 捕获查询规划期间优化器考虑的所有备选路径，含 startup/total 成本、行数估算，并以 [CHOSEN] 标记最终选中计划
  • 自动从 PostgreSQL 二进制的 DWARF 调试信息解析 planner 结构体偏移，支持 PostgreSQL 17 和 18
  • 提供 JSON 输出，配套 visualize_plan_graph 工具可生成 PNG/SVG 图，并可通过 --db-url 连接数据库将 OID 解析为表名

适用场景（解读层）

  • 研究 PostgreSQL 基于成本的优化器在特定查询中考虑过哪些执行路径（顺序扫描、索引扫描、位图扫描、各种连接策略等）
  • 教学或内部演示：将规划备选方案可视化为图，展示 ORDER BY、聚合、JOIN 等场景下优化器的决策过程
  • 将追踪结果与 EXPLAIN (VERBOSE, ANALYZE) 输出对照，核对最终计划的成本与行数估算
