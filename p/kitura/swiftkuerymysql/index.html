Swift-Kuery 框架的 MySQL 插件，用于以 Swift 操作 MySQL 数据。

综述（解读层）

SwiftKueryMySQL 是 Swift-Kuery 框架的 MySQL 插件，使开发者能用 Swift-Kuery 构建的查询操作 MySQL 数据库。要求 Swift 4.0 以上，支持 macOS 和 Linux，通过 MySQLConnection 或 URL 建立连接。连接不支持并发执行操作，多线程共享连接需使用自带的 ConnectionPool，超出容量的任务会排队等待。

  • 提供 MySQLConnection，支持参数或 URL 两种方式建立连接，所有连接参数均可选
  • 提供 ConnectionPool 连接池，确保连接不被多线程并发使用，超出的任务排队执行
  • 支持 Linux 下 MySQL 5.7 以下版本时通过 -Xcc 编译标志指定 MySQL 头文件路径

适用场景（解读层）

  • 在 Swift 应用中通过 Swift-Kuery 查询框架读写 MySQL 数据库
  • 多线程环境下需要共享 MySQL 连接的场景（配合 ConnectionPool 使用）
  • 使用 Cloud Foundry Swift buildpack 部署并连接 MySQL 的应用
