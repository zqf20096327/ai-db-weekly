🧭 简介解读层（AI·证据行可回查）

单二进制分布式任务服务器，用于异步排队执行 SQL 读作业

综述（解读层）

DungBeetle 是一个单二进制分布式作业服务器，用于排队并异步执行大量 SQL 读作业（如报表）。它从 .sql 文件加载命名任务，通过 Redis、AMQP 等共享 broker 实现多进程多线程队列，作业结果写入独立的 MySQL/Postgres 结果库中每个作业专属的临时表，供前端轮询读取。适合需要将报表层与主应用分离、避免大量并发查询压垮源库的团队；支持 MySQL、Postgres、ClickHouse 作为源库。

  • 支持 MySQL、PostgreSQL、ClickHouse 作为源数据库，MySQL、PostgreSQL 作为结果库
  • 以 goyesql 格式的 .sql 文件定义任务，启动时自动注册并预编译 SQL 语句，支持位置参数
  • 通过 Redis、AMQP 等 broker 后端实现多进程、多线程的分布式作业队列

适用场景（解读层）

  • 应用中用户报表生成的异步排队，避免大量并发查询压垮源数据库
  • 将报表查询层从应用中分离，后续的筛选、排序查询可发往临时的结果缓存库
  • 需要定时（eta）、重试或多作业并发分组执行的一批 SQL 查询场景
