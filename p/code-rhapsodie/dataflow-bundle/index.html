🧭 简介解读层（AI·证据行可回查）

基于 Symfony 的数据导入导出框架，采用读取-步骤-写入三段式流水线

综述（解读层）

这是一个 Symfony 3.4+ 的 bundle，用于构建导入/导出数据流，受 PortPHP 启发。每个 dataflow 由一个 Reader、若干可同步或异步的 Step、一个或多个 Writer 组成。支持命令行运行与调度任务，依赖 Doctrine DBAL 在数据库表 cr_dataflow_scheduled 和 cr_dataflow_job 中存储调度与作业记录。安装需通过 composer 引入并执行 schema 生成命令。

  • 提供 Reader、Step、Writer 三段式固定工作流，Reader 可为任意 iterable，Step 为接受元素并返回元素或 false 的 callable
  • 支持通过命令行运行、调度、启用/禁用 dataflow，并可将作业执行委托给 Symfony Messenger 并发处理
  • 可配置 Doctrine DBAL 连接、自定义 logger，以及通过 Flysystem 将异常写入文件系统

适用场景（解读层）

  • 在 Symfony 应用中实现从文件、数据库、Web 服务等外部资源到目标的批量数据导入/导出
  • 需要定时或命令行触发的数据流水线作业，并将调度和作业历史持久化到数据库
  • 借助 Messenger 模式让多个 worker 并发执行数据流作业的场景
