基于 Ecto 的数据库嵌套集模型实现库

综述（解读层）

as_nested_set 是一个 Elixir 库，基于 Ecto 在关系数据库中实现嵌套集模型。模型需包含 id、lft、rgt、parent_id 四个字段（字段名可配置），并支持 scope 参数划分多棵树。API 返回延迟执行的 executable，节点修改操作由用户决定是否包在事务中，并发修改场景 README 要求使用事务包裹 execute。适用于 Ecto 3.x 项目。

  • 要求模型包含 id、lft、rgt、parent_id 四个字段，字段名通过模块属性配置，默认为 lft/rgt 以避开 MySQL 保留字
  • 提供节点创建、删除（含子孙节点）、移动、根节点查询、遍历等操作，API 返回延迟执行的 executable
  • 支持通过 scope 参数限定同一棵树的列，实现同一表中多棵树的管理

适用场景（解读层）

  • 需要在 Elixir/Ecto 项目中以嵌套集模型存储和查询树形数据（如分类目录）
  • 同一表中需按 scope 列维护多棵独立树
  • 存在并发修改节点需求、需自行控制事务粒度的场景
