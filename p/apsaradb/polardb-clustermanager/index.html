PolarDB for PostgreSQL 的集群管理组件，负责拓扑、高可用与配置管理

综述（解读层）

PolarDB Cluster Manager 是 PolarDB for PostgreSQL 的集群管理组件，支持 Shared-Nothing 与 Shared-Storage 两种集群形态。其内部按检测、采集、状态、决策、执行、元数据、服务等模块划分：探测器通过心跳检测节点可用性，采集器收集节点系统与数据库指标，决策组件判定高可用切换等操作并由执行组件落实。部署上当前推荐通过 PolarDB-Stack-Operator 自动化完成，构建依赖 Docker。

  • 包含 detector、collector、status、decision、action、meta、service 七个子模块，覆盖检测、指标采集、状态维护、决策、执行、元数据持久化与 HTTP 接口
  • 通过心跳请求检测节点可用性，采集集群节点的系统指标（cpu/io 等）与数据库指标（lock/buffer 等）
  • 同时支持 Shared-Nothing 与 Shared-Storage 两种集群形态，service 模块对外提供 HTTP 接口（状态查询、手动切换等）

适用场景（解读层）

  • 配合 PolarDB for PostgreSQL 使用集群的高可用切换与拓扑管理
  • 通过 PolarDB-Stack-Operator 自动化部署 PolarDB 集群
  • 查询集群状态、执行手动切换等管理操作
