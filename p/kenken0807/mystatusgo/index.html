终端版 MySQL 实时监控工具，读取 status、performance_schema 等展示多实例指标

综述（解读层）

myStatusgo 是一个基于终端的 MySQL 实时监控工具，支持同时监控多个实例。它从 SHOW GLOBAL STATUS、performance_schema（MySQL 5.6+）、information_schema 及 SHOW SLAVE STATUS 采集指标，展示 QPS、线程、语句摘要、InnoDB 锁与缓冲池、表 I/O 等信息；若 MySQL 服务器装有 node_exporter，还可经 -n 选项显示 OS 指标。需要 SELECT performance_schema 及 PROCESS、REPLICATION CLIENT 权限，通过 go get 安装。

  • 支持多种主机指定方式：JSON 格式 -h、逗号分隔 -hc 或主机列表文件
  • 展示 QPS、运行线程、statement_digest、InnoDB 行锁/缓冲池、各表 I/O 与 SELECT/DML 计数
  • 提供 -a 显示每服务器全部指标、-t 设置各视图显示条数（默认 10）

适用场景（解读层）

  • 同时监控主从复制拓扑（含 SHOW SLAVE STATUS 从库信息）
  • 排查 InnoDB 行锁等待与长事务
  • 分析各表 I/O 请求与 DML/SELECT 频次
