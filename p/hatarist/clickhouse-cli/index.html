基于 HTTP 接口的 ClickHouse 非官方命令行客户端

综述（解读层）

clickhouse-cli 是一个用 Python 编写的第三方 ClickHouse 命令行客户端，通过服务器 HTTP 端口（默认 8123）连接。它提供自动补全、语法高亮、多查询/多行模式、less 分页器以及 \d+、\ps 等 PostgreSQL 风格命令。需 Python 3.7+，通过 pip 安装。由于走 HTTP 通道，会话支持不完整，SET 选项在本地保存并随每次请求发送。

  • 提供查询与数据输出的语法高亮、自动补全及 less 分页支持
  • 默认启用多查询与多行模式，支持从文件或 stdin 读取 SQL
  • 支持 PostgreSQL 风格自定义命令、用户自定义函数替换规则及配置文件/环境变量配置

适用场景（解读层）

  • 通过 HTTP 端口交互式查询和管理 ClickHouse 数据库
  • 在脚本或管道中以 CSV、TabSeparated 等格式批量执行查询或导入文件数据
  • 需要语法高亮、补全或分页等终端查询体验的 ClickHouse 使用者
