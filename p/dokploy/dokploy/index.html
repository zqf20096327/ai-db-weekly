自托管 PaaS 平台，用于部署和管理应用与数据库

综述（解读层）

Dokploy 是一个免费、可自托管的开源 PaaS，用于在 VPS 上部署与管理各类应用（Node.js、PHP、Python、Go、Ruby 等）及 MySQL、PostgreSQL、MongoDB 等多种数据库。它基于 Docker，集成 Traefik 做路由和负载均衡，通过 Docker Swarm 支持多节点集群，并提供 CLI/API 管理入口。安装只需在 VPS 上运行一行脚本，也可选用官方云服务跳过安装。

  • 支持部署多语言应用及 MySQL、PostgreSQL、MongoDB、MariaDB、libsql、Redis 等数据库
  • 集成 Traefik 路由与负载均衡，基于 Docker Swarm 支持多节点部署
  • 提供数据库自动备份、实时资源监控、日志与指标外发（Grafana、Datadog 等）及 CLI/API 管理方式

适用场景（解读层）

  • 在自有 VPS 上自托管部署 Web 应用与数据库
  • 使用 Docker Swarm 管理多服务器集群的应用部署
  • 自动化数据库备份并将容器日志与指标外发到监控平台
