🧭 简介解读层（AI·证据行可回查）

面向多智能体团队的自托管可审计记忆服务，含角色权限与来源追踪。

综述（解读层）

Attestor 是一个自托管的多智能体共享记忆层，记忆存于 Postgres 并派生至 Pinecone（向量）与 Neo4j（图）。读写经由携带身份、角色、命名空间与预算的 AgentContext，支持基于角色的权限（六种角色）、可选 Ed25519 签名的来源记录、按时间点回放的 as_of 查询、租户隔离与可审计的 forget_user 删除路径。检索默认走无 LLM 的确定性排序流水线。提供 Python 库、REST 与 MCP 三种接入方式，MIT 许可，面向需要治理能力的多智能体生产环境。

  • 实现六种角色的读写权限控制，越权操作在触达后端前抛出 PermissionError；每条记忆携带 agent_id、session_id 等来源信息，可选用 Ed25519 签名
  • 支持时间性替代与 as_of 回放，替代操作不删除数据；检索默认按向量→BM25→RRF→图→MMR→预算适配的确定性流水线排序，无 LLM 参与
  • 治理任务（整合、修复、删除）以 Temporal 工作流运行，带重试策略与操作界面；forget_user 采用先写审计行再删除的顺序

适用场景（解读层）

  • 多个不同信任级别的智能体写入同一记忆库的多智能体产品
  • 需要按时间点重建历史状态与可辩护删除流程的受监管系统
  • 自有 VPC 内自托管部署（Postgres、Pinecone、Neo4j）的场景
