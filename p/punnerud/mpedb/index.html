🧭 简介解读层（AI·证据行可回查）

Rust 实现的嵌入式多进程共享内存数据库，兼容 sqlite C-API 并提供 MVCC 并发

综述（解读层）

MPEdb 是用 Rust 编写的嵌入式数据库：进程通过 mmap 共享文件直接附加，无服务器架构，保留 sqlite 的运行模型并加入 MVCC 快照并发、严格 schema 校验和内容哈希编译计划。它通过 cdylib 导出 sqlite3 C-API，可用 LD_PRELOAD 或 PyPI 的 `import mpedb as sqlite3` 接入现有程序，并直接打开已有 sqlite .db 文件，写操作落盘为 sidecar 增量文件，checkpoint 时回写为 sqlite 格式。适用于希望在保持 sqlite 文件式部署方式的同时获得多进程并发写入能力、且使用 Python/Django/SQLAlchemy/PHP 等既有 sqlite 调用路径的本地应用场景。

  • 导出 sqlite3 C-API 的动态库，可经 LD_PRELOAD、soname 替换或 PyO3 模块接入既有 sqlite 调用方；可直接打开并回写 sqlite .db 文件
  • 基于 copy-on-write B+tree 的 MVCC 快照实现无锁读，写采用单写锁与 group commit；多进程并发写入，进程被 SIGKILL 不损坏数据库
  • 提供严格 schema 校验（NOT NULL/UNIQUE/CHECK、文件权威 schema）、内容哈希编译计划（execute(hash, params) 免解析热路径）及 SQL 文本 memo 缓存

适用场景（解读层）

  • 为不改代码的 sqlite 调用方（Django 测试、CPython sqlite3 模块、PHP pdo_sqlite）替换底层引擎
  • 多进程并发读写同一本地数据库文件且需进程崩溃安全的本地应用
  • 需要严格 schema 校验和预编译 SQL 计划复用的 Python/ORM 工作流
