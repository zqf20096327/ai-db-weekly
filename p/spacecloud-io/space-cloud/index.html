🧭 简介解读层（AI·证据行可回查）

基于 Kubernetes 的无服务器平台，为多种数据库即时生成 GraphQL/REST API

综述（解读层）

Space Cloud 运行于 Kubernetes，将 MongoDB、MySQL、PostgreSQL、SQL Server 等数据库以 GraphQL/REST API 形式直接暴露给前端：客户端发送查询描述对象，经安全规则验证后动态生成并执行数据库查询。也支持文件存储、事件触发及通过统一 API 接入自定义 HTTP 服务。README 注明项目现处于维护模式。

  • 提供 CRUD、事务、聚合与跨数据库联接的 API，支持实时查询
  • 数据库或文件存储事件可触发 webhook 或 serverless 函数，并与 auth0、firebase-auth 等集成细粒度访问控制
  • 集成 Kubernetes 与 Istio，支持自动扩缩容（含缩容至零）和默认流量加密

适用场景（解读层）

  • 在 Kubernetes 上为前端应用快速生成数据库 API 而不编写后端代码
  • 基于数据库或文件事件的 webhook/无服务器函数触发场景
  • 统一网关接入自定义微服务，并通过 GraphQL 联接数据库与微服务数据
