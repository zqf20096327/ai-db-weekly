Go 数据库迁移库，结合 goose 与流畅式 schema 构建器，支持多数据库

综述（解读层）

Migris 是面向 Go 语言的数据库迁移库，借鉴 Laravel 迁移的 API 风格，通过流畅式 schema 构建器以 Go 代码定义表结构。它提供 up/down/reset/status/create 等命令，内置 dry-run 预览生成 SQL，所有迁移在数据库事务中执行，支持 PostgreSQL、MySQL、MariaDB 和 SQLite3，可通过 urfave/cli 或 Cobra 助手集成到现有 CLI，无需外部工具。MIT 协议开源。

  • 支持 PostgreSQL（pgx 驱动）、MySQL、MariaDB、SQLite3 四种数据库
  • 提供 dry-run 模式，可在不执行的情况下预览将生成的 SQL 语句
  • 通过 WithDB/WithDSN 构造选项与 WithDryRun/WithAllowMissing 运行时选项管理连接与执行行为

适用场景（解读层）

  • Go 项目中用 Go 代码（而非手写 SQL）定义表结构的版本化迁移
  • 需要集成到 urfave/cli 或 Cobra 命令行应用的迁移管理
  • 上线前用 dry-run 检查迁移将执行的 SQL 与耗时统计

Migris is a database migration library for Go, inspired by Laravel's migrations. It combines the power of pressly/goose with a fluent schema builder, making migrations easy to write, run, and maintain
