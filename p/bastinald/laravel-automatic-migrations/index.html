🧭 简介解读层（AI·证据行可回查）

在模型类内声明 migration 方法，基于 Doctrine 比对并自动同步数据库结构的 Laravel 扩展包

综述（解读层）

这是一个 Laravel 扩展包，用于替代传统迁移文件：开发者在模型中编写 migration 方法，执行 migrate:auto 命令时，包通过 Doctrine 将模型声明与现有数据库结构比对并自动应用变更。可与传统迁移文件共存，先运行传统迁移再运行自动迁移；支持通过 migrationOrder 属性控制表创建顺序。

  • 在模型类中通过 migration 方法定义表结构，由 migrate:auto 命令借助 Doctrine 与现有 schema 比对并自动应用变更
  • 支持 make:amodel 生成含 migration 方法的模型及指向该方法的工厂，可用 --force 覆盖已有模型
  • migrate:auto 提供 --fresh、--seed、--force 选项，模型可声明 migrationOrder 控制迁移执行顺序，未声明时默认为 0

适用场景（解读层）

  • 希望将表结构定义与模型类耦合维护、减少迁移文件管理的 Laravel 项目
  • 存在外键、数据透视表等需要控制表创建顺序的场景，可通过 migrationOrder 指定先后
  • 仍需模型无关迁移的项目，可与传统迁移文件混合使用
