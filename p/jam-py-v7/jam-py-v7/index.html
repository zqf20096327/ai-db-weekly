基于 Python 的低代码 Web 数据库应用生成器与事件驱动框架

综述（解读层）

Jam.py 是一个面向对象、事件驱动的 Web 数据库应用开发框架，服务端用 Python 编写，客户端使用 JavaScript、jQuery 和 Bootstrap。开发者通过浏览器内的 Application builder 创建应用，支持多数据库迁移而不改项目代码，采用 BSD 许可证，可通过 pip 安装，也提供 Windows 免装 Python 的可执行包。

  • 支持 SQLite、PostgreSQL、MySQL、Firebird、MSSQL、Oracle、DB2、DuckDB、MS Access 等数据库
  • 提供认证、授权、会话管理及角色权限控制，支持审计跟踪/变更历史记录
  • 自动创建和修改数据库表并生成 SQL 查询，基于 LibreOffice 模板生成报表

适用场景（解读层）

  • 单人开发业务应用（如 CRM、账本、看板任务）且不希望搭建复杂 Web 技术栈
  • 在 Windows 或离线/隔离网络环境中部署数据库应用
  • 在不全部重写的前提下对现有系统进行现代化改造，或从 MS Access 模板迁移应用
