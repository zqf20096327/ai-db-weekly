🧭 简介解读层（AI·证据行可回查）

MCP 服务器，让编码代理在 SQLite 中构建并查询项目知识图谱。

综述（解读层）

MegaMemory 是一个面向编码代理的 MCP 服务器，以 LLM 作为索引器（不做 AST 解析或静态分析），由代理自行读写概念节点（feature/module/pattern/decision 等），实现跨会话记忆。数据存于每项目的 SQLite 数据库；嵌入模型（约 23MB）首次使用时自动下载，搜索为暴力余弦相似度，官方说明适用于万节点以下规模。提供 npm 安装与面向 opencode、Claude Code 等编辑器的一键配置，MIT 协议。

  • 提供 9 个 MCP 工具（understand/get_concept/create_concept/update_concept/link/remove_concept/list_roots/list_conflicts/resolve_conflict），支持语义检索、带类型的概念关系和软删除历史
  • 嵌入由本地 ONNX 模型（Xenova/all-MiniLM-L6-v2，量化版）进程内生成，除首次模型下载外无网络调用、无需 API 密钥
  • 内置知识图谱合并流程：按概念 ID 双向合并，冲突以 ::left/::right 变体保留，支持 CLI 手动或经 MCP 工具的 AI 辅助解决；含 Web 图谱浏览器（megamemory serve）

适用场景（解读层）

  • 让 Claude Code、opencode、Codex 等支持 MCP 的编码代理在会话开始时检索既往架构与决策，任务完成后写回知识
  • 团队分支并行改动 .megamemory/knowledge.db 后，用 merge/conflicts/resolve 命令合并知识图谱
  • 通过浏览器可视化查看项目概念节点、父子层级与关系边
