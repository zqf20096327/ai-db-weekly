DBMS 性能评测课程项目，用 Java/JDBC 对比 PostgreSQL 与 openGauss

综述（解读层）

这是一个数据库课程实验项目，包含两组对比实验：文件直接读写与数据库操作的差异，以及 PostgreSQL 16 与 openGauss 5.0 在相同负载下的表现。数据为程序化放大的 IMDb 风格电影数据集（movies 100 万行、people 50 万行），两库均以 Docker 运行，客户端统一使用 Java 21 + JDBC。计时采用预热 1 次加 5 次运行取中位数的方法，覆盖检索、更新、索引、并发吞吐等 8 项实验。

  • 实验覆盖 E1–E6b 共 8 项，含文件线性扫描 vs 数据库、B-tree 对模糊查询失效分析、手工倒排索引对照、ACID 演示及高并发线程池 vs 进程模型对比
  • 两库均以 Docker 容器运行，客户端用同一个 PostgreSQL JDBC 驱动连接，控制除数据库外的变量一致
  • 计时方法为预热 1 次 + 运行 5 次取中位数（热缓存）

适用场景（解读层）

  • 数据库课程作业或教学中演示 DBMS 与文件读写的差异
  • 需要可复现的 PostgreSQL 与 openGauss 同负载对比实验参考
  • 学习倒排索引、B-tree 索引失效等索引机制的教学实验
