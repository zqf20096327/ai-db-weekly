VS Code 扩展，在编辑器内浏览、编辑 SQLite/SQLCipher 数据库

综述（解读层）

SQLite IntelliView 是一款 MIT 许可的 VS Code 扩展（Beta），用于在编辑器内浏览、编辑和查询 SQLite 与 SQLCipher 数据库。提供表分页浏览、内联单元格编辑、Monaco SQL 查询、外键跳转与 ER 图、JSON/BLOB 查看及 CSV 导出。数据留在本地，无云服务或遥测；查询默认最多返回 10,000 行，SQL 写入不自动保存，无稳定行标识的视图为只读。

  • 支持打开 .sqlite/.db 等扩展名的 SQLite 文件和经 sqlcipher CLI 解密的加密库，可浏览、内联编辑、删除行并以 CSV 导出选中行
  • 内置 Monaco SQL 编辑器运行查询，提供 Schema 检查、外键导航和交互式 ER 图
  • 监控数据库/WAL/SHM 文件的外部变更并支持 WAL checkpoint，通过设置可调页大小、结果行数上限和自定义文件扩展名

适用场景（解读层）

  • 在 VS Code/VSCodium/Cursor 等兼容编辑器中直接查看和修改本地 SQLite 数据文件
  • 检查数据库 schema、外键关系并浏览 ER 图
  • 配合 sqlcipher CLI 打开和编辑加密数据库，或在重要数据副本上做临时的表级浏览与编辑
