🧭 简介解读层（AI·证据行可回查）

Rust 编写的 AI 代理认知记忆数据库，支持衰减、合并与矛盾检测

综述（解读层）

YantrikDB 是用 Rust 实现的记忆数据库，为 AI 代理提供带时间衰减、记忆合并和矛盾检测的存储。可作 Python/Rust 嵌入库、MCP 服务器（15 个工具）或基于 openraft 的 HTTP HA 集群运行，默认使用本地 SQLite 存储。README 明确记录了矛盾检测的两项限制和部分基准数据的撤回，性能数据存在未复测项。

  • 支持记忆半衰期衰减、think() 合并重复记忆并检测单值关系上的矛盾
  • 提供 MCP 服务器、HTTP/二进制协议网络服务器与 Python/Rust 嵌入库三种使用方式
  • HA 集群采用 openraft（2 投票者 + 1 见证者），含每租户配额、Prometheus 指标、AES-256-GCM 静态加密

适用场景（解读层）

  • 为 Claude Code/Cursor/Windsurf 等 MCP 客户端添加持久化代理记忆
  • 多机或多团队共享记忆的集群部署
  • 以嵌入库形式集成到 Python 或 Rust 应用中
