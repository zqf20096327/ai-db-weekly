Go 编写的 MetaTube SDK 与 RESTful API 服务，聚合多源元数据抓取

综述（解读层）

MetaTube SDK Go 是用 Go 实现的 MetaTube SDK 及 API 服务端，提供 RESTful API，内置 20+ 数据源提供方，支持文本翻译与图像处理（裁剪、徽标、人脸检测、哈希）。依赖 gin、gorm、colly、pigo 等库，数据库支持 SQLite 和 PostgreSQL，需 go1.25+，采用 Apache-2.0 许可，可运行于 Linux、Darwin、Windows 及 BSD 平台。

  • 提供 RESTful API，包含 20+ 元数据提供方
  • 支持 SQLite 与 PostgreSQL 存储，图像处理含自动裁剪、人脸检测与图像哈希
  • 依赖 gocolly/colly 抓取框架与 robertkrimen/otto JavaScript 解释器

适用场景（解读层）

  • 为 Emby/Jellyfin 类媒体服务器提供元数据接口服务
  • 通过 go get 引入 SDK，在 Go 项目中调用各提供方抓取元数据
  • 部署于 Linux/Windows/macOS/BSD 的云原生环境（CloudNative 标签）

PostgreSQL、SQLite
