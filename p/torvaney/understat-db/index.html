抓取 Understat 足球数据并存入 Postgres 数据库的工具

综述（解读层）

Understat DB 从 Understat 网站抓取足球数据并写入 Postgres 数据库，可作为足球数据项目的数据来源或起点。使用时需克隆仓库，通过 make env 建立 Python 虚拟环境，用 docker-compose 启动数据库容器，再执行 migrate 建表和 ingest 命令按联赛与赛季导入数据。运行依赖 Python 3.6+ 和 Docker，采用 MIT 许可证。

  • 支持通过 ingest 命令按联赛和赛季抓取并导入数据（如 --leagues EPL --seasons 2020）
  • 提供 docker-compose 方式启动 Postgres 数据库容器
  • 提供 migrate 命令创建基础数据库表

适用场景（解读层）

  • 需要本地存储 Understat 足球数据的分析项目
  • 作为使用足球数据的项目的数据来源或起点
  • 按联赛和赛季批量导入比赛数据入库
📖 README 首段存档原文 · 程序抽取

Understat DB is a project to scrape data from Understat and store it in a Postgres database. It aims to be a useful companion or starting point for projects using football data.
