面向分析型数据库的数据流入流出包装服务，接受任意 JSON 并提供查询接口

综述（解读层）

Scratch Data 是一个以 Go 编写的数据流服务，作为分析数据库的包装层：接收任意 JSON 写入并自动建表建列，支持 SQL 查询、生成限时过期的 CSV/JSON 共享链接，以及在多个数据库间按查询复制数据。默认无配置时自动启用本地 DuckDB，也可通过 config.yaml 自定义；主题标签显示支持 BigQuery、ClickHouse、Snowflake 等。适合需要在应用与 OLAP 数仓之间做数据写入、查询与搬运的团队。

  • 接受任意 JSON 通过 HTTP API 写入，目标表和列自动创建
  • 提供 SQL 查询接口，可生成带过期时间的 CSV/JSON 共享链接
  • 支持在多个数据库间执行查询并自动在目标库建表复制数据

适用场景（解读层）

  • 将应用产生的 JSON 事件数据流式写入分析数据库
  • 把查询结果以临时链接形式共享给其他用户
  • 在多个分析数据库之间复制表数据
📖 README 首段存档原文 · 程序抽取

Scratch Data is a wrapper that lets you stream data into and out of your analytics database. It takes arbitrary JSON as input and lets you perform analytical queries.
