SheetJS 电子表格数据工具包，解析与生成多种电子表格格式的 JavaScript 库

综述（解读层）

SheetJS Community Edition 是一个 JavaScript 库，用于从复杂电子表格中提取数据并生成新电子表格，生成结果可在传统及现代软件中使用。源码仓库已迁移至 git.sheetjs.com，README 中的 GitHub master 分支包含截至提交 515d1c6 的内容。社区版采用 Apache 2.0 许可证；商业版 SheetJS Pro 提供模板编辑、样式、图表/图片/数据透视表及公式求值等扩展能力。

  • 从复杂电子表格中提取数据，并生成兼容传统与现代软件的新电子表格
  • 社区版采用 Apache 2.0 开源许可证
  • 官方文档、脚本与 NodeJS 模块通过 docs.sheetjs.com 和 cdn.sheetjs.com 提供

适用场景（解读层）

  • 在 JavaScript 应用中读取电子表格文件并提取数据
  • 生成可供传统及现代软件打开的电子表格文件
  • 需要模板编辑、样式、图表或公式计算等扩展功能时使用 SheetJS Pro
