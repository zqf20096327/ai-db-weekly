本体驱动的 WorkBuddy 技能，从需求探索到生成可运行领域应用

综述（解读层）

该仓库是一个 WorkBuddy 技能，通过九阶段需求探索和两次人工确认门禁，生成十一类本体 YAML 模型，并据此产出包含 SQLite 运行引擎、REST API、录入表单与离线知识图谱的自包含领域技能。当前定位为本地单用户 MVP，运行时无登录与权限拦截，HTTP 仅监听 127.0.0.1。

  • 按九阶段流程交互式澄清需求，生成 M1~M7、ME、MU、MM、MI 十一类 YAML/JSON 本体模型
  • 运行引擎读取 M1 JSON 自动创建 SQLite 表，提供通用 CRUD API 与只读 SQL 查询接口
  • 生成离线 ECharts 知识图谱 HTML 和独立录入表单，运行时仅依赖 Python 标准库与内置 SQLite

适用场景（解读层）

  • 将一段业务想法或需求文档转换为可运行的应用原型
  • 为特定业务领域建立结构化本体模型并可视化知识图谱
  • 在 WorkBuddy 中通过自然语言查询本地 SQLite 业务数据
