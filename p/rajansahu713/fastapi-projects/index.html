基于 FastAPI 的示例项目集合，覆盖认证、数据库、缓存等场景

综述（解读层）

该仓库收录 20 个 FastAPI 示例项目，每个示例聚焦一个功能点，包括 RBAC 资源访问管理、SQLAlchemy/MongoDB 数据库操作、JWT 认证、中间件、日志、Pytest 测试、APScheduler 定时任务、分页、Jinja2 模板渲染、Docker 容器化、Celery 后台任务、Redis 缓存与 Pub/Sub、GraphQL、PgBouncer 连接池及 Text-to-SQL。面向希望查阅具体功能实现的 FastAPI 使用者。安装与运行方式需查看各子项目目录内的 README。

  • 包含 20 个示例项目，覆盖认证、RBAC/ABAC 访问控制、CRUD、分页、模板渲染等功能点
  • 集成 SQLAlchemy、MongoDB、Redis、Celery、PgBouncer、GraphQL、APScheduler 等组件的接入示例
  • 包含 Pytest 单元与集成测试、Docker 容器化及 OpenAPI 元数据配置的示例

适用场景（解读层）

  • 查阅 FastAPI 与数据库、缓存、消息组件集成的参考实现
  • 了解 JWT 认证与角色/属性访问控制在 FastAPI 中的搭建方式
  • 参考定时任务、后台任务、分页等常见功能的示例代码
