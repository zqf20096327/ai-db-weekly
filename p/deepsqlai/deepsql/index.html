🧭 简介解读层（AI·证据行可回查）

面向 PostgreSQL 与 MySQL 的自托管数据库 AI 代理

综述（解读层）

DeepSQL 是一个自托管的数据库 AI 代理，用户将 Postgres 或 MySQL 实例接入后，可用自然语言进行模式探索、查询生成、慢查询分析与索引建议。系统本身不内置模型，需在 .env 中配置 OpenAI、Azure、Anthropic 或任意 OpenAI 兼容端点；通过 Docker Compose 从源码构建部署，数据库凭据加密存储于本地 vault。查询以只读方式执行，嵌入模型须输出 3072 维向量。

  • 读取 pg_stat_statements 或 MySQL 慢日志，按指纹分组并按成本排序查询，标记回归
  • 提供索引建议，可在 PostgreSQL 上以 CREATE INDEX CONCURRENTLY 应用索引（不锁表）
  • 内置 MCP 服务器，使 Claude Code、Cursor 等编码代理可通过 stdio 使用相同能力

适用场景（解读层）

  • 业务人员用自然语言提问获取 BI 数据结果
  • DBA 排查和优化慢查询、生成索引方案
  • 在气隙或自控环境中部署，模型与数据均不出本地环境
