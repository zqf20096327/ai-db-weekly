基于 Docker 的 wal-g 备份与恢复 Postgres 实验环境

综述（解读层）

该项目提供一组 Docker 化脚本和 docker-compose 配置，用于演练 wal-g 对 PostgreSQL 的全量备份、WAL 归档与恢复流程：数据写入实例 1，基础备份上传至 Minio（S3 兼容）存储，随后在实例 2 上恢复并校验数据。还包含 GnuPG 密钥配置说明，可通过环境变量启用 OpenPGP 加密。适合想动手验证 wal-g 备份恢复流程的开发者。

  • 提供 shell 脚本构建包含 wal-g 的 PostgreSQL Docker 镜像并编排 postgres1、postgres2 与 Minio 服务
  • 实现完整演练场景：基础备份上传 Minio、WAL 归档（可通过 pg_stat_archiver 查看状态）、在第二实例恢复全量与 WAL 数据
  • 支持通过 WALG_PGP_KEY_PATH 环境变量配置基于 GnuPG 密钥的 OpenPGP 加密与解密

适用场景（解读层）

  • 本地动手演练 wal-g 的 PostgreSQL 归档备份与 PITR 相关恢复流程
  • 验证备份到 Minio/S3 兼容存储后的数据恢复完整性
  • 测试 OpenPGP 加密的备份与解密恢复配置
