🧭 简介解读层（AI·证据行可回查）

dbdaddy 是一个数据库管理 CLI，以类似 git 分支的方式管理 PostgreSQL 数据库。

综述（解读层）

dbdaddy 是一个数据库管理命令行工具，目前仅支持 PostgreSQL，处于开发中状态。它把服务器上的多个数据库当作分支来切换和复制，提供 schema 查看、dump 恢复、SQL 执行导出、schema push/pull 与迁移文件生成等功能。README 明确说明迁移功能不稳定，不支持索引、触发器与自定义类型的修改，列变更会通过删除重建实现并可能丢失数据，不建议用于生产环境。

  • 将服务器上的多个数据库作为分支管理，支持 checkout 创建、复制或新建空分支
  • 支持 schema 内省、SQL 文件执行、查询结果导出为文本与 CSV，以及 dump 与 restore
  • 迁移按序号目录组织，含 up.sql/down.sql/info.md/state.json，支持生成、上下迁移与 reset

适用场景（解读层）

  • 本地开发中通过分支方式复制和切换 PostgreSQL 数据库状态
  • 用 SQL 文件定义 schema 并生成迁移，在迁移序列间前进或回退
  • 恢复他人提供的 dump 文件、修改后重新导出备份
