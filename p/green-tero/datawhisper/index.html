综述（解读层）

DataWhisper 是一个本地运行的表格数据分析工具，支持自然语言问答与 PR 中 SQL/数据文件的变更审计。支持 SQLite、DuckDB、PostgreSQL、Parquet 和 JSONL 数据源；所有模型生成的 SQL 须经语义防火墙、AST 沙箱和 EXPLAIN 成本门控后才执行，结果经 PII 清洗后输出。要求 Python 3.11+，从仓库安装（未发布 PyPI）。提供 CLI 与 GitHub Action 两种使用方式，可通过 DW_LLM_PROVIDER=local 离线运行。

  • 支持 SQLite、DuckDB、PostgreSQL、Parquet、JSONL 等数据源，以只读模式打开数据库
  • SQL 执行前经过语义防火墙评分、AST 沙箱白名单校验与 EXPLAIN 成本门控三层防护
  • 内置 PII 清洗器，支持 hash/mask/tokenize/redact 四种脱敏模式，并提供 PR 中的 schema 漂移、PII 列与迁移静态审计

适用场景（解读层）

  • 对本地数据文件或数据库提出分析问题并生成图表报告
  • 在 CI 中审计涉及 SQL、迁移或数据文件的 Pull Request
  • 需要限制模型权限、在本地网络环境下运行 LLM 数据分析的场景
