🧭 简介解读层（AI·证据行可回查）

基于 Tauri 的 macOS 多数据库客户端，支持 PostgreSQL、Redis、ClickHouse 等连接管理

综述（解读层）

DBcooper 是一款用 Tauri v2（Rust 后端）+ React + TypeScript 构建的 macOS 数据库客户端，支持 PostgreSQL、MySQL、MariaDB、MongoDB、SQLite、DuckDB、Redis、ClickHouse 和 Cloudflare D1 连接。它可从连接界面创建或关联 Docker 容器数据库并自动保存连接，还内置可选的 MCP 服务器供外部代理调用，并支持配置 AI 提供商生成 SQL。安装方式为 Homebrew cask 或下载 DMG，应用数据存储使用 SQLite。需注意构建目标是 macOS ARM（Apple Silicon），D1 连接走 HTTPS API 不支持 SSH 隧道，且超范围的整数显示可能丢失精度。许可证为 MIT。

  • 支持连接 PostgreSQL、MySQL、MariaDB、MongoDB、SQLite、DuckDB、Redis、ClickHouse 和 Cloudflare D1
  • 可在 Docker 容器中创建多种数据库或关联现有容器（含 Docker Compose 服务），并提供停止、重启容器和复制连接字符串功能
  • 包含可选的、基于令牌认证的 MCP 服务器；支持配置 OpenAI 兼容 API 或本地 CLI（Claude Code、Codex CLI、opencode）生成 SQL

适用场景（解读层）

  • 开发者在 macOS 上集中管理多种数据库连接（含 Docker 容器中的数据库）
  • 需要通过 MCP 协议向外部编码代理暴露数据库客户端能力的场景
  • 使用自然语言描述生成 SQL 并在查询编辑器中审查后执行
