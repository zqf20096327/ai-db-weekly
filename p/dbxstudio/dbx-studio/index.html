开源 AI SQL 客户端，用自然语言生成并管理数据库查询

综述（解读层）

DBx Studio 是一款基于 Electron 的桌面数据库管理工具，也可通过 Web/桌面双端运行。用户以自然语言描述需求，由 AI 生成 SQL，并提供带语法高亮、自动补全和查询历史的编辑器。支持 PostgreSQL、Snowflake、SQLite 等数据库，内置 PGLite 存储连接与历史记录，无需外部数据库。开发者需自行配置 AI 提供商（OpenAI/Anthropic/AWS Bedrock）的 API 凭证。采用 Apache 2.0 许可证。

  • 支持自然语言生成 SQL 查询，并感知表结构与列关系
  • 内置 SQL 编辑器，包含语法高亮、自动补全、查询历史与多标签工作区
  • 支持 PostgreSQL、Snowflake、SQLite、Supabase、Amazon Redshift 多种数据库连接

适用场景（解读层）

  • 开发者通过自然语言描述查询数据库数据
  • 浏览表结构、预览行数据并可视化检查表关系
  • 团队部署为 Web 服务或桌面客户端管理多个数据库连接
