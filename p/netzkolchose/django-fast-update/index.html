Django 批量更新库，用 UPDATE FROM VALUES SQL 变体提速

综述（解读层）

django-fast-update 为 Django ORM 提供替代 bulk_update 的批量更新实现，核心使用 UPDATE FROM VALUES 类 SQL 语句。通过 FastUpdateManager 挂载到模型后即可调用，也支持直接以 queryset 为首参调用。支持 SQLite 3.15+、PostgreSQL、MariaDB 10.2+、MySQL 5.7+，不支持时回退到 flat_update。限制包括不支持 F 表达式、变更集不允许重复项，适用于需大批量更新模型字段的 Django 项目。

  • 提供 fast_update、copy_update（仅 PostgreSQL，基于 COPY FROM）、flat_update、merged_update 四种更新实现
  • 通过 FastUpdateManager 挂载模型，或以 queryset 为首参直接调用（跳过部分检查换取约 30% 提速）
  • 支持 Django 3.2/4.2/5.2 与 Python 3.8–3.13，可用 register_implementation 注册其他数据库实现

适用场景（解读层）

  • Django 项目中需要批量更新大量模型对象字段的场景
  • PostgreSQL 上中等及以上规模的变更集可用 copy_update
  • 不支持 UPDATE FROM VALUES 的旧版数据库自动回退到 flat_update
