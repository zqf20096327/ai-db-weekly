单二进制 Go 网络延迟监测工具，内置 SQLite 与 Web UI，类 SmokePing。

综述（解读层）

fogping 是一个面向 Linux 的网络延迟监测工具，以单个 Go 二进制发布，数据存于内置 SQLite，通过 8518 端口提供 Web UI 管理监测目标并绘制图表。适合需要自托管、轻量部署延迟观测的用户。无默认登录，需通过命令行参数设置用户密码，加 --edit 后才能在 UI 中增删目标；历史保留默认 30 天，上限 93 天。

  • 单个二进制运行，内置 SQLite 存储，提供 Web UI 管理与图表展示
  • 支持命令行参数配置登录（含多用户）、只读模式、历史保留天数（默认 30，最大 93）等
  • 提供只读 stats 端点供 Zabbix 拉取聚合，支持目标列表 JSON 导出/导入（与 pingping 共用格式）、HTTP API（OpenAPI 3.1）与 Docker 镜像（amd64/arm64/armv7）

适用场景（解读层）

  • 在单台 Linux 服务器上自托管监测若干目标的 ICMP/TCP 延迟并查看图表
  • 多地点各部署一个实例，由 Zabbix 每分钟拉取 stats 端点做聚合、仪表盘与告警
  • 通过 Docker 快速运行，并借助导出/导入在实例间迁移目标列表
