🧭 简介解读层（AI·证据行可回查）

Orca 编辑器的数据库插件，在编辑器标签页内查询 PostgreSQL、MySQL/MariaDB 和 SQLite。

综述（解读层）

DB Studio 是一个 Orca 插件，让使用者在 Orca 内连接并查询 PostgreSQL、MySQL/MariaDB 和 SQLite，无需切换窗口。它支持保存连接、从工作区 .env 读取 DATABASE_URL 提供按工作区分组的连接，查询文档为带连接行注释的 .sql 文件。查询结果有行数与体积上限（默认 100 行，最高 5000 行/约 900KB），查询超时默认 30 秒、上限 110 秒。安装需 Orca 1.4.248+，通过指纹批准授予 secrets、storage、workspace 等权限。

  • 支持 PostgreSQL、MySQL/MariaDB、SQLite 三种引擎，统一的面板、编辑器与结果网格，驱动层为纯 JavaScript 无原生模块
  • 查询结果通过游标流式读取，到达行数或体积上限即停止；支持取消运行中的查询（PostgreSQL 用 pg_cancel_backend，MySQL/MariaDB 用 KILL QUERY，SQLite 停止查询线程）
  • SQL 编辑器基于 CodeMirror 6，提供方言感知高亮和基于实时 schema 的表/列/关键字自动补全；大整数与十进制数以字符串传输保持精确

适用场景（解读层）

  • 在 Orca 中并行运行多个代理（各自工作树）时，直接在编辑器内检查代理写入的数据表
  • 从工作区 .env 自动发现数据库连接，按工作区查看和查询对应数据库
  • 以 .sql 文件形式编写、运行并保留 SQL 查询，通过网格查看结果与单元格完整值
