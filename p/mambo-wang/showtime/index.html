综述（解读层）

ShowTime 是一个运维监控系统，为新华三云基产品线（CAS/UIS/Workspace 等）提供日志采集检索、指标监控报表与 RAG 知识库问答。采集层采用 Java 插件体系（Spring Boot，端口 8888），服务层为 Python FastAPI + ChromaDB + LLM（端口 8000），前端为 Vue 3 + TypeScript（端口 9090）。环境要求 JDK 17+、Python 3.11+、Node.js 18+、MySQL 8.0+，仅支持 macOS/Linux。README 标题含 'AI Agent'，正文未展开 Agent 相关机制说明。

  • 采集层插件化设计，含 CAS 虚拟化、UIS 超融合、Workspace 云桌面插件
  • RAG 知识库支持向量检索、多轮对话历史管理，并提供知识库与对话 API
  • 多产品日志统一采集与全文检索，指标数据可视化展示

适用场景（解读层）

  • 新华三 CAS/UIS/Workspace 等云基产品的服务器、网络、存储资源监控与告警
  • 多产品日志统一采集与问题定位检索
  • 基于内部文档构建知识库进行运维问答
