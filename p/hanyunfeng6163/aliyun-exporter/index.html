从阿里云云监控 API 抓取指标的 Prometheus exporter

综述（解读层）

该项目是 aylei/aliyun-exporter 的 fork，在原基础上增加 oss/polardb/dts/mq/elasticsearch 等 CloudMonitor 指标支持，并通过 special projects 机制补充 RDS 性能指标。它按配置文件从云监控 API 拉取指标并以 /metrics 暴露，提供指标元数据站点与含 Prometheus/Grafana/Alertmanager 的 docker-compose 全栈方案。需 Python 3.7+ 和阿里云 AccessKey，注意 API 有频率限制与月度调用配额。

  • 通过 CloudMonitor API 采集阿里云指标，支持 oss/polardb/dts/mq/elasticsearch 等项目
  • 内置 special projects（如 rds_performance），调用不同 API，不消耗云监控调用配额
  • 自带指标元数据站点（/projects/{project}、/yaml/{project}）及含 Grafana、Alertmanager、钉钉通知的 docker-compose 部署栈

适用场景（解读层）

  • 将阿里云 CloudMonitor 指标接入 Prometheus/Grafana 监控体系
  • 需要采集 PolarDB、OSS、DTS 等服务的云监控指标
  • 需要多地域指标展示或多实例分片、HA 部署的云上监控场景
