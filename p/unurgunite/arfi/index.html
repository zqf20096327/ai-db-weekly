🧭 简介解读层（AI·证据行可回查）

Rails 的自定义 SQL 函数管理 gem，以文件为源在数据库任务中自动加载

综述（解读层）

ARFI（ActiveRecord Functions Integration）是一个 Ruby gem，用于在 Rails 应用中创建和维护自定义 SQL 函数。开发者将函数定义以 .sql 文件形式放在 db/functions 目录下，ARFI 在 db:migrate、db:prepare 等常见数据库任务时自动加载它们，无需将 schema.rb 切换为 structure.sql。它采用"当前状态"模型，支持 PostgreSQL 与 MySQL 兼容数据库（含多库配置），并支持 PostgreSQL 适配器目录与 schema 目录区分。注意 SQLite3 不受支持，MySQL 不支持与 PostgreSQL 相同的 CREATE OR REPLACE FUNCTION 语义。

  • 在 db:migrate、db:prepare、db:test:prepare 等常见 Rails 数据库任务中自动加载 db/functions 下的 SQL 函数文件
  • 支持 PostgreSQL 与 MySQL（mysql2）、MariaDB、Trilogy 适配器，支持单库与多库 Rails 配置，适配器目录文件按文件名覆盖通用文件
  • 提供 Thor CLI（functions create/destroy），支持 --template、--adapter、--schema、--force 选项；PostgreSQL 下可在 PG::UndefinedFunction 出错时自动加载函数并重试一次查询

适用场景（解读层）

  • 在保持 schema.rb 格式的 Rails 项目中维护用于函数索引或查询辅助的自定义 SQL 函数
  • 多数据库 Rails 配置下向环境的每个数据库连接同步加载函数定义
  • 使用 PostgreSQL 特定 schema（如 audit）按目录组织并区分适配器生成函数文件
