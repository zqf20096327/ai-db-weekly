SQL Server on Linux 的 Kubernetes Operator，自动化单实例与 Always On AG 生命周期

综述（解读层）

这是一个面向 Kubernetes 集群的 SQL Server on Linux 管理器，提供 SQLServerInstance（单 Pod + PVC + Service）和 SQLServerAvailabilityGroup（多副本 AG）两种 CRD。Operator 通过 T-SQL 自动引导 AG、管理证书端点认证，并作为外部集群管理器替代 Pacemaker 角色执行自动与计划内故障转移。需 Go 1.25+ 与 Kubernetes v1.11.3+ 集群，核心安装无需 cert-manager，启用准入 Webhook 时则需要。

  • 提供 SQLServerInstance 与 SQLServerAvailabilityGroup 两个 CRD，分别管理独立实例与多副本 Always On 可用性组
  • 在 clusterType: EXTERNAL 下实现自动故障转移：基于 Pod 就绪探针与 sp_server_diagnostics 双层健康信号判定主副本降级
  • 通过 preStop 钩子在滚动更新或节点排空前执行 ALTER AVAILABILITY GROUP FAILOVER，实现计划内故障转移

适用场景（解读层）

  • 在 Kubernetes 上以声明式方式部署和管理独立 SQL Server 实例
  • 需要自动故障转移与读写监听器 Service 的多副本 Always On 可用性组部署
  • 通过 CRD YAML 与示例配置进行 AG 拓扑配置与故障转移测试
