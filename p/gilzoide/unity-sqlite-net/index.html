将 SQLite-net 与加密 SQLite 集成的 Unity UPM 包

综述（解读层）

该包把 SQLite-net 库打包为 Unity UPM 包，底层使用 SQLite3 Multiple Ciphers，支持加密数据库及 FTS5、R*Tree 等模块，覆盖 Windows、Linux、macOS、移动端与 WebGL（WebGL 通过 Indexed DB VFS 持久化）。提供同步/异步 API、CSV 导入和 SQLiteAsset 只读数据库资源。首次贡献者需注意 Android/WebGL 无法从 Streaming Assets 加载数据库，只能读入内存。

  • 提供 SQLite-net 同步与异步 API，并扩展 Serialize/Deserialize、CSV 导入等方法
  • 基于 SQLite3 Multiple Ciphers 2.5.1，支持加密数据库，启用 FTS5、R*Tree、Geopoly、内置数学函数模块
  • 提供 SQLiteAsset 资源类型，支持 .sqlite/.csv/.sql 文件导入为只读数据库

适用场景（解读层）

  • Unity 项目中访问本地 SQLite 数据库（含加密需求）
  • WebGL 构建中需要本地持久化存储的场景
  • 将 CSV 或 SQL 脚本作为只读数据库资源随应用分发
