🧭 简介解读层（AI·证据行可回查）

单二进制自托管平台，在自有机器上运行 Cloudflare Workers 兼容运行时

综述（解读层）

open-compute 是一个自托管的 Cloudflare Workers 兼容平台，以单个 Rust 二进制提供运行时、控制平面与调度，支持 Workers、KV、D1、R2、Durable Objects、Queues 等绑定。它面向希望在自有硬件上运行 Workers 编程模型的开发者，要求单机部署，元数据存于内嵌 SQLite，对象数据默认存本地文件系统或可选 S3 兼容存储。部署不可变且内容寻址，通过 ocd CLI 与仪表盘管理。

  • 支持 Workers、KV、R2、D1、Durable Objects、Queues、Cron、Workflows、Vectorize 等绑定，测试套件覆盖 2,256 个稳定 API 成员与重载
  • 单个 Rust 二进制包含运行时、控制平面、调度器与产品绑定，使用锁定并经校验和验证的 workerd 分叉，元数据由内嵌 SQLite 管理
  • 工作区级禁止 unsafe 代码，部署不可变且内容寻址，提供原生扩展机制（Cap'n Proto 直连的 Provider 进程）

适用场景（解读层）

  • 在自有单机或内部服务器上运行与 Cloudflare API 兼容的 Workers 应用
  • 需要本地一致性、单实例数据权限，且不依赖 Kubernetes、Redis 等分布式组件的自托管部署
  • 通过原生扩展让 Worker 调用本地硬件、专有库或内部守护进程的场景
