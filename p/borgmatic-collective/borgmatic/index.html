🧭 简介解读层（AI·证据行可回查）

基于 Borg Backup 的配置驱动型备份软件，用于服务器和工作站

综述（解读层）

borgmatic 是运行于服务器和工作站的备份软件，以 YAML 配置文件驱动，底层由 Borg Backup 提供客户端加密与去重能力。它支持备份多种数据库与文件系统快照，并可集成第三方监控与凭据管理服务，适合需要数据库备份和集中监控的服务器管理员使用。

  • 基于 Borg Backup 实现，支持客户端加密备份数据
  • 支持 PostgreSQL、MySQL/MariaDB、MongoDB、SQLite 等多种数据库备份，以及 OpenZFS、Btrfs、LVM 快照集成
  • 集成 Healthchecks、Uptime Kuma、PagerDuty、ntfy、Loki 等第三方监控服务，并支持 KeePassXC、1Password 等凭据来源

适用场景（解读层）

  • 服务器和工作站的定期文件备份，配合客户端加密
  • 对 MySQL、PostgreSQL、MongoDB 等数据库进行备份
  • 备份流程需接入第三方监控服务进行状态通知的场景
