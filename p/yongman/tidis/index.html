基于 TiKV 后端的分布式 NoSQL 数据库，兼容 Redis 协议

综述（解读层）

Tidis 是用 Go 编写的分布式 NoSQL 数据库，提供 Redis 协议 API（string、list、hash、set、sorted set）。架构类似 TiDB 层，负责协议转换和数据结构计算，底层由 TiKV 提供 Raft 复制与 2PC 分布式事务。README 声明本仓库已归档、不再维护，官方新版本由 PingCAP 在 tidb-incubator/tidis 维护。项目采用 MIT 许可证，可通过 docker-compose、源码编译或 Docker 镜像运行，默认端口 5379。

  • 兼容 Redis 协议，支持 string、list、hash、set、sorted set 五类数据结构的常用命令
  • 采用存算分离架构，以 TiKV 为后端，通过 Raft 复制数据、2PC 实现分布式事务
  • 支持 MULTI/EXEC 事务命令，并提供 docker-compose 一键部署方式

适用场景（解读层）

  • 需要使用 Redis 客户端协议访问、但要求后端数据具备 Raft 多副本与事务能力的场景
  • 希望基于 TiKV 存储运行 Redis 数据结构 API 的部署环境
  • 需要水平扩展的 NoSQL 键值数据服务
