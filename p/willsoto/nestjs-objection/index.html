将 Objection.js 与 Knex 集成到 NestJS 的模块

综述（解读层）

该包提供 NestJS 模块，用于把 Objection.js 和 Knex 接入 Nest 应用。支持通过 register 或 registerAsync 注册连接，可注入连接或 Objection 模型，并支持多连接（需用 name 命名区分）。Knex 与 Objection 为 peerDependencies，需单独安装。适用于在 NestJS 中使用 Objection.js 做数据库访问的项目。

  • 提供 ObjectionModule.register 与 registerAsync 两种注册方式
  • 支持注入 Knex 连接与 Objection 模型
  • 支持多个命名连接，配置项包含 name、Model、config

适用场景（解读层）

  • 在 NestJS 应用中使用 Objection.js 与 Knex 访问数据库
  • 需要在一个应用中配置多个数据库连接的场景
  • 结合 @nestjs/terminus 注入连接实现健康检查（README 示例所示）
