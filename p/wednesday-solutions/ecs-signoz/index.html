🧭 简介解读层（AI·证据行可回查）

通过一条命令在 AWS ECS Fargate 上部署 SigNoz 可观测平台的部署模板

综述（解读层）

该仓库提供在 AWS ECS Fargate 上部署 SigNoz（含 ClickHouse 集群及 otel、query、alert、frontend 等服务）的脚本与 CloudFormation/Copilot 配置。使用者通过 signoz-ecs-config.yml 配置 VPC、ClickHouse 实例类型与磁盘、服务名称等，执行 make deploy 完成部署；支持使用已有 VPC、已有 ClickHouse 集群或已有 Copilot 应用，也可替换自定义 AMI。

  • 用 CloudFormation 部署 3 节点 ZooKeeper + 3 分片 ClickHouse 集群，含私有子网放置与 bastion 实例
  • 通过 AWS Copilot 在 ECS Fargate 上部署 otel collector、query、alert、frontend 四个 SigNoz 服务
  • 支持四种部署路径：全新部署、复用现有 VPC、复用现有 ClickHouse 集群、部署到已有 Copilot 应用，以及自定义 Fluent Bit/OTel 镜像推送 ECR

适用场景（解读层）

  • 希望在 AWS ECS Fargate 上自托管 SigNoz 收集应用 traces、metrics、logs 的团队
  • 已有 VPC、ClickHouse 集群或 Copilot 应用，需将 SigNoz 部署接入现有 AWS 环境
  • 组织有自定义 AMI 或安全要求，需修改 ClickHouse/ZooKeeper 镜像与部署配置
