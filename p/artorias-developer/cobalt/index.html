🧭 简介解读层（AI·证据行可回查）

自托管游戏服务器管理面板，基于 Docker 容器隔离运行多个游戏服务器

综述（解读层）

Cobalt 是一个面向朋友群体的自托管游戏服务器 Web 面板，部署在自有 VPS/VDS 上，用 FastAPI 与 Vue 构建，整体运行于 Docker。每个游戏服务器运行在独立容器中，支持 Minecraft、Terraria、Factorio 等 8 款游戏及其加载器。仅官方支持 Ubuntu 22+ 和 Debian 13+，项目免费。

  • 支持 Minecraft、Terraria、Don't Starve Together、Factorio 等 8 款游戏，服务器各自运行在隔离的 Docker 容器中
  • 提供 VPS/VDS 及各服务器的 CPU 与内存实时/近 15 分钟监控，集成 Prometheus、cadvisor、node-exporter
  • 支持多用户与角色权限控制、文件管理器与配置编辑、自动获取最新游戏版本，提供英/俄/乌克兰语界面

适用场景（解读层）

  • 在自有 VPS/VDS 上为朋友群体创建和管理多个游戏服务器
  • 按需启停不常用的服务器以控制资源占用
  • 通过 Web 面板发送游戏指令、编辑配置文件和管理服务器文件
