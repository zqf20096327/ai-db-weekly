🧭 简介解读层（AI·证据行可回查）

从 Airflow 数据库读取指标并以 Prometheus 格式导出的 Go 编写的导出器

综述（解读层）

该工具用 Go 编写，通过读取 Airflow 的数据库（默认 MySQL，也提及 PostgreSQL 及其 SSL 配置）获取指标，并以 Prometheus 格式在 /metrics 端点暴露，供 Prometheus 抓取。配置通过环境变量完成，提供二进制编译和 Docker/docker-compose 两种运行方式，默认监听 :9112。适用于已部署 Airflow 并使用 Prometheus 监控的环境。

  • 通过环境变量配置监听地址和数据库连接参数，默认监听 :9112
  • 支持 MySQL 数据库后端，并支持 PostgreSQL 及 SSL 证书配置
  • 提供 Docker 镜像和 docker-compose 部署方式，指标暴露于 /metrics 端点

适用场景（解读层）

  • 为使用 Prometheus 的监控体系采集 Airflow 指标
  • 在无法直接部署 Airflow StatsD 等方案时，通过数据库读取指标
  • 以容器化方式部署导出器并接入现有 Prometheus 抓取配置
