基于终端的 SQL Server 管理工具，Go 编写，单文件免安装

综述（解读层）

goSSMS 是一个终端界面的 SQL Server 管理应用，用 Go 编写，以单个可执行文件分发，不需要安装器、SQL 客户端工具或独立数据库驱动，通过 Homebrew、APT 或直接下载获取，覆盖 Windows/Linux/macOS 的 amd64 与 arm64。它提供对象资源管理器、查询编辑器、结果导出、Always On 副本发现等功能，支持 SQL Server 2016 SP1 及以上与 Azure SQL Managed Instance，也可连接 Fabric Data Warehouse。需要支持 UTF-8 与 256 色的终端。适合需要在非 Windows 环境用键盘操作管理 SQL Server 的用户。

  • 以单个可执行文件分发，不依赖安装器、SQL 客户端工具或独立驱动，提供 Windows/Linux/macOS 的 amd64 与 arm64 二进制
  • 提供对象资源管理器（支持按模式分组）、连接历史、多种认证方式（SQL Server、Windows 集成、Microsoft Entra ID 各方法）及 CSV/TSV/JSON/XML 结果导出
  • 支持 SQL Server 2016 SP1 及以上、Azure SQL Managed Instance，对不可用功能隐藏或禁用，旧版本实例仍可连接并给出警告

适用场景（解读层）

  • 在 Linux 或 macOS 终端中连接和管理 SQL Server 实例
  • 通过 SSH 或无图形界面的环境进行 SQL Server 管理（如使用 Device Code 方式登录 Entra）
  • 管理 Always On 可用性组、Fabric Data Warehouse 或 Azure SQL Managed Instance 的连接与浏览
📖 README 首段存档原文 · 程序抽取

goSSMS is a terminal-based SQL Server management application. It is distributed as a single executable and does not require an installer, SQL client tools, or separate database drivers.
