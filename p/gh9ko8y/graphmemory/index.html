基于 Graphiti、PostgreSQL 与 Redis 的双时态 AI 代理长期记忆服务

综述（解读层）

GraphMemory 是一个面向 AI 代理的记忆服务，以 FastAPI 提供 REST 接口，并通过 MCP server 供支持 MCP 的代理调用。事实带有效时间与记录时间两条时间轴，采用六变量衰减模型、时间梯度与 TTL 分类时效，遗忘为降级而非删除，原文账本只追加保留。依赖 Docker 运行 Neo4j、PostgreSQL、Redis，需要 OpenAI 兼容的 Embedding 与 LLM 接口。仓库不含 IM 适配插件等部署环境集成。

  • 双时态事实记录，每条事实同时包含有效时间（valid_from/until）与记录时间（tx time），并保留只追加的原文账本 episodes
  • 六变量衰减模型（S/D/R/E/C/I）、分级 TTL 与时间梯度存储，配合基于激活、匹配与资源适配的竞争检索
  • 提供 MCP server（add_memory、search_memory、memory_dedupe、memory_forget 等工具）与 Web 管理台（/ui）及 REST API

适用场景（解读层）

  • 为支持 MCP 的 AI 代理接入可积累、可衰减的长期记忆库
  • 需要区分「当时是什么」与「后来改了什么」的双时态事实查询场景
  • 按内容类型自动设置时效（临时状态 1 天至不可更改事实永久）的记忆管理场景
