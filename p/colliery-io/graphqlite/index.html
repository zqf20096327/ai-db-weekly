为 SQLite 添加图数据库能力与 Cypher 查询语言支持的扩展

综述（解读层）

GraphQLite 是一个 SQLite 扩展，通过 Cypher 语言在 SQLite 中存储和查询图数据。README 显示它支持 MATCH、CREATE、MERGE 等子句，内置 PageRank、Louvain、Dijkstra 等图算法，并提供 Python、Rust 和原生 SQL 三种接口。项目通过 openCypher TCK 验证，总体通过率 98.5%，采用 MIT 许可证，可通过 brew、pip 或 cargo 安装。

  • 支持 Cypher 查询子句：MATCH、CREATE、MERGE、SET、DELETE、WITH、UNWIND、RETURN
  • 内置图算法：PageRank、Louvain、Dijkstra、BFS/DFS、连通分量等
  • 通过 openCypher TCK 验证，3,880 个场景总体通过率 98.5%；提供 Python、Rust 和 SQL 接口

适用场景（解读层）

  • 在无需服务器的单文件 SQLite 环境中存储和查询图数据
  • 使用 Cypher 语言建模节点关系并执行图分析
  • 通过 Python 或 Rust 嵌入式调用图算法（如社区发现、路径计算）
