Rust 编写的嵌入式键值数据库，结合 B+ Tree 读与 LSM Tree 写的混合设计

综述（解读层）

Mace 是用 Rust 编写的嵌入式键值数据库，存储设计组合了 B+ Tree 式读取路径与 LSM Tree 式日志结构写入。提供 MVCC 快照隔离、ACID 事务、崩溃恢复、CRC 校验和可选 Zstd 压缩，支持 Linux、Windows、FreeBSD 和 macOS，通过 Cargo 引入，库 crate 发布名为 mace-kv 并另附独立发布的离线维护 CLI（mace-kv-cli）。README 称存储格式与公共 API 已基本稳定，适用于需要进行嵌入式存储方案生产评估的 Rust 开发者；跨版本的破坏性磁盘格式变更需执行一次离线重建迁移。

  • 支持并发 MVCC 快照隔离读写与崩溃安全的 ACID 事务提交、中止和恢复
  • 大值与索引分离存储，支持按 bucket 启用 Zstd 压缩与 Merge Operator
  • 持久化记录带 CRC 校验，跨重启和崩溃验证；提供独立发布的离线维护 CLI mace-kv

适用场景（解读层）

  • 在 Rust 应用中嵌入本地键值存储，需要事务与快照隔离读写的场景
  • 面向 SSD/NVMe 存储介质、需要日志结构写入设计的应用
  • 需要对现有数据库做离线维护和版本迁移的运维场景

Mace is a high-performance, embedded key-value database written in Rust, combining the predictable read performance of B+ Trees with the write throughput of LSM Trees.
