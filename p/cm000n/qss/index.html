Home Assistant 自定义集成，通过 InfluxDB 行协议将实体状态写入 QuestDB

综述（解读层）

QSS 是一个 Home Assistant 自定义组件，将实体状态经 InfluxDB 行协议持久化到 QuestDB 表中，用于长期存储与后续分析。组件维持单一持久连接，按 max_batch_size 或 flush_interval_seconds 批量写入，并支持按域名、实体 ID 或 glob 模式过滤。它不是 recorder 组件的替代品，也不能在无 QuestDB 实例时独立运行；需 Python 3.14+ 环境开发。

  • 通过 InfluxDB 行协议写入 QuestDB，缓存行按 max_batch_size（默认 500）或 flush_interval_seconds（默认 5 秒）批量刷出，并对瞬时写入错误自动重试
  • 支持按 domains、entities、entity_globs 进行包含/排除过滤，可配置目标表名以隔离多套 Home Assistant 实例的数据
  • 支持可选的身份认证与 SSL/TLS 连接，提供 HACS 与手动复制两种安装方式

适用场景（解读层）

  • 将 Home Assistant 实体状态长期存入 QuestDB，供 SQL 查询或 Grafana 等工具进行时间序列分析
  • 多套 Home Assistant 实例需要共用同一 QuestDB、通过不同表名隔离数据的场景
  • 需要按域名、实体或 glob 模式选择性记录部分实体状态的场景
📖 README 首段存档原文 · 程序抽取

QSS makes it possible to transfer state information of the Home Assistant entities simply and efficiently via InfluxDB Line Protocol into a QuestDB for long-term storage and later analysis.
