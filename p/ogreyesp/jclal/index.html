基于Java的主动学习开源类库，集成WEKA与MULAN实现单标签与多标签查询策略

综述（解读层）

JCLAL 是一个用 Java 编写的主动学习框架，遵循 GNU GPL 开源协议，面向需要设计和运行主动学习实验的开发者与研究者。实验通过单个 XML 配置文件定义评估方法、数据集、查询策略、停止条件与 oracle 等，可在终端批量执行多个实验，支持学习曲线可视化与非参数统计检验。1.1 版移除了实验配置 GUI 和 Weka 插件。

  • 基于 WEKA 和 MULAN 库实现单标签与多标签学习范式的查询策略，并支持 CLUS 和 LibSVM 多标签数据集格式
  • 实验通过 XML 配置文件定义评估方法、数据集、oracle（模拟或人工标注）、停止条件和监听器，可批量运行多个配置
  • 支持增量分类器（含 MOA 库）、5X2 与留一交叉验证、EPS/SVG 图形导出及基于 KEEL 代码的非参数统计检验 GUI

适用场景（解读层）

  • 运行单标签和多标签主动学习实验，比较不同查询策略的学习曲线
  • 通过 Console Human Oracle 进行人工逐条标注的真实使用场景，会话结束可导出已标注数据集
  • 在框架的对象结构上复用、修改和扩展新的查询策略或评估流程
