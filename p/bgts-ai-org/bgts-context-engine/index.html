🧭 简介解读层（AI·证据行可回查）

基于 PostgreSQL 代码图的确定性上下文引擎，供 AI 编码代理检索代码

综述（解读层）

BGTS Context Engine 将仓库索引为符号、调用、类型层级、HTTP 路由等构成的代码图，通过图遍历回答代理的任务定位问题；检索路径不含 LLM，同一提交返回相同排序，可选的上下文选择器为标记的概率步骤。部署依赖 PostgreSQL 16 加 Apache AGE 与 pgvector，通过 MCP（stdio）或 REST 提供服务，为 Cursor、Claude Code、OpenCode 等编辑器提供初始化命令。

  • 将仓库索引为包含符号、调用、引用、类型层级、HTTP 路由与跨语言桥接的代码图，用图遍历返回带 file:line 定位的结果
  • 检索路径不含 LLM，同一任务文本对同一提交返回相同排序；嵌入仅用于任务文本无明确命名时的入口点查找
  • 提供 MCP（stdio）与 REST 两种接口，附 cursor-init、claude-init、opencode-init、codex-init、copilot-init 等编辑器初始化命令，支持 hint 与 trust 两种代理模式

适用场景（解读层）

  • 为 AI 编码代理在陌生仓库中定位任务相关文件，替代逐轮 grep/glob 搜索
  • 需要可复现检索过程以排查代理错误修改的场景，可回放并定位出错的阶段
  • 在 Cursor、VS Code、Claude Code、OpenCode、Codex、GitHub Copilot 等工具中接入代码上下文服务
