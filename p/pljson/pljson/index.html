基于 PL/SQL 对象类型实现的 JSON 处理库，用于 Oracle 数据库

综述（解读层）

PL/JSON 在 Oracle 数据库内提供处理 JSON 数据的包与 API，使用者可在 PL/SQL 代码中实例化 JSON 对象并添加成员、数组与嵌套对象。当前主版本为 3，为每种 JSON 元素提供独立对象类型，继承自 pljson_element；安装仅作用于安装 schema，版本 3 不再提供 JSON 前缀同义词。

  • 提供 pljson、pljson_list、pljson_string、pljson_number、pljson_bool、pljson_null 等类型，均继承自 pljson_element
  • 支持 pljson_table.json_table 将 JSON 数据（含表中存储的 JSON 字符串）以表形式查询
  • 提供路径表达式操作，兼容 Oracle Basic SQL/JSON Path Expression Syntax（不含过滤表达式与函数步骤），数组索引从 1 开始

适用场景（解读层）

  • 在 Oracle PL/SQL 代码中持久化存储与操作 JSON 数据
  • 将 JSON 文档或表内 JSON 字符串转换为关系表形式查询
  • 需要在 12c 之前或未启用原生 JSON 支持的 Oracle 版本中处理 JSON
📖 README 首段存档原文 · 程序抽取

PL/JSON provides packages and APIs for dealing with JSON formatted data within PL/SQL code. General information about JSON is available at http://www.json.org.
