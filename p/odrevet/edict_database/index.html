🧭 简介解读层（AI·证据行可回查）

将 JMdict/KANJIDIC2 日语词典数据转换为 SQLite、PostgreSQL 数据库及 CSV 的工具

综述（解读层）

该项目用 Dart 编写的脚本读取 EDRDG 的 JMdict、KANJIDIC2 和 RADKFILE 数据源，生成 SQL 插入语句、CSV 文件，并进一步构建 SQLite 与 PostgreSQL 数据库。提供 bash 辅助脚本完成下载、建库、填充、压缩及测试，支持按 ISO 639 语言代码选取释义语言。源代码采用 MIT 许可，生成的数据库文件遵循 EDRDG 许可。

  • 支持从 JMdict、KANJIDIC2、RADKFILE 生成 SQLite、PostgreSQL 数据库及 CSV 导出
  • 提供 --langs 参数按语言（ISO 639-2/639-3）过滤释义，并可控制每条 INSERT 的 VALUES 数量
  • 包含 release.bash 一键构建流程，输出 SQLite、SQL、CSV、PostgreSQL dumps 及含版本与行数的 RELEASE.md

适用场景（解读层）

  • 需要将日语词典数据导入关系型数据库进行查询的应用开发
  • 构建本地 SQLite 格式的日语词汇或汉字查询数据集
  • 通过 docker 运行 PostgreSQL 并批量导入词典数据的环境部署
