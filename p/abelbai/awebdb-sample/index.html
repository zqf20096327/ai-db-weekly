Android 内嵌 SQLite 库的 Web 查询工具

综述（解读层）

AWebDB 基于 nanohttpd 在 Android 应用内运行一个小型 Web 服务器，供开发者通过浏览器执行 SQL 语句查询应用的 SQLite 数据库，免去导出 db 文件的步骤。接入方式为添加 Gradle 依赖后调用 AWebDB.hook 传入上下文、库名和端口，再访问 http://ip:port/?sql 格式的地址。README 未提及鉴权机制，样本仓库为 abelbai/AWebDB-Sample。

  • 基于 nanohttpd 在 Android 设备上启动 Web 服务器
  • 通过浏览器 URL 中的 SQL 参数直接查询 SQLite 数据库
  • 提供获取本地 IP 地址和服务器端口的 API

适用场景（解读层）

  • Android 应用开发调试时查看数据库内容
  • 无需导出 db 文件即可在浏览器中检查表结构
  • 在局域网内对设备上的 SQLite 数据执行查询
