从 PostgreSQL schema SQL 文件生成 Ecto 迁移脚本的 Elixir Mix 任务库。

综述（解读层）

这是一个 Elixir 库，提供 mix ecto.extract.migrations 任务，读取 pg_dump 导出的 schema-only SQL 文件并生成对应的 Ecto 迁移文件，供将现有数据库项目迁移到 Elixir 开发流程的团队使用。解析器基于 NimbleParsec 按 SQL 语法实现，支持 CREATE TABLE/VIEW/INDEX/FUNCTION/TRIGGER/TYPE 等常用语句；README 说明不覆盖全部冷门选项，可通过指定 repo 与迁移目录在目标项目外部运行。

  • 基于 NimbleParsec 依 SQL 语法解析 pg_dump 导出的 schema SQL 文件并生成 Ecto 迁移
  • 支持 CREATE TABLE、CREATE VIEW、CREATE INDEX、CREATE SEQUENCE、CREATE FUNCTION、CREATE TRIGGER、CREATE TYPE、CREATE SCHEMA、CREATE EXTENSION 及对应 ALTER 语句
  • 可在目标项目外运行，通过 --repo 与 --migrations-path 参数指定仓库和迁移输出目录

适用场景（解读层）

  • 将已有的 PostgreSQL 数据库引入 Elixir/Ecto 的开发工作流
  • 为包含大量表和对象的存量数据库生成初始迁移文件
  • 生成迁移后在测试库上重放并与原库导出比对验证一致性
