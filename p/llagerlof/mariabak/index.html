mysqldump 的命令行前端，用于简化 MariaDB/MySQL 备份操作

综述（解读层）

mariabak 是一个 PHP 编写的命令行脚本，封装 mysqldump，用于备份 MariaDB 和 MySQL 数据库。它为每个数据库生成单独的 dump 文件，可在跳过指定表数据的同时保留表结构，并把用户授权、系统变量和事件写入单独文件。运行需 PHP 7+（含 pdo_mysql 扩展）及 PATH 中的 mysqldump，账号需 select、lock tables 等权限。

  • 每次备份为每个数据库生成独立的 dump 文件，并在当前目录创建带时间戳的备份目录
  • 支持用 --ignore-tables 排除指定表的数据，同时保留这些表的表结构
  • 可将用户授权、系统变量和事件备份到单独文件，支持 * 通配符备份全部数据库

适用场景（解读层）

  • 需要为多个数据库分别生成 dump 文件的备份任务
  • 备份数据库时需要排除日志、缓存等表的数据但保留其结构
  • 希望用单条命令完成 mysqldump 多条命令组合的操作
