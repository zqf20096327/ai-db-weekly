macOS 上的 MySQL/MariaDB 数据库管理应用，Sequel Pro 的后续项目

综述（解读层）

Sequel Ace 是 Sequel Pro 的后续 macOS 应用，用于管理 MySQL（≥5.7）与 MariaDB（≥10.0）数据库，支持 Intel 与 Apple Silicon，要求 macOS ≥13.5。可通过 App Store、mas CLI 或 Homebrew Cask 安装。内置 MCP 服务器（默认关闭）供 AI 代理通过已有连接查询数据库，旧版 macOS 可下载历史版本。

  • 支持 MySQL ≥5.7 与 MariaDB ≥10.0，兼容 Intel 与 Apple Silicon 处理器
  • 提供 App Store、mas CLI 和社区 Homebrew Cask 三种安装方式
  • 内置 MCP 服务器，允许 AI 代理复用已有连接查询数据库，默认关闭且默认只读、仅监听 localhost

适用场景（解读层）

  • 在 macOS 上管理 MySQL 或 MariaDB 数据库
  • 让 Claude Code、Cursor 等 AI 代理通过 MCP 协议查询数据库
  • 从 Sequel Pro 迁移已保存的连接 favorites
