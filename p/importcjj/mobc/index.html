支持 async/await 的 Rust 通用数据库连接池

综述（解读层）

mobc 是一个面向 Rust 异步生态的通用连接池，通过 Manager trait 管理任意后端的连接获取与校验。支持 tokio 与 async-std 两种运行时，并提供 postgres、redis、bolt、arangodb 等适配器 crate。可配置最大连接数、空闲数、连接生命周期与获取超时，部分参数支持运行时动态调整。注意基于 tokio 的驱动无法在 async-std 运行时中使用。

  • 支持 async/.await 语法，同时兼容 tokio 与 async-std 运行时
  • 提供 max_open、max_idle、max_lifetime、get_timeout 等配置项，max_open 等参数可通过实例方法动态调整
  • 内置连接统计信息，并暴露 tokio metrics 格式的计数器、仪表与直方图指标

适用场景（解读层）

  • 为 tokio-postgres、redis 等 Rust 异步数据库驱动添加连接复用与并发控制
  • 需要按生命周期、空闲数等策略管理连接并监控池状态的服务
  • 需要通过适配器接入 bolt、arangodb、lapin 等后端的 Rust 应用
