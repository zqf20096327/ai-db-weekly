Rust 编写的可嵌入式/服务器模式关系数据库，各组件为可替换插件接口。

综述（解读层）

Turborel 是用 Rust 编写的关系数据库，版本 0.0.0 处于 alpha 阶段，SQL、API、协议与文件格式均可能变动。可作为库嵌入或以 turboreld 服务端运行，配套命令行客户端。存储引擎、索引、类型、优化器规则等均为插件接口；支持行式/列式存储、MVCC 事务、基于 Viewstamped Replication 的复制。BSD 2-Clause 许可。

  • 支持嵌入为库或以 TCP/Unix socket/Windows 命名管道服务端运行，带 TLS、用户认证与预编译语句
  • 事务默认 READ COMMITTED，最高可到 SERIALIZABLE，基于 MVCC、WAL、检查点与崩溃恢复
  • 存储引擎、索引方法、数据类型、优化器规则、认证与传输协议等均为可替换或可扩展的插件接口

适用场景（解读层）

  • 通过 cargo run 启动服务端并用 SQL 客户端进行本地开发与测试
  • 将数据库作为库嵌入应用进程内运行
  • 以三节点部署使用多数派提交复制，容忍单节点故障
