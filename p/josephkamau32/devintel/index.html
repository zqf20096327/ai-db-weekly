基于 PostgreSQL pgvector 的代码库索引与 RAG 问答开发平台

综述（解读层）

DevIntel AI 是一个异步代码智能平台，将 GitHub 仓库索引到 PostgreSQL 向量数据库，提供代码库问答、代码健康评分、架构图生成和自动 PR 审查，面向需要查询和理解代码库的开发者。系统采用 FastAPI 后端、React 前端和 VS Code 扩展的单仓结构，代码分块基于 Tree-sitter 语法单元而非行偏移，运行需 PostgreSQL 16、pgvector 扩展及 Gemini 或 OpenAI API 密钥。

  • 使用 Tree-sitter 按类、函数、方法等语法单元分块索引，支持 Python、TypeScript、Go、Rust、Java 等 11 种语言，解析失败时回退到按行切分
  • 在 PostgreSQL 内通过 pgvector 执行余弦距离向量检索，可选结合 BM25 词法搜索与 RRF 融合，并支持 Gemini 和 OpenAI 两种嵌入提供商
  • 通过 PostgreSQL 作业表与 SELECT FOR UPDATE SKIP LOCKED 实现异步任务队列，处理全量索引、增量提交更新和健康分析任务

适用场景（解读层）

  • 连接 GitHub 仓库后通过流式聊天界面或 VS Code 扩展进行代码库上下文问答
  • 对仓库生成复杂度、文档、可维护性、测试覆盖和安全等维度的健康评分并给出技术建议
  • 解析 PR 的 unified diff 生成结构化审查意见，并基于补丁计划自动创建修复分支和 Pull Request
