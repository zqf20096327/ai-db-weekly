CoCreate 生态下的 TiDB CRUD 封装与多租户状态路由客户端

综述（解读层）

该库为 CoCreate 生态提供 TiDB 的 CRUD 封装，把类 NoSQL 的 JSON 操作（如 object.create/object.read）转换为 MySQL 兼容查询在 TiDB 分布式引擎上执行。支持通过 storage 数组并行写入多个后端（如 MongoDB、Qdrant），并注入租户元数据实现多租户路由。面向使用 CoCreate 状态路由管线的开发者，通过 npm/yarn 安装，依赖 TiDB 集群本身。

  • 将 JSON 格式 CRUD 操作（object.create、object.read）转换为 MySQL 兼容查询在 TiDB 上执行
  • 支持在 storage 键声明数组，单次调用并行写入多个数据库后端
  • 路由时自动注入租户元数据，提供多租户组织边界隔离

适用场景（解读层）

  • 在 CoCreate 协作应用中将业务数据持久化到 TiDB 分布式 SQL 存储
  • 需要同一份数据同时写入 TiDB、MongoDB、Qdrant 等多个后端的场景
  • 多租户应用中需要按组织边界隔离 TiDB 关系型查询的环境
