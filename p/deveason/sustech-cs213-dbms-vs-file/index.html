🧭 简介解读层（AI·证据行可回查）

C++ 微基准：对比纯文件、索引文件、PostgreSQL 与 openGauss 的查询性能

综述（解读层）

南科大 CS213 数据库课程项目，包含一个约 1340 行的 C++17 基准程序 filmbench，对纯 CSV 文件、自建索引文件、PostgreSQL 与 openGauss 四种存储方案运行扫描、前缀匹配、全文检索、连接、分组等九类查询。采用 C/S/ε 双时钟计时模型（调用方耗时、服务器耗时、空往返），10 张表 76,131 行数据，输出报告 PDF。需 WSL2 + Linux 容器环境运行。

  • 单个 C++ 文件实现四种存储后端（csv、indexed、PostgreSQL、openGauss）的九类查询基准，测量输出为 20 次运行的中位数（3 次预热）
  • 提供 C（调用方耗时）、S（服务器语句日志耗时）、T（空往返）的计时分解模型
  • 命令行支持 --op、--layout、--dsn、--log-server-timing、--no-index 等参数，结果可追加至共享 CSV 并用 verify 校验一致性

适用场景（解读层）

  • 数据库系统课程实验：量化 DBMS 与手写索引在内存可容纳数据规模上的行为差异
  • 在同一机器上对 PostgreSQL 与 openGauss（PG 兼容模式）运行相同查询矩阵做性能记录
  • 教学演示计时方法论：将客户端等待拆分为网络往返、服务器执行与残余开销
