实现 Apache Kafka API 的无状态 broker，存储引擎可插拔

综述（解读层）

Nisshi 是用 Rust 编写的单二进制无状态服务器，实现 Apache Kafka 线协议（基于 Kafka 3.9.1 消息描述符生成），应用可直接使用 Kafka 客户端。数据保存在可插拔存储引擎（PostgreSQL、SQLite/libSQL、S3、内存）中，共享引擎的 broker 均可响应请求；带 schema 的主题可写入 Iceberg 或 Delta Lake 表。不支持事务，Kafka Streams 的 exactly_once_v2 无法使用。

  • 实现 Kafka 线协议，幂等生产者可用，事务不支持
  • 存储引擎可插拔：PostgreSQL、libSQL、SQLite、S3、内存
  • 按 Avro/JSON Schema/Protobuf 校验的主题可写为 Apache Iceberg 或 Delta Lake 表，支持 TLS 与 SASL SCRAM

适用场景（解读层）

  • 希望用现有 Kafka 客户端而不运行 Kafka broker 集群的场景
  • 需要消息落库共享存储（如与业务同库实现事务性 outbox）的架构
  • 将带 schema 的消息写入数据湖表（Iceberg/Delta Lake/Parquet）供 Spark、DuckDB 等查询
