MiniProfiler 的 IDbProfiler 扩展库，记录执行成功与失败的数据库命令

综述（解读层）

MiniProfiler.Integrations 提供 IDbProfiler 的自定义实现，记录已成功执行和失败的数据库命令，包含命令文本、参数、数据库与连接信息及错误。核心包内置 SQL Server 连接工厂，通过安装 MiniProfiler.Integrations.MySql 包获得 MySQL 支持，也可自行实现 IDbConnectionFactory 接入其他数据提供程序。适用于 .NET 项目中需要留存命令执行日志的场景。

  • 自定义 IDbProfiler 实现可记录成功与失败的数据库命令，含命令文本、参数、连接细节与错误信息
  • 核心包包含 SQL Server 连接工厂，MySQL 支持通过单独的 MiniProfiler.Integrations.MySql 包提供
  • 支持实现 IDbConnectionFactory 接口以接入其他数据库提供程序

适用场景（解读层）

  • 需要记录应用中全部已执行 SQL 命令（成功与失败）用于日志留存
  • 结合 MiniProfiler 与 Dapper 使用 SQL Server 或 MySQL 的 .NET 数据访问层
  • 需要接入 MiniProfiler 之外的其他数据库提供程序时自定义连接工厂
