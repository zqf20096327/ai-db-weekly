PHP 侧 PostgreSQL 复杂类型转换器与 pgsql 扩展的面向对象封装

综述（解读层）

该包提供两部分功能：将 PostgreSQL 数组、范围、几何、日期时间、复合类型、JSON 等复杂类型转换为 PHP 对应值，并封装原生 pgsql 扩展。转换器可配合 PDO 单独使用，但查询结果的透明类型转换仅在封装层可用，类型依据结果元数据推断。要求 PHP 8.2 以上，PostgreSQL 12 以上，生产环境建议配置 PSR-6 元数据缓存。

  • 支持 PostgreSQL 数组、范围、几何、日期时间、复合（行）类型、JSON 等复杂类型与 PHP 值的双向转换
  • 可基于查询结果元数据自动推断类型，无需额外配置；转换器部分可单独配合 PDO 使用
  • 提供对 pgsql 扩展的面向对象封装，支持原生 $1 位置参数；生产环境支持 PSR-6 元数据缓存

适用场景（解读层）

  • PHP 应用中需要读取或写入 PostgreSQL 复杂类型字段（如数组、复合类型、几何类型）的场景
  • 在 PDO 或原生 pgsql 之上需要类型转换能力，且希望使用一次性执行查询的场景
  • 通过 id = ANY($1::INTEGER[]) 原生数组方式向 IN 类查询传递参数列表
📖 README 首段存档原文 · 程序抽取

This package has two parts and purposes * Converter of PostgreSQL data types to their PHP equivalents and back and * An object-oriented wrapper around PHP's native pgsql extension.
