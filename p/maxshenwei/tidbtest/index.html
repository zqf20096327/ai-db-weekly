🧭 简介解读层（AI·证据行可回查）

面向 TiDB 的 AI 辅助测试框架，支持 SQL 测试执行、用例生成与失败分析。

综述（解读层）

这是一个用于 TiDB 的最小可用测试框架（MVP），通过 Python CLI 运行 YAML 与 .test 两种格式的 SQL 测试用例，生成 JSON 与 HTML 报告，并可调用 OpenAI API 生成测试用例和分析失败原因。提供 docker-compose 一键启动 TiDB 单节点容器，兼容 mysql-tester 的 .test/.result 用例格式，可直接运行 pingcap/tidb 仓库中的测试文件。适用于需要搭建 TiDB SQL 测试流程的测试人员。

  • 支持 YAML 原生用例格式，包含 rows/count/error/affected_rows/regex 五种断言类型及 tolerance、ignore_order、min_version 反 flaky 选项
  • 兼容 TiDB/mysql-tester 的 .test/.result 格式，支持 --error 和 --sorted_result 指令，可直接运行 pingcap/tidb 仓库的测试文件
  • 每次测试运行自动生成 JSON（机器可读）与 HTML（人工查看）报告，可调用 OpenAI API 生成测试用例和分析失败

适用场景（解读层）

  • 对 TiDB 或 MySQL 实例执行 SQL 回归测试并生成可视化报告
  • 复用 pingcap/tidb 仓库中已有的 .test 测试用例而无需格式转换
  • 借助 OpenAI API 根据功能描述生成测试用例或对失败结果进行分析
