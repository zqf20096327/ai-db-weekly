🧭 简介解读层（AI·证据行可回查）

内嵌 PHP 的 Adminer 单文件桌面版，免装 Web 服务器，启动后于浏览器窗口打开

综述（解读层）

该项目将 Adminer 数据库管理工具与自带 PHP 打包为 Windows 的 adminer.exe、Linux 的 tar.xz 和 macOS 的 Adminer.app，无需安装 PHP 或配置 Web 服务器。程序仅在 127.0.0.1 监听，运行时解包到临时目录，关闭窗口即停止。支持 MySQL/MariaDB、PostgreSQL、SQLite；MS SQL 与 Oracle 需额外驱动。适合没有 PHP 环境或不想搭建服务器的用户。

  • 提供 Windows exe、Linux tar.xz、macOS Apple Silicon 版三种免安装包，启动即解包到临时目录，停止时删除
  • MySQL/MariaDB、PostgreSQL、SQLite 开箱即用，Elasticsearch、ClickHouse、Redis 通过插件驱动支持；允许空密码但服务仅监听 127.0.0.1
  • Linux/macOS 使用 static-php-cli 构建的静态 PHP，不依赖发行版库；构建脚本可指定版本和平台

适用场景（解读层）

  • 本机没有 PHP 或 Web 服务器环境、需要通过浏览器界面管理 MySQL、PostgreSQL 或 SQLite 数据库
  • 在 Windows 上管理 MS SQL 或 Oracle，需手动安装 ODBC Driver 17/18 或 Oracle Instant Client
  • 通过插件驱动连接 ClickHouse、Elasticsearch、Redis（含 https:// 服务器）
