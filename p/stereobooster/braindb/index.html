BrainDB：基于 Markdown 的图数据库内容层

综述（解读层）

BrainDB 是一个处于开发中的项目，定位为 markdown-graph-content-layer-database，即基于 Markdown 的图数据库内容层。它由核心包 @braindb/core 和 remark-wiki-link 插件组成，附有 astro-digital-garden 示例。README 明确警告项目仍在进行中，可能出现破坏性变更。

  • 提供核心包 @braindb/core 与 remark-wiki-link 插件两个 NPM 包
  • 包含 astro-digital-garden 示例项目
  • 项目处于开发进行中，README 声明可能出现破坏性变更

适用场景（解读层）

  • 需要将 Markdown 内容以图结构形式组织与管理的场景
  • 参考 astro-digital-garden 示例构建数字花园类站点
  • 在 Remark 生态中处理 wiki 链接语法
