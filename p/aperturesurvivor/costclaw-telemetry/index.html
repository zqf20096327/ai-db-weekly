🧭 简介解读层（AI·证据行可回查）

面向 OpenClaw 的本地缓存感知 LLM 用量与成本遥测插件。

综述（解读层）

CostClaw 是一个独立的社区 OpenClaw 插件，通过 llm_output 钩子读取模型调用的 token、缓存和成本元数据，写入本地 SQLite 数据库，并在 127.0.0.1 提供仪表盘，另注册两个查询花费的代理工具。需 OpenClaw 2026.5.7+ 与 Node.js 22+；项目已声明不再维护，且非记账系统，成本为估算性质。

  • 记录每次调用的提供商、模型、缓存读写 token、成本来源分类及会话/触发器/子代理归因，不存储提示词或响应文本
  • 成本计算优先采用 OpenClaw 归一化成本，其次用户自定义价格（支持输入/输出/缓存读/缓存写分项费率），否则记为 $0.00
  • 数据仅存于本地 ~/.openclaw/costclaw.db，仪表盘默认绑定 127.0.0.1，无出站网络请求

适用场景（解读层）

  • 在本地仪表盘查看今日/月度/七日/三十日 LLM 花费与含缓存流量的 token 总量
  • 按模型、触发器、子代理和会话维度分解用量，并查看工具失败信息
  • 通过 costclaw_status 代理工具在会话中查询当前花费汇总
