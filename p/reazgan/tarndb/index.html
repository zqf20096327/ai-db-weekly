🧭 简介解读层（AI·证据行可回查）

C11 编写的嵌入式键值存储，每笔写入追加并 fsync 后才返回。

综述（解读层）

tarn 是一个以崩溃安全为设计目标的嵌入式键值存储，提供 C API 和命令行工具，面向需要在进程崩溃或断电后不丢失已确认写入的场景。数据写入仅追加的段文件并同步落盘，内存哈希表索引实现单次读取；恢复时逐条校验 CRC32C，可截断损坏尾部或跳过坏记录。限制包括全部键常驻内存（每键约 100 字节索引）、不支持范围扫描、句柄非线程安全。

  • 默认 TARN_SYNC_ALWAYS 模式下每次写入 fsync 后才返回，macOS 使用 F_FULLFSYNC；fsync 失败后拒绝后续写入
  • 段文件采用 16 字节记录头（双 CRC32C 校验），恢复支持截断尾部、跳过坏值记录和逐字节滑动寻找下一个完整记录
  • 内存索引为线性探测哈希表，使用 SipHash-2-4，键长上限 64 KiB、值上限 1 GiB；提供 tarn_compact 压实，以重命名作为提交点

适用场景（解读层）

  • 需要单进程嵌入式持久化键值读写的 C/C++ 应用
  • 进程可能被 kill -9 或遭遇断电、要求已确认写入不丢失的存储场景
  • 通过命令行工具 tarn 对指定目录执行 put/get/del 操作的脚本化使用
