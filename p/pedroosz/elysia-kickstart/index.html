基于 Bun + Elysia + Drizzle ORM 与 PostgreSQL 的脚手架项目

综述（解读层）

该项目是一个后端开发脚手架，组合 Bun 运行时、Elysia Web 框架、Drizzle ORM 和 PostgreSQL 数据库，用于快速搭建 TypeScript API 服务。启动流程包含依赖安装、docker compose 启动数据库、执行迁移及运行开发服务器，并在 /swagger 路径提供 API 文档访问。

  • 使用 bun install 安装依赖，bun run dev 在 localhost:3000 启动开发服务器
  • 通过 docker compose 启动 PostgreSQL 数据库实例
  • 使用 bun run migrate 执行数据库迁移以创建数据表

适用场景（解读层）

  • 需要 Bun 与 Elysia 技术栈起点的新 API 项目初始化
  • 需要 Drizzle ORM 配合 PostgreSQL 进行数据库迁移管理的项目
  • 需要本地容器化数据库环境的开发与调试场景
