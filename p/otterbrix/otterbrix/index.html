C++ 编写的半结构化数据处理计算框架，融合文档模型与列式分析，支持 SQL 查询。

综述（解读层）

Otterbrix 是一个面向半结构化数据处理的开源计算框架，使用 C++ 实现，通过 PyPI 以 Python 包形式分发。它提供 SQL 和 DataFrame 两种查询接口，采用混合元组与 Arrow 格式的内存布局，可直接读取 JSON、Parquet、ORC、Avro 等格式的数据。构建需 C++20 编译器、CMake 3.25+ 与 Conan 2。

  • 支持无需预定义 schema 的数据摄取与查询，统一处理扁平表格和嵌套层级数据
  • 提供 SQL 语法和 DataFrame 风格操作两种接口，支持行、列、文档及高维向量多种存储模式
  • 可在 JSON、Parquet、ORC、Avro、Arrow 等标准格式之间进行数据转换

适用场景（解读层）

  • 在微服务或后端服务中嵌入，对日志、流式数据进行本地过滤和聚合
  • 处理结构变化的 IoT 传感器数据或第三方 API 响应等混合结构化与半结构化负载
  • 在应用程序内集成查询与报表功能，实现离线分析而不依赖外部数据库服务
