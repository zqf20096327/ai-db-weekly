Outerbase Studio：浏览器端轻量 SQL 数据库管理 GUI

综述（解读层）

Outerbase Studio 是运行在浏览器中的 SQL 数据库管理界面，最初面向 LibSQL 和 SQLite 构建，现支持 Turso/LibSQL、SQLite 本地文件、Cloudflare D1、rqlite、StarbaseDB、Val.town 等 SQLite 系数据库，MySQL 与 PostgreSQL 为 beta 且功能受限。它提供查询编辑器、数据编辑器、架构编辑器与连接管理器，也可通过 Electron 桌面版连接浏览器环境不便支持的驱动。适合需要直接管理 SQLite 系数据库的用户。

  • 提供查询编辑器，支持自动补全、函数提示与同时执行多条查询
  • 数据编辑器支持暂存变更、提交前预览，数据表可渲染数千行列
  • 支持 SQLite 系数据库（LibSQL、D1、rqlite 等），MySQL/PostgreSQL 为 beta 且功能受限

适用场景（解读层）

  • 在线编辑与管理 SQLite 及 LibSQL 数据库
  • 管理 Cloudflare D1、rqlite 等 SQLite 系托管数据库
  • 通过桌面版连接 MySQL/PostgreSQL 数据库
