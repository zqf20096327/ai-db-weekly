🧭 简介解读层（AI·证据行可回查）

基于 Spark 将大规模 RDF 数据集转换为关系数据库、CSV、JSON 和 ElasticSearch 的工具。

综述（解读层）

RDF2X 用于将大型 Linked Data RDF 数据集转换为关系模型（写入 JDBC 数据库，支持 PostgreSQL COPY 批量加载）、CSV、JSON 或 ElasticSearch，基于 Spark 1.6 运行，可本地执行或提交至 YARN 集群。它将实体和关系组织为表并持久化元数据表，提供 Wikidata 与 Bio2RDF 两种 flavor，README 附带 ClinicalTrials.gov 约 1.59 亿 quads 的实测参数。注意其依赖的 Spark 1.6 存在已公告的反序列化安全问题。

  • 支持输出到关系数据库（DB）、CSV、JSON、ElasticSearch 及 Preview 目标
  • 提供资源 URI、类型、语言等过滤参数，以及针对 Wikidata 和 Bio2RDF 数据源的 flavor 配置
  • 转换时生成 _META_Entities、_META_Columns、_META_Relations、_META_Predicates 元数据表

适用场景（解读层）

  • 将 Wikidata、Bio2RDF（如 ClinicalTrials.gov）等 RDF 转储导入 PostgreSQL 供 SQL 查询
  • 为 Tableau 等分析工具准备关系化或 CSV/JSON 格式的 RDF 数据
  • 在 YARN 集群上分布式处理超大规模 RDF 数据集的格式转换
