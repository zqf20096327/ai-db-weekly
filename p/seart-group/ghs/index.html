🧭 简介解读层（AI·证据行可回查）

持续抓取并存储 GitHub 仓库数据，通过 API 与网页前端展示的项目平台

综述（解读层）

GHS 平台由两部分组成：Spring Boot 后端持续调用 GitHub GraphQL API 抓取仓库信息存入 MySQL 数据库，并对外提供 API；前端为 Bootstrap/jQuery 网页界面。附带的仓库分析作业会克隆项目并用 cloc 统计代码规模。适用于需要自建 GitHub 仓库数据集的研究者，MSR 主题标签提示其面向挖掘软件仓库方向。部署需 Java 17、Maven、MySQL，或使用提供的 docker-compose；可用官方 SQL dump 预填数据。

  • 后端持续抓取 GitHub API 仓库信息并存储，同时以 API 形式提供数据访问；配套 Bootstrap/jQuery 网页前端
  • 支持通过配置项控制抓取行为，包括 star 下限、目标语言列表、起止日期与抓取间隔等参数
  • 提供 docker-compose 部署（含数据库、Flyway 迁移、服务器、网站容器），并托管可导入的 SQL 数据 dump

适用场景（解读层）

  • 自建 GitHub 仓库元数据与统计数据的采集平台
  • 生成用于挖掘软件仓库（MSR）研究的数据集
  • 通过 API 或导出（主题含 csv/json-export）获取仓库统计数据供后续分析
