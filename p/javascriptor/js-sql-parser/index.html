基于 jison 的 SQL Select 解析器，可将 SQL 解析为 AST 并还原

综述（解读层）

js-sql-parser 是一个 JavaScript 编写的 SQL 解析器，使用 jison 生成，语法依据 MySQL 5.7 文档的 SELECT 部分。它把 SELECT 语句解析为抽象语法树（AST），也支持将 AST 序列化回 SQL 字符串，并支持 ${param} 占位符（占位符为 literal 而非 identifier，表名/列名不可替换）。可通过 npm（CommonJS）、script 标签或 AMD 引入，支持 Node 与浏览器运行。文档列出了暂不支持的部分语法，如 COLLATE、全文检索函数、INTERVAL 关键字等。

  • 用 jison 实现的 SQL (select) 解析器，提供 parse 与 stringify 双向转换
  • 语法依据 MySQL 5.7 文档中 SELECT 部分的描述
  • 自 v1.5.0 起支持 ${param} 形式的占位符

适用场景（解读层）

  • 需要将 SELECT 语句解析为 AST 供 JavaScript 代码读取或改写的场景
  • 需要在浏览器中通过 script 标签解析 SQL 的场景
  • 需要用占位符模板生成 SQL 的场景
