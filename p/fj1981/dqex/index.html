🧭 简介解读层（AI·证据行可回查）

单二进制跨平台数据库工具箱，集成导入导出、迁移、比较与AI辅助SQL

综述（解读层）

dqex 是用 Go 编写的数据库工作台，打包为单个静态二进制文件，无需 JVM 或网络依赖，通过 Web UI 与 CLI 提供导出、导入、跨方言迁移、结构数据比较、快照和 Excel 数据字典等功能，支持 MySQL、PostgreSQL、Oracle 三种数据库。AI 辅助 SQL 需配置 API 后才启用，写操作需人工确认，离线场景可用内置 SQL 模板库替代。适合受限网络环境下的数据库运维人员。

  • 以单一静态二进制分发，内嵌前端，支持 macOS/Linux/Windows，可在离线环境运行
  • 提供导出、导入、跨方言迁移（如 MySQL 转 PostgreSQL）、双库 schema 与数据比较、快照生命周期管理
  • AI 辅助 SQL 基于真实表结构生成方言适配语句，写操作需确认；未配置 AI 时自动隐藏入口，并内置离线 SQL 模板库

适用场景（解读层）

  • 在无外网的隔离网络（如内网服务器）中部署数据库管理与查询工具
  • 执行跨数据库方言的结构与数据迁移、双库差异比较与快照对比
  • 生成 Excel 数据字典、导出执行历史等审计所需的合规材料
