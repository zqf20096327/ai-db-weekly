微软 Bw-Tree 无锁并发 B+ 树索引的开源 C++ 实现

综述（解读层）

该项目实现了 Microsoft Research 提出的 Bw-Tree，一种通用并发无锁 B+ 树索引，允许多线程同时修改和查询。项目与 CMU 的 Peloton 数据库原型共同开发，采用 Apache License。README 指出其只保证操作原子性，不提供并发控制，需要隔离性时须额外实现并发控制层。文档还记录了 ABORT delta 等设计改动、已知问题及编译测试命令。

  • 提供无锁并发 B+ 树索引，支持多线程并发读写
  • 提供 make 命令集，覆盖调试编译、基准测试（含与 std::map、stx::btree 等对比）、压力测试和多种专项测试
  • 包含 ABORT delta、InnerDeleteNode 等 delta 链处理机制的实现改进，并提供 baseline 等多个 release 版本

适用场景（解读层）

  • 需要在多线程环境中使用的有序索引结构
  • 数据库系统原型中的索引组件集成（从 STL 容器切换通常只需少量代码修改）
  • 无锁数据结构的研究与教学参考实现
