Go 编写的轻量级内存向量数据库，基于 HNSW 算法

综述（解读层）

EigenDB 是用 Go 编写的开源内存向量数据库，面向 AI 应用场景。它采用 HNSW（分层可导航小世界）算法进行相似性检索，该算法逻辑由其开源 Go 库 faissgo 实现，对外提供简单 REST API，并配有 Python SDK 便于集成。项目采用 GPL v3 许可证，文档站点已上线，贡献指南尚未发布。

  • 基于 HNSW 算法实现向量相似性检索，相关逻辑由其开源 Go 库 faissgo 处理
  • 提供 REST API，附带 Python SDK 用于集成
  • 以内存方式运行，使用 Go、C++、Python 等多种语言开发，支持 Docker 部署

适用场景（解读层）

  • 为 AI 代理与 LLM 应用提供向量存储与 KNN 检索
  • 在 Python 应用中通过 SDK 集成向量数据库能力
  • 使用 OpenAI 或 Ollama 嵌入数据的场景下进行相似性查询
