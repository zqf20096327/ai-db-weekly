综述（解读层）

Telemetry Tracker 是一个 MIT 协议的开源遥测项目，用于收集应用错误、事件、会话与 Web Vitals 数据。架构为 Fastify 摄入/读取 API 加 Next.js 仪表盘，数据存于 PostgreSQL，仪表盘仅通过 API 读取。提供 @telemetry-tracker/* 系列 SDK，支持 React、Next.js、Node、NestJS、Vue、Nuxt、React Native 等。本地运行需 Node.js 18+、pnpm 9、PostgreSQL 16。告警仅支持错误计数与 no events 条件，其他条件类型仅限 API。

  • 支持错误、事件、会话、性能/Web Vitals、发布版本、告警规则、source maps 与 REST API
  • 提供 @telemetry-tracker/* 系列 SDK，覆盖 React/Vue、Next.js、Node/NestJS、Nuxt、React Native 与原生 JS
  • 告警可通过应用内通知、邮件、HTTPS webhook、Slack、Discord、Teams、Telegram 投递

适用场景（解读层）

  • 在自有基础设施上自托管错误追踪与产品分析
  • 前端应用采集错误、Web Vitals 与会话遥测
  • 配置错误计数或业务心跳类告警并推送至 Slack/Telegram 等渠道
