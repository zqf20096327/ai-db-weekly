基于 PostgreSQL 与 pgvector 的多模态语义搜索引擎

综述（解读层）

Pany 是一个运行在 PostgreSQL 内的语义搜索服务，通过 CLIP 模型将文本与图像转为向量，存入 pgvector 扩展并以余弦相似度检索。它提供 Web 界面、REST API、Python SDK 与 React 组件，支持通过 SQL 将搜索结果与既有数据表连接。需 Python 3.9+ 与带 pgvector 的 PostgreSQL，最低 4GB 内存，README 注明其为 Beta 阶段、v1.0 前 API 可能变动。

  • 使用 CLIP 模型实现文本与图像的跨模态检索，向量存储在 PostgreSQL 的 pgvector 扩展中
  • 支持 pip 安装、Docker Compose 与 Kubernetes 部署，提供 REST API、Python SDK 与网页搜索组件
  • 搜索结果可与既有关系数据通过 SQL join 联合查询

适用场景（解读层）

  • 对已有 PostgreSQL 应用在其数据库内追加语义搜索能力
  • 产品目录、PDF 文档、媒体库或支持知识库的自然语言检索
  • 以文本描述搜图或以图搜图的跨模态内容查找
