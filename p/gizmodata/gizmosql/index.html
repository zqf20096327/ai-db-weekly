基于 DuckDB/SQLite 后端与 Apache Arrow Flight SQL 协议的 SQL 服务器

综述（解读层）

GizmoSQL 是一个 SQL 服务器，以 DuckDB 或 SQLite 作为查询执行后端，通过 Apache Arrow Flight SQL 协议对外提供服务，支持 TLS/mTLS 与 JWT 认证，可用于容器、原生二进制或 Kubernetes 部署。项目处于维护模式，README 建议后续使用 Hardcharger。Core 版本采用 Apache 2.0 许可，会话管理、Prometheus 指标等功能需商业授权的 Enterprise 版本。

  • 支持 DuckDB 与 SQLite 双后端，可通过 -B 参数在运行时选择
  • 采用 Apache Arrow Flight SQL 协议，提供 JDBC、Python ADBC、CLI、SQLAlchemy、Ibis 等客户端接入方式
  • 内置基于中间件的认证机制，支持 TLS/mTLS 与服务端签发的 JWT 令牌，并可设置查询超时

适用场景（解读层）

  • 通过 Docker、Homebrew、Windows MSI 或 iOS 应用部署 DuckDB/SQLite 数据库服务端
  • 将本地 DuckDB/SQLite 数据库文件以 Flight SQL 协议方式暴露给 JDBC/ADBC 等客户端
  • 配合 Kubernetes Operator、MCP Server、Superset、dbt 等集成使用
