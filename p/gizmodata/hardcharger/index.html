🧭 简介解读层（AI·证据行可回查）

将 DuckDB 2.0 网络化的分析服务器，通过 HTTP 协议 Chargewire 传输 Arrow 数据

综述（解读层）

Hardcharger 是 GizmoData 开发的分析服务器，将 DuckDB 2.0 以独立服务形式运行（基于 DuckDB v2 C API）。客户端通过自研开放 HTTP 协议 Chargewire 连接，查询结果以 Apache Arrow 记录批次流式返回。支持 TLS/mTLS、RBAC、SSO 等，Apache 2.0 协议发布，面向需要在网络上访问 DuckDB 的开发者。

  • 提供 Chargewire 开放 HTTP 协议，查询与首行结果一次往返返回，大结果集以 Arrow IPC 流式输出并支持 LZ4/zstd 压缩与断点续传
  • 内置安全能力：Token 登录、TLS/mTLS、语句计划级 RBAC、行列策略、OIDC/JWKS SSO 与防篡改审计日志
  • 提供 Prometheus /metrics 端点、查询画像、KILL SESSION，支持命令行、环境变量与 YAML 三种配置方式，附原生桌面应用与编译进二进制的 Web UI

适用场景（解读层）

  • 需要远程访问 DuckDB 的应用服务端部署
  • 通过 Arrow 流式协议进行大批量数据查询与表批量导入
  • 需要 TLS、RBAC、SSO 与审计日志的受控数据库访问场景
