🧭 简介解读层（AI·证据行可回查）

通过 SQL 函数调用 FastTransfer 工具的 PostgreSQL 扩展，实现跨数据库数据传输。

综述（解读层）

pg_fasttransfer 是 PostgreSQL 扩展，提供 SQL 函数 xp_RunFastTransfer_secure 来执行需单独安装的 FastTransfer 工具，在数据库间传输数据。参数对齐 FastTransfer 0.18，密码经 pg_fasttransfer_encrypt 加密存储并自动解密；返回退出码、行数、耗时等结果表。README 记录了 Windows 与 Debian/Ubuntu 上 PostgreSQL 15-18 的验证环境。

  • 提供 xp_RunFastTransfer_secure 函数，支持多种并行切分方法（RangeId、Ntile、Ctid 等）及多目标连接类型（clickhousebulk、duckdb、pgcopy、orabulk 等）
  • 提供 pg_fasttransfer_encrypt 函数，使用 pgp_sym_encrypt 加密并以 base64 编码，密码参数自动解密
  • 函数返回包含 exit_code、total_rows、transfer_time_ms 等字段的结果表，debug 参数可返回完整日志

适用场景（解读层）

  • 在 SQL 中发起 PostgreSQL 与 SQL Server、Oracle、ClickHouse 等数据库间的数据传输
  • 需在 SQL 脚本中集中管理传输密码加密的场景
  • 按表分区（DBPartition）或时间分区（Timepartition）切分执行传输任务
