基于 Cloudflare Worker MCP 与 TiDB Cloud Zero 的 Grok Bot 项目状态隔离插件

综述（解读层）

这是一个个人 Grok Bot 插件，通过远程 Cloudflare Worker 提供无状态 Streamable HTTP MCP 服务，将项目状态存入 TiDB Cloud Zero 的一次性 MySQL 数据库。按 projectId 加载有限状态胶囊，减少跨聊天混合导致的 token 浪费。包含 /project /lead /research /code /drain 等斜杠技能，并依赖单独安装的 pstack 插件。限制：无法清除 Grok Bot 隐藏记忆、无法选择路由模型、无法隔离共享 VM，每项目仍需使用全新 Bot 或聊天。

  • 按 projectId 加载有限状态胶囊，避免不同项目的上下文混合
  • Worker 无状态，状态存于 TiDB Cloud Zero（最长保留 30 天，可下载 SQL/JSON 备份并恢复）
  • 提供 /project /lead /research /code /drain 五个斜杠技能，缺 pstack 时 research/code/review 阻塞

适用场景（解读层）

  • 为每个项目维护独立可隔离的状态上下文的个人 Grok Bot 使用者
  • 团队通过 Cursor 插件市场分发部署该 MCP 的场景
  • 需要限时临时数据库并定期备份/恢复项目状态的流程
