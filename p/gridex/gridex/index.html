🧭 简介解读层（AI·证据行可回查）

Swift 编写的原生跨平台数据库 IDE，支持七种数据库并内置 MCP 服务器与 AI 聊天。

综述（解读层）

Gridex 是用 Swift 实现的桌面数据库 IDE，运行于 macOS（AppKit）、Windows（WinUI 3）和 Linux（Qt 6），通过统一的 DatabaseAdapter 协议连接 PostgreSQL、MySQL、SQLite、Redis、MongoDB、SQL Server 和 ClickHouse。提供查询编辑器、数据网格、ER 图、备份导入、SSH 隧道与 mTLS，并内置 MCP 服务器（含权限分层与审计日志）和多模型 AI 聊天。凭据存于系统密钥链。注意：ClickHouse 驱动目前仅支持 macOS。

  • 支持 7 种数据库驱动，共享同一 DatabaseAdapter 协议（约 50 个方法），Linux/Windows 平台支持其中 6 种
  • 内置 MCP 服务器，提供 15 个工具、5 级权限分层、SQL 清洗器、行数估算与审批门控及活动审计日志
  • AI 聊天支持 Claude、GPT、Gemini 与 Ollama 本地模型，可读取 schema 并按所选连接生成 SQL；凭据保存在 macOS Keychain / Windows Credential Manager

适用场景（解读层）

  • 在单一桌面应用中管理多种数据库连接，执行查询、浏览数据、查看结构并生成 ER 图
  • 将数据库连接通过 MCP 暴露给 Claude Desktop、Cursor 等 MCP 客户端，进行带权限控制的 AI 辅助查询
  • 需要备份恢复（pg_dump、mysqldump、NDJSON 等）或从 TablePlus、Navicat、DataGrip、DBeaver 导入现有连接配置的场景
