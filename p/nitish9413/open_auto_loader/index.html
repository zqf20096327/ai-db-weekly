基于 Polars 与 SQLite 的增量文件摄取工具，写入 Delta Lake。

综述（解读层）

OpenAutoLoader 是一个 Python 编写的增量数据摄取引擎，用于将本地及云存储（S3、Azure Blob、GCS）中的文件写入 Delta Lake。流程包括 fsspec 扫描新文件、JSON schema 校验、Polars 流式写入，并通过 SQLite 检查点记录批次状态，写入成功后才更新。每行自动附加 _batch_id、_processed_at、_source_file 元数据列。要求 Python 3.12+，提供 MIT 许可。

  • 支持本地、S3、Azure Blob（ABFSS）与 GCS 四类存储的增量加载
  • 基于 SQLite 检查点实现 exactly-once 处理，仅写入成功后更新检查点
  • 自动推断并保存 JSON schema 契约，读取时校验文件头

适用场景（解读层）

  • 从云对象存储增量摄取新文件到 Delta Lake 表
  • 在无 Spark 的标准 Python 环境中运行文件摄取任务
  • 需要批次级审计信息（批次号、处理时间、来源文件）的 ETL 流程
📖 README 首段存档原文 · 程序抽取

OpenAutoLoader is a high-performance, incremental data ingestion engine. It bridges the gap between raw cloud storage and production-ready Delta Lakes using the lightning-fast Polars Rust engine.
