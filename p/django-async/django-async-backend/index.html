替换 Django 数据库层的 PostgreSQL 异步 ORM 后端

综述（解读层）

该项目为 Django 提供异步数据库后端，替换默认数据库层，使查询经 psycopg 3 在真实 asyncio 连接上执行，支持异步事务、异步游标和可选连接池，无需线程模拟。版本号与 Django 特性版本一一对应，仅支持 ASGI 部署，WSGI（含开发服务器）下连接池不被支持。部分 QuerySet 方法如 prefetch_related、aiterator 及 RawQuerySet 尚不支持。

  • 通过 psycopg 3 在真实 asyncio 连接上执行查询，提供异步事务与异步游标，可选连接池（需 pool extra）
  • 版本号与 Django 主/次版本对应绑定，ORM 层部分由 Django 源码生成
  • QuerySet 多数 a* 方法及 filter/annotate/select_related 等已支持，提供 AsyncModelMixin 与原生异步游标接口

适用场景（解读层）

  • ASGI 部署的 Django + PostgreSQL 项目，需避免 sync_to_async 线程池执行查询
  • 需要异步事务或异步游标的数据库操作
  • 使用 asyncio 并希望查询不经过线程模拟的 ORM 调用
