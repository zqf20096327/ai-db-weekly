Rust 实现的混合搜索数据库，融合 KV 存储、文档模型与全文检索

综述（解读层）

CameoDB 是一个 Rust 编写的数据库引擎，将 redb 键值存储、文档模型和 tantivy 全文搜索合并在单一二进制中，通过统一写入路径提交数据，并提供 MCP 接口供 Agent 查询。支持分布式无主节点部署、多语言分析器、字段投影和数组截断控制，可通过 Docker 单节点启动，默认 HTTP 端口 9480，支持 rustls TLS 配置。

  • 每个分片为原子单元，同时包含 KV 存储（redb）与倒排索引（tantivy），写入返回后即可按 ID 读取，提交后可全文搜索
  • 提供 MCP 接口、字段投影、ghost 字段（一份文本以多个分析器检索而不重复存储）与按语言命名的分析器（含 Snowball 词干化与克罗地亚词典还原器）
  • 去中心化拓扑：无主节点，使用一致性哈希与自定义 Kademlia DHT 行为进行节点发现与路由；数据加载支持 CSV/TSV/JSON/JSONL 及 Gzip/Zip 解压，可从本地磁盘或 HTTP(S) 流式读取

适用场景（解读层）

  • 为通过 MCP 协议查询数据的 AI Agent 提供带全文搜索的持久化存储
  • 需要在单一进程内同时获得键值读写与全文检索、避免多系统同步的场景
  • 需要多节点去中心化部署与 HTTPS 加密连接的检索型应用
