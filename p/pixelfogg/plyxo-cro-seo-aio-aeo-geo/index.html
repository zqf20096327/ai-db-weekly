🧭 简介解读层（AI·证据行可回查）

开源自托管网站审计工具，用 Gemini AI 执行 CRO、SEO、AEO/GEO 检查

综述（解读层）

Plyxo 是一个基于 Next.js、React 19、TypeScript、PostgreSQL 与 Drizzle ORM 构建的开源网站审计平台，采用 FSL-1.1-MIT 许可证，使用 Google Gemini AI。它对目标站点执行视觉 CRO 检查、技术 SEO 与 Core Web Vitals 读取、JSON-LD Schema 校验，以及针对 ChatGPT、Perplexity、Gemini、Claude 的引用可能性评分。扫描结果与修复建议存入本地 PostgreSQL，支持自托管且无使用数量限制；审计依赖配置 Gemini API 密钥。

  • 集成 Google PageSpeed Insights 读取 LCP、CLS、INP、TTFB 指标，并校验 robots.txt、sitemap、canonical URL 与重定向链
  • 生成带视觉标注框的截图定位页面摩擦点，并输出 React、Tailwind、HTML/CSS 修复代码片段
  • 实现 AgriciDaniel/claude-seo 的技能集，包含 Schema.org 校验、E-E-A-T 分析、实体密度解析与失效链接爬取（含 SSRF 防护）

适用场景（解读层）

  • 自托管扫描自有网站的技术 SEO、Core Web Vitals 与结构化数据问题
  • 评估页面内容被 ChatGPT、Perplexity、Gemini、Claude 引用的可能性（AEO/GEO）
  • 对比竞品域名生成差距矩阵并提取关键词机会
