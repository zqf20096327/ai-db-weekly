🧭 简介解读层（AI·证据行可回查）

面向 PostgreSQL 的 ETL/ELT 数据同步工具，支持 CDC 等多种流式复制模式

综述（解读层）

PeerDB 是一个将 PostgreSQL（及 MySQL、MongoDB、CockroachDB、BigQuery 等）数据流式复制到 ClickHouse、ClickHouse Cloud 或另一 PostgreSQL 实例的 ETL/ELT 工具，支持基于日志的 CDC、cursor 及 XMIN 流式模式（后两者已弃用，官方推荐 CDC）。它提供兼容 Postgres 的 SQL 接口、并行初始加载、TOAST 列同步及类型映射。需注意 Snowflake、BigQuery、Kafka 等多数目标连接器已标记弃用但仍可用。

  • 支持 CDC、cursor（时间戳/整数）和 XMIN 三种流式复制模式，其中 CDC 为推荐且持续维护的方式
  • 支持并行大表初始加载、TOAST 大列同步，以及包含 jsonb、数组、地理空间等 Postgres 数据类型的映射
  • 提供兼容 Postgres 的 SQL 接口，可配合 psql、pgAdmin、Flyway、Airflow 等现有 Postgres 生态工具使用

适用场景（解读层）

  • 需要将 Postgres 数据持续同步到 ClickHouse 或 ClickHouse Cloud 的团队
  • Postgres 到 Postgres 的数据复制场景
  • 需要基于 SQL 界面管理 ETL 流程，并复用现有 Postgres 客户端与调度工具的使用者
