🧭 简介解读层（AI·证据行可回查）

基于 Promise 的 IndexedDB 封装，提供模型化 ORM 与查询构建器。

综述（解读层）

该库将浏览器 IndexedDB 封装为基于 Promise 的 API。开发者可通过配置定义数据库结构、索引与版本，自动生成表对应的模型实例，并支持继承 Model 类编写自定义 ORM 类以实现作用域查询和自定义关系。查询构建器同时覆盖索引列与非索引列的过滤条件。需注意：索引查询一次仅允许一个，非索引查询为性能较重的操作，插入时自动写入 createdAt/updatedAt 时间戳。

  • 支持创建带索引和版本的数据库结构，并提供多表间关系定义
  • 提供 create/find/first/all 等系列 Promise API，插入时自动添加 createdAt/updatedAt 时间戳
  • 查询构建器支持索引查询、非索引条件组合、嵌套属性点表示法及 multiEntry 数组索引搜索

适用场景（解读层）

  • 需要在浏览器端以模型和 ORM 方式读写 IndexedDB 的 JavaScript 应用
  • 需要对索引列执行范围查询（gte/gt/lte/lt/between）或对非索引列组合过滤的场景
  • 需要通过扩展 Model 类实现自定义关系和作用域查询的项目
