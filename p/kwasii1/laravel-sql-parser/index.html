纯 PHP 编写的 Laravel SQL 解析与转译包，移植自 sqlglot

综述（解读层）

本包将 SQL 解析为语法树，并支持在 30 多种方言之间转译（如 MySQL 到 SQL Server、Postgres 到 SQLite），是 sqlglot v30.21.0 的 PHP 移植版，并通过了 sqlglot 的方言测试用例。提供解析、流式构建器、优化器、语法树序列化及 Artisan 命令；解析核心不依赖 Laravel。通过 composer 安装，支持缓存、memo 与自定义方言配置，无效 SQL 会抛出含行列信息的 ParseError。

  • 解析 SQL 为语法树，并在 30+ 方言间转译，Laravel 驱动名（mysql、pgsql、sqlite、sqlsrv 等）可直接作为方言名使用
  • 提供 toSqlFor()/bindingsFor()/toRawSqlFor() 查询构建器宏、fluent Builder、Optimizer 优化器与 dump()/load() 序列化
  • 纯 PHP 实现，解析核心可脱离 Laravel 使用；README 附带与 sqlglot（含编译版）在 16 组基准查询上的耗时数据

适用场景（解读层）

  • 在 Laravel 应用中生成面向特定数据库方言的 SQL（如同一查询输出 MySQL 与 SQL Server 两种版本）
  • 对 SQL 做语法树层面的处理：优化、简化、表名替换、解析查询读取的表
  • 跨方言迁移 SQL 文件或管道脚本（可通过 artisan sql:transpile 处理文件与标准输入）
