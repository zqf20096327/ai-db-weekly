从 NBA 官方统计接口抽取数据、生成星型模型分析仓库的 Python 工具

综述（解读层）

nbadb 是一个 Python 命令行工具，通过 nba_api 抽取 NBA 官方统计网站数据，构建以 DuckDB 为引擎的星型模型数据库，覆盖 1946-47 赛季至今的比赛、球员、球队和联盟层面数据。安装方式为 pip install nbadb，提供全量构建、每日增量、格式导出（SQLite/Parquet/CSV）、目录路由式问答及 Kaggle 上传验证等子命令。

  • 提供 dim_/fact_/bridge_/agg_/analytics_ 五类表构成的星型模型仓库，覆盖 1946-47 赛季至今
  • 支持导出 DuckDB、SQLite、按赛季分区的 Zstd 压缩 Parquet 及 CSV 四种格式
  • 提供 nbadb ask 自然语言问答与 Chainlit 聊天界面，基于预定义目录路由执行只读查询

适用场景（解读层）

  • 构建本地 NBA 历史与实时数据的分析数据库，用于 Notebook、仪表盘和探索性分析
  • 发布和维护 Kaggle 上的篮球数据集，含完整性审计与远程校验
  • 通过目录匹配的自然语言问答查询赛季统计信息
