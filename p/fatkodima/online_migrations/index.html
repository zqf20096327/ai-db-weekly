检测 Rails PostgreSQL 不安全迁移并提供安全改写辅助的 Ruby gem

综述（解读层）

OnlineMigrations 是面向 Rails + PostgreSQL 项目的迁移辅助 gem，在开发环境检测可能阻塞读写或引发应用错误的迁移操作并默认阻止执行，同时给出说明与代码辅助工具。它包含表/列重命名、列类型变更、带默认值加列、数据回填等 helper，以及后台数据/架构迁移功能。要求 Ruby 3.3+、Rails 7.2+、PostgreSQL 12+；README 提示小项目可能不需要它。

  • 检测并默认阻止潜在危险迁移操作，支持自定义检查或禁用特定检查
  • 提供 add_column_with_default、update_column_in_batches、initialize_column_type_change 等迁移 helper
  • 支持后台数据迁移与后台架构迁移，通过生成器安装，部分 helper 基于 database VIEW 实现

适用场景（解读层）

  • 对大规模表执行加列、回填、改列类型、重命名列等迁移时按安全步骤操作
  • 在开发阶段识别会长时间锁表或导致应用出错的迁移语句
  • 需要在不停机情况下分批更新大表数据
