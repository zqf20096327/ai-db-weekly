🧭 简介解读层（AI·证据行可回查）

依据官方选型方法估算 TiDB Cloud Dedicated PoC 集群规模的 Agent Skill

综述（解读层）

这是一个纯 Markdown 的 Agent Skill，按 PingCAP 官方集群选型文档流程，根据源库类型、数据量、QPS、读写比例、延迟 SLA 等输入，生成包含推荐配置、计算公式、假设、风险与验证说明的五段报告。输入缺失时采用文档化默认值并在报告中列出假设。无脚本，适用于支持 Agent Skills 格式的任意 Agent；内置参数为官方文档 2026-07 快照，需随官方更新维护。

  • 纯 Markdown 实现，仅含 name/description 头字段，兼容 Claude Code 及支持开放 Agent Skills 格式的 Agent
  • 输入缺失不阻塞，按文档化最小要求默认值处理并在报告中列出全部假设，无工作负载数据时回退到最小 HA 基线（2× TiDB 8C16G + 3× TiKV 8C32G / 500 GiB）
  • 内置规则包括：默认延迟档位 P95≈100ms、TiKV 取容量/性能路径与 3 的最大值并取 3 的倍数、节点数小数部分 ≤0.1 时向下取整、最低节点数不可违反

适用场景（解读层）

  • 为客户 PoC 快速生成 TiDB Cloud Dedicated 初始集群配置估算报告
  • 售前/解决方案场景下基于源库信息（如 Cloud SQL for MySQL 的数据量与 QPS）进行选型推演
  • 以任意语言输出报告，并标注精度风险与 PoC 验证要点供后续校准
