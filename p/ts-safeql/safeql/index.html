🧭 简介解读层（AI·证据行可回查）

通过 ESLint 插件对 PostgreSQL 原生 SQL 查询校验并自动生成 TypeScript 类型。

综述（解读层）

SafeQL 是一个 ESLint 插件（@ts-safeql/eslint-plugin），用于根据 SQL 查询语句本身推断查询结果的 TypeScript 类型并校验查询。它面向使用 PostgreSQL 的 JavaScript/TypeScript 项目，兼容 Prisma、Sequelize、pg、Postgres.js 等客户端。安装需先按 typescript-eslint 文档配置 ESLint，并依赖 libpg-query 包。

  • 基于查询语句自动推断查询结果的 TypeScript 类型
  • 兼容 Prisma、Sequelize、pg、Postgres.js 等 PostgreSQL 客户端
  • 支持 monorepo 与微服务中的多数据库场景

适用场景（解读层）

  • 在 TypeScript 项目中对原生 SQL 查询进行类型校验
  • 使用多种 PostgreSQL 客户端库的代码库统一接入查询检查
  • monorepo 或微服务架构下连接多个数据库的项目
