🧭 简介解读层（AI·证据行可回查）

通过读取 MySQL binlog 生成 Parquet 列式副本并用 DuckDB 查询的 HTAP 工具

综述（解读层）

DBTrail 以复制协议读取 MySQL/MariaDB/RDS/Aurora 的 binlog，在本地磁盘或 S3 维护 Parquet 副本，并通过兼容 MySQL 协议的端口接受现有客户端查询，重查询由 DuckDB 从副本应答。支持基于 binlog 的 AS OF 时间旅行与行级 undo SQL 生成。要求 ROW 格式 binlog、完整行镜像和主键，副本有延迟且不提供高可用。

  • 以复制协议读取 binlog，无需在 MySQL 上安装插件、代理或触发器
  • 通过 MySQL 协议端口路由：写入和按键查找发往 MySQL，重读取由 Parquet/DuckDB 副本应答
  • 提供 AS OF 时间旅行查询和生成撤销 SQL 的行级 undo，可通过 MCP 客户端查询

适用场景（解读层）

  • 为现有 MySQL 应用分担全表聚合、排名、多年趋势等重分析查询，应用 SQL 无需改动
  • 接入 Metabase、Grafana 等支持 MySQL 协议的仪表盘工具
  • 查询表的历史时点状态或生成误操作撤销 SQL
