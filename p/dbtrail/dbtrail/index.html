🧭 简介解读层（AI·证据行可回查）

读取 MySQL binlog 维护 Parquet 副本，用 DuckDB 提供 HTAP 查询与行级历史。

综述（解读层）

DBTrail 通过复制协议读取 MySQL/MariaDB 的 binlog，在本地磁盘或 S3 中维护 Parquet 列式副本，并以兼容 MySQL 协议的端口配合 DuckDB 响应重型查询，提供 AS OF 时间 travel 与生成撤销 SQL 的行级 undo。适合需要在原库旁搭分析副本的 DBA；要求 ROW binlog、full row image 及每表主键，副本存在秒到分钟延迟。

  • 通过复制协议读取 binlog，无需在 MySQL 上安装插件、agent 或触发器，数据存储为 Parquet 文件，查询由 DuckDB 执行
  • 提供路由模式：同一连接上写事务和按键查找发往 MySQL，重型读由副本回答，兼容 Metabase、Grafana 等 MySQL 协议工具
  • 支持 AS OF 时间点查询、行级 undo SQL 生成，并通过 MCP 协议接入 Claude 等客户端，工具仅读且不在 MySQL 上执行 SQL

适用场景（解读层）

  • 在不改动应用 SQL 的前提下，将报表、仪表盘等重型分析查询从主库分流到列式副本
  • 按时间点查看表或行的历史版本，并为误操作生成待人工审核的撤销 SQL
  • 面向 RDS/Aurora 等托管数据库搭建分析副本，无需访问 binlog 文件所在磁盘
