MATLAB 与 SQLite 之间的 MEX 接口，通过 mksqlite 命令执行 SQL 操作

综述（解读层）

mksqlite 是一个将 MATLAB 与 SQLite 数据库连接的开源 MEX-DLL，用户在 MATLAB 命令行执行 mksqlite('SELECT ...') 即可返回结构体数组形式的查询结果。它在 SQLite 之上实现，支持 BLOB 数据类型处理、将数值数组和 struct/cell 等复杂数据结构以（压缩）BLOB 形式存储，并可通过 MATLAB 函数回调定义自定义 SQLite 函数。适用于需要在 MATLAB 环境中读取或写入 SQLite 数据库文件的用户，已在 Windows、Linux 和 macOS 上的多个 MATLAB 版本中测试。

  • 提供 mksqlite 命令接口，执行 SQL 查询并返回结构体数组结果
  • 支持 BLOB 数据类型（uint8 数组），可将数值数组及 struct/cell 等复杂结构以压缩 BLOB 形式存储
  • 支持批量插入、命名参数绑定，以及用 MATLAB 函数回调定义自定义 SQLite 函数

适用场景（解读层）

  • 在 MATLAB 中查询和写入 SQLite 数据库文件（不存在时自动创建）
  • 将 MATLAB 数值数组、struct、cell 等数据结构持久化到 SQLite 的 BLOB 字段
  • 在 MATLAB 中通过函数回调扩展 SQLite 自定义函数
