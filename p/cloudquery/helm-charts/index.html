将 CloudQuery 部署到 Kubernetes 集群的 Helm v3 chart

综述（解读层）

CloudQuery 是面向安全与基础设施团队的开源数据集成平台，从云 API 抽取、转换并加载配置数据至数据库、数据湖或流式平台。本仓库提供 Helm v3 chart，用于将该平台部署到 Kubernetes 集群，文档位于 charts/cloudquery 目录。安装需具备 Helm v3 及 Kubernetes 集群环境。

  • 提供 Helm v3 chart，用于将 CloudQuery 部署到 Kubernetes 集群
  • 支持从云 API 抽取、转换、加载配置数据到数据库、数据湖或流式平台等目标
  • chart 已收录于 Artifact Hub

适用场景（解读层）

  • 在 Kubernetes 集群中以 Helm 方式部署 CloudQuery
  • 将云基础设施配置数据汇总到 PostgreSQL 等数据库以供后续分析
  • 面向安全与基础设施团队的云 API 数据集成场景
