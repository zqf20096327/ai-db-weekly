PostgreSQL 按表复制的 C 语言扩展

综述（解读层）

Mimeo 是一个 PostgreSQL 扩展，用于在 PostgreSQL 实例之间实现按表级别的复制。它提供三种复制方式：snapshot（整表复制）、incremental（基于递增时间戳或 id）以及 DML（插入、更新和删除）。该扩展需要 PostgreSQL 9.1 及以上版本并依赖 dblink 扩展，同时推荐安装 pg_jobmon 扩展用于记录复制活动并提供监控。使用者通过源码编译安装，并需在固定的 schema 中创建扩展。该扩展采用 PostgreSQL License 开源协议。

  • 提供 snapshot、incremental、DML 三种表级复制模式
  • 依赖 dblink 扩展实现跨实例复制
  • 支持通过 ALTER EXTENSION 进行版本升级

适用场景（解读层）

  • PostgreSQL 实例间的单表数据同步
  • 基于时间戳或 id 增量更新数据的场景
  • 需要记录和监控复制活动的环境（配合 pg_jobmon）
