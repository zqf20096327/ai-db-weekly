基于 Docker Compose 的三节点 ScyllaDB 本地测试集群

综述（解读层）

该项目通过 Docker Compose 部署包含三个节点的 ScyllaDB 集群，供本地测试使用。README 要求先配置内核参数 fs.aio-max-nr（提供 make setup 命令自动设置为 1048576），随后 docker compose up 启动。集群内节点经 ws-scylla 网络以 9042 端口互访，对外则映射为 localhost 的 9040–9042 端口，适用于需要在本地运行多节点 ScyllaDB 的开发者。

  • 提供三节点 ScyllaDB 集群的 Docker Compose 配置，附带 make setup 命令自动配置 fs.aio-max-nr 内核参数
  • 节点通过 ws-scylla Docker 网络在 9042 端口内部互访，对外映射至 localhost 的 9040、9041、9042 端口
  • 支持通过 cqlsh 与 nodetool 管理集群，并提供 Cassandra JS Driver 与 JDBC 连接示例

适用场景（解读层）

  • 在本地环境搭建多节点 ScyllaDB 集群进行测试
  • 通过 Docker 网络将应用服务接入集群内部节点
  • 使用 CQLSH、Nodetool 或外部驱动（含 DataGrip JDBC）连接和查询数据库
