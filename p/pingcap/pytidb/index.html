TiDB 的 Python AI SDK，统一向量、全文与混合检索的数据平台。

综述（解读层）

pytidb 是面向 TiDB / TiDB Cloud 的 Python SDK，面向构建 AI 应用与 Agent 的开发者。它在常规数据存取之上提供自动嵌入：写入文本字段时自动生成向量并存入向量字段，查询时自动嵌入查询语句。支持向量、全文、混合及图像检索，含 $eq/$gt/$in 等过滤算子、可选重排序、结构化与非结构化数据的 join，以及 commit/rollback 事务。README 提示该包处于快速开发期，API 可能变动，建议固定版本安装，如 pytidb==0.0.14。

  • 支持向量检索、全文检索、混合检索及文本搜图、图搜图四种检索方式
  • 通过 EmbeddingFunction 在写入与查询时自动生成文本/图像嵌入向量
  • 提供 $eq/$gt/$in/$and 等过滤算子、可选 reranker、事务管理与 MCP 支持

适用场景（解读层）

  • 构建需要语义检索或 RAG 流程的 AI 应用与 Agent
  • 在同一数据库中对结构化与非结构化数据执行 join 查询
  • 需要事务保证一致性的多模态数据存储与检索场景
