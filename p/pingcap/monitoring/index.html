PingCAP 的 TiDB 监控配置生成与 Prometheus 规则热加载工具集

综述（解读层）

该仓库包含三部分功能：为 tidb-operator 和 tidb-ansible 部署自动生成版本化监控配置、监控目录结构的加载工具，以及一个监听规则目录并在变更时调用 Prometheus reload API 的重载器，附带类 Prometheus 风格的规则编辑 UI。配置生成基于 git tag 识别 TiDB 版本，默认为 2.1.8 及以上版本生成监控数据；构建依赖 dependencies.yaml 与校验和文件保持一致。适用于维护 TiDB 集群监控配置的运维与 CI 场景。

  • 从组件仓库拉取监控配置并按目录结构自动生成面向 ansible 部署与 operator 部署的版本化监控数据
  • 提供 Prometheus Rule Reloader 二进制，监听规则目录变更并调用 reload API，附带 YAML 编辑 UI
  • 构建过程校验 Grafana 与 Prometheus 发布归档的 sha256 哈希，不匹配时中止构建

适用场景（解读层）

  • 为不同 TiDB 版本（默认 >=2.1.8）的 operator 或 ansible 部署生成对应监控配置
  • 在 Prometheus 规则文件更新后自动触发 reload，无需手动重启
  • 通过修改 dashboards.go 映射和 init.sh 向 monitoring-initializer 镜像添加新 Grafana 看板
