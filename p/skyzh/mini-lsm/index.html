🧭 简介解读层（AI·证据行可回查）

用 Rust 从零构建 LSM-tree 存储引擎的三周实战课程

综述（解读层）

Mini-LSM 是一门面向系统与后端工程师的存储引擎动手课程，学员在 mini-lsm-starter 代码上逐步实现 memtable、SST、压缩、WAL 恢复、MVCC 与事务。课程分三周共 21 章，仅覆盖存储层，不含 SQL 解析与分布式内容；需具备基础 Rust，可用 CLI 与压缩模拟器验证实现。

  • 三周课程结构：第一周完成可运行的存储引擎，第二、三周加入压缩策略、崩溃恢复、MVCC 与可串行化事务
  • 提供多种压缩策略实现（tiered、leveled）与压缩模拟器用于实验
  • 配套 mini-lsm-cli 参考实现与按章节提交的 solution checkpoint 仓库

适用场景（解读层）

  • 希望理解 PostgreSQL、RocksDB 等系统存储层内部机制的后端工程师
  • 学习 LSM-tree、WAL、MVCC 等概念的 Rust 实践者
  • 需要带测试与参考答案的教学场景或自学路径
