基于 PostgreSQL 的多语言后端基础设施库，统一提供八类原语

综述（解读层）

Forge 是面向 Rust、Node.js/Bun、Python 与 Go 的后端基础设施库，通过 forge.toml 配置将队列、键值存储、blob、认证辅助、限流、调度、配置与 pub/sub 等原语纳入后端进程内，以 PostgreSQL 18 作为共享持久后端（可内嵌运行），并提供进程内内存后端用于测试。认证不覆盖 OAuth、MFA 等场景，也不含工作流引擎与 ORM。MIT 许可证发布。

  • 提供键值、队列、pub/sub、blob、认证、限流、调度、配置八类原语，在 Rust、Node/Bun、Python、Go 四种语言间共享同一版本化契约
  • 支持 PostgreSQL 18 生产后端、进程内非持久内存测试后端与本地磁盘/S3 兼容 blob 存储；内存配置文件带手动时钟与固定熵种子，用于测试 TTL 与重试
  • 生产启动默认仅校验 schema，迁移通过 ForgeClient.migrate() 在部署任务中执行，contract/schema-ownership.json 列出库拥有的对象清单

适用场景（解读层）

  • 将多个独立后端服务（缓存、任务队列、对象存储、会话等）合并为单进程加单 PostgreSQL 数据库的部署形态
  • 测试环境使用内存后端配合手动时钟驱动 TTL、延迟任务与限流补充，无需真实数据库
  • 多语言团队在 Rust、Node、Python、Go 服务间复用同一套后端原语 API 与迁移契约
