基于 Termux 的 Android 本地 Web 服务器栈，集成 Nginx、PHP-FPM、MariaDB 与 Redis。

综述（解读层）

MyServer 是一个运行在 Android Termux 上的 PHP Web 服务器管理工具，通过单个 Python 脚本安装并管理 Nginx、PHP-FPM、MariaDB、Redis、phpMyAdmin 等组件。它针对 Android 后台进程限制做了适配，例如 PHP-FPM 使用 ondemand 模式和 Redis 可关闭以节省进程槽位。适用于需要在手机上运行本地 PHP 网站的开发者。

  • 提供交互式 TUI 菜单与 CLI 命令，管理 Nginx、PHP-FPM、MariaDB、Redis 的启动、停止与状态查看
  • 支持虚拟主机多站点管理、数据库 CLI（创建/导入/导出）、全栈备份恢复及 Cloudflare Tunnel 公网访问
  • 包含 doctor 自诊断命令，可检查软件包、PHP 扩展、端口、SSL 有效性及 Android 12+ Phantom Process 预算

适用场景（解读层）

  • 在 Android 设备上搭建本地 PHP 开发环境（WordPress、Laravel、Nextcloud 等）
  • 通过虚拟主机在同一手机上运行多个隔离的 PHP 项目
  • 需要通过 Cloudflare Tunnel 将本地站点临时分享为公网可访问地址
