Rust + egui 编写的跨平台单文件数据库管理桌面客户端

综述（解读层）

navicat-rs 是一个用 Rust + egui/eframe 实现的本地优先数据库管理桌面客户端，界面与工作流参考 Navicat Premium 18，无登录、无订阅限制。目前 SQLite 为完整后端，PostgreSQL 走真实网络协议，MySQL、Oracle 等其余引擎仅为连接配置加离线演示数据，需按 src/realdb.rs 模式自行接入。适合需要本地 SQLite/PostgreSQL 图形化管理、希望离线单文件运行的用户。

  • 提供数据表分页浏览、内联编辑、SQL 多语句执行、Explain 执行计划树、ER 图、表结构设计器、模型设计器与数据传输/同步/导入导出等工具
  • 单文件可执行程序，基于 egui/eframe 无需 WebView，支持 Windows/macOS/Linux 三平台，内置 6 套主题
  • 通过 --selftest 提供无头功能自检（22 项），支持 GHCR 容器镜像运行，配置保存在各平台标准配置目录

适用场景（解读层）

  • 本地 SQLite 数据库的图形化管理、查询与表结构设计
  • 通过真实网络协议连接并查询 PostgreSQL 数据库
  • 需要离线、无账号依赖的数据导入导出、备份还原与 ER 建模工作流
