用 Jupyter Notebook 对空气污染 CSV 数据做清洗并加载到 PostgreSQL 的 ETL 项目

综述（解读层）

该项目对 2017–2020 年 8 个城市的空气污染数据（两个 CSV 文件）执行 ETL 流程：用 pandas 读取文件，删除多余列并按 Date、Country、City 左连接合并 o3 与 pm25 计数，再通过 to_sql 写入 PostgreSQL 数据库 etl_projct2 的 merge_counts 表。使用 PostgreSQL、PGAdmin 与 Jupyter Notebook。

  • 使用 pd.read_csv 读取 Resources 文件夹中的两个 CSV 文件
  • 将两个 DataFrame 按 Date、Country、City 列做左连接合并，得到每日各城市的 o3 与 pm25 计数
  • 通过 new_df.to_sql 将数据写入 PostgreSQL 数据库，并用 pd.read_sql_query 验证加载结果

适用场景（解读层）

  • 学习以 Python 和 pandas 实现提取、转换、加载的完整流程
  • 将 CSV 格式的数据集清洗合并后存入 PostgreSQL 数据库
  • 参考在 PGAdmin 中建库建表并验证数据写入的流程
