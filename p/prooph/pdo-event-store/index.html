Prooph EventStore 的 PDO 实现，基于 MySQL/Postgres 存储事件流

综述（解读层）

该项目为 Prooph EventStore v7 提供 PDO 数据库实现，面向 PHP 中使用事件溯源的 CQRS/DDD 开发者。要求 PHP >= 7.3 及 PDO_MySQL 或 PDO_PGSQL 扩展，分别支持 MariaDB（>=10.2.11）、MySQL（>=5.7.9）与 Postgres（>=9.4）。部署需在服务器上执行 SQL 脚本创建事件流表；如需投影功能，另需执行 projections 表脚本。1.6 到 1.7 的升级采用优化后的表结构，README 称可用后台脚本完成、无需数据库停机。Postgres 下 event_id 须为合法 UUID，自定义 MetadataMatcher 传入非法值会抛出异常。项目以 New BSD 许可证发布。

  • 提供针对 MariaDB、MySQL（>=5.7.9）、Postgres（>=9.4）三种数据库的安装 SQL 脚本，用于创建事件流表和投影表
  • 支持通过 Composer 运行 phpunit 单元测试，并提供基于 Docker Compose 的三种数据库测试流程
  • 1.6 至 1.7 升级提供 ALTER TABLE 迁移语句，README 说明该迁移向后兼容、非强制执行

适用场景（解读层）

  • 在 PHP 项目中使用 Prooph EventStore 进行事件溯源，需要将事件持久化到 MySQL、MariaDB 或 Postgres
  • 基于 CQRS/DDD 架构的应用需要数据库承载的事件流和投影存储
  • 需要本地或通过 Docker Compose 运行针对三种数据库的单元测试
