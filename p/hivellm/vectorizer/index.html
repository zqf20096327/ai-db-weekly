Rust 编写的内存向量数据库，支持 HNSW 索引与多协议检索

综述（解读层）

Vectorizer 是用 Rust 编写的向量数据库，Cargo workspace 形式包含 5 个 crate，面向语义搜索与 AI 应用中的 top-k 近邻查询。数据通过 .vecdb 二进制格式持久化，支持内存映射存储与标量/乘积量化。访问方式包括 TCP 上的 MessagePack RPC（默认端口 15503）、REST（15002）、gRPC、GraphQL 及 MCP 工具，并提供 Rust/Python/TypeScript/Go/C# SDK 和 React 控制台。

  • 提供 HNSW 索引的向量检索，支持余弦、欧氏、点积相似度及 Dense+Sparse 混合搜索（RRF 融合）
  • 通过 openraft 实现 Raft 共识的主从复制、分布式分片与 Kubernetes 部署清单
  • 内置 TF-IDF、BM25、FastEmbed、BERT、MiniLM 等嵌入提供者，并支持 JWT/API Key 认证与 RBAC

适用场景（解读层）

  • AI 应用中的语义搜索与文档索引（支持 PDF、DOCX 等 14 种文档格式转换）
  • 需要高可用部署的向量检索服务（Kubernetes 3 节点 Raft 集群，写重定向至 leader）
  • 多租户场景下的向量服务托管（HiveHub 集群模式，含配额与租户隔离）
