Rails ActiveRecord 的 SQL Server 数据库适配器

综述（解读层）

该适配器让 Ruby on Rails 应用通过 ActiveRecord 连接 SQL Server 2012 及以上版本数据库，依赖 TinyTDS，底层使用 FreeTDS 协议。版本号与 Rails 版本一一对应，如 8.x 只用于 Rails 8.x。提供存储过程调用、SHOWPLAN 执行计划、计算列、insert_all/upsert_all（经 MERGE 实现）等能力；含触发器的表插入需额外配置。

  • 支持 FreeTDS 支持的全部数据类型，迁移中的 Rails 简化类型对应 SQL Server Unicode 数据类型
  • 每个 ActiveRecord::Base 子类获得 execute_procedure 类方法，可按连接规范自动加引号调用存储过程
  • insert_all/upsert_all 通过 MERGE 语句实现，并在查询中自动去重以避免 JOIN 失败

适用场景（解读层）

  • 需要将 Rails 应用连接到 SQL Server 数据库的项目
  • 迁移中需使用 SQL Server 计算列、schema 前缀或 datetime2 类型等特性的应用
  • 需在 Rails 中调用存储过程或查看 SHOWPLAN 执行计划（默认 SHOWPLAN_ALL，可切换 SHOWPLAN_XML）的场景
