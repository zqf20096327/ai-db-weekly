🧭 简介解读层（AI·证据行可回查）

通过XML清单生成DTO/DAO数据访问层代码的IDE插件

综述（解读层）

SQL DAL Maker 用于为 PHP、Java、C++、Python 和 Go 项目生成数据访问层代码，包括 DTO、Model 和 DAO 类。用户编写 XML 清单描述要生成的类与 SQL，生成器读取 JDBC 数据库元数据完成解析并输出源码。以 Java 实现，提供 Eclipse 和 IntelliJ 平台插件，另有命令行工具 sdmc 可在 CI 中使用。生成时需要数据库可连接。

  • 通过 XML 清单描述 DTO、Model、DAO 及 SQL，翻译为不含 PDO/JDBC/QtSql 直接调用的源码，底层访问封装在用户持有的 DataStore 接口之后
  • 支持逆向工程生成清单初稿，并在翻译时读取 JDBC 活动元数据（表、视图、自定义 SQL 结果集）解析清单未明确的内容
  • 提供 Eclipse 3.8+ 和 IntelliJ 平台（PhpStorm、IntelliJ IDEA、Android Studio、CLion、PyCharm、GoLand）插件，以及支持 Go/Python/C++(Qt) 的命令行工具 sdmc

适用场景（解读层）

  • 在 PHP、Java、C++、Python 或 Go 项目中生成基于数据库表的 DTO 与 DAO 代码
  • 数据库模式变更后重新运行生成器，保持清单可重复再生成
  • 在 CI 流程中通过 sdmc 命令行工具生成代码，无需 IDE
