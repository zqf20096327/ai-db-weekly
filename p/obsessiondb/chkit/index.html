chkit：用 TypeScript 定义 ClickHouse 模式并生成 SQL 迁移的 CLI

综述（解读层）

chkit 是一个面向 TypeScript 项目的 ClickHouse 模式与迁移 CLI，工作流为定义、生成、审查、迁移、检查。开发者用 @chkit/core 的 DSL 在代码中定义表、视图、物化视图和字典，CLI 生成可审查的 SQL 迁移文件，并通过 status/check/drift 命令对比线上模式差异。支持 Node.js 22+ 或 Bun 运行，采用 MIT 许可。配置通过 CLICKHOUSE_URL 等环境变量提供；对于已存在数据的库需走 adoption 流程，排序/分区键变更可生成零停机 cutover 迁移。

  • 提供 schema DSL，在 TypeScript 中定义表、视图、物化视图和字典，并生成可审查的 SQL 迁移
  • check --strict 对未应用迁移、校验和变更或线上漂移以非零退出码作为 CI 门禁
  • 插件体系包含 live schema 导入、Tinybird 项目导入、TypeScript 类型与 Zod schema 生成及 backfill（beta）

适用场景（解读层）

  • 在 CI/CD 中以 check --strict 作为门禁，阻断待迁移、校验和不一致或线上漂移
  • 通过 generate --cutover 对排序/分区键变更生成零停机切换迁移
  • 用 plugin-pull 采用既有线上表，或用 plugin-codegen 生成 TypeScript 行类型与 Zod schema
