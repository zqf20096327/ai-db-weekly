基于 Ansible 编排的 MySQL InnoDB Cluster 自动化部署与运维工具集

综述（解读层）

该项目用 Ansible 统一编排 MySQL Server、InnoDB Cluster（组复制）、MySQL Router、HAProxy 与 Keepalived，覆盖安装、组网、配置变更、扩缩容、状态检查和可选备份，面向 DBA、SRE 与平台工程团队。通过 inventory 与 Vault 管理环境与凭据，默认拓扑为 3 数据库 + 2 Router + 2 入口主机；备份功能默认关闭，且不含数据库版本升级与恢复执行入口。

  • 支持 MySQL 8.4 / 8.0 版本线安装、集群创建与成员逐台加入，提供 RW（3307）、RO（3308）、自动读写分离（3309）三类 VIP 入口
  • 实现节点扩缩容、按硬件档位的滚动配置应用、Router 与 LB 的部署缩减，并提供成员、端口、VIP 归属的状态检查
  • 提供 MySQL Shell 逻辑备份与 Percona XtraBackup 物理备份选项，支持 local/NFS/rsync 目标，以及基于 Lima VM 的本地模拟环境

适用场景（解读层）

  • 从空白 Linux 主机为业务建立分层 MySQL 高可用集群
  • 对已部署集群执行日常运维：状态检查、参数调整、节点增减与备份
  • 在本地模拟环境中学习或演练 InnoDB Cluster 的部署与运维流程
