本地实时电商数据管道：Python 生成订单事件，经 Kafka、PySpark 流处理写入 PostgreSQL。

综述（解读层）

StreamFlow 是一个在本地运行的电商订单事件流处理项目：Python 脚本生成合成 JSON 订单并发送到 Kafka 的 orders 主题，PySpark Structured Streaming 按预定义 schema 解析、校验并转换事件，通过 JDBC 写入 PostgreSQL 的 processed_orders 与 invalid_orders（DLQ）两张表，并提供 SQL 视图供 Power BI 查询。Kafka 与 PostgreSQL 由 Docker Compose 启动；Airflow 仅包含独立的批处理演示，不参与流式管道。项目定位为教学/作品集用途，需在虚拟环境中依次运行 Spark 与生产者脚本。

  • 实现 DLQ 模式：按 order_id 非空、timestamp 非空、quantity>0、unit_price>0 规则分流，无效事件写入 invalid_orders 供审计
  • 使用 foreachBatch 微批处理与 checkpoint 目录保存消费进度，支持重启恢复；processed_orders 为 append-only 表以避免主键冲突
  • Kafka 采用 KRaft 模式容器化部署（1 分区、副本因子 1），生产者与 Spark 处理器解耦，通过 powerbi_order_analytics 视图暴露分析数据

适用场景（解读层）

  • 学习 Kafka→Spark Structured Streaming→PostgreSQL 端到端流处理架构的本地演示环境
  • 演示数据质量校验与死信队列（DLQ）分流模式的实现
  • 连接 Power BI 等下游 BI 工具，基于 SQL 视图构建订单分析仪表板
