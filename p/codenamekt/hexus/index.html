基于 Postgres+pgvector 的智能体向量记忆存储，兼作 Hermes 插件与独立 MCP 服务器

综述（解读层）

Hexus 使用 Postgres 与 pgvector 实现智能体记忆存储，嵌入检索由本地 BERT 模型完成，不调用云端 LLM。它提供两种集成方式：作为 Hermes agent 的记忆插件（pip 安装后配置两个 YAML 块），或作为独立 MCP 服务器供 Claude Desktop、Cursor 等客户端使用，支持 Docker 部署。依赖一个启用 pgvector 的 Postgres 实例，schema 需通过迁移预先创建。

  • 支持 Hermes 插件与独立 MCP 服务器（stdio/HTTP 传输）两种集成路径，共享同一存储
  • 内置混合搜索（BM25+向量）、时间衰减、TTL 遗忘、实体标注与对话摘要功能
  • 通过 themes 和 agent identity 实现多智能体内存隔离，提供 shared/strict 两种读取隔离模式，并支持签名 Webhook 通知内存写入

适用场景（解读层）

  • 为 Hermes 多智能体团队提供集中式、按主题隔离的记忆后端
  • 为 Claude Desktop、Cursor 等 MCP 客户端接入本地 Postgres 向量记忆
  • 在纯 CPU 本地环境中运行智能体记忆服务，数据不出本地
