综述（解读层）

MemForge 是用 TypeScript 编写、基于 PostgreSQL（pgvector/pg_trgm）的智能体记忆系统，面向需要持久化记忆的 AI 智能体开发者。它采用热/温/冷三层存储，后台睡眠周期分十个阶段执行打分、冲突消解、LLM 修订和反思等操作；提供 HTTP API、MCP 服务器（30 个工具）及 TypeScript/Python SDK。当前状态为 Beta，此前发布的 LongMemEval 基准数据已撤回，重测正在进行。

  • 三层记忆（热→温→冷）配合混合检索：PostgreSQL 全文检索、pgvector HNSW 语义搜索与倒数排名融合，支持本地进程内嵌入生成
  • 睡眠周期后台处理器包含打分、冲突消解、记忆修订、知识图谱维护、反思与元反思等 10 个阶段，在空闲期间重写低置信度记忆
  • 提供 HTTP API、MCP 服务器（30 个工具）、TypeScript 与 Python SDK、Docker 单容器镜像（内嵌 PostgreSQL），操作按 agent ID 实现多租户隔离

适用场景（解读层）

  • 为长期运行的 AI 智能体提供跨会话记忆存储、检索与预热上下文恢复
  • 通过 MCP 将记忆工具接入 Claude Code、Cursor 等兼容工具链
  • 需要记忆整合、知识图谱与反思能力的持续学习场景（注：项目标注 Beta，且基准数据处于重测阶段）
