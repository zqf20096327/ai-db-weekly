🧭 简介解读层（AI·证据行可回查）

测量 Telegram Serverless 平台资源限制的探测工具与结果集

综述（解读层）

该项目通过可复现的 JavaScript 探针测量 Telegram Serverless 的资源边界，涵盖 JS 堆约 128 MiB、CPU 时间约 3 秒、SQLite 存储约 496 MiB、并发约 8 路 CPU 调用等指标，数据于 2026 年 10 月 9 日用 @tgcloud/cli 0.2.0 在单个机器人上测得。它面向需要了解平台配额的 bot 开发者；诊断脚本需 Node.js 18+ 且 bot 已启用 Serverless，结果为单机观察而非官方配额。

  • 提供 JS 堆、ArrayBuffer、CPU 时间、SQLite 存储与并发五类资源的探测脚本及结果数据
  • 诊断命令在 Telegram 端运行，仅分配 4 MiB 并做只读 SQLite 查询，不部署模块或修改 webhook
  • 结果写入被 Git 忽略的 reports/*.json 与 *.jsonl，已发布快照保持不变，可用 npm test 做本地检查

适用场景（解读层）

  • 开发 Telegram Serverless bot 前了解内存、CPU 与存储的实际边界
  • 复现或扩展平台资源探测实验
  • CI 或本地运行轻量诊断以获取 bot 可用资源指标
📖 README 首段存档原文 · 程序抽取

How much memory, CPU time and SQLite storage does Telegram Serverless give a bot? This project measures those limits, tests concurrent calls, and includes JavaScript probes you can run yourself.
