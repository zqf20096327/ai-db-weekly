Python 脚本，将 SQLite 数据库转换为 MySQL SQL dump 文件

综述（解读层）

该工具是一个 Python 脚本，读取 SQLite 数据库文件并生成 MySQL 格式的 SQL dump 文件，包含表结构和数据。使用者可通过命令行参数自定义 MySQL 表的引擎、字符集和排序规则，也可选择仅导出结构或数据。运行需要 Python 3.x。README 说明该项目由 ChatGPT 3.5 生成，采用 MIT 许可证。

  • 支持将 SQLite 数据库转换为 MySQL SQL dump，可分别或同时导出表结构和数据
  • 支持通过命令行参数自定义 MySQL 引擎、字符集和排序规则，默认 InnoDB / utf8mb4 / utf8mb4_unicode_ci
  • 提供 --no-drop 选项控制是否包含 DROP TABLE IF EXISTS 语句，并处理 Ctrl+C 中断以正常终止

适用场景（解读层）

  • 需要将 SQLite 数据库文件迁移为 MySQL 格式 SQL dump 的场景
  • 仅需要导出 SQLite 表结构或仅导出数据供 MySQL 使用的场景
  • 需要指定目标 MySQL 表引擎、字符集或排序规则的导入准备场景
