基于 Apache Calcite Avatica 的 Java 数据库代理，可同时连接多种引擎

综述（解读层）

Fense 是用 Java 编写的数据库代理，基于 Apache Calcite Avatica 构建，可同时连接 MySQL、Hive、ClickHouse、TiDB、Doris 等不同引擎的数据库。它提供权限管理、查询缓存、审计安全、限流熔断及 One SQL 等功能，面向需要对多引擎数据库访问做统一接入管控的场景。README 标明运行需 JDK 1.8 及以上。

  • 支持同时连接不同引擎的数据库（主题标签含 MySQL、Hive、ClickHouse、TiDB、Doris）
  • 提供权限管理、查询缓存、审计安全、限流熔断功能
  • 提供 One SQL 能力，构建于 Apache Calcite Avatica 之上

适用场景（解读层）

  • 对多引擎数据库进行统一代理接入
  • 需要数据库访问的权限控制与审计记录
  • 需要查询缓存与限流熔断管控的数据库查询服务
