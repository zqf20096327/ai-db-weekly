将原生 SQL 查询结果行映射为嵌套纯业务对象树的 Node.js ORM。

综述（解读层）

PureORM 是运行在数据库驱动（如 pg-promise、node-postgres 等）之上的对象关系映射层：开发者自行编写原生 SQL，ORM 将扁平且列名冲突的关系结果行转换为按自定义模型类组织的嵌套业务对象。需自行提供数据库驱动并定义各表对应的模型/集合类，提供 one/many 等按顶层对象数校验的方法。

  • 支持用户自带数据库驱动，仅负责结果行到对象的映射
  • 支持将多表 JOIN 的扁平结果行映射为嵌套的业务对象实例
  • 提供 one、oneOrNone、many、any 等按生成顶层模型数量校验的查询方法，以及基于列名空间化的 columns 便捷 getter

适用场景（解读层）

  • 在 Node.js 后端使用原生 SQL 并需要结构化嵌套对象作为响应载荷
  • 多表关联查询导致列名冲突、需要将结果按模型类组织的场景
  • 数据访问层需要返回纯对象（与数据库连接状态分离）的设计
🔌 适配哪些库db_scan 程序判定

MySQL、Oracle、PostgreSQL、SQL Server
