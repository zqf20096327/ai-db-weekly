基于 MySQL 8.4 的分支，通过 VEF 框架支持自定义数据类型与函数扩展

综述（解读层）

VillageSQL Server 是 MySQL 的开源分支，引入 VillageSQL Extension Framework（VEF），支持以 .veb 扩展包形式定义自定义数据类型和函数，并保持 MySQL 8.4 兼容。提供 C++ 与 Rust SDK 及内置示例扩展。目前处于 alpha 阶段，仅建议用于开发与测试，不支持 Windows 编译，自定义类型的 SUM/AVG 聚合和自定义索引类型尚未提供。

  • 提供 VEF 扩展框架，支持加载 .veb 扩展包并定义自定义数据类型与函数
  • 与现有 MySQL 8.4 应用和工具兼容，构建要求与标准 MySQL 8.4 相同
  • 提供 C++ 与 Rust SDK、项目模板及示例扩展（复数类型、UUID、HTTP 客户端函数等）

适用场景（解读层）

  • 在 SQL 模式中定义和使用领域专用数据类型与函数
  • 为现有 MySQL 8.4 应用开发数据库内扩展
  • 开发与测试环境中探索数据库扩展机制（暂不建议生产使用）
