🧭 简介解读层（AI·证据行可回查）

通过JDBC连接数据库、以自然语言查询并生成可视化的MCP服务器

综述（解读层）

DBChat 是一个 MCP 服务器，充当 MCP 客户端（如 Claude Desktop）与数据库之间的桥梁，用户以自然语言提问即可查询数据、生成图表和交互式仪表盘。它基于 JDBC 驱动运行，按内置驱动范围分为 basic、standard、enterprise、cloud-analytics、all 等多个发行版本，数据库连接通过 dbchat.conf 配置文件完成。需自行确认所用 JDBC 驱动的许可授权。

  • 通过 JDBC 驱动支持多种数据库，包括 PostgreSQL、MySQL、Oracle、SQLite 及 Redis、MongoDB 等多个发行版本，并提供 CSV/Excel 文件查询
  • 提供 MCP 提示词、交互式工作流、演示数据生成和洞察收集工具（如 start_workflow、append_insight）
  • 支持折线图、柱状图、饼图等多种图表类型生成与数据库结构探索

适用场景（解读层）

  • 业务人员或分析师无需编写 SQL，用自然语言查询数据库数据
  • 通过 MCP 客户端为数据生成可视化图表和摘要仪表盘
  • 利用内置演示数据与引导式工作流进行产品演示或入门培训
