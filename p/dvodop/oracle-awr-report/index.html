从 Oracle 数据库与 SSH 数据源导出 AWR 数据并生成 Excel 报表的 Python 脚本

综述（解读层）

oracle-awr-report.py 是一个 Python 脚本，通过 oradb 与 ssh 两类插件从 Oracle 数据库（执行 SQL 查询）或远程主机（运行 shell 脚本，如 atop 日志解析）采集数据，写入 xlsx 工作表并绘制折线/散点图。报表、图表、计算列均由 conf.d 下的配置文件定义，支持在 cygwin 环境运行。适合需要将 Oracle AWR 指标与 atop 系统日志整合到 Excel 报告的运维人员使用。

  • 支持从 Oracle 数据库执行 SQL 查询导出数据到 xlsx 工作表
  • 支持通过 SSH 运行 shell 脚本采集数据，内置 atop 日志解析脚本 atop_parser.sh
  • 支持自定义图表（折线/散点）与基于公式的计算列

适用场景（解读层）

  • 导出 Oracle AWR 相关指标（如服务时间、等待事件、Redo 统计）生成 Excel 图表报告
  • 解析主机 atop 日志，将 CPU、磁盘、swap 等系统数据生成报表
  • 将数据库指标与操作系统采集数据整合到同一份 xlsx 文档
