离线解析 openGauss 堆文件并导出 SQL/CSV/DDL/元数据的 Go 工具

综述（解读层）

gauss2sql-go 是 Python 版 gauss2sql 的 Go 重写，直接读取 openGauss（含 MogDB 等衍生库）数据目录中的堆文件，无需在线数据库服务即可导出 DDL、INSERT SQL、CSV 与元数据 JSON。它通过解析系统目录定位表，支持分区表展开、TOAST 解压、流式导出与坏页恢复。适用于无法启动实例时的数据恢复、取证与离线迁移场景。需 Go ≥1.23 构建，产物为静态二进制。

  • 直接读取 openGauss 数据目录堆文件，支持 openGauss 5.0.0~6.0.6 及衍生库 MogDB 5.0.9
  • 支持流式导出与 --parallel/--jobs 两层并行，README 记载大表导出峰值内存不随表大小增长
  • 对页头损坏、坏行、字段级损坏提供三级检测与恢复处理，全程不 panic

适用场景（解读层）

  • 数据库实例无法启动时，从数据目录离线还原表结构与数据
  • 批量导出 openGauss/MogDB 表为 SQL 或 CSV，用于跨库迁移或备份
  • 导出含 --deleted 选项的已删除行，用于数据取证或误删恢复
📖 README 首段存档原文 · 程序抽取

gauss2sql-go 是 gauss2sql（Python 版）的 Golang 完整重写版，功能完全等同：直接读取 openGauss 数据目录中的堆文件（heap file），不依赖任何在线服务，实现数据库对象的导出与数据还原。
