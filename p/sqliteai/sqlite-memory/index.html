🧭 简介解读层（AI·证据行可回查）

SQLite 扩展，为 AI 智能体提供基于 Markdown 的持久化可检索记忆。

综述（解读层）

该项目是一个 SQLite 扩展，将 Markdown 内容解析、切块并生成本地嵌入后存入单个 .db 文件，供 AI 智能体持久化存储与语义检索使用。检索采用向量余弦相似度与 FTS5 全文搜索结合的混合方式；多个智能体可借助 sqlite-sync 的 CRDT 机制在离线状态下各自工作、联网后合并记忆。使用需准备 SQLite、sqlite-vector 扩展及 GGUF 嵌入模型或远程 API 密钥；1.0.0 之前创建的数据库需重建。

  • 提供向量相似度与 FTS5 全文搜索结合的混合检索，以及感知 Markdown 语义边界的切块
  • 支持通过 llama.cpp 本地生成嵌入，或使用 vectors.space 远程 API
  • 基于内容哈希检测变更的增量同步，写入操作在 SAVEPOINT 事务中运行；多智能体间通过块级 LWW CRDT 同步 dbmem_content 表

适用场景（解读层）

  • 为 AI 智能体构建跨会话持久化、可语义检索的长期记忆库
  • 多智能体分布式部署场景下离线工作、联网合并共享知识
  • 通过 Go CLI（sqlmem）或 MCP 索引本地 Markdown 文档并执行混合搜索
