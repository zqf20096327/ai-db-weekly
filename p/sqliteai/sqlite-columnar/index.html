🧭 简介解读层（AI·证据行可回查）

以可加载扩展形式为 SQLite 提供列式存储与分析查询能力的扩展

综述（解读层）

sqlite-columnar 是一个自包含的 SQLite 可加载扩展，通过列式虚拟表为分析型扫描、聚合和分组汇总提供独立存储与执行路径，不修改 SQLite 内核。适用于嵌入式应用中的本地 OLAP 场景，如仪表盘、时序汇总和边缘分析；事务型点查场景仍建议使用普通行式表。元数据由 columnar_analyze() 增量构建，脏块按需重建。

  • 以列式虚拟表形式存储数据，按列单独存放并维护 chunk 级元数据与 zone map
  • 提供 columnar_sum/avg/count 等专用聚合函数与分组哈希聚合，在 C 层仅读取所需列的 shadow table
  • 支持增量 analyze：插入、更新、删除只标记脏块，后续分析仅重建受影响块；提供 Linux、macOS、Windows、Android、iOS 等平台的预编译扩展二进制

适用场景（解读层）

  • 对本地事件、遥测或产品分析数据构建嵌入式仪表盘
  • 按时间戳范围过滤的时序汇总、IoT 边缘分析与传感器宽表扫描
  • 审计日志与可观测性数据的按服务、区域、状态或时间桶聚合，以及 ETL 校验中的重复计数/求和/极值检查
