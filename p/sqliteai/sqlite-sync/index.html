基于 CRDT 的 SQLite 离线优先同步扩展

综述（解读层）

SQLite Sync 是一个多平台 SQLite 扩展，通过 CRDT（含 Causal-Length Set、Delete-Wins 等算法）把本地数据库变成可自动合并的离线副本，可与 SQLite Cloud、PostgreSQL、Supabase 同步。开发者经 `.load` 或 npm/Maven 等方式安装后，建表并调用 `cloudsync_init()`、`cloudsync_network_sync()` 即可同步；参与同步的设备须使用相同表结构。适用于离线应用与 AI Agent 状态共享。

  • 实现 CRDT 合并算法（Causal-Length Set、Delete-Wins、Add-Wins、Grow-Only Set），设备离线独立写入后自动合并
  • Block-Level LWW 按行级合并 text/markdown 列，不同行的并发编辑在同步后均被保留
  • 支持 Linux、macOS、Windows、iOS、Android、WASM 平台，内嵌 libcurl 网络层，一次函数调用完成同步

适用场景（解读层）

  • 离线优先应用：笔记、待办、野外数据采集、POS 系统，断网时本地写入、联网后合并
  • AI Agent 同步：多个实例共享记忆或 markdown 知识库，无中心协调下同步状态
  • 多租户企业应用：配合服务器端 RLS，单库内按行权限隔离各客户端同步数据
