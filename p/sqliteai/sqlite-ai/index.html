在 SQLite 内直接运行 LLM 推理与向量嵌入的 SQL 扩展

综述（解读层）

sqlite-ai 是一个 SQLite 扩展，通过 SQL 函数加载 GGUF 模型，在数据库内实现文本生成、对话、嵌入生成、Whisper 语音转写和多模态图像分析。支持 iOS、Android、Linux、macOS、Windows 平台，可通过预编译二进制、Swift、Gradle、PyPI、Flutter 等方式安装。README 注明部分 API 与功能仍在演进中。

  • 支持从 SQL 查询运行任意 GGUF 模型（Qwen、Gemma、Llama、DeepSeek 等），可在 Metal/CUDA 上进行 GPU 加速
  • 提供 token 级流式输出、跨会话上下文保存与恢复，以及基于 Whisper 的音频转写（WAV/MP3/FLAC）和多模态图像分析（JPG/PNG/BMP/GIF）
  • 支持 iOS、Android、Linux、macOS、Windows，提供预编译二进制及 Swift、Android、Python、Flutter 包

适用场景（解读层）

  • 在移动或边缘设备上离线运行推理，不依赖服务器或网络连接
  • 在 SQL 中生成向量嵌入，配合 sqlite-vector 做搜索与分类
  • 构建带历史记录的对话式助手或语音转写应用
📖 README 首段存档原文 · 程序抽取

Run Llama, Phi, Qwen, and embedding models directly from SQL queries — local, private, no API calls. GGUF support, GPU acceleration on Metal/CUDA.
