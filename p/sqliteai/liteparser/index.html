纯 C 实现的可嵌入 SQLite SQL 解析器，将 SQL 解析为可操作的 AST

综述（解读层）

liteparser 是一个用纯 C 编写、无外部依赖的 SQLite SQL 解析库，面向需要程序化处理 SQL 的 C/C++ 或 FFI 项目。其文法取自 SQLite 官方 parse.y，使用 Lemon LALR(1) 生成器。AST 基于 arena 分配，一次性释放；支持 JSON 序列化、AST 转回 SQL、容错解析与节点变更。仅支持 SQLite 方言，编译需 C 编译器。

  • 提供完整 SQLite 文法解析，输出 arena 分配的可遍历、可变更 AST
  • 支持 AST 与 JSON、SQL 文本双向转换，以及容错解析模式
  • 无外部依赖，可编译为静态库、动态库或 WebAssembly 模块

适用场景（解读层）

  • 需要解析、分析或改写 SQLite SQL 语句的 C/C++/FFI 应用
  • IDE 或 linter 场景下对含语法错误的 SQL 进行容错解析与诊断
  • 浏览器或 Node.js 环境中通过 WASM 模块解析 SQL
