🧭 简介解读层（AI·证据行可回查）

以 VFS 扩展形式实现 SQLite 多线程/多进程并发写入

综述（解读层）

sqlite-multiwriter 是一个 SQLite VFS 扩展，通过为每个写者维护私有 WAL、提交时校验页面并以 first-committer-wins 方式发布，使多个线程或进程并发写同一个数据库文件。不修改 SQLite 本体，无需改 schema 或 SQL，文件仍为普通 SQLite 格式。应用程序需处理 SQLITE_BUSY_SNAPSHOT 重试；可选 mw_rebase 仅支持按主键的简单事务。

  • 每个写者使用独立私有 WAL，提交时校验并合并，写入期间互不等待
  • 以 VFS 扩展加载，不改 SQLite、不改 schema、不改 SQL，数据库文件保持普通 SQLite 格式
  • 提供 mw_mp=1 多进程模式和可选 mw_rebase 参数以重放仅因共享页面冲突的提交

适用场景（解读层）

  • 单进程多线程高频写入同一 SQLite 数据库的应用
  • 多个进程或多个 agent 并发写同一个数据库文件的场景
  • 希望在不改 SQL 与 schema 的前提下减少 SQLITE_BUSY 重试的既有 SQLite 项目
