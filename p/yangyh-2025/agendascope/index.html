🧭 简介解读层（AI·证据行可回查）

面向国际关系研究的全球媒体议程设置实时监控与分析平台

综述（解读层）

AgendaScope 观澜用于监控 172 国 408 个主流媒体源，通过 RSS 采集文章，以 bge-m3 跨语言向量聚类议题、LLM 与实体关系抽取识别首发源、跟随国序列与时滞，并支持 50 个监控对象的社交图谱（关系边附新闻原文证据）。架构为 L0-L3 四层 PostgreSQL 数据库加 article_processing 状态机与基于 FOR UPDATE SKIP LOCKED 的分布式任务队列，本地算力机负责采集与计算，云端 2C2G 仅做存储展示。技术栈为 Python/FastAPI、React、PostgreSQL 16 + pgvector、Redis、Docker Compose，许可证为 CC BY-NC 4（仅限非商业学术用途）。

  • 提供 172 国 408 个媒体源的 RSS 实时采集与跨语言议题聚类，支持首发源、跟随国序列与时滞的溯源判定，议题合并/重命名/首发修正记录于 topic_lifecycle_events 表
  • 采用 L0-L3 四层数据库架构与 article_processing 处理状态机，配合 worker_tasks 表分布式任务队列（FOR UPDATE SKIP LOCKED），支持本地机器接入贡献采集/NLP 算力
  • 提供 RESTful 开放数据 API（X-API-Key 鉴权 + Redis 限流），支持 Docker Compose 单机部署，LLM 使用 GLM-4-Flash/SiliconFlow 多模型池

适用场景（解读层）

  • 国家安全与国际关系领域的议程设置研究，观察跨国媒体报道传播链路
  • 通过开放 API 获取议题与实体关系数据，用于学术数据分析与论文研究
  • 接入本地算力机参与分布式采集与 NLP 处理，支持部署监控看板
