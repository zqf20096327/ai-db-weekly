基于 Spring Boot + MyBatis Plus + Vue & Element 的后台管理系统与微信小程序开发平台

综述（解读层）

该项目是一个基于 Spring Boot 多模块架构的开源快速开发平台，后端使用 MyBatis Plus、Redis 与 Flowable，前端提供 Vue3 管理后台和 uni-app 商城小程序。功能分为精简版与完整版两个分支，完整版包含系统管理、工作流、支付、商城、微信公众号、会员中心等模块，供需要搭建后台管理或业务系统的个人与企业使用，采用 MIT 协议。

  • 支持 RBAC 动态权限、按钮级权限控制、SaaS 多租户与 SSO 单点登录，权限认证基于 Spring Security + Token + Redis 实现
  • 提供代码生成器，可生成 Java、Vue 前后端代码、SQL 脚本与接口文档，工作流基于 Flowable 支持在线设计流程与动态表单
  • 集成支付宝、微信支付与退款、阿里云/腾讯云短信、多种云存储（S3/MinIO 等），并接入 SkyWalking 链路追踪与 Spring Boot Admin 监控

适用场景（解读层）

  • 需要 RBAC 权限、数据权限或多租户隔离的企业后台管理系统开发
  • 需要审批流程、支付、短信、商城或微信公众号能力的业务系统搭建
  • 通过代码生成器快速生成前后端 CRUD 代码的应用开发场景
