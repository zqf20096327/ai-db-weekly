使用 EF Core 操作四种数据库的示例 .NET 项目集合

综述（解读层）

该仓库包含多个 .NET 示例项目，用 EF Core 对 MS SQL Server、MySQL、SQLite 和 CosmosDB 执行数据库操作，内容覆盖 CRUD、加载关联数据、读取视图和调用存储过程，并附有各数据库对应的视频教程，用于帮助初学者从零创建 Web API 项目。

  • 提供针对 MS SQL Server、MySQL、SQLite、CosmosDB 四种数据库的 EF Core 示例项目
  • 示例覆盖 CRUD、关联数据加载、视图查询与存储过程调用
  • 提供配套视频教程，演示如何从零创建 Web API 项目

适用场景（解读层）

  • EF Core 初学者学习各类数据库的基本操作
  • 开发者需要参考视图查询、存储过程调用等示例代码
  • 按教程步骤构建基于不同数据库的 Web API 项目
