基于 SQLite 与 LanceDB 的本地优先关系型与向量数据库引擎

综述（解读层）

CortexDB 是 Cortex-Works 生态的专用数据库引擎，用 SQLite 存储 Epic、Ticket、Backlog 等关系型数据，用 LanceDB 支持向量存储与语义检索（RAG），用于替代扁平 JSONL 台账。当前处于早期 Alpha 阶段，API 与 CLI 命令可能在不通知的情况下发生破坏性变更；截至 2026 年 2 月 25 日仅在 macOS Sequoia 15.7.4 的开发机上测试，Windows/Linux 用户可能遇到不稳定或功能失效。

  • 基于 SQLite 存储关系型数据，包含 Epic/Ticket 跟踪、任务分配与结构关系
  • 内嵌 LanceDB 本地向量数据库，用于语义搜索与 RAG，零配置
  • 支持与 cortex-studio 的看板、燃尽图与 Sprint Backlog 等界面集成

适用场景（解读层）

  • 为自主多智能体团队管理 Scrum 流程与 Agent 记忆
  • 从 JSONL 台账迁移到本地关系型与向量存储
  • 在 CortexSync/CortexRelay 生态中承担状态管理与数据集成角色
