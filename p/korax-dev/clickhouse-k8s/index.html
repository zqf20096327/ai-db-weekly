🧭 简介解读层（AI·证据行可回查）

基于官方 ClickHouse 容器在 Kubernetes 上部署的 Helm Chart

综述（解读层）

这是一个 Helm Chart 仓库，用于在 Kubernetes 上部署 ClickHouse 及可选的 ClickHouse Keeper，镜像采用官方 ClickHouse 容器。README 提供了通过 helm repo add 与 helm install 安装、helm upgrade 升级的命令，配置细节需查阅 chart 自身的 README。适合需要以 Helm 方式管理 ClickHouse 部署的 Kubernetes 用户。

  • 支持使用官方 ClickHouse 容器部署 ClickHouse
  • 支持可选部署 ClickHouse Keeper
  • 通过 Helm 提供安装与升级流程

适用场景（解读层）

  • 在 Kubernetes 集群中部署 ClickHouse
  • 需要同时部署 ClickHouse Keeper 的场景
  • 通过 Helm 管理与升级 ClickHouse 部署
📖 README 首段存档原文 · 程序抽取

This repository contains resources for deploying ClickHouse and optional ClickHouse Keeper on Kubernetes using the official ClickHouse containers.
