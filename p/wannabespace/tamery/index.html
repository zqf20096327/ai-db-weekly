🧭 简介解读层（AI·证据行可回查）

AI 驱动的数据库客户端与 MCP 服务器，支持桌面与网页

综述（解读层）

Tamery 是一个面向开发者与 AI Agent 的数据库客户端，提供桌面与 Web 两种形态。它读取连接字符串、.env、JDBC URL 等多种格式建立连接，内置表浏览、带自动补全的查询编辑器、模式可视化和 AI 助手；MCP 服务器允许 Claude Code、Cursor 等 Agent 查询数据库。写操作需人工确认。项目不接受 pull request，仅接受 issue。

  • 支持 PostgreSQL、MySQL、MariaDB、SQL Server、Oracle、ClickHouse、MongoDB、SQLite、DuckDB 等多种数据库
  • 内置 MCP 服务器，Agent 的每次写操作需用户点击确认
  • 支持 SSH 隧道与 SSL，连接字符串加密存储，可离线使用

适用场景（解读层）

  • 用图形界面浏览、编辑和查询多种数据库
  • 让 Claude Code、Cursor 等 Agent 通过 MCP 查询数据库
  • 本地或私有网络数据库的连接管理与 AI 辅助 SQL 编写
