嵌入 .NET 应用的可编程工作流引擎，含可视化设计器与多数据库持久化

综述（解读层）

Workflow Engine by Optimajet 是一个以 NuGet 包（WorkflowEngine.NETCore-Core）分发的嵌入式 .NET 工作流引擎，用于在自有应用中添加审批、状态机和长时流程。流程以 scheme 描述，可在浏览器端 HTML5 设计器或用 C# 的 ProcessDefinitionBuilder 构建，运行时在进程内执行并管理命令、定时器与流转历史。进程状态存于 SQL Server、PostgreSQL、MySQL、Oracle、MongoDB 或 SQLite。支持 .NET 8、.NET 10 与 .NET Framework 4.7.2。免费版需署名，限 10 个流程定义与 4 个执行线程；商业版按 EULA 授权。

  • 以 scheme 定义流程，支持浏览器端 Workflow Designer、C# ProcessDefinitionBuilder 以及 BPMN 图导入
  • 进程状态持久化到 SQL Server、PostgreSQL、MySQL、Oracle、MongoDB 或 SQLite，SQL 提供程序含自动数据库版本迁移
  • 支持持久化执行（断点恢复）、流程版本控制、并行子进程、定时器与工作日历、多租户与可插拔安全

适用场景（解读层）

  • 为现有 .NET/ASP.NET Core 应用内嵌审批流、状态机和长时业务流程
  • 需要流程可视化编辑供开发者与业务使用者共同操作的应用
  • 有定时升级、重启后恢复、流程版本迁移等需求的多租户业务系统
