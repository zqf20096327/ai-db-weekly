基于 ADO.NET 的 C# 关系数据库操作类库

综述（解读层）

DatabaseInvoke 是一个用于操作关系数据库的 C# 类库，基于 ADO.NET 实现，通过 SqlManipulation 类配合连接字符串与 SqlType 枚举使用，并在 using 块结束后自动清理连接资源。它提供 .NET 4.0 与 .NET Standard 2.0 两个目标框架版本，可配合 Dapper ORM 使用（需手动添加引用）。README 提示 Oracle 用户在 .NET Framework 下使用 .NET Standard 版本可能遇到依赖问题，可通过 NuGet 替换 Oracle 包解决。

  • 通过 SqlManipulation 类传入连接字符串和 SqlType 枚举执行数据库操作，using 块结束后自动清理连接资源
  • 提供 .NET 4.0 和 .NET Standard 2.0 两个目标框架版本
  • 支持 DataReader 方式读取数据库数据，可配合 Dapper ORM 使用（需手动添加引用）

适用场景（解读层）

  • 需要在 C# 项目中对关系数据库进行增删改查操作
  • 需要在 .NET Framework 4.0 或 .NET Standard 2.0 项目中统一封装数据库访问代码
  • 需要以 DataReader 方式逐条读取数据而不在内存中保留数据副本的场景
