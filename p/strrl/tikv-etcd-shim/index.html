基于 TiKV 后端实现 etcd v3 API 的适配层

综述（解读层）

tikv-etcd-shim 是一个适配器项目，尝试实现 etcd v3 API 并以 TiKV 作为存储后端，watch API 依赖 TiCDC 实现。README 中标注的 TODO 包括 txn KVServer、watch API 实现与 A/B 测试工具，说明多项功能仍在开发中，尚未完成。适合关注 etcd API 与 TiKV 集成的开发者研究其实现思路。

  • 实现 etcd v3 API，并使用 TiKV 作为存储后端
  • 计划通过 TiCDC 为 watch API 提供支持
  • 开发路线包含 txn KVServer、watch API 及 A/B 测试工具

适用场景（解读层）

  • 需要在 TiKV 之上运行 etcd v3 API 客户端的环境
  • 研究 etcd API 与 TiKV、TiCDC 集成方式的开发者
  • 对 A/B 对比测试 etcd 与该适配层感兴趣的工程团队
