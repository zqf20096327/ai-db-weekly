🧭 简介解读层（AI·证据行可回查）

面向 Claude Code 开发者的本地仪表盘，单页聚合会话、MR、任务、Docker 与 Postgres。

综述（解读层）

Opsboard 是一个运行在 127.0.0.1 的本地 Web 仪表盘，将 Claude Code 会话及其子代理状态、GitLab/GitHub 合并请求、Jira 任务、Docker 容器、Postgres 慢查询、Claude 用量限额和机器资源集中在一个浏览器页展示。依赖 Python 3.8+（仅标准库）与 git，可选 Docker、Jira token、Claude Code CLI。仅支持 macOS 和 Linux，不支持 Windows。

  • 单页展示运行中的 Claude Code 会话、子代理状态、后台任务与每条回答耗时
  • 聚合 GitLab/GitHub 合并请求的管线状态、评审线程、冲突与关联 Jira 任务，并支持在页面内查看 diff 与评审线程
  • 侧边栏每分钟读取 Claude 订阅计划的会话/周/模型限额与重置时间，凭据仅存内存且只发往 api.anthropic.com

适用场景（解读层）

  • 同时管理多个 Claude Code 会话并查看其代理与资源占用
  • 将 Jira 任务与合并请求关联跟踪评审进度与冲突
  • 本地监控 Docker 容器、Postgres 慢查询与机器 CPU/内存/GPU 资源
