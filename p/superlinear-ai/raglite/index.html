基于 DuckDB 或 PostgreSQL 的 Python 检索增强生成（RAG）工具包

综述（解读层）

RAGLite 是一个 Python 工具包，用于在 DuckDB 或 PostgreSQL 数据库上构建检索增强生成（RAG）流程。它通过 LiteLLM 支持任意 LLM（含本地 llama.cpp 模型），实现 PDF 转 Markdown、语义分块、混合检索（FTS+VSS）与重排序，并支持自适应 RAG、可编程管线、查询适配器和 Ragas 评估。依赖仅限轻量开源库，不含 PyTorch 或 LangChain，适合在自有数据库上搭建文档问答系统的开发者。

  • 支持 DuckDB 与 PostgreSQL 作为关键词与向量搜索数据库（tsvector+pgvector），提供关键词、向量及混合检索，并可通过 rerankers 配置重排序模型
  • 实现 PDF 转 Markdown、late chunking 多向量嵌入、基于二元整数规划的语义分块与句子切分，以及通过正交 Procrustes 求解的闭式查询适配器
  • 内置基于 FastMCP 的 MCP 服务器（暴露 search_knowledge_base 工具），可选 Chainlit 前端、Pandoc 文档转换、Mistral OCR 处理与 Ragas 评估

适用场景（解读层）

  • 在本地或远程数据库中插入 PDF 等文档，构建带引用来源的文档问答与知识库检索系统
  • 需要自定义 RAG 管线各步骤（搜索、重排序、分块扩展、指令生成）的开发场景
  • 通过 MCP 服务器将知识库检索能力接入 Claude 桌面端等 MCP 客户端，或用 Chainlit 部署网页、Slack、Teams 聊天界面
