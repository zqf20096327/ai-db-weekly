🧭 简介解读层（AI·证据行可回查）

终端里的 PostgreSQL 复制槽监控工具，以 TUI 展示各槽的 WAL 保留量与增长速率。

综述（解读层）

slotwatch 是用 Go 编写的 PostgreSQL 复制槽查看工具，面向使用逻辑复制或物理复制的数据库运维人员。它通过 pgx 周期性读取 pg_replication_slots，计算每个槽保留的 WAL 量、增长速率和空闲时长，对超阈值或长期未消费的槽给出标记及建议。工具只做读取，不修改或删除复制槽。

  • 提供 TUI 界面，显示每个槽的 WAL 保留量、增长速率、消费方与空闲时长，支持排序、过滤和详情面板
  • 提供 --check 模式，以 0/1/2/3 退出码输出表格或 JSON，可接入 cron、CI、Kubernetes 及常规监控插件
  • 支持逻辑与物理槽（含临时槽）、主库与备库，实测 PostgreSQL 14–18，无需特殊授权即可登录使用

适用场景（解读层）

  • 排查因消费方停止（如 Debezium 连接器崩溃、订阅被遗忘）导致 WAL 持续堆积的复制槽
  • 在 cron、CI 或 Kubernetes 中以 --check --json 方式定期检查复制槽健康状态
  • 通过 --demo 模式在没有数据库的环境下查看工具的界面与告警表现
