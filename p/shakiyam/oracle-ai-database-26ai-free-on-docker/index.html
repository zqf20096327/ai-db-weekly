一组通过 Docker 运行 Oracle AI Database 26ai Free 容器镜像的脚本集合

综述（解读层）

该仓库提供一组 Shell 脚本，用于拉取 Oracle Container Registry 中的 Oracle AI Database 26ai Free 容器镜像并本地运行。使用前需将 dotenv.sample 复制为 .env 配置容器名、监听端口和密码。脚本覆盖创建/启动/停止/删除容器、查看告警日志、通过 SQL*Plus 连接 CDB 与 PDB、用 SQLcl 查询、安装示例 Schema 等操作。适合需要在本地容器环境运行该数据库的用户；MIT 许可，作者为 Shinichi Akiyama。

  • 提供 run.sh、start.sh、stop.sh、remove.sh 等脚本，管理数据库容器的创建、启动、停止与删除
  • 提供 sqlplus.sh 与 sql.sh，分别以 SQL*Plus 连接 CDB/PDB、以 SQLcl 连接 PDB
  • 提供 install-sample.sh 安装示例 Schema，logs.sh 查看数据库告警日志

适用场景（解读层）

  • 本地以容器方式运行 Oracle AI Database 26ai Free 实例
  • 加载示例 Schema 后通过 SQL*Plus 或 SQLcl 进行 SQL 练习与查询
  • 启动/停止容器并查看数据库日志进行日常管理
