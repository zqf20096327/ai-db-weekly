基于 SQL Tools Service 的 Neovim SQL Server 工作区插件

综述（解读层）

sqlserver.nvim 是面向 Neovim 的 SQL Server 工作区插件，用于在编辑器内完成连接、浏览对象、执行 T-SQL 与查看结果。它通过 Microsoft SQL Tools Service 提供语言智能与查询执行，支持 SQL Server 和 Azure SQL 连接配置。要求 Neovim 0.11.7 以上；首次安装时自动下载固定版本的 SQL Tools Service；对象浏览器需可选依赖 snacks.nvim。

  • 通过 Neovim 内置 LSP 与 SQL Tools Service 提供 T-SQL 补全、诊断、格式化、悬停、导航和签名查看
  • 支持执行光标语句、可视选区或整个缓冲区，可取消查询并查看持久化活动记录
  • 结果可导出为 CSV、JSON、XML、Excel .xlsx，或复制为富文本 HTML 表格

适用场景（解读层）

  • 在 Neovim 中连接 SQL Server / Azure SQL 并浏览表、视图、存储过程和函数
  • 执行 T-SQL 查询并在专用结果缓冲区中查看、导航和导出结果集
  • 从 mssql.nvim 迁移的用户（需按迁移指南调整配置与工作流）
