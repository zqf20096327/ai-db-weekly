只读终端 TUI，可视化探索 ClickHouse 物化视图及其数据流

综述（解读层）

ch_insp 是一个 Go 编写的只读终端界面工具，用于查看 ClickHouse 物化视图：展示源表到 MV 再到目标表的数据流，可检查依赖、列血缘和 SQL 定义。通过 URL 或命令行参数连接服务器，也可用 --schema 离线读取 SQL 转储（不执行语句，无实时指标）。访问为只读，指标依赖本地节点的 system logs。

  • 可视化源表 → 物化视图 → 目标表的数据流，支持共享目标和多输入
  • 支持搜索/过滤流、检查表依赖、目标列、列血缘和 SQL 定义
  • 提供离线模式（--schema 读取 SQL 转储）和集群节点切换；监控指标仅在日志可用时提供，且全部只读

适用场景（解读层）

  • 排查 ClickHouse 物化视图链路：查看依赖关系、列血缘和 SQL 定义
  • 观察连接节点的读写速率、近期历史和 MV 错误（需 system logs 可用）
  • 无服务器环境下离线检查 SQL schema 转储中的物化视图结构
