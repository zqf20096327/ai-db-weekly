Oracle 到 MySQL 系数据库的在线迁移命令行工具

综述（解读层）

OracleSync2MySQL 是一个在客户端运行的 Oracle 数据库在线迁移工具，将表结构、行数据、视图、索引约束和自增列迁移到 MySQL、PolarDB、MariaDB、OceanBase、TiDB、GaussDB for MySQL 等 MySQL 内核数据库。运行机器需同时连接源库与目标库，解压即用，支持 Windows/Linux/macOS。配置通过 yml 文件指定源/目标库、并发数、分页大小及自定义表清单，迁移完成后可执行源/目标行数比对并生成迁移摘要。

  • 支持整库迁移表结构、行数据、视图、索引约束与自增列，采用多线程分页批量写入
  • 提供六种迁移模式：整库迁移、自定义 SQL 查询迁移、全库/自定义表结构创建、整库/自定义表数据迁移，以及仅输出 DDL 脚本到日志文件
  • 支持迁移后源库与目标库表行数比对，仅显示不一致的表

适用场景（解读层）

  • 将 Oracle 数据库表结构与行数据迁移到 MySQL 内核的目标数据库
  • 按自定义 SQL 查询仅迁移部分表的结构或数据
  • 迁移前仅导出建表、索引、视图等对象的 DDL 语句以供检查

GaussDB、MariaDB、MySQL、OceanBase、Oracle、PolarDB、TiDB
