基于 Raft 协议的 Go 语言分布式键值存储，提供 HTTP/OpenAPI 接口

综述（解读层）

LeifDB 是一个用 Go 实现的集群化键值存储，通过 Raft 协议维护一致性，客户端经由 OpenAPIv2.0 兼容的 HTTP 接口读写，节点间使用 gRPC 与 protobuf 通信。README 提及擦除码功能尚属计划中（in progress）。适合希望研究 Raft 实现与分布式一致性机制的读者，仓库附 3 节点 docker-compose 演示集群与基础前端界面。

  • 实现 Raft 协议的集群键值存储，节点间通过 gRPC/protobuf 通信
  • HTTP 客户端接口符合 OpenAPIv2.0，根端点提供 Swagger schema 供程序化发现，附带自动生成的 Swagger 交互页
  • 通过环境变量配置端口、数据目录、快照阈值、日志级别及多节点集群成员列表；快照机制按日志大小阈值压缩日志并可保留多个快照

适用场景（解读层）

  • 在本地或 docker-compose 环境启动 3 节点演示集群，通过 UI 或 HTTP 端点观察 Raft 选主、日志复制与读写重定向行为
  • 作为 Go 实现的 Raft 参考代码库，用于阅读测试用例中 Raft 消息构造方式及调试日志
  • 部署多节点键值服务：设置 LEIFDB_MODE=multi 并提供成员地址列表，写请求自动重定向至 leader 节点
