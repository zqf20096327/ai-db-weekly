🧭 简介解读层（AI·证据行可回查）

基于 Spring Boot 3 与 React 的 A 股量化因子投研平台，覆盖因子计算到模拟交易全流程。

综述（解读层）

该平台面向 A 股量化研究与学习场景，提供行情采集、因子计算、策略回测、每日选股推荐、AI 分析与模拟交易等模块。后端为 Java 21 + Spring Boot 3，使用 MySQL 存元数据、ClickHouse 存时序数据（可用 MySQL 替代），前端为 React。需手动导入 61 张表的建表脚本，应用启动时不执行 DDL。README 声明仅供研究学习，不构成投资建议。

  • 内置 35+ 因子（动量/价值/质量/情绪/资金/形态六类），提供 IC 分析、衰减检测、相关性去冗余与等权/Markowitz/风险平价三种权重优化方法
  • 回测引擎支持事件驱动模拟（含手续费与滑点）、Brinson 归因、Fama-French 3 因子、蒙特卡洛 VaR/CVaR 与 Walk-Forward 验证
  • 从 Baostock、腾讯、AKShare、东方财富、同花顺五个数据源采集行情，定时任务通过 cron 表达式与依赖表编排

适用场景（解读层）

  • 个人量化研究者搭建本地 A 股因子回测与选股推荐环境
  • 量化学习者阅读完整源码与策略文档并实际运行系统
  • 研究团队进行因子生命周期管理与策略健康监控
📖 README 首段存档原文 · 程序抽取

Quant Platform 是一个企业级 A 股量化投研一体化平台，将因子挖掘、策略构建、回测验证、AI 辅助分析和模拟交易打通成完整闭环。不同于只能回测的工具，它覆盖了从原始行情数据采集到每日选股推荐产出的全链路——你给策略，它给答案。
