Go 编写的多数据库 Web 管理工具，基于 Go Template 渲染页面

综述（解读层）

SimpleDBWeb 是用 Go 和 Go Template 实现的数据库管理 Web 工具，支持 MySQL、PostgreSQL、SQLite、ClickHouse 及达梦、人大金仓等国产数据库。用户可通过 DSN 或表单连接数据库，浏览表结构、分页查询、编辑删除行数据并执行 SQL。它既可编译为独立服务运行，也可通过 go mod 作为库嵌入应用，采用适配器模式接入 Gin、Echo 等框架；编辑删除依赖主键，SQL 字符串有转义但生产环境建议使用参数化查询。

  • 支持 MySQL、PostgreSQL、SQLite、ClickHouse、达梦、OpenGauss、人大金仓等多种数据库的连接与管理
  • 提供表结构查看、数据分页查询、行编辑删除和 SQL 执行功能
  • 采用适配器模式可集成 Gin、Echo 等框架，资源通过 Go embed 嵌入，可经 go mod 作为库引入

适用场景（解读层）

  • 通过 Web 界面查看和管理 MySQL、PostgreSQL 等数据库的表数据与结构
  • 需要将数据库管理页面嵌入到既有 Go Web 应用中的场景
  • 需要管理达梦、人大金仓、OpenGauss 等国产数据库的环境
