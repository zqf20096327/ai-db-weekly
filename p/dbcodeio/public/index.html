运行于 VS Code 及其分支的数据库客户端扩展，内置 MCP 与 AI 集成

综述（解读层）

DBCode 是一个 VS Code 扩展，提供数据库连接、SQL 编辑、数据查看与编辑、ER 图、SQL Notebook、图表可视化等功能，支持 PostgreSQL、MySQL、MongoDB 等 README 中列出的多种数据库类型。它面向在 VS Code、Cursor、Windsurf 等编辑器内进行数据库操作的开发者。安装来自 VS Code Marketplace 或 OpenVSX；基础功能免费，Pro 与 Team 版本提供额外功能，且在启用 VS Code 遥测时会收集匿名使用数据。

  • 支持 README 列出的多种数据库类型，包括 SQL、NoSQL、图/向量、流式/时序数据库及 CSV、Excel、Parquet、Avro 文件
  • 提供 SQL 编辑、表格数据编辑、自动生成 ER 图、SQL/Python Notebook、查询结果图表与执行计划可视化
  • 内置 MCP 工具，可在 VS Code、Cursor 中注册供 AI 代理使用，并支持按连接配置 AI 权限

适用场景（解读层）

  • 开发者在编辑器内查询与编辑多种数据库数据，无需切换独立客户端
  • 通过自然语言或 MCP 让 AI 代理访问已有数据库连接
  • 从项目配置文件（.env、settings.py 等）自动发现并配置数据库连接
