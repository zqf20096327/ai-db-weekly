蜜蜂记账 App 的自托管同步云端，单 Docker 镜像提供同步服务与 Web 控制台

综述（解读层）

为 BeeCount（蜜蜂记账）App 提供自部署云端，一个 Docker 镜像包含 FastAPI 后端与 React Web 控制台，数据持久化在单个 ./data 目录（SQLite + 附件）。支持 iOS/Android/Web 多端实时同步、共享账本、内置 AES-256 加密备份与 MCP server。许可证为 BSL，个人自部署免费，商业使用需付费授权。

  • 基于 WebSocket 的双向实时同步，离线优先，冲突按"最后写入 + 设备 ID"规则确定性解决
  • 共享账本支持 Owner/Editor 双角色，通过邀请码（默认 24 小时）加入，交易标注创建者与最后编辑者
  • 内置多远端加密备份系统：rclone 推送至 S3/R2/B2/WebDAV/Google Drive 等，APScheduler cron 调度，备份为 AES-256 加密 zip

适用场景（解读层）

  • 个人自托管记账，iOS/Android/Web 三端共用一份账本数据且数据存于自有服务器
  • 家庭成员或小组通过共享账本协作记账并查看成员收支统计
  • 通过内置 MCP server 在 Claude Desktop/Cursor/Cline 等客户端中用自然语言查询交易、记账与修改预算
