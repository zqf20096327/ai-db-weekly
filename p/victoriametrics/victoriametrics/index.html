时序数据库与监控方案，提供单节点与集群两种部署形态

综述（解读层）

VictoriaMetrics 是一个面向时序数据的监控存储方案，提供 Apache 2.0 许可下的单节点版与集群版，可通过二进制、Docker 镜像或源码部署。它支持以 PromQL 与 MetricsQL 查询，可作为 Prometheus 长期存储及 Grafana 数据源。部署形态为单个二进制文件，无外部依赖，通过命令行参数配置，支持快照备份与恢复。企业版另含异常检测、降采样、多重保留等特性。

  • 支持 Prometheus remote write、InfluxDB line protocol、Graphite plaintext、OpenTSDB、OpenTelemetry、DataDog、JSON line、CSV、原生二进制等多种数据接入协议
  • 提供流聚合能力，可作为 StatsD 替代，支持多数据源全局查询视图
  • 支持在 NFS 存储上运行，包含 metrics relabeling 与基数限制器等功能

适用场景（解读层）

  • 作为 Prometheus 或 Graphite 的长期存储，在 Grafana 中展示监控数据
  • 聚合多个 Prometheus 实例或其他数据源的指标，实现统一查询
  • 处理来自 Kubernetes、IoT 传感器、APM、工业遥测、金融数据等来源的时序数据
