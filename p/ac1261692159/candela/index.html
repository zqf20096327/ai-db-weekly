基于 ClickHouse 的开源可私有化用户行为分析平台

综述（解读层）

Candela 是一个可自托管部署的开源用户行为分析平台，底层使用 ClickHouse 存储分析数据，与 ClkLog 社区版共用 Kafka 事件流，ClkLog 负责采集与基础报表，Candela 提供漏斗、留存、用户分群等行为分析、协作与治理能力。项目提供单机 Docker Compose 部署脚本，采用 AGPL-3.0 许可证，README 标注代码由 AI 编写，AI 分析助手默认关闭。

  • 提供事件分析、漏斗（2-32 步）、留存、用户时间线、条件/SQL/ID 分群等分析模型，支持自定义 SQL 只读查询与指标定义
  • 支持保存分析卡片、仪表盘、指标告警、埋点目录（含虚拟事件与虚拟属性）、数据质量检查与项目级权限，界面提供 13 种语言
  • 与 ClkLog 社区版共用 Kafka 事件流但使用独立分析库，社区镜像与表结构保持不变，提供单机 Docker Compose 幂等部署脚本

适用场景（解读层）

  • 需要在自有服务器上私有化部署、对 Web/App/小程序产品做用户行为分析的团队
  • 已运行 ClkLog 社区版、需补充漏斗、留存与分群等行为分析能力的场景
  • 需通过仪表盘、指标告警持续跟踪转化与留存，或用自定义 SQL 回答标准模型未覆盖问题的分析团队
