为 Ember.js 应用生成基于 Express 和 Sequelize 的 Node.js API 的命令行工具

综述（解读层）

November 是一个命令行工具，用于为 Ember.js 应用生成 Node.js API，基于 Express 与 Sequelize 构建。面向使用 Ember Data 的前端开发者，提供项目脚手架生成、模型与 action 生成等功能。默认使用 MySQL，可通过 config/config.json 更换为 Sequelize 支持的其他关系型数据库；生成的控制器按 Ember Data 的 JSON API 约定渲染模型和错误信息。

  • 提供 november new、november generate model/action 等命令，生成含路由和增删改查控制器的项目结构
  • 默认使用 MySQL，支持更换为 Sequelize 支持的其他关系型数据库
  • render() 方法按 Ember Data 的 JSON API 约定渲染模型，支持关联模型 sideload 或嵌入式输出，并可渲染自定义错误信息

适用场景（解读层）

  • 为 Ember.js 应用快速生成配套的后端 API 项目
  • 基于 Sequelize 约定生成模型的增删改查路由与控制器
  • 生成不绑定具体模型的 API 端点（action）
📖 README 首段存档原文 · 程序抽取

November helps you generate a simple Node.js API tailored for Ember.js apps, with the help of Express and Sequelize.
