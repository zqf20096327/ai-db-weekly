🧭 简介解读层（AI·证据行可回查）

基于 Juju 的 PostgreSQL Charmed Operator，封装 Patroni 实现虚拟机上的生命周期管理

综述（解读层）

该仓库提供用于在虚拟机上通过 Juju 编排引擎部署 PostgreSQL 的 charmed operator，面向使用 Juju 的运维人员。其本质是一个 Python 脚本，包装 Ubuntu Jammy 系列分发的 PostgreSQL 并叠加 Patroni，处理安装、配置、集成、移除等生命周期事件。支持一主多热备副本的复制部署、密码轮换、postgresql_client/pgsql/TLS 接口集成；许可证为 Apache 2.0，PostgreSQL 本身遵循 PostgreSQL License。

  • 提供带复制功能（一主一或多热备）的 PostgreSQL 部署，基于 Patroni 管理生命周期
  • 支持 get-primary、set-password 等 action，以及通过 juju add-unit/remove-unit 逐个增删副本
  • 支持 postgresql_client、legacy pgsql、tls-certificates 三种集成接口

适用场景（解读层）

  • 在 Juju/LXD 或虚拟机环境中部署带热备副本的 PostgreSQL 集群
  • 通过 postgresql_client 接口将 PostgreSQL 集成为应用的关系数据库
  • 为内部或外部连接启用 TLS 加密的 PostgreSQL 部署
