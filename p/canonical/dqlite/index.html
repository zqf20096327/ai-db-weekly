嵌入式分布式 SQLite 引擎库，基于 Raft 实现数据复制与自动故障转移

综述（解读层）

dqlite 是一个 C 语言库，在 SQLite 基础上扩展网络协议，将多个应用实例组成高可用集群，不依赖外部数据库。它采用 libuv 单线程异步实现，基于 Raft 算法复制数据，仅支持 Linux 且需内核原生异步 I/O 支持。提供 Go 语言绑定，适合需要在应用内嵌 SQLite 复制能力的开发者。

  • 基于 Raft 算法实现数据复制，具备高可用与自动故障转移
  • 使用 libuv 的异步单线程实现，并采用针对 SQLite 数据类型优化的自定义线协议
  • 遵循带静态链接例外条款的 LGPLv3 许可，支持静态链接集成

适用场景（解读层）

  • 在多个应用实例间复制 SQLite 数据，构建无需外部数据库的高可用集群
  • 嵌入 C/C++ 或 Go（通过 go-dqlite 绑定）应用程序，提供嵌入式 SQL 引擎
  • 运维场景中使用 dqlite-utils 检查实例状态、加载节点快照或查看历史数据库状态
