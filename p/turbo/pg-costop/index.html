🧭 简介解读层（AI·证据行可回查）

在 Postgres 中实现向量运算与加权随机化余弦相似度排序的 SQL 函数库

综述（解读层）

pg-costop 是一组 Postgres SQL 函数，提供向量加减、缩放、点积、范数计算等运算，核心是 ct_weigh 与 ct_similarity 两个函数，用于将正/负偏好向量合成为加权向量（可加噪声与缩放系数）并按余弦相似度排序。适用于已将数据向量化并预先存储向量模长的场景；向量类型为 double precision[]，未提供模长时计算会变慢。

  • 提供 ct_add、ct_sub、ct_scale、ct_dot、ct_norm、ct_random_normal 等向量运算函数，向量类型为 double precision[]
  • ct_weigh 支持正/负向量列表，含可选 pos_scale、neg_scale 缩放参数与 noise 噪声参数，返回向量及其模长
  • ct_similarity 返回余弦接近度排序值（-1.0 表示最相似），支持传入缓存的模长以跳过即时计算

适用场景（解读层）

  • 基于用户已喜欢和不喜欢的多个向量生成加权、带随机性的推荐排序查询
  • 在 Postgres 内对预计算的嵌入向量执行余弦相似度检索与排序
  • 需要纯 SQL 向量算术（求和、点积、缩放、生成正态随机向量）的场景
