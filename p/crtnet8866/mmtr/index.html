🧭 简介解读层（AI·证据行可回查）

基于人脑记忆机制的 agent 记忆层，用 SQLite 单文件存储，支持按通道衰减

综述（解读层）

MMTR 是面向 agent 的记忆层，把每段经历拆成 fact/gist/affect 三条以不同半衰期衰减的通道，配合四级压缩、联想图、六维关系向量和前瞻记忆（约定锁定 L0 且临近到期更清晰）。零依赖，基于 Node 22.5+ 内置 node:sqlite，可嵌入应用或以 HTTP 服务运行，也可作为 DSH 插件提供六个 agent 工具。单机 SQLite，不面向多写并发。

  • 三条衰减通道（fact/gist/affect）各有独立的半衰期、曲线陡度与地板值，配 L0-L3 压缩层级与基于重要性的 floorLevel
  • 记忆间建立 entity/temporal/same_anchor/same_theme 四类边，检索时按 hopDecay 沿边扩散，并含三道防检索自增强闸门
  • 支持 sleep/consolidate 会话结算与巩固、core_memory 常驻块、HTTP 接口、MMTR_TOKEN 鉴权及全量导出

适用场景（解读层）

  • 需要长期运行、维持用户关系状态的 agent（角色扮演、陪伴类应用）的记忆后端
  • 需要跟踪承诺与约定到期（自动判定 kept/broken 并结算关系代价）的场景
  • 作为 DSH 插件为 agent 提供 remember/recall/promise/settle 等六个记忆工具
