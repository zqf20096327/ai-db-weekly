🧭 简介解读层（AI·证据行可回查）

为 Rails 提供版本化数据库视图管理的 ActiveRecord 迁移扩展

综述（解读层）

Scenic 通过在 ActiveRecord::Migration 中加入 create_view、update_view、drop_view 等语句，让 Rails 应用以 SQL 文件方式定义并按版本管理数据库视图，无需切换 schema 格式。内置 PostgreSQL 适配器，其他数据库可经第三方适配器扩展；维护方表示无添加更多官方适配器的计划。

  • 提供 rails generate scenic:view / scenic:model 生成器，生成版本化 SQL 定义文件与可逆迁移
  • 支持物化视图，含 concurrently 与 cascade 刷新选项，以及 side_by_side 更新策略
  • 内置 PostgreSQL 适配器，适配器接口可配置，已有 SQLite、MySQL、SQL Server、Oracle 第三方适配器

适用场景（解读层）

  • 在 Rails 项目中用 SQL 视图承载 ActiveRecord 模型
  • 需要保持迁移历史可逆、可版本化地变更视图定义
  • 使用 PostgreSQL 物化视图并周期性刷新或建索引
