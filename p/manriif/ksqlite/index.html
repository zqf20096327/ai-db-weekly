Kotlin 多平台 SQLite 绑定库，全目标使用同一 SQLite 构建并集成多加密方案

综述（解读层）

ksqlite 为 Kotlin Multiplatform 各目标提供接近完整的 SQLite C API 绑定，所有平台共用同一套 SQLite 编译产物与版本。每个构建内置 SQLite3MultipleCiphers，支持多算法加密；提供 C API 映射层与面向对象 API 两套实现，自动加载原生库并管理内存。项目处于活跃开发中的实验状态，仅暴露 UTF-8 接口，不支持 VFS 与 wasmWasi 目标。

  • 支持 JVM、Android、Linux、Windows、macOS、iOS、tvOS、watchOS、JS、WasmJs 等 Kotlin 目标（不含 wasmWasi 与 Node.js）
  • 约 220+ SQLite C 函数绑定，含备份、快照、WAL、增量 blob I/O、虚表及自定义函数（标量/聚合/窗口）
  • 每个目标内置 SQLite3MultipleCiphers，支持 AES、ChaCha20-Poly1305、Ascon、AEGIS 等内置加密算法及 Kotlin 动态注册自定义加密器

适用场景（解读层）

  • 需要在多个 Kotlin 平台目标上使用统一版本 SQLite 的应用开发
  • 需要对数据库文件或列级数据进行加密的场景
  • 需要调用较完整 SQLite C API（如虚表、备份、快照）的 Kotlin 项目
