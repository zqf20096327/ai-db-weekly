🧭 简介解读层（AI·证据行可回查）

网络流采集、增强与可视化工具，导出至 ClickHouse

综述（解读层）

Akvorado 接收 NetFlow/IPFIX 和 sFlow 网络流数据，通过 SNMP 补充接口名称、通过 IPinfo.io 补充地理信息，随后将数据写入 ClickHouse，并提供网页界面浏览数据。项目由法国 ISP Free 开发，采用 AGPLv3 许可证，可通过 docker compose 运行，另有 Grafana 插件。

  • 接收 NetFlow/IPFIX 与 sFlow 流量数据，使用 SNMP 与 IPinfo 数据库进行接口名称与地理信息增强
  • 将数据导出至 ClickHouse，并提供网页界面浏览数据
  • 提供 Grafana 插件，可运行于 docker compose 环境

适用场景（解读层）

  • 需要集中采集与存储 NetFlow/IPFIX、sFlow 流量数据的网络运维环境
  • 需要对流量数据按接口、地理信息维度浏览分析的场景
  • 需要将流数据接入 ClickHouse 或 Grafana 进行查询与展示的环境
