基于 bitcask 论文的 Ruby 日志结构哈希 KV 存储

综述（解读层）

bitcask-rb 是一个用 Ruby 实现的持久化键值存储，基于 bitcask 论文，以日志结构文件加内存哈希表的方式组织数据，可存储超出内存容量的数据。项目定位为学习 bitcask 原理的教学实现，README 明确声明不用于生产环境，且实现为求简化省略了论文中的部分规范。安装需 Ruby 和 bundler，通过 bundle install 后以 Bitcask::DiskStore.new 创建实例，提供 put/get API，键值支持 Integer、Float、String 类型，条目含 CRC 校验。测试用 rspec 运行。

  • 提供 put 和 get 两种 API，支持 hash 风格赋值
  • 数据持久化到磁盘，键值支持 Integer、Float、String 类型，记录包含 CRC 校验
  • 基于日志结构文件与内存哈希索引，可存储超出 RAM 容量的数据

适用场景（解读层）

  • 学习 bitcask 论文的存储原理与日志结构设计
  • Ruby 项目的键值持久化实验或原型验证
  • 阅读源码理解 KV 存储的读写路径实现
