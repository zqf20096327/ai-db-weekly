🧭 简介解读层（AI·证据行可回查）

本地索引 shell 历史、git 提交与项目文档的 MCP 服务器，按 token 预算返回检索切片。

综述（解读层）

NexusMem 将 git 提交及 diff、带退出码的 shell 命令、项目文档（可选助手对话记录）索引到本地 SQLite 数据库，通过 MCP 向编码代理提供按相关性排序、受 token 预算限制的历史切片。检索基于 BM25/FTS5，可选 sqlite-vec 向量搜索做倒数排名融合。适合使用 Claude Code 等 CLI 编码代理、需要回溯本机操作历史的开发者。限制：要求 Node 22+ 与 git；向量搜索需本地 Ollama；对话记录默认关闭。数据全部留在本地，无账户与遥测，MIT 许可，npm 分发。

  • 索引 shell 命令（含退出码、工作目录、时间戳）、git 提交及逐文件补丁、项目文档到本地 SQLite 数据库，数据不出本机
  • 检索采用 BM25 over FTS5，配合可选的 sqlite-vec 向量搜索，经 Reciprocal Rank Fusion 按排名位置融合，结果按 token 预算裁剪，带 [observed]/[authored] 出处标签
  • 提供 Claude Code hook 集成（nexusmem agent install），命令失败时向代理报告该命令的历史失败记录及对应的修复命令；写入前对命令做脱敏，匹配基于命令哈希

适用场景（解读层）

  • 让编码代理查询本机 shell 历史，获取失败的命令、执行顺序及退出码等 git log 之外的信息
  • 通过失败→修复链（nexusmem sync --link-failures）检索某条失败命令后来的解决方式，支持跨项目查询（query --all-projects）
  • 在无云服务、无账户的本地环境下为 MCP 客户端提供项目历史上下文，可选本地 Ollama 生成会话摘要（qwen2.5:3b 默认，仅在摄取阶段运行）
