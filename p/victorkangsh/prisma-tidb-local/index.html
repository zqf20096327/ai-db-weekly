基于 docker-compose 运行 TiDB 集群并连接 Prisma 的本地测试环境

综述（解读层）

该仓库提供一套 docker-compose 配置，用于在本地启动 TiDB 集群（含 PD、TiKV、监控、TiDB-Vision、TiSpark 组件），并在其上部署 Prisma 服务。要求 Docker ≥17.03、Docker Compose ≥1.6.0，Mac 需 8GB 以上内存，且不支持 Docker Toolbox。README 注明当前 TiDB 无法执行多条并发的 schema 变更，DDL 需逐条执行。适用于需要在本地验证 Prisma 与 TiDB 兼容性的开发者。

  • 通过 docker-compose 一键启动 TiDB 集群及监控（Grafana :3000）、TiDB-Vision（:8010）、Spark Web UI（:8080）等组件
  • 支持通过 Helm 模板渲染自定义集群规模、镜像版本与端口映射，也支持从二进制或源码构建组件镜像
  • 提供基于 pprof 与 Graphviz 的容器内调试工具，用于分析 TiDB/TiKV/PD 实例的性能数据

适用场景（解读层）

  • 为 Prisma 项目搭建本地 TiDB 测试环境
  • 本地运行 TiDB 集群并通过 Grafana 监控与 TiDB-Vision 可视化查看状态
  • 通过 TiSpark 在 Spark Shell/PySpark/SparkR 中对 TiDB 数据执行 OLAP 查询
