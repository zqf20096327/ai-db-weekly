🧭 简介解读层（AI·证据行可回查）

在 AWS 中国区用 kops 部署 TiDB 到 Kubernetes 的操作指南文档。

综述（解读层）

该项目是一份部署指南文档，面向 AWS 中国区用户，分步骤说明如何用 kops-cn 创建 Kubernetes 集群，再通过 Helm 安装 PingCAP 的 tidb-operator 与 tidb-cluster，涵盖 values.yaml 配置、镜像源替换为中国可用地址、扩缩容、访问及资源清理。内容包含中国区特有的 ICP 备案、gcr 镜像替换等注意事项，文档以固定版本（如 tidb-operator v1.0.0）示例演示。

  • 提供从 Kubernetes 集群创建到 TiDB 安装、扩缩容、访问和资源删除的完整命令流程
  • 针对中国区环境说明镜像源替换（gcr.azk8s.cn）、ICP 备案处理与 8443 端口调整等步骤
  • 说明存储类配置要求：EBS-only 实例（如 c4/c5）需将所有组件 storageclass 改为 EBS 类型

适用场景（解读层）

  • 在 AWS 中国区（北京 cn-north-1 / 宁夏 cn-northwest-1）从零搭建 Kubernetes 并部署 TiDB
  • 需要对 TiDB 集群进行手动或通过 Cluster Autoscaler 自动扩缩容的场景
  • 排查中国区 Kubernetes 部署中的镜像拉取失败、PV 创建失败等常见问题
