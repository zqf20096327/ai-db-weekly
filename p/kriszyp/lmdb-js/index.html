🧭 简介解读层（AI·证据行可回查）

LMDB 的 Node.js/Bun/Deno 接口封装库，提供 JS 值到键值数据库的转换

综述（解读层）

lmdb-js 是 LMDB 存储引擎在 NodeJS、Bun 和 Deno 环境下的接口封装，以 NPM 包 lmdb 发布，通过 npm install lmdb 安装。它将 JS 对象、数组等值转换为二进制键值数据存入 LMDB，采用同步读、异步批量写的设计，写入操作在独立线程排队执行并返回 Promise。基于 Node-API 实现，默认使用 MessagePack 编码，键默认为 ordered-binary 且保留排序一致性。

  • 支持 JS 原始值、对象、数组、Buffer 等作为键和值，提供 msgpack、cbor、json、string、binary 等多种编码
  • 写入操作异步排队到独立线程执行，返回 Promise，并可批处理合并事务；支持条件写入与乐观锁
  • 提供可迭代的查询/游标、记录版本控制，以及可选的 LZ4 压缩（在写入线程中执行）

适用场景（解读层）

  • 在 NodeJS/Bun/Deno 应用中需要将结构化 JS 数据持久化到键值数据库的场景
  • 需要跨多进程或线程扩展的存储场景，借助记录版本控制和乐观锁实现并发
  • 构建工具缓存等用途（README 提及 Parcel、Kibana 将其用作构建缓存，HarperDB、Gatsby 将其用作存储层）
