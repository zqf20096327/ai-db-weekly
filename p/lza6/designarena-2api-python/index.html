🧭 简介解读层（AI·证据行可回查）

将 DesignArena 图像生成服务封装为 OpenAI 兼容 API 的 Python 网关

综述（解读层）

该项目基于 Playwright 无头浏览器捕获 DesignArena 的 JWT Token 与 Cookie，将其图像生成能力转换为 /v1/chat/completions 格式的 OpenAI 兼容接口，供 LobeChat、Cherry Studio 等客户端调用。需 Python 3.10+，通过 pip 安装依赖并执行 playwright install chromium，首次运行需在弹出的浏览器中手动登录；Chrome Profile 镜像同步依赖 Windows 的 Robocopy。内置多账号负载均衡、任务队列、熔断器、速率限制，并提供 PySide6 桌面界面与 Prometheus 指标端点，服务默认监听 127.0.0.1:8000。项目采用 Apache 2.0 协议。

  • 通过 Playwright Chromium 无头浏览器配合 playwright-stealth 与隐藏 webdriver 属性运行，并用全局正则从请求头嗅探 Bearer Token
  • 提供 FastAPI 异步服务，暴露 OpenAI 兼容的 /v1/chat/completions 端点，支持 SSE 流式输出与图生图（Image-to-Image），并自动生成 /docs 交互式文档
  • 实现多账号负载均衡、任务队列（3 个 worker）、熔断器、令牌桶速率限制、后台 Token 自动刷新，以及 SQLite 审计日志与 Prometheus 兼容指标、/health 健康检查端点

适用场景（解读层）

  • 需要通过 OpenAI 兼容接口（如 LobeChat、Cherry Studio 等客户端）调用 DesignArena 图像生成的用户
  • 需要批量提交生成任务并配合任务队列、多账号轮换运行自动化流程的场景
  • 需要通过 SQLite 审计日志与 Prometheus 指标追踪 API 调用记录（IP、User-Agent、时间戳）的本地部署运维场景
