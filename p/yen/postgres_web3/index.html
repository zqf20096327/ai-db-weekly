为 web3 数据提供 128/256 位整数与十六进制类型的 PostgreSQL 扩展

综述（解读层）

该扩展为 PostgreSQL 添加 int128/uint128/int256/uint256 四种整数类型及 hex160/hex256 十六进制类型，配套算术、比较、位运算符、类型转换与聚合函数，用于存储 web3 场景中的大整数与地址、区块哈希等数据。项目基于 PGXS 构建，依赖 clang16 的 C23 _BitInt 特性，源码编译需以非常规方式配置 PostgreSQL，README 建议使用预构建的 linux/amd64 Docker 镜像，安装后在数据库中执行 CREATE EXTENSION 即可启用。

  • 提供 int128、uint128、int256、uint256 与 hex160、hex256 六种数据类型，整数可从十进制字符串构造，hex 类型不保留输入大小写
  • 为上述类型实现加减乘除取模、比较、位运算符，以及 sum/min/max/avg 聚合函数和隐式/显式类型转换
  • 提供 linux/amd64 的 Docker 镜像（Docker Hub 与 GHCR），也可通过 PGXS 以 clang16 编译源码安装

适用场景（解读层）

  • 在 PostgreSQL 中存储以太坊地址（hex160）与区块哈希（hex256）等十六进制标识符
  • 存储 web3 应用中的 128/256 位大整数并直接使用 SQL 算术与位运算符
  • 其他需要超出 bigint 范围的固定宽度整数运算的通用数据库场景
