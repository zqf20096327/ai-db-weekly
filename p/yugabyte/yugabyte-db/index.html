综述（解读层）

YugabyteDB 是一个兼容 PostgreSQL 的分布式 SQL 数据库，采用 Apache 2.0 许可。它复用 PostgreSQL 查询层提供 YSQL API，另支持类 Cassandra 的 YCQL API；事务设计参考 Google Spanner，使用 Raft 共识与混合逻辑时钟实现分布式 ACID 事务。适合需要事务一致性、容错或多区域部署的云原生 OLTP 应用，可通过添加节点横向扩展。

  • YSQL 复用 PostgreSQL 查询层，支持数据类型、存储过程、触发器、扩展等 PG 特性
  • 基于 Raft 复制与混合逻辑时钟的分布式 ACID 事务，支持 snapshot、serializable、read committed 隔离级别
  • 支持多区域、多云、Kubernetes 部署，以及 xCluster 复制与只读副本

适用场景（解读层）

  • 需要分布式事务与数据一致性的云原生 OLTP 应用
  • 跨多可用区、多区域或多云的高可用部署
  • 在 Kubernetes 上运行的横向扩展关系型数据库场景
