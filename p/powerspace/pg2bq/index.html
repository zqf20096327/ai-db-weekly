pg2bq 是基于 Spark 将 PostgreSQL 表导出到 Google BigQuery 的命令行工具

综述（解读层）

pg2bq 用于将 PostgreSQL 表数据导出到 Google BigQuery，适合元数据存于 PostgreSQL、实时数据在 BigQuery 的团队。它内部使用 Spark 框架但默认以本地模式独立运行，无需 Hadoop 集群；数据先以 Avro 格式存入 GCS 以携带 schema，再通过 BigQuery 作业导入，可配合 cron 或 Airflow 定时执行。

  • 通过 JDBC 读取 PostgreSQL 表并导出为 Spark DataFrame
  • 数据以 .avro 格式写入 GCS，随数据携带 schema，无需预先创建 BigQuery 表结构
  • 启动 BigQuery 作业将 .avro 文件导入对应 BigQuery 表

适用场景（解读层）

  • 元数据在 PostgreSQL、分析数据在 BigQuery 时需要定期同步表数据
  • 配合 cron、Airflow 等调度器按固定周期执行导出任务
  • 需要在 BigQuery 中对 PostgreSQL 表数据执行 JOIN 查询的场景
