浏览器端 Analogue 3D labels.db 文件查看、编辑与生成工具

综述（解读层）

这是一个纯客户端 Web 应用，用于查看、编辑和生成 Analogue 3D 主机使用的 labels.db 标签文件。用户可加载 db 文件解析卡带签名索引与图像块、以 PNG 预览缩略图、按 CRC32 添加或替换标签图像，导出 labels_modified.db。所有处理在浏览器本地完成，不向服务器上传数据；也可通过 Docker 自托管。编辑器不计算 ROM 的 CRC32，需用户自行提供。

  • 解析 labels.db 文件头、CRC32 卡带签名索引及 BGRA 图像块，并将 74×86 像素标签图渲染为 PNG 预览
  • 支持按子字符串或逗号分隔的 CRC 搜索数据库、按区域（PAL/NTSC/NTSC-J/PAL-M）筛选、批量导出图片为 ZIP
  • 内置多阶段 Docker 构建（Node 构建 + nginx 服务 dist/），默认暴露端口 4377，无需容器外手动构建

适用场景（解读层）

  • 为 Analogue 3D 的 labels.db 添加、替换或删除游戏标签图像，导出修改后的文件替换 SD 卡中的原文件
  • 在离线或无互联网环境中使用浏览器本地解析和查看现有 labels.db 的内容
  • 通过 Docker Compose 在自托管环境中部署该编辑器静态站点
