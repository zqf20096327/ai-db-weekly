🧭 简介解读层（AI·证据行可回查）

自托管备份软件，单 Web 控制台管理服务器、虚拟机、数据库与 Microsoft 365 备份

综述（解读层）

BackupZit 是一款基于 AGPLv3 的自托管备份软件，用于备份 Windows/Linux 机器、Proxmox VE、ESXi、Hyper-V 虚拟机、SQL Server/PostgreSQL/MySQL 数据库、NAS 共享和 Microsoft 365。控制台为 Linux 服务（2 vCPU、2–4 GB 内存即可），代理直接写入存储，客户端无需开放端口；支持去重、加密、不可变备份与裸机恢复。

  • 支持文件、整盘、无代理虚拟机、数据库（含日志备份）与 Microsoft 365 备份，存储目标涵盖 SFTP、S3 兼容存储、Azure Blob、SMB 及加固仓库
  • 提供 AES-256 加密、S3 Object Lock/加固仓库不可变备份、勒索软件式批量删除检测与自动恢复测试
  • 控制台支持 14 种语言、LDAP/AD 与 SAML/OpenID Connect 单点登录、REST API（含 OpenAPI 规范）与 Prometheus 指标

适用场景（解读层）

  • 需要将服务器、虚拟机与数据库备份集中在自有网络内管理、不依赖云服务的企业环境
  • Proxmox VE/ESXi/Hyper-V（含故障转移集群）虚拟机的无代理备份与即时恢复
  • 需要裸机恢复到不同硬件、或将 Linux 系统恢复为新 Proxmox 虚拟机（P2V）的灾难恢复场景
