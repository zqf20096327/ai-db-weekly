🧭 简介解读层（AI·证据行可回查）

Windows 本地工具，同步修复 Codex 的 SQLite 与 JSONL provider，恢复侧边栏聊天记录

综述（解读层）

这是一个运行在 Windows 上的本地脚本工具，用于处理 Cursor/Codex 切换中转站、API 或模型后，会话文件仍存在但侧边栏不显示的情况。它同时修改 state_5.sqlite 和 sessions/*.jsonl 头部的 provider 字段，避免 Cursor 启动时按旧 provider 重建数据库导致记录再次隐藏。需要 PowerShell 5.1+ 和 Python 3.8+，通过 bat 图形界面或命令行操作。

  • 同时修复 SQLite 数据库与 JSONL 头部的 session_meta.payload.model_provider 字段
  • 提供全部同步、按 thread-id 选择性同步、删除（含 dry-run 预览）及手动备份/恢复功能
  • 删除时将 JSONL 移动到 history_sync_deleted 目录，操作前自动备份数据库和原文件

适用场景（解读层）

  • 切换 Cursor/Codex 中转站或 OpenAI-compatible API 后，本地 sessions 目录有 JSONL 但侧边栏不显示
  • 需要选择性迁移部分旧会话到当前 provider/model，而非全部迁移
  • 需要清理指定旧对话记录并保留备份以便找回
