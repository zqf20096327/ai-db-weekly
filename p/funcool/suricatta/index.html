基于 jOOQ 库实现的 Clojure 高层 SQL 工具集

综述（解读层）

Suricatta 是一个面向 Clojure 的 SQL 工具集，底层基于 jOOQ 库实现。它通过 Clojars 发布，以依赖方式引入项目，提供 context 建立数据库连接并执行查询，查询结果以映射形式返回。文档站点提供进一步使用说明。适合需要在 Clojure 项目中执行 SQL 的开发者。

  • 基于 jOOQ 库实现，提供高层 SQL 工具接口
  • 通过 sc/context 建立数据库连接，sc/fetch 执行查询并返回映射形式的结果
  • 使用 with-open 管理连接生命周期，经 Clojars 引入依赖

适用场景（解读层）

  • 在 Clojure 项目中连接数据库并执行 SQL 查询
  • 以依赖方式集成到基于 Clojure 的数据访问层
  • 使用 H2 等数据库进行快速查询验证
