基于 SQLAlchemy 的 Python 原生 SQL 查询库

综述（解读层）

Records 是一个用于向多种关系数据库发送原生 SQL 查询的 Python 库，面向需要直接写 SQL 的开发者。它基于 SQLAlchemy 构建，查询结果以 Record 对象返回，支持属性、键、索引三种取值方式，并提供参数化查询、事务、批量查询及 $DATABASE_URL 环境变量支持；数据库驱动需另行安装。

  • 支持 Postgres、MySQL、SQLite、Oracle、MS-SQL、RedShift 等数据库（驱动不含在内）
  • 集成 Tablib，可将查询结果导出为 CSV、XLS、JSON、HTML、YAML 或 Pandas DataFrame
  • 支持安全参数化查询、事务以及 bulk_query 批量操作

适用场景（解读层）

  • 在 Python 中直接执行原生 SQL 并以对象方式读取结果
  • 将查询结果导出为 CSV/Excel/JSON 等格式用于生成报告或数据分享
  • 通过命令行 records 工具导出查询结果
📖 README 首段存档原文 · 程序抽取

Records is a very simple, but powerful, library for making raw SQL queries to most relational databases.
