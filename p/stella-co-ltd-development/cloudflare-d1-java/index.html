非官方的 Cloudflare D1 REST API Java 客户端 SDK

综述（解读层）

cloudflare-d1-java 是一个面向 Cloudflare D1 REST API 的非官方 Java SDK，与 Cloudflare 无隶属关系。它提供同步 D1Client 和异步 D1AsyncClient 两类客户端，支持查询、取首行、执行写入、批量操作及 Jackson 类型映射，内置针对瞬时读失败的默认重试策略。要求 Java 8 及以上，运行时仅依赖 jackson-databind；README 明确其定位不含 JDBC、ORM、SQL 构建器或迁移工具。凭据通过环境变量或 builder 显式配置，API token 需具备 D1 编辑权限。

  • 提供同步 D1Client 与基于 CompletableFuture 的 D1AsyncClient，支持 query、queryFirst、raw、execute、batch 及类型化行映射
  • 默认对读操作在 429、500、502、503、504 及瞬时网络失败时重试，写操作默认不重试，重试策略可通过 D1RetryPolicy 自定义或关闭
  • 仅依赖 jackson-databind，默认传输基于 Java 标准库，允许替换自定义 transport，兼容 Java 8

适用场景（解读层）

  • 服务器端 Java 工具、管理任务、批处理作业或迁移类工作流中通过 REST API 直接访问 D1 数据库
  • 需要将查询结果映射为 Map 或 Jackson 模型类的 Java 应用
  • 运行在 Java 8 环境的旧工具链中调用 D1（注意 README 建议延迟敏感流量考虑 Worker 代理或 Workers D1 绑定）
