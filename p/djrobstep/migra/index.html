已停止维护的 PostgreSQL 架构差异比较工具，用 Python 编写

综述（解读层）

migra 是一个用 Python 编写的 PostgreSQL schema diff 工具，可比较两个数据库架构并生成迁移所需的 SQL 语句，支持在 Python 脚本或命令行中运行。项目已正式废弃，最终版本为 2022 年 9 月 18 日的 3.0.1663481299，不再有后续发布。其功能已在另一项目中延续。

  • 比较两个 PostgreSQL 数据库的 schema 差异
  • 自动生成从状态 A 到状态 B 所需的 SQL 迁移语句
  • 可作为 Python 库调用或通过命令行使用

适用场景（解读层）

  • 对比开发库与生产库的 schema 差异并生成变更 SQL
  • 在 Python 脚本中集成 schema 比较与迁移脚本生成流程
  • 从应用模型自动同步开发数据库的 schema
