🧭 简介解读层（AI·证据行可回查）

基于 Docker Compose 的便携式数据栈，用 Airflow 编排 dbt 模型运行于 DuckDB 并以 Superset 展示

综述（解读层）

该项目是一个面向虚构明信片公司的示例数据集市与分析套件，通过 Docker Compose 将 generator、dbt、Airflow、Superset 四个服务组装起来：Python 脚本生成示例 parquet 数据，Airflow 触发 dbt-core 在 DuckDB 中建模，Superset 提供查询与可视化界面（含预置 dashboard）。dbt 模型和 Superset 构建自 postcard-company-datamart 仓库，通过 DATAMART_REF 变量指定版本。适合本地学习数据栈或演示流程的读者。

  • 提供 run_dbt 与 run_dbt_individual_models 两个 DAG，后者从 dbt 编译后的 manifest.json 为每个模型生成独立任务
  • generator、dbt 项目与 Superset 镜像在构建时直接从 postcard-company-datamart 仓库按 DATAMART_REF 标签拉取，各容器共享同一模型与 dashboard
  • DuckDB 数据文件位于 shared/db/datamart.duckdb，可在 Superset（端口 8088）之外直接连接查询

适用场景（解读层）

  • 在本地通过 Docker Compose 学习 Airflow 编排 dbt-core 构建数据集市的流程
  • 使用同一 dbt 数据模型对比不同编排工具（Mage、Dagster、SQLMesh 等）的实现方式
  • 对生成的示例数据集进行 Superset 可视化探索或直接连接 DuckDB 文件查询
