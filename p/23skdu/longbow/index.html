基于 Apache Arrow Flight 的分布式向量引擎，面向 Agent 内存共享场景

综述（解读层）

Longbow 是用 Go 编写的分布式向量引擎，通过 Arrow Flight（gRPC/HTTP2）提供零拷贝数据路径，采用共享无（shared-nothing）架构、SWIM 协议成员管理和一致性哈希分片，面向 AI/Agent 工作负载的内存共享。支持多种向量类型与距离度量、HNSW 检索、WAL 与 Parquet 快照持久化，可通过环境变量配置并暴露 Prometheus 指标。运行需 Go 1.27.4+，GPU 加速需单独编译对应二进制。

  • 基于 Apache Arrow Flight 协议，将数据端口（3000）与元数据端口（3001）分离为两个 gRPC 服务器，并同时提供 REST v1 和 GraphQL 接口
  • 支持多向量数据类型（float32/16/64、int8-64、complex、turboquant，维度 128–3072），带 SIMD 内核（AVX2/AVX-512/Neon）与可插拔距离度量（欧氏、余弦、点积）
  • 搜索模式包含 Dense ANN/k-NN、稀疏/BM25、混合（RRF）、地理空间、时序、GraphRAG、联邦跨集合检索等；存储为内存临时存储，配合 io_uring 可选 WAL 与 Parquet 快照

适用场景（解读层）

  • 需要多节点集群部署的 Agent 记忆/向量数据共享与高吞吐读写场景
  • 需要通过 Go SDK 智能客户端进行透明路由请求的应用
  • 需要 Prometheus 指标监控与结构化日志可观测性的向量检索服务部署
