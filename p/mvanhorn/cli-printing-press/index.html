读取 API 文档生成 Go CLI、MCP 服务器与技能的生成器

综述（解读层）

cli-printing-press 是一个用 Go 编写的 CLI 生成器，读取 API 文档或网站流量，生成面向 AI agent 的 Go CLI 及配套 MCP 服务器和 Claude Code 技能。生成物支持本地 SQLite 存储、FTS5 全文搜索、复合命令、管道自动 JSON 输出与类型化退出码。使用需 Go 1.26.11+、Node/npm 及支持 skills 的 agent；主要面向使用 Claude Code 或 Codex 的开发者。

  • 生成 Go CLI 与 MCP 服务器，无需 OpenAPI 规范，支持 REST、GraphQL 或浏览器嗅探流量
  • 生成的 CLI 包含本地 SQLite 存储、FTS5 搜索、增量同步及 --data-source local/live/auto 选项
  • 管道输出自动 JSON，提供 --compact 与类型化退出码（0/2/3/4/5/7）

适用场景（解读层）

  • 为没有官方 API 的网站（如航班查询）生成可编程访问的 CLI
  • 为有文档的 API 生成本地缓存与复合查询 CLI
  • 在 Claude Code 或 Codex 工作流中为 AI agent 提供 token 节省的命令行接口
