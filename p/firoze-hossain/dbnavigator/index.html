🧭 简介解读层（AI·证据行可回查）

基于 JavaFX 的桌面多引擎数据库客户端与 SQL IDE，支持 SQL 数据库和 MongoDB。

综述（解读层）

DBNavigator Pro 是用 Java 和 JavaFX 构建的桌面数据库管理工具，将 PostgreSQL、MySQL、MariaDB、SQL Server、Oracle、SQLite、StratosDB 与 MongoDB 纳入统一界面，提供模式树、SQL 控制台、数据编辑器、ER 图与 Mongo Shell 控制台。面向开发者、DBA 和数据分析师；macOS 包未经 Apple 签名，首次启动需手动绕过 Gatekeeper。

  • 支持 8 种数据库引擎，各引擎通过官方 JDBC/驱动连接，同一界面提供模式浏览、查询控制台与数据编辑
  • SQL 控制台包含光标处语句执行、命名参数绑定、模式感知自动补全、服务端游标分页、EXPLAIN 执行计划查看与本地查询历史
  • 提供全库/单表 ER 图（Sugiyama 分层布局与正交连线、PNG 导出）、MongoDB Shell 语法控制台，以及导出 CSV/TSV/HTML/XML/Markdown/JSON

适用场景（解读层）

  • 在多数据库引擎间切换使用的开发与运维场景，统一管理连接、模式结构与查询脚本
  • 通过 ER 图查看表结构与主外键关系，或通过内置编辑器对表格数据进行带暂存的修改与批量提交
  • 使用 Mongo Shell 语法直接对 MongoDB 执行 find/insert/update/delete 等命令并浏览文档
