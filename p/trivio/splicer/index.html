在 Python 项目中以 SQL 查询多种异构数据源的模块

综述（解读层）

Splicer 是一个 Python 模块，让来自不同来源的数据以表的形式被 SQL Select 语句查询。分析师可定义 Dataset 并挂接 Python 编写的用户自定义函数；扩展开发者可编写扩展将 REST 接口、日志文件、NoSQL、数据库、CSV 文件映射为表。若数据源本身支持 join 等能力则交由其执行，否则在本地完成运算。README 未包含安装与运行命令。

  • 支持用 SQL Select 语句查询由多个外部表组成的 Dataset
  • 支持以 Python 编写用户自定义函数并接入查询
  • 数据源支持 join 等能力时由其执行，缺失时由 Splicer 本地补偿实现

适用场景（解读层）

  • 对 CSV、日志文件、REST 接口等数据源执行一次性查询
  • 编写声明式风格的 ETL 脚本
  • 将多种异构数据源组合为可查询的视图
