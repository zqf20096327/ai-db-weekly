🧭 简介解读层（AI·证据行可回查）

基于 Valkey 的开源键值引擎，通过 spill 模块将被逐出的键透明持久化到磁盘。

综述（解读层）

DiceDB 是 Valkey（Redis 的分支）的一个分支，扩展了内存缓存之外的分层存储能力，同时保持与 Valkey/Redis 工具链和 SDK 兼容。其核心 dicedb-spill 模块基于 RocksDB，将被逐出的键写入磁盘并在缓存未命中时恢复，从而在固定内存预算内支持更大的工作集。适合已有 Redis/Valkey 使用经验、需要磁盘分层存储的团队；README 同时提到日志和代码中仍可能保留 Valkey 引用。

  • 与 Valkey 和 Redis 的工具链及 SDK 生态兼容，兼容的客户端均可连接
  • 提供 dicedb-spill 模块，将被逐出的键透明持久化到 RocksDB 并在缓存未命中时恢复，支持设置内存上限
  • 支持 Linux、macOS、OpenBSD、NetBSD、FreeBSD，含大/小端及 32/64 位架构，可用 Docker 镜像或源码构建运行

适用场景（解读层）

  • 在固定内存预算内运行大于内存容量的键值工作集的场景
  • 需与现有 Redis/Valkey 客户端和工具链兼容的部署环境
  • 需源码编译或 Docker 快速启动的自托管键值存储场景

DiceDB is a fork of Valkey (a fork of Redis). DiceDB extends Valkey with additional capabilities while staying fully compatible with Valkey and Redis tooling and SDK ecosystem.
