在 Visual Studio 中配置 MySQL + Entity Framework Code First 的教程项目

综述（解读层）

该项目是一份图文教程，演示如何在 .NET 项目中通过 MySQL Connector/NET 接入 Entity Framework 6.1+ 并启用 Code First 迁移。内容涵盖安装 EF 与 MySQL.Data/MySQL.Data.Entity 程序集、编写连接字符串与 entityFramework 配置、定义模型类与 DbContext（使用 MySqlEFConfiguration 特性），以及 Enable-Migrations、Add-Migration、Update-Database 三步迁移流程，并附 TypeLoadException 的降级版本处理方法。面向使用 Visual Studio 的 .NET 开发者，README 注明同样适用于 MariaDB。

  • 提供从 NuGet 安装 EntityFramework 与 MySQL.Data/MySQL.Data.Entity 程序集的完整步骤
  • 给出 Web.Config/App.Config 中的连接字符串与 entityFramework 提供程序配置示例
  • 演示 DbContext 上使用 [DbConfigurationType(typeof(MySqlEFConfiguration))] 的代码级配置方式

适用场景（解读层）

  • 在 Visual Studio 中为 .NET 项目搭建基于 MySQL 的 EF Code First 环境
  • 为现有 MySQL 或 MariaDB 数据库创建 Code First 模型与 DbContext
  • 排查添加迁移时出现的 System.TypeLoadException（回退安装旧版 MySQL 包）
