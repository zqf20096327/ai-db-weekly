PGMQ 消息队列的 Go 客户端，基于 pgx 驱动访问 Postgres

综述（解读层）

pgmq-go 是 Postgres Message Queue (PGMQ) 的 Go 语言客户端库，其实现参考了 Rust 客户端。库依赖 pgx，多数函数的第二个参数接受满足 DB 接口的任意类型，如 *pgx.Conn、*pgxpool.Pool 或 pgx.Tx。使用前需部署安装了 PGMQ 扩展的 Postgres 实例，README 提供 Docker 镜像与 Go 代码示例。

  • 提供 PGMQ 扩展的 Go 客户端 API，实现参考 Rust 客户端
  • 基于 pgx 工作，函数接受 *pgx.Conn、*pgxpool.Pool、pgx.Tx 等满足 DB 接口的类型
  • README 提供带 PGMQ 扩展的 Postgres Docker 镜像启动方式及使用示例

适用场景（解读层）

  • 在 Go 项目中通过 PGMQ 扩展实现基于 Postgres 的消息队列读写
  • 已使用 pgx 的应用中接入 PGMQ，复用现有连接、连接池或事务对象
  • 通过 Docker 快速启动带 PGMQ 扩展的 Postgres 进行本地开发测试
