面向大规模工作负载的派生数据存储平台，支持批流混合读写

综述（解读层）

Venice 是一个派生数据存储平台，提供批量与流式异步写入、低延迟在线读取、跨区域主动-主动复制（CRDT 冲突解决）及多集群、多租户支持。它可承载 Feature Store 等有状态组件，AI 应用将 ML 训练输出写入后供在线推理查询。Java 项目经额外仓库定义添加依赖，非 Maven Central 发布。

  • 支持批量推送、增量推送、流式写入、Write Compute 部分更新及混合存储
  • 提供 Thin/Fast/Da Vinci 三类客户端，读延迟分别低于 10ms、2ms、1ms，共享同一套 API
  • 提供读计算服务端操作（点积、余弦相似度、字段投影）及 CDC 变更数据捕获

适用场景（解读层）

  • 作为 Feature Store（如 Feathr）的存储后端，支撑在线推理读取
  • ML 训练产出数据的批量/增量发布与低延迟在线查询
  • 通过 CDC 流式同步数据变更，用于客户端侧索引构建
