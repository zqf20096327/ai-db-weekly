🧭 简介解读层（AI·证据行可回查）

一个面向 TiDB 集群管理的 ticat 模块仓库，通过 ticat hub 加载使用

综述（解读层）

该仓库为 ticat 工具提供 TiDB 集群管理模块，包含集群创建、销毁、启动、停止及 MySQL 连接等功能，主机操作（如 raw-backup）处于部分实现状态，自动配置部署尚未完成。使用者需先安装 ticat，并通过 hub.add 命令加载本仓库。

  • 提供 TiDB 集群的创建、销毁、启动与停止模块
  • 提供 TiDB 与 MySQL 的连接功能
  • 附带子仓库 innerr/ssh-based.tidb.ticat（基于 ssh 的 TiDB 集群工具箱）

适用场景（解读层）

  • 通过 ticat 管理本地 TiDB 集群的生命周期操作
  • 需要以命令方式连接 TiDB/MySQL 的场景
