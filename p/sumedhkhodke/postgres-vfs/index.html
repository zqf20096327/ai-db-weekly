基于 PostgreSQL 的 AI Agent 虚拟文件系统，支持 bash 命令

综述（解读层）

postgres-vfs 是一个用 PostgreSQL 作为存储的虚拟文件系统，面向 AI Agent。它基于 TypeScript 解释器 just-bash 实现自定义 IFileSystem，将文件系统调用编译为 SQL，数据存储在 vfs_files 表中。Agent 通过 bash/readFile/writeFile 三个工具执行 75+ Unix 命令；依赖 PostgreSQL ≥14（Node ≥18 或 Bun ≥1.0），语义搜索需额外配置 pgvector 和 OPENAI_API_KEY。

  • 提供 75+ bash 命令（grep、find、sed、awk、jq 等），由 just-bash 解释并通过 IFileSystem 编译为 SQL 执行
  • 三层搜索：tsvector 全文检索、pg_trgm 模糊/正则匹配，配置 OPENAI_API_KEY 后经 pgvector 附加语义搜索，写入时自动生成嵌入
  • 通过 PostgreSQL Row-Level Security 实现 tenant_id 行级多租户隔离，数据持久于 vfs_files 与 vfs_symlinks 两张表

适用场景（解读层）

  • 为 AI Agent 提供持久化、多租户隔离的文件工作区
  • 在无真实沙箱/容器的环境下让 Agent 运行 bash 命令操作文件
  • 对 Agent 工作区文件执行全文、模糊或向量混合检索
