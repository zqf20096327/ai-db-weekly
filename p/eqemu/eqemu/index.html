开源《EverQuest》服务器模拟器平台，基于逆向工程的 C++ 服务端

综述（解读层）

EQEmu 是社区驱动的经典 MMORPG《EverQuest》服务器模拟器，未使用原始源码，通过协议解码与行为研究以洁净室方式重建服务端。核心为 C++ 引擎，后端采用 MySQL/MariaDB（200+ 表结构），支持 Perl/Lua 脚本编写任务与 NPC 行为，跨 Linux 与 Windows 平台，提供 Docker 镜像。适用于希望自建并自定义服务器的玩家与开发者，项目采用 GPLv3 许可，为非商业性质。

  • C++ 核心引擎，支持 Linux 和 Windows 跨平台运行
  • MySQL/MariaDB 后端，包含 200+ 张表的数据库结构
  • 原生支持 Perl 和 Lua 脚本扩展任务、NPC 行为与自定义事件

适用场景（解读层）

  • 自建并运营自定义的 EQ 游戏服务器
  • 编写任务、NPC 行为与游戏事件脚本
  • 游戏协议研究与服务器技术学习
