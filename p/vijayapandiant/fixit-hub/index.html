🧭 简介解读层（AI·证据行可回查）

自托管的实时错误追踪与异常监控平台，结合 Gemini AI 生成诊断。

综述（解读层）

FixIt Hub 是一个自托管错误追踪与异常监控平台，采用 monorepo 组织多个服务：Go 守护进程将异常日志写入 ClickHouse 并向 Redis 队列投递任务，Node.js worker 计算 MD5 指纹去重并调用 Gemini API 生成根因分析，Spring Boot 3 提供基于 JWT 的管理 API，前端为 React 19 仪表盘。依赖 PostgreSQL、Redis、Elasticsearch，通过 docker-compose 启动整套容器。适合需要自建错误监控并希望接入 LLM 诊断的开发团队。

  • Go 摄入守护进程将原始异常日志写入 ClickHouse，并通过 Redis 队列异步触发去重与 AI 诊断
  • Node.js worker 使用 MD5 stacktrace 指纹聚合重复崩溃，并调用 Gemini API（默认 gemini-1.5-flash）生成根因分析与修复建议
  • Spring Boot 3 提供 JWT 认证、问题生命周期管理、Elasticsearch 全文检索，以及异步的 Slack/Discord webhook 告警

适用场景（解读层）

  • 自托管收集多应用运行时异常并按指纹聚合成可分派的问题
  • 接入 Slack/Discord webhook 在新崩溃或重开崩溃时通知团队
  • 使用 Gemini API 生成错误根因解释与代码修复建议供开发者分诊参考
