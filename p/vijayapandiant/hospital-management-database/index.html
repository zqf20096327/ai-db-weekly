🧭 简介解读层（AI·证据行可回查）

医院管理系统的 SQL 关系数据库设计，含建表、示例数据与分析查询脚本

综述（解读层）

该项目提供一套用于医院管理的标准化关系数据库设计，分为 schema、示例数据、报表查询三个 SQL 脚本，覆盖患者、医生、预约、治疗、账单、支付六张核心表。可用于医疗类应用的后端数据基础搭建或 SQL 学习练习，支持在 PostgreSQL、MySQL、SQL Server 中运行。

  • 包含 Patients、Doctors、Appointments、Treatments、Bills、Payments 六张核心表，使用主键、外键及 NOT NULL 约束
  • 提供六个分析查询示例：医生工作量、患者完整病史、应收账款、预约冲突检测、科室收入、预约状态统计
  • 按 1NF/2NF/3NF 规范化设计，兼容 PostgreSQL、MySQL、SQL Server

适用场景（解读层）

  • 医疗应用、临床看板或医院管理软件的后端数据基础搭建
  • 数据库课程或学习中的关系建模与 SQL 查询练习
  • 使用示例数据测试报表与仪表盘场景
