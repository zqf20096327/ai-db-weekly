IndexedDB 示例库，以原生、企业分层、DSL 三种实现对同一数据库操作

综述（解读层）

该仓库提供 IndexedDB 的三套示例实现：原生 API 版、分层架构封装版和 DSL 声明式封装版，各自以单文件或多模块结构组织。README 逐项列出每种实现的目标、结构、优缺点，用于展示不同抽象层级下访问浏览器 IndexedDB 的写法差异。安装依赖后通过 node 启动本地服务器在浏览器查看，面向学习 IndexedDB 用法的开发者。

  • 提供原生、企业分层、Pragmatic DSL 三种 IndexedDB 实现，含代码结构与各自优劣说明
  • DSL 版支持声明式查询与模式定义，如 db.select 按 store/where/order 查询
  • 企业版实现 Database、Repository、Service 等分层抽象，并提供 UI 自动绑定的 action 方法

适用场景（解读层）

  • 学习 IndexedDB 原生 API 的 open、transaction、objectStore 用法
  • 对比不同抽象层级封装 IndexedDB 的代码组织方式
  • 了解声明式 DSL 查询与模式定义在浏览器存储中的写法
