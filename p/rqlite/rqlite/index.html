基于 SQLite 的分布式关系数据库，通过 Raft 实现多节点复制与容错

综述（解读层）

rqlite 是用 Go 编写的分布式关系数据库，底层使用 SQLite 存储引擎，借助 Raft 共识协议在多节点间复制数据。项目以单个二进制文件分发，无外部依赖，也可通过 Docker 运行。操作接口为 HTTP API，并附带 CLI、控制台和客户端库。适用于需要 SQL 能力与数据多副本的场景。

  • 通过 SQLite 提供完整 SQL 支持，含全文搜索、JSON 支持，并可加载 SQLite 扩展
  • 基于 Raft 的多节点复制，单节点故障不影响集群，支持通过 Kubernetes、Consul、etcd 或 DNS 自动组网
  • 提供 HTTP API、原子化多条 SQL 执行、变更数据捕获（CDC）、热备份及向 S3/MinIO/Google Cloud 的自动备份，支持 TLS 加密与认证授权，读一致性和持久性可调

适用场景（解读层）

  • 需要容错存储重要关系型数据的云上服务部署
  • 边缘环境中需要数据多副本的可靠应用
  • 通过单个 Docker 命令或单二进制文件快速启动并组成多节点集群的开发与运维场景
