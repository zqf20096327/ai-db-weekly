在 AWS 上创建数据库实验环境的命令行工具

综述（解读层）

easy-db-lab 用于在 AWS EC2 上自动化创建用于测试、基准测试和学习的数据库实验环境，支持 Cassandra、ClickHouse 及任意兼容 Kubernetes 的数据库。它通过 Packer 构建预装多版本数据库的 AMI，在节点上运行 K3s，并内置 Prometheus、Grafana、OpenTelemetry 等观测组件。使用需配置 AWS 凭证和四项 IAM 策略；Homebrew 或发布版安装目前要求使用 us-west-2 区域。README 建议使用独立的 AWS 账户以实现资源和成本隔离。

  • 支持 Apache Cassandra 2.2 至 trunk 版本、混合版本集群、自定义分支，以及带可配置副本的分片 ClickHouse 集群，并可通过 Kubernetes 清单部署任意 K8s 兼容数据库
  • 通过 Packer 构建单个 AMI，预装多个 Cassandra 版本、ClickHouse、bcc-tools、async-profiler、cassandra-easy-stress 和 K3s
  • 内置 Prometheus/Grafana 仪表盘、OpenTelemetry 追踪、火焰图与内核级性能指标；提供 REPL 模式 CLI、REST 状态端点和 Homebrew/Docker 两种安装方式

适用场景（解读层）

  • 在隔离的 AWS 环境中搭建 Cassandra 集群，进行版本切换（如 use 4.1 配合 -j 指定 Java 版本）、配置修改与压力测试
  • 为 ClickHouse、OpenSearch、Spark EMR 等数据组件搭建可观测的测试与基准环境
  • 通过容器镜像在 CI/CD 流水线中运行环境创建命令
