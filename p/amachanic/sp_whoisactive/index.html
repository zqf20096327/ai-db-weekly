SQL Server 活动监控存储过程，支持单脚本安装运行

综述（解读层）

sp_WhoIsActive 是一个用于监控 SQL Server 活动的存储过程，以单脚本形式分发。它支持 SQL Server 2005 至 2022 以及 Azure SQL DB，旧版本可使用仓库中 2019 或 2008 文件夹内对应脚本。安装方式为在 SQL Server Management Studio 中打开脚本并运行，脚本会在当前连接会话所在数据库中创建存储过程；如需从实例中任意数据库调用，可将数据库切换为 master。许可证为 GPLv3。

  • 提供单脚本存储过程，在 SSMS 中运行即可安装
  • 支持 SQL Server 2005 至 2022 及 Azure SQL DB，并按版本提供对应分支脚本
  • 版本号格式 vAABB.YYYYMMDD 标明支持的最低/最高 SQL Server 版本及发布日期

适用场景（解读层）

  • DBA 或运维人员需要查看 SQL Server 实例当前活动会话时
  • 需要覆盖多版本 SQL Server 环境（含 Azure SQL DB）的活动监控场景
