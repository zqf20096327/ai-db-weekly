基于终端的键盘驱动 SQL 客户端，Go 编写的单个静态二进制

综述（解读层）

squi 是一个运行在终端中的 SQL 客户端，支持 PostgreSQL、MySQL、MariaDB、ClickHouse、SQL Server、Azure SQL 和 SQLite。它面向需要在本地或经 SSH 连接服务器上浏览 schema、编写和执行 SQL、编辑数据的开发者。程序由 Go 编写为单个静态二进制，提供多标签编辑器、语法高亮与自动补全；生产环境可启用只读连接、破坏性语句确认和默认 30 秒语句超时。许可证为 MIT。

  • 支持六种数据库（PostgreSQL、MySQL、MariaDB、ClickHouse、SQL Server/SQLite），可通过 SSH bastion、~/.ssh/config 别名和 ProxyJump 链连接，不在本地开放端口
  • 提供多标签查询编辑、上下文感知自动补全、流式结果网格（排序/过滤/以 CSV、JSON、INSERT、Markdown 等格式复制）、外键导航与内联编辑（生成 SQL 在单事务中应用）
  • 包含面向生产环境的安全机制：只读连接、破坏性语句的类型化确认、prod 标红状态栏与默认 30 秒语句超时，以及 `squi diff` 生成对齐两环境 schema 的 ALTER 脚本

适用场景（解读层）

  • 在终端中浏览和查询多种数据库的 schema、表结构与执行计划（EXPLAIN）
  • 通过 SSH 连接远程或生产数据库，在只读保护与语句超时下执行查询和受控的数据编辑
  • 导入/导出 CSV、TSV、JSON、SQL 数据，以及比较 staging 与 prod 环境的 schema 差异并生成 ALTER 脚本
