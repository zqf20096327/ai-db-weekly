Go 编写的自托管 OAuth2/OIDC 身份提供方，单二进制内嵌 SQLite 运行

综述（解读层）

Auténtico 是一个用 Go 实现的自托管 OAuth2/OIDC 身份提供方（IdP），将登录、MFA、Passkey、会话管理、令牌签发与管理界面打包为单个二进制，状态存储于单一 SQLite 文件，无需外部数据库或缓存。协议实现含授权码+PKCE、令牌自省/撤销、OIDC Discovery、RS256 JWT。README 明确其不适用于需水平扩展、多区域部署或 SCIM/LDAP 等企业合规场景。

  • 支持授权码流+PKCE、刷新令牌、令牌自省（RFC 7662）与撤销（RFC 7009）、OIDC Discovery 与 RS256 签名 JWT
  • 认证方式涵盖密码、WebAuthn Passkey、TOTP 与邮件 OTP，支持密码/密码+Passkey/仅 Passkey 三种运行时可切换模式
  • 内置编译进二进制的 React 管理 UI，支持 REST API 动态客户端注册与按客户端的配置覆盖

适用场景（解读层）

  • 为小型团队或自托管应用的 OAuth2/OIDC 登录提供集中式身份服务
  • 作为 CI/测试套件中的真实 OIDC 测试桩（启动约 375ms，无需 Docker 或 mock）
  • 需要脱离第三方服务实现用户认证的个人项目与独立开发者场景
