APIJSON 协议的 .NET Core 后端实现，基于 JSON 自动生成增删改查接口

综述（解读层）

该项目是 APIJSON 协议的 C# .NET Core 版后端实现。APIJSON 是一套 JSON 网络传输协议及其 ORM 库，前端通过请求 JSON 定制返回的数据与结构，后端据此自动生成增删改查、复杂查询及简单事务的接口，减少手写接口和文档的工作。从主题标签看，其实现基于 SqlSugar，支持 MySQL 与 SQL Server。适合前后端分离的中小型项目使用。

  • 根据请求 JSON 自动实现增删改查、模糊搜索、正则匹配、远程函数等接口
  • 自动生成接口文档，支持自动校验与格式化
  • 支持 MySQL 与 SQL Server 数据库，基于 .NET Core 与 SqlSugar

适用场景（解读层）

  • 前后端分离项目中由前端定制返回 JSON 数据与结构
  • 中小型项目或企业自用项目快速提供通用数据接口
  • 配合 APIAuto 等生态工具进行接口管理、文档生成与回归测试
