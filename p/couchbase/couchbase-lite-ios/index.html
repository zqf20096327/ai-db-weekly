面向 iOS/macOS 的嵌入式可同步文档型 NoSQL 数据库引擎

综述（解读层）

Couchbase Lite for iOS/macOS 是一个嵌入式的文档导向 NoSQL 数据库引擎，支持数据同步，其实现基于跨平台的 Couchbase Lite Core，包含 CRUD、查询与文档版本管理功能。提供 Objective-C 与 Swift 两套 API，分社区版与企业版，可经 Swift Package Manager 或 CocoaPods 集成，也可用脚本自行构建 XCFramework。要求 iOS 15.0+、macOS 13.0+。

  • 提供嵌入式文档导向存储，基于 Couchbase Lite Core 实现 CRUD、查询与文档版本管理
  • 提供 Objective-C 与 Swift 两套 API，社区版与企业版均可通过 Swift Package Manager 或 CocoaPods 安装
  • 提供 build_xcframework.sh 脚本，可分别构建 Swift 或 Objective-C 的 XCFramework

适用场景（解读层）

  • 需要本地数据存储与可同步能力的 iOS / macOS 应用开发
  • 使用 Swift Package Manager 或 CocoaPods 管理依赖的 Xcode 项目集成
  • 需要自行编译 Swift 或 Objective-C XCFramework 的构建流程
