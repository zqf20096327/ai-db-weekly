Couchbase Lite 嵌入式 NoSQL 数据库的 C 语言 API 绑定

综述（解读层）

couchbase-lite-c 为 Couchbase Lite 可同步嵌入式 NoSQL 数据库提供纯 C API，附 C++ 封装（内联调用 C 实现，API 尚未定稿），也可作为 Python、Rust、Go 等语言绑定的基础。数据模型为无模式 JSON，支持 CRUD、N1QL 查询、全文检索、二进制附件，以及与 Couchbase Server 的双向多主复制。通过 CMake 构建，依赖 C++ 标准库、libz、ICU 等；数据库加密仅企业版提供。

  • 提供无模式 JSON 数据模型、CRUD 操作、基于 N1QL 的查询语言、JSON 属性索引与全文检索
  • 支持与 Couchbase Server 的多主双向复制，基于 WebSocket 协议传输文档增量，含 TLS/SSL 与重试机制
  • 官方支持 macOS、Debian/Ubuntu、Windows、iOS、Android 等平台，可在数百 MB 内存级别的嵌入式 Linux 设备上运行

适用场景（解读层）

  • 需要在本地设备上存储与查询 JSON 文档的嵌入式或移动应用
  • 需与 Couchbase Server 进行数据同步的离线优先应用
  • 为 Python、Rust、Go 等语言构建 Couchbase Lite 绑定的开发工作
