🧭 简介解读层（AI·证据行可回查）

自托管的 MCP 服务器，用于让 AI 客户端连接并操作 Couchbase 数据

综述（解读层）

该项目提供两个 MCP 服务器：operational 服务器通过 couchbase Python SDK 连接 Capella 或自托管的 Couchbase 集群，提供 52 个工具；operational-insights 服务器连接自托管 Operational Insights 集群，提供 13 个工具。默认只读模式，写工具不加载，支持 STDIO 与 Streamable HTTP 传输及 OAuth 2.1。经 PyPI、Docker 或源码分发，需 Python 3.11+。

  • 默认只读模式，写工具不加载，可禁用单个工具或要求用户确认，支持用户名密码或 mTLS 证书认证
  • operational 服务器包含集群健康、schema 发现、KV 操作、SQL++ 查询、索引、全文与向量搜索等 52 个工具
  • 支持 STDIO 本地传输和带 OAuth 2.1、健康检查、审计日志的 Streamable HTTP 传输

适用场景（解读层）

  • 在 Claude Desktop、Cursor、VS Code 等 MCP 客户端中通过自然语言查询 Couchbase 的 bucket、schema、文档或执行 SQL++ 查询
  • 检查集群健康状况、服务状态、索引统计与查询性能分析
  • 在 CB_MCP_READ_ONLY_MODE=false 时执行文档写入、scope/collection 创建与索引管理等写操作
