🧭 简介解读层（AI·证据行可回查）

任务无关的开源 AI 竞赛平台外壳，提供报名、提交、排行榜与租约机制

综述（解读层）

这是一个用于运行 AI 竞赛的开源外壳，不含任何任务实现、数据集或评分密钥，由运营方在壳外自行提供。后端为 FastAPI，前端为 Next.js，数据库为 PostgreSQL；MCP 提交客户端走同一认证 API 而非直写数据库，worker 依赖到期租约防止过期结果发布。适合需要自行组织竞赛并搭建沙箱执行参赛代码的运营方。本地可用 Docker Compose 或 just 命令启动。

  • 提供注册、组队、定时任务揭示、端点与工件提交、排行榜、决赛、证书等竞赛流程组件
  • MCP 提交工具与浏览器共用同一认证 API，不直接写数据库；验证器按配置任务在到期租约下认领，租约栅栏阻止过期 worker 发布结果
  • 仓库不含任务实现、测试数据、评分密钥等事件相关数据；上传代码按敌意输入处理，自带模板不执行参赛代码

适用场景（解读层）

  • 运营方自建 AI 竞赛（报名、提交、排行榜、决赛全流程）
  • 参赛者或 agent 通过 MCP 客户端列出任务、提交并查询结果
  • 需隔离信任边界、由运营方自备沙箱与评分环境的比赛场景
