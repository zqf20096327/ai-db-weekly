基于 Nacos v2.2.1 源码适配达梦数据库的构建方案与容器化脚本

综述（解读层）

该项目记录将 Nacos 2.2.1 源码改造为支持达梦数据库的完整流程：引入 DmJdbcDriver18 驱动、修改 ExternalDataSourceProperties 与数据源插件模块并新增 Dm Mapper 实现类、提供达梦建表 SQL，并给出 Maven 打包与 Docker 镜像构建、运行脚本。面向需要在达梦数据库上运行 Nacos 的运维与开发人员。README 未提供适配的测试覆盖情况说明。

  • 在 nacos-datasource-plugin 模块新增达梦实现的 Mapper 类并注册到 Mapper 文件
  • 提供达梦数据库建表 SQL 与 Maven 打包命令
  • 提供 Dockerfile、镜像构建及容器启停、日志查看脚本

适用场景（解读层）

  • 需要在达梦数据库环境中部署 Nacos 配置/注册中心
  • 需要构建支持达梦的 Nacos Docker 镜像并容器化运行
  • 需要参考 Nacos 数据源插件扩展方式的改造过程
