基于 Vue + Element UI 的离线工具箱，按 SQL/字段配置生成 DDL 与 MyBatis-Plus 代码

综述（解读层）

Code Forge 是一个断网可用的多数据库工具箱，包含 SQL 工作台、Java 代码生成器、工作命令库和 Skill 经验库四个页面。使用者输入 SQL 脚本或字段配置，即可生成 MySQL、Oracle、SQL Server、达梦、PostgreSQL 五种方言的 DDL，以及 MyBatis-Plus 的 Entity、Mapper、XML、Service、Controller 文件并打包 ZIP。全部处理在本机完成，不连接数据库、不执行 SQL，生成 Java 代码需宿主工程提供 Spring Web 等依赖。

  • 支持 MySQL、Oracle、SQL Server、达梦、PostgreSQL 五种数据库方言的 DDL 生成，以及 MyBatis-Plus 的 Entity、Mapper、XML、Service、Controller 文件生成并导出 ZIP
  • SQL 工作台支持字段描述、多表 CREATE TABLE 脚本与 UTF-8 .sql 文件导入（最多 100 张表），可生成建表、插入（含模拟测试数据）、查询、修改、删除等操作的参数模板 SQL
  • 离线分发：npm run build 生成 ZIP 后解压双击 HTML 即可用，无需安装 Node、Python、数据库驱动或前端依赖；依赖库固定版本随仓库提供

适用场景（解读层）

  • 需要在无网络环境中编写或核对多数据库 DDL、INSERT/SELECT/UPDATE/DELETE 参数模板 SQL 的开发人员
  • 基于 MyBatis-Plus 的 Spring Boot 项目中，根据表结构快速生成 Entity、Mapper、Service、Controller 层代码骨架
  • 需要批量生成带模拟测试数据的 INSERT 语句，或按页生成查询 SQL 用于联调与测试的场景
