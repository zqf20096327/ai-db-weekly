连接 AI 代理与数据库的开源 MCP 服务器，提供预置工具与自定义工具框架

综述（解读层）

MCP Toolbox for Databases 是一个开源 MCP 服务器，用于将 AI 代理、IDE 和 MCP 客户端连接到数据库。它提供两种使用方式：通过 --prebuilt 标志加载针对特定数据库的通用工具，或通过 tools.yaml 配置文件定义 sources、tools、toolsets、prompts 和 resources 构建自定义工具。支持 PostgreSQL、MySQL、BigQuery、Spanner 等多种数据库，可通过 npx、二进制、容器镜像、Homebrew 或 go install 运行。原项目名为 genai-toolbox，后更名为 mcp-toolbox。适用于需要在代理或开发环境中接入数据库读取与查询能力的开发者。

  • 提供 --prebuilt= 参数加载预置工具，支持 PostgreSQL、MySQL、BigQuery、Cloud SQL、Spanner、Firestore、MongoDB、Redis、Elasticsearch 等数据库
  • 通过 tools.yaml 配置文件定义 sources、tools、toolsets、prompts、resources 等资源类型
  • 内置连接池、IAM 认证集成和 OpenTelemetry 可观测性支持

适用场景（解读层）

  • 在 Gemini CLI、Claude Code、Codex 等 MCP 兼容客户端中连接数据库，执行列表查询、SQL 执行、模式探索等操作
  • 为生产环境的 AI 代理定义受控的结构化查询、语义搜索等自定义数据库工具
  • 按代理或应用划分工具组（toolsets），并通过二进制或容器部署独立运行 MCP 服务
