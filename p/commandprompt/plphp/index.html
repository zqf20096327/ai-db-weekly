🧭 简介解读层（AI·证据行可回查）

在 PostgreSQL 中用 PHP 编写函数、触发器与存储过程的过程语言扩展。

综述（解读层）

PL/php 是 PostgreSQL 的过程语言处理器，允许在数据库内编写和执行 PHP 代码，覆盖普通函数、集合返回函数、触发器、事件触发器和带事务控制的过程。2.0 版面向 PostgreSQL 18 与 PHP 8 Zend API 重写，以 CREATE EXTENSION 安装。要求 PG 11+ 和 embed SAPI 的 PHP 8.1–8.4（非 ZTS）。注意其为非受信语言，仅超级用户可创建函数，函数拥有服务器 OS 用户权限。

  • 支持通过 spi_exec、spi_prepare/spi_exec_prepared 等 SPI 接口在 PHP 函数内执行 SQL 与预编译语句
  • 支持行/语句触发器（$_TD）、事件触发器，以及过程内 spi_commit/spi_rollback 和 subtransaction() 事务控制
  • 提供 jsonb_plphp、hstore_plphp、bytea_plphp 转换，将 jsonb/hstore 映射为 PHP 数组、bytea 映射为二进制字符串

适用场景（解读层）

  • 需要复用 PHP 生态/标准库逻辑的团队，在数据库端以 PHP 编写函数、触发器与过程
  • 在存储过程内执行事务控制（如分批提交/回滚）的数据处理任务
  • 需要返回多维数组、复合类型或使用 jsonb/hstore/bytea 与 PHP 数据结构直接互转的场景
