Rust 编写的多数据库 SQL 客户端，单二进制、无 JVM/Electron

综述（解读层）

TernaryGrid 是一款面向 macOS、Windows 和 Linux 的 SQL 数据库客户端，使用 Rust 与 egui 构建，单个二进制文件，不依赖 JVM 或 Electron。它通过 Rust 原生驱动连接 PostgreSQL、MySQL、SQLite、SQL Server、ClickHouse 等，并提供 SQL 编辑器、数据网格、SSH 隧道连接与从 DBeaver 导入连接等功能。安装提供 dmg、安装包、deb/rpm、AppImage 及 cargo 源码构建；macOS 版本尚未经 Apple 公证，浏览器下载会被 Gatekeeper 拦截。

  • 支持 PostgreSQL、MySQL/MariaDB、SQLite、SQL Server、Oracle、ClickHouse、Redis、MongoDB、Elasticsearch 等多种数据库，驱动以 Rust 编写
  • SQL 编辑器包含基于 schema 的自动补全、`:name`/`${name}` 参数、`@set`/`@include`/`@export`、explain 计划与查询历史；数据网格支持内联编辑、外键导航、服务端/客户端筛选排序与图表
  • 支持 SSH 隧道、SOCKS5/HTTP 代理与 SSL 连接，密码存于系统钥匙串或加密 vault；可从 DBeaver、~/.pgpass 和 URL 导入连接

适用场景（解读层）

  • 需要在一个客户端中同时管理 SQL 数据库及 Redis/MongoDB/Elasticsearch 的开发者
  • 从 DBeaver 迁移连接配置、希望以单文件应用在 macOS/Windows/Linux 上运行的用户
  • 需要通过 SSH 隧道或代理连接数据库、并要求密码存入系统钥匙串的环境
