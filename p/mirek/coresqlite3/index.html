面向 iOS 和 macOS 的 Core Foundation 风格 SQLite3 封装框架

综述（解读层）

CoreSQLite3 是基于 Core Foundation API 封装的 sqlite3 库，供 iOS 与 Mac OSX 平台的 C/Objective-C 开发者使用。它借助 toll-free bridging 直接支持 Objective-C 类型，内置 sqlite3 amalgamation（含 FTS3 与 R*Tree 扩展），并可注册数学、逻辑、加密、空间等自定义 SQL 函数，同时提供属性列表序列化绑定和类 Rails 的 schema 迁移模式；备份、图片绑定等部分在 README 中为空白章节。

  • 提供基于 Core Foundation 的连接/语句/绑定 API，支持索引（?、?1）与命名（:name、@name、$name）两种参数绑定方式，并可经 toll-free bridging 在 Objective-C 中使用 NSArray、NSDictionary 等类型
  • 内置 sqlite3 amalgamation，包含 FTS3 全文搜索与 R*Tree 范围/地理空间查询扩展，也可改用系统 sqlite3.dylib
  • 支持注册扩展 SQL 函数（sin/cos、if、md5/sha1、经纬度距离等），并提供属性列表（CFData/CFString/CFArray/CFDictionary/CFDate/CFBoolean/CFNumber）的序列化读写

适用场景（解读层）

  • 在 iOS 或 Mac OSX 应用中以 C/Core Foundation 或 Objective-C 代码读写 sqlite3 数据库
  • 需要使用 FTS3 全文搜索、R*Tree 空间查询或自定义 SQL 函数（加密哈希、地理距离计算等）的场景
  • 需要将结构化数据（字典、数组等）序列化存入单个列，或进行类似 Rails 风格的数据库 schema 迁移的项目
