综述（解读层）

Stoolap 是一个以 Rust 实现的嵌入式 SQL 数据库，无需外部服务器进程，面向低延迟事务负载与实时分析查询。它提供 MVCC 事务、AS OF 时间旅行查询、多类索引（B-tree、Hash、Bitmap、HNSW 向量索引），采用热/冷双层存储：内存 MVCC 加 WAL 处理活动写入，冷卷为不可变列式文件。通过 cargo 依赖引入使用，另提供 CLI REPL、桌面应用与 Web 管理界面。

  • 支持 ACID 事务与 MVCC，并发读写带事务隔离，并提供 AS OF 时间旅行查询
  • 支持 VECTOR(N) 数据类型与基于 HNSW 的近似最近邻搜索，可选 semantic feature 生成文本嵌入
  • 采用热/冷卷存储架构，冷卷为含 zone map、布隆过滤器、字典编码与 LZ4 压缩的不可变列式文件，后台线程自适应合并

适用场景（解读层）

  • 在 Rust 应用中嵌入运行 SQL 数据库，处理事务型与分析型混合查询
  • 需要对向量数据做近似最近邻搜索或语义文本检索的应用
  • 通过 CLI、桌面端或 Web 端（Stoolap Studio）管理本地数据并浏览 schema 与数据
