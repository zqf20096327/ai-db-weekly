Stoolap 嵌入式 SQL 数据库的 Node.js 驱动，基于原生 N-API 插件实现。

综述（解读层）

@stoolap/node 是嵌入式 SQL 数据库 Stoolap 的 JavaScript 驱动，通过 N-API C 插件接入，支持 Node.js、Bun 与 Deno。提供异步与同步两套 API，支持 MVCC、事务、预编译语句、游标迭代与批量执行；文件数据库采用 WAL 与列式卷存储。安装时需 C 编译器通过 node-gyp 编译插件。

  • 提供异步与同步 API，运行于 Node.js、Bun 和 Deno；支持预编译语句、事务、批量执行、原始行格式查询与分块游标迭代
  • 支持内存与文件两种数据库；文件模式使用 WAL 与列式 .vol 卷存储，含 zone map、bloom filter 与 LZ4 压缩，并提供 sync_mode 等 10 个配置参数
  • clone() 可创建共享底层引擎、拥有独立执行器状态的新句柄，用于 worker threads 等并发访问场景

适用场景（解读层）

  • 在 Node.js/Bun/Deno 应用中嵌入 SQL 数据库，进行内存或持久化数据存储
  • 需要事务、预编译语句和批量插入的 SQL 数据读写场景
  • worker threads 等多句柄并发访问同一数据库的场景（通过 clone 共享引擎）
