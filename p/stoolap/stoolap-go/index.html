Stoolap 嵌入式 SQL 数据库的 Go 驱动，提供原生与 WASM 两种实现

综述（解读层）

该仓库为纯 Rust 编写的 Stoolap 嵌入式 SQL 数据库提供 Go 驱动，含原生驱动（运行时加载 libstoolap，需预编译共享库）和基于 wazero 的 WASM 驱动（单线程，需手动执行 checkpoint/VACUUM 维护）。两种驱动均提供 Direct API 与 database/sql 接口，面向需要在 Go 进程内嵌入 SQL 数据库的开发者。

  • 提供 Direct API 和标准 database/sql 两种访问方式，支持位置参数 $1、? 占位符及 :name 命名参数
  • 原生驱动无需 CGO，模块内捆绑 macOS arm64、Linux x64、Windows x64 预编译共享库；WASM 驱动为纯 Go，依赖单个 5 MB .wasm 文件
  • 支持 Read Committed 与 Snapshot 两种隔离级别、ExecBatch 单事务批量执行、类型化错误码及约束违规判断

适用场景（解读层）

  • 在 Go 应用中嵌入 SQL 数据库，使用内存（memory://）或文件持久化（file://）模式
  • 跨平台分发且不希望携带原生共享库的场景（使用 WASM 驱动）
  • 需要批量写入、事务快照隔离或通过错误码处理约束冲突的数据访问层
