🧭 简介解读层（AI·证据行可回查）

按表名查询信息_schema生成随机数据并插入 MySQL/TiDB 的 Java 工具

综述（解读层）

这是一个 Java 命令行数据生成工具，通过查询目标表的信息 schema 与列信息，生成随机数字、字符串、日期值并拼装 INSERT 语句写入 MySQL 或 TiDB，自动跳过自增/auto_random 列。支持多线程、批量插入（默认批次 500）、按主表列生成关联表数据以及自定义 SQL 插入，还包含并发 DDL 测试入口，适合需要向指定表填充数据的场景。

  • 按表名查询 information schema 与列信息，生成含随机数字、varchar、日期值的 INSERT 语句，跳过 auto_increment/auto_random 列
  • 支持多线程与可选 BATCH_SIZE（默认 500）批量插入，可指定线程数与目标数据量
  • 提供三种入口：按表生成、按主表列生成关联表数据（DataGenerateRelation）、按自定义 SQL 生成（DataGenerateBySQL），并含并发 DDL 测试类 TestCurrencyDDL

适用场景（解读层）

  • 向 MySQL 或 TiDB 的指定表批量填充随机测试数据
  • 先为主表生成数据，再按主表某列生成关联表（如 t_user 与 t_order）的外键数据
  • 以自定义 INSERT SQL 为模板按并发方式写入数据，或对分区表执行并发 DDL 测试
