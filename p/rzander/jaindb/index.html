🧭 简介解读层（AI·证据行可回查）

基于区块链的 JSON 对象数据仓库，通过哈希去重存储并提供 REST API。

综述（解读层）

JainDB 是一个面向 JSON 对象的数据仓库，将数据拆分为哈希引用的块以实现去重，并把包含所有哈希引用的根哈希写入区块链以保留变更历史。数据存储支持文件系统、Redis、CosmosDB 和 RethinkDB，读写需通过其 REST API 完成。最初用于以可审计方式保存计算机资产清单数据，因 schema-less 也可存其他数据；数据不分发且无需工作量证明计算。提供 Docker 镜像。

  • 将 JSON 数据拆分为哈希引用块，相同数据块只需存储一次（去重）
  • 把包含全部哈希引用的根哈希追加到区块链，记录数据变更历史
  • 存储后端可选文件系统、Redis、CosmosDB 或 RethinkDB；数据不分发、无工作量证明计算

适用场景（解读层）

  • 以可审计方式保存计算机硬件/软件清单及其变更历史
  • 存储可按哈希引用共享重复片段的 JSON 数据
  • 通过 REST API 上传与查询 JSON 数据的自建数据存储服务
