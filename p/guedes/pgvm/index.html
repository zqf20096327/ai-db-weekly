pgvm 是一个管理多个 PostgreSQL 版本安装的命令行工具

综述（解读层）

pgvm 用于在同一台机器上管理多个 PostgreSQL 安装版本及配套集群。它可从官方源码包下载、校验并编译指定版本（支持版本号简写自动匹配最新小版本），也能从 git master 分支或特定 commit 安装。通过 use 切换当前版本，并提供 cluster 子命令创建、启动、删除集群。README 记载仅在 Debian 和 OS X 上测试过。适合需要在多版本环境间切换的开发者与测试人员。

  • 支持按版本号安装 PostgreSQL（自动解析如 9 到 9.2.0），也可从 master 分支或指定 git commit 源码编译安装
  • 通过 install/list/use/current 等子命令管理多版本，切换后 pg_config、psql 等二进制指向对应版本
  • 提供 cluster 子命令创建、启动、列出、删除集群，自动分配端口，支持传入 initdb 参数（如 --encoding、--locale）

适用场景（解读层）

  • 在同一台机器上安装并切换多个 PostgreSQL 版本进行兼容性测试
  • 从 master 分支或特定 commit 编译 PostgreSQL，供开发调试使用
  • 为不同版本快速创建多个本地集群并在各集群间执行 psql 命令
