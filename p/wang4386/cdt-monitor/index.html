阿里云 CDT 流量监控与 ECS 自动化控制单机 Go 控制台

综述（解读层）

CDT Monitor 是一个单进程 Go 控制台，将 HTTP 服务、定时调度器、并发 Worker、SQLite 和前端静态资源集成一体，用于监控阿里云 CDT 流量、控制 ECS 实例开关机和观察账单余额。支持多账号多地域管理，可配置流量阈值触发停机或通知。适用于使用阿里云 CDT 并需要自托管监控的个人或团队，通过 Docker（端口 43210）或独立二进制部署，数据存储于 SQLite，需备份 data/master.key 才能恢复加密凭据。

  • 单 Go 进程集成 HTTP 服务、定时调度器、并发 Worker、SQLite（WAL 模式）和前端静态资源，不需要 MySQL 或 Redis
  • 支持流量阈值触发“停机并通知”或“仅通知”，包含普通停机 KeepCharging 和节省停机 StopCharging 两种模式，以及每日定时开关机和抢占式实例保活
  • 通过 SMTP、Telegram Bot（支持自定义反代和 SOCKS5）和自定义 Webhook 发送通知，提供带 scope、可撤销的 API Key 及兼容 URL Cron 接口

适用场景（解读层）

  • 对多个阿里云账号、多地域的 ECS 实例进行集中 CDT 流量监控与用量历史图表查看
  • 按流量阈值自动停机或仅通知，以及抢占式实例的定时开关机与保活自动化
  • 通过 API Key 为 Android、iOS 和桌面小组件提供状态摘要读取接口
