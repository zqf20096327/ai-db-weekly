基于 TiKV v2 API 的 Web 管理界面，支持 RawKV 与事务双模式操作

综述（解读层）

该项目为 TiKV 提供基于 v2 API 的 Web 管理界面，前端 React 18 + Ant Design，后端 Node.js/Express + @tikv/client，通过 Docker Compose 部署。功能包含键值 CRUD、前缀搜索、分页浏览、批量操作、原子事务及集群状态查看。需连接外部已有 TiKV 集群（示例默认地址 172.16.0.x:2379），采用 MIT 许可证。

  • 支持 RawKV 与 Transaction 双操作模式，事务模式提供多操作原子执行
  • 提供键值 CRUD、前缀搜索、分页查询、批量操作与集群状态监控
  • 后端暴露 REST API（如 /api/kv 系列接口），支持 Docker Compose 一键部署，前端适配桌面和移动端

适用场景（解读层）

  • 通过 Web 界面查看和管理 TiKV 中的键值对数据
  • 需要在事务模式下执行多个键值操作的原子性变更
  • 运维场景中检查 TiKV 集群连接状态与统计信息
