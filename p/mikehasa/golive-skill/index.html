🧭 简介解读层（AI·证据行可回查）

开源 Agent Skill 与零依赖 Node CLI，按 detect→plan→approve→apply→verify 流程把应用部署到自有云账户。

综述（解读层）

GoLive 是一个供 Codex、Claude Code 等编码代理调用的开源 Agent Skill（0.1.0-alpha.9，早期 alpha），用于将代理构建的应用上线：托管、数据库、域名 DNS、邮件、支付等，全部使用用户自己的服务商账户。核心机制为检测→生成计划→人工审批→执行→验证，并记录所建资源、按需检查漂移、支持拆除。安装需 Node.js 20+，经 GitHub Skills CLI、npm 或 ClawHub 三种渠道分发。

  • 覆盖六条已测试路径：Vercel/Netlify 托管、Supabase/Neon 数据库、Porkbun/GoDaddy DNS、Resend 邮件、Stripe 测试模式支付、Supabase 认证，及 teardown 卸载
  • 每次写入需经审批的计划 ID 加 --yes，DNS/删除/live 模式分别要求 --confirm-dns/--confirm-destroy/--confirm-live，apply 失败即停止并可从该步恢复
  • 无 GoLive 账户、托管后端或遥测；提供 ownership 记录文档与只读的 golive status 漂移检查

适用场景（解读层）

  • 编码代理完成应用开发后，需要在用户自己的 Vercel、Supabase、Stripe 等账户上完成托管、数据库与支付配置
  • 需要审批门控、失败即停与可按需拆除的资源生命周期管理的代理部署流程
  • 为移交或手动清理生成遗留资源清单的交接场景
