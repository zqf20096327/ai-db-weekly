自动配置 Hasura GraphQL 表与关系追踪的命令行工具

综述（解读层）

QikTrak 是一个用于自动设置 Hasura GraphQL 追踪配置的工具，面向使用 PostgreSQL + Hasura 的开发者。它基于环境变量运行，可去除 schema 名前缀等默认命名，使表和关系在 GraphQL 中的名称与数据库中的命名一致，另支持将 JSON 数据通过 GraphQL 接口呈现为类似 SQL 数据。注意：运行会清除现有追踪数据，且取消追踪时会丢失权限设置。

  • 基于环境变量配置，可通过 npm 或 Docker 容器运行，自动完成 Hasura 表和关系的追踪设置
  • 为表和关系生成与数据库命名约定一致的名称，去除 schema 名前缀
  • 支持将 JSON 数据通过 GraphQL 接口呈现，使其可像 SQL 数据一样处理

适用场景（解读层）

  • 快速原型开发中反复销毁重建数据库并自动化设置 Hasura 追踪
  • 本地开发或测试环境的自动化构建流程
  • 需要在 GraphQL 中以表原始名称访问数据和 JSON 字段的场景
