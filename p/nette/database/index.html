PHP 数据库访问层，含 PDO 封装与 Explorer 关联查询机制

综述（解读层）

Nette Database 是 Nette 框架的数据库访问层，包含两个部分：Database Core 封装 PDO 提供基础查询功能，Database Explorer 提供基于表和关联关系的取数方式，将 1:N 关联数据分摊为常数次查询并通过缓存只查询用到的列。支持 MySQL、PostgreSQL、SQLite、MS SQL Server、Oracle 驱动，要求 PHP 8.4 至 8.6，通过 Composer 安装。

  • 提供 Database Core（PDO 封装）和 Database Explorer 两个层次
  • Database Explorer 通过 IN 批量查询处理 1:N 关联，查询次数为常数
  • 开启缓存后仅查询实际使用的列

适用场景（解读层）

  • 需要以 ActiveRow 方式操作单表数据及关联数据的 PHP 项目
  • 在 Nette 框架中集成数据库访问
  • 希望减少关联查询中 N+1 查询次数的场景
🔌 适配哪些库db_scan 程序判定

MySQL、Oracle、PostgreSQL、SQL Server、SQLite
