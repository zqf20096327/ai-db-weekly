基于经典ASP的低代码CRUD应用生成器，通过在线GUI配置Data Views操作SQL Server

综述（解读层）

CRUDE-ASP 是一个运行于 IIS 经典 ASP 环境的低代码平台，用于生成针对 Microsoft SQL Server 的 CRUD 网站应用。用户无需编写代码，通过在线图形界面创建 Data Views 和浏览模块，操作数据库数据并执行自定义命令（如存储过程）。注意项目仍处于初始开发阶段，暂无可安装的发布版本。

  • 支持创建 Read、Update、Delete、Execute 等数据操作视图，可执行存储过程等自定义数据库命令
  • 所有 CRUD 元素的配置与管理通过在线 GUI 完成，无需编程知识
  • 基于 AdminLTE v3 模板，依赖 Bootstrap 4、jQuery 3、DataTables、Summernote、Toastr 等组件

适用场景（解读层）

  • 在 IIS + SQL Server（含 Express/LocalDB/Azure 版本）环境中快速搭建简单业务（LOB）应用
  • 通过图形界面生成 SQL Server 数据的管理与维护页面
  • 为数据库存储过程提供在线执行入口
