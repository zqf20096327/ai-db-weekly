基于 Selenium 的 Orchard Core 应用 Web UI 测试工具箱

综述（解读层）

该工具箱为 Orchard Core 应用提供基于 Selenium 的自动化 Web UI 测试能力，由 Lombiq 开发并通过 NuGet（Lombiq.Tests.UI 等包）分发。它封装了测试运行、浏览器管理、数据库快照、日志检查、HTML 校验、无障碍与安全扫描（ZAP）、视觉验证等功能，支持 GitHub Actions 与 TeamCity 集成。适合开发与测试 Orchard Core 应用的人员使用。

  • 基于 Selenium、Atata 与 xUnit 构建，可在本地或远程以并行方式运行可重复的自动化 UI 测试
  • 支持 Chrome、Edge、Firefox 跨浏览器测试（含 headless 模式），并自动安装固定版本浏览器；可使用 SQLite/SQL Server 数据库快照
  • 内置 HTML 校验、无障碍检查、日志错误检测、猴子测试、ZAP 安全扫描及 SQL 查询监测（检测 SELECT N+1）等检查能力

适用场景（解读层）

  • 为 Orchard Core 应用编写并运行自动化 Web UI 回归测试
  • 在 CI（GitHub Actions、TeamCity）中执行跨浏览器 UI 测试并获取失败详情与报告
  • 检查应用的无障碍性、HTML 有效性、SQL 查询问题及安全漏洞
