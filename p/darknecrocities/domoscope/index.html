本地优先的仓库静态分析平台，提供CLI、Web界面与MCP服务器

综述（解读层）

DomoScope 是一个 TypeScript 编写的开源工具，用于对本地项目或 GitHub 公开仓库做静态分析，输出架构图、模块依赖图、数据库 ERD、API 路由目录和安全审计结果。它提供 npm CLI 交互式终端、本地 Web 仪表盘和 MCP 服务器两种接入方式，支持 Claude、Cursor 等 AI 客户端连接。分析结果可导出为 Markdown、Mermaid 图或 JSON。

  • 解析多种数据库 schema 来源，包括 Prisma、TypeORM、Drizzle、Mongoose、SQL DDL、Supabase 类型和 Firestore 规则，生成 ERD
  • 解析 ECMAScript/CommonJS/Go/Python/Rust/Dart 的 import 语句，生成模块依赖图并检测循环依赖
  • 内置 MCP 服务器，提供 get_database_erd、get_security_audit、get_dependency_graph 等 16 个注册工具，支持 stdio 和 HTTP/SSE 传输

适用场景（解读层）

  • 接手不熟悉的代码库时查看架构、依赖关系与 API 路由
  • 从 ORM 定义或 SQL DDL 反向生成数据库 ER 图
  • 为 AI 编码代理（Claude、Cursor、Gemini CLI 等）提供仓库分析工具集
