🧭 简介解读层（AI·证据行可回查）

一个通过 Cordova 访问 SQLite 数据库的自定义插件，API 区别于 WebSQL。

综述（解读层）

该插件为 Cordova 应用提供对 SQLite 数据库文件的读写访问，API 采用 openDatabase/execQuery 等自有函数，而非其他插件常用的 WebSQL API。通过 cordova CLI 安装，查询支持参数绑定，回调方式返回结果。iOS 平台需手动添加 libsqlite3.0.dylib 链接；浏览器环境测试需额外插件支持（Firefox 自 v36 起实现已失效），且 File 插件在浏览器端不可用，需自行处理。

  • 提供 openDatabase、execQuerySingleResult、execQueryArrayResult、execQueryNoResult、closeDB 等函数，查询支持数组形式参数绑定
  • execQueryArrayResult 以二维 JavaScript 数组返回行与列；数字以字符串返回，需 eval() 后使用
  • 可在浏览器环境测试（Chrome 开箱支持 SQLite；Firefox 需安装 WebSQL 插件，且自 v36.0 起该实现已失效）

适用场景（解读层）

  • Cordova 应用中对指定路径的 SQLite 数据库文件执行 SQL 查询与增删改操作
  • 在浏览器环境中预置或用命令行工具填充数据库后，对 Cordova 应用进行测试
  • 需要以文件路径管理 SQLite 数据库并控制是否自动创建库文件的场景
