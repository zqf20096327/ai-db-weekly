🧭 简介解读层（AI·证据行可回查）

基于 Wails 的本地多主机运维桌面工作台，集成终端、数据库、Docker 与上下文感知助手。

综述（解读层）

WWorkbench 是一个用 Go 与 Wails 构建的桌面应用，将 SSH 终端、数据库控制台、Docker 管理、SFTP 文件传输、日志查看和 Markdown 笔记整合在同一工作台，面向需要同时操作多台主机的运维与全栈开发者。连接信息与偏好存储在本地 ~/.wworkbench 的 SQLite 中，无需强制云账号；侧栏助手可通过 @ 绑定主机/数据库/容器，并经 MCP HTTP 端口向 Cursor 等外部编辑器提供当前 shell 上下文，写入类操作需在应用内确认对话框中批准。

  • 支持 MySQL、PostgreSQL、SQLite、Redis 的 SQL 控制台与表/键浏览，MySQL 含 DDL 设计
  • 提供本地 shell 与交互式 SSH 终端、SFTP 文件管理、本地/远程 Docker 管理、Node/Go/PHP/Java 本地环境版本切换
  • 侧栏助手支持 Ask/Plan/Agent 模式，@ 绑定资产；MCP HTTP 本地端口配合 Bearer 认证可被 Cursor 读取当前上下文，危险写入需应用内确认

适用场景（解读层）

  • 多主机故障排查：在同一界面内查看 SSH 终端、容器日志与数据库
  • 自托管/全栈开发：将本地与远程资产保存在可恢复的工作区中
  • 配合 Cursor 使用 MCP，使编辑器 AI 读取当前正在查看的约 100 行 shell 内容
