🧭 简介解读层（AI·证据行可回查）

自托管的开源实时后端，用 TypeScript 函数实现数据变更自动推送更新。

综述（解读层）

Concile 是一个可自托管的开源实时后端，将数据库、实时查询、认证、文件存储、定时任务和仪表盘集成在一个二进制/容器中。开发者编写普通 TypeScript 函数，数据变更时相关查询自动重跑并推送前端。默认内嵌 SQLite，可通过参数切换 Postgres。许可为 FSL-1.1-Apache-2.0，两年后自动转 Apache 2.0，禁止将其转售为托管服务。目前为 pre-1.0 版本。

  • 写操作发生时仅重运行受影响数据的查询，实现毫秒级实时更新，前端经 useQuery hook 自动重渲染
  • 默认内嵌 SQLite，可通过单个参数切换到 Postgres，代码不变且无需迁移；文件存储支持磁盘或 S3/R2
  • 提供可选的认证、授权、定时任务/重试调度、持久化工作流包，内置可浏览数据、查看日志、手动运行函数的仪表盘

适用场景（解读层）

  • 需要多端屏幕随数据变更自动更新的实时应用（聊天、订单状态等）
  • 希望以 Docker Compose 或单二进制方式自托管后端的个人或团队项目
  • 使用 Convex 的项目通过 codemod 迁移并保持查询/变更/操作写法
