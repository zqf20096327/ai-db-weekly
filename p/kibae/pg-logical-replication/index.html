Node.js 的 PostgreSQL 逻辑复制客户端，订阅 WAL 变更流

综述（解读层）

pg-logical-replication 是面向 Node.js（>=22）的 PostgreSQL 逻辑复制客户端，通过复制槽订阅服务器端数据变更。依赖 node-postgres 与 eventemitter2，npm 安装即用，支持 pgoutput、wal2json、decoderbufs、test_decoding 四种输出插件。提供自动/手动 LSN 确认、事件监听与可选背压流控，适用于需要在 JS 侧消费数据库变更事件的开发者。

  • 支持 pgoutput、wal2json、decoderbufs、test_decoding 四种输出插件
  • 提供自动/手动 acknowledge(lsn) 确认与 heartbeat 心跳事件
  • 提供 flowControl 背压选项，处理慢于生产速率时暂停流并顺序排队

适用场景（解读层）

  • 基于 CDC 模式同步 PostgreSQL 数据变更到下游系统
  • 构建需要订阅数据库 WAL 变更流的 Node.js 服务
  • 需要手动控制 WAL 确认位置或背压处理的场景
