提供列存与行存两种压缩表访问方法的 PostgreSQL 扩展

综述（解读层）

storage_engine 是一个 PostgreSQL 扩展，以 Table Access Method 形式提供 colcompress（列式压缩，含向量化执行与并行扫描）和 rowcompress（行式批压缩）两种存储引擎，面向分析与 HTAP 负载。它是 Hydra Columnar 的 fork，目录对象隔离在 engine 模式并使用 se_ 前缀导出符号。支持 zone-map 剪枝、GROUP BY 向量化聚合及自定义无符号整型 engine.uint8；删除/更新需依赖其完整 DML 支持，效果与数据排序程度相关。

  • 提供 colcompress 与 rowcompress 两种表访问方法，可与标准 heap 表在同一数据库共存
  • 实现 stripe 级与 chunk 级两层 min/max 剪枝、基于 DSM 的并行扫描和向量化 GROUP BY 聚合
  • 提供 engine.uint8 类型及索引扫描路径，v2.4 在 PG15–PG19 上通过回归测试

适用场景（解读层）

  • 宽表上的分析查询：只读取查询引用的列，配合排序与 merge 提升剪枝效果
  • HTAP 场景中需要压缩存储同时支持 DELETE/UPDATE 的表
  • 按主键或唯一标识点查的文档存储表，可开启索引扫描路径
