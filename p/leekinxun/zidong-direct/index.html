纯网页版多源数据库直连工作台，Go 单二进制 + React，支持六种数据库

综述（解读层）

紫东直连是一个纯 Web 数据库管理工作台，面向运维、研发与企业内网场景。后端用纯 Go 协议驱动（无 CGO、无 JRE、无 Oracle Instant Client），打包为单个 Docker 容器运行，提供 MySQL、PostgreSQL、SQLite、SQL Server、Oracle、达梦 DM7/DM8 的连接、SQL 查询、在线改数、表结构设计与导入导出。前端构建目标锁定 Chrome 109 / Firefox 115 ESR，README 称可在 Windows 7 老终端的浏览器中直接使用。

  • 使用纯 Go 协议驱动直连 MySQL/MariaDB、PostgreSQL、SQLite 3、SQL Server、Oracle（Service Name/SID）与达梦 DM7/DM8，无需 Java 环境或 Oracle/达梦 C 客户端
  • 提供数据网格在线增删改查、CodeMirror 6 SQL 编辑器（方言高亮与表/列补全）、可视化表结构设计器（含差异 DDL 预览）及 13 种格式导出、多来源格式导入
  • 凭据采用 AES-256-GCM 加密存储，支持签名 Cookie 登录保护、SSH 隧道与内置 SSH 终端，前端构建目标为 Chrome 109 / Firefox 115 ESR 并有自动化兼容性检查脚本

适用场景（解读层）

  • 企业内网中需要统一管理多种数据库（含达梦等国产数据库）的运维与研发场景
  • 仅能运行 Windows 7 及旧版浏览器（Chrome 109 / Firefox 115 ESR）的老旧终端，希望通过浏览器访问数据库工作台
  • 需要单容器部署、免安装桌面客户端的数据库连接、查询与数据导入导出环境
