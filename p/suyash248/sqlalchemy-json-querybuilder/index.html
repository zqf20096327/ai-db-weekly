将 JSON 条件转换为 SQLAlchemy ORM 查询的构建器

综述（解读层）

该工具把 JSON/对象形式的过滤条件转换为 SQLAlchemy queryset，用于从 RDBMS 取数。使用时以字典描述字段、操作符和值，支持比较、字符串匹配等约二十种操作符及 any/has 关系操作符，经 pip 安装后在 Python 项目中配合已有 SQLAlchemy session 使用。截至当前版本，TODO 中标注尚不支持 JSON 列。

  • 提供 equals、lt、in、like、isnull、match 等约二十种过滤操作符，以及关系操作符 any、has
  • 支持用 and/or 组合多个查询条件，并生成对应的 WHERE 子句
  • 支持 ASC/DESC 排序与基于 windowing/slicing 的分页，可通过 all 参数禁用分页

适用场景（解读层）

  • 前端或 API 传入 JSON 过滤条件，后端转换为 ORM 查询
  • 需要在关系（如 User.addresses）或集合内做过滤的场景
  • 需要统一实现排序与分页参数化查询的应用
📖 README 首段存档原文 · 程序抽取

Utility to convert JSON/objects to SQLAlchemy queryset, which is used later to generate SQL queries to fetch data from RDBMS.
