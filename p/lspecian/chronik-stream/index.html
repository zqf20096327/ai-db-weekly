Rust 实现的 Kafka 协议兼容事件流平台，内置 SQL、全文检索与向量查询

综述（解读层）

Chronik Stream 是一个用 Rust 编写的单二进制事件数据平台，实现 Kafka 线协议（24 个 API），并按主题可选开启基于 DataFusion 的 SQL 查询、基于 Tantivy 的全文检索和 HNSW 向量检索。索引在写入确认后异步进行，写路径不受影响。集群模式使用 Raft 共识，最少 3 节点；README 标注其流式吞吐基准因旧版本复制缺陷已撤回，待重测。

  • 实现 24 个 Kafka 线协议 API，兼容现有 Kafka 客户端
  • 按主题启用能力：SQL（DataFusion/Arrow/Parquet）、BM25 全文检索（Tantivy）、向量检索（HNSW），索引异步于写路径之后
  • 支持 Raft 共识的多节点集群、自动复制与在线加节点；可选 MCP 工具服务器与本体层（默认关闭）

适用场景（解读层）

  • 通过 Kafka 协议写入事件后直接用 SQL 做运营分析查询
  • 对事件流消息做全文检索
  • 事件向量化后用于语义检索与 Agent 记忆场景
