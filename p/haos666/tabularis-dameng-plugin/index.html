达梦数据库的 Tabularis 外部驱动插件，经 JSON-RPC 提供连接与元数据管理

综述（解读层）

该插件为 Tabularis 提供达梦（DM）数据库连接能力，以独立 Java 进程运行，通过 stdin/stdout 上的 JSON-RPC 2.0 与 Tabularis 通信。用户需自行提供本地达梦 JDBC 驱动 jar（仓库不随附），插件经 URLClassLoader 加载。支持 Java 17+，用 Maven 构建，覆盖元数据浏览、SQL 执行、行编辑、DDL 生成等功能。

  • 读取 schemas、表、列、注释、索引、外键、视图、存储例程和触发器元数据，并返回 EXPLAIN 计划与 ER 图 schema 快照
  • 实现 SQL 查询/DML/DDL 执行、多语句批量执行及按 JDBC 列类型绑定的行增删改，支持 base64/data URI/BLOB 线格式等二进制值写入
  • 生成表、列、索引、外键及视图/触发器管理 SQL，错误返回保留 DM 原始消息、SQLState 和 vendor code

适用场景（解读层）

  • 在 Tabularis 中浏览和编辑达梦数据库的表结构、视图、索引与外键
  • 通过 SQL 编辑器对达梦执行查询、DML/DDL 并查看 Visual Explain 执行计划
  • 在 Tabularis 行编辑中对含 BLOB/CLOB 列的达梦表进行类型化数据写入
