基于 C++/Qt 的 PostgreSQL 可视化数据库建模工具，可生成 SQL。

综述（解读层）

pgModeler 是面向 PostgreSQL 的开源数据建模工具，通过图形界面创建和编辑表、视图、关系、函数等数据库对象，并从模型生成 SQL 脚本，提供模型校验以发现引用和依赖问题。基于 C++ 和 Qt 构建，支持 Linux、Windows 和 macOS，采用 GPLv3 许可证。反向工程、模型比对同步等功能属于付费的 Plus 版，社区版不含；Windows 编译不支持 MSVC。

  • 提供拖拽式可视化建模界面，支持表、视图、关系、函数、操作符等 PostgreSQL 对象
  • 从可视化模型生成 SQL 脚本，并包含校验工具以检测建模不一致和引用损坏
  • 基于 C++ 与 Qt 构建，可运行于 Linux、Windows、macOS，支持插件扩展

适用场景（解读层）

  • 为新系统设计 PostgreSQL 数据库模式，替代手写 DDL 语句
  • 在开发或教学流程中进行关系模式的可视化编辑与 SQL 脚本导出
  • 部署前检测模型中的引用断裂与依赖问题
