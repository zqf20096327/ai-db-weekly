rusqlite 库的异步句柄封装，用于在 Tokio 中调用 SQLite

综述（解读层）

tokio-rusqlite 为 rusqlite（Rust 的 SQLite 绑定）提供异步句柄，使阻塞的 SQLite 调用可经 Connection 的异步接口在 Tokio 运行时中执行。README 含 Rust 用法示例， crate 禁用 unsafe 代码（#![forbid(unsafe_code)]），采用 MIT 许可，发布于 Crates.io 并提供稳定版文档。适合在 Tokio 应用中读写 SQLite 的开发者。

  • 提供 rusqlite 的异步句柄（Connection），供 Tokio 运行时使用
  • 使用 #![forbid(unsafe_code)]，全部以安全 Rust 实现
  • 发布于 Crates.io，提供稳定版文档，MIT 许可

适用场景（解读层）

  • Tokio 异步应用中需要读写 SQLite 数据库的场景
  • 希望在不使用 unsafe 代码的前提下集成 rusqlite 的项目
