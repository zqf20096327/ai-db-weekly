SQL Server 到 TiDB 迁移的 GitOps 元数据控制工具，含 Go CLI 与执行器适配器

综述（解读层）

sqlserver2tidb 是一个面向 SQL Server 到 TiDB 迁移的 GitOps 控制工具包，用 Go 编写。它以仓库本身作为元数据存储，将迁移状态、计划、审批、检查点和证据以 YAML/JSON/Markdown 文件形式管理，通过 GitHub PR 提供评审与审批边界。CLI 提供 SQL Server 目录发现、兼容性分析、schema/CDC/校验计划草稿生成、执行器 dry-run 与审批后执行等命令；仅显式执行路径会打开数据库连接。适合以 PR 流程管理迁移过程的团队。

  • 以仓库文件（YAML/JSON/Markdown）持久化迁移状态、计划、审批、检查点与证据，GitHub PR 作为审批边界
  • 提供 SQL Server 目录发现、兼容性分析、schema/CDC/行数校验等计划草稿生成，默认 dry-run，仅显式 --execute 路径连接数据库
  • executor 支持 CSV 导出/导入（本地、HTTP(S)、S3、GCS、Azure Blob）及 DDL 应用、CDC LSN 探测/启用/范围应用、行数与标量查询校验

适用场景（解读层）

  • 需要以 PR 评审流程管理 SQL Server 到 TiDB 迁移计划与审批记录的团队
  • 通过 CSV 导出导入及三种导入引擎（sql-insert、tidb-import-into、tidb-lightning）执行数据搬迁
  • 使用 CDC 增量同步并通过 cdc-health 命令监控检查点新鲜度与延迟，配合 Feishu/Sl webhook 告警
