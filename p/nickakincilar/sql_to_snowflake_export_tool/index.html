Windows 桌面工具，将多种关系库整库表结构与数据迁移至 Snowflake

综述（解读层）

这是一个运行于 Windows 的数据迁移工具，用于把 Microsoft SQL、Oracle、MySQL、Postgres、Redshift、SAP Hana 等源库中的表结构与数据导出到 Snowflake。它依赖各源库的 OLEDB/ODBC 驱动及 Snowflake ODBC 驱动，按表生成 DDL、映射数据类型并转换日期与二进制格式。需安装在独立机器上，作者声明为个人项目、不含担保，且与 Snowflake 公司无关。

  • 支持 Microsoft SQL、Oracle、MySQL、Postgres、Redshift、SAP Hana 作为源库，生成 DDL 并自动映射数据类型
  • 数据导出为分块的平面文件（10MB–600MB，可选 gzip 压缩），上传至 Snowflake 内部 stage 后 COPY 进目标表
  • 支持 SSO 登录 Snowflake、代理服务器选项及 SQL Server Windows 身份验证

适用场景（解读层）

  • 需要将 SQL Server、Oracle 等库整表迁移到 Snowflake 的数据搬运场景
  • 无服务器端部署权限、需在独立 Windows 机器上执行批量表导出的场景
  • 需要日期/二进制格式转换与数据类型映射的异构库迁移场景
