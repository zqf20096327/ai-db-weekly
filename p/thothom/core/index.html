基于 TypeORM 语法与插件化架构的 ORM + ODM 对象映射库

综述（解读层）

ThothOM 是面向 TypeScript 的对象映射器，融合 ORM 与 ODM，语法基于 TypeORM。核心包只提供类型定义，数据库连接由独立插件实现，可通过 npm tag `thothom` 检索插件。需开启实验性装饰器，仅支持 Data Mapper 模式，设计上面向微服务与 serverless 项目。

  • 核心包通过 @thothom/core 提供 Column、Entity、PrimaryGeneratedColumn 等装饰器与 Repository 类型
  • 插件化架构：核心包负责类型，连接与读写由插件（如 Connection 类）实现，插件可由社区创建
  • 配置默认封装在类内部，不依赖全局作用域，也可通过 setGlobalConnection() 启用全局连接

适用场景（解读层）

  • 在 TypeScript 项目中以统一语法接入 SQL 或 NoSQL 数据库（需有对应插件）
  • 微服务或 serverless 项目中的数据建模与访问
  • 开发者希望基于既有插件扩展新数据库集成
