面向 Tauri v2 的本地优先 SQLite 复制与同步插件，基于 CDC 触发器与 LWW 冲突消解。

综述（解读层）

tauri-plugin-sync 是一个 Tauri v2 插件，为桌面应用提供 SQLite 本地写入与到远端云后端的变更集复制。它通过影子触发器自动捕获增删改，断网时本地排队变更、恢复联网后自动同步，并以后台引擎执行同步。README 称其提供亚毫秒级本地写入延迟与确定性的 Last-Write-Wins 冲突消解（含墓碑删除与微秒级平局判定），并附可复现的基准测试脚本。安装需在 Cargo.toml 添加 Rust 依赖、在 Tauri Builder 中初始化，前端通过 npm/pnpm 安装 Guest-JS SDK 使用。适用于需要在 Tauri v2 桌面应用中实现本地 SQLite 与云端后端间数据同步的开发者。

  • 通过影子触发器自动捕获 insert、update、delete 变更，无需修改现有应用 SQL
  • 断网时本地排队变更，网络恢复后自动继续同步；提供 TypeScript SDK 与响应式状态监听
  • 采用 LWW 冲突消解（含微秒级平局判定与墓碑删除），并内置会话级递归抑制以防入站同步再次触发本地 CDC 触发器

适用场景（解读层）

  • 开发需要在离线状态下持续写入 SQLite、恢复联网后同步到云端后端的 Tauri v2 桌面应用
  • 多个桌面客户端与共享云后端之间需要变更集复制与确定性冲突消解的场景
  • 希望在已有 SQLite 应用上接入同步而不重构现有 SQL 代码的 Tauri 项目
