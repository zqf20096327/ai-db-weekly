综述（解读层）

Thaliyola 是一个自托管的团队知识库，以远程 MCP 服务器形式向 Claude Code、claude.ai 等客户端提供搜索、读取与写入工具。它本身不含 LLM，推理由客户端完成，服务器负责存储、检索、版本与人工审核：所有 Agent 写入均以提案形式经人批准后发布。支持团队/项目/library 三级范围、混合语义搜索、跨项目共享与影响通知。需 Postgres（pgvector）与本地或 S3 兼容存储。

  • 提供 20 余个 MCP 工具：混合关键词与语义搜索、文章/发现读取、浏览、上下文加载、提案写入与审核队列
  • 所有写入均为提案，经人工审核后发布；写入时进行密钥与个人数据脱敏和版本冲突检查
  • 使用 Postgres 全文索引（GIN）与 HNSW 向量索引实现混合搜索，内置 bge-small-en-v1.5 嵌入模型，无需外部 API，可设 EMBEDDINGS=off 降级为关键词搜索

适用场景（解读层）

  • 团队成员的多个 Claude 客户端共享同一份项目设计文档、API 契约、runbook 与历史调查结论
  • Agent 将事故根因、已知问题等以提案形式沉淀，经人工审核后纳入知识库并触发下游影响通知
  • 通过 docs_* 工具让 Agent 按提交为代码仓库生成或更新文档页面，并为每个论断附带 repo:// 源码行证据
