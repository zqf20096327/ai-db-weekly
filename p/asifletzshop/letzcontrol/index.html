自托管 VPS/网站托管控制面板，单面板管理站点、DNS、邮件、数据库与 Docker

综述（解读层）

letzControl 是一个基于 Node.js 的自托管服务器控制面板，运行在 Debian/Ubuntu 上，从单一仪表盘管理网站、DNS（BIND9）、邮件（Postfix+Dovecot）、MariaDB/MySQL、PHP 多版本、Docker 容器、定时任务和用户套餐。通过一行安装脚本部署到 /opt/letzcontrol 并注册为 systemd 服务，默认端口 2087，首次登录后由 Setup Wizard 安装缺失的托管组件。适合需要自管理 VPS 托管环境的运维人员。

  • 支持 Nginx、Apache、OpenLiteSpeed 并行运行，可按站点配置 PHP 版本与 php.ini
  • 集成 BIND9 DNS 区域管理、Postfix+Dovecot+OpenDKIM 邮件栈与 phpMyAdmin
  • 提供一键 Let's Encrypt SSL、Docker 容器管理、cron 任务及带资源限额的用户套餐

适用场景（解读层）

  • 自行托管多个网站（含 SSL、PHP 版本、DNS 与邮件记录）的 VPS 服务器管理
  • 需要带资源限额套餐（站点、域名、邮箱、磁盘、流量）的分销式托管场景
  • 通过单面板集中管理 Docker 容器、定时任务与数据库的开发/运维环境
