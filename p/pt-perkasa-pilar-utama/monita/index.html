Rust 编写的自托管监控工具，单二进制加 SQLite 存储。

综述（解读层）

Monita 是一个自托管的服务监控程序，用 Rust 编写，以单个二进制文件和 SQLite 文件运行。它提供 URL、TCP、DNS、ping 监控，cron 心跳，事件与告警（邮件、Slack、Discord、Telegram、PagerDuty 等）、公开状态页和工单。README 说明需 64 位 Linux 服务器、512 MB 内存；也提供 Docker 镜像。适合需要在自有服务器上集中管理网站可用性检查与定时任务监控的团队。

  • 支持每 30 秒至 5 分钟对 URL、TCP 端口、DNS 名称或 ping 主机进行检查，并在 HTTPS 证书到期前发出警告
  • 心跳机制等待 cron 任务回报，错过时限或调用 /fail 端点即开启事件，/fail 会附带前 1 KB 输出作为原因
  • 支持通过邮件、Slack、Google Chat、Discord、Telegram、ntfy、PagerDuty 告警，并提供维护窗口、多地点检查、角色、双因素登录与作用域 API 密钥

适用场景（解读层）

  • 监控团队网站和 API 的可用性，并对外发布包含 90 天在线率与事件时间线的状态页
  • 为 cron 备份等定时任务配置心跳，任务失败或超时未回报时自动开启事件并通知
  • 通过状态页或应用接口收集 bug 报告，在工单看板上进行分诊与流转
