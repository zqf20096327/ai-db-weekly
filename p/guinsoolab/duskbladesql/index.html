面向实时应用的流式数据库，将 SQL 查询转为增量维护的数据流

综述（解读层）

DuskbladeSQL 是一个流式数据库，用于对持续变化的实时数据提出查询并由系统增量维护结果。用户可通过 PostgreSQL 协议定义视图并读取结果，数据来源支持 Kafka、Kinesis 及本地文件。项目基于 differential dataflow 与 timely dataflow 实现，使用 Rust 编写，采用 BSL 1.1 许可并计划转为 Apache 2.0。

  • 支持 Avro、Protobuf、JSON 及换行分隔文本格式，可读取 Kafka 主题、Kinesis 流（预览）和本地文件
  • 兼容大部分 PostgreSQL 语法与协议，支持多路连接、子查询去相关、CDC（Debezium 格式）及 jsonb 操作符
  • 提供拉取式（PostgreSQL 驱动 SELECT）与推送式（结果流至 Kafka 主题）两种数据输出方式

适用场景（解读层）

  • 对流式数据进行交互式探索查询
  • 对实时关系型数据执行数据仓库分析
  • 为仪表盘和监控任务提供持续更新的查询结果
