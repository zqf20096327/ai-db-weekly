基于 SQL 的语义建模与查询语言

综述（解读层）

Malloy 是一个开源语言，用于描述数据关系与转换，兼具语义建模与查询功能，编译为 SQL 后在现有数据库引擎上执行。开发者可通过 VS Code 扩展、npm 包、CLI 或 Publisher 服务器使用它；支持 BigQuery、Snowflake、DuckDB、PostgreSQL 等多种引擎。运行要求 Node.js >=20，许可证为 MIT。

  • 编译为 SQL 并嵌入 SQL，使用现有 SQL 引擎执行查询，支持 BigQuery、Snowflake、DuckDB、PostgreSQL、MySQL、Trino、Presto、Databricks 等引擎
  • 原生支持嵌套数据（记录数组、查询管道）作为一等语法，查询具有可组合性
  • 提供四种使用方式：VS Code 扩展、npm 包、CLI（run/compile/build 命令）以及 Publisher 语义模型服务器（REST 与 MCP API）

适用场景（解读层）

  • 在数据仓库上编写和执行分析查询，并将度量定义固化在语义模型中复用
  • 在 Node.js 应用、脚本、CI 流水线中通过 npm 包或 CLI 编译和运行 Malloy 查询
  • 通过 Publisher 将 .malloy 模型以 REST 和 MCP 接口提供给 BI 工具和 AI 代理查询
