Malloy 开源分析引擎，以一个数据模型经 MCP 与 REST 对外服务。

综述（解读层）

Malloy Publisher 是 Malloy 语言的开源分析服务器，用于定义数据模型（来源、联接、度量、访问控制）并经 MCP 与 REST 提供给 AI 代理、应用和 BI 工具。支持本地文件（CSV、Parquet、JSON、Excel，内置 DuckDB）与 BigQuery、Snowflake、Postgres 等连接；通过 npx、Docker 或 Compose 运行，需 Node.js 20 以上；服务器无状态且自身不做认证，访问控制依赖前置网关设置身份 givens。

  • 通过 MCP 端点向 Claude、Cursor、Codex 等代理提供 get_context、execute_query、compile_model、search_database_schema 等工具，并同时提供 REST API 与 OpenAPI 规范
  • 支持 `#@ persist` 与 `#@ preaggregate` 注解实现物化与预聚合，可按需或按计划重建；`#(authorize)`、`#(access_filter)` 等注解用于访问控制
  • 内置 DuckDB 读取 CSV、Parquet、JSON、换行分隔 JSON 与 Excel 文件，并可通过连接访问 BigQuery、Snowflake、Postgres、Databricks、MotherDuck 等数据源

适用场景（解读层）

  • 为 AI 代理提供基于已建模数据的查询接口，替代由代理直接编写 SQL 访问原始表
  • 构建打包于 Malloy 模型之上的报告与无构建 HTML 数据应用，并在控制台浏览
  • 将本地文件或数据仓库模型以微服务形式部署于自有网关之后，按身份控制查询与可见范围
