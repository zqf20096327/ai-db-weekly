🧭 简介解读层（AI·证据行可回查）

基于 PostgreSQL 表、函数和视图实现的双式记账账本

综述（解读层）

pgledger 是一个用 PostgreSQL 实现的双式记账账本，无应用层代码，应用通过调用 SQL 函数写入、通过视图查询。安装只需依次执行 vendor 的 ULID 辅助 SQL 和 pgledger.sql。支持批量转账、账户余额约束、event_at 事件时间戳和 idempotency_key 幂等重试；每个账户为单一货币，多币种需用多个账户。

  • 全部以 PostgreSQL 表、函数和视图实现，账本写入与应用内其他操作共用同一事务，原子提交
  • 支持批量转账（按数组顺序逐条校验）、可选 event_at 时间戳，以及基于 idempotency_key 的幂等重试
  • 账户可配置是否允许负余额；转账金额必须为正有限数，拒绝的调用不改变账本状态

适用场景（解读层）

  • 为处理资金的应用提供可复用的账本层，跨编程语言使用
  • 需要账本写入与业务操作在同一 PostgreSQL 事务中原子提交的场景
  • 记录来自 webhook 等延迟到达的真实世界事件，并按 event_at 与银行对账单对账
