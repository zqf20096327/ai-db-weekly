综述（解读层）

Tupai 是一款基于 Electron 的桌面数据库管理工具，供需要在同一应用中连接多种数据库的用户使用。它提供对象浏览、数据网格编辑、多标签 SQL 编辑器、表结构设计、用户与权限管理、CSV/JSON/SQL 导入导出、备份恢复及跨引擎数据传输与结构同步。采用 MIT 许可证，无账户或订阅。注意当前构建未数字签名，无主键的表只读，MongoDB 不提供 SQL 类功能。

  • 支持连接 MySQL、MariaDB、PostgreSQL、Oracle、SQLite、MongoDB，可选 SSL/TLS、证书与 SSH 隧道
  • 提供多标签 SQL 编辑器（含补全、查询计划、手动事务）、表设计器、用户权限管理、CSV/JSON/SQL 导入导出、备份恢复与跨引擎数据传输/结构同步
  • 凭据经操作系统安全存储加密，数据本地存储，支持中文等五种界面语言与自定义主题

适用场景（解读层）

  • 需要在一个桌面应用中管理多种关系型数据库连接与查询工作
  • 进行表结构设计与数据在数据库间（含跨引擎）的传输或结构同步
  • 本地导入/导出 CSV、JSON、SQL 数据及数据库备份恢复
