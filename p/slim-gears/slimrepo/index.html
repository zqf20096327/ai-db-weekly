面向 Java 与 Android/SQLite 的轻量级模块化 ORM 库

综述（解读层）

Slim Repo 是一个面向 Java 和 Android 的轻量级模块化 ORM，用于将数据持久化逻辑与底层存储解耦，通过注解处理在编译期生成代码，运行时不使用反射。它以 SQLite 作为可扩展的存储提供者，定位为 Android 应用开发者的数据访问组件。当前版本 0.9.0，文档 Wikipedia 尚未完整。

  • 基于注解处理生成代码，运行时不使用反射
  • 支持批量更新与批量删除操作
  • 模块化设计，存储提供者（如 SQLite）以扩展形式接入

适用场景（解读层）

  • Android 应用中的 SQLite 数据持久化
  • Java 应用中需要类型安全 CRUD 语法的场景
  • 需要在存储提供者之间切换而保持用户代码不变的项目
