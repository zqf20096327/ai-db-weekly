🧭 简介解读层（AI·证据行可回查）

AI 原生 Rust 库与运行时，提供模型驱动的类型化查询、表达式与审计变更。

综述（解读层）

TeaQL 是用于构建 Rust 业务应用的库与运行时。它依据语义模型生成领域库，包含 Q 查询、E 表达式与带审计原因的变更 API，通过 metadata、Context、Checker、Policy 与数据库提供者执行。面向使用编码代理和需要可审查业务操作的开发团队；Save 的原子性限于 provider 范围，审计事件在提交后投递，回滚时丢弃。

  • 提供模型驱动的生成式领域库，包含 Q 查询、E 访问路径表达式与变更方法
  • Save 遍历变更图，执行 Checker/Fix 与配置的 Mutation Policy，并使用 provider 事务边界
  • 运行时自动生成查询与变更诊断日志及追踪上下文，诊断 SQL 经过字段感知脱敏

适用场景（解读层）

  • 构建需要可审查业务操作与执行日志的 Rust 业务应用
  • 需要对查询意图（comment/purpose）与变更原因（audit_as）进行审计留痕的场景
  • 使用编码代理开发时，通过 Assist 命令按需获取实体/字段 API 指引
