检测隐式外键约束的RDB分析器，基于表/列名推测表关系

综述（解读层）

HAKAGI 是一个用 Go 编写的 RDB 分析器，用于检测数据库中未声明外键约束的隐式表关系，并生成相应的 ALTER TABLE 外键约束语句，以支持 ER 图自动生成工具读取。通过 go get 安装，命令行连接 MySQL 指定目标数据库运行。README 示例基于表/列名猜测关系，TODO 表明推测规则和输出格式仍在扩充中。

  • 基于表名/列名推测未显式声明的外键约束，输出 ALTER TABLE ... ADD CONSTRAINT 语句
  • 推测结果可写入 SQL 文件并导入 MySQL，使 ER 图工具能生成含关系的图
  • 通过 go get 安装，命令行参数指定数据库用户、密码、主机、端口和目标库

适用场景（解读层）

  • 数据库缺少显式外键约束、ER 图工具无法自动生成关系图时的补充处理
  • 批量分析存量 MySQL 库并生成补全外键约束的迁移 SQL
  • 整理无外键定义的数据库表关系文档
