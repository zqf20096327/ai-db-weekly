🧭 简介解读层（AI·证据行可回查）

将 WARC 网页爬取数据导入 SQLite 数据库以便查询的文件格式与 CLI 工具

综述（解读层）

WarcDB 定义了一种基于 SQLite 的 .warcdb 文件格式，用于把 WARC（ISO 28500:2017）爬取归档解析后写入关系数据库，供用 SQL 查询和分享。它通过 pip 安装，import 命令支持本地/远程、原始/压缩的 WARC 及 WACZ 文件；底层是 sqlite-utils 的封装，sqlite-utils 命令可直接操作其数据库文件。适用于需要处理 WARC 数据子集、希望用 SQL 检索请求/响应 HTTP 头等内容的用户。

  • import 命令支持混合导入本地/远程、原始/gzip 压缩的 WARC 文件，以及 ArchiveWeb.Page、Browsertrix-Crawler、Scoop 等工具生成的 WACZ 文件
  • 提供 v_request_http_header、v_response_http_header 等辅助视图查询 WARC 请求/响应记录中的 HTTP 头
  • 作为 sqlite-utils 的封装实现，数据库可通过 sqlite-utils CLI 直接操作，并支持 migrate 命令迁移数据库 schema

适用场景（解读层）

  • 对 Common Crawl 等大规模 WARC 数据的子集进行流式导入并用 SQL 查询
  • 用 wget --warc-file 生成个人网站的 WARC 归档后导入数据库分析
  • 检索 WARC 记录中的特定 HTTP 头（如 Cookie 或 Content-Type）
