🧭 简介解读层（AI·证据行可回查）

陪伴型机器人的情感加权记忆层，用本地 SQLite 实现遗忘与召回

综述（解读层）

hippocampus_22 为长期运行的陪伴机器人提供记忆层，按事件编码、巩固、遗忘、联想召回、元记忆五环节实现。记忆以事件加情绪权重形式存于单个本地 SQLite 文件（node:sqlite，零第三方依赖），支持库、HTTP 服务、DSH 插件三种接入方式，派生自 dsh-hippocampus v0.3.1。运行需 Node 环境；库方式使用时需要 DEEPSEEK_API_KEY。适合需要跨会话记忆且记忆按人隔离的聊天机器人场景。

  • 提供事件编码、情绪加权遗忘、联想召回和确定度标注（记得清/大概记得/只记得有这回事）
  • 全部记忆存于单个本地 SQLite 文件，仅用 node:sqlite，不依赖第三方包
  • 支持三种接入：npm 库、带 token 鉴权的 HTTP 服务、DSH 插件

适用场景（解读层）

  • 为陪伴型聊天机器人添加带情绪权重的跨会话记忆
  • 多渠道接入（im/网页/QQ 桥）且需按人隔离记忆的场景
  • 需要记忆衰减、事实改口作废等机制而非简单存档的对话系统
