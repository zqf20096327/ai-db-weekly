Express.js + PostgreSQL 的单元测试示例仓库，集成 Mocha/Chai/Istanbul 与 CI/CD

综述（解读层）

这是 Dicoding 直播活动产出的示例仓库，演示如何用 Mocha、Chai、Istanbul 为 Express.js REST API 编写单元测试并生成覆盖率报告，数据库使用 PostgreSQL。项目含 6 个 BREAD 端点和 11 个测试用例，通过 GitHub Actions 实现 CI，并部署至 Heroku。运行需本地安装 Node.js 与 PostgreSQL，并在 config/config.js 中配置数据库连接。

  • 使用 Mocha 作为测试运行器、Chai 进行断言，Istanbul 生成测试覆盖率报告
  • 通过 GitHub Actions 实现持续集成，并集成 Codecov 在线查看覆盖率
  • 提供 6 个 BREAD（浏览/读取/编辑/添加/删除）端点，使用 Swagger 生成 API 文档

适用场景（解读层）

  • 学习为 Express.js REST API 编写自动化单元测试的流程
  • 参考基于 GitHub Actions 与 Heroku 的 CI/CD 配置方式
  • 作为直播教学内容的源码对照材料
