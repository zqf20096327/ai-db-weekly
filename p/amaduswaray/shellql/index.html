基于 Rust/Ratatui 的终端数据库管理 TUI，采用 Vim 式模态编辑与标签-面板布局。

综述（解读层）

ShellQL 是一个运行于终端的数据库管理工具，面向使用 Vim/tmux 的开发者，支持 Postgres、MySQL、SQLite 三种引擎。其核心机制是标签-面板-视图的可组合布局，SQL 编辑器实现 normal/insert/visual 模态与操作符、motion，数据修改采用暂存（staged）后以 `:w` 提交的模式。项目目前处于 beta 阶段（v0.1.x-beta），键位与功能仍在演进，安装可通过 Homebrew、cargo 或源码构建，许可证为 MIT。

  • 支持 Postgres、MySQL、SQLite 连接管理（TUI 与 CLI 两种方式），提供多标签、多面板工作区与 tables/table/schema/editor/results 五种视图
  • SQL 编辑器实现 Vim 式模态操作（motions、operators、text objects、yank/paste），并带上下文感知的 SQL 与表名自动补全
  • 表格视图支持浏览、`:where` 过滤、`:order` 排序、`:select` 投影、单元格编辑、暂存插入/删除，经 `:w` 提交；`:! ` 可在命令行直接执行 SQL

适用场景（解读层）

  • 通过 SSH 会话检查数据库行数据
  • 编码过程中排查数据问题并执行一次性 SQL 更新
  • Vim/tmux 用户的纯键盘数据操作工作流
