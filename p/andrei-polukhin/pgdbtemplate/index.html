通过 PostgreSQL 模板数据库创建测试库的 Go 库

综述（解读层）

pgdbtemplate 是一个 Go 库，利用 PostgreSQL 的模板数据库机制为测试创建数据库：初始化一次模板后，每个测试可快速派生独立数据库。它支持 pq、pgx/v5、pgx/v4 三种驱动，提供 goose、golang-migrate、Atlas 迁移适配器及内置 SQL 迁移运行器，并可集成 testcontainers-go。要求 PostgreSQL 9.5+ 和 Go 1.20+，采用 MIT 许可。

  • 支持 pq、pgx/v5、pgx/v4 连接提供程序，并提供 goose、golang-migrate、Atlas 迁移适配器与内置文件迁移运行器
  • 线程安全：模板初始化由互斥锁保护，数据库命名使用时间戳与原子计数器避免冲突，适用于并行测试
  • 提供 Testcontainers 集成，以及自定义连接提供程序和迁移运行器的扩展点

适用场景（解读层）

  • 需要为每个测试创建隔离 PostgreSQL 数据库的 Go 测试套件
  • 通过 testcontainers-go 在容器化环境中运行 PostgreSQL 集成测试
  • 使用 goose、golang-migrate 或 Atlas 管理迁移的项目，在测试前批量应用 schema
