综述（解读层）

TrivialDB是一个用C++实现的数据库管理系统，是清华大学2018年秋季'数据库概论'课程的期末项目。它实现了常见的SQL增删改查语句，支持多主键、外键等完整性约束，采用Bison和Flex解析SQL，并通过B+树索引对连接查询做优化。项目通过CMake构建，需要支持C++11的编译器。注意COUNT不支持DISTINCT关键字。

  • 支持INSERT、DELETE、SELECT、UPDATE及数据库、表、索引的管理语句
  • 支持多列联合主键、外键、UNIQUE、NOT NULL、DEFAULT、CHECK六种完整性约束
  • 实现COUNT、SUM、AVG、MIN、MAX五种聚集函数与基于B+树索引的连接查询优化

适用场景（解读层）

  • 数据库系统课程的学习与教学参考
  • 对SQL解析和查询执行流程感兴趣的C++开发者的代码阅读材料
  • 运行简单SQL语句的实验性环境
📖 README 首段存档原文 · 程序抽取

TrivialDB是一个简单的数据库管理系统，我们实现了大部分常见的SQL语句和类型。同时支持多表连接、复杂表达式运算、多主键约束、外键约束、CHECK约束、UNIQUE和DEFAULT约束、聚集查询、利用B+树索引的查询优化，同时，我们支持任意长度的VARCHAR类型。
