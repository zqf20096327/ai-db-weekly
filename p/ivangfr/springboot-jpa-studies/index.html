基于 Spring Boot 的 JPA 批处理与锁机制学习项目

综述（解读层）

该项目用于学习 JPA 批量插入、更新、删除及乐观/悲观锁机制，包含 jpa-batch 和 jpa-locking 两个模块，各配 ER 图与示例 API。面向想了解 Spring Data JPA 批处理与加锁行为的 Java 开发者。运行需 Java 25+ 和 Docker，通过 docker compose 启动 MySQL/PostgreSQL，测试用 Testcontainers，代码格式由 Spotless 强制检查。

  • 提供 jpa-batch 与 jpa-locking 两个模块，分别演示 JPA 批处理与锁机制
  • 支持 MySQL 和 PostgreSQL，测试通过 Testcontainers 自动启动数据库容器
  • 使用 docker compose 启动环境，集成 springdoc-openapi 和 Spotless 格式化

适用场景（解读层）

  • 学习 JPA 批量插入、更新、删除的实现方式
  • 对比实践 JPA 乐观锁与悲观锁
  • 作为 Spring Boot + Spring Data JPA 多数据库集成测试的参考示例
📖 README 首段存档原文 · 程序抽取

The goal of this project is to study JPA Batch Processing (i.e., inserting, updating, or deleting a set of records in a single command) and JPA Locking.
