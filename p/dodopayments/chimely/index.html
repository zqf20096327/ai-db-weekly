自托管的应用内通知收件箱基础设施：Rust 单二进制 + Postgres/Redis + React 组件

综述（解读层）

Chimely 是开源、可自托管的应用内通知收件箱基础设施，由一个 Rust 二进制、Postgres、Redis、小型 HTTP API 和 React 的 <Inbox /> 组件组成。后端发送一个 POST 即写入通知，前端组件提供未读计数、已读状态、归档等界面。定位为只做收件箱：不含工作流引擎、邮件/短信/推送渠道与服务端模板。适用于需自行搭建应用内消息中心的团队。

  • Postgres 作为权威数据源，Redis 仅承载实时提示与可重建缓存，丢失 Redis 不丢数据
  • SSE 提示触发基于 ETag 的条件重取（多返回 304），提示丢失不致数据不一致
  • 二进制内嵌迁移、操作面板（含四种固定角色、Argon2id 密码、DLQ 重放）、Prometheus 指标与 OpenAPI 文档

适用场景（解读层）

  • 为 Web 应用嵌入带未读计数、标签页、归档和分类偏好的应用内通知收件箱
  • 自托管部署，通过 Docker 镜像配合 Postgres/Redis 运行单个服务
  • 仅限应用内渠道的通知场景，多租户以运行多个实例方式实现
