🧭 简介解读层（AI·证据行可回查）

Directus 自定义操作扩展，用 pg_dump 备份 PostgreSQL 并上传 .dump 文件。

综述（解读层）

这是一个 Directus 扩展（operation 类型），在 Directus Flow 中调用 pg_dump 生成 PostgreSQL 数据库的 .dump 文件并上传到 Directus 存储。部署时需在 Directus 机器上安装 PostgreSQL Client 以供 Node 启动 pg_dump 进程；安装方式是将项目克隆到 /extensions/operations 目录后执行 yarn && yarn build。目前仅支持 local 存储。

  • 通过 Node 启动 pg_dump 进程生成数据库 .dump 文件
  • 将备份文件上传到 Directus 存储的指定文件夹（在操作注册时填写文件夹名）
  • 作为 Directus Flow 的自定义操作运行，触发方式由 Flow 定义

适用场景（解读层）

  • 在 Directus Flow 中按设定触发器执行 PostgreSQL 数据库备份
  • 将生成的 .dump 备份文件集中存放到 Directus 存储的指定文件夹
  • Docker 环境下运行的 Directus 实例（需容器内具备 pg_dump）
