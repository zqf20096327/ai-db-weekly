🧭 简介解读层（AI·证据行可回查）

Rust 编写的独立确定性 MVCC 核心库，用于构建事务型键值存储。

综述（解读层）

nexir-mvcc 是 Nexir 数据库开源的 MVCC 核心库，提供多版本管理、两阶段 intent 事务、CAS 守护写入与增量 GC 原语。核心逻辑在内存中确定性运行，持久化通过 Backend trait 委托给适配器实现；不包含网络、解析、共识等组件。面向需要在 Rust 中实现事务型键值存储层的开发者。

  • 支持调用方提供的 u128 逻辑时间戳排序，提供 prewrite/commit/abort 及批量接口实现两阶段 intent 事务
  • 提供 apply_direct_batch 与 apply_guarded_batch 直写快速路径，带 CAS 守护校验
  • 通过 conformance feature 提供内置测试宏，用于验证自定义 Backend 的逻辑契约

适用场景（解读层）

  • 基于 Backend trait 接入自有存储引擎或复制状态机，构建事务型键值数据库
  • 为适配器实现增量 GC 与按键 GC 计划的历史保留策略
  • 通过一致性套件验证自定义持久化后端是否符合逻辑契约
