封装 Neo4j Python Driver 的 Python 类，用方法调用替代常见 Cypher 查询

综述（解读层）

Neointerface 是 GlaxoSmithKline 开发的 Python 类，包装官方 Neo4j Python Driver，提供面向常见图数据库操作的方法，减少编写 Cypher 的需求，高级用户也可直接传入 Cypher。支持 Pandas DataFrame 与字典和 Neo4j 节点间的互转；部分功能依赖 APOC 库，RDF 功能需额外安装 n10s。README 注明在 Neo4j 4.3.6 与 4.4.11 版本上测试。

  • 提供 load_df / get_df 方法，实现 Pandas DataFrame 与 Neo4j 节点之间的双向转换
  • 提供 load_dict 方法，将嵌套字典写入图数据库并指定根节点标签
  • 支持通过环境变量（NEO4J_HOST/NEO4J_USER/NEO4J_PASSWORD）配置连接，可选启用 APOC 与 RDF 功能

适用场景（解读层）

  • 希望以 Python 方法调用而非手写 Cypher 操作 Neo4j 的开发者
  • 需要在 Pandas DataFrame 与图数据库之间导入导出数据的分析流程
  • 将嵌套字典等结构化数据写入 Neo4j 并构建节点关系的场景
