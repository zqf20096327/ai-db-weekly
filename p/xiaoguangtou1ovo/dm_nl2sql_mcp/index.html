🧭 简介解读层（AI·证据行可回查）

面向达梦数据库的 NL2SQL MCP 工具，通过 Excel 目录、FAISS 检索与受限查询计划实现只读自然语言问答

综述（解读层）

本项目提供基于 MCP 协议的达梦数据库自然语言查询能力：用户通过 Excel 工作簿声明可查询的表、字段与业务语义，程序读取达梦真实元数据核验后增量构建 FAISS 索引。模型只生成受限 QueryPlan，由程序编译为参数化 SELECT 执行。使用 uv 管理，需配置达梦只读账号与 LLM、Embedding 服务；当前不提供公网认证与行列级权限。

  • 提供 catalog-sync 增量同步，按描述文本哈希复用旧向量，失败时不切换旧索引
  • 提供三个只读 MCP 工具（list_datasets、search_catalog、query_data）及独立管理型 MCP
  • 模型只能生成受限 QueryPlan，禁止写操作、CTE、子查询、OR 等自由 SQL，并对行数、字节数和执行时间设限

适用场景（解读层）

  • 为达梦数据库搭建受控的自然语言查询入口，仅开放指定表和字段
  • 通过 Excel 工作簿由业务方维护表字段说明、枚举、同义词和指标口径
  • 以 MCP 方式接入智能体客户端，或通过 LangChain 客户端进行带 trace 的问答联调
