基于 Go 的 PostgreSQL 数据脱敏工具，导出生产库并匿名化后供 QA 使用

综述（解读层）

Gonymizer（Go + Anonymizer）由 SmithRx 开发，用于在将生产数据库转储载入 QA 环境前对 PHI/PII 敏感数据进行匿名化处理。它通过 JSON/YAML/TOML 配置和映射文件指定需脱敏的列及处理方式，内置地址、姓名、邮箱、IP 等多种伪造处理器，并提供 CLI 与 API 两种使用方式。目前仅支持 PostgreSQL 9.x-13.x，README 注明 12+ 版本未经测试。

  • 提供 dump 命令导出数据库，并按映射文件对指定列应用脱敏处理器（如 FakeEmailAddress、FakeFirstName、RandomDate 等）
  • 支持 pg_dump 风格的 exclude-table、exclude-table-data、schema 等选项控制导出范围
  • 内置 Kubernetes CRONJOB 调度与 AWS S3 存储处理示例，基于 Cobra + Viper 支持 JSON/YAML/TOML 配置

适用场景（解读层）

  • 在将含 PHI/PII 的生产 PostgreSQL 数据载入 QA 或测试环境前进行脱敏处理
  • 结合 Kubernetes CRONJOB 或 AWS S3 建立定期脱敏导出流程
  • 需要按 HIPAA 等合规要求处理测试数据中敏感字段的数据库管理场景
