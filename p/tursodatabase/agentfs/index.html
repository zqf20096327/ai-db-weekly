为 AI Agent 设计的文件系统，基于 SQLite 存储文件、状态与调用记录

综述（解读层）

AgentFS 是 Turso 团队面向 AI Agent 的文件系统，将文件、状态、工具调用历史存入单个 SQLite 数据库。提供 TypeScript/Python/Rust SDK 和 CLI，可经 FUSE（Linux）或 NFS（macOS）挂载。文件操作记录可用 SQL 查询，支持快照复制恢复；当前为 BETA，官方提示注意生产数据备份。

  • 提供 POSIX 风格文件系统、键值存储、工具调用审计三类接口
  • 所有文件操作与状态存于单个 SQLite 文件，可用 SQL 查询和 cp 快照
  • 支持 FUSE/NFS 挂载，并提供 TypeScript、Python、Rust SDK

适用场景（解读层）

  • 查询与审计 Agent 的工具调用历史和行为记录
  • 快照并恢复 Agent 执行状态，用于复现或回滚
  • 为无服务器或浏览器等无法挂载块设备的环境提供文件系统接口
