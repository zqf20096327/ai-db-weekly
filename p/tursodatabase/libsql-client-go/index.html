libSQL 数据库的 Go 语言客户端 API

综述（解读层）

该仓库提供连接 libSQL 的 Go 客户端 API，服务于使用 Turso（基于 libSQL 的 SQLite 兼容数据库）的 Go 开发者。README 已声明仓库被弃用：连接 Turso Cloud 建议改用 go-libsql，连接 Turso Database 可考虑 turso-go。文档含 Quickstart 与 SDK 安装、查询执行说明。

  • 提供 libSQL 的 Go 客户端 API，可安装并执行查询
  • 配套 Turso Quickstart 与 SDK Quickstart 文档
  • README 标注仓库已弃用，并给出 go-libsql 与 turso-go 替代指引

适用场景（解读层）

  • Go 应用连接基于 libSQL 的 Turso 数据库并执行 SQL 查询
  • 查阅 Turso 与 Go 集成的快速上手示例
  • 查找迁移至 go-libsql 或 turso-go 的入口指引
