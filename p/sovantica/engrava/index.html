基于 SQLite 的 AI 代理记忆数据库，内置图结构与混合检索

综述（解读层）

Engrava 是一个进程内 Python 库，底层为单个 SQLite 文件，提供 thought 的增删改查、类型化边知识图谱、向量相似检索与 FTS5/BM25 全文检索，通过 MindQL 声明式查询，默认写入路径不含生成式模型调用。可选 extra 接入本地或 API 嵌入服务，另有 opt-in 的遗忘循环与 SHA-256 哈希链日志。适合需要持久化记忆的 agent 应用及个人知识库场景。

  • 混合检索组合向量相似度、BM25 文本相关性、时间新近性、优先级与图连通性信号，不可用信号跳过并重分配权重
  • 内置 Dreaming 巩固扩展，通过确定性结构函数聚类生成 REFLECTION thoughts，默认信号不调用 LLM
  • opt-in 哈希链日志以 SHA-256 链接记录 thought 与边的变更，可通过 verify_journal 校验

适用场景（解读层）

  • 为 AI agent 提供基于单 SQLite 文件的持久化记忆存储
  • 通过 MCP 服务器（engrava-mcp）向 Claude Desktop、Cursor 等客户端提供记忆工具
  • 构建带语义检索的会话存档或个人知识库
