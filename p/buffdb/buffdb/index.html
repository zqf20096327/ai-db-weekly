基于 gRPC 与 Protocol Buffers 的嵌入式存储引擎，用于模型管理。

综述（解读层）

BuffDB 是 Rust 编写的嵌入式存储库，面向边缘计算与离线优先应用，提供键值存储、带元数据的 BLOB 存储与模型文件存取，并通过 gRPC 暴露网络接口，客户端可用 Protocol Buffers 交互。默认使用 SQLite 后端，二进制小于 2MB；DuckDB 后端因链接与绑定问题暂被禁用。项目处于实验阶段，macOS 构建需安装 protobuf、sqlite 等依赖。

  • 提供键值存储与带元数据的 BLOB 存储，支持流式操作和基于哈希、B-tree 的二级索引
  • 通过 gRPC 服务暴露接口，README 附 Rust、TypeScript、Python、Java、Go、Swift、Kotlin 客户端示例
  • 默认内嵌 SQLite 后端，支持 CLI 执行原始 SQL 查询与 ML 模型存储、Hugging Face 缓存示例

适用场景（解读层）

  • 在边缘设备或无网络环境中本地存储并加载 ML 模型文件
  • 离线优先应用中本地管理键值配置与状态，之后再同步到云端
  • 作为 Hugging Face 模型的本地缓存层，供多语言客户端经 gRPC 读取
