自动清理 Rails db/structure.sql 冗余内容的 Ruby gem

综述（解读层）

该 gem 面向使用 ActiveRecord 与 PostgreSQL 的 Rails 项目，在 rake db:migrate 时自动清理 db/structure.sql 中的不必要输出，减少合并冲突。通过配置项可按字母排序列定义、按时间排序 schema_migrations、保留指定扩展、忽略特定 schema。限制：假设 id 为主键且为 SERIAL/BIGSERIAL/uuid，不支持多列主键。

  • 自动挂载到 rake db:migrate 任务，在结构文件更新时执行清理
  • 提供 group_table_definition、order_column_definitions、order_schema_migrations_values 等可配置选项
  • 可通过 ignore_ids、keep_extensions、ignore_schemas 控制清理行为

适用场景（解读层）

  • 多人协作的 Rails + PostgreSQL 项目中减少 structure.sql 的合并冲突
  • 团队需要统一的 schema 结构文件格式（列排序、迁移版本排序）
  • 从含辅助函数或扩展的数据库副本导出结构时过滤指定 schema
