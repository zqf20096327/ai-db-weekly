🧭 简介解读层（AI·证据行可回查）

为 SQLite 添加图数据库能力与 Cypher 查询支持的 C99 扩展

综述（解读层）

sqlite-graph 是一个 SQLite 加载扩展，以节点/边存储图数据，通过 cypher_execute 等SQL 函数执行 Cypher 的 CREATE/MATCH/WHERE/RETURN 子集，并提供连接性、密度、度中心性等图算法函数与虚拟表接口。面向已使用 SQLite 且需要图操作的开发者。当前为 0.1.0-alpha 版本，API 可能变动，README 明确不建议用于生产环境；目前仅支持有向关系，双向关系与变长路径等仍在计划中。

  • 通过 cypher_execute 函数执行 Cypher 子集（CREATE、MATCH、WHERE、RETURN），CREATE 部分通过 70/70 TCK 测试
  • 提供 SQL 函数（graph_node_add、graph_edge_add、graph_is_connected、graph_density、graph_degree_centrality 等）与虚拟表接口，可混合使用 SQL 与图操作
  • 纯 C99 实现、无外部依赖，附 Python 3.6+ 绑定，支持并发访问

适用场景（解读层）

  • 已使用 SQLite 的应用需要以节点/边模型存储和查询图数据
  • 在专用图数据库之前用 SQLite 原型验证图功能
  • 边缘设备或移动应用中的嵌入式图分析
