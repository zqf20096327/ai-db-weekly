本地AI会话记忆库：以书/章/页结构存储对话证据，Python+SQLite+FTS5实现

综述（解读层）

AI-Memory-Book 是一个面向编程代理的本地会话记忆存储工具，将项目组织为书、任务为章、证据为页，保留原始对话文本和来源引用。技术栈为 Python 3.10+ 与 SQLite FTS5，通过 CLI、Python、MCP 和 HTTP 接口提供检索，默认词法检索无需嵌入模型或数据库服务器，支持 Claude Code、Codex、Gemini 等客户端共享同一数据库。v0.5.0 为 MIT 许可。

  • 支持按项目、任务、会话和原始回合定位证据，保留页 ID 与来源引用
  • 标识符检索支持驼峰、蛇形命名与缩写的跨风格匹配，且不改动原始拼写与项目边界
  • 默认词法摄取与检索不调用模型，仅需 SQLite FTS5；支持在线备份、导入校验与导出暂存

适用场景（解读层）

  • 会话或客户端切换后恢复约束、参数修正与失败尝试并继续任务
  • 代码评审或任务交接时打开引用页核对边界条件、错误信息等原始证据
  • 跨 Claude Code、Codex、Gemini 等多个客户端共享同一份项目存档
