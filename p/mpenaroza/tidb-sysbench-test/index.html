面向 TiDB Cloud 集群的 Sysbench 性能测试脚本套件

综述（解读层）

该仓库提供一组用于在 TiDB Cloud（Dedicated Tier）上执行 Sysbench 性能测试的 Lua 脚本与 Shell 脚本，包含 schema 初始化、数据填充和高并发测试流程。README 以 EC2 Ubuntu 实例（推荐 96 vCPU）为运行环境，给出从创建集群、配置 SSL 连接、导入 schema 与测试数据到运行测试及重置的完整步骤。适合需要在 TiDB Cloud 上复现并发测试的数据库使用者。

  • 提供 high_concurrency_test.lua、insert_dummy_data.lua 与配套 shell 脚本，用于数据填充与并发测试
  • 包含 schema.sql 与 sys-reset.sql，用于初始化表结构和通过 truncate 重置测试环境
  • README 给出 TiDB Cloud 集群配置参数：TiDB 3 节点、TiKV 3 节点、TiFlash 1 节点，各 16 vCPU

适用场景（解读层）

  • 在 TiDB Cloud Dedicated Tier 集群上执行高并发 Sysbench 测试
  • 需要可重复执行的测试数据填充与重置流程时
  • 评估 TiDB 在 EC2 客户端环境下的事务并发表现
