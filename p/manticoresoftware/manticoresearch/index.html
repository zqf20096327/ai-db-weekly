基于SQL的开源搜索引擎数据库，支持全文、向量与混合搜索

综述（解读层）

Manticore Search 是一个 C++ 编写的开源搜索数据库，用于全文检索、向量搜索和流式过滤，采用 SQL 作为原生查询语法并兼容 MySQL 客户端。它提供行式/列式两种存储、基于 Galera 的多主复制、MySQL/PostgreSQL/Kafka 等数据源同步，以及 HTTP JSON 与 Elasticsearch 兼容写入接口。需要注意其事务不承诺完整 ACID。

  • 支持全文搜索、向量搜索（KNN）、自动生成 embedding 与分块、以及通过 CALL CHAT 的对话式搜索
  • SQL 原生语法与 MySQL 协议兼容，提供 PHP/Python/Go/Java/Rust 等官方客户端及 HTTP JSON API
  • 支持实时插入、分片表、同步多主复制、基于 PGM-index 的二级索引与列式存储

适用场景（解读层）

  • 需要 SQL 或 MySQL 客户端接入的全文检索与日志/数据搜索场景
  • 结合全文与向量检索的混合搜索应用
  • 通过 percolate 表或 Kafka 集成对流式数据进行规则过滤
