开源搜索数据库，用 SQL 与倒排/向量索引实现全文与混合检索

综述（解读层）

Manticore Search 是一个面向搜索场景的开源数据库，使用 C++ 编写，GPLv3 许可发布。它支持全文检索、向量检索及二者结合的混合搜索，实时插入即刻可查，并提供 MySQL 兼容的 SQL 语法与 HTTP JSON API 两种访问方式。适用于需要在自有基础设施中运行搜索服务的团队，可用作独立搜索服务器，也支持 MySQL、PostgreSQL、Kafka 等数据源同步。

  • 提供全文、向量与混合搜索，支持实时插入、分片表与基于 Galera 的多主同步复制
  • 以 SQL 为原生语法，兼容 MySQL 客户端，同时提供 HTTP JSON API 及多种语言的官方客户端
  • 包含行式、列式、docstore 三种存储方式，支持基于 PGM-index 的二级索引与代价优化器

适用场景（解读层）

  • 为应用搭建全文/混合搜索服务，如站内搜索、日志查询
  • 通过 percolate 表或 Kafka 集成对流数据进行过滤
  • 从 MySQL、PostgreSQL、XML、CSV 等数据源同步数据建立搜索索引
