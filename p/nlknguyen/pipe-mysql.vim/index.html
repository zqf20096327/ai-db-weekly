基于 pipe.vim 的 Vim 插件，在编辑器内交互执行 MySQL 语句

综述（解读层）

pipe-mysql.vim 是一个 Vim 插件，依赖 pipe.vim，用于在 Vim 中对本地或远程（经 SSH）的 MySQL / MariaDB / Amazon Aurora 数据库执行语句。它支持按文件、单行或可视块执行 SQL，结果返回本地 Preview 窗口；远程执行时本地无需安装 MySQL。通过按键映射设置 SSH 与 MySQL 登录信息，每个缓冲区登录信息独立，支持在 .vimrc 中预设登录信息或用 .my.cnf 类配置文件。默认作用于 filetype 为 mysql 的缓冲区。

  • 支持本地或经 SSH 远程执行 MySQL 语句，远程执行时本地无需安装 MySQL
  • 可按整个脚本文件、当前行、可视选中块或自定义提示输入执行语句，结果以表格或批量视图显示
  • 每个缓冲区维护独立登录信息，支持动态设置 SSH/MySQL 连接、切换数据库，以及查看光标所在表的列表、SELECT、结构描述与建表定义

适用场景（解读层）

  • 在 Vim 中编写 MySQL 脚本并在远程服务器上执行、本地查看结果
  • 需要频繁在多个数据库连接间切换并管理各缓冲区独立登录信息的场景
  • 对光标处表执行常用查询（列表、SELECT、DESCRIBE、建表语句）的日常数据库操作
