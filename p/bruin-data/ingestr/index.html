🧭 简介解读层（AI·证据行可回查）

单命令行数据摄取工具，用 URI 标志在数据库间复制数据

综述（解读层）

ingestr 是一个命令行工具，通过 source-uri/dest-uri 等标志即可在数据库、文件和 SaaS 平台之间复制表数据，无需编写代码；亦提供 pip 包和 Python SDK，Python 数据经 Arrow IPC 流传输。支持 append、merge、delete+insert 三种增量加载模式，部分数据库支持 CDC。许可证为 FSL 1.1，禁止用于构建竞争性摄取类产品。

  • 通过单一 CLI 命令（--source-uri/--dest-uri 等）从源复制表到目标，支持数据库、本地文件（CSV/Parquet/JSON 等）及众多 SaaS 平台作为源或目标
  • 提供 append、merge、delete+insert 三种增量加载模式；Postgres、MySQL、MongoDB、SQL Server 等支持 CDC
  • pip 包可嵌入 Python 使用，行/生成器/DataFrame 经 Arrow IPC 流发送，另有 mmap 传输与 CLI 直通接口

适用场景（解读层）

  • 在数据库与数据仓库（如 Postgres 到 BigQuery）之间迁移或同步表数据
  • 将 SaaS 平台（Stripe、HubSpot、Google Ads 等）数据定期加载进仓库
  • 在 Python 代码中把 DataFrame、生成器或行数据写入 DuckDB 等目标库
