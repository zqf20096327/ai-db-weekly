🧭 简介解读层（AI·证据行可回查）

单命令行工具，用于在数据库与数据平台间复制数据

综述（解读层）

ingestr 是一个命令行工具，通过 URI 标志指定源和目标，把表数据从一个系统复制到另一个，无需编写代码。它支持 Postgres、MySQL、Snowflake、BigQuery 等数据库和众多 SaaS 平台，提供 append、merge、delete+insert 三种增量加载模式；pip 包还可作为 Python SDK，以 Arrow IPC 流发送 DataFrame 或生成器数据。对部分数据库支持 CDC。许可证为 FSL 1.1，限制用于竞争性数据管道产品。

  • 通过命令行标志在任意支持的源与目标之间复制表数据，无需编写代码
  • 支持 append、merge、delete+insert 三种增量加载方式
  • pip 包可作为 Python SDK 使用，以 Arrow IPC 流传输 DataFrame、生成器数据

适用场景（解读层）

  • 在数据库与数据仓库（如 Postgres 到 BigQuery）之间同步表数据
  • 从 CSV、Parquet 等本地文件或 SaaS 平台装载数据到 DuckDB、Snowflake 等目标
  • 在 Python 程序中将 DataFrame 或生成器数据写入目标数据库
