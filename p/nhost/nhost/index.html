开源后端即服务平台，基于 PostgreSQL 与 Hasura 提供 GraphQL API

综述（解读层）

Nhost 是一组开源软件组合的后端服务，包含 PostgreSQL 数据库、Hasura 即时 GraphQL API、认证、存储和 Node.js 无服务器函数。面向前端开发者使用，提供托管平台、本地 CLI 和自托管（docker-compose）三种运行方式。CLI 内置 MCP 服务器，可与 AI 编码助手交互；MIT 许可证授权。

  • 集成 PostgreSQL、Hasura GraphQL API、认证、存储与 Node.js 无服务器函数
  • CLI 支持本地开发，跟踪数据库迁移与 Hasura 元数据，并内置 MCP 服务器供 AI 助手调用
  • 提供托管平台、本地 CLI 与 docker-compose 自托管三种使用方式，客户端支持 JavaScript/TypeScript 与 Dart/Flutter

适用场景（解读层）

  • 需要 SQL 数据库和 GraphQL API 的应用后端搭建
  • 使用 Next.js、Flutter 等前端框架开发并接入认证与存储
  • 本地开发或自托管完整的开源后端技术栈
