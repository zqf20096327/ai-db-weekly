AI Agent 工具调用运行时拦截与防篡改审计平台

综述（解读层）

PANOPTIS（原 AgentWatch）位于 Agent 与其工具之间，在工具调用执行前做出决策、执行后检查输出，并以 Merkle 链封存审计记录。通过 Python SDK、Claude Code hook、MCP 网关等 enforcing 集成接入，默认使用 SQLite 存储，pipx 安装后 panoptis up 启动本地 API 与仪表盘。覆盖经由受支持集成的调用，非沙箱；基于模式与解析器规则，无法捕获新型编码或改写式注入。

  • 决策管线按序执行威胁分析、RBAC、意图检查、人工审批等步骤，被拒绝的调用其工具体不会运行
  • 工具结果中的注入指令行在 Agent 读取前被隔离移除，其余内容保留
  • 记录按每 200 条或 30 秒封入 hash 链 Merkle 段，独立验证器可检测编辑、重排与截断；支持影子回放用证据回放运行并对比 traces

适用场景（解读层）

  • 为接入的 Python Agent、Claude Code 或 MCP 路由的工具调用提供执行前拦截与升级审批
  • 需要可验证审计记录的场景：Merkle 封存证据与独立验证器校验
  • 用影子回放将录制运行重放到新模型上，不接触真实环境即可对比行为差异
