用 Rust 从零实现的玩具级 ACID 关系型数据库管理系统

综述（解读层）

niwid-db 是一个用 Rust 编写的玩具数据库管理系统，用于探索内存与磁盘管理、ACID 特性、事务、索引和查询执行等数据库内部机制。它通过影子分页实现 ACID，采用槽式页面、LRU 页面淘汰和 B+ 树索引。除 SQL 语法解析使用 sqlparser-rs 外均从零实现；不支持主外键、无优化器和物理计划，每表仅允许单一写入者。

  • 通过影子分页实现 ACID（原子性、读已提交隔离、持久性），无需 WAL 或 MVCC
  • 实现 B+ 树索引、槽式页面、LRU 页面淘汰策略及嵌套循环连接
  • 支持事务提交/回滚、NOT NULL 与 UNIQUE 约束、EXPLAIN 与 EXPLAIN ANALYZE

适用场景（解读层）

  • 学习数据库内部机制：存储、索引、事务与查询执行
  • 通过 sqllogictest（.slt 文件）验证 SQL 执行行为
  • 通过目录表 `SELECT * FROM __CATALOG__` 或配套演示网站查看元数据与示例
