🧭 简介解读层（AI·证据行可回查）

Node.js 的 ORM，通过 define() 模式推导类型并提供 Promise API

综述（解读层）

Toshihiko 是一个面向 Node.js 的 ORM，当前 v2 处于预发布版本，要求 Node.js 22 及以上。它以 Model 为中心组织 API（Model、Query、Yukari、find() 等），行类型直接从 define() 的 schema 推导，无需单独维护行接口。核心通过适配器包连接数据库，MySQL 适配器基于 mysql2 预编译执行，另提供 Redis/Memcached 缓存包，更新和删除前会失效对应主键缓存条目。

  • Schema 推导 TypeScript 类型：行字段、主键、默认值由 define() 直接推断
  • Monorepo 内含核心、MySQL 适配器（基于 mysql2）、Redis 与 Memcached 缓存包，各包独立发布
  • 查询读取并填充缓存，支持按 Model 覆盖、全局配置或用 { noCache: true } 单次绕过

适用场景（解读层）

  • 需要 TypeScript 类型推断的 MySQL 应用数据层
  • 希望为查询接入 Redis 或 Memcached 缓存的 Node.js 服务
  • 按适配器契约编写自定义数据库扩展的团队
