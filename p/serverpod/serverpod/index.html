基于 Dart/Flutter 的全栈应用服务器框架，含 ORM 与代码生成

综述（解读层）

Serverpod 是面向 Flutter/Dart 生态的开源后端框架，用 Dart 编写服务端并自动生成类型安全客户端、数据库 schema 与迁移。内置 Postgres ORM、认证、流式通信、缓存、日志等模块，支持 hot reload 本地运行和一键部署。需 Flutter 3.44.4+；主包采用 SSPL 许可，禁止将其作为云服务转售。

  • 以 YAML 定义数据模型，自动生成服务端与 Flutter 客户端的类型安全 Dart 类及数据库迁移
  • 支持 PostgreSQL ORM（含 relations、事务、pgvector、PostGIS）、多种第三方认证、Dart 流式方法、Redis 集群缓存与文件上传（S3、GCS、R2 等）
  • serverpod start 一条命令启动数据库、服务器与 Flutter 应用并支持热重载；测试框架在 dart test 中运行真实服务器与隔离数据库

适用场景（解读层）

  • 为 Flutter 应用构建后端服务，端到端使用 Dart 保持类型安全
  • 配合 AI 编码代理（Claude Code、Cursor 等）开发全栈应用，通过 MCP server 读取日志、热重载与执行迁移
  • 开发 Web 页面、Webhook 与 REST API，或部署 Flutter Web 应用至 Serverpod Cloud 或自托管环境
