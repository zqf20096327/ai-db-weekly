面向 AI 应用的时序记忆引擎，以确定性生命周期管理持久化记忆

综述（解读层）

Chronem 是一个早期阶段的开源 Python 记忆引擎，将自然语言捕获转为带生命周期的结构化记忆，覆盖 FACT、PREFERENCE、CURRENT_STATE、EVENT、INTENT 五类。核心机制为不依赖模型的生命周期决策（APPEND/NOOP/SUPERSEDE），保留溯源与历史，召回时可因证据不足而弃答；当前无语义/向量检索。面向需要确定性记忆管理的 AI 应用开发者，Apache-2.0 协议。

  • 提供五种记忆类型（FACT/PREFERENCE/CURRENT_STATE/EVENT/INTENT）及确定性生命周期决策，状态变更时保留被取代记录的历史
  • 支持 PostgreSQL 持久化适配器、捕获溯源与召回时的引用验证，证据不足时可选择弃答
  • 提供可选 OpenAI 适配器（Extractor/RecallPlanner/AnswerSynthesizer），持久化决策不交给模型

适用场景（解读层）

  • 为 AI 智能体或 LLM 应用构建带状态与历史的长期记忆存储
  • 需要保留证据来源与时间线、要求召回结果可溯源的场景
  • 无需 API 密钥的零网络演示与确定性记忆生命周期测试
