基于 Akka HTTP 与 Sangria 的 GraphQL 微服务脚手架模板

综述（解读层）

这是一个运行于 Lightbend 技术栈（JDK8/sbt）上的 Akka GraphQL 微服务样板项目，供开发者在其基础上构建自己的 GraphQL 服务。内置 Sangria GraphQL 集成、GraphiQL 界面、Slick 数据访问与 Flyway 迁移、HikariCP 连接池，并通过环境变量（SQL_URL、SQL_USER 等）配置数据库连接，测试时使用内存版 PostgreSQL。

  • 集成 Sangria 实现 GraphQL，并内置 GraphiQL 调试界面（localhost:8080）
  • 使用 Slick 与 Flyway 进行数据库访问和迁移，HikariCP 作为连接池，支持 AWS Cognito JWT 认证
  • 支持 Docker 镜像生成与 CloudFormation 部署，配置通过 application.conf 及环境变量注入

适用场景（解读层）

  • 在 Akka 技术栈上快速启动一个新的 GraphQL 微服务项目
  • 需要 PostgreSQL 数据库迁移与连接池配置的 Scala 服务开发
  • 面向 AWS 环境、使用 Cognito 用户池做认证的服务部署场景
