🧭 简介解读层（AI·证据行可回查）

基于 SwiftNIO 构建的非阻塞、事件驱动的 PostgreSQL Swift 客户端

综述（解读层）

PostgresNIO 提供连接 PostgreSQL 服务器的 Swift 客户端，包含用于连接、认证与查询的 PostgresConnection，以及负责连接池管理的 PostgresClient。它基于 SwiftNIO 实现 async/await 接口并支持背压，将 Swift 基本类型与 Postgres 传输格式自动转换。需先配置并调用 client.run() 后才能查询，要求 Swift 6.2+。

  • 提供 PostgresConnection 连接查询与 PostgresClient 连接池管理
  • 查询结果以 AsyncSequence（PostgresRowSequence）返回，支持逐行迭代与按类型解码
  • 字符串插值查询通过 PostgresQuery 实现参数绑定，防止 SQL 注入

适用场景（解读层）

  • Swift 服务端应用中连接和查询 PostgreSQL 数据库
  • 需要连接池管理多个数据库连接的场景
  • 支持 Unix Domain Socket 或 Network.framework 的 Apple 平台数据库访问
