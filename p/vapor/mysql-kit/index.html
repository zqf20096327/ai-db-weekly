综述（解读层）

MySQLKit 是 Vapor 生态中面向 MySQL 的 SQLKit 驱动，供服务端 Swift 开发者连接 MySQL 数据库。底层通过 MySQLNIO 异步通信，并借助 AsyncKit 实现连接池；支持结构体或 URL 字符串配置、Unix 域套接字连接，以及 MySQL 方言 SQL 查询的构建与序列化。要求 Swift 5.10+，支持 Ubuntu 20.04+ 和 macOS 10.15+，采用 MIT 许可证。

  • 基于 MySQLNIO 以异步方式连接并与 MySQL 服务器通信
  • 通过 AsyncKit 提供 EventLoopGroupConnectionPool 连接池，支持随机或指定 event loop 获取连接
  • 实现 SQLKit 驱动接口，支持构建与序列化 MySQL 方言 SQL 查询

适用场景（解读层）

  • 在 Ubuntu 或 macOS 上的服务端 Swift 项目中连接并查询 MySQL 数据库
  • 在 Vapor 服务中通过 SQLKit 构建类型化的 MySQL SQL 查询
  • 需要按 event loop 管理数据库连接池的异步 Swift 应用
