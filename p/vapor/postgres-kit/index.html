基于 PostgresNIO 的 PostgreSQL SQLKit 驱动，提供异步连接池。

综述（解读层）

PostgresKit 是 Swift 生态中的 PostgreSQL SQLKit 驱动，通过 SQLKit API 构建并序列化 Postgres 方言 SQL，底层使用 PostgresNIO 异步连接数据库，并提供连接池管理。支持主机、URL 与 Unix 域套接字三种配置方式；README 建议直接使用者优先用 PostgresNIO 的 PostgresClient，AsyncKit 连接池已弃用（FluentKit 场景除外）。适用于 Vapor 等服务端 Swift 项目。

  • 通过 SQLKit API 构建和序列化 Postgres 方言 SQL 查询
  • 基于 PostgresNIO 实现异步通信，提供连接池（PostgresClient 或 AsyncKit 池）
  • 支持主机/端口、URL 字符串及 Unix 域套接字配置方式，运行于 Ubuntu 20.04+ 与 macOS 10.15+

适用场景（解读层）

  • 为 Vapor 或其他服务端 Swift 项目提供 PostgreSQL 访问层
  • 配合 Fluent ORM 使用（需采用 AsyncKit 连接池）
  • 直接通过 SQLKit API 以类型化链式查询操作 PostgreSQL 数据库
