基于 SwiftNIO 实现的 MySQL 非阻塞事件驱动 Swift 客户端库。

综述（解读层）

MySQLNIO 是一个用于连接、认证和查询 MySQL 服务器的 Swift 客户端包，通过 SwiftNIO channel handler 直接实现 MySQL 私有线路协议的解析与序列化，不依赖 libmysqlclient。它定位为低层、无倾向性的协议实现，明确不包含连接池、Codable 集成和查询构建，高层用法需配合 vapor/mysql-kit 等包。支持 Swift 6.0+，采用 SwiftPM 安装。

  • 提供简单（text）与参数化（prepared statement）两种查询方式，后者以二进制格式传输数据
  • 提供 MySQLData 类型，在 MySQL 线路格式与 Swift 原生类型之间进行转换
  • 支持 TLS 配置、Unix domain socket 连接，无额外的系统依赖

适用场景（解读层）

  • 作为基础包供更高层 Swift MySQL 客户端库（如 mysql-kit）复用线路协议逻辑
  • 在 Ubuntu 20.04+、macOS 10.15+、iOS 13+ 等平台上连接并查询 MySQL 服务器
  • 直接执行 SQL 语句（含绑定参数的查询）并处理返回行数据
