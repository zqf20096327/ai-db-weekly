🧭 简介解读层（AI·证据行可回查）

自托管的 AI 聊天代理平台，基于 PostgreSQL 混合检索回答自有知识库问题

综述（解读层）

ChatVia.ai 是一个可自托管的 AI 聊天代理平台，供团队创建基于自有知识（文件、网页、文本、问答对、音视频）回答问题的代理。检索采用 PostgreSQL 内的向量与关键词混合搜索加重排序。代理可通过托管聊天页、网站挂件、六个消息应用或 REST API 发布；支持 MCP 工具、护栏、人工转接与多渠道发布，可通过 Docker、Ubuntu 脚本或源码安装。

  • 知识源支持文件、网页、纯文本、问答对、音频和视频，经 PostgreSQL 内向量与关键词混合搜索及重排序生成回答
  • 每个代理可配置不同模型，包括闭源与开放权重模型
  • 支持 MCP 服务器与自定义函数工具，工具调用可配置人工审批并记录日志

适用场景（解读层）

  • 将基于自有知识库的聊天代理部署到网站挂件、托管页面或 REST API
  • 客服场景下的知识问答、表单与线索收集、人工转接
  • 需数据留在自有基础设施内的自托管部署（Docker 或 Ubuntu 服务器）
📖 README 首段存档原文 · 程序抽取

ChatVia.ai is a free, self-hosted platform for AI chat agents that answer from your own knowledge. It runs on your server, so your files, chats and customer details stay with you.
