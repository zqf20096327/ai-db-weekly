基于 PHP 与 jQuery/Bootstrap 的数据表格组件，实现分页、排序与筛选

综述（解读层）

php_bs_grid 是一个 PHP 数据表格（datagrid）类库，配合 jQuery 插件与 Bootstrap 3 前端，将 MySQL/MariaDB 或 PostgreSQL 数据库数据以表格展示，提供分页、排序、多类型筛选及导出 Excel 功能。后端依赖同作者的 dacapo 抽象层，使用预处理语句，支持模板化自定义与多语言。

  • 支持文本、数字、lookup、日期、autocomplete、多选复选框等六种筛选类型
  • 提供分页、简单与高级列排序，并可将会话状态保存至 $_SESSION
  • 使用预处理语句，支持固定 WHERE 条件，数据导出为 Excel .xlsx 文件

适用场景（解读层）

  • 在 PHP 应用中展示 MySQL、MariaDB 或 PostgreSQL 的数据库表数据
  • 需要带筛选、分页与排序功能的后台数据管理列表页
  • 需要将表格数据导出为 Excel 的数据查询界面
