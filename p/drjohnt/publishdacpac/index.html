基于 DAC Publish Profile 调用 SqlPackage 部署 SQL Server DacPac 的 PowerShell 模块

综述（解读层）

PublishDacPac 是一个 PowerShell 模块，核心命令 Publish-DacPac 通过比较 DacPac 与目标服务器上现有数据库生成部署脚本，并借助 DAC Publish Profile 控制架构、触发器、存储过程等升级细节。面向需要在本地 SQL Server 上自动化数据库部署的团队，可在 Azure DevOps、Octopus Deploy 等流程中调用。运行依赖 SqlPackage.exe，示例解决方案默认面向 SQL Server 2016。

  • 提供 Publish-DacPac 命令，依据 DAC Publish Profile 生成并执行部署脚本
  • 另含 Remove-Database、Ping-SqlDatabase、Find-SqlPackageLocations 等 8 个辅助命令
  • 已作为 Azure DevOps 扩展发布，支持持续部署场景

适用场景（解读层）

  • 在 Azure DevOps 构建/发布管道中自动化部署 SSDT 项目生成的 DacPac
  • 本地（on-premise）SQL Server 实例的数据库创建与升级
  • 配合 Octopus Deploy 进行服务器部署时的数据库发布
📖 README 首段存档原文 · 程序抽取

Publish-DacPac allows you to deploy a SQL Server Database DacPac to an on-premise SQL Server instance using a DAC Publish Profile.
