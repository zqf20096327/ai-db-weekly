面向 Azure DevOps 的 SQL Server 部署扩展集合

综述（解读层）

该项目包含多个 Azure DevOps 扩展，用于部署 Analysis Services 表格多维数据集、SQL Server 数据库（DACPAC，配合 DAC 发布配置文件）和 Integration Services 项目，也支持传入多个 SQLCMD 变量执行 SQLCMD 脚本。仓库 Wiki 介绍数据仓库 DevOps 基础、自建构建服务器与 Azure Pipelines 及测试套件的配置方法。适合需要在 Azure Pipelines 中部署 SQL Server 组件的团队。

  • 提供使用 DAC 发布配置文件部署 SQL Server 数据库 DACPAC 的扩展
  • 提供部署、更新和删除 SSAS 表格模型（Tabular Cube）的扩展
  • 支持传入多个 SQLCMD 变量执行单个或多个 SQL/SQLCMD 脚本

适用场景（解读层）

  • 在 Azure Pipelines 中以 DAC 发布配置文件部署数据库 DACPAC
  • 部署、更新或删除 SSAS 表格多维数据集模型
  • 在流水线中运行带变量的 SQLCMD 脚本
