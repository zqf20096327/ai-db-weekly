综述（解读层）

dbmigrations 是一个用于创建、管理和安装关系数据库模式迁移的 Haskell 库，并附带各数据库对应的命令行工具。迁移以 YAML 文件存于文件系统目录，可声明相互依赖，升级时按依赖关系确定缺失项并按序安装，已安装迁移记录在数据库的追踪表中。支持 sqlite 和 postgresql 后端，mysql 后端因上游问题暂被禁用。

  • 迁移以 YAML 文件表示，支持声明式依赖，安装时按依赖顺序执行
  • 提供 dbm new/apply/revert/test/list/upgrade-list 等命令，test 命令在事务中安装并回滚以验证迁移
  • 支持环境变量、配置文件及 linear migrations 模式自动选择依赖

适用场景（解读层）

  • 需要对 SQLite 或 PostgreSQL 数据库模式变更进行版本化管理的项目
  • 迁移之间存在依赖关系、需按指定顺序安装或回滚的场景
  • 希望迁移以纯文本 YAML 文件形式纳入版本控制存储的团队
