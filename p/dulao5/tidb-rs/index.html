TiDB SQL 层的实验性 Rust 实现，以只读节点形式加入 Go TiDB 集群。

综述（解读层）

tidb-rs 是 TiDB SQL 层的 Rust 移植原型，从 Go TiDB v8.5.8 按块移植，作为只读节点与 Go TiDB 共存于同一集群。目前仅支持 autocommit 单表 SELECT（整数主键），通过 PD 客户端、etcd 注册和 TiKV coprocessor 读取集群数据，结果须与 Go TiDB 完全一致。优化器、计划缓存、写入事务、权限系统等尚未实现，构建需 C++ 编译器、CMake、protoc 与 OpenSSL。

  • 实现批量与异步 TSO 获取、乐观 schema 校验及 etcd 注册与 MDL 上报，行为对齐 Go TiDB
  • 复用 TiKV 的 tidb_query_* crate 做行解码与下推求值，解析器移植自 TiDB 的 parser.y
  • 实现 MySQL 协议（含 TLS、prepared statements）与 /metrics、/status 端口，指标名与 Go TiDB v8.5.8 一致

适用场景（解读层）

  • 在运行 Go TiDB 的 tiup playground 或既有集群中加入一个 Rust 只读 SQL 节点进行实验
  • 面向 sysbench oltp_read_only 类型的单表整数主键点查与扫描查询场景
  • 研究 TiDB SQL 层结构与 Go 到 Rust 移植方法的参考实现
