🧭 简介解读层（AI·证据行可回查）

扫描 mysqldump 导出的 MySQL Schema，检测并自动修复 TiDB 不兼容项

综述（解读层）

该工具读取 mysqldump 生成的 Schema 文件，检测存储过程、触发器、全文索引等 TiDB 不兼容特性，生成逐行报告；加 --apply 参数可直接修改原文件完成自动修复。README 同时列出无法从 Schema 检测、需应用层验证的运行时特性。适用于迁移前准备数据库的 DBA 和开发者。

  • 检测存储过程、触发器、事件、全文/空间索引等 10+ 类 Schema 层不兼容项
  • 提供 --apply 选项，自动执行删除或替换 utf8mb4 等修复动作并原地修改文件
  • 输出逐行兼容性报告，并标注仅告警项与需人工验证的运行时特性清单

适用场景（解读层）

  • MySQL 迁移到 TiDB 前批量检查 mysqldump 导出的建表脚本
  • 按文件名模式扫描多个 Schema 文件并自动移除不支持的定义
  • 梳理需要应用层代码配合验证的运行时不兼容特性
