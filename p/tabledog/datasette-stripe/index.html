🧭 简介解读层（AI·证据行可回查）

在单个 Docker 容器中运行 Datasette 与 tdog，将 Stripe 账户转为可 SQL 查询的 SQLite 数据库

综述（解读层）

该项目是一个 Web 应用，把 tdog CLI 与 Datasette 打包进单个 Docker 容器，将 Stripe 账户数据转换为 SQLite 数据库并提供 Web SQL 查询界面，面向需要用 SQL 查询自己 Stripe 数据的用户。它通过轮询 /events 实时同步变更，支持全文搜索、导出 Excel、快照下载和 JSON/GraphQL API；使用时需提供 Stripe 密钥，首次启动会执行全量下载。

  • 通过轮询 Stripe /events 接口将变更实时应用到 SQLite 数据库
  • 提供全文搜索、可分享的查询 URL、表格导出 Excel 及 JSON/GraphQL API
  • SQLite 数据库可通过 curl 与 HTTP basic auth 下载快照，供本地 GUI 或其他编程语言使用

适用场景（解读层）

  • 团队内用 SQL 查询与共享 Stripe 账户数据
  • 后端服务器通过 JSON/GraphQL API 查询 Stripe 状态而无需处理 webhooks
  • 在本地或 Docker 环境中运行，对 Stripe 数据进行全文搜索与导出分析
