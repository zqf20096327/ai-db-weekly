通过 planner 钩子将外部查询计划树注入 PostgreSQL 直接执行的扩展

综述（解读层）

PgCuckoo 是一个 PostgreSQL 扩展，利用 planner 钩子注入外部生成的计划树并由查询执行器执行。它提供表值 SQL 函数 plan_execute(·)，并附带一个基于 Haskell 的计划装饰器，通过规则推断和查询系统目录补全骨架计划（如表达式类型、运算符重载解析）。适用于需要绕过优化器直接执行外部代码生成器产出的计划的研究与开发场景。

  • 通过 planner 钩子注入外部计划树并由 PostgreSQL 执行器执行
  • 提供表值 SQL 函数 plan_execute(·) 接收计划文本表示
  • 基于 Haskell 的计划装饰器可补全骨架计划并解析节点引用

适用场景（解读层）

  • 外部代码生成器生成计划树后注入 PostgreSQL 执行
  • 研究或调试查询计划的实验环境
  • 需要绕过常规优化流程直接执行指定计划的场景
