🧭 简介解读层（AI·证据行可回查）

sqly 是在内存 SQLite 上对 CSV/TSV/JSON/Excel 等文件执行 SQL 的命令行工具

综述（解读层）

sqly 将 CSV、TSV、LTSV、JSON、Parquet、Excel、ACH、Fedwire 等文件载入内存 SQLite 数据库后执行 SQL，供需要在命令行查询本地文件的用户使用。文件名即表名，支持跨格式 JOIN、窗口函数与 CTE，透明读取多种压缩格式，可通过 --dialect 使用 MySQL/PostgreSQL/GoogleSQL 语法，并提供交互式 shell 与 .save 写回功能。会话仅在内存中运行，不支持事务控制等部分 SQLite 语句。

  • 将多种格式文件载入内存 SQLite3 数据库，文件名作为表名，无需声明 schema 或导入步骤
  • 支持跨格式 JOIN、CTE、窗口函数、json_extract()，并可透明读取 .gz、.bz2、.lz4 等压缩文件
  • 提供交互式 shell（tab 补全、历史记录、dot-commands）、.save 写回原文件（保留格式与压缩），以及 --inspect 输出文件结构信息

适用场景（解读层）

  • 对日志、数据文件执行 SQL 查询、聚合或窗口函数分析
  • 不同格式文件之间的 JOIN 查询与格式转换（如 CSV 转 Excel/JSON）
  • 通过管道将查询结果交给 jq、awk、sort 等工具进一步处理，或交互式探索未知结构的数据文件
