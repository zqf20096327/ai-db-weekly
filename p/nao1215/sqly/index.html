🧭 简介解读层（AI·证据行可回查）

用 SQL 查询 CSV、TSV、JSON、Parquet、Excel 等文件的命令行工具

综述（解读层）

sqly 是一个用 Go 编写的命令行工具，将 CSV、TSV、LTSV、JSON、JSONL、Parquet、Excel、ACH、Fedwire 等格式的文件加载进内存中的 SQLite3 数据库后执行 SQL。它面向需要在终端对本地文件做查询、连接与格式转换的用户，支持跨格式 JOIN、窗口函数、CTE，可通过 --dialect 书写 MySQL/PostgreSQL/GoogleSQL 语法的查询，并用 .save 将修改写回源文件。

  • 支持 CSV、TSV、LTSV、JSON、JSONL、Parquet、Excel、ACH、Fedwire 等格式，并将透明读取 .gz、.bz2、.xz 等压缩文件
  • 文件即表：不同格式文件可在同一条 SQL 中作为表 JOIN，SQLite 的窗口函数、CTE 和 json_extract 等均可用
  • 提供交互式 shell，包含关键词/表/列的补全、跨会话历史、.edit 外部编辑器及 .save 将更改写回源文件

适用场景（解读层）

  • 在终端中用 SQL 查询、筛选、聚合本地表格文件
  • 对不同格式的多个文件执行跨格式 JOIN 或格式转换
  • 通过管道将查询结果以 jsonl/tsv 等格式输出给 jq、awk 等其他工具
