🧭 简介解读层（AI·证据行可回查）

将 CSV、JSON、Parquet、XLSX 等多种文件载入内存 SQLite 供 SQL 查询的 Go 库

综述（解读层）

filesql 是一个 Go 库，通过 database/sql 接口将 CSV、TSV、LTSV、JSON、JSONL、Parquet、XLSX、ACH、Fedwire 等文件载入内存 SQLite 数据库，不依赖 cgo。每个文件对应一张以文件名命名的表，支持跨格式 join，可用 WithDialect 以 MySQL、PostgreSQL 或 GoogleSQL 方言书写查询（由库翻译为 SQLite 执行）。模块内还包含 prep 包用于加载前清洗校验行数据，以及基于它的交互式 shell sqly。支持从路径、目录、io.Reader 和 embed.FS 读取，支持多种压缩格式，可将内存中的修改以 DumpDatabase 或自动保存方式写回文件。需 Go 1.26.11 及以上。

  • 将 9 种格式（CSV、TSV、LTSV、JSON、JSONL、Parquet、XLSX、ACH、Fedwire）文件载入内存 SQLite，无 cgo 依赖，支持 .gz、.bz2、.xz、.zst、.snappy、.s2、.lz4 等压缩封装
  • 支持通过 WithDialect 以 MySQL、PostgreSQL、GoogleSQL 方言书写查询，由库翻译为 SQLite 执行；翻译覆盖声明范围的 SQL 子集，超出范围会报出具体行列位置
  • 同模块提供 prep 包用于加载前的行清洗与校验（去空格、大小写规范化、默认值填充、按行号报告错误），并可通过 DumpDatabase、EnableAutoSave 等将修改写回文件

适用场景（解读层）

  • 在 Go 程序中对本地多格式数据文件执行 SQL 查询，包括跨格式 join 与 json_extract() 嵌套查询
  • 数据入库前的清洗与校验流程，结合 prep 包在数据成为表之前处理行数据
  • 与 sqlc、GORM、sqlx、Bun、Squirrel、Ent 等常用 Go 数据库工具集成（仓库 examples 目录提供示例）
