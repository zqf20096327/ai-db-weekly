🧭 简介解读层（AI·证据行可回查）

基于 SpringBoot 与 Vue2、调用 ChatGPT 由表结构和需求生成 SQL 的前后端全栈平台

综述（解读层）

Text2SQL 是一个前后端分离的 NL2SQL 平台，前端 text2sql-web 基于 Vue2，后端 text2sql-api 基于 SpringBoot 与 MySQL，通过 OpenAI 接口根据用户输入的表结构和需求生成 SQL 语句。用户可导入数据库和表结构并选择具体表。运行需配置 OpenAI 密钥，后端启动前还需配置邮箱服务用于登录注册发送邮件。

  • 支持导入数据库和表结构，选择具体表后由 ChatGPT 生成对应的 SQL 语句
  • 在输出 SQL 后可提供该语句的优化建议
  • 前端使用 fetch-event-source 实现 SSE 流式输出，并集成 Monaco Editor 与 SQL Formatter

适用场景（解读层）

  • 开发人员通过表结构和自然语言需求生成 SQL 语句
  • 对已生成 SQL 获取优化建议
  • 作为前后端全栈项目用于学习 SpringBoot + Vue2 与 OpenAI 接口集成
