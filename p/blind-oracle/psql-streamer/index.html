🧭 简介解读层（AI·证据行可回查）

基于 PostgreSQL 逻辑复制协议、将数据库事件流式投递到 Kafka 的 Go 服务

综述（解读层）

psql-streamer 是一个用 Go 编写的数据流服务，通过 PostgreSQL 逻辑复制协议读取数据库事件并写入可配置的 sink（如 Kafka），也可从 Kafka 读取事件作为源。WAL 日志位置持久化于 BoltDB，并支持延迟确认以保留日志供事件重放。要求 PostgreSQL 10+，服务端需设置 wal_level=logical。适合需要消费数据库变更事件并接入流处理管道的团队。

  • 通过逻辑复制协议接收 PostgreSQL 事件并转换为统一 JSON 事件格式
  • WAL 日志位置持久化（BoltDB），支持 walRetain 参数实现延迟确认与事件重放
  • 提供 HTTP API：/health、/status、/stats、/metrics（Prometheus）、/debug

适用场景（解读层）

  • 将 PostgreSQL 数据库变更事件流式转发到 Kafka 供下游系统消费
  • 级联部署：从一个实例的 Kafka 输出读取事件作为另一个实例的源
  • 调试与测试场景中使用 stub sink 或 HTTP API 进行状态监控与统计查看
