一个零依赖、单目录、无需 Composer 的 PHP 8.3+ 自包含后端框架

综述（解读层）

Aether-PHP 是一个面向 REST API、Web 应用和 SaaS 后端的自包含 PHP 框架，要求 PHP 8.3+，整个框架在 1MB 以内且不依赖 Composer 或运行时第三方包。它内置自动加载器、查询构建器、会话层与中间件管道；路由通过 PHPDoc 注解声明并自动扫描生成，数据库支持 MySQL 与 SQLite（基于 PDO 预处理语句）。许可为 Source-Available，并非开源协议。

  • 无 Composer、无运行时依赖，克隆后用 PHP 内置服务器即可运行，体积小于 1MB
  • 路由通过控制器方法上的 PHPDoc 注解声明，支持动态参数提取与 APCu 路由表缓存
  • 内置安全层：Argon2ID 密码哈希、CSRF 防重放令牌、HMAC-SHA256 签名会话、IP 限流、SSRF 防护与 SQL 标识符白名单校验

适用场景（解读层）

  • 构建 REST API 或 Web 应用的后端服务
  • 部署环境受限、不希望引入包管理器与构建流程的项目
  • 需要自带认证、CSRF、限流等安全中间件的 SaaS 后端原型开发
