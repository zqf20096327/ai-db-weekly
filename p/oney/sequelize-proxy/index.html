基于 Sequelize 的代理层，通过合并查询解决 GraphQL 中的 N+1 问题

综述（解读层）

sequelize-proxy 在 Sequelize 之上增加代理层，将 findByPk 和 get[Association] 等多次调用合并为单条 SQL 查询，用于缓解 GraphQL 查询中的 N+1 问题。它依赖 sequelize-typescript，通过 findByPk_、$get_(association) 等代理方法触发优化查询，适用于以 Sequelize 为 ORM 的 GraphQL 服务端项目。

  • 支持 hasOne、belongsTo、hasMany、belongsToMany 四种关联的查询合并
  • 提供 findByPk_ 与 $get_(association) 代理方法以启用优化查询
  • README 示例中 6 层深度的 GraphQL 查询仅执行 6 条 SQL

适用场景（解读层）

  • GraphQL 服务端存在 findByPk 或关联读取引发的多次数据库查询
  • 使用 sequelize-typescript 定义模型并需要合并关联查询的项目
  • 多层嵌套的 GraphQL 查询希望将 SQL 数量与查询深度对应
