Go 编写的嵌入式单文件 SQL 数据库，通过 database/sql 驱动接入

综述（解读层）

MiniSQL 是一个用纯 Go 实现的嵌入式单文件 SQL 数据库，提供 database/sql 驱动，适合需要在 Go 进程内嵌入数据库且不引入 CGO 的开发者。存储采用 B+ 树加 WAL 实现崩溃恢复，读使用 MVCC 快照隔离，写为单写者串行化，且要求连接池最大连接数设为 1。

  • 纯 Go 实现零 CGO，支持 JSON、UUID 原生列类型与全文检索、JSON 倒排索引、向量相似度检索（HNSW ANN 索引）
  • 读取采用 MVCC 快照隔离，写入为串行单写者，B+ 树存储配合 WAL 与崩溃恢复
  • 支持 AES-256-CTR 页级加密及 HKDF 密钥推导，提供 CLI shell 与 go get/database/sql 驱动接入方式

适用场景（解读层）

  • Go 应用内嵌轻量级 SQL 数据存储，需要免 CGO 部署
  • 需要全文检索或向量相似度检索的本地数据场景
  • 对数据文件要求加密存储的应用
