综述（解读层）

SimpleBase 是一个以单个 Go 二进制运行的后端服务，提供 SQL 表、JSON 集合与 KV 三种数据模型（落盘为 DuckDB 或 SQLite 单文件），并包含对象存储、进程内 Go 云函数、定时任务、事件触发器、SSE 实时订阅、备份恢复与 LLM 网关，附带 Vue 控制台与 CLI。本地默认用本地盘，生产可切换 S3 作持久层；部署为单写实例（副本数为 1），建多个用户库会被拒绝。适合需要单进程自托管后端能力的开发者。

  • 支持 SQL 参数化查询/事务、JSON 集合（filter/投影/patch/导入导出）与 KV（String/Hash/List/Set/ZSet/TTL）共用一个单文件库
  • 提供 gofunction 解释器运行的云函数、cron/interval/once 定时任务、事件触发器与 SSE 实时订阅（支持 Last-Event-ID 回放）
  • 包含 API Key HMAC 存储、权限位与 Scoped Key、SQL 守卫、审计日志脱敏，以及 OpenAI 兼容的 LLM 网关接口

适用场景（解读层）

  • 单进程自托管后端：本地以本地盘起步，生产切换到 S3 兼容存储作在线持久层
  • 通过 simplebase.json 声明库/迁移/函数/定时任务，实现本地开发与云端幂等重放部署
  • 需要 LLM 网关、云助手及自动化任务（定时/触发/订阅）的业务站点开发
