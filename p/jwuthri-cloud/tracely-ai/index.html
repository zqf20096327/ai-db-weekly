🧭 简介解读层（AI·证据行可回查）

面向 AI Agent 的 Trace 原生 CI/CD 平台，将生产失败固化回放用例

综述（解读层）

Tracely 是一个 MIT 许可、可自托管的 AI Agent 观测与测试平台。它通过 OTLP 接收 Agent trace，用 LLM 评审与结构化检查打分，将失败按签名与嵌入聚类成 issue，并把失败 trace 固化为含工具/LLM 输出 fixture 的回归用例，供 CI 离线回放并通过 tracely gate 阻断 PR。技术栈含 ClickHouse、Postgres、Redis、MinIO，支持 Docker Compose 或 Railway 部署。

  • 通过 OTLP/HTTP 接收 trace，将 agent.id、conversation.id 等语义提升为索引列，支持对话级/运行级/span 级的 LLM 评审与无模型结构化检查
  • 将失败 trace 固化为携带录制 fixture 的密封回归用例，附 fail-to-pass 契约；CI 回放离线进行，无需 API key 或模型调用
  • 提供 `tracely simulate/replay/gate` 命令与 GitHub Action，失败时输出非零退出码、commit status 与 PR 评论；API 兼作 MCP 端点

适用场景（解读层）

  • 为在生产中持续接收 trace 的 AI Agent 应用建立失败检测、聚类与告警流程
  • 将已知的失败 trace 转为回归用例，在 CI 中阻断引入同类回归的 PR
  • 自托管部署需要 trace 存储、评估打分与失败告警完整栈的团队
