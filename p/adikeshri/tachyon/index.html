🧭 简介解读层（AI·证据行可回查）

Rust 编写的单二进制自托管全文搜索引擎，支持 BM25 与容错检索

综述（解读层）

Tachyon 是用 Rust 实现的开源全文搜索引擎，以单个二进制或 Docker 容器运行，通过 REST API 提供文档索引与检索。核心能力包括 BM25 相关性排序、基于 Damerau-Levenshtein 的拼写容错、过滤表达式、分面统计、排序与自动补全。它定位为文本搜索而非向量数据库；README 明确列出尚未实现分布式集群、副本、同义词、词干化、地理搜索等功能，分析数据在重启后不保留。适用于需要自托管文本检索的应用场景。

  • 支持 BM25 相关性评分、逐字段权重提升、短语匹配与拼写容错（Damerau-Levenshtein）
  • 支持过滤表达式（比较、集合、逻辑运算）、全结果集分面统计、数值排序与容错自动补全
  • 写入经 WAL 持久化，memtable 满后刷盘为不可变段并做流式 k 路合并；提供 Prometheus 指标与 API key 认证

适用场景（解读层）

  • 为电商目录、内容站等应用添加文本搜索、过滤与分面功能
  • 需要拼写容错搜索和自动补全的输入框场景
  • 自托管环境下的单节点全文检索服务
