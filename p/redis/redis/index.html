内存键值数据库，提供多种数据结构与查询引擎

综述（解读层）

Redis 是内存数据存储服务器，面向构建实时数据驱动应用的开发者，支持缓存、会话存储、消息队列与向量查询等场景。数据主要保存在内存中，提供字符串、JSON、哈希、流等数据类型及事务、脚本能力。自 v8.0 起 Redis Community Edition 更名为 Redis Open Source，可通过 Docker、二进制包或源码编译安装。

  • 提供字符串、JSON、哈希、列表、集合、有序集合、流、时间序列等多种数据类型，以及 Bloom 过滤器、t-digest 等概率结构
  • 支持向量搜索、全文搜索、地理空间查询与聚合的 Redis Search 查询引擎
  • 实现事务与脚本、发布/订阅，并提供模块 API 以扩展新命令

适用场景（解读层）

  • 为应用缓存高频数据，支持多种淘汰策略、键过期与哈希字段过期
  • 服务间消息传递：任务队列、发布/订阅、事件流
  • GenAI 应用中的 LLM 记忆、语义缓存与 RAG 内容检索
