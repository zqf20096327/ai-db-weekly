CMU 数据库课程配套的教学用关系数据库管理系统

综述（解读层）

BusTub 是卡内基梅隆大学为其数据库系统导论课程（15-445/645）开发的教学用关系数据库管理系统，包含课程项目代码。修完全部课程项目后，系统可支持基本 SQL 并提供交互式 shell。README 明确说明其仅用于教学、不可用于生产环境；官方支持环境为 Ubuntu 24.04 和 macOS，不支持 WSL；选课学生须以私有仓库完成作业且不得公开实现代码。

  • 支持基本 SQL，附带交互式 shell
  • 提供课程作业的 Gradescope 在线评测，向非 CMU 学生在截止日期后开放
  • 构建支持 Debug 模式，默认启用 AddressSanitizer，可通过 CMake 选项启用 thread 等 sanitizer

适用场景（解读层）

  • 作为 15-445/645 课程项目完成数据库系统各模块的实现练习
  • 非 CMU 学习者在截止日期后使用在线评测检验作业实现
  • 阅读源码研究课程项目对应的数据库组件实现方式
