基于 PHP 的 SQLite3 网页端数据库管理系统

综述（解读层）

SQLite Web Master 是一个通过浏览器管理 SQLite3 数据库的 PHP 应用，用于管理表、视图、触发器、索引等 schema 及数据内容，并支持多种格式的导入导出。运行需 PHP 5.3.3 及以上并加载 Sqlite3 扩展，项目 tmp 目录须可写；导入 MDB/XLS 文件需 Windows 平台并加载 dotnet_com 扩展。安装时需在 etc/config.php 中配置数据库文件、账户并注意数据库文件不可置于浏览器可直接访问的位置。

  • 管理 schema：可创建/更新/删除表、视图、触发器、索引
  • 支持数据的就地编辑与 blob 编辑器
  • 导入/导出 xml、csv、sql、mdb（Windows）、xls（Windows）格式内容

适用场景（解读层）

  • 通过浏览器管理 SQLite3 数据库的 schema 与数据
  • 在 xml、csv、sql、mdb、xls 与 SQLite 之间导入导出数据
  • 集中管理多个 SQLite 数据库文件（按文件夹分组）
