为 MySQL 服务器提供活动日志记录的开源审计插件

综述（解读层）

该插件是 Amazon RDS for MySQL 所用的审计插件，基于 MariaDB Audit Plugin 改写，适配 MySQL 5.7 与 8.0 的插件 API，用于记录服务器活动日志，常用于安全与合规场景。源码面向具备 C++ 能力、可自行编译的开发者发布，AWS 不提供质保与支持，且仅在 Amazon Linux 上经过测试，不支持 Windows。

  • 基于 MariaDB Audit Plugin，适配 MySQL 8.0 插件 API，另有 mysql-5.7 分支提供 5.7 兼容版本
  • 通过将源码复制到 MySQL 源码树中随 MySQL 构建一同编译，可选启用 MTR 测试
  • 安装方式为放置 server_audit.so 并在 my.cnf 配置 plugin_load_add 或执行 INSTALL PLUGIN 语句激活

适用场景（解读层）

  • 为 MySQL 5.7 或 8.0 服务器开启活动日志记录，用于安全审计与合规需求
  • 需要自行编译、定制或研究审计插件实现的 C++ 开发者
  • 在 Amazon Linux 环境下为 MySQL/MariaDB 部署审计日志能力

The Audit Plugin for MySQL Server is used by [Amazon RDS for MySQL](https://aws.amazon.com/rds/mysql/) to enable logging of server activity, typically for security and compliance purposes.
