基于 React 的 PostgreSQL 数据库性能实时监控仪表盘

综述（解读层）

dbHive 是一个面向 PostgreSQL 数据库的实时监控与分析工具，通过交互式仪表盘展示一个或多个数据库的性能指标。它提供查询执行时间、最频繁查询、冲突、死锁、缓存命中率等统计数据，支持加密账户登录和多数据库切换。使用需数据库加载 pg_stat_statements 扩展，且数据库用户权限可能需提升。开发者可通过 npm run dev 或 Docker 启动开发模式。

  • 提供查询执行时间统计，包括全库平均及按 SQL 查询类型分类的平均值
  • 支持查看冲突、死锁、回滚事务、缓存命中率、块命中、最频繁查询等指标
  • 数据在客户端加密，应用不存储用户数据库连接信息、用户名和密码

适用场景（解读层）

  • 开发和运维人员需要查看 PostgreSQL 数据库性能指标与慢查询
  • 需要在同一界面监控多个 PostgreSQL 实例并按需切换
  • 需要定位高频查询和查询耗时以进行数据库调优分析
