通过数据建模界面生成 React/Express/Apollo/GraphQL 样板代码的开发者工具

综述（解读层）

GraphQL Blueprint 是一款网页工具，开发者通过可视化界面建模数据库表和字段后，可自动生成 GraphQL 根查询、变更、客户端查询、服务端文件及 NoSQL schema 或 SQL 建表脚本并打包下载。支持 MongoDB、PostgreSQL、MySQL 数据库，本地运行需 npm install 后执行 npm run pack 和 npm run server。该项目由 GraphQL Designer 分叉迭代而来，采用 MIT 许可证。

  • 提供可视化数据建模界面，输入类型和字段后自动生成 GraphQL 根查询、变更、客户端查询代码
  • 支持 MongoDB、PostgreSQL、MySQL 多种数据库，可生成 NoSQL schema 或 SQL 建表脚本
  • 基于字段关系动态生成各 GraphQL 类型的 resolver，下载包内含说明文件

适用场景（解读层）

  • 为新 GraphQL 应用快速生成样板代码，减少重复的查询和变更编写工作
  • 对数据库 schema 进行数据建模时同步生成对应的 GraphQL 类型与数据库脚本
  • 在 React/Express/Apollo 技术栈中搭建包含 GraphQL 的全栈应用初始结构
