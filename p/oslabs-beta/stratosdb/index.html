面向 AWS RDS PostgreSQL 实例的开源图形界面工具

综述（解读层）

StratosDB 是一个基于 NodeJS 和 React 的开源 GUI 应用，用于连接 AWS RDS 上的 PostgreSQL 数据库实例。用户填入用户名、主机端点、数据库名和密码即可连接，并通过内置代码编辑器执行 psql 命令、导入 .sql/.txt 文件、运行 SELECT 查询查看结果表格和以毫秒计的查询耗时折线图。项目处于 Beta 阶段，通过 git clone 并执行 npm install、npm run beta 在本地 8080 端口运行，采用 MIT 许可证。

  • 通过输入 AWS RDS 端点、用户名、数据库名和密码连接 PostgreSQL 实例
  • 内置代码编辑器支持 psql 命令（如 CREATE TABLE、INSERT INTO）并可导入 .sql/.txt 文件
  • 以折线图展示每次成功执行的 SELECT 查询的耗时（毫秒），悬停可查看对应查询

适用场景（解读层）

  • 为 AWS RDS PostgreSQL 实例编写并执行 psql 查询
  • 观察 SELECT 查询的执行耗时以了解现有 schema 设计下的性能表现
  • 导入 .sql 或 .txt 文件以填充内置编辑器中的代码基础
