🧭 简介解读层（AI·证据行可回查）

DraQLa 是通过内省 PostgreSQL 数据库自动生成 GraphQL 模式的迁移辅助工具

综述（解读层）

DraQLa 是一款 GraphQL 迁移辅助工具，用户输入 PostgreSQL 数据库的 URI 后，它读取库中的表和关系，生成包含类型与 resolver 的 GraphQL 模式代码。开发者可在其网页版使用可视化图表查看结构、通过 Advice Console 了解生成内容，并借助临时服务器在 Playground 中测试样例查询，最后导出代码用于集成。URI 在客户端与服务端加密处理。

  • 通过内省 PostgreSQL 数据库提取表与关系，生成含 resolver 和 mutation 的 GraphQL 模式，无需手写代码
  • 提供数据库可视化交互图表、Advice Console 说明面板，以及带样例查询/变更的临时 GraphQL 服务器供 Playground 测试
  • 数据库 URI 在客户端与服务端进行加密，支持导出自定义 schema 及集成说明

适用场景（解读层）

  • 将现有 PostgreSQL 数据库迁移或接入 GraphQL API 时生成初始 schema 与 resolver
  • 通过可视化图表查看数据库表结构与关系
  • 在正式集成前通过 Playground 测试样例查询与 mutation
