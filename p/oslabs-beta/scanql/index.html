ScanQL 是一款连接 PostgreSQL 的实时监控、查询分析与可视化开发工具

综述（解读层）

ScanQL 是一个面向 PostgreSQL 数据库的开发者工具，通过提交 URI 连接字符串接入数据库后，提供数据库组成概览、容量指标、ER 图可视化，并自动对每张表运行通用 SELECT 与 UPDATE 查询以测量计划与执行时间，也支持自定义查询的性能分析（耗时、缓存、扫描类型、命中行数）。采用 MIT 许可证，技术栈包含 React、Express、Chart.js、Docker 等。注意：部分指标依赖数据库权限，未付费版 Postgres 的历史性能数据不可用。

  • 支持通过 URI 连接字符串接入 Postgres 数据库，自动生成数据库概览、容量指标与 ER 图
  • 自动对每张表运行通用 SELECT/UPDATE 查询并测量计划与执行时间；支持自定义查询分析（耗时、缓存、扫描类型、命中行数）
  • README 声明不存储或缓存 URI 字符串，不存储、共享或传输数据库数据

适用场景（解读层）

  • 需要以 ER 图形式查看 Postgres 数据库表结构与表间关系的开发者
  • 在不手写 SQL 的情况下获取 SELECT/UPDATE 查询的计划与执行时间基线
  • 分析自定义查询的执行指标以定位性能问题
