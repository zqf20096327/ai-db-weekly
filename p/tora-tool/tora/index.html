面向 Oracle/MySQL/PostgreSQL 的开源 SQL IDE，含调试与调优工具

综述（解读层）

TOra（Toolkit for Oracle）是一个面向数据库开发人员和管理员的开源 SQL IDE，采用 GPL v2 许可，基于 Qt 构建。它支持多连接，提供 SQL 工作表、模式浏览器、PL/SQL 调试器和服务器调优等模块。Oracle 支持需 8.1.7 或更新客户端（已在 10g/11g 上验证）；MySQL 与 PostgreSQL 支持取决于 Qt 库是否编译相应后端。Windows 版自带 stub oci.dll，安装 Oracle 客户端后需删除该文件以启用 Oracle 支持。

  • SQL 工作表提供执行计划（Explain plan）、语法高亮、代码补全、PL/SQL 自动缩进与语句统计
  • 内置 PL/SQL 编辑器/调试器，支持断点、监视、单步执行与结构树解析
  • 包含服务器调优工具：调优图表、等待状态分析、表空间 I/O、SGA 与长操作跟踪

适用场景（解读层）

  • Oracle 数据库管理员进行服务器调优、会话与存储管理
  • 开发者编写和调试 PL/SQL 代码、查看执行计划
  • 需要通过图形界面连接和管理 MySQL/PostgreSQL 数据库（Qt 编译含相应支持时）
