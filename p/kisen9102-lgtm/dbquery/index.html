基于 Django 4.2 的多数据库运维查询平台，支持在线 SQL 编辑与实例管理

综述（解读层）

dbquery 是一个自托管的数据库查询平台，用于统一查询已注册的 MySQL、TiDB、PostgreSQL、Redis、MongoDB 实例。平台提供跨实例数据库检索、在线 SQL 编辑器、集群拓扑查询、用户组权限管理，并附 CLI 工具管理实例。部署需自行提供外部 MySQL 8.0 作为元数据库，支持 Docker Compose 或本地运行。适合需要为团队提供受控只读查询入口的 DBA 和运维团队。

  • 支持 MySQL 8.0、TiDB、PostgreSQL 14+、Redis 7+、MongoDB 6+ 五类实例的注册与查询
  • 内置三种角色（root/admin/query），query 角色仅限只读 SQL、按用户组限定可见实例并隐藏 IP/端口
  • 提供 Docker Compose 与本地两种部署方式，并附带可通过 API 管理实例的 CLI 工具 dbcli

适用场景（解读层）

  • 团队自托管统一的数据库查询入口，限制成员只读访问并按用户组控制可见实例
  • 跨多个 MySQL/TiDB/PostgreSQL 实例按名称或 IP+端口检索数据库信息
  • 通过 Redis 命令白名单和 MongoDB find/aggregate 查询 NoSQL 数据
