面向 MySQL、Postgres、SQLite 与 SQL Server 的 PHP 独立查询构建器库

综述（解读层）

Aura.SqlQuery 提供针对 MySQL、Postgres、SQLite 和 Microsoft SQL Server 的查询构建器，不依赖特定数据库连接库，仅一般性地建议配合 PDO 使用。它通过 Composer 以 aura/sqlquery 安装，遵循 PSR-1/4/12，要求 PHP 8.4 及以上。适合需要在 PHP 代码中程序化生成多方言 SQL 语句、且希望构建器与连接层解耦的开发者使用。

  • 提供 MySQL、Postgres、SQLite、Microsoft SQL Server 四种方言的查询构建器
  • 构建器独立于任何特定数据库连接库，PDO 仅为推荐而非强制
  • 遵循 PSR-1、PSR-4、PSR-12 规范，经 Composer 以 PSR-4 自动加载安装

适用场景（解读层）

  • 在 PHP 项目中按数据库方言生成 SELECT/INSERT 等 SQL 语句
  • 应用需要同时或分别支持多种数据库类型时的统一查询构建层
  • 不希望查询构建逻辑与具体数据库连接实现绑定的架构设计
📖 README 首段存档原文 · 程序抽取

Provides query builders for MySQL, Postgres, SQLite, and Microsoft SQL Server. These builders are independent of any particular database connection library, although PDO in general is recommended.
