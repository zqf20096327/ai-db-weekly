以模型目录驱动的 SQL 数据库原型构建工具

综述（解读层）

dbd 是一个 Python 编写的命令行数据库原型工具，面向数据分析师和工程师。它将 model 目录映射为数据库结构：子目录生成 schema，CSV/JSON/Excel/Parquet 文件生成数据表，.sql 文件经 insert-from-select 生成表或视图，.ref 文件可引用本地、URL、ZIP 内或 Kaggle 数据源。工具自动按依赖顺序处理文件。安装需 Python 3.8+，通过 pip 安装后执行 dbd run 命令。

  • 支持加载 CSV、JSON、Excel、Parquet 格式数据，来源可为本地文件、HTTP URL、ZIP 压缩包内文件及 Kaggle 数据集
  • 通过 model 目录约定生成 schema 与表：目录为 schema，数据文件为表，.yaml 文件可选定义列类型、约束和索引
  • 支持 Postgres、MySQL/MariaDB、SQLite、Snowflake、BigQuery、Redshift 数据库，数据可全量或增量加载

适用场景（解读层）

  • 将多来源数据文件（本地/在线/ZIP/Kaggle）快速加载到 SQL 数据库形成表结构
  • 用 .sql 文件编写 SELECT 语句在库内做数据变换，生成表或视图
  • 执行 prolog.ddl/epilog.ddl 等 DDL 脚本完成建 schema 等 SQL 操作
