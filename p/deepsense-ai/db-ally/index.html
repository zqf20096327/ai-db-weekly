基于 LLM 的自然语言查询数据源库，用受限 IQL 替代生成任意 SQL

综述（解读层）

db-ally 是 deepsense.ai 开源、MIT 许可的 Python 库，用于为数据源构建自然语言查询接口。开发者通过定义 view、filter 和 aggregation 划定 LLM 可处理的用例，模型以受限的中间查询语言 IQL 输出，不直接访问数据库或执行任意 SQL；视图注册于 collection 作为自然语言问答入口。通过 pip 安装，可选 litellm、faiss、langsmith 扩展。

  • 开发者通过 views、filters、aggregations 定义用例，LLM 以 IQL 中间查询语言生成响应
  • 阻止直接数据库访问与任意 SQL 执行，输出格式与操作限于开发者预定义范围
  • 提供抽象层隔离底层数据源，支持通过 LiteLLM 扩展使用 100+ LLM，支持 Faiss 相似性检索与 LangSmith 查询追踪

适用场景（解读层）

  • 对输出格式和行为有精确要求的数据查询应用
  • 需要限制模型对数据库访问方式、避免任意 SQL 执行的场景
  • 需对接多种数据库技术并复用同一自然语言查询层的项目
