🧭 简介解读层（AI·证据行可回查）

基于 TiDB 单表单 SQL 的五种 Agent 记忆架构基准测试。

综述（解读层）

该项目在单个 TiDB 集群的一张 memories 表上实现并对比五种记忆写入策略，从原始向量基线到带确定性 supersede 的 SPO 三元组，全部共享同一混合检索 SQL（融合向量、全文、JSON 与结构化条件排序）。面向研究 Agent 记忆方案的开发者，运行依赖 bun 与 LLM 抽取步骤；README 同时记录了各架构在特定评测切片上的得分差异。

  • 五种写入策略共享同一 schema 与检索语句，通过 WHERE approach = ? 切换架构
  • 单条 SQL 在 ORDER BY 中联合向量相似度、全文、JSON_CONTAINS 与时间衰减评分
  • supersede 通过同事务内 UPDATE 与 WHERE superseded_at IS NULL 谓词实现，runs 表支持用 bun run summary 以标准 SQL 做统计分析

适用场景（解读层）

  • 在统一存储与检索路径下对比不同 Agent 记忆架构的基准评测
  • 研究写时摘要、原子事实抽取与 SPO 三元组 supersede 策略的实现细节
  • 评估 TiDB 上向量与结构化条件混合检索的查询组织方式
