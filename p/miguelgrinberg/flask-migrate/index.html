基于 Alembic 的 Flask 数据库迁移扩展

综述（解读层）

Flask-Migrate 是 Flask 扩展，借助 Alembic 处理 SQLAlchemy 数据库迁移，操作以 `flask db` 子命令形式提供。使用时需通过 pip 安装，运行 `flask db init/migrate/upgrade` 等命令生成并应用迁移脚本，migrations 目录需纳入版本控制。注意 Alembic 无法检测全部变更（如索引），迁移脚本需人工审查编辑。

  • 通过 flask db 命令行提供数据库迁移操作，包括 init、migrate、upgrade 等子命令
  • 基于 Alembic 为 Flask 应用生成和管理 SQLAlchemy 迁移脚本
  • 支持通过版本控制中的 migrations 文件夹在其他系统同步数据库

适用场景（解读层）

  • Flask + SQLAlchemy 应用的数据库结构变更管理
  • 团队协作中通过版本控制共享并同步数据库迁移
  • 多环境部署时对数据库执行 upgrade 同步结构
