🧭 简介解读层（AI·证据行可回查）

用 JV-Link 将 JRA-VAN 赛马数据导入 SQLite/PostgreSQL 的 Python 命令行工具。

综述（解读层）

该工具通过 JV-Link 组件获取 JRA-VAN DataLab 的中央竞马（JRA）数据，并存入 SQLite 或 PostgreSQL，分为蓄积系（出马表、成绩、返还金等）和快报系（当日快报、截止前赔率）两类，命令名为 jltsql。使用前需自行签订 JRA-VAN DataLab 合同并安装 JV-Link，运行环境仅限 Windows 或 x86_64 Linux + Docker（Wine）。数据库架构（schema）升级不自动迁移，须按照版本停止采集器并备份数据后手动执行。

  • 支持存入 SQLite 或 PostgreSQL，可通过环境变量读取 PostgreSQL 连接配置
  • 覆盖蓄积系（JVOpen：出马表、成绩、返还金、主数据）和快报系（JVRTOpen：当日快报、赔率）数据源
  • 提供用于 Linux (Docker + Wine) 的镜像，内置 noVNC 屏幕及无人值守处理对话框的选项

适用场景（解读层）

  • 以 SQLite 为起点在 Windows 上进行初步尝试，随后迁移到 PostgreSQL 的日常数据同步
  • 在 x86_64 Linux 主机上通过 Docker + Wine 运行采集器
  • 需要固定版本进行部署、留存部署记录（full SHA、SHA-256）并进行手动架构迁移的运维场景
📖 README 首段存档原文 · 程序抽取
