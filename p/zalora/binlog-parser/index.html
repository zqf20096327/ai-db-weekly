读取 MySQL binlog 文件并输出 JSON 消息的 Go 解析工具

综述（解读层）

binlog-parser 是一个 Go 编写的命令行工具，读取 MySQL binlog 文件，连接运行中的 MySQL 查询 information_schema 以获取字段名，将行事件（Insert/Update/Delete）以 JSON 写入 stdout。要求 row-based binlog 格式，面向 MySQL 5.6 设计，不使用 GTID 时也可用于 MariaDB。由于不维护内部 schema 表示，解析旧 binlog 时若表结构已变更，字段可能映射为 unknown 或错位。

  • 读取 binlog 文件并将行事件输出为包含 Header、Type、Data 的 JSON 消息
  • 通过 DB_DSN 环境变量连接 MySQL，查询 information_schema 获取字段名并映射到数据
  • 支持按 schema 和表过滤，提供 -prettyprint 等输出选项；无法匹配列数时字段名映射为 unknown_N 并附 MappingNotice

适用场景（解读层）

  • 从 binlog 文件生成可存储和分析的数据库事件流
  • 生成基于 binlog 的审计日志数据
  • 离线解析已存在的 binlog 文件以检查行级变更
