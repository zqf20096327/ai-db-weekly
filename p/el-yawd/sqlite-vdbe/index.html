综述（解读层）

sqlite-vdbe 是一个 Rust crate，提供对 SQLite VDBE（虚拟数据库引擎）字节码的底层访问，允许直接创建并执行 VDBE 程序而无需经过 SQL 解析。构建时自动编译捆绑的 SQLite 3.51.2，需 C 编译器。该 crate 以 SQLITE_THREADSAFE=0 编译，所有类型均为 !Send 和 !Sync，需每线程使用一个连接。

  • 通过 Insn 枚举以类型安全方式构建 VDBE 程序
  • 提供 jump_here() 用于前向跳转地址的回填
  • 默认 bundled feature 自动编译捆绑的 SQLite 3.51.2 amalgamation

适用场景（解读层）

  • 在 SQLite 存储之上构建自定义查询引擎
  • 测试 VDBE 行为或学习 SQLite 内部机制
  • 实现特定的数据库操作
