基于 GPUI 的 SQLite 数据库文件物理页面布局查看工具

综述（解读层）

这是一个用 Rust 和 GPUI 构建的原生桌面应用，用于查看 SQLite 数据库文件的物理页面结构，可视化数据库页面头和 B-tree 页面头，支持页面检查，并在打开的文件变化时刷新。目前不支持 WAL 解读、记录浏览和数据库编辑。适合需要检查 SQLite 文件底层页结构的开发者。通过 script/bootstrap 引导、cargo run 运行。

  • 可视化数据库页面头和 B-tree 页面头
  • 支持页面检查，文件变更时自动刷新
  • 基于 Rust 和 GPUI 构建的原生应用

适用场景（解读层）

  • 查看 SQLite 数据库文件的物理页面布局
  • 检查数据库与 B-tree 页面头内容
  • 监控打开中的数据库文件的变化
