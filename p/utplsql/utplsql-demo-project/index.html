utPLSQL v3 单元测试演示项目，集成 Travis CI/Azure DevOps 与 SonarCloud

综述（解读层）

该项目为 Oracle PL/SQL 代码提供基于 utPLSQL v3 的单元测试与持续集成示例。每次提交触发 Travis CI 构建，或经 Azure DevOps 流水线分阶段执行：安装 Oracle 11g XE 数据库与 utPLSQL 框架、通过 SQLCL Liquibase/Redgate Flyway 部署代码、运行测试并将覆盖率与测试结果发布至 SonarCloud，最终生成不可变制品供部署阶段使用。适合希望搭建 PL/SQL CI 流程的开发者参考。

  • 提供基于 Travis CI 的构建流程，包含下载安装 Oracle Database 11g XE、utPLSQL 框架并执行全部测试的完整步骤
  • 提供 Azure DevOps 流水线示例，分 Build 与 Deploy 两个阶段，支持 SQLCL Liquibase 与 Redgate Flyway 部署
  • 将测试结果与代码覆盖率发布至 SonarCloud，构建阶段产出不可变制品传递给下游部署作业

适用场景（解读层）

  • 为 Oracle PL/SQL 项目搭建自动化单元测试与 CI 流程时参考配置
  • 通过 Liquibase 或 Flyway 结合测试验证数据库变更的语法与完整性
  • 将已测试的数据库代码制品部署到 DEV、UAT 等多套环境
