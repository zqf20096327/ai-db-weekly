🧭 简介解读层（AI·证据行可回查）

将 pg_dumpall 经 restic 加密去重备份到 S3/B2 的 Docker 容器

综述（解读层）

pg-restic 是一个 Docker 镜像，按 cron 计划运行 pg_dumpall，将数据流直接写入 restic 仓库（不落本地磁盘），支持 S3、Backblaze B2 及 S3 兼容存储或 restic REST 服务端，并按保留策略自动清理旧快照。适用于自托管 Postgres 实例的运维者；要求 Postgres 14+ 的 pg_read_all_data 用户或超级用户，镜像内置 pg_dumpall 18，可备份 9.2 至 18 版本的服务器，无法备份更新版本。

  • 备份流式写入 restic 仓库，不写入本地磁盘；dump 失败时不保存快照
  • 首次运行自动初始化 restic 仓库，通过环境变量配置 cron 计划、保留策略（小时/天/月）与每日 prune 时间
  • 支持 PING_URL/PRUNE_PING_URL 心跳监测，并透传任意 restic 环境变量；镜像基于 Alpine，仅含 postgresql-client 与 restic

适用场景（解读层）

  • 定时将自托管 Postgres 全库（含角色）加密备份到 S3、B2 或 S3 兼容存储
  • 配合 healthchecks.io 或 Uptime Kuma 等心跳监控，在备份或 prune 停止时收到提醒
  • 通过 restic snapshots/restore 命令在任意装有 restic 的机器上恢复快照
