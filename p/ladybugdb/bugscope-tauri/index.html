🧭 简介解读层（AI·证据行可回查）

LadybugDB 图谱可视化桌面应用，基于 Tauri 2 与力导向图交互浏览数据库实体关系

综述（解读层）

Bugscope 是 LadybugDB 的交互式图可视化工具，以 Tauri 2 桌面应用形式运行（React/Vite 前端加 Rust 后端，链接 liblbug 预编译库），面向需要浏览数据库中 bug、文件等实体关系的用户。节点大小映射连接数、颜色区分实体类型；可选启用基于 icebug 的 Leiden 聚类分析，该特性需系统安装版本匹配的 Arrow C++ 与 OpenMP。默认不带分析特性即可运行。

  • 支持力导向图交互：拖拽节点、缩放、平移，悬停查看节点标签与边的关系类型
  • 节点大小反映连接数，颜色区分实体类型，支持深浅色主题切换
  • 可选 icebug-analytics 特性提供基于 NetworKit 的 Leiden 聚类及可选 LLM 集群命名（默认端点 openrouter.ai）

适用场景（解读层）

  • 浏览 LadybugDB 数据库中实体（bug、文件等）之间的关系结构
  • 启用 icebug-analytics 后对图数据进行 Leiden 聚类分析
  • 通过 LLM 访问令牌为可见集群生成命名标签
