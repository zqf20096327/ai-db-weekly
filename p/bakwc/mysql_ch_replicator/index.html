🧭 简介解读层（AI·证据行可回查）

将 MySQL 数据库实时复制到 ClickHouse 的工具，基于 binlog 批量同步。

综述（解读层）

mysql_ch_replicator 用于把 MySQL 数据复制到 ClickHouse，通过读取 MySQL 二进制日志（GTID/ROW 格式）实现持续同步，支持 JSON、布尔等类型映射与部分表结构变更。面向需要在 ClickHouse 中分析 MySQL 数据的场景。要求 MySQL 开启 binlog 并授权复制权限，ClickHouse 需启用 final 设置，支持 Linux/macOS，可经 pip 或 Docker 安装。

  • 通过 binlog 实现持续复制，README 称实时延迟约 ±5 秒，单核约每秒 2 万事件
  • 支持库/表级过滤、目标库表重命名、自定义类型映射与 PARTITION BY/ORDER BY 配置
  • 提供一次性初始拷贝（可中断续传）、跳过初始复制的追加模式、忽略删除及 HTTP 控制端点等配置项

适用场景（解读层）

  • 需要将 MySQL 数据持续同步到 ClickHouse 进行查询分析的场景
  • 仅需一次性将 MySQL 库/表批量拷贝到 ClickHouse 的场景
  • AWS RDS 等托管 MySQL（按文档设置 binlog ROW 格式参数）向 ClickHouse 复制的场景
