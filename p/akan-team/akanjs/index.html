基于 Bun 的 TypeScript 全栈框架，内置 AI 代理与 MCP 支持

综述（解读层）

Akan.js 是一个运行于 Bun 的 TypeScript 全栈框架，以单行业务声明贯穿 schema、API、客户端状态与 UI 等八层代码，并可编译为 Web、iOS、Android 及桌面应用。其特色是将带权限守卫的端点自动发布为 MCP 工具、屏幕控件发布为页面内代理工具。适用于 TypeScript 开发者构建需要同时服务人类用户和 AI 代理的全栈应用。

  • 一次字段声明贯穿 schema、查询、服务、API、客户端类型、状态和 UI 八层，支持六平台输出
  • 带守卫的端点默认通过 POST /mcp 暴露为 MCP 工具，复用同一权限模型并支持 OAuth 2.1、限流与密钥剥离
  • 工作区自动生成 AGENTS.md、Cursor 规则并注册 MCP 服务器，代码按业务域模块组织

适用场景（解读层）

  • 构建需要同时面向人类用户和 AI 代理访问的全栈 Web/移动/桌面应用
  • 为已有业务端点提供 MCP 接入而不单独编写工具 schema 或权限模型
  • 在 monorepo 中以业务域为单位组织代码并使用 AI 编码代理协作开发
