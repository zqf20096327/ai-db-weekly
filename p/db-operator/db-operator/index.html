通过 Kubernetes 自定义资源管理集群内外 MySQL/PostgreSQL 数据库的 Operator

综述（解读层）

DB Operator 是一个 Kubernetes Operator，用于管理数据库：用户创建 Database 和 DbUser 自定义资源，即可在运行于集群内或集群外的数据库服务器上创建或删除数据库与用户，并使用 GO 模板生成自定义连接字符串。它统一管理 MySQL 和 PostgreSQL，通过 Helm 安装，适合在 Kubernetes 环境中以声明式方式维护数据库资源与凭证分发的团队。

  • 通过 Database 自定义资源在集群内外的数据库服务器上创建/删除数据库
  • 通过 DbUser 自定义资源创建/删除数据库用户
  • 以相同方式管理 MySQL 和 PostgreSQL 数据库

适用场景（解读层）

  • 数据库服务器运行在 Kubernetes 集群之外时以 Kubernetes 原生方式管理数据库
  • 需要为应用自动创建数据库及用户并生成连接字符串
  • 统一管理多个 MySQL 与 PostgreSQL 实例上的数据库生命周期
