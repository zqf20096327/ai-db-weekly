基于 ClickHouse 或 Cassandra 的多租户 Prometheus 长期存储层

综述（解读层）

SquirrelDB 是一个无状态服务，实现 Prometheus 的 remote write（v1/v2）、remote read 与 PromQL HTTP API，将指标写入 ClickHouse 或 Cassandra（ScyllaDB 已测试）。由 Bleemeo 在其监控平台生产环境中使用。数据先缓存在内存或 Redis，再批量写入长期存储；通过 X-SquirrelDB-Tenant 请求头隔离租户。启动前需存储后端已在运行。

  • 提供 remote write（v1/v2）、remote read 及 query、query_range、series、labels 等 Prometheus HTTP API 端点
  • 支持 ClickHouse、Cassandra 两种后端，含内置的 Cassandra 到 ClickHouse 在线迁移（extra_write_backend）及 sandbox/dummy 后端
  • 支持基于 X-SquirrelDB-Tenant 头的多租户隔离、按请求 TTL、TLS/mTLS、basic auth 和带 read/write/admin scope 的 bearer token

适用场景（解读层）

  • 为 Prometheus、Grafana Alloy 等远程写入代理提供月到年级的指标长期存储
  • 作为 Grafana 的 Prometheus 数据源，供查询、告警工具和 API 客户端使用
  • 多租户监控平台中隔离各租户读写并按租户设置保留期与查询限制
