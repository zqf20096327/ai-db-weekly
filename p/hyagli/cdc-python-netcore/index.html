基于 Debezium 与 Protobuf Outbox 模式的 MySQL 到 Elasticsearch CDC 示例项目

综述（解读层）

该项目是一个概念验证示例，演示如何用 Debezium 实现带 Protobuf 二进制载荷的 Outbox 模式：Django 应用将序列化事件写入 MySQL 的 outbox 表，Kafka Connect 中的 Debezium MySQL 连接器监听 binlog 并推送到 Kafka 主题，.NET Core 后台服务消费并写入 Elasticsearch。通过 ByteBufferConverter 关闭 schema 输出，使下游只依赖 proto 定义。全部组件以 docker-compose 编排，仅需安装 Docker 即可运行。

  • 使用 Debezium Outbox Event Router 与 ByteBufferConverter，以二进制 Protobuf 载荷写入 Kafka，下游消费无需依赖 Debezium JSON 结构
  • 提供完整的 docker-compose 编排，包含 Django/MySQL、Kafka/Kafka Connect/Kafdrop、.NET Core 应用、PostgreSQL、Elasticsearch 与 Kibana
  • 附带自实现的 Confluent Kafka 消费端 Protobuf 反序列化器，直接使用 Google 生成的 C# 类解析载荷

适用场景（解读层）

  • 学习 Debezium CDC 与 Outbox 模式的端到端实现方式
  • 搭建 Python/Django 数据源到 .NET Core/Elasticsearch 数据管道的参考示例
  • 演示跨语言（Python/C#）共享 proto 文件进行序列化与反序列化的流程
