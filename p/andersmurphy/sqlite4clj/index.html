基于 Java 22 FFI 直接绑定 SQLite C API 的 Clojure 库

综述（解读层）

sqlite4clj 是一个 Clojure 库，通过 babashka/ffi 与 Java 22 FFI 直接调用 SQLite C API，不依赖 sqlite-jdbc/HikariCP/next.jdbc。它维护 :reader 连接池加单一 :writer 连接，缓存预编译语句，支持读写事务、自定义结果集函数、EDN 自动编解码与表达式索引。项目自述为高度实验性的概念验证，未发布到 Maven，需 Java 22 并启用原生访问选项。

  • 通过 Java 22 FFI 直接绑定 SQLite C API，类路径内置 macos/linux（aarch64/x86_64）预编译 libsqlite3
  • 应用层维护 :reader 连接池与单一 :writer 连接，缓存预编译语句，提供 d/with-write-tx、d/with-read-tx 事务接口
  • 自动将 EDN 数据编码为 blob 存储，支持通过 SQLite 表达式索引和部分索引对编码数据建索引，并提供内存用量查询 API

适用场景（解读层）

  • 在 Clojure 项目中以非 JDBC 方式读写 SQLite 数据库
  • 将 SQLite 用作 EDN 文档存储并利用表达式索引查询 blob 内数据
  • 多租户/每用户一库等需要运行大量 SQLite 数据库实例的场景（连接池基于 LinkedBlockingQueue 实现）
📖 README 首段存档原文 · 程序抽取

Conceptually sqlite4clj is inspired by sqlite4java a sqlite library that doesn't use the JDBC interface. The goal of sqlite4clj is to have a minimalist FFI binding to SQLite's C API using Java 22 FFI
