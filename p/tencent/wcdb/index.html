微信开发的跨平台移动数据库框架，基于 SQLite 与 SQLCipher。

综述（解读层）

WCDB 是微信团队开发的移动端数据库框架，基于 SQLite 和 SQLCipher 构建，提供 C++、Java、Kotlin、Swift、Objective-C 五种语言接口。它通过 ORM 映射和 WINQ 查询语言支持对象级 CRUD 操作，并内置数据库加密、损坏修复、SQL 注入防护、全文检索、数据迁移与压缩等功能，适用于移动应用的数据存储开发。

  • 支持 C++、Java、Kotlin、Swift、Objective-C 五种语言接口，各语言接口共享同一底层逻辑
  • 基于 SQLCipher 提供数据库加密，并内置损坏修复工具和 SQL 注入防护
  • 通过连接池支持读-读与读-写并发访问，支持基于 Zstd 的字段级数据压缩与全文检索

适用场景（解读层）

  • 移动应用中需要对象化 CRUD 操作的本地数据存储
  • 需要对数据库进行加密保护的应用场景
  • 同一项目中多语言混合开发、共享数据库逻辑的场景
