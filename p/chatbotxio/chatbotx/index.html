🧭 简介解读层（AI·证据行可回查）

开源全渠道 AI 聊天营销平台，支持自托管与多平台消息自动化

综述（解读层）

ChatbotX 是一个基于 TypeScript 与 Next.js 构建的开源聊天营销平台（MIT 许可，企业功能为商业许可），用于在 WhatsApp、Instagram、TikTok、Telegram、Zalo、Email 等渠道进行消息自动化。它面向需要自托管部署的营销与客服团队，提供可视化流程编排、AI Agent 接入、实时人工接管和联系人管理。技术栈依赖 PostgreSQL（pgvector）、Redis/BullMQ 队列，可通过 Docker Compose 运行预构建镜像或以 pnpm 从源码启动。

  • 提供可视化拖拽流程编排器，包含 15+ 种节点类型，并支持接入 OpenAI、Claude、Gemini、DeepSeek 及本地 LLM
  • 支持 WhatsApp、Facebook、Instagram、Threads、TikTok、Telegram、Zalo、Email、API 与 Webchat 十类渠道的消息收发
  • 提供实时聊天收件箱、联系人 CRM、批量群发、定时序列、A/B 测试及公开 API、CLI 与 MCP 接口

适用场景（解读层）

  • 在多个社交平台自动回复评论、关键词触发私信及评论互动自动化
  • 搭建 drip 营销序列并对联系人分群进行定向群发与 A/B 测试
  • 结合人工接管收件箱与 AI Agent，管理多渠道客服会话与团队协作
