🧭 简介解读层（AI·证据行可回查）

离线优先的 SQL 审计引擎，提供 CLI 与 MCP 服务端。

综述（解读层）

DeltaScope 是用 Go 编写的 SQL 审计引擎，支持 MySQL、TiDB、PostgreSQL 的 DDL/DML 语句审查，可离线运行或连接数据库做元数据感知审计。通过 CLI 执行审计，提供 reject/pass/review 三类判定，支持 JSON、SARIF、GitHub Actions、GitLab Code Quality 等输出格式；也可作为 MCP server 供 AI 客户端调用。存在语句配额（每请求 1024 条 MySQL/TiDB 顶层语句）限制，超出部分标记 incomplete。

  • 支持 --dialect mysql|tidb|postgresql 三方言离线审计，可联网读取实例元数据
  • 提供 JSON、SARIF、github-actions、github-summary、gitlab-codequality 输出格式，含 --fail-on 阈值与 --target-version 版本事实输入
  • 发布单一归档含 deltascope、deltascope-server、deltascope-mcp 三个二进制，支持 Homebrew、npm 启动器安装

适用场景（解读层）

  • 在 CI 流水线中对迁移文件执行 SQL 审计并以注解/摘要形式回写运行结果
  • 将 MCP server 接入 AI 客户端，在执行 SQL 前调用审计
  • 离线环境对 MySQL/TiDB/PostgreSQL 的 DDL/DML 变更做规则化审查
