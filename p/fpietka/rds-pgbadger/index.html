下载 RDS 日志文件并用 pgBadger 进行分析的 Python 命令行工具

综述（解读层）

该工具通过 AWS 凭证连接 RDS 实例，下载实例日志文件并交由 pgBadger 生成分析报告。使用前需在参数组中开启 log_checkpoints、log_connections 等日志参数，并确保 pgbadger 已安装且在 PATH 中。支持指定日期、区域、输出目录，以及通过 STS assume-role 实现跨账号访问。README 提及大日志文件下载可能偶发失败，重试通常可解决。

  • 支持通过 pip 安装，仅传实例 ID 即可下载日志并生成 pgBadger 报告
  • 提供日期过滤、区域指定、输出目录、跳过处理、透传 pgBadger 参数等命令行选项
  • 支持 STS assume-role 进行跨账号访问

适用场景（解读层）

  • 为 AWS RDS 上的 PostgreSQL 实例生成 pgBadger 日志分析报告
  • 按指定日期下载 RDS 日志文件而不做处理
  • 需要跨账号访问其他 AWS 账号中 RDS 实例日志的场景
