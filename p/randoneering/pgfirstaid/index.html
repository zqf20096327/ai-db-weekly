单文件部署的 PostgreSQL 健康检查函数，按严重程度输出改进建议

综述（解读层）

pgFirstAid 是一个开源 SQL 函数（及视图），对 PostgreSQL 数据库运行一系列健康检查，输出按 CRITICAL 到 INFO 分级的问题清单，含修复步骤和官方文档链接。安装只需执行一个 SQL 文件，无外部依赖，适合 DBA 及非 DBA 用户。仅读取系统目录，无写操作；可选依赖 pg_stat_statements 做查询负载检查。支持 PostgreSQL 10+，兼容 RDS、Aurora、Azure、Cloud SQL 等托管环境，许可证为 GPLv3。

  • 单 SQL 文件部署，零外部依赖，只读操作，不改数据或 schema
  • 检查结果按 CRITICAL→HIGH→MEDIUM→LOW→INFO 分级，含修复建议与 PostgreSQL 官方文档链接
  • 非 INFO 结果附带 agent_prompt，可用于 AI 代理的只读诊断流程

适用场景（解读层）

  • 定期巡检生产库，按严重程度筛查并处理稳定性/性能问题
  • 部署前或 schema 变更、数据迁移后的健康验证
  • 集成到 CI/CD 流水线做数据库健康门禁与日常监控
