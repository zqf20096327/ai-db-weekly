🧭 简介解读层（AI·证据行可回查）

自托管 Supabase 生产运维手册，覆盖备份、PITR、升级与加固

综述（解读层）

该仓库是一份面向自托管 Supabase 生产环境的运维手册，内容包含备份与恢复演练、时点恢复、Kong 到 Envoy 及 Postgres 15 到 17 的升级流程、安全加固清单、磁盘/WAL 增长排查、监控与 Coolify 部署，并附带可读性检查脚本。作者在生产栈及其克隆上做过验证，但未覆盖 Storage、Edge Functions、多节点等场景，且需在克隆环境先行演练。

  • 提供只读检查脚本（preflight、verify、hardening-check 等六项）与每月恢复演练流程
  • 记录 Kong 2.8.1 替换为 Envoy 1.39、Postgres 15.14 原地升级到 17.6 的带回滚流程与测试矩阵
  • 包含 Coolify 专用行为说明、堆栈裁剪（移除 Storage/imgproxy/MinIO 等）及 WAL 增长与告警清单

适用场景（解读层）

  • 基于 Docker Compose 或 Coolify 自托管 Supabase 并需自行负责备份与恢复的团队
  • 需将多年未升级的旧版 Supabase 栈（Kong、Postgres 15）在维护窗口内升级的运维场景
  • 对自托管实例进行安全加固检查、WAL/磁盘增长监控的日常运维
