🧭 简介解读层（AI·证据行可回查）

用 Go 实现的轻量 REST 代理服务，用于替代遗留系统中的 ADODB 调用

综述（解读层）

SQL-PROXY 是一个用 Go 编写的 REST 服务，供支持 Web 请求的遗留软件（如 1C:Enterprise）通过 HTTP 调用替代 ADODB COM 组件访问数据库，支持 PostgreSQL、MSSQL、MySQL。它不存储数据库凭据、不做 SQL 校验，安全依赖 DBA 在数据库端配置权限；可独立运行或容器化部署。

  • 通过 HTTP 接口执行 SQL 命令，SELECT 结果以 JSON 格式返回，支持行数限制与预编译语句
  • 支持 PostgreSQL、Microsoft SQL Server、MySQL，无需安装驱动包或配置 ODBC 数据源
  • 提供共享 SQL 连接池、并发连接数限制、HTTPS 通信及 Prometheus 监控指标

适用场景（解读层）

  • 遗留软件（如 1C:Enterprise）在 Linux 等环境无法使用 ADODB COM 组件时改用 Web 请求访问数据库
  • 需要将数据库访问封装为独立服务或容器（如 k8s）部署的场景
  • 数据库与应用同机部署、服务绑定 localhost 使用的内网环境
