将 Garmin 等健康数据解析导入 SQLite 的 Python 脚本集

综述（解读层）

GarminDB 是一组 Python 脚本，用于从 Garmin Connect 下载每日监测、睡眠、体重、活动等数据并导入无服务器的 SQLite 数据库，也支持 FitBit CSV 与 MS Health CSV。脚本按日/周/月/年生成分组表，保留原始 JSON 与 FIT 文件以便离线重建数据库，可通过命令行或 Jupyter 笔记本查看数据。脚本主要在 MacOS 上开发。

  • 从 Garmin Connect 下载并导入每日心率、活动、压力、睡眠、体重等数据，并支持 FitBit CSV 与 MS Health CSV
  • 生成分日、周、月、年的汇总表，保留下载的 JSON/FIT 文件以支持离线重建数据库
  • 提供插件机制处理第三方 Connect IQ 应用数据，支持导出 TCX 文件与 Jupyter 笔记本分析

适用场景（解读层）

  • 将 Garmin 手表长期健康数据本地化存储于 SQLite 并用 SQL 或 Jupyter 分析
  • 通过命令行定时增量下载导入，配合 SQLite 图形工具浏览个人活动与睡眠记录
  • 基于课程视图比较同一赛道的多次活动数据
