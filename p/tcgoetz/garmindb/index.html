将 Garmin/FitBit/MS Health 健康数据解析入库 SQLite 的 Python 脚本集

综述（解读层）

GarminDB 是一组 Python 脚本，用于从 Garmin Connect 下载监测、睡眠、活动等数据，也支持 FitBit 与 MS Health 的 CSV 文件，解析后写入免服务器的 SQLite 数据库，生成日/周/月/年汇总表。适合拥有 Garmin 设备并想本地保存与分析健康数据的用户。脚本保留原始 JSON 和 FIT 文件，可离线重建数据库；需在配置文件中填写 Garmin Connect 账号密码。

  • 自动下载并导入 Garmin 每日监测数据（心率、活动、爬升、压力、强度分钟）、睡眠、体重与静息心率
  • 生成日、周、月、年汇总表，并可通过命令行或 Jupyter notebook 绘图
  • 保留下载的 JSON 与 FIT 文件，支持离线重建数据库；支持插件扩展处理第三方 Connect IQ 数据

适用场景（解读层）

  • 本地长期保存并增量更新 Garmin 健康与活动数据
  • 用 Jupyter notebook 或 SQLite 浏览工具（如 DB Browser for SQLite）分析健康数据趋势
  • 将活动记录导出为 TCX 文件，或按课程生成数据库视图比较活动
