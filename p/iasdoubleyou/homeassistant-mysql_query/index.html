🧭 简介解读层（AI·证据行可回查）

Home Assistant 自定义集成，通过 query/execute 两个动作读写 MySQL/MariaDB 数据库。

综述（解读层）

该组件为 Home Assistant 提供 MySQL/MariaDB 访问能力，注册 mysql_query.query 与 mysql_query.execute 两个动作，分别用于只读查询和写入/DDL 操作，结果可作为模板响应数据使用。支持 UI 配置多连接、参数化语句、行数上限与查询超时，需 Home Assistant 2026.9 以上及 aiomysql 驱动，YAML 配置不受支持。

  • 提供 query 与 execute 两个动作，按只读/写入分离语句，结果通过 response_variable 返回
  • 支持 %s 占位符参数化查询、多连接配置、行数上限（默认 1000）、查询超时（默认 30 秒）与可选 TLS
  • 使用连接池（1-5 连接），同一连接调用串行执行，不同连接并行，启动时不可达的连接自动重试

适用场景（解读层）

  • 自动化或模板中执行 SELECT 读取数据表内容并用于响应
  • 通过 INSERT/UPDATE/DELETE/DDL 语句在自动化中写入或维护数据库
  • 为仪表板或报表配置只读连接，禁止该连接上的写操作

A Home Assistant custom component that talks to a MySQL or MariaDB database through two actions: mysql_query.query reads with a SELECT and hands you the rows, and mysql_query.execute writes with an IN
