开源原生 macOS Postgres GUI，含审阅后执行的 Text-to-SQL

综述（解读层）

Widen 是运行于 macOS 14+ 的原生 PostgreSQL 图形客户端，支持浏览 schema、管理查询会话与执行 SQL。它集成 Particle-1 云模型，可将英文问题转成 SQL 草稿，执行前展示供用户审阅。无需后端与账号，密码存于 macOS Keychain。Text-to-SQL 处于 beta，需自备 Particle API key，且仅支持 Postgres。

  • 无后端、无账号、无分析上报，密码与 API key 存于 macOS Keychain
  • 所有语句经确定性安全校验器：禁 DDL、事务关键字、分号链与 pg_sleep/dblink，写入不自动执行
  • Text-to-SQL 发布受预注册 release gate 约束，gate 实验脚本与失败报告公开，可用 make eval-release 自行运行

适用场景（解读层）

  • 需要浏览 Postgres schema、保存查询会话并在本地执行手动 SQL
  • 希望以英文提问生成 SQL 草稿、执行前逐条审阅的工作流
  • 对数据外发敏感的连接可关闭 schema 元数据共享，仅用浏览与手动查询功能
