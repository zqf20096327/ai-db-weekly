基于 Promise API 操作 IndexedDB 与 localStorage 的浏览器端 ORM。

综述（解读层）

Beast-ORM 是一个面向前端浏览器的对象关系映射库，通过注册模型类生成数据库抽象 API，以 Promise 方式读写 IndexedDB 和 localStorage。其 QuerySet 机制提供 filter、get、update、delete 及字段查找（gt、contains 等），支持 ArrayField、JSONField 与多对多关系；indexedDB 实现将多个请求放入单事务执行，SQLite 支持计划在 2.0.0 版本发布。

  • 提供基于 Promise 的 API 访问 IndexedDB 与 localStorage，支持 create、get、filter、update、delete 等 CRUD 操作
  • IndexedDB 实现在单个事务中运行多个请求；filter 支持 gt/gte/lt/lte/not 及链式路径查找
  • 内置 ArrayField（支持 contains/overlap/len/索引变换）与 JSONField（支持键/索引/路径变换及 has_key 系列查找），可嵌套定义多对多关系

适用场景（解读层）

  • 需要在浏览器端以模型类方式结构化操作 IndexedDB 数据的前端应用
  • 离线优先应用中的本地数据持久化与查询场景
  • 需要按条件批量过滤、更新或删除本地存储记录的业务逻辑
