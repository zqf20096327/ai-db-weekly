面向 FiveM 脚本的数据库封装库，统一封装 mysql2/sequelize、MongoDB 与 Redis 访问。

综述（解读层）

ICMySQL 是面向 FiveM（CFX）平台的数据库连接资源，封装 mysql2 与 sequelize，并支持 MongoDB 和 Redis。通过 server.cfg 中的 mysqlCredentials 配置项写入连接信息，以 ensure icmysql 加载。提供缓存、备份、日志、ORM 与命名/未命名参数等能力，支持 Lua、JS、C#。已知问题包括重启后首次查询较慢及启动时线程 hitch 警告。

  • 支持 MySQL（mysql2/sequelize）、MongoDB、Redis 多种数据库及多连接配置
  • 提供高频查询缓存、备份系统、日志与 Discord 日志、ORM 支持及命名/未命名参数
  • 所有函数支持 await/async，支持 Lua、JS、C# 三种语言的库调用

适用场景（解读层）

  • FiveM 服务器脚本需要访问关系型数据库的场景
  • 需要在 CFX 资源中同时使用 MongoDB 或 Redis 的项目
  • 需要将现有 mysql 系统函数迁移到该封装的 FiveM 脚本
