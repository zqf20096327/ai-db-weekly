Windows 本地 PHP/Laravel 开发服务器，一键集成 Apache/Nginx、MySQL、Redis 与 WebSocket

综述（解读层）

SoftNix Server 是面向 Windows 10/11 的免费 WAMP 本地开发环境，供 PHP、Laravel 和 WordPress 开发者使用。它将 Apache 或 Nginx、MySQL/MariaDB、PHP 多版本以及 Redis、Laravel Reverb WebSocket、队列进程等组件整合在一个图形界面中，各组件按需从官方渠道下载并经 SHA-256 校验。安装程序未代码签名，SmartScreen 可能提示警告；默认服务仅监听 127.0.0.1，MySQL root 初始密码为 root。

  • 支持 Apache（mod_php）与 Nginx（FastCGI）切换，PHP 8.2–8.5 多版本一键切换，www 目录下文件夹自动映射为 https://folder.test 本地域名
  • Realtime 模式一键启动 Redis、Laravel Reverb WebSocket 服务与队列进程，并提供 WiFi 二维码共享和临时 trycloudflare.com 公网链接
  • 包含 Mailpit 本地邮件捕获、dump()/dd() 查看器、laravel.log 实时日志、数据库快照保存/恢复，以及通过 SSH 将变更文件部署到托管主机

适用场景（解读层）

  • 在 Windows 本地开发 Laravel、WordPress 或纯 PHP 项目，需要自动域名、HTTPS 与多 PHP 版本切换
  • 开发 WebSocket 实时应用（聊天、通知、仪表盘）并在同一 WiFi 下的手机上真机测试
  • 通过临时公网链接向客户演示本地项目，或测试 Stripe 等需要回调地址的 webhook
