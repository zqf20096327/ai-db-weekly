通过 FFI 与 Z-Engine 在 PHP PDO 之上暴露 SQLite 原生 C API 的库

综述（解读层）

该库面向需要在 PHP 中调用 PDO 未提供接口的 SQLite API 的开发者。它基于 PDO 连接，借助 Z-Engine 和 PHP FFI 将 PHP 变量解析为 SQLite C API 的连接指针，再通过 FFI 调用原生方法，目前提供加载扩展与获取数据库文件路径两类接口。要求 PHP 7.4+、启用 FFI 扩展，且仅支持 x64 非 ZTS 构建；因依赖尚未发布 1.0.0 的 Z-Engine，README 提示生产使用需自担风险。

  • 通过 wrapPDO() 包装现有 PDO 连接，暴露 loadExtension() 加载 SQLite 扩展库
  • 提供 getDatabaseFilename() 获取所连数据库的完整磁盘路径（内存数据库返回空字符串）
  • 实现机制为 Z-Engine 解析 PDO 变量得到原生连接指针，再经 PHP FFI 调用 SQLite C API

适用场景（解读层）

  • 在 PHP PDO 连接上加载 mod_spatialite 等 SQLite 扩展库
  • 需要读取 SQLite 数据库文件的完整磁盘路径
  • PHP 项目需要调用 PDO 未封装的 SQLite C 接口
