将类型化属性序列化存入 JSON 列的 ActiveRecord 扩展 gem

综述（解读层）

AttrJson 是一个 Ruby gem，通过 attr_json 声明方式在 ActiveRecord 模型上定义序列化到 jsonb/json 列（默认 json_attributes）的类型化属性，属性支持类型转换、校验、脏跟踪与嵌套模型。面向 Rails 6.0–7.0、Ruby 2.7+ 用户。为 postgres 开发，MySQL json 列多数功能可用但未测试；直接使用 attribute API 修改数据时两份数据可能失同步，需手动调用同步方法。

  • 支持类型转换、ActiveRecord 校验方法、脏跟踪，可与普通列属性共存于同一模型
  • AttrJson::Model 支持任意深度嵌套模型、多态模型类型及单模型序列化整个 JSON 列
  • 提供基于 postgres jsonb @> 操作符的 jsonb_contains 查询，支持点号键路径查询嵌套结构

适用场景（解读层）

  • 需要在 ActiveRecord 模型中以类型化属性方式使用 jsonb 列存储结构化数据
  • 需要将复杂嵌套对象图序列化到单个 jsonb 列并可查询的场景
  • 需要在 Rails 表单中编辑嵌套 JSON 属性的场景
