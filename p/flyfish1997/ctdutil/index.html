🧭 简介解读层（AI·证据行可回查）

单文件零依赖表结构登记工具，按向导登记并生成 DDL 与 Excel。

综述（解读层）

ctdutil 是一个交付为单个 index.html 的表结构登记工具，支持 Oracle、GaussDB、MySQL、H2（文件模式）四种目标库，按六步向导录入字段、主键、索引后生成建表 DDL 与 Excel 2003 格式结构总览。同一引擎（src/core.js）同时供页面、node 命令行（JSON 载荷进出，退出码区分校验与 I/O 结果）和浏览器内 window.Core/window.ctdutil 接口调用。运行需 Node.js >= 18，项目无 npm 依赖、可离线使用。README 自述存在未验证边界：真实 MySQL 引擎执行与真实浏览器交互均未自动化验证，界面数据仅存内存、刷新即失。

  • 支持 Oracle / GaussDB / MySQL / H2（文件模式）四种目标库，类型映射与注释语法随库切换
  • 同一引擎提供三个操作面：纯前端页面、命令行（JSON in / JSON out）、浏览器内 window.Core 与 window.ctdutil 接口
  • 零依赖、离线可用：index.html 双击即用，jQuery 3.7.1 本地引入，测试基于 Node 内置能力

适用场景（解读层）

  • 在没有数据库客户端的离线或受限环境中，通过浏览器向导登记表结构并产出建表 DDL
  • 用命令行 JSON 载荷在流水线或脚本中批量生成表结构 DDL 并按退出码判定结果
  • 需要表结构登记结果同时留存 DDL 与 Excel 结构文档的场景

单文件、零依赖的表结构登记工具：人类界面为纯前端页面（双击即用）， 按六步向导登记数据库表结构，自动生成建表 DDL 与结构总览 Excel。 支持 Oracle / GaussDB / MySQL / H2（文件模式），支持普通索引与唯一索引。 同一个引擎同时提供人类界面、命令行（JSON in / JSON out）与浏览器内自动化接口三个操作面。
