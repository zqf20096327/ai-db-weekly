🧭 简介解读层（AI·证据行可回查）

面向 Rails ActiveRecord 的 PostGIS 空间数据库连接适配器，基于 postgresql 适配器扩展并用 RGeo 表示空间数据。

综述（解读层）

该项目是 ActiveRecord 的连接适配器，扩展标准 postgresql 适配器以支持 PostGIS 空间类型与功能，用 RGeo 库在 Ruby 中表示空间数据。它提供空间迁移语法、空间列到 RGeo 对象的自动类型转换，以及查询中嵌入 WKT/RGeo 数据的能力。使用者需自备 PostgreSQL 9.0+ 与 PostGIS 2.4+，并在 database.yml 中将 adapter 设为 postgis。各版本对 ActiveRecord、Ruby、PostGIS 有对应版本要求。

  • 扩展 ActiveRecord 迁移语法，支持创建空间类型列（geometry、st_point、line_string、st_polygon 及各类集合类型）和空间索引（using: :gist）
  • 自动将数据库中的空间数据转换为 RGeo 对象，支持按 SRID、维度配置，支持 geographic/geographic 属性（经纬度球面计算）及 Z/M 坐标
  • 支持在 where 子句中嵌入 WKT 格式数据和 RGeo 对象进行简单空间查询

适用场景（解读层）

  • Rails 应用需要在 PostgreSQL/PostGIS 数据库中存储点、线、面等空间数据
  • 需要在 ActiveRecord 模型中以 RGeo 对象方式读写和查询空间字段
  • 需要通过迁移创建带 SRID、维度、geographic 约束的空间列与 GiST 空间索引
