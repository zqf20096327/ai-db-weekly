🧭 简介解读层（AI·证据行可回查）

基于 Tauri、Rust 与 React 的开源数据库图形界面客户端，支持 PostgreSQL、MySQL、SQLite 和 Redis。

综述（解读层）

Gridline 是一款桌面数据库 GUI 客户端，采用 Tauri 2.0、Rust、React 与 TypeScript 构建，基线体积约 40 MB。它面向管理多套数据库环境的开发者、平台与 DBA 人员，提供连接管理、数据浏览与编辑、备份恢复、跨库同步和 ER 图查看等功能，随版本更新持续修复连接字符串、SSH 隧道等问题。

  • 提供数据网格、外键预览、对象浏览器和以鸦脚标记表示基数的交互式 ER 图
  • 支持 PostgreSQL 的 pg_dump/pg_restore 及数据库间直接同步，MySQL 使用 mysqldump 或内置 MariaDB 客户端，SQLite 使用 .dump
  • 提供 INSERT/UPDATE/DELETE 变更暂存、生成 SQL 审查后统一提交的编辑流程，以及按连接取消长查询的按钮

适用场景（解读层）

  • 开发者在本机、测试与生产等 PostgreSQL、MySQL 或 SQLite 环境之间切换浏览和编辑数据
  • DBA 在原生界面中执行 pg_dump 备份、pg_restore 恢复及数据库间同步
  • 团队在 macOS、Windows 或 Linux 上通过安装包或 Homebrew 安装桌面客户端连接云托管数据库（如通过 sslmode 参数配置 Neon、Supabase 等）
