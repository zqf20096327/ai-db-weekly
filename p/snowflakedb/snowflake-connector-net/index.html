Snowflake 官方 .NET 数据连接器，基于 ADO.NET 机制访问 Snowflake 数据库

综述（解读层）

该连接器由 Snowflake 官方维护，供 .NET 应用程序连接并查询 Snowflake 数据库。包 ID 为 Snowflake.Data，通过 NuGet 安装，目标 netstandard2.0 并提供多平台定制构建。支持同步/异步查询、连接池、PUT/GET 阶段文件传输及 VECTOR 类型读取。限制包括：仅支持 glibc 发行版，不支持 GCP 区域端点。

  • 支持 .NET Framework 4.6.2–4.8.1 及 .NET 6.0–10.0，NuGet 按目标框架和操作系统自动选择对应构建
  • 提供连接池（v4.0.0+）、SSO/MFA/OAuth 令牌缓存、ILogger 日志集成及 CRL 证书吊销检查
  • 支持同步/异步查询、多语句执行、结构化类型与 VECTOR 列读取，以及 PUT/GET 阶段文件上传下载

适用场景（解读层）

  • 在 Windows/Linux/macOS 上的 .NET 应用中执行 Snowflake SQL 查询并读取结果数据
  • 通过 PUT/GET 命令在应用程序与 Snowflake 内部阶段之间上传和下载文件
  • 需要连接池、令牌缓存或 ILogger 日志集成的企业 .NET 数据访问场景
