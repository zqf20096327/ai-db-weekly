基于 Docker 容器的本地分布式系统模拟实验环境

综述（解读层）

DistSim 在本机通过 Docker 提供分布式系统实验环境，每台“机器”是带浏览器终端的 Ubuntu 容器，可安装 22 种服务、用可视化拓扑编辑器连线组网，并注入延迟、丢包、进程终止等故障。面向想动手实践负载均衡、数据库复制、消息队列的学习者。依赖 Docker 20+、Go 1.22+、Node.js 20+，MIT 许可。

  • 支持 22 种服务（Nginx、PostgreSQL、Redis、Kafka、Prometheus 等）的安装、配置、启停与连接
  • 提供可视化拓扑编辑器、浏览器终端、Monaco 代码编辑器及内置 API 压测工具
  • 支持注入网络延迟、丢包、分区、进程终止、CPU/内存压力和磁盘填满等故障

适用场景（解读层）

  • 在本地练习配置负载均衡、数据库主从复制、Redis 缓存与 Kafka 生产消费
  • 通过注入故障观察服务降级，学习熔断器、副本提升等容错机制
  • 搭建 Prometheus/Grafana 监控并查看请求速率、错误率与 p99 延迟面板
