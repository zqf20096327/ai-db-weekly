Laravel 包，在 schema:dump 生成的 SQL 中包含指定表的数据

综述（解读层）

该包扩展 Laravel 的 `php artisan schema:dump` 命令，在迁移合并生成的 SQL 转储文件中写入配置指定表的内容数据，便于配合 `schema:dump --prune` 清理迁移文件。适用于 Laravel 10–13、PHP 8.2+，支持 SQLite、MySQL、PostgreSQL。配置需手动在 `config/database.php` 中添加表名数组，还支持为含文件路径的表（如 migrations）指定文件删除目录。

  • 运行 `php artisan schema:dump` 时将配置指定表的数据写入生成的 SQL 转储文件
  • 支持 SQLite 3、MySQL 5.7/8/9、PostgreSQL 12–18
  • 可为表指定含文件名的列与文件夹路径，在 `--prune` 时删除对应文件（Laravel 11.36 起）

适用场景（解读层）

  • 执行 `schema:dump --prune` 压缩迁移时保留权限、字典等基础数据表
  • 导出含 migrations 表记录的转储并同步清理相关目录文件
  • 需要 schema 与指定表数据合并为单一 SQL 文件的 Laravel 项目
