Django 的 Valkey 缓存与会话后端，fork 自 django-redis

综述（解读层）

django-valkey 是面向 Django 的 Valkey 缓存和会话后端，BSD 许可，fork 自 django-redis 项目。它使用 valkey-py 原生 URL 连接串，提供可插拔的客户端、解析器和序列化器，支持异步、主/从配置和 Unix 套接字。要求 Python 3.11+、Django 5.2+、valkey-py 6.0.2+、Valkey 服务端 7.2.6+；集群支持仍待完善。

  • 作为 Django 的缓存和会话后端运行，采用 valkey-py 原生 URL 连接字符串
  • 客户端、解析器、序列化器均可插拔，默认客户端支持主/从配置和异步
  • 通过 pip extras 提供 libvalkey C 绑定及 lz4/zstd/brotli 压缩、msgpack/msgspec 序列化选项

适用场景（解读层）

  • 为 Django 5.2+ 项目接入 Valkey 服务端（7.2.6+）作为缓存存储
  • 将 Valkey 用作 Django 会话存储，支持 Unix 套接字和无限超时配置
  • 从 django-redis 迁移到 Valkey 的项目（该项目为其 fork）
