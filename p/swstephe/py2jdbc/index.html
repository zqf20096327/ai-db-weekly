通过 ctypes 调用 JNI 访问 JDBC 数据库的 Python 模块，实现 DB-API 2.0

综述（解读层）

py2jdbc 是一个 Python 模块，用于访问 JDBC 兼容数据库，实现 Python DB-API 2.0（PEP 249）规范。它通过 ctypes 对 JNI API 进行 FFI 调用，无需额外 JVM 绑定库。通过 py2jdbc.connect 传入 JDBC URL 建立连接，classpath 可从 CLASSPATH 环境变量、lib 目录或连接参数读取。适用于已有 JDBC 驱动的数据库接入 Python 的场景。

  • 实现 Python Database API Specification 2.0（PEP 249），支持 cursor 的 execute、executemany 与上下文管理器
  • 通过 ctypes 调用 JNI API 连接 JDBC 数据库，classpath 可经环境变量、lib 目录或 connect 参数指定
  • 查询结果自动描述结果集并将值转换为标准 Python 类型，参数绑定使用问号占位符

适用场景（解读层）

  • 在 Python 中访问有 JDBC 驱动但缺少原生 DB-API 适配器的数据库
  • 需要按 JDBC URL 直接连接并复用现有 Java classpath 驱动 jar 的环境
  • 遵循 DB-API 2.0 接口的通用数据库脚本与原型开发
