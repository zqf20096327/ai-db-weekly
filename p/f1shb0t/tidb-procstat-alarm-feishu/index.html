🧭 简介解读层（AI·证据行可回查）

基于 CloudWatch procstat 与 Lambda 的 TiDB 进程存活飞书告警方案

综述（解读层）

该项目提供一套 AWS CDK 代码与 CloudWatch Agent 配置文件，用于监控自建 TiDB 集群中 PD、TiKV、TiFlash 进程的存活状态，链路为 procstat 采集 pid_count、CloudWatch Alarm、SNS 转发至 Lambda，进程退出或缺数据（BREACHING）时推送红色/绿色告警卡片到飞书。仅覆盖进程层，不含组件健康检测，适合已将 TiDB 部署在 EC2 上、使用飞书协作的运维团队。

  • 通过 CDK 生成 SNS Topic、Lambda 及每个实例×组件的 procstat Alarm，实例清单支持 context 参数免改代码传入
  • cwagent 配置目录提供 PD / TiKV / TiFlash 三份组件配置及带注释的模板文件
  • Alarm 默认设 treatMissingData=BREACHING，解决进程死后无数据点导致漏报的问题

适用场景（解读层）

  • 监控部署在 EC2 上的自建 TiDB 集群，进程挂掉或恢复时在飞书群接收告警/恢复卡片
  • 在未部署 Prometheus+Alertmanager 的环境中补充进程级告警能力
  • 作为基础扩展「健康抓取脚本 + 自定义 metric Alarm」模块以检测组件级健康状态
📖 README 首段存档原文 · 程序抽取
