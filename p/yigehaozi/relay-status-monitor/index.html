🧭 简介解读层（AI·证据行可回查）

自托管的 AI API 中转站状态监控面板，按 Key/分组采集指标并推送飞书告警。

综述（解读层）

该面板用于监控 SUB2API 与 New API 上游，采集余额、延迟、首 Token 延迟和流式 TPS，并支持在线/降级/离线状态聚合与余额、延迟、可用率告警规则。基于 Next.js 14 + Prisma + PostgreSQL，通过 AES-256-GCM 加密保存上游凭证，定时采集依赖外部 cron 触发接口；重量测试会发送真实模型请求并消耗额度。

  • 支持 SUB2API 与 New API 上游，可为一个上游配置多个独立 Key/分组
  • 采集余额、接口延迟、模型测试延迟、首 Token 延迟和流式 TPS，维护 Key 与上游两级状态
  • 提供余额、延迟、连续失败、可用率四类告警规则，经飞书 Webhook 通知并支持冷却与自动恢复

适用场景（解读层）

  • 自托管运维场景中集中查看多个 AI API 中转站的余额与可用性
  • 通过定时采集和飞书告警在余额不足、连续失败或可用率下降时收到通知
  • 对模型接口执行生成与流式测速，验证上游的模型响应能力
📖 README 首段存档原文 · 程序抽取

一个面向 AI API 中转站的自托管状态监控面板。它可以统一管理多个 SUB2API 与 New API 上游，按 Key/分组采集余额、延迟、可用率和模型测速数据，并通过告警规则与飞书 Webhook 发送异常通知。
