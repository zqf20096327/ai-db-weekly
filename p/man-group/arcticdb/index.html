面向 Python 数据科学生态的无服务器 DataFrame 数据库

综述（解读层）

ArcticDB 是一个面向 Python 数据科学生态的 DataFrame 数据库，通过 Python API 将 Pandas DataFrame、NumPy 数组写入 S3、LMDB 或 Azure Blob 存储，底层采用 C++ 数据处理与压缩引擎。数据按 symbol 组织，支持版本快照与无模式写入。采用 BSL 1.1 许可，生产环境使用需向 ArcticDB Limited 购买商业授权。

  • 支持读写 Pandas DataFrame、NumPy 数组至 S3、LMDB 和 Azure Blob 存储
  • 按 symbol 组织数据，保留历史版本并可创建数据库快照
  • 内置 Pandas 风格语法的过滤、聚合与动态新建列操作

适用场景（解读层）

  • 时间序列数据的本地或对象存储持久化（量化分析、数据科学工作流）
  • 流式与稀疏数据的追加、更新与修改
  • 需要版本回溯与快照管理的 DataFrame 存储
