开源自托管产品分析平台，Go 构建，含漏斗、留存与 MCP 服务器。

综述（解读层）

Pug 是一个开源产品分析平台，用于采集事件、识别用户，并以漏斗、留存、趋势、细分和用户流等形式展示在可配置仪表盘上。技术栈为 Go、PostgreSQL、ClickHouse 和 NATS，提供 Web/iOS/Android/Flutter/Node.js/Go/Ruby SDK，可自托管（容器镜像发布于 ghcr.io/pug-sh），并内置 MCP 服务器供 AI 客户端查询数据。在访客同意前不使用 Cookie，支持 GDPR/DPDP 数据主体删除。

  • 基于 NATS 的事件摄取管线，自动进行地理位置、User-Agent、机器人检测和流量归因富化
  • 提供趋势、漏斗、留存、细分、用户流（Sankey）与 top-K 拆解分析，及实时访客世界地图视图
  • 内置 MCP 服务器，提供 16 个读取工具和 1 个仪表盘编辑工具，支持 Claude/ChatGPT 等 MCP 客户端接入

适用场景（解读层）

  • 自托管网站与移动应用的产品/行为分析：事件采集、漏斗与留存分析
  • 通过 MCP 客户端（如 Claude、ChatGPT）用自然语言查询分析数据并生成仪表盘
  • 需要合规数据删除（GDPR/DPDP）与无 Cookie 采集的团队，以及 AI 爬虫访问报告场景
