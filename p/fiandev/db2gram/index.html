将多种数据库备份加密分块上传至 Telegram 的命令行工具

综述（解读层）

db2gram 是一个 Node.js 命令行工具，按 dump→zip→AES-256-GCM 加密→分块（≤48 MB）→上传的流程，把 PostgreSQL 和 MariaDB/MySQL 数据库备份到指定 Telegram 聊天，并生成记录 file_id 的 manifest 以便单命令恢复。配置与凭据加密存储于 config.yaml.enc，运行记录写入控制数据库。适合需自管服务器备份且使用 Telegram 作存储介质的运维人员；SECRET_KEY 丢失则无法恢复。

  • v1 支持 PostgreSQL 与 MariaDB/MySQL 两种方言，备份管道为 dump→zip→加密→分块→上传
  • 使用 AES-256-GCM 加密归档与配置文件，分块带 SHA-256 校验
  • 提供 --wizard 交互向导、--dry-run 演练模式，并通过控制数据库记录运行与分块历史

适用场景（解读层）

  • 通过 systemd timer 或 cron 定时执行多数据库每日备份并上传到 Telegram 私聊、群组或频道
  • 使用 manifest 结合 SECRET_KEY 与 Bot Token 单命令恢复指定数据库到目标 URL
  • 在 VPS、NAS 或 CI 环境中运行备份，需 Node.js 20+、对应 DB 客户端及通往 api.telegram.org 的 HTTPS 出站访问
