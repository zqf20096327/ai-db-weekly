🧭 简介解读层（AI·证据行可回查）

基于 Rust 运行时的异步 ORM，用 Pydantic v2 模型声明数据库表。

综述（解读层）

Ormdantic 是面向 Python 应用的异步 ORM，允许用 Pydantic v2 模型装饰为数据库表，通过 Rust 实现的运行时执行 SQL 编译、类型转换与驱动执行。提供异步 CRUD、关系加载、事务、迁移、数据库反射与原生 SQL 执行，支持 SQLite、PostgreSQL、MySQL、MariaDB、SQL Server 和 Oracle。README 注明项目仍在快速演进，建议生产环境使用前审查生成的 SQL。

  • 支持以 Pydantic v2 模型装饰声明数据库表，提供异步 CRUD（插入、更新、upsert、删除、查找、计数、批量更新）
  • 包含迁移快照、diff、计划、历史、回滚、修复与 squash 助手，并提供可从 --url、DATABASE_URL 或 .env 读取连接的迁移 CLI
  • 通过 Rust 原生运行时支持 SQLite、PostgreSQL、MySQL、MariaDB、SQL Server 和 Oracle 驱动

适用场景（解读层）

  • 需要在 Python 应用中使用 Pydantic 模型定义数据库表并执行异步数据库操作的场景
  • 需要迁移管理与数据库结构反射（表、列、索引、约束、视图等）检查的项目
  • 需要同时使用字典过滤和表达式对象构建普通或复杂 SQL 查询的应用

Ormdantic lets you declare database tables with Pydantic v2 models and run async CRUD, relationship loading, migrations, reflection, and native SQL execution through a Rust-backed runtime.
