自托管的 Web 数据库工作台，单一 Go 二进制连接多种数据库引擎

综述（解读层）

Rowsmith 是一个自托管 Web 工作区，用于浏览、查询、编辑和管理 MySQL、PostgreSQL、MongoDB、Redis 等 22 种数据库引擎。面向团队使用，提供角色权限、连接密钥加密存储、SSH 隧道、审计日志、跨引擎迁移、定时查询和可自选模型（含 Ollama 本地部署）的 AI 助手。项目处于早期开发阶段，部署方式为在自有反向代理后以独立容器运行。

  • 以单一 Go 二进制内嵌 Web 应用运行，支持 SSH 隧道（含跳板机链）和信封加密的团队密钥库
  • 提供跨服务器与跨引擎的表和行迁移，列类型逐列映射并逐值校验
  • 包含查询计划树（EXPLAIN）、行级安全编辑（单事务、逐行匹配校验）、导入导出 CSV/JSON/Excel/SQL 及定时报告与变更告警

适用场景（解读层）

  • 团队需要统一的 Web 界面管理多种异构数据库连接与密钥
  • 在 MySQL、PostgreSQL、SQL Server 等引擎之间复制表数据或迁移模式
  • 配置定时只读查询，将结果以邮件、Slack/Teams 或 webhook 推送并在数据变化时告警
