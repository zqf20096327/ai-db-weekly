🧭 简介解读层（AI·证据行可回查）

自托管的数据库查询审批平台，以类 PR 流程执行四眼原则审查

综述（解读层）

Kviklet 为生产数据库访问提供类 Pull Request 的审查与审批工作流，请求分为单条 SQL 审查和限时会话两种形式。支持 Postgres、MySQL、MariaDB、SQL Server、MongoDB，数据库密码不向用户展示，所有执行语句记录审计日志。以 Docker 容器部署，依赖自身 PostgreSQL 存储元数据；SAML、代理、MCP Server 等功能需企业版许可。

  • 提供单条 SQL 审查与限时临时访问两种请求类型，经他人审批后方可执行
  • 支持 OIDC/Google、Keycloak、GitHub、LDAP 等认证方式，通过数据库自身 RBAC 管理底层权限
  • 记录所有已执行语句的审计日志，代理模式支持用临时密码通过本地客户端连接（Postgres、MariaDB、MySQL）

适用场景（解读层）

  • 工程团队需要在不经 DBA 逐条转发的情況下审批生产库查询
  • 需要向工程师发放临时数据库会话而不共享底层凭证
  • 需要集中留存生产数据库手动操作的审计记录
