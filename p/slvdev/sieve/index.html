🧭 简介解读层（AI·证据行可回查）

自托管以太坊/OP-Stack 事件索引器，通过 P2P 网络同步区块并写入 Postgres

综述（解读层）

Sieve 是用 Rust 编写的自托管索引器，直接从 P2P 网络获取以太坊及 OP-Stack 链（Base、OP Mainnet、Unichain、World Chain）的区块，无需 RPC 提供商。它按 TOML 配置解码事件日志、函数调用、原生转账和工厂子合约，表结构由 ABI 自动生成，并通过 GraphQL API 查询。区块提交前须经多节点 quorum 校验和头部链验证；一个进程只索引一条链。

  • 直接连接 P2P 网络（discv4/discv5、basev0）获取区块，不需要 RPC 提供商或 API 密钥
  • 支持索引事件日志、函数调用、原生 ETH 转账和工厂合约动态发现的子合约，数据存入 PostgreSQL 并提供 GraphQL API
  • 区块提交前执行多节点头部 quorum 确认、规范链逐块验证和负载根重算，并在 Base 上支持经校验的归档快照导入

适用场景（解读层）

  • 需要自托管索引以太坊或 OP-Stack 链合约事件并写入自有数据库的场景
  • 通过 GraphQL 查询合约事件、函数调用或原生转账历史的应用
  • 需要导入 Base 历史区块（含归档快照引导）并持续跟踪链头的分析流水线
