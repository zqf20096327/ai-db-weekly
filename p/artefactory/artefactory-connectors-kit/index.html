基于命令行的 E(T)L 工具，通过 Reader/Stream/Writer 组件实现 API 数据采集。

综述（解读层）

ACK（Artefactory Connectors Kit）是一个面向 API 数据采集的 E(T)L 命令行工具，提供 Readers（读取 API 生成流）、Streams（处理单条记录）和 Writers（写入目标）三个 Python 类组件。README 说明常见输出格式为 .njson，即每行为一个 JSON 对象的文件，适用于需要从广告、分析类 API 抽取数据并加载到数据仓库或云存储的场景。

  • 以 CLI 方式运行，由 Readers、Streams、Writers 三个 Python 类组件组成 E(T)L 流水线
  • 提供约 20 余个 Readers，覆盖 Adobe Analytics、Google Analytics、DV360、Facebook Marketing、MySQL、S3 等来源
  • Writers 支持 Google BigQuery、Amazon S3、Google Cloud Storage、Azure Blob Storage、Console 及本地文件输出

适用场景（解读层）

  • 从广告与营销类 API（Google Ads、DV360、Twitter Ads 等）批量抽取数据
  • 将 API 数据以 .njson 格式写入 S3、GCS、Azure Blob 等对象存储或 BigQuery
  • 在 Airbyte 暂无对应连接器时作为补充采集工具使用
