🧭 简介解读层（AI·证据行可回查）

为 Claude Code 提供跨会话持久记忆的插件，以 Markdown 存储并用 SQLite FTS5 检索。

综述（解读层）

memem 是一个 Claude Code 插件，用于在多个会话间保存和检索记忆。它通过 Stop-hook 触发后台子进程，从对话中提取决策、约定、修复方案等内容，以 Markdown 形式写入本地 Obsidian vault，并在检索时生成 Active Memory Slice。数据完全存放在本地，不依赖云服务或 API key。适用于使用 Claude Code 并希望保留项目上下文的开发者，运行需 Python 3.11+。

  • 事件触发的 miner 从每轮对话中提取决策、约定、bug 修复、偏好等记忆，存为 Obsidian vault 中的 Markdown 文件
  • 检索由单一三路 RRF 引擎（cosine + BM25 + FTS5）服务，覆盖 hook、MCP 工具和 CLI 调用路径，transcript_search 基于 ~/.memem/transcript_fts.db 的持久 FTS5 索引
  • 本地优先：无云服务、无需 API key，记忆存储为人类可读的 Markdown，v2.9.0 将 MCP 工具面从 14 个精简为 6 个

适用场景（解读层）

  • 在 Claude Code 中跨会话保留项目决策、约定和偏好，避免每次会话重复说明项目背景
  • 在 Obsidian vault 中集中管理 AI 生成的记忆条目，保持本地化、可读的数据存储
  • 检索历史会话记录：通过 FTS5 索引按 Q/A 轮次搜索过去的 transcript
