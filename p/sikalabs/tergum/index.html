🧭 简介解读层（AI·证据行可回查）

命令行备份工具，通过 YAML 配置从多种数据源备份到多种存储后端。

综述（解读层）

Tergum 是 SikaLabs 开发的备份工具，通过 YAML 配置文件定义备份任务。数据源支持 MySQL、PostgreSQL、MongoDB、MSSQL、Redis、Vault、Consul、Kubernetes 资源、文件/目录、FTP、Notion、GitLab、Proxmox VM 等，目标存储支持文件系统、S3、Azure Blob 和 Telegram。提供 Gzip 压缩、对称加密、S3 保留策略、备份失败通知与自动恢复测试。README 注明项目处于活跃开发阶段，并非所有功能已实现。

  • 支持多种数据源（MySQL、PostgreSQL、MongoDB、MSSQL、Redis、Vault、Consul、Kubernetes、文件/目录、FTP、Notion、GitLab、Proxmox 等）和多种存储目标（S3、Azure Blob、文件系统、Telegram）
  • 提供 Gzip 压缩、对称加密、S3 上传重试与基于 KeepCount/KeepDays 的保留策略
  • 包含备份监控、失败通知和自动恢复测试；Vault 源支持静态 Token 与 Kubernetes auth 两种认证方式

适用场景（解读层）

  • 将多台服务器上的数据库与文件集中备份到 S3 或 Azure Blob 等对象存储
  • 在 Kubernetes 环境中备份 TLS Secret、Pod 资源或通过 Service Account 认证备份 Vault 数据
  • 需要备份保留策略（按数量或天数自动清理旧备份）与备份失败告警的场景
