纯 Go 编写的嵌入式向量数据库，提供 HNSW 索引与 Qdrant 兼容 API

综述（解读层）

GoVector 是一个用纯 Go 实现的嵌入式向量搜索引擎，无需 CGO 依赖，数据经 Protocol Buffers 持久化到 BoltDB。它可作为 Go 库直接嵌入应用，也可通过 `govector serve` 以独立服务运行，提供 Qdrant 风格的 REST API（/collections、/points、/search），并附带 CLI 与交互式 TUI。索引默认启用 HNSW，支持 Cosine、欧氏距离、内积三种度量与载荷过滤。安装可通过 Homebrew、源码构建或 `go get` 引入。

  • 纯 Go 实现、无 CGO 依赖，可交叉编译至 Windows、macOS、Linux 及边缘设备
  • 内置 HNSW 图索引（默认启用、自动创建），支持 Flat 与 HNSW 两种索引及 SQ8 标量量化
  • 提供嵌入式库、独立 REST 服务（Qdrant 兼容端点）与 CLI/TUI 三种使用方式，数据经 Protobuf + BoltDB 持久化

适用场景（解读层）

  • 在 Go 后端或桌面/边缘应用中嵌入向量检索，避免网络开销与 C 依赖
  • 本地 AI / RAG 场景的单机向量存储与近邻搜索
  • 通过 Qdrant 兼容 REST API 作为轻量微服务运行，使用 CLI/TUI 管理集合与数据
