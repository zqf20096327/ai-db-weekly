基于 ORM 模式的 Android SQLite 数据库操作库，免写 SQL 完成建表与增删改查。

综述（解读层）

LitePal 是一个开源 Android 库，采用对象关系映射（ORM）模式封装 SQLite 操作，开发者通过继承 LitePalSupport 并在 litepal.xml 中注册模型类，即可自动创建和升级表，用链式 API 完成增删改查、聚合函数和多数据库切换。升级时若新增 unique 约束等特定变更会导致表数据被清除。适用于需要在 Android 应用中管理本地 SQLite 数据的开发者。

  • 采用 ORM 模式，模型类继承 LitePalSupport 后自动维护表的创建、变更和删除
  • 提供封装的 CRUD API 与链式查询 API，支持事务操作和多数据库运行时创建与切换
  • 仅需要一个 litepal.xml 配置文件，通过 gradle 依赖 org.litepal.guolindev:core:3.2.3 集成

适用场景（解读层）

  • Android 应用需要在本地 SQLite 中存储和查询结构化对象数据
  • 应用需要通过修改模型类加版本号的方式升级数据库表结构
  • 应用需要运行时创建、切换或删除多个数据库
