Ruby 安全数据数据库库，基于 ActiveRecord 提供 ORM 模型与 CLI 管理

综述（解读层）

ronin-db 是 ronin-rb 项目下的一个 Ruby 库，用于管理和查询安全数据（URL、邮箱、主机名、IP、端口等）。它基于 ActiveRecord 提供公共 ORM 模型，默认使用 SQLite（也可通过 URI 连接 PostgreSQL 等），并提供 `ronin-db` 命令行工具完成数据库增删及主机名等条目的查询、插入、导入。要求 Ruby >= 3.0.0，通过 `gem install ronin-db` 安装，面向做安全数据收集与管理的 Ruby 用户。

  • 提供 ActiveRecord ORM 模型，用于与数据库 SQL 表交互并插入/查询安全数据
  • 提供 ronin-db CLI 命令，支持列出/添加/删除数据库，以及查询、插入、删除、导入各表条目
  • 默认使用 SQLite，可通过 URI 添加 PostgreSQL 等自定义数据库连接

适用场景（解读层）

  • 集中存储与查询安全采集数据（主机名、URL、IP、端口、邮箱等）
  • 通过 CLI 导入目标清单文件并按域名过滤查询
  • 在 Ruby 代码中通过 Ronin::DB.connect 与 ORM 模型直接操作数据库
