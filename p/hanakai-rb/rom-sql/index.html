rom-rb 的 SQL 适配器，为 Ruby 数据映射提供关系数据库支持

综述（解读层）

rom-sql 是 rom-rb 生态的 SQL 适配器 gem，用于将 rom-rb 的数据映射能力连接到关系数据库。主题标签显示支持 PostgreSQL、MySQL、MariaDB、SQLite、Oracle 及 MSSQL 等数据库。README 内容较简略，仅说明官方支持 MRI >= 3.2 的 Ruby 版本，具体使用方式需查阅其用户文档与 API 文档链接。

  • 作为 rom-rb 的 SQL 适配器 gem 提供，可通过 RubyGems 安装
  • 主题标签涵盖 PostgreSQL、MySQL、MariaDB、SQLite、Oracle、MSSQL 等数据库
  • 官方支持 MRI >= 3.2 的 Ruby 版本

适用场景（解读层）

  • 在 rom-rb 项目中连接关系型数据库进行数据映射
  • 使用 Ruby 3.2+ 构建需要 SQL 存储支持的应用
