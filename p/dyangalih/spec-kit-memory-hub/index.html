面向 Spec Kit 的仓库内持久记忆扩展，含 SQLite 缓存与 MCP 服务器

综述（解读层）

Spec Kit Memory Hub 是一个 Spec Kit CLI 扩展（memory-md），为 AI 辅助开发提供跨功能的持久项目记忆。记忆按三层存储于 .specify/memory/、docs/memory/ 和 specs/<feature>/ 目录，以 Markdown 形式纳入 Git 跟踪，并借助 SQLite 缓存选择性索引与检索。安装方式为 specify extension add memory-md，需通过 /speckit.memory-md.init 初始化仓库结构；内置的 MCP 服务器可通过 npx speckit-memory mcp-start 启动。

  • 提供三层记忆架构：治理规则、项目长期记忆与功能级临时上下文（生成上限 900 词的 memory-synthesis.md）
  • 内置原生 MCP 服务器，暴露 speckit_memory_search、synthesize、share_lesson 等工具，经 JSON-RPC 供 LLM 客户端调用
  • 记忆条目以 Git 可审阅的 Markdown 存储，跨项目共享 lesson 时以 SHA-256 匿名化项目路径

适用场景（解读层）

  • 使用 Spec Kit 的团队需要在新功能开发中复用既往架构决策、bug 预防模式与经验教训
  • 在 Claude Desktop、VS Code Cline、Cursor 等支持 MCP 的客户端中为 AI 代理提供项目持久上下文
  • 需要将经验教训以 Markdown 文件形式留在仓库中供新成员与代理查阅的项目
