🧭 简介解读层（AI·证据行可回查）

MariaDB 关系数据库服务器，MySQL 社区分支，支持可插拔存储引擎与向量搜索。

综述（解读层）

MariaDB Server 是由全球社区与 MariaDB Foundation、MariaDB plc 共同开发的开源关系数据库，最初源于 MySQL 分支并保持较高的 MySQL 兼容性。支持内置 VECTOR 类型与 HNSW 向量索引、多种可插拔存储引擎、Galera 同步集群及系统版本表等特性。采用 GPLv2（不含 later version 条款）许可，提供每年一次的 LTS 版本与季度滚动版本。

  • 内置 VECTOR 数据类型与 HNSW 近似最近邻索引，11.8 起无需扩展即可使用
  • 提供 InnoDB、Aria、MyRocks、ColumnStore、Spider、S3 等多种可插拔存储引擎
  • 支持异步、半同步、并行复制及 Galera 同步多主集群，含全局事务 ID

适用场景（解读层）

  • 从 MySQL 现有部署迁移的应用场景
  • 需要向量搜索、全文检索或 GIS 功能的应用
  • 需要多主同步集群或分析型负载（ColumnStore）的生产系统
