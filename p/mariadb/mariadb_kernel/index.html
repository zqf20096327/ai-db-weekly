Jupyter 的 MariaDB 内核，可在 Notebook 中运行 MariaDB。

综述（解读层）

mariadb_kernel 是一个开源 Jupyter 内核，使用户能在 Jupyter Notebook 中运行 MariaDB。前提是系统需已安装 Jupyter Lab 和 MariaDB；安装通过 PyPI 包完成，conda-forge 打包在 README 中标注为即将提供。适合希望在 Notebook 环境中使用 MariaDB 的用户。

  • 提供 Jupyter 内核，支持在 Notebook 中运行 MariaDB
  • 已发布至 PyPI，可通过 pip 安装
  • 提供安装脚本以注册 kernelspec，使其在 JupyterLab 中可见

适用场景（解读层）

  • 在 Jupyter Notebook 中编写和运行 MariaDB 语句
  • 为已部署 Jupyter Lab 与 MariaDB 的环境添加数据库内核
  • 结合官方文档中的示例笔记本进行学习与演示
📖 README 首段存档原文 · 程序抽取

mariadb_kernel is a an Open Source kernel for Jupyter which enables users to run MariaDB in a Jupyter notebook.
