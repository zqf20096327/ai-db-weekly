🧭 简介解读层（AI·证据行可回查）

为 MariaDB 提供 MCP 协议接口的服务器，支持 SQL 查询与向量检索

综述（解读层）

该项目实现 Model Context Protocol 服务器，供 AI 助手连接 MariaDB 数据库，提供列出库表、读取表结构、执行只读 SQL 等工具；配置嵌入服务商后还可创建向量存储并做语义搜索。默认开启只读与敏感 SHOW 命令屏蔽，但项目明确说明真正的只读保障需依赖数据库用户权限配置。需 Python 3.11、uv 与 MariaDB 服务端。注意：仓库将于 2026 年 11 月 3 日弃用，后续开发转移至 mariadb-corporation/ai-plugins。

  • 提供 list_databases、list_tables、get_table_schema、execute_sql 等标准数据库工具
  • 支持可选的向量存储能力，可对接 OpenAI、Gemini、HuggingFace 嵌入服务
  • 通过环境变量配置只读模式、敏感命令屏蔽、SSL/TLS、连接池与传输方式（stdio/sse/http）

适用场景（解读层）

  • 让 AI 助手通过 MCP 协议查询 MariaDB 数据库结构和执行只读 SQL
  • 基于嵌入向量在 MariaDB 中构建文档语义搜索
  • 以本地 stdio 或远程 sse/http 方式向 AI 工作流暴露数据库操作
