基于Java的MySQL到OpenGauss全量建表与数据迁移工具

综述（解读层）

该项目将MySQL数据库中的表结构转换为OpenGauss表并全量传输数据，需用户提前建好目标库。工具采用Java开发，建议JDK 17以上，提供自动运行和HTTP接口两种触发方式，执行后在result目录生成迁移报表。仅在Linux、MySQL 8.x和OpenGauss 6.x环境完成测试。

  • 支持OpenGauss A模式（PostgreSQL）和B模式（MySQL）两种模式的表转换与数据传输
  • 提供全量迁移、仅转换表、仅迁移数据三个HTTP接口，可通过配置auto-run自动执行
  • 支持配置迁移表与过滤表，执行完成后在result目录生成含报错信息的迁移报表

适用场景（解读层）

  • 需要将MySQL全部表结构和数据全量迁移到OpenGauss的场景
  • 借助B模式支持在两个MySQL数据库之间互相迁移数据
  • 需要通过HTTP接口触发迁移，分步执行建表或数据传输的场景
📖 README 首段存档原文 · 程序抽取

本项目的功能为将MySQL中的全部数据传输到OpenGauss中。OpenGauss的库需要用户提前建好，本工具只提供建表和传输数据的功能。
