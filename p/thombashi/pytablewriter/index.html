将表格数据写入 Markdown、Excel、LaTeX 等多种格式的 Python 库

综述（解读层）

pytablewriter 是一个 Python 表格写入库，可将二维数据输出为 AsciiDoc、CSV、Markdown（含 GFM）、HTML、LaTeX、JSON、TOML、YAML、Excel（.xlsx/.xls）、SQLite、Elasticsearch 等多种格式。它支持从嵌套列表、CSV、pandas.DataFrame 等数据源读取，自动处理单元格对齐、数字小数位与千分位格式，并可写入文件、标准输出或 Jupyter Notebook。部分格式需安装可选依赖。

  • 支持将表格写入二十余种文本、二进制及应用格式，包括 Markdown、LaTeX、Excel、SQLite、Elasticsearch 等
  • 自动进行单元格对齐、内边距和数字小数位格式化，并支持多字节字符与 ANSI 颜色
  • 输出目标可为文件、标准输出、字符串缓冲区或 Jupyter Notebook

适用场景（解读层）

  • 在脚本或 Notebook 中生成 Markdown、reStructuredText 等文档格式的表格
  • 将 Python 数据导出为 Excel、SQLite 或 JSON/LDJSON 文件
  • 将表格数据写入 Elasticsearch 或生成 JavaScript、NumPy、Pandas 代码定义
