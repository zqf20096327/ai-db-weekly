基于 PyDBML 的 Python 包，将 .dbml 文件转换为 SQLite DDL

综述（解读层）

dbml_sqlite 是一个构建于 PyDBML 之上的 Python 包，读取 .dbml 文件或含该类文件的目录，生成有效的 SQLite DDL 字符串，支持 CLI 与 toSQLite 函数两种调用方式。由于 SQLite 不直接支持枚举，它提供 full（建独立枚举表）与 half（CHECK 约束）两种模拟模式，并将 bool、varchar 等外部类型映射为 SQLite 类型。需要 Python 3.7+，MIT 许可，并非所有 DBML 都能转换为有效 SQLite，无法转换时报错。

  • 提供 toSQLite 函数与 dbml_sqlite 命令行工具，可打印、写入文件或直接在 SQLite 数据库上执行生成的 DDL
  • 支持 full（独立枚举表）和 half（CHECK 语句）两种枚举模拟模式，并可自动添加 IF NOT EXISTS 语句
  • 将 bool、bigint、varchar、datetime 等常见外部 SQL 类型映射为对应的 SQLite 类型（INTEGER/REAL/TEXT/BLOB）

适用场景（解读层）

  • 在 Python 项目中由 .dbml 模型文件生成 SQLite 建表脚本
  • 通过 CLI 将 DBML 转换为 DDL 并写入文件供人工检查或修改
  • 需要在 SQLite 中模拟 DBML 枚举定义的数据库建模流程
📖 README 首段存档原文 · 程序抽取

This is a simple package built on top of the PyDBML package by Vanderhoof. It allows you, within certain constraints, to generate valid SQLite from .dbml files for your Python programs.
