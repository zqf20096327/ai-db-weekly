🧭 简介解读层（AI·证据行可回查）

Web 版统一资源管理操作平台，以资源树集中管理机器、数据库、缓存等资源

综述（解读层）

mayfly-go 是基于 Go（Gin/GORM）与 Vue 3 的 Web 平台，将机器运维（终端、文件、脚本、进程）、多类数据库（MySQL、PostgreSQL、Oracle、SQL Server、达梦、高斯、SQLite、ClickHouse）、Redis、MongoDB、Elasticsearch、Kafka、Docker 等资源挂载于统一资源树下操作。内置工单审批、命令拦截、告警与消息通知，适合运维工程师、DBA 与后端开发者使用，提供 Docker 单容器部署，默认端口 18888。

  • 提供 Web 终端（含终端录像回放）、文件管理、脚本执行、计划任务、进程监控与多机批量命令执行等机器运维能力
  • 支持多种关系型数据库及 Redis（单机/哨兵/集群）、MongoDB、Elasticsearch、Milvus、Kafka、Docker 的在线管理，含 SQL 编辑器、Schema Diff、数据同步与迁移、数据脱敏
  • 实现命令黑名单拦截（禁止/审批/提醒三级处置）、工单流程审批、告警规则与多渠道通知（企业微信/钉钉/飞书/邮件），并提供 AI 助手与 AgentOps 运维编排

适用场景（解读层）

  • 通过浏览器统一管理多台 Linux 主机的终端、文件与批量命令执行
  • 在单一平台内操作多种数据库实例，进行 SQL 编写、结构比对与数据同步迁移
  • 需要操作审批留痕、危险命令拦截与告警通知的团队运维场景
