Java/Kotlin 强类型 ORM 框架，基于表达式 API 生成 SQL，支持分库分表

综述（解读层）

easy-query 是 dromara 旗下的 Java/Kotlin ORM 框架，用于替代手写 JDBC 查询。它通过 APT 为实体生成代理代码，开发者以强类型 lambda 表达式编写查询，框架生成对应 SQL。特性包含隐式 join/子查询、逻辑删除、列加密、多租户、读写分离与自动分表，支持 MySQL、PostgreSQL、Oracle 等 12 种数据库，需 JDK 8 及以上，可通过 Spring Boot 或控制台方式集成。

  • 提供隐式 join、隐式子查询、隐式分组、隐式分区分组、隐式 CASE WHEN 五类隐式查询能力
  • 支持单表/多表查询、union、子查询、分页、动态表名、VO 投影返回
  • 包含逻辑删除、列加密（支持 LIKE 查询）、数据追踪差异更新、乐观锁、多租户、自动分库分表与读写分离

适用场景（解读层）

  • Java/Kotlin 项目中以强类型表达式编写 OLTP 查询，避免手写 SQL 字符串
  • 需要分库分表、读写分离或多租户能力的数据库应用
  • 基于 OneToMany/ManyToOne 关联的关联筛选、排序与聚合查询场景
