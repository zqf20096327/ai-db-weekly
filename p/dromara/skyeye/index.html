基于Spring Cloud Alibaba微服务的企业级智能制造零代码一体化管理平台

综述（解读层）

SkyEye云是Dromara开源组织下的企业管理平台，内置CRM、ERP进销存、MES、WMS、OA、EHR、工作流等业务模块，通过表单、布局、工作流、编码、打印五类可视化设计器实现拖拽式搭建。后端采用Spring Cloud Alibaba、Nacos、RocketMQ、Activiti，前端为Vue3+Ant Design Vue，移动端用uni-app编译多端。需注意开源仓库不含全部代码，完整源码需开通会员获取，运行依赖JDK 1.8、MySQL、Redis、Nacos、RocketMQ。

  • 提供CRM、ERP进销存、MES生产、WMS仓储、OA行政、EHR人事、项目管理、售后工单等多个业务模块
  • 内置表单、布局、工作流、编码、打印五类可视化设计器，支持拖拽式搭建业务表单与流程
  • 后端基于Spring Cloud Alibaba微服务架构（Nacos、RocketMQ、Sentinel、XXL-Job、Activiti），前端Vue3，移动端uni-app一套代码编译小程序/H5/App

适用场景（解读层）

  • 需要CRM、进销存、生产执行等业务模块的企业信息化管理场景
  • 希望以可视化设计器定制业务表单与审批流程的低代码开发场景
  • 需要PC端与移动端（小程序/H5/App）多端发布的企业内部系统开发
