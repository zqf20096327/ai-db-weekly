🧭 简介解读层（AI·证据行可回查）

WP-CLI 的数据库字符串搜索替换命令，能正确处理序列化数据。

综述（解读层）

wp-cli/search-replace-command 是 WP-CLI 自带的 wp search-replace 命令包，用于在 WordPress 数据库表中搜索并替换字符串，面向需要迁移域名或批量修改内容的站点管理员。它默认操作 $wpdb 注册表，支持通配符限定表名、跳过或指定列、正则匹配、dry-run 预演和导出 SQL 文件；可正确处理 PHP 序列化数据，不修改主键，无主键的表会被跳过。

  • 处理 PHP 序列化数据，且不更改主键值
  • 支持 --dry-run、--export、正则替换、表/列级别的包含与排除

适用场景（解读层）

  • WordPress 站点更换域名后的数据库 URL 替换
  • multisite 生产库转本地开发环境的数据调整
  • 不改动数据库、仅生成替换后的 SQL 导出文件
