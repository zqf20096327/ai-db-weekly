🧭 简介解读层（AI·证据行可回查）

基于 Tauri 的跨平台 SQL 数据库客户端，支持 70+ 数据库和 AI 代理功能

综述（解读层）

SqlKit 是基于 Tauri（Rust）和 Vue 3 构建的桌面数据库 GUI 客户端，运行于 macOS、Windows 和 Linux。它通过原生驱动、协议兼容和 JDBC/HTTP 桥接四种适配策略连接 70+ 数据库，提供 Monaco 编辑器、模式浏览和查询历史等功能。基础功能按 Apache 2.0 协议开源；AI 代理、跨引擎数据传输等高级能力属于付费订阅部分，AI 功能需用户自备 API 密钥。

  • 通过四种适配策略（原生 Rust 驱动、PG/MySQL 协议兼容、JDBC 桥接、HTTP 桥接）支持 PostgreSQL、MySQL、Oracle、ClickHouse 等 70+ 数据库
  • 内置 AI 代理功能，支持 OpenAI、Anthropic、DeepSeek 和 Ollama 端点，凭据不暴露给 LLM，破坏性操作需确认
  • 编辑器基于 Monaco，提供语法高亮、自动补全、多标签页、模式树浏览和 CSV/JSON/Markdown 导出；支持 SSH 隧道、SSL/TLS 及操作系统密钥链凭据存储

适用场景（解读层）

  • 需要在单一桌面应用中连接多种类型数据库（关系型、分析型、国产数据库等）进行日常 SQL 查询与管理
  • 需在离线或隐私敏感环境中使用数据库客户端（应用可完全离线运行，凭据存储于本机）
  • 通过自然语言生成 SQL、分析执行计划并进行跨数据库引擎的数据迁移与导入导出（部分功能为付费版）
