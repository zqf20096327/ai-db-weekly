🧭 简介解读层（AI·证据行可回查）

基于 Tauri (Rust) 的跨平台 SQL 数据库桌面客户端，内置 AI 代理，支持 70+ 数据库

综述（解读层）

SqlKit 是一款桌面 SQL 数据库管理客户端，基于 Tauri v2 与 Vue 3 构建，提供 SQL 编辑（Monaco）、模式浏览、查询历史、结果导出及跨引擎数据传输。通过原生驱动、PG/MySQL 协议兼容、JDBC 与 HTTP 四类桥接策略连接 70 余种数据库。社区版（Apache 2.0）免费；AI 代理、MCP 服务器、批量导入导出等为付费订阅功能。

  • 支持 70+ 数据库，通过原生 Rust 驱动、PG/MySQL 线协议兼容、JDBC 桥接和 HTTP 桥接四种适配策略实现连接
  • 内置 AI 代理：自然语言生成 SQL、SQL 优化、执行计划可视化与错误修复，支持 OpenAI、Anthropic、DeepSeek、Ollama（自带密钥）
  • 基于 Tauri v2（Rust）与 Monaco 编辑器，提供多标签编辑、模式树浏览、DDL 查看和 CSV/JSON/Markdown 结果导出

适用场景（解读层）

  • 在 macOS、Windows 或 Linux 桌面环境中统一管理多种数据库连接与 SQL 操作
  • 在支持引擎之间迁移数据（如 PostgreSQL 到 ClickHouse、MySQL 到 BigQuery），含自动类型映射（付费功能）
  • 通过自然语言驱动代理完成查询编写、SQL 优化与执行计划分析（自带 LLM 密钥或本地 Ollama）
