基于 Meltano Singer SDK 构建的 PostgreSQL Singer Tap 数据抽取工具

综述（解读层）

tap-postgres 是一个用于从 PostgreSQL 数据库读取数据的 Singer tap，由 MeltanoLabs 维护，基于 Meltano Singer SDK 构建。它支持 FULL_TABLE、INCREMENTAL 和 LOG_BASED 三种复制方式，提供 SSL、SSH 隧道连接及 schema 过滤、stream maps、schema 扁平化等配置能力，可独立运行或在 Meltano 管道中使用，适用于需要按 Singer 规范抽取 Postgres 数据的数据工程流程。

  • 支持 FULL_TABLE、INCREMENTAL、LOG_BASED 三种复制方式，可通过 catalog 条目覆盖默认选择
  • 提供 SSL 验证与客户端证书认证配置，并支持经 SSH 隧道（bastion）连接非公开访问的数据库
  • 包含 catalog、state、discover、stream-maps、schema-flattening 等 Singer 能力，可用 sqlalchemy_url 或分项参数配置连接

适用场景（解读层）

  • 按 Singer 规范将 PostgreSQL 数据接入 Meltano 等编排工具的数据管道
  • 通过逻辑复制槽（LOG_BASED）或增量方式持续同步数据库表数据
  • 需要经 SSH 隧道或 SSL 连接内网 Postgres 实例进行数据抽取
