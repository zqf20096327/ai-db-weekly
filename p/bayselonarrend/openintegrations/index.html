面向1C/OneScript与CLI的多服务API集成工具库

综述（解读层）

OpenIntegrations 是一组用于调用外部 API 的开源工具，以 1C:Enterprise 扩展、OneScript 包和跨平台 CLI 应用（Windows/Linux）形式提供，覆盖 Telegram、VK、Bitrix24、Google/Yandex 服务、S3、PostgreSQL 等 30 余种服务。代码按服务拆分为独立模块，公共逻辑（HTTP、JSON）复用；1C 兼容模式为 8.3.10，不依赖 БСП，支持直接复制模块代码使用。

  • 以 1C 扩展、OneScript ospx 包和 Windows/Linux CLI（exe/rpm/deb）三种形态分发，同一功能可在库调用或 oint 命令行中使用
  • 覆盖 30 余种服务与协议的现成方法，包括消息发送、文档创建、SQL 查询，及 SFTP、SSH、WebSocket、gRPC、ZeroMQ 等
  • 源代码按服务划分模块，HTTP/JSON 等公共逻辑为可复用组件，文档站 openintegrations.dev 提供方法级示例，CLI 内置 --help 帮助

适用场景（解读层）

  • 在 1C:Enterprise 或 OneScript 项目中调用 Telegram、Bitrix24、Notion、Google Sheets 等外部服务的 REST API
  • 通过 oint 命令行在 bash/PowerShell 脚本中执行消息发送、文件上传、SQL 查询等操作
  • 对 PostgreSQL、MySQL、SQLite、MS SQL、ClickHouse、MongoDB 等数据库执行查询以及 S3 对象存储读写
