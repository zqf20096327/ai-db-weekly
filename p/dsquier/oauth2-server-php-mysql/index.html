为 oauth2-server-php 提供 PDO 存储的 MySQL 建库 DDL 脚本

综述（解读层）

该项目包含用于创建 oauth 数据库及 9 张相关表的 DDL 脚本，为 bshaffer/oauth2-server-php 库的 PDO 存储接口提供 MySQL 数据结构。使用者通过 source 命令执行 oauth.ddl 建库，已有 oauth 库会先备份为 oauth_backup 再重建；另提供 test-data.sql 用于单元测试和授权类型示例，README 说明其不应在生产环境运行，并附有 1.8 版本前 scope 问题的处理说明。

  • 提供 oauth_access_tokens、oauth_clients、oauth_scopes 等 9 张表的 DDL 定义
  • 重建前自动将已有 oauth 数据库备份为 oauth_backup
  • 附带 test-data.sql 测试数据，用于 PDO 接口单元测试与授权类型示例

适用场景（解读层）

  • 为基于 oauth2-server-php 的 PHP 应用搭建 MySQL OAuth2 存储层
  • 为 PDO 存储接口执行单元测试准备测试数据
  • 排查 pre-1.8 版本库中 scope 权限相关的行为问题
