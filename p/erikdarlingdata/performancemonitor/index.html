🧭 简介解读层（AI·证据行可回查）

SQL Server 与 PostgreSQL 的开源性能监控工具，含采集器、实时告警与 MCP 服务器。

综述（解读层）

PerformanceMonitor 是 MIT 许可的数据库性能监控工具，分两个版本：Lite 为桌面应用，数据存于本地 DuckDB 与 Parquet 文件，不在被监控服务器上安装组件；Darling 为运行于 Windows/Linux 的常驻服务，7×24 采集写入中央 PostgreSQL 存储，提供桌面查看器与 Web 仪表盘。它内置 MCP 服务器供 AI 分析，支持 SQL Server 2016 SP2–2025、Azure SQL、AWS RDS 及 PostgreSQL 14–18。注意 3.4.0 之前版本用 Setup.exe 升级会删除安装目录内数据。

  • 提供专业采集器、实时告警与图形化执行计划查看器
  • 内置 MCP 服务器，可将告警交给你自运行的 AI 代理处理，且每项代理能力可按服务器单独开关
  • Lite 以本地 DuckDB/Parquet 存储数据，数据保留在本地

适用场景（解读层）

  • 需要在不安装服务端组件的前提下远程监控 SQL Server 实例的桌面场景
  • 需要 7×24 采集并集中存储、多席位查看的团队环境
  • 希望把告警交给自有 AI 代理做分析或受限处置操作的 DBA 团队
