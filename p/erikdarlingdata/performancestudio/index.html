跨平台 SQL Server 执行计划分析器，含 GUI、CLI 与内置 MCP 服务器

综述（解读层）

Performance Studio 是一个 MIT 许可的 SQL Server 执行计划分析工具，解析 .sqlplan XML 并依据约 30 条规则检测内存授予过大、行数估算偏差、缺失索引、TempDB 溢出等问题。面向开发者和 DBA，提供 Avalonia 跨平台桌面 GUI 与 dotnet tool 形式的 CLI（planview 命令），预编译二进制无需 .NET SDK；文件分析可离线进行，仅实时抓取计划需连接 SQL Server。

  • 内置 MCP 服务器，可由 AI 客户端调用以分析已加载的计划、识别警告、建议索引和比较计划；支持可选的 GCF 紧凑输出格式以减少 token 消耗
  • 提供 GUI 查询编辑器、图形化计划树、多语句导航、计划对比（按指标计算退步/提升的增量）、Query Store 集成与迷你地图导航
  • CLI 以 .NET tool 形式发布于 nuget.org，支持 JSON/紧凑输出、.env 凭据文件、OS 凭据存储、目录批量处理及 CI 中固定版本安装

适用场景（解读层）

  • 在命令行或 CI 流水线中离线批量分析 .sqlplan 文件并生成结构化（JSON）结果
  • 连接 SQL Server 实例执行查询并捕获实际执行计划，或从 Query Store 拉取高开销查询的计划进行分析
  • 通过 MCP 服务器在 Claude Code 等 AI 客户端中辅助审阅执行计划
