综述（解读层）

Warpgate 是一个部署在 DMZ/堡垒机上的代理服务，接受 SSH、HTTPS、Kubernetes、MySQL、PostgreSQL、RDP 和 VNC 连接，在本地认证用户后将连接转发至目标主机，对客户端透明。管理员通过内置 Web UI 管理用户与目标并分配权限，会话记录存于 SQLite，支持实时查看与回放。以单个 Rust 二进制发布，无依赖。

  • 支持 SSH、HTTPS、Kubernetes、MySQL、PostgreSQL、RDP、VNC 协议的连接转发，无需客户端安装额外软件
  • 内置管理 Web UI，提供会话录制、实时会话查看、回放及用户-目标权限分配
  • 原生支持 2FA（TOTP）与 SSO（OpenID Connect），并内置暴力破解防护（IP 封锁与用户锁定）

适用场景（解读层）

  • 在 DMZ 中部署堡垒机，按用户精确分配内网主机与 URL 访问权限
  • 需要会话录制与审计回放的运维访问场景
  • 通过浏览器访问 SSH/RDP/VNC 目标，或为非交互式连接提供透明代理
