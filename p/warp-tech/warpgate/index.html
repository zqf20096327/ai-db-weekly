透明代理型堡垒机，支持 SSH/HTTPS/K8s/数据库/RDP/VNC 且免客户端

综述（解读层）

Warpgate 是部署在 DMZ 的堡垒机服务，接收 SSH、HTTPS、Kubernetes、MySQL、PostgreSQL、RDP 与 VNC 连接，本地认证后将连接转发至目标主机，可录制会话并通过内置 Web 管理界面实时查看与回放。适合需要管理内网主机访问权限的运维团队。以单个无依赖二进制发行，`warpgate setup` 生成交互式配置；用户与目标的授权关系及会话历史存储于 SQLite，支持 TOTP 与 OpenID Connect 的 2FA/SSO，内置 IP 封禁与账户锁定的防暴力破解机制。

  • 以单二进制部署，接收 SSH、HTTPS、Kubernetes、MySQL、PostgreSQL、RDP、VNC 连接并转发至目标，对客户端透明
  • 内置管理 Web UI，支持用户与目标绑定、会话录制、实时会话查看与回放，数据存于 SQLite
  • 原生支持 TOTP 与 OpenID Connect 的 2FA/SSO，内置 IP 封禁与用户锁定的防暴力破解机制

适用场景（解读层）

  • 在 DMZ 部署堡垒机，将用户精确指派到内网特定主机与 URL
  • 通过浏览器访问 SSH、RDP、VNC 目标，或录制会话用于事后审计回放
  • 需要临时访问凭证（Tickets）或 SSO 单点登录接入的内网访问管理
