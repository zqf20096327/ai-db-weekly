IDA Pro 9.x 插件，将 PE 二进制上下文提取为 SQLite 与 C++ 文件供 AI 代理使用

综述（解读层）

DeepExtract 是面向 IDA Pro 9.x 的插件，用于把 PE 二进制（.exe/.dll/.sys）的结构化上下文导出为 SQLite 数据库（含 file_info、functions、function_xrefs 三张表）、可选的 C++ 源文件、汇编及 JSON 元数据，供 Claude Code、Codex、Cursor 等 AI 编码代理读取与推理。它支持 headless 批量模式与 IDA GUI 交互模式，需 IDA Pro 与 Hex-Rays 反编译器（缺许可证时函数将排除出 C++ 输出）。安装方式为 hcli plugin install DeepExtract。

  • 提取文件级元数据（PE 头、导入导出、安全特性、Rich header、TLS 回调、.NET CLR 元数据等 30+ 项）与函数级分析（反汇编、反编译代码、交叉引用、480+ 危险 API 匹配、栈帧、循环、vtable 与间接调用解析）
  • 每个二进制生成含三张表的 SQLite 数据库，支持 SQL 调用图查询；可选生成按类与模块分组的 C++ 文件、.asm 汇编文件及 function_index.json、module_profile.json 等 JSON 元数据
  • 提供 headless 批量处理与 IDA GUI 交互（Ctrl-Shift-E）两种运行模式

适用场景（解读层）

  • AI 辅助漏洞研究与逆向工程：让编码代理像阅读源码仓库一样读取 PE 二进制
  • 批量提取大型二进制数据集（如系统目录下的 DLL）到结构化数据库供程序化查询
  • 在 IDA 中对单个二进制做目标性分析并生成报告（file_info.md）
