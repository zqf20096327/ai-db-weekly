综述（解读层）

Group-Co是基于Swoole异步特性与PHP Generator实现的PHP服务化框架，分为协程客户端（BFF）与服务端两部分，服务端以多进程模式提供RPC调用。面向需要将原生PHP项目转向微服务化的开发者，使用yield触发协程切换，以Zookeeper、Redis或Mysql作为注册中心实现服务治理。要求PHP版本不低于7.0，服务间通过protobuf编码传输数据。

  • 提供基于协程的异步TCP、HTTP、WebSocket、Redis、Mysql客户端及异步日志与文件读写
  • 实现以Zookeeper、Redis、Mysql为注册中心的服务化治理，包含服务发现、心跳检测与服务监听
  • 支持Tcp、Mysql、Redis、WebSocket连接池，并封装RPC通信与服务调用失败事件、监控等机制

适用场景（解读层）

  • 原生PHP项目转向微服务化（SOA）架构
  • API、Http Server、Rpc Server类服务的开发
  • 需要异步IO与连接池的场景，如秒杀系统、日志分析服务
📖 README 首段存档原文 · 程序抽取

- 不在支持php5.6以下版本。php>=7.0 - 基础服务之间的依赖与通信松耦合(写业务时要考虑到事务的处理) - 数据传输通过protobuf编码，所以基础服务层编码规范要严格定义数据类型 - 将基础服务拆分了，单独分离了接口(API interface)与ServiceImpl。
