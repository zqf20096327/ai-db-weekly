🧭 简介解读层（AI·证据行可回查）

本地运行的 Go 语言代理记忆 CLI，提供向量与 BM25 混合检索。

综述（解读层）

Mnemoteca 是一个用 Go 编写的本地文档存储与检索 CLI，通过 SQLite 存储、sqlite-vec 向量检索与 FTS5 BM25 混合搜索来保存和召回代理记忆，嵌入与可选重排序均用 ONNX Runtime 在本地推理，无需云 API。面向需要为多个 AI 助手提供共享记忆的用户，支持 JSONL 导入导出与 BEIR/LongMemEval 基准工具。

  • SQLite 存储，支持向量（sqlite-vec 余弦相似度）与 BM25 词法混合检索，可选本地交叉编码器重排序
  • 嵌入与重排序模型通过 ONNX Runtime 本地运行，setup 命令自动下载 ONNX Runtime 与默认模型
  • 提供 JSONL 导出/导入、三种搜索输出格式（color/plain/json），并为 Claude Code、OpenCode 等提供共享集合的集成插件

适用场景（解读层）

  • 为多个 AI 代理或 IDE 提供跨工具共享的本地长期记忆
  • 无法访问云 API 或需离线运行的环境中的语义检索
  • 构建检索评测流程：JSON 输出映射外部语料 ID，并运行 BEIR SciFact / LongMemEval 基准
