综述（解读层）

PAXM 是用 Go 编写的记忆适配层，为 Codex、Claude Code、OpenCode、Pi 等 Agent 及 MCP 客户端提供跨会话的记忆读写。它通过 CLI、MCP、skills 提供主动记忆，通过生命周期钩子实现被动召回与回合捕获；默认使用本地 SQLite（FTS5/BM25 检索），无需账号或 API key，也可切换到 Zep、Mem0、MemOS 等远程提供商或经 JSON-RPC 接入私有提供商。被动写入经本地持久化队列投递，召回有默认 800ms 总预算。

  • 提供主动（CLI/MCP/skill）与被动（Agent 生命周期钩子）两条记忆路径，同一运行时与提供商路由
  • 默认 SQLite 提供商使用 FTS5 与 BM25 检索，记忆摄取和召回不调用外部 LLM 或嵌入服务
  • 被动写入先提交到本地持久化队列再交付提供商，召回默认 800ms 总预算、250ms 单提供商预算

适用场景（解读层）

  • 让新会话恢复项目决策、约定与工作上下文，避免重复向 Agent 说明
  • 在多个 Agent（Codex、Claude Code、OpenCode、Pi、MCP 客户端）间共享同一条记忆路径
  • 无账号环境下以本地 SQLite 快速搭建记忆层，后续按需更换提供商
