内置数据库 JDBC 驱动的 Liquibase Docker 镜像，用于执行数据库变更

综述（解读层）

该项目提供运行 Liquibase 的 Docker 镜像。由于 Liquibase 本身无法直接连接数据库，需要 JDBC 驱动，仓库另提供捆绑 Postgres、MySQL、MariaDB、SQLite 驱动的衍生镜像。使用时通过环境变量配置连接信息，entrypoint 自动生成 liquibase.properties；changelog 可通过 COPY 进镜像或挂载卷两种方式提供，文件型数据库 SQLite 不适用部分连接变量。

  • 提供捆绑 Postgres、MySQL、MariaDB、SQLite JDBC 驱动的多个 Docker 镜像变体
  • entrypoint 依据 LIQUIBASE_HOST/PORT/DATABASE/USERNAME/PASSWORD 等环境变量自动生成 liquibase.properties
  • 支持通过继承 Dockerfile 构建或直接挂载 docker volume 两种方式使用，并支持 ${VAR} 变量替换

适用场景（解读层）

  • 在容器化环境中对数据库执行 Liquibase changelog 变更（如 updateTestingRollback 命令）
  • CI/CD 或本地流程中以挂载 changelog 目录的方式直接运行，无需自建镜像
  • 需要为不同数据库捆绑对应 JDBC 驱动的场景，选择对应的衍生镜像使用
