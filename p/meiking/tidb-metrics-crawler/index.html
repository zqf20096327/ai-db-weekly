🧭 简介解读层（AI·证据行可回查）

从 Prometheus 实例抓取 TiDB 指标并导出到 CSV、MySQL 或飞书的 Go 工具

综述（解读层）

tidb-metrics-crawler 是一个用 Go 编写的命令行工具，用于从多个 Prometheus 实例抓取 TiDB 相关指标数据，并写入 CSV 文件、MySQL 数据库或发送到飞书消息。抓取按小时分批以避免超时，失败请求采用指数退避重试。使用 YAML 配置文件并可由命令行参数覆盖，支持指定起止时间与步长。MIT 许可证。

  • 支持同时连接多个 Prometheus 实例抓取指标
  • 自动将时间范围按小时分批抓取，失败请求带 5 次指数退避重试
  • 输出目标包含 CSV、MySQL（可自动建表）和带附件的飞书消息

适用场景（解读层）

  • 定期拉取 TiDB 的 Prometheus 指标并归档到 MySQL 便于后续查询分析
  • 将指定时间范围的指标导出为 CSV 用于离线处理
  • 通过飞书消息附带文件分发指标数据
