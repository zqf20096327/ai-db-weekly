面向 bun:sqlite 的 TypeScript ORM 库，提供类型化表操作接口

综述（解读层）

BunORM 是一个运行于 Bun、基于 bun:sqlite 的同步 ORM 库，使用 TypeScript 编写且无依赖。使用者通过配置对象定义表结构后，可经 db.tables 调用 find 等方法操作数据。README 自述该包仍处早期阶段，多种关系类型与批量操作等能力尚未实现。

  • 提供自定义数据类型（如 JSON）、中间件（get/set）、表间关系及自动 Id/createdAt/updatedAt 属性
  • 接口设计参考 TypeORM，通过 db.tables.[table] 的方式访问和查询数据
  • 无依赖的小型包，可通过 bun install 安装稳定版或 GitHub 开发版

适用场景（解读层）

  • 在 Bun 运行时中使用 bun:sqlite 的 TypeScript 项目
  • 需要带类型支持的 SQLite 表定义与查询的场景
  • 希望自定义或修改源码的开发者（可克隆仓库修改并本地构建安装）
