🧭 简介解读层（AI·证据行可回查）

本地优先的 Windows 桌面监控套件，覆盖网站、协议与远程 Linux VPS

综述（解读层）

Surf Monitor 是运行于 Windows 桌面的本地监控套件，基于 Electron 33、React 18 与 SQLite 存储。它支持 HTTP 多方法、SSL 证书、DNS、TCP、ICMP 等多协议健康检查（三态分类 UP/DEGRADED/DOWN），并通过 SSH 隧道连接远端 Linux VPS 上的 localhost agent，采集服务器、Docker、systemd 与 PM2 指标。数据本地存储，无需外部账号。

  • 多协议检查：HTTP/HTTPS 各方法、SSL 证书到期、DNS、TCP 端口、ICMP ping、关键词匹配、心跳接收与 RDAP 域名到期
  • 远程 Linux 监控：agent 绑定 127.0.0.1 经 SSH forwardOut 隧道通信，支持 Docker、systemd 及多用户 PM2 进程指标与受控启停
  • 通知渠道含 Discord/Telegram/Webhook/Windows 桌面通知/SMTP，凭据经 Electron safeStorage 加密存储

适用场景（解读层）

  • 在本地桌面集中监控多个网站的可用性、证书有效期与内容变更
  • 通过 SSH 管理 Linux VPS 的系统资源、Docker 容器与 PM2 进程状态
  • 配置维护窗口与服务依赖图，依赖 Discord/Telegram/邮件等渠道接收告警
