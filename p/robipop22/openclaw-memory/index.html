🧭 简介解读层（AI·证据行可回查）

AI 智能体三层记忆服务：SQLite 缓存、Qdrant 语义搜索与 Postgres/AGE 知识图谱

综述（解读层）

openclaw-memory 是一个 TypeScript/Bun 编写的独立记忆服务，为 AI 智能体提供三层存储：SQLite 本地查找、Qdrant 向量语义搜索、PostgreSQL+Apache AGE 知识图谱，通过统一 API 或 HTTP 服务访问。Lite 模式零外部依赖即可启动，分层可升级且 API 不变；层宕机时写入回退 SQLite 并经同步队列重试。适合本地运行智能体到多智能体系统的场景。

  • 三级分层模式（Lite/Standard/Full），从仅 SQLite 起步，升级层级无需更改代码，API 保持一致
  • 支持语义向量搜索（Qdrant）、SQLite FTS 全文搜索和 Apache AGE 图遍历，并提供自动选择层的 smart search 端点
  • 运行时某存储层故障时自动降级：写入 SQLite 并将失败同步放入队列自动重试

适用场景（解读层）

  • 本地 CLI 工具或原型智能体的会话间记忆持久化（Lite 模式，零外部依赖）
  • 生产环境智能体需要按含义而非关键词检索记忆（Standard 模式，SQLite+Qdrant）
  • 多智能体系统中按 agentId/scope 隔离或共享记忆，并对存储内容做实体关系抽取与图遍历（Full 模式）
