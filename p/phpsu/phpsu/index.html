🧭 简介解读层（AI·证据行可回查）

Phpsu 是一个 PHP 编写的文件与数据库同步工具，基于 rsync 与 mysqldump 实现同步。

综述（解读层）

Phpsu 是一个用于在系统之间同步文件与 MySQL 数据库的 PHP 命令行工具，例如将生产环境数据同步到测试环境。它通过 SSH、rsync 和 mysqldump 执行同步，使用 phpsu-config.php 配置源与目标。要求 PHP 8.1-8.3，依赖 bash、ssh、rsync、mysql 客户端工具，暂不支持 Windows。

  • 通过 Composer 安装为开发依赖，也提供 phpsu/phpsu Docker 镜像运行方式
  • 支持 --dry-run、--no-db、--no-fs 等选项，可分别控制文件与数据库同步
  • 提供 phpsu-config.php 配置文件定义同步的源与目标环境

适用场景（解读层）

  • 开发或测试环境需要从生产环境拉取数据库与文件副本时
  • 需要在多台服务器之间通过 SSH 同步文件与 MySQL 数据的场景
  • 希望在 Docker 容器中执行同步命令而不本地安装依赖的场景
