🧭 简介解读层（AI·证据行可回查）

本地 Zero 同步开发服务器，以 WASM 方式运行 PGlite/SQLite，免配置启动

综述（解读层）

orez 是一个开发用服务器，将 Rocicorp Zero 与 PGlite（WASM 版 Postgres）、bedrock-sqlite（WASM 版 SQLite）打包，通过 bunx orez 即可启动，无需安装 Postgres、Docker 或编译本地依赖。面向使用 Zero 同步框架的本地开发者。它提供 pg_proxy、零缓存管理面板、pg_dump 恢复等能力；README 明确 Node 运行器仅限开发用途，单会话 pglite 后端经互斥锁串行化查询，不适用于生产。

  • 提供 pglite（默认）与 postgres（嵌入式真实 Postgres）两种后端，通过 --backend 或配置文件切换
  • 内置管理面板（默认 localhost:6477），包含日志流、HTTP 请求检查、重启/重置操作
  • 提供 onDbReady/onHealthy 生命周期钩子与 startZeroLite 编程 API，钩子命令可接收 DATABASE_URL 等环境变量

适用场景（解读层）

  • 在本地以零原生依赖方式运行 Zero Sync 开发环境
  • 通过 pg_dump/pg_restore 将生产数据恢复到本地开发库
  • 使用 limesync/cloudflare 在 Cloudflare Workers 上部署 SQLite 原生的 Zero 服务端
