基于 Pydantic 模型与 Rust 引擎构建 SQL 的 Python 异步 ORM

综述（解读层）

Ferro 是一个 Python 异步 ORM：用户声明 Pydantic v2 模型，内置 Rust 引擎负责生成 SQL、执行查询并将行转换为模型实例。面向需要异步数据库访问的 Python 开发者。引擎基于 pyo3-async-runtimes 与 SQLx，在 GIL 之外生成 SQL 和解析行；运行时依赖为 Pydantic 和 pydantic-settings。支持 SQLite 和 PostgreSQL，驱动编译进引擎，无需额外驱动包。auto_migrate 适合开发与测试环境，生产环境需使用迁移 CLI。

  • 声明 Pydantic v2 模型，Rust 引擎生成 SQL、执行查询并填充模型实例，全过程为异步实现
  • 支持 SQLite 与 PostgreSQL，驱动编译进引擎；会话内通过 identity map 保证一行对应一个 Python 对象
  • 提供迁移 CLI（ferro migrate）与 Alembic 桥接，支持多数据库命名连接

适用场景（解读层）

  • 使用 Pydantic v2 与 asyncio 的 Python 应用中访问 SQLite 或 PostgreSQL
  • 需要异步 ORM 且希望减少额外数据库驱动包依赖的项目
  • 开发阶段用 auto_migrate、生产阶段用迁移文件管理表结构变更的团队流程
📖 README 首段存档原文 · 程序抽取

Ferro is an async ORM for Python: you declare Pydantic models, and a Rust engine builds the SQL, runs it and turns rows into model instances. Its runtime dependencies are Pydantic and pydantic-setting
