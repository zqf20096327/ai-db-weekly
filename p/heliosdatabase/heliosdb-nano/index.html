综述（解读层）

HeliosDB Nano 是一个 Rust 编写的内嵌式 SQL 数据库，提供单个自包含二进制（Linux x86_64 约 53 MB），可作为 Rust 库嵌入或以服务器方式运行。它实现 PostgreSQL 与 MySQL 线协议，支持 HNSW 向量索引、BM25 全文检索、git 式分支与时间旅行查询、AES-256-GCM 静态加密，以及内置 Auth/REST/Realtime 的 BaaS 层。README 标注其定位面向 local-first 应用、AI 记忆、边缘分析与开发者工作流。限制包括：Linux 二进制要求 glibc ≥ 2.39；MySQL 监听器尚不校验密码；未提供 WASM/浏览器版本；官方对比表自述其生态尚处于 young 阶段。

  • 单二进制集成 SQL、HNSW 向量检索（<->、<#>、<=>）与 BM25 全文检索，支持向全文混合查询
  • 实现 PostgreSQL 与 MySQL 线协议，psql、psycopg2、node-postgres、JDBC、Prisma、SQLAlchemy 等客户端可直接连接，并支持 SQLite 文件一次性导入
  • 提供 git 式数据库分支、AS OF TIMESTAMP 时间旅行查询、只读物理备库复制（含提升与计划切换）、可选 AES-256-GCM 加密、SCRAM 认证与 TLS，以及构建期可选的代码图索引、graph-RAG 与 MCP 服务器功能

适用场景（解读层）

  • local-first 应用：以单文件后端进程对接现有 Postgres/MySQL 客户端
  • AI 智能体记忆存储：将向量、全文检索与分支置于同一存储，可选启用 MCP 服务器
  • 边缘/IoT 与多租户托管：无需外部服务的自包含二进制，内置多租户支持
