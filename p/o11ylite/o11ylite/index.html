基于 DuckDB 与 SQLite 的单进程开源 OpenTelemetry 后端

综述（解读层）

O11yLite 是一个开源的 OpenTelemetry 后端，通过 OTLP/gRPC 和 OTLP/HTTP 接收 traces、logs、metrics，单容器内完成采集、存储、查询与 UI。遥测数据以 Parquet 文件经 DuckDB/DuckLake 存储，新字段自动变为可查询列。提供告警规则、Notebooks、内置 MCP 服务器供 LLM agent 使用。采用 AGPL-3.0 许可，面向小型至上中规模团队。

  • 通过 OTLP/gRPC 与 OTLP/HTTP 摄取 traces、logs、metrics，单容器运行摄取、存储、查询和 UI
  • 遥测数据以 Parquet 文件存储（DuckDB + DuckLake），新字段自动演化为可查询列
  • 内置 MCP 服务器（含 OAuth）、Alertmanager 兼容告警通知、Notebooks 与查询构建器/trace 瀑布视图

适用场景（解读层）

  • 通过 docker run 一条命令部署本地或小团队可观测性后端
  • 从 Kubernetes 集群收集 logs、traces 和 metrics（文档提供 Helm chart 与 OpenTelemetry 配置指引）
  • 让 LLM agent 通过 MCP 查询遥测数据、管理告警和编辑 notebooks
