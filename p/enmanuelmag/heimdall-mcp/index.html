MCP 透明代理，拦截 JSON-RPC 并生成 OpenTelemetry 追踪

综述（解读层）

该项目是一个位于 MCP 客户端与服务器之间的透明代理，拦截全部 JSON-RPC 消息，为每对请求/响应生成含时序与输入输出的 OTel span，并持久化到 SQLite、Postgres 或 MySQL。它面向使用 Claude Desktop、Cursor 等 MCP 客户端的用户，无需修改原服务器即可运行，支持按服务器配置工具/提示/资源的允许与拒绝策略。没有配置文件时代理保持完全透明；追踪存储与锁存储可通过 --store 与 --lock-store 参数分别指定。

  • 拦截所有 JSON-RPC 消息并将每对请求/响应转换为含时序、属性与输入/输出内容的 OpenTelemetry span
  • 支持通过本地或全局配置文件定义每服务器的工具/提示/资源允许与拒绝策略，含参数级约束与路径包含检查
  • 提供基于工具参数的互斥资源锁（TTL 兜底），锁存储支持本地 SQLite 及 Postgres/MySQL 跨实例协调

适用场景（解读层）

  • 为经由代理的 MCP 调用建立可查询的追踪与延迟记录
  • 在不修改 MCP 服务器代码的前提下按项目或组织粒度限制代理可调用的工具与参数取值范围
  • 多个 AI 代理并发操作同一资源（如同名文件写入、数据库迁移工具）时通过锁序列化调用
