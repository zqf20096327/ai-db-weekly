🧭 简介解读层（AI·证据行可回查）

MailScanner 的 PHP/MySQL Web 前端，记录并展示邮件处理数据

综述（解读层）

MailWatch for MailScanner 是 MailScanner 的 Web 前端，用 PHP 编写，数据存于 MySQL。其 CustomConfig 模块让 MailScanner 将邮件元数据（不含正文）写入数据库，供报告与统计查询。面向 MailScanner 邮件网关管理员，支持多用户级别与 XML-RPC 多节点整合；要求 MySQL 5.7+/MariaDB、PHP 5.6–8。

  • CustomConfig 模块将邮件数据（不含正文）写入 MySQL，供报告与统计查询
  • 提供隔离区管理，可释放、删除隔离邮件或对其运行 sa-learn
  • 支持 user/domain/admin 三级用户权限及 XML-RPC 多安装点协同

适用场景（解读层）

  • 查看进出邮件队列、垃圾邮件、病毒与拦截内容的统计报表
  • 管理隔离邮件并对其进行释放或 SpamAssassin 学习
  • 集中监控多台 MailScanner/MailWatch 安装
