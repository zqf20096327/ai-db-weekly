基于多模式版本并存机制的 PostgreSQL 无停机模式迁移命令行工具

综述（解读层）

pgroll 是 Xata 开源的 Go 语言命令行工具，用于 PostgreSQL 的可回滚模式迁移。它通过在物理表上创建视图实现多个模式版本同时可用，迁移期间通过触发器同步新旧列的写入，支持自动回填列数据。需 Postgres 14.0 及以上版本，适用于需要对已上线的数据库执行不中断服务变更的团队。

  • 迁移期间新旧模式版本同时可用，客户端通过设置 search_path 切换版本
  • 提供 complete 与 rollback 命令，迁移过程中可随时回退到前一版本
  • 单二进制文件运行，无外部依赖，支持 Postgres 14.0 及以上版本与 RDS/Aurora 等服务

适用场景（解读层）

  • 对已在生产环境中运行的 PostgreSQL 数据库执行加列、建表等模式变更且不中断客户端服务
  • 客户端应用需要按版本逐步切换到新 schema 的发布流程
  • 对已有数据库通过 baseline 命令导入现有结构后纳入迁移管理
