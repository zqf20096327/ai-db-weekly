基于 Kubernetes 的开源 Postgres 平台，提供存储级写时复制分支与缩容到零。

综述（解读层）

Xata 是一个用于在 Kubernetes 上自托管大量 Postgres 实例的开源平台，底层使用 CloudNativePG operator，之上增加 SQL 网关、分支 operator、控制平面服务、Keycloak 认证和 CLI。它支持基于写时复制的快速分支、闲置休眠的 scale-to-zero、高可用与 PITR 备份，官方注明面向内部 PGaaS 和开发测试环境，不适用于单实例部署或面向外部用户的多租户服务。

  • 支持存储级写时复制分支，可在数秒内复制 TB 级数据
  • 支持 scale-to-zero：闲置时移除计算实例，有连接时自动恢复
  • 基于 CloudNativePG 提供高可用、自动故障转移、PITR 备份及 REST API 与 CLI 管理控制平面操作

适用场景（解读层）

  • 企业内部搭建自托管的 Postgres-as-a-Service
  • 创建预览、测试和开发环境的 Postgres 分支副本
  • 在 Kubernetes 上批量管理多个 Postgres 实例并按需自动伸缩
