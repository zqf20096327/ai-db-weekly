用于用 Zig 语言开发 PostgreSQL 扩展的库

综述（解读层）

pgzx 是一个用 Zig 编写 PostgreSQL 扩展的开发库，提供错误处理包装、基于 Postgres 内存上下文的 Zig 分配器、函数注册（PG_FUNCTION_V1）与测试工具，并附 Nix flake 开发环境模板。README 提示开发者仍需了解 Postgres 内部机制，且部分 C 宏无法自动翻译，需借助 pgzx 提供的模块。

  • 提供 elog 日志与错误报告包装，并用 err.wrap 模拟 PG_TRY/CATCH 语义以配合 Zig 的 defer/errdefer
  • 提供包装 Postgres 内存上下文的 Zig 分配器 createAllocSetContext，并支持上下文重置/销毁回调
  • 支持通过 PG_FUNCTION_V1 注册 SQL 可调用函数并自动反序列化参数；提供 pg_regress 与在 Postgres 实例内运行的单元测试

适用场景（解读层）

  • 用 Zig 编写可注册到 PostgreSQL 的新函数或钩子回调（如审计类扩展）
  • 参考 char_count_zig、pghostname_zig、pg_audit_zig 等示例学习扩展开发
  • 需要复用 Postgres 内存上下文管理与 C ABI 互操作的系统级扩展开发
