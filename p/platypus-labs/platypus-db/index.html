Rust + Tauri 构建的桌面 SQL 客户端，支持多种数据库并内置 MCP 服务器

综述（解读层）

PlatypusDB 是一款面向开发者、DBA 和分析师的桌面 SQL 客户端，采用 Rust 核心 + Tauri 2 + React 界面，支持 PostgreSQL、MySQL、SQL Server、SQLite、DuckDB 等 20 种左右数据源。提供查询、数据编辑、表设计、执行计划、图表等功能；连接按类型着色区分，代理（AI agent）通过 MCP 访问时默认只读且需人工确认变更。采用 AGPL-3.0 许可，支持 Windows、macOS 和 Linux。

  • 支持 PostgreSQL、MySQL、Oracle、ClickHouse、DuckDB、MongoDB、Redis、Snowflake 等 20 种左右数据源，使用统一编辑器与结果网格
  • 提供连接类型着色、危险语句确认、生产连接手动提交、编辑保存生成撤销脚本等机制
  • 内置 MCP 服务器，Claude Code、Cursor 等 AI 代理可按只读或读写权限使用已保存连接，写入操作需在应用内确认

适用场景（解读层）

  • 日常需要切换多个数据库进行查询、浏览和编辑数据的开发与运维工作
  • 分析慢查询：使用 Explain Analyze 热图与索引建议定位执行计划中的耗时步骤
  • 让 AI 编码代理通过 MCP 只读访问已保存的数据库连接
