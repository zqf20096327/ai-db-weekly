pggen 是从 Postgres SQL 查询生成类型安全 Go 代码的命令行代码生成器

综述（解读层）

pggen 读取用户编写的 SQL 查询文件（带 :one/:many/:exec 注解），通过内省 Postgres 系统目录表获取参数与结果列的类型信息，生成强类型的 Go 查询方法，底层使用 pgx 驱动。它只生成查询所需的结构体，不生成全表模型；仅支持 Postgres，且代码生成阶段需要连接 Postgres 或 Docker。安装提供各平台预编译二进制，也可用 go install 从源码安装（需 Go 1.16）。

  • 通过 Postgres 目录表（pg_type、pg_class、pg_attribute）获取查询参数和结果列的类型信息，生成不依赖 interface{} 的强类型 Go 代码
  • 支持自定义类型映射（--go-type）、枚举映射为 Go 字符串常量、复合类型生成嵌套结构体、JSON struct 标签与首字母缩写配置
  • 为每个生成的查询提供基于 pgx.Batch 的批量（查询流水线）接口，并使用预编译查询执行 SQL

适用场景（解读层）

  • Go 项目中希望手写 SQL 并获得类型安全的查询执行代码
  • 使用 Postgres 扩展（如 ltree、pgcrypto）或自定义类型，需要为任意查询生成代码
  • 需要通过批量接口在单次网络往返中发送多条查询的场景
