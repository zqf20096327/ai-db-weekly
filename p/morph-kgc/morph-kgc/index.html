基于 R2RML/RML 映射语言从异构数据源构建 RDF 知识图谱的引擎

综述（解读层）

Morph-KGC 是一个使用 R2RML 和 RML 映射语言从异构数据源构建 RDF 知识图谱的引擎，基于 pandas 实现，通过映射分区机制降低大数据源执行时间和内存消耗。支持关系数据库、表格文件、JSON/XML、HTTP API 等多种输入，可作为命令行工具或 Python 库运行，并可与 RDFLib、Oxigraph 集成。采用 Apache 2.0 许可证。

  • 支持 R2RML、RML 1.2、YARRRML、RML-FNML（含 Python UDF）等映射语言
  • 输入支持关系数据库（MySQL、PostgreSQL、Oracle 等）、表格/层级文件、Python 数据结构、云数据湖、Neo4j 与 HTTP API
  • 通过映射分区机制减少大规模数据源物化的执行时间和内存消耗，可与 RDFLib、Oxigraph 集成

适用场景（解读层）

  • 将关系数据库或表格/JSON/XML 数据转换为 RDF 知识图谱
  • 需要 Python UDF 转换函数或基于 SPARQL 端点做实体对齐的数据集成流程
  • 作为 Python 库在数据处理管线中生成三元组并加载到 RDFLib 图中
