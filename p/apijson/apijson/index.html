🧭 简介解读层（AI·证据行可回查）

基于 JSON 的通信协议与 ORM 库，由客户端定制返回 JSON 自动生成接口

综述（解读层）

APIJSON 是一种基于 JSON 的网络传输协议和 ORM 库，客户端通过在请求 JSON 中声明所需数据来自动生成后端接口与文档，减少后端 API 编写工作。支持增删改查、模糊搜索、远程函数调用等。后端通过 Maven/Gradle 引入 JitPack 依赖使用，生态含 C#、Go、PHP、Node.js、Python、Rust 等多语言实现。

  • 支持 CRUD、模糊搜索、远程函数调用等操作
  • 客户端可在请求中自定义返回 JSON 的数据和结构
  • 提供 Maven/Gradle 依赖接入方式，并有 C#、Go、PHP、Node.js、Python、Rust 等多语言实现

适用场景（解读层）

  • 后端希望减少 API 设计与文档编写工作量的项目
  • 前端/客户端需要自定义返回数据结构和减少接口请求次数的场景
  • 需要接入多种数据库或向量/时序数据库的数据查询服务
