Socio 是基于 WebSocket 的实时通信 Web API 框架，实现前后端数据自动同步

综述（解读层）

Socio 在后端通过 SocioServer 建立 WebSocket 服务并可连接数据库，前端通过 SocioClient 编写 SQL 查询，资源变更时自动向所有客户端刷新；同时通过 Server Props 同步任意 JS 变量。SQL 字符串在前端源码中以 AES-256-GCM 加密保存，动态参数需开发者自行在服务端净化。支持 Node.js >= 16。

  • 提供 Query、Subscribe 接口执行 SQL，并提供 Prop、GetProp、SetProp、SubscribeProp 同步服务端 JS 变量到多客户端
  • 前端源码中的 SQL 字符串使用 AES-256-GCM 加密，可经 SocioSecurity 类或 Vite 插件 SocioSecurityVitePlugin 处理
  • 使用 @msgpack/msgpack 进行二进制序列化，消息传输基于 WebSocket（服务端使用 ws 库）

适用场景（解读层）

  • 需要前端直接编写 SQL 并在数据变更时自动刷新界面的实时应用
  • 多客户端间同步共享服务端状态变量的场景
  • 在已有 express.js 等 HTTP 服务上挂载 WebSocket 实时通道的项目
