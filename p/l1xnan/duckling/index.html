综述（解读层）

Duckling 是一款基于 Tauri 构建的桌面数据查看器，用于快速浏览 Parquet/CSV/JSON 文件和数据库数据，内置 SQL 编辑器、透视表、列统计和导出功能。原生支持 DuckDB 与 SQLite，MySQL/PostgreSQL/ClickHouse/Doris 为实验性支持。README 明确说明其定位不是完整的数据库管理工具，且项目处于活跃开发中的不稳定阶段。

  • 支持 DuckDB/SQLite 原生连接，提供 MySQL/PostgreSQL/ClickHouse/Doris 等实验性连接器
  • 内置 Monaco SQL 编辑器，支持 Jinja2 风格模板变量与多值批量执行（最多 50 组合）
  • 提供透视表、列画像、值查看器，结果可导出为 CSV/TSV/JSON/Parquet/XLSX

适用场景（解读层）

  • 直接打开 parquet/csv 文件或目录进行快速浏览与轻量分析
  • 连接多种数据库浏览表数据并运行 SQL 查询
  • 通过模板变量对多张表或多组参数批量执行同一 SQL
