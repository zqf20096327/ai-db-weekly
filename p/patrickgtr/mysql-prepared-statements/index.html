PAWN MySQL 插件的预处理语句库，用于绑定参数执行 SQL

综述（解读层）

这是一个面向 PAWN（SA-MP）环境的 MySQL 预处理语句封装库，通过 sampctl 安装并包含 <mysql_prepared> 头文件即可使用。它提供语句准备、参数绑定（字符串/整数/浮点/玩家名/IP）、结果读取以及线程化或并行执行等函数，README 还附带账号系统完整示例。适用于 SA-MP 服务器脚本开发者在 MySQL 插件基础上编写参数化查询。

  • 支持参数绑定：字符串、整数、浮点数，以及玩家名称和玩家 IP 的快捷绑定
  • 提供结果绑定读取函数，支持字符串、整数与浮点字段
  • 提供线程化、并行及 inline 回调（Func:callback<>）等多种执行方式

适用场景（解读层）

  • SA-MP 服务器脚本中执行带参数的 SQL 查询与写入操作
  • 使用参数占位符（?）方式编写账号系统等数据存取逻辑
  • 需要以线程化或并行方式执行预处理语句并回调结果处理
