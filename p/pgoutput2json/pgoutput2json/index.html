🧭 简介解读层（AI·证据行可回查）

基于 PostgreSQL 逻辑复制（pgoutput）将行级变更加工为 JSON 并推送的 .NET 库

综述（解读层）

PgOutput2Json 是一个 .NET 库，通过 PostgreSQL 内置的 pgoutput 插件连接复制槽，把 INSERT/UPDATE/DELETE 变更转为 JSON 消息，输出到 Kafka、RabbitMQ、Redis、MongoDB、ClickHouse 等，或经委托处理器直接交给 .NET 应用。它要求 PostgreSQL 14 及以上（Publication 行过滤器需 15+），投递语义为 at-least-once，消息携带 LSN 加序号的去重键，初始数据拷贝以类型 C 表示且无位置信息。

  • 使用 PostgreSQL 内置的 pgoutput 逻辑解码插件，无需额外安装解码扩展，支持 PostgreSQL 14 至 18
  • 提供 Kafka、RabbitMQ、Redis、MongoDB、SQLite、Amazon Kinesis、DynamoDB、ClickHouse、Azure Event Hubs 及 Webhook 等多种输出适配器，也可通过 .NET 委托在应用内直接处理消息
  • 消息以至少一次语义投递，每条消息包含事务 LSN 与事务内序号组成的去重键；支持 Compact 模式以数组形式输出列值并在 schema 属性中携带列名与类型信息

适用场景（解读层）

  • 对数据库插入/更新触发后台任务的近实时场景
  • 低延迟应用缓存更新、异步日志写入（文件或其他数据库）
  • 面向数据仓库的轻量级 ETL 与实时数据聚合
