面向 Kubernetes 的数据库治理框架，含控制面与 SQL 代理数据面

综述（解读层）

Pisanix 是面向 Kubernetes 环境的数据库治理框架，采用控制面加数据面架构：Pisa-Controller 负责边车注入与配置转换，Pisa-Proxy 用 Rust 实现 SQL 流量代理。应用通过 localhost:3306 访问数据库，无需感知真实数据源。当前已实现读写分离、分片、熔断、并发控制等 TrafficStrategy/DataStrategy 能力，部分功能如细粒度访问控制仍在开发中。

  • 提供本地数据库服务，应用可在 localhost:3306 访问 MySQL 而无需了解真实数据源
  • 支持读写分离、负载均衡、分片、熔断与并发控制等 SQL 流量治理策略
  • 插件机制支持 Lua 与 Wasm，可编程扩展数据库行为

适用场景（解读层）

  • 在 Kubernetes 中统一管理多个数据库的 SQL 流量治理
  • 需要读写分离或分片策略的 MySQL 应用接入
  • 通过 SQL 代理层实现审计、访问控制与可观测性采集
