🧭 简介解读层（AI·证据行可回查）

基于 MCP 协议的本地工作记忆服务器，用 SQLite 持久化 AI 会话上下文

综述（解读层）

Work Memory MCP 是一个实现 Model Context Protocol 的服务器，将多 AI 工具（如 Claude Desktop、Cursor AI）会话中的工作内容存入本地 SQLite 数据库，按项目、标签和重要度组织记忆，并提供会话管理、全文检索、版本历史与系统维护五组工具。安装需 Node.js 18+，克隆后经 npm install/build 启动，在客户端配置文件中注册即可使用。

  • 提供 Memory、Search、Session、History、System 五个 MCP 工具，覆盖记忆增删改查、关键词检索、会话创建与检测、版本恢复及数据库优化
  • 数据存储于本地 SQLite，包含 work_memories、sessions、work_memory_history、search_keywords 等表，并使用 16 个复合索引与 LRU 缓存（500 条/50MB，硬编码）
  • 记忆支持 0-100 重要度评分、标签分类、todo 分离与完成状态跟踪，历史工具可查询变更并还原先前版本

适用场景（解读层）

  • 在多个 AI 工具之间延续同一项目的上下文，无需在每次会话中重复说明已整理的信息
  • 按项目建立独立会话，管理待办事项与工作产出的结构化记忆库
  • 对本地存储的工作记录执行关键词检索、变更历史追溯与版本恢复
