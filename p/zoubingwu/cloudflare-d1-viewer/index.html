🧭 简介解读层（AI·证据行可回查）

在浏览器中查看 Cloudflare D1 数据库与本地 SQLite 文件的 Web 工具

综述（解读层）

该项目是一个 Web 应用，通过 Cloudflare API token 连接账号，查看账号下的 D1 数据库并浏览表数据，支持大结果集分页；也可在浏览器本地读取 SQLite 文件，无需 API token。适合需要在不离开浏览器的情况下查看 D1 数据的开发者。项目采用 MIT 许可，可部署到 Cloudflare Pages。

  • 通过 API token 连接 Cloudflare 账号，列出并浏览账号下的 D1 数据库及表，支持分页查看大结果集
  • 支持在浏览器本地读取 SQLite 数据库文件，全部操作在浏览器内完成
  • 可克隆仓库自行构建并部署到自己的 Cloudflare Pages 实例

适用场景（解读层）

  • 在浏览器中查看 Cloudflare D1 数据库的表结构和数据
  • 无需后端环境地在浏览器中查看本地 SQLite 文件内容
  • 将应用部署到自有 Cloudflare Pages 实例，避免使用托管站点的令牌存储方式
