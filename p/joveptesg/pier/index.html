自托管的单二进制 PaaS，用 Rust 实现，部署容器与 Git 应用

综述（解读层）

Pier 是一个开源自托管 PaaS，以单个 Rust 二进制运行，官方标注空闲内存占用约 20-40 MB。它支持部署 Docker 容器、Compose 栈与 Git 仓库，通过 Traefik 反向代理提供自动 HTTPS，使用内嵌 SQLite 存储数据，并提供 Web 面板、npm 私有仓库和数据编辑器。适合需要在自有服务器或低配 VPS 上自行管理部署的运维与开发人员。注意 README 中的对比数据（如与 Coolify 的资源对比）为项目方自述，尚未经独立验证。

  • 单二进制部署容器、Docker Compose 栈及 30+ 一键模板，通过 GitHub/GitLab webhook 实现从 Git 到部署的流水线，支持基于 Railpack 的免 Dockerfile 自动构建
  • 内置 Traefik 反向代理与 Let's Encrypt 自动 SSL 证书签发，支持多服务器管理与远程代理
  • 内置 npm 兼容私有仓库与上游代理缓存，以及面向 PostgreSQL、MySQL/MariaDB、MongoDB、Redis 的面板内数据编辑器

适用场景（解读层）

  • 在小内存 VPS（README 称最低 512 MB RAM）或 homelab 服务器上自托管容器化应用，通过 Web 面板与自动 SSL 管理域名反代
  • 团队需要一个私有 npm 仓库兼 npmjs 上游代理，统一 .npmrc 地址并缓存公共包
  • 通过 Git webhook 实现推送后自动构建与部署，需要部署历史回滚和定时备份到 S3
