面向 AI Agent 的多模型存储引擎，支持向量、图、时序等，兼容 PostgreSQL 协议。

综述（解读层）

NodeDB 是一个面向 AI Agent 记忆场景的数据库引擎，将向量、图、文档、时序、全文、KV、空间和数组八类引擎置于同一存储核心与查询规划器中。它以内嵌库（NodeDB-Lite，含 WASM）运行在设备端，也可作为服务端（Origin）以 Multi-Raft 分布式部署，两端通过 CRDT 同步。通过 pgwire 协议可用 psql 或标准 SQL 客户端连接。当前处于公开 beta（v0.6.2），跨小版本升级时存储格式不兼容，需在空目录启动 0.6。

  • 包含向量、图、文档、列式、时序、空间、KV、全文等八类引擎，共享一个身份空间与查询规划器，支持跨引擎融合查询
  • 提供 PostgreSQL 线协议（pgwire），兼容 psql 与标准客户端库，另支持 HTTP/REST、WebSocket、RESP、ILP、MessagePack 共六种协议
  • NodeDB-Lite 作为嵌入式库支持 Linux/macOS/Windows/Android/iOS 及浏览器（WASM，实验性），与 Origin 采用相同 API，通过 CRDT 离线同步

适用场景（解读层）

  • AI Agent 的本地记忆存储：在设备端嵌入运行，离线可用，联网后与服务器端通过 CRDT 合并
  • RAG 与 GraphRAG 场景：同一查询中组合语义检索、图遍历与全文过滤
  • 需要 RBAC、行级安全、审计日志与多租户加密的嵌入式或边缘到云端数据存储
