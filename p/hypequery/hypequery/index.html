综述（解读层）

hypequery 是一组 Apache 2.0 许可的库，用于在自己的应用内定义 ClickHouse 数据集（维度、度量、指标与租户规则），并通过 HTTP 端点、类型化 React hooks 与 MCP 工具对外提供查询。面向在自己 ClickHouse 上构建仪表盘、API 和 AI 代理工具的工程师。README 标注 Python SDK 为 beta，托管版 hypequery cloud 尚未推出。

  • 提供 TypeScript 与 Python（beta）两套 SDK，使用同一套 conformance fixtures 校验，共享相同的语义与部署产物
  • @hypequery/clickhouse 提供类型安全的查询构建器，查询结果类型由真实 schema 与查询本身推断生成
  • @hypequery/mcp 提供 MCP 服务器，向代理暴露 list_datasets、get_dataset_schema、query_metric、query_dataset 四个工具，不提供原始 SQL 工具

适用场景（解读层）

  • 在自有后端中通过 npm 安装 @hypequery/cli 后以 npx hypequery init / dev 启动 TypeScript 项目
  • 用 FastAPI、Django、Flask 或任意 ASGI/WSGI 服务器托管 Python（beta）数据集查询
  • 为 Claude Code、Cursor、Codex 等代理配置受治理的 ClickHouse MCP 工具
