基于 PostgreSQL JSONB 的 Python 面向对象数据库

综述（解读层）

Newt DB 是一个 Python 面向对象数据库，上层以 Python 对象形式操作数据，底层将数据存储于 PostgreSQL 的 JSONB 列并支持检索。需要 Postgres 9.5 或更高版本。官网为 newtdb.org，README 未提供安装与使用细节，需查阅官方站点。

  • 上层提供 Python 对象接口，底层存储于 PostgreSQL JSONB
  • 支持基于 JSONB 的数据访问与搜索
  • 要求 PostgreSQL 9.5 及以上版本

适用场景（解读层）

  • 需要在 PostgreSQL 中存储和检索 Python 对象的场景
  • 希望数据以 JSONB 形式持久化的 Python 应用
