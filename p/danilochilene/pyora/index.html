基于 cx-Oracle 的 Python 脚本，用于采集 Oracle 数据库监控指标。

综述（解读层）

Pyora 是一个用 Python 编写的 Oracle 数据库监控脚本，通过命令行子命令查询数据库状态。使用者需先在 Oracle 中创建专用账号并授予 V$ 视图等查询权限，随后可通过传用户名、密码、地址和数据库名调用 version、activeusercount、tablespace 等数十个检查项。依赖 cx-Oracle 8.2.1 与 argparse，测试环境为 Python 3.8，另有 python2 分支。其输出形式适合接入 Zabbix 等监控工具。

  • 提供 40 余个检查子命令，覆盖版本、活跃用户数、提交/回滚次数、死锁、表空间使用率、归档日志等指标
  • show_tablespaces 命令以 JSON 格式输出表空间名列表，符合 Zabbix 低级发现的键格式
  • 通过命令行参数传入连接信息（用户名、密码、地址、数据库名），单次调用返回单个指标值

适用场景（解读层）

  • 在 Zabbix 中通过 UserParameter 调用脚本采集 Oracle 数据库监控项
  • 通过命令行快速查询 Oracle 实例状态，如版本、活跃会话数、表空间使用率
  • 以 JSON 输出的表空间列表用于监控系统自动发现 Oracle 表空间
