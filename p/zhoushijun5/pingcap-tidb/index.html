TiDB：兼容 MySQL 的开源 NewSQL 分布式 HTAP 数据库

综述（解读层）

TiDB 是 PingCAP 开源的 NewSQL 数据库，同时支持事务处理（OLTP）与分析处理（OLAP），对应用呈现 MySQL 5.7 兼容接口。内部将表切分为约 100MiB 的 region，用两阶段提交保证分布式事务一致性，用 Raft 协议实现副本复制与故障自愈。存储层 TiKV 于 2018 年成为 CNCF 成员项目。适合需要 MySQL 语法且读写可水平扩展的场景；项目并非 MySQL 分支，存在已知兼容性差异。采用 Apache 2.0 许可证。

  • 兼容 MySQL 5.7 语法，可直接使用现有 MySQL 客户端库
  • 表数据按 region 分片（默认约 100MiB），通过两阶段提交实现分布式强一致事务
  • 基于 Raft 协议复制数据，节点故障时自动选主并自愈，SQL 层与存储层（TiKV）可独立扩展

适用场景（解读层）

  • 将现有 MySQL 应用迁移到可水平扩展的数据库而尽量少改代码
  • 同一系统内同时承载 OLTP 事务与 OLAP 分析，减少 ETL 步骤
  • 在公有云、私有云或混合云环境中部署分布式数据库集群
