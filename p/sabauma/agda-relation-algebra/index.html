Agda 编写的关系代数实现，经 FFI 绑定 SQLite 数据库

综述（解读层）

该项目在 Agda 中定义关系代数操作及 SQL 数据类型映射，可将关系代数语句编译为 SQL 并通过 Agda FFI 调用 Haskell 模块与 SQLite 通信。句柄创建前需校验 schema，Handle 构造器被隐藏以防止生成未经校验的句柄，查询结果解析为与 schema 对应的 Row 类型。适合需要在 Agda 类型系统中操作关系数据库的使用者。

  • 提供 SQL 类型宇宙、Schema 与 Row 类型族，并将 SQL 类型映射到对应 Agda 类型
  • 关系代数语句可编译为 SQL，语句按其所需句柄参数化
  • Handle 构造器隐藏，须先经 schema 校验函数验证后方可创建；通过 Agda FFI 由 Database.hs 收发 SQL 查询与结果字符串

适用场景（解读层）

  • 在 Agda 中以关系代数语句查询 SQLite 数据库
  • 对数据库表句柄的构造施加类型级校验
  • 参考 example.agda 编译运行示例，对 test.db 的 Cars 表执行系列查询
📖 README 首段存档原文 · 程序抽取

This project consists of an Agda definition of relational algebra operations along with a means for communicating with an SQLite database. To see the examples, compile and run example.agda.
