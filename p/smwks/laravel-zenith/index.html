面向 Laravel database 队列驱动的实时仪表盘与 worker 管理包

综述（解读层）

Zenith 是一个 Laravel 扩展包，为 database 队列驱动提供仪表盘、worker 进程管理与任务生命周期追踪，数据写入 zenith_processes、zenith_history、zenith_events 三张表。通过 zenith:work 启动 supervisor 及其子进程，以心跳机制配合 zenith:monitor 检测卡死 worker，支持 fixed/manual/automatic 三种平衡策略。默认仪表盘受 auth 中间件保护，提供 /zenith/api/ 下的 JSON 接口。适用于不引入 Redis 而需要队列可视化与运维能力的 Laravel 项目。

  • 提供每 5 秒刷新的实时仪表盘，展示 pending/completed/failed/batches 任务及吞吐、失败率等指标
  • 支持三种 supervisor 平衡策略：fixed、manual（UI 手动扩缩）、automatic（按 pending_jobs/jobs_per_worker 心跳自动扩缩）
  • 提供 /zenith/api/ 下的 JSON 端点，包括指标快照、worker 列表、任务重试与取消等操作

适用场景（解读层）

  • 使用 database 队列驱动且需要实时查看任务状态与失败详情的 Laravel 应用
  • 需要从浏览器或外部监控接口管理 worker 扩缩、终止与失败任务重试的运维场景
  • 不同队列需采用不同扩缩策略（如 Kubernetes 下用 fixed、手工控制用 manual）的部署环境

Think Laravel Horizon, but for database-backed queues. Zenith brings the same real-time visibility and worker management that Horizon provides for Redis — to the database queue driver.
