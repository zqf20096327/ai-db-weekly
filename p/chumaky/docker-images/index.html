🧭 简介解读层（AI·证据行可回查）

集成多种外数据封装的 Postgres 镜像，构成 Datero 数据平台引擎

综述（解读层）

该项目将 mysql_fdw、oracle_fdw、mongo_fdw 等 FDW 扩展编译打包进官方 postgres 镜像，提供单一 FDW 镜像和包含全部 FDW 的 Datero 引擎镜像两种形态。用户通过 CREATE EXTENSION 启用扩展并配置外部数据源凭据后，可在单条 SELECT 语句中访问异构数据源。Datero 镜像另附数据源连接配置与 SQL 编辑器 GUI。镜像以 Docker 容器形式分发，可部署于本地或云端。

  • 提供 mysql_fdw、oracle_fdw、sqlite_fdw、mongo_fdw、tds_fdw、redis_fdw、jdbc_fdw、duckdb_fdw 等单一 FDW 镜像及包含全部 FDW 的 datero_engine 镜像
  • 通过单条 SELECT 语句访问不同类型的外部数据源，实现 SQL/MED 标准扩展与数据虚拟化能力
  • 镜像标签遵循 _fdw 命名模式，并提供各 FDW 版本兼容矩阵与 Compose 演示文件

适用场景（解读层）

  • 在 Postgres 中联合查询 MySQL、Oracle、MongoDB、MSSQL 等异构数据库的数据
  • 借助 jdbc_fdw 连接任何有 JDBC 驱动的数据源，或通过 duckdb_fdw 用 SQL 查询 JSON、Excel、Parquet 等文件
  • 快速搭建容器化的本地或云端数据枢纽（data hub）进行数据探索
