🧭 简介解读层（AI·证据行可回查）

基于FreeTDS的PostgreSQL外部数据封装器，连接TDS协议数据库

综述（解读层）

tds_fdw 是一个 PostgreSQL 外部数据封装扩展，通过 TDS 协议连接 Sybase 和 Microsoft SQL Server 数据库。它依赖实现 DB-Library 接口的库（如 FreeTDS），支持 PostgreSQL 9.2+。使用时需创建外部服务器、外部表和用户映射；不支持 JOIN 下推和写入操作，在启用 match_column_names 时支持 WHERE 与列下推。加密连接和字符集需在 freetds.conf 中配置。

  • 支持连接使用 TDS 协议的数据库，包括 Sybase 和 Microsoft SQL Server
  • 在启用 match_column_names 时支持 WHERE 条件和列下推
  • EXPLAIN (VERBOSE) 可显示远程系统执行的查询及成本相关参数

适用场景（解读层）

  • 需要在 PostgreSQL 中查询 Sybase 或 SQL Server 数据的场景
  • 通过导入外部.schema 将远端表结构映射到 PostgreSQL
  • 依赖 RHEL、Ubuntu、Debian、openSUSE、OSX、Alpine 等環境部署 PostgreSQL 的场景
