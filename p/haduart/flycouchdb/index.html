基于 EDN 迁移文件的 Clojure 版 CouchDB 数据迁移工具

综述（解读层）

FlyCouchDB 是用 Clojure 编写的 Apache CouchDB 迁移工具，机制类似关系型数据库中的 Flyway。迁移以 EDN 文件定义，按版本号和子版本号排序执行，工具记录已运行的迁移并从上次位置继续。支持创建/删除数据库、创建视图、重命名键、编辑与插入文档及组合操作，可打包为 JAR 或 WAR 运行于 Java 项目、JBoss、Tomcat、Jetty 等环境。

  • 迁移以 V{版本}_{子版本}__描述.edn 文件定义，按版本顺序执行并避免重复应用
  • 提供创建/删除数据库、创建视图、重命名键、编辑/插入文档及组合操作等迁移动作
  • 可作为 Clojure 项目运行，也可打包为可执行 JAR 或部署为 WAR（支持 JBoss/WildFly、Tomcat、Jetty）

适用场景（解读层）

  • 为 schemaless 的 CouchDB 数据中隐含的结构演进维护有序迁移列表
  • 在多个 CouchDB 实例间同步应用相同的数据结构变更
  • 初始化数据库或通过插入文档动作生成初始/测试数据
