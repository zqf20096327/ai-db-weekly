🧭 简介解读层（AI·证据行可回查）

一个用 Groovy DSL 通过 JPA 实体填充数据库的测试数据加载库

综述（解读层）

test-data-loader 提供 Groovy DSL，用于在 .groovy 文件中以声明式语法定义 JPA 实体并通过 TestDataLoader 持久化到数据库。DSL 可从纯 Java 调用，支持嵌套实体、按名引用已有实体和 Groovy 控制结构；要求调用方提供已初始化的 EntityManager。已知限制：无法设置父类私有字段，需改为 protected 或添加 protected setter。主要面向测试场景。

  • 实体以模块化 .groovy 文件定义，加载时创建、持久化并按名称注册
  • 支持嵌套定义实体、按名称引用已创建实体，以及使用循环、条件等 Groovy 控制结构
  • 提供 clear() 方法删除已创建实体并清空缓存，可从 classpath 或文件系统加载定义文件

适用场景（解读层）

  • 配合 H2 和 JUnit 编写使用 JPA 实体的单元测试数据准备
  • 在 Arquillian 结合 WildFly/WebSphere Liberty 与 PostgreSQL/DB2 的集成测试中填充数据
  • 需要在 Java 代码中以脚本文件方式批量创建并持久化 JPA 实体的场景
📖 README 首段存档原文 · 程序抽取

This project implements a Groovy DSL that can be used to populate a database using JPA entities. Its indented use is testing but it could be used in other scenarios as well.
