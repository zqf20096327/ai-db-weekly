基于 Ansible IaC 的自托管 PostgreSQL 发行版，集成 HA、备份与监控

综述（解读层）

Pigsty 是 Apache-2.0 协议的开源 PostgreSQL 发行版，通过 Ansible playbook 以声明式配置部署数据库集群。它打包了 626 个 PG 扩展和 12 种 PG 内核分支，集成 Patroni 高可用、pgBackRest PITR 备份及 Victoria/Grafana 监控栈。面向需要在自有 Linux 节点（EL 8/9/10、Debian、Ubuntu）上运行数据库的运维与开发人员，可在裸 Linux 上运行，也支持 Docker 方式。

  • 提供 HA 集群（Patroni+Etcd）、PITR 备份（pgBackRest）和基于 Victoria/Grafana 的监控模块
  • 打包 626 个 PostgreSQL 扩展与 12 种内核分支（含 Citus、Babelfish、IvorySQL、PolarDB 等），支持 16 种 Linux 平台
  • 通过单一配置文件中的 300+ 参数声明集群、用户、数据库与服务，可组合 PGSQL/INFRA/NODE/ETCD 及 Redis、MinIO、Docker 等可选模块

适用场景（解读层）

  • 在自有节点或数据中心部署多节点 HA PostgreSQL 集群，替代云托管数据库服务
  • 使用 Citus 做水平分片，或以 Babelfish/IvorySQL/OpenHalo 等内核模拟其他数据库协议
  • 自托管 Supabase、GitLab、Dify 等以 PostgreSQL 为核心的软件
