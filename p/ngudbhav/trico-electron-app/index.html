基于 Electron 的桌面工具，将 Excel/CSV 表格导入 MySQL 或 MongoDB

综述（解读层）

TriCo 是一款跨平台 Electron 桌面应用，读取 XLS/XLSX/CSV 文件并将数据写入指定的 MySQL 表或 MongoDB 集合。支持批量文件、行列范围选择、生成 .sql 文件及处理前数据库备份。提供 Windows、Linux、macOS 安装包，也可通过 npm 从源码运行。

  • 支持 XLS/XLSX/CSV 格式文件导入 MySQL/MongoDB
  • 支持批量文件处理和行列范围选择
  • MySQL 模式可生成 .sql 文件并自动添加 id 主键

适用场景（解读层）

  • 将电子表格数据批量导入已有的 MySQL 表或 MongoDB 集合
  • 在不直接操作数据库的情况下从 Excel/CSV 生成 .sql 脚本文件
  • 需要对导入前数据库做备份并保留操作历史的导入任务
