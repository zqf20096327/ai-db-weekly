以单个 Kamal accessory 为 Rails 应用提供定时加密备份的 Ruby gem

综述（解读层）

kamal-backup 是一个 Ruby gem 与 Docker 镜像，通过一个 Kamal accessory 为部署在 Kamal 上的 Rails 应用定时备份数据库（PostgreSQL、MySQL/MariaDB、SQLite）和挂载卷中的 Active Storage 文件。底层使用 restic 加密、去重快照，支持 rclone 远端，提供本地恢复、恢复演练和证据输出。开发者经 init 生成配置后加入 deploy.yml 即可运行。

  • 支持 PostgreSQL、MySQL/MariaDB、SQLite 数据库备份及文件型 Active Storage 备份
  • 基于 restic 的加密去重快照，支持原生 restic 后端或任意 rclone 远端
  • 提供恢复演练与脱敏 JSON 证据输出，包含快照、check 结果、保留策略和工具版本

适用场景（解读层）

  • 使用 Kamal 部署、需要定时数据库和文件备份的 Rails 应用
  • 需要在不触碰生产库的情况下进行恢复演练或本地查看生产数据
  • 需要为 CASA 等安全审查生成备份证据的团队
