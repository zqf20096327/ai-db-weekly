自托管的 Web 数据库客户端，支持 MySQL、MariaDB、PostgreSQL 及兼容引擎

综述（解读层）

Flase 是一个以 Docker 容器部署的 Web 数据库管理工具，连接 MySQL、MariaDB、PostgreSQL 及 TiDB、CockroachDB、YugabyteDB 等兼容引擎。提供类电子表格数据网格、SQL 控制台、ER 图、导入导出、服务器监控、用户权限管理等功能，支持 SSH 隧道和 TLS 连接。密码不存储在服务器端，服务器可强制只读连接。适用于需要在浏览器中管理自建或云数据库的开发者与运维人员，采用 AGPL v3+ 许可证。

  • 提供虚拟化数据网格，仅渲染可见行列，支持内联编辑、多选、查找替换及 TSV/CSV/JSON/XML/Markdown/HTML/LaTeX/SQL INSERT 复制格式
  • SQL 控制台支持多语句执行、查询历史、SQL 补全、树状执行计划、:name 参数绑定，并对无 WHERE 的 UPDATE/DELETE 下划线提示
  • 支持流式 SQL dump 导入导出（含 gzip）、CSV 导入与列映射、可视化查询构建器、ER 图、跨库 schema 对比与迁移脚本生成

适用场景（解读层）

  • 通过浏览器集中管理多个 MySQL/MariaDB/PostgreSQL 数据库，替代 phpMyAdmin 或 Adminer 的工作流
  • 部署于数据库所在内网，由管理员预定义连接并强制只读，用于生产数据的查询与查看
  • 通过 SSH 隧道经跳板机访问仅内网可达的数据库

Flase is a fast, open source web-based database client for MySQL, MariaDB and PostgreSQL, also TiDB, CockroachDB, YugabyteDB and cloud services like Supabase, Neon, RDS or Aurora.
