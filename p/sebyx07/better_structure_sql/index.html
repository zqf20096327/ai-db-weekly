Ruby Gem，通过数据库内省为 Rails 生成确定性 schema 转储文件

综述（解读层）

该项目是一个 Rails Gem，通过纯 Ruby 数据库内省替代 pg_dump、mysqldump 等外部工具生成 db/structure.sql。支持 PostgreSQL 12+、MySQL 8.0+ 和 SQLite 3.35+，从 ActiveRecord 连接自动检测适配器。可选提供 schema 版本存储（基于 MD5 去重）、多文件目录输出及可挂载的 Web UI 引擎。当前 PostgreSQL 支持为 0.2.2 版，MySQL/SQLite 为实验性。

  • 纯 Ruby 实现，不依赖 pg_dump、mysqldump、sqlite3 CLI 等外部工具，适配器由 ActiveRecord 连接自动检测
  • 提供 rake 任务用于 schema 转储、加载、版本存储/列出/清理/恢复，支持单文件与多文件目录两种输出模式
  • 可挂载 Rails Engine 提供 Web 界面，浏览、查看和下载存储的 schema 版本，支持配置认证

适用场景（解读层）

  • Rails 项目需要生成格式一致、纳入版本控制的 structure.sql，替代外部 dump 工具
  • 大规模 schema（如 100+ 表）项目需要按目录拆分 schema 文件以便导航
  • 团队需要记录 schema 历史版本，并通过 Web 界面查看或从特定版本恢复
🔌 适配哪些库db_scan 程序判定

MariaDB、MySQL、PostgreSQL、SQLite
