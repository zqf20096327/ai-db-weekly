🧭 简介解读层（AI·证据行可回查）

Go 编写的教学用简单关系数据库，实现 SQL 解析、slotted page 存储与 WAL 日志。

综述（解读层）

该项目是 Edward Sciore《Database Design and Implementation》书中 SimpleDB 的 Go 语言移植，定位为学习数据库原理的教学工具，并在原设计基础上重构为符合 Go 惯例的代码结构。它实现基于 slotted page 的存储引擎、预分配缓冲池、带 LSN 的 WAL、B-tree 索引，支持 INT/TEXT 两种类型和一个 SQL 子集。需要 Go 1.22 及以上环境，构建后以 TCP 服务运行，默认监听 8765 端口，可通过 telnet 执行以分号结尾的 SQL 语句。

  • 存储引擎采用 8KB slotted page 架构，页头记录块号、页类型与槽位信息，记录头部含 xmin/xmax 为 MVCC 预留基础
  • 实现 Write-Ahead Logging：每条日志分配 LSN，修改页在其日志持久化前不写盘；缓冲池使用 pin/unpin 引用计数
  • 支持 CREATE TABLE、INSERT、SELECT、UPDATE、DELETE、CREATE INDEX、ORDER BY 等 SQL 子集及 INT/TEXT 类型

适用场景（解读层）

  • 学习关系数据库内部原理，如存储页结构、缓冲管理与 WAL 恢复机制
  • 以 Go 语言视角研究 SimpleDB 教学模型的工程实现
  • 搭建最小可运行数据库实验环境，通过 TCP 客户端练习执行基础 SQL
