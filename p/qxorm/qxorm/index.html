面向 C++ Qt 开发者的 ORM/ODM 库，提供持久化、序列化与反射

综述（解读层）

QxOrm 是面向 C++/Qt 开发者的 ORM 与 ODM 库，用于管理持久化数据层。支持 SQLite、MySQL、PostgreSQL、Oracle、MS SQL Server、MongoDB 等数据库及 1-1、1-n、n-n 关系，并提供 JSON/二进制/XML 序列化、类反射和多线程 HTTP 服务器。默认仅依赖 QtCore 与 QtSql，启用 HTTP 功能需 QtNetwork，部分功能需 boost。配套 QxEntityEditor 图形工具可生成 C++ 类与 DDL 脚本，文档要求具备 C++ 与数据库知识。

  • 持久化支持 SQLite、MySQL、PostgreSQL、Oracle、MS SQL Server、MongoDB，含 1-1、1-n、n-1、n-n 关系
  • 提供 JSON、二进制、XML 序列化及运行时反射（动态访问类定义、属性与方法）
  • 内置多线程 HTTP 1.1 web 服务器，支持 SSL/TLS、cookie、会话与 URL 路由；提供 Docker 快速演示环境

适用场景（解读层）

  • 在 C++/Qt 项目中管理持久化数据层
  • 通过 REST web 服务、QML 应用或脚本语言与后端交互
  • 使用 QxEntityEditor 导入现有数据库结构、生成持久化类与 DDL 脚本、管理 schema 演进
