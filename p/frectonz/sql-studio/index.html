单二进制单命令的 SQL 数据库浏览工具，用 Rust 编写

综述（解读层）

SQL Studio 是一个通过单条命令启动的 SQL 数据库浏览器，支持 SQLite、libSQL、PostgreSQL、MySQL/MariaDB、DuckDB、ClickHouse、Microsoft SQL Server，并可读取本地 Parquet 和 CSV 文件。提供概览、表、查询、模式等页面，包含无限滚动行视图与自定义查询的 SQL 智能提示。适用于需要在本地或服务器上浏览数据库与数据文件的场景，可通过 shell 脚本、Nix 或 Docker 安装运行。

  • 支持 SQLite、libSQL、PostgreSQL、MySQL/MariaDB、DuckDB、ClickHouse、Microsoft SQL Server 等数据库连接，并可读取 Parquet 和 CSV 文件
  • 提供概览页、表页、查询页、模式页等界面，行视图支持无限滚动
  • 自定义查询页面包含 SQL 智能提示功能

适用场景（解读层）

  • 浏览本地 SQLite 或 DuckDB 数据库文件的结构与数据
  • 连接 PostgreSQL、MySQL、ClickHouse 等服务器查看表元数据并执行查询
  • 直接打开本地 Parquet 或 CSV 文件查看内容
