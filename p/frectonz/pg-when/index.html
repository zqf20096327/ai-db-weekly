pg-when：用自然语言解析生成时间值的 PostgreSQL 扩展

综述（解读层）

pg-when 是一个 PostgreSQL 扩展（基于 Rust/pgrx 构建），用于将自然语言时间表达式解析为时间值。查询由日期、时间、时区三个可选组件组成，通过 at 和 in 关键字连接；日期支持相对短语（如 5 days ago）和多种格式，时区支持 IANA 名称与 UTC 偏移。提供 when_is 返回 TIMESTAMPTZ，另有返回 UNIX 时间戳整数的 seconds_at 至 nanos_at 五个函数。README 说明未提供时区时默认使用 UTC，未提及 SQL 之外的安装方式，仅提供 Docker 镜像，覆盖 PostgreSQL 14 至 18。

  • 提供 when_is、seconds_at、millis_at、micros_at、nanos_at 五个 SQL 函数，分别返回 TIMESTAMPTZ 及自 UNIX 纪元起的秒/毫秒/微秒值
  • 查询由日期、时间、时区三个组件组成，用 at 和 in 关键字连接；未提供时区时默认使用 UTC
  • 日期支持相对短语（today、5 days ago、in 2 years 等）与多种精确格式，时区支持 IANA 名称与 UTC 偏移

适用场景（解读层）

  • 在 SQL 查询中直接书写相对时间表达式（如 'next friday at 8:00 pm in America/New_York'）并获取时间戳或 UNIX 时间戳
  • 需要按指定时区解析自然语言时间描述的 PostgreSQL 应用
  • 通过 Docker 快速运行一个已安装该扩展的 PostgreSQL 数据库进行测试或使用
