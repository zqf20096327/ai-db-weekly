通过 WebSocket 查询 SQLite 数据库并生成类型安全 TypeScript 客户端的服务

综述（解读层）

Jabroni 是一个用 Rust 编写的服务，通过 WebSocket 连接 SQLite 数据库并执行查询，可生成依赖 zod 和 nanoid 的类型安全 TypeScript 客户端库，其 API 类似浏览器内置 fetch。支持行增删改查、分页、批量插入和轮询连接池。JWT 鉴权与表 join 尚在计划中，尚未实现。

  • 通过 WebSocket 执行表查询、列筛选、分页、批量插入及单行增删改查
  • 生成依赖 zod 与 nanoid 的类型安全 TypeScript 客户端库，API 类似浏览器 fetch
  • 采用轮询连接池处理 socket 拥塞，支持通过命令行参数或环境变量配置地址与数据库路径

适用场景（解读层）

  • 从浏览器或 TypeScript 应用经 WebSocket 读写 SQLite 数据
  • 为已有 SQLite 数据库生成带类型的客户端代码
  • 通过 Docker 挂载数据库文件部署查询服务
