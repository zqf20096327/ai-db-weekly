🧭 简介解读层（AI·证据行可回查）

基于 Gin 与 Traefik 网关的 Go 微服务后台脚手架，含 16 个服务进程

综述（解读层）

GopherForge（曾用名 go-admin-kit）是一套 Go 微服务管理平台：后端按域拆分为 16 个 Go 服务，前端用 React 19 + Ant Design 6，Traefik 网关统一 ForwardAuth 鉴权。内置 RBAC、多租户、审计日志、监控与代码生成器，数据栈与应用栈分离，`make compose-up` 拉起全栈。适合搭建企业内部管理平台或 SaaS 后台的 Go 团队。项目处于 0.x 阶段，API 与表结构可能调整；IM、呼叫中心、CRM 等为实验业务线，支付仅 mock 渠道，上线前需替换默认密钥。

  • 后端 Go + Gin 拆分为 16 个服务（认证/RBAC/审计/监控等底座与 IM/CRM 等业务线），Traefik 网关统一 ForwardAuth 验签，NATS JetStream 解耦登录事件
  • 支持 RBAC、共享库多租户（tenant_id + 租户码登录）、JWT Access/Refresh 吊销与轮转、OAuth2 授权服务端 + OIDC（PKCE/JWKS）、goose 版本化迁移
  • 提供 Prometheus/Grafana/Alertmanager 告警、OpenTelemetry 链路、OpenAPI 3.1 契约、ghcr 多架构镜像（amd64/arm64），`make compose-up` 一键启动

适用场景（解读层）

  • 需要真微服务架构起点、快速搭建企业内部管理平台或 SaaS 管理后台的 Go 团队
  • 前端更熟悉 React/Ant Design 而非 Vue 的团队
  • 需要 RBAC、多租户、审批流、监控告警等底座能力并按需裁剪业务线的项目；本地开发可用 Docker Desktop 环境配合默认账号 admin/admin123 体验
