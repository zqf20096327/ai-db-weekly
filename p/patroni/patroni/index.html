基于分布式配置存储的 PostgreSQL 高可用集群模板

综述（解读层）

Patroni 是一个用 Python 编写的 PostgreSQL 高可用集群构建模板，适用于需要管理 PostgreSQL 主备集群的运维人员。它通过 ZooKeeper、etcd、Consul、Kubernetes 或内置 Raft 等分布式配置存储协调集群成员与主节点选举，支持 PostgreSQL 9.3 至 18 版本，使用流复制并可通过 YAML 或环境变量配置，3.0 起还集成 Citus 扩展。README 提示在严格内存限制与 Python 3.11+ 环境下 REST API 可能无响应。

  • 支持 etcd、Consul、ZooKeeper、Kubernetes、Raft 等多种分布式配置存储作为 DCS
  • 使用 PostgreSQL 流复制，支持异步复制（maximum_lag_on_failover）与同步复制两种模式
  • 提供 REST API、HAProxy 配置示例，并可通过 YAML 文件与环境变量进行配置

适用场景（解读层）

  • 在自建机房或云上搭建多节点 PostgreSQL 高可用集群
  • 在 Kubernetes 环境中原生运行 PostgreSQL 集群
  • 使用 Citus 构建分布式 PostgreSQL 并配合 Patroni 管理
