🧭 简介解读层（AI·证据行可回查）

将 Garmin Connect 健康数据下载为本地文件并载入 SQLite 的 Python CLI。

综述（解读层）

这是一个 Python 命令行工具，通过 garmin auth 登录后用 garmin extract 将 Garmin Connect 的睡眠、心率、HRV、活动文件（FIT/TCX）等数据下载为本地文件并载入 SQLite 数据库。内含自带 SSO/MFA 登录的 Garmin 客户端，源自 OpenETL 的 Garmin 管道但无需 Airflow/PostgreSQL。支持多账号合库、断点续传、按日期/类型失败隔离；要求 Python 3.10+、SQLite 3.35+，pip 安装即可使用。

  • 单命令下载睡眠、HRV、压力、心率、VO2 max、月经周期及 FIT/TCX 活动文件并载入 SQLite，可用 --extract-only/--process-only 分离两个阶段
  • 支持多账号写入同一数据库，内置 SSO/MFA 登录客户端，无第三方 Garmin 客户端库依赖；采用 ingest/process/storage/quarantine 四目录生命周期，支持自动续传与崩溃恢复
  • 提供 garmin downsample 将逐秒传感数据聚合为时间桶、garmin prune 删除源行并收缩数据库文件以控制磁盘占用

适用场景（解读层）

  • 将个人 Garmin 健康与活动数据备份为本地文件并导入 SQLite 进行 SQL 分析
  • 多 Garmin 账号（如家庭成员）数据汇总到同一数据库
  • 为 AI agent 或量化自我分析提供结构化的健康数据源
