🧭 简介解读层（AI·证据行可回查）

自托管 AI 治理与隐私基础设施，提供带引用的 RAG 和可审计决策记录

综述（解读层）

Alchimista 是一个可自托管的基础设施层，功能包括证据摄入、租户隔离检索索引、强制引用的问答，以及记录带隐私元数据的 AI 决策审计证据。基线部署仅需 Docker Compose 与 Python 3.11，不依赖外部向量库或云服务；GCP、Vertex、OIDC 等以可选适配器形式保留。README 明确说明它实现的是技术控制，不构成 GDPR 或 AI Act 的法律合规认证。

  • 提供 local 与 gcp 两种运行配置，local 模式使用 PostgreSQL、SQL 检索和离线确定性嵌入，无外部付费服务
  • 提供 off/detect/protect_egress/strict 四级隐私策略，包含 Rizzo PII 检测、AES-256-GCM 加密 PII vault、伪名化与级联删除约束
  • 提供强制引用的 RAG 问答、租户隔离、审计证据记录，隐私服务不可用时策略默认失败关闭（fail closed）

适用场景（解读层）

  • 需要在本地或私有网络部署文档问答与检索的场景
  • 需要为 AI 决策留存带引用与隐私元数据的审计记录的团队
  • 需要对文档中 PII 进行检测、伪名化和加密存储的处理流程
