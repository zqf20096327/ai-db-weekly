综述（解读层）

bit-api 将多个上游模型服务统一为兼容 OpenAI 与 Anthropic 调用方式的 API，并提供用户、密钥、渠道、定价与用量管理。采用 FastAPI+SQLite 单实例部署，无需 Redis、PostgreSQL 或前端构建，适合搭建团队内部模型入口或带自助控制台的 API 服务。注意：它不做模型推理，需自备上游 Key，且 SMTP 为注册前置条件。

  • 提供 Chat Completions、Responses、Anthropic Messages 与 Embeddings 接口，并通过 Adapter 扩展特殊上游
  • 支持多渠道路由调度（优先级、权重、账号轮换）及用户密钥配额、定价分组与用量流水管理
  • 通过事件插件实现签到赠额、邀请奖励、返佣、兑换码与 Webhook 告警等运营策略

适用场景（解读层）

  • 搭建团队内部的统一模型调用入口
  • 部署带用户注册、计费与自助控制台的 API 服务
  • 对多个上游渠道做统一路由、密钥池与用量归一管理
