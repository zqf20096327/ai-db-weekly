面向 TypeScript 的装饰器风格 ORM，机制上对标 Laravel Eloquent 的 Active Record 模式。

综述（解读层）

Fedaco 是一个 TypeScript 编写的 ORM，README 将其定位为 Laravel Eloquent 风格。它通过 @Table、@Column 等装饰器定义模型，提供流式查询构建器、事务、Schema 构建器与迁移 CLI，支持 SQLite、MySQL/MariaDB、PostgreSQL、SQL Server（驱动需单独安装）。适合在 Node.js/TypeScript 项目（含 NestJS）中使用 Active Record 风格的开发者。注意：ES2022 及以上 target 需为列字段加 declare。

  • 基于装饰器的模型定义，配套流式查询构建器与 Schema 构建器、迁移 CLI
  • 关系加载覆盖 HasOne/HasMany/BelongsTo/BelongsToMany/Through/HasOneOfMany 及多态，并提供每关系 onQuery 钩子
  • 支持软删除、批量赋值保护、访问器与类型转换；多连接、读写分离、连接池与隔离事务

适用场景（解读层）

  • Node.js/TypeScript 项目中需要 Active Record 风格数据访问层的场景
  • 使用 NestJS 的后端服务（提供 @gradii/nest-fedaco 模块）
  • 本地开发/测试可选用 SQLite 驱动，生产可切换 MySQL/MariaDB、PostgreSQL、SQL Server 多数据库场景
