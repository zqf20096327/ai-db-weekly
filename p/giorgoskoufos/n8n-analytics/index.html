自托管 n8n 分析面板，ETL 读取自有 PostgreSQL 生成执行分析

综述（解读层）

面向自托管 n8n 实例的分析面板，通过每 5 分钟的 ETL 将 n8n PostgreSQL 中执行与工作流表的少量列同步到本地 SQLite 副本，用于展示长周期执行历史、错误指纹分组、队列延迟与 ROI。代码对 n8n 数据库只读，不写入任何数据；需自托管 n8n 且 PostgreSQL 后端，不支持 SQLite 默认配置。

  • ETL 每 5 分钟从 n8n PostgreSQL 只读同步，分析查询全部运行在本地 SQLite 副本上
  • 提供错误指纹分组、触发类型拆分、队列延迟 p50/p95/p99 与静默停止检测等分析
  • 支持七种告警规则（webhook/Telegram/n8n workflow），并提供可选的 OpenAI 助手

适用场景（解读层）

  • 追溯 n8n 已删除的执行记录以保留长期执行历史
  • 将重复错误按指纹归组，区分已自愈与未恢复的失败
  • 检测不再按原节奏运行的活动工作流，并配置告警通知
