Dgraph 备份恢复 CLI 工具，通过 AWS S3 存取备份归档

综述（解读层）

dgbr 是一个用 Go 编写的命令行工具，用于将 Dgraph 数据库备份到 AWS S3 存储桶或从中恢复。备份流程为：请求 Dgraph 导出数据库、打包归档并上传至 S3；恢复则从 S3 下载归档，解压后通过 live loader 导入数据和 schema。适用于需要管理 Dgraph 备份的运维人员，需提供 AWS 密钥、存储桶和区域参数；备份要求 Dgraph alpha 启动时指定 export 路径并具备相应读写权限。README 说明该项目已用于生产环境并计划持续维护。

  • backup 子命令将 Dgraph 导出数据打包为 zip 并上传至指定 S3 存储桶
  • restore 子命令从 S3 下载归档，解压后通过 live loader 导入数据与 schema
  • 支持通过 cron 脚本配置周期性（如每小时、每日）备份

适用场景（解读层）

  • 对运行中的 Dgraph 数据库执行定期 S3 远程备份
  • 从 S3 存储桶中的 zip 归档恢复 Dgraph 数据库和 schema
  • 结合 cron 实现小时级或日级的自动化备份任务
📖 README 首段存档原文 · 程序抽取

dgbr is CLI tool allowing to backup/restore Dgraph database to/from AWS S3 bucket. dgbr handles backups by requesting Dgraph to export existing database, archiving the data and uploading it to the S3
