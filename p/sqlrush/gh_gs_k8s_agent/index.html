GaussDB 数据库智能体后端，用 Kubernetes 隔离环境运行 opencode 诊断技能

综述（解读层）

该项目是 GaussDB/openGauss 智能体的后端部分，由接入网关、用户运行环境、知识库导入环境、标准知识库和可选发版台组成，通过 K8s 按用户分配隔离 Pod 或池化槽位，状态存于 NAS。交付以 diag 与 kbimport 两个技能包分支为主，代码在测试仓库维护后由脚本生成。适用于与前端方联合搭建面向 DBA 的数据库诊断场景。

  • 包含接入网关（认身份、分配用户环境、反向代理）与 17 个诊断技能包，提供部署自检脚本核对版本、白名单与权限
  • 每个用户一个隔离 Pod 或固定池化槽位，凭据代理使中间件令牌、签名私钥、模型 Key 不进模型所在容器，状态统一存于 NAS 的 RWX 卷
  • 提供 128 条白名单诊断脚本清单、含升级增量的 SQL 文件、五组 pytest 测试与 Apache License 2.0 许可的技能代码

适用场景（解读层）

  • 为 GaussDB / openGauss 诊断环境部署带 K8s 隔离与网关认证的智能体后端
  • 运维通过发版台容器执行资源扫描、变更预览确认、按槽位在线替换与回滚
  • 知识库管理员导入官方文档集（CHM）、网页剪藏、扫描件 PDF 转录与 PPT 到标准知识库

GaussDB 数据库智能体的后端：把 opencode 与 GaussDB / openGauss 诊断技能放进 Kubernetes。 每个用户一个隔离的环境（按需建 Pod，或固定池化的槽位），状态全部在 NAS 上；接入网关负责认身份、分配环境、反向代理。
