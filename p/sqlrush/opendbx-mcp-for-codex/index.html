🧭 简介解读层（AI·证据行可回查）

面向 GaussDB/openGauss 的只读 DBA MCP server，供 Codex 等 agent 调用

综述（解读层）

该项目把 opendb 的数据库专家技能封装为标准 MCP server（stdio JSON-RPC），当前内置 GaussDB/openGauss 服务，提供约 36 个只读工具，覆盖诊断、会话锁、事务空间、SQL 性能调优和 WDR 报告等域。任何支持 MCP 的客户端均可接入；数据展示类工具采用确定性渲染，数字不经模型。构建需 Go 环境，纯 Go 无 CGO，GaussDB 使用专有 gaussdb-go 驱动（SCRAM-SHA256），系统视图复用 openGauss 的 pg_stat_* 与 dbe_perf.*。

  • 内置约 36 个只读工具，覆盖诊断、会话/锁、事务/空间/膨胀、SQL 性能/调优、WDR/趋势等域
  • 以标准 MCP 协议（stdio JSON-RPC）提供接口，支持 codexgo、OpenAI Codex、Claude Code、VS Code 等客户端
  • 数据展示类工具确定性渲染对齐表格，health/sqltune/wdranalyze 在采集确定性证据后由模型叠加分析

适用场景（解读层）

  • 在 Codex/codexgo 等 agent 中对 GaussDB/openGauss 进行只读诊断、慢 SQL 分析与索引建议
  • 通过 Claude Code 或 VS Code 以自然语言触发数据库体检、阻塞链与复制状态查询
  • 在 codexgo 中将工具映射为 /health 等确定性 slash 命令执行常规 DBA 检查

把 opendb 的数据库专家能力,封装成一个标准 MCP server(stdio JSON-RPC),供 codexgo、OpenAI Codex、Claude Code、VS Code 等任何支持 MCP 的 agent 使用。 当前内置 GaussDB / openGauss 服务(codexgo-db-gaussdb),全部工具只读(不修改数据或配置)。
