🧭 简介解读层（AI·证据行可回查）

面向 MySQL 的 Model Context Protocol 服务器，提供数据库查询与诊断工具

综述（解读层）

该仓库实现一个基于 MCP 协议的 MySQL 服务器，用于通过 AI 客户端执行数据库操作与诊断。支持 Docket 与本地两种部署方式，提供 stdio 与 SSE 传输、HTTP API 端点，并给出 Claude Desktop 的集成配置。内置只读查询、性能分析、慢查询分析、用户权限审计、复制延迟监控等工具，通过环境变量配置连接。README 中的安全章节提示其仅适用于受信任环境。

  • 提供只读 SQL 查询、服务器状态、InnoDB 指标等核心工具，以及慢查询分析、死锁检测、权限审计、复制监控等诊断类工具
  • 支持 Docker Compose 部署与 pip 本地安装，运行于 Python 3.10+，提供 stdio 与 SSE 两种传输方式及 /health、/tools、/invoke HTTP 端点
  • 安全机制包含 Bearer token/API key 认证、按 IP 限流、Pydantic 输入校验、只读查询限制与请求大小限制

适用场景（解读层）

  • 在 Claude Desktop 等 MCP 客户端中查询表结构、执行 SQL 并获取结果
  • 分析慢查询、死锁与缓冲池缓存，进行 InnoDB 性能诊断
  • 审计用户权限、监控复制延迟与 SSL/TLS 配置等数据库运维检查
