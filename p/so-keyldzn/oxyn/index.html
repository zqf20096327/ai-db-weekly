综述（解读层）

Oxyn 是一个本地运行的桌面数据库工作区，用于浏览表结构、检查列与表定义、执行 SQL 并查看结果。核心与数据库驱动以 Rust 实现，界面基于 Tauri 2 构建。面向数据专业人员。README 中 PostgreSQL、MySQL/MariaDB、SQLite 驱动已有说明，而文档中提及的关系型之外的数据库类型是否已实现无法从 README 验证；Intel macOS 与 Windows 无官方构建包。

  • 提供 PostgreSQL、MySQL/MariaDB 与 SQLite 协议驱动，支持执行 SQL 并检查结果与表定义
  • 以单个 Cargo workspace 组织，包含 crates/* 核心、drivers/* 协议实现与 apps/desktop 前端
  • 提供 Apple Silicon macOS DMG 及 x86_64/ARM64 Linux 的 DEB、RPM、AppImage 包，含签名与签名内更新

适用场景（解读层）

  • 浏览数据库行、检查列与表定义并执行 SQL 查询
  • 在本地桌面环境中管理 PostgreSQL、MySQL/MariaDB 或 SQLite 连接
  • 借助 AI 代理辅助理解 schema 与查询（隐私感知模式）
