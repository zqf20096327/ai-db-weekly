SQL Server T-SQL 运维诊断脚本集合，覆盖健康检查与维护场景

综述（解读层）

该仓库收录 135 个面向 SQL Server 的 T-SQL 脚本，按编号组织，内容涵盖阻塞查询与 CPU 占用排查、索引冗余/缺失与碎片分析、统计信息更新、备份恢复状态检查、会话与内存监控等。脚本可直接在 SSMS 中运行，作者提示需先在开发或 QA 环境验证后再用于生产实例。适合 SQL Server DBA 与运维人员日常排障使用。

  • 包含 135 个编号 T-SQL 脚本，覆盖索引、统计信息、会话、备份、内存等诊断主题
  • 提供维护类脚本，如索引重建/重组、更新统计信息、生成收缩脚本
  • 部分脚本针对特定版本特性，如 SQL Server 2014/2016 的 Columnstore 与内存优化表监控

适用场景（解读层）

  • 日常排查阻塞查询、高 CPU 查询与慢查询
  • 数据库健康巡检：索引冗余与缺失、碎片率、过期统计信息、文件大小与自动增长设置
  • 备份与恢复管理：备份历史、进度与预估完成时间查询
