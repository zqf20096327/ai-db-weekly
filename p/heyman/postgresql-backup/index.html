🧭 简介解读层（AI·证据行可回查）

基于 Docker 的 Postgres 定时备份镜像，可将备份上传至 Amazon S3

综述（解读层）

该镜像按 CRON_SCHEDULE 定期使用 pg_dump 导出 Postgres 数据库，并可选上传至 Amazon S3。通过环境变量配置数据库连接、S3 凭据、保留天数等，支持 webhook 通知和一次性备份/恢复任务。需注意上传 S3 需提供 AWS 访问密钥，备份默认仅保留 7 天。

  • 提供基于 crontab 表达式的定时备份调度，备份文件写入 /data/backups 目录并可选上传 S3
  • 支持 webhook 通知（含 Slack 示例）和 Amazon SES 邮件通知，Webhook 内容可插入日期、耗时、文件大小等变量
  • 提供一次性备份与恢复命令，支持通过 PG_DUMP_EXTRA_OPTIONS 和 S3_EXTRA_OPTIONS 传入自定义参数，可搭配自定义 S3 兼容端点

适用场景（解读层）

  • 需要定时自动备份 Postgres 数据库并存储到 S3 的容器化部署环境
  • 希望在备份完成后通过 Slack、邮件或自定义 HTTP 接口接收通知的运维场景
  • 需要从 S3 下载备份文件并恢复到指定 Postgres 数据库的操作场景
