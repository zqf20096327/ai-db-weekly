用于在 OCI 上部署 Oracle E-Business Suite 的 Terraform 模块

综述（解读层）

该项目是 Oracle 官方提供的 Terraform 模块，用于在 Oracle Cloud Infrastructure 上创建 Oracle E-Business Suite 所需的基础设施。支持单可用域与多可用域两种架构，通过 OCI Resource Manager 或 Terraform CLI 部署，模块包含堡垒机、计算实例、数据库系统、负载均衡器和 VCN 等子模块。要求 Terraform 0.13.x，需要填写 terraform.tfvars（含数据库管理员密码等输入）后依次执行 init、plan、apply。

  • 支持单可用域和多可用域两种部署架构，应用实例按故障域/可用域轮询方式分配
  • 包含 bastion、compute、dbsystem、loadbalancer、network（vcn/subnets）等子模块
  • 可通过 OCI Resource Manager 控制台或 Terraform CLI 两种方式部署

适用场景（解读层）

  • 需要在 OCI 上为 Oracle E-Business Suite 建置基础设施（计算、数据库、负载均衡、网络）的团队
  • 希望以代码化方式批量创建并销毁 EBS 环境（terraform apply/destroy）的场景
  • 需要通过 OCI Resource Manager 栈部署、按配置生成多可用域架构的运维流程
