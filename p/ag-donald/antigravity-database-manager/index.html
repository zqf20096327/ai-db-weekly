非官方 Antigravity IDE 数据库管理与会话历史恢复工具

综述（解读层）

这是面向 Google Antigravity IDE 社区用户的非官方恢复工具，用于修复 IDE 更新或异常关闭后侧边栏会话历史消失的问题。它从磁盘上完好的 .pb/.db 会话文件重建 state.vscdb 中的索引映射，写入前自动备份并在出错时回滚；原始会话文件不被修改。需 Python 3.10+，无外部依赖，运行前须完全关闭 IDE。

  • 提供 recover、scan、repair、merge、fix-uris 等子命令及交互式 TUI，支持 G1/G2/G3 三代 IDE 数据库位置自动检测
  • 恢复流程包含时间戳备份与出错自动回滚，重建 Protobuf trajectorySummaries 与 JSON ChatSessionStore.index，不修改原始会话文件
  • 仅用 Python 标准库实现，无外部依赖，另提供免安装的 .pyz 便携包，跨 Windows/macOS/Linux 平台

适用场景（解读层）

  • IDE 更新、重启、异常断电或崩溃后，侧边栏会话历史消失但磁盘会话文件仍存在时执行恢复
  • 工作区路径变更、大小写或 URI 编码不匹配导致会话与项目失去关联时，用 fix-uris 修复绑定
  • G3 世代构建中 agyhub_summaries_proto.pb 摘要缓存被清零时，运行 repair --summaries 重建侧边栏索引
