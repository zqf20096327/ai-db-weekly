基于 Python 的 ETL 框架，通过 Task 组合 Reader 与 Writer 实现数据抽取转换加载

综述（解读层）

Pyetl 是面向 Python 3.6+ 的 ETL 框架，通过 Task 类组合 Reader 和 Writer 构建数据管道，可用 functions 参数为字段配置 UDF 映射做校验、标准化和清洗，也支持继承 Task 扩展。Reader/Writer 覆盖关系型数据库、csv、Excel、Elasticsearch 及 Hive 等。示例代码以 sqlite3 与 pymysql 展示用法，经 pip3 install pyetl 安装。

  • 提供 DatabaseReader、FileReader、ExcelReader、ElasticsearchReader 等读取器，DatabaseWriter、ElasticsearchWriter、HiveWriter、FileWriter 等写入器
  • 支持通过 functions 配置字段的 UDF 映射，实现字段类型转换、去空格等规则校验、数据标准化与清洗
  • 支持继承 Task 类进行扩展，可在源表与目标表字段名称不同时进行映射

适用场景（解读层）

  • 在 MySQL、SQLite 等关系型数据库之间迁移或同步表数据
  • 读取 csv、Excel 等结构化文本文件并写入数据库或 Elasticsearch 索引
  • 在 ETL 流程中对字段做清洗、标准化后批量写入 Hive 表
