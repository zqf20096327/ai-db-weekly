支持中文与拼音分词的 SQLite fts5 全文搜索扩展

综述（解读层）

simple 是一个 SQLite3 fts5 分词器扩展，用于在 SQLite 中实现中文及拼音搜索，实现自微信移动端全文检索多音字方案中的方案四，并可选集成 cppjieba 实现词组匹配。适合在应用内嵌 SQLite 的场景中使用，提供 C++、Python、Go、Node、Rust、Java、C#、iOS、Flutter 等使用示例。构建需 C++14 以上编译器，可通过 cmake 或脚本编译，支持 iOS 与 ohos 平台；拼音表可通过 pinyin_dict() 自定义，替换后需重建已有索引。

  • 支持中文和拼音分词，可通过开关控制是否启用拼音
  • 提供 simple_query()、simple_highlight()、simple_snippet() 等 SQL 函数，用于组装查询、高亮与截取片段
  • 可选 jieba_query() 基于 cppjieba 实现分词匹配，拼音表与分词词典路径均可配置

适用场景（解读层）

  • 在移动端（iOS、Android/Flutter、React Native）内嵌 SQLite 的应用中做中文与拼音全文检索
  • 在 C++/Python/Go/Node/Rust/Java/C# 等语言中使用 SQLite 并需要中文搜索
  • 需要自定义拼音映射表或jieba词典路径的检索场景
