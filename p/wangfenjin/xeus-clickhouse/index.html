基于 xeus 原生实现的 ClickHouse SQL Jupyter 内核

综述（解读层）

xeus-clickhouse 是一个面向 ClickHouse 的 Jupyter 内核，基于 Jupyter 协议的原生实现 xeus 构建，使用户可在 Jupyter Notebook 中以 SQL 单元访问 ClickHouse。项目提供 Docker 镜像可直接运行，也支持从源码编译安装，依赖 xeus、clickhouse-cpp、Tabulate 等。README 明确标注当前为早期开发者预览版，不适合一般使用，功能与实现可能变更；conda 安装渠道仍标记为 WIP。

  • 基于 Jupyter 协议的原生实现 xeus 构建，在 Notebook 中执行 ClickHouse SQL
  • 提供 Docker 镜像，通过 docker run 即可启动带有 xclickhouse 内核的 Jupyter
  • 支持从源码编译安装，依赖 xeus、clickhouse-cpp、Tabulate，并使用 examples/ 目录作为文档示例

适用场景（解读层）

  • 在 Jupyter Notebook 中编写并运行 ClickHouse SQL 查询
  • 通过 Docker/Binder 快速试用 ClickHouse SQL 笔记本环境
  • 参考 examples/ 中的示例学习内核用法
📖 README 首段存档原文 · 程序抽取

xeus-clickhouse is and early developer preview and is not suitable for general usage yet. Features and implementation are subject to change.
