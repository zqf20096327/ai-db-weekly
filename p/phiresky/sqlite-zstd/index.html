SQLite 扩展，提供基于 zstd 字典的透明行级压缩

综述（解读层）

sqlite-zstd 是一个 SQLite 扩展，对指定表的指定列做 zstd 字典压缩：原表数据移入 _table_name_zstd，原表名变为可正常执行 SELECT/INSERT/UPDATE/DELETE 的视图，从而在保留随机访问的前提下压缩行数据。通过 zstd_enable_transparent 配置，用 zstd_incremental_maintenance 分步执行压缩与字典训练（需另调 VACUUM 才能缩小文件）。作者自述尚未达到可放心托付数据的程度，建议保留备份。适合存储大量 blob/text 数据的 SQLite 用户。

  • 提供透明行级压缩：原表转为视图，SELECT/INSERT/UPDATE/DELETE 可照常执行
  • 提供 zstd_incremental_maintenance 增量维护函数，支持限定时长与数据库写入占比，可随时安全中断
  • 提供 zstd_compress/zstd_decompress/zstd_train_dict 等基础 SQL 函数，支持按 id 引用已训练字典及 compact 输出模式

适用场景（解读层）

  • 需要压缩 SQLite 数据库中 blob/text 大字段同时保留随机查询访问
  • 希望以增量维护方式逐步压缩存量数据并控制对在线写入的影响
  • 在 Python 项目或 Datasette 中以扩展方式加载使用压缩能力
