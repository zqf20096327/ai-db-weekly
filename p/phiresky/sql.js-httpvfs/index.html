🧭 简介解读层（AI·证据行可回查）

基于 HTTP Range 请求的只读虚拟文件系统，让浏览器直接查询静态托管的 SQLite 数据库

综述（解读层）

该项目是 sql.js 的分支与封装，将 SQLite 编译为 WebAssembly 在浏览器中运行，并通过基于 HTTP Range 请求的虚拟文件系统按需读取数据库页面，使静态文件托管（如 GitHub Pages）上的数据库可被前端 SQL 查询而不必完整下载。README 建议先为数据库建立合适的索引并调整 page_size，可选用脚本分块存储；依赖 WebAssembly 与 WebWorker 支持，且无缓存淘汰机制。

  • 通过 HTTP Range 请求按需读取数据库页面，浏览器端查询无需完整下载数据库文件
  • 提供分块存储脚本 create_db.sh，在主机有文件大小限制时拆分数据库并生成 json 配置
  • 虚拟文件系统包含带虚拟读取头的加速逻辑，顺序读取时加快获取速度

适用场景（解读层）

  • 将 SQLite 数据库托管在 GitHub Pages 等静态文件主机上，供浏览器端 SQL 查询
  • 通过 CDN 分块缓存机制，仅缓存用户实际访问的数据库块
  • 用于个人小型项目，配合索引优化实现按需读取数据
