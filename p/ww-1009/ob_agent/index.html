🧭 简介解读层（AI·证据行可回查）

基于 LangChain/LangGraph 的对话式 OceanBase 数据库诊断助手，通过 SSE 流式返回结果。

综述（解读层）

该项目面向 OceanBase 运维人员，提供自然语言问答式诊断：后端用 FastAPI 与 langchain create_agent 编排 11 个 DBA 工具，实时读取 OCP 元数据与只读 SQL，经 SSE 流式返回；前端为 Vue 3 + Vite 聊天界面。依赖 OCP 企业版 4.2.5，支持 mock 模式离线运行、执行 SQL 人工审批（HITL）及 Bearer 鉴权。

  • 提供 11 个 DBA 工具（慢 SQL 查询、执行计划解释、DDL 获取、计划对比等），OCP 客户端与 SQL 执行器采用双适配器架构，支持 mock/real 切换
  • 内置离线 mock fixture 数据，无需连接 OCP 或数据库即可端到端演示；SQL 执行器仅使用只读账号，execute_sql 可配置人工审批
  • 文档检索评估基于 5146 篇文档语料与 179 个真实问题，CI 按 recall@5 与 MRR 设门限，支持 sparse/hybrid/API rerank 三通道评测

适用场景（解读层）

  • OceanBase DBA 通过自然语言查询慢 SQL、租户/集群信息与执行计划
  • 无 OCP 或数据库环境的离线演示与功能验证（mock 模式）
  • 连接真实 OCP 4.2.5 与 OceanBase 企业版做只读诊断辅助
