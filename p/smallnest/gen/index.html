从数据库读取表结构生成 Go 结构体与 CRUD REST API 项目的代码生成工具

综述（解读层）

gen 是一个命令行代码生成工具，连接 MySQL、PostgreSQL、SQL Server、SQLite 或 MariaDB 数据库，读取表结构后生成带 gorm 标签的 Go 结构体，并可生成包含 Gin 服务器、DAO 层、HTTP 处理器、Makefile 的完整 CRUD REST 项目。支持通过模板目录、--exec 脚本和命名模板自定义生成结果。注意：非整型或字符串主键的表会被忽略。

  • 支持 MySQL、PostgreSQL、SQL Server、SQLite、MariaDB，读取主键、自增、可空等元数据生成 gorm 注解
  • 生成包含 Gin 服务器、DAO CRUD 函数、HTTP 处理器、Makefile、Swagger 注释的完整项目结构
  • 提供自定义模板目录、--exec 脚本及结构体命名模板等生成定制能力

适用场景（解读层）

  • 基于既有数据库表结构快速生成 Go 数据模型与 gorm 标签
  • 为数据库表生成完整的 CRUD REST API 项目脚手架
  • 需要自定义代码生成模板或项目布局的 Go 开发流程
