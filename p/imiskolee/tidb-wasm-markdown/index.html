markdown-it 插件，在 Markdown 中运行 TiDB Wasm 实例

综述（解读层）

该项目是一个 markdown-it 插件，用于在 Markdown 文档中嵌入并运行 TiDB Wasm 实例。使用者通过 ::: tisql 关键字标记 SQL 语句，解析 Markdown 生成 HTML 后自动启动 TiDB Wasm 实例并在编辑器中输出执行结果，适合在浏览器中构建交互式 SQL 学习环境。安装方式为克隆仓库后用 SimpleHTTPServer 启动本地服务查看 example.html。路线图显示后续将支持更多控制指令。

  • 通过 ::: tisql 关键字在 Markdown 中标记 SQL 语句
  • 点击 Parser 后自动启动 TiDB Wasm 实例并在编辑器输出结果
  • 在浏览器中提供交互式 SQL 运行环境

适用场景（解读层）

  • 编写包含可执行 SQL 示例的教程文档
  • 在浏览器中学习 SQL 语法
  • 构建交互式技术演示页面
