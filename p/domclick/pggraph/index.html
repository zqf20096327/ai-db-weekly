处理 PostgreSQL 表依赖关系的 Python 命令行工具

综述（解读层）

PgGraph 是一个 Python 编写的 PostgreSQL 表依赖处理工具，支持递归删除/归档指定主键的行、查找表间外键依赖及行级引用。通过 pip 安装，需配置 config.ini 指定数据库连接，归档时将行移入带 archive 后缀的同结构表。提供 CLI 和 Python API（PgGraphApi）两种使用方式，支持 debug 模式、分块大小和递归深度配置。

  • 支持按主键递归删除并归档表数据，归档行自动转入带 archive 后缀的同结构表
  • 提供 get_table_references 和 get_rows_references 命令，查询表的入向/出向外键依赖及指定主键行的引用
  • 可通过 config.ini 配置连接信息，支持 debug 模式、chunk_size 分块与 max_depth 递归深度限制

适用场景（解读层）

  • 删除或归档 PostgreSQL 中具有外键关联链的数据行
  • 分析指定表的外键依赖关系及引用情况
  • 在 Python 环境中通过 API 调用实现归档操作
