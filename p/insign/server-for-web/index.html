🧭 简介解读层（AI·证据行可回查）

一键自动化 shell 脚本，在 Ubuntu LTS 上安装运行 Laravel 所需的整套软件。

综述（解读层）

这是一个通过 curl/wget 一条命令执行的安装脚本，面向需要从零配置服务器的运维或开发者。它创建用户并安装 nginx/Apache、PHP-FPM、数据库、缓存、队列、Certbot 等组件，支持约 30 个可选参数按需跳过模块，结束后输出包含全部随机密码的报告。要求使用全新服务器与 root/sudo 权限，且 Ubuntu 18.04 支持已标记弃用，20.04 处于 BETA。

  • 单条命令完成安装：创建用户、配置 ufw/fail2ban、nginx（可选 Apache）、PHP 7.4 FPM、MariaDB/PostgreSQL、Redis、Memcached、Beanstalkd、supervisor、Certbot 及多个 DNS 插件
  • 额外安装 CLI 工具（ncdu、awscli、httpie、micro、mosh 等）与 zsh/oh-my-zsh 环境，创建 swap 文件并自动生成密码
  • 提供约 30 个可选参数用于跳过模块、指定密码、导入 SSH 公钥以禁用密码登录

适用场景（解读层）

  • 为 Laravel 或其他 PHP 框架初始化全新 Ubuntu 服务器（Web/数据库/缓存队列服务器可按参数组合拆分部署）
  • 通过 --key-only 参数导入 SSH 公钥并禁用密码登录的新机初始化流程
  • 按 README 示例组合参数，分别搭建 nginx+PHP Web 机、MySQL/PostgreSQL 数据库机或 Redis/Memcached/Beanstalkd 缓存队列机
