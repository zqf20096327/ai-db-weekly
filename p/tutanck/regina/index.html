基于 MongoDB 和 Socket.IO 的实时数据库服务器，客户端可直接调用数据库操作

综述（解读层）

Regina 是一个运行于 MongoDB 之上的实时数据库服务器，允许客户端通过 Socket.IO 直接执行 insert、find、update、delete、count、aggregate 操作。它支持基于 tags 的事件订阅，按 emit、broadcast、io 三种作用域向客户端推送请求结果及上下文。默认连接 localhost:27017 的 reginadb 并监听 3009 端口，可通过参数自定义数据库地址与端口。适用于已使用 MongoDB 并希望客户端直连数据操作的实时应用场景。

  • 支持客户端通过 Socket.IO 直接调用 insert、find、update、remove、count、aggregate 六种 MongoDB 操作
  • 支持基于 tags 的事件订阅，可携带请求结果与上下文推送给订阅的客户端
  • 提供 emit、broadcast、io 三种消息作用域，并可使用 IOS 和 Java 客户端接入

适用场景（解读层）

  • 需要客户端直接读写 MongoDB 的实时 Web 应用
  • 基于 tag 订阅向多个连接客户端推送数据变更结果的场景
  • 需接入 Socket.IO 协议的 JavaScript、iOS 或 Java 客户端项目
