Haskell 类型安全高层 SQL 库，支持 SQLite 与 PostgreSQL 后端

综述（解读层）

Selda 是一个用于与 SQL 关系数据库交互的 Haskell 库，设计受 LINQ 与 Opaleye 启发，适合需要在 Haskell 中操作数据库的开发者。它提供单子接口和类型安全的数据库 schema，支持建表、查询、插入、更新、删除，以及事务、外键等能力，后端覆盖 SQLite 与 PostgreSQL。要求 GHC 8.0+，SQLite 后端需 C 编译器，PostgreSQL 后端需 libpq 开发库。

  • 提供单子化接口与类型安全的数据库 schema，支持建表、查询（含过滤、连接、聚合）、插入、更新与删除
  • 支持事务、唯一性约束、外键及条件插入/更新，提供无缝的预编译语句
  • 后端可移植：提供 SQLite 与 PostgreSQL 两个后端，非核心功能拆分为附加包

适用场景（解读层）

  • 在 Haskell 项目中通过类型安全查询语言读写 SQLite 或 PostgreSQL 数据库
  • 需要对同一套代码在不同 SQL 后端间复用的应用开发
  • 使用 JSON 查询等后端特定类型安全功能的数据处理场景
