🧭 简介解读层（AI·证据行可回查）

Convex 后端的水平扩展实验分支，用分区加 Raft 与 2PC 保持原语义

综述（解读层）

这是 Convex 开源后端的一个实验性分支，目标是实现水平扩展，同时保留响应式订阅、可串行化事务和一致性快照等语义。项目通过表级分区、每分区 Raft 组、基于 NATS KV 的全局时间戳 oracle 及跨分区两阶段提交来组织集群，当前处于 alpha 阶段，README 列出了尚未完成的事项（如 Raft 统一提交点、Jepsen/Elle 验证），适合自托管 Convex 且关注集群化部署的开发者试用研究。

  • 按表分区分配写所有权，单分区写路由到属主分区，跨分区写使用两阶段提交
  • 每个分区运行 Raft 组实现 leadership 与持久化，并支持 NATS JetStream 提交增量复制
  • 通过 NATS KV 全局时间戳 oracle 和共享表编号分配器保持文档 ID 跨节点可移植

适用场景（解读层）

  • 自托管 Convex 并需要按表划分数据到多节点的研究性集群部署
  • 测试与验证分区化数据库中的 Raft 故障转移、两阶段提交和副本增量复制
  • 为分布式正确性验证（如 Jepsen/Elle 类测试）搭建可复现的本地 Docker 集群测试环境
