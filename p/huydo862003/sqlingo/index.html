SQLGlot 的 TypeScript 移植版，可在浏览器与 Node 中解析、转换、优化 SQL。

综述（解读层）

sqlingo 是 Python SQL 工具 SQLGlot 的 JavaScript/TypeScript 移植，在浏览器和 Node 运行时中提供 SQL 的解析、方言转换、优化、列血缘追踪和执行，覆盖 32 种方言。包为纯 JavaScript 实现，无需 WASM 或原生依赖，依赖 luxon 作为 peer dependency 处理日期时间。README 标注其处于 alpha 阶段，当前对齐 SQLGlot v30.5.0。适合需要在 JS 环境做 SQL 分析或转换的开发者。

  • 支持 32 种 SQL 方言的解析、转换、优化、列血缘、diff 与执行
  • 纯 JavaScript 实现，兼容浏览器与 Node 运行时，无 WASM 或原生依赖
  • 提供流式 API 的 SQL Builder，并支持注册自定义方言或覆写现有行为

适用场景（解读层）

  • 在浏览器端解析、转换或分析 SQL 语句
  • 跨方言（如 MySQL 转 DuckDB）转写查询语句
  • 基于 schema 优化查询、追踪列血缘，或以编程方式构建 SQL
