🧭 简介解读层（AI·证据行可回查）

基于 v$ 视图采集 Oracle 性能指标并以 Prometheus+Grafana 呈现的监控工具

综述（解读层）

kPerf for Oracle 是一个 Oracle 数据库活动监控工具，以 Python 实现，将采集到的指标写入 Prometheus 并用 Grafana 仪表板可视化。它面向 Oracle 数据库管理员，提供实例等待事件、SQL（SQLID/PHV）、会话和对象大小四类模块。使用需在数据库创建用户并授予 v_$ 视图与 dba_segments 等只读权限，无需创建对象或不依赖 Diagnostic/Tuning pack。程序由 Pyarmor 加密并内置许可证，运行环境要求 Python 3.11 与 Grafana 12.3.1，当前面向 linux.x86_64 平台。

  • 采集实例级与会话级数据，涵盖 v_$system_event、v_$sqlarea、v_$session、dba_segments 等 12 类视图，无需访问 ASH 或 Diagnostic/Tuning pack
  • 以 PULL 模式工作，指标仅在收到 GET 请求时采集；SQLID/PHV 与会话指标带有多个标签（SQLTEXT、WAITCLASS 等）可用于过滤和关联
  • 包含 InstanceWaitStat&SQL、SQL details、SESSION、DBSIZE 四个模块及配套 Grafana 仪表板，2.5.1 版新增 SQLTEXT 与 TNS 别名连接

适用场景（解读层）

  • 实时查看数据库等待事件、SQL 执行与活动会话，用于定位性能问题
  • 将历史指标存入 Prometheus，进行资源使用的长期趋势查看
  • 按表空间、OWNER、SEGMENT 等标签过滤查看数据库对象与数据文件大小，包括 CDB/Non-CDB 环境
