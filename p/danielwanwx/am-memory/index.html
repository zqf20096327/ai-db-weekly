为 Claude Code 提供基于 SQLite 的跨会话持久化记忆与 MCP 集成

综述（解读层）

am-memory 是一个面向 Claude Code 用户的持久化记忆工具，将对话与文件编辑中产生的知识存入本地单个 SQLite 文件，并通过 BM25 全文检索与可选的 Ollama 向量检索提供搜索。安装后通过 am init 注册 MCP 服务器并配置 SessionStart/Stop 钩子；内置 TTL/LRU 与 dream 整理机制，可进行过期清理、矛盾消解和冗余合并。要求 Python 3.10+，MIT 许可。

  • 提供 am_search、am_save、am_state_get/am_state_set 等 MCP 工具，搜索走分层级联，默认 BM25，可选混合向量检索
  • 知识库为单个 SQLite 文件（~/.am-memory/memory.db），含 TTL + LRU 生命周期，过期仅影响搜索索引不删物理文件
  • am dream 命令分 5 阶段做后台记忆整理，包括陈旧检测、跨文档矛盾扫描与冗余合并

适用场景（解读层）

  • 跨会话保留架构决策、调试结论、配置约束等技术知识，减少重复解释
  • 长周期项目调试：历史解决方案在新会话或新任务中被检索复用
  • 团队/个人知识库质量维护：自动清理陈旧引用、合并冗余文档、生成概念索引
