通过 Telegram 和 Web 面板监控管理 VPS 的 Python 机器人系统

综述（解读层）

该项目是一个基于 Python/Aiogram 3.x 的 Telegram 机器人，用于通过 Telegram 与 Web 界面（WebUI/PWA）监控和管理 VPS 或独立服务器，采用 Agent-Client 架构支持多节点接入。数据存储使用 SQLite，部署提供 Systemd 与 Docker 两种模式，GPL-3.0 协议，面向系统管理员、DevOps 和主机服务商。远程节点需运行客户端安装器并使用 token 接入。

  • 提供 CPU、RAM、磁盘、网络（HTTP/ICMP ping）的实时指标采集与 Web Push、Telegram 通知
  • 支持 WebUI 内的 SSH 终端、systemd 服务启停、定时备份与节点租用计费提醒
  • 采用 Agent-Client 架构管理多节点，支持 Docker Compose 与 Systemd 部署及 TLS 证书自动续期

适用场景（解读层）

  • 系统管理员通过 Telegram 远程监控多台服务器的资源状态与服务运行情况
  • VPN/主机服务商管理 X-ray/VLESS 面板并跟踪节点租用到期提醒
  • 需要 Web 终端、审计日志与 Fail2Ban 集成的自托管服务器运维场景
