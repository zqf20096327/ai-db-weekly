🧭 简介解读层（AI·证据行可回查）

基于 Docker Compose 的 PHP 开发环境模板，集成 Nginx、PHP-FPM、Xdebug 与 MariaDB。

综述（解读层）

该项目提供一套用 Docker Compose 编排的 PHP 开发环境，包含 PHP 8.5.1（PHP-FPM）、Nginx 1.29.4、Xdebug 3.5.0、PHPUnit 12.5.4、Redis 8.4.0 与 MariaDB 12.1.2，并内置 Composer。面向需要本地搭建 PHP 项目调试与测试环境的开发者。安装方式为克隆仓库后执行 docker compose up --build，README 附示例 PHPUnit 测试。

  • 提供由 Docker Compose 编排的服务组合：PHP-FPM 8.5.1、Nginx 1.29.4、Xdebug 3.5.0、PHPUnit 12.5.4、Redis 8.4.0、MariaDB 12.1.2
  • 包含 Composer 依赖安装与 PHPUnit 测试（含代码覆盖率）的执行命令示例
  • tests 目录中附带示例 PHPUnit 测试

适用场景（解读层）

  • 本地搭建 PHP 项目的 Web 开发环境
  • 通过 Xdebug 进行 PHP 调试
  • 在容器内运行 PHPUnit 测试与代码覆盖率分析
