🧭 简介解读层（AI·证据行可回查）

单二进制 Go 程序，用本地 SQLite 目录实现 MCP 工具的搜索式发现与代理调用

综述（解读层）

lazy-tool 是一个用 Go 编写的 MCP 运行时，为 agent 提供 MCP 工具的本地索引与代理服务。它读取 Claude Desktop、Cursor 或 VS Code 的配置自动导入 MCP 源，将工具、提示和资源索引到本地 SQLite 目录，并以 stdio 或 HTTP 作为 MCP 端点供 agent 连接。提供 direct、search、hybrid 三种模式：search 模式下 agent 只见 5 个元工具，通过先搜索后调用的方式访问上游工具；direct 模式按名称暴露全部工具并透明路由。面向需要聚合多个 MCP 服务器且希望本地运行的 agent 开发者。运行依赖 Go 1.25+ 构建和至少一个 MCP 源，缓存与嵌入搜索默认关闭需在配置中开启。

  • 单二进制 + 本地 SQLite，支持从 Claude Desktop/Cursor/VS Code 配置自动导入 MCP 源
  • 以 stdio 或 HTTP 作为 MCP 服务端运行，提供 direct/search/hybrid 三种代理模式
  • 搜索模式将上游目录压缩为 5 个元工具（search_tools、inspect_capability、invoke_proxy_tool、get_proxy_prompt、read_proxy_resource），检索结果带 why_matched 解释

适用场景（解读层）

  • 已配置多个 MCP 服务器、希望 agent 通过单一端点聚合访问并按需搜索工具的场景
  • 大工具目录（README 提及 50+ 工具）配合强模型使用 search 模式减少上下文占用的场景
  • 较小模型或偏好单步直调的部署使用 direct 模式的场景
