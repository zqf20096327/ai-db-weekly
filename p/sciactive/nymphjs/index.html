面向 Node.js 与浏览器的对象关系映射与应用数据访问框架

综述（解读层）

Nymph.js 是一个为 Node.js 和浏览器提供的应用数据与访问框架，包含 ORM、查询语言、用户组管理与访问控制、REST 服务器、PubSub 实时协作服务器及客户端。后端支持 SQLite3、MySQL、PostgreSQL，可开发用 SQLite、生产用 MySQL/Postgres。多个包按需组合使用，主要变更记录见 README 的 Breaking Changes 章节。

  • ORM 支持嵌套原子事务和查询语言，后端可选 SQLite3、MySQL 或 PostgreSQL
  • 提供 Express 中间件形式的 REST 服务器与基于 WebSocket 的 PubSub 服务器，可订阅实体、查询和 UID 的变更
  • Tilmeld 提供用户与组管理、细粒度访问控制、认证服务及 XSRF 防护

适用场景（解读层）

  • 需要在 Node.js 与浏览器间共享数据访问层并做实时协作更新的应用
  • 需要在开发环境用 SQLite、生产环境用 MySQL/PostgreSQL 的项目
  • 需要用户注册、登录与访问控制的 Web 应用，可配合 Tilmeld 相关组件使用
