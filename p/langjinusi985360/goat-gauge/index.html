本地运行的 Command Code GOAT 用量仪表盘，Python + SQLite 存储历史记录

综述（解读层）

GOAT Gauge 是面向 Command Code GOAT 用户的本地用量仪表盘，读取 CLI 同源的账户与计费端点，展示 5 小时滚动/周/月配额、额度余额、模型用量、缓存命中率和单次请求费用记录。历史存于本地 SQLite，API 密钥用 Windows DPAPI 加密，运行于 127.0.0.1。支持浏览器会话或 API key 两种凭据，非官方社区项目。

  • 提供 5 小时滚动/周/月配额环、重置倒计时、额度余额与模型用量环图
  • 本地 SQLite 累积用量记录，支持今日/7天/30天/全部时间范围及单请求成本表
  • 凭据支持浏览器会话（DevTools 捕获、DPAPI 加密存储）或 API key，遵循 *_proxy 环境变量与系统代理

适用场景（解读层）

  • 查看 Command Code GOAT 的配额、额度与计费周期统计
  • 分析模型用量、缓存命中率与单次请求成本
  • 在本地持久化用量趋势，弥补上游仅暴露有限窗口的限制
