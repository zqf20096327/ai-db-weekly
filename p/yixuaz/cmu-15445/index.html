CMU 15-445 数据库课程四个实验的参考实现与学习笔记集

综述（解读层）

该仓库包含 CMU 15-445（2017 版）四个实验项目的源码与作者解答，覆盖缓冲池、B+ 树索引、并发控制、日志与恢复。README 附中文博客链接、测试覆盖情况与 TODO 列表。作者提醒在校学生遵守课程独立完成要求，仅作自学参考。

  • 包含四个实验（Buffer Pool、B+ Tree、并发控制、日志与恢复）的解答，作者记录各项目测试数量并通过 make check 验证
  • 提供 SQLite 虚拟表扩展（libvtable），支持以 CREATE VIRTUAL TABLE 方式运行 SQL 语句
  • 附四个实验的中文学习笔记链接

适用场景（解读层）

  • 自学 CMU 15-445 课程实验时参考实现思路
  • 学习缓冲池、B+ 树、并发控制与 WAL 日志恢复机制
  • 通过 SQLite 虚拟表扩展观察课程数据库组件与 SQL 的对接方式
