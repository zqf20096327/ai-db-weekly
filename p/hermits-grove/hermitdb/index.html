🧭 简介解读层（AI·证据行可回查）

基于 Git 等分布式日志复制数据的私有去中心化数据库，用 Rust 编写。

综述（解读层）

HermitDB 是一个用 Rust 编写的去中心化数据库，通过 Git 或其他分布式日志复制数据，每个日志使用独立加密密钥。README 给出的示例依赖 sled 存储与 hermitdb crate，适合需要在用户自有的 Git 仓库上同步加密数据的开发者。当前实现每次编辑生成一条日志提交，尚未支持日志压缩。

  • 支持通过 Git 或任意分布式日志复制数据
  • 每个日志使用独立加密密钥，密码经 KDF 处理
  • 提供 Rust API，示例使用 sled 存储引擎与内存日志

适用场景（解读层）

  • 在用户自控的 Git 仓库上跨设备同步应用数据
  • 构建以私有日志为复制通道的本地优先应用
  • 对加密与数据主权有要求的分布式存储实验
