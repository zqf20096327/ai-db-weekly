基于三张SQLite表和递归查询为AI助手提供知识图谱记忆的开源套件

综述（解读层）

该项目是一个演示型知识图谱记忆系统，供AI助手在回答前通过钩子自动查询。核心由三张SQLite表、一个递归SQL查询和一个Claude Code提示钩子组成，无需服务器和API密钥。包含RAG与图谱两种方案，附带8篇建模文档、A/B对照组及测试用例。前提是Python 3和支持prompt hooks的助手。

  • 通过hooks.json在每次提示前自动运行SQLite递归查询并注入上下文文本
  • RAG层使用本地bge-small-en-v1.5模型（67MB，384维向量）由fastembed加载，无需API密钥
  • digest组件支持session和headless两种模式，将会话记录提炼为笔记并写入索引

适用场景（解读层）

  • 需要AI助手在回答前跨多文档链式查找事实（如策略→角色→持有人→代理人）的场景
  • 将Markdown笔记目录作为持久记忆源，配合Claude Code等支持钩子的助手使用
  • 自建文档的知识抽取：用extraction提示让LLM产出节点、边和别名后构建自己的图谱
