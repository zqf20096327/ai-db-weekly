综述（解读层）

Replication Manager 是 SIGNAL18 开发的 GPLv3 开源工具，用于 MariaDB、MySQL、Percona Server 复制拓扑及 PostgreSQL 集群（自 3.1.43 起）的监控、备份与高可用管理。它实现故障检测后的主库自动选举与切换、通过 mysqldump/mariabackup/xtrabackup 等执行计划备份，并集成 ProxySQL、HAProxy 等代理的自动化后端管理，支持 Kubernetes 部署。

  • 支持 GTID、多源、延迟复制及异步、半同步、多主、mesh、wsrep、组复制等拓扑的实时监控与检测
  • 通过 mysqldump、mydumper、mariabackup、xtrabackup 进行计划备份，支持 Restic 快照与时间点恢复、S3 兼容存储后端及保留策略自动清理
  • 实现领导选举与故障自动 failover、受控 switchover，并通过 REST 和 gRPC API 提供基于角色的访问控制

适用场景（解读层）

  • 需要多集群统一监控与 NOC 大屏展示的数据库运维团队
  • 依赖复制拓扑自动故障切换与主从切换的高可用场景
  • 在 OpenSVC 或 Kubernetes 上部署与管理数据库服务的环境
