🧭 简介解读层（AI·证据行可回查）

Python DataFrame API 到 SQL 的转译器，将计算下推到数据库执行

综述（解读层）

Grizzly 提供 trek自己实现的惰性 DataFrame 结构，记录过滤、投影、连接、聚合等操作序列，仅在需要结果时生成 SQL 语句并交由 DBMS 执行，并支持将 Python 标量 UDF 编译为过程式 SQL。适合需要在数据库内处理大规模数据、希望沿用类 Pandas 写法的 Python 用户。README 明确其 DataFrame 尚未完全兼容 Pandas，项目处于活跃开发中。

  • 惰性求值：操作仅在调用时才生成 SQL 并发送到 DBMS，可查看 generateQuery() 输出
  • 支持过滤、投影、连接、分组聚合（min/max/mean/count/sum）、Python UDF 及计算列
  • 可通过 UDF 机制在数据库内应用 TensorFlow、PyTorch、ONNX 模型

适用场景（解读层）

  • 数据已在关系型数据库中、希望用类 Pandas API 处理但避免客户端内存与 CPU 负载的场景
  • 需要将预训练的 ONNX/TensorFlow/PyTorch 模型应用于数据库内数据的机器学习推理
  • 生成并检查 SQL 的教学或研究场景（项目本身为研究项目）

Grizzly is a transpiler from a Python-API to SQL to move computations from the client into a database system.
