面向金融的开源知识图谱平台，以图数据库承载总账与XBRL数据供AI代理查询。

综述（解读层）

RoboSystems 是一个开源知识图谱平台，将自有总账、上市公司 SEC XBRL 文件及自定义图模型（Parquet 导入、Cypher 查询）整合于同一本体之上，运行在 LadybugDB 图数据库上。平台按租户提供独立图实例，通过 MCP 暴露子图工作区与语义记忆给 AI 代理；附带 RoboLedger（总账系统）与 RoboInvestor（组合研究）两个扩展。采用 Apache 2.0 许可，可单机部署或运行于自己的 AWS 账户，适合需要数据留存自有基础设施的财务与投资团队。

  • 支持三类图：自有总账、SEC XBRL 共享仓库与自定义 schema 图（Parquet 导入，Cypher 查询）
  • 报告可序列化为 holon（JSON-LD）、JSON 模型与 Arelle 校验的 XBRL 2.1 包；写入采用带 Idempotency-Key 与审计日志的 OperationEnvelope
  • 每个租户拥有独立图实例与 OLTP schema，子图工作区通过 MCP 供 AI 代理扩展，Docker 环境集成 Dagster、PostgreSQL、OpenSearch 等组件

适用场景（解读层）

  • 将公司总账数据以结构化、可溯源形式提供给 AI 代理进行查询与分析
  • 基于 SEC XBRL 文件构建上市公司对标与研究报告
  • 在自有基础设施上运行总账记账、关账流程与多期财务报告发布
