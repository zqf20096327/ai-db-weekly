🧭 简介解读层（AI·证据行可回查）

开源自托管后台管理系统，由 AI 编码代理按数据库表生成 TypeScript 管理页面

综述（解读层）

AntelopeJS DMS 是一个自托管的后台管理系统，通过粘贴 PostgreSQL、MySQL、MariaDB、MongoDB 或 RethinkDB 连接串，由 Claude Code 或 Codex 等编码代理生成管理页面和仪表盘，代码以 TypeScript 形式写入用户仓库。自身数据存于 MongoDB（或经 @antelopejs/mysql 存于 MySQL/MariaDB）。需 Node.js、Git 与 Docker Compose v2，默认只读，写操作需手动开启；助手仅在开发阶段运行，不进入生产环境。

  • 每张表生成含搜索、筛选、保存视图、导出的页面，支持网格、卡片、看板、分组列表四种展示，并提供 14 条带权限校验的 API 路由
  • 内置 41 个构建块（表格、表单、KPI 卡片与 13 种图表），标准页面无需前端代码，页面代码为可读可改的 TypeScript 类
  • 默认只读；支持细到每个动作的角色权限、登录、双因素认证、多租户与 SaaS 模式

适用场景（解读层）

  • 为已有产品的数据库快速生成管理页面与仪表盘的自托管后台
  • 从模板起步构建新产品的表结构和后台页面的内部工具项目
  • 需要在代码仓库中以 TypeScript 形式维护、可自定义块和权限的后台定制开发
