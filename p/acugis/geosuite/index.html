GeoSuite 是一键安装并管理开源 GIS 组件栈的安装脚本与控制面板

综述（解读层）

GeoSuite 通过一个 shell 安装脚本在 Ubuntu 24 LTS 上安装、配置 Apache Tomcat、GeoServer、PostgreSQL/PostGIS、PgRouting、QGIS Server、QuartzMap 等组件，并提供浏览器端控制面板统一管理各服务。所装软件均为未修改的原版，卸载面板后组件仍可独立运行。要求磁盘 15GB、内存最低 2GB。

  • 通过单个安装脚本部署 Tomcat、GeoServer、PostgreSQL、PostGIS、PgRouting、QGIS Server、QuartzMap 等组件
  • 提供基于浏览器的控制面板管理全部服务
  • 所有安装的软件保持原版未修改，控制面板可卸载且组件继续运行

适用场景（解读层）

  • 在干净的 Ubuntu 服务器上快速搭建包含 GeoServer 与 PostGIS 的 GIS 环境
  • 需要浏览器面板集中管理多个 GIS 相关服务的部署
  • 需要 PgRouting 或 QGIS Server 等附加地理空间组件的服务器配置
