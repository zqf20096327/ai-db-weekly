基于 TOML 配置文件为 TiDB 构建 MySQL 连接池的 Rust 库

综述（解读层）

tidb-pool 是一个 Rust crate，基于 sqlx 库封装了面向 TiDB 的 MySQL 连接池创建流程。使用者编写 TOML 配置文件填写主机、端口、用户名、密码、数据库名及可选的 SSL CA 证书路径，再调用 build_pool_from_config 函数即可获得 MySqlPool，支持配置最大/最小连接数、各类超时和懒加载模式。适用于需要在 Rust 异步项目中连接 TiDB 的开发者。创建失败时返回 sqlx::Error 由调用方处理。

  • 通过 TOML 文件配置连接信息与连接池参数（最大/最小连接数、获取超时、空闲超时、连接最大生命周期）
  • 基于 sqlx 库在异步环境中构建 MySQL 协议连接池，返回 Result
  • 支持可选 SSL（ssl_ca 指定 CA 证书路径）以及懒加载/立即建立两种连接初始化模式

适用场景（解读层）

  • Rust 异步应用中需要连接 TiDB 并管理连接池的场景
  • 希望将数据库连接配置从代码中分离、由 TOML 文件统一管理的项目
  • 需要按需懒建立连接或在启动时立即建立连接的不同部署场景
