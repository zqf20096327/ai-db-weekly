🧭 简介解读层（AI·证据行可回查）

用于分析 Neo N3 区块链数据的工具套件，含索引、API 与界面。

综述（解读层）

Shrike 是一组面向 Neo 区块链数据分析的工具集合，由四个组件构成：Indexer 与 NeoGo 节点同步并将链上数据处理写入关系数据库，API 以 REST 形式提供对已索引数据的查询，GUI 提供网页界面访问数据，Lib 为各组件共享的模型与方法库。每个组件有独立 README 说明使用方式，使用前需按对应组件文档分别安装运行。

  • Indexer 同步 NeoGo 节点并将区块链数据处理为关系数据库存储
  • 提供 REST API 用于查询已索引数据
  • 提供网页 GUI 用于与数据交互，组件间共享 Lib 库

适用场景（解读层）

  • 需要将 Neo N3 链上数据同步到 SQLite 等关系数据库的场景
  • 需要通过 REST API 查询已索引区块链数据的场景
  • 需要通过网页界面浏览区块链数据的场景
