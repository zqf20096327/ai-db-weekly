为 Godot 4.x 提供的 GDExtension SQLite3 封装插件

综述（解读层）

该项目通过 GDExtension 将 SQLite3 引入 Godot 4.0+，无需重新编译引擎或编写构建脚本，可通过 Asset Library 或手动下载安装。它提供 open_db、query、参数绑定及 create_table、insert_row 等方法，支持外键、只读模式（含 PCK 打包数据库）和查询结果返回。README 以游戏开发为标签，面向需要在 Godot 项目中读写本地 SQLite 数据库的开发者。

  • 提供 query、query_with_bindings、query_with_named_bindings 等方法，通过参数绑定实现参数清洗
  • 支持外键开关、只读模式（基于自定义 VFS 可读取打包在 PCK 内的数据库）
  • 支持 Mac OS X、Linux、Windows、Android（arm64）、iOS（arm64）及 HTML5

适用场景（解读层）

  • Godot 4.x 项目中存储与查询游戏本地数据
  • 通过 read_only 模式随游戏打包只读数据库并在 PCK 中读取
  • 需执行含 BLOB 二进制数据或带绑定参数 SQL 语句的场景
