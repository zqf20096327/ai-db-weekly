基于 Tauri 的跨平台多数据库图形化管理工具

综述（解读层）

DataSmith 是一款基于 Tauri 2.x（Rust 后端 + Vue 3 前端）的桌面数据库管理工具，面向需要同时操作多种数据库的开发者。它提供连接管理、表格数据查看编辑、SQL 编辑器（Monaco，带语法高亮与自动补全）、数据导入导出，以及数据对比、查询构建器、SQL 片段管理；密码经系统密钥环存储。关系型数据库经 SQLx 驱动，MongoDB 与 Redis 有专门驱动。项目采用 GPL-3.0 许可证，需 Node.js 18+ 与 Rust 1.70+ 从源码构建。

  • 支持 MySQL、PostgreSQL、SQLite、MongoDB、Redis 五种数据库的连接管理与数据操作
  • 提供 Monaco SQL 编辑器，支持语法高亮和自动补全
  • 密码通过系统密钥环存储，数据库驱动可经 Cargo feature flags 按需启用

适用场景（解读层）

  • 开发者在图形界面中查看和编辑关系型或 NoSQL 数据库数据
  • 需要将表格数据进行导入导出或在数据库间对比数据
  • 管理多个数据库连接并维护 SQL 查询片段
