🧭 简介解读层（AI·证据行可回查）

将 SQL 数据库结构转换为 JHipster JDL 格式的 Java 转换工具

综述（解读层）

sql-to-jdl 是一个 Java 工具，读取 SQL 数据库的 schema 并生成 JHipster 的 JDL 文件，供后续用 JHipster 构建 Angular-Java Web 应用。通过配置文件指定导出的 schema、忽略表、导出路径等；生成后仍需人工处理 ManyToMany 关系、枚举值和实体校验。运行需 git、maven 3 和 Java 17。

  • 支持 MySQL 5.7.x/8.x/9.x、MariaDB 10.x、PostgreSQL 9.x+，MsSQL 和 Oracle 支持尚不完整
  • 提供可配置项：schema 名称、忽略表、导出路径、对象前缀移除、未定义 JDL 类型处理（ERROR/SKIP/UNSUPPORTED）及类型覆盖
  • 内置规则：仅含 id 与 code/name 两列的表转换为枚举；仅含两个外键的表转换为 ManyToMany 关系

适用场景（解读层）

  • 为已存在于生产环境的数据库生成 JDL 文件
  • 实体和关系数量较多（如超过 100 个）时从现有数据库导出 JDL
  • 已有 MySQL Workbench 等数据库设计、需转换为 JHipster 项目结构的场景
