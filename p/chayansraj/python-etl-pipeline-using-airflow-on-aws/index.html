基于 Apache Airflow 在 AWS EC2 上编排 OpenWeather API 到 S3 的 ETL 管道教程项目

综述（解读层）

该项目演示如何用 Python 编写 ETL 管道，在 AWS EC2 上以 standalone 模式运行 Airflow，通过 HTTPSensor 检测 OpenWeather API 可用性，用 SimpleHttpOperator 按小时调度抓取 JSON 数据，再经 PythonOperator 转为 CSV 并写入 S3 存储桶。适合想了解 Airflow 连接配置、DAG 编写及 AWS 凭证授权流程的学习者。

  • 提供包含 API 可用性检测、数据抓取、转换加载三个任务的完整 DAG 示例
  • 支持通过 Airflow connections 和 HTTP operator 调用外部 API，并按 @hourly 等间隔调度
  • 演示 EC2 虚拟环境中安装 Airflow 与 pandas，以及配置 S3 访问权限的流程

适用场景（解读层）

  • 学习 Airflow DAG 编写与 HTTP operator 使用
  • 搭建 API 数据定期抓取并存入 S3 的管道实践
  • 了解 Airflow 在 AWS EC2 上的 standalone 部署方式

This project demonstrates how to build and automate an ETL pipeline written in Python and schedule it using open source Apache Airflow orchestration tool on AWS EC2 instance.
