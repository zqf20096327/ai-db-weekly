从 MySQL 数据库自动生成 Objection.js 模型的代码生成工具

综述（解读层）

Objection Model Generator 是一个 Node.js 代码生成工具，读取 MySQL 数据库的 information_schema 表获取表、列及 BelongsToOne 关系信息，自动生成对应的 Objection.js 模型文件。示例通过 dotenv 读取配置、fs 写出文件。适用于已有 MySQL 库并使用 Objection.js 的开发者。

  • 读取 MySQL information_schema 表获取表与列信息
  • 自动生成 Objection.js 模型文件
  • 自动识别 BelongsToOneRelations 关系

适用场景（解读层）

  • 为现有 MySQL 数据库批量生成 Objection.js 模型
  • 数据库表结构变更后重新生成模型代码
  • 减少手写模型与关系声明的重复工作
