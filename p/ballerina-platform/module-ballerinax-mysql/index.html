Ballerina 语言访问 MySQL 数据库的客户端库

综述（解读层）

该库为 Ballerina 程序提供连接和操作 MySQL 数据库的功能，通过 mysql:Client 对象执行查询、插入、更新、删除及批量更新操作。使用前需引入 ballerinax/mysql.driver 依赖（支持 8.0.13 以上驱动版本），支持 SSL 连接配置与可共享/独享的连接池管理，并支持 GraalVM 原生构建。

  • 提供 mysql:Client，支持查询、插入、删除、更新和批量更新操作
  • 支持 SSL 连接（提供 SSL_PREFERRED、SSL_REQUIRED、SSL_VERIFY_CA、SSL_VERIFY_IDENTITY 四种模式，密钥与证书须为 .p12 格式）
  • 支持三种连接池使用方式（全局共享、客户端独享、本地共享），并支持 GraalVM 原生构建与 Change Data Capture 的二进制日志配置

适用场景（解读层）

  • 在 Ballerina 应用中读写 MySQL 数据库数据
  • 需要参数化查询动态构建 SQL（含 IN 数组展开、查询拼接）的场景
  • 需要 SSL 加密连接或自定义连接池配置的数据库访问场景
