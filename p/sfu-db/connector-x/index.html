用 Rust 实现零拷贝数据加载的数据库到 DataFrame 读取库

综述（解读层）

ConnectorX 是一个以 Rust 编写、供 Python 调用的数据库读取库，通过 cx.read_sql 一行代码将 SQL 查询结果加载为 DataFrame。它按查询结果 schema 预分配内存，数据从源到目的地仅复制一次；指定 partition_on 数值列后可按分区多线程并行加载。支持 Postgres、MySQL、Oracle 等数据源，输出 Pandas、PyArrow、Polars 等格式，通过 pip install connectorx 安装。

  • 提供 cx.read_sql 单行接口，从数据库执行 SQL 并写入 DataFrame
  • 支持按数值列（不含 NULL）分区，多线程并行加载 SPJA 查询结果
  • 实验性支持跨多个数据库的联邦查询，同源 join 默认下推

适用场景（解读层）

  • 将 Postgres、MySQL、Oracle 等数据库中大表数据加载到 Pandas/Polars/PyArrow 进行分析
  • 对大查询按数值列分区并行拉取以缩短加载时间
  • 跨多个数据库的表编写单条 join 查询取数
