为 Ridgepole 提供 TiDB AUTO_RANDOM 列属性支持的 Ruby 扩展 gem

综述（解读层）

这是一个 Ruby gem，扩展 Ridgepole Schemafile 管理工具，使其支持 TiDB 的 AUTO_RANDOM 列属性：建表时写入 AUTO_RANDOM(n)、设置 AUTO_RANDOM_BASE、导出时解析 SHOW CREATE 回写选项，且不使用 ALTER 语句。使用 mysql2 或 trilogy 适配器连接，自动判定连接目标是否为 TiDB。适用于 Ruby 3.2+、Ridgepole 3.0.4+、ActiveRecord 7/8、TiDB v7.5.0+ 环境。

  • 在 create_table 列定义中生成 AUTO_RANDOM(n) 并抑制 AUTO_INCREMENT，支持 auto_random/auto_random_base 表选项的 schema 导出，apply→export→diff→apply 往返无差异（不使用 ALTER）
  • 自动检测连接目标是否为 TiDB，提供 auto_random_column? 列检测方法，兼容 mysql2 与 trilogy 适配器
  • RSpec 集成测试通过 docker compose 自动启停 TiDB 容器运行

适用场景（解读层）

  • 使用 Ridgepole 管理 Schemafile 且数据库为 TiDB 的 Ruby/Rails 项目
  • 需要在建表时使用 AUTO_RANDOM 分布式 ID 生成的表结构管理流程
  • 需要验证 TiDB 环境下 schema apply/export 幂等性的场景
