运行在开放数据格式上的实时分析数据库引擎

综述（解读层）

Pivot 是用 Rust 编写的分析型数据库，直接查询 Delta Lake 和 Iceberg 等开放格式的数据，无需将数据复制到独立的实时分析库。支持以服务器形式运行，也可作为本地引擎供用户和 Agent 直接查询数据源。项目处于早期开发阶段，版本间可能存在破坏性变更。

  • 基于 Rust 编写，实现 morsel-driven 并行、SIMD、NUMA 感知执行和缓存友好的聚合与连接等列式执行技术
  • 以对象存储作为后端存储，支持扩容、缩容和缩容至零
  • 支持 Delta Lake 和 Iceberg 开放数据格式，Pivot 写入的数据对其他查询引擎保持可读

适用场景（解读层）

  • 对存储在数据湖（Delta Lake / Iceberg）中的数据进行低延迟分析查询
  • 本地临时分析与 Agent 式分析，与仪表盘和应用内分析共享同一引擎
  • 不希望将数据复制到专用实时分析数据库的场景
