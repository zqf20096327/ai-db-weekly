纯 PHP 实现的零依赖扁平文件 JSON 文档型 NoSQL 数据库

综述（解读层）

SleekDB 是一个用 PHP 编写、无第三方依赖的 NoSQL 数据库，数据以纯 JSON 文件存储，运行时无需后台进程或网络协议，全部查询在同一个 PHP 进程内完成。README 说明它面向低到中负载场景，用于管理数 GB 级数据，不针对高并发 IO；支持 PHP 7+，可在共享主机或 VPS 上运行。

  • 数据以纯 JSON 文本存储，无需二进制转换，附带默认查询缓存层，缓存可自动重新生成
  • 无模式限制，支持对 JSON 文档的嵌套属性进行条件过滤（如 where('post.author.role','=','admin')）
  • 提供 where、orWhere、join、sort、search、groupBy、having、distinct 等查询与操作方法，支持文本搜索、多属性排序

适用场景（解读层）

  • PHP 项目中需要嵌入式持久化存储且无法安装数据库服务的环境（如共享主机）
  • 低至中等负载、数 GB 以内规模的数据管理场景
  • 需要便捷备份、导入导出的应用——数据即为文件，可直接复制处理
