基于 B+ 树的 Go 数据库存储引擎

综述（解读层）

DragonDB 是用 Go 编写的 B+ 树存储引擎，可在其中创建多棵 B+ 树，通过槽页（slotted page）组织节点、以 LRU 缓冲池管理内存页，并集成 WAL 用于崩溃恢复。采用 Direct I/O 绕过内核页缓存，要求 Go 1.19 以上及 POSIX 系统（Linux/macOS），MIT 许可证发布。

  • 支持创建多棵 B+ 树，每棵树允许多个并发读者或单个独占写者
  • 使用槽页格式存储变长记录并支持紧凑化，缓冲池以 LRU 策略缓存页
  • 内置 Write Ahead Log，页级修改先记日志、崩溃恢复时重放

适用场景（解读层）

  • 学习数据库存储引擎内部实现（作者在博客中逐层讲解构建过程）
  • 需要可嵌入 Go 程序的键值索引存储层
  • 研究 WAL、缓冲池管理与 Direct I/O 等工程问题的参考代码
