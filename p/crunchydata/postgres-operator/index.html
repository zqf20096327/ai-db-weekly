Crunchy Data 出品的 PostgreSQL Kubernetes Operator，以声明式方式管理数据库集群。

综述（解读层）

PGO 是 Crunchy Data 开发的 Kubernetes Operator，通过声明式配置管理 PostgreSQL 集群。它提供高可用（基于 Patroni 的分布式共识）、故障转移、pgBackRest 备份恢复、TLS 连接、pgMonitor 监控及连接池等功能，支持 S3/GCS/Azure 等备份存储。README 说明其安装流程会从 Crunchy Data Developer Portal 拉取容器镜像，该部分使用需遵循 Crunchy Data Developer Program 条款。

  • 提供高可用、备份恢复（pgBackRest 支持 full/incremental/differential）、监控（pgMonitor/Prometheus/Grafana）、连接池（pgBouncer）等能力
  • 支持将备份存储到本地、S3 协议对象存储、GCS、Azure Blob Storage 及多位置组合
  • 支持异步与同步复制、集群克隆、滚动更新、Pod 反亲和/节点亲和/容忍度配置，以及按命名空间限定管理范围

适用场景（解读层）

  • 在 Kubernetes、OpenShift、GKE、EKS、AKS 等平台上以声明式方式运行和管理 PostgreSQL 集群
  • 需要自动化故障转移、计划备份与灾难恢复方案的 GitOps 工作流场景
  • 需要从现有集群或备份克隆新集群、支持发布流程中各阶段数据库的环境
