Crunchy Data PGO Postgres Operator 的部署示例集合

综述（解读层）

该仓库包含一组用于在 Kubernetes 上部署、运维和维护 Postgres 集群的示例，基于 Crunchy Data 的 PGO Operator。示例按工具分类，每个附独立 README。使用前提是已运行 PGO（可经 kustomize 或 Helm OCI 安装），示例默认面向 Crunchy Postgres 镜像与 PGO v6 的 PostgresCluster v1 API，v5 需改用 v1beta1 后缀，采用 Apache 2.0 许可。

  • 提供按部署工具分组的 PGO 部署示例，每个示例附有独立 README 部署指南
  • 默认使用 PGO v6 的 PostgresCluster v1 API，并支持通过修改 apiVersion 后缀适配 PGO v5
  • 支持通过 kustomize 安装器（postgres-operator 仓库）或 Helm OCI registry 安装 PGO

适用场景（解读层）

  • 在 Kubernetes 上使用 PGO 部署 Postgres 集群时参考配置样例
  • 围绕 Postgres 部署配置高可用、灾备等主题标签所列能力的场景
  • fork 仓库并修改示例以实验和学习 PGO 的使用
