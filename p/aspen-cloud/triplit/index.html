🧭 简介解读层（AI·证据行可回查）

开源 TypeScript 包形式的全栈数据库，在服务端与浏览器间实时同步数据。

综述（解读层）

Triplit 是以 npm 包形式引入应用的开源数据库，服务端存储数据并通过 WebSocket 将查询结果同步到客户端，客户端内置完整数据库支持本地缓存。支持 Schema 定义、CRDT 协作、可插拔存储（SQLite、IndexedDB、LevelDB、Memory 等）及服务端读写鉴权，提供 CLI 脚手架、React/Svelte 绑定与管理控制台。

  • 通过 CRDT 实现属性级冲突解决与协作/多人编辑
  • 支持可插拔存储提供者，包括 SQLite、IndexedDB、LevelDB、Memory 等
  • 在服务端对读写强制执行授权，并提供 Schema 与 TypeScript 自动补全

适用场景（解读层）

  • 需要离线模式与自动重连、一致性保障的 Web/移动应用
  • 多用户实时协作或多人场景应用开发
  • 使用 React、Svelte 等框架并需实时查询更新的前端项目
