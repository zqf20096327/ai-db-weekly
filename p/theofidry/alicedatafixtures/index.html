🧭 简介解读层（AI·证据行可回查）

为 Nelmio Alice 加载的 fixtures 提供持久化层的 PHP 库

综述（解读层）

该库为 Alice 3.x 补充持久化能力：将 Alice 加载的对象写入数据库。面向 PHP/Symfony 开发者，支持 Doctrine ORM/ODM/PHPCR 与 Eloquent 多种驱动，可通过配置启用或禁用各驱动，并提供 Processor、排除清除表等高级用法，亦可用于 PHPUnit 与 Behat 测试。

  • 支持 Doctrine ORM 3.3+、ODM 5.1+、PHPCR 2.0+ 与 Eloquent 12.0+ 驱动，可通过配置强制启用或禁用
  • 提供 LoaderInterface 加载 YAML fixture 文件并持久化对象
  • 提供 Processor、排除清除表等高级用法，可集成 PHPUnit 与 Behat

适用场景（解读层）

  • 在 Symfony 应用中加载并持久化 Alice 生成的测试数据
  • 在 PHPUnit 或 Behat 测试中准备数据库 fixture 数据
  • 使用 Eloquent 或 Doctrine 多种 ORM 的 PHP 项目填充数据
