面向生物信息学与医学信息学的自动化图数据仓库与映射工具

综述（解读层）

BioDWH2 是一款基于图的数据仓库与映射工具，面向生物信息学和医学信息学领域，用于为研究分析或信息系统构建数据仓库。它以 Java 编写，仅需 JRE 11 及以上即可运行，无需其他前置依赖；支持多个官方数据源模块，也允许开发者按文档编写新的数据源模块，并可配合单独的 BioDWH2-Neo4j-Server 在 Neo4j 中使用生成的数据仓库。

  • 提供多个官方支持的数据源模块，并支持开发者自行编写新数据源模块
  • 仅依赖 Java 11 或更高版本的运行环境，开箱即用
  • 生成可用于 Neo4j 的数据仓库，配套 BioDWH2-Neo4j-Server 组件

适用场景（解读层）

  • 为研究分析搭建图数据仓库
  • 集成多个生物医学数据源并建立映射
  • 在 Neo4j 中查询和使用生成的数据仓库
