纯 Go 编写的终端 TUI 数据库查看与编辑工具

综述（解读层）

termdbms 是一个用 Go 编写的终端界面程序，用于查看和编辑数据库文件，支持 SQLite 和 CSV 文件。用户通过键盘（WASD、vim 风格按键）或鼠标浏览任意行数和列数的表格，可执行 SQL 查询、增删改数据并支持撤销/重做（限 SQLite），还能将 CSV 转换为 SQLite 数据库。适合需要在终端环境中直接操作 SQLite 文件的用户。

  • 支持 SQLite 与 CSV 文件的表格浏览，可处理任意行数和列数的表
  • 提供 SQL 模式执行查询与增删改操作，SQLite 支持撤销/重做，查询历史可存入剪贴板
  • 支持将修改序列化为副本或覆盖原文件（仅 SQLite），并可在 CSV 与 SQLite 格式间转换

适用场景（解读层）

  • 在无图形界面的服务器终端中查看和修改 SQLite 数据库文件
  • 执行 SQL 查询并将结果导出为 CSV 文件
  • 将现有 CSV 数据转换为 SQLite 数据库进行编辑
