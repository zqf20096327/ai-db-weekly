🧭 简介解读层（AI·证据行可回查）

纯 Python 标准库实现的离线 SQL 网页控制台，零第三方依赖运行。

综述（解读层）

面向无外网、不能安装客户端或 pip 包的内网运维/实施场景，提供浏览器访问的数据库查询工具。驱动以纯 Python 形式随包放在 vendor/ 目录，解压后仅依赖目标机的 Python 3.7+ 即可运行；内置账号登录、动态图片验证码与默认只读拦截，支持在界面中配置数据源并热加载。SQL Server 与 Oracle 驱动因仅提供平台相关二进制包，需离线场景自行补入对应 wheel。

  • 支持 PostgreSQL、MySQL/MariaDB、SQL Server、Oracle、达梦 DM8、SQLite、Redis 七种数据源，驱动按优先级自动降级并在缺失时明确报错
  • 强制登录采用 PBKDF2-HMAC-SHA256（20 万次迭代）与 32 字节随机会话 token，验证码 PNG 由标准库 zlib/struct 生成
  • 语句级只读保护，剥注释、按分号切分并保留 BEGIN…END 程序块完整性，默认拦截 INSERT/UPDATE/DELETE/DDL，可按数据源放开

适用场景（解读层）

  • 内网或信创环境（含麒麟 V10）中无法安装客户端与 pip 包的目标机上查询数据库
  • 需要多账号使用并按账号分配可见数据源与模式的团队共用控制台
  • 有安全扫描要求的现场，通过登录、验证码、限流与只读拦截提供访问入口
