🧭 简介解读层（AI·证据行可回查）

纯浏览器端 SQLite/SQL dump/CSV 打开、编辑与再导出的静态工具

综述（解读层）

editsqlite 是驱动 editsqlite.com 的静态站点，无后端：在浏览器中读取 SQLite 文件、mysqldump/pg_dump/sqlite3 生成的 .sql dump 或 CSV，以表格网格或 SQL 控制台编辑数据后导出新文件，原始文件不上传。读写字节级 SQLite 编解码均为手写 JS，也可在 Node 中使用。索引、视图、触发器不会被重建。MIT 许可。

  • 手写 SQLite 读取器与写入器，导出文件可通过官方引擎 PRAGMA integrity_check
  • 支持编辑表格网格与本地 SQL 控制台（SELECT/UPDATE/DELETE/INSERT），复杂查询懒加载 sql.js 只读执行
  • 含本地英文→SQL 辅助器与格式转换页（CSV↔SQLite、MySQL/Postgres→SQLite 等）

适用场景（解读层）

  • 在不上传文件的前提下本地查看和修改 SQLite/SQL dump/CSV 数据
  • 在 CSV、SQLite、MySQL/Postgres dump 之间做格式转换
  • 以 Node 脚本方式读取或生成 SQLite 文件
