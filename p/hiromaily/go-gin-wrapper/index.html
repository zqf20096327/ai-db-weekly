gin-gonic 框架的封装层，附带反向代理与示例实现

综述（解读层）

go-gin-wrapper 是对 gin-gonic/gin Web 框架的封装，附带反向代理功能，前端部分含 ES6 编写的 React 代码。项目始于 2016 年，作者用于学习 Golang，当前处于重构阶段，已完成 ORM 换用 sqlboiler、移除 MongoDB、接入 zap 日志等项。依赖 MySQL 与 Redis（作为会话存储），支持 Docker Compose、Heroku 部署，配置为 toml 文件并可对敏感信息做 AES 加密。

  • 登录支持 Google/Facebook 的 OAuth2 认证，API 使用 JWT 认证
  • 内置 Swagger API 文档生成与 pprof 性能分析端点
  • 配置为 toml 文件，支持通过 AES 加密敏感信息，可通过 Docker Compose 或 Heroku 部署

适用场景（解读层）

  • 作为 gin 框架封装与反向代理的运行示例
  • 需要 JWT/OAuth2 认证与 Swagger 文档的 Golang Web 项目参考
  • 基于 Docker Compose（MySQL+Redis）搭建本地开发环境
