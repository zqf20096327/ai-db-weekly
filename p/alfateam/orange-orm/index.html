🧭 简介解读层（AI·证据行可回查）

面向 Node.js/TypeScript 的对象关系映射库，无需代码生成

综述（解读层）

Orange ORM 是运行于 Node.js、Bun、Deno 的对象关系映射库，支持 TypeScript 与 JavaScript（含 CommonJS 与 ECMAScript）。开发者通过 map() 方法声明表与列的映射，用 hasOne/hasMany/references 定义表关系，支持 Active Record 风格操作及插入后的关联数据获取策略。数据库驱动需按需单独安装，SQLite 连接在 serverless 环境需显式关闭。

  • 支持 Postgres、PGlite、MySQL、MariaDB、MS SQL、Oracle、SAP ASE、SQLite、Cloudflare D1 等数据库
  • 通过 map()/column() 定义表映射，用 hasOne、hasMany、references 声明表关系，无需代码生成即可获得 IntelliSense
  • 提供 Express/Hono 插件以在浏览器端使用，服务端回放并验证客户端方法调用

适用场景（解读层）

  • Node.js/Bun/Deno 项目中访问关系型数据库
  • 在 Cloudflare Workers 等 serverless 环境连接 SQLite/D1
  • 浏览器端通过 Express/Hono 插件间接操作后端数据库
