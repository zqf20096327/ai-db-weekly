为 PHP/Laravel 提供 Cloudflare D1 数据库绑定的连接包

综述（解读层）

该包由 Composer 安装，为 PHP/Laravel 应用提供 Cloudflare D1 的连接支持。由于 D1 不支持 SQL 协议接入，它通过自定义 PDO 驱动将查询与绑定参数代理到 Cloudflare API 的 /query 端点执行；Laravel 侧可在 config/database.php 中注册 d1 驱动并配置令牌、账户 ID 与数据库 ID。当前已支持 D1，KV 与 Queues 尚未支持，README 中列出的 Vectorize 等标签未在正文体现。

  • 提供基于 PDO 的 D1 驱动，将查询代理到 Cloudflare API 的 /query 端点
  • 支持作为 Laravel 数据库连接（driver 为 d1）使用
  • 附带模拟 Cloudflare API 的内置 Worker 用于本地测试

适用场景（解读层）

  • Laravel 应用需读写 Cloudflare D1 数据库
  • PHP 项目需通过 HTTP API 方式执行 D1 SQL 查询
  • 本地测试需模拟 Cloudflare API 行为的集成测试环境
