基于SpringBoot与LLM的多数据源数据治理与分析平台

综述（解读层）

DataLoom是一个数据治理与分析平台，用户上传MySQL、API、Excel等数据源后，系统转换为统一存储格式，并支持通过自定义SQL或LLM生成数据集，提供自然语言问数、图表看板及分析报告功能。后端采用Spring Boot微服务架构（含网关、数据引擎、积分服务），需部署MySQL、RabbitMQ、Redis、XXL-JOB、Nacos等中间件，并配置Kimi大模型API密钥。MIT协议。

  • 支持上传MySQL、API、Excel等多种数据源并转换为统一存储格式
  • 支持自定义SQL、LLM自动生成数据集，以及自然语言问数获取数据
  • 包含后台管理、数据引擎、网关、积分与优惠券等微服务模块

适用场景（解读层）

  • 将分散在多数据源中的数据整合为数据集并做联合分析
  • 通过自然语言查询数据并生成可视化看板
  • 需要接入LLM进行自动化数据分析与报告生成的团队
📖 README 首段存档原文 · 程序抽取

传统数据可视化平台存在一些明显的缺点，例如需要用户具备一定的技术知识，因此对用户的技术要求较高。一次完整的数据可视化过程包括数据清洗、数据分析、数据可视化等多个步骤，操作起来较为复杂。DataLoom区别与传统的数据可视化平台，在用户上传数据源（支持MySQL、API、Excel等），系统即自动从元数据中识别出高价值数据，由LLM大模型进行自动化分析，也可支持用户自定义分析目标。
