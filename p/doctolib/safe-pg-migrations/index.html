让 Rails ActiveRecord 的 PostgreSQL 迁移更安全的 Ruby gem

综述（解读层）

safe-pg-migrations 通过 patch ActiveRecord::Migration 并扩展 ActiveRecord::Base.connection，将 add_reference、add_index 等潜在阻塞操作改写为安全版本，如并发建索引、分步添加外键约束等。面向使用 Rails 和 PostgreSQL 的开发者，仅需在 Gemfile 中加入一行即可启用。限制：不支持事务/语句池模式的 PgBouncer，迁移失败不会自动回滚。

  • 运行迁移前设置短 lock timeout（默认 5 秒）和 statement timeout，避免长时间阻塞其他语句
  • 强制使用 CREATE INDEX CONCURRENTLY / DROP INDEX CONCURRENTLY 创建和删除索引，并对此类语句将超时设为 0
  • 将外键和 check constraint 的添加拆分为先加不验证、后验证两步，缩短阻塞锁持有时间

适用场景（解读层）

  • 对大表执行加列、加索引、加外键等迁移且要求服务在迁移期间保持可读写的 Rails 项目
  • 开发者不完全熟悉 Postgres 锁机制，希望迁移代码无需手工编排 disable_ddl_transaction!、分步验证等细节
  • 通过 CI/CD 自动执行数据库迁移的团队，需要减少迁移引发的长事务与锁等待
