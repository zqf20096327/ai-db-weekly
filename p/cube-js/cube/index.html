开源语义层，以代码定义指标并通过 SQL/REST/GraphQL API 对外提供

综述（解读层）

Cube Core 是开源的无界面（headless）语义层，用代码定义指标、维度、关联和访问规则，再通过 SQL、REST 和 GraphQL API 供 BI 工具、自建应用或 AI 代理调用。它连接 Snowflake、Databricks、BigQuery、Presto、Postgres 等 SQL 数据源，内置关系缓存引擎。部署用 Docker，注意开发模式会关闭 JWT 验证，仅限本地使用。

  • 用代码统一定义指标、维度、关联和访问规则，并通过 SQL、REST、GraphQL API 暴露
  • 支持各类 SQL 数据源（Snowflake、Databricks、BigQuery、Presto、Amazon Athena、Postgres 等），内置关系缓存引擎
  • 不含 UI，无头运行，可与 BI 工具、自定义应用或 AI 代理集成

适用场景（解读层）

  • 为 BI 工具或嵌入式分析提供统一的语义层与 API
  • 为 AI 代理提供受治理的指标定义供其查询
  • 自托管（Docker 本地或部署）构建定制化分析产品
