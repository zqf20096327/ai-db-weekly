Berkeley DB 的历史存档与社区延续 fork，嵌入式事务性键值存储库

综述（解读层）

该仓库包含 Berkeley DB 完整发布历史的存档，以及在 master 分支上持续开发的社区 fork（Sleepycat 许可证，排除 AGPLv3 的 6.x+ 版本）。它以库形式嵌入应用，提供 B-tree/Hash/Queue/Recno 访问方法、ACID 事务、MVCC 与复制。fork 版本采用 CalVer，分常规版与 LTS 线；仓库亦披露相对 5.3.28 的基准数据与已知回归。

  • 提供 B-tree、Hash、Queue、Recno 四种访问方法，支持 ACID 事务、写前日志、MVCC 快照隔离与复制，以链接库方式运行，无服务器进程
  • historical 分支与标签存档 1.85（1992）至 5.1.29（2011）各版本及官方补丁，可用 git diff 对比任意版本
  • fork 发布采用 CalVer（如 v2026.10.8），LTS 线冻结磁盘/日志/region 格式与 ABI，仅接受修复，支持到下一 LTS 后 12 个月

适用场景（解读层）

  • 需要以库形式嵌入应用、无独立服务器进程的键值存储场景
  • 需要查阅或对比 Berkeley DB 历史版本源码与官方补丁的研究与维护工作
  • 依赖稳定格式与 ABI、需长期修复支持的嵌入式数据库部署（选用 LTS 线）
