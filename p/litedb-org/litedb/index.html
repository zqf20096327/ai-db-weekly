.NET 嵌入式 NoSQL 文档数据库，数据存储于单一文件

综述（解读层）

LiteDB 是用 100% C# 编写的嵌入式 NoSQL 文档数据库，面向 .NET 4.5 / NETStandard 1.3/2.0 环境，以单个 DLL（约 450kb）发布，无需独立服务器。它提供类 MongoDB 的 API、LINQ 查询、ACID 事务和 WAL 写失败恢复，数据存放于单文件中。README 提示其数据文件加密实现当前不安全，不应使用。可通过 NuGet 安装：Install-Package LiteDB。

  • 无服务器文档存储，100% C# 实现，单 DLL（小于 450kb）发布
  • 支持 ACID 事务、线程安全、WAL 日志实现写失败后数据恢复；v5 引入新存储引擎，读操作无锁、写锁按集合粒度
  • 支持 POCO 到 BsonDocument 映射（特性或 fluent mapper）、文档字段索引、LINQ 查询、SQL-Like 命令、跨文档引用，以及文件/流存储，并提供 BsonSerializer 写入调用方缓冲区的重载（IBufferWriter 重载仅在 net8.0/net10.0 构建中提供）

适用场景（解读层）

  • 桌面或本地小型应用程序的数据存储
  • 用作应用程序文件格式
  • 小型网站/应用，或每账号/每用户一数据库的数据存储
