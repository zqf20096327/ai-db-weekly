PingCAP 官方示例项目，演示 Java 通过 MyBatis 连接 TiDB 执行 CRUD 操作

综述（解读层）

该项目是 PingCAP 提供的示例代码仓库，包含一个使用 MyBatis 持久层框架连接 TiDB 集群并执行基本增删改查操作的 Java 应用。项目要求 JDK 17+ 与 Maven 3.8+，通过 env.sh 配置连接信息，支持 TiDB Cloud Serverless、Dedicated 及自建 TiDB 三种连接方式，运行 make 命令即可执行示例。适合希望了解 Java 应用接入 TiDB 的开发者作为起点。

  • 提供连接 TiDB Cloud Serverless、TiDB Dedicated 与自建 TiDB 三种环境的配置示例
  • 基于 MyBatis 框架实现基本的 CRUD 操作
  • 通过 env.sh 环境变量管理连接配置，Serverless 场景要求开启 SSL

适用场景（解读层）

  • Java 开发者学习使用 MyBatis 连接和操作 TiDB 数据库
  • 作为 Java 应用接入 TiDB 的代码模板
  • 验证 TiDB 集群与 Java 开发环境的连通性
