使用 mysqljs/mysql 驱动连接 TiDB 并执行基础 CRUD 操作的 Node.js 示例代码

综述（解读层）

该仓库提供一套 Node.js 示例代码，演示通过 mysqljs/mysql 驱动（纯 JavaScript 实现的 MySQL 协议客户端）连接 TiDB 集群并执行增删改查。面向 Node.js 开发者，运行流程为：克隆仓库、npm install 安装 mysql 与 dotenv 依赖、在 .env 文件中填写连接参数、npm start 执行。README 支持 TiDB Serverless、TiDB Dedicated 和自建 TiDB 三种集群的配置方式，并注明 Serverless 公网端点必须启用 TLS 连接。

  • 提供连接、插入、查询、更新、删除五类 SQL 操作的代码片段，使用参数化占位符传入查询值
  • 支持通过 .env 环境变量配置连接参数，并提供 Serverless、Dedicated、自建三种集群的配置步骤
  • README 附带最佳实践说明：连接池管理、查询值转义、BIGINT/DECIMAL 列启用 supportBigNumbers 选项

适用场景（解读层）

  • Node.js 应用需要连接 TiDB 集群时参考连接配置与代码示例
  • 学习和验证 mysqljs/mysql 驱动对 TiDB 的基础 CRUD 操作
  • 接入 TiDB Serverless / Dedicated / 自建集群时按对应章节配置连接参数
