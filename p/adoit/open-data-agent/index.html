🧭 简介解读层（AI·证据行可回查）

本地 CLI 工具 oda，以只读方式和自动生成的 Schema 文档桥接自然语言与 SQL 数据库。

综述（解读层）

Open Data Agent 是运行在本地的命令行工具，供数据分析师、开发者和 AI 编码代理（主要是 OpenCode）查询 PostgreSQL、MySQL、SQLite 数据库。其机制包括：从活库生成 Markdown Schema 目录作为上下文、通过白名单加黑名单强制只读、自动注入 LIMIT 与超时、零行结果时输出结构化诊断信息供代理自我修正。需 Python 3.12+ 与 uv，无密钥链环境密码以明文回退存储。

  • 默认只读：查询经白名单（SELECT/WITH/EXPLAIN 等）与黑名单双重检查，写操作被硬阻断且无绕过机制
  • `oda docs generate` 从数据库内省生成分层 Markdown 目录，`--enrich` 可附加空值数、去重数、最值等列统计
  • 零行结果或错误时 DiagnosticEngine 输出行数、样本值、NULL 数等结构化诊断；查询自动写入 JSONL 历史日志

适用场景（解读层）

  • 数据分析师做探索性数据分析（EDA），无需记忆表结构即可查询已连接数据库
  • 将 oda 作为 OpenCode 等 AI 代理的只读数据库工具，实现自然语言到 SQL 的查询流程
  • 开发者临时执行 SQL，依赖自动 LIMIT 注入、超时和查询历史保障安全
