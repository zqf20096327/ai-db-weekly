在 RPC 上安全执行客户端组合的类型化 SQL 查询构建器

综述（解读层）

Typegres 提供 SQL over RPC 能力：客户端基于服务端 @expose 标记的方法组合类型化查询闭包，经序列化后由服务端受限解释器求值，仅能访问暴露面。类型由 Postgres 目录与 SQLite 文档代码生成，覆盖基础类型、运算符并在类型层跟踪可空性。支持 Postgres、PGLite、SQLite 多驱动与 .live() 实时查询。README 标注为开发者预览，不建议生产使用。

  • 类型代码生成覆盖 Postgres/SQLite 的基础类型、函数与运算符，并在类型层跟踪可空性
  • 客户端只能通过 @expose 标记的方法组合查询，闭包在服务端受限解释器下求值
  • 支持 .live() 实时查询与 Cap'n Web RPC 传输，驱动按需从 typegres/drivers/* 显式导入

适用场景（解读层）

  • 浏览器客户端直接组合类型化 SQL 查询、由服务端控制可访问面的应用
  • 需要实时订阅推送（如基于 Cloudflare Durable Objects 的全栈应用）的场景
  • 需要同一套 schema 类与查询构建器运行于 Postgres 与 SQLite 两种方言的项目
