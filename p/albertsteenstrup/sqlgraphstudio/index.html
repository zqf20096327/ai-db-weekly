🧭 简介解读层（AI·证据行可回查）

面向 SQLite 与 PostgreSQL 的原生 macOS 数据库浏览器，支持交互式模式图。

综述（解读层）

SQLGraphStudio 是一款运行于 macOS 15+ 的原生数据库浏览器，面向需要查看与操作 SQLite、PostgreSQL 数据库结构的开发者。它将外键关系渲染为可交互的模式图，提供行浏览、查询与导出；SQLite 支持行编辑与模式修改，PostgreSQL 为只读。还可解析 SQL 迁移文件生成纯结构模型，无需运行数据库服务，并通过内置 MCP 服务器连接 Codex、Claude Code 等 AI 编码代理。

  • 将外键关系呈现为交互式模式图，支持搜索表并以分组和注释组织大型模型
  • 支持打开 SQLite 文件、PostgreSQL 连接文档或备份，以及项目文件夹与 SQL 迁移文件
  • 内置 MCP 服务器与三个技能，可将模式图与数据展示接入支持的 AI 编码代理

适用场景（解读层）

  • 浏览与编辑本地 SQLite 数据库，查看行及其关联关系
  • 从 `.postgres`/`.pgstudio` 连接文档或 PostgreSQL 备份中只读浏览模式与数据
  • 通过版本化 SQL 迁移文件探索模式结构及其历史，无需数据库服务器
