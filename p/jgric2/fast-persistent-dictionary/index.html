C# 持久化键值字典，键驻内存、值存盘，用 Grobuf 序列化

综述（解读层）

FastPersistentDictionary 是一个 C# 持久化字典库：键保留在内存、值写入磁盘，通过 Grobuf 序列化复杂对象，支持压缩、保存/加载、CompactDatabaseFile 手动压缩文件，并实现 .NET 的 IEnumerable 与 ISerializable 接口。API 与标准 Dictionary 用法一致，可被多线程访问，单个值最大 2GB。适合需要在 .NET 应用中以字典方式读写大量持久化数据的开发者。README 基准数据显示其在 N=1000000 时 Add 约 2.3 秒。

  • 键保留在内存中，值存储在磁盘，数据以单文件形式保存与加载
  • 使用 Grobuf 序列化，任意可被 Grobuf 序列化的键/值类型均可使用
  • 支持多线程访问、值最大 2GB、数据压缩及 CompactDatabaseFile 手动缩减文件体积

适用场景（解读层）

  • 需要以 Dictionary 方式操作大量持久化数据的 .NET 应用
  • 键值读取频率高、同时需要数据落盘保存与加载的场景
  • 需要在多个线程间共享同一持久化键值集合的程序
