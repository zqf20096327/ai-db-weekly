🧭 简介解读层（AI·证据行可回查）

基于 React + Electron + Java 17 的 macOS 多数据库桌面连接工具

综述（解读层）

该工具是运行在 macOS（arm64）上的数据库桌面客户端，支持达梦、MySQL、MongoDB、Redis、PostgreSQL、Oracle、SQL Server 与 SQLite 八种数据库的连接、对象浏览、SQL 执行与导出。前端 React、核心逻辑由 Java 17 后端实现，密码与 SQL 历史经 AES-256-GCM 本地加密存储；另提供 stdio MCP 入口供 Claude Code 等 AI 客户端复用连接。DM/Oracle 驱动需按服务器版本自行导入，部分高级能力（表设计器、序列）仅限 DM/MySQL。

  • 支持八种数据库的连接管理、懒加载对象浏览、表数据预览与列/约束/索引/DDL 查看
  • Monaco 多标签 SQL 工作台，每标签独立 JDBC 会话与事务状态，支持多结果集与执行取消
  • 内置 stdio MCP 服务，默认只读模式，可分级开启写入与完全权限

适用场景（解读层）

  • macOS 上统一管理多种关系型及 MongoDB/Redis 连接并浏览对象、执行 SQL
  • 通过 MCP 入口让 Claude Code 等 AI 客户端以只读方式查询已保存的数据库连接
  • 导出查询结果或整表数据为 CSV / INSERT SQL 文件
