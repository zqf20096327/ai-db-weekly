zqlite.zig：封装 SQLite C API 的轻量级 Zig 数据库包装库

综述（解读层）

zqlite.zig 是 Zig 语言的 SQLite 包装库，为 SQLite C API 提供薄封装。面向使用 Zig 0.16.0 的开发者，经 SQLite3 3.53.0 测试。它提供 Conn 连接类型、参数化查询、行迭代器、类型化取值接口及线程安全的 Pool 连接池。默认静态编译捆绑的 SQLite amalgamation，也可通过 system_sqlite3 选项动态链接系统 SQLite。使用时需在 build.zig 中链接 libc。

  • 提供 row/rows/exec/execNoArgs 等查询与执行接口，支持参数化绑定与事务（含 exclusiveTransaction）
  • Row 提供类型化取值方法，支持 i64、f64、bool、text、blob 等及其 nullable 版本；非 nullable 版本省去一次 sqlite3_column_type 调用
  • 包含线程安全的 Pool 连接池，支持固定连接数与 on_connection/on_first_connection 回调

适用场景（解读层）

  • 在 Zig 项目中读写 SQLite 数据库
  • 多线程应用中通过连接池复用 SQLite 连接
  • 需要静态或动态链接 SQLite 的 Zig 程序构建场景
