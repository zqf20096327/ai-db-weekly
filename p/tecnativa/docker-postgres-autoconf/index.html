在启动前自动生成 Postgres 配置的 Docker 镜像

综述（解读层）

该 Docker 镜像在容器 entrypoint 阶段根据附加 Docker 网络的动态 IP 范围，区分 LAN 与 WAN 来源，自动生成 postgres.conf 和 pg_hba.conf，供通过容器运行 Postgres 并需按网络来源管理访问的用户使用。配置通过环境变量完成；镜像不校验用户设置，证书、TLS 与密码需使用者自行保证正确。

  • 在 entrypoint 阶段检测附加 Docker 网络的 IP 范围，区分 LAN 与 WAN 连接并生成对应 postgres.conf 与 pg_hba.conf
  • 通过 CERTS 变量或挂载 /etc/postgres/ 下 PEM 文件配置 ssl_ca_file、ssl_cert_file、ssl_key_file 等参数
  • 支持 LAN/WAN 分别的认证方式、连接类型、数据库、用户、TLS 开关配置，并可用 CONF_EXTRA 与 HBA_EXTRA_RULES 追加自定义配置和 pg_hba 规则

适用场景（解读层）

  • 在 Docker 环境中按网络来源（LAN/WAN）自动化配置 Postgres 访问控制
  • 为远程客户端启用基于证书的 cert 认证与 TLS 加密连接
  • 需要自定义 pg_hba.conf 规则而不手工维护配置文件的容器化部署
