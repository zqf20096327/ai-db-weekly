🧭 简介解读层（AI·证据行可回查）

基于 JDBC 的关系型数据库子集提取与关联数据浏览工具

综述（解读层）

Jailer 是一款开源数据库工具，包含两个组件：Subsetter 从生产库中提取引用完整的数据子集，导出为拓扑排序 SQL、JSON、YAML、XML 或 DbUnit 记录；Data Browser 支持沿外键或自定义关系双向浏览数据。基于 JDBC 技术，只要有驱动的数据库均可连接，并对十余种数据库提供专门支持。提供 Windows/Linux 安装包及跨平台 zip，需 Java 环境；内置演示数据库可免配置试用。

  • 提取引用完整的数据子集，导出为拓扑排序 SQL-DML、JSON、YAML、XML 和 DbUnit 格式
  • 沿外键或用户定义的关系双向浏览数据库，SQL 控制台支持代码补全、语法高亮与图表
  • 通过 JDBC 支持任意数据库，并为 PostgreSQL、Oracle、MySQL、SQL Server、Db2、SQLite 等提供专门支持

适用场景（解读层）

  • 为开发和测试环境创建小规模、引用完整的生产数据样本
  • 在本地环境中使用相关生产数据做问题分析
  • 在不破坏引用完整性的前提下删除和归档过时数据
