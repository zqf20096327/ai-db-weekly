汇总 TiDB 运维脚本与配置文件的工具集仓库

综述（解读层）

该仓库整理了 TiDB 运维中常用的脚本与配置文件，涵盖 br 备份恢复、dm 部署拓扑、dumpling 本地及 S3 备份、lightning 导入、磁盘挂载、系统参数优化、minio 安装、mysql-client 离线包等，均以可执行脚本和现成配置文件形式提供。面向 TiDB 运维人员，拿来即用；minio 安装包通过百度网盘链接分享。

  • br-backup.sh 支持日志备份、快照备份及按周期定期备份并按保留天数定时清理
  • install/topy 目录包含单机测试、生产多节点、大单行、3 物理机混合部署（含 NUMA 绑核）等多种拓扑配置文件
  • 包含磁盘挂载、系统参数优化、手动收集表统计信息、导出用户与资源管控语句等运维脚本

适用场景（解读层）

  • 搭建 TiDB 测试或生产集群时套用现成部署拓扑文件
  • 对 TiDB 集群执行快照/日志备份与数据恢复
  • 离线环境安装 mysql-client 及进行日常运维操作（统计信息收集、用户导出等）
📖 README 首段存档原文 · 程序抽取

该代码工程是一个tidb工具类的工程，里面汇总了各种工具的脚本和配置文件，包括br的备份和恢复脚本，dm的部署拓扑，dumpling的本地和s3备份的脚本，数据库安装中磁盘挂载、系统参数优化和不同场景的部署拓扑文件，lightning的配置文件和启动脚本（包含从本地或从s3同步），minio的安装脚本，mysql-client的rpm安装包和包括运维中使用的手工收集统计信息和导出数据库用户等脚本。
