基于 MySQL 语法族的 SQL 评分、美化与 EXPLAIN 解析命令行工具

综述（解读层）

mSQL 是一个对 SQL 进行优化和改写的自动化命令行工具，通过 git 克隆源码后用 Go 编译并运行 sh.php 构建，配置数据库 DSN 后即可用 -q 参数执行 SQL 查询并输出评分与解析结果。它基于启发式算法进行语句优化，仅支持 MySQL 语法族协议，Windows 环境未全面测试。

  • 支持基于启发式算法的语句优化及多列索引优化（UPDATE/INSERT/DELETE/SELECT）
  • 支持 EXPLAIN 信息解读、SQL 指纹、压缩与美化
  • 支持同一张表多条 ALTER 请求合并及自定义规则的 SQL 改写

适用场景（解读层）

  • 对 MySQL SQL 语句进行打分、压缩和美化
  • 解读 EXPLAIN 输出并获取索引优化建议
  • 合并同一张表的多条 ALTER 请求或按自定义规则改写 SQL
