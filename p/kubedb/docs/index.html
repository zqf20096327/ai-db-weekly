KubeDB 官方文档站点，介绍其在 Kubernetes 上部署管理数据库的用法

综述（解读层）

该仓库是 KubeDB 的文档源，内容涵盖架构概述、各云厂商安装指引、任务操作指南、运维手册（推荐配置与维护窗口），以及 CLI、operator 与 webhook-server 的命令行、配置和 API 参考。面向需要部署和使用 KubeDB 的用户，文档托管带版本号的目录结构。发现问题时可通过 issue 或提交贡献反馈。

  • 包含 Overview、Setup、Guides、Operator Manual 等文档板块
  • 提供 CLI、operator 与 webhook-server 的命令行选项、配置选项和 API 定义的详细列表
  • 文档支持按版本组织的菜单结构与 URL 别名

适用场景（解读层）

  • 在各类云提供商上安装 KubeDB 前查阅安装说明
  • 学习 KubeDB 架构并按指南执行数据库管理任务
  • 配置 KubeDB 的建议与维护窗口等运维事项
