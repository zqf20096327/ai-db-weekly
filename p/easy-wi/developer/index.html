基于 PHP/MySQL 的游戏与语音服务器 Web 管理面板，含自动化租借 CMS

综述（解读层）

Easy-WI 是一个用于管理游戏服务器与语音服务器（TS3/TSDNS）守护进程的 Web 界面，附带可自动化游戏及语音服务器租借业务的 CMS。面向托管服务商、赞助商、LAN 活动组织者、战队及个人用户。运行需 PHP 7.4+、MySQL 及指定扩展，游戏模块另需 sudo、cron、proftpd 与 bash。提供 REST API、多语言、模板回退机制及移动端适配界面。

  • 提供游戏服务器与 TS3/TSDNS 语音服务器的自动化部署、监控与修复管理
  • 全部模块支持 REST API，可与 WHMCS、Magento 等现有商店流程集成
  • 默认模板基于 Twitter Bootstrap 实现响应式，支持英语、丹麦语、意大利语、德语，文本以 XML 维护，PHP 模块与 HTML 视图分离且模板缺失时回退默认视图

适用场景（解读层）

  • 托管服务商管理并自动化出租游戏及语音服务器，可设置经销商账户
  • 管理战队服务器、赞助服务器或 LAN 活动的游戏与语音服务
  • 通过 REST API 将服务器管理接入 WHMCS/Magento 等已有业务流程
