基于 Kafka 的 Python 消费者，实现 MongoDB 到 MySQL 的变更数据捕获

综述（解读层）

该项目提供一套 MongoDB 到 MySQL 的 CDC 流程示例：通过 Kafka Connect 加载 MongoDB Source Connector 将变更写入 Kafka 主题，再用 Python（kafka-python）编写的消费者读取数据并记录 offset 与 topic 日志，可用 Supervisord 托管脚本并通过其 Web UI 监控。适合需要在 Kafka 环境中同步 MongoDB 数据变更的开发者参考部署。

  • 支持通过 confluent-hub 安装 MongoDB Kafka Connect 连接器，配置 Source/Sink 连接器
  • 消费者基于 kafka-python 模块读取新数据并写入包含 offset 和 topic 的日志文件
  • 提供 Supervisord 配置用于运行 Python 脚本，并可开启 Web 监控界面

适用场景（解读层）

  • 将 MongoDB 的数据变更经 Kafka 同步到下游 MySQL 环境
  • 需要记录消费者 offset 与 topic 日志的 Kafka 消费流程
  • 使用 Supervisord 托管和监控 Python 消费者进程的部署场景
