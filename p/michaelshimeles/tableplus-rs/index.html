用 Rust 和 egui 编写的原生数据库 GUI，支持 PostgreSQL、MySQL、MariaDB 与 SQLite。

综述（解读层）

tableplus-rs 是一个以 Rust 编写、基于 egui 的桌面数据库 GUI，不依赖 Electron 或 Web 视图，产物为约 30 MB 的单一二进制。它面向需要本地图形界面管理 PostgreSQL、MySQL、MariaDB 和 SQLite 的开发者，提供 SSH 隧道、TLS、分页数据网格、暂存式编辑和带自动补全的 SQL 编辑器。macOS 为主要目标平台，也可在 Linux 构建运行；不连接 Redis、MongoDB。

  • 支持 PostgreSQL、MySQL 8、MariaDB、SQLite 连接，含 SSH 隧道（密码/私钥）和五档 TLS 模式
  • 数据网格采用虚拟化绘制与服务端分页（100–20,000 行/页），编辑分阶段暂存并以单事务提交，可预览生成的 SQL
  • SQL 编辑器提供方言语法高亮、别名感知的自动补全、按语句分标签的结果展示与可搜索的查询历史

适用场景（解读层）

  • 开发者在本地或远程服务器（经 SSH 隧道/TLS）上浏览、过滤、排序和编辑数据库表数据
  • 需要将表结构变更以 ALTER 语句形式预览后再执行的数据库结构维护
  • 通过 CSV/JSON/SQL INSERT 导入导出，或以流式方式导出整表数据
