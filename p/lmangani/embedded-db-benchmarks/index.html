在 GitHub Actions 中运行嵌入式 OLAP 数据库基准测试的项目

综述（解读层）

该项目使用 Python 3.x 对多种嵌入式 OLAP 引擎（chdb、duckdb、glaredb、databend、datafusion）执行基准查询，测试在 GitHub Actions 的免费低配运行器上进行。README 明确声明结果不作为严谨基准。查看最新结果需查阅 Action 报告；复现需克隆仓库后用 poetry 安装依赖并运行 run.sh 脚本。

  • 使用 Python 3.x 执行基准查询，覆盖 chdb、duckdb、glaredb、databend、datafusion 五种引擎
  • 基准测试在 GitHub Actions 中自动运行，结果发布于 Action 报告
  • 通过 poetry 管理依赖，提供 run.sh 脚本一键运行

适用场景（解读层）

  • 在免费低资源运行器上对比多种嵌入式 OLAP 引擎的查询表现
  • 获取各引擎最新一轮基准测试的 Action 报告数据
  • 克隆仓库本地复现基准测试流程

This project benchmarks embedded OLAP engines using Python 3.x Benchmark queries for supported databases are executed within Github Actions.
