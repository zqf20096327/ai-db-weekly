ClickHouse 指标导出器，将周期性查询结果发布为 Prometheus 指标

综述（解读层）

ClickHeus 是一个 ClickHouse 自定义指标导出器，按配置周期执行 ClickHouse 查询，将查询列映射为标签和数值，经 gauge/histogram 类型的 metric bucket 聚合后通过 /metrics HTTP 端点发布为 Prometheus 指标。行为由 config.js 定义，适用于需把 ClickHouse 查询结果接入 Prometheus 抓取体系的场景。README 标明活跃开发已转移至 promcasa。

  • 按配置的刷新率周期性执行 ClickHouse 查询，并将列映射为指标标签与数值
  • 支持 gauge 与 histogram 两种 metric bucket 类型进行结果聚合
  • 通过配置的 /metrics HTTP 端点以 Prometheus 格式暴露指标

适用场景（解读层）

  • 将 ClickHouse 表中按时间窗口聚合的查询结果（如状态计数）导出为 Prometheus gauge 或 histogram 指标
  • 为已在 Prometheus 监控体系中的 ClickHouse 数据源建立周期性自定义指标采集
  • 通过 config.js 定义多个查询与指标桶，向 Prometheus 暴露带标签的业务统计指标
