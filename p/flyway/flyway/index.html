综述（解读层）

Flyway 是 Redgate 维护的开源数据库迁移工具，用于在多个实例间演进数据库模式。可运行于 Windows、macOS、Linux、Docker 和 Java 环境，集成 Maven 与 Gradle，支持 Oracle、SQL Server、MySQL、PostgreSQL 等 50 多种数据库管理系统。仓库提供文档与 OSS 版下载；带 GUI 的 Redgate 商业版不属于此开源项目。

  • 支持 50+ 数据库管理系统，含 Oracle、SQL Server、MySQL、PostgreSQL、MongoDB、Snowflake 等
  • 可运行于 Windows、macOS、Linux、Docker 和 Java，支持 Maven 与 Gradle 构建工具
  • 提供 SBT、Ant、Spring Boot、Grails 等第三方插件集成

适用场景（解读层）

  • 在多实例数据库间执行模式变更的团队
  • 将数据库变更纳入 Maven/Gradle 构建流程的项目
  • 连接 CI/CD 流程管理数据库部署的场景
