🧭 简介解读层（AI·证据行可回查）

以 JSON 模式运行 barman 命令、输出 Prometheus 指标的备份导出器

综述（解读层）

该工具用 Python 3 编写，通过调用 barman 的实验性 JSON 输出获取备份状态并转换为 Prometheus 指标，供使用 Barman 管理 PostgreSQL 备份的运维人员监控。默认作为服务监听 127.0.0.1:9780，指标每小时缓存刷新；也可经 cron 以 -f 参数写文本文件，由 node_exporter 解析，此时无需 Prometheus 抓取配置。

  • 提供 barman_up、barman_backups_failed、barman_last_backup_copy_time 等指标，barman_up 将 barman check 结果的 OK/FAILED 映射为 1.0/0.0
  • 支持服务模式（-l 指定 HOST:PORT，默认 127.0.0.1:9780，缓存每小时刷新）和文本文件模式（-f 输出供 node_exporter textfile 收集器读取）
  • 可通过 pip3 install barman-exporter 安装，依赖 prometheus_client 和 sh 模块，README 附带 systemd 服务文件与 Grafana 仪表盘 JSON

适用场景（解读层）

  • 监控 Barman 管理的 PostgreSQL 备份服务器的备份成败与检查状态
  • 以 cron 定时运行并写入 textfile 目录，通过 node_exporter 采集指标而不暴露服务端口
  • 使用随附的 grafana-dashboard.json 在 Grafana 中展示备份指标
