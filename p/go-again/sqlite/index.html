Go 语言的纯 Go（CGo-free）SQLite 驱动及配套功能模块

综述（解读层）

gosqlite 是一个不依赖 CGo 的 SQLite 驱动，同时注册 sqlite 与 sqlite3 两个驱动名，兼容既有 mattn、modernc 等驱动的导入路径与 DSN 写法。除 database/sql 接口外，还提供向量检索、FTS5 全文检索、RRF 混合排序、页面级加密 VFS、自定义 VFS、有界页缓存、sessions/changesets 及 ext/ 目录下的 SQL 扩展等类型化 API。适合需要在 Go 项目中无需 C 工具链使用 SQLite 及其扩展功能的开发者。

  • 纯 Go 实现，注册 sqlite 与 sqlite3 两个驱动名，兼容既有导入路径与 DSN 参数
  • 提供类型化的向量检索（sqlite-vec）、FTS5 全文检索与 RRF 混合排序 API
  • 支持页面级加密（vfs/crypto）、自定义 VFS、有界页缓存与 sessions/changesets

适用场景（解读层）

  • 需交叉编译或静态链接、避免 C 工具链依赖的 Go 应用
  • 在 SQLite 上构建向量检索、全文或混合搜索的场景
  • 需要对数据库文件进行页面级加密或实现自定义存储后端的场景
