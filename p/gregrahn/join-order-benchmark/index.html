Join Order Benchmark 查询集的分发仓库

综述（解读层）

该仓库收录 Join Order Benchmark（JOB）查询，源自 2015 年 PVLDB 论文《How Good Are Query Optimizers, Really?》，由第三方维护以方便查询分发（如作为 git 子模块）。查询针对论文使用的数据集（2013 年 IMDB CSV）设计，并提供在 PostgreSQL 中通过 imdbpy2sql.py 导入数据的分步流程；用于其“Frozen Data Set”可能产生异常结果。

  • 包含论文《How Good Are Query Optimizers, Really?》(PVLDB Vol.9 No.3, 2015) 中的 JOB 查询
  • 提供基于 imdbpy 的 PostgreSQL 数据导入分步说明及 schema.sql 建表脚本
  • 提供 2013 年 5 月版本 IMDB CSV 数据集的下载链接

适用场景（解读层）

  • 评估查询优化器的连接顺序处理
  • 作为 git 子模块分发 JOB 查询以用于数据库实验
  • 构建与论文一致的 IMDB 测试数据环境
