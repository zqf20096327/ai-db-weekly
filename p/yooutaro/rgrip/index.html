🧭 简介解读层（AI·证据行可回查）

macOS 原生 PostgreSQL 客户端，内置 PostGIS 数据地图显示。

综述（解读层）

rgrip 是面向 macOS 的 PostgreSQL 客户端，用 Rust 编写（基于 tokio-postgres 与 egui），单二进制约 10 MB。除常规 SQL 查询、表格编辑、导入导出外，内置地图视图显示 PostGIS 数据，网格选中行与地图要素联动，支持 WGS84、Web Mercator、UTM 投影。适合日常 Postgres 工作及不打开桌面 GIS 的情况下检查空间数据。项目为 alpha 阶段，未公证的 zip 首次启动需手动放行。

  • 网格与地图联动：选中行在地图高亮，可在地图框选以按区域过滤表格，支持暗色/浅色/街道/卫星底图
  • 导入 CSV、TSV、GeoJSON、Shapefile，带预览、可编辑列名与类型、SRID 猜测，行写入在单事务内完成
  • 地图排版导出 PDF/PNG，含标题、图例、比例尺、指北针；SQL 控制台带自动补全、格式化与斜杠命令

适用场景（解读层）

  • 日常 Postgres 查询、表格编辑与表结构调整工作
  • 在不打开桌面 GIS 的前提下查看、检查和加载 PostGIS 空间数据
  • 按版面（A4/A3/Letter）排版地图并导出 PDF/PNG 用于出图
