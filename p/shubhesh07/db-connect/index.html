支持八种数据库引擎的原生桌面客户端，基于 Go + Wails 构建

综述（解读层）

DB Connect 是一款桌面数据库客户端，连接 MySQL、PostgreSQL、Redshift、DynamoDB、Redis、MongoDB、Elasticsearch/OpenSearch 与 ClickHouse，提供 SQL/PartiQL 编辑、schema 浏览、EXPLAIN 可视化与数据导出。面向需要同时操作多种数据库的后端开发者。凭据经 AES-256-GCM 加密存于系统钥匙串，无云同步；macOS 可用 Homebrew 安装，另提供 Windows 安装包。

  • 支持八种数据库引擎，提供 SQL 编辑器、schema/table 浏览器、上下文自动补全、EXPLAIN 可视化及 CSV/JSON/Excel 导出
  • 内置本地 MCP 服务器，供 MCP 客户端执行只读查询，需 per-install auth token、连接白名单与限时写入授权
  • 无云同步与遥测，凭据以 AES-256-GCM 加密并存放于操作系统钥匙串

适用场景（解读层）

  • 后端团队需在同一界面内访问 MySQL/PostgreSQL 事务库与 Redshift/ClickHouse 分析库
  • 需要通过可视化 Scan/Query/GetItem 构建器或 PartiQL 编辑器操作 DynamoDB，并使用 access key、SSO profile、IAM role 等多种 AWS 认证
  • 希望让 Claude Code、Cursor 等 MCP 客户端在授权范围内读取已建立的数据库连接并执行查询
