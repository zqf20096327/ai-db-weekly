PostgreSQL 外部数据包装器，将 RocksDB 作为 PG 的外部存储引擎接入

综述（解读层）

pgrocks-fdw 是一个 PostgreSQL 扩展，实现了连接 RocksDB 的外部数据包装器（FDW），使 PostgreSQL 可以以 RocksDB 作为外部存储引擎。由于 RocksDB 是嵌入式键值存储，使用该扩展无需额外运行独立服务。构建需要 C++20 编译器，目前仅支持 PG18，且存在限制：不支持回滚/中止、不支持二级索引、表建后不能增删列、首属性须为主键。适用于 VidarDB 团队维护，亦兼容类 RocksDB API 的系统。

  • 实现 Foreign Data Wrapper，将基于 LSM 树的 RocksDB 接入 PostgreSQL，嵌入式运行无需额外服务
  • 提供 make uninstall 卸载流程和 sql 目录下的 SQL 语句测试脚本，支持 run_tests.sh 自动比对结果
  • 可通过 VIDARDB=true 编译选项用于 VidarDB 引擎，也支持其他类 RocksDB API 的系统（需自行检查兼容性）

适用场景（解读层）

  • 在 PostgreSQL 中以 RocksDB 作为外部存储引擎读写键值数据
  • 为 VidarDB 引擎（版本 <= 1.0.0）提供 FDW 接入
  • 需要在 PostgreSQL 18 环境中通过 Docker 容器运行带 RocksDB 的 PostgreSQL
