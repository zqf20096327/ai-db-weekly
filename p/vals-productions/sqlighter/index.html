面向 Android 与 iOS 的面向对象 SQLite 实现，含 ORM，兼容 J2ObjC。

综述（解读层）

SQLighter 为 Android 和 iOS 移动平台提供基于 SQLite 的数据库访问层，接口设计类似 JDBC，支持参数绑定执行 select/insert/update/delete 及 join 查询。其内含的 AmfibiaN ORM 子项目提供属性映射、关联加载、自动建表、JSON 映射和数据库 schema 版本升级管理。代码可经 Google J2ObjC 工具从 Java 翻译为 Objective-C 复用于 iOS，也可在单一平台独立使用；README 提示该实现不完整复刻 Android 的 SQLite 实现。

  • 提供类似 JDBC 风格的 SQL 接口，支持参数绑定（含 NULL 绑定）执行查询与变更语句
  • AmfibiaN ORM 子项目支持属性映射、关联加载、自动生成表、JSON 映射及 schema 版本升级管理（AnUpgrade 类）
  • 符合 J2ObjC 代码翻译标准，提供 Android 与 Objective-C 两套库，同一示例代码经翻译后输出一致

适用场景（解读层）

  • 需在 Android 与 iOS 间共享数据库逻辑代码的跨平台移动应用
  • 需要在 iOS 项目中直接使用 Objective-C 库访问 SQLite 的场景
  • 需要将领域对象在原生状态、JSON 与数据库存储之间转换的移动应用
