Oracle Graph 官方示例库，含属性图/RDF/GraphRAG 示例与 80+ 图算法样例

综述（解读层）

该仓库收录 Oracle Graph 的示例与演示，覆盖属性图、RDF 图、知识图谱及 GraphRAG 等方向。Oracle Graph 是 Oracle AI Database 26ai 与 Oracle Database 19c+ 的原生功能，使用该库需具备相应数据库环境，并可选用 SQLcl、Graph Studio 或 Python/Jupyter 运行示例。内容按数据库版本与主题分目录组织，并附兼容性与迁移说明。

  • 提供 80+ 内置图算法示例，含 PageRank、Louvain、Dijkstra、中介中心性等
  • 包含 GraphRAG、向量语义搜索与图模式匹配结合、从非结构化文本构建知识图谱的示例
  • 支持 SQL:2023 属性图语法、PGQL（19c）、SPARQL 1.1 及 RDF/RDFS/OWL 本体推理示例

适用场景（解读层）

  • 在 Oracle AI Database 26ai 或 Oracle Database 19c 环境中学习创建和查询属性图
  • 构建基于知识图谱的 GraphRAG 应用示例
  • 查阅 PageRank、社区发现、最短路径等图算法示例
