Oracle 数据库官方示例模式集，用于文档与 SQL/PL/SQL 演示

综述（解读层）

该仓库提供 Oracle 数据库官方示例模式，基于一家虚构的跨国销售公司构建，包含 HR（人力资源入门）、CO（客户订单，支持 JSON 半结构化数据）、SH（销售历史大数据量演示）三个维护中的模式及若干已归档模式。适合学生、开发者运行 Oracle 文档与培训材料中的示例，通过各目录下的 <schema_name>_install.sql 脚本安装。

  • 包含 HR、CO、SH 三个维护中的示例模式，以及 OE、PM、OC 等已归档但可用的模式
  • CO 模式支持以 JSON 存储半结构化数据，适用于电商事务演示
  • 提供各模式对应的 _install.sql 与 _uninstall.sql 安装卸载脚本，并生成安装日志供校验

适用场景（解读层）

  • 在自己的数据库环境中运行 Oracle 文档与培训材料中的示例
  • 学习 SQL 与 PL/SQL 的入门到中级主题（HR 为入门设计）
  • 电商事务及 JSON 半结构化数据、大数据量分析场景的演示环境搭建
