🧭 简介解读层（AI·证据行可回查）

把 VCD 波形、SystemVerilog RTL 与仿真日志整合进单个 SQLite 调试数据库的 CLI 工具

综述（解读层）

xevdb 将 VCD/FST 波形、解析后的 RTL 源码（模块、端口、信号声明）及仿真日志（UVM/iverilog/Questa 等）写入一个自包含的 .xevdb SQLite 文件，提供波形查询、X/Z 追踪、波形 diff 与参数化 SQL prompt 等命令。面向硬件仿真调试人员。RTL 解析依赖外部 Rust 解析器，无 Rust 时该功能不可用；要求 Python ≥3.10、Rust ≥1.75 与 git。

  • 支持 VCD/FST（经 fst2vcd）与 xtrace 输入，数据库内含信号值变化、RTL 全文与结构化仿真日志事件
  • 提供 X/Z 追踪子命令（summary/first/propagate 等）与两库波形 diff，定位最早分歧信号
  • 内置 42 条参数化 SQL prompt，含跨波形/RTL 联查；结果缓存于数据库内

适用场景（解读层）

  • 仿真挂死或 X/Z 传播的根因定位：从最早 X/Z 信号追溯到驱动它的 RTL file:line
  • golden 与 DUT 波形的回归比对，按信号报告最早分歧时刻
  • 将波形、源码、日志打包为单个 .xevdb 文件供同事离线查询或共享
