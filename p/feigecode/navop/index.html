🧭 简介解读层（AI·证据行可回查）

基于 Rust 与 GPUI 的原生桌面工作区，集成数据库、SSH、远程桌面与 AI 工具。

综述（解读层）

Navop 以同一原生核心发布三款应用：Navop 全功能版、Navop Shell（远程操作）、Navop Data（数据库工具），面向需要同时管理多种数据库和远程服务器的开发者与运维人员。它用 GPUI 实现 GPU 渲染、不含 WebView；内置 MySQL、PostgreSQL、SQLite、DuckDB、SQL Server、Oracle 连接，ClickHouse、达梦、人大金仓等以扩展驱动提供。许可为 Apache-2.0 及补充条款，提供 sha256 校验文件，macOS 首次运行需手动清除隔离标志。

  • 内置 MySQL、PostgreSQL、SQLite、DuckDB、SQL Server、Oracle 等数据库支持，ClickHouse、TDengine、达梦、KingbaseES、OceanBase、openGauss 等通过可安装扩展驱动提供
  • 提供 SSH/SFTP/FTP 终端与文件管理、端口转发、RDP/VNC 远程桌面，Windows 下可嵌入 MSTSC ActiveX 控件，其他平台使用纯 Rust 的 IronRDP 后端
  • 三个应用共享 AI 工作台、Notes、团队同步、扩展市场和 Public MCP 服务器，可通过 CLI 与 Agent Skill 向外部 Codex、Claude 等 MCP 客户端暴露工具

适用场景（解读层）

  • 在同一桌面环境中连接并查询多种数据库、执行 SQL、查看执行计划、绘制 ER 图与进行数据迁移
  • 管理远程服务器：SSH 终端、SFTP 文件传输、端口转发与 RDP/VNC 远程桌面操作
  • 通过 Public MCP 和 @navop/cli 将主机工具接入 Codex、Claude Code 等外部代理与自动化流程
