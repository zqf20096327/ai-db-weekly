Rust 动态 SQL 查询构建器，以 AST 方式生成 MySQL/Postgres/SQLite 语句

综述（解读层）

SeaQuery 是面向 Rust 开发者的动态 SQL 查询构建器，以抽象语法树形式构造表达式、查询与 schema 语句，通过统一接口生成 MySQL、Postgres、SQLite 三种方言的 SQL。它是 SeaORM 的基础组件，提供 SQLx、postgres、rusqlite 集成；全部依赖可选，所有 workspace crate 声明禁用 unsafe 代码。MS SQL Server 支持归入 SeaORM X。

  • 通过统一接口为 MySQL、Postgres、SQLite 构建查询与 schema 语句，运行时按用户输入动态拼接条件
  • 参数与表达式内联绑定，自动处理 $N 序号；1.0 版提供支持命名参数、嵌套字段访问、数组与元组展开的 raw_query! 宏
  • 提供 Iden derive 宏、聚合函数、类型转换、自定义函数及建表/改表/外键/索引等 schema 语句接口

适用场景（解读层）

  • 需要在运行时依据用户输入动态构造 SELECT/INSERT/UPDATE/DELETE 查询的场景
  • 需要同一套查询逻辑适配多种数据库后端的应用
  • 作为 SeaORM 底层或配合 SQLx、rusqlite 构建数据库访问层
📖 README 首段存档原文 · 程序抽取

SeaQuery is a query builder to help you construct dynamic SQL queries in Rust. You can construct expressions, queries and schema as abstract syntax trees using an ergonomic API.
