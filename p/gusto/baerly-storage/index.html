运行在自有 S3/R2 桶中的文档数据库，无数据库服务器，提交靠条件写入日志对象

综述（解读层）

baerly-storage 是一个以 TypeScript 库形式嵌入请求处理器的文档数据库：数据存于用户自有的 S3/R2 桶，无数据库进程或守护服务。写入通过 create-if-absent 创建编号日志对象完成提交，读取按集合日志折叠为行。面向 Cloudflare Workers 等边缘应用与小型内部工具，API 为 8 个动词、约 12k token 表面积。限制：仅单集合线性化，跨集合写入非原子，无 SQL 与 join。

  • 提供 8 个动词（first/all/count/get/insert/update/replace/delete）与 where/order/limit 修饰符的文档 API，无 DDL 与 SQL
  • 每次写入以 If-None-Match 条件创建下一编号日志对象作为提交，实现按集合线性化，请求结束后不留常驻进程
  • 支持 baerly export --target=postgres 生成按集合的 SQL 快照导出；提供多租户前缀与 Cloudflare Access、JWKS 认证方案

适用场景（解读层）

  • 以单一集合为核心访问模式的小型应用，如待办清单、单看板、活动 RSVP、单频道聊天
  • Cloudflare Workers/R2 边缘部署且希望复用已过安全审查的存储桶的内部工具
  • 需人工或 LLM 直接操作 API 的原型与小流量后端，后续可经 postgres 导出迁移
