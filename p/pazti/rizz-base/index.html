Node.js 本地优先加密数据库，每个项目为一个 AES-256-GCM 加密的 .rizz 文件

综述（解读层）

Rizzbase 是面向 Node.js/TypeScript 开发者的本地优先数据库，数据以 AES-256-GCM（PBKDF2 600,000 次迭代）加密的单个 .rizz 文件存储，由单独安装的 Go 引擎处理，通过本地 stdin 传递密钥。V1 无索引与云端服务，查询将 Lobby 读入内存过滤，单文件上限 64 MiB，无口令恢复机制。另提供 Python SDK、CLI 与 Wails 桌面应用 Studio。

  • 支持 AES-256-GCM 加密与 PBKDF2-HMAC-SHA256 密钥派生，密钥仅经 stdin 传给本地引擎
  • 提供 Node.js 20+/Python 3.10+ SDK 与 Go 引擎，支持 AND 过滤、orderBy、limit 及 JSON 导出/恢复
  • create()/export/import 均拒绝覆盖已有文件，支持 JSON 备份迁移实现口令轮换

适用场景（解读层）

  • 需要本地加密存储 JSON 文档、无云服务的 Node.js 应用
  • 需要可移植加密文件备份与明文 JSON 快照导出的数据管理
  • 通过示例应用（Notes/Todo）学习过滤排序查询与持久化更新
