基于 JDBC 的 HTTP/REST 风格 SQL 数据库访问服务器框架

综述（解读层）

AceQL HTTP 是一个 Java 库，通过 HTTP 提供对远程 SQL 数据库的 REST 风格 API 访问，客户端可用 cURL 直接调用，也可使用 C#、Java、Python 的 SDK。服务器端通过 properties 文件配置数据库连接（支持 Tomcat JDBC 连接池）、SQL 防火墙规则和会话配置（含 JWT），也可部署为 Java EE Servlet。

  • 提供 REST 风格 HTTP API，客户端可通过 HTTP 调用执行 SELECT、UPDATE 等 SQL 语句及存储过程
  • 提供 C#、Java、Python 三种客户端 SDK，以 fluent 风格封装 API 调用
  • 内置 SQL Firewall Manager，支持 detecting、learning、protecting 三种运行模式及白名单机制

适用场景（解读层）

  • 需要从支持 HTTP 的设备（桌面、移动端等）访问远程 SQL 数据库的场景
  • 需要在服务器端对远程 SQL 访问设置防火墙规则（如禁止 DDL、禁止更新）的场景
  • 需要以 Servlet 形式嵌入现有 Java EE 容器提供 SQL API 的场景
