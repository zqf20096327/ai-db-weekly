单 Go 二进制的自托管状态页与在线监测工具，内置 SQLite

综述（解读层）

Pulse 提供状态页与 uptime 监测：检查服务、记录延迟与可用性、连续两次失败自动开事件并告警。单二进制加单 SQLite 文件即可运行，监测 worker 在同一进程内。适合需要对外发布服务状态的个人或团队自托管使用；事件须填写根因分析才可标记解决。

  • 单 Go 二进制内嵌监测 worker 与 SQLite，无需独立数据库服务器或 Node.js 运行时
  • 支持多个自定义域名状态页、事件生命周期、维护窗口（期间抑制告警）与按作用域限定、可吊销的 API 密钥
  • 提供安装脚本、apt/deb/rpm 包与 Docker Compose 部署方式，含 TOTP 双因素认证和 Atom 订阅源

适用场景（解读层）

  • 为自有服务搭建对外的公开状态页
  • 对服务进行定时可用性与延迟检查并自动生成事件
  • 在 homelab/自托管环境中以单二进制或容器方式运行监测
