基于 ADO.NET 的 PowerShell 数据库查询模块

综述（解读层）

Horker DataQuery 是一个用 C# 编写的 PowerShell 数据库查询模块，通过 ADO.NET 驱动连接 SQL Server、Oracle、MySQL、PostgreSQL、SQLite、DuckDB、Access、OLEDB、ODBC 等数据库。查询结果以 PowerShell 对象返回，对象也可导出为数据库表。内置 SQLite（以及 PowerShell 7 下的 Npgsql 和 DuckDB），支持通过 app.config/web.config 定义连接串。仅支持 Windows x64：PowerShell 5.1（.NET Framework 4.8+）或 7.6.5+（.NET 10），不支持 32 位。

  • 查询结果以 PowerShell 对象返回，并可通过 Export-DataTable 将 PowerShell 对象写入数据库表
  • 内置 SQLite 提供程序，PowerShell 7 下还捆绑 Npgsql 与 DuckDB 驱动，无需单独安装
  • 可读取 app.config 或 web.config 定义数据库提供程序和连接字符串，并获取数据库架构信息

适用场景（解读层）

  • 在 PowerShell 脚本中直接查询 SQLite 或其他 ADO.NET 兼容数据库
  • 将 PowerShell 对象批量导出/插入到数据库表
  • 复用既有 .NET 应用 app.config/web.config 中的连接字符串配置
