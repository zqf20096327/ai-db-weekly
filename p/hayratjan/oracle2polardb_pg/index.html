Oracle 到 PolarDB PostgreSQL 的 Web 端结构数据迁移与增量同步平台

综述（解读层）

该平台基于 Python/Django、Vue 3 与 Celery 构建，用于将 Oracle 11g 及以上版本的表结构、数据与视图、序列、存储过程等对象迁移至 PolarDB PostgreSQL，提供表级向导、整库编排、目标环境 DDL 生成、增量同步与断点续传，并内置行数/聚合/哈希/抽样多层校验。适合需要将 Oracle 数据库迁移到 PolarDB 的企业与运维团队。部署支持 Docker 镜像或 compose 全栈；表空间创建需超级用户权限，触发器仅导出模板不自动执行。

  • 支持表级五步向导与整库一键迁移两种方式，覆盖序列、表、视图、物化视图、触发器模板、存储过程等对象类型，多阶段编排且支持断点续传
  • 提供 none/timestamp 水位列/pk_mirror 主键对齐三种增量同步模式，可配合 Celery Beat 定时调度，并提供只读对比预览
  • 内置 4 层数据校验（行数、聚合、哈希、抽样）、结构化日志协议、24 种 Oracle 类型映射与 SQL 语法转换（DECODE→CASE WHEN、LISTAGG→STRING_AGG 等）

适用场景（解读层）

  • 将 Oracle 11g+ 数据库的结构与数据分批或整库迁移至 PolarDB PostgreSQL
  • 对核心业务表按时间戳或主键对齐方式进行定时增量同步
  • 迁移前在 Web 端自动创建目标库、用户、Schema 等环境，并做迁移后数据一致性校验
