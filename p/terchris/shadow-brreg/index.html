基于 Docker 将挪威全部公司公开记录复制为本地 PostgreSQL 影子数据库

综述（解读层）

shadow-brreg 通过 docker-compose.yml 启动容器，从挪威公共登记机构 Brønnøysundregistrene（brreg.no）下载 JSON 数据，转换为 CSV 后导入本地 Postgres，包含约 100 万条公司记录，并每分钟同步一次变更。数据首次导入需下载 91MB 压缩文件（解压后 1.1GB），数据库自动更新代码由作者、ChatGPT 与 GitHub Copilot 协作编写。适合需要在本地数据集上做分析、可视化的开发者与数据从业者。

  • 通过单个 docker-compose.yml 文件启动，包含 Postgres 数据库容器与自动安装、自动更新机制
  • 每分钟从 brreg.no 公共记录同步变更，首次导入使用 JSON 数据源（此前 Excel 导入会丢失数据，2023-02 修复）
  • 内置 pgAdmin 网页查询工具，并提供 shadow-brreg-node 作为 Node.js 开发起点

适用场景（解读层）

  • 在本地数据库上对挪威公司数据进行分析、可视化
  • 作为机器学习或数据科学项目的本地数据集
  • 通过 pgAdmin 或 Node.js 程序查询公司登记信息
