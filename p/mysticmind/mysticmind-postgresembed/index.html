从 .NET 代码内启动真实 PostgreSQL 服务器的嵌入式库

综述（解读层）

该库用于在 .NET 代码和测试中启动真实 PostgreSQL 服务器，支持 Windows、Linux（glibc/musl）和 macOS，无需 Docker 或本地安装 Postgres。首次启动按平台下载并校验二进制文件并缓存共享，后续启动约需一秒；支持版本规格解析、命名实例持久化数据及扩展安装。适用于 .NET 8 及以上。注意服务器仅监听 localhost 并使用 trust 认证，且不能以 root/Administrator 运行。

  • 支持 Windows x64、Linux x64/arm64（glibc 或 musl）、macOS x64/arm64，目标 .NET 8/9/10/11
  • 支持精确版本（如 17.6.0）或规格（17、latest）解析，下载经校验和验证并按用户共享缓存
  • 提供命名实例（跨运行保留数据）与 xUnit fixture 共享服务器

适用场景（解读层）

  • 在本地开发和集成测试中运行真实 PostgreSQL，无需 Docker 或本地安装
  • 在 CI 流水线中共享服务器并缓存二进制文件
  • 需要随库安装 Postgres 扩展归档的场景
