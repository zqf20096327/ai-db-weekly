面向 ClickHouse 的单容器性能监控与查询诊断工具

综述（解读层）

QueryDog 是由 New Cadence 开发的 ClickHouse 观测工具，通过 Docker Compose 单容器运行，提供 Web UI 和同名 CLI。用户在 querydog.yml 中配置多个环境后，可查看查询运行耗时、后台活动，并以 SQL 文件形式维护监控检查、性能追踪查询和数据质量断言，由内置调度器定时执行，历史记录存于本地 SQLite 数据库。

  • 支持在 YAML 中配置多个 ClickHouse 环境，并在 UI 中切换
  • 以只读 SQL 文件形式加载监控检查、性能查询和数据质量断言，调度器按定时对每个环境执行
  • 同一镜像提供 CLI，输出支持 table/JSON/CSV 格式，可进入交互式 REPL

适用场景（解读层）

  • 持续观测 ClickHouse 集群的慢查询与后台活动
  • 按计划运行 SQL 数据质量断言并触发告警
  • 通过 CLI 在脚本或管道中查询表结构、慢查询等信息
