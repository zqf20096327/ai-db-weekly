🧭 简介解读层（AI·证据行可回查）

基于 SQLite 的本地知识图谱，为 AI 编码代理提供长期项目记忆。

综述（解读层）

这是一个运行在项目本地的知识图谱工具，通过 Tree-sitter 解析 Python、TS、JS、Go、Rust 等语言的 AST 构建代码调用图，并以 append-only 账本记录代理决策。数据存储于项目内单个 SQLite 文件，通过 MCP stdio 或 HTTP 提供 20 个工具，支持 Claude Code、Cursor、Codex 等 9 种代理框架的生命周期钩子。事实按半衰期衰减，重新验证可重置；核心包仅依赖标准库。

  • 通过 Tree-sitter 提取 7 种语言变体的函数签名、docstring、调用图与继承关系，增量重解析单文件低于 5ms（hash 跳过）
  • 提供 20 个 MCP 工具与 30 个 CLI 命令，支持 stdio 与 streamable HTTP 两种传输，快照为字节稳定的确定性 Markdown
  • 事实信任度按 half_life 查询时衰减，重验证重置为 100%，过期未引用节点由 prune 命令软删除

适用场景（解读层）

  • 为 Claude Code、Cursor、Codex 等代理配置 MCP 服务器或生命周期钩子，跨会话保留代码结构与决策记录
  • 将决策账本导出为 Obsidian vault（含 wikilinks）或从 mem0/Markdown 文件导入迁移
  • 通过 graph-memory ingest-code 离线构建仓库知识图谱，供 FTS5 全文搜索与代码片段查询
