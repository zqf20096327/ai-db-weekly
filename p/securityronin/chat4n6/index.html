用 Rust 实现的开源聊天取证工具，从 WhatsApp/Signal/Telegram 数据库中提取证据

综述（解读层）

chat4n6 是一款开源聊天记录取证工具，面向事件响应团队、数字取证从业者和律师，用于从 Android 镜像、iOS 备份和 DAR 归档中提取 WhatsApp、Signal、Telegram 数据。它实现八层 SQLite 恢复，为每条记录标记证据来源与置信度，检测反取证痕迹，输出静态 HTML 报告。单二进制运行，依赖 Rust 1.75+ 构建；不支持加密数据库密钥破解。

  • 八层 SQLite 恢复，每条记录带证据来源标签与雕刻置信度
  • 自动检测 VACUUM、头部篡改、选择性删除、ROWID 复用等反取证行为
  • 输出无外部依赖的静态 HTML 报告，支持 SHA-256 去重与验证命令

适用场景（解读层）

  • 设备镜像的快速分诊，评估案件是否需要深入取证
  • 恢复 WAL、freelist、FTS 索引等来源中的已删除消息
  • 生成可离线归档、附于法律文件的聊天证据报告
