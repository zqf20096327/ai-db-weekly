将用户输入解析为合法 PostgreSQL tsquery 的 Node.js 模块

综述（解读层）

pg-tsquery 是一个 Node.js 模块，把用户输入的文本转换为 PostgreSQL to_tsquery 可用的查询串。相比直接使用 to_tsquery（用户输入可能报错）或 plainto_tsquery（仅在词间加 and），它支持可配置的 and、or、followedBy、not、前缀、括号、引号等操作符。适用于在 Node 应用中让用户输入参与全文检索的场景，通过 require 传入 options 可覆盖默认行为。

  • 支持 and、or、followedBy、not、prefix、括号、引号文本等操作符，并可自定义默认选项
  • 输出可直接配合 to_tsquery 使用，如 'foo bar' 转为 'foo&bar'，'foo>bar>bip' 转为 'foo<->bar<->bip'
  • 以 npm 模块分发，通过工厂函数调用并可传入 options 覆盖默认值

适用场景（解读层）

  • Node.js 应用中把用户搜索框输入转为 PostgreSQL 全文检索查询
  • 需要用户输入支持否定、前缀、括号分组等搜索语法的场景
  • 避免 to_tsquery 因原始用户输入语法非法而抛错的调用流程
