🧭 简介解读层（AI·证据行可回查）

基于官方 C 驱动的 Lean 4 TypeDB 3 客户端，提供编译期事务检查与类型化 TypeQL。

综述（解读层）

typedb-lean 是面向 Lean 4 语言的 TypeDB 3 客户端，构建于官方 C 驱动之上。它将读、写、schema 事务建模为不同类型，在编译期拒绝非法操作，并通过插值转义生成类型化 TypeQL。附带 deriving Entity/Relation 的轻量 ORM 和带校验和的版本化迁移。构建需 Rust 工具链与 protoc，支持 Linux x86_64/arm64 与 macOS arm64，Lean 固定在 v4.35.0。

  • 读/写/schema 事务为不同类型，读事务中的 insert 无法通过编译；Driver.runSync 成功提交、出错回滚并可重试提交冲突
  • typeql! 宏对所有插值值转义，行数据按原生调用批量解码为 Lean 结构
  • 提供 deriving Entity/Relation 的 ORM（插入、读取、更新、删除、子类型、多态读取、schema 生成与校验）及带历史和校验和的版本化迁移

适用场景（解读层）

  • 在 Lean 4 项目中通过 FFI 访问 TypeDB 3 数据库
  • 需要编译期约束事务使用方式的函数式编程项目
  • 需要 ORM 与 schema 迁移流程的 TypeDB 应用开发
