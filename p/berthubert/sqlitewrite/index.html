提供类 CSV 写入接口的 C++ SQLite/PostgreSQL 存储库

综述（解读层）

sqlitewriter 是一个 C++ 库，提供向 SQLite（及 PostgreSQL）写入类似 CSV 数据的接口。使用者通过 addValue() 传入字段键值对，表和列在首次使用时自动创建。库内置写入线程与每秒一次的事务批量提交，启用 WAL 模式，并自动创建与复用预处理语句。集成方式为将 sqlitewriter.cc/hh 复制进项目并链接 libsqlite3。

  • addValue() 支持传入任意数量字段，列在首次使用时自动生成，表为 STRICT 模式
  • 写入在独立线程中以事务批量执行（每秒循环一次），读取方实现 busy handler，不阻塞主进程
  • 提供 query/queryT 读取接口、只读模式、NoTransactions 标志、JSON 辅助函数及逐字段元数据（如 collate nocase、UNIQUE）

适用场景（解读层）

  • 批量导入日志或计数器类数据到 SQLite 文件
  • 需要通过同一 API 将记录写入远程可访问的 PostgreSQL 时
  • 以只读模式查询现有 SQLite 数据库并输出类型化结果或 JSON
