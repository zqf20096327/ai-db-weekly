开源 AI 仓库发现与追踪站点，按趋势与质量双评分排序

综述（解读层）

这是一个索引 GitHub 上开源 AI 仓库的站点，托管于 topairepos.com。它每日运行 `npm run daily` 八阶段流水线（发现、同步、快照、分类、评分等），当前索引约 3 万个仓库、33 个分类。核心机制是独立计算趋势分（基于 star 增量、贡献者增长、发布时效）与 0-100 质量分（维护、发布节奏、文档、许可证等），并采用只记录变更的快照策略以控制数据库体积。适用于想自行部署类似追踪站点的开发者。

  • 通过 317 个精选 topic 加 61 个自由文本短语发现仓库，覆盖无 topic 的热门项目
  • 质量分覆盖维护状态、发布节奏、贡献者广度、issue 积压、文档与许可证安全性
  • 快照仅在有变化时写入行，README 截断至 4000 字符，适配 500 MB 免费数据库

适用场景（解读层）

  • 自建每日更新的 AI 仓库追踪与排名站点
  • 按趋势与质量维度筛选和比较开源 AI 项目
  • 基于 Postgres 快照数据分析仓库增长历史
