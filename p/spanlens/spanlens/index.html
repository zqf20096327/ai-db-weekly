开源 LLM 可观测性平台，通过代理接入记录调用、成本与 Agent 链路

综述（解读层）

Spanlens 是一个开源（MIT）LLM 可观测性与监控平台，面向使用 OpenAI、Anthropic、Gemini 等 11 家供应商的 LLM 应用开发者。核心机制是替换客户端 baseURL 的代理接入，记录每次调用的 prompt、响应、延迟、token 与成本，并支持 Agent 链路追踪、异常检测、告警、prompt 版本与评测。可用一条 Docker 命令自托管，也可使用托管版。

  • 支持 OpenAI、Anthropic、Gemini 等 11 家供应商的代理接入，并提供 Vercel AI SDK、LangChain、LlamaIndex 等框架集成
  • 记录每次调用的模型、token、成本、延迟及完整请求/响应体，流式响应可自动重建，支持 Agent span 追踪与图拓扑视图
  • 提供异常检测、预算告警、PII 与提示注入扫描、prompt 版本 A/B 实验、LLM-as-judge 评测，附 OpenAPI 3.0 规范与 MCP 服务器

适用场景（解读层）

  • 为生产环境 LLM 应用记录请求日志并按功能/用户追踪成本
  • 对多步 Agent 工作流进行 span 级追踪与延迟关键路径分析
  • 通过预算告警、异常检测和 PII/注入扫描监控线上 LLM 调用质量与合规
