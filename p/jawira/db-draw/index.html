读取 Doctrine DBAL 连接生成 .puml 格式数据库 ER 图的 PHP 库

综述（解读层）

DB Draw 是一个 PHP 库，通过 Doctrine DBAL 连接读取数据库结构，生成 PlantUML（.puml）格式的 ER 图。README 指出它主要作为 jawira/doctrine-diagram-bundle 的依赖被使用，而非直接面向最终用户。通过 Composer 安装，文档托管在 GitHub Pages。生成 .puml 后通常还需配套工具将图渲染为图片。

  • 接受 Doctrine DBAL 连接作为输入
  • 生成 .puml（PlantUML）格式的数据库 ER 图
  • 通过 Composer require 安装

适用场景（解读层）

  • 为已有数据库连接自动生成 ER 图源文件
  • 作为 jawira/doctrine-diagram-bundle 的底层依赖在 Symfony 项目中使用
  • 配合 PlantUML 工具链将 .puml 转换为图片用于文档
