纯 Go 编写的嵌入式持久化键值数据库，基于 WiscKey 设计

综述（解读层）

BadgerDB 是用纯 Go 编写的嵌入式持久化键值数据库库，也是 Dgraph 图数据库的底层存储。设计基于 WiscKey 论文，键值分离存储并针对 SSD 优化；支持带 SSI 保证的并发 ACID 事务、TTL 和按键多版本访问。README 另注明本仓库的 v4 为精简版，移除了 Value Log、WAL 和写事务，写入需经 WriteBatch 或 HandoverSkiplist。版本号按磁盘数据格式是否兼容划分。

  • 纯 Go 实现，无 Cgo，可嵌入 Go 程序；安装仅需 Go 1.12+ 并 go get 该库
  • 支持并发 ACID 事务（可序列化快照隔离 SSI）、TTL、快照及通过迭代器 API 访问键的多版本
  • 提供 badger 命令行工具，通过 go install 安装到 $GOBIN

适用场景（解读层）

  • 作为 Go 应用内的嵌入式持久化键值存储（v3 及更早版本）
  • 需要在 SSD 上运行、数据量达 TB 级的键值存储场景
  • 从 dgraph-io/badger 迁移的项目，可用 gofmt 替换 import 路径切换到本 fork
