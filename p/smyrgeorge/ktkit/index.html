🧭 简介解读层（AI·证据行可回查）

面向 Ktor 服务端开发的 Kotlin 多平台工具集，整合 Web、数据库、鉴权与可观测性模块。

综述（解读层）

KtKit 是一个用于配合 Ktor 构建服务端应用的 Kotlin 多平台工具集，将 REST 处理器基类、Koin DI、Arrow Raise 错误模型、sqlx4k 数据库访问、PGMQ 队列与 log4k 日志追踪整合为一体。通过 Gradle 插件统一构建配置，README 标注项目处于早期阶段，API 可能在版本间变更。

  • 提供 REST 处理器基类，支持 RFC 9457 格式错误响应、基于角色与自定义谓词的两层鉴权，以及通过 x-real-name 头解析 Principal 的认证机制
  • 基于 sqlx4k 提供数据库访问，支持 PostgreSQL、MySQL/MariaDB 和 SQLite，包含 @Table 实体、编译期生成的 @Repository 实现与审计列自动管理
  • 提供 TOML 配置加载（含环境变量插值与分层覆盖）、/api/status/health 与 /api/status/metrics 状态端点，以及通过 PGMQ 的消息队列模块

适用场景（解读层）

  • 使用 Ktor 构建服务端应用，希望统一处理路由注册、错误响应与依赖注入的项目
  • 需要 Kotlin 多平台（JVM 与 Native）下数据库访问与编译期查询校验的服务端开发
  • 以 PostgreSQL 为数据库并需消息队列（PGMQ）与链路追踪贯通的后端服务
