面向 Ktor 服务端的 Kotlin 多平台后端开发工具包

综述（解读层）

KtKit 是一套 Kotlin 多平台工具库，整合 REST 处理器、依赖注入、TOML 配置、数据库访问与消息队列等组件，用于基于 Ktor 的服务端开发。它通过 Arrow 的 Raise 上下文参数处理错误，基于 sqlx4k 支持 PostgreSQL、MySQL 和 SQLite，并提供 RBAC 权限控制。项目处于早期阶段，README 明确说明版本间 API 可能出现破坏性变更。

  • 提供 Application 引导封装，管理 Ktor 生命周期、JSON 配置、Koin DI 容器并自动注册 REST 处理器
  • 基于 sqlx4k 支持 PostgreSQL、MySQL/MariaDB、SQLite 的数据库访问与编译期代码生成的 @Repository，并提供基于 Postgres 的 PGMQ 消息队列模块
  • 内置基于角色的权限控制与自定义谓词两层授权，错误响应遵循 RFC 9457，序列化使用 kotlinx.serialization 无反射实现

适用场景（解读层）

  • 使用 Ktor 构建服务端应用并希望统一处理引导配置、错误模型、日志追踪的 Kotlin 项目
  • 需要基于 Postgres 的消息队列（PGMQ）和带审计字段的实体/仓库代码生成的后端服务
  • 在 JVM 与 Native 目标上运行 Kotlin 多平台服务端程序，需要无反射序列化与多平台日志
