综述（解读层）

sqlx4k 是一个面向 Kotlin Multiplatform 的 SQL 工具集，不是 ORM，提供驱动、连接池、事务等原语直接与数据库通信。通过 @Table/@Repository 注解和 Gradle 插件生成 CRUD 实现，@Query 在编译期做语法与 schema 校验并优化 SQL。支持 PostgreSQL、MySQL/MariaDB、SQLite/SQLCipher，目标平台含 JVM、Android、iOS、macOS、Linux、Windows，MIT 协议。

  • 支持 PostgreSQL、MySQL/MariaDB、SQLite 与 SQLCipher，目标平台包括 JVM、Android、iOS、macOS、Linux、Windows
  • 通过 @Repository 与 @Query 注解生成 CRUD 实现，编译期进行 SQL 语法与 schema 校验及查询优化
  • 提供协程异步 I/O、连接池、事务与 Savepoint、数据库迁移及 PGMQ、SQLDelight 等扩展

适用场景（解读层）

  • Kotlin Multiplatform 项目中需要在 JVM、iOS、Linux 等多目标平台访问关系型数据库
  • 希望在编译期发现 SQL 拼写或 schema 错误、避免运行期查询失败的开发流程
  • 只用驱动层执行手写 SQL，配合预处理语句、行映射器与事务的场景
