🧭 简介解读层（AI·证据行可回查）

基于 CLIProxyAPI 的定制构建层，内嵌 SQLite 用量服务与账号巡检调度器。

综述（解读层）

该项目不 fork upstream，而是以 patch 与 overlay 维护对 router-for-me/CLIProxyAPI 后端及其管理前端 CLIProxyAPI Management Center 的定制，发布时拉取 upstream 最新 release 应用定制层生成 Pro 产物。核心增加 SQLite 用量持久化、账号巡检调度、代理池与 OAuth 账号策略等模块，面向需要这些扩展功能的 CLIProxyAPI 使用者。需注意前端部分功能依赖 Pro 后端 API，单用 upstream 后端时对应页面无数据。

  • 内嵌 SQLite usage service，暴露 /v0/management/usage 系列 API，支持 JSONL/NDJSON 导入导出与 WebDAV 备份恢复
  • 账号巡检调度器支持 Codex、Claude、Antigravity、Gemini CLI、Kimi、xAI，可将巡检结果持久化并自动执行启用、禁用、删除、刷新令牌
  • 二进制内建代理池（HTTP/SOCKS 节点汇聚为本地 SOCKS5，支持轮询、加权、健康隔离）与按提供商 OAuth 套餐配置的账号策略

适用场景（解读层）

  • 需要持久化保存请求用量、模型价格与配额缓存并进行备份恢复的 CLIProxyAPI 部署
  • 需要对多个提供商 OAuth 账号进行定时巡检、限制检查与自动化账号管理的场景
  • 需要将多个代理节点汇聚为本地 SOCKS5 地址并按策略调度账号的部署环境
