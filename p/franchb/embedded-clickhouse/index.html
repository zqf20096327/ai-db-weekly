🧭 简介解读层（AI·证据行可回查）

Go 库，以子进程方式在本机运行真实 ClickHouse 二进制，用于应用与测试

综述（解读层）

这是一个 Go 库，用于在 Linux 或 macOS 上以子进程形式运行真实的 ClickHouse 数据库，供 Go 应用或测试嵌入使用。二进制从官方 GitHub 发布页下载并缓存在本地，无需 Docker、testcontainers 或预装的 ClickHouse，仅依赖 Go 工具链。支持集群模式（基于内嵌 Keeper）测试 ReplicatedMergeTree 表，也支持指向私有构建的自定义归档，并可校验 SHA256/SHA512。默认自动分配端口，数据目录在 Stop 时移除。

  • 以子进程方式运行 ClickHouse 官方发布二进制，缓存于 ~/.cache/embedded-clickhouse/ 并跨测试运行复用
  • 提供集群模式，在 localhost 上运行多个副本，使用二进制内嵌的 Keeper（基于 Raft）进行协调，无需额外组件
  • 支持自定义二进制来源（本地归档、私有 URL、自定义镜像）及 SHA256/SHA512 校验，配置采用值接收者的 builder 模式

适用场景（解读层）

  • 在 Go 集成测试中运行真实 ClickHouse 执行 SQL，替代 mock 或基于 Docker 的方案
  • 在 GitLab CI 等无特权容器的流水线中运行 ClickHouse 集成测试
  • 测试 ReplicatedMergeTree 表和 ON CLUSTER 查询，或连接 Kafka、S3 等通过端口暴露的外部依赖
