基于可扩展哈希的 Go 键值存储，通过 HTTP 接口读写

综述（解读层）

Bluckdb 是一个用 Go 编写的键值存储，采用基于可扩展哈希的持久哈希表，索引与数据存于同一文件，页面固定 4096 字节。server.go 提供 2233 端口的 HTTP 服务，含 data、meta、debug 等端点。项目自述仅用于实验和学习，非生产就绪；单条记录不能超过一个桶的大小。

  • 实现基于可扩展哈希的持久哈希表，目录表存页指针、页大小 4096 字节
  • 提供 HTTP 接口：GET/PUT /v1/data 读写键值，/v1/meta 查看表元数据，/v1/debug 查看指定页转储
  • 通过 mmap（Mmap-go）实现 KV 存储实例，put 为追加写、get 反向遍历读

适用场景（解读层）

  • 学习和实验可扩展哈希、持久哈希表等数据结构
  • 在本地通过 HTTP 接口做简单的键值读写试验
  • 查看页级调试信息以理解存储布局
