🧭 简介解读层（AI·证据行可回查）

将 OpenFGA 模式编译为 PostgreSQL 内 SQL 权限函数的编译器

综述（解读层）

Melange 读取 .fga 授权模式文件，在迁移时分析各关系的模式（直接、并集、排除、tuple-to-userset 等），为每个关系生成专用 PL/pgSQL 函数并安装到现有 PostgreSQL 数据库中。运行时权限检查是对 check_permission() 的一次函数调用，数据通过用户自定义的 melange_tuples 视图直接读取应用表，无需独立元组存储与同步。支持 OpenFGA Schema 1.1 除 conditions 外的特性。适用于希望权限检查在数据库内运行的项目。

  • 将 OpenFGA Schema 1.1 模式编译为 PL/pgSQL 函数，角色层级在编译期解析并内联，运行时无需递归查找
  • 权限检查通过读取用户定义的 melange_tuples 视图直接访问现有表，无独立元组存储；同事务内可见未提交变更，可用于触发器与 RLS 策略
  • 提供 CLI（migrate/validate/diff/explain/expand/doctor）及可选 Go、TypeScript 客户端，melange studio 提供只读本地 Web 控制台

适用场景（解读层）

  • 应用数据已存于 PostgreSQL，需在同一数据库内执行关系型权限检查（RBAC/ReBAC）的场景
  • 需要权限检查在事务内感知未提交数据、用于触发器或行级安全策略的场景
  • 已使用 OpenFGA 模式定义权限、希望以 SQL 函数形式部署检查逻辑的项目
