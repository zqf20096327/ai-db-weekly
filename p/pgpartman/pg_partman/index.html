基于 PostgreSQL 声明式分区的表分区创建与维护扩展

综述（解读层）

pg_partman 是一个 PostgreSQL 扩展，用于创建和管理基于时间与数值的分区表集合，并在声明式分区之上提供子表自动维护，如按保留策略新增与删除分区。5.x 起仅支持声明式分区，触发器方式已弃用；要求 PostgreSQL ≥ 14，可由内置后台进程自动执行维护，无需外部调度器。

  • 支持基于时间和数值两种分区集合的创建与维护，可按保留策略自动新增或删除子分区
  • 内置后台进程（BGW），通过 shared_preload_libraries 加载后无需外部调度器即可运行维护
  • 支持将现有表转换为分区表及反向迁移，且安装与运行不要求超级用户权限

适用场景（解读层）

  • 需要按时间或数值自动滚动分区并基于保留策略清理旧数据的 PostgreSQL 大表管理
  • 在无外部 cron 调度条件的环境（如 Amazon RDS 等托管数据库）中运行分区维护
  • 将既有单表迁移为声明式分区表，或将旧触发器分区方案迁移到声明式分区
