Firefox 等应用的 SQLite 数据库管理扩展

综述（解读层）

SQLite Manager 是一款面向 Firefox、Thunderbird、SeaMonkey、Komodo 等应用的浏览器/邮件客户端扩展，用于管理 SQLite 数据库。安装后通过 Tools 菜单访问，可从 Mozilla Addons 下载。它提供表、索引、视图、触发器的创建删除对话框，支持执行自定义 SQL 并保存命名查询，可导入导出 CSV/SQL/XML 格式，支持浏览、搜索、编辑表中数据及处理 blob 字段，无需手写 pragma 语句即可修改 sqlite 库设置。

  • 提供表、索引、视图和触发器的创建、删除、重命名、复制和重索引操作，支持添加和删除列
  • 支持导入导出 CSV、SQL、XML 格式的表数据，可执行单条或多条自定义 SQL 查询并保存命名查询
  • 支持浏览、搜索、编辑和删除表/视图数据，处理 blob 数据，并可免写 pragma 语句查看和修改 sqlite 库设置

适用场景（解读层）

  • 需要在 Firefox/Thunderbird/SeaMonkey/Komodo 中查看或修改 SQLite 数据库
  • 通过图形界面管理 SQLite 表结构（表、索引、视图、触发器）而手写 SQL
  • 在 CSV/SQL/XML 格式间导入导出表数据，或编辑含 blob 字段的记录
📖 README 首段存档原文 · 程序抽取

After installing the addon, the SQLite Manager is accessible through Tools menu (Click Customize and drag SQLite Manager icon into the Menu if not found by default).
