SQLx 0.9 + PostgreSQL Rust 课程配套代码库，含13个十亿行级压力测试场景

综述（解读层）

该仓库是两段共6小时课程的配套代码，演示 SQLx 0.9 与 PostgreSQL 的用法，覆盖连接池、编译期宏、事务、RLS 多租户等内容，并包含13个十亿行规模的生产场景挑战与 Axum REST 服务。面向学习 Rust 后端数据访问的开发者。需本地运行 PostgreSQL 16+，通过 sqlx-cli 迁移初始化，cargo test 验证。

  • 支持编译期查询宏、QueryBuilder 动态构建、离线模式准备等 SQLx 0.9 特性
  • 包含13个针对十亿行数据的场景挑战，如深度分页、BRIN 索引、分区删除、SKIP LOCKED 任务队列
  • 提供迁移脚本、12个自动化测试，以及可运行的 Axum REST API 演示服务

适用场景（解读层）

  • 学习 Rust 中 SQLx 与 PostgreSQL 的进阶用法
  • 参考索引、分区、连接池等调优实现
  • 运行基准演示并对比不同查询方案的表现
