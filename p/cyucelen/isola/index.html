🧭 简介解读层（AI·证据行可回查）

按 git worktree 隔离服务、端口与 Postgres 数据库的运行工具

综述（解读层）

isola 是一个 Go 编写的单二进制 CLI，为每个 git worktree 分配独立进程、端口、*.localhost URL、环境变量和数据库（Postgres 从模板物理克隆，Redis 分配编号逻辑库）。配置集中在仓库根的 .isola.toml，可声明 setup 步骤自动安装依赖和迁移；通过机器级反向代理提供按分支的子域名访问，支持 git hook 自动启停、TUI 面板和供编码 agent 调用的技能。不使用 Docker，依赖机器上已有的运行时与数据库服务器。

  • 每个 worktree 获得独立进程、端口、*.localhost URL、环境变量及从模板克隆的 Postgres 数据库，worktree 删除时自动停止服务并回收数据库
  • 支持通过 git post-checkout hook 自动启动新 worktree，反向代理提供按分支子域名的 HTTP/HTTPS 访问，配置中的 ${...} 引用解析为当前 worktree 的实际值
  • 提供 TUI 面板、机器可读输出与可安装的 agent 技能（npx skills add cyucelen/isola），并支持按需启动的服务与每个分支的配置覆盖

适用场景（解读层）

  • 在同一台机器上并行运行多个 AI 编码 agent 或多个分支的开发环境
  • 需要多个 worktree 各自拥有隔离的开发数据库、避免端口和 schema 冲突的项目
  • monorepo 中可选服务按需启动、希望新 worktree 自动完成依赖安装与迁移的开发流程
