面向游戏团队的数据驱动设计工具，含可视化编辑器、代码生成与数据管线

综述（解读层）

Charon 用于将游戏数值、物品、任务等数据与代码分离：先定义 schema，再通过本地 Web UI 或 Unity/Unreal 插件编辑数据，随后生成 C#、C++、TypeScript、Haxe 的类型安全代码供项目加载。独立版为 .NET 全局工具（需 .NET SDK 8+），可运行于 Windows/macOS/Linux，提供 REST API 与 CLI 用于 CI/CD 集成；Community 版免费，Professional 版为订阅制。

  • 支持 C#、C++、TypeScript、Haxe 四种语言的类型安全代码生成，无运行时反射
  • 本地 Web 编辑器及 Unity/Unreal Engine 原生插件，可通过 CLI 或 REST API 集成到 CI/CD 流程
  • 基于 .NET 8，跨 Windows/macOS/Linux 运行；Community 版可随游戏分发以支持 Mod 制作

适用场景（解读层）

  • 设计师独立维护角色、物品、任务等游戏数据与本地化内容
  • 程序员通过 schema 生成代码替代手写 JSON 解析与硬编码 ID
  • 在 CI/CD 管线中对游戏数据进行校验、diff 与版本间补丁
