在 Cloudflare Worker 中创建和查询任意数量 SQLite 数据库的库

综述（解读层）

DORM 是一个运行于 Cloudflare Workers 的库，通过 Durable Objects 的 SQLite 能力按租户动态创建数据库（每个上限 10GB），并提供从 worker 直接执行 SQL 的客户端 API。内置 Outerbase 数据管理集成、基于 JSON Schema 的建表和 JIT 迁移机制。适合需要在 Cloudflare 平台上做多租户数据隔离的开发者。项目目前处于 beta 阶段，API 可能变动。

  • 支持在 worker 任意位置直接执行 SQL，无需编写 Durable Object 处理代码
  • 提供 JSON Schema 定义表结构并自动转换为 SQL，以及访问时触发的 JIT 迁移（@Migratable）
  • 内置 Outerbase Studio 集成和 REST API 数据访问，支持将操作镜像到聚合数据库

适用场景（解读层）

  • 为每个客户或组织创建独立数据库的多租户 SaaS 应用
  • 将用户数据存储在靠近访问位置的边缘场景
  • 通过镜像将租户操作同步到中央数据库进行聚合分析
