基于 Odoo 20 的自托管软件工厂，提供 dev/staging/prod 环境流水线与可观测性

综述（解读层）

Kizuku 将 Odoo 20 作为可复用后端骨架，运行在单个 Docker 主机上，提供 dev/staging/prod 三阶段隔离环境、声明式 BFF（backend.yaml）、迭代快照与回滚、定期备份、TLS、多用户面板以及含 MCP 服务器（21 个工具）的 AI 代理层。要求 Docker Engine 24+ 与 Compose v2，建议 6 GB 内存；通过 install.sh 安装，CLI 命令仍为 core-odoo。平台采用 Apache-2.0，Odoo 模块采用 LGPL-3.0。

  • 提供 dev/staging/prod 每阶段独立 Compose 项目，支持带 neutralization 的提升、自动回滚与 last_good_iteration 保留
  • 声明式 BFF 通过 backend.yaml 仅暴露所声明的模型与字段；备份含每环境转储与控制平面，7 天保留，可选异地镜像
  • 代理层包含 7 个 skill、3 个项目 subagent 及含 21 个工具的 MCP 服务器；可观测性组件有 Prometheus、Loki（14 天保留）、Grafana、Alertmanager、Uptime Kuma

适用场景（解读层）

  • 在单个 Docker 主机上自托管 Odoo 应用并管理多环境部署流水线的团队
  • 希望以声明式 backend.yaml 暴露 Odoo 模型字段给前端的开发场景
  • 使用 MCP 工具与 skill 让 AI 代理参与 Odoo 模块开发、审查与部署操作的环境
