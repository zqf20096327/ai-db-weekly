综述（解读层）

该项目是一个基于 Model Context Protocol 的服务器，使用 C# 与 .NET 10.0 开发，提供九个工具，覆盖连接测试、建库建表删表、建表语句读取及数据的插入、查询、更新、删除。面向需要在 VS Code 或 Visual Studio 中通过 Copilot Chat 以自然语言操作 GaussDB 数据库的用户。连接参数通过环境变量配置，支持 NuGet 安装或 dotnet run 本地运行。

  • 提供 9 个 MCP 工具：连接测试、创建数据库、创建/删除表、获取建表 SQL、插入/查询/更新/删除数据
  • SQL 查询使用参数化方式，数据库标识符经转义处理，连接字符串敏感信息在日志中隐藏
  • 通过 GAUSSDB_HOST/PORT/USER/PASSWORD/DATABASE 等环境变量配置连接，内置连接池管理

适用场景（解读层）

  • 在 Copilot Chat 等支持 MCP 的 AI 助手中以自然语言执行 GaussDB 的库表创建与数据增删改查
  • 开发过程中快速验证数据库连接配置并读取已有表的建表语句
  • 在 Windows、macOS、Linux（含 musl）多平台环境中作为 .NET 应用部署运行
