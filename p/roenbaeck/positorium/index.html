Rust 编写的嵌入式证据数据库，保留冲突断言的来源、时间与确定性

综述（解读层）

Positorium 是一个用 Rust 实现的实验性嵌入式数据库，不将事实收敛为单一当前值，而是以不可变的 posit 模型保留相互冲突的断言及其来源、确定性、出现时间与断言时间。它提供 Traqula 查询语言、只追加存储、Python 3.9+ 绑定、可信本机 HTTP 服务和浏览器 WASM 测试环境。项目处于 beta 阶段，服务器默认绑定 127.0.0.1 且无认证，不含复制与分布式执行，适用于合规取证、调查、冲突主数据等需要积累并修订证据的场景，可作为现有系统旁的证据层。

  • 不可变的 Things、Roles、appearance sets、posits 与断言信封，每个断言可保留来源、签名确定性和时间
  • Traqula 查询语言支持连接、union、safe not exists、快照、typed predicates、in effect、参数、排序与限制
  • 提供只追加原生存储、原子持久变更批次与确定性重放恢复，以及 Rust/HTTP/SSE/WASM/Python 多种结果通道

适用场景（解读层）

  • 合规取证或调查中需要保留证据来源与修订历史的记录
  • 存在相互冲突记录的主数据管理场景
  • 作为现有业务系统旁的专用证据层，配合 Python 或 HTTP 接口嵌入应用
