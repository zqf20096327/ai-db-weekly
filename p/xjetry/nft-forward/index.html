🧭 简介解读层（AI·证据行可回查）

基于 nftables 的多租户多节点端口转发面板，server+agent 双二进制

综述（解读层）

该项目由 nft-server 面板和 nft-agent 节点两个 Go 二进制组成，用于管理多节点端口转发。agent 通过反向 WebSocket 连入面板，节点侧无需开放管理端口。数据面支持 nftables 内核态 DNAT 与用户态 split-TCP 逐跳选择，含多租户配额与组合节点多跳编排。仅支持 amd64 Linux，需 root 与 nftables，面板为单实例 SQLite 存储。

  • 数据面支持 nftables 内核态 DNAT（TCP/UDP）与用户态 split-TCP 两种模式，可逐跳选择
  • agent 反向 WebSocket 连接面板，面板自动编排多跳链路并分配对齐端口
  • 多租户支持节点级授权、规则配额、全局与 per-node 流量配额及周期重置、到期时间

适用场景（解读层）

  • 管理员集中管理多个转发节点的场景
  • 需要按用户分配转发规则并限制流量与到期时间的多租户环境
  • 需要将多个节点编排为多跳转发链路的部署
📖 README 首段存档原文 · 程序抽取

基于 nftables 的轻量多节点端口转发平台。两个二进制（nft-server + nft-agent），零外部依赖——面板管理多节点推送规则，节点 agent 反向连入面板，零端口暴露。支持内核态 DNAT 与用户态 split-TCP 逐跳混用，多租户配额管理，组合节点自动编排多跳链路。
