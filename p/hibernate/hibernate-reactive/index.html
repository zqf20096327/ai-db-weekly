Hibernate ORM 的响应式 API，基于非阻塞数据库驱动实现响应式数据库交互

综述（解读层）

Hibernate Reactive 为 Hibernate ORM 提供响应式 API，通过 Vert.x 响应式 SQL 客户端以非阻塞方式与数据库交互。可用于任意 Java 程序，主要面向 Quarkus 和 Vert.x 等响应式环境。当前支持 PostgreSQL、MySQL、MariaDB、Db2、CockroachDB、MS SQL Server 和 Oracle，尚未覆盖 Hibernate ORM 全部特性，例如不支持 @CollectionId 注解。

  • 支持 PostgreSQL、MySQL、MariaDB、Db2、CockroachDB、MS SQL Server、Oracle 七种数据库，底层使用 Vert.x 响应式 SQL 客户端
  • 提供响应式会话（reactive session）进行数据访问，并包含基于其上的 Panache Reactive 活动记录风格 API
  • 提供 Quarkus 扩展、示例项目、JBang 快速运行示例，以及基于 Testcontainers 的多数据库测试支持

适用场景（解读层）

  • 在 Quarkus 或 Vert.x 等响应式环境中使用 Hibernate ORM 进行数据库访问
  • 需要以非阻塞方式操作 PostgreSQL、MySQL 等关系型数据库的 Java 应用
  • 通过 Panache Reactive 以活动记录风格编写响应式数据访问代码
