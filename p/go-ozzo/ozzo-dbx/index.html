增强 database/sql 的 Go 包，提供命名参数绑定与数据库无关的查询构建

综述（解读层）

ozzo-dbx 是一个 Go 包，在标准 database/sql 之上提供数据填充与数据库无关的查询构建能力。它不是 ORM，可通过结构体映射、命名参数、条件表达式等方式构建并执行 SELECT、数据操纵和模式操纵查询，支持取消查询和日志记录，适用于需要在 Go 中访问关系型数据库且不引入完整 ORM 的开发者。需注意匿名参数绑定不被支持。

  • 支持将查询结果填充到结构体和 NullString 映射，字段映射可通过 FieldMapper 函数和 db tag 定制
  • 提供数据库无关的 SELECT、数据操纵与模式操纵查询构建方法，并按数据库类型自动引用表名和列名
  • 开箱支持 SQLite、MySQL、PostgreSQL、MS SQL Server（2012+）、Oracle，并可通过自定义构建器扩展其他数据库

适用场景（解读层）

  • 在 Go 应用中以命名参数绑定方式执行参数化 SQL 查询
  • 以编程方式构建跨数据库的 SELECT、增删改和表结构变更语句
  • 配合 context.Context 实现运行中查询的取消
