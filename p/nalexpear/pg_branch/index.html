基于 BTRFS 快照的 Postgres 扩展，实现快速数据库分支

综述（解读层）

pg_branch 是一个实验性 Postgres 扩展（pre-alpha），当 PGDATA 位于 BTRFS 等写时复制文件系统时，可将 CREATE DATABASE ... WITH TEMPLATE 转为原子文件系统快照，无需模板库无活动连接的独占要求，模板库增大时耗时仍为秒级。使用前需格式化磁盘为 BTRFS、初始化集群并用 init.sh 将 segment 目录转为子卷，目前仅在 Linux 上测试过。

  • 将 CREATE DATABASE WITH TEMPLATE 转为原子文件系统快照，创建大数据库副本耗时秒级
  • 写时复制策略仅在数据文件被修改时写入新 segment，降低磁盘占用
  • 通过指定 WAL_COPY 或 FILE_COPY 等显式 STRATEGY 可回退到默认行为

适用场景（解读层）

  • 需要从大数据库快速创建副本的开发/测试环境
  • 基于已有数据库模板批量生成分支数据库的场景
  • 模板库持续有连接、无法使用默认 TEMPLATE 机制的环境

A Postgres extension for quickly creating "branches" of individual databases within a Postgres cluster using copy-on-write file systems like BTRFS.
