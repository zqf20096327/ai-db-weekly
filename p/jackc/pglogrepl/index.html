综述（解读层）

pglogrepl 是一个 Go 语言包，用于 PostgreSQL 逻辑复制。它以 github.com/jackc/pgx/v5/pgconn 作为底层连接实现。仓库提供两个示例程序：pglogrepl_demo 记录逻辑复制消息、pgphysrepl_demo 记录物理复制消息。使用该包需要理解 PostgreSQL 复制协议概念，测试运行需数据库开启 logical wal_level、配置复制权限用户及 pg_hba.conf。

  • 以 github.com/jackc/pgx/v5/pgconn 作为底层 PostgreSQL 连接
  • 包含逻辑复制与物理复制两个示例演示程序
  • 支持通过环境变量 PGLOGREPL_TEST_CONN_STRING 配置连接串运行测试，可用 PGLOGREPL_SKIP_BASE_BACKUP 跳过 base backup 测试

适用场景（解读层）

  • 在 Go 程序中接收并处理 PostgreSQL 逻辑复制的消息流
  • 需要与 PostgreSQL 复制协议交互的数据同步组件开发
  • 基于该包调试和查看逻辑/物理复制消息的学习与测试场景
