Go 库，将 SQL 行扫描结果直接映射到结构体、切片和基本类型

综述（解读层）

Scan 是一个 Go 小型库，读取标准库 database/sql 的行结果，通过 scan.Rows/Row 写入结构体、切片或标量变量，支持嵌套结构体、基于 db 标签的严格模式及自定义列名映射，并提供 Columns/Values 用于配合 squirrel 等 SQL 构建库。作者声明项目约 2021 年后不再更新，视为已完成状态。适合已在用标准库或 squirrel、只需行映射功能的开发者。

  • 支持将行扫描到结构体、基本类型切片和标量值，支持 v2.0.0 起的嵌套结构体字段
  • 提供 RowsStrict/RowStrict 基于 db 标签的严格扫描，以及可自定义的 ColumnsMapper/ScannerMapper 列映射
  • 提供 Columns/Values 函数生成列名与对应值，使用 sync.Map 缓存结构体字段以提升重复扫描性能

适用场景（解读层）

  • 使用标准库 database/sql 或 squirrel 编写查询后，将结果行映射到 Go 类型
  • 配合 squirrel 等 SQL 构建库生成 INSERT 语句时，用 Columns/Values 提取结构体列名与值
  • 多表 JOIN 查询结果需要映射到含嵌套字段的结构体的场景
