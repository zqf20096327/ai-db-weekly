开源地理空间数据管理平台，含C++核心库与CLI

综述（解读层）

DroneDB 是一个用于地理空间数据存储、可视化与分享的开源平台，由 C++ 核心库和 ddb 命令行工具组成，通过 SQLite/SpatiaLite 建立数据索引，并可推送数据集至 DroneDB Hub 协作。支持无人机影像、点云、3D 模型等格式的元数据提取与切片生成。可在 Windows 与 Linux 上运行，提供 .deb 安装包、安装程序及 Docker 镜像；采用 MPL-2.0 许可证。

  • 提供 init/add/search/build/cog/3dtiles 等命令行子命令，可生成瓦片、预览、COG、COPC 及 OGC 3D Tiles
  • 自动从图像 EXIF、栅格数据（GDAL）、点云和矢量文件提取元数据，并支持导出 STAC 目录
  • 支持 GeoTIFF、LAS/LAZ/E57、OBJ/glTF、GeoJSON/SHP/KML 等多种格式，提供 Web 端正射影像、点云、3D 模型与 360° 全景查看器

适用场景（解读层）

  • 无人机航拍数据（正射影像、点云、航迹）的索引、可视化与在线分享
  • 地理空间数据集的格式转换，如生成 COG、COPC、3D Tiles 或 Gaussian Splat 压缩文件
  • 通过 DroneDB Hub 进行团队间数据集的推送/拉取协作
