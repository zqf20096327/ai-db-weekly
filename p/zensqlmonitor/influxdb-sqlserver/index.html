用 Go 编写的 SQL Server 指标采集器，写入 InfluxDB 供 Grafana 展示

综述（解读层）

该项目基于 Go 编写，通过 SQL Server 动态管理视图采集性能计数器、等待统计、内存、数据库 I/O 与 CPU 等指标，以 InfluxDB line protocol 写入名为 SQLSERVER 的库，并随仓库提供 Grafana 面板文件供导入。使用前需在 SQL Server 实例创建登录账号，配置采用 TOML 格式，依赖 Go 1.5 与 go-mssqldb 驱动。适用于需要自行搭建 SQL Server 指标采集与展示链路的运维环境。

  • 提供 8 个 T-SQL 脚本，读取 sys.dm_os_performance_counters 等动态管理视图，包含 1000+ 性能计数器指标
  • 使用 InfluxDB line protocol 写入数据，支持通过 TOML 配置文件及 -config 命令行参数运行
  • 支持 go run/go build/go install 方式运行，附带可导入的 Grafana 面板文件

适用场景（解读层）

  • 需要将多个 SQL Server 实例的指标集中写入 InfluxDB 的监控采集
  • 需要在 Grafana 中展示 SQL Server 性能计数器、内存与 I/O 数据
  • 需要基于 DMV 编写自定义 SQL 查询并扩展采集指标的场景
