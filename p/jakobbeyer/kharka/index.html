Rust 编写的本地优先 JSON 存储库，每台机器持有完整副本，单一 hub 排序并广播变更。

综述（解读层）

kharka 是一个用 Rust 实现的本地优先 JSON 存储，面向需要离线可用、小规模 JSON 文档同步的少数机器。每台机器的 daemon 持有完整副本，CLI 与脚本经 unix socket 以 JSON 行协议读写；hub 通过 ssh 排序并广播变更。数据分 state（TTL 过期）与 record（混合逻辑时钟排序、后写者胜）两类，存储为自实现的带校验和追加日志与快照。处于 0.x 阶段，仅支持 macOS 和 Linux。

  • 读取不离开本机，写入离线即时落地，网络恢复后由 daemon 推送至 hub
  • 支持 watch 按键前缀流式推送本机与其他机器的变更，值上限 1 MB JSON 文档
  • 提供部分副本（--sync 指定键前缀）与集合 schema 约束（受保护配置热重载，被拒绝写入留存于 _rejected/）

适用场景（解读层）

  • 少量互信机器间共享小型 JSON 数据（机器状态上报、共享任务、配置）
  • 网络分区频繁、需离线读写并在恢复后同步的场景
  • Shell 脚本或程序通过管道/socket 读写与监听 JSON 键值变更
