面向 SQLite 的用户态版本化文件系统，以 VFS 扩展实现快照

综述（解读层）

MojoFS 是一个专为 SQLite 数据库设计的用户态版本化文件系统，以 SQLite 扩展/VFS 形式提供（libmojo 动态库），并附带 mojo-cli 管理工具。任意时刻仅有一个可写版本，已提交的旧版本不可变，可通过连接参数 ver 与 mode=ro 只读访问历史版本。当前为 pre-alpha 阶段，仅支持 macOS/Linux，要求页面大小设置与 SQLite 一致，否则数据库会损坏。

  • 以 SQLite VFS 扩展（.load 加载）方式运行，数据库存储为目录，通过 URI 参数 vfs=mojo、pagesz、ver、mode 控制版本与读写模式
  • 提供版本/快照机制：mojo-cli commit 提交后版本号递增，旧版本不可变且只读，最大版本数为 2^24（约 1677 万）
  • 由 Rust（crates 目录）与 C（sqlite-ext 目录）实现，使用 Meson+Ninja 构建，包含黑盒测试 testdb.py（198 项测试组合）与性能测试 perftest.py

适用场景（解读层）

  • 需要保留 SQLite 数据库历史版本并在旧版本上执行只读查询的场景
  • 在 macOS/Linux 上通过 VFS 扩展为 SQLite 应用接入版本化存储机制
  • 对 SQLite 存储层进行黑盒与性能测试的实验环境

MojoFS is a versioning, userspace filesystem for sqlite DB. It is tailor made for sqlite and not supposed to be used as a general purpose fs.
