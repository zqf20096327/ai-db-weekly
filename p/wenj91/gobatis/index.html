Go 语言的 MyBatis 风格 SQL 映射框架，基于 XML mapper 配置

综述（解读层）

gobatis 是一个 Go 语言的类 MyBatis 持久层框架，通过 XML mapper 文件编写 SQL，支持 select/insert/update/delete 标签及 resultType 多种结果映射（map、struct、value 等）。数据源经 YAML 或代码配置，支持多数据源。目前仅在 MySQL、TiDB、MariaDB 上测试，Postgres、SQLite 尚未兼容。适合需要在 Go 中沿用 MyBatis XML SQL 组织方式的开发者。

  • 通过 XML mapper 文件管理 SQL，select/insert/update/delete 标签以 id 唯一标识
  • resultType 支持 map、maps、array、arrays、struct、structs、value 七种结果映射
  • 支持多数据源 YAML 配置与代码方式配置，可设置连接数、存活时间等参数，并提供增删改查代码生成工具（mctl）

适用场景（解读层）

  • 需要在 Go 项目中以 XML mapper 方式组织 SQL 语句的场景
  • 使用 MySQL、TiDB 或 MariaDB 且需要多数据源配置的项目
  • 需要自动生成基础增删改查代码以减少手写模板代码的团队
