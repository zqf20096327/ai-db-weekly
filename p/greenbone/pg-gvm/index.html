🧭 简介解读层（AI·证据行可回查）

Greenbone 出品的 PostgreSQL 扩展，提供 SQL 内计算主机与 ical 信息的工具函数库

综述（解读层）

pg-gvm 是 Greenbone 维护的 PostgreSQL 扩展库，封装主机信息与 iCalendar 相关的工具函数，可在 SQL 语句内调用，另含 PostgreSQL 升级迁移器。需 GCC、cmake≥3.18、libical≥3.0.11、glib、PostgreSQL dev≥9.6 等依赖，经 cmake 构建安装后用 CREATE EXTENSION 启用，测试基于 pgTAP，通过 pg_prove 运行。适合需要在 SQL 中处理 ical 数据或配合 Greenbone 技术栈使用的场景。

  • 提供在 SQL 语句中计算主机信息与 ical（iCalendar）信息的工具函数
  • 包含 PostgreSQL Upgrade Migrator，用于数据库升级迁移
  • 支持 CREATE EXTENSION 方式安装，测试基于 pgTAP 并用 pg_prove 执行

适用场景（解读层）

  • 需要在 SQL 语句内处理或计算 iCalendar 数据的 PostgreSQL 数据库
  • Greenbone 相关系统的数据库部署与版本升级迁移
  • 需要对扩展函数进行 pgTAP 单元测试的 PostgreSQL 开发环境

This library contains PostgreSQL utility functions. For example to compute host and ical information within SQL statements.
