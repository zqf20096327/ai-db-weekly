MySQL 客户端库的 Swift 6 封装，提供原始 API 与 PerfectCRUD 集成层

综述（解读层）

Perfect-MySQL 是 libmysqlclient 的 Swift 封装，供服务端 Swift 开发者在 macOS 12+ 或 Linux 上访问 MySQL 服务器。它提供同步阻塞的原始 MySQL API，并通过 MySQLDatabaseConfiguration 接入 PerfectCRUD，支持外键约束与动态行查询。4.0 版要求 Swift 6.2，依赖系统级 mysqlclient 客户端库，不支持 iOS。

  • 提供原始 MySQL API（MySQL/MySQLStmt）与 PerfectCRUD 集成层两种使用方式
  • 支持 TLS 连接设置（SSL_MODE 与 CA 证书），并对 MariaDB Connector/C 做 SSL 模式映射
  • 支持 @ForeignKey 生成的真实外键约束及 PerfectCRUD 动态行（DynamicRow）读取 API

适用场景（解读层）

  • 服务端 Swift 项目中通过 PerfectCRUD 或原始 API 访问 MySQL 数据库
  • 需要运行时动态构建查询（表、字段、谓词在编译期未知）的模板引擎、管理工具或查询生成器
  • 需要 MySQL 外键约束（CASCADE/SET NULL 等）并在 Swift 类型间往返的场景
