🧭 简介解读层（AI·证据行可回查）

基于多种数据源的分布式监控报警系统，用查询规则触发消息

综述（解读层）

Frostmourne 是汽车之家经销商技术部监控系统的开源版本，用于对 Elasticsearch、Prometheus、SkyWalking、InfluxDB、MySQL/TiDB、ClickHouse、SqlServer、IoTDB 数据及 HTTP、PING、Telnet 做监控并报警。基于 Java8/Spring Boot2 与 vue-element-admin 实现，通过编写数据查询配置监控规则，支持 Freemarker 消息模板、同比环比计算与报警抑制。README 注明其 HTTP 数据源功能存在 SSRF 风险，建议仅部署于内网。

  • 支持 Elasticsearch、Prometheus、SkyWalking、InfluxDB、MySQL/TiDB、ClickHouse、SqlServer、IoTDB 数据监控，以及 HTTP、PING、Telnet 监控
  • 提供 count、min、max、avg、sum、unique count、percentiles、标准差等数值计算监控和同比、环比监控
  • 消息发送支持钉钉、企业微信、飞书机器人、Email、短信、HTTP，消息格式含 text 和 markdown，使用 Freemarker 模板定制

适用场景（解读层）

  • 已建立日志系统或指标体系后，需要对 Elasticsearch、Prometheus 等数据配置监控报警的团队
  • 需要通过钉钉、企业微信、飞书、Email 等渠道接收报警消息的运维场景
  • 内网环境下对 HTTP 接口、端口连通性（PING/Telnet）进行监控
