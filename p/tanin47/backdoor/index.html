可自托管的数据库查询与编辑工具，基于 Java 嵌入式 Web 框架。

综述（解读层）

Backdoor 是一个数据库查询与编辑工具，提供自托管版本和桌面应用版本。它支持 PostgreSQL、SQLite 和 ClickHouse，用于查看、编辑数据、执行 SQL 及管理表。自托管版本以 fat jar 形式发布，无外部依赖，可通过 Docker、JAR 独立运行，也可嵌入 JVM 应用。它支持 masked users 与数据库用户两种登录方式，避免共享数据库凭据。DuckDB、MySQL 等数据库在 README 中标记为开发中。

  • 支持 PostgreSQL、SQLite、ClickHouse 三种数据库，可同时配置多个数据源
  • 支持 masked users 与数据库用户两种认证方式，Cookie 使用 AES-256 加密并内置 Proof-of-Work 验证码
  • 以自包含 fat jar 发布，可作为独立服务运行或嵌入 JVM 应用指定端口/路径提供服务

适用场景（解读层）

  • 团队需要自托管的数据查询与编辑入口，避免向成员共享数据库凭据
  • Java 应用需内嵌数据库管理界面，通过指定端口或路径提供服务
  • 个人在 macOS 或 Windows 上通过桌面应用查询和编辑本地数据库
