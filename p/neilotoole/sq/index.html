🧭 简介解读层（AI·证据行可回查）

提供 jq 风格查询 SQL 数据库与 CSV/Excel 等文档格式的命令行数据工具

综述（解读层）

sq 是一个 Go 编写的命令行工具，通过驱动机制访问 SQLite、Postgres、MySQL、SQL Server、Oracle 等数据库及 CSV、Excel 等文档数据源，将其统一当作数据源处理。用户用 sq add 注册数据源后，可执行 jq 风格查询或原生 SQL，支持跨数据源连接、查询结果写入数据库表，并提供 inspect、diff、tbl copy/truncate/drop 等子命令。可通过 brew、scoop、脚本、go install 或 Docker 安装。

  • 支持 jq 风格查询语法与数据库原生 SQL，可跨数据源执行连接（如 CSV 连接 Postgres 表）
  • 输出格式包含 text、json、jsonl、csv/tsv、xlsx、html、xml、yaml、markdown 等，查询结果可直接插入数据库表
  • 提供 sq inspect 查看源/表元数据，sq diff 比较表结构与行数据，tbl copy/truncate/drop 操作表，文件源支持 UNIX 管道输入

适用场景（解读层）

  • 在命令行中对 SQL 数据库或 CSV/Excel 文件执行查询并导出为多种格式
  • 在不同数据库或文档数据源之间复制、迁移数据（如 Excel 写入 SQLite 表）
  • 比较表结构或行数据差异，或在 Kubernetes 容器中执行数据操作任务

sq is a command line tool that provides jq-style access to structured data sources: SQL databases, or document formats like CSV or Excel. It is the lovechild of SQL+jq.
