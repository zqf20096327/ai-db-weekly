浏览与编辑 DaruDB 数据库文件的跨平台桌面应用

综述（解读层）

DaruDB Studio 是一个基于 Electron 的桌面应用，用于打开、浏览、查询和编辑 DaruDB 本地数据库文件，支持 Windows、macOS 和 Linux。它以项目为单位管理文件，从文件本身读取 schema，提供分页表格、过滤查询、CSV/JSON 导入导出、完整性检查、备份与修复工具；加密文件的密钥可存入系统 keystore。适合使用 DaruDB 存储数据、需要在无代码情况下查看和修改数据的开发者。

  • 支持打开、浏览、编辑加密或非加密的 DaruDB 数据库文件，加密密钥可交由操作系统 keystore 加密保管
  • 提供分页网格浏览、查询语言过滤、单元格及表单编辑，并可导出/导入 CSV 与 JSON
  • 包含 schema 查看（TypeScript/JSON）、文件完整性检查、压缩、备份及损坏文件抢救等工具

适用场景（解读层）

  • 无需编写程序，直接查看和修改 DaruDB 文件中的 collections 与对象
  • 检查数据库文件完整性、执行压缩、备份或更改加密密钥
  • 通过示例商店数据库尝试和了解 DaruDB 的各类字段类型
