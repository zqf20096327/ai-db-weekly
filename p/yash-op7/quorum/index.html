Go 编写的多 Raft 分片分布式键值存储，底层为自建 LSM 引擎

综述（解读层）

Quorum 是一个用 Go 从零实现的分片 KV 存储：键空间按范围分片，每个分片独立运行 Raft 复制组，副本数据由手写 LSM-tree 引擎持久化，客户端经 gRPC 获得线性一致读写。README 说明其定位为学习型系统（作者为实践 DDIA 内容而构建），v1 已完成；集群拓扑为静态配置，多键事务与跨节点扫描尚未实现。

  • 每个分片独立 Raft 组（基于 hashicorp/raft），支持领导者选举、日志复制、快照与自动故障转移
  • 自建 LSM-tree 存储引擎：skip-list memtable、含稀疏索引与布隆过滤器的 SSTable、size-tiered 压缩、LRU 块缓存
  • 实现 leader-lease 本地读、group commit（并发写合并为一条日志条目）及 NOT_LEADER 重定向路由

适用场景（解读层）

  • 学习多 Raft 分片、Raft 共识与 LSM 引擎等分布式存储机制
  • 在测试环境运行具备线性一致读写与自动 failover 的小型 KV 集群
  • 通过 gRPC API（Get/Put/Delete/流式 Scan/Join）接入自定义客户端，或用 quorumctl CLI 操作
