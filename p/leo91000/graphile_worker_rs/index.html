🧭 简介解读层（AI·证据行可回查）

基于 PostgreSQL 的 Rust 后台任务队列，移植自 Graphile Worker。

综述（解读层）

该项目为 Rust 应用提供以 PostgreSQL 作为队列与协调后端的持久化后台任务系统，基于 Graphile Worker 用 Rust 重写。通过 `SKIP LOCKED` 认领任务并利用 `LISTEN`/`NOTIFY` 实现低延迟唤醒。适用于需要在 Rust 服务中执行后台任务、或需将 PostgreSQL 触发器产生的任务导出到其他队列的开发者。支持与 Node.js 版本共享同一 schema 并行运行。

  • 任务认领使用 PostgreSQL 的 `SKIP LOCKED`，通过 `LISTEN`/`NOTIFY` 实现低延迟唤醒
  • 支持类型化任务处理器、延迟任务、优先级、重试、命名队列及基于 crontab 的周期任务
  • 提供 CLI 与管理 UI 模块，以及生命周期钩子、心跳式死 worker 恢复等运维能力

适用场景（解读层）

  • Rust 应用需要持久化后台任务且以 PostgreSQL 为队列后端
  • 将 PostgreSQL 触发器/函数生成的任务导出到其他工作队列
  • 与现有 Node.js 版 Graphile Worker 共享同一数据库 schema 并行运行
