为 Doctrine 提供 PostgreSQL 原生类型、操作符与函数映射的 PHP 包

综述（解读层）

该包面向使用 Doctrine ORM/DBAL 的 PHP 开发者，通过注册自定义类型与 DQL 函数，在 PHP 层使用 PostgreSQL 的数组、JSONB、范围、PostGIS 几何、全文搜索等特性。支持 PostgreSQL 9.4+ 与 PHP 8.2+，通过 Composer 安装，部分类型需启用对应数据库扩展（如 pgvector、hstore、citext）。

  • 提供 40 余种 PostgreSQL 类型映射，覆盖数组、JSONB、范围/多范围、几何、网络地址、ltree、向量等，并支持用户自定义 enum 与复合类型
  • 实现数组、JSON、范围、PostGIS 空间等 PostgreSQL 操作符及 100+ 个可在 DQL 中调用的函数，包括聚合、窗口、文本搜索与向量距离函数
  • 提供 Symfony、Laravel、Doctrine 集成指南，并附针对真实 PostgreSQL+PostGIS 数据库的集成测试

适用场景（解读层）

  • Doctrine 项目需在 PHP 侧映射与操作 PostgreSQL 原生数组、JSONB 或范围类型
  • 需要通过 DQL 使用 PostGIS 空间查询、全文搜索或 pgvector 向量距离函数的场景
  • 使用 Symfony 或 Laravel 且需扩展 Doctrine DQL 以调用 PostgreSQL 专用函数的项目
