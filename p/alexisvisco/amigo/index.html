Go 语言数据库迁移工具，支持 SQL 与 Go 两种迁移方式

综述（解读层）

Amigo 是一个用 Go 编写的数据库迁移工具，提供 CLI 和可编程 API 两种使用方式。迁移可用 SQL 文件（通过 embed.FS 嵌入二进制）或 Go 代码编写，SQL 迁移通过注释标注区分 up/down 并控制事务开关。内置 PostgreSQL、SQLite、ClickHouse 驱动，仅依赖标准库。适合需要在 Go 项目中管理数据库 schema 版本的团队。

  • 支持 SQL 文件与 Go 代码两种迁移编写方式，SQL 通过 embed.FS 嵌入二进制
  • 提供 generate/up/down/status 等 CLI 命令，以及带进度反馈的可编程 API
  • 内置 PostgreSQL、SQLite、ClickHouse 驱动，支持逐迁移的事务开关（tx=true/false）

适用场景（解读层）

  • Go 项目中管理 PostgreSQL/SQLite/ClickHouse 的 schema 版本变更
  • 需要将迁移 SQL 打包进单个二进制进行部署的场景
  • 多数据库环境（如 PostgreSQL + ClickHouse）分别管理迁移的场景
