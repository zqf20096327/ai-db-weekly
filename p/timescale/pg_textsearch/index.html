🧭 简介解读层（AI·证据行可回查）

PostgreSQL 扩展，基于 BM25 排序的全文检索，采用 C 实现

综述（解读层）

pg_textsearch 是 Timescale 发布的 PostgreSQL 扩展，为文本列提供 BM25 相关性排序搜索。通过 `USING bm25` 索引和 `<@>` 操作符查询，支持 PostgreSQL 17/18/19，需加入 shared_preload_libraries 后重启。支持表达式索引、部分索引、分区表、tsquery 布尔过滤，及 Block-Max WAND top-k 查询和并行索引构建。注意布尔过滤与排序尚未合并为单次索引扫描，部分索引需显式指定索引名。

  • BM25 排序，支持 k1/b 参数配置
  • Block-Max WAND 实现快速 top-k 查询
  • 支持表达式索引、部分索引、分区索引和并行索引构建

适用场景（解读层）

  • 在 PostgreSQL 内对文档表做 BM25 相关性排序检索
  • JSONB 字段或表达式的全文搜索
  • 多语言表按语言建部分索引（含中文场景）
