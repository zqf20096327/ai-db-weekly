PostgreSQL 的 BM25 相关性排序全文搜索扩展

综述（解读层）

pg_textsearch 是 Timescale 开发的 PostgreSQL 扩展，通过 bm25 索引类型和 `<@>` 操作符实现按 BM25 分数排序的全文检索，需加入 shared_preload_libraries 后启用。支持 tsquery 布尔过滤、表达式/部分/分区索引、Block-Max WAND top-k 查询与并行建索引，兼容 PostgreSQL 17、18（19 beta 尽力支持），采用 Postgres OSS 许可证。

  • 提供 BM25 排序索引，可配置 k1、b 参数，查询语法为 ORDER BY content <@> 'query'
  • 支持 tsquery 布尔过滤（AND/OR/NOT、短语、前缀匹配）、表达式索引、部分索引与分区表
  • top-k 查询使用 Block-Max WAND，支持并行索引构建与分段压缩

适用场景（解读层）

  • 在 PostgreSQL 内实现按相关性排序的文档全文检索
  • 基于 JSONB 字段或多列表达式建 BM25 索引的检索
  • 多语言表按语言分别建索引检索，或经 zhparser 配置中文检索
