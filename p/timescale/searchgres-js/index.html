基于 PostgreSQL 的混合检索 TypeScript 库，融合 BM25 与向量搜索及 RRF。

综述（解读层）

searchgres.js 是开源 TypeScript 库，在 PostgreSQL 中实现 BM25、HNSW 向量搜索、RRF 混合排序与结构化过滤，由库管理搜索 schema、索引和嵌入流程。适合希望在自控数据库内搭建检索或 RAG 能力的开发者。需 PostgreSQL 18 及 pgvector、pg_textsearch、ltree 扩展，Node ≥22 或 Bun ≥1.4；核心不含用户与授权模型。

  • 支持 BM25、HNSW 向量搜索、RRF 混合检索及按树路径、JSONB、时间范围和正则的组合过滤
  • 搜索索引为普通 PostgreSQL schema，支持事务、备份、复制与直接 SQL 访问
  • 内置嵌入队列，提供 processEmbeddings() 与并发安全的 EmbeddingWorker；仓库附带 CLI、MCP 工具和 Docker Compose 评估环境

适用场景（解读层）

  • 在自有 PostgreSQL 中实现应用搜索或托管搜索 API
  • 基于自有分块与生成流程构建 RAG 检索层
  • 通过代码、SQL 或触发器从现有表构建索引管道
