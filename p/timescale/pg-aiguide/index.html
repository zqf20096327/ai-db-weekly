为 AI 编码工具提供 PostgreSQL 技能与文档语义检索的 MCP 服务器

综述（解读层）

pg-aiguide 是由 Timescale 维护的项目，为 AI 编码代理提供 PostgreSQL 知识：通过 MCP 服务器对官方 PostgreSQL、TimescaleDB、PostGIS 文档做语义与关键词（BM25）检索，并通过 npx skills 或 Claude Code 插件分发整理好的 Postgres 最佳实践技能。支持 Claude Code、Cursor、Codex、Gemini CLI 等 40+ 代理。MCP 服务器端点由 TigerData 托管，扩展文档目前仅含 TimescaleDB 与 PostGIS，pgvector 尚未支持。

  • 提供 search_docs 工具，支持跨 PostgreSQL、Tiger Data、PostGIS 文档的语义（向量相似）与关键词（BM25）检索，PostgreSQL 手册按版本划分
  • 通过 npx skills 或 Claude Code 插件分发 postgres、schema-exploration 等最佳实践技能，覆盖模式设计、索引、数据类型、约束、命名规范、性能调优等主题
  • 支持 MCP 服务器、Agent Skills、Claude 插件三种接入方式，兼容 Claude Code、Cursor、Codex、Gemini CLI 等多种代理，Apache 2.0 许可

适用场景（解读层）

  • 让 AI 编码工具在生成 PostgreSQL 模式和查询时参考特定版本的官方文档与最佳实践技能
  • 用 schema-exploration 技能调查现有 PostgreSQL 数据库的结构与对象
  • 为使用 TimescaleDB 或 PostGIS 的项目在 AI 代理中接入相应扩展文档检索
