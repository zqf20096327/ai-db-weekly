Rust 编写的 Sigma 检测工程工具集，涵盖解析、评估、转换与流式运行时

综述（解读层）

RSigma 是面向 Sigma 检测标准的 Rust 工具集：将 YAML 规则解析为强类型 AST 并编译为匹配器，实时评估日志事件，支持有状态关联与多格式输入（JSON、syslog、EVTX、OTLP 等）。提供 linter、formatter、LSP/MCP 服务及可插拔后端转换。README 未给出安装命令，文档在 rsigma.io，采用 MIT 许可。

  • 内置 90 项检查的 linter 与支持 VSCode、Neovim 等 LSP 编辑器的实时诊断、补全与格式化
  • 流式守护进程支持热重载、Prometheus 指标、stdin/HTTP/NATS/OTLP 等输入及带重试与 DLQ 的多路输出
  • 规则可转换为 PostgreSQL/TimescaleDB、LynxDB、Fibratus 原生查询，或经 sigma-cli 委托 30+ 个 pySigma 后端

适用场景（解读层）

  • 在 CI 中通过 GitHub Action 对规则仓库执行 lint、校验、回测与覆盖率检查
  • 以长驻守护进程实时接收多格式日志并运行无状态检测与滑动/滚动/会话窗口关联
  • 将 Sigma 规则转换为后端查询语言，对 PostgreSQL/TimescaleDB 日志归档执行只读狩猎
