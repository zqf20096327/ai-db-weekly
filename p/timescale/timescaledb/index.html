TimescaleDB：以 PostgreSQL 扩展形式提供的时间序列实时分析数据库

综述（解读层）

TimescaleDB 是一个 PostgreSQL 扩展，用于对时间序列和事件数据执行实时分析，通过 CREATE EXTENSION 后调用 tsdb.hypertable 将普通表转换为超表。它支持按时间自动分块、列式存储压缩、time_bucket 聚合函数以及可增量刷新的 continuous aggregates。安装可用一键脚本或 Docker 镜像 timescale/timescaledb-ha:pg18，脚本仅适用于本地开发测试。适合需在 PostgreSQL 生态内处理时序数据的开发者。

  • 将 PostgreSQL 表转换为 hypertable，按时间自动分块分区以限定查询扫描范围
  • 支持列式存储写入与向量化查询，并可采用 continuous aggregates 在后台增量刷新预聚合数据
  • 提供 time_bucket 函数用于时序聚合，支持数据保留策略与分层存储

适用场景（解读层）

  • IoT 传感器数据等高频时序数据的存储与聚合查询
  • 金融市场行情数据、加密货币 tick 数据的分析
  • 应用事件日志记录与基于时间的实时分析
