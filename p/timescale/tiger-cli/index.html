Tiger Cloud 的命令行工具，含管理数据库服务和供 AI 助手调用的 MCP 服务器

综述（解读层）

Tiger CLI 是 Tiger Cloud 的命令行界面，用于管理和查询数据库服务，面向使用 Tiger Cloud 托管 Postgres 的开发者与运维人员。它提供服务生命周期（创建、fork、启停、调整规格）、psql 连接、SQL 查询、schema 查看及指标读取等命令；内置 MCP 服务器可由 `tiger mcp install` 接入 Claude Code 等 AI 助手，暴露服务管理与 db_query、db_schema 等工具，并代理文档语义搜索服务器 pg-aiguide。MCP 复用 CLI 登录凭据，需先 `tiger auth login`；destructive 命令要求输入服务 ID 确认，HTTP 模式下 db_query 仅接受内联 SQL。

  • 提供服务创建、fork、启停、resize、密码更新、日志与指标时间序列等命令，服务可用 ID 或名称引用（名称须精确且唯一）
  • 内置 MCP 服务器，支持 stdio 与 Streamable HTTP 两种传输，暴露 service_*、db_query、db_schema 等工具，并代理 view_skill 与 search_docs 文档工具
  • 提供 `tiger skills install` 为 AI 编码代理安装 PostgreSQL 与 TimescaleDB 技能

适用场景（解读层）

  • 在终端或脚本中管理 Tiger Cloud 数据库服务的生命周期与查询
  • 为 Claude Code 等 AI 助手配置 MCP，使其能创建服务、执行 SQL 并读取 schema 与文档
  • 通过 `tiger upgrade` 以校验和验证方式升级 CLI，或通过 Homebrew/apt/yum/Go 安装
