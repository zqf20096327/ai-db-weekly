🧭 简介解读层（AI·证据行可回查）

AI 代理插件，从源码生成项目 ERD，无需外键也能推断表关系。

综述（解读层）

open-erd 是一个 Claude Code / Codex 插件，通过读取模型、迁移与关联代码为项目生成实体关系图，即使数据库未声明外键也能推断关系，并经第二个代理逐项核对。输出交互式 SVG、Excel 与 draw.io 文件。支持 Rails、Laravel、Django、Prisma、TypeORM、Sequelize、Mongoose 及原始 SQL。仅读取文件，不启动应用、不写入仓库。

  • 从模型、迁移和关联（含多态关联）中提取表关系，经第二个代理验证后写入结果
  • 生成浏览器可用的交互式 erd.svg，附带 Excel（每表一页，含 Relations/PII/Health）与 draw.io 文件
  • 支持命令面板搜索表与列、查看两表连接路径并生成 SELECT…JOIN、PII 高亮、schema 健康项列举及 /open-erd:diff 版本对比

适用场景（解读层）

  • 为缺少外键声明的遗留数据库项目补全实体关系文档
  • 代码变更后通过 /open-erd:sync 保持 ERD 与代码同步
  • 面向数据模型提问（如退款流程）、梳理 PII 分布或准备讲解演示（按 domain 的 tour 模式）
