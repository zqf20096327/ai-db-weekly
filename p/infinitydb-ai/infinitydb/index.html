🧭 简介解读层（AI·证据行可回查）

开源 Agent 记忆引擎，用符号短期记忆加分层长期记忆存储与检索对话事实。

综述（解读层）

InfinityDB 是面向 AI Agent 的本地记忆引擎，将原始对话日志与规则抽取的原子事实分层存储，支持时间戳事实替换、SHA-256 溯源链、按租户隔离的策略，以及基于 SQLite FTS5 的混合检索。读写路径无需 API 密钥和网络调用，后端可运行于 SQLite 或 Postgres。注意内置规则只能解析特定句式事实，自由文本事实不会自动替换。

  • L0–L6 分层记忆结构：原始日志、原子事实、事件图，均可离线检查，附 Mermaid 导出
  • 带时间戳的事实历史，单值新事实自动替代旧值，recall 支持 as_of 时间点查询
  • 每条事实含 SHA-256 哈希链接到原始日志片段；内置 MCP server，examples/ 提供 LangChain、CrewAI、LlamaIndex 适配器

适用场景（解读层）

  • 为多轮对话 Agent 提供本地持久化记忆，减少模型上下文中的历史对话占用
  • 多租户环境下需要按会话/租户隔离记忆与策略的应用
  • 需要事实时间演进追踪（如地点、角色、雇主变化）与来源可验证的 Agent 系统
