开源 ERD 数据库图表绘制工具，支持 JavaScript 脚本执行

综述（解读层）

HedgehogDBD 是一个用于 ERD 模式创建的 Web 应用，通过紧凑的表格编辑视图和自动关系连接实现数据库模型的可视化。用户可基于模式编写并执行 JavaScript 脚本，使用 Monaco Editor 编辑，内置脚本与用户通过 Giscus 评论分享的脚本均可使用。支持本地运行于 localhost:8080。

  • 支持表 CRUD、PNG 导出、JSON 导入/导出、平移/缩放/小地图导航及撤销/重做
  • 基于 Monaco Editor 编写可执行的 JavaScript 脚本，可基于模式数据运行
  • 包含内置脚本及通过 Giscus 评论分享的用户脚本

适用场景（解读层）

  • 在浏览器中可视化数据库模型并绘制 ER 图
  • 编写脚本对数据库模式数据进行处理或生成内容
  • 通过 JSON 导入/导出在不同环境间迁移模式定义
