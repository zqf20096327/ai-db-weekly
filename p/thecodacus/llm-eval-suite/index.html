🧭 简介解读层（AI·证据行可回查）

自托管的本地 LLM 测试套件，以 Docker 一体化运行三类评测。

综述（解读层）

这是一个面向自托管环境的本地 LLM 评测 Web 应用，对接任何 OpenAI 兼容服务（如 LM Studio、Ollama、llama-server）。提供确定性、智能体（真实 curl 工具调用并经内置捕获服务器验证）和盲评主观三类测试，每轮记录正确率与速度（tok/s）。支持从 HuggingFace 导入 GPQA Diamond、MMLU-Pro、AIME 2025 等公开基准；数据存于 SQLite 卷，README 提示执行模型生成的代码时建议为对抗性输出添加沙箱。

  • 支持三类评测：确定性（数学/代码/抽取/结构化 JSON）、智能体（生成 curl 并由内置捕获服务器验证）、盲评主观（A/B/C 匿名对比）
  • 支持导入 HuggingFace 公开基准（GPQA Diamond、MMLU-Pro、AIME 2025），可经 Web 界面或 stdlib 实现的 CLI 脚本导入，重跑幂等
  • 智能体套件以无 shell（tokenized argv）方式执行 curl，仅允许指向内置捕获服务器并拒绝文件系统相关标志；每轮记录正确率与 tok/s

适用场景（解读层）

  • 对本地部署的多个 OpenAI 兼容模型做正确率与速度对比测试
  • 量化/家族模型对比时导入 GPQA Diamond、MMLU-Pro、AIME 等难基准作为参照
  • 对模型生成写作质量做人工盲评（匿名 A/B/C 选择）
