嵌入式 ACID 向量数据库，单文件融合 SQL、向量检索与知识图谱

综述（解读层）

SochDB 是一个嵌入式、支持 ACID 事务的 AI 数据库，将结构化数据、向量与代理记忆存储于单一列式引擎，并提供按 token 预算组装上下文的 Context Query Builder。提供 SQL-92 兼容查询、HNSW+BM25 混合检索与双时态知识图谱，面向构建 LLM 代理及记忆功能的开发者，支持 Rust/Python/Node.js/Go SDK 与 Docker 部署。

  • 支持 SQL-92 兼容查询（JOIN、聚合、多方言归一化）、HNSW 向量+BM25 混合检索及 MVCC+WAL+可串行化快照隔离的 ACID 事务
  • 提供双时态知识图谱、Context Query Builder 按 token 预算融合多源检索并输出 TOON 紧凑格式
  • 提供 Rust/Python/Node.js/Go SDK，支持嵌入式（FFI）与 IPC（Unix socket）两种运行模式，并可经 Docker 以 gRPC 服务部署

适用场景（解读层）

  • 为 LLM 代理构建本地长期记忆与知识图谱检索
  • 在单文件嵌入模式下为应用集成向量+关键词混合搜索
  • 按 token 预算组装多源上下文供大模型调用
