基于 asyncio 通过原生接口访问 ClickHouse 的 Python 库

综述（解读层）

aioch 是一个 Python 库，用于在 asyncio 环境下通过原生接口访问 ClickHouse 数据库。它在 clickhouse-driver 之上封装异步用法，接受自定义 executor 和事件循环参数，其余参数透传给被封装的 Client。适合需要在 asyncio 应用中读写 ClickHouse 的开发者，使用示例可参考 clickhouse-driver 文档。

  • 通过原生接口访问 ClickHouse 数据库
  • 包装 clickhouse-driver 以支持 asyncio 异步使用
  • 支持传入自定义 Executor 与 asyncio 兼容的事件循环

适用场景（解读层）

  • 在 asyncio 应用中通过原生接口连接 ClickHouse
  • 复用 clickhouse-driver 参数配置的异步查询场景
  • 需要自定义执行器或事件循环的异步数据库访问
📖 README 首段存档原文 · 程序抽取

aioch is a library for accessing a ClickHouse database over native interface from the asyncio. It wraps features of clickhouse-driver for asynchronous usage.
