🧭 简介解读层（AI·证据行可回查）

以 case class 为源、自动派生表单与 CRUD 路由的 Scala 3 Web 框架

综述（解读层）

Eezo 是一个 Scala 3 Web 框架，以 case class 声明为单一来源，派生 Postgres 表、HTML 表单、7 条 CRUD 路由，加 derives Api 后再提供 5 条 JSON 路由。处理器为普通函数，基于虚拟线程，UI 服务端渲染并通过 websocket 推送 DOM 差异补丁。要求 JDK 25、Scala 3.9、sbt 插件与 Postgres，可用 eezo deploy 部署到 Fly.io。

  • case class 派生 Postgres 表、类型安全查询 API 与 7 条 CRUD 路由，schema 变更可检测并生成带指纹的 SQL 迁移
  • 文件路径即 HTTP 路由：sbt 插件读取源码生成路由表，可用 Route.under 等方式在运行前变换
  • 提供行级守卫（Owned given 实例）控制登录与行归属，内置 sessions、CSRF、email/密码登录等认证模块

适用场景（解读层）

  • 以数据模型为中心的 CRUD 应用（如博客、后台管理），希望由模型声明直接生成页面、API 与数据库表
  • 需要服务端渲染并保持服务器状态的实时页面（如带 PubSub 的实时看板）
  • 部署到 Fly.io 的 Scala 3 全栈小应用，使用 Postgres 作为数据库
