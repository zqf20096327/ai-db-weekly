CEDS 教育数据集成数据仓库，基于第三范式关系的 SQL Server 数据模型

综述（解读层）

CEDS IDS 是美国 Common Education Data Standards 项目提供的 SQL Server 数据库模型，将 CEDS 全部元素、实体与属性以第三范式规范化组织，用于 P-20W 教育数据系统集成。用户可通过 /src 下的 DDL 脚本创建实例，再执行脚本加载 CEDS 元数据与选项集参考数据，默认数据库为空。版本采用显式版本管理并定期与 CEDS 元素对齐，需自行备份后运行升级脚本。

  • 提供 SQL Server DDL 脚本（/src/ddl/CEDS-IDS.sql）创建第三范式数据库实例
  • 包含 _CEDSElements 与 _CEDStoIDSMapping 元数据表及参考数据（选项集）加载脚本
  • 提供 /src/upgrade 下的增量升级脚本与显式版本管理机制

适用场景（解读层）

  • 构建事务型教育数据系统的操作型数据存储
  • 作为标准暂存区加载 CEDS 数据仓库
  • 教育数据系统的准实时报告
