综述（解读层）

AbyssDB 是一个以 Go/SQL 形态发布的项目，README 宣称其存储直接对接内核字符设备（Linux 上设备号为 1,3，即 /dev/null 类设备），状态转移函数将每次写入映射回初始状态 S₀，并以此给出同时满足 ACID、BASE 与 CAP 的“证明”。它提供 AbyssQL 方言、键值接口、分支、ML-KEM-768 与双重加密等特性。读者可将本条目理解为对 README 内容的转述，其宣称的零占用、常数时间等性质与常规数据库语义不一致，使用前需自行核实其设计意图与实际行为。

  • 提供 SQL 接口（AbyssQL，README 称 33 种语句类型的手写递归下降解析器）与键值接口，支持 JSON/YAML/TOML/XML/CSV 格式自动检测
  • README 描述其存储层为内核字符设备（Linux/macos/FreeBSD/Windows/WASI 均标注 Certified），无文件系统、无页缓存
  • 支持数据库分支（copy-on-write）、模式校验、AES-256-GCM 与 ChaCha20-Poly1305 双层加密及 ML-KEM-768 密钥派生

适用场景（解读层）

  • 阅读其 README 与论证文档（CAP 证明、ACID/BASE 同时满足论文）作为教学或讨论材料
  • 在需要了解开源社区中娱乐性/概念性数据库项目形态时作为编目对象
  • 作为数据库一致性理论（CAP/PACELC）讨论的反例素材（以其 README 自述内容为依据）
