PQL 是一个将类 Kusto 管道式查询语言编译为 SQL 的 Go 库

综述（解读层）

这是一个用 Go 编写的查询语言编译器，把受 Kusto Query Language 启发的管道式语法（如 StormEvents | where … | top …）编译为 SQL，并提供 CLI 调用。生成的 SQL 不绑定特定数据库，但仅在 ClickHouse SQL 方言上做过测试。支持的表操作符包括 where、summarize、join、project、extend 等，let 语句仅支持标量表达式；未内置的函数会透传给底层 SQL 引擎。适用于希望在 SIEM/检测工程等场景用管道语法生成 SQL 的 Go 开发者。

  • 将管道式查询语言编译为数据库无关的 SQL，并针对 ClickHouse 方言做过测试
  • 支持 as、count、join、project、extend、summarize、take/limit、top、where 等表操作符
  • 内置 not、now、isnull、iff、countif、tolower 等标量函数，未列出的函数透传到底层 SQL 引擎

适用场景（解读层）

  • 在 Go 程序或 CLI 中以管道语法生成 SQL 查询
  • 面向 ClickHouse 的 SIEM 与检测工程查询场景
  • 希望复用底层引擎完整函数 API 的查询构建
