综述（解读层）

SQLGlot 是一个无第三方依赖的纯 Python SQL 工具库，用于解析、格式化、转译、优化 SQL，并内置可将 Python 字典作为表进行查询的执行引擎。它将 SQL 解析为 AST，支持在 DuckDB、Spark、BigQuery、Hive 等 30 多种方言间转换，可通过子类化 Dialect 添加自定义方言。需要注意：解析器刻意宽松，解析成功不代表 SQL 能通过校验；使用 mypyc 编译版（sqlglot[c]）时运行时子类化受限。

  • 支持在 30 多种 SQL 方言间转译，处理日期函数、标识符定界符和数据类型的差异
  • 提供 AST 构建与修改能力，支持递归节点变换、语义 diff 和查询优化（optimize）
  • 可检测语法错误并输出结构化错误信息，方言不兼容时可配置为警告或抛出异常

适用场景（解读层）

  • 在不同数据平台（如 Spark 与 DuckDB、Presto 与 Hive）之间迁移或翻译 SQL 查询
  • 对 SQL 做格式化、查询分析（提取列/表引用）与语义化改写
  • 以 Python 字典为数据源执行 SQL，用于单元测试场景
