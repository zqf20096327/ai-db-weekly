零依赖的纯 Python SQL 解析、转译、优化与执行库

综述（解读层）

SQLGlot 是一个无第三方依赖的 Python SQL 工具库，用于解析、格式化 SQL，并在 DuckDB、Spark、Snowflake、BigQuery 等 30 余种方言间转译。它将 SQL 解析为 AST，支持表达式遍历、程序化构建与修改、语法错误检测和查询优化，还可对以 Python 字典表示的表执行 SQL。适用于需要以编程方式处理 SQL 的开发者。注意：解析器设计上较宽松，不能作为 SQL 有效性校验器。

  • 支持 30 余种 SQL 方言间的转译，包括标识符引号、数据类型、时间函数与自定义时间格式的转换
  • 提供 AST 构建、遍历、递归变换、语义 diff，以及基于优化规则的查询重写
  • 纯 Python 实现，另提供 mypyc 编译的 C 扩展版本（Python 3.10+），可检测不平衡括号、保留字误用等语法错误并给出结构化错误信息

适用场景（解读层）

  • 在不同数据平台（如 Spark SQL 与 DuckDB）之间迁移或改写 SQL 查询
  • 程序化分析、构建或修改 SQL，如提取查询中的列与表引用
  • 以 Python 字典作为表对 SQL 进行解释执行，用于单元测试
