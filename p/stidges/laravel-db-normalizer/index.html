🧭 简介解读层（AI·证据行可回查）

将 Laravel 数据库查询结果统一为 Collection 与 Entity 接口的规范化包

综述（解读层）

该 PHP 包面向 Laravel 开发者，拦截 Eloquent、Query Builder 或其他实现的数据库结果，统一转换为 Collection 与 Entity 类，便于替换仓储实现。可通过注册 ServiceProvider 启用自动规范化（Eloquent 模型需继承 NormalizableModel），或手动调用 Normalizer 类（须传入数组）。当前版本为 0.*，2014 年发布，MIT 许可。

  • 将 Eloquent、Query Builder 等不同来源的查询结果统一转换为 Collection 与 Entity 类
  • Entity 支持嵌套实体与集合、流式属性访问、toArray/toJson 转换，并提供 getDirtyAttributes() 获取变更属性
  • 支持自动规范化（注册 ServiceProvider）与手动调用 Normalizer 两种使用方式

适用场景（解读层）

  • 需要在 Eloquent、Query Builder 等不同数据访问实现之间替换仓储的项目
  • 需要以统一实体对象封装数据库结果并跟踪属性变更的场景
  • 需要将查询结果转为数组或 JSON 输出的应用
