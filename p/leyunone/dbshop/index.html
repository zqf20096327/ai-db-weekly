DBSHOP 是基于 JDBC 规则可配置的 MySQL 数据库结构比对工具

综述（解读层）

DBSHOP 是一个运行在 SpringBoot 环境中的数据库结构比对工具，提供 dbshop-api、dbshop-web、dbshop-core 三个依赖模块，分别用于 API 调用、页面交互和自动装配三种使用方式。它支持两表之间、两个数据库之间及多数据库之间的结构对比，可自定义类型转化策略（如 int(1) 与 bit(1) 归为 tinyint(1)），并生成新增/删除字段、类型与备注变更、主键增删等 SQL 语句；还提供无用表和无用字段的双向检查。当前试用版本仅支持 MySQL，且只有两种类型转换规则。

  • 支持两表、两数据库、多数据库间的对比，输出表、字段、元属性级结果，并生成字段增删、类型/备注变更、主键增删等 SQL 语句
  • 提供 API 调用、页面交互、配置文件自动装配三种使用模式，支持自定义类型转化策略
  • 提供无用表与无用字段的双向检查功能，通过页面路径 /dbshop/home 操作

适用场景（解读层）

  • 开发迭代中核对测试环境与正式环境的数据库表结构差异并生成变更 SQL
  • 项目数据库年代更迭时按自定义规则（如类型归一化）进行结构比对
  • 结合项目代码双向检查数据库中未被使用的表和字段
