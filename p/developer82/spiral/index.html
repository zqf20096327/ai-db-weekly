跨平台桌面数据库客户端，集成查询、ERD、性能分析与备份管理

综述（解读层）

Spiral 是基于 Electron、React 和 TypeScript 构建的跨平台桌面应用，用于在一个应用中管理和查询 SQL Server、MySQL、PostgreSQL、SQLite、MongoDB 与 Redis。它提供懒加载架构树、可编辑结果网格、执行计划可视化、SQL Profiler、模式对比与同步、备份恢复，以及本地运行的 AI SQL 助手（实验性）。数据与连接密码均存本地，可设应用密码加密并自动锁定。通过 npm 安装，支持 Windows/macOS/Linux 构建；macOS 因签名公证需手动下载更新。

  • 支持 SQL Server、MySQL、PostgreSQL、SQLite、MongoDB 和 Redis（含集群与哨兵模式），采用可插拔 provider 架构
  • 提供交互式 ERD 图、SQL Server 执行计划图、客户端统计、模式/行级对比与同步脚本生成
  • 内置本地 AI 助手（SQLCoder via node-llama-cpy），查询不发送到远程服务；支持环境标记、Critical 环境防护与 SSH/TLS 连接

适用场景（解读层）

  • 开发者在同一桌面工具中管理多种 SQL/NoSQL 数据库并编写、执行查询
  • 需要生成 ERD 图、查看执行计划或进行数据库性能分析的场景
  • 对生产/QA/开发环境进行区分管理，并对敏感环境执行写操作前需要确认防护
