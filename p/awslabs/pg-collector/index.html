一个 SQL 脚本，收集 PostgreSQL 数据库信息并生成可导航的 HTML 报告

综述（解读层）

PG Collector 是一个 psql 可执行的 SQL 脚本（pg_collector.sql），收集数据库大小、配置参数、扩展、Vacuum 统计、索引、用户角色、表空间等信息，输出至 /tmp 下的 HTML 报告。脚本不创建数据库对象；Observations 部分提供自动健康检查项。自 PostgreSQL 13 起每个大版本有对应分支。表数量达数万时部分查询耗时较长，可用 statement_timeout 控制。

  • 收集数据库大小、配置参数、扩展、Vacuum 与统计、未用/无效索引、用户角色、表空间等信息并生成单个 HTML 文件
  • 包含 Observations 自动健康检查部分，涵盖重复索引、无效索引、未用索引等检查项并给出建议
  • 运行时不创建任何数据库对象，输出文件命名格式为 pg_collector_[DB Name]-[timestamp].html

适用场景（解读层）

  • 对生产或 RDS/Aurora PostgreSQL 实例进行数据库信息收集与巡检
  • 排查索引冗余、Vacuum 统计、复制槽等数据库配置与状态信息
  • 为不同 PostgreSQL 大版本（12 及更早、13 起）选择对应分支的脚本运行
