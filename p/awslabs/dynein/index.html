🧭 简介解读层（AI·证据行可回查）

Rust 编写的 Amazon DynamoDB 命令行工具，支持表上下文切换与数据导入导出。

综述（解读层）

dynein 是 awslabs 出品的 DynamoDB 命令行工具，二进制名为 dy，供开发者从终端操作 DynamoDB 表和条目。它使用 aws-sdk-rust 依赖 AWS 凭证，通过 dy use 缓存表模式后自动推断键类型，内部将保留字替换为占位符。支持 DynamoDB Local 免费测试，CloudFormation 声明式管理功能尚在开发中。

  • 提供 scan/get/query 等命令读取条目，支持按排序键条件查询，自动处理 DynamoDB 保留字占位
  • 支持标准 JSON 读写、CSV/JSON 导入导出、按需备份与恢复，以及通过 dy bootstrap 加载示例表
  • 安装方式包括下载各平台二进制、Homebrew 或 Cargo 源码编译，支持 DynamoDB Local

适用场景（解读层）

  • 在终端中对 DynamoDB 表进行日常查询、写入与备份恢复操作
  • 在本地使用 DynamoDB Local 免费测试 DynamoDB 操作
  • 通过单条命令在表与 CSV/JSON 文件之间导入导出数据
