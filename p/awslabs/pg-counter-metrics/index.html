将 PostgreSQL 性能计数数据发布到 AWS CloudWatch 的监控工具

综述（解读层）

PGCM 由 AWS Labs 发布，通过 Lambda 采集 PostgreSQL 实例的性能计数器并写入 CloudWatch，生成对应的指标、仪表盘和告警。支持 IAM 数据库认证、Secrets Manager 和明文密码（仅限测试环境）三种认证方式。指标覆盖数据库级、每张表级和 pg_stat_statements 查询级三类；当前仅支持实例上的单个数据库。

  • 提供 51 项数据库级性能指标，包括事务 ID 回卷百分比、连接利用率、复制槽滞后、autovacuum 频次等
  • 支持按表和按 query id 发布 pg_stat_statements 查询级指标（限于 DB Time 消耗前 20 的查询）
  • 组件包含 Lambda、CloudWatch 指标/仪表盘/告警、RDS IAM 认证与 Secrets Manager，可通过 CloudFormation 部署

适用场景（解读层）

  • 在 CloudWatch 上持久化保存 PostgreSQL 性能计数数据并配置告警
  • 按表查看增删改行数、死元组比例、autovacuum/autoanalyze 执行次数
  • 配合 pg_stat_statements 扩展跟踪 DB Time 消耗最高的查询的调用次数、耗时与块读写指标

PG Counter Metrics ( PGCM ) is a tool for publishing PostgreSQL performance data to CloudWatch. By publishing to CloudWatch, dashboards and alarming can be used on the collected data.
