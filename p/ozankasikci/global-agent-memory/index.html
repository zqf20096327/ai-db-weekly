🧭 简介解读层（AI·证据行可回查）

本地优先的项目感知 AI 代理记忆 MCP 服务器，以 Markdown 为事实源

综述（解读层）

该项目为 Claude Code、Codex 等 MCP 客户端提供跨代理共享的项目级持久记忆层。记忆以 Markdown 文件为规范事实源，代理只能创建候选记忆，由所有者在仪表板审批、编辑或删除；检索基于 SQLite FTS5，可选 Ollama 嵌入做语义排序。要求 macOS/Linux、Python 3.12+ 与 uv，通过 uv tool install 安装后运行 global-memory setup 完成引导配置。

  • 代理经 MCP V1 契约创建候选记忆，由所有者在仪表板审批、编辑或硬删除
  • 混合检索：SQLite FTS5 关键词搜索，可选 Ollama + sqlite-vec 语义排序；无守护进程时命令在进程内回退运行
  • Markdown Vault 可在 Obsidian 中直接读写，支持模板、wikilinks 和 Bases 视图；仪表板绑定 127.0.0.1 并使用 bearer token 认证

适用场景（解读层）

  • 为多个编码代理维护可人工审核的共享项目记忆（架构决策、约定、解决方案）
  • 需要记忆内容可移植、可备份、可在 Obsidian 中长期管理的个人知识库
  • 代理生成内容需人工审批后才能生效的受控工作流
