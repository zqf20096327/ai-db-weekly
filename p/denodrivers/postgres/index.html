Deno 运行时的轻量级 PostgreSQL 驱动

综述（解读层）

deno-postgres 是面向 Deno 运行时的 PostgreSQL 驱动，通过 Client 建立连接并提供 queryArray 等查询接口，以 JSR 包 @db/postgres 发布。设计上借鉴 node-postgres 与 pq。因依赖 Deno 不稳定 API，不同 Deno 版本需匹配对应驱动版本区间，目前仍处 1.0 之前的开发阶段，可能存在破坏性变更。

  • 提供 Client 客户端与 queryArray 等查询方法，通过 jsr:@db/postgres 导入使用
  • 提供版本兼容表，明确各驱动版本支持的 Deno 版本区间
  • 测试基于查询结果断言，可用 Docker Compose 运行，支持 clear/md5/scram 三种认证数据库环境

适用场景（解读层）

  • 在 Deno 应用中连接并查询 PostgreSQL 数据库
  • 需要按 Deno 版本匹配驱动版本的运行环境
  • 开发者基于 Docker 测试环境参与驱动开发与贡献
