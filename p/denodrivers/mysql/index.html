Deno 平台的 MySQL/MariaDB 数据库驱动，提供连接池与事务支持

综述（解读层）

deno_mysql 是面向 Deno 运行时的 MySQL 与 MariaDB 驱动，通过 Client 类连接数据库，支持连接池、参数化 SQL、事务、TLS 验证及流式迭代查询。提供 execute/query 两类接口，execute 可返回 rows 数组或异步 iterator。测试需借助 Docker 运行数据库实例。在其基础上另有 Deno Simple Orm 库。

  • 支持连接池，池大小从 0 自增至指定 poolSize
  • execute() 默认返回 rows 数组，第三参数可切换为异步 iterator，README 建议后者仅用于可能包含大量结果（如 10 万行）的 SELECT 查询
  • 提供 TLS 配置，mode 可选 "disabled"（默认）或 "verify_identity"，支持指定 PEM 格式 caCerts

适用场景（解读层）

  • 在 Deno 应用中连接并操作 MySQL 或 MariaDB 数据库（增删改查、建库建表）
  • 需要事务封装的多语句操作场景
  • 结果集较大的 SELECT 查询需逐行异步迭代处理
