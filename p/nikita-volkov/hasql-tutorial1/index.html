Haskell 的 Hasql 代码组织教程，讲解如何构建数据库访问层（DAL）库

综述（解读层）

这是一篇 Haskell 教程仓库，讲解如何用 Hasql 将 PostgreSQL 集成代码组织为独立的数据访问层（DAL）库。内容包含一个完整的用户管理 DAL 示例库（注册、认证等）、对应数据库的迁移脚本及说明文档。教程阐述了库隔离、封装、按抽象层级分模块（Statement/Transaction/Session）、编解码器归属语句定义、避免自定义行类型、版本化 DDL 迁移等组织原则。注意 README 开头已标注本文档已弃用，推荐结构现参见 Hasql.Mapping.IsStatement。

  • 提供用户注册、认证等功能的完整 Haskell DAL 库示例及对应数据库 schema
  • 按抽象层级组织模块：Statement、Transaction、Session 各自独立
  • API 仅导出 Session 模块，语句与事务作为实现细节封装；schema 以版本化 DDL 脚本存放于 schema-migrations 目录

适用场景（解读层）

  • 学习如何将 Hasql 数据库集成代码组织为可复用的独立 DAL 库
  • 参考模块划分、封装与 schema 版本化迁移的组织方式
  • 为 CLI 工具、REST API、Web 应用等多个项目共享同一数据访问层的场景
