Go 编写的 Prometheus exporter，通过 SQL 查询生成监控指标

综述（解读层）

query-exporter 是一个用 Go 编写的 exporter，通过执行配置文件中定义的 SQL 查询生成指标。它提供集中式查询执行、目标数据库分组管理和灵活的指标定义，使用 YAML 分别配置数据库连接（config-database）与指标（config-metrics），支持 MySQL 和 Postgres 驱动，SQLite 与 MS-SQL 列为暂不支持。适合需要将自定义 SQL 查询结果暴露为指标的用户。

  • 支持按分组管理目标数据库，MySQL 和 Postgres 提供驱动
  • 指标与数据库连接分离，通过两个 YAML 文件配置
  • 支持 --threads 并发线程数、--bind 监听地址等启动参数，可通过 LOG_LEVEL=debug 调试

适用场景（解读层）

  • 将自定义 SQL 查询结果生成 Prometheus 指标
  • 集中管理多个 MySQL/Postgres 数据库的定时查询采集
  • 按指标定义灵活组合多个目标数据库的采集任务
