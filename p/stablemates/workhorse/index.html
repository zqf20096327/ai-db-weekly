🧭 简介解读层（AI·证据行可回查）

基于 PostgreSQL 的持久化任务队列，多语言 worker 共用一套 SQL 协议

综述（解读层）

Workhorse 将版本化 SQL 函数部署在现有 PostgreSQL 中，任务入队与应用事务共用同一数据库事务，回滚时保持一致。它支持 TypeScript、Python、Go、Rust、Ruby、Java、Kotlin、C# 等 worker，包含重试、fence token 认领、仪表盘与定期调度，无需数据库之外的 broker。当前为公开 beta，0.x 小版本可能变更行为。采用 Apache-2.0 许可证。

  • 入队与业务变更共享同一 PostgreSQL 事务，回滚时二者一致
  • 多语言 worker（TypeScript、Python、Go、Rust、Ruby、Java、Kotlin、C#）经由同一 SQL 协议工作
  • 提供仪表盘展示任务活动、生命周期事件、队列与定期调度；worker 以 fence token 认领任务

适用场景（解读层）

  • 应用已依赖 PostgreSQL，需要与业务事务同生共死的后台任务
  • 需要跨多种语言服务共用一套任务队列与调度
  • 需要任务历史、重试与运维仪表盘的小规模到早期生产部署
