单文件交互式网页，动画演示一条 SQL 在 TiDB 中的完整执行旅程

综述（解读层）

本项目是 1024 TiDB AIGC 黑客松的参赛作品，以单个 index.html 实现对 SELECT 语句在 TiDB 内部旅程的可视化动画。零依赖、不依赖真实集群，可直接打开或用 HTTP 服务器本地运行，也可部署到 GitHub Pages。技术解读附 PingCAP 官方文档来源，AIGC 文案与动画均注明生成方式。

  • 零依赖单文件应用：单个 index.html，无外部资源、无需构建、不依赖真实 TiDB 集群
  • 以代码生成的 SVG/Canvas 呈现 SQL 执行过程的动画，未使用图像生成模型
  • 配套技术解读稿 sql-life-technical-notes.md，关键论断逐条附 PingCAP 官方文档来源

适用场景（解读层）

  • 需要以可视化方式演示 SQL 在 TiDB 中执行路径的教学或分享场景
  • 参加产品特性可视化或 AIGC 实践方向的黑客松项目参考
  • 无需搭建集群即可离线浏览 SQL 执行流程的轻量演示
📖 README 首段存档原文 · 程序抽取

交互式单文件 Web 应用：把 SELECT name FROM users WHERE id = 42; 在 TiDB 里的一次完整旅程 做成可点击、可播放的动画。
