将 API 数据映射为 SQL 表的零 ETL 查询引擎

综述（解读层）

Steampipe 是一个用 SQL 实时查询 API 与服务的工具，无需提前抽取数据。社区提供覆盖 AWS、Azure、GCP、Kubernetes、GitHub 等服务的插件，将 API 映射为数据库表，合计超过 2000 张表并附示例。可通过 CLI、Postgres FDW、SQLite 扩展或独立导出工具运行，采用 AGPL 3.0 许可。

  • 提供插件机制，将 AWS、Azure、GCP、GitHub、Kubernetes 等 API 映射为 SQL 可查询的表，合计超过 2000 张表
  • 以单个二进制文件发布，可在本地使用，也可部署于 CI/CD 流水线
  • 支持多种分发形式：内嵌 Postgres 的 CLI、Postgres FDW、SQLite 扩展，以及无需数据库的独立导出工具

适用场景（解读层）

  • 用 SQL 实时查询云服务（AWS/Azure/GCP）API 数据，用于运维检查与配置核查
  • 在 CI/CD 流水线中以单二进制方式运行查询或导出 API 数据
  • 通过 Postgres FDW 或 SQLite 扩展在既有数据库环境中访问 API 数据
