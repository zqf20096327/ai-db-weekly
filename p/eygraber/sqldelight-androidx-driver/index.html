包装 AndroidX KMP SQLite 库的 SQLDelight 驱动，基于挂起协程实现

综述（解读层）

该项目提供一个 SQLDelight 驱动，包装 AndroidX Kotlin Multiplatform SQLite 库，支持 AndroidX SQLite 的任意实现。它面向 Kotlin 多平台项目，要求 SQLDelight 开启 generateAsync，所有数据库调用为挂起式并运行在驱动自身的协程调度器上。Web 端通过独立的 :opfs-driver 依赖支持 JS/wasmJs，文件持久化于浏览器的 Origin Private File System，并提供三种多标签页协调模式。

  • 支持 Android/JVM、原生及 Web（JS/wasmJs，基于 OPFS）多平台目标
  • 挂起式驱动：数据库调用运行在自带协程调度器上，无需额外 withContext 包装
  • 提供 onConfigure/onCreate/onUpdate/onOpen 四个生命周期回调，自动处理 schema 的创建与迁移

适用场景（解读层）

  • Kotlin 多平台项目中通过 SQLDelight 访问 AndroidX SQLite 实现
  • 需要 SQLite 持久化的 JS/wasmJs Web 应用（文件存储于浏览器 OPFS）
  • 需要挂起式异步数据库访问并在多标签页间协调数据库使用的 Web 应用
