Rust 编写的 Redis 兼容内存 KV 存储与 PostgreSQL 查询缓存代理

综述（解读层）

FyroDB 是一个用 Rust 编写的单一二进制程序，包含两个功能：兼容 RESP2/RESP3 协议的内存 KV 存储引擎，以及实现 PostgreSQL 线协议的查询缓存代理。支持字符串、哈希、列表、集合、有序集合、JSON、流、向量检索、全文检索等数据类型，并包含 Lua 脚本引擎与发布/订阅。代理模式下应用只需修改连接串即可将相同 SQL 的结果缓存于内存。提供 Docker 镜像与 cargo 构建，Apache 2.0 许可。

  • KV 引擎实现 RESP2/RESP3 协议，支持 Hash、List、Set、Sorted Set、JSON、Stream、Bitmap、HyperLogLog、地理空间、向量检索与全文检索等数据类型
  • 缓存代理实现 PostgreSQL 线协议，按 SQL 模式缓存查询结果，后续相同查询从内存返回
  • 配置项包含认证密码、键数量上限、RDB 快照路径、代理缓存 TTL 与 dual/cache-only 模式等环境变量

适用场景（解读层）

  • 需要兼容 Redis 客户端的内存 KV 存储，用于缓存、计数器与发布/订阅消息
  • 在应用不改代码的前提下，为 PostgreSQL 数据库添加查询结果缓存
  • 使用向量检索或全文检索能力支撑检索类业务查询
