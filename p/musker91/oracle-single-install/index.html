Oracle 12C 静默安装 Shell 脚本，支持单实例与 CDB 安装

综述（解读层）

该项目提供一组 Shell 脚本，用于在 CentOS 7 系统上静默安装 Oracle 12C 数据库。用户将安装包放入 /tmp 后，通过配置本机 IP、密码、SID、字符编码（AL32UTF8 或 ZHS16GBK）等变量，可选择不装实例、装单实例或安装 CDB（CDB 需手动初始化）。支持远程或本地获取 rsp 响应配置文件。适用对象为需要在 Linux 环境部署 Oracle 的运维人员。

  • 支持单实例和 CDB 容器两种安装模式，通过 IS_INSTANCE 参数选择
  • 提供远程与本地两种静默安装配置文件（db_install.rsp 等）获取方式
  • 默认字符编码可选 AL32UTF8 或 ZHS16GBK

适用场景（解读层）

  • 在 CentOS 7 64/32 位系统上批量或快速部署 Oracle 12C
  • 需要静默（无人值守）方式安装 Oracle 数据库的场景
  • 初始化 CDB 容器数据库并自定义 SID 与字符集
