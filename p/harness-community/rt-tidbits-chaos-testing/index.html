🧭 简介解读层（AI·证据行可回查）

Harness 弹性测试模块的混沌工程入门教程，演示故障注入与弹性评分。

综述（解读层）

这是一份约 20 分钟完成的操作教程（Tidbit），演示如何在 Kubernetes 上完整走一遍 Harness 弹性测试流程：部署示例电商应用、通过向导配置 Chaos Infrastructure 代理、自动发现服务并生成 Pod Delete 实验、运行实验并查看执行时间线。实验中一个副本被删除，探测持续检查应用健康状态并汇总为 Resilience Score。前置条件包括启用弹性测试模块的 Harness 账号、集群内运行的 Harness delegate 以及配置好的 kubectl。

  • 通过 Chaos Infrastructure 代理连接 Kubernetes 集群，自动发现服务并按命名空间生成 Application Map
  • 自动创建结合故障（Pod Delete）与弹性探测（健康检查）的混沌实验，并提供实时执行时间线
  • 根据探测结果计算百分比形式的 Resilience Score

适用场景（解读层）

  • 首次使用 Harness 弹性测试模块的用户按步骤搭建并运行第一个混沌实验
  • 在预生产环境中验证多副本应用在 Pod 被删除时是否持续响应
  • 通过对比不同副本数的弹性评分，观察冗余对故障期间可用性的影响
