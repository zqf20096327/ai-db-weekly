一个用于操作 LevelDB 的 C++ REPL 与 CLI 工具

综述（解读层）

ldb 是一个用 C++ 编写的命令行工具和交互式 REPL，用于读取和写入 LevelDB 数据库。它支持通过 --create 标志创建不存在的数据库，提供 get、put、del 等命令以及基于范围的 ls、in 正则查找、start/end/limit 范围控制、size 和 JSON 格式化输出等操作。适用于需要在终端直接检查或修改 LevelDB 数据的开发者。

  • 提供交互式 REPL 模式和单次执行的 CLI 模式
  • 支持 get、put、del、ls、in（正则查找 keys/values）、start/end/limit 范围控制、size、json 格式化等命令
  • 基于当前范围内前 n 条记录实现按键自动补全，Tab 键可循环匹配键并高亮部分匹配

适用场景（解读层）

  • 在终端中交互式浏览和编辑 LevelDB 数据库内容
  • 通过正则表达式在键或值中查找匹配的数据
  • 以脚本方式对 LevelDB 执行单条读写命令
