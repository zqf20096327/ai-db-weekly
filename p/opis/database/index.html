基于 PDO 的 PHP 数据库抽象层，提供查询构建器与模式构建器

综述（解读层）

Opis Database 是一个 PHP 库，在 PDO 扩展之上实现数据库抽象层，提供查询构建器和模式构建器，目标是提供统一方式操作不同的关系型数据库。官方支持 MySQL、PostgreSQL、SQL Server 和 SQLite，另有实验性支持。要求 PHP 7 以上并启用 PDO，通过 Composer 安装，采用 Apache 2.0 许可证。

  • 在 PDO 扩展之上提供查询构建器和模式构建器
  • 官方支持 MySQL、PostgreSQL、Microsoft SQL 和 SQLite
  • 提供 Firebird、IBM DB2、Oracle、NuoDB 查询构建器的实验性支持

适用场景（解读层）

  • PHP 项目中需要以统一接口操作多种关系型数据库
  • 需要通过构建器生成查询和管理数据库模式的应用
  • 基于 PDO 的项目希望以库形式组织数据库访问代码
