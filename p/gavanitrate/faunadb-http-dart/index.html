纯 Dart 实现的 FaunaDB 客户端，查询类贴近 FQL 函数

综述（解读层）

faunadb-http 是用 Dart 编写的 FaunaDB 客户端库，可在 Dart/Flutter 项目中通过 HTTP 访问 FaunaDB。它提供与 FQL 函数对应的查询类，查询写法与 FQL 相近；可选参数改为命名参数、可变参数函数接受 Dart List、与 Dart 保留字冲突时加尾部下划线。构建依赖 json_serializable 生成序列化代码。

  • 提供与 FQL 函数对应的查询类，查询写法与 FQL 相近
  • 纯 Dart 实现，可运行于 Dart 与 Flutter 项目
  • 使用 json_serializable 包为查询类生成 JSON 序列化代码

适用场景（解读层）

  • 在 Dart 后端或服务中访问 FaunaDB
  • 在 Flutter 应用中通过 HTTP 与 FaunaDB 交互
  • 按 FQL Cheat Sheet 所列函数编写类型化查询

A pure Dart implementation of a [FaunaDB][faunadb] client. This library also provides query classes that closely mimic FQL functions.
