🧭 简介解读层（AI·证据行可回查）

面向 MCP 客户端的 PostgreSQL 只读运维服务器，内置预定义监控 SQL 工具

综述（解读层）

MCP-PostgreSQL-Ops 是一个 MCP 服务器，将自然语言请求转换为预定义的只读 SQL 查询，返回 PostgreSQL 的活动连接、慢查询、表膨胀、VACUUM、索引、复制与容量等统计数据，不执行任意 SQL 或写操作。支持 PostgreSQL 12–18 并自动适配版本视图。适用于通过 Claude Desktop、OpenWebUI 或其他 MCP 客户端检查数据库的运维人员；README 建议在生产环境使用最小权限监控账户。

  • 提供 30+ 只读工具，覆盖连接、锁/死锁、表膨胀、autovacuum、索引使用、复制、WAL 与容量等监控查询，不执行任意 SQL
  • 自动检测 PostgreSQL 12–18 的版本差异视图与列，核心工具无需安装扩展（pg_stat_statements 等可选增强查询分析）
  • 支持 Claude Desktop 扩展（MCPB，stdio）、uvx 本地运行、Docker Compose + OpenWebUI 的 Streamable HTTP，以及经 MCPO 的 OpenAPI 客户端

适用场景（解读层）

  • 通过 AI 助手用自然语言排查 PostgreSQL 慢查询、阻塞会话和锁等待
  • 检查表膨胀、VACUUM/autovacuum 状态与索引使用情况等日常维护项
  • 在 RDS/Aurora 等托管服务上，以常规监控角色读取性能与容量统计
