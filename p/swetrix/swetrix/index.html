无 Cookie 的开源网站分析平台，内置错误追踪与性能监控

综述（解读层）

Swetrix 是一个注重隐私的开源网站分析平台，提供流量统计、自定义事件、会话回放、漏斗、性能监控和客户端错误追踪。后端采用 Nest.js + MySQL/TypeORM/ClickHouse/Redis，前端为 React，跟踪脚本用 TypeScript/rollup 打包。支持 Docker 自托管（社区版）或使用其云服务；社区版部分功能（警报、邮件报告、高级 GeoIP 等）仅云版提供，许可证为 AGPLv3。

  • 无 Cookie、数据匿名化的流量统计，支持自定义事件、会话、漏斗、性能指标（TTFB/DNS/TLS/render）与客户端错误追踪
  • 自托管社区版通过 Docker 部署，需连接 ClickHouse、Redis 及 S3 兼容存储用于会话回放
  • 提供 CSV 导出与开发者 API，支持公开或密码保护的分析看板

适用场景（解读层）

  • 需要无 Cookie 分析方案以简化 GDPR 合规流程的网站运营者
  • 希望在一个平台内同时查看流量、错误与真实用户性能指标的团队
  • 偏好自托管、数据存储在自有基础设施中的用户
