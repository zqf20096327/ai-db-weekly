🧭 简介解读层（AI·证据行可回查）

为 AI Agent 提供基于 WAL+快照与 blake3 哈希链的可验证持久化状态存储服务。

综述（解读层）

AgentState 是一个面向 AI Agent 的状态存储服务，用 Rust 编写，通过 HTTP/gRPC API 提供 Agent 状态的读写、查询与 SSE/gRPC 订阅，内置分布式租约。其持久化采用 WAL+快照机制，并通过 blake3 哈希链、运行时不变量、LTL 时序属性检查和断言验证四层机制记录与校验状态变更。提供 Python、TypeScript、Go SDK，可经 Docker、Compose 或 Helm 部署，附带 Prometheus 指标端点。

  • 持久化采用 WAL+快照机制，支持通过 ?at=RFC3339 参数查询历史时间点状态
  • 每次写入扩展 blake3 哈希链，提供 chain-verify 端点校验记录完整性
  • 支持 JSON 规则的运行时不变量校验、LTL 时序属性检查及带证明 DAG 的断言验证，内置 healthcare/finance/tax/legal 四个领域包

适用场景（解读层）

  • 需要按标签/JSONPath 查询并通过 SSE/gRPC 订阅状态变更的多 Agent 状态管理
  • 需要对状态写入施加规则校验并保留可校验审计链的场景
  • 通过 LTL 属性文件在 CI 中对 WAL 历史执行离线属性检查
