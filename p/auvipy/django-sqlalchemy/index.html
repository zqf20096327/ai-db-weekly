基于 SQLAlchemy Core 2.0 构建的 Django ORM 替代实现

综述（解读层）

django-sqlalchemy 旨在将 Django ORM 构建在 SQLAlchemy Core 2.0 之上，使现有 Django 应用能以尽量少的改动迁移到 SQLAlchemy。目前仅支持 Django 4.2+ 与 PostgreSQL 14+，项目处于早期设计阶段（pre POC）。规划包括 Meta API 兼容层、管理命令、迁移方案（Django 内置迁移或 Alembic）及对 forms、Admin、Signals 的集成，采用 AGPLv3 许可。

  • 基于 SQLAlchemy Core 2.0 实现，目前仅支持 Django 4.2+ 与 PostgreSQL 14+
  • 规划提供 Django Meta API 兼容层，用于对接 forms/modelforms 与 Admin
  • 迁移方案列为待定选项：Django 内置迁移框架或 Alembic

适用场景（解读层）

  • 希望将现有 Django 应用的数据层从 Django ORM 迁移到 SQLAlchemy 的项目
  • 需要在 Django Admin/表单体系中使用 SQLAlchemy 表定义的场景
  • 关注或参与该项目早期设计决策的开发者
