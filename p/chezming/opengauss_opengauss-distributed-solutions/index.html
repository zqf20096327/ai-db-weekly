🧭 简介解读层（AI·证据行可回查）

基于K8S的openGauss分布式部署方案，含自动故障管理

综述（解读层）

该仓库提供在Kubernetes上搭建openGauss分布式集群的脚本与说明。核心组件为patroni、openGauss、etcd，用于容灾与主备倒换；ha-proxy管理主备关系，shardingsphere作为客户端按分库分表规则分发数据到各分片。仓库包含部署脚本、镜像打包、适配openGauss的patroni及K8S环境初始化脚本；安装教程以docx文档形式提供。

  • 由patroni、openGauss、etcd构成数据库核心组件，提供容灾与主备倒换能力
  • shardingsphere作为client按分库分表规则将数据分布到各分片
  • 包含适配openGauss的patroni，负责对openGauss数据库集群进行自动故障管理

适用场景（解读层）

  • 需要在Kubernetes上部署openGauss分布式集群
  • 需要数据库容灾与主备自动倒换能力
  • 需要基于shardingsphere的分库分表部署
📖 README 首段存档原文 · 程序抽取

使用K8S搭建openGauss分布式方案：由patroni、openGauss、etcd构成了数据库核心组件，提供数据库的容灾以及主备倒换等能力。使用ha-proxy管理数据库的主备关系；shardingsphere作为client，在集群部署完毕后，由shardingsphere根据分库分表规则，连接各个ha-proxy提供的服务ip，并将数据分布到各个分片。
