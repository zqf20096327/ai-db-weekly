开源多租户知识图谱数据库，支持自动构建与双时态记录

综述（解读层）

HASH 是一个开源的多租户平台，将原始信息转化为知识与流程图谱，供自动化、决策和 AI 场景使用。它由 Rust 图层、TypeScript API 与前端等服务组成，通过智能体从公开网络与私有数据源采集并标准化信息，支持双时态（事件发生时间与知晓时间分别记录）。仓库为 monorepo，可通过 hash.ai 云端、本地开发环境或自托管三种方式运行。

  • 支持双时态（bitemporality）：分别记录并查询事件发生时间与信息获知时间
  • 用户可通过可视化界面浏览和管理实体（数据）与类型（模式），非技术用户亦可操作
  • 依赖 Docker Compose 编排 Postgres、Redis、Kratos、Hydra、Temporal、Vault、MinIO 等服务，并提供 Grafana 与 Temporal UI 可观测性栈

适用场景（解读层）

  • 构建图谱支撑的世界模型，用于流程自动化、优化与决策
  • 部署智能体从公开互联网及私有数据源自动采集、校验并结构化信息
  • 自托管部署或参与代码开发（monorepo 含 /apps、/blocks、/infra、/libs、/tests 等目录）
