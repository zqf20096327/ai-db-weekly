🧭 简介解读层（AI·证据行可回查）

面向 AI Agent 的持久记忆层，基于 MatrixOne 提供快照/分支/回滚版本控制

综述（解读层）

Memoria 是 MatrixOrigin 开发的 AI Agent 持久记忆层，通过 MCP 接口为 Cursor、Claude Code、Kiro 等 Agent 提供跨会话记忆存储与检索。其记忆变更由 MatrixOne 的写时复制引擎支持，可实现快照、分支、合并与按时间点回滚；还包含矛盾检测与低置信度记忆隔离等治理机制。可通过 Memoria Cloud、Docker 自托管或 OpenClaw 插件方式部署，数据可留在本地。

  • 通过 MCP 兼容任意 Agent，提供 memory_store/search/branch/merge/rollback 等工具集
  • 基于 MatrixOne Copy-on-Write 实现记忆的快照、分支、合并与时间点回滚
  • 支持向量+全文混合检索，提供本地嵌入模型选项，数据不离开本机

适用场景（解读层）

  • 为 AI Agent 保存偏好、事实、决策与会话摘要，实现跨会话记忆复用
  • 在高风险记忆实验中用分支隔离修改，验证后合并或回滚
  • 需要对记忆变更保留审计链与来源追溯的记忆治理场景
