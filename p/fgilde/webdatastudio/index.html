浏览器中运行的数据库管理工具，单容器连接九类数据库引擎

综述（解读层）

WebDataStudio 是一个以 Docker 容器运行、通过浏览器访问的数据库管理工具，支持 PostgreSQL、MySQL、SQL Server、SQLite、Oracle、DuckDB、ClickHouse、MongoDB 和 Redis，还包含对象存储与 OData 连接。它面向开发者与自托管用户，可通过环境变量在启动时附加连接串，并提供了 CasaOS、Umbrel、Unraid 等家庭服务器应用商店的安装方式。注意：默认未设置 WDS_USER/WDS_PASSWORD 时无登录界面。

  • 通过环境变量在启动时附加连接串，一个容器内支持 PostgreSQL、MySQL、SQL Server、SQLite、Oracle、DuckDB、ClickHouse、MongoDB、Redis 及对象存储、OData 连接
  • 提供查询编辑器（Monaco，方言感知补全与高亮）、结果虚拟化网格、电子表格式编辑并预览变更脚本、多种格式流式导入导出与跨引擎表复制
  • 包含数据质量规则、执行计划分析、索引建议、模式与数据对比、ER 图、审计日志，并可作为 MCP 服务器供代理使用

适用场景（解读层）

  • 在本地或家庭服务器（CasaOS/Umbrel/Unraid/Cosmos/Proxmox VE）自托管一个统一的数据库管理界面
  • 通过 .NET Aspire 将开发栈中的多个数据库接入同一个工作台
  • 对 MongoDB 集合与 Redis 键空间进行浏览、分页、排序和筛选，或对 S3 兼容存储中的 Parquet/CSV/JSON 文件经 DuckDB 查询
