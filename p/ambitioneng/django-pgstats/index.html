记录 Postgres 内部表与索引统计的 Django 应用

综述（解读层）

django-pgstats 为 Django 项目提供跟踪 Postgres 内部统计的命令与模型，包含 IndexStats 和 TableStats 两个模型，分别存储索引和表的统计信息。通过定期执行 snapshot_pgstats 管理命令（可由 Celery 等任务调度器触发）保存快照，供后续分析表和索引的使用情况。数据以 JSON 字段存储，键格式为 schema.table 或 schema.table.index。

  • 提供 IndexStats 和 TableStats 模型，分别存储 Postgres 索引与表的统计信息
  • 提供 snapshot_pgstats 管理命令，可周期性执行以保存统计快照
  • 统计数据以 JSON 字段存储，兼容 Python 3.10-3.14、Django 4.2-6.0、Psycopg 2-3、Postgres 14-18

适用场景（解读层）

  • 周期性采集 Postgres 表和索引统计快照，用于后续分析使用情况
  • 接入 Celery 等任务调度器定时运行统计采集
  • 需要以 Django 模型形式持久化存储 Postgres 内部统计数据的场景
