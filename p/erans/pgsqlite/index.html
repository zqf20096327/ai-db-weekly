🧭 简介解读层（AI·证据行可回查）

将 SQLite 数据库以 PostgreSQL 线协议对外提供的适配器

综述（解读层）

pgsqlite 是一个 Rust 编写的协议适配器，实现 PostgreSQL v3 线协议，使 psql、pgAdmin 及各类 PostgreSQL 驱动和 ORM 能连接并查询 SQLite 数据库文件或内存库。项目标注为实验性，未达到生产可用状态；存在约 360 倍于纯 SQLite 的单操作开销，且不支持存储过程、pg_* 系统函数和多个并发写入者。

  • 实现 PostgreSQL v3 线协议，支持 psql、pgAdmin、DBeaver 及 psycopg2、Node.js pg 等驱动连接 SQLite
  • 支持 40+ PostgreSQL 数据类型、JSON/JSONB 操作符、数组类型、全文检索（基于 SQLite FTS5）、ENUM、RETURNING、CTE 等语法
  • 内置 AST 级 SQL 注入防护、审计日志、速率限制；可通过 PGSQLITE_USE_POOLING 启用读写分离连接池

适用场景（解读层）

  • 在测试与 CI/CD 中以 SQLite 文件替代 PostgreSQL 实例运行集成测试
  • 通过复制 SQLite 文件为功能分支或 AI Agent 沙箱提供隔离数据库
  • 本地开发时用 PostgreSQL 客户端工具操作轻量级 SQLite 存储，或作为向 PostgreSQL 迁移前的原型方案
