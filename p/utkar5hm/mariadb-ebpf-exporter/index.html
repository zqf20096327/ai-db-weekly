🧭 简介解读层（AI·证据行可回查）

基于 eBPF 探测 MariaDB/MySQL 查询延迟并导出 Prometheus 指标的采集器。

综述（解读层）

该项目使用 eBPF（基于 libbpfgo）探测 mysqld/mariadbd 的查询执行函数，采集查询延迟，按指纹归一化分组相似查询，并以 Prometheus 指标形式导出。通过 build.sh 脚本支持本地构建与 Docker 构建，Docker-attach 模式可进入数据库容器的 PID 命名空间挂载探针。使用前需确认内核支持所需 eBPF 特性；构建 mysql 版本时需用 -d 参数显式指定。

  • 通过 eBPF 探测 mysqld/mariadbd 进程测量查询执行延迟，无需在数据库内安装组件
  • 按指纹归一化对相似查询分组统计，以 Prometheus 指标导出
  • build.sh 支持多种构建模式（local-build、docker-build、docker-attach 等），生成静态二进制，可通过参数指定数据库类型、二进制路径、容器名、端口及慢查询延迟阈值（默认 0 毫秒即采集全部查询）

适用场景（解读层）

  • 为 MariaDB/MySQL 实例采集按查询指纹分组的延迟指标，接入 Prometheus 与 Grafana 进行性能分析
  • 对 Docker 中运行的数据库容器，通过 docker-attach-run 挂载探针采集查询延迟统计
  • 通过 -t 参数设置慢查询延迟阈值，只采集超过阈值的查询
