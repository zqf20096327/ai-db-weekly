基于适配器机制支持多数据库的 Node.js 数据库迁移工具

综述（解读层）

east 是一个 Node.js 数据库迁移工具，通过适配器连接 mongodb、sqlite、postgres、mysql、couchbase、couchdb、dynamodb 等数据库，在库内记录已执行的迁移名称，并提供 migrate/rollback 等 CLI 命令和 MigrationManager 类供程序调用。迁移文件为普通 Node.js 模块，支持 tag 表达式过滤、自定义模板及 TypeScript 等转译语言，也可自写适配器扩展。

  • 提供 CLI（init/create/migrate/rollback/list）与 MigrationManager 库两种使用方式，后者暴露事件钩子
  • 通过适配器支持 mongodb、sqlite、postgres、mysql、couchbase、couchdb、dynamodb，并允许自定义适配器
  • 迁移文件名支持序号或 YYYYMMDDhhmmss 日期时间前缀，可用 --tag 布尔表达式过滤执行的迁移

适用场景（解读层）

  • Node.js 项目中对多种数据库执行版本化迁移与回滚
  • 在应用代码内通过 MigrationManager 类嵌入迁移流程
  • 使用 TypeScript 或其他转译语言编写迁移脚本
