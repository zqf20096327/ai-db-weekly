🧭 简介解读层（AI·证据行可回查）

Rust 实现的嵌入式数据库，融合属性图、向量检索与 Lance 列式存储。

综述（解读层）

Uni 是一个以库形式运行、无需服务进程的嵌入式数据库，将 OpenCypher 属性图、K-NN 向量检索与 Lance 列式存储合于单一引擎，数据可持久化到本地磁盘或 S3/GCS。提供 Rust crate 与 Python 绑定，并另附 uni-pydantic OGM 包，适合在应用内进行本地多模态数据访问的开发者。

  • 支持 OpenCypher 查询（MATCH/CREATE/WHERE/ORDER BY/LIMIT 与聚合）及 PageRank、Louvain、最短路径等图算法库
  • 默认开启快照隔离加乐观并发控制的可串行化事务，冲突提交返回可重试错误
  • 向量检索支持 L2 与余弦相似度、预过滤和阈值，另有向量与 BM25 的混合融合查询

适用场景（解读层）

  • 在应用进程内嵌入运行、无需部署数据库服务的本地数据存储场景
  • 需要同时使用图查询、向量相似度检索与列式持久化的多模态数据应用
  • 基于 PyO3 绑定与 uni-pydantic OGM 的 Python 项目开发
