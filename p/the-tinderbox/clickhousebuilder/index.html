PHP 编写的 ClickHouse 流式查询构建器，提供 Laravel/Lumen 集成。

综述（解读层）

该项目是面向 ClickHouse 的 PHP 流式查询构建器，要求 PHP 7.1 以上，通过 composer 安装，需传入 the-tinderbox/clickhouse-php-client 实例才能工作。它以链式调用生成 SQL，覆盖 select、from、join、where/prewhere/having、groupBy、orderBy、limit、unionAll 等子句，并支持临时表、文件导入与异步请求，主要供在 PHP 应用中操作 ClickHouse 的开发者使用。

  • 通过链式方法构建 select、from、sample、join、arrayJoin、where、prewhere、having、groupBy、orderBy、limit/limitBy、unionAll 等子句并编译为 SQL
  • 支持以闭包或 Builder 实例构造子查询，以及 whereDict 字典查询和 Identifier 传参
  • 支持通过 TempTable 将本地文件作为临时表用于 whereIn/prewhereIn/havingIn/join，提供 insertFile/insertFiles 文件导入及 Memory 引擎临时表辅助函数

适用场景（解读层）

  • 在 PHP 7.1+ 项目中通过代码构建并执行 ClickHouse 查询
  • 需要将大量 ID 数据以本地文件上传为临时表来过滤或关联查询的场景
  • 批量导入 TSV 等格式文件到 ClickHouse 表或异步执行多条查询
