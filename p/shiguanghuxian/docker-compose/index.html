🧭 简介解读层（AI·证据行可回查）

收录多款基础服务 docker-compose 配置的仓库，用于快速启动容器组

综述（解读层）

该仓库收录 consul、etcd、kong、mysql、redis、postgres、rabbitmq、jumpserver 等基础服务的 docker-compose 配置文件，供使用者在一台新电脑上快速启动这些服务，无需逐条输入 docker 命令，且可实现数据持久化。仓库内另附 docker-compose 的构建、启动、停止、查询状态等常用命令说明。各服务配置分散为独立文件，README 未说明版本号与镜像来源。

  • 包含 consul、etcd、kong、mysql、redis、memcached、mongo、postgres、rabbitmq、jumpserver、php、soar-web、Yearning、KeyDB、jaegertracing、prometheus 等服务的 docker-compose 配置文件
  • 通过 docker-compose 启动服务，可免去输入一长串 docker 命令，并实现持久化
  • README 附带 docker-compose 常用命令说明：build、up、start、stop、ps、down

适用场景（解读层）

  • 在新电脑或新环境中快速启动 redis、mysql、postgres 等常用基础服务
  • 需要集中管理多套服务的 docker-compose 配置文件时作为参考
  • 搭建含 jaegertracing、prometheus 等组件的本地服务环境
