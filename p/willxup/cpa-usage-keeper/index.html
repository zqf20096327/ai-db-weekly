CLIProxyAPI 用量追踪器，以 SQLite 持久化并提供内置仪表盘

综述（解读层）

CPA Usage Keeper 是面向 CLIProxyAPI（CPA）的用量追踪工具，独立部署，通过 CPA 管理接口采集用量数据并存入 SQLite，内置仪表盘展示用量分析、请求详情、凭据配额等信息。要求 CPA v8.0.12+ 并开启 usage-statistics-enabled；多个采集端共连一个 CPA 实例时须都使用订阅模式。支持 Docker Compose、Docker、Homebrew 及各平台二进制部署，默认启用登录保护（需设置 LOGIN_PASSWORD）。

  • 将 CPA 用量持久化到 SQLite，支持定时备份
  • 按模型、API Key 和提供商分析用量、缓存与估算成本；可检查并导出请求详情，查看成功率、首 token 时间（TTFT）与总延迟
  • 监控凭据健康状况与剩余配额，支持刷新配额、编辑优先级，并可提供按单个 API Key 限定的只读用量视图

适用场景（解读层）

  • 已部署 CLIProxyAPI 的用户需要保留历史用量记录并按模型、Key、提供商分析成本
  • 需要排查请求成功率、TTFT、延迟等请求级性能指标
  • 需要跟踪凭据配额变化及 Codex 配额历史
