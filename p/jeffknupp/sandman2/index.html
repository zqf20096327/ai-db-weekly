从现有数据库自动生成RESTful API服务的Python工具

综述（解读层）

sandman2 基于 SQLAlchemy 读取数据库 schema，自动生成带超媒体支持的 RESTful API，无需编写 ORM 或连接代码。可通过命令行工具 sandman2ctl 传入数据库 URI 直接启动服务，也可集成到应用中以限制暴露的表。支持 SQLAlchemy 所支持的 MySQL、PostgreSQL、SQLite 等数据库，并提供 Admin 管理界面。

  • 通过 sandman2ctl 命令行工具传入数据库 URI 即可启动 RESTful API 服务，支持超媒体
  • 支持 SQLAlchemy 支持的数据库，包括 MySQL、PostgreSQL、Oracle、SQL Server、SQLite 等，第三方驱动可扩展至 DB2、Redshift 等
  • 提供 Admin 管理界面，并支持通过环境变量参数以官方 Docker 镜像运行

适用场景（解读层）

  • 为已有遗留数据库（如生产 PostgreSQL、SQLite 文件）生成 REST API，供各类语言的 HTTP 客户端访问
  • 在无法修改原应用的情况下，以 REST 接口方式程序化读取数据库数据
  • 通过 Docker 部署，为本地或远程数据库快速启动 API 服务
