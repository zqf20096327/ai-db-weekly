🧭 简介解读层（AI·证据行可回查）

面向 TiDB 升级场景的离线执行计划采集与比较工具，生成 HTML 评审报告

综述（解读层）

PCC Core 通过导出 SQL 及其表结构、统计信息构成 CaptureBundle，将其导入升级前、后的两套 TiDB 后执行 EXPLAIN 比较执行计划，产出 HTML 报告并按规则卡分类差异，供 DBA 逐条人工评审。工具只执行 EXPLAIN，不运行业务 DML；运行在 Linux x86_64（glibc 2.28+），导入步骤需 MySQL 8 客户端，比较结果经返回码 0/1/3 区分。

  • 提供 CLI 与 SDK，支持采集、prepare、compare 等命令及菜单交互模式，既有接口保持兼容
  • 生成带规则卡（64 张）、复核勾选、备注、分页搜索与 JSON/CSV 导出的 HTML 比较报告
  • 支持完整采集包离线传输后在临时端自动导入，并提供 413 条、17 类固定 SQL 回归案例与 1,203 项离线回归

适用场景（解读层）

  • TiDB 版本升级前后批量比较同批 SQL 的执行计划是否一致
  • 生产与临时环境分网场景下，导出采集包后在临时环境离线完成导入与比较
  • 从 Statement Summary 按时间范围与 top-n 指标（执行次数、总耗时等）采集待比对 SQL
