🧭 简介解读层（AI·证据行可回查）

提供统一接口的键值存储库，通过存储适配器支持多种后端

综述（解读层）

Keyv 是一个 JavaScript 键值存储库，通过存储适配器以一致接口访问多种后端。默认存于内存，可安装 Redis、MongoDB、PostgreSQL、SQLite 等适配器实现持久化，支持 TTL 过期。适用于需要缓存或持久化键值存储的 Node.js/浏览器项目，采用 MIT 许可证发布。

  • 通过存储适配器提供统一键值读写接口，支持 Redis、MongoDB、MySQL、PostgreSQL、SQLite、etcd、DynamoDB、Memcache、文件系统等后端
  • 支持 TTL 过期机制，可作为缓存或持久化键值存储使用
  • 提供 Brotli/Gzip/LZ4 压缩适配器及 JSON、SuperJSON、MessagePack 等序列化选项

适用场景（解读层）

  • 为 Node.js 或浏览器应用添加缓存层
  • 在后端数据库之上以统一 API 读写键值数据
  • 通过共享测试套件实现自定义存储适配器并验证 API 兼容性
📖 README 首段存档原文 · 程序抽取

Keyv provides a consistent interface for key-value storage across multiple backends via storage adapters. It supports TTL-based expiry, making it suitable as a cache or a persistent key-value store.
