Oracle APEX 动态动作插件，基于 tooltipster 为页面元素生成提示框

综述（解读层）

这是一个 Oracle APEX 动态动作（Dynamic Action）插件，封装开源 jQuery 库 tooltipster，用于为页面元素添加工具提示。面向 APEX 开发者，通过导入 SQL 文件安装，可选将 JS/CSS 部署到自有 Web 服务器。提供主题、内容来源（自由文本/项值/HTML title 属性）、动画、位置、触发方式等可配置项，支持 Items、Buttons、Regions 或 jQuery 选择器作为绑定对象，并提供 on Show/on Hide 两个插件事件。版本 1.2 将 tooltipster 升级至 4.1.5 并移除了不再支持的对角位置选项。

  • 提供 5 种主题、5 种动画（Fade/Grow/Swing/Slide/Fall）及 Top/Bottom/Left/Right 四种位置配置
  • 内容文本来源支持自由文本、APEX 项值或受影响元素的 HTML title 属性，可选项将内容按 HTML 解释
  • 提供 on Show / on Hide 两个自定义动态动作事件，支持 Items、Buttons、Regions 或 jQuery 选择器绑定

适用场景（解读层）

  • 为 APEX 页面中的 Items、Buttons、Regions 或任意 jQuery 选择器匹配元素添加工具提示
  • 在报表/交互式报表中显示隐藏列的提示文本：可见列的 HTML Expression 中用 title 属性携带隐藏列文本
  • 在提示框打开或关闭时执行附加动态动作逻辑
