🧭 简介解读层（AI·证据行可回查）

面向 ServerPilot 服务器的 Bash 脚本集合，交互式执行常见配置任务

综述（解读层）

该仓库提供一组可在 ServerPilot 开通的服务器上运行的 Bash 脚本，通过 SSH 以 root 身份执行，逐项询问是否运行各部分。包含 LEMP 栈配置、AutoMySQLBackup 安装、Imagick 扩展、MySQL 5.7 关闭严格模式、图像优化库、Basic Auth 保护及 Nginx expires 配置。README 明确声明脚本需自行承担运行风险，不承诺对数据损失负责。

  • 通过 curl 拉取脚本并以交互提示方式逐项选择执行
  • 支持安装 AutoMySQLBackup，实现每日自动运行 mysqldump 备份全部数据库
  • 包含 Basic Auth（写于 Nginx 配置，兼容 Nginx+Apache 与纯 Nginx 两种模式）及基于 HTML5 Boilerplate 的 Nginx expires 配置

适用场景（解读层）

  • 在 ServerPilot 服务器上为不使用 .htaccess 的应用搭建纯 Nginx（LEMP）环境
  • 为旧版应用（如 WHMCS 6、Craft 2）关闭 MySQL 5.7 严格 SQL 模式
  • 为应用添加 HTTP Basic 认证或静态资源 expires 缓存头
