单二进制 Rust 自托管错误追踪服务，兼容 Sentry SDK 接入

综述（解读层）

errex 是一个自托管错误追踪工具，以单个 Rust 二进制运行，内嵌 SvelteKit 控制台，数据持久化于单个 SQLite 文件（WAL 模式），不依赖 Postgres/Redis。应用通过 Sentry SDK 将 envelope 发送到 /api/<project>/envelope/，系统按指纹分组异常、统计发生次数、检测回归，并可向 Slack/Discord/Teams 发送 webhook。项目处于 alpha 阶段，尚未支持 source maps 符号化和多租户组织。

  • 兼容 Sentry SDK envelope 接入（gzip 与明文），提供指纹分组、回归检测与 resolve/mute/ignore 状态管理
  • 单二进制架构，SQLite WAL 持久化，控制台通过 WebSocket 实时更新，ingest 为单写者有界缓冲
  • 包含 MCP server 接口（当前为 stub），供 AI agent 进行问题分诊；支持 DSN 认证、保留策略与每项目限速

适用场景（解读层）

  • 独立开发者或家庭实验室环境在低配 VPS/小内存容器上自托管错误收集
  • 小型产品需要异常分组、堆栈展示与 Slack/Discord/Teams 告警而不部署多组件消息队列栈
  • 已有 Sentry SDK 埋点的应用，将上报端点指向自托管服务以收集事件数据
