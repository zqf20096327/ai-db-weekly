解析 CronosPro 数据库并导出为多种格式的转换工具

综述（解读层）

cronodump 是一个解析 CronosPro（俄罗斯机构常用的数据库软件）数据库文件并将其导出为 CSV、HTML、PostgreSQL 语句等格式的 Python 工具。附带的 crodump 可进行结构、记录级和十六进制检查。对受密码保护的 Cronos v4+ 数据库提供基于统计的 --strucrack/--dbcrack 两种 KOD sbox 推导方法，不保证每次成功。需要 Python 3.7+，Jinja2 为可选依赖，支持 Linux/macOS/Windows。

  • 将 CronosPro 数据库各表导出为 CSV，并复制库内全部存储文件（区分引用与未引用）
  • 通过 Jinja2 模板渲染 HTML 输出，或以 CREATE TABLE/INSERT INTO 语句导出到 PostgreSQL
  • 提供 strudump/crodump/recdump 子命令用于元数据与记录级十六进制检查，-v 选项可显示未使用字节区间以辅助识别已删除记录

适用场景（解读层）

  • 将 CronosPro 数据库迁移或导入 PostgreSQL 等其他系统
  • 导出数据库中的表数据及内嵌文件用于归档或查看
  • 检查受密码保护的 Cronos 数据库结构（基于统计推导 KOD sbox）
