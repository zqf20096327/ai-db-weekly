🧭 简介解读层（AI·证据行可回查）

面向 AI Agent 的开源数据库与工作区，写入以变更请求形式留存审查

综述（解读层）

Busabase 是一个开源的 Agent 工作区，用类型化记录（Bases）、文档、技能和应用构成节点树，供 Claude Code、Codex、Cursor 等多种 Agent 与人共享。Agent 的写入以 Change Request 提交，附字段级 diff 与历史，由权限决定合并或等待审查。本地版内嵌 PGlite，可离线运行，MIT 许可；服务端设计用于本机或私有网络，不应直接暴露公网。

  • 支持 Agent Skill、MCP、OpenAPI、CLI、SDK 及 ACP 会话等多种接入方式，无内置模型
  • 所有 Agent 写入以 Change Request 呈现，包含字段级 diff、作者与历史，可配置自动合并或人工审查
  • 本地启动无需数据库与账号，内嵌 PGlite 与本地文件存储，支持外接 Postgres 与 S3 兼容存储

适用场景（解读层）

  • 让多个 Agent 共享项目记录、约定与技能文档，实现跨会话与跨工具的持久上下文
  • 软件交付、CRM、SEO 内容、团队记忆、数据集标注等需要 Agent 写入并可人工复核的场景
  • 本地或私有网络中自托管，通过 Change Request 审查队列管理 Agent 的数据写入
