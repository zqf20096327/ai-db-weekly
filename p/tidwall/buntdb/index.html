🧭 简介解读层（AI·证据行可回查）

纯 Go 实现的嵌入式内存键值数据库，支持自定义索引与地理空间索引

综述（解读层）

BuntDB 是一个用纯 Go 编写的嵌入式内存键值存储库，数据可持久化到磁盘（追加式文件格式），读写操作须在事务中完成，采用多读单写的锁机制并提供 ACID 语义与回滚。数据按 key 存于 B-tree，可通过 CreateIndex 建自定义索引、通过 CreateSpatialIndex 基于 R-tree 做空间查询，索引也可建在 JSON 文档字段上（底层使用 GJSON）。适用于需要在 Go 程序内嵌数据库、偏重读写速度的场景；同一时刻仅允许一个写事务。

  • 通过 buntdb.Open() 打开数据库，支持 ":memory:" 纯内存模式；所有读写须在 View/Update 事务中执行，读事务可并发，写事务同一时刻仅一个
  • 支持自定义索引与内置 String/Uint/Int/Float 索引类型，可对 JSON 文档字段建索引，并支持类似 SQL 多列索引的多值索引及 Desc 降序索引
  • 基于 R-tree 提供最多 20 维的空间索引，支持 Intersects 范围查询与 Nearby 最近邻查询，矩形采用自有括号语法表示

适用场景（解读层）

  • Go 应用需要嵌入式、可持久化的内存键值存储（通过 go get 引入）
  • 需要按自定义顺序遍历数据，或对 JSON 文档字段建立索引查询的场景
  • 地理空间应用：对经纬度等点/矩形数据做范围相交查询与最近邻查询
