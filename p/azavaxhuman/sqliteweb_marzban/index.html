🧭 简介解读层（AI·证据行可回查）

面向 Marzban 的 SQLite 数据库 Web 管理工具，自动安装配置 sqlite-web。

综述（解读层）

该项目是 SQLiteWeb 的一个 fork，修改后可在安装了 Marzban 的同一台服务器上运行，用于通过浏览器管理 SQLite 数据库。它提供安装脚本自动安装并配置 sqlite-web，默认连接 /var/lib/marzban/db.sqlite3，默认端口 8010，支持随机生成访问路径或自定义路径，可创建 systemd 服务并支持 SSL/TLS。安装方式为运行一条脚本命令。

  • 自动安装并配置 sqlite-web，可注册为系统服务
  • 提供随机生成或自定义的 Web 访问路径，支持 SSL/TLS
  • 支持浏览/编辑表与数据、搜索过滤、执行 SQL、导出 CSV/JSON

适用场景（解读层）

  • 在部署 Marzban 的服务器上通过浏览器查看和编辑 db.sqlite3 数据
  • 对 Marzban 数据库表数据进行搜索、过滤与 CSV/JSON 导出
  • 在浏览器中编写并直接执行 SQL 查询
