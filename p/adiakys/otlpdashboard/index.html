自托管 OTLP 接收器与可视化面板，接收并展示 traces/logs/metrics

综述（解读层）

该项目是一个自托管 OpenTelemetry 面板，通过 gRPC :4317 与 HTTP/Protobuf :4318 接收 OTLP 遥测数据，以 .NET 10 + EF Core 为后端、Nuxt 4 SPA 为前端，支持 SQLite/PostgreSQL/SQL Server 存储。面向需要自建可观测性栈的开发者，提供按信号独立配置的保留期清理、可选双 Bearer 令牌认证，以及可对接 LLM 客户端的只读 MCP 服务器。

  • 支持 OTLP gRPC（:4317）与 OTLP HTTP/Protobuf（:4318）接入 traces、logs、metrics，存储可选 SQLite、PostgreSQL 或 SQL Server
  • 提供可配置的数据保留期后台清理任务，按信号独立运行，设为 0 时在 /healthz 报告 Degraded
  • 内置可挂载的只读 MCP 服务器（默认关闭），以工具形式暴露与读 API 相同的查询能力，并支持通过文件或 Git 仓库安装 widget pack

适用场景（解读层）

  • 为单体或微服务应用搭建自托管的遥测数据接收与查看端点
  • 配置保留期清理日志（默认 30 天）与 traces/metrics（默认 7 天）的团队环境
  • 将 MCP 客户端接入面板，通过 query_logs/query_traces 等工具直接查询遥测数据
