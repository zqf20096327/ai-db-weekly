🧭 简介解读层（AI·证据行可回查）

基于 Vue 和 Go 的前后端分离数据交互管理平台，集成鉴权与 SQL 审批

综述（解读层）

Owls 是一个数据交互管理平台，用于管理 MySQL、Redis 等中间件系统，面向需要对数据操作进行审批管理的团队。技术栈为 Vue + Go 的前后端分离架构，集成 JWT 鉴权与 casbin 权限控制，提供 SQL 查询、任务流审批、执行备份回滚及规范化规则自动审批。项目继承自伴鱼 Owl 项目，README 标注仍在持续建设中。

  • 支持 SQL 数据查询、任务流审批、执行与备份回滚，以及基于规范化规则的自动审批
  • 基于 JWT 和 casbin 实现权限管理，支持角色分配 API 与菜单权限
  • 支持注册和 LDAP 两种登录方式，提供集群管理与条件搜索功能

适用场景（解读层）

  • 团队对 MySQL 查询与变更操作进行审批流程管理的场景
  • 需要对 Redis 等中间件使用进行权限控制与操作审计的环境
  • 通过 LDAP 接入企业统一账户体系进行用户与角色管理
