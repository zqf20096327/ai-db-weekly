基于 Raft 的分布式 MySQL binlog 存储系统

综述（解读层）

Kingbus 是用 Go 实现的分布式 MySQL binlog 存储系统。它以 slave 身份从真实 master 拉取 binlog，同时以 master 角色向下游 slave 提供 binlog，中间通过 GTID 模式传输。集群用 Raft 复制数据，多个节点间保持 binlog 一致且事件顺序与 master 相同。适用于需要在 master 与大量 slave 之间增加中间存储层的部署，采用 Apache 2.0 许可证。

  • 兼容 MySQL 复制协议，以 GTID 模式从 master 拉取并向 slave 推送 binlog
  • 基于 Raft 实现跨地域复制，多节点写入的 binlog 数据一致且事件顺序与 master 相同
  • 支持异构日志复制组件接入，文档包含管理 API 与 docker-compose 部署说明

适用场景（解读层）

  • 在 master 与多个 slave 之间部署中间层，减少 master 负载并简化故障 master 的替换
  • 跨地域站点复制，替代深层嵌套复制结构
  • 对接 canal 等异构复制组件消费 MySQL binlog
