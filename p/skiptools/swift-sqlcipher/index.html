内嵌 SQLCipher 扩展的 Swift 跨平台 SQLite 接口包

综述（解读层）

该项目将 SQLite3 的 C 源码打包，内置 SQLCipher 加密扩展与全文搜索（FTS5），并提供与 SQLite.swift API 对齐的 SQLiteDB Swift 包。它自带 sqlite 与 sqlcipher 编译版本，不依赖系统 sqlite3 库，面向需要在 iOS、macOS、Android、Windows、Linux 等环境下使用 SQLite 的 Swift 开发者。高层接口提供类型安全表达式与链式查询层，连接类内置串行队列支持跨线程访问。

  • 库内嵌入 sqlite 3.51.1 与 sqlcipher 4.12.0 构建，不依赖系统 sqlite3 二进制
  • 提供与 SQLite.swift 对齐的 API，包含类型安全的 SQL 表达式构建器与链式、延迟执行的查询层
  • 支持 SQLCipher 加密（使用内嵌 LibTomCrypt）、FTS5 全文搜索及 Schema 迁移

适用场景（解读层）

  • 在没有可访问系统 sqlite3 库的环境（如 Android、Windows）中的嵌入式 Swift 项目
  • 需要 SQLite 数据库加密或全文搜索功能的 Swift 应用
  • 需要只读内置数据库或内存数据库的应用（可分别以 readonly 连接或省略路径创建）
