🧭 简介解读层（AI·证据行可回查）

基于 ply 的 Python SQL DDL 解析库，将建表语句解析为结构化元数据

综述（解读层）

simple-ddl-parser 是一个用于解析 SQL DDL 语句的 Python 库，基于 ply（lex & yacc）实现，通过 pip 安装，也提供 sdp 命令行工具。它将 CREATE TABLE、ALTER TABLE 等语句解析为包含表名、列、主键、外键等信息的字典或 JSON，供需要从 DDL 提取 schema 元数据的开发者使用。解析失败时默认静默跳过，可通过 silent=False 改为抛错。

  • 支持多种方言解析，可通过 output_mode 参数获取 HQL、Redshift、BigQuery、Snowflake 等方言的额外字段（如 stored_as、location、external）
  • 支持 CREATE TABLE 及多种 ALTER TABLE 语句（ADD/DROP/MODIFY/ALTER/RENAME COLUMN、添加主键、外键、UNIQUE、CHECK、DEFAULT），并可在单条语句中组合多个操作
  • 提供 normalize_names 去除标识符分隔符、group_by_type 按实体类型分组、custom_output_schema（内置 bigquery JSON schema 转换）等输出选项，可经 run(json_dump=True) 输出 JSON

适用场景（解读层）

  • 从 DDL 文件批量提取表、列、约束等 schema 元数据为 JSON
  • 将 DDL 转换为 BigQuery JSON schema 等自定义输出格式
  • 解析 HQL/Hive 等 DDL 中的方言特有属性（外部表、存储格式、location 等）
