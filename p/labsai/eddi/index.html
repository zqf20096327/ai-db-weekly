自托管 AI 代理管理系统：以版本化 JSON 配置代理，含审批与审计

综述（解读层）

EDDI 是一个可自托管的 AI 代理管理系统，基于 Java/Quarkus 构建，以 Apache-2.0 协议发布。代理由版本化 JSON 配置定义，通过一个 Docker 镜像提供 REST API、管理界面和聊天 UI。支持人工审批门控、仅追加审计台账、秘密保险库，可作为 MCP 服务器/客户端并兼容 A2A 与 OpenAI API。需要 Docker 环境及至少一个模型 API 密钥或本地 Ollama。

  • 以版本化 JSON 配置定义代理，支持差异对比、ZIP 导出与实例间同步
  • 支持 19 个模型提供商，提供 RAG、持久化用户记忆与多代理群组讨论
  • MCP 服务器（120 个工具）与客户端、A2A、OpenAI 兼容 API（默认关闭），HMAC 签名的仅追加审计台账

适用场景（解读层）

  • 在自有服务器上运行代理并对工具调用、回合或群组阶段设置人工审批
  • 通过 Claude、Cursor 等 MCP 客户端创建、测试和修改代理配置
  • 为面向终端用户的代理部署提供管理后台、嵌入聊天 UI 与 Slack 接入
