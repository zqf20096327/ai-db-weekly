🧭 简介解读层（AI·证据行可回查）

通过查询分发服务器系统表监控 SQL Server 复制订阅状态的脚本方案

综述（解读层）

该项目由一个视图和一个存储过程组成，部署于分发数据库，通过查询系统表检查复制订阅健康状态，并可结合 Database Mail 与 SQL Agent 定时作业发送告警邮件。适用于维护 SQL Server 复制环境的管理员。部署需在脚本中配置邮件配置文件名与收件人；SQL Server 2012 以下版本需使用专用视图。

  • 提供视图 v_ReplicationMonitorData 查询分发数据库系统表，SQL Server 2012 以下版本另有 v_ReplicationMonitorData_2008R2 版本
  • 存储过程 usp_ReplicationMonitor 支持输出参数 @p_RiseAlert（告警标志）和 @p_HTMLTableResults（HTML 表格格式结果），可抑制结果集输出
  • 部署脚本自动创建名为 "Warning: Replication Health" 的 SQL Agent 作业（不含计划），需自行配置 Database Mail 与调度

适用场景（解读层）

  • 定期检查分发服务器上各复制订阅是否正常运行
  • 通过 SQL Agent 作业定时执行并在订阅异常或存在警告时发送邮件通知
  • 在 T-SQL 开发流程中以编程方式获取复制状态标志或 HTML 格式结果
