便携式家庭网络性能诊断工具，以iperf3等测试生成每日PDF报告

综述（解读层）

该工具用于诊断家庭网络性能问题，部署时无需修改被监控网络的配置。测试内容包括互联网速度、连通性（ping）、域名解析和局域网速度（可用于测试2.4GHz与5GHz无线网络），并测量每日带宽使用量，生成含图表和断网指示的每日PDF报告。注意它不是路由器、WiFi接入点或无线桥接器。构建与安装说明位于Wiki。

  • 测试互联网速度、ping连通性、域名解析和本地网络速度（iperf3，覆盖2.4GHz/5GHz无线网络）
  • 包含带宽监控功能，测量全天互联网带宽使用量，并支持流量配额（针对计量计费服务）
  • 生成每日PDF报告，包含测试结果图表和互联网中断指示

适用场景（解读层）

  • 诊断家庭网络的性能问题（无线与有线链路）
  • 记录全天的互联网带宽使用模式与断网情况
  • 计量计费互联网服务下的流量配额监控

The Network Performance Monitor is a portable tool for diagnosing performance issues on home networks. It can be deployed without making configuration changes to the network being monitored.
