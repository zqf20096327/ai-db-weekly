🧭 简介解读层（AI·证据行可回查）

JavaScript 键值存储库，支持内存、文件系统与浏览器驱动的键值存储库

综述（解读层）

storage-box 是一个 MIT 许可的 JavaScript 键值存储库，通过 Client 与可替换驱动实现存储：默认为内存驱动，Node.js/Bun 环境可用文件系统驱动（JSON 或 MessagePack 序列化），浏览器端提供 Local/Session 存储驱动。API 包含 TTL 过期、哈希与列表操作，并支持继承 HashMap/List 自定义数据结构。适合需要在 JS 应用中统一管理键值数据持久化的开发者。

  • 提供内存、文件系统（Node.js/Bun，JSON/MessagePack 序列化）、浏览器 Local/Session 三类存储驱动
  • 支持以秒为单位的键 TTL 过期设置及剩余时间查询
  • 提供哈希与列表操作，并可扩展 HashMap/List 类实现自定义数据结构

适用场景（解读层）

  • Node.js/Bun 服务端需要将键值数据持久化到文件系统的场景
  • Web 应用需要基于 Local/Session 存储管理键值数据
  • 需要带 TTL 过期或哈希/列表等结构化键值操作的应用
