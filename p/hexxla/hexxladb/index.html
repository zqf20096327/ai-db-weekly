🧭 简介解读层（AI·证据行可回查）

Go 内嵌数据库，以稀疏六边形网格单元存储记录并按坐标环扫描检索。

综述（解读层）

HexxlaDB 是一个以 Go 库形式在进程内运行的嵌入式数据库，将记录存为稀疏六边形网格上的单元格，支持文本/标签/向量检索、环向邻域扩展、MVCC 版本、来源与有效性窗口记录，以及记录矛盾与取代关系的 seams。README 标明项目处于 alpha 阶段，建议在可恢复数据的受控评估中使用；原生记录不含任意元数据字段，JSON 以字符串存储且不做字段索引，向量需由应用自行生成。

  • 单元格携带 tags、来源引用、置信度、时间戳和可选的有效性窗口，seams 记录单元格间的矛盾与取代关系
  • 提供 QueryCells 文本与标签检索、可选 HNSW 向量相似度（近似）、带 MaxScanRows 的有界扫描，以及 LoadContext 环向扩展和按边类型遍历
  • 写入通过 DB.Update 原子提交，读取经 DB.View 获得一致快照，默认以 MVCC 打开并保留修订历史直到剪枝

适用场景（解读层）

  • 按主题锚点与放置半径组织记录，并用有界环扫描组装邻域上下文的应用
  • 需要为 LLM 提示词组装带来源、置信度与有效性窗口的上下文记录的 Go 程序
  • 需要以网格可视性规则（LoadContextFOV 与调用方透明度规则）做空间检索的应用
