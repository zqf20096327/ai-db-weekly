🧭 简介解读层（AI·证据行可回查）

用 Docker 与 JavaScript 脚本测试三节点分布式数据库在节点被隔离时的响应能力

综述（解读层）

Perseus 是一组基于 Docker Compose 和 JavaScript 的测试脚本，用于研究三节点分布式一致性数据库在某一节点与同伴隔离时的可用性表现。客户端以三线程循环执行读-改写计数，每秒输出各节点操作数与错误数的统计。README 附带 Etcd、Consul、MongoDB、TiDB、YugaByte 等系统在指定版本下的测试结果表；结果基于默认参数配置，MongoDB 与 TiDB 等部分结果不稳定者记录多条。

  • 包含 Etcd、Consul、RethinkDB、MongoDB、TiDB、YugaByte、Gryadka 等系统的隔离与恢复测试结果数据表
  • 基于 Docker Compose 的可复现测试环境，每个数据库子目录含运行说明
  • 客户端三个线程分别连接一个节点循环执行读-增量-写操作，每秒转储各节点操作数与错误数统计

适用场景（解读层）

  • 以三节点配置对比分布式一致性数据库在节点隔离与恢复期间的可用性表现
  • 在默认参数下复现各数据库的隔离/恢复行为并提交相关 bug
  • 研究 2n+1 节点容忍 n 故障的复制算法性质
