🧭 简介解读层（AI·证据行可回查）

面向 AI 的记忆与上下文引擎，可云端调用或本地单二进制运行

综述（解读层）

Supermemory 提供 AI 应用的记忆层：从对话中提取事实、维护用户画像、执行混合搜索（RAG+记忆），并通过 API 或 MCP/插件为 Claude Code、Cursor 等客户端注入持久记忆。支持 Google Drive、Notion、GitHub 等连接器自动同步，可经 npm/pip 调用，也可用单二进制、Docker 或 Ollama 离线本地运行。本地默认使用 Xenova 嵌入模型，数据存于 ~/.supermemory。

  • 提供记忆提取、用户画像、混合搜索、文件抽取（PDF/图片/视频/代码）与外部数据连接器，通过一个 API 暴露
  • 支持 MCP 服务器及 Claude Code、Cursor、OpenCode 等客户端插件，内存按项目以 containerTag 分隔
  • 可本地运行：单二进制或 Docker 部署，默认本地嵌入模型，支持接入 OpenAI/Anthropic/Gemini/Groq 或 Ollama 等任意模型

适用场景（解读层）

  • 为 AI 编码助手添加跨会话持久记忆与偏好存储
  • 在自建 AI 应用中集成记忆、RAG、用户画像与文档处理
  • 需要离线/私有部署记忆服务的场景（Ollama + 本地嵌入）
