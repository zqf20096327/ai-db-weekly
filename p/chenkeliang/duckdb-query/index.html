基于 DuckDB 的本地优先 AI 可视化 SQL 工作台，支持跨源关联查询

综述（解读层）

DuckQuery 是一个基于 DuckDB 的桌面/Docker 数据工作台，将文件导入（CSV/Excel/JSON/Parquet）、数据库连接（MySQL/PostgreSQL/SQLite/Oracle 等）、SQL 编辑、可视化查询、图表与导出整合在一个界面。面向临时对账、跨源核查和数据探索场景。启用 AI 时需自备模型 API Key，应用本身无多用户鉴权，Docker 部署默认仅监听 127.0.0.1。

  • 支持 CSV/Excel/Parquet/JSON 等本地文件与 MySQL/PostgreSQL/SQLite/DuckDB/Oracle 远程库在同一条 SQL 中跨源关联，MySQL 查询支持安全条件及关联键下推
  • 提供可视化关联查询、集合运算与透视表，以及带补全、历史、收藏的多标签 SQL 编辑器；支持异步任务转后台、取消与重试
  • 内置 text-to-SQL 智能体（只读限量查询、SQL 解释与优化）、MCP 服务供 Claude Code/Cursor 等客户端接入，提供 read-only/normal/full 三种权限模式

适用场景（解读层）

  • 用一条 SQL 关联本地 Excel/CSV 与业务数据库，进行对账与跨源核查
  • 通过可视化 JOIN、透视表和图表探索数据，结果导出为 CSV/Excel/JSON/Parquet 或保存为 DuckDB 本地表
  • 通过 MCP 接口让 Claude Code、Cursor 等 AI 编程工具直接查询本地文件与远程数据库
