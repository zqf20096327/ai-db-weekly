🧭 简介解读层（AI·证据行可回查）

基于 Airlabs API 与 SQLite 的突尼斯航空航班延误每日报告生成工具

综述（解读层）

该项目包含数据管道与分析脚本，用于生成突尼斯航空航班延误的每日 KPI 报告。数据每小时经 CRON 调度从 Airlabs API 抓取，清洗后存入 SQLite3 数据库；每日 9 点用 Pandas 与 Matplotlib 生成图表报告，并经 Pillow 合成后自动发布到 Twitter 账号 @Tunisairalert。运行需在 .env 中配置 Airlabs token 与 Twitter API 密钥。

  • 数据摄取：CRON 调度每小时调用 Airlabs API，JSON 数据清洗、用 pyairports 模块丰富机场信息后写入 SQLite3 数据库 tunisair_delay.db
  • 数据分析：每日查询 SQLite 数据库，用 Pandas 与 Matplotlib 生成延误次数、最值及均值统计和四家航空公司对比柱状图，经 Pillow 合成日报
  • 发布与部署：每日 9 点（Europe/Paris 时区）自动发布推文，README 提供 FreeBSD 服务器上的 CRON 配置示例与 FTP 更新脚本

适用场景（解读层）

  • 跟踪突尼斯航空出发/到达延误的每日统计指标
  • 对比 Tunisair、Nouvelair、Air France（含 Transavia）的延误表现
  • 作为 API 抓取、SQLite 存储与定时报告发布的管道参考实现
