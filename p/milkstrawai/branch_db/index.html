🧭 简介解读层（AI·证据行可回查）

为 Rails 开发环境按 git 分支自动创建隔离 PostgreSQL 数据库的 gem

综述（解读层）

BranchDb 是一个 Ruby gem，为 Rails 应用的每个 git 分支生成独立命名的 PostgreSQL 数据库，通过增强 db:prepare 任务在分支缺失数据库时用 pg_dump | psql 从父分支或主分支克隆。适用于在多个功能分支间切换的 Rails 开发者。需 Ruby >= 3.2、Rails >= 7.0 及 psql/pg_dump/dropdb 工具；切换分支后须重启 Rails 服务器。

  • 为每个分支生成后缀命名的隔离数据库，切换分支后自动对应正确数据库
  • 克隆时按优先级检测父分支：BRANCH_DB_PARENT 环境变量、git reflog 分析、配置的主分支，并支持嵌套分支
  • 提供 db:branch:list/purge/prune 命令，purge 时保护当前与主分支数据库及有活动连接的数据库

适用场景（解读层）

  • 多个功能分支包含不同 migration，需要避免 schema 冲突的开发流程
  • 嵌套特性分支需要从父分支而非主分支克隆数据库的场景
  • 通过 BRANCH_DB_DATABASE_ 环境变量临时指向共享或恢复的数据库
