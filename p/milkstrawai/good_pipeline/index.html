基于 GoodJob 的 Rails DAG 任务流水线编排 Gem

综述（解读层）

GoodPipeline 是一个面向 Rails 应用的 Gem，用于将多步骤任务定义为有向无环图并基于 GoodJob 执行。它通过 run/after 声明步骤依赖，支持并行执行、barrier 阶段屏障、branch 运行时条件分支、failure_strategy 失败策略、.then 管道链及异步生命周期回调，并附带 Web 仪表盘。依赖 Ruby ≥ 4.0、Rails ≥ 7.2、PostgreSQL 与 GoodJob ≥ 4.14，且要求开启 preserve_job_records，否则启动时报 ConfigurationError。

  • 以 DAG 声明多步骤工作流，依赖的步骤自动并行执行或等待；支持 :halt/:continue/:ignore 三种失败策略并可按步骤覆盖
  • 提供 barrier 阶段屏障、branch 运行时条件分支（支持空臂）与 .then 管道串联，链式管道等待上游以 ignore 结局或成功
  • 内置可挂载的 Web 仪表盘，含过滤器、KPI、DAG/阶段视图、取消与重跑控制；取消仅停止未来调度，重跑生成独立新执行

适用场景（解读层）

  • 在 Rails 应用中将下载、转码、发布等多步骤后台任务编排为可并行、可分支的流水线
  • 通过仪表盘检查管道执行历史、步骤错误与 DAG 结构，并对终态管道进行取消或重新运行
  • 以 .then 将多个管道串联为依赖链，实现跨管道的串行/并行编排与失败传播控制
