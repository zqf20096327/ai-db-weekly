面向 OCaml 5 + Eio 的 RESP3 协议 Valkey 客户端库

综述（解读层）

ocaml-valkey 是为 OCaml 5.3+ 与 Eio 编写的 Valkey 7.2+ 客户端，仅支持 RESP3 协议，不含 RESP2 回退。当前为 alpha 状态（v0.4.0 已发布至 opam），提供约 140 个类型化命令封装、集群路由（CRC16 槽位哈希、MOVED/ASK 重试）、批处理、事务、客户端缓存、pub/sub、TLS 与 AWS IAM 认证。适合使用 OCaml 5 effects 并发模型访问 Valkey 的开发者，官方文档含从旧 OCaml Redis 客户端迁移的对照指南。

  • 基于 Eio 的 effects 风格并发，仅支持 RESP3，针对 Valkey 8/9 特性（hash field TTL、分片 pub/sub 等）提供封装
  • 包含集群路由（槽位哈希、拓扑发现、MOVED/ASK 重定向）、批处理（scatter-gather 与 MULTI/EXEC 原子模式）、阻塞命令 lease pool 与客户端缓存（Default/BCAST/OPTIN 三种模式）
  • 支持 TLS/mTLS、AWS ElastiCache IAM 认证（纯 OCaml SigV4 签名与自动刷新 token）、OpenTelemetry 观测，以及 Search/JSON/Bloom 模块的类型化封装

适用场景（解读层）

  • 在 OCaml 5 + Eio 项目中通过 RESP3 访问 Valkey 单机或集群
  • 需要客户端缓存失效推送、WATCH 事务守卫或跨槽位 HLL 合并等集群操作的键值存储应用
  • 连接启用 IAM 认证的 AWS ElastiCache，或需要 TLS 连接的生产部署
