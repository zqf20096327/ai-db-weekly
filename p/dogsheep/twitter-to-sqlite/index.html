将 Twitter 数据导入 SQLite 数据库的命令行工具

综述（解读层）

twitter-to-sqlite 是一个 Python 命令行工具，使用 Twitter API v1 将推文、用户资料、关注者、好友、收藏、列表及提及时间线等数据保存到 SQLite 数据库。使用者需先在 Twitter 开发者平台申请账号并配置包含 API key、secret、access token 等四项凭据的 auth.json。工具提供 --since 增量抓取、--sql 从已有数据库读取输入等选项，支持通过 Datasette 浏览数据。部分接口（如关注者）受 Twitter 速率限制约束。

  • 支持抓取用户时间线、批量查询推文/用户资料、关注者、好友、收藏、列表、主时间线与提及等多种 Twitter 数据，并写入 SQLite 表
  • 提供 --since/--since_id 增量抓取、--skip-existing 去重，以及 --sql/--attach 选项从已有 SQLite 数据库的查询结果获取输入
  • 凭据通过 twitter-to-sqlite auth 命令保存为 auth.json 文件，可通过 -a/--auth 指定路径

适用场景（解读层）

  • 将指定账号的推文、收藏、关注者等数据存档到本地 SQLite 数据库
  • 用 --sql 从已有 SQLite 表读取账号/ID 列表，批量拉取对应的 Twitter 资料
  • 配合 Datasette 浏览和查询导入的 Twitter 数据，例如按时间线过滤展示推文
