🧭 简介解读层（AI·证据行可回查）

将 Eloquent 访问器的计算值持久化到数据库的 Laravel 扩展包

综述（解读层）

这个 Laravel 包为 Eloquent 模型提供“计算属性”机制：属性值由访问器函数计算后写入数据库保存，可随时重新生成或校验，避免每次读取时重复计算，并支持按模型事件自动更新。通过 computed-attributes:generate 与 validate 两个 artisan 命令维护属性值，命令支持 chunkSize 参数和自定义查询范围。适用于 Laravel 10-13、PHP 8.1-8.4，经 Composer 安装。

  • 计算属性值保存在数据库中，可随时重新生成或校验
  • 提供 generate 和 validate 两个 artisan 命令，支持 chunkSize 分块处理
  • 可在模型中使用 computedAttributesGenerate 查询范围自定义取数逻辑

适用场景（解读层）

  • 需要将复杂计算结果持久化以便直接用数据库查询过滤的场景
  • 避免每次读取模型时重复执行计算的场景
  • 需定期批量校验或重算已有属性值的数据维护任务
📖 README 首段存档原文 · 程序抽取

Laravel package that adds computed attributes to eloquent models. A computed attribute is an accessor where the value is saved in the database. The value can be regenerated or validated at any time.
