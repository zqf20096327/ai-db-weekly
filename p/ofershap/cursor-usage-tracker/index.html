自托管 Cursor 企业版用量监控面板，含异常检测与 Slack 告警

综述（解读层）

该项目连接 Cursor 企业版 Admin API，按小时采集各开发者的用量与花费数据，通过阈值、Z-Score、趋势与单次请求成本四类检测层识别异常，并经 Slack 或邮件告警。面向工程管理、财务与平台团队，用 Next.js/TypeScript 编写，数据存于 SQLite，可经 Docker 自托管；需 Cursor Enterprise 计划与 Admin API Key。

  • 对接 Cursor Enterprise API，每小时采集成员、花费与用量事件数据
  • 实现多层异常检测（静态阈值、Z-Score、个人/团队趋势对比、单请求成本）并跟踪事件 MTTD/MTTI/MTTR
  • 提供 Web 面板（团队总览、洞察、用户下钻、异常页）与 Slack/邮件告警，支持 Docker 部署

适用场景（解读层）

  • 监控 Cursor 企业团队各开发者 AI 花费，识别超额或异常支出
  • 在账单周期结束前获取周期汇总、未使用席位与高频花费者信息
  • 追踪模型采用情况与各用户、仓库、功能维度的用量明细
