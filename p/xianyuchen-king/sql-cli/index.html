基于 JDBC 的多数据库 CLI 工具，面向 AI 编程助手设计

综述（解读层）

SQL-CLI 是一个运行于 Java 21 的命令行数据库客户端，通过 JDBC 驱动连接 MySQL、Oracle、PostgreSQL、SQL Server、SQLite、达梦等数据库，提供交互式 REPL、连接管理、数据导入导出和元数据浏览功能，并附 AI Skill 供 Claude Code、Cursor 等助手集成。其安全级别仅控制 SQL 执行策略，agent 级权限治理需由宿主工具负责。需自备 Java 21+ 环境，项目处于 Beta 阶段。

  • 通过 JDBC 支持多种关系型数据库，可用自定义驱动扩展
  • 提供 REPL 模式，支持连接复用、SQL 历史、快捷命令与输出格式切换
  • 密码采用 AES-256-GCM 加密存储，含 strict/normal/none 三级 SQL 执行控制

适用场景（解读层）

  • 让 AI 编程助手通过安装 Skill 直接执行数据库查询与元数据操作
  • 在终端以交互式 Shell 进行多数据库的日常查询与表结构查看
  • 以 CSV/JSON/SQL 格式进行数据导入导出与结果落盘
