Laravel Artisan 命令，在控制台实时监控应用执行的 SQL 查询

综述（解读层）

laravel-tail-db 是一个 Laravel/Lumen 的 Composer 包，通过 Artisan 命令 tail:db 在控制台实时显示应用执行的 SQL 查询。它会自动对查询运行 explain 并输出结果，并根据配置高亮慢查询。支持 PHP ^7.0 与 Laravel 5.5–8.0，安装后需发布配置文件。

  • 通过 php artisan tail:db 在控制台实时显示应用执行的 SQL 查询
  • 自动运行 explain 命令并将结果输出到控制台
  • 按配置文件高亮显示慢 SQL 查询

适用场景（解读层）

  • 开发调试时实时查看应用发出的 SQL 语句
  • 通过 explain 输出排查查询执行计划
  • 按自定义阈值定位慢查询
