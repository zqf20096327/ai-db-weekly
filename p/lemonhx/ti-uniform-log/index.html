🧭 简介解读层（AI·证据行可回查）

基于 ANTLR4 实现 TiDB 统一日志格式的解析器，供 TiDB 生态组件使用

综述（解读层）

该项目实现 TiDB 统一日志格式（RFC 0018），用于解析 TiDB、TiKV、PD 等 TiDB 生态软件的日志。解析器通过 ANTLR4 语法生成器构建，以 Go 编写，包含基于 go test bench 的性能基准。README 给出的测试数据为处理约 100M 大小的日志文件耗时约 16 秒，吞吐约 6.6MiB/s（约 20000 行/秒）。

  • 实现 TiDB 统一日志格式（tikv/rfcs 0018）的解析
  • 使用 ANTLR4 解析器生成器构建
  • 以 Go 实现，附带 go test bench 基准：约 100M 日志文件耗时约 16 秒（约 6.6MiB/s，20000 行/秒）

适用场景（解读层）

  • 解析 TiDB、TiKV、PD 组件产生的统一格式日志
  • 需要按 TiDB 日志格式做日志文本结构化处理的工具开发
  • 基于日志格式的自动化分析或处理脚本
