运行于 OpenLDK 的 Common Lisp JDBC 接口，将 JDBC 驱动字节码转译后在 SBCL 进程内运行

综述（解读层）

cl-jdbc 为 Common Lisp 提供 JDBC 数据库 API 封装，通过 OpenLDK 将 Java 驱动字节码转译为 SBCL 原生执行的 Lisp 代码，无需独立 JVM。提供 connect/query/execute/with-transaction 等原生 API 与 dbd-jdbc 驱动两种用法。需要 SBCL、Linux 与 JDK 25；SQLite 等依赖 JNI 本地库的驱动暂不支持。

  • 通过 OpenLDK 将 JDBC 驱动的 Java 字节码转译为 Lisp 代码，由 SBCL 在同进程同堆中编译运行
  • 内置驱动注册表，可按连接 URL 从 Maven Central 自动下载并缓存驱动 jar，支持 H2、PostgreSQL、MySQL、Oracle、SQL Server、DB2、Snowflake、Trino 等纯 Java（type-4）驱动，并可用 register-driver 注册新驱动
  • 提供 jdbc: 原生 API（含参数化查询、事务控制）与 cl-dbi 后端驱动 dbd-jdbc，连接 Mito、sxql 等基于 cl-dbi 的库

适用场景（解读层）

  • 在 SBCL 环境中用 Common Lisp 直连 Oracle、SQL Server、DB2、Snowflake 等无原生 Lisp 驱动的关系数据库
  • 让基于 cl-dbi 的既有 Lisp 项目（如使用 Mito ORM 或 sxql 的应用）通过 :jdbc 驱动访问 JDBC 数据库
  • 用 asdf:test-system 对内存 H2 或实时 PostgreSQL 运行测试套件进行验证
