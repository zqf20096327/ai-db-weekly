Python 3.10+ 异步 ClickHouse HTTP 客户端，支持双向类型转换与流式读取

综述（解读层）

aiochclient 是基于 aiohttp 或 httpx 的异步 ClickHouse 客户端，提供 execute/fetch/fetchrow/fetchval/iterate 等接口。README 说明了 TSV、RowBinary、Native 三种编解码引擎，安装时可选 Cython 扩展与 speedups 附加依赖。它面向需要在 asyncio 应用中通过 HTTP 访问 ClickHouse 的 Python 开发者。

  • 支持 aiohttp 与 httpx 两种连接器，异步执行查询与 INSERT
  • 自动进行 ClickHouse 与 Python 类型双向转换，覆盖整数、日期、Decimal、UUID、Map、Nested 等
  • 提供 native 与 binary 二进制引擎及 Cython 扩展，多块 Native 插入可通过 insert_block_size=0 保持原子性

适用场景（解读层）

  • 在 asyncio/uvloop 应用中通过 HTTP 读写 ClickHouse
  • 需要流式逐行遍历大结果集而不全部载入内存的查询场景
  • 批量 INSERT 时需要按列编码并以 Native 块流式提交的场景
