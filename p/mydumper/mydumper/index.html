🧭 简介解读层（AI·证据行可回查）

MySQL 逻辑备份工具套件，含 mydumper 导出与 myloader 导入，均基于多线程。

综述（解读层）

MyDumper 是开源的 MySQL 逻辑备份工具集，由社区维护，并非 Percona、MariaDB 或 MySQL 的官方产品。它包含 mydumper（导出一致性备份）和 myloader（读取备份并导入目标库）两个程序，均使用多线程。导出通过全局读锁、读取主从日志位置并建立一致性快照实现一致性；支持按表分文件输出、PCRE 正则筛选库表、--exec 调用外部命令处理文件，以及通过 defaults-file 配置主机、会话变量和按表 where/limit 条件。针对含字符串主键的大表提供基于元数据的分块规划器。

  • mydumper 导出一致性备份，myloader 读取备份并导入目标数据库，两者均使用多线程
  • 支持 PCRE 正则指定数据库与表的包含/排除规则，输出按表分文件并记录主从日志位置
  • 提供 --exec 调用外部命令处理导出文件，--defaults-file 支持全局、会话变量及按表 where/limit 配置

适用场景（解读层）

  • 对 MySQL/MariaDB/Percona/TiDB 环境进行一致性逻辑备份导出
  • 使用 myloader 将 mydumper 备份导入目标数据库，支持 AWS RDS 等需禁用会话 binlog 的恢复场景
  • 需要按条件（where/limit）导出部分表数据或按 PCRE 规则筛选库表的备份任务
