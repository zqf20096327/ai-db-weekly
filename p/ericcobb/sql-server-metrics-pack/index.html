🧭 简介解读层（AI·证据行可回查）

从 SQL Server DMO 收集指标的 T-SQL 脚本集合，支持跨重启留存历史数据

综述（解读层）

该项目是一组 T-SQL 脚本，通过读取 SQL Server 动态管理对象（DMO）的指标并存入表中，解决服务器重启后 DMO 数据被清空的问题。面向无专职 DBA 的开发者与系统管理员，也供 DBA 做长期分析。使用方式是运行安装脚本并定期（建议每晚）调度存储过程；开发者可通过只读视图查看指标而无需获得运行 DMO 的提升权限。

  • 提供索引指标脚本，将索引使用情况存表并跨重启聚合，支持生成 CREATE/DROP 脚本和查看索引定义变更历史
  • 提供数据库文件指标脚本，记录数据/日志文件的已用与空闲空间及自动增长设置
  • 安装脚本会创建表、存储过程和用于报表的视图，通过定期调度存储过程实现持续采集

适用场景（解读层）

  • 在缺少专职 DBA 的环境中，由开发者或系统管理员获取索引使用与数据文件使用情况
  • 识别未使用或极少使用的索引
  • 长期跟踪数据库文件增长趋势，用于规划存储与容量需求
