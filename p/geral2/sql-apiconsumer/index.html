SQL Server CLR 存储过程库，用于在数据库内调用 GET/POST API

综述（解读层）

SQL-APIConsumer 是一个用 C# 编写的 SQL Server CLR 数据库项目，提供通用存储过程在 SQL Server 内调用 API 的 GET/POST/PUT/DELETE/PATCH 方法。核心过程 APICaller_Web_Extended 返回 JSON 结果、状态码、响应头等扩展信息；另含 HMACSHA256 等工具函数。需启用 clr enabled、TRUSTWORTHY 模式并注册多个程序集，开发和测试环境为 SQL Server 2016 及以上。

  • 提供 APICaller_Web_Extended/APICaller_WebMethod 通用过程，支持 GET/POST/PUT/DELETE/PATCH 方法并可自定义请求头
  • 扩展版返回 JsonResult、StatusCode、ContentType、Json_Headers 等 HTTP 响应信息
  • 包含 Create_HMACSHA256、GetTimestamp 等工具函数，并附 DTO 自定义方法示例

适用场景（解读层）

  • 需要在 T-SQL 存储过程或作业中直接调用外部 REST API 的 SQL Server 环境
  • 需要在数据库端生成签名（如 HMACSHA256）以对接需认证 API 的场景
  • SQL Server 2016 及以上、允许启用 CLR 的实例上的接口集成任务
