面向 Mac 的原生数据库与商业智能工作区应用

综述（解读层）

RockxyBase 是一款原生 macOS 应用，用于连接 PostgreSQL 17（含 Supabase、Neon）和 SQL Server 2022，在同一工作区内编写 SQL、浏览数据、建模度量并生成图表与报告。该仓库不含源代码，仅发布 DMG 安装包与版本信息；当前为 0.5.0 公测版，要求 macOS 26.5 及以上。凭证存于 macOS 钥匙串，界面层强制只读连接。

  • 支持连接 PostgreSQL 17（含 Supabase、Neon）与 SQL Server 2022，默认经 TLS 连接，可直连或经 SSH 隧道，凭证保存在 macOS Keychain
  • 提供原生 SQL 编辑器（含补全、执行计划、事务与取消）及结果网格，支持表/结果的画像、分布与离群值分析（由数据库计算）
  • 支持数据建模（关系、度量、计算字段）、原生图表与含页面、切片器、下钻和交叉筛选的报告，并可导入 CSV 和 Excel 文件

适用场景（解读层）

  • 在 Mac 上连接并查询 PostgreSQL 或 SQL Server 数据库、探索表结构与关系
  • 基于数据库或导入的 CSV/Excel 数据构建图表与多页报告
  • 需要本地运行、无浏览器/服务器/云账户依赖的数据工作流
