PHP 数据源抽象层，将数据库、JSON、XML、CSV 等统一为 Row 迭代器

综述（解读层）

Anydataset Core 是 Anydataset 项目的核心模块，为 PHP 提供与具体数据源无关的抽象层。不同来源（数据库、JSON、XML、CSV、定宽文件、NoSQL 等）经 getIterator() 返回统一的 Row 对象迭代器；同一个 IteratorFilter 既可过滤内存数据，也可转换为数据库查询的 WHERE 子句。通过 composer 安装，测试使用 phpunit。文本文件、XML、JSON 等实现仅支持读取，核心与数据库驱动支持读写。

  • 为数据库、JSON、XML、CSV、定宽文本文件、NoSQL 等数据源提供统一的 Row 对象迭代器接口
  • IteratorFilter 支持 SQL 类语法过滤，同一过滤器可作用于内存数据或转换为数据库 WHERE 子句
  • 提供 JSON、XML、数组间的格式转换（Formatter）以及字段校验，支持自定义数据源实现

适用场景（解读层）

  • PHP 项目需以同一套代码读取多种数据源（关系数据库、MongoDB、JSON、文本文件等）
  • 需要将内存数据集与数据库查询共用同一过滤逻辑
  • 需在不同格式（JSON/XML/数组）间转换数据或按规则校验字段
