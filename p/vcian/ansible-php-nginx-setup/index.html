基于 Ansible Playbook 的 PHP+Nginx+MySQL 服务器环境自动部署工具

综述（解读层）

该仓库提供一组按编号组织的 Ansible Playbook，用于在新 Linux 服务器上自动部署 PHP 网站：检查 SSH 连通、安装 MySQL 并创建用户与数据库、安装 PHP 8.1 与 Nginx、下载 Adminer，并重写 Nginx 默认配置、重启 PHP-FPM。使用前需配置 hosts 清单与 SSH 凭据，安装 community.mysql 集合，运行命令为 ansible-playbook playbook/*.yml -i hosts -u ubuntu。执行前需按环境修改变量，README 提示运行前应阅读代码并做好备份。采用 MIT 许可。

  • 包含 8 个可单独或组合执行的 Playbook，覆盖连通性检查、MySQL、PHP 8.1、Nginx 安装及配置重启
  • 安装 MySQL 时在执行过程中交互式提示输入用户名、密码和数据库名
  • 支持通过 hosts 清单文件指定多台目标服务器，并用自定义 Nginx 配置覆盖默认配置，调整 upload_max_filesize、post_max_size、memory_limit

适用场景（解读层）

  • 在新 Linux 服务器上批量初始化 PHP 网站运行环境（Nginx + PHP 8.1 + MySQL）
  • 需要为多台服务器复制相同 PHP 环境配置的部署流程
  • 需要附带 Adminer 数据库管理工具的本地或测试服务器搭建
