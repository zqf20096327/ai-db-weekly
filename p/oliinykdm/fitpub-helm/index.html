非官方 Helm Chart，用于在 Kubernetes 上部署联邦健身追踪平台 FitPub

综述（解读层）

这是一个由第三方独立维护的 Helm Chart，用于将 FitPub 部署到 Kubernetes 集群，不隶属于 FitPub 官方项目。它要求外部提供启用 PostGIS 扩展的 PostgreSQL 数据库，内置非 root 运行、只读根文件系统、探针、PDB、Ingress/HPA/NetworkPolicy 等选项，并通过 kind 中的真实 PostGIS 启动做 CI 验证。适合需要在 Kubernetes 上自托管 FitPub 的运维人员。

  • 以非 root 用户（UID 1001）运行，默认 readOnlyRootFilesystem，符合受限的 Pod Security Standard
  • 提供可选 Ingress、HPA、NetworkPolicy、ServiceMonitor，以及 extraEnv/volumes/sidecars 等扩展点
  • 发布至 GitHub Pages 和 GHCR OCI registry，带 GPG/cosign 签名；CI 在 kind 中配合真实 PostGIS 执行安装与健康检查

适用场景（解读层）

  • 在 Kubernetes 1.26+ 集群上部署自托管的 FitPub 实例，需自备带 PostGIS 的 PostgreSQL
  • 通过 charts 值文件定制生产部署：外部 Secret、上传 PVC、Markdown 法律页面挂载、JVM 内存参数
  • 用 scripts/local-quickstart.sh 在 kind/minikube 上快速启动一套含临时 PostGIS 的本地实例
