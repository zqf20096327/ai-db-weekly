基于数据库的 Clojure 事务性任务队列，任务随业务事务原子入队

综述（解读层）

Drip 是一个面向 Clojure 的事务性任务队列，直接使用 MariaDB、PostgreSQL 或 SQLite 存储任务，任务可在应用自身事务内入队，事务回滚则任务消失。支持优先级、定时执行、指数退避重试、唯一约束、周期任务、Web UI 与 CLI。要求 Java 21+，依赖对应数据库的 JDBC 驱动。

  • 任务插入与业务写入共用同一数据库事务，通过 SKIP LOCKED 实现原子领取
  • 支持 1–4 优先级、定时执行、按 kind 配置的指数退避重试与超时、按参数/时间窗/队列的唯一约束
  • 提供周期任务、outbox 模式、队列暂停/恢复、实时 Web UI、CLI/TUI，PostgreSQL 下自动启动 LISTEN 连接触发即时轮询

适用场景（解读层）

  • 需要在业务事务中原子入队后台任务、避免双写不一致的 Clojure 应用
  • 已有 PostgreSQL/MariaDB/SQLite 且不希望新增独立消息中间件的团队
  • 需要通过 Web UI 或 CLI 查看和管理任务与队列的场景
