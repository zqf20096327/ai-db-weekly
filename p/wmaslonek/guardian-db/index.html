🧭 简介解读层（AI·证据行可回查）

基于 Rust 与 Iroh 的本地优先 P2P 去中心化数据库，支持本地读写与自动同步。

综述（解读层）

GuardianDB 是一个用 Rust 编写、构建在 Iroh 之上的去中心化数据库，面向需要点对点同步和离线优先运行的应用。每个节点保存完整本地副本，读写均为本地操作，变更经 Iroh 的 QUIC 传输与 Willow 差量对账在节点间收敛。提供键值、文档、事件日志三种存储，支持 PostgreSQL 线协议访问、可选 ODM 层与 WASM 计算任务分发；一致性保证限于集合实例本地，跨节点最终收敛。

  • 提供键值、文档、事件日志（LWW CRDT + 因果 DAG）三种存储类型，节点间经 Iroh QUIC 与 Willow 差量对账同步
  • 实现 PostgreSQL 线协议网关（pgwire），psql、TypeORM、node-postgres、DBeaver 可直接连接执行 SQL
  • 支持 pgvector 兼容的 HNSW 向量索引与 RAG 流程、基于 WASM 的 Guardian Compute 任务调度，以及可选 Rust/TypeScript ODM 层

适用场景（解读层）

  • 需要离线优先与点对点同步的本地优先应用（多节点无服务器部署）
  • 边缘计算/Edge AI 场景：数据与 WASM 推理任务分发到网络中各节点
  • 希望用现有 PostgreSQL 生态客户端（psql、TypeORM 等）访问去中心化存储的应用
