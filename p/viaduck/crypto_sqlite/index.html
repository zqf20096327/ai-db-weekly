SQLite3 页级加密 C++ 编解码接口，密码算法由用户自选

综述（解读层）

CryptoSQLite 提供 SQLite3 全页加密的 C++ 编解码接口，面向需要在 SQLite 中实现透明加密的 C++ 开发者。它不内置具体算法，用户实现 IDataCrypt 接口接入任意加密库；构建时自动下载并打补丁编译 SQLite3 amalgamation 以支持文件头加密。多库同时打开操作非线程安全，使用阶段线程安全。许可证为 LGPLv3。

  • 提供 IDataCrypt 接口，支持接入自定义加密库，不含硬编码算法列表
  • 实现 SQLite3 数据库全页加密，并支持对 SQLite3 文件头加密
  • 支持密钥文件：长加密密钥可单独存储并使用密码保护

适用场景（解读层）

  • 需要对 SQLite 数据库页面内容进行透明加密的 C++ 项目
  • 希望使用自有加密库或自定义算法实现 SQLite 加密的场景
  • 需要将长密钥存放于受密码保护的独立密钥文件的应用
