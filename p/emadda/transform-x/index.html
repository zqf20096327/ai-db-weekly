🧭 简介解读层（AI·证据行可回查）

在 JSON、SQLite、Excel 三种格式间互相转换的 JS 工具库

综述（解读层）

transform-x 提供三种格式两两互转的功能，可用作 JS 库、CLI、Web UI 和 HTTP API 四种方式，目标兼容浏览器、Node.js、Deno、Bun、Cloudflare Workers 等运行时。CLI 通过 npm 全局安装，文件经参数传入；受 JS 字符串限制，sqlite_to_json 转换约 500MB 内文件，JSON 输出 500MB 至 1GB，二进制值输出为 null。

  • 支持 JSON、SQLite、Excel 三种格式两两互相转换，提供 json_to_sqlite、sqlite_to_excel 等 6 个转换函数
  • 提供 JS 库、CLI、Web UI（transform-x.dev）和 HTTP API 多种使用方式
  • 目标兼容任意符合 Web 标准的 JS 运行时（浏览器、Node.js、Deno、Bun、Cloudflare Workers）

适用场景（解读层）

  • 需要在 JSON 数据与 SQLite 数据库或 Excel 表格之间批量转换格式
  • 在多种 JS 运行时环境中集成格式转换功能
  • 通过浏览器网页快速执行一次性格式转换
