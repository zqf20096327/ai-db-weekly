面向编码代理的技能包，注入 FastAPI/PostgreSQL/Docker 等生产工程模式

综述（解读层）

production-stack-skills 是一组安装到 ~/.claude/ 与 ~/.agents/ 的技能文件，为 Claude Code、Codex 等 AGENTS.md 兼容代理提供生产工程指令，覆盖 FastAPI、PostgreSQL、Docker、部署、安全与可观测性。核心命令 /production check 对项目做六类审计并输出 0-100 分与行动清单；审计脚本需 Python 3.10+，许可证为 MIT。

  • 提供 12 个 /production 子命令，包括 audit 打分、FastAPI/Postgres/Docker 模式、部署检查清单与 OTel 监控配置
  • 技能同时镜像到 ~/.claude/ 与 ~/.agents/，支持 Claude Code、Codex 及 AGENTS.md 兼容代理 CLI
  • 包含 production-check、production-review 等 10 个技能，采用编排器 + 子技能的目录结构，技能可依上下文自动触发并互相推荐

适用场景（解读层）

  • 为使用编码代理开发的项目执行生产就绪度审计并按分数生成整改清单
  • 在 FastAPI/PostgreSQL/Docker 技术栈中应用零停机迁移、多阶段构建、非 root 容器等既定模式
  • 在部署前执行检查清单、回滚方案与 OpenTelemetry/结构化日志/告警配置
