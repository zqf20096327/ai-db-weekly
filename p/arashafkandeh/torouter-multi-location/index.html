综述（解读层）

ToRouter 是一个运行在服务器上的 Tor 代理管理工具，通过多个独立 Tor 通道提供不同出口国家与 IP。包含 Rust 编写的守护进程、Web 管理面板、交互式 CLI（tor-p 命令）、SQLite 存储及 API。配置项支持按时间间隔自动轮换通道，数据库具备自愈机制；安装通过 curl 脚本完成，面向自建 VPS 的用户。

  • 支持定义多个独立 Tor 通道，每个通道可指定出口国家，宣称可配置超过 50 个位置
  • 提供 Web 面板与 CLI 两种管理方式，包含实时延迟/IP 监控、定时自动轮换出口、数据库备份与恢复
  • 设置存储于 SQLite 并带自愈机制，支持设置 Web Base Path 与登录保护，对外提供 API

适用场景（解读层）

  • 在一台 VPS 上维护多个不同出口国家/出口 IP 的 Tor 通道
  • 通过 Web 面板或 CLI 实时查看各通道延迟与出口 IP，并按时间间隔自动轮换
  • 通过 API 与本地管理结合，构建自定义的 Tor 路由控制脚本
