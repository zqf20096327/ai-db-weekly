🧭 简介解读层（AI·证据行可回查）

基于 Rust 与 ratatui 的键盘驱动终端 UI，用于浏览、查询和管理 Turso 与 SQLite 数据库。

综述（解读层）

tursotui 是一个在终端中运行的数据库客户端，面向使用 Turso 或 SQLite 数据库的开发者。它以 Rust 编写（需 1.85+），采用 ratatui 构建界面，导航键位仿 vim 风格。功能包括多数据库标签页、SQL 编辑器、模式浏览器、内联数据编辑、ER 图、模式对比与数据导出等；MIT 许可，需从源码用 cargo 构建。

  • 提供 SQL 编辑器（语法高亮、撤销/重做、参数化查询）、模式树浏览、可排序结果表及内联 DML 编辑，提交前可预览生成语句并支持事务回滚
  • 支持 ER 图生成、跨库模式对比（F7）、EXPLAIN 视图、数据采样剖析（Profile 标签）及慢查询跟踪与过滤
  • 针对 Turso 兼容面设计：外键元数据从 CREATE TABLE SQL 解析，自动补全含 Turso 特有函数（uuid4、vector_top_k、fts_match 等），README 列有上游已知限制清单

适用场景（解读层）

  • 在终端中同时打开并切换多个 Turso/SQLite 数据库文件，浏览表结构、执行查询、查看 DDL
  • 直接在结果视图中增删改行数据，预览生成的 INSERT/UPDATE/DELETE 语句后事务性提交
  • 对比两个数据库的模式差异并复制迁移 SQL，或对表做列级统计分析（空值率、唯一性、值频率等）
