监听磁盘文件并载入 XTDB 数据库的响应式 Clojure 数据环境

综述（解读层）

FileDB 监视本地文件，将 EDN、JSON、Markdown 元数据等内容读入 XTDB 数据库，用户通过 Clojure 代码和 Datalog 查询与之交互，并可添加触发器实现自动化。数据以磁盘文件为准，可通过任意文件同步工具在设备间复制数据库。README 说明其面向 Clojure 开发者，需安装 Clojure 与 Babashka。

  • 监视文件变化，自动读取 EDN、JSON、Markdown yml 元数据入库，无读取器的文件可通过 .meta.edn 旁挂文件添加元数据
  • 支持 repl.fdb.clj 文件在持久进程中求值、query.fdb.edn 查询文件、fdb.on/modify 与 fdb.on/schedule 等响应式触发器
  • 内置 http-kit 服务器映射路由到函数，支持 Hiccup 渲染与外部 API 调用辅助函数，并提供 .eml 邮件同步功能

适用场景（解读层）

  • 对 Obsidian 等本地 markdown 笔记库编写个人自动化脚本
  • 通过文件同步（如手机保存文件触发笔记本计算）实现跨设备自动化
  • 用 Hiccup 和 HTMX 为个人数据搭建小型 Web 界面或调用外部 API
