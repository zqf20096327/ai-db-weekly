以 SQLite 为存储的单机 Datomic Pro Docker 快速启动镜像

综述（解读层）

该项目提供将 Datomic Pro 运行在 SQLite 存储之上的 Docker 镜像，用于在单机上快速启动 Datomic。启动时自动创建名为 app 的数据库（可用 DATOMIC_DB 环境变量改名），数据落在挂载的 ./storage 目录；客户端需添加 Datomic peer 库与 SQLite JDBC 驱动依赖，并通过 4334 端口连接。备份可直接复制存储目录，Datomic 自带的 backup/restore 也照常可用。

  • 通过单条 docker run 命令启动，暴露 4334 端口并将 SQLite 数据库存放在挂载的 ./storage 目录
  • 自动创建默认名为 app 的数据库，支持通过 DATOMIC_DB 环境变量自定义数据库名
  • 支持 Datomic 原生 backup/restore 流程，且 SQLite 数据库文件可随时直接备份

适用场景（解读层）

  • 在单机上快速启动 Datomic Pro 进行本地开发或实验
  • Clojure 应用连接 Datomic 时使用 SQLite 作为本地存储
  • 配合 Litestream 等工具将存储目录持续复制到 S3 兼容桶实现备份，或后续迁移到其他存储服务
