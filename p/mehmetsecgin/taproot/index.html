综述（解读层）

TapRoot 是一个 TypeScript 编写的命令行工具，用于查询 MySQL/TiDB、Redis 和 gRPC 数据源，每条命令输出单行 JSON，README 表明其面向 AI 代理场景。它依赖 Node.js 20+，凭据默认存入系统钥匙串（可选 keytar），失败时回退到加密文件；支持 Teleport 的 tsh 登录和 kubectl 端口转发访问，并提供基于 services.json 的知识库自动生成数据源配置。项目需从源码构建安装，通过 skills 目录供 Claude Code 等代理引用规则。

  • 每条命令输出单行 JSON，提供 --help 分层命令文档
  • 凭据写入系统钥匙串（keytar），不可用时回退到 ~/.taproot/ 下的加密文件
  • 支持三种访问方式：native、tsh（Teleport）和 qa-portforward（kubectl 端口转发），并提供知识库驱动的 taproot init datasource 自动建档

适用场景（解读层）

  • AI 代理或脚本通过 JSON 输出查询 MySQL/TiDB、Redis、gRPC 数据源
  • 经 Teleport（tsh）或 kubectl 端口转发访问受管控的远程数据库
  • 基于 services.json 知识库批量初始化环境/服务的数据源配置
