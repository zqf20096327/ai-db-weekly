综述（解读层）

Databend 是一个用 Rust 编写的开源数据仓库，运行在 S3、Azure、GCS 等对象存储之上，在同一套表上提供 SQL 分析、向量搜索和全文检索，并支持沙箱化 Python UDF。项目采用存算分离架构，提供 Git 式数据分支功能。可通过 Docker 一键自部署并使用 BendSQL 连接，也提供云服务；Apache 2.0 许可，少数企业功能为 Elastic 2.0。

  • 在同一存储层实现 SQL 分析、向量搜索与全文检索
  • 支持沙箱化 Python UDF，通过 Arrow Flight 与隔离的 Sandbox Worker 交互
  • 提供 Git 式数据版本分支，以及自动 schema 演进与事务支持

适用场景（解读层）

  • AI Agent 编排：结合沙箱 UDF、SQL 与分支机制
  • 大规模 SQL 分析与 BI 报表
  • 检索增强生成（RAG）中的向量与全文检索场景

Databend is an open-source data warehouse built in Rust. Analytics, search, and agent workloads run on the same tables, so there is no second system to sync.
