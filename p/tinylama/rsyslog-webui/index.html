rsyslog 写入 MySQL 的 syslog 事件的 Web 浏览界面

综述（解读层）

rsyslog-webui 提供一个网页界面，用于浏览 rsyslog 写入 MySQL 的 syslog 事件，包含实时搜索、tail 式轮询更新、基于角色的访问控制，以及可选的 Microsoft Entra ID OIDC 登录和 TOTP/通行密钥 MFA。项目以 Docker Compose 部署，内置监听 5514 端口（TCP/UDP）的收集器，将网络 syslog 消息转发到 MySQL；生产路径通过 Traefik 与 Cloudflare DNS-01 提供 HTTPS。适用于需要网页端查看 rsyslog 数据库日志的运维人员。

  • 提供带防抖关键词/过滤集搜索的实时 syslog 表格与轮询式 tail 更新
  • 支持本地用户与 Microsoft Entra ID（OIDC + PKCE）认证，含 TOTP 与 WebAuthn 通行密钥 MFA
  • 内置 TCP/UDP 5514 syslog 收集器，将消息写入 MySQL，提供 TLS（Traefik/手动 PEM）与 HTTP 本地开发两种 Compose 部署方式

适用场景（解读层）

  • 通过浏览器检索和跟踪 rsyslog 写入 MySQL 的 syslog 事件
  • 需要角色访问控制和审计日志（登录尝试、访问决策）的日志查看环境
  • 使用 Entra ID 登录与 MFA 的组织内部日志门户部署
