基于 Oracle PL/Scope 的 PL/SQL 源码分析工具集

综述（解读层）

plscope-utils 基于 Oracle Database 11.1 起提供的 PL/Scope 功能，包含两个组件：核心数据库对象提供关系视图和 PL/SQL 包，用于简化常见源码分析任务，需服务器端安装；SQL Developer 扩展在数据库导航树中增加 PL/Scope 节点、上下文菜单和报表，仅需客户端安装。SQL 扩展提供二进制发布版本。

  • 核心组件提供关系视图与 PL/SQL 包，用于源码分析任务
  • SQL Developer 扩展新增 PL/Scope 导航节点、上下文菜单、视图展示与报表
  • SQL 扩展提供二进制发布版本，仅需客户端安装

适用场景（解读层）

  • 分析 Oracle 数据库中的 PL/SQL 源代码
  • 在 SQL Developer 中查看 PL/Scope 分析结果
  • 在服务器端通过 SQL 查询执行源码分析
