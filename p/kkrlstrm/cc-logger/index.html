通过 HTTP hooks 将 Claude Code 会话与工具调用记录到 Postgres 的观测工具

综述（解读层）

cc-logger 基于 Claude Code 的 HTTP hooks（不修改 Claude Code 本身）将每次会话、子代理调用、工具调用及模型文本叙述写入 Postgres，供后续 SQL 查询检查。它捕获的 Read/Skill 调用可对比磁盘文件找出未被读取的上下文，token 与模型信息从 transcript 文件恢复。需 Postgres 连接，支持 Docker Compose 或 uv 原生安装，工具捕获按白名单过滤。

  • 通过 HTTP hooks 捕获会话、子代理、工具调用及工具间文本叙述，存入 Postgres JSONB
  • 提供 sessions/inspect/insights/rate 等 CLI 命令及 queries/ 目录下 17 个 SQL 查询文件
  • 写入前默认按正则对常见密钥模式脱敏，工具捕获遵循白名单（跳过 Read/Glob/Grep/TodoWrite）

适用场景（解读层）

  • 回看单个会话完整调用树，检查代理实际执行过程
  • 跨会话运行 SQL 查询，对比重复运行同一代理时的工具序列差异
  • 统计模型与 token 使用、子代理扇出模式等跨会话数据
