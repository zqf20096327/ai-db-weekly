用类电子表格界面在 PostgreSQL 中构建和管理数据的 Web 应用

综述（解读层）

Dataface 提供类电子表格界面，让非 IT 人员在 PostgreSQL 数据库中创建行列、跨表关联列；底层是带 REST API 与 Web 应用的标准 PostgreSQL。技术栈含 Koa2 与 Vue，提供 docker-compose 一键启动，访问 localhost:9966 使用。

  • 以类电子表格界面增删数据、创建行和列，并支持跨表关联列
  • 数据存储于原生 PostgreSQL 数据库，其上提供 REST API 与 Web 应用
  • docker-compose 提供 Postgres 容器与应用容器，运行后经 localhost:9966 访问

适用场景（解读层）

  • IT 部门为非 IT 人员提供可直接管理数据的工具
  • 替代由单人维护的电子表格或 Access 数据库场景
  • 后续可迁移为正式应用的前期数据搭建
