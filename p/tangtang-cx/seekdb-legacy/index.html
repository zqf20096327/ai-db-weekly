OceanBase 推出的面向 AI Agent 的 MySQL 兼容状态存储数据库，fork 参赛仓库

综述（解读层）

seekdb 是 OceanBase 团队基于其 SQL 引擎构建的开源数据库，定位为 AI Agent 的状态存储，支持向量、全文与标量的混合 SQL 查询、MySQL 协议以及内核级 Copy-on-Write 的 FORK/MERGE 沙箱。提供嵌入式、单机服务器和分布式三种运行形态。本仓库为参赛者 fork，用于提交 OceanBase seekDB 2026 挑战赛的基础实践题交付内容。安装方式包括 pip 安装 pyseekdb、Docker 镜像、二进制安装或云端实例。

  • 支持向量、全文与标量过滤合并在单条 SQL 查询中执行
  • 提供 FORK DATABASE / MERGE TABLE / DROP DATABASE 的内核级 COW 沙箱机制
  • 通过 Change Stream 异步索引管道配合两级 HNSW 索引实现写入与查询解耦

适用场景（解读层）

  • Agent 记忆与状态的持续写入及毫秒级检索
  • RAG 与知识库中的混合检索场景
  • AI 编码助手的语义代码搜索与多项目隔离
