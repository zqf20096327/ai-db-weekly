综述（解读层）

这是一个基于 NestJS 的 REST API 脚手架项目，面向需要快速搭建典型后端服务的开发者。它集成了 TypeORM 与 Mongoose 两种数据层方案，提供邮箱及社交登录认证、角色管理、文件上传（本地与 S3）、邮件发送、国际化翻译等模块，并包含 Swagger 文档、E2E 与单元测试、GitHub Actions CI 和 Docker 配置。项目属于 bc boilerplates 生态，配有在线 Demo 与完整文档，还有一个配套的前端脚手架。

  • 同时支持 TypeORM 和 Mongoose 两种数据库访问方式，并提供数据填充（Seeding）功能
  • 实现邮箱注册登录及 Apple、Facebook、Google 社交登录，包含 Admin 和 User 两种角色
  • 包含文件上传（本地与 Amazon S3 驱动）、邮件发送、I18N 国际化、Swagger 文档、E2E 与单元测试、GitHub Actions CI 及 Docker 配置

适用场景（解读层）

  • 搭建包含用户认证与角色管理的 NestJS 后端服务
  • 需要 Postgres/MongoDB 数据库、邮件、国际化等常见后端功能的 REST API 项目起点
  • 与配套的 extensive-react-boilerplate 前端脚手架配合进行全栈开发
