🧭 简介解读层（AI·证据行可回查）

Miro 数据库模式可视化设计插件，支持协作建模并生成代码

综述（解读层）

这是一个 Miro 白板插件，用于团队在画布上协作设计数据库模式，可创建数据库实体、通过表单交互式编辑实体名称和字段，并生成 MySQL DDL 等代码。数据存储在 Miro 小部件元数据中，服务器仅提供静态文件。项目已归档。开发需克隆仓库、npm install、在 ./src/Config.ts 中设置 APP_ID 后运行 webpack dev server。

  • 在 Miro 画布上创建数据库模式实体，并通过表单交互式编辑实体名称和字段
  • 生成代码，包括 MySQL DDL 等格式
  • 数据存储于小部件元数据，服务器仅用于提供静态文件；使用 preact 和 webpack 构建以减小包体积

适用场景（解读层）

  • 团队在 Miro 画布上协作设计数据库模式
  • 从可视化设计的模式生成 MySQL DDL 等代码
  • 为开发插件参考其基于小部件元数据存储数据的实现方式
