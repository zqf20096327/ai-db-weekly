🧭 简介解读层（AI·证据行可回查）

面向数据工程的决策溯源与数据流追踪插件，记录变更原因

综述（解读层）

provLedger 是一个 Claude Code 插件（另有 pip 安装的独立核心库），用于追踪数据项目中的代码与数据变更及其决策原因。它将决策记录挂载到项目实体（函数、列、任务等）上，从源码测量、用户陈述、外部证据三类来源构建图谱，记录已删除对象的历史。适合数据团队及与编码代理协作的开发者。

  • 提供 Graph、Node、Task 三视图共享同一项目/节点/时间点锚点，涵盖数据流图谱、单节点历史与任务决策链
  • 保留已删除对象的完整历史（tombstone），记录被否决的路径、失败步骤与后来被推翻的原因，未记录处标注 unstated
  • 每次运行从源码重建图谱并与前次比较计算差异；/ledger 答复每句引用记录 id，/receipts 以时间线输出记录

适用场景（解读层）

  • 查询项目中被移除的列/函数的决策来源及其背后的邮件、会议等证据
  • 编码代理在编辑前获取约束规则与被否决路径的提示，以及上游依赖变更的 blocking findings
  • 新成员或接手项目者无需参与历史会议即可追溯项目实体随时间的演变与规则
