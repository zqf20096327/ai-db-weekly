基于 node sqlite3 的类型安全、Promise 风格查询客户端

综述（解读层）

sqlite3-queries 是 Node.js sqlite3 驱动之上的查询客户端，将回调式 API 封装为 Promise 形式，并通过泛型为查询结果提供类型标注。它支持打开内存或磁盘数据库、自动迁移、事务、PRAGMA、扩展加载和 VACUUM 等操作，也可直接调用 sqlite3 原生 API。安装时需同时安装 sqlite3 依赖，适用于希望在 Node 项目中以 TypeScript 编写 SQLite 查询的开发者。

  • 提供 run/get/all/exec/prepare/transaction 等 Promise 化 API，get/all 支持泛型声明结果行类型
  • 支持自动迁移、verbose 调试模式、参数追踪日志，以及 pragma/loadExtension/vacuum/escape 等辅助方法
  • 支持数组参数与命名参数（$ 前缀）两种占位符形式，且可访问 sqlite3 全部原生 API

适用场景（解读层）

  • Node.js 或 TypeScript 项目中通过 sqlite3 访问 SQLite 数据库
  • 需要以 Promise/async-await 方式编写查询并显式控制事务的场景
  • 需要数据库结构自动迁移或内存数据库调试的场景
