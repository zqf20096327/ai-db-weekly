面向 Rails/ActiveRecord 的慢查询追踪 Gem，含 Slack 通知

综述（解读层）

QueryTrack 是一个 Ruby Gem，用于在基于 ActiveRecord 的 Rails 应用中找出耗时超过阈值的数据库查询，并记录原始 SQL、执行时长与调用 backtrace。适用于 Rails 开发与运维人员。配置项包括时长阈值（duration）、console 日志、按 backtrace 过滤、app_dir 自定义、ENV 开关、Slack incoming webhook 通知及自定义 handler；通知在独立线程中发送，支持 MIT 许可开源。

  • 支持配置 SQL 时长阈值，捕获超时查询的原始 SQL、时长与 backtrace
  • 支持 Slack webhook 通知与自定义通知 handler，可自定义输出目标
  • 提供 backtrace 过滤、app_dir 自定义、ENV 变量启停开关

适用场景（解读层）

  • Rails 应用开发/运维中定位耗时 SQL 查询
  • 希望将慢查询告警接入 Slack 或其他自定义通知渠道
  • 多节点横向扩展项目中仅需在部分节点安装监控

Tool for finding time-consuming database queries for ActiveRecord-based Rails Apps. Provides Slack notifications with backtrace, raw SQL, time duration, etc.
