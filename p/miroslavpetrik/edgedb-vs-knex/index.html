用任务系统示例对比 Knex/Objection ORM 与 EdgeDB 查询构建器的 TypeScript 实现项目

综述（解读层）

该项目围绕一个任务模型（含状态计算、通知、已读事件等）分别提供 Knex/Objection 与 EdgeDB 两种 TypeScript 实现，包含任务状态、通知标记、通知计数三个查询场景，并用 Jest 进行测试。README 记录了迁移方式、类型模型、类层级查询、参数化查询等维度的实现差异。适用于想通过同一模型对照两种数据访问方式的开发者。

  • 提供 Knex/Objection 与 EdgeDB 两套同一任务模型的 TypeScript 实现
  • 实现任务状态计算、用户相关通知判断、通知计数三个对比查询场景
  • EdgeDB 侧使用 schema 文件生成迁移、查询构建器与 TypeScript 接口，并使用全局变量（global variables）实现多用户测试

适用场景（解读层）

  • 对照学习 Knex/Objection 与 EdgeDB/EdgeQL 在同一模型上的写法差异
  • 评估图关系数据库 schema 与查询构建器工作流的参考样例
  • 作为含继承类型、计算属性、多用户通知场景的测试用模型源码
