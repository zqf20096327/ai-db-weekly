基于.NET Core数据提供者接口的通用数据库操作封装类库

综述（解读层）

netcoreDbHelper（包名CodeM.Common.DbHelper）是对.NET Core数据库操作的封装类库，非ORM框架。它通过注册数据提供者工厂和数据源配置，将操作代码与具体数据库隔离，支持Sqlite、SqlServer、Mysql、Oracle、PostgreSQL及达梦等数据库。2.0.0起基于.NET 8开发，通过NuGet安装使用。

  • 通过RegisterDbProvider/AddDataSource实现操作代码与具体数据库的隔离，更换数据库时只需替换数据提供者和连接配置
  • 提供ExecuteNonQuery、ExecuteScalar、ExecuteDataReader等执行方法，支持传入数据源名称、DbConnection或DbTransaction，并可指定超时时间、命令类型和参数
  • 支持注册任意实现微软数据提供者接口的关系型数据库，README给出Sqlite、Mysql、Sqlserver、Oracle、PostgreSQL、达梦六种数据库的注册示例

适用场景（解读层）

  • 需要在多种关系型数据库间保持统一数据访问代码的.NET应用程序
  • 需要使用达梦等国产数据库且基于.NET Core/NET 8开发的项目
  • 需要以轻量封装方式执行SQL命令、参数化查询和事务操作，而不引入ORM的场景
📖 README 首段存档原文 · 程序抽取

netcoreDBHelper不是ORM框架，只是对.netcore中数据库操作的封装。封装的意义在于使用DBHelper进行数据库操作时，将操作代码和具体的数据库隔离开，在未来如果需要更换数据库便不需要修改操作代码，只需简单的替换数据提供者和数据源配置信息。
