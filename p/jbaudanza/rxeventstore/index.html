基于事件溯源模式和 RxJs 的事件存储模块，支持 Redis 与 PostgreSQL。

综述（解读层）

RxEventStore 是一个 Node.js 模块，用于以事件溯源模式持久化和查询数据，事件日志持久且只追加。它提供 Redis 和 PostgreSQL 两种驱动，通过 .observable() 返回 RxJs Observable、.query() 以 Promise 返回事件。支持游标断点续订、事件元数据、元数据过滤，以及将事件日志投影到 Redis 数据结构的 worker 机制。可通过 NPM 安装，也可与 RxRemote 配合实现 WebSocket 远程订阅。

  • 提供 Redis 和 PostgreSQL 两种驱动存储和查询事件，可单独或混合使用
  • 支持游标（cursor），可在取消订阅后从断点恢复订阅，适用于跨进程续接
  • redis 驱动提供投影机制，通过 worker 进程以 MULTI 块原子更新投影并在更新后通知

适用场景（解读层）

  • 以事件日志作为应用唯一事实来源的事件溯源型应用
  • 需要将事件流投影到 Redis 数据结构的后台 worker 进程
  • WebSocket 断线后需恢复订阅位置或长期运行的事件流处理任务
