自托管的 MCP 记忆服务器，为 AI 代理和团队提供混合检索与神经记忆图。

综述（解读层）

Kagura Memory Cloud 是一个面向 AI 代理与团队的自托管 MCP 服务器，用于持久化存储与检索记忆。检索采用语义向量与 BM25 关键词混合的 recall() 路径，并配合基于赫布学习的记忆图遍历 explore() 路径做关联发现。技术栈包含 FastAPI、PostgreSQL、Qdrant、Redis 与 Next.js 前端，支持工作区、RBAC 与上下文隔离，需 Python 3.11+、Node.js 24+、Docker 及一个嵌入服务（OpenAI 或 Ollama 等自托管后端）。

  • 提供 recall()（语义 60% + BM25 40% 混合检索，可选 AI 重排序）与 explore()（记忆图遍历）两条独立检索路径
  • 每次 recall() 会在后台强化被共同检索的记忆之间的图边；通过 MCP 暴露 72 个工具，涵盖记忆、上下文、标签、文件、密钥管理等类别
  • 支持 OpenAI 或自托管（Ollama/vLLM）嵌入后端、工作区与 RBAC 团队协作、按 workspace_id→context_id→user_id 过滤的数据隔离，以及单进程场景下的 LanceDB 内嵌向量后端（preview）

适用场景（解读层）

  • 为 Claude Code、Claude Desktop、ChatGPT、Gemini 等 MCP 客户端接入跨会话的持久化记忆
  • 团队或组织通过工作区、上下文隔离与共享记忆管理项目知识
  • 本地部署场景下使用 Ollama 等自托管嵌入服务构建私有化知识库
