🧭 简介解读层（AI·证据行可回查）

为 AI 客户端与团队提供共享持久记忆的自托管 MCP 服务器

综述（解读层）

Kagura Memory Cloud 是一个 Apache 2.0 开源的记忆存储服务，通过 MCP（Streamable HTTP）与 REST API 供 ChatGPT、Claude、Cursor 等客户端保存和检索决策与项目知识。数据按工作区—上下文—记忆三层组织，检索采用语义向量（Qdrant）加 BM25 关键词的混合方式，存储依赖 PostgreSQL、Redis，构建栈为 FastAPI 与 Next.js。自托管需 Docker Compose、Python 3.11+ 及外部 embedding 提供方；仅存储显式保存的内容，不自动导入历史聊天。

  • 提供 remember/recall/reference 等 MCP 工具，支持 ?profile=full 与 ?add_tools=explore 调整工具目录
  • 实现语义搜索与 BM25 关键词匹配的混合检索，可选重排序，并以 PostgreSQL 与 Qdrant 分别存储记录、关键词、图与向量
  • 支持记忆更新、取代（supersession）与修订历史查看，以及工作区、私有/共享上下文、角色等团队控制

适用场景（解读层）

  • 跨 AI 客户端复用同一工作区的项目决策与约束，恢复之前会话未完成的工作
  • 团队通过共享上下文与角色权限协作维护项目知识库
  • 为自建 agent 提供按需检索相关上下文、替代发送完整会话日志的接口
