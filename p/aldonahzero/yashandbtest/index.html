🧭 简介解读层（AI·证据行可回查）

基于 SQLancer 对 YashanDB 的黑盒逻辑测试工程，运行 TLP 分区比较检查。

综述（解读层）

该工程在指定服务器环境（Java 11、YashanDB 23.4.1.109 评估版）上运行 SQLancer 的 TLP_WHERE 黑盒逻辑测试，面向需要长期自动化验证 YashanDB 的测试人员。支持 systemd 托管的七天实验、双工作进程独立 seed、按小时轮次保存结果，并提供 manifest、oracle-metrics、summary 等 JSON 记录。限制包括：未启用自动 reducer、不报告代码覆盖率，结果不一致需干净状态重放。

  • 生成器支持 INT、NULL 数据、重复行、简单索引、UPDATE/DELETE、INNER/LEFT JOIN 及有界算术、COALESCE、ABS、NULLIF 等确定性表达式
  • TLP 比较完整投影行的频数，保留重复次数与 NULL；第三分区用 CASE WHEN 等价实现，拒绝对布尔谓词直接使用 (p) IS NULL
  • 通过 3 项结果比较单元测试、12 项固定数据契约检查及跨 10 个数据库状态的 10,000 次 TLP 检查

适用场景（解读层）

  • 对 YashanDB 执行长期无人值守的 TLP 黑盒逻辑测试（systemd 托管七天实验）
  • 保留测试运行日志与候选复现材料，供后续干净状态重放与最小化分析
  • 通过 scripts/build.sh 与 db_admin.py 管理测试构建和数据库启停
