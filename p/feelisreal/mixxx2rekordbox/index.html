将 MIXXX 曲库导出为 Rekordbox 可导入 XML 的 Python 脚本

综述（解读层）

该脚本读取 MIXXX 的 SQLite 数据库，将曲库（含热点、颜色标记、播放列表与 Crates）导出为 output.xml，供导入 Pioneer Rekordbox。目标用户是家用 MIXXX 用户，需在 extract_to_xml.py 中手动修改数据库路径后运行。README 提示不提供任何保证，使用前需备份两侧曲库。

  • 读取 MIXXX 的 SQLite 数据库并生成 XML 文件
  • 导出内容包括热点、颜色标记、播放列表和 Crates
  • 生成 output.xml，可手动导入 Rekordbox

适用场景（解读层）

  • 将 MIXXX 曲库导入 Rekordbox 以在 Pioneer 设备上使用
  • 迁移家中整理的热点、播放列表等元数据到俱乐部设备
