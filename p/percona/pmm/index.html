开源数据库监控管理工具，采集指标与查询数据用于分析

综述（解读层）

PMM 是一个自托管的开源数据库监控与可观测性工具，支持 MySQL、PostgreSQL、MongoDB、Valkey/Redis、ProxySQL、HAProxy 及多家云托管数据库。采用 Server/Client 架构：Client 部署在数据库主机旁读取数据库已有统计数据，Server 集成 Grafana、VictoriaMetrics、ClickHouse、PostgreSQL 存储并展示指标。所有功能随开源版发布，许可证为 AGPLv3（Server），通过 Docker 脚本或 Helm 等方式部署。

  • 提供 Query Analytics，按负载对查询排序并附带执行计划（EXPLAIN）与表统计信息
  • 内置基于 Grafana 的多层仪表盘（节点→实例→查询）、告警模板、Advisor 检查，以及 MongoDB 时间点恢复的备份功能
  • 客户端读取数据库自身采集的统计（Performance Schema、pg_stat_statements、MongoDB profiler 等），支持 RDS/Aurora、Azure、Google Cloud 的免主机接入

适用场景（解读层）

  • 从节点 CPU 异常定位到对应的 PostgreSQL/MySQL 查询的数据库性能排查
  • 运维 MySQL、PostgreSQL、MongoDB、Valkey/Redis 混合实例及 RDS/Aurora 等云数据库的统一监控
  • 需要查询样例数据保留在自有服务器上的自托管监控部署
