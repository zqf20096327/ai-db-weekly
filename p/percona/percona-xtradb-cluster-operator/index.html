🧭 简介解读层（AI·证据行可回查）

在 Kubernetes 上自动化创建和管理 Percona XtraDB Cluster MySQL 集群的 Operator

综述（解读层）

该项目是基于 Operator SDK 的 Kubernetes Operator，用于自动化部署和管理基于 Percona XtraDB Cluster 的 MySQL 集群，适用于在本地或云上运行 Kubernetes 并需要 MySQL 集群运维能力的团队。它通过自定义资源描述集群，支持 HAProxy/ProxySQL 代理、定时与手动备份、基于 Kubernetes API 的密码轮换等机制，主要经由 kubectl 命令行管理，也可选用 Percona Everest 提供的 Web 界面操作。

  • 通过 deploy/bundle.yaml 与 cr.yaml 两步 kubectl apply 即可部署 Operator 与数据库集群
  • 提供 HAProxy 或 ProxySQL 负载均衡与代理服务，支持定时和手动备份
  • 集成 Percona Monitoring and Management 监控，支持 Smart Update 自动更新与通过 Kubernetes API 实现的系统用户密码轮换

适用场景（解读层）

  • 在本地或云端 Kubernetes 环境中部署 Percona XtraDB Cluster MySQL 集群
  • 对集群执行计划备份、软件更新和密码轮换等日常运维任务
  • 需要命令行之外的管理方式时，通过 Percona Everest Web 界面进行数据库配置与管理
