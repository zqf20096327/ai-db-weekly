MySQL 服务器指标的 Prometheus 导出器，通过 SQL 采集并暴露监控指标

综述（解读层）

mysqld_exporter 是一个面向 MySQL/MariaDB 的 Prometheus 导出器，连接数据库实例并采集全局状态、performance_schema、information_schema、复制等指标。支持 MySQL >= 5.6 和 MariaDB >= 10.3，可通过 .my.cnf 或环境变量配置凭据，支持单实例和多目标 /probe 两种运行模式，并提供 TLS 与基本认证。适用于已部署 Prometheus 的数据库监控链路。

  • 提供约 30 个 collector 标志，可按需启用 global_status、performance_schema、processlist、复制状态等指标采集，部分默认启用
  • 支持多目标模式：单个实例通过 /probe?target= 端点采集多个 MySQL 实例，凭据可用 config.my-cnf 分节匹配 auth_module
  • 支持 TLS 和基本认证（经 --web.config.file 配置），并可配置 SSL CA 与客户端密钥对连接启用 SSL 的 MySQL 服务器

适用场景（解读层）

  • 为 Prometheus 抓取 MySQL/MariaDB 实例的状态、InnoDB、性能schema与复制指标
  • 以单导出器实例通过 /probe 模式监控多个 MySQL 目标（含 unix socket）
  • 部署为容器（prom/mysqld-exporter 镜像）接入监控体系
