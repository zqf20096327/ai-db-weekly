🧭 简介解读层（AI·证据行可回查）

Percona PMM 的扩展框架，基于 Python 的应用脚手架，集成认证、任务调度与配置管理。

综述（解读层）

这是 Percona PMM Extensions 的框架代码库，为构建 PMM 相关的 Web 应用提供基础设施：Casdoor OAuth 认证、Celery 加 Nomad 的后台任务执行、会话与 CSRF 防护、数据脱敏插件等。面向需要在 PMM 环境中开发扩展应用的开发者，通过 make 命令与 .env/settings.yaml 完成安装配置。要求 Python 3.11.9 以上（3.14 以下）及 Docker、Percona Toolkit 等依赖。

  • 提供基于 Casdoor 的 OAuth 认证集成，支持通过 BaseAuthProvider 子类替换为自定义认证提供方（仅允许同时配置一个）
  • 提供 Celery 任务队列与 Nomad 任务执行集成，包含 PII 数据脱敏（anonymizer）插件，可配置脱敏实体集合
  • 提供可配置的会话管理、双提交 Cookie 的 CSRF 防护及 Content-Security-Policy 安全头设置；配置按环境变量、.env、secret 文件、settings.yaml 的优先级读取

适用场景（解读层）

  • 在 PMM 环境中开发需要认证与后台任务的扩展 Web 应用
  • 需要对任务输出中的个人信息（PII）进行脱敏处理的数据处理任务场景
  • 本地开发环境中用 Docker 启动 Casdoor、PMM、Nomad 进行框架调试与二次开发
