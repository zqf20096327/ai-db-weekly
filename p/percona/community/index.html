Percona 开源数据库社区网站仓库，基于 Hugo 生成静态页面

综述（解读层）

该仓库存放 Percona 社区网站的源码，内容涵盖社区博客、活动、Meetup 视频与 MySQL、PostgreSQL、MongoDB、PMM 等项目的贡献信息。网站由 Hugo 引擎将 Markdown 转为 HTML，托管于 GitHub Pages。外部作者可按仓库流程提交文章，也支持邮件发送 PDF/Google Doc/Markdown 格式稿件由官方代为发布。

  • 站点基于 Hugo 引擎运行，Markdown 页面转换为 HTML，使用 GitHub Pages 托管
  • 提供博客发文流程：fork 仓库、本地运行 `hugo server -D --disableFastRender` 预览、向 content/blog 提交 Markdown 文件并发起 PR
  • 接受任何数据库与开源技术相关的技术文章，无首发唯一性要求，也接受通过邮件投稿（PDF/Google Doc/Markdown）

适用场景（解读层）

  • 向 Percona 社区博客投稿技术文章或提交活动、视频链接
  • 参与 MySQL、PostgreSQL、MongoDB、PMM 等开源项目的社区贡献
  • 查阅社区 Meetup、播客（HOSS Talks FOSS）、活动与调查信息
