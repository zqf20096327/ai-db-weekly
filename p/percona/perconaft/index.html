事务型键值存储库，提供类 Berkeley DB 接口，支撑 TokuDB 引擎

综述（解读层）

PerconaFT 是一个以共享库形式发布的事务型键值存储，接口风格类似 Berkeley DB，曾用于 Percona Server/MySQL 的 TokuDB 存储引擎及 TokuMX。使用 CMake 和 C++11 编译器构建，产出 libft.so 与 libtokuportability.so。仅支持 64 位 Linux 系统，透明大页需关闭，否则无法启动。

  • 提供类似 Berkeley DB 的接口，以共享库（libft.so、libtokuportability.so）形式发布
  • 使用 CMake >= 2.8.9 构建，需要 C++11 编译器、zlib 与 jemalloc 源码
  • 使用 CTest 运行测试；locktree 与 omt 部分采用 Apache 2 许可，整体采用 GPLv2/AGPLv3

适用场景（解读层）

  • 作为存储引擎底层库集成到 MySQL/Percona Server（经 TokuDB）或 MongoDB 分发版（TokuMX）
  • 需要事务型键值存储接口的 64 位 Linux 应用开发
  • 运行基准测试或生产部署（需链接随库安装的 jemalloc）
