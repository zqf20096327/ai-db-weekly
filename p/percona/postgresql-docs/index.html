PostgreSQL 管理工具集合 Percona Distribution 的文档源码仓库

综述（解读层）

该仓库存放 Percona Distribution for PostgreSQL 的文档源文件，文档用 Markdown 编写并通过 MkDocs 生成。发行版本身包含 Percona Server for PostgreSQL 及一组扩展，用于管理 PostgreSQL 数据库系统；Percona Server 与上游二进制兼容、可互相迁移，并暴露 SMGR 与 WAL 读写 API。适合使用该发行版并查阅或贡献文档的用户。

  • 包含 Percona Server for PostgreSQL 及多个扩展，用于管理 PostgreSQL 数据库系统
  • Percona Server 与上游 PostgreSQL 二进制兼容、功能一致，可相互迁移
  • 在上游基础上暴露 SMGR API 和 WAL 读写 API，供扩展集成

适用场景（解读层）

  • 查阅 Percona Distribution for PostgreSQL 的官方文档
  • 在 PostgreSQL 社区版与 Percona Server 之间迁移部署
  • 为需要自定义存储管理器或挂钩 WAL 读写功能的扩展开发提供环境
