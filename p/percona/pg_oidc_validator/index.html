面向 PostgreSQL 18 的 OIDC/OAuth 令牌验证库

综述（解读层）

pg_oidc_validator 是用于 PostgreSQL 18 的 OAuth 验证库，验证符合 OIDC 规范的提供方签发的 JWT 访问令牌。管理员通过 postgresql.conf 启用该库并在 pg_hba.conf 配置 oauth 认证条目后，客户端可用含 oauth_issuer 参数的连接串登录。需 C++23 编译器构建；提供 authn_field 用于指定 JWT 中做用户映射的字段，默认为 sub。

  • 支持大多数实现 OIDC 并以 JWT 作为访问令牌的提供方
  • 提供 pg_oidc_validator.authn_field 变量，可在 sub 之外指定 email 等字段做身份映射
  • 提供 discovery_url_override 变量，可覆盖与 OIDC 提供方通信的 URL

适用场景（解读层）

  • 为 PostgreSQL 18 接入 Keycloak、Microsoft Entra ID 等 OIDC 提供方做客户端认证
  • 通过 JWT 中的 claim（如 email）将外部用户映射到数据库角色
  • 使用 OAuth 设备流在 psql 等命令行工具中连接数据库
