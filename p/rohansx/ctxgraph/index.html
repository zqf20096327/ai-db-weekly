🧭 简介解读层（AI·证据行可回查）

单二进制 Rust 知识图谱引擎，为 AI 代理提供本地优先的类型化上下文存储。

综述（解读层）

ctxgraph 是用 Rust 编写的类型化知识图谱引擎，面向 AI 代理与团队，把日志文本抽取为实体和关系，存入单个 SQLite 文件。写入路径采用分层抽取（本地 ONNX 模型优先，LLM 兜底），读取路径对约 90% 的查询用 SQL 完成、不调用 LLM。提供 local-only、cloud-fallback、cloud-quality 三种模式，可通过配置强制禁用云端调用。安装支持 Homebrew 预编译二进制或 cargo 源码编译，需要 Rust 1.85+。

  • 写入每条记录最多一次 LLM 调用，分层升级：本地 ONNX（GLiNER2，CPU 约 30ms）处理大部分条目，本地 LLM 次之，仅在前两者失败时调用云端
  • 通用模式包含 9 种实体类型和 10 种关系类型，无需用户编写 schema；约 90% 的读取查询通过本地 SQL 完成，不调用 LLM
  • 提供 CLI（init/log/query/entities/stats 等）、MCP 服务器（6 个工具，对接 Claude Code/Cursor/Cline）和 Rust SDK，支持双时态边与 FTS5+语义+图谱融合搜索

适用场景（解读层）

  • 在本地或离线环境记录团队决策与事件，并以自然语言查询因果和先后关系
  • 通过 MCP 服务器将知识图谱读写能力接入 Claude Code、Cursor、Cline 等代理工具
  • 对隐私敏感数据使用 local-only 模式，全程不产生云端 LLM 调用
