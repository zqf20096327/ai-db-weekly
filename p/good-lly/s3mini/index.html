零依赖的 TypeScript S3 客户端，运行于 Node、Bun 与边缘平台

综述（解读层）

s3mini 是一个约 20 KB（minified）的 TypeScript S3 兼容对象存储客户端，零依赖，运行于 Node.js、Bun、Cloudflare Workers 等边缘平台，不支持浏览器环境。提供 put/get/list/delete、服务端复制、条件请求、预签名 URL、SSE-C 加密头与自动分片上传；安装方式为 npm/yarn/pnpm install s3mini，凭据通过 .env 环境变量配置。

  • 零依赖 TypeScript ES 模块，支持 tree-shaking 并附带类型定义
  • 实现 AWS SigV4 签名、预签名 URL、SSE-C 请求头与 multipart 上传（默认 8MB 分片、4 并发、3 次指数退避重试）
  • 提供 putAnyObject 自动在单请求与分片上传间切换，及手动分片上传、进度控制与中止接口

适用场景（解读层）

  • 在 Cloudflare Workers 等边缘运行时中读写 S3 兼容对象存储（R2、B2、MinIO、Garage 等）
  • 为无凭据的 HTTP 客户端生成有时限的上传/下载预签名 URL
  • 大文件的分片上传、断点控制与孤儿上传清理
