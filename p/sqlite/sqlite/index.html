SQLite 数据库引擎源码仓库，含自 2000 年起的完整源码与构建脚本

综述（解读层）

该仓库是 SQLite 数据库引擎源码树的 Git 镜像，官方权威版本由 Fossil 分布式版本控制系统管理，check-in 名称与 Git 命名不一致。源码属公有领域，因此通常不接受 pull request。支持 configure/make 或 MSVC 构建 sqlite3 CLI 与 amalgamation 文件 sqlite3.c，部分测试目标需 TCL 8.6+。适合需要从源码编译或审阅 SQLite 实现的开发者。

  • 包含自 2000-05-29 起的 SQLite 完整源代码、部分测试与文档
  • 支持 Unix（configure + make）和 Windows MSVC（make.bat/Makefile.msc）构建，可生成 sqlite3、sqlite3.c（amalgamation）与 sqldiff
  • 源码处于公有领域；src/、test/、tool/、ext/、doc/ 目录分别存放核心源码、TCL 测试脚本、构建工具（含 Lemon 解析器生成器）及扩展如 FTS5、RTREE

适用场景（解读层）

  • 需要自行从源码编译 SQLite 命令行工具、sqlite3.c amalgamation 或 sqldiff 的开发者
  • 通过 Fossil 或镜像获取指定历史版本源码，并依据 manifest.uuid 核对官方 check-in 名称、验证代码完整性
  • 需要构建带 FTS5、RTREE 等扩展的 SQLite 或使用 tclextension-install 安装 TCL 扩展并运行 test/releasetest 的场景
