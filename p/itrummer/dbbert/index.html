DB-BERT：从文本中提取调参提示并用强化学习优化数据库参数的工具

综述（解读层）

DB-BERT 通过自然语言分析从文本（如文档集合）中提取数据库参数调优提示，再用强化学习针对给定工作负载和性能指标优化参数设置，支持 PostgreSQL 和 MySQL。用户需提供目标机器的内存、磁盘、核心数及工作负载 SQL 文件，通过 CLI 或 Streamlit GUI 运行。运行依赖数据库重启命令，建议配置 recover_cmd 以便在服务器无法重启时重置配置。

  • 通过自然语言分析从文本中提取参数调优提示
  • 使用强化学习针对给定工作负载和性能指标优化数据库参数设置
  • 支持 PostgreSQL 和 MySQL，提供 CLI 和 Streamlit GUI 两种使用方式

适用场景（解读层）

  • 为 PostgreSQL/MySQL 实例针对特定 SQL 工作负载自动调整参数配置
  • 将手册、文档等文本作为提示来源辅助数据库调优
  • 在 EC2 GPU 实例等环境中运行调优实验并生成性能与配置结果文件
