基于 Deno KV 实现 MongoDB 兼容 API 的 TypeScript 文档数据库层。

综述（解读层）

Dengo 在 Deno 内置 KV 存储之上实现一组 MongoDB 兼容接口，提供 find/insert/update/delete、聚合、投影、排序、skip/limit 等集合方法，支持比较、逻辑、元素、数组类查询操作符及多种更新操作符，并提供单字段、复合、唯一与稀疏索引。适用于使用 Deno 或 Deno Deploy 的开发者，也可作为本地开发测试中 mongodb-driver 的内存替代。性能对比文档尚未完成（TO DO），MIT 协议发布。

  • 实现 find、update、delete、聚合等 MongoDB 风格集合方法，支持 $eq/$or/$elemMatch/$push 等查询与更新操作符
  • 基于 Deno.openKv() 运行，无外部存储依赖，支持投影、sort、skip、limit、upsert 等选项
  • 提供 createIndex/dropIndex/listIndexes，支持单字段、复合、唯一约束与稀疏索引，集合支持 TypeScript 泛型

适用场景（解读层）

  • 在 Deno 或 Deno Deploy 边缘/无服务器环境中使用 MongoDB 风格查询读写文档数据
  • 本地开发与测试中作为 mongodb-driver 的内存替代
  • 需要唯一约束或复合索引的 Deno KV 文档存储场景
