C++17 编写的 SQLite 封装库，支持用 lambda 创建 SQL 函数

综述（解读层）

sqlite3cpp 是 SQLite 的 C++17 封装库，面向需要在 SQL 中调用 C/C++ 函数的开发者。它根据 lambda 或仿函数的原型自动生成 SQL 标量函数与聚合函数的包装，并提供带类型参数绑定的 range-based for 查询和 RAII 事务。可通过 CMake 构建，依赖兼容 C++17 的编译器（VS 2017、clang 6.0+ 或 gcc 7.0+）；其映射类可通过 get() 获取底层 sqlite3 结构以调用原生函数。

  • 根据 lambda 或自由函数原型自动生成 SQL 标量函数与聚合函数包装，无需手写函数原型
  • 支持 range-based for 循环查询与类型化参数绑定
  • 提供 RAII 事务对象，并可附加到已有的 sqlite3 原生实例；映射类可通过 get() 获取底层 sqlite3 指针

适用场景（解读层）

  • 需要将 C++ 函数注册为 SQL 标量函数或聚合函数并在查询中调用
  • 在 C++17 项目中以绑定参数和 range-based for 方式执行 SQLite 查询
  • 已有 sqlite3 原生代码，需要在其上附加 C++ 封装并混合调用原生 API
