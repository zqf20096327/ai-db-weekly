基于 JDBC API 的简单数据库分片中间件

综述（解读层）

Simple-Sharding 是基于 JDBC API 实现的数据库分片中间件，应用程序通过替换 DataSource 即可接入分片能力。它提供逻辑数据源到物理数据源的映射、单库内事务支持及 SQL 改写规则，可通过 Spring 自定义命名空间配置，并兼容 JDBC API 或 MyBatis 等 ORM 框架。项目尚未完成，README 明确说明适合用于学习研究；安装需克隆源码并执行 mvn clean install 到本地仓库。

  • 基于 JDBC API，通过替换 DataSource 接入分片
  • 支持单库分片内事务与 SQL 改写规则
  • 提供 Spring 自定义命名空间配置

适用场景（解读层）

  • 需要学习数据库分片中间件实现原理的场景
  • 通过 JDBC API 或 MyBatis 访问分片数据库的应用
  • 使用 Spring 配置数据源并需要逻辑/物理数据源映射的项目
