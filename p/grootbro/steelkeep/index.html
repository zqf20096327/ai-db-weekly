自托管数据库备份与恢复平台，支持八种数据库引擎并提供 MCP 访问

综述（解读层）

Steelkeep 是一个自托管的数据库备份与恢复系统，支持 PostgreSQL、MySQL、MariaDB、MongoDB、SQLite、Redis、ClickHouse 和 SQL Server 八种引擎，提供 Web 控制台、REST API 和 MCP 接口。基于 TypeScript、TanStack Start、Elysia 与 Bun 构建，存档写入 S3 兼容存储，恢复前需经空目标审查并校验 SHA-256。项目处于 alpha 阶段，存档上限 2 GiB，各引擎配置有版本与一致性限制。

  • 支持八种数据库引擎的备份计划、快照检查（大小、SHA-256、可用性检查）与保留策略
  • 提供原生 MCP 服务器（/mcp）、REST API（/api/v1）与 OpenAPI 文档；AI 代理令牌默认只读、24 小时过期、可撤销且含子代理
  • 恢复流程要求写入前校验 SHA-256、绑定空目标审查，未知结果不自动重放

适用场景（解读层）

  • 在自有基础设施上对多种数据库实施定时备份与人工审查后的恢复
  • 通过 MCP 客户端以受限作用域的代理令牌让 AI 代理执行备份、恢复等操作
  • 需要通过 REST API 或脚本集成备份任务的运维场景
