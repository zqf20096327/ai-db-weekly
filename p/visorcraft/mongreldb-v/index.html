🧭 简介解读层（AI·证据行可回查）

MongrelDB 的纯 V 语言客户端，通过 HTTP 提供 SQL、向量与全文检索访问。

综述（解读层）

该项目是 MongrelDB 服务器的 V 语言客户端，仅依赖标准库 net.http，API 与官方 PHP、Go 客户端保持一致。它提供类型化 CRUD、批处理事务、原生查询构建器、SQL 执行与历史版本保留管理，使用前需运行 mongreldb-server 守护进程，并要求 V 周更版本以使用 x.json2 类型化 JSON。适用于在 V 项目中以文件拷贝或 git 子模块方式引入使用。

  • 提供类型化 CRUD、幂等批处理事务与原子提交，提交时由服务端强制唯一、外键和 check 约束
  • 查询构建器支持将条件下推至位图索引、FM-index 全文检索和 HNSW 向量相似度等专用索引
  • 通过 /sql 端点执行 SQL，支持递归 CTE、窗口函数、物化视图与多语句执行

适用场景（解读层）

  • 在 V 语言项目中访问 MongrelDB 服务器的 SQL、向量搜索与全文检索能力
  • 需要原子批量写入、幂健重试和约束校验的数据事务场景
  • 配置 ANN 索引后端（hnsw/diskann/ivf）与量化选项以执行向量相似度查询
📖 README 首段存档原文 · 程序抽取

No external dependencies - built on the standard library net.http. The API mirrors the MongrelDB PHP and Go clients.
