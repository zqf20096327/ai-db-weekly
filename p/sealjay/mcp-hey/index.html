本地运行的 MCP 服务器，让 Claude 等 MCP 客户端读写和管理 Hey.com 邮箱。

综述（解读层）

mcp-hey 是一个本地运行的 MCP 服务器，为 Claude Code、Claude Desktop、Cursor 等 MCP 客户端提供对 Hey.com 邮箱的读写访问，包含 37 个工具，覆盖读信、发信、草稿、标签、分拣和搜索。它通过浏览器一致的请求调用 Hey 的非官方 Web 端点，使用 Bun/TypeScript 实现，经 stdio 通信；登录由 Python 助手在系统 webview 中完成，仅保存权限为 600 的会话 cookie，用本地 SQLite 缓存邮件并支持全文搜索。依赖 Bun 1.1+ 与 Python 3.10+，因 Hey 无公开 API，接口可能随时失效，且仅支持英文界面与单账户。

  • 提供 37 个工具，覆盖邮件读取、发送、草稿、标签、Collections、分拣、Screener 与搜索
  • 会话 cookie 以 mode 600 本地保存，无云中转、无遥测；请求先获取 CSRF token 并按 x-ratelimit 退避
  • 本地 SQLite 缓存邮件、会话与全文搜索；支持 Docker 运行

适用场景（解读层）

  • 在 Claude 等 MCP 客户端中通过对话读取、搜索和回复 Hey.com 邮件
  • 对邮件执行分拣操作：Set Aside、Reply Later、贴标签、Screen 发件人
  • 本地运行、不外置凭据的 Hey.com 邮箱自动化处理场景
