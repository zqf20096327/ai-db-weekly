🧭 简介解读层（AI·证据行可回查）

嵌入式 SQLite 任务状态对账工具，按截止时间与宽限期收敛重启后遗留的卡住任务状态

综述（解读层）

TaskStateGuard 用本地 SQLite 保存任务生命周期与投递状态两套独立状态机，供 AI 智能体运行时、后台 worker 和本地工作流在重启或超时后对账：超时任务转为 timed_out，投递状态仅在收到真实回执后才标记 delivered。它不是队列、调度器，不续跑计算，不保证恰好一次执行；收敛仅由调用方执行 reconcile 触发，无后台进程。

  • reconcile 支持 --dry-run 只读预览，返回将收敛的聚合计数而不修改任务、事件或数据库
  • doctor 健康检查覆盖数据库、schema、状态语义、时间戳与事件链，仅输出汇总数字，健康时退出码为 0
  • 运行时仅依赖 Python 标准库（支持 CPython 3.11–3.14），不含网络请求或遥测，数据库不保存提示词或任务正文

适用场景（解读层）

  • 智能体或 worker 服务重启后识别失联任务并核对超时与待投递状态
  • 需要将任务终态与结果投递状态分开管理的本地工作流
  • 在不记录提示词与任务正文的前提下增加工作流可观测性
