基于 FastAPI+React+RAG 的 MySQL/Oracle 迁移 OceanBase 评估工具

综述（解读层）

该项目是一个前后端分离的迁移评估工具：后端用 FastAPI 加载本地离线 Qwen 大模型、bge-m3 Embedding 与可选 LoRA 权重，结合 ChromaDB 向量知识库提供 SQL 兼容性评估、知识库问答与文档管理；前端基于 React 18 + Ant Design 提供工作台、SQL 评估、对话等页面。适用于准备将 MySQL/Oracle 应用迁移到 OceanBase 的开发与运维人员，需本地自备模型文件。

  • 提供 SQL 解析、静态规则检查与迁移建议，识别 MySQL/Oracle SQL 迁移 OceanBase 的高风险语法
  • 实现本地文档切片、向量检索（ChromaDB + bge-m3）与基于知识库的多轮对话问答，回答附来源
  • 支持模型目录、RAG 参数、端口、CORS 等配置通过 backend/.env 统一管理，知识库文档本地持久化

适用场景（解读层）

  • 迁移前对存量 MySQL/Oracle SQL 进行兼容性与风险静态评估
  • 将迁移手册、FAQ、排错指南等文档入库，供团队进行带来源引用的知识库问答
  • 离线内网环境部署迁移辅助工具，不依赖在线模型下载
