基于 YAML/JSON 配置的 Python 开源 ETL 数据搬迁工具

综述（解读层）

Petaly 是一个 Python 编写的开源 ETL/ELT 命令行工具，用于在 PostgreSQL、MySQL、BigQuery、Redshift、S3、GCS 与本地 CSV 文件之间移动数据。它通过 YAML/JSON 文件定义管道，提供源到目标的 schema 评估与映射、CSV 列类型识别及目标表结构生成，适合需要配置化数据搬运流程的数据从业者使用。当前测试环境限于 Python 3.10-3.12、Linux 与 macOS，采用 Apache 2.0 许可证。

  • 支持 PostgreSQL、MySQL、BigQuery、Redshift、GCS、S3 及本地 CSV 等端点间的数据读取与写入
  • 提供源到目标 schema 评估与映射、可配置的跨数据库类型映射及目标表结构生成
  • 通过 YAML/JSON 配置管道，CLI 支持 init/run 命令及 --source_only 等分步操作；另有一个基于自然语言提示运行管道的实验性 AI Agent 分支

适用场景（解读层）

  • 在云仓库（BigQuery、Redshift）与关系数据库之间批量卸载/加载全表数据（CSV 格式）
  • 将本地 CSV 文件按识别的列类型加载到 PostgreSQL、MySQL 等数据库
  • 通过 YAML/JSON 配置文件统一管理多条数据管道的定时或手动执行
