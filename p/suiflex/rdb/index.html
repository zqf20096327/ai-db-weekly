基于 Rust 与 Slint 的原生跨平台数据库管理桌面应用

综述（解读层）

RDB 是一个用 Rust 和 Slint 编写的桌面数据库管理工具，支持 PostgreSQL、MySQL、Redis、MongoDB、SQLite、Oracle、ClickHouse 等 12 种引擎，UI 通过 GPU 渲染，不依赖 webview 或 Electron 运行时。面向需要多引擎管理的开发者，提供标签页查询编辑器、架构树、DSN 导入和 MCP 服务器；MCP 模式默认拒绝连接访问、单次查询最多返回 500 行。

  • 单一应用连接 12 种数据库引擎，通过 tokio 异步运行时处理所有 I/O
  • UI 由 Slint GPU 渲染，不含 webview、Chromium 或 Electron
  • 内置 CLI 与 MCP 服务器（rdb-cli / rdb-mcp），连接与数据库访问默认拒绝，查询响应最多 500 行

适用场景（解读层）

  • 在同一桌面应用中管理多种 SQL、NoSQL 与键值数据库连接
  • 通过 MCP 服务器向 AI 代理提供范围受限的数据库只读或读写访问
  • 使用标签页编辑器执行各引擎语法的查询并客户端过滤结果
📖 README 首段存档原文 · 程序抽取

A native, lightweight, cross-platform database manager built with Rust and Slint — in the spirit of TablePlus but compiled from a single codebase for macOS and Linux.
