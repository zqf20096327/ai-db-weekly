🧭 简介解读层（AI·证据行可回查）

GaussDB SQL 格式化 VSCode 插件，离线单文件安装，支持逗号前导与注释对齐

综述（解读层）

这是一个面向 GaussDB（兼容 PostgreSQL 语法）的 VSCode 离线 SQL 格式化插件，以单个 .vsix 文件导入即用，无需联网或运行时依赖。支持逗号前导列表、关键字大小写、block/aligned 两种排版风格，并承诺格式化不改变 SQL 内容（除关键字大小写外），该保证由自动化测试与模糊变异脚本验证。适用于内网离线环境中的 GaussDB SQL 开发者。已知限制包括超长表达式不二次折行等。

  • 支持 @ 行、${} 参数、字符串、注释、美元引号等内容原样保留，并以 @ 行作为语句级分隔符
  • 提供 block 与 aligned 两种子句排版风格，可配置关键字大小写、缩进宽度、最大行宽与拆行模式
  • 提供内容守恒验证脚本，覆盖测试用例、样例一致性、边界输入与随机变异

适用场景（解读层）

  • 内网或离线环境中使用 VSCode 编写 GaussDB SQL 的日常格式化
  • 需要在保存时自动格式化 SQL 文件的工作流
  • 使用逗号前导风格和行尾注释对齐规范的团队统一 SQL 排版
