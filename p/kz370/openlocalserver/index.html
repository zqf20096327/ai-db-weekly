Windows 本地开发环境管理器，集运行时、站点、数据库与受信 HTTPS 于一体

综述（解读层）

OLS 是面向 Windows 的本地开发环境管理器，通过一个核心引擎 ols-core 同时提供桌面 GUI、CLI、MCP 服务器和本地 HTTP API 四种接口。站点、数据库与运行时按项目隔离，各站点可绑定本地域名并使用内置 CA 签发的受信 HTTPS 证书。第三方运行时与数据库不随安装包附带，按需下载或注册本机已有安装。

  • 一个核心引擎驱动桌面 GUI、CLI（olsc）、Stdio MCP 服务器（供 Claude Desktop、Cursor 等调用）与本地 JSON API（127.0.0.1:7420）四种接口
  • 支持 PHP、Node.js、Python 运行时多版本并存，可通过 Nginx/Apache/Caddy 托管站点，下载含 SHA-256 校验并支持手动离线安装
  • 内置设备端 CA 生成受信本地 HTTPS 证书，支持任意域名与通配符子域名；另有 Docker/Compose 管理与隧道分享功能

适用场景（解读层）

  • 在 Windows 上为多个项目配置隔离的 PHP/Node/Python 运行时与本地域名站点
  • 让 AI 编码助手通过 MCP 协议检查和操作本地开发环境
  • 管理本机 Docker 容器与 Compose 项目，或将本地站点通过隧道对外分享
