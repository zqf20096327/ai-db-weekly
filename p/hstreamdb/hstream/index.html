综述（解读层）

HStreamDB 是一个开源的云原生流数据库，主要面向 IoT 等实时应用场景。它提供流订阅推送、基于 SQL 的流处理（过滤、转换、时间窗口聚合、多流连接）、物化视图实时查询，存储层基于 LogDevice，采用存算分离架构并支持 Paxos 复制。用户可通过 Docker 快速启动本地服务，使用交互式 CLI 创建流和运行连续查询。

  • 支持基于 SQL 的流处理，包括过滤、转换、多类时间窗口聚合和多流连接
  • 基于 LogDevice 的持久化存储，采用存算分离架构，计算与存储层可独立扩展
  • 通过连接器与 MQTT Broker、MySQL、Redis、ElasticSearch 等外部系统集成

适用场景（解读层）

  • IoT 设备数据的实时写入、订阅与推送
  • 需要实时统计和聚合分析的流数据处理
  • 基于增量维护物化视图的实时查询应用
