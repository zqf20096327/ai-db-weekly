综述（解读层）

Querya Desktop 是一个开源桌面数据库管理工具，使用 Flutter 和 Dart 构建，运行于 Linux、Windows 和 macOS。它支持 PostgreSQL、MySQL/MariaDB、SQLite、Redis 和 MongoDB，提供虚拟化数据网格、DML 暂存缓冲、多标签独立会话和 JSON-RPC 驱动扩展机制。凭据存储依赖系统原生密钥库，Linux 需安装 libsecret-1。

  • 提供 2D 虚拟化数据网格，仅渲染可见单元格，排序和过滤在后台 isolate 执行
  • 实现 DML 暂存缓冲：单元格编辑生成 UPDATE/INSERT/DELETE 语句，可在执行前审查并提交或回滚
  • 连接凭据委托给操作系统原生密钥库（Keyring/Keychain/DPAPI），README 声明不含遥测

适用场景（解读层）

  • 需要在统一客户端中同时管理 SQL 与 NoSQL 数据库的开发者
  • 浏览和编辑大表数据并需要生成、审查 DML 语句的场景
  • 离线或内网环境中管理数据库凭据与查询
