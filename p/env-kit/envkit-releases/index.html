综述（解读层）

EnvKit 是一款面向 Windows 和 macOS 的免费本地开发环境桌面应用，通过托盘程序以原生进程方式运行 nginx/Apache/Caddy/FrankenPHP、多版本 PHP、Node.js 及 MySQL、PostgreSQL、Redis、MongoDB 等服务，无需 Docker 或 WSL。首次运行向导自动完成站点创建并通过本地 CA 提供 .test 域名的可信 HTTPS。注意：该项目免费使用但非开源，Windows 构建目前为自签名，安装时可能触发 SmartScreen 提示。

  • 支持每站点独立的 PHP 版本，并可按版本号安装自定义版本的 MySQL、nginx、Node.js、MongoDB 等组件
  • 内置 MCP 服务器，可注册到 Claude Code、Cursor、VS Code 等 AI 客户端以控制本地服务栈，默认关闭且仅监听 127.0.0.1
  • 提供一键服务、数据库管理工具（phpMyAdmin、Adminer、pgAdmin）、Mailpit 邮件捕获、Cron 定时任务与每站点 Git 面板

适用场景（解读层）

  • 在 Windows 或 macOS 上本地运行 PHP（Laravel、WordPress 等）或 Node.js 项目，需要 .test 域名与可信 HTTPS
  • 从 Laragon 迁移项目和数据库到新工具
  • 需要在本机同时运行多个数据库、缓存和搜索服务并进行调试、日志查看和定时任务管理
