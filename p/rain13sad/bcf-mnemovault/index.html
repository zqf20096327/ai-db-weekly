🧭 简介解读层（AI·证据行可回查）

LLM 情感感知记忆引擎，以稀疏编码单元存储记忆并四通道注入召回

综述（解读层）

MnemoVault 是面向 LLM 的持久化记忆插件，将记忆存为固定大小单元（稀疏码、int8 向量、类型化超边）而非文本，每轮注入约 117 tokens。可独立运行或作为 DeepSeek Harness 插件，由 11 个 TypeScript 包构成，运行时除 @deepseek-ai/* 外无第三方依赖。当前为 v0.7.3 开发者预览，中文文档为权威版本，README 列出 28 项已知弱点。

  • 记忆以固定大小单元存储：稀疏码、int8 向量、类型化超边与压缩残差，每轮注入约 117 tokens
  • 包含情感感知内核、四通道召回、评分式遗忘机制与 3D 星图可视化
  • 377 个测试，运行时无第三方依赖（仅 schemastery 用于配置 schema），提供 Prometheus 指标、导出/备份/审计等运维工具

适用场景（解读层）

  • 为基于 DeepSeek Harness 或独立运行的 LLM 应用提供跨轮持久记忆
  • 多会话隔离场景（scopeMode: per-session）下的用户记忆管理
  • 需要情感感知、PII 标记与危机检测机制检查的智能体记忆层
