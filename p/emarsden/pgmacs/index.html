基于 pg.el 在 Emacs 中浏览和编辑 PostgreSQL 数据库的界面

综述（解读层）

PGmacs 为 Emacs 提供 PostgreSQL 数据库的编辑界面，可浏览表列表与行内容、修改列值、插入和删除行、复制粘贴行、导出 CSV/TSV/JSON。通过键位在小缓冲区或 widget 缓冲区中编辑，支持外键跳转与大表分页。需 Emacs 29 及以上，基于 pg-el 通信，当前为 beta 状态， GPL v3 许可。

  • 支持在终端（TUI）和图形界面两种模式下运行
  • 支持通过连接字符串、连接 URI 或 pg.el 连接对象打开数据库
  • 可对 PostgreSQL 兼容数据库进行有限支持，兼容性取决于 wire 协议、SQL 方言和系统表实现

适用场景（解读层）

  • 在 Emacs 环境中直接浏览和修改 PostgreSQL 表数据
  • 需要将表内容导出为 CSV/TSV 或行导出为 JSON 的场景
  • 对 Neon、TimescaleDB、AlloyDB Omni 等 PostgreSQL 兼容数据库进行管理操作
