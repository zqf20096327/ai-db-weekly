PM2 模块，自动采集 MongoDB 关键运行指标

综述（解读层）

pm2-mongodb 是一个 PM2 模块，通过 `pm2 install` 安装后自动采集 MongoDB 的查询、连接数、内存占用、网络流量及副本集状态等指标。使用者需在配置中提供可访问 admin 数据库的账号，默认连接本机 27017 端口，刷新间隔等参数通过 `pm2 set` 命令设置，采用 MIT 许可证发布。

  • 采集查询、插入、更新、删除操作及连接数、内存占用、网络收发速度指标
  • 提供副本集名称与状态信息
  • 支持配置 MongoDB 地址、认证凭据及刷新间隔，默认每 5000 毫秒刷新

适用场景（解读层）

  • 通过 PM2 管理进程的环境中监控 MongoDB 运行状态
  • 查看 MongoDB 的查询量、连接数、内存与网络流量等统计信息
  • 需要跟踪副本集名称与状态的部署
