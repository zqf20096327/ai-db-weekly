🧭 简介解读层（AI·证据行可回查）

自托管的地理空间数据目录与地图构建工具，支持语义搜索与来源追踪

综述（解读层）

GeoLens 是一个自托管的地理空间数据目录与地图构建工具，面向空间数据分散在文件共享、PostGIS 数据库、Web 服务和 STAC 目录中的团队。它将数据汇集到可搜索目录，记录每个数据集来源并检查上游源是否仍然可用；支持 OGC API 与 STAC 标准供 QGIS、脚本和 AI 客户端读取。默认不发送遥测数据，基于 Docker Compose 部署。

  • 支持上传 Shapefile、GeoPackage、GeoParquet、GeoTIFF 等多种格式，GeoTIFF 转换为 Cloud-Optimized GeoTIFF，并可托管 3D Tiles 与 COPC 点云
  • 提供 OGC API Features（含 CQL2 过滤）、OGC API Records、STAC API 1.0 及 DCAT 系列输出，每个图层带瓦片 URL，可导出 GeoJSON、GeoPackage、PMTiles 等格式
  • 记录数据集来源并跟踪刷新状态（fresh/due/overdue），检测上游 schema 变化，服务消失后本地副本仍可用；内置模糊搜索与配置嵌入模型后的语义搜索

适用场景（解读层）

  • 团队需要整合分散在文件共享、数据库、WFS/ArcGIS 服务和 STAC 目录中的空间数据并统一检索
  • 通过 OGC API Features、STAC、DCAT 端点向 QGIS、GDAL/OGR、开放数据门户或 AI 代理提供数据访问
  • 在浏览器中构建和共享地图、故事地图与仪表盘，或通过 CLI 与 SDK 发布数据集
