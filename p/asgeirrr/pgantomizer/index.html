基于 YAML 规则对 PostgreSQL 数据进行匿名化处理的 Python 工具

综述（解读层）

pgantomizer 是一个 Python 命令行工具和库，用于匿名化 PostgreSQL 数据库中的数据，适用于需要向无权访问个人信息的第三方提供数据的场景。规则写在单一 YAML 文件中，采用白名单机制——仅显式标记 raw 的列保留原样，其余列按数据类型自动匿名化；支持 custom_rules 指定匿名化函数、truncate 截断表和 where 限定范围。处理流程为 pg_dump 导出、加载到目标实例、匿名化后默认删除 dump 文件。

  • 通过单一 YAML 文件定义匿名化规则，未在 raw 中显式标记的列默认匿名化
  • 提供 aggregate_length、clear、example_email、md5、x_out 等匿名化函数，并支持通过 value 键直接指定替换值
  • 提供 pgantomizer_dump 和 pgantomizer 命令行工具及 dump_db、load_anonymize_remove、anonymize_db Python 函数，连接参数可经命令行或环境变量传入

适用场景（解读层）

  • 向不应访问用户个人信息的第三方提供脱敏数据副本
  • 将数据导入无法保证数据处理方式的第三方工具前进行匿名化
  • 需要保留部分原始列（通过 raw 标记）或截断特定表（truncate）的数据交付流程
