Rust 编写的 Debian 多节点托管控制面板

综述（解读层）

Hyperion 是面向 Debian 12/13 的自托管主机控制面板，用 Rust 编写并声明 forbid(unsafe_code)。主节点运行 Web UI，每个节点运行 agent，通过签名 RPC 组成集群。它以事务方式创建站点（Linux 用户、nginx vhost、PHP-FPM 池、数据库、TLS），失败即回滚，并提供 HTTP API（/api/v1）与 CLI（hctl）。支持从 HestiaCP、CloudPanel 导入。项目自述尚处早期，多节点路径使用较少。

  • 主节点 + N 个 worker 的多节点架构，节点间使用签名 RPC；站点配置在单一事务内完成，任一步失败即回滚
  • 提供 OpenAPI 风格的 /api/v1 HTTP API、hctl CLI、后台作业实时进度页，以及基于 BLAKE3 哈希链的防篡改审计日志
  • 支持 PHP 8.1–8.4 并存、Let's Encrypt HTTP-01/DNS-01 证书与自动续期、内核级磁盘配额、S3（age 加密）及 FTP/FTPS/SFTP 异地备份

适用场景（解读层）

  • 在自有 Debian 服务器上为多个站点（WordPress、PHP、静态站、反向代理）配置运行环境并通过 Web UI/API/CLI 日常管理
  • 管理多台服务器组成的集群，在节点间创建、迁移站点并查看各节点指标
  • 从 HestiaCP 或 CloudPanel 迁移现有主机到该面板，或对 WordPress 站点执行更新、备份与文件完整性扫描
