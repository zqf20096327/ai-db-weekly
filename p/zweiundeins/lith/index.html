🧭 简介解读层（AI·证据行可回查）

用于 Go、SQLite 和 Datastar 应用的运行时，提供线性写入、即时模式渲染与 SSE 推送。

综述（解读层）

lith 是由 zwei und eins gmbh 开发的 Go 运行时库，用于构建 SQLite + Datastar 的超媒体应用。核心机制包括：单一写入者按序批量提交命令、view=f(state) 的整体渲染加 morph 更新、commit 触发的 tick 渲染循环，以及按流压缩的 SSE 帧。路由交给 net/http、模板交给 templ，纯 Go 构建，CGO_ENABLED=0。默认 synchronous=NORMAL，断电可能丢失约 35 秒内的提交，需要时可设为 FULL。

  • 单一写入者将命令按序批量进一个事务，每命令带 savepoint，支持 Once 重试与 Exclusive 批间操作
  • live 包按 tick 渲染：提交使视图标记脏，每个变更视图对全部观看者每 tick 渲染一次，支持 Depends 依赖声明与 Seq/Version 缓存编号
  • SSE 每流独立 zstd/brotli/gzip 压缩，带内存预算、每客户端流上限；sqlite 包提供 query_only 读池、user_version 迁移与 VACUUM INTO 备份

适用场景（解读层）

  • 需要多客户端实时同步页面状态的 Go 超媒体应用（如 README 中的看板示例）
  • 以 SQLite 为存储、事件溯源为写入模型的单二进制 Web 服务
  • 用 lith-new 模板快速启动带测试、CI、systemd、Caddy 与备份脚本的新项目
