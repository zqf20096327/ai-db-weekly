🧭 简介解读层（AI·证据行可回查）

本地优先的音频标签元数据工作流，经暂存SQLite数据库清洗、丰富并导出标签。

综述（解读层）

Tagminder 将音乐文件的标签导入暂存 SQLite 数据库，通过编号的 SQL 与 Polars 管道脚本进行清洗、规范化和丰富，记录字段级变更日志，最后由用户显式导出回音频文件。面向拥有大型本地音乐库、希望通过可审查流程批量维护元数据的用户。导入与管道处理不写入音频文件；可选接入 MusicBrainz 主数据用于作品与贡献者丰富。要求 Python 3.14+ 和 uv。

  • 将音频文件标签导入暂存 SQLite 数据库，管道仅在数据库上执行变换，导出是独立的显式步骤
  • changelog 表记录字段级变更审计，支持 `--new-files`/`--modified-files`/`--prunedb` 增量导入模式
  • 支持多目录并发导入，提供 --workers/--chunk-size 参数按磁盘类型调整并行度

适用场景（解读层）

  • 对大规模本地音乐库（FLAC 等）批量清洗和规范化标题、艺人、碟号等标签字段
  • 在写入文件前通过健康报告和变更日志审查元数据修改效果
  • 基于 MusicBrainz 主数据（作品、贡献者）对曲库进行关联丰富，人工审核后再采纳
