多智能体共享知识服务：OKF Markdown 存储，SQLite FTS5/BM25 检索

综述（解读层）

JBrain 是一个用 Rust 编写的知识服务，供多个智能体通过 HTTP、MCP 或 CLI 共享读写 OKF v0.2 Markdown 文件。检索基于 SQLite FTS5/BM25 词法匹配，不依赖嵌入或本地模型服务；写入经单一写者串行处理，带修订号防冲突和 request-id 幂等，可用 Git 记录历史并推送 GitHub 远端。每次仅允许一个服务实例持有数据目录，存储须在本地文件系统。

  • 提供 HTTP（默认 127.0.0.1:7331）、Streamable HTTP MCP 和 CLI 三种接入方式，客户端经共享 bearer token 认证
  • 检索为 BM25 词法搜索，字段权重 title 8 / description 4 / tags 3 / aliases 6 / body 1，全部词前缀 AND 匹配，无嵌入与模型
  • 支持修订冲突检测（409）、request-id 幂等重试、持久化日志崩溃恢复，可选 Git 历史与 GitHub 远端后台推送

适用场景（解读层）

  • 多个智能体进程需读写同一份结构化知识库且避免各自打开数据库的归属冲突
  • 需要跨机器多端访问同一服务 URL 的团队知识存储
  • 需要将知识以纯 Markdown 形式同步到 GitHub 仓库做备份的场景
