.NET 数据库迁移框架，用 C# 类描述并版本化数据库 schema 变更

综述（解读层）

FluentMigrator 是一个面向 .NET 的数据库迁移框架，借鉴 Ruby on Rails Migrations 的模式。开发者用 C# 类编写迁移，替代手工执行 SQL 脚本，迁移代码可纳入版本控制。类主题标签显示支持 SQL Server、MySQL、PostgreSQL、Oracle、DB2、Redshift、Snowflake 等多种数据库。最新 7.1.0 版本支持 .NET 9；包通过 NuGet 发布，预发布版本存于 Azure Artifacts。

  • 迁移以 C# 类描述，可签入版本控制系统，替代手工运行 SQL 脚本
  • 通过 NuGet 发布正式版本，CI 预发布版本存储在 Azure Artifacts 源
  • 存在第三方生态扩展，如基于 POCO 定义 schema 的 EasyMigrator、包管理器控制台生成迁移的工具等

适用场景（解读层）

  • 多环境（本地开发、测试、生产）数据库 schema 演进的统一管理
  • .NET 团队希望以 C# 代码而非 SQL 脚本方式维护迁移历史
  • 需要向多种数据库平台（MySQL、PostgreSQL、Oracle、Snowflake 等）应用 schema 变更
