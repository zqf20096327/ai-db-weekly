访问 LibSQL 数据库的纯 Java JDBC 驱动库

综述（解读层）

这是 DBeaver 团队发布的 LibSQL JDBC 驱动，供 Java 应用或依赖 JDBC API 的工具连接和管理 LibSQL 数据库。1.0.x 版本通过 HTTP API 协议通信，支持 Turso 云端与本地 LibSQL 服务器，要求 Java 17 与 Maven 构建，采用 Apache 2.0 许可，可从 Maven Central 获取。

  • 纯 Java 实现，1.0.x 版本基于 LibSQL 的 HTTP API 协议通信
  • 支持预编译语句、数据库元数据、结果集、数据类型等大部分 JDBC 特性
  • 支持 Turso 与本地 LibSQL 服务器，并提供基于 token 的认证方式

适用场景（解读层）

  • 在 DBeaver 和 CloudBeaver 中作为默认 LibSQL 驱动连接数据库
  • Java 应用通过 JDBC API 访问 Turso 托管或本地部署的 LibSQL 数据库
  • 依赖 JDBC API 的其他产品或框架接入 LibSQL

Turso LibSQL JDBC is a library for accessing and managing LibSQL databases in Java. - It is a pure Java library - Version 1.0.x uses simple HTTP API protocol for LibSQL
