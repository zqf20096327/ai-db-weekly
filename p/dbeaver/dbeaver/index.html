综述（解读层）

DBeaver 是一款面向开发者、SQL 程序员、数据库管理员和分析师的多平台数据库工具，提供模式/SQL/数据编辑器、ER 图、数据导入导出迁移、执行计划、仪表盘、SSH 隧道等功能。通过 JDBC/ODBC 连接数据库，内置 350+ 驱动，社区版基于 OSGI 含 130+ 插件，运行需 Java（发行包内置 OpenJDK 25），另有商业版扩展 NoSQL 与文件数据源支持。

  • 内置 350+ 数据库驱动，支持任何有 JDBC 或 ODBC 驱动的数据库
  • 提供模式编辑器、SQL 编辑器、ER 图、数据导出/导入/迁移、执行计划、SSH 隧道等功能
  • 内置 AI Chat 视图，社区版支持 OpenAI 与 Copilot 提供商，可生成/分析/优化 SQL

适用场景（解读层）

  • 开发和 SQL 编写：编辑、执行查询并查看执行计划
  • 数据库管理与运维：仪表盘、管理工具、代理与 SSH 隧道连接
  • 数据导出/导入/迁移与空间数据查看
