DBeaver 全系项目共用的 Maven 工具库与基础依赖仓库

综述（解读层）

该仓库为 DBeaver Community 与 CloudBeaver Community 提供公共 Maven 根模块和基础 Java 工具，包含 org.jkiss.utils、com.dbeaver.jdbc.api、com.dbeaver.rpc 三个模块，可通过 Maven 坐标 com.dbeaver.common 引入。构建时须与主仓库位于同一目录下检出。面向参与 DBeaver 系列项目开发或编写自定义 JDBC 驱动的开发者。

  • 提供根 Maven 模块，定义各项目的基础属性与依赖（如 Tycho）
  • com.dbeaver.jdbc.api 模块包含驱动、连接、语句、结果集与元数据读取的 JDBC 接口实现类，用于自定义 JDBC 驱动开发
  • com.dbeaver.rpc 提供 RPC 客户端-服务端实现，各模块均支持通过 Maven 依赖（版本 2.5.0）引入

适用场景（解读层）

  • 构建或二次开发 DBeaver Community、CloudBeaver Community 时作为依赖检出
  • 基于 com.dbeaver.jdbc.api 开发自定义 JDBC 驱动
  • 使用 org.jkiss.utils 中的 Java 工具类或 com.dbeaver.rpc 的客户端-服务端通信实现
