🧭 简介解读层（AI·证据行可回查）

Python 库，用于 SQL 语句与 MongoDB 查询字典的双向转换。

综述（解读层）

该库提供 sql_to_mongo 与 mongo_to_sql 两个函数，将 SELECT/INSERT/UPDATE/DELETE/CREATE/DROP/JOIN 等 SQL 语句转为 MongoDB 查询字典，或将含 $match、$lookup、$group 等操作符的 MongoDB 查询翻译回 SQL，输出字典或字符串而非直接执行。写操作可通过 allow_mutations 参数开关，附 CLI、查询校验与 pytest 测试套件。适合需要在 SQL 与 MongoDB 数据模型间迁移或原型验证、又不想引入完整 ORM 的开发者。

  • 支持 SQL 与 MongoDB 查询双向转换，JOIN 转为 $lookup 聚合管道
  • 覆盖 BETWEEN、LIKE、IN、IS NULL 等条件符及 COUNT/SUM/AVG/MIN/MAX 聚合函数
  • 提供 allow_mutations 开关、查询校验、CLI 与含 103 项测试的 pytest 套件

适用场景（解读层）

  • 从关系型数据库向 MongoDB 迁移时批量翻译既有 SQL 查询
  • 在两种数据库间做查询原型验证或学习查询语法对应关系
  • 工具链中需要程序化生成对方数据库的查询结构
