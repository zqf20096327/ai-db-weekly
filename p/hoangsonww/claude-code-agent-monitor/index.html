🧭 简介解读层（AI·证据行可回查）

本地运行的AI编码代理实时监控仪表盘，基于hooks与SQLite

综述（解读层）

CCAM 用于实时监控 Claude Code、Cursor 和 Codex 会话，聚合会话、代理层级、工具调用、令牌用量与成本等信息。默认绑定 127.0.0.1，不向云端传输数据。需 Node.js 22+，通过 npm run setup 安装并按提示安装对应 provider 的 hooks；支持源码、桌面应用、Docker/Kubernetes 等部署方式。

  • 通过原生 hooks 与 provider 感知的 transcript 发现，在同一仪表盘聚合 Claude Code、Cursor、Codex 会话
  • 提供会话、活动流、Kanban 视图，以及代理父子树、工具流图、编排与并发分析
  • 提供 ccam CLI 与本地 MCP server，暴露会话、事件、分析、配置等操作；支持 REST/OpenAPI、WebSocket 与 SSE

适用场景（解读层）

  • 集中查看多个 AI 编码代理的会话进度、工具调用与令牌/成本用量
  • 从仪表盘启动、续接或重新接入 Claude Code/Codex 后台运行
  • 检查 Claude Code/Codex 的 skills、hooks、MCP servers、规则与插件配置
