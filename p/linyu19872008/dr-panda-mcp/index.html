只读 MCP 服务，通过 Web 控制台注册生产组件供 AI 排障查询

综述（解读层）

DrPanda MCP 是一个面向生产排障的只读 MCP 服务，提供 39 个工具，覆盖 MySQL、MongoDB、Elasticsearch、Redis、GitLab、RabbitMQ、Kafka、CLS、Nacos、Jenkins 共 10 类组件。管理员在 Web 控制台注册目标（地址、凭据、范围），AI 客户端经 Streamable HTTP 携带 Bearer token 调用 /mcp，仅以 environment+target 名称选择查询对象，不接触主机与密码。服务本身用 Python 3.11+ 编写，可从源码或 PyPI 安装，默认监听 127.0.0.1:8111，配置存储支持 SQLite/MySQL/PostgreSQL。运行时执行只读白名单，拒绝管理命令与高成本查询，并记录审计。

  • 支持 10 类组件共 39 个只读工具，含 systems_status 状态查询与 investigate_error 排障 prompt；凭据加密存储，工具调用仅接受环境与目标名称
  • 通过连接、操作、身份三层边界限制查询：仅可达控制台注册目标、仅执行只读白名单、Web 登录与 MCP token 相互独立并逐调用审计
  • 目标可配置缩小读取范围（如 MySQL 库/表、Kafka topic/分区、GitLab 项目/分支），每个目标可附 512 字符以内的 operator_notes

适用场景（解读层）

  • 生产事故排查中让 AI 客户端同时查询数据库、日志、缓存与消息队列，凭据不出控制台
  • 需要审计每次 AI 对生产目标访问的运维团队，token 以哈希存储并按真实管理员审计
  • 多环境（如测试/生产）下按环境键隔离目标，限制 AI 可读的库表、索引或 topic 范围
