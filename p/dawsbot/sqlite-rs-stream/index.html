Rust 库形式的 Litestream 兼容 SQLite S3 复制工具

综述（解读层）

该仓库将 Litestream 的 SQLite 复制功能移植为 Rust 库，把数据库 WAL 流式写入 S3 上的 LTX 文件并支持恢复，文件格式与键布局兼容 Litestream v0.5+，双向可恢复。提供库调用和 CLI 两种用法，支持按 TXID 时间点恢复与基于条件写入的租约锁。适用于需要进程内灾备复制的 Rust 应用开发者；README 注明其为灾备工具而非分布式数据库，且尚未在真实 AWS S3 与崩溃注入场景下测试。

  • 以库形式在 Rust 进程内运行，无需独立 sidecar 二进制；兼容 Litestream v0.5+ 的文件格式与键布局，副本可被 litestream 恢复，反之亦然
  • 支持 S3、S3 兼容存储、本地目录与 memory:// 后端；支持按 TXID 时间点恢复，恢复时逐文件下载、内存占用以页为界
  • 实现 LTX 编解码（LZ4 压缩、CRC-64 校验）、k-way 压缩、按 Litestream 默认的分层压缩与保留策略，以及基于条件 PUT 的复制租约

适用场景（解读层）

  • 为 Rust 应用内嵌 SQLite 灾备复制，将 WAL 流式备份到 S3 或本地目录
  • 与 Litestream 用户互通：恢复对方写入的副本，或由对方恢复本工具写入的副本
  • 按事务 ID（TXID）进行时间点恢复，验证副本文件完整性（verify 命令）
