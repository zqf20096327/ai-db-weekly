基于 Zig 编译期类型检查的 Web 框架，函数即路由、结构体即数据表

综述（解读层）

nilo 是 Zig 语言的 HTTP Web 框架，v0.8.0 构建于 Zig 0.17。核心机制是编译期读取函数签名与结构体：普通函数成为路由，参数类型自动解析请求并生成 OpenAPI 文档；结构体映射 Postgres/SQLite 表并生成迁移。包含 13 个模块，按需导入，无需 C 库依赖，适合用 Zig 构建 HTTP、gRPC 服务的开发者。

  • 同一端口支持 HTTP/1.1、HTTP/2、gRPC 与 Connect，需开启 .http2 = true
  • 路由、SQL、OpenAPI、配置均从同一结构体读取，编译期检查列名、参数与服务注册
  • 提供 Postgres/SQLite、S3、后台任务、缓存、JWT、protobuf、argon2id 密码哈希等 13 个独立模块

适用场景（解读层）

  • 用 Zig 构建带类型检查的 REST API 或 gRPC 服务
  • 需要 OpenAPI 文档随代码自动生成的后端项目
  • 希望编译期捕获 SQL 列拼写、路由参数等错误的数据库应用开发
