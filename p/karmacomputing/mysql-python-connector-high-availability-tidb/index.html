演示 mysql-connector-python 连接 TiDB 实现故障转移的示例项目

综述（解读层）

该项目提供在 Python 中使用 mysql-connector-python 对 TiDB 节点做连接故障转移的示例代码与测试记录。作者用至少 3 个节点随机重启模拟宕机，验证初始连接阶段的 failover 行为。README 记录了故障转移仅在 connect 调用时尝试备用主机、需重建连接等实测限制，适合需要评估该方案可用性的运维与开发人员参考。

  • 提供随机重启节点模拟宕机的故障转移测试方法
  • 记录 mysql/connector 的 failover 仅在初始连接阶段生效，需通过 mysql.connector.connect 重建连接
  • 包含单节点宕机（约 1 秒内切换）与全部节点宕机（约 30 秒恢复）的实测输出示例

适用场景（解读层）

  • 评估 mysql-connector-python 的 failover 机制在 TiDB 环境下的行为
  • 为需要多 MySQL/TiDB 节点连接的应用编写 Python 故障转移逻辑
  • 参考日志输出排查节点宕机时的连接切换与恢复耗时
