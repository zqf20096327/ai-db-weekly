🧭 简介解读层（AI·证据行可回查）

将 H3 地理索引库绑定到 SQLite3 的扩展，提供 SQL 可调用的 H3 函数

综述（解读层）

h3-sqlite3 把 Uber 开源的 H3 六边形地理索引库封装为 SQLite3 可加载扩展（.load libh3ext），使用户可在 SQL 查询中直接调用经纬度转单元格、父子层级、分辨率等函数。适合在 SQLite 中处理地理网格数据的开发者。编译依赖 libsqlite3-dev 与 CMake，且需以 -fPIC 编译 H3；目前仅实现部分 H3 函数，Spatialite 支持尚在计划中。

  • 提供 h3_latlng_to_cell、h3_cell_to_parent、h3_get_resolution 等 12 个 SQL 函数
  • 通过 .load ./libh3ext 方式加载，在 sqlite3 命令行中直接使用
  • 使用 CMake 构建，Apache 2 许可证

适用场景（解读层）

  • 在 SQLite 查询中对经纬度计算 H3 单元格索引
  • 查询 H3 单元格的层级父格、分辨率与有效性质
  • 以 SQL 方式做六边形网格的空间索引实验或数据处理
