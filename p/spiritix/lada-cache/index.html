基于 Redis 的 Laravel 数据库查询自动缓存层

综述（解读层）

Lada Cache 是一个 Laravel 扩展包，通过注册自定义数据库连接拦截 SQL 查询，将结果存入 Redis 并在数据变更时自动失效缓存。它面向使用 Eloquent 的 Laravel 应用，安装后需在模型中引入 trait，无需改动业务代码。仅支持 Redis 作为后端，依赖单列主键实现行级失效，复杂 SQL 构造会回退到表级失效。

  • 自动缓存 Eloquent 和 Query Builder 查询，基于 SQL、参数与数据库计算缓存键
  • 在 insert、update、delete、truncate 时自动按行级或表级标签失效相关缓存
  • 支持 withoutCache() 单查询跳过缓存、按表配置包含/排除，并提供 Debugbar 集成与 artisan flush 命令

适用场景（解读层）

  • 重复执行相同查询、数据库负载较高的 Laravel 应用
  • 需要分布式缓存与细粒度失效、替代手动缓存或基于时间过期的场景
  • 希望在不修改业务代码的情况下为 Eloquent 查询添加缓存的现有项目
