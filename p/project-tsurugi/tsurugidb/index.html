面向多核大内存环境的开源关系型数据库，采用组件化架构。

综述（解读层）

Tsurugi 是一个开源关系数据库（Apache-2.0），针对数百 CPU 核与大内存环境设计，支持事务与 SQL，可通过 JDBC、ODBC、Python、Rust、C 等多种客户端接口同时访问。安装提供 Docker 镜像和入门文档（部分仅日语）；其事务引擎、SQL 编译器等以 shirakami、mizugaki 等子项目形式组件化实现。

  • 面向多核与内存环境的 SQL 关系数据库，强调一致性（含 serializable 事务）
  • 组件化架构：事务引擎、SQL 执行引擎、框架与客户端库拆分为多个子项目
  • 提供 Java（Iceaxe/Tsubakuro/JDBC/Hibernate）、Rust、C、ODBC、Python 等多种客户端接口，并包含 tgctl、tgsql、tgdump 等 CLI 工具和 UDF、FDW、MCP 集成

适用场景（解读层）

  • 在多核大内存服务器上运行 OLTP 事务型 SQL 应用
  • 需要批处理与长事务同时保证串行化一致性的场景
  • 通过 JDBC/ORM、PostgreSQL FDW 或 gRPC UDF 集成到既有应用与管理体系
