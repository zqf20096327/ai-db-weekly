基于 sqlite3-rdiff 与 rsync over SSH 的 SQLite3 主从复制工具

综述（解读层）

sqlite3-sync 将本地（主）SQLite3 数据库以增量方式复制到远程（从）端。依赖双侧安装 sqlite3-rdiff 和 rsync，并需配置免密 SSH 登录；主端放置脚本与配置文件，双侧需建 cache 目录。README 给出签名文件约占从库大小 2.6%、双向传输量约 0.6% 的数据，并附 Rspamd 数据库复制示例。

  • 通过 sqlite3-rdiff 生成签名与增量文件，配合 rsync over SSH 传输
  • 签名与增量文件缓存可减少传输数据量，双向传输量约占从库大小的 0.6%
  • 配置基于样例文件 sqlite3-sync.conf，运行脚本即可启动复制

适用场景（解读层）

  • 需要将本地 SQLite3 数据库持续同步到远程主机的场景
  • 带宽受限环境下的数据库异地复制
  • Rspamd 等 SQLite 数据库文件的远程副本维护
