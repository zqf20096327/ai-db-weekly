基于 Delphi/FireDAC 的 Windows SQL 查询工具，支持多数据库连接

综述（解读层）

DataGrabber 是一个面向 Windows 的 SQL 查询工具，通过 FireDAC 连接多种数据库，使用 Delphi 开发并依赖 Spring4D、Virtual Treeview、SynEdit 等第三方库。支持列分组与合并、多结果集展示、数据导出，连接配置以 JSON 文件存储并可通过连接配置文件管理多个数据库。可选集成商业组件 DevExpress cxGrid。

  • 通过 FireDAC 连接拓扑支持多种 SQL 数据库，连接配置以 JSON 格式存储并可编辑文件直接修改
  • 支持列分组、列合并与数据导出，多结果集可水平、垂直或以标签页方式展示
  • 界面基于 Virtual Treeview、SynEdit、TChromeTabs 等组件实现，含字段检查器

适用场景（解读层）

  • 需要在一个工具中配置和管理多个数据库连接配置文件的查询场景
  • 需要对查询结果进行列分组、列合并展示并导出的数据分析操作
  • 需要以多种布局（水平/垂直/标签页）查看多个查询结果集的场景
