观察 Rails 应用产生的 PostgreSQL 数据库锁的 Ruby gem

综述（解读层）

pg-locks-monitor 是一个 Ruby gem，用于在 Rails 应用中观察数据库锁。PostgreSQL 默认不持久化锁数据，该 gem 通过分析 pg_locks 元数据表的瞬时状态，按配置的时长阈值等条件筛选后，将锁信息通知到日志或 Slack。需要以定期后台任务方式调用 snapshot! 方法，需自行调度。

  • 提供 snapshot! 方法，按配置条件捕获锁并通知到 Rails.logger 或 Slack
  • 支持配置锁时长阈值、阻塞锁监控、数量上限及自定义过滤 proc
  • 支持自定义 notifier 类以接入其他通知渠道

适用场景（解读层）

  • Rails 应用排查长期持有或阻塞其他查询的数据库锁
  • 需要将锁事件定期通知到 Slack 或日志的监控流程
  • 按来源（如 Puma/Sidekiq 进程）过滤上报特定锁数据
