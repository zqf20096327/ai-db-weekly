面向 Rails 应用的 PostgreSQL 性能洞察工具，提供锁、索引等查询

综述（解读层）

rails-pg-extras 是 Heroku PG Extras 的 Rails 移植版，供未使用 Heroku PostgreSQL 插件的 Rails 应用获取 PostgreSQL 实例元数据，覆盖锁、索引使用、缓存命中率、vacuum 统计等。每个查询可经 rake 任务或 Ruby API 调用，支持 hash/array/raw 等输出格式，可通过 Rails engine 挂载 Web 界面并配置 Basic Auth。calls、outliers 等查询依赖 pg_stat_statements 扩展。

  • 提供 diagnose 方法，运行一组检查并输出报告，标注可能需进一步调查的区域
  • 支持通过 Ruby API、rake 任务、Web UI 及 MCP 接口访问，并可指定 schema 与数据库连接 URL
  • measure_queries 方法可统计代码片段中 SQL 查询的最小/平均/最大耗时，用于排查 N+1 问题

适用场景（解读层）

  • 分析 Rails 应用 PostgreSQL 性能问题，如锁等待、索引使用、缓存命中率
  • 排查 N+1 查询及评估 eager loading 配置效果
  • 检查缺失外键索引与缺失外键约束的列，查看表结构与表的元数据指标
