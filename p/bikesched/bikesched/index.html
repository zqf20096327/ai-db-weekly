基于 PostgreSQL 的 Java/Kotlin 任务调度库，支持持久化步骤、事件与重试

综述（解读层）

bikesched 是一个以 PostgreSQL 为唯一基础设施的任务调度库，面向 Java 和 Kotlin 开发者。任务、持久化步骤、事件与节点均存储在 bikesched_* 表中，首次使用时自动建表和迁移；节点通过 SELECT … FOR UPDATE SKIP LOCKED 认领任务，并用 LISTEN/NOTIFY 通知到期任务。核心仅依赖 PostgreSQL JDBC 驱动和 SLF4J API。README 标明项目处于 0.2.0-SNAPSHOT 早期阶段，API 与数据库模式可能无迁移地变更；它不含 BPMN 流程模型，不做跨服务编排。发布版与快照发布到 GitHub Packages，读取需带 read:packages 权限的令牌。

  • 核心仅两个运行时依赖（PostgreSQL JDBC 驱动和 SLF4J API），任务与步骤结果存于普通 PostgreSQL 表，模式在首次使用时自动创建和迁移
  • 支持持久化步骤（结果跨重试保留）、可选补偿（saga）、事件等待、postpone、sleep、子任务及循环调度，任务运行在 Java 21+ 的虚拟线程上
  • 模块化扩展：Jackson 载荷、Kotlin DSL、Spring Boot starter、cron、Micrometer 指标、管理 UI（查找/重试/取消任务）与测试支持，按需引入

适用场景（解读层）

  • 在已有 PostgreSQL 数据库的 Java/Kotlin 应用中内嵌任务队列与调度，无需引入额外基础设施
  • 需要多步持久化流程的场景：任务步骤带补偿（saga 模式）、等待事件、轮询外部服务、跨节点故障恢复
  • 使用 Spring Boot 或 Kotlin 团队需要自动配置、类型化处理器与内置管理界面来重试和取消任务
