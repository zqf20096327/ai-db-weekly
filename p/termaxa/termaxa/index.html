🧭 简介解读层（AI·证据行可回查）

位于 AI 编码代理与 shell 之间的命令网关，预览后果、备份并可回滚。

综述（解读层）

Termaxa 是一个 Rust 单二进制工具，部署在 Claude Code、Codex、Cursor、Copilot CLI 等代理的 hook 路径中。它按仓库内的策略文件对命令执行允许/询问/拒绝判断，预览破坏性命令的具体影响（删除的文件、丢失的提交、DROP 的行），运行前做备份并支持 rollback，内置跨 shell 语法的熔断器，并以哈希链日志记录决策。策略未匹配的命令默认询问。

  • 按仓库内 policy.yaml 决策，首个匹配规则生效，未匹配命令默认询问；支持 observe 模式先观察后强制
  • 拆分复合命令（&&、||、;、| 等）逐段判断，按最危险段裁决；熔断器跨 shell 统计破坏性意图，默认阈值 2
  • 运行前备份文件、钉住 ref、导出表，termaxa rollback 可撤销；决策写入仅追加的哈希链日志

适用场景（解读层）

  • 在无人监督或无人值守场景下运行 AI 编码代理的项目
  • 接入新代理工具前，用 replay 评估历史命令中有多少会被询问
  • 需要对 rm -rf、git reset --hard、force push、DROP TABLE 等操作先看影响范围并留备份的团队
