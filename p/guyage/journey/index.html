基于 Django REST framework 与 Vue.js 的数据库管理平台

综述（解读层）

Journey 是一个面向企业内部数据库管理的 Web 平台，后端采用 Python 3.8 + Django 3.0 + djangorestframework，前端使用 Vue.js 2.5 + element-ui。它提供 MySQL、MongoDB、Redis 的实例管理与权限申请审批流程，包含 SQL 工单系统（审核部分集成 inception）、Query 查询功能及基于用户-角色-权限的访问控制，支持 LDAP 登录。README 标注 SQL 工单审核所依赖的 inception 已闭源，作者提供个人 fork 项目；项目由个人维护，更新节奏有限。

  • 支持 MySQL、MongoDB、Redis 三类数据库的实例管理、用户管理与状态查看（processlist、innodb、master/slave）
  • 数据库权限采用申请-审批流程，默认用户无可访问权限；SQL 工单审核集成 inception（依赖作者 fork 项目）
  • 提供 QuerySql 查询功能，含语法提示、结果导出及可动态调整的 QueryLimit 限制，登录支持 LDAP 与普通方式

适用场景（解读层）

  • 企业内部 DBA 团队集中管理 MySQL/MongoDB/Redis 实例与数据库账号
  • 通过审批流程管控数据库访问权限并执行 SQL 上线工单
  • 为开发人员提供带语法提示与查询限制的数据库查询入口
