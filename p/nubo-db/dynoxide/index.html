Rust 编写的 DynamoDB 模拟器，以 SQLite 为存储后端

综述（解读层）

Dynoxide 是一个用 Rust 实现的 DynamoDB 模拟器，使用 SQLite 作为存储层，可运行方式包括 HTTP 服务器、面向编码代理的 MCP 服务器、可嵌入 Rust 与 iOS 应用的库，以及 WebAssembly 浏览器构建。项目定位为本地开发、测试与 CI 用途，明确不作为生产环境的 DynamoDB 替代；云专属操作（备份、全局表等）未实现。README 提供了性能对比表和 Parity Suite 一致性套件的公开测试结果。

  • 实现 DynamoDB API：表、条目、query/scan、批量、事务、PartiQL、Streams、TTL、GSI/LSI 及表达式语法
  • 提供 HTTP 服务器、MCP 服务器、Rust/iOS 嵌入库、WebAssembly 四种运行形态，以单个静态二进制分发
  • 通过 Parity Suite 公开一致性套件对真实 AWS 持续验证，结果与测试代码开放

适用场景（解读层）

  • 本地开发与集成测试：将 AWS SDK 指向本地端点，通过 npm、Docker、Homebrew、Cargo 或 GitHub Actions 安装
  • 编码代理场景：以 MCP 服务器形式运行供代理调用
  • CI 流水线：毫秒级启动的静态二进制或官方 GitHub Action
