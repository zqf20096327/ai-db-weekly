🧭 简介解读层（AI·证据行可回查）

基于 SQLite 的 Rust 编写的 DynamoDB 本地模拟器，支持 HTTP/MCP/嵌入/WebAssembly 多种运行形态。

综述（解读层）

Dynoxide 是一个用 Rust 实现的 DynamoDB 模拟器，底层存储为 SQLite，面向本地开发、测试和 CI 场景。它以单个静态二进制分发，通过公开的一致性测试套件对照真实 AWS 验证行为；项目自述非生产环境替代品，不支持备份、全局表等云专属操作，且部分行为（如最终一致性读、事务争用错误）与线上 DynamoDB 存在已知差异。

  • 实现 DynamoDB API，覆盖表、条目、Query/Scan、批次、事务、PartiQL、Streams、TTL、GSI/LSI 及表达式语法与错误码
  • 可作为 HTTP 服务器、MCP 服务器、可嵌入的 Rust 库（含 iOS），并编译为 WebAssembly 在浏览器运行
  • 提供 npm、Docker、GitHub Actions、Homebrew、Cargo 等安装方式，并通过 Parity Suite 公开一致性测试对照 AWS 验证

适用场景（解读层）

  • 本地开发与集成测试中替代 DynamoDB 端点，AWS SDK 指向本地 HTTP 端口即可运行
  • CI 流水线中通过 npm、Docker 或 GitHub Action 启动 DynamoDB 兼容服务
  • Rust 项目以嵌入式库方式在测试中调用内存数据库，无需 HTTP 层
