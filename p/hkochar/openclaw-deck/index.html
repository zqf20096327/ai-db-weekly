OpenClaw 智能体的自托管运维仪表盘，含预算管控与会话回放

综述（解读层）

Deck 是面向 OpenClaw 框架的自托管运维面板，用于监控本机运行的自主智能体。通过网关插件采集 LLM 调用与费用写入 SQLite，提供每智能体预算限制与自动暂停、模型漂移检测、配置版本备份还原、会话逐步回放及 Discord 告警。仅支持 macOS，需与网关同机运行，不面向其他框架。

  • 提供按智能体的预算限制、达到上限自动暂停和降级到更便宜模型的节流链，并通过 Discord 发送含恢复按钮的告警
  • 实时记录每次 LLM 调用、工具调用与文件读取，包含 token 数、单次费用、缓存命中率和完整提示/响应内容
  • 以 FILE 快照与 GIT 提交保存网关配置的版本化备份，支持 Preview、Diff 与一键 Restore，并自动重启网关

适用场景（解读层）

  • 在本机长期运行 OpenClaw 自主智能体并需要控制 API 花费的用户
  • 在无人值守场景（如夜间）需要智能体超预算或静默时收到手机端 Discord 告警的运维流程
  • 排查智能体行为异常时逐步回放会话、查看思考块与工具调用细节
