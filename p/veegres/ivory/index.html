自托管数据库集群管理 Web UI 与 MCP 服务器，单容器运行

综述（解读层）

Ivory 是一个开源自托管的数据库集群管理系统，通过单个 Docker 容器运行，无需在目标主机安装代理或编排器。它提供 Web UI 用于部署集群（基于 SSH）、监控健康与复制延迟、执行 switchover/failover 等 HA 操作、运行 SQL 查询控制台和查看主机指标与日志；同时内置 MCP 服务器供 AI 代理调用，权限与用户体系一致。支持 PostgreSQL+Patroni（稳定版）及 etcd、Redis、ClickHouse、MongoDB、ZooKeeper（Beta），各引擎以插件形式接入。

  • 支持 PostgreSQL Patroni 主备、etcd、Redis、ClickHouse、MongoDB、ZooKeeper 等集群的健康监控与 switchover/failover/reinit 等 HA 操作
  • 通过 SSH 和模板部署集群节点，无需在主机上安装代理、编排器或 Kubernetes/Ansible
  • 内置 MCP 服务器，可接入 Claude、Cursor 等支持 MCP 的 AI 客户端操作集群，受每用户权限控制

适用场景（解读层）

  • 统一管理多引擎数据库集群：查看节点角色、复制延迟、告警，并从浏览器或手机执行切换、重启等运维操作
  • 在自己的 VM 上以 Docker 方式部署高可用数据库集群（无需 K8s/Ansible）
  • 通过 MCP 将数据库集群接入 AI 代理，用自然语言进行诊断与修复
