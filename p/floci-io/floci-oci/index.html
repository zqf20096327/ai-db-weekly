🧭 简介解读层（AI·证据行可回查）

本地运行的 Oracle Cloud 基础设施模拟器，通过 Docker 容器提供 OCI 协议服务

综述（解读层）

floci-oci 是一个开源的本地 Oracle Cloud Infrastructure 模拟器，面向开发、测试和 CI 场景。它以 Docker 容器（端口 4599）实现 OCI 请求签名、分页、etag 等线上协议细节，官方 SDK、OCI CLI、Terraform 提供方可直接指向 localhost 使用；API 密钥仅解析签名上下文、不校验。基于 Quarkus 构建，需 JDK 25 从源码运行。

  • 支持 Identity、Object Storage、Queue、Streaming、Vault+KMS、Functions、OKE、PostgreSQL 数据库、Organizations 等多类 OCI 服务的本地模拟，部分服务（Functions/OKE/OCIR/PostgreSQL）通过 Docker sidecar 运行真实组件
  • 实现 OCI 线上协议细节：opc-request-id、opc-next-page 分页、etag/if-match 条件请求、OCID、异步 work requests 及 OCI 错误体格式
  • 提供 in-memory、持久化、混合、write-ahead log 四种存储模式，支持 GraalVM native-image；提供 bin/ocilocal 封装脚本自动注入本地端点

适用场景（解读层）

  • 无 Oracle Cloud 账户或凭据时在本地开发与调试 OCI 集成代码
  • 在 CI 流水线中运行依赖 OCI API 的集成测试
  • 测试 Terraform/OpenTofu 配置及对象存储、KMS、队列等服务的 IaC 工作流
