检测并修复 Alembic 并行迁移导致多头的命令行工具

综述（解读层）

alembic-head-fixer 用于处理两个分支基于同一 head 各自添加迁移导致 alembic upgrade head 失败的问题。提供 check、fix、mark-applied 三个命令：check 在 PR 中检测多头、重复 id、超长 id 等；fix 通过 git 标签记录已应用的迁移并保证其不被改动，将未运行的迁移按合并顺序重新串联；mark-applied 在迁移后移动标签。可通过 CLI、GitHub Action 或 pre-commit 钩子运行，需 Python 3.10+，无第三方依赖，不支持 branch label 及多 version_locations。

  • check 命令检测多 head、重复 revision id、缺失父版本及超过 32 字符的 id，支持 --base-ref 检查分支起点
  • fix 命令基于 git 标签识别已应用的迁移且不改动这些文件，将未运行迁移按 PR 合并顺序重新串联，支持 --dry-run 与 JSON 报告输出
  • 以 GitHub Action、pre-commit 钩子和 CLI 三种方式运行，通过 ast 读取迁移文件，兼容 Flask-Migrate 目录布局

适用场景（解读层）

  • 多开发者并行开发导致迁移历史分叉、alembic upgrade head 失败的团队 CI/CD 流程
  • 部署前自动检测并修复两个已合并 PR 产生的迁移冲突，并在相关 PR 上留言说明改动
  • 本地提交时通过 pre-commit 钩子提前发现迁移历史问题
