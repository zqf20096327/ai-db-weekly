AWS 数据库实时监控轻量应用，参照 Unix top 于单屏展示性能数据

综述（解读层）

DBTop Monitoring 是 aws-samples 下的参考代码项目，为 AWS 数据库资源提供实时监控，界面沿用 Unix top 的单屏展示概念。前端为 React 应用，后端为 NodeJS API，从数据库引擎、CloudWatch 及 RDS Enhanced Monitoring 采集性能数据，通过 CloudFormation 部署到 EC2，并以 Cognito 做用户登录。README 声明其仅供教育演示用途，生产使用需自行审查、测试与加固。

  • 支持 RDS（MySQL、PostgreSQL、MariaDB、Oracle、SQL Server）、Aurora（MySQL/PostgreSQL 兼容版）、ElastiCache for Redis、MemoryDB、DocumentDB 等数据库引擎
  • 后端 NodeJS API 从数据库引擎、CloudWatch（按需调用 GetMetricData）和 RDS Enhanced Monitoring 采集性能指标，需预先启用 Enhanced Monitoring
  • 通过 CloudFormation 模板一键部署，包含 EC2 应用服务器与 Cognito 用户认证，官方声明约 10 分钟部署完成

适用场景（解读层）

  • 实时查看数据库实例性能数据，定位排查性能问题的根因
  • 分析数据库与操作系统指标以缩短故障排查时间
  • 识别消耗最高的会话，收集 SQL 语句与资源使用情况以优化资源
