🧭 简介解读层（AI·证据行可回查）

基于 Aurora PostgreSQL、RDS Proxy 与 Route53 的区域内及跨区域故障转移演示方案

综述（解读层）

这是 AWS 官方示例仓库，通过单个 CloudFormation 模板部署跨两个区域的 Aurora PostgreSQL Global Database 集群。区域内故障转移由 RDS Proxy 实现，将查询排队等待读取实例升为写入实例；跨区域由 Canary Lambda 每 10 秒探测主区域，连续失败 30 秒后触发故障转移并改写 Route53 CNAME。模板部署约需 60 分钟，需提前提升两个区域的 Lambda 并发配额至少 1000。附带的测试应用可生成负载并以图表记录成功请求、错误及故障转移耗时。

  • 通过 CloudFormation 模板一键部署双区域数据库集群与 VPC，部署约需 60 分钟
  • Canary Lambda 每 10 秒从次区域探测主区域，连续失败 30 秒后自动执行跨区域故障转移
  • RDS Proxy 将读写查询排队，把 SQL 错误转为数秒延迟，并提供有无代理的对比测试面板

适用场景（解读层）

  • 评估区域内 Aurora PostgreSQL 故障转移时 RDS Proxy 对应用错误率与中断时长的影响
  • 验证跨区域灾难恢复流程，包括区域级中断模拟、Canary 探测与 Route53 切换
  • 复用模板中的 CloudFormation 工程机制（如跨区域资源引用、Lambda Layer 构建）到自有部署中
