🧭 简介解读层（AI·证据行可回查）

基于 AWS CDK 的示例项目，用 DMS 将 MySQL CDC 数据经 Kinesis 流入 OpenSearch。

综述（解读层）

该项目提供 CDK 脚本与示例代码，构建从 MySQL（Aurora MySQL）到 Amazon OpenSearch Service 的 CDC 数据管道，中间经由 AWS DMS 与 Amazon Kinesis。面向需要在 AWS 上搭建事务数据复制与检索管道的开发者。部署需 Python 虚拟环境、EC2 密钥对及 cdk.context.json 配置，并需确认源库开启 binlog、设置 binlog 保留小时数，以及预先创建 OpenSearch 服务关联角色。

  • 提供 VPC、Aurora MySQL、Kinesis Data Streams、DMS 复制任务、OpenSearch 域等多个 CDK Stack，分步部署完整管道
  • 通过 EC2 堡垒主机连接集群，提供验证 binlog 开启与创建示例库表（testdb.retail_trans）的步骤
  • 数据库凭据存于 AWS Secrets Manager，部署前通过 cdk.context.json 配置库名、表名、流名与索引名

适用场景（解读层）

  • 需要将 MySQL/Aurora MySQL 事务数据变更复制到 OpenSearch 进行检索的场景
  • 学习 AWS DMS 以 Kinesis Data Streams 为目标端点的 CDC 流水线搭建流程
  • 通过 AWS CDK 以 CloudFormation 方式按 Stack 分步构建和演示端到端数据管道
