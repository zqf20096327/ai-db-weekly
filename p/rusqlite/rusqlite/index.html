Rust 语言的 SQLite 封装库，提供面向 Rust 的 SQLite 绑定接口

综述（解读层）

Rusqlite 是一个供 Rust 程序使用 SQLite 的封装库，通过 libsqlite3-sys 提供 SQLite C API 的 Rust 声明。基础包支持 SQLite 3.45.3 及以上版本，默认通过 pkg-config 或 vcpkg 查找系统已装的 SQLite，也可用 bundled 特性从源码编译并链接内置的 SQLite 3.54.1。库提供大量 Cargo 特性（备份、自定义函数、虚拟表、扩展加载等），使用前需在 Cargo.toml 中按需启用。

  • 通过 libsqlite3-sys 提供 SQLite C API 的绑定，支持系统链接或 bundled 源码编译（内置 SQLite 3.54.1）
  • 提供 backup、functions、window、vtab、load_extension、hooks、serialize 等多个 Cargo 可选特性
  • 为 chrono、serde_json、uuid、url 等类型实现 FromSql/ToSql 转换；在 wasm32 目标上可用 sqlite-wasm-rs

适用场景（解读层）

  • 在 Rust 应用中读写 SQLite 数据库
  • 需要用 Rust 编写 SQLite 虚拟表、自定义函数或加载扩展的场景
  • 系统未装 SQLite 或链接复杂（如 Windows）时，通过 bundled 特性从源码编译 SQLite
