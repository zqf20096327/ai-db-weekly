SQL Optimizer And Rewriter：小米开源的 SQL 优化与改写命令行工具

综述（解读层）

SOAR 是小米人工智能与云平台数据库团队开发的 SQL 自动化优化与改写工具，以命令行方式运行，支持 Linux/Mac（Windows 未全面测试）。它基于启发式算法提供建议，解读 EXPLAIN 信息，进行索引优化、SQL 美化与规则改写；目前仅支持 MySQL 语法族协议，采用 Apache 2.0 许可证发布。

  • 基于启发式算法的语句优化，支持 SELECT、UPDATE、INSERT、DELETE 的多列索引优化
  • 支持 EXPLAIN 信息丰富解读、SQL 指纹/压缩/美化及同表多条 ALTER 请求合并
  • 支持基于自定义规则的 SQL 改写，跨平台运行（Linux、Mac，Windows 未全面测试）

适用场景（解读层）

  • MySQL 语法族 SQL 语句的优化建议生成与审查
  • 查询执行计划（EXPLAIN）解读分析
  • SQL 格式化、指纹提取及批量 ALTER 语句合并处理
