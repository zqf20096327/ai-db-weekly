连接 PMM 2/3 与 MCP 客户端的社区服务器，默认只读

综述（解读层）

该服务器为 Percona Monitoring and Management 2.x/3.x 实现 Model Context Protocol 接口，供 Claude 等 MCP 客户端读取 MySQL、MongoDB、PostgreSQL 的指标、Query Analytics、告警和仪表盘。安装需 Python 3.11+ 和 uv，通过 PMM_URL 与 Grafana 服务账户令牌连接，默认以 Viewer 令牌只读运行；写操作（静默、注释）需 PMM_ALLOW_WRITE=1、Editor/Admin 令牌且每次调用 confirm=true。未覆盖 firing 状态告警及 ProxySQL/HAProxy。

  • 提供 PromQL 即时/区间查询、指标与标签发现，及 QAN 慢查询分析（含经校验的 ClickHouse SELECT）
  • 默认只读，凭 Viewer 令牌运行；写工具默认关闭且先 dry-run，需显式确认
  • TLS 默认验证并支持自定义 CA，SQL 仅接受单条 SELECT/WITH 且行数与时间窗口设上限

适用场景（解读层）

  • 在 Claude 客户端中查看数据库监控状态、 firing 告警和仪表盘 PromQL/SQL
  • 用自然语言查询慢查询详情、每服务负载与指标时间序列
  • 在维护期间显式开启写权限后创建/删除告警静默、添加部署注释标记
