ParadeDB 的官方 SQLAlchemy 集成库，用于在 ORM 中使用其检索能力

综述（解读层）

该项目是 ParadeDB 的官方 SQLAlchemy 集成，使 Python 开发者能在 ORM 层使用 ParadeDB 基于 PostgreSQL 的检索能力。要求 Python 3.10+、SQLAlchemy 2.0.32+、PostgreSQL 15+、pgvector 0.7.0+ 及 ParadeDB/pg_search 0.26.2+，采用 MIT 许可证。README 未包含安装命令与具体 API 用法，需参阅其设置指南文档。

  • 官方 SQLAlchemy 集成，支持 Python 3.10+ 与 SQLAlchemy 2.0.32+
  • 依赖 PostgreSQL 15+、pgvector 0.7.0+ 与 ParadeDB/pg_search 0.26.2+
  • 采用 MIT 许可证开源

适用场景（解读层）

  • 使用 SQLAlchemy 的 Python 项目接入 ParadeDB 全文检索
  • 在 ORM 层结合 pgvector 进行向量检索
  • 基于单个 PostgreSQL 运行应用数据、搜索与聚合的工作流
