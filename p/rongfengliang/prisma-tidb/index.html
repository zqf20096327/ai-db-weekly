通过 docker-compose 在 TiDB 集群上运行 Prisma GraphQL 服务的示例项目

综述（解读层）

该项目将 Prisma 与 TiDB 通过 docker-compose 组合，提供 docker-compose up -d 启动 TiDB 集群、prisma deploy 部署后在 4466 端口访问 GraphQL API 的流程。README 主体内容沿用了 tidb-docker-compose 的文档，包含集群配置自定义、Helm 模板渲染、TiSpark 接入与调试方法；要求 Docker >= 17.03、Docker Compose >= 1.6.0，且注明不支持 Docker Toolbox 与 Docker Machine。

  • 支持 docker-compose 一键启动 TiDB 集群，通过 prisma deploy 部署后提供 GraphQL API（4466 端口）
  • 支持通过 Helm 模板渲染自定义集群规模、镜像与端口映射，可配置 Prometheus、Grafana 监控与 tidb-vision 可视化
  • 包含 TiSpark 组件，可通过 spark-shell、pyspark、sparkR 访问 TiDB 数据，并提供 pprof 调试工具脚本

适用场景（解读层）

  • 在本地 Docker 环境中搭建 Prisma + TiDB 的 GraphQL 服务运行环境
  • 基于 docker-compose 或 Helm 模板自定义部署 TiDB 集群并接入监控组件
  • 通过 TiSpark 在 TiDB/TiKV 上运行 Spark Shell 执行 OLAP 查询测试
