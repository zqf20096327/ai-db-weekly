基于 PolarDB pgvector/PASE HNSW 索引的内核级性能优化参赛项目

综述（解读层）

本项目是计算机系统能力大赛 PolarDB 数据库创新设计赛的参赛作品，面向使用 pgvector/PASE 做 HNSW 向量检索的数据库内核开发者。它通过 SQ8 标量量化、AVX-512 SIMD 距离计算、硬件预取、乐观锁及编译优化等六项叠加策略，在 Recall≥0.85 约束下降低索引构建时间、提升查询吞吐并缩小索引体积。需 AVX-512 CPU，仓库不含数据集，需自行下载。

  • 针对 200 维固定维度实现 AVX-512 SIMD 距离计算与硬件预取，并提供 SQ8 标量量化存储格式（每向量 800B 降至 208B）
  • 提供版本号乐观锁三阶段无锁读协议，失败重试 3 次后降级加锁
  • README 中列出量化结果：索引构建时间下降约 54.8%、QPS 提升 8.7%、索引体积缩小 34.1%（Recall≥0.85）

适用场景（解读层）

  • 参加 PolarDB 数据库创新设计赛或类似向量索引内核优化竞赛的团队参考
  • 在支持 AVX-512 的环境构建 PolarDB + pgvector HNSW 索引并复现性能评测
  • 学习用 perf 火焰图定位热点、逐项量化验证优化效果的工程流程
📖 README 首段存档原文 · 程序抽取

在不引入任何新算法的前提下，围绕 HNSW 索引在高维固定维度（200 维）场景下的内存带宽瓶颈与热路径冗余开销，通过「压缩存储 + 访存优化 + 并发改进 + 微观精简」的综合策略，在严格保证 Recall ≥ 0.85 的前提下，将索引构建时间降至原来的 45%（加速 2.21×），查询吞吐提升 8.7%，索引体积缩小 34.1%。
