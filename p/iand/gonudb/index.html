Go 编写的仅追加（append-only）键值数据存储库

综述（解读层）

Gonudb 是 C++ 键值存储 NuDB 的 Go 移植版，以库形式提供。数据文件顺序追加键值且不可变，键文件构成磁盘哈希表，提交时生成日志文件用于故障修复。插入在内存缓冲后定期落盘，客户端按刷盘速率被限流。当前为 0.1.0 alpha 版，适合用可丢弃数据做测试，无删除或修改操作。

  • 数据文件与键文件相互独立，键文件可从数据文件重建，并可换用其他哈希方案
  • 键文件采用线性哈希算法管理固定大小的桶，桶超容时可溢出（spill）到数据文件形成链表
  • 附带 gonudbadmin 管理工具，提供 info 和 verify 命令查看文件信息并校验数据与键文件一致性

适用场景（解读层）

  • 在 Go 项目中需要仅追加、不可变键值存储的场景
  • 使用可丢弃负载对 NuDB 式设计的 Go 实现进行测试
  • 需要从数据文件重建哈希索引或校验存储文件一致性的运维场景
