🧭 简介解读层（AI·证据行可回查）

基于 DuckDB 的临时数据沙箱，通过 MCP 与 REST API 供 AI 代理查询分析。

综述（解读层）

SpotDB 是一个面向 LLM 与代理工作流的临时数据沙箱，支持通过 Homebrew 安装后启动服务，上传 CSV 并用 SQL 查询。它提供 MCP 与 REST 两种访问接口，具备快照与护栏机制，用于隔离分析数据、避免代理直接访问生产数据库。提供浏览器端 Explorer UI，本地运行无需额外基础设施。

  • 提供临时性数据沙箱，支持上传 CSV 后以 SQL 查询数据
  • 同时提供 MCP API 与 REST API 两种数据访问方式
  • 支持快照功能，可恢复到指定时间点的数据状态

适用场景（解读层）

  • 让 AI 代理在隔离环境中分析 CSV 数据
  • 在不接入生产数据库的前提下做临时数据探索
  • 通过 REST API 将 SQL 查询能力集成到传统系统
