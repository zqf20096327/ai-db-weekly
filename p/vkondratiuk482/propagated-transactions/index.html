基于 AsyncLocalStorage 的 Node.js 数据库事务传播与管理封装库

综述（解读层）

该库为 Node.js/TypeScript 项目提供事务上下文传播能力：通过 AsyncLocalStorage 隐式传递数据库连接，避免在方法参数中显式传递 connection。开发者需自行实现 ITransactionRunner 接口适配具体数据库或 ORM，业务逻辑因此不与特定驱动绑定。支持四种隔离级别（默认 READ COMMITTED），1.2.0 起支持嵌套事务执行。零生产依赖，MIT 协议。

  • 基于 AsyncLocalStorage 隐式传播数据库连接，无需在方法参数中传递 connection 对象
  • 通过 ITransactionRunner 接口解耦事务管理逻辑与具体数据库、驱动、ORM 实现
  • 支持 READ COMMITTED/READ UNCOMMITTED/REPEATABLE READ/SERIALIZABLE 隔离级别及嵌套事务执行（自 1.2.0 起），回调失败自动回滚并抛出错误

适用场景（解读层）

  • 多个服务方法（如 UserService 与 WalletService）需在同一事务中原子执行，但不希望污染方法签名
  • 业务逻辑需保持与数据库驱动/ORM 解耦，便于更换底层实现
  • 存在嵌套调用链的路由或服务层，需要内层方法自动纳入外层事务
