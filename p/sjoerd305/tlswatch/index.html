自托管 TLS 证书到期监控工具，Go 单二进制加 SQLite 实现

综述（解读层）

tlswatch 是一个自托管的 TLS 证书监控服务，用 Go 编写，以单二进制加 SQLite 文件运行，并带 Web UI。它检查主机名与 IP 实际提供的证书到期时间、信任链、主机名匹配和签名强度，检测证书变更及旧版 TLS 协议，并通过邮件、Telegram、Slack、Discord、ntfy 或 webhook 告警。面向需要自行管理证书监控的个人与运维人员；部署方式为 Docker、Compose 或直接运行二进制，首次启动需在设置页创建管理员账户。

  • 支持任意端口的隐式 TLS 与 STARTTLS（SMTP、IMAP、POP3、FTP、PostgreSQL），并探测域名背后的每个地址
  • 支持系统证书存储、私有 CA 包与固定自签证书，识别 ACME 续期，并提供每日旧协议与弱密码套件检测及 A 到 F 配置评级
  • 提供证书清单（可导出 CSV）、REST API（/api/v2，附 OpenAPI 文档）、Prometheus 指标端点、证书透明度日志比对、加密备份与角色/SSO/TOTP 认证

适用场景（解读层）

  • 自托管环境中对多个服务、任意端口和内网地址的 TLS 证书到期与配置进行集中监控
  • 通过分布式节点从服务器自身无法到达的网络内部执行探测，并结合证书透明度日志发现未在目标上部署的证书
  • 需要告警升级、确认、周报汇总，或将监控结果接入 Prometheus / REST API / CSV 导出的运维流程
