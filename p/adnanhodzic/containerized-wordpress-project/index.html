基于 Ansible 与 Docker 的 WordPress 容器化自动化部署工具

综述（解读层）

该项目提供一个 Ansible playbook，用于在全新 Linux 实例上部署由 WordPress、Nginx（Let's Encrypt HTTPS）和 MySQL 三个容器组成的 WordPress 环境，支持交互式与参数化非交互式运行。README 要求目标主机开放 80/443 端口、内存不低于 1G，本地安装 Ansible（建议 2.7 以上）。适用于需要快速在 Ubuntu、Debian、CentOS、RedHat 主机上运行 WordPress 的用户。

  • 以 Docker Compose 部署 WordPress、Nginx（Let's Encrypt）与 MySQL 三个相互连接的容器
  • 包含系统升级、Python 引导、Docker 及 Docker Compose 安装等 Ansible roles，覆盖 Ubuntu/Debian 与 CentOS/RedHat
  • 支持 Let's Encrypt 证书自动续期、staging/production 两种模式以及多子域名配置

适用场景（解读层）

  • 在 AWS 等云平台的全新 Linux 实例上自动化部署 WordPress 博客/站点
  • 需要 Let's Encrypt HTTPS 加密与证书自动续期的容器化 WordPress 部署
  • 通过 --extra-vars 参数以非交互方式批量或脚本化部署 WordPress
