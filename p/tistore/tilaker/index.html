🧭 简介解读层（AI·证据行可回查）

基于 TiCDC 的 Flink CDC Connector，用于 TiDB 数据实时入湖。

综述（解读层）

TiLaker 是面向 TiDB 的 Flink CDC Connector，基于 TiCDC 组件实现全量历史数据读取与增量数据实时读取，切换时保证 exactly-once 语义。用户通过 Flink SQL 建表即可将 TiDB 表映射为实时物化视图，配合 Flink 对 Hudi、Iceberg 等数据湖产品的支持实现入湖，适用于 TiDB 与 Flink 生态的对接使用场景。

  • 提供全量读取历史数据和实时读取增量数据的能力，切换时保证 exactly-once 语义
  • 提供 SQL API，用户通过 Flink SQL 定义 tidb-cdc 表作为对应表的实时物化视图
  • 基于 Flink CDC 生态，可与 MySQL、Postgres 等异构数据源做 Join、Union 等流式加工

适用场景（解读层）

  • 将 TiDB 数据通过 Flink SQL 实时写入 Hudi、Iceberg 等数据湖
  • TiDB 与其他数据库表之间的实时流式融合分析
  • 从数据湖中读取数据进行离线分析与可视化
