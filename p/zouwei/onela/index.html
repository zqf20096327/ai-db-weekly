🧭 简介解读层（AI·证据行可回查）

Onela 是一套支持多种关系型数据库的 TypeScript ORM 框架。

综述（解读层）

Onela 是一个 TypeScript 编写的 ORM 框架，通过统一 Model 层接入 MySQL、PostgreSQL、SQLite、SQL Server、Oracle 等 9 种数据库，基于统一 SQLBuilder 与适配器架构生成 SQL。提供简单对象、操作符、链式、Lambda 等查询模式，以及 Schema 管理、读写分离、审计日志等模块，通过 npm 安装，按需引入数据库驱动，采用 GPL-3.0 协议。

  • 支持 9 种关系型数据库（MySQL/MariaDB/TiDB/PostgreSQL/SQLite/SQL Server/Oracle/OceanBase/PolarDB），按需安装对应驱动
  • 提供 5 种查询模式、DDL 构建、结构自省、迁移运行与动态 Model 注册
  • 包含读写分离与负载均衡路由、故障转移、SQL 注入防护、操作白名单、审计日志、行级与字段级访问控制模块

适用场景（解读层）

  • 需要在多种数据库间复用同一套 Model 业务代码的 Node.js/TypeScript 服务端开发
  • 配置读写分离、负载均衡与故障转移的数据库连接路由场景
  • 通过动态 Model 与元数据查询接口实现数据库结构管理或 AI 数据库管理工具
