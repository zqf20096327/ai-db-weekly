基于 SQLite 的便携无服务器图数据库，以 Arturo 语言实现

综述（解读层）

Grafito 是用 Arturo 语言编写的图数据库，底层基于 SQLite 存储，可在内存或磁盘文件中运行。它提供 put/link/fetch/unlink 等图查询命令，支持属性过滤、反向边查询和桌面应用预览。既可作为 Arturo 脚本库使用，也可作为独立工具运行，需先安装 Arturo，采用 MIT 许可证。

  • 基于 SQLite 存储，支持内存数据库和磁盘文件持久化，可指定文件名重新打开已有数据库
  • 提供 put/unput/link/unlink/fetch 等命令，支持 contains、prefix、over、under、in、not 等过滤条件和反向边查询
  • 可在 Docker 中运行（arturolang/grafito），也可作为 Arturo 库或独立工具（grafito.art）使用

适用场景（解读层）

  • 在 Arturo 脚本中以库形式创建和查询小型图数据
  • 通过独立工具或 Docker 快速运行图数据交互操作
  • 使用 preview 命令在桌面应用中可视化查看节点集合
