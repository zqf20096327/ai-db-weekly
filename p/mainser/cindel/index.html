🧭 简介解读层（AI·证据行可回查）

Flutter 本地数据库，Rust 内核加生成式类型化 Dart API

综述（解读层）

Cindel 是面向 Flutter 应用的本地数据库，基于 Rust 原生核心，默认使用 MDBX 存储引擎，并支持原生 SQLite 与 Web 端 SQLite/OPFS 后端。开发者用 Dart 注解定义模型后，由 build_runner 生成类型化集合、序列化器与查询助手，应用代码通过 db.users 等类型化集合操作数据。同一套模型与生成代码可在三种后端运行。提供 CRUD、事务、watchers、原子迁移与流式备份等能力；记录默认上限 16 MiB，Freezed 不支持 union/sealed 多构造器模型。

  • 从 Dart 模型类生成类型化集合、where()/filter() 查询助手，支持排序、分页、去重、投影与聚合
  • 提供 MDBX（默认）、原生 SQLite、SQLite Web/OPFS 三种后端，同一模型与生成代码可在三者上运行
  • 支持读写事务、类型化 watchers、打开时的原子迁移步骤，以及带校验和与原子恢复的流式 JSONL 备份导出导入

适用场景（解读层）

  • 需要类型化本地持久化与生成查询 API 的 Flutter 移动/桌面应用
  • 需要 Web 端本地存储的 Flutter Web 项目（经 SQLite/OPFS 后端）
  • 需要数据库迁移、备份导出导入或实验性 local-first 同步的应用工具链
