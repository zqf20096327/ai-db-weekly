将多来源睡眠数据导入 IPython Notebook 与 pandas 分析的工具集

综述（解读层）

Sleepnotebook 读取消费级睡眠设备与应用的原始数据——SleepCycle 导出的 CSV、iOS 备份中的 Eventlog.sqlite、Jawbone Up 手环 API——并将其导入 IPython Notebook 与 pandas 供分析使用。README 还整理了 SleepCycle 数据导出流程（CSV 经 OpenRefine 去除空行）及 R 语言曲线清洗的外部参考，面向自行分析睡眠数据的用户。

  • 支持从 SleepCycle CSV 导出与 iOS 备份中的 Eventlog.sqlite 文件读取数据
  • 包含 Jawbone Up API 相关实现与端点更新参考
  • 数据导入后可在 IPython Notebook 与 pandas 中进行分析

适用场景（解读层）

  • 将 SleepCycle 或 Jawbone Up 的历史睡眠数据导入 pandas 做个人数据分析
  • 从 iOS 备份中提取 Eventlog.sqlite 并读取睡眠记录
  • 结合 OpenRefine 清洗 CSV 后在 Notebook 中做进一步处理
