🧭 简介解读层（AI·证据行可回查）

基于 tree-sitter 与 SQLite/FTS5 的本地代码知识图谱工具

综述（解读层）

该项目将源码树转换为本地知识图谱：符号作为节点，调用、导入、继承、引用等关系作为边，存储于 SQLite 并支持 FTS5 全文检索，通过 CLI、MCP 服务器和浏览器查看器三种方式访问，不内置 AI 或向量运行时。面向编码代理与开发者，索引保存在项目目录下，支持增量同步，输出受字节级黄金样例约束。

  • 通过 tree-sitter 提取符号与调用/依赖关系，持久化为 SQLite/FTS5 索引，无 AI/LLM 调用，输出经字节级确定性校验
  • 提供 CLI（init/sync/search/callers/impact/explore 等命令）、MCP stdio 服务器及仅绑定 127.0.0.1 的本地浏览器查看器
  • 安装器可自动注册到 Claude Code、Codex、Zed 等客户端，支持增量 sync 与 watcher 更新，提供 musl 静态构建与 SHA256/attestation 校验

适用场景（解读层）

  • 为编码代理（如通过 MCP 接入的 Claude Code/Codex）提供符号检索、调用方/被调方查询与修改影响分析
  • 在本地浏览查看器中并排查看符号的调用者、源码与被调函数、调用路径与模块依赖图
  • 对大型代码库进行确定性的结构化索引与全文搜索，替代反复的文本检索式代码探索
