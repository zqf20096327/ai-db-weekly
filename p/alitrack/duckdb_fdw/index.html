🧭 简介解读层（AI·证据行可回查）

基于 DuckDB C API 的 PostgreSQL 外部数据包装器扩展，让 SQL 直接查询 DuckDB 与数据湖。

综述（解读层）

duckdb_fdw 是一个 PostgreSQL 扩展（MIT 许可，支持 PG 13–18），通过原生 DuckDB C API 将 DuckDB 作为外部数据源接入 PostgreSQL。它以外部表形式提供 DuckDB 数据的读取与写入，支持批插入、参数绑定、S3 凭据配置、MotherDuck 连接及 DuckLake/Iceberg 目录挂载，并内置与 pg_duckdb 同后端共存的运行时守卫。事务方面 PostgreSQL 与 DuckDB 各自独立，无两阶段原子性。适合需要在 PostgreSQL 中访问 Parquet、Iceberg 等 Lakehouse 数据的用户。

  • 基于 DuckDB C API 原生实现，提供分块扫描迭代、参数绑定与 Appender/批插入写入路径（批插入需 PG14+）
  • 支持 Parquet、Iceberg、S3 Tables、DuckLake、MotherDuck 及 Quack 协议，可自动检测 arn:aws:s3tables URI 并注入 sigv4 授权
  • 连接默认事务结束即刷新；keep_connection GUC 可跨事务复用连接，文件型数据库受 DuckDB 单写者锁约束

适用场景（解读层）

  • 在 PostgreSQL 中以外部表方式直接查询 S3 上的 Parquet/Iceberg/DuckLake 数据
  • 通过 MinIO、Ceph 等 S3 兼容对象存储配置 path 风格端点访问数据
  • 连接 MotherDuck 云端库并在会话中复用连接执行分析查询
