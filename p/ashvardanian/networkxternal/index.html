🧭 简介解读层（AI·证据行可回查）

以 NetworkX 接口操作 Postgres、SQLite、MongoDB、Neo4J 等后端存储的图数据库客户端

综述（解读层）

NetworkXternal 为 NetworkX 形状的图（nodes/edges/degree/neighbors）提供外存存储后端，支持 UStore、ClickHouse、MongoDB、PostgreSQL、SQLite、MySQL、Neo4J 与 Memgraph，每种后端均提供 Graph/DiGraph/MultiGraph/MultiDiGraph 四种视图。algorithms 包以分页方式驱动存储运行 PageRank 等图算法，结果以 VertexMap 返回。需 Python 3.12 及以上，通过 pip extras 安装对应驱动。

  • 实现十余个存储动词（扫描顶点、查找/更新边、合并属性文档），各后端继承 BaseGraph 的视图、遍历与属性映射
  • algorithms 包包含 PageRank、连通分量、Dijkstra、三角计数等约 20 个外存算法类，顶点状态存于 array，边按页读取
  • 遵循 NetworkX 3.x 的 __networkx_backend__ 分发协议，并附带统一 API 的基准测试程序与一致性测试套件

适用场景（解读层）

  • 图数据规模超出内存、需要持久化到 SQL/NoSQL/图数据库的场景
  • 在多种存储后端上运行图算法（PageRank、连通分量、社区发现等）并进行后端间基准比较
  • 开发与测试：通过统一一致性套件验证任一后端实现
