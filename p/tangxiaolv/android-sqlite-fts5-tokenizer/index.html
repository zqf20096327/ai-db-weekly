集成FTS5中文分词器（wcicu）的Sqlite3源码库

综述（解读层）

该项目提供内嵌FTS5中文分词器（tokenize='wcicu zh_CN'）的Sqlite3源码，分词器移植自微信的fts4分词器。面向需要在Android本地搜索大量中文文本数据的开发者。通过System.loadLibrary加载库文件，使用CMake脚本编译。README中包含以BenchmarkActivity为基准测试类的分表量级与分关键字数量的搜索耗时对照数据。

  • 提供带FTS5中文分词器的Sqlite3源码（版本3.21.0），支持通过 'CREATE VIRTUAL TABLE ... USING fts5(msg, tokenize='wcicu zh_CN')' 创建中文全文检索虚拟表
  • 内置基准测试类BenchmarkActivity，覆盖10w至100w行数据、1-4个关键字、每组10次取平均耗时的测试流程
  • 使用CMake脚本编译，支持调试与跨平台

适用场景（解读层）

  • 在Android应用本地对大量中文文本数据（如几十万条聊天记录）进行全文检索
  • 需要替代 LIKE '%关键字%' 模糊查询的本地搜索实现
  • 需要在本地编译和调试带自定义中文分词器的Sqlite3
📖 README 首段存档原文 · 程序抽取

Sqlite3全文检索是本地搜索引擎，用来搜索大数据量(几十万条聊天数据)，文本数据再适合不过。
