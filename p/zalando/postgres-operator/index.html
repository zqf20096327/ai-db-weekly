在 Kubernetes 上创建和管理由 Patroni 驱动的 PostgreSQL 集群的 Operator

综述（解读层）

该 Operator 通过 Postgres 清单（CRD）配置，在 Kubernetes 上创建和管理高可用 PostgreSQL 集群，由 Patroni 提供流复制支持，使用 Go 编写，由 Zalando 开发并已在生产环境使用五年以上。它面向需要在 K8s 上以基础设施即代码方式运维 Postgres 的团队，可集成到无法直接访问 K8s API 的 CI/CD 流程。部署 v2 前需阅读 v1 到 v2 的迁移文档。

  • 通过 CRD 清单配置集群，支持滚动更新、在线卷扩容（AWS EBS/PVC）与就地大版本升级
  • 支持基于 Patroni 的流复制集群、PITR 恢复（pg_basebackup/WAL-G/WAL-E，经 Spilo）及到 S3/GCS/Azure 的恢复与克隆
  • 支持 PostgreSQL 14+（v2.0.3 至 18）、K8s 1.27+、OpenShift、多架构及自定义 TLS 证书

适用场景（解读层）

  • 在 Kubernetes 上以基础设施即代码方式自动化管理 Postgres 集群的 CI/CD 流水线
  • 需要流复制高可用、时间点恢复及 S3/GCS 备份或 standby 集群的云或非云环境
  • 需要连接池（PgBouncer）、常用扩展（如 pgvector、timescaledb、postgis）的应用数据库托管场景
