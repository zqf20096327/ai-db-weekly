🧭 简介解读层（AI·证据行可回查）

将 PostgreSQL 与 Patroni 打包的 Docker 镜像，用于搭建 HA 集群

综述（解读层）

Spilo 是 Zalando 开源的 Docker 镜像，将 PostgreSQL 与 HA 模板 Patroni 捆绑在一起；多个以相同 etcd 地址和集群名启动的 Spilo 实例可组成 HA PostgreSQL 集群。需要外部配置负载均衡器指向主节点，项目不定期发布镜像，官方建议自行从源码构建。构建时可通过 --build-arg 调整 PostgreSQL 版本、是否含 perl、是否精简为仅 Kubernetes 可用等。

  • 镜像内捆绑 PostgreSQL 与 Patroni，多实例配合相同 etcd 地址可组成 HA 集群
  • 镜像发布于 ghcr.io，提供 linux/amd64 与 linux/arm64 架构
  • 通过环境变量配置，支持 WITH_PERL、PGVERSION、DEMO、TIMESCALEDB 等构建参数

适用场景（解读层）

  • 需要基于 Docker 部署高可用 PostgreSQL 集群的团队
  • 在 Kubernetes 环境中配合 Helm chart 或 Postgres operator 供给 PostgreSQL 集群
  • 需要自建含 TimescaleDB 或多版本 PostgreSQL 的定制镜像
