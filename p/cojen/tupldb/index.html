Java 低层嵌入式键值数据库，提供事务、锁与 B-tree 索引。

综述（解读层）

TuplDB 是一个用 Java 编写的低层嵌入式键值数据库，通过 DatabaseConfig 打开实例，管理一组有序的 byte[] 键到 byte[] 值的索引。它提供事务、记录级锁、死锁检测、游标、复制与加密等功能，不 impose 数据结构或编码，应用需自行编码数据，也可作为实现高层 SQL 或 NoSQL 数据库的底层。

  • 支持事务、记录级锁、可升级锁与死锁检测
  • 索引为有序 byte[] 键值映射，支持游标、视图、过滤与排序
  • 支持持久化模式配置、压缩、加密与复制

适用场景（解读层）

  • 作为应用内嵌的键值存储直接使用
  • 作为实现关系型 SQL 或 NoSQL 数据库的底层存储引擎
  • 需要事务与并发控制的自定义数据管理场景
