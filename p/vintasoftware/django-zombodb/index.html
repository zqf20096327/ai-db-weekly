基于 ZomboDB Postgres 扩展的 Django 与 Elasticsearch 集成库

综述（解读层）

django-zombodb 通过 ZomboDB Postgres 扩展将 Django 模型与 Elasticsearch 同步，同步发生在事务时刻，查询可在 queryset 上调用 search 方法完成。使用时需在模型中添加 SearchQuerySet 与 ZomboDBIndex，并在迁移首操作加入 ZomboDBExtension，且要求迁移用的 Postgres 用户为 SUPERUSER。支持 Python 3.5-3.7 与 Django 2.0-2.2，由 Vinta Software 维护。

  • 模型数据在事务时刻与 Elasticsearch 同步
  • queryset 提供 query_string_search 等方法直接执行 Elasticsearch 查询
  • 通过 ZomboDBIndex 与 ZomboDBExtension 操作集成 Django 迁移流程

适用场景（解读层）

  • 在 Django 项目中对模型字段建立 Elasticsearch 全文检索索引
  • 在现有 queryset 过滤结果上执行 Elasticsearch 查询字符串搜索
  • 需要随数据库事务自动同步搜索索引的应用
