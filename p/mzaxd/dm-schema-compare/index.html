🧭 简介解读层（AI·证据行可回查）

针对达梦(DM8)数据库的结构差异对比与同步 SQL 生成工具

综述（解读层）

该工具用 Python 连接两个达梦 DM8 数据库，提取模式、表、字段、索引信息并生成差异对比，输出含 5 个工作表的 Excel 报告，可在 Streamlit 界面勾选生成并执行同步 SQL。支持 legacy 单源端多目标端与 dual 多源端多目标端两种配置模式，并内置长度反向同步逻辑，避免目标端临时扩长的字段被改短。运行需 dmPython 驱动和具备查询权限的数据库账户。

  • 自动提取两端数据库的模式、表、字段、索引并生成 Excel 对比报告（含汇总、模式、表、字段、索引 5 个工作表）
  • 生成的同步 SQL 按依赖排序，Streamlit 界面中可勾选执行并按「执行端」列自动路由连接
  • 提供长度反向同步机制：目标端字段被临时扩长时生成在源端执行的扩长 SQL，部署脚本不含反向项

适用场景（解读层）

  • 对比测试环境与生产环境的达梦数据库表结构与索引差异，生成部署所需的同步 SQL
  • 多库多实例场景下通过 dual 模式同时对比多对源端/目标端连接
  • 生产字段因数据超长被临时扩长后，反向将变更同步回源端以保持结构一致
