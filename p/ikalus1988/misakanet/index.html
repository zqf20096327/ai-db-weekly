🧭 简介解读层（AI·证据行可回查）

基于 Git 仓库的 AI 编程代理故障记忆库，通过 MCP 提供证据分级修复经验检索

综述（解读层）

MisakaNet 是一个面向 AI 编码代理的故障恢复知识库：每条修复经验（lesson）都是仓库中的 Markdown 文件，按 E0–E4 证据等级分级，检索使用基于 Python 标准库的 BM25，托管端点在无匹配时可选用 bge-m3 语义回退（可用 MISAKANET_SEMANTIC=0 关闭）。代理经 MCP 搜索命中则返回经验文件与等级，未命中返回 no_match 及可提交的 intake 表单。仅覆盖已收录的故障，intake 队列为待处理瓶颈。

  • 提供本地 stdio MCP 服务（pip install misakanet，含 11 个工具）与托管 MCP 端点（8 个工具，匿名读取），支持 Claude Code、Codex、DeepSeek Harness 等多客户端安装方式
  • 经验条目按 E0–E4 五级证据分级；E4 需两个不同客户端实际检索观察到，无法由单方文件声明，CI 会核验声明的等级分布
  • 发布 267 查询检索评测数据（语义回退 R@1 0.446、no_match 0.453）及可下载、带 SHA-256 与逐文件许可的版本化语料包

适用场景（解读层）

  • AI 编码代理在开发或 CI 中遇到已收录的故障时，检索并应用先前已验证的修复步骤
  • 通过 intake 流程提交 no_match 未命中的故障，补充语料供后续代理检索
  • 基于公开下载的语料包与评测脚本，离线运行检索或复现基准测试
