自托管的 OpenAI API 用量实时监控 Web UI 与数据库

综述（解读层）

tokmon beam 是一个自托管工具，通过 Web UI 与 Postgres 数据库监控程序的 OpenAI API token 用量。它与 CLI 工具 tokmon 配合：在程序调用前加 tokmon 命令并指定 --beam 地址，用量数据即存入数据库并实时显示。安装依赖 Docker，通过 python3 tool.py 启动 stack。README 注明其为调试工具，处于 alpha 阶段，可能有破坏性变更。

  • 实时 Web UI 用于查看 OpenAI API 用量数据，基于 Websocket 更新
  • 将 tokmon 的 JSON 数据存储到 Postgres 数据库（本地或远程，通过 .env 配置）
  • 支持从 Web UI 将数据导出为 JSON，运行于 localhost

适用场景（解读层）

  • 追踪应用或脚本中不同流程的 OpenAI token 用量与开销
  • 开发阶段调试 OpenAI API 调用
  • 在本地或远程 Postgres 中存档 tokmon JSON 数据
