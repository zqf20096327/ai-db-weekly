Oracle RMAN 的 SBT 驱动，通过 SFTP 将备份集读写到任意 SSH 服务器

综述（解读层）

LibobkSFTP 实现 RMAN SBT API V2，以 SFTP 客户端方式在远程 SSH 服务器上列出和传输备份集，使 RMAN 备份恢复不依赖本地存储或第三方软件。认证仅用 SSH 密钥交换，静态链接 LIBSSH2 和 OpenSSL，无需额外代理。通过 OB_SERVER、OB_USER、OB_PATH 等环境变量配置通道。由于 SBT API 非公开，接口基于逆向工程，作者提示使用风险自负。

  • 实现 SBT API V2，支持多通道且不限传输速率
  • 认证仅使用 SSH 密钥交换，远程服务器只需持有公钥且无法回连数据库服务器
  • 静态链接 LIBSSH2 与 OpenSSL，无需代理或第三方软件

适用场景（解读层）

  • 无本地存储或共享存储时将 Oracle RMAN 备份集写入远程 SSH 服务器
  • 从远程 SSH 服务器恢复数据库备份
  • 通过 ssh 命令列出远程备份片并生成 CATALOG 脚本填充恢复目录

It is a SBT driver for ORACLE® RMAN allowing to backup and restore database from any SSH server. The transfer protocol is highly secure using SFTP over SSH2. Thus, you can backup the database anywhere
