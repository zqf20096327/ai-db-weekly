综述（解读层）

Gridix 是一款用 Rust 编写的桌面数据库管理工具，支持 SQLite、PostgreSQL 和 MySQL/MariaDB，面向偏好键盘操作的数据库使用者。其交互采用作用域感知的键盘优先模型，以 hjkl 在侧边栏、数据表格和 SQL 编辑器间导航，并提供应用内学习指南（F1）。查询执行提供类型化入口，PostgreSQL 与 MySQL 支持服务端取消请求，SQLite 不承诺中断运行中的语句。可通过 AUR、Homebrew、Nixpkgs 安装，源码构建使用 nightly 工具链，许可证为 Apache 2.0。

  • 支持 SQLite、PostgreSQL、MySQL/MariaDB 三类数据库的统一界面
  • 提供 Helix/Vim 风格导航，焦点区域通过 Tab/Shift+Tab 流转
  • 包含凭据加密、SSH 隧道、SSL/TLS 连接，以及 ER 图、数据导入导出、内置主题等功能

适用场景（解读层）

  • 使用 hjkl 键位浏览、编辑数据表并快速执行 SQL
  • 为新手提供应用内学习路径（SQLite 示例 + F1 学习指南）
  • 通过 SSH 隧道或 SSL/TLS 连接管理远程数据库
