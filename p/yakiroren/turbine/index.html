基于 SQLite 的 Go 持久化工作流引擎，单二进制无外部依赖

综述（解读层）

Turbine 是一个面向 Go 开发者的持久化工作流引擎，用 SQLite 存储执行状态，崩溃后可从断点恢复。核心机制包括步骤记录中间结果、指数退避重试、可跨重启的持久化 Sleep、队列并发控制与 cron 调度，另提供 Dashboard UI。安装通过 go get 引入，examples/ 目录下每个功能都有可运行示例。

  • 步骤记录中间结果，崩溃或重启后从上次位置恢复执行
  • 队列支持并发控制、优先级、速率限制和分区，内置 cron 调度器
  • 提供 Send/Receive 工作流间通信、事件信号、超时取消与自动垃圾回收

适用场景（解读层）

  • 需要跨进程崩溃恢复的后台任务与长流程编排
  • 按 cron 周期调度的定时任务
  • 多工作流间需要事件通信或等待外部事件到达的场景
