dtle 是 MySQL 数据传输与复制工具，支持分布式部署

综述（解读层）

dtle（Data-Transformation-le）是爱可生公司出品的 MySQL 数据传输/复制工具，也是其云树·DTS 产品的开源版本。README 说明它可在传输中压缩数据、支持双向同步与云间 RDS 复制，并以分布式服务方式部署。文档部分目前仅提供简体中文版本，英文文档标注为即将提供。

  • 支持在数据传输过程中进行压缩
  • 支持双向数据同步，可用于 master-master MySQL 架构
  • 可在云 RDS 之间复制数据，支持分布式部署

适用场景（解读层）

  • MySQL 实例间的数据迁移与复制
  • master-master 架构的双向同步场景
  • 跨云 RDS 的数据复制场景
