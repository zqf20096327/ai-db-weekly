🧭 简介解读层（AI·证据行可回查）

基于 MySQL 协议的分库分表中间件，提供分布式事务与复杂查询支持。

综述（解读层）

dble 是由爱可生公司维护的开源 MySQL 分库分表中间件，其云树 Sharding 产品的开源版本，基于 MyCat 衍生并取消多数据库支持、专注 MySQL。应用可不改代码接入，支持 SQL92 与 MySQL 方言、两阶段提交分布式事务（普通或 XA 模式，XA 依赖 MySQL 5.7），并可集群部署避免单点故障。

  • 兼容 MySQL 协议，多数情况下可替换 MySQL 而无需修改应用代码
  • 支持 SQL 92 标准与 MySQL 方言，含 group by、order by、distinct、join、union 等查询，子查询在 Roadmap 中
  • 提供分布式事务，可选普通模式或依赖 MySQL 5.7 XA 事务的 XA 模式

适用场景（解读层）

  • 业务增长后需要将单一 MySQL 实例拆分为分库分表架构的场景
  • 需要集群部署以避免单节点故障影响业务的 MySQL 应用
  • 涉及分片表与全局表关联查询（ER 关系、复杂查询）的分布式数据访问
