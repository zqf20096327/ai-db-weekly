.NET Core 编写的 Web 端 CodeFirst 代码生成器与在线建表工具

综述（解读层）

WebFirst 由果糖大数据团队基于 .NET Core 和 SqlSugar 开发，在 Web 中以 CodeFirst 方式在线建表并生成实体、UI、API 等代码。可通过数据库导入、在线创建或 SQL 三种方式配置实体，使用 Razor 模版引擎，方案中包含模版、路径、文件名与后缀配置，支持一键生成多个解决方案，并提供 EXE 与 Web 两种部署方式。

  • 支持 MySQL、PGSQL、SQLite、SQL Server、Oracle、达梦等多种数据库
  • 提供数据库导实体、在线建实体、SQL 建实体三种实体配置方式
  • 基于 Razor 模版引擎的模版管理与方案管理，可自定义模版、路径、文件名与后缀

适用场景（解读层）

  • 为数据库表批量生成实体类、数据访问及 API 代码
  • 在 Web 中以 CodeFirst 方式在线建库建表
  • 为大量重复且有共性的功能（如各类 Model）配置模版批量生成代码
