综述（解读层）

SqlSugar 是由果糖大数据团队维护的 .NET 开源 ORM 框架，覆盖 .NET Framework 到 .NET 10，支持 MySql、SqlServer、Oracle、达梦、人大金仓等数十种数据库。开发者无需手写 SQL 即可完成建表、索引和增删改查，并提供跨库查询、多租户、自动分表等机制。文档含中英文版本。

  • 支持 MySql、SqlServer、Oracle、PostgreSQL、MongoDB、达梦、人大金仓、ClickHouse、TDengine 等多种数据库及自定义数据库扩展
  • 提供 BulkCopy 大数据批量写入、按年/月/日等自动分表、跨数据库查询与多租户数据隔离功能
  • 包含联表查询、分页、动态表达式、查询过滤器、ValueObject、UnitOfWork、AOP 等特性

适用场景（解读层）

  • 需要兼容多种数据库（含国产数据库）的 .NET 应用开发
  • SAAS 多租户系统中的租户分库、分表与数据隔离
  • 海量数据写入与分表查询统计场景
