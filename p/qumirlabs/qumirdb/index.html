基于 LLVM/JIT 编译 SQL 内核、直接对 Parquet 文件执行分析查询的数据库引擎

综述（解读层）

QumirDB 是一个在 Parquet 文件上运行分析型 SQL 的编译式查询引擎。查询表达式与算子计算经 Qumir 编译为机器码或 WebAssembly 后执行；原生路径面向命令行与本地应用，浏览器路径基于 OPFS 数据集运行。通过 CREATE MODULE 可注册 Rust 模块并与查询内核一同经 LLVM 优化。本地构建见 docs/building.md。

  • 支持原生机器码与 WebAssembly 两种内核编译目标，浏览器端可基于 OPFS 数据集运行
  • 提供分布式执行：qdbd 守护进程按节点切分任务图并以 sink/source 对流式交换数据行
  • 支持 CREATE MODULE 注册 Rust UDF，其 LLVM bitcode 与查询内核链接后联合优化

适用场景（解读层）

  • 在本地或浏览器中直接对 Parquet 文件执行过滤、连接、聚合与排序查询
  • 多表连接、复杂连接条件与关联子查询等复杂分析查询
  • 用 Rust 编写数值模型、解析器等域逻辑并从 SQL 中调用
