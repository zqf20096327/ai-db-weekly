基于 Protobuf 与协程的 Android/JVM 键值存储库

综述（解读层）

PufferDB 是一个运行于 Android 和 JVM 的键值存储库，使用 Protobuf 二进制格式序列化数据。其核心模块不依赖 Android Context，适合希望保持纯 Kotlin 数据模块的项目。API 类似 SharedPreferences，写操作通过 StateFlow 与 Mutex 异步保存；支持通过 coroutines 和 rxjava 模块调用。支持的类型为基本类型及其列表。

  • 支持 Android 与 JVM 平台，核心模块无需 Android Context
  • 写入操作经 ConcurrentHashMap 缓存、StateFlow 与 Mutex 异步保存
  • 提供 Coroutines 与 RxJava 包装模块及扩展函数

适用场景（解读层）

  • Android 应用中替代 SharedPreferences 的键值存储场景
  • 纯 Kotlin/JVM 数据模块中需要本地键值持久化
  • 使用协程或 RxJava 的响应式读写访问
