综述（解读层）

frauddb 是一款 Android 应用，读取 /data/misc/user/0/securitycenter/ 下的 fraud_detection_data.db（由 com.miui.securitycenter 的涉诈检测服务写入），将截图、录屏、通话、应用安装等记录整理为按天分组的时间线。面向想查看自己设备上这些不显示在系统设置中记录的用户。需 root 或手动复制 db 文件；通过自实现的 JavaScript SQLite 解析器读取 b-tree，支持删除记录恢复；不上传数据、权限可全部拒绝。

  • 支持时间线、表格、统计、导出（TXT/JSON/CSV）与媒体配对等查看方式
  • 通过扫描空闲页与页内空闲块列出已删除但仍有残留的记录
  • 默认开启敏感信息打码，可临时点显；支持多份数据集按内容去重合并

适用场景（解读层）

  • 查看自己小米设备上反诈组件记录的事件时间线
  • 恢复数据库中已被滚动清理删除但仍未覆盖的历史记录
  • 用号码 MD5 比对还原通话对应的明文号码与联系人
