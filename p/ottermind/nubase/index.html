自托管的 AI 原生后端服务，Agent 通过 MCP 直接操作数据库、Auth、存储与部署

综述（解读层）

Nubase 是一个 Apache 2.0 协议的开源后端平台，面向 AI 编码代理和自托管团队，将数据库、Auth、存储、Functions、AI Gateway、Memory 和 cron 集成在单一服务中。它基于 Java 实现，提供 PostgREST 兼容的 REST API，每个项目对应独立 PostgreSQL 数据库，代理通过 MCP 工具完成建表、部署边缘函数、发布前端和写入记忆。需要 Java 17、Maven、Docker 与 Node.js 运行；README 注明暂不支持 Realtime。

  • 提供八项能力模块：Database、Auth、Storage、Assets、Functions、AI Gateway、Memory、cron，打包为单一 Docker 镜像自托管
  • 每个项目分配独立 PostgreSQL，支持 RLS、JWT 双令牌模型、S3/R2 兼容存储，Memory 基于 pgvector + 全文检索实现混合检索
  • 内置 MCP 接口（nubase_cli），支持 Claude Code 和 Codex 通过 install-skills 命令完成代理连接与授权

适用场景（解读层）

  • 用 Claude Code、Codex 等 AI 编码代理生成应用并直接完成后端建模、函数部署与前端发布
  • 需要在一个自托管控制平面中运行多个相互隔离的项目数据库
  • 为代理式应用构建持久化记忆、事实提取与混合检索能力
