将 SQL 语句转换为 Mongo 查询或聚合管道的 JavaScript 库

综述（解读层）

NoQL 是一个 npm 包，读取 mySQL 或 Postgres 语法的 SQL 语句，生成兼容 Mongo 3.6 及以上版本的 find 查询或聚合管道，输出包含 type（query 或 aggregate）及查询组件的对象，供 MongoDB NodeJS Driver 的 MongoClient 使用。提供在线 playground 与供 Claude、Cursor 等代理使用的 Agent Skill。不支持 Over、CTE、Pivot、Union 等语句。

  • 支持 mySQL 和 Postgres 语法，生成兼容 Mongo 3.6+ 的查询
  • 简单查询输出 query 对象，含 group by 等语句输出聚合管道对象
  • 提供在线文档、playground 及面向 AI 代理的 Agent Skill

适用场景（解读层）

  • 将现有 SQL 查询转换为 MongoDB 查询或聚合管道
  • 在 NodeJS 应用中通过 MongoClient 执行生成的 Mongo 查询
  • 供 AI 编码代理学习与生成 NoQL 语法
📖 README 首段存档原文 · 程序抽取

NoQL Converts SQL statements to Mongo find statements or aggregation pipelines. NoQL supports mySQL and Postgres Syntax, and generates Mongo 3.6 or greater compatible queries.
