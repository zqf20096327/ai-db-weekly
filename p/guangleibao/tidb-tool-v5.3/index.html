TiDB 实验脚本集，用 tiup 在 EC2 上部署单机或多机集群

综述（解读层）

该项目是一组用于实验目的的 Shell 脚本，面向在 AWS EC2 上搭建 TiDB 环境的使用者。包含 general-lab（单机 all-in-one 集群、无副本）、tidb-lab（单机部署 2 个 TiDB Server）和 tikv-lab（跨两台 EC2 的混合集群、3 个 TiKV）三个文件夹，均依赖无密码 sudo 与 tiup 工具，并提供编号编排的安装、启停、检查、连接及销毁脚本。

  • 提供三个实验目录，分别部署单机 all-in-one、单机双 TiDB Server、跨两台 EC2 的 3 TiKV 混合集群
  • 每个目录统一提供 00/01/02 安装、03/04 启停、check-cluster.sh 检查、MySQL 接口连接及 destroy-all.sh 销毁脚本
  • 当前脚本按 AWS 环境设计，需 EC2 实例具备 passwordless sudo 与相应服务角色

适用场景（解读层）

  • 在 AWS EC2 上快速搭建用于实验的 TiDB/TiKV 集群环境
  • 需要单机无副本的 all-in-one 集群或双 TiDB Server 布局的演示
  • 通过 MySQL 接口脚本连接不同节点的集群实验
