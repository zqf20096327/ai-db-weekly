🧭 简介解读层（AI·证据行可回查）

终端数据库客户端，内置多数据库驱动，展示SQL并经MCP向AI代理提供只读访问。

综述（解读层）

tql 是一个用 Rust 编写、以单文件二进制分发的终端数据库客户端，支持 MySQL、MariaDB、PostgreSQL、SQL Server、SQLite、DuckDB、libSQL/Turso、ClickHouse、Snowflake、Redis/Valkey，以及遵循相应协议的托管数据库（Neon、Supabase、PlanetScale 等）。界面上可排序、过滤并查看行及关联记录，SQL 面板始终显示生成当前结果的语句，过滤值以绑定方式呈现。内置的 MCP 服务器让 AI 代理通过同一代码路径只读访问数据，所有语句进入共享历史。编辑与删除需输入 :w 确认提交；连接可标记只读。安装无需配置与运行时，Linux 版为静态链接。

  • SQL 面板显示当前界面结果对应的语句，排序与过滤会生成相应的 order by / where，且过滤值采用参数绑定
  • 内置 MCP 服务器，AI 代理仅具只读权限，代理与用户命令行共用同一引擎与共享语句历史
  • 单文件二进制分发，所有数据库驱动内置，Linux 上静态链接，首次运行自动创建配置目录

适用场景（解读层）

  • 在终端中浏览与编辑 MySQL/PostgreSQL/SQLite 等多种数据库及托管服务上的数据
  • 通过 MCP 为本地运行的 AI 代理提供数据库的只读访问
  • 需要查看界面对应 SQL、以确认后方式批量编辑生产库数据的开发与运维场景
