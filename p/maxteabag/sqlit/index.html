综述（解读层）

sqlit 是一个用 Python 和 Textual 构建的 TUI SQL 客户端，面向希望在终端中连接和查询数据库的开发者。它支持 PostgreSQL、MySQL、SQLite、SQL Server 等 20 多种数据库，通过 pipx 安装，直接运行 sqlit 即可在界面中选择连接，无需 CLI 配置；缺失的 Python 驱动由内置向导辅助安装。

  • 支持 PostgreSQL、MySQL、SQLite、SQL Server、Oracle、DuckDB、ClickHouse 等 20 多种数据库
  • 提供连接管理器、SSH 隧道、Docker 容器自动发现，密码存于操作系统 keyring
  • 查询编辑器支持语法高亮、Vim 风格按键与自动补全，结果支持模糊过滤搜索

适用场景（解读层）

  • 在终端中浏览表、视图、索引、触发器等数据库对象并执行 SQL 查询
  • 通过 Docker 自动发现或 Azure/AWS/GCP CLI 连接本地容器或云端数据库
  • 通过 sqlit -c 命令行模式在脚本或管道中执行 SQL
