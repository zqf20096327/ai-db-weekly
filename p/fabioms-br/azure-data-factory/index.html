Azure Data Factory ETL/ELT 视频教程合集，涵盖数据复制、迁移与集成

综述（解读层）

该仓库是作者围绕 Azure Data Factory 整理的视频教程索引，内容以葡萄牙语呈现，共 18 个主题条目。每个条目包含操作说明与对应视频链接，覆盖从互联网复制 CSV 数据、迁移 SSIS 包、读取 XML 发票文件、连接本地资源、使用 Data Flow 与 Power Query 合并表、Web Scraping、SAP HANA 数据复制到循环执行 Pipeline 等场景。附有 SharePoint 权限配置的代码片段与 Microsoft Learn 参考链接。适用于希望按主题逐步学习 ADF 各项功能的数据从业者；仓库本身不含可运行的完整工程代码，学习需配合视频观看。

  • 包含 18 个主题的视频教程索引，覆盖数据复制、SSIS 包迁移、XML/JSON 文件处理与 Pipeline 编排
  • 涉及 Self-Hosted Integration Runtime 连接本地资源及 Azure DevOps 版本控制集成
  • 附 SharePoint 加载项权限请求的配置代码片段及 Microsoft Learn 文档链接

适用场景（解读层）

  • 学习 Azure Data Factory 各组件（Linked Services、Pipelines、Datasets、Data Flow）的基本操作
  • 参考将本地 MS Access、SAP HANA、SharePoint 等数据源数据复制到 Azure 存储或 SQL 数据库的流程
  • 了解 SSIS 包向 Azure Data Factory 迁移的路径
