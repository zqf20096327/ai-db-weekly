Dart 语言的 MySQL 驱动，支持 Flutter 与服务端

综述（解读层）

mysql1 是面向 Dart 的 MySQL 驱动，源自 SQLJocky 的分支，可在 Flutter 和服务器端运行。API 参照 package:postgres 设计，支持参数化查询、批量执行及自增主键读取。参数在客户端绑定并转义后以单条查询发送，无服务端预编译；因依赖 socket，不支持 Flutter Web。

  • 支持参数化查询与多组参数批量执行（queryMulti）
  • 插入结果可读取自增列生成的 insertId
  • 客户端绑定参数并转义，行为对齐 MySQLdb、libmysqlclient 等主流驱动

适用场景（解读层）

  • Flutter 移动/桌面应用连接 MySQL 数据库
  • Dart 服务端应用执行查询、插入、更新操作
  • 需要读取自增主键或批量写入数据的场景
