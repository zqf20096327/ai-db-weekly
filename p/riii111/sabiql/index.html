🧭 简介解读层（AI·证据行可回查）

Rust 编写的终端数据库 TUI，采用 Vim 键位与先预览后执行机制

综述（解读层）

sabiql 是一个基于 Rust 和 ratatui 的终端界面工具，用于浏览、查询和编辑 PostgreSQL、MySQL 与 SQLite 数据库，底层调用各数据库的原生 CLI。它采用 Vim 风格键位，编辑与删除操作在执行前展示 SQL 及风险等级，并提供只读模式在客户端层面阻止写入。适合习惯 Vim 操作、需要在终端内管理多种数据库的开发者。Windows 支持为实验性，SQLite 不支持 ER 图。

  • 支持通过模糊搜索浏览表结构、约束、索引、外键、触发器与 DDL
  • 编辑和删除前显示 SQL 语句及风险等级，只读模式（Ctrl+R）在客户端层面阻止写入
  • 支持 SQL 补全与查询历史、执行计划查看，以及生成 PostgreSQL/MySQL ER 图

适用场景（解读层）

  • 需要在终端内浏览、查询和编辑 PostgreSQL、MySQL 或 SQLite 数据
  • 习惯 Vim 键位并希望在数据修改前预览 SQL 与风险等级
  • 需要查看查询执行计划或生成 ER 图辅助分析表关系
