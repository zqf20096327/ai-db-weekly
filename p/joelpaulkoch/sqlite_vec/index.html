sqlite-vec 向量扩展的 Elixir 封装库

综述（解读层）

该包为 Elixir 提供 sqlite-vec（SQLite 向量处理扩展）的封装，通过 Hex 安装后自动从 GitHub releases 下载预编译的扩展库，并提供 Float32、Int8 和 Bit 向量的结构体及自定义 Ecto 类型。面向需要在 SQLite 中处理向量的 Elixir 开发者。限制：Ecto 无法直接创建 Int8/Bit 向量，须用 SQL；vec_each 与 vec_quantize_i8 未实现。维护者已停止在 hex.pm 发布新版本，后续版本将由官方 sqlite-vec 仓库发布。

  • 从 GitHub releases 下载预编译的 sqlite-vec 可加载扩展库，经 SqliteVec.path/0 提供加载路径
  • 提供 Float32、Int8、Bit 向量的结构体及自定义 Ecto 类型
  • 可配合 Exqlite 或 ecto_sqlite3 的 Ecto.Repo 加载使用

适用场景（解读层）

  • 在 Elixir/Ecto 项目中通过 SQLite 存储和查询向量数据
  • 使用 Exqlite 时加载 sqlite-vec 扩展以启用向量运算
  • 结合 Ecto 类型在现有 Ecto.Repo 中读写 Float32 向量
📖 README 首段存档原文 · 程序抽取

A wrapper to use sqlite-vec, a SQLite extension for working with vectors, in Elixir. The configured version of the precompiled loadable library will be downloaded from the GitHub releases.
