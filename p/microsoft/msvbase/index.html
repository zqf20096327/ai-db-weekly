🧭 简介解读层（AI·证据行可回查）

在 PostgreSQL 中集成高维向量索引、统一支持相似检索与关系运算的系统。

综述（解读层）

MSVBASE 是微软开源的系统，将高维向量索引以少量代码改动集成进 PostgreSQL，通过统一查询执行引擎支持向量与标量数据上的近似相似检索及关系运算混合查询。兼容 PostgreSQL 语法与协议，支持 hnsw 和 sptag 索引、L2 与内积距离、TopK+Filter、距离阈值过滤、多向量列查询及带阈值的向量相似 Join；向量以 float array 存储，通过 Docker 脚本构建运行。

  • 兼容 PostgreSQL 语法与协议，通过 create index 支持 hnsw 与 sptag 向量索引及 L2/内积距离计算
  • 提供 TopK+Filter、距离阈值过滤、多向量列加权查询、带阈值的向量相似 Join 等 SQL 查询能力
  • 提供 Docker 脚本（dockerbuild.sh/dockerrun.sh）完成构建与运行

适用场景（解读层）

  • 需要在 SQL 中同时使用向量相似检索与标量条件过滤的应用
  • 基于向量相似度的 TopK、阈值检索及表间相似 Join 查询
  • 已有 PostgreSQL 环境，希望以扩展方式存储和检索向量的场景
