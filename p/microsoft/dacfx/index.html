微软 DacFx 系列库与工具，用于 SQL 数据库声明式开发与 dacpac/bacpac 包部署

综述（解读层）

本仓库是微软 DacFx 相关组件的入口，包含 SqlPackage 命令行工具、DacFx .NET 库、Microsoft.Build.Sql SQL 项目 SDK 及系统数据库 dacpac 包，支持将 T-SQL 项目编译为 dacpac 并发布到 SQL Server 或 Azure SQL 数据库，覆盖 SQL Server 2008 至 2025 版本。面向需要数据库生命周期管理和跨环境迁移的开发者。仓库主要承载相关组件的问题反馈分诊，部分组件源码在其他仓库。

  • SqlPackage 是跨平台命令行工具，可通过 dotnet tool 安装，用于创建和部署 .dacpac/.bacpac 包
  • Microsoft.Build.Sql SDK 将 SQL 项目中的 T-SQL 编译为 dacpac，配套提供项目模板 NuGet 包
  • 提供 SQL Server、Azure SQL、Synapse、Fabric 等系统数据库对象的 dacpac NuGet 包，覆盖 SQL Server 2008 至 2025

适用场景（解读层）

  • 以声明式 SQL 项目方式管理数据库架构，并通过 CI/CD 或命令行发布部署
  • 跨 SQL 版本与环境（SQL Server、Azure SQL、Synapse、Fabric）进行数据库包迁移
  • 校验两个 dacpac 包（含部署脚本与 SQLCMD 变量）是否一致
