🧭 简介解读层（AI·证据行可回查）

以 PostgreSQL 扩展形式实现数据库内持久化执行，用 SQL 定义可断点续跑的工作流

综述（解读层）

pg_durable 是微软发布的 PostgreSQL 扩展（支持 PG 17/18），允许在数据库内用 SQL 定义持久化工作流。运行时以图结构执行 SQL 步骤并逐步检查点记录状态，崩溃、重启或步骤失败后可从最近检查点恢复。适合后端/数据工程师与 DBA；要求环境可安装扩展并运行后台 worker，模型仅限 SQL 步骤与 HTTP 调用。

  • 以 PostgreSQL 扩展运行，无需 Redis、Temporal 等外部服务，状态持久化到数据库并可跨崩溃与重启恢复
  • 提供 ~> 和 |=> 等组合算子定义工作流，支持调度、条件、并行执行原语及 df.http() 外部调用
  • 通过 df.instances 等表查询运行状态，复用数据库自身的认证与备份体系；含 restricted 默认 HTTP 策略

适用场景（解读层）

  • 向量嵌入流水线：分块、调用嵌入 API、写入 pgvector
  • 摄取管道的暂存、去重、转换与发布，以及按行/文档/批次的持久化处理
  • 定时维护与扇出聚合：膨胀检测、审批等待、并行查询后合并结果
