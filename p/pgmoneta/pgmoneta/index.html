PostgreSQL 备份/恢复工具，支持全量与增量备份及时间点恢复

综述（解读层）

pgmoneta 是面向 PostgreSQL 集群的备份与恢复解决方案，采用进程模型与共享内存架构，基于 libev 处理网络交互。它支持全量和增量备份（增量需 PostgreSQL 14+）、时间点恢复、WAL 流传输，并提供 Prometheus 监控端点与 Web 控制台。增量备份的 tablespace 支持仅限 PostgreSQL 17+。可通过 PGDG YUM 仓库安装或从源码编译，运行于 Linux 与 BSD 平台。

  • 支持全量与增量备份、时间点恢复、WAL 流传输与热备
  • 备份支持 gzip/zstd/lz4/bzip2 压缩与 AES 静态加密，客户端与服务端连接使用 TLS v1.2+
  • 提供 Prometheus 指标端点、Web 控制台、pgmoneta-cli/pgmoneta-mcp 远程管理及 systemd 集成

适用场景（解读层）

  • PostgreSQL 集群的定期备份、增量备份与灾难恢复
  • 需要时间点恢复（PITR）和热备副本的生产环境运维
  • 基于 Prometheus 的备份状态监控与指标采集
