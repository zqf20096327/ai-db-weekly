用 Docker Compose 搭建 Laravel 本地开发环境的模板项目

综述（解读层）

该项目通过 Docker Compose 编排 Nginx、PHP、MySQL、phpMyAdmin 及 PostgreSQL/pgAdmin 配置，用于在本地运行 Laravel 应用。使用者克隆仓库后执行 composer install、构建并启动容器即可访问。README 附有 Medium 文章和 YouTube 视频教程链接，适合需要容器化 Laravel 本地开发环境的开发者参考。

  • 提供基于 Docker Compose 的 LEMP 栈配置（Nginx、MySQL、PHP、phpMyAdmin）
  • 支持在 docker-compose.yml 中切换启用 MySQL 或 PostgreSQL（含 pgAdmin）
  • 可通过 docker-compose exec app php artisan 执行 Laravel 命令

适用场景（解读层）

  • 为 Laravel 项目搭建容器化本地开发环境
  • 团队需要统一开发环境配置时作为模板使用
  • 在本地方便切换 MySQL 或 PostgreSQL 数据库进行开发
