整合 Kafka、TiDB、Iceberg、Trino 等引擎的湖仓查询路由平台（应用代码）

综述（解读层）

这是一个云原生分布式分析平台的应用代码仓库，整合 Kafka、Vitess、TiDB、Iceberg、Trino、Redshift、StarRocks 七类引擎的连接器、管道、查询路由与参考 SQL。面向需要统一管理流式接入、OLTP/OLAP 负载与联邦查询的团队。仓库仅含应用层，不含 Terraform 等基础设施配置，需自备各引擎集群。

  • 提供 `LakehouseEngine` Python 库和 `lakehouse` CLI，CLI 仅做参数解析并输出 JSON 或状态，分析逻辑位于 engine.py
  • 按负载路由到不同引擎：Kafka 流式接入、Vitess 分片 OLTP、TiDB HTAP、Trino 跨目录联邦查询、StarRocks 实时 OLAP、Redshift 仓库 OLAP
  • 通过 `platform.yaml` 配置集群端点，支持 `LAKEHOUSE_` 前缀加 `__` 分隔的环境变量覆盖，附 Mermaid 架构图与初始化 SQL

适用场景（解读层）

  • 需要统一入口管理多引擎数据管道与查询路由的湖仓平台开发
  • 跨 Iceberg、Trino 等多目录的联邦 SQL 查询应用
  • 运维调试各引擎连接器与初始化表结构、种子数据
