Go 语言知识点合集，收录 init 与 go:generate 等小技巧示例

综述（解读层）

该仓库收集 Go 语言的使用知识点（tidbits），以可运行的示例形式呈现，覆盖 init() 函数与 go:generate 魔法注释两例，分别用 go run 和 go generate 命令演示，并引用 Gorm postgres dialect 导入 lib/pq 作为 go:generate 的实例。适用于想了解这些语言特性用法的 Go 开发者。README 未提供系统文档，内容以条目式罗列为主。

  • 提供 init() 函数的示例代码，可通过 go run main.go 运行
  • 提供 go:generate 魔法注释示例，可通过 go generate 命令执行
  • 以 Gorm postgres dialect（导入 lib/pq）作为 go:generate 的引用示例

适用场景（解读层）

  • 查阅 init() 函数的用法示例
  • 了解 go:generate 注释的运行方式
  • 参考通过导入驱动包（如 lib/pq）配合 Gorm 使用 postgres dialect 的写法
