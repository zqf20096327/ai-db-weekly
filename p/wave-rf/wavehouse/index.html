🧭 简介解读层（AI·证据行可回查）

面向 ClickHouse 的实时 API 网关，单二进制提供摄入、查询与 SSE 推送。

综述（解读层）

WaveHouse 是一个用于 ClickHouse 的 API 网关，用 Go 编写，以单二进制运行，外部依赖仅 ClickHouse。它提供基于 WAL（内嵌 NATS JetStream）的异步批量写入、对 system.columns 的 schema 校验、结果缓存、SSE 实时推送，以及基于 JWT 的按表/按角色列与行策略。适用于构建面向用户的分析应用的团队。项目当前处于 alpha 阶段，API 与配置格式在版本间可能变更且无迁移路径。

  • 异步摄入：写入返回 200 后由内嵌 NATS JetStream 支持的后台批量刷入，含 schema 校验、可选 ID 去重及被拒行的死信队列
  • 查询支持进程内 Ristretto 或共享 Redis 的结果缓存、singleflight 合并，以及参数化 SQL 的命名管道端点
  • 原生 SSE 推送（在 ClickHouse 刷入前广播），并为断线/迟到客户端提供 JetStream 补齐；访问策略为按表、按角色的列/行策略，定义于可热重载的设置目录

适用场景（解读层）

  • 为前端应用提供经过行/列权限控制的 ClickHouse 查询接口
  • 高频事件写入场景，需要批量落库、幂等去重与失败行死信处理
  • 通过 SSE 将新写入数据实时推送给浏览器或客户端
