基于 Terraform 在 Kubernetes 中部署和管理 Redis 的模块，封装 Helm 发布流程

综述（解读层）

该模块是一个 Terraform 模块，用于在 AWS EKS、Azure AKS 与 GCP GKE 集群中部署 Redis。它通过 helm_release 与 kubernetes_namespace 两个资源实现部署，按指定架构创建 master 与一个或多个 slave，并以 outputs 输出访问端点与凭据；支持自定义命名空间、密码存储到云密钥管理服务、Grafana 监控等配置项。启用 exporter 需先部署 Prometheus/Grafana。适用于以 IaC 方式管理 Redis 部署的运维与平台团队。

  • 通过 helm_release 与 kubernetes_namespace 资源在 EKS/AKS/GKE 集群上部署 Redis master 与 slave，并以 outputs 提供访问端点与凭据
  • 提供命名空间创建、chart 版本（默认 19.6.1）、存储、副本数、自定义 values_yaml 与自定义凭据等输入变量
  • 支持将密码存入 AWS Secrets Manager、Azure Key Vault、GCP Secret Manager 并可配置恢复窗口，可选用 Redis exporter 供 Grafana 监控

适用场景（解读层）

  • 在 AWS EKS、Azure AKS 或 GCP GKE 上以 Terraform 声明式部署带复制的 Redis
  • 需要将 Redis 密码托管到云厂商密钥管理服务的部署流程
  • 需要为 Redis 集群配置 Prometheus/Grafana 指标采集与监控看板的场景
