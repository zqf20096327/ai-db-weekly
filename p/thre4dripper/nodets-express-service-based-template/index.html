Node+TypeScript+Express 服务模板，集成 REST、gRPC、Socket、Cron 与 Redis

综述（解读层）

这是一个基于 Node.js、Express 与 TypeScript/JavaScript 双源码树的服务端项目模板，通过 MasterController 基类统一处理 REST、gRPC、Socket.IO 事件与 cron 任务。支持经 Sequelize 接入多种 SQL 数据库、经 Mongoose 接入 MongoDB，路由、socket、cron、gRPC 模块按文件命名约定自动加载。数据库方言依赖需按需手动安装。

  • 提供 REST、gRPC、Socket.IO、cron 四类处理器的统一 MasterController 基类与 Joi 校验
  • 按命名约定（*.routes / *.grpc / *.socket / *.cron）自动加载模块，Swagger 文档自动生成于 /api-docs
  • 支持 MySQL、PostgreSQL、MariaDB、Sqlite、MSSql、DB2、Snowflake、Oracle 与 MongoDB，含 Redis 双客户端与 Docker 部署

适用场景（解读层）

  • 需要同时暴露 REST 与 gRPC 接口的 Node.js 后端服务
  • 需要 Socket.IO 实时事件与定时任务的服务端项目
  • 基于 Sequelize 或 Mongoose 的多数据库后端脚手架搭建
