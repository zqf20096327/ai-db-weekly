🧭 简介解读层（AI·证据行可回查）

面向 Google Antigravity 的零依赖本地实时 Token 与 API 价值监控面板

综述（解读层）

该项目以只读方式解析 Antigravity 的本地 SQLite（含 WAL 页面）对话数据库，提供实时 Token 用量与计价统计。后端为纯 Python 3 标准库 HTTP 服务，前端为无 CDN 依赖的单文件页面；可选编译为 macOS 菜单栏应用。依赖 Python 3.8+，模型映射与价格需在源码中手动调整，且不含外部网络调用。

  • 以只读 URI 模式读取本地 SQLite/WAL 文件，通过 (mtime_ns, size) 跳过未变更会话，实现毫秒级增量刷新
  • 提供 4 种计价模式、USD/CNY 切换、多时间窗口与自适应粒度趋势图，并可导出 CSV 与 PNG 快照
  • 后端仅用 Python 标准库，前端 HTML/CSS/JS 内嵌无外部请求，所有数据留在 127.0.0.1

适用场景（解读层）

  • 本地查看 Antigravity 会话的 Token 消耗、5 分钟活跃窗口与 tok/min、$/hr 速率
  • 按自定义时间区间或计价口径生成用量汇总并导出 CSV 报表
  • 在 macOS 菜单栏持续显示近 7 天/今日用量摘要与燃烧率
