用 PL/SQL 生成 Excel（xlsx）工作簿的 Oracle 包

综述（解读层）

xlsx_writer-Oracle 是一个 Oracle 数据库内的 PL/SQL 包，用于生成 xlsx 格式的 Excel 工作簿，基于 Office Open XML。它依赖 zipper 包，测试需要 blob_writer 包，采用 GPL v3.0 许可发布。作者主页提供了 sql_to_xlsx 过程的示例，该过程可将 SQL 语句的查询结果转为 Excel 工作表。

  • 提供在 Oracle 数据库内用 PL/SQL 创建 xlsx 工作簿的能力
  • 包含 sql_to_xlsx 过程，用于将 SQL 语句结果生成为 Excel 工作表
  • 基于 Office Open XML 格式

适用场景（解读层）

  • 在 Oracle 数据库中直接生成 xlsx 文件用于导出
  • 将 SQL 查询结果转换为 Excel 工作表
