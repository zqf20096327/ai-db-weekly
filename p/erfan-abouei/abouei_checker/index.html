综述（解读层）

AboueiChecker 是一个用 Go 编写的命令行工具，用于探测后端 HTTP 健康端点、检测宕机与恢复，并在本地 SQLite 中持久化观测与事件记录，同时向可配置的通用 webhook 发送告警。它支持 check 一次性探测与 monitor 持续调度两种模式，配置基于 YAML，密钥通过环境变量引用。README 明确说明尚未发布生产版本，不建议用于生产监控，适合需要自托管健康检查脚本的开发者参考或试用。

  • 支持 check 一次性探测、monitor 持续调度、status/history 只读查询及 TTY 交互式 tui 面板
  • 以 SQLite 持久化观测数据、事件与重试队列，webhook 通知具备至少一次投递与有界重试
  • 配置采用 YAML，密钥经环境变量引用并以脱敏方式处理，拒绝符号链接的配置文件

适用场景（解读层）

  • 通过 cron 或 CI 运行 check 命令做单次健康探测并依据文档化退出码集成到脚本流程
  • 在单机上自托管少量后端端点的持续监控，事件历史存于本地 SQLite
  • 以 JSON 输出对接自动化管道，或用 tui 面板在终端查看实时后端状态
