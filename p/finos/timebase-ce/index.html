面向金融时序数据的开源数据库，兼作实时流消息服务器

综述（解读层）

TimeBase CE 是 FINOS 孵化、由 EPAM Systems 版权持有的开源时序数据库，源自在交易公司商用逾十年的商业版本。它可同时用作传统时序数据库和实时消息/流服务器，数据结构（streams）由用户定义，提供用于数据写入与流式读取的 API。构建需 Java 11+ 和 Gradle，可经 Docker 运行服务端，文档与 CVE 清单见官方渠道。

  • 同时提供时序数据库与实时消息/流服务器两种用途，数据结构（streams）由用户定义
  • 提供用于数据摄取与流式交互的 API，支持 SQL 查询（TimeBase 1.0 起）
  • 支持 Docker、Kubernetes 部署及 REST/WS 访问，提供低延迟 IPC/UDP 模式（topics）

适用场景（解读层）

  • 金融机构时序数据的存储、摄取与流式分发
  • 与其他开源或商业组件组合构建分析应用和数据可视化
  • 在 Docker/Kubernetes 环境中运行时序数据服务
