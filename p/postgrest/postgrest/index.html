🧭 简介解读层（AI·证据行可回查）

为任意 PostgreSQL 数据库自动提供 RESTful API 的服务器

综述（解读层）

PostgREST 是用 Haskell 编写的独立服务器，读取现有 PostgreSQL 数据库的表、视图与角色信息，生成对应的 REST API，无需编写后端代码。它通过 Hasql 维护连接池并使用二进制协议通信，将 JSON 序列化、校验和授权尽量下推到数据库端完成，且进程无状态、可水平扩展。适合已有 Postgres 数据库并需要 HTTP 接口的团队。

  • 为任意现有 PostgreSQL 数据库生成 RESTful API，支持 Docker 部署
  • 认证基于 JWT，授权委托给数据库角色，服务器以当前用户身份执行操作
  • 通过数据库 schema 实现 API 版本管理，并按 OpenAPI 标准自动生成文档

适用场景（解读层）

  • 为现有 PostgreSQL 数据库快速暴露 HTTP/REST 接口
  • 依赖数据库声明式约束与角色体系保障数据完整性和访问控制的后端服务
  • 需要自动生成 OpenAPI 文档并配合 Swagger-UI 使用的 API 开发流程
📖 README 首段存档原文 · 程序抽取

PostgREST serves a fully RESTful API from any existing PostgreSQL database. It provides a cleaner, more standards-compliant, faster API than you are likely to write from scratch.
