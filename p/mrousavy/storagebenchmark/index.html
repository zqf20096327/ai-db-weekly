React Native 存储库性能基准测试应用

综述（解读层）

这是一个用于比较 React Native 常用存储方案（MMKV、WatermelonDB、RealmDB、SQLite、AsyncStorage）的基准测试应用，运行于 React Native 0.68 并启用 Hermes。测试方式为执行一千次 get 操作并统计耗时。README 附带 iPhone 11 Pro、Debug 模式下的测试结果，作者也列出硬件、Debug/Release、JS 引擎和操作类型等会影响结果的因素。

  • 对 MMKV、AsyncStorage、WatermelonDB、RealmDB、SQLite 等存储库进行一千次 get 操作的耗时基准测试
  • 基于 React Native 0.68 运行，默认启用 Hermes，可在 Podfile 中切换为 JSC
  • 提供完整本地运行步骤：clone 仓库后在 app/ 目录依次执行 yarn、yarn pods、yarn ios

适用场景（解读层）

  • 想在 React Native 项目中自行测量各存储库读取耗时的开发者
  • 需要在真机或模拟器上复现并对比不同 JS 引擎（Hermes/JSC）下存储性能的团队
  • 针对 set、delete、update 等其他操作类型扩展测试逻辑的场景
