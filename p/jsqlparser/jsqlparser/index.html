🧭 简介解读层（AI·证据行可回查）

JVM 上的 SQL 解析器，将 SQL 语句解析为可遍历的 Java 类层次结构（AST）

综述（解读层）

JSqlParser 读取 SQL 文本并生成 Java 对象树，可通过 Visitor 模式遍历，也支持用 fluent API 从 Java 构建语句并渲染回 SQL 文本。面向需要在 JVM 上解析或改写 SQL 的开发者，覆盖 SQL 标准及 Oracle、MySQL、PostgreSQL 等多种方言。安装建议使用 Manticore 持续构建版本，Maven Central 上的 com.github.jsqlparser 上游发布版本较旧。

  • 将 SQL 文本解析为 Java 类层次结构（AST），支持 Visitor 模式遍历，并可反向从 Java 对象渲染为 SQL 文本
  • 单一语法覆盖 SQL 标准及 BigQuery、Snowflake、Oracle、MS SQL Server、PostgreSQL、MySQL、MariaDB、SQLite 等多种方言
  • 提供语句分类 API（getFeatures），以三值（proven/not excludable/ruled out）判断语句是否返回行或修改数据，支持嵌套子查询、绑定参数、窗口函数、Oracle hints 等语法

适用场景（解读层）

  • 在应用执行 SQL 前做只读校验：通过 Features API 判断语句是否包含数据修改操作
  • SQL 改写与格式化工具：解析为 AST 后遍历重写节点，再渲染回 SQL 文本
  • 需要处理多数据库方言 SQL 的 JVM 项目，如 SQL 审计、查询分析工具
