自托管的表格数据 UI 框架，基于 Preact + Hono + SQLite

综述（解读层）

OpenTable 是面向 OpenClaw 社区的开源表格 UI 框架，用于自托管构建数据看板、CRM 和类表格应用。支持多表、动态列、排序过滤分页和 CSV 导出，行数据以 JSON 存储在 SQLite 中，列变更无需迁移表结构。提供人类点击编辑与 ?agent=true 参数切换的自动化代理两种界面。需 Node.js 20+，MIT 许可。

  • 支持多表管理与动态列（添加、重命名、拖拽排序、类型变更），并提供列级排序、过滤、分页与 CSV 导出
  • 行数据以 JSON 对象存储于 SQLite，列操作仅修改元数据，无需 ALTER TABLE 迁移
  • 提供双模式 UI：人类交互模式与 ?agent=true 的自动化代理模式（显式按钮、更大点击目标）

适用场景（解读层）

  • 自托管构建 SaaS 数据看板或 CRM 类工具
  • 搭建类电子表格的数据管理应用
  • 为浏览器自动化代理提供可操作的数据表格界面
