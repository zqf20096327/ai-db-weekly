🧭 简介解读层（AI·证据行可回查）

Rust 编写的原生桌面应用，将数据库管理与本地文件 SQL 查询结合在同一工作区。

综述（解读层）

Kuery 是一个桌面端工作区，用于连接 PostgreSQL、MySQL、MariaDB、SQL Server、SQLite、Redis 和 MongoDB，并在无数据库连接时用 Polars SQL 查询 CSV、JSON 与 Parquet 文件。数据库默认以只读运行，写入需显式模式并带影响预览；文件 SQL 当前为临时只读工作区。项目处于早期原型阶段，提供 macOS、Windows、Linux 安装包。

  • 支持多数据库浏览与 SQL 编辑（多标签、补全、取消、超时），并用 Polars SQL 查询本地 CSV/TSV、JSON/JSONL/NDJSON 与 Parquet 文件
  • 提供 Profile 视图展示缺失值、分布、百分位、数值相关性，以及以树形或图形查看查询计划
  • 默认只读，写入采用显式 SQL 模式、事务提交/回滚与影响预览；连接密码存于操作系统凭据库，支持 TLS 与 OpenSSH 隧道

适用场景（解读层）

  • 在本地打开 CSV、JSON 或 Parquet 文件并用 SQL 做联接、聚合等探索性查询
  • 浏览数据库的 schema、表、索引与查询计划，查看结果的列分布与相关性
  • 通过环境策略和只读默认模式管理开发、staging 与生产连接的受控写入
