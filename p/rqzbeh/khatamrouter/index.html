基于 Bun 的本地 AI 路由网关，统一 OpenAI 兼容端点接入多上游提供商。

综述（解读层）

KhatamRouter 是一个本地运行的 AI 路由网关，在 AI 开发工具（如 Claude Code、Cursor、Codex、Cline）与上游模型提供商之间充当代理，对外暴露单一 OpenAI 兼容 /v1 端点并翻译 OpenAI、Anthropic、Gemini 等请求格式。它基于 Bun 运行时与 bun:sqlite（WAL 模式），通过 node:cluster 在多核上启动多 worker，可选 Redis 做分布式协调，包含多账号轮换、凭据管理、用量与花费记账等功能。安装运行方式需参考仓库 Quick Start 与配置文档。

  • 提供统一 OpenAI 兼容 /v1/* 端点，翻译 OpenAI、Anthropic Claude Messages、Google Gemini 三类上游格式，支持 40+ 提供商
  • 基于 Bun 运行时与 bun:sqlite（WAL 模式），通过 node:cluster 监管进程按 CPU 核数启动多 worker（KHATAM_WORKERS 可配置），可选 Redis Pub/Sub 做分布式事件与登录限流
  • 内置请求入口加固（拒绝 Content-Length 与 Transfer-Encoding 组合、64 MiB 分块上限）、可选滑动窗口 LoopGuard 工具循环检测，以及按 API key 的日/周/月花费限额与 request_cost_ledger 记账表

适用场景（解读层）

  • 将多个 AI 编码/开发客户端统一接入一个本地端点，集中管理多提供商、多账号凭据与 OAuth 令牌刷新
  • 需要对不同模型组合（combo）配置自动故障转移、配额切换与成员冷却策略的本地代理部署
  • 需要按 API key 设置花费上限、统计用量成本，或在多进程/可选 Redis 环境下运行本地网关的场景
