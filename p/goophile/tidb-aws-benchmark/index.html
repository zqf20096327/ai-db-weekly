🧭 简介解读层（AI·证据行可回查）

在 AWS EC2 上部署 TiDB 集群并用 go-tpc 执行基准测试的脚本工具

综述（解读层）

该项目提供一组 Python 脚本和 AWS CloudFormation 模板，可在 AWS EC2 上自动创建资源、部署 TiDB 集群、用 go-tpc 运行 TPC-C 基准测试并销毁资源。使用者需具备 AWS 账号，创建具有 EC2 与 CloudFormation 权限的 IAM 用户并配置访问密钥。模板默认按 TiDB 开发测试环境推荐配置选择实例类型，OS 镜像为 Ubuntu 20.04，均可编辑调整。README 提示测试用的 CloudFormation 栈每小时约花费 4 美元，测试后需删除。

  • 通过 benchmark.sh 完成一键流程：创建 CloudFormation 栈、部署 TiDB 集群、运行 go-tpc 基准测试、删除 AWS 栈
  • main.py 支持按参数单独执行创建密钥、创建/删除 EC2、安装 TiDB 等步骤
  • 通过编辑 aws-cloudformation.json 和 tidb-topology.yaml 调整实例类型、集群拓扑与 OS 镜像

适用场景（解读层）

  • 在 AWS 上快速搭建可重复创建和销毁的 TiDB 测试集群
  • 以 go-tpc TPC-C 对指定配置的 TiDB 集群运行基准测试并采集结果
  • 按不同 EC2 实例类型与拓扑配置批量对比测试环境
