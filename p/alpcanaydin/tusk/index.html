🧭 简介解读层（AI·证据行可回查）

基于 Rust/GPUI 的原生键盘驱动数据库客户端，支持 20 种数据库。

综述（解读层）

Tusk 是一个用 Rust 编写、基于 GPUI 框架的数据库客户端，运行于 macOS、Windows 和 Linux。它支持 PostgreSQL、MySQL、MongoDB、ClickHouse 等 20 种数据库引擎，提供可编辑数据网格、SQL 编辑器、结构/DDL 编辑、备份恢复与 CSV/JSON/SQL 导入导出。AI 助手通过 Agent Client Protocol 调用外部 CLI，只写入查询不自行执行 SQL；密码存储在系统凭据管理器中。macOS 14+ 或 Apple Silicon，macOS 版可经 Homebrew 安装并支持自动更新。

  • 支持 20 种数据库引擎，包括 PostgreSQL、MySQL、SQLite、Oracle、Redis、MongoDB、DynamoDB 等
  • 基于 GPUI 的 GPU 渲染虚拟化表格网格，支持单元格编辑、事务保存与撤销重做
  • AI 助手通过 Agent Client Protocol 对接 Claude/Codex/Gemini CLI 等代理，经内置 MCP 服务器访问连接，只生成查询不自行执行 SQL

适用场景（解读层）

  • 在同一桌面客户端中管理多种数据库引擎的连接与查询
  • 通过自然语言生成 SQL 并人工审阅后执行的数据分析工作流
  • 在虚拟化网格中直接编辑大表数据并生成各引擎 DDL 修改表结构
