面向 Swift 的 SQLite 编译器、静态分析器与代码生成器

综述（解读层）

PureSQL 是用 Swift 编写的 SQLite SQL 编译器与代码生成工具，供 Swift 开发者使用。它读取 Migrations 与 Queries 目录下的 SQL 文件，编译校验后生成访问数据库的完整 Swift 数据层代码，包括表与查询的输入输出类型。SQL 文件通过 puresql.yaml 配置，可用 Swift Package Manager 插件、@Database 宏或 Homebrew 安装的 CLI 运行；README 注明宏方式目前不适合较大项目。

  • 校验 SQL 与数据库 schema，schema 变更时在编译期报错，并生成表结构、查询输入输出类型等 Swift 代码
  • 提供 @Database/@Query Swift 宏及 puresql CLI（init/generate/migrations add/queries add），支持 SPM 与 Xcode 构建插件
  • 连接默认使用 WAL 日志模式与连接池，自动处理查询的线程调度；每个查询文件生成可注入的 Queries 协议及 noop 实现

适用场景（解读层）

  • Swift/iOS 应用中需要类型安全的 SQLite 数据访问层
  • 以 SQL 文件为中心管理迁移与查询并通过依赖注入进行测试的项目
  • 希望从 SQL 生成 Swift 结构体与查询协议、避免手写仓库层的团队
