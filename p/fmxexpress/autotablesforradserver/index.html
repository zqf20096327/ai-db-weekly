面向 RAD Server 的低代码 REST API 自动生成器，通过 FireDAC 配置动态生成数据表端点。

综述（解读层）

AutoTables for RAD Server 是一个为 RAD Server 生成 REST API 的 Delphi 工具：通过图形化端点编辑器配置 FireDAC JSON，自动生成提供读取、写入和删除访问的动态端点，支持 30 多种数据库并可借助 Embarcadero Enterprise Connectors 扩展到 80 多种数据源。输出包括 RAD Server 项目、REST 客户端项目、REST SDK、OpenAPI 2.0 规范及 Swagger UI 文档，ResourceModule 提供完整源代码。

  • 通过图形化端点编辑器配置动态端点，提供对数据表的读取、写入和删除访问，配置格式为标准 FireDAC JSON
  • 支持 30 多种 FireDAC 数据库（含 MySQL、SQL Server、Oracle、PostgreSQL 等）及通用 ODBC 数据源，可通过 Embarcadero Enterprise Connectors 生成 80 多种数据源的端点
  • 可生成 RAD Server 项目、REST 客户端项目、REST SDK、OpenAPI 2.0 规范文件和 Swagger UI 文档，ResourceModule 附带完整源代码

适用场景（解读层）

  • 为 30 多种 FireDAC 支持的数据库或 ODBC 数据源快速生成带读取、写入和删除端点的 RAD Server REST 服务
  • 根据 OpenAPI 2.0 规范生成多种语言的 REST API 客户端（如 Python、Java、Go、TypeScript 等）
  • 在现有 Auto Tables RAD Server ResourceModule 中加载端点配置，或修改源代码以适配自有方案
