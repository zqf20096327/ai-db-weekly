🧭 简介解读层（AI·证据行可回查）

一款基于 Electron 的桌面数据库客户端，支持七种数据库且无需额外客户端软件。

综述（解读层）

Lookup 是一个桌面应用，用于连接 Oracle、PostgreSQL、MySQL/MariaDB、SQLite、ClickHouse、Redis 和 MongoDB。它通过纯 JavaScript 驱动（如 node-oracledb Thin 模式、mysql2 等）访问数据库，因此无需安装 Oracle Instant Client、psql、redis-cli 等客户端软件。适合需要同时管理多种数据库的开发者与运维人员。构建依赖 Node.js 20+；当前未设置打包的 Linux 构建，发布包未做代码签名。

  • 支持 Oracle、PostgreSQL、MySQL/MariaDB、SQLite、ClickHouse、Redis、MongoDB 七种数据库，多个连接可同时打开且各自维护独立的事务
  • 数据网格支持服务端分页、过滤、排序与待提交的行内编辑；SQL 编辑器提供高亮、自动补全、Explain 和运行中查询的 Stop
  • 提供 CSV、Excel、JSON、SQL INSERT 四种流式导出；密码通过操作系统钥匙串加密存储，支持只读连接与 Production 连接变更确认

适用场景（解读层）

  • 需要在同一桌面应用中同时打开和查询多种数据库（含 Redis 键浏览、MongoDB 集合视图）的开发场景
  • 通过 Production 标签、手动提交默认和只读连接进行生产环境数据查看与受控修改
  • 通过 kubectl port-forward 转发各 master 节点后访问 Kubernetes 中的 Redis Cluster
