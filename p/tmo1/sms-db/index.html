用 Perl 将多种格式的短信彩信集合导入 SQLite 库以供查询导出

综述（解读层）

sms-db 是一个 Perl 脚本工具，把来自 Android Bugle 数据库、SMS Backup & Restore 的 XML、Signal 加密备份等多种来源的 SMS/MMS 消息合并存入 SQLite 数据库的 messages 和 parts 两张表，支持标准 SQL 查询和 XML 导出（CSV 可经 sqlite3 生成），并通过 SHA-256 哈希避免重复导入。依赖 XML::LibXML、DBD::SQLite 等 Perl 模块，无需专门安装。数据库格式尚不稳定，README 要求保留原始消息来源以便重建。

  • 支持 Bugle SQLite、Synctech XML、Signal 解密备份三种输入格式，可将多来源消息合并至单一库
  • 基于 SHA-256 元数据哈希实现消息去重，防止重复存储
  • 数据库仅含 messages 和 parts 两张表，可用标准 SQLite 查询，并可导出为 XML 或经 sqlite3 生成 CSV

适用场景（解读层）

  • 合并来自多个 Android 应用或备份工具的 SMS/MMS 消息为统一存档
  • 对消息集合执行 SQL 查询或导出为 XML 以导入其他系统（含 Android 内部消息存储）
  • 备份 Signal Android 明文短信彩信数据以便后续分析处理
