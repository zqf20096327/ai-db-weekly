基于 Bash 脚本的 LEMP/LNMP 一键安装器与虚拟主机管理工具

综述（解读层）

LEMPer 是一组 Bash 脚本，用于在 Debian/Ubuntu 服务器上自动安装 Nginx、PHP（多版本）、MariaDB/PostgreSQL、MongoDB、Redis、Memcached 等 LEMP 栈组件，并提供 lemper-cli 命令行与 TUI 管理虚拟主机。设计为干净服务器上运行，支持按内存/CPU 自动调优，适合在云 VPS 或裸金属服务器上部署 PHP 框架与 CMS（WordPress、Laravel、Drupal 等）的用户。

  • 通过 install.sh 在 Debian 11/12 与 Ubuntu 22.04/24.04 上自动安装 Nginx、多版本 PHP、SQL/NoSQL 数据库、缓存与 FTP 服务
  • 提供 lemper-cli 命令行与交互式 TUI，用于创建虚拟主机、启用 SSL/FastCGI 缓存/CORS、更新 PHP 与 Nginx
  • 包含 Adminer、phpRedisAdmin 等 Web 管理工具，以及可选的 ModSecurity、CrowdSec、配置加密等安全组件

适用场景（解读层）

  • 在云 VPS 或本地裸金属服务器上从零部署 LEMP 栈
  • 托管 WordPress、Laravel、Symfony 等 PHP 应用与 CMS 的多站点环境
  • 通过命令行集中管理虚拟主机、SSL 证书与 PHP 版本迁移
