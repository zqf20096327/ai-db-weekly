综述（解读层）

Salve DB 是一个 React Native 离线优先 SQLite 数据库库。开发者用 TypeScript 声明表结构和 REST 同步契约，原生核心负责建表、迁移、通过 SQLite 触发器将本地写入加入同步队列，并与自有 REST API 推拉数据。同步引擎、HTTP 客户端、OAuth2 刷新和后台调度均运行在原生层，后台同步不启动 JS 运行时。前置查询为 Drizzle 风格类型化查询构建器，要求 where/orderBy 列必须是已声明索引的首列或主键，limit 上限 500；删除为软删除，自动注入 deletedAt 字段。支持 iOS 0.86+、Android minSdk 23，iOS 需配置 BGTaskScheduler 与 Keychain entitlements。

  • 同步编排器、HTTP 客户端、OAuth2 凭证刷新与后台调度（WorkManager/BGTaskScheduler）全部在原生层运行，后台同步不启动 JS 引擎
  • 所有 INSERT/UPDATE/DELETE（含原生 SQL）由 SQLite 触发器捕获并进入同步队列，支持声明式 TypeScript schema 与自动 ADD COLUMN 迁移
  • 提供 Drizzle 风格类型化查询构建器、useQuery/useInfiniteQuery 响应式钩子，附带 salve-db-studio 浏览器调试工具和 salve-db-server 参考后端实现

适用场景（解读层）

  • 需要离线读写本地 SQLite 数据并与自有 REST API 双向同步的 React Native 应用
  • 希望后台同步与 OAuth2 令牌管理在原生层完成、不依赖 JS 无头任务的场景
  • 开发期通过 Studio 在浏览器中浏览、编辑运行中应用的数据库并执行原生 SQL
