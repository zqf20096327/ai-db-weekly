综述（解读层）

OrientDB 是一个开源多模型 NoSQL 数据库管理系统，由 Java 编写，支持图、文档、全文检索、地理空间与面向对象概念，采用 Apache 2 许可证发布。它支持无模式、全模式与混合模式，提供基于用户、角色和谓词的安全机制，并支持 SQL 作为查询语言；记录间连接以持久指针管理，运行时不执行 JOIN 操作。适用于需要多模型数据的 Java 及其他语言的开发者。

  • 在同一产品中支持图、文档、全文、地理空间等多种数据模型
  • 支持 SQL 查询语言与 ACID 事务
  • 支持无模式、全模式与混合模式，并提供基于用户、角色和谓词的安全机制

适用场景（解读层）

  • 需要同时处理图与文档等多模型数据的应用
  • 熟悉关系型数据库 SQL 的开发者希望在 NoSQL 中使用 SQL
  • Java 平台或通过语言绑定接入的其他开发环境
