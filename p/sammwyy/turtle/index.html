模块化 Java ORM，将实体映射、SQL AST、方言渲染与数据库驱动分层解耦

综述（解读层）

TurtleSQL 是一个 Java 编写的模块化 ORM/ODM，将实体映射、查询 AST、方言渲染与驱动层分离。当前经测试的持久化路径基于 JDBC 的 SQLite 反射实现，PostgreSQL、MySQL、MariaDB 提供初始 SQL 渲染与冒烟测试。面向需要在多数据库方言间工作的 Java 开发者，API 兼容边界与有意延后的能力记录于 SPECS.md 与 ROADMAP.md，项目尚处 1.0 之前的兼容策略阶段。

  • 提供方言中立的查询 AST、流式 SelectQuery 构建器及游标分页、偏移分页与投影查询
  • 支持 @ManyToOne/@OneToMany/@ManyToMany/@EmbeddedId 等映射注解，并通过 DRef/DCollection 提供显式缓存加载
  • 支持 SQLite、PostgreSQL、MySQL、MariaDB 方言渲染，能力受限的操作符（如 ilike）在渲染期被拒绝而非改变语义

适用场景（解读层）

  • Java 项目中需要以注解映射实体并进行 SQLite/PostgreSQL/MySQL 等关系库读写
  • 需要确定性 schema 迁移、schema 内省与多方言 DDL 渲染的持久化层开发
  • 需要在异步栈（如 R2DBC）或分页、批量读取场景下使用会话与事务管理的应用
