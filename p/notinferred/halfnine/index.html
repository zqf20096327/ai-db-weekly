面向 PostgreSQL 的桌面客户端，内置 MCP 服务器供 AI 代理使用。

综述（解读层）

Halfnine 是一款运行于 macOS 和 Windows 的 PostgreSQL 桌面客户端，提供连接管理、Docker 数据库操作与备份撤销机制。它同时作为 MCP 服务器，可被 Claude Code、Codex、Cursor、VS Code 和 Claude Desktop 调用，并按连接设置代理权限（关闭/只读/审批写入/完全）。项目处于早期阶段，采用 Tauri（Rust 加 React）构建，源码在 PolyForm Shield 1.0.0 许可下可用。

  • 提供 macOS 与 Windows 安装包，支持直接连接本机 Docker 中的 Postgres 容器（兼容 Docker Desktop、OrbStack、Colima、Rancher Desktop），并可创建 PostgreSQL 14 至 18 的容器
  • 内置 MCP 服务器，代理操作按连接分级授权（Off/Read/Read with approved writes/Full），变更可作为待定行或 SQL 展示等待确认，并在 Agents 页记录操作日志
  • 危险操作（删表、清空、删列、删除 Docker 数据库）默认先备份并支持撤销；技术栈为 Tauri，UI 用 React/Vite，后端为 Rust crates

适用场景（解读层）

  • 开发者日常查看和操作 PostgreSQL 数据库，包括本地 Docker 容器中的实例
  • 让 Claude Code、Cursor 等 AI 代理通过 MCP 访问数据库连接，同时保留人工审批写入的环节
  • 需要本地源码构建或参与开发的前端与 Rust 开发者（需 Node 24+、pnpm、Rust）
