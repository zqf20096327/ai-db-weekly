🧭 简介解读层（AI·证据行可回查）

PHP 编写的 MySQL 数据库抽象层与 ORM，可依据代码自动调整数据库 schema。

综述（解读层）

Moldable 是一个 PHP 库，提供 MySQL 数据库连接管理和 ORM 类（Storable），用于管理持久化对象，并支持根据类模型自动创建或更新数据库 schema。通过 composer 安装，目标使用者是 PHP Web 应用开发者，其设计旨在将 schema 变更纳入开发流程而非独立的迁移步骤。

  • 提供 Database 类用于连接 MySQL 数据库
  • 提供 Storable ORM 类管理持久化对象，并根据类定义自动创建或更新数据库表结构
  • 通过 composer require javanile/moldable 安装，附带基于 PHPUnit 的测试配置说明

适用场景（解读层）

  • PHP Web 应用中管理持久化对象
  • 需要依据类模型生成或变更 MySQL 表结构的开发流程
  • 通过脚本方式操作和管理数据库 schema
