🧭 简介解读层（AI·证据行可回查）

自托管的私有应用、LLM 与 AI 代理统一访问网关

综述（解读层）

Liaison 是一个部署在自有 Linux 服务器上的控制平面，通过仅出站连接器接入私有设备，使用户在浏览器中访问 SSH/RDP/VNC、数据库、S3 存储及本地 LLM，并为 Codex、Claude Code 等代理提供会话式访问与权限审批。适用于需要在不开入站端口的前提下管理内部服务的团队。安装依赖 Docker 20.10+，采用 AGPL-3.0 许可证。

  • 提供浏览器工作区，支持 SSH/SFTP、WebRDP、WebVNC、多种 SQL/NoSQL 数据库及 S3 存储（只读浏览）的 Web 访问
  • 支持本地 LLM 共享：API Key 按模型限定作用域、Token 配额、可撤销授权与用量跟踪，上游兼容 OpenAI/Anthropic Messages/Ollama 协议
  • 内置仅出站连接器与按需 TCP 端口（5–300 秒过期），并包含基于 Casbin 的身份授权、防火墙策略与审计日志

适用场景（解读层）

  • 无本地客户端环境下通过浏览器访问内网数据库、远程桌面和终端会话
  • 将本地大模型以经过认证的 API 形式共享给团队成员并控制配额与权限
  • 在浏览器中使用 Codex/Claude Code 操作自有设备，代理查询需经用户批准
