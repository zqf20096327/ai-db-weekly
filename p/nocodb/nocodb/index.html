开源数据库管理平台，为数据库提供电子表格式界面并自动生成 REST API

综述（解读层）

NocoDB 是一个可自托管的数据库管理平台，用户通过电子表格界面操作底层数据库，支持连接 PostgreSQL 等数据源，并提供 REST API 和 SDK 供程序化调用。项目采用 Sustainable Use License 许可证，提供 Docker、Docker Compose、Kubernetes、Helm 等部署方式，适用于需要以表格形式管理和共享数据、同时保留数据库与 API 访问能力的团队。

  • 提供电子表格界面，支持表格/列/行的增删改查，以及排序、筛选、分组、隐藏列等字段操作
  • 支持 Grid、Gallery、Form、Kanban、Calendar 多种视图类型，以及协作视图与锁定视图权限
  • 提供 REST API 和 NocoDB SDK，可使用 JWT 或社交登录令牌进行请求鉴权；内置 Slack/Discord/SMTP/S3 等集成

适用场景（解读层）

  • 需要以电子表格方式协作管理数据库数据的团队
  • 需要为现有数据库快速生成 REST API 的开发场景
  • 自托管环境下搭建表单、看板、日历等多视图数据管理工具
