基于 Rust 与 GPUI 的开源跨平台数据库客户端与 SQL 编辑器

综述（解读层）

FluxDB 是一个以 Rust + GPUI 构建的原生桌面应用（不用 Electron 或 WebView），支持 macOS、Windows 与 Linux。它将 MySQL、MariaDB、PostgreSQL、SQLite、TiDB、SQL Server、Dameng、MongoDB、Redis 等接入同一工作流，提供 SQL 编辑、数据编辑、表设计、导入导出、备份恢复、ER 图、MongoDB 与 Redis 工作台等功能。许可证为 GPL-3.0，README 注明各数据库能力存在差异。

  • 支持 MySQL、PostgreSQL、SQLite、Redis、TiDB、MongoDB 等多种数据源的查询、数据编辑、模式管理与备份恢复
  • 提供语法高亮、补全、SQL 格式化、查询历史、可视化查询计划解析与跨连接结构比对/数据传输
  • 基于 Rust 与 GPUI 原生实现，不依赖 Electron 或 WebView；含权限感知的 AI Agent 与签名校验的应用内更新

适用场景（解读层）

  • 在单一桌面应用中同时管理关系型数据库、MongoDB 与 Redis
  • 进行 SQL 编辑、表结构设计、数据导入导出与备份恢复等数据库日常操作
  • 查看 ER 图、解析查询计划或执行跨连接的表结构比对与数据迁移
