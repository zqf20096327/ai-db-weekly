🧭 简介解读层（AI·证据行可回查）

基于 ClickHouse 的 OpenTelemetry 优先聚合系统，存储指标、链路与日志

综述（解读层）

oteldb 是面向指标、链路、日志与 profiles 的遥测数据聚合存储系统，底层基于 ClickHouse 列式数据库，也可用 --embedded 标志切换到内置存储引擎以实现单二进制运行。查询语言兼容 PromQL、TraceQL 和 LogQL；数据接入支持 Prometheus remote write（含 exemplars）与 OpenTelemetry gRPC 协议，可通过 OTel Collector 的 90 多种协议采集。Apache 2.0 许可，提供 docker compose 快速启动与 Grafana 面板。

  • 兼容 PromQL、TraceQL、LogQL 三种查询语言，PromQL 兼容性测试通过 547/548（99.82%）
  • 支持 Prometheus remote write（含 exemplars）与 OpenTelemetry gRPC 协议接入
  • 支持嵌入式存储引擎，单标志即可脱离 ClickHouse 运行，并可按信号混合两种后端

适用场景（解读层）

  • 统一存储指标、链路、日志与 profiles 的可观测性后端
  • 通过 OTel Collector 汇聚多种协议的遥测数据
  • 本地开发或单节点部署时使用嵌入式引擎的自包含运行
