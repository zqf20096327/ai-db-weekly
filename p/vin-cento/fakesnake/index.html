Python CLI 工具，用于生成随机假数据并插入数据库

综述（解读层）

FakeSnake 是一个命令行工具，通过 fakes 命令生成地址、邮箱、姓名、数字等假数据列表，并可将数据插入数据库。数据库相关功能目前仅支持 Postgres，需额外安装 psycopg2-binary 及 postgres 客户端和开发库。适合需要快速构造测试数据的开发者使用。

  • 提供 gen 子命令，可生成 address、email、geojson、name、number、password、shape、text 等类型的假数据列表
  • 提供 db 子命令，包含 config、describe、exec、insert、table、tables 等数据库操作
  • 通过 pip install fakesnake 安装，连接 Postgres 依赖 psycopg2-binary

适用场景（解读层）

  • 快速生成随机数据列表用于开发或测试
  • 向 Postgres 数据表批量填充随机数据
  • 通过命令行查看数据库表结构和执行 SQL 命令
🔌 适配哪些库db_scan 程序判定
