基于 Tortoise ORM 与 MySQL 8.0+ 生成并执行批量 DML SQL 的 FastAPI 集成库

综述（解读层）

fastapi-efficient-sql 是一个 Python 包，通过 pip 安装，面向使用 Tortoise ORM、MySQL 8.0+ 和 FastAPI 的开发者。它在模型 Manager 上提供 select_custom_fields、update_json_field、upsert_on_duplicate、insert_into_select、bulk_update_from_dicts 等方法，生成含 JSON 函数、FORCE INDEX、JOIN 批量更新等 MySQL 特定语法的 SQL 并直接执行，可用 pytest 运行其自带测试。

  • 支持 select_custom_fields、update_json_field、upsert_on_duplicate、insert_into_select、bulk_update_from_dicts 等批量 SQL 生成方法
  • 生成并执行包含 JSON_EXTRACT、JSON_MERGE_PATCH、INSERT ... ON DUPLICATE 等语法的 MySQL 8.0+ SQL
  • 通过 pip 安装，提供 demo 服务（python -m examples.service）与 pytest 单元测试

适用场景（解读层）

  • FastAPI 项目中需要按主键批量查询、更新或 upsert MySQL 表数据的场景
  • 对 JSON 字段进行局部读取与合并更新的 MySQL 应用
  • 需要 INSERT INTO ... SELECT 做表间数据复制或备份表写入的场景
