基于 Neovim 的交互式数据库客户端，后端 Go、前端 Lua

综述（解读层）

nvim-dbee 是一个运行在 Neovim 内的数据库客户端插件，用户可在编辑器缓冲区中编写并执行查询、分页浏览结果。它采用 Go 编写的独立二进制后端（不依赖 CLI 工具）与 Lua 前端通信，支持通过 MemorySource、EnvSource、FileSource 配置连接，并提供 secrets 占位符模板。要求 nvim>=0.10，项目处于 Alpha 阶段，README 明确提示可能存在破坏性变更。

  • 后端为 Go 编译的二进制，通过构建约束适配多平台，不依赖外部 CLI 工具
  • 结果集使用迭代器分页加载（默认 page_size 为 100），支持 H/L/F/E 键翻页
  • 结果可按行或全部导出为 JSON/CSV，通过 store() API 写入文件、yank 寄存器或缓冲区

适用场景（解读层）

  • 在 Neovim 中编写 SQL 并针对活动连接执行、翻页查看结果
  • 用 scratchpad 文件保存常用查询，重启后自动加载
  • 通过环境变量或 JSON 文件管理多数据库连接配置，避免明文存储密钥
