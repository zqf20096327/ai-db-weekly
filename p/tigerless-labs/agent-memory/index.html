🧭 简介解读层（AI·证据行可回查）

以 Markdown 文件为唯一真源的 AI 代理长期记忆运行时，本地检索无需 API 密钥

综述（解读层）

agent-memory 用一个存储目录管理 AI 代理的长期记忆：每个记忆是一个 Markdown 文件，SQLite 索引仅作可重建缓存，检索返回路径与摘要供代理按层级读取。写入在会话边界触发，睡眠时段负责整合与删除提案。面向使用 Claude Code、Codex CLI 等可执行 shell 命令的代理用户，通过 `mem setup` 接入，需 Python 3.12+ 和 uv，目前需从源码安装，尚未发布到 PyPI。

  • Markdown 文件为单一真源，删除 .index 后 `mem rebuild` 可无损重建索引；记忆含 validity interval、links 和 provenance 等 frontmatter 字段
  • 三级读取轨道：MEMORY.md 注入、基于 FTS5 的 BM25 检索（可融合向量插件）、以及可直接 ls/grep 的目录树；recall 返回 L0 列表，代理可按 outline/abstract/full 层级读取
  • 内置 record/correct/supersede/merge/delete 等修正操作，supersede 保留链路，`recall --as-of` 支持按日期回溯；可经 MCP stdio 服务（mem-mcp）提供同名调用

适用场景（解读层）

  • 让 Claude Code、Codex CLI、Muse Code 等多个代理共享同一份长期记忆存储
  • 希望记忆以纯 Markdown 文件形式保留、可用 git 管理并可脱离该系统迁移的团队
  • 需要在无 API 密钥、无内置 LLM 客户端的本地环境下运行代理记忆的系统
