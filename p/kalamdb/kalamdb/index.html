单二进制 Rust 后端数据库，兼容 PostgreSQL 协议并内置实时订阅

综述（解读层）

KalamDB 是一个以单个 Rust 二进制发布的开源后端数据库，提供 PostgreSQL 语法与 PGWire 协议、WebSocket 实时查询、V8 运行时中的 JS/TS 服务端函数、持久化 pub/sub、认证与 Raft 集群。表格按用户分区的 USER/SHARED/STREAM 类型，近期数据存 RocksDB，旧数据转为 Parquet。可通过 CLI 或 Docker 安装，Apache 2.0 协议。

  • 支持 PostgreSQL 语法与 wire 协议，可使用 psql、DBeaver 及 PostgreSQL 驱动，含预处理查询与事务
  • 同一 SQL 查询可作为 WebSocket 实时订阅，SDK 在数据插入、更新、删除时维护结果集
  • 提供按用户分区的 USER 表、共享的 SHARED 表和按 TTL 过期的 STREAM 表，支持 RocksDB 与 Parquet 双层存储

适用场景（解读层）

  • 构建实时聊天、协作应用和实时仪表盘，前端通过 SDK 订阅查询结果
  • 作为现有后端之后的存储层，使用 Postgres 工具直接连接查询
  • 开发 AI Agent 与事件驱动后端，利用持久化 pub/sub、消费组与重试机制传递表变更事件
