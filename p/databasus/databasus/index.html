自托管数据库备份工具，基于 WAL 流实现 PITR 并执行真实恢复验证

综述（解读层）

Databasus 是 Apache 2.0 许可的自托管备份工具，支持 PostgreSQL（物理+逻辑备份）及 MySQL、MariaDB、MongoDB（逻辑备份）。核心机制包括 WAL 流式捕获实现时点恢复、启动数据库容器执行真实恢复校验，以及 AES-256-GCM 加密。面向需要数据库备份与灾难恢复的运维与开发团队。

  • 支持物理（全量+增量+WAL 流）与逻辑备份，实现 PostgreSQL 时点恢复（PITR），兼容 Patroni 与 CloudNativePG 集群时间线切换
  • 通过启动容器执行真实恢复并逐表报告行数来验证备份可用性，可按计划或备份后触发
  • 提供 GFS 等保留策略、S3/Azure/FTP 等多存储目标、AES-256-GCM 加密及 Email/Slack/Telegram 等通知渠道

适用场景（解读层）

  • 需要低 RPO/RTO 灾难恢复能力的 PostgreSQL 生产数据库备份
  • 使用 Patroni 或 CloudNativePG 的高可用集群的时间线连续备份
  • 多项目团队通过工作区、角色权限与审计日志集中管理数据库备份
