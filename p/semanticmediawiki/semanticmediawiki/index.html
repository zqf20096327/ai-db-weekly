🧭 简介解读层（AI·证据行可回查）

MediaWiki 扩展，在 wiki 页面内存储与查询数据，支持 RDF 导出。

综述（解读层）

Semantic MediaWiki 是一个免费的 MediaWiki 扩展，让用户在 wiki 页面内存储和查询数据，并提供语义网发布能力。它面向需要协作式知识管理的 MediaWiki 用户，配有多个衍生扩展。要求运行 MediaWiki 及 PHP 依赖，推荐用 Composer 安装；克隆仓库测试需 --recursive，CI 基于 docker-compose 与 Make。

  • 在 wiki 页面内存储并查询数据
  • 数据可通过语义网（RDF）发布供其他系统使用
  • 作为框架包含多个衍生扩展，支持 docker-compose-ci 测试流程

适用场景（解读层）

  • 在 MediaWiki 中构建可查询的结构化数据页面
  • 向语义网/关联数据系统导出 wiki 数据
  • 为 MediaWiki 扩展搭建基于 Make 和 Docker 的 CI 测试环境
📖 README 首段存档原文 · 程序抽取

Semantic MediaWiki (a.k.a. SMW) is a free, open-source extension to MediaWiki – the wiki software that powers Wikipedia – that lets you store and query data within the wiki's pages.
