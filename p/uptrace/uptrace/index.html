基于 OpenTelemetry 与 ClickHouse 的开源应用性能监控系统（APM）

综述（解读层）

Uptrace 是一个开源 APM 工具，用于监控应用并排查问题，支持分布式追踪、指标与日志三类数据，通过 OpenTelemetry 采集并以 ClickHouse 存储、PostgreSQL 存元数据（另需 Redis）。提供统一 UI、告警通知、类 SQL/类 PromQL 查询语言，也兼容 Grafana 数据源。适用于需要自托管监控的团队。

  • 单一 UI 展示 traces、metrics、logs，内置 50+ 自动创建的预置仪表盘
  • 数据采集支持 OpenTelemetry、Prometheus、Vector、FluentBit、CloudWatch 等，可配置为 Grafana 的 Tempo/Prometheus 数据源
  • 单核处理超过 10K spans/秒，支持 Kafka 摄入、OIDC 单点登录与基于 YAML 的用户/项目管理

适用场景（解读层）

  • 监控分布式应用并基于追踪/指标/日志排查问题
  • 配置告警规则并通过 Email、Slack、WebHook、AlertManager 接收通知
  • 通过 Docker 本地运行或使用云演示环境进行快速试用
