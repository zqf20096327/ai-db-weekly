综述（解读层）

Bun 是一个 Go 语言 ORM，构建在 database/sql 之上，提供链式查询 API，可将结果扫描到 struct、map、标量或切片。支持 PostgreSQL、MySQL/MariaDB、MSSQL、SQLite、Oracle 五种方言，并通过 struct tag 定义表关系。内置迁移、fixtures、软删除，提供 bundebug 查询日志和 bunotel 的 OpenTelemetry 集成。适合需要在 Go 中编写显式 SQL 并需跨多种数据库运行的团队。

  • 支持 PostgreSQL、MySQL/MariaDB、MSSQL、SQLite、Oracle 五种数据库方言
  • 查询结果可扫描到 struct、map、标量或切片，基于 database/sql 实现
  • 内置迁移、fixtures、软删除，提供 bundebug 与 OpenTelemetry 查询钩子

适用场景（解读层）

  • 需在 Go 代码中编写接近 SQL 语法的复杂查询（如 CTE、聚合）的场景
  • 需同一套数据访问代码运行在多种 SQL 数据库上的应用
  • 需要数据库 schema 版本迁移与分布式链路追踪的服务端项目
