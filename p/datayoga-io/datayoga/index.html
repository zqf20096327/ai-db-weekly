基于 YAML 低代码定义流式/批量数据管道的框架

综述（解读层）

DataYoga 是一个构建与运行流式或批量数据管道的框架，管道通过 YAML 声明式文件以低代码方式定义。Job 由多个 Step 组成，每个 Step 执行一个 Block，支持读写关系型与非关系型数据库、本地及云存储、调用外部 API 等。自带的 Runtime 提供校验、错误处理、指标与凭据管理，支持异步、多线程、多进程运行。适合需要用声明式配置搭建数据转换管道的 Python 用户，可通过 pip 安装。

  • 支持流式和批量两种管道模式，通过 YAML 声明式文件定义
  • Block 可读写关系型/非关系型数据库与本地/云存储，并可调用外部 API 做数据富化
  • Runtime 提供校验、错误处理、指标、凭据管理，支持异步、多线程与多进程及缓冲、限流策略

适用场景（解读层）

  • 从数据库、文件或云存储读取数据并做多步转换后写入目标
  • 通过外部 API 对数据字段进行富化或结构修改
  • 使用 pip 与 datayoga init/run 命令快速搭建并运行数据管道项目

DataYoga is a framework for building and running streaming or batch data pipelines. DataYoga uses low-code to easily define data pipelines using a declarative markup language using YAML files.
