🧭 简介解读层（AI·证据行可回查）

基于 Rust 与 Raft 的分布式键值数据库，无分布式文件系统依赖。

综述（解读层）

TiKV 是一个使用 Rust 实现的分布式 Key-Value 数据库，共识状态存储于 RocksDB，通过 Raft 算法保证数据一致性，并借助 Placement Driver（PD）实现分片与自动数据迁移。它可单独部署，也可作为 TiDB 项目的存储组件与 TiDB 配合运行；当前客户端接口为 TiDB Go 客户端与 TiSpark Java 客户端。项目采用 Apache 2.0 许可证，构建依赖 git、rustup、cmake、go 等工具。

  • 提供快照隔离（SI）、带锁快照隔离（对应 SQL 的 SELECT ... FOR UPDATE）及外部一致的分布式读写事务
  • 通过 PD 与 Raft 组实现地理复制、水平扩展和自动负载均衡，Region 为数据迁移基本单元
  • 实现类似 HBase 的 coprocessor 框架以支持分布式计算

适用场景（解读层）

  • 作为 TiDB 的存储引擎，为 RDBMS 场景提供具备分布式事务的底层 KV 存储
  • 通过 Go 或 Java 客户端单独使用 TiKV，构建需数据一致性与可扩展性的 KV 存储服务
  • 使用 tidb-docker-compose 或 Docker 在单机/多节点搭建测试集群进行功能验证
