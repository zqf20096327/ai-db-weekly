用于在 Debian 11 上自动化部署 LEMP/LAMP 服务器的 Ansible Playbook

综述（解读层）

该项目提供一组 Ansible 角色，在 Debian 11 服务器上自动化安装 Nginx 或 Apache、MariaDB、PHP 及 PhpMyAdmin，并按域名创建虚拟主机、数据库和网站目录骨架。要求目标机具备 SSH root 权限，使用者需自行填写 web-server.yml 中标注 REQUIRED 的配置项。README 提醒需自行处理 PhpMyAdmin 路径、防火墙与 SSL 等安全事项。

  • 支持安装 Nginx 或 Apache、MariaDB（10.5–10.10）与 PHP（8.0–8.2）
  • 按域名创建虚拟主机与对应的 MariaDB 数据库，并生成网站目录骨架
  • 支持配置本地或远程 Debian 服务器（通过 ansible/hosts 文件）

适用场景（解读层）

  • 在 Debian 11 服务器上批量初始化 PHP Web 运行环境
  • 为多个域名一次性创建虚拟主机与数据库
  • 通过 Ansible Playbook 统一执行服务器部署流程
📖 README 首段存档原文 · 程序抽取

This Ansible script allows you to automate the configuration of a LEMP web server or a LAMP web server on Debian 11 server.
