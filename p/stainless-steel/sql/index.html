Rust 语言库，以程序化方式构造 SQL 语句

综述（解读层）

这是一个 Rust 包，提供 SQL 语句构造器，README 标题标注与 SQLite 相关。用户通过 prelude 模块引入 API，以代码方式生成如 CREATE TABLE 等语句的字符串（示例含 users 表定义）。项目接受 issue 与 pull request，贡献内容按 LICENSE.md 条款授权。README 未详述支持的语句类型范围。

  • 提供 SQL 语句构造 API，通过 prelude 模块统一导出
  • 支持以 Rust 代码生成 SQL 语句字符串，示例包含 CREATE TABLE 语句
  • 采用 LICENSE.md 所列许可证条款接受社区贡献

适用场景（解读层）

  • 在 Rust 代码中程序化生成 SQL 语句字符串
  • 在处理 SQLite 相关场景时构造建表等 DDL 语句
  • 作为依赖库集成到需要动态拼接 SQL 的 Rust 项目中
