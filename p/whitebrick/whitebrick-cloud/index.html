基于 Hasura 与 Serverless 的多租户无代码数据库后端

综述（解读层）

whitebrick-cloud 是 Whitebrick 无代码数据仓库的后端部分，由 JavaScript 编写的 Serverless 函数构成，通过 Apollo GraphQL 接口连接 PostgreSQL 执行建表、加列等 DDL 操作，并调用 Hasura Metadata API 跟踪变更，同时管理用户权限与后台任务。前端为 whitebrick-client（Gatsby 静态客户端）。注意：项目已停止维护。

  • 通过 Hasura schema stitching 将 DDL 等函数暴露在同一 GraphQL 端点
  • 提供多租户 DDL、表级 RBAC、订阅式实时编辑与后台任务队列
  • 本地部署依赖 PostgreSQL（pgcrypto）、Docker/Kubernetes 运行的 Hasura 及 Serverless 框架

适用场景（解读层）

  • 为已有 Hasura + PostgreSQL 环境添加基于 GraphQL 的建表与权限管理能力
  • 搭建类电子表格界面（AG Grid 前端）的多租户数据录入仓库
  • 研究 Hasura Metadata API 与远程 schema stitching 的集成方式
