Rust 编写的分布式事务型键值数据库，基于 Raft 共识与 RocksDB 存储

综述（解读层）

TiKV 是 PingCAP 创建的开源分布式事务键值数据库，现为 CNCF 毕业项目。它除经典 KV API 外提供符合 ACID 的事务 API，事务模型类似 Google Percolator，共识状态存于 RocksDB。最小部署需同时运行 PD 与 TiKV 实例，官方文档已迁移至官网，原 Wiki 页面已停用。

  • 提供 ACID 事务 API 与快照隔离（SI）、带锁快照隔离（SELECT ... FOR UPDATE）及外部一致性读写
  • 使用 Raft 共识算法与 Placement Driver（PD）实现地理复制、自动分片和自动数据迁移，支持横向扩展至 100+ TB 数据
  • 实现协处理器框架支持分布式计算，数据以 Region 为基本迁移单元，多副本组成 Raft group

适用场景（解读层）

  • 作为 TiDB（兼容 MySQL 协议的分布式 HTAP 数据库）的存储层配合使用
  • 需要分布式事务和外部一致性读写的键值存储场景
  • 通过 Go、Java、Rust、C 客户端驱动及 Python 客户端接入的应用开发
