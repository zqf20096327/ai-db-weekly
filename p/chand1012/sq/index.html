用 SQLite 语法查询并转换 JSON、JSONL、CSV、SQLite 文件的命令行工具

综述（解读层）

sq 是一个 Go 编写的命令行工具，用于在 SQLite、CSV、JSON、JSONL 四种格式之间相互转换，并使用真实 SQLite SQL 语句查询 CSV、JSON、JSONL 数据。它支持从文件读取或管道输入数据，适合需要在 shell 脚本中对结构化数据做筛选和格式转换的用户，可通过预编译二进制或 go install 安装。

  • 支持 SQLite、CSV、JSON、JSONL 四种格式之间的相互转换
  • 使用 SQLite SQL 语句查询 CSV、JSON、JSONL 数据
  • 支持管道输入或文件读取，可与其他命令行工具组合使用

适用场景（解读层）

  • 在 shell 脚本中用 SQL 语句筛选 CSV 或 JSONL 数据集
  • 下载 JSONL/JSON 数据后经管道查询并导出为其他格式
  • 配合 jq 等工具对处理后的数据执行 SQL 查询
📖 README 首段存档原文 · 程序抽取

sq is a simple yet powerful command line tool for query and converting from and to SQLite, CSV, JSON, and JSONL files, heavily inspired by jq .
