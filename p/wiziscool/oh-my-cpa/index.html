CLIProxyAPI v8+ 的自托管 Web 控制台与可观测层

综述（解读层）

Oh My CPA 是面向 CLIProxyAPI v8+ 的自托管 Web 控制台，供管理多个 AI 提供商、OAuth 账号、可视路由及请求用量与成本的运维者使用。它以单个 Go 二进制内嵌 React SPA，使用 SQLite WAL 存储数据，由用量采集器从 CPA 读取数据；支持 AES-GCM 加密存储、写前配置备份与审计日志。需注意它依赖 CLIProxyAPI v8+，OMCPA_MASTER_KEY 需妥善备份。

  • 提供请求级延迟、token 与成本记录，可按模型、提供商、密钥、状态与成本过滤
  • 支持 OAuth 账号额度窗口追踪与预热调度，以及基于 OpenRouter 价格册的定价匹配（含时间/层级/渠道乘数、11 种显示货币）
  • 包含内置 Agent/MCP 会话助手，采用人工审批的能力机制；配置编辑支持表单/Monaco 双模式与写前加密备份

适用场景（解读层）

  • 集中管理多个 CLIProxyAPI 提供商、客户端密钥与 OAuth 账号的可视化路由
  • 按请求追踪延迟、token 与成本并进行多维用量分析
  • 通过 Docker Compose 或原生二进制在现有 CPA 实例旁部署控制台
