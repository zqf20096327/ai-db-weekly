Sensu 的 PostgreSQL 原生监控插件集，提供检查与指标采集脚本

综述（解读层）

该仓库是 Sensu 监控体系的 PostgreSQL 插件包，包含多个 Ruby 脚本：用于存活、连接数、复制延迟、自定义查询等检查，以及数据库大小、锁、pg_stat_bgwriter 等指标采集。支持 pgpass 文件、环境变量与命令行参数认证，通过 gem 或 sensu-install 安装。已知问题是 Sensu 内嵌 Ruby 的 libssl 与系统 libpq 不兼容时需全局 gem 安装。

  • 包含 14 个脚本：check 类覆盖存活、连接数、复制状态、查询，metric 类覆盖 dbsize、locks、statsbgwriter、statstable、statsdb、statsio 等
  • 认证配置支持命令行参数、pgpass 文件、PGHOST/PGPORT 等环境变量及默认值四级优先级
  • 提供 gem install 和 sensu-install（含 CentOS 依赖说明）两种安装方式

适用场景（解读层）

  • 为 Sensu 监控环境接入 PostgreSQL 存活、连接数与复制延迟检查
  • 采集 pg_stat_bgwriter、锁、表统计、数据库与关系大小等指标供 metrics 系统（含 Graphite 输出）使用
  • 通过 check-postgres-query.rb 执行自定义 SQL 查询并以阈值告警
