Rust + Dioxus 构建的原生桌面数据库客户端，支持 SQLite/PostgreSQL/MySQL/ClickHouse 与 ACP AI SQL

综述（解读层）

Shovel 是一个用 Rust 和 Dioxus 编写的原生桌面数据库客户端，支持 SQLite、PostgreSQL、MySQL、ClickHouse 的连接、浏览、查询、导出及行级编辑（ClickHouse 暂不支持编辑）。它通过 ACP 协议接入 DeepSeek、Ollama、OpenCode 等代理生成 SQL，并提供行内 SQL 补全。代码按 Rust workspace 拆分为多个 crate；AI 功能可选，需 Rust nightly 从源码构建。

  • 支持 SQLite、PostgreSQL、MySQL、ClickHouse 的连接、探索、查询与 CSV/JSON/XLSX 导入导出
  • 包含 ACP 客户端层及 DeepSeek/Ollama 嵌入式代理，支持流式、感知 schema 的行内 SQL 补全
  • 提供多标签 SQL 编辑器、查询历史、可编辑结果表格、SSH 连接，代码按功能 crate 拆分

适用场景（解读层）

  • 日常运行 SQL 查询、浏览与编辑本地或远程数据库表数据
  • 导入导出 CSV/JSON/XLSX 等常见数据格式
  • 通过 ACP 代理（DeepSeek/Ollama/OpenCode）辅助生成 SQL
