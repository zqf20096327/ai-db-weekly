🧭 简介解读层（AI·证据行可回查）

面向 AI Agent 团队的记忆中枢，将对话、文档与代码转化为四类可复用记忆资产。

综述（解读层）

腾讯云开源的 Agent 记忆服务（MIT 协议，Node 实现），由 memory-core、memory-hub 与 proxy 三部分组成。它从对话中提取 Chat Memory 与 Skill，把文档转为 Wiki、把代码索引为 CodeGraph，并提供团队面板进行资产管理、版本与 ACL 权限控制。通过将 Agent 的 base URL 指向 Proxy 并配置 User Key 即可接入，多数客户端无需插件或 MCP 服务。

  • 提供 Chat Memory、Skill、Wiki、CodeGraph 四类记忆资产的提取、管理、审阅与共享机制
  • 通过统一 Proxy 接入多种 Agent 客户端（如 Claude Code、Codex、DeepSeek Harness 等），以 base URL 与 User Key 配置实现零代码集成
  • 支持 private/team/ACL 三级可见性控制，以及系统管理员与团队级管理员的角色分层

适用场景（解读层）

  • 团队多 Agent 协作场景中共享用户偏好、决策与交互历史，避免跨会话重复提供上下文
  • 将已有代码库与文档导入后建立代码调用关系索引与结构化知识页，供 Agent 做影响分析
  • 为单人公司组建多角色 Agent 团队，按角色绑定不同记忆资产并在新会话中加载团队既有经验
