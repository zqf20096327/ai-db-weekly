🧭 简介解读层（AI·证据行可回查）

面向 LLM 智能体的持久化可迁移记忆系统，基于 SQLite/PostgreSQL 存储

综述（解读层）

Octop Memory 是为 LLM 智能体提供的持久记忆库，将对话事件经抽取与提升转为带证据引用的 AtomCard 事实，支持跨会话召回及通过 .hmpkg 包在主机间迁移。核心依赖为零，可单独作为 Python 库、CLI 或 JSON-RPC 桥运行；自动抽取需注入 LLMClient，需 Python 3.12+。向量搜索接口存在但真实集成未经测试验证。

  • 零核心依赖，基于标准库与 SQLite/FTS5 实现手动存储与词法召回，无需模型
  • 提供 RawEvent→Candidate→AtomCard→EntityPage 的记忆流水线，自动执行提升检查、去重与冲突处理
  • 支持导出/导入 .hmpkg 便携包，并提供 Python API、JSON-RPC 桥与 OpenClaw/Hermes 插件三种接入方式

适用场景（解读层）

  • 为个人助手保存用户偏好，在多轮会话间维持项目上下文与决策记录
  • 在支持的主机（OpenClaw、Hermes 等）之间迁移已积累的记忆数据
  • 通过 CLI 或 JSON-RPC 在无 Python 主进程环境下管理、检查与召回记忆
