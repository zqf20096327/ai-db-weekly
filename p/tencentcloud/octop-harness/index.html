基于 deepagents 的生产级 Agent 运行时，含模型路由与分层记忆

综述（解读层）

octop-harness 是一个 MIT 协议的 Python 3.12+ 库（非应用），对 deepagents 的 create_deep_agent 原语做工程化封装，最终委托该原语执行。它提供多提供商模型路由（OpenAI/Anthropic/Bedrock 及 17 个可编辑预设）、L0→L3 分层记忆、浏览器/搜索/MCP 工具、多 Agent 注册表、可插拔工作区（本地/S3/COS/PostgreSQL）、ACP stdio 服务器与终端 CLI。适用于需要将 deepagents 部署为运行时的开发者。

  • HarnessAgentManager 在单进程中注册并流式运行多个隔离 Agent，通过 LangGraph AsyncSqliteSaver 实现可恢复会话
  • ChatModelFactory 将模型名解析为客户端，支持 OpenAI（含 base_url 兼容端点）、Anthropic、AWS Bedrock 及 Hunyuan、Kimi、GLM、DeepSeek 等 17 个可编辑预设
  • octop-memory 中间件将对话捕获为 L0 原始事件，异步蒸馏为 L2 原子卡与 L3 实体页，记忆随工作区迁移

适用场景（解读层）

  • 将 deepagents Agent 封装为可部署运行时，按需替换模型、存储后端而不重写 Agent 逻辑
  • 在 IDE 或终端中通过 ACP 协议驱动 Agent，或用内置 CLI 进行交互式对话与 Agent 管理
  • 需要会话可恢复、跨工作区持久记忆及多 Agent 共存于单进程的应用构建
