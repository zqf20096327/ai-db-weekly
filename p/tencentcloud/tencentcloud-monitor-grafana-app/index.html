适配 Grafana 的腾讯云监控与日志应用插件，通过 API 获取数据

综述（解读层）

腾讯云监控 App 是一款 Grafana 应用插件，通过调用腾讯云监控 API 3.0 与日志服务 API 3.0 获取监控和日志数据，并在自定义 Dashboard 中展示，附带云服务器、云数据库 MySQL、负载均衡等预设 Dashboard 模板。2.0.0 起要求 Grafana 7.3 及以上版本；告警目前仅 CLS 数据源支持，且不支持模板变量。

  • 调用腾讯云监控 API 3.0 和云日志服务 API 3.0 获取监控与日志数据并生成 Dashboard
  • 提供云服务器、云数据库 MySQL、负载均衡和云产品日志数据的 Dashboard 预设模板
  • 提供地域、云服务器实例、云数据库 MySQL 实例等模板变量，支持通过 Grafana CLI 安装

适用场景（解读层）

  • 在 Grafana 中查看腾讯云云服务器、云数据库等产品的负载与性能监控指标
  • 通过云日志服务 API 在 Grafana 中进行日志检索分析与图表展示
  • 基于预设 Dashboard 模板快速搭建腾讯云资源监控面板
