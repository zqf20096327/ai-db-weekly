综述（解读层）

KORM 是一个 Go 语言 ORM 框架，作者参考 Django 的功能设计，支持 SQLite、MySQL、MariaDB、Postgres、Cockroach 五种数据库。它通过 struct 标签实现 AutoMigrate 和 Schema Diff 预检，提供基于 goroutine 和 channel 的缓存清理机制；驱动独立发布为单独的包。适合需要在单二进制中组合数据库、路由与服务总线的 Go 开发者。

  • 支持 SQLite、MySQL、MariaDB、Postgres、Cockroach 五种数据库，驱动以独立 Go 包提供
  • 提供 AutoMigrate、Schema Diff 干跑检查、Hook（OnInsert/OnSet/OnDelete/OnDrop）、外键与多对多关系
  • 内置事件总线（WithBus）、管理面板（WithDashboard）、交互式 Shell、MCP Server、反向代理与负载均衡、Prometheus 指标及 PPROF

适用场景（解读层）

  • 需要用 Go struct 标签管理表结构迁移和多数据库方言的项目
  • 需要多实例间通过 websocket pubsub 同步数据或搭建管理面板的应用
  • 已有 database/sql 代码库，希望通过 korm.GetConnection() 渐进集成的场景
