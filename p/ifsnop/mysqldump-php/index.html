🧭 简介解读层（AI·证据行可回查）

纯 PHP 实现的 mysqldump 数据库导出库，基于 PDO 连接。

综述（解读层）

mysqldump-php 是 MySQL 官方 mysqldump 命令行工具的 PHP 版本，无外部依赖，通过 PDO 的 DSN 连接数据库，可将表结构、数据、视图、触发器、存储例程与事件导出为 SQL 文件，并支持 Gzip/Bzip2 压缩输出。它面向需要在 PHP 环境中执行数据库备份且无法调用 mysql 可执行文件（如虚拟主机环境）的开发者。要求 PHP 5.3+、MySQL 4.1+ 与 PDO 扩展；2.0 版起连接改用标准 PDO DSN。导出时需要 SELECT、SHOW VIEW 等相应数据库权限。

  • 支持备份表结构、数据、视图、触发器、存储例程（函数与存储过程）和事件
  • 提供导出时的数据转换钩子（transformTableRowHook）、进度报告钩子（setInfoHook）以及按表设置 where 条件与行数限制的能力
  • 可通过压缩流包装器（GZIPSTREAM）直接写入 Google Cloud Storage，并支持从文件恢复导出内容而无须 mysql 可执行文件

适用场景（解读层）

  • 在 PHP 应用或无法调用命令行 mysqldump 的主机环境中执行 MySQL/MariaDB 数据库备份
  • 导出数据时脱敏处理：通过钩子移除敏感字段，或按表限定导出范围与行数
  • 生成结构转储用于数据库重建（如 no-data 模式配合 reset-auto-increment）
