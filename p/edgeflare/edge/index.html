基于 PostgreSQL 及配套组件组装统一应用后端的配置编排工具

综述（解读层）

edge 通过配置与管理多个组件（PostgreSQL+pgvector、OIDC IdP、S3 存储、pgo REST API/CDC、Envoy 网关）组装成统一后端，面向 Web 和移动应用开发者。组件可替换为外部或专有服务，支持在树莓派类设备到多区域 Kubernetes 集群运行。README 标明项目处于早期阶段，IdP 客户端密钥等部分仍需手动配置。

  • 提供 PostgREST 兼容的 REST API 与 Debezium 兼容的 CDC 管道（edgeflare/pgo）
  • 支持任意 OIDC 兼容 IdP（默认 dexidp/dex）结合 PostgreSQL 行级安全（RLS）实现认证授权
  • 组件可混搭替换为外部或专有服务，如 GCP Cloud SQL、AWS S3、Auth0

适用场景（解读层）

  • 为 Web 和移动应用搭建包含数据库、认证、对象存储和 API 网关的自托管后端
  • 在 Kubernetes 集群（含 k3s）上部署可扩展的多组件应用栈
  • 通过 pgo pipeline 实现数据库间的实时事件同步或复制
