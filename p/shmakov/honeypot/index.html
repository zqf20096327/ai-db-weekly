Rust 编写的低交互蜜罐，实时记录攻击并可视化展示

综述（解读层）

这是一个用 Rust 编写的低交互网络蜜罐，通过模拟 SSH、FTP、Telnet 协议横幅与基本响应来捕获登录尝试，并监听 1024 以上常见端口。后端为 Axum + SQLite + tokio，通过 SSE 向仪表盘实时推送攻击事件，结合 MaxMind GeoLite2 显示来源国家。适合安全运维人员部署在服务器上观察攻击行为；README 明确其为低交互实现，仅提供基础协议响应。

  • 模拟 SSH/FTP/Telnet 横幅与基本响应，记录登录尝试的凭据
  • 通过 SSE 实时推送攻击事件，提供统计页面、国家分布等分析接口
  • 监听 1024+ 常见攻击目标端口，集成 MaxMind GeoLite2 地理定位

适用场景（解读层）

  • 在自有服务器上部署以观察针对 SSH/FTP/Telnet 等端口的扫描与登录尝试
  • 通过仪表盘与统计接口查看攻击来源国家分布与历史统计
  • 作为安全监控组件，配合 Docker、systemd 或 Caddy TLS 部署运行
