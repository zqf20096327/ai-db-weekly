综述（解读层）

Releem Agent 是一个开源采集代理，负责连接用户的数据库与托管的 Releem 订阅服务，收集查询活动、数据库设置和资源指标，生成基于工作负载的查询、索引和配置调优建议，并通过 CLI 或仪表板应用配置变更。面向负责生产 MySQL 性能的工程师、DBA 和基础设施团队。该仓库同时承载产品反馈、Issue 和路线图讨论。使用需注册托管服务账户，功能范围取决于数据库类型、版本、权限和套餐。

  • 支持 MySQL 5.5–9、MariaDB 10–13、PostgreSQL 12–18 和 Percona Server for MySQL
  • 可运行于 Linux、Windows Server、Docker、Kubernetes，以及 Amazon RDS、Aurora、Google Cloud SQL、Azure Database 等托管环境
  • 提供工作负载分析、查询与索引建议、配置调优及变更后性能对比功能

适用场景（解读层）

  • 生产 MySQL/MariaDB 数据库的配置参数调优与查询性能分析
  • 需要人工审批后应用配置和 schema 变更的团队协作流程
  • 云托管数据库（RDS、Aurora、Cloud SQL、Azure）的性能监控与健康检查
