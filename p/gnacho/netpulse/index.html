🧭 简介解读层（AI·证据行可回查）

自托管家用网络监控面板：Go 后端加 React PWA，经 SSE 实时呈现路由器与设备状态。

综述（解读层）

NetPulse 是一个自托管的家用网络监控面板，服务端为单个静态 Go 二进制，数据存于 SQLite，前端为 React 19 的可安装 PWA。它通过部署在 OpenWrt/GL.iNet 路由器上的 agent 采集状态，经 SSE 每 5 秒更新路由器健康分、设备清单、WireGuard 对端和 AdGuard Home 统计，数据保留在局域网内。另可通过外部 pusher 集成 MikroTik、Asuswrt-Merlin、OPNsense、UniFi 及 SNMP 交换机。安装为一条脚本命令，需一台 Linux 主机和局域网内可 SSH 的路由器。

  • 提供 0-100 网络健康分、拓扑图、设备分类列表与告警流，数据经 SSE 每 5 秒实时更新
  • 支持 WireGuard 对端流量、AdGuard Home 统计、WAN 测速（M-Lab/Ookla/Cloudflare/LibreSpeed）与固件升级
  • 内置多用户（bcrypt、admin/viewer 角色）、i18n（ES/EN）、Web Push/ntfy/Telegram 告警通道及只读 MCP 服务器（默认关闭）

适用场景（解读层）

  • 用自托管面板集中监控多台 OpenWrt/GL.iNet 路由器的 CPU、内存、温度与流量
  • 查看局域网设备清单、Wi-Fi 漫游事件与自动推断的网络拓扑
  • 通过 MQTT 将网络状态接入 Home Assistant，或经 MCP 接口让 AI 助手查询网络状态
