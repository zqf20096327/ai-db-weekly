基于 sqlc 生成的代码创建 gRPC 与 HTTP/JSON 服务器的命令行工具

综述（解读层）

sqlc-grpc 是一个 Go 命令行工具，读取 sqlc 生成的代码并生成 gRPC 及 HTTP/JSON 服务器项目。使用流程为：编写 SQL 查询文件与 sqlc.yaml 配置，执行 sqlc-grpc 命令生成代码，再以数据库连接 URL 运行生成后的服务器。生成的 HTTP 端点基于 grpc-gateway，可通过 SQL 注释自定义方法与路径；生成的服务器提供 Swagger UI。README 另提及通过 go-ha 实现高可用 SQLite 的示例，以及依赖 Go 1.26 与 buf 工具。

  • 从 sqlc 生成的代码生成 gRPC 与 HTTP/JSON 服务器
  • 支持通过 SQL 注释自定义 grpc-gateway 生成的 HTTP 端点（方法与路径）
  • 生成代码中无 DO NOT EDIT 标记的文件可安全编辑，修改 SQL 后用 go generate、修改 proto 后用 buf generate 重新生成

适用场景（解读层）

  • 已有 sqlc 定义的 SQL 查询，需要为其生成 gRPC 服务的 Go 项目
  • 需要同时暴露 gRPC 与 HTTP/JSON 接口并通过 Swagger UI 调试的数据访问服务
  • 使用 SQLite 并参考 go-ha 示例搭建高可用数据库访问服务的场景
