综述（解读层）

agent-database-cli 是用 Rust 编写、通过 npm 分发的本地 CLI 工具，封装 MySQL、PostgreSQL、Redis、Oracle、MongoDB 的连接、查询与元信息读取，供 Agent 作为本地命令调用。默认启用只读模式并支持命令黑名单，凭据在首次使用时加密为密文引用存入本地文件；Oracle 默认走 SQLcl，原生驱动需显式配置。适用于需要让 AI Agent 在受控权限下访问数据库的场景。

  • 支持 MySQL、PostgreSQL、Redis（单机与集群）、Oracle（SQLcl 或原生驱动）、MongoDB 的连接与查询执行
  • 默认只读模式叠加命令黑名单，检查顺序为先黑名单后只读，并拦截 SELECT INTO、$out、$merge 等带写入语义的查询
  • 敏感信息（数据库密码、SSH 密码与通行短语）首次使用时加密写入 secrets.json，配置中以 *Ref 引用；支持 SSH 隧道与本地 daemon 连接复用

适用场景（解读层）

  • 让 Claude Code、Codex 等 Agent 通过本地命令查询数据库与读取元信息
  • 通过分组、标签筛选管理多环境连接，并经 SSH 隧道访问内网数据库
  • 使用本地编辑页面可视化维护连接配置，配合只读与黑名单控制 Agent 可执行的操作范围
