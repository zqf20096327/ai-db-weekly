面向 Oracle APEX 的 LDAP 身份认证与组授权插件集

综述（解读层）

该项目包含两个 Oracle APEX 插件：LDAP_Authentication_Plugin 通过 DBMS_LDAP 连接 LDAP 服务器完成认证，并将用户组列表写入 LDAP_GROUPS 表；LDAP_Group_Authorization_Plugin 读取该表判断用户是否属于指定组。适用于使用 Oracle APEX 且以 LDAP 为目录服务的环境，安装需先运行 prerequisite.sql 创建包与表。

  • 认证插件连接 LDAP 服务器并将用户组列表存入 LDAP_GROUPS 表
  • 授权插件按 LDAP 组实现访问控制，每个组需单独安装一个授权插件
  • 支持通过 LDAP_PREF 表或插件内部属性存储偏好设置，并可配置 LDAP 主机、端口、DN 前后缀与搜索过滤器

适用场景（解读层）

  • 使用 Oracle APEX 应用并需要对接 LDAP 服务器进行用户登录认证
  • 基于 LDAP 组成员身份控制 APEX 应用内访问权限
  • 需要将用户的 LDAP 组信息持久化到数据库表中供授权检查使用
