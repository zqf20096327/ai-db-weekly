ABMT 是框架无关的数据库迁移工具，通过可插拔提供者执行迁移

综述（解读层）

ABMT 是一个用 TypeScript 编写的数据库迁移工具，用于执行 schema 迁移、数据种子及其他基于时间的版本操作。它通过三种可注入依赖解耦：迁移提供者（文件系统或内存）、存储提供者（记录迁移执行状态）、上下文提供者（提供数据库连接等）。支持 Mongoose（MongoDB/DynamoDB）和 Sequelize（SQLite/Postgres/MySQL/MariaDB/MSSQL/Oracle SQL）。项目处于 Alpha 阶段，文档中 CLI 与编程用法章节尚未完成。

  • 提供内置 CLI 和编程 API 两种方式执行迁移
  • 支持 Mongoose 与 Sequelize 覆盖的多种数据库方言
  • 核心支持注入迁移提供者、存储提供者和上下文提供者

适用场景（解读层）

  • 需要对 MongoDB/Mongoose 或 Sequelize 支持的 SQL 数据库执行 schema 迁移和数据种子
  • 测试套件中通过内存迁移提供者以编程方式运行迁移
  • 分布式系统中将迁移状态存储在独立于服务所用数据库的存储上
