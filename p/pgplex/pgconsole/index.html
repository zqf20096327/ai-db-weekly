单二进制、单配置文件的 Web 端 PostgreSQL SQL 编辑器

综述（解读层）

pgconsole 是一个基于 Web 的 PostgreSQL SQL 编辑器，由 Bytebase 维护。以单个二进制和单个 pgconsole.toml 配置文件运行，不需要额外数据库。提供 SQL 编辑、AI 助手、MCP Server、连接级访问控制和审计日志，面向需要多人协作访问 PostgreSQL 的团队。支持 npm、npx 和 Docker 安装，可连 Cloud SQL、Aurora、Neon 等托管 Postgres。

  • SQL 编辑器支持上下文感知自动补全、格式化、错误检测、代码折叠、函数签名提示，以及带暂存编辑与生成 SQL 预览的虚拟滚动结果网格
  • 内置 AI 助手支持 Text-to-SQL、SQL 解释、纠错、改写和变更风险评估，可接入 OpenAI、Anthropic、Google 供应商
  • 提供 MCP Server（Streamable HTTP 端点 /mcp，Bearer token 认证），让外部 AI 代理以纯服务账户或代理用户身份访问连接，工具按权限逐级解锁

适用场景（解读层）

  • 团队通过 Web 界面共享访问 PostgreSQL，并需要按连接粒度控制读写权限
  • 让 Claude、Cursor、CI 机器人等 AI 代理通过 MCP 访问数据库而不分发原始凭据
  • 需要将查询和登录行为以 JSON 审计日志转发到日志基础设施的场景
