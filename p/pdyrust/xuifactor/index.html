🧭 简介解读层（AI·证据行可回查）

3x-ui 3.x 面板的流量倍率 sidecar，通过面板数据库安全调整计数器。

综述（解读层）

XuiFactor 是运行在 Linux 上的 3x-ui 3.x 流量倍率 sidecar，用 Go 编写，不修改面板源码，直接在面板的 SQLite 或 PostgreSQL 数据库中对客户端计数器应用临时倍率，规则元数据存于 xui_factor_* 表。提供单用户与批量规则、排除/覆盖策略、审计日志、备份与 systemd 服务。要求面板为 3.x；master/node 架构下只装在 master。采用 AGPL-3.0 许可。

  • 支持单用户规则、enable-all 批量作用域（含持久化自动纳入与 --once 快照模式）
  • 内置策略决策链：排除优先于用户覆盖、单用户规则、入站与全局作用域，重叠元数据不重复计倍率
  • 提供备份、审计日志、reconcile 元数据修复、自动清理（30秒/7天/30天保留期）与 systemd 安装

适用场景（解读层）

  • 需要按用户或批量对 3x-ui 客户端流量计数应用临时倍率（如 1.2 倍、5 倍）
  • master/node 多面板部署中在 master 上统一对本地与节点流量施加倍率
  • 需要审计倍率生命周期事件、生成策略与流量影响报告的运维流程
📖 README 首段存档原文 · 程序抽取

XuiFactor applies temporary traffic factors to 3x-ui client counters as a sidecar. It does not modify 3x-ui source code. Rule metadata is stored in the same database using xui_factor_* metadata tables
