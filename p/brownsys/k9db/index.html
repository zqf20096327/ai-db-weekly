兼容 MySQL 协议、按数据主体组织存储以内置处理 GDPR 请求的数据库

综述（解读层）

K9db 是一个提供 MySQL 兼容连接的数据库，内置处理 GDPR 规定的主体访问请求（SAR），包括数据访问与数据删除两类。它通过跟踪每行数据与数据主体的关联来自动处理 SAR，并要求在 SQL schema 中添加所有权标注。项目自述为验证合规可行性的原型，存在已知 bug 与限制。可通过 Docker 镜像或 bazel 从源码构建运行。

  • 支持数据访问与数据删除两类 SAR，自动跟踪每行数据与数据主体的关联关系
  • 提供基于增量数据流处理的内置缓存，自动随 SAR 与应用更新保持同步
  • 接受 MySQL 兼容连接，强制 PK 唯一性与带所有权标注 FK 的引用完整性，每条查询以 REPEATABLE_READ 隔离级别的单语句事务运行

适用场景（解读层）

  • 需要以程序化方式响应 GDPR 数据访问与删除请求的应用后端
  • 希望在使用 SQL schema 标注数据主体所有权关系的同时沿用 MySQL 客户端连接的应用
  • 研究合规数据库设计（如 OSDI'23 论文实验复现）的开发与教学场景
