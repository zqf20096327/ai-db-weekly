面向 SQL 数据库的水平分片路由器，按路由键将查询分发到分片

综述（解读层）

CollegeDB 是一个 TypeScript 分片路由库，将单张逻辑表拆分到多个数据库，通过映射存储或哈希计算把每个路由键定位到所属分片。支持 Cloudflare D1、PostgreSQL、MySQL、MariaDB、SQLite，可直接使用或经 Drizzle ORM 接入，运行于 Cloudflare Workers、Node 和 Bun。无运行时依赖，类型声明依赖 @cloudflare/workers-types。

  • 支持 hash、round-robin、random、location 四种分片策略，读写可用不同策略；hash 策略支持 rendezvous hashing 计算式放置，无需映射查找
  • 提供 reassignShard、rebalance 与 recoverMigrations，通过日志（journal）与恢复租约迁移分片数据；batch() 按分片分组语句并在支持的事务中执行
  • 适配器覆盖 D1、PostgreSQL、MySQL、SQLite、Hyperdrive、Workers KV、Redis、Valkey 等，分片数据库与映射存储可任意组合，含内存实现用于测试

适用场景（解读层）

  • 需要在 Cloudflare Workers、Node 或 Bun 上将单表数据水平拆分到多个 SQL 数据库的应用
  • 需要在不中断服务的情况下执行分片扩容、数据重均衡或迁移的场景
  • 在单元测试与本地开发中用内存提供者模拟分片与映射存储
