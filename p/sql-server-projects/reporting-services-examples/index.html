微软报表服务器（SSRS 与 PBIRS）示例报表与配套文档集合

综述（解读层）

该仓库提供面向 Microsoft Report Server（SSRS 与 PBIRS）的示例报表，包括查询报表、订阅、执行日志、计划作业和数据库字典等，另含 Power BI 模板、外部工具 JSON 配置，以及单元测试、需求文档和样式指南模板。适用于使用 SSRS/PBIRS 环境的报表开发与管理人员；部署时需将外部工具 JSON 放入指定目录并更新其中的站点 URL。

  • 包含查询报表服务器已部署报表、订阅与执行日志的 SSRS 示例报表
  • 提供含日历矩阵、书签与日期层级切换的 Power BI 模板（含 ServiceNow REST API 集成模板）
  • 提供 Power BI 外部工具的 JSON 配置文件及软件清单、单元测试、需求与样式指南文档

适用场景（解读层）

  • 管理 SSRS 报表服务器：查询部署报表、订阅、执行日志与计划作业
  • 基于模板统一组织内 Power BI 报表设计
  • 配置 Power BI Desktop 外部工具菜单（ALM Toolkit、DAX Studio、Tabular Editor 等）
