🧭 简介解读层（AI·证据行可回查）

面向 AI 编码代理的本地记忆工具，单 Rust 二进制加一个 SQLite 文件实现自动回忆

综述（解读层）

Omoikane 用 Rust 编写，为 AI 编码代理提供本地持久记忆：将代理会话中的经验存为带类型的短记忆到本地 SQLite 文件（含 FTS5 与 sqlite-vec），通过 hook 在用户输入相关时自动注入记忆，未命中时不注入。支持通过 git 仓库加密同步，提供 15 个代理的 setup 配置与 9 个 MCP 工具。适用于使用 Claude Code、Codex、Cursor 等代理工具并希望跨会话保留经验的开发者。

  • 单二进制 + 内置 SQLite，无 Python/Node/Docker，支持 Windows/Linux/macOS，可离线运行
  • 提供 9 个 MCP 工具，支持 101 种语言的搜索，含去重、历史记录、陈旧标记、密钥脱敏、回收站与每日备份
  • 支持通过加密的 git 仓库在多设备与团队间同步，spaces 隔离不同客户端的记忆

适用场景（解读层）

  • 使用 Claude Code 等 15 种支持代理的开发者，希望跨会话自动保留与回忆项目经验
  • 团队通过 git 仓库共享加密记忆库，多个成员与多台设备使用同一份记忆
  • 无人工值守环境（CI、服务器、容器）中通过环境变量配置代理记忆
