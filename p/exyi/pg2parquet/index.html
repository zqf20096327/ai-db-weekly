pg2parquet：将 PostgreSQL 表或查询结果导出为 Parquet 文件的命令行工具

综述（解读层）

pg2parquet 是一个用 Rust 编写的命令行工具，用于把 PostgreSQL 的表或 SQL 查询结果导出为 Parquet 文件。它支持较多的 Postgres 类型映射，如区间、数组、复合类型、枚举、jsonb 及 pgvector 向量，并通过 --xxx-handling 参数控制转换方式。适合需要将 Postgres 数据落入 Parquet 供分析工具读取的用户。部分类型不支持时可改用 SQL 侧类型转换绕过。

  • 支持导出整表或自定义 SQL 查询结果，可通过 --query 塑造输出 schema
  • 支持区间、数组、复合类型、枚举、jsonb、pgvector 等类型的 Parquet 映射，多种 --handling 选项控制序列化方式
  • 支持 PGPASSWORD/PGUSER/DATABASE_URL 环境变量配置连接，可通过 Cargo、Nix、AUR 或源码安装

适用场景（解读层）

  • 需要把 PostgreSQL 数据导出为 Parquet 文件供 DuckDB、Spark 等工具读取的场景
  • 导出包含 pgvector 向量、区间、复合类型等复杂 Postgres 类型的数据
  • 在 ETL 流程中用 SQL 查询裁剪列并指定输出格式后落盘为 Parquet
