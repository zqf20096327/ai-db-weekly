面向 Phoenix/Ecto 的查询过滤库，由 Ransack 风格查询语言构建 Ecto.Query

综述（解读层）

ExSieve 是一个 Elixir 库，为 Phoenix/Ecto 应用提供动态过滤与排序能力。它将基于 Ransack 风格查询语言的参数转换为 Ecto.Query 结构体，使用者需让应用 Repo 使用 ExSieve，并调用 filter/3 回调处理查询参数。README 提及当前依赖 Ecto.Query 内部结构提取主 Schema，版本为 0.8.2。

  • 提供 ExSieve.filter/3 回调，根据查询参数过滤条目
  • 从 Ransack 风格查询语言构建 Ecto.Query 结构体
  • 通过在 Repo 中 use ExSieve 集成

适用场景（解读层）

  • Phoenix 控制器中基于请求参数过滤列表接口数据
  • 需要为 Ecto 查询实现动态排序的场景
📖 README 首段存档原文 · 程序抽取

ExSieve is a filtering solution for Phoenix/Ecto. It builds Ecto.Query structs from a ransack inspired query language.
