🧭 简介解读层（AI·证据行可回查）

tbls 是连接数据库自动生成 GFM 格式 schema 文档的 Go 单二进制 CI 工具

综述（解读层）

tbls 用一条命令连接数据库并生成 GitHub Flavored Markdown 格式的 schema 文档，可输出 ER 图、Excel 等多种格式。通过 .tbls.yml 配置 DSN，提供 tbls doc、diff、lint、coverage 子命令，可嵌入 CI 流程检查文档与 schema 是否一致。适用于维护数据库文档的团队；需注意密码含特殊字符时须 URL 编码。

  • 单二进制运行，支持 PostgreSQL、MySQL、MariaDB、SQLite、BigQuery、Cloud Spanner、Redshift、DynamoDB 等数据源
  • 提供 doc、diff（文档/数据库间及数据库间比对）、lint（可配置规则如 requireColumnComment）、coverage（文档覆盖率统计）等子命令
  • 支持 SSL/TLS 证书配置、Docker 镜像、GitHub Actions 安装方式，文档可随配置提交到仓库

适用场景（解读层）

  • 为已有数据库生成并提交 Markdown 格式的 schema 文档到代码仓库
  • 在 CI 中运行 tbls diff 或 tbls lint 检查 schema 变更后文档是否同步更新
  • 统计各表描述与注释的文档覆盖率，检查列注释等规范
