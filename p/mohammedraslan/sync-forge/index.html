🧭 简介解读层（AI·证据行可回查）

本地运行的数据同步任务构建工具，以 UI 定义 PostgreSQL、MySQL、MongoDB、Cosmos DB、CSV、HTTP API 间的同步作业

综述（解读层）

Syncforge 是一个在本机运行的开源工具，用于在 PostgreSQL、MySQL、MongoDB、Cosmos DB、CSV 文件和 HTTP API（GET JSON）之间构建、运行并验证数据同步任务。用户通过 UI 选择源与目标、映射字段并配置转换，任务以 JSON 作业文件形式保存，可在 PR 中评审。README 明确标注其为本地工具，无登录机制，仅绑定 127.0.0.1，不面向生产环境或公网部署。通过 Docker Compose 启动，支持预览、dry-run、增量同步（watermark 字段）和源目标比对报告。

  • 支持以字段映射和转换（类型转换、JavaScript 表达式、固定值、fallback）定义同步作业，作业以 JSON 文件保存并可评审
  • 提供预览、dry-run、基于 watermark 字段的增量运行，以及源目标逐字段抽样比对报告
  • 写入按选定 key 字段做 upsert 匹配，重复运行不会产生重复记录

适用场景（解读层）

  • 平台过渡期间在旧库与新库间复制表、重命名字段并转换值，之后按增量重复运行
  • 需要以 lookup 或 SQL 查询跨库关联数据（如订单关联客户邮箱）的迁移作业
  • 将 CSV 文件或 REST API 数据作为源或 lookup 写入数据库，写入前预览并事后校验一致性
