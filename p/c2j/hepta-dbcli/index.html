综述（解读层）

hepta_dbcli 是一个 Rust 编写的数据库客户端，提供一次性命令行、交互式 REPL 和 MCP 服务器三种运行方式，连接 MySQL、PolarDB-X、Oracle、GaussDB 和 DuckDB。核心机制是三层写控制：MCP 端强制只读，数据变更需 --allow-write，破坏性 DDL 一律拒绝。适合需要在 AI 工具与本地 CLI 中统一访问多种数据库、并执行跨库 delta-diff 比对与合成数据生成的开发者与 DBA。

  • 可作为 MCP 服务器运行，按方言执行只读语句前缀校验（MySQL 允许 SELECT/SHOW/DESCRIBE 等，Oracle/GaussDB 允许 SELECT/EXPLAIN/WITH）
  • 提供跨数据库表数据比对（delta-diff），支持 hashdiff/joindiff/bucketdiff/iblt/keyeddiff 五种算法，CLI 与 MCP 均可用
  • 支持从真实表训练按列统计模型生成含外键完整性的合成数据（synth），密码可存入 macOS Keychain 或 Linux Secret Service，并记录独立 JSONL 审计日志

适用场景（解读层）

  • 在 Claude、Cursor 等 MCP 客户端中接入数据库只读查询，强制 read-only 语句前缀限制
  • 通过 CLI/REPL 对多种数据库执行 SQL，输出 table/json/csv/vertical 格式结果
  • 对比两个命名连接之间的表数据差异（delta-diff），或基于真实表生成结构相似的合成数据
