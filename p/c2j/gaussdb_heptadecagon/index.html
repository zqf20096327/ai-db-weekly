围绕 GaussDB/openGauss 的开源开发者工具集，含 12 个独立工具

综述（解读层）

GaussDB Heptadecagon 是一组面向 GaussDB/openGauss 的开源开发者工具，已发布 12 个，覆盖 SQL 解析、执行计划诊断、SQL 重写、代码图谱、数据迁移、安全扫描、驱动与 CLI 等环节。各工具独立可用、各自迭代，共享 ogsql-parser 解析器；其中 9 个内置可运行 MCP Server（共 62 个工具），供 AI 助手通过 stdio 调用。主要面向 GaussDB/openGauss 应用开发者与运维人员，工具以 Rust 为主，部分为 Java 或 Python。

  • 包含 12 个工具（ogsql-parser、ogexplain-analyzer、codeweb、flux-gauss、rust-opengauss 等），各自独立运行并共享 ogsql-parser SQL 解析器
  • 9 个工具内置可运行 MCP Server，共 62 个 MCP 工具，基于 rmcp SDK，统一 stdio 传输
  • ogsql-parser 为手写递归下降解析器，含 724 关键字、219+ 语句类型、53 条 lint 规则，并附带 1980+ 单元测试

适用场景（解读层）

  • 对 GaussDB/openGauss SQL 执行计划进行解析诊断并生成优化建议
  • 将 GaussDB 存储过程自动转换为 Java + iBatis/MyBatis 服务代码
  • 在 AI 助手（Claude Desktop、Cursor 等）中通过 MCP 调用 SQL 解析、诊断、安全扫描与跨库比对能力
🔌 适配哪些库db_scan 程序判定

GaussDB、MySQL、Oracle、PolarDB、PostgreSQL、openGauss
