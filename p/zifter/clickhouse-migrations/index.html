🧭 简介解读层（AI·证据行可回查）

面向 ClickHouse 的 SQL 文件式 schema 迁移工具，含 CLI、Python API 与 CI 集成。

综述（解读层）

该工具用于以 {版本}_{名称}.sql 文件管理 ClickHouse 的 schema 迁移，按版本号顺序执行多语句 SQL。面向使用 ClickHouse 的 Python 开发者与运维人员。支持集群感知记录迁移状态、双驱动（clickhouse-driver TCP 与 clickhouse-connect HTTP）、schema dump/diff、可选 Keeper 锁及离线 validate。最低要求 ClickHouse 23.3，部分功能需更高版本。

  • 支持 CLI、Python API、GitHub Action 和 Docker 运行方式，迁移文件按 {VERSION}_{name}.sql 命名规则离线排序
  • 提供 status、dump、diff、validate、baseline、repair 等子命令，其中 validate 和 dump --check 可离线运行
  • 集群感知迁移，可选基于 KeeperMap 的锁（需 ClickHouse 23.8+）防止并发运行交错

适用场景（解读层）

  • 在 CI/CD 流程中通过 GitHub Action 或 Docker 对 ClickHouse 集群执行 schema 迁移
  • 用 dump --check 检测 schema 漂移，或用 diff 从目标 schema.sql 生成迁移文件供人工审阅
  • 多个 Kubernetes Job 副本并发迁移时，通过 --lock 加 Keeper 锁避免执行交错
