从 PostgreSQL 表元数据生成 Go 结构体与 Table/Row Data Gateway 代码的工具

综述（解读层）

dgw 读取 PostgreSQL 表元数据，生成对应的 Go 结构体及 Table/Row Data Gateway 风格的查询与插入函数，面向偏好手写 SQL 而非 ORM 的 Go 开发者。它可自动识别自增列和复合主键以生成相应 SQL，并支持通过 toml 配置自定义 PostgreSQL 列类型到 Go 类型的映射；工具通过 Homebrew 安装，仅需提供数据库连接串即可运行。

  • 从 PostgreSQL 表定义生成 Go 结构体和 get/create 行级函数
  • 自动识别自增列（serial/bigserial）与复合主键并生成相应 SQL
  • 通过 toml 配置文件自定义 PostgreSQL 列类型与 Go 类型的映射，支持 --exclude-column 排除指定列

适用场景（解读层）

  • 为 PostgreSQL 数据表批量生成 Go 数据访问代码，避免手写重复的列清单与占位符 SQL
  • 在偏好 Table/Row Data Gateway 模式而非 ORM/查询构建器的 Go 项目中生成基础 CRUD 函数
  • 需要按团队规范调整类型映射或排除特定列（如大字段）后再生成代码的场景
