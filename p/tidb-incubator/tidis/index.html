基于 TiKV 的 Redis 协议兼容分布式 NoSQL 存储服务

综述（解读层）

Tidis 是 PingCAP 开发的 TiKV 服务层，用 Rust 编写，通过实现 Redis 协议提供分布式存储服务，支持 string/hash/list/set/sortedset 数据类型及 Lua 脚本、TLS 连接。计算与存储分离，依赖 TiKV（Raft 共识）提供数据分片、高可用与全局事务。运行需先用 TiUP 部署 PD、TiKV 和一个 TiDB（触发 GC），再构建并启动 tidis-server，客户端可直接使用 redis-cli。

  • 实现 Redis 协议，支持 string、hash、list、set、sortedset 五种数据类型及 Lua 脚本、TLS 连接
  • 存储与计算分离，依赖 TiKV 的 Raft 共识提供数据分片、线性扩展与全局事务
  • Rust 编写，支持单阶段提交和异步提交等特性

适用场景（解读层）

  • 需要 Redis 协议接口但数据量超出单机内存容量的场景
  • 需要全局事务和持久化保证的键值存储场景
  • 已有 Redis 客户端（如 redis-cli）并希望接入分布式存储的现有应用
