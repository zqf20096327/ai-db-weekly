让 TiDB 组件间通信走 RoCE/RDMA 的实验项目

综述（解读层）

该项目提出在 RoCE 协议上运行 TiDB，使 TiDB、PD 与 TiKV 之间的通信使用 RDMA 技术。项目包含 go-rdma 与 grpc-rdma 两套设计（README 中标注为 TODO），并提供了基于 gRPC 与 go-ycsb 的基准测试结果数据。适用于希望在 RDMA 网络环境部署 TiDB 的用户；使用前需自行编译 go-rdma 版 GOROOT、rdma-core 库及 TiDB/PD。

  • 支持将 TiDB、PD、TiKV 组件间通信改为 RDMA 传输
  • 提供 gRPC-TCP 与 gRPC-RDMA 在 295 个场景下的 QPS 与系统时间对比测试数据
  • 包含基于 go-ycsb 的 YCSB 负载测试结果

适用场景（解读层）

  • 在支持 RoCE 的网络环境中部署 TiDB 集群
  • 对 TiDB 各组件间通信进行 RDMA 性能基准评估
  • 在 Go 项目（如 go-mysql-client、go-ycsb）或 grpc-rs 项目中集成 RDMA 通信
