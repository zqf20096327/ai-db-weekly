🧭 简介解读层（AI·证据行可回查）

Rust 编写的嵌入式时序数据库与事件驱动回测引擎，面向量化研究。

综述（解读层）

h5i-db 提供嵌入式时序数据库和事件驱动回测器，经 pip 安装后可在 Python 中直接使用，无需服务器。其机制包括：为每次回测运行创建数据库 fork、将决策时间固定（pin）以阻止其后数据进入计算、通过浏览器 UI 查看试验与版本。支持从 Kalshi、Binance 等交易所加载数据，提供 ASOF join 等时间序列 SQL，采用 Apache-2.0 许可。

  • 通过 pip 安装即可在 Python 中运行回测，无需部署服务器
  • 支持固定决策时间的防前视（no lookahead）机制，并提供数据库 fork 实现参数扫描
  • 提供时间序列 SQL（ASOF join、time_bucket、vwap、滚动窗口）与按版本读取历史数据（db.read version=n）

适用场景（解读层）

  • 需要对参数组合进行批量回测并按样本外结果排序的量化研究流程
  • 读取 Kalshi、Polymarket、Binance 等 venue 数据或本地 OHLCV/成交数据进行分析
  • 配合 AI agent 使用（提供 agent skill），在终端中完成量化数据读写与回测
