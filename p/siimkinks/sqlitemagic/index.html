Android SQLite 数据库层，基于注解驱动与编译期 KSP 代码生成，不使用反射

综述（解读层）

SqliteMagic 是面向 Kotlin Android 项目的 SQLite 数据库层，要求 API 24 及以上并通过 KSP 在编译期生成代码，不使用反射。它提供 SQL 风格的 Kotlin DSL，由编译器检查子句顺序、列类型与可空性；通过插件集成 Gradle 构建，需自行选择设备 SQLite 或打包 SQLite 驱动。3.x 未发布到公共仓库，需从源码构建后安装到本地 Maven 仓库。

  • 提供 SQL-first Kotlin DSL，编译器检查子句顺序、列类型与可空性，通过 KSP 进行编译期代码生成
  • 通过 sqlitemagic-coroutines、sqlitemagic-rxjava3、sqlitemagic-rxjava2 适配器支持可观察查询与一次性操作，含 withTransaction 事务 API
  • 支持自动 schema 迁移及生成的迁移测试，可自定义对象转换器持久化第三方对象，支持复杂列（关联对象与内嵌值）

适用场景（解读层）

  • 需要在 Android 应用中操作 SQLite 数据库并希望编译期类型检查 SQL 查询的 Kotlin 项目
  • 使用 Kotlin 协程或 RxJava 观察表变化（查询结果随数据变更重新发射）的场景
  • 需要可控 SQLite 版本的项目：可选择设备自带 SQLite 或打包近期 SQLite 版本以在各 Android 版本上运行相同 SQL
