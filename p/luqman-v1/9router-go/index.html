Go 实现的 LLM 代理网关，单二进制内嵌 Svelte 面板，路由多提供商请求

综述（解读层）

9router-go 是 9Router 的 Go 实现，以单个二进制提供代理网关与内嵌 Svelte 仪表盘，面向使用 Claude Code、Cursor、Cline 等 CLI 工具的开发者。它将请求转发到 40+ 提供商与 100+ 模型，支持 RTK 工具输出压缩、组合路由（fallback/round-robin/sticky 等）与多账号轮换。默认监听 20130 端口，数据存于 ~/.9router，并直接读取上游 9Router 的同一 SQLite 数据库，无需迁移；仅做增量式 schema 变更，不导入旧 JSON 导出。

  • 单二进制运行，无需 Node.js 运行时，支持 Docker、后台守护进程与 systemd/launchd/cron 等开机自启
  • 支持 fallback、round-robin、sticky、capacity、fusion 等组合路由策略，可为每个 API key 绑定代理池
  • 兼容 OpenAI Chat、Claude Messages、Gemini、Ollama 等接口格式，含 SSE 流式与每请求日志检查

适用场景（解读层）

  • 在 Claude Code、Codex、Cursor 等 CLI 工具中通过本地端点统一接入多个 AI 提供商
  • 对工具输出类内容做自动压缩以减少 token 消耗
  • 已使用 9Router（Next.js 版）时切换或并行运行 Go 实现而保留既有数据库配置
