基于 Swift NIO 的纯 Swift 原生 MongoDB 驱动

综述（解读层）

MongoKitten 是一个用 Swift 编写的 MongoDB 驱动，完全基于异步实现，不阻塞线程，可用于 Vapor、Hummingbird 等服务端框架。它要求 Swift 5.5+ 与 MongoDB 3.6+，通过 Swift Package Manager 安装，提供 CRUD、索引、聚合管道、事务（需副本集，MongoDB 4.0+）、GridFS 文件存储及 BSON 编解码等能力，并附带的 Meow 模块提供 ORM。

  • 全异步驱动，基于 Swift NIO，支持 async/await，提供 connect 与 lazyConnect 两种连接方式
  • 实现完整 BSON 规范（依赖 OpenKitten/BSON），Document 遵循 Collection 协议，并提供 BSONEncoder/BSONDecoder 支持 Codable
  • 支持 CRUD、索引创建、聚合管道、事务、Change Streams 与 GridFS 文件上传下载

适用场景（解读层）

  • 在 macOS、iOS 或 Linux 上使用 Swift 构建需要 MongoDB 访问的服务端应用
  • 与 Vapor 或 Hummingbird 等异步框架集成，在请求中直接使用 MongoDB
  • 需要 GridFS 大文件存储或多操作原子事务的项目
