综述（解读层）

DB-GPT 是一个面向 AI + 数据产品的开源智能体数据助手（MIT 协议）。它连接数据库、CSV/Excel、数仓和知识库，支持自然语言生成 SQL、Python 分析执行、可复用 skills 加载，并在沙箱环境中运行代码，最终生成图表、仪表盘与 HTML 报告。同时提供 agents、AWEL、RAG 与多模型支持，可用于构建数据应用。安装支持一键脚本、PyPI（Python 3.10+）和 Docker。

  • 支持自然语言转 SQL、Python 代码执行、图表与 HTML 报告生成
  • 接入关系数据库、CSV/Excel、文档和知识库等多种数据源
  • 支持 DeepSeek、Qwen、GLM、Llama 等多系列模型，并可通过代理脱敏与沙箱执行保障数据隐私

适用场景（解读层）

  • 用自然语言查询数据库并自动生成 SQL
  • 分析 CSV/Excel 文件并生成可视化报告
  • 构建企业内部 AI 数据助手与数据分析工作流
