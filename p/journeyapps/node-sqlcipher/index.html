🧭 简介解读层（AI·证据行可回查）

基于 node-sqlite3 修改的 SQLCipher Node 绑定，从源码编译原生扩展。

综述（解读层）

该项目是 node-sqlite3 的分支，修改为使用 SQLCipher，为 Node 与 Electron 应用提供加密 SQLite 数据库的访问接口。软件包直接捆绑 SQLCipher 4.14.0（基于 SQLite 3.51.3）源码，安装时始终从源码编译原生扩展，仅支持 macOS 与 Linux，不支持 Windows 与预编译二进制。API 文档位于项目 wiki。

  • 基于 node-sqlite3 修改，捆绑 SQLCipher 4.14.0（基于 SQLite 3.51.3）源码
  • 安装时从源码编译，支持 macOS 与 Linux；macOS 使用 CommonCrypto，Linux 链接系统 libcrypto
  • 提供与 electron-forge / @electron/rebuild 的配合方式，API 沿用 node-sqlite3 风格

适用场景（解读层）

  • Node.js 程序需要读写 SQLCipher 加密的 SQLite 数据库
  • 基于 Electron（当前 CI 目标为 Electron 41）的桌面应用中通过 @electron/rebuild 编译使用该原生模块
  • macOS 或 Linux 环境下需自行从源码构建原生 SQLite/SQLCipher 绑定的项目
