🧭 简介解读层（AI·证据行可回查）

自托管 Jellyfin/Emby 仪表板，以 PostgreSQL 记录播放历史并聚合周边应用

综述（解读层）

JellyGlance 连接 Jellyfin 或 Emby 服务器，用自有 PostgreSQL 记录播放数据，提供仪表板、统计回顾、活动历史、请求与下载队列视图。以单个 Docker 容器运行，需配置 PostgreSQL 和 JWT_SECRET；支持 OIDC 登录、Webhook 通知与备份导出恢复，含中文等多语言界面。

  • 支持 Jellyfin 与 Emby，可自动检测服务器类型，并能导入 Jellystat、Tautulli 及 Emby Playback Reporting 插件的历史记录
  • 集成 Jellyseerr/Overseerr、Sonarr/Radarr 等 *arr 应用、qBittorrent/Transmission/SABnzbd 等下载客户端及 Discord/Gotify/Telegram 等通知渠道
  • 统计图表基于每日/每月 rollup 表生成，支持本地账户、Jellyfin Quick Connect 和 OIDC 单点登录

适用场景（解读层）

  • 集中查看 Jellyfin/Emby 的实时会话、播放历史和观看统计
  • 统一管理媒体请求、*arr 日历与下载客户端队列
  • 通过 Webhook/Discord/Gotify 接收通知并定期导出备份
