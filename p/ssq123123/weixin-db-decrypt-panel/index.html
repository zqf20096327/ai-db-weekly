解密 Windows 微信 4.1.9.23 本地数据库并提供只读可视化面板

综述（解读层）

本项目针对 Windows 微信 4.1.9.23，从运行中的客户端进程提取经页校验的数据库密钥，将 .db/.kvdb 解密为本地 SQLite 副本，再通过 FastAPI 与 React 面板只读查看联系人、会话、消息、媒体与统计。面板经 SQLite 只读 URI 打开数据库，服务默认仅监听 127.0.0.1；不支持消息发送与远程托管。需 Windows 10/11、Python 3.11+、Node.js 20+。

  • 从运行中的微信进程提取密钥并解密 .db/.kvdb 为本地 SQLite 副本，写前校验页面 HMAC、SQLite 头和文件页数
  • 面板通过 SQLite 只读 URI 和 PRAGMA query_only=ON 加载解密副本，FastAPI 与 Vite 默认仅监听 127.0.0.1
  • 可选构建原生 FTS5 tokenizer（需匹配版本 Weixin.dll）以支持微信原生全文搜索

适用场景（解读层）

  • 本地查看微信聊天记录、联系人、媒体及统计信息
  • 对解密后的本地数据库副本进行搜索与分析
  • 个人数据留存场景下对本机微信数据库做只读访问
