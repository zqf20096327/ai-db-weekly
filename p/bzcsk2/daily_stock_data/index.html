综述（解读层）

该项目是一组面向A股市场的数据采集脚本，通过 cron 定时运行，采集日线与5分钟OHLCV、腾讯行情快照、基础资料及 pytdx 参考数据（除权除息、财务、F10 等）。默认写本地 CSV，无需数据库；长期高频任务可切换或双写 PostgreSQL，脚本会自动建表。代码源自个人采集流程，README 注明为早期开源版本。需要 Python 3.11+ 与 Linux/macOS/WSL 环境，Tushare 与 TickFlow 数据源需自行配置密钥。

  • 提供 CSV、PostgreSQL、双写三种存储模式，通过 .env 配置切换
  • 包含日线、5分钟线、行情快照、基础资料及 pytdx 除权除息、财务、F10 等采集脚本
  • 提供 bin/run_*.sh 包装脚本与 cron 示例，自动读取 .env 并按 Asia/Shanghai 时区运行

适用场景（解读层）

  • 搭建个人 A 股行情数据的定时采集流程
  • 将日线、分钟线等数据写入本地 CSV 或 PostgreSQL 供 SQL 查询
  • 采集 pytdx 除权除息、财务快照、F10 章节等参考数据
