本地优先、fail-closed 的 AI 代理 API/MCP 流量网关与防火墙 SDK

综述（解读层）

Mont 是一个面向 AI 代理流量的本地网关与防火墙，提供 Express 中间件、无代码反向代理和 MCP 代理三种使用方式，数据存于内嵌 SQLite，无需 Redis 或云服务。规则按路由与负载分层判定，支持审批、预算、重复防护、MCP 工具默认拒绝及哈希链审计日志。需 Node.js 20.17+ 或 Docker；许可为离线 Ed25519 密钥，Community 版免费，Pro/Agency 功能按订阅授权。

  • 支持三种部署形态：Express 中间件、无代码反向代理、MCP 代理（stdio、Streamable HTTP、HTTP+SSE）
  • 提供按路由与负载的规则判定、每路由限流、支出预算、重复操作防护与人工审批队列
  • 包含 fail-closed 机制与哈希链审计账本，数据存于内嵌 SQLite（WAL），许可密钥离线校验

适用场景（解读层）

  • 为商店或 SaaS API 前置网关，控制 AI 代理的退款、发信等写操作并设置消费预算
  • 在 Claude、Cursor 等 MCP 客户端与工具服务器之间做默认拒绝的工具调用过滤与审批
  • 需要留存的合规/审计场景，导出防篡改审计日志供退款争议或审计取证
