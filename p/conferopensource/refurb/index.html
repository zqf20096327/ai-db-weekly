用于构建 PostgreSQL 数据库迁移工具的 Haskell 库

综述（解读层）

Refurb 是一个 Haskell 库，用于构建 PostgreSQL 数据库迁移软件。开发者以 Haskell action 编写迁移并随代码提交，库内通过 refurbMain 提供命令行接口，负责按序执行迁移、维护数据库中的已应用迁移记录。迁移分 schema 与 seed data 两类，后者在生产库中被禁止执行。示例项目位于 example/ 目录。

  • 支持 show-log、show-migration、migrate、backup 等子命令，可查询迁移记录、预览待执行迁移并执行迁移
  • 迁移通过 MonadMigration 类型的 Haskell action 实现，使用 postgresql-simple 的数据库连接，可包含可选的前置检查 action
  • 内置迁移日志表记录时间戳、耗时与结果，backup 命令通过 pg_dump 生成压缩二进制备份，migrate 支持 -b 参数在迁移前自动备份

适用场景（解读层）

  • Haskell 项目中需要对 PostgreSQL schema 与数据进行可复现的有序变更管理
  • 团队开发中需将数据库变更自动应用到其他环境（开发、QA）
  • 开发与 QA 环境需安装 seed 数据，同时需防止 seed 数据进入生产库
