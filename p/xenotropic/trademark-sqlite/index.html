将 USPTO 商标 XML 文件解析并存入 SQLite 数据库的工具

综述（解读层）

trademark-sqlite 由 PHP 脚本组成：get_data_from_uspto.php 用 wget 下载 USPTO 初始发布的 53 个商标 XML 文件（约 5GB），create_tmdb.sql 用于初始化默认名为 tmdb.sqlite3 的数据库，parse_trademarks.php 解析单个文件并提取商标名称、申请日期、序列号和注册号后写入数据库。目前仅对 2015 年及更早的数据做过测试，且数据库默认路径需在使用者代码中手动修改。

  • 解析 USPTO 商标 XML 文件并提取商标名称、申请日期、序列号和注册号等字段写入 SQLite
  • 包含下载脚本（使用 wget，初始数据约 5GB）和数据库初始化 SQL 文件 create_tmdb.sql
  • 提供 process_files.php 批量循环调用解析逻辑处理多个文件

适用场景（解读层）

  • 需要将 USPTO 历史商标申请数据（2015 年及更早）导入本地 SQLite 数据库进行分析
  • 需要离线保存和查询商标名称、序列号、注册号等基础字段的场景
  • 希望基于该数据集扩展开发商标监控工具的开发者（作者在 README 中提及此方向）
