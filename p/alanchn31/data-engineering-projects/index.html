🧭 简介解读层（AI·证据行可回查）

基于 Udacity 数据工程课程实践的 ETL 与数据建模项目集合。

综述（解读层）

该仓库收录作者在学习 Udacity 数据工程纳米学位期间完成的七个项目，涵盖 Postgres 星型模型、Cassandra 查询建模、Scrapy 采集入库 MongoDB、AWS Redshift 数据仓库、Spark 构建 S3 数据湖、Airflow 调度管道及电影数据仓库毕业项目。课程笔记存放于 `0. Back to Basics` 文件夹，适合参照学习多种存储与管道技术。

  • 提供 Postgres、Cassandra、MongoDB 三种数据库的 ETL 与数据建模实践，分别采用 STAR schema、查询中心建模和文档存储
  • 包含使用 Spark 将 JSON 文件反规范化为事实与维度表并以 Parquet 格式写入 AWS S3 数据湖的项目
  • 使用 Airflow 定义并调度从 S3 到 Redshift 的 ETL 工作流，毕业项目为自选的电影数据仓库

适用场景（解读层）

  • 参考 Postgres、Cassandra 等不同数据库在数据建模上的实践方式
  • 了解从数据采集（Scrapy）、存储（MongoDB/S3/Redshift）到调度（Airflow）的 ETL 流程实现
  • 作为学习数据仓库与数据湖构建时的代码示例
