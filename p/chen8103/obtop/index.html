基于 OBProxy 与 GV$OB_PROCESSLIST 的 OceanBase 活动 SQL 终端监控工具

综述（解读层）

obtop 是面向 OceanBase 的活动 SQL 监控工具，交互风格参考 innotop。它通过 OBProxy 查询 GV$OB_PROCESSLIST 并过滤空闲会话，提供终端 TUI、输出 JSON/NDJSON 的机器可读 CLI 以及可被 Go 程序导入的公共 SDK。使用者需通过具备查询 GV$ 视图权限的账号连接 OBProxy；当前版本 v0.1.4 处于试用阶段，SDK 和 CLI 接口后续可能调整。

  • 提供 TUI、JSON/NDJSON 输出的 CLI（snapshot/watch/sql-history/explain）与 Go SDK 三种使用方式
  • 默认每 1 秒刷新活动 SQL，展示 OPS/QPS 及按语句类型的每秒速率，支持排序、筛选、kill、explain 和按用户会话排空
  • 基于 GV$OB_SQL_AUDIT 提供短 SQL 历史查询，带 completeness 状态、游标翻页与明确错误返回

适用场景（解读层）

  • DBA 在终端实时查看 OceanBase 活动 SQL、QPS/OPS 指标并按会话 ID 执行 kill 或 explain
  • 运维脚本或监控系统通过 CLI 获取 JSON/NDJSON 格式的快照与历史数据
  • Go 程序通过导入 SDK 实现会话查询、KillSession 或按用户排空会话等管理功能
