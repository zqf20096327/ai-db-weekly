🧭 简介解读层（AI·证据行可回查）

面向 AI 的多数据源命令行工具，按连接名非交互执行，统一 JSON 输出，默认只读。

综述（解读层）

ai-db-cli 是一个独立 Java 17+ 命令行工具，首版支持达梦 DM8 与 Redis，供 AI 代理或脚本按连接名调用数据库。查询使用 ? 参数绑定，stdout 始终输出 JSON 对象，默认只读，写入需同时满足连接开启写、表在允许列表、调用带 --allow-write 三个条件。分发包内置裁剪 OpenJDK 与驱动，仅覆盖 macOS；首版不支持 DM TLS、Redis Cluster/Sentinel 或 SSH 隧道。

  • SQL 使用 ? 参数绑定，结果统一 JSON 输出，数值以字符串保留精度，退出码区分参数、权限、后端与超时错误
  • 写入采用三重条件控制：连接级开关、表/命令允许列表、--allow-write 标志，UPDATE/DELETE 必须带 WHERE 且超 maxRows 回滚
  • 分发包内置裁剪 OpenJDK、JDBC 驱动与 Redis 客户端，配置以 0600 权限原子写入并加文件锁

适用场景（解读层）

  • 为 AI 代理或自动化脚本提供 DM8/Redis 的非交互查询与受控写入接口
  • 在 macOS 上以独立分发包运行数据库 CLI，无需预装 Java 或数据库客户端
  • 需要将 SQL 与 Redis 命令结果以结构化 JSON 解析的流水线场景
