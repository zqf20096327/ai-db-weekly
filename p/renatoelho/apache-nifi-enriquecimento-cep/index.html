🧭 简介解读层（AI·证据行可回查）

基于 Docker Compose 的 Apache NiFi 数据流示例项目，演示消费 API 数据并写入 MySQL。

综述（解读层）

该项目提供一个 Apache NiFi 数据流配置，用于调用 CEP（巴西邮政编码）API 获取数据并将结果写入 MySQL 数据库。运行环境由 Docker Compose 编排，包含 NiFi 与 MySQL 两个服务。使用者需要安装 Docker、Docker Compose 和 Git，通过 docker compose 命令启动后经 HTTPS 8443 端口访问 NiFi 图形界面。访问凭据记录在 docker-compose.yaml 文件中。

  • 提供经 Docker Compose 编排的 Apache NiFi 与 MySQL 服务，可通过单条命令启动和停止
  • 包含用于消费外部 API 数据并写入 MySQL 的 NiFi 数据流配置
  • NiFi 服务通过 https://localhost:8443/nifi 图形界面访问，凭据位于 docker-compose.yaml

适用场景（解读层）

  • 学习和演示如何在 NiFi 中配置从 API 读取数据并写入数据库的流程
  • 在本地搭建基于 Docker 的 NiFi 与 MySQL 集成实验环境
  • 参考使用 NiFi 图形界面编排 ETL/ELT 数据管道的方式
