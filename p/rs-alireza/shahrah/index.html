用 Rust 编写的 PostgreSQL 代理，按指定键分片并按区域路由用户数据

综述（解读层）

shahrah 是面向地理分布式 PostgreSQL 部署的代理，维护每个键所在区域的目录，将读写拆分路由到对应区域，并在迁移键时保持应用读写不中断。应用通过 PostgreSQL wire protocol 连接，无需安装驱动；无拓扑文件时所有语句透传到后备后端。Geo-partitioned 表语句若不带键会被拒绝。

  • 通过 PostgreSQL wire protocol 通信，请求路径中不含 shahrah 特有代码，无需安装驱动
  • 维护键到区域的目录并提供 RELOCATE 命令，迁移期间持有相关语句直到切换完成；中断的迁移可用 REPAIR 完成
  • 提供 psql 可访问的 shahrah 控制台、Prometheus 格式 /metrics、WebSocket 实时仪表盘及多代理 Raft 组同步拓扑

适用场景（解读层）

  • 用户分布在多个区域、需要每个用户数据存于其所在区域的 PostgreSQL 部署
  • 需要在应用程序持续读写的同时把某个键迁移到另一区域
  • 需要读写拆分、连接池以及按区域拓扑观测多代理集群
