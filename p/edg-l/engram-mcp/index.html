🧭 简介解读层（AI·证据行可回查）

Rust 编写的 MCP 服务器，为编码代理提供跨会话的持久记忆。

综述（解读层）

Engram 是一个用 Rust 实现的 MCP 服务器，让编码代理在不同会话间保留记忆。代理在会话结束时写入交接记录（决策、阻塞项、已放弃的尝试），同 git 分支的下个会话可从中恢复。数据存储在本地 SQLite 文件，使用本地 ONNX 嵌入模型，不调用云服务。安装通过 cargo install，含 engram（服务器）与 engram-cli（命令行）两个二进制。限制为单用户、单节点、无鉴权，同步需通过 SSH 两两进行且删除不同步。

  • 会话交接按 git 分支链式组织，附带项目级待办列表（含 done/dropped 状态）
  • 检索结合 BM25 与本地 ONNX 嵌入，记忆可被新版本取代并可从回收站恢复
  • 架构决策以编号 ADR 形式管理（proposed/accepted/superseded），可导出为 Markdown；项目 id 取自 git remote，可经 SSH 在两台机器间同步

适用场景（解读层）

  • 编码代理（如 Claude Code）跨会话恢复某个分支上的工作上下文
  • 需要将决策、调试发现等以 ADR/事实形式长期留存并检索的个人项目
  • 在两台可通过 SSH 访问的机器之间同步同一仓库的记忆数据
