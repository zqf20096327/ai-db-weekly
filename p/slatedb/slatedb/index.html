基于对象存储的嵌入式 LSM-tree 存储引擎，用 Rust 编写。

综述（解读层）

SlateDB 是一个以 Rust 实现的嵌入式存储引擎，采用 LSM-tree 结构，将数据写入对象存储（S3、GCS、ABS、MinIO 等）。写入先更新内存 WAL 与 MemTable，定期批量刷盘为 SST 以降低 PUT 成本；读取依赖块缓存、压缩、布隆过滤器和本地磁盘缓存。面向需要在应用中嵌入键值存储且后端使用对象存储的开发者。许可为 Apache-2.0，隶属 Commonhaus 基金会。

  • 提供 get、put、delete 基础 API，支持范围查询、事务、合并算子和 CDC
  • 通过 object_store crate 支持任何实现 ObjectStore trait 的对象存储，MemTable 按可配置间隔批量刷为 SST
  • 实现块缓存、磁盘缓存、压缩、布隆过滤器、Compaction，以及数据库拆分/合并和 Clone 功能

适用场景（解读层）

  • 在 Rust 应用中嵌入基于对象存储（S3/GCS/ABS/MinIO 等）的键值存储
  • 需要利用对象存储实现存储容量扩展和数据持久化，并可接受较高读写延迟与 API 成本的场景
  • 通过官方 Go、Java、Node.js/TypeScript、Python 绑定在其他语言中使用
📖 README 首段存档原文 · 程序抽取

SlateDB is an embedded storage engine built as a log-structured merge-tree. Unlike traditional LSM-tree storage engines, SlateDB writes data to object storage (S3, GCS, ABS, MinIO, Tigris, and so on).
