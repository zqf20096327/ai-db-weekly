UNEP/GRID-Geneva 开发的自然资源地理空间数据在线管理平台

综述（解读层）

MapX 是由 UNEP/GRID-Geneva 开发的在线平台，用于管理自然资源相关的地理空间数据，应用于化学品管理、灾害风险治理、生物多样性规划、土地利用等领域，目标用户包括联合国环境署及其伙伴、多边环境协定秘书处、NGO、学术界等。技术栈包含 Node.js、Express.js、R/Shiny、PostgreSQL/PostGIS、GeoServer 与 Mapbox GL JS，基于 Docker 容器部署，并已集成到 UNEP 的世界环境状况室平台。README 主要面向开发者，描述了开发环境搭建、CI/CD 构建流程与版本管理机制。

  • 提供基于 docker-compose 的开发环境，包含 app、api、routines、pg 等服务，通过 GitHub Actions 实现推送、手动和每周定时三种构建工作流
  • 使用 release-it 管理版本，遵循 Conventional Commits 规范生成版本号与更新日志
  • 内置基于 SDK 的端到端测试工具，并附含用于导出裁剪的国家边界示例数据集（mx_countries）

适用场景（解读层）

  • 环境决策场景中的地理空间数据收集、管理与可视化，如生物多样性规划、土地利用规划
  • 开发者参与 MapX 项目开发，在本地通过 Docker 搭建与生产环境一致的容器化开发栈
  • UNEP 相关机构及合作伙伴需要接入 World Environment Situation Room 数据平台时的部署参考
