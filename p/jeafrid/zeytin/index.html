基于 Dart 的内嵌式 Web 服务器与自研 NoSQL 数据库一体化方案

综述（解读层）

Zeytin 用 Dart 实现 Web 服务器与内嵌磁盘型 NoSQL 引擎（Truck）的一体化架构，数据以 Truck/Box/Tag 三层组织，通过 .dat 数据文件与 .idx 索引文件存储。每个 Truck 运行在独立 Isolate 中，配备 LRU 缓存与自定义二进制编码。安装脚本会配置 Dart、Docker、Nginx、SSL 等依赖。面向需要在单一进程中同时获得服务与存储能力的开发者。

  • 提供 Truck（每用户隔离的数据库文件）、Box（逻辑分类）、Tag（唯一键）三层键值存储结构，含 .dat 数据文件与 .idx 偏移索引
  • 每个 Truck 运行于独立 Dart Isolate，拥有独立内存、缓存和处理队列；写入数据经自定义二进制编码后追加至文件并写入 LRU 缓存
  • 提供 AES-CBC 端到端加密（密钥源自用户密码）、IP 限速与封禁的 Gatekeeper 模块、WebSocket 变更监听及 LiveKit 音视频房间集成

适用场景（解读层）

  • 希望服务器与数据库部署在同一进程、避免外部数据库服务的应用后端
  • 需要按用户隔离数据（每用户独立 Truck）的多用户场景
  • 需要实时数据变更推送或音视频通话房间的应用（依赖内置 WebSocket 与 LiveKit 支持）
