面向多种 SQL 数据库的响应式类型安全 Scala DSL

综述（解读层）

Morpheus 是一个面向 MySQL、Postgres、MSSQL、MariaDB、Oracle 和 Sybase 的响应式类型安全 Scala DSL。它不设查询编译器，而是为各数据库分别实现引擎，通过切换依赖与 import（如 com.outworkers.morpheus.mysql._）获得对应方言的完整方法集，使用方在编译期即可发现该方言不支持的语法。README 声明项目尚未达到生产可用状态。

  • 为 MySQL、Postgres 等多种 SQL 数据库分别实现引擎，并以统一的流式 DSL 提供访问
  • 按数据库方言划分模块，通过依赖与 import 切换，不支持的语法在编译期报错
  • 稳定版发布于 Maven Central，中间版发布于 Bintray 仓库 outworkers/oss-releases

适用场景（解读层）

  • Scala 项目中需要以类型安全 DSL 读写 MySQL 或 Postgres 等数据库
  • 希望直接使用数据库原生 SQL 语法特性（如 MySQL 的 DISTINCTROW）而非抽象层原语
  • 需要按目标数据库切换方言模块且在编译期校验语法可用性的场景
