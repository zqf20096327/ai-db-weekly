Rust 编写的单机内存优先向量数据库，HNSW 检索 + pgwire/HTTP 接口

综述（解读层）

HouyiDB 是一个用 Rust 实现的单机、内存优先向量数据库，提供 HNSW 向量检索、PAX 行列混存、pg_wire 与 HTTP 双接口，并通过 WAL 与磁盘快照支持 kill -9 后重启恢复。面向需要嵌入向量存储与检索的 AI/RAG 应用开发者，可通过 Docker、源码构建运行，附 Python、TypeScript、Go 等六语言 SDK 及 MCP server。

  • 提供 pg_wire（text/binary）与 HTTP 双接口，支持带 payload 的 upsert、SQL 混合检索与谓词下推 bitset 剪枝
  • 实现 HNSW 双速写入（HotBuffer + Async-Builder）、SIMD 距离计算（NEON/AVX feature 隔离）及 Clustered/PQ/HII-L0 多后端
  • 通过 WAL（异步写线程 + checkpoint/rotate）、磁盘快照与冷启动实现重启恢复；提供 C ABI 轻量索引支持 iOS/Android

适用场景（解读层）

  • LLM/RAG 应用中嵌入向量的存储与近似最近邻检索
  • 通过 pgwire 客户端或六语言 SDK（含 LangChain/LlamaIndex adapter）集成向量检索
  • 通过 MCP server 接入 Claude Code、Cursor、Cline 等客户端进行检索与写入
