基于 SQLite 与 ContentProvider 的 Android 数据库操作库

综述（解读层）

该库是面向 Android 的数据库封装，基于 SQLite 和 ContentProvider 实现，提供增删改查和 RxJava 两种操作方式。开发者需为每张表编写继承 BaseTable 的表类，并在 AndroidManifest 中注册 ContentProvider。它不使用反射，支持表级数据迁移；自定义对象需序列化为 TEXT 存储，且不支持表关联。

  • 提供 SQLite 与 RxSQLite 两个入口类，query/insert/update/delete 操作均有直接调用与 Rx 两种形式
  • 支持通过 BasicTableObserver/ContentTableObserver 观察表变更，可手动或自动发送通知
  • 基于表类版本号（getLastUpgradeVersion）实现数据迁移，默认重建表并可通过 onUpgrade 覆写自定义

适用场景（解读层）

  • Android 应用中需要通过 ContentProvider 管理本地 SQLite 数据的场景
  • 使用 RxJava 并需要订阅数据库表变更的 UI 与网络层通信
  • 需要手动控制表结构升级与数据迁移逻辑的项目
