PHP 后台管理框架，可视化生成可修改的 CRUD 模块代码

综述（解读层）

Milk Admin 是一个用于构建后台与内部管理工具的 PHP 框架（Beta 状态）。其 Projects 模块可从 UI 设计表单并生成真实 PHP 模块（PHP 层为最终权威，JSON 层存配置）；字段存为真实数据库列而非 EAV。支持 MySQL/SQLite，经 PHPStan Level 5 与 PHPUnit 验证，MIT 协议发布。

  • 从模型定义生成含分页、排序、搜索、验证与自动持久化的 CRUD 界面，数据库表自动创建和更新
  • 可视化模块生成器输出 PHP 代码加 JSON 配置的双层结构，生成代码可自由修改扩展
  • 内置认证（含防暴力破解）、基于 DAG 的角色权限、CSRF/XSS/SQL 注入防护及 Token/JWT API 支持

适用场景（解读层）

  • 构建关系型、嵌套数据模型的内部后台或管理工具
  • 需运行在共享主机、不依赖完整框架栈的场景
  • 先快速原型再逐步加入自定义业务逻辑的项目
