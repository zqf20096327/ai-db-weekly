🧭 简介解读层（AI·证据行可回查）

连接多种数据库的 MCP 服务器，为 LLM 提供统一的查询 API

综述（解读层）

Turbular 是基于 FastAPI 实现的开源 MCP 服务器，通过统一 API 接口让 LLM 代理连接 PostgreSQL、MySQL、SQLite、BigQuery、Oracle 等 7 种数据库。它对数据库模式做归一化处理以适配 LLM 命名规范，并支持将 LLM 生成的归一化查询转换回原始形式后执行，查询返回行数可通过 max_rows 限制。

  • 通过单一 API 支持 PostgreSQL、MySQL、SQLite、BigQuery、Oracle、MS SQL、Redshift 七种数据库
  • 提供模式归一化机制：将数据库模式规范化为 LLM 兼容命名，并支持归一化查询与原始查询间的转换
  • 提供 get_schema、execute_query、健康检查等 REST 端点，支持 SSL 与多种认证方式，可用 Docker Compose 部署

适用场景（解读层）

  • 为需要访问多种数据库的 LLM 代理或 AI 应用提供统一的数据读取接口
  • 让 LLM 基于归一化后的模式生成 SQL 查询，再由服务器转换并执行
  • 需要通过 MCP 协议向模型暴露数据库 schema 与查询能力的集成场景
