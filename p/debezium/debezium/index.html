开源变更数据捕获平台，基于 Kafka 与 Kafka Connect 流式传输数据库行级变更事件

综述（解读层）

Debezium 是一个用于变更数据捕获（CDC）的开源数据流平台，通过部署在 Kafka Connect 上的连接器监控数据库，将已提交的行级变更以统一事件模型写入 Kafka 主题；也提供嵌入式引擎在应用内直接运行连接器。适用于需消费数据库变更事件的应用开发者与数据集成团队。构建需 JDK 21、Maven 3.9.8 及 Docker。

  • 提供统一的变更事件模型，只暴露已提交的事务变更，应用可随时停止并在重启后从断点继续消费
  • 连接器运行于 Kafka Connect 分布式服务之上，变更事件按上游顺序记录到 Kafka 主题，支持多客户端独立消费
  • 包含通用模块与针对特定数据库的定制模块，并通过 Docker 运行集成测试验证与外部数据库的交互

适用场景（解读层）

  • 缓存失效：记录变更或删除时同步更新 Redis 等外部缓存
  • 替代双写：提交后异步更新搜索索引、发送通知等，降低多系统不一致风险
  • 数据集成与 CQRS：捕获变更事件以同步多个存储或更新只读视图
