根据数据库 schema 生成 Go ORM 代码的 database-first 工具

综述（解读层）

SQLBoiler 是一个 Go 代码生成工具，读取已有数据库 schema 后生成配套的 ORM 模型代码，属于 database-first 而非 code-first 路线。使用者需先用迁移工具建好表结构。README 注明项目处于维护模式：不再接受新特性，仅接受社区提交的 bug 修复与版本兼容改动。仅 v4 为维护中的版本，且不支持 GOPATH 项目。

  • 根据现有数据库 schema 生成类型安全的 Go ORM 模型代码，支持钩子、预加载、事务、自动 CreatedAt/UpdatedAt、原始 SQL 回退等特性
  • 官方提供 PostgreSQL、MySQL、MSSQL Server 2012+、SQLite3 驱动，并支持外部自定义驱动（如社区提供的 CockroachDB 驱动）
  • 配置基于 viper，支持 TOML 配置文件与环境变量，可通过 whitelist/blacklist 控制生成的表和列

适用场景（解读层）

  • 已有存量数据库表结构、希望基于 schema 直接生成 Go 模型代码的场景
  • 使用 PostgreSQL、MySQL、MSSQL 或 SQLite3 并需 ORM 能力（关联、预加载、钩子）的 Go 项目
  • 偏好 database-first 工作流、用 sql-migrate 等工具管理 schema 迁移的团队
