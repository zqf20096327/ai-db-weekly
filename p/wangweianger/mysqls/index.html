Node.js 链式调用生成 MySQL SQL 语句的插件，支持事务

综述（解读层）

mysqls 是一个用 JavaScript 编写的 Node.js 插件，通过链式调用（table、field、where、data 等）生成 SQL 语句，覆盖 select、insert、update、delete 操作，并提供 transaction API 执行事务。它既可仅生成 SQL 语句，也可经 init 初始化连接配置后用 exec 或 async/await 直接执行，默认启用连接池。适用于需要在 Node.js 项目中操作 MySQL 数据库的开发者。

  • 提供链式调用方式生成 select、insert（含批量插入）、update、delete 语句
  • 提供 transaction API，可传入 SQL 数组执行事务
  • 支持 Promise 与 async/await 调用方式，init 配置默认启用连接池

适用场景（解读层）

  • 在 Node.js 项目中通过链式调用生成或执行 MySQL 的增删改查语句
  • 需要将多条 update 等语句放入同一事务执行的场景
  • 仅需生成 SQL 语句字符串供其他环节使用的场景
