基于 ClickHouse 的多租户指标存储服务

综述（解读层）

Vertex 是一个用 Elixir 编写的 HTTP 服务，用于将带租户标识的指标事件写入 ClickHouse。事件按 tenant 字段划分，可携带标签，支持单条和批量提交。部署时需先执行 setup.sql 建库，通过环境变量配置 ClickHouse 连接，并在 projects.json 中登记项目名与访问令牌的对应关系。触发器和异常提醒功能在 README 中列为计划中的设想，尚未实现。

  • 事件按 tenant 字段划分租户，可附带 tags 标签
  • 提供 /event 与 /events 两个 HTTP 接口，支持单条与批量写入
  • 通过 Bearer 访问令牌认证，令牌映射在 projects.json 中配置

适用场景（解读层）

  • 按租户记录应用事件（如 account.login、order.success）并存储到 ClickHouse
  • 需要区分多租户/多项目指标数据的场景
  • 在已有 ClickHouse 基础设施上接入指标写入服务
