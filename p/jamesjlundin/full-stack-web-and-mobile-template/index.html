基于 pnpm+Turborepo 的全栈 Web/移动端单仓模板，集成认证、数据库与 CI/CD

综述（解读层）

这是一个 TypeScript 单仓模板，在共享代码库下同时提供 Next.js Web 应用和 React Native 移动应用，内置 Better Auth 认证、PostgreSQL+Drizzle 数据库、AI 流式聊天、邮件发送及 GitHub Actions 部署流水线。适合想以同一套代码同时构建 Web 与移动端应用的开发者；部分功能依赖 Vercel、Neon、Resend 等外部服务，iOS 发布需 Apple 开发者账号。

  • 采用 pnpm workspaces + Turborepo 组织 Next.js 16 与 React Native 应用，共享业务逻辑与类型
  • 包含 Better Auth 认证（Web 会话 + 移动端 JWT）、Drizzle ORM 自动迁移、基于 Upstash Redis 的限流
  • 提供 OpenAI 流式聊天示例，支持工具调用与图像生成，并内置 Playwright/Vitest 测试与 GitHub Actions 部署流程

适用场景（解读层）

  • 从模板创建新仓库，快速搭建同时包含 Web 与 iOS/Android 客户端的全栈项目
  • 需要认证、数据库、邮件、AI 聊天等模块预先接线的项目起点
  • 部署到 Vercel 并通过 GitHub Actions 自动执行测试、迁移与发布
