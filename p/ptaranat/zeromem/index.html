🧭 简介解读层（AI·证据行可回查）

为 Hermes Agent 提供本地 SQLite 存储、无 LLM 调用检索的记忆系统

综述（解读层）

zeromem 是 Zero-Mem 论文（arXiv:2607.29377）的 Rust 实现，将 Hermes Agent 的每条消息逐字存入单个本地 SQLite 文件，检索过程不调用 LLM，仅在模型读取返回结果时消耗 token。每轮消息通过实体图、时间线层级和 BM25+稠密嵌入三种方式索引，图与时间线索引在打开时可从原始轮次重建。可作为 Hermes 插件安装，也提供 Python 库、CLI 和 Claude Code MCP 集成；默认嵌入模型为英文向的 bge-small-en-v1.5，非英语对话需切换 multilingual-e5-small。

  • 消息逐字存储于单个本地 SQLite 文件，存储与检索消耗零 token，检索步骤不调用任何 LLM
  • 每轮消息以三种方式索引：实体图（PPR）、时间线层级（轮次/窗口/片段）、BM25 加稠密嵌入，查询经确定性画像路由并融合两路检索分数
  • 提供 zeromem_recall/zeromem_stats/zeromem_forget_session 工具，支持后台同步与前一轮的证据预取，可从 Hermes 会话历史零 token 导入且幂等

适用场景（解读层）

  • 为 Hermes Agent 配置本地记忆提供者，逐字保留会话历史并按轮次检索证据
  • 在 Claude Code 中通过 MCP 共享跨项目的单一记忆库（注意无会话身份限制）
  • 通过 Python 或 CLI 对 JSONL 格式的对话轮次做离线摄取与查询检索
