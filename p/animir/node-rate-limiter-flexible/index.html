Node.js 事件计数与限流库，支持内存、Redis、数据库等多种存储

综述（解读层）

rate-limiter-flexible 是 Node.js/Deno 环境下的计数与限流工具，用于按 IP、用户 ID、token 等键消耗点数并限制事件频率。它对接 Redis/Valkey、MongoDB、MySQL、PostgreSQL、SQLite、DynamoDB、Memcached、Prisma 等存储，也可运行于进程内存、Cluster 或 PM2，内存版可在浏览器使用。内存与分布式操作采用原子递增，提供 get、set、block、penalty 等方法，并给出 Express、Koa、Hapi、NestJS 等中间件或插件包。

  • 支持内存、Cluster/PM2、Redis、Valkey、MongoDB、MySQL、PostgreSQL、SQLite、DynamoDB、Memcached、Prisma、Drizzle、Etcd 等多种存储后端
  • 内存与分布式环境下的递增操作为原子操作，并提供 Block Strategy 与 Insurance Strategy 选项
  • 提供 consume/get/set/block/delete/penalty/reward 等 API，支持 RateLimiterUnion 组合限流与黑白名单包装器

适用场景（解读层）

  • 登录接口或密码重置端点的暴力破解防护
  • API 接口、WebSocket 连接、第三方调用等按 IP/用户/token 限流
  • 应用从单机内存限流迁移到分布式存储限流的统一接口场景
