🧭 简介解读层（AI·证据行可回查）

基于 Couchbase Lite C 库与 dart:ffi 的 Dart 版嵌入式 NoSQL JSON 文档数据库。

综述（解读层）

该库将 Couchbase Lite 数据库通过 dart:ffi 移植到 Dart，底层依赖 Couchbase Lite C 共享库。支持文档 CRUD、N1QL 风格查询、复制同步与 Blob 存储，主要面向 Dart/Flutter 开发者。README 明确警告项目处于早期开发阶段，API 尚不稳定，可能出现破坏性变更；Windows 为 Beta 状态，Android 需自行配置共享库，iOS/macOS 暂不支持。

  • 提供数据库打开/关闭/复制/压缩/删除、批量操作（类事务）与变更通知能力
  • 支持基于 N1QL 的查询、查询参数、explain、实时查询监听及 value/全文（FTS）索引
  • 提供复制同步（Basic/Session 认证、pull/push 过滤器、冲突解决回调）与 Blob 的内容/流式 API

适用场景（解读层）

  • 在 Flutter/Dart 应用中进行本地 JSON 文档数据存储与查询
  • 需要本地数据库与远程服务器间数据同步（pull/push 复制）的移动或桌面应用
  • 需要在本地存储 Blob 二进制数据并使用 FTS 全文索引的场景
