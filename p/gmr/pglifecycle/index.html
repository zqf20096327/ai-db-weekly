将 PostgreSQL 数据库 schema 管理为版本控制的 YAML 文件的工具

综述（解读层）

pglifecycle 用于把 PostgreSQL 数据库 schema 纳入版本控制的项目目录：每个数据库对象对应一个 YAML 文件，并依据 JSON-Schema 合同校验。它提供 pull（从在线数据库或 pg_dump 归档读取并写入项目）、build（生成 pg_restore 兼容的自定义格式归档）和 create（脚手架空项目）三个子命令。适用于以 Rust 工具链、Homebrew 或 Docker（内置 PostgreSQL 17 客户端工具）方式安装的 DBA 与开发团队。

  • 每个数据库对象对应一个 YAML 文件，并按 JSON-Schema 合同进行校验
  • pull 命令可读取在线数据库或 pg_dump 归档并写入项目目录
  • build 命令生成 pg_restore 兼容的自定义格式归档

适用场景（解读层）

  • 将现有数据库 schema 导出为可版本控制的项目文件
  • 把 YAML 项目构建为可由 pg_restore 恢复的数据库归档
  • 在 CI 或容器环境中通过 Docker 镜像执行 schema 构建流程
