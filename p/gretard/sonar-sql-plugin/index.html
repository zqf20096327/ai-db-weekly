🧭 简介解读层（AI·证据行可回查）

基于 ANTLR4 语法的 SonarQube SQL 静态分析插件，支持多种方言

综述（解读层）

该插件为 SonarQube 提供 SQL 语言分析能力，支持 T-SQL、MySQL、PostgreSQL、Vertica、Snowflake 五种方言，基于 ANTLR4 语法实现解析。它可聚合 SQLCodeGuard、SQLCheck 等外部工具的问题报告，并支持 SQLCover 覆盖率、复杂度度量，以及用户以声明式格式自定义规则。版本 1.0.0 需 SonarQube 7.4+，1.2.0 需 9+。适用于需在 SonarQube 中纳入 SQL 代码检查的团队。

  • 基于 ANTLR4 语法支持 TSQL、MySQL、PostgreSQL、VSQL、Snowflake 五种 SQL 方言
  • 可报告 SQLCodeGuard、MSBuild、SQLCheck 的问题及 SQLCover 计算的代码覆盖率
  • 支持以声明式格式定义自定义检测规则，并提供 rulesHelper.jar 命令行工具打印解析 AST

适用场景（解读层）

  • 在 SonarQube 平台中对 T-SQL、MySQL、PostgreSQL 等数据库代码执行静态扫描
  • 结合 SQLCover 报告将 T-SQL 代码覆盖率导入 SonarQube 展示
  • 为特定代码库和领域定义声明式自定义规则以检测特定违规模式
