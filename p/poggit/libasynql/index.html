🧭 简介解读层（AI·证据行可回查）

面向 PocketMine 插件的异步 SQL 访问库，通过多线程执行查询避免阻塞主线程。

综述（解读层）

libasynql 是一个供 PocketMine 插件使用的异步 SQL 访问库，支持 MySQL 和 SQLite 两种数据库。插件作者在资源目录中按 Prepared Statement File 格式编写 SQL 语句，通过 libasynql::create() 初始化并返回 DataConnector 查询接口，查询在其他线程执行并经回调返回结果。README 提醒回调模式存在竞态问题，结果只能在其回调作用域内使用。

  • 支持 MySQL 与 SQLite 两种数据库类型，用户可通过 config.yml 选择
  • 在独立线程中执行 SQL 查询，提供 GENERIC、CHANGE、INSERT、SELECT 四种查询模式
  • 采用 Prepared Statement File 格式组织 SQL，按方言分文件，从 phar 资源直接读取

适用场景（解读层）

  • PocketMine 插件需要访问 MySQL 或 SQLite 存储数据
  • 插件需避免在主线程执行 SQL 造成阻塞
  • 需要为多种 SQL 方言维护各自的查询语句
