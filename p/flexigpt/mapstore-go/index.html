Go 本地文件系统键值存储库，可插拔编解码、密钥环加密与 FTS5 全文检索

综述（解读层）

mapstore-go 是一个 Go 库，用文件系统实现 map[string]any 的持久化存储，通过原子写入和乐观并发控制保持内存与磁盘同步。编码器可插拔，支持 JSON 及自定义格式；可选通过操作系统密钥环对值做 AES-256-GCM 加密，可选集成 SQLite FTS5 做全文检索。目录存储支持按月分区和 UUIDv7 文件名。需 Go 1.26+，跨进程并发为尽力而为模式。

  • 文件存储通过原子重命名写入和乐观并发保持内存 map 与磁盘文件同步，提供监听钩子观察每次变更
  • 提供可插拔的键/值编码器，内置 JSON 编码及基于 OS 密钥环的 AES-256-GCM 字符串值加密
  • 内置 SQLite FTS5 全文检索引擎及 SyncIterToFTS 增量索引同步工具，支持月分区与 UUIDv7 文件名

适用场景（解读层）

  • 需要在本地文件系统持久化键值数据并要求线程安全的 Go 应用
  • 需对敏感字符串值透明加密存储的本地配置或凭证管理场景
  • 需要本地全文检索能力且希望按时间分目录组织大量数据文件的场景
