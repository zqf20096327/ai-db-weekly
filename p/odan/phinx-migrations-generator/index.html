🧭 简介解读层（AI·证据行可回查）

通过对比当前数据库与已有 schema 生成 Phinx 迁移类的 PHP 代码生成器

综述（解读层）

该工具基于 PHP 8.1-8.5，通过 Composer 以开发依赖安装，对比当前数据库与 schema.php 中记录的上次结构，生成相应的 Phinx 迁移类。首次运行生成初始 schema，再次运行仅生成差异。支持表、列、索引、外键的增删改及字符集、排序规则等属性。适用于使用 Phinx 管理数据库迁移的 PHP 项目。MariaDB 为部分支持，外键迁移默认关闭。

  • 独立于框架运行，通过 vendor/bin/phinx-migrations generate 命令生成迁移类
  • 支持 MySQL 5.7+、MySQL 8，MariaDB 部分支持
  • 覆盖表/列/索引/外键的创建、更新、移除，以及字符集、排序规则、引擎、注释等属性

适用场景（解读层）

  • 为已有数据库生成 Phinx 初始迁移 schema
  • 数据库结构变更后生成增量差异迁移文件
  • 在 PHP 项目中以开发依赖形式集成自动化迁移生成流程
