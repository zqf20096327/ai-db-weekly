🧭 简介解读层（AI·证据行可回查）

基于服务端提交日志同步客户端 SQLite 数据库的离线优先同步引擎

综述（解读层）

Syncular 在每个客户端维护本地 SQLite 数据库，通过服务器拥有的提交日志进行同步，写操作先更新本地状态并进入 outbox，联网时由服务器校验。浏览器端用 OPFS 上的 SQLite，原生端共享 Rust 核心与 C FFI 绑定。项目处于 pre-1.0 阶段，公开 API 与协议细节仍可能变化，由 Benjamin Kniffler 个人维护。

  • 客户端读取本地 SQLite，支持离线写入，写入经 outbox 在同步时由服务器校验
  • TypeScript 与 Rust 双核心运行同一套一致性测试目录，协议规格附字节级测试向量
  • 服务器可运行于 Bun、Node 或 Cloudflare Workers，后端存储支持 SQLite、Postgres 或 D1

适用场景（解读层）

  • 需要离线继续工作、联网后同步的本地优先应用
  • 跨 Rust、Swift、Kotlin、Flutter、React Native、Tauri 等多端共享同步逻辑的项目
  • 后端服务以 headless 客户端或无数据库 SyncRemoteClient 形式参与同步流程
