AI 原生 ClickHouse 控制台，集成查询、诊断与可视化。

综述（解读层）

DataStoria 是面向 ClickHouse 集群的 Web 控制台，提供自然语言生成查询、AI 优化建议、执行日志查看、依赖图与监控面板等功能。SQL 查询从浏览器直接发往 ClickHouse 服务器，AI 功能需用户自带 LLM API 密钥。可通过在线站点、Docker 镜像或源码构建使用，采用 Apache-2.0 许可证。

  • 支持自然语言生成 ClickHouse 查询，以及基于 schema 检查和证据收集的优化建议
  • 提供查询执行时间线、AST 与 pipeline 视图、物化视图与分布式表依赖图
  • SQL 从浏览器直连 ClickHouse 执行，支持多集群、多节点监控；支持 OpenAI、Anthropic、Gemini、GitHub Copilot 等多种模型接入

适用场景（解读层）

  • ClickHouse 集群运维与多节点实时监控
  • 查询性能诊断与执行计划分析
  • 通过自然语言生成查询并渲染时间序列、柱状、饼图等可视化
