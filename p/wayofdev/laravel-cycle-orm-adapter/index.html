将 CycleORM DataMapper ORM 集成到 Laravel 框架的适配器包

综述（解读层）

该包为 Laravel 提供 CycleORM（DataMapper 模式 ORM）的适配层，面向需要在 Laravel 中采用领域驱动设计、分离领域模型与持久层的 PHP 开发者。README 给出版本兼容表：支持 Laravel 10.28 至 13.x、Cycle ORM 2.x、PHP 8.2/8.3，不同 Laravel 版本对应不同适配器版本。完整文档位于独立站点，安装方式需查阅文档。

  • 将 CycleORM DataMapper ORM 集成进 Laravel，用于领域模型与持久层的分离
  • 提供 Laravel 10.28 至 13.x 与 Cycle ORM 2.x 的版本兼容映射
  • 要求 PHP ^8.2（适配器版本 >5.0.0 时要求 ^8.3）

适用场景（解读层）

  • 在 Laravel 项目中采用 DDD 并使用 DataMapper 模式组织领域模型
  • 需要使用 Cycle ORM 2.x 进行数据库对象映射的 PHP 应用
  • 为 Laravel 应用引入 Eloquent 之外的另一种 ORM 集成
