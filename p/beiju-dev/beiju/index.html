面向 Node.js 的分析型查询构建器，含语义层与英/葡双语 API。

综述（解读层）

Beiju 是一个运行在 Node.js 20+ 上的 PostgreSQL 分析查询构建器，将 TypeScript 链式调用编译为参数化 SQL。它通过运行时自省数据库 schema 生成类型化列对象，提供窗口函数、聚合、JOIN 等面向 OLAP 操作的 API，适合需要在应用内编写分析查询的开发者。README 注明其源于本科毕业论文项目，定位为研究性制品，暂不支持 CTE、HAVING、DISTINCT 等。

  • 支持窗口函数（RANK、LAG、LEAD 等）及嵌套聚合如 AVG(SUM(col))
  • 运行时自动自省 PostgreSQL schema，列引用带类型并支持 IDE 补全
  • 每个语义层方法提供葡语别名，两种 API 生成相同 SQL

适用场景（解读层）

  • 在 Node.js 后端应用中构建销售排名、环比对比、移动平均等 OLAP 查询
  • 希望以类型化链式调用替代手写原始 SQL 字符串访问 PostgreSQL
  • 需要英语或葡语词汇编写查询的葡语开发团队
