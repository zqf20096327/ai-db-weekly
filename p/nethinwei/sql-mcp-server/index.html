综述（解读层）

该项目是一个 SQL 访问网关，以 MCP 协议向 AI Agent 提供对 PostgreSQL、MySQL 与 OceanBase 的查询能力，不接受任意 SQL，不提供 DDL。治理面通过显式 Entity、关系代数 IR 与参数化代码生成实现访问控制，含 RBAC、字段 ACL、row policy、EXPLAIN 预筛与结果上限等机制。可信操作者另有默认关闭的 execute_sql 逃生通道。当前版本 v0.1.21，MIT 许可，提供 Docker 快速体验。

  • 支持 PostgreSQL、MySQL 与 OceanBase 三类数据源，通过显式 Entity、关系代数 IR 和参数化 codegen 访问数据
  • 包含 RBAC、字段 ACL、row policy 与 mask 的统一治理，以及 EXPLAIN 预筛、结果上限、超时与 session/tenant 预算等成本控制
  • 提供默认关闭的 execute_sql 逃生通道，仅对显式授予 sql:execute@<数据源> 权限的用户可见，并有配置热重载、异步审计与 OpenTelemetry hook

适用场景（解读层）

  • 让 AI Agent（如通过 MCP 接入 Cursor、Claude Desktop、VS Code）以受控方式查询关系数据库
  • 需要对 Agent 的 SQL 访问实施字段级权限、行策略、数据脱敏与成本上限的多租户环境
  • 为数据源提供带审计与遥测的统一 SQL 访问入口，由可信操作者管理配置与权限
