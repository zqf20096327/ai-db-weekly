Rust 的 SQL 查询构建库，以组合式 API 生成 SQL 语句

综述（解读层）

这是一个 Rust 编写的 SQL 查询构建库，通过类似原生 SQL 的链式 API 生成查询语句，支持按调用顺序累积子句、条件添加子句以及结构体函数式的组合复用。库不校验参数内容，提供 debug() 方法打印当前构建状态以辅助调试，并提供 raw/raw_before/raw_after 插入任意 SQL 片段。通过 Cargo feature 启用 postgresql、sqlite、mysql 三种方言语法，另含 Insert、Update、Delete 构建器，适合需要在 Rust 中动态拼装 SQL 的项目。

  • 通过可选 feature（postgresql、sqlite、mysql）启用对应方言语法
  • 同一子句多次调用按调用顺序累积，limit/offset 等覆盖前值，子句顺序不影响输出
  • 支持 raw/raw_before/raw_after 插入原始 SQL，以及 .debug() 打印当前构建状态

适用场景（解读层）

  • 在 Rust 中根据条件动态拼装 SELECT/INSERT/UPDATE/DELETE 语句
  • 需要将复杂查询拆分为可复用的组合函数或模块的场景
  • 需要针对 Postgres、SQLite 或 MySQL 生成方言 SQL 的项目
