🧭 简介解读层（AI·证据行可回查）

Conduit 的 PostgreSQL 连接器插件，含源与目标，基于逻辑复制实现 CDC。

综述（解读层）

该插件为 Conduit 数据管道提供 PostgreSQL 的源与目标连接器。源端启动时先以只读锁对配置表做快照读取，随后切换到 CDC 模式，通过创建逻辑复制槽与 publication 监听表变更并转为记录；连接以 URL 配置，支持 SCRAM/TLS 及 channel_binding 设置。CDC 模式要求连接用户具备相应权限，复制槽丢失或被替换时连接器会拒绝启动并报出错误码。

  • 提供 source 与 destination 两种连接器，通过 url 设置连接数据库
  • 源端支持初始快照（可由 snapshotMode 配置关闭）与基于逻辑复制槽和 publication 的 CDC 模式
  • 写入 slot 身份信标（beacon）到 WAL，可检测复制槽被替换或被其他客户端推进的情形并拒绝启动

适用场景（解读层）

  • 捕获 PostgreSQL 指定表的行变更并转换为记录流入 Conduit 管道
  • 将数据写入 PostgreSQL 数据库作为管道目标端
  • 通过宿主进程提供的 dialer 代理连接器所有网络连接的场景
