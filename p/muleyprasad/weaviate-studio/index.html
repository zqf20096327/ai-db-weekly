🧭 简介解读层（AI·证据行可回查）

在 VS Code 中管理和查询 Weaviate 向量数据库的扩展，内置 GraphQL 编辑器

综述（解读层）

Weaviate Studio 是一款 VS Code 扩展，用于连接、管理和查询 Weaviate 向量数据库，支持自托管与云实例。功能包含多连接管理、Data Explorer 数据浏览（过滤、四种向量搜索、导入导出）、Monaco GraphQL 编辑器、RBAC 用户/角色管理、只读模式、备份恢复及集群监控。可通过 Marketplace、Open VSX 或 VSIX 安装；沙箱环境经 Docker Compose 启动，查询性能分析要求 Weaviate ≥ 1.36.9，MMR 多样化要求 ≥ 1.39。

  • 提供 Data Explorer，支持文本/对象/向量/混合四种向量搜索模式、10+ 过滤算子、JSON/CSV 导入导出与只读连接保护
  • 基于 Monaco 实现 schema 感知的 GraphQL 编辑器，包含模板生成、自动补全与实时校验
  • 支持 RBAC 用户/角色/组管理、API key 轮换、凭据经 VS Code secret storage 存储及跨文件系统/S3/GCS/Azure 的备份恢复

适用场景（解读层）

  • 开发者在 VS Code 内直接浏览、编辑和导出 Weaviate 集合数据而无需切换浏览器
  • 运维人员监控集群健康状态、管理用户权限并执行备份与恢复
  • 通过内置 Docker 沙箱学习 Weaviate，并使用生成式搜索界面测试 RAG 查询
