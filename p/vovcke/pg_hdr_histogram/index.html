🧭 简介解读层（AI·证据行可回查）

基于 HDR 直方图的 PostgreSQL 扩展，提供有界误差延迟分位数计算与无损合并。

综述（解读层）

该扩展将 HdrHistogram 封装为 PostgreSQL 一等类型，以压缩序列化 blob 存储于普通表中，支持 SQL 内聚合、查询 p50/p99/p99.9 等分位数及直方图间无损合并，聚合可并行执行。默认记录范围 0..1e9、3 位有效数字，范围与精度可按会话配置。适用于 PostgreSQL 14–18，需 zlib 与编译环境，MIT 许可，trusted 可由非超级用户安装。

  • hdr_histogram 类型以压缩 blob 存储，大小取决于数值分布跨度而非记录条数（密集数据约 42–48 B，全范围约 3.5 KB）
  • hdr_merge 支持跨时间窗口/主机无损合并，含 lossless/strict/left/union 四种参数不一致时的合并策略（会话级 GUC）
  • 聚合提供 COMBINEFUNC 与 SERIAL/DESERIAL 函数，GROUP BY 可跨 worker 并行合并；扩展标记 trusted，非超级用户可安装

适用场景（解读层）

  • 在 SQL 中对请求延迟等原始数值计算 p50/p99/p99.9 分位数
  • 将应用或遥测代理生成的 HdrHistogram 序列化数据写入表，按时间范围聚合查询
  • 跨时间窗口或主机合并预聚合的直方图帧而不丢失分布信息
