🧭 简介解读层（AI·证据行可回查）

FQLite：Java 编写的 SQLite 删除记录取证与恢复工具，提供图形界面。

综述（解读层）

FQLite 是用 Java 与 JavaFX 编写的开源工具，用于在 SQLite 数据库文件中查找并恢复被标记为删除的记录，同时支持正常记录浏览。它支持 UTF-8/UTF-16 数据库、freelist 页与未分配空间扫描、WAL 与回滚日志、sqlcipher 加密库，并可导出 CSV/TSV、HTML 及新 SQLite 库。项目提供官网与用户手册，另有介绍其技术背景与 AI 辅助 SQL 查询生成的论文。

  • 扫描并恢复数据库中标记为删除的记录，包括 freelist 页、未分配空间、被删除的表，支持 UTF-8/UTF-16BE/UTF-16LE 编码及溢出页
  • 支持 Rollback-Journal 与 WAL 存档、sqlcipher 加密数据库，提供内置十六进制查看器与 SQL 分析器
  • 可导出 CSV/TSV、HTML 格式，并将恢复数据写入新的 SQLite 数据库

适用场景（解读层）

  • 对 SQLite 数据库文件进行取证式检查，查找并显示已删除记录
  • 浏览数据库内容并导出为 CSV/TSV、HTML 或新 SQLite 数据库
  • 查看 WAL 与回滚日志存档中的数据，以及查看数据库 PRAGMA 值
