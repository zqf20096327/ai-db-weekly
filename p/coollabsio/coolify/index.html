综述（解读层）

Coolify 是一个开源、可自托管的应用部署平台，用于在自有服务器（VPS、裸金属、树莓派等）上管理应用、数据库和 360 余种一键服务。它基于 Docker 构建部署，支持从 GitHub、GitLab、Bitbucket、Gitea 拉取代码，用 Nixpacks、Dockerfile 或 Docker Compose 构建。README 提到项目免费开源，另有官方维护的付费 Cloud 版本。

  • 支持从 GitHub、GitLab、Bitbucket、Gitea 构建部署，提供 Nixpacks、Railpack、Dockerfile、Docker Compose 及预构建镜像方式
  • 提供 360+ 一键服务部署、托管数据库，含持久化存储与自动生成的凭据
  • 支持 Git push 自动部署、Pull Request 预览、Webhook 触发部署及镜像回滚；可管理自定义域名、自动 HTTPS 证书与反向代理

适用场景（解读层）

  • 在自有 VPS 或裸金属服务器上部署静态站点、全栈应用与数据库
  • 需要 Git push 自动部署和 Pull Request 预览环境的个人或团队开发流程
  • 管理多台服务器的基础设施运维，包括日志查看、容器终端、健康检查与资源监控
