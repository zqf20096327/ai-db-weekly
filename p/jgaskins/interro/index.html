Crystal 语言的 Postgres 查询库，将查询对象与模型分离

综述（解读层）

Interro 是面向 Crystal 语言的 Postgres 数据查询库。它要求模型只实现 crystal-db 的 DB::Serializable，不承担查询职责；查询由 QueryBuilder（生成 SQL）和 Interro::Query（手写 SQL）两种对象承担。查询需封装在 scope 方法内，数据库结构变更时只需修改对应查询类内部。安装方式为在 shard.yml 添加依赖后运行 shards install，仅支持 Postgres。

  • 提供 QueryBuilder 与 Query 两类查询对象，前者生成 SQL，后者支持任意手写 SQL 及 read_one/read_all/write 等读写方法
  • 查询构建方法返回新的 builder 实例，支持组合；where 等方法仅在查询类内部可用
  • 内置迁移工具 bin/interro-migration，以 up.sql/down.sql 文件执行与回滚迁移；通过 Interro.transaction 支持事务并自动回滚异常

适用场景（解读层）

  • Crystal 应用中访问 Postgres 数据库的增删改查
  • 复杂报表查询或单行返回多实体的场景，可用 Query 对象手写 SQL
  • 需要通过迁移文件管理数据库 schema 变更与回滚的项目
