综述（解读层）

dbcake 是一个单文件 Python 数据存储模块，可放入项目直接使用，也可通过 pip 安装。它提供键值存储、字典/列表/元组/数值操作，支持 binary、dec、hex 等存储格式，可选用 PBKDF2 与 AES-GCM 加密，并通过连接器访问 MySQL、SQLite、PostgreSQL、MongoDB、Redis 等数据库。加密功能需可选安装 cryptography 包。

  • 单文件零依赖，支持直接拷贝使用或 pip 安装
  • 支持多 Python 数据类型存储、三种加密级别、密钥轮换与多进程文件锁
  • 提供 MySQL、SQLite、PostgreSQL、MongoDB、Redis、Prisma 连接器及命令行接口

适用场景（解读层）

  • 需要嵌入式键值持久化存储的小型 Python 项目
  • 需要对本地数据文件加密保存的场景
  • 统一接口访问多种数据库并管理远程密钥的应用
