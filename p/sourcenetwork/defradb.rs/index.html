DefraDB 的 Rust 实现：P2P 文档数据库，基于内容寻址 CRDT、访问控制与 GraphQL

综述（解读层）

该项目是 DefraDB 数据库的 Rust 实现，提供 CLI、HTTP API、GraphQL 查询引擎与 P2P 复制能力，存储层使用纯 Rust 的 LSM-tree 引擎 Regolith。它面向嵌入式、边缘、浏览器（WASM）与服务器部署，并通过 FFI 以 C 兼容静态库形式供 Go 等语言嵌入。当前与 Go DefraDB v1.0.0-rc1 兼容，Go 与 Rust 节点可互联并复制数据。

  • 提供 GraphQL 查询引擎，覆盖查询、变更、订阅、聚合与 explain，并支持全量 defradb 测试套件
  • 支持基于 libp2p 的 P2P 复制传输（iroh 为可选），并提供 Postgres 客户端连接兼容（实验性）
  • 存储层统一使用纯 Rust ACID LSM-tree 引擎 Regolith，读取与扫描以流式方式执行，内存占用以当前页为界

适用场景（解读层）

  • 需要浏览器（WASM）或嵌入式设备上运行文档数据库的场景
  • Go 与 Rust 节点之间进行 P2P 数据复制的部署
  • 通过 FFI 将数据库以 C 兼容静态库嵌入 Go 或其他语言应用
