🧭 简介解读层（AI·证据行可回查）

用于在 Render 上部署定时任务，将 PostgreSQL 备份到 Amazon S3 的模板仓库。

综述（解读层）

该仓库提供在 Render 平台部署 Cron Job 的配置，用于将 PostgreSQL 实例备份到 Amazon S3。使用者需 Fork 仓库后一键部署，并根据所用数据库选择对应的 POSTGRES_VERSION 与 ALPINE_VERSION 组合（覆盖 Postgres 12 至 18）。更多操作说明见 Render 官方指南文档。

  • 提供 Fork 后一键部署到 Render 的 Cron Job 模板
  • 支持 PostgreSQL 12 至 18 版本，配套对应 Alpine 版本
  • 备份目标为 Amazon S3

适用场景（解读层）

  • 需要定时备份 Render 上托管的 PostgreSQL 数据库
  • 需将数据库备份文件存储到 Amazon S3
  • 使用 Render Blueprint 快速搭建备份流程
📖 README 首段存档原文 · 程序抽取

This repo can be used to deploy a Cron Job on Render to backup a PostgreSQL instance to Amazon S3.
