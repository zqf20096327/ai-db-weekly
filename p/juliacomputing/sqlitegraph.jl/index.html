基于 SQLite.jl 构建的 Julia 属性图数据库库

综述（解读层）

SQLiteGraph.jl 是一个在 SQLite.jl 之上实现的图数据库包，采用 Cypher 查询语言的属性图模型，节点含标签与键值属性，边为有向关系且须有类型。数据分别存于 nodes 与 edges 两张表，属性以 JSON3 序列化为 TEXT 存储；labels 以分号分隔，故标签中不能使用分号。适合在 Julia 环境中需要轻量图存储的用户。

  • 实现属性图模型：节点可含 0 个以上标签和键值属性，边为带类型的有向关系
  • 提供 insert!、replace! 等修改操作及 getindex 查询接口，使用 : 可返回迭代器
  • 节点与边分别存入 SQLite 的 nodes 和 edges 表，属性以 JSON3.write 序列化为 TEXT

适用场景（解读层）

  • 在 Julia 中以 SQLite 文件形式存储和查询属性图数据
  • 按标签筛选节点或按 id 访问节点与边
  • 对节点和边附带键值属性（如 title、genre 等示例字段）的场景
