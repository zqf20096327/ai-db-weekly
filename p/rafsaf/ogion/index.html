综述（解读层）

Ogion 是一个用 Python 编写的数据库定时备份工具，使用 pg_dump、mariadb-dump 等客户端导出数据，先经 lzip 压缩再用 age 加密，然后上传至 S3 兼容存储、Google Cloud Storage 或 Azure Blob Storage。它面向 home lab、个人项目等场景，可部署于 docker 或 Kubernetes，支持 amd64 和 arm64 架构。作者声明该项目不计划做根本性破坏变更，并在文档中注明更大的数据库可使用 pgBackRest 等工具。

  • 支持 PostgreSQL 18/17/16/15、MariaDB、MySQL 及单文件/目录备份
  • 备份流程为 lzip 压缩后用 age 格式加密，再上传至 GCS、S3 兼容或 Azure 存储
  • 提供 Discord、Email（SMTP）、Slack 通知，以 docker 镜像形式部署，支持 linux/amd64 与 linux/arm64

适用场景（解读层）

  • 为 home lab 或个人项目中的数据库设置每日定时备份并加密上传云端
  • 在 Kubernetes 或 docker compose 环境中运行容器化备份任务
  • 备份自托管服务的数据文件与配置目录（如 Nextcloud 配置、服务器文件）
