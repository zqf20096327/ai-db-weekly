Linux 自托管服务器控制面板，基于 Python/Flask + Alpine.js，MIT 开源

综述（解读层）

VortexPanel 是面向 Linux 服务器的开源控制面板，用于管理网站、数据库与应用部署。它支持 Nginx/Apache/OpenLiteSpeed/Caddy 四种 Web 服务器、MySQL/MariaDB/PostgreSQL/MongoDB 数据库，内置 WP Toolkit、ModSecurity WAF、Fail2ban、防火墙管理与 27 项一键安装的 App Store。安装脚本面向 Debian/Ubuntu 及 RHEL 系等多发行版，面板自身支持 HTTPS 与 2FA。README 包含与其他面板的功能对比表，解读时应以实际功能清单为准。

  • 支持管理 Nginx、Apache2、OpenLiteSpeed、Caddy 四种 Web 服务器及 PHP 多版本按站点配置
  • 内置 WP Toolkit（WordPress 一键安装、暂存克隆、安全扫描）、Git 部署与网站导入向导
  • 安全模块包含 UFW/firewalld 防火墙、Fail2ban、ModSecurity（OWASP CRS v4）、面板 2FA（TOTP）与 Argon2id 密码哈希

适用场景（解读层）

  • 在自有 VPS 或服务器上通过 Web 界面集中管理网站、SSL 证书、数据库与防火墙
  • 托管并部署 WordPress、Laravel、Go、Node.js、Python 等多种应用
  • 从 cPanel、aaPanel、HestiaCP 等面板迁移站点（备份归档导入或服务器间迁移）
