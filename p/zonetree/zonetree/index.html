.NET 平台上的 LSM-tree 有序键值存储引擎，支持事务与持久化

综述（解读层）

ZoneTree 是一个面向 .NET 的有序键值数据库与 LSM-tree 存储引擎，供开发数据库、索引、搜索系统、队列、事件存储等数据系统的团队使用。它提供写前日志、快照/可串行化事务、原子读改写操作、正反向迭代器与后台合并，通过 NuGet 包安装，支持内存与磁盘两种运行方式。

  • 提供可串行化与快照两种事务模式，事务基于多版本乐观并发控制，提交时全部写入生效或全部不生效
  • 支持配置 WAL 模式（Sync/AsyncCompressed/Shared 等），并提供 MIT 许可的开源实现
  • 可配置可变段记录上限以控制内存使用，支持数据量超过内存的数据集运行

适用场景（解读层）

  • 为 .NET 应用构建自定义索引、有序扫描与时间序列键值存储
  • 需要多键协调变更的事务性写入场景
  • 作为队列、事件存储或本地优先应用的上层存储基础
