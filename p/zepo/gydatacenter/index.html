基于 FMDB 的 iOS 持久化库，面向偏好直接使用 SQLite 的开发者

综述（解读层）

GYDataCenter 是一个构建在 FMDB 之上的 Objective-C 数据持久化库，提供面向对象接口，同时允许使用原生 SQL 查询。模型类继承 GYModelObject 并实现协议方法即可使用，库会自动创建和更新表结构与索引。适合既想要 Core Data 式便利、又希望直接控制 SQL 的 iOS 开发者，通过 CocoaPods 安装，采用 MIT 许可证。

  • 基于 FMDB 构建，提供面向对象接口并支持直接使用 SQL 子句（含嵌套查询）过滤数据
  • 自动创建和更新表结构，通过运行时 API 依据属性类型选择列类型，并自动创建和删除索引
  • 支持关系属性和 Faulting（惰性加载），并维护模型对象内部缓存，同一记录在不同线程返回同一对象副本

适用场景（解读层）

  • iOS 应用中需要对象化存储模型数据且开发者已熟悉 SQL 的场景
  • 需要对查询、索引和性能实现进行直接控制的本地数据持久化
  • 涉及对象关系且希望延迟加载关联对象、控制内存占用的数据模型设计
