将 SQLite 以 Swift Package Manager 包形式发布的封装库

综述（解读层）

该包将 SQLite amalgamation 按 SQLite 推荐的编译时选项打包为 Swift Package，供 Swift 项目通过 Swift Package Manager 引入。默认构建包含 carray、FTS5、数学函数、percentile、R*Tree、快照、stmt 与 stat4 等特性，decimal、ieee754、series、sha3、uuid 扩展以静态链接方式提供；Swift 6.1 及以上可通过 package traits 定制编译选项与功能。README 未提及对 SQLite C API 之外的 Swift 层封装（仅提供部分 C 函数 shim）。

  • 包含按 SQLite 推荐编译时选项构建的 SQLite amalgamation
  • 默认启用 carray、FTS5、数学函数、percentile、R*Tree、快照、stmt 与 stat4 特性，另静态链接 decimal、ieee754、series、sha3、uuid 扩展
  • Swift 6.1 及以上可通过 package traits 自定义编译选项（如 DQS、THREADSAFE）与启用功能（如 FTS4、SESSION）

适用场景（解读层）

  • Swift 项目需通过 Swift Package Manager 集成 SQLite
  • 需要按自定义编译时选项或特性组合构建 SQLite 的场景
  • 需要 FTS5、R*Tree、数学函数等 SQLite 扩展功能的 Swift 应用
