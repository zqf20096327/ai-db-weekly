🧭 简介解读层（AI·证据行可回查）

Rust 编写的本地 SQLite shell 历史存储，附带 AI 代理追踪与 MCP 服务器

综述（解读层）

Suvadu 用 SQLite 替代 shell 历史，为每条命令记录退出码、耗时、目录、执行者和会话等结构化上下文，并在 git 仓库内记录分支。通过 shell hook 集成 zsh/bash，AI 代理可经内置 MCP 服务器（22 个只读工具、8 资源、6 prompts）查询历史，Prompt Explorer 可回溯命令对应的触发提示词。数据 100% 本地存储，无云与遥测；每日一次的版本检查可关闭。适合需要在本地保留完整命令与代理会话记录的开发者。

  • 每条命令记录退出码、耗时、目录、执行者、会话及 git 分支（从仓库文件读取，不在提示符运行 git）
  • 提供 MCP 服务器：22 个只读工具、8 资源、6 prompts，两个写入工具默认关闭需 opt-in 开启
  • 捕获 Claude Code、Codex、OpenCode、Cursor 等代理会话；Prompt Explorer 将命令追溯到触发它的提示词

适用场景（解读层）

  • 在 zsh/bash 中以上箭头、Ctrl+R 或 TUI 交互式检索带完整上下文的历史命令
  • 让 MCP 兼容的 AI 代理查询本地命令历史、代理会话与项目上下文
  • 将团队命令技能以 Markdown 提交到代码仓库，克隆者经信任流程后同步使用

Suvadu replaces your shell history with a SQLite-backed store. Every command gets structured context — exit code, duration, directory, executor, session. AI agents can query it via MCP. 100% local.
