🧭 简介解读层（AI·证据行可回查）

TiDB 跨集群站点复制操作指南，结合 BR 备份恢复与 TiCDC 增量同步

综述（解读层）

该仓库是一份操作指南，内容为在两个 TiDB 集群之间建立站点复制的分步流程：通过 TiDB Operator 部署目标集群、在源集群禁用 GC、用 BACKUP/RESTORE SQL 语句经 S3 兼容存储（如 MinIO）做全量迁移，再创建 TiCDC changefeed 实现增量复制。面向需要在 Kubernetes 环境下执行 TiDB 集群间数据迁移与容灾搭建的运维人员。

  • 提供八个步骤的完整流程：部署目标集群、安装 TiCDC、禁用 GC、全量备份、恢复、创建 changefeed、验证状态、恢复 GC
  • 使用 BACKUP/RESTORE SQL 语句配合 S3 兼容存储，支持全库或指定数据库的备份与恢复，可指定文件夹路径
  • 给出 cdc cli 命令创建和查询 changefeed 的示例及预期输出

适用场景（解读层）

  • 在两个 TiDB 集群间进行全量加增量的数据迁移
  • 搭建基于 TiCDC 的站点间复制/容灾环境
  • 在 Kubernetes 上通过 TiDB Operator 管理的目标集群中执行恢复与同步操作
