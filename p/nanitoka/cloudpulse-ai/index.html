基于 FastAPI 与 Gemini 的多云 Kubernetes 可观测性与 AIOps 运维平台。

综述（解读层）

CloudPulse AI 是一个面向多云 Kubernetes 与微服务环境的可观测性运维平台，提供拓扑爆炸半径计算、SLO 监测、FinOps 成本治理、RAG 基础设施问答与自愈工作流。后端为 FastAPI + PostgreSQL + Redis + ChromaDB，前端为 React 18。默认运行于确定性演示模式，无需云凭据；实时模式需配置 Gemini API。支持 Docker Compose 一键启动，采用 MIT 许可证。

  • 集成 Gemini LLM 推理与本地确定性 SRE 引擎自动回退，基于 ChromaDB 向量库实现带证据引用的 RAG 基础设施问答
  • 支持多云（AWS/GCP/Azure/K8s）资产盘点、依赖拓扑图、SPOF 检测与标记 SIMULATION ONLY 的故障传播模拟
  • 内置多租户 RBAC、JWT 吊销、OpenTelemetry 分布式追踪与 WebSockets 亚秒级指标流

适用场景（解读层）

  • 多云 Kubernetes 集群与微服务的指标、日志、链路统一监控与 SLO 错误预算预测
  • 运维团队通过自然语言 RAG 对话查询集群遥测并进行多阶段审批的自愈修复操作
  • 企业 FinOps 成本治理：预算违规告警、成本异常检测、闲置与孤儿资源识别
