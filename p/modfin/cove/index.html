基于 SQLite 存储的 Go 嵌入式 TTL 缓存库

综述（解读层）

cove 是一个以 SQLite 为存储后端的 Go 缓存库，以嵌入式库形式集成到应用中而非独立服务，用于缓存计算或获取成本较高的数据，也可作为键值存储使用。它以 WAL 模式将数据写入磁盘，支持数百 GB 级缓存容量；依赖 cgo 并将 SQLite 编译进项目。SQLite 任意时刻仅允许一个写入者，写密集场景需通过 PRAGMA 调优。

  • 提供带 TTL 的键值缓存，支持命名空间隔离、Range 扫描、迭代器（逐行扫描不需全部载入内存）和淘汰回调
  • 提供 BatchSet/BatchGet/BatchEvict 批量操作，必要时拆分子批次以保证原子性
  • 基于 Go 泛型的 TypedCache，使用 encoding/gob 序列化，提供 GetOr 等类型安全 API

适用场景（解读层）

  • 嵌入 Go 应用缓存计算或获取成本较高的数据，无需部署独立缓存服务
  • 需要缓存超出内存容量的大规模键值数据（利用磁盘和 SSD）
  • 需要缓存跨应用重启持久化的场景（通过 URIFromPath 指定数据库文件）
