Rust 编写的多线程 PostgreSQL 连接池器，监听 6432 端口转发客户端连接。

综述（解读层）

pg_doorman 是 Ozon 用 Rust 实现的多线程 PostgreSQL 连接池器，客户端经 6432 端口接入共享池。核心机制包括匿名预处理语句计划缓存、Pool Coordinator 连接上限与优先级驱逐、Patroni 辅助的后端切换，以及无需断开客户端的二进制升级（TLS 连接依赖 tls-migration 特性编译）。提供 Prometheus 指标与诊断 UI。适用于多语言客户端共享连接池的部署场景。

  • 多线程运行，一个进程内所有工作线程共享同一连接池
  • 将匿名预处理语句重映射为命名形式，使查询计划在后端缓存并被共享池的客户端复用
  • Pool Coordinator 实现数据库级连接上限、优先级驱逐与按用户最低配额

适用场景（解读层）

  • 多客户端/多语言应用（Go、.NET、Python、Node.js 等驱动）共享 PostgreSQL 连接池
  • 使用 Patroni 的 PostgreSQL 集群中需要后端自动重路由的部署
  • 需要在不中断客户端连接的情况下升级 pooler 二进制的运维场景
