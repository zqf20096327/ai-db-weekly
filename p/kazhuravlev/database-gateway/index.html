🧭 简介解读层（AI·证据行可回查）

通过 OIDC 认证与 OPA 策略控制对生产 PostgreSQL 访问的 Go 网关服务

综述（解读层）

Database Gateway 是一个 Go 编写的 Web 网关服务，为员工提供访问生产 PostgreSQL 实例的统一入口。用户经外部 OIDC 提供商认证后，提交的 SQL 会先经解析与校验，再由磁盘加载的 .rego 策略按用户、目标实例、操作类型和表进行授权判定，查询结果缓存在本地 PostgreSQL 中并生成可分享链接。限制包括部分复杂查询可能被解析器拒绝，且远程数据库仅能经网关访问。

  • 基于 OPA 策略在实例、表和查询类型层面控制权限，.rego 文件从磁盘加载并内嵌编译
  • 提供 Web UI 与 LRPC API，支持查询书签、最近查询列表及 HTML/JSON/CSV 结果导出
  • 解析并校验 SQL 以限制查询类型，基于 schema 校验实现列白名单，支持连接池配置

适用场景（解读层）

  • 团队需要按角色区分生产库读写权限（如组长可 SELECT/INSERT，成员只读 SELECT）的场景
  • 需要保留查询结果及执行元数据用于调试和审计的场景
  • DevSecOps 流程中通过网关隔离生产数据库直接访问的场景
