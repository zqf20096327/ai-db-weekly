服务端数据同步引擎，基于 SQLite 与 PostgreSQL 做增量双向同步

综述（解读层）

AMPLI-SYNC 是一个 Java 17 / Jersey 3 实现的服务端同步引擎，以 WAR 部署于 Tomcat，用于在无网络环境下工作的边缘/移动客户端（使用本地 SQLite）与中央 PostgreSQL 之间进行增量双向同步。同步基于版本计数器和软删除标记，按设备维护水位（watermark），支持 gzip 压缩传输、多租户（subscriber 映射到 PostgreSQL schema）与 JWT 认证。当前实现仅针对 PostgreSQL，README 明确其为框架而非开箱即用产品。

  • 提供 prepopulate-db、receive-changes、sync-compressed、commit-sync 等 REST 端点，实现推送、拉取与设备引导流程
  • 同步为增量式：按设备水位返回 gzip 压缩的变更增量，不复制全表；端点无状态并容忍重试与重复提交
  • 通过环境变量配置（数据库连接、JWT 密钥、批量大小等），启动时由 Flyway 自动执行 PostgreSQL 迁移

适用场景（解读层）

  • 需在弱网或离线环境（外勤销售、现场服务、仓储物流）运行的移动应用数据同步
  • 多租户 SaaS 中每个订阅者映射到独立 PostgreSQL schema 的同步场景
  • 需要自定义冲突策略（版本计数、服务端/客户端优先或领域合并）的分布式 B2B 系统
