综述（解读层）

Materialize 是一个实时数据集成平台，读取 PostgreSQL、MySQL 复制流或 Kafka 数据源，将 SQL 查询转化为数据流以增量维护物化视图，并通过 PostgreSQL 协议提供查询或推送至下游。开发者可用 psql、dbt Core 等现有工具接入，采用 Rust 编写，提供社区版、企业版自部署和托管云服务。

  • 支持从 PostgreSQL/MySQL 复制流、Kafka（含 Redpanda 等 API 兼容系统）及 webhook 读取数据
  • 使用 PostgreSQL 方言与协议，支持多路连接、delta-joins、子查询去相关、递归及 JSON 操作
  • 多个视图可共享底层索引，支持 pull 式 SELECT 查询与 push 式 SUBSCRIBE/Kafka 流输出

适用场景（解读层）

  • 查询卸载（CQRS）：承接源自数据库的复杂读查询
  • 集成枢纽（ODS）：从多源抽取、加载并增量转换数据
  • 为 AI/RAG 管道提供实时上下文或支撑运营仪表盘
