🧭 简介解读层（AI·证据行可回查）

一组 SQLite3 可加载扩展，提供字符串、正则、JSON、Bloom 索引等函数

综述（解读层）

该项目包含多个 SQLite3 运行时加载扩展，涵盖 Unicode 字符串处理（含 ICU 模块）、浮点数学、blob 操作、PCRE2 与 POSIX 正则、JSON 函数及 Bloom 过滤器索引，另有 CSV 导入等脚本工具。构建使用 CMake，依赖满足时才会编译对应扩展，需 C99 编译器。适合需要在 SQL 中扩展函数能力的 SQLite 使用者。

  • 提供 string_funcs、math_funcs、blob_funcs、pcre2_funcs、posix_re_funcs、json_funcs、bloom_filter1 七个扩展模块
  • string_funcs 包含全部标准 ICU 模块并支持 Unicode 文本处理
  • 通过 CMake 构建，仅编译满足依赖的扩展，采用 MIT 许可证

适用场景（解读层）

  • 在 SQLite 查询中使用 PCRE2 或 POSIX 正则函数
  • 通过 .load 加载扩展以获得额外的 JSON 或 Unicode 字符串函数
  • 使用 csv2sqlite 将 CSV 文件导入 SQLite 数据库
