stolon 是基于流复制与集群视图计算的 PostgreSQL 高可用管理器

综述（解读层）

stolon 是用 Go 编写的 PostgreSQL 高可用集群管理器，由 keeper、sentinel、proxy 三个组件构成：sentinel 监控并计算集群视图，keeper 管理本地 PostgreSQL 实例向该视图收敛，proxy 将客户端连接强制指向当前主库。数据存储与选主依赖 etcd、consul 或 Kubernetes API server。要求 PostgreSQL 9.6–15，分区场景下倾向于一致性而非可用性。

  • 基于 PostgreSQL 流复制，支持异步（默认）与同步复制两种模式
  • 使用 etcd、consul 或 Kubernetes API server 作为高可用数据存储并用于选主
  • 支持结合备份/恢复工具的时间点恢复（PITR）与 standby cluster 多站点复制

适用场景（解读层）

  • 在 Kubernetes 或其他基础设施上运行高可用 PostgreSQL 集群
  • 多站点复制及接近零停机的迁移（standby cluster）
  • 需要时间点恢复的灾备场景
