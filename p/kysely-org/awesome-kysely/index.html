Kysely 生态资源清单，收录适配器、方言、插件、工具与应用。

综述（解读层）

这是一个围绕 Kysely（TypeScript 类型安全 SQL 查询构建器）整理的资源列表，按类别收录链接：框架适配器（NestJS、Fastify、Auth.js 等）、多种数据库方言（PlanetScale、Neon、Cloudflare D1、DuckDB 等）、插件、迁移 CLI、ORM 扩展、文章与项目模板。列表条目附名称、描述与 npm/GitHub 链接。适合为 Kysely 项目寻找集成方案或学习资料的 TypeScript 开发者参考。条目描述来自各自仓库，本清单本身不包含安装或使用文档。

  • 按适配器、方言、插件、CLI、工具、模板等类别收录 Kysely 生态条目，每条附描述与 npm/GitHub 链接
  • 方言部分覆盖 PostgreSQL、MySQL、SQLite 之外的多种数据库与运行环境（PlanetScale、Neon、Cloudflare D1、Deno、浏览器/Worker 等）
  • 收录与 NestJS、Fastify、FeathersJS、TypeORM、Sequelize、Knex、Supabase 等既有框架/工具对接的适配器

适用场景（解读层）

  • 为基于 Kysely 的 TypeScript 项目查找特定数据库或运行环境的方言与适配器
  • 查找迁移 CLI、分页/缓存/访问控制等插件和工具扩展查询构建器功能
  • 通过收录的文章与项目模板学习 Kysely 在不同技术栈中的集成方式
