🧭 简介解读层（AI·证据行可回查）

为 Kysely 提供 PostgreSQL 方言，适配 Postgres.js 客户端与 Bun 原生 SQL 绑定。

综述（解读层）

该项目是一个 Kysely 方言包，让 Kysely 查询构建器可连接 PostgreSQL，支持 Postgres.js 客户端（≥3.4）与 Bun（≥1.2）的 SQL 原生绑定，供使用这两种客户端的 TypeScript 开发者使用。它由 Kysely 核心团队成员维护，实现 AbortSignal 中断查询、控制连接配置及预处理语句等机制。

  • 支持 Postgres.js 客户端（≥3.4）与 Bun（≥1.2）的 SQL 原生绑定两种运行方式
  • 实现 Kysely 的 AbortSignal 集成，包含 'cancel query' 与 'kill session' 两种数据库侧中断策略
  • 提供 controlPostgres 配置项，可用独立控制实例执行 pg_cancel_backend/pg_terminate_backend 等控制查询

适用场景（解读层）

  • 在 Node.js 或 Deno 环境中用 Postgres.js 客户端配合 Kysely 构建类型安全的 PostgreSQL 查询
  • 在 Bun 运行时中使用其 SQL 原生绑定连接 PostgreSQL
  • 需要对运行中的查询进行数据库侧取消或终止会话的长时间运行服务
