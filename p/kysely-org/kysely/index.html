类型安全的 TypeScript SQL 查询构建器

综述（解读层）

Kysely 是一个面向 TypeScript 的 SQL 查询构建器，受 Knex.js 启发。它基于数据库表和列的类型定义生成查询，在编译期校验所引用的表与列，并推断结果行的类型、别名和自动补全。主要用于 Node.js，也可运行于 Deno、Bun、Cloudflare Workers 和浏览器。对于无法在编译期确定类型的情况，提供 sql 模板标签和 DynamicModule 作为逃生通道。

  • 提供类型安全的查询构建，仅允许引用当前查询部分可见的表和列
  • 从子查询、join 子查询和 with 语句中推断列名、别名和类型
  • API 文档写入类型文件，可在 IDE 中悬停查看

适用场景（解读层）

  • 在 Node.js、Deno、Bun、Cloudflare Workers 或浏览器中构建 SQL 查询
  • 使用 PostgreSQL、MySQL、MSSQL、SQLite、PGlite 等数据库的 TypeScript 项目
  • 需要编译期查询校验和结果类型推断的场景
🔌 适配哪些库db_scan 程序判定

MySQL、PostgreSQL、SQL Server、SQLite
