为 Turso 提供 Kysely 方言的 TypeScript 适配库

综述（解读层）

kysely-turso 为 Kysely 查询构建器提供连接 Turso 的方言实现，包含面向 @tursodatabase/serverless 的 TursoServerlessDialect 和面向 LibSQL 客户端的 LibSQLialect。面向在 TypeScript 项目中使用 Kysely 操作 Turso/LibSQL 数据库的开发者。限制：截至 @tursodatabase/serverless@0.1.3，不支持交互式事务，compat 接口签名已定义但功能不可用。

  • 提供 TursoServerlessDialect 与 LibSQLialect 两种方言，分别对接 @tursodatabase/serverless 和 @libsql/client
  • 通过 npm/pnpm/yarn/Deno/Bun 安装，运行时依赖 kysely 与 Turso 客户端包
  • 配套使用 Kysely 的类型定义（如 GeneratedAlways）实现类型化查询

适用场景（解读层）

  • 在 Node.js/Deno/Bun 项目中用 Kysely 以类型安全方式查询 Turso 数据库
  • 基于 LibSQL 客户端构建 SQL 查询层
  • 在 serverless 环境中连接 Turso（注意交互式事务不支持的限制）
