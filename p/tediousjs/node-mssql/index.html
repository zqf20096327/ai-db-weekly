Node.js 的 Microsoft SQL Server 客户端库，基于 TDS 驱动实现连接

综述（解读层）

node-mssql 提供 Node.js 环境下连接 Microsoft SQL Server 的接口，支持 Tedious（纯 JavaScript，默认）与 MSNodeSQLv8 两种 TDS 驱动。API 覆盖连接、请求、事务、预处理语句、存储过程，支持回调/Promise/async-await 与 ES6 标签模板写法。安装需 npm install mssql，服务器需启用 TCP/IP 连接。

  • 支持两种 TDS 驱动：默认的纯 JavaScript Tedious（Windows/macOS/Linux）和可选的 MSNodeSQLv8（Windows 或 64 位 Linux/macOS，v2.4.8-v6 原生）
  • 支持 Promise（默认原生 Promise，可通过 sql.Promise 替换）、async/await 及 ES6 标签模板字面量的查询写法
  • 文档覆盖连接管理、请求、事务、预处理语句、存储过程与标识符规则等内容

适用场景（解读层）

  • Node.js 应用需要通过 TCP/IP 连接并查询 Microsoft SQL Server 数据库
  • Windows 环境下需要使用 Windows 身份验证访问 SQL Server（配合 MSNodeSQLv8 驱动）
  • 需要执行事务、预处理语句或存储过程的 Node.js 数据访问层
