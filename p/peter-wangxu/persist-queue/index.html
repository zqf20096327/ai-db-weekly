Python 线程安全的磁盘持久化队列，基于文件/SQLite/MySQL 实现

综述（解读层）

persist-queue 为 Python 提供基于文件和 SQLite3 的持久化队列，条目写入磁盘，可在进程崩溃或重启后读取。面向需要在 Python 程序中保留队列数据的开发者。支持 FIFO/FILO、优先级、去重、确认（ack/nack）等队列类型，序列化可选 pickle、msgpack、cbor、json，v1.1.0 起提供异步版本；MySQL 队列需额外安装 DBUtils 和 PyMySQL。要求 Python 3.5+，异步功能要求 3.7+。

  • 提供基于文件、SQLite3 与 MySQL 的持久化队列实现，条目存储在磁盘并在进程重启后可读取
  • 支持多线程生产者/消费者，兼容 greenlet/eventlet，v1.1.0+ 提供全部队列类型的异步版本
  • 支持 pickle（默认）、msgpack、cbor、json 多种序列化协议，包含 PriorityQueue、UniqueQ、SQLiteAckQueue、PDict 等多种结构

适用场景（解读层）

  • 需要队列数据在进程崩溃或重启后不丢失的 Python 任务处理程序
  • 多线程生产者-消费者架构中的任务分发与确认处理（ack/nack/ack_failed）
  • 需要优先级排序或仅存唯一条目的持久化队列场景
