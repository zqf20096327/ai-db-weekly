🧭 简介解读层（AI·证据行可回查）

用于 1C:Enterprise 8 的原生外部组件，用于执行 SQLite 数据库查询。

综述（解读层）

该组件为 1C:Enterprise 8 提供了在 Windows x86/x64 和 Linux x64 上处理 SQLite 数据库的功能。其静态链接了 SQLite 库（版本 3.51.2）。它通过 OpenDataBase、Exec、ExecQuery 等方法执行 SQL 查询，并将结果返回为值表（ValueTable）或 JSON。它增加了有限的 Unicode 大小写折叠支持。提供了预编译查询和参数绑定功能。在 UTF-16 编码的数据库中，可以避免文本重新编码。

  • 查询结果返回为值表（ValueTable）或 JSON 字符串，并进行 SQLite 到 1C 类型映射（integer/real → Number，text → String，blob → BinaryData）
  • 支持预编译命名查询和参数绑定（BindParam），并支持将日期列从 'YYYY-MM-DD HH:MM:SS' 字符串格式进行转换
  • 支持 :memory: 数据库、URI 文件名，以及静态链接的 SQLite 3.51.2

适用场景（解读层）

  • 从 1C:Enterprise 8 应用程序中读写本地 SQLite 数据库文件或内存数据库
  • 执行批量插入/更新/删除操作（通过预编译查询配合参数）并获取 last inserted id 和 changes count
  • 使用 upper/lower/fold/like/collate nocase 执行不区分大小写的查询，适用于第一平面 Unicode 字符
