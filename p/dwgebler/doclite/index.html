基于 SQLite 的 PHP NoSQL 文档存储，以 JSON 集合管理文档

综述（解读层）

DocLite 是一个构建于 SQLite 之上的 PHP NoSQL 文档存储，通过 PDO SQLite 库将 JSON 文档组织进命名集合，并利用 SQLite JSON1 扩展完成存储、解析、索引与查询。适用于快速原型、中小型网站、API 本地缓存等场景。需 PHP 8.1+ 及 pdo_sqlite 扩展，经 Composer 安装，MIT 协议。

  • 使用 PHP PDO SQLite 库自动管理按命名集合组织的 JSON 文档
  • 借助 SQLite JSON1 扩展对 JSON 文档进行存储、解析、索引和查询
  • 支持事务、查询构建器、FTS5 全文检索、JSONB、PSR-16 缓存适配器及 Symfony 集成

适用场景（解读层）

  • 快速原型开发与中小型网站/应用的数据存储
  • 远程 API 数据的本地缓存
  • 微服务或本地 Web 应用的文档数据库
