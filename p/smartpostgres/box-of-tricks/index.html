PostgreSQL 索引健康检查与清理的 SQL 工具脚本集

综述（解读层）

该项目包含一组 SQL 函数，用于 PostgreSQL 性能调优辅助。check_indexes 分析索引的健康状况与设计（大小、死元组、fill_factor、autovacuum 状态等）并输出带优先级的警告；drop_indexes 按模式/表批量删除索引，支持 dry run 和并发删除等选项。目标用户为已会创建和查询 Postgres 函数的数据库使用者。支持 Postgres v12 及以上和 Amazon RDS Aurora PostgreSQL，MIT 许可。

  • check_indexes 函数分析索引健康状况与设计，输出索引定义、大小、元组数、vacuum 时间、警告及修复参考 URL 等列
  • drop_indexes 函数按 schema/table 删除索引，支持 dry run、并发删除、列出待删索引等布尔参数
  • 支持 Postgres v12 至当前所有受支持版本及 Amazon RDS Aurora PostgreSQL

适用场景（解读层）

  • 数据库索引健康巡检：定位 autovacuum 跟不上、fill_factor 异常等问题并获取详细说明链接
  • 索引调优训练中重置表的基础状态，或批量清理无用索引前先 dry run 预览
  • 将索引创建语句纳入源码管理或在其他环境重建索引
