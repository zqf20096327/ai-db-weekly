Windows 原生液态玻璃风格 Codex 用量监控悬浮组件与看板

综述（解读层）

读取本机 ~/.codex/sessions 的 JSONL 会话文件，增量解析 Token 用量并写入本地 SQLite 索引，生成费用估算、额度快照、主/子代理模型状态与历史速率曲线，支持跨电脑导入 SQLite 并自动去重合并。面向在 Windows 上使用 Codex 的用户。费用按当前配置单价估算，不等于实际账单；EXE 仅面向 Windows x64，默认只监听本机、不上传记录。

  • 提供桌面悬浮组件与含总览/模型/历史/额度/设置五页的原生看板，费用、Token、缓存命中与模型占比等用量范围支持今日/5小时/累计三档
  • 读取本机会话文件生成主代理请求模型、子代理数量与每秒输出速率，支持导出本页 CSV 与导入其他电脑 SQLite 索引并按会话事实去重
  • 支持窗口 55%–150% 缩放、迷你模式、托盘收起、透明度预设与动画开关；可下载 EXE 运行或用 Python 3.10+ 与 PyQt5 从源码运行

适用场景（解读层）

  • 在 Windows 桌面上持续查看 Codex 的 Token 用量、费用估算与账号额度快照
  • 查看当前任务的主代理与子代理模型调用状态及各对话的每秒输出速率
  • 将多台电脑的 Codex 用量历史通过 SQLite 导入合并为一份去重后的本地统计
