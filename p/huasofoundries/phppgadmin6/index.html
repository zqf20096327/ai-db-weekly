基于 PHP7 与 Slim Framework 3 重构的 PostgreSQL 管理工具

综述（解读层）

phpPgAdmin6 是一个用 PHP 编写的 PostgreSQL 管理工具，基于原 phppgadmin 项目重构而来，采用 Slim Framework 3 路由与 AdoDB 抽象层。面向需要通过 Web 界面管理 PostgreSQL 9.3+（物化视图、BRIN 索引等）数据库的使用者。安装需 PHP 7.1+、ext-psql 与 Composer，通过 composer create-project 部署，配置支持 config.inc.php 与 config.yml（后者优先级更高），部署于子目录时须显式配置 subfolder 并调整 Web 服务器 rewrite 规则。

  • 支持 PostgreSQL 9.3+ 特性，包括物化视图与 BRIN 索引
  • 采用 Composer 管理依赖，遵循 PSR-2、PSR-4、PSR-7、PSR-11 等规范
  • 配置支持 config.inc.php 与 config.yml 两种文件，YAML 配置项优先合并

适用场景（解读层）

  • 需要 Web 界面管理 PostgreSQL 9.3+ 数据库（物化视图、BRIN 索引等）
  • 从旧版 phppgadmin 迁移到支持 PHP 7+ 的管理工具
  • 在 Nginx/Apache 等服务器或子目录环境下部署 PostgreSQL 管理后台
