基于 Vue 3 + Express + SQLite 的自托管服务监控与站点服务平台

综述（解读层）

该系统为个人或团队提供站点运行状态展示能力，通过 UptimeRobot API 获取监控数据，并附带故障公告、音乐点播、信息发布与访客统计模块。前后端分离，SQLite 存储数据，无需额外数据库服务。服务监控数据依赖 UptimeRobot 账号及 API Key。

  • 集成 UptimeRobot API，展示服务状态、响应时间及 30 天 GitHub 风格可用性热力图
  • 基于 WebSocket 的实时数据推送，支持故障/维护公告发布与页面提醒
  • 内置访客统计（在线人数、地理位置与设备分布）、公告系统、应用中心与后台管理

适用场景（解读层）

  • 搭建自托管的服务/站点可用性状态页，配合 UptimeRobot 监控数据展示
  • 个人站点集成公告发布、故障通知与应用资源分发
  • 需要访客在线统计与后台内容管理的小型站点运行平台
