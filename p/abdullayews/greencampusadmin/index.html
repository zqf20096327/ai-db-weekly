GreenCampus 学生门户的管理端面板，Flask 后端操作共享 TiDB 数据库

综述（解读层）

GreenCampus Admin 是 GreenCampus 学生门户的管理面板，面向宿舍管理人员。它与学生端 greencampus 共享同一 MySQL 兼容的 TiDB Cloud 数据库，提供学生、宿舍与床位/柜/椅槽位、小组、请求、申请、公告、罚款、食堂菜单、洗衣机的管理接口，全部 63 个 API 经 admin_required 会话守卫保护，部署于 Render，需与学生端成对部署。

  • 提供 63 个 /api/admin/* 接口，覆盖学生、宿舍槽位、小组、请求、申请、公告、罚款、食堂、洗衣、日志与 CSV 导出
  • 基于 Flask + PyMySQL 连接 TiDB Cloud（SSL），凭据全部通过环境变量读取，代码中不含密码
  • 每个 API 端点由 admin_required 会话守卫保护，破坏性操作（单条/批量删除、强制处理）写入操作日志

适用场景（解读层）

  • 校园宿舍系统的管理人员后台：管理学生住宿状态、房间槽位分配与小组
  • 与学生端 greencampus 共库部署，处理申请审批、公告发布、罚款结算等事务
  • 个人/教学场景下学习 Flask 管理面板与 TiDB 云数据库的集成实践
