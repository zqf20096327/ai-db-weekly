基于 hypercore 的支持事务的对象存储库

综述（解读层）

HyperObjects 是构建在 hypercore 之上的对象存储，提供并发原子事务和简单 DB 日志。默认合并处理器合并修改不同对象的事务，冲突时抛错并回滚；每个事务可传入自定义合并处理器。对象 ID 采用顺序生成，内部用八叉树存储 ID 到 hypercore 索引的映射。适合已在 hypercore 生态中需要事务写入的使用者。

  • 支持并发原子事务，包含简单 DB 日志
  • 默认合并修改不同对象的事务，冲突时抛错并回滚，可传入自定义合并处理器
  • 顺序生成对象 ID，内部以八叉树维护对象 ID 到 hypercore 索引的映射

适用场景（解读层）

  • 在 hypercore 数据流上需要事务性写入对象的应用
  • 需要自定义事务合并策略的 P2P 存储场景
  • 以顺序对象 ID 组织大量对象并按索引读写的数据管理
