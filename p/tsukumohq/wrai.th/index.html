综述（解读层）

wrai.th 是一个用 Go 编写的 MCP 服务器，为多智能体协作提供管理设施：持久化记忆（跨会话保留）、代理间消息（5 种寻址模式、P0-P3 优先级、TTL）、最多 3 层的嵌套任务，以及按优先级×相关性×新鲜度打分的上下文预算裁剪。数据存储在单个 SQLite 文件中，单个二进制文件运行，默认本地使用；启用 API key 后可作为团队共享服务器。提供 mission-control 仪表盘展示任务与代理活动。适用于使用 Claude Code 等 MCP 客户端的开发者和团队。

  • 提供 58 个 MCP 工具，支持持久记忆（FTS5 搜索）与 query_context RAG 查询
  • 支持 5 种消息寻址模式（direct/broadcast/team/conversation/user）、优先级路由与 TTL 过期
  • 单二进制部署，数据存于 SQLite，默认本地运行，可选 API key 用于团队/服务器部署

适用场景（解读层）

  • 多个 AI 代理（如 Claude Code、Cursor）协作开发同一项目时的通信与任务分工
  • 需要代理记忆跨会话保留、在上下文重置后恢复状态的工作流
  • 团队通过共享服务器与 Linear 镜像统一管理任务分发
