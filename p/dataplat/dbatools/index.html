用于 SQL Server 管理自动化的 PowerShell 模块，含约 700 条命令

综述（解读层）

dbatools 是一个 PowerShell 模块，提供近 700 条命令，用于 SQL Server 实例迁移、备份恢复测试、健康检查与多服务器查询，面向 SQL Server 数据库管理员。支持 SQL Server 2008 至 2022（2.8.3 起不再支持 2000/2005），Windows 需 PowerShell 3+，Linux/macOS 需 PowerShell Core 7.4+ 且仅支持约 78% 命令。通过 Install-Module 从 PowerShell Gallery 安装。

  • 提供约 700 条命令，覆盖备份/恢复、实例迁移、监控、跨多服务器查找数据库等操作
  • 支持 SQL Server 2008–2022、Azure SQL VM/Database/Managed Instance 及容器环境（各版本命令支持率不同）
  • 支持 SQL 与 Windows 双凭据认证，可用 Export-CliXml 加密存储凭据

适用场景（解读层）

  • 批量执行多台 SQL Server 实例的备份与恢复验证
  • 执行 SQL Server 实例间的整体迁移
  • 跨多台服务器查找数据库并生成 HTML/Excel 报告
