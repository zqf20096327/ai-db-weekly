🧭 简介解读层（AI·证据行可回查）

Keydra 的 Quarkus 后端 API，用于多人管理 Redis、Aerospike 等键值服务器。

综述（解读层）

keydra-backend 是 Keydra 管理控制台的后端 API，基于 Quarkus 与 Java 21 构建，全链路非阻塞（Uni/Multi、Hibernate Reactive、Vert.x）。它供多用户通过 REST/WebSocket 与 GraphQL 读写 Redis、Valkey、KeyDB、Dragonfly、Garnet、Aerospike、TiKV 等键值服务器，并管理权限；自带数据存于 PostgreSQL，凭据以 AES-256-GCM 加密，TiKV 引擎需以 tikv Maven profile 构建才可用。

  • 按协议实现引擎：五种 RESP 服务器共用一套实现，通过询问目标服务器判定其能力，而非按类型假设
  • 键枚举始终使用游标式 SCAN 并流式输出，不以 KEYS 命令实现
  • REST（/api/v1）与 GraphQL（/graphql）调用同一组 service 并执行相同的权限检查

适用场景（解读层）

  • 团队多人共同管理同一批 Redis/Valkey/Aerospike 等键值服务器并区分操作权限
  • 需要大键空间流式浏览（基于 SCAN）而非整库枚举
  • 以 Docker/Podman 本地起 PostgreSQL 加一个目标实例进行开发调试（%dev profile 含种子 admin 账户）
