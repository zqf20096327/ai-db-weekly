基于 PostgreSQL 与 PostGIS 的移动对象轨迹数据库扩展

综述（解读层）

MobilityDB 是面向移动对象（如 GPS 轨迹）地理空间数据管理的数据库系统，通过向 PostgreSQL 和 PostGIS 添加时间及时空对象支持实现。由布鲁塞尔自由大学（ULB）开发，代码遵循 PostgreSQL License。需 PostgreSQL 16–19、PostGIS ≥3.0 等环境，构建后在数据库中以 CREATE EXTENSION 启用，亦提供 Docker 镜像。

  • 为 PostgreSQL/PostGIS 添加时间与时空对象类型，用于存储和分析 GPS 轨迹等移动对象数据
  • 提供 Python 适配器 PyMEOS（支持 psycopg 与 asyncpg）、基于 BerlinMOD 的数据生成与基准工具、以及在 QGIS 中显示查询结果的 MOVE 插件
  • 兼容 OGC Moving Features 标准，被 OSGeo 接纳为社区项目

适用场景（解读层）

  • GPS 轨迹数据的存储与 SQL 方式分析
  • 地理空间与公共交通（GTFS/Netex）数据的时空查询
  • 配合 QGIS、deck.gl、Leaflet 等工具进行轨迹结果可视化
