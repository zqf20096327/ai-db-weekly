基于 PostgreSQL/PostGIS 的移动对象轨迹数据库扩展

综述（解读层）

MobilityDB 是面向移动对象（如 GPS 轨迹）的地理时空数据库管理系统，由布鲁塞尔自由大学开发。它在 PostgreSQL 与 PostGIS 之上增加时间与时空对象类型，通过扩展方式启用（CREATE EXTENSION）。支持 Docker 部署，要求 PostgreSQL 16–19、PostGIS ≥3.0 及 64 位编译环境；提供 Python 适配器 PyMEOS 与 BerlinMOD 基准工具。

  • 在 PostgreSQL 和 PostGIS 上增加时间与时空对象类型支持
  • 提供 PyMEOS Python 适配器（基于 psycopg 和 asyncpy），以及基于 BerlinMOD 的数据生成与基准工具
  • 兼容 OGC Moving Features 标准，提供官方 Docker 镜像部署方式

适用场景（解读层）

  • GPS 轨迹等移动对象数据的存储与分析
  • 基于 SQL 的移动性行为查询分析
  • 结合 QGIS、deck.gl、Leaflet 等工具进行轨迹可视化
