Scala 库，用 case class 在编译期校验并生成可 JSON 序列化的 SQL 查询

综述（解读层）

Case-QL 是一个 Scala 小型库，通过 case class 表达实体、过滤器和修改操作，在编译期对数据模型做类型检查，运行时将 JSON 形式的过滤条件转成 SQL 查询。它提供 CRUD 操作和含实体关系的过滤机制，底层依赖 Doobie 生成 SQL 片段，并附有面向 Sangria 的模块。用户需自行编写实体与过滤器 case class；不支持聚合与 join（列为 TODO），也不处理 DDL 等模式层面任务。

  • 在编译期对代表过滤器和修改操作的 case class 与数据模型进行类型检查
  • 将 JSON 形式的过滤条件转换为 SQL 查询，支持嵌套过滤和实体关系条件
  • 提供 insert、update、delete 操作，包含面向 Doobie 和 Sangria 的模块

适用场景（解读层）

  • 在 Scala 项目中以类型安全方式构建和执行 SQL CRUD 查询
  • 需要将可序列化的查询过滤器通过 GraphQL（Sangria）传递并在服务端转换为 SQL 的场景
📖 README 首段存档原文 · 程序抽取

Case-QL is a small library for creating type-safe and JSON-serializable SQL queries using Scala case classes. It provides basic CRUD operations for entities, and it offers a powerful filter mechanism
