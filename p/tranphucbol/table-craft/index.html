🧭 简介解读层（AI·证据行可回查）

基于 Electron 的桌面数据库 IDE，通过运行时加载的数据源插件连接多种数据库

综述（解读层）

TableCraft 是一款用 TypeScript 与 Electron 构建的桌面数据库 IDE 和 SQL 客户端，提供数据库浏览树、带模式感知补全的 SQL 控制台、结果网格、表格数据编辑器、查询历史与 EXPLAIN 计划等功能，面向需要浏览和编辑多类数据库表数据的开发者。其关键机制是：每个数据源运行在独立的引擎进程中，各数据库方言由插件实现，SQLite 与 MySQL 内置，PostgreSQL、Oracle、Redis、etcd 等首次使用时从 npm 下载；安装包未签名，首次启动需额外操作。

  • 支持 SQLite、MySQL/MariaDB/TiDB、PostgreSQL、Redis、Oracle、SQL Server/Azure SQL、etcd、DuckDB 等数据源，其中部分内置、部分经 npm 按需下载插件
  • 提供模式感知补全、表格数据编辑器（编辑操作以单事务提交）、ER 图、查询历史和以树形展示的 Explain Plan
  • 内置 MCP 服务器供 Claude Code、Cursor 等 AI 代理列出模式并执行查询，写操作默认等待用户批准；结果行保留在引擎进程中，网格按窗口读取

适用场景（解读层）

  • 在单一桌面应用中浏览和编辑 MySQL、PostgreSQL、SQLite 等多种数据库的表数据
  • 编写 SQL 并查看执行计划：通过 SQL 控制台运行语句、查看树形 Explain Plan 与查询历史
  • 让 AI 代理（经 MCP）在用户批准写操作的前提下查询本地数据源
