NetSuite 定制与 SuiteApp 开发脚手架，基于 TypeScript 与 SuiteCloud CLI 生成项目模板。

综述（解读层）

NetSuite Starter 是一个用于构建 NetSuite 账户定制和 SuiteApp 的脚手架项目。开发者通过 npm 安装 SuiteCloud CLI 与 netsuite-starter CLI，运行 `nsx project` 命令并根据提示填写信息即可生成项目。生成的项目基于 TypeScript 与 SuiteScript 2，附带一组封装库，覆盖浏览器、缓存、CSV 文件读取、治理配额和搜索等常用 API 场景，并采用 Jest 作为主题标签中的测试工具。项目采用 GNU GPL 许可证，作者为 Felipe Chang。

  • 提供 `nsx project` 命令行向导，用于生成 NetSuite 定制项目模板
  • 包含 Browser、Cache、CSV、Governance、Search 等封装库，支持按 ID 读取 CSV 文件和带类型定义的搜索响应
  • 基于 TypeScript 与 SuiteScript 2，依赖 Oracle SuiteCloud CLI for Node.js

适用场景（解读层）

  • 需要为 NetSuite 账户创建定制化脚本的 TypeScript 开发者
  • 构建基于 SuiteCloud 工具链的 SuiteApp 项目
  • 需要统一封装 NetSuite 缓存、搜索、治理配额等 API 调用的开发团队
