基于 ActiveAndroid 的 Android ORM，支持多数据库与 RxJava 2

综述（解读层）

ReActiveAndroid 是一个 Android 平台的 ORM 库，作者接手自已停止维护的 ActiveAndroid 项目。模型类通过 @Table 注解映射到表，支持 save()/delete() 等实例方法；查询以类 SQL 语法构建。相比原库新增多数据库支持、迁移机制、表变更通知和 RxJava 2 支持。通过 Gradle 依赖引入并在 Application 中初始化。minSdkVersion 14，MIT 协议。

  • 支持多个数据库，通过 @Database 注解声明数据库名称与版本
  • 提供类 SQL 语法的查询构建器（Insert/Select 等）
  • 支持 RxJava 2、一对多关系、模型继承及表/模型变更通知

适用场景（解读层）

  • Android 应用中需要在 SQLite 上以模型类方式存取数据的场景
  • 需要同时访问多个 SQLite 数据库的应用
  • 原 ActiveAndroid 项目使用者寻求继续维护的替代实现
📖 README 首段存档原文 · 程序抽取

ReActiveAndroid is Android ORM based on popular library ActiveAndroid. Unfortunately, the author of the library stopped maintaining it, so I decided to continue maintain the library instead of him.
