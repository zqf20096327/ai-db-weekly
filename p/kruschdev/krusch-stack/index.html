🧭 简介解读层（AI·证据行可回查）

面向 AI 编码代理的一体化工具包，经 npx 安装提供记忆、代码搜索、安全执行与评测等 39 个 MCP 工具。

综述（解读层）

KruschStack 将其生态中的七个组件（工作记忆、Git/AST 图、文件页记忆、编码 harness、前端设计、工作区枢纽、任务路由）合并为单一安装单元，默认存储用 Node 22 原生 node:sqlite，另有 PostgreSQL 16 + pgvector 的 Docker Compose 部署方式。安装时自动写入 .mcp.json 以对接 Claude Code、Cursor、Windsurf、Antigravity 等客户端。README 含大量基准测试与队列状态提交数据，其中多项结果标注为自评或待接受，阅读时需注意区分验证层级；项目要求 Node.js >= 22，MIT 许可。

  • 通过 npx krusch-stack init 一条命令完成安装并自动配置 Claude Code、Cursor、Windsurf 与 Antigravity，提供 doctor 子命令验证组件
  • 提供 39 个标注的 MCP 工具，覆盖上下文记忆、Git/AST 符号搜索与依赖图、文件检索、2PC 暂存执行 harness、前端设计与任务路由
  • 支持两种部署：零 Docker 的 node:sqlite 本地安装，或 docker compose 启动 PostgreSQL 16 + pgvector + Gateway 的完整栈

适用场景（解读层）

  • 为 Claude Code、Cursor 等 MCP 兼容客户端集中接入记忆、代码搜索与受控执行工具
  • 需要本地零 Docker 或 PostgreSQL/pgvector 两种部署方式的 AI 代理开发环境
  • 对编码代理执行过程进行分阶段（staged）diff 审查、应用与中止管控
