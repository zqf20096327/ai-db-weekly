TiDB：开源分布式 SQL 数据库，计算存储分离，支持 HTAP 与 MySQL 兼容

综述（解读层）

TiDB 是 PingCAP 开源的分布式 SQL 数据库，采用计算与存储分离架构，通过两阶段提交实现分布式事务，基于 Raft 协议实现多副本与自动故障转移。它包含 TiKV 行存和 TiFlash 列存两个存储引擎，兼容 MySQL 8.0 协议。可通过本地 playground、Kubernetes 上的 TiDB Operator 或 TiDB Cloud 部署，源码以 Apache 2.0 许可发布。

  • 使用两阶段提交协议实现跨节点分布式事务，提供 ACID 与强一致性
  • 内置 TiKV 行存与 TiFlash 列存双引擎，通过 Multi-Raft Learner 协议实时复制数据
  • 兼容 MySQL 8.0，支持通过 MySQL 驱动或 ORM 连接，并附带数据迁移工具

适用场景（解读层）

  • 需要水平扩展且保持 MySQL 协议兼容的数据库迁移场景
  • 事务与分析混合负载（HTAP）场景
  • 在 Kubernetes 或公有云中部署的分布式数据库集群场景
