将 tabix 索引的 VCF 转换为可 SQL 查询的 SQLite 数据库的 R 流水线

综述（解读层）

VCFdbR 是一组 R 脚本，用 Rscript 调用主脚本 VCFdb.R，将 bgzip 压缩并 tabix 索引、已拆分多等位基因位点的 VCF 转换为 SQLite 数据库，数据分散于 variant_info、variant_impact、variant_geno 三张表，通过索引的 variant_id 关联。数据库体积约为压缩 VCF 的 10 倍以上。面向需要在 Linux 集群上处理大型队列 VCF 数据的分析者。

  • 提供 --mode 'table' 与 'file' 两种模式：前者将基因型存于 SQLite 表内，后者将基因型存为独立文件并可通过 --threads 并行写入
  • 将 VCF 的核心信息、INFO 列、VEP 结果注释和基因型分别写入 variant_info、variant_impact、variant_geno 三张表，以 variant_id 索引关联
  • 默认忽略多值 FORMAT 字段，可通过 --include-multivalue-gt 参数（需 reshape2 包）解析固定值数的字段

适用场景（解读层）

  • 将大型队列的 VCF 转为 SQLite 数据库，用 SQL 按变异注释或基因型进行过滤查询，避免将整个 VCF 读入内存
  • 对包含 VEP 注释的 VCF 建库，将每个变异的多条后果记录存入 variant_impact 表
  • 在文件系统或 SQLite 单文件大小受限的场景下，用 file 模式将基因型拆分为目录中的独立文件存储
