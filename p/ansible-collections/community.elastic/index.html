用于管理 Elasticsearch 实例与集群的 Ansible 模块集合。

综述（解读层）

community.elastic 是一个 Ansible 集合，提供与 Elasticsearch 实例和集群交互的模块，涵盖索引、快照、用户、角色、keystore、Logstash 管道等资源的管理。面向使用 Ansible 进行 Elasticsearch 运维自动化的用户。支持 Elasticsearch 服务器 7、8、9 版本，但 Python 的 elasticsearch 库版本需与服务器版本对应。模块在 Debian 和 RHEL 系发行版上经过测试。

  • 包含 elastic_bulk、elastic_index、elastic_snapshot、elastic_user、elastic_role 等 16 个模块，覆盖索引、集群设置、快照、用户与角色等资源管理
  • 支持 Elasticsearch 服务器 7、8、9 版本，要求 Python elasticsearch 库版本与服务器版本对齐
  • 提供 elastic_bulk（Bulk API 文档操作）与 elastic_reindex（源到目标文档复制）等数据操作模块

适用场景（解读层）

  • 通过 Ansible 剧本批量管理 Elasticsearch 索引、生命周期、快照及快照仓库
  • 自动化管理 Elasticsearch 用户、角色与 keystore 条目
  • 使用 Bulk API 批量写入或操作文档，以及在源索引与目标索引之间复制文档
