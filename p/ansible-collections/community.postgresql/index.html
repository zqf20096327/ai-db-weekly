用于自动化管理现有 PostgreSQL 数据库的 Ansible 集合

综述（解读层）

community.postgresql 是 Ansible 官方社区集合，提供约 22 个模块用于管理已存在的 PostgreSQL 实例，涵盖数据库、用户、权限、扩展、pg_hba、表、索引、逻辑复制等操作，依赖 Psycopg2/3 适配器。它不负责安装 PostgreSQL 本身，需另行使用安装类角色。通过 ansible-galaxy 安装，遵循 GPLv3+ 许可。

  • 包含 info、basic、other 三类模块，覆盖 postgresql_db、postgresql_user、postgresql_privs、postgresql_query、postgresql_table 等 PostgreSQL 对象与操作管理
  • 依赖 Psycopg 适配器，同时支持 Psycopg2（最低 2.5.1）与 Psycopg3（最低 3.1.8），在 RHEL、Fedora、Ubuntu 多个系统与 PostgreSQL 13–18 上有 CI 测试
  • 仅用于与已安装的数据库交互，不提供 PostgreSQL 安装功能；ansible-core 2.16–2.21 在测试矩阵中，2.12.0 之前版本不受支持

适用场景（解读层）

  • 用 Ansible 剧本自动化管理现有 PostgreSQL 实例中的数据库、用户、权限、扩展、表结构等对象
  • 需要通过声明式模块执行 SQL 查询、pg_hba 配置、表空间与逻辑复制（publication/subscription/slot）相关运维任务
  • 作为 Ansible package 的一部分或经 ansible-galaxy 独立安装，集成进现有配置管理工作流
