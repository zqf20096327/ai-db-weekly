让 AI 编程工具按《阿里巴巴 Java 开发手册》审查代码的 Agent Skill

综述（解读层）

这是一个遵循 Agent Skills 规范的技能包，使 Claude Code、Codex 等支持该规范的 AI 编程工具能按《阿里巴巴 Java 开发手册》审查、生成和重构 Java 代码。核心由 SKILL.md 入口与 references 规范中文摘要组成，附 Python/Node.js/Go 三种本地校验脚本，不绑定特定运行器。

  • 包含 SKILL.md 入口与阿里巴巴 Java 编码规范中文摘要（references/alibaba-java-rules.md）
  • 提供 Python、Node.js、Go 三种校验脚本及统一测试脚本
  • 核心能力仅依赖 SKILL.md 与 references/ 目录，可被多种支持 Agent Skills 的工具加载

适用场景（解读层）

  • 对 Java、Spring、MyBatis 等代码改动按阿里规范进行审查
  • 让 AI 按规范生成或重构 Java 相关代码
  • 适用于涉及 SQL、日志、异常处理、安全校验、数据库建模的编码工作
