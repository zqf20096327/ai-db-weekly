QuickeyDB 是基于 Sqflite 的 Flutter SQLite ORM 封装库

综述（解读层）

QuickeyDB 是一个受 ActiveRecord 启发、构建在 Sqflite 之上的 Flutter SQLite ORM 库。它以 CREATE TABLE 语句配合正则解析生成表结构，属于运行时库、不依赖代码生成。开发者通过继承 DataAccessObject 编写 Schema 即可进行增删改查。支持事务、批量操作、内存缓存和本地数据库导入；迁移采用重建表搬移数据的强制方式。适用于 Flutter 移动与桌面应用的本地数据存储。

  • 支持 Android、iOS、macOS、Windows、Linux 平台，Web 平台标注为开发中
  • 支持 Belongs To、Has One、Has Many 三种关系定义及事务、批量操作、自定义 SQL 查询
  • 提供内存缓存（Memory）、本地数据库导入（importDB）与调试日志开关

适用场景（解读层）

  • Flutter 应用的本地 SQLite 数据持久化
  • 需要以 Dart 对象方式操作表、避免手写 SQL 的场景
  • 需要表间关系（一对一/一对多）查询及事务、批量写入的应用
