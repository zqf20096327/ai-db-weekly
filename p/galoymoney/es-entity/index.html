Rust 事件溯源实体框架，基于 sqlx 将实体持久化到 PostgreSQL

综述（解读层）

es-entity 是面向 Rust 的事件溯源实体框架，通过派生宏生成仓储方法，将实体以事件投影方式水合并存入 PostgreSQL。适用于需要事件溯源架构的 Rust 后端开发者。依赖 sqlx 实现编译期 SQL 校验，实体需两张表存储；提供 _in_op 后缀函数支持跨实体事务。禁止 unsafe 代码，采用 Apache-2.0 许可。

  • 通过 EsRepo 派生宏自动生成仓储 CRUD 方法，SQL 查询经 sqlx 在编译期校验
  • 实体通过事件投影水合，基于事件序列实现乐观并发检测，内置防重复操作的幂等守卫
  • 提供 _in_op 事务变体、嵌套实体/聚合支持、游标分页，以及 Forgettable 类型支持在不改写事件流的前提下删除个人数据

适用场景（解读层）

  • 在 Rust 中构建基于事件溯源的应用，事件存储于 PostgreSQL
  • 需在多个实体间执行原子事务操作的领域模型（配合 _in_op 与 tx）
  • 受 GDPR 等法规约束、需在保留事件历史的同时删除个人数据的系统（Forgettable 字段）
