基于SpringBoot+Vue3前后端分离的开源全栈快速开发脚手架

综述（解读层）

AgileBoot是前后端分离的Java快速开发平台，后端采用Spring Boot、Mybatis Plus、Redis与MySQL，前端基于Vue3、TypeScript、Pinia与Element Plus。项目在Ruoyi基础上重构，借鉴CQRS与DDD理念分离查询与操作逻辑，提供用户、角色、菜单等内置管理功能。需JDK、MySQL、Redis环境，也可用内置H2/Redis无依赖启动，适合个人开发者与公司内部项目。

  • 支持注解式主从切换、限流、重复请求拦截及权限校验，权限认证基于JWT并支持多终端
  • 提供Map、Guava、Redis三层缓存实现，操作日志、登录日志、服务监控、缓存监控等内置功能多数配有单元测试与集成测试
  • 代码结构按admin、domain等模块划分，查询与操作流程借鉴CQRS，业务逻辑集中于Domain模块

适用场景（解读层）

  • 个人开发者或企业内部管理后台系统的二次开发基座
  • 希望学习CQRS/DDD落地方式与SpringBoot+Vue3全栈项目的初学者案例
  • 需要用户、部门、角色、权限等通用后台功能的快速搭建
📖 README 首段存档原文 · 程序抽取

AgileBoot是一套开源的全栈精简快速开发平台，毫无保留给个人及企业免费使用。本项目的目标是做一款精简可靠，代码风格优良，项目规范的小型开发脚手架。 适合个人开发者的小型项目或者公司内部项目使用。也可作为供初学者学习使用的案例。
