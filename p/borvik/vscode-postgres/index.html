面向 VS Code 的 PostgreSQL 查询扩展，提供资源管理器与语言服务

综述（解读层）

该扩展为 VS Code 提供 PostgreSQL 连接管理、数据库对象浏览、语法高亮、基于连接的代码补全与 EXPLAIN 诊断，支持在编辑器中运行查询并将结果导出为 json/xml/csv。适用于需要在编辑器内编写和执行查询的用户；不支持 9.4 之前版本和 AWS RedShift，资源管理器不用于建删数据库或表。

  • 提供连接管理、服务器/数据库/函数/表/列的列表浏览，以及表的前 N 行快速查询
  • 语言服务基于当前连接提供代码补全（关键字、函数、表、字段）、函数签名提示与基于 EXPLAIN 的内联错误检测
  • 查询结果可序列化为 json、xml、csv 三种格式并打开于新编辑器

适用场景（解读层）

  • 在 VS Code 中编写并运行 pgsql 查询文件或选中片段
  • 浏览数据库结构以辅助编写查询（表、列、主键、类型）
  • 将查询结果导出为 json/xml/csv 文件
