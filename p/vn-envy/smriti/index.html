🧭 简介解读层（AI·证据行可回查）

本地优先的 AI 智能体记忆层，单 SQLite 文件存储，支持双时间事实更新与混合检索。

综述（解读层）

Smriti 是一个为 AI 智能体提供持久记忆的 Python 库，全部数据存于单个 SQLite 文件，核心依赖仅标准库和 numpy。写入路径提供 lite（无 LLM，纯离线）和 full（事实抽取与合并）两种模式；被修改的事实以取代方式保留历史而非删除。读取引擎默认在查询时零 LLM 调用，融合 BM25 与向量分数并解析相对日期。支持通过 OpenAI 兼容端点做抽取，包名为 smriti-agents，目前需从仓库安装，尚无 PyPI 发布。

  • 零外部基础设施：数据存于单 SQLite 文件，lite 模式下写入与检索完全离线、不调用 LLM
  • 双时间取代机制：事实更新不删除旧值，检索结果附带有效期标注，可回答不同时间点的状态
  • 默认读取路径为分数级 BM25+向量融合，保持完整回合打包，查询时确定性运行、无 LLM 调用

适用场景（解读层）

  • 为本地运行或调用廉价/本地模型的智能体添加跨会话持久记忆
  • 需要按时间点查询事实（如某月住址、事件时间线）的多会话对话系统
  • 通过 MCP 为 Claude Code、Cursor 等客户端接入可复制、可备份的本地记忆存储
📖 README 首段存档原文 · 程序抽取

Smriti is a memory layer for AI agents that runs on your machine, in one SQLite file. No Postgres, Neo4j, Docker, cloud account or paid tier; the core depends on the Python standard library and numpy.
