Webhook.site：生成随机 URL 实时显示 HTTP 请求的测试工具

综述（解读层）

Webhook.site 为用户生成随机 URL，用于接收并即时查看 Webhook 和 HTTP 请求，配合 Custom Actions 图形编辑器或 WebhookScript 脚本可转换、验证和处理请求。开源版基于 Laravel API 与 Angular SPA，MIT 许可，可用 Docker 自托管，但不包含 Custom Actions 等功能；完整功能在云版提供，部分需付费订阅。

  • 生成唯一随机 URL，即时显示收到的 Webhook 与 HTTP 请求
  • 提供 Custom Actions 图形编辑器和 WebhookScript 脚本语言，用于转换、验证和处理请求
  • MIT 许可的开源版本，支持通过 Docker 自托管，后端 Laravel，前端 Angular SPA

适用场景（解读层）

  • 无需公网 Web 服务器即可接收和调试 Webhook
  • 把 Webhook 转换为其他格式并转发到不同系统，或连接互不兼容的 API
  • 快速搭建无需基础设施的 API 或可发送邮件的联系表单
