🧭 简介解读层（AI·证据行可回查）

面向 PostgreSQL 与 MySQL/InnoDB 的数据库设计、审计与调优 Agent Skill。

综述（解读层）

这是一个供 Claude 等 AI 代理使用的技能包，覆盖关系数据库的模式设计、索引策略、EXPLAIN 计划诊断、事务与锁、零停机迁移等五类工作流。它强调基于真实 schema、执行计划和统计信息给出建议，并附带仅用标准库 Python 的审计脚本，可作为 CI 门禁运行。适用于需要在 AI 会话中获得 PostgreSQL 13+ 或 MySQL 8.0+ 数据库工程支持的开发者与 DBA。范围不含 NoSQL，且未经明确批准不会执行 DDL。

  • 覆盖模式设计、索引策略、EXPLAIN 计划诊断、事务并发与零停机迁移五个主题，按 PostgreSQL 与 MySQL/InnoDB 分别说明机制
  • 附带标准库 Python 审计脚本（无安装、无网络），退出码 0/1/2 可用作 CI 门禁
  • 通过 npx 安装到用户级或项目级 skills 目录，会话涉及 schema、慢查询或迁移时自动激活

适用场景（解读层）

  • 审查与优化 PostgreSQL 或 MySQL 的 schema、索引与慢查询
  • 诊断 EXPLAIN 计划、锁等待、死锁与并发异常
  • 规划零停机 DDL 迁移，覆盖 Alembic、Prisma、Flyway 等十余种迁移工具的引擎差异
