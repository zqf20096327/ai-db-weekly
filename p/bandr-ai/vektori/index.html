面向 AI Agent 的三层句子图谱记忆库，SQLite 零配置起步

综述（解读层）

Vektori 是一个供 AI Agent 使用的长期记忆存储库，用 Python 编写、经 PyPI 分发，采用 Apache 2.0 许可。它将记忆组织为三层句子图谱：L0 事实层做向量检索，L1 情节层通过图遍历自动发现模式，L2 句子层保存带 NEXT 边的原始对话序列。检索支持 l0/l1/l2 三种深度。默认使用 SQLite，无 Docker 与外部服务依赖，可换用 Postgres、Neo4j、Qdrant、Milvus；嵌入模型支持 OpenAI、Ollama、NVIDIA NIM 等 10 个提供商。

  • 三层句子图谱结构：事实层（向量检索）、情节层（图遍历自动发现模式）、句子层（原始对话顺序存储）
  • 默认 SQLite 零配置运行，支持切换 Postgres、Neo4j、Qdrant、Milvus 后端
  • 检索深度可选 l0/l1/l2，返回 token 量约 50-3000；嵌入支持 OpenAI、Ollama、NVIDIA NIM 等 10 个提供商

适用场景（解读层）

  • 为多轮对话 Agent 添加跨会话长期记忆
  • 需要从对话历史追溯结论来源或分析态度变化轨迹的场景
  • 本地无外部服务依赖的快速原型（Ollama + SQLite）
