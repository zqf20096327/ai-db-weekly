从大型 PostgreSQL 数据库抽取保持引用完整性的小型样本数据集的命令行工具

综述（解读层）

pg_sample 是一个 Perl 编写的命令行工具，用于从较大的 PostgreSQL 数据库导出小型样本数据集，输出格式与 pg_dump 纯文本格式接近，可通过管道交给 psql 构建样本库。抽取结果包含全部表并维持外键引用完整性与循环依赖，样本表行数可能超出 limit 设定以满足外键约束。要求 PostgreSQL 8.1+、pg_dump 在路径中，以及 Perl DBI/DBD::Pg 模块。

  • 按表设定行数上限，支持数字、百分比及基于条件的模式/规则对等 limit 规则
  • 输出包含原库全部表并维护引用完整性，支持循环依赖
  • 支持随机选行、按主键确定性排序（--ordered）以及 Docker 容器运行方式

适用场景（解读层）

  • 从大型生产库生成小规模样本库，用于本地开发或测试环境搭建
  • 需要样本数据保持外键关系、可直接 psql 导入的场景
  • 按表定制抽样规模或按条件筛选行（如只取未停用用户）的导出任务
