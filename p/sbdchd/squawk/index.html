基于 Rust 的 Postgres 迁移与 SQL 语句静态检查工具

综述（解读层）

Squawk 是一个用 Rust 编写的命令行 linter，用于检查 Postgres 迁移脚本和 SQL 文件中的规则违规项。面向使用 Postgres schema 变更的开发团队。内置解析器基于 rust-analyzer 构建，通过 CST/AST 记录警告；规则可通过 --exclude、squawk-ignore 注释或 .squawk.toml 配置文件禁用，支持 npm、PyPI、Docker、VSCode 扩展及 GitHub PR 评论等使用方式。

  • 提供 CLI、Docker 镜像、WASM 网页 Playground 和 VSCode 扩展多种运行方式
  • 规则可通过 --exclude 参数、squawk-ignore/squawk-ignore-file SQL 注释及 .squawk.toml 配置文件禁用
  • 解析器基于 rust-analyzer 构建，生成 CST 并在其上叠加 AST 以记录警告

适用场景（解读层）

  • 对 Postgres 迁移 SQL 文件执行规则检查
  • 将检查集成到 GitHub Pull Request 流程（GitHub Action 或 bot 评论）
  • 通过 pre-commit hook 在本地 Git 工作流中检查迁移文件
