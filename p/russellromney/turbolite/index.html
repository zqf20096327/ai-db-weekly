🧭 简介解读层（AI·证据行可回查）

Rust 实现的 SQLite VFS，将页级读写分层到 S3 并支持压缩加密

综述（解读层）

turbolite 是用 Rust 编写的 SQLite VFS，通过 B-tree 内省将页按类型分组存储到 S3，配合 manifest 间接寻址、64KB 大页、zstd 可寻址压缩与查询计划预取，实现冷启动点查与 JOIN 直接从 S3 读取。支持页面级 zstd 压缩与 AES-256 加密，可独立于 S3 使用。适用于每租户/工作区一库、单一写入源的场景。README 标注为实验性项目，包含 bug。

  • 支持 Python、Node.js、Go 绑定及 C FFI/SQLite 可加载扩展（.so/.dylib），兼容任意 S3 兼容存储（AWS S3、Tigris、R2、MinIO 等）
  • 基于 EXPLAIN QUERY PLAN 的查询计划 frontrunning 与按 B-tree 计数的自适应反应式两层预取，预取计划可在打开时配置
  • 写入始终本地速度，S3 成本仅发生在 checkpoint 时；manifest PUT 为原子提交点，旧版本由 gc() 清理

适用场景（解读层）

  • 单机托管数百至数千个数据库（每租户/工作区/设备一库）且不希望为每个库配备持久卷的场景
  • 需要在 S3 兼容对象存储上以低冷启动延迟运行点查询与 JOIN 的读多写少工作负载
  • 仅需页面级 zstd 压缩或 AES-256 加密、可脱离 S3 单独使用的 SQLite 存储需求
