Gleam 编写的 SQL 查询构建库，面向四种主流数据库方言

综述（解读层）

Cake 是一个用 Gleam 语言编写的 SQL 查询组合库，只负责构建读写查询语句，不执行查询也不解码返回值。它不绑定特定数据库方言，通过 pog、sqlight、shork 等适配器连接 PostgreSQL、SQLite、MariaDB 和 MySQL，使用预备语句防止 SQL 注入。需要注意它不校验生成的 SQL 是否有效，也不在方言间回补特性。

  • 支持组合与替换、移除查询部件，构建 SELECT、INSERT、UPDATE、DELETE 及 JOIN、UNION 等语句
  • 通过预备语句允许自定义 SQL 片段，同时防止 SQL 注入
  • 可在任意 Gleam 目标上运行，支持浏览器环境配合 SQLite WASM 或 PGLite 使用

适用场景（解读层）

  • 在 Gleam/Erlang 服务端为 PostgreSQL、SQLite、MariaDB 或 MySQL 动态拼装读写查询
  • 在浏览器中通过 WASM 适配器执行组合出的 SQLite 或 PostgreSQL 查询
  • 需要与现有 Gleam 方言适配器（pog、sqlight、shork）配合构建类型安全的查询
