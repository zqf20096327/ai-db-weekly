🧭 简介解读层（AI·证据行可回查）

基于 Flask 的运维管理平台，集成 SaltStack 与 Zabbix。

综述（解读层）

DevOpsPlatform 是一个面向运维场景的 Web 管理平台，由个人开发者完成并已在实际工作中部署，但源码暂不开源。技术栈包含 Flask、BootStrap、SaltStack、Zabbix、Celery 等，功能涵盖用户注册登录（邮件确认）、权限页面控制、IP 访问限制、Salt 主机命令执行、Zabbix 主机批量增删。README 提供在线 demo，部分功能已禁用。

  • 支持用户注册登录（邮件确认）、基于用户权限的页面视图限制与 IP 访问限制
  • 通过 Celery 实现后台任务执行与周期性任务执行
  • 支持 Salt 单/多主机命令执行，以及 Zabbix 主机批量添加与删除

适用场景（解读层）

  • 运维人员批量执行 Salt 命令管理多台主机
  • 批量添加或删除 Zabbix 监控主机
  • 需要用户权限控制与 IP 访问限制的内部运维平台场景
📖 README 首段存档原文 · 程序抽取

1. 用户注册、登录(邮件确认) 2. 通过用户权限进行页面视图限制 3. 第三个方API接入管理 4. 通过用户添加/设置IP地址进行访问限制 5. Celery后台任务执行,周期性任务执行 6. Salt单(多)主机命令执行 7. Zabbix主机批量添加(删除)
