从单个 YAML 描述生成 CRUD gRPC 后端代码的工具

综述（解读层）

Pike 是一个用 Go 编写的代码生成工具，读取单个 YAML 文件，生成包含基础增删改查操作的 gRPC Protobuf 服务描述及其 Go 实现，并生成兼容 migrate 工具的 PostgreSQL 建表迁移脚本。生成代码仅依赖 grpc 和 pq 两个库，支持 TLS。安装方式为 go get，通过 `pike project.yaml` 运行。

  • 从 YAML 描述生成含 CRUD 操作的 gRPC Protobuf 服务定义与 Go 实现
  • 生成兼容 migrate 工具的 PostgreSQL CREATE TABLE 迁移文件
  • 生成代码仅依赖 grpc 与 pq，支持 TLS

适用场景（解读层）

  • 为以 PostgreSQL 为存储的服务快速生成 gRPC CRUD 后端骨架代码
  • 生成数据库建表迁移脚本并配合 migrate 工具使用
  • 在生成的服务代码基础上继续自行扩展开发
