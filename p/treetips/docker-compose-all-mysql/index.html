🧭 简介解读层（AI·证据行可回查）

通过 docker-compose 一键启动多版本 MySQL/MariaDB 容器的测试环境集合

综述（解读层）

该仓库用 docker-compose 同时启动 MySQL 5.5/5.6/5.7/8.0 与 MariaDB 10.0–10.3 共八个数据库容器，目的是便于测试应用在不同数据库版本下的兼容性。各容器分配不同端口，通过内置 connect 脚本连接（无需本地安装 mysql 客户端）；默认库、用户、密码可在 .env 中修改，服务器与客户端配置、初始化脚本均可自定义。

  • 支持 MySQL v5.5/5.6/5.7/8.0 与 MariaDB v10.0/10.1/10.2/10.3 共八个版本，docker-compose 一条命令同时启动
  • 内置 connect-xxx.sh 连接脚本，复用容器内 mysql 客户端，本机无需安装 mysql-client
  • 支持自定义客户端/服务端 my.cnf、.env 中的默认库与账号密码，以及 common 与各容器两级 initdb.d 初始化脚本

适用场景（解读层）

  • 应用升级前验证其在不同 MySQL/MariaDB 版本上能否正常启动运行
  • 本地同时测试多个数据库版本的行为差异
  • 需要临时启动指定版本 MySQL/MariaDB 实例并通过初始化脚本灌入测试数据
