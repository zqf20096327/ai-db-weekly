综述（解读层）

Archery 是一个 SQL 审核查询平台，基于 archer 二次开发，采用 Django 框架构建。面向需要管理数据库查询与变更流程的团队，提供在线查询、SQL 审核、执行、备份及回滚语句生成等操作。其功能覆盖 MySQL、MariaDB、Oracle、MongoDB、ClickHouse 等十余种数据库，但各数据库支持的功能维度不同，如仅 MySQL/MariaDB 支持完整的查询、审核、执行、备份及会话、账号、参数管理。项目提供 Docker 部署方式，依赖 goInception、gh-ost、SOAR 等外部工具实现审核执行、大表 DDL 与 SQL 优化。

  • 支持 MySQL、MariaDB、Oracle、MongoDB、ClickHouse、Redis、PgSQL、Doris 等 17 种数据库的接入，各库功能覆盖范围不同
  • 对 MySQL/MariaDB 提供查询、审核、执行、备份、数据字典、慢日志、会话管理、账号管理、参数管理、数据归档全维度功能
  • 集成 goInception、SQLAdvisor、SOAR、gh-ost、pt-query-digest 等工具，用于 SQL 审核执行、索引优化、大表 DDL 和慢日志解析

适用场景（解读层）

  • 需要通过工单流程对 MySQL/MariaDB 进行 SQL 审核与执行备份的数据库运维场景
  • 团队对多种数据库（如 Oracle、MongoDB、ClickHouse）进行统一在线查询管理的场景
  • 需要慢日志解析展示、会话与账号管理、数据脱敏等数据库日常管理操作的场景
