基于 Django REST Framework 的后端/API 项目启动模板仓库

综述（解读层）

这是一个供开发者启动 Django REST Framework 后端/API 项目的模板仓库。它预置认证（Djoser）、PostgreSQL、Docker Compose 本地环境、Swagger 文档、自定义用户模型等配置，并通过 Makefile 和 pre-commit 钩子管理常用命令与代码检查。文档接口默认需要 admin 账号登录后方可访问。

  • 内置 Djoser 认证，包含注册、登录、邮箱验证、密码重置及确认流程
  • 提供 Dockerfile 与 Docker Compose 本地开发环境，使用 PostgreSQL 数据库，静态文件由 Whitenoise 提供
  • 集成 Pytest 自动化测试（modal bakery、pytest-xdist 并行、Faker、Coverage）及 Ruff pre-commit 钩子

适用场景（解读层）

  • 需要快速搭建带有用户认证的 Django REST API 项目的场景
  • 希望使用 Docker Compose + PostgreSQL 进行本地开发的后端项目
  • 需要自动生成 Swagger 文档并通过 Pytest/Coverage 管理测试的项目
