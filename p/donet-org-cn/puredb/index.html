🧭 简介解读层（AI·证据行可回查）

纯 .NET 10 托管代码实现的嵌入式文件数据库，提供 KV、SQL 与可选 SQLite 文件兼容

综述（解读层）

PureDb 用 C# 与 .NET 10 标准库实现嵌入式数据库，包含 KV 与 SQL 两套 API 及内置 ADO.NET 连接，支持 JOIN、事务、保存点、JSON、多线程与多进程写入，可选兼容包可原地读写部分模式的 SQLite 文件。存储采用追加日志、CRC32 校验与分页检查点。主键范围为 [0, 2^40)，当前版本为 1.0.0-rc.1 候选版，README 自述尚未在生产环境验证。适合 .NET 应用中需要无原生依赖嵌入存储的场景。

  • 纯托管 C# 实现，核心与兼容库无原生库和第三方 NuGet 依赖，支持 Native AOT
  • SQL 层支持复合索引、外键、CHECK、UPSERT、视图、触发器、CTE、窗口函数、JSON5 及 C# 用户自定义标量函数
  • 内置 ADO.NET Connection/Command/Reader/Transaction，写入采用有界队列、单写入者与分组提交，多进程访问使用 Shared 模式

适用场景（解读层）

  • .NET 应用内嵌入本地结构化存储，避免部署原生数据库文件
  • 需要通过 SQL/ADO.NET 接口读写 KV 与关系数据的应用
  • 需原地读取或修改受支持模式 SQLite 文件的场景（需安装 SqliteCompatibility 包）
