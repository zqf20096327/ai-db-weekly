🧭 简介解读层（AI·证据行可回查）

用于将 SNOMED CT RF2 发布数据加载到多种数据库的脚本集

综述（解读层）

该仓库提供一组脚本，用于将 RF2 格式分发的 SNOMED CT 术语发布数据创建并填充到 MySQL、PostgreSQL、MSSQL、Neo4j 等数据库，还包含 Python DataFrame 和 DuckDB 版本，各数据库脚本按子目录组织。适用于需要在本地方便地构建 SNOMED CT 术语库的开发与研究人员；使用者需自备 RF2 发布包及对应数据库环境，其他数据库脚本可通过 fork 和 pull request 方式贡献。

  • 支持 MySQL、PostgreSQL、MSSQL、Neo4j 等多种数据库的建库与数据加载脚本
  • 处理 SNOMED CT RF2 分发格式的术语发布数据
  • 包含 Python DataFrame 与 Python DuckDB 两种加载方式

适用场景（解读层）

  • 在 MySQL、PostgreSQL 等关系型数据库中构建 SNOMED CT 术语表
  • 将 SNOMED CT 发布数据载入 Neo4j 图数据库
  • 使用 Python（DataFrame/DuckDB）读取和处理 RF2 格式术语数据
📖 README 首段存档原文 · 程序抽取

The scripts in this repository can be used to create and populate a MYSQL, PostgreSQL, MSSQL or NEO4J database with a SNOMED CT terminology release distributed in the RF2 distribution format.
