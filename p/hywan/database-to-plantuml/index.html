🧭 简介解读层（AI·证据行可回查）

读取 PostgreSQL/MySQL 表信息并生成 PlantUML 图描述的工具

综述（解读层）

这是一个 PHP 命令行工具，通过 Composer 安装，连接 PostgreSQL 或 MySQL 数据库读取表结构信息，生成 PlantUML 描述并渲染为图形。它支持 commonmark 和 plantuml 两种后端，后者借助 resource/plantuml.jar 输出多种格式。使用时需在命令行指定 DSN、用户名和 schema 名称，适合需要在文档中呈现数据库表结构图、且环境已具备 PHP、Composer 和 Java 的使用者。

  • 支持 PostgreSQL 与 MySQL 两种数据库前端
  • plantuml 后端可输出 PNG、SVG、EPS、PDF、VDX、XMI、HTML、TXT、UTXT、LaTeX 等格式
  • 通过 Composer 安装，也可作为项目依赖引入（composer require hywan/database-to-plantuml）

适用场景（解读层）

  • 为已有 PostgreSQL/MySQL 数据库的 schema 生成表结构可视化图
  • 将数据库结构图输出为 SVG/PDF 等格式用于文档编写
  • 作为 PHP 项目依赖集成数据库结构可视化功能
