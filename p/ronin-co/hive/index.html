🧭 简介解读层（AI·证据行可回查）

在 TypeScript 项目中嵌入 SQLite，支持可插拔存储后端与双向同步。

综述（解读层）

Hive 是一个将 SQLite 数据库嵌入 TypeScript 项目的工具库，面向前端与全栈开发者。它通过模块化组件提供 MemoryStorage、DiskStorage、S3Storage、RemoteStorage 等存储后端，支持客户端与服务器副本间的自动双向复制，并提供 Bun 等运行时驱动、HTTP REST API、鉴权组件与 SDK。安装方式为通过包管理器添加 hive 依赖；README 注明未来版本驱动将自动按运行时选择。

  • 提供 MemoryStorage、DiskStorage、S3Storage、RemoteStorage 四种可插拔存储后端
  • 内置客户端与服务器副本间的自动双向复制与同步
  • 包含 REST API、API Key/静态密钥鉴权、WebSocket 通信及 SDK 等模块化组件

适用场景（解读层）

  • 开发、测试或迁移脚本中使用内存存储运行嵌入式数据库
  • 构建需要与服务器副本同步的桌面或移动客户端
  • 基于 S3 兼容存储做备份或对外暴露 HTTP API 的服务端部署
