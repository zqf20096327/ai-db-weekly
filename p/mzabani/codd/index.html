🧭 简介解读层（AI·证据行可回查）

以纯 SQL 文件应用 Postgres 迁移并自动做跨环境模式一致性校验的 CLI 工具

综述（解读层）

Codd 是一个面向 PostgreSQL 的命令行迁移工具：用户只需编写 .sql 文件并通过 codd add / codd up 添加执行，无配置文件，仅需 3 个环境变量。迁移默认在单个事务中应用，并在提交前自动比对开发库与其他环境的 schema（列、函数、角色、权限、策略等），差异以文件形式存于 expected-schema 目录，可通过 git 合并冲突发现多人修改同一对象。仅支持 PostgreSQL，不支持 psql 元命令。

  • 以流式方式解析迁移文件，保持有界内存占用，支持任意大的迁移和数千个迁移文件
  • 自动生成并校验 schema 表示文件，检查列、函数、角色、权限、行安全策略等对象差异
  • 支持特殊头注释指令，如 no-txn 事务豁免、自定义连接串及基于 pg_cron 的渐进式大表迁移

适用场景（解读层）

  • 多环境（开发/生产）Postgres schema 一致性校验
  • 多人协作的 SQL 迁移管理，借助 git 冲突提示避免同对象修改
  • 大数据量表结构的后台渐进式变更场景（需 pg_cron）
