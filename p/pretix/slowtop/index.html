基于 Textual TUI 的 PostgreSQL 慢查询浏览与分析工具

综述（解读层）

slowtop 是一个终端界面的 PostgreSQL 慢查询分析工具，可从 JSON 格式的 PostgreSQL 日志文件读取慢查询，也可通过 `-s` 选项读取 pg_stat_statements 数据。它提供按 query_id 分组的统计视图、语法高亮的 SQL 展示，并可将查询发送到 explain.dalibo.com 获取执行计划。需要 PostgreSQL 日志为 JSON 格式或启用 pg_stat_statements，通过克隆仓库并配置 config.py 安装， GPLv3 协议发布。

  • 支持从 JSON 格式日志文件或 pg_stat_statements 读取慢查询
  • 提供按 query_id 分组的统计视图，并支持分组/非分组视图在运行时切换
  • 可将选中查询发送至 explain.dalibo.com 或兼容站点，并复制查询到剪贴板（支持 SSH 环境）

适用场景（解读层）

  • 浏览和检索 PostgreSQL 日志文件中记录的慢查询
  • 通过 pg_stat_statements 按查询分组查看执行统计数据
  • 生成查询执行计划并提交到 explain.dalibo.com 进行分析
