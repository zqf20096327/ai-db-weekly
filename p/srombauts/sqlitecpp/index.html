封装 SQLite3 C API 的 C++ 类库，基于 RAII 管理资源

综述（解读层）

SQLiteC++ 将 SQLite 原生 C API 封装为若干 C++ 类，对象构造时需传入有效的数据库连接，错误通过抛出 std::runtime_error 子类异常报告（析构函数中改用 assert）。4.x 主线要求 C++17 与 SQLite 3.38.0+，3.x 分线兼容 C++11。面向需要在 C++ 项目中调用 SQLite 的开发者，可经 CMake、Meson 或 vcpkg 集成。

  • 采用 RAII 与异常机制封装 SQLite3 C API，API 命名贴近 SQLite 原生名称
  • 提供 CMake、Meson、vcpkg 三种构建/安装方式，支持作为 Git 子模块或子项目使用
  • CI 覆盖 Linux/Windows/macOS 与 GCC、Clang、MSVC 等编译器，附带 Doxygen 文档生成配置

适用场景（解读层）

  • 在 C++ 桌面或服务端项目中以面向对象方式读写 SQLite 数据库
  • 以子模块/子目录形式嵌入自有 CMake 或 Meson 工程
  • 需要 MIT 许可、可静态或动态链接 SQLite 的商业或专有软件项目
