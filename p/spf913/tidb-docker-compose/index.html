用 Docker Compose 编排 TiDB 集群各组件的开源部署模板。

综述（解读层）

该项目通过 docker-compose.yml 和配置模板编排 TiDB、PD、TiKV、TiDB-Binlog、Prometheus、Grafana、tidb-vision 及 TiSpark 等容器。适合需要在单机环境运行完整 TiDB 平台的开发测试人员。README 明确警告仅用于测试，不得用于生产；配置文件需与 TiDB 版本对应，且不支持 Docker Toolbox/Docker Machine。

  • 提供 docker-compose 与 Docker Swarm 两种部署方式，Swarm 模式可用 docker service scale 调整 TiDB Server 实例数量
  • 包含 Grafana（3000 端口）、tidb-vision（8010 端口）监控展示和 Spark Web UI（8080 端口）访问入口
  • 支持用 Helm 作为模板引擎自定义集群规模、镜像、端口映射，并可从二进制或源码构建镜像

适用场景（解读层）

  • 在本机或单机测试环境快速运行包含 TiDB/PD/TiKV/监控组件的完整 TiDB 平台
  • 通过 Swarm 部署多实例 TiDB 并测试并发连接与负载分配
  • 结合 TiSpark 在 Spark Shell/pyspark/sparkR 中处理 TiDB 集群中的样例数据
