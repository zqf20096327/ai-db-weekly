基于 PostgreSQL 与 Docker Compose 的自托管开源后端服务平台（BaaS）

综述（解读层）

SelfDB 是以 PostgreSQL 为核心的自托管 BaaS 平台，通过 Docker Compose 编排六个容器化服务：FastAPI 后端网关、存储服务、Deno 函数运行时、Phoenix 实时中继、PostgreSQL 加 PgBouncer 连接池，以及 React 管理控制台。当前处于早期 beta，官方说明存在破坏性变更且 v0.04 客户端 SDK 与 v0.05 不兼容，暂需直接调用 REST API；另有付费的 Stable 版本。

  • 提供统一 REST API 网关，涵盖认证（JWT + refresh token）、动态表操作、SQL 执行、文件存储与 webhook 管理
  • 包含 Deno 无服务器函数运行时，支持 HTTP、cron、数据库 LISTEN/NOTIFY 等多种触发方式及热重载
  • 通过 Phoenix WebSocket 中继与 PG NOTIFY 实现实时事件推送，并配套多环境隔离端口配置与测试套件

适用场景（解读层）

  • 自托管部署应用后端，将数据库、存储、函数与实时功能整合在一套 Docker Compose 栈中
  • 在单台主机上以隔离端口并行运行开发、预发布、生产等多套环境
  • 需要通过 REST API 或 WebSocket 进行实时事件订阅的应用集成与测试
