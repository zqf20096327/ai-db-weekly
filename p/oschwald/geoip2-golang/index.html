读取 MaxMind GeoIP2/GeoLite2 .mmdb 数据库的 Go 查询库

综述（解读层）

该库基于 maxminddb-golang 实现，读取 MaxMind GeoIP2 与 GeoLite2 数据库文件，提供 City、Country、ASN、ISP、Enterprise 等多种查询方法。面向需要在 Go 程序中按 IP 查询地理与网络信息的开发者。v2 改用 netip.Addr 类型，Reader 可被多个 goroutine 并发使用；不支持的数据库类型返回 UnknownDatabaseTypeError，使用需自备 .mmdb 文件。

  • 支持 City、Country、ASN、ISP、Enterprise、Anonymous IP 等多种数据库类型的查询方法
  • v2 使用 netip.Addr 类型，结果结构体包含 Network、IPAddress 字段并提供 HasData() 方法
  • Reader 支持多 goroutine 并发使用，结果结构体带 JSON 标签

适用场景（解读层）

  • 按 IP 地址查询城市、国家等地理位置信息
  • 查询 IP 对应的 ASN、ISP 组织或域名信息
  • 识别匿名网络/代理类型的 IP
