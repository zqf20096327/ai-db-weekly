Greenplum 数据库的开源 fork，延续 MPP 数仓开发

综述（解读层）

open-gpdb 是 Greenplum Database 转闭源后的开源分支，项目方继续修复 core dump 类缺陷、适配扩展、从 Postgres 9.4+ 与 Cloudberry 回移植特性。当前稳定版本为 6X，7.X 在推进中。支持 configure/make 构建与回归测试，补丁采用 Apache 2.0 许可。适合需要继续使用 GPDB 并参与维护的团队。

  • 修复导致 master/segment 进程 core dump 的缺陷，并回移植 Postgres 与 Cloudberry 的稳定特性
  • 提供 S3 相关扩展（yezzey、yproxy）及审计、表操作统计、内存分布统计等扩展
  • 支持 configure/make 构建、Docker/Vagrant 使用方式与 make installcheck-world 回归测试

适用场景（解读层）

  • 已部署 Greenplum 且需要开源版本继续维护的环境
  • 需要对 AO/AOCS 数据进行 S3 卸载/下载或限流代理的场景
  • 需要表操作统计、内存占用统计等 GP 扩展的运维监控
