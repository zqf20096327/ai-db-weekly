🧭 简介解读层（AI·证据行可回查）

面向 LLM 的 SQL Server 性能调优技能集，含 29 个技能、950 项检查

综述（解读层）

该项目为 LLM（如 Claude）提供一组 SQL Server 性能调优技能，覆盖 T-SQL 源码审查、执行计划、等待统计、Query Store、死锁、索引、Always On AG、加密、SPN/Kerberos、内存与磁盘 I/O 等分析流程，并提供一个编排技能将混合产物路由到对应专项技能。适用于需要按诊断流程处理 SQL Server 各类诊断产物的 LLM 使用者。README 注明技能由 Claude 生成，检查目录与阈值有待人工验证。

  • 包含 29 个专项技能与 950 项编号检查，覆盖从 T-SQL 审查到执行计划、死锁、加密、迁移就绪等 SQL Server 诊断环节
  • 提供 agentic 编排技能（可别名 /sql-triage），将混合诊断产物路由到对应技能并生成含证据链与风险分级的合并报告
  • 通过远程 MCP 服务器接入 Claude.ai（Settings → Connectors → Add custom connector 填入给定 URL）

适用场景（解读层）

  • 将 .sqlplan、等待统计、Query Store DMV 输出、死锁 XML 等诊断产物交给 LLM 进行结构化分析
  • 对比基线与当前工作负载采集，定位回退查询及配置、版本、等待特征差异
  • 审查 Always On AG 健康状况、WSFC 集群日志、ERRORLOG 及 SPN/Kerberos 配置
