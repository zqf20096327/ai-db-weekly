Rust 编写的 Redis 兼容字符串 KV 服务器，支持 RESP2 协议与 AOF 持久化

综述（解读层）

kvred 是用 Rust 和 Tokio 实现的 Redis 兼容字符串键值服务器，通过 TCP 提供 RESP2 协议，支持 PING/GET/SET/DEL/EXISTS 五个命令。所有写命令经单一写序列化器追加到 AOF，按 always/everysec/none 三种 fsync 策略落盘，启动时重放 AOF 恢复状态并支持 AOF 重写压缩。项目定位为系统学习实现，不支持 TTL、事务、复制、集群等特性，适合作为理解协议解析、写顺序与持久化权衡的参考代码，可用 redis-cli 连接测试。

  • 实现 RESP2 协议解析与编码，处理部分读取、单缓冲多帧及二进制安全载荷
  • 通过单一写序列化器保证全局写顺序，支持 always/everysec/none 三种 fsync 持久化策略
  • 启动时重放 AOF 恢复数据，支持 AOF 重写压缩，并提供基准测试脚本与报告生成工具

适用场景（解读层）

  • 作为学习 Rust 异步网络服务、RESP 协议与 AOF 持久化机制的实现参考
  • 测试不同 fsync 策略下的写入吞吐与延迟权衡
  • 作为支持 redis-cli 的轻量字符串 KV 服务运行使用
