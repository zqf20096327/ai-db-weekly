面向 AI 编程客户端的 MCP 数据库服务器，复用 DBeaver 连接查询多种数据库

综述（解读层）

OmniSQL MCP 是一个 MCP 服务器，用于让 Claude Code、Codex、OpenCode 等客户端连接和查询 PostgreSQL、MySQL、SQLite、SQL Server、Oracle、DuckDB、ClickHouse 等数据库。它可读取 DBeaver 兼容工作区的已保存连接，支持通过 npx 引导安装，默认只读模式，并提供连接白名单、工具禁用、策略文件等访问控制。运行要求 Bun 1.4.3+ 或特定版本的 Node.js。

  • 支持 PostgreSQL、MySQL/MariaDB、SQLite、SQL Server、Oracle、DuckDB、ClickHouse，并自动路由 Postgres 兼容数据库（如 CockroachDB、Redshift、Supabase）
  • 可读取 DBeaver 兼容工作区的连接与 SSH 配置，通过 connectionId/database 参数在单个服务器上切换多实例
  • 提供分页结果读取、CSV/JSON 导出（可选 gzip/Brotli/zstd 压缩）、显式事务工具，以及只读模式、连接白名单、策略文件等访问控制

适用场景（解读层）

  • 让 Claude Code、Codex 或 OpenCode 通过 MCP 直接查询本地或远程已配置的数据库
  • 复用 DBeaver 中已保存的连接配置，避免在 AI 客户端中重复录入凭据
  • 以只读方式让 AI 助手浏览表结构、解释查询和导出数据
