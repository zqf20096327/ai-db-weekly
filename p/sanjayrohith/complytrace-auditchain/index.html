基于 RAG 的 AI 合规平台，匹配州法规并生成哈希链审计记录

综述（解读层）

ComplyTrace 是面向部署 AI 系统的公司的合规工具：登记企业与 AI 系统后，用向量检索将系统描述与美国六个州的 AI 法规语料做余弦相似度匹配，生成引用法条原文的披露文档，并以 SHA-256 哈希链记录所有合规操作。技术栈为 Next.js、PostgreSQL + pgvector、Drizzle ORM，通过 Docker Compose 启动。README 注明其披露文档非法律意见，演示配置需额外加固方可用于生产。

  • 使用 all-MiniLM-L6-v2 嵌入（零填充至 1024 维）与 pgvector HNSW 索引实现法条语义检索匹配
  • 审计日志采用 SHA-256 哈希链，数据库层 REVOKE UPDATE, DELETE 强制追加写入，并提供链完整性验证接口
  • 提供带 x-api-key 认证的 REST API，覆盖组织登记、RAG 分析、披露生成与外部决策日志写入

适用场景（解读层）

  • 在加州、伊利诺伊、科罗拉多、弗吉尼亚、纽约、犹他等州运营 AI 系统的企业进行适用法规匹配与合规状态跟踪
  • 生成引用法条原文、含来源溯源和占位符的合规披露文档
  • 通过公开 API 端点将外部系统的 AI 决策写入可验证的追加式审计日志
