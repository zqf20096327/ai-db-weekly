基于 .NET 与 Hyperlambda 的开源低代码全栈平台，含 MCP 服务器

综述（解读层）

Magic 是一个 MIT 许可、基于 .NET 的开源平台，通过自然语言或向导生成数据库、REST API、前端与 AI Agent，运行于用户自有硬件。其 Hyperlambda 语言以 AST 方式由 LLM 生成并校验函数存在性，沙箱执行并通过 RBAC 白名单限制函数调用。内置 Hyper IDE、SQL Studio、端点生成器、Web Designer、Chat Ops 等仪表盘组件，支持 Docker 部署与 OpenAPI 导入。README 中的性能与省钱数据为作者自测，未经独立复现。

  • 提供 Endpoint Generator、SQL Studio、Hyper IDE、Web Designer 等仪表盘组件，保存代码后即可测试，无部署步骤
  • 内置 MCP 服务器，可将 modules 文件夹中的 HTTP 端点暴露给 MCP 客户端作为工具调用
  • Hyperlambda 生成基于 AST 并校验函数存在性，运行于沙箱，可经 RBAC 白名单限制可调用函数

适用场景（解读层）

  • 为已有 MySQL、PostgreSQL、SQL Server 或 MariaDB 数据库生成 CRUD REST API
  • 构建可查询自有数据库、受 RBAC 控制的 AI Agent 与 MCP 工具服务器
  • 基于网站内容爬取生成可嵌入的聊天机器人及后台定时任务
