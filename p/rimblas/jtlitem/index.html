Oracle APEX 条目插件，用 JSON 列在单表中存储多语言翻译

综述（解读层）

jtlitem 是一个 Oracle APEX Item 插件，将多语言翻译（MLS）以 JSON 数组形式存入单个表列（如 NAME_JTL），无需为每张表建翻译子表。用户可通过弹窗编辑各语言译文，数据可经 JSON_TABLE 从 _VL 视图提取，并提供 tk_jtl_plugin 包做程序化访问。列大小需按“所需长度×语言数+偏移”设置；12c 以上支持 JSON 列约束，11g 可用 varchar2/clob 配合 apex_json 转换运行（有性能开销）。v1.2.0 起支持 Interactive Grid。

  • 在单个表列中存储多语言翻译，支持通过弹窗对话框编辑各语言译文
  • 提供 tk_jtl_plugin 包（含 get_tl_value 等）用于程序化读写 JSON 翻译数据
  • 支持 Interactive Grid（IG）、Textarea 子类型，可在 11g 上以 varchar2/clob 方式运行

适用场景（解读层）

  • 使用 APEX Automatic Row Fetch/Processing 的多语言应用，需在单表中保存翻译字段
  • 需要通过 _VL 视图与 JSON_TABLE 按语言提取翻译数据供 LOV 或报表使用
  • 已有翻译表数据需迁移为 JSON 列存储的场景（README 提供数据转换说明）
