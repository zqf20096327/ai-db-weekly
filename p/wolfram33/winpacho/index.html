Windows 便携式 WAMP 整合包：Apache、PHP、MariaDB/MySQL 单压缩包解压即用

综述（解读层）

winpacho 是面向 Windows 本地开发环境的便携式 WAMP 服务器整合包，将 Apache、MariaDB/MySQL（可切换）、PHP 8.3/8.4/8.5 与 Adminer 打包为单个 zip，解压后运行 WinpachoController.exe 即可使用，无安装器与注册表写入。它由 The Uniform Server 的控制程序源码（Free Pascal/Lazarus 编写）延续而来，本仓库只含控制器源码，服务器二进制由 CI 打包脚本从各官方渠道获取。升级采用覆盖 exe 或换目录迁移 www、数据库与配置的方式。

  • 单个 zip 包含 Apache、MariaDB 与 MySQL（可切换）、PHP 8.3/8.4/8.5（控制器内切换）、Adminer，无外部依赖，无安装器与注册表项
  • 控制器首次启动自动生成 localhost 自签名证书并启用 SSL，支持创建多个去重写入 hosts 的虚拟主机（http/https）
  • 提供滚动发布（每次 push 更新）与按 git 标签构建的版本化发布，CI 对每个已装 PHP 版本做冒烟测试

适用场景（解读层）

  • 在 Windows 上搭建本地 PHP 开发/测试环境，需要多版本 PHP 切换或 MariaDB/MySQL 双引擎
  • 需要免安装、可随目录移动的便携服务器（如 U 盘或无权限安装软件的机器）
  • 从 The Uniform Server 或 uniserver-reload 迁移的既有安装继续维护与升级
