综述（解读层）

PgDog 是一个面向 PostgreSQL 的开源代理，用于连接池管理、查询负载均衡和数据库分片。客户端通过 PostgreSQL 协议连接它，其内置 SQL 解析器可识别写语句并路由到主库、按分片键路由查询，跨分片结果在内存中聚合。部署方式包含 Helm chart、ECS Terraform 模块和 Docker Compose。

  • 支持事务级与会话级连接池，可解析 SET 语句和启动参数以维护会话状态
  • 作为应用层负载均衡器提供 round robin、random、least active connections 三种策略，并内置健康检查与副本提升后的写路由切换
  • 支持 HASH/LIST/RANGE 分区及 schema 两种分片算法，跨分片查询结果在内存中合并返回

适用场景（解读层）

  • 多客户端共享少量数据库连接的连接池场景
  • 主库加多副本架构下的读写分离与故障切换
  • 按分片键拆分数据到多个 PostgreSQL 实例的分库部署
