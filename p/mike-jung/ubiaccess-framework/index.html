🧭 简介解读层（AI·证据行可回查）

基于 Node/Express 与关系型数据库的 MVC 架构样板项目，支持注解自动加载

综述（解读层）

这是一个 MVC 架构的样板项目，使用 Node.js、Express 与 MySQL/MariaDB（亦支持 SQLite 和 Oracle），供开发者快速搭建 Web 服务。它通过注解（类似 Spring）自动扫描加载控制器，SQL 语句与服务、控制器分离，服务定义后自动生成 Promise 方法。运行前需安装 MySQL 和 Redis 并修改 config/config.js，通过 npm start 启动。Windows 下安装部分模块需 Python 和 Visual Studio 环境。

  • 支持注解方式的控制器自动扫描与加载，无需额外配置
  • SQL 语句独立于控制器和服务存放，通过 sql-config.js 注册后自动加载
  • 内置数据库主从 failover 配置，支持 MySQL(MariaDB)、SQLite 和 Oracle

适用场景（解读层）

  • 需要预置分页、排序、搜索等 REST API 能力的 Web 服务开发
  • 使用 SocketIO 实现聊天类应用，WebRTC 进行音视频流传输
  • 需要向 Android 和 iOS 设备发送 FCM 推送消息的应用场景
