🧭 简介解读层（AI·证据行可回查）

Rust 实现的持久化 copy-on-write B+Tree 索引结构。

综述（解读层）

该仓库用 Rust 实现持久化的 copy-on-write B+Tree，设计目标为键值存储的索引，设计上参考了 SQLite。每个 BTree 实例对应一个文件，节点按预定义结构落盘，写入或删除时复制新节点而不改动旧版本，并通过 write-ahead-log 记录当前根节点。支持从磁盘进行崩溃恢复，目前键值对为固定长度，变长键值对、键压缩与垃圾回收尚未实现。单元测试位于 src/page.rs 和 src/node.rs，可作为 API 使用示例。

  • 支持读、写、删除等 CRUD 操作
  • 写入采用 copy-on-write 方式，并通过 write-ahead-log 记录树的当前根节点
  • 支持从磁盘进行崩溃恢复

适用场景（解读层）

  • 为键值存储提供持久化索引
  • 需要了解 B+Tree 落盘结构（内部节点/叶子节点）的学习与实验场景
  • 作为 Rust 中 B+Tree 与反序列化（TryFrom）实现的参考代码
