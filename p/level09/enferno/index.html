面向编码代理的 Flask 框架：Vue 3 免构建、内置生产级认证与 AGENTS.md。

综述（解读层）

Enferno 是一个为 Claude Code、Cursor 等编码代理设计的 Flask 框架，前端采用 Vue 3 与 Vuetify 且无需构建步骤。它通过 AGENTS.md、代理技能文件和只读 MCP 服务器向代理提供项目信息，并用 pytest 套件校验路由权限、迁移一致性等。使用方式为克隆仓库后运行 setup.sh，需 Python 3.11+ 与 uv。

  • 提供 AGENTS.md、enferno-dev 技能和只读 flask mcp 服务器，用于向编码代理传达栈结构、命令与运行状态
  • 内置登录、注册、TOTP 2FA、passkeys（WebAuthn）、恢复码及 Google/GitHub OAuth 认证
  • 测试套件自动检查受保护路由的匿名访问拒绝、模型与迁移一致性和 CSRF 强制执行

适用场景（解读层）

  • 由编码代理按自然语言描述生成并迭代 Flask + Vue 应用
  • 作为带用户、角色和审计日志的 SaaS 项目起始代码库
  • 需要免构建前端（vendored Vue 3/Vuetify）的 Python 全栈项目
