🧭 简介解读层（AI·证据行可回查）

基于 redb 的 Rust 内嵌数据库，支持多索引与实时订阅

综述（解读层）

Native DB 是面向多平台应用（服务器、桌面、移动端）的 Rust 内嵌数据库。它通过 native_model 实现透明的序列化/反序列化，事务由 redb 提供并保证 ACID。README 注明项目处于活跃开发阶段，API 尚不稳定、可能变动。安装需在 Cargo.toml 中添加 native_db 与 native_model 两个依赖。

  • 支持主键、二级、唯一、非唯一、可选等多种索引，查询具备类型安全检查
  • 支持插入/更新/删除操作的实时订阅，可设置过滤器，并提供热快照
  • 通过 native_model 实现透明序列化，可选用 bincode、postcard 或自定义序列化库，支持自动模型迁移

适用场景（解读层）

  • Rust 多平台应用（服务器、桌面、iOS/Android 移动端）中的本地数据存储
  • 需要对数据变更进行实时监听的应用场景
  • 需要跨版本数据模型迁移的内嵌存储场景
