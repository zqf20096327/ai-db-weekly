Android 链式调用 SQLite 封装库，无需写 SQL 即可建表与 CRUD

综述（解读层）

AndroidEasySQL 是面向 Android 的 SQLite 封装库，供需要在本地存储结构化数据但不想手写 SQL 或 SQLiteOpenHelper 的开发者使用。开发者声明表名和各列后，通过链式调用 addData/updateData 等方法完成增删改查；2.0.0 用 Kotlin 重写，同时兼容 Java，最低要求 API 21，经 JitPack 引入，采用 MIT 许可证。

  • 链式 API 建表与增删改查，无需编写 SQL 或自定义 SQLiteOpenHelper
  • 每张表自动生成自增 ID 主键列；值支持 String、Int、Long、Double 或 null
  • 无额外依赖，最低支持 Android 5.0（API 21），可从 Kotlin 和 Java 调用

适用场景（解读层）

  • Android 应用中本地结构化数据的增删改查，如示例中的笔记应用
  • 需要按列搜索、排序或统计行数的轻量本地存储场景
  • 从 1.x 版本迁移的既有项目，多数代码无需修改即可继续使用
📖 README 首段存档原文 · 程序抽取

A small SQLite library for Android. Create a table, then add, read, update and delete rows in a few chained calls, without writing SQL or a SQLiteOpenHelper of your own.
