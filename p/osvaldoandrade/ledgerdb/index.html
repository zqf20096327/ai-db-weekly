🧭 简介解读层（AI·证据行可回查）

基于裸 Git 仓库的不可变文档数据库，每次写入作为一个提交并经 CAS 解决冲突。

综述（解读层）

LedgerDB 接受 JSON 文档，将每次写入序列化为 TxV3 protobuf blob 并以乐观并发控制在裸 Git 仓库上提交；SQLite sidecar 可将提交日志投影为 SQL 表。CLI 为主接口，另提供 Go 与 TypeScript SDK。仓库无服务端进程，多写者拓扑依赖 Git 克隆与远程；历史模式支持 append 与 amend，后者仅保留最新状态。

  • 每次写入以 TxV3 protobuf blob 作为不可变 Git 提交存储，支持 RFC 6902 JSON patch 与 doc log 历史遍历
  • 通过 git push/pull 复制，doc put/patch 默认自动 fetch 与 push，冲突经 CAS 与指数退避重试
  • ledgerdb index watch 维护 SQLite sidecar，将数据投影为可 SQL 查询的表，支持表达式索引与唯一约束

适用场景（解读层）

  • 需要离线本地写入、经 Git 远程同步的多副本场景
  • 需要文档级不可变历史以供审计的写入负载
  • 需要在同一数据上运行 SQL 查询的部署
