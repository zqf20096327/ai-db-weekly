Firebolt 分布式查询引擎的免费自托管版本，以单个 Docker 镜像部署

综述（解读层）

Firebolt Core 是 Firebolt 托管云数仓的自托管版本，提供查询优化器、分布式执行引擎和 Iceberg 支持等能力，SQL 方言与 Postgres 兼容并包含数组处理等分析扩展。通过 Docker 镜像运行，数据持久化于 /var/lib/firebolt，可按 config.json 组建多节点集群，也提供 Kubernetes 部署文档。要求 Linux 内核 ≥6.1（依赖 io_uring），建议每节点 16GB 内存、25GB SSD。查询通过 HTTP 客户端、内置 CLI 或配套 Web UI 提交。

  • 以单个 Docker 镜像（ghcr.io/firebolt-db/engine:dev）交付，包含运行所需全部组件
  • 支持 Docker Compose 多节点部署与 Kubernetes 部署，多节点时使用 io_uring 进行网络和磁盘 I/O
  • 提供 HTTP 查询接口（默认端口 3473）、容器内 CLI 及可选 Web UI 镜像，发布 amd64/arm64 多架构镜像

适用场景（解读层）

  • 在自建服务器或本地工作站上运行分析查询引擎
  • 用多台主机组装分布式集群处理大规模数据处理工作负载
  • 通过 Postgres 兼容 SQL 与 JDBC 接入现有分析工具链
