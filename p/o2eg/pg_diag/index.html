面向 PostgreSQL 10-18 的诊断报告工具，采集目录/统计并生成 HTML/JSON 报告

综述（解读层）

pg-diag 是一个 PostgreSQL 诊断报告工具，基于 pg_perfbench，支持 PostgreSQL 10-18。它通过只读 SQL 采集目录与统计数据，支持本地、SSH 远程和仅远程数据库三种采集模式，可做重复快照生成速率/增量图表，默认输出 report.json、report.html 和 report.log。报告内容以声明式 content pack 组织，运行需 Python 3.10+、asyncpg、AsyncSSH 与 PyYAML。

  • 支持一次性采集、重复快照与日志文件三种报告模式，采集途径覆盖本地、SSH 远程和仅数据库连接
  • SQL 执行限定为只读，核心报告部分（目录、活动、锁、WAL、复制、存储、vacuum、索引）无需扩展
  • 默认生成自包含 HTML 报告与结构化 JSON 构件，错误诊断直接嵌入失败的报告条目中

适用场景（解读层）

  • 对 PostgreSQL 实例进行健康检查与性能排查，生成可人工审阅的 HTML 报告
  • 将 JSON 诊断构件接入 LLM、ETL 或其他自动化流程做后续处理
  • 通过可选的 pg_stat_statements / pg_wait_sampling 扩展采集 SQL 工作负载与等待采样数据
