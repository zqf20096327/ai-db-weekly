🧭 简介解读层（AI·证据行可回查）

C++17 编写的多模型自托管数据库，支持 JSON 文档、向量搜索与媒体存储。

综述（解读层）

PacificDB 是用 C++17 构建的多模型数据库引擎，将 JSON 文档、向量嵌入和媒体文件存于同一系统，采用 WAL/LSM 持久化和 RF3 复制，面向探索 AI、RAG 应用或通用数据负载的开发者。支持精确相似度检索与可选的 HNSW ANN 索引；分布式分片向量搜索不在支持范围内，提供网络访问前需配置 TLS 与访问控制。

  • 支持文档 CRUD、过滤器、二级索引与聚合，以及带 collection schema 的稠密/稀疏/命名向量记录
  • 提供精确余弦、L2、点积相似度搜索，可选择性启用独立 HNSW 索引与混合检索
  • 包含可断点续传的图像/音频/视频/文件存储、WAL/LSM 持久化、快照、备份恢复与 RF3 复制

适用场景（解读层）

  • 本地自托管运行，查询 JSON 文档并评估向量搜索能力
  • 开发者在 AI 与 RAG 应用场景中存储文档、嵌入向量和媒体文件
  • 从源码构建测试：通过 CMake 构建引擎并用 ctest 运行测试
