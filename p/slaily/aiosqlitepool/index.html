🧭 简介解读层（AI·证据行可回查）

基于 asyncio 的 SQLite 连接池层，复用长生命周期连接管理并发。

综述（解读层）

aiosqlitepool 是面向 asyncio 应用的 SQLite 连接池层，非数据库驱动，需与 aiosqlite 等驱动配合使用。它通过 connection_factory 创建连接，支持连接复用、健康检查、空闲替换，返回连接时回滚未提交事务，但事务提交由使用者负责。适用于并发较高的 asyncio Web 服务或后台任务场景。

  • 按需创建连接至 pool_size 上限，复用空闲连接并提供健康检查与空闲超时替换
  • 支持 async 上下文管理器自动清理，连接返回时自动回滚未提交事务
  • 提供 pool_size、acquisition_timeout、idle_timeout 等配置参数，README 给出读写负载的推荐配置

适用场景（解读层）

  • 处理持续 Web 流量（README 建议 5-10 请求/秒以上）的 asyncio 应用
  • 高吞吐后台任务/工作队列的数据库访问
  • 配合 FastAPI lifespan 与依赖注入管理连接池生命周期
