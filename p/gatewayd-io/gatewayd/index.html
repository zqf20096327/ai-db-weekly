云原生数据库网关，位于数据库与客户端之间代理通信

综述（解读层）

GatewayD 是开源数据库网关与框架，以 L4 代理方式转发数据库服务器与客户端之间的通信。核心与数据库协议无关，通过启动时加载的插件（通常用 Go 编写为独立可执行文件，可用 SDK 开发）实现对流量的解析、缓存、注入检测等处理。采用 AGPLv3 许可，文档涵盖安装、配置、可观测性与插件开发。

  • 提供连接池与代理，管理数据库服务器与客户端间的连接
  • 核心与数据库协议无关，数据库支持由插件编码解码流量实现
  • 内置日志、指标与追踪，支持多租户管理多个数据库与客户端

适用场景（解读层）

  • 在客户端与 PostgreSQL 等数据库间代理并池化连接
  • 通过插件缓存 SELECT 查询结果或检测 SQL 注入
  • 需要认证授权、防火墙、变更数据捕获等中间件能力的场景
