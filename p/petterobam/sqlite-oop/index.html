Java 版 SQLite 面向对象封装库，基于实体类自动建库建表并提供增删查改操作

综述（解读层）

这是一个对 SQLite 进行面向对象封装的库，根据实体类自动创建库和表，提供通用动态增删查改、自定义 SQL 和动态 SQL 支持，无需 XML 配置，并提供批量事务与连接池能力。适用于 Java 项目中需要嵌入式 SQLite 存储的场景，扩展支持按日期自动分库，可用于日志系统与数据统计分析。查询分页、备份、密码连接等仍在 Todo 清单中，尚未实现。

  • 根据实体类自动创建库和表，无需 XML 配置
  • 提供默认通用动态增删查改操作，支持自定义 SQL 和动态 SQL
  • 扩展实现表格分库，可按日期自动生成库，批量操作（事务）与连接池已实现

适用场景（解读层）

  • Java 项目中使用 SQLite 作为嵌入式存储的场景
  • 日志系统等按日期自动分库的数据存储
  • 数据统计分析类应用的数据管理
