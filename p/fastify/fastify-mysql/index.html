Fastify 的 MySQL 连接池插件，基于 mysql2 共享连接池

综述（解读层）

该插件为 Fastify 服务器注册 mysql 命名空间，通过 mysql2 创建连接池并提供 pool、query、execute 等属性，客户端关闭由插件内部处理。支持 connectionString、uri 配置及 promise 模式以配合 async/await，还支持命名实例作用域。适用于需要在 Fastify 各处共享 MySQL 连接池的项目，使用时需注意 connectionString 会忽略其他 mysql2 选项。

  • 在 Fastify 实例上注册 mysql 命名空间，包含 pool、query、execute 属性，支持在服务器各部分共享同一连接池
  • 底层使用 mysql2，支持 connectionString/uri 配置及 promise: true 选项以支持 async/await
  • 提供命名实例作用域机制，命名客户端可被子作用域继承，并导出 MySQLRowDataPacket、MySQLResultSetHeader 等类型与 isMySQLPool 等类型检查方法

适用场景（解读层）

  • 为 Fastify 应用接入 MySQL，在路由等各处共享连接池执行查询
  • 使用 async/await 风格代码时以 promise 模式创建 mysql2/promise 连接池
  • TypeScript 项目中需要为 mysql2 四种客户端类型及查询返回数据指定类型
