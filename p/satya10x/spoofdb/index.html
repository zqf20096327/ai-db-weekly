单二进制程序，模拟 Postgres、MySQL、ClickHouse、Redis 线协议并提供查询服务

综述（解读层）

spoofdb 是一个用 Go 编写的单二进制工具，通过实现 Postgres、MySQL、ClickHouse 的真实线协议和 Redis 的 RESP 协议对外提供服务，SQL 数据统一由内嵌 DuckDB 引擎处理，Redis 由内嵌 miniredis 支持。数据源可来自 parquet/csv 文件、目录或对真实数据库启动时快照。适用于本地开发、测试、CI 和演示环境。运行时创建的表默认持久化到单个数据文件，可通过 -stub-missing-schema 让应用在缺少表结构时以空表方式启动。

  • 实现 Postgres、MySQL、ClickHouse、Redis 四种线协议，标准客户端和驱动无需改动即可连接
  • 三种 SQL 协议共用同一个内嵌 DuckDB 引擎，一个协议下创建的表可通过其他协议查询；支持 DuckDB 方言的 DDL/DML、COPY、窗口函数、CTE 等
  • 支持从 parquet/csv 文件、目录或 Postgres/MySQL/ClickHouse 活库（启动时快照后断开）加载源数据；可配置多个实例模拟分片拓扑，共享源数据的实例共用一个引擎

适用场景（解读层）

  • 本地开发和测试中替代真实数据库栈，仅修改连接的 host/port
  • CI 流水线中提供轻量数据库依赖，支持 -persist=false 纯内存运行
  • 对真实生产库做快照后离线提供数据服务，或用 RDB dump 离线提供 Redis 数据
