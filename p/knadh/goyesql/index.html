🧭 简介解读层（AI·证据行可回查）

解析含命名查询的 SQL 文件并映射到 Go 程序的库

综述（解读层）

goyesql 是一个 Go 库，用于解析包含多条命名查询（-- name: 标记）的 SQL 文件，将查询文本关联到 map，并可通过辅助函数将其准备为 *sql.Stmt 后扫描进结构体字段。适用于在 Go 项目中将 SQL 与代码逻辑分离的开发者。基于 nleof/goyesql 但不再兼容，引入任意标签类型并更改了结构体和错误类型；支持通过 stuffbin 与 ParseBytes 嵌入查询。安装使用 go get 获取 v2 版本。

  • 解析 SQL 文件并将命名查询关联到 map，查询字符串与任意标签列表可被访问
  • 提供辅助函数将查询准备为 *sql.Stmt 并扫描进结构体
  • 支持 ParseBytes 配合 stuffbin 将 SQL 查询嵌入二进制

适用场景（解读层）

  • 将 SQL 查询从 Go 代码逻辑中分离到独立 .sql 文件管理
  • 在应用启动时集中准备多条预编译语句并传入结构体复用
  • 需要为查询附加自定义标签参数的场景
