🧭 简介解读层（AI·证据行可回查）

将持续到达的内容流转为可搜索、可监控资源的开源引擎

综述（解读层）

Quivr 是 The Vibe Company 开发的开源引擎（MIT 协议），用于存储持续到达的文档、提供关键词与语义混合搜索，并按保存的告警规则记录匹配文档。它通过 HTTP API 交互，自身无用户界面；文档经确认后落库于 PostgreSQL 与对象存储，保留各版本，处理在后台进行。搜索索引可从存储重建。运行依赖 Docker Compose、Go 与 Python 3.12。

  • 支持关键词、语义或两者结合的搜索，结果指向具体段落、文档及版本，可通过 quivr mcp 供 AI 代理调用
  • 文档确认后持久存储，保留所有版本；文档撤回时立即退出搜索并通知相关告警
  • 文件格式、数据源、嵌入模型、排序与告警规则均以插件（小型 HTTP 服务）形式实现，可用任意语言替换

适用场景（解读层）

  • 应用通过 HTTP API 集成文档搜索能力，需引用原文段落与版本来源
  • 按订阅主题（如布尔表达式或自然语言描述）监控 RSS、Microsoft 365 邮箱、X 列表等来源的新内容，并经签名 webhook 接收匹配结果
  • 需要保留文档修正历史、撤回内容即时生效的场景
