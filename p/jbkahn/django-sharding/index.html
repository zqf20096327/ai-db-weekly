Django 应用的数据库分片库，按用户等模型将数据分片存储到多个数据库

综述（解读层）

这是一个为 Django 应用提供分片能力的库与轻量框架，由开发者在 Wave 工作期间经验总结而成。它通过装饰器配置分片模型（如以 User 模型为分片键），将同一表的不同行分布到多个数据库中，以增加连接数并提升读性能。支持 Python 3，不支持 Django 1.10.3。各流水线组件均含至少一个实现且可替换，需阅读文档完成安装配置。

  • 提供 @shard_storage_config 和 @model_config 装饰器配置分片用户模型与分片模型
  • 数据迁移沿用 Django 原生 makemigrations/migrate 流程，并在各分片上执行
  • 分片流水线各组件均含默认实现，且每个组件可单独替换

适用场景（解读层）

  • 需要将单表数据水平拆分到多个 PostgreSQL 数据库的 Django 应用
  • 以用户为分片键、按用户路由数据存储位置的多租户类应用
  • 希望提升数据库连接数与读取性能的场景
