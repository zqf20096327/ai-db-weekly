🧭 简介解读层（AI·证据行可回查）

基于 Go 与 React 的 WordPress/PHP 主机控制面板，以数据库驱动的调和器收敛多租户服务器状态

综述（解读层）

Jabali Panel 面向 WordPress 与 PHP 托管场景的多租户控制面板，面板二进制同时提供 API 与内嵌 SPA，特权操作经由 root 属主的 Unix-socket 代理执行。安装脚本在 Debian 13 上编译构建并部署 MariaDB、PowerDNS、Stalwart、CrowdSec 等模块，通过 60 秒调和器读取数据库收敛 nginx、PHP 池、邮箱、DNS 与 SSL 配置。

  • 每用户独立 Linux 账户与 PHP-FPM master，配合 cgroup v2、POSIX 配额及 bubblewrap 沙箱 SSH
  • 60 秒调和器以数据库为唯一事实源，收敛 nginx vhosts、PHP 池、邮箱、DKIM、DNS、SSL 与资源限额
  • 集成 restic 加密备份（SFTP/S3/B2/Azure/GCS 目标）、CrowdSec AppSec WAF、cPanel/WHM 迁移与 IMAP 邮件同步

适用场景（解读层）

  • 在单台 Debian 13 服务器上运营多租户 WordPress/PHP 托管
  • 从 cPanel/WHM 迁移账户并保留 MySQL 用户与密码哈希
  • 需要自建邮件（Stalwart + JMAP 网页邮箱）与权威 DNS（PowerDNS + DNSSEC）的主机环境
