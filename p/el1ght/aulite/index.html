🧭 简介解读层（AI·证据行可回查）

欧盟AI法案合规HTTP代理，拦截分析AI交互并生成审计报告

综述（解读层）

Aulite 是一个部署在应用与AI提供商之间的 HTTP 代理，对每个请求/响应做欧盟AI法案（Regulation 2024/1689）合规风险分析，写入 SHA-256 哈希链的追加式 SQLite 审计日志，并生成 Art. 12/27/72/73 相关 PDF 报告。面向需要自托管合规审计的AI应用团队，通过 Docker 单容器部署，应用仅需修改 base_url 即可接入，规则以关键词匹配为主，可选 LLM Judge 做语义分析。

  • 内置 143 条关键词规则，覆盖欧盟AI法案 Annex III 全部 8 个高风险领域，含 11 种欧盟 PII 模式
  • 审计日志采用 SHA-256 哈希链与 WAL 模式的追加式 SQLite，可通过 /verify 端点校验
  • 支持 OpenAI、Anthropic、Azure OpenAI 及任意 OpenAI 兼容 API，按模型名自动路由，支持 SSE 流式传输

适用场景（解读层）

  • 为使用高风险类别场景（招聘、信贷、教育等）的 AI 应用建立交互日志与合规审计
  • 自托管环境中监控 AI 交互中的禁用实践与 PII 泄露风险
  • 生成 FRIA 草案、事件报告等 PDF 文档供监管沟通使用
