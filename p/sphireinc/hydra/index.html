Go 结构体注水库，基于反射与 hydra 标签从多数据库行填充结构体字段

综述（解读层）

Hydra 是一个 Go 库，通过反射和 `hydra` 标签将数据库行数据填充到 Go 结构体。支持 MySQL、MariaDB、SQLite、PostgreSQL、CockroachDB、MSSQL、Oracle 七种数据库，接受 *sql.DB 或 pgx.Conn 等句柄。使用时需以可寻址指针调用 Init，表名按覆盖方法、HydraTableName()、小写类型名的顺序解析。README 提示该项目仍在演进中，API 处于稳定化阶段而非完全成熟。

  • 支持 `hydra` 标签做列映射，并提供 pk、lookup 标签用于主键和查找字段填充
  • 内置多种类型转换，包括字符串/字节、布尔、有符号与无符号整数、浮点数、指针、接口，NULL 可填入指针、切片、映射和接口字段
  • 支持字段级 HydraConvert 与父级 HydraConverters() 两种自定义转换器，以及带 context 取消/超时的 API 变体

适用场景（解读层）

  • 在 Go 应用中将单行查询结果直接填充到结构体，用于按主键或 lookup 字段读取记录
  • 需要在同一代码库中对接多种数据库（如 SQLite 本地开发、PostgreSQL/CockroachDB 生产）的场景，可通过 XDBTypeOverride 路由
  • 需要对取消/截止时间敏感的数据库调用，可使用 HydrateContext 等带 context 的接口
