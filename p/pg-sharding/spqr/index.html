SPQR：基于分片的 PostgreSQL 水平扩展查询路由器

综述（解读层）

SPQR 是由 Yandex Cloud 数据平台团队开发的 PostgreSQL 查询路由器，通过分片实现数据库水平扩展。项目以 Go 编写，采用无状态路由机制，由 spqr-router 进程读取 YAML 配置运行。README 提及现有分片方案多面向 OLAP/HTAP 场景，SPQR 旨在为单体到分片的迁移提供路径。源码遵循 PostgreSQL 许可证发布。

  • 提供通过分片实现的 PostgreSQL 水平扩展能力
  • 使用 spqr-router 命令读取 YAML 配置文件运行
  • 包含单元、回归和端到端三类测试，需 Docker Compose 运行

适用场景（解读层）

  • 单实例 PostgreSQL 数据量达 TB 级、查询量高的分片改造
  • 需要从单体数据库向分片架构迁移的场景
  • 本地开发可用 make run 通过 Docker 快速启动示例
