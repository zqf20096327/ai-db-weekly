🧭 简介解读层（AI·证据行可回查）

Go 编写的 LLM 网关，提供兼容 OpenAI 的统一端点并内置 SQLite 与管理面板。

综述（解读层）

Lintasan 是一个用 Go 编写的 LLM 网关，将 OpenAI、Anthropic、Gemini 等多个提供商聚合到一个 OpenAI 兼容端点后面。它实现多阶段路由、连接池轮询负载均衡、熔断器、语义缓存和成本追踪，使用嵌入式 SQLite 存储数据，SvelteKit 面板通过 go:embed 打包进单个约 26MB 的二进制文件，无需 Node.js 运行时。面向自托管用户与需要集中管理多个 API key 和使用监控的团队。

  • 提供 OpenAI 兼容端点，通过多阶段路由（header → model → priority → fallback）与熔断器自动禁用故障提供商
  • 包含 25 页面的 SvelteKit 嵌入式仪表盘、实时分析、请求日志、成本追踪及带使用追踪的 API key 管理
  • 使用嵌入式 SQLite（无需外部配置），支持 SSE 流式传输、语义缓存、token 压缩、MCP server 以及凭据的 AES-256-GCM 加密存储

适用场景（解读层）

  • 统一由多个 LLM 提供商支持的应用程序背后的单个 API 端点
  • 通过仪表盘和指标端点对 token 使用情况、延迟和每个请求的成本进行监控
  • 部署单二进制文件的自托管网关实例
