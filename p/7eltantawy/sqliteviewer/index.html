一款用于读取和查看 SQLite 数据库内容的 Flutter 应用。

综述（解读层）

SQLite Viewer 是一个基于 Flutter 构建的数据库查看工具，可读取 SQLite 数据库文件，浏览其中的表和列，并直接执行 SQL 查询。界面提供针对 SQL 关键字、数据类型及现有表和列的基础语法高亮。适合需要在图形界面下查看 SQLite 数据内容的用户使用。

  • 读取 SQLite 数据库并查看其中的表和列
  • 支持在数据库上执行 SQL 查询
  • 提供针对 SQL 关键字、数据类型及现有表和列的基础语法高亮

适用场景（解读层）

  • 浏览 SQLite 数据库中的表数据内容
  • 通过执行 SQL 查询检索数据库数据
  • 在图形界面中选择特定表和列进行查看
