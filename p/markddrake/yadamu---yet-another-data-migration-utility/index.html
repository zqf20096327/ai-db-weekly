跨数据库数据迁移工具，支持异构导入导出与云端暂存

综述（解读层）

YADAMU 是一个数据迁移工具，最初定位为 Oracle 传统 IMP/EXP 工具的替代品，现已支持 Oracle、Postgres、MySQL、MariaDB、SQL Server、MongoDB、Snowflake、Vertica 等多种数据库之间的导入、导出与复制操作。工具提供三种运行模式：EXPORT/IMPORT（经文件中转）、PUMP（源库直连目标库）、COPY（生成 CSV 供 Vertica/Snowflake/Redshift 直接加载）。它同时迁移 DDL 与数据内容，但异构迁移场景下 DDL 目前仅限于表结构，索引等其他模式对象不受支持；Teradata 与 Redshift 为实验性支持。

  • 支持 Oracle、Postgres、MySQL、MariaDB、SQL Server、MongoDB、Snowflake、Vertica、DB2、CockroachDB、Yugabyte 等数据库间的导入、导出与复制
  • 提供 EXPORT/IMPORT、PUMP、COPY 三种操作模式
  • 可导出数据至 Amazon S3 与 Azure Blob Storage，格式包括 CSV、JSON 数组与 JSON

适用场景（解读层）

  • Oracle 与其他数据库之间的数据迁移（异构迁移仅限表结构）
  • 将源库数据以 CSV 形式暂存后由 Vertica、Snowflake 或 Redshift 直接加载
  • 将数据库数据导出为 CSV 或 JSON 文件存入 Amazon S3 或 Azure Blob Storage
