🧭 简介解读层（AI·证据行可回查）

解析伊利诺伊州年度学校报告卡数据并导入 PostgreSQL 的工具集

综述（解读层）

该工具集用于处理美国伊利诺伊州（ISBE）1997-2015 年的学校报告卡数据，通过 Makefile 编排下载、格式转换与入库流程，依赖 Python 3、csvkit、PostgreSQL 等。运行 make database 可将数据写入规范化表；完整处理仅覆盖 22 年数据中均存在的学校级指标。适合需要本地化分析该州历史教育数据的研究者与开发者。

  • 提供 make csv 流程，下载 1997-2015 年 ISBE 报告卡数据并将定宽文件转换为列名跨年规范化的 CSV
  • 提供 make database 流程，需先执行 createdb schools 初始化 PostgreSQL，随后将数据导入规范化数据表
  • 完整处理的数据涵盖 ACT 成绩、人口统计与入学、学科课时、各年级班级规模及家长参与、逃学、毕业率等学校级特征

适用场景（解读层）

  • 需要将伊利诺伊州多年份学校报告卡数据导入 PostgreSQL 进行 SQL 分析
  • 只需批量下载并转换为跨年列名统一的 CSV 文件供其他工具处理
  • 对 ACT 成绩、入学人口统计、班级规模等学校级历史指标开展研究或数据分析
