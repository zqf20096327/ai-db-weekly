开源自托管的无代码在线数据库平台，基于 Django/Vue/PostgreSQL。

综述（解读层）

Baserow 是一个开源无代码平台，用于搭建数据库、应用、自动化流程与仪表盘，并提供 AI 助手以自然语言创建数据库和工作流。面向需要自建数据工具与内部系统的团队，支持云端或自托管部署。采用 open-core 模式，非付费功能遵循 MIT 许可；技术栈为 Django、Vue.js 和 PostgreSQL，提供 REST API 与 OpenAPI schema。README 含有与 Airtable 对比的表述，属项目方自述。

  • 支持数据库、应用构建、自动化工作流、仪表盘与 AI 助手（Kuma）等模块
  • 支持 Docker、Helm、Docker Compose 及 Heroku、AWS、Railway 等多种部署方式
  • 非付费与非企业功能以 MIT 许可开源，提供 API 文档与 OpenAPI schema

适用场景（解读层）

  • 搭建在线协作数据库与内部工具
  • 自托管部署以满足数据自主控制需求
  • 创建自定义门户、仪表盘并绑定自有域名发布
