Claude Code SEO/GEO 诊断插件，含审批制 Next.js 自动修复

综述（解读层）

SeoMedic 是一个 Claude Code 插件，用于诊断网站在搜索引擎（SEO）与 AI 搜索（GEO）中的暴露状态，覆盖爬取、渲染、Core Web Vitals、结构化数据与 AI 爬虫策略，并可集成 GSC/GA4/PSI。对 Next.js 项目提供基于审批的自动修复（canonical、OG、noindex、robots、JSON-LD、标题、meta 描述），也可针对 GitHub 仓库生成 Pull Request 建议（实验性）。要求 Node.js 22+、Claude Code 与 git，修复需干净的 git 仓库状态。

  • 提供 /seo-audit（爬取+渲染诊断）、/seo-check（基线回归对比）、/seo-fix（自动修复）三类命令
  • 通过 Playwright 打开页面，对比原始 HTML 与渲染结果，诊断含 CWV、结构化数据与 AI 爬虫策略
  • 影响搜索展示的修改需用户批准，构建失败时自动回滚；GitHub 模式仅提交新分支 + PR，不做 force-push 或自动合并

适用场景（解读层）

  • 对有权限的网站 URL 运行 SEO/GEO 诊断并生成 Markdown 报告
  • 保存诊断基线后定期检测页面 SEO 状态的回归
  • 对本地 Next.js 项目或 GitHub 仓库执行审批制 SEO 修复并回写文件或提交 PR
