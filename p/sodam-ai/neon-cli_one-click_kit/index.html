Windows 批处理工具包，双击即可安装、登录、使用和卸载 Neon CLI（neonctl）

综述（解读层）

该工具包面向不熟悉终端的 Windows 用户，通过 시작하기.bat 等批处理脚本以菜单方式操作 Neon（无服务器 Postgres）的命令行工具 neonctl。若系统未装 Node.js，会自动改用独立可执行文件安装。登录走浏览器 OAuth，不将密码或密钥写入文件，卸载脚本仅删除本机工具，不触及云端数据。

  • 提供安装、登录、项目/数据库管理、AI 集成（MCP）等 17 个菜单功能，通过双击 .bat 文件运行
  • 自动检测 Node.js：存在则经 npm 安装 neonctl，否则下载独立可执行文件，并记录安装方式以便后续更新和卸载
  • 包含自诊断脚本，将检查结果保存为桌面文本文件；提供韩语和英语文档

适用场景（解读层）

  • 不熟悉终端操作的 Windows 用户需要通过图形化菜单使用 neonctl 管理 Neon 项目和数据库
  • 需要为 Claude Code 配置 Neon 的 MCP 集成
  • 需要一键卸载 neonctl 及相关登录配置信息
