为 go-pg 数据库客户端暴露连接池 Prometheus 指标的 Go 库

综述（解读层）

go-pg-monitor 是一个 Go 库，用于将 go-pg 数据库客户端的连接池统计信息以 Prometheus 指标形式暴露。适用于已在应用中使用 go-pg 并导出 Prometheus 指标的开发者。使用时需按 go-pg 版本引入对应子模块（如 gopgv10），并在应用入口创建 Monitor。由于 go-pg 处于维护模式，该库主要修复 bug 与安全问题，不新增功能。

  • 导出 go_pg_pool_* 系列 Gauge 指标，覆盖连接命中、未命中、超时、总/空闲/陈旧连接数
  • 按 go-pg 版本提供子模块（如 gopgv10）适配不同客户端版本
  • grafana/ 目录包含两个示例 Grafana 仪表盘，分别对应单数据库对象和多池场景

适用场景（解读层）

  • 使用 go-pg 的 Go 应用需要通过 Prometheus 监控连接池状态
  • 已搭建 Prometheus + Grafana 技术栈、希望复用参考仪表盘观察池命中与超时情况的团队
