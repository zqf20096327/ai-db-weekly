集成多数据库备份/恢复工具的容器镜像，提供统一 Shell 环境

综述（解读层）

该容器镜像将 PostgreSQL、MongoDB、MariaDB 的 dump/restore 工具及 AWS CLI、MinIO Client、kubectl 等打包在一起，解决本地需安装多个版本工具及依赖的问题。适合需要手动或脚本化管理数据库备份的运维人员，可通过 Docker 运行或部署在 Kubernetes、docker-compose 中，支持挂载凭据目录复用现有配置。

  • 包含 PostgreSQL Client Tools 10–17（pg_dump、pg_restore、pg_basebackup 等）、MongoDB tools 100.5.2 及 MariaDB Client Tools 10.8
  • 内置 AWS CLI、MinIO Client、kubectl、Redis cli、kcat 等配套工具，以及别名和辅助脚本
  • 预构建镜像发布于 ghcr.io，支持指定版本标签运行，也可自行构建

适用场景（解读层）

  • 在容器中手动执行数据库备份/恢复并将备份文件上传至 S3
  • 在 Kubernetes 或 docker-compose 环境中运行备份任务容器
  • 复用宿主机已有的 AWS/kube/azure 凭据配置执行备份操作
