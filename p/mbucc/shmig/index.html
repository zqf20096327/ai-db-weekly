🧭 简介解读层（AI·证据行可回查）

单文件 Bash 编写的数据库迁移工具，依赖各 RDBMS 自带的命令行客户端执行 SQL。

综述（解读层）

shmig 是由单个 Bash 脚本实现的数据库迁移工具，用于管理 PostgreSQL、MySQL、SQLite3 的 schema 版本变更。它不依赖驱动或连接器，直接调用 mysql/psql/sqlite3 客户端批量执行 SQL；迁移文件以 UNIX 时间戳命名，按时间顺序应用，文件内用 UP/DOWN 标记区分应用与回滚段落。配置可来自 shmig.conf、shmig.local.conf、环境变量或命令行。适合需要在 POSIX 环境中以最少依赖管理数据库变更的用户；README 提到每条语句会新启客户端进程，速度有限制。

  • 单文件 Bash 脚本实现，通过数据库自带的命令行客户端与数据库交互，无需额外驱动
  • 迁移文件以 UNIX 时间戳命名，按文件名时间顺序应用，支持 -- ==== UP ==== / -- ==== DOWN ==== 标记的应用与回滚段落
  • 支持配置文件（shmig.conf / shmig.local.conf）、环境变量和命令行三种配置方式，并可通过符号链接目录实现测试数据与生产迁移分离

适用场景（解读层）

  • 在仅有 POSIX shell 和数据库 CLI 客户端的环境中执行数据库迁移
  • 对 PostgreSQL、MySQL、SQLite3 项目统一管理 schema 变更及回滚
  • 在 Docker 或 docker-compose 环境中通过环境变量配置运行迁移（镜像 mkbucc/shmig）
