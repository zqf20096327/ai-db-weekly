sqlite-unity-plugin 的示例实现项目，演示在 Unity 中以 C# 使用 SQLite。

综述（解读层）

该项目是 sqlite-unity-plugin 的示例实现，通过 C# 脚本演示在 Unity 中使用 SQLite 数据库。仓库包含 DataBank 文件夹内的示例脚本及 DbTestBehaviourScript.cs 用法示例，可将后者挂载到空 GameObject 上运行测试。项目可在 Windows、Android 和 iOS 设备上测试，适合需要在 Unity 项目中了解该插件实际用法、希望获得参考代码的开发者。

  • 提供 sqlite-unity-plugin 的 C# 示例实现，DataBank 文件夹包含 SQLite 数据库使用示例脚本
  • DbTestBehaviourScript.cs 提供用法示例，可挂载到空 GameObject 上运行
  • 支持在 Windows、Android 和 iOS 设备上进行测试

适用场景（解读层）

  • 在 Unity 项目中学习 sqlite-unity-plugin 的实际用法
  • 在 Windows、Android、iOS 多平台上测试 SQLite 数据库功能
  • 作为编写 Unity SQLite 相关代码的参考示例
