挂载于开发环境的 Rails 引擎，通过 Web UI 生成数据库迁移文件

综述（解读层）

Localtower 是一个可挂载的 Rails Engine，在开发环境中提供 Web 界面用于创建模型和生成迁移文件，产物为 db/migrate 目录下的原生 Rails 迁移文件，可通过命令行编辑后再执行迁移。它不锁定用户，卸载只需移除 gem 和路由。它未实现全部 Rails Migrations API，需 Rails >= 5.2、Ruby >= 2.3。

  • 提供用于创建模型和迁移的 Web UI，生成的迁移文件与 rails generate 命令产物一致
  • 以可挂载 Engine 形式集成，从 config/routes.rb 挂载即可使用，可随时安装或卸载
  • 不限制命令行方式生成迁移，生成的文件可手动编辑后再执行 rails db:migrate

适用场景（解读层）

  • Rails 开发者希望通过界面操作生成模型与迁移文件
  • 减少手写迁移命令时的拼写错误
  • 对迁移有特殊需求时，先用 UI 生成再用手工编辑补充
