通过 DLL 桥接在 Excel VBA 中内嵌运行 DuckDB 的分析库

综述（解读层）

该项目通过一个 C 语言桥接 DLL 调用 DuckDB C API，使 VBA 可在进程内执行 SQL，无需 ODBC 或外部服务器。提供 Range/数组与 DuckDB 间的数据写入、查询返回二维数组或字典、upsert 同步，以及 CSV/JSON/Parquet 的 SQL 读写。支持 :memory: 内存库与 .duckdb 文件两种模式。仅限 Windows 64 位 Excel，需 VC++ 2015-2022 运行库。

  • 提供 cDuck 封装类：Exec/QueryFast/Scalar、FrameFromValue、AppendArray、UpsertFromArray、CreateTempList、SelectToDict* 等 VBA API
  • 支持 CSV/JSON/Parquet 的读取、建表与 COPY 导出，以及 parquet/json/rapidfuzz/miniplot/nanodbc/ui 等 DuckDB 扩展加载
  • 提供 Access 迁移路径：AppendAdoRecordsetFast 导入 .mdb/.accdb，或经 nanodbc 扩展执行 ODBC 查询

适用场景（解读层）

  • 在 Excel 工作簿内对 Range 数据执行 SQL JOIN/GROUP BY/WINDOW 等分析并回写结果
  • 读取、转换并导出本地 Parquet/CSV/JSON 文件
  • 将 Access (.mdb/.accdb) 数据导入 DuckDB 做本地持久化分析
📖 README 首段存档原文 · 程序抽取

No ODBC setup. No external server. No complex deployment. Just DuckDB running directly inside Excel/VBA, turning your workbook into a fast local analytics front-end.
