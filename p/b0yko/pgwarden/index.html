🧭 简介解读层（AI·证据行可回查）

面向 AI 助手的 Postgres MCP 网关，以数据库权限实施只读与治理

综述（解读层）

pgwarden 是一个 MCP 网关，让 Claude、ChatGPT、Cursor 等 MCP 客户端查询 Postgres。用户经 OIDC 登录后，网关以其个人 Postgres 角色连接，由数据库的授权、行级安全和脱敏视图决定可见数据；读操作用只读事务实现，写操作需指定审批人批准，工具调用、审批和管理变更记录在哈希链式的追加型审计日志中。附红队测试套件与 Cloud Run 的 Terraform。适用于需要为 AI 助手提供按身份隔离数据库访问的团队。

  • 支持 OAuth 2.1/OIDC 登录，每个用户映射到独立 Postgres 角色，读权限由 grants、RLS 和脱敏视图在数据库层强制
  • 读路径不解析 SQL：只读事务、扩展协议单语句、行数与字节上限、固定 ROLLBACK 序列
  • 写操作经 EXPLAIN 检查并由指定审批人签核后执行一次；含 133 项红队用例和 hash-chained 审计日志

适用场景（解读层）

  • 让 AI 助手以用户身份安全查询生产 Postgres，按角色限制可见行并掩蔽 PII
  • 需要对助手发起的写操作做人工审批并留存防篡改审计记录
  • 在 Cloud Run 上部署带登录与审计的 MCP 数据库访问入口
