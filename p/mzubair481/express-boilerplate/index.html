基于 Express 5 与 TypeScript 的 PostgreSQL API 项目模板，含 Drizzle ORM 与认证体系

综述（解读层）

该仓库是一个面向生产环境的 API 脚手架，提供用户注册、登录、邮箱验证、密码重置及用户管理等完整认证接口，供开发者快速搭建 Node.js 后端服务。项目采用模块化单体结构与手动构造注入，认证使用短时效 JWT 与 SHA-256 哈希存储的轮换刷新令牌；数据库为 PostgreSQL 18，迁移依赖 Drizzle Kit，应用启动时不自动执行迁移。运行要求 Node.js 24、pnpm 11 与 Docker。

  • 内置注册、邮箱验证、登录、密码重置、用户与角色/状态管理的完整路由，OpenAPI 3.1 文档配 Scalar 交互式参考页面
  • 认证机制包含短时效 JWT 访问令牌、仅存 SHA-256 哈希的轮换刷新令牌（带家族级重用检测）、Argon2id 密码哈希与 HttpOnly 刷新 Cookie
  • 集成 Prometheus 指标、Grafana 仪表盘配置、Pino 结构化日志（含敏感信息脱敏）、Vitest/Supertest 测试及 Docker Compose 部署编排

适用场景（解读层）

  • 启动新的 TypeScript/PostgreSQL 后端 API 项目，复用已有的认证、迁移与监控配置
  • 需要 JWT 访问令牌加轮换刷新令牌认证体系，并要求密码重置、邮箱验证流程带重试队列与频率限制的服务
  • 需要 Prometheus 指标暴露、存活/就绪探针与 Grafana 告警配置的容器化 API 部署
