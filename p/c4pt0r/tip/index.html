TiDB 数据库的命令行交互工具，支持 SQL 执行、多格式输出与 Lua 脚本扩展

综述（解读层）

tip 是一个用于在 shell 工作流中与 TiDB 数据库（尤其针对 TiDB Serverless）交互的命令行工具，提供连接服务器、执行 SQL 查询并以 table、json、plain 等格式查看结果的能力。它面向需要在终端中操作 TiDB 的用户，支持命令行参数、config.toml 配置文件、环境变量和 .env 文件四种配置方式，并提供交互式 REPL，内置 .lua-eval 命令可执行 Lua 脚本（含 sql.query/sql.execute 与 http.fetch 函数），便于与 jq、parallel 等 shell 工具组合使用。

  • 支持以 plain、table（默认）、json 三种格式输出查询结果，可与 jq 等 shell 工具配合使用
  • 提供交互式 REPL，包含 .connect、.output_format、.lua-eval、.lua-eval-file 等点命令
  • Lua 集成提供 sql.query、sql.execute、http.fetch 函数，脚本可从文件或 URL 加载

适用场景（解读层）

  • 在 shell 脚本或管道工作流中执行 SQL 并以 JSON 格式输出结果，供 jq、parallel 等工具处理
  • 需要与 TiDB Serverless 或自建 TiDB 建立交互式 REPL 会话并执行查询的场景
  • 通过 Lua 脚本组合 SQL 查询与 HTTP 请求的处理流程
