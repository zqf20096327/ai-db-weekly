🧭 简介解读层（AI·证据行可回查）

开源本体平台，从领域 schema 编译出带治理的 GraphQL/REST API、授权与审计。

综述（解读层）

Open Foundry 是 Apache 2.0 协议的开源本体平台，用于构建运营数字孪生。用户以 GraphQL SDL 风格的 ODL schema 声明对象、动作与权限，平台据此生成 GraphQL/REST API、OpenFGA 授权模型、动作流水线、版本历史与审计记录。运行依赖 Docker Compose 与 PostgreSQL + Apache AGE，代码栈为 TypeScript。默认开发模式关闭治理强制，生产启动需完整配置否则退出。项目处于 pre-1.0 阶段，未经独立安全审计。

  • 无通用 CRUD 写入路径，所有变更经动作流水线：校验、授权、同意、前置条件、事务执行、补偿、审计、事件
  • 基于关系的授权（OpenFGA）与按角色字段策略驱动的字段级脱敏，随 schema 生成
  • 存储经 SPI 抽象：PostgreSQL + Apache AGE 与内存实现通过同一一致性测试；提供 JDBC 连接器与 Debezium CDC 接入既有系统

适用场景（解读层）

  • 以领域包（AML、供应链、NHS 急诊等内置示例）建模行业对象与业务动作，构建带版本历史与审计的操作型系统
  • 需基于 schema 生成的 GraphQL/REST API 及关系型授权、字段脱敏的治理型数据平台评估与受控试点
  • 通过 FHIR R4（capability-gated）与 CDM 投影对接医疗类既有系统的集成原型
