开源云平台，在裸金属服务器上提供虚拟机、托管 Postgres 等云服务

综述（解读层）

Ubicloud 是一个可在任意位置运行的开源 IaaS 云，支持在 Hetzner、Leaseweb、AWS 裸金属上部署虚拟机、托管 PostgreSQL、Kubernetes、GitHub Actions runner 和 AI 推理等服务。其控制平面为 Ruby 编写的 Postgres 应用，通过 SSH 与数据平面通信；既可用官方托管服务，也可克隆仓库自建云。

  • 提供虚拟机（Cloud Hypervisor）、私有子网、防火墙、负载均衡器与非复制加密块存储 ubiblk
  • 托管 PostgreSQL 支持高可用、读副本、时间点恢复、主版本升级、PgBouncer 及指标日志导出，可运行在裸金属、AWS 和 GCP
  • 支持通过云控制台、REST API（OpenAPI 规范）、ubi CLI 和 Terraform 管理资源

适用场景（解读层）

  • 为 GitHub Actions 工作流提供 x64/arm64 托管 runner，切换只需修改 runs-on 字段
  • 在裸金属或指定云上部署带高可用与备份的托管 Postgres 数据库
  • 将自有裸金属机器通过控制平面脚本 cloudify，搭建自用云环境
