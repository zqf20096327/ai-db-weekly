LIFE 是面向 AI agent 的持久化身份架构，含 16 个 MCP 服务器模块

综述（解读层）

LIFE 是一个基于 MCP 协议的 AI agent 持久化状态系统，由 drives、heart、semantic 记忆、patterns、journal 等 16 个模块组成，各模块作为独立 MCP 服务器运行。适用于配合支持 MCP 的 AI 客户端使用。需 Python 3.8+，通过 setup.py 初始化，并需保持 5050 端口的 embedding 服务运行以支持语义搜索；无该服务时退化为关键词匹配。

  • 提供 16 个 MCP 服务器模块，覆盖记忆存储、情绪记录、模式提炼、日志、文件访问与语音交互等功能
  • 内置 embedding 服务（all-MiniLM-L6-v2，端口 5050）支持基于语义的长期记忆检索，缺失时回退为关键词匹配
  • 提供 Genesis 三步初始化流程：回答 80 个场景问题后映射为 46 项特征并生成自我文档

适用场景（解读层）

  • 为运行于 MCP 兼容客户端（如 Claude）的 AI agent 提供跨会话的记忆与状态持久化
  • 需要为 agent 记录会话日志、关系情感与经验教训并进行语义检索的场景
  • 需为 agent 配置图像识别（摄像头/截图）、语音合成与收听（需 OpenAI API key）等多模态能力
