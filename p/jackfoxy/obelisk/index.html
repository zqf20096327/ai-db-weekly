面向 Urbit 计算机的时序索引关系数据库引擎及 urQL 脚本语言

综述（解读层）

Obelisk 是运行于 Urbit 之上的关系数据库引擎，使用 SQL 方言 urQL 编写脚本。数据库状态按时间索引，查询隐式幂等，不使用 NULL，脚本以原子方式执行（整体通过或失败）。通过 %obelisk desk 以 %tape 等动作提交 urQL，或复制 sur/obelisk-ast.hoon 使用其 API。当前为 beta 版，安装会覆盖旧 alpha 版状态。

  • 数据库状态按时间索引，查询隐式幂等
  • 表、视图与查询结果均为规范行集合，全程不使用 NULL
  • 内置 Sail 原生 Web 工作台，支持运行、解析、模式浏览、多标签编辑与分隔符导出

适用场景（解读层）

  • 在 Urbit ship 上运行关系数据库并通过 /apps/obelisk 界面或 dojo 执行 urQL 脚本
  • 通过 %tape/%tape-print 动作或 obelisk-ast.hoon API 以编程方式提交查询与命令
  • 使用自带的 animal-shelter 示例数据库学习或复现问题提交 bug 报告
