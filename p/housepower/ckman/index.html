CKMAN：Web 控制台，用于管理与监控 ClickHouse 集群

综述（解读层）

CKMAN 是一个通过 Web UI 与 API 管理 ClickHouse 集群的工具，提供部署、升级、节点增删、监控、表管理、备份恢复等功能，监控直接查询 ClickHouse 系统表，也可选集成 Prometheus/Grafana。适用于需要集中管理多个 ClickHouse 集群的运维团队，支持 rpm/deb/tar.gz/Docker/Kubernetes 多种分发方式，默认端口 8808。

  • 支持集群部署、滚动升级、销毁、启停及节点增删，可通过 Web UI 或 API 操作
  • 内置监控直接读取 ClickHouse 系统表，并可选集成 Prometheus/Grafana
  • 提供定时备份与恢复策略，支持本地与 S3 目标，RBAC 含三种角色及 JWT 认证

适用场景（解读层）

  • 通过单一代码界面管理多个 ClickHouse 集群的部署与升级
  • 配置 ClickHouse 集群的定时备份与增量去重恢复
  • 需要 RBAC 权限控制与多实例高可用部署的运维场景
