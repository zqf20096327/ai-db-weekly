🧭 简介解读层（AI·证据行可回查）

为 pgx v5 提供的 OpenTelemetry 追踪插桩库，将数据库操作记录为 span

综述（解读层）

pgxotel 是一个 Go 库，用于为 pgx v5 驱动生成 OpenTelemetry 追踪数据。将 QueryTracer 挂载到 pgx.ConnConfig 或 pgxpool.Config 后，查询、批量发送、prepared statements、COPY 和连接操作会被记录为 span。默认不记录 SQL 文本，可通过 IncludeStatement 开启；span 名称取首个 SQL 关键字或 -- name: 注释。通过 go get 安装，适用于已使用 pgx v5 并接入 OpenTelemetry 的服务。

  • 实现 pgx 全部五个 tracer 接口：QueryTracer、BatchTracer、ConnectTracer、PrepareTracer、CopyFromTracer
  • 遵循 OpenTelemetry 稳定语义约定 semconv/v1.40.0，包含 db.namespace、db.operation.name、db.query.text 等属性
  • 支持低基数 span 命名，可通过 -- name: 注释显式指定，SQL 文本默认不记录（需 IncludeStatement 开启）

适用场景（解读层）

  • 为使用 pgx v5/pgxpool 的 Go 服务接入 OpenTelemetry 追踪
  • 需要区分数据库 span 来源的多服务场景（可配置 Name 与 TracerProvider）
  • SQL 文本含敏感信息、需默认关闭语句记录的系统
