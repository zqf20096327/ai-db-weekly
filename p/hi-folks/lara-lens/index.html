Laravel artisan 命令行诊断工具，汇总应用配置、数据库与运行环境信息

综述（解读层）

LaraLens 是一个 Laravel 包，通过 artisan 命令 laralens:diagnostic 在终端显示应用配置变量、数据库连接、数据表、HTTP 连接及 PHP 版本与扩展等服务器要求。适合部署后检查环境或接手他人配置的场景，支持 --show 选择输出类别、跳过数据库检查，也可通过配置在浏览器查看，README 建议生产环境关闭 Web 视图。

  • 通过单条 artisan 命令输出配置、数据库连接、数据表、HTTP 连接与 PHP 运行环境信息
  • 支持 --show 选项选择输出类别（config/connection/database/runtime/migration/php-ext/php-ini/os/all），并可指定表和排序列查看数据
  • 可选启用浏览器 Web 报告，可配置 URL 前缀与中间件；输出表格样式与宽度可通过 --style 和 --large 调整

适用场景（解读层）

  • Laravel 应用部署到目标服务器后检查配置、数据库连接与服务器要求
  • 应用部署在本地环境且由他人负责配置时，快速查看当前应用配置
  • 查看指定表的数据状态（如按 created_at/updated_at 排序取最新记录）
