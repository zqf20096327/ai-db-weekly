Go 代码生成器，为 PostgreSQL 低抽象持久化生成结构体与函数

综述（解读层）

construct 是一个 Go 代码生成器，面向使用 PostgreSQL 的开发者：通过读取模型结构体标签（struct tags），经 go:generate 生成 JSON 查询表达式、变更集结构体、表/字段 schema 变量及可排序字段映射。写入不依赖模型本身，适合 CQRS 架构；数据库迁移不在其范围内，需配合 goose 等工具，查询构建依赖 networkteam/qrb。

  • 为模型生成默认 JsonBuildObject 表达式，可通过 JSON 选择嵌套关联数据实现预加载
  • 生成类型安全的 changeset 结构体，用于部分数据的插入与更新
  • 生成表与字段的 schema 变量及可排序字段映射，配合 qrb 查询构建器使用

适用场景（解读层）

  • 以 CQRS 方式组织命令与查询分离的 PostgreSQL 持久化层
  • 希望绕过 ORM 抽象、手写仓储代码但减少样板代码的项目
  • 需要通过 JSON 查询灵活加载嵌套关联数据的读取场景
