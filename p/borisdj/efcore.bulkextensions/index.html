为 EF Core 提供批量 CRUD 操作的扩展库

综述（解读层）

EFCore.BulkExtensions 是 EF Core 扩展库，提供 BulkInsert、BulkUpdate、BulkDelete、BulkRead、BulkSaveChanges 等方法，支持 SQL Server、PostgreSQL、MySQL、SQLite、Oracle 等数据库，各库分别使用 SqlBulkCopy、COPY BINARY、MySqlBulkCopy 等底层机制实现。方法作用于 DbContext 并接受实体列表与可选 BulkConfig 参数。README 提示小数据集有临时表创建开销，建议数据量大于 1000 时使用；Sync 操作不支持 SQLite 与 PostgreSQL。通过 NuGet 安装，需按 .NET 版本选择对应包版本。

  • 提供 BulkInsert、BulkInsertOrUpdate、BulkInsertOrUpdateOrDelete、BulkDelete、BulkRead、BulkSaveChanges 等批量方法，含同步与异步版本
  • 支持 SQL Server、PostgreSQL、MySQL、SQLite、Oracle、GBase，按数据库分别使用 SqlBulkCopy、COPY BINARY、MySqlBulkCopy 等底层实现
  • 提供 BulkConfig 配置项，可用 PropertiesToInclude/PropertiesToExclude 控制更新列，支持显式事务与 SetSynchronizeFilter 部分同步

适用场景（解读层）

  • 需要向数据库批量写入、更新或删除大量实体列表的应用
  • 需要根据大列表进行查询（替代 SQL IN 或内存 JOIN）的读取场景
  • 需要在一次连接中按主键匹配执行插入或更新（Upsert）及表数据同步的场景
