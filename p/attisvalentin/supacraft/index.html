综述（解读层）

SupaCraft 是一个 Go 编写的开源后端：数据库、认证、自定义端点、定时任务等全部在 supacraft.json 中声明式定义，由单个二进制读取并基于 SQLite 运行。它内置 MCP 服务器，Claude Code、Cursor 等 AI 代理可通过 MCP 生成并修改配置，每次改动先经校验再保存。迁移仅做增量新增，不删除或重命名既有数据。适合 MVP、原型、内部工具等场景。

  • 提供 JWT 认证、Google/GitHub/OpenID Connect 登录、角色权限与行级策略，以及文件上传（本地磁盘、S3、GCS、Azure、FTP 等）、邮件、Webhook、后台任务与 WebSocket 实时订阅
  • 内置 MCP 服务器，AI 代理可构建、测试和部署项目；配置在保存前经过校验，含列类型、引用存在性、步骤字段、cron 表达式等检查
  • 生成 OpenAPI 3.1 文档，附种子数据与请求级测试（测试运行于全新数据库），单个 serve 进程可通过 X-Tenant-ID 托管多个项目

适用场景（解读层）

  • 通过自然语言描述让 AI 代理生成 REST API 的 MVP 与原型开发
  • 需要 SQLite 存储、认证、文件上传、定时任务的小型内部工具
  • 在一台服务器上集中托管多个小型后端项目（多租户部署）
