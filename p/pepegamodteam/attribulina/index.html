面向 Black Box 极品飞车游戏 AttribSys 数据库的编辑与模组脚本工具

综述（解读层）

Attribulina 是一款针对 EA AttribSys 数据库的图形化编辑工具，覆盖多款 Black Box 开发的极品飞车游戏及多个平台，支持类与 Vault 编辑、State Graph Builder 的 Lua 反编译/编译、nfsms 与自定义 .amod 脚本执行，并附带 Mod 安装器和命令行工具 attribcli。README 未说明安装依赖与许可证信息，Nitro 平台为部分支持。

  • 支持 Most Wanted 到 World 等多款游戏的 PC/PS2/Xbox 360/PS3 等多平台数据库读写
  • 提供类编辑（含自动 C++ 头文件生成）、Vault 增删重命名及 State Graph Builder 的 Lua 反编译与编译
  • 附带 Mod 安装器与 attribcli 命令行工具，支持脚本应用、diff 生成与数据导出

适用场景（解读层）

  • 查看和编辑 Black Box 极品飞车游戏的 AttribSys 数据库内容
  • 为这些游戏制作、安装和卸载 nfsms/amod 模组脚本
  • 通过命令行或批处理批量应用模组脚本及导出数据库条目
