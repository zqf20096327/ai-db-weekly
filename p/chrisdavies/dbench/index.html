SQLite 与文件系统（btrfs/EXT4）写入性能的非正式基准测试

综述（解读层）

该仓库包含作者在 2020 款 Dell XPS SSD 上对比 SQLite 与文件系统（btrfs、EXT4）写入性能的测试脚本与结果，覆盖顺序写入、100 并发写入及含增删改的任务模拟场景。测试使用 mattn/go-sqlite3，配置为 WAL 日志、timeout 5000、_sync=1。作者结论是在预热后更接近真实场景的任务模拟中 SQLite 约为文件系统的两倍速度；附注提及同机 Postgres 性能与 SQLite 最差表现相近。

  • 提供线性写入、并发写入（100 写入者各写 1K 条）和多步任务模拟三类基准场景的耗时数据
  • 使用 mattn/go-sqlite3 驱动，SQLite 配置为 WAL 日志模式（_timeout=5000&_journal=WAL&_sync=1）
  • 补充 EXT4 文件系统上的对比数据，并附有与同机部署 Postgres 的测试记录

适用场景（解读层）

  • 为在 SQLite 与基于文件的方案之间做技术选型时提供参考数据
  • 了解 WAL 模式下 SQLite 与文件系统在写入吞吐上的实测差异
  • 研究文件写入方式（直接覆写与 tmp 文件+rename）对性能的影响
