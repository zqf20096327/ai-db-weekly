面向 SQLite 的轻量级 CDC 模式教学代码集

综述（解读层）

sqlite-delta 收录两种经测试的 SQLite 变更数据捕获模式：trigger-lite（基于 rowid 追踪上次 diff 后变更行）和 three-phase（三缓冲行以支持增量压缩）。仓库定位为教育用途，提供带完整测试的示例实现，供使用者理解后按自身表结构重写，而非直接用于生产。运行需通过 uv sync 安装依赖。

  • 提供 trigger-lite 与 three-phase 两种 CDC 模式的带测试示例实现
  • trigger-lite 模式要求所有表具备 rowid；three-phase 模式通过表内三缓冲实现最小额外数据移动的 delta 压缩
  • 使用 uv sync 命令安装全部依赖以运行脚本与测试

适用场景（解读层）

  • 学习并理解 SQLite 变更数据捕获（CDC）的实现模式
  • 在自建代码库中参考重写适用于自身表结构与需求的 CDC 逻辑
  • 对数据库快照（Changeset/Checkpoint）间的增量差异编码做概念研究
