综述（解读层）

Graft 是一个开源事务存储引擎，用于边缘环境的数据同步，提供惰性、部分复制与 Serializable Snapshot Isolation 强一致性，可将对象存储转化为页粒度的可事务更新系统。使用方式包括 SQLite 扩展和 Rust crate；README 标明当前为 Alpha 质量，生产使用前需联系作者。

  • 支持惰性、部分复制，客户端按需同步所需数据
  • 提供 Serializable Snapshot Isolation 事务语义，以页粒度更新数据子集，不限定数据格式或 schema
  • 元数据与数据解耦，副本可立即启动，无需回放或完整恢复

适用场景（解读层）

  • 离线优先及移动应用的数据同步
  • serverless 或嵌入式环境中的无状态副本
  • 为数据库提供存储与复制能力
