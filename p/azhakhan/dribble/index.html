基于 Web 的开源 SQL IDE，内置 AI 数据分析代理

综述（解读层）

Dribble 是一个 Web 版 SQL IDE，面向需要查询和分析 Postgres 数据库的开发者与数据人员。提供 SQL 笔记本（Monaco 编辑器）、模式树浏览、带分页/排序/过滤的表格查看器，以及通过 Anthropic API 运行的 AI 代理：代理检查模式、编写并执行只读 SQL、将结果渲染为表格。目前仅内置 Postgres 驱动，驱动注册表设计用于扩展 MySQL、Snowflake 等引擎；需要 Node.js 20+、一个存储元数据的 Postgres 和 Anthropic API key，MIT 协议发布。

  • 内置 AI 数据分析代理，检查模式、编写并执行只读 SQL、迭代处理错误并将结果渲染为表格
  • 提供 SQL 笔记本、模式浏览器和带服务端分页、列排序、WHERE 过滤的表格查看器
  • 支持本地免登录运行或配置 Google OAuth 多用户模式，凭据静态加密存储，状态保存在服务端

适用场景（解读层）

  • 连接 Postgres 数据库进行查询编写、模式浏览和数据表探索
  • 通过对话式 AI 代理提问并获取只读查询分析结果
  • 团队部署时用 Google 登录隔离各用户的连接、笔记本和聊天记录
