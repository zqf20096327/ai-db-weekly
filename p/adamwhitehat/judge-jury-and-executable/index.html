综述（解读层）

Judge Jury and Executable 是一个用 C# 编写的文件系统取证扫描与威胁猎杀工具，面向安全分析人员。它读取 NTFS 主文件表（MFT）记录，绕过文件权限、锁与隐藏机制，为每个文件采集最多51项属性（哈希、签名、YARA匹配、熵等），写入 SQL、SQLite 或 CSV；用户通过 SQL 查询进行威胁排查与回溯分析。需要 .NET Framework 4.8 与可读写的 SQL 数据库。

  • 扫描 MFT 记录并采集每个文件最多 51 项属性，包括 SHA256/MD5、Authenticode 签名验证、YARA 规则匹配和文件熵
  • 扫描结果存入 SQL/SQLite/CSV，可跨多次扫描与多台机器进行 SQL 聚合查询与历史回溯分析
  • OS API 不可访问的文件仍会在 MFT 层被记录，仅缺失不可获取的属性

适用场景（解读层）

  • 对磁盘或磁盘镜像进行恶意软件/APT 取证排查
  • 事故发生前采集系统基线，用于事后对比与回溯分析
  • 跨多台工作站的集中式文件属性数据采集与 SQL 查询审计
