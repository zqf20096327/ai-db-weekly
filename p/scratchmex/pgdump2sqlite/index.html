解析 pg_dump 文件并直接生成 SQLite 数据库的 Rust 命令行工具

综述（解读层）

pgdump2sqlite 是一个 Rust 编写的命令行工具，读取 PostgreSQL 的 pg_dump 导出文件（tar 或 sql 格式）并生成 SQLite 数据库。它以原样使用 dump 文件为目标，无需剥离语句中的模式前缀。实现上使用 pest 解析器提取语句，建表后按表逐表用事务加预处理语句插入数据。README 的 TODO 显示它尚不支持 insert into 语句、directory/custom 等导出格式，布尔值映射也未完成。

  • 支持读取 tar 和 sql 两种 pg_dump 格式，无需修改原始 dump 内容
  • 使用 pest 解析器提取语句，按表逐表以事务和预处理语句写入数据
  • 以 crates.io 发布，可通过命令行指定输入 dump 文件和输出 sqlite 文件运行

适用场景（解读层）

  • 需要将 pg_dump 导出的 tar 或 sql 文件转换为本地 SQLite 数据库文件
  • 处理包含模式前缀（如 public.table_name）的 dump 语句而不想手动清洗
  • 需要离线单命令方式从 PostgreSQL 备份生成 SQLite 数据的场景
