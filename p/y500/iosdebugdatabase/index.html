🧭 简介解读层（AI·证据行可回查）

iOS 应用数据库调试库，启动本地 Web 服务在浏览器查看编辑 SQLite 数据

综述（解读层）

YYDebugDatabase 是用于调试 iOS 应用中数据库的库，基于 FMDB 与 GCDWebServer 实现，在应用内启动 HTTP 服务器，开发者可在浏览器中查看、搜索、排序数据库内容，执行 SQL 查询，编辑、新增、删除数据行并下载数据库文件。适用于 iOS 开发者调试阶段排查数据，需 iPhone 与电脑处于同一网络，默认仅显示 Documents 与 Library/Cache 目录下的数据库。

  • 支持在浏览器中查看、搜索、排序数据库数据，可执行 SQL 查询并编辑、新增、删除数据行
  • 基于 GCDWebServer 启动本地 HTTP 服务，控制台打印地址与 Bonjour 名称，兼容 Firefox、Safari、Chrome
  • 支持 CocoaPods 与 Carthage 集成，可通过 configurations 限定仅在 Debug 构建中运行

适用场景（解读层）

  • iOS 开发调试阶段在浏览器中查看和修改应用 SQLite 数据库
  • 调试真机与模拟器上应用的数据库内容（模拟器可用 127.0.0.1:9002 访问）
  • 需要指定目录（如自定义数据库目录）时通过 startServerOnPort:directories: 扩展可见范围
