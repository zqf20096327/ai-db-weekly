综述（解读层）

StackRender 是一款数据库模式图设计与生成工具，提供拖拽式图表界面，可自定义表、列、类型与约束，导入/导出 SQL DDL，并检测外键循环依赖。支持 PostgreSQL、MySQL、MariaDB、SQLite、Oracle、SQL Server 六种数据库。当前处于 Public Beta，AGPLv3 许可，可通过 Docker 或 Node.js 本地部署，另有含 AI 助手的云版本。

  • 交互式图表界面，拖拽设计表、列、类型与约束
  • 支持导入/导出 SQL DDL，覆盖 MySQL、PostgreSQL、MariaDB、SQLite、Oracle、SQL Server 六种方言
  • 提供外键循环依赖检测；云版本含 AI 助手，可从规范生成图表并做模式增强等操作

适用场景（解读层）

  • 为新项目从规范出发可视化设计数据库模式并生成 DDL 脚本
  • 导入既有数据库的模式进行查看、编辑与调整
  • 团队讨论表结构与外键关系时生成模式图与文档（云版 AI 自动文档生成）
