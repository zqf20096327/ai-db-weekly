Rust 编写的多线程内存数据库，兼容 Redis 协议并内置全文与向量搜索。

综述（解读层）

KiviDB 是用 Rust 编写的多线程内存键值数据库，实现 RESP2/RESP3 协议，现有 Redis 客户端可直接连接，内置全文、标签、数值与向量搜索及 JSON、时间序列命令，支持快照与 AOF 持久化、主从复制、集群和 Kubernetes operator。默认监听 6380 端口并开启保护模式；许可证为 AGPL-3.0，TLS 与 Lua 仅包含在特定构建变体中。

  • 实现 RESP2/RESP3 协议，兼容 Redis 8.10 的字符串、列表、哈希、集合、有序集合、流、位图、HyperLogLog、geo、pub/sub 与事务命令
  • 内置 Redis Stack 风格的 FT.* 全文/标签/数值/向量（FLAT、HNSW）搜索命令，以及 JSON.* 和 TS.* 命令
  • 支持快照与可选追加文件持久化、--replicaof 复制、含故障检测与故障转移的集群模式、ACL 与 TLS

适用场景（解读层）

  • 复用现有 Redis 客户端和 redis-cli 的内存缓存与键值存储场景
  • 需要全文检索或向量搜索的 AI 与实时应用
  • 通过 Helm/Artifact Hub 的 Docker 镜像或 KiviDB operator 在 Kubernetes 上部署
