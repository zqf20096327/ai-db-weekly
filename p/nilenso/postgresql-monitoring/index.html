一组以 PREPARE 语句封装的 PostgreSQL 监控查询集合

综述（解读层）

该项目包含一组可直接在 psql 中执行的 SQL 监控查询，源自 PostgreSQL wiki 和 check_postgres 等多个来源。查询以 PREPARE 命名语句形式封装，通过 EXECUTE 调用，覆盖查询统计、缓存命中、表/库大小、表膨胀、索引使用、autovacuum 与复制状态等维度，部分查询区分 pg9.x 与 pg10 版本。适用于需要定期采集数据库指标的运维与 DBA 人员；query_stats 需预先配置 pg_stat_statements。

  • 全部查询以 PREPARE 命名语句封装，EXECUTE 即可运行，支持定期轮询采集
  • 覆盖查询状态、长事务、缓存命中率、磁盘占用、表/索引膨胀、索引使用、autovacuum 与复制延迟
  • README 说明查询开销较低，可在高负载下每隔数秒运行；部分查询提供 pg9.x 与 pg10 两个版本

适用场景（解读层）

  • 定期执行查询并将结果发送到现有监控系统
  • 排查长时间运行、占用 CPU 或网络的查询
  • 检查表与索引膨胀、缓存命中率及复制延迟
