🧭 简介解读层（AI·证据行可回查）

PostgreSQL 膨胀索引自动重建工具，通过尺寸/元组比率估算膨胀并调用并发重建。

综述（解读层）

pg_index_watch 是一个以 SQL 形式安装的 PostgreSQL 工具，用于监控索引膨胀并在超过阈值（默认 2 倍膨胀、索引 ≥10MB）时执行 REINDEX INDEX CONCURRENTLY。它安装到控制数据库，经 dblink 管理本机其他库，不依赖 pgstattuple，靠尺寸与 reltuples 比率估算膨胀，并用 ANALYZE 确认避免误判。要求 PostgreSQL 12+ 与超级用户免密连接各库，重建时会产生约 2 倍索引的临时磁盘占用与较多 WAL。

  • 使用 pg_relation_size 与 pg_class.reltuples 的比率估算索引膨胀，无需 pgstattuple 扩展
  • 通过 dblink 连接本机其他数据库远程执行 REINDEX INDEX CONCURRENTLY，控制数据库默认被跳过
  • 提供 periodic 的 dry-run/force 模式、按库/模式/表/索引的定向重建，以及 reindex_history 历史与 reindex_work 工作集视图

适用场景（解读层）

  • 频繁更新的表上索引持续膨胀，需要周期性（cron）自动重建
  • 大规模集群初次运行前，先用 do_force_populate_index_stats 记录基线而不触发批量重建
  • 对特定数据库、模式、表或索引执行带确认的定向膨胀重建
