VS Code 扩展，通过点击方式查看 Microsoft SQL Server 数据库数据

综述（解读层）

SQL Data Inspector 是一个 VS Code 扩展，用于查看 MSSQL 数据库中的数据。它列出库中的表与视图、显示列信息、展示选中列的去重值与计数，并支持编辑 WHERE 子句过滤数据和定时刷新的实时监控模式。连接与查询执行依赖 SQL Server (mssql) 扩展，扩展本身不存储凭据。适用于需要在 VS Code 中浏览 SQL Server 数据的用户。仅支持 MSSQL；Azure Data Studio 最高可用 0.8.2 版本。

  • 从 SQL Server Object Explorer 右键菜单或查询编辑器选中的表名启动数据检查
  • 显示表/视图列表、列信息、行数据，以及选中列的去重值和计数，并支持双击值自动添加过滤条件
  • 通过 mssql 扩展的连接共享 API 管理连接，扩展自身不存储数据库凭据

适用场景（解读层）

  • 在 VS Code 中浏览 SQL Server 数据库的表结构与行数据
  • 查看某列的去重值和计数，并复制到 Excel 等工具进一步处理
  • 通过实时监控模式按设定间隔定时刷新视图数据
