以 SQLite 为后端的 Pervasive Btrieve v5/v6 替代 DLL

综述（解读层）

该项目实现与原版 WBTRV32.DLL 相同接口的开源替代库，将 Btrieve 5/6 版 .DAT 文件的数据转换为 SQLite 数据库供应用读写。它面向依赖旧版 Btrieve 的遗留程序（如 Major BBS 模拟项目），替换 DLL 后应用无需修改代码即可运行，原 .DAT 文件保持不变。使用 Bazel 或 Visual Studio 构建，日志写入 wbtrv32.log 并可通过 ini 或环境变量调节级别。

  • 模拟原版 WBTRV32.DLL 接口，应用无需改动代码即可运行
  • 首次访问时自动将 Btrieve .DAT 文件转换为 SQLite 数据库，原始文件保持不变
  • 支持 Windows、Linux、macOS 等平台，提供 Bazel 跨平台交叉编译与 NuGet 打包

适用场景（解读层）

  • 运行仅支持 Btrieve 5/6 版本的遗留 Windows 应用，且不修改其代码
  • 将 Btrieve .DAT 数据迁移至 SQLite 后，使用标准 SQLite 工具进行维护与检查
  • 在 Linux 或 macOS 主机上交叉编译生成 Windows 版 WBTRV32.DLL 等多平台库文件
