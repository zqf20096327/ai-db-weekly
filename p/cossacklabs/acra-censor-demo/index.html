🧭 简介解读层（AI·证据行可回查）

AcraCensor SQL 防火墙示例项目，演示在易受攻击的 OWASP 应用中拦截 SQL 注入。

综述（解读层）

该项目通过 Docker Compose 部署 OWASP Mutillidae 漏洞应用与 Acra 加密套件，Acra 作为 Web 与数据库间的代理，由内置的 AcraCensor 检查双向 SQL 查询。读者可按 README 步骤执行 SQL 注入测试，替换 allowlist/denylist 配置文件并重启 acra-server 容器来观察查询拦截。附带演示视频与配置示例。

  • 提供 docker-compose 文件，一键运行 Mutillidae、数据库与 Acra 代理的完整环境
  • 包含 allowlist 与 denylist 两类 YAML 规则集配置示例
  • 内置多组可测试的 SQL 注入样例，覆盖认证绕过与盲注页面

适用场景（解读层）

  • 学习 AcraCensor 配置文件的写法与重启生效流程
  • 在漏洞应用中观察 SQL 注入查询被防火墙拦截的日志表现
  • 作为 Acra 数据保护套件示例项目系列的一部分进行体验
📖 README 首段存档原文 · 程序抽取

This project illustrates how to use AcraCensor as SQL firewall to prevent SQL injections. Target application is a well-known vulnerable web application OWASP Mutillidae 2.
