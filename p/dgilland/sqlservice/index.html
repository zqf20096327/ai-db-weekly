sqlservice 是构建在 SQLAlchemy ORM 之上的统一接口层

综述（解读层）

sqlservice 基于 Python 3.7+ 与 SQLAlchemy 2.0+，为 ORM 交互提供统一接口层：管理数据库连接与 session、创建/反射/删除数据库对象、持久化和销毁模型实例。适合使用 SQLAlchemy 且希望集中管理数据库操作的开发者，通过 pip 安装，文档位于 readthedocs。

  • 提供同步 Database 与异步 AsyncDatabase 客户端，管理 ORM session
  • 提供声明式 Model 基类，支持转字典（to_dict）和基于装饰器的事件注册
  • session 提供 save/upsert、get、first、all 等持久化与查询方法

适用场景（解读层）

  • 统一管理 SQLAlchemy 数据库连接、session 与建表/删表操作
  • 以声明式模型类集中定义 ORM 事件处理
  • 需要同步与 asyncio 两种客户端访问数据库的场景
