🧭 简介解读层（AI·证据行可回查）

基于 GPUI 编写的 PostgreSQL 与 MySQL 查询管理桌面 GUI 应用。

综述（解读层）

pgui 是用 Rust 的 GPUI 框架编写的桌面图形界面应用，用于查询和管理 PostgreSQL 及 MySQL 数据库。连接与查询历史保存在本地 SQLite 数据库中，密码通过系统密钥链存储；每个连接可配置经 SSH 隧道连接（仅支持密钥或 agent 认证）。附带 AI 面板与补全功能，需配置 Anthropic API Key。

  • 支持 PostgreSQL 与 MySQL 8.4 LTS（协议兼容 8.0 系列）
  • 连接可通过 SSH 隧道转发，凭据经系统密钥链保存
  • 提供 AI 补全（Cmd+.）与 Agent 面板，依赖 ANTHROPIC_API_KEY 环境变量

适用场景（解读层）

  • 需要图形界面查询和管理 PostgreSQL/MySQL 数据库
  • 通过 SSH 隧道访问远程数据库
  • 借助 AI 辅助生成 SQL 语句
