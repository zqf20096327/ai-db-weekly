sqlite3 的 Python 包装库，通过 Model 类实现对象的保存、查询与读取

综述（解读层）

sqlitemodel 是 sqlite3 数据库的 Python 包装库，包含 Model、SQL、Database 三个类，分别用于模型与数据库映射、SQL 语句构建和数据库连接管理。开发者通过继承 Model 并实现 tablename() 与 columns() 方法来映射表结构，可用 pip 安装。数据库文件不存在时会自动创建。

  • Model 类通过 tablename() 和 columns() 方法将数据库表列映射到对象，支持 getModel() 按 id 读取、selectCopy() 按条件查询填充对象
  • SQL 类以链式方法构建 INSERT、UPDATE、SELECT、DELETE 语句，WHERE 支持 isRaw 参数直接嵌入值或使用 ? 占位符
  • Database 类支持 with 语句自动关闭连接，提供 getRaw()、zeroZero()、table_exists()、column_exists() 等方法

适用场景（解读层）

  • Python 应用中以模型对象方式读写 sqlite3 数据库
  • 需要以链式调用方式生成 SQL 语句以减少拼写错误
  • 无对应 Model 的场景下以列表或字典列表形式读取原始查询结果
