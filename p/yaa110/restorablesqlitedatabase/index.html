Android SQLiteDatabase 的包装库，为写操作生成可回滚的还原查询

综述（解读层）

RestorableSQLiteDatabase 包装 Android 的 SQLiteDatabase，在 insert、update、delete、replace、rawQuery 等写入/查询方法中接受一个 tag 参数，将对应的还原 SQL 查询存入哈希表，之后可通过 restore(tag) 或 restoreAll() 执行还原查询以撤销之前的更改。适用于需要在 Android 应用中撤销数据库操作的场合。使用时需提供表名到 ROWID 列名的映射，依赖 JSqlParser 解析 SQL，采用 MIT 许可证发布。

  • 包装 SQLiteDatabase 的 insert、update、delete、replace、rawQuery 等方法，通过 tag 将还原 SQL 查询映射到哈希表
  • 提供 restore(tag)、restore(tags)、restoreAll() 等方法执行还原查询，撤销已执行的写入操作
  • 支持通过 Gradle 或 Maven 引入 aar 依赖，可从 SQLiteDatabase 实例或 SQLiteOpenHelper 子类构造单例或新实例

适用场景（解读层）

  • Android 应用中需要撤销用户删除或修改数据行的操作
  • 需要对已执行的 SQL 写操作按标签粒度或批量回滚的场景
  • 基于现有 SQLiteOpenHelper 代码接入可还原数据库能力的项目
