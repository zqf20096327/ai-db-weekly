运行于 JS 环境的本地优先响应式 NoSQL 数据库，支持与既有后端实时复制

综述（解读层）

RxDB 是面向 JavaScript 应用的本地优先 NoSQL 数据库，除查询当前状态外，可订阅查询结果或文档字段的状态变更。通过实现三个 HTTP 端点的同步协议与既有后端复制，提供 GraphQL、CouchDB、Firestore 等插件。存储层基于存储接口，可切换 IndexedDB、SQLite 等引擎。部分高级插件需付费获取。

  • 提供响应式订阅能力，可观察查询结果或单个文档字段的状态变化
  • 同步引擎通过实现三个 HTTP 端点接入既有基础设施，并提供 GraphQL、CouchDB、WebRTC、Supabase、Firestore 等复制插件
  • 存储层可通过存储接口更换底层引擎，支持 LocalStorage、IndexedDB、OPFS、SQLite、in-memory、FoundationDB、DenoKV 等

适用场景（解读层）

  • 浏览器、Node.js、React Native、Electron 等 JavaScript 运行环境中的本地数据存储
  • 需要实时数据同步的多用户协作应用
  • 需与既有后端（如 CouchDB、GraphQL 服务、Supabase）进行数据复制的应用
