基于BDD的实时查询增量更新算法，从变更事件在内存中计算新查询结果

综述（解读层）

EventReduce 是一个用于实时查询的算法库：当数据库发生写入事件时，它接收旧查询结果与变更事件，在内存中计算出新的结果集，而无需重新执行查询。它通过 18 个状态函数与 16 个动作函数构建真值表并优化为二叉决策图（BDD）。适用于需要保持查询结果实时更新的应用开发者。限制包括：仅支持单表/集合查询，排序必须有可预测顺序（通常以主键作为最后排序字段）。

  • 提供 18 个状态函数与 16 个动作函数，预计算出 2^18 种状态组合对应的动作真值表，并优化为二叉决策图（BDD）
  • 适用于任何提供变更流（change stream）的数据库，README 列举 MongoDB、PostgreSQL、MySQL、IndexedDB、SQLite 及内存存储
  • 除 JavaScript 参考实现外，提供 Rust、Dart、Kotlin、Swift、C#、Python、Go 实现，各实现运行同一共享测试套件

适用场景（解读层）

  • 响应式 UI 与实时仪表盘中保持查询结果随数据库写入自动更新
  • 本地优先应用的实时查询及后端向客户端推送查询结果订阅
  • 以更新内容代替缓存失效的查询结果缓存场景
