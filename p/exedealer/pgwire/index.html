面向 Deno 与 Node.js 的 PostgreSQL 客户端库，直接暴露 wire 协议全部特性。

综述（解读层）

pgwire 是一个用于 Deno 和 Node.js 的 PostgreSQL 客户端库，通过连接字符串或对象建立连接，提供 query 与 stream 两种取数方式。它实现简单与扩展查询协议、pgoutput 消息解析，可消费逻辑复制流。README 说明需调用 .end() 释放连接；部分章节标注 TODO，文档尚未完整。

  • 支持逻辑复制（含 pgoutput 协议解析）、流式读取大结果集、COPY FROM STDIN/TO STDOUT、Listen/Notify、单往返查询管道化
  • 纯 JS 无依赖，支持多语句隐式事务查询与查询取消，提供 pgconnection 与 pgpool（连接池，可切换外部池如 pgBouncer）两种入口
  • pgconnection() 接受多个 URI/对象参数并按 first-win 优先级合并，便于设置默认回退值

适用场景（解读层）

  • 应用订阅 insert/update/delete/truncate 数据变更事件，用于副本同步、缓存失效或历史记录跟踪
  • 处理大数据集查询结果（通过 pg.stream() 按块迭代而非整体载入内存）
  • 在 Deno 或 Node.js Web 服务中通过连接池执行参数化查询与多语句脚本
