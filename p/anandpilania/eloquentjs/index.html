Node.js 版 Laravel Eloquent 风格 ORM，采用 monorepo 多包架构

综述（解读层）

EloquentJS 是一个面向 Node.js 的 ORM monorepo，提供参照 Laravel Eloquent 风格的 Model、QueryBuilder、关联、事件与校验机制。数据层通过 resolver 契约与具体数据库解耦，官方驱动覆盖 PostgreSQL、MySQL、SQLite、MongoDB。附加包可自动生成 GraphQL schema、REST CRUD 路由、WebSocket 实时广播，并内置 MCP server 供 AI 编码工具调用。适合 Node.js 后端开发者及使用 AI 助手管理数据层的团队。

  • 通过 resolver 接口实现驱动扩展，@eloquentjs/core/testing 提供 shape 与 behavior 两级一致性测试套件
  • 内置 MCP server 提供 21 个工具供 Claude、Cursor、Windsurf 等 AI 工具操作模型，附带 CLAUDE.md、.cursorrules 等 agent 配置文件
  • 支持 eager loading 关联预载、观察者事件注册（按类引用作为 key，避免压缩破坏），实时频道采用 Pusher 协议并对 private/presence 频道签名

适用场景（解读层）

  • Node.js 后端需要 Active Record 风格模型、事务与多数据库连接的项目
  • 为模型快速生成 GraphQL schema 或 Express/Fastify 的 REST CRUD 路由
  • 让 AI 编码助手通过 MCP 工具直接读取和操作项目数据模型
