单文件 PHP SQL 框架，基于 PDO 提供查询构建器与读写路由

综述（解读层）

NDT-DBF 是一个以单个 DBF.php 文件运行、基于 PDO 的 PHP SQL 库，提供查询构建器、事务与嵌套保存点、读写路由、软删除、keyset 分页和 JSON 字段读写。面向 PHP 8.1+ 开发者，可直接 require 或经 Composer 安装。README 明确说明它是 SQL 库而非 ORM、迁移系统或权限边界；SQL Server 仅支持 SQL 编译，无实时集成测试。

  • 运行时集中于 DBF.php 单文件，仅需 PHP 8.1+、PDO 及对应数据库驱动
  • 支持 MySQL/MariaDB、PostgreSQL、SQLite 的事务、嵌套保存点、upsert 与 JSON 读写，并提供读/写连接自动路由
  • 提供软删除（deleted_at 时间戳或 flag 模式）、租户 scope、forUpdate 行锁、keyset 分页与流式 chunk 处理

适用场景（解读层）

  • PHP 项目中以单文件方式接入 MySQL、PostgreSQL 或 SQLite 数据库进行增删改查
  • 配置主库写入、从库读取的分离路由场景
  • 需要软删除、多租户查询过滤或基于唯一键的分页遍历的应用
