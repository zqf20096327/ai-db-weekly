Quarkus 扩展，将 JPA/Hibernate 查询以 Java Stream 形式表达并渲染为 SQL

综述（解读层）

该项目是 Quarkus 的 JPAStreamer 扩展，面向使用任意 JPA 提供者（如 Hibernate）的 Java 应用，通过添加依赖即可用 filter/sort/map 等标准 Stream 操作符操作数据库内容，编译期从实体自动生成字段元类，并将 Stream 最终渲染为 SQL 以减少 JVM 与数据库负担。需 Java 8 及以上，采用 LGPL 2.1 许可，且默认会向服务器回传部分数据，需联系官方关闭。

  • 支持以标准 Stream 操作符（filter、sorted、skip、limit、forEach 等）表达数据库查询
  • 编译期从 JPA 实体自动生成字段元类（如 Film$）用于类型安全的字段引用
  • 将 Stream 渲染为 SQL 查询执行，单个 Maven 依赖即可接入现有 JPA 提供者

适用场景（解读层）

  • 在 Quarkus 项目中用 Java Stream 语法替代手写 JPQL/Criteria 查询
  • 对已有 JPA 实体表进行过滤、排序和分页读取
  • 需要通过 JPA 提供者（如 Hibernate/MySQL）执行渲染后的 SQL 的应用
