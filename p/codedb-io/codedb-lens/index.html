🧭 简介解读层（AI·证据行可回查）

只读数据库健康检查工具，以规则目录扫描 SQL Server 与 PostgreSQL 并生成 A-F 评级报告

综述（解读层）

codeDB Lens 使用只读账号连接 SQL Server 或 PostgreSQL 实例，运行基于证据的规则目录并生成包含 A-F 评级与覆盖印章的自包含 HTML+JSON 报告。提供 CLI、桌面应用与 MCP 服务器模式，规则以 YAML 文件加 SQL 查询定义。支持 record/report 对实例录制最长 24 小时，含 26 条检查规则及 8 条录制规则。

  • 只读检查，无 DDL/DML、无代理、不在服务器安装组件，支持 --redact 参数用于报告分享
  • 每条发现附带采集值、产生它的 SQL 查询与时间戳，置信度分为 Confirmed、Hint、No data 三级，权限不足时计入覆盖率而非显示正常
  • 支持 Windows 安装包/Scoop、Linux .deb/.rpm、Docker 镜像，可经 MCP 集成 Claude、GitHub Copilot、Cursor，界面与报告提供英语和巴西葡萄牙语

适用场景（解读层）

  • DBA 对 SQL Server/PostgreSQL 实例执行快照式健康检查，涵盖备份、阻塞会话、索引、事务 ID 回卷风险、autovacuum 滞后等项
  • 将本地 MCP 服务器接入 AI 客户端，让 AI 运行诊断或以受限 SELECT 回答数据问题
  • 使用 record 与 report 对实例录制最长 24 小时并生成对比（compare）报告
