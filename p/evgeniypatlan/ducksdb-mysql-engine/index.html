MySQL 9.7 内置 DuckDB 存储引擎，通过整查询下推执行分析型 SELECT

综述（解读层）

该项目为 MySQL 9.7 提供内置的 DuckDB 存储引擎，建表时指定 ENGINE=DuckDB 即可使用。引擎注册 handlerton::pushdown_select 钩子，将基础表全部为 DuckDB 表的 SELECT 重新生成为 DuckDB 方言并在 DuckDB 中执行，无法翻译时回退到普通 MySQL 执行。适合需要在一个 MySQL 实例内同时运行事务与分析查询的开发者。

  • 提供 ENGINE=DuckDB 建表方式，无需 SECONDARY_ENGINE 配置
  • 整查询下推覆盖聚合、内外连接、派生表、CTE、标量子查询及 IN/EXISTS 类谓词
  • 提供 Docker 预构建镜像及 MTR、GoogleTest/CTest 测试套件

适用场景（解读层）

  • 在 MySQL 单一 SQL 接口下对 ENGINE=DuckDB 表运行分析查询
  • 基于 TPC-H 基准对比不同引擎执行行为的测试环境
  • 从源码构建含该引擎的 mysqld 的开发与 CI 场景
