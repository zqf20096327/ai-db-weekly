🧭 简介解读层（AI·证据行可回查）

Linux 服务器备份脚本，基于 Bash 与 YAML 配置执行加密备份与恢复

综述（解读层）

Backfort 是运行于 Linux 的备份与灾难恢复工具，以单个 Bash 4.3+ 脚本和严格校验的 YAML 配置实现全量备份，支持 Docker Compose 项目、命名卷与数据库转储，经可选压缩加密后以原子方式发布到本地或 rclone 目标，完成后退出而不驻留守护进程。恢复需指定新目录，调度交由 cron、systemd timer 或 Kubernetes CronJob 完成。适用于需要显式声明备份源路径与目标、以文件为交付形态的运维人员。

  • 支持 GNU tar 全量备份、gzip/zstd 压缩，以及 age/GPG 加密与 Minisign 分离签名
  • 可归档 Compose 清单、命名卷、bind 挂载，并生成 PostgreSQL/MySQL/MariaDB 逻辑转储及 MS SQL/Oracle 原生导出
  • 通过 rclone 将备份发布到多个本地或远端目标（S3 兼容存储、FTP、Dropbox 等），提供 .complete 标记、SHA-256 校验与 GFS 式保留策略

适用场景（解读层）

  • 用 cron 或 systemd timer 定期备份 Linux 服务器上的指定文件与目录
  • 备份 Docker Compose 项目的清单、卷和数据库，或将 Compose 项目迁移到新服务器
  • 通过 rclone 将加密备份分发到 S3 兼容对象存储等异地目标，并按保留策略清理旧版本
