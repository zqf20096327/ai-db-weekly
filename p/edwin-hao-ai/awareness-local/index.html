🧭 简介解读层（AI·证据行可回查）

面向 MCP IDE 的本地优先 AI 代理持久记忆服务器

综述（解读层）

Awareness Local 是一个本地优先的 MCP 记忆服务器，为 Cursor、Claude Code、Copilot、Cline 等 MCP 兼容 IDE 提供跨会话持久记忆。记忆以 Markdown 存储于 .awareness/ 目录，用 SQLite FTS5 与嵌入构建混合检索索引，经 MCP 协议（localhost:37800）提供 recall、record 等工具，附 Web 控制台。本地模式可完全离线运行，无需账号；云端同步为可选项。需 Node.js 18+，通过 npx @awareness-sdk/setup 一条命令安装。

  • 记忆以 Markdown 文件存储在 .awareness/ 目录，配合本地 SQLite（FTS5 + 嵌入）索引进行关键词与语义混合检索
  • 通过 MCP 协议提供 awareness_init/recall/record/lookup 等工具，采用两阶段渐进式召回（先返回摘要索引再取全文）
  • 本地模式完全离线运行，无需云账号；支持 13+ MCP 兼容 IDE 的自动检测配置

适用场景（解读层）

  • 跨多次会话的长期代码库迁移，代理可延续先前决策与待办任务
  • 需要共享决策历史与任务记忆的多代理协作设置
  • 个人工作流中持久保存编码偏好与项目约定
