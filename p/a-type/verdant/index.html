面向 local-first Web 应用的存储与同步框架

综述（解读层）

Verdant 是一个面向 Web 应用的本地优先存储与同步框架。客户端基于 IndexedDB 存储数据，提供实时更新的查询和基于 schema 的类型安全；可选的 Node 服务端组件增加设备同步与实时协作。数据以 baseline 和操作记录表示，按对象 ID 绑定操作以处理变更合并。适用于愿意自建同步服务的前端开发者。

  • 客户端使用 IndexedDB 跨会话存储数据，支持索引查询、实时刷新、撤销重做及文件存储
  • 数据模型基于 baseline 与操作的组合，操作按唯一时间戳确定性排序，并按对象 ID 应用变更
  • 提供 CLI 从 schema 生成类型化客户端与迁移文件，并提供 React hooks 绑定

适用场景（解读层）

  • 纯本地存储的 Web 应用，数据保存在用户设备上并可部署为静态页面
  • 需要多设备同步的应用，自建 Node 服务端配合 SQLite 进行数据备份与同步
  • 需要实时多人协作的应用，通过 WebSocket 传输并展示在线成员 presence 信息
