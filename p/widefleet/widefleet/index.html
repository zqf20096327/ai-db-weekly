开源自托管平台，用于部署和运行编码智能体构建的内部应用与工作流

综述（解读层）

Widefleet 是一个开源、可自托管的平台，团队可用自己的编码智能体在独立项目中开发内部工具（默认 SvelteKit，可选 TanStack Start），通过 CLI 构建部署到共享平台。平台提供公司 SSO 登录、数据库与文件存储绑定、网络权限控制，以及 Cron、队列和持久化工作流。发布的应用在管理组件停止后仍持续运行，运行时、代理、身份与存储服务需保持可用。

  • 应用代码保留在开发者自己的项目中，通过 CLI 构建、上传并部署，支持发布隔离预览、查看部署历史、回滚代码和查询应用日志
  • 提供公司 SSO 登录、应用访问组管理和共享应用目录，并通过网络权限和应用服务控制对外部系统与 IT 托管服务的访问
  • 支持声明式数据库、文件存储和键值绑定，包含 Cron、队列和带重试与事件等待的持久化工作流

适用场景（解读层）

  • 团队使用自己的编码智能体开发内部工具，并需要一个统一的部署与共享入口
  • 企业需要带 SSO 登录、访问控制和数据绑定的自托管内部应用平台
  • 需要在 Linux x86-64 Docker 主机上运行包含预览、部署历史和后台工作流的应用运行环境
