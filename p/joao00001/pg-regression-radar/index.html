🧭 简介解读层（AI·证据行可回查）

检测 PostgreSQL 查询延迟回退并关联到触发部署的 Kubernetes 工具。

综述（解读层）

pg-regression-radar 是一个面向在 Kubernetes 上运行 Postgres 并频繁发布应用变更的团队的工具。它定时采样 pg_stat_statements，接入 Argo CD、Argo Rollouts、Flux 或通用 webhook 的部署事件，对每条查询执行 E-divisive 变化点定位并以 Welch t 检验确认，输出查询、对应部署、变化幅度与置信分。项目以单个二进制提供 operator、manager、collector、ingester 四种命令，支持 PostgreSQL 16–18，采用 Apache 2.0 许可证。

  • 对每条查询运行两阶段统计检测：E-divisive 变化点定位加 Welch t 检验确认
  • 从 Argo CD、Argo Rollouts、Flux、Kubernetes 或通用 webhook 读取部署事件并做关联，也支持无部署事件的周期性检测
  • 提供 operator、manager、collector、ingester 四个子命令，manager 模式将每条回退记录为 PerformanceRegression 资源并支持多集群 PostgresWatch

适用场景（解读层）

  • 在 Kubernetes 上运行 CloudNativePG、Zalando 等发行版并每日多次发布，需要定位哪次部署引起查询变慢的团队
  • 在回退发生时捕获 EXPLAIN 计划以区分执行计划变更与同计划变慢
  • 通过 Slack、Microsoft Teams、PagerDuty 或自定义 webhook 接收回退告警，或在置信分超过阈值时中止 Argo Rollouts 金丝雀（默认关闭）
