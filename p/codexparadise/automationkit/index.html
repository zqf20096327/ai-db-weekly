自托管 AI 自动化 Docker 套件，以 Caddy 网关统一编排 11 个微服务

综述（解读层）

AutomationKit 用 Docker Compose 将 n8n、OpenWA、Ollama、Qdrant、Crawl4AI 等服务打包在隔离的 Docker 网络中，由 Caddy 反向代理并提供 .local 域名访问。面向想在本地机器部署自动化工作流与本地大模型的开发者，需自备 Docker 与 Git，通过 automation.bat 脚本或 docker compose 启动，密钥通过 .env 配置。

  • 通过 Docker Compose 部署 n8n、Ollama、Qdrant、Neo4j、PostgreSQL、Redis、Crawl4AI、Docling、Supabase、SearXNG、Caddy 等服务
  • 集成 OpenWA 实现 WhatsApp 消息触发 n8n 工作流，支持多会话持久化与异步队列
  • n8n 代码在 Docker-in-Docker 沙箱中执行，由独立 mTLS 控制 API 管理

适用场景（解读层）

  • 在本地或家庭服务器搭建自托管自动化工作流环境
  • 构建结合本地大模型、向量检索与网页抓取的 n8n 流程
  • 基于 OpenWA 接入 WhatsApp 消息并触发自动化响应
