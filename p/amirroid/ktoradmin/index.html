面向 Ktor 的动态管理后台框架，运行时自动发现实体生成管理界面

综述（解读层）

KtorAdmin 是为 Ktor 应用提供的管理后台框架，不依赖预定义数据库模式，而是在运行时自动发现实体并生成管理界面。支持 Exposed、Hibernate 与 MongoDB 数据源，提供 RBAC、事件系统、文件管理、过滤搜索、导出与多语言等能力。通过 Gradle 插件（KSP）安装依赖后以 install(KtorAdmin) 启用，访问 /admin 路径进入面板。要求 Java 21，采用 MIT 许可证。

  • 运行时自动发现实体并生成管理界面，无需预定义数据库模式
  • 支持 Exposed、Hibernate 两种 SQL 访问方式以及 MongoDB，提供 RBAC、认证、自定义操作、事件系统、文件管理与缩略图生成、过滤搜索排序、数据导出、多语言支持
  • 提供可扩展与可自定义的模板系统，界面含明暗两种模式

适用场景（解读层）

  • 为已有 Ktor 服务端应用快速接入数据管理后台
  • 数据模型同时涉及 SQL（Exposed/Hibernate）与 MongoDB 的项目
  • 需要基于角色的访问控制和多语言界面的内部管理系统
