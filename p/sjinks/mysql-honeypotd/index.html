🧭 简介解读层（AI·证据行可回查）

用 C 编写的低交互 MySQL 蜜罐守护进程，模拟 MySQL 服务并记录登录尝试。

综述（解读层）

mysql-honeypotd 是一个低交互 MySQL 蜜罐，监听指定端口（默认 3306）模拟 MySQL 服务器，把登录尝试（用户名、来源 IP、是否带密码）写入 syslog。基于 libev 实现，支持绑定多个 IP、自定义模拟的服务器版本、登录延迟，以及在 root 运行时降权、chroot。适用于需要记录针对 MySQL 端口扫描与爆破行为的场景。

  • 基于 libev，可绑定多个 IP 地址，默认监听 3306 端口
  • 将登录尝试（用户、来源地址、是否使用密码）记录到 syslog，可通过 --setver 自定义模拟的 MySQL 版本
  • 支持以 root 运行时切换用户/组、chroot 隔离，并可在每次登录尝试后加入延迟

适用场景（解读层）

  • 部署在服务器上开放 3306 端口，记录针对 MySQL 的扫描与暴力破解来源
  • 在不需要真实 MySQL 对外服务的环境中代替真实端口，收集连接日志
  • 配合 syslog 集中日志，分析暴破尝试的 IP 与用户名
