TiDB 集群 DBA 运维工具集，提供交互式/非交互式 CLI 巡检、诊断与治理命令

综述（解读层）

TiDBA 是面向 TiDB 数据库 DBA 的运维命令行工具集，支持交互式与非交互式两种模式。命令集包含数据巡检配置与启动（inspect）、写入热点打散语句生成（split）、热点 region 与副本诊断（region）、SQL 耗时/CPU 等维度排序（topsql）、基于 SQL Digest 的限流拦截（runaway）、session 终止（kill）以及执行计划查看与绑定（sql）。使用前需在 TiUP 中控机用户环境下运行，并通过 meta create 创建集群访问元数据，clusterName 须与 TiUP 集群名一致。

  • 提供 inspect 命令实现数据库巡检参数配置的创建、查询、修改、删除及巡检启动
  • split 命令支持基于已有数据（range、key）或采样（estimate、sampling）生成数据与索引打散语句
  • runaway 命令基于 SQL Digest 创建集群级 SQL 限流/拦截，kill 命令支持间歇性或持续性终止 session

适用场景（解读层）

  • 对 TiDB 集群进行自动化巡检与配置管理
  • 排查热点 region、宕机副本及 TOP SQL 性能问题
  • 通过 SQL Digest 进行限流、拦截、执行计划查看与绑定
