基于 Rails DSL 以声明式方式管理数据库 schema 的 Ruby 命令行工具

综述（解读层）

Ridgepole 是一个 Ruby 编写的数据库 schema 管理工具，用 Rails DSL 在 Schemafile 中定义表结构，工具对比 DSL 与数据库差异后生成并执行变更，工作方式类似 Chef/Puppet。通过 gem 安装，面向使用 ActiveRecord 的 Rails 项目。README 注明不支持 SQLite，v1.0 起默认跳过 DROP TABLE，需显式传 --drop-table。

  • 以 Rails DSL 声明式定义 schema，对比 DSL 与数据库差异后应用变更
  • 支持列/表重命名（renamed_from）、外键、CHECK 约束、生成列、函数索引、PostgreSQL 部分索引、collation/charset 及通过 execute 管理视图
  • 提供 --diff 对比 schema 文件或数据库（可配 --with-apply）、--dry-run、--export，并支持 ignore 标记与 --alter-extra 附加 ALTER 语句

适用场景（解读层）

  • Rails/ActiveRecord 项目中用单一 Schemafile 维护数据库表结构
  • 在应用 schema 变更前用 --diff 或 --dry-run 查看待执行的 DDL 差异
  • 通过 Git 仓库以 Schemafile 为准管理多环境的数据库结构定义
