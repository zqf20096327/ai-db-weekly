基于 dat 协议栈的 p2p 内容数据库与搜索引擎

综述（解读层）

Sonar 是一个运行在 dat 技术栈上的 p2p 数据库与搜索引擎，典型用法是本地启动 sonar-server，再通过 Web UI（默认 9191 端口）、CLI 或 JavaScript 客户端库交互。核心模块 core 管理集合（collection），每个集合包含 kappa-record-db、经 tantivy 插接的搜索索引及用于存原始文件的 Hyperblobs；需 Node.js 16+。

  • 集合数据通过 kappa-record-db 管理，并接入基于 tantivy 的搜索索引
  • 使用 Hyperblobs 存储原始文件内容，server 提供 REST 风格 HTTP API 供 CLI 和 UI 使用
  • monorepo 结构，包含 core、server、client、ui、cli 等包

适用场景（解读层）

  • 在本地运行数据服务并通过 CLI 管理集合、读写数据、上传下载文件和执行搜索
  • 通过单页 UI 浏览数据库中的数据
  • 用 JavaScript 客户端库经 HTTP 访问 server 数据进行二次开发
