面向 GBase 8s dolphin MySQL 协议端口的 Go 连接兼容层

综述（解读层）

该项目提供面向 GBase 8s openGauss/dolphin MySQL 协议端口的 Go 驱动封装与连接示例，基于 go-sql-driver/mysql 修改，处理 COM_PING 不支持、客户端参数内插、十六进制写入与自增 ID 补查等协议层问题，并附冒烟测试工具。仅适用于启用 dolphin 协议的 B 兼容数据库；不包含业务模型与部署配置， Informix 底座的 GBase 8s 不适用。

  • 用 SELECT 1 探活以避开不支持 COM_PING 的端口，默认启用客户端参数内插
  • 支持以 decode(..., 'hex') 写入二进制参数并解码 BLOB 结果的 \x 十六进制形式
  • 提供只读或含写入的冒烟测试，以及特定构建的 NULL 结果集服务端临时补丁及回滚说明

适用场景（解读层）

  • Go 应用通过 dolphin MySQL 协议端口连接 GBase 8s B 兼容数据库
  • 在目标实例上验证驱动与服务端的实际兼容性（冒烟测试）
  • GORM 上层复用 *sql.DB 连接并禁用自动 Ping 的接入场景
