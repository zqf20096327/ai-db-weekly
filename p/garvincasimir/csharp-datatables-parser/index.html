面向 jQuery DataTables 服务端数据源的 C# .NET Core 解析器

综述（解读层）

该项目为 jQuery DataTables 插件提供服务端解析功能，接收其请求参数后基于 IQueryable 生成排序、分页与过滤表达式，配合 EF Core 等提供程序查询数据库。目标平台为 Netstandard 1.3，附有 In Memory、MySql、SQL Server、PostgreSQL 测试。支持通过投影控制返回字段，并可用 SetConverter 替换日期等属性的字符串转换表达式。注意默认过滤依赖提供程序对 DateTime 和数值类型 .ToString() 的支持，缺失时 EF Core 会回退到客户端求值；起止匹配 token 功能未发布到 NuGet 包。

  • 支持 Netstandard 1.3，测试覆盖 EF Core In Memory、MySql、SQL Server、PostgreSQL
  • 根据 DataTables 发送的设置和过滤文本生成 WHERE 子句表达式，支持通过 SetConverter 自定义属性转换表达式
  • 提供投影（projection）用法示例及起止匹配 token（默认 *| 与 |*），后者尚未进入 NuGet 包

适用场景（解读层）

  • 在 ASP.NET Core / .NET Core 服务端为 jQuery DataTables 提供分页、排序、过滤数据接口
  • 配合 EF Core 对 SQL Server、MySQL、PostgreSQL 等数据库执行服务端查询
  • 需要通过投影控制序列化字段（如排除敏感列）或包含计算字段、父表字段的表格场景
