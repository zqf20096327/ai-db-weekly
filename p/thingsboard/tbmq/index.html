综述（解读层）

TBMQ 是由 ThingsBoard 团队开发的 MQTT 消息代理，完整支持 MQTT v3.1、v3.1.1 与 v5.0 协议。项目基于 Kafka 实现数据持久化与复制，采用无主节点集群架构，面向物联网设备连接与消息通信场景。安装方式包括 Docker、Kubernetes 与 Helm Charts，单节点部署后默认在 8083 端口提供 Web UI。项目采用 Apache 2.0 许可证发布，同时提供商业专业版（PE）。

  • 完整支持 MQTT v3.1、v3.1.1 和 v5.0 协议的核心特性，单节点与集群环境均适用
  • 基于 Kafka 构建持久化机制，集群采用无主（masterless）节点设计
  • 提供客户端会话与订阅管理界面、实时监控、多种认证方式（Basic、JWT、X.509、SCRAM、HTTP）及按客户端的 ACL 规则

适用场景（解读层）

  • 物联网遥测采集（fan-in）：大量设备消息集中由少数应用消费
  • 广播通知（fan-out）：少数请求触达大量订阅设备
  • 点对点命令与控制（p2p）：通过唯一定义的主题在一对发布者与订阅者之间路由消息
