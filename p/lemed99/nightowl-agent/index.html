自托管 Laravel 监控 agent，接 Nightwatch 遥测并写入自有 PostgreSQL

综述（解读层）

NightOwl Agent 是一个 MIT 许可的 Laravel 包（PHP 8.2+，支持 Laravel 11-13），接收 laravel/nightwatch 产生的 12 类遥测数据，经 ReactPHP TCP 摄入和 SQLite WAL 缓冲后用 COPY 协议写入自备的 PostgreSQL。适合想把 Laravel 可观测数据留在自己基础设施内、用 SQL 或 BI 工具直接查询的团队。需 PostgreSQL 14+；表带 nightowl_ 前缀，按 environment 分区。

  • 接收 Nightwatch 全部 12 类记录（请求、查询、任务、异常、日志等），经本地 TCP 摄入与 SQLite WAL 缓冲后以 COPY 协议写入自备 PostgreSQL
  • 提供异常指纹聚合、新 issue 告警（Email/Webhook/Slack/Discord）、阈值性能问题、agent 与主机健康诊断
  • 基准测试显示单实例摄入约 13,400 payloads/s，单个 drain worker 写入约 2,500 payloads/s

适用场景（解读层）

  • 在自有基础设施内自托管 Laravel APM，遥测数据不出内网
  • 用 psql、Metabase 或自建 UI 直接查询 nightowl_ 表中的原始遥测数据
  • 多环境（local/staging/production）共用一个 PostgreSQL 数据库并按 environment 过滤分析
