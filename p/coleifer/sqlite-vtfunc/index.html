用 Python 实现 SQLite 表值函数的 Cython 绑定库

综述（解读层）

vtfunc 是一个 SQLite 表值函数的 Python 绑定库，基于 Cython 实现，供使用标准库 sqlite3 或 pysqlite2 驱动的开发者使用。它封装了 SQLite 匿名虚拟表的创建细节，开发者继承 TableFunction 类即可编写可在 FROM 子句或 IN 表达式中调用的函数。要求 SQLite >= 3.9.0；SQLite <= 3.13 时函数注册不跨连接，需每次连接重新注册；若使用 Peewee 3.0+，相关代码已并入其 sqlite 扩展模块，此库不再是必需。

  • 通过封装 eponymous 虚拟表，允许用 Python 编写返回多行多列的表值函数，可在 FROM 子句和 IN 表达式中使用
  • xBestIndex 查询计划选择优先采用包含全部参数值的计划，参数不全的计划会被降权
  • 要求 SQLite >= 3.9.0，支持标准库 sqlite3 或 pysqlite2 驱动；SQLite <= 3.13 需每次连接重新注册

适用场景（解读层）

  • 在 SQL 查询中抓取网页并返回链接表，或与存储 URL 的表做关联查询
  • 传入文件路径返回目录内文件及其元数据表
  • 对文本执行正则搜索并为每个匹配子串返回一行，如从消息表中提取邮箱地址
