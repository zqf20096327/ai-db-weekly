🧭 简介解读层（AI·证据行可回查）

面向 Filament 的演示模式插件，用持久 SQLite 沙箱与角色切换展示面板

综述（解读层）

这是 Laravel 12/13 与 Filament 4/5 的插件，将选中的模型数据批量复制到独立 SQLite 沙箱，供演示面板操作并在退出后保留、之后恢复，不影响生产库；附带独立角色切换器（默认适配 Spatie Permission，非 Spatie 需自定义授权策略）。依赖 PHP 8.2+、PDO SQLite，且应用迁移须兼容 SQLite。文档明确其为应用级隔离而非安全边界，数据不匿名化，租户面板需显式集成，多服务器部署需共享存储。

  • 从所选模型以可恢复的分批进度复制数据到持久 SQLite 沙箱，退出后可随时恢复，无过期或定时清理
  • 提供独立角色切换器（/demo-mode/roles），默认适配 Spatie Permission，也可通过 ApplicationAdapter/RoleSwitcher 接口自定义
  • 在演示运行期间隔离 Laravel 数据库连接、磁盘、缓存与 Redis 操作，并抑制邮件、队列任务和外部通知渠道

适用场景（解读层）

  • 向客户或内部演示 Filament 面板工作流，而不改动生产数据
  • 用单一选定角色展示不同角色下的权限与界面表现
  • 在应用更新后缺少表或列时，通过恢复页重建沙箱并保留选定的起始数据
