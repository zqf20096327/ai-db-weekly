基于 Terraform 在 GCP 部署 Node.js 服务与 PostgreSQL 的模板

综述（解读层）

该仓库提供一套 Terraform（HCL）模板，用于在 GCP 上部署 Node.js 服务与 PostgreSQL 数据库，组件包含 VPC、Cloud Run、Cloud SQL、Memorystore Redis、Cloud Storage、Cloud Scheduler、监控告警及基于 Cloud Build 的 Prisma 迁移与部署 CI/CD。使用者需安装 Terraform 与 gcloud CLI、具备启用计费的 GCP 项目及相应 IAM 角色；每个环境对应一个根模块，通过复制 tf/dev 目录并修改 terraform.tfvars 来新建环境，状态迁移至 GCS 存储。

  • 包含 VPC、Cloud Run、Cloud SQL（PostgreSQL）、Memorystore Redis、Cloud Storage（含 CORS 配置的公开/私有桶）、Cloud Scheduler 及 IAM 角色等组件的 Terraform 定义
  • 提供 Cloud Monitoring 告警策略，覆盖 Cloud Run 5xx、ERROR 级应用日志、部署与迁移构建失败，通知可发至邮箱或 Slack，通知中含日志/构建深链接
  • 包含基于 Cloud Build 的 Prisma 数据库迁移与部署配置，由分支更新触发；每个环境为独立根模块，复用同一组子模块

适用场景（解读层）

  • 需要在 GCP 上以基础设施即代码方式部署 Node.js 服务和 PostgreSQL 数据库的项目
  • 需要维护 development、staging、production 等多个环境且保持配置一致性的团队
  • 需要将 Secret Manager 密钥注入 Cloud Run 容器并配置 Cloud Monitoring 邮件/Slack 告警的场景
