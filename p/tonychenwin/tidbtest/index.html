TiDB 测试框架，通过 HTTP 接口部署集群、管理测试用例执行与服务停止

综述（解读层）

TidbTest 是一个 TiDB 测试框架，面向需要在本地管理 TiDB 集群生命周期与测试用例的使用者。它以 HTTP 接口形式提供部署（可指定 pd 和 tikv 个数）、获取 case 列表、执行指定 cases、停止单个服务或整个集群四类功能。部署基于 helm template 生成 docker-compose 配置，返回命令执行日志。README 仅记录部署接口示例，其余接口未给出请求细节。

  • 提供 POST /deploy/deploy 接口，支持通过 pdSize 和 tikvSize 参数指定 PD 与 TiKV 节点个数
  • 部署流程调用 helm template 生成 docker-compose 文件，并执行 docker-compose pull 与 up -d，返回各命令的执行日志
  • 提供获取 case 列表、执行指定 cases、停止指定服务或整个集群的接口

适用场景（解读层）

  • 按指定拓扑（pd/tikv 数量）部署本地 TiDB 测试集群
  • 批量获取并执行 TiDB 测试用例
  • 停止集群中单个服务或整体集群以进行环境管理
