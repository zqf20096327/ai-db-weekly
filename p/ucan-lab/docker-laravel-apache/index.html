🧭 简介解读层（AI·证据行可回查）

基于 docker-compose 搭建 Laravel 开发环境的模板项目，含 Apache 与 MySQL 容器。

综述（解读层）

该仓库提供一组 docker-compose 配置与 Makefile，用于克隆后通过 make create-project 命令安装最新 Laravel 项目并运行于 http://localhost。web 容器基于 php:7.4-apache、composer:2.0 与 node:14 镜像，db 容器为 MySQL 8.0，数据通过命名卷持久化。适用于本地开发，README 未提供生产部署说明。

  • 提供 make create-project 等命令一键安装 Laravel 项目
  • 包含 web（php:7.4-apache、composer:2.0、node:14）与 db（MySQL 8.0）两个容器
  • MySQL 数据默认挂载命名卷，容器销毁后数据保留

适用场景（解读层）

  • 本地搭建基于 Apache 的 Laravel 开发环境
  • 需要 PHP、Composer、Node 与 MySQL 组合容器的项目初始化
  • 学习 docker-compose 编排 PHP Web 应用
