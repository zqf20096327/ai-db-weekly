支持 MongoDB 与 SQL 数据库的 Rust 原生桌面客户端

综述（解读层）

Quarry 是一个桌面客户端，用于连接 MongoDB、MySQL、MariaDB 和 PostgreSQL，macOS、Linux 和 Windows 平台可用，MIT 许可且无付费版。连接默认只读，编辑以草稿暂存后批量保存并支持撤销。程序为单个 Rust 二进制文件，使用 egui 绘制界面，不依赖 Electron 或 Web 视图，需按系统下载对应安装包。

  • 支持 MongoDB（find/aggregate、管道阶段预览、explain）、SQL 编辑器、SSH 隧道、SOCKS5、TLS 及 Google Cloud SQL 连接
  • 内置基于 Bun 的 JavaScript shell，一个脚本可使用多个连接，并包含 JSON/CSV/TSV/SQL 导入导出
  • 内置 MCP server 供 AI agent 查询和修改数据库，支持按连接设置读写权限、Ask 确认、数据脱敏与审计日志

适用场景（解读层）

  • 在同一客户端中并排管理多种 MongoDB 与 SQL 数据库连接
  • 团队通过脚本库链接磁盘目录，将 .sql/.js/.json 脚本纳入仓库管理
  • 在 Claude Code、Cursor 等支持 MCP 的 agent 中受控地查询和修改数据库
