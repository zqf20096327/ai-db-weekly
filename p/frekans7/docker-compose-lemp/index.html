基于官方 Alpine Docker 镜像的 LEMP 开发环境编排模板

综述（解读层）

该项目提供一组 Docker Compose 配置文件，通过编排 nginx:1.30.4-alpine、php:8.4.11-fpm-alpine、mariadb:12.3.2 和 phpmyadmin:5.2.3 四个官方镜像启动 LEMP 栈。环境变量支持自定义镜像版本、数据库账号和端口映射（默认 Web 8080、phpMyAdmin 8183）。部署前需在 .env 中修改默认的 change-me 密码，README 未提及生产环境配置说明。

  • 提供基于 Docker Compose 的 LEMP 栈编排，包含 Nginx 1.30.4、PHP-FPM 8.4.11、MariaDB 12.3.2 与 phpMyAdmin 5.2.3
  • 通过 .env 文件配置各镜像版本、数据库参数（MYSQL_ROOT_PASSWORD、MYSQL_DATABASE 等）及端口（NGINX_PORT、PMA_PORT）
  • 提供 docker compose 启动、停止及移除（含删除数据卷选项 down -v）的操作命令

适用场景（解读层）

  • 本地启动 PHP 网页开发环境，通过 http://localhost:8080 访问 Web 服务
  • 需要 MariaDB 数据库及 phpMyAdmin 管理界面的 PHP 项目开发
  • 需要自定义镜像版本或端口映射的容器化 LEMP 环境搭建
