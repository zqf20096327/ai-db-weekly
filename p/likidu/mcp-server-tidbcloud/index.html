面向 TiDB Cloud 的 MCP 服务器，通过 OpenAPI 和数据库连接供 LLM 调用

综述（解读层）

该项目是一个 MCP 服务器，使 LLM 能以自然语言操作 TiDB Cloud：提供集群与分支的增删改查、区域查询，以及 show_databases、db_query、db_execute 等数据库工具。支持 stdio（本地）和 Streamable HTTP（远程）两种传输方式，需要 Node.js 22+、pnpm 和具备 API 访问权限的 TiDB Cloud 账户。集群/分支创建等操作为异步，需用对应 get 工具查询状态；db_query 仅允许 SELECT、SHOW、DESCRIBE、EXPLAIN。README 建议用于本地开发与 IDE 集成，执行前需人工审核 LLM 请求的操作。

  • 提供集群与分支管理工具（创建、列表、查询、更新、删除），创建为异步操作，配 get 工具检查状态
  • 提供数据库操作工具：db_query 仅允许只读语句（SELECT/SHOW/DESCRIBE/EXPLAIN），db_execute 支持修改数据或 schema
  • 支持 stdio 与 Streamable HTTP 两种传输方式，API 密钥分别通过环境变量或请求头传递

适用场景（解读层）

  • 在 Claude Desktop 或 IDE 集成中通过自然语言管理 TiDB Cloud Serverless 集群与分支
  • 通过 LLM 执行 SQL 查询与 schema/数据变更、管理数据库用户
  • 托管部署场景下通过 mcp-remote 以 HTTP 方式远程连接使用
