综述（解读层）

ArcadeDB 是一个基于 Java 21+ 编写的多模型事务型 DBMS，源自 OrientDB 创始人发起的概念分支，复用了其 SQL 引擎（大量改造）。它支持图、文档、键值、搜索引擎、时序、向量、地理空间七类模型及 SQL、Cypher、Gremlin 等五种查询语言，可嵌入 JVM 或通过 HTTP/Postgres/Redis/MongoDB 协议远程访问。兼容性方面 MongoDB、Redis 仅实现操作子集，使用时需注意。

  • 支持图、文档、键值、搜索引擎、时序、向量嵌入、地理空间七种数据模型
  • 支持 SQL、Neo4j Cypher、Gremlin、GraphQL、MongoDB 查询语言，并实现 Postgres Wire 协议
  • 支持 ACID 事务、全文索引、地理空间查询、70+ 内置图算法、物化视图及内置 MCP Server

适用场景（解读层）

  • 需要同一数据库同时处理图遍历、向量相似度和时序数据的推荐引擎场景
  • 通过 JVM 嵌入方式在应用内使用，或经 Docker/Kubernetes 部署的服务端场景
  • 知识图谱、Graph RAG、反欺诈等需要多语言查询（Cypher/SQL/Gremlin）的场景
