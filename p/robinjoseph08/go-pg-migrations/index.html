配合 go-pg/pg 使用的 Go 数据库迁移工具包

综述（解读层）

这是一个基于 go-pg/pg 的迁移包，通过在 main 包中调用 migrations.Run 并配合 create、migrate、status、rollback 等命令管理 PostgreSQL 迁移文件。它采用时间戳前缀命名迁移、完整 diff 判断待执行迁移、支持迁移锁与按批次回滚，依赖 Go modules 及 go-pg v10，也可编译为独立二进制在无 Go 工具链的镜像中运行。

  • 提供 create、migrate、status、rollback、help 五个子命令，通过 migrations.Run 或 RunWithOptions 调用
  • 使用时间戳前缀命名迁移文件，并支持完整迁移 diff、迁移锁机制与按批次回滚
  • 支持逐个迁移选择是否在事务中执行，并可在无 Go 工具链的 Docker 镜像中以编译后的二进制运行

适用场景（解读层）

  • 使用 go-pg/pg 的 Go 项目需要管理 PostgreSQL 数据库 schema 迁移
  • 多人协作或自动部署环境下需要避免迁移版本冲突与并发执行
  • 部署环境（如 scratch/alpine 镜像）无 Go 工具链时需运行迁移
