基于 Docker Compose 的 PHP 多容器开发环境套件

综述（解读层）

DockBox 是一个用 Docker Compose 编排的 PHP 开发环境，面向 PHP/Web 开发者，用于在本地搭建无需逐一安装软件的运行环境。它提供多个可组合的容器：Apache/Nginx、PHP 5.6/7.0/7.1（含 XDebug、Composer、PHPUnit、Laravel、Symfony 等工具）、MySQL、Postgres、MongoDB、Redis 等数据库与中间件。通过 .env 与两套 docker-compose 模板（SIMPLE/FULL）选择启用容器；README 为西班牙语，组件版本基于 2017 年（Ubuntu 16.04），已较为陈旧。

  • 通过 docker-compose 按需组合 apache2/nginx、php-fpm 及多种数据库、缓存、搜索、消息队列容器
  • 服务器容器内置 Composer、PHPUnit、Deployer、NodeJs、Webpack 等命令行工具，可经 exec 或 SSH 进入执行命令
  • 提供 dockerup/dockerdown/dockerrebuild 别名脚本及 .env 配置，可设定 PHP 版本、容器 IP、PUID/PGID 等

适用场景（解读层）

  • 本地搭建多项目 PHP 开发环境并配置虚拟域名访问
  • 运行依赖多种数据库或中间件（MySQL/Postgres/MongoDB/Redis/Elasticsearch 等）的 PHP 应用开发与测试
  • 按文档配置 PHPStorm 进行 XDebug 调试
