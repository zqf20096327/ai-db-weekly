单用户 OpenTelemetry 遥测容器，Go + 内嵌 chDB，集成日志/错误/RUM/AI 采集分析

综述（解读层）

SOBS 是一个面向单用户的 OpenTelemetry 兼容可观测性容器，采集日志、错误、追踪、RUM、Web 流量和 LLM 调用记录。后端为 Go 单进程内嵌 chDB，内存占用 768 MB-1 GB，支持 Docker/Kubernetes 运行，可独立部署或作 sidecar。当前为 v0.1.0-beta.2 公开测试版，API 与 UI 行为在稳定版前可能变动；AI/GitHub 写入与 OSV 集成的请求体构造尚未完成。

  • 接受 OTLP（JSON 与 protobuf）格式的日志、追踪、指标数据，并提供 RUM JS 片段采集 Web Vitals（LCP、CLS、INP、TTFB、FCP）
  • 使用 Go 单进程与内嵌 chDB 存储，MergeTree 架构采用 ZSTD 压缩与选择性 Delta/T64 编码，支持 TTL 保留窗口和 S3 备份恢复
  • 提供正则/SQL WHERE 日志过滤、实时 SSE tail 流、通知渠道（Slack/webhook/邮件/浏览器推送）以及基于规则的指标异常检测

适用场景（解读层）

  • 本地开发环境中的应用可观测性数据采集与查看
  • 集成和测试环境中的轻量级遥测收集，保持环境隔离
  • 多租户场景下每个租户独立运行实例以实现数据隔离
