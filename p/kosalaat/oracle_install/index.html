在 RHEL/CentOS 6/7 上安装 Oracle 11g/12c 的 Ansible role

综述（解读层）

该项目是一个 Ansible role，用于在 RedHat/CentOS 6/7 服务器上安装 Oracle 11g 与 12c。使用时将仓库克隆到项目 roles 目录，需自定义安装包路径（oracle_installer_path）与镜像列表（oracle_images）两项参数，即可按 SID 创建数据库实例或仅安装软件二进制。要求存在或可创建逻辑卷组（默认 oravg），安装包默认解压到 /tmp/oracle；12c 需大于 10GB 的卷组空间。

  • 支持 Oracle 11g（11.2.0.1）与 12c（12.2.0.1）两个版本的安装包配置
  • 既支持创建带 SID 的数据库实例，也支持仅安装软件二进制
  • 可通过 oracle_vg/oracle_pvs 变量指定或自动创建逻辑卷组

适用场景（解读层）

  • 在 RHEL/CentOS 6/7 服务器上批量自动化部署 Oracle 数据库
  • 只需安装 Oracle 软件二进制、暂不建库的环境准备
  • 使用已有卷组或双磁盘环境的标准 Oracle 安装场景
