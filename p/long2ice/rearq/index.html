基于 asyncio 和 Redis 的分布式任务队列，改写自 arq 并内置 Web 界面

综述（解读层）

ReArq 是基于 asyncio 和 Redis 的分布式任务队列，从 arq 重写而来。支持延迟任务、cron 定时任务和异步任务，内置分布式任务锁与 Web 管理界面。依赖 Redis ≥5.0，可选 MySQL 或 PostgreSQL 后端，通过 pip 安装，命令行启动 worker 和 timer 进程，可作为 FastAPI 子应用挂载，采用 Apache-2.0 许可证。

  • 支持延迟任务、cron 定时任务和异步任务
  • 内置分布式任务锁，使同一任务同时只运行一次
  • 提供 Web 界面和 API 文档，可挂载为 FastAPI 子应用或在应用内启动 worker

适用场景（解读层）

  • 在 FastAPI 应用中集成异步任务处理
  • 需要 cron 定时或延迟执行的任务调度
  • 通过 Web 界面查看任务、结果与 job 状态的管理场景
