从 MySQL/PostgreSQL/SSH 等数据源备份数据到 S3 等存储的工具

综述（解读层）

databack 是一个数据备份工具，用于将 MySQL、PostgreSQL、SSH 及本地数据源备份到 S3、SCP、本地等存储。它支持通过 cron 定时自动备份，并可从备份文件恢复数据，提供 Web UI 管理备份任务。部署依赖 Redis 与数据库连接，推荐使用 docker-compose，工作进程可通过 WORKER 环境变量或独立命令启动，支持多 worker 扩展。项目采用 Apache-2.0 许可证，界面支持英文和中文。

  • 支持 MySQL/PostgreSQL/SSH/本地作为数据源，S3/SCP/本地作为备份存储
  • 支持 cron 定时任务自动备份，并支持从备份文件恢复数据
  • 提供 Web UI 管理备份任务，支持多 worker 运行和 i18n（英文/中文）

适用场景（解读层）

  • 通过 cron 定时将数据库备份自动上传到 S3 等远程存储
  • 通过 Web UI 集中管理多个数据源的备份任务并执行恢复
  • 需要中英文界面与多 worker 并行执行备份任务的环境
