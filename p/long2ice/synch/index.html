将 MySQL/PostgreSQL 数据同步到 ClickHouse 的 ETL 工具

综述（解读层）

synch 是一个基于 Python 的数据同步工具，用于将 MySQL 和 PostgreSQL 的数据同步到 ClickHouse，支持全量 ETL 和基于 binlog 的实时增量同步。它通过 redis 或 kafka 作为 broker 传递变更消息，支持 DML 与部分 DDL 同步，可部署为多个 producer/consume 进程。需注意 DDL 同步不支持 postgres，且表需包含非空主键或唯一键。

  • 支持全量 ETL 与实时增量 ETL，增量基于 MySQL binlog 监听
  • 支持 Kafka 和 Redis 作为 broker，可将多个源库同时同步到 ClickHouse
  • 支持 MergeTree、CollapsingMergeTree、VersionedCollapsingMergeTree、ReplacingMergeTree 表引擎及 ClickHouse 集群

适用场景（解读层）

  • 将 MySQL 业务库数据持续同步到 ClickHouse 用于分析查询
  • 在持续增量同步前对指定表执行全量数据 ETL
  • 通过 docker-compose 部署 Redis 或 Kafka broker 模式的同步服务
