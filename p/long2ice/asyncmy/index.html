基于 Cython 实现协议核心的 asyncio MySQL/MariaDB 驱动，API 兼容 aiomysql

综述（解读层）

asyncmy 是面向 Python 3.10+ 的 asyncio MySQL/MariaDB 驱动，将协议核心用 Cython 重写，保留 aiomysql 的 API 与游标语义，可直接替换。它提供服务端预处理语句（可经 stmt_cache_size 对常规 Cursor 透明启用）、内置连接池、密码轮换回调、语句日志，以及基于 asyncio 的 binlog 复制协议支持。默认 autocommit=False 且不缓存语句，二进制协议下 FLOAT 返回精确存储值。

  • 提供 create_pool() 连接池，连接可复用并缓存预处理语句
  • 通过 conn.prepare() 或缓存 Cursor 调用实现服务端预处理语句（二进制协议）
  • 实现 MySQL 复制协议（BinLogStream），可在 asyncio 下读取 binlog

适用场景（解读层）

  • 需要异步访问 MySQL/MariaDB 且希望沿用 aiomysql 代码的应用
  • 重复执行同类查询、希望启用服务端预处理语句的场景
  • 订阅 MySQL binlog 进行数据复制的程序
