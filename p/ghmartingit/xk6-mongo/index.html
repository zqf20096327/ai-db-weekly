🧭 简介解读层（AI·证据行可回查）

x6-k6 的 MongoDB 扩展，在 k6 性能测试脚本中读写 MongoDB

综述（解读层）

xk6-mongo 是 k6 的扩展，通过 xk6 重新编译 k6 二进制后，可在 JavaScript 测试脚本中调用 MongoDB 的 CRUD、聚合、BulkWrite、索引管理、Change Streams 和事务等 API。面向需要在性能测试中让虚拟用户直接操作 MongoDB 的测试工程师。事务与 Change Streams 要求副本集或分片集群；连接超时 10 秒，操作超时 30 秒。

  • 提供 CRUD、Upsert、Aggregate、Distinct、CountDocuments、BulkWrite 等数据库操作 API
  • 支持基于 Session 的事务和 Change Streams（需副本集），并提供索引的创建、删除与列举
  • 连接超时 10 秒、操作超时 30 秒，可配置连接池的 max/min pool size

适用场景（解读层）

  • 在 k6 负载测试脚本中生成或校验 MongoDB 数据
  • 验证 MongoDB 副本集/分片集群在并发写入下的事务行为
  • 编写包含聚合管道、索引管理与批量写入的数据层测试场景
