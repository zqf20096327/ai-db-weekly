基于 Ansible Playbook 部署 pg_auto_failover PostgreSQL 高可用集群

综述（解读层）

该项目提供一组 Ansible Playbook，用于在 Ubuntu 节点上自动搭建由 1 个 monitor 节点和 2 个数据库节点组成、带同步复制的 PostgreSQL 集群，支持 PostgreSQL 12/13/14 与可选 pgbouncer。使用前需自行生成证书、配置 inventory 与 SSH 密钥；备份配置、旧节点移除需手动处理。适合需要通过 Ansible 自动化部署 pg_auto_failover 集群的运维人员。

  • 自动搭建含 1 个 monitor 节点和 2 个数据库节点、启用同步复制的集群
  • 支持 Ubuntu 18.04/20.04 和 PostgreSQL 12/13/14
  • 提供基础 pgbouncer 配置支持（默认未启用），并内置基于 Vagrant 的测试脚本

适用场景（解读层）

  • 在 Ubuntu 环境中自动化部署 pg_auto_failover PostgreSQL 高可用集群
  • 通过修改 inventory 重新运行 Playbook 向集群添加新数据节点
  • 使用 Vagrant 和 VirtualBox 在本地验证集群部署流程
