基于 XPO ORM 与 ASP.NET Core OData 8 构建 OData v4 REST API 的示例项目

综述（解读层）

该项目演示如何在 .NET 8（ASP.NET Core）中创建 OData v4 服务：安装 DevExpress.Xpo 与 Microsoft.AspNetCore.OData 包，定义 XPO 持久类与 EDM 模型，配置数据库连接字符串与中间件依赖注入，并实现继承 ODataController 的控制器。附带演示数据生成、自定义 Action/Function（InitializeDatabase、TotalSalesByYear）等辅助文件，默认使用 SQL Server LocalDB。

  • 演示 XPO 数据模型到 EDM 模型的两种填充方式，并支持添加自定义 OData Actions 和 Functions
  • 通过继承 ODataController 的控制器实现 Get/Post/Put/Patch/Delete 等 CRUD 方法
  • 提供演示数据生成、LINQ 与 OData API 扩展的辅助代码文件

适用场景（解读层）

  • 需要基于 XPO ORM 构建 OData v4 REST API 的 .NET 8 服务
  • 需要为 XPO 持久类暴露 CRUD 接口及自定义 Action/Function
  • 需要将 XPO 数据模型映射到已有数据库表并通过 Web API 访问
