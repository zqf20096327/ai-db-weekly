原生 macOS 应用，本机接收 OTLP 并即时展示追踪与日志

综述（解读层）

Magnife 是一款原生 macOS 应用，在本机 127.0.0.1 的 4317（gRPC）和 4318（HTTP）端口接收 OTLP 数据，展示追踪、日志及慢 SQL、N+1、HTTP 错误等检测结果，数据以 SQLite 持久化。面向在 Mac 上以 .NET、Go、Node、Python 或 Java 接入 OpenTelemetry 的后端与全栈开发者。架构上由 Go 写入进程与 SwiftUI 只读应用共享一个数据库文件，需 macOS 26 及以上。

  • 内置 OTLP 接收器监听 127.0.0.1:4317（gRPC）与 4318（HTTP/protobuf/JSON），应用启动即监听；追踪数据以 SQLite（WAL 模式）本地持久化，重启后可查看
  • 提供瀑布图与 span 详情、按级别/服务过滤的日志视图、⌘K 查询语言搜索，以及命名查询与路由的慢 SQL、N+1、失败 HTTP 检测
  • 附带 MCP 服务器 magnife-mcp，向 Claude Code、Codex、Cursor 等编码代理提供七个只读工具（列出追踪、读取 span、搜索日志、对比追踪等），并支持通过 OTLP JSON Lines 文件导入导出追踪

适用场景（解读层）

  • 本地开发时查看本机服务的 OpenTelemetry 追踪与日志，替代在 Docker 中运行收集器或浏览器查看器
  • 排查本地请求中的慢 SQL、N+1 查询与失败 HTTP 调用等具体问题点
  • 让接入 MCP 的编码代理读取本地追踪数据，在修改代码时查询运行时表现
