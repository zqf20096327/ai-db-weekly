🧭 简介解读层（AI·证据行可回查）

基于 Tree-sitter 的多语言代码图系统，将源码解析为多类图数据存入 SQLite

综述（解读层）

CodeOrion 通过 tree-sitter-language-pack 集成 173 种语言的语法，将源码解析为统一 IR，构建 CST 图、调用图、数据流图、框架端点图和依赖调用图并存入 SQLite。它提供 CLI、Python SDK 和 MCP Server（35 个工具），输出结构化事实供 AI Agent 做漏洞推理，本身不内置漏洞判定规则。Java/Go/Python 有深度增强分析，其他语言仅具备基础能力。

  • 通过 tree-sitter-language-pack 支持 173 种语言的 CST 解析，主力支持 Java/Python/Go/C#/JS/TS/Rust/Ruby/PHP/C/C++ 等约 19 种语言的基础语义分析（符号表、调用图、DFG、CFG、类型图）
  • 提供语言增强能力：Java 支持 Spring/JAX-RS/Servlet 端点检测、DI 注入消解、Maven/Gradle 依赖解析及基于 SootUp 的 JVM 字节码级分析；Python 支持 Flask/FastAPI/Django 端点检测与 ast/ts 双引擎；Go 支持 receiver 解析与三级降级的依赖源码展开
  • 图数据统一存储于单一 SQLite（WAL 模式）数据库，CLI 所有命令支持 --json 输出，并通过 FastMCP 暴露 35 个工具和 3 个资源

适用场景（解读层）

  • 为 AI Agent 的漏洞挖掘流程提供可解释的代码结构事实（调用链、数据流、HTTP 端点、跨边界依赖调用），由 Agent 自行完成漏洞推理
  • 对多语言代码库进行静态结构索引，使用 query 子命令查询调用者/被调用者、HTTP 端点、依赖图及跨边界调用链
  • 以 Python SDK 或 MCP Server 方式集成到自动化分析管线，配合 SafetyPolicy（strict/默认/lenient）控制文件大小、远程 grammar 与代码执行等安全限制
