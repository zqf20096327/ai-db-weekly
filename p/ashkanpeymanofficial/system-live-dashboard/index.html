基于 .NET 8、SignalR 与 Chart.js 的实时系统监控仪表盘

综述（解读层）

该项目读取 CPU（按线程）、内存、网络速度、磁盘用量及内存占用前 5 的进程，经 SignalR 实时推送至浏览器页面，无需刷新。指标通过 EF Core 存入本地 SQLite，支持查看 1 或 24 小时历史趋势、CSV 导出，并在 CPU 超 80% 或内存超 90% 时显示脉冲提示。需要 .NET 8 运行环境，依赖 LibreHardwareMonitorLib 读取硬件信息。

  • 通过 SignalR 向浏览器实时推送 CPU、内存、网络、运行时长数据，无需页面刷新
  • 使用 SQLite + EF Core 存储指标，提供 1/24 小时历史趋势图与 CSV 导出
  • CPU 超过 80% 或 RAM 超过 90% 时显示视觉脉冲提醒

适用场景（解读层）

  • 监控单台 Windows/本机开发环境的 CPU、内存与网络状态
  • 查看系统资源的历史趋势并导出 CSV 做外部分析
  • 需要在资源占用超过阈值时获得界面提示的场景
