🧭 简介解读层（AI·证据行可回查）

基于 quorum 的分布式事务预写日志，用于事务复制

综述（解读层）

Waltz 是 WePay 开源的分布式复制写前日志（WAL），用于事务复制，面向需要在分布式环境中记录事务日志的系统构建者。它使用 Java/Gradle 构建，依赖 ZooKeeper 协调，提供本地 Docker 测试集群脚本和冒烟测试，可在服务器节点随机启停的情况下写入百万级事务并校验数据校验和，还附带基于 MySQL 的账户余额示例应用。

  • 提供 quorum 机制的分布式复制写前日志，用于事务复制
  • 内置冒烟测试：3 个 server 节点、3 个 storage 节点与 ZooKeeper，随机启停节点后验证事务完整性与校验和
  • 提供 Docker 脚本搭建本地测试集群，支持多分区配置（WALTZ_TEST_CLUSTER_NUM_PARTITIONS）

适用场景（解读层）

  • 为需要事务复制的应用提供预写日志层
  • 在本地 Docker 环境中搭建测试集群进行分布式日志相关开发与验证
  • 参考其 demo 应用（基于 Waltz 的账户余额数据库 + MySQL）构建上层应用
