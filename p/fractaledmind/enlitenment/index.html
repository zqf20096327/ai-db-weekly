Rails 应用模板脚本，为 Rails 应用配置基于 SQLite 的组件栈

综述（解读层）

enlitenment 是一个 Rails application template 脚本，用于在新建或已有 Rails 应用中安装并配置 SQLite 连接及 Solid Queue、Solid Cache、Solid Cable、Solid Errors、Litestream 五个组件。它通过环境变量控制安装范围（全局或仅生产环境）、跳过指定组件或步骤、自定义各组件独立 SQLite 数据库名与 Web 控制台路由，并为控制台提供 HTTP 基础认证等安全配置。

  • 支持通过 rails new --template 或 bin/rails app:template 应用到新建或已有 Rails 应用
  • 为每个组件使用独立的 SQLite 数据库，名称可通过 QUEUE_DB 等环境变量配置
  • 各组件安装流程可通过 SKIP_* 环境变量整体跳过，或按单个步骤跳过

适用场景（解读层）

  • 新建 Rails 应用时一次性配置 SQLite 及 Solid 系列组件
  • 为已有 Rails 应用追加后台任务、缓存、WebSocket、错误监控与备份配置
  • 按需选择性安装部分组件，或自定义数据库名与控制台路由
