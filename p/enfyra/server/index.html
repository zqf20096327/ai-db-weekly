开源自托管 BaaS，从数据库表自动生成 REST 与 GraphQL API

综述（解读层）

Enfyra 是一个开源、自托管的 BaaS 平台，用户通过可视化界面建表后，系统自动生成对应表的 REST 与 GraphQL API。它提供基于 JWT 的认证、文件存储、WebSocket 实时推送及服务端 Functions，支持 MySQL、PostgreSQL、MariaDB 和 MongoDB。模式迁移由 TypeScript 快照定义、JSON 声明非增量变更，且破坏性操作需 confirm-hash 二次确认。适用于希望以数据库表为中心快速搭建后端服务的开发者。

  • 根据表结构自动生成 REST 与 GraphQL API，无需手写接口代码
  • 内置 Query Engine、JWT 认证服务、文件存储 API、WebSocket 实时推送与服务端 Functions
  • 模式迁移采用 TypeScript 快照加 JSON 手工声明，破坏性 API 操作带 confirm-hash 保护机制

适用场景（解读层）

  • 通过可视化建表快速生成后端 API 的应用开发
  • 需要认证、文件管理与实时数据推送的自托管后端服务
  • 对 SQL 与 MongoDB 数据库做结构化模式迁移管理
