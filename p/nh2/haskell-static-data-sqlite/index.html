🧭 简介解读层（AI·证据行可回查）

演示用 SQLite append VFS 将静态数据追加到 Haskell 可执行文件的示例。

综述（解读层）

该项目提供示例代码，展示如何借助 SQLite 的 append VFS 把数据库文件追加到 Haskell 可执行文件末尾，再以只读方式从程序内查询数据。构建使用 stack，追加数据用 sqlite3 命令行的 --append 参数。适合需要随可执行文件分发查找表、白名单等静态数据的开发者；需在 .cabal 中链接 appendvfs.c。

  • 使用 sqlite3 --append 命令即可将数据库追加到可执行文件，修改数据无需重新编译或重新链接
  • 追加后的数据可用 sqlite-simple 等包以普通 SQLite 数据库方式只读查询
  • README 中还列出了 file-embed、自定义汇编嵌入、compact region 序列化等其他嵌入方式的机制与限制

适用场景（解读层）

  • 为面向 Amazon Lambda 或自包含部署构建的静态可执行文件附带数值查找表、白名单或示例数据
  • 希望在不重新编译、不重新链接的情况下更新可执行文件内的静态数据
  • 需要用 SQL 直接查询嵌入数据，或用 sqlite3 工具检查、修改其中的内容
