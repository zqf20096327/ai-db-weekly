综述（解读层）

r0b0tlabbra1n 是一个面向 Hermes 及其他 CLI Agent 的本地、可审计记忆系统。知识以可读可编辑的 Markdown 保存，Obsidian wikilink 提供导航，索引为可重建的加速层。提供 FTS5 搜索、分层上下文包、漂移检测、秘密扫描写入防护与检索评测。通过 Python venv 安装后以 brain CLI 运行，附 MCP JSON 门面，MIT 许可。

  • 以 Markdown 为唯一真源，索引可在任意时刻从源文件重建
  • 内置 FTS5/BM25 搜索、链接图、backlinks、gold-query 检索评测（65 条）
  • 写入路径带秘密扫描，覆盖 OpenAI/AWS/JWT 等常见密钥模式；会话读取以只读 SQLite 模式进行

适用场景（解读层）

  • 为 Hermes 等 CLI Agent 搭建本地持久化知识/记忆库
  • 需要人工可编辑、可 diff、可审计的 Agent 记忆方案
  • 在本地 LLM 环境做带质量评测的知识检索
