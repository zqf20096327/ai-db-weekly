管理 SQL Server、PostgreSQL、MySQL 数据库集群更新的命令行工具

综述（解读层）

SQL Build Manager 是一个 .NET 命令行工具，用于管理 SQL Server、PostgreSQL 和 MySQL 数据库的生命周期更新。它将脚本打包为 .sbm 文件，以事务方式执行，任一脚本失败即整体回滚，并在数据库中记录构建历史。支持本地、线程化以及 Azure Batch、Kubernetes、Container Apps、ACI 远程并行执行。注意：PostgreSQL/MySQL 不支持 DACPAC 操作和基于 SMO 的对象脚本。

  • 支持 SQL Server、PostgreSQL、MySQL 三种数据库平台，通过 --platform 参数在运行时选择
  • 提供本地、线程化及 Azure Batch、Kubernetes、Container Apps、ACI 六种构建执行方式，可在数千个数据库上并行运行
  • 构建以全有或全无事务执行，任一脚本失败则回滚；包内脚本使用 SHA-1 哈希校验完整性

适用场景（解读层）

  • 需要批量更新大量 SQL Server、PostgreSQL 或 MySQL 数据库的运维团队
  • 需要跨多个数据库并行执行 SELECT 查询并汇总结果
  • 依赖 Azure Batch/Kubernetes/Container Apps 等平台进行大规模并行构建分发
