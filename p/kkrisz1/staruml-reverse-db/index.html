StarUML 扩展，从数据库 schema 生成 ER 数据模型

综述（解读层）

这是一个 StarUML v5 的扩展，用于从数据库 schema 生成 ER Data Model，支持 MS SQL Server、PostgreSQL 和 MySQL。使用时先在 Tools > Database 菜单下配置数据库连接，再通过菜单或快捷键生成模型；表转换为 ERDEntity，列、关系等按规则映射为对应的 ERD 元素。README 说明它不提供完整的逆向工程功能，需要完整功能的用户需使用专业工具。生成结果写入当前项目，无打开项目时自动创建。

  • 支持从 MS SQL Server、PostgreSQL、MySQL 三种数据库读取 schema 并生成 ER Data Model
  • 按规则将表、列、关系、关系端点转换为 ERDEntity、ERDColumn、ERDRelationship、ERDRelationshipEnd 等模型元素
  • 提供菜单入口和快捷键（Alt+Shift+M/L/P）触发生成，模型写入当前项目

适用场景（解读层）

  • 基于已有 SQL Server / PostgreSQL / MySQL 数据库生成 ER 数据模型用于在 StarUML 中绘制 ER 图
  • 需要在 StarUML 项目中查看表结构（列属性、主键、外键、唯一约束等）的场景
  • 从数据库外键关系生成 ERDRelationship 及其端点基数信息的场景
