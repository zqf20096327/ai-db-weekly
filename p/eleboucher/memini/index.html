🧭 简介解读层（AI·证据行可回查）

面向 MCP agent 的共享持久记忆服务，Go 单二进制实现分层存储与混合检索

综述（解读层）

memini 为支持 MCP 的 agent（如 Claude Code、Cursor、opencode 等）提供统一的 remember/recall 记忆服务。采用工作、情景、语义、程序四层记忆并支持衰减，检索用向量加关键词的混合方式并经 RRF 融合与重排序。以 Go 单二进制运行，存储可选嵌入式 sqlite-vec 或 Postgres + VectorChord，LLM 为可选项，AGPL-3.0 授权。

  • 提供 REST、MCP（stdio 与 Streamable HTTP）及内嵌 Web UI 三种接口，共享同一服务层
  • 分层记忆（工作、情景、语义、程序）配合 TTL、衰减与近重复折叠
  • 支持可选 LLM 后台去重与矛盾消解，无 LLM 时以标记启发式运行相同生命周期

适用场景（解读层）

  • 为多个 agent 配置共享或按命名空间隔离的持久记忆
  • 部署无状态 HTTP 记忆服务并接入 Prometheus 监控
  • 在无 LLM 的纯 embedding 环境下运行记忆生命周期管理
