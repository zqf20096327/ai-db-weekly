数据库保全工具箱：命令行与Java库，在DBMS与SIARD保存格式间转换

综述（解读层）

Database Preservation Toolkit 是一个 Java 库与命令行工具，用于数据库保存操作：将 MySQL、PostgreSQL、Oracle、SQL Server 等在用或备份的关系数据库转换为 SIARD 1/2/DK 保存格式，也可将保存格式载回 DBMS。采用输入/输出模块架构，可经 JDBC 驱动接入未专门支持的数据库（README 提示该路径转换质量依赖驱动、无法保证）。需 Java 21 及以上运行。

  • 支持与 MySQL/MariaDB、PostgreSQL、Oracle、Microsoft SQL Server、Microsoft Access、Progress OpenEdge、Sybase ASA 连接，并可用 JDBC 模块接入其他数据库
  • 支持在上述 DBMS 与 SIARD 1、SIARD 2、SIARD DK 保存格式之间双向转换
  • 以模块化平台实现，通过实现新接口并添加驱动即可新增输入/输出模块

适用场景（解读层）

  • 将在用数据库导出为 SIARD 格式用于数字保存归档
  • 将 SIARD 保存格式中的数据库重新载入在用 DBMS 以恢复完整功能
  • 通过 JDBC 驱动类与连接字符串接入未提供专用模块的数据库
