纯 Java 实现的线程安全嵌入式 KV 存储，基于 LSM-tree 架构

综述（解读层）

DataStore4J 是一个用 Java 编写的键值存储库，采用受 LevelDB 启发的 LSM-tree 架构，作为零配置嵌入式库运行。它通过 Write-Ahead Logging 保障写入、支持 mmap 与 FileChannel 两种 I/O 方式。面向需要在 Java 应用内嵌 KV 存储的开发者。要求 Java 22+；README 明确列出压缩期间崩溃可能导致数据不一致等已知限制，当前版本为 0.1.0。

  • 纯 Java 实现，无 JNI 或本地代码
  • 写前使用 WAL 日志，memtable 刷新前落盘
  • 支持内存映射文件与 FileChannel I/O，用 Arena 管理映射内存

适用场景（解读层）

  • 需要嵌入 Java 应用的键值存储场景
  • 无需本地依赖、仅用 JVM 运行时的部署环境
  • 学习 LSM-tree 存储引擎设计的参考实现
📖 README 首段存档原文 · 程序抽取

A thread-safe, high-performance key-value store, built on an LSM-tree architecture inspired by LevelDB, and written entirely in Java.
