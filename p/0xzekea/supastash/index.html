面向 React Native 的 Supabase 与 SQLite 离线优先同步引擎

综述（解读层）

Supastash 是一个 npm 库，用于在 React Native、Expi 及实验性 Tauri 桌面应用中，将 Supabase 数据与本地 SQLite 双向同步。它通过 replication cursor 跟踪行变更，提供冲突处理、失败重试和分批后台同步。使用前需安装 supabase-js 与 NetInfo 等对等依赖，且 Supabase 表必须含 id 主键及 timestamptz 时间戳列，启用 server-side 复制模式还需额外的 arrived_at 列与服务器触发器。

  • 支持 Supabase 与 SQLite 之间的双向同步及 INSERT、UPDATE、DELETE 的实时更新
  • 内置冲突处理、同步重试、分批更新、行级过滤和分阶段任务处理
  • 兼容 expo-sqlite、react-native-nitro-sqlite、react-native-sqlite-storage 及实验性的 tauri-plugin-sql 四种 SQLite 客户端

适用场景（解读层）

  • 需要在弱网或离线状态下继续读写数据、恢复联网后与 Supabase 同步的移动应用
  • 基于 Expo 或 React Native 并使用 SQLite 做本地缓存的应用
  • 依赖 Supabase Realtime 保持多端数据一致的仪表盘或聊天类应用
