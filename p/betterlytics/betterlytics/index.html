开源网站分析工具，集成会话回放、错误追踪与性能监控，基于 Rust 与 ClickHouse。

综述（解读层）

Betterlytics 是一个开源（AGPL-3.0）的网站分析工具，将页面访问统计、会话回放、错误追踪、Core Web Vitals 与正常运行时间监控集成在同一仪表盘中。采用无 Cookie 追踪，提供 EU 托管云服务或通过 Docker 自托管。技术栈为 Rust、ClickHouse、Next.js 与 PostgreSQL，适用于需要网站数据统计的团队。

  • 提供页面访问、访客、跳出率、流量来源、自定义事件等核心分析功能
  • 支持会话回放、用户路径、漏斗分析及自动分组的客户端错误追踪
  • 支持 Core Web Vitals（LCP、INP、CLS、TTFB）监控、SSL 证书监控与公共状态页

适用场景（解读层）

  • 需要在同一仪表盘中查看网站流量、错误与性能数据的团队
  • 受 GDPR/CCPA 合规要求约束、倾向无 Cookie 追踪或 EU 托管的网站
  • 希望自托管并保留数据控制权的基础设施团队
