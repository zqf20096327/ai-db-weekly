Diesel ORM 对 Turso 数据库的异步后端与连接实现

综述（解读层）

diesel-turso 为 Rust 的 Turso 数据库提供 Diesel 后端和连接实现，使开发者能在 Turso（兼容 SQLite 的进程内数据库）上使用 Diesel 的类型安全查询构建。项目通过 diesel-async 提供 async/await 支持，并可选接入 bb8、deadpool、mobc、r2d2 连接池。README 标明项目处于早期开发阶段，不适用于生产环境，且并非所有 Diesel 功能均已支持，文档不完整。采用 MIT 许可证，当前需通过 Git 依赖引入。

  • 通过 diesel-async 提供 async/await 支持，并实现自定义 Turso 后端
  • 通过 feature flags 支持 bb8、deadpool、mobc、r2d2 四种连接池
  • 提供可选的 chrono 日期/时间类型支持（默认启用）

适用场景（解读层）

  • 在 Rust 项目中以 Diesel ORM 操作 Turso 数据库
  • 需要异步 SQLite 兼容数据库访问的 Rust 应用
  • 需要搭配异步连接池（如 bb8、deadpool）使用 Diesel 的场景
