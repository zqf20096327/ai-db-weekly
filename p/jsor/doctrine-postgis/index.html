连接 Doctrine ORM/DBAL 与 PostGIS 的 PHP 空间数据扩展库

综述（解读层）

jsor/doctrine-postgis 让 PHP 开发者在 Doctrine ORM 或 DBAL 中使用 PostgreSQL 的 PostGIS 空间扩展。通过注册 DBAL Middleware、SchemaManagerFactory 及 ORM 事件监听器后，实体属性可映射为 geometry/geography 列类型，值以 WKT 格式读写，并支持空间索引与大部分 PostGIS 函数注册为 DQL 函数。官方支持 PostGIS ≥3.2、PostgreSQL ≥14，MIT 许可发布。

  • 支持 geometry 和 geography 两种列类型，可通过 geometry_type 和 srid 选项配置
  • 提供对 ORM Schema Tool 和 DBAL Schema Manager 的完整支持，可为 geometry 字段定义空间索引
  • 将多数 PostGIS 函数注册为 DQL 函数，并提供 Configurator 类一次性注册全部函数

适用场景（解读层）

  • PHP 项目需在 Doctrine 实体中存储和查询点、线等空间/地理数据
  • 使用 Symfony 框架并需要集成 PostGIS 与 Doctrine
  • 需通过 Doctrine DQL 编写包含 PostGIS 空间函数的查询
