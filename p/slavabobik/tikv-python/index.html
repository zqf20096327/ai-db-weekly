🧭 简介解读层（AI·证据行可回查）

纯 Python 实现的 TiKV raw KV API 客户端，直接经 gRPC 通信，提供阻塞与 asyncio 两种接口。

综述（解读层）

该库以纯 Python 通过 gRPC 直连 TiKV 的 PD 与存储节点，实现 raw key-value API，供需要在不依赖 Rust 工具链的环境中使用 TiKV 的 Python 开发者使用。客户端维护 region 路由缓存并自动重试，提供 RawClient 与 AsyncRawClient 两套接口；限制方面，批次原子性仅限 region 内部，CAS 需启用 atomic 模式且要求所有写入端模式一致。

  • 提供完整 raw API：get/put/delete、批量操作、正向与反向范围扫描、delete_range、TTL、compare_and_swap 和 checksum，阻塞与 asyncio 客户端接口一致
  • 自动进行跨 region 路由，跟随 region 分裂、合并、leader 变更与 PD failover，每个操作有时间预算并按指数退避加抖动重试
  • 扫描采用惰性分页方式保持常量内存；支持双向 TLS，代码完整类型标注（mypy --strict），以 py3-none-any wheel 发布，依赖 grpcio 与 protobuf

适用场景（解读层）

  • 在 Python 3.10+、ARM Linux 或 slim 容器等无法方便编译 Rust 绑定的环境中接入 TiKV raw KV API
  • asyncio 应用中需要原生事件循环上的 TiKV 客户端，或需要线程安全阻塞客户端的多线程服务
  • 需要 key TTL 过期、单键原子 CAS（如分布式锁）或大规模常量内存范围扫描的 TiKV raw 存储场景
