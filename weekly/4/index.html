五万星与不停转的月度发版机器：ClickHouse 新稳定版又至

ClickHouse/ClickHouse

列式实时分析的事实标准之一走完第十年：★50k 里程碑、7 天 1,663 次提交、311 位贡献者，v26.7.34.3-stable 如期落地。

51k Star+120 本周1663 c/7天311 贡献者
阅读全文 ↓

ClickHouse 是开源列式数据库管理系统，面向实时生成分析报告的 OLAP 场景，2016 年开源、仓库即数据库本体，Apache 2.0 许可证。在站内口径里它是内核/引擎类的看板项目：唯一归属、官方仓库标记齐备，star 体量在全站 17 库生态里名列前茅。

为什么本期选它：类别轮盘 3/13 转到内核/引擎，恰好官方发版信号同时触发——v26.7.34.3-stable 于 10-18 发布（LTS 线补丁），月度发版节奏雷打不动。工程数字更能说明这台机器的成色：7 天 1,663 次提交、90 天 46,041 次、311 位贡献者、9,160 次 fork，本周 ★50,578 稳在五万星关口之上。对选型者而言，这种持续吞吐意味着缺陷修复和性能优化的到货速度都有保障。

适合谁：实时报表、用户行为分析、日志与监控这类写多读少的分析负载。风险观察点：分析型引擎不擅长事务与点查，别拿它当 OLTP 用；默认配置吃内存，资源规划要留余量；站内在册安全通告 7 条，作为常被暴露在公网的查询入口，升级与访问控制不能松。

9 个月 5,300 星：tabularis 把 MCP 服务器装进桌面 SQL 工作台

TabularisDB/tabularis

跨平台桌面客户端，3 个内置驱动加 24 个插件覆盖达梦等 24 种数据源，内置 MCP 服务器让 AI 代理直接读 schema 执行查询，7 天 122 次提交。

5.3k Star+46 本周122 c/7天83 贡献者
阅读全文 ↓

tabularis 是一个跨平台桌面 SQL 工作台：连接管理、SQL 编辑器之外，提供 SQL 笔记本（SQL 与 Markdown 混排单元、跨单元变量、图表）、交互式 ER 图、可视化 EXPLAIN 和 SSH 隧道。驱动架构分两层——PostgreSQL、MySQL/MariaDB、SQLite 三个内置，DuckDB、ClickHouse、Redis、SQL Server、Oracle、达梦等其余 24 种数据源走 JSON-RPC 插件接入，站内按支持口径归属 8 库。

为什么本期选它：双期国产主打，而它是国产工具里少见的「节奏型选手」——2026 年 1 月创建，9 个月站上 ★5,276、394 次 fork，7 天 122 次、90 天 1,090 次提交，nightly 构建发到 10-18。更值得说的是 AI 原生设计：内置 MCP 服务器，Claude、Cursor、Devin 可直接读取 schema 并执行查询，另支持基于 Ollama 本地模型的 text-to-SQL——数据不出本机。插件清单里带达梦，对国产库的适配态度也算个信号。

适合谁：想在桌面端统一管理多种数据库、又想让 AI 安全地摸库的开发者与 DBA。风险观察点：目前只有 nightly 发版、没有稳定版契约，生产依赖要谨慎；star 体量与 DBeaver（★52k）差一个量级，桌面客户端赛道竞争惨烈（本刊第 1 期写过 TablePro 与 dbx）；长期胜负手在插件生态能否滚起来。

2.4 万星停在 v3.0：pandas-ai 停维，自然语言数据分析赛道退潮

sinaptik-ai/pandas-ai

让非技术用户用自然语言问数据的明星库，一年无发版、90 天零提交登顶停维榜；与已归档的 vanna 只差 88 星，同赛道双子星同年熄火。

24k Star+15 本周0 c/7天109 贡献者
阅读全文 ↓

PandasAI 是 2023 年 AI 浪潮捧起的明星项目之一：一个 Python 库，让用户以自然语言向 DataFrame、SQL、CSV、parquet 提问，由 LLM 生成代码并在 Docker 沙箱中执行，返回答案与图表——非技术用户拿它做对话式分析，技术用户拿它省掉写分析代码的时间。★23,901、2,341 次 fork、109 位贡献者，站内按支持口径归属 PostgreSQL、MySQL、Oracle、SQL Server 4 库。

为什么登上事件席：这是本站事件信号的最高级别——千星停维。v3.0.0 发布于 2025-10-07，整整一年再无发版；最后一次推送停在 2025-10-28，90 天零提交、7 天零提交。更扎眼的是停维榜的构图：第一名 pandas-ai（★23,901）与第二名、已标记归档的 vanna（★23,813）只差 88 星——自然语言数据分析赛道的双子星在同一年双双熄火。仓库里 ee 目录与云/企业版采用单独许可，开源版与商业版的关系是值得留意的一条线索。

适合谁：已在生产使用的话，建议尽快评估迁移——上游能力并未消失，DB-GPT 等数据助手、本期板块席 tabularis 内置的 text-to-SQL、各家 BI 的 AI 功能都在吸收同一波需求；新人不建议再入坑。停维不是删除，存量代码与文档仍可用，但它不会再跟进 pandas 与模型 API 的破坏性变更，越晚迁成本越高。全站本周共 1,021 个千星级工具停维或归档，本条为其中星数最高者。
