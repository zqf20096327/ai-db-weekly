六周 3,000 星：agent-memory 把 AI 记忆写进 Markdown，SQLite 只是缓存

tigerless-labs/agent-memory

agent 关掉会话就忘掉一切——这个长期记忆运行时把 Markdown 定为唯一事实源，索引删了随时重建。开发库类本周增速第一的新贵。

3.0k Star+782 本周9 c/7天8 贡献者
阅读全文 ↓

agent-memory 解决的是 AI agent 最根本的短板：关掉会话，这次学到的一切就没了。它给自己的定位是「任意 agent 的长期记忆运行时」——不限于编程 agent。设计立场非常鲜明：所有记忆都是 Markdown 文件，一个目录就是唯一事实源；旁边的 SQLite 索引只是缓存，删掉随时可以重建。这意味着记忆可以直接用 git 管理，AI 改了哪条记忆，一条 diff 就能审计出来。

为什么本期选它：本周 +782 星是开发库类第一增速，距创建（2026-09-01）只有六周就站上 ★3,032，90 天 165 次提交。技术上有两个值得注意的克制设计：检索走三路——BM25（FTS5）召回、可选向量插件经 RRF 融合、再留一个 ls/grep 可遍历的目录回退，索引坏了也不丢数据；「sleep-time」整理层按价值合并与遗忘，但删除记忆只以提案形式由用户确认，运行时没有乱删的权力。通过 mem-mcp，任何支持 MCP 的 agent 都能挂上这套记忆。

适合谁：用 Claude Code、Codex CLI 且在意记忆可控、可审计的开发者——「记忆是纯文本」这一点在同类里独一份。风险观察点：尚无正式发版，源码安装、要求 Python 3.12+，六周项目的接口随时可能变；7 天仅 9 次提交、8 位贡献者，小团队节奏，长期维护能力有待观察。

+3,565 星登顶全站：claude-mem 距十万星一步，AI 记忆赛道彻底内卷

thedotmack/claude-mem

自动捕获 agent 每一步操作、压缩成语义摘要存进 SQLite、下次会话自动注入——这个持久上下文插件本周增速近乎第二名两倍。

99k Star+3565 本周260 c/7天143 贡献者
阅读全文 ↓

claude-mem 名字里带 claude，实际上 Claude Code、OpenCode、Codex 等主流编程 agent 都能用。它做的是「持久会话上下文」：通过生命周期钩子自动捕获 agent 每次工具使用记录，压缩成语义摘要存进本地 SQLite，后续会话再把相关上下文注入回去——全程不需要你手动记录任何东西。

为什么本期选它：本周 +3,565 星，全站第一，几乎是次席 Octop（+1,792）的两倍；总星 ★98,735，距离 10 万星一步之遥。检索设计是关键词+语义混合：SQLite 分层存会话、观察、摘要三层数据，Chroma 向量库做语义召回，4 个 MCP 工具（search / timeline / get_observations）分层查询，另配 Web UI 实时查看记忆流、管理隐私排除项。v13.29.0、143 位贡献者、7 天 260 次提交，工程节奏已经相当成熟。

适合谁：重度 AI 编程工具用户——换会话不换上下文，项目记忆自动延续，开箱即用。风险观察点：自动捕获意味着工作痕迹持续落入本地库，隐私边界依赖排除配置，共用机器的环境要留意；版本迭代极快（已进 v13 大版本），频繁升级下接口可能有变动；对比本期类别席的 agent-memory，它是应用层插件而非可嵌入运行时，深度定制能力弱一些。

九年 46.5k 星按下停止键：awesome-cheatsheets 停维，一代人的书签该更新了

LeCoupa/awesome-cheatsheets

2017 年创建、4.6 万星、6,700 次 fork 的速查表标杆，最后一次推送停在 2026-04-12。文档仓库停维不是事故，但「awesome 策展」的时代正在翻页。

47k Star+9 本周0 c/7天133 贡献者
阅读全文 ↓

2017 年创建、★46,540、6,691 次 fork、133 位贡献者——awesome-cheatsheets 是「awesome 系列」黄金年代的标志性仓库：bash、JavaScript、Python、MySQL、Redis……每个主题一份单文件速查表，内容整理自官方文档和书籍，是一代开发者浏览器书签里的常客。但它的最后一次推送停在 2026-04-12，90 天零提交，本站已将其列入停维预警名单——这也是本周事件席捕获的最高级别信号。

为什么值得一个深读席位：文档类仓库停维和工具类停维性质完全不同。速查表的存量内容依然有效——MySQL、Redis 的基础命令十年没变，新人拿来入门照样好用；真正停掉的是「跟进」：新版本语法、新工具条目不会再更新，引用时需要自己核对时效。它更像一个提醒：人工策展的 awesome 清单，维护动力正在让位于随问随答的 AI 工具。

适合谁：新人快速上手某语言或工具的入门材料依然推荐；生产环境的参考请以官方文档为准。风险观察点：本站将其归入 MySQL 生态资料位，停维状态会持续体现在停维预警榜（本周全站共 987 个千星级工具停维或归档），直到上游标记归档或恢复推送。
