**OtterMind/Chat2DB**

**本周重点解读：Chat2DB**

**① 解决什么问题**  
为开发者、DBA 及数据团队提供跨平台（Windows/macOS/Linux）的 AI 数据库客户端，整合 SQL 工作台与自带模型（BYOM）的 AI 助手，解决多数据库管理、SQL 编写优化及数据可视化需求。

**② 核心亮点**  
- 支持 40+ 数据库（MySQL、PostgreSQL、MongoDB 等），可通过配置扩展新 JDBC 数据源，无需改代码。  
- 内置 AI 助手，支持自然语言生成、解释、优化 SQL；提供 SQL 编辑、补全、格式化及执行历史。  
- 开源 CLI 支持 MCP，并具备数据导入导出、仪表盘图表及 ER 图功能。

**③ 适用场景/注意事项**  
适用于本地化数据库管理与 AI 辅助开发场景。桌面版需从 GitHub Releases 下载安装；Docker 部署要求 Docker 19.03.0+ 及 Compose V2。AI 功能需自备模型 API，数据完全本地运行。
