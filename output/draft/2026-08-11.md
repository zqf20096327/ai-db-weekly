- 提供开源 CLI 并支持 MCP 协议，可扩展自动化工作流。

**③ 适用场景/注意事项**  
适用于日常数据库管理、SQL 开发及轻量级 BI 场景。桌面端需从 GitHub Releases 下载安装；Docker 部署要求 Docker 19.03.0+ 及 Compose V2。AI 功能需自备模型密钥，数据本地处理。
