**① 解决什么问题**  
为开发者、DBA 及数据团队提供跨平台（Windows/macOS/Linux）的 AI 数据库客户端，整合 SQL 工作台与自带模型的 AI 助手，解决多数据库管理及 SQL 编写优化效率问题。

**② 核心亮点**  
- 支持 40+ 数据库（MySQL、PostgreSQL、ClickHouse 等），可通过配置扩展新 JDBC 数据库，无需改代码。  
- 内置 SQL 编辑、补全、格式化、执行历史，及数据导入导出、仪表盘图表、ER 图功能。  
- AI 助手支持自然语言生成/解释/优化 SQL，模型由用户自带。  
- 提供开源 CLI 并支持 MCP 协议。

**③ 适用场景/注意事项**  
适用于本地数据库日常管理、SQL 开发及数据分析场景。桌面版安装即用，Docker 部署需 Docker 19.03.0+。AI 功能依赖用户自行配置模型，数据完全本地运行。
