- 开源 CLI 支持 MCP，可本地运行，AI 模型由用户自带。

**③ 适用场景/注意事项**  
适用于日常多库管理、SQL 开发及数据分析场景。桌面端需从 GitHub Releases 下载安装；Docker 部署要求 Docker 19.03.0+ 及 Compose V2。AI 功能需自行配置模型，数据完全本地处理。
