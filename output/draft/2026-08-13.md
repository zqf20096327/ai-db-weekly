### 本周解读

**malisper/pgrust**

**本周重点解读：pgrust**

**① 解决什么问题**  
用 Rust 重写 PostgreSQL，目标是在保持 wire 与 SQL 方言兼容的前提下，通过新架构解决原生 PG 的并发调度与内存溢出（OOM）风险，并提升查询性能。

**② 核心亮点**  
- 通过全部 46,066 项 PG 回归测试，宣称性能优于 PG 与 ClickHouse。  
- 引入向量化 JIT 执行器、线程级并发模型、查询调度器及内置 OOM killer。  
- 完全基于 Rust 实现，无 C 代码依赖。

**③ 适用场景/注意事项**  
- 明确标注“非生产就绪”，不建议存储重要数据。  
- 现有 PG 扩展不兼容，PL/Python、PL/Perl 等未移植。  
- JIT 编译器仅针对 Graviton4 优化，其他平台性能可能受影响。
