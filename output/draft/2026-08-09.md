**本周重点解读：Chat2DB**

**① 解决什么问题**  
为开发者、DBA 及数据团队提供跨平台（Windows/macOS/Linux）的 AI 数据库客户端，将 SQL 工作台与自带模型（BYOM）的 AI 助手整合，解决多数据库管理、SQL 编写优化及数据可视化需求。

**② 核心亮点**  
- 支持 40+ 数据库（MySQL、PostgreSQL、MongoDB 等），新 JDBC 库可仅通过配置扩展，无需改代码。  
- 内置 SQL 编辑、补全、格式化及执行历史，并支持数据导入导出、仪表盘与 ER 图。  
- 提供开源 CLI 及 MCP 支持，桌面端可本地运行。

**③ 适用场景/注意事项**  
适用于日常数据库管理、SQL 调试及团队协作。需注意：AI 功能需自行接入模型；桌面版需从 GitHub Releases 下载安装，Docker 部署要求 Docker 19.03.0+ 及 Compose V2。
