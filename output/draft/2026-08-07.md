**① 解决什么问题**  
为开发者、DBA 及数据团队提供跨平台（Windows/macOS/Linux）的 AI 原生数据库客户端，整合 SQL 工作台与自带模型接入的 AI 助手，解决多数据库管理、SQL 编写优化及数据可视化需求。

**② 核心亮点**  
- 支持 40+ 数据库（MySQL、PostgreSQL、MongoDB 等），新 JDBC 库可仅通过配置扩展，无需改代码。  
- 内置 SQL 编辑、补全、格式化及执行历史，并支持 AI 生成/解释/优化 SQL。  
- 提供数据导入导出、仪表盘图表及 ER 图，附带开源 CLI（支持 MCP）。

**③ 适用场景/注意事项**  
适用于日常数据库操作、SQL 教学及多源数据管理。桌面版需从 GitHub Releases 安装，Docker 部署要求 Docker 19.03.0+；AI 功能需自备模型密钥，数据完全本地运行。
